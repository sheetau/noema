# 真空領域と場の物理的な規約

第六節の見出しと続く本文で使うために、真空領域・物理的な二場・六つの回転方程式を結ぶ依存定義を構成する。対象の一文は、方程式の変換と運動による起電力の性質を主題として案内するu0152である。まだ見出し全体を記述したとは数えず、その主題を説明するための関係を整える。

真空は、指定した四座標領域の全有効点で、物質的な占有がないという読みを採る。既存eiroは物体の物質が同じ系・長さ時間単位でその位置・時刻を占有する関係なので、全個体に対する不存在を構成できる。正味電荷が零でも中性物質があれば、この条件は満たさない。物質の所在が未知の場合も、単に記録がないことから真空とはしない。新しい真空専用の基本記号は不要である。

領域に含めない外部の物体や発生源は許す。領域に含めた表面に物質があれば真空条件は満たさない。光や電磁場そのものを物質占有へ置き換えず、場の三成分が非零である真空も許す。領域は非空とし、座標役割、校正されたCartesian基底、長さと時間の単位を固定する。この非空性だけで領域の開性や微分可能性を認定するわけではない。

二場は同じ系・文脈・領域へのznnで割り当てる。それぞれの数値関数をeirnで場単位へ結び、eirmの単位電荷あたりの電気的作用と、eiruの速度依存の磁気的作用の規約を共有する。換算係数は正の有効実数とし、同じ電荷・力・長さ時間単位を保つ。場を定義する試験電荷の規約を、真空内に実際の粒子がいるという条件にしない。特定の担体に働く力は既存eibs/eicoで、同じ出来事・電荷・場の評価・速度を別途結ぶ。

ejspは、この真空領域と場の規約へ同じ二場・同じ領域のs5yを接続する。s5yは18偏微分と六つの回転式を保持する。正のlight値を光速度として同定する本文の参照は適用時に必要で、正値だけから物理的な光速度を認定しない。六式を発散条件の代わりにせず、物質の不在だけから発散零や変換後の方程式をNoemaで導出したとも扱わない。

正本では全四座標関数を量化する。検査は明示した二点への代入診断と、各点の物質占有の本体、場と単位の結合、六式への同一引数の受け渡しを分ける。空領域、内部の物質、外部の物体、時刻・単位の取り違え、非零場と非占有を対照する。全実数・全関数域の有限列挙は拒否する。以前の357主張と意味判断は保持し、u0152の主題への接続が済むまで新しい全単位判断は行わない。
