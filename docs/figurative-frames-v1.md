# 対象の意味と比喩による描写

[比喩の提示関係](../examples/v014/figurative-frames.noema)を既存の文法で追加し、[カントの自然による宣告の草案](../examples/v014/kant-nature-depiction.noema)へ接続した。自然的成熟への移行と、それを自然による宣告になぞらえる描写を異なる式記述として保持する。描写を参照するだけで、自然が実際に発話したという事実にはしない。

## 表現の条件

基本関係qaは、著者・談話節点・対象の性質記述・描写の性質記述・文脈を結ぶ。二つの性質記述の人物引数を対応させることも、その意味規約に含める。qhは両記述が異なることとqaを要求する。記述の内容を実行しないため、真偽が一致している別々の記述を混同しない。

qiはqhと、明示的に渡した対象内容の成立を組み合わせる。描写の成立は要求しない。ただし、対象の式記述と内容が対応していることは呼出側の責任であり、qiがその対応まで証明するわけではない。この制限を隠して、任意の内容を対象の意味として認証する用途には使わない。今回の原文草案はqhを用いる。

これは比喩の対応を明示する形式である。比喩の自動発見や、描写から適切な意味を推論する処理、比喩の全理論を実装したものではない。

## 原文への接続

対象の記述には、既存の自然的成熟への移行kfを使う。描写qgは、同じ人物の履歴と生涯範囲を参照し、その範囲より十分以前に自然qbがその人をqfの状態として宣告した、という内容を組み立てる。qfは自然的な発達上の依存によって他者の指導を必要とする状態klの否定であり、現実に誰からも指導されないという条件とは異なる。

qbを個体型で参照しても、人間・意思・発話能力を持つとは断定しない。宣告の関係qcも、宣告の正当性、宣告内容の真理、宣告による地位の成立を含意しない。自然と宣告の一般的な意味は未完成の基本関係として明示している。

元の原因説明と割合の条件は保持し、別の文でkfとqgの比喩的な提示関係を記述した。これにより、描写の字義的な真理を本文の成熟条件へ追加することを避けた。ただし、比喩の評価的効果やラテン語の独立した読みを含め、原文との完全な同義性は未確認である。

語義の参考には[Deutsches Rechtswörterbuchのfreisprechen項目](https://drw-www.adw.uni-heidelberg.de/drw-cgi/zeige?index=lemmata&term=freisprechen)の検索取得抜粋を用いた。そこでは裁判に関する用法と義務からの解放に関する用法が区別されている。直接のページ取得はキャッシュミスとなり、項目全文や原資料画像は確認できていない。この資料だけでカントの解釈が一意に決まるとはしない。[照合記録](../data/figurative-reading-review-v1.json)に取得範囲と制約を保存した。実行時に辞書を参照して意味を代入する処理はない。

## 検査と再現

対象の真偽・描写の真偽・比喩の提示の8組合せ、著者等の参照を変えた7例、宣告の主体・対象・状態・時間範囲を変えた8例、既存の主張と比喩の付記を分離する2例を検査する。内容を評価してはいけない箇所では、呼び出すと失敗する基本関係を渡し、意図しない実行がないことを確認する。

```powershell
python -S -m scripts.compose_figurative_frames
python -S -m scripts.check_figurative_frames --verify-only
python -S -m noema parse --input examples/v014/kant-nature-depiction.noema --output artifacts/kant-nature-depiction.json
python -S -m noema render --input examples/v014/kant-nature-depiction.noema --alphabet v2 --output artifacts/kant-nature-depiction.svg
python -m pytest -q
```

宣告の描写を評価する検査だけ、有限実行器の計算予算を200万段階に指定する。通常の評価方法を使い、呼出しの観察を結果のキャッシュで省略しない。完全形・短縮形・固有文字の往復、基礎定義の監査、入力ハッシュを[検査記録](../reports/figurative-frames-v1.json)に保存する。

全文の意味確認済み単位数はカント0/20、アインシュタイン0/282のままである。今回の検査は明示した読みの構造と有限モデルでの区別を確かめるもので、原文全体の意味一致の代わりにはならない。

新規4件を含む全790テストが通過した。文書の再生成照合、検査記録の再現、CLIのJSONと原文書の構造一致、固有文字SVGの出力も確認した。
