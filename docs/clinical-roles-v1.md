# 健康一般の助言と、治療に関する判断の役割

カントの代行例にある医師について、身体の病気・損傷・不調への対応を判断する役割を明示した。旧srは健康一般の専門的な助言役であり、体力増進などの助言だけを務めとする役割も条件を満たし得た。旧定義はrqxtとして保存し、本文srでは対象分野・主要性・専門性を同じ役割へ結ぶ。

## 対象分野と、役割の四条件

基本関係hzw2は、事柄・本人・状況を受け取り、その事柄が本人の身体の病気・損傷・不調を見分け、防止・軽減・回復のための対応を判断することに関わると述べる。一般的な体力増進や好みへの助言だけとは区別する。現に病気があることや、判断の正しさ、措置の成功までは要求しない。

hzw3は、同じ本人の同じ判断と同じ事柄へ、既存の身体的健康shとhzw2を結ぶ。hzw4は、その仕事について他者を援助する専門的知識・技能を、既存のhzwqで記述する。これらを役割の機能や資格要求として引用するだけでは、受け手の自己判断や、担い手の実際の技能を実行評価しない。

一般定義rqxsは、役割の保持・機能・機能の主要性・資格要求の四関係を一つの役割で満たす。同じ人が複数の役割を持っていても、別々の役割の条件を寄せ集めることはできない。この定義は職名を受け取る処理ではなく、修理など別の活動と資格の記述にも使える。

本文srは、従来の継続的な健康上の援助実践rqxjに加え、hzw3への援助を主要な務めとし、hzw4を資格要件とする役割を要求する。主要性を唯一の務めや時間割合へ置き換えず、役割保持者が必ず十分な技能を持つとも要求しない。本人の技能はhzw4を別途評価して記述できる。

旧srを単に否定する変更ではなく、対象分野の指定を変えた定義である。引用された仕事の記述は別々の識別子を持つため、臨床上の機能を明示しただけで一般的健康判断の機能も登録済みだとは自動推論しない。検査では、旧来の一般役割しかない場合と、臨床上の役割だけを明示した場合を分けて比較する。旧役割を使いたい文章はrqxtを参照できる。
