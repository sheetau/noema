## 対応の範囲

二系の四座標は同じ一つの出来事に属する。全対象出来事が両側の値を持ち、同じ静止系の値には同じ移動系の値が対応するという条件を保つ。別の記録が同じ四値を持つことや、同じ場所・時刻に別の出来事があることを許す。任意の実数四組の実現、逆向きの一意性、両系の値の一致は加えない。
