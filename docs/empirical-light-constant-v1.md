# 経験に従う光速度の定数設定

u0019〜u0021の112非空白本文文字とM0040を、一つの文として接続する。著者は先の時刻定義に加えて、経験に従い光の往復速度を普遍定数として採用する。具体的な実験名や現代の光速の数値は原文に補わない。

M0040の分子は二地点間の一方向距離の2倍、分母は同じA時計の帰着時刻から出発時刻を引いた差である。正の距離・経過時間・速度を要求し、既存saiの積の形へ接続する。反射側のB時計の指示は分母に使わず、その原点合わせや同期式を速度測定の条件に加えない。

普遍性は同じ系と互換単位での全適用試行に一つの共通値tcを使う条件として表す。位置・方向・正の距離・出発時刻を変えた理想的試行も含み、観測済みや成功した試行だけの一覧とはしない。既存tdの範囲をこの全適用範囲と一致させた上で、sanの完全性・非空性・全試行の速度条件を用いる。

距離はth、往復の両真空区間はtk、互換単位はti/tj、同じ光と時計の読取りはsalのプロトコルで確認する。括弧内の真空中の光速度はこの同じ値の説明として接続する。式の具体化、nochの追加、経験への帰属、先の時刻定義からの順序を保持する。

固定された距離と経過時間について速度が定まる算術と、全試行で値が共通という物理的採用は異なる。距離・真空・単位の明示的規約を使うが、その測定器や微視的な物理理論までこの文で導入しない。有限モデルは結合と式の検査に使い、全物理状況や意味同値の自動証明へ広げない。
