# 公的な活動への許可を、条件付きの能力変化へ結ぶ

カントu0011の「自由を残した場合のほぼ避けがたさ」に向け、既存の公的使用の許可と、同じ公衆の能力変化を条件付きの可能性へ接続した。ここでは自由の規範的な読みを採り、公的な理性使用に分類される全活動への積極的な許可と、不実行要求の不在を使う。物理的機会や社会的妨害の不在、権利の保障まで、この許可だけで説明したとはしない。

## 同じ範囲に条件を課す

`rqta`は、非空の人の範囲を取り、全員の適格性と、各人に対象となる役割・活動の組があることを要求する。その全組について、同じ出所・評価状況・実行記述への許可を既存の`rdm`で調べる。ある人の許可を別人へ流用せず、一つの役割で許可されていても別の対象役割の不足を隠さない。不実行の要求と衝突する許可も受理しない。

`hzna`は、この構成へ想定読者の範囲`h6t`と公的使用の分類`zzo`を渡す。人・活動・役割の範囲は一つの参照文脈で固定し、規範だけを候補状況で評価する。候補の中で禁止された活動を分類から外して、「残った全活動が許可されている」と判定することを防ぐ。実行記述`zzq`は引用したまま扱い、実行関係`cg`を評価しない。

この構成は、各人に対象となる公的活動が少なくとも一つある読みである。活動範囲が空の人一般について、自由がないと結論する分類器ではない。また、想定読者としての公衆と、公的発言の宛先である読者世界全体を同一個体にする条件は設けていない。

## 同じ公衆の変化を可能性の目標にする

`hznb`は、参照文脈で固定した想定読者の範囲を、既存の`hzmy`へ渡す。ある過程・開始点・終了点を通じて、指定した広がりの能力変化が成立するという条件である。候補状況ごとに過程の有無、履歴、能力、内部の関与、因果を評価するが、対象の公衆や範囲を成功者だけに差し替えない。

`hznc`は、`hzna`を条件、`hznb`を目標として、条件付きのほぼ必然を表す`rqsu`へ接続する。条件が成立する候補は、同じ候補範囲から式の内部で選ぶ。成功する候補だけを別途指定する引数はない。自由の条件がどの候補にも成立しない場合、空の全称から必然を導かない。

`hznd`は、同じ条件と目標を`rqsv`へ渡し、別の比較対象より可能性が高いという判断も併記する。比較対象の内容は引数として明示する。これを個人一般の自己啓蒙へ自動的に同定しない。近さは前段の質的な尺度を引き継ぎ、候補の人数や件数から確率を算出しない。

## 検証

一般形では二人の所属・許可・不実行要求の64組合せを、独立した集合の計算と比較する。公的使用への接続の18対照では、対象者・役割・活動・出所・実行記述・評価状況の取り違え、空範囲、二人目の許可の不足、候補内での活動範囲の縮小、極性、反対要求を調べる。読者世界全体の宛先を別個体にする例と、三つの未知入力も検査する。許可だけの評価では実行関係を利用不能にしている。

可能性への接続は、保存した能力変化・規範・尺度の定義を同時に実行して検査する。集団の変化を、別の真偽値を返す基本関係へ置き換えていない。候補内での変化が真と偽になる場合、条件に該当する候補が空の場合、条件を成功例だけに絞ると厳密な「ほぼ」ではなく必然になる場合、変化の因果が欠ける場合を区別する。現在の許可や変化がなくても、条件付きの判断自体は成立するモデルも確認する。能力変化の因果と程度の値が未知の場合は、それぞれ推測せずに返す。

一般形と許可の代表例はメモ化なしで評価する。存在量化を重ねた変化と可能性の同時評価にはメモ化を用いるが、式の短絡化や定義の差し替えは行わない。初回の同時評価は計算量上限に達したため、本文では読者範囲の関数を存在量化の外で一度束縛し、検査でも同じ広がり基準を複数の判断へ共有する形に整理した。条件・反例・領域は減らしていない。現在の許可、候補内の許可、三時点の変化、四つの出所の政策による二判断を、13項目の真偽列として比較する。因果があるモデルと欠けるモデルの両方を検査する。後者では過程の存在探索を最後まで行うため、共有後も旧検査上限の6,000万ステップを超えた。同時評価の二モデルに限り上限を1億8,000万ステップとし、通常の解釈器は変更していない。検査は有限のモデルについての結果であり、現実の全活動・候補の網羅を証明するものではない。

## 原文について残る内容

規範の出所は明示した引数であり、原文の不定の主体を特定の統治者へ確定していない。自由が過去から維持される経過や、活動を妨害しない社会的条件は追加で記述する必要がある。候補の評価状況と変化の前後は区別するが、自由を残してから将来の啓蒙に至る時間的な関係を、この構成だけで完成したとは扱わない。

目標の`hznb`も、集団内の能力変化を記述する構成である。公開された議論、理性的な自己評価や自ら考える態度の普及を含む、公衆の自己啓蒙全体の同義文ではない。社会的な公衆の範囲、原文に適した広がりと比較対象、`ja`の強め方、著者への帰属を引き続き接続する。したがって、新しい著者主張・原文対応範囲・意味確認済み単位は加算しない。
