# 共通零原点からの球面波

u0087–u0088は、t=τ=0で両系の原点が重なる出来事から球面波を放出すると仮定し、波が到来した点の静止系の座標について球面方程式を示す。原刊901頁の二文と表示式を一続きに読む。

波を構成する光線は非空とし、その全てを同じ放出出来事からの現在のK測定区間へ結ぶ。到来には、同じ光線・放出元・区間・局所時計・両端の四座標・幾何学的光路長を使う。先行の零原点条件ei46を同じ放出へ適用し、全時刻での原点や時刻の一致には拡張しない。

球面波は、全対象出来事の現在の座標範囲で、到来と正時刻の球面式が過不足なく一致する波面として記述する。数式を満たす点だけを検査対象として選ばず、波面上の到来の欠落と波面外の余分な到来を区別する。これは全対象範囲についての記述であり、有限例だけで連続空間を確認したという主張ではない。

式x²+y²+z²=V²t²は、時刻の正負を単独では区別しない。未来側の到来には正時刻を別に要求し、零時刻の放出点は放出条件に置く。Kでの同じVの伝播を、既存の全区間法則ei43にも結ぶ。場の振幅・偏光・波長や、全実数四組の現実の実在はこの波面の読みへ追加しない。

後半の点は、同じ波がいま到来した任意の点として扱う。全出来事と現在のK座標記録を量化し、その同じ記録の三位置と時刻を数式へ渡す。放出の仮定と到来点の式への帰結を同じ著者へ帰属し、後続の座標変換計算や両立性の証明完了を先取りしない。
