# 角度を含む速度合成式

アインシュタイン1905年論文§5のM0257を、既存の実数・平方根・角の二成分から記述した。新しい文法や意味演算の基本記号は追加していない。追加した基本記号一つは本文箇所への参照であり、式の内容は九つの定義で構成した。

記述する式は、cとsを角の余弦・正弦成分として、次の形である。

```text
c²+s² = 1
A = v²+w²+2vwc − (vws/V)²
B = 1+vwc/V²
U = √A / B
```

保存済みの原刊906頁画像で式を照合した。電子転記では分母にsinがあるが、原刊ではcosである。[訂正記録](written-math-corrections-v1.md)の層を明示的に使い、原データと訂正後の両方のハッシュを対応表へ残した。原データは変更していない。この照合はM0257の式について行ったものであり、角の枝や符号に関する原文全体の規約を確認した証拠にはしない。

`s2t`はV>0、w≥0、有効な実数切断、単位円条件、A≥0、B≠0を要求し、非負平方根を符号付きのBで割る。分母を絶対値へ置き換えたり、二乗して符号の情報を捨てたりしない。Bが負なら式単独の値も負になり得る。本文への接続`s2v`は、同じ点の同じ評価時刻の座標微分から得た非負の速さUと結ぶため、この場合には条件が両立しないことも記録する。

たとえばV=5、v=3、w=25、c=−3/5、s=4/5なら、A=400、B=−4/5であり、式の値は−25になる。一方、前段階の成分から得る非負の速さは25である。二乗式だけではこの違いが消える。超光速の入力を含むこの例を、原文がその範囲への適用を主張した証拠にはしない。

既存の成分式への接続では、縦成分u=w*c、横成分yの二乗y²=w²*s²と、非負のノルムを要求する。横の符号を反転しても合成後の速さは変わらない。正の基準系速度については、前段階の向きなしの角からこの対応が得られることを有理数の多項式として確認した。負の基準系速度では、向きなしの角の余弦と縦成分の符号が合わない場合があるため、同一視しない。

検査では、Bが正の場合に二乗式と平方根を含む式が一致すること、成分から角への置換、二つの非負の速度の入れ替え、正弦の符号反転を確認した。|v|<Vかつ0≤w<Vなら分母が正となる条件も確認した。これらは有理数多項式の補助検査であり、全ての実切断上で体や平方根の法則を機械的に証明したものではない。

十の代数検査、実切断の具体例19件、成分との接続10件、本文の速さと文脈への接続10件、帰属5件を記録した。平方根が有理数となる具体例では、保持した切断と厳密な有理数演算を使い、近似値の比較をしない。有限検査器は式を先行評価するため、定義域外の平方根・逆数に二通りの仮の値を返し、いずれの場合も定義域の条件が入力を拒むことを確認した。仮の値を数学上の平方根や逆数とは解釈しない。

新規8件と関連28件のテストを確認した。最初の24件の実行では21件が通過し、残る3件は検査例が有理数平方根の範囲を外れていたため失敗した。同じ単位円条件の違反を有理数平方根で検査する例へ変更し、その3件と進捗集計の12件が通過した。通常記法・短縮記法・固有文字の構文往復、CLIのJSONと構文木の一致、SVGのXMLとしての読み込みも確認した。全テストの実行と字形の目視確認は今回の検査に含まない。

累積文書は基本記号481、定義709、文134、正規形185,052文字である。親文書から2,665文字増えた。定義を含む累積長であり、一文の翻訳長ではない。

M0257への部分対応が増え、アインシュタインの部分草案は123/282区間、数式要素は228/446件となった。原文の明示文字範囲は13,113/35,614文字（36.82%）のままである。計算が容易だという評価、二速度の対称性への注目、前後の導出、近似、歴史的な角と適用範囲の規約は未完である。両作品とも意味一致確認済みの区間は0であり、今回の検査を全文の意味一致確認とは扱わない。
