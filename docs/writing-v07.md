# 「一緒に」と「それぞれ」を区別する

集団を書くだけでは、共同で動くのか各成員について述べるのかは決まらない。文語0.7ではこの違いを明示できる。先頭は`g:`。次は犬と猫を共同の主体として、子供を見る文である。

```noema
g:w-w i[no w[mu][si] fo].
```

`w-w i[...]`は中の節の主体`i`を共同の主体にする。集団を表す`w[mu][si]`だけの場合とは異なる。

「犬も猫も眠る」のように各成員について述べるときは、成員を指す名前を置く。

```noema
g:w-p a[w[mu][si]][po p a].
```

読み方は「犬と猫の集団の、各成員aについて、aは眠る」。`a`は好きな参照名に変えられるが、使えるのは二つ目の角括弧の中だけである。犬と猫は既存の語、各成員を指す仕組みはどの明示的な集団にも共通であり、対象の種類ごとに新しい文法を学ぶ必要はない。

否定の位置には注意する。

```noema
g:w-p a[w[mu][si]][u[po p a]].
```

これは各成員が眠らないことを述べる。

```noema
g:u[w-p a[w[mu][si]][po p a]].
```

こちらは全員が眠るわけではないことを述べる。一方だけが眠る状況でも成り立つ。

集団全体に通常の参照名を付ければ、次の文でまた使える。次は犬と猫がそれぞれ眠り、その後の文では同じ集団を共同の主体として子供を見る。ただし文の順序だけから、出来事の前後関係は追加しない。

```noema
g:w-p a[w[mu][si]o pets][po p a].
w-w i[no p pets fo].
```

練習として、二つの文の違いを説明してほしい。

```noema
g:w-p door[w[maj-sai][maj-saj]][t 6-sam qo n"葵" p door].
```

```noema
g:w-w j[t 6-sam qo n"葵" w[maj-sai][maj-saj]].
```

前者は赤いドアと青いドアの各々について、葵が明日開けることを述べる。後者は二つのドアを対象全体として開けることを述べる。前者の出来事が時間的に別々だという条件や、後者の具体的な開け方までは指定していない。

試すには`/writing`へ入力するか、CLIを使う。

```powershell
python -m noema parse --text "g:w-p a[w[mu][si]][u[po p a]]."
python -m noema render --text "g:w-p a[w[mu][si]][po p a]." --output artifacts/distribution.svg
```

固有文字にしても参照と作用範囲は変わらない。「2匹の犬」という数量だけから、別々の2匹を導入する機能はまだない。また、この記法を自然言語から自動で選ぶ翻訳器は未完成である。入れ子、型、旧版の読込みと変換については[仕様](spec-v07.md)を参照。
