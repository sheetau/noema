# 中心で止まる接続と円周からの斜線・試作08

更新された `concept/alphabet-concept.md` に従い、独立した半径線と円周・中心の重なりを減らした。通常文六例、カントの既存構文三例、アインシュタイン二式を `output/alphabet-circle-v8/overview.png` に集約し、下部に大円の斜線八種類の確認欄を加える。確認欄は例文ではなく、構造が生成できることを示すもの。

## 常用する接続

半径線を全ての中円・大円に足す方式をやめ、次を基本にする。

- 構文を続ける線は外から入り、接続先の中心で止まる。円周で止まる線とは区別して記録・検査する。
- 原子的な参照などでは、中心に線を入れず円周だけで接続する。小円の中心禁止も維持する。
- 文頭で中心接続を使う場合は、円の外から始まる導入線とする。円内だけに収まる半径線ではない。
- 独立した半径線は内容の境界を示す場合などへ限定する。八方向を使えることと、全方向を毎文へ出現させることを分ける。

今回の107個の主部では、中心で止まる接続48、中心に線を入れない形47、文頭の導入線8、円周からの斜線3、独立した半径線1となった。小円などの側枝と確認欄はこの主部の集計に含めない。

円周・中心を重ねる複合形は、参照が繰り返される場合へ絞り、出現数にも上限を設けた。今回の主部では試作07の25箇所から14箇所へ減少。共有された論理積の同心円は別の構造として保持する。

半径線を取り除くだけでは同じ大きさの参照が区別できなくなる場合があったため、参照登録に基づく中心接続・円周接続の違いと間隔にも識別を持たせた。三項の受け渡しについて全六順列で字形が異なり、改名では変わらないことを検査する。画像単独の全参照の一意な復号まで証明したものではない。

## 大円の斜線

中心から四方向へ出る45度線は試作07でも生成可能だったが、使用した構文の優先方向に出現が偏っていた。これに、**円周から外へ伸び、中心を通らない四方向**を追加した。

どちらも終点は大円の上端・下端と同じ高さとし、その先で曲がったり他の線につながったりすることを拒否する。円周から出る場合は円周上を始点とし、中心との間に線を描かない。最新の指定に合わせ、この形を使う大円については従来の「必ず中心に線を持つ」条件の例外とした。何も線を持たない大円を一律に許す変更ではない。

同じ `nucleus` と幾何検査を使って中心始点4種類、円周始点4種類を生成し、一覧下部へ掲載する。例文中の頻度を増やすための割り当てはしない。

## 他の選択肢の確認

| 形 | 確認内容 |
| --- | --- |
| 中円・大円の片側の半径線 | 八方向を引き続き生成可能。例文への出現を強制しない |
| 中円の中心で止まる外部接続 | 八方向からの生成と実際の中心終端を検査 |
| 小円・中円の、中心を通らない円周接続 | 八方向を検査。小円の中心線は依然禁止 |
| 大円の45度線 | 中心始点4種類と円周始点4種類を同じ描画器で検査・表示 |
| 円の複合形・一回の直角曲がり・限定的な接触 | 試作07の生成候補を保持し、頻度を下げることと候補の削除を区別 |
| 小円を含む同心円を可視線で結ぶ形 | 小円の中心禁止と、円内の線を中心から片側へ出す条件に反するため採用しない |

全ての図形の組合せを網羅した最終仕様ではない。確認欄と検査は上記の構造が生成可能である証拠であり、任意の文脈で衝突なく採用できるという意味ではない。
