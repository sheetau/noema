# 等速並進する二座標系での法則の独立性

第一原理u0025の全255文字・226本文文字を扱う。物理系の状態変化を支配する法則は、互いに等速並進する二座標系のどちらへその変化を関係づけるかに依存しない、という定式化である。

二系の運動条件は、原点だけで判定しない。一方の系に固定された原点・軸・格子・計器の配置点の全範囲を、他方の系の同じ長さ・時間尺度で追う。全時点対の全配置点で変位が同じ速度ベクトルと経過時間の積に等しいことを要求する。全配置の同一変位により相対回転を除き、途中の加速も全時点の条件で除く。速度の方向や符号は限定せず、零速度を退化例として許す。二系の時刻が共通だとは仮定しない。

法則の内容は、同じ一般的な物理量の関係・適用条件として両系で成立することと、候補履歴の適合が両系で保存されることを合わせて読む。各履歴が同じ物理系へ結ばれ、各系にその履歴の記述が存在することを先に要求する。法則に適合しない候補も比較し、記述の追加や欠落によって不一致を隠さない。座標値の一致や、全候補が法則に従うことは要求しない。

原理の全範囲は物理系の状態変化一般である。先の推測eifjは電気力学・光学の共通法則と絶対静止の特性否定を含むため、同じ式をそのまま代入しない。著者が今回の定式化を先に名付けた相対性原理の定義として提示する関係と、今回の内容を分けて保存する。この対応は、二式の論理的同値を処理系が証明したという意味ではない。

数値の検査には、保持した有理数切断の厳密な演算を使い、全実数の標本化を行わない。等速・加速・回転の有限配置例、引数結合、全候補の適合保存、原理の定義提示を別々に検査する。物理的な範囲の完全性、座標の実現、全法則の真理は外部の意味規約に従う入力であり、有限検査から認定しない。
