# 任用された自己思考者と、同じ人による伝播

独立した判断傾向を持つ人と、自己離脱を経て伝播する人を、同じ人物へ結んだ。その複合条件を、任用された後見役の中にいる複数人と、将来の各評価点へ接続する。原文の別々の条件を、別人の存在だけで満たすことを防ぐ。

## 発信者の判断傾向と、受け手の性向

`hzog`は同じ発信者について、初期の評価点での独立判断への応答傾向`hzhh`と、その点より後に受け手が取得を完了する伝播`hzof`を要求する。前段の自己活動による自立、最初の発信との順序、受領・理解・原因・取得後の持続をそのまま用いる。

発信者の性質は、本人の理解力と理由に基づき、他者の指導によらず、提示された同じ話題について判断する応答傾向である。受け手へ広がる性質は、理由ある自己評価と、全ての人が自ら考える課題を認める判断への応答傾向である。二つの性質を同義としてまとめない。

現在の一回の判断だけでは、指定場面に対する応答傾向を満たさない。判断の話題、用いた理由と支持、本人の理解力、他者による指導を、既存の定義で調べる。場面・重み・閾値が現実の性向を適切に評価できるかは、別途の解釈条件である。

## 任用された同じ人々を数える

`hzoh`は、指定点の母集団が人の範囲であることを確認し、その中で同じ点の任用条件`hzhb`と複合条件を満たす異なる二人を要求する。任用行為の出所・本人・職務・過去時点、過去と現在の委任を結び、自称や現在の職務だけで任用済みとは扱わない。

複合条件は、人と評価点を受け取る関数として渡す。原文の接続例では、その関数の本体で`hzog`を実行する。任用された人、考える人、伝える人を、それぞれ別の存在量化で揃える構成ではない。

ここでは、後見役の中にも複数の該当者がいるという明示した読みを採る。全ての自己思考者が後見役であること、正確に二人しかいないこと、母集団の全員ではないことは要求しない。`sogar`の比較背景や役割の歴史的意味は、この存在条件だけでは説明し終えていない。

## 指定した将来点と、履歴内の全将来点

`hzoi`は、同じ順序付き履歴の基準より後にある非空の指定範囲について、各点で`hzoh`を要求する。時点ごとに該当者が交替してもよく、同じ二人が全期間を通じて該当することは要求しない。

`hzoj`は、同じ履歴の基準点より厳密に後の全点を内部で選び、`hzoi`へ渡す。不成立の時点だけを外した範囲を別に供給することはできない。後のある点で条件を満たす人が足りない例では、前の点だけを選ぶ`hzoi`は真でも、`hzoj`は偽になる。将来点が一つもない場合も偽になる。

履歴自体の完全性は解釈の条件である。有限の評価窓を指定した検査から、無期限の将来や全ての可能世界について成立するとは結論しない。発信者を評価する機会の履歴と、その後に伝達が進む期間枠も区別する。

## 検証の範囲

6テストで、次を確認する。

- 母集団への所属・任用・複合条件の64組合せと5対照。同じ二人が全条件を満たすことを調べる。この一般検査でも任用の定義は実行するが、複合条件には明示した真偽の解釈を渡す。
- 将来範囲の6対照と、選択した点だけの検査と全将来点の検査の違い。人物の交替、将来点の欠如、後の点だけの不成立を区別する。
- 独立判断と伝播を同時に実行する7対照。別々の人に条件が分かれる例では、二人とも複合条件を満たさない。
- 二人の具体例による同一グラフ内の評価。任用、理由ある独立判断、自己活動による離脱、別々の発信行為、受け手の具体的な自己評価・規範承認の性向、取得と持続を実行する。一時点の集団条件は保存された定義をそのまま評価し、短絡評価とも照合する。意味定義を真偽の解釈関数へ置き換えない。
- 七つの未知入力、通常・短縮・固有文字の往復、既存の全意味規約・32文・七単位の確認の保持。

具体例では、同じ受け手の状態に二つの活動が関わる前後区間を設定する。取得の最初・唯一の瞬間や、単独の十分原因を確認した例ではない。将来を含む同時評価の例は、明示した評価窓内の一つの将来機会であり、人物交替は別の有限検査で確認する。

全将来点を含む具体例の通常評価は、対象外の時点についても含意の結論を評価し、1億2千万ステップの上限に達した。この具体例には既存の短絡診断を用い、対象点の任用・判断・離脱・伝播の本体は実行する。保存文書は書き換えず、論理演算を遅延評価する実行用グラフを作る。未知の入力が未使用の枝にあれば通常評価と結果が異なり得るため、通常評価で完了したとは記録しない。小さい将来モデルの七例と一時点の具体的な集団条件で、通常評価と短絡評価の結果を照合する。未知入力の検査は通常評価を使う。

四つの合成定義を追加し、新しい基本関係はない。任用された人を選ぶ一般形は依存先込みで2,002文字、累積本文への追加は1,141文字である。原文対応は既存のカントu0011の137–176と184–217の範囲を補うもので、新しい原文範囲や意味確認済み単位は加算しない。
