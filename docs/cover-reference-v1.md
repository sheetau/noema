# 指示された覆いと直前の制度条件

カント第17区間の成長描写に、「この覆い」の参照先を結ぶ候補を追加した。原文は高い市民的自由の側と低い側を対比し、後者の発展機会の直後に、指示詞付きの硬い覆いと芽の展開を置く。今回は低い自由の側へ対応させる読みを採る。統治制度全般や服従の条件まで含める別の読みを排除する確定ではない。[AA VIII, 41頁29–34行](https://www.korpora.org/Kant/aa08/041.html)

`ryr` は、先行箇所への内容記述の帰属、本文順序、描写物と指示対象の対応を結ぶ。現在箇所と先行箇所の範囲は別々に渡し、同じ著者と発話文脈を保持する。本文上の先行を時間的な先行や因果へ変換しない。引用された内容は評価しないため、指示関係を記述するだけで制度上の効果が実際に生じたとは主張しない。

`iazreference` は直前の低い側の内容 `iafright` と、同じ比較文脈の `iaclower` を使う。高い側の障壁へ指示を移さず、現在箇所の範囲と前の箇所の範囲も混同しない。制度条件は状況、覆いは描写世界の対象として扱い、両者を物理的に同一視する条件は設けない。

`iazselected` は箇所・著者・範囲・発話文脈から覆いを固定する。新しい `iazdepiction` はこの覆いを成長過程の全区間で使い、従来の展開と世話の条件を保持する。以前の描写では任意の覆いを存在量化していたため、指示された物と別の覆いでも成立し得た。対照例では、指示された覆いだけを変えると、旧描写と指示関係は真のまま、新しい描写だけが偽になる。

新しい `iazfamily` はこの描写の提示と指示関係を結び、実際の最終帰属から参照される。旧定義と先行21主張は保存した。本文点検v5で参照経路を調べ、八引数の部分ひな形と14項目の未達一覧を維持する。前段の因果・利益判断を含む条件文の実定義でも、新しい指示が正しい例と別制度を指す例を評価する。

指示の認定そのもの、先行範囲の選択、硬さの尺度や機構、芽の名詞内容、尊厳と全文の意味一致は未完である。参照入力が未確定なら、適当な覆いで埋めない。有限モデルの検査と表記の往復成功を、語義の完成や原文範囲の増加には数えない。
