# 文語0.5：状態から変化を構成する規則

文語0.5は、状態を表す基本語から「その状態になる」「その状態に変える」を規則的に作る。基本概念は0.3の91個を保ち、派生語を基本語彙の別IDとして列挙しない。語の構成を、意味構造の構成に対応させるための拡張である。

## 語形成と意味

文書の先頭を `noema e e` とする。その他の発話・参照・数量・時間・複合名詞の規則は[文語0.4](spec-v04.md)を継承する。ここに示す `5` と `6` は代用記号であり、この位置で十進数の五・六を意味しない。固有文字で書いても同じ形態素の区別が残る。

| 語 | 構成 | 意味 |
|---|---|---|
| `sam` | 状態の基本語 | 開いた状態にある |
| `5-sam` | 変化＋状態 | 開いていない状態から開いた状態になる |
| `6-sam` | 使役変化＋状態 | 主体が対象を、開いていない状態から開いた状態に変える |
| `sai` | 状態の基本語 | 赤い状態にある |
| `5-sai` | 変化＋状態 | 赤くない状態から赤い状態になる |
| `6-sai` | 使役変化＋状態 | 主体が対象を、赤くない状態から赤い状態に変える |

`5-P` は、対象が状態Pを満たさない時点から、Pを満たす時点への変化を表す。Pの解釈や比較基準は変化の前後で同一とする。原因、意図、方法、変化に要した時間を追加しない。`6-P` は、主体がその変化を引き起こす出来事を表す。意図的だったかどうかは指定しない。肯定の断定では到達した変化を述べ、単なる試みや進行中の変化は表さない。

適用できるPは、空腹・疲労・喜び・赤・青・大・小・開いた状態・閉じた状態・濡れ・乾燥・高温・低温の13基本概念。対象を一つ取る性質に限る。「持つ」のように別の対象を取る関係や、「そこにいる」のように場所を必要とする状態へは適用しない。適用範囲・標識・役割は版付き資源 `language-v05.json` で定める。

字句は `operator-state_word` の形で、ハイフンの前後に空白を置かない。作用を重ねた `5-6-sam`、名詞を基底にした `5-mu`、状態の代わりに出来事を置いた `5-vat` は不正とする。0.4の名詞修飾には、引き続き状態の基本語だけを使う。`maj-5-sam` のような出来事による名詞修飾は、この版で定義しない。

## 役割と作用範囲

`5-P` では、`i` が変化する対象、`l` が変化の場所になる。`6-P` では、`i` が変化を起こす主体、`j` が変化する対象、`l` が出来事の場所、`3` が手段としての道具になる。変化する対象の型はPの主体の型から導く。例えば「空腹になる」に場所は使えないが、「赤くなる」には場所を指定できる。使役の主体と道具は対象型、場所役割は場所型に限る。

役割を省略したときは未指定のまま保つ。`6-sam j maj.` は、誰が引き起こしたかを指定せず、ドアを開いた状態にする出来事を述べる。`5-sam i maj.` は原因自体を述べないため、両者を同じ意味構造にしない。

否定、時間、質問、依頼は派生述語を含む節全体へ作用する。`u [ 5-sam i maj ].` は開く変化の否定で、現在のドアが開いているかどうかを決めない。これを `u [ sam i maj ].` へ置き換えない。「開いていない」と「閉じている」も、定義上の同義とはしていないため、自動で入れ替えない。

変化の前後の状態を、元の文の外へ二つの独立した断定として出力することはしない。そのような展開は、否定・質問・条件・依頼の作用範囲を変えてしまう。時間標識は変化の出来事へ付ける。主節の時刻を複合名詞の性質へ補完する規則も追加しない。

## 意味JSON

文書の `schema_version` と `lexicon_version` はともに `0.5`。基本述語の `predicate` は従来どおり概念ID文字列である。派生述語には次のいずれかを使う。

```json
{"operator": "become", "state": "fm"}
```

```json
{"operator": "cause_change", "state": "fm"}
```

`operator` と `state` 以外のフィールドは拒否する。`state` は上記13概念のID文字列で、入れ子の述語ではない。派生述語の型は出来事であり、その役割は作用と状態基底から計算する。自然言語モデルのクラス番号や語ごとの追加学習を、文法の定義に使わない。

## 正規化と互換性

0.1〜0.4から0.5へは、意味を変えずに変換できる。0.5に派生述語がない場合は、対象版が許す既存の内容を保って戻せる。派生述語がある場合、0.1〜0.4への変換を拒否し、状態だけを残して変化・使役を落とすことはしない。

旧来の `vat`（開ける）・`vau`（閉める）などの語は引き続き読める。この版で既存語の意味や型を変更せず、派生述語との同義判定も正規化には加えない。字句・参照・役割順の正規化と、任意の同義表現の統合は区別する。

保証する往復は `parse(format_graph(document)) == normalize_document(document)`。固有文字を経由しても同じ意味JSONを得る。自然言語側の分類器は依然この版全体に対応していない。双方向画面で未対応の派生述語を自然言語へ戻そうとした場合、意味を切り捨てず未対応として返す。
