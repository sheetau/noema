# 同じ君主の公的威厳への損傷

第六段落最終文の「Es thut selbst seiner Majestät Abbruch」に向け、先に構成した著作への介入が、同じ君主の公的な威厳を損なう関係を構成する。全文の意味判断はまだ加えない。

[AdelungのMajestät](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_1_0_180)は最高の権力・地位、外に示される威厳、人物への敬称を区別する。ここでは同じ最高統治職の公的な威厳と読む。[Abbruch](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_3_0_116)の名望・権利・威厳等の減損という語義を補助にし、身体的損害や法的廃位へ置き換えない。君主の現実の支持率や実力が下がることも必須にしない。

`r5pg` は同じ側面・基準の質的程度を非空の全前順序にし、`r5ph` は既存の `r2cl` で各場面の値が一意に確定することを確認する。`r5pi` は比較側が当該側以上で逆は成り立たない厳密な低下である。同順位・比較不能・未知を損傷へ補わず、数値単位や等間隔を要求しない。

`r5pj` は実際の活動と、関連背景を保った無介入の比較場面を結ぶ。比較範囲は結果を見ずに固定し、その全比較について同じ側面の厳密な低下と、同じ活動の因果的な寄与を要求する。過去と現在の並置だけから因果を作らない。他の要因によって以前より高い評価になっていても、無介入の場合よりは損なわれているという場合を扱える。比較ごとに結論が割れる入力では、この確定した損傷は成立しない。

`r5pk` は評価側面を同じ君主・最高職・共同体へ固定する。`r5pl` は同じ臣民の同じ作品を通じた試みへの介入について、内容審査 `r5pd` と威厳の損傷 `r5pk` を同じ最高職の束縛へ結ぶ。別々の職の審査と損傷を寄せ集めない。`r5pm` は後の条件文に使う七対象列の内容族である。

検査は尺度の空・循環・比較不能・同順位、一意な測定の欠落・曖昧さ、全比較への低下と因果寄与、主体・役職・共同体・活動・作品・時点の取り違えを扱う。因果的に妥当な比較範囲や現実の威厳評価を有限検査で発見・証明したとはしない。
