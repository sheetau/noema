# 同じ軍隊による公的平穏の保証

第十段落第一文の `zum Bürgen der öffentlichen Ruhe` を、本人が利用できる規律ある多数の軍隊が、通常の関連事態に対して公的平穏を保証するという因果比較で具体化した。同じ指揮者・制度・軍隊・共同体について、直前の人数・軍事的準備能力・規律・現在の利用条件をそのまま使う。保証人の金銭債務や補償、約束する発話は補わない。

比較には既存 `rks/rku` を使う。軍隊なし・事態なしでは平穏、軍隊なし・事態ありでは平穏でなく、軍隊ありでは事態の有無によらず平穏であることを、四条件それぞれの非空の全解に要求する。軍隊の存在と平穏が同時に観測されるだけでは足りず、一つの成功解だけでも通らない。同じモデルの三つの異なる変数を、同じ軍隊の利用内容、同じ事態の内容、同じ共同体の平穏内容へ対応させる。

平穏は既存 `r572` の、公的共同生活を乱す強制・威嚇・集団衝突がないという内容である。非空の政治的共同体を要求し、批判の不在、思想的一致、活動可能性・保有など別の目標へは置き換えない。事態の成立は平穏の喪失とは分ける。組織的な圧力があっても、抑止によって共同生活が乱れない場合を扱えるようにする。

通常の実践的な事態の候補は非空であり、全候補について背景が非空で、その全背景が比較条件を満たすことを要求する。範囲は結果から独立に固定し、軍隊を選んだ後で都合のよい事態や背景だけを残さない。関連する複数事態の相互作用も候補に含める。具体的な候補内容と因果機構、その現実的な範囲の妥当性は解釈入力の責任であり、有限試験はカントの歴史的主張の真理や全災害への絶対保証を証明しない。

ここで現在点に要求するのは同じ軍隊の利用条件であり、保護効果は固定した背景での反事実比較である。現実の戦闘や騒乱の発生は要求せず、現在の平穏を別の独立した事実として補ってもいない。抑止を含む保証役割としての読みを採用し、実際の観測記録があるという条件は加えない。

七定義 `r6fk–fq` と九入力を追加した。`r6fp` は同じ本人の判断能力、根拠のない恐れの不在、同じ軍隊の利用と平穏の保証を同じ点で合わせる。`r6fq` はこれを段階7の閉じた人物条件記述として作る。引用から本人の実在や条件の真理、発言可能性を導かない。

検査は三変数の四介入比較を実行し、非空の全解と内容対応を確認する。軍隊利用の深い本体は直前の固定済み証拠を参照し、公的平穏は実際の定義を実行する。全入力の引数を記録して接続を確認し、脅威・背景の空範囲や二つ目の失敗を検査する。二脅威・二背景を通じた統合も確認する。人物条件は同じ本人・点・基準を要求し、構築した引用と直接適用の結果を照合する。

第一文の必要条件としての限定、自由国との対比、引用命令、本人自身への強調、接続語と比喩の提示、著者帰属と全文通読は未完である。本文119主張、登録簿v203、19全単位判断を保持し、確認文字数は増やさない。
