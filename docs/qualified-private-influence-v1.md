# 対応する結果間の許容低下と私的使用の方針

私的使用の制限に付く進行への留保を、同じ啓蒙尺度上で構成する。制限あり側の一過程の広がりに許容低下を足すと、なし側の各過程の広がり以上になることを求める。別の過程の変化を合算しない。許容値0なら先行の進行順序 `r2xd` と一致する。

比較するのは同じ背景に対応する結果同士である。`r2wi` で両側の全解が対応組に含まれることを確かめ、全解に同じ啓蒙目標の評価範囲があることを `r2xf` で確認する。対応しない別の選択枝の差を、制限の害として数えない。

許容差付きの関係には推移性を要求しない。各段階の小さな低下が累積すれば、両端の低下は許容値を超え得る。そのため、先行の前順序検査 `r2wj` へ許容差付きの関係を渡さず、各対応組を直接検査する。

方針の適用と解除には同じ要求表・期間を使う。`r2yx` の解除は、対象期間の全点で全要求が不適用であることを意味する。強い制限の頻度を下回っただけ、一部の要求を取り消しただけ、ある時点だけ解除した状態では代用しない。

`r2yy` は先行の選択肢の排除率と頻度を含む方針を作り、それを介入要因に結ぶ。方針の成立と、全対応組での許容低下以内という条件を一つの内容として返す。頻度側の期間枠は同じ公衆・基準の啓蒙比較期間へ一致させる。これだけで現実の啓蒙達成や、制限への許可を意味させない。

具体的な許容値、程度と頻度の基準、原文側の人物・職務・選択範囲の供給と許可への帰属は次に束縛する。数値例は検査用であり、「特に妨げない」の閾値を原文へ追加したものではない。[定義集](../examples/v016/qualified-private-influence.noema)、[意味規約](../data/qualified-private-influence-basis-v1.json)、[検査記録](../reports/qualified-private-influence-v1.json)を保存する。
