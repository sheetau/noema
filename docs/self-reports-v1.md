# 自分の義務判断についての発言

カントu0015の「自分の義務と考えている、と言う」に、本人の判断内容を表明する構造を追加した。発言の成立、本人の判断、実際の義務、政策の実施を独立に記述する。原文の不定詞「言うこと」は品位の評価の対象なので、実際に発言したという著者の主張は追加していない。

| 定義 | 内容 |
| --- | --- |
| `rna` | 本人について指定された内容を、本人が判断しているという内容 |
| `rnb` | `rna`を主張するメッセージ。義務そのものではなく、義務だと判断していることを述べる |
| `rnc` | 同じ本人が、同じ活動・文脈で、本人についてのメッセージを非空の聞き手範囲に提示する |
| `rnd` | 発言の条件を人物と活動の性質として包み、別の判断の対象にできるようにする |
| `hzfr` / `hzfs` | 判断とその対象を既存の`fa`・`fb`へ接続する |
| `hzft` / `hzfu` | 発言とその条件を既存の`dg`・`f3`・`f2`へ接続する |

義務についての判断は、前段の閉じた義務記述と本人一人の引数を使う。同じ本人の判断が、その本人についての内容に対応し、非空の候補状況すべてで成立することを求める。実際にその義務があるとは限らず、政策が実施されているとも限らない。本人が判断を持っていないのに、持っていると発言する場合も表せる。

話者、活動、対象人物、メッセージ、文脈をそろえる。発言の対象は話者本人であり、聞き手へ交換しない。指定した聞き手が二人なら、両者への提示を要求する。これは提示の記録であって、聞き手が理解・納得したことや、世界中へ届いたことの保証ではない。聞き手範囲は明示的な引数であり、原文が特定の聞き手を指定しているという解釈ではない。

`rnc`自体は本人についての任意のメッセージを受け取る。義務判断の自己報告になるのは、同じ本人・義務記述から`rnb`または`hzfs`を組み立てて渡した接続例の性質である。型だけで任意のメッセージの内部まで保証しない。引用前に既知の閉じた義務記述を特殊化し、未確定の記述を引用内で実行しない。発言条件の引用も、実際の発言の実行評価とは別である。

[一般文書](../examples/v014/self-reports.noema)は4,146文字、[原文付き草案](../examples/v014/kant-self-reports.noema)は186,792文字、[抽出文書](../examples/v014/self-reports-core.noema)は5,364文字である。八定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-self-reports-basis-v1.json)と[検査記録](../reports/self-reports-v1.json)を保存する。

発言の発生・提示者・内容提示と、本人の判断・実際の義務・実際の政策の64通りを検査した。原文付き文書と抽出文書では、話者・活動・対象人物・文脈・メッセージの取り違え、空の聞き手、空の判断候補を含む八条件ずつを検査した。追加12テストでは虚偽の自己報告、複数の聞き手、引用の非実行、未知の義務、記述の同一性などを確認した。三文書のCLI解析の構文木一致、固有文字v2の往復、SVGのXML検査も通過した。SVGの目視確認は含めない。

部分草案の原文範囲は重複を除いて八文字増えた。この増加は「言う」という構造を記述できた範囲であり、発言が実際にあったという確認ではない。「それを言うことを品位に反しないと考える」という外側の評価、寛容という名称の拒否、称賛、政府による解放、後続の公的使用と自己発達は未完である。候補状況による判断も信念の一般理論を完成させたものではなく、段落全体の意味一致は未確認である。
