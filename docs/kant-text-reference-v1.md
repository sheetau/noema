# 文中の位置を指定して本文順序を記述する

カント正本の主張12（0始まり）が述べる「第三段落第一文から第二文への本文順序」を、文脈を指定した閉じたNoema文書として円文字へ接続した。前段の4引数テンプレートに対し、今回は提示文脈と二つの文の位置を本文内の定義で指定し、元の主張を保持している。

## 指示の方法

公開する文書参照プロファイルは、共通基盤の第12版375語に次の3語を追加して選ぶ。円文字のヘッダーはこの組合せを17として識別する。旧第16版424語の置換版ではなく、旧辞書と語義・綴りを保存した別の構成である。

| 語 | 型と役割 |
| --- | --- |
| `textpresentation` | 使用時に指定した対象文章の提示文脈を返す状況型の参照。出来事の時刻や内容の真理を表さない |
| `sentencereference` | 提示文脈・本文段落番号・文番号から、その文の談話箇所を指す。段落と文は1始まり |
| `textbefore` | 同じ提示文脈で第一箇所が第二箇所より本文上で前にある。元の `ue` の型と意味規約を保持する |

前二者は、文章内の位置で参照を指定するための一般的な基本関数である。第三の関係は既存正本から意味規約を共有したもので、文ごとの新しい関係ではない。基礎語の追加を全く不要にしたとは主張しない。

今回の本文では提示文脈を固定し、`sentencereference(context, 3, 1)` と `sentencereference(context, 3, 2)` を別々の固有名で定義する。その二つの名前と同じ文脈を、元の本文順序の式に渡す。定義の引数は残っておらず、位置と参照関係が見える本文に書かれる。

番号は対象文章における段落・文の位置である。読解時に文書専用の語義番号表を参照する必要はない。基本関数の意味は公開プロファイルにあり、局所名の定義は円文字の本文にある。ただし、位置を指定しただけでは、その文の内容をNoemaで表現したことにならない。

## 原文との対応

固定転写の本文段落を数えると、第三段落は `kant-1784:u0010` である。前付・署名・日付・著者注・編集注を本文段落の番号へ混ぜない。既存の原文読解資料から、第一文の範囲 `[0,125)` と第二文の範囲 `[126,292)` を照合した。間の1文字は空白であり、句点だけによる自動分割で境界を決めていない。

対応する旧参照は第一文 `hzzq`、第二文 `hzzr`、提示文脈 `wh`。この抜粋の基準となる `textpresentation` は、同じ第三段落の提示文脈を指すと明示する。位置から主張の真理や因果を導かず、第一文の困難さと第二文の愛着・不能の内容をこの順序式へ隠さない。

[接続資料](../data/kant-text-reference-bridge-v1.json)は、原文境界、旧意味規約、旧宣言、局所名と指示条件を記録する。円文字の復号にはこの資料を使わない。元の本文順序の関係と主張は単射な改名で保持し、旧3参照を今回の明示的な定義に接続した。既存の意味判断や正本は書き換えていない。

## 検証

[閉じた文書](../examples/v016/kant-text-reference-v1.noema)には公開3宣言、局所4定義、1主張がある。`output/kant-text-reference-v1/` のSVGから、共通基盤と文書参照プロファイルだけで復号する。旧3参照との対応条件を検査したうえで、元の5宣言と主張を正確に戻せることも確認する。変更された定義から旧証拠へ戻す操作は拒否する。

二つの個体値と二つの提示文脈を使い、旧式と復号後の式の結果、逆順の偽、異なる名前への引用の区別、別文脈での順序変更を確認する。未知の文脈・未指定の文位置・個体、非整数や不正な番号は、既定の値や偽を返さず拒否する。完全な数学的モデルの全域関数と、既知の参照だけを実行する有限の解釈器は区別する。

```powershell
python -X utf8 -m scripts.project_work check --module scripts.check_kant_text_reference --prepare --tests tests/test_text_reference_profile.py --verify reports/kant-text-reference-v1.json
python -X utf8 -m scripts.visible_text_reference_collection decode output/kant-text-reference-v1/page-00001.svg
```

[検査報告](../reports/kant-text-reference-v1.json)が示すのは、指示条件を明示した本文順序の1主張の接続である。二つの文の意味内容の移行、著者や名称など別種の参照、二論文全文の可視化、第三者の読解は未完である。自然言語の全単語網羅を辞書の完成条件にはしない。
