# 一般形状の寸法・平面極限・適用範囲の円文字表現

原刊903頁のu0116は、任意の有限形状の寸法、光速未満からの極限、超光速での適用限界と後続の予告を述べる三文からなる。続くu0117は、観測系を交換しても同じ形状の結果が成り立つと述べる。同じ変換と形状の定義を使うため、二段落を一つの依存群として円文字本文へ接続する。四つの原文主張と、極限の読みを明示する一つの解釈注記は別々に保持する。

球に限らない形状は、その全占有位置で表す。穴、非凸性、離れた成分を埋めず、全物質点の包含と全占有位置の被覆を共に要求する。寸法は三軸への射影の有限幅であり、上限・下限の達成は要求しない。空集合や無界集合に有限幅を与えず、静止側と各観測時刻における幅の存在を明示する。

横二方向の幅は保たれ、縦方向の静止時対運動時の比は1対√(1−(v/V)²)となる。正の幅は縮み、幅0は0のままである。速度の比較では、同じ光速と正の静止幅を固定する。異なる大きさの物体の比較や、同じ物体の加速履歴を加えない。Währendは対照として、alsoは球から一般形状への拡張と速度比較の帰結として保持する。

光速の極限では、固定した形状とKの時刻について、全元位置が共通の精度と近傍でVtの平面へ近づく。近傍は形状・時刻・精度に依存してよい。極限像は元形状の横射影を保ち、穴や離れた成分も残るため、平面全体を埋めるとは限らない。光速未満では順像と逆代入の一致を保つ。v=Vで有限のβや正則な逆変換を評価する解釈は採らず、この読みを著者の文と分離した注記に記録する。

超光速については、有限βの不成立と、同じ考察・方程式族の物理的適用の不成立を別の条件として保持する。予告は、同じ理論が許す状況、同じ物体と全物質点、系と単位に対する物理的上限を扱う。光の伝播をこの物体速度の領域へ含めない。無限大の速度との比較は、あらゆる有限上限を超える近傍で記述し、無限大を実数値や実際の物体速度として導入しない。予告や補足の引用を取得しても、その内容が現に成立するという証明を実行したことにはならない。

観測系を交換する結論では、kに静止する物体をKから見る場合の+vと、Kに静止する物体をkから見る場合の−vを区別する。対象の同一性は各適用の内部で保持し、一つの物体を両系へ同時に静止させない。縮小係数と正の半軸は同じだが、中心の移動と極限平面は符号に応じて逆になる。先行する予告を証明済みの結果に変えず、後続の時計の議論も先取りしない。
