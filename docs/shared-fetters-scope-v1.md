# 前の文から受ける人物範囲を、第三文でも保つ

第三文の比較事例と足枷の比喩について、利用者を前二文と同じ人物範囲へ結び付けた。前版では使用・能力・原因・結果の本人は文内で一致していたが、その本人が第一文から続く説明の対象かどうかは検査していなかった。本文の第53文（索引52）を更新し、他の53文と既存の定義・意味規約は保持する。

原文の第一文は各人について述べ、第二文は `Er`、第三文は `seiner Naturgaben` と続く。ここでは、その同じ人物範囲について説明が続く読みを採る。新しい一般文法や人称解決のハードコードを導入するのではなく、既存の人物範囲と事例の役割写像を、量化と所属条件で結ぶ。採用した読みは候補の一部であり、ドイツ語から自動的に証明されたものではない。

## 事例を削らず、役割の参照先を検査する

一般定義 `r2fx` は三つの入力を受ける。

- 検査する非空の事例範囲。
- 各事例から役割を担う対象を選ぶ写像。
- その対象が属するべき参照範囲。

全ての指定事例で、役割の対象が同じ参照範囲に属することを要求する。範囲外の対象を持つ事例を先に除外すると、不正な参照を隠せてしまうため、その処理はしない。複数の事例が同じ対象を選んでもよく、参照範囲内の全員が事例に現れる必要もない。

`r2fy` は、第三文の全比較事例 `hzzzb` と利用者 `hzzzd` を渡す。参照範囲には第一文の箇所 `hzzq` に結び付く `hzzn` を使い、各利用者が人であることも要求する。通常性の順位が低い事例もこの検査に含む。一般化の例外を別の人物集団へ移すことは許さない。

参照範囲の基準は第三文の提示文脈である。各事例で使用を評価する時点 `hzzze` や、継続履歴の各点へ置き換えない。仮定の時点が変わるたびに「その人」の範囲を選び直さないためである。

## 主張内容と比喩の両方に接続する

`r2fz` は、この人物参照の整合性と、既存 `r2fu` の二種類への一般化を同じ提示文脈で要求する。条件付きの継続作用や通常性の構成は変更しない。

比喩の対象側 `r2g3` も、対象と本人という二位置を保ち、その本人が同じ先行人物範囲に属することを要求する。作用を評価する基準点は別の引数として保持する。身体的な足枷の記述を、規定や定型表現そのものと同一視する変更ではない。

帰属 `r2g2` は新しい主張内容と比喩対象を参照する。同格、合理的使用から誤用への言い直し、前後文との順序はそのまま使う。著者への帰属を検査する際に、引用された世界内容を実行することはない。

追加は五定義で、新しい基本関係はゼロ。固有の単語を新しい翻訳規則へ登録する変更でもない。

## 検証と残る課題

一般形の64組合せで、事例の採否・役割の参照先・参照範囲を変える。原文接続の64組合せでは、人であることと先行人物範囲への所属を分ける。参照元の箇所、提示文脈と使用時点の取り違え、空の範囲、範囲外の人物を検査する。未指定の入力は偽や既知の人物として補わない。

結合検査では、旧候補は成立するが人物が先行範囲外という反例を用意する。新しい主張内容と比喩対象がそれを拒否することを確認する。使用・一般化を境界で分離した検査に加え、既存の能力・因果・継続・二種類への一般化を実行する検査も行う。後者でも分類の全記述領域は有限例で代用せず、分類境界を明示する。

帰属の32組合せでは、旧内容や旧比喩対象への取り違えと、引用内容を実行しないことを確認する。短縮・展開・固有文字の往復、既存の十二全単位2,212文字と別記した先頭二文247文字の判断も保存確認する。
