# 共同計画と、脅威に対する保護の仕組み

カント第17区間には、軍隊を公的平穏の保証として手元に持つという条件がある。前段の共同計画は、全員の指定目標と共通目的の同時成立を扱う。今回は、その集団活動が脅威から目的を保つというモデル内の比較を接続した。新しい文法やPython演算子は追加せず、既存の集団・介入・観測の定義を合成した。

## 集団活動と保護要因を同じ内容へ結ぶ

`ruv` は、基準文脈の全構成員を過不足なく列挙した上で、同じ計画者・集団・計画の全員の目標が成立するという内容を作る。計画の利用可能性や評価結果の選択は含めない。これにより、集団活動のない比較状況も記述できる。

`ruw` は次の三条件を組み合わせる。

- 同じ利用可能な計画の、非空で整合した全評価結果で、全構成員の目標と共通活動が成立する。
- 同じ方程式で集団活動と脅威を別々に切り替えると、活動なし・脅威なしでは共通活動が成立し、活動なし・脅威ありでは失われ、集団活動ありではどちらでも保たれる。四条件それぞれに解があり、その全解が条件を満たす。
- 介入解を比較状況へ対応させたとき、集団活動の要因は `ruv`、目的は共同計画と同じ共通活動、脅威は同じ脅威内容と一致する。

保護効果と内容対応には既存 `rks`・`rku` を用いる。集団活動と無関係な真偽値を保護要因へ渡すことはできない。構成員の一人だけが比較状況で活動していない場合や、比較上の目的だけを別の内容へ置き換えた場合は、この対応条件が失われる。

`rux` は、固定した集団・文脈・機構のもとで `ruw` を満たす計画があるという条件である。指定した一計画が不適合でも別の計画が成立する場合を、検査で区別した。

## 評価結果の記録も同じ機構へ照合する

`ruy` は `ruw` に、各評価結果の記録と機構の整合性を加える。既存 `rk2` を使い、記録が介入による上書き前の方程式を満たすこと、モデル外の変数を勝手に真にしていないこと、同じ集団活動・共通活動・脅威の内容と真偽が一致することを求める。評価結果が複数あれば全てに要求する。`ruz` は、この条件を満たす計画の存在を表す。

| 作例の状態 | 共同計画 | 保護比較付き `ruw` | 記録適合付き `ruy` |
| --- | --- | --- | --- |
| 集団活動と目的は成立するが、活動がなくても脅威下の目的は保たれる | 真 | 偽 | 偽 |
| 保護の比較は成立するが、評価結果の記録は介入前の方程式と矛盾する | 真 | 真 | 偽 |
| 複数の評価結果のうち一つだけ記録が不整合 | 真 | 真 | 偽 |
| 脅威がない評価結果で目的を保ち、機構・記録も適合する | 真 | 真 | 真 |

これは指定した脅威による喪失を防ぐ強い保護の読みである。常に目的が成立する場合を「その集団によって保護された」とは判定しない一方、補償・救済・確率的な危険低減などの用法は含めていない。原文の「保証」の唯一の必要十分条件とは扱わない。

## 検証と範囲

[定義文書](../examples/v016/collective-protection.noema)は30宣言・本文0文で、新規定義は五つ。[作例](../examples/v016/collective-protection-example.noema)は50宣言・7質問である。47テストが通過した。二要因に対する16通りの決定的な機構を独立した解の列挙と比較し、複数解・解なし、人数と計画の不整合、比較状況での内容の取り違え、記録の不整合、予防、別計画による成立を検査した。未知の機構・活動・記録を含む記述は構築できるが、その評価は拒否する。

通常表記・短縮表記・固有文字の往復、保存文書と検査記録の再現、CLI解析、固有文字SVGのXML検査を確認した。記録適合付きの基準例は評価キャッシュの有無でも一致した。SVGの目視検査は行っていない。

```powershell
python -X utf8 -m scripts.compose_collective_protection
python -X utf8 -m pytest tests/test_collective_protection.py -q
python -X utf8 -m scripts.check_collective_protection --verify-only
```

評価対象の結果が将来や仮想の状況なら、整合する記録があっても現在の保護事実にはならない。機構・比較状況・記録の現実への適合は別途必要である。軍隊の制度・訓練・指揮権、公的平穏そのものの内容、本文の上位主張への接続は残る。今回は新たな原文対応範囲を加えず、全文の意味確認済み区間数も変更しない。
