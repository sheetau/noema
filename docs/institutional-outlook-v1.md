# 制度導入の目的と、よりよい法への期待の描写

カント第六段落u0013第七文 `[1437,2309)` のうち、導入の目的と期待を構成する。全文確認は未完で、確認済み文字数は加算しない。

`um eine gewisse Ordnung einzuführen` は、同じ法の採択によって一定の宗教上の制度配置を導入する目的と読む。`r5fl` はその目標内容を、活動・共同体・制度の三対象と、基準・候補・起点の三つの状況引数で表す。同じ行為の生起・導入効果・制度の実施状態を含むが、その内容を目的として引用するだけでは実際の達成を要求しない。`r5fm` が同じ主体・行為にその目標採用を結ぶ。

`r5fo` では先行する短期制度の構成 `r5fh` と、その同じ導入活動の目的を結ぶ。制度がたまたま導入された場合と、導入を目的としていた場合を分ける。`r5fp` は、渡された到達内容が同じ期限で初めて成立する条件も保持する。実際の法の全条項、制度の存続、全市民への批評の自由は先行構成から引き継ぐ。

`eines bessern` は、直前の `ein solches Gesetz` を受ける「よりよい法」と読む。中性の形と直前の名詞に基づく明示読解であり、女性名詞Ordnungが指す制度配置と法を同一個体に潰さない。この照応判断は[原文](https://litgloss.buffalo.edu/kant/text.php)を根拠とする解釈であり、語形だけから全ての解釈可能性を排除したとはしない。

`r5fj` は同じ共同体の公的な法を比較し、双方の自己比較、改善側が元の法以上で逆は成立しないことを要求する。改善側には `r5ej` を適用し、同じ完全な人民について非空の全条項の規律が同じ点に成立することを構成する。同程度・悪化・比較不能を厳密な改善としない。原文が示さない数値尺度、特定の教派、元の法の全面的な廃止は追加しない。

`r5fk` はこの改善内容を、同じ候補の起点より後の履歴点へ制限する。`r5fn` はその到来を見込み待ち受ける字義的な期待の描写である。**gleichsam（いわば）が付くため、この字義内容は制度導入の条件へ直接連言しない。** 全文では、同じ政策をこの期待の描写になぞらえる対応を著者の提示として別に結ぶ。全市民の実際の内心や改善法の将来の成立を、この挿入句から断言しない。

目的と期待の基本関係は、閉じた内容族・個体列・三つの状況引数を保持する。目的志向の意味上の区別は既存のhztlを引き継ぐが、その引数を黙って増やさず、新しい型付き関係とする。目的の対象は段階0、全条項を評価する期待の対象は段階1で引用する。心理機構の一般理論を構成したものではない。旧riの「全ての選んだ予想候補で成立する」という確信的なモデルも、この見立てへ追加しない。

検査では比較の16組、改善法の三種類の全条項の8組、目標の未来性と開始時点、個体列の順序・長さ、同じ主体・行為・基準・候補・起点への結合を実評価する。態度だけの検査では対象内容の実施・改善・時間入力を未知のままにして、引用が実行されないことを確認する。期間との接続検査は `r5fh/r5fi` を境界とし、先行するtemporary-institution報告の実評価を保持する。
