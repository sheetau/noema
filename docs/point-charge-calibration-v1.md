# 点状電気量の校正

u0173は六文からなる段落である。第一文は直前の六式の解釈の導入、第二文は点状電気量1と距離1 cm・力1 Dynによる校正の仮定、第三文は相対性原理による移動系での値1、第四・第五文は静止条件付きの力と電場の同定、第六文は二つの言い表しへの導入である。段落全体を接続する前に、旧草案の第二文に残っていた物理的な校正の説明を補う。

実装前に、不足していた点状の理想化、単位規約、同じ量を持つ別対象、同じ校正時刻の距離、第一対象から第二対象へ働く力、力の大きさと三成分、d. h.の仮定内の説明を要件として整理した。既存の単位付き結果sbw2、電気量1のsbz2、静止x4、電気的力の帰属eirl、力ベクトルの記録zpc、仮定ugと説明ufを再利用する。旧zokやzoiの未説明の判定だけで点状性・量の同一性を済ませない。

点状電気量は、電気的作用の強さと極性を担う量を一つの位置へ集中させ、内部の広がりや多極構造を分解しない古典的な理想化として採る。第一対象はこの理想化に属し、同じ系・出来事・電気量単位で値1を指定する。第二対象にも同じ単位・尺度で値1を与えるので、異なる物体が同じ電気量を持つ。第二対象の静止や内部構造は追加しない。

cmは長さの1/100 m、Dynは質量×長さ/時間²の1/100000 kg m/s²として同じ基準へ結ぶ。後者は1 g cm/s²である。m/kg/sは単位を比較するための基準であり、1905年の論文へ現代の定義定数を持ち込むものではない。電気量の単位zouは同じ静電的な作用による校正に属する。数値1だけを別の単位から借用しない。

同じ試行・系・出来事で両対象の四座標をcm/秒の単位で与える。時刻の一致と三空間成分の距離1 cmを要求する。力については、第一対象から第二対象への電気的な機械力の寄与を、同じ出来事・系・Dyn単位の三成分へ結ぶ。三成分の平方和が1となることで大きさ1 Dynを表し、原文にない方向を固定しない。ここで相手に及ぼす力は、後続で第一対象自身に働く力とは別である。

位置と力の物理的な帰属は一般的な入力関係であり、その数値・単位・対象・向き・時刻の一致をNoemaの定義で合成する。任意の数値関数から物理的な記録であることを推測しない。仮定された記録を使い、測定・試行の実行済みや一般のクーロン則の証明は要求しない。

電気量1の仮定と作用による校正の説明を同じ著者の第二文へ接続し、旧文163だけを置き換える。旧版・旧証拠・他357主張は保持する。段落の残る五文、現在の相対性原理・物理的な場・静止と瞬間静止への接続は未完であり、u0173全体の意味確認数は増やさない。
