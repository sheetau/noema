# 外積による一次の式と、共動する系での力

アインシュタイン1905のu0174・u0175へ、力を述べる二通りの説明を部分記述した。旧来の説明は二次以上の項を無視する留保を持つ。新しい説明では、電荷とともに動く系へ場を変換して、その系での力を評価する。

## 外積と近似の範囲

[一般用文書](../examples/v014/force-wordings.noema)に、三成分の外積、光速度による除算、電気側ベクトルとの加算を追加した。外積は右手系の順序付き三軸を使い、速度と磁気側ベクトルの順序を保存する。零速度や平行な二ベクトルでは外積は零になる。光速度は正とし、同じ軸を二つの成分へ割り当てない。

一次の候補式は `E + (u × H) / V` である。これと、先行する正規化変換の電気側三成分を分けて構成した。x方向の速度比をrとすると、変換後の値は `Ex, β(Ey − rHz), β(Ez + rHy)` となり、一次の式では横成分のβを1として扱う。非零速度では、一般に両者は一致しない。

既存の漸近的な誤差条件を使い、固定したE・Hについてrを零へ近づけたとき、各成分の差がr²のオーダーになることを記述した。定数と近傍幅はrごとに選び直さず、固定した場の値には依存できる。任意の場・運動方向に一様な誤差定数があるとは指定していない。

補助検査では、β²(1−r²)=1、β≥1、r²≤1/4から、0≤β−1≤2r²を有理数の一般式で確認した。|E|≤A・|H|≤Bの固定した成分値なら、横成分の誤差は2(A+B)r²以下となる。漸近条件で正の定数が必要な場合は、この上限の係数より大きい正の値を選べる。ただし、これらの補助式の検査を、Noemaの全実切断にわたる漸近定理の機械的証明とは扱わない。有限標本による漸近条件の確定も拒否する。

## 同じ対象・出来事での力への接続

[論文文書](../examples/v014/einstein-force-wordings.noema)では、点状の単位電気量という前提を同じ対象・出来事・基準系・単位へ結んだ。運動には、前回訂正で意味を確認した既存の運動の記号 `xm` を使う。

旧来の説明は、標準配置のx方向の運動と、固定地点での場の値へ限定して部分記述した。外積自体は三方向の成分を持つが、今回の近似の接続から任意方向の運動まで検証済みとはしない。

新しい説明は、電荷が当該瞬間に移動系へ静止する条件を保ち、同じ出来事の旧座標から新座標への変換を要求する。その新座標で変換後の電気側の場を評価し、先行する移動系の力の記録と三成分を一致させる。旧系で評価した場をそのまま使う場合や、同じ数値の座標を両系へ流用する場合を区別する。
