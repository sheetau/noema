# 未対応例の周囲も注釈する対照実験

v9は、v8と同じ入力文を使い、5,456件の未対応学習例に周囲の既知語と非対象部分の注釈を追加した。新規確認評価では英語の確定率が51.00%にとどまり、不合格となった。完全一致率だけは条件を満たすが、必要な確定率80%との両立はできていない。この候補を採用版にはしない。

## 対照条件

[corpus-v9の記録](../reports/corpus-v9-manifest.json) にあるとおり、50,966文の本文・ID・順序はv8と同一で、開発用と旧回帰用の注釈も変更していない。同じ入力であることを検査してXLM-Rの固定特徴量を再利用した。変更したのは、名前を参照未解決の語へ置換した学習例の局所的なラベルである。

これらの例は未対応のままとし、文全体の正しい意味構造を作っていない。範囲以外の全体分類や数量の参照先も、未対応例では正解を補わず学習対象から外した。推論時の修正規則、エンコーダーの重み、共同役割割当ては変えていない。

374,451パラメーターの分類器を30エポック、CPUで約23.1分学習した。開発用の固定基準で30エポックが選ばれ、日本語の閾値0.0、英語0.79で重みを固定した。[選択記録](../reports/routed-v9-selection.json) と [学習・回帰の詳細](../reports/joint-v9.json) を保持した。

## 新規確認v4

[事前条件](confirmation-v4-protocol.md)、[予測前点検](confirmation-v4-review.md)、[固定記録](../reports/confirmation-v4-manifest.json) に基づき、日英各600対応文と96未対応文を確認した。

| 言語 | 確定／対応文 | 確定率 | 正解／確定 | 完全一致率 | 未対応の誤確定 |
|---|---:|---:|---:|---:|---:|
| 日本語 | 550 / 600 | 91.67% | 548 / 550 | 99.64% | 2 / 96 |
| 英語 | 306 / 600 | 51.00% | 306 / 306 | 100% | 2 / 96 |

[全集計](../reports/confirmation-v4-result.json) では、英語の確定率に加え、日本語の代名詞区分と英語の名前／抽象概念区分がそれぞれ誤確定2/12で不合格となった。「明日、彼女は眠る。」「明日、彼女は家で空腹だ。」と、Valorを含む眠る文2件を誤確定した。

日本語の対応文の誤り2件は主体・対象の交換だった。英語の棄却294件は、役割と対象範囲の不整合135、未知概念78、対応範囲分類57、低確信度24に分かれた。文頭の `In` の先頭だけを対象として抽出する失敗が残る。場所句が文頭の能動文は46/208、受動文は10/92しか確定せず、主語後の場所句では117/119を正しく確定した。

全4文を確定した同義グループ48/300組では構造が一致した。日英6文ずつの反復と単独／一括実行、全確定出力のNoema往復も通過した。

## 同じ資料での比較と残る問題

v8と同じ確認v3を回帰として再測定すると、日本語の確定率は89.00%から94.33%、完全一致率は100%から99.65%となった。英語の確定率は49.83%から48.17%へ下がり、完全一致率は100%のままだった。したがって、確認v4の51.00%をv8からの改善と解釈しない。

周囲の範囲注釈だけでは、未対応語の保留と対応文の抽出を両立できなかった。次の検討では、範囲抽出と既知概念／名前／未対応の判定を分ける分類器の比較、文頭場所句と新しい名前への汎化を測る開発資料の見直しが必要になる。基盤モデルの追加学習や基準の引下げは今回行っていない。確認v4も今後の改善へ使う場合は回帰資料とし、新規確認として再利用しない。

## 再現と保存

`noema.context_corpus` は既存v8本文とv7の置換元から注釈を作り、入力の同一性を確認して特徴量を再利用する。`noema.train_structured` は既存の出力ディレクトリを拒否し、過去の重みを上書きしない。再実行ではデータ・特徴量・モデル・報告それぞれに新しい出力先を指定する。

```powershell
python -m noema.context_corpus --output artifacts/replay-v9.jsonl --manifest artifacts/replay-v9-manifest.json --features artifacts/replay-v9-xlmr.pt
python -m noema.train_structured --dataset artifacts/replay-v9.jsonl --features artifacts/replay-v9-xlmr.pt --epochs 30 --decoder joint-v1 --regression-test --output artifacts/replay-v9-xlmr
```

同じCPU環境での再現手順であり、異なるGPU・ランタイムでの完全一致を保証するものではない。人による文語と固有文字の読み書きは、分類器の成績と別に確認する。
