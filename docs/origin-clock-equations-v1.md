# 同じ原点時計の場所に関する二式

u0119–u0122は、原刊904頁の導入、時間変換式、接続詞und、原点の軌道式からなる一文である。xとtはKの記録、τは同じ出来事のkの記録に属する。前の設定でτを正確に指示する同じ時計をkの原点に置いているため、時計の表示とその記録を一緒に参照できる。

対象範囲には、原点配置と全時刻の比較に使う局所記録対をそのまま使う。その全てを既出の座標変換の範囲と同じ出来事の対応へ結び、kの空間三成分が零であることも保持する。式を満たす記録だけを選ぶと、誤った別の記録や対応の欠落を見落とすため、選択条件から数値式を分離した。

時間式τ=β(t−vx/V²)と軌道式x=vtは、既存の数値定義を再利用する。係数βは正の1/√(1−(v/V)²)であり、同じV/√(V²−v²)に一致する。元の時刻の符号を保ち、tを常に正の経過時間とはしない。一般の空間点や時計の内部部品までx=vtに制限するものでもない。

「明らかに成り立つ」は、既出の時計設定と最終変換を文脈上の前提として、著者が同じ二式の成立を提示する表現と読む。コロンとundによる二式の連言を一つの適用範囲に保つ。著者への帰属と明白さの提示は、処理系が物理的真理を証明したという認定とは別である。

検査では二式を独立に壊した例、負・零・正の座標時刻、係数の逆数、両系の記録順、原点の三成分、全候補への適用、欠けた対応を確認する。全時間の配置・表示・比較は前段で検査した定義と証拠を引き継ぐ。続く平方根への代入、単位時間の遅れ、近似は後続の原文単位に残す。
