# τの具体形、未定係数、原点仮定の本文接続

原刊899頁のu0062–u0064は、先行する方程式とτの線形性からτ=a(t−v*x′/(V²−v²))を提示し、aを暫定的に未知のφ(v)と説明した後、簡潔さのためk原点でτ=0ならt=0と仮定する。三つの内容を、式への帰結、現在段階の未決定性、理由を伴う仮定として本文順に接続する。

ei4oは現在の測定対応から取った同じアフィン五係数ei4nと、その同じτの四偏微分smrを結ぶ。ei4pは同じτの全空間の縦条件sknと横条件slm、同じ係数の存在、原点条件ei4lを含む推論前提である。係数の存在を入力ごとに取り直さず、時間係数を同じφの同じvでの値へ結ぶ。結論smnは同じ関数と速度を使い、全有効四入力で式を要求する。

linearは先行箇所と同じくアフィン性として読む。元の時間行を(A,B,C,D;E)とすれば補助座標での時間係数はD+vAである。全測定入力から全実数入力への同じ式の延長を明示した前回の読みを引き継ぐ。原点での値を別に零とするためEは消えるが、微分条件だけから消えるとはしない。一般の実数体と微分の定理を有限検査で証明することは、この記述の意味には含めない。

未知のφは、現在の考察段階で排除されていない候補速度関数が複数残るというsmpの読みを採る。現在の関数は同じ速度域で候補族へ接続し、ある速度で値が一致しても全関数が同一とはしない。これは唯一の解を主体が知らない場合も含む知識一般の定義ではない。係数を1や後段の確定値へ補わず、候補の全てが後続の条件を満たすとも述べない。

原点内容ei4qは現在の同じ出来事と二座標組へ結び、全対象でτ=0ならt=0を保つ非空の時刻規約として読む。既出の原点表示に合わせる空間ラベルの選択は別条件であり、時刻条件そのものが全空間成分零を述べたことにはしない。ei4xはこの内容をugで仮定とし、同じ仮定にzexで簡潔さの理由を付ける。

ei4t、ei4w、ei4zの三主張は同じ著者・論説・第三節を保持し、先行する横方向の式から、具体的時間式、未知係数、原点仮定へ続く。引用内容を実行して物理的な証明へ変えることはない。既存定義と判断は保存し、新規原始語は追加しない。u0065以降の空間座標の導出はこの範囲に含めない。
