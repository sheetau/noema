# 運動の時間関数表示と時間の理解

固定原文 `einstein-1905:u0010` の前二文を扱う。第一文は `[0,126)`、108非空白文字、第二文は `[127,337)`、178非空白文字で、原刊892頁末尾と転記を照合した。原刊の行末分割 `be-schreiben` を接続する。後二文は次頁に続くため、前二文の検査で段落全体を完成と数えない。

第一文の「運動を記述しようとするなら、座標の値を時間の関数として与える」は、著者が採る一般的な記述方法として読む。既に特定の物質点が動いた事実や、読者が実行した行為を報告する文ではない。前段落と同じ座標系 `ra` に対する同じ物質点の三座標を扱い、位置の時間的な経過を表す。定数関数、往復、非等速の経過も許し、微分可能性や動力学法則を追加しない。

`eiii` は物質点、`eiij` は有効な非退化実時間区間の全入力で有効な三実座標を与える関数の型である。`eiik` はこの三関数を、同じ物質点・系・長さ単位・時間単位・全対象期間を持つ記述へ割り当てる。既存の `se` を、その記述が物理的な履歴に正しく対応するための基準として引用する。`se` は全時刻の出来事存在と、逆向きに全ての対象観測が曲線に一致することを要求するので、測定標本だけで正しい全軌跡とはしない。ただし、基準を記述へ結び付けることから、その物理的真理を実行しない。

`eiil` は同じ記述が論説の範囲に属し、著者がその三関数を記述手段として与えることを結ぶ。`eiim` は物質点を記述しようとする意図に対する条件、`eiin` はその主張、本文224の `eiio` は著者・論説への帰属と位置指定段落からの順序である。単なる関数の存在では提示行為を済ませず、特定の表示形式や有限の全桁計算能力は要求しない。

第二文の `derartige mathematische Beschreibung` は同じ数学的記述の型を指す。`eiip` はその全範囲を取り、物理的意味や理解の成立した記述だけを選ばない。物理的意味とは、変数を物質点・位置・出来事・尺度へ指示する解釈が定まることであり、軌道の予測が正しいこととは区別する。数学的に整った式でも時間の指示が不明なら、この意味での物理的解釈をまだ与えられない。

`eiiq` は同じ記述における時間の意味規約と、その規約について使用者が明確な理解へ到達した先行状況を結ぶ。既存の `zm4` により、同時や後からの理解を `vorher` に替えない。時間の規約は、どの出来事へどの時間値を割り当て、何を同時と扱うかを定める。後続本文の具体的な時計・同時性の説明はまだここで完成したとはしない。

`eiir` は、同じ種類の数学的記述がその使用者にとって物理的意味を持つなら、同じ時間の意味を先に明確に理解している、という必要条件を述べる。原文の `erst dann … wenn` をこの向きで読み、理解だけで全てが十分になるという逆向きの条件は追加しない。`man` はその記述を用いる任意の使用者であり、全読者の現在の理解を断言しない。`eiis` はこの主張、本文225の `eiit` は帰属・順序と既存 `zei` による注意喚起を保持する。読者が実際に注意したことや証明済みは要求しない。
