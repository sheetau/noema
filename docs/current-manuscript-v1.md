# 現在の本文全体と未充足引数の検査

現在のカント本文の条件文を、集団変化・政策置換・自己利益判断・公的理性使用の許可と同じ有限モデルで評価する検査を追加した。覆いの参照、性質記述を指す同格、未試験の覆いの耐性への接続を含む最新版の定義を、そのまま読み込む。本文の定義をテスト用の真偽関係へ置き換えない。

正常例では、前件が成立する実例を持ち、条件文全体が成立する。政府が利益を認めても現実の利益条件は偽であるという区別も維持する。参照する制度条件、同格の指示対象、説明関係、描写の版、公的許可、残余条件をそれぞれ崩した対照例では、条件文全体が成立しない。不明な名詞句の指示は例外として返す。

覆いの負荷応答は、本文中で提示される描写の内容である。条件文全体の検査でも、描写への帰属を、実際に荷重試験をしたという主張へ変えない。応答関係が呼ばれると失敗する診断入力を使い、帰属だけでその関係が実行されないことを検査する。負荷した場合の耐性そのものは、前段の別の検査が対象とする。

この検査は、未充足の引数がなくなった証拠にはならない。記録には、現在のひな形が受け取る8引数と、診断で与えた式を並べる。特に残余条件は外部の関係を渡しており、その内容をNoemaで説明したことにはならない。政府・政策・比較範囲を与えた診断例と、原文に帰属する内容の確定を区別する。

次に本文を閉じるには、政府の資格と共同体への接続、政策の内容、尊厳の追加条件、残余条件の具体化が必要である。いずれも適当な定数や常に真の関係で埋めて完成とは扱わない。全文との意味一致、原文の対応範囲、意味確認済み区間の集計値は変更しない。

```powershell
python -m pytest -q tests/test_current_manuscript.py
python -m scripts.check_current_manuscript --report
```

検証記録は [current-manuscript-v1.json](../reports/current-manuscript-v1.json) に保存する。`--report` は既存記録を上書きしない。
