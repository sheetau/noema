# 評価対象を明示した本文での署名の再確認

[前回の署名の読み](author-signature-review-v2.md)を、kant-targeted-adequacy.noemaとその意味規約・識別表記へ結び直した。今回の本文修正は冒頭の不足評価と因果条件を対象とし、署名の文と依存する意味は変えていない。

署名の10宣言について、型・本体・意味規約・基本関係の引数ラベルを前版と比較した。相違は所属文書と意味規約のファイル名だけである。17番目の文、名称hzifの四表記も同じである。新しい決意・勇気・理解力の評価関係は署名の依存先に入らない。

原文u0018全体と八項目の理由を再読した。末尾の名称使用が同じ人物waを同じ文書hzikの著者として表示するという判断、印刷された略記と編集上の展開の区別、頭文字を固定転記の規約に従って読むことを維持する。著者自身が掲出したことや自筆の真正性は加えない。署名内の未処理意味項目はないという判断も維持する。

[新版の判断記録](../data/author-signature-review-v3.json)は新しい本文・意味規約・識別表記のハッシュと、旧版の判断、今回の比較検査を固定する。単位別判断は引き続きアシスタントの読解であり、独立した専門家による査読や自動証明ではない。同じ署名の版更新なので、意味確認済み区間数を増やさない。

現在の登録簿はdata/semantic-review-index-v2.json。冒頭段落の修正を完了区間とする登録は含めない。

```powershell
python -X utf8 -m scripts.audit_written_progress_reviewed --index data/semantic-review-index-v2.json --verify-only
```
