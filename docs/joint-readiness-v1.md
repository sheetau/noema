# 集団の人数と、同じ計画・同じ結果での準備

カント第17区間の集団的な統制と平穏の保証を記述する準備として、構成員の人数、共同計画の利用可能性、要求への適合、共通目的の成立を分ける六定義を追加した。軍隊や公的平穏という名詞の意味を一つの未説明な真偽入力へ置き換えたものではなく、その説明に必要な構造を作る段階である。

## 構成員を過不足なく数える

`rup` は既存 `rcm` を使い、指定範囲の構成員を全て含む非空・重複なしの列であることを確認する。その列の長さが、与えた人数の評価基準を満たすことを要求する。人数を増やすために同じ人を二度書いたり、一部だけを選んだ列を全集団の人数と扱ったりしない。

評価基準は人数を受け取る関数として明示する。例えば二人の集団は「一人より多い」を満たすが、「二人より多い」は満たさない。これは計算の作例であり、「多数」という語の閾値を二人などの固定値に決めるものではない。既存の有理数の加算・比較・真理値の指示関数を再利用している。

## 個別の計画を共同計画として継ぎ合わせない

`ruq` は同じ計画者・集団・基準文脈の一つの利用可能な計画を評価する。評価対象の結果は非空で、想定結果に含まれる必要がある。その全結果で、同じ構成員全員の目標が成立することを要求する。

作例の構成員の目標には、既存 `rty` による要求記録の網羅性と履行を用いる。要求の出所は同じ計画者に固定し、本人・計画・基準文脈の役割範囲と要求記録を渡す。別人や別出所の要求で履行を補うことはできない。

検査には、第一の計画では一人目だけが成功し、第二の計画では二人目だけが成功する例を置いた。各人について成功する計画はあるが、全員が成功する同じ計画はない。Noemaで書いた「各人について計画が存在する」という診断式と、「一つの計画で全員が成功する」という条件は、異なる結果を返す。

## 共通目的と全計画での適合を分ける

`rur` は `ruq` と同じ計画の同じ評価対象で、共通目的も成立することを求める。構成員が要求を満たす結果と、共通目的を満たす別の結果を継ぎ合わせない。`rus` は、この条件を満たす計画が一つ以上利用できることを表す。

`rut` は別の条件である。利用可能な計画が少なくとも一つあり、その全てで構成員が要求へ適合することを求める。一つの計画が成功しても、他の利用可能計画で不適合や評価範囲の欠落があれば成立しない。共通目的まで全ての計画に要求する条件ではない。

`ruu` は、同じ集団の人数基準、全利用可能計画での構成員の適合、共通目的を保証する一計画の存在を合わせる。

| 状態 | 共通目的を満たす計画がある `rus` | 全計画で構成員が適合する `rut` |
| --- | --- | --- |
| 各人に別々の成功計画だけがある | 偽 | 偽 |
| 全員が成功する一計画はあるが、別の計画で一人が不適合 | 真 | 偽 |
| 全計画で全員が適合し、その一つだけが共通目的も満たす | 真 | 真 |
| 全計画で全員が適合するが、共通目的が成立する結果は別にしかない | 偽 | 真 |

ここでの「全計画」は明示した利用可能性と評価範囲に相対的である。訓練、服従の意図、例外を許す信頼性、指揮権の正当性、現実の因果的な保証まで同じ条件で説明したとは扱わない。

## 検証と残る作業

[定義文書](../examples/v016/joint-readiness.noema)は15宣言・本文0文、[作例](../examples/v016/joint-readiness-example.noema)は43宣言・6質問である。46テストが通過した。計画の利用可否、二人の履行、共通目的を変える16組合せに加え、別々の成功計画、評価が不整合な別計画、一つの評価結果だけでの失敗、人数の不正な列挙、出所・集団・文脈・要求の取り違えを検査した。

要求の網羅性は保存文書では全行為記述へ量化する。有限診断ではその量化だけを二つの記述へ限定し、全域の直接評価は拒否されることを確認した。これを全域の網羅性や自然言語の意味の証明とは扱わない。

長形式・短縮形式・固有文字の往復、文書と検査記録の再現、CLI解析、SVGのXML検査が通過した。キャッシュの有無で人数と固定した共同計画の適合判定が一致することも確認した。SVGの目視検査は行っていない。

```powershell
python -X utf8 -m scripts.compose_joint_readiness
python -X utf8 -m pytest tests/test_joint_readiness.py -q
python -X utf8 -m scripts.check_joint_readiness --verify-only
```

[意味条件](../data/joint-readiness-basis-v1.json)と[検査記録](../reports/joint-readiness-v1.json)を保存した。軍隊の制度的・活動上の特徴、公的平穏の内容、計画者による統制の成立、本文の発話可能性への接続は残る。今回の構造を原文の完成訳とせず、原文対応範囲と意味確認済み区間数は据え置く。
