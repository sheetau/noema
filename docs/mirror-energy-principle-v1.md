# 鏡のエネルギー原理と光圧表示

対象は原刊915頁のu0222の四文とu0223の表示式です。原文359非空白本文文字とM0377–M0381を、同じ移動鏡の続きとして記述します。先行の402主張と意味規約を保存します。

第一文の静止系はKです。入射量は同じ矩形の全位置で一様な時間平均、第二文の戻る量も同じ区間・面部分の平均と読みます。先行のektxが、Jx−v*uの鏡上の引戻し、全接線位置の平均、同じ力からの平均圧力と機械的仕事を構成しています。原文のA‴²は三重プライムを付けた振幅全体の平方です。MathMLではプライムと空基底平方が二つのmsupに分かれますが、別の量ではありません。

今回追加する一般関係eisu2は、有限面部分・時間区間での五経路の物理的帰属です。到来・戻り・透過・機械的仕事・その他の正味移転を同じ相互作用、物体、面部分、系、単位、領域へ結びます。保存式は含めません。先行eisudの点ごとの完全な四経路モデルを、有限区間の総量として扱い、物体への移転を機械的仕事とその他に分けます。eisu2の採用をeisudから自動的に導くことはせず、同じ理想モデルについての追加の対応として明記します。

ekt5はその対応と量の有効性、正の面積と時間幅を構成します。ekt6は同じ102設定を維持し、ektxの入出と仕事の平均値に同じ面積と時間幅を掛けて総量へ結びます。透過とその他の正味移転を零とする理想鏡の読みを採用します。熱等の個別経路が全て不存在とまでは要求しません。kでの物体移転零をKでの仕事零に変えることもありません。

保存の数式はekt7で独立に構成し、ekuaは全ての有効な完全収支についてそれが成り立つという一般の原理内容です。Energieprinzipの表記をこの内容へeischで結びます。ekt6には保存式、仕事=P*v、閉じた圧力式を含めません。

四文の役割はekuoで同じ評価状況へまとめます。二つの量が同じ設定に結ばれること、文の順序、箇所の区別は別に構成します。Pの命名規則ekuhは同じpatchと値に96証人を共有し、既存の力・区間・面積へ結びます。閉じた圧力式をPの語義へ含めません。

仕事=P*vは零速度でも定義されますが、零速度では仕事零から圧力を決められません。表示右辺の零速度値と、それを仕事だけから導けることは別です。本文の「得る」は著者の導出提示として保存し、極限による補証を原文に追加しません。先行のk結線角の読解と周波数分母の不一致も保存します。

局所検査では、完全収支の役割と総量への倍率、全ての量化位置と真偽値の選択側、仕事と圧力の独立性、正・負・零速度での数式、各文の照応・引用・提示・命名・帰属、原文五式と既存の証拠の保存を確認します。有限対照を保存則の物理的証明や意味同義性の自動証明とは扱いません。全単位の意味判断は別の記録で行います。
