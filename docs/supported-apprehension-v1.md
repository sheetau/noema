# 恐れを支える理由と、実際に起きる害を分ける

カント第17区間の「影を恐れない」に対し、「理由に支えられない不利益予期がない」という解釈候補をNoemaで記述した。前段で未充足だった `target` 引数へ、この性質の記述を渡す。解釈候補を具体化した段階であり、原文との意味一致を確認し終えた訳ではない。

## 解釈の根拠と選択

[カント原文 AA VIII, 41頁](https://www.korpora.org/Kant/aa08/041.html)には、啓蒙、影を恐れないこと、軍隊を持つことが発言資格に関わる条件として並ぶ。[AdelungのSchatten項の転載](https://www.kassiber.de/grimmschatten.htm)には、自分の影から逃れるという関連表現を、理由なく恐れる意味で説明した用例がある。項目本文は確認したが、辞書の原刊画像との照合は未実施である。

この用例を根拠に、理由に支えられない恐れを解釈候補として採った。カントと同一の言い回しではなく、語義用例から著者の意図が一意に決まるとはしない。また、理由を正当化の根拠として扱うことも、本草案で明示した選択である。情動が発生した心理的原因の不在とは区別する。判断と根拠は[解釈記録](../data/shadow-reading-review-v2.json)に保存した。

## Noemaで構成した条件

[一般定義](../examples/v016/supported-apprehension.noema)は四定義であり、新しい原始記号や構文演算子を持たない。情動と理由の関係を引数として受け取る。

| 定義 | 内容 |
| --- | --- |
| `rvv` | 同じ本人・状態・対象記述・基準文脈に、不快な情動と不利益予期が結び付く。既存 `rvm` の条件を状態ごとに取り出す。 |
| `rvw` | 本人に利用可能な理由があり、同じ対象記述について、その状態で予期する不利益候補の少なくとも一つを支持する。 |
| `rvx` | `rvv` を満たすが `rvw` を満たさない状態が存在する。 |
| `rvy` | どの対象記述についても `rvx` が成立しない。 |

理由は、別の人物にだけ利用可能なものや、別の記述・候補を支えるもので代用できない。一つの状態が支持されていても、別の支持されない状態を打ち消さない。同じ真理を持つ別名の記述へ、支持関係を自動で移すこともない。

ここでの支持は、指定した評価基準に照らして予期候補を支えるという入力関係である。理由の存在、本人の確信、演繹的な証明、現実の真理とはそれぞれ異なる。利用可能性と支持の評価基準そのものの基礎付けは残る。また、一つの不利益予期に支持があれば `rvw` は成立するため、全予期の正当化や恐れの程度の妥当性を要求する定義ではない。

| 恐れている | 利用可能な支持がある | 実際の害 | この状態は `rvx` の例になるか |
| --- | --- | --- | --- |
| はい | はい | 起きなくてもよい | ならない |
| はい | いいえ | 起きてもよい | なる |
| いいえ | 任意 | 任意 | ならない |

## 本文への接続と検査

[後継草案](../examples/v016/kant-supported-apprehension.noema)の `hzwtarget` は `rvy` から本人の性質を作り、`hzwonly` がこれを既存の発言資格へ渡す。描写との対応、啓蒙、引用内の話者・聞き手・文脈の照合を引き継ぐ。字義的な影の存在や、それへの恐れの真偽は解釈先の成立条件に加えない。元の全宣言と先行18文を保持し、最後の候補解釈の帰属を更新した。[接続部分だけの文書](../examples/v016/supported-apprehension-core.noema)も保存する。

226テストが通過した。情動と理由の128通り、現実の対象・害との8通り、本文の資格条件との64通りを含む。未知の支持を支持の不在として補完しないこと、候補解釈の帰属が内容の実行を伴わないこと、必要な引用層も検査した。[検査記録](../reports/supported-apprehension-v1.json)には表記往復と入力ハッシュを保存する。

`rvy` は全ての型付き対象記述への量化を保持する。実行器はこの無限領域を有限に列挙できないため、直接の真偽評価を拒否する。有限検査では、保存された量化の本体を二つの明示した記述へ適用している。この検査を全域の証明とはしない。全域への主張を記述・引用できることと、実行器が真偽を決定できることを分ける。

```powershell
python -X utf8 -m scripts.compose_supported_apprehension
python -X utf8 -m scripts.check_supported_apprehension --verify-only
python -X utf8 -m pytest tests/test_supported_apprehension.py -q
```

同じ原文範囲の候補を具体化したため、部分草案の文字割合は増やさない。軍隊・公的平穏などの `remaining` 条件、比喩の解釈の確認、基礎概念、全文の意味確認は残る。意味確認済みの全文単位は両作品とも0のままである。
