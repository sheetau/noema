# 物質点への質量結果の適用

原刊919頁u0260を全文で扱う。前半は、直前までに得た質量結果がponderableな物質点にも当てはまるという指摘。後半は、任意に小さい電荷を加えれば、この論文でいう電子にできるという理由である。

最初に不足していたのは、物質点の範囲、元と結果の電荷の物理的帰属、先行の電子という呼称、電荷を要求しない同じ質量結果への接続である。既存seqr–seqtの厳密な小ささと加法的収支、ek3oの低速慣性質量、ek5sの両系履歴、seppの実二階微分、seph/sepfの二係数を再利用する。

eocは機械的状態を一つの位置で扱う点状物体と、正に校正した単位で正の低速慣性質量を持つことを合わせる。ponderableはこの力学的な質量を持つ物体の意味で読む。重量の測定を追加せず、最初から荷電粒子又は中性物体へ限定しない。

eodは同じ対象と単位の電荷値を物理的な記録へ結び、eoeは同じ点状荷電担体と非零電荷を要求する。この分類がu0240のElektronという著者の呼称に対応する。eof/eogは同じ物体と単位を保つ許容操作と可能結果を一組で扱い、元の量＋追加量＝結果の量を保つ。零への相殺や別対象への置換を成功としない。eohは同じ元状況・単位について全ての正の有理上限を扱い、eoiは全物質点へ接続する。上限ごとに操作と結果が違ってよく、実際の実行又は全結果での成功は要求しない。

eoj–eomは電荷を前提にせず、同じ物質点の正の低速慣性質量、整合した単位、二系の完全な履歴と同じ出来事、瞬間共動系の機械的力と元系の座標加速度へ、μβ³,μβ²を結ぶ。速度方向をx、直交二方向をy,zとする先行の配置を各設定に使う。原点の一致や全期間の等速運動は付け足さない。eonはこの規約での全設定に二係数の結果が適用されるという内容であり、観測された一つの零入力だけで質量を定めない。

eooは前半を著者の指摘として提示し、先行の二質量へ照応させる。dennの理由は電荷付加の可能性から適用拡張へ向ける。in unserem Sinneは同じ著者が先に採った点状荷電対象という呼称に限定する。電荷付加時に質量が厳密に不変であるとか、可能性だけで式が数学的に証明できるという追加前提は置かない。物理的論証の妥当性と、そのように著者が述べた内容の記述を分ける。

検査は二係数、単位、同じ履歴・力・物質点、正負の小電荷、既存電荷、相殺・置換・不可能な操作、理由方向と引用、各存在束縛を扱う。全有理上限と全実履歴は有限標本で認定しない。全文判断は検査の成功とは別に原文と照合して記録する。
