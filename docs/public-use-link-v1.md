# 公的・私的使用の草案と取得条件の統合

別文書だった公的・私的な理性使用の草案を、現在のカント文書へ統合した。発言する本人の立場・活動・宛先と、同じ内容を取得する読者側の条件を結んだ。発言の許可と取得の許可は、同じ出所から与えられる場合でも別の条件として保持する。

## 旧文書を復元できる結合

旧草案を0.11から0.14へ明示的に上げ、既存の文書結合器で全宣言と参照を移した。元の二文書の宣言は共有していない。同じ綴りでも、例えば旧 `aa` は規範上の要求であり、現行 `aa` の人の分類とは異なる。衝突する名前には新しい名前を割り当て、変数や引数の位置は保つ。

意味規約と定義の説明に出てくる記号も同じ対応表で更新した。対応表は意味規約の `role_linkage` に保存している。結合後の文書から現行文書の全構文木を復元し、旧草案も元の版に戻して全構文木が一致することを検査した。全主張15件を保持しており、公開性の現実の成立を述べる主張は追加していない。

名前を分けて取り込むことだけでは、異なる説明同士の意味的な接続は成立しない。次の定義で、どの宛先・内容・提供経路を共有するかを明示した。

## 同じ活動と読者範囲を固定する

`h6t` は指定した宛先を、想定される読者の範囲へ展開する。実際に読んだ人や、有限の構成員列だけを指す関係ではない。`h6u` は活動の記述を、予定された提供経路・話題・Noema発話記述へ結ぶ。計画や活動分類の関係であり、提示や受領の実行を意味しない。

`rdl` は二つの範囲が非空で、対象が双方向に一致する条件である。一人だけ共通する場合や、片方がもう片方の部分集合であるだけの場合は成立しない。

`h6v` は、旧草案の公的使用の分類に加え、同じ活動の指定した宛先が公衆に分類され、その想定読者範囲と取得条件の読者範囲が `rdl` で一致することを要求する。同じ活動の提供経路・話題・発話記述も固定する。別の公衆に向けた活動や、別の経路の取得条件を借りて結合できない。

## 読む許可と述べる許可

`h6w` は `h6v` で固定した活動について、同じ読者範囲の全員に取得方法の許可がある条件を加える。`h6x` は同じ範囲の全員に実効的な取得機会がある条件を加える。先行版の `h6q`・`h6r` をそのまま使う。

`h6y` は、発言者本人が同じ立場で同じ活動を実行することについて、指定した規範の出所から積極的な許可があり、禁止と衝突していないという条件を加える。これは旧草案の規範と活動実行の定義へ接続しており、読者の取得許可で代用しない。

読者の取得許可だけがある場合、発言者の発言許可だけがある場合、読者には許可があっても取得手段がない場合を区別する。活動が公的使用に分類され、許可や取得機会もあって、まだ発言が実行されていない場合も表せる。

## 検証と残る意味

旧草案の規範12例・役割17例を元の文書と結合後の文書で実行し、29組全ての結果が一致した。現在の取得条件の25例と未評価の扱いも、結合後の文書で再実行した。再利用した検査関数の一時的な接続先は検査後に復元する。

二人を持つ領域での範囲一致16組と、新しい接続の19例を検査した。別の公衆、読者の欠落・余分な読者・空範囲、発言者の別の立場、別の経路・話題・発話記述・文脈による取り違えを除外する。発話の真理や理解の判定は実行しない。

この統合は、公衆・学識者・市民的職務の意味規約を完成させたものではない。二つの読者範囲が一致していても、双方が公衆を適切に捉えているかは別途確認が必要である。規範の条件も、公的使用の自由全体や権利の保障と同一ではない。旧草案の内容値による規範評価を保持しており、同じ真偽を持つ別の活動記述を区別する一般的な規範理論への拡張も残る。

具体的な活動実行から伝達経路への接続、集団内の能力変化、討議と応答、原文の頻度・程度・留保の記述は未完である。原文対応は旧草案の四つの範囲を新しい記号へ移したもので、対応文字数や意味一致確認済み区間数は増やしていない。

統合文書は基本関係244・定義414・主張15である。累積正規形は2,432文字増えて65,213文字になった。関連35テストが通過し、保存済み検証記録との再生成一致、通常・短縮記法と固有文字の往復、CLIのJSONと構文木の一致、SVGのXML形式を確認した。字形の目視検査は今回行っていない。
