# 曲線と時計・出来事の対応

[世界線の草案](../examples/v014/einstein-worldlines.noema)では、数学的な曲線を、特定の対象の運動に結び付ける条件を記述した。以前の曲線と近似の文書に、既存の次元定義8件と今回の15定義を追加し、29基本記号・96定義となる。文法と32文字の字形は変更していない。

## 全経路の条件

曲線に始点と終点を与えるだけでは、その間に時計がどう動いたかは指定できない。今回のseは、同じ対象・基準系・文脈・長さ単位・時間単位を共有して、次の条件を要求する。

- 区間の全ての実数時刻について、曲線上の座標を持つ、その対象の出来事が存在する。
- 逆に、その対象について区間内に割り当てられた座標は全て、同じ曲線上の値と一致する。
- 同じ出来事に、同じ基準系・文脈・単位で異なる有効な四座標を割り当てない。

「全時刻に出来事が存在する」と「既にある出来事が曲線に一致する」を分けて記述する。後者だけでは、出来事が一つもなくても条件を満たしてしまう。出来事の数を有限に制限する条件は言語には追加していない。

sgはこの経路へ時計の指示関数を結ぶ。同じ時計・出来事・基準系・時間単位の指示が一意であり、経路上の指示が関数の値と一致することを要求する。進み率を積分した値になるという法則はsgにも経路の定義にも含めない。

## 単位と物理的な意味規約

| 記号 | 基本関係として与える意味 |
| --- | --- |
| tf | 出来事の、基準系・文脈・長さ単位・時間単位を指定した実数の四座標 |
| tg | 指定文脈で、出来事が指定対象の世界線に属する関係 |
| tj | 同じ基準系・文脈・長さ／時間単位比での実数の光速度 |
| tk | 指定文脈で基準系が慣性系である条件 |
| tl | 単位の次元と正の有理数尺度。前のpeの意味規約をそのまま再利用 |

これらは言語から導出した物理法則ではない。基本関係の引数と意味を[意味規約](../data/worldlines-basis-v1.json)へ記録し、物理的な実現や一般理論への還元は未完としている。

sfは長さと時間の異なる基底軸・単位を要求し、既存の次元定義dhと単位の記録を照合する。尺度は正とし、例えば長さ尺度1と1/1000は別の記録として扱える。今回は異なる単位間の観測値の換算法則までは追加していない。同じ単位の組で座標・指示・光速度を使う条件を述べている。

## 原文の仮定と帰結への接続

shは以前の観測条件qbに、動く時計と静止する参照時計の全経路を接続する。参照時計は全区間で同じ位置にあり、その指示は座標時刻に一致する。出発・帰着は指定した同じ出来事に結び、初期の指示一致と最終指示を保持する。

qiはshを前提として時計の積分法則を採用する、という仮定の内容である。qjは同じ観測条件を使う近似と残差の帰結である。どちらも著者に帰属する仮定範囲の記述として引用し、文書全体の無条件な真理として評価しない。観測の前提shには積分法則neを含めていない。

保存済みのアインシュタインu0128・M0241に部分対応させた。前段の折れ線の証明、地球上の時計についての推論、物理的な基礎付け、原刊との照合は残る。今回も完成した全文単位としては数えず、アインシュタイン0/282・カント0/20を維持する。

## 検査の範囲

有理数を実数の切断へ埋め込んだ、31の観測・単位・一意性の具体例を検査した。別の時計・出来事・基準系・文脈・単位へのすり替え、指示の欠落、不正な次元や負の尺度、矛盾する座標と指示を区別する。検査器で切断を比較するのは、検査用に構成した既知の有理数埋込みだけである。

これらは有限個の点の検査であり、全ての実数時刻にわたる世界線の検証ではない。全域の一意性を有限意味論へ直接渡した場合は、検査不能として拒否する。引用内容を評価せずに著者への帰属を記録できること、観測の前提へ積分法則が混入していないこと、正規形・固有文字・SVGの往復も検査する。

```powershell
python -S -m scripts.compose_worldlines
python -S -m scripts.check_worldlines --verify-only
python -S -m noema parse --input examples/v014/einstein-worldlines.noema --output artifacts/worldlines-v014.json
python -S -m noema render --input examples/v014/einstein-worldlines.noema --alphabet v2 --output artifacts/worldlines-v014.svg
python -m pytest -q
```
