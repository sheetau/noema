# 四つの座標変換式と出来事・基準系の接続

アインシュタイン原文のu0082、数式M0135の四式を、[一つのNoema文書](../examples/v011/einstein-coordinates.noema)にまとめた。βの定義と単位・次元の定義を引き継ぎ、同じ出来事について二つの基準系の読みを結び付ける関係も追加した。

原文のこの箇所にあるφ(v)は、まだ値が確定していない速度の関数である。そのまま関数として受け取り、1には置き換えない。直後のu0085に述べられる原点の加法定数も、四つを別々の引数として保持した。

## 四式の記述

原文の記号では次の式である。

```text
τ = φ(v) β (t − vx/V²)
ξ = φ(v) β (x − vt)
η = φ(v) y
ζ = φ(v) z
```

定義eaは、有理数の引数について四式とβ条件cmを合わせる。時間式はVが正であるため、分母を払った`V²τ = φβ(V²t−vx)`で表す。βの条件からV≠0なので、この操作でV=0の場合を新たに受け入れることはない。

ebは、速度から値を得る関数φを受け取り、その速度での値をeaへ渡す。ecは、出力座標からそれぞれの原点定数を引いてebを適用する。実数の切断については、ed・ee・efに同じ構造を記述し、入力・出力・原点定数の切断の妥当性を要求する。

| 定義 | 範囲 |
| --- | --- |
| ea / ed | φの値を受け取る四式。有理数版／実切断版 |
| eb / ee | φを速度の関数として受け取る |
| ec / ef | 四つの原点定数を明示する |
| eh | ecにφ(v)≠0を加えた、退化しない有理数の座標変換条件 |
| eg | 同一出来事の二基準系での読みとehを結び付ける |

φ=0では、原点定数を除く全ての出力座標が0となり、四式そのものは成立し得る。しかし全出来事を一点へ潰す写像を座標変換とは扱わない。ehではその退化を除外する。これは式の適用条件として明記したものであり、原文の同じ位置にある独立した主張として数えない。

## 観測との参照を揃える

egは、二つの読みが同じ出来事・文脈を指すことを、同じ引数への参照で保持する。新しい基本関係には次の意味規約を与えた。

| 基本関係 | 内容 |
| --- | --- |
| pa | 出来事・基準系・文脈・長さ単位・時間単位を指定した四座標の読み |
| pb | fromから見たtoの、x軸方向への符号付き相対速度 |
| pc | 指定基準系・文脈・単位での光速度 |
| pd | 二つの慣性座標系が標準の平行配置にあるという設定 |
| pe | 単位の次元と基準尺度 |
| pf | 二基準系・文脈・単位表記に対応するφと四つの原点定数 |

paを二度適用するとき、出来事・文脈・単位は共通にし、基準系をfromとtoに分ける。読みが存在しない場合に数値を補わない。相対速度の引数順も保持する。toから見たfromの記録を、そのまま同じ向きの速度として採用しない。

長さ単位と時間単位には、前回の基底次元条件dhと正の尺度条件を適用する。速度の数値単位は、同じ長さ単位を時間単位で割ったものとする。この構成では入力側と出力側に共通の単位表記を使う。別々の単位から読みを与える場合は、前回の換算関係で共通の単位へ揃える処理が必要となる。

pfにも単位を含めた。φの引数が数値としての速度であり、原点定数も座標の数値だからである。ある単位表記に対応する関数・定数を、別の単位表記へそのまま流用しない。

基本関係を追加しただけでは、出来事・測定・慣性系・方向・単位の物理的な意味を定義し終えたことにはならない。[意味規約](../data/coordinates-basis-v1.json)には10基本記号・50定義と、それらの未解決点を記録した。また、一出来事でegが成立することと、全ての出来事に共通の変換として成立することは別である。

## 検査した式と具体例

有理数の座標について、四式から次の二つを多項式検証した。

1. `V²τ²−ξ²−η²−ζ² = φ²(V²t²−x²−y²−z²)`が成立する。
2. φ=1の場合、変換後の座標から速度を−vにした四式を適用すると元の座標へ戻る。

二つ目はφ=1を条件にした性質である。原文の未知関数が1であることを証明したわけではない。実切断の構成との一般的な対応や、物理的な光の伝播の議論も、今回の多項式検証だけでは完成しない。

数値検査では、速度3、光速度5、β=5/4、入力座標(t,x,y,z)=(2,4,6,8)を用いた。φ=1なら(τ,ξ,η,ζ)=(19/10,−5/2,6,8)、φ=2なら(19/5,−5,12,16)となる。横方向の座標にもφを掛ける必要があり、省略した式は成立しない。これらは数学的な確認用の仮定の数値であり、現実の光速度の測定結果ではない。

φ(v)=v−1、原点定数(1,2,3,4)も検査し、速度3でφ=2を使うことと、四つの原点定数を保つことを確認した。時間混合項の符号、V²の分母、原点定数の欠落、φ=0の退化も含めた9例を記録した。

観測の側では15例を使い、正しい結び付けの1例と、別の出来事、別の文脈、基準系や相対速度の向き、読みの欠落、単位や変換パラメータの不一致など14例を区別した。検査用のpfは、φの値を当該速度で確認する解釈である。任意の数値関数の全域的な同一性を有限個の値で検証したとはしない。
