# 光速未満の合成と光速度の不変性を円文字へ接続する

対象は原刊906頁のu0143–u0146である。既存の49定義を再利用し、光速未満という一般的な上限、不足量による説明、光速度への特殊化、同じ結果が光速度に等しいことを円文字本文へ接続する。固定アルファベット・共通375語・任意プロファイル64の861語を維持し、公開語彙や参照用の基礎関係は追加しない。

第66段落の第一文は一般主張、第二文は仮定と表示式を含む説明である。第二文中の仮定提示zlj、局所範囲zlk、表示式zllを別々の参照として保持する。κとλは同じ文中のそれぞれの記号位置を参照し、既存のdescribedcutreferenceで取得する。役割はs3o(V,v,κ)とs3o(V,w,λ)から構成する。これは同じ入力への対応と0<κ,λ<Vを表す記述であり、参照取得が仮定の真偽や実在を判定するわけではない。

一般主張の0≤v,w<Vと、不足量の条件が表す0<v,w<Vを区別する。零速度を一般式から除かず、厳密な不足量による説明が零速度まで扱うことにもならない。κとλを入れ替えて商の値が同じでも、それぞれのv/wへの対応は失われ得る。表示式の等号、内外の除算、厳密な不等号を保ち、上限だけで式全体を代用しない。

第67段落では、一般の光速度不変性と、その場合の表示式を得る提示を結ぶ。原刊のU=(V+w)/(1+w/V)=Vの二つの等号を同じ結果について保持する。電子転記との差は既存の訂正層を使用する。数式の入力交換と物理的な系・点の役割交換を区別し、光速の点への条件付き適用を、光速で動く系の実在仮定へ変えない。

診断では既存の数値核、全称の束縛、物理的な適用条件、著者への帰属を復号後の定義に接続する。全実数量化の有限列挙拒否を残し、各参照の引数、役割の型と階数、未知入力の拒否、引用した役割を実行しない取得を調べる。有限の識別診断、既存の有理多項式証拠、原文の採用解釈、独立した読解は別の根拠として扱う。
