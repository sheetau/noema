# 二組の方程式の比較と共通係数

u0163の三文とu0164の六式を一つの推論段落として読む。必要な関係は、先行する二つのkでの式とKでの式への参照、両者がKの式に等価であるという理由、同じことを表すという必要性、Offenbarの明白さ、さらにベクトルを指す表記だけが異なる式の形、全六成分・全地点時刻に共通する係数、速度依存の許容、結果の表示である。

等価性は、同じ物理的な二系・過程・場・真空領域と座標変換の比較設定における双方向の成立条件の一致という読みを採る。一つの観測で真偽が一致したという意味にはしない。前提の比較範囲は方程式の成否で選ばず、非空の全評価状況への必要性を既存ejrjで構成する。著者は両方がKの式に等価であると述べているが、前段の六回転式だけでその導出が証明されたとは認定しない。

「記号以外は一致」は、同じV、四座標と三軸、六つの回転式の偏微分・係数・差の形を保ち、二つのベクトル関数だけを対応箇所で置き換えることと読む。表示の対応には一般の閉じた二場方程式の型を使う。原刊の分母1/Vは正のVで払ったs5yと対応し、二列の配置順は六条件の並べ方の差として扱う。式の真理やベクトル関数の等値を、同形性へ混ぜない。

係数は同じψ(v)を電気側・磁気側の全六成分に使い、領域全体の量化の外へ置く。ξ,η,ζ,τに依存せず、vに依存してよいという内容であり、速度に実際に依存することは要求しない。正・負・零、定数関数をこの箇所では除かず、非零性・偶性・値1は後続に残す。「alle Funktionen des einen Gleichungssystems」は対象となる一組の六成分関数全てと読み、全く別の物理的な場の選択に対する追加の普遍量化は補わない。
