# 義務判断の自己報告と、本人の品位評価

第八段落冒頭では、本人の評価対象は「宗教上の自由を残すことを義務と考えている」と述べる行為である。その行為を自分にふさわしくないとは考えないことから、実際の発言や、その発言の誠実さまでは導かない。今回はこの入れ子を、前回の自由方針・義務・本人の義務判断へ接続した。

r5wf–r5wgは同じ本人の同じ義務判断を述べる主張発話を作る。r5wh–r5wjは、その内容を同じ提示者が同じ生起活動で、非空の受け手全員へ伝えるという実行条件を作る。受け手と発話の対象となる本人を別の引数に保つ。受け手が内容を理解・承認することや、特定の歴史的な一回の発言は加えない。

r5wk–r5wmはこの自己報告を行為記述として受け取り、本人の品位についての最低基準を満たさないものがあるか、全て満たすかを評価する。既存rne・rnfの非空の全基準を調べる構成を、高い段階の行為記述へ適用した。空の基準列は不適合とも適合とも認めず、同じ真理値の別の行為へ基準を移さない。

[DWBのunwürdig](https://www.dwds.de/wb/dwb/unw%C3%BCrdig)には、個人の品位・道徳的な自己意識に反する用法と、Wielandの「自分にふさわしくないとは考えなかった」という同形の用例がある。この文では、本人にふさわしい尊重や自己のあり方に反しないという最低水準の評価を採る。前段落の公的威厳への実際の因果的損傷を、そのまま評価の必要条件にはしない。

各基準は本人と行為記述からNoema内容を返す関数として入力し、固定基準における全条件を列に含める。具体的な基準の内容と、品位の基準として適切であることは解釈の責任として残す。既存のテスト用の二条件が、あらゆる人物の品位を定義するとはしない。最も立派であることや称賛を得ることも、最低条件の充足に加えない。

r5wn–r5wqは、同じ本人・規範出所・公的立場・対象集団・共同体・宗教主題・受け手・固定基準を保ち、この非不足の内容を本人が受け入れることを構成する。否定的な評価を持たないだけでは、この肯定的な受入れを満たさない。逆に、実際には基準を満たさなくても、本人がそう判断することはありうる。

発話族は段階4、その報告行為は段階5、品位への評価内容は段階6で引用する。外側の判断は引用内容を実行せず、本人の品位評価、現実の基準充足、報告行為、内側の義務判断、義務、自由方針の実現を区別する。検査は外側の評価・実際の適合・実際の報告の8通りと、自己報告内容の真偽、全受け手の接続、全参照の取り違え、未知入力、引用段階を調べる。
