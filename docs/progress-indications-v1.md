# 同じ進行を示す徴候

第七段落第三文の「それを示す明瞭な徴候がある」を、前回の機会開放と障害漸減の同じ連言へ接続する。徴候があることと、その対象が実際に真であることは区別する。第一文の回答には同じ進行内容を主張内容として渡す。

原文は [AA VIII 40](https://korpora.org/kant/aa08/040.html) の保存済み本文と原版491ページを参照した。`davon` は前の二節を受ける。`wir` は著者を含む話者側に利用できる徴候と読み、人類全員の実際の認識や同意は加えない。

## 実際の内容と比較用の内容

前回の `r5uj` は現在を固定する。そのまま旧 `rmb` の仮説に渡すと、外側の比較点を替えても内容が一定なので、必要な真偽の両群が存在しない。この誤接続を避けるため、`r5ul` は同じ人口・主題・基準について、比較例ごとに対応する候補履歴・現在・開始点・過程を渡して `r5uj` を返す。

`r5um/un` は、進行族とその評価条件を実際のNoema記述として閉じる。`r5uo/up` が選ぶ実際の対象は固定する。一方、診断用の `r5uq` は、同じ族の各比較例を評価する。現実の時刻の変化、代替状況の違い、同じ命題への引用を混同しない。

`r5uk` は各例の現在人口枠、全取り組み候補の両端の機会評価、全障害候補の全区間評価、正の段階上限を確認する。能力評価やモデルが欠けた例を「進行していない例」へ混ぜない。実際の例も比較範囲に含める。

## 採用する「明瞭」の読み

ここでは、同じ固定された比較範囲で、対象が成立する例の方に十分偏って現れる徴候という読みを採る。旧 `rmb` の正の重み、真偽両側の存在、1より大きい文脈係数による識別力を再利用する。原文が確率や具体的な係数を指定したとはしない。事後確率、実測頻度、演繹的な保証、証拠の独立性は追加しない。

`r5ur/us` は、同じ主体が利用でき、同じ閉じた対象へ結ばれ、実際に内容が成立する複数の項目を求める。各項目の命題内容はNoemaとして与え、分類・対応・利用可能性の未知を偽で埋めない。`r5ut/uu` は同じ進行族の全比較例の評価を確認し、同じ話者・実際の現在へ徴候を結ぶ。対象が現実には偽でも徴候は成立しうる。

`r5uv/uw` は実際の例の同じ現在人口・宗教的能力・基準と、同じ進行内容を `r5tm/tn` の問答へ渡す。回答が進行を述べることと、徴候だけからその真理を推論することは別である。

## 検査と残作業

閉じた対象の同一性、外側の評価点の不変性、比較例の対応、32種類の徴候配置、実際の対象が偽である場合、未評価例・不正な列・重み・閾値の拒否を検査する。問答は人口と割合基準の実定義で確認し、進行・課題能力など先行検査済みの部分は型付き境界として明記する。

第三文の場の比喩、現在進行、`doch`、`Allein`、`oder` の説明的提示と著者帰属は未完である。第一文の条件付き問答と談話上の提示、第二文の大きな不足と支援可能性、最後の時代名、段落通読も残る。本文108主張・確認済み16区間を保持し、今回の意味確認文字の追加は0とする。
