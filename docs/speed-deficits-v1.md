# 光速からの不足と、合成結果の厳密な上限

アインシュタイン1905年論文§5のu0143とu0144・M0271を部分記述した。二速度の合成結果が常に光速より小さいという主張、κ・λによる置き換え、変形後の式、後続の式を論証として示す働きを区別して接続する。

原文の置き換えと式は次の形である。保存済みの原刊906頁で条件句と数式を照合した。

```text
v = V−κ,  w = V−λ
0 < κ < V,  0 < λ < V
U = V(2V−κ−λ)/(2V−κ−λ+κλ/V) < V
```

正の上限Vからの不足gを、0<g<Vかつa=V−gという一般の関係として定義した。速度に限る基本演算は追加していない。同じ関係は、上限5に対する量3と不足2のような数量にも使える。元の量が0になる境界ではg=Vとなり、この厳密な不足条件には入らない。

本文の一般主張は、前段の同方向の一次元合成式に続く速さの記述として、0≤v,w<Vの範囲で読む。入力範囲を満たす任意の二実数に対し、既存の式で構成した結果が有効な合成結果であり、0≤U<Vとなることを全称量化した。「条件を満たす結果があれば小さい」とだけ記述して、結果の不在によって空虚に成立させる形にはしていない。

この一般主張の範囲には零速度が入るが、原文の0<κ,λ<Vという論証の条件は、元の速度が0の場合を含まない。κ=Vまで条件を緩めず、v=0またはw=0の合成は別の境界例として確認した。単に「Vより小さい」という符号付き数の比較へ読み替えて、任意の負速度まで範囲を広げてもいない。

変形後の商とU<Vは別の条件である。V=5、κ=2、λ=4なら正しい結果は25/7となる。1も5より小さいが、同じ式の値にはならない。検査ではこのような誤った結果を拒む。V=1、κ=λ=1/100の場合も、結果19800/19801を分数のまま扱い、丸めて1と同一視しない。

有理数の補助検査ではA=2V−κ−λ、D=VA+κλと置き、元の一次元合成式とDU=V²Aの同値性を確認した。厳密な不足条件からA>0、D>0が得られ、D(V−U)=Vκλという等式と合わせて0<U<Vが得られることも確認した。これらの関係を分けて検査することで、結論の不等式を式の定義へ埋め込んで正しいと判定することを避けた。

本文の帰属には既存のzc・ug・zfrを使った。一般形の式から上限の主張へ進むこと、置き換えを局所的な論証範囲へ置くこと、同じ変数を使って変形後の結果を得ること、その結果を先行する主張の論証として提示することを記述する。著者が論証として提示する関係は、検査器がその論証を受理したという関係ではない。実切断全域の体・順序の法則の機械的証明は未完である。

検査記録には代数12件、不足の境界9例、変形後の商12例、一般主張の具体例10件、本文の変数接続10例、帰属8例を保存した。κとλだけを交換すると商の値は変わらなくても、元のvとwへの接続は変わるため、置き換え条件を満たさなくなる例も確認した。

全実切断への量化はNoema文書内に保持した。有限解釈器にこの量化を実行させると拒否されることを確認し、具体例の一致を全域の証明として扱っていない。新規8件を含む関連28テストが通過した。通常記法・短縮記法・固有文字の往復、CLIのJSONと構文木の一致、SVGのXMLとしての読み込みも確認した。全テストの実行と字形の目視確認は今回の検査に含まない。
