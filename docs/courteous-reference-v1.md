# 敬称による言及と、紹介記事内の名称使用

脚注の`des Herrn Mendelssohn`に、人物を丁寧に扱う言及という側面を追加した。既存の紹介行為`hzjq`は、週報の案内が回答を紹介する行為である。一方、今回の`hzlp`はカントの脚注自身にある人名使用の箇所を指す。同じ人物へ同じ名称を使っていても、二つの使用を同じものとして扱わない。

一般形`rqsl`は、名称使用の成立、その名称の対象への適用、同じ使用で対象を丁寧に扱うことを、共通の文脈で結ぶ。新しい基本関係`hzlq`は表現の慣習的な扱いを述べる。相手を本心から敬愛する、学説に賛同する、相手に命令権がある、といった主張は含まない。直接相手へ呼びかけることも必要条件にしない。

原文への定義`hzlr`は、既存の名称`hzjp`と人物`hzjo`を再利用する。名前と人を区別し、紹介記事内の使用とは別の使用で同じ人を丁寧に指すことを要求する。誰が実際に印刷したか、肉筆かどうかは追加しない。Herrnを姓の一部に入れず、姓の識別表記は保存した。

この読みは、原刊494頁の脚注と、Adelungの[Herrの第三の語義](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_3_1_1987)にある、名前の前に置く敬称と第三者への丁寧な言及の説明を照合したものである。辞書の記述には性別・社会階層・地域差もあり、単に現代の中立的な呼称へ置き換えて全語義を解決したとはしない。辞書は読解の資料として保存し、実行時の翻訳辞書や語ごとの補正ルールには使わない。

検査は三関係の全8組合せと、同じ人・名称・使用・文脈を取り違える12対照を含む。紹介記事の中だけに丁寧な扱いがあっても、脚注自身の使用にはならない。未知の扱いは推測しない。丁寧な言及が成立しながら実際の敬愛が成立するモデルと成立しないモデルを両方許すこと、紹介・未受領・読書の既存三文と独立に評価できることも確認する。

一般関係一つ、名称使用の局所参照一つ、合成定義二つ、一文を追加した。既存23文・全宣言・意味規約と署名・日付行の依存ハッシュはそのまま保持する。敬称の性別・階層上の含意と、刊行物名・代名詞・思想比較を含む脚注全体の確認は残る。今回は丁寧な言及という側面の部分記述であり、意味確認済み単位は増やさない。
