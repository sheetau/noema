# 全ての事柄についての公的使用

第五段落第一文の末尾を構成するため、公的使用と許可の範囲に主題を明示した。[冒頭の原文](https://korpora.org/Kant/aa08/036.html)と[同段落で後に示す定義](https://korpora.org/Kant/aa08/037.html)に沿い、公的使用は自分の理性を用い、学識者の立場で、読者世界全体へ向ける活動の分類 `zzo` を再利用する。これは活動の実行や実際の到達人数の判定ではない。

既存の `hzna` は同じ公衆の全読者と全公的活動について、積極的な許可があり、不実行の要求と衝突しないことを表す。ただし主題を引数に持たないため、「すべての事柄について」に対応する範囲の確認が不足していた。

新しい `h227z` は活動記述と主題の関係、`h232a` は同じ公衆・基準文脈に固定した全主題範囲である。範囲は許可・成功・実行済みかどうかに依存させず、公的に論じうる事柄を特定の教義や職務に制限しない。どの事柄が実際にこの範囲へ入るべきかは解釈側の入力条件であり、有限モデルの検査が現実の全主題を列挙したという意味ではない。

`r2sj` は、非空の読者・主題範囲を確認し、各読者と各主題に公的活動の役割・記述があることを要求する。逆方向にも、その人の全公的活動が少なくとも一つの範囲内主題に結ばれることを要求し、主題対応のない活動を黙って除外しない。一活動が複数の主題を持つことは許す。

ここで必要なのは活動記述であり、あらゆる問題を解ける能力、発言内容の正しさ、実行、聴衆の理解ではない。公的使用の分類には禁じられた活動や未実行の活動も含める。

`r2sk` はこの範囲条件を既存 `hzna` と結び、全公的活動への許可を要求する。各主題で一つだけ許される活動を見つける読みにはしない。別の出所・人・役割・活動・実行記述への許可は代用できない。

`r2sl` は範囲条件を、第四段落で確認済みの自由維持 `r2lm` へ接続する。範囲は同じ基準で固定し、許可の成立は同じ候補の起点と後続期間で評価する。新しい条件は旧内容を保持した上で強めるため、その逆方向の無条件な同値は主張しない。旧定義と第四段落の判断は変更しない。

検査は公的使用の分類、全主題への対応、全活動への許可、起点以降の継続を定義から実評価する。第二の話題への活動記述がない場合、対応のない公的活動がある場合、第二の話題だけ許可がない場合、起点または後続点で許可が欠ける場合を区別する。実行 `cg` は未知のままにし、規範的な判定が実行を必要としないことも確認する。

第一文全体の構成には、先行する同じ啓蒙への照応、自由以外の要件を求めない限定、最も無害な自由の比較、aber・und zwar・nämlichの提示と著者帰属が残る。今回、新たな著者主張や意味確認済み文字数は追加していない。
