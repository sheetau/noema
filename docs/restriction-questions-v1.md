# 同じ文脈における二つの制限の問い

直前の四事例と追加の制限候補を、同じ要求・介入・啓蒙尺度へ結び、二つの問いの答え条件を構成した。[本文](../examples/v016/kant-restriction-questions.noema)は先行70主張を保持し、新しい部分は定義として追加している。[意味規約](../data/restriction-questions-basis-v1.json)と[検査報告](../reports/restriction-questions-v1.json)に共通入力と検査の境界を保存した。

## 候補と全要求表

比較文脈は、候補の範囲、各候補の全要求表、介入モデル、同じ背景の対応を指定する。公衆は全候補で共用し、基準は先行文と同じものに固定する。要求表の各行には出所・本人・立場・行為型・閉じた内容記述・極性を保持する。

四事例では、行の範囲を先行する全宛先と照合し、内容も同じ命令記述であることを確認する。本人の自由選択を別人の選択へ取り替えたり、行を欠落させたりした場合は拒否する。統治者の議論への許可と全服従内容は維持する。

追加候補は四事例の形式に限定しない。行の索引と本人が異なる表や、否定形の要求も受け取る。検査では、第五の候補の否定形要求について、本人の自由選択・要求の適用と解除・対応比較をNoemaで評価し、空の表や解除されていない要求を拒否することを確認する。検査用の第五候補を原文に登場する実在の政策として追加するわけではない。

## 二問は同じ対象を問う

第一問は、その範囲のうち同じ啓蒙を妨げうる候補を問う。第二問は同じ範囲・公衆・基準で、妨げず、促しうる候補を問う。第二問で公衆を変更したり、他の候補の改善を借りたりしない。

四事例を全て候補範囲に含めるが、それだけで候補が尽きるとはしない。検査では第五候補も回答になり、範囲外の候補は回答にならないことを確認する。全候補が中立なら、どちらの質問も空の回答集合を取れる。質問の構成自体は、答えの存在・唯一性や著者の賛同を主張しない。

## 本文への提示で残ること

今回追加した基本関係は、比較文脈と要求表・モデルの入力欄であり、原文の一文を名前で代用する演算子ではない。影響の内容は先行する要求・対応・尺度の定義から構成している。入力が候補の全要求を尽くすことや、モデルの背景が現実に適合することは、公開する意味規約に従って説明する必要がある。

質問の内部では段階1の要求内容を評価するため、著者へ帰属させる閉じた質問記述は段階2を必要とする。両問について段階2の引用が型検査に通り、段階1への引き下げが拒否されることを確認する。

二つの質問を著者の問いとして提示する帰属、同じ制限と啓蒙への照応の明示、aber/sondern、wohl/garの対照・留保・強調、後続回答との関係は次の統合で扱う。原文の二問の通読判断はまだ行っておらず、意味確認済み文字数は増やしていない。
