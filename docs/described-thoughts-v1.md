# 思想の内容項目と型付き発話記述の接続

前版では内容項目の対応を関係として受け取っていた。今回は項目をNoemaの閉じた発話記述へ結び、記述を比較する基準を論点・状況とともに渡す定義を追加した。新しい基本関係や構文は加えず、既存の引用・型・論理・範囲比較を使う。

発話記述には、主張・真偽を問う質問・指示の違いと、内容に含まれる対象・述語・否定・量化・条件の構造が残る。引用内の内容を評価しないため、内容が未知でも記述の比較ができる。二つの文がたまたま同じ真偽を返すことだけで、同じ内容項目にはしない。

rqrzは構文同一性による保守的な比較基準である。束縛変数名の違いは正規化するが、別名を展開したり、論理的な同値を推定したりはしない。意味が同じでも別構文なら不一致となりうる。rqsaは二つの項目の記述を同じ論点・状況で取得し、指定基準へ渡す。rqscはこれを前版の論点ごとの双方向対応と正確な一致範囲へ接続する。

rqsbは、従来の項目対応関係と記述による比較の整合条件である。比較領域内で、いずれかの文献に帰属する項目同士の対応を調べる。範囲外の項目や別状況を使って整合を満たすことはできない。条件が成立すれば、同じ比較領域・候補範囲・帰属関係を使う二方式の範囲判定は一致する。条件を定義しただけで、その成立を主張したことにはならない。

原文側ではhzljを整合条件、hzlkを記述による範囲判定、hzllを明示した基準による可能な一致範囲の問いとした。従来の問いhzldと提示文hzleを無条件には置換しない。まだ二文献の実際の思想項目を記述し終えておらず、どの基準が原文の一致に適切かも未確定だからである。比較基準に構文同一性以外を渡すことはできるが、その妥当性や内容を実行しない性質は別途確認する。

検査では、肯否・発話の種類・対象・述語・全称と存在・否定の作用域・条件の向きを区別する。両内容が同じ真偽になるモデルでも記述は同一化されない。512通りの項目帰属と従来の対応関係について、整合条件が成立する場合の判定一致を照合する。原文への接続では、整合しない従来の関係で旧問いだけが候補を認める反例と、整合させた場合、空の一致範囲、因果条件の欠落を検査する。

有限診断では、非帰属項目の未知の記述を実行しない短絡評価を使う。全項目の記述を与えたモデルでは保存した非短絡グラフとも照合する。対象となる項目の記述が未知なら、空記述や既定の内容で補わない。標準評価器自体は変更しない。

今回の型i[f]は発話の記述であり、答えの対象型を持つg[a]等の問いは混在できない。その接続、実文献への忠実な帰属、非構文的な同義関係の説明、原文全体の意味一致は未完である。七定義を追加し、既存23文と全宣言・意味規約を保存した。原文対応範囲や意味確認済み区間数は増やさない。
