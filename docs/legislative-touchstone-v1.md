# 立法の試金石

第六段落第六文 `[1265,1436)` の144非空白文字を、同じ人民による自己賦課の可能性を立法の許容性の判定基準とする文として記述する。本文102番目の主張 `r5e4` は、この基準、問い、思案的な提示と道具への見立てを著者へ帰属する。

同じ政治的共同体の完全な人民と非空の公的法案 `r5ei` を範囲に取り、二つの可能性を比べる。一方の `r5ex` は、ある主体がその人民に法を正当に採択し得ること。もう一方の `r5es` は、同じ人民が自らに同じ法を課し得ること。いずれも同じ仮定経過の資格と採択を結び、別経過の条件を合算しない。一般の主体の資格と人民自身の資格は別入力であり、比較が定義上の恒真になることを避けている。

`r5ev` は主体・人民・共同体・法の四対象を既存 `r5el` へ束縛する。`r5ew` は同じ四対象と固定基準を持つ段階1の内容への資格を、既存 `r37c` の積極的許可と反対要求の不在で構成する。全条項の内容、採択行為、制度的な効果は [law-enactment](law-enactment-v1.md)、自己賦課の規範的可能性は [rational-self-imposition](rational-self-imposition-v1.md) の構成を保持する。

`r5e2` は全対象について両可能性の同値を述べる。ここでは「試金石」を肯否の両側を判定する基準と読むため、必要条件だけの旧 `rke` にはしない。この読みを唯一必然の形式化とはしない。[原文](https://korpora.org/kant/aa08/039.html)の一般的な問いと、続く暫定的に可能な秩序・不許可の取り決めの両側の検討を根拠とする。特定の人物に無条件で立法権を与える命題ではない。

`h26ck` は同じ全体・対象範囲・判定性質・質問箇所と質問族を結ぶ。二度の人民と同じ法律への照応は同じ三対象の束縛に保持する。`wohl` は同じ問いを思案的に差し出す `h26cl` として扱う。[AdelungのWohl](https://lexika.digitale-sammlungen.de/adelung///lemma/bsb00009134_6_2_2635)の疑問・推量を伴う用法を参考にするが、数値確率や必ず肯定されるという回答を補わない。

試金石の道具側は `r5e3`、基準への見立ては `h26cm` に分ける。[AdelungのStreichen](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_2_3_3293)が記す金属の跡から品質を調べる用法を参照した。物的な石・金属・試験の存在を本文から導かず、基準が問いに「ある」を物理的位置へ置き換えない。
