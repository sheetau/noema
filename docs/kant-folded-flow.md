# 接続線の切断による折返しと復元

元の `proof_kant_page_script_v3.paragraph_view` は文を横へ配置し、`balanced_circle_script.pack_lines` は円の組の間で直線を切断する。一行の終端が構文の終端とは限らない。この描画方法を、独立した図形復号へ接続する。

一つの流れを描いてから、すべての円の左右の範囲を調べ、円を横切らない縦の切断位置を選ぶ。切断位置には少なくとも一本の横線または斜線が通る必要がある。屈曲点・分岐点・交点そのものでは切らない。円が一つもない行を作らない。指定幅内に条件を満たす切断位置がなければ、幅不足として扱う。

折返しの両側では、切断された線の端が、その行の全円より外側にある共通の縦位置へ揃う。前行右端と次行左端の線の本数、上からの順序、傾き、相対的な高さを一致させる。これによって次行の平行移動量が決まり、元の円・線を復元できる。円の内側にある半径線の端や、大円の上下端まで延びる対角線の端は継続口にならない。

復号側は空白帯から行を分け、実際の線端から対応を読む。切断座標、行番号、要素グループ、元の構文を入力に使わない。対応する切断線がない片側だけの継続、線の本数・傾き・高さの不一致は拒否する。各流れを復元した後、通常の幾何検査と構文読取を行う。分割された線は共線区間として併合するため、円への入射・曲げ・分岐の規則を緩めない。

両端に継続口のない行の間は、完結した項目列の境界として読む。続いている行の間では、語・数値・型・引用・変数のスコープを閉じない。辞書更新は構文上の項目を読み終えてから行う。行の終端だけを根拠に未完の宣言を公開しない。

この段階では一つの流れの既存の大きさ上限を維持する。頁をまたぐ継続、本文全体の行幅・縮尺の調整、最終外観の承認は別に残る。折返し位置を見失った図形を語義の推測で補完しない。
