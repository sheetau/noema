# 部分式を読む枝の規則

`kant-public-fragment-11-expression-branches` は、従来の一語の枝に加えて、複数語からなる部分式を一本の枝に配置する試作である。円の偏心内包を禁止する訂正は維持する。新しい意味primitiveや文ごとの構文対応表は追加しない。

## 共通の読み方

主列と枝は同じ前置文法で読む。枝に割り当てる引数位置は公開された型から決める。状況引数があれば最後の状況引数、それ以外は従来の中央位置である。元の宣言順に引数を復元し、その位置で枝の式を読む。枝はちょうど一式で終わらなければならず、不足や余分な式を拒否する。

枝の読取中だけ位置カーソルと語境界の集合を切り替える。束縛環境はその引数位置の環境を引き継ぎ、引用に入れば従来どおりリセットする。型、順位付き引用、外側の束縛参照も主列と同じ構文を用いる。共有引数を二つの呼出しへ展開する `and_shared` は引き続き終端語に限り、一般部分式を複製する規則には拡張しない。

図形からは最右まで続く経路を主列として区別する。一つの核に一つの横枝を認め、横枝自体は分岐しない。入れ子の物理的な枝や複数の引数枝はまだ扱わない。本文のAST、出力順、生成器のグループ情報は復号に渡さない。

## 空白接続と円の組

枝の語境界には同じ段の主円どうしを一定の円周間隔 `MIN_GAP` で置く空白接続を使う。非接触の二円組は一つの核として扱い、小さい付属円を別の接続端点にしない。候補の空白接続を加えると閉路になる場合や、接続を一意に回収できない場合は拒否する。これらの局所的な接続をまとめた後、従来の成分端点による空白接続を読む。

この間隔は語義を表す番号ではない。復号器は接続された二核が同じ主列または枝の隣接位置にあり、後続が語または引用の入口であることも確認する。枝の後の引用は、従来の任意の空白接続では曖昧になるため、見える線でつなぐ。

## 大円を含む配置

大円の中心は中央段に保つ。後続への線は外側段を通り、障害となる円の近くを既定の45度線で迂回する。円への直角入射、曲げるまでの長さ、間隔、円から出る45度線の終端条件は緩和しない。接続候補が別の円の中心を横切る場合は候補選択時に除く。

後続へ合法な経路を作れない場合は、該当する任意の部分式枝を主列に戻して組み直す。この変更は配置だけに作用し、語、型、構文、参照先を捨てない。元の構文木の有限個の位置を除外していくため、同じ枝の再試行を繰り返さない。復号失敗や未知の入力をこの処理で隠さない。

## 確認範囲と制約

`scripts/check_kant_expression_branches.py` は語境界、引数順、引用、束縛、大円を含む独立例と、既存の40文を実SVGから復号する。語義・参照先の照合には既存の公開辞書と意味証拠を使い、原文の意味審査を反復しない。処理は文ごとのチェックポイントを持つ。変更前のSVGも再描画せずに新しい読取器で確認する。

長い枝の上を接続線が長く通る配置があり、外観は未完成である。特に元の主張55・56・57では迂回線が目立つ。合法な部分式枝を描けることを、有機的な外観の完成と扱わない。文頭反復、長い主列、入れ子枝、未対応の式構成、文書宣言・辞書・行頁の復元、未使用の許容形への意味対応が残る。利用者の外観確認前に固定しない。
