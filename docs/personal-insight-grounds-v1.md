# 本人の認識判断に基づく制度変更への同意

カントu0013第七文の「自分たちの考える、よりよい認識に従って」を、各当事者が保持する判断を、その同じ制度変更への同意の理由にすることとして構成します。判断の正しさや全員共通の基準は要求しません。この本人への相対化は[原文AA VIII:39の25–26行](https://korpora.org/kant/aa08/039.html)に基づく採用解釈です。

`r5ga` は、同じ制度領域の二つの代表認識内容を、事柄の区別・関係・根拠を適切に捉えるという基準で比較します。同じ基準による両自己比較、候補以上の比較、逆比較の不成立を結びます。別名だけや比較不能を厳密な改善にしません。具体的な内容は既存の `h26ae` によるNoema記述、比較基準は明示した解釈入力です。

`r5gb` はその認識の優越と、同じ候補認識に新制度配置が適合することを、正確な五対象列へ結びます。`r5gc` は本人が自分の比較基準と文脈上の比較元を採用し、この内容を肯定する判断を現在保持することです。客観的に優越することは評価せず、同意の時点より前に形成して保持する判断も扱います。旧制度が特定の旧理解に由来したという歴史は補いません。

`r5gd` は、前回構成した同意の本人・活動・点と、その判断を自分の理由として使う関係を結びます。別の同意や事後の説明では満たせません。`r5ge` は合意の固定した全当事者へこれを分配します。各人が異なる基準・比較元・認識内容を持っていても、同じ制度変更に合意できます。

検査では厳密な比較の16組、別名と同一内容の区別、五対象列の1,024組、同じ保持判断・基準・同意活動・時点の接続を確認します。判断内容は誤っていても本人の判断として扱えること、同意の検査で新制度の実施を要求しないことも確かめます。全当事者の検査では合意と各人の理由付き同意を境界にして接続を調べ、それぞれの構成を前回と今回の実評価で確認します。

保護・非妨害の同じ制度内容への接続、公的洞察が共同提案に足りる条件、期間・談話・全文帰属は未完です。本文102主張と登録簿v185・集計v76、確認文字数を保持します。
