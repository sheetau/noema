## 形を読む前に覚えること

現在の試作では、意味を決める辞書、文を組み立てる文法、円と線の配置規則を区別する必要がある。辞書で「雨が降る」「町」などの意味を決め、文法でその関係を指定し、最後に円の大きさ・線・枝・位置を生成する。同じ語も文の中での役割や隣の形によって姿を変える。

三本の見えない基準線を考え、円の中心をその上に置く。大円は中央段に置く。線は水平・垂直・45度に限り、円に接するときは中心を向ける。円の中へ入る線は中心で止め、直径にはしない。小円は中心へ線を入れない。円周から曲がるまでにも間隔を取り、隣の形を避けながら接続する。

ただし、現在の画像だけから単語や構文を一意に読み戻す方式は未完成である。語の識別には文ごとの辞書があり、その辞書の順番も形の選択に使っている。位置や線をすべて意味として説明することはできない。以下は付属の構文・辞書との対応を使い、実際に描かれた①・③を説明するものである。

## 通常文①「町に雨が降っている」

まず「雨が降っている」という関係に、場所「町」を一つ渡す。説明用に書けば`rain(town)`となる。Noemaの文字列では`s[k rain[k town[]]].`であり、文全体を主張として提示する。独立した主張記号は図の外枠の慣例にまとめている。

左上の中円は、一つの対象を受け取る`rain`の部分である。単項の関係には中円と半径線を使う規則により、中心から右の円周まで線が入る。雨だから上段に置く、あるいはこの半径線そのものが雨を意味する、という規則ではない。

右の中央段の中円は、対象`town`に対応する。左円の右下の円周から45度で外へ出て、間隔を取って水平に曲がり、この円の中心で止まる。これで「雨が降っている場所として町を指定する」という構文上のつながりを描く。上下の配置は、線の衝突を避け、文全体の偏りを調整する処理で決まる。

今回の町が中円・中心終端になるのは、文中の辞書番号が2であり、その番号に対してこの形を選ぶ現行規則による。「町」一般にこの形を固定したものではない。この番号に依存する部分は、学習者が語を識別できる書記規則へ整理すべき未解決点である。

## 通常文③「アキが本をナオに渡す」

この文には「渡す」という関係と、三つの対象がある。順番を`give(渡す人, 渡す物, 受け取る人)`と決めているため、内容は`give(aki, book, nao)`となる。Noemaの文字列は`s[k give[k aki[] k book[] k nao[]]].`である。

| 図の部分 | この文での意味 | その形になる規則 |
| --- | --- | --- |
| 左の大円 | 渡すという関係 | 二つ以上の対象を受け取る関係なので大円を使い、中央段に置く。最初の円なので左から中心へ導入線を入れる。 |
| 大円の右下へ分かれる先の中円 | 本、第二項 | 複数の単純な対象のうち中央の項を枝へ移す規則により、三項の第二項が枝になる。 |
| 本の右上の中円 | アキ、第一項 | 本流に残る最初の対象。今回の辞書番号2により接続線を中心で止める。 |
| 右端の中央段の中円 | ナオ、第三項 | 本流に残る次の対象。今回の辞書番号4により線は円周で止める。 |

読むときは「渡す」を見つけ、本流の第一項アキ、枝の第二項本、本流の第三項ナオを、その関係の三つの欄に戻す。図の左からの円の順だけで単語を列挙すると、先に枝の本が見えるため読み違える。枝も含めた構造を読む必要がある。

ここで「下の枝はいつでも物」「上はいつでも人」という規則を覚えてはいけない。枝になる項は構文から決まり、その上下は配置から決まる。本が中円になるのも枝の局所規則による。別の文や位置でも同じ輪郭になるとは限らない。

書く練習では、最初に関係と対象の欄を確定し、次に枝へ出す項を選び、最後に基準線・間隔・接続の規則に沿って描く。アキとナオを交換したら、第一項と第三項の意味も交換される必要がある。現在の処理系ではこの交換を構文として保持するが、画像だけからの確実な復号はまだ検証できていない。人が新しい文まで自力で読み書きするには、語の識別と枝の順序を画像から一意に復元できる規則が必要である。
