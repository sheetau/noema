# 現在と後続時代の集団、応答の範囲

カントu0015の「世界と後世」を、同じ母集団から時代ごとに選ぶ人々として記述する部分草案を追加した。集団が同じ時代に生存する人々から成ることと、その人々が実際に称賛することを分ける。時代の順序は既存の定義を再利用し、後世を直後の一世代に限定しない。

| 定義 | 内容 |
| --- | --- |
| `roj` | 現在と後続の異なる集団を、同じ母集団・所属・生存関係で、前後する二時代に結ぶ |
| `rok` | 話者の所属と行為時点を指定集団・時代へ限定した応答関数 |
| `rol` | 指定時点に、その集団の少なくとも一人が応答する |
| `rom` | 非空の集団の全員が、同じ時点に応答する |
| `ron` | 非空の集団の各人が、時代内の各自の時点に応答する |
| `hzgi` | `roj`の人間・時間順序を既存の`aa`・`ic`へ結ぶ |
| `hzgj` | 現在集団・現在時代、または後続集団・後続時代からの、同じ対象者への提示行為を記述する |

たとえば二人のうち一人が月曜、もう一人が火曜に応答すれば、各人が期間内に応答したとは言える。しかし、二人が同じ時点に応答したとは言えない。一人だけの応答は、全員の応答にも、代表権を持った集団の発言にもならない。これらの区別は称賛以外の応答にも利用できる。

現在と後続の集団には、同じ人が重なって所属してよい。時代区間は前後するが、間に別の時代や未指定の時間があってもよい。「後世」を生物学的な親子関係や全人類の一斉交代に置き換えない。時代・生存・所属の整合性は`roj`または`hzgi`で照合する。応答範囲を限定するだけの`rok`から`ron`には、この照合を暗黙に含めていない。

`hzgj`の応答記述を、既存の`ro6`へ渡せるようにした。根拠と明示基準が成立して「その応答に値する」と評価できても、現在の人々や後続の人々が実際に応答したことは要求しない。この記述は応答者を限定するもので、両集団それぞれに応答の実例があることや全員の同意を述べるものではない。検査では功績の根拠を入力関数として与え、その真偽と応答の実行を別々に変えた。原文の功績・感謝・称賛をすべて定義し終えた検査ではない。

[一般形](../examples/v014/cohort-responses.noema)は2,355文字、[原文付き文書](../examples/v014/kant-cohort-responses.noema)は198,006文字、[抽出文書](../examples/v014/cohort-responses-core.noema)は3,779文字である。七定義を追加し、原始記号と著者主張は増やしていない。親の宣言と15件の著者主張を保持した。[意味規約](../data/kant-cohort-responses-basis-v1.json)と[検査記録](../reports/cohort-responses-v1.json)を保存する。

所属と時点ごとの応答の64通りを、量化の順序を別途計算した結果と照合した。三文書で集団・時代の12条件ずつ、原文付き文書と抽出文書で応答・評価の八条件ずつも検査した。追加23テストは、空集団、外部者、時代の重なり、所属と生存の不一致、時間をまたぐ構成員、対象者・発話・受け手の保持、値することと実行の独立性、引用、未確定入力の扱い、歴史の保存を対象とする。三文書のCLI解析、正規形・固有文字v2の往復、SVGのXML検査が通過した。SVGの目視確認は含めない。

有限解釈器は条件の両辺を評価するため、所属しない人や範囲外の状況の関数値も要求する場合がある。未知の値を偽で補って意味の成立を判定しない。現在の集団を世界全体とみなす母集団の網羅性、無限の後世、感謝と称賛の意味、集団の代表権・共同意思、功績と適合基準の正当化、原文全体の意味一致は未完である。
