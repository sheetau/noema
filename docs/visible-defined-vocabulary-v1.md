# 構成定義を持つ共有語の円文字

この文書は旧字体の検討記録です。旧試作の生成物は整理しました。現行の仕様・本文・証拠は[Noema 1.0](language-edition-v1.md)を参照してください。

## 基本関係と共有定義

共有辞書第1版の16語の形・型・意味を保ち、第2版へ[候補評価と能力の14定義](shared-modality-v1.md)を追加する。新しい語も一つの公開語形を持つが、意味は既存概念から構成した定義である。図形が一つであることを、説明できない基本関係であることと同一視しない。

字形は[公開対応表](../noema/resources/visible-defined-vocabulary-v1.json)に名前とともに固定する。辞書の登録順、文書内での出現順、名前のハッシュから形を生成しない。旧語形は変更せず、追加語の型・役割・成立条件は共通モジュールの公開規約へ結び付ける。語の形だけから正確な意味を推測する規則ではない。

## 導入と依存関係

文書ヘッダーにはNative Noema 0.16と共有辞書第2版を明記する。共有語の導入標識とその語形を読むと、辞書の宣言を導入する。辞書が基本関係として登録した語は基本関係、構成定義として登録した語は定義として復元する。辞書の定義本体を文書専用の外部データから取らない。これは学習する共有語彙であり、公開された内容はすべての文書で同じである。

定義が別の共有語を参照する場合、その依存先も先に可視の導入を記す。復号時に足りない宣言を暗黙に補わない。文書独自の新語は従来どおり複合名・固有名とし、型と定義本体を文書内に書く。共有語の本体を変更したり、共有定義を基本関係に置き換えたりする入力は拒否する。

導入した定義は、関数呼出し、関数参照、引用、文書独自の定義の中で使える。共有するのは語の規約であり、文書ごとの評価状況や候補範囲ではない。方法の実行可能性や評価基準などの引数を、辞書が自動的に与えることはない。

## 互換性と残る範囲

辞書の版は見えるヘッダーから選び、第1版の文書は第1版の規則で読む。未知の版を第2版と推測しない。第1版の語が第2版の辞書にある場合も、形と型だけでなく既存の意味規約を保存する。

共有語の追加は、定義が参照する語の意味を変えない範囲で行う。定義本体が同じでも、依存する基本関係の意味が変われば同じ語義の拡張とは扱わない。単独語形の組合せには限りがあり、今後の語彙すべてに別の基本図形を要求しない。複合名と型付き定義による命名を引き続き使う。

今回の14語は候補評価と能力に関する範囲である。他の意味領域、二論文の全文の円文字化、人による読解試験まで完了したとはしない。

## 利用と検証

[候補の評価例](../examples/v016/visible-shared-library-v1.noema)を円文字へ書き、同じ公開名へ戻す。

```powershell
python -X utf8 -m scripts.visible_library render examples/v016/visible-shared-library-v1.noema output/visible-library-v1/candidates.svg --width 3000 --public-names
python -X utf8 -m scripts.visible_library decode output/visible-library-v1/candidates.svg --native --public-names
```

検証記録（旧試作・整理済み）は、辞書導入だけの文書、候補評価、能力評価の三文書について、円と線から復元した構文と評価結果を記録する。候補と能力の例には、空の候補、実行不能な方法、成功の保証、評価材料の不足を含む。有限モデルでの八主張の評価であり、語義の網羅的な証明ではない。

`tests/test_visible_library.py` の28検査は、全14語の呼出し・関数参照・引用、文書独自の複合語の定義、辞書登録順の不変性、既存語義と定義本体の保存、依存漏れ・循環・未知の版の拒否、第1版との互換性、コマンドによる往復を確認する。語形一覧（旧試作・整理済み）は学習用のラベル付き画像であり、復号へ渡す文書ではない。

処理量の上限は従来の可視書式を引き継ぎ、本文768字形、全体4096図形、展開後8192構文ノード、128行までとする。大きな原稿を一つの画像として処理できるという意味ではない。
