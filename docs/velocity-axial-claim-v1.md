# 速度式の対称性と同じ軸方向の場合

原刊906頁のu0141–u0142を対象とする。必要な関係は、同じ速度式の二入力の対称性、その性質への注目価値の評価、wも既存の正の縦軸方向に進む条件、その場合に次の表示式を得るという提示である。既存の対称性s3a/s3b、評価s2z、正方向s3i、符号付き商s3g/s3jを再利用する。

ejplは直前に取得した同じ三量ejpaと、同じV・角を固定したs3bを結ぶ。交換するのは式の非負の数値入力であり、Kとk、系速度と点速度という物理的な役割ではない。対称性の記述をejpmの評価対象とし、別の式や結論の真理を「注目すべき」の代用にしない。注目価値の尺度と基準は文脈に依存し、数値や読者の実際の反応を原文へ加えない。

第二文のRichtungは、既存の読みを引き継いで正方向への非零運動とする。ejppは同じ運動・軸・現在の三量を保持し、点速度の横成分が零、縦成分が正の速さwと等しいことを要求する。ejpaのejowは系速度vの正方向を既に保持するため、auchもこの同方向性へ結び付く。XとΞは同じK/kの対応した縦軸である。反対向きも許す「軸に沿う」という別の読みや、零ベクトルに方向を与える読みは採らない。

ejpqは同じU、v、w、VをU=(v+w)/(1+vw/V²)へ渡す。s3g自体は符号付き入力と結果を許し、正のVと非零分母を要求する。式単独が零入力で定義できることと、幾何学的な方向の条件は別である。点の光速上限は後続文で扱い、ここへ追加しない。ejprは条件内容、ejps/ejpuは著者がその前提から式を得ると提示したことを表す。条件の含意が真でも前提が実際に成立したとは限らない。

原刊の第一文の句点、第二文の括弧付き軸名とコロン、表示式の分子・外側の分母・V²による内側の除算・句点を照合した。第一文の評価から条件付き提示、表示式まで同じ著者・第五節の流れを保つ。

検査は数式と方向の本体、三量への接続、評価対象と文脈、帰属の引数を区別して行う。全実数量化は有限標本で済ませず、ネイティブ評価の列挙拒否を確認する。多項式証拠の既存報告を保存し、有限例と普遍的な物理導出、原文の通読による意味判断を混同しない。旧文136–138を更新し、他の353主張と旧証拠を保存する。
