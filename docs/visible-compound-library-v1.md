# 共有複合語を持つ円文字辞書第3版

## 追加する語と綴り

辞書第2版の30語の形・型・意味・定義を保存し、時間14語、指示・前提22語、省略補完・読み14語を共有複合語として追加する。単独語形や基本関係は増やさない。[公開綴り表](../noema/resources/visible-compound-vocabulary-v1.json)で各語の部品列を固定し、[時間](shared-time-v1.md)・[指示と前提](shared-reference-v1.md)・[読み](shared-readings-v1.md)の共通定義へ結び付ける。

複合語は従来の入口、2〜3個の既知語、終端で書く。入口と終端を含むまとまりが一語であり、部品の語を別々に呼び出す式ではない。たとえば時間の前後を表す二語では、基準となる部品を前後に置き分ける。綴りは公開の命名規約であって、部品の意味から新語の正確な定義を自動推論する規則ではない。既存の部品語を時間や指示だけの意味へ変更しない。

綴り表の順番、文書内の出現順、番号、名前のハッシュから字形を生成しない。登録順を変えても同じ語は同じ部品列で書く。別の複合名を作る機能も残し、未知の組合せは文書内で型と本体を定義する。

## 共有語の導入と定義の保存

文書の可視ヘッダーに辞書第3版を記す。導入標識に続く名前が公開された単独語または共有複合語なら、その辞書にある宣言を導入する。導入する定義が参照する他の語も、先に明示的に導入する。綴りに使った部品だけを理由に、その部品の関数を文書へ暗黙導入しない。

共有複合語の意味は、すべての文書で同じ公開定義である。文書ごとの外部ASTや番号表を復号器へ渡す方式ではない。共有定義を基本関係へ置き換えたり、本体や依存先の意味を変更したりする入力は拒否する。共有名を文書内の別定義で上書きすることも許さない。文書独自の定義には未登録の複合名または固有名を使う。

呼出し・関数参照・引用には、導入と同じ複合名を使う。複合名の呼出しは既存の明示的な呼出し標識と引数の終端を保つ。定義が返す内容・関数・発話・記述・列の型も共通モジュールと同じである。

## 版と検証範囲

新しい復号入口はヘッダーから第1・第2・第3版を区別する。旧版の複合名が第3版の共有名と偶然一致しても、旧版を読み替えない。版の変更で名前が衝突する場合は、自動的に上書きせず、衝突を解消する明示的な編集が必要である。

50定義の導入・呼出し・引用した関数参照は、各語についてSVGの円・線から復号する。型付きの呼出しを同じ呼出しと比較する式を使うため、これは構文と型・参照の検査であり、高階の引数領域全体を評価した証明ではない。公開辞書の登録順の不変性、依存漏れ・衝突・改変の拒否も検査する。

80語すべての導入を含む辞書ページと、時間・前提・未決定の読みの三つの例文ページは、改行を含むSVGからNative文書へ復号する。例文の4主張は二個体・二状況の有限モデルで真となる。時間の例は途中で成立し、まだ完了していない出来事、前提の例は一意に指示できる対象についての否定、読みの例は二種類の候補と列挙未完の一候補を扱う。各語の意味検査は元の共通モジュールの証拠を保持し、今回の復号成功で代替しない。

形状・字形・展開後の構文・行数の資源制限は従来どおりである。50語を使えることから、二論文の全宣言や全本文を一画像へ収められるとはしない。二作品の固定ページと既存の意味判断は保存する。

## 出力と再現

[検査報告](../reports/visible-compound-library-v1.json)は、語ごとの字形数・図形数・依存導入数と、辞書・例文ページの復号結果を記録する。[時間のNative例文](../examples/v016/visible-common-vocabulary-v1.noema)は、公開語名で編集して円文字へ変換できる。

```powershell
python -X utf8 -m scripts.visible_public_page render examples/v016/visible-common-vocabulary-v1.noema output/visible-compound-library-v1/time.svg --width 3200 --public-names
python -X utf8 -m scripts.visible_public_page decode output/visible-compound-library-v1/time.svg --native --public-names
python -X utf8 -m scripts.project_work check --module scripts.check_visible_compound_library --tests tests/test_visible_compound_library.py --prepare --verify reports/visible-compound-library-v1.json
```

`--prepare` は `output/visible-compound-library-v1/` に4枚のSVGと、10語ずつの語形一覧 `compound-forms-1.png` 〜 `compound-forms-5.png` を作る。PNGの英語ラベルは語形を調べるための索引で、復号器へ渡す意味情報ではない。人が画像だけから意味を復元する読解試験と、ラスター画像のOCRは未実施である。
