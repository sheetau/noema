# 閉じた伝播内容の記述と、著者への帰属

任用・独立判断・自己離脱・周囲への伝播を結んだ条件から、引数を充足した一つの内容記述を作れるようにした。著者への帰属は、その内容が真かを調べる操作と分ける。

## 人と評価機会を保つ内容

`hzoo`は、同じ人・同じ評価機会に対応する参照文脈、話題、発話、期間枠、基準時、自己離脱の過程と前後点を取り出し、既存の`hzol`へ渡す。受け手ごとの伝達経路と取得過程にも、その同じ人と機会を渡す。人物や機会が違えば別の行為・経路を使えるが、他人の発信を本人の発信として流用しない。

`hzop`は、この複合条件を、任用された人々を選ぶ`hzoj`へ結ぶ。内容の評価点より後の全機会について、任用・独立判断・自己離脱・伝播を満たす異なる二人を要求する。機会ごとに人物が交替してよい。伝達する性向の記述は共通に保つ。

個々の離脱・伝播の基準時は、本人と機会を受け取る関数で指定する。全将来機会を区切る内容の評価点、個々の過程を評価する基準時、著者へ帰属する文脈は別の役割であり、暗黙に同じ時点へ置き換えない。

## 引数を充足した引用

`hzoq`は、`hzop`の関数記述へ33個の引数を構成的に適用し、閉じた内容記述を作る。履歴・任用・範囲・評価基準や、各人の行為を与える関数は、閉じたNoema式として指定する。共通の性向記述は、既存の`o r`で値として持ち上げて渡す。構築時に、その性向や伝播の真偽を調べない。

結果は関数ひな形そのものの引用ではなく、全引数を適用した内容の引用である。ただし、構文的に閉じていることは、その記号の解釈が既知であることや、原文への適合を保証しない。引数が一つ欠けた構成や、未確定の原文解釈を完成した命題の読解と呼ぶことはできない。

伝播の内部では階数0の性向記述を評価するため、その全体の引用には階数1が必要になる。階数0に縮めた引用は構文検査で拒否される。既存の主張帰属`uc`は階数0の内容記述を受けるため、その型を変更せず、同じ主張帰属の意味を階数1の内容へ与える`hzon`を追加した。高い記述を低い型に押し込む変換や、別記述の自動的な同義判定は行わない。

`hzor`は、`hzoq`が作った同じ内容を、指定された箇所・著者・帰属文脈へ結ぶ。帰属を評価するだけなら、世界の事実を知らなくてもよい。内容を後から明示的に評価する場合には、その解釈が必要になる。

## 検証と原文への接続の限界

5テストで、次を確認する。

- 世界の事実を全て未知にしたまま、帰属の肯否を評価できる。箇所・著者・帰属文脈の取り違えを拒否し、異なる性向記述を区別する。
- 帰属が真で内容が偽、帰属が偽で内容が真という場合も含む四組合せを評価する。片方の人の経路の流用、片方だけの周囲、任用の欠落、独立判断する人の不足を対照にする。
- 13種類の供給関数が、同じ本人・機会・受け手を受け取る。人物ごとに別の経路を持てることを具体例でも調べる。
- 低すぎる引用階数と、帰属関係への異なる階数の入力を拒否する。未知の帰属を偽にせず、帰属が既知でも未知の内容を真に補わない。
- 通常・短縮・固有文字の往復、既存の全意味規約・32文・七単位の確認を保持する。

具体的な本人の複合条件は、保存された定義を通常評価で実行する。引用した全将来機会の内容は短絡診断で実行し、任用・判断・自己離脱・相対範囲への伝播の定義を、別の真偽関数へ置き換えない。有限の評価窓の例であり、無期限の将来の実証ではない。短絡診断は未使用の枝の未知入力を省く場合があるため、帰属自体とその未知入力は通常評価でも検査する。

四つの合成定義と、一つの高い階数に対応する帰属関係を追加した。累積本文への追加は2,986文字。カントu0011の既存範囲137–176、184–217、422–440を結ぶ構成候補として記録し、原文対応率は増やさない。
