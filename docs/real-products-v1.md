# 実数の積・除算・平方根とアインシュタインの係数

[実数の切断](real-cuts-v1.md)へ13定義を追加し、符号付きの積、非零の逆数、除算、非負平方根を記述した。[Noema文書](../examples/v011/real-products.noema)は既存の0.11文法で解析でき、新しい演算子やモデルを必要としない。4つの有理数の基本演算と22定義からなる。

アインシュタイン原文のu0084、数式M0136にある`β = 1/√(1−(v/V)²)`を、これらの定義で構成した。ただし、物理量・基準系・単位、周囲の変換式との接続は未完成であり、原文単位の完成とは数えない。原文のβを、別の文献で速度比に使われる同じ記号と混同しない。

## 定義域と結果を区別する

切断は有理数から真偽への関数`h[b] c`である。実数rに対応する切断には、rより小さい有理数を含め、r自体は含めない。妥当な切断の条件baは、非空・真部分集合・下方閉・最大元なしである。関数型の全ての値が実数を表すわけではない。

| 定義 | 役割 |
| --- | --- |
| ca / cb | 非負判定／絶対値の構成式 |
| cc / cd | 非負の積／符号付きの積の構成式 |
| ce | 入力と結果の切断条件を含む乗算関係 |
| cf / cg | 正数の逆数／符号付き逆数の構成式 |
| ch / ci | 非零条件と切断条件を含む逆数／除算関係 |
| cj | 非負平方根の候補の構成式 |
| ck | 非負条件と切断条件を含む平方根関係 |
| cl | 切断を使った原文βの関係 |
| cm | βを有理数の多項式条件で検査する補助関係 |

言語の関数は全域関数なので、内部の構成式は型に合う入力なら関数値を返す。その値を演算結果として認めるための条件をce・ch・ci・ckに置く。例えば負数へcjを適用して得られる性質を、その数の平方根とは解釈しない。ckは非負条件を要求するため、その入力に対応する結果はない。chとciも分母零を除外する。未定義な演算に0を割り当てる規約ではない。

切断から実数を構成する背景は、McMullenの講義ノートの実数の構成を参照した。同資料は境界を下側へ含める規約であり、ここで採用した「最大元のない下側」の規約とは異なるため、式をそのまま転記していない。[Real Analysis, pp. 7–8](https://people.math.harvard.edu/~ctm/papers/home/text/class/harvard/114/course/course.pdf)

## 構成式の数学的な理由

非負の二切断L・Rの積ccには、負の有理数を全て含める。非負のqについては、Lに属する正のx、Rに属する正のyで`q < x*y`となるものがあるとき含める。どちらかが0なら正の要素を持たず、結果は0の切断になる。両方が正なら、その実数の値へ下から近付く有理数x・yの積も積の値へ近付く。符号付きの積cdは絶対値でこれを行い、符号が異なるときに既存の符号反転beを適用する。

有理数a,bの積への近似では、正のgapをa,bより小さくし、`gap*(a+b) < a*b−q`と選べば、`q < (a−gap)*(b−gap)`となる。この不等式を全有理数について補助検証した。正の上限より小さい有理数gapを選べることと、切断の上限へ有理数で近付けることを用いる数学的説明であり、切断上の一般定理を検査器が全て証明したという意味ではない。

正の切断Lの逆数cfは、負のqに加えて、Lの外にある正の上側値uで`q*u < 1`となるqを含める。uは元の数以上なので、これによって逆数未満のqを表せる。逆数より小さいqに対しては、元の数に十分近い有理数の上側値を選べる。厳密な不等号を使い、逆数自身を含めない。負数には符号反転を組み合わせる。

非負切断Lの平方根候補cjは、`q < 0`または`q*q`がLに入る場合にqを含める。従って0の平方根は0となり、4の平方根の切断には2を含めない。qが非負でその二乗が切断に入る場合、さらに大きな有理数rも切断から選べる。`gap = (r−q²)/(2*(q+r+1))`は正の有理数で、`(q+gap)² < r`となる。この不等式も補助検証し、最大元が生じない理由に使った。

これらの構成が全ての有効な切断で実数体の演算となること、四則の一般法則、clとcmの同値性の機械的証明は未完である。説明上の数学的理由と、実際に検査器を通った式を分けて記録する。

## βの記述

cl(speed,light,factor)は、入力と結果が有効な切断、lightが正、speedの絶対値がlight未満であることを条件にする。その上で、ratio・rootという切断があり、次を満たすことを述べる。

1. ratioはspeed/lightの結果である。
2. rootは`1−ratio*ratio`の非負平方根である。
3. factorはrootの逆数である。

正の光速度に対する有限実数として式を読むための定義域であり、この条件を原文が同じ箇所で別の命題として主張したと扱わない。平方根の非負枝と逆数の非零条件を保持した。[原文対応表](../data/einstein-beta-v1.json)では元の数式のMathMLハッシュを照合する。

有理数のspeed,light,factorに対する補助条件cmは、正のlight、`speed² < light²`、正のfactor、`factor²*(light²−speed²)=light²`を要求する。この多項式条件について、正の解の唯一性、速度の符号によらないこと、factorが1以上であること、速度0でfactor=1となることを検証した。`speed/light=±3/5`なら`factor=5/4`が成立し、負の枝や逆数を取り違えた4/5は成立しない。

これは実数の全域を有理数で置き換える規約ではない。例えば速度比1/2の係数は有理数ではなく、cmに有理数の解がないことはclにも実数の解がないという意味にはならない。

## 非線形検証で有理数と実数を混同しない

追加した補助検査器は、先頭に有理数の全称量化だけを持ち、定義展開後の本体が量化なしの多項式・論理式となる主張に限定する。実数上でも反例がない場合は、有理数上でも反例がないと判定できる。実数上の反例が見つかった場合は、その値が全て有理数であり、厳密に代入すると式が偽になることを確認した場合だけ、有理数の反例と認める。

例えば「全有理数xについてx²≠2」は、実数では反例があるが有理数では正しい。検査器はこの場合に偽とせず、未判定を返す。非線形の存在量化や、全称・存在が混じる式を、実数へ置き換えて判定することもしない。Z3の有理数値と代数的実数値の区別を利用する。[Z3 API](https://z3prover.github.io/api/html/namespacez3py.html)
