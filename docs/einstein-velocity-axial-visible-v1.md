# 対称性・注目価値・同方向の速度合成の円文字接続

第5節のu0141–u0142を、一般の速度合成式に続く一群として接続する。現行稿の主張5、6、7を原文順に選ぶ。既存の17定義を再利用し、対称性、その性質への著者の評価、同方向の運動という条件から式を得る提示を区別する。原稿と採用済みの意味判断は保持する。

共通基盤375語と固定アルファベットを使う。任意プロファイル64では、既存の「内容に注意を向ける価値」と「文脈上の注目基準」の2規約を公開する。価値と基準を同じ内容・文脈へ結び、内容の真理値、驚きの強さ、計算の負担とは区別する。著者の評価を全読者共通の反応にせず、原文にない数値閾値を固定しない。

原刊906頁の第65段落を、対称性と評価を述べる18トークンの文、および方向条件・コロン・表示式を含む12トークンの文として参照する。M0258–M0263の各式を保持し、M0263には転記訂正を加えない。先行する第64段落の一般式と、ここでの同方向の式を混同しない。

対称性は、光速と角度を固定したときの非負の数値入力二つの交換である。二つの座標系や観測上の役割を交換する主張にはしない。Richtungには、既存の「正方向への非零運動」という明示した読みを保持し、逆方向と停止を除く。符号付きの一次元合成式そのものは零や負の入力も扱うが、光速の正値と分母が零でない条件を残す。後続区間の速度上限を先取りしない。

検証では復号された定義へ識別用モデルを接続し、三つの全称変数の束縛、引用内容と評価文脈、方向と符号付きの式、著者への帰属と導出の真理を確認する。旧ejprの条件内容は選択された本文の一部ではなく、偽の前提からの含意を区別する診断用比較式としてのみ保持する。その前提・帰結には復号された定義を使う。有限の診断を全実数領域での証明とは扱わない。

実行状態と残作業の正本はプロジェクト台帳に置く。
