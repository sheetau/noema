# 評価場面における独立した判断

カント第四段落の「自分で考える人」を表すには、一度だけ独立した判断を行ったことと、その人の判断の仕方を区別する必要がある。前段の`hzhc`は一つの実際の判断を要求する。今回、明示した評価場面での応答をまとめる別の構成を追加した。

六つの合成定義を加え、原始記号は増やしていない。[累積本文](../examples/v014/kant-independent-profiles.noema)の既存15主張と全宣言を保持した。性向の唯一の定義を完成させたとはせず、評価範囲と基準を明示した読解候補として扱う。

## 一回の実行と応答のプロフィール

`rqa`は、指定範囲を非空・重複なし・過不足なしで列挙し、全場面が評価済みで、それぞれに正の重みがあることを要求する。既存の`rd5`でこの条件を確認する。応答が成立する重みの合計を全重みと比較し、指定した閾値以上かを判定する。閾値は0より大きく1以下であり、例外を許す場合と全場面で成立する場合を区別できる。

三つの等しい重みの場面で閾値が2/3なら、二場面での成立で条件を満たす。一場面だけの成功や、未評価の残り二場面からは認めない。失敗した場面を一覧から外す、成功した場面を重複させる、失敗の重みを0にする入力も拒否する。2/3を「自分で考える人」の固定した語義にはしていない。

`rqb`は、範囲・評価済み条件・重み・閾値・応答を同じ本人と基準状況へ結ぶ。別人の緩い閾値や、別時点で選んだ容易な場面へ取り替えない。場面の並べ替えと重み全体の正の比例変更では結果を保つ。

範囲・話題・重み・閾値は結果を見る前に選ぶ解釈条件である。範囲を明示的に一場面へ狭めること自体は記述できるが、その結果から広い性向を推論する規則はない。有限の試験結果を未知の場面や生涯へ一般化しない。この機構は、例えば機器が明示した試験条件にどう応答するかの記述にも使える。

## 同じ話題と同じ人への接続

`hzhg`は、同じ人に指定話題が提示され、その人が自分の理解力と理由を用いて独立した判断`h5c`を行い、その判断が同じ話題について述べることを要求する。別の話題について考えたことや、他人が判断したことでは満たさない。

`hzhh`はこれを同じ本人・基準状況の評価場面へ接続する。場面は仮定した状況でもよい。基準状況の現在に実際の判断がなくても、指定場面の応答条件を満たすことはある。反対に、現在一回判断した人でも、指定場面では条件を満たさないことがある。考えたいという態度、実行済みの出来事、場面ごとの応答を別々に記述する。

`hzhi`は、同じ母集団で、任用された現在の役割`hzhb`とこのプロフィールを持つ異なる二人がいることを表す。役職者と判断者を別人に分けない。`hzhj`は、基準より後の非空の範囲の各状況でこの存在条件を要求する。状況ごとに人物は交替してよいが、各人のプロフィールの基準もその状況に結ぶ。

## 検証と残る課題

評価済み条件と応答の128組合せ、閾値の境界、不完全な列挙、重複、重みの不正値、並べ替え・比例変更を検査する。原文側では、現在の一回の判断とプロフィールの両方向の区別、話題・本人・基準の取り違え、任用された人との共有、将来の人物交替、後の時点だけプロフィールを失う例を確認する。

結合検査では既存の任用条件`hzhb`と判断条件`h5c`に明示的な解釈を与え、六つの新定義は全て実行する。判断の所有者・理由・支持・他者の指導は、前段の実際の`h5c`・`rcr`を実行する7例でも確認する。任用条件の直接検査は固定した[前段の記録](../reports/appointed-thinkers-v1.json)へ参照を残す。

有限診断には既存の短絡評価を使い、保存するNoema本文は書き換えない。一般条件の肯定例・否定例と本人のプロフィールは、短絡変換なし・キャッシュなしでも一致を確認する。未知の評価と未知の判断は、通常の不成立へ置き換えず拒否する。
