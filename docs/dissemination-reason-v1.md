# 公衆の自己啓蒙についての理由提示

カント原刊483頁を目視で照合し、自己思考者による伝播の記述を、直前の公衆の自己啓蒙についての判断へ理由として結ぶ一文をNoema本文へ追加した。既存の32文を保った33文目である。本文中で先に結論側を述べ、その後に `Denn` で理由を提示する順序も記述した。[原刊画像](https://api.digitale-sammlungen.de/iiif/image/v2/bsb10926843_00523/full/full/0/default.jpg)、[翻刻](https://de.wikisource.org/w/index.php?title=Beantwortung_der_Frage:_Was_ist_Aufkl%C3%A4rung%3F&oldid=3778353)を参照した。

結論側は、公衆の自己啓蒙の可能性と、自由を残す場合のほぼ不可避性を述べる先頭文全体とする。根拠側は、それに続く自己思考者・後見役・自立・価値評価・伝播の文とする。この範囲選択は採用した読みに基づく。後の文が前の文の各下位節を独立に証明するとまでは要求しない。

`hzp4` と `hzp5` は二つの文章箇所、`hzp3` はこの段落の提示文脈を指す局所参照である。箇所の参照は内容そのものの代わりにはならない。これまでの内容構成を同じ箇所へ結ぶ作業は残る。提示文脈を現実の将来時点や、自由を仮定した状況内の時点と同一視しない。

追加した `hzp6` は既存の `ud` を使い、同じ著者が `hzp5` を `hzp4` の根拠として提示すると述べる。根拠側の集合はその箇所だけを選ぶ。`ue` で結論箇所が本文上で先にあることを述べ、二箇所が異なることも確認する。新しい意味関係は増やさず、局所参照三つと合成定義一つを追加した。累積文書への追加は186文字、依存する宣言を含む単独の文書は236文字である。

この記述は、根拠の内容や結論の内容が真であることを要求しない。推論の妥当性、説明の十分性、出来事の因果関係、現実に自由があることも要求しない。著者が何を理由として提示したかを表す文である。

原文の読解では、伝播の予測を直前の自由を残す場合の議論につなぐ読みを次の内容接続に採用する。`immer` の機会範囲や `sogar` の比較範囲も明示し、無限の物理時間や数値確率を補わない。これらは[読解記録](../data/dissemination-reason-reading-v1.json)に、今回実装した関係と今後の接続条件を分けて保存した。画像照合だけで唯一の意味解釈が証明されたとは扱わない。

四項目の検査では、著者、提示文脈、根拠と結論の向き、余計な根拠、同一箇所への混同、本文順序と出来事の時間の混同を九対照で区別する。未知の理由関係・本文順序は補完しない。内容の真偽・推論の妥当性・現実の自由を変えた16組合せでも、同じ理由提示が成立する。全ての内容関係が未知の累積文書でも、新しい一文を通常評価できる。

原文の二文への参照位置、原刊画像のハッシュ、通常・短縮・固有文字の往復、既存の宣言・意味規約・32文・七単位の確認も検査する。画像照合はアシスタントによる判断であり、独立した人間の査読ではない。二文の位置を指定したことを、その全文を表現できた証拠にはしない。原文対応範囲に加えるのは `Denn` の四文字だけで、段落全体の意味確認は増やさない。
