# 数量の比較条件と排除

「少数」という人数条件に、数量についての比較条件を明示して排除する構成を追加した。実際の人数や、誰を数えるかは先行版のまま保持する。「予想より少なかった」という驚きや、知的活動についての譲歩を、数量の排除条件へ自動的に加えない。

焦点を比較対象と結び付ける設計には、[Mats Rooth, Alternative Semantics](https://compling.cis.cornell.edu/mr249/papers/rooth-2016-alternative.pdf)の代替意味論を参考にした。同論は焦点の位置・範囲と代替対象を区別する。ここでの有限な人数領域による排除はNoemaの実装上の構成であり、この資料がカントの当該箇所の唯一の読みを保証するものではない。

## 従う条件まで排除しない

ある数量条件が成立するとき、それから従う弱い条件や同値な条件も成立する。例えば、該当者が少なくとも一人いる少数者なら、「少なくとも一人いる」も真である。比較条件を全て無条件に偽とすると、このような場合に矛盾してしまう。

一般構成 `rcy` は、指定した人数領域の全要素について、選んだ条件から比較条件が従うかを検査する。`rcz` は実際の人数が領域内で選んだ条件を満たすことを要求し、従わない比較条件だけを実際の人数で排除する。比較条件の列が空の場合は成立しない。

この判定は、比較条件の文脈的な適切さを保証しない。比較条件が全て弱い条件だけなら追加の排除効果はなく、どの人数でも偽になる条件を混ぜても、それだけで不適切とは判定できない。比較条件を選ぶ根拠は別途必要である。

## 実測値だけで条件の強弱を決めない

実際の該当者が1人でも、母集団が2人なら、「1人または2人」と「ちょうど1人」は異なる。実測した1だけを比較領域にすると、両条件を同値だと扱ってしまう。

`rcx` は対象列の長さNから、取り得る人数0,1,...,Nの全てを生成する。初期列は0だけであり、対象を一つ読むごとに現在の人数列の長さを追加する。原文接続ではこの全領域を `rcy`・`rcz` に渡し、実測値だけを使う判定を避ける。対象列の重複や対象範囲の完全性は、先行する人数条件が別に検査する。

0からNまでを対象にするため、この検証で人数以外の一般の有理数全域を有限個の値へ置き換えることはない。一方、任意の列長に対する生成規則の帰納証明を機械的に完了したものではない。

## 原文の数量部分への接続

`h5v` は、母集団の全人数と基準文脈に対応する比較条件の列である。各要素は人数を受けて真偽を返すNoemaの述語であり、対訳語や固定の人数辞書ではない。対象者・達成の性質・時点を取り替える関数も受け取らない。期待する比較状況を与える既存の `ke` とは型も役割も異なる。

`h5w` は実際の人数条件 `h5o` を保持する。その同じ母集団・数える性質 `h5k`・文脈・上限 `h4h` を固定し、正の人数で上限未満という条件に対して `h5v` の各比較条件を調べる。原文に具体的な人数の上限や比較条件の一覧が書かれているとは主張しない。

`h5x` は数量の排除と既存の譲歩 `h5p` を共に持つ内容、`h5y` はそれを満たす完全な対象列の存在を述べる結論候補である。著者への帰属は `h5z` に更新し、同じ結論箇所・根拠集合・本文順序を保持した。旧 `h5u` の本文主張を置き換え、旧定義と旧版の文書は残している。

## 検証と限界

- 対象数0・1・2・5・16について、人数の列が0から全人数までを欠けなく含むことを検査する。
- 3つの人数での数量条件・比較条件の全真偽と実際の人数の192組を検査する。
- 弱い条件、同値条件、一部が重なる条件、不完全な人数領域、領域外の実測値、空・重複・恒偽の比較条件を区別する。
- 原文接続の8例では、同じ実際の人数条件を保って、比較条件とその文脈・母集団人数への結び付けだけを変える。数量の検査が期待候補 `ke` を実行しないことも確認する。
- 実際の人数では比較条件を評価できても、別の取り得る人数で未評価なら判定を拒否する。
- 帰属の6例では、新しい引用内容、結論箇所、著者、根拠集合、順序を区別し、人数や比較条件を実行しない。

比較条件の適切さ、上限の文脈的根拠、前提と断言の区分、存在含意、焦点位置・韻律、`nur` の評価的意味、`Daher` の根拠範囲と原文との意味一致は未完である。今回の変更は既存の原文範囲を具体化したもので、部分対応文字数や意味一致確認済み区間数は増やしていない。
