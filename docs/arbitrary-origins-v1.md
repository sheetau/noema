# 任意の出発点と、全空間への成立範囲の拡張

アインシュタイン§3の `u0058` を部分記述した。原点の代わりに他の点から光を出すことも選べたという内容と、そのため微分形の式が全てのx′,y,zに成り立つという著者の推論を分けて保存する。

`ski` は、同じτ候補の空間三引数を平行移動する関数である。移した原点からの座標を `(dx,dy,dz)` とすると、`τ(x₀+dx,y₀+dy,z₀+dz,t)` を返す。時刻や尺度、関数値に補正を加えない。`skk` がこの関数を前段の近傍全体の中点条件へ渡す。

`skl` は指定された位置と同じ時刻で、近傍半径と二つの偏微分値の存在を要求する。その位置での中点条件、元のτ候補の二変数の全微分可能性、x′とtの各偏微分を結ぶ。`skm` はその位置での偏微分値が整理後の式を満たす条件であり、`skn` が全ての実数のx′,y,zについて要求する。偏微分値は各位置で存在量化するため、原点の値を全空間の定数として扱わない。時刻は前段と同じパラメータに保つ。

出発点の選択可能性は `skj` で表す。主体がその設定で選べる試行があり、その同じ試行の可能な結果の一つで、指定地点についての成功条件が成り立つという構成である。地点ごとに異なる試行や結果を選んでよく、一つの試行で全地点を扱う必要はない。成功しない結果も可能である場合に、成功の可能性まで否定することはしない。実際の実行も含意しない。

`sko` は地点の履歴を静止系の時刻へ結び、x-vt・y・zが指定された値であることを確認する。`skp` はその地点から同じ地点へ戻る光往復で、原点への一致を要求しない。光路の支持線はX軸に平行であればよく、軸そのものと一致する必要はない。往路と復路の進行方向の正負は限定しない。同じ光、三出来事、二時計、同期、局所時刻、配備と静止は保持する。

`skq` は同じ試行の三出来事の静止系座標からτの引数を作り、運動系の時計の三つの読みへ結ぶ。`skr` は別の設定でも同じ速度・光速度の条件を保ち、同じ地点の同じ補助座標と時刻で試行と局所前提が成立することを要求する。`sks` がその地点での可能な選択、`skt` が全空間座標での可能な選択を表す。

この成功条件には、前段で補った近傍全体の中点式と局所的な微分可能性を含める。原文がこれらをこの形で明記しているとは主張しない。平行移動した実際の光路から近傍全体の中点式を得る一般定理と、局所条件から微分式へ移る全実数上の導出は未証明である。

著者がこの選択可能性を注意すべき事項として提示することと、そこから全空間での式を述べることを別の主張にした。「注意すべき」と「明白である」「証明済みである」を同一視しない。引用だけで選択可能性や式を実際の真理として認定することもしない。

新規12件を含む関連35テストが通過した。選択可能性10例、移した関数7例、原点以外の試行15例、地点の座標10例、τと三つの読みの接続12例、別設定での条件15例、帰属8例を検査した。地点に合う試行が一方にしかない場合、成功した結果が別の試行のものだった場合、座標・時刻・光・帰着時計・平行方向が変わった場合を検出する。

有理数の検査では三つの空間成分の移動と時刻成分の保存を確認し、検査用多項式関数について二回の平行移動が移動量の和による一回の移動に一致することも確認した。これらは座標の演算の検査であり、物理的にどこでも同じ試行が可能であることの証明ではない。全空間の式と全空間での選択可能性の量化は、有限検査器が評価を拒否することを確認した。

有限検査では、構成した有理数切断と、同期・局所時刻・座標・局所微分条件などの検査用の関係を使う。地点の履歴の検査では既存の補助座標演算を検査用の関係に置き換え、元の設定と別設定の座標の結合を確かめる。全ての座標に対応する地点と候補試行の存在を、これらの有限例で保証することはできない。
