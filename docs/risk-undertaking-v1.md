# 危険を認識した試みと、その試みへの許可

カント第17区間の `nicht wagen darf` に、危険を認識して発言を試みることと、その試みへの許可を分けた候補解釈を追加した。前段の発言資格の限定と同じ基準文脈に置き、発言する能力と許可を同一視しない。

読みの参考にした現代の[Duden「wagen」](https://www.duden.de/rechtschreibung/wagen)には、失敗や不利益の可能性があっても試みる用法がある。今回の構成はその側面を採ったもので、1784年の語義や、この箇所の `darf` が法的・政治的・実践的な判断のどれに当たるかを確定するものではない。自由国の制度的な構成は未充足の引数として残す。

## 認識、開始、成功を分ける

[共通定義](../examples/v016/risk-undertaking.noema)では、本人・活動・目標の記述・文脈をそろえて、次の条件を合成する。

| 定義 | 条件 |
| --- | --- |
| `rwg` | その活動の可能結果に、本人への不利益となるものがある |
| `rwh` | 同じ目標記述を認識し、本人が採る非空の判断候補の全てで `rwg` が成立する |
| `rwi` | 同じ目標を目指して同じ活動を開始し、その時点で `rwh` が成立する |

本人の判断候補は、現実の状況を含むとは限らない。そのため、実際には危険がなくても本人が危険だと判断する場合を表せる。逆に、危険があっても本人が認識せず、試みを始めていなければ `rwi` は成立しない。開始後の成功、実際の被害、恐れの不在は試みの成立条件に加えない。

判断候補の中で可能な結果と、その同じ結果での不利益を結ぶ。別の人、別の活動、同じ真理値を持つ別名の目標記述から条件を借りることは認めない。認識・候補の選定・活動の開始・目的・不利益の一般理論は、意味規約を持つ基本関係として残っている。勇気、ためらい、危険を受け入れる因果的な態度、結果の不確実性の全側面まで定義したとは扱わない。

## 許可の対象を記述のまま保持する

`rwj` は、同じ基準・主体・役割・活動・記述・時点について、積極的許可があり、不実行の要求がないことを表す。既存の許可条件 `rdm` を段階2の記述へ具体化した。新しい文法演算子は追加していない。

`rwk` は、指定された活動候補のどれにも `rwj` が成立しないことを表す。積極的な許可がない場合と、許可に反対要求が併存する場合の両方で成立する。禁止だけを意味する語ではない。基準を法に限定せず、実践的判断の基準を別に指定できる。

この検査では対象の行為記述を実行しない。試みが現実に行われたか、その目標が成功したかを、許可の成立条件へ追加しない。したがって「試みは可能だが許可がない」「実行していないが許可はある」も表せる。活動候補が空なら全称条件は真になるため、候補が現実の選択肢を網羅しているかは別に確認する必要がある。

## 本文との接続

[本文草案](../examples/v016/kant-risk-undertaking.noema)の `iaautterance` は、既存の許可と服従を述べる引用ひな形 `hzsquotation` を使う。`iaaundertake` は、その発言目標を危険を認識して試みる内容である。自由国に当たる主体の範囲、規範の基準、役割、活動候補を引数に取り、`iaadenial` が各対象への非許可を調べる。

活動に結び付く基準文脈と、引用の話者・聞き手・文脈の一致も要求する。参照が食い違ったために許可の対象が見つからない場合を、非許可の成功例にしない。`iaacontrast` は、この条件と既存の `hzzonly` を同じ基準文脈で連言する。左側の軍隊・保護・発言資格の定義は保持する。

本文は先行する19文を保持し、結合した候補解釈の帰属を1文追加した。帰属時には試み、規範、軍事的能力を実行評価しない。自由国の分類、政治的な危険と基準、対比の論証関係、段落後半は未完である。新しい原文対応は `nicht wagen darf` のみで、自由国の名詞を説明済みとは数えない。

## 検査

312テストで、八条件の256組合せ、現実の危険と成功の独立性、対象・時点・記述の取り違え、未知入力の拒否、候補が空の場合、別候補に許可がある場合を確認した。本文側では、非許可、発言の実現、試みの開始を16組合せで分け、引用の参照不整合も検査した。

前段の統合例とも接続し、左側の資格と右側の非許可のどちらを欠いても連言が成立しないことを実際の定義で確認する。この統合例に含まれる二つの記述量化は、前段と同じ有限診断である。全記述域の証明や原文の語義の検証完了とは数えない。

```powershell
python -X utf8 -m scripts.compose_risk_undertaking
python -X utf8 -m pytest tests/test_risk_undertaking.py -q
python -X utf8 -m scripts.check_risk_undertaking --verify-only
```
