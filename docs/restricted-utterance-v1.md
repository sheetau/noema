# 発言者を限定する条件と、引用への接続

カント第17区間の「その者だけがそう言える」という構造を、既存の許可・服従の引用へ接続した。資格条件を引数に残した部分ひな形であり、原文の完成した翻訳ではない。

`hztonly` は、資格条件と基準文脈を受け取る。対象範囲の各人について、引用の話者がその本人、引用の文脈が同じ基準文脈、引用の聞き手が指定された聞き手集合であることを要求する。その上で、同じ引用を発言できるなら、同じ本人・基準文脈で資格条件が成立するという必要条件を表す。

ここから、資格条件を満たす人が必ず発言できることや、そのような人の存在は導かない。既知の対象範囲が空なら普遍条件は真になる。評価結果が不足する場合の「発言可能性を確認できないこと」も、発言の不可能を示す証拠とは扱わない。必要条件と、不可能性の根拠を要求する強い条件は既存の定義で分かれている。

`hztattribution` は、このひな形の閉じた記述を、著者・原文箇所・範囲・文脈へ結び付ける解釈注記である。記述を引用するだけでは、資格条件も、内側の許可・服従の内容も評価しない。著者への帰属文脈と、資格・発言可能性の基準文脈も別に保持する。

資格条件を受け取る引数は、意味が説明済みの語の代用品ではない。原文の啓蒙、影を恐れないこと、規律ある多数の軍隊、公的平穏を、この引数一つで翻訳済みとは数えない。先行する指揮・保護・権限の定義を、それらの同義条件として自動的に代入することもしない。

## 原文への対応と残る範囲

今回の対応記録は `nur derjenige` と `kann das sagen` に限定した。これは限定と可能性の構造に対する部分的な解釈注記であり、両句の意味を検証し終えたという記録ではない。発言可能性は指定した方法と評価範囲に相対的であり、政治的な許容、勇気、発言の効果までは説明していない。

資格条件の中身、`Aber auch`、同時性、自由国との対比と `wagen`、引用内の `nur`、段落後半の議論は残る。全文の意味確認済み区間数は両作品とも0のままである。
