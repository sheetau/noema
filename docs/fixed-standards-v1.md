# 採用した基準を保持する条項

カントu0013の「一定で変更しない信条」への拘束について、指定した基準を変えずに採用し続ける内容を、相互引受けの条項へ接続した。[アカデミー版電子本文38頁](https://www.korpora.org/Kant/aa08/038.html)の35–36行で対象箇所を確認した。ここでは明示した時間範囲の保持を記述する。永久性、変更する権能の不在、どの可能な場合にも変更できないことまで同義に構成したとは扱わない。

基準には、[既存の採用基準](adopted-standards-v1.md)と同じ型の閉じたNoema記述を使う。その記述は対象と発話に適用する基準関数の列を表す。教義の内容を自然言語の綴りで埋め込んだり、特定の教理を補ったりする仕組みではない。

| 定義 | 内容 |
| --- | --- |
| `rh3` | 同じ組織・基準・状況の版が指定記述と一致し、その組織がその記述を採用している |
| `rh4` | 基準時を含む履歴内の将来区間の全状況で`rh3`が成立する |
| `rh5` | `rh4`の保持を、個体引数列から命題内容への条項関数として構成する |
| `hzcj` | `rh5`の時間順序を、同じ評価文脈における既存の先行関係へ結ぶ |

版の一致と採用は別の条件である。同じ記述を保存していても採用を中断したなら、保持は成立しない。途中で改訂し最後に元へ戻した場合も、区間全体の保持は成立しない。区間は非空で基準時を含み、同じ履歴の選んだ二点の間を抜かさず、基準時より前へは遡らない。単一時点の範囲も書けるため、この条件だけを永久性の表現とは扱わない。

基準の同一性は記述の構造で判定する。関数の本体が同じでも別名の記述へ入れ替えると変更として検出する。意味を保つ表記改訂を許す場合は別途その規約が必要であり、任意の同義性を自動判定したことにはならない。採用された基準そのものの真理や、当事者個人の信念はこの検査で評価しない。

`rh5`の条項は、組織が同じ基準を保持するという共同の結果を表す。引数列に含まれる当事者が違っても、対象となる結果は同じである。当事者個人の行為や確信を表す場合は、別の条項が必要になる。前版の相互引受けは、引数列の先頭がその本人であることを引き続き要求する。

既知の閉じた引数を`hzcj`へ適用した式を引用し、その同じ記述を合意への条項割当と各人の表明へ渡す。既存の`apply_description`はこの閉じた適用式を構成するだけで、基準や未来の事実を推測しない。人が同じ適用式をNoemaで直接記述してもよい。記述を引き受けた事実と、その記述を実行評価したときに保持が成立することは独立している。

検査では、基準時と中間時点それぞれの版の一致と採用を独立に変える16通りを調べた。区間の空集合・欠落・履歴外・過去への拡張・順序の循環など10対照例も区別した。一般文書と抽出文書の結果を照合し、版・採用・時間関係が未知なら評価を拒否することを確認した。

原文接続では、相互引受けの成立・実際の保持・規範的な効力の不成立を独立に変える8通りを調べた。保持が偽でも引受けを記述でき、保持の解釈が未知でも引受けの表明を評価できる。実際の保持を尋ねた場合には未知の解釈を要求する。組織・基準・基準記述を交換した三つの別条項は、元の引受けとして認めない。全対象にわたる規範の不成立には、前版と同じく検査用の解釈を明示しており、全記述の列挙証明ではない。

[一般用文書](../examples/v014/fixed-standards.noema)は1,409文字、[原文付き草案](../examples/v014/kant-fixed-standards.noema)は115,331文字、[抽出文書](../examples/v014/fixed-standards-core.noema)は4,453文字である。4定義を追加し、親の宣言と15件の主張を保持した。新しい原始概念と著者主張は追加していない。[意味規約](../data/kant-fixed-standards-basis-v1.json)と[検査記録](../reports/fixed-standards-v1.json)に意味と検査範囲を保存した。

宗教・教会・教理の一般的な説明、版や採用を現実に認定する制度、宣誓、変更を許さない拘束力、永続的な後見という目的、著者の問いと無効性の主張への帰属は残る。原文範囲は部分的な解釈注記として集計し、意味確認済みの全文単位には数えない。
