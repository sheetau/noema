# 範囲への先行と、基準時点から見た遠い過去

第二段落の第一文を読み直すと、旧 `km`・`qg` は時間の二つの比較を混同していた。解放は、その後に未成熟な状態が続く範囲より前にある。一方、[原文の「längst」](https://korpora.org/Kant/aa08/035.html)は、ここでは内容を述べる基準時点から見て解放が遠い過去である、という読みを採る。継続範囲の各時点から遠い過去であることまで要求する必要はない。

例えば、解放の直後から未成熟な状態が続き、現在は解放から十分な時間が経っている場合、旧条件は継続の初期を理由に偽になった。逆に、解放は現在から見れば最近でも、遠い将来だけを継続範囲にすると旧条件は真になり得た。範囲の選び方で、現在からの経過の意味が変わっていた。

一般定義 `rqxe` は、指定点が非空で間の抜けない継続範囲の全体に先行する条件 `te` を保持し、距離を評価する基準点を別の引数で受け取る。基準点も同じ順序付き履歴に属し、指定点より後にあることを求める。距離の条件は指定点から基準点までの一組に適用する。数値的な年数や距離の単位は補わない。

本文の `km` は、依存していた本人が自然的成人の状態に移る過程と、その本人への影響を従来どおり要求する。移行の後状態は継続範囲の前にあり、そこから内容の基準状況までの経過を `kd` で評価する。解放から継続開始までの長い待機期間を追加しない。

自然による宣告という描写 `qg` にも、同じ時間構造を使う。宣告の時点と、宣告された条件の記述 `qf`、その対象者は保持する。描写を提示することから、自然の現実の発話、宣告の正当性、宣告内容の実現は導かない。本文は従来どおり `kf` と `qg` を非字義的な提示として結び、因果内容と描写を著者に帰属する。

内容を評価する時間的な基準状況と、帰属文を記録する本文の文脈は同じとは限らない。新条件では、内容の基準点を履歴内に要求する。時間に属さない単なる本文位置を、そのまま時間比較の引数として使う解釈は受け入れない。一般形では基準点を明示的に渡せるため、過去の視点からの叙述にも別の基準を設定できる。

従来の `tf` は、指定点から範囲内の全時点まで十分な経過がある、と述べる用途に保持する。言語一般でその意味を削除したのではなく、今回の原文への接続先を修正した。新しい基本関係や構文は増やさず、一つの一般定義を追加して二定義の本体を改訂する。

検査では、初期・現在・後期への距離の八組合せと、基準点の交換、履歴外の点、空範囲、途中の欠落、循環した順序など十二対照を扱う。現行の移行証人 `km` と描写 `qg` を旧版とともに実行する二十六対照では、本人、過程、以前の依存、後の成熟、宣告者・対象・条件・時点も交換する。未知の距離や履歴は真偽へ補完しない。帰属だけを実行する八対照では、全ての時間的・因果的事実を不明のまま扱う。

これは移行の証人と描写の時間条件の検証である。`kf` の全存在探索、人口比率、譲歩、後見役になる容易さを合わせた全定義の再実行とはしない。読み直した参照構造では、生涯の範囲は同じ本人に結ばれ、後見の対象 `oi` は先行する `kg` の該当者を保持している。ただし、生涯と態度の粒度、自然的成熟とラテン語、容易さの尺度と他者の範囲内での全称条件は部分的な読みとして残る。
