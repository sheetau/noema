# 共同原因と各構成員の必要性

複数人の発展を別々の原因変数へ結び、同じ集団の応答傾向と行為能力への作用を比較する候補を追加した。全員をまとめて変えたときに結果が変わる条件と、各人がその組合せに必要である条件を分ける。前段の一人からの条件文は保存し、共同原因の候補を別の注記として帰属する。集合的な前件を持つ条件文全体への統合は残る。

## 二つの強さを区別する

[一般定義](../examples/v016/joint-development.noema)の `rxq` は、原因側に採る人々の非空の列と範囲を一致させる。各人には異なる宣言済みの原因変数を割り当て、媒介変数とは分ける。一つの変数を二人の発展として使うと、一人だけを外す比較ができないためである。

`rxr` は同じ方程式の下で次を要求する。

| 比較 | 要求する結果 |
| --- | --- |
| 観測された割当て | 全原因、媒介、結果が成立し、対応する内容も評価済みで成立する |
| 全原因をまとめて偽へ固定 | 非空の全解で、媒介と結果が評価済みで成立しない |
| 全原因をまとめて真へ固定 | 非空の全解で、媒介と結果が評価済みで成立する |
| 全原因を真に保ち、媒介を偽・真へ固定 | 各側に解があり、全解で結果もそれぞれ偽・真となる |

各解では、各人の前件内容の真偽をその人の変数と照合する。媒介についても同じ内容を照合する。変数名の反転だけで、内容が変わったことにはしない。

`rxs` はさらに、他の原因を真に保ち、一人の原因だけを偽にする比較を全員について行う。各側に解があり、全解で媒介と結果が評価済みで成立しないことを求める。これは「この背景では各人を外せない」という強い条件である。

例えば、甲か乙のどちらか一人が発展すれば結果が出るモデルでは、両人を同時に外すと結果が消えるため `rxr` は成立し得る。しかし甲だけを外しても乙が残るので、`rxs` は成立しない。甲と乙の両方が必要なモデルでは、双方が成立し得る。

## 各人の内容を同じ世界で評価する

[本文草案](../examples/v016/kant-joint-development.noema)の `iapjoint` と `iapnecessary` は、前段の思考の発展の記述を、原因側の各人に適用する。原因側の人々は同じ共同体の元の開始点で固定し、影響先共同体の構成員であることも要求する。影響先の全員が原因側に参加するとは限らない。

各人の発展は同じ解の共通始点で評価する。有限検査では「両人が発展」「甲だけ」「乙だけ」「どちらも発展しない」の四つの世界を区別する。共通の評価時点を使うことは、発展の過程が同時に始まったという意味ではない。

媒介には前段の集団の応答拡大 `ianchange`、結果には行為選択の拡大 `iaoeffect` を使う。構成員、判断対象、行為の活動は同じ元の開始点で固定し、各解では共通の履歴を使う。集団の変化を未定義の真理値へ置き換えず、実際の判断条件と実行・不実行の方法を評価する。

全員が発展した世界と誰も発展しない世界だけでは、甲と乙の変数を取り違えても見えない場合がある。一人ずつ外した世界では、それぞれの実際の発展と変数の不一致が表れる。この反例も検査する。

## 検査と限界

285件のテストが通過した。二つの原因から媒介を決める16種類の二値関数と、全原因の連言・媒介から結果を決める16種類の関数の、計256組合せを検査する。全原因をまとめた比較では四種類の媒介関数が通り得るが、両人が必要という条件では両原因の連言だけが残る。この有限な関数族での結果であり、任意の因果モデルの分類を完了したものではない。

原因側の重複・欠落、同じ変数の流用、未宣言の変数、媒介との同一化、一人を外した側だけの評価不足・未知入力・解の不在も検査する。本文では実際の発展、集団の判断、行為能力を同じ解釈で評価し、内的な衝動と課題の付与という前段の二つの読みも保持する。

診断には明示的な短絡評価と、純粋で外延的な解釈向けの関数再利用を使う。キャッシュなしとの比較は一般条件の基準例に限る。 三文書の長形式・短縮形式・固有文字の往復とCLI解析、抽出文書のSVGのXML検査も通過した。形式的な評価、表記の往復、CLI解析、SVGのXML検査は、原文との意味一致や字形の目視確認を代替しない。

```powershell
python -X utf8 -m scripts.compose_joint_development

python -X utf8 -m scripts.check_joint_development --verify-only

```

[意味規約](../data/joint-development-basis-v1.json)と[検査記録](../reports/joint-development-v1.json)に、強い候補としての限界を残す。各人が必要であることは、協力する意図、共同意思、共同の行為を意味しない。代替可能な参加者、過剰決定、確率的寄与を含む一般的な共同寄与とも区別する。非単調なモデルの全ての部分集団を、一人ずつ外す検査だけで比較したとも主張しない。

親の全宣言と先行21文を保存し、最後の文に共同原因の注記への帰属を連言で加えた。集合的な前件から後件・残余条件までの統合、作用の独立した時刻、政府の原則、尊厳、原文の語義との一致は未完である。新たな原文文字範囲や意味確認済み区間は加算しない。
