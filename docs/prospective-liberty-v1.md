# 許可の継続と、基準時点より後の変化

前段は、候補状況での許可と、その状況までに起きた能力変化を結んでいた。今回は、許可を残す基準時点を別に指定し、それより後に完了する変化を可能性の目標にする。既に完了した変化を、将来の見通しの成功例へ流用しない。

## 範囲を決める文脈と、時間を区切る点

参照文脈は、想定読者と公的活動・役割の範囲を固定する。基準時点は、候補ごとにその内部の前後を区切る。候補状況は、既存の`h7q`によって期間枠の経過を解釈し、`ic`によって先後を評価する。条件文では、候補から基準点への対応関数を明示し、現実の一点を全候補の基準点へ暗黙に共有しない。

停止前の試作は、全候補に同じ基準点を渡していた。その点を現実の時点と解釈すると、条件を満たす候補の存在から、その現実の時点での許可まで導いてしまう。構文や時間順序のテストが通っていても、この意味上の問題は残る。今回の修正では、仮定内の基準点を現実から分ける対応を渡せるようにした。定数関数で現実の一点を共有する強い読みも書けるが、それを条件文の既定の意味にはしない。

`rqtb`は、経過の順序を既存の`ta`で確認し、基準点が経過内にあることと、それより後の点があることを要求する。`rqtc`は、その同じ経過で、基準点自身と以後の全点に条件を課す。許可された点だけを選ぶ別の期間は受け取らない。

`rqtd`は、同じ経過内の開始点・終了点を持つ変化過程を探す。終了点は開始点より後で、かつ基準点より厳密に後でなければならない。開始が基準点より前の過程も許す。将来に完了する変化を述べるために、将来になってから新しく始まる過程だけを要求する必要はない。

| 過程の位置 | 将来の変化として扱うか |
| --- | --- |
| 基準点より前に始まり、後に完了する | 扱う |
| 基準点から始まり、後に完了する | 扱う |
| 基準点より後に始まり、さらに後に完了する | 扱う |
| 基準点と同時、またはそれより前に完了している | 扱わない |

## 公衆の能力変化への接続

`hzne`は、同じ期間枠・候補の経過を`rqtb`へ渡す。`hznf`は`rqtc`の条件へ既存の`hzna`を渡し、基準点から後の全点で、同じ出所が公的活動を許可して不実行を要求しないことを述べる。人と活動の範囲は参照文脈で固定し、各時点で規範を評価する。候補内の基準点と最後だけが許可され、中間で撤回されている場合は成立しない。

`hzng`は、`rqtd`が選ぶ同じ過程・前後を既存の`hzmy`へ渡す。共通の経過にも、能力変化の対象者の履歴にも、その前後点が入る。候補の先後関係も共用する。個人の履歴全体を、公衆を評価する共通の経過と同一にする条件は加えない。

`hznh`は、各候補に対応させた同じ基準点で、許可の継続`hznf`を条件、将来の変化`hzng`を目標として、質的な「ほぼ必然」の`rqsu`へ接続する。その前に、選択した全候補の経過を、同じ対応関数を使う`hzne`で検査する。不正な候補だけ前件が偽になり、結果に影響しないものとして消えてしまうことを防ぐ。条件を満たす候補は非空とし、仮定内の許可を現実の許可へ移さず、実際の将来の実現・自由の必要性も追加しない。

## 検証

一般形は、四時点における許可と基準点の64組合せ、過程の有無・開始・完了・基準点の128組合せを独立した計算と照合する。空の経過、基準点の欠落、将来点の不在、循環する順序、未知の経過・順序・条件・変化も検査する。これらはメモ化せずに実行する。

原文への接続では、既存の規範・能力変化・因果・尺度の定義を同時に実行する。許可が継続する場合と中間で撤回される場合、基準より後の完了と既に完了した変化、別候補の変化、全候補の経過検査の有無を比較する。不正な候補を入れても、経過検査を外した様相式だけなら成立してしまう例を、検査付きの構成で拒否する。

さらに、候補ごとに基準点を変える例、現実では許可がない例、仮定内では同じ政策だが現実の許可がある別の出所、現実の点を基準点に誤用する例を加え、計15項目の真偽列として検査する。現実の許可が偽でも、仮定内の許可が続く場合の条件付き判断は成立する。現実で許可がある場合も、そのことだけで仮定内の結果を変えない。経過にない現実点は時間検査の`hzne`で拒否し、`hznh`が経過検査・許可・変化の三か所で同じ対応関数と同じ候補を使うことを構文木でも照合する。

読者・活動の参照文脈と期間枠を固定して問い合わせていることも調べる。未知の経過・許可・基準点の対応は、候補の条件を偽として埋めずに返す。同時評価はメモ化を使い、この検査だけの上限を3億6,000万ステップとする。現実を別の四つ目の状況として加えた検査は、経過にない基準点の反例を前述の時間検査と接続構造の検査に分けても、前段の1億8,000万ステップの上限に達した。意味の条件を保ったまま専用の上限を増やし、各対照の完了を表示する。現実の許可と仮定内の条件付き判断の対照は、能力変化の定義を含む同時評価で確認する。保存した定義を真偽値だけの基本関係へ差し替えたり、式を短絡変換したりしない。通常表記・短縮表記・固有文字の往復と、既存32文・意味規約・七単位の確認の結び付きを検査する。

## 採用した読みと残る内容

許可を選択した経過の全将来点に課すのは、自由を継続して残す政策としての読みである。一回の試みの間だけの許可より強く、自由一般の唯一の意味とはしない。原文に具体的な期限や日数は補わないが、経過そのものが現実の全時点を尽くすかは別途根拠が必要である。有限モデルの検査を、無限の持続の実証とは扱わない。

許可の継続と結果の前後を結んでも、自由がその変化の原因だという追加の因果主張にはならない。規範的な許可を超える自由の社会的条件、公衆の意味、公開された議論・自己評価・態度の普及、適切な広がりと比較対象、強調と著者帰属は引き続き必要である。新しい著者主張・原文対応範囲・意味確認済み単位は加算しない。
