# 条件が決まった定義を、言及できる形へ展開する

前回の規則評価は、条件と目標の式を記述として受け取り、それを評価する。そのため、現行の引用制限では適用・遵守・違反の定義自体を引用できなかった。今回は、条件と目標が具体的に決まっている場合に、同じ評価条件を持つ引用可能な定義を機械的に作る機能を追加した。

引用を許す文法条件は変更していない。未確定の式を評価する一般定義には、従来の制約が残る。今回の処理はモデルやプロンプトによる生成ではなく、型付きの構文木を決められた変換規則で展開するものである。

## 何を固定して、何を保持するか

`specialize_definition(document, source, target, bindings)` は、元の定義の引数位置を指定し、その位置に閉じた型付きの式を代入する。残りの引数は新しい定義の引数として保持する。元の宣言と本文の主張は変更しない。

処理は、評価を含む定義の展開、変数の捕獲を避ける代入、既知の引用に対する評価の除去を行う。自由変数や型違いの引数、未確定の引用、引用制限に抵触する残りの参照は拒否する。基本関係の解釈を実行して値を推測することはない。展開には大きさの上限も設ける。

深い定義の連鎖にも展開時の深さの上限を設け、Pythonの再帰上限による失敗に至る前に拒否する。入力として有効な全ての定義を、必ず展開できるという保証ではない。

引用された式の内部は展開しない。採用された目標の記述が別名の式に変わると、真偽は等しくても「どの記述が採用されたか」が変わるためである。一方、引用を実行して得た関数を使う部分では、通常の型付きの適用として展開する。

```python
from noema.grammar import parse
from noema.specialization import specialize_definition

doc = parse('n:r aa[] c.d ab[value i[c]] c[s[v value]].')
result = specialize_definition(doc, 'ab', 'ac', {
    0: {'kind': 'quote', 'body': {
        'kind': 'call', 'symbol': 'aa', 'arguments': []
    }}
})
# acはaaの値を返す通常の定義になり、r[p ac]で言及できる。
```

変換後には、通常の型検査と引用可能性の検査を再実行する。特別な実行時構文を保存するのではなく、既存の0.13または0.14として読める文書を得る。結果とともに、固定した引数位置、展開した定義、取り除いた引用評価の件数も返す。

## 規則の適用・遵守・違反への適用

[構成例](../examples/v014/kant-prescription-mentions.noema)では、前回の規則評価の条件を既存 `bf`、目標を既存 `bm` に固定した。規則・出所・本人・立場・要求の肯否・文脈・立場への該当関係は、引数として残している。

| 元の定義 | 派生定義 | 内容 |
| --- | --- | --- |
| `rbb` | `he2` | 固定した条件・目標を持つ規則の適用 |
| `rbc` | `hf2` | 同じ規則への遵守 |
| `rbd` | `hg2` | 同じ規則への違反 |

この三つは記述として引用できる。引用を受け取る関係は、規則を適用・実行せずに、その適用条件や違反条件へ言及できる。ただし、元の式と派生した定義の記述が構文上同一になるわけではない。

条件と目標の組は、既存の性質を使った構成例である。カントがその規則を採用したという原文対応や、新しい本文の主張は追加していない。原文の範囲も増やしていない。任意の規則の機械的な使用・誤用、足枷の比喩への接続は残る。

## 検証と限界

一般形では32通りの規則の存在・立場・条件・目標・肯否について、三つの派生定義を元の定義と比較した。構成例でも32通りを比較し、適用・遵守・違反の各値が一致することを確認した。派生定義への言及では、言及を受け取る関係以外の全ての基本関係を実行時に拒否する検査により、内容を実行していないことを確認した。

変数名が重なる呼出し、引用された関数、引用を返す補助定義、同じ値の別名、開いた式、型違い、未確定の引用、過大な展開も検査する。変換後の意味の一致は、Noemaの値の等しさを尊重する、全域で純粋な解釈に基づく。副作用や例外を持つ外部関数の実行順序・回数・計算量まで同じにする機能ではない。

全ての静的に計算できる式を処理する最適化器ではなく、扱えない展開は拒否する。式記述の全領域にわたる量化、一般の引用内評価、自己言及の拡張も行っていない。有限の比較検査を、全ての原文に対する意味一致の証明とは扱わない。

追加した定義は3件で、基本述語は増やしていない。原文接続文書は累計基本述語178・定義246、正規形36,122文字で、追加は534文字である。既存の全宣言と9主張は保持した。

関連61テストが通過した。検証記録と進捗集計の再生成一致、通常・短縮記法と固有文字の往復、CLIのJSONと元の構造の一致、SVGのXMLとしての妥当性も確認した。今回、字形の目視確認は行っていない。
