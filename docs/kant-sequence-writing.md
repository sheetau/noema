# 列と列の操作を読む規則

既存の native `sequence`、`length`、`position`、`concat`、`fold` を、そのまま円文字から復元する。要素型には既存の再帰型文法を、位置と長さには数値文法を使う。列ごとの語や意味規約は追加しない。

列は「列の開始・要素型・要素の並び・列の終端」とする。要素型を先に一つ読み、空列でも型が失われないようにする。要素はそれぞれ一つの完全な式であり、入れ子の列・引用・関数も自身の規則で読み終える。列の終端には既存の型列終端形を使う。型を読む位置、式を読む位置、列の次要素を読む位置を区別するので、再帰型の終端と列の終端は混同しない。

列開始からの枝には先頭から連続する要素を置き、見える枝順で読む。残りの要素は主列で読み、終端で閉じる。枝を使う場合も最後の要素を主列に残す。この規則では要素数を別の数値で書く必要がなく、枝数を変えても要素順が変わらない。主列の要素型は枝より先に解釈する。枝自身は一式だけを含み、列終端を付け足さない。

| 構成子 | 元の引数順 | 結果 |
| --- | --- | --- |
| length | 列 | 数 |
| position | 列・位置の数・照合する要素 | 真偽 |
| concat | 左の列・右の列 | 同じ要素型の列 |
| fold | 列・初期状態・更新関数 | 初期状態と同じ型 |

更新関数は「状態・列の要素」を受け取り、同じ型の状態を返す。これらの操作には既存の引数分岐規則を適用する。型の不一致を読み替えたり、畳込み順や位置の意味を変えたりしない。型検査は既存 native 検査器で行う。

列開始は大円の左円周に中円中心を置き、大円から右上へ外向きの終端斜線を出す。四操作は大円の右円周に中円中心を置いた形を共用し、大円中心からの線を、長さは上、位置は下、結合は左上、畳込みは左下とする。方向は構成子の区別であり、配置に合わせて回転させない。元の円配置・線方向・間隔規則を満たす形だけを用いる。

実装前の検査計画：空列・一要素・複数要素・入れ子・要素順の交換を対照にする。各操作を数値、束縛、引用、関数適用へ接続し、実SVGから元構文へ戻す。終端欠落、余分な終端、型不一致、枝の余剰式も拒否する。既存数値と非列の保存図形は再描画せず読み戻す。最後に保存された列の定義本体へ接続する。全ページの外観完成や宣言文法の完成とは別に扱う。
