# 判断の実行と、その遂行の不確かさ

カント第三段落の第四文について、依存を捨てた後にも不確かな跳躍になるという描写の対象側を構成した。候補は「自分で判断に取り組むが、同じ基盤と課題で、理由に支えられた自己遂行を通常比較全体に確保できない」である。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)にある身体的な跳躍を、知的活動の条件へ結ぶための読解候補として保存する。

## 比較条件を先に確認する

一般形 `r2gu` は、比較する全場面に保持条件と外的機会があり、通常性の厳密な優先関係と非空の通常候補が有効であることを確認する。前版の応答傾向 `r2gl` を、常に真の応答へ適用して評価条件を取り出す。`r2gv` は同じ比較に実際の応答条件を渡し、全通常場面での成立を要求する。

`r2gw` は、有効な比較で `r2gv` が成立しない場合を表す。一つでも通常場面に応答がなければ成立するため、応答する場合としない場合が混じることを許す。一方、空の比較、不正な順序、本人側の基盤の交換、外的機会の欠落は、不確かさの根拠にならない。全通常場面で応答しない傾向とも区別する。

## 同じ判断と課題を保持する

`r2gx` は、本人が自分の理解力を使い、他者によるその判断への指導なしに、同じ課題について判断活動を行うことを表す。`r2gy` は、その同じ判断へ既存 `h5c` の理由と支持の条件を加える。別の判断への理由や、別の話題への支持を借りることはできない。

比較場面には、この取り組みに対応する活動を指定する。`r2gz` は全候補で非空の対応を確認し、通常場面の全対応活動に `r2gy` が成立するとは限らないことを要求する。対応活動が未遂であるなど、既知の応答不成立は許すが、対応の指定が欠けているだけでは不確かさを導かない。比較の選択、通常性、対応活動の範囲を、応答の成否から決め直すことも許さない。

`r2ha` は基準での実際の独立した判断と、その同じ活動の不確かさを結ぶ。現在の判断に支持する理由があっても、通常比較全体に同じ条件を確保できなければ成立する。結論の真理、主観的な自信、実際の失敗、全方法にわたる能力不足は、この構成の条件に加えない。

## 前件との接続

`r2hb` は、提示文脈で固定した同じ課題への判断活動を存在量化する。`r2hc` は前版の依存離脱 `r2gt` とこの後件を同じ本人へ渡し、非空の仮定集合に条件を課す。前件を満たす仮定が少なくとも一つ必要であり、前件がどこにも成立しないことで条件を通さない。`r2hd` は、この骨格を固定した提示文脈の知的活動側の仮定集合へ結ぶ。

今回の課題参照は、同じ課題を保つところまでを扱う。「最も小さい困難」の比較尺度、`nur` の限定、`auch` と `dennoch` の期待対比、不慣れの活動記述と理由、身体的描写との対応は残る。したがって、この条件骨格を第四文の最終訳として著者へ帰属する本文に採用してはいない。

## 検査の範囲

六テストで、比較条件と応答の64組合せ、実際と比較場面の理由支持の8組合せ、条件文の16組合せを検査する。対応の欠落、別の課題、別の理解力、他者による指導、別の判断への支持、通常性の循環、非通常候補の条件不足、未知入力も区別する。

前件と後件の結び方を分離した試験に加え、前版の離脱、実際の判断、比較場面の理由支持、存在量化した後件を同じ有限世界で実行する。正の一例と、後件が確実になった場合・離脱がない場合・実際の判断がない場合の三対照を確認する。引用の試験では世界の入力を全て未知にしたまま、条件の記述を保持できることを確認する。これらは有限モデルでの検査であり、原文との同義性の自動証明ではない。

十定義と七つの解釈入力を追加した。既存54文、全ての既存宣言・意味規約、十二全単位2,212文字と先頭三文408文字の判断を保持する。短形・長形・独自文字の往復も確認する。原文対応範囲と意味確認済み分量は増やさない。

```powershell
python -X utf8 -m scripts.check_uncertain_judgment
```
