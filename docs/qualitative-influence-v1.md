# 影響の比較と二つの問いの構成

第五段落の二問へ進むため、制限の有無による結果の比較を構成した。現時点では一般ライブラリであり、カント本文への帰属や意味判断は追加していない。[Noema](../examples/v016/qualitative-influence.noema)、[意味規約](../data/qualitative-influence-basis-v1.json)、[検査報告](../reports/qualitative-influence-v1.json)を別に保存する。既存本文の複製は作らず、必要な介入定義だけを変更せずに取り込んだ。

先行する介入の試作では、要因ありの全結果が、要因なしの全結果より厳密に良いことを促進の候補にしていた。この条件では、結果が同程度となる組を許さない。新構成は、同程度・悪化・改善を区別し、非悪化に加えて改善があることを組み合わせられるようにした。

## 同じモデルで比較する

変数列・方程式・背景を固定し、一つの要因だけを真と偽へそれぞれ固定する。既存の `ru` で介入方程式の解を調べ、`rs` で有限変数の全割当てを列挙する。両側に解があることを要求するため、解のない側を比較して害がないとは判定しない。

結果の「少なくとも同程度」という関係は、数値尺度に限定しない。全介入解について評価が済み、比較が反射的・推移的であり、両側の各組を比較できることを確かめる。相互に同程度と判定された異なる割当ては許す。比較不能や評価欠落は、同程度にも非悪化にも置き換えない。

この比較関係と介入の結果から、次の条件を作る。

| 条件 | 要求 |
| --- | --- |
| 潜在的な不利益 | 要因ありの方が厳密に低い組がある |
| 非悪化 | 有効な評価の下で、低い組が一つもない |
| 非悪化かつ改善 | 非悪化であり、高い組が少なくとも一つある |

改善する組と悪化する組がともにある場合は混合した影響として残す。改善があることだけで非悪化にはしない。同程度の組しかない場合は非悪化となるが、改善とはしない。

全解の交差比較には限界がある。同じ外生背景で比較する必要があり、無関係な背景を混ぜて得た結果を因果的な影響に数えることはできない。解同士の対応を限定するモデルには、別途その条件が必要である。このライブラリの比較は頑健なモデル内の分類であり、社会的な一般傾向や現実の因果関係の実証ではない。

## 問いとしての構成と検査

候補範囲、評価条件、悪化、改善を同じ個体へ適用する二つの質問を作った。一方は悪化する候補、もう一方は悪化せず改善する候補を求める。候補の存在や唯一性は断言せず、空の答え集合も表せる。語彙として「阻害」「促進」という真偽未展開の基本関係を追加したものではない。

検査では、二変数の結果方程式16通りと結果の大小16通りを独立に組み合わせる。解なし・複数解・同程度・混合した影響を含め、Noemaが求めた解と比較結果を独立の列挙計算に照合する。別に三段階の程度、反射性と推移性の違反、比較不能、評価欠落、重複変数、範囲外の要因、未知入力の拒否、質問の候補範囲を確認する。

## 原文への接続で残ること

対象となる二問は[原文AA8:37](https://korpora.org/Kant/aa08/037.html)の、制限を啓蒙への影響で区別する箇所である。このライブラリを使う前に、制限の候補とモデル要因、既存 `r2ln` の啓蒙と結果尺度、対象となる人々・期間・背景の対応を明示する必要がある。潜在性と一般的な傾向のどちらを採るかも未確定である。

候補範囲を直前の四個人だけに縮めず、二問で同じ制限と啓蒙を参照する。`aber` と `sondern` の対照、`wohl` の留保、`gar` の焦点、回答への接続を残す。[Dudenのwohl](https://www.duden.de/rechtschreibung/wohl_vermutlich_doch)と[gar](https://www.duden.de/rechtschreibung/gar_besonders)は語用の検討資料であり、特定の読みの唯一性を証明するものではない。本文の先頭七文496文字と旧14全単位判断を保持し、今回は確認済み文字数を増やさない。
