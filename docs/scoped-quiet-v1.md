# 行動の落ち着きと内面の平静を分ける

カントの「diese ruhigen Geschöpfe」に向け、指定した種類の出来事の不在を表す四定義を加えた。新しい基本述語はない。これは語義を比較するための構成であり、`ruhigen` の描写を本文へ採用した段階ではない。

## 不在を判断する対象と範囲

`rqzz` は、同じ本人・出来事・時点について、本人との関係、生起、指定された性質を結ぶ。`rqz2` は、指定した範囲のどの時点にもその出来事がないことを表す。既存の `tb` によって、範囲が空でなく、一つの順序づけた履歴の中で間が欠けていないことも要求する。

`rqz3` は同じ範囲条件の下での存在を表す。範囲が整合しているときは存在と不在が反対の結果になる。範囲が空、途中が欠けている、履歴から外れている場合は、両方を偽とする。この区別により、範囲が不適切で検査を通らなかったことを不在の成立へ取り違えない。

範囲と履歴の完全性は解釈の前提である。少数の観測時点だけを履歴全体として渡せば、検査だけでは観測漏れを見抜けない。連続する現実の全時点を、有限の検証例で網羅したという主張はしない。

## 動いていることと、落ち着かないこと

`rqz4` は本人との関係を既存の行為参加 `df`、生起を `dg` に固定する。性質を「顕著な乱れを持つ活動」に指定した場合、そのような活動の不在を検査できる。別の性質の活動まで排除しないため、活動していてもこの不在条件は成立できる。

同じ一般形へ経験主体の関係と内面的な経験の性質を渡せば、内面側の不在を別に表せる。外面の活動が落ち着いていても内面に負担のある経験がある場合、その逆の場合も区別する。外面側を評価する際に、内面が未知なら平静だと補完することはない。

ここで性質は引数であり、「顕著な乱れ」の境界や内面的な平静の心理学的構成まで説明したわけではない。全ての活動の停止、服従、非抵抗、勇気不足を代わりに使う定義も置いていない。

## 歴史的用法と本文への接続

[Adelung の Ruhig 項目](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_6_2_2115)には、動きに関する用法、他者を煩わせない振る舞い、内面的な感覚に関する用法が併記されている。この区別を踏まえ、本文の語を単なる不実行や服従へ置き換えない。[出典記録](../data/scoped-quiet-evidence-v1.json)には取得した本文、元の符号化、バイト列のハッシュを保存した。

この用例がどの側面をどの程度まで示すか、同じ対象者と先行局面へどう結ぶか、`Geschöpfe` の呼び方とどう組み合わせるかは、次の読解課題とする。辞典の複数用法があること自体は、特定の読みの正しさの証明ではない。

## 検証

四テストで、二出来事に対する参加・生起・性質の64組合せ、人物・出来事・時点と範囲の十二対照、外面の活動と内面の経験の16組合せを通常評価器で検査する。未知入力を不在へ変換しないこと、三記法の往復、既存48文と十一単位の意味依存関係の保持も確認する。

比較文書の定義は増えるが、採用本文の主張と意味確認済み分量は増やさない。原文の全内容を表現したことや、自然言語との意味一致を自動証明したことには数えない。
