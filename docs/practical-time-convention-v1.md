# より実用的な規定への導入

固定原文u0012第三文[489,569)、71非空白文字を扱う。前二文で検討した受信時の割当を比較先とし、同じ時間的評価の課題に対する新規定の実用性を述べる。比較基準は、複数地点の出来事を共通の規約で扱うための適用のしやすさとして固定する。

二方式の程度を同じ基準へ結び、新規定の程度が厳密に高いことと、差が顕著に大きいことを要求する。これによりpraktischerとweitを分けて保持する。質的な尺度であり、原文にない数値閾値、費用、全ての評価項目での優越、最適性は加えない。程度の評価と顕著な開きの基準は意味規約付きの入力であり、有限例による実用性の実証とは区別する。

新規定は、既存の同期した局所時計による時刻付与規則quと、その定義箇所rjへ結ぶ。著者がこの規定へ至る手段として同じ考察を用いる関係を記述する。単に文章が後に続くという関係とは別に、u0013冒頭の点Aの時計からu0018の時刻付与定義までを指す前方参照を置く。

この文は後続の考察を予告する主張である。規則への参照で同期の物理条件を全評価したり、後続段落の仮定を実証済みとしたりしない。前二文の採用可能性と不都合を保持したまま、新たな規定へ議論を進める。
