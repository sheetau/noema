# 運動を求める問いと、過不足のない方程式

アインシュタイン1905年論文§5のu0133冒頭にある「静止系に対する点の運動を求める」という課題を、Noemaの既存の質問構文で記述した。答えを方程式の列として求める読みを採用する。問いの提示は、答えが存在する、一つしかない、既に発見されたという断言を含まない。

回答候補の条件は、指定した座標集合と方程式の解集合が過不足なく一致することである。対象の座標が式を満たすだけでは、別の余分な解を排除できない。前回の運動条件はこの片方向の一致を記述していたため、それだけから今回の回答条件が満たされるとは主張しない。

一般の定義 `szb` は、指定範囲内の非空の対象集合と、非空の有限方程式列を比較する。各記録について全式を満たすことと対象に属することの同値を要求する。既存の左右の式の評価と有限列の演算を再利用しており、速度合成専用の基本演算を追加していない。`szh` はこの条件を満たす列を尋ねる質問である。

運動への適用では、対象の点、基準系、設定を固定する。履歴の全出来事に有効な座標記録があることを要求し、記録のない出来事を黙って除外しない。別の識別子を持つ同値な座標記録も、四成分の値の一致によって対象に含める。

`sze` が質問、`szf` が先行する速度変換の三式から構成した候補、`szg` がその候補の回答条件を表す内容である。質問の定義は、候補や速度合成の式に依存しない。`szg` では許容速度・正のβ・非零分母も要求するが、その内容を本文の断言として追加してはいない。著者が質問を課題として提示する関係には既存の `zdc` を再利用した。

検査では、式を満たす未選択の座標を対象範囲へ残す例を設けた。この例では、先行する履歴の運動条件は成立しても、今回の回答条件は成立しない。対象を式の全解に合わせて縮めたり広げたりして検査を通す方式にはしていない。同値な記録、欠けた記録、不正な記録、別の点・系・設定、誤った速度成分も区別した。

運動の候補判定12例、課題の帰属5例に加え、別の話題である長方形の面積記録を11例で検査した。式の順序変更や重複は答えの解集合を変えず、余分な解、対象の取りこぼし、空の式列は回答条件を満たさない。真偽値で実切断の左右を選ぶ定義も、境界を含む10例で検査した。

これらは明示した有限領域と有理数から構成した切断での検査である。任意の実数上の方程式の発見、全時刻での出来事の存在、全座標値の表現可能性を証明したものではない。有限列を答えとする無限の候補領域を、有限解釈器で全列挙しようとすると拒否する。候補一つの判定と全回答の列挙は区別する。

新規8テストと関連テストの計27件が通過した。両文書について、通常記法・短縮記法・固有文字の構文上の往復、CLIのJSONと構文木の一致、SVGのXMLとしての読み込みも確認した。全テストの実行と字形の目視確認は今回の検査に含まない。

追加した定義は、一般用途3個と原文への接続6個である。新たな基本記号は本文箇所の参照1個に限る。累積文書は基本記号467、定義671、文129で、正規形175,635文字となった。親文書からの増加は1,734文字であり、これは定義を含む文書長であって一文の翻訳長ではない。

原文の明示範囲は48文字増え、前回除外した基準系の記号M0249も対応へ追加した。部分草案の文字範囲は13,043/35,614文字（36.62%）となった。原刊照合、基礎概念、全空間での回答条件の充足、原文の意味一致確認は残る。両作品の意味確認済み区間数は0のままである。
