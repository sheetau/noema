# 遠方の波源と原点近傍の近似

u0179は、系Kに遠方の電磁波源を置き、原点を含む空間部分でその波を十分な近似によって表示式で表す、という仮定設定である。befinde sichとdargestellt seiを同じ設定の仮定提示として読み、実験実施や実在源の発見を述べる文にはしない。

既存のseaw/seaxは光信号cfと横波の振幅条件seajを含む。その全体を流用すると、今回の表示する波形だけに別の条件を追加してしまう。今回は正弦・位相・六成分の構成sd24/sdx2、全領域の誤差seat、校正された物理的な場ejsnを再利用して、源と同じ電磁過程への帰属、空間部分、用途上の十分性を結んだ。

## 局所領域と距離

空間部分spaceは球形に限定しない。正の内半径より原点に近い点を全て含み、外半径の内側に収まる集合を、正の長さの時間区間にわたって固定する。ekat/ekavがこの空間条件、ekauが同じ空間部分と時間区間の積である四座標領域を構成する。原点を含む一時刻の集合から全期間の包含を推測するのではなく、採用する局所的な読みの条件を明示している。

sehr ferneは、この空間部分の外半径に比べて、源の全ての関連位置が非常に大きい倍率以上の原点距離にあるという読みを採る。ekawは三空間成分による距離二乗を、外半径と倍率の積の二乗と比較する。時間成分を距離へ混ぜない。ekaxは物理的な源の関連支持範囲を非空とし、全点にこの条件を要求する。代表点だけが遠い配置を全体の遠さにしない。

倍率の具体値は原文にない。1より大きいという数値条件だけで非常に遠いとはせず、用途の同じ文脈における程度基準eisrvも要求する。源を一点又は静止した物体に限定せず、源の物理的支持範囲eisrtを数値関数から勝手に認定しない。

## 波源・物理場・近似

eisruは源が外へ伝わる振動的な電磁過程を発生させ、その同じ波が対象領域の二場に対応するという物理的帰属である。静電場や任意の正弦関数だけでは、この帰属を満たさない。特定の放射機構・可視周波数・点源・球対称性・源の静止は語義に追加しない。

ekayは共通位相と正弦から六成分の近似場を作り、同じ実際の二場が全領域で指定する二誤差以内にあることを要求する。誤差の数値は補わない。eisrwはその二上限が同じ波・領域・用途・単位で十分とされることを別に指定する。遠い源や有限の誤差上限だけでは、十分性を認定しない。

ekazは幾何学、源、同じ過程と二場、校正単位、波形、誤差、十分性を共有する。場の単位は先行の規約と同じく電気側換算1・磁気側換算1/Vで物理作用へ結び、長さ時間尺度は既存Vの速度単位に対応させる。真空や横波関係、全場の方程式を表示波形だけの条件に加えない。

ekbaはK・V・第七節を固定し、残る値を一つの設定として存在量化する仮定内容である。ekbb–ekbdは著者の仮定提示と、コロンで後続のM0320へ示す参照を本文に接続する。表示式そのものの個々の記号と全数式の意味確認はu0180で別に行う。第七節見出しu0178も未完であり、節への参照記号だけで主題を表せたとはしない。

## 検査の限界

局所幾何学は正確な有理数切断を使い、原点の欠落・外側へのはみ出し・区間外・三空間成分と時間の違いを検査する。全量化の接続は小さな区別可能な域で調べ、全実数・全関数域を有限標本へ交換する評価は拒否する。多数の存在証人は一つずつ量化へ残して点検し、残る証人を固定する。

波形の接続検査では、位相の計算と六成分の共有を調べるために明示した関数を使う。この診断用関数を正弦と認定しない。正弦の数学的規約・物理場の規約・誤差の全領域条件は保存済みの検査証拠と照合する。原文全体の読解判断は検査の通過とは別である。
