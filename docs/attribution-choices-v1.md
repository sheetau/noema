# 著者帰属の候補と、採用する記述

原文の解釈が複数残る場合に、著者への帰属を一つへ勝手に固定しないための構成を追加した。既存の引用、有限列、論理結合から定義し、カントの草案では既存の主張帰属関係`uc`を使う。候補の生成や順位付けは行わず、候補と採用する記述を人が明示する。

特に、次の三つは別の命題である。

- Aへの著者帰属、Bへの著者帰属の少なくとも一方が成立する。
- AとBの双方について著者帰属が成立する。
- 「AまたはB」という一つの内容について著者帰属が成立する。

たとえば「AまたはB」としか述べていない著者に、Aを単独で主張したともBを単独で主張したとも帰属できるとは限らない。逆に、Aへの帰属があっても、語句と記述に敏感な帰属関係では「AまたはB」という別の記述への帰属を自動的に追加しない。いずれも、内容の真理を判定する条件ではない。

| 定義 | 内容 |
| --- | --- |
| `rj4` | 非空の候補列の少なくとも一つについて、同じ箇所・著者・文脈への帰属が成立する |
| `rj5` | 非空の候補列の全てについて、同じ箇所・著者・文脈への帰属が成立する |
| `rj6` | 明示的に採用した記述が候補に含まれ、その同じ記述への帰属が成立する |
| `hzdy` / `hzdz` / `hzd2` | 上の三条件を既存の著者主張の関係`uc`へ接続する |

候補列にあることだけでは、その内容を著者に帰属できるとは認定しない。帰属が成立するという情報も別に必要になる。また、内容が同じ別名の記述であっても、列に入っていない記述を採用済みの候補へ移さない。候補の順序と重複は列として保存するが、重複を票数や信頼度へ換算しない。空列は「全候補の帰属が成功した」とは扱わない。

カントu0013への接続例では、前版の改善不能・将来・因果・目的付き宣誓を含む同じ政策に対する、全称的な禁止と積極的許可の欠如を候補とする。候補の内部には実際のNoemaの構成を保持し、政策の内容を未説明の基本記号へ置換しない。帰属だけを評価する場合は、規範の真理、実際の契約成立、目的の達成を実行評価しない。

この二候補が原文の全ての可能な読解を尽くすとは主張しない。権能の欠如など他の候補も残り、今回の候補から一つを自動選択する規則は置かない。著者の局所参照・文章箇所・文脈も引数で指定し、冒頭段落用の文脈をu0013へ流用しない。

一般例と原文側の例では、二つの個別帰属と内部選言の帰属の八通りを検査する。著者・箇所・文脈の差し替え、列の並べ替え・重複・空列、候補外の別名への既知の帰属も比較する。未知の帰属関係を偽として埋めず、評価を拒否する。

[一般文書](../examples/v014/attribution-choices.noema)は512文字、[原文付き草案](../examples/v014/kant-attribution-choices.noema)は141,989文字、[抽出文書](../examples/v014/attribution-choices-core.noema)は14,864文字である。六定義を追加し、原始記号と著者主張は追加していない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-attribution-choices-basis-v1.json)と[検査記録](../reports/attribution-choices-v1.json)を保存する。

関連11テストが通過した。三文書のCLI解析結果は構文木と一致し、通常表記・簡略表記・独自文字v2の往復を確認した。抽出文書のSVGはXMLとして検査し、字形の視覚検査とは区別する。進捗集計は210件の対応表と457件のNoema文書を対象とする。

これは帰属の候補と採用条件を表す構成であり、原文に適合する帰属を確定した結果ではない。原文の一意の解釈、代表資格、規範の根拠、基礎概念の意味、啓蒙全体の進展と全文の意味確認は残る。既存の主張帰属自体の基礎説明も引き継ぐ。
