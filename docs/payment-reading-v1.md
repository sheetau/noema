# 支払いと他者の引受けを述べる一文

カント第二段落の「支払えさえすれば自分で考える必要はなく、他者が煩わしい仕事を引き受けるだろう」という一文を、[現在のNoema本文](../examples/v016/kant-payment-reading.noema)へ通して照合した。原刊482頁の128文字・109非空白文字を十一範囲に分け、文5と追加した文43に結び付けた。この一文について、以下の読解の下では対応すると判断する。アシスタントによる読解判断であり、自動的な証明や独立査読ではない。

前版には、支払能力を前件とし、本人の思考なしの達成と将来の引受けの見込みを帰結とする内容がある。ただし、通常の条件提示と「この条件だけで足りる」という限定の提示を区別する項目がなかった。今回追加したhzxlは、同じ箇所・提示者・文脈で、指定前件を指定帰結に十分な条件として取り立てる扱いを表す。金銭やドイツ語の語形は引数に含まず、資格があれば入場に足りると述べる別分野の例でも使える。

本文への接続hzxmは、既存のt3の提示と、支払能力tpから本人の思考なしの達成tqに足りるという限定を結ぶ。本文の前の43文、定義、意味規約は保持し、提示を表す一文を末尾へ追加する。条件の内容を必要十分条件へ変更しない。背景の文脈を取り払うことや、支払不能なら必ず思考が必要だとすること、他の達成手段を排除することは、この限定からは従わない。

歴史的用法として、[Adelungのnurの項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_2_1_1192)には条件を示す用法があり、除外・願望などの用法とは区別される。[schonの項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_7_2_2627)には、先の発言を受けた確言と将来についての確言の例がある。後者は現在のtwとriが表す、確信を伴う将来の見込みという読みに対応する。辞典だけで、この文の解釈が一意に決まるとはしない。[出典記録](../data/payment-reading-evidence-v1.json)には取得本文とハッシュを保存した。

照合では、次の範囲を固定した。

- 一人称は前文から続く仮定例の話者であり、著者の自伝的事実や全員への断言にしない。
- 思考の不要は、同じ実用上の用事を処理する方法の経路に、本人の対象となる判断が含まれないことと読む。思考不能、全ての心的活動の停止、単なる不実行とは区別する。
- 支払能力は、その仕事の必要対価を賄う方法があることと読む。部分払いと必要額の充足、能力と支払い済みを分けた前版の定義を使う。
- 後半の見込みは、同じ支払い仮定の下で、その状況を基準とする未来へ結ぶ。独立した後続文とする別読解もあり、セミコロンだけを作用域の証明とはしない。
- 煩わしいという評価は仮定上の話者の視点へ結ぶ。仕事は前の判断の仕事を受け、引受け手と受益者を混同しない。
- 他者は不特定の人による引受けとして読む。全ての候補で同じ一人、全員、固定人数は要求しない。引受けの見込みから実行や完了を推論しない。

検査では、別分野の提示と内容の真偽を変えた16組合せ、提示の結合11対照、現在の内容と限定の提示を独立に変えた8対照、予想候補と引受け手の12対照を評価する。前版の34対照は入力ハッシュが一致し、今回の内容照会文書が前版と同一であることも確認する。新しい提示から支払能力や予想内容の真理を導かず、未知の情報は補わない。通常評価、既存十一単位の意味依存関係、完全形・短縮形・固有文字の往復も確認する。

[読解記録](../data/payment-reading-v1.json)は全十一範囲と採用した文脈を示し、[検査報告](../reports/payment-reading-v1.json)は固定した入力と結果を示す。公開した基本関係の解釈に依存する判断であり、価値・取引制度・心理・限定の提示の全内部構造まで定義展開したものではない。綴りの復元、皮肉の全効果、第二段落全体の議論は今回の判断に含めない。

一文の確認を段落全体の確認として加算しない。全単位の確認済み分量はカントの1,001非空白文字、約6.45%のままである。次は後見人が未成熟を維持させる後半の記述を確認し、第二段落全体の読解へ進む。
