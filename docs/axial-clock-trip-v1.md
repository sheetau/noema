# 軸上の光往復と、運動系の時計の中点条件

アインシュタイン§3の `u0049` と `u0050` を部分記述した。運動系の原点から出た光が軸上の地点で反射し、同じ原点へ戻るという設定と、その三つの時計の読みが `½(τ₀+τ₂)=τ₁` を満たすという著者の推論を分けて保存する。

`siu` は一つの試行について、同じ光、出発・反射・帰着の三出来事、二つの時計、場所、基準系、単位、文脈を結ぶ。原点の時計で出発と帰着を読み、別の反射地点の時計で反射を読む。両時計が配備され静止し同期していること、読みがその系の局所時刻に一致すること、時刻が厳密に進むことも要求する。軸上の端点だけでは経路全体が軸上とは限らないため、伝播経路の支持線を指定する関係 `zdw` を加えた。

`siv` は同じ出来事の静止系の座標から補助量 `x-vt` を作り、`siw` が出発・反射・帰着をそれぞれ `0・x′・0` に結ぶ。yとzは0である。運動系の測定座標ξをx′へ代入せず、運動系の時計の読みτをこの演算のtへ代入しない。`six` はこの座標条件と時計の試行を、共通の速度・単位・文脈で接続する。

原文の非退化な往復は、異なる出発・反射地点、非零のx′、三つの異なる出来事、厳密な時刻順序として解釈した。原文がここで方向を明示していないため、x′を正に限定していない。X軸の記号は先行配置で共通になる軸の支持線に接続しているが、その一般的な配置の整合性と原刊の字面は未確認である。

`siq` は有理数の中点式、`sir` は指定された加法と値一致を使う二倍の式である。`sis` が後者を実切断に接続し、`sit` は実切断の加法・正の尺度変更を使って原式の半和を構成する。中点式だけなら、逆順の読みや同じ時刻も満たせる。光往復の順序は試行の条件として別に保存する。

仮定した設定は `siy`、結論の式は `siz` という内容として引用する。著者の仮定を `ug`、その仮定から式が必要だと述べることを `zc` で記述した。引用だけで内容を実行したり、物理的な導出が検証済みであると扱ったりしない。

新規8件を含む関連36テストが通過した。原文接続36例、中点式7例、同期範囲7例、帰属7例を検査した。帰路で光が変わる、別の時計で帰着を読む、反射や局所時刻が欠ける、軸の割当や経路が違う、静止系時刻をτへ代入する、出来事の座標を交換する、といった変更を検出する。

同期範囲の検査では、選択した一往復が中点式を満たしていても、別の対象試行が失敗すれば同期条件を満たさない。逆に、選択した試行が対象範囲から外れていれば、他の試行による同期判定をその試行へ適用できない。元の `qo`・`qn`・`db` の範囲と接続は評価するが、物理的な試行条件と実数の演算には検査用の解釈を与える。

有理数の代数的検査では、中点式と差の等式、中点式と二倍の式、共通の非零尺度と原点の変更による条件の保存を確認した。中点式だけから時刻の順序が従うという主張と、反射側の時計の原点だけを変えても条件が保たれるという主張には反例を得た。実切断全域での同値性や物理的な一般定理を、この有理数検査で証明したとは扱わない。

有限検査の数値は構成済みの整数切断である。原文接続の検査では、先行実装の同期判定・局所時刻・静止系の座標取得を検査用の関係として与える。このため、結合条件が誤った引数を受理しないことの証拠にはなるが、実空間・実時間全域での整合性の証拠にはならない。
