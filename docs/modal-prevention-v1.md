# 許容欠如を慎重な働きかけの結果へ結ぶ

カント第二段落の `sorgfältig verhüteten, daß ... wagen durften` を通して確認したところ、本文に余分な非試行の条件が残っていた。従来の構成は、実際に試みない状態を生じさせる原因行為と、その非試行を目指す注意を要求し、さらに同じ局面の許容欠如を加えていた。

しかし[既に採用した許容の規約](unpermitted-undertaking-v1.md)では、許されなかったことと、実際に試みなかったことは別である。今回の修正はこの区別を本文全体へ一貫して適用する。否定された許容を含む従属節を、慎重な働きかけが対象とする結果へ置く。これは既存の許容読解に沿う範囲の修正であり、原文の実行機会や能力に関する全ての読みを同時に採るものではない。

`r2ah` は同じ本人への既存の許容欠如を、`r2ai` は注意や目的へ渡す同じ内容を表す。`r2aj` はその内容への分担された注意を要求し、`r2ak` は実際の原因行為とその結果、同じ行為の注意を結ぶ。新しい基本関係はなく、既存の許容・原因・参加・目的・注意の構成を使う。

| 条件 | 従来の本文 | 改訂した本文 |
| --- | --- | --- |
| 許容欠如を生じさせ、本人は試みなかった | 成立し得る | 成立し得る |
| 許容欠如を生じさせたが、本人は試みた | 不成立 | 成立し得る |
| 非試行を生じさせたが、許容欠如への寄与はない | 成立し得る | 不成立 |
| 許容がある | 不成立 | 不成立 |

いずれの成立にも、先行する理解不足の原因行為、同じ対象者への後の危険提示、同じ行為に結び付いた目的と注意など、他の条件が必要である。単に許容が見つからないことを、誰かが許容欠如を生じさせた証拠にはしない。また、許容欠如を明示的禁止や実行不能へ読み替えない。

同じ結果を指すよう、複文の主張と、身体的な一歩・落ち着き・強調・閉じ込めへの対応をまとめて改訂した。変更する本文は35・36・47・48・49文（ゼロ始まり）の五文。本文全体は50文のままで、他の45文、既存の宣言・意味規約、十一単位の意味確認の選択は保持する。閉じ込めを先行局面へ置く前回の修正と、身体側の既存の定義も保持する。

許容の出所と対象行為は、この用例の `db`・`hztd`・`bb` に明示的に固定する。原因行為の行為者群は別引数であり、本文では同じ `db` を渡す。行為者を変えたとき、規範の出所まで暗黙に変わる略記ではない。

五テストに、許容・実行・規範への原因関係の8組合せ、原因・注意・目的・本人・時点の9対照、実際の試み等を未知のまま評価する検査、必須の未知情報4種の拒否、七文の提示に対する8対照と未知対応3種の拒否、三記法の往復を含める。新旧の本文を実際の定義から評価し、新しい本文の依存先から非試行 `hzsm` が除かれたことも検査する。

未知入力の検査では、対象者の選択に必要な既存の危険評価の事実を維持する。その上で、実際の試み・勇気・成功と、条件付き警告の場面範囲を未知にしても新しい複文を評価できることを調べる。全ての危険関係を一括して未知にした検査とは区別する。

原文対応は既存範囲内の `[981,1114)` で、新しい文字数は加算しない。複文全体の意味確認、段落末尾と段落全体、二作品全文は未完了である。有限モデルの検査から、原文との意味一致を自動認定しない。
