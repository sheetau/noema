# 同体積を仮定する第二文

u0203[164,389)の第二文を、先行する平均密度の説明から同体積の仮の計算へ進む文として記述した。正本は `examples/v014/einstein-equal-volume-supposition.noema`。原刊913頁でM0351=A′²/A²、M0352=K、M0353=kを照合した。

「特定の光の集合」は、直後に移動球面で具体化して追う同じ光の部分zvaaを指すという文脈を共有する読みである。新旧の同時断面・単位・平均密度・総量を既存ekmiへ結び、平均密度と体積の積の関係ekmjを保つ。光子の個数や新しい実測を補わない。球の例に依存しない一様密度の代数規則ekmmは別に保持しており、比の計算を球だけの法則とはしない。

「もし体積が同じなら」は、実際の新系体積を訂正する主張ではない。ekmpで独立な比較値hypovolumeを旧体積に等しく仮置きし、ekmnで同じ新系密度から比較総量を計算する。実際のnewvolume/newenergyはそのまま残す。ekmtは比較した二総量を同じ密度の説明へ結び、ekmqがその新旧比を述べる。旧側の分母は正とし、比はE′A²=EA′²で記述する。

この分離により、実際の体積が異なる場合にも条件文を評価できる。検査の有理数標本では、旧体積8、新体積32/5、旧総量100/3、新総量125/3を保持する。新系密度625/96のまま比較体積を8とすると、比較総量は625/12となる。仮の総量比25/16は二乗振幅比に一致し、実際の総量比5/4とは異なる。これは値の接続を調べる標本であり、検査用pi=3/4を円周率と認定するものではない。

ekmsは、各有効な物理的設定について旧体積そのものを比較値に使う構成を示す。ekmrは同じ65役割と比較体積を全称量化し、等体積の比較なら同じ値の比が得られるという条件内容を述べる。実際のLorentz体積比と等体積の仮定を同一の値に同時に課して、前件を空にする構成ではない。

著者がこの比較を思考上の構成として扱うことを既存eislzへ、daherによる先行密度からの帰結提示をzcへ、条件文の主張をuhへ結ぶ。新たな一般関係は追加せず、追加した原始記号は第二文箇所の参照一件だけである。全ての物理法則を保持する最類似世界の一般理論としての反事実条件ではなく、この議論で密度を保ち体積について仮置きする条件付き計算という読みを明示する。

第二文の本文174非空白文字と数式等3要素を通読判断した。第一文の127文字・2要素と合わせて301文字・5要素になるが、u0203全体の確認済み件数には加算しない。「実際はそうでない」の一般性、球面を挟む無流出入と同じ光の集合、新系エネルギーの問いと言換えは残る。
