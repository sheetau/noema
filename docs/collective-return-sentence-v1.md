# 第十段落第四文の全体接続

`Wenn denn die Natur` から末尾の注標識までを、第三文と同じ制度比較に関する条件的な経過として接続した。同じ非空の全比較組ごとに、結果から選び直さない非空の全事例を指定する。各事例で、原因側の全員について二性向の発達がそろえば、その後に民衆の心的・能力変化を確認する点と、さらに後の政治的な評価点がある。前件が現実に成立する事例の存在までは断言しない。

前件の芽・自然・硬い覆い・優しい世話は、既存の植物描写と対象側の二性向の発達を結ぶ比喩として保つ。覆いは同じ比較の低い市民的自由の側、芽は同じ民衆に属する固定された原因側の人々の二性向の組である。原因側は民衆全員とは限らず、各人の発達開始も同時とは限らない。共通起点までに発達がそろうという採用した集合的な読みを明示した。

後件では、同じ民衆への心的反作用、その変化を介する行為能力の増加、同じ原因による後の政府原則の採用変化を結ぶ。原則変更が対照側で全て消えること、旧原則撤回と新原則採用の両方、民衆の変化による完全媒介は要求しない。`endlich` は後の評価点とし、心的変化の完全終了や政府作用の初発を補わない。

同じ政治的終点で、同じ政府が尊厳に応じた扱いを政府自身にも有益と判断し、同じ全人間成員が自分の理由による行為能力を持つことを結ぶ。後者を政府の信念内だけに置かず、政府の誤認だけで能力を成立させない。尊厳の対象を能力成功者に限定せず、利益判断から実際の利益・方針採用・履行を導かない。

`denn` は先行説明の継続、括弧は同じ条件内の因果的補足、`auch` は作用先の追加、`sogar` は予想しにくい先まで及ぶ強調として、内容と別に提示する。`dieser` は芽の同格で説明した二性向、`dieses` は同じ民衆を指す。`selbst` は同じ政府自身も受益対象であることを強調する。各提示には同じ条件量化内の対象・時点の内容族を渡し、引用の真理を実行しない。

末尾の標識は、既存の論説・標識・著者注u0020・著者表示への接続をそのまま使う。注を直前の一文だけの理由に限定せず、別単位で確認済みの内容を本文へ重複加算しない。先行122主張と既存判断を保存し、この一文の帰属を一主張として追加した。

固定原文の383非空白文字を14範囲と全体で通読した。二性向、漸次変化、能力、構造的因果、尊厳、利益比較の採用解釈と限界は各依存群から引き継ぐ。これは明示した解釈でのアシスタントの意味判断であり、局所検査による自然言語との同義性の自動証明でも、哲学上の主張の真理の証明でもない。第十段落の四文全体の確認は別記録とする。
