# 愛着の強調と、現在の不能の接続

第三段落第二文について、愛着の取得と、過去に試行を許されなかったことによる現在の不能を、一つの内容へ接続した。旧第12・13文の別々の部分帰属を置き換え、第一文と同じ人物範囲を保つ。本文は52文のままである。第二文全体の意味確認はまだ完了していない。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)

## 同じ人について二つのことを述べる

新しい `r2ee` は、同じ本人の愛着の取得・保持 `r2ck` と、過去の試行の許容不在から現在の行使不能への因果 `r2cg` を併記する。`r2ef` は第一文の非空の人物範囲を使い、これを各人へ結ぶ。一人が愛着を持ち、別人が不能であるだけでは、この文を満たさない。

未成熟への愛着が、不能の原因だという因果は加えない。また、ここでの「自分の理解力を使えない」は、他人の指導があっても使えないという行使能力の内容である。第一文の未成熟に使う「他人の指導なしでは使えない」とは区別する。現在の不能を述べることから、将来の訓練による回復や永続的な不能も決めない。

## 強調する内容の範囲

`sogar` は、期待や評価の尺度に照らして焦点を位置づける働きを持つ。焦点になり得る範囲は単語だけでなく、より大きな表現にも及ぶ。今回は「愛着を持つようになった」を焦点とし、先行する「内的な性向として定着した」という内容に比べて見込みにくいものとして提示する読みを候補にした。[IDS grammis「Fokuspartikel」](https://grammis.ids-mannheim.de/systematische-grammatik/408)

この比較対象と、各人への内容を全体として比較する作用範囲は、明示的な解釈選択である。文法資料だけで唯一の読みが決まるわけではない。数値確率や実際の驚きを加えず、期待比較の真偽も本文の事実の真偽と分ける。

| 構成 | 保持する内容 |
| --- | --- |
| `r2eg`・`r2eh` | 同じ各人への愛着の取得と、内的定着の比較候補 |
| `r2ei` | 同じ各人への愛着・不能・原因を結ぶ主張全体 |
| `r2ej` | 愛着だけを焦点とする主張と期待背景の組 |
| `r2ek` | 主張全体と、愛着だけにかかる期待背景の組 |
| `r2el` | 主張と背景を、範囲を区別して同じ著者へ帰属する |
| `r2em` | 第一文から第二文への本文順序 |

既存の主張・背景の組、期待比較、範囲付き帰属を再利用する。新しい一般的な基本関係は追加せず、追加した三つの基本記号は本文箇所と範囲への参照である。

## 検証と未完の範囲

人物の結合と量化は、二人の愛着・不能の原因・内的定着を独立に変える64組合せで検査する。この試験では内容の境界を単純な述語へ置き換えており、世界内容全体の同時実行とは区別する。取得・能力・因果の実際の定義については、既存の有限モデル検証とその依存定義・意味資料が保存されていることを確認して再利用する。

二内容間の全16比較関係と、愛着・不能の原因・内的定着の真偽を変える128組合せでは、期待背景と事実の独立を確認する。主張だけを否定しても背景を保つ。同順位、比較不能、逆向き、反射性の欠落を区別し、未知の比較を偽へ補わない。帰属には別の著者・箇所・文脈・範囲、主張全体を焦点へ取り替える誤り、比較対象の取り替えを含める。

`wirklich` の確認的な強調、`vor der Hand` の語用、単数人称と各人への一般化の読みは引き続き確認する。したがって、この接続候補を第二文の意味確認完了とは数えない。第一文108非空白文字の意味判断と、十二全単位2,212文字の判断は保持する。

部分草案の対応範囲は、従来別々だった二範囲を結ぶ接続詞と句読点の五文字だけ増える。これは表現率や意味一致率の向上を示す数字ではない。
