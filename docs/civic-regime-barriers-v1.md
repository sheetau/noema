# 同じ市民的制度による判断課題への制限

第三文の「越えがたい制限」を、同じ人・同じ判断課題の機会を市民的な制度条件が閉ざすという、明示した因果モデルへ接続した。二制度の許可集合と判断課題は[自由の比較](civic-intellectual-options-v1.md)から保持し、[有利に見えること](civic-advantage-appearance-v1.md)と同じ比較起点に置く。

因果モデルの要因が真なら高い側、偽なら低い側の制度条件を選ぶ。各介入解に対応する状況で、選んだ法秩序が同じ共同体の公的な制度として運用され、その全成員・全関連行為への許可集合が、先に固定した同じ側の集合と一致することを確認する。観測された状態だけが一致していても、別の解で集合が増減していれば通らない。

制限には、低い側へ介入した少なくとも一つの解では同じ判断課題を達成でき、高い側へ介入した非空の全解では、全方法の整合した評価の下で達成できないことを要求する。既存の構造方程式と評価済みの不能の定義を再利用した。高い側の観測割当てについても、元の方程式への適合、要因の真偽、対応する現状とその不能を確かめる。

越えがたさは、指定された制度条件・方法・評価範囲に相対的な読みである。利用できる方法がないと評価できた場合と、方法があるが結果を評価できていない場合を区別する。後者を不能には数えない。全精神活動が不能だとはせず、制限が及ぶ対象として指定した非空の人・課題の全組について条件を満たすことを要求する。

検査では、二変数の構造方程式の全16表を独立に列挙した解と比較する。全介入解での許可集合の一致、観測の不整合、未評価の方法、対象課題の欠落、各入力の引数位置も確認する。公的な法秩序と一行為への規範的許可だけを境界とし、その不変の本体と前回までの検査を固定する。判断課題の内容、介入、方法評価、実際の不能は本体を実行する。

この群は第三文の部分構成である。見かけの利益と一部の制限は両立し得るため、`doch` の対照を論理矛盾から導かない。低い側が与える全能力に応じた展開の余地、対照・照応と全文帰属へ続けて接続する。原文の通読による意味確認文字数は増やさない。
