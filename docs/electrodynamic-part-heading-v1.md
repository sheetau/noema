# 第二部の見出し

u0151「II. Elektrodynamischer Teil.」を原刊907頁で照合した。直前には運動学の総括と応用への移行、直後には第六節の見出しがある。第二部の表示番号2と文書階層の深さ1は、次の節番号6・深さ2と区別する。

既存eihqの見出し構造に、同じ論説、第二部の区分と見出し箇所、電気力学の主題eie5を渡す。eie5は電荷輸送eibf・電気作用eibs・磁気作用eicoへ接続済みである。新しい意味定義はこの結合ejsiだけであり、追加した二つの基本記号は区分と箇所への参照に限る。第一部との区別と、u0150後半の移行からの順序も保持する。

見出しは区分全体を案内する。本文の断言や応用を示す課題の達成とはしない。第六節から第十節が下位にあることと、それぞれの内容の意味確認が済んでいることは別である。記事末の謝辞や日付表示を電気力学の物理命題へ変更せず、末尾に集められた脚注も参照位置に従って扱う。

検査は表示番号・深さ・親文書・主題・順序を一つずつ欠落・交換させ、未知入力と箇所・区分の同一視を拒否する。既存の電気力学の主題では、三つの物理的規約が同じ研究対象と文脈に渡されることを確認する。本文356主張と既存の意味規約・判断は保持する。主題の引用を有限の物理事例として実行せず、意味判断は通読による別記録に置く。

次の第六節見出しには追加の接続が必要である。旧s5yは六つの回転方程式を構成しているが、物理的な真空の条件を含まない。光の伝播経路に媒体がないeiscaを、任意の場の領域へそのまま代入できない。場の物理的な解釈にはeibs/eico、運動で生じる局所的な力/電荷の駆動にはeidz/eisasがあるが、導体・磁石の一例の条件を見出し一般へ持ち込まないようにする。「性質について」は説明対象を案内する役割であり、力の公式や説明の完成を見出しから断言しない。
