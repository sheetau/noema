# 非期待・反期待性とほとんど全ての範囲

第十段落第二文では、予期していなかったこと、理解の枠に収まりにくいこと、逆説的であることを区別する。期待は、通常の予測として積極的に採用する非空の標準候補の全てにその内容が含まれることと読む。非期待は、その一貫した肯定的な見通しが成立しないことである。単に否定しきれない稀な例外まで候補に集め、その可能性があるだけで非期待にすることは避ける。反対を積極的に予測していた場合に限定せず、空の想定や未知入力でも成立させない。

逆説性には、実際に成立する内容が、その同じ内容の否定より通常は見込まれにくい、という反期待的な読みを採る。既存の弱い見込み比較 `rqts` を使い、自己比較と推移性を確認して厳密な向きを取り出す。同順位や比較不能は反期待性ではない。内容と否定の両方が同じ点で真になるような、形式的な矛盾も要求しない。

`befremdlich` は、同じ観点で使い慣れた説明の枠組みがあるにもかかわらず、そのどれも基本的な見方の修正なしにはその内容を無理なく説明できない、という読みで構成する。これは期待の成否とは独立している。実際の驚きの感情、説明の永遠の不可能性、歴史上の著者の伝記的な心情までは追加しない。

`fast alles` は、全てではないが例外が少ないという読みを採る。評価対象の全関連側面を、非空で重複のない正確な有限列として与え、その内容が実際に成立することを確認する。例外数は正であり、あらかじめ決めた小さな許容比率と全数の積より小さくなければならない。単なる過半数や全件成立とは区別し、対象の粒度・分母・上限を結果に合わせて変更しない。数値の具体値は原文へ追加しない。

八定義と八つの文脈入力を構成した。期待候補、見込み比較、説明枠、対象範囲・列・上限はそれぞれ独立に固定する。第一文の具体的な対比との内容対応、人間の事柄の推移、全体として捉える考察条件、一般的な観察者、接続と全文帰属は続けて統合する。この依存群の検査だけでは、第二文の意味確認文字数を増やさない。
