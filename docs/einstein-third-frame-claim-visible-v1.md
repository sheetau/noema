# 第三座標系と二回の変換を円文字へ接続する

原刊901頁のu0093–u0094を、第49段落の三文として参照する。第一・第二文は第三系K′の導入と三原点・零時刻の設定、第三文は座標の命名から四つの連鎖等式の末尾句点までを含む。

既存29定義を再利用する。第三系はKともkとも別の系として導入し、kに対する縦方向の速度−v、全固定配置の並進、全比較時点での原点の横座標零を保持する。三原点と零時刻は同じ基準出来事へ結ぶ。この出来事を光の放出に限定しない。

二回の変換は、同じ出来事に対する同じ中間の座標記録を使う。対象出来事の範囲は非空で、その全体について三系の記録の存在と座標値の一意性を要求する。同じ値を持つ別記録は許す。四つの中間式と四つの最終式をともに保ち、最終倍率はφ(v)φ(−v)とする。倍率1、φの偶関数性、KとK′の恒等変換は先取りしない。

導入の目的は、直前に表明した同じφを決定する意図を受ける。導入行為は記述するが、目的達成や引用された物理的結論の真理を含意しない。x′・y′・z′の三つの新しい命名と、t′を含む四つの表記の解釈を区別する。以前の補助変数x′と第三系座標を同一視しない。

第三系と基準出来事には既存の役割付き参照を使い、五つの呼称には既存の名称参照を使う。参照を得る際に役割や物理条件を実行しない。共通375語とアルファベットを維持し、任意プロファイル55は796語となる。追加する7規約は採用済みの物質軸・幾何・目的・命名の意味を公開するもので、物質の基礎説明や物理的測定と方向の接続を新たに証明したという意味ではない。

検査は原文への逆投影、実際に復号した定義の有限対照、参照引数と引用の非実行、円文字の独立復号、描画点検を区別する。量化の引数結合を小さな領域で診断しても、一般実数域の証明や第三者読解の完了とはしない。
