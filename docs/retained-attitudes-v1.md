# 好むようになったことと、そこから抜け出す難しさ

カント第三段落に、未成熟の状態を好むようになったことと、そこから自立へ向かう活動の負担を部分的に接続した。前回の現在の能力不足と過去の許容不在による説明も、同じ人物と文脈へ結ぶ。新しい基本語や構文は追加していない。

## 取得と現在までの持続

一般定義 `raf` は既存の時間順序 `ta` と変化 `th` を再利用する。一つの実際の過程が、同じ人物について同じ性質の不成立から成立への変化を結び、その人物が変化を受ける。その後端から現在の基準状況まで、その性質が持続することを要求する。

現在の状態だけでは、取得したことを表せない。また、変化の直後と現在に状態が成立していても、間に失われた状況があれば、この同じ取得から持続したという条件にはならない。履歴の外の出来事、別人が受けた変化、別の過程も区別する。未来までの永続や、唯一の取得時刻、心理的な変化の機構は要求しない。

この一般形は態度専用ではない。性質と変化・対象の関係を引数で指定し、取得後に保たれる他の状態にも使える。前状態の偽は意味上の否定であり、記録の欠落を偽とする処理ではない。実世界の履歴が十分に調べられていることは、今回の形式条件とは別に確かめる必要がある。

## 原文との関係

対象は[アカデミー版電子本文第36頁](https://korpora.org/kant/aa08/036.html)にもある第三段落の冒頭である。原文の固定版と対応位置は[検証記録](../reports/retained-attitudes-v1.json)へ保存した。今回、原刊画像の照合は追加していない。

「好む」の部分には既存の好ましい受容を使ったが、情緒的な愛着まで説明し終えたとは扱わない。「ほとんど本性となった」という修飾も、状態の持続や習慣だけへ置き換えず、未記述の意味として保持する。

活動の負担には前段落の `uy` を再利用した。これは活動に対する評価であり、成功できないことや、全ての手段が困難であることと同一ではない。現在未成熟にあることは要求するが、自責的な原因 `bd` は付け加えない。愛着を能力不足の原因にする条件も追加していない。

原文の一般化、推論としての接続、強調、自己による作業の機構や程度、自然・習慣・愛着の基礎説明は残る。今回の原文範囲にもこれらの未記述要素が含まれる。部分草案の範囲を拡大したことを、その範囲の意味を全て保存した結果とはしない。既存の8主張は変更せず、新しい無条件の本文主張は追加していない。
