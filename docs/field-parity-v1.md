# 磁気成分を使う比較例と、符号・大きさの応答

アインシュタイン1905の著者脚注u0282を部分記述した。X=Y=Z=L=M=0、N≠0という同じ場の値を保ち、速度vを−vへ変えたときのY′を比較する。場が全領域で一定であることは要求しない。

## 応答を分ける

[一般用文書](../examples/v014/field-parity.noema)は、比較条件でのY′を `−factor×β×(v/V)×N` として構成する。`saz2` は二つの値が厳密に反対の符号を持ち、大きさが等しい条件である。[論文文書](../examples/v014/einstein-field-parity.noema)の `sba2` は、これを実数値と絶対値で表す。

同じ大きさでも符号が変わらない場合、符号が変わっても大きさが異なる場合、応答が零のままの場合を区別する。原文の「numerischen Wert」は、符号変更との対比に従い、絶対値として読んだ。速度自体もvと−vを比較するので、その絶対値を保つ。

`sbe2` は、静止系に割り当てた場と領域の同じ点で、五成分の零条件とNの非零条件を要求する。`sbf2` は、その点の同じNについて速度の符号を反転した二つの応答を比べる。βと係数関数も両方の速度に対してそれぞれ評価する。

脚注の応答は著者の要求として記録する。先行する逆係数の積1と比較条件を前提として明示し、その応答を採用した場合の係数の偶性への推論も追加した。物理的対称性そのものを、単なる算術定義から導いたとは扱わない。

## 非零条件と残る負の枝

v=0やN=0では応答が零となり、係数が異なっていても見かけ上の符号反転の等式を満たしてしまう。この比較例は非零の速度と磁気成分に限定した。v=0における係数の偶性は、同じ関数を同じ引数で評価する恒等関係であり、非自明な符号反転実験とは別である。

非零の比較では、二つの応答が厳密に反対の符号で同じ大きさなら係数が等しいことを、有理数の一般式で検査した。それでも係数が正だとは決まらない。両係数が−1の場合も今回の条件を満たし、先行する正の枝の課題は残る。
