# 軌跡の二階微分としての座標加速度

前段の質量係数式で入力にしていた加速度を、同じ対象の座標時刻による軌跡の二階微分へ分解した。既存の実切断・極限・微分・履歴を組み合わせるため、新しい文法演算や意味の原始関係は追加していない。

最初に、選んだ時間領域内の全ての有効な時刻で、速度関数が位置関数の一階微分であると定める。その関数を、領域の両側内点でさらに微分して加速度にする。領域は局所的に選べるため、軌跡の全期間で二階微分可能であることは要求しない。一方、孤立した観測点や一方向だけの領域を通常の両側微分の根拠にはしない。

この区別により、指定時刻の速度だけが一致する別の関数を、そのまま二階微分へ使うことを防ぐ。たとえば位置を `1+3t+t²` としたとき、速度は `3+2t` である。候補 `3+99t` は時刻0では同じ値になるが、近傍で位置の微分と一致しない。後者を微分して99を加速度とする読みは認めない。

物理的な接続では、対象・出来事・座標系・座標時刻を既存の履歴へ束縛する。力の記録も同じ対象・出来事へ結び、瞬間共動系での力と静止系での加速度、両者の単位を別々に保持して、縦横の係数式を適用する。本文には引数を持つ内容構成子を収録した。これは読解候補であり、観測の存在や法則の成立を著者へ新たに帰属させるものではない。先行176文は変更していない。

検査には、登録した多項式とその係数から厳密に得た導関数を使う。未知の関数を有限個の値から多項式と推定せず、登録した曲線の座標を取り出すNoemaのラムダ式も構文を限定して識別する。履歴の完全性は明示したモデル前提である。実際の全称条件の本体を複数の時刻で検査することと、全実数上の成立を証明することは分け、全域量化の有限評価は拒否する。

座標加速度の数学的な分解は追加したが、座標の時間・長さの尺度と加速度単位の換算、力の測定の実現と種類の意味は残る。実切断の微分法則全体と原文区間の意味一致も未確認である。原文対応は前段の数値式u0255への解釈注記として記録し、対応範囲と意味確認済み区間数を増やさない。
