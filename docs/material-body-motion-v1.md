# 物質点の履歴から表す物体の運動

物体の運動を、同じ物質点の位置が指定区間内で変わることとして構成した。物体の中心や占有範囲だけを比較すると、同じ範囲を占めながら回転する場合や内部の変形を見落とす。同じ物質点の対応を保ち、全物質点それぞれに既存の軌跡定義seを適用する。

eiacは物体と全物質点の範囲を結ぶ。新しい基本関係eirhは、指定文脈でその物体を構成し、履歴を通じて追跡する物質点を表す。与えたmembersと双方向に一致させ、空の範囲や動かない点だけの選択を許さない。この入力の物理的な完全性を、測定した標本の数から推定するわけではない。

eiadは全物質点に、同じ基準系・長さ単位・時間単位・文脈・区間の軌跡を要求する。seは区間内の全実時刻に出来事があり、同じ対象の全出来事の座標が同じ三関数に一致する条件である。別の点の軌跡や、別の基準系で得た数値を取り合わせない。単一出来事の接続eiaiでも、既存sbの物質点と出来事の所属zzbv、単位付き座標zzbuを実際に使う。

eiaeは同じ点の二時刻で六つの座標値を取り出し、いずれかの成分に大小差があることを表す。eiafは全履歴の成立に加え、その点が同じ物体に属し、二時刻が同じ閉区間に入り、厳密に前後することを求める。これが運動の証人である。eiagはそのような証人の存在を述べ、eiahは全履歴の下で全点・全時刻対に位置差がないことを述べる。無効な履歴や不明な観測を静止として扱わない。

この構成では区間の両端だけを比較しない。途中で動いて元の位置へ戻る場合にも証人があり得る。等速性、並進だけの運動、剛性、微分可能性を追加条件にはしていない。瞬間速度と、二物体間の相対運動は別の定義として残す。

採用するのは、指定区間で構成を保つ物体を物質点で追跡する記述である。物質点は空間位置や原子そのものではない。原文へ接続するときは、どの記述尺度で全物質点を定めるかを明示し、静止した導体の記述へ微視的な熱運動を無条件に持ち込まない。物質の出入りや生成消滅を含む可変構成には別の扱いが必要であり、この定義だけで一般の物体の意味が完成したとはしない。

有限検査では、保持した有理数の実切断だけに正確な順序を与え、点の所属、全点への軌跡の引数接続、位置差の証人、単一出来事の座標接続を評価する。全区間のseは接続検査の境界として与える。その本体とeiag/eiahの実数全域量化は有限評価を拒否することを確認し、有限の時刻列を実数全域とみなさない。原文の一文全体への統合と意味判断は未完で、以前の207主張と著者表示の判断を保持する。
