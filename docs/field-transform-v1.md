# 場の成分の混合と座標引数の変換

アインシュタイン1905年論文のM0291・M0292にある変換後の六式をNoemaで部分記述した。場の成分を組み合わせる操作と、同じ出来事を別の座標で表す操作を分け、最後に合成している。速度vと係数βは、先行する座標変換と同じ定義を使う。

旧座標での電気側の三成分をE=(X,Y,Z)、磁気側をH=(L,M,N)と書くと、構成する混合成分は次の形になる。βは正の枝を取り、V>0かつ|v|<Vを適用範囲とする。

| 軸 | 電気側の混合 | 磁気側の混合 |
| --- | --- | --- |
| x | X | L |
| y | β(Y − vN/V) | β(M + vZ/V) |
| z | β(Z + vM/V) | β(N − vY/V) |

この表の各成分は、まだ旧座標の関数である。新座標qで値を求めるときには、速度−vの逆座標変換で旧座標へ戻し、その位置で表の関数を評価する。新旧の座標に同じ数値を渡しても、一般には同じ出来事を指さない。領域も同じ写像の逆像として変換し、領域と場が別の場所を参照しないようにした。

座標引数の変換は任意の四座標写像を受け取る合成関数として定義している。そのため、この構成はローレンツ変換以外にも使える。三成分の混合には新しい文法を追加せず、既存の関数、実数の演算、成分の選択を使った。構成した二場に既存の六式を適用すると、M0291・M0292の形になる。ここで構成した関数と、動く系で実際に測る力との同定は後続の課題である。

今回の検査で、現行草案の前提不足が明確になった。前段に表示された六つの回転の式だけでは、変換後の六式は一般に導けない。例えば静的なE=(x,0,0)、H=(0,0,0)は旧六式を満たす。V=5、v=3、β=5/4とすると、変換後の電気側のx成分は(5/4)(ξ+3τ)となる。その時間微分は15/4である一方、磁気側の回転は零なので、最初の式が成立しない。

この場の電気側の発散は零ではない。現行草案では真空の概念とその条件をまだ六式へ十分に接続しておらず、今回の反例はその不足を示す。追加すべき前提と連鎖律の検査は未完として残した。Noema本文には著者が変換後の式を帰結として提示する談話関係を記録するが、それを妥当な定理として機械的に認定してはいない。

検査には三速度・三地点を含む成分の17例、領域の逆像6例、方程式と反例7例、逆変換6例、前提の真偽の組合せ8例、帰属7例を使った。順方向の座標写像、座標を変えない流用、成分の混合の省略、四箇所の符号の誤りを区別する。逆変換では、二つの場の全成分と領域を同時に元へ戻すことを確認した。

混合の逆操作と二乗差については有理数の代数を検査した。方程式の例では、明示的に構成したアフィン関数とその線形変換だけに対する微分値の検査用関係を使う。任意の関数を数点調べて微分を認定する手続きではない。全領域での微分方程式は有限検査器が評価を拒否し、これらの例を全実数上の連鎖律や共変性の証明とはしていない。
