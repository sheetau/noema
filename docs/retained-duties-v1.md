# 発言への許可と、残る職務上の義務

カントu0015の「職務上の義務を損なうことなく」という限定へ、要求の保存と、同じ候補内での発言・義務履行の両立を記述した。発言への許可を、職務義務の免除として扱わない。

| 定義 | 内容 |
| --- | --- |
| `rp3` | 非空の選択項目すべてについて、基準文脈で同じ本人・職務への要求がある |
| `rp4` | 同じ出所・活動・記述・極性の要求が、比較文脈でも残る |
| `rp5` | 非空の比較範囲で、対象活動が成立するすべての候補に`rp4`を要求する |
| `rp6` | `rp5`に加え、対象活動が成立する候補が存在する |
| `rp7` | 同じ比較文脈で要求が残り、選択したすべての要求が履行される |
| `rpa` | `rp5`を満たし、同じ一つの候補で対象活動と`rp7`が共に成立する |
| `hzgr`・`hzgs`・`hzgt` | 保存・適用例・共充足を、既存の要求関係`h7a`へ接続する |
| `hzgu` | 同じ本人の公的役割での活動への許可と、その活動を条件とする職務要求の保存を結ぶ |

たとえば職務上はAを行い、Bを行わないよう要求されているとする。公的発言が許されても、この二つの要求が消えれば「義務を残したまま」の条件は成立しない。要求がそのまま残る場合でも、Aを行っていなかったりBを行っていたりすれば、履行条件は成立しない。

要求の保存と両立性も異なる。発言が成立する候補と、義務を履行する候補が別々にあるだけでは`rpa`は成立しない。同じ候補で双方が成立する必要がある。相反する肯定・否定の要求はそのまま保存され得るが、同じ内容について両方を履行することはできない。保存から無矛盾性を導かない。

`rp5`は対象活動の実例がない場合にも成立し得る。そのため、適用例の存在を`rp6`で別に表す。空の比較範囲は両方とも受け入れない。候補の存在は本人の実行能力や現実の発言を意味せず、基準文脈と比較文脈が時間的な前後であることも要求しない。

選択した要求の本人・職務・出所・活動・記述・極性を固定する。同じ真偽を持つ別名の記述や、別人・別職務に移した要求で保存を代用しない。原文側では発言の許可元と職務義務の出所を別々に指定できる。公的活動という意味は渡す記述の内容に依存し、型だけで任意の活動を公的発言と認定しない。

[一般形](../examples/v014/retained-duties.noema)は1,670文字、[原文付き文書](../examples/v014/kant-retained-duties.noema)は205,303文字、[抽出文書](../examples/v014/retained-duties-core.noema)は2,726文字。十定義を追加し、原始記号と著者主張は増やしていない。親の宣言と15件の著者主張を保持した。[意味規約](../data/kant-retained-duties-basis-v1.json)と[検査記録](../reports/retained-duties-v1.json)を保存する。

基準時の要求・比較時の保存・肯定／否定の履行の64通りを検査した。原文付き文書と抽出文書では、それぞれ16通りと11条件を確認した。追加20テストは許可・保存・履行の独立性、空範囲、実例の不在、候補の混同、矛盾する要求、人物・役割・出所・記述・極性の保持、引用、未確定入力、選択項目の非網羅性、親文書と原文範囲の保存を扱う。CLI解析、正規形と固有文字v2の往復、SVGのXML検査が通過した。SVGの目視確認は含めない。

選択項目が職務上の全要求を尽くすことは、今回の検査だけでは保証しない。既存の`rfh`などによる記述全域への網羅性条件と、有限の入力一覧を区別する。職務遂行を因果的に妨げないこと、実行方法の存在、法的な優先順位や制度の正当性も未記述である。聖職者・学者の資格、教理との差異、公開性、公衆による吟味の目的、原文全体の意味一致は残る。
