# 閉じ込めを同じ先行局面へ結ぶ

カント第二段落の閉じ込めの描写を、阻止と許容欠如がある同じ先行局面へ結び直した。従来は警告時点まで続く閉じ込めを独立に述べていたため、その開始が阻止より後でも両立した。新しい本文では、同じ本人・装置について、閉じ込めが先行局面までに成立し、その局面へ続くことを要求する。

警告時点まで続いたことは、この文の必須条件にしない。採用するのは、装置内に閉じ込めていた局面で、その外への試みを許さなかったという文脈上の読みである。時制に関する一般的な参考として、IDSの[Betrachtzeit](https://grammis.ids-mannheim.de/terminologie/859)は、出来事をどの時点から捉えるかと発話時点を区別している。この一般的な区別がカントの唯一の読解を証明するわけではない。短い引用と判断の限界は[資料記録](../data/prior-confinement-evidence-v1.json)に残した。

一般構成 `r2ad` は、一つの変化過程・前後端・状態を保持し、成立端が指定局面以前であることと、そこから終点までの継続を検査する。状態が不成立から成立へ変化した両端と、その後の継続範囲では評価が整っていなければならない。`r2ae` はこの構成を、既存の移動経路による閉じ込めと、同じ後見人が参加する適用過程へ具体化する。新しい基本関係は追加していない。

| 時系列 | 先行局面での成立・継続 | 同じ成立から警告まで継続 |
| --- | --- | --- |
| 先行局面より前に閉じ込め、そのまま続く | 成立 | 成立 |
| 先行局面の後に初めて閉じ込める | 不成立 | 不成立 |
| 先行局面後に解放する | 成立 | 不成立 |
| 解放後に再び閉じ込める | 成立 | 不成立 |

最後の例では、先行局面と警告時点のどちらでも閉じ込められている。しかし二つの端点の状態だけでは、同じ閉じ込めが続いたとは言えない。新しい構成は、後の再閉じ込めを前の継続へ流用しない。本文の描写 `r2af` は局面と終点を同じ先行局面に置く。より長い継続を述べる場合には、別の終点を明示できる。

非字義的な対応 `r2ag` は、先行局面の阻止・許容欠如 `rqzw` と、この閉じ込めの描写を、同じ複文の同じ本人・先行局面・基準時点へ結ぶ。本文の第36文（ゼロ始まり）を置き換え、残り49文、既存の宣言・意味規約、十一単位の意味確認の選択を保持する。本文は50文のまま。旧定義は比較と過去の成果物を読むために残す。

検査には、一般形16組合せ・10対照と未知入力5種、実際の閉じ込めの8時系列、家畜像と訓練装置を含む本文の7対照、提示の8対照と未知対応の拒否、三記法の往復を含む。世界の内容を未知のままでも、七文の非字義的な提示を評価する検査も行う。有限モデルでの検査は原文との同義性の自動証明ではない。履歴は意味上の全範囲であり、観測から抜け落ちた時点を自動的に復元する仕組みではない。

この修正が対応する原文範囲は既存の `[1073,1101)` で、新しい文字数は加算しない。家畜像・落ち着き・歩行・強調を含む複文全体、段落末尾、二作品全文の確認は残る。
