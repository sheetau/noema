# 規範的に可能な自己賦課

第六段落第六文の `könnte` を、同じ人民が同じ法を自らに課すことが、理性的な公的規律として許容される仮定を置き得ることとして構成する。現在の制度で立法権限があるか、実際に投票したかという判定にはしない。[原文の前後](https://korpora.org/kant/aa08/039.html)が、権力による承認、暫定的な秩序の可能性、啓蒙を放棄する取り決めの不許可を区別していることに基づく読みである。

`r5ep` は、全成員と全条項を保持する人民・共同体・法の枠組みと、結論に依存しない仮定経過の範囲、整合した履歴を結ぶ。`h26cf` の範囲には不成功・不許可の経過も含める。現在の統治形態や賛否は固定しない。候補の網羅性は解釈入力の責任であり、有限モデルの検査を現実世界の全候補を列挙した証明とはしない。

`r5eq` は同じ段階1の自己賦課内容 `r5en` と三対象列・固定基準を引用し、評価規範 `h26cg` から人民自身の立場 `h26ch` への積極的許可と、反対要求との非衝突を既存 `r37c`（`h245c` / `h237z`）で構成する。引用された内容の実行と資格の判定を分ける。単なる禁止の不在や制度上の効力だけでは成立しない。

`r5er` は同じ一つの候補で枠組み・資格・自己賦課 `r5em` を結び、`r5es` がその候補の存在を取る。採択活動・主体と宛先・全条項・制度的効果は先行の [law-enactment](law-enactment-v1.md) を変更せず使う。別候補の資格と採択を合算せず、新設と再確認をともに扱う。`r5et` は正確な三対象を保持する内容族、`r5eu` はその肯否を問う質問である。質問の記述を引用して提示するだけで回答を断言しない。真理表の実評価と、引用された質問を実行しないことは別に検査する。

理性的な共同意思は、この読解では全人民へ帰属する公的採択と、その同じ内容に対する規範的な資格によって扱う。全員の現実の同意や直接投票、個々の心理的な熟慮行為は補わない。[1793年の原始契約論](https://korpora.org/kant/aa08/297.html)も可能な同意と現実の賛否を区別するが、これは比較資料である。その別作品の学説全体や服従義務を1784年の本文へ追加しない。

局所検査では候補選別の結論独立性、許可と反対要求の四組、規範の引数一致、同じ候補での全構成、二候補中の一成功、別候補への分裂、新設と再確認、空範囲、全条項の欠落、三対象の順序、質問と断言の区別を確認する。構成の全接続は元の定義で実評価し、三対象列の検査と質問の真理表だけに明示した境界を置く。

第六文全体の確認はまだ行わない。`kann` による立法許容の全範囲、`Probierstein` の判断基準の強さ、`wohl`、照応と問いの著者帰属を接続してから通読する。本文101主張、登録簿v184、集計v75、確認済み文字数を保持する。
