# 同じ時計の一秒当たりの遅れ

u0125は、前の比例式から同じ時計の指示の遅れを導き、二次近似とその留保を続ける文である。Kで正の時間が経過する間に時計が示す時間差を取り、観測時間差との差を遅れとする。負でもよい座標時刻の一回の大小比較とは区別する。

観測経過をT秒、指示経過をE秒、正の進み率をf=√(1−(v/V)²)とすると、E=Tf、遅れはT−E=T(1−f)である。同じ時計の先後の局所記録対を使い、Kの差とτの差へ同じ正の換算尺度を掛ける。その尺度は全ての記録対で共通とする。

「一秒当たり」はこの関係を単位時間へ規格化した表現であり、実際に一秒ちょうどの区間を測ったという存在主張は加えない。秒は原文が指定する共通の時間基準単位として、既存の線形換算の規約へ接続する。座標単位を無条件に秒と同一視したり、一方の差だけを別の尺度で換算したりしない。

厳密な一秒当たりの遅れは1−fで、二次近似は(v/V)²/2である。「または」に続く表示は、四次以上を除くという留保の下での同じ遅れの言い換えと読む。速度比u=v/Vの零近傍で残差がO(u⁴)となる条件を保持し、両者を厳密に等置しない。全近傍で共通の定数と近傍幅を要求する量化を、有限標本へ置き換えない。

前段の全時間の原点配置、校正された表示、現在の両系記録と正の時間幅を引き継ぐ。有限検査では換算と引数の結合、数値の厳密値・近似・残差、誤差条件の量化を別々に確認する。原文にない残差の具体的な上下限は、著者の主張には加えない。
