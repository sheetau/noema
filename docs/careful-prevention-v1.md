# 慎重な遂行を、同じ原因行為へ結ぶ

[カント第二段落](https://korpora.org/Kant/aa08/035.html)の `sorgfältig` を、目的に沿って遂行上の関連事項へ注意を配るものとして記述する。[AdelungのSorgfalt項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_2_1_1145)が対象とその細部への精神の方向付けを説明することを参考にした。集団内での分担と関連範囲の具体化は今回の読みであり、唯一の解釈とはしない。

一般定義 `rqvp` は、生起した同じ行為、同じ目標記述と引数列、関連事項の範囲を固定する。その非空の範囲の全事項について、行為者群の中に、同じ行為へ参加し、同じ目標を目指し、その事項へ注意を配る者がいることを要求する。全員が全事項を担当する必要はなく、一人が全部を担当してもよい。

目標達成は条件にしない。注意深く取り組んで失敗する場合も表せる。逆に、偶然成功しただけでは注意や目的の条件を満たさない。別の行為、目標、対象への注意を転用することもできない。注意・関連性・目的が未知の場合は、判明した真偽へ補わない。

今回追加する基本関係は、注意を配る `hztj`、遂行上の関連範囲 `hztk`、引数列を保つ目的志向 `hztl` の三つである。最後の関係は既存のAIMS規約を具体化する。単語としての「慎重」を一つの基本述語へ置換せず、再利用できる関係へ分けた。関連範囲は注意を向けた事項だけから逆算しない。注意の認知的機構や持続時間の測定を全て説明したとはしない。

## 原文の阻止行為への接続

`hztm` は一個体の引数列から同じ本人を取り、試みの不成立を返す目標関数である。`hztn` は後見人群の成員、その目標、同じ本人の引数列を `rqvp` に渡す。

`hzto` は、結果を生じさせた行為を選ぶ既存 `raa` の内部で `hztn` を要求する。実際の阻止が行為Aによるもので、注意を配ったのが無関係の行為Bだった場合、両者を足し合わせて慎重な阻止とは判定しない。因果関係、参加者、本人、結果と注意は同じ行為に結び付く。

先行二段階、同じ時点の許容欠如、後続する危険提示と著者帰属を新しい候補へ接続する。閉じ込めの比喩の対象側も同じように更新する。本文二文（0起算35・36）だけを更新し、他の35文と意味確認済み九単位は保つ。合計十定義・三基本関係を追加する。一般定義だけの文書は、カント固有の参照や基本関係を持たない。

## 検証と限界

一般形では、行為の生起・二事項への注意・二人の目的の32組合せ、十二対照、五つの未知入力を通常評価で検査する。目標内容は未知のまま実行しない。目標関数を別に評価し、同じ本人の非試行という結果、列の過不足、未知の試みの扱いも照合する。本文接続の十二対照では、注意の欠落、空の関連範囲、別の行為での注意、目的や因果の欠落を区別する。七つの帰属対照では、注意・目的・因果などを全て未知のまま著者の提示を扱う。本文の時間探索は純粋な計算結果を再利用する。通常記法・短縮記法・固有文字の往復も確認する。

原文は具体的な注意事項や担当者を列挙していない。解釈で固定する範囲の全称条件を記述したのであって、有限の検査対象が現実の全事項を尽くすと認定したわけではない。穏順さ、強調、身体的描写、皮肉、学習と萎縮の接続と第二段落全体の意味確認は残る。原文対応範囲と確認済み九単位・587非空白文字は増やさない。
