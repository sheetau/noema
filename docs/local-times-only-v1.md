# 局所時間だけの定義と比較の限界

固定原文u0013第三文[561,821)、181非空白本文文字と六つの場所記号を原刊894頁へ照合する。前二文のA側・B側の時計、場所、局所的な表示と時刻付与の規則を引き継ぐ。

これまでに定義した局所A時間とB時間を、それぞれ前二文の局所規則eik4へ結ぶ。この二地点について第三文直前までに定義した時間規約はその二つだけであることと、両地点へ適用できる共有された時間規約をまだ定義していないことを別に保持する。同じ名前を二つの局所時刻表に付けるだけでは、共通の時間規約としない。

比較不能は、二地点の同じ出来事を時間的に比較する課題について、今までの規定だけで必要条件を全て満たせる手続きがないという読みを採る。各手続きの必要な規定を全て調べ、未導入の規定を隠れた前提にしない。将来の追加規定を使う手続きは、この否定の対象には含めない。

「これまで」は論述段階に限った範囲である。共通時間一般の不存在や、将来も比較不能であることへ広げない。全既定義範囲・全手続き・必要な規定と条件は意味規約を持つ入力であり、未知を空集合や不成立で埋めない。

セミコロン後を、比較不能の説明理由として結ぶ。前文の局所評価の可能性との対比、局所二時間だけと共通時間未定義との対比、引用されたA-Zeit・B-Zeitの指示を保持する。次の等片道時間による追加規定と段落全体の判断は残る。
