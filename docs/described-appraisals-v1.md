# 不利益の可能性と、危険だという判断

カント第二段落の、自立への一歩を危険だと人々が考える箇所へ部分草案を接続した。本人の判断があること、実際に高い危険があること、活動が骨の折れるものであることを別々に表す。非生成型の言語本体の拡張であり、自動翻訳器は使用していない。

原文の照合には固定済みの本文と、[Akademie-Ausgabe VIII・35頁の電子本文](https://www.korpora.org/Kant/aa08/035.html)の18–21行を使った。後者は原刊画像の確認ではなく、一部の綴りも異なるため、固定済み本文を置換していない。[読みの記録](../data/appraisal-reading-review-v1.json)に判断と未確定事項を残した。

## 合成する条件

| 定義 | 条件 |
| --- | --- |
| `rl` | 本人が、記述された活動を行う場合の可能な結果に、本人への不利益がある |
| `rm` | `rl`に加え、同じ本人・活動・文脈の危険の程度が指定基準に入る |
| `rn` | 本人について選ばれた判断候補が非空で、その全候補で指定した性質が成立する |

可能な結果と不利益は、同じ結果に関する条件でなければならない。ある結果が可能であり、別の不可能な結果に不利益があるだけでは`rl`を満たさない。程度の基準にも同じ文脈を渡す。不利益の可能性があるだけで、高危険度とはしない。

危険の程度は、数値に限定しない尺度上の対象として渡す。原文へ確率・損失額・一定の閾値を追加しない。尺度を算定する理論や、不利益の一般的な意味を確定したものではない。

判断候補は、本人が判断する際の状況の範囲である。現実の文脈を必ず含むとはしないので、現実には偽であっても判断は成立する。候補が空の場合は肯定判断としない。このモデルは、矛盾した信念や人間の認知全体を説明するものではない。

## カントへの接続

`up`は既存の自分の理解力を他者の指導なしに使う内容`bb`と、その達成能力`xd`を組み合わせる。この状態へ向かう活動について、危険`uw`と負担`uy`を記述する。活動の実行済みや、未成熟からの移行済みを条件にしない。

`ux`は、本人が`uw`の記述を認識し、同じ記述について採用した判断候補で`uw`が成立するという条件である。関数への参照、引用された記述、候補選択に同じ定義名を明示して渡す。引用の内部を実行する演算は用いない。真理値が等しい別の記述を本人が認識しているとは限らず、別名への置換は自動化しない。

`uz`では負担`uy`を通常の文脈で評価し、危険については判断`ux`だけを要求する。これは負担の挿入句を著者による説明として読む草案である。負担も本人の判断に含まれる読みや、追加を示す語の作用範囲は未確定として残す。

`u5`は、この性質が成り立つ人々の割合を数える。重複のない完全な母集団を要求し、厳密な過半数と、それより強い文脈上の程度基準を分ける。検査用の具体的な比率基準は、原文の閾値ではない。

女性全体への挿入句と、後見人がこの判断を生じさせるという主節は未記述である。新しい従属節の内容を、独立した著者の断言として本文末へ追加していない。対応表でもこの二箇所を未処理として残し、全文意味一致の確認済み区間は0のままとする。

## 検証

判断候補32組合せ、可能結果の結合11例、原文への接続12例、母集団と割合8例、自立の目標6例を確認した。特に、偽だが本人が肯定する場合、真だが本人が肯定しない場合、負担だけが成立しない場合、認識した記述と候補の記述が違う場合を区別した。実際の定義を基本記号で置き換えず、基本関係への解釈を与えて評価した。通常評価と定義の計算再利用も基準例で一致した。

一般文書は基本記号0・定義3、接続文書は基本記号106・定義138である。型検査、通常表記と短縮表記、32文字による固有表記の往復、SVG出力を確認した。基本関係の意味規約を与えた有限モデル内の検査であり、原文との同義性の証明ではない。

全827テストが通過した。CLIによるJSON出力が元の構造に一致することと、固有文字SVGが妥当なXMLであることも確認した。
