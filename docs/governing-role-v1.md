# 政策の主体を同じ共同体の統治役職へ結ぶ

政府役の引数を、本文が対象とする共同体の統治役職へ接続した。これまでは政策変更と自己利益判断の主体が同じであることを要求していたが、その主体が共同体を統治する立場にあるという条件はなかった。

新しい `ryv` は、同じ組織・文脈の役職順序について、指定役職が最高であり、指定主体がその役職を担い、その組織の管轄が指定共同体に及ぶことを合わせる。役職順序の判定には既存の `rwo` を使う。最高役職に就くこと、組織への所属、共同体への管轄を別々に扱い、別組織の役職や別共同体の管轄で欠落を補わない。

本文では、共同体と基準文脈で組織を固定する。条件文の前件の真偽に先立って基準時の資格を確認し、後件では同じ主体・役職について始点と政治的終点の資格を確認する。途中の全時点での在任までは要求しない。原則の変更・公的理性使用の許可・政府自身の利益判断には、同じ主体を渡す。規範の出所を、その主体そのものと同一化することはしない。

原文には、民衆側への作用に続いて、政府の原則と政府自身の利益判断が記される。[カント AA VIII, 041頁](https://www.korpora.org/Kant/aa08/041.html)を基準に、同じ共同体への接続を候補化した。現代の[Duden「Regierung」](https://www.duden.de/rechtschreibung/Regierung)の機関・統治する人々という区別と、[Adelung「Obrigkeit」](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_3_0_199)の共同体に対する権力・上位下位の区別も比較した。後者は隣接語であり、両資料から1784年のRegierungの意味を一意に確定したとは扱わない。

一人の統治者と組織としての政府を許し、多数決・選挙・複数の保持者を要件にしない。一方、今回の役職範囲は統治を指導する体系として選んでいる。国家の全機関が一つの役職の下にあるという主張にはしない。国家・組織・役職・管轄の制度的な成立、権限分立や連邦制との対応、組織が判断主体となる仕組みは残る。

検査では、下位役職の保持者、最高ではない極大役職、別組織・別共同体、政治的終点での失職や管轄の消失を区別する。最新版の条件文全体も評価し、以前の因果・規範・認識の定義をテスト用の真偽関係へ置き換えない。帰属された描写は事実として実行しない。
