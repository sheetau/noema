# 移動する球と、座標系を指定した同時刻の断面

[移動する形状のNoema定義](../examples/v011/einstein-moving-shapes.noema)を、φ=1での座標変換へ接続した。球面が別の座標系の同時刻の断面では楕円体となること、縦半軸が縮み横半軸は変わらないことを記述する。新しい基本記号や文法演算子は使わず、17定義を追加し、全体は10基本記号・81定義となる。

原文は[アインシュタインの論文](https://de.wikisource.org/wiki/Zur_Elektrodynamik_bewegter_K%C3%B6rper)§4、u0110〜u0117である。物理的な剛性や、段落全体の論述の記述は未完成であり、原文との対応は部分草案として扱う。

## 世界管と一時刻の形を分ける

四座標(t,x,y,z)で真偽を返す関数を、表面に属する出来事の数学的な成立条件として使う。ggは全時刻で同じ位置を占める球面、ghは変換後の球面を表す。giはその関数の時刻だけを固定し、三つの位置座標を引数とする断面を作る。球面以外の形状にも同じgiを使える。

| 定義 | 条件・働き |
| --- | --- |
| ga | 正の半径Rについて、x²+y²+z²=R² |
| gb / gh | β²(x−vt)²+y²+z²=R²と、正のβ・光速未満の条件 |
| gc | 原点時刻の楕円体、β²x²+y²+z²=R² |
| gd | 正の縦半軸aについてβa=R、二つの横半軸はR |
| ge | βを消去した、V²a²=R²(V²−v²)と正の値・定義域の条件 |
| gi | 一つの座標系で時刻を固定した断面 |
| gj | 全位置の成立条件が任意の二時刻で一致するという時間不変性 |

gaは表面の条件であり、内部まで含む球体の条件ではない。半軸は中心から正の軸との交点までの距離であり、直径を代入しない。また、時間不変な表面があることだけで、その中の物質の剛性や運動まで定義したとはしない。

座標変換fhを満たす二組の四座標について、静止側で球面上にあることと、変換先でgbを満たすことが同値になると検証した。t=0ならgcとなる。tが変わる場合は中心がvtへ移動するため、原点時刻の式をそのまま再利用しない。

## 同時刻は座標系と組にする

同じ時刻tの二つの出来事について、変換後の時刻差は次を満たす。

```text
V²(τ₂−τ₁) = −βv(x₂−x₁)
```

二つの座標変換式からこの式を検証した。定義域内では、両系で同時になるのはv=0またはx₂=x₁の場合である。従って「同時に測った」という情報から座標系を省かない。

数値検査ではR=5、v=3、V=5、β=5/4とした。一方の系のt=0でx=−4とx=4にある表面上の二つの出来事は、球の静止系ではξ=−5とξ=5、時刻はそれぞれτ=3/5とτ=−3/5になる。同じ二出来事を静止系でも同時刻の断面として扱う条件は成立しない。

glは二つの出来事に、同じ座標系・文脈・単位・時刻の位置を割り当てる。gmは同じ物体等を表す出来事集合への所属も要求する。さらにgq・gr・gsで、その座標が同じ世界管の形状条件を満たすことを結ぶ。所属と同時刻の読みが合っていても、半径が違う形状を与えた場合にはgsが偽になる。物体への所属自体は集合引数で明示し、座標が一致しただけで同じ物体だと推定しない。

## 速さの増加と定義域

同じR・Vでv²が大きくなると、正の縦半軸aが小さくなることを検証した。vの符号だけを変えた場合は半軸が変わらず、v=0ではa=Rとなる。正のεについて、R²(V²−v²)<V²ε²ならa<εになるという評価も検査した。

これは定義域内の半軸についての条件付きの評価である。v=Vで有限のβを代入したり、正の半軸を持つ正則な変換があると扱ったりはしない。原文の光速での平面状の形への言及について、極限の説明や物理的な到達可能性まで完成させたわけではない。特に、退化した二次方程式をそのまま全ての平面点の集合と読むことで、極限の物体を記述したことにはしない。

実数の切断についてもgn・go・gpで球面・移動・半軸を記述した。実切断演算の一般法則から同じ結果を導く機械的証明は未完である。多項式検査の実数に関する判定を、そのライブラリ全体の正当性の証明とは数えない。

## Noemaの主張文と検査

定義群に加え、[14の条件付き主張をNoema本文として保存](../examples/v011/einstein-moving-shape-claims.noema)した。検査用Pythonコードの中だけに主張を置かず、CLIで解析・表示できる独立した文書になっている。これらは有理数について条件を明示した数学的な主張であり、原文の物理的な論述をそのまま全部記述した文書ではない。

[検査記録](../reports/moving-shapes-v1.json)は、14の代数的性質、誤った一般化を反証する3つの有理数の具体例、15の数値例と有限標本への置換を拒否する1例、10の観測例を収める。算術の検証では、定義の依存関係を調べ、算術以外の観測関係に依存する定義を除外している。観測を算術上の公理として真と置く処理は行わない。

原文の球面・楕円体・軸の三つの数式に対応を付けた。周辺の物理的な設定、剛性、一般形状への言及、極限、著者の帰結としての提示は残る。確認済みの全文単位数はアインシュタイン0/282、カント0/20のままである。

```powershell
python -S -m scripts.compose_moving_shapes
python -m scripts.check_moving_shapes --verify-only
python -S -m noema parse --input examples/v011/einstein-moving-shape-claims.noema --output artifacts/einstein-moving-shape-claims.json
python -S -m noema render --input examples/v011/einstein-moving-shape-claims.noema --alphabet v2 --output artifacts/einstein-moving-shape-claims.svg

```

構文解析・表示・数値と観測の検査にはモデルや数式ソルバーを必要としない。多項式の検証には補助依存関係`.[proof]`を使う。全時刻・全位置への量化を有限値の標本で代用しない。
