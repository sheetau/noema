# 第四文の依存群：公共の平穏・一致と根拠ある懸念の不在

第四文の公共の平穏と共同体の一致を、別の内容として構成する。既存の市民的法秩序r5m6をそのまま同義語として当てない。共同体には固定基準で少なくとも一人の成員を要求し、人口が空だから平穏・一致が成立する構成を避ける。

r57zは、生起する同じ出来事が暴力・威嚇・集団衝突の種類に属し、同じ共同体の公的共同生活を妨げることを結ぶ。r572はその出来事が存在しないという平穏の内容である。強制的な性格と公的な影響を分け、単に政府に不都合な意見、平穏な討論、無関係な私事を公共の乱れへ置き換えない。無音や全活動の停止も要求しない。

r574は、同じ共同体に属する非空で重ならない二集団の間に、同じ公的共同生活の一員として関わり続けることを拒む対立があり、それが公的な結び付きを損なう広がり・持続を持つことを述べる。拒否は一方向でもよく、暴力が発生しなくても分裂を表せる。r575はそのような対立の不在を一致とする。全員の同じ信仰・政策意見、常時の協同行為、政府支持を必須としない。集団範囲と対立の広がりの適切さは、公開した意味規約の入力条件である。

r576は同じ共同体の平穏か一致の一方でも失われる内容である。両方が同時に失われた例だけを危害とせず、一方の安全で他方の危害を隠さない。

`nicht das mindeste zu besorgen`は、自由の下で同じ二状態への危害を見込む根拠が一つもない、と読む。r577は条件を満たす関連候補が非空であり、その全候補について評価がそろい、その中に根拠を持って見込む危害候補がないことを求める。条件が実現不能なために空虚に成立する例、未評価の経過、未知を根拠なしへ補う例を拒否する。単なる論理的可能性や根拠のない想像上の危害は、それだけで実践的懸念としない。

r6aaは、同じ政府・最高職・共同体・対象集団・宗教主題のr56hの自由内容と、同じ共同体のr576をr577へ接続する。関連する可能経過、評価完備性、見込みの根拠は全て同じ設定・固定基準・評価点を使う。今の平穏、全未来の無害の保証、当該政府に不安という感情がないこととは区別する。

局所検査では、平穏と一致の四通りの組合せ、集団の混入・重複・空、無暴力の分裂、局所的な意見相違、三候補での条件・危害・根拠の512通り、評価漏れと未知を扱う。自由内容の内部には既存の深い検査証拠を使い、今回の接続検査の境界を報告する。
