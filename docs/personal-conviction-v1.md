# 本人の確信と仮定的な賛同の否定

カント第五段落の次の一文 `kant-1784:u0012[3899,4278)` には、規定を本人自身が十分な確信をもっては認めないであろうという節がある。この依存群では、同じ対象への本人の肯定、確信のあり方、仮定の下での否定を分けて構成する。本文91主張と確認済み文字数は増やさない。

採用する局所的な読みは、`unterschreiben` を規定内容への本人自身の賛同と捉え、紙への署名や公的な宣言を必須としないもの。現代の [Dudenの用例](https://www.duden.de/rechtschreibung/unterschreiben) は比喩的な賛同の意味を裏付けるが、1784年の唯一の読みを証明しない。職務上の教示と本人の確信を対照させる原文の文脈を保持する。

`voller Ueberzeugung` は、本人にとって承認を確定させるだけの根拠を得たという確信があり、疑いの留保を置かないという受け入れ方として扱う。ただし、カントが [KrV AA III 531](https://korpora.org/Kant/aa03/531.html) で述べる技術的なÜberzeugungには客観的に十分な根拠が含まれ、[次頁](https://korpora.org/Kant/aa03/532.html) は主観的な状態だけからÜberredungとの違いを確定することを認めていない。新しい関係はこの技術的定義の代用ではない。本文統合時には、本人の受け入れ方に限定する読みを明示する必要がある。

| 定義 | 構成 |
| --- | --- |
| `r42c` | `fa`の本人の判断と、同じ対象・閉じた内容関数・固定基準についての`h245q`の肯定を結ぶ。 |
| `r42d` | 同じ判断に、根拠を得たという留保のない確信`h252d`を要求する。 |
| `r42e` | そのような判断が評価状況で存在する。 |
| `r42f` | `hzko`で選ぶ比較状況が非空で、その全てで前提と帰結が成り立つ。 |
| `r42g` | `r42f`の帰結を、同じ内容に対する`r42e`の否定にする。 |

`r42g`の否定は仮定的な帰結の内側にある。「確信を伴って認めるだろう」が成立しないという外側の否定とは区別する。比較状況に賛同する場合としない場合が混在すれば、肯定形と否定形のいずれも成立しない。選択が空の場合も両方とも不成立になる。なお、賛同はしているが十分な確信を持っていない場合は、否定形と両立する。

`würde`から現実の前提が偽であることまでは補わない。このため、その条件を持つ既存`rqrs`をそのまま使わない。比較状況の選択は既存`hzko`を再利用し、呼び出し側が閉じた前提記述を与える。前提を満たすだけで選択されていない状況を混ぜず、選択された状況が前提を満たさなければ構成を拒否する。規定内容・本人・基準は候補を通じて固定し、肯定を行う判断そのものは候補ごとに異なってよい。

新しい基本関係は`h252d`の一つだけで、特定の聖職者・教会・規定・原文節を含まない。確信という受け入れ方を、全候補での賛同、確率、客観的真理、教示の義務に還元しない。旧`rgj`は判断候補に賛同しない点が一つあるという別の意味のまま保持する。
