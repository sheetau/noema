# 六成分と全座標に共通する係数

アインシュタイン1905のu0163の結論節と、u0164の六式を部分記述した。計算した混合場と動く系の場を、一つの係数ψ(v)で結ぶ。係数は速度だけを引数とし、成分・場所・時刻ごとには選び直さない。

## 再利用できる構成

[一般用文書](../examples/v014/field-common-scale.noema)の `sag2` は、指定した成分列について「第二ベクトル＝同じ係数×第一ベクトル」を要求する。非空の成分列、重複の不在、実数値の有効性を検査し、値の一致と関数の個体同一性を分ける。零係数を排除せず、零ベクトルの場合に係数が一意だとも仮定しない。

[論文文書](../examples/v014/einstein-field-common-scale.noema)の `sah2` は、同じ四座標で電気・磁気の全六成分に同じ係数を適用する。`sai2` は空でない領域の全点でこの条件を要求する。`saj2` で領域の一致を要求し、異なる領域の共通部分だけへ主張を縮めない。

`sak2` では既存の混合・逆座標変換を再利用する。ψ(v)は全座標の量化の外に置く。内容は著者の主張として記録し、二組の式が成り立つことから自動的に導いた定理にはしない。

## 共通係数を結論する前提の区別

定数場E=(1,0,0)、H=0と、別の定数場E′=(0,1,0)、H′=0を考える。どちらも微分は零であり、六つの回転の式と二つの発散条件を満たす。一方、共通係数を掛けて前者を後者にできない。検査器は零勾配について八つの代数条件を評価し、係数に関する二等式が同時成立しないことを有理数の一般式で検査する。

これは「同じ微分方程式を満たす」という条件だけでは値や共通係数を決められないことの検査である。同じ物理的な場を測定することなど、未形式化の同定条件まで否定するものではない。原文の前半にある等価性、記号置換、明白さを含む推論の説明は未記述として残す。

## 原刊との局所照合

保存済みのMathMLでは、M′の右辺の混合項が小文字のzになっていた。[ラプラタ国立大学の公開スキャン](https://sedici.unlp.edu.ar/handle/10915/2786)から印刷908頁を確認すると、大文字のZと読める。六式の並びと共通係数も画像で照合した。

生のMathMLと既存の検査結果は変更していない。[照合記録](../data/field-common-scale-facsimile-v1.json)にPDFの取得先・ハッシュ、抽出画像のハッシュと訂正箇所を保存し、新しい文書では大文字Zを採用した。[抽出した画像](../artifacts/written-facsimiles-v1/einstein-1905-unlp-p908-0.jpg)を保持する。画像はPDF内の単一のページ画像を抽出したもので、図の描き直しではない。全文やページ全体の意味確認を終えたという記録ではない。

## 検査範囲と残る作業

ベクトル10例、六成分9例、速度・場・文脈の接続15例、著者への帰属6例と、反例の代数条件を検査する。源文書の接続検査では、全領域の比例関係と領域一致を明示したテスト用の関係として与える。混合成分と逆座標の引数は実際の定義を評価する。全実数上の量化を有限標本に置き換える評価は拒否する。

関連30テストが通過した。通常記法・圧縮記法・固有文字を経由した往復、保存した検査結果の再計算、二つの文書のCLI JSONと構文木の一致、SVGが妥当なXMLであることも確認した。字形の目視検査は今回行っていない。
