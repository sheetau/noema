# 旧草案の143記号の所在と接続

前回の整理では、アインシュタインの入力にエネルギーの問いまでの174文を選んだ。その後の密度・時刻の草案には175文があり、未統合候補とした143記号のうち83記号が既に含まれていた。入力の選定が古かったために生じた不足である。今回は後続草案を基準にし、追加の一文と密度の時刻を照合する修正も保持した。

残る60記号は、経路・認識・世界線の三つの別草案に集約できた。原文対応記録が指す11種の古い資料と照合し、必要な定義の依存先全体と、原始関係・定義の意味説明が一致することを確認した。後続草案にあった83記号についても、記録に固定された元文書と意味基盤を照合した。名前の一致だけによる所在確認にはしていない。

## 一つの文書に含めたもの

[統合した草案](../examples/v014/einstein-reconciled-v1.noema)には、現行の175文と三つの独立した定義ライブラリを収録した。現行草案から不要な宣言を除く際には、全ての文と、入力中に存在する原文対応記録の参照先を保持した。

別草案の記号名が衝突する場合は名前を変更し、引用内を含む全ての参照を変更先へ結ぶ。独立した原始関係を同じものと仮定せず、式の本体が同じだけの記述も統合しない。各出典へ逆に投影すると、取り込んだ文書を構文木としてそのまま復元できる。

古い版0.11・0.13の定義を必要に応じて版0.14へ明示的に変換し、元の版へ戻せることも検査する。現行文の引用先や論理条件を、古い候補で置き換える操作はしていない。とくに密度の修正先 `seoz` は維持する。

[意味基盤](../data/einstein-reconciled-basis-v1.json)には各出典の意味説明と留保を残した。説明中の記号は元の名前空間で読み、`source_symbols` の対応表で統合後の名前を引く。自然言語の説明中の単語を一括置換して、別の参照先を作ることは避けた。

## 検証範囲

[所在・接続記録](../data/einstein-reconciliation-v1.json)に、旧143記号の出典と統合後の参照先、27組の依存先・意味説明の照合を記録した。143記号の所在未解決は0になったが、これは意味の完成数ではない。

数値検査では、実際の統合文書に収録した時計の進み率の定義を使う。正負の速度について成立する例、誤った進み率、光速で零の進み率を指定した不成立例を、元ライブラリの評価結果と比較する。無関係な名前空間の解釈は実行できないようにして検査する。同じ綴りだった算術記号を引用しても、独立した出典間では同じ記述にならないことも確認する。

```powershell
python -X utf8 -m scripts.compose_einstein_reconciliation
python -X utf8 -m pytest -q tests/test_einstein_reconciliation.py tests/test_linking.py
python -X utf8 -m scripts.check_einstein_reconciliation --verify-only
python -X utf8 -m noema parse -i examples/v014/einstein-reconciled-v1.noema
```

三つのライブラリは候補定義として収録したもので、古い草案の主張を新たな著者主張として追加していない。また、現行の175文が各候補を実際に使っているとは限らない。概念の基礎説明、原文の未記述部分、候補の選択と本文への統合、原文との意味一致は残る。今回の整理によって原文の対応範囲や意味確認済み区間数は増やさない。
