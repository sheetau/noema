# 電荷の通過と電流の経過

導入段落の「同じ大きさと経過の電流」へ向け、物体に付随する有向断面を通る電荷の時間変化率を構成する。IOPの[電流の説明](https://spark.iop.org/current-electric)にある電荷通過率を参照した。単位は電荷単位と時間単位の組で与える。BIPMの[アンペアの説明](https://www.bipm.org/en/si-base-units/ampere)はこの量の関係の確認に用い、現代SIの定義定数を1905年の本文へ加えない。両ページは2026-10-23に参照した。

新しい基礎関係eiriは、種類を指定した量の符号付き正味通過を、同じ物体・断面・向き・評価系・二時刻・単位・文脈に結ぶ。断面は物体に追随し、その断面に対する通過を数える。したがって、導体が移動しただけで電荷が導体内を流れたことにはならない。断面と正方向の物理的同定は入力の規約であり、名称や座標関数だけから成立を推測しない。

eia4は二時刻間の累積値の差をその通過量へ結ぶ。eia5は有効な非零幅区間の全二時刻でこの対応を要求する。累積量の原点には任意の定数を許す。領域内に保有する電荷量の変化とは異なり、一方から入り他方から出る定常電流でも、一つの断面の累積通過量は変化する。負電荷が逆向きに通れば、正方向の正電荷と同じ正の寄与になる。正味零から通過した担体が存在しないとは推論しない。

eia6は既存liの微分関係をこの累積関数と区間へ結び、eia7は量の種類を既存zorの電気量へ固定する。eibaは全時刻の電流関数を結ぶ。区間端では片側微分を採り、内点では両側からの条件を保つ。導体電流に採るマクロの連続体記述であり、個々の荷電粒子の通過による跳躍が常に微分可能という意味ではない。

eibbは時刻原点の定数差で対応する二時刻の符号付き電流値を照合し、eibcは二場合の完全な電流履歴と全時刻の一致を要求する。絶対値だけ同じで向きが逆の場合や、総通過量だけ同じで途中の経過が違う場合を区別する。eibdは前回のeia3と、右側物体の同じ断面におけるeibcを同じ引数で結ぶ。二条件を同時に述べる構成であり、相対運動の一致から電流の一致を導く法則ではない。

有限検査は、正負・零の通過量、時刻順序、累積原点の変更、量の種類と全参照の結合、微分への引数、電流の途中の経過と向き、相対運動比較との引数共有を確認する。微分と完全な通過履歴を扱う検査境界を明示し、全実数の微分・全履歴を標本で代用しない。

電気量の作用と校正への基礎接続、導体の性質、磁石の性質、電気力学的相互作用は未完である。比較対象となる全断面の対応、マクロ尺度、保持する物理的性質、電場・起電力・エネルギー、通常の理解への帰属と原文全体の接続も必要である。今回の一断面の条件を導体全体の電流分布の完成としない。既存207主張と意味判断を保持し、原文対応の文字数を増やさない。
