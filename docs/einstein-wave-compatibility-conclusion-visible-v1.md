# 同じ波と両立性の結論を円文字へ接続する

原刊901頁のu0091は、同じ波が移動系でも速度Vの球面波であるという結論と、これによって二原理の両立性が示されたという二文である。前段から続く段落座標47の第一文16トークン、第二文10トークンを、それぞれ全体の本文参照として記述する。

既存の11定義を合成し、同じ波・放出・二つの系を保つ。波の構成光線は非空であり、全構成光線と全適用区間に同じ放出と速度Vの伝播を要求する。途中から始まる区間の始点を、元の放出点へ置き換えない。到来と未来側の球面式が一致する条件も保ち、一つの成功光線や二乗式だけで全体を代用しない。

著者による帰結の提示と、その帰結を検査器が証明したことは区別する。二原理の両立性には、同じ意味を保つ二つの原理が一つの許容設定で共に成り立つ既存定義を使う。「示された」という位置付けは旧規約uiを公開名`presentsasproved`へ移し、同じ著者・箇所・文脈に結ぶ。正のφなどを発話へ補わず、以前に証明が未提示だった段階と本文順序も保持する。

共通375語と固定アルファベットを維持し、任意プロファイル53は788語となる。参照型は追加しない。検査では実際に復号したNative定義を使って、全光線と全区間、波面と伝播、同一状況の前提、共通許容設定、帰結と証明済みの帰属を対照する。有限診断・原文への逆投影・画像の復号・描画点検は別々の証拠であり、一般的な物理的証明や第三者による読解の代わりにはしない。
