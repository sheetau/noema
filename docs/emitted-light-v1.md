# 光源の運動から独立した光速度

光源が静止している場合も運動している場合も、対象となる光の伝播区間に同じ速度値を適用する条件をNoemaに記述した。区間の光路長と経過時間を結び、両端の時刻には前節で定義した局所時計の読みを使う。二つの原理を後続議論の前提として採用する談話も接続した。

[アインシュタイン原文§2](https://de.wikisource.org/wiki/Zur_Elektrodynamik_bewegter_K%C3%B6rper)の `u0024`、`u0026`〜`u0028` と、数式要素 `M0041`・`M0042` に対応する部分草案である。`M0041` は速度を表す文字記号であり、新しい独立した式一本とは数えない。光の放出・運動・光路長の基礎説明、全区間の範囲、原刊画像との照合、全文の意味確認は残る。

## 片道の速さと、前節の時刻

| 定義 | 内容 |
| --- | --- |
| `sax` | 正の光路長・経過時間・速度について、速度×経過時間＝光路長を実切断で記述する |
| `say` | 有理数の読みを正の単位尺度で換算した、同じ片道の速度条件 |
| `saz` | 同じ光・物体・放出出来事・基準系・文脈を結び、静止か運動かを区別する |
| `sba` | 同じ区間の光路長と、共通参照時計に同期した両端の局所時計の読みを速度条件へ渡す |
| `sbb` | 完全と指定した非空の全区間に、一つの同じ速度値を適用する |
| `sbc` | 同期を既存の `qo`、速度の条件を実切断の `sax` に接続する |
| `sbd` | 前節の共通値 `tc` を使う第二原理の、状況ごとの内容 |

片道の式は光路長を2倍しない。前節の往復の式との数値的な関係は、全光路長が一方向距離の2倍である場合として別に検査した。端点間の距離だけを、任意の光路の長さと同一視する条件は加えていない。

両端の局所時計には、前節の `qt` を使う。それぞれの出来事と時計が同じ場所にあり、時計が指定基準系で静止し、両時計が同じ参照時計へ同期することを要求する。光源が動いてよいという条件は、測時用の時計が動いてよいという条件にはしていない。時間単位・長さ単位・速度単位の対応も保持する。

対象区間の始点は放出出来事そのものでも、その光が放出地点から伝播した先の出来事でもよい。この接続により、放出から到着までの全経路だけでなく、途中の部分区間も扱う。全経路の平均速度が一致しても部分区間で異なれば、全区間の共通値という条件は成立しない。必要な全ての部分区間が範囲に含まれることは、完全性の前提として明示する。有限の観測で瞬間速度の法則を証明する仕組みではない。

## 光源の状態を混同しない

光の放出元は同じ光・同じ放出出来事へ結び付ける。静止・運動はその出来事における同じ基準系との関係として評価する。後で運動したことを、放出時の状態の代用にしない。分類の欠落や両分類の矛盾は、静止と補完せずに不成立とする。

一方、静止光源と運動光源がどちらも実際に存在・観測されたことまでは要求しない。法則は指定された対象全てへ適用するものであり、二分類の実例が必ずあるという主張を補わない。検査では両方を含むモデルを使い、一方を都合よく除く範囲指定を正当化する根拠にはしない。

真空中という適用範囲は、前節の共通速度値の定義から引き継ぐ解釈を明記した。媒質中の全ての光まで同じ速さとする条件ではない。光源の速度値を勝手に与えたり、それを共通光速度に足したりする処理も含めていない。

## 二原理と後続議論

第二原理は、著者が `sbd` の記述を定義として提示するという主張にした。さらに導入箇所では、先行する第一原理 `saw` と第二原理 `sbd` の両方を、同じ後続議論の範囲で採用すると記述した。この範囲は、前節で同期を仮定した範囲と別に保持する。

この帰属は二原理の内容を実行しない。著者が前提としたことと、検査器が内容を物理的に証明したことを区別する。両原理から後続の全ての推論が正しく導かれることも、この採用だけでは保証しない。

## 検証

放出と光源分類の16組合せ、有理数の具体例12件、量化付き多項式条件7件を検査した。多項式条件では、共通の時刻原点変更、速度の一意性、単位換算、往復距離との関係が成立し、光源速度を足してよいという主張には反例が得られた。

原文接続は28例で検査した。二つの光源状態と途中の部分区間を含むモデルを受け入れ、光源の静止・運動の分類だけを変えても速度条件が保たれることを確認した。違う放出元・光・単位・参照時計、同期しない終点時計、動く測時用時計、不完全・空の範囲、全経路だけ一致する速度などは拒否した。帰属の7例では、一方の原理の欠落や異なる推論範囲を区別した。

接続検査では、同期と速度の条件に明示した判定関数を渡している。読みの比較は入力した整数の埋込みだけを識別するもので、任意の実切断の一致を判定するものではない。実数全域の `qo` と `sax` を有限の候補で近似した検証でもない。実切断への全量化を有限実行器が拒否することは別に確認した。
