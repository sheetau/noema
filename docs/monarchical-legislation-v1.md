# 人民と君主の立法上の限界

第十文の公的決定について、人民が自らに定めることへの不許可と、同じ内容を君主が同じ人民へ定めることへの不許可を結ぶ。どちらも同じ内容への負極性の規範要求として扱う。許可が見つからないことや実行方法がないことだけで禁止とはしない。君主の採択内容では、同じ人・共同体・点の役職保持と採択を結ぶ。

全人民意志は、先の立法の試金石を引き継ぎ、人民全体が理性的な公的規律として引き受け得る内容の全範囲と読む。全成員の現在の心理的一致や投票結果を代用しない。引受け得る法案の範囲は選択肢であり、全てを一度に採択する意思ではない。

君主自身の公的意志への統合には、人民意志を構成的な規律として取り込むことと、関連する全法案についてその範囲を過不足なく保持することを要求する。偶然の賛否一致だけでも、取り込むという名称だけでも足りない。

立法上の権威は正当な資格と読む。その規範的根拠を意志統合に置き、正当な権威がある場合には統合を必要とする。全ての事実上の君主の正当性、統合だけからの十分性、個別決定への無制限な許可は加えない。

これは採用する規範的読解を明示した依存群である。比較・強調、denn による理由の提示、全文への帰属と通読は残るため、第十文を意味確認済みの文字数に加えない。原文は保存済み原刊490頁と [AA VIII 39末](https://korpora.org/kant/aa08/039.html)・[40冒頭](https://korpora.org/kant/aa08/040.html) による。
