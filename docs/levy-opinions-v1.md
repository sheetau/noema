# 同じ賦課についての本人の公的見解

第五段落u0012[2771,2983)の前件に向け、同じ人が学識者として賦課の不適切さ・不正義について自分の見解を公に表す構成を用意した。本文と意味確認文字数はまだ更新しない。市民の義務への不違反、demohngeachtetの譲歩対照、oder auchの追加焦点、全文の帰属を続けて接続する。

不適切さr342は対象と事情への適合条件の不足、不正義r343は権利・権原・公平の条件の不足として区別する。[Adelungの語義と保存ハッシュ](../data/levy-opinions-lexical-v1.json)を採用根拠とする。補助資料は1811年版であり、1784年の当該箇所の唯一の意味やKantの正義論全体を確定するものではない。具体的な条件はNoema関数の列で明示し、同じ対象・固定基準・評価点でretへ渡す。空列を不充足とせず、未知の条件は評価を拒否する。

r344/r345はそれぞれの内容を主張する発話である。r346は同じ提示活動・本人・賦課・固定基準を保ち、本人が持つ判断fa、その判断内容と肯定極性h245q、同じ活動による表出h245rを結ぶ。同じ固定した非空の宛先範囲の各人への提示h245pと否定的な評価の立場h244nを要求する。単なる引用や他人の批判の中立的な紹介は通らない。引用した判断内容の真理は実行しないため、賦課が実際に不正だという著者の主張は生じない。

r347は既存の公的理性使用r2ziと、同じ活動・全読者世界cc/ceを結び、不適切さについての表出と不正義についての表出の選言を取る。一方でも両方でも成立し、選言命題一つを述べることや二種の批判を同時に行うことを要件にしない。全読者の実際の受領・理解、書面という追加要件、先行の納付拒否や出過ぎた批判の実行は要求しない。

局所検査では、二種の内容を独立に実評価し、空列・条件の順序と重複・異なる対象や基準・未知の条件を対比する。発言の検査は引用内容の評価関数を未知のまま、本人・活動・判断・極性・宛先・内容関数・対象・基準・評価点のすり替えを拒否する。公的使用と選言も元の定義を実評価し、検査用の真偽関数への置換はしていない。両表記と文字体系v2の往復、親の意味規約と出典のハッシュを検査する。検査成功は全文の意味同等性の判断とは別である。
