# 認識を理由に使うことと、評価に基づく応答

前段では、恩恵の認識と応答が同じ時点に成立する条件を記述した。今回は、同じ認識を相手への評価の理由として使い、その評価を動機として応答する構造を追加した。認識・評価・応答の共存だけでは、この理由関係は成立しない。

| 定義 | 内容 |
| --- | --- |
| `rot` | 同じ本人・対象・時点に二つの異なる判断があり、第二の判断で第一の判断を理由として使う |
| `rou` | `rot`に加え、第一の判断が第二を支えるという評価がある |
| `rov` | `rot`の第二の判断を、本人の同じ応答行為の動機として結び、その応答が実際に成立する |
| `row` | `rov`に、`rou`の支持条件も要求する |
| `hzgm` | 判断主体・対象・理由の使用を既存の`fa`・`fb`・`fc`へ結ぶ |
| `hzgn` | `hzgm`と同じ構造で、支持`fd`の成立も要求する |

原文側では、第一の判断に「この行為者が本人へ好ましい結果を与えた」という前段の基準を使う。第二の判断には、その同じ結果を根拠として「同じ行為者が指定応答に値する」という既存`ro6`の基準を使った。受益対象・行為者・過去の行為、応答者・応答行為・応答先を保持する。判断の内容を取り違えたり、別人や別行為の動機を流用したりすると成立しない。

理由を使うことと、理由が判断を支えることは異なる。本人が恩恵の認識を理由に評価していても、その理由を採用することが妥当とは限らない。逆に、支持できる理由があっても、本人がそれを用いているとは限らない。`rot`と`rov`は支持の成立を要求しないため、支持が未確定でも理由の使用や動機の条件は検査できる。

判断候補と現実の履歴も分けたままにした。実際には恩恵がないのに、本人が恩恵を認め、その認識に基づいて相手を評価して応答する場合を表せる。支持関係を加えただけで、認識が誤り得ないことや、称賛が道徳的に正しいことを結論しない。

動機は本人・行為・評価判断・時点の関係として明示する。単なる同時成立から推定しない。一方、この関係を与えることは、心理的な因果機構を説明し終えることでも、唯一の動機を証明することでもない。二判断は同じ文脈時点で評価するが、その内部の時間順序を確定したとはしない。

[一般形](../examples/v014/reasoned-responses.noema)は1,828文字、[原文付き文書](../examples/v014/kant-reasoned-responses.noema)は201,316文字、[抽出文書](../examples/v014/reasoned-responses-core.noema)は6,608文字。六定義を追加し、原始記号と著者主張は増やしていない。親の宣言と15件の著者主張を保持した。[意味規約](../data/kant-reasoned-responses-basis-v1.json)と[検査記録](../reports/reasoned-responses-v1.json)を保存する。

認識・評価・理由の使用・支持・応答・動機の64通りを検査した。原文付き文書と抽出文書では、それぞれ16通りと十条件を確認した。追加21テストは、共存と理由の違い、使用と支持の独立性、動機・応答の不在、誤認、人物・対象・行為・時点・記述の保持、自己支持と二判断の区別、引用、未知の動機、親文書と原文範囲の保存を扱う。三文書のCLI解析、正規形と固有文字v2の往復、SVGのXML検査が通過した。SVGの目視確認は含めない。
