# 冒頭の二つの不足と因果の作用範囲

カント冒頭の第三文について、現在の「決意と勇気がともに不足する」という読みを採用した。本文の定義は変更していない。今回の成果は、この作用範囲についての読解判断と、それを別の論理形式へ取り違えない検査である。[現在の課題一覧](../data/opening-reading-status-v1.json)には、すでに修正された実装と、残る意味確認を分けて記録した。

[原文](https://korpora.org/Kant/aa08/035.html)では、Mangelに続く理解力を、決意と勇気に対比し、後半の二つをundで並列している。[IDSの句の説明](https://grammis.ids-mannheim.de/progr@mm/90102)は同種の句の並列を説明する。ただし一般文法だけで、この箇所の不足や因果の解釈が一意に決まるわけではない。ここでは不足を二つに共通に適用する読解を採った。

決意の十分さをR、勇気の十分さをCとすれば、採用した不足は `¬R ∧ ¬C` である。片方でも足りなければよい `¬R ∨ ¬C` や、両方がそろって十分という条件を否定する `¬(R ∧ C)` とは異なる。後二者は同じ真理値になるが、原文の訳をその形へ黙って弱める理由にはならない。現在の `rqqy`・`rqqz`・`rqrh` は、同じ本人・目標・状況に関する前者を記述している。

因果を述べる `bd` は、この合わさった不足を `rqrh` として引用する。合わさった状態が原因であることから、各不足が単独でも原因であるとは推論しない。逆に、各不足について因果記録があっても、それを合わせた記述の因果関係は自動では得られない。この区別は、二つの要因の共同作用を、各要因の独立した十分性と取り違えないために必要である。どの因果関係が現実に成立するかを、この有限検査で実証したわけではない。

検査では現行本文から依存する定義をそのまま取り出す。未成熟 `bc` もNoemaの定義として評価し、Python側の真偽値に置き換えない。二つの不足と三つの因果関係の32組合せでは、共同の原因だけが成立する場合と、各不足の原因だけが成立する場合を対照する。別の四組合せで、理解力の不足があっても、それが原因でなければ原文の対比を満たせることを確かめる。不明な十分さや不明な共同原因を、偽や既知の個別原因で補完する処理も拒否する。

本文への新しい語彙・定義・文の追加はない。診断用の別形式は試験内だけで使う。既存の部分草案の範囲と、八単位・166非空白文字の全体確認は変わらない。今回の作用範囲の判断を、第三文全体や第一段落全体の意味確認へ数えない。
