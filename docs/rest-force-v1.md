# 静止条件の訂正と、各基準系での力

アインシュタイン1905のu0173へ、移動系でも同じ電気量を1とする主張と、各系で静止するときの力の三成分の同定を追加した。先行する校正草案の静止条件にも誤りが見つかったため、新しい文書で訂正した。

## 前の草案の訂正

校正草案の `sby2` は、静止の条件へ `xm` を渡していた。しかし、既存の意味規約では `xm` は運動を表す。前回の検査も `xm` を静止として解釈していたため、26例の接続検査が通過しても、この誤りを検出できなかった。

[訂正版の文書](../examples/v014/einstein-rest-force.noema)では、この参照だけを、測定設定内の静止を表す既存の `x4` へ置き換えた。元の文書と報告は履歴として保存している。親文書の他の定義・基本関係・著者文を変更していない。

回帰検査は、以前から保存されている棒の測定の意味規約を確認し、静止と運動を独立の真偽で与える。旧草案が運動に、新草案が静止に従うことを、両方の文書で再現した。これは単なる名前の変更ではなく、成立する条件の訂正である。

## 同じ電荷と、系ごとのベクトル

移動系の電気量の結果記録は、先行する同じ対象・出来事・電気量の単位へ結ぶ。著者が相対性原理を根拠にこの値も1と述べる構造を、校正の仮定と既存の原理の内容を前提とする推論の帰属で表した。原理だけから電荷不変性を数学的に導出した記録ではない。

力の記述は二つの条件文に分けた。静止系ではその設定での静止、移動系では少なくとも当該出来事の瞬間の静止を条件とする。条件文を書いただけでは、対象が静止していること自体を断言しない。瞬間の静止から前後の時間の静止も補わない。

各条件の帰結では、同じ対象・系・出来事の四座標、成分場の割当、力の記録、単位、三成分の値を結ぶ。ベクトルはその系の対象位置と時刻で評価する。電荷が両系で同じ1でも、力のベクトルが両系で同じ数値になるとは要求しない。校正で使った力の大きさと、符号・方向を持つ力ベクトルの量の種類も分けた。

力を評価する出来事は、校正試行の出来事と別に参照する。同じ出来事であるとも、異なる出来事であるとも指定せず、原文にない時間の制約を加えない。

[一般用文書](../examples/v014/rest-force.noema)には、指定した四座標で評価した場と、指定ベクトルの成分を比較する定義を抽出した。関数を同一の実装に限定せず、選択した成分の値を比較する。これは物理的な力に限らず、複数の成分を持つ場の評価に使える。

## 検査と残る意味

静止・運動の回帰8例、成分比較8例、移動系の電気量の接続9例、推論前提4例、力の条件33例、著者への帰属8例を検査する。力の検査は有理数のアフィン場と明示した関係を使う。条件文の両枝を検査するための真偽の割当を、二つの相対運動系で同時に静止する物理的な実現の証拠とはしない。

関連26テストが通過した。通常記法・圧縮記法・固有文字を経由した構文の往復、報告と進捗集計の再計算、二文書のCLI JSONと構文木の一致、SVGが妥当なXMLであることを確認した。字形の目視検査は今回行っていない。

点状の理想化、電気量・力・単位の物理的な基礎説明、一般の観測から四座標を得る規約は未完である。原文の「定義により」という根拠の参照と、続く二つの言い表しも完成していない。全文の意味一致を確認した区間数は0のままである。
