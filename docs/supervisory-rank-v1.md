# 最高位の監督と、その立場の引受け

[カント本文の新しい固定版](../examples/v016/kant-supervisory-rank.noema)は、Oberaufsichtを同じ対象について最高位にある監督として記述する。前版diでは、総括的な監督dcと過去の引受けde・dvだけを要求していた。この条件では、同じ対象への監督上の上位者がいても成立し、最高位を引き受けたことまでは区別できなかった。

歴史辞典の[Oberaufsichtの項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_3_0_22)は最上位の監督と説明し、[Aufsichtの項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_3_3_3699)は他者の行動を定める用法も挙げる。取得した本文とハッシュは[出典記録](../data/supervisory-rank-evidence-v1.json)へ保存した。中間の監督者が必ず存在することまでは、この語義から導かない。

一般定義rqyiは、指定範囲に属する候補が、その範囲の全対象以上であることを要求する。比較の反射性と推移性も検査する。両方向の比較が成立する同順位は許すため、最高位の候補が複数いてもよい。比較不能な相手が残る場合は、単に上位が見つからなくても最高位とはしない。下位者同士が比較できる必要はなく、監督者一人だけの範囲も許す。

本文用のrqyjは、同じ対象・同じ状況に監督dcの立場を持つ主体を比較範囲とし、その中の順位を新しい基本関係hzxnで比較する。別の対象についての上下や、別の状況での地位を流用しない。全社会で一人の最高者がいることや、監督の正当な資格を主張するものでもない。

現在の最高位だけでは、以前に何の立場を引き受けたかは定まらない。もう一つの基本関係hzxoは、指定行為で同じ主体が同じ対象について、記述された立場を実際に引き受けることを表す。新diでは、以前のde・dvと同じ行為・主体・対象・時点に、rqyjという立場の引受けを結び、その引受け状況でもrqyjが成立することを検査する。一般的な監督を引き受けた後、別の理由で最高位になっただけの履歴を、そのまま最高位の引受けとは扱わない。二時点の間の連続保持、具体的な儀礼、合法性、自発的な発意は補わない。

旧diはrqykへ保存する。新たに二つの基本関係と三定義を追加し、既存定義の変更はdiだけで、意味が変わる本文は文7に限る。既存44文の構文と、確認済み十一単位・先行四文の意味依存関係を保つ。

検査は二対象の比較128組合せと三対象の四対照を扱い、同順位、比較不能、非推移的な比較を区別する。本文の二十三対照では、従属的な監督、対象・時点の違い、別の引受け行為、別の立場、過去だけ下位だった場合を分ける。目的・因果を含む現在の本文への接続三対照、帰属六対照、未知入力、三記法の往復も確認する。通常評価とメモ化評価の三照合は別の小さな有限モデルで行い、任意のモデルでの同値性や原文との意味一致の証明とはしない。
