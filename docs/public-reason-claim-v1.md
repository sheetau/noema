# 公的な理性使用の許可を政策の基準にする

これまで内容を引数で渡していた政策の作例に、「本人の公的な理性使用を許可し、その不実行を要求しない」という一つの基準を接続した。既存の公的使用の分類と許可を再利用し、新しい原始語を「尊厳」と名付けて意味の代わりにはしていない。

`iavclaim` は `[行為主体, 本人]` の二個体列を受け取る。本人が人間であることを確認し、全ての立場について既存 `h7d` を要求する。`h7d` はその人・立場で公的使用に分類される各活動について、同じ行為と実行記述への積極的な許可 `h7b` があり、不実行への要求 `h7a` がないことを表す。一つの立場だけを選んで、他の立場での禁止を隠すことはできない。

`iavpolicy` は、この基準を前段の `ryi` に束縛して展開した通常の階数0の政策である。`iavtreatment` はその外側の要求関係を `h7k` へ接続する。規範の出所が政府役の主体にこの基準を要求することと、その主体が本人の活動を許可することを分ける。同じ基準について比較状況で要求が維持され、現在も要求と許可内容が成立する。

許可から実行・能力・積極的支援を導かない。実行関係 `cg` が評価できなくても許可は表せる。公的活動が一つも分類されない場合、許可の全称条件は真になる。これは実例が存在するという主張ではない。活動や立場の分類、政府の資格、権利の根拠については引き続き説明が必要である。

検証では二つの活動を異なる公的立場に置き、許可と禁止の16通り、現在と二つの比較状況の要求の8通りを調べる。別人・別の出所・別の活動・別の記述・異なる極性への許可を混ぜない。通常形と展開形の一致、政策の置換、集団の条件文への接続も検査する。評価できない許可を偽とみなすことはしない。

この接続は解釈の候補であり、原文末尾の「尊厳に即した扱い」の全体や唯一の読みではない。原文の新しい対応範囲と著者主張は加えず、両作品の意味確認済み区間も0のままである。文書の解析や表記の往復が成功しても原文との意味一致を証明したことにはならない。
