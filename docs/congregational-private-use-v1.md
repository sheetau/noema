# 会衆の前での私的使用と規模によらない集会の性格

原文 `kant-1784:u0012[4408,4734)` の一文に向け、同じ会衆への実際の理性使用、私的分類、他者の委託の遂行、家内的な集会としての性格を構成する。原刊487頁を目視し、直前の辞職条件と、直後の学識者が世界へ語る公的使用との対照を確認した。本文への帰属はまだ行わず、確認文字数を増やさない。

`r44a` は既存の実際の教示 `r372` に、同じ本人・活動・評価点の理性使用と会衆への宛先を結ぶ。少なくとも一人の実際の担当受領者が、同じ会衆の成員であることを要求する。教理問答の生徒にしか届いていない活動を、会衆の前での使用へ混ぜない。全会衆への到達や全員の理解は追加しない。

`r44b` は同じ活動・職務・時点の私的分類 `r2zj` と、公的分類 `r2zi` の否定を合わせる。これは `bloß` を同じ使用の立場について排他的に読むための構成であり、私的使用一般を公的使用の否定で定義し直すものではない。同じ本人が学識者として別の立場で公衆へ語ることを妨げない。`r44c` は実際の同じ活動に、同じ教会・職務・主題に属する受託業務の遂行を結ぶ。任務の存在だけで遂行済みとはせず、全任務の完了や教義の真理も求めない。

`r44d` は会衆を、共通の主題について働きかけを受ける人々の集会とし、家の用事になぞらえた組織内の範囲を持ち、読者世界全体ではないことを結ぶ。`häuslich` の辞書的な家・家庭との関係、`Versammlung` の集まる人々という語義を補助にしたが、ここでの家内的という読みは、後続の世界としての公衆との対照に基づく文脈的な解釈である。家屋内・同居家族・小人数・秘密の集まりとは同一化しない。[Duden: häuslich](https://www.duden.de/rechtschreibung/haeuslich)、[Duden: Versammlung](https://www.duden.de/rechtschreibung/Versammlung)、[カント本文 AA08/038](https://korpora.org/Kant/aa08/038.html)を比較した。

`r44e` は、同じ集会を同じ担当関係の下で扱う関連機会と規模の全候補に `r44d` を要求する。現在点も候補範囲に含めるため、空範囲では成立しない。`immer` と `obzwar noch so große` を、機会や規模が変わっても当該集会としての内部的性格を保つという読みで接続する。候補範囲に人数上限を追加せず、家内的な結果を示す候補だけ選ぶことも禁止する。ただし、無限人数の集会や任意の規模の現実化は主張しない。全候補の供給は明示解釈の条件であり、有限検査がその完全性を保証するわけではない。

`r44f` は同じ事例・活動・発話でこれらをまとめる。実際の教示と私的・公的分類を通常評価し、規模と機会の候補に対する全称、候補からの現在点の脱落、他者の委託元・主題・活動の取り違えを検査する。記述内容の引用では、実際の教示や教義の真理を評価しない。

残るのは `nicht frei` と `darf es auch nicht sein` の区別、`also`、二つの `weil`、`in Ansehung dessen`、規模への譲歩の提示、全文の著者帰属である。今回の依存群を一文全体の意味判断としては数えない。
