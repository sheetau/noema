# 良心の機能上の代行と、本人による判断

カントの第二段落にある「自分のために良心を持つ」という関係節について、既存の定義を原刊画像と歴史辞典へ照合した。今回採るのは、本人が自分の行為を道徳的要求に照らして判断する仕事を、宗教的な助言者に任せるという機能上の読みである。この読みを支える根拠と参照の結合を確認し、本文と意味規約は変更しない。

[原刊482頁](https://www.digitale-sammlungen.de/de/view/bsb10926843?page=522)では、書物、宗教上の助言者、医師の三例が続く。助言者の関係節はこの列挙の中にあり、仮定例の本人への代行として読む。助言者自身の行為を助言者が反省する場面や、本人の感情を他人へ移す出来事としては記述していない。

[AdelungのGewissen項目](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_2_1_1967)は、道徳上の通常の意味を、自己の行為と法の関係への意識・確信として説明する。誤る良心の用例と、罪責感やためらいに関わる用例も区別している。この資料は自己の行為への判断という読みを支えるが、カントの唯一の意図や、語の全用法に共通する必要十分条件を確定しない。後年のカントの良心論も、この一節へそのまま追加しない。取得したHTMLと抽出本文は[出典記録](../data/conscience-evidence-v1.json)に保存し、検証時にはネットワークへアクセスしない。

既存の `sm` は、同じ人物が行う判断と、その人物の行為を道徳的要求に照らす評価を、同じ判断・状況へ結ぶ。別の判断に道徳的な内容があっても、本人の判断の代わりにはならない。三つの判断について二関係を変えた64条件と、主体・判断・状況などを取り違える八条件で、この結合を検査した。道徳的評価そのものの意味は既存の基本関係 `se` に依存するため、その哲学的妥当性や内面性を有限モデルで証明したことにはならない。

`st` は、この自己判断の記述を代行の対象として参照する。供給元を利用でき、その同じ供給元が同じ本人のために同じ仕事の代わりとなる判断・指示を供することが必要である。ここでは自己判断の内容を実行評価しない。本人の自己判断が不明でも代行の供給は述べられ、本人が判断したか否かと代行の供給の四組合せを区別できる。供給を受けることから、本人が自ら判断しなかったという事実も導かない。

この違いは、例の人物が持つ良心という能力の有無とも別である。今回の記述は代行される仕事の内容を示す。能力一般、罪責感、ためらいの全意味を `sm` 一つで定義したとはしない。助言の正しさ、本人の信仰、教義の真理を追加する条件もない。

供給元・受け手・仕事・状況・役割を変える十条件では、実際の現行定義を通常評価した。未知の関係を既知の意味へ補完しない。既存の本文の帰属検査も再実行し、著者による仮定例の提示だけから実際の役割・代行・判断を断定しないことを確認する。抽出した[Noema文書](../examples/v016/conscience-delegation.noema)は現行の二定義とその依存関係をそのまま含み、通常表記・簡略表記・独自文字v2の往復を検査する。

この確認は「自分のために良心を持つ」という表現の機能上の読みについてのものに限る。宗教上の職務の全条件、良心の全語義、他の名詞、便宜・反語と条件文全体、第二段落の通し確認は残る。[読解記録](../data/conscience-reading-v1.json)を登録簿v49へ固定するが、確認済みの全文単位や1,001文字の集計は増やさない。

python -X utf8 -c "from scripts.check_conscience_reading import prepare; prepare()"
