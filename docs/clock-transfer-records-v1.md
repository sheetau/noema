# 移送時計の現在表示と全期間の履歴

u0126は、Kに静止して同期する二時計の一方をAからBへ移送し、到着時に指示が遅れるという条件付きの主張である。原刊904頁では、導入の「特有の帰結」に続いて、初期同期・直線移送・到着時の比較・所要時間の説明が一文に結ばれている。今回はその一文全体に必要な表示と履歴の依存群を構成する。

局所表示は同じ時計・対象出来事・表示出来事・現在のK記録・場所へ結ぶ。表示値の正しさで候補を選ばず、指定値が対象出来事と表示出来事の両方で読まれ、他の有効な読みも同じであることを別に要求する。時刻の記録だけが合っていても、別の時計や遠隔の受信表示なら同じ候補にはならない。

初期の二時計は、それぞれAとBで代表位置が静止し、Kの同じ時刻に同じ値を指示する。初期区間の末端を出発とする。全区間で率1と共通の指示原点を保ち、一回の一致を同期全体へ置き換えない。時計の針や内部機構の運動を禁止する条件ではない。

移送中は、全実時刻に局所表示が存在する条件と、全ての現在表示が所定の値を持つ条件を分ける。移送時計の位置は三次元の端点を時間について線形補間し、正の速さと端点距離も結ぶ。経路はX軸に限定しない。Bの時計は同じ区間の全体でBに残り、到着時の二指示は同じ出来事と場所を共有する。

指示法則は初期指示をr₀、Kの出発時刻をt₀としてr(t)=r₀+f(t−t₀)とする。移送時計はf=√(1−(v/V)²)、B時計はf=1である。両端を含めたこの法則には、発進・停止で追加の指示変化がないという読みが含まれる。原点時計の慣性運動の式から加速中の応答を導出したとは扱わず、後続の本文接続で追加解釈として明示する。

現在の定義だけではu0126の完成ではない。秒への換算、到着時の遅れの二次近似と四次以上の留保、導入の前段参照と評価、条件付きの著者帰属を統合した後に単位全体を判断する。有限の検査例は全実数時刻の量化を置き換えない。
