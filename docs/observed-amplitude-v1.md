# 同じ波の振幅の探索と二乗比

u0197–u0198を原刊912頁の探索、命名、二系で評価する振幅、帰結と表示へ接続する。AとA′はそれぞれ静止系と移動系での振幅であり、電気側か磁気側かを同じ一つの選択として共有する。

振幅は、先行の同じ局所正弦波形の三係数の非負の大きさとする。測定という語は、各系で校正された電気力又は磁気力の単位によって量を評価するという理想化した読みを採る。eketから同じ物理場・源・過程・観測者・系・単位・領域を継承し、近似の誤差と用途上の十分性も保持する。特定の測定記録を存在させたり、近似係数を実際の場の厳密な振幅へ置き換えたりしない。

ekhzは選んだ側の三係数をsealへ渡す。ekiaは同じ六係数と同じ速度の成分変換から旧新の振幅を構成し、ekibで同じ物理設定へ結ぶ。電気側と磁気側の振幅が等しいという条件は加えない。横波条件の下では既存の代数的証拠が二乗比を支えるが、原文で省かれた横波条件や真空方程式からの導出を、新たな明示的な著者主張として挿入しない。

質問ekidは61設定を候補の外側で固定し、その同じ変換後振幅を求める。eiss4は条件と実数質問の閉じた族を受ける一般的な課題提示関係であり、物理的な意味は引用した規則から構成する。nun nochは先行の同じ波の検討に続き、なお取り扱う課題という位置付けに保持する。ekif/ekigの各56証人を使う表記規則へA/A′を結び、比の内容ekikでは同じ59全称役割を共有する。

M0345は保存電子テキストの分母に平方根があるが、原刊ではない。[既存の照合](../data/wave-amplitudes-facsimile-v1.json)を引き継いで、A′²=A²(1−(v/V)cosφ)²/(1−(v/V)²)を記述する。元のMathMLと照合後のMathMLを併記し、ハッシュを保持する。V=5、v=3、cosφ=0、A=1では原刊の値25/16と電子在庫の5/4を区別できる。

先行の成分変換を同じ設定で明示したekimから、著者がekikを得るという帰結提示をzcへ結ぶ。コロン、表示への説明と順序、表示項目と条件内容を保持する。これは著者の推論の記述であり、引用内容の自動評価ではない。非横波の係数を入れた反例を隠すために、比の結論を前件へ追加することもしない。

検査は振幅の非負性と側の選択、正負零の速度と場の尺度、成分変換、原刊の分母、63設定と61質問入力、各存在・全称位置、課題・命名・帰結・表示への参照を区別する。全実数の評価は有限列挙に置き換えず拒否する。原文全体の意味判断は局所検査の成功と分けて記録する。
