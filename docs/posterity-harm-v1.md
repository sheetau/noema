# 後代集団への害と推量された帰結

第八文の Nachkommenschaft は、合意が属する先行時代の後に生きる人々全体と読む。血縁の子孫、直後の一世代、固定化期間の終了後の人々だけには限らない。既存の後代人の条件を基準引数付きに一般化した `r5jy` と、全成員を一致させる `r5jz/r5j2` で範囲を構成する。

害は、認識獲得・理由ある訂正・理由ある自己判断を継承し発展させる機会と条件について、後代の集団に不利益があるという読みを採る。全員の個別被害や、誰か一人の被害だけとは同一視しない。`r5j3` は同じ後代成員・評価観点・関連背景を保った比較基準より厳密に不利であることを要求する。基準状況では同じ期間が不毛でなく、両側の評価が与えられていなければ成立しない。集団的な利益の評価と比較基準の妥当性は明示入力であり、有限検査が現実の社会的評価を証明するわけではない。

`r5j4` は同じ期間の不毛化と後代の範囲を結び、`r5j5/r5j6` はその不毛化から同じ後代への害に至る因果的帰結を既存 `h253x` で記述する。第一の合意実施から不毛化への帰結と、第二の不毛化から害への帰結は別々に保持する。不毛化だけから害を認定せず、因果の推移律も補わない。

wohl はこの第二の帰結を推量として提出する読みとする。`r5ka` は候補範囲 `r5j7` と帰結 `r5j6` を引用したまま、同じ全体・箇所・著者・基準・文脈で結ぶ。推量から無条件の帰結を別途断言してはならない。高確率や単なる論理的可能性への置換もしない。

この構成は比較の評価済み関係、利益の順序、反事実的な比較基準、推量の提示という一般関係と、一つの評価観点参照を追加する。原文一文を一記号へ置き換えるものではない。人口構成自体が異なる場合の害や、全種類の利益の集約理論はこの読みの範囲外である。
