# 条件付きの規定を、その記述を保って扱う

規則の存在、本人への適用、遵守、違反を分ける定義を追加した。規則が採用されていても、本人の立場や条件が合わなければ適用されない。適用された要求が実現していることも、規則の存在だけからは導かれない。

## 条件と目標の記述

従来の規範関係は命題内容を引数に取るため、全ての評価状況で真偽が等しい内容を区別できない。今回の `rba` は、規則・出所・立場・条件の記述・目標の記述・要求の肯否・文脈を結ぶ。条件と目標は、人から命題内容へのNoemaの式として保持する。

同じ真偽になる別名の式へ、採用された記述を自動的に置き換えない。これは同義性を否定する判断ではなく、どの記述が規定として採用されたかを保持するための区別である。規範を制定・採用する社会的関係は今回も意味規約として与えており、その基礎説明を完了したとはしない。

| 定義 | 評価する条件 |
| --- | --- |
| `rbb` | 同じ規定が採用され、本人が指定の立場にあり、その本人について条件が成立する |
| `rbc` | `rbb` が成立し、同じ本人の目標の真偽が要求の肯否と一致する |
| `rbd` | `rbb` が成立し、目標の真偽が要求の肯否と一致しない |
| `rbe` | 条件・目標・出所・立場・肯否を結ぶ採用済みの規定としての構造がある |

例えば「点検担当者は、故障がある場合に報告する」という条件付きの規定を考える。故障がなくても規定は存在し得るが、その条件から報告しなかったことを違反とは評価しない。故障があっても、その役割にない人へ要求を移さない。適用される人が報告しなかった場合には違反の条件が成立するが、責任や罰まで認定することにはならない。

この例を語句の対訳表や個別補正として実装してはいない。条件・目標・立場を引数として渡す一般形であり、本文の自動翻訳処理でもない。

## 相反する規定と検査の限界

同じ本人に、同じ目標を満たす要求と満たさない要求が適用される場合も記述できる。目標の真偽が確定していれば一方に従い、他方に違反する。それによって目標とその否定を両方とも事実として主張したことにはならない。どちらの規範を優先すべきか、実行可能か、責任があるかは別の内容である。

今回の遵守・違反は現在の評価状況における条件である。期限、将来の達成義務、例外、権限の正当性を補ってはいない。未記録を偽とする処理もない。検査では確定した真偽を与えており、現実の不完全な証拠から違反を認定する手続きではない。

適用と遵守・違反の定義は、渡された式の記述を評価する脱引用を含む。現行文法では、それらの定義をさらに記述として引用することを許していない。この制約を回避したふりはせず、拒否を回帰検査する。規定の採用関係 `rba` と、式を実行しない構造の分類 `rbe` は参照できる。

`rbe` は式の記述の全領域に存在量化するため、有限検査器では評価できない。知っている数個の式だけを全領域として扱うことは拒否する。これはNoemaで条件を書けないという意味ではなく、この検査器で全ての該当例を判定できないという限界である。

## カントへの部分接続

第三段落の `Satzungen` に、採用された条件付きの規定という構造を `hd2` として接続した。特定の出所・役割・条件・目標は原文へ補っていない。名詞の固定性、制定の機構、一般的な拘束性は未完であり、この語の意味を全て記述したとはしない。

`Formeln`、機械的な道具という描写、自然的な能力の使用と誤用、足枷の比喩と未成熟の持続への働きは残る。今回はこれらの句まで原文の対応範囲へ追加していない。新しい本文の主張も追加せず、統合した親文書の全宣言と9主張を保持した。

一般文書は基本述語1・定義4、原文接続文書は累計基本述語178・定義243である。新しい文法・実行時機能・翻訳規則は追加していない。

正規形の原文接続文書は累計35,588文字で、追加は716文字である。一般定義を含む文書全体の分量であり、単語の翻訳長を意味しない。短文化の課題は引き続き残る。
