# 実際の原因と、原因説明への採用

カント冒頭の「自分に原因がある未成熟」の条件を、説明への採用から実際の原因へ改訂した。[アカデミー版の電子本文](https://korpora.org/Kant/aa08/035.html)では、理解力の不足と決意・勇気の不足を、未成熟の原因として対比している。今回の読解では、誰かが原因として挙げたという報告だけではこの条件を満たさない。

この変更は定義の内容に関するものである。本文は著者がその定義を提示したことを引き続き表し、特定の人物が実際にその状態にあるとは主張しない。原著者の哲学的主張を実証することと、その主張をNoemaで記述することも区別する。

## 原因として採用されても、原因とは限らない

旧版の `bd` は、未成熟 `bc` と、決意・勇気の不足 `bs` を原因説明へ採用して理解力の不足 `bj` を採用しない条件 `ed` を結んでいた。この形では、実際の因果関係がなくても、さらに `bs` 自体が成立しなくても、採用の記録だけで条件が成立した。

改訂版では、性質記述の要因が結果の成立へ因果的に寄与する基本関係 `hzie` を加えた。要因側の対象・要因記述・結果側の対象・結果記述・評価状況を引数とし、説明への採用、単なる共存、先後関係からは区別する。唯一・十分・必要な原因であることや、特定の介入モデルは要求しない。

一般定義 `rqqu` は、両内容が同じ評価状況で成立することと、同じ記述・対象間の因果的な寄与を結ぶ。`rqqv` は、選択した要因が `rqqu` の実際の原因で、除外した要因はその実際の原因ではないという対比を作る。

否定は原因であることへ作用する。理解力の不足が存在しても、それが当該結果の原因でなければ対比を満たせる。「理解力が十分である」を新しい必要条件として追加しない。一方、選択した原因については、決意の不足・勇気の不足・未成熟の内容と因果関係が必要になる。二つの不足を連言で扱う従来の読みは残している。

説明への採用を表す `ea` と `ed`、内容の共存を表す `eb`、共存と採用を結ぶ `ec` は変更していない。これらと実際の原因を表す定義を併存させ、誤った原因説明や、実際には原因だが説明には採用されていない場合も区別できるようにした。

## 引用の層を保つ本文への接続

`rqqv` は任意の性質記述を脱引用して検査するため、層1の評価を含む。これをそのまま `bd` の内部へ呼び出すと、層0で引用している `bi` の制約に違反する。

本文では、既知の `bs`・`bf`・`bj` を直接評価する形に展開した。記述の引用は同じまま因果関係へ渡すが、内容の真理は既存の性質定義への直接適用で調べる。引用の層を下げる例外や、評価を隠す処理は追加していない。一般形と本文の展開形が有限モデルで一致することを検査する。

[改訂本文](../examples/v016/kant-factive-cause.noema)は260基本記号・1,118合成定義・16文となる。変更した既存定義の本体は `bd` だけで、他の宣言と本文16文の構文は保持した。`be` の説明にも、この版の `bd` が実際の因果条件を使うことを明記した。[独立文書](../examples/v016/factive-cause.noema)には離脱までの依存先と、対照用の旧 `ed`、新しい一般形を収録する。[完全な意味規約](../data/factive-cause-basis-v1.json)に改訂元と従来の限界を保存した。

## 検証と限界

五条件32組合せで、本文の展開形・一般形・離脱の評価を照合する。要因側と結果側の人物、原因の向き、記述、評価状況の取り違えも両文書で調べる。説明への採用の四組合せを独立に変更し、実際の因果条件の真偽が変わらないことを確認する。

旧版との六比較には、採用されているだけの偽の原因、要因が存在しない場合、除外した要因が実際には原因である場合、実際の原因が採用されていない場合、除外した要因は存在するが原因ではない場合を含む。前段の本人・過程・能力評価に関する13例も検査する。

二例では `bd`・一般形 `rqqv`・旧 `ed` を短絡変換とキャッシュなしで照合する。全過程 `bi` の展開を含む五問すべての非短絡評価は実行ステップ上限を超えたため、この補助照合の対象にはしていない。全過程は通常の短絡評価を用いた32組合せと対照例で検査する。未知の因果関係は評価時に拒否し、著者の定義提示では内容を実行しないこと、一般形の層0引用が拒否されることも確かめる。

```powershell
python -X utf8 -m pytest tests/test_factive_cause.py -q
python -X utf8 -m scripts.check_factive_cause --verify-only
```

[意味確認記録](../data/factive-cause-review-v1.json)は固定原文の第三文と、比較した電子本文の保存位置・ハッシュを示す。原刊画像との照合ではなく、固定原文の綴り・句読点は変更しない。[検査報告](../reports/factive-cause-v1.json)には型・表記・固有文字の往復・CLI解析も含める。

因果寄与の意味を明示しても、その心理機構や現実の因果の発見方法を説明し終えたわけではない。決意と勇気の不足の結び方、程度の基準、能力評価範囲、`wenn` による条件提示の扱い、第一段落全体の意味確認は残る。他の段落の原因説明も再点検が必要であり、今回は原文の新しい範囲や意味確認済み区間を加算しない。
