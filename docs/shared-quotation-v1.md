# 同じ話者・聞き手を保った許可と服従の引用

カント第17区間の引用部分を、話者・聞き手・基準文脈を引数に持つひな形として本文へ部分接続した。前段で作った選択許可と要求への適合を使い、複数の聞き手に対する二つの内容を同じ条件で構成する。[本文草案](../examples/v016/kant-shared-quotation.noema)は1,547宣言・18文で、親の1,510宣言と17文を保持し、最後に引用の帰属を一文加えた。

## 聞き手ごとの希望と要求を結ぶ

`rua` は、同じ基準文脈で選択した各聞き手について、その人の役割範囲・要求記録・行為記述・極性を既存 `rty` へ渡す。要求の網羅性と履行を各人ごとに確認するため、一人が従ったことで別の人の不履行を補うことはできない。

`rub` は同じ聞き手範囲を、話題・程度の全組合せへの許可 `rtu` に接続する。希望の範囲は本人ごとに取り出す。許可は全員にあっても、一人が要求を満たしていなければ服従側の内容は不成立になる。その逆も表せる。

`ruc` は、同じ話者・聞き手範囲・基準文脈・要求関係の閉じた記述を両方へ渡し、許可を述べる主張と要求への履行を促す指令の列を作る。一方だけ別の話者や聞き手へ差し替える引数は設けていない。聞き手範囲が空の場合は両側とも全称条件として成立し、存在を補わない。

## 本文の公的な発言への接続

許可対象の行為は、既存 `rri` によって、自分の理解力を使い、自分を語りの帰属先として公的に提示する行為記述から構成する。許可側の役割と話題は、同じ行為記述を構成する提示項目から取り出す。別の役割や話題へ取り替えれば、構成された対象記述も変わる。

これは `räsonnieren` の一つの部分的な読みである。推論の内容・正当性や全語義を説明し終えたとは扱わない。程度の分類も入力として残り、具体的な量の測定や上限、行為の量との対応は未完である。

## 実際の発言や服従を断言しない帰属

`hzsquotation` は引用内の話者・聞き手・文脈を閉じた記述として受け取る。特定の君主や現実の聞き手を本文外から補わない。`hzsattribution` が帰属するのは、著者がこの箇所でその引用ひな形を提示していることだけである。

引用内容が現実に真であること、許可が新設されたこと、指令が実行されたこと、著者が読者へ直接命令したことは、この帰属から導かれない。「誰だけがそれを言えるか」という上位の条件は、別途接続する必要がある。

## 検証

[共通定義](../examples/v016/shared-quotation.noema)は15宣言・本文0文で、今回の新規定義は三つである。[最後の帰属文を抽出した文書](../examples/v016/shared-quotation-core.noema)は66宣言・1文。40テストが通過した。

二人の許可と実行を変える16組合せ、聞き手の一人だけを選ぶ場合と空範囲、他人・別出所・別文脈の要求、未記載の要求、同じ真偽を持つ別記述を検査した。有限モデルでは行為記述の量化だけを二記述へ限定した診断用の複製を使い、保存本文の全記述域の評価は拒否されることを確認した。これを全域の意味検証とは扱わない。

実際の本文と抽出文書について、引用を構成する際に未知の内容を評価しないこと、独立に書いた式と引用の構造が一致すること、箇所・著者・範囲・文脈が違えば帰属が成立しないことを確認した。本文の役割・話題と行為記述に同じ参照が使われることも検査した。

長形式・短縮形式・固有文字の往復、文書と検査記録の再現、三文書のCLI解析、抽出文書のSVGのXML検査が通過した。SVGの目視検査は行っていない。
