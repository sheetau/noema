# 役割が提供する活動と、実際の措置

医師の説明へ、判断への援助に加えて措置を提供する実践を接続した。実施者と受け手を持つ活動を記述し、その提供を役割の機能として引用できるようにした。活動を提供する役割の保持、必要とされる専門性、本人が実際に持つ技能、現在の活動の実行を分けて述べる。

## 二者間の活動を記述する

一般定義rqxuは、同じ行為の生起dg、同じ実施者の参加df、実施者から受け手への措置hzw5、その措置が扱う事項の関係を結ぶ。別行為への参加や別人への措置を混ぜない。hzw5は、評価や指示を述べることだけとは区別した、措置を施す行為の構成内容である。実施者自身の操作だけでなく、能動的な当事者として他者と遂行する場合も含む。

医療の例ではhzw6が、同じ受け手について身体的健康shと病気・損傷・不調への対応hzw2に関する事項を指定する。これを実行評価すると、該当する行為が実際に生じ、指定実施者が参加していることを要求する。一方、病気が現にあること、措置が適切であること、治癒が成功したことは要求しない。予防的な措置や不成功の処置も記述できる。

hzw6の第一引数は実施者、第二引数は受け手である。二つの位置を逆にした活動や別人への活動を同一視しない。一般構成では自己への措置も許す。原文の供給元と本人が異なる条件は、既存の供給関係側で保つ。

## 役割と資格へ結ぶ

hzxaは、二者間の活動を提供する機能を役割へ結ぶ。その第一引数の位置には役割の担い手、第二引数には受け手を対応させる。hzxbは同じ提供機能が主要な務めの一つであることを表す。別人が実施する活動について助言するだけの役割と、その担い手が当事者として活動を提供する役割を分けられる。

hzxdは、その活動を第一引数の実施者として提供する専門的な知識・技能の保持を表す。学習・経験による技能であり、現在の実行、成功、役割や免許の保有は別である。hzxeは、同じ本人について、従来の臨床上の判断を援助する専門性hzw4と、措置を提供する専門性を結ぶ。

一般定義rqxvは、一つの同じ役割に、保持・判断への援助機能・その主要性・活動の提供機能・その主要性・資格要求の六関係を結ぶ。活動と資格は記述として渡すため、その内容を実行評価しない。修理など別の二者間の活動にも同じ構成を使える。

本文srは、この六関係で判断と措置の提供を結び、両方の専門性を資格要件とする役割へ改訂した。旧来の判断役はrqxwとして保存する。現在の技能が不足する担い手や、今は処置をしていない担い手についても、役割と実際の状態を分けて表せる。

## 原文への適用と限界

固定済みの[AdelungのArzt項目](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_3_3_3081)にある治療の知識と実践を参照し、今回その二面を役割の説明へ結んだ。医師が常に単独で手作業を行うという条件は加えない。個々の原文の仕事は依然として食事・生活の調整の判断snであり、原文にその場の処置や治癒の生起を挿入するものでもない。

この用例に採る歴史的な職務の範囲と条件文全体の最終確認は残る。全診療形態、全時代・地域の職種境界、治癒の因果機構をこの定義だけで説明したとはしない。基本関係を四つ追加したことも、医学的概念の全基礎を構成し終えたことを意味しない。
