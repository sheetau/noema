# 電位降下と電子の速度

アインシュタイン1905年論文のu0269・M0438について、電位差、場の積分、電子の速度の関係を部分記述した。既存の仕事・運動エネルギー・収支を再利用し、同じ電子、場、基準系、運動過程の両端へ結ぶ。先行197文を保存し、式の主張と導出への帰属を二文追加した。

[原刊921頁](https://de.wikisource.org/wiki/Seite:Einstein-Elektrodynamik.djvu/31)では、`P = ∫X dx = (μ/ϵ) V² (β−1)` と書かれている。原刊画像と電子MathMLの分母が電荷ϵであること、正規化係数の根号と減算の符号を照合した。積分の上下端は印刷されていないため、前段の初期静止・原点からの軸上運動を引き継ぐ読みで明示した。この補足と原文の印刷内容を照合記録で区別する。

## 符号と適用条件

電位差Pは、初期電位から最終電位を引いた降下として扱う。非零の電荷qについて、数値式を `qP = μV²(β−1)` と表す。質量と光速度を正、速度を零以上かつ光速未満とし、βには既存の正の正規化を使う。零電荷は除外するため、割り算を消去した結果として零電荷の不定な式を受け入れることはない。

電荷の符号は固定しない。正の運動エネルギーを得る場合、負の電荷には負の電位降下が対応する。両方を同時に反転すれば式は変わらないが、電荷だけを絶対値へ置き換えると式を壊す。

場の積分には既存の向き付き積分`sero`を使う。単位電荷での積分を電位降下とし、同じ場・上下端で電荷qの仕事を求め、仕事とqPの等値を明示する。逆順の経路では符号が反転し、同じ端点では零になる。電荷零で仕事が零になる積分は扱えるが、電荷で割る速度の公式には適用しない。

## 電位関数と本文の接続

一般定義では、領域内の全ての二点について、電位関数の値の差が場の積分に等しいことを要求する。一つの経路の両端が合うだけでは、この条件を満たしたとは扱わない。二点の降下を取り出すときには、その両端が同じ領域に属することも要求する。

電位の基準値を全域で同じだけずらしても差は変わらない。例えば場が`X(x)=2x`のとき、`φ(x)=3−x²`と`φ(x)=103−x²`は同じ降下を与える。一方、`φ(x)=3+2x²−x³`は0と3で同じ値を与えても途中の場と合わない。検査では、この違いを多項式の係数全体の恒等式で確認した。

本文は原点から指定終点までの局所的な積分を使う。局所積分から全領域の電位関数の存在まで推定せず、一般定義は独立して収録する。本文の電位降下の帰属は、同じ交換過程・場・系K・開始・終了・電位単位・文脈を保持する。

導出の前提には、既存の初期運動エネルギー零・放射零・閉じた収支・仕事積分と、同じパラメータの運動エネルギー式を置いた。積分の線形性も別の明示条件である。数値式がたまたま一致しているだけでは、これらの物理的な前提を認定しない。著者の「導出から従う」という接続には、この前提を具体化した候補を用いており、原文が全条件を列挙したという主張ではない。

| 定義 | 内容 |
| --- | --- |
| `seuq` / `seur` | 有理数 / 実切断での符号付き電位降下と速度の式 |
| `seus` / `seut` | 場の積分としての降下 / 同じ積分と電荷付きの仕事 |
| `seuu` | 両端の電位値の差 |
| `seuv` / `seuw` | 全領域で場と整合する電位関数 / 領域内の二点の降下 |
| `seux` / `seuy` / `seuz` | 本文の積分と帰属 / 数値式 / 等号列の接続 |
| `seva` | 同じエネルギー過程の導出候補の前提 |

## 検証と残る課題

有理数の一般命題として、収支と仕事から数値式が従うこと、電荷と降下の同時反転、共通の電位基準の変更、固定した値に対する非負速度の一意性を検査する。電荷の符号を捨てる主張には反例を残す。本文と抽出版では、電位の帰属先・場・出来事・単位の取り違え、初期運動・放射・他の移転を検査する。

実切断の実行例は登録した有理数を使う。積分と全域の電位関数の検査には、登録した多項式を厳密計算する解析的なモデルを使い、未知の関数を標本から推定しない。全実切断の定義を有限個の点で証明したとは扱わず、通常の有限評価では全称条件の実行を拒否する。

単位は電荷と電位の積、場と長さの積分が整合する規約を前提とする。測定・校正、三次元の経路独立性、時間変動する場、全実切断の積分の線形性と基本定理の機械的証明、原文全体の意味一致は残る。以前のM0427の中間積分にある質量係数の欠落も、この式の追加によって解消したとはしない。
