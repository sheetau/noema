# 静止する単位電気量への力

u0173第四・第五文を一群として、静止条件、同じ電気量、力を評価する出来事、同じ系の位置と単位、場の三成分、力の記録、定義への参照、著者の提示を接続する。既存の瞬間速度seoc、単位付き電気量sbw2、電気的作用eibs、場の静止試験応答ejtsを再利用する。原文が述べる二つの条件を同時に成立した事実へ変えない。

Kでの静止は同じ測定設定での静止x4を使う。kでの「少なくとも当該瞬間」の静止は、同じ対象の座標時刻による履歴と当該出来事を保ち、三つの座標微分が0となることで構成する。正の幅を持つ両側の内点を要求する既存のseocを用いるので、孤立した一点の記録や片側だけの履歴では足りない。加速度が非零でも当該瞬間の速度が0なら許し、近傍全体の静止は要求しない。

同じ点状電気量zolが力を評価する出来事zpoでも単位値1であるという読みを、Kとkのそれぞれの記録へ明示する。校正の出来事zooとzpoを勝手に同一化しない。これは原文で与えられた単位電気量の保持を記述する条件であり、任意の時間にわたる電荷保存の証明ではない。

その系の明示した座標単位で対象の位置を与え、同じ場所・時刻・量単位・場単位・力単位を共有する。電気量1、単位積の換算1の下で、同じ電場の三成分と同じ対象に働く力の三成分を結ぶ。同じ場は全領域・全符号付き試験量の静止試験応答として定義され、その当該点での量1への応答も同じ力に一致する。場の全方程式をこの同定の前提には加えない。

この電磁場の文脈での力は、理想的な試験電気量への局所的な作用と読む。重力・支持力などを含む合力ではない。既存の静止試験応答の規約に従い、実際の有限試験体が場を乱さないこと、真空を占有すること、測定を実行したことは主張しない。場の座標尺度ta/rbを先行校正のcm/秒の座標数値に置き換えず、同じDynの力でも校正の相手へ及ぼす力と、今回zol自身に働く力を区別する。

第四文のdefinitionsgemäßは、既存の場の定義を根拠にして述べるという一般的な参照関係へ結ぶ。定義内容・条件文・著者は別の引数で保持する。第五文はkで測る力と(X′,Y′,Z′)の同定を同じ系の記録へ結ぶ。原刊909頁の両文とM0316/M0317を照合する。段落冒頭の解釈導入、末尾の二表現への導入、段落全体の意味判断は残る。
