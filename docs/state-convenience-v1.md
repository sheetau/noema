# 状態にある場合の便宜さと負担の評価

[状態の便宜さの定義](../examples/v014/state-convenience.noema)を追加し、[カント第二段落の草案](../examples/v014/kant-state-convenience.noema)に、未成熟でいることの便宜さを述べる文を接続した。原因説明と三つの代行例の間に置く。これで第二段落の冒頭四文には全て部分草案が対応するが、意味一致の確認はまだ完了していない。

## 評価しているもの

rjは、本人が開始時点でその状態にあり、一つの選択可能な方法について、評価する結果が非空で想定結果に含まれ、その全結果で状態と実用上の目的が共に成立し、方法の負担が基準内であることを要求する。目的だけを容易に達成できても、その評価結果で状態が失われる場合は、この条件を満たさない。

既存の低負担な達成ndへ、状態と目的を合わせた内容を渡して構成した。状態を保つ方法、目的を達成する別の方法、負担の低いさらに別の方法から条件を集めることはできない。

これは「その状態にある場合、低い負担で実用上の用を足せる」という操作的な読みである。状態に入ることの容易さとは分ける。また、継続経路の全瞬間で状態を保つことまで保証する定義ではなく、明示した評価結果での保持を要求する。便利さの全語義をこの条件に還元したとはしない。

rkは本人・元の文脈・仮定場面を結び、非空の場面範囲の全てでrjを要求する。方法の利用可能性と負担は各場面で評価し、負担の判定基準は元の文脈へ固定する。仮定場面と文脈が違うために、基準まで無関係なものへ入れ替わることを避ける。

## 原文の状態と目的への接続

ulは状態として既存の未成熟bfを、実用上の目的として前の代行例と支払いの文で使ったswを渡す。未成熟の定義を仮の真偽へ置き換えず、本人の理解力を独立に使用する方法についての既存の条件をそのまま評価する。

unは、この文脈で評価に採る人物の範囲が非空であり、その全員が人でulを満たすという内容を表す。適用する人物・仮定場面・目的・負担・基準は、解釈の前提として明示する。全人類や全ての場面で無条件に成立すると補わない。原文の一般化をどの範囲で読むかは、この草案で一意に確定していない。

状態への好意を表す既存のid、行為の理由を表すme、自ら発意した行為のoaは、この便宜さの条件に含まれない。低負担で用を足せることだけから、その状態を好んでいる、自由に選んだ、実行した、道徳的に望ましいとは推論しない。著者が未成熟を推奨しているという条件も追加しない。

本文ではunの記述を著者の主張として帰属させる。著者への帰属を検査するだけで未成熟や便宜さの内容が成立すると認定したり、読者本人が未成熟であると補ったりはしない。

## 四文の部分草案の対応

原文単位kant-1784:u0009の先頭から、原因説明、便宜さ、三つの代行例、支払いと将来の引受けの四文を、談話箇所mw・uo・s3・t4へ対応させた。文の提示順と原文区間を保ち、接頭区間の非空白文字を全ていずれかの部分草案へ割り当てた。

これは区間の草案化についての記録であり、全ての語義や含意を説明し終えたという判定ではない。とくに、便宜さの程度、一般化の範囲、soや皮肉の働き、先行する未成熟等の基礎概念には課題が残る。四文以後の段落も残っている。意味確認済み全文単位は、カント0/20・アインシュタイン0/282のままである。

新しい基礎定義記録では、以前の版から継承していた「便宜さと支払いの文を含めていない」という記述を除いた。以前の草案とその記録は変更していない。現在の不足と、過去の作業段階での不足を混同しないための整理である。
