# 同じ民衆への漸次的な反作用

第四文の前件に構成した発達を、同じ民衆の心的傾向へ作用を返す原因側として接続する。原因側には比較の前から固定した非空の成員範囲を用い、その全員が影響先の共同体に属することを要求する。対象側の既存の発達内容を使い、比喩の提示が成立したことから因果的内容の真理を導かない。

原因要因は、その範囲の全員に同じ前件の発達が成立することを表す。偽側はこの連言が成立しない側であり、全員が未発達であることまでは要求しない。原因側に含まれる一人一人が不可欠だという旧候補の条件は継承しない。民衆全員が原因側に入ることや、後件に別の原因がないことも加えない。

比較には同じ構造方程式と外生的背景を用い、原因要因だけへ介入する。観測割当ては元の方程式を満たし、原因要因が真でなければならない。真偽双方に解があり、その全解について、要因の真偽と実際の発達内容が一致することを確認する。このモデルが原文に数値データとして与えられているという主張ではなく、採用する因果解釈を明示したものである。

各解の履歴は、基準履歴の全時点と一対一かつ全射に対応し、順序も同じにする。観測解は同じ基準時点をそのまま指す。途中の時点を落とす、後の時点を前へ移す、別の共同体や特徴へ交換する、という操作で比較結果を作らない。固定した全成員・全特徴・重み・段階上限を引き継ぐ。

作用の漸進性を、観測された傾向が変化したことだけで済ませない。各時点で、観測と原因なしの解との間に、同じ人・特徴の傾向の差があるかを求める。その差の組自体にも、固定した段階上限と中間状態を伴う漸次的変化を要求する。両側で共通して進む変化や一定の既存差だけでは通らない。始点にすでにある差は許すため、発達した二性向そのものを始点で同じに戻す条件にはならない。

この要求は原因なしの全解に及ぶ。解の非決定性だけで都合のよい一例を選ばないための頑健な比較である。確率的寄与や代替的な実際原因の全てを定義したわけではない。二値特徴の粒度と段階上限に関する前回の限定も残る。

今回の接続は、同じ民衆への戻り先と、同じ発達内容に関する後続の因果的経過を扱う。Wenn/soの条件文全体への人口・時点の量化、行為能力以降、著者への全文帰属は未統合である。局所検査から意味確認済みの文字数を加算しない。
