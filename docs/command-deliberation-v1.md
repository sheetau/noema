# 命令を論じようとする内容と勤務の範囲

将校の例示文の前件に向け、同じ命令の目的適合性・有用性を論じようとする条件を構成する。前回の将校・上官・命令の束縛をそのまま使用する。文全体の重大な害の評価、服従要求、例示の提示は未統合であり、確認済みの原文分量は増やさない。

目的適合性と有用性は同一にしない。前者はその命令が目指す目的への進み具合、後者は同じ軍事組織の実務上の利害を評価観点とする。命令内容が成立する側としない側で、他の方程式と背景を固定した同じモデルを比較する。既存 `r2vi` の非悪化と少なくとも一つの改善を使う、明示した操作的な候補である。完全な目的達成、唯一の手段、道徳的な正当性、金銭的利益に限定しない。

`r32o` は同じ本人・行為の実行と指定極性の一致を表す。`r32p` はこの内容に介入要因を対応させて改善を検査する。否定命令では行為をしない側が内容成立側になる。`r32q` と `r32r` は同じ命令のモデルを、目的と実務上の利害のそれぞれの尺度へ接続する。

`r32s` と `r32t` は、これらの評価が成立するかを問う発話を構成する。`r32u` では、そのどちらかを理拠を述べて検討する論点に据える。問いは議論の論点を指定しており、議論全体を短い質問一つへ縮めない。`oder` は両論点を扱う場合も含む選言とし、両評価が実際に真であることの選言にはしない。

勤務中という範囲は、同じ本人・職務・組織の遂行場面と活動の役割帰属で固定する。役職を持つ人の全生活や、勤務外の学識者としての発信を含めない。`laut` は他者に聞こえるよう声に出す様式、`wollte` は自分で取り掛かろうとする意向と読む。実際に発言したこと、内心の吟味一般、叫び、全読者世界への公開は要求しない。

`r32v` はこの議論の意向を、同じ将校が同じ上官から命じられた同じ行為・極性・提示行為へ結ぶ。命令内容が実際に適切・有用であること、議論がすでに起きたこと、命令を実行したことを脱引用しない。有限検査では評価の構成と、評価内容を実行しない引用の接続を分ける。
