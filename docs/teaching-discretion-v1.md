# 本人の判断による自由な教示の権限

第五段落の `kant-1784:u0012[3528,3793)` にある自由な権限の否定を、職務上の内容決定権限と、その決定基準の組合せとして構成した。実際に独断で教示したかどうか、教示能力があるかどうかは別である。既存の任用方針とも接続するが、まだ文全体の提示関係へは統合していない。

[AdelungのGewalt項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_2_1_1887)は、物理的な力の用法だけでなく、行為の権能・権限を含む用法も挙げる。[Deutsches Rechtswörterbuchのgutdenken/Gutdenken項](https://drw-www.adw.uni-heidelberg.de/drw-cgi/zeige?index=lemmata&term=gutduenken)では、判断・裁量の意味と同意の意味が区別されている。今回の文は本人の判断と教会の規定を対置しているため、前者の意味を採る。原HTMLと抽出本文は[語義資料](../data/teaching-discretion-lexical-v1.json)に固定した。辞書がカントの唯一の意図を確定するとはしない。

`h247p` は、指定した制度上の出所の下で、本人がその職務で同じ主題・発話内容の教示の扱いを決める権限を持つことを表す。`h247q` は、その際に本人の判断を最終的かつ十分な基準としてよく、他者の指定した内容や規定への適合によって裁量を制限されないことを表す。二つの関係は同じ出所・本人・職務・主題・閉じたNoema発話記述・内容基準・評価点を受ける。

`r4d` はこの二条件を合わせ、`r4e` はその組合せを否定する。したがって、内容決定の権限はあっても教会の規定に従う必要がある場合は、この意味で自由な権限を持たない。規定を適用する際の個々の判断が一切できないとはしない。職務外の学識者としての自由、思考能力、実際の発言の有無も否定しない。

既存の `h237b` は独立に方針を決め直す立場を実際に行使すること、`rnk` は同じ政策の肯否が許されることを扱う。今回の権限をこれらへそのまま置き換えると、不行使や伝達行為への許可の有無に意味が変わるため、旧定義の意味を変更して流用しない。追加した二関係は権限と決定基準の明示した意味規約であり、その一般理論や法的正当化を完成させたものではない。

`r4f` は、同じ教会を出所とする同じ主題・発話の裁量否定と、[代表教示への現任用](representative-policy-v1.md) `r4c` を同じ評価点で合わせる。任用から裁量否定を論理的に導かず、否定だけで任用を補わない。was/das/dessenへの接続に使えるよう、閉じた発話記述を引数のまま保持する。教義の真理や本人の確信は実行しない。

検査は二条件と任用の八組合せ、出所・本人・職務・主題・記述・基準・評価点の取り違え、過去任用と現職の結合、未知入力の拒否を扱う。同じ真偽となる別名の発話も元の記述へ置換しない。有限モデルは基本関係の哲学的な妥当性や意味同値性を証明しない。
