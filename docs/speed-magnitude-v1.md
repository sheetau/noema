# 速度成分と非負の大きさ

アインシュタイン1905年論文§5のu0135末尾「Wir setzen:」とu0136のM0252について、二つの速度成分から大きさを指定する部分草案を追加した。静止系では同じ時刻の座標の時間微分、動く系では先行する等速運動の成分へ接続する。

一般の大きさは、m≥0かつm²=x²+y²という関係で記述する。成分xとyは正負のどちらも許す。大きさが正であることを要求していた以前の曲線時計の定義は変更せず、新しい関係では静止の場合の0も含める。原文の二乗式だけでは負の枝も満たすため、非負の速さとして読む規約を明示した。

静止系の記述では、同じ点の履歴の全出来事について、有効な座標記録が同じ二つの座標関数に一致し、第三成分が零であることを要求する。二関数の微分値は既存の相対微分 `sjs` へ接続し、定義域と評価時刻を共有する。微分の値を単に名付けた基本記号だけで済ませず、どの関数のどの時刻の値かを条件に含める。

動く系では、前回までに記述した平面内の等速運動を再利用する。同じ点の同じ二成分から大きさを得る。静止系のU、動く系のw、縦・横それぞれの符号付き成分を区別する。

著者が量を指定して名付ける関係には、棒の長さの命名で使用した `zb` を再利用した。二つの方法とそれぞれの参照名は引用された記述として渡し、命名の帰属を評価するときに測定方法や微分を実行しない。新たな基本関係や文法演算は追加していない。

先行する速度変換から、大きさどうしを結ぶ補助的な二乗式も構成した。光速をV、基準系の速度をv、動く系の成分をuとq、その大きさをW、変換後の大きさをUとすると、D=V²+vu≠0の下で次の形になる。

```text
D² U² = V² [V² (v² + W² + 2vu) − v²q²]
```

有理数の多項式検査で、既存の二成分の変換式と前後の大きさの条件から、この式が従うことを確認した。分母Dが負でもUを負にはせず、逆向きの速度が打ち消し合う場合も許す。この補助式を、角度を含むM0257の記述が完了した証拠にはしない。

八つの代数検査で、大きさの一意性、零の条件、成分の符号反転、打ち消し合いなどを確認し、負の枝と成分の単純和を大きさとする候補を退けた。実切断の具体例は大きさ9例・変換後の関係8例、微分と履歴の結合は15例、命名の帰属は6例で検査した。

微分の結合検査は、保持したアフィン関数だけを識別する明示的な解釈を使う。有限個の値から任意の関数の微分を推定する方式ではない。一般の微分の存在、実切断上の体の法則、全実時刻での履歴や測定の存在は未証明である。

新規7件を含む関連27テストが通過した。通常記法・短縮記法・固有文字の構文上の往復、CLIのJSONと構文木の一致、SVGのXMLとしての読み込みも確認した。全テストの実行と字形の目視確認は今回の検査に含まない。
