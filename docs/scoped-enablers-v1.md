# 実施者の範囲と、支援結果の能力評価

前版は、特定した実施者が本人を能力のある状態へ置けるかを表した。今回は実施者の範囲を本人ごとに指定し、その範囲のいずれかによって可能になることを表す。カントu0014第二文の受動表現への部分草案を精密化する。原文は実施者を指定していないため、現実の誰を範囲に含めるかは引き続き解釈上の課題である。

| 定義 | 内容 |
| --- | --- |
| `rlq` | 同じ実施者について、全ての利用可能な支援方法に結果があり、その全結果で本人の能力評価が整合する |
| `rlr` | 本人に対して指定した実施者範囲の全成員が`rlq`を満たす |
| `rls` | 同じ範囲に、本人を同じ事柄について能力のある状態へ置ける実施者が存在する |
| `hzev` | 人・主題・基準時点・事柄・実施者の規約へ`rlr`を接続する |
| `hzew` | 同じ範囲で、理由に支えられた自立的判断ができるようになる可能性を述べる |
| `hzex` | 全対象について現在と支援結果の評価を確認したうえで、現在能力と支援可能性の人数による不足を比較する |

実施者の範囲と事柄の範囲は、指定した基準時点に固定する。支援が失敗したときに実施者を範囲から外したり、結果時点の容易な事柄だけへ対象を変更したりしない。本人も、他の個人も、集団や装置も、意味を説明したうえで実施者範囲へ指定できる。型が個体であることだけで支援能力が与えられるわけではない。

既知の空の実施者範囲では、成功する実施者は存在しない。一方、範囲が未確定であることは空の範囲ではない。範囲への所属を未知のまま偽へ補わない。検査は指定した有限領域に対するものであり、現実のあらゆる支援を網羅した証明ではない。

支援の想定結果があっても、その結果で本人の能力を評価できない場合がある。例えば、能力判定に使う方法は存在するが、評価する結果が一つも指定されていない場合である。前版の実施者別の支援評価`rln`に加え、その全支援結果で同じ本人・事柄の能力評価`rll`を要求する。これによって、将来の評価欠落を「支援してもできない」として不足の人数に算入しない。

成功する実施者の存在と、範囲全体を評価し終えたことは別である。一人の支援による成功が確認できても、別の実施者の結果に評価欠落が残る場合がある。この場合、可能性は真になり得るが、全評価を前提とした不足の人数比較は成立しない。一つの方法に、成功する結果と能力評価が欠けた結果の両方がある場合も同様である。これは式で表された評価対象の欠落についての区別であり、実行器が未知の基本関係を要求した場合には評価自体を拒否する。

人ごとに異なる実施者が支援できれば、各人の可能性は成立する。全員に共通する一人の実施者、同時に実行可能な一つの計画、共有資源の十分さまでは導かない。共同実施や複数段階の支援は、その主体・方法・結果を別途説明する必要がある。

[一般文書](../examples/v014/scoped-enablers.noema)は3,722文字、[原文付き草案](../examples/v014/kant-scoped-enablers.noema)は169,495文字、[抽出文書](../examples/v014/scoped-enablers-core.noema)は6,000文字である。六定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-scoped-enablers-basis-v1.json)と[検査記録](../reports/scoped-enablers-v1.json)を保存する。

対応範囲は前版と同じ一文であり、原文の文字数や対応区間数は増えない。宗教的な事柄の具体的内容、確実さとよい判断の全語義、人数に還元されない程度、時代についての問答、進行と徴候、著者帰属と全文の意味確認は残る。

二人と二実施者の成功関係16通り、範囲・方法・評価欠落の八つの対照例、既知の成功と範囲全体の評価欠落の両立を検査した。原文付き文書と抽出文書では五つの条件をそれぞれ検査し、未知の内容への言及が評価を実行しないことも確認した。追加7テスト、三文書のCLI解析と構文木の一致、固有文字v2のSVGのXML検査が通過した。SVGの目視確認は含めない。
