# 共動する観測者と、動く棒端間の光往復

原刊896頁のu0036から897頁冒頭の二式までを次の統合単位とし、その依存関係を構成する。注u0280は同じ三出来事の静止系時刻と動く時計の表示を説明する注として扱う。今回は著者の想定・原理からの結果という提示・注の付着をまだ追加せず、既存261主張と全単位の判断を保持する。

`eitd/eite` は、時計と観測者の代表位置の相対変位が全区間で一定であるという共動を記述する。距離が一定なだけでは、周囲を回る観測者を排除できない。時計・観測者それぞれの同じ系・単位の完全な `se` 履歴も要求する。観測者の代表点を取り出す汎用入力 `eismh` は、身体の内部運動を凍結しない巨視的な位置の理想化である。そばにいるという `zap` は別に残し、原文にない数値の距離閾値は設けない。

`eitf` は始位置と速度成分から一次時刻関数を作り、完全な `se` へ渡す。`eitg/eith` は任意の出発位置・時刻について、光と動く端点が反射・帰着の同じ位置で出会う条件を記述する。Aを進行方向の後端、Bを前端と読む向きは、原刊の分母 `V−v` と `V+v` に対応する。この選択を、向きを固定していなかった以前の棒の定義へ遡及させない。

`eiti` は二端と往復の光の四つの完全な軌道、同じ三出来事への帰属、反射、二つの真空区間を結ぶ。復路の光の速度成分は `−V`、棒端は往復を通じて `+v` とする。光の分類・真空・反射という物理的入力と、座標上の交点は別に要求する。反射点は両区間に含め、そこでの位置の連続性を保持する。

`eitj/eitk` は同じ三記録を現行の局所時刻比較 `eiq2` と両端の全区間の時計条件 `eiq4` へ接続する。出発位置は実際のA端の関数から取る。`eitl/eitm` は時計の取り付けと観測者の共動を結び、両観測者が同じ二時計・光試行に第一節の中点判定 `bi` を適用すると記述する。判定の適用は判定条件の成立ではなく、動く時計に静止時計の要件 `qo` を課すことでもない。

検査では、有理数を埋め込んだ実切断による交点と既存 `sdb` の二式の一致、各位置・速度成分、全履歴境界の引数、三記録と観測者の取り違えを調べる。有限境界で比較する関数の値は検査用の標本であり、全実時刻の軌道を証明しない。`eite` の本来の全時刻量化は有限評価を拒否する。未知の切断や物理入力も拒否する。

次の本文接続では、`zav` を現在の静止系測定 `eip6` に結び、現行の第二原理 `eiot` に基づく二式の著者帰属を記述する。追加の想定、三つの指示の時刻、脚注の説明と付着位置も保持する。u0040の観測者ごとの判断は別の未完部分であり、この依存群の成功を全文の意味判断へ数えない。
