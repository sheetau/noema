# 動く鏡での反射と、原刊の式の不整合

アインシュタイン1905年論文の反射鏡の計算を、鏡の静止系への変換、その系での反射、元の系への逆変換に分けてNoemaで記述した。数値の変換には既存の四則演算と正のβを使う。鏡の座標面ξ=0と、旧系で動く平面x=vtも別に記述した。

原刊914–915頁の画像を確認したところ、振動数の式の最右辺に、直前の式からの導出結果と合わない分母がある。電子テキストも原刊と同じ表記だった。そこで、原刊にある式と導出結果を別々の定義として保持する。原文を書き換えて完成訳と扱ったり、電子テキストの転記訂正として処理したりはしない。

## 三段階の計算

速度比をr=v/V、入射方向の縦成分をa=cos φ、振幅をA、振動数をνとする。|r|<1、|a|≤1、A≥0、ν>0を要求する。βは正でβ²(1−r²)=1を満たす。

第一段階では鏡の静止系へ変換する。

```text
D = β(1−ra)
A′ = A D
a′ = (a−r)/(1−ra)
ν′ = ν D
```

第二段階は、鏡の静止系での反射である。振幅の大きさと振動数を保存し、方向の縦成分を反転する。

```text
A″ = A′
a″ = −a′
ν″ = ν′
```

第三段階は、第二段階の値を速度比−rで元の系へ戻す。同じ中間値を三段階で共有するため、入射値を途中へ混ぜたり、反射による方向反転を飛ばしたりしたものは条件を満たさない。

この三段階から、N=1−2ra+r²として次の結果を得る。

```text
A‴ = A N/(1−r²)
a‴ = [2r−(1+r²)a]/N
ν‴ = ν N/(1−r²)
```

有理数の定義は`seja`〜`sejf`、実数切断の定義は`sejg`〜`sejl`である。`sejd`と`sejj`が三段階、`seje`と`sejk`が導出結果を表す。Noemaの定義では分母を払った等式を使い、分母が正となる定義域を要求する。実数版のV、v、βには既存定義を使う。

## 原刊にある式を保持する

原刊915頁の振動数の最右辺は、次の形で印刷されている。

```text
ν‴ = ν N/(1−r)²
```

振幅の最右辺の分母は1−r²で、振動数のものだけが括弧全体の二乗になっている。振動数の直前の等式は、三段階の変換に使ったβ(1+ra″)倍を示している。[原刊PDF](https://sedici.unlp.edu.ar/bitstream/handle/10915/2786/Documento_completo__.pdf?isAllowed=y&sequence=1)の914–915頁と、保存した電子テキストのM0376を照合し、画像・式のハッシュを[照合記録](../data/mirror-reflection-facsimile-v1.json)に残した。

`sejf`と`sejl`は、この印刷された最右辺をそのまま保持する。導出結果との違いを確認するため、r=3/5、a=1、A=2、ν=8を用いた。三段階ではA‴=1/2、a‴=−1、ν‴=2となる。一方、印刷された振動数の最右辺は8となり一致しない。

この違いは一例の数値計算だけではない。正の振動数などの定義域のもとで、導出結果と印刷された最右辺が一致するのはr=0の場合だけであることを、有理数について代数的に検査した。速度が零の例だけでは違いを検出できない。

今回確認したのは原刊の表記と式の不整合である。誤植の由来や、その後の訂正の歴史的調査を終えたという意味ではない。原刊全体の主張を黙って一貫した理論へ直すことも、この草案では行っていない。

## 座標平面と検査

`sejm`は新系のξ=0、`sejn`は旧系のx=vt、`sejo`は後者を既存の逆ローレンツ変換で新系の座標へ移した条件である。27設定で`sejm`と`sejo`が一致することを確認した。同じ数値の座標を旧系のx=vtへ直接入れた場合は、一般に結果が違うことも検査した。

三段階の数値条件は、速度3通り、方向5通り、振幅2通りの30設定で検査した。零振幅も許す。15対照例では中間値・最終値の交換、方向反転の省略、負の振幅、零または負の振動数を区別した。全文草案と独立抽出文書で同じ結果を確認している。

代数検査は7件である。三段階からの閉じた式、係数の正値、静止系で反射を二回行うと戻ること、振幅と振動数の係数の一致、原刊最右辺との一致条件などを検査し、誤った式を使う一件は反例として拒否した。実数版の具体例は登録した有理数切断による有限の解釈であり、全実数の演算法則の証明ではない。

## 残る接続

鏡という物体と平面の対応、完全反射の電磁的な境界条件、位相と偏光、入射・反射光の所属、測定の単位と基準系の帰属は残る。特定の側から鏡へ届く条件Va−v>0や、接触の時刻・位置も別途必要である。数値変換そのものには両符号の方向成分を許している。

光圧、仕事とエネルギー収支、原文の問いと導出の談話は未記述である。今回はM0368・M0372・M0374・M0376へ部分対応を追加し、意味確認済みの全文区間数は増やしていない。

15定義を追加し、原始概念と著者の主張文は追加していない。全文草案は289,649代用文字、前版からの増分は7,207文字である。有理数の独立文書は3,657文字、実数版の依存定義を抽出した文書は8,584文字。いずれも定義を含むため、原文の各文の長さとの比ではない。
