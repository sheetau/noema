# 禁止状態と、その禁止に反対する規範（2026-10-14）

カントの軍人の例にある「正当に禁じることはできない」へ、指定された禁止状態を成立させてはならないという上位の要求を接続した。前版の公的発言への許可は現状を表していた。今回の条件は、禁止が現にあっても、その禁止に反対する要求を表せる。

[Noema文書](../examples/v014/kant-protected-speech.noema)には、250基本関係・499定義・15本文主張がある。新たな基本関係や構文は追加していない。前版の宣言・本文主張を保存し、4定義を加えた。正規形は80,846文字で、追加は465文字である。定義ライブラリを含む文書全体の長さであり、翻訳文の文字数比ではない。

| 定義 | 内容 |
| --- | --- |
| `hzq` | 指定した規制者が、本人・役割・行為を固定した対象の実行を禁じているという内容 |
| `hzr` | 評価側の出所が、規制者にその立場で、指定した閉じた政策内容を不成立にするよう求める |
| `hzs` | `hzr`があり、同じ評価側の出所・対象・文脈からの反対要求はない |
| `hzt` | `hzr`があるにもかかわらず、同じ政策内容が現在成立している |

`hzq`は、本人が発言しないという事実を表すのではなく、本人に発言しないよう要求する規範の存在を表す。この内容へ`hzr`を適用することで、規制者にその禁止状態を不成立にするよう求められる。`hzt`は、その上位の要求に反して禁止が存在している状態を検出する。

## 対象を固定する方法

既存の[閉じた政策記述](closed-policies-v1.md)を使い、`hzq`へ規制者・本人・役割・活動の四つの閉じた式を渡した通常のNoema引用を作る。対象記述には引数の式と順序が残る。Pythonの補助関数は通常の引用を組み立てるだけで、意味を外部の翻訳処理で補わない。同じ引用は人が直接記述できる。

作例では、内側の規制者を外側の要求の名宛人へ対応させ、内側の本人・役割・活動を既存`h6v`による公的使用の同じ引数へ対応させた。一般関数`hzr`は任意の政策対象を受け取るので、任意の引用を渡せば公的発言の保護になるわけではない。この対応は[検査記録](../reports/protected-speech-v1.json)の`closed_ban_target`にも保存した。

式の記述は構造で区別する。別名が同じ禁止状態を返しても、その別名に対する上位の要求は自動的に成立しない。この制約により、記述の展開・同義性を根拠にした規範推論はまだ行えない。

## 区別する状態

| 状態 | 上位の禁止反対要求 | 実際の禁止 | 上位要求への違反 | 積極的な発言許可 |
| --- | ---: | ---: | ---: | --- |
| 保護要求はあるが守られていない | あり | あり | あり | これだけでは決まらない |
| 保護要求が守られている | あり | なし | なし | これだけでは決まらない |
| 禁止はないが保護要求もない | なし | なし | なし | これだけでは決まらない |

表の積極的な許可とは、`h7b`の許可そのものを指す。`h7c`で公的使用への衝突のない許可を判定する際には、同じ許可元の禁止があれば成立しない。許可と禁止が両方存在すること自体は、矛盾した規範状態として記述できる。

本人が発言したかどうかは、いずれの状態とも独立である。実際の禁止が不明なら、上位の要求が分かっていても違反を認定しない。別の文脈に禁止があるだけで、現在の違反とも判定しない。

## 原文との関係と限界

前版と同じ`kant-1784:u0012`の原文範囲を具体化した。原文の`billigermaßen`について、指定された評価規範に反する禁止という部分的な読みを表す。ただし、その評価規範が公正・正当である根拠は、要求が存在するだけでは確定できない。あらゆる規制者への一般化、権利の全条件、軍務の欠陥、注記の内容、公衆の判断への提出という目的も残る。

今回の対象は現在の禁止状態であり、禁止を発出・撤回する行為やその時間経過ではない。以前に禁止して現在は解除した場合の過去の違反、補償、故意や責任は含まない。また、`hzs`が除く衝突は同じ評価側の出所からの反対要求に限る。出所間の優先順位は定義していない。

対応する原文範囲は増えておらず、全文単位の意味一致確認は二作品とも0のままである。

## 検証
