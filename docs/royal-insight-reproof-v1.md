# 自分の最高の見識に基づく介入と批判への曝露

第六段落最終文の「aus eigener höchsten Einsicht」と「wo er sich dem Vorwurfe aussetzt」、およびラテン語格言の内容を構成する。同じ君主による同じ作品への介入との接続までを扱い、全文の意味確認文字数は増やさない。

ここでは君主が自分の見解を、自分の採る基準で最上とみなし、その見解に基づいて介入する読みを採る。höchstenの敬称的な含みを排除した唯一の歴史的読解とはしない。著者が君主の客観的な認識の正しさを保証する文にすると、直後の批判と最高職の権威限界を取り違える。認識内容を保持することと、その内容が最上だと判断することを分け、いずれも本人の判断内容として引用する。

`r5pn` は固定した同じ領域の全比較範囲と整合した評価を構成し、`r5po` はその全項目以上という最高性を表す。同順位を許すが、都合のよい一例に優るだけでは足りない。`r5pq` は同じ本人の内容判断と最高性判断を保持し、`r5pr` は前者を同じ行為の理由に結ぶ。最高性のメタ判断まで別の動機であること、客観的な真理、現在新たに判断することは要求しない。`r5ps/pt` は既存の統治的介入と同じ七対象列で接続する。

[Kantの原文](https://korpora.org/kant/aa08/040.html)にある「Caesar non est supra Grammaticos」は、統治職を保持することだけでは、学識上の正否を決める権威において専門家の上には立てないという限界と読む。`r5pu` は本人が保持する全最高職と、その領域の全学識者についてこの限界を述べる。本人の証拠に基づく知識の優越や、専門家の市民的義務は否定しない。

`r5pv/px` は文法・言語用法・文献解釈についての一般格言の内容、`r5pw` は本文の同じ宗教的認識領域への適用である。後者は文脈に基づく拡張として明示し、文法領域だけの一般命題から論理的に導出したとはしない。[Suetonius De grammaticis](https://penelope.uchicago.edu/Thayer/L/Roman/Texts/Suetonius/de_Grammaticis*.html)第4章のgrammaticiの説明と、第22章のMarcellusによるTiberiusへの反論を、語の射程と権威の区別の並行例として参照する。Kantと同じ文言ではなく、直接の出典や伝承経路を確定する証拠にはしない。

`r5py` は同じ介入が機会又は根拠を与える応答候補に、同じ原則で同じ行為を批判し、正当化できる判断があることを表す。現実に誰かが発言済みであることや、必ず非難されることへ強めない。応答可能な範囲、批判の内容、判断者、正当化可能性を分け、原則を引用するだけで実行評価しない。`r5pz/p2` は自分の見識に基づく介入とその同じ行為への批判可能性を結ぶ。

検査では全比較・循環・同順位・代表内容、同じ本人の保持内容と行為理由、全最高職と全専門家、文字どおりの領域と文脈的適用、批判場面と実際の場面、同じ対象列の取り違えを確認する。個々の内容の真理・現実の批判の正当性・歴史的に唯一の解釈を有限モデルが証明したとはしない。
