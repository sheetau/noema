# 刊行物の呼称に、人物と周期の説明を結ぶ

著者注の刊行物名に含まれる人物への帰属と週刊の周期を、名称の綴りとは別に記述した。既存の系列・号・日付・読書対象は保ち、同じ名称使用に人物の参照と系列の説明を加える。新しい文は、著者がその系列をこの性質で指すという呼称の記述である。

原刊週報289頁では、Büschingの人物名と週刊の表題、37号・1784年9月13日の表示、版元が別々に確認できる。カント原刊494頁の短い呼び方と照合し、人物には文面の作成・選定・編成に関する編集上の責任を結ぶ読みを採用した。全記事の単独著作、印刷・販売の版元、所有権、現代の編集長職の細部までは追加しない。[画像と読解記録](../data/periodical-profile-reading-v1.json)を保存した。

刊行周期は、慣行上の方針として「この暦の連続した7日を一周期とし、通常1号を出す」と記述する。日数と号数は独立した正の整数であり、既存の32進自然数列の検査と数値化を再利用する。14日周期に2号という方針は平均頻度が同じでも別である。周期の始点や曜日、1日を何秒とするかは指定しない。

| 定義・関係 | 役割 |
| --- | --- |
| `hzwa` | 系列・暦・周期の日数・通常号数・文脈を結ぶ慣行上の刊行方針 |
| `hzwh` | 著者・使用箇所・対象記述・性質記述・文脈を結ぶ非事実的な呼称の使用 |
| `hzwb` | 人物と同じ系列の編集上の責任 |
| `rqw4` | 二つの数量を正の自然数として検査し、同じ刊行方針へ渡す |
| `rqw5` | 同じ系列・文脈の編集上の責任と刊行方針を結ぶ |
| `hzwe` | 人物参照を固定し、7日周期に通常1号という系列の性質を構成する |
| `hzwf` / `hzwg` | 既存系列の選択／同じ名称使用でその性質を用いること |

週刊専用の真偽記号は作らず、三つの一般関係と五つの合成定義で構成する。人物とその名称の参照を一つずつ追加し、名称の綴りは従来と同じ別添えの識別表記に置く。人物と系列や号を同じ対象にはしない。

慣行上の方針と実際の発行履歴は独立である。欠刊、特別号、発行日のずれがあっても、方針の存在まで否定する必要はない。一方、一定期間の実績が偶然その比率だっただけでは、方針があるとは認めない。`hzwa` はその制度的な方針を意味規約とする関係であり、刊行制度の社会理論全体や過去の全発行履歴を自動検証するものではない。

呼称で性質を使うことと、その性質の実際の成立も分ける。`hzwg` は同じ著者・名称使用・系列について閉じたNoemaの性質記述を使う。人物の編集上の責任や刊行方針が未知でも、その記述の使用は表せる。性質自体を評価するときには、これらの解釈が必要になる。これは敬称の人物分類で採用した提示と事実の区別に合わせた読みである。人物の呼称を規約とする既存の `du` は刊行系列へ流用せず、引数順と人・物の範囲を明示した一般関係 `hzwh` を用いる。

検査では100組の数量表記、刊行方針と責任の四組合せ、九つの呼称接続例、八つの方針・責任・実際の発行の組合せ、九つの周期・人物・系列・暦・文脈の対照を扱う。空列・零・負数・分数・桁の範囲外を退け、同じ平均頻度の別周期も区別する。表題・冒頭回答接続・著者注と新しい記述の計12文を、六つの同時解釈で評価する。保存した構文をそのまま使い、短絡変換とメモ化は用いない。

既存41文を保存し、著者注の説明を一文追加する。通常表記・簡略表記・独自文字v2の往復、既存の識別表記と十件の意味判断の保持を確認する。今回の説明は既に草案がある原文範囲を補うため、対応文字数は増えない。偶発性と思想の一致の基準、および著者注全体の意味確認は残る。
