# 存在する伝播と、自由の条件を共用した比較

以前の比較用の枠は、伝達経路を外から指定する伝播内容を使っていた。経路を存在量化した `hzpf` と組み合わせるときも、焦点側と比較側で人物・時間・伝播の条件をそろえる必要がある。今回、存在量化を保った枠と、自由の条件まで共用する枠を追加した。

`hzpq` は既存 `hzpf` の22引数を保ち、部分集団の閉じた述語記述だけを受け取る。`hzpr` はその枠を閉じた階数1の記述にする。既存 `rqtm` に渡すことで、独立判断、共有する自己離脱、受け手ごとの存在する経路、将来の範囲を共通にした比較を作れる。以前の経路供給関数は戻さない。

仮定する候補ごとに履歴や母集団を変える場合は、`hzps` を使う。22の供給関数は全て同じ候補を引数に受け取り、その候補での値を返す。部分集団の記述はこれらの供給関数へ渡さず、同じ条件の下で比較する範囲だけを変える。

`rqtp` は、公衆・参照文脈・許可の出所・期間枠・基準時点の対応・候補範囲・内容族を保ち、部分集団だけを差し替える枠を作る。各候補の内容を、その同じ候補の基準時点で既存 `hzpa` により評価する。焦点の内容だけ自由の条件を外したり、比較対象だけ別の候補範囲へ移したりしない。

比較の背景は、これまでと同じく主張内容から分ける。主張を否定しても背景の記述は変えず、背景の評価だけで世界の事実や部分集団の述語を実行しない。任用された後見役を表す `hzhb` と、その否定を比較する接続例を検査した。ただし、それらが原文の唯一の比較対象であるとは確定していない。

| 検査 | 確認する範囲 |
| --- | --- |
| 条件・内容・比較の32組合せ | 許可の継続は元の定義で評価し、候補内容は検査用の単純な述語として評価する |
| 候補・基準時点の五対照 | 自由のある候補がない場合、不正な候補、基準時点の取り違えを区別する |
| 存在する伝播の比較背景 | 22引数・性向記述・条件の共用を確認し、後見役とその外側の述語を引用したまま比較する |
| 未知入力と否定 | 必要な未知入力を拒否し、背景と主張が互いの不要な事実を評価しない |

一般の条件付き内容の検査には、明示した短絡診断を使う。存在する伝播の比較背景は、世界の基本関係を全て未知にした通常評価で調べる。この二つを、任意長の経路を含む伝播内容全体の真理の検証と混同しない。`hzpb` の中継列は無制限の有限列のままであり、候補表や長さ上限へ変更していない。

比較は全将来内容、または条件付きの全内容の間に置く構成である。各将来点の内部で比較する読みを同じものとはしない。比較対象の実際の成立、数値確率、原文に適した尺度・視点・解釈値は補わない。それらの選択と本文への全内容の接続は未完なので、新しい本文主張・原文対応範囲・意味確認済み単位は加算しない。
