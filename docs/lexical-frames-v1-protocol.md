# 予測された範囲・役割と概念定義の接続

## 条件

前段の範囲・役割・出来事判定器と、概念定義を照合する共通判定器を固定して接続する。主画面の15概念分類器を拡大する学習は行わない。自然文だけを推論APIへ渡し、評価資料・正解範囲・正解の概念型・対訳表・語別規則は入力しない。

構造側はKWJAとevent-gate-v6の選択済みヘッドを使う。文字位置は検証済みAlignedJapanesePASへ差し替え、旧文字位置処理との違いも実行条件に残す。概念側はshared-matcher-v1の3係数方式を固定する。過去の比較を既に観察したうえでの接続であり、今回の資料でモデルやepochを選ばない。候補は同実験の91概念の日英定義、全候補の先頭スコアを記録する。型の正解で候補を絞らず、不適合な先頭候補を次点へ置き換えない。

同じ原文位置の照合は共有するが、異なる原文位置の同一対象への統合は行わない。範囲を原文の単語表から補正しない。生成・辞書等の禁止経路5種を遮断する。重み、候補定義、依存コードとモデルのハッシュ・実行環境を記録する。旧学習とPython/PyTorchの版が異なる場合、同一環境だったとしない。

## 評価

予測前に作る18日本語文には能動・受動、役割逆転、旧15概念の外の語、未知概念、状態、数量、否定・時間、関係節、主体省略を含める。過去に使った概念や文型も含む小規模な接続試験であり、広い自然文の独立した採用評価ではない。英語の構造抽出はこの接続の対象外として明示し、日英の完成基準を満たすとはしない。

予測した述語主辞と人手で注釈した述語範囲の重なりで出来事を対応付ける。この対応付けは評価時だけであり、予測の入力・修正に使わない。役割は原文範囲が完全一致する場合だけ一致とする。出来事数・役割と範囲・述語概念・項概念を合わせた全フレーム一致を測る。候補のない正解、余分な出来事・役割、重複割当ても分母に残す。

診断として正解範囲での概念照合も同じ資料で別に行い、予測範囲からの結果と区別する。未知概念に相当する候補は存在せず、先頭候補を返しても正解には数えない。未知入力を確定出力しないことと、意味的に未知と判定できることは区別する。

この接続は否定、時制、数量、名前、語の性質、照応、発話・節の作用範囲の確定が未接続である。常に研究用の未確定結果を返し、肯定や時刻を補ってNoemaの完成した文章として出力しない。完成条件の「確定率80%以上・全文意味構造一致率95%以上」については、確定率0%・確定出力の一致率未定義の不合格として報告する。部品のフレーム一致を全文意味の一致と呼ばない。

先頭4文は原文から反復し、全18文で構造側の単独実行と不変であることを確認する。保存結果から評価を再計算する。実行時に正解データへアクセスする推論経路を作らない。
