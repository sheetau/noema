# 検証対象と既存証拠の引き継ぎ

意味確認済みの二作品を、描画変更のたびに原文から再審査しない。既存の採用解釈と判断は保持し、変更された層とその依存先だけを検証する。これは検証範囲の規則であり、固定表記用の新しい描画器・復号器が既に完成したという宣言ではない。

## 分けて扱う三つの対象

1. 原文とNoemaの意味の対応。原文、構文、語義、参照先、採用解釈を固定した既存の意味判断。
2. 文書の表現変換。共有語彙への名前の付け替え、定義の展開・共有、文書参照の具体化。元の構文へ戻す対応と、変更した意味規約の有無を検査する。
3. 円文字の表示と復号。実際の円・線から、同じ構文・語・引数順・束縛・引用・参照を取り出せること。SVGのメタデータや付属ASTを読むことでは代替しない。

`project_work audit --full` は過去の判断記録・原稿・語義・依存入力・草案対応の全量再確認であり、円文字の画像復号そのものではない。これが通っても固定した文頭規則との一致を保証しない。

## 表記変更で意味の証拠を引き継ぐ条件

確認済みの構文をT、共有語義と参照規約をMとする。新しい描画Eと、図形だけを入力とする復号Dについて、`D(E(T)) = T` が成立し、Mも変わっていなければ、既存のTとMに対する意味判断を引き継げる。元の内容に対する有限モデルの物理・哲学診断を、表示変更だけを理由に再実行しない。

一致は許可した名前の対応と正規化の下で確認する。単に同じ真偽を返す例があること、文字数が同じこと、Tのハッシュだけが同じことでは、新しい図形を読める証拠にならない。新しい図形を別に復号した結果、または適用条件を検査できる局所変換の証明が必要である。型・作用範囲・語義・指示対象のいずれかが変わる場合は、影響する部分の意味確認へ戻る。

## 変更に応じた検査

| 変更 | 必要な検査 | 変更だけを理由に繰り返さない検査 |
| --- | --- | --- |
| 内容も成果物も不変 | 保存済み証拠と必要な入力の内容ハッシュ確認 | 生成、画像復号、意味診断の再実行 |
| 円の配置・文頭・改行だけ | 変更規則の局所対照例、衝突・読順・境界検査、影響する出力の構文回収一致 | 原文の再読、同じ構文に対する意味診断 |
| 既存語の名前や参照の表現変換 | 元へ戻す構文一致、語義と参照先の対応 | 対応が証明済みの変更なし部分の意味診断 |
| 定義・語義・量化範囲・参照先が変更 | 変更部分と依存する主張の意味診断・判断 | 無関係な文・作品の意味診断 |
| 解析器・復号器・キャッシュの変更 | バグを区別する例、構文種類・束縛・引用の対照、キャッシュ有無の小コーパス比較、影響範囲の検査 | 理由を特定しない二作品と全歴史版の反復全量走査 |

変更が全成果物の字形に及ぶ場合、新しい出力全体の軽量な構文回収照合が一度必要になることはある。変更していない意味の再審査とは分ける。影響範囲が不明なときは都合のよい標本だけで完了扱いにせず、範囲の特定から行う。

## 共通規則を先に完成させる

固定した見た目と両立する規則について、語の識別、引数の順序と数、束縛・引用の範囲、文頭と改行の区別を明示する。各構文要素が一意に読めることと、結合・配置がその区別を壊さないことを、最小の区別可能な対照例で確認する。構成規則から任意の深さへ保証を拡張する場合は、その論証と配置上の前提を記述する。有限テストの通過だけを一般的な証明と呼ばない。

新しい実装の最初の到達点は、小さい独立例での固定文頭規則と一意な復号の両立である。ここが未確定のまま、両作品の累積ページを繰り返し生成しない。既存の中間構文・語義・参照対応・意味診断は再利用し、新しい実装に必要な差分だけを接続する。

長時間の残る検査は[進捗・中断再開](long-jobs.md)を備える。変更した規則、再利用する証拠、再実行する検査とその理由を実行前に記録する。既存の判定条件を変更する場合も旧検証器と証拠は保存し、代わりの条件が何を保証するかを明記する。古い報告のハッシュ更新だけで新しい表記を検証済みにしない。
