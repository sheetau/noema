# 定型表現の型と引数数を固定しない

定型表現の分類にあった、個体一つを受け取って内容を返す型への制約を外した。零引数の定型文、二者の関係、数値を含む式、関数・列・質問・記述を引数に取る式を、元の型と構文を保ったまま同じ保持関係で扱える。第三文の対象分類へこの構成を接続し、使用・誤用・因果・持続の既存条件は保持した。

以前の `h22` は、関数の記述型を `i[h[a] e]` に固定していた。言語本体の引用合成は既に任意の型と引数数を検査できたが、この分類ではその範囲を使えていなかった。新しい構成は既存0.16の構文を使う。型や引数数ごとの概念表、生成モデル、新しい文法は追加しない。

## 元の式を復元できる共通コード

型Tの閉じた式Mを、次の構文の引用として保持する。

```text
「(λx:T. x=x)(M)」
```

この包み全体の結果型は真偽だが、コードとして使うのはその引用の構文である。型Tと式Mが内部に残り、復元時には両方を取り出して型検査し、再び包んだ結果が元と一致することも検査する。包みを評価して得る真理値から、元の式やその意味を復元する方式ではない。

例えば二個体から内容を返す関数 `relation` のコードは、既存の代用記法で次のように書ける。

```text
r[c[i[term h[a a] e][e[v term][v term]]][p relation]]
```

関数の型も参照名も引用内に残っている。別の関数が同じ有限モデルで同じ結果を返しても、コードを同じものにはしない。変数名の正規化は行うが、別名展開や適用の簡約はしない。コードの作成・復元・識別は内容を実行しない。

`noema.expression_codes` は構文木に対する決定論的な補助APIである。`encode_expression` は元の引用と明示した型を検査して包み、`decode_expression` は型と元の引用を返す。`is_template_code` は、正規的な包みであり元の型が関数型であるかを検査する。単なる真の式や、関数以外の式を包んだものを定型関数のコードにはしない。不正な型・自由変数・未知記号・資源上限違反を、単なる非該当として隠さない。

引用の層も保存する。層1が必要な式を包んでも層0にはならない。本文の分類は従来と同じ層0の定型表現を対象にしており、全ての引用層を一つの型へまとめる変更ではない。通常の型検査、深さ制限、計算量制限も残る。

## 本文への接続

| 定義・関係 | 内容 |
| --- | --- |
| `r2fd` | 上記の構造検査で判定できる、層0の定型関数コード |
| `r2fe` | 同じ対象・文脈が、その同じ適格コードを保持しているという既知の証拠 |
| `r2ff` | そのようなコードが存在する対象の一般分類 |
| `hzzza` / `r2fg` | 表現が再利用する固定構成を保持する関係と、原文側の定型表現分類 |
| `r2fh` | 規定または新しい定型表現分類に属する対象 |
| `r2fi`–`r2fk` | 新分類を使う同じ使用活動・対象と利用者の二位置・足枷の比喩帰属 |
| `r2fl` | 同じ新分類を使う、条件付き持続の未採用候補 |
| `r2fm` | 旧来の一項の型を共通コードへ包む明示的な移行式 |

原文は定型表現の型や引数数を指定していないため、旧来の一項制限を維持する理由にはしない。一方、「固定した再利用可能な表現の構成を保持するもの」という読みの限界は残す。慣習や表現一般の成立、規定の拘束性、一般化の範囲、指示、持続の強さ、文全体の意味確認は未完である。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)

本文54文のうち、第三文の比喩帰属に当たる第53文（索引52）の対象分類を更新する。第三文の言い直し、第四文の仮定、先頭二文と十二全単位の判断は保持する。既存の宣言と意味規約は保存し、新しい九定義、一つの構造的に判定できる関係、一つの保持関係を追加する。

旧保持関係の事実が自動で新保持関係へ移るわけではない。`r2fm` は同じ旧式の記述を新コードへ変換するが、そのコードを同じ表現が保持しているという解釈も明示する必要がある。また、`r2ff` の存在量化は式記述の全域に及ぶため、既知の六種類だけを全域として評価することは拒否する。既知コードを伴う `r2fe` の検査と、この分類全体の量化を区別する。

## 検査

補助APIでは、異なる引数数・型、束縛名の正規化、元の記述への往復、参照名の違い、引用層、不正な型、自由変数、形の崩れた包み、資源上限を検査する。原文側は六つの型について保持対象・コード・文脈を変える24対照、旧型からの移行、比喩帰属の八対照、未知入力、有限評価の限界を検査する。内容の実行は禁止したモデルでも、コードの作成と保持の検査は成立する。

使用・因果・持続と条件付き候補の依存定義が変わらないことを照合し、過去の検査記録を再利用する。今回それらの有限モデルを全て再実行したとはしない。三文書の短縮記法・展開記法・固有文字の往復も確認する。新しい原文対応文字数や意味確認済み分量は加えない。

```powershell
python -X utf8 -m scripts.check_polymorphic_forms
python -X utf8 -m pytest tests/test_expression_codes.py tests/test_polymorphic_forms.py -q
```
