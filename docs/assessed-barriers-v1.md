# 評価を伴う達成不能と、自由の障壁

カント第17区間の「実際には越えられない障壁を設ける」という節を、前段の見かけの利益へ接続した。同じ人・活動・目標について、制度条件を外した場合の達成可能性と、条件がある場合の達成不能を比較する。現実の社会制度の因果を同定したものではなく、明示した二値モデルに相対的な候補解釈である。

## 見つからない方法と、評価したうえでの達成不能

既存の `xd` は、利用可能な方法のうち、非空で整合した評価結果の全てで目標を達成するものがあることを表す。`xg` は、利用可能な全方法の評価が整合し、なお `xd` を満たす方法がないことを要求する。未評価の方法が残る場合は、単に `xd` が偽でも `xg` は成立しない。

[一般定義](../examples/v016/assessed-barriers.noema)の `rww` は、変数列・構造方程式・要因・本人・目標を固定し、次を同時に要求する。

- 要因を偽に固定した解の中に、同じ目標を `xd` で達成できるものがある。
- 要因を真に固定した解が存在し、その全てで同じ目標が `xg` を満たす。

同じ目標が両側で達成不能なら、この条件は成立しない。真に固定した側に解がない場合も、全解で失敗することを空虚に認定しない。現在の解では失敗していても、別の解で達成できるなら、全解で越えられないという強い条件には合わない。

偽の側では、一つの有効な達成方法が見つかればよい。その側の他の方法が未評価であることだけでは、既にある達成方法を取り消さない。この違いは、成功の存在と、不成功の網羅的な確認を分けるために必要である。

## 観測と介入をそろえる

`rwx` は、`rww` に現在の観測割当てを加える。観測が介入前の方程式を満たし、要因が真で、割当てに対応する状況が現在の状況と一致することを検査する。その同じ現在状況でも `xg` を要求する。

介入後に都合のよい解があるだけでは、現実に障壁があるとは扱わない。観測の要因が偽、別の結果を観測している、または観測が元の方程式に反する場合は `rwx` が成立しない。列外の因果変数を観測だけで真にすることも、既存の変数範囲規約に反する。

## 同じ自由条件と活動を保つ

[本文草案](../examples/v016/kant-assessed-barriers.noema)では、因果モデルの変数を「自由」と名付けるだけで済ませず、両介入の全解を前段の許可条件へ照合する。

`iadaligned` は、要因の真偽が実際の `iaccivilgain` と一致することを確認する。さらに `iadmatch` が、同じ人・市民的活動の範囲で、各解の許可集合を現在の比較制度と照合する。要因が真なら高い側と、偽なら低い側と、両方向の包含が成立しなければならない。単に「高い側ではない」という別の制度を、低い側の代わりには使えない。

`iadbarrier` は、前段と同じ本人・精神的活動の目標・方法・評価範囲を `rwx` へ渡す。`iadboundaries` は、指定した非空の対象が全て前段の人・活動の範囲に入り、各対象でこの障壁条件が成立することを要求する。全ての精神的活動が不可能だとは述べない。一つの選択された対象だけが失敗すれば、全対象への条件は成立しない。

`iadcontrast` は、前段の見かけの優位とこの障壁を同じ基準視点で合わせる。親の全宣言と先行20文を保ち、最後の候補解釈の帰属を更新した。引用の帰属時には、その内容を実行評価しない。`doch` の期待に反する働きや論証上の強調を、この連言だけで説明し終えたとはしない。

## 検査と限界

58テストが通過した。二値の機会変数について全16方程式を独立した固定点列挙と比較し、解なし、複数解、両側で失敗する場合を検査した。見かけの利益・条件を外した側の成功・観測された要因を八組合せで変えた。別制度の流用、対象・目標の取り違え、空範囲、評価不足、未知の入力も区別した。

本文側の検査は、既存の明示的な短絡評価とメモ化を使う。保存したNoemaの量化は変更せず、有限の個体・状況と二変数モデルで実際の `rv`、`rw`、`ru`、`xd`、`xg` を評価する。全域の数学的証明や、現実の制度の検証とは分ける。

既定の計算枠300万段階では、キャッシュなしの全質問評価が上限に達した。この再現性検査だけ上限を2,000万段階と明示して実行し、キャッシュありと結果が一致した。上限による拒否を無効化したり、記述の内容を別の判定器で代用したりはしていない。最初の実行で通過した57件と、計算枠を指定し直して通過した1件を合わせた検査結果である。

三文書の長形式・短縮形式・固有文字の往復、CLI解析、抽出文書のSVGのXML検査が通過した。字形の目視検査は行っていない。
