# 集団による制約と状態保持

第四段落第三文の、公衆が後見人を未成熟の下に留める部分へ向けて、集団の行為・離脱への制約・期間内の状態保持・実際の因果的寄与を接続した。未成熟が続いただけの場合や、制約が不成功だった場合とは区別する。第三文全体の照応・条件・比喩・著者への帰属はまだ未完である。

[原文](https://korpora.org/Kant/aa08/036.html)と原刊483–484頁を照合した。第三文は、公衆への先行する作用、後の逆向きの強制、一部の後見人による扇動、偏見の害と生み手側への反作用を含む。このうち今回扱うのは、強制によって同じ人をその状態に留める関係である。先頭二文の確認済み382非空白文字は保持する。

`r2ml` は、一つの集団の非空の参加者群が同じ行為へ参加し、その行為が生起して、集団の共同的な働きに帰属することを要求する。参加者全員はその集団の人でなければならないが、全構成員が参加する必要はない。集団の構成員の私的な行為を自動的に集団全体の行為とみなさないため、共同作用への帰属 `h223o` を別に要求する。

`r2mm` はその同じ行為が、同じ本人による指定状態からの離脱へ圧力をかけることを `h223n` で要求する。物理的阻止や拒否への不利益の威嚇などを含み、理由を示すだけの説得や、無関係な活動の制約とは分ける。この基本関係だけで成功を認定しない。

保持内容 `r2mk` は、順序付き履歴の始点から終点まで、両端を含む全時点で同じ状態が成立することを述べる。状態の新たな取得や、途中の喪失後の再取得で代用しない。評価時点より未来の終点、同じ始終点、循環した順序は拒否する。履歴の完全性と期間の妥当性は解釈で固定する。

同じ行為の先行する生起 `r2mj` と保持内容を閉じた記述にし、既存 `rqqu` に渡す。この定義は要因・結果の真理に加えて `hzie` の実際の因果的寄与を要求する。要因は始点での行為の生起なので、後の評価時点で行為が再び起きる必要はない。結果は瞬間的な状態ではなく、同じ人の同じ期間全体の保持である。

| 対照 | この強制・保持の構成 |
| --- | --- |
| 同じ集団の行為が離脱を制約し、同じ人の状態保持に寄与する | 成立 |
| 状態は続くが制約や寄与がない | 不成立 |
| 制約はあるが状態が途中で失われる | 不成立 |
| 集団の一部が共同的な働きを担い、他の構成員は不参加 | 成立し得る |
| 別の集団の人、別の行為、別の対象への制約を混ぜる | 不成立 |
| 同じ状態に戻ったが期間の途中で離脱している | 不成立 |

原文用の `r2mn` は状態を既存の知的未成熟 `bf` に固定する。公衆・行為・後見人・履歴・時点の引数は残っており、任意の検査値を原文の事例として確定したわけではない。次は、誰が誰を先に頚木の下へ置いたか、その同じ公衆が誰に働き返すか、一部の後見人の扇動がどこにかかるかを結ぶ。頚木の指示、際立て、偏見の植え付け・害・報復の提示も残る。

検査は六条件の64組合せ、参加者・対象・因果・時系列・途中の喪失の対照、未知入力の拒否、内容を実行しない引用、既存判断の保存と記法往復を扱う。一般ライブラリはカントや未成熟の語彙を含まず、別の状態についても同じ構成を使える。有限対照例の成功を、第三文全体の意味確認や現実の強制機構の証明とはしない。
