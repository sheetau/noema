# 個体・状況の領域を固定しない一階論理の検査

[first_order_proofs.py](../noema/first_order_proofs.py)は、Noemaの定義を展開した後の一階論理の断言をZ3で検査する。個体と状況の領域は、それぞれ空でない任意の集合として扱い、有限個の例で代用しない。状況を個体型へ読み替えず、独立した型として保持する。真偽の領域は二つの真理値である。

対応するのは、個体・状況・真偽の引数と結果を持つ基本関係・関数、同一性、論理結合子、それらの型への量化である。関数を引数に取る定義やラムダ式も、一階の式へ展開できる場合には使える。基本関数は未解釈の全域関数とする。状況の時間順序や到達可能性を自動的に仮定することはない。

数、実数の下側切断、命題内容、引用された記述、列、関数への量化、関数同士の同一性は扱わない。これらを別の個体型へ読み替えて検証することもない。問いや指示を断言として証明することは拒否する。

断言の否定が充足不能なら `valid`、反例モデルが存在すれば `invalid`、時間制限などで決着しなければ `unknown` を返す。`unknown` は成功にも反例にも数えない。一般の量化を含む論理は常に決着するとは限らないため、時間制限と定義展開の予算を明示する。

```python
from noema.grammar import parse
from noema.first_order_proofs import verify

result = verify(parse("n:s[f x a[e[v x][v x]]]."))
assert result[0]["status"] == "valid"
```

補助項の一般用文書から、許容状態と定義による拡張に必要な四定義だけを取り出し、全域関数のグラフが許容状態を保存し、追加値を一意に定めることを検査した。これは実際のNoemaの定義を展開した検査である。実数ベクトルの演算の閉性や、物理的な量の意味まで、この一階論理の結果で証明したことにはしない。

実行には既存の `proof` オプション依存関係が必要である。通常の構文解析・字形表示にZ3は必要ない。

[使用の評価基準](use-standards-v1.md)では、個体・状況をともに任意の領域として、適合・違反・未確認・衝突に関する5つの一般的性質を検査した。また、未確認から違反を導くなどの3つの推論に反例を得た。これは定義の論理的性質であり、現実の評価基準の正当性や証拠の信頼性を証明したものではない。
