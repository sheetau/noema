# 電気的作用と電流応答のモデル内対照

導入u0003の「電流を生じさせる」へ向け、電気的作用と電流の併存を、作用を変えた場合の応答の違いから区別する。カント側で使った有限変数の介入ライブラリの六定義を、記号名だけ替えて再利用した。新しい原始関係は加えない。

eib6は、同じ構造方程式で要因を真・偽に固定し、両側に解が存在することと、全解で結果がそれぞれ真・偽になることを要求する。eib7は、両介入の全解で変数と指定した実内容の成立を照合し、観測割当てが非介入方程式にも従うことを要求する。要因と結果が元から同時に真であるだけのモデルは通らない。

eicaは、同じ物体内の同じ担体への電気的作用と、物体の全断面電流履歴を結ぶ。既存eibsの電荷・場・力の記録に、出来事への担体の関与sb、単位付き物質領域eiro、同じ時刻と断面の適用範囲を接続する。eicbはこの電気的力が非零であること、eiccは同じ断面の電流の絶対値が指定閾値を超えることを表す。非零の合力や物体の並進では代用しない。

eicdは各モデル解をこれらの記録へ結ぶ。物体・担体・系・単位・区間・全断面範囲・断面・向き・比較時刻・閾値を固定し、電荷や力の記録、場、文脈、電流履歴の関数族を同じ割当てで選ぶ。観測された作用ありの側だけを検査して、作用なしの側の欠損を隠すことはできない。

この対照は一般の因果寄与より強い。別原因で既に電流が流れている場合、確率的な応答、冗長な原因、遅れのある応答を尽くさない。また、方程式が介入後にも同じ機構を表すことはモデルの仮定であり、真偽表を当てはめたという事実からは導けない。物体全体の作用を一つの担体・出来事だけで代表できることも自動認定しない。原文の電流生成や導体という語を、この強い対照と無条件に同義にしない。

導体の読解では、物体内部を移動できる電荷と電気的作用による応答を区別して接続する必要がある。参照した[OpenStaxの金属伝導モデル](https://openstax.org/books/university-physics-volume-2/pages/9-2-model-of-conduction-in-metals)は、自由電荷の運動と電場に伴う平均的な流れを区別している（2026-10-23確認）。この説明を原文へ電子種・散乱機構・特定の数値定数として追加したわけではない。

検査は二変数の結果方程式16通りを独立に列挙し、無解、複数解、作用に依存しない応答を区別する。物理記録は既存eibsとsbを実行し、全電流履歴eibfを明示した境界として検査する。統合検査ではeicaを境界とし、作用なしの解でだけ各記録を変えて、同じ解から値を選ぶ接続を確認する。実数全区間の電流履歴を有限の介入変数と混同しない。

許容試行eirk・物理的可能性zrdpossible、材料と背景の保持、作用範囲、応答時間、導体の分類基準は適用判断として残る。物理法則の実証は翻訳の完成条件ではないが、仮定したモデルの適用範囲を省くこともできない。今回の構成は原文207主張と著者表示判断を保持する補助定義であり、意味確認済み単位を増やさない。
