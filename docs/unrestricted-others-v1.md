# 職務義務による制約と、他の対象者全員への許可

カントu0015の「jeder andere, der durch keine Amtspflicht eingeschränkt ist」について、職務義務が対象活動を制約しない条件と、該当する他の人々への許可を分けて記述した。十二の合成定義を追加し、新しい原始記号や著者主張は加えていない。

## 両立と無制約の違い

比較する活動内容と候補状況を固定する。職務上の各要求には、出所・職務・活動・閉じた実行記述・肯否の極性を持たせ、基準文脈の要求を比較候補へ適用する。

| 定義 | 条件 |
| --- | --- |
| rpl | 一覧の各項目が指定した職務の役割範囲に属し、同じ本人への実際の要求に一致する。 |
| rpm | rplを満たし、同じ比較候補で一覧の全要求の内容が各極性に一致する。 |
| rpn | 対象活動が成立し、全要求とも両立する比較候補が一つ以上ある。 |
| rpo / hzgz | 対象活動が成立する比較候補が一つ以上あり、その全てで全要求と両立する。hzgzは要求を既存h7aへ結ぶ。 |

一つの候補で発言と義務が両立しても、他の発言候補が義務に反するなら、義務は候補を一部排除している。rpnの両立可能性とrpoの排除の不在を区別する。どちらも比較範囲を明示した条件であり、全可能状況の能力や因果的な無妨害を認定するものではない。

義務が存在しても、全ての対象活動候補で満たせることがある。逆に、発言の候補そのものがない場合は、制約がないと確認できたことにはしない。rpn・rpoはこの場合に偽となるが、そこから制約が実在すると結論する規則は設けない。

## 一覧の空と、全義務の不存在

空の一覧についてrplとrpmは成立し得る。しかし、一覧が空でも、一覧に載っていない職務義務があるかもしれない。

rppは、指定職務の役割範囲について、同じ本人・基準文脈への全出所・全活動・全実行記述・両極性の要求が一覧に含まれることを量化する。rplとrppをともに満たせば、一覧とその職務範囲の要求が一致する。rpq / hzg2は、この網羅性とrpoの候補排除の不在を結ぶ。

職務以外の立場への要求は、職務義務に混ぜない。職務の役割範囲はofficerolesで明示する。指定範囲が本人の実際の全職務を尽くすことや、役割の制度上の成立は別途確認が必要である。職務上の制約がなくても、別の規範による禁止がある可能性は残る。

rppは型に合う全実行記述へ量化する。有限解釈器はその全域を列挙せず拒否する。検査では二つの記述へ量化範囲を限定した別の検証用文書を作り、一覧にない出所・職務・活動・記述・極性の要求を取りこぼさないことを確認した。この限定検査を、保存した全域の定義の証明とは扱わない。引用した条件を保持するだけなら、全域を評価する必要はない。

## 「他の人々全員」の許可

rpr / hzg3は、指定人口から既出の対象群を除いた人々について、該当活動と無制約条件を満たす全ての本人・活動の組に許可があるという内容を作る。「他の人」を話者本人以外という条件には置き換えない。

hzg3の許可は同じ権限側・本人・公的役割・活動・閉じた実行記述・基準文脈へ固定し、積極的許可と反対要求の不在を確認する。一人への許可や別の活動への許可では代用できない。rps / hzg4では、該当する本人・活動の組の存在も要求する。これは空の対象範囲でも成立する普遍条件と区別した、追加の強い読みである。

職務義務との両立だけで許可が生じるとは定義しない。前版の[公的な提示](public-divergent-judgments-v1.md)から作った同じ実行記述を、無制約条件の活動内容と、対象者全員への許可で共有する接続を検査した。全活動候補での履行が揃わない本人・活動の組は対象から外れ、許可が欠ける場合には普遍的な許可内容が成立しない。

## 残る意味

「noch mehr」の「なおさら」は、許可の真偽に数値的な大小を付ける表現ではない。前節の許可と制約の減少を根拠とする推論、強調の度合い、著者がその根拠を採用していることは、今回の普遍的な許可内容とは別に接続する必要がある。

聖職者・学者・職務・公衆の基礎的な説明、人口と職務範囲の網羅性、君主への照応、複数の判断と洞察、一般化した文の著者への帰属と全文の意味確認は未完である。今回の原文対応は52文字の部分注記であり、文や段落が完成したことを示さない。
