# 後見役の比較に使う期待の尺度

カントの `sogar unter den eingesetzten Vormündern` には、著者が提示する期待の尺度で、任用された後見役の中に該当者がいることを相対的に見込みにくいものとする読みを採用する。比較するのは、自由の条件と将来の範囲をそろえた内容である。同じ母集団の後見役と、その外側を比較し、数値確率や実際に驚いたという心理的事実は加えない。

IDSの文法資料は、焦点粒子が比較の尺度を伴うことと、`sogar` が話者・聞き手の期待に照らした位置を示す用例を説明している。これを今回の読解の根拠の一つとする。[IDS grammis「Fokuspartikel」](https://grammis.ids-mannheim.de/systematische-grammatik/408)

ただし、予想しにくさだけで英語 `even` の全用法を説明できるわけではない。Greenbergの論文要旨も比較的な起こりにくさの必要性・十分性に対する問題を述べている。本実装は全用法の規則や、ドイツ語への一律な転用を主張しない。[Greenberg 2016](https://semprag.org/index.php/sp/article/view/sp.9.2)

採用した読みと参照資料のハッシュは[読解記録](../data/expected-focus-reading-v1.json)に残す。原刊照合は既存の483頁の記録を引き継ぐ。著者の内心を復元したとする読解ではなく、本文で提示される期待を記述するための選択である。

## 比較の構成

新しい基本関係 `hzpt` は、同じ視点・同じ文脈で、第一の内容が第二の内容と少なくとも同程度に見込まれることを表す。比較対象は閉じた内容記述であり、その内容を実行しない。どの期待比較が成立するかは解釈の入力であり、内容の真理から自動計算するものではない。

| 構成 | 役割 |
| --- | --- |
| `rqtq` | 比較範囲での反射性・推移性を確認する。全ての二項が比較可能であることは要求しない |
| `rqtr` | 逆方向が成立し、順方向が成立しない場合だけ、第一を厳密に見込まれにくいものとする |
| `rqts` | 同じ弱い比較の整合性と、焦点が各候補より見込まれにくいことを背景に置く |
| `rqtt` | 同じ人物・時点について焦点の述語を否定した、閉じた比較候補を構成する |
| `hzpu` | `hzpt` を厳密な比較へ接続する |
| `hzpv` | 共通の枠へ焦点とその補集合を渡し、焦点の内容と比較背景を組にする |
| `hzpw` | 視点を著者 `wa`、比較文脈を当該箇所の `hzp3` に固定する |

両方向が成立する同順位、両方向の不成立が確認された比較不能、入力自体が未知である場合を区別する。未知は偽で埋めない。焦点の主張を否定しても比較背景を維持し、比較側にも現実の該当者がいるとは要求しない。

既存の `rqtp` により、焦点と比較側には同じ自由の条件・候補範囲・基準点・存在する伝播経路を使う。`hzhb` で構成した任用された後見役の述語と、その補集合を接続した。原文の唯一の読みだと証明したわけではなく、この作用範囲と比較対象を採用することを明示した。

## 検証と残る範囲

三つの内容上の全512関係を検査し、集合の合成による独立した判定と一致する29の前順序を受理する。期待の向き・主張の真偽の八組合せ、比較の自己整合性、視点・文脈の取り違え、補集合の人物と時点、未知入力を検査する。具体的な後見役の比較は、世界の基本関係を全て未知にした通常評価で確認する。束縛変数の名前だけが違う場合は同じ述語として比較し、関係記号の違いは保持する。

```powershell
python -X utf8 -m scripts.compose_expected_focus
python -X utf8 -m pytest tests/test_expected_focus.py -q
python -X utf8 -m scripts.check_expected_focus --verify-only
```

原文への部分対応に加えるのは `sogar` の五文字だけである。尺度・視点・比較対象は具体化したが、原文に適した全解釈値を満たす内容の著者帰属と、段落全体の意味確認は残る。背景の評価は無制限の伝播経路を含む主張全体の成立証明ではなく、新しい本文主張や意味確認済み単位は加算しない。
