# 同じ目標の最初の達成者

カントu0015の「最初に」に対し、同じ履歴・比較対象者・受益対象・目標記述の中で達成時点を比較する構造を追加した。最初の達成者と、唯一の最初の達成者を分ける。前段の応答適合には、この達成経験の記述を根拠として渡せる。

| 定義 | 内容 |
| --- | --- |
| `rob` | 指定した行為が基準時までに同じ目標を達成し、比較範囲内にそれより早い達成がない |
| `roc` | `rob`に加え、同時点の達成者も本人だけである |
| `rod` | 基準時までに`rob`を満たす行為と時点を持つ人物の内容関数 |
| `roe` | 基準時までに`roc`を満たす行為と時点を持つ人物の内容関数 |
| `rof` | 同じ行為が対象を目標不成立から成立へ移し、生起・本人の関与・同じ目標への結果生成がある |
| `rog` | 同じ履歴・順序・目標記述に固定した`rof`の達成関係 |
| `hzgd`・`hzge` | 変化・対象・生起・関与・結果生成を既存`ag`・`la`・`dg`・`df`・`g3`へ接続する |

二人が同時に達成した場合、両方が`rob`に当たり、どちらも`roc`には当たらない。同じ本人に複数の達成行為があっても、唯一の人物であるという条件は失われない。他者の後の達成は先行者の経験を消さず、本人にとって初めての成功でも、他者が先に同じ目標を達成していれば最初の達成者にはならない。

比較では、既存`ta`の非空の厳密な全順序を要求する。循環や比較不能な時点を勝手に並べ替えず、基準時より後の出来事を完了済みの経験にしない。候補時点までの比較対象者について、該当達成の評価範囲がそろっていることも要求する。評価漏れや未知の先行事例を不達成へ補わない。この条件は宣言された範囲の検査であり、現実の全人類・全歴史を調べた証明ではない。

達成の成立には、既存`th`の目標不成立から成立への変化を使う。その同じ行為について、受益対象・生起・行為者・同じ目標記述への結果生成を結ぶ。目標が後で真になったというだけでは達成した行為を認定しない。行為者と受益対象は別に保持し、同じ行為に複数人が関与することや、他の原因・援助があることを排除しない。結果生成の関係そのものの因果的な正当性は、既存の意味規約と接続例の前提である。

原文への接続例では、指定した集団の人々・主題・活動に対して、同じ規範源が実行と不実行を許す政策を目標にする。現行の自由政策が成立するだけでは足りず、対象集団についてその政策条件が不成立から成立へ変わり、その同じ変化行為への関与と結果生成が必要になる。これは政府側からの自由への部分候補であり、人類の未成熟からの解放や一人一人の自立を、この政策条件だけで説明したとはしない。

最初の達成者の内容は、前段`ro6`へ同じ対象者の根拠として渡す。時間的に先行しただけで称賛に値すると結論せず、応答の記述と非空の評価基準を引き続き要求する。既知の目標記述を達成関係へ、既知の達成者記述を応答評価へ静的に特殊化し、脱引用を一箇所ずつ解消した。達成者の内容を引用するだけなら、履歴・規範・因果関係を実行評価しない。

[一般文書](../examples/v014/first-achievers.noema)は2,456文字、[原文付き草案](../examples/v014/kant-first-achievers.noema)は195,804文字、[抽出文書](../examples/v014/first-achievers-core.noema)は4,421文字である。八定義を追加し、原始記号と著者主張は増やしていない。親の宣言と15件の著者主張を保持した。[意味規約](../data/kant-first-achievers-basis-v1.json)と[検査記録](../reports/first-achievers-v1.json)を保存する。

二人・三時点の達成の64通りを、時点の表から独立に求めた最早時点と比較した。原文付き文書と抽出文書では十七条件ずつを検査した。追加16テストは、同時達成、後発者、空の履歴上の実績、評価不足、比較範囲の変更、未来の達成、未知の先行事例、順序の不整合、因果関係と対象の不一致、既に真の目標、別の目標記述、応答適合、引用、同じ行為への複数人の関与、原文範囲を対象とする。三文書のCLI解析、正規形と固有文字v2の往復、SVGのXML検査も通過した。SVGの目視確認は含めない。

原文範囲は「最初に」にかかる短い部分だけを追加し、人類・未成熟・少なくとも政府側という限定・解放の全内容は対応済みには数えない。比較範囲の現実的な網羅性、功績の帰属、感謝・世界・後世、原文との意味一致も未完である。
