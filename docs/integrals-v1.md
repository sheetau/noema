# タグ付き分割と積分

[積分の定義群](../examples/v014/integrals.noema)は、有限列・関数・実数の下側切断を組み合わせ、分割の取り方や代表点によらない和の極限を表す。既存の極限の文書へ16定義を追加し、4基本記号・54定義となった。新しい文法や字形、論文専用の基本記号は追加していない。

## 分割をNoemaで構成する

一つのタグ付き区間は、左端・右端・代表点の三値を持つ。今回は関数型のレコードを使い、構造上の欄番号0・1・2をそれぞれの値に対応させる。その他の入力での関数値も存在するが、この表現の意味には用いない。欄番号は区間の構造を指定するためのもので、名詞の意味を番号へ置き換える辞書ではない。

有理数のレコードはmgで作れる。mgは三値a・b・tから、0・1・2で正確にその値を返す多項式の関数を構成する。近似ではなく、三つの欄の実装である。入力iに対する係数は、それぞれ`(i−1)(i−2)/2`、`−i(i−2)`、`i(i−1)/2`となる。実数のレコードniは、この有理数係数を実切断へ埋め込んで同じ構成を行う。

例えば、次の式は左端0・右端3・代表点2のレコードを作る。

```text
k mg[n p a b n p d b n p c b]
```

区間列はそのレコードの有限列である。[実行可能なNoema例](../examples/v014/tagged-sums.noema)は、0→3→10の分割をmgから構成し、進み率4/5の和が8になることを記述する。区間の情報を外部の基本記号へ預けず、Noemaの式で直接構成している。必要な外部解釈は従来の有理数算術4記号だけである。

## 有限和と積分の区別

| 有理数領域 | 実数の切断領域 | 内容 |
| --- | --- | --- |
| ma | na | 正の幅を持ち、代表点が両端を含む区間内にある |
| mb | nb | 指定した下端から上端へ接続する、非空の分割 |
| mc | nc | すべての区間幅が正のδより厳密に小さい |
| md | nd | 各区間幅と代表点での関数値の積を加算する |
| me | ne | 正方向の積分関係 |
| mf | nf | 同じ両端での0と、逆向きの符号反転を含む積分関係 |
| mg | ni | 三値からレコードを作る |

mb・nbでは、区間の終点と次の始点を共有し、最初と最後の端点も固定する。正の幅を要求するため、隙間・重複・逆順や同一区間の重複を有効な分割と扱わない。mc・ncだけなら空列で成立する場合があるが、積分ではmb・nbも要求する。空列を細かい分割の代わりにはしない。

md・ndは有限和の構成式である。代表点を変えると一般に値が変わる。積分関係me・neは、以下の条件を別に要求する。

```text
すべての ε > 0 について、δ > 0 が存在し、
  最大の区間幅がδより小さい有効な分割が存在し、
  その条件を満たすすべての分割・代表点について、
  |有限和 − 積分値| < ε。
```

一つの好都合な分割だけを選んだり、分割を選んでからεを緩めたりはしない。実際に該当する分割が存在する条件も明記し、該当例が空だから成立するという扱いを避けた。

実数版では、端点・代表点・精度・細かさ・積分値が有効な実切断であることを条件にする。被積分関数も区間内で有効な実切断を返す必要がある。向き付きのnfでもこの条件を保持し、両端が同じ場合はその点での関数値の妥当性を要求する。

## 曲線上の時計への条件付き接続

ngは、正の長さの実時間区間で連続かつ正で1以下の進み率r(t)を受け取り、その積分を経過、区間時間との差を遅れとする。nhはさらに三座標の連続閉曲線と速度成分を受け取り、各成分が対応する座標の相対的な微分であることを要求する。

nhでは、正の光速度Vに対して、各時刻で次の関係を課す。

```text
vₓ² + vᵧ² + v𝓏² < V²
V² r² = V² − (vₓ² + vᵧ² + v𝓏²)
```

正の進み率はngから引き継ぐ。ng・nhはこうした理想的な曲線上の時計の法則を**採用した場合の条件**であり、加速の物理的な法則を有限区間の検査から導いたものではない。nhは各時刻の微分と進み率の連続性を要求するため、角を持つ折れ線や、さらに一般の可積分な速度までは含めない。実際の時計・出来事・基準系・単位との観測接続も、以前の有限経路の草案とはまだ統合していない。

## 検査した範囲

94の具体例で、分割の接続、代表点、細かさの厳密な境界、有限和を検査した。分割数1・2・3・4・8・12について、左端・中点・右端を代表点にした定数関数、恒等関数、`2x+3`の和を独立した分数の式と比較した。恒等関数の区間[0,1]では、左端の和は`1/2−1/(2n)`、右端は`1/2+1/(2n)`、中点は1/2となる。

さらに、[11のNoema主張](../examples/v014/integral-scalar-claims.noema)を有理数の多項式として検証した。レコードの三欄が正しいこと、定数と線形関数の区間値が接続時に加算できること、恒等関数の一区間の誤差を細かさと幅の積で抑えられること、誤差上限の加算、向きの反転と零区間を含む。Noema自身で構成した有限和の文書も5主張を検査した。

これらは具体的な有限列の検査とスカラー式の証明であり、任意の全分割についての積分定理の機械的証明ではない。有限解釈器は、全分割への量化も、積分での全有理精度への量化も、有限標本へ置き換えず拒否する。実切断全域の積分法則の機械的証明も未完である。[検査記録](../reports/integrals-v1.json)にこの範囲を記した。
