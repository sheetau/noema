# 枝の内側で同じ文法を読む

`kant-public-fragment-13-nested-branches` は、主列と横枝の両方に同じ分岐規則を適用する。前の版では横枝を一本の前置式の列に平坦化していたが、この版では横枝の内部にも引数の枝を置ける。

## 再帰的な読取

各分岐で、接続をたどって最初に到達する主円のx座標を比べる。右側をその経路の続き、左側を引数の枝とし、枝の内部にも同じ読取を適用する。同じx座標の入口、最初の主円に到達する前の再分岐、一つの核から二つ以上の横枝が出る配置は拒否する。二円組を一つの核にする規則と文頭の決め方は変えない。

構文読取器は、図形から回収した全ての枝を対象に、前置式をちょうど一式ずつ読む。枝に入るたびに位置と語境界を保存し、読み終わったら元の経路へ戻る。型から決まる引数位置、元の引数順、引用での束縛環境のリセット、外側の束縛変数への参照を引き継ぐ。枝が足りない式を隣の経路から補ったり、余った式を読み捨てたりはしない。

`and_shared` も枝の内部で読める。共有する対象は従来どおり終端の語または許容された変数参照に限る。一般の部分式を複製する機能は追加しない。

## 描画と配置不能時の扱い

主列・枝・枝の内側を同じ配置処理へ渡す。分岐では枝の最初の円を先に置き、その右に元の経路の続きを置く。先読みでは、枝の入口をまだ待っている親側の経路も対象に含める。次の円を置くときは、親側の続きに使える接続口も残す。

全ての候補が使えない場合は、内側の枝を一つ主列へ戻して組み直す。除外する構文上の位置を記録し、同じ枝を繰り返し試さない。共有頭自体はこの除外対象にせず、共有引数の短縮を保持する。内側の枝を除いた後も配置できない場合には、従来の平坦な枝の配置を試す。いずれも構文と語義を変える操作ではなく、実図形の復号一致を別に確認する。

読取失敗や未知の字形を理由に配置を差し替えて合格にする処理は設けない。偏心内包の禁止、三段の基準、中心線・入射角・線の曲げと間隔の制約は維持する。

## 確認範囲

独立した例では、引数順の交換、枝の主列・横枝からの外側参照、枝内での束縛、引用、共有引数、四段の枝を実SVGから確認する。深い入れ子には「二つの引数のうち第一引数を返す」という共通の定義を繰り返し使用する。この定義は検査用辞書に明示し、新しい意味primitiveや作品の文ごとの定義は追加しない。

検査は `scripts/check_kant_nested_branches.py` で行い、前段の保存40SVGと変更後の40SVGを確認する。枝数と深さは、生成器の診断情報ではなく図形から回収した接続構造で数える。既存の意味判断は、構文の一致と語義・参照先の不変を確認して引き継ぐ。

配置器が全ての部分式を希望どおりの深さで描けることは保証していない。主列へ戻した位置と従来配置への移行を報告する。複数の横枝、未対応の式構成、文書宣言・辞書・行頁の復元、未使用の許容形への意味対応は残る。長線、中央段への集中、文頭の反復も外観として引き続き点検し、利用者の確認前に固定しない。
