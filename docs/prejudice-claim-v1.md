# 偏見の反作用の範囲と理由節への帰属

第三文後半の反作用を、固定された全関連事例と各事例の全対象者へ結んだ。`zuletzt` の終わりの読みと `denen selbst` の本人への取り立ても接続し、理由節の関係内容を著者へ帰属する。`so/weil` の論述上の接続と植え付け・報復の描写は残る。

## 成功から選ばない全範囲

事例範囲 `h225b` と各事例の対象者列 `h225c` は、反作用の結果を調べる前に文脈から固定する。どちらも非空を要求し、対象者は重複のない人々である。一つの事例や一人の対象者について関係が失敗すれば、全体の内容は成立しない。

後半の一般的な述定を、この文脈で関連する全事例について読む。成功した例だけを取り出す読みにはしない。一方、時代や社会を問わない全人類の全履歴へ量化範囲を広げることもない。固定範囲が原文に対して十分かどうかは、型検査や有限解釈だけでは決まらない。

`r2oi` は、同じ事例の生み手・行為・受け手・意見・植え付けの点を既存 `r2og` へ供給する。役割・経過・帰結点は対象者ごとに結び、全被害者に同時刻の害を要求しない。意見名と先行点名は閉じた記述と元の参照の一致を内部で検査する。異なる事例の行為や別の被害者の役割を混ぜない。

## 経過の終わりと本人の取り立て

`zuletzt` は、述べている因果的な展開の終わりにという読みを採る。[原文](https://korpora.org/Kant/aa08/036.html)と、終わりの用法を挙げる[辞書](https://www.duden.de/rechtschreibung/zuletzt)を参照した。直近の一回という読みではない。

同じ対象者に関係する全経過の範囲と順序を、反作用の成否から切り詰めずに固定する。`r2oh` は、その経過が厳密な線形順序を持ち、指定点が範囲に属する最大点であることを検査する。単なる任意の後続点では足りない。文脈上の経過の終わりであり、その後の世界で何も起きないことや、同じ害がそれ以前にはなかったことは要求しない。

`denen selbst` の焦点族は `[事例,意見,本人]` の三位置と参照文脈を共有する。範囲 `r2om` は全対象者列から本人を取り、焦点 `r2on` は同じ本人の反作用 `r2oi` を取る。害が生じた人だけへ範囲を縮めない。生み手本人の枝だけでなく、生み手を先任者に持つ本人の枝も取り立ての対象に含める。

## 帰属と検査

`r2ok` は非空の全事例について、非空の全対象者に関係が成立する内容である。`r2ol` は閉じた段階3の記述として、理由節 `[746,845)` の同じ箇所・著者・段落文脈へ帰属する。`r2oo` は同じ主張の中での本人への取り立てを帰属する。帰属時に世界の植え付けや害を実行評価しない。

文番号59は、前半の既存統合 `r2ny` と今回の理由節の関係内容・取り立てを合わせた `r2op` へ置き換えた。先頭59文と旧定義の意味は保持している。後半の一般化から、前半の扇動条件の現実の成立や無条件の強制を導かない。

個別の事例では既存の偏見・植え付け・因果・役割継承・時間の定義まで実行する。全事例・全対象者の量化と焦点族の検査では、その個別関係を明示した境界とし、量化する引数の接続を別に構文木で照合する。未知の事例、失敗する第二事例・第二対象者、重複・非人間・空の対象列、別の意見名や先行点名、終点より後の関連局面を区別する。

既存13区間と先頭二文382非空白文字を保持する。次は `so schädlich` の程度と前半との関係、`weil` の理由づけ、植え付け・報復の描写を接続し、第三文全体を統合して通読する。今回も第三文の意味確認済み分量は増やさない。
