# 二つの述語で共有する対象を一度だけ描く

元kant-pageの生成器は、同じ対象に関する単項述語をまとめ、その対象を横枝に置いていた。しかし元の構文の位置を fused_paths に保存しており、付属情報なしに復元する規則がなかった。今回の規則は、二項の連言と二つの単項述語だけを一つの可逆な構成として扱う。

## 構成と展開

対象は and(P(a), Q(a)) の形である。P と Q は公開定義に従う individual から truth への単項述語で、a の構文は二か所で完全に同じでなければならない。意味が似ている、同一かもしれない、同じ型であるといった理由では融合しない。

共有頭は、小円の中心を中円の左円周上に置いた二円と、中円中心から右への線で表す。中心間距離は中円半径とする。以前の小円半径だけ偏らせる形は、利用者の指摘を受けて違反として撤回した。[円配置の訂正](kant-circle-pair-rule.md)を参照。a をその頭から出る横枝に置き、主な連なりには P と Q の公開された名前を順に置く。小円中心へ線を通さず、入口と出口も区別する。根語の方向は保存し、複合語の境界には既存の最長一致規則を使う。

読取器は、この共有頭と一つの終端横枝を見たら、続く二語を単項述語名として読み、両方へ同じaを戻して二項のandを構成する。隠れた元構文、繰り返し回数、構文位置の配列を参照しない。一核に限っていた対象は、[中小円だけからなる終端複合語](kant-terminal-words.md)まで拡張した。大円を含む対象は通常の適用として省略せず描く。

この局所規則は、左結合と右結合の連言を平坦化しない。三つ以上の述語では、条件に当てはまる二つの部分式だけが融合し、残る連言構造はそのまま描かれる。引用内で用いても、展開後は引用された元の構文に完全一致する。引用の束縛環境を外部から引き継ぐことはない。

## 外観と確認範囲

元の生成器と同様、対象を実際の横枝として配置する。共有対象が上下に置ける場合は、累積した円の面積重心に従って配置する。大きな文頭記号を追加する方法ではなく、既存の連言頭の形と接続を変更して、対象の重複を一つ減らす。

十二の対照例を、共有ありと省略なしの両方で実SVGへ描き、同じnative構文へ戻す。異なる対象、二引数の述語、大円の外側参照を誤って融合しないことも確認する。元の構文の順序・結合・参照先が一致する検査であり、語義モデルの再実行ではない。

省略しない対照形を組み立てる際に、不可視の語境界の直後が大円だと、その前の円も中央段へ置く必要があることが分かった。必須の不可視接続が続く区間に大円が含まれれば、その区間全体を配置前に中央段へ制約する。配置済みの形が行き詰まってから全体をやり直す方法は採らない。

直前の公開語375語の全参照検査は、コミット7db25d10と reports/kant-public-words-v1.json に保存してある。今回は共有連言と語境界の段制約を変更し、字形表の非衝突、既存の文法対照、四つの代表的な公開語参照、六つの複合語適用・境界例を確認する。全375語を再検査したとは報告しない。共有例の初回報告v1を保持し、段制約の影響範囲と適用例の結果を含む reports/kant-shared-argument-v2.json を現行報告とする。

見本は output/kant-shared-argument/index.html。円配置の訂正を反映した現行報告は reports/kant-circle-pair-correction-v1.json とする。旧v1/v2は偏心配置を許容する根拠に使わない。全構文、任意型の束縛、接触適用、行・頁の復号、長文の外観評価はまだ残る。固定する前に、完全な候補を利用者へ提示する。
