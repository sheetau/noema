# 公的使用と私的使用の定義

第五段落[981,1293)の二文を、著者自身がこの論説で採る語の使い方の定義として構成した。公的使用は本人自身の理性を学識者として全読者世界へ向ける活動、私的使用は委ねられた市民的職務の立場での理性使用である。既存の分類に人である条件を明示し、同じ本人・活動・立場・基準を保持する。

二つの語の言及箇所を、それぞれ合成された閉じた分類記述へ結ぶ。語の綴りだけで意味を代用せず、著者が自ら「こう理解する」「こう呼ぶ」と提示することを表す。分類の引用は実際の使用例の存在を要求しない。原刊のGelehrterの強調は、同じ活動で学識者として振る舞う役割条件へ結ぶ。職業名だけで分類せず、全読者世界へ向けることを全員による実際の受領とも同一視しない。

私的使用の `darf` は、委任に伴って認められる職務上の使用範囲という規範的限定として読む。これは今回の明示した解釈であり、その時点で各行為に積極的な許可があるという別の読みとは区別する。禁止が加わるたびに禁止された活動が私的使用から消えることを避け、分類と個別指示への適合を分ける。職務外の行為への許可や無条件の発言の自由は補わない。

`aber` は、先行回答で使った語を区別して明確にする説明への転換と読む。前の回答全体と同じ著者・提示文脈へ接続するが、定義から前の規範主張の正しさが証明されたとはしない。`Posten, oder Amte` は市民的な地位・職務を指す言い換えを含む分類とし、両職の同時所有や排他的な二択にはしない。

原刊485頁と[AA8/37](https://korpora.org/Kant/aa08/037.html)を照合し、全語句・照応・定義の提示・規範的限定を通読した。明示した読みの下で二文268非空白文字を確認し、第五段落の文単位の確認は1,106文字となる。公的・私的使用が全活動を尽くす排他的分類であることや、一般的な役割概念の説明が全て完成したことは主張しない。
