# 引用の参照と能力評価の対象をそろえる

前段の発言能力の作例では、引用に埋め込む話者の参照が、能力を評価している本人を指すかどうかを入力側に任せていた。今回は、話者・聞き手・基準文脈の一致を明示的に検査し、参照の不整合を「発言できない」という結論へ流用しない六定義を追加した。

この一致は、今回の自己発話ひな形への接続条件である。他人の発言や別時点の内容を引用する一般の能力を禁止する規則ではない。別の人物を指す内容を、ある話者が発言すること自体は、整合条件を加える前の発言目標として記述できる。

## 指示先を確認する

`ruj` は、引用の話者記述を評価した結果が能力の評価対象者に一致し、引用の文脈記述が評価の基準文脈に一致することを要求する。引用の聞き手条件については、その基準文脈における範囲と、発言の受け手として指定した範囲の一致を要求する。聞き手の欠落と余分な聞き手の両方を区別する。

比較するのは記述の字面ではなく、同じ解釈内での指示先である。異なる閉じた記述が同じ人や文脈を指す場合は認める。ただし、引用内容の記述そのものを同義として自動で書き換えることはしない。

聞き手条件は基準文脈で比較する。別の状況で聞き手が変わる関数でも、基準文脈で一致すればこの条件は成立する。全状況にわたる関数の同一性を、参照の一致に余分に要求してはいない。

## 参照不整合と不可能を分ける

`ruk` は、同じ三つの参照記述を実際の本文ひな形 `hzsquotation` に渡して発話記述列を作り、それを評価対象者が指定した聞き手へ順序付きで提示する目標を構成する。`ruk` 単独では参照の整合性を要求しない。

`rul` は、参照が整合し、その目標を評価対象の全結果で達成する利用可能な方法があることを要求する。`rum` は、参照が整合し、全方法の評価範囲が整合したうえで達成方法がないことを要求する。

| 参照 | 方法・結果の評価 | `rul` | `rum` |
| --- | --- | --- | --- |
| 整合 | 達成方法を確認 | 真 | 偽 |
| 整合 | 達成方法がないと確認 | 偽 | 真 |
| 整合 | 評価範囲が未指定で、達成方法も未確認 | 偽 | 偽 |
| 不整合 | 達成方法の有無にかかわらず | 偽 | 偽 |

最後の二行は、参照整合性と評価範囲の条件を別に調べて区別できる。未知の参照は不整合と決め付けず、評価を拒否する。引用や条件式の記述を作る際には参照を評価しない。

## 限定条件を空虚に成立させない

参照不整合によって `rul` が偽になった場合、「発言できるなら条件を満たす」という含意だけなら成立してしまう。`run` は、指定した各対象者の参照整合性を別途要求したうえで、この必要条件を述べる。

`ruo` も全対象者の参照整合性を要求し、条件を満たさない対象者について `rum` による不可能の確認を求める。これにより、参照の不整合や未評価の方法を使って「条件を満たす者しか言えない」と確認したことにしない。条件を満たす人が必ず発言できるという逆向きの含意は加えない。

## 検証と限界

[定義文書](../examples/v016/anchored-ability.noema)は16宣言・本文0文、[作例](../examples/v016/anchored-ability-example.noema)は106宣言・8質問である。作例は前段の全宣言を保持している。

46テストが通過した。三種類の参照整合性、発言の実現、資格条件を変える32組合せに加え、同じ対象を指す別記述、基準文脈以外で異なる聞き手、余分な聞き手と欠落、空の聞き手範囲、未知の参照、方法がない場合、未評価の場合を検査した。参照が誤っていても発話列自体を実現できる例を含め、単なる発言の失敗だけで判別していない。

段階1の参照記述を評価するため、結果の引用には段階2を用いる。段階1の引用へその評価を隠すと拒否されることも確認した。長形式・短縮形式・固有文字の往復、文書と検査記録の再現、CLI解析、SVGのXML検査が通過した。SVGの目視検査は行っていない。

```powershell
python -X utf8 -m scripts.compose_anchored_ability
python -X utf8 -m pytest tests/test_anchored_ability.py -q
python -X utf8 -m scripts.check_anchored_ability --verify-only
```

[意味条件](../data/anchored-ability-basis-v1.json)と[検査記録](../reports/anchored-ability-v1.json)を保存した。方法・結果・評価基準の妥当性や、現実の指示の社会的な同定を完成させたものではない。原文の啓蒙・軍隊・平穏などの限定条件と、政治的な発言可能性、上位の著者主張への接続は残る。新たな原文対応範囲や意味確認済み区間数は追加していない。
