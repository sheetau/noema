# 同じ電子の力・ばね秤・質量規約

u0252第一文とu0254–u0258を一群として統合するため、力の物理的な帰属、ばね秤の測定可能性、力と加速度の単位・系の選択、二係数の候補を構成する。既存の423主張は保存し、この段階では全単位判断を増やさない。

必要な関係は、同じ電子と時点、共動するkの実電場、符号付き電荷、機械的な力の記録、ばねの復元応答、変位と校正目盛り、同じ力を対象とする可能な測定、Kの実加速度、整合単位、二つの係数を問う規則である。PAIR、new_values、ek63、eibs、zpc、eirl、eirm、zjg、x4、zrdpossible、ejwb、zraconvention、seph、sepi、sepfを再利用する。

elyは同じ新点の実電場三成分と電荷を、同じkの電気的な機械作用へ結ぶ。支持力を含めた合力をεE′と呼ばない。sourceの粒子はその瞬間にkへ静止するが、加速度は零とは限らない。

ばね秤は三つの物理的対応を用いて構成する。eisyrが可逆な弾性変形と復元力、eisysが変位読取りと校正目盛り、eisytが同じ元の力を比較する試行での荷重・変位の対応を与える。これらは一般の装置・力に使う関係であり、電子や特定の公式を基本関係に格納しない。校正の数値条件、部分関係、装置の静止、操作の物理的可能性、変位の範囲、読みの一致はelz–el3で合成する。

el4–el7は同じ装置と弾性要素を共有し、各成分について向きを変えた別の試行を許す。各試行が存在し得ることを記述し、全試行での成功や実施済みは述べない。測定の比較対象は元状況の同じ力記録であり、可能結果へ元の電子軌道全体を複製しない。ばねによる支持力と元の加速軌道の矛盾を避け、同じ力の寄与を等価な荷重として比較する読みを明示する。

emcは加速度の派生単位をA T²=LとM A=Fへ結び、同じkの力とKの加速度を指定する。emdは現在の実三成分における係数×加速度=力と、全六実数に対する係数恒等条件sepiをともに要求する。emeは同じ設定を二実数候補の外側で固定した質問である。零加速度の一例から係数を同定せず、全数値の実験的実現も要求しない。

局所検査は、同じ引数の接続と取り違え、三成分の符号、校正曲線、可能結果、同じ装置、単位尺度、数値候補を区別する。有限の校正標本や一つずつの二値束縛診断は全実数・全関数域の証明ではない。未知の曲線や物理的対応を真と補わない。

本文への統合では、通常の考え方に沿う問い、縦横の名称と軸の幾何、zunächst、ばね秤を例えばとする括弧文、力の呼称、規約を採る条件文、平方根の分母を含む二表示式、著者帰属を接続し、一群を再読する必要がある。今回の依存定義だけでこれらを完成扱いしない。
