# 語形を可視幾何から識別する最初の規則

## 対象と実装前の要求

対象は既存の通常文例にある `rain(town)` と `rain(home)` の最小対である。旧描画器では出現した参照に局所番号を振るため、この二文の可視形状が一致する。必要なのは、語ごとの形を公開語彙で固定すること、図形からその語を特定すること、適用先を線で結ぶことの三点である。

既存の型付き関数適用、`assert`、円の三サイズ、三本の基準線、放射方向の接続と幾何検査を再利用する。新しい意味演算子は加えない。今回は一引数の真偽関数を個体定数に適用した一主張を統合単位とし、既存のサンプルの二文と同じASTへ戻す。多引数、束縛、引用、文書の定義はこの断片の対象外で、入力されたら拒否する。

## 公開語彙と語形

共通語彙 `noema/resources/visible-lexicon-v1.json` に、各語の型、引数の役割、意味規約、反例、文脈依存、語形を収録する。配列位置や内部番号は語形を決めない。語形の割当ては学習する規約であり、円の形から自然界の意味を自動的に推論する仕組みではない。

| 語 | 公開された語形 | この例での読み |
| --- | --- | --- |
| rain | 大円と、中心から下の円周までの半径線 | 指定場所で、文脈の時点・範囲に雨が降っている |
| town | 中円と同心の小円 | 文脈で指定した町 |
| home | 中円の右端の円周上に中心を置く小円 | 文脈で指定した住まい |

`town` と `home` はこの例では個体を指す。町の性質や住まいの性質を持つ対象すべてを表す述語ではない。同じ場所が両方の役割を満たす文脈でも、二つの表現の語形は区別する。指示先の一致と語形の一致は別に判定する。

各語形は主円、最大一つの伴円、任意の半径線から構成する。円の寸法と合法な接触は固定済みの幾何規則に従う。今回の二つの個体表現は内部に線を持たず、適用を表す外部線は円周で止める。線が内部の識別特徴を上書きすることを防ぐ。

公開語彙を拡張するときは、既存項目を保持し、新しい語形が既存語形と一致しないことを検査する。同じ語に複数の実装上の別名を与えることはできるが、復号結果は公開された正規名へ戻す。この別名機能は「意味が同じ」という新しい判断を自動生成しない。同義語・多義語の一般規約や、文中で新語を導入する規則は別途必要である。

## 一引数主張の読み方

左の語を関数、右の語をその唯一の引数として読む。語と語は一本の外部経路で接続する。経路は水平・垂直・45度の直線からなり、途中で曲がってよい。関数は真偽を返す一引数関数、引数は個体定数でなければならない。この断片全体を一主張として扱う。

中円の語は上・中央・下の基準線のいずれにも置ける。同心・右側重なりなど語の内部関係は保つ。高さや接続経路の違いから語の違いを推測しない。上下反転・左右反転や回転は同値扱いしない。画像全体の平行移動と正の一様拡大縮小は読みを変えない。

復号器は円と線の一覧だけを受け取る。円の接触・包含関係から語のまとまりを取り出し、内部形状を公開語彙と照合する。外部線について、二つの語だけを結ぶ経路であることを検査してから、型と左右の順序を確認する。元AST、出現アドレス、辞書番号、配列順、SVG内の不可視属性は使わない。

大円を基準として拡大率と中央の基準線を求める。この断片は大円の関数を一つ含むため、この正規化が可能である。大円のない一般文書へ同じ方法を無条件に適用しない。線の逆向きの格納と、同一直線上の線分分割は正規化する。余分な円や線、切れた接続、未知語形、曖昧な語彙、対象外の構文は拒否する。

## 検査と次の統合条件

最小対の可視形状の相違、公開語彙の並べ替え・追加・別名による不変性、三つの高さ、経路の違い、平行移動と拡大縮小を検査する。異常入力の拒否は、接続の欠落、余分な形、語形の衝突、型違いで確認する。旧描画器の反例と固定資産は保存する。

この規則はW1の最初の反例を扱う実装である。語の構成による拡張、文書内の新語・固有名の導入、同義・多義、W2の一般構文、W3の自立文書、画像だけを読む第三者試験がそろうまで、W1全体や言語の完成とは判定しない。既存の全文ページを置き換える段階でもない。

実装入口は `scripts.visible_lexical_script`、検査結果は [visible-lexical-v2.json](../reports/visible-lexical-v2.json)、二つの可視例は `output/visible-lexical-v1/` にある。既存の幾何実装を利用するリポジトリ内の試作であり、インストールされたNoemaパッケージの公開APIにはまだ含めない。変更のない言語解析・意味検証の実装と、書記の試作を別のモジュールに置く。

```powershell
python -X utf8 -m scripts.project_work check --module scripts.check_visible_lexical --prepare --tests tests/test_visible_lexical.py tests/test_script.py tests/test_script_v2.py --verify reports/visible-lexical-v2.json
```

最初の検査報告v1とそのソースはGitに保持する。v2では、半径線と外部接続が同一直線になる場合に、円周を境に両者を分けて読む処理を加えた。固定資産は内容ハッシュで照合し、旧最小対の衝突を再現する。変更のない二作品の全文解析はこの局所検査で繰り返さず、全体監査に任せる。
