# 光速度保存の証明課題

u0086は、静止系で仮定した光速度の法則が運動系でも成り立つことを、これから示す課題として述べる。対象は先行の真空光伝播の全適用範囲であり、一つの縦光線や後続の球面波の標本だけではない。両系の現在の時計・測定規約を使うei43へ、同じVを渡す条件内容として記述する。

「仮定したように」は、同じ著者が先行wuで真空光速度の原理eifyを後続議論の仮定として採用したことへの振り返りと読む。原理の仮定採用と、各系における法則の現実の成立を区別し、挿入的な補足を課題へ結ぶ。

その理由は、二原理の両立性について証明をまだ提示していないことである。探索対象を、この段階zfxまでの同じ論説全体における同じ著者・同じ両立性の証明提示とする。第三節だけに範囲を狭めず、別の課題の証明や後の段階での提示を数えない。提示の有無と、論証の妥当性・証明可能性は別である。

両立性には既存eif5を使い、同じ二原理が一つの許容設定で共に成り立つ余地を保持する。原理ごとに別々の設定で成り立つだけでは足りない。この内容の証明未提示を光速度保存の課題の理由として述べる関係を、著者の提示へ結ぶ。後続の球面波の計算や証明完了を先に追加しない。

原刊900頁末尾から901頁冒頭までを照合した。有限検査は、条件の方向、同じ速度と設定、証明探索の全範囲、挿入補足・理由・著者帰属と引用の非実行を確認する。課題の記述を物理的導出や意味同値の自動証明としない。
