# 別の導出の可能性と、条件に沿った必要性

アインシュタイン1905年論文のu0147第一文とu0149の挿入句を部分記述した。「二つの変換によっても式を得られた」という振り返りと、群をなすことについて「そうでなければならない」とする表現である。結果の式や群の条件を述べる内容とは分けて保持した。

別の導出の可能性は、主体がその段階で利用できる方法と、その方法に割り当てた有限手順列によって表す。手順は既存のs2wを使い、前提の記述から結論の記述まで同じ許容規則でつながることを要求する。実行記録を要求する条件は入れていない。利用可能性を、実際に実行したことや内容の真理へ置き換えない。

「別の方法でも」の比較では、以前の方法の手順がその前提から同じ結論へつながり、それとは異なる利用可能な方法も指定結論へつながることを要求する。さらに、指定された変形の一手を新しい方法自身が含むことを確認する。必要な一手が別の利用できない方法にあるだけでは成立しない。

論文への適用では、目標を既出の同方向の条件付き合成式s3mへ接続した。以前の方法は運動と計算の前提s3cを使い、別の方法は二変換の設定s4sから、一変換の式s4rを得る一手を含む。両経路の途中式や許容規則は引数で指定する規約として保持し、原文が具体的な手順を列挙しているとは扱わない。第三系から同じ物理的な速さの式へ至る接続の健全性も、経路が記述されたことだけでは証明されない。

振り返る段階と発話時点には別の参照を使い、前者が後者より厳密に前であるという関係を加えた。段階に「以前」という名前を付けただけでは成立しない。同じ時点や先後関係を満たさない例も拒否する。一方、この表現だけから「実際にはその方法を一度も使わなかった」という否定を補うことはしない。

必要性は、同じ内容と文脈について採用した候補状況が非空であり、その全候補で内容が成立する、という形にした。一つの成功例だけでは足りず、空の候補集合によって空虚に成立することも認めない。比較用には、同じ内容が現在状況でも成立するという追加条件も定義した。これにより、採用した候補での必要性と現在の真理を区別できる。

原文の挿入句には、この議論の条件に沿う候補に関する必要性という読みを採用し、同じ群の内容s5fへ接続した。行為者への命令や義務には変換していない。この読みを、論理的必然性、方法上の要請、修辞的な当然さの全てと同一視するものではない。候補の選定根拠と歴史的な語義の確定は残る。

手順の前後は記述として比較する一方、必要性の評価には状況ごとの真偽を持つ内容を渡す。必要性を著者へ帰属させる記述も既存の引用規則を満たし、引用の内部に脱引用を隠さない。帰属の検査で、物理的な前提や群の式を実行して真だと認定することはない。
