# ここでは全ての事例に制限がある

第五段落u0012の `[537,581)` を、直前の四つの事例のどれにも、本人の選択に任せない要求があるという読みで構成した。将校・財務担当官・聖職者・統治者の発話の対応を保ち、その要求が本人の選択肢の一部を排除することを全四事例について要求する。[通読判断](../data/everywhere-restriction-reading-v1.json) は39非空白文字、[検査報告](../reports/everywhere-restriction-v1.json) は構成の実評価と検査の境界を記録する。

## 指示する範囲と制限の意味

`Hier` は直前の四事例を指すものとし、四つの文章箇所の列 `r2us` を談話の指示と `überall` の全称量化で共用する。列には重複を認めない。世界の全ての場所・人・自由が制限されているという主張へ広げない。

各事例の話者と発話を参照し、同じ役割・方面・宛先・指示内容へ再接続する。前三者は、同じ本人が議論を行わず教練・支払い・信仰を行うという命令である。統治者は議論への容認を保ったまま、同じ出所の要求に従って履行するよう命じる。制限を一律に議論の禁止へ置き換えない。

自由の制限は、要求の適否をいったん除けば本人の選択肢になる候補のうち、当該要求を満たさないものがあるという意味で構成した。要求は、その選択を適合するものとして残さない。他人の違反や、もともと選択肢にならない不可能な行動だけではこの条件を満たさない。

比較候補では、発話者、要求、宛先、本人以外の行動、関係する背景を同じに保ち、その本人の選択だけを変える。候補の範囲を要求に適合するものだけへ先に絞らない。この選択肢の比較関係は意味規約に明示し、単に真偽の異なる二つの状況を渡せば制限になるとはしていない。

この読みは要求が本人の選択を制限することを扱い、その命令の法的・道徳的な正当性、物理的な強制の成功、実際の服従や違反を付け加えない。発話を提示したという前文の構成から、正当な義務が発生したと推論する規則ではない。この文で著者が追加する評価として帰属する。

各事例に少なくとも一人の制約される宛先がいることを要求する。全員の全選択肢が消えるとは主張しない。一方、一事例だけに制限があって他にない場合は `überall` を満たさない。

## 構成と検査

`r2uv` は四事例と同じ話者・発話の対応、`r2uw` は同じ発話の宛先、`r2ux` はその本人が当該指示の内容を満たす条件である。`r2uy` は、その本人の自由選択候補で内容が満たされない例を要求する。`r2uz` は異なる全四事例への量化、`r2va` は指示範囲・著者帰属・本文順序をまとめる。

前三者の内容はNoemaで評価し、理性的な検討・教練・支払い・信仰の組合せを確認する。統治者の `r2ud` には全記述域を量化する要求の網羅性があるため、内容の選択の検査ではその既存定義を境界に置く。全記述域の有限評価拒否と有限診断の限界は [先行報告](free-choice-obedience-v1.md) のまま保持する。

発話の接続と役割、各人の選択候補、全四事例の量化は検査を分け、境界の引数を照合する。別人・別の出所・別の発話、利用できない選択、全選択が指示を満たす場合、四事例の一つだけに制限がない場合、事例の重複を拒否する。著者への帰属の検査では世界の制限や候補の内容を実行しない。
