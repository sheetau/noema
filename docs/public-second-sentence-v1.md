## 自己離脱と比喩の照応

新たな離脱過程を付け足す必要はなかった。既存の予測には、同じ発信者の自己離脱がすでに入っている。その接続を実際の定義の引数から確認した。

| `r2lu → hzr5` | 同じ本人・話題・発話・性向・期間・基準点 |
| `hzr5 → hzr4` | 一つの離脱過程と前後点を全受け手へ共用する |

| `hzoe → hzod → h4p` | 同じ本人の実際の自己活動・因果・状態変化、最初の発信に先立つ完了 |

`h4q` は新たな出来事を要求する条件ではなく、実際に予測内で要求される `h4p` の存在閉包である。したがって、別の人の達成や経路外の出来事で比喩の対象を埋める必要はない。検査はこの存在導入と変数の対応を確認し、人物・完了点・発信点を取り違えた候補を拒否する。

頚木の描写は現実の身体条件として実行しない。知的な自己離脱と物理的な装具の除去は、対応する人物役を持つ異なる内容である。物理過程と知的過程の同一性、木製であること、二頭一組、独力での除去、全ての文化的連想は追加しない。頚木を負担・支配からの解放に用いる用法は、先行する[語義確認](yoke-depiction-v1.md)とも整合する。

## 通し読みと採用した範囲

[読解記録](../data/public-second-sentence-reading-v1.json)は、Dennから文末までを二十の連続した範囲に分け、全語句・句読点を対応させている。原刊483頁も再度目視した。判断の要点は次の通りである。

- daは先行文の自由を残す場合への照応。第一文と同じ公衆・候補・期間・起点を使う。
- immerは議論上の全評価機会。非空性・将来性・後続点を検査し、成功する時点だけを選ばない。各機会で同じ人が該当するとは限らない。
- einigeは異なる二人以上。その中に少なくとも一人の任用された後見役がいる。正確に二人、全員ではないこと、後見役の外側にも成功者がいることは加えない。
- welcheとsieは同じ自己思考者を指す。本人の離脱完了は最初の発信より前にあり、将来の取得完了と混同しない。伝達がすでに始まっていた場合の継続も許す。
- Geistは理由ある自己評価と各人の自己思考への使命承認に向かう性向。高い自己評価、特定の職業、神や国家を唯一の規範源とすることは補わない。
- um sichは社会的な接点、伝播はその範囲の異なる二人以上への取得。受領・理解・同じ状態の取得・因果・持続を保持し、単なる発話や全読者への普及としない。
- Dennは第一文への理由提示。主張の真理や論理的な十分性の証明は、著者の理由提示と別である。

これらは意味規約と文脈を固定した一つの読みである。機会・通常性・人数基準・社会的接点の適切な値を自動発見すること、全ての可能な読解や読者の連想を同時に再現することは主張しない。この読みの下で、第二文に未処理の語句・関係・提示は残っていないと判断する。
