# 円の偏心包含を禁止する訂正

利用者は2026-11-03に、output/kant-shared-argument/index.html の中円内で小円が左右に偏る形を「明確な違反」と指摘した。内側に偏った小円まで許容した実装側の解釈が誤りであり、当該形を撤回する。

現在の構成規則は次のとおりとする。

- 離れた円と、既定の二種類の接触は従来の制約に従う。
- 同心の二円は中心を共有する。
- 非同心で重なる二円は、**小さい円の中心が大きい円の円周上にある**場合に限る。
- 大きい円の中心を小さい円の円周上に置くことを理由に、内側の偏心配置を許可しない。

旧生成器の幾何検査は、中心間の距離がどちらかの半径に等しければ許可していた。この判定を当初の要求の十分な検査として扱ったことが誤りの原因である。旧コードと旧証拠は保存し、現在の描画器と図形読取器は scripts/kant_geometry_rules.py の追加制約を必ず通す。

連言・選言・含意・共有頭には、小円の中心を中円の左円周上に置く形を用いる。中心間の距離は小円半径ではなく中円半径である。連言は中心線なし、選言は上、含意は下、共有頭は右への中心線で区別する。既存の30根語と衝突しないことと、接続後も区別が残ることを確認する。

以前の「許容二円配置41」という集計は、禁止された偏心配置を含んでいたため、現在の許容範囲を示す根拠として使わない。新しい検査で絞り直した一覧を使う。既存の意味判断や語義は変更せず、誤った字形とその許容判定を訂正する。
