# 同じ法則の個別適用と、独立した量の記述

アインシュタイン1905のu0161・u0162に、相対性原理から動く系の方程式を要求する部分草案を追加した。計算で得た混合成分と、動く系で定義する電気・磁気の成分は別の参照で保持する。同じ方程式を満たすことだけでは、成分値の一致や比例関係は導けない。

## 合成した条件

[一般用文書](../examples/v014/law-specialization.noema)は既存の法則保存の定義を再利用する。新しい基本演算子は追加しない。

- `s77`：同じ候補履歴、二つの系、同じ法則を指定する。指定した左右の記述が各系に対応し、すべての対応記述対で法則への適合が一致することを要求する。
- `saa2`：左右それぞれの法則適合を、同じ文脈での命題内容の真偽へ結び付ける。
- `sab2`：この対応が成立し、源側の内容が真なら、対象側の内容も真になるという条件文を作る。源側が偽の場合に対象側を真だとは断定しない。

[論文の文書](../examples/v014/einstein-law-specialization.noema)では、既存の六式を独立した新しい二つの場と領域に適用する内容を `sac2` とした。比較する系・法則・候補履歴・対応記述と、方程式内容への橋渡しを `sad2` に明示し、相対性原理と合わせた前提 `sae2` から条件文 `saf2` を要求する、著者の推論として記述した。

橋渡し条件は形式化にあたり明示した条件である。原文がこれらを同じ形式で列挙しているとは扱わない。また、著者に推論を帰属させることと、その推論の妥当性を証明することを区別する。

## 検査と限界

一般条件96例、原理の個別適用32例、場の引数対応8例、著者への帰属7例を検査する。法則・履歴・対応記述の取り違え、対応の欠落、別の対応記述での不一致、完全性の前提の欠落を区別した。既存の定義と著者文を保持し、通常記法・圧縮記法・固有文字を経由した構文の往復も検査する。

原理の検査は、与えた有限の法則・履歴・対応関係について実際の定義を評価している。方程式の内容の真偽は明示したテスト用の解釈であり、任意の物理系に対する証明ではない。場の引数対応の検査も六式の成立をテスト用の関係で与え、実数全域を標本で代用していない。

関連27テストが通過した。二つの文書についてCLIのJSON出力と構文木の一致、SVG出力が妥当なXMLであることも確認した。字形の目視検査は今回行っていない。一般用文書は基本記号0・定義6、論文文書は基本記号541・定義861・著者文155となる。論文の圧縮記法は225,865文字で、親文書から1,314文字増えた。基本記号には既存の未説明の物理関係や個別の参照を含み、この件数を説明済みの語数とは扱わない。

原文の六式M0300は、保存したMathMLの微分の順序・成分・座標・係数との対応を検査した。u0161で範囲を明示した本文は、相対性原理の要求と「静止系で成立するなら動く系でも成立する」という箇所に限定した。次は未完である。

- 力の作用による測定上の定義、電気的・磁気的な量の基礎説明、真空の意味。
- 計算した混合成分と、動く系で定義する成分との関係、および後続の共通係数の議論。
- 原刊画像との照合、原文全体の意味一致確認。
