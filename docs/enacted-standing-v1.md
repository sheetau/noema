# 活動の役割と、実際の遂行

前版の評価語の読解候補には、「同じ人が同じ行為でその立場を取る」という関係が引数として残っていた。今回は、その入力へ、既存の活動・立場の対応と本人による実行を結んだ条件を渡す。評価語のための新しい基本記号は追加しない。

| 記号 | 内容 |
| --- | --- |
| `rfs` | 同じ人・活動・立場・状況について、活動がその立場での行為として位置付けられ、その人が実際に行う。 |
| `rft` | `rfs`が成立し、その人へその立場の職務が委ねられていない。 |
| `hza7` | `rfs`を既存の活動分類`cb`と実行`cg`へ接続する。 |
| `hzbd` | 委任`cf`の不在も含む`rft`を既存関係へ接続する。 |
| `hzba` / `hzbb` / `hzbc` | 前版の前件・条件文・前件の実例の存在へ、`hza7`を渡す。 |

活動の記述で立場が指定されていても、未実行なら実際の役割遂行には数えない。本人が何かを実行していても、別の活動や別の人についての役割分類とは組み合わせない。一つの行為が複数の立場で記述されることは妨げず、そのうち指定した立場への対応を調べる。

職務の委任は別に保持する。委任がなくても、評価条件を満たしていれば、前版の条件不足の前件は成立しない。逆に委任があっても、独立した別の条件に不足があれば前件は成立しうる。したがって、`hzbd`を批判の不適切さや処罰可能性の十分条件として追加していない。

この接続で構成したのは「その立場で実際に行為した」という条件である。本人が自発的に立場を選んだこと、立場を自認していること、意図的に権限を主張したことは含めない。前版の「自ら取る」という関係の全意味を定義したとは扱わず、実際の役割遂行として読む候補を明示する。前版の関係引数も保持している。

検査では、役割分類・実行・委任・条件不足・納付要求・誘発可能性・措置の可能性の128通りと、参照先を変えた11対照例を確認した。肯定例の発話の生起と提示も、実行の有無に合わせた。引数を取り違えた対照例は式の結合を調べるための有限解釈であり、そのまま現実の整合した状況を記述したとは扱わない。全文草案と独立抽出文書の結果は一致する。

古い評価性質と「立場を取る」の入力を未評価にし、新しい定義だけで計算できることも確認した。委任情報が未知でも、委任を参照しない評価条件と実際の役割遂行は判定できる。一方、委任の不在を尋ねる場合は、その情報が未知なら停止する。役割分類や実行自体が未知の場合も、勝手に成立・不成立を補わない。

活動と立場の対応、実行の基礎説明、評価条件の採用根拠、評価語の語用論は残る。*vorwitzig* の唯一の解釈や原文との意味一致は確定していない。*Skandal*、*sogar*、*demohngeachtet* と制度の説明も未完である。既存範囲内の具体化なので、対応範囲の文字数と意味確認済み区間数は増やしていない。

7定義を追加し、基本記号と著者主張は追加していない。全文草案は92,170代用文字で、親からの増分は1,242文字、独立抽出文書は6,626文字である。
