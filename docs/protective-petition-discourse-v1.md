# 保護提案の目的・対象・留保

第六段落u0013第七文の後半を、同じ共同提案の保護目的、仮定的な改革対象、同じ政策への非妨害の留保として接続した。原文の対応範囲は [AA VIII, 39](https://korpora.org/kant/aa08/039.html) の24–27行で照合した。

`r5he` は同じ政策を採用するよう共同で提出する行為、`r5hf` は提案される複合政策内容である。`r5hg` に全該当改革共同体への保護、`r5hh` に旧配置を維持したい全該当共同体への非妨害を分けた。どちらも同じ政策の実施を含み、その連言が既存の複合内容と一致する。対象は選択点で固定し、政策の効果を評価する後の点で選び直さない。

`r5hk–r5ho` は、提案の四対象に宗教共同体・領域・主題・旧配置・新配置・合意を続けた十対象を共有する。改革合意と維持意向は独立した選択条件であり、一方の否定を他方にしない。`etwa` と接続法は、この条件に該当することになるかもしれない共同体を仮定的に扱う提示と読む。現実の改革共同体の存在や数値確率は付け加えない。

「王座」の指示対象は、同じ宛先・共同体・評価点の公的な君主的統治者 `r5hi` とする。それに制度上結び付く物理的な座席の描写を `r5hj` に残し、換喩として提示する。座席の現実の存在や身体的な対面は提案の条件にしない。座から王の威厳や統治者側を指す用法は [AdelungのStuhl項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_2_3_3550) にも見られるが、ここでの読解は原文の公的提出という文脈に基づく。

`r5hp` は同じ全体内容・著者・文脈について、換喩、保護目的、仮定的な対象選択、非妨害の留保を結ぶ。目的を偶然の結果と区別しつつ、引用した行為や政策の現実の実施・達成は要求しない。主目的を留保によって撤回せず、同じ政策の両条件を保持する。

これは全文統合に使う依存群である。全文の量化、`Nun`・`wohl`・`gleichsam`、前文との照応、同じ全文内容への適用と著者帰属、通読が残る。第七文の確認済み文字数はまだ加算しない。
