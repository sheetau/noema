# 担体ごとの電荷と全分布の合成

第九節u0232の小さい剛体への電荷付着は、各担体の局所成分について述べる。複数の担体を一つの剛体にまとめず、場の方程式が使う全電荷分布との対応を別に構成する。

ekybは、全分布の物質成員を各担体の全物質点へ漏れなく重複なく分け、各局所成分の全成員とも一致させる。物質点の同一性と空間的位置は別である。異なる担体の空間的重なり、正負の相殺、零電荷の部分は、この分割から除外しない。ekycは同じ各担体へ完全な付着ekx3を適用し、担体ごとの系・区間・座標族・部分量関数を明示する。

電荷の合成は、有限個の担体に範囲を狭めずに表す。ekx4–ekx7は重複しない有限選択、その包含、符号付き和を構成する。ekyaは任意の正の精度に対して、ある有限選択以後の全有限拡張の和が同じ値へ近づく条件である。順序に依存しない総和という読みを明示し、特定の列挙順でだけ収束する値や発散を有限電荷として採用しない。有限族では通常の和になり、空の族では零になる。担体の内部は既存の連続体の部分量で扱い、全空間のあらゆる物質点を原子電荷へ置換する構成ではない。

ekydは各成分と全分布の電荷を、同じ系・出来事・座標時刻・空間領域・種類・単位の物理的保有量eisvxへ結ぶ。ekyeは場に使う領域総量の全選択領域でこの合成を要求する。ekyfは、これを同じ密度・規格化・六方程式と、各担体の付着へ接続する。

場の系での各成分の量には、その系の物理的帰属を要求する。担体の別の評価系で固定した部分量を代入して、系間の電荷不変を先取りしない。各担体の評価系と場の系について、同じ物質点・出来事・期間の座標対応を全領域へ適用することは残る。イオン・電子、理論の電磁的基礎、著者提示、原文単位全体の統合も別に確認する。

有限検査は畳込みの数値本体、分割、全有限拡張の診断、物理量と場の引数共有を分ける。実数・列・関数の全域を有限に列挙できない場合は拒否し、有限例を無限担体族の収束又は原文同義性の証明にしない。
