# 同じ法の共同変更と、自己立法の問い

カントu0013の「人民が自分自身に同じ法を課せるか」という問いと、それを立法の判断基準に置く部分へ草案を広げた。人民を行使主体と規範の名宛人の双方に束縛し、同じ法の条項を同じ前後状況で成立・廃止させる構成を用いる。法の名前だけを内容の代用にせず、要求や許可の変更を既存の規範構成で記述する。

一つの法が複数の条項を持つ場合、各条項の変更が別々の結果状況で可能なだけでは足りない。例えば、一方の状況では義務を成立させられ、別の状況では許可を廃止できても、その二つを同じ行使で実現できるとは限らない。今回の変更条件は、全ての条項に同じ法・人民・開始状況・結果状況を渡す。

| 定義 | 内容 |
| --- | --- |
| `rj7` | 法と人民を保った、一つの要求・許可の成立または廃止 |
| `rka` | 非空の条項列に含まれる変更が、同じ前後状況で全て成立する |
| `rkb` / `rkc` | 同じ行使の統制・制度上の認定・全条項の変更／その結果状況の存在 |
| `rkd` | 同じ仮定状況で、人民自身の行使への許可と、その行使の権能がそろう |
| `rke` / `rkf` | 自己立法の条件を、対象とする立法の必要条件／必要十分条件として使う |
| `rkg` | 同じ自己立法の条件が成立するかを問う発話 |
| `hzd3` / `hzd4` | 条項の変更を既存の要求／許可関係へ接続する |
| `hzd5` / `hzd6` | 既存の規範関係を用いた自己立法の内容／質問 |
| `hzd7` / `hzea` | 既存の規範関係を用いた必要条件／必要十分条件の内容 |

行使の対象列は「行使主体・人民・法」の三個体である。自己立法では先頭二位置に同じ人民を渡し、法もそのまま保持する。別の統治者が人民に課せること、同じ人民が別の法を課せることを、この自己立法へ移さない。各条項の対象記述・役割・肯否・引数列も保持する。

「課せる」の草案には、指定候補の状況で許可と制度上の権能が共にあるという操作的な読みを使う。現在の制度で許可されていることや、実際に行使したことは要求しない。逆に、ある候補で許可され、別の候補で権能があるだけでは成立しない。物理的な実行可能性、現実の採択、全市民の賛成、直接投票、代表者の正当な選出は補わない。

判断基準は、指定した主体と法の全てに適用する。「立法が許容されるなら自己立法の条件を満たす」という必要条件と、両者が同値だという強い条件を分けた。対象範囲が空でも普遍条件は成立するが、法や立法主体の存在を断言したことにはならない。原文の「判断基準」をどの強さで採るか、現実の制度がその基準を満たすかは別途確認が必要である。

質問発話の内容は、この同じ自己立法の条件である。問いを提示することと、肯定・否定の回答を主張することを区別する。著者への質問提示の帰属だけを評価するときには、引用した内容の規範・候補状況・権能は実行評価しない。

検査は、二つの条項の変更・統制・制度上の認定・行使の許可・反対要求の64通りを一般文書と原文側で扱う。別々の結果状況での条項変更、許可と権能の候補の不一致、別の人民・法・行使主体、空の条項列・候補集合なども比較する。必要条件と必要十分条件の差、二つの法のうち一方だけが自己立法の条件を満たす場合、質問と主張の発話の差も検査する。

[一般文書](../examples/v014/self-legislation.noema)は3,319文字、[原文付き草案](../examples/v014/kant-self-legislation.noema)は145,986文字、[抽出文書](../examples/v014/self-legislation-core.noema)は4,764文字である。14定義を追加し、原始記号と著者主張は追加していない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-self-legislation-basis-v1.json)と[検査記録](../reports/self-legislation-v1.json)を保存する。

関連18テストが通過した。三文書のCLI解析結果は構文木と一致し、通常表記・簡略表記・独自文字v2の往復を確認した。抽出文書のSVGはXMLとして検査し、字形の視覚検査とは区別する。全体監査は211件の対応表と460件のNoema文書を検査し、保存済みの集計と一致した。カントの部分草案の明示範囲は144文字増え、4,883 / 15,513文字（31.48%）となった。意味確認済み全文区間数は増やしていない。

これは自己立法の十分な哲学的定義ではない。理性的に可能な同意や正当性、候補の選定根拠・網羅性、人民と法の基礎定義、共同意思、代表資格、原文の`wohl`の含意は残る。指定した規範の変更を扱うため、変更を伴わない確認や全ての法形式を網羅したとも言えない。後続の暫定的な秩序や君主の議論、著者帰属と全文の意味確認も未完である。
