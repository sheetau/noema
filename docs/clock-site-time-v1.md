# 時計所在地の時刻設定

u0045第二文は、前文の二系と計器を受け、それぞれの系で時計のある全地点に時刻を定める追加指示である。原刊898頁を再照合し、静止系のt、移動系のτ、二度の第一節参照、後半の「時計が置かれた地点の間の光信号」を確認した。現在の命名や実験結果の報告ではない。

`eiye`は既存`eivj`の時計校正と代表配置の完全な静止履歴を任意の系へ適用する。針を含む全物質点を静止させない。`eiyf`は初期と同じ配備範囲を維持し、各時計の全所在地点が測定空間内にあり、参照時計も配備範囲に属することを要求する。共通参照への同期に加え、同じ配備範囲の全時計対に既存`qo`を適用する。これは§1の一つの整合的な網としての読みであり、`ql`による試行範囲の完全性、非空な光往復試行、全試行での`db`を保持する。参照時計はこの設定で共通に選ぶ。初期には参照時計の選定まで指定されていないので、初期の関数候補との等置は加えない。

`eiyg`は同じ配備時計・場所・系・値について、既存`eiui`の同所の表示出来事、光同期、校正された自系静止を合わせる。`eiyi`は既存`eiuk`の存在・全実数にわたる一意性を保持し、その同じ候補値が指定場所の配備時計による表示であることも要求する。`eiyk`は既存`sgi`を使い、時計のある全地点で起こる全対象出来事へこれを適用する。時計のない地点には値を生成せず、出来事のない地点に出来事の存在を追加しない。`zcz`は対象の全出来事範囲であり、成功する測定だけへの限定を意味しない。

tの既存規則`eiwt`は時点を引数とする一方、局所表示は出来事を引数とする。この差を隠してtに別の規則を上書きしない。新しい一般関係`eisnk`で出来事とその系内の生起時点を結び、`eiyj`で少なくとも一つの対応と、全対応時点における`yl`と同じ局所時刻`zbe`の一致を要求する。異なる時点記述を許すため、時点個体の一意性は要求しない。移動系のτには同型の`eiym`を結ぶ。両系の時刻値を等置しない。新しい原始記号はこの出来事・時点の一般関係とτの呼称個体だけで、文の内容や時刻設定の完了を原始関係へ移していない。

`eiyn/eiyo`は、§1の局所表示と光往復同期を同じ型の閉じた規則として各系へ適用する。`eiyq`はこの二つの規則と第一節の対応を`eislp`で保持する。既存`eing`のra/rcへの固定を移動系へ流用せず、同じ手順の系ごとの適用として読む。`eiyp`は両系の時計所在地の時刻条件、`eiyr`は先行空間測定への追加採用、`eiys`は指示、`eiyt`は著者帰属と本文順序である。引用された物理内容は著者帰属や参照だけでは実行されない。

検査は、配備時計の欠落・余分な同期対象・参照時計の交換・一試行の失敗・地点の取り違え・別表示の混入・時点対応の欠落と複数記述の不一致・両系の規則の混同を区別する。全実数の履歴と一意性は有限標本へ縮めず、既存の依存検査と拒否動作を保持する。構文・型・往復と有限対照検査の成功は、原文の意味同値や物理的実現の自動証明ではない。第一文と第二文の全体判断は別記録で行う。
