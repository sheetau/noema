# 私的活動の制限の程度

既存の規範と割合の定義を組み合わせ、指定した私的活動の範囲について、明示的な禁止の割合を表す候補を追加した。新しい基本概念は追加していない。これはカントの `sehr enge eingeschränkt` の程度を検討するための操作的な尺度であり、その句の意味を完全に記述したとはしない。

規範を調べた結果は、同じ出所・人・役割・活動・実行記述・文脈に固定する。実際に活動したかどうかは判定しない。

| 分類 | 条件 |
| --- | --- |
| 許可 | 明示的な実行許可があり、規範の衝突がない |
| 禁止 | 不実行の要求があり、実行要求も実行許可もない |
| 衝突 | 両極性の要求、または許可と反対極性の要求がある |
| 未分類 | 上のいずれにも決まらない |

実行と不実行を両方許可することは選択を認めるため、衝突とはしない。実行の要求だけから許可を導く規則は追加していない。要求があるのに許可の有無が明示されていない場合は、ここで採用した二分類には決まらない。各規範の有無を評価できない場合は、未分類という既知の結果に置き換えることもせず、評価を拒否する。

一般定義 `rdx` は衝突、`rdy` は指定極性の禁止、`rdz` は衝突なく許可か禁止に分類済みである条件を表す。`rd2` は、独立した対象範囲の非空・重複のない全列挙、全対象の分類済み条件、正確な割合、評価基準を組み合わせる。カント草案の `h7y`・`h7z`・`h72`・`h73` が同じ実行記述へ接続し、`h74` が既存の私的使用の範囲に対する禁止割合を評価する。

たとえば、固定した二活動の一方が禁止、他方が許可なら、禁止割合は1/2である。許可された活動を一覧から抜き、割合を1と報告することは拒否する。全規範を確認しても一方が未分類であれば、全範囲の制限の程度は確定しない。原文に数値はないため、「非常に」の基準を1/2などへ固定しない。テスト中の閾値は境界を検査するための仮定に限る。

この尺度には活動の粒度への依存が残る。禁止一件・許可一件を、禁止二件・許可一件と分ければ2/3、禁止一件・許可二件と分ければ1/3になる。対象範囲そのものを狭めても割合は変わる。これらが計算上成立する例を検査に残し、同じ自由度を測った証拠とはしない。比較には対象範囲と活動の分け方を固定する必要がある。強度や重要性による重み、連続的な選択範囲、時間に占める頻度はこの尺度に含まれない。
