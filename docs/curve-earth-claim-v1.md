# 曲線への仮定と地球時計の比較

u0128の第一文は、前段の折れ線の結果を証明済みとして扱い、それを連続曲線へ拡張する仮定を置く。その仮定の下で、初め同期した二時計の一方を一定の速さで閉曲線に沿って戻すと、残した時計より留保付きの量だけ遅れると述べる。仮定の採用、帰結の提示、所要時間tの説明を同じ推論範囲へ結ぶ。

曲線・現在表示・初期同期と残留・到着比較は前段の定義を共有する。全期間の指示が厳密率に従うというモデル法則は、近似残差を構成するための補足注記として発話外に置く。原文が明記する曲線への拡張仮定と、読解上補うモデル法則を区別する。

第二文では、赤道の時計と一方の極の時計を比較する。Unruhuhrは、慣性体と復元ばねからなる回転振動系を歩度の調整に用いる時計として読む。部分の帰属、復元作用を持つ振動、時計を調速する機能を既存の三関係から合成する。この読みの機構上の確認には、製造者の用語集にある調速器とばねの説明も用いた。[Patek Philippeの用語集](https://www.patek.com/en/glossary)

同じ構造・性状を持つことと、その他の比較条件が全て一致することは別の条件である。赤道と極の位置を表面と回転軸への関係で定め、どちらの極も許す。一様回転の地球という背景の下で比較する読みを明示する。これは実際の地球の環境や重力の影響まで導いたという記述ではない。

歩度を文字盤の絶対値から比較しない。同じK時間区間に属する実際の表示を一つの関数へ結び、その前後の差を正の時間差で比較する。二時計は別々の指示原点を持ってよく、初期同期や対面帰還を追加しない。比較期間内の任意の正の時間幅について赤道時計の正の平均歩度が小さく、その差が文脈の「ごく小さい」という基準を満たす読みを採る。原文にない数値閾値は固定しない。

mußは、議論の物理的前提と一様回転背景を保つ許容候補で、同じ比較内容が例外なく成立するという推論上の必要性として表す。範囲は非空で基準設定自身を含み、結果が成立する候補だけを選ばない。著者がこの必要性を帰結として述べることと、その現実での成立や処理系による物理的証明は区別する。
