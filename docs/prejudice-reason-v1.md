# 有害さの程度と理由提示

第三文の `so schädlich` の評価を構成し、前半の条件付きの反転を受ける程度の指示と、後半理由節からの `weil` の理由づけを接続した。文番号59を `r2ox` へ更新し、先頭59文と旧定義の意味は保持する。

## 同じ植え付けの有害さ

結論側の有害さ `r2oq` は、理由側の事例と同じ参照から既存 `r2oe` を評価する。植え付け行為が同じ受け手の偏見採用を生じさせ、その先行状態が同じ対象者の後の不利益へ寄与するという二つの因果関係を保つ。一般的な因果の推移律によって、別の直接原因を作ることはしない。

生み手本人または先任者の関係と、経過の終点という追加条件は理由節側に保つ。結論側の基礎となる害には、元の行為・受け手・意見・前後順序・実際の要因と結果を要求する。

全対象者への害 `r2or` は、理由節と同じ非空で重複のない列 `h225c` を使う。全事例の範囲も同じ `h225b` である。程度の評価に都合がよい事例や被害者へ選び直さない。

## これほど有害だという読み

[原文](https://korpora.org/Kant/aa08/036.html)の `so schädlich` は、前半の作用の反転を受けて、これほど有害だと高い程度を取り立てる読みで採る。厳密な尺度値、損失額、確率、最大性は加えない。

`r2os` は一位置の列 `[事例]` から、その事例の全対象者への害を内容として返す。`h225q` は既存 `hzxr` の高程度評価を段階3の記述に適用する一般形であり、`r2ot` は害の成立と同じ事例の高程度評価をともに要求する。各対象者が個別に高程度の損害を受けるという追加条件にはしない。

評価内容は `r2ou` で評価箇所 `[701,744)` に帰属する。`r2ov` は、その同じ評価の性質と程度を、前半の箇所 `h224m` の内容 `r2nf` が示すものとして指示する。前半の条件を落とさず、示された出来事が現実に起きたことや、前半と後半の人物・時点の一対一対応を補わない。この程度の指示は、数値的な等式ではなく著者による提示の関係である。

## 理由の向きと検査

`r2ow` は、既存 `ud` により理由節 `h225o` を評価箇所 `h225s` の根拠として提示する。本文の並びは既存 `ue` により、前半・評価・理由節の順で結ぶ。根拠の向きと文章の前後は別の関係である。提示された理由が高程度評価を十分に証明することや、引用内容の現実の真理を自動認定しない。

検査では、理由側の供給済みの引数から得た害の関係が、結論側と構文木で一致することを確認する。害だけが成立する場合、高程度評価だけが成立する場合、第二事例・第二対象者に失敗がある場合を区別する。程度の性質・事例・参照文脈が一致しなければ評価を採らず、未知の程度も拒否する。

帰属と理由提示は世界の入力を全て未知にして検査する。前半の条件付き内容をそのまま引用すること、程度の参照先、理由の向き、本文順序を確認する。巨大な全事例の意味構成を毎回再評価する検査では、個別の因果関係を別途直接検査した境界として使う。
