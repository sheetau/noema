# 対応する二種類の介入による威厳の損傷比較

第六段落最終文の二側を、同じ君主の同じ最高職における公的威厳の損傷として比較する。自身の見識による介入にも損傷があり、宗教的専制を支援する側では、対応する条件の下でそれがさらに大きいという読みである。全文の意味判断はまだ追加しない。

単に第二側の終点が低いだけでは、損傷が大きいとはいえない。`r5qi` は両側の無介入比較範囲を非空とし、その全範囲の一致を要求する。関連背景を保ったこの共通基準の下で、`r5qj` は両場面の一意な評価値、第二側への厳密な低下、その同じ二値の大きな隔たりを結ぶ。`r5qk` はさらに両側それぞれの因果的な損傷 `r5pj` を要求する。

[原文](https://korpora.org/kant/aa08/040.html)のweitは、大きな隔たりという評価を伴う。単なる順序の違いや語調の強さだけにせず、固定した同じ質的尺度の同じ二値を比較する。数値の差、割合、倍率、等間隔は追加しない。隔たりが大きいという入力だけで、尺度の整合、一意な評価、大小の向きを代用することもできない。

`r5ql` は両場面の評価を同じ君主・最高職・共同体へ結ぶ。`r5qm/qn` は、先に構成した二種類の介入について最高職を引数に出し、内容審査、権能の使用、専制支援と威厳の帰属に同じ職を使う。自身の見識側の批判可能性を比較対象の選択条件にはしない。これは全文で別の帰結として接続する。

`r5qo/qp` は同じ臣民・検討活動・作品・領域を保った二側と、同じ比較結果を結ぶ。場面対の範囲は、関連背景を保って比較対象の働き方を対応させる全範囲として、結果を見る前に固定する。無関係な全事例の交差比較に広げず、都合の悪い結果を後から除かない。二種類の介入条件は排他的とは限らない。同一場面を左右へ複製しただけでは、厳密な追加低下は成立しない。

`r5qq/qr` は非空の全対応対に、両側の適合と比較結果を要求する。登録された場面対の一部に損傷がない場合や、介入の種類・役職が違う場合を、候補から消して通過させない。これらは比較する仮定場面の条件であり、現実に二種類の行為が発生したという歴史的事実の主張ではない。

検査では空・一部だけ共通の比較範囲、別基準で低い終点、因果寄与の欠落、評価の曖昧さ・同順位・逆転、小さい隔たり、別役職の混同、登録された不適合な対、十対象列と評価局面の取り違えを扱う。現実の社会的因果や威厳の評価を有限モデルが測定・証明したとはしない。
