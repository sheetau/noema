# 市民の納付拒否と賦課批判の処罰可能性

第一節は、同じ納付要求への全候補反応に拒否禁止を適用する `r34p` と、全賦課事例を扱う `r34u` で記述する。拒否は要求と反対の実践方針を取る反応であり、未払い・不能だけではない。禁止の出所は、この議論で市民の公的負担と規律を評価する規範源 `h245d` とする。実際の賦課発令者が別途拒否禁止を発令したという歴史的事実は加えない。旧 `r33z` は保存するが、この文の外側の禁止にはこの規範源を明示する。

第二節では `r34d` の同じ本人・賦課・批判を条件にする。批判の時点にも同じ納付要求が適用されることを要求し、実際の拒否や納付済みを前件にしない。`r34q` / `r34s` / `r34v` が、同じ規範源と同じ納付要求の義務規則 `h245e` を `r34o` の処罰可能性へ渡す。処罰の実行可能性や現実の実行は追加せず、制度上の施行者・立場・措置についての規範的な可能性として読む。

`als ein Skandal` は同じ批判を、公然と示される義務規則の軽視の例として評価したことを措置の根拠へ結ぶ。評価の内容と、それを根拠として扱うことは別であり、措置から評価の真理を逆算しない。規則は同じ賦課・共同体・出所・本人・立場・納付行為・受取先・媒体・基準に結び、無関係な義務違反を借りない。この語義の補助資料はカントの1797年の説明であり、1784年の唯一の意味を証明したものではない。

括弧の `das ... könnte` は、同じ批判の一般的反抗の誘発可能性を、その評価の性質に関する補足として保持する。`r34r` / `r34t` / `r34w` は処罰節と同じ条件・全範囲を用いる。現実の反抗を処罰許可の必要条件へ移さず、因果的可能性から処罰許可を導く一般規則も置かない。`h234k` が括弧の挿入、`h245l` が評価に関する説明としての関係を記述する。

`sogar` は、拒否が禁じられるだけでなく、条件に該当する批判の処罰可能性まで述べる取り立てとして読む。`r34y` は後者を前者より期待されにくいとする定性的な比較を、反射性と厳密な向きから構成する。`h245k` はこの背景を焦点へ付随させ、世界内容の真理や数値確率へ変換しない。先行する将校の例と並べる関係と本文順序も `r34z` に含める。
