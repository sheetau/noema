# 一枝の後続を残す配置

一か所から出る枝が一本だけでも、枝の内部と主列の続きは接続位置を取り合う。従来は複数の枝が同じ語から出る場合だけ、経路の候補ごとに後続の接続可能性を調べていた。そのため、一枝ずつの入れ子では別の経路があっても配置失敗となり、枝を本文へ戻すことがあった。

既存の配置が成功すれば、その図形を使う。失敗し、まだ後続を保つ経路探索を試していなければ、同じイベント列に対してその探索を一度行う。複合語を続けて配置し、内側の枝を優先し、接続可能性を残す経路候補を選ぶ規則は、先行する複数枝の配置と共通である。それでも配置できない場合には従来の枝数削減へ進む。探索条件を無制限に変える処理や、復号結果によって図形を選び直す処理は加えない。

変更するのは配置の探索だけであり、字形、構文、引数順、束縛、語義、公開参照、図形の読取器は変えない。偏心内包の禁止を含む幾何制約もそのまま適用する。保存済みSVGと新しいSVGの双方を元構文へ復号し、円数が不変であること、既存の枝数を減らさないこと、最初の配置に成功した例ではSVG自体が変わらないことを確認する。

旧報告には、最初の配置に失敗した後で別の直列配置へ切り替えた事実が含まれないものがある。枝数の削減が空でも、最初の配置に成功したとは限らない。今回の報告は後続を保つ探索への切り替えを明示する。この記録は配置の診断用であり、読取器への入力には使わない。

枝が増えても横幅が短くなるとは限らない。比較画面では元と同じ倍率で全文を示す。これは配置の局所改善であり、本文全体、行・頁、未対応構文、外観の最終確認は残る。
