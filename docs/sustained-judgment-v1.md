# 知的活動と「確かな歩み」の対応

カントの「確かな歩み」に、知的活動の側からの解釈候補を接続した。同じ活動を構成する各判断で、自分の理解力を使い、その判断で使った理由に支持され、他者による指導がないことを要求する。身体的な歩行ができることは条件に加えない。

原文は[AA VIII 36、13–15行](https://korpora.org/kant/aa08/036.html)にある。ここで採用する「活動内で独立した理由ある判断を維持する」という読みは、実装上の明示的な解釈である。原文がこれらの条件を列挙したわけではない。確信の強さ、習熟、外乱への安定性などを含めた語義の確認は残る。

## 同じ判断に条件を結ぶ

一般構成 `rcr` は、人・判断・状況を固定する。その人が所有する理解力を、その同じ判断に使う。判断には対象となる事柄があり、実際に用いた理由の少なくとも一つが、その判断を支える。他の判断で使った理解力、別の理由への支持、過去の状況での支持では条件を満たさない。

原文側の `h5c` は、これを既存の理解力の所有・使用 `ab`・`ac`、判断・対象・理由・支持 `fa`・`fb`・`fc`・`fd`、指導 `ad` に接続する。新しく「安定した知性」という未説明の基本記号を置く方法は採らない。ただし、再利用した基本関係の基礎説明が完成したことにはならない。

指導の排除は、その同じ判断を他者が指導することに限定する。他人との会話、助言や情報を受け取ること、その人の別の活動が指導されることは、この条件だけでは禁止しない。理由の支持も、判断が絶対に正しいことや、全ての理由が正しいことを保証しない。

## 活動中の各判断を調べる

`rcs` は、同じ活動の全過程を、順序付き履歴の非空の区間として扱う。区間には完了点とそれより前の点があり、完了点より後の時点は含まない。完了点とそれより前の少なくとも一時点で、その人が活動の一部として判断していることを要求する。判断がない活動や、準備の後に一時点で判断しただけの活動を、継続する判断の活動とは認定しない。

区間内では、その人が同じ活動の一部として行う全判断に指定条件を課す。判断のない準備時点は許す。判断や理由の同一性を全時点で要求せず、途中で検討し直す活動も記述できる。一方、最後の判断だけが条件を満たしていても、途中の判断が満たしていなければ、この構成は成立しない。

`h5a` は知的活動の全過程、`h5b` はその活動を構成する判断の部分関係を指定する。これらは不適切な判断を省くための選択条件ではない。現実の活動を尽くすことは意味規約であり、有限の例だけでは保証できない。`h5d` は同じ人の履歴にこれらを結び、基準時までに完了した活動だけを扱う。`h5e` はその活動を持つ人の内容である。

## 比喩を引用間の対応として記述する

`h5g` は既存の `qh` を使い、知的活動 `h5e` を、身体的な歩行 `h4z` によって描くという著者への帰属を追加する。同じ人についての二つの異なる記述を対応させる。知的活動と身体活動の同一性、両内容の真理値の一致は要求しない。比喩の帰属だけを記述しても、その人が現実に歩いたことや、知的活動を行ったことは断言されない。

自立達成 `h4q` の過程と今回の活動との時間的な接続は、まだ定義していない。両方が過去に存在するだけでは、自立後の活動を表したことにはならない。`dennoch` の期待との対比、`Daher` の推論、少数者の人数条件への接続も残る。この版は既存13主張を保持し、解釈上の比喩帰属を1主張追加する。

## 検証と範囲

- 判断の7条件の128組と、本人・理解力・判断・理由・時点・指導を取り違える8例を検査する。
- 実際のNoema定義を展開した一階論理の検査で、判断の4法則と活動の3法則を検証する。理解力の使用だけ、理由の支持だけ、終点の良好な判断だけで十分とする3推論には反例を得る。
- 原文接続の23例で、準備時点、理由の更新、途中の判断・支持の欠落・指導、不正な範囲、別の活動・理解力、未来の完了を区別する。身体的な歩行と自立達成の基本関係は実行されたら失敗する設定で検査する。
- 比喩帰属の7例では、著者・談話箇所・二つの記述・文脈を区別し、引用内容を実行しないことを検査する。
