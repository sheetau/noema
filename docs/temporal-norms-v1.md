# 規範の内側と外側の時間量化

公的使用は `jederzeit` 自由でなければならないという原文について、時間量化の作用範囲を明示した。「各対象時点で、その時点の許可を要求する」と「一つの評価文脈で、対象期間を通じた許可を要求する」は異なる条件である。現在の許可や、始点・終点だけの許可で、全期間の条件を代用しない。

## 同じ期間を対象にする

期間枠を引数として固定する。`h7q` は、その期間枠を評価状況で解釈するときの一つの時間的経過、`h7r` はその経過のうち対象にする範囲を与える。先行関係には既存の `ic` を使う。

既存の `tb` で、経過が厳密な全順序を持ち、対象範囲が非空でその経過内にあり、選択した二点の間の点を欠かないことを調べる。既存の `tc` で、範囲の全点に条件を課す。新しい時間演算子は追加していない。

期間枠と、その評価状況での解釈は別の引数である。同じ評価状況の中では対象範囲を固定し、各点を検査するたびに都合のよい範囲へ選び直さない。別の評価状況に属する時間的経過を、同じ順序へ混ぜることもしない。

## 要求の二つの位置

`h7t` は、規範の出所・本人・立場・期間枠の四引数を取り、整合した対象範囲の全点で公的活動の許可状態 `h7d` が成立する内容を返す。引数列の長さは `h7s` で検査する。

`h7u` は、一つの評価文脈で `h7t` の成立を要求する条件である。時間量化は要求の対象内容の中にある。要求を述べるだけなので、期間や各点の許可状態を実行評価しない。対象が現在不成立でも、要求があることは表せる。

`h7v` は、固定した対象範囲の全点で `h7m` の要求が成立する条件である。時間量化は規範の外側にある。期間の整合性と各点の要求は評価するが、各点の実際の許可は評価しない。

この二条件には、外側の評価時点も含めた違いがある。全期間についての要求があるから各時点で同じ要求が成立する、あるいは各時点の要求があるから現在全期間についての要求がある、とは無条件に推論しない。原文の唯一の作用範囲を確定したとも主張しない。

`h7w` は、同じ期間について実際に `h7t` が成立する条件である。`h7x` は、全期間への要求があり、その同じ対象内容が現在の評価状況では満たされていないという条件である。要求・実際の許可・未履行を分ける。これは期限経過後の違反を判定する条件ではなく、将来部分の確定や期限の規約は別途必要である。

## 中間の欠落と範囲の縮小

始点と終点で許可されていても、中間で許可が失われれば `h7w` は成立しない。その中間点を対象範囲からだけ除いた場合も、`tb` により除外する。空の範囲や、履歴外の点を含む範囲、循環する先行関係も成立させない。

ただし、対象範囲自体を始点の一時点だけへ狭めれば、その短い範囲についての条件は成立し得る。この対照例も検査している。形式的に整合した期間であることは、原文が対象とする期間を尽くす証明ではない。履歴自体の完全性、時点の粒度、期間の始終をどう定めるかは別途根拠が必要である。生涯・永遠・過去だけといった期間を原文から補っていない。

空や不整合な期間では `h7t` は不成立になるが、それを要求する規範まで自動的に消去しない。期間の情報が未評価で判定できない場合とも区別する。要求自体を述べる `h7u` は対象期間を評価せず、要求の情報が未評価なら判定を拒否する。

## 検証と残る範囲

三つの対象時点の要求と全期間への要求の16組で、時間量化の位置を入れ替えられないことを検査した。期間や対象の取り違え等の8例も検査し、内側の許可を未評価のまま保持した。

三点の実際の許可の8組では、中間の不成立と未履行を確認した。要求の不在、空範囲、中間の欠落、履歴外の点、循環順序、範囲の縮小、別評価状況での範囲の変化という8例も区別した。対象範囲外の状況まで、一律に「常に」の対象には含めない。

今回は既存の時間・規範の定義を再利用した部分構成である。「しばしば」という頻度、制限の程度、啓蒙への影響と留保、権利の保障、公衆・役割の基礎的な意味、全文の意味一致は未完である。原文対応は既存範囲の具体化なので、対応文字数や意味一致確認済み区間数は増えていない。
