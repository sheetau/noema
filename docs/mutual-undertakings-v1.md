# 同じ条項を当事者ごとの引受けに結び付ける

カントu0013の相互の引受けを、同じ合意対象・条項記述・当事者への参照を保って構成した。複数人が異なる行為や時点で引き受ける場合を扱い、合意の形成と、その合意から要求・許可が生じるかという評価を分ける。契約の全要件を定義したものではなく、原文への部分的な解釈注記である。

| 定義 | 内容 |
| --- | --- |
| `rhx` | 本人の行為が生起し、その行為で同じ合意・条項・引数列を引き受ける旨を表明する |
| `rhy` | `rhx`が指定履歴に属し、基準文脈と同時かそれ以前に生じる |
| `rhz` | 基準文脈で選んだ二者以上の適格な当事者全員に、同じ合意の同じ条項への`rhy`がある |
| `rh2` | `rhz`の形成と、同じ合意から全要求・許可が生じないという`rhq`を合わせる |
| `hzcg` | 既存の人・行為の生起・行為者・時間順序の関係へ`rhz`を接続する |
| `hzch` | `hzcg`の形成と、同じ合意の要求・許可の不成立を同時に述べる |
| `hzci` | 形成があるなら、前版の無効性と仮定した承認への判断が成立する、という内容を作る |

条項は自然言語の文字列ではなく、順序付き引数列から命題内容を作る閉じたNoema記述である。同じ条項関数にも、当事者ごとに異なる引数列を渡せる。引数列の先頭は引き受ける本人と一致させ、残りは条項側の引数規約で解釈する。引数を増やした条項も扱えるが、表明側と割当側で異なる列を使うことは認めない。

当事者の範囲は基準文脈で固定する。過去の表明を探す際に過去の当事者へ選び直さない。各人の表明には、それぞれの行為と時点を存在量化するため、全員が同じ時に同じ行為をする必要はない。一方、生起・行為者・引受けの表明は同じ行為と時点に結び付ける。別々の記録から条件だけを拾って成立させない。

条項の同一性は記述の同一性で判断する。同じ真偽になる別名や、改訂後の条項へ引受けを自動移送しない。合意の識別子が異なる場合も区別する。表明された内容の実際の履行や真理を、引受けの認定から導くことはない。

`declares`は本人による引受けの表明を、`assigned`は合意と条項の版との対応を与える解釈パラメータである。これらを認定する慣習・認知・媒体の仕組みは、まだ構成し終えていない。受領、他者の発言の報告、宣誓、署名、自由な同意、強制や欺罔の不在、対価、能力、他の当事者による理解、解除・失効も今回の条件には含めていない。当事者範囲が現実の全当事者を尽くすことも、有限検査で保証しない。

検査では、二人の表明と条項割当の8通り、生起・行為者・表明の8通り、19の対照例を一般用文書と抽出文書で比較した。空集合・一人だけ・引き受けていない追加当事者、未来や履歴外の表明、循環した時間順序、改訂条項、別の合意、引数の入替えを区別する。ある行為が失敗しても別の適切な表明があれば成立する例も含む。未知の記録は偽として補わず評価を拒否する。

形成と規範の不成立を独立に変える4通りでは、形成した事実があっても規範的効力がない場合を表せることを検査した。ここで全要求・許可の不成立は検査用の解釈として明示している。全記述と全有限列を列挙した証明ではない。その量化の限界は[前版の検査](ratified-norms-v1.md)を引き継ぐ。`hzci`は条件内容であり、形成や承認が現実にあったことを断言しない。

[一般用文書](../examples/v014/mutual-undertakings.noema)は2,257文字、[原文付き草案](../examples/v014/kant-mutual-undertakings.noema)は114,323文字、[抽出文書](../examples/v014/mutual-undertakings-core.noema)は3,524文字である。7定義を追加し、新しい原始概念と著者主張は加えていない。親文書の宣言と15件の主張を保持した。[意味規約](../data/kant-mutual-undertakings-basis-v1.json)と[検査記録](../reports/mutual-undertakings-v1.json)に根拠と限界を保存した。

原文対応は「unter einander」と「zu verpflichten」の二範囲に限定する。誓い、変更しない信条、教会などの制度、永続的な後見の目的、その目的を持つ契約の選択、著者の主張への帰属は未接続である。一般の契約を無効だとする主張を追加したものではない。全文単位の意味確認済み件数は増えていない。
