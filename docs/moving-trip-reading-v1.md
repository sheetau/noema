# 光往復の想定・二式と時刻の著者注

u0036の三文、表示式u0037とu0039、それらを結ぶu0038のund、著者注u0280を原刊896/897頁と照合する。本文は三つのNoema主張を追加して264主張となる。想定の提示、原理を考慮した結果提示、脚注の説明を分け、注は原刊896頁のZur Zeitの直後へ結ぶ。

試行設定 `eito/eitn` は、各時計のそばの共動観測者、第一節の判定の適用、光と両端の同じ出発・反射・帰着を保持する。光の三出来事の位置を実際の端点の同時刻の座標へ結ぶ。第一節の判定を引用して適用しても、判定成功や静止系での時計の静止は導かない。

一定光速度による直線軌道と交点は、結果 `eitp` に置く。結果には現在の静止系測定 `eip6` と旧 `sdi/sdb` を接続し、同じ長さ・単位比・三つの指示値を用いる。往路は `(V−v)(t_B−t_A)=r_AB`、復路は `(V+v)(t_A′−t_B)=r_AB` であり、正の分母の下で原刊の商の式と同じ条件になる。`sdb` の連言でundも保持する。Aを後端、Bを前端とする向きはこの往復の式から採る読みで、以前の向きを固定しない棒の定義は変えない。

`eits` は先行の時計設定への追加想定と第一節への参照、`eitt` は同じ想定で現行の第二原理 `eiot` を考慮して結果を得るという提示である。原文の現在の結果提示を、必然性の主張・未来の予告・実測済みへ替えない。構成や検査は、光速度原理を実証したという意味ではない。

注の `eitq` は、当該二時計の任意の適格記録について、同じ値を現在位置の局所静止系時刻 `zah` と動く時計の表示 `zag` の両方へ結ぶ。`eiq2` の同じ出来事・場所・局所時計・自分の表示を再利用するため、数値だけが偶然等しい記録では足りない。`eitr` は引用呼称Zeitのこの使用を説明し、第一節からの静止系時間規約を保持する。zugleichは同じ局所出来事における二通りの読みであり、別々の時刻の順序ではない。

原刊897頁の次文はr_ABを静止系で測った動く棒の長さと説明するため、量の指示を確かめる文脈として読む。その後の観測者別の同期判断、一般的同時性への結論は今回の全単位判断に含めない。有限検査は値・記録・引用の接続を調べ、全実数の履歴や物理的法則の証明にはしない。全単位の意味判断は原文と定義を通読して別に登録する。
