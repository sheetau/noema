# 同じ軍隊の規律と本人による利用

第十段落第一文の `wohldisciplinirtes` と `zur Hand hat` を、通常の軍務で同じ指揮担当者の命令を全成員が安定して遂行でき、その人物が現在の編成を実際に使えるという読みで具体化した。前の依存群の人数・任務・武力行使準備能力に、同じ制度・軍隊・共同体・開始点で接続する。

命令の対象となる役職は、同じ制度に置かれ、本人が保持し、同じ軍事的任務に責任を持つ役職から導く。役職の範囲を新しい真偽入力で指定する方法は採らない。各構成員について命令記録が非空であり、記録上の全役職がこの範囲に属することを確認する。既存の要求網羅性と履行の定義が、同じ発令者・受け手・役職・行為・記述・極性を結ぶ。命令を記録から落とした場合も通らない。

利用できる計画が少なくとも一つあり、その全てについて、非空の全選択結果で全成員が命令内容を満たすことを既存 `rut` で要求する。これは通常の運用範囲での強い適合条件であり、訓練の履歴や服従の心理的理由、異常事態での無例外の成功まで含める読みではない。通常の計画と結果範囲は先に固定し、失敗する計画や人物を除かない。待機や差控えも命令内容になり得る。

「手元にある」は、本人が現在の編成・指揮・連絡・資源の下で、通常の用途に間に合う形で実行させられることと読む。部隊に抽象的な能力があることとは分ける。新たな軍隊を編成したり指揮担当を獲得したりする必要がある場合は、この利用可能性には含めない。固定距離・秒数、現在の出動や指揮権の合法性は補わない。この実際の利用可能性は文脈入力として明示し、輸送・連絡の個別機構まで分解したとはしない。

六定義 `r6fe–fj` と九つの入力を追加した。既存 `rvf/rty/rtx/rtw/rpm/rpl` と `rut/ruq` の構文・意味は保存した。要求網羅性の全行為記述への量化も保存し、有限検査では実際の束縛本体を二つの閉じた記述へ適用した診断用コピーだけを評価する。これは全記述域の証明ではなく、全域の直接評価は拒否する。

検査は二人・二計画・二記述の小さいモデルで命令内容と集団遂行を実評価する。軍隊の制度的位置・人数・武力行使準備能力の本体は直前の固定済み報告を参照し、同じ重い検査を繰り返さない。存在量化の接続は別に二値域で全位置を確認する。空の命令・計画・結果、名簿の欠員・重複、別の制度・発令者・受け手・役職、未記録の要求、二つ目の計画や結果の失敗を区別する。

公的平穏の因果保証はまだ接続していない。旧共同体保護が対象とする活動可能性・保有を公的平穏と同一視せず、同じ軍隊の利用内容と同じ共同体の `r572` を比較モデルへ結ぶ必要がある。第一文全体の意味判断も未完で、本文119主張、登録簿v203、19全単位判断と確認文字数は保持する。
