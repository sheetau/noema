# 真理値による数値選択と該当個体の計数

既存の真理値の数値化から、条件に応じて有理数値を選ぶ関数を構成した。[共通Nativeモジュール](../examples/v016/shared-selection-v1.noema)では、[割合の旧定義](proportions-v1.md)の `hd`・`he`・`hf` を、それぞれ `truthindicator`・`indicatorvalid`・`occurrencecount` として再利用する。名前の対応を除いて宣言本体を保持し、加算は既に公開した `rationaladd` へ対応させる。

新たに共有する語は、既存基本宣言1語と構成定義4語の計5語である。既存の加算・乗算、所属・重複検査も同じ宣言を共有し、新しい原始概念や文法演算子は追加していない。[公開規約](../data/shared-selection-basis-v1.json)に全引数の型・役割・意味を記録する。

## 値を選ぶ式と評価順序

`truthindicator` は真を1、偽を0とする。`indicatorvalid` は真偽の両方についてこの条件を検査する。真理値の型を持つだけでは任意の外部解釈がこの規約を満たすとは限らないため、誤った数値化も検査で区別する。

`selectnumber(condition, whenyes, whenno)` は、次の和で値を選ぶ。

```text
truthindicator(condition) × whenyes
  + truthindicator(not condition) × whenno
```

標準の指示関数と有理数算術の規約の下で、真の場合は `1×whenyes＋0×whenno`、偽の場合は `0×whenyes＋1×whenno` となる。負数や厳密な分数もそのまま選べる。型付きの関数内にこの式を書けば、対象との同一性や既知の性質に応じて、異なる数値を返せる。

これは遅延評価の条件式ではない。引数は選択前に評価するため、未選択側の値が未知の場合も、従来の処理系は評価を拒否する。0を掛ける側だからといって不明値を消したり、未知の性質を偽として数えたりはしない。

## 出現数と個体数

`occurrencecount` は、有限列の各出現について性質の真偽を0か1へ変え、その和を返す。同じ個体が二度現れれば二度数える。この旧定義の意味を、暗黙の重複除去へ変更していない。

`countselected` は、指示関数の規約を満たし、列全体に重複がなく、該当する出現数が指定数と等しいことを要求する。該当しない個体の重複も拒否する。空列の該当個体数は0だが、列が現実の母集団を尽くすことや標本として代表的であることは別の指定となる。

## 測定関数をNative本文で定義する

[統合例](../examples/v016/native-measurement-values-v1.noema)では、先行する水・米の二題材の `readings`・`volumedimension`・`massdimension` を、外部から渡す関数からNativeの構成定義へ置き換えた。水の250・500・750、米の400・600・1,000という六つの値を、対象との同一性による数値選択で返す。体積と質量の次元指数も、基底軸との同一性と数値選択から作る。

数値を返す関数と、測定の成立は分けたままである。数値関数は列挙した対象以外で0を返すという全域的な規約を持つが、それを未知対象の測定値として認めることはない。`amountat` や `amountsum` では測定関係とも照合し、未知の測定対象は従来どおり拒否する。値関数の定義だけで測定の根拠を作ったことにはしない。

この例では、個体の指示、単位登録、測定、部分・内容の関係は引き続き明示的な入力である。数値関数三つの外部実装を除いたことと、文書全体を円文字だけで読めることを区別する。次に5語を可視辞書へ接続し、多部分の値関数と関係を可視本文で構成する例を進める。

## 検証

数値選択72組、真偽に対する指示関数の16解釈、二個体から作る長さ0〜4の列と性質の124組を検査する。統合例は六つの個別値、二題材の個数・合計・換算、次元の一致を確認する。値関数や次元関数を壊した対照例では、容器数が保たれても該当する量の検査が不成立になる。有限の検査を任意の外部算術解釈の正しさの証明とはしない。
