# 含まれる対立と、対立があるという判断

カントu0012の、規定群に内的宗教と矛盾するものがないという条件と、本人がそのようなものを含むと判断するという仮定の内容を、別々に記述した。原文の意味を確定するには、内的宗教の内容、対立の基準、発見、良心と辞職の関係の説明が残る。

## 部分の対立と全体の整合性

`rgu`は、指定した対象に含まれる部分のうち、指定基準と対立するものがあることを表す。`rgv`はその否定である。どの部分が対象に含まれるかは基準文脈で固定し、評価する状況ごとに別の部分へ入れ替えない。対立の判断に使う関係は引数で明示する。

この構成と併せて、命題的な内容について、範囲を限定した充足可能性を定義した。

| 定義 | 条件 |
|---|---|
| `rgq` | 対象の全ての命題的部分が、指定状況で真になる。 |
| `rgr` | 指定範囲のどこかで`rgq`が成立する。 |
| `rgs` | 同じ一状況で、対象と基準の全ての部分が共に真になる。 |
| `rgt` | 対象と基準はそれぞれ充足可能だが、共同では充足できない。 |
| `rgz` | 一つの命題的部分と基準がそれぞれ充足可能だが、共同では充足できない。 |
| `rg2` | `rgz`を、`rgu`などに渡す対立関係の関数にする。 |

例えば、対象が「A」と「B」を含み、基準が「AとBが同時には成立しない」とする。AだけならBが偽の状況で基準と両立し、BだけならAが偽の状況で基準と両立する。それでも対象全体と基準を同時に満たす状況はない。したがって、個々の部分に対立がないという`rgv`から、全体の共同充足可能性`rgs`は導けない。

一方の対象だけで既に充足できない場合も、`rgt`とは区別する。空の範囲や自己矛盾する基準を、二対象間の対立の証拠にしないためである。`rgt`が偽でも、両立するとは限らない。既知の空の内容集合では`rgq`は真になるが、範囲が空なら`rgr`は偽になる。

これらは指定範囲内での命題的な解釈である。範囲を狭めると結論が変わりうる。全ての可能状況を網羅した論理的矛盾の判定や、宗教・規範の対立の一般的な定義ではない。カントへの接続では対立関係を明示的な引数として残し、`rg2`の解釈を強制しない。

## 何かが対立すると判断する場合と、同じ部分が対立すると判断する場合

本人・対象・基準・基準文脈に対応する判断候補を選び、既存の`rn`で評価する。

| 定義 | 非空の判断候補についての条件 |
|---|---|
| `rgw` | 各候補で、対象に対立する部分がある。 |
| `rgx` | 対象の同じ一部分が、全候補で対立する。 |
| `rgy` | 全候補で、対象に対立する部分がない。 |

第一候補では部分Aだけが対立し、第二候補では部分Bだけが対立するなら、`rgw`は真で`rgx`は偽となる。候補ごとに存在する証人と、候補をまたいで共通する証人を区別する。部分の所属自体は、どちらも基準文脈で固定する。

対立がある候補とない候補が混在する場合、`rgw`も`rgy`も偽になる。判断が確定しないことを、反対の判断が確定したことへ置き換えない。候補が空の場合、三つの条件は全て偽である。

本人が対立を認めることから、現実の対立は導かない。検査では、全候補で対立すると判断していても、現実には対立がない設定を含めた。対立関係による判断の評価には、命題の真理を直接評価する必要もない。関係や候補が未知の場合は、空や偽で補完しない。

## 職務上の提示への接続

`hzbx`は、前版の`hzbw`が表す職務上の提示・賛同の不足・含まれる真理の可能性に、同じ規定群には指定基準と対立する部分がないという条件を加える。対立の不在から、実際の発話やその許可を生成する規則ではない。本人が対立すると判断する`rgw`は、この実際の条件と独立に記述できる。

`glaubte er das letztere darin zu finden`との対応は、本人の判断内容を部分記述した範囲に限る。見つける行為、仮定節からの帰結、良心に適う職務遂行ができないこと、辞職すべきことは未接続である。内的宗教の同定、`auf alle Fälle`の範囲、`wenigstens`と`doch`の焦点も残る。

## 検査

内容集合64組、評価範囲16設定、恒偽の内容・恒真の内容・反対の命題など6対照例、範囲の参照先を変えた1例を検査した。判断については、候補・各部分の対立・現実の対立を変えた256設定と、本人・対象・基準・文脈・部分の所属を変えた10対照例を検査した。全文草案と独立抽出文書で結果が一致した。これらは明示した有限モデルでの検査である。
