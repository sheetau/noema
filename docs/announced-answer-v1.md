# 案内対象の号と、そこに収録された回答

脚注の既存草案は、案内が月刊誌の9月号を対象とし、案内内でメンデルスゾーンの回答を紹介するところまで記述していた。しかし、その回答が同じ9月号に掲載されることは要求していなかった。別の号の回答を案内が付随的に紹介しただけでも、従来の条件を満たせた。

今回は`hzkk`へ、既存の掲載関係`hzjw`を一つ加えた。対象は既存の回答`hzjn`、掲載先は既存の案内対象号`hzkf`、文脈は同じ脚注の`hzjl`である。新しい語・基本関係・宣言・本文の文は増やさない。紹介の条件`hzjt`と未受領の条件`hzju`は保存する。案内を読むことと回答を読むことは別であり、掲載から受領や賛同を導かない。

この接続は原文の孤立した語からは決まらず、当該号の内容案内を読んだという文脈的な解釈に基づく。原刊資料を照合した。[週報37号289頁](https://www.digitale-sammlungen.de/de/view/bsb10429071?page=299)に1784年9月13日の日付と刊行物名があり、[291〜293頁](https://www.digitale-sammlungen.de/de/view/bsb10429071?page=301)には月刊誌の1784年9月号の案内がある。案内はMoses Mendelssohnの啓蒙論を紹介し、続けて他の収録内容を述べる。案内対象の[月刊誌193頁](https://www.digitale-sammlungen.de/de/view/bsb10926843?page=217)には9月号の表示と啓蒙についての論説の開始、198頁には週報が引用する箇所がある。画像を保存し、目視した頁と参照を[照合記録](../data/announced-answer-evidence-v1.json)に固定した。

外部資料の情報をすべてカントの主張へ加えることはしない。週報の37号という番号、記事の頁数、人名の名、版元、紹介文の評価は参照同定の根拠であり、Noema本文へ補っていない。原刊が保存されていることも、カントの読書・未受領が史実だったことの証明にはならない。

検査では、掲載がない、週報だけに載る、別の回答、別の号、別の文脈、逆向きの掲載、案内自体を回答の代わりにする、という七つの反例を旧版が受理し新版が拒否することを確かめる。掲載が未知なら補完せず保留する。既存の読書・日付の24対照と、紹介・未受領・読書を同時に評価する五つのモデルも確認する。

脚注全体の意味確認は未完である。刊行物名の記述的な働きと週刊性、敬称、代名詞、反事実と思想の比較は引き続き点検する。署名と日付行は文・依存宣言・意味規約が変わらないことを確認して、後継版の登録簿へ結び直す。原文の部分草案の範囲と意味確認済み件数は増やさない。
