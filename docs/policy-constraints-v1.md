# 同じ政策が満たす必要条件

カント第17区間の候補草案へ、公的な理性使用の許可を扱いの必要条件として接続した。前段で指定した新政策・主体・共同体・基準時の対象者をそのまま使う。これは尊厳の全体を定義したものではなく、本文の意味一致も未確認である。

`ryp` は、非空の比較状況の全てで政策内容が成立するなら指定の条件も成立する、と述べる。逆向きの含意は要求しない。たとえば政策が三状況のうち一つで成立し、必要条件が二つで成立してもよい。政策に別の条件を加える余地がある。

`iaycontent` は既存の `iavtreatment` を使う。同じ対象者について、比較状況での基準への要求、評価時点の要求、その時点での公的理性使用の許可を求める。実際に公的活動を行ったことまでは要求しない。`iaymeaning` は対象者一覧と範囲の一致、比較状況の非空性を確認し、全評価状況における政策内容からの含意を課す。対象者が空なら、政策内容が常に偽でも受け入れない。

政策内容が常に偽なら、含意だけは成立し得る。`ryq` は政策の成立例を別に調べる。従来の自己利益判断で使う `rx6` も、同じ政策について実現側と非実現側の候補を要求する。今回の検査では `rx6` 自体を評価し、常に偽の政策が実現可能性の検査を通らないことを確認する。自己利益判断は非事実的なので、現在の現実で政策を履行したという結論は補わない。

新しい `iayschema` は親の `iaxschema` へ同じ引数を渡し、残りの条件に `iaymeaning` を追加する。本文末尾の帰属はこの新しい部分ひな形を引用する。旧定義と先行21主張は保存した。内容が同じ別の政策記述でも、規範や自己利益判断の対象を自動で同一視しない。

検査は、三状況での64通りの含意・成立例の組合せ、対象者・規範出所・職務・政策記述の取り違え、未確定の許可、空の範囲、帰属時に引用内容を実行しないことを含む。親ひな形への接続は引数を記録する代替関数で調べるため、従来の因果・自己利益モデル全体を再評価した検査とは区別する。本文点検v4は候補定義への参照経路を確認するが、その経路を意味一致の証明とは扱わない。

有限モデルの検査は一般の状況領域に対する証明ではない。規範の正当性、対象者の総称的な範囲、尊厳の他の内容と根拠は未完である。旧 `iaustanding` / `iautreatment` の可変基準一覧を接続したとは主張せず、今回は静的に展開した公的許可の基準を使う。八引数の部分ひな形と14項目の未達一覧を維持し、原文範囲や意味確認済み区間を加算しない。
