# 縦横質量の問い・力の例示・条件付き導出

原刊918頁末と919頁を読み合わせ、u0252、u0254–u0258を一群として接続する。u0252第二文とu0253の六等号は旧主張422を共有する。新しい主張423は質量の問い、424は同じ瞬間共動系の力とばね秤の例示、425は規約の採用を条件とする二質量の表示を担う。

先に問う二係数は、後続で指定する規約の下での値として読む。問いの提示には答えの存在や既知性を含めない。「通常の考え方に沿って」は当時の論述上の慣行への準拠であり、現在の標準的な質量定義への置換ではない。縦はKの運動軸x、横は直交するy,zの共通係数である。物理的な軸と速度(v,0,0)は同じek63に保つ。v=0では選択済みの三軸の係数が共にμとなる。

εX′, εY′, εZ′は、同じ電子がその瞬間に静止するkの電気的機械作用の三成分としてely/emaに結ぶ。ばね秤の文は、同じ力を校正された可逆弾性要素と目盛りで比較し得るというembの内容を、eir5による例示とeisa5による括弧内補足にする。三成分の試行は一つの装置・要素を共有するが、向きを変えて別々に測ってよい。測定実施済み、唯一の方法、三方向同時測定を加えない。「まず」は三行の書換え、力の指摘、測定例、質量導出という説明順へ反映する。

「この力」を端的に力と呼ぶ規約emsと、質量数値×加速度数値=力数値を保持するemrを、条件文encの前件emtに置く。数値法則は同じ物理設定の三成分へ展開し、あらゆる独立な三数値の積が等しいとはしない。emcが力をk、加速度をKへ結び、単位の尺度A T²=L、M A=Fを保つ。eisywの無修飾の呼称はkという物理的限定を消さない。先行六等号eluと採用規約emtを前提に、著者が結果を導くとzcで提示する。

係数同定には全六実数の成分関係sepiを使い、現実の一組の零加速度から任意の質量を選ばない。同じ実三成分もsephで保持する。結論emjは先行のμβ³・μβ²と、原刊のμ/(√(1−(v/V)²))³・μ/(1−(v/V)²)を併記する。平方根は非負の根、適用はV>0、0≤v<V、μ>0。横を別の力の定義に基づくμβへ修正しない。

検査は分母・次数・符号・三成分の取り違え、条件文の真理表、同じ48役割の接続、全44束縛位置と二つの候補の共有、引用の非実行を区別して調べる。束縛の二値診断前に引数ASTを公開役割から独立に構成した契約と比較する。平方根の検査は完全平方の有理数に限る境界解釈であり、一般の実数切断の解析定理を有限例で認定しない。物理的な履歴、校正、単位、可能測定と旧六等号の検査証拠は固定した既存報告を参照する。

u0259以降の別定義・理論比較、質量結果の物質点への拡張、運動エネルギーの導出は別の未完部分に残す。旧主張、意味規約、判断と証拠は変更しない。
