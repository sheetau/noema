# 第十節の運動エネルギー論証の円文字接続

u0261–u0264の四主張を、質量規約までの円文字文書へ接続する。原典919–920頁の112–114段落に沿って、仕事と運動エネルギーの等置、印刷された等号列、光速への極限、超光速の否定と物質的質量への適用を保持する。

同じ電子・軌道・場・単位・運動過程を、既存の型付き参照と本文に定義した役割によって照合する。新しい一般契約はprofile82/83を使い、固定アルファベットと共通375語を変更しない。参照の取得は存在・唯一性・各役割に共通する証人の証明ではなく、本文の結合された条件を置き換えない。

原文の中間積分には質量係数がない。その表現を保持し、補正式や単位質量の仮定を著者の主張へ加えない。無放射と簡略化した収支の設定、そこからの著者の推論、全実数域の数学的な証明を区別する。

原文への逆対応、型と参照の有限診断、実際の円文字からの復号を別に検証する。仕様やNative本文の作成だけでは正式な文書統合に数えない。
