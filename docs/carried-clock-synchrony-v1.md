# 棒端の動く時計と静止系における同期

対象は原刊896頁のu0035全321文字、257非空白本文文字とA/Bの二数式である。同じ棒の既出の両端xn/xoに呼称A/Bを結び、別々の時計zaj/zakを取り付ける。新しい呼称個体を作り、先行する端点本体の意味や識別表記を変えない。

時計の取り付けは、同じ棒端に伴う物理的接続zaaと、時計の位置を代表する基準点がその端点と同じ全区間の座標履歴を持つseへ結ぶ。時計の針や歯車の内部運動まで止める条件にはしない。偶然同じ座標を通っただけの物体を、取り付けた時計として扱わない。

時計は動いている。その各出来事での現在位置はzabで指定し、比較先はその同じ場所に静止する別の局所時計とする。既存scvの局所比較に、現行の時刻付与eingと両方の時計表示の局所的一致eisgmを加える。同じ数値を別周期で示したことや遠隔で光を受け取った時刻は、同じ出来事の表示の代わりにならない。端点と時計の出来事を同じ静止系時刻・三座標へsbで接続する。

「その時々にいる場所」は、一回の比較ではない。全照合記録に同じ条件を課し、さらに運動区間内の全実時刻について、その時刻の記録が少なくとも一つあることを要求する。位置や局所時計は記録ごとに変わってよい。少数の記録を一致させただけでは全時間の条件を満たさない。

動く時計と静止系の参照時計rcを直接qoで同期させると、動く時計自体へ静止の条件を誤って課す。ここではqoを比較先の静止時計と同じrcの間に適用する。動く時計は、各場所で与えられる静止系時刻と自分の表示が一致する条件を持つ。この時計が補正なしに自然にその表示を保つという法則や、補正の機構は原文に追加しない。

著者の「更に想像する」は、同じ棒の設定への追加の仮定である。「d. h.」は同期の言い方を局所時刻の一致によって説明する提示とし、「also」はその条件に基づいて同じ二時計を「synchron im ruhenden System」と呼ぶ理由付けとして保持する。物理的な設定は引用のまま保持し、本文の命名や説明を評価するときに測定を実行しない。引用された「Zeit des ruhenden Systems」は、第一節の規約eisjdと同じeing・ra・rbへの対応を保つ。

検査では、動く時計と局所時計の区別、端点・出来事・現在位置・表示・参照の一致、全区間の世界線への引数接続、記録の欠け、二時計の対応、説明と結論の向き、引用の非実行を確認する。有限モデルや時間領域の明示した置換による検査を、全実数時間の物理的実現や意味同値の証明とは扱わない。
