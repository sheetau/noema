# 二方法の長さの命名と、比較の主張・予告

アインシュタイン§2の `u0032`・`u0033` を、長さの命名、相対性原理に基づく等値の主張、二原理による決定の予告へ分けてNoemaに記述した。既存の棒・初期長・測定方法・二原理への参照を使う。原文のこの箇所が述べる論証の関係を保持する部分草案であり、物理的な導出を完成させたものではない。

## 値の比較と一意性

| 定義 | 条件 |
| --- | --- |
| `sbx` | 候補と基準が有効な値であり、候補が測定条件を満たし、同じ候補と基準が比較関係を満たす |
| `sby` | 指定候補が得られ、得られる全候補がそれと値として一致する |
| `sbz` | 存在する一意な値について、基準との比較が成立する |
| `sca` / `scb` | 実切断の両方向包含による一致／その否定 |

原文の「その長さ」を、存在する一意な値として読む解釈を明示した。これは定冠詞一般の意味理論ではない。候補が空であることを「全候補が等しい」という条件だけで通さず、異なる値が複数得られる場合も一意とは扱わない。同じ値を表す異なる関数表現は許す。

`scc` は方法aの長さと初期静止長との一致を、`scd` は方法bの長さと同じ初期長との不一致を述べる内容である。両方法にはそれぞれの測定設定を渡す。不一致は大小の向きを指定しないため、原文にまだない収縮率や公式を補わない。

## 呼び方を対象・基準系・単位へ分解する

方法aの量は「同じ棒の、移動側基準系に関する長さ」、方法bの量は「同じ運動する棒の、静止側基準系に関する長さ」という数量記述へ結び付けた。`scg`・`sch` は棒、基準系、長さ単位、値、文脈を保持し、後者は棒が静止系に対して動くことも要求する。

この接続は著者が提示する命名規約として記述する。原語の綴りを未知の意味の代わりに格納する方式ではない。ただし、長さという数量の一般的な構成説明はまだ基本関係 `za` の意味規約に留まる。命名の記述だけで、その規約に従う測定が現実に実行されたとも扱わない。

## 必要性の帰属と、後続の決定予告

方法aについては、相対性原理 `saw` に基づき等値の内容 `scc` が従わなければならない、と著者が述べる関係を記述した。必要性を著者の根拠付き主張として帰属している。有限検査器がその導出の妥当性を証明したという意味ではない。

方法bについては、値を問う質問 `scf`、予告された不一致の内容 `scd`、二原理 `saw`・`sbd`、後続議論への参照を同じ予告へ結び付ける。方法aも含めた先行の問い `sbv` と、これから値を定める方法bだけの問いを区別した。二原理の記述は両方を要求するが、列挙順は意味上の優先順位としない。

予告された議論は、実行済み・成功済みの導出ではない。著者が結論を述べた事実と、前提や結論が真であることも分ける。命名・主張・予告を解釈する検査では、引用された物理内容を実行しない。具体的な後続箇所と実際の導出への接続は残る。
