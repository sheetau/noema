# 共同体から任じられた役割と公的な責務

前回の[条件文の照合](delegation-sentence-v1.md)では、宗教上の援助を主要な務めとする役割だけでは、Seelsorgerに必要なGeistlicherの区別を保持できなかった。今回は、同じ共同体からの制度上の任用と、その共同体の公の宗教的奉仕を担う責務を、既存の援助役へ結ぶ。援助者が任用されていない場合を区別できるようにする。

## 採用する歴史的用法

Adelungの[Geistlich](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_2_0_955)第4義は、公の礼拝を担うために任じられた者という広い用法と、秘跡を扱える者・宗教行為のために叙任された者という狭い用法を分ける。[Geistlichkeit](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_2_0_956)の集合的な用法も、公の礼拝のために任じられた者を説明する。この二項目を[出典記録](../data/appointed-roles-evidence-v1.json)へ保存した。

本用例には広い用法を選ぶ。Seelsorgerが主要な務めとして宗教上の援助をするという先行の読みへ、公的な宗教上の責務を接続する。全教派・全時代の職制を共通の叙任儀礼で定義したり、カントの唯一の意図を証明したりはしない。国家の承認、教義の真理、本人の信仰、成功を条件に追加しない。

## 構成

| 項目 | 内容 |
| --- | --- |
| hzxf | 同じ人物・役割・共同体・状況における有効な制度上の任用 |
| hzxg | 役割に委ねられた共同体への公的責務。活動の二引数は担い手と共同体 |
| hzxh | 同じ共同体の公の宗教的奉仕・礼拝という行為内容。生起・参加は別条件 |
| rqxx | 役割の保持、援助機能、主要性、任用、公的責務を同じ役割と共同体へ結ぶ一般定義 |
| hzxi | 同じ宗教上の行為の生起dgと本人の参加dfとhzxhを結ぶ活動の内容 |
| rqxy | 任用を要求しない旧spを保存した定義 |
| sp | 継続的援助rqxmと、soへの主要な援助・hzxiの公的責務・制度上の任用を結ぶ改訂定義 |

rqxxは宗教やカント固有の参照を持たない。学校などの役割にも、活動記述と制度上の関係を引数として渡せる。個々の自然言語の語に反応する規則や分類器は追加しない。

hzxhは領域上の基本関係として公開する。公的な宗教行為の内容を、儀礼・教義・共同体の全要素へ分解した実装ではない。また、任用が有効か、ある責務が制度上委ねられているかという事実は解釈に与える必要がある。Noemaはそれらを他の条件と結んで記述する。定義の存在を、その事実を自然言語から自動判定する能力と扱わない。

同じ人物でも、任用された役割と援助をする役割が異なればspは成立しない。別共同体の任用と責務も合算しない。役割に活動の責務があることと、その時点で活動が起きることは独立である。責務の内容としてhzxiを引用しても、その引用だけでdg・df・hzxhを真として評価しない。

## 検証と残る作業

六つのテストは、二役割・五条件の1,024組合せ、原文の十四対照、条件文の32組合せ、活動の八組合せと六対照、任用と現在の活動の四組合せ、帰属十二対照を調べる。別人・別役割・別共同体・別状況の混同と、未知入力の補完を拒む。役割の一般形と活動は通常評価でも検査し、条件文の反復計算には純粋な計算結果の再利用を使う。現行定義を検査用の基本関係に置き換えない。

新規の基本関係は三つ、定義は三つ。意味を変える既存定義はspだけで、影響する本文は文4・42である。df・dgは定義参照のため宣言位置だけを前へ移す。既存43文の構文、他の意味規約、確認済み十一単位、第一原因文・支払い・便利さの意味は保持する。compact・full・固有文字の往復を確認する。

この変更で、前回の非任用者の反例は現行定義に受け入れられなくなる。ただし条件文全体の自然言語との意味一致をテストが自動証明したとは扱わない。修正後の通し読解へ戻り、第二段落・二作品全文の確認を続ける。原文対応範囲と全体確認済み1,001非空白文字は据え置く。登録簿v57へ移す十一の判断は、新しい本文と意味規約に結び直し、元の読解・判断を保存する。
