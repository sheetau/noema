# 光学問題の一般的方法（u0226）

原刊915頁の三文を本文主張406へ接続する。第一文は先行の方法による全問題の解決可能性、第二文は方法の中心となる操作、第三文はその操作による静止物体の問題列への還元を述べる。著者がこう主張したことと、物理的な一般命題が真であることは区別する。

## 範囲と読み

「動く物体の光学」は、動く物体が作用する光について量や性質を求める問題全体と読む。問題ごとの全条件と問いは実際のNoema質問g[a]に保持する。問題の主題を分類するeisvkは閉じた条件規則ekwmを受け取るが、その設定の現実成立、静止系の存在、解や方法の成功を要求しない。仮定の下で検討する問題も含め、鏡・平面波・二場だけを問う問題・成功済み問題へ範囲を限定しない。静止側の主題は同じ構成でekwnへ結ぶ。

「解決できる」は、同じ方法で正しい還元を行う案と、還元先の各問題に対する完全な解答列が存在し、元の正解を構成できるという可能性として読む。現在の実行、既知性、一意解、所要時間の上限は補わない。一般の手続き適格性eisvnは固定与件と下位問題の答えを使う構成を要求し、元の正解を先に格納した定数写像だけを方法とはしない。この関係の現実成立は原始入力であり、計算可能性の自動判定器を追加したものではない。

Reiheは少なくとも二項の順序付き有限列と読む。反復は許す。全ての項が静止物体の光学の問題で、同じ物体・光の過程・新系・物理文脈に対応する。各問いは別々の求める対象と条件を保持する。場の下位問題を列の任意位置へ置き、その記録から復号した二場を逆変換し、列全体の答えとともに後処理へ渡す。元問題の質問との一致は既存の還元の全称条件で要求する。

「本質的」は同じ方法の中心的で不可欠な操作という役割関係eisvoとして読む。操作本体ekwqは、同じ源と波の光、作用する物体、元の電場と磁場、同じ物体に相対静止する系、両方向の座標規約に結ぶ。最速・最短の評価は加えない。「これによって」は同じ操作を手段とする帰結の提示eisvrと、直前の特徴付けへの照応で表す。

ここで用いた方法は、先行の反射後の二系比較の提示ekti/eisuuへ結ぶ。過去の印刷された式の不一致を修正したり、その内容を真と認定したりする関係ではない。任意の加速・回転・変形体に一つの静止慣性系があることも証明しない。難しい問題を範囲から除かず、著者の全称主張を保持する。
