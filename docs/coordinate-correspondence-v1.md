# 同じ出来事の四座標と、方程式を求める課題

アインシュタイン§3の `u0046` を部分記述した。同じ出来事について静止系と運動系の四座標を対応させ、その対応を表す方程式系を求める課題として保存する。座標対応の主張と、未解決の課題の提示は別の文にした。

四座標の記録は、三つの位置成分と一つの時刻成分からなる。`sha` は四つの役割が異なり、全ての値が有効であることを要求する。`shc` は同じ出来事がある場所を、その系の物差しで定めた三座標と局所時計で定めた時刻へ結ぶ。前段の測定の存在・一意性の定義を再利用し、単位も位置と時刻で分ける。

三座標が同じ別地点を許すと、座標から場所を特定できない。そこで `shl` は、対象範囲の測定済み地点で同じ三座標を持つ場所が、その場所と同一であることを要求する。これは条件の明示であり、その成立を全空間について証明したものではない。一方、同じ場所・時刻に起こる別の出来事は許す。出来事の識別子、場所の同一性、座標値の一致を区別する。

一般定義 `sgu` は、同じ一つの出来事から両系の座標を取る。`sgv` は全対象出来事に両系の座標が存在し、それぞれ値として一意であることを要求する。`sgw` は、同じ値の入力座標に対応する出力座標が同じ値になることを要求する。入力や出力に別の記録名を付けても、この条件は変わらない。逆方向の変換の存在や一意性は、この段落へ補わない。

方程式系は、既存の有限列の構文で表す。列の各要素は、同じ二つの座標記録に対して式の左右の実数値を返す関数である。`sgx` は列が空でないこと、全式の左右が有効で同じ値になることを要求する。式の順序を変えたり同じ式を重複させたりしても、解の条件は変わらない。

`sgy` は対象範囲の全座標対について、方程式を満たすことと同じ出来事の座標として対応することを同値にする。一部の対応例に合うだけでは足りず、対応しない座標対を余分な解にする式も拒否する。`sgz` はこの条件を満たす方程式列を答えとする質問である。原文接続の `shk` は、著者が取り組む課題として引用される。答えの存在や発見済みを断定せず、後段の変換式をここで先に埋め込むこともしない。

新規9件を含む関連31テストが通過した。一般定義と原文接続でそれぞれ12例の対応を調べた。座標の欠落、同じ入力に異なる出力が付く場合、同じ値を別の記録名で表す場合、同じ座標を持つ別出来事を含む。測定への接続23例では、各成分の欠落・取り違え、単位や基準系の違い、同じ三座標を持つ別地点を検査した。

方程式の検査は一般定義と原文接続でそれぞれ11例である。有限な座標例に対する簡単な平行移動を使い、式の不足による余分な解、強すぎる式、無効な値、空の列を拒否する。具体的な候補が質問の答えに合うかも、同じ条件で検査する。これらの例から原文の相対論的な変換を導出したとは扱わない。帰属の検査7例では、引用内容を実行せず、主張・課題・著者・設定を取り違えないことを確認する。

測定条件と実数条件には検査用の関係や構成済み整数切断を与える。有限例に対する確認は、任意の実数四組や全空間についての証明ではない。現時点の接続範囲は前段で定めた時計配置点であり、時計のない地点への時刻の拡張、全空間の座標の完全性、線形性と具体的変換の導出、原刊照合は残る。

標準表記・圧縮表記・固有文字の往復、CLIのJSONと構文木の一致、SVGのXMLとしての妥当性、検証記録の再現と進捗集計の整合性を確認した。SVGの目視確認と全テストの再実行は含めていない。
