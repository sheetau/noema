# 有限集団の比率の直接計算と、二つの結果の結合検査

[有限比率の定義](../examples/v014/finite-ratios.noema)を追加し、[カント草案](../examples/v014/kant-finite-ratio.noema)のhqを更新した。前版では比率を全有理数にわたって存在量化していたため、有限実行器が評価を拒否していた。今回は有限集団の人数から唯一の比率を計算する。Noema一般の有理数量化を有限の候補リストへ置き換える処理ではない。

## 存在量化を取り除ける理由

母集団の人数をN、性質を満たす人数をCとすると、旧条件はNが正で、比率rが0以上1以下であり、N×r=Cであることを要求する。正しい有理数演算の下で、そのrはC/Nに一意に決まる。Cが0以上N以下なら、C/Nも0以上1以下となる。したがって、任意の文脈的基準について「この等式と基準を満たすrが存在する」と「C/Nが基準を満たす」は同値である。

正のNについての比率の一意性、比率の範囲、候補と計算値の一致という三つの多項式条件を、既存の有理数検査器で検証した。候補値が有理数として存在することは、有理数の非零数による除算の意味規約による。これだけで、任意の基本関係の誤った実装や原文全体の意味を検証したとはしない。

pbはC/Nの候補値を作り、pcは従来のhj、pdは従来のhkへその値を渡す。空集団、重複、対象の種類の不一致、指示関数の不正、人数との等式の不一致を拒否する条件は保持した。hqはさらに、文脈の母集団を過不足なく列挙するという既存hrの条件を要求する。

補助関数paは非零の分母では正確な商を返し、分母が0の場合だけ0を返す規約を持つ。これは先に全引数を評価する実行器でも空列の入力を検査できるようにするための全域化であり、空集団の割合を0と認める規則ではない。空集団はhjのN>0を満たさず、必ず拒否される。候補値pbだけを有効な割合として扱わない。

## 変わらない解釈の値を再利用する

二つの結果を通して評価すると、同じ人物の命題内容を何度も計算する負荷が大きかったため、有限実行器に`memoize_definitions=True`を追加した。既定値は無効であり、既存の評価方法は変わらない。

有効にする場合は、基本関係の結果が同じ入力に対して変化せず、呼出し回数や副作用に意味を持たせない解釈を呼出側が与える必要がある。再利用するのは、引数と結果が基本の型である定義だけである。関数・質問・列・式記述などを引数や結果に含む定義は、この再利用の対象から外す。基本関係自体を直接キャッシュする機能でもない。

キャッシュは一回の評価に閉じ、別の文書やモデルへ持ち越さない。命題内容の場合は全指定状況での真偽をまとめて保持する。型検査、計算予算、全有理数量化の拒否は維持する。呼出し回数に依存する実装を、このオプションで安全に実行できるとはしない。

## 実際の定義による二結果の検査

前版では対象参照の接続検査にkgの仮の真偽を用いた。今回の有限モデルはkg、移行、譲歩、持続、母集団、容易さ、役割の定義をそのまま評価し、仮の基本関係へ置き換えていない。

肯定モデルでは、第一の結果msと第二の結果okが共に成立した。同じモデルで後見の方法の負担だけを増やすと、msは成立したままokが不成立になった。旧文書は同じ入口で全有理数量化を拒否することも確認した。

これは明示した有限モデル内で、二つの結果の定義を接続して評価できるという検査である。因果説明の実在や原文との完全な同義性、現実の人々の生涯を証明していない。原因の意味、基礎概念、比喩、評価範囲、残る本文と原刊確認は引き続き未完であり、確認済み全文単位数はカント0/20・アインシュタイン0/282のままである。
