## 今回の構成

構文木を、主部・引数の順序・束縛・引用を保持した続きへ変換する。独立した単語タイルを並べず、各構文要素は一度だけ出現する。複数の引数に原子的な項があるとき、そのうち一項を実際の親の側枝へ接続する。残りは構文順に続ける。左右対称の二枝をひと組の定型にはしない。

大円以外の主部は三本のどの罫線からも始められる。円面積と中央からの上下距離の積を累積し、偏りが一定量を超える配置へ費用を課す。短い区間の偏りは許し、その後の円が反対側の重さを補う。各単語の中央面積を半分以上にする旧条件は廃止した。長い文で重心が中央へ近づくことを確認するが、あらゆる構文に対する収束の証明ではない。

円の大きさは構文の種類・項数・参照辞書に、内包・円周と中心の重なりは参照に、位置と出入りの方向は構文の深さ・前の円・累積した重さに依存する。接続線は隣接する円の位置から解き、円周を正面から捉える経路のみを採用する。配置候補の選択は決定的で、例文ごとの手描き座標や乱数は使わない。文字列の各文字を置換する処理もない。

参照の局所辞書は宣言順・量の登録順から作り、引数を交換した場合は形が変わり、参照名だけを改名しても形が変わらないことを検査する。語義を名前の綴りから推測しない。この試作でも辞書は必要で、字形だけから全参照と構文を一意に読めることは未証明である。原構文の保存と復元は付属JSON/SVGを使った検査であり、画像単独の復号とは区別する。

## 接続と中心

- 小円には可視線を中心まで入れない。線は円周で止まる。
- 利用者による訂正「中心に**2本以上**の線が繋がることを禁止」を採用。中心に許す線軸は一本だけで、中心分岐はない。途中で分割された同一直線は一本として数える。
- 大円は中央罫線に置き、一本の水平な直径線を通す。外部への45度接続は採用しない。検査器では旧条件の自由端45度線も保持する。
- 内包した小円は、外円の円周から内円の円周までの放射状の線でつなぐ。この終点は内円の円周であり、外円の内部に浮かぶ任意の終点ではない。試作04の検査器ではこの配置も拒否していたため、試作05に独立した検査を設けた。非放射状の接触は引き続き拒否する。
- 一円が接触・交差・内包する相手は最大一円。線だけの閉路、矢印、連続する直角曲がりも拒否する。

通常の接続は可視線とする。引用へ入る境界で両円の中心が同じ罫線にあるときだけ、中心同士を結ぶ直線を不可視接続として使う。空白を任意の余白として挿入しない。不可視線の幾何条件は水平・垂直・45度の直線であり、折れ線を許さない。小円の中心禁止は可視線の条件、不可視接続は利用者の指定どおり中心間の関係とする。

円周同士、円周と線、線同士、不可視接続の実際の接続成分を数え、各文が一つにつながることを確認する。同心円を「内側にあるだけで接続済み」と数えることはしない。長い文の折り返しは連続する原配置の表示上の切り分けで、円の間だけで行う。円の個数と可視線の総延長を保持し、意味上の新しい空白を作らない。
