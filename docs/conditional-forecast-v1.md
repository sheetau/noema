# 支払いの仮定内に置く引受けの見込み

支払能力を前提とする一文の後半を、同じ仮定の続きとして扱うようにした。従来の `t3` は、仮定範囲内で成立する条件文 `tr` と、範囲外の基準状況で成立する見込み `t2` を結んでいた。そのため、支払能力のない仮定しか採らなくても、他者が引き受ける見込みを別に要求していた。

[原刊482頁](https://www.digitale-sammlungen.de/de/view/bsb10926843?page=522)の保存画像と、[アカデミー版の電子本文](https://korpora.org/Kant/aa08/035.html)で、支払能力を述べる条件の後に、セミコロンを挟んで他者による引受けの予想が続くことを確認した。ここでは後半を、支払えるという仮定を受けた続きとして読む。句読点だけから作用範囲が一意に決まるという主張ではない。独立した予想として読む別案は、従来版に残る。

新しい一般定義 `rqxg` は、人物・前件・二つの後件・仮定範囲を受け取る。非空の仮定範囲の各状況で、同じ人物の前件が成り立つなら、同じ人物について二つの後件をともに要求する。既存の条件定義 `rc` と連言から構成し、新しい基本関係や文法は追加していない。支払い以外にも、同じ仮定内で複数の帰結を述べるために使える。

本文の `t3` は、前件に支払能力 `tp`、後件に本人の思考なしの達成 `tq` と引受けの見込み `t2` を渡す。見込みの基準も、その仮定状況となる。仮定が現在と異なる場合、現在を基準にした予想だけでは足りず、その仮定を基準にした予想を要求する。支払能力・思考の不要・予想・引受けの中身は従来の定義を保持する。

条件文が成立しても、支払える仮定が存在すること、現実に支払ったこと、他者がすでに引き受けたことは導かれない。支払えない場合には、自分で考えなければならないという逆向きの条件も加えない。原文が引受けを仕事の完了と同一視するという追加もない。

一般定義は、二状況の選び方と三内容の真偽を変えた256例で検査した。本文の19対照では、実際の支払い・能力・努力なしの達成・予想・引受けの定義を実行し、旧版と比較した。定義を検査用の基本関係に置換していない。支払えず予想もない場合と、仮定の状況が現在と異なる場合、誤って現在へ予想を結ぶ場合に違いが現れる。

実際の定義の三例で通常評価と純粋な計算結果の再利用が一致すること、六種の不明入力を既知の意味へ補完しないことも確認した。帰属の六対照では、本文が著者による仮定例であることを検査し、支払い・思考・予想の事実は不明のままにした。完全記法・短縮記法・独自文字の往復を検査する。

意味が変わるのは現行本文の文5だけで、42文の構文は保持する。確認済み十一単位と、前回確認した第一文の推移的な依存先には変更がない。登録簿v45は十一単位の判断を新しい本文へ結び直すが、確認済みの単位数や分量は増やさない。第一文の読解記録そのものは、元の固定版を参照したまま保持する。

思考・支払い・仕事の語義、`nur`・`schon` の談話上の作用、代行の名詞、第二段落全体の意味確認は残る。今回の修正を、一文全体の意味一致や二作品の完成とはしない。
