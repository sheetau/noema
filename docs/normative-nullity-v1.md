# 契約を根拠とする規範的効力の否定

第六段落の次文 `[444,712)` に向け、無効性と仮定上の承認への条件を構成する。前版の `rhq` は要求・許可の不成立に範囲を限定していた。今回の `r475` は、権能・免責なども含む規範的帰結の全対象について、同じ契約がその帰結の正当な根拠にならないことを述べる。

帰結の項目ごとに、閉じたNoema内容を `h256k` で指定する。その内容には名宛人・立場・対象や肯否などを保持する。`h256l` は、指定した評価規範の下で同じ出所がその内容を正当化する根拠として働く関係である。単独で十分な根拠になる場合だけでなく、承認などと組み合わさって効力を支える場合も含む。`r475` はこの関係を全対象について否定する。帰結の真理や対象行為の実行は評価しない。

全対象範囲 `h256j` を、既に有効とされた帰結や既知の一覧だけに限定してはならない。範囲の完全さと根拠の正当性は解釈入力の責任として明記する。有限モデルで三つの帰結を区別したことは、現実の全帰結を列挙し終えた証明ではない。項目の内容を閉じた段階3の記述へ結ぶ構成も、言語の全記述段階の万能性を証明するものではない。

`r476` は、基準で固定した候補状況において、指定主体の全員の承認があっても同じ無効性が保たれる条件を加える。承認主体を契約という規範の出所へ置換しない。承認主体は非空でなければ承認済みと扱わず、承認の実在や承認候補の存在は要求しない。外部の独立した根拠による救済・制裁や、現実の強制まで否定しない。

[AdelungのNichtig項](https://lexika.digitale-sammlungen.de/adelung//lemma/bsb00009133_2_0_887)を補助根拠に、`null und nichtig` を無効性を強める一まとまりとして読む。二種類の独立した欠如や、契約の物理的な不存在とはしない。[原文AA VIII 039](https://korpora.org/Kant/aa08/039.html)の承認への譲歩と後続世代に関する文脈も、現行権力の承認と正当性を分ける読みを支える。ただし、当時の語義から現代の無効法理全体を導くものではない。保存資料は[根拠記録](../data/normative-nullity-evidence-v1.json)に固定する。

今回の検査では、要求・許可・それ以外の帰結を独立に変え、異なる出所・評価規範・評価点・内容への入替えを区別する。三状況の根拠と二主体の承認128通りを、独立した条件計算と照合する。引用内容が未知でも根拠の帰属を検査でき、根拠の関係自体が未知なら拒否する。

同種の合意への参照、全人類の今後の啓蒙を永久に妨げる目的、仮定的な形成、承認する制度と最上級、無留保の提示と譲歩、著者帰属は次に接続する。本文98主張と確認済み380文字は保持し、この依存群だけで新たな全文判断は加えない。
