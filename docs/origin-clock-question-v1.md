# 原点の時計の設定と進み方の問い

u0118は、同じ時計を考察に加える設定と、その進み方を問う二文である。原刊903頁末から904頁へ続く。Kで静止した場合にtを、kで静止した場合にτを指示できるという能力は、それぞれ許容される代替状況として表す。現在はその時計をkの原点に置き、τを正確に示すよう校正する。

静止するのは時計の代表位置であり、針や内部機構の全物質点ではない。指定系と状況を持つ完全な代表軌跡を再利用する。旧zacの記録は動く時計を静止系の局所時計と比較する用途なので、一般的な代替設定の局所表示へは流用しない。同所表示・現在所在・場所付き四記録を組み合わせ、各自系時刻に表示が存在し、全ての候補で同じ時刻値が指示されることを要求する。

校正された指示は座標時刻と同じ尺度・原点を持つ。単に二つの表示の差が比例するだけでは、τを指示することにはならない。同じ表示出来事に別の誤った読みがある場合も排除する。各記録の三位置は時計の代表軌跡に結び、別の場所や出来事の四値を集めて代用しない。

実際の原点配置は、測定原点という場所、時計の所在、零の三座標、全時刻の代表位置を結ぶ。Kとkの時刻を同じ値にせず、能力を述べた二つの代替状況を現在の同時成立にもしない。

第二文の問いは、Kの観測時間差に対する同じ時計の実際の指示差の、正の一定な割合を答え候補とする。全K時刻の両系の照合と、異なる時刻の非空な記録組、その全ての時間順の組を使う。これは今回の等速運動と理想時計についての読みであり、一般の変動する進み方をこの一つの率に縮めるものではない。問いを作る際には平方根の答えを入れず、答えの存在・一意性・発見済みも主張しない。

思考設定への追加、tとτの既出規則、同じ時計への問い、著者への帰属と文順をそれぞれ接続する。新しい基本記号は追加していない。全実数時刻・指示値の量化は保持し、有限の検査と原文全体の読解、実際の時計の物理的実現を区別する。
