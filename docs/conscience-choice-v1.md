# 各人の全良心事項における理性使用の自由

カント第八段落第一文末の `und Jedem frei ließ ... seiner eigenen Vernunft zu bedienen` に向け、自由にされる具体的内容を構成する。14定義r5y3–r5ziと4基本関係h26nw–h26nzを追加する。本文112主張・登録簿v196・意味判断17単位は保持する。

良心事項は、同じ本人の行為や選択を道徳的要求に照らして自己評価することに関わる事柄と読む。既存hzgqのfa/fb/seを用い、本人・事柄・判断・分類事例を結ぶ。分類に用いる候補状況は現実の履歴や本人の実行可能性と別であり、全候補範囲をh26nwで固定する。信仰に関わる事柄を含めうるが、現在自責している事柄や宗教だけには狭めない。DWBの[Gewissenssache](https://www.dwds.de/wb/dwb/gewissenssache)を補助資料とする。

自身の理性使用は、本人の理解力を使い、同じ事柄について理由を用いて、自分で判断する内容とする。既存rcrの引数による合成を再利用し、理由の支持を要求する引数だけを恒真関係へ替える。これにより、誤った推論を自由の対象から除くことを避ける。本人の能力、判断、対象、用いた理由は同じ行為へ保持する。その判断を今他人が指導していることは除くが、過去の学習や別の判断への指導は除かない。正しさや確実さは要求しない。

自由は同じ統治側からの実行・不実行の両方向の許容、両方向の指図の不在、その統治側が参加する権威的・強制的介入の不在として構成する。良心主体と上位の権威との外的な関係を、内面の自責の不在と分ける読みにはDWBの[Gewissensfreiheit](https://www.dwds.de/wb/dwb/gewissensfreiheit)を参照した。規範の沈黙だけ、許可だけ、実際に判断できることだけを自由としない。

本人・事柄ごとの全判断候補をh26nxで固定し、各候補のNoema実行記述を同じ三対象列へ結ぶ。介入には共同体と本人の自己判断の立場h26nyを加えた五対象列を渡す。候補の内容は別途Noemaで構成しており、自然言語の原文や未知の自由フラグを値にしない。h26nzは全候補の要求・許容・介入の評価が揃うことを示す。実行できる人、成功した判断、許可された候補だけへ範囲を選び直さない。

該当する良心事項がない人も対象集団から除かない。その人についての全称は空範囲でもよいが、該当事柄があるなら各事柄の判断候補は非空でなければならない。これにより、候補を一つも供給せず自由が成立したことにする誤りと、人の範囲を狭める誤りを分ける。
