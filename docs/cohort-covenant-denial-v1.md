# 後代を拘束する合意の否認

カント第六段落 u0013 [713,1004) の一文を統合する。対象は「ある時代の人々は、後代が認識を拡げ、誤りを正し、啓蒙を進めることが不可能になる状態へ置くために、相互に誓約してよい資格を持たない」という一般的な否認である。原刊488頁を再読し、[AA VIII 39の対応箇所](https://korpora.org/kant/aa08/039.html)と照合した。

中心命題 `r5dh` は、前後時代・集団・合意・状態の全候補について、同じ目的付き相互宣誓形成への正当な資格を否認する。形成・目的達成を候補の外側で要求しない。目的の中では、同じ合意の原因性、後続時代内の状態成立、状態の下での進展不能の必然性を分ける。不能性は、同じ集団の全方法・全結果・全継続に認識獲得、理由ある訂正、理由ある自己判断の進展のどれもないこととして保持する。

括弧内は、後代自身の認識事項が非常に切実であることを特に取り立てる補足と読む。`r5di` は同じ後続集団と認識対象の全範囲を保ち、`r5dj` は既存の高程度評価を結ぶ。`r5dk` は中心命題と同じ候補範囲の補足内容である。中心命題の範囲を重要性が確認できた項目だけへ狭めず、全員の心理的興奮、全事項の認識済み、数値的な最大性を追加しない。現代の[形容詞項目](https://www.duden.de/rechtschreibung/angelegentlich_Adjektiv)は補助にとどめ、十八世紀の用法を一意に証明するものとはしない。

`r5dl/r5dm/r5dn` は、認識獲得・訂正・啓蒙進展を、同じ六対象・前後点・経過へ結ぶ。`überhaupt` は前二者からより一般的な啓蒙へ論述を広げる提示として接続する。三つの同時成功や、知識の獲得から自己判断能力への論理的含意は要求しない。論理的な不能性と、列挙から総括へ進む提示の役割を区別する。

`verschwören` は先の相互宣誓を保持し、後代に不利益をもたらす企てへの結束として否定的に描くものと読む。[辞書は秘密の結束と古い誓約の用法を区別する](https://www.duden.de/rechtschreibung/verschwoeren)ため、一般公衆に隠して行うことを必須条件にはしない。内心の一致、刑法上の罪名、目的の成功も追加しない。

`r5do` は中心命題と補足を同じ著者・第六段落の提示文脈へ帰属する。括弧、焦点、総括、否定的な性格づけ、前文と各箇所の順序を結び、原文の語句を命名しただけで済ませない。引用した内容を実行せず、現実の契約形成や規範判断の真理を追加しない。

検査は、関心事であることと高程度評価の区別、認識範囲の非空性と同じ後代への接続、候補範囲を保つ補足、三種類の進展の引数、提示の閉じた記述と順序を確認する。依存部分の実評価と境界は既存報告と新報告に明記する。全文判断はこの検査から自動生成せず、原文の各節・代名詞・様相・提示の関係を再読して記録する。
