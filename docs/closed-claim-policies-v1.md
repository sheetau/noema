# 明示した基準を、通常の政策へ展開する

前段の基準履行は、動的に渡したNoema記述を評価するため、階数0の政策引数へそのまま渡せなかった。今回は、基準が閉じたNoemaの定義として列挙されている場合に限り、既知の記述と有限の畳み込みを展開し、通常の政策として引用できる接続を追加した。型検査や引用階数の規則は変更していない。

現行版用の[特殊化処理](../noema/constructed_specialization.py)は、従来の[旧版用処理](../noema/specialization.py)を保存した別モジュールである。元の宣言と主張を保持して新しい定義を追加し、最後に通常の型検査と階数0での引用検査を通す。自然言語を翻訳する規則や、モデルによる意味の補完ではない。

| 定義 | 内容 |
| --- | --- |
| `ryg` | 一つの基準について、同じ本人への要求と実際の履行を結ぶ |
| `ryh` | 明示した非空の基準記述列の全要素について`ryg`を要求する |
| `ryi` | 同じ対象者の非空で完全な一覧と比較状況について、要求の維持と現在の要求・履行を政策内容にする |
| `jvclosed`・`jvpolicy` | 作例の二基準を固定し、展開によって作られた通常のNoema定義 |

二基準の作例では、比較状況での要求を二回、現在の要求と履行を二回展開する。既知の引用の脱引用を二箇所除去し、四段の畳み込みを具体化した。得られる文書は通常のNoemaであり、実行時にPythonが基準の意味を決めるものではない。人が同じ定義を直接記述することもできる。

展開では、原始関係を実行しない。記述が未知なら推測せず、高い引用階数の脱引用を低い階数へ移すことも拒否する。列の順序と重複、記述そのものの同一性、変数の束縛を保持する。同じ内容になる別名へ要求を流用しない。空の基準列は展開できても、政策の非空条件により不成立になる。

特殊化の対象は、静的に確定した階数0の引用である。脱引用が残る未知の列は受け付けない。通常の演算や、脱引用を含まない呼出しは必要に応じて残す。展開量と深さには上限があり、上限を超えたときは結果を切り詰めず拒否する。

意味の比較は、全域的で純粋な、Noemaの値に従う解釈を対象にする。評価順序や呼出し回数、実行時間、副作用、未知値でどこから停止するかまで一致するという主張ではない。元の一般形を保持するため、展開前後の値を同じモデルで比較できる。

94テストが通過した。検査では、二基準の要求について現在・比較二状況の64通りと、現在の履行4通りを比較した。別人への要求、不正な対象範囲、空の比較範囲、別名の記述、重複・空の基準列も含む。変数の捕捉、列順序、未知の記述、高い引用階数、誤った型、展開上限を別に検査した。四文書の長形式・短縮形式・独自文字の往復とCLI解析、展開作例のSVGのXML構造も確認した。字形の目視確認は今回行っていない。

統合例では、この政策を前段と同じ新原則として渡した。基準への要求には、外側の原則採用と同じ規範関係`h7k`を使い、対象記述と引数列で区別する。旧来の政策真偽を返す作例用の関係を呼ばず、実際の基準内容から政策を評価する。自己利益の肯定判断と、現実の評価文脈では利益条件が不成立になる状態を保ったまま、集団の条件文全体が成立した。一基準への要求または履行を欠く場合は、判断と条件文は不成立になる。

ここでの基準内容は型と接続の検査用であり、尊厳の具体的な定義ではない。一般用の対象範囲は人に限定せず、必要な資格条件は呼出側が明示する。具体的な尊厳・人格・自律の説明、政府の資格、人間と機械の対比、原文との意味一致は残る。本文の新しい著者主張や原文の対応範囲は増やしていない。
