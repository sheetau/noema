# 同じ球面の零時刻断面の円文字表現

原刊903頁のu0112–u0113を、前の球面をKの座標x,y,zで時刻t=0に表す提示として接続する。既存12定義と文位置の参照を再利用し、共通375語、任意プロファイル58の802語、アルファベットを維持する。一般語彙と参照型は追加しない。

比較する両側を同じK零時刻の出来事へそろえる。その出来事のk記録には、k自身の対象期間を要求するが、τ=0は要求しない。たとえばV=5、v=3、R=5なら、Kでx=±4、t=0にある両端は、kでξ=±5、τ=∓3/5となる。両系の時刻値や期間の端を等置すると、同じ断面を比較できなくなる。

同じ物体・半径・出来事に対し、独立に定義された物質境界と表面式が、全ての適格な現在記録で双方向に一致することを保持する。境界記録の非空性も要求する。表面の正例だけに範囲を狭めず、有限点の一致を全連続体の証明とは扱わない。

K側の式はx²/(√(1−(v/V)²))²+y²+z²=R²である。分母の平方根の外にある二乗、横二成分、正の半径、同じ速度と光速の条件を保持する。球の設定、kの表面式、最終四座標変換を三つの前提として、著者による書換えの提示へ結ぶ。引用された内容の取得時に、式や物理的主張を実行しない。

本文位置は第54段落の第三文とする。原刊では最初の表示式に続く文に改段落の字下げがなく、座標・時刻の指定と次の表示式が一文を構成する。zh2はこの12トークン全体を指し、直前の球面式の範囲eisn6と区別する。末尾の句点はM0199のMathML内にある。

検査は、復号した定義本体による数値対照、二値の出来事・記録の範囲、各引数の結合、著者への帰属と引用の非実行を調べる。有限診断、円文字復号、採用した意味判断、独立した読解は区別する。回転楕円体という形状分類と三半軸は、後続のu0114–u0115で扱う。
