# 同じ文書の標識に付された著者注

カントの論説末尾では、本文の最後にある標識と、署名・日付行の下にある脚注冒頭の標識が対応する。原刊494頁を再確認し、この接続をNoemaで記述した。注の話題が直前の一文に限定されるとは読まない。今回記述するのは文書の構成上の接続であり、注が直前の主張の根拠や言い換えになるという論理関係ではない。

一般定義`rqsm`は、注と標識位置が同じ文書の異なる部分であること、同じ表示が両者を結ぶこと、その表示で注の著者が帰属されることを要求する。注や標識位置を文書全体と同一視しない。二つの新しい基本関係は、文書の部分としての所属`hzlx`と、文書内で注と標識位置を結ぶ表示`hzly`である。表示の成立と著者表示には既存の`dg`・`hzij`を使う。

原文用の`hzlz`は、既存の論説`hzik`・著者`wa`・脚注文脈`hzjl`を共有する。新しい三つの局所参照は注の箇所、本文末尾の標識位置、接続の表示を指す。標識の星印や紙面上の座標を意味の必須要素にせず、独自文字で表したときも同じ接続を保持する。標識位置を指すことは、最終段落の思想内容を記述し終えたことにはならない。

著者注という帰属は、固定資料の著者注区分と論説から続く一人称の読みを採用する。肉筆の真正性や印刷者を証明する主張は加えない。注の著者を別人にした例では、構成上の接続だけが成立しても、この著者注の記述は成立しない。

検査には21の原文接続例、一般形の五条件32組合せ、既存七文と合わせた九つの同時解釈を使う。別文書の標識、別の注、異なる表示や文脈への著者帰属を流用できない。未指定の所属・接続・著者表示は補わない。注が直前の内容を論理的に説明する場合としない場合の両方を許し、構成から説明関係を導かないことも確認する。

既存25文と全意味規約・識別表記を保存し、一文を追加する。原文対応には二つの標識の計4文字だけを加える。周辺本文や脚注の意味確認済み範囲は増やさない。注内部で各文がどの位置を占めるかという細分対応、他の注記慣行の分類、全文の構成記述は引き続き課題である。刊行物名、敬称の社会的含意、偶発性と思想の一致についても脚注全体の確認が残る。
