# 座標系の設定を、著者に帰属する指示として読む

Einstein正本の主張57を、[著者表示](einstein-name-presentation-v1.md)と同じ円文字文書へ接続する。対象は固定原文 `einstein-1905:u0008[0,95)` の第一文である。Newtonの力学方程式が成り立つ座標系を置き、その仮定のもとで議論を始める指示として、既存の読解を保つ。

## 依存群と参照

接続対象は17宣言（基本宣言12、定義5）。座標系という条件とNewton力学の適格性を組み合わせた `eifb`、その条件内容 `eiht`、対象の導入と仮定採用の内容 `eihu`、指示メッセージ `eihv`、著者への帰属と本文順序 `eihw` を一群として扱う。一文の内容を新しい基本語で置き換えない。

既存の著者表示から著者 `rd` と文書 `eirf` を再利用する。前付の提示文脈 `eirg` と本文の提示文脈 `ri` は、異なる参照定義を持つ。本文文脈は `documentcontext(eirf)`、見出し箇所は `headingreference(ri,2)`、文の箇所は `sentencereference(ri,4,1)` で指定する。見出しは文書全体の出現順で数え、本文段落には前付と見出しを数えない。対象の座標系は `discoursereferent(eirf,eisec,1,ri)` で、同じ箇所で導入する第一の対象に結び付ける。これらの数字は文中の位置であり、語義を引く番号ではない。

参照が与えられることと、その対象が条件を満たすことは別である。座標系の世界での唯一性や、実験による同定は加えない。第一節見出しの主題と、同じ段落の後続文は今回の移行範囲に含まれない。

## 意味と公開規約

任意プロファイル19は、共通基盤375語と既存の文書参照・名称表示8語に、参照機能3語と既存関係5語を加えた391語である。共通辞書と旧プロファイルは変更しない。新しい参照機能は本文文脈、見出し位置、文中で導入する対象を指定する。5関係は、旧正本の仮定採用・閉じた発話の提示・参照導入・物理座標系・Newton力学の適格性を、型と意味を保って公開する。数学などの専門定義を共通辞書へ昇格させる作業ではない。

既存 `speechpresented` は受け手を引数に取るメッセージ関数の記述と行為関係を用いる。今回の閉じたメッセージの著者帰属とは意味条件が一致しないため、同義と見なして代用しない。`textbefore` は既存の本文順序関係を再利用する。物理座標系の構成や測定は旧基本規約でも未説明であり、今回新しく導出したとは扱わない。

外側の主張は「著者がこの指示を提示する」ことを表す。引用された `eihv` を実行せず、現実に条件を満たす座標系があること、読者が指示に従うこと、著者が実験をしたことを導かない。内容を明示的に評価する診断では、対象導入・仮定採用・物理条件を別々に検査する。

## 検証範囲

`scripts.check_einstein_discourse_setting` は、元の17宣言と主張への復元、参照条件、旧関係の意味、円文字図形からの復号を検査する。復元は今回の文書と一致する場合に限定し、変更された定義を旧判断へ再登録しない。対応情報は検査の証拠であり、復号器は旧記号の対応表や旧本文を読解に使用しない。

二個体・二文脈で各参照位置を一つずつ変える束縛診断を行う。仮定の中の物理条件、設定操作、外側の帰属を別々に評価し、内側の全関係が偽でも帰属主張が成立する場合を確認する。これは全てのモデルに対する意味同値の証明ではない。原文の読解、型と構文、有限診断、図形復号は別の証拠として扱う。

成果物は `examples/v016/einstein-discourse-setting-v1.noema`、参照と意味の記録は `data/einstein-discourse-setting-bridge-v1.json`、検査報告は `reports/einstein-discourse-setting-v1.json`。同じ文書には著者表示の原文主張、識別表記の注記、今回の設定の原文主張がある。二論文全文の可視化と第三者読解は未完である。
