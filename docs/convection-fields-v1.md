# 電荷密度・対流の項と、同じ場の偏微分

アインシュタイン1905年論文§9の、電荷の流れを含む六つの方程式と密度の定義を部分記述した。電気側の場を`E=(X,Y,Z)`、磁気側を`H=(L,M,N)`とすると、変換前の式は次の関係になる。

\[
\partial_t E+\rho u=V\,\operatorname{curl}H,
\qquad \partial_t H=-V\,\operatorname{curl}E,
\qquad \rho=\operatorname{div}E=4\pi q.
\]

ここで`q`を電荷密度とし、原文の`ρ`はその`4π`倍の量として扱う。密度は符号付きであり、正と仮定しない。`ρu`も、この規格化に対応する流れの項である。

## 微分値を同じ場へ結ぶ

`semc`は、正の`V`について、一成分の時間変化率と`ρu`の和を、二つの空間微分値の差の`V`倍に結ぶ。`seme`は軸の循環順序と符号を保ち、三つの電気側の式と三つの磁気側の式を組み立てる。`semd`は、電気側の三つの空間対角微分の和を、同じ`ρ`へ結ぶ。

数表が式を満たすだけでは、場の微分方程式を記述したことにはならない。`semg`は、既存の偏微分の構成を使い、同じ二場・領域・四座標に、式に使う21個の偏微分を結びつける。内訳は回転と時間変化に使う18個と、電気側の発散に使う3個である。

磁気側の三つの空間対角微分は、この原文の式には使われない。今回の条件にはその微分の存在や、磁気側の発散が零であることを追加していない。`semh`は21個の偏微分、発散による密度、六式を同時に要求する。

`semj`は、指定領域が空でないことと、その全ての有効な四座標で`semh`を満たす微分表が存在することを表す。有限個の標本点への置き換えは行わない。現在の有限解釈器にこの全域条件を評価させると、必要な有理数域の列挙を拒否する。

## 原刊にもある磁気側の係数の違い

原刊916頁では、変換前のM0383の磁気側三式に`1/V`がある一方、変換後のM0389の三式にはない。電子テキストもこの原刊の形と一致していた。したがって、転記ミスとして原文を置き換える処理はしていない。

`semf`は変換後に印刷された形を保存する。磁気側では時間微分が回転の負値そのものに等しくなり、`V`倍する`seme`とは別の条件になる。点での微分との接続を`semi`、領域全体の条件を`semk`で表す。

`V=1`なら二つの形は一致する。しかし`V≠1`で回転が非零なら、同じ時間微分を両方へ代入することはできない。この相違は有理数の恒等式と反例で検査した。今回の実装は係数の異なる二形を区別した段階であり、座標・場の変換からM0389全体を導いた証明ではない。誤植の歴史的な由来も確定していない。

[原刊照合記録](../data/convection-fields-facsimile-v1.json)には、PDFと916頁画像のハッシュ、照合した数式、原文を変更していないことを保存した。以前に扱った鏡の振動数式M0376の相違とは別の記録である。

## 密度・速度と基準系の対応

`seml`は、既存の積分によるπの指定を使って`ρ=4πq`を表す。`semm`は同じ物質・基準系・出来事・文脈・地点へ、電気側と磁気側の場、密度場、電荷密度場、流速場、領域を結ぶ。物質への割当は明示した関係引数であり、値が等しいことから帰属を推定しない。

`semn`はこの割当の同じ地点で密度と流速を評価し、21個の偏微分と六式、`4π`による換算を接続する。`semo`は同じ接続を印刷形の式について行う。別の基準系・物質・出来事の値を混ぜない。

これらは単一の密度と流速を共有する対流の形である。複数の電荷種が異なる速度で流れるとき、各電流の和を合計密度と一つの速度の積で常に表せるとは限らない。そのような置換は追加していない。単位系、電気量の測定、物質への帰属、イオンや電子、剛体への不変な結合の説明は残る。

## 検査と未完の範囲

有理数の主張10件を検査し、7件の恒等関係を確認した。「零密度なら流速も零」「密度だけを反転しても式は同じ」「規格化した密度は電荷密度そのもの」という3件には反例を得た。

場の検査では、正・零・負の密度、流速の反転、`V=1`と`V=5`、二つの磁気側の形を組み合わせた24設定を使った。21個の使用する微分を一つずつ変えたときには接続が崩れ、使わない磁気側の三対角値だけを変えたときには条件を保つことを確認した。場・地点・領域・密度・流速・系・出来事などの参照先も変えて検査した。

有限検査の実数演算は有理数を登録した実切断で代用し、偏微分には明示的なアフィン関数の検査用解釈を使った。πの積分条件も検査用の関係へ置き換え、値3を合成データとして使っている。これはπの値を3と定義したものでも、全実関数の微分や実際の場の測定を証明したものでもない。
