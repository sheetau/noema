# 案内を読む行為と二つの刊行物の日付

カント脚注の冒頭を、既存の案内`hzjr`と著者`wa`に接続した。読む対象は案内、掲載媒体は9月13日付の週報の号、案内の対象は同じ9月の雑誌の号である。紹介された回答`hzjn`は引き続き別の参照であり、案内の読書から回答そのものの読書や受領を導かない。

一般定義`rqrp`は読書行為の成立、読者・文書・時点、同じ文書の同じ号への掲載を結ぶ。文書名、刊行系列、号を分け、名称の使用は別の提示行為に置く。読書行為そのものを名称を提示する行為として扱わない。原文の曲用された二名称は、それぞれの名称個体の識別表記に保存する。

日付は既存`rqrm`を再利用し、同じ暦・年・第9月の第13日と第30日を指定する。年1784は先行する日付行から引き継ぐ読みで、脚注が年を明記したとは扱わない。週報の号には13日の期間、雑誌の号には月の期間を結ぶ。号に表示された期間は実際の印刷・刊行・受領時刻とは異なる。

新しい読書時点`hzkl`と、未受領を評価する既存基準時`hzjm`を、どちらも同じ第30日の内に結ぶ。同じ日なら異なる時点でもよく、同一瞬間でもよい。日付行の表示文脈や名称使用の行為と時点を混同しない。

新規基本記号は読書・掲載・案内対象・号の表示期間・期間内の時点・系列所属の六関係と十局所参照である。週ごとの発行周期とビュッシングの人物・編集関係は、名称の綴りだけで説明できたとはしない。暦の歴史的同定、敬称と代名詞の解釈、反事実・試み・偶然を含む脚注全体の意味確認も残る。

検査は三条件8組合せ、読む対象・掲載号・案内対象・系列・年・月・日・時点の対照を含む。前版の紹介・未受領と新しい読書を同じモデルで評価し、案内を読む一方で回答は未受領という組合せが成立すること、過去の回答受領は未受領だけを取り消すことを確認する。有限モデルの結果を歴史的事実や単位全体の意味一致の証明として数えない。
