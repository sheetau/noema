# 啓蒙の達成経路と公的使用

回答文の[768,833)を、同じ人間の啓蒙に至る経路の可能性と、公的使用を欠く経路の排除として構成する。前節の自由という規範状態を、そのまま成功の原因へ置き換えない。後続の公的使用の説明も踏まえ、既存 `zzo` の活動を変化の過程へ結ぶ。[参照本文37頁](https://korpora.org/Kant/aa08/037.html)

`r2yj` は、先行する啓蒙の目標 `r2ln` と同じ公衆・期間・広がり基準について、一つの過程と開始終了点による達成証拠を取り出す。`r2yk` は、その同じ過程で人の能力変化を生じさせる活動部分が公的使用であることを求める。能力変化と結果生成には既存 `hzmx`、公的使用には `zzo` を使う。新しい意味上の基本関係は加えず、本文の箇所参照だけを追加した。

`der allein kann` は、公的使用を生産的部分に含む達成経路が少なくとも一つ可能で、比較する全ての達成経路がそのような部分を持つという読みを採る。公的使用のない独立した達成経路が一つでもあれば成立しない。同じ候補経過に複数の達成過程がある場合も調べる。別の公的発言が同時にあるだけでは、当該過程の生産的部分にならない。

これは公的使用だけで必ず成功するという十分性ではない。失敗する候補も許し、他の背景条件・補助行為・共同の原因も排除しない。可能性は結果で選別しない既存 `h222k` の比較範囲に相対的である。その範囲の適切さと網羅性を有限検査で証明したとはしない。

個々の過程の達成判定が先行目標と一致すること、公的活動と因果的部分が同じ過程・人・時点へ結ばれること、可能性と排除の量化を分けて検査する。局所モデルでは `hzmx` の能力変化の詳細と公衆分類 `r2la` を境界とし、その既存の検査・意味規約を固定する。境界を使った検査を全内部定義の再実行とは記録しない。
