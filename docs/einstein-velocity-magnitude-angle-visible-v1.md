# 第一近似・速さ・角度・合成式の円文字接続

第5節のu0135–u0140を、速度合成の導入に続く一群として接続する。対象は第一近似の帰結、二つの速さ、三量の定義導入、角度の説明、計算と合成式の提示である。現行稿で採用された7主張は登録位置が離れているため、190、191、0、1、2、3、4の順に選択する。原稿と既存の意味判断は保持する。

共通基盤375語と固定アルファベットを使う。任意プロファイル63では、既存の「理論構成の到達先」「主張項目の内容対応」「数量の意味・役割の提示」の3規約を公開し、閉じた役割による参照方式を真理値から実数切断への関数型に特殊化する。この参照は候補関数や役割を実行せず、未知の文書・箇所・役割・文脈を拒否する。数学的な内容は既存61定義を合成して表す。

原刊905頁のαの式はセミコロンで終わり、906頁の角度の説明へ続く。第64段落を、第一近似15トークン、三量導入と角度説明18トークン、計算と合成式6トークンの三文として扱う。Uとwは同じM0252に含まれるが、二つの式の役割を区別して参照する。名称の順序はU、w、αとし、MathMLブロックの順序と混同しない。

第一近似は共通倍率を零へ近づける微分としての採用解釈を保持する。Uとwは非負の速さであり、符号付き成分、実際の座標関数、全期間、端点での片側微分を残す。向き付き角の代表範囲と象限補正は明示した解釈であり、原文に完全な枝指定があるとはしない。零速度のノルムと、零ベクトルに角度を与えない条件を区別する。

M0257では、電子転記の分母sinと原刊cosの差を既存訂正記録で扱う。分子のsinと元のMathMLは維持する。負の分母により印刷式の値が負となり、非負の速さUと一致しない既存の反例も残す。著者が式を帰結として提示することと、全入力で式が成立することは別である。「簡単な計算」の負担評価から健全な証明を導かない。

検証は、元の定義への逆対応、参照の型・作用域・未知入力拒否、識別用の有限モデル、円文字からの復号を分ける。積分・微分や関数型の量化を有限標本で証明したとは扱わない。実行状態と残作業の正本はプロジェクト台帳に置く。
