# 第四節見出しの円文字表現

原刊903頁のu0109を、得られた四座標変換の物理的意味を、動く剛体と動く時計について検討する主題へ接続する。旧6定義と採用済みの主題提示関係1つを使う。共通375語とアルファベットを維持し、任意プロファイル58を802語とする。新しい参照型は追加しない。

見出しの出現順は5、印刷された節番号は4、第一部内の階層深さは2である。第四節はu0109–u0128で、次の同階層見出しはu0129にある。見出しの位置と節そのものを分け、節を第一部直下の第四節という閉じた役割で参照する。参照取得は役割や主題を実行せず、後続の収縮や時計遅れを証明済みとは扱わない。

方程式は同じK/k記録の範囲と最終四式を保つ。動く剛体は、同じ物体についてkでの全物質点の剛性とKでの全履歴に基づく運動を結ぶ。各系の同時性と期間を等置しない。動く時計は時計本体の代表配置が移動することを表し、針だけが動く静置時計と区別する。時計内部の全物質点を凍結する条件は加えない。

運動の定義は全区間の履歴と、区間内の前後する二時刻に少なくとも一成分の位置差があることを保持する。途中で動いて元へ戻る場合も含む。検査では復号した定義の二つの証人を例化し、全履歴への引数接続、各軸、逆順・同時刻・区間外の対照を調べる。実数全域の有限評価は拒否する。主題に両方の対象が含まれること、見出しの階層と順序、引用の非実行を別に確認する。

球の設定と著者脚注u0281は後続の意味群で扱う。有限診断、円文字の復号、原文の意味判断、独立した読解はそれぞれ区別する。
