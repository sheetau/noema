# 文語0.12：答えの型を持つ質問

0.12では「どの対象か」「どの対象と数値の組か」を尋ねる質問を値として構成できる。版指定は`l:`または`noema l l`。従来の真偽を尋ねる質問に加え、答えの型と成立条件を記述する。

この拡張を、カントの「どの制限が啓蒙を妨げるか」「どの制限が妨げず、むしろ促すか」という二つの問いに適用した。質問の構造を記述できた段階であり、原文全体の完成ではない。

## 型と構文

```text
g[型 …]                   順序付きの答えの型を持つ質問型
j v[真理値を返す関数]      その関数を答えの成立条件とする質問
h[質問][候補の式 …]        候補が成立条件を満たすか（真理値）
q[質問].                   質問する
```

例えば`g[a]`は対象を一つ答える質問、`g[a b]`は対象と有理数を順に答える質問である。後者の意味領域は、対象領域と有理数領域の直積の部分集合全体とする。一つの質問の意味は、その中の一つの集合、すなわち成立する答えの組の集合である。関数`h[a b] c`で成立条件を記述する。

```text
l:
r aa[a a] c.
d ba[] g[a a][j v[p aa]].
q[k ba[]].
```

この例は、関係aaを満たす二対象の組を尋ねる。aaが「第一の対象が第二の対象を追う」関係なら、追う側と追われる側の順番は保持される。質問の構成や参照だけでは質問を実行しない。`q[...]`が質問の発話であり、`s[...]`は真理値の主張のままである。質問を主張や関数へ暗黙変換しない。

JSONの型は`{"kind":"question","parameters":["individual","number"]}`。構成式は`{"kind":"question","function":式}`、候補判定は`{"kind":"answer_matches","question":式,"arguments":[式,...]}`。関数の結果型はtruthでなければならず、候補の個数と型は質問型に一致しなければならない。

質問は変項・量化・関数の引数と結果に使用できる。例えば`g[g[c]]`は、真理値を答える質問を、さらに答えとして求める質問型となる。型は有限の構造から再帰的に作り、無型の「全ての質問」を自己包含させない。型の深さには他の型と同じ128の実装上限がある。

## 存在・文脈・同一性

質問することは、答えがあるとも、一つだけだとも主張しない。存在・唯一性を求めるなら別の条件として記述する。答えの集合が空の場合と、要素が一つの場合と、複数の場合を区別する。引数0個の質問型`g[]`も許す。この場合、成立する空の組が一つある場合と、成立する組がない場合の二通りとなる。

質問の同一性は、同じ型の全候補について成立・不成立が一致することとする。同じ答えを持つ異なる説明方法や、質問者の意図は、この同一性だけでは区別しない。「なぜ」を説明の妥当性として扱う理論、答えの十分性、部分回答、推量や証拠の強さの体系を完成させたわけではない。

成立条件に必要な状況は、関数の引数や外側の変項として明示する。現在日時を自動で代入しない。複数の状況にわたる質問を表すなら、状況から質問への関数`h[d] g[a]`などを定義する。構成時に外側の変項を参照した場合は、その値を保持する。

既存の発話型fは、0.10以来の三つの働きと命題内容の組であり、その意味領域は拡大しない。新しい質問型をfに混ぜると、古い「全発話について」の量化の意味が版変換で変わってしまうためである。異なる型の質問や発話を一つの集合にまとめる共通型は、今回追加していない。

## カントの部分草案

[統合草案](../examples/v012/kant-questions.noema)は、0.11の冒頭・標語の定義を引き継ぎ、次を追加する。

| 記号 | 意味・役割 |
| --- | --- |
| ma | 指定文脈で自由への制限に当たる |
| mb | 指定された過程の性質について、文脈内で妨げる |
| mc | 指定された過程の性質について、文脈内で促す |
| md | 二つの問いを評価する明示的な文脈 |
| qa | maかつmbとなる対象を尋ねる |
| qb | maかつmbでなく、かつmcとなる対象を尋ねる |

本文の問いは次の形になる。

```text
q[k qa[p bi k md[]]].
q[k qb[p bi k md[]]].
```

biは以前に記述した離脱過程の性質への参照であり、「啓蒙」を新しい未接続の基本記号で置き換えていない。ただし、bi自体の能力・因果・離脱についての暫定的な意味を引き継ぐ。18基本記号と11定義の[意味規約](../data/kant-question-basis-v1.json)に未解決点を明記した。

四つの検査用解釈で、妨げる制限、中立的な制限、促す制限、妨げも促しもする制限を区別した。制限ではない要因は答えから除き、効果が全くない場合は空の答えを返す。文脈の変更と、先行する離脱の定義の成立条件の変更も結果へ反映した。同じ閉じた性質の計算は検査用解釈内で一度評価して再利用する。これらは明示した解釈の確認であり、現実の制度への自動判定ではない。

[原文対応表](../data/kant-question-alignment-v1.json)はu0012の二つの範囲を部分草案とし、選択外の範囲を未処理として保存する。wohl garの推量・強調、aber/sondernの談話関係、発話の著者への帰属と後続回答への接続は未記述。妨害・促進・自由の制限も、一般的な意味の定義は未完成である。確認済み全文単位数はカント0/20、アインシュタイン0/282のままである。

## 検査器と実行

有限解釈器は、候補領域を列挙できる場合に、成立する順序付きの組を`answers`として返す。候補の並び順は提供した領域に従うが、意味上は答えの集合であり、優先順位ではない。真偽を尋ねる旧構文の返却値は従来どおり`value`である。仮定内の質問は仮定の範囲に保持し、本文全体の断言に変えない。

有理数領域を列挙して全回答を得る処理は拒否する。ただし、[数値候補の例](../examples/v012/number-question.noema)のように、具体的な1/2や1が条件を満たすかは厳密な分数で検査できる。無限集合を有限の標本に置き換えた「全回答」は返さない。有限でも引数組・関数表の4,096上限と評価ステップ上限を引き継ぐ。上限超過は検査器の実行制限であり、答えがないことを意味しない。

```powershell
python -S -m scripts.compose_kant_v012
python -S -m scripts.check_written_v012 --verify-only
python -S -m noema parse --input examples/v012/kant-questions.noema --output artifacts/kant-questions-v012.json
python -S -m noema render --input examples/v012/kant-questions.noema --alphabet v2 --output artifacts/kant-questions-v012.svg
python -m pytest -q
```

[検査記録](../reports/written-v012.json)には、反例の結果、原文対応位置、通常記法・短縮記法・固有文字の往復、入力ハッシュを保存する。構文解析と表示に学習モデルは不要。0.8〜0.11の文書を意味を保って0.12へ変換でき、新しい質問を含む文書の旧版への変換は拒否する。

新規27件を含む全601テストが通過した。`python -S`での草案再構成、検査記録の再現、CLIのJSON・SVG出力も確認した。
