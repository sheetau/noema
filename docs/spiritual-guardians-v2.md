# 宗教的な事柄とその当人の引数順の訂正

最終文の全文統合に向けて意味規約を照合したところ、[後見役の依存群v1](spiritual-guardians-v1.md)の `r45e` が `sg` の引数を逆に渡していました。公開済みの `sg` は「事柄・人・状況」ですが、旧定義は「相手・事柄・基準」を渡していました。両引数とも個体型であり、旧検査も逆順のモデルを共有していたため、構文・型検査と有限例では検出できませんでした。

訂正した `r45q` では、同じ担当範囲 `h253r` の事柄を `sg` の第一引数、同じ被後見人を第二引数へ渡します。後見役の非空性と全該当例への未成熟要求は `r45r`、正確な三個体列からの方針内容は `r45s`、その評価は `r45t`、評価と持続への帰結の接続は `r45u` です。旧定義・意味規約・報告はハッシュを固定した履歴として保存し、後続の全文統合では訂正後の定義を使います。

新検査では、意味規約の引数名を確認した上で、人と事柄が異なる解釈を直接与えます。「相手の宗教的な事柄」だけが成立するモデルでは旧定義が偽・新定義が真になり、逆順だけが成立するモデルでは旧定義が真・新定義が偽になります。加えて、人民の範囲、同じ相手・役割・事柄、全後見役への要求、束縛列の過不足、評価・帰結での訂正済み方針の一致を検査します。全後見役への要求は通常評価します。方針アダプターの検査ではその既検査部分を境界に置き、三個体列の全組合せの内側で全後見役の量化を繰り返す費用を避けます。未成熟そのものは引用の内側に保ちます。

現在の本文95主張は誤った依存群をまだ使っていません。本文カタログの `sg` の全直接使用箇所も点検し、既存の `so` が判断対象の事柄を第一引数、判断する本人を第二引数に渡していることを確認しました。既存本文・意味判断を変更する訂正ではなく、最終文の統合前に依存群を修正するものです。

成果物は [訂正後のNoema依存群](../examples/v016/spiritual-guardians-v2.noema)、[意味規約](../data/spiritual-guardians-basis-v2.json)、[検査報告](../reports/spiritual-guardians-v2.json)です。新しい基本関係や原文解釈は加えていません。評価基準の具体化、全文の参照供給、`selbst wieder`、`Denn`、著者帰属は引き続き未統合であり、最終文146非空白文字の意味確認はまだ加算しません。
