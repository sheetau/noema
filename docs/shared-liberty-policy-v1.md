# 第三文の自由の精神：政府に相対的な共通方針

前回のr555は、先行する君主の下の自由を好ましく支持する態度を記述した。その例だけへの賛同では、特定国の外にも共有される自由の精神の内容として不足する。今回は同じ自由の型を政府組織に相対的な方針へ一般化し、異なる人が同じ内容を支持できるようにした。

政府は公的運営と管轄を持つr5zjの組織であり、公的行為を担う人はr5zkで分ける。宗教的自己選択の自由r56aは、政府による両方向の許可と非指図に加え、その政府の公的活動による介入の不在を要求する。君主個人が行動していないだけでは、官吏による公的介入を見逃すためである。

公的提示の自由r56e/r56gでは、全候補への許可の出所を同じ政府へ明示的に渡す。職務の義務の出所は政府だけに限定せず、聖職者の非免除・共充足と他者の全職務による無制約を保持する。見解と洞察、採用信条との差、審査目的、候補の非空性、任意の有限項目列は先行定義を再利用する。

r56iは固定基準の政府・最高統治職・共同体・全対象集団・宗教主題を適格範囲とする。自由な政府だけを選ばず、君主制や特定の君主の功績を条件にしない。r56jは全適格設定について同じ自由を述べる共通内容であり、r56kはその段階2の引用である。支持の態度r56m/r56nは、非空の適格範囲と同じ内容を保つ。支持時に引用内の政策を実行せず、外国でその政策が実現済みだとも、外国政府自体が支持しているとも述べない。

この読みは、自由の精神を宗教的自己選択と公的提示の一般方針への肯定的態度として扱う。全ての政治形態・活動に関する無制限な自由の定義ではない。本文の先行例への照応、社会的な取得・影響経路・広がり、外的障害、格闘の必要、政府の自己誤解と談話接続は残る。第三文全体の意味確認文字数は増やさない。

局所検査では政府と公的行為者、全候補と全人物、同じ規範出所、同じ内容の支持を区別する。深い先行内容の検査証拠を保存し、接続の検査境界を報告へ明記する。任意有限列の量化は有限評価を拒否し、少数の列による診断を全域証明にしない。本文114主張と既存の判断は保持する。
