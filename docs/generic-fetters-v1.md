# 二種類への一般化と、使用が続く場合の足枷

カント第三段落の第三文について、別々に記述していた対象分類、使用の作用、同格、言い直し、足枷の比喩を一つの候補へ接続した。現行本文の第53文（索引52）を更新し、他の53文と既存の意味規約は保持する。

原文は規定と定型表現を足枷として述べ、その直後にはそれを投げ捨てる仮定が続く。ここでは二種類への一般化として、通常の事例でそれらを吟味せず使い続ける場合に、同じ本人の未成熟への因果的作用が続くという読みを構成する。全員が実際に永久に脱出できないとの主張へ置き換えない。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)

この一文の候補ができたことと、原文との意味一致を確認し終えたことは分ける。以下の読みを明示して本文に採用するが、語義と持続の強さについての最終判断は残す。

## 継続点を履歴から作る

新しい一般形 `r2fr` は、各比較候補について次の条件を要求する。

1. その候補の履歴が基準点を含む。
2. 履歴内の先行関係が厳密な全順序を満たす。
3. 同じ履歴の基準点とそれより後の全点を継続範囲にする。
4. その全範囲で使用条件が続く候補では、結果も全範囲で続く。
5. 使用条件が全範囲で続く候補が少なくとも一つある。

順序と将来範囲には既存 `ta`・`rby`、条件付き継続には既存 `r2eu` を使う。過去の不成立は将来の不成立として数えず、基準点や後続点での結果の喪失は区別する。空の履歴、基準の欠落、循環・反射・推移性違反をそのまま通さない。

原文側の履歴入力は、その候補における本人の残りの生涯全体を含めるという意味規約を持つ。単に都合のよい観測期間へ限定した集合ではない。ただし、現実の履歴を漏れなく指定したかどうかは、形式上の順序検査だけでは証明できない。

終点のある履歴も許す。個人の無限の寿命、最後の点がないこと、数値時間の無上界性は要求しない。また、条件は残部全体での継続使用であり、途中で使用をやめた候補について、その停止前の全時点まで結果を保証する演算ではない。一度の使用の遅延効果も、この構成だけでは表さない。既存のより強い持続表現は保持する。

## 二種類を別々に一般化する

`r2fs` は、同じ対象・本人・基準について、規定または定型表現という分類と、上記の条件付き作用を結ぶ。吟味のない使用、能力の誤用、行為の生起、因果的関与、未成熟は既存の定義を使い、各条件の活動を取り違えない。

基準点はこの定義の明示的な引数にする。基準点一つでの作用を検査するたびに全基準点の内容を作り直す構成は、接続検査で計算量の上限に達したため改めた。比喩に渡す関係記述では、必要な位置で内容型へ包む。

`r2fu` は、比較事例を規定と定型表現の種類ごとに分け、各種類の通常事例で `r2fs` を要求する。既存の `r2fa` を導入して用いる。一方の種類に通常の成功例が多くても、他方の種類の不成立を消さない。両種類の重なりは許すが、どちらかの種類の比較範囲が空なら成立しない。

比較事例は仮定でもよいため、現在の利用者の実例を新たに主張する条件ではない。一般化を現況の多数や全称へ置き換えず、通常性の順位も結果の真偽から作らない。

## 同じ主語を受ける同格と比喩

主語句と `diese` で受ける同格句は、規定と定型表現の同じ種類記述 `r2fh` を指す。既存の性質記述の同格構成 `ryt` と、その指示・説明関係を再利用し、主語句から同格句への順序を保持する。個別の物の一覧や原語の綴りを指示対象の代用にしない。

比喩の対象側 `r2ft` と、身体側の足枷 `h2b` は、対象と本人という二つの位置を共有する。著者がこの関係を足枷として描くことを記述し、身体的な拘束が実在するとは断定しない。

`r2fv` は、一般化の主張帰属、比喩の帰属、同格、既存 `ho2` の合理的使用から誤用への言い直し、第二文から第三文・第三文から第四文への本文順序を合わせる。著者への帰属を記述するだけでは、引用された世界内容を実行しない。

既存の二定義と二つの談話関係を再利用し、六つの合成定義、八つの比較文脈入力、二つの原文箇所参照を追加した。新しい文法、生成モデル、語ごとの翻訳規則は追加していない。

## 検査と進捗の数え方

一般形では二候補の条件・結果・採否の256組合せと、履歴の欠落や不正な順序などを検査する。原文側では、二種類、同じ事例の対象・本人・基準、使用行為と原因・結果の結合を変える。分類と能力を境界で分離した検査に加え、既存の能力評価と因果的内容を実行する検査も行う。引用記述の全領域へ量化する分類は、既知例だけで代用せず有限評価を拒否する。

帰属は五条件の32組合せに加え、指示対象の変更、同一箇所への潰し、逆向きの本文順序、前後文の欠落、旧比喩対象への取り違えを検査する。未知入力は偽に補わない。短縮・展開・固有文字の往復、旧宣言と意味規約、十二全単位と先頭二文の判断も保存確認する。
