# 結論と、その結論を支える推論の道筋

前提から結論へ至る有限の推論列をNoemaで記述し、同じNoemaの定義で検査できるようにした。結論の内容だけでなく、何を前提とし、どの先行式を使って結論へ進んだかを対象にする。既存の「同じ人・対象についての判断で、支持する理由を用いる」定義 `ya` に接続した。

この追加は、カント草案に残る「洞察」の検討から必要になった。従来の情報増加の条件では、すでに判断している結論について理由を新たに得る場合を十分に区別できない。ただし、形式的な演繹を洞察一般の定義とはしない。カントの許可文を、証明できる判断だけに限定する改訂も行っていない。

## 書き分けるもの

例えば、内容記述 `P` と `Q` について、次の列を明示できる。

1. `P` を指定前提として採る。
2. `P ⇒ Q` を指定前提として採る。
3. 先行する二つの式から `Q` を導く。

この検査に `P` や `Q` の現実の真偽は必要ない。前提からの導出が正しいことと、前提が真であることは別である。前提が誤っていても、列の推論規則そのものは正しい場合がある。

結論を同じ式として以前から判断しているが、その理由はまだ用いていない状態も表せる。理由を用いるようになっても、結論の真偽や内容上の区別が必ず増えるとはしない。一方、理由がどこかに存在するだけで、その人が理解した、またはその判断で用いたとは扱わない。

## 型と規則

命題は状況ごとの真偽を持つ内容 `e`、その式の記述は `i[e]` である。推論列は段階を指す有限列 `j[a]`。各段階に、式の記述、規則番号、二つの参照式を指定する。これらは列全体で固定した関数として渡す。

| 定義 | 役割 |
| --- | --- |
| `rqq`、`rqr` | 二つの記述から、含意・連言の記述を構成する。 |
| `rqs` | それまでの式の列に、構文として同一の記述があるか調べる。 |
| `rqt` | 一段階が指定規則と先行式に適合するか調べる。 |
| `rqu` | 非空の全列が正当で、最後の式が指定結論であることを調べる。 |
| `rqv` | `rqu` に加え、最後の段階が前提の列挙だけでなく導出であることを要求する。 |
| `rqy` | `rqv` に加え、結論と同じ記述を前提行として使っていないことを要求する。 |
| `rqw` | 同じ理由・判断・文脈に推論列、前提、結論の記述を結ぶ。 |
| `rqx` | `ya` の理由による支持を `rqw` で具体化し、同じ本人・対象・判断での理由使用を要求する。 |

規則番号は、0が前提、1が含意除去、2が連言導入、3と4が連言の左・右の除去である。それ以外の数は規則として受け入れない。番号は語彙や自然言語の分類結果ではなく、この証明形式の規則を指定する値である。

含意除去では、参照式 `P` と、`rqq` で構成した `P ⇒ Q` の双方が先行部分に必要で、現在の式が同じ `Q` でなければならない。連言導入は両項を、連言除去はその連言を先行部分に要求する。将来現れる式や、当該段階自身を根拠にはできない。

途中の不正を後の正しい段階で取り消すこともできない。実装は、先行部分の妥当性と出現した式の列を、既存の関数と列の折り畳みで保持する。不正な段階の式も列には残るが、妥当性の値は偽のまま保持され、全列は拒否される。新しい文法演算子やPython側の証明判定器は追加していない。

## 支持する理由への接続

`rqw` は、その判断が対象にしている結論の記述と、推論列の最終式を照合する。同じ理由に属する前提を用いるため、別の判断の結論や、別の理由・時点に属する推論列の流用を区別できる。さらに `rqy` を使い、結論そのものを前提に戻す列は支持の対象から外す。

例えば `P` と `Q` を前提に `P ∧ Q` を作り、そこから `P` を取り出す列は、規則上は正しい。しかし `P` をすでに前提に使っているため、この列を `P` への独立した支持とは扱わない。利用可能な前提群に `P` が含まれるだけで、列の前提行として使っていなければ、この条件では排除しない。列の全ての前提行が検査対象であり、結論への最小の依存部分を自動抽出するものではない。同義な別記述や、前提の正当化に結論を頼る循環は別途検査が必要である。

`rqx` は既存 `ya` の支持関係へこの条件を渡す。したがって、本人が対象について判断したこと、その同じ判断で当該理由を用いたこと、理由の推論列が当該結論を導くことが必要になる。判断の実行や理由の使用は明示した関係であり、検査器が心理状態を推測するわけではない。

証拠の信頼性、前提採用の正当性、説明の有用性、本人の理解の深さは別の条件として残る。この五規則では、仮定の導入・解除、量化や帰納、経験的説明などもまだ扱わない。

## 検査の範囲と再現

53テストが通過した。正しい列、空列、順序の逆転、循環した参照、異なる結論、不正な先行段階、別記述へのすり替え、不明の前提採用、規則番号の不正、複数規則の連結を検査した。判断・対象・理由・文脈の取り違え、結論を前提に用いる場合と利用可能なだけの場合も区別した。

6種類の推論例について `P` と `Q` の真偽4組合せ、計24例を評価し、前提が真なら結論も真であることを確認した。構造検査では引用された命題を実行すると失敗する解釈を使い、真偽の検査とは分離した。これは検査した規則と実装についての証拠であり、任意の推論・洞察・原文全体の意味を保証する結果ではない。
