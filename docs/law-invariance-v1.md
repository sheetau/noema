# 座標記述を変えたときの法則の保存

同じ物理的な状態変化を二つの座標系で記述し、同じ法則への適合が保たれるという条件をNoemaに追加した。座標値や記述自体が等しいことは要求しない。原文の相対性原理を、許容される状態変化の保存として扱う部分草案である。

対応するのは[アインシュタイン原文§2](https://de.wikisource.org/wiki/Zur_Elektrodynamik_bewegter_K%C3%B6rper)の第一原理、`u0025` である。原文は、物理系の状態変化をどちらの座標系に関して記述するかによって法則は変わらないとし、二座標系が相対的に等速並進する条件を置く。今回の解釈は、その全意味を確定した完成訳ではない。法則の同一性、状態変化や座標の基礎、等速並進の構成説明、原刊画像との照合は残る。

## 候補履歴・記述・法則を分ける

| 定義 | 条件 |
| --- | --- |
| `sap` | 同じ候補履歴の両方の表現系に記述が存在し、全ての記述対で同じ法則への適合が一致する |
| `saq` | 非空の選択した候補履歴全てについて `sap` が成立する |
| `sar` | 非空の選択した法則全てについて `saq` が成立する |
| `sat` | 異なる二座標系で、軸の相対回転がなく原点の相対速度が一定である |
| `sau` | 候補履歴が物理系の状態変化に対応している |
| `sav` | 指定範囲が完全で、全候補が物理系に結び付き、二座標系の間で `sar` が成立する |
| `saw` | 対象となる座標系対が存在し、その全対で `sav` が成立するという原理の内容 |

候補履歴には、法則に適合しないものも含める。実際に観測した適合例だけを集めれば、異なる許容条件でも一致して見えるためである。ただし候補範囲の完全性は明示する前提であり、有限の観測から自動認定するものではない。

一つの履歴に複数の記述がある場合は、対応する全ての組合せで適合の真偽を比較する。一組だけ都合よく一致していても成立しない。また、異なる履歴の記述を持ってきて、欠けている対応を埋めることも認めない。選択した履歴の中に物理系へ結び付かないものがあれば、それだけを除外して合格にはしない。

法則は二つの記述に同じものを適用する。二座標系で別々の法則を選ぶ条件にはしていない。一方、この構成は外延的な許容条件の保存を記述するものであり、法則の説明力や原因機構、式の字面の同一性まで定義したわけではない。法則ごとの内容と、記述への適用規約は別に必要である。

等速並進は、相対回転がないことと相対速度が一定であることを分けている。共通原点や軸の一致は補わず、ゼロ相対速度も退化例として許す解釈を明記した。これらの関係を軌道・時間・座標の変化から構成する作業はまだ残る。ガリレイ変換やローレンツ変換を原理そのものの定義に固定していない。

## 定義の提示と内容の真理

新しい本文の主張は、著者が `saw` の記述を原理の定義として提示するという帰属である。内容を実行せずに、著者・本文箇所・原理の記述・推論範囲・文脈を結ぶ。これは、全ての物理法則の成立を処理系が認定する主張とは異なる。

前節の時刻・往復速度の文書の宣言と主張は保持した。ただし、二原理を後続議論の根拠とする `u0024` の談話、第二原理の光源の運動からの独立性、`u0022` の時間の命名は今回の対応には含まれない。

## 検証の範囲と計算量

一履歴に左右各二つの記述を用意し、その存在と法則適合の256組合せを検査した。記述の欠落、複数記述の不整合、両側とも不適合である場合を区別できる。

別に三つの等間隔時点で、位置の読みを `x(t) − v·t + offset` へ変える243例を検査した。連続する二つの位置差が等しいという条件は保存されるが、位置の読みが一定という「静止」の条件は保存されない例がある。これは明示した有限の代数例であり、相対論的な座標変換や現実の物理法則を導出した結果ではない。

原文接続では、座標系の条件7例、複数の法則・候補履歴・記述の結合16例、定義の帰属6例を検査した。原理全体の量化式は、7対象・一法則・一候補履歴の明示した有限モデルで4例を実行した。逆方向だけ範囲が欠ける場合、対象の座標系対がない場合、法則適合が一致しない場合を拒否する。

13対象を使った原理全体の検査は、1,500万ステップの上限に達した。現在の有限評価器は含意の前件が偽でも後件を評価するため、対象外の座標系対でも内側の量化に費用がかかる。全体の検査モデルを小さくし、複数法則・複数履歴の結合は別に検査した。原理や対象範囲の定義を狭めたわけではない。大きいモデルでの実行効率は課題として残る。

一般文書は基本述語0・定義3、原文接続文書は基本述語65・定義46・主張4である。新規9件を含む関連30テストが通過した。通常記法・短縮記法・固有文字の往復、CLIのJSONと解析構造の一致、SVGのXMLとしての妥当性、入力ハッシュと進捗集計の再生成一致も確認した。SVGの目視検査や全テストの再実行ではない。これは任意の物理系への相対性原理の証明でも、全文の意味一致の認定でもない。
