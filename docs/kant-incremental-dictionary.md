# 未登録の名前と宣言の逐次読取

## 先行計画

一つの宣言を対象の本体・型情報なしで復元できても、既登録の綴り表から名前を探している間は新しい辞書を読み始められない。既存の基礎語形、完全名の構成規則、型と本体の読取を再利用し、宣言名の未登録を解消する。

宣言頭の次に full_name を置いた場合、その後の基礎語形を types_end まで一つの完全名として読む。1要素は root、2〜24要素は compound とし、既存 Word/symbol と同じ単射な native 名へ戻す。語形の並びを既存の最長一致で切らない。明示区間内には引数枝や語境界の無線接続を付けず、隣接する中円の接触は同じ名の構成要素として従来どおり読める。

full_name は大円の右上円周上に小円の中心を置き、下方向の半径線を使う。偏心内包や幾何制約を緩めない。既存の登録名を使う宣言表記も保持する。

完全名を読んだだけでは型を登録しない。宣言の型列・本体まで読み、既に利用可能な依存語だけで native 型検査を通した後に登録する。未定義の参照、自己参照、前方参照、同名の再宣言を拒否する。本文が始まった後の宣言も拒否し、native 文書の宣言列・本文列という順序を保つ。本文の文種別は従来どおり型と図形から読み、別添の種別ラベルを使わない。

基礎となる公開共通辞書は明示的な前提として利用する。追加宣言の本体・型・綴り表を最初から読取側へ渡さない。完全綴りで追加した名前はそのまま後続の文で使え、省略綴りを途中で自動再計算しない。

## 今回の境界

ここで実装するのは、個々の項目の円・線を順番に受け取る読取器である。項目内の名前・型・本体・種別を図形から読むが、入力配列の項目境界と順序をページ画像から復元したとは扱わない。行・頁の境界、省略綴りの図形上の公開、辞書の語義説明は残る。小依存群の復号と、完成済み辞書を最初から渡した場合の検査を混同しない。
