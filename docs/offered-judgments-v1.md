# 判断と洞察を公衆の審査へ提示する

第八段落第二文の発表対象と目的を、既存の認識・公的使用・本人名義の発話から構成する。新しい基本記号は追加しない。本人が保持する判断と、その内容を把握し同じ判断への根拠を持つ洞察を分け、発表する内容と公衆が審査する内容を同じ代表項目へ固定する。

ここでの洞察は審査に提出される本人の根拠ある理解という読みである。公衆へ提示したから真であるとはせず、本人の把握と根拠、客観的真理、公的な確証を区別する。判断の保持と発表実行は後の許可対象の内側に置く。現に発表していないことを理由に自由の対象から除かない。

公衆は学識者が向ける全読者世界であり、実際の提示にはその中の少なくとも一人の人間を要求する。同じ本人・活動・立場・項目・基準を通じて、発話と審査目的を結ぶ。目的の実現、全員の読了や賛同は要求しない。複数項目を一つの行為に結べるが、別々の発表への許可から複合発表への許可を推論しない。

第二文全体の意味判断はまだ行わない。信条との差、君主への照応、聖職者への敬意、職務義務の保持、自由、他者へのなおさらの適用を同じ本文へ結ぶ作業が残る。第一文の判断と既存の本文は変更しない。
