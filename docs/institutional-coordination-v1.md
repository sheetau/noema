# 同じ仕事・目的を保つ制度的協調

カント第五段落の「ある仕事には仕組みが必要である」という文を記述するため、成員・仕事・政府・目的を共有する依存群を構成した。文全体の意味確認はまだ行っていない。現行本文と確認済み文字数は変えない。

`r2zn` は人である成員の非空の範囲を固定する。「一部」を、全成員を対象にする条件にも、必ず誰かを除外する条件にも変えない。所属を判断する基準と、目標状態を評価する点は分ける。

`r2zo` は同じ政府・本人・仕事・協調配置・目的内容について、目的へ方向付けられる場合と、その目的を破壊することを抑止される場合を包含的に結ぶ。両方でもよく、人によって成立側が違ってもよい。`r2zp` は固定した対象者全員にこの条件を要求する。方向付けのある人だけを成功後に集め直すことは許さない。

`r2zq` は同じ配置を人為的協調、機構による供給、各人への方向付けまたは抑止の関係へ渡す。無関係な配置の存在を、効果の手段として代用できない。供給や効果の関係は公開された引数であり、偶然の同時成立ではない。協調を全員の内心の信念一致とは解釈しない。

`r2zr` はこの目標状態を内容として組み立てる。内容の構成と、その真理の評価は別である。引用先で目的として扱っても、政府の指示が実際に通ったことや目的が達成されたことを含意させない。

`r2zs` は同じ人・役割・機構・仕事について役割の割当てと規範上の要求を結ぶ。要求先へ渡す引数列は本人、役割、仕事の順で固定する。要求の出所は機構と別に受け、本文にない命令者を先取りしない。要求関係には既存 `h7k` をそのまま渡せる。要求内容の実行や正当性は検査しない。

次に残るのは、公共の利益に関わる仕事、目的の公共性、機構の必要性、職務上の受動性の具体的内容、この構成を目的として引用する結合、最低限として示す `wenigstens`、前文からの接続である。`hzu` が要求する個人の意図を政府へ無断で適用しない。物理機械への分類もしない。

検査は成員の範囲、二つの結果の組合せ、参照の取り違え、要求と遂行の分離、未知入力の拒否を扱う。入力関係の歴史的な適切さや原文との同義性を自動証明するものではない。
