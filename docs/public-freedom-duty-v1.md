# 全適用時機の公的使用の自由を求める

回答文の公的使用の節[704,768)を、[本文](../examples/v016/kant-public-freedom-duty.noema)の主張72へ接続する。公的使用は、同じ段落の後続定義に沿った既存の `zzo` を使う。本人の理性を学識者として読者世界へ向ける活動であり、単に人前で行う活動ではない。[参照本文37頁](https://korpora.org/Kant/aa08/037.html)

`r2ye` は、一つの基準で固定した公衆・人・役割・全公的活動について、対象期間の全点で積極的な実行許可があり、反対の不実行要求がないという内容である。分類は基準に固定し、各点で変わるのは規範の状態だけとする。公的活動の実行は必要としない。

以前の `h7t` は各点で活動も分類していた。時点ごとに公的活動が空になる入力では、許可がなくても全称条件が成立する。新しい内容は既存 `hzna` の固定範囲を期間全体へ使う。旧定義とそれを検査した記録は保存し、今回の回答へ接続する対象を新たに構成する。

`muß jederzeit` は、全適用時機の自由を要求する読みを採る。期間の量化は要求内容の内側に置く。要求があることから現在の許可や発言の実行を導かず、各点で同じ要求が発せられるという別の命題にも替えない。規範の出所は著者、名宛人は許可方針を定める主体として明示するが、歴史上の統治者を名指さない。

全適用時機の枠 `h235q` は、啓蒙の達成を比較する既存 `h222g` の期間とは別に指定する。有限の検査期間を、そのまま「常に」の全範囲とはしない。期間の非空・一つの時間的経過・間の欠落は `tb`、全点の条件は `tc` で検査する。正しい全期間・公衆・活動範囲の供給は解釈上の責任であり、有限モデルで証明したとはしない。

`r2yf` は公衆・内側の規範源・期間枠の三引数を持つ方針内容で、既存の記述付き要求 `h7k` と長さ検査 `h7g` へ渡す。外側の規範源・名宛人・立場と、内側の公衆・規範源・期間の取り違えを検査する。著者への節の帰属は `hzon` を用い、帰属の評価時には要求や方針を実行しない。

これは回答文の部分構成である。`Ich antworte` の自己提示、公的使用だけが啓蒙を実現できるという内容、私的使用の制限の頻度・程度・進行への留保、回答文全体の対照と通読は残る。文単位の確認済み588文字は増やさない。[意味規約](../data/public-freedom-duty-basis-v1.json)、[対応と未解決点](../data/public-freedom-duty-reading-v1.json)、[検査報告](../reports/public-freedom-duty-v1.json)を保存する。
