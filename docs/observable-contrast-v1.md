# 観測される現象と通常の説明の対照

導入u0003[308,549)を、先の磁石・導体の例についての二つの対照的な内容として読む。前半は観測可能な現象の相対運動への依存、後半は通常の理解の下で二場合を厳密に区別するという説明上の制約である。観測結果が同じことと説明が同じことを混同しない。

ここでの現象は、後続の段落末尾が比較する、導体を流れる電流の大きさと経過を中心とする現象として読む。eisaeは同じ例・物体・系・単位・区間・全有向断面の記録を、その観測可能な電流現象へ帰属する。校正した測定によって電荷輸送とその作用を識別できる量として扱い、現に誰かが測定済みであることは要求しない。原文を全物理量や全空間の観測についての主張へ拡張しない。

hierの比較範囲はeisadで固定し、既存eirsの材料・回路・準備条件も共有する。eidaは両場合の磁石と導体、源の場と結合設定、全電流履歴の妥当性、観測可能な記録を結ぶ。結果の一致した標本だけを比較範囲に選ばず、相対履歴や電流の一致を前提の定義へ混入しない。

eidbは、妥当な比較で相対配置履歴eia2が同じなら、全断面電流履歴eibiも同じであるという条件である。eidcは全候補の記述へこの条件を課す。nurはこの範囲での機能的依存と読み、違う相対運動なら必ず違う電流になるという逆の含意は加えない。相対静止や、両物体が評価系で動いている比較も初めから除かない。既存eia3の「片方だけが動く二場合」へ依存の全範囲を縮めない。

相対履歴には既存eia2の同じ物質点・マクロな剛い左側参照配置・正方向・単位と経過時間対応を引き継ぐ。任意の回転・加速・変形まで同じ物理結果になるという定理を加えるものではない。また、同じ入力なら同じ結果という内容を記述するのであって、物理法則の経験的真理や因果的な介入実験を翻訳時に証明するものではない。

後半の区別は、その理解が許容する説明のすべてに課す規則として記述した。eisafは指定二場合の完全な説明の許容範囲、eisagは各説明が各場合へ割り当てる電磁的な生成・説明機構の分類である。eiddは許容説明の非空性と、各説明における両場合の分類の存在、両者に共通分類がないことを要求する。単に二つの名前が異なるだけ、ある一つの説明だけが違う、全て電磁現象という別の粗い観点では同じ、といった置換を避ける。

eideは、第一の場合が磁石の運動・導体の静止、第二の場合が磁石の静止・導体の運動という役割を持つとき、この区別規則を要求する。ここには相対履歴や電流の一致を前提として加えない。eidfはこの制約を全候補の二場合へ述べる。具体的な電場・起電力・エネルギーによる二説明は、後二文で別途記述する。

eidiは、その規則を記述した閉じたeidhを、論説の記述時点で通常とされる理解へ帰属する。著者本人の承認や現代の読者の理解へ置き換えず、帰属した内容をその場で実行しない。eidj/eidkは観測現象についての前半と、見解帰属としての後半を主張としてまとめる。eidlは同じ著者・論説・例を保って本文へ帰属し、既存zbcでwährendの順序付き対照を示す。

局所検査では、全引数が同じ比較へ接続すること、同じ相対履歴で異なる電流が条件を偽にすること、異なる相対履歴でも同じ電流を許すことを確認する。説明の検査では許容される追加の説明一つが区別を破る反例、空の説明範囲、共通分類を調べる。実数・関数の全候補の量化は有限評価を拒否し、全量化の構造と局所条件の検査を区別する。

固定一文について、ここでの現象、比較範囲、nur、二物体の同一性、二つの運動役割、通常の理解への帰属、厳密な区別、währendの対照と主張の提示を通読して確認した。これは明示した読みの下でのアシスタントの判断であり、自動的な同義証明ではない。第一文と後二文および導入段落全体は未完で、全単位判断数は増やさない。
