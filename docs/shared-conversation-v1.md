# 会話の採用記録と受諾・訂正・撤回

会話で誰がどの発話記述を採用しているかを、前後の状態として記述できるようにした。[共通本文](../examples/v016/shared-conversation-v1.noema)は新14定義、既存の提示・受諾5定義、既存の有理数加算1基本宣言からなる。[意味規約](../data/shared-conversation-basis-v1.json)に型、役割、社会的な解釈入力を固定する。

## 人物と記述の対応を保持する

状態は、人物の有限列と発話記述の有限列を同じ位置で対応させたものとする。たとえば人物列が[Aki, Nao]、記述列が[第一の発言, 第二の発言]なら、Akiが第一を、Naoが第二を採用した記録になる。列の長さが違う状態は拒否する。

状態の比較では人物・記述の組を集合として扱う。同じ組が二回並んでいても採用内容が増えたとはしない。二列を対応させて並べ替えた状態は同じだが、人物列だけを並べ替えれば記録の意味が変わる。実際の発言の回数や時間順は、状態とは別に履歴へ記述する。

| 定義 | 検査する条件 |
| --- | --- |
| `commitmentvalid` / `commitmenthas` | 列の長さが一致し、同じ位置に指定人物と指定記述がある |
| `commitmentsubset` / `commitmentsame` | 人物・記述の組の包含、または集合としての一致 |
| `commitmentexceptsubset` | 指定の一組を除いた全記録が後状態にもある |
| `commitmentincluded` | 指定の組を含めた結果だけが後状態になり、既存の同じ組も許す |
| `commitmentadded` | 指定の組が新規に加わり、他の全記録は保たれる |
| `commitmentremoved` | 以前あった指定の組だけがなくなる |
| `commitmentreplaced` | 同じ人物の旧記述だけを、構文上異なる新記述へ置き換える |

人物と記述の照合には、既存の列の位置判定とfoldを使う。foldは現在位置を受け取る検査関数を組み立て、列の最後から一つずつ位置を戻して対応を確認する。位置の加減には既存の有理数加算を使う。外部の状態選択関数や、各発言専用の基本宣言は追加していない。

## 状態差と、受諾・訂正・撤回の行為

`commitmentaccepted`は[既存の受諾条件](shared-speech-v1.md)と、受け手の採用記録を含める状態変化を結ぶ。既存の受諾は対象一個体を受け取る発話関数の記述を扱うため、`utteranceinstance`で対象の記述を適用し、一つの発話記述にする。対象記述の指示対象が、提示・理解・受諾で扱った対象と一致することも要求する。発話内容は引用のまま保持し、対象の同定だけを実行評価する。同じ記述を再受諾した場合、採用内容の集合は変わらなくてもよい。

`commitmentwithdrawn`は指定記録の除去に加え、同じ人物・行為・記述・理由・状況について撤回したという関係を要求する。`commitmentcorrected`は旧記述から新記述への置換に加え、同じ人物・行為・新旧記述・理由・状況について訂正したという関係を要求する。状態に記録が見当たらないというだけでは、撤回行為があったとは判定しない。

ここでの採用記録は、会話で採用した記述を明示するためのものである。内容の真理、心理的信念、法的義務の認定は含まない。撤回しても、反対の内容を新たに主張したことにはならない。訂正後の内容が偽であっても、指定した記述への訂正行為と状態差は記録できる。撤回・訂正を認定する社会的関係は明示的な入力であり、新しい基本宣言を加えなかったことを、意味の入力が増えていないこととは扱わない。

## 旧状態を残す履歴

[接続例](../examples/v016/accepted-corrected-withdrawn-v1.noema)は、[部分回答の定義](shared-answers-v1.md)と三段階の会話を結ぶ。答えがAkiとNaoである問いに対し、Naoが「Akiが全回答だ」という誤った内容をいったん受諾する。次に「Akiは答えの一部だ」という正しい内容へ訂正し、その後、その正しい内容の採用記録を撤回する。Aki自身の記録は全段階で保たれる。

各段階は、変更前後の二列、行為、理由、状況を本文中に残す。`conversationlinked`は、同じ会話の前段の後状態と次段の前状態が一致し、指定の時点間に前後関係があることを検査する。個別の受諾・訂正・撤回の成立はそれぞれの定義で検査する。終状態が初期状態と同じでも、途中の三つの行為がなかったことにはならない。

接続例の条件・回答内容・社会的関係は本文のlambdaに記述する。外部モデルは二個体名、三時点名、既存の有理数加算だけを解釈する。仮想的な検査例であり、現実の人物についての事実認定ではない。状態更新の定義は前後関係の検査であり、外部アプリを自動で書き換える命令でもない。

[検証報告](../reports/shared-conversation-v1.json)は、二人物・二記述の全256前後状態、社会的関係の三つの真偽と全16後状態を組み合わせた128モデル、38の単枠束縛診断を記録する。全状態検査ではNativeの定義を集合演算の独立した期待値と比較する。束縛診断は他の値を固定して一枠だけ変える検査であり、引数全体の領域を列挙した証明とは区別する。

扱う記述は閉じた段階0の発話記述で、同義性の自動認定は行わない。未知の内容は引用状態で保持できるが、未知の対象同定・社会的認定・加算の解釈は、必要になった時点で評価を拒否する。回答20語と新しい会話14語の円文字接続、約束の期限・解除・不履行、知識と情報構造、第三者の学習・読解、二作品全体の新書式化は残る。
