# 確定しない賛同と、含まれる真理の可能性

カントu0012の、規定群を十分な確信をもって支持するわけではないが、そこに真理が含まれる可能性は排除されない、という部分へ接続した。全体への賛同と、含まれる命題的部分の真理を別の対象として扱う。

## 賛同の候補を評価する

既存の判断候補の構成`rn`を使い、同じ本人・対象・基準文脈で選んだ状況を評価する。

| 定義 | 選んだ判断候補についての条件 |
|---|---|
| `rgi` | 非空で、全候補において対象への賛同が成立する。 |
| `rgj` | 賛同が成立しない候補が少なくとも一つある。 |
| `rgk` | 非空で、全候補において賛同が成立しない。 |
| `rgl` | 賛同が成立する候補と、成立しない候補がそれぞれある。 |

候補が空なら四条件は全て偽である。`rgj`を単なる`rgi`の否定にはしていない。空の候補から「賛同が確定しない」という結論を作らないためである。

`rgk`も、対象全体が偽だと信じることとは異なる。評価しているのは賛同という関係の成立・不成立であり、対象内容の真偽ではない。判断候補に実際の状況が含まれることも要求しないので、現在の賛同の有無は独立に記述できる。

これは質的な候補モデルである。確信度を数値化したり、心理的な「十分な確信」の全意味を定義したりしたものではない。候補範囲や賛同関係の選び方を、解釈の前提として明示する。

## 全体の真理と、一部に真理が含まれること

`rgm`は、基準文脈で対象に含まれると指定した命題的部分のうち、評価状況で真であるものが一つ以上ある、という条件である。全ての部分が真であることを要求しない。規範や命令そのものを、そのまま真偽命題へ置き換えることもしない。

`rgn`は、選んだ可能状況のどれかで`rgm`が成立することを表す。部分の所属は基準文脈で固定する。ある候補では別の規定群や都合のよい別の命題を「含まれるもの」として選び直すことを許さない。

`rgp`は、可能状況の範囲が非空で、その中に真なる部分を含む状況がないことを表す。空の可能状況を不可能性と扱わない。また、未知の所属関係を空集合へ、未知の真理を偽へ置き換えない。

例えば二つの命題が含まれ、一方だけがある候補状況で真なら、真理を含む可能性は成立しうる。もう一方が全候補で偽でもよい。現在の状況で両方が偽でも、この可能性から矛盾は生じない。

## 二つの範囲を保った接続

`rgo`は、賛同が成立しない判断候補があることと、含まれる真理の可能性を結ぶ。判断候補と可能状況は別の選択関係として渡す。同じ候補状況で両条件が実現することや、一方の範囲が他方に含まれることは要求しない。

カント草案の`hzbw`は、この条件を前版の組織の名による職務上の提示に接続する。提示する対象・発話と、賛同や部分的な真理を評価する同じ規定群との関係を明示する。別の規定群への確信を、今回の発話の条件へ流用しない。

`hzbw`は実際の提示に加える条件である。賛同の不足や真理の可能性から、提示の生起・義務・許可・能力を導く規則ではない。原文の「可能だから引き受けられる」という理由づけや、良心との両立を説明し終えたものでもない。

## 検査と残る課題

判断候補の選択と賛同、現在の賛同を変えた32設定を検査した。真理の可能性では、二候補の選択・二命題の所属・各候補での真偽を変えた256設定を検査した。さらに現在の真理4設定と、本人・規定群・基準文脈・所属・発話の参照先などを変えた17対照例を確認した。

判断候補と可能状況が交わらない設定でも、それぞれに必要な証人があれば結合条件は成立する。賛同の判定だけなら、含まれる命題の真理が未知でも評価できる。真理や選択関係を実際に評価する必要がある場合は、未知を補わず停止する。全文草案と独立抽出文書の結果は一致した。

これらは指定した有限モデルの検査であり、全ての可能世界や心理状態を検証したものではない。`voller Ueberzeugung`の程度、仮定的な`würde`、`ganz`や`verborgen`の含意、命題的部分の同定、内的宗教との無矛盾、実益、良心・辞職、全文の意味一致は未完である。
