# 現在の行使能力と、試行を許されなかったこと

カント第三段落の旧草案では、自分の理解力を使う現在の不能を、その場で利用できる方法の不在で評価していた。第一段落で採用した、本人側の判断基盤を保って通常の機会を比較する評価は、この箇所にはまだ適用されていなかった。今回、同じ一般構成を再利用して肯定・否定の能力を定義し、過去の許容不在との因果的な接続を追加した。三つとも既存要素の合成で、新しい基本関係はない。

## 能力の対象

この箇所の対象は、自分自身の理解力の使用である。第一段落の「他者の指導なし」という条件を加えない。したがって、人から指導を受けながら自分の理解力を使える人について、こちらの肯定評価が成立し、自立的な使用能力の否定評価も成立するモデルを許す。

評価するのは現在の本人側の判断基盤を行使する能力である。その場の外的な機会がないだけで不能とはしない。将来の訓練を含めれば成功できることも、そのまま現在の行使能力には数えない。方法の区分や結果の評価が未知なら、能力の否定を確定しない。

## 履歴と因果

旧草案の履歴構成を再利用し、同じ本人・基準より前の履歴で、自分の理解力を使う試みを許容した行為者がいないことを表す。基準時以後、別履歴、別人、別活動に関する許容は、この否定履歴を覆さない。実際に試したことがないという条件とは分ける。宣言された過去範囲が空なら否定履歴は空虚に成立するが、それだけで因果を得ることはない。

因果の内容式は、過去の許容不在と現在の不能の双方の成立に加え、その同じ本人・内容・基準についての実際の因果的寄与を要求する。説明として採用されたこと、二つの内容が共存すること、単なる時間順序では代用できない。既存の因果構成と同じ三条件を、内容の直接評価と因果関係で組み立てる。許容不在から能力不足への普遍法則や、唯一・必要・十分な原因であることは足さない。

ここではweil節を事態間の因果として読む。文法だけでこの読みが強制されるとはしない。IDSの説明も、因果の事態と関係を区別し、因果を単純な反実仮想の必要条件へ還元する限界を示している。[Kausalspezifikation](https://grammis.ids-mannheim.de/systematische-grammatik/2425)

weilには発話や認識の根拠を述べる読みもあり、動詞末尾の形でもその可能性は残る。今回の選択は、試行をさせなかったことと現在の不能を結ぶ、この段落についての解釈である。[IDSのweilの説明](https://grammis.ids-mannheim.de/fragen/133)

## 実装と検証

| 定義 | 内容 |
| --- | --- |
| `r2cf` | 現在の判断基盤に基づく、自分の理解力の使用不能 |
| `r2ch` | 同じ活動・判断基盤に基づく肯定的な使用能力 |
| `r2cg` | 過去の試行の許容不在と現在の不能、その間の因果的寄与 |

能力の検査は、現在地での機会、二つの通常候補での結果、候補の優先順位を独立に変える16組合せを使う。指導つきの使用、訓練だけによる成功、未知の方法区分、比較範囲や評価の欠落も対照にする。実際の既存能力定義を実行し、期待する結果だけを返す仮の能力判定器へ置き換えない。

因果の検査は、過去の許容不在・現在の不能・因果的寄与・説明への採用・実際の試行を独立に変える32組合せを使う。因果の向き、本人、活動、文脈、履歴外や未来の許容、過去範囲の空虚さも確認する。引用による主張の帰属は世界の内容を未知のまま扱えることを別に検査する。

記述を逆引用して評価する汎用関数は、階層0の引用内では使えない。今回の内容式は両内容を直接評価するため、同じ因果の三条件を保って著者への帰属に引用できる。検査では、逆引用を隠した旧形式が階層検査で拒否されることと、現在の内容式を引用できることの両方を確認する。

三定義は本文の宣言へ追加し、診断用の引用文を無条件の本文主張として加えることはしない。第三段落で人称が指す範囲とその量化、著者への帰属は、第一文との接続時に確定する。既存の51本文文と十二単位の意味判断は変えない。意味確認済み分量は2,212文字のままである。
