# 最高権力による宗教的専制の支援

第六段落最終文の後半で、君主が最高権力を宗教的専制の支援にまで低める場合を構成する。同じ作品への統治的な介入、支援される複数の専制者、対抗対象となる残りの臣民、権能の不相応な用い方を結ぶ。全文の意味判断はまだ増やさない。

[原文](https://korpora.org/kant/aa08/040.html)のgeistlichenはDespotismを修飾する。したがって担い手全員に正式な聖職者の資格を追加せず、宗教的な理解・判断・実践の領域における恣意的支配と読む。`r5p6` は既存 `r2qa` の事実上の決定統制と抑制されない個人裁量を、同じ国家・同じ領域の仕組みに結ぶ。宗教的な肩書や助言だけでは成立しない。

`r5p3/p4` は支援される不定の複数者を、同じ君主の臣民の部分集合として固定する。異なる少なくとも二人を要求するが、具体的な人数・比率や全専制者の列挙は要求しない。`r5p5` は同じ臣民集合からその集団を除いた残余である。`r5p7/qa` は各専制者の支援される仕組みと、残余全員に向けられる対抗的支配を結ぶ。各専制者が全員を同じ仕組みで支配することや、対象全員の服属が成功したことは要求しない。

支援は同じ活動がその仕組みの維持・運用に実務上の支えを供することとする。[Adelungのunterstützen](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_4_1_1272)にある援助・意図や作用の促進という語義を補助にし、賛意だけや未着手の意図だけへ弱めない。資金、執行、法令など特定の手段は本文外から補わない。

`r5qb` は同じ君主の同じ最高職の権能を、同じ生起活動で実際に動員することを要求する。`r5qd/qe` はその権能を同じ支援対象の仕組みの補助手段として用いることと、その用い方が同じ職の公的な地位・役割にふさわしくないという評価を分ける。[Adelungのerniedrigen](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_7_1_1973)の品位に反する行為という比喩用法と整合させ、強制力の減少、権限の譲渡、正式な上下関係の逆転や失職にしない。

`r5qf` は同じ専制者と残余臣民の全範囲に、その支援と不相応な権能使用を要求する。`r5qg/qh` は同じ残余臣民の同じ作品への介入に接続する。作品の内容審査、権能の使用、専制の支援の最高職を一つの束縛で共有し、別々の役職や仕組みから条件を集めない。

so weit ... zu unterstützenの低め方を具体化するのは、この同じ支援である。数値の程度や後に必ず生じる結果を追加しない。二側の損傷を比べるnoch weit mehr、程度の提示、全仮定範囲と条件、格言引用と著者帰属、selbstの取り立て・würdigtの皮肉、全文通読は残る。今回の不相応な使用の評価から、君主の威厳への因果的損傷を自動的に導いたことにもしない。

検査は重複した一人を複数とする入力、別国の対象、残余の一部の脱落、専制性と支援対象の不一致、別活動・別最高職の混同、適切な支援を低下とみなす入力を扱う。有限モデルで現実の支配や品位の評価基準を発見したとはしない。
