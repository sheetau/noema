# 定義文書を参照を保って結合する

別の文書で同じ記号を使っていても、同じ概念とは限らない。`noema.linking` は、共通だと明示した宣言だけを共有し、衝突した独立の記号を改名して一つの文書へ結合する。翻訳や新しい言語構文ではなく、既存の文語文書を組み立てる機能である。

## 共有と改名

`link_documents` には、ラベルから文書への順序付き辞書を渡す。先の文書の記号は保持し、後の文書の衝突した記号には決定論的に未使用名を割り当てる。後の文書に元から存在する名前も予約し、改名先として使わない。返り値には統合文書、各出典の記号対応表、文の位置対応表がある。

```python
from noema.grammar import parse
from noema.linking import link_documents, project_document

first = parse('n:r aa[] c.q[k aa[]].')
second = parse('n:r aa[] c.q[k aa[]].')
linked = link_documents({'first': first, 'second': second})
assert linked.symbols['first']['aa'] != linked.symbols['second']['aa']
assert project_document(linked, 'second') == second
```

共有するときは、`shared={'second': {'aa': ('first', 'aa')}}` のように明示する。共有先は前に読み込んだ文書の宣言に限る。参照を移した後の宣言が一致するかを検査し、型が同じでも本文が違う定義や、別の依存先を持つ定義を拒否する。同じ文書内の異なる二記号を一つへ共有する指定も拒否する。

基本関係の型が同じことは、意味が同じことの証拠ではない。このAPIの共有指定は呼出側の明示的な同一視であり、意味規約の一致を呼出側で確認する必要がある。カントの統合では、共通祖先の宣言だけでなく、基本関係と定義の意味説明が両枝で変わっていないことも検査する。

## 引用・変数・発話

改名は大域的な定義参照と呼出しに適用し、記述として引用された式の内部にも適用する。束縛変数の名前や型は置き換えない。同じ本文を持つ別名定義を自動的に一つへまとめることもしない。Noemaでは、値が一致することと、その定義の記述が同じであることが別だからである。

原文書の記述と改名後の記述は、文字列としては異なる。記述を扱う外部の解釈関数は記号対応表に従って参照を移す必要がある。旧名を比較する外部関数が、改名後もそのままで同じ結果になるとは保証しない。出典への射影では逆対応を使い、引用を含む元の構造を復元できる。

文は順序と重複を保って連結し、質問・主張・呼びかけ・仮定を実行しない。同じ文の再出現が同じ発話であるとは限らないため、APIは文の重複を自動的に削除しない。版の混在も拒否し、必要な版変換は呼出側で明示する。統合が成功しても、異なる文書の主張が相互に矛盾しないことや、実世界で真であることを証明したわけではない。

## カント草案への適用

[取得した態度の草案](../examples/v014/kant-retained-attitudes.noema)と[閉じ込めの成立過程の草案](../examples/v014/kant-confinement-onset.noema)は、共通の343宣言から分岐していた。両枝の `rab` から `raf` までの5記号には別の定義があり、単純な連結や同名による共有はできなかった。

[統合草案](../examples/v014/kant-linked-draft.noema)では、現在の枝の名前を保持し、閉じ込め側の5記号を `zza` から `zze` へ改名した。共通祖先から継承した同一の8主張は、祖先との完全一致を検査して一度だけ保持する。これは共通部分に限った明示的な処理であり、一般の発話の重複排除ではない。

統合結果は基本述語177・定義238・主張9である。正規形の文字数は二文書合計62,629文字から34,872文字になった。共通定義を一度だけ含むための削減であり、単文の翻訳長が短くなったという結果ではない。二つの元文書は、共有された主張の対応を戻すことで、引用を含む全構造を正確に復元できる。

意味規約内の記号参照も改名し、[統合した意味規約](../data/kant-linked-draft-basis-v1.json)の `linkage` に由来と対応を保存した。過去の許容・取得した好み・閉じ込めの13例を統合文書で検査した。現在の草案の `raf` と閉じ込め側の旧 `raf` が別の意味を保つことを確認している。

新しい原文範囲は追加していない。習慣・愛着・比喩等の未記述要素と、全文の意味一致確認は残る。文書を結合したことは、分岐した二つの草案を同時に扱えるようにした成果であり、全文翻訳の完成ではない。

結合処理15件・統合文書4件・進捗監査12件の計31テストが通過した。検証記録と進捗集計の再生成一致、通常・短縮記法と固有文字の往復、CLIのJSONと元の構造の一致、SVGのXMLとしての妥当性も確認した。今回、字形の目視確認は行っていない。
