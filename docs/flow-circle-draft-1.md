# 横書き円文字案 1

未固定の表記案。kant-pageの横の流れ、三つの高さ、短い枝、円の接触を基準とする。構文木をそのまま紙面に展開する旧試案は採用しない。新しい配置の承認は利用者の見た目確認を経る。

実装は `scripts/flow_circle.py`、比較ページは `output/flow-circle-draft-1/index.html`。この文書は表記規則であり、現在の引き継ぎの正本はプロジェクト台帳に置く。

## 保存するものと変更するもの

公開語彙の語形、語義、引数の型と役割、複合語の綴り、文書内定義を保存する。文書別の番号から語形を作らない。通常の主張は式から書き始める。質問・実行・仮定には、それぞれの発話標識を付ける。文脈から意味を推測して標識を省く規則ではなく、文の位置に式が現れれば主張と読むという文法規則である。

文法標識は、既存の族と操作の二字を一字の合字にする。族は大円の組合せと中心から円周までの長線、操作は中心から中円の半径までの短線で表す。両者の方向が等しい場合は長線だけにする。方向なしの操作には同心の小円を加える。49操作の対応は `visible_syntax_vocabulary.KEYWORDS` と `visible_sharing.SHARING` を使う。生成時に全合字・語形・境界字・行標識の衝突を拒否する。

## 読順と連結

行は上から下、行内は大きい主円の中心を基準として左から右へ読む。同じ横位置には、中円以下の単円を上段・下段に一つずつだけ置ける。その列は上、下の順で読む。同列の大円、三字以上、中央段との組合せは認めない。

高さは上段0・中央32・下段64の三段。大円は中央段に置く。短い二叉では上の字を末端、下の字を次へ続く字とする。枝がない横並びでも同じ字列を表せる。文法の作用範囲は、枝の長さや紙面上の距離から判断しない。

描画は局所規則で決める。中央段の後に単円二字を置ける場合は短い二叉にする。それ以外は、大円を中央段、単円の上下方向の線を持つ字をその側、水平線または線なしの字を中央段に置く。小円に続く接続は直角、それ以外の高さ変更は45度、同じ高さは直線とする。次の字は直前の列の右端より先に置くため、深い構文でも行の高さは増えない。配置候補の総当たり探索は行わない。

復号はこの描画手順を再実行しない。円と線から字を識別し、読順を回収する。字の内部線を取り除いた外部接続について、連結、循環なし、切断・余分な末端・字内への侵入・無標識交差がないことを確認する。接続の違いは同じ字列の異体配置として扱う。上下の二字が同じ横位置にあるかどうかも図形から判断する。

## 構文の区切り

| 対象 | 共通規則 |
| --- | --- |
| 文頭 | 文の位置で式から始まれば主張。質問・実行・仮定は明示標識。式の開始と発話標識の字形集合は分離する。 |
| 引数 | 演算子の後に公開された順で式を並べる。根語は辞書の引数数、固定演算は文法の個数で区切る。可変長の呼出し・列などは既存の終端字で閉じる。 |
| 分岐 | 左右順、同列では上下順という一つの読順を適用する。二叉を論理積や選択と解釈しない。論理関係は演算子自身が示す。 |
| 引用 | 引用標識と階数を読み、一つの式を引用内部として読む。内部に入ると変数環境と共有参照環境を空にする。引用解除等は各演算の規則による。 |
| 束縛 | 束縛子が型と本体を導入する。変数は最内側からの距離で指定する。複数引数の束縛順も固定し、存在しない距離は拒否する。 |
| 共有 | 明示的なshare/reuseは既存規則で展開する。引用を越える参照や範囲外参照を拒否する。自動的な共有の挿入は無効とする。 |

字列へ戻した後は既存の公開構文読取器を使い、型検査と束縛名の正規化を行う。これにより、配置の変更と意味規約の変更を分離できる。抜粋APIは宣言を省いた文の構文を読むためのもので、型の確定には別途その宣言が必要となる。

## 行と頁

各行の先頭に、小円一つにつき八方向の一方向を示す八進の行番号を置き、無線の小円で閉じる。番号は0から始まり、頁をまたいでも連続する。語彙の番号ではない。行末には、東と南の二線を持つ小円で継続、東と北の二線を持つ小円で全体の終わりを示す。最終頁の最終行だけが終了標識になる。

改行・改頁は字の間で行い、読取器の構文状態は引き継ぐ。引用・束縛・語の途中で改頁しても、新たな文や作用範囲を開始しない。頁ごとの図形を入力順に読み、可視の行番号と継続標識によって脱落・重複・交換・終端欠落を拒否する。連続した複数頁をそれぞれ独立した完結文書として連結することはできない。

全行にある小円の半径から一様な縮尺を求めるため、頁ごとに拡大率・平行移動が違ってもよい。回転・鏡映・歪み・手描きの揺れ・ラスター画像のOCRは扱わない。形状リストの順序、SVGの要素順、線分の分割や向きは読順を表す情報として使わない。

## 整合性を支える構造と検査の境界

一意性は、字形の識別、幾何的な読順、prefix文法の解析の三段階に分ける。字の接触を字内部に限定し、内部線と外部接続を区別できれば、各字は公開表の一つの要素になる。左から右、同列は上から下という規則で全順序を得る。各演算の引数個数または終端字がその次の式の境界を決め、束縛環境と引用境界も文法から決まる。配置を意味の推測に使わないので、紙面上の分岐の深さによる曖昧さを生じさせない。

実装の有限検査を全域の形式証明とは呼ばない。40の構文対照、引数順の全6通り、引用と束縛、全許容字形、手で記述した図形、改行・改頁、分割した線分、不正な図形を検査する。同一プロセス内で各対照のSVG復号結果を報告にも再利用する。意味モデルの全量再実行は行わない。

既存カント抜粋の4主張は実SVGから回収し、保存された113宣言を付けて元と同じ正規化構文になることを確認する。宣言は図形を推測するための入力にせず、回収後の型検査に使う。この抜粋だけで作品全体が自立したとはしない。既存の原稿・語義・参照と保存済み監査の対応は内容ハッシュで確認する。全402主張の新表記への移行は別の作業である。

## 見た目と実装の制限

通常主張の共通接頭字を省き、合字を使い、短い枝を行内に収めた。一方で、数値と変数距離、長い複合語では字の反復が残る。構文の違いは語形・合字・引数列として現れるが、式ごとに固有の枝模様を割り当てる方式ではない。比較ページでこの差を確認する。

公開375語を構成する根語の部品と49文法操作を含む字形一覧に、短文群での使用・未使用を表示する。未使用の字形も単独の図形識別を検査する。旧kant-pageの不可視接続、文書別番号による語形、共有引数の図形融合、円周外だけの斜線はこの案では使わない。

単頁は4096図形部品、2048字、128行以内。複数頁APIは1頁8行まで、全体128頁・8192字以内。行番号は4桁の八進数以内、文法解析には既存の深さ・展開量の制限も適用する。これらは実装の入力上限であり、許容した最大値の全組合せを試験したという意味ではない。
