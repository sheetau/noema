# 一様性と線形性の必要性

u0047は、先行する方程式探索の課題に対し、まず式が線形でなければならないことが明らかだと述べ、その理由を、われわれが空間と時間に与える一様性に置く。原刊898頁の一文全体を対象とする。

ここでは、この運動学の同じ系・計器・尺度における比較規則に特権的な場所・時刻がないことを、一様性の操作的な意味として採る。同じ四変位に対する出力の増分が、その出発点によって変わらないという既存`shs`を使う。`eizc`は前段の測定済み座標`eiyz`と値で一致するベクトルの全範囲、`eizd`は現行の同じ出来事の対応`eiyy`と変換出力の過不足のない一致である。`eize`はこの二つを通じて`shs`を実際の場所・局所時計の規約へ接続する。単なる任意の関数の一様性や、全物理法則についての一様性一般と同義だとはしない。

比較範囲は非空で、すべての出発点対と、移動後も範囲内にとどまるすべての有効な四変位を対象にする。空間の三方向と時間方向、両者が混ざった変位を含む。原点を動かしても同じ比較結果を得るという性質を、零変位や一地点での成功へ弱めない。範囲は成功例から選ばず、前段で対象にした全座標に固定する。`sia/sie`は入力・出力を同じ四役割へ正規化し、無関係な第五成分を入力に使わせない。

linearは、この時点では原点一致が指定されていないため、原点定数を許すアフィン形として読む。`eizf`は同じ一つの行列と定数ベクトルによる全入力の表示を、同じ現行の座標対応へ結ぶ。`eizg`はその行列と定数ベクトルの存在内容である。係数を入力ごとに取り替えず、原点保存や零定数を補わない。各成分の単位は固定され、混合係数はその単位規約に従う数値である。時間と長さを同種の物理量として加算しているのではない。

`eizh`はこの空間・時間の一様性の採用を著者に帰属する。`eizj`は同じ一様性を理由にアフィン形が必要だという主張、明白さの提示、前段の課題への必要条件を、既存`zc/zdg/zdh`で結ぶ。一様性から一般の実数域で行列表示が従うという証明は追加しない。原文にない連続性などを仮定へ足さず、著者が述べる必然性と処理系が証明した含意を区別する。

Zunächstは、この方程式探索に対する主要な検討段階の最初と読む。一般的な段階所属`eisnm`と本文順序`ue`を用い、`eizi`で現在段階の所属と他の全主要段階への先行を要求する。課題以前の準備や、この段階内の理由説明を別の先行段階へ混ぜない。新しい原始記号はこの一般的な課題内の段階所属だけで、一様性や線形性の文全体を一語へ置き換えていない。

検査は、現行の座標域と対応への接続、全四成分と全出発点・変位の量化の骨格、同じ行列・定数の共有、原点定数と二次変換の対照、理由と結論・明白さ・課題の交換、最初という順序の欠落を扱う。有限の数値モデルと、全実数・行列・関数の量化を区別し、後者を処理系が有限標本で認定することは拒否する。既存の有理多項式の証拠も、アフィン形なら増分が出発点に依存しない向きの補題であり、その逆向きの一般証明ではない。
