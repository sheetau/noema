# 二値の意思決定における影響と一方的な決定

同じ決定規則の下で、本人の入力が結果へ影響する場合と、本人の入力だけで結果が決まる場合を区別した。前段の「関係から離れる」の関係引数へ後者を接続する。カントの個人的専制を説明するための部品であり、その概念全体を定義し終えたものではない。

入力者の有限列と、各人の二値入力から二値結果を返す規則を用いる。たとえば三人の多数決では、他の二人が分かれていれば本人が結果を変えられる。しかし他の二人が一致すれば本人だけでは決められない。一方、常に一人の入力だけで結果を決める規則なら、他者の入力をすべて変えてもその人の入力に対応する結果は変わらない。

| 定義 | 内容 |
| --- | --- |
| `rqt` | 人物ごとの入力を人物列の位置へ対応させる。 |
| `rqu` | 指定した本人だけに指定値を与え、他の入力を偽にした比較配置を作る。 |
| `rqv` | 他の入力を固定して本人の入力だけを変えると、結果が変わる配置が存在する。 |
| `rqw` | 全配置で結果が本人の入力だけから決まり、本人の二つの入力は異なる結果を生む。 |
| `rqy` | 同じ対象・状況について、入力者列が重複なく完全で、対象自身を含むことを検査する。 |
| `rqx` | 同じ対象・状況の完全な入力者列について、対象自身も参加し、別の相手が`rqw`を満たす。 |
| `hzhr` | `rqx`の関係から離れる変化を、同じ当事者・評価済みの前後・作用過程で記述する。 |
| `hzhs` | 設定の記述から`hzhr`の内容記述を構成する。 |
| `hzht` | 因果対比の第一の結果を、その同じ離脱内容の記述へ固定する。 |

一方的な決定は、結果が本人の入力と一致する場合に限らない。規則がその入力を常に反転しても、本人が選べる二つの入力と結果は一対一で対応する。常に同じ結果を返す定数規則は、本人にも結果を変える余地がないため除外する。少数者の拒否権、全員一致、論理和、偶奇による決定は、影響があっても一人だけの決定とは区別する。

`rqx`では、同じ対象・状況から入力者列と規則を得る。入力者の範囲に対する完全性、重複の不在、対象の参加、決定者と対象の相違を要求する。列の並びを変える場合には、規則の位置と人物の対応も変更する。異なる対象の規則や、対象を省いた入力列で関係を成立させない。

この関係を前段の変化へ組み込むことで、「前には他者だけで決まっていたが、後にはそうでなくなった」を表せる。後に本人が決定する場合も、多数で決める場合も、別の相手が決定する場合も、選んだ相手からの離脱と両立する。離脱を引き起こす活動と離脱内容は、既存の因果記録で同じ結果記述へ結ぶ。内容の引用を作るだけでは、関係や出来事の成立を評価しない。

離脱の判定では、前後両方の入力者一覧に`rqy`を要求する。終了時点の入力者の欠落や重複によって関係の検査が不成立になっても、それを離脱の証拠にはしない。指定範囲に対する設定の有効性と、関係の成立を分けて検査する。

## 検証

独立したPythonの真理値表判定とNoema評価を照合する。二人の全16規則を両者について、三人の全256規則を指定した一人について検査する計288例である。規則名に応じてNoemaの結果を返す補正処理は使わず、入力列に対する純粋な二値関数を与えて定義を実行する。

全文草案と依存定義だけの文書の両方で、代表規則、入力者の欠落・重複、人物列の並べ替え、対象の取り違え、関係の継続、最初から不成立な関係、未評価の終了点、別の変化過程、因果活動の欠落、結果記述の不一致を検査する。引用構成時は内容を実行する全コールバックを禁止して検査する。未知の規則・入力者範囲はエラーを保持する。

有限モデルの診断には既存の短絡評価変換を用いる。元のNoema文書は変えない。二つの代表規則では短絡変換もキャッシュも使わない評価と一致することを確認する。全表記・固有文字への往復、専用CLIの解析、親文書の全宣言と15主張の保存、意味説明と型の対応も検査する。検査結果は[報告](../reports/unilateral-decision-v1.json)に保存する。

## 残る意味

これは純粋な決定規則の性質である。現実に各入力を実行できること、判断形成が自由であること、実際に服従したこと、物理的な強制や制度上の権限までは表さない。完全性は指定された入力者範囲に対して検査するため、その範囲が現実の全要因を含むかは別の説明を要する。

対象に入力の余地がない支配、多値・確率的な選択、議題を設定する権力、複数人による連合支配も残る。個人的専制、利欲・支配欲による圧迫、革命、真の改革、具体的な著者帰属と全文の意味一致は未完である。九つの合成定義を追加し、原始記号・原文の主張・対応範囲・意味確認済み区間は増やさない。
