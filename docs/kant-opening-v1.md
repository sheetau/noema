# カント冒頭の定義草案

冒頭段落のうち、理解力の使用、未成熟、自己に責任がある未成熟、そこからの離脱を、文語0.9の式として組み立てた。[Noema草案](../examples/v09/kant-opening-draft.noema)は11の基本関係と6つの定義からなる。新しい文法演算子や翻訳処理は追加していない。

これは原文と同義であることを確認済みの訳文ではない。能力と原因の解釈には未解決点があり、呼びかけ・標語はまだ記述していない。全文対応の確認済み単位はカント0/20、アインシュタイン0/282のままである。

## 合成した内容

| 定義 | 内容 |
| --- | --- |
| `ba` | 選べる方法があり、その想定結果が非空で、全結果で目的内容が成立する |
| `bb` | 自分自身の理解能力を実際に使い、その同じ行為について他者の指導を受けていないという内容 |
| `bc` | 人であり、`bb`を確実に達成する手段がない |
| `bf` | 状況ごとに`bc`を評価する内容 |
| `bd` | `bc`にあり、その原因説明として理解力の不足を採用せず、決意と勇気の不足を採用する |
| `be` | 変化過程を通じて、`bd`にある状況から`bc`にない状況へ移る |

`bb`は能力の所有と使用を分け、行為を一つの対象として参照する。他者が別の行為を指導しているだけでは、この行為への指導にならない。自己による指導も「他者の指導」に含めない。

`bd`では「理解力の不足が原因ではない」と「理解力が不足していない」を区別する。`be`では、自己に責任があるという分類から外れただけで、未成熟から脱したとはしない。変化の前後を逆にすることや、関係のない二状況を並べることも区別する。

草案は定義だけを含む。特定の人物の存在や、全ての人についての事実を主張する文書にはしていない。

## 基本関係の意味と限界

[意味の規約](../data/kant-opening-basis-v1.json)に、11の基本関係それぞれの引数・型・意味と、6つの定義の説明を記録した。検査器は宣言との過不足、型の不一致、説明の欠落を拒否し、定義が依存する基本関係を報告する。説明が存在することの検査であり、その意味の正しさや、普遍的な基礎概念としての十分さを証明する検査ではない。

特に、以下は原文との対応を確定する前に解決する必要がある。

- `ba`は想定結果すべてに対する達成の保証である。失敗の可能性を許す通常の能力や傾向と同じではなく、カントの能力概念を確定したものではない。
- 原因の基本関係`ah`は、原因として説明に採用する関係である。実在の因果関係そのものとの対応は未確定で、同時成立や含意から原因を導く規則はない。
- 0.9の内容型は全状況で同じ真偽になる内容を同一とする。同じ真偽を持つ異なる因果機序や認識の仕方を区別する仕組みは残る課題である。
- 決意と勇気の不足を論理積と読むこと、離脱を前後の状態によって表すことが、原文の意味を十分に保つかは未確認である。
- 人・理解能力・指導・勇気などの基本関係は意味の規約を与えた段階であり、全てを共通の基礎から説明済みにはしていない。

## 原文との対応と検証

[対応表](../data/kant-opening-alignment-v1.json)は、保存済みの冒頭段落`kant-1784:u0008`を6区間に分ける。最初の3区間は部分草案、標語・命令・標語の位置付けを述べる後半3区間は未記述とした。段落の全非空白文字が対応表に一度ずつ含まれることを検査する。この網羅性は原文の見落としを防ぐためのもので、全内容をNoemaで記述したという意味ではない。

17の有限モデル例で、所有と実行、自他と行為の同一性、原因説明と同時成立、未成熟と責任の帰属、変化の方向を区別した。モデルの事実は検査用に明示的に与えたもので、原文から自動抽出した事実ではない。全例と、通常記法・短縮記法・固有文字版2の意味構造の往復が通過した。[検査記録](../reports/kant-opening-v1.json)には各例の条件・期待値・実測値と入力ファイルのハッシュを保存した。
