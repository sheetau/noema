# 角度付き速度合成式と計算の評価

原刊906頁のu0139後半とu0140を、同じ点のU,w,αを用いた計算の帰結として接続する。u0139前半の角の意味の説明は前段のまま保持する。「簡単な計算の後で得られる」のコロンは次の表示式を指し、計算の出発内容・結論・負担の評価を同じ著者と第五節へ結ぶ。

表示式はU=√((v²+w²+2vw cosα)−(vw sinα/V)²)/(1+vw cosα/V²)である。固定した電子転記の分母sinは原刊のcosと異なるため、[既存の訂正記録](../data/written-math-corrections-v1.json)を明示して読む。元のMathMLとハッシュは変更せず、訂正後の別の式を併記する。分子のsinは変更しない。

現在の同じ点・両系・尺度・全期間における非負速さU,wと、同じαの実数測度・単位円成分を、既存の被開平数s2r、分母s2s、零も含む非負平方根と符号付き商s2tへ渡す。角は正の系速度から点速度への向き付き代表(-π,π]という前段の明示した読みを保つ。零速度に角を補ったり、縦成分零の商を定義したりしない。

印刷式の分母が負だと、非負のUと右辺が一致しないことがある。例えばV=5,v=3,w=25,cosα=−3/5,sinα=4/5では、根号内は400、分母は−4/5、右辺は−25となる。対応する速度成分の非負ノルムは25である。前段では点の速度に光速上限を課していないため、この不一致を消すためにw<Vや正分母条件を前提へ追加しない。絶対値分母に直すことも、二乗の等式だけで原文の式を代用することもしない。

Noema本文では、同じ既出の運動と三量の定義を前提として、著者が印刷式を帰結として提示したことを記述する。前提を持つ設定で結論が偽になり得ることも保持する。著者の主張・推論を記述できることと、その普遍的な正しさを立証することは別である。この区別は、原文の条件を都合よく削るためではなく、印刷された内容と既出の量の意味を共に保つために用いる。

「簡単」は、同じ前提から同じ結果へ至る非空有限手順列があり、その各手順の非負負担の合計が文脈上の低負担基準に入るという既存の読みを再利用する。手順の許容関係、負担尺度、基準を明示するが、原文にない具体的な手順や閾値は補わない。著者による評価の引用は、その方法の健全性や実際の実行済みを証明しない。

旧文133–135の部分的な式・帰結・計算評価を現在の取得規則へ接続し直す。旧s2v/s3c/s3dと旧本文・証拠は保存し、内容が異なるものの判断は引き継がない。後続u0147の未判断の別導出s5mはまだ旧前提s3cを参照しており、その単位の統合時に接続し直す必要がある。数値核の符号と定義域、同じ三量への接続、有限手順の連続性・負担・同じ方法、帰属の引数を検査する。原刊を通読して行う意味判断は別記録とし、後続の対称性と軸方向の合成は今回の範囲に含めない。
