# 集団としての到達と進行の区別

カント第十四区間は「啓蒙された時代」と「啓蒙の時代」を区別し、その説明で人々を「全体として」判断する。既存の `rmj` / `hzfb` は選んだ集団の全員が能力を持つ場合だけ到達を認める。その条件を原文の唯一の読みとして固定する根拠は足りないため、集団の到達基準を引数にする比較候補を追加した。

基準は、対象集団、現在条件を満たす部分集団、評価文脈を受け取る。`rqwg` は誰も満たさない分布を拒否し、全員が満たす分布を受け入れる両端条件を検査する。中間の分布に数値比率を固定しない。両端条件だけでは、一般の単調性・匿名性・公平さまで保証されない。適切な基準の意味規約は、本文への採用に先立って確定する必要がある。

`rqwh` は同じ時代・現在・非空の集団について全員の評価が整っていることを求める。`rqwi` は集団外の人を除いた能力分布が基準を満たすこと、`rqwj` は評価が整い、到達せず、進行内容が成立することを表す。全員が評価されている条件と、全員が能力を持つ条件を分ける。未知入力を非到達の根拠にしない。

`rqwk` と `rqwl` はそれぞれ問いと主張の発話を作る。内容が真かどうかと発話の種類は別であり、発話を構成するだけでは実際の問答や著者による提示を認めない。同じ基準を問答の間で保持することは、組み立てる側の条件である。`hzvc`–`hzvf` は既存の `fo` と `h4l` に接続し、知的活動の評価・能力を実行して比較する。

検査では三人の能力・評価・進行の128組合せを照合し、全員一致を指定した八例では旧候補と一致することを確認する。二人以上という基準は試験モデルの一例であり、Noemaの文法やカントの語義ではない。空の集団、時代の穴、不在者、別集団・別時点の判定、集団外の成功、不正な基準、未知入力も検査する。本文用の能力定義を真偽の仮置きに置き換えず、五つのモデルで旧候補との差と共通点を確認する。有限モデルの検査は原文との意味同一性の証明ではない。

宗教上の理解力使用、安全で適切な遂行、能力を得させうる可能性、隔たりの程度、開かれる機会と徴候、条件付きの問答と段落全体の帰属は未解決である。比較草案は現行本文に採用せず、既存41文と十単位・604非空白文字の確認を保持する。今回の新しい原文対応範囲、全単位確認はともにゼロである。
