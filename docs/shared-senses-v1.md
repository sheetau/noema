# 文脈ごとの語義、同義、多義、置換

語形と意味の対応を、文脈・語義識別子・意味関数・項数・順序付き役割列とともに保持する。候補を複数残すこと、出現箇所で一つを選ぶこと、候補を尽くして一意に確定することは別の判断である。[共通定義](../examples/v016/shared-senses-v1.noema)には新25定義を構成し、既存の `memberof`、`distinctmembers`、`focusentails`、`focusequivalent` の4定義を変更せずに再利用した。新しい基本宣言はない。[意味基盤](../data/shared-senses-basis-v1.json)に引数と限界を記録する。

## 項目と候補

`senseentry` は六欄を、既存の関数型で符号化する。入力する項目はこの構成子から作る契約である。同じ型を持つ任意の関数をレコードだと認証するものではない。`entryvalid` は構成した項目の項数と役割列を検査する。意味関数の全域性や、採用した意味の現実への適合まで保証しない。

意味欄は「個体の有限列から内容を作る関数」の閉じた記述である。0項の命題、1項の性質、多項関係を同じ方法で適用できる。役割列の長さと順序を保持し、同じ対象を複数の異なる役割に入れることは妨げない。他の型を受ける関数には従来の型付き引用適用を使う。

`sensecatalog` は、同じ語形・文脈・語義識別子に異なる定義や役割列が登録されていないことを要求する。同一項目の重複は別の語義に数えない。`sensecandidates` は同じ語形・文脈の整合した候補列であり、空列も保持できる。

`senseunique` は観測した非空の候補列に一つの語義識別子しかないこと、`senseresolved` はそれに加えて列挙完了を明示したことを表す。`sensechosen` は、候補内の完全に一致する項目と、同じ出現箇所・理由についての選択関係を要求する。選択しただけで他の候補は消えない。`senseinterpreted` は選択と引用適用を結び、内容の真理とは分ける。

## 同値と置換

意味の比較には、非空の閉じた引数例と非空の状況域を指定する。`meaningentails` と `meaningequivalent` は既存の焦点比較をこの範囲へ適用する。例や状況を増やせば反例が現れ得るため、有限範囲の一致を全ての使用での同義性にはしない。

`senseequivalent` は同じ文脈・項数・順序付き役割を持つ二項目の比較である。`sensesynonymous` はさらに異なる語形について、両語義と理由を結ぶ明示的な同義規約を要求する。意味記述の構文上の同一性と、指定範囲での真偽の一致は区別する。

`sensereplaceable` は同義規約だけでは成立しない。同じ出現箇所・閉じた枠・理由に対する許可と、その枠での内容の一致を検査する。枠は語形参照と意味記述の双方を受け取る。「この語形を用いた」「この定義を認識した」のように表現自体に言及する場合を残すためである。同じ意味定義に二つの語形が対応している場合でも、語形への引用は異なり得る。

## 多義と同音異義

`sensemultiple` は登録上の候補の複数性だけを表す。多義と同音異義の分類は、異なる語義・意味を結ぶ関連の認定と無関連の認定を別に受け取る。`sensepolysemous` は前者だけ、`sensehomonymous` は後者だけがある場合に成立する。両方ない場合は未分類、両方ある場合もどちらかに勝手に決めない。真偽の一致や、関連の証拠がないことから分類を推測しない。

## 検証範囲

[検査器](../scripts/check_shared_senses.py)は、候補16モデル、意味比較1,024モデル、分類64モデル、置換16モデルを独立した有限仕様と比較する。選択8欄、同義6欄、関連と無関連各7欄、置換8欄の計36件は、他の値を固定して一欄だけ変える結合診断であり、大域的な全域証明ではない。

四つのNative例は、[選択](../examples/v016/senses-selection-v1.noema)、[文脈](../examples/v016/senses-context-v1.noema)、[同義と引用](../examples/v016/senses-synonym-v1.noema)、[分類](../examples/v016/senses-classification-v1.noema)を各12判定で確認する。意味本体と選択・分類・許可の関係をNativeで定義し、外部から渡すのは二個体と二状況への参照だけである。これらは仕組みを区別するための架空の小モデルであり、自然言語の特定語の辞書分析ではない。

[検証報告](../reports/shared-senses-v1.json)は定義・テスト・この文書と既存証拠の内容ハッシュを保持する。引用構成と選択は未評価の内容を保持できるが、真理比較で必要な入力が未知なら拒否する。論理演算は短絡しないため、項数検査と部分的な意味関数の安全な実行は分けて扱う。円文字への接続、学習資料、第三者読解は別に確認する。
