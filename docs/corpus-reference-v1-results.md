# 公開文章512文書での参照解析

**撤回:** 以下の主辞位置と参照ペアの評価には、注釈のない主辞を句の先頭語として扱う不備があった。[修正内容](corpus-reference-v2-correction.md)を参照。文字位置不整合と原文保存・反復一致の検査はこの撤回の対象ではない。

既存の固定モデルを、手作り短文から公開コーパスの実文へ広げて評価した。原文を解析できたのは508/512文書。今回の注釈範囲で同一参照ペアの適合率は47.6%、再現率は58.6%だった。主辞の位置まで一致した文書は58/512であり、一般の文章をNoemaへ変換できる状態には遠い。モデルの追加学習、語別の補正、生成は行っていない。

## 資料と扱う意味の範囲

[KWDLC](https://github.com/ku-nlp/KWDLC)のリビジョン`c6ae49d29eca4e1134c6676d682adf5ed6a25f5a`を取得し、公式`split_for_pas`に従い学習3,915・開発512・評価700文書を取り込んだ。5,127文書全てについて、原文位置、主辞、照応注釈、ファイルのハッシュを保存した。本文・注釈はローカルの`artifacts`に置き、リポジトリにはIDと集計を保存する。配布元は研究目的の公開資料として利用上の注意を記載しており、その記録を保持した。

モデル予測を行ったのは開発512文書だけである。KWJA自身もKWDLCを利用しているため、今回の資料は完全に独立した未知文章とは呼ばない。公式の学習・評価間には同一本文が1組あり、IDを[取り込み記録](../reports/corpus-reference-v1/preparation.json)へ保存した。開発との本文重複はなかった。

[固定した方針](corpus-reference-v1-protocol.md)に従い、明示的な文書内の同一参照タグ`=`・`=構`・`=役`を、原文中の主辞範囲で比較した。全基本句の主辞を数えるため、主体・対象だけを扱った以前の12文とは測定対象が異なる。近似参照、外界参照を介した同一性、AND・OR・曖昧な同一参照は今回の参照グループへ変換していない。

AND・OR・曖昧な同一参照がある40文書は、同一性の正解を単純化せず、未対応としてペア精度の対象から外した。全512文書の完了数には残している。以下のペア精度は残る472文書が対象で、原文解析に失敗した4文書の正解ペアも分母に含める。この定義は公式評価ツールの総合スコアではなく、注釈の扱いを限定した基準測定である。余分な予測ペアの全てが、自然言語として解釈不能な関係だと断定する結果でもない。

## 測定結果

| 測定 | 結果 |
|---|---:|
| 原文解析成功 | 508 / 512文書 |
| 主辞範囲の一致 | 9,771 / 11,019箇所 |
| 主辞の欠落／過剰 | 1,248 / 1,181箇所 |
| 同一参照ペアの一致 | 539 / 920組 |
| 余分な予測ペア | 594組 |
| ペア適合率／再現率 | 47.6% / 58.6% |
| 評価する全参照ペアが一致 | 209 / 472文書 |
| 主辞集合と全参照ペアが一致 | 58 / 512文書（40文書は未対応） |

正解参照ペアがある301文書に限ると、全参照ペアの一致は64文書、主辞集合も含めた一致は13文書だった。正解参照ペアがない171文書では、それぞれ145文書・45文書だった。参照がない文章の正解だけで性能を評価しない。

主辞範囲の誤りだけでも、正解ペア163組の端点が欠落し、余分な主辞を含む予測ペアが261組あった。一方、両端の主辞範囲が正解と一致する部分だけに限定した診断でも、適合率61.8%・再現率71.2%だった。境界を直すだけで参照先の判定も十分になるとは言えない。この条件付きの値を全体の成績へ置き換えていない。

解析失敗4文書は全て、文字トークナイザー内部のNFKC正規化で「…」が3文字へ展開し、原文とモデルの文字位置が一致しなくなったものだった。長さ制限による失敗は今回はなかった。既存のメタデータの`normalization: false`は原文を前処理で書き換えないことを示すが、トークナイザー内部の正規化まで無効という意味ではなかった。[文字位置の監査](../reports/corpus-reference-v1/character-audit.json)では、この設定と不整合を別途記録した。

新規環境での取得例であり、既存の取得先へ再cloneしない。取り込みは指定リビジョンと一致しない場合に停止する。配布元のHEADが変わっている場合は、内容の変更と配布元の注意を確認した上で取得版を扱う必要がある。取り込み・予測・検証結果は上書きしない。既存成果物の診断2コマンドは再計算の一致検査としても使える。

- 5,127文書を配布元ファイルから再取り込みし、全注釈と原文位置が一致した。保存した512予測から全評価も一致した。[検証記録](../reports/corpus-reference-v1/verification.json)を保存した。
- ID順の先頭8文書のうち解析可能だった7文書で、原文からの反復結果が完全一致した。残る1文書は文字位置不整合として失敗に含めた。
- モデルの生成・辞書補完等の禁止経路5種はいずれも呼出し0回だった。[実行記録](../reports/corpus-reference-v1/run.json)と[全評価](../reports/corpus-reference-v1/evaluation.json)を保存した。
- 境界を重なりだけで正解へ補正しないこと、複数対象の参照を二値の同一性へ押し込まないこと、解析不能文書の分母保持、分割の重複拒否、文字展開の検出を含め、全280テストが通過した。

次は、原文を失わない文字位置の対応付けを修正する。その後、公開資料の公式学習部分を使い、語別ではなく共通の参照判定を学習・検証する。複数対象・曖昧な参照の表現も必要である。全文の意味構造95%、英語を含む広い自然文への対応、辞書に依存しない逆変換、文字数の膨張は未達のまま保持する。
