# 同じ判断への基準適合と、評価資料の状態

既存の使用評価 `rbi`〜`rbm` を、判断の質の引数へ渡せるように接続した。目的を達成したという `rbn` と、採用基準に照らした適合は別の条件として保持する。例えば、望んだ結果が得られても検査項目に違反する場合と、手順に適合しても結果を得られない場合を区別できる。

評価では基準を固定する文脈と、遂行の時点を分ける。基準の採用と項目範囲は前者、実際の使用は後者に結ぶ。適用条件と証拠には両方を渡す。これにより、後の判断を評価するときに、後から緩めた基準へ入れ替わることを防ぐ。証拠を入手した日時や評価者の知識を、この二時点から推定することはしない。

| 定義 | 既存の評価との接続 |
| --- | --- |
| `rqwx` | 全適用項目に肯定・否定の証拠のちょうど一方がある |
| `rqwy` | 全適用項目に肯定の証拠だけがある |
| `rqwz` | 衝突がなく、少なくとも一項目に否定の証拠がある |
| `rqw2` | 同じ一項目に肯定・否定の証拠が共存する |
| `rqw3` | 衝突がなく、少なくとも一項目に両方の証拠がない |

各評価には、採用された基準、実際の使用、非空の適用項目が必要である。違反項目と未確認項目は共存できる。資料がないことを違反の根拠にせず、異なる項目の肯否を証拠の衝突にまとめない。

`hzvx` は、本人がその事柄について行う判断と、その判断で実際に使う本人所有の能力を固定し、同じ能力について全項目の適合を求める。能力Aに第一項目、能力Bに第二項目の適合があっても、それだけでは成立しない。ただし、複数能力を使う場合の全能力の適合を要求する定義ではない。

`hzvy` は基準・採用・項目範囲・適用条件・証拠の閉じた記述から、五引数の質の基準記述を組み立てる。構築時には参照や証拠を実行せず、実行時には指定された基準を評価する。能力目標へ渡す例は次の形になる。

```text
d zadequate[p a m a j a c d s d] c[
 c[k hzvx[k zstandard[] p zadopted p zmember p zapplicable p zevidence]][v p v m v j v c v s]
].
```

この例で能力の対象になるのは、証拠に基づく適合を伴う遂行である。資料が欠けると、この条件は成立しない。一方、元の自立した判断条件が成立する場合もある。したがって、その不成立から実際の判断能力の欠如や判断の誤りを結論することはできない。証拠の信頼性、項目の網羅性、採用基準の正当性は別に検証を要する。

検査は、二項目の四証拠状態と使用・基準採用の64組合せ、空範囲の二条件、人物・能力・行為・二時点などの18対照、判断への八接続条件、八つの未知入力を扱う。閉じた基準の構築と実行を区別し、実際の判断定義・活動別能力定義を使って適合・資料不足・衝突の三条件を評価する。通常表記・簡略表記・独自文字v2の往復、現行41文と十件の意味判断の保持も確認する。

成果物は[一般形](../examples/v016/judgment-standards.noema)、[抽出文書](../examples/v016/judgment-standards-core.noema)、[比較用の累積文書](../examples/v016/kant-judgment-standards.noema)、[意味規約](../data/judgment-standards-basis-v1.json)、[検査記録](../reports/judgment-standards-v1.json)である。七定義を追加し、新しい基本関係は使わない。

原文の `sicher und gut` の必要十分条件としては採用していない。[並行用例からの制約](../data/secure-use-reading-v1.json)に照らしても、個人の任意の目的達成や一律の証拠制度へ語義を置き換える根拠は足りない。具体的な質の採用、宗教的対象範囲、程度と集団基準、段落全体の帰属を確定する作業が残る。今回の接続で新しい原文範囲や意味確認済み全文単位を増やさない。

