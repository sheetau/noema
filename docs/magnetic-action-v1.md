# 磁気的作用と全電磁力

導入の磁石・導体の相互作用へ向け、電気的作用と区別した磁気的な力を、同じ担体・系・出来事へ接続する。磁石という物体からの場の発生源の帰属は、この力の構成とは別に残る。

eicnは、符号付き電荷と速度・磁気側場の外積に、正の規約係数を掛けた三力成分を表す。外積には既存scg2、電荷と成分の積にはeibrを再利用する。零電荷、静止、速度と磁場が平行な場合も扱い、磁場があれば必ず非零の力があるとはしない。通常の磁気力の外積関係は[OpenStaxの磁場の説明](https://openstax.org/books/university-physics-volume-2/pages/11-2-magnetic-fields-and-lines)を確認した（2026-10-23）。

eicoは電荷記録sbw2、同じ担体の四座標、磁気側場の割当と評価scb2、磁気的な力の寄与と記録を結ぶ。速度には、既存seocによる同じ軌跡の座標時刻微分を使う。sepwは全軌跡の座標に長さ・時間単位を接続する。平均速度、別の系の速度、固有時による微分、片側しかない履歴を代用しない。

新しい基礎規約eirtは磁気的な力の寄与への帰属、eiruは同じ系の右手直交基底と単位正規化、eirvは電気的・磁気的寄与を合わせた全電磁力の記録への帰属である。磁気側場の表示単位そのものは既存eirnへ結ぶ。係数を1や1/cに固定せず、原文へ現代SIの規約を無条件に補わない。また、原文の磁気側成分を現代の物質中のHと同一視したり、任意の透磁率関係を仮定したりしない。

eicpはeicoと既存eibsを同じ電荷・出来事・場・力単位で結び、二寄与の三成分和を全電磁力の記録へ合わせる。重力・支持力・接触力を含む全機械的な合力とは区別する。旧scj2の一階近似についての意味規約や、旧主張を一般の力の式へ書き換えてはいない。

検査では外積の本体を実行し、正負・零の電荷、静止・平行・逆向きの速度と、各成分の誤りを調べる。数値演算と実数値の条件選択sziは、構成済み有理数値を扱う検査境界に置く。物理記録の検査ではseoc・sbw2・scb2と電磁力の和を実行する一方、全軌跡・内点・微分・全時刻の単位対応は明示した境界に置く。宣言したアフィン軌跡の有限照合を一般の実数微分の証明にはしない。全実数履歴を有限評価器へ渡すと拒否することも確認する。

磁石の種類、その物体に由来する場、周囲の領域、導体との相互作用への適用、起電力・エネルギーと導入全体の意味判断は未完である。物理法則の実証を翻訳の完成条件にはせず、採った物理量と適用規約を明示する。本文207主張と著者表示判断を保持し、今回の検査を原文単位全体の完成には数えない。
