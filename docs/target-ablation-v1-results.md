# 対象を伏せる前後の関連度差と、対象切替の評価

対象範囲を伏せる前後のスコア差で概念を選ぶ方式を実装した。新しい対象切替資料では、日本語9/17・英語11/17が正解だった。全文の関連度だけを使う対照よりは対象を区別できたが、対象だけの入力に対しては日本語で劣り、英語で同数にとどまった。翻訳器へ採用せず、同じ文の対象を切り替えて検査できる資料と評価器を残す。

## 固定した条件

[事前条件](target-ablation-v1-protocol.md)に従い、[前回の固定BGE reranker](pretrained-reranker-v1-results.md)と既存91概念を使った。原文の注釈範囲だけをモデルのマスク記号一つへ置換し、同じ定義について`full_logit - masked_logit`を計算した。学習パラメーター、語ごとの補正、指示文、生成処理は追加していない。

置換は文字範囲に対して行い、前後の文字と定義を保つ。ただし再トークン化による系列長や隣接部の分割の変化も含むため、差分を対象の意味だけの寄与とは呼ばない。関連度から語義の確率が得られるという仮定も置いていない。

観察済みv6に加えて、予測前に[対象切替資料](../data/target-switch-v1.json)を作成した。日英7組の文に各言語20対象を注釈し、うち既知17、未知3である。同じ文中の犬・猫・追う出来事、青さ・鳥・飲む出来事・水などを別々の対象として扱う。既存`data/**/*.json`の23ファイルとの原文完全一致は0件だった。[監査記録](../reports/target-ablation-v1/novelty.json)

この資料は小規模な手作りの語義注釈で、全文の意味構造を注釈したものではない。語彙の多くは観察済みで、公開モデルの事前学習資料との不交差も保証できない。

## 新資料での概念正解と対象の切替

| 方式 | 日本語の概念正解 | 英語の概念正解 | 日英とも正解 |
| --- | ---: | ---: | ---: |
| 対象だけ | 14/17 | 11/17 | 10/17 |
| 全文 | 4/17 | 5/17 | 2/17 |
| 全文からマスク後を引く差分 | 9/17 | 11/17 | 8/17 |

全文だけの方式は、同じ文の対象を変えてもモデル入力が変わらない。新資料では各文中の既知対象が異なる概念であるため、同じ候補を返す方式には各言語6/17という構造上の正解上限がある。全文方式に勝つことだけで、対象の意味を十分に識別できたとは判断しない。

既知対象を二つ以上持つ文は各言語6文あり、その文内で正解概念の異なる対象対は各言語17対ある。候補が変わった対数と、両対象とも正しかった対数を分けて集計した。

| 方式 | 候補が変わる対：日本語／英語 | 両対象とも正解：日本語／英語 | 文内の既知対象が全て正解：日本語／英語 |
| --- | ---: | ---: | ---: |
| 対象だけ | 16/17・16/17 | 12/17・6/17 | 4/6・2/6 |
| 全文 | 0/17・0/17 | 0/17・0/17 | 0/6・0/6 |
| 差分 | 14/17・17/17 | 6/17・7/17 | 1/6・2/6 |

英語の差分方式は全17対で候補を切り替えたが、両対象とも正しいのは7対だった。対象に応じて出力が変わることと、その意味を正しく選べることは一致しない。また、ここでいう文内の全対象正解は注釈した既知範囲の概念だけの一致であり、役割・否定・時刻・数量などを含む全文一致ではない。[全指標](../reports/target-ablation-v1/target-switch-evaluation.json)

## 観察済み資料と未知例

| 方式 | v6：日本語 | v6：英語 |
| --- | ---: | ---: |
| 対象だけ | 15/19 | 10/19 |
| 全文 | 8/19 | 11/19 |
| 差分 | 9/19 | 10/19 |

v6の全文方式と比べると、差分は日本語で3件を改善し2件を悪化させ、英語では2件を改善し3件を悪化させた。英語の`message`は改善したが、`drink`と`meet`は悪化した。対象だけの方式を上回る改善も確認できなかった。[v6の全指標](../reports/target-ablation-v1/v6-evaluation.json)

差分でも、未知例と既知正解の先頭スコアには重なりがある。例えばv6英語の未知例の最大値は約6.61で、既知正解の最小値約1.40を上回る。これは閾値で十分に分離できるという根拠にならない。今回は閾値を選ばず、全文の確定出力は0件である。未知を拒否できた、通常の自然文に対応した、意味構造一致率95%を満たした、という扱いにはしない。

## 検証と計算量

全443テストが通過した。反復語の指定位置だけを伏せる処理、日本語・複数語・句読点と定義の保持、差分の向き、同じ候補バイアスの相殺、非有限値の拒否、対象切替の正解指標を検査した。

固定モデルでは、原文とマスク後の文対4組について、反復・直接forwardとの完全一致を確認した。全層eval・重み固定、生成・辞書等の禁止経路5種の呼出し0回も確認した。再現検査ではモデルを再読込みして4組を再計算し、保存スコアから3方式それぞれ90行の予測・差分・集計を再計算して一致した。全ての文対のforwardを再実行したわけではない。[再現検査](../reports/target-ablation-v1/verification.json)

CPU float32・8スレッド・batch 16で、新資料40範囲の全文スコアは重複を除いた1,274組で約54秒、マスク後は3,640組で約156秒だった。差分方式にはこの両方が必要で、合わせて約210秒かかる。対象だけの対照は3,094組で約96秒。v6のマスク後4,550組には約195秒かかり、全文・対象だけの値は前回保存分をハッシュ検査して再利用した。モデル読込みや範囲抽出の時間は含まない。

実行環境はPython 3.12.10、PyTorch 2.13.0 CPU、Transformers 4.57.6。モデル、コード、全入力・出力、既存資料の監査対象のハッシュを[実行記録](../reports/target-ablation-v1/run.json)に保存した。

```powershell
artifacts/kwja-venv/Scripts/python.exe -m scripts.probe_target_ablation
artifacts/kwja-venv/Scripts/python.exe -m scripts.probe_target_ablation --verify-only
```

前回のモデルキャッシュとスコアが必要で、既存成果物は上書きしない。差分だけで語義一致へ変換する方法はこの条件では不十分だったため、関連度モデルの出力をそのまま翻訳の意味判定へ使う方針は採らない。対象切替の資料と指標は、今後の対象範囲を扱う判定器にも使える検査として維持する。
