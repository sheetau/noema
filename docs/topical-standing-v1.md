# 主題付きの行使能力と、その取得を可能にする支援

カントu0014の旧候補 `rll`・`rlm` は、主題を固定していたものの、能力を現在地で利用可能な方法だけで判定していた。一方、現在の第一段落の能力は、本人側の基盤を保った通常の機会で行使できることとしている。この不一致を除く比較候補を追加し、集団としての到達にも接続した。旧候補の語義と現行本文は変更しない。

`rqwm`・`rqwn` は非空の事柄の範囲を取り、その各事柄に結んだ閉じた活動記述から本人の目標内容を得る。同じ記述を活動別の六つの評価入力へ渡し、既存 `rqvv`・`rqvw` を使う。別に渡した目標との対応を呼出側の推測に任せず、記述から目標を取り出す。現在の機会がなくても既有能力はあり得る一方、新しい基盤を先に習得する方法は既有能力の証拠にしない。

本文用の `hzvg` は指定事柄についての自立的で理由に支えられた判断 `rlk` を返す。`hzvh` は事柄の閉じた参照記述からこの活動記述を構築する。構築するだけでは参照先や判断の真偽を評価しない。実際の能力評価では `hzvi` が各参照先と対象事柄の一致を確認する。参照が誤る事柄を対象範囲から除いて成功とすることはない。

`hzvj`・`hzvk` は評価済みであることと能力があることを区別し、元の本人・主題・基準時点で事柄を固定する。評価時点が支援後に移っても、その時点の容易な事柄だけへ対象を狭めない。事柄ごとに異なる行使方法を使ってよく、すべてを同時に処理できる一つの方法までは要求しない。

`rqwo` は指定実施者の全支援結果で能力評価が整うこと、`rqwp` は一つの同じ結果で本人の評価と能力が成立する支援方法が存在することを表す。本文用 `hzvl`・`hzvm` はこれに `hzvj`・`hzvk` を渡す。成功結果が一つあっても他の結果や同じ実施者の別方法に評価欠落があれば、可能性と全評価は異なる値になる。別人の能力や、事柄ごとの別々の成功結果を寄せ集めて本人の取得可能性としない。支援の実施済み、全結果での成功保証、集団全員への同時実施可能性は追加しない。

`hzvn`・`hzvo` はこの主題付き能力を前段の集団基準 `rqwi`・`rqwj` に接続する。到達と進行は区別し、評価の欠落を未到達として数えない。

検査は二事柄の能力の四組合せと八対照、支援の四組合せと七対照、十五種類の未知入力、原文用判断を実行する十条件、閉じた記述の構築と実行の区別、集団への三接続条件を含む。現在地で機会がない場合と、現在地で偶然できても通常機会ではできない場合について、旧候補と新候補を実行比較する。有限モデルの検査であり、現実の全人類・全主題・全方法の評価ではない。

宗教的な事柄の具体的範囲、`sicher und gut` の確実さと適切さ、不足の程度、集団基準の妥当性、問答・進行・徴候と著者帰属の統合は残る。理由に支えられた判断という条件だけでこれらを定義し終えたとはしない。原文の[当該箇所](https://korpora.org/Kant/aa08/040.html)に対する比較候補として記録し、全体確認済み十単位・604非空白文字を増やさない。
