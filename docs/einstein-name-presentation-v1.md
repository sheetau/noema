# 名称と人物を区別した著者表示

アインシュタイン正本の主張42（0始まり）を、前付の参照先を指定する定義とともに円文字へ接続した。元の主張は、同じ名称使用が同じ文脈で成立し、その名称を対象人物へ適用し、同じ使用が同じ文書の著者としてその人物を表示することを要求する。名称個体と人物が異なる条件も保持する。

## 参照値と関係の真偽を分ける

前付第2項目は固定原文の `einstein-1905:u0002`、`von A. Einstein.` に対応する。提示文脈を固定して、この項目に結び付いた名称使用・名称個体・対象人物・文書個体を一組の参照値として取り出す。参照値が得られたことから、名称の適用や著者としての表示を真にはしない。それらは元の三つの関係を保って別に検査する。

参照の組は、4個体を受け取る選択関数に、その4値を同じ順で渡す関数として記述する。4つの取り出し定義と組を作る定義はNoemaの型付き関数だけで構成し、文書内に本体を書く。役割を文書専用の番号表で解読する仕組みではない。

| 要素 | 保持する区別 |
| --- | --- |
| 名称使用 | どの表示で名称を適用するか。物理的な印刷行為や自筆署名とは同一視しない |
| 名称個体 | 名称を対象化した個体。人物本人とは区別する |
| 対象人物 | 同じ名称使用で指す対象。綴りの一致だけで同定しない |
| 文書個体 | どの論説の著者として表示するか |
| 提示文脈 | 前付の著者表示を読む文脈。本文の物理的設定や推論範囲とは区別する |

名称使用の成立・名称の適用・著者表示の三関係は、正本の `eira`・`eirb`・`eirc` と型・意味規約を同じにする。下位定義 `eiaa` と主張の定義 `eiab` は単射な改名で保持する。表示の真正性、実際の執筆者、自筆性、提示者と著者の一致は追加しない。

## 識別表記も本文から読む

既存の識別注記にある言語ラベル `de` と印刷上の識別表記 `A. Einstein` を、Unicodeスカラー値の有限列として本文に記述する。元の主張とは別の1主張で、その表記を同じ名称個体・提示文脈に結び付ける。これは既存注記を見える形にしたもので、人物の同一性を推論する主張ではない。

円文字を復号したNative本文から、対応JSONや元の注記を読まずにこの言語ラベルと綴りを再構成できる。正規化・大小文字変換・翻字は行わない。同じ綴りの異なる名称個体や、異なる名前で呼ばれる同じ人物を、綴りだけで統合しない。自然言語本文を文字列にして意味の記述を代用する機能としては使わない。

## 公開語彙と検査

任意プロファイル18は、共通基盤375語と文書参照3語の構成に5語を加えた383語である。新しい基本機能は参照の組を選ぶ `presentationrecord` と識別表記の `printedform`。残る3語は旧正本の関係の意味を共有する。共通基盤や旧第16版424語を置き換えず、特定の人物のための基本語は追加しない。

[閉じた文書](../examples/v016/einstein-name-presentation-v1.noema)には19宣言と2主張がある。局所13定義のうち5つは参照の組の構成と取り出しであり、公開辞書に新語として加えない。[対応資料](../data/einstein-name-presentation-bridge-v1.json)は旧10宣言・元の主張・各参照条件・注記との一致を記録する。円文字の復号にこの対応資料は使わない。

旧式と復号後の式を同じ解釈で比較する。三関係の真偽、名称と人物の相異、4つの参照位置、提示文脈、表記の成立を分けた22件の診断を行う。参照の組には二値の個体域を使い、一つの位置だけを変えた組で全4位置を検査する20件のNative診断を行う。これは引数結合の診断であり、全関係解釈の総当たりではない。

未知の前付位置・関係・識別表記は、既定の人物や偽で補わず拒否する。不正なUnicodeスカラー値・分数・空表記も拒否する。完全なモデルの全域関数と、既知の入力だけを扱う有限実行器を区別する。

```powershell
python -X utf8 -m scripts.project_work check --module scripts.check_einstein_name_presentation --prepare --tests tests/test_name_presentation_profile.py --verify reports/einstein-name-presentation-v1.json
```

[検査報告](../reports/einstein-name-presentation-v1.json)の対象は、指示条件を明示した著者表示の1主張と識別注記の可視化である。二論文全文の可視化と第三者による読解は引き続き必要である。旧正本・旧意味判断・固定字体は変更しない。
