# 事務に必要な仕組みと職務上の受動性

第五段落の `ist zu manchen Geschäften` から `passiv verhalten müssen` までを部分内容として接続した。`Nun` と後続の目的節は未接続であり、文全体の意味確認や確認文字数の追加はしていない。

必要性は、既存の `h232e` が表す、同じ目標へ向けて供給を求める条件として読む。この文の目標はその事務の遂行 `r2zt` である。求める条件の内容 `h232f` は、同じ事務に対して同じ仕組みが利用可能である `r2zw` と一致させる。世界全体の論理的必然、唯一の手段、実際の供給、成功の保証へは強めない。

仕組みは役割・指示系統・分担を結んで執行を組織する制度的な構成として分類する。物理機械の名前を与えるだけでは満たさない。共同体の利害に関わる事務とこの構成、必要要件、同じ成員の役割上の要求を `r2zx` で結ぶ。

本文の内容では基準を第五段落の `h232v` に固定する。内容を別の評価点で調べても、扱う事務、成員の範囲、役割上の要求をその点の都合で取り替えない。

受動性 `r2zu` は、その職務で外から与えられた方針に沿って事務を執行し、その執行の中で方針を自分の判断で独立に決め直すことがない、という二条件から構成した。何もしないこと、思考能力を欠くこと、職務外での議論の禁止とは区別する。方針を適用するための実務判断まで排除する読みでもない。後続の同じ人による学識者としての議論と両立できる範囲に留める。

要求には既存 `h7k` と前回の `r2zs` を使う。対象者は同じ基準で固定した非空の成員範囲であり、同じ人・役割・事務を三引数の `r2zv` に渡す。要求内容を実際に評価することはない。仕組みの存在と規範の出所、規範の存在とその正当性も分ける。一般の服従 `r2ud` の全記述域をこの受動性で置き換えない。

`manchen` は全称化しない存在読みとして部分構成した。他の事務には機構が不要だという否定は加えない。複数の種類を述べるニュアンスを含めた量化の適合は、目的節を接続した文全体の通読で確認する。

次には、同じ事務・成員・役割を、人為的協調を通じた政府の方向付け、または公的目的の破壊の抑止という目的内容へ結ぶ。`um` は機構の現実の成功へ交換せず、`wenigstens` の最低限としての提示も残す。本文の順序は今回保持したが、`Nun` の説明への移行は未構成である。
