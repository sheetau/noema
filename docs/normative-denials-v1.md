# 同じ契約内容に対する、異なる規範的な否認

カントu0013の「契約し、そうすると誓うことはできない」に対し、許可・禁止・権能を区別する部分草案を追加した。先行する集団と後続する集団、時代区分、契約の条項、改善不能を生じさせる目的を含む同じ行為内容を、規範の対象へ渡す。

| 定義 | 内容 |
| --- | --- |
| `rjp` | 適合する対象について、指定極性への積極的な許可がない |
| `rjq` | 同じ対象について、反対極性が要求される |
| `rjr` | 同じ対象について、反対要求と衝突しない許可がない |
| `rjs` | 適合する同じ主体・行使・規範対象について、指定の規範変更を生む権能がない |
| `hzdk` | 一個体の引数列を先行集団へ束縛し、既存`hzdf`の目的付き宣誓の成立内容を返す |
| `hzdl` / `hzdm` / `hzdn` | 既存の規範関係について、`rjp` / `rjq` / `rjr`を内容にする |
| `hzdo` / `hzdp` | 要求を変更する権能と、積極的許可を変更する権能の欠如を別々に内容にする |

許可がないことは、その行為が禁止されていることと同じではない。許可も禁止も指定されていない場合を表せる。一方、許可と反対要求が併存する場合には、積極的許可そのものはあるが、衝突のない許可はない。この場合を、許可の欠如へ書き換えない。

禁止と権能の不在も別である。ある行使が禁止されていても、行えば制度上の規範を変える場合を記述できる。反対に、行使を許可されていても、指定された規範を変える権能があるとは限らない。要求を変更する権能と、積極的許可を変更する権能も同一視しない。

否定に先立ち、対象の引数の適合性を要求する。権能の否認`rjs`では、行使の引数列の先頭が同じ主体であることと、行使・規範対象の双方の引数規約も確認する。対象が不正なために肯定判定が偽になった場合を、適切な対象についての否認とは扱わない。

実行時に規範や制度の情報が未知なら、否定関係も評価を拒否する。既知の情報に記録がないだけで許可や権能がないと認定する仕組みではない。検査用の有限解釈では、各関係の真偽を明示して、どの組合せを記述できるかを調べる。

具体的な規範の対象は、先行集団を一個体の引数列から受け取る`hzdk`の閉じた適用記述である。他の型付き引数は記述内に保持する。空列用の既存の政策記述を一個体列へ読み替えず、主体と行使の引数を照合する既存の権能構成にも同じ記述を渡せるようにした。余分な引数を捨てず、集団を差し替えた場合も同じ行使とはしない。

内容を評価する別の検査では、正しい先行集団を渡せば`hzdf`の引受け・宣誓が成立し、後続集団や空列・過剰な引数では成立しないことを確認する。規範だけを述べる際は、その内容を評価しない。宣誓・時代区分・知識・将来の候補・因果が未知でも、同じ内容に対する許可や禁止を記述できる。

また、権能が変更する規範の出所には、行為内容で指定した同じ契約を渡す。別の契約の規範を変更できることを、対象契約の権能へ流用しない。名宛人・役割・対象記述・引数列・前後の状況も保持する。ただし、ここでの権能の否認は指定した一つの規範変更に関するもので、契約全体の全ての制度的効果がないことを意味しない。

一般検査は、引数の適合性・許可・反対要求・同極性の要求・内容極性の32通りと、規範の前後状態・統制・制度上の認定の16通りを扱う。原文側は、許可・禁止・統制・認定・許可を生む効果の32通りと、別主体・列の過不足・別契約の対照例を検査する。

[一般文書](../examples/v014/normative-denials.noema)は2,762文字、[原文付き草案](../examples/v014/kant-normative-denials.noema)は135,554文字、[抽出文書](../examples/v014/normative-denials-core.noema)は15,439文字である。10定義を追加し、新しい原始記号・著者主張は追加していない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-normative-denials-basis-v1.json)と[検査記録](../reports/normative-denials-v1.json)を保存する。

関連24テストが通過した。三文書のCLI解析結果は構文木と一致し、通常表記・簡略表記・独自文字v2の往復を確認した。抽出文書のSVGはXMLとして検査した。字形の視覚的な確認を行った結果ではない。

原文のkann nichtをどの否認として読むかは一意に確定していない。集団が契約を代表する資格、評価側の規範の出所、制度的な正当性、権利・人間本性からの理由付け、任意の時代や契約への量化、著者帰属は未完である。複数の読解候補を全てカントの主張へ追加したり、物理的な実行不能へまとめたりしない。意味確認済み全文単位数は増やしていない。
