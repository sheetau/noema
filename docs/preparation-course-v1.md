# 方法の準備区間と、経験による能力取得

前段の比較例では、方法を範囲内に含めるかを一つの入力で与えていた。[新しい比較例](../examples/v016/preparation-course-example.noema)は、同じ本人・方法・基準状況に対応する準備履歴を使い、選んだ基礎能力を途中で取得するかどうかをNoema内で調べる。範囲を表す `zscope` は基本関係から合成定義に置き換えた。

基礎能力とは、この方法評価で取得の有無を調べる性質である。最終目標の達成可能性とは別に指定するため、同じ能力判定を自己参照して方法を分類しない。これは選んだ基礎能力の不在から存在への変化の説明であり、程度的改善や学習一般の定義ではない。

| 定義 | 条件 |
| --- | --- |
| `rqvf` | 履歴に厳密な順序と両端があり、準備区間の全状況で本人の基礎能力を評価できる |
| `rqvh` | その区間内に、基礎能力がない先の状況と、ある後の状況が存在する |
| `rqvg` | 区間の評価が整い、そのような変化がない |
| `rqvi` | 同じ区間について、既存の経験による取得 `r5` が成立し、経験時点も同じ履歴に属する |
| `rqvj` | 利用できる全方法について、分類に用いる履歴の評価が整っている |

時間の順序と閉区間には既存の `ta`・`rlz`、経験列と能力取得には `r4`・`r5` を使う。五つの一般定義を追加し、新しい基本関係や文法は加えていない。比較例の履歴・能力評価・経験・因果的寄与などは、引数の意味規約を持つ診断用入力である。

取得して後で失った場合、始点と終点だけでは変化を見落とす。`rqvh` は途中の変化も拾う。一方、経験の寄与が未確認なら `rqvi` は成立しなくても、能力の変化自体は成立し得る。したがって `rqvi` の否定を「取得なし」という方法区分に使わない。もともとある能力を失うだけの場合は `rqvg` を満たし得る。能力の維持や成功を保証する条件ではない。

評価不足では `rqvg` も `rqvh` も偽になる。その方法を単に除いて不能を判定すると、未知を不能へ置き換えてしまう。比較例では、範囲内の達成方法がないという `xg` に加え、全利用可能方法の分類確認 `rqvj` を要求する。範囲内の有効な成功例を確認できた場合には、他の方法の分類不足だけで肯定を取り消さない。

比較例は、全方法での自立的使用 `bb` の可能性、準備区間で基礎能力の取得を含まない方法に限った可能性、分類済みの不能を分ける。対象行為の時点が同じ方法の履歴に属し、準備終了より後であることも要求する。経験・過程・本人・時点と寄与を既存 `r5` で結ぶが、その心理的機構を自動で推定する処理はない。方法の名前から学習の有無を決めることもない。

検査は能力の有無と評価可否の64組合せ、途中の取得と喪失・区間外の経験・別の過程など11対照、五つの未知入力、方法評価の七比較を含む。通常・短縮・固有文字の往復を確認する。履歴は指定した一つの評価コースであり、全可能コースの網羅、現実の時間の粒度や完全性、基礎能力と方法範囲の選定は入力側の前提として残る。現在のカント本文と意味確認登録簿は変更せず、原文対応率と確認済み文字数は増やさない。
