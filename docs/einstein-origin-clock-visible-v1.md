# 原点時計の問いと遅れの円文字表現

u0118–u0125を、同じ時計についての一組の議論として円文字本文へ接続する。設定と問い、二つの座標式、比例時刻、厳密な遅れ、留保付きの近似という六つの既存主張をそれぞれ保持する。既存66定義を再利用し、時計の代替設定・実数値の問いの提示・時間単位換算の3規約を任意プロファイル60へ接続する。共通375語と固定アルファベットは維持する。

同じ時計がKに静止してtを示せる場合と、kに静止してτを示せる場合は、許容される別々の設定である。現在の思考設定ではkの原点へ置き、全対象時刻でτを正確に示す。代表位置の静止を、針や内部機構の全物質点の静止へ広げない。全ての表示候補と全時刻の存在条件を保ち、二つの都合のよい表示だけで代用しない。

進み率の問いは、Kから見た時間差に対する同じ時計の指示差の割合を尋ねる。問いの構成時に平方根の答えを入れず、答えの存在・一意性・発見済みも要求しない。著者による問いの提示と、その答えが成立することは別に扱う。

二式τ=β(t−vx/V²)とx=vt、および続くτ=t√(1−(v/V)²)=t−(1−√(1−(v/V)²))tは、同じ時計の同じ出来事を両系で記録した値に適用する。βとその逆数を区別し、全記録への適用と対応の存在を保持する。tは負でもよい座標時刻であり、この段階で正の経過時間へ読み替えない。

一秒当たりの遅れは、正の観測時間差と指示時間差へ同じ正の換算尺度を掛けて表す。その尺度を全記録対で共通にし、測定済みの一秒ちょうどの区間の存在は追加しない。厳密な係数1−√(1−(v/V)²)と二次近似(v/V)²/2を区別し、残差が零近傍でO((v/V)⁴)となる採用解釈を保持する。共通の定数・近傍幅・全近傍点への量化を有限標本へ縮めない。

本文位置は第57段落の設定と問い、第58段落の二式と、それに続く比例式・遅れの文へ接続する。比例式末尾のコンマを文末とせず、Sek.という略記でも文を分けない。秒の参照は後者の文のSekundeに結ぶ。時計の参照役割は同じ候補の能力と現在の配置を結び、秒の役割は同じ候補単位への正の線形換算を結ぶ。参照取得時に引用役割を実行せず、物理的存在や一意性の証明にはしない。秒の歴史的な実現方法は既存の意味規約の範囲に残る。

検査では、復号した定義へ既存の識別モデルを接続し、同じ証人・出来事・記録・尺度の結合、時刻の符号、全記録対、近似条件、引用の非実行を確認する。量化の本体は別に照合する。有限診断、円文字復号、採用した意味判断、独立した読解は区別する。後続のAからBへの時計の運搬はこの接続に含めない。
