# 測定長と対称性を円文字へ接続する

原刊902頁のu0101–u0104を第52段落の四文として参照する。端点の表示から測定長によるφの解釈へ進み、方向一般の対称性、速度反転の帰結、二つの分数の等値、φの値の一致への書換えを順に保持する。

測定長は、同じ系の同時刻における両端の現在記録と校正計量から得る正の距離である。二端の出来事は別でも時刻値は等しく、全履歴と対象区間の全実数時刻を保つ。先行する座標式から得られる距離はl/|φ(v)|であり、本文のl/φ(v)との一致には正の枝を選ぶ採用解釈がある。端点の代数だけからφの正値を証明したことにはしない。

比較する棒は同じ全物質点、固有形状、固有長、二端を持つ。K/kと尺度も同じであり、配置の位置と向き、各設定の時計原点は変えられる。非零かつ光速未満の全速度ベクトルに適格な設定が存在する理想化した比較群を保持し、その全範囲で同速なら測定長が一致する。長さが一致する設定だけを候補に選ぶ条件は加えない。正負二方向の例だけでは、この主張の範囲を代用できない。

空間的な対称性を理由とすること、明白だと述べること、内容を採用すること、帰結を示すことは別の論述関係である。速度反転では同じK/k、棒、φを保ち、異なる設定でvと−vを比較する。Hieraus folgtの分数等値に続くoderは、同じ正のlと非零φの下でφ(v)=φ(−v)へ同値に書き換える提示である。φ=1は次の段落に残す。

測定長の候補は「状況から切断への関数」として参照する。各設定で測定が成立するときに同じ長さを返す閉じた役割を本文に記述し、測定のない設定の値は指定しない。逆向き設定も同じ棒と符号付き速度の条件で参照する。参照取得はこれらの役割や候補関数を実行せず、物理条件の成立や唯一性を証明しない。
