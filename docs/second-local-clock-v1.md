# 点Bの時計と同じ構成という追加条件

固定原文u0013第二文[252,560)、234非空白本文文字を原刊893頁末から894頁冒頭へ照合した。M0005・M0007・M0008は点B、M0006は先行する点Aであり、それぞれ既存zir・ziqへ固定する。頁境界A0005は文の意味に新たな要素を加えない。

A側の設定を引き継ぎ、Bにも時計を置くならBの観測者もその直近の出来事を時間的に評価できる、という条件付きの可能性を記述する。局所評価の定義は第一文と同じものを使い、時計・観測者・表示・課題・場所をB側へまとめて結ぶ。二時計の同期や共通の読みの原点はまだ要求しない。

「全く同じ構成」は、両時計に共通する完全な構成記述の規約の下で、全特徴の内容が正確に一致するという読みを採る。各特徴の記述集合について、非空性と双方向の包含を確認する。共通する特徴を一つ持つだけ、外見や型番が同じだけ、現在の読みが一致するだけでは成立しない。規約は材質・配置と結合・周期生成と指針表示の構成・固有応答を扱い、個体番号、所在地、初期の指示位相は含めない。

この一致は条件として付け加える内容である。著者がその条件を付け加えたいと述べる意思、ダッシュ内への挿入、時計の追加と局所評価の追加という二つのauchを別に保持する。時計の構成一致を実測済みとする断言へ替えない。

有限例は全特徴と記述の結合を調べる検査であり、実機の完全一致の証明ではない。第三文以降の共通時間と同期の導入は残る。
