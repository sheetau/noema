# 君主ごとの功績と評価基準の範囲

第八段落第一文の一般条件に、君主ごとの解放の証人と、比較評価・称揚適合の基準の供給元を結ぶ。8定義r52q–r52xと2基本関係h26n5・h26n6を追加する。本文112主張・登録簿v196・確認済み17単位は保存する。

## 人物ごとの出来事

前回のr52pは具体的な出来事を外部で固定した接続例であり、そのままでは全君主へ一つの活動・政府・受益者を要求してしまう。今回は各君主への結論の内側で、活動・政府・前後人口・受益者・前状態・行為点・結果点を選ぶ。前件と後件の役職・共同体・固定基準は共有し、現在世界と後代の範囲も同じまま保つ。

選んだ全引数はr52vの同じ解放へ一緒に渡す。一人の活動を別人の功績へ流用したり、複数の不完全な出来事の一部分ずつを合わせたりしない。本人の能力と功績への称揚適合は同じ現在点で連言する。条件に合う君主がいない場合に一般条件が真でも、そのことから君主の存在や解放の実在は導かない。

## 比較評価と規範の供給

r52qは既存r52aの、人・活動・結果点を引数に取る時点別人口の解放関係を閉じる。h26n5はこの同じ関係についての評価完備を表す。評価が済むことと、その人物の成功は別である。未評価を先行達成の不在にせず、別の基準や履歴の評価済み情報を使わない。これは解釈モデル上の評価の条件であり、著者が現実に全歴史を調査したという主張を補うものではない。

h26n6は同じ人物・役職・共同体・応答者集団・時代・固定基準における、応答適合の全条件の有限列を供給する。各条件はNoema関数で、同じ人物・応答記述・功績記述から内容を返す。r52vは現在世界と後代の双方に別々の全列を渡し、既存の非空・全条件の判定を保つ。検査用の常時真を本文へ固定せず、特定の倫理学説、数値的功績点や称揚の義務を原文に補わない。

比較評価の関数記述には段階1が必要になる。功績引用と具体的接続について、評価入力の段階だけを上げたr52t/uを置き、元の定義は保存する。功績は段階1、恩恵の状態は0、応答は1を保つ。r52u自体には段階1の評価関数の脱引用があるため、その全体を引用する際は少なくとも段階2が必要である。
