# 同伴する直接測定と同期時計による端点測定

u0030の方法aは、観測者が先に用いた物差しを伴って棒と共に動き、物差しを直接当てて棒の長さを読む操作である。棒・物差し・観測者の巨視的配置を静止系では同じ速度の並進、同伴する系では静止として記述する。同じ物差しと長さ単位を保ち、初期測定に登場した観測者が必ず今回の観測者だったとはしない。

末尾の「静止しているなら行うのと同じように」は、物差しを当てて直接読む手順の比較と読む。両側を一つの直接測定規則eipzに接続し、比較する系を分けた。比較側の静止を現実化したり、二状況で得る長さの数値が同じだと結論したりはしない。原文は次のu0032で相対性原理から長さの一致を述べるため、その結論をこの手順の比較へ前倒ししない。

u0031の方法bでは、静止系に設置された静止時計を用い、一つの指定時刻tにおける両端の場所を確定する。両端の出来事・場所・局所時計・その場で同時に生じた表示を第一節のeingへ結び、同じ参照時計rcと時間単位rbを使う。両端の値は同じxvに一致し、その時刻は棒の運動を扱う区間内にある。端点の世界線と同じ三座標にも接続し、別の出来事や遠隔での受信時刻を混ぜない。

さらに同じ物差しを、今回は静止系で静止させて二地点の距離を測る。二地点の距離th、同じ観測者・物差しによる測定xh、同じ指定時刻における棒の軸長を一つの値へ結ぶ。観測者自身の静止は追加しない。方法aとbは別の測定設定であり、同じ物差しが相対運動する両系へ同時に静止するとは主張しない。

改頁後の第二文は、この距離も「棒の長さ」と呼び得ると述べる。二つの操作で得る候補値を同じ量の呼称へ含める許容として記述し、呼称の使用を義務にせず、値の一致・相違・存在・唯一性も補わない。先行の二方法への問いは保持し、旧sbi/sbkを含む具体的な操作条件を同じ方法の箇所へ接続する。
