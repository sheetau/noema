# 対象の全列挙と、存在を分けた人数の上限

カントの段落末にある少数者の数量表現へ向け、指定範囲の全員を重複なく数える構成を追加した。該当人数が上限未満であることと、該当者が少なくとも一人いることを分ける。成功した自立や確かな歩みの条件は、まだ性質引数として残している。

## 全体を数える条件

既存の `hi` は、列の各個体が適格で重複しないことを調べるが、適格な個体の抜けまでは調べない。新しい `rcm` は、個体が指定範囲に属することと列に現れることの同値を、全個体について要求する。指示関数の規約、非空性、重複の不在も検査する。

これにより、対象のうち都合のよい一部だけを並べた列は拒否される。ただし、完全性は指定した範囲に対する条件である。範囲そのものが現実の評価対象を正しく指定することや、有限の評価モデルが現実の全員を含むことを保証するものではない。無限の範囲を有限列で完全に列挙することもできない。

## 上限と存在

`rcn` は `rcm` の下で、性質を満たす人数が、与えた正の有理数の上限より厳密に少ないことを表す。`rco` はさらに、その人数が正であることを要求する。対象範囲が空の場合は両方とも拒否するが、非空の対象範囲で該当者がゼロなら、正の上限に対して `rcn` だけが成立する。

人数は通常の真偽の指示関数と有理数の加算を使って数える。上限を1.5とした場合も、人数1は通り、人数2は通らない。上限と同じ人数は拒否する。列を並べ替えても人数は変わらず、性質が未知の場合は評価を停止する。未知を偽として人数を減らさない。

人数が少ないことと、母集団の半数未満であることは同一ではない。小さい母集団では全員でも絶対人数として少ない場合がある。そのため、半数という閾値は固定しない。相対的な基準を使う場合には、母集団の人数から上限を求める規則を明示する。

## 原文への接続候補

`h4i` は基準文脈で評価する人々の範囲を指定し、実際に人であることは既存の `aa` でも要求する。`h4h` は、全人数と同じ基準文脈から上限候補を返す。原文に具体的な数値があるとしたものではなく、適切な上限や比較基準は未確定である。

`h4j` はこの範囲・文脈・上限を `rcn` に接続し、指定した性質を同じ文脈で満たす人を数える。`h4k` は `rco` に接続し、存在を追加する候補である。どちらを原文の最終的な読みとして採るかは確定していない。

今回の対応範囲は[電子本文 AA VIII 36、13行](https://korpora.org/kant/aa08/036.html)の少数者を述べる短い表現であり、空白を除く9文字である。先行する推論接続、期待との対比や焦点、後続の成功・自分の精神への働きかけ・確かな歩みは含めていない。二つの数量候補を新しい本文主張として追加せず、前版の13主張を保持した。

## 検証

3個体について、長さ0〜3の列と対象範囲の320組を独立した集合の計算と比較した。正しい全列挙について、並べ替え・性質・整数と分数の上限を変えた576組も検査した。対象者の抜け、成功者だけの標本、範囲外の個体、重複、ゼロ該当者、上限との等値、小さい集団の全員、誤った指示関数を区別した。

原文接続の11例では、対象範囲・性質・上限に同じ基準文脈を渡すこと、母集団の人数に応じた上限、人数の境界と存在条件を確認した。関連25テストと保存した検証記録の再生成一致が通過した。通常・短縮記法と固有文字の往復、2文書のCLIによるJSONと構文木の一致、SVGのXML形式も確認した。字形の目視検査は今回行っていない。

一般用文書は既存の算術用基本関係4・定義11であり、一般用の新しい基本関係や文法は追加していない。原文接続文書は基本関係215・定義330・主張13で、前版から基本関係2・定義5・654文字増えた。正規形は50,206文字であり、以前の本文と定義も含む長さである。

原文の数値基準・存在含意・焦点、対象範囲の現実への対応、数える性質の接続と全文の意味一致確認は未完である。この構成を追加したことは、成功者の人数を原文から判定できるようになったことを意味しない。
