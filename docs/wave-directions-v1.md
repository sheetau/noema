# 波の位相・周波数・方向の変換（2026-10-14）

アインシュタイン1905の第7節へ、位相、ドップラー効果、光行差の数式の部分草案を追加した。新しい基本関係は使わず、既存の有理数演算と実数の下側切断から構成する。光源・観測者・波の測定との対応、平面波の近似条件や振幅の説明は別の課題として残す。

## 記述した式

光速度を $V>0$、符号付きの相対速度を $v$、比を $r=v/V$ とする。原文の β は正の $1/\sqrt{1-r^2}$ であり、方向余弦 $a,b,c$ は $a^2+b^2+c^2=1$ を満たす。適用範囲は

\[
|r|<1,\qquad \omega>0
\]

である。同じ入力に対して、変換倍率と四つの変換値を次のように構成する。

\[
g=\beta(1-ar),\qquad
\omega'=g\omega,\qquad
a'=\frac{a-r}{1-ar},\quad b'=\frac b g,\quad c'=\frac c g.
\]

`sdl2`は入力の許容条件、`sdm2`は分母、`sdn2`は周波数、`sdo2`は縦方向の余弦、`sdp2`は横方向の余弦の値を表す。`sdq2`で、同じ入力と変換後の四値を結ぶ。角度そのものと、その余弦を混同しない。

通常の周波数 ν についても同じ倍率を使う。ただし、角周波数 ω と ν の値を等しいとはしない。今回の検査では、正の共通尺度倍と周波数変換が可換であることを確認した。両者の比例定数や周期の定義全体は含めていない。

平行方向 $a=1$ では、`sdr2`により

\[
\nu'=\nu\sqrt{\frac{1-r}{1+r}}
\]

を構成する。平方の等式だけでは負の枝も許してしまうため、有理数の条件`sdk2`では変換後の周波数が正であることを要求する。垂直方向 $a=0$ では、縦方向の余弦が $a'=-r$ になることも検査した。

位相は、同じ周波数・方向余弦・四座標を使って`sds2`で構成する。

\[
\Phi=\omega\left(t-\frac{ax+by+cz}{V}\right).
\]

原点を合わせた標準配置の変換

\[
V\tau=\beta(Vt-rx),\qquad \xi=\beta(x-rVt),\qquad\eta=y,\quad\zeta=z
\]

と、上記の周波数・方向の変換を併用すると、同じ位相を保つという多項式の性質を確認した。任意の原点定数や位相定数まで今回の式に含めたわけではない。
