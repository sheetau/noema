# 学習済み多言語意味役割モデルの転用試験

## 目的と方式

Noemaの15概念ごとに学習例を増やす方法から離れ、既存の述語・項構造の学習を利用する。[Unify-SRLの公開実装](https://github.com/SapienzaNLP/unify-srl)と、同リポジトリが配布する `xlmr_ft_full_all` を調べる。XLM-Rと分類・系列符号化層の学習済み重みをすべて固定し、Noema用の追加学習はしない。

このモデルの公開コードは、述語・語義・役割を分類する。文章生成や指示プロンプトは使わない。英語PropBankとVerbAtlasを含む複数の出力体系を持つ。[原論文](https://aclanthology.org/2021.naacl-main.31/)の方法が日英のNoema変換にも有効かは未検証である。日本語は公開学習設定にないため、転用の結果を日本語で学習済みの性能と呼ばない。

公開評価コードは正解の述語位置を入力する。今回の主試験では、述語位置もモデルで予測する。正解位置を与える診断を実施する場合には別集計とする。

## 固定する入力と計数

[16組の入力](../data/srl-transfer-v1.json)を予測前に保存する。役割の逆転、能動・受動、省略、否定、数量・時間、既存の語彙にない述語、従属節、関係節、条件、複数文を含む。人工の小資料であり、一般文全体を代表しない。

モデルには各言語の原文だけを渡す。単語と文の境界はStanzaの学習済みトークン分類器で予測する。生成型のMWT展開器や見出し語辞書は使用しない。原文中の文字位置を保持し、Noemaの概念辞書や原文の語形表による補正を挟まない。学習済み分類層の出力ラベル一覧と、訳文検索用の辞書を区別する。

判定対象は、指定した述語の検出と、その述語に対するPropBankの役割付きの項の主要語の抽出である。正解の文字範囲と予測した単語範囲の重なりで位置を照合する。日本語の「承認する」のような複合述語は意味を担う部分を指定する。これは語全体の厳密な範囲一致ではない。ラベルは完全一致を求める。

- 言語別に、指定述語の検出数、指定役割の正解数、各文で指定した条件がすべて成立した数を報告する。
- 余分な予測を含む全出力を保存する。この部分注釈では、追加の正しい述語と誤検出をすべて区別できないため、精度や全文構造完全一致率と呼ばない。
- 省略例について、主体を出力したかを別に確認する。
- 否定・時間・数量・条件の意味構造を復元できたとは数えない。役割が合っても、これらが欠ければNoema翻訳として未完成である。
- 同じ入力を反復し、出力の一致を検査する。モデル・前処理・実行環境・重みのハッシュを保存する。

評価資料の文字列は位置照合だけに使い、推論や訳文検索へ渡さない。成績を見て語別規則を追加したり、未対応の例を評価から外したりしない。

## 採用判断

役割抽出の候補部品として検討し、単独で本番翻訳器へ接続しない。名詞の概念、否定の作用範囲、時制・数量、文間参照などを保持する別の仕組みが必要である。既存フレームの番号をそのままNoemaの永久的な語彙にしない。得られた関係を表せない場合はNoemaの言語仕様側も拡張対象となる。

元の意味構造一致率95%以上、広い自然文の翻訳、辞書・ハードコードに依存しない双方向変換の要求は維持する。この部分試験の良い成績だけでは完成判定しない。
