# 保存した本文を同じ流れへ接続する

## 先行計画

既存の複数項目読取と折返しを使い、保存済みの各本文を水平方向へ移動して接続する。円・内部の線・枝は描き直さない。三本の罫線も動かさず、前項目の主流末尾と次項目の主流先頭を実図形から求める。追加するのは既存の入射・曲げ・間隔規則に従う接続線だけとする。語の境界が必要で、既存の無線接続規則を満たす場合にはその境界を使う。

不足しているのは保存図形どうしの接続であり、新しい意味関係ではない。文頭記号、項目番号、原文ごとの特別な字形は追加しない。接続後は、公開辞書から実図形を読み、別々に読んだ項目列と宣言・綴り・束縛を含めて一致することを要求する。うまく接続できない組は明示的に失敗させ、枝の省略や別の構文への置換で成功扱いにしない。

この接続器が扱うのは同じ三罫線上の完結した項目である。行へ移動した後の断片を直接接続するものではない。接続後の流れを既存の折返しとページ分割へ渡す。40項目全体の段落組み・外観確認の完了とは区別する。

接続可能性は限定した候補で調べる。例えば、文末と次の文頭が複合語として連続して読まれてしまい、必要な無線境界の両端が水平に揃っていない既存図形は、この方法では接続できない。その場合に語を読み替えたり、大円を中央罫線から移したりはしない。既存の項目列生成器で境界を含めて配置するか、別の流れとして組む必要がある。
