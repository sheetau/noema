# 状態の成立と、その状態への移行

[変化過程の定義](../examples/v014/transitions.noema)を追加し、[カントの解放の草案](../examples/v014/kant-release-transition.noema)へ接続した。以前の草案は「十分前の時点で、自然的な成人の状態にあった」という条件にとどまっていた。この版では、前後の状態、変化過程、その変化を受ける本人を結び付ける。

## 二つの状況を並べるだけでは過程にならない

tgは、同じ順序付き履歴に属する二状況が厳密に前後し、指定した変化過程がその二状況を結ぶことを要求する。thはさらに、ある内容が前では成立せず、後で成立するという条件を加える。既存の関数・命題内容・量化だけで構成しており、新しい構文は追加していない。

後の状況で内容が成立していても、過程が存在しなければthは成立しない。前から同じ内容が成立している場合も、その過程の前後で成立するようになったという条件は満たさない。前後を逆にした場合、同じ状況を両端にした場合、履歴外の状況や循環した順序、別の過程を使った場合も拒否する。

これは過程の前後条件であり、内部の連続性、変化の唯一の瞬間、因果機構まで主張しない。現実にその過程が起きたという関係自体は、解釈の前提として渡す。

## 本人の移行として記述する

カント草案では既存agを変化過程の関係として再利用する。追加したlaは、その人が指定された過程の前後で状態変化を受ける対象であるという関係である。本人が単に過程を見ていた場合や、同時に起きた別人の過程を流用する場合とは区別する。

klは、自然的な発達上の依存によって、本人と異なる他者の指導が必要な状態を表す。kmは次を一つの条件として結合する。

1. 前ではklが成立し、自然的な成人の状態kcは成立していない。
2. 後ではkcが成立する。
3. 同じ本人を対象とする変化過程が、その前後状況を結ぶ。
4. 後状態は、既存の生涯の評価範囲より文脈上十分前にある。

kfを、kmを満たす前後状況と過程が存在する内容へ更新した。後続の譲歩kgと割合kh・kiは同じkfを参照するため、この移行が同じ人々の先行条件として使われる。旧文書は比較用に保持し、旧版の意味を上書きしない。

これは「解放」を過去の依存からの移行として読む候補であり、前状態の依存を明示的に要求する。自然的成人や依存の一般的な説明、自然を宣告者に見立てる比喩、ラテン語の独立した語義確認、過程の具体的な機構は残る。怠惰・臆病の原因説明や後見人の容易さ、段落の残部も未完成である。確認済み全文単位数はカント0/20・アインシュタイン0/282のままである。

## 検証

前状態・後状態・過程の有無の8組合せと、不正な結合の5例を検査した。原文へ接続した12例では、過程の欠落、別人・別過程、前の依存の欠落、本人への指導だけ、後にも残る依存、時間範囲の誤りを区別した。

旧条件との3比較では、過程がない場合と過去の依存がない場合に、旧版の「先行する状態」は成立しても新版の移行条件は成立しないことを確認した。肯定モデルでは、移行・譲歩・割合までを結合して評価した。具体的な有限モデルでの検査であり、原文の唯一の解釈や現実の人々の生涯を証明した結果ではない。

```powershell
python -S -m scripts.check_transitions --verify-only

```
