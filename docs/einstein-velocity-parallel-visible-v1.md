# 第三系・別導出・平行変換群の円文字接続

原刊906頁から907頁へ続くu0147–149を、固定された円文字と既存profile64の861語で記述する。既存の56定義を再利用し、新しい基礎語や参照演算子を追加しない。親文書の原文149主張・注記32件に、この選択の5主張と第三系の呼称k′の注記1件を接続する。

第68段落は二文として位置を定める。第二文は表示式M0285と改頁後のtritt;を含み、群の主節とその中の必要性の挿入句まで続く。第三系の導入、速度置換、群の主節、挿入句には異なる範囲参照を与える。呼称は同文で新たに導入する呼称の第一番目として参照し、対象の第三系への命名を別に保つ。

第三系はK/kとは別に導入される座標系として参照する。第三系の速度は同じkに対する並進と符号付き光速未満の条件で記述し、前の点速度とは補助設定の中だけで結ぶ。過去段階と既出方法は別の型で参照する。方法の役割は同じ段階のejpb→ejpc→ejprの手順を指定する。これらの役割は引用した定義の照合に使い、参照検索で内容を実行しない。

群の定義域は負と零を含む−V<v<Vであり、同方向の点速度の条件へ縮めない。同じ合成速度を四座標式とβへ渡す。必要性は同じ数学的前提を満たす非空の全評価状況について述べ、群であることを候補の選定条件に含めない。著者の提示と実際の一般的な証明の健全性は区別する。

検証では元の採用解釈への復元、親の宣言・主張の保持、各参照引数と変数の結合、符号付き速度・四成分・非空の必要性を検査する。有限診断は全実数域の証明ではない。円文字の復号、描画確認、独立した人間の読解も別の証拠であり、この文書の作成だけで検証済みとはしない。
