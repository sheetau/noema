# 移動系の同時刻結線と波面法線

u0193の原刊912頁は、φ′を移動系の波面法線（光線方向）と結線「光源―観測者」の間の角として導入する。M0339はa′、続くM0340は `cosφ′=(cosφ−v/V)/(1−(v/V)cosφ)` である。基準線を速度方向へ置き換えると通常の式になるが、その変更を固定本文へ暗黙に持ち込まない。

ここでは結線を、同じ移動系kの同時刻に取る源から観測者への向きと読む。Kに静止する源のモデル位置は−R(a,b,c)。新時刻τを固定してLorentz時間変換を解くと、旧時刻は `τ/γ−vRa/V²`、源の新位置は `(-Ra/γ−vτ,-Rb,-Rc)` となる。旧時刻をτへ置換してから空間変換を行うと、同時刻の結線にならない。

有限な観測者位置pと新時刻τを固定すれば、源からの変位は `(p_x+vτ,p_y,p_z)+R(a/γ,b,c)` である。`L=|(a/γ,b,c)|` としてρ=RLへ尺度を変えると、既存の源配置−ρnに対する遠距離方向の定義を再使用できる。結線の極限方向は `(a/γ,b,c)/L`。同じ波の変換後法線 `(a−v/V,b/γ,c/γ)/(1−av/V)` と区別する。

二つの単位方向の内積、非負の正弦、既存の積分に基づく角の枝を結び、0からπまでの実数角を構成する。物理的な設定では先行の波・観測者の全条件を保持し、同じ源の新曲線族をeisskへ対応させる。結線の方向と角度を指定する条件へ、M0340の等式を混ぜない。

この読解では表示式と一致しない例がある。V=5、v=3、旧方向(0,1,0)では、新波面法線は(−3/5,4/5,0)、同時刻結線の極限方向は(0,1,0)。角の余弦は4/5だが、M0340の右辺は−3/5となる。これは印字や歴史的意図の訂正ではない。採用した字義的な結線読解と、著者が提示する式の真理を分けるための対照である。

今回追加するのは、この幾何学と条件内容の依存群である。φ′の命名、括弧内の光線方向との同定、a′の式をこの形にするという提示、コロンと表示、著者への帰属を次に接続する。u0193–u0194をまだ全単位確認済みには数えない。既存375主張と判断を保持し、新しい一般基本関係は追加しない。

検査では新旧の全四座標、有限位置からの尺度変更、同じ波の二方向、全65設定引数と61全称位置を確認する。平方根を有理数で厳密に評価できる対照と、角の積分部分だけを明示的に差し替えた枝の検査を区別する。全実数の極限や積分を有限標本へ縮めず、未知の値は拒否する。
