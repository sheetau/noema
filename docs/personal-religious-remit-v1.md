# 本人への委任と君主の所管

カント第六段落第十一文の `u0013[3353,3488)` に向け、[同じ臣民と本人の必要性判断](personal-salvation-judgment-v1.md)を、君主の非指図・非介入と所管外へ接続します。kannによる許容、Wennの監督条件、nur/übrigens/wohl aberの限定と対照、後続の妨害防止を含む全文はまだ統合していません。

本人に委ねるlassenは、本人が自分の救済について判断し実践を選ぶ立場で、君主が実行も不実行も要求せず、本人に代わる決定を押し付けたり権威的・強制的に妨げたりしないことと読みます。指図がまだ執行されていなくても、指図なしに実力で介入していても、この条件は満たしません。積極的な許可の発令、臣民の実際の行動や救済の成功は要求しません。

同じ営みでも、宗教上の正否・必要性を本人が決める立場と、外的な行為について市民的秩序を守る立場を区別します。前者を引用する内容族の対象列に明示し、後者の規律まで否定しません。「秩序」と呼べば宗教的支配が許される例外も設けません。この区別を全文で前半の実効的監督と後半の暴力的妨害防止へ結ぶ必要があります。[原文AA VIII 40頁](https://korpora.org/kant/aa08/040.html)はこの両側を同じ一文に置いています。

「君主には関わりがない」は、救済上の必要性を本人に代わって公的に判断する所管・職責がないこととして読みます。君主が無関心だという心理や、何も要求していない事実とは別です。同じ最高統治職と、同じ本人・営み・目的の必要性内容を保持し、その内容を所管の判定時に実行しません。

全称の対象は、同じ固定基準での臣民と本人の営み・救済目的です。各候補の呼称が元の対象を指すことを確認した上で、本人が必要と考える全候補へ委任と所管外を結びます。後に本人の信念が変わったことや、呼称が別の対象を指す不備によって、元の対象を全称の範囲から落としません。

検査は、両極性の規範、実際の介入、所管の独立性、第二の臣民への不備、固定基準と評価点の区別、呼称不備、引用内容を実行しないこと、対象列・引用段階・未知入力を扱います。君主の役職内部と以前の判断範囲は保存済みの個別検査を境界として再利用します。本文106主張と意味確認済み文字数は据え置きます。
