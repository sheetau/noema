# 全文検証用の原文単位

保存した2作品のHTMLから、著者本文を含む領域を区切り、原文単位と数式・注参照を抽出した。選択した領域内の非空白テキストを、原文単位、数式、ページ表示、注参照のいずれかへ一度ずつ割り当てた。原刊の画像との照合は未完了で、この検査だけで転記の正確さまで保証しない。

## 抽出した範囲

| 対象 | 原文単位の内訳 | 別保存した数式 | Noema全文対応の確認済み単位 |
| --- | --- | ---: | ---: |
| Einstein 1905 | 前付2・本文等173・見出し12・独立数式91・著者注4 | MathML 446要素 | 0/282 |
| Kant 1784 | 前付7・本文等12・著者注1・編集見出しと編集注6 | 0 | 0/20 |

「本文等」には署名、日付、短い接続句も含む。段落を文数として数えない。数式446要素は本文中の変数や注中の式も含む数で、独立数式91単位とは異なる。カントの編集資料6単位は保存するが著者全文の分母から除く。

アインシュタインでは891〜921の31ページ表示、カントでは481〜494の14ページ表示を取得した。ページ表示の連続性は欠ページの検出に役立つが、ページ内の転記漏れがない証明ではない。

アインシュタインの非空白テキストノード4,364個、カントの180個を全て割り当てた。MathMLは元HTML中の開始・終了位置と生のマークアップを保持し、分数・指数・根号などを平文へ平坦化していない。本文中では`[M0001]`などの参照に置き換えて保存する。この記号とMathMLは検証用の原文資料であり、Noemaの記述ではない。

注の参照先IDは注の本文単位へ対応する。カントの最後にある`*)`の段落は著者注で、Wikisourceが付けた5件の注とは分けた。編集注に記載された原刊の誤植・修正も、後の照合で確認する必要がある。

## 再現と成果物

```powershell
python -m scripts.segment_written_sources
python -m scripts.segment_written_sources --verify-only
```

初回は[保存元の記録](../reports/written-sources-v1.json)のSHA-256と一致するHTMLだけを処理する。原文と数式の実体は`artifacts/written-units-v1/`、全単位のID・内容ハッシュ・種類と集計は[原文単位の記録](../reports/written-units-v1.json)へ保存した。既存成果物は上書きしない。再現検査では保存したHTMLから抽出し直し、全内容と集計が一致した。

画像・表・動画など、まだ抽出方法を定義していない要素が著者領域にある場合は拒否する。今回の両領域にはこれらの要素はなかった。空白だけの表示要素は記述単位にしない。HTML外側のサイト案内や本文書誌表は対象領域外とし、元HTMLには残している。

7件のテストで、インライン装飾による語の分断、HTML実体参照、数式構造、注と編集資料の区別、ブロック間のテキスト、未対応要素、壊れたHTML、未解決の注参照を検査した。

## 原文から確認した言語側の不足

カントの冒頭`kant-1784:u0008`は、単なる人物と属性の関係では表せない。以下を区別する必要がある。

- 自分の判断力を使うことと、他者の指導なしで使うこと。
- 実際に行わないことと、行う能力がないこと。
- ある状態にあることと、その状態から脱する変化。
- 判断力の欠如が原因である場合と、決意・勇気の欠如が原因である場合。
- その内容の主張と、読者への呼びかけ、引用された標語。

0.8の真理値に対する否定・含意だけで能力や原因を代用すると、これらの区別が失われる。次の拡張では、内容を指す式を導入し、能力・規範・発話者の態度を、現在の真偽と混同しないようにする。これは原文を手動で読んだ要求分析であり、完成した意味対応の判定ではない。

アインシュタインの`einstein-1905:u0016`と`u0017`は、同期関係の対称性と、共通の時計に同期する二時計の関係を述べる。量化・条件・関係の部分は0.8で書けるため、[部分草稿](../examples/v08/einstein-synchrony-draft.noema)を作成した。例の基本記号は次の仮の解釈を持つ。

| 記号 | 仮の解釈 |
| --- | --- |
| `aa(x)` | xは時計 |
| `ab(x,y,r)` | xとyは基準系rで同期して進む |
| `ac()` | この節で導入された静止基準系 |

草稿では時計の型条件と、同じ基準系への参照を両式に残した。しかし、時計・同期・基準系の概念はまだNoemaで定義していない。地点A/B/Cとそこにある時計の結び付け、先行する光往復の定義、著者がこれらを仮定するという発話上の位置付けも未記述である。したがって、2単位を対応済みには数えない。

後続の時間・光速度の式では、0.8の有理数型を物理時間全体と同一視できない。数量・単位・実数や関数の理論と、数式の仮定範囲が必要になる。文書内の関数宣言だけでこれらを意味説明済みにすることはしない。
