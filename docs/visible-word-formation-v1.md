# 語形の合成と定義による命名

## 対象と再利用する機能

前段の公開3語は、語形の衝突を解消する最小対だった。語を増やすたびに新しい基本図形を割り当てる方式では、学習する字形の数も増え続ける。ここでは既知の語形を有限列として組み合わせ、新しい語の綴りを作る。部品の順序、複合名と固有名の区別、語の終端を可視化することを一つの作業単位とする。

円の寸法、三本の基準線、接続、既知語の内部形状は変更しない。意味の導入には既存のNoemaの型付き定義を使う。新語一つにつき新しいprimitiveを追加することはしない。新語の綴りを読み戻すことと、その定義を含む文書全体を円文字で読み戻すことは別の到達点である。

## 綴りの構成

複合名は二つ以上、固有名は一つ以上の既知語を順序付きで並べる。部品の繰り返しも許す。文法上は任意の有限列であり、今回の描画・復号実装は資源上限として24部品までを扱う。二部品や登録済みの組合せだけを列挙する方式ではない。

| 要素 | 可視形状 | 読み |
| --- | --- | --- |
| 複合名の入口 | 大円と同心の中円、中心から上への半径線 | 後続する既知語の列を、一つの新語の綴りとして読む |
| 固有名の入口 | 大円と同心の中円、中心から左への半径線 | 後続する既知語の列を、固有名の綴りとして読む |
| 部品 | 公開語彙の語形 | その既知語を綴りの一部として読む |
| 終端 | 単独の小円 | この語の綴りを閉じる |

入口から終端まで、主円の中心のx座標が小さい順に部品を読む。上下の位置、外部線の曲げ方、線分データの順序は部品の順序を変えない。語の内部を結ぶ外部線は、すべての部品を結ぶ木でなければならない。線の分岐は許すが、切断、循環、未接続の端、余分な部品は拒否する。この区間内の線は綴りのまとまりを表し、関数の引数順などの意味構造を推測させない。

描画時は、中央の語の後に中円の部品が二つ続く場合、二つを上下へ分岐させる。ほかの配置では、既存の接続探索で合法な経路を選ぶ。読解規則は描画器が選んだ一つの経路への一致を要求せず、同じ部品列を表す別の合法な木も受け入れる。

入口には大円と中円があるため、その半径比と位置から全体の拡大率と中央の基準線を確定できる。絶対座標、SVGの寸法指定、元AST、辞書番号、出現アドレスは復号に使わない。複合名と固有名は、同じ部品列でも別の綴りである。単独の既知語と、その語を部品に含む固有名も区別する。

## 綴りと意味の接続

「雨＋住まい」という綴りだけでは、雨の降る住まい、雨から守る住まい、住まいでの降雨などのどれを意味するかは決まらない。語の導入時に型と定義本体を記述する。例えば引数なしの真偽値として `rain(home)` を定義すれば、「文脈の住まいで雨が降っている」という内容を指す名になる。定義しただけで、その内容が真だとは主張しない。

固有名の例では同じ「雨＋住まい」という部品列を、個体定数 `home` の別名として定義できる。この名前を付けることから降雨は導かれない。複合名と固有名を区別する入口により、真偽値の定義と個体の別名が同じ綴りに潰れることを防ぐ。ただし固有名一般の指示を解決する理論ではなく、すでに指示された個体に名前を与える範囲である。

実装上の参照名は、可視の種別と部品列から可逆な綴り規則で作る。登録順や出現順を用いず、ハッシュもしない。既知語、複合名、固有名の接頭部を分け、部品に含まれる区切り文字をエスケープする。復号した可視名から同じNoema識別子を再構成でき、文書専用の対応表は不要である。この内部表記は語義を与えるものではなく、語義は型と定義本体による。

新語を参照するには、それ以前に定義が存在しなければならない。未導入の語、同じ綴りの二重定義、前方・自己・循環参照、型の取り違えは既存のNoemaの検査へ接続して拒否する。固有名の定義は引数なしの個体型に限定する。定義と参照に同じ可視名を使い、別の名前が同じ対象を指しても二つの綴りを自動的に一つへまとめない。

## 検査範囲と残る統合

「雨＋住まい」と「住まい＋雨」、複合名と固有名、同じ対象への二つの名前を区別する。24部品までの名前、別の合法な接続木、上下配置、拡大縮小・平行移動、辞書順と語彙追加に対する不変性を検査する。名前に降雨の部品を含めても、降雨の主張にならないことは、雨の真偽を変える二つのモデルで別途確認する。

この段階で読めるのは語の綴りである。導入標識と型・定義本体を含む文書の可視化、語の境界を一般文に埋め込む規則、多引数・束縛・引用への接続は残る。公開語彙の意味領域を一般化し、人が画像だけで読解する試験も必要である。二作品の正本や固定したページ画像を、この試作へ置き換えない。

[命名のNoema文書](../examples/v016/visible-word-definitions-v1.noema)は共有の3基本関係・定数から4定義を作る。二つの別名が同じ個体を指す主張と、住まい・町の降雨を問う二つの質問を収録した。[検査報告](../reports/visible-word-formation-v1.json)は、二地点の降雨の4通りの組合せを記録する。語形の図版は `output/visible-word-forms-v1/word-forms.png`、文字を含まない各語のSVGも同じフォルダにある。
