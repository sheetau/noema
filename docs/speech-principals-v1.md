# 発言の帰属先と、実際の受け手・想定公衆

カントの職務内の発言と公的な発言の対比を、同じ本人による二つの活動として部分記述した。他者の委任による提示、本人への発言の帰属、職務と学識者の役割、想定する宛先、実際に提示した相手を別々に保持する。人数から公的・私的を決めない。

今回追加したのは既存構文による7定義である。原始概念と著者の主張は追加せず、親文書の宣言と15件の主張を保存した。翻訳器や生成プロンプトは使わない。

| 定義 | 条件 |
| --- | --- |
| `rhe` | 非空の相手への実際の提示と、同じ発言の帰属先が本人であるという明示的な関係 |
| `rhf` | 委任・職務・奉仕を伴う提示で、発言の帰属先が本人と異なる |
| `rhg` | 同じ本人・文脈に、`rhf`と`rhe`の別々の行為がある |
| `rhh` | 実際の相手が非空で、全員が想定宛先に含まれる |
| `hzb3` | `rhf`に既存の私的使用の分類と指定宛先を接続する |
| `hzb4` | `rhe`に既存の公的使用・公衆・経路・内容の分類を接続する |
| `hzb5` | 同じ本人の`hzb3`と別行為の`hzb4`を併記する |

「他者の代わりに語った」という情報がないだけでは、自分自身の立場から語ったとはいえない。`rhe`は本人への積極的な帰属を必要とする。ただし、それによって本人の内心の同意、独創性、真理、許可まで確定しない。帰属関係は引数として解釈を明示する。従来の組織を帰属先とする使い方を残し、本人への帰属を新しい構成で記述する。複数の帰属先を持つ発言も言語全体では排除しない。

実際の受け手は、全読者世界と一致させない。公的な使用の想定宛先は既存の`h6v`で読者世界へ結び、実際に提示した相手はその非空部分集合として記述する。これは今回の発言例に課す条件であり、想定外の読者に伝達されることを一般に禁止する公理ではない。提示は受領・理解・同意とも異なる。

職務内の提示についても、会衆の全員が現に提示を受けたことを要求しない。受け手の数を変えても、委任された職務としての活動という分類はそのまま保持する。ただし、`häuslich`という家庭内の集まりの意味や「いかに大きくても」という譲歩の様相を完成させたわけではない。原文のその部分は今回の新しい文字範囲に数えない。

検査では、提示・帰属・委任・学識者・公衆の7条件による128状態、実際の読者と想定読者の64通りの組合せ、職務側の人数を0・1・2・8・64人へ変えた10例を使う。0人では実際の提示条件を満たさないが、活動の私的使用という分類は失われない。想定公衆へ1人だけ提示した例では、公的な提示条件を満たせる。帰属先、役割、行為、内容、状況、経路を取り違えた73例も検査する。同じ真偽を持つ別名や、主張を質問に変えた記述は元の発言と区別する。

原文付き草案と依存定義だけを抜き出した文書で同じ結果になること、未解釈の関係を偽や空集合へ置き換えないこと、規範・信念・引用した内側の真理を実行しないことを確認する。通常表記・圧縮表記と固有文字の往復も検査する。有限例による区別の検査であり、全社会での公衆や自由の完成した意味理論ではない。

関連する36テストは通過した。3文書のCLIによる解析結果が直接解析と一致し、抽出文書から出力したSVGのXML構造が有効であることも確認した。SVGの見た目の検査や、原文との意味同一性の認定は含まない。

残るものは、公衆・職務・学識者の基本的な意味規約、書物という媒体、自由の無制限性、委任を理由とする論証、後見人と未成年の議論である。今回の定義は実際の提示条件を組み立てるが、原文が特定の発話の実行を断言したという著者主張は追加しない。全文の意味一致を確認し終えた区間数は引き続き0である。
