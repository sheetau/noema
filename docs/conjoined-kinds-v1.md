# 二種類の一般化を、一方だけで成立させない

カント第三段落第三文の「規定と定型表現」を、それぞれについて作用を述べる読みへ接続する三定義を追加した。二種類を一つの候補範囲へまとめて通常性を評価すると、一方の種類だけが通常事例に残り、他方について何も成立しなくても文全体が成立する反例がある。新しい構成は、各種類の内部で通常性を評価し、その両方を要求する。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)

一般文は、現在の全事例や多数の事例についての報告と一致するとは限らない。Cohenの論考もその区別と複数の分析を扱っている。今回の方式は、既存の通常性構成を用いた分配的な読みの実装であり、同論考からカントの唯一の読みが決まるとはしない。[Cohen, Genericity, 第2節](https://tzin.bgu.ac.il/~arikc/gen.pdf)

| 定義 | 内容 |
| --- | --- |
| `r2fa` | 第一の種類と第二の種類について、既存 `r2bg` の一般化を別々に評価する |
| `r2fb` | 同じ事例の対象・本人・基準を、使用継続の候補と結果の比較へ渡す |
| `r2fc` | 規定の事例と定型表現の事例を分類し、両方で条件付きの作用を評価する |

例えば、架空の製品について「赤い栓と青い栓は、通常、気密を保つ」と記述する場合を考える。赤い栓の事例が青い栓の事例より優先され、赤だけが気密を保つとする。二色をまとめて最も通常な事例を選べば、赤だけを見て成立してしまう。二色それぞれについて述べる読みなら、青の側でも条件が必要になる。Noemaの `r2fa` は、二つの分類述語、通常性、応答を受け取り、この差を表せる。

各種類の中では、通常性に劣後する例外を許す。比較不能な通常事例の失敗は無視せず、範囲内の循環や空の通常事例も成功にしない。両方の種類に属する同じ事例は許す。種類間の優先関係は、それだけでは一方を消す理由にならず、種類間だけの循環も種類内の順序不正とは扱わない。種類同士の序列を表す演算ではないためである。

この構成は各種類に少なくとも一つ通常事例を要求する。ただし、それらは仮定の事例でもよく、現在どこかに実例があるという存在主張を加えるものではない。比較範囲と通常性を結果に合わせて選んでよいという意味でもない。個々の実例に一般化を適用するには、その実例の適格性や通常性について別の情報が必要になる。

原文側では、既存の規定 `hd2` と定型表現 `h22` を事例の同じ対象・基準へ適用する。応答には前段の `r2ey` を使い、対象・本人・基準を同じ事例から取り出して、候補選択と継続点選択にも渡す。他の事例の成功を流用しない。二種類が共同で一つの効果を生む読みや、全実例で必ず成立する読みとは区別する。

検査は二個体上の範囲・通常性・応答の1,024組合せと、三個体を含む九対照を使う。原文側では十一対照で、二種類目の候補欠落、対象・本人・基準の取り違え、分類の取り違え、原因行為の不一致、途中での状態の喪失を調べる。この接続検査では分類と能力の内容を分離し、別の三例で既存の能力評価と条件付き作用をそのまま実行する。未知入力は確定せず、式記述全域を量化する分類全体の有限評価は拒否する。

これは独立した比較文書として保存する。現行の本文54文、登録簿v100、十二単位と先頭二文の判断を変更しない。三定義を追加したが、新しい基本関係や原文対応範囲は加えない。規定の拘束性、任意の型の定型表現、通常性の根拠、持続の強さ、指示と比喩の全体接続が残るため、第三文の意味確認を完了とはしない。
