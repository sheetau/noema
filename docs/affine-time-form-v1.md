# 時間座標の式、原点の選択、未定の速度係数

アインシュタイン§3の `u0062`〜`u0064` を部分記述した。同じτの三つの空間偏微分条件とアフィン表示を結び、時刻原点を合わせる仮定のもとで `τ=a*(t-v*x′/(V²-v²))` を記述する。係数aは同じvにおける未定の関数φの値であり、この段階で1や最終的な係数には固定しない。

`smc` は四座標のアフィン式を作る。縦・横二方向・時間の四係数と定数項を分け、`smd` は一組の係数が全入力で同じτを表すことを要求する。`sme` は同じ評価点の四偏微分を対応する係数へ結ぶ。`smf` はこのアフィン表示に、先行する縦方向の微分方程式と横方向の零条件を加える。

定数項は偏微分条件から消えない。`smg` は `τ(0,0,0,0)=0` を別の条件として記述する。`smk` は運動系の原点にある同じ出来事を両系の座標記録へ結び、x′,y,z,tとξ,η,ζ,τが零になることを要求する。`sml` はこの出来事、関数の零点、実際の座標対応を結ぶ。原文の原点選択をこの共通零点の規約として読んだ部分解釈であり、含意の過不足の確認は残る。

`smh` は時間座標の式の右辺を実切断で構成する。`smi` は `0≤v<V` と有効な入力を要求し、同じaを使った式が全四座標で同じτを与えることを記述する。`smj` はφへ同じvを渡す。前提側の `smr` でも、アフィン表示の時間係数をφ(v)へ明示的に結ぶ。結論側だけで別の係数関数を選べる記述にはしない。

有理数の代数的検査では、縦方向の係数方程式、二つの横係数の零、定数項の零から時間座標の式を得られることを確認した。原点条件を外すと加法的な定数が残ること、アフィン式の原点での値がその定数に等しいことも確認した。V=5、v=3、a=2、縦係数=-3/8、定数項7は、微分の係数条件を満たしても原点条件を満たさない反例である。a=2の例によって、これらの条件がa=1を強制しないことも確認した。

未知関数には、指定主体が指定段階で排除していない候補状況と、その状況ごとの速度関数を使う。`sma` は同じ速度における二候補の値の差、`smb` はそのような速度の存在を記述する。`sms` と `smq` は現在のφを現在段階の関数族へ値として結ぶ。`smp` は現在の候補を含めた有効な候補が複数残るという内容になる。これは未決定性の部分モデルであり、答えが一意でも主体が知らない場合を含む知識一般の定義ではない。

同じ速度で値が等しくても、二つの関数が同じとは限らない。検査ではφ₁(v)=2とφ₂(v)=2+(v-3)²を使い、v=3で差がなく、v=2では差があることを確認した。主体や段階を変えた場合、候補を除外した場合、対象速度域の外へ出た場合も区別する。後の段階で候補が減ることや、全候補が残りの物理条件を満たすことまでは主張しない。

本文での提示は三つに分けた。原点の選択は記述を簡潔にするための仮定、時間座標の式は前提からの著者の推論、未知関数はこの段階の未決定性の提示として記述する。これらの帰属が真でも、その内容を検査器が証明したことにはならない。
