# 結語の謝辞と二つの日付

原刊921頁のu0276–u0278を、同じ論説の三関係の総括の後へ接続する。謝辞の主張者は既存の著者`rd`、M. Bessoとdemselbenは既存の同じ人物`zrqperson`、研究は`zrqwork`である。友人関係と同僚関係は別の社会関係として意味規約を置き、それだけから支援を推論しない。同じ研究の対象と、ここで扱った問題を、同じ論説の考察対象へ結ぶ。`Zum Schlusse bemerke ich`は結語としての付言と著者の主張の組合せにする。

`treu zur Seite stand`は、同じ過去の一続きの研究で、支援が問われる全機会に、研究を前進させる目的に向けた実行があるという読みを採る。既存`sewx`の区間・機会・行為・目的の合成を再利用し、範囲帰属`eis5y`で支援に成功した機会だけへの切り詰めを禁じる。全時刻での支援、物理的な同席、唯一の動機、研究の成功を要求しない。信頼性一般の定義を完成したとはしない。

`manche wertvolle Anregung verdanke`は、異なる少なくとも二つの有益な思考上の入力についての寄与の認識と読む。旧`sewi`の複数性と非事実的な判断を再利用するが、旧`sewe`の同じ文脈に寄与と評価を置く形をそのまま流用しない。`etm`は、同じ過去の作業区間でBessoの行為から生じた入力を著者が研究の思考へ取り入れ、現在の仕事に相対的な肯定的基準を満たすという内容を作る。`eto`が四個体列の順序と長さを保ち、`etq`が既知の記述を静的に展開して著者の認識へ結ぶ。認識が現実と違う場合も記述できる。金銭債務、返礼義務、入力の真理や特定の感謝感情は足さない。

日付の一般関係はカントの日付行・文献受領・期間内所属から意味規約ごと再利用する。`etw`は年と月だけ、`etx`は既存`rqrm`そのままの年・月・日を表す。月・日の列内位置は0始まりで、第6月は5、第30日は29である。同じグレゴリオ暦・1905年・6月を共有するが、u0277には日を選ぶ条件を入れない。Bernという名称と都市は分け、日付行がその場所と月を表示することを記述する。実際に執筆を終えた場所や日時とはしない。

u0278は、同じ論説が刊行側の受け手へ届いた時点を存在量化し、それが1905年6月30日の内にあるという報告である。受理を査読採択と読み替えず、時刻・UTCオフセット・印刷日を追加しない。括弧に入った刊行側注記を著者の主張から分け、日付行の後へ置く。

検査は、過去の全作業範囲と現在の評価、複数入力、四引数の結合、支援目的とその達成の区別、名称と対象、年月日と受領時点、引用の非実行を対象とする。旧441主張・意味規約・判断・証拠を保存する。有限例の通過は歴史的事実や原文との同義性を証明しない。全文判断は別の通読記録に保存する。
