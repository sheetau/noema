# 同じ数値化規約の下での方向別の質量係数

アインシュタイン論文919頁の数値式と縦・横の質量係数を追加した。力は瞬間的な共動系k、加速度は静止系Kで数値化するという規約を残す。原文の横係数は μβ² であり、μβ に置き換えない。β は正の 1/√(1−v²/V²) とする。

一般定義は、係数×加速度＝力、一つの縦係数と共有する横係数、三成分の式、全数値に対する係数恒等条件を分ける。加速度も力も零の一例では任意の係数が式を満たすため、その成立を係数の同定とは扱わない。既存の算術・量化・実切断・引用を組み合わせ、新しい文法演算は設けていない。

有理数版では、正規化を含む係数式から三成分の式の同値性を証明する。逆方向には独立な二つの入力で十分であることを検査する。零入力だけから係数が決まるという誤った主張には反例を求める。実切断版は有理数を埋め込んだ演算モデルで対照例を検査する。全実数の演算法則を証明したものではなく、有限評価器は全有理数・全実切断の係数恒等条件を標本で代用せず拒否する。

本文には、同じ対象・出来事・系・単位に結び付いた前提から結論を述べる著者の推論帰属を一文追加する。先行175文は保存する。引用された式の正しさや物理的事実を、帰属の成立だけから補わない。

数値化規約を採る関係はまだ入力である。加速度を座標時刻の二階微分として構成すること、ばね秤・電荷・場からの物理的導出、μの測定上の意味は残る。数学的入力のμに正値制約を追加していないが、負の物理的質量を主張するわけではない。別の力・加速度の定義による比較を述べるu0259も未完である。

原文対応はu0255の数値式と、u0257・u0258のM0420・M0421を部分草案として記録する。周囲の説明の完成や、区間全体の意味一致を認定しない。
