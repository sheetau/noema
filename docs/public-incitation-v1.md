# 公衆を同じ行為へ向かわせる扇動

第四段落第三文の扇動を構成し、後見役・啓蒙不能と合わせて条件へ接続した。提示、受領、理解、行動意欲、感情、因果を分けて検査する。原文事例の閉じた参照供給と第三文全体の確認はまだ完了していない。

## 採用する読み

原文は、一部の後見人に公衆が扇動された場合の帰結として、先行する後見人への強制を置く。今回は、後の強制を担う人々への呼びかけが、その同じ行為に向けた意欲と反抗的な感情の高まりを実際に生じさせる読みを採る。公衆全員が一斉に同じ感情を持つことは補わない。[原文 AA VIII 36](https://korpora.org/Kant/aa08/036.html)

現代のDudenはこの動詞を、人々を反抗へ駆り立てる意味として説明する。この語義を、単なる冷静な助言や情報の伝達と区別するための補助に用いた。現代の辞書だけで歴史的用法の全範囲を確定したとは扱わない。[Duden「aufwiegeln」](https://www.duden.de/rechtschreibung/aufwiegeln)

## 呼びかけとその効果

`r2mw` は指定行為への本人の参加と行為の生起を内容とし、`r2mx` はその内容を求める発話を作る。同じ閉じた行為名から作ったこの発話を、提示 `f2`、受領 `h6e`、理解 `h6g` に渡す。発話は引用された目標であり、理解したという事実から将来の実行を導かない。

`r2mz` は、その同じ提示行為が反抗的な感情へ訴える様式 `h223t` を持つことも要求する。受け手については、同じ行為へ取り組む意向・準備 `h223s` と、反抗的な感情の高まり `h223u` を `r2my` で結ぶ。その内容が実際に成立することと、提示行為がそれを結果として生じさせる `g3` を別に検査する。

新しい三つの基本関係は、意欲、提示様式、感情をそれぞれ表す。どれも扇動の文全体を代用せず、提示の生起・当事者・受け手・目標行為・因果は合成側で結ぶ。虚偽や暴力、提示者の公的権限、受け手が冷静に熟慮したことは必須にしない。

`r2na` は後の公衆側参加者を受け手に固定する。発信者全員が同じ提示行為へ参加し、その提示側の当事者であり、全受け手に `r2mz` が成立することを要求する。一人ひとりの発信者が単独で十分な原因になる必要はない。

## 条件と帰結の分離

`r2nb` で既存の作用の反転へ接続し、未充足だった扇動関数を置き換えた。後の強制の実行は、扇動の成立条件に含めない。呼びかけの受領・理解・意欲・感情が成立しても強制しない解釈では、扇動は成立し、原文の条件付き帰結は不成立になる。この区別により後件を前件へ先取りしない。

引用する行為名が元の圧力行為と一致することは、含意の外でも検査する。別の行為を指す名前によって前件を偽にし、条件文だけを通すことはできない。

局所検査では七条件の128通り、受け手と発信者の取り違え、別の行為への意欲や感情、因果結果の取り違え、求めた行為の未実行を確認する。統合検査では後見役・取得不能・扇動・強制・保持の実際の定義を実行し、知的状態 `bf/up` の内容だけを明示的な境界にする。未知の入力は肯定にも否定にも補わない。
