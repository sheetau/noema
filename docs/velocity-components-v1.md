# 平面内の運動と速度成分の変換

アインシュタイン1905年論文§5冒頭のu0130〜u0134について、動く系での等速運動と、§3の座標変換を代入して得る運動方程式の部分草案を追加した。新たな文法や速度合成専用の基本演算は追加せず、既存の量化・実切断の演算・四座標変換から12定義を構成した。

動く系での二つの速度成分をu、wとすると、元の式はξ=uτ、η=wτ、ζ=0である。Noemaでは同じuとwを履歴に属する全出来事へ渡す。出来事ごとに別の速度を選び直す条件とは区別する。原点を通る条件も保持し、任意の位置定数を補わない。

変換後の式はD=V²+vuと置き、Dx=V²(u+v)t、βDy=V²wt、z=0と記述した。βは既存の正の枝を使う。原文の商と同じ定義域を保つため、D≠0を明示する。これは分母を払って記述するための条件であり、原文の全箇所に明記された仮定として扱わない。点の速度には光速未満という制約を先回りして加えず、負の速度成分や負のDも許す。

運動方程式は同じ点の履歴、同じ出来事、指定された基準系の座標記録へ接続する。記録の存在を要求し、同じ出来事に複数の記録があれば全てを検査する。空の履歴を運動の例として通すこともない。基準系の縦軸に沿う相対運動は、以前の物理的な関係を再利用した。

有理数の多項式検査では、四座標変換と非零分母の下で、元の運動方程式と変換後の式が同値になることを確認した。このほか、静止系の極限、零でない時刻からの成分の一意性、零分母の排除、負の分母の例を確認した。通常のベクトル加算と横成分を不変にする候補は反例で退けた。これら7件の検査は、Noemaの実切断上の体の法則全体の機械的証明ではない。

13件の実切断の具体例と13件の運動・座標対応の例で、符号、時刻、同じ定数の使用、点・出来事・軸・設定の取り違えを検査した。実切断の検査は、保持した有理数から構成する切断と明示した演算の解釈を使う。任意の実数値を有限サンプリングから推定する方式ではない。座標記録の物理的な実現も、この検査だけで証明したとはしない。

運動の指定は著者が置く仮定、変換は前提から結論への推論として帰属させた。この帰属を7例で検査し、引用された物理的内容の真理をその場で評価することとは分離した。

u0133冒頭の「静止系に対する運動を求める」という課題提示は未記述であり、その範囲と対応するM0249は進捗に含めない。§5の見出し、後続の近似・速度の大きさ・角度も今回の追加範囲外である。また、全実時刻で履歴の出来事が存在する条件、点状の対象・出来事・測定の基礎関係、原刊照合と原文の意味一致確認が残る。

新規7テストと関連テストの計26件が通過した。通常記法・短縮記法・固有文字の構文上の往復、CLIのJSONと構文木の一致、SVGのXMLとしての読み込みも確認した。全テストの実行と字形の目視確認は今回の検査に含まない。
