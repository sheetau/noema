# 速度の平行四辺形則と第一近似

u0135第一文は、直前の速度合成式を受け、我々の理論では速度の平行四辺形則が第一近似でのみ成立すると述べる。今回は、その加法則、近似の意味、厳密な一般則との差を構成する。帰結の提示と理論への限定、後続の速さ・角度の定義導入、全単位の意味判断は別に接続する。

平行四辺形則は共通の三軸と尺度での成分和として表す。共通始点から二辺を取り、その和の頂点への対角成分を結果とする規則である。物理的な速度に適用する際は、同じ点・K/k・現在の全記録と定速度へ接続し、数値の三組だけで対象の同一性を済ませない。

第一近似には、光速Vを固定し、系の速度vと点の二速度成分u,wを同じ倍率λで縮小する読みを採る。a=v/V、b=u/V、c=w/Vを固定すると、厳密な無次元成分はλ(a+b)/(1+λ²ab)とλc√(1−λ²a²)/(1+λ²ab)になる。零での値は零、同じ局所定義域に対する微分値はa+bとcであり、線形項は平行四辺形則に一致する。

この読みは小量と次数を明示するための解釈で、原文が展開変数を逐語的に指定したという主張ではない。実切断の微分によって零近傍の線形化を記述し、特定の有限差分や実用誤差幅を第一近似としない。原文にない三次誤差の具体的な上界や、全次数の解析級数は追加しない。

「のみ」は、成分和が厳密な一般則にはならないという限定と読む。厳密式と和が異なる同じ入力の反例が存在することを要求し、全ての個別設定で異なるとはしない。局所族の分母は零近傍で正だが、元の合成式の非零の負の分母を排除する条件にはしない。点の光速上限も追加しない。

検査は共通倍率と正の根、実際の合成成分との接続、微分に渡す定義域・関数・基点・導関数、反例の共有引数を確認する。全実数の微分と全速度・反例の量化は有限評価を拒否する。有限例の通過は、全単位の意味判断や一般の物理的真理の証明とは区別する。
