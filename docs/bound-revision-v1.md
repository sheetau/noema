# 改善不能の目的を、変数を持つ政策へ接続する

前版で分離した目的の型と対象列に、知識の改善不能・将来・条件付き必然性・因果を含む目的を接続した。同じ政策の対象として、先行集団、後続集団、先行時代、後続時代、契約の五個体を渡す。これにより、一つの契約へ固定した目的だけでなく、対象を変えて再利用する目的付き宣誓を記述できる。

構成の内側から順に、後続集団の知識の拡大不能と誤りの減少不能、それが後続時代の将来に成立する条件、その結果を生じさせる行為、同じ目的への志向を持つ宣誓、同じ宣誓政策への規範条件を結ぶ。目的の成立と達成、実際の契約成立と禁止は、それぞれ別に評価する。

| 定義 | 内容 |
| --- | --- |
| `rj3` | 五個体を直接受け取る関数を、同順の五個体列を受け取る関数にする |
| `hzdu` | 後続集団・後続時代を同じ対象列から取り、前件の適用例を伴う将来の改善不能を返す |
| `hzdv` | 同じ対象について、選択された将来全体での改善不能を返す |
| `hzdw` | 同じ対象について、前件の適用例の存在を要求しない条件付き内容を返す |
| `hzdx` | 同じ五個体を目的付き宣誓へ渡し、契約ごとの条項・当事者・宣誓の設定を選ぶ政策 |

`rj3`は既存の順次集計で作る。五引数の関数から始め、列を先頭から読み、その先頭引数を一つずつ固定する。五要素を読んだ時点で、元の五引数が同順の五要素に固定される。残った仮引数は結果へ影響しない。長さ五を条件とするため、空列や過剰な引数を受理せず、重複する対象も消さない。これは既存の関数と列による定義であり、新しい構文や基本演算ではない。

改善不能の内容では、同じ列の後続集団を知識主体へ、後続時代を将来点の範囲へ渡す。条件の関数には五個体全てを渡すため、契約や先行時代によって前件を変えることもできる。別集団の改善不能や、別時代の将来を流用しない。どの条件が制度上・歴史上妥当かは別の記述を必要とする。

目的を引用する際は、閉じた設定から改善不能の関数記述を作り、既存の因果構成`hzdr`を静的に特殊化する。そこへ同じ契約の当事者を行為者として渡し、五個体列を変数のまま残す。これで、引用内部の未知の内容を実行せずに、改善不能を生じさせる目的全体を指せる。目的の達成を評価するときには、その同じ結果記述と対象列への因果関係に加えて、指定した改善不能の内容も実際に成立することを要求する。

規範の対象には、この目的を含む`hzdx`の政策記述を渡す。規範の検査用に、政策を意味未説明の基本記号へ置換しない。全称的な禁止と積極的許可の欠如は、同じ政策に対する別々の条件として扱う。規範を述べるだけなら、契約が実際に成立したことも目的の達成も要求しない。

検査には、二個体の32通りの五要素列と二状況による64モデル、長さ0・1・4・6の不正な列、改善不能の直接適用との比較、別の知識主体・時代・契約、目的と宣誓の四通り、因果的達成の16通り、二契約への禁止・許可の16通りを含む。さらに、条項記述と当事者の引数列が異なる二つの契約がそれぞれ成立する例と、二番目の契約へ一番目の引数を流用すると成立しない例を検査した。有限の例による検査であり、任意の高階関数についての一般証明や、現実の全ての契約の網羅性を示すものではない。
