# πの積分による指定と球・楕円体の体積

前版で正の共通係数として残していた8πについて、πを積分関係で指定する定義を加えた。球と、光の球面を別の基準系で見た断面の体積も、断面積の積分として記述する。有限の小数をπそのものとして置く原始記号は追加していない。

## 既存の積分定義の接続

積分の一般定義は別の文書群にあったため、タグ付き分割の妥当性・接続・細かさ・和・積分・向き付き積分・区間レコードの7定義を、現在の実数演算の名前へ対応させた。定義本体は対応表による名前の変更を除いて保持し、区間・関数値の有効性・誤差条件の依存先も照合した。

`sede`が正方向の積分関係である。任意の正の精度に対して細かさを選び、その細かさを満たす分割が存在し、すべての該当分割と代表点で和が指定値へ近づくことを要求する。有限個の分割の検査をこの全称条件の代用にはしない。

## πと円板面積

`sedh`は実数xに対して1/(1+x²)を構成し、`sedi`は正の実数pを

\[
\int_0^1\frac{dx}{1+x^2}=\frac p4
\]

で指定する。πという名前だけを宣言するのではなく、その値を定める条件を言語内へ記述した。逆正接の積分表示を使う定義であり、数学的な根拠は[DLMF 4.23.3](https://dlmf.nist.gov/4.23.E3)を参照した。積分の存在・一意性や、円周長と直径の比との一致をNoemaの証明器で確認し終えたという主張ではない。

円板面積は`sedj`で、第一象限の円弧の高さsqrt(R²−x²)を0からRまで積分し、4倍する関係として記述する。`sedk`は面積=pR²という式を別に持つ。両者の同値性を定義の前提に含めず、証明すべき関係として区別する。円板は零半径・零面積も許す。

## 断面積による体積

球の断面積の式をp(R²−x²)とし、`sedm`で−RからRまでの積分を体積とする。`sedn`は体積=(4/3)pR³という式である。今回は正の半径の球を対象にする。

変換後の断面では、前版と同じD=β(1−av/V)を使う。x方向の範囲は−R/DからR/D、各断面の面積の式はp(R²−D²x²)となる。`sedo`がこの積分、`sedp`が同じ半径・pを使った球と変換後の断面の二つの積分を要求する。体積比DS′=Sを`sedp`の条件へ先に含めてはいない。

ここで採用する体積は断面積の積分による定義である。断面の横方向の中心移動が面積に影響しないこと、円板面積の式、一般の三次元測度との一致、積分変数の変換則を一括して証明済みにはしない。

`sedq`は前版のエネルギー条件へ、`sedi`で指定したpと係数8pを渡す。`sedr`は非負の二乗振幅Pと密度uについて8pu=Pを要求する。零振幅・零密度は許すが、エネルギー比では引き続き正の分母を要求する。この式を記述できることと、実際の光エネルギー密度がその法則に従うことは別である。

## 検査の範囲

有理数の代数検査では、被積分関数の単調性・一様な変化の上限、球と楕円体の原始関数候補の端点差、区間ごとの誤差の恒等式、端点差の加算、二つの体積式からの比という7項目を確認した。πの係数の取り違え、半径の三乗の欠落、変換後の体積を変えない値の3項目には反例を得た。

πの有限計算では、4・8・16・32分割の左右端を代表点にして、分割の接続・被積分関数の値・和をNoemaで検査した。各和は有理数として厳密に計算し、上下界の幅が2/Nとなって狭まることを確認した。これはπの有限上下界であり、どれか一つの和をπそのものとして採用する処理ではない。

球・楕円体・係数8pの引数の接続は18例と10対照例で確認した。この有限検査では、無限の積分とπの成立条件を検査用の仮定へ置き換えている。代入する有理数3は計算経路を検査するための代用値であり、3をπと認定した結果でも、元の積分定義のモデルでもない。被積分関数の有限点での比較も、引数の取り違えを探すためにだけ使う。

πの定義への接続では、区間0–1、被積分関数、係数1/4の取り違えを別の4例で検査した。元のπ・体積の定義を抽象化しない有限評価は、有理数全域の量化で停止する。未確認の全域条件を真にする処理は言語本体へ追加していない。
