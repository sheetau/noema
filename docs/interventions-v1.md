# 介入と結果の比較をNoemaで定義する

「妨げる」「促す」を基本記号として置くだけでは、何を意味する関係なのかの説明が足りない。今回は、条件の一部を変えた場合の結果を比較するための14定義を、[文語0.12の文書](../examples/v012/binary-interventions.noema)として追加した。新しい文法や因果専用のPython演算子は追加していない。関数・真偽・量化・同一性から構成し、この数学的ライブラリ自体には未定義の基本記号がない。

対象は明示的な二値構造方程式である。変数の方程式を指定値に置き換え、他の方程式を保つ介入の考え方は、Pearlの概説§3.2.1を参照した。観測の条件付けと、機構を変更する介入を区別するための方法である。[Causal inference in statistics: An overview](https://ftp.cs.ucla.edu/pub/stat_ser/r350.pdf)

このライブラリで現実の原因を自動認識するわけではない。どの変数と方程式が現実を表すかは、記述者が明示する仮定である。確率、非二値の変数、実際に生じた出来事への責任や原因の帰属まで、今回の定義だけで完成したとはしない。

## 方程式・介入・解

個体型aを変数の識別子に使い、割当てstateを`h[a] c`で表す。方程式equationsの型は`h[a h[a] c] c`で、変数と割当てから、その変数が従うべき真偽を返す。背景条件は方程式を作るときに指定し、介入の両側で保持する。

介入は、変更する変数を選ぶmaskと、固定する値を返すvaluesで記述する。いずれも型は`h[a] c`。解の条件saは、全ての変数xについて次の二つを要求する。

- mask(x)なら、state(x)とvalues(x)が一致する。
- mask(x)でなければ、state(x)とequations(x,state)が一致する。

介入した変数には元の方程式の成立を要求しない。例えば元の方程式が`x = ¬x`で解を持たなくても、xを真へ固定する介入はその方程式を置き換える。単に「xは真」という観測条件を追加する場合との違いである。

| 定義 | 内容 |
| --- | --- |
| sa | 指定介入後の解の条件 |
| sb | 解が存在する |
| sc | 目標を満たす解が存在する |
| sd | 解が存在し、全解で目標を満たす |
| se | 一変数を固定した場合の解の性質 |
| sf / sg | 一変数の介入で、目標が可能／保証される |
| sh / si | 要因の真偽を変えると、目標の真偽が全解で正／逆向きに変わる |
| sj | 要因の真偽にかかわらず目標が必ず真、または必ず偽 |
| sk | 一変数の介入後の解が一つだけある |
| sl / sm | 指定した比較基準で、全解が改善／低下する |
| sn | 改善する解の組が存在する |

解なし、複数解、結果が一意に決まる場合を区別する。解がない場合を「全ての解で成立するから保証」とは数えない。また、正の効果と負の効果を確認できないだけでは、無効果とは結論しない。

## 程度を比較する

目標の達成・未達だけでは、進行が遅くなることや少し改善することを扱いにくい。そこでslには、二つの割当てを比較する関数betterを渡す。その型は`h[h[a] c h[a] c] c`で、「第一の割当てに比べて第二の割当てが上位なら真」という向きとする。

slは、要因を真にした側と偽にした側の双方に解があり、真の側の全解が偽の側の全解より上位であることを表す。smは逆向き、snは改善する組が少なくとも一つある場合である。比較基準が非反射的・推移的であるなどの規約は、その基準を定義・解釈する側で明示する必要がある。

検査では、二つの二値変数から進行量を1または2として計算し、1から2への改善を確認した。達成の真偽だけを反転する定義に限定していない。同じ変化でも比較基準を逆にすると低下になること、一部の解で改善しても全解の改善とは限らないことも検査した。二値変数で任意精度の連続量や、確率的な傾向の一般理論を完成させたわけではない。

## カントの問いへの接続

[モデルを明示する読み](../examples/v012/kant-interventions.noema)では、従来基本記号だったmb・mcを、それぞれsm・slへの定義にした。mpが文脈に対応する構造方程式、mqが先行する離脱過程biに対応する進行の比較基準を与える。同じ背景・方程式・比較基準の下で、制限を適用する場合と適用しない場合を比較する。結果だけを「妨げる」「促す」と基本事実に指定する形から、比較の手続きを明示した形へ進めた。

これは全解で効果があるという強い読みであり、カントの一般的な語義と同義な訳として採用したものではない。[元の一般的な問いの草案](../examples/v012/kant-questions.noema)も保持する。mpの機構・変数選択、mqの進行尺度を原文の社会的議論へ適合させること、確率的な傾向・程度・推量を扱うことが残る。単純なモデルで得た効果を現実の制度へ転用しない。

[意味規約](../data/kant-intervention-basis-v1.json)には18基本記号・27定義と未解決点を保存した。比較の向きに応じて、先行草案の二つの質問の答えが変わることを有限解釈で検査したが、原文への同義性は確認済みにしていない。対応箇所は従来のu0012の二つの問いであり、新たな全文単位の完成数には加えない。

## 検証と再現

二変数の全ての二値方程式は256通りある。その各々について、変数二つと固定値二つの4通り、計1,024通りの介入を検査した。Noemaの解集合と、Python側で割当てを列挙して求めた解集合を比較し、可能性・保証・唯一性・正の効果・負の効果・確定した無効果の6条件も一致した。循環・自己参照のある方程式も含む。

さらに三変数で、共通原因による同時変化と、直接の影響を区別した。背景が偽／真のどちらでも観測される割当ては同じだが、片方の変数へ介入すると結果が異なる。観測上の一致だけから因果を決めていないことを示す検査である。結果は[検査記録](../reports/binary-interventions-v1.json)に保存した。

```powershell
python -S -m scripts.compose_kant_interventions
python -S -m scripts.check_binary_interventions --verify-only
python -S -m noema parse --input examples/v012/kant-interventions.noema --output artifacts/kant-interventions-v1.json
python -S -m noema render --input examples/v012/kant-interventions.noema --alphabet v2 --output artifacts/kant-interventions-v1.svg
python -m pytest -q
```

通常記法・短縮記法・固有文字の往復、宣言と意味規約の対応も検査する。検査器の有限領域・計算量の上限は従来どおりであり、大きなモデルの解探索に成功することを保証しない。モデル・翻訳器の学習は行わない。

新規7件を含む全608テストが通過した。`python -S`での草案再構成・検査記録再現と、CLIのJSON・SVG出力も確認した。二作品の確認済み全文単位は引き続きカント0/20、アインシュタイン0/282である。
