# 任務を割り当てられた組織と、任務の達成を分ける

カント第17区間の軍隊に関する残余条件へ、編成・任務割当・構成員の役職・指揮担当を結ぶ部分構造を追加した。保護に成功する集団であることだけでは、その集団の制度上の役割は説明できない。逆に、任務を割り当てられていても、実際の成功や能力は保証されない。

今回の定義だけで救援組織と軍隊を区別できるわけではない。軍事的任務の内容は未充足引数として残している。軍隊の意味を新しい一語に置き換えて説明済みとしたものではない。

## 同じ任務へ役職を結ぶ

[一般定義](../examples/v016/assigned-formation.noema)は三定義で、新しい原始記号や構文演算子を持たない。

| 定義 | 内容 |
| --- | --- |
| `rvz` | 当該制度・集団に役職が置かれ、本人が保持し、その役職が指定した対象共同体・任務に関わる責任を持つ。 |
| `rwa` | 制度が集団を構成して任務を割り当て、その時点の非空の構成員全員が `rvz` を満たす役職を持つ。 |
| `rwb` | `rwa` に加え、指定した指揮者が同じ任務に関わる役職を保持し、その役職が同じ集団の指揮を担当する。 |

各人の役職は異なってよい。全員が任務全体を単独で遂行する能力や義務を持つとはしない。指揮者については、役職と集団への担当を要求するが、部隊の構成員であることまでは要求しない。別集団で指揮を担当しているだけでは成立しない。

任務は、集団と対象共同体から内容を作る関数の閉じた記述として保持する。割当先の共同体も照合するため、別の共同体に関する任務を使えない。同じ真理値になる別の記述へ、割当や役職の責任を自動で移すこともない。

## 割当と実行を区別する

[作例](../examples/v016/assigned-formation-example.noema)では、組織の成立と指揮担当を調べる質問と、任務内容の真偽を調べる質問を分けている。

| 任務の割当と役職 | 現在の任務達成 | 組織の条件 |
| --- | --- | --- |
| 成立 | 不成立 | 成立できる |
| 不成立 | 成立 | 成功だけでは成立しない |
| 成立 | 解釈が未知 | 割当と役職の条件だけは評価できる |

編成、割当、保持、責任、指揮担当は意味規約を持つ入力関係である。これらから、法的正当性、社会的承認、実際の発令、履行、物理的な遂行能力は導かない。制度の成立過程を説明したことにもならない。

## 本文への接続と残る条件

[後継草案](../examples/v016/kant-assigned-formation.noema)の `hzyformation` は、前段の保護条件と同じ構成員の関係を取得し、同じ候補者・集団・共同体・文脈へ `rwb` を適用する。`hzyqualified` がこれと残余条件を合わせ、`hzyonly` が前段の `hzxonly` へ渡す。元の全宣言と先行18文を保持し、最後の解釈注記を改訂した。[抽出文書](../examples/v016/assigned-formation-core.noema)にも同じ接続を保存する。

軍事的任務の記述 `mission` と、残る資格 `remaining` は未充足である。武力・戦闘・防衛と非軍事的な救援の違い、公的平穏全体の説明を今後ここへ接続する必要がある。同時代辞書のHeer項を調べたが、直接本文の取得は確認できなかったため、検索結果の断片を語義確定の根拠にはしていない。

全構成員が任務に関わる役職を持つという条件は、組織化の一つの候補である。一時的な未配置や名簿の不備があっても軍隊と呼ばれる場合まで網羅した必要十分条件とはしない。

## 検証

176テストが通過した。編成・割当・各構成員の役職・指揮担当・実際の達成を変える128通り、別制度・別集団・別共同体・別時点・別任務の流用、未配置の構成員、空の集団を検査した。原文に接続した `hzyformation` と `hzyqualified` も実際に評価し、残余条件を合わせる16通りと参照の対照例を確認した。

新しい資格を保護条件へ渡す箇所は、実際の構文木で引数を確認している。保護・発言能力・今回の組織条件を一つの解釈で同時実行した検査ではない。帰属文は内容を実行せず、必要な引用層を下げた文書は拒否される。[検査記録](../reports/assigned-formation-v1.json)と[意味規約](../data/assigned-formation-basis-v1.json)に、検査範囲と限界を保存する。

```powershell
python -X utf8 -m scripts.compose_assigned_formation
python -X utf8 -m scripts.check_assigned_formation --verify-only
python -X utf8 -m pytest tests/test_assigned_formation.py -q
```

既に対応している原文範囲の改訂なので、部分草案の文字割合は増やさない。意味確認済みの全文単位は両作品とも0のままである。
