# 対流を伴う電荷と場の設定

第九節冒頭u0228–u0232を、原系の六方程式、ρの定義、同じ電気量の速度、小さい剛体への不変な結合、理論の基礎という位置付けの一つの意味依存群として扱う。この版では物理的な電荷・密度・速度と六式の接続を完成させる。本文408主張は維持し、原文単位全体を判断済みにはしない。

既存seme/semg/semhは原刊M0383の六式と同じ21偏微分を、semdは電気側の発散を表す。局所密度のseojは球の総電荷と体積の比の極限を、semlは同じπによる4π倍の規格化を表す。seocは同じ担体の座標時刻履歴の二側微分である。今回はこれらを任意の割当関数でつなぐ旧草案を再利用せず、各引数を同じ物理的対象と単位へ接続する定義を追加する。

ekxeは同時刻の領域族について、符号付き有限加法的総量seorと座標表現不変性seowを使う。新しい基礎関係eisvxは種類・分布・系・出来事・座標時刻・領域・三単位・値・文脈を共有する保有量の帰属であり、量種を既存zorへ固定する。電気量の二極性と尺度は同じeirmの物理的規約に従う。加法性だけでは電荷と認定せず、流束や保有量の時間差を総電荷へ置き換えない。ekxfでは全ての0<r<upperの球がその同じ領域族に入り、球の総量と体積から平均密度の極限を得る。ekxgはその4π倍をρとする。

密度の定義に物質点の存在は含めない。零密度の空間を扱うためであり、零密度から速度零や担体不在も導かない。ekxkは非零密度の点に同じ分布の担体を要求する。既存zqnの成員関係を再使用し、ekxlは領域内にある全成員の全出来事の速度を、同じ一価の速度場へ結ぶ。ekxhは全時間履歴の各出来事を同じ長さ・時間単位の位置割当へ結び、ekxiがその履歴とseocを共有する。同じ速度で移る異符号の電荷の相殺は許す。異なる速度の複数種を、合計ρと一つの速度の積にまとめる読みは採らない。

ekxjは同じ物理的二場と校正ejsn、同じρ・電荷密度・速度場・地点・偏微分を接続する。ekxmは非空領域の全有効四座標へこの条件を適用する。各点の九つの局所証人は一組として共有する。物質のない真空というejsoの条件は使わず、磁気側発散零も追加しない。後続M0389の磁気側に1/Vがない印刷形は既存semfとして保存し、今回の原系には使わない。

小さい剛体、イオン・電子、電荷の不変な付着、Lorentzの電気力学と動く物体の光学の電磁的基礎、著者の出発点とwhere説明、見出しの接続が残る。局所構成を全単位完成として数えない。

検査は局所引数の入れ替え、符号付き規格化の数値本体、保有量の種類と全領域の接続、全時間の単位、全担体への適用、各局所証人の束縛位置を区別する。全関数・全実数域を処理系が有限標本として受け入れないことも確認する。有限診断で使うπ=3はsediを明示的に置き換えた対照値であり、実際の円周率ではない。平均・極限・偏微分・有限加法性の既存証拠は固定ハッシュで再利用する。
