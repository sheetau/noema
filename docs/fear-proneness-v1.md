# 現在の恐れと、恐れやすい性向

カント第二段落の「schüchtern」を、その活動へ向かう際に害の手掛かりに恐れやすい局所的な性向として記述する。旧定義は、基準状況で十分な勇気がなく、少なくとも一つの将来の試みを恐れていることを要求した。これでは、現在は落ち着いているが弱い刺激にも恐れやすい人を表せず、恐れを感じながら行動する勇気のある人も除いてしまう。

[AdelungのSchüchtern項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_7_2_2938)は、受動的な用法を害への反応の傾向として説明している。この語義を[原文36頁](https://korpora.org/Kant/aa08/036.html)へ適用し、恐れやすさと、その後の試みの回避を分ける読みを採用する。辞書から原文の唯一の意味を確定したとはしない。生涯の性格、不可逆の変化、以前は恐れやすくなかったことは追加しない。

既存の性向構成`hzq6`を再利用する。同じ本人・活動の記述・評価基準を固定し、害の弱い手掛かりにも接する仮定状況を比較する。そのうち通常の候補すべてで、活動へ向かう試みに伴う害への恐れが成立することを求める。候補が空の場合と通常性に循環がある場合は成立せず、比較不能な通常候補での不成立も無視しない。弱い刺激の意味は背景の強度基準であり、実際の危険の小ささや、結果として恐れたことから決めない。

新しい二関係は候補範囲と通常性を指定する解釈入力である。性向そのものを未分解の「萎縮」関係として与えることはせず、候補の量化・通常性・既存の試みの範囲と恐れを組み合わせる。ただし、適切な刺激の範囲や妨害条件の心理学的な根拠は、この形式から自動的に得られない。

| 範囲 | 記述する内容 |
| --- | --- |
| 一人の心理的条件を固定した候補状況 | 弱い害の手掛かりにも恐れやすい性向 |
| 通常比較状況内の通常事例 | 先行例の認識が、その性向へ因果的に寄与する一般化 |
| 同じ比較状況内の全事例 | 例外を含めて数える、因果的な回避の頻度 |

性向があっても実際に試みを避けるとは限らないため、回避の頻度は前版の構成をそのまま使う。原因の結果側は新しい性向の記述へ更新する。一時的な恐れへの因果だけでは、性向への因果を満たさない。本文第37文の主張・帰属・期待背景を同じ新しい内容へ更新し、他の51文と既存宣言を保持する。

検査は、現在の恐れ・十分な勇気・性向を独立に変える八組合せ、先行例の認識・性向・因果を変える八組合せを含む。人物・活動・基準の取り違え、空の候補、順序の循環、通常候補と例外、旧状態への因果、未知入力を検査する。外側の事例一般化と回避頻度、著者への帰属、期待比較、既存の十一単位と先頭六文の選択、三記法の往復も確認する。

新しい九定義と二つの比較関係を加えた。原文の対応範囲と意味確認済み分量は増やさない。末尾一文には学習の見込みなどの通し確認が残り、有限・等重みの頻度や架空の例、基礎概念の説明も未完である。
