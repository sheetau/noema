# 同じ聖職者の生徒と会衆

第五段落u0012[2984,3185)に向け、聖職者の役割と二つの受け手範囲を同じ教会組織へ結ぶ依存群を構成した。教会の信条、教示義務、同じ条件での過去任用、説明と例示の談話、全文帰属は未統合であり、本文と意味確認文字数は更新しない。

r35mは既存spの存在証人だった役割と共同体を明示引数にする。継続的な宗教上の援助、主要な務め、任用、公的な宗教奉仕の責務を同じ役割・教会へ揃える。別の組織に任用された役割の証拠を借りず、実際の宗教行為や成功は要求しない。

Adelungは[Katechismus](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_6_0_493)を問答体による宗教の初歩の教えを収める本と説明する。この教授内容を学ぶ者として生徒を読み、特定版や物理的な本の所有は追加しない。r35nは初歩の教授・問答形式・宗教上の主題を別々に結び、r35oが本人の同じ職務・組織における同じ課程の生徒へ接続する。

[Gemeinde／Gemeine](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_2_1_1191)には、聖職者の配慮・指導に委ねられた宗教的集団という説明がある。r35qは同じ人に同じ役割・教会で配慮を委ねた集団を固定し、r35pの全成員を会衆側の宛先へ結ぶ。当日の出席者だけや、たまたまその発言を聞いた人へ限定しない。生徒側の範囲と会衆側の範囲は全個体について別々に一致を要求し、和集合にまとめて取りこぼしを隠さない。

二範囲の重なりは許す。この指定だけでは授業の実行や非空の出席者を主張せず、実際の教示内容は後続で構成する。教会の共同組織としての分類と信条の採用も次に接続する。保存した[Symbolisch](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_2_3_3821)の信条の語義と[Kirche](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_6_1_1017)の共同組織の語義は、その接続の補助資料である。1811年版の資料を1784年の唯一の解釈の証明とはしない。[保存記録](../data/clerical-teaching-lexical-v1.json)

検査では、役割・任用・奉仕の組織のすり替え、別の教師の生徒、無関係な課程・主題、問答形式の欠落、各宛先の過不足と入れ替えを拒否する。重複所属と空範囲を区別し、未知入力・保存資料のハッシュ・両表記の往復も確認する。意味同等性の全文章判断はまだ行わない。
