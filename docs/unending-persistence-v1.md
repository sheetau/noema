# 期間内の持続、終点のない履歴、時間の非有界性

指定期間内で状態が続くこと、履歴の残り全体で続くこと、その履歴に最後の状況がないこと、時間座標がどんな上限も越えることを分けた。これまでの期間内の持続から、無期限の持続を結論することはできない。

新しい文法や基本語は増やしていない。既存の量化・関数・厳密な順序を組み合わせ、持続の強さを明示して記述する。カント側には比較のための候補を接続したが、どの強さを原文に採用するかは未確定であり、本文の主張と原文対応範囲は増やしていない。

## 四つの強さ

| 構成 | 条件 |
| --- | --- |
| 既存 `h26` | 本人の履歴から選んだ、基準時以降の非空の区間の全点で状態が続く |
| `rca`／接続候補 `h2k` | 同じ履歴の基準時以降の全点で状態が続く |
| `rcb`／接続候補 `h2l` | 上記に加え、将来のどの点にも同じ履歴内でさらに後の点がある |
| `rcc`／接続候補 `h2m` | 上記に加え、同じ時間座標についてどんな有理数の限界より先にも点がある |

`rby` は、履歴に属し、基準時そのものかそれより後にある点の範囲を返す。`rbz` は履歴の順序と基準時への所属を検査し、将来に最後の点がないことを表す。`rca` はその同じ範囲全体での状態成立、`rcb` は `rbz` と `rca` の結合である。

履歴には既存 `ta` による非空の厳密な全順序を要求する。基準時が履歴にない場合は拒否し、空の将来範囲を調べただけで持続を認定しない。循環する先行関係も時間順序として受け入れない。

終点を持つ履歴でも `rca` は成立できる。有限の全履歴では `rbz` と `rcb` は成立できない。非空の有限な厳密全順序には最大の点があるためである。要素を順に比較して大きい方を残せば最後に最大の点が得られるが、`rbz` はその点にもさらに後の点を要求する。

有限評価器に有限の状況集合を全領域として与えたときの偽という結果は、そのモデルについての結果である。現実の未来に終点があると判定したことや、Noemaで終点のない持続を表せないことを意味しない。有限の観測記録を全履歴とみなす根拠も、この定義からは得られない。

## 最後の点がないことと、時間の上限がないこと

0以上1未満の有理数の範囲には最大の点がない。どの点 `x` にも、例えば `(x + 1) / 2` という、より大きく1未満の点がある。一方、この範囲は上に有界である。したがって、最後の点がないだけでは数値的な持続時間の非有界性を示せない。

`rcc` は、同じ座標の有理数限界を全て量化し、各限界を越える将来の点を要求する。`beyond(horizon, point)` は、その限界が点の時間座標を厳密に下回るという関係である。実数の時間座標にも、その下側切断として使える。ただし、実際に正当な時間座標を与えるか、順序と整合するか、原点と単位が共通かは、引数を与える側の意味規約である。

数値例の独立したNoema文書では、通常の有理数の大小関係により、次の四つの主張を有理数全体について検証した。

- `[0, 1)` に属する有理数には最後の点がない。
- その範囲は上に非有界ではない。
- 0以上の有理数には最後の点がない。
- 0以上の有理数は上に非有界である。

これは数についての正確な比較例であり、状況型を数型へ暗黙に置換した検査ではない。これらに対応する時間の解釈を考えるには、各有理数座標に対応する状況と、その座標に従う先行関係を明示する。例えば前者は終点を含まない有界な履歴、後者は上に非有界な履歴のモデルになる。現実の時間や人の生涯を、このどちらかと断定したものではない。

## 検証

任意の非空の状況領域について、実際のNoema定義を展開し、次の6性質を一階論理の補助検査器で検証した。

- 全将来での持続は基準時の状態成立を含む。
- 終点のない持続は全将来での持続を含む。
- 終点のない持続には、基準時より後の点がある。
- 履歴に最後の点があれば、終点なしの条件は成立しない。
- 同じ履歴・順序・状態のまま基準時を将来へ進めても、全将来での持続は保たれる。
- 同じ条件で基準時を進めても、終点のない持続は保たれる。

「全将来で続くなら履歴に終点がない」「基準時で状態が成立すれば全将来でも続く」という二つの推論には反例モデルを得た。基準時を変える性質は同じ履歴・順序を固定した場合の定理であり、基準時とともに履歴の選び方まで変える場合を含まない。

有限検査では、1〜3点の二項関係530通りを調べ、厳密全順序となる1・2・6通りを確認した。どの有限モデルも終点なしとは認定しなかった。状態と基準時を変えた24例、空の履歴と基準時の欠落、カント側の6例も検査した。有理数の全限界への量化を有限の数値例で代用しようとする評価は拒否する。

## 原文への接続と限界

カント側の `h2k` と `h2l` は既存の本人の履歴・先行関係・依存状態を使う。`h2m` はさらに時間座標の比較関係を引数として要求する。選んだ区間内の持続が成立しても履歴の残部で状態が失われる場合や、残部全体で続いても履歴に終点がある場合を区別した。
