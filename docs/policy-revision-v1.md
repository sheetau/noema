# 原則の置換・追加・選択的な取り下げ

政府の原則への作用を、旧原則の廃止と新原則への置換だけに限っていた条件を緩めた。新しい変化条件では、旧原則を残して別の原則を加える場合と、既存の別原則を残して一方を取り下げる場合も記述する。従来の厳密な置換条件は変更せず、別の定義として保持する。

`ryx` は同じ規範源・主体・職務と、内容の異なる二原則を使う。第一原則が始点で要求され、第二原則が終点で要求されることに加え、第一原則への要求が失われるか、第二原則への要求が新たに成立することを要求する。両方が前後とも要求されているだけなら成立しない。

この条件は三つに分かれる。第一原則への要求が失われ、第二原則への要求が生じる場合は既存の `rx3` による置換である。第一原則が残る場合は `ryy` による追加、第二原則が以前から残っている場合は `ryz` による選択的な取り下げになる。二原則の前後の要求状態について、16通りを検査し、変化が成立する場合は三分類の一つだけが成立することを確認する。

本文では、同じ規範状態の比較を、これまでの構造モデルの政治的な効果へ渡す。追加や取り下げが、同じ原因側の変化に依存する場合を認める。一方、原因側が変化しない比較状況でも同じ原則変更が生じる例は、因果条件から除く。単に後の時点で原則が変わったというだけでは、原文の作用への候補として通さない。

ここで扱うのは規範上の要求の前後差である。原則の採択・撤回という行為、要求の強さ、信念や目的としての原則は別の説明を要する。指定した二原則以外の変化を排除せず、期間の途中の全時点での継続も要求しない。要求が失われることを反対内容への義務と同一視せず、要求される内容の実際の履行も補わない。

この拡張は、原文の政府の原則への作用を三分類で完全に定義したとの主張ではない。原則を規範上の要求として扱う読み、作用の全体、焦点、尊厳と残余条件の意味確定は未完である。政府の役職・管轄、組織的な利益判断、公的理性使用の必要条件は保持した。
