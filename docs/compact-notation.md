# 意味を保つ短縮記法

文語0.2〜0.5に、短く書ける別の記法を追加した。意味構造や基本語を変更せず、長いヘッダーと毎回の主体・対象の標識を減らす。自然言語を解釈する規則や対訳辞書を追加する変更ではない。

## 書き方

「犬が猫を追う」は、文語0.5では次のように書ける。ここでは入力・説明用の代用文字を示す。固有アルファベットでも同じ文字数になる。

```noema
e:ih mu si.
```

`e:` は文語0.5の指定で、文書の先頭に一度だけ書く。`b:`・`c:`・`d:` はそれぞれ0.2・0.3・0.4を指定する。従来の `noema e e` 形式も引き続き読み込める。別の意味版へ自動的に読み替えることはない。

述語の後の最初の無標識の項が主体、次が対象となる。`ih si mu` なら「猫が犬を追う」。受け手・場所などは従来の標識を使う。主体を省いた「猫を追う」は `e:ih j si.` と書き、猫を主体に変えない。`e:ih ? si.` も同じ意味で受理するが、正規形は前者となる。

- 明示的な標識も使える。`e:ih i mu j si.` は `e:ih mu si.` と同じ意味。
- 無標識の項は最大2つで、明示的な標識より前に置く。`e:ih j si mu.` は受理しない。
- 数量・固有名・参照・時間を省略で補完しない。名前と日付では標識と引用符の間の空白を省ける。
- 否定や接続の角括弧は残す。空白だけを減らし、作用範囲を保持する。
- 同じ対象を繰り返す場合の参照名は、正規形で `a`、`b` …と付ける。異なる対象を同一視しない。
- 複数の文は句点で区切り、正規形では改行する。本文の空白・改行は既存の字句規則に従う。

```noema
e:u[ih mu si].
```

これは「犬が猫を追う」ことの否定である。次の文では、条件の犬を後半でも参照する。

```noema
e:y[wm mu o a][po p a].
```

## 実装と利用

`parse` は両方の記法を読む。`format` の既定値は従来形式で、`--notation compact` を指定すると短縮形を返す。`script`・`render`・編集用の検査は入力の記法を保持し、CLIでは明示的に切り替えることもできる。文語0.1は構造が異なるため、短縮形にする前に明示的な版変換が必要となる。

```powershell
python -m noema parse --text "e:ih mu si."
python -m noema script --text "e:ih mu si." --alphabet v2
python -m noema script --text "e:ih mu si." --decode --notation full
python -m noema render --text "e:ih mu si." --output artifacts/compact.svg
python -m scripts.measure_compact
```

主画面の日英→Noemaも短縮形を出力する。現行解析器の意味版は0.4なので、`d:` で始まる。これは解析できる語彙や構文を拡大する変更ではない。

## 文字数の測定

[12例の評価資料](../data/compact-length-v1.json)と[再現可能な結果](../reports/compact-length-v1.json)を保存した。文字数はUnicodeコードポイントで数え、版指定、空白、改行、句読点、名前も含める。バイト数・表示幅・読みやすさの測定ではない。資料は記法を比較する手書きの例であり、実行時の訳文検索には使わない。日英の例は意味の説明であり、翻訳精度の試験には用いない。

| 12例の合計 | 従来形式 | 短縮形式 |
| --- | ---: | ---: |
| 全文字数 | 305 | 161 |
| 版指定とその区切りを除いた本文 | 185 | 137 |

全体で47.21%減った。本文だけでも48文字減っており、ヘッダーを計数から除外した結果ではない。一方、日本語の説明文は合計97文字、英語は235文字で、短縮形でも日本語より長い例は12/12、英語より長い例は1/12だった。たとえば `e:ih mu si.` は11文字、「犬が猫を追う。」は7文字である。短い日本語に対する負担は残る。

複数文の例は含むが、長い文章の代表的なコーパスではない。少数の例での短縮率を一般の文章全体に外挿しない。文字数の課題は一部改善であり、解消とは扱わない。

## 検証と残る課題

既存資料、役割の逆転、省略、否定・条件の入れ子、大きな数量、引用符を含む名前、日付、共有参照、複合語・派生語について、意味構造との往復を検査した。固有文字2版、CLI、SVG、編集用の正規化にも適用した。旧記法で標識を省略した文は引き続き誤りとして扱い、既存の解釈を変えない。

全202テストが通過した。実ブラウザーでも英語からの短縮形出力、固有文字／代用表記の切替、既存15概念の逆変換を確認し、コンソールのエラーはなかった。後者は既存の定型文処理の動作確認であり、辞書・ハードコードなしの翻訳を達成した検証ではない。

人による読み書きや識別性の評価は未実施である。標識の減少が学習しやすさにつながるか、語順への依存で誤読が増えないかを別に確認する必要がある。通常の自然文への広い対応、辞書・ハードコードに依存しない双方向変換、意味構造一致率の要求は未解決のままである。
