# 単位別の意味判断を集計へ接続する

[既存の八項目](semantic-review-v1.md)に沿って原文単位全体を再読した判断だけを、明示した登録簿から集計する。有限テストの成功や対応範囲の拡大から意味一致を推定しない。旧集計器の「対応報告に正の完成件数があれば拒否する」という保護は変更しない。

判断記録には、原文単位全体と数式のハッシュ、対象本文・意味規約・識別表記、選択した文と依存する宣言・規約、八項目それぞれの理由、採用した読み、判断者の種別、根拠と限界を記す。単位内の未処理項目が残る記録は登録しない。文書全体の別の未解決箇所はそのまま残す。

検証器は原文の完全な範囲、固定した本文との一致、型と宣言、依存関係、根拠ファイルのハッシュを検査する。判断理由の内容が正しいかを自動証明するものではない。assistant_reviewはこの作業を行ったアシスタントの読解であり、独立した専門家の査読ではない。完成件数はこの留保を伴う単位別判断の件数である。

登録簿は作品ごとに対象本文を一つ指定する。同じ単位の二重登録、古い本文への判断を新しい本文へ流用すること、意味規約や根拠の変更、部分範囲の登録、数式の欠落を拒否する。本文を更新する際には、新たな対象と判断の登録簿を明示的に作る。最新ファイルを自動選択しない。

最初の登録は[カントの署名一単位](author-signature-review-v2.md)である。16非空白文字の署名一つを、長い段落一つと同じ完成分量だとは扱わない。任意の文章に対する表現率、翻訳精度、二作品全体の完成率はこの件数から求められない。

```powershell
python -X utf8 -m scripts.audit_written_progress_reviewed
python -X utf8 -m scripts.audit_written_progress_reviewed --verify-only
python -X utf8 -m pytest tests/test_semantic_reviews.py tests/test_written_progress.py
```

現行登録簿はdata/semantic-review-index-v1.json。将来の登録簿は--indexで指定する。旧集計器は過去の部分草案監査を再現するために保存してあり、現在の意味判断を含む進捗はこの後継入口で作成する。
