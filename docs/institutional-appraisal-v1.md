# 個人の認識と組織としての採用

政府の自己利益判断へ、組織の構成規則による採用を接続した。前段では同じ政府・政策について認識関係を要求していたが、その関係が個人の認識なのか、組織の判断なのかを構成し分けていなかった。

新しい `ryw` は、その判断の担当者を完全な非空の列として与え、全員が人で入力が確認済みであることを要求する。既存の `rwl` で担当者順に肯否の入力列を作り、同じ判断で有効な構成規則と担当者の順序を照合してから、指定規則で採否を計算する。担当者一覧は住民全員や組織の全構成員と同一とは限らない。一人の担当者でもよい。

規則は、担当者の順序と入力から結果を得る手続である。検査では、いずれかの肯定、全員の肯定、列の最後の担当者の入力を使う三つの手続をNoemaで記述した。これらを全政府へ固定せず、手続の識別子と計算、その手続が同じ判断で有効であるという構成関係を分ける。単に多数が賛成しても、その集計が組織の判断を構成するとは限らない。

`ibeawareness` は個人と組織を明示的に分ける。個人は既存の認識関係を使い、組織は `ryw` を使う。組織の入力は手続上の肯否であり、担当者の私的な信念から自動的に埋めない。人でない対象を全て組織にすることも、未確認の入力を反対として処理することもしない。

本文の自己利益判断では、構成規則による採用に加えて、既存の非空の判断候補全てで同じ利益評価が成立することを要求する。政府が採用した内容が、現実には有益でない例も保持する。役職と管轄、政策・共同体・文脈、覆いの参照と同格を含む条件文全体に接続した。著者への帰属だけでは、この組織的採用を事実として実行しない。

構成規則の成立と承認、担当者の資格、入力の成立過程、棄権や異議の扱いは未完である。原文が具体的な投票や手続を指定したという主張にもしていない。これは制度上の採用を組織の肯定判断へ使う候補であり、組織の信念・意思決定の全理論ではない。政府の語義、利益の読み、尊厳と残余条件の意味確定も残る。
