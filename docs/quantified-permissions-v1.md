# 人物・活動・内容を量化した許可の部分草案

カントu0015の「職務義務に制約されない他の人々」への許可について、一般条件を著者へ帰属する一文を追加した。以前の接続例では対象内容が一つに固定されていたが、今回は本人・活動・閉じた内容記述のすべてを量化する。同じ人の同じ活動についても複数の対象記述を扱い、義務との比較と許可に同じ記述を渡す。

この文は、指定した対象人口・公的提示の範囲・職務一覧・比較候補に依存する部分的な読みである。特に、公的提示の資格条件を、既存の判断・主張・吟味目的の合成定義へ接続する作業が残る。原文の意味を確認し終えた訳文には数えない。

## 組み合わせた条件

`rpt` は、同じ本人と基準文脈に応じた義務一覧を、既存 `rpq` の網羅性・非制約条件へ渡す。対象活動の内容は、指定された閉じた記述を同じ本人・活動に適用して得る。義務の出所・役割・活動・内容記述・肯否と、比較候補も明示する。

`rpu` は、本人・活動・対象記述の全組について、次の条件を述べる。

> 対象人口に属し、既出の対象群には属さず、指定された公的提示の資格条件と `rpt` を満たすなら、その同じ本人・活動・記述・公的役割・権限側・文脈について、積極的許可があり、反対の要求がない。

職務上の制約がないことを、許可の存在そのものとは定義しない。前件に該当する組について許可がある、という独立の条件文である。対象人口や比較候補が空の場合、普遍条件だけでは実際の対象者や活動の存在を保証しない。

`hzjq` では要求・許可を既存の `h7a`・`h7b` に結ぶ。`hzjr` はその内容を層1で引用し、既存の著者 `wa` と文脈 `wh`、発話箇所と原文範囲へ帰属する。帰属を確認するだけでは引用内容を評価しない。帰属関係 `hzjn` は層1の内容記述を受け取る規約として追加しており、旧版の帰属関係との同一性を証明したものではない。

検査では、二人に異なる義務記述と対象記述を割り当てた。二人それぞれの許可と履行の16組合せが、対応する人物の条件文と一致した。同じ人物に二つの対象記述がある場合、片方の許可だけでは足りないことも確認した。別人の内容・別の公的役割への許可、反対要求の存在を区別した。

空の義務一覧や空の比較候補については、無制約条件の不成立と、前件が成立しない許可文の真を別々に記録した。後者だけを検査して「許可が確認できた」とは扱わない。未知の許可を偽や省略へ変える処理も設けていない。

検査用文書では、義務網羅性と対象記述の二つの全称量化を、明示した四つの記述に具体化した。**保存した本文の全域量化は変更していない。** 全域をそのまま評価すると有限評価器が拒否することも確認した。これらの有限検査は、全記述に関する原文との意味一致の証明ではない。

本文と抽出文書の双方で、帰属の真偽だけが結果に反映され、引用内容が実行されないことを確認した。長形式・短縮形式・固有文字の往復、CLI解析、抽出文書のSVGのXML検査も通過した。SVGの目視検査は行っていない。

## 原文への接続で残る点

今回の資格条件 `activities` は、人・活動・内容記述・文脈の範囲を指定する入口である。それが既存 `hzgy` の、本人の判断、採用された教理との差、公的な自己帰属、同じ内容を吟味してもらう目的をすべて満たすことは未接続である。この入口を自由に変更しても、同じ原文を表したことにはならない。

対象人口、既出の聖職者、学者の役割、君主への照応、実際の全職務を尽くす範囲の同定も残る。「なおさら」の根拠と強調、先行する聖職者への許可全体も、この一文だけでは記述していない。対象となる実行記述は層0の型に限り、任意の層の義務全体を量化したとは主張しない。

標準版には未採用の0.15の草案であり、原文対応集計へ新たに加算していない。既存の248件・566文書の集計、明示範囲43.12%／48.79%、意味確認済み区間0件は据え置く。今回の原文位置とハッシュは、検査記録の `source_note` に別途保存した。
