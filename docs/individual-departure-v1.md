# 個々人の離脱についての第一文

カント第三段落の第一文を、これまで別々に構成していた性向と困難さから一つの記述候補へ接続した。現行原稿の末尾、第52文に置く。既存51文の順序と内容、十二単位の意味判断は保持する。

この候補は「同じ本人について、経験を通して定着した未成熟があり、そこから自己作業で離脱することが困難である」と述べる。対象範囲に属する各人へこの二条件を適用し、著者が先行する説明からの帰結として提示していることを記述する。文脈を受け取る引数を埋めた閉じた内容なので、以前の部分ひな形と違い、本文の一文として帰属できる。

## 尺度と人物をそろえる

性向の程度と必要な力の程度には、別々の評価種類を用いる。各尺度は低い順に並べた有限列として指定し、所属と順序を列から構成する。重複を拒み、両端を先頭と末尾から直接取り、既存の有界全順序条件で検査する。空列の列操作は明示した代替値を返すが、その値は空の尺度に属さず、有効な尺度としては受理されない。文字列の並びや数値を、そのまま意味の程度とみなす方法ではない。

近接域・余力の少ない帯・測定値は、同じ種類と基準文脈に結ぶ。帯には本人も渡す。これらは解釈に必要な文脈入力であり、主張が成立するように都合よく選ぶ存在変数にはしない。測定の欠落・多値、比較候補の欠落、本人以外の能力は、既存の検査にそのまま渡す。

| 定義 | 役割 |
| --- | --- |
| `r2dj` | 列内の厳密な前後関係 |
| `r2dp`・`r2dq` | 列の先頭と末尾を直接取る操作 |
| `r2dk` | 同じ本人の、形成され定着した内的寄与 |
| `r2dl` | 同じ本人の力と自己作業の方法を比べる困難さ |
| `r2dm` | 非空の対象範囲の各人について、上記二条件を結ぶ内容 |
| `r2dn` | 「したがって」の根拠側として読む先行六箇所 |
| `r2do` | 同じ内容・著者・文脈の帰属、帰結提示、本文順序 |

対象範囲には、その性質を満たす人だけを選んではならない。先行文の代名詞範囲や、段落末で成功者を数える範囲を無断で流用しない。`einzelnen`は各人への分配として扱い、集団による同時達成や、他者からの援助を完全に禁じる条件を補わない。

## 著者の主張と、主張内容の真理

追加する本文文は、内容`r2dm`を引用して著者へ帰属する。「したがって」は既存の談話関係`ud`で表す。先行する原因説明・便宜さ・代行例・支払い・後見人の働きかけ・萎縮の説明を根拠側とする読みを採る。直前の学習見込みだけに限定しない。

これは著者が帰結として提示したという記述である。世界の内容を評価した結果や、根拠から結論への論理的な含意とは異なる。原版482末から483冒頭への継続は、保存済み画像で確認した。画像は文の境界を確認する材料であり、この前提選択や人物範囲を一意に決める証拠ではない。

## 残る読解上の問題

現在の`r2dl`は、達成する方法があるが余力のある方法はない、という`r2di`の読みを保つ。これを全員に適用すると、全員に到達可能な方法があることまで含む。原文の`schwer`がそこまで含意するかは未決である。単に「容易な方法がない」へ変更すれば、到達不能や未評価も紛れ込むため、その変更だけでは解消しない。

また、本性に近いことを、内的な形成・寄与と外的更新や毎回の決定を要さない比較で表す読みについて、停止能力の欠如まで必要か、程度をどう校正するかは残る。後続文の強調や照応も今回の対象外である。

したがって第一文全体を意味確認済みには登録しない。明示的に対応づけた範囲は冒頭へ広がるが、意味確認済み分量は2,212文字のままである。

## 検証の範囲

列の前後関係と重複は独立の位置比較と照合する。性向側と困難さ側の尺度接続は、それぞれ既存の基礎関係まで通常の評価器で実行する。全称・同一人物の結合は、二つの内容の境界を置換した専用試験で確認する。この境界試験を、全ての世界内容を同時に評価した試験とは呼ばない。

帰属の試験では世界内容を未知のままにし、著者・文脈・内容の取り違え、根拠集合の変更、順序の逆転を検査する。旧本文とレビューの保持、通常記法・展開記法・独自文字記法の往復も確認する。これらの検査は形式上の接続を調べるもので、原文との同義性の自動証明ではない。
