# 革命候補における偏見の将来予測

[第五文後半](https://korpora.org/Kant/aa08/036.html)の `werden … dienen` を、前半で論じる革命のある候補における将来予測として接続する。同じ公衆について、新しい偏見が古い偏見と同じく大衆の判断の根拠として働くという読みである。

## 同じ対象と時間枠を使う

旧意見群は公衆と基準文脈から固定して取り出し、新意見群は同じ公衆・基準の候補ごとに参照する。参照した意見が実際に採用され働くことは、先行の `r2rk` により検査する。候補ごとに古い偏見を入れ替えたり、新意見群のうち成功した項目だけを残したりしない。

`r2rl` は、先頭文と前半から引き継いだ同じ期間と起点を使う。その起点より後の点で、同じ大衆について新旧の比較が成立することを要求する。個々の新しい意見が同時に生まれること、永久に働くこと、革命が直接その意見を作ることは追加しない。革命の完了時を特定して、その後に初めて変化が始まるという読みでもない。

## 全ての革命候補を検査する

`r2rm` は、前半と同じ `r2qx` に該当する活動と候補を全て検査する。政治的離脱に成功した革命だけへ範囲を狭めない。同じ候補に複数の活動があっても、新意見群を活動ごとに選び直さない。

革命候補は少なくとも一つ必要で、全候補の時間枠も有効でなければならない。これは、空の前件や無効な時間枠によって予測を成立させないための条件である。著者の予測として全対象候補に課す読みを採り、確率値や実際の歴史についての真理を示すものとはしない。

`r2rn` は先頭四文と同じ非空の公衆範囲へ一般化し、`r2ro` はその閉じた予測を著者と後半の箇所へ帰属する。帰属の検査では、引用された世界の判断・意見・革命を実行しない。

## 呼称と残る描写

`r2rp` は、第二文と同じ大衆参照を使い、後半でその集団を低く扱う呼称を帰属する。人数や未吟味の判断という内容は別に保持し、語調から社会的身分や思考能力を推論しない。`r2rq` は予測・語調と前半からの本文順序をまとめた追加文である。

Leitbandの身体的な紐と歩行誘導の描写、前半の留保・譲歩、aber/sondernによる意味上の対比、一文と段落の通読はまだ残る。既存62文、13区間の意味判断、先頭四文771非空白文字の確認は保持する。
