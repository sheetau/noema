# 同じ制度の導入と一定の短い期間

対象はカント第六段落u0013の第七文 `[1437,2309)`。法の採択、宗教上の制度導入、期限の指定、期間の短さ、同じ制度と全市民の批評の自由の維持を接続する依存群である。全文の意味判断ではなく、確認文字数は増やさない。

`r5ff` は全条項の成立を含む既存の採択 `r5ek` と、同じ行為による同じ宗教制度の導入を結ぶ。単に採択と制度の存在が同時に起きるだけでは足りない。一方、同じ規律の確認を採択から排除したり、全ての教えが歴史上初めて生まれたことを導入の条件にしたりはしない。

`r5fd` は完全な一つの履歴上で開始が終了より前にあることを要求する。`r5fe` はさらに、導入行為の決定に期限が含まれることと、同じ期間が文脈の基準で短いことを別々に要求する。期限は日付でも、同じ経過で終点を一意に定める条件でもよい。後から都合のよい区間を切り取る解釈は許さない。原文に日数がないため、短さを特定の数値へ置き換えない。

`r5fg` は開始を含み終了を含まない全履歴点に、既存の `r5fc` を要求する。この内容は同じ制度の存続と、その点の全市民の書面批評の自由を含む。開始点だけ自由があっても足りず、途中の市民の加入・離脱も先行構成のまま扱う。終点自体の継続・廃止と、その後の存続については制約しない。

`r5fh` がこれらを一つの候補内で結ぶ。`r5fi` ではさらに、指定された終点が渡された到達内容の開始以後の最初の成立点となる。旧 `rkh` を使い、到達せず無期限に維持する弱いuntilの分岐は持たない。全文では仮定の可能な経過に具体的な洞察・提案可能性を渡す予定であり、現実の将来の到達を予言する形ではない。最初の成立点が存在しない到達集合は、この形式では満たされない。

検査は採択と全条項を実評価し、導入側の六つの引数の取り違えを拒む。時間側では期限指定と短さを分離し、順序異常・履歴外の点・零期間を拒む。三つの内部点における存続と自由の64組、到達内容の16組を独立の真理値条件と比較する。時間の検査では採択 `r5ek` と全市民の自由 `r5fa` を境界とし、採択は同じ検査内、自由は固定されたinstitutional-criticism報告で実評価済みである。未知の入力を成功へ置き換えない。
