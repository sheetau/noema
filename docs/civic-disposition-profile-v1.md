# 民衆の心的応答傾向とその変化

第四文のSinnesart des Volksを、同じ民衆各人の感情・欲求・動機・構えに関する経験的な応答傾向の組として読む。旧候補の「独立した判断ができる人と話題の組の数」だけでは、対象を狭めすぎる。その候補と証拠は保存し、今回の定義では特徴の範囲を明示して、思考課題への判断以外も比較できるようにする。

語義の比較資料には[AdelungのSinn](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_2_0_853)と[カントAA VII 285](https://www.korpora.org/kant/aa07/285.html)、[286](https://www.korpora.org/kant/aa07/286.html)を用いた。前者は心や欲求に関する用法を含み、後者には感情・欲求に関する側面がある。ただし後年の分類を1784年へそのまま戻すことはできない。本稿では先天的な気質だけに固定せず、原文で変化を受ける経験的な傾向として扱う。これは採用する解釈であり、語の唯一の意味の証明ではない。取得した転記とHTMLは保存している。

個人の傾向は一回の応答と分ける。本人の同じ心理的基盤を保った全比較場面について、関連局面への直面と評価可能性を確認する。そのうち全ての通常場面で、指定された特徴の応答を示すことを傾向とする。例外場面での無反応は許し、現実の基準点でその応答が起きたことは要求しない。応答の成否で通常場面を選ぶことも許さない。

民衆の全成員と各人の全関連特徴を固定し、各組に正の重みを付ける。二時点の距離は、同じ組の傾向の真偽が変わった場合の重みの総和である。異なる二人の変化を相殺せず、同じ真の個数を保つ特徴の交換も検出する。これは心理的な善さや能力の得点ではなく、公開した尺度上の変化量である。全員の変化や多数派は要求しない。

区間内の全点で評価可能性を確認した上で、異なる両端の間に、双方から正の距離を持ち、その距離が両端間より小さい中間点を要求する。固定した段階上限を超える任意の二点にも同じ条件を課す。停滞や途中の逆行は許すが、大きな飛躍の前後に同じ状態を追加しただけでは通らない。固定特徴の尺度が粗くて中間を表せない場合には、この条件は成立しない。時点の粒度と尺度の妥当性は、実際の比較へ適用する際に明示する必要がある。

特徴・重み・段階上限は原文の数値の翻訳ではなく、漸次的な心的変化を明示するための解釈入力である。今回構成したのは傾向の内容と変化であり、前件の発達がその変化へ作用したという因果はまだ接続していない。allmähligが作用過程にかかる点、zurükの戻り先、人口・時点の量化、行為能力以降を残し、第四文全体の意味確認文字数は加算しない。
