# 政府の原則と内容の変化

u0017第四文の「政府の原則にまで作用する」を接続するため、政府が自らの統治を方向付ける一般的な行動規則を比較する。旧 `rx3` は旧規則の廃止と新規則の採用を同時に要求していた。原文にこの二つの同時成立を必須とする記述はないため、新しい `r6la` は追加だけ、撤回だけの場合も扱う。

`r6k3` は、同じ民衆の共同体に対する政府の運営・管轄と、政府自身の制度上の立場を確認する。`r6k4` は既存の `rxx/h7k` を使い、同じ政府が出所かつ名宛人となる統治上の自己規律として規則の採用を表す。政府を一人の人間へ置換せず、個々の職員の私的な考えとも分ける。採用は規則の実行を含意しない。

規則内容は空の外側引数列から内容を返す、閉じたNoemaの記述で与える。`r6k5` は固定した非空の比較状況全てで内容が同じ真偽になるかを調べ、`r6k6` はその同値類の規則が少なくとも一つ採用されているかを返す。記述の名前が異なっても、同内容の規則への付け替えだけではプロフィールは変わらない。一方、特定の記述への要求自体は別名へ転用しない。

`r6k7` は、同じ全候補と比較状況、全候補の採用状態の評価を確認する。`r6la` は前後で少なくとも一つの内容の同値類について採用が変わることを要求する。規則の履行状況が変わっただけでは採用の変化としない。比較は公開した範囲に相対的であり、範囲外でも二つの規則が同義だという証明ではない。

[AdelungのGrundsatz項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_2_3_3397)には行動の規則という用法がある。HTMLと転記を `artifacts/government-principle-profile-v1` に保存した。この用例は実践的な規則という読みの比較資料であり、政府の原則が必ず明文の法令や自己に宛てた義務の形を取るという証拠ではない。今回の採用形式は明示した解釈上の選択である。

原文の続きは、同じ政府が人間を尊厳に応じて扱うことを自らにも有益と判断する関係節である（[AA VIII 41](https://korpora.org/Kant/aa08/041.html)、[42](https://korpora.org/Kant/aa08/042.html)）。その具体的な規則内容、機械以上の人間、利益判断はまだ未接続である。今回の候補内容入力 `h27dc` を未記述の名前だけで埋めて完成扱いにしない。政府原則への因果的作用、最後という時間関係、auch/sogarの提示、全文帰属も後続の作業に残す。
