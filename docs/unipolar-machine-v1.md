# 単極誘導機の装置構成

u0177第二文の括弧内「Unipolarmaschinen」を、利用可能な運転設定を持つ装置の種類として構成する。回転する導体、滑り接触を介する閉回路、磁場との作用、整流の接続切替なしに極性を保つ誘導出力を結ぶ。これは第二文を読むための語義の注記であり、「Sitz」を問う前提と「gegenstandslos」の判断はまだ接続していない。

装置の分類には、少なくとも一つの利用可能な運転設定を使う。機械本体に属する回転部分を一様に一回転以上させ、同じ二つの滑り接触で帰路へ接続する。帰路は外部の負荷や試験接続を含んでよく、本体内部の部品であることは要求しない。現在実際に運転したことや、全ての条件で成功することも要求しない。

回路の接続方向は運転区間を通して固定する。これにより、回転位相ごとに端子を交換して整流する機構を区別する。出力は同じ経路方向の誘導作用の仕事/電荷であり、全時刻で非負又は全時刻で非正、かつ少なくとも一時刻で非零とする。大きさが一定であることは加えず、零になる時刻も許す。正と負のどちらの取り出し方向も扱う。

局所的な磁気駆動は既存eidzの単位電荷への力/電荷の規則を使う。その局所作用から回路方向の出力へ至る物理的な結合はeisrdに明示し、同じ過程・場・領域・磁場単位・出力単位・経路・区間を共有する。数値の出力関数だけを発電作用と認定しない。回路量を、前段の電動力ejygの局所的な三成分の代わりにすることもない。

磁場の源と回転部分の別体性は要求しない。[Faradayの原報 §§218–220, 229–230](https://www.gutenberg.org/cache/epub/14986/pg14986-images.html)には、磁石と銅円板を共に回す配置、導電性の磁石自体を使う配置、接続箇所と回路の他の部分を区別した考察がある。この資料を装置の範囲の検討に使い、円板の形・材質・水銀接触・検流計を一般概念へ固定しない。資料の保存先と内容ハッシュは[読解準備記録](../data/unipolar-machine-research-v1.json)にある。

検査では、正負の取り出し方向、変動するが極性を保つ履歴、途中の極性反転、恒等的な零、区間外だけの非零、一回転未満、欠けた接触、別の回路・場・単位への交換を区別する。実際の型を保つ本体の接続と、有限の時刻域での量化診断を分ける。全実数・全関数の量化を有限評価で代用せず、物理的な帰属は明示した規約へ接続する。
