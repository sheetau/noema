# 同じ軸方向の速度合成

アインシュタイン1905年論文§5のu0141後半とu0142・M0263を部分記述した。保存済みの原刊906頁で直前の条件文と式を照合し、次の式を既存の加算・積・符号付き逆数から構成した。

```text
U = (v+w)/(1+vw/V²)
```

新しい文法や意味演算の基本記号は追加していない。追加した基本記号は本文箇所への参照一つで、内容は八つの定義で記述する。分母は前段階の角度式の定義s2sへ、余弦成分1を渡して再利用した。

式そのものは符号付きの成分に対する関係とした。V>0と分母非零を要求し、結果を絶対値へ置き換えない。v=1、w=−3、V=5なら結果は−25/11であり、非負の速さ25/11とは異なる。二つの速度を正の大きさにして同じ式へ入れる操作は、逆向きの運動を保持しない。

一方、本文ではUとwを非負の速さへ既に接続している。「wもX軸（Ξ軸）の方向を持つ」という条件には、横成分が0という軸上の条件と、正の縦成分がその大きさに等しいという方向条件を分けて用意した。後者は非零を要求する。今回の本文への接続は、点と基準系がともに正の縦方向へ進むという読みを採用する。原文全体の符号規約を確定した唯一の訳とはしない。

零速度は軸上の条件を満たせても、正方向へ進む条件は満たさない。式はv=0やw=0でも定義でき、他方の値を返す。この代数的な性質から、停止した物体に向きがあるとは主張しない。また、|v|≥Vでも分母が非零なら式として値を持ち得ることと、その値を物理的な基準系変換として認めることは別である。

本文の「もし……なら得られる」は、既存の推論帰属関係zcで、方向の条件s3kと同じ点の速さの式s3lを結んだ。結論を無条件の断言として追加してはいない。条件内容s3mも別に定義し、前提が偽なら含意が真であっても、前提や結論の現実の成立は導けないことを検査した。

有理数の代数検査では、横成分0の既存の速度成分式から一次元式が得られること、非負入力で角度式の余弦1・正弦0と一致すること、交換性、結果の一意性、零の恒等性、逆速度による打ち消しを確認した。|v|<Vかつ|w|<Vなら分母が正であり、合成結果も|U|<Vとなる条件も確認した。これを後続の原文段落の記述済みという集計には使っていない。

検査記録は、代数13件、符号付き実切断の式17例、軸と方向8例、本文の条件への接続12例、帰属6例を含む。分母零の逆数に検査器が二通りの仮の値を返しても、定義域の条件がその入力を拒むことを確認した。これらは保持した有理数切断の厳密な検査であり、全実切断上の体・平方根の法則や物理的な導出の一般証明ではない。
