# 公衆と後見人の作用の反転

第四段落第三文のうち、公衆が先に後見人から未成熟をもたらされ、後には同じ後見人を未成熟に留めるという関係を結んだ。`kant-1784:u0011` の `[449,845)` 全体の意味確認ではなく、セミコロンより前の関係構成である。新しい基本語は加えていない。

## 同じ事例の参加者

`r2mp` は、後見人群の実際の先行参加者が担う一つの共同作用を、同じ公衆の被作用者へ結ぶ。被作用者は非空の人の列で、公衆の構成員に含まれる。各人の未成熟 `bf` が実際に成立し、その同じ行為が結果を生じさせる `g3` も必要になる。単に状態が存在する場合や、その後見人が行為に参加していない場合は満たさない。

`r2mr` は、この先行参加者全員を、後の公衆の作用 `r2mn` の対象にする。後見人群に属するだけの人まで広げず、別の後見人へすり替えない。後の作用も同じ公衆に属する参加者の共同行為であり、先に構成した離脱の制約・全期間の未成熟の保持・その保持への因果的寄与をそのまま使う。

先行する被作用者の範囲は文脈で固定する引数として残した。「公衆」への集団的な述定にその範囲が十分かを決める条件は未構成である。非空の部分集合を選べることだけで原文を尽くしたとは判定しない。

## 扇動の条件と時間

`r2mq` は、異なる二人以上の後見役が啓蒙不能の条件を満たし、一つの扇動行為に参加することを要求する。その行為が同じ公衆を同じ後続行為へ駆り立てる関係も必要である。後見役・啓蒙不能・扇動は具体的な構成を受け取る関数引数として残っている。参加者が複数いることから扇動を推論しない。

`r2mr` では、この扇動条件が満たされた場合に後の強制を要求する。先行作用は条件の外に置く。不能を要求する範囲は扇動者であり、全ての後見人でも、前文の自己思考者でもない。扇動者と先行参加者は別の列で渡し、一致・部分的な重なり・非重複をいずれも許す。

先行作用と扇動は、共通の履歴の中で強制開始より厳密に前にある。両者の間の前後は追加しない。同時点も許す。強制の始点と終点は異なり、評価時点までにその期間が終わっている。

## 検査と未完部分

有限解釈では、先行作用の原因と実際の状態、扇動者の人数・役割・参加・不能、同じ公衆と行為への接続を独立に変える。統合検査は `r2mn` を代用品にせず実行し、一人だけへの強制、一人の途中での状態喪失、因果の欠落、不正な時間順序を拒否する。未成熟の内容と未充足の三つの関数は検査境界として明示する。検査の成功はその境界の原文との一致を証明しない。
