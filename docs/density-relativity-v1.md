# 相対性原理による新系の密度解釈

u0203の第一文は、旧系の単位体積当たりの光エネルギーがA²/(8π)であることを前提に、相対性原理によって新系でもA′²/(8π)を対応する量として扱うべきだと述べる。新系のLichtenergieに省略された「単位体積当たり」は、同じ文の前半と後続の体積との積から補う。

採用する量は、同じ横波の周期平均密度である。瞬間の密度場、原文に対応する単位係数、各系の周期積分は[密度と動く境界の定義](radiative-density-v1.md)を使う。旧系と新系で同じ波・単位を保ち、位相率・位相原点・周期・振幅は各系の値に結ぶ。零振幅も第一文の適用域に含める。

基礎設定は密度モデルの採用から分離した。先行する波の物理的設定と振幅を前件に置き、旧系と新系それぞれの密度モデル及び平均値への対応を帰結に置く。新系の密度説明を前提としてしまうと、原理による新系への適用という文の役割が失われるためである。

原理の参照は既存の内容eifjと同じ呼称eiscgを使う。Relativitätsprinzipという複合語は同じ呼称を返す別表記として記録する。著者への帰属では、旧系の説明、原理と旧系説明を合わせた根拠、新系の説明が従わなければならないという提示を分ける。引用内容を真として実行することは、この帰属の条件にしない。

波の設定と振幅の記号は第7節から引き継ぎ、密度モデルを採用する考察と第一文の提示は第8節へ結ぶ。検査では同じ60量化役割の共有、旧新のモデルと平均の結合、結論を含まない前件、引用と根拠の向き、原理の同一性を確認する。全文判断は第一文の範囲[0,163)に限り、同体積の反実仮想、体積不一致、続く球面と同じ光の集合の説明を完了扱いにしない。
