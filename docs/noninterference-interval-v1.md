# 保持目的の全設定と期間全体の非介入

第五文の非介入条件には、保持を目指す目的の期間と、その操作が行われる時機の二つの範囲がある。r6a5は、同じ行為者・活動・対象・点に関する全ての関連する目的設定から、r6atの意図的な保持操作を満たすものがあるかを調べる。最初に選んだ一設定だけではなく、別の終点や履歴を持つ目的も調べる。

設定は履歴・順序・始点・終点の閉じた四記述で、設定範囲は目的採用や成功から独立している。実際の保持目的があれば、それを表す設定を必ず含むという入力条件を公開する。r6a6は非空性と全設定の始点の一致を確認し、設定の欠落を非介入へ補わない。未来の保持や目標達成は引用の内側に保つ。

r6a7は同じ集団と順序付き期間の全点について、全成員・全行為者・全活動の設定条件を確認し、介入が一つもないことを述べる。始点や終点だけの検査では途中の操作を見落とす。特定政府だけや成功した操作だけに範囲を限らず、関係のない対象への操作は同じ集団への介入に混ぜない。

局所検査では、別の目的設定だけが採用される場合、四記述と活動点の誤対応、設定が空の場合、区間内の全介入位置、区間外や非対象への操作、未知を確認する。実際の目的・全時点の範囲を自動発見したことは主張せず、完備性を解釈入力として明示する。

本文へ接続するときは、離脱過程と同じ候補履歴・同じ期間を使う。条件の成立時に人々がどのように抜け出すか、nurの限定と全文帰属はまだ接続していない。正本116主張と既存判断を保持し、第五文の確認文字数は増やさない。
