# 同じ初期部分を囲み続けるという記述

原刊913頁のu0203[422,597)からu0204の球面式を挟んでu0205[0,107)までを、一続きの文として読む。波面法線の方向余弦、光速度で動く球面、表面要素をエネルギーが横切らないこと、そこから「同じ光の集合を永久に囲む」と言えるという提示を接続する。

同じLichtkomplexは、初期の球内部の放射部分を、同じVnの流れで輸送した連続体の部分系として読む。現在位置xをx−Vntという同じ初期位置へ戻し、前進・逆向きの対応がともに元の点へ戻ることを要求する。現在領域の所属と、その点の部分密度は同じ初期領域・初期密度から定まる。領域と密度は分け、瞬間密度零の節で領域に穴を作らない。

これは同じ総エネルギーや体積を持つ別の分布というだけではない。異なる場所へ密度を配り直した場合、対応する初期位置での密度条件を満たさない。一方、全ての場・流・初期データが同じなのに微視的な生成消滅や交換履歴だけが違うという存在論は、この連続体モデルからは判別しない。原文の同一性を光子の個体同一性へ読み替えず、初期部分と輸送規則で同定する解釈を明示する。

eknwは、先行eknoの同じ物理モデル・無流出入・内部の位相と密度の持続に、この初期部分との対応を加える。eknyが全時刻モデルの下での無流出入、eknzが同じ初期部分の持続という内容である。両方とも前文と同じK・V・波範囲・部分・状況を固定し、残る65役割を同じ順に量化する。

dauerndは全実時刻として記述する。そのため、有限の局所近似から全時刻への妥当性を導いたとはせず、球の全領域履歴で理想的な平面波の流・密度モデルを採る条件eknpを明示する。瞬間の密度を使うこの輸送と、先行の位相平均総量も区別する。

「wir können daher sagen」は、無流出入を根拠に、同じ初期部分の持続として記述できるという著者の提示である。既存eisqoで記述可能性を構成し、それをuhで著者へ帰属する。udが根拠側から結論側への提示、eisraが同じ球面と内容を受ける後方参照を保持する。必然的帰結や明白性、処理系の証明済みは補わない。新しい一般関係は追加しない。

この文の本文はu0203側148文字、u0205側94文字、計242非空白文字で、M0354とM0355を含む。u0203前三文の判断と合わせてu0203及び数式単位u0204を全体として再読する。u0205の続くエネルギーの問いと言換えは未完である。
