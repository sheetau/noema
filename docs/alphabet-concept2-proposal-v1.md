# Alphabet concept 2：意味・構成・復号を合わせた設計案

これは外観確認前の提案であり、実装済み・復号検証済みの仕様ではない。[利用者の構想](../concept/alphabet-concept2.md)と[画像](../concept/noema-alphabet-concept2.png)を基準に、未決事項を補い、衝突する規則の変更案を示す。元の構想ファイルは変更しない。

方針は、対象への性質付与、役割を持つ関係、共有、範囲、参照、列を、それぞれに適した形へ構成することである。文全体の構図を一種類にそろえず、意味と公開された構成規則から描画を決める。現行Noemaの語義・型・構文・参照は維持し、既存の単純字形一覧やその接続探索を前提にしない。

成立の見込みはある。段の宣言、円弧による範囲、局所的な略記を組み合わせれば、長い字形列と迂回線を減らせる。一方、空の円弧の多義性、段の上書き、ドットの対応、見える形が一致する別構成をそのまま残すと一意に読めない。本案では、それぞれの解釈が有効になる範囲と条件を定める。最適性や全構造の可逆性は、外観試作と構成規則の確認を経るまで主張しない。

**継承する規則と、変更を提案する規則**

明記した変更以外は[alphabet-concept 1](../concept/alphabet-concept.md)を継承する。画像下段の基準図を、そのまま許可された字形の一覧とは扱わない。

| 項目 | 本案での扱い | 根拠・補足 |
| --- | --- | --- |
| 円中心と水平線の三罫線、縦横45度の線 | 継承 | 通常の中心は三段。直交交差する従属円の中心だけは、concept2の明示どおり基準外も使う |
| 大円以上の中心は中段 | 継承 | 大円自体を上下へ移すことと、上下段へ接続することを区別する |
| 円周への直交 | concept2で強化 | 線だけでなく、交差する円周同士にも適用。接触と同心は交差とは別の関係 |
| 同心・既定の中中／中小の接触 | 継承 | 偏心包含は許可しない。旧「中心が円周上」の交差は直交交差へ置換する |
| 一つの円につき相手は一円だけ | concept2に合わせて撤回 | 複数の内包・接合を認める。各接合の相手と役割が一意で、非関係部分の離隔を保つことを代わりの条件とする |
| 小円の中心線、中心を貫く直径、中心の複数方向の線 | 継承して禁止 | 45度刻みの直径は作図基準であり、全直径を描いてよいという意味にはしない |
| 大円に必ず中心線または斜め線を持たせる | 撤回を提案 | 部分円・同心・内包だけでも語や構成を識別できる場合に、余計な同形の線を足さない |
| 大円の斜め線はそのまま終端まで伸ばす | 継承し、終端の基準を第4円へ変更 | 線をそこで曲げたり別の線へ直結したりしない。上下小円への接続は後述の無線の接続で表す |
| 線だけの閉路・矢印状の構造、連続する直角曲がり | 継承して禁止 | 形の一部に使う線も対象。直角の分岐自体は許可する |
| 第4円の上下90度の弧と、その上下端の水平線 | concept2どおり禁止 | 左右90度の弧、線の終端基準には使える。第4円の完円は描かない |
| 半径線・接触・長い線の頻出抑制、重心の偏りの抑制 | 継承 | 数量の固定ノルマにせず、同じ構文を保つ合法な配置候補の評価に使う |
| 同一文内の空白 | concept2の三種類へ限定 | 大円の上下接続、独立ドット、認識可能な一形状の内部の分離。旧来の任意の見えない直線接続は使わない |
| ドットへの線、小円内のドット | 継承して禁止 | 円内のドットはその支持円の中心に置く。外のドットには後述の所属規則を設ける |

**寸法と円周の扱い**

小円半径を `u` とする。利用者の寸法指定から次が導かれる。縮尺を変えても、この比率は変えない。

| 寸法 | 値 |
| --- | --- |
| 小円半径 | `u` |
| 中円半径 | `(1 + √2)u` |
| 大円半径 | `(1 + 2√2)u` |
| 第4円半径 | `(1 + 3√2)u` |
| ドット半径 | `(√2 − 1)u` |
| 隣接罫線間隔 | `(2 + √2)u` |

通常の配置原点は三罫線上に置く。中大・小中・小大の直交交差では、半径を `R, r` として中心間距離を `√(R² + r²)` にする。配置の角度は中大で90度刻み、小を含む組で45度刻み。角度は大きい円の中心から小さい円の中心へ向かう方向で測る。同心、接触、直交交差以外の偏心配置を追加しない。

45度刻みの円弧分割と、直交交差によって生じる円弧の端は別に扱う。交点が45度の位置にある必要はない。交差の結果できた端を45度へ丸めると、直交と寸法の両方を壊す。

くりぬき型と日食型は、現状の文章だけではどちらも「小円側で大円周を隠す」と読める。区別を成立させるため、残すインクを次のように定義する案とする。

| 構成 | 残す円周 | 内側の線・ドット |
| --- | --- | --- |
| 交差型 | 両方の円周 | 小さい側の内部には入れない |
| くりぬき型 | 小さい側の円周全部と、その外側にある大きい側の円周 | 小さい側が中円の場合だけ許可 |
| 日食型 | 中円の円周全部と、その内側にある大円の弧だけ | 小さい側の内部には入れない |

日食型の定義は提案上の変更であり、元画像の全箇所をこの読みで説明できたという意味ではない。まず単独の三形を比較して見た目を判断する。見えなくなった大円の中心や半径は、残った弧から一意に復元できる場合だけ認める。白塗りの順序やSVGのマスク情報には依存しない。

複数の交差やくりぬきを組み合わせる場合は、各支持円について残す弧を一意に定める。同じ部分を残す規則と消す規則を、描画順で選び分けない。異なる構成から同じ可視形ができる場合は、同じ文脈で異なる意味を割り当てない。

非関係のインク同士の最小離隔、円周から外で曲げるまでの長さ、独立した曲がり同士の最小距離には、試作開始値として `u` を用いる。接触、直交交差、明示した接合点には離隔を要求しない。水平の接続をすべて `u` の整数倍に制限するわけではない。円の寸法と接続方向から必要な長さを算出する。線幅を含む実際の見え方によって、この最小値は外観確認前に見直す。

**意味の構成と、図形の組み立て**

一つの意味のまとまりには、外へ返す値の種類と、受け取る引数の役割を与える。例えば「渡す」は、主体・対象・受け手という三つの役割を持つ。一つの引数口に二つの値を暗黙に入れることは認めず、一つの対象や結果を複数の役割で共有することは認める。どの共有先へ何を渡したかは図形から回収する。

まとまりの構図は次の六系統を基本にする。これは六つの固定字形ではなく、構成方法の分類である。

| 構成方法 | 言語上の例 | 図形に求めること |
| --- | --- | --- |
| 局所付加 | 対象の性質、否定、役割の限定 | 付加先と、付加が及ぶ範囲を識別できる |
| 関係の接合 | 比較、移動、授受、関数適用 | 引数ごとの役割を保ち、必要な段へ展開できる |
| 対象の共有 | 同じ対象に複数の述語を適用 | 対象を一度示し、各述語の使用箇所を区別できる |
| 範囲の構成 | 量化、引用、仮定、局所定義 | 内外と開始・終端を識別できる |
| 参照と再利用 | 変数、定義済みの語、文内略記 | 定義元と参照先を一意に結べる |
| 延長できる構成 | 引数列、数、列挙、型の列 | 順序、続き、終端を識別できる |

語や関係の公開定義には、使える構成方法と引数の対応を記す。一つの構成方法へ複数の構文要素をまとめてもよいが、元の構文へ戻す規則を併記する。同じ意味のように見えることだけを理由に、連言の結合順や引用内の構造を省かない。

図形の識別に用いるのは、円の大きさ、残る弧、内包、接合の種類、終止する線、接続口の位置である。語義を文番号・辞書順・ハッシュへ置き換えない。意味を変えずに使える鏡映や別配置は、その構成方法の許可形として公開する。方角が参照を表す場合やドットの識別弧は、配置の都合で反転しない。

各構成方法には、見える主円の中心や入口小円の中心など、読順の基準になる位置も定める。線が左へ長く伸びたことだけで、宣言や呼び出しの順序は変えない。内包された内容は、その構成の規則に従って読む。単に全ての図形の最左端を並べる方法では、内包と並列の区別を失う。

外部接続線と字形の一部の線は、構成方法が定める接続口で区別する。見た目だけでは両方に読める接続は採用しない。認識には辞書と先行する可視の宣言を使えるが、生成元のAST、隠れた図形グループ、描画順は使わない。

**三段の役割と引数の順序**

三段は配置の場所であり、必要な範囲では意味上の役割も割り当てられる。役割を宣言していない部分では、引数の対応を局所構成の公開規則で決め、段の位置自体に追加の意味を持たせない。上段にあるだけで常に主体、下段にあるだけで常に対象、とはしない。

段へ役割を付ける宣言は、対象のまとまり・引数の役割・受け取る型を指定する。宣言には構想にある「小円を含む分岐」を用いるが、通常の引数分岐と区別できる機能形を予約する。どの輪郭を予約するかは外観試作で決める。宣言の機能が未定のまま、すべての小円分岐を宣言として扱うことはしない。

宣言は、その宣言全体を読み終えた位置から、現在の範囲の終わりまで有効とする。同じ範囲の後の宣言で上書きでき、内側の範囲での上書きは範囲を出た時点で元へ戻る。三段を同時に再指定する宣言は一括して切り替える。既に読んだ部分を後の宣言で読み替えない。

宣言済みの段へ入ることは、その役割へ値を渡すことになる。衝突回避だけのために別の役割の段へ移すことは認めない。必要なら短い範囲に役割の再指定を行うか、役割未指定の局所構成を選ぶ。単段なら中段、二段なら上下段を優先するが、意味を持つ宣言の途中で勝手に中段へ戻さない。

四つ以上の引数は、役割を保った複数の引数群として配置する。公開された引数数と順序から「次の引数群」が決まる場合は、それを共通の構成として使える。一般の名前付き関係には20引数の例もあるが、三段を使い回すことで表せる。型だけでは同型の引数を区別できないので、主体と受け手などの役割順は残す。

円周の接触は、二つの意味要素の直接の接続として使うことを原則とする。一方、公開された語の内部構成として接触を持つことも許可する。その場合は構成全体を一つの語として認識し、内部の接触を外部の引数接続として重ねて数えない。同じ可視の状態・文脈で両方に読める形は除く。接触の種類を単に幾何から決める旧方式は継承しない。

**方角を表す中心線と、大円の上下接続**

中心線の方角には、近傍の接続先または参照先を選ぶ役割を与える。既存の語形で使っていた任意の語識別方向とは分けて再設計する。同じ線を、その場によって説明なしに語の識別と参照方向へ使い分けない。

| 方角 | 本案の候補領域 |
| --- | --- |
| 左・右 | 現在の範囲の中段にある、直前・直後のまとまり |
| 左上・右上 | 上段にある、直前・直後のまとまり |
| 左下・右下 | 下段にある、直前・直後のまとまり |
| 上・下 | 同じ局所構成内で対応する、上側・下側のまとまり |

「直前・直後」は図形間の距離でなく、当該段の読順で決める。指定位置に適合するまとまりがなければ不正とし、型の合う別の対象を飛び越えて探さない。垂直方向に複数の候補がある構成には、役割宣言または明示的な参照を用いる。遠方の対象には略記・束縛参照・ドットを使う。

線の長さで束縛の深さを表す案は採らない。長さを間隔調整にも使うと、配置変更で参照先が変わるためである。最寄りの束縛は省略形で表し、外側の束縛は何段外かを合成的に指定する。深さを三種類の長さへ制限しない。

大円の上下接続は、方向を持つ終止斜線と、対応する上下段の小円の組で認識する。斜線の自由端は第4円と同じ上下の高さまでとし、そこへ線を足さない。小円は同じ側の対応段に置く。右側へ続く場合、小円の左端を大円の局所構成の右端から `u` 離し、左側はこれを反転する。この組の間に他の候補を挟まない。組が存在すれば接続となり、単なる装飾へ読み替えない。

**ドットの対応と所属**

ドットは接続先を対応付けるための局所的な目印とする。通常の直線接続、接触、内包、大円の上下接続で短く合法に構成できる場合は、それらを優先する。ドットによって語義や文全体を番号へ置き換えない。

ドットの識別には、同じ中心を持つ中円の45度区間の有無を使う。八区間の組合せは `2^8 = 256` で、中円なしを全区間なしに含める。中円なしを別に足して257種類にはしない。ただしこれは組合せ上限であり、最小離隔や他の構成との識別条件を満たす実用形が256種類あると確認したわけではない。

上位円と外側の線は識別キーに含めない。中円の弧が他の円やマスクで隠れる形は、ドットの識別用には使わない。くりぬき型の中円へドットを置く場合も、識別に使う中円弧は見えている必要がある。したがって、ドットだけの形と、大円だけに含まれるドットは同じ識別キーになる。

円内のドットは、その中心を持つ局所構成に属する。単独ドットは、同段で直後にあるまとまりの入口に属し、ドットの右端と入口の間を `u` 離す。対応先を探す前に、この所属が一意であることを確認する。単独ドットへ線を引かず、文の先頭・末尾にも置かない。

対応は、同じ文の同じ引用階層内で、同じキーの第一出現と第二出現、第三出現と第四出現、という対で作る。「一番目から全部へ」や「一番目から二番目、二番目から三番目」という接続にはしない。同じキーが三回だけ現れた場合は、三回目が未完了となる。別々の引用は同じ深さでも別の対応領域とする。

各対は、一方のまとまりの出力と、もう一方のまとまりの指定された引数口を結ぶ。局所構成と役割宣言から出力側・入力側が決まることが必要で、型が合うという理由だけで向きを選ばない。同じ対象を複数へ渡す場合は、共有を表す構成または文内略記を使う。ドットの出現回数から共有を暗黙に推測しない。

対応順は、行を継いだ文の左から右を基本とする。同じ位置では上・中・下の順を用い、同段・同位置の複数ドットは許可しない。並べ替えると対応先が変わるため、配置器はこの順序を保つ。引用の境界を越えた対応は認めず、改行・改頁は対応を切らない。通常の範囲をまたぐ対応は許すが、その範囲内で導入した変数を外へ漏らす接続は不正とする。外へ渡す必要があるものは、変数を束縛した関数や閉じた内容にまとめる。未対応の対を残したまま引用または文を終えることは不正とする。

**円弧による定義、呼び出し、未充足の役割**

円弧による文内略記は、宣言を読み取れば元の構文へ展開できる形で導入する。単純化した図形に対応する内容が、文書の外にある非公開表へ隠れないようにする。

略記の名前は、円弧の半径・方向・区間、同心の弧の組、外側の終止線で識別する。外部へ続く接続線は名前の一部に数えない。名前に使う形と、範囲の開閉・ドットの識別に使う形が同じ文脈で衝突しないよう、公開する構成規則で予約する。外側の終止線を増やす場合も、旧規則の矢印・閉路・中心線の制約を守る。

| 見える構成と文脈 | 読み方 |
| --- | --- |
| 名前の円弧の内側に、円弧とは線で接続されない完成した内容がある | その内容を示し、以降で使える略記を定義する |
| 定義済みの名前の円弧が、式を使う位置に現れる | 対応する内容を呼び出す |
| 引数の導入位置に、型・役割とともに空の円弧が現れる | 後で埋める引数を宣言する |
| 未定義の空円弧が、通常の式の位置に現れる | 不正。自動的に新しい変数として救済しない |
| 範囲の終端として予約された反対向きの円弧が現れる | 対応する範囲を閉じる。略記の呼び出しとしては読まない |

通常の式の中で行う略記定義は、その内容をそこで一度使い、後でも呼び出せるようにする。単に新しい語を定義する文書上の宣言とは、宣言の構文で区別する。空円弧の機能を毎回同じ追加記号で表示する必要はないが、上表の文脈が一意に決まる構成を使う。

略記の内容は、外側の変数を含まない閉じた式か、必要な変数を引数として明示したひな形にする。呼び出し場所の近くに同名の変数があるという理由で、定義時とは別の変数へ結び直さない。引数を代入するときも、内側で新たに束縛した変数を捕獲しない。

定義が有効になるのは内容を読み終えた後であり、自己参照や前方の未完了定義は使わない。上書きは現在の範囲の後続部分にだけ作用し、外へ出たら前の定義へ戻る。段別に同じ略記形を使うことは、段の役割が明示されている場合に限って認める。通常の無指定の段では形を移しても別の語にはしない。

「空の役割」「引数0個の値」「長さ0の列」は別の構造である。空の役割は型付きのひな形の一部として存在し、式の評価結果がないことを意味しない。必要な引数が埋まっていないものは関数として扱い、完成した真偽の文としては読まない。

未充足の役割には、利用者が追記した「接続のない小円を内包する円弧」も使える。空の円弧を略記の呼び出しにも使う場合、この内包小円を役割の導入側に残すと区別しやすい。外側への接続があっても、未充足の小円自体には線を接続しない。[最初の外観試作](concept2-kant-preview.md)では、関数と全称変数の導入にこの形を採っている。外観採用前の候補であり、全ての未充足構造の最終字形を固定するものではない。

長い内容を一つの円内へ押し込める必要はない。構想にある内包小円を本文の入口とし、そこから接続する一つの式を内容にできる。その式の終端は公開された引数数から決まる。可変長の内容や、複数の文を含む場合は明示的な範囲を使う。「つながっている線を全部たどった先」を内容とする規則にはしない。共有や参照まで無制限に取り込んでしまうためである。

**作用範囲と区切り**

内側へ接続されない第4円の左右90度の弧は、範囲の開閉に予約する。通常の本文の進行に対し、後続側へ開く弧を開始、その反対を終端とする。入れ子は直近の未終了の開始から閉じ、交差する範囲は作らない。

終了弧を省けるのは、その範囲が文末まで続く場合だけとする。文末で未終了の開始を内側から順に閉じる。開始のない終了弧は誤りである。二重の弧は二つの範囲の開始・終了として扱い、意味を強める装飾とはしない。語としての部分円と範囲記号を兼用して読むことは避ける。

範囲そのものと、範囲へかかる操作は分ける。範囲の付近の構成から、否定、量化、引用、仮定などの操作を識別する。二重の弧だけで引用と量化を入れ替えたり、「囲まれているから引用」と推測したりしない。各操作は局所構成へ組み込めるので、全ての文に共通の先頭記号を置く必要はない。

| 境界 | 変数・略記・段の役割・ドットへの作用 |
| --- | --- |
| 通常の内側の範囲 | 外側の有効な宣言を参照できる。内側の上書きは閉じると戻る。ドット対応は継続できるが、変数の有効範囲は越えない |
| 引用 | 公開語彙は使える。外側の変数、文内略記、段の役割、ドット対応は持ち込まず、内部で新たに始める |
| 改行・改頁 | 全ての状態を保つ |
| 文末 | 文内略記と段の役割を終了し、未対応のドットがないことを確認する。公開された語の宣言は文書内で維持する |

引用へ外の内容を組み込む必要がある場合は、現行Noemaの明示的な引用構成の操作を使う。単なる図形上の接続で引用の境界を越えない。

上下の第4円の高さまで達する、線分だけで連結した縦の構成は区切りに予約する。円弧の円周をたどれば上下へ行けるという状態は、この判定に含めない。円の中心を貫く直径を作らない場所に置く。分断された上下の短線は区切りとしない。

この区切りは、現在の階層で引数群・定義の項目などを区切る。量化や引用の範囲を自動的に全て閉じる機能は持たせない。区切りの両側が何の構文を構成しているかは、その局所構成から読めることを必要とする。単独の縦線に複数の終了操作を詰め込まない。

**文境界、読順、改行**

文は円要素を含むまとまりで始まり、円要素を含むまとまりで終わる。ここで円要素には部分円を含め、ドットだけの形は含めない。文の種類は、本文の型と必要な局所操作から読む。真偽を主張する通常文に固定の文頭記号を追加しない。主張か質問かのように同じ型だけでは決まらない場合には、識別できる操作が必要になる。

円が先頭と末尾にあるという条件だけでは、内部の分離と文境界を区別できない。補足として、同一行の文間には、当該行の全書字高にわたって空く幅 `4u` 以上の帯を予約する。罫線を越えて張り出す円弧や線も、この空白の判定に含める。文内部の三種類の空白はこれ未満に収める。長距離のドット対応は、途中に別の内容がある場合も含めて表せるが、大きな空帯をまたぐ接続にはしない。この数値は外観試作で変更可能だが、文間と文内の区別は維持する。

文内の配置順は左から右を基本とし、同じ位置の独立した要素には上・中・下の順を与える。引数の意味上の順序は公開された役割によって決まるため、見た目の上下順へ置き換えない。同じ位置で互いの宣言を必要とする構成は作らず、先行宣言または一括の宣言に分ける。

一文を改行するときは、続く全ての流れについて、行末・次の行頭に対応する接続線を置く。同じ段の継続線を対応付け、改行だけで段の意味を交換しない。図形の途中、ドットだけの位置、無線の上下接続だけの位置では切らず、全体を移すか、可視の継続線を持つ合法な構成へ組み直す。改頁も同じ規則に従う。

接続線の一部を切って改行できる条件は、円や機能形を分断しないこと、各段の対応が一意であること、復元しても線の方向・曲がり・最小長さが変わらないことである。自由端の斜線を行末継続と誤認しない。対応する継続線がない切断は誤りとして扱う。

**現在の言語本体との対応**

現在のNoemaには、29種類の式の作り方がある。下表はそれらの受け皿であり、29個の独立した字形を追加する指示ではない。局所付加や接合で複数の構文要素をまとめる場合も、復号時には該当する式へ戻す。

| 言語の機能 | 現行の種類数 | 本案での表現方法 |
| --- | ---: | --- |
| 変数・数・関数そのものの参照 | 3 | 型と参照先を持つ値。関数参照と、引数0個の呼び出しを区別する |
| 名前付きの語・関係の適用 | 1 | 公開された語形と引数の役割。性質・出来事などに応じた局所構成を選べる |
| 否定・連言・選言・条件・同値・等しさ | 6 | 付加・接合・共有・範囲へ組み込む。種類と結合順は復元する |
| 全称・存在 | 2 | 変数の導入、型、本文の範囲と参照を組み合わせる |
| 関数を作る・関数へ引数を渡す | 2 | 未充足の役割を宣言した本文と、その役割を埋める構成 |
| 引用・脱引用・引用の持ち上げ・引用の合成 | 4 | 引用境界と明示的な操作。引用階数も必要な場合は合成的に示す |
| 命題内容を作る・状況で評価する | 2 | 状況変数を持つ内容と、内容／状況の二役の接合 |
| 質問・答えの照合 | 2 | 求める値の役割を持つまとまりと、その役割への答え |
| メッセージ・内容の取り出し | 2 | 内容と主張／質問／指示の区別、および内容を取り出す操作 |
| 列・長さ・位置・連結・集約 | 5 | 可変長のまとまり、順序、終端、各操作に必要な役割 |

基本の型は個体・数・真偽・状況・命題内容・メッセージの六つ、合成する型は関数・列・質問・式の記述の四系統である。公開された語の型から一意に決まる情報は毎回描かない。引数列・型の列・数の表現は延長可能にし、三段や八方向を言語の要素数の上限にしない。

文書の原始宣言・定義、主張・質問・発話の実行・仮定の範囲も区別する。文内略記は表記上の展開規則であり、新しい原始語や意味判断を作る操作ではない。引用された構文と命題内容を同じものへまとめない。

具体的な語彙の新字形は、構成方法と同時に設計する。現在の30根語や94通常字形の輪郭を固定条件にしないが、語の意味と定義は保持する。新しい語を既存の原文一文に一対一で追加する方法は使わない。短縮が必要なら、既存の定義、引数共有、文内の可視な略記を使う。

**文によって構図を変える例**

以下は構図を選ぶ規則の例であり、字形や描画結果を検証したものではない。`A` などは説明上の名前で、本文へラテン字を加える提案ではない。

| 表す内容 | 選ぶ構成 | 省略できない情報 |
| --- | --- | --- |
| Aは赤い | Aを中心にした局所付加 | 対象Aと性質「赤い」 |
| Aは赤く、丸い | Aの共有と二つの性質の展開 | 二つの述語、連言、各述語の対象が同じAであること |
| AがBをCへ渡す | 授受の役割に応じた接合 | 主体・対象・受け手。二つの役割を同型だから交換しない |
| AがBをCへ渡すことを、Dが望む | 授受の内容を一つのまとまりにして外の関係へ接続 | 望まれる内容と、実際の授受の主張の違い |
| PならばQ | 二つの内容の非対称な接合 | 前件と後件、条件全体への作用範囲 |
| 全員に、それぞれ相手がいる | 変数を導入する範囲の入れ子 | 誰に依存して相手を選ぶか。量化の順序 |
| 「Pという表現」を扱う | 独立した引用の範囲 | Pの構文と引用境界。Pをそのまま主張したことにしない |
| 複雑な関係を繰り返し使う | 内容の提示と局所略記、必要なら引数を持つひな形 | 元の内容、引数、適用回数、各回の参照先 |

全てを同じ中心核と左右の枝へ変換する必要はない。関係の種類と引数構成から使える候補を限定したうえで、内包、付加、分岐、共有、範囲、短い接続を組み合わせる。同じ構造が意味上必要な箇所では反復してよい。異なる内容を見た目だけの都合で一つに融合しない。

段の割り当てや合法な異体の選択には、線の総延長、折れ数、円の密集、三段の偏り、半径線や同じ局所形の連続を評価に使える。ただし、候補間で役割・型・参照・語が同じであることを先に確認する。違う意味の形を混ぜて反復を減らすことはしない。図形の識別に必要な最小情報は、見た目を整えるためにも消さない。

**生成と復号を組み合わせる手順**

生成では、意味と構文から使える局所構成を選び、その構成に必要な接続口と余白を予約してから隣を配置する。個々の字形を固定してから文全体に迂回線を探索する方式は引き継がない。衝突した場合は、局所構成の合法な別配置、短い範囲での段の再指定、可視の略記や共有を検討する。ドットはその後の選択肢とする。

復号は次の順序を想定する。

1. 見える円弧・円・線・点を、縮尺と寸法規則に沿って認識する。SVG要素順・グループ・マスク定義を取り除いても同じ結果になることを要求する。
2. 文間、継続線、明示範囲を認識し、文と引用の対応領域を定める。語の推測を先に行って境界を都合よく補わない。
3. 公開された構成規則から局所的なまとまりと接続口を取り出す。離れた構成要素には、共通中心・基準寸法・役割の対応などの認識根拠を必要とする。
4. 可視の宣言を読順に処理し、段の役割、略記、変数の有効範囲を決める。同時の宣言は一括して切り替える。
5. ドットの対と引数の役割を確定し、共有・略記・局所合成を元の構文へ展開する。未対応、重複充足、型違い、束縛範囲違反を拒否する。
6. 回収した構文を確認済みの構文と比較する。語義・参照も同じなら、その範囲の既存の意味判断を引き継ぐ。

この段階分けが成立するよう、構成の認識と宣言の解釈が互いを前提にする循環を作らない。例えば「まだ読めていない段の意味を使わないと、その段の宣言が見分けられない」構成は不許可とする。局所的に同じインクへ異なる構文を割り当てる二規則が残った場合は、型でたまたま一方を除ける例だけで承認しない。識別する構成か、適用範囲の違いを規則に加える。

**試作で決めるものと、確認の範囲**

構成の概念が追加で不足しているというより、既にある形の機能を区別する約束が不足している。本案で補うのは、役割の宣言、定義／呼び出し／未充足の役割の区別、範囲の開始と終端、引数群の継続と終端である。これらを識別する実際の輪郭は、円弧・内包・終止線・小円の組み合わせから選ぶ。新しい固定の文頭形を一律に足すことはしない。

外観確認用の最初の候補には、局所付加、同じ対象の共有、三役の接合、役割の交換、条件、二重の量化、引用、局所略記、未充足の役割の補充、四つ以上の引数、ドットの複数対、複数段の改行を含める。各例を単独の記号見本で終えず、短い連続した文章にも組み込む。通常の円、部分円、三種類の交差、同心、接触、単段・二段・三段を使えるかも、その構成に意味がある例で確認する。全てを一文へ詰め込む必要はない。

その候補では、次をまとめて判断する。

- 利用者画像の有機的なまとまりと、元kant-pageの文としての密度へ近づいているか。
- 同じ文頭・同じ中心核・同じ半径線・長い迂回線が、構成方法の制約によって繰り返されていないか。
- concept1の継承規則と、本案で明記した変更以外の違反がないか。
- 実際の図形だけと公開辞書・可視の宣言から、引数順・引用・束縛・語・参照先を回収できるか。
- 接続先を交換した例、範囲を変えた例、ドットが余る例、区切りに見える未接続線などを正しく区別できるか。

最初の段階で全作品や全歴史版の監査を繰り返さない。幾何の最小例と、意味の違いを識別する短い対照で構成規則を確認する。語形一覧の適合と、任意の合成での一意性は別に検討する。後者には、接続口の所有、宣言の有効範囲、終端、図形の識別が合成後も保存される条件が必要になる。

本案からまだ実形へ落としていないのは、機能形の具体的な輪郭、語彙の合成規則ごとの形、全ての局所構成の接続可能範囲である。日食の残し方、ドットの対方式、文間の幅、最小離隔には外観上の選択も残る。これらの代表例を描き、利用者の外観確認と図形からの回収を経てから採否を決める。現時点で旧方式からの移行や新しい外観の固定は行わない。
