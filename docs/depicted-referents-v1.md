# 描写側と指示対象側の範囲を結ぶ

第四文の冒頭で捨てる対象を、第三文で足枷として描いた規定・定型表現へ対応させる候補を追加した。描写の足枷と指示対象を物理的に同じ物とせず、同じ人物について、両側の範囲を網羅する対応を要求する。[カント原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)の第三文から第四文への接続を採る解釈である。

既存の第四文には、描写上の除去対象を選ぶ `h2s` があった。しかし、その対象と先行する規定・定型表現との対応は未接続だった。新しい構成は、描写側の一部だけに対応があればよいという状態も、先行する指示対象を一部取り落とす状態も拒否する。

## 二つの範囲を同時に検査する

一般形 `r2gf` は、非空の二つの範囲と、対象間の対応関係を受け取る。それぞれの範囲の全要素が少なくとも一つの対応辺に参加し、全ての辺の両端が指定範囲に属することを要求する。一対一や物理的同一性は要求しない。多対多、複数の描写対象と一つの指示対象の対応も表せる。

`r2gg` は、非空の人物範囲の各人についてこの検査を行う。人物の範囲外にある選択や対応辺も検出する。範囲外の人に属する入力を先に除外することや、別人の辺を使って不足を埋めることはできない。

この一般形は比喩に固有ではない。二つの表現や模型の部品を対応させる際にも、対象と対応関係の意味を指定して使える。ただし、対応関係の解釈そのものを自動で発見する演算ではない。

## 原文への接続

`r2gh` は第一文からの人物範囲を提示文脈で固定し、描写上の除去対象 `h2s` と、先行する種類記述を受ける指示対象 `hzzzm` を、対応関係 `hzzzn` で結ぶ。先行箇所・著者・人物・文脈をそれぞれ保つ。規定と定型表現の種類 `r2fh` は引用して渡すため、その内容や世界での作用を実行しない。描写内の後状態を見て、指示対象を選び直すこともない。

`hzzzm` は、先行する種類記述を受ける指示の解釈である。任意の対象を選んでよいという入力ではないが、その適切さを機械的に測定できるとはしない。`hzzzn` も同じ先行比喩を受ける対応を与える解釈入力であり、それだけで除去や能力の獲得は成立しない。

`r2gi` は、この対応を第三文の既存の主張・比喩・同格・言い直し・順序へ接続する。第四文から第三文への逆順は拒否する。第四文の条件部分を受ける `r2gj` と、理由部分を受ける `r2gk` は、同じ `r2gi` を使う。片方だけが別の先行箇所や人物の対応を借りることはできない。

六定義と二つの指示解釈入力を追加した。本文の索引13・53の二文を改訂し、残る52文と既存の全宣言・意味規約を保持する。第三文までの文単位408文字、十二全単位2,212文字の判断は変わらない。

## 検査と未完の範囲

二つの対象集合と対応辺の256組合せ、人物範囲と選択の64組合せを検査する。片側だけの網羅、範囲外への辺、別人の対応、指示文脈と描写時点の混同を対照例で区別する。多対一・一対多も受け入れる。

実際の除去の定義も実行し、次の二つを分ける。対応が完全でも足枷を外したことにはならない。逆に、身体的な除去が成立しても、指示対象との対応が欠けていれば新しい接続は成立しない。二つの帰属部分についても、先行する主張・条件部分・理由部分・対応の16組合せと順序の対照を検査する。引用内容の真理は未知のままにしており、帰属を通すために内容を真に置き換えない。

今回接続したのは指示対応である。規定への依存をやめること、知的課題への不確かな取り組み、不慣れの原因説明を持つ比喩の対象側の条件文はまだ必要になる。既存の身体的描写は残しており、第四文全体の意味一致とは数えない。譲歩・尺度・限定、自由な運動の種類、第五文と段落全体の判断も未完である。原文対応範囲と意味確認済み分量は増やさない。
