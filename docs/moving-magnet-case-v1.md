# 磁石が動く場合の説明

導入u0003[550,770)は、前文の「通常の理解」が区別する第一の場合を説明する文として読む。磁石が動き導体が静止するなら、磁石周囲にエネルギーを持つ電場が生じ、導体の部分がある場所でその場が電流を生む、という条件内容である。nämlichは先行する区別の具体的な説明への接続とする。

eidmは前二文と同じ磁石・導体・結合設定を保ち、同じ評価系と区間で磁石の全物質点履歴に運動を、導体の全物質点履歴に静止を要求する。事例の範囲eisapは準備と記述尺度で固定し、生成する場や電流が成功した組だけを選ばない。

電場は既存の源帰属eirwと単位・成分場の規約を引き継ぐ。eisalは磁石周囲として選んだ空間範囲、eisamはその源の過程に伴う場の生成という物理的帰属である。単なる数値場の指定や共存とは分ける。entstehtから全空間の場が直前まで零だったという時間条件は補わない。eidoで同じ場の非零な成分を持つ点を要求し、eidnで導体の全物質点の全区間の位置を同じ領域へ接続する。全点での非零場や球状の範囲は要求しない。

eisanは同じ電気側の場と領域のエネルギーを、仕事やエネルギー交換の収支で扱う量として帰属する。エネルギー単位は力と変位の積による仕事の基準に整合させ、零の電気的場を零基準とする。数値だけ、磁石の運動エネルギー、電気側と磁気側の合計に置き換えない。eidpは時刻と非負値の妥当性、eidqは全区間での帰属を要求する。「あるエネルギー値」は各時刻で定まる値と読み、時間一定性を加えない。密度の公式や特定の単位系、実際の測定記録を原文へ追加しない。

eisaoは電気的な場の作用を通じた導体の輸送応答という、一般的な物理的生成の帰属である。既存eicaの閉じた局所作用型を渡し、同じ導体・系・状況・単位・場・領域・断面範囲・履歴を共有させる。該当する局所記録は導体内部の位置での場評価、荷電担体への電気的作用、同じ時刻の断面輸送へ結ぶ。一つの担体の一力を全応答の説明にはせず、指定された全電流履歴への帰属を要求する。

eidrは既存eibfによる全断面履歴の妥当性と、同じ断面・向き・時刻での非零の電流を結ぶ。電流が全場所・全時刻で非零であるとはせず、符号反転や零交差を許す。「生む」を、刺激を除けば全介入解で必ず応答が消える既存eicdの強い因果対照へ狭めない。原文の物理的説明を記述することと、その説明の経験的真理や微視的機構を証明することを分ける。

eidsはこれらを同じ設定へ接続する。eidtは磁石運動・導体静止の前件から、エネルギーと電流の履歴および場・電流の証人が存在するという結論を構成する。eiduは許容する全候補へこの条件を述べる。eidvは前二文と同じ談話対象への適用で、eidwはその閉じた内容を通常の理解へ帰属する。eidx/eidyは主張の提示と著者・文書への帰属、既存ufによる先行文の説明、本文順序を保持する。引用した物理内容は帰属を評価するときに実行しない。
