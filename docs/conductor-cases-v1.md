# 同じ導体の二場合と電流一致の条件

導入u0003で繰り返されるLeiterを、二場合で同じ右側物体として接続する。前の[導体の読み](conductor-reading-v1.md)は性質評価の可能な試行を使うが、原文が比較する電流履歴とは別である。この区別を引数と条件文の構造へ反映した。

eicjは同じ物体が両状況でeiciの能力を持つことを要求する。基準・単位・閾値・最小時間・試行規約は共有する一方、能力を示す試行と可能結果は両場合で異なってよい。本文で現に流れる電流をその試行履歴で代用しない。

eickは、逆の運動・静止の役割を含む同じ相対運動、両状況での導体の能力、比較の準備条件をまとめる。新しい基礎関係eirsは、指定した範囲で同じ材料・内部状態・回路などを保って比較するという物理的入力である。形と座標が一致するだけでそれらを認定せず、誘起される電場・起電力・電流・エネルギーの一致を準備条件へ含めない。

eiclは「eickの前件が成り立つなら、同じ全断面の電流履歴が一致する」という条件内容である。前件に電流一致を入れていないため、比較条件を満たしていて電流が異なる解釈では偽になる。eicmは前件と電流一致をともに要求し、前件不成立でeiclだけが真になる場合を、条件を満たした比較例から区別する。いずれも物理法則を処理系が証明したという主張ではない。

実際の電流を比較するeibiには、能力評価の閾値や最小時間を渡さない。零電流、閾値より小さい電流、途中で符号の変わる電流も、二場合で同じ大きさと経過なら一致として扱う。この例にどの電流が実際に生じるか、電場や起電力がどう説明されるかは、原文の残る内容として別に記述する。

有限検査では、前件の四条件と電流一致の全真偽組合せ、64引数の変更と位置を識別する別値を確認する。能力の存在量化は本体を実行し、両場合で別の試行・結果が成功する例を使う。電流の三種類の線形履歴は宣言した全履歴境界として比較し、有限標本で一般の実数履歴を証明したとはしない。原文の六使用箇所は[参照接続記録](../data/conductor-case-binding-v1.json)に保持した。

まだ左側物体の磁石としての性質、電磁相互作用、例示・呼びかけ、通常の理解への帰属、場・起電力・エネルギーは未接続である。既存の剛な参照配置・尺度・時刻対応と比較準備範囲を原文へ適用する解釈も明示する必要がある。本文207主張と著者表示判断を保持し、導入段落全体を意味確認済みとはしない。
