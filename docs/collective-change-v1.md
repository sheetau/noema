# 同じ過程で変わった構成員の範囲

集団内の一人への働きかけを記す既存の構成から、同じ過程で変化した人々の範囲を取り出す定義を追加した。一人の変化を集団全体の啓蒙として扱う前に、誰の変化を集め、どの広がりを要求するかを区別する。

一般定義`rqsw`は、構成員の範囲と各人の変化条件を受け取る。両方を満たす人の範囲を内部で作り、元の構成員範囲とともに広がりの基準へ渡す。元の集団と変化した人の範囲はどちらも非空でなければならない。集団外の成功者を混ぜたり、変化を評価していない人を落として成功者だけの集団へ取り替えたりしない。

広がりの基準は明示的に選ぶ。`rqsy`は異なる二人が変化したこと、`rqsx`は構成員の全員が変化したことを要求する。一人以上という条件は`rqsw`自身が持つ。二人や全員を「公衆の自己啓蒙」の既定の意味にするものではない。他の基準も同じ二つの範囲を引数に取る式で書ける。範囲を受け取る基準は、閉じ込めた文脈を使って他の条件を調べてもよい。

原文に向けた接続`hzmw`は、既存の`h6b`を使う。集団、変化過程、開始点、終了点、評価の基準時を共通に固定し、その条件で内部の当事者と活動部分がある構成員を変化範囲に含める。当事者や活動部分は対象者ごとに異なってよい。違う過程や違う前後時点の成功を合算しない。

個々の変化では、能力の前後の評価、前状態から目標状態への移行、対象者への作用、内部の人が参加する活動部分、その部分による同じ対象者への結果生成を保持する。すでに能力を持っていた人を新たな変化として数えない。外部からも助けられたことは除外理由にならないが、内部の関与がない場合は満たさない。獲得過程で他者が関わることと、獲得後の能力使用が他者の指導に依存することも区別する。

## 検証

構成員であるかと変化したかの64組合せを調べ、広がり基準へ渡る二つの範囲を毎回観察する。空集団、空の変化範囲、集団外の変化、未知の変化や未知の基準を検査する。

既存の能力・変化の定義を実際に評価する16対照では、一人・複数人・全員、集団外の二人目、別の過程・開始点・終了点、欠けた因果、指導に依存する結果、内部関与の不在、重複した構成員を区別する。異なる内部当事者と活動部分、外部からの追加の援助も扱う。二人目がすでに能力を持っている例では、その人を変化範囲から外す。

一般形は意味評価のメモ化なしで調べる。原文側の多重の存在量化では、式を短絡変換せずにメモ化を使う。一人の因果的な変化の具体的証拠は、メモ化なしでも同じ結果になることを検査する。構文木の一部を基本関係へ置き換えて済ませる検査ではない。

前段の程度比較の六定義も、同じ拡張候補へ収めた。定義だけでなく、数値確率を補わないことや最大値の手前として読むことなど、元の適用上の制限も引き継いで照合する。新しい基本記号は追加せず、既存32文・全宣言・全意味規約と、確認済み七単位の選択ハッシュを保存する。三つの文書について代用表記・通常表記・固有文字の往復を調べる。確認済みの現行本文と登録簿は据え置き、今回の文書は追加定義を持つ候補として扱う。

## 残る原文の内容

この構成は「同じ集団で同じ過程により能力を得た人々」を記述するもので、公衆の公開性や全体の啓蒙を説明し終えていない。構成員は現在の`mp`による固定範囲で、加入・離脱は含まない。変化しなかった人の状態、能力を失った人、変化の持続、態度の伝播を、この正の変化範囲だけから推定しない。集団全体の進展を述べる場合には、そうした条件も含む読みを別に明示する必要がある。
