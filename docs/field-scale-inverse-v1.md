# 逆係数と、値1を選ぶ条件

アインシュタイン1905の係数の積・対称性による等値・値1という結論と、係数を除いた最終六式を部分記述した。著者の推論を記録することと、その前提から結論が導けることを分ける。

## 逆変換で残る係数

[一般用文書](../examples/v014/field-scale-inverse.noema)では、二つの係数の積が1になる条件 `sam2` と、符号の異なる二種類の成分混合を往復させる `sax2`・`say2` を定義した。β²(1−r²)=1のもとで、往復後の値は「第一係数×第二係数×元の値」になる。

この積が1なら両係数は零でなく、成分は元に戻る。一方、零の成分だけが戻ったという事実からは係数の積を決められない。元の値が非零である場合に積1を結論できることを、有理数の一般式で検査した。実際のNoemaの混合・逆座標変換と場の係数乗算 `sal2` を組み合わせた検査でも、正・負の逆係数を区別せず往復することを確認する。

## 対称性と正の枝

[論文文書](../examples/v014/einstein-field-scale-inverse.noema)では、次の内容を分けた。

- `saq2`：正負の速度に対応する係数の積が1。
- `sar2`：正負の速度に対応する係数が等しい。
- `sas2`：上の二つを採用した前提。
- `sat2`：係数が1という結論。

両係数が−1なら、`sas2` は成立して `sat2` は成立しない。前提に正の条件を補ってしまうと、原文の主張と実装側の追加条件が混ざる。そのため、正の係数を要求して値1を結論する `sap2` は独立した数学的注記にした。本文の結論は著者の推論として保持する。物理的な向きの規約、連続性や対称性の具体的な理由まで、この反例で否定するものではない。

最後に、先行する共通係数付き六式と値1を合わせた前提 `sav2` から、係数を1とした六式 `sau2` を提示する推論を記述した。場と座標系の割当、逆座標変換、領域の一致は先行する定義を再利用する。
