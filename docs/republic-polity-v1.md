# 公的な共同体と最高統治職の共同保持

第十段落第一文の `ein Freistaat` を、最高権力が複数に委ねられる共和国として具体化した。保存済みのAdelungの電子転写では、Freystaatの狭い用法がRepublikへ導かれ、その狭い語義が市民的共同体の最高権力の共同委託を述べる。1811年版であり、1784年のカントの唯一の用法を確定したり、原刊画像を照合したりした証拠とはしない。

旧 `rwp` は、同じ一つの最高役職の全保持者が二人以上の人であり、全員に決定への影響可能性があることを構成していた。今回は未充足だった国家としての条件を、既存の非空の政治的成員範囲、対外的な合意を自らの公的行為として担う主体、市民的法秩序の非空の条件範囲と、その枠組みの運用へ結んだ。人間個人、私的な会社や委員会の規則だけではこの枠を満たさない。

秩序の運用と、その規則に誰も違反していないことは分ける。現実の紛争や騒乱だけを理由に分類から外さず、秩序が提案や過去の文書として存在するだけの場合も分ける。現代の国籍法・外交承認・領域の一括要件や、制度の道徳的な正当性を補わない。ここで使う国家的な公的制度の分類は公開した基本関係を組み合わせたもので、国家論の全分解ではない。

最高職には同じ共同体の統治役職の全範囲と推移的な上位関係を渡す。さらに上の君主や比較不能の役職を隠して、合議委員会を最高権力としない。保持者は現在の保持関係から過不足なく列挙し、全員の同じ共同体による有効な任用と職務委託を別に要求する。任用が確認できない者を名簿から除いて成功させることは認めない。

同じ名簿の位置に対応する公式の決定規則を用い、他者の入力を固定して本人の入力だけを変えれば結果が変わる組合せが、全保持者について存在することを旧 `rwm` で確認する。名目上二人いても、一人以外が常に無関係な規則は通らない。多数決、全員一致、等しい重み、普通選挙、実際の投票や法案採択は加えない。一つの最高職を共同で担う制度モデルであり、連邦制・権力分立等を含む歴史上の全共和国の必要十分条件とはしない。

四定義 `r6fr–fu` と、法秩序の運用・保持者名簿・公式決定規則の三入力を追加した。旧最高職の構成と、既存の公的制度・役職の意味は保存している。検査では二保持者の全16決定規則、欠落・重複・非人間の保持者、任用・委託の欠落、上位役職の隠蔽、秩序の運用と全引数の対応を確認する。国家的条件と最高職の統合は実際の本体を実行し、存在量化の全位置は別に二値域で調べる。

この分類を、危険を認める試みの非許可、集団としての同じ発言、引用命令との対比へ渡す作業は残る。第一文全体の意味判断はまだ行わず、本文119主張・登録簿v203・19全単位判断と確認文字数を保持する。
