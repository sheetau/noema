# 移動する領域への所属と同じ内容の持続

アインシュタイン1905年論文のu0205には、動く球面をエネルギーが横切らず、同じ光の集合を包み続けるという記述がある。このうち、各対象の所属が全時刻で変わらないという条件と、境界に対する相対的な流れが零という条件を記述した。固定ラベルと等速経路による解釈モデルであり、ラベルを物理的な光子として扱う定義ではない。

対象の個数や総量だけでは、同じ内容が続くかは決まらない。一つが出て別の一つが入れば、個数は変わらなくても対象は入れ替わる。最初と最後の所属が一致する場合にも、途中で出入りした可能性が残る。これらを、対象ごとの所属と指定期間の全時点への量化によって書き分ける。

## 定義

| 記号 | 記述する条件 |
| --- | --- |
| `sefa` | 対象範囲の各対象について、指定した二時点の所属が一致する。 |
| `sefb` | 基準時点が期間に属し、期間内の全時点で各対象の所属が基準時点と一致する。 |
| `sefc` / `sega` | 有理数／実切断による等速経路の一成分 `offset + V*direction*time`。 |
| `sefd` | 有理数の相対的な流れの成分 `current − density*velocity`。 |
| `sefe` / `seff` | 非負の流入量と流出量が等しい条件／両方とも零である条件。 |
| `segb`–`segf` | 三次元の等速経路、その点の移動球への所属、初期時刻と指定時刻の所属の一致。閉内部と球面を別々に扱う。 |
| `segg` | 有効な全実時刻について、閉内部と球面への所属が初期時刻と一致する。 |
| `segh` / `segi` | 対象ラベルから初期位置を得て、指定時刻の所属／各ラベルの全時刻の所属不変を表す。 |
| `segj` | 非負の密度について、流れ `j` と球の速度 `V*n` が `j − density*V*n = 0` を三成分とも満たす。 |

`sefa`と`sefb`は光や座標を使わない。例えば、容器内の部品を識別番号ごとに追う場合にも同じ定義を使える。期間に含める時点を省けば、その時点の所属は拘束されない。空の期間は基準時点を含められないため拒否するが、空の対象範囲では各対象への条件は自動的に成り立つ。対象が実在するという主張には別の存在条件が必要になる。

球の中心は`V*n*t`、各経路の位置は`q₀ + V*n*t`である。その差は初期位置`q₀`なので、中心からの距離は時刻に依存しない。半径を正、方向を単位ベクトルとして、内側・球面・外側を区別する。`segh`の初期位置関数は三つの空間成分を使い、時刻成分を使わない。ラベルの範囲と初期位置の対応を途中で取り替えることも、このモデルには含まれない。

相対流れが点ごとに零という`segj`は、明示的に採用した強い輸送条件である。球面全体で流入と流出が相殺されるだけの場合とは区別できる。一方、この条件だけで物理的な構成要素の生成・消滅まで排除したとはしない。電磁場からエネルギー密度と流れを構成する法則、局所的な保存則、境界積分との接続は別に記述する必要がある。

## 検証した範囲

- 二対象・三時点の所属64通りで、二時点の一致16通りと、全三時点での持続4通りを区別した。途中の出入り、対象の入れ替わり、空の期間、範囲外の対象など7対照例も検査した。
- 一般の対象領域について、期間内での基準時点の変更など3法則を一階論理の検査器で確認した。二時点だけから持続を導く主張と、期間外まで一致を拡張する主張には反例がある。
- 有理数上で、中心からの二乗距離の不変、時間を分けた移動の合成、相対流れの零、出入りがともに零なら差し引きも零という4性質を検証した。流入・流出が等しいだけの場合と、球を静止させた場合について2つの誤った主張を退けた。
- 実切断の演算を登録済みの有理数切断で解釈し、36経路、5つの不正な幾何条件、9つのラベル・時刻の組合せ、8つの流れの条件を検査した。全文草案と独立抽出文書の結果は一致した。
- 全時刻の条件に真偽を与えた別の4例で、範囲内の対象の失敗が全体に反映されることと、範囲外の対象・空集合の扱いを検査した。これは条件の結合の検査であり、全時刻の条件自体の証明には数えない。
- 全実時刻への量化を有限検査器に渡すと停止することを確認した。有限時点の検査結果を、実数全域の証明へ置き換えない。

これらは定義の検査であり、原文との全文意味一致の検証ではない。u0205の二つの短い範囲を部分対応として追加した。「したがって」という著者の推論の提示、同じ光の集合への物理的な帰属、後続のエネルギーを問う発話は残る。著者の主張を保存する既存173文は変更していない。

## 成果物
