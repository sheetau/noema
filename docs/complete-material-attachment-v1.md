# 物質部分の全範囲と不変な付着

前段の[不変な電荷の付着](attached-material-charge-v1.md)は、宣言された部分族の全てで電荷を一定にする。ただし部分族を空部分と全体だけにすれば、内部の交換がその族に現れない。原文の不変な付着へ適用するには、部分族を選んで不一致を除外できない条件が必要である。

ekxzは既存eisvyの物理的な部分保有量について、有効な実数値が存在することを表す。ekx2は、同じ時刻・出来事・物体・分布・量種・単位の下で、その存在条件と部分族への所属を双方向に一致させる。さらに同じ出来事で全部分を固定部分量へ結び、全空間逆像を空間保有量へ接続する。完全性の確認だけを別出来事へ分けない。ekx3はこの条件と、同じ小さい剛体の条件を共有する。

適格な部分を新しい任意の真偽関係にしてはいない。eisvyは物理的な量の帰属全体であり、測定済みの標本一覧や記録の有無ではない。未知入力は不存在と扱わない。一方、物理的に有限な量を持たない部分にまで有限値を強制しないため、全ての任意部分集合を無条件に定義域へ入れることもしない。

検査では二部分の電荷が2と−1から3と−2へ移る例を使う。全体量1は変わらない。空部分と全体だけを選べば旧条件が通ることを確認し、物理的には個々の二部分にも有限量があるため、新条件がその粗い選択を拒否することを確認する。旧定義・検査記録は保持し、以後の本文接続にはekx2/ekx3を使う。

複数担体の成分と場の全分布、評価系の対応、イオン・電子、理論の基礎という文全体の統合は残る。有限診断を連続体の全部分・全時刻の証明、又は原文の全単位判断としない。
