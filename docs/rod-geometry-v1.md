# 棒の長軸・静止長・全物質点の並進

u0029の棒は、直線状の長軸を持つ巨視的な物体として読む。長軸の端面中心は幾何学的な標識として与え、必ずしも物質点とはしない。これにより空洞のある棒も扱え、全物質点を一本の線上へ押し込めずに済む。形状上の端面・中心の同定は物理的入力として明示し、座標値だけから推定しない。

二標識の座標には、同じ系・単位・時刻規約の全区間履歴を要求する。正の長さの二乗を二標識の距離二乗へ結ぶ。長軸をX軸上へ置く条件は、両端のyとzが零、xが異なることとする。X軸に平行でも横へずれている配置は含めず、端点の順序や棒の向きは固定しない。

剛性には既存の全物質点対の距離保存を使う。静止は全物質点の全区間履歴で要求する。等速並進も全物質点と順方向の全時刻対を対象とし、同じ正の速度でxが時間に比例して変わり、yとzは変わらない条件を既存sbmへ接続する。端点だけが並進して内部が変形する場合や、区間端でだけ等速の式に合う場合を除く。

静止時の長さを指定する条件と、運動後の区間の条件は別にした。運動後にも同じ長さを要求せず、加速過程の実現や任意の系での長さ不変は導かない。全実数時刻にわたる条件は有限標本で認定せず、検査では局所の代入・数値・引数の接続と全域評価の拒否を確認する。

原刊895頁のu0029を照合したが、今回はこの依存群を構成する段階である。原文の静止した物差しによる測定、同じ棒を移す想定、二操作による長さへの問いと著者帰属への接続が残る。新しい全単位の意味判断は追加しない。
