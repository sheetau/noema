# 同じ物質領域の密度・体積・電荷

一様に並進する物質領域について、二つの系で測る密度と体積を結び、総電荷が一致する条件を記述した。二系の同時刻面は異なるため、旧系のある時刻の領域を座標変換するだけでは、新系で同時に測った体積にはならない。

原文u0238は、物体が任意に運動する場合に、随伴する系で電荷が変わらなければ静止系でも変わらない、と述べている。今回はその前段の一様並進に限った構成である。任意の加速・変形、非一様な電荷分布、領域の境界を横切る電荷を含む一般の保存則は未完であり、対応表では解釈注記として記録する。

新たな原始概念と著者の主張は加えず、既存の型・量化・数式・実数切断を使って7定義を追加した。親文書の宣言と174件の本文主張を保存する。

| 構成 | 内容 |
| --- | --- |
| `senc` / `senf` | 同じ物質点の等速並進とローレンツ座標変換を結ぶ。有理数版／実数版 |
| `send` / `seng` | 新系の同じ時刻で物質ラベルから位置へ移すときの伸縮・せん断係数 |
| `sene` / `senh` | 密度の変換、体積の変換、両側の総量＝密度×体積を共有する値で結ぶ |
| `seni` | 同じ物質領域、二系、二つの切片、密度・体積・電荷の割当を結ぶ |

光速度をV、基準系の速度をv、物質の旧系での速度を(uₓ,uᵧ,u_z)、正規化係数をβとする。物質点を旧系のt=0の位置(aₓ,aᵧ,a_z)で識別し、x=aₓ+uₓtなどの等速並進を記述する。D=V²−v uₓ>0を要求する。Dが正という条件だけで、物理的に許容された荷電物体の運動だと認定するわけではない。

新系の同時刻τを固定すると、旧時刻は次の関係を満たす。

```text
β D t = V² τ + β v aₓ
```

したがって、同じτでもaₓが違えばtが違う。例えばV=5、v=3、uₓ=1、β=5/4、τ=2なら、aₓ=1の点ではt=43/22、aₓ=2の点ではt=23/11となる。この差を消すと、同じ物質領域の新系での同時刻体積を正しく指定できない。

同じτにおけるラベルから新しい位置への写像は、変換後の速度を(u′ₓ,u′ᵧ,u′_z)として、次の形になる。

```text
ξ = L aₓ + u′ₓ τ
η = aᵧ + B aₓ + u′ᵧ τ
ζ = a_z + C aₓ + u′_z τ

β D L = V²
D B = v uᵧ
D C = v u_z
```

ラベルに関する線形部分は三角行列で、行列式は正のLである。同じラベル領域の体積WとW′にW′=LWを課す。一方、先行版の密度変換はV²ρ′=βDρである。この二式とQ=ρW、Q′=ρ′W′からQ=Q′が帰結する。総電荷の等値を前提に加えて結果を作ったわけではない。ただし、一般の三次元測度に対する体積変換定理の機械的証明は未完であり、ここでは同じラベル領域への幾何学的な体積条件を明示して使う。

ここで積に用いるρは共通の規格による電荷密度として解釈する。原文の電場の発散として定義されたρを、そのまま物理的な電荷密度の値と同一視しない。先行版の4πによる換算条件との接続は、今回の領域・総量の構成にはまだ含めていない。

例えば旧密度4、旧体積11の場合、新密度22/5、新体積10となり、総量は両方44になる。密度だけ、または体積だけが不変なのではない。密度と電荷は負や零も許す。零電荷を理由に物質の速度を零とは決めない。

`seni`は同じ物質領域を二つの系・切片に結び、各側の密度・体積・総量がその領域へ割り当てられていることを要求する。`paired`と`assigned`は、対応と量の解釈を明示する入力である。数値が一致するだけで別の物体・系・切片を転用しない。二切片が同じ座標時刻や同じ出来事であるとも仮定しない。座標ごとの全場の構成や、実際の物体の追跡をこの引数だけで証明したことにはならない。

検査では、有理数について密度・体積の相殺、総量の一致、伸縮係数の正値、静止時の体積収縮、同時刻切片の旧時刻と位置写像を確認する。密度・体積がそれぞれ不変という二つの誤った主張には反例を保存する。実数版は、有理値の切断への埋込みによる54設定と、座標・係数・総量・物体・系・切片の取り違え42例で検査する。非正体積とD≤0の拒否、未知の対応関係の拒否も確認する。
