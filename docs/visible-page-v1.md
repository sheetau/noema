# 可視文書の行継続と段落

## 対象と読み方

一行の[可視構文](visible-syntax-v1.md)を、型付き定義・入れ子の引用・仮定の範囲を維持して複数行へ配置する。意味演算子や基本語は追加せず、固定した円の大きさと方向から行標識を構成する。旧ページや既存の可視構文の証拠は保存する。

ページは上から下へ、各行は主円の中心の左から右へ読む。行間の空白は行を分離する。空白の大きさだけでは文・段落・引用の終わりを決めない。各行には可視の開始標識、0から始まる行順の自然数、本文、終了標識がある。行順は束縛距離と同様の構造上の数であり、語の意味を文書専用の番号へ割り当てるものではない。

| 標識 | 形 | 半径線の方向 |
| --- | --- | --- |
| 行開始 | 大円と中円の同心円 | 右下 |
| 継続する行の終端 | 大円と中円の同心円 | 左下 |
| 段落開始 | 大円と中円の同心円 | 左上 |
| 文書の最終行の終端 | 大円と中円の同心円 | 右上 |

この4形は共有語・名前の入口・既存文法の分類とは衝突しない。自然数には既存の二進表記と小円の終端を使う。段落開始の標識は行順の直後にだけ置ける。行内は一つの接続木とし、行間を直接結ぶ線は使わない。行の切断を空白だけで継続と推測せず、両側の行標識を読む。

## 折り返しと意味の範囲

文法分類と操作の2字形、新語の名前全体、自然数の桁列と終端は分割しない。これらの間であれば、式・型・宣言・仮定・引用の途中でも次行へ継続できる。行標識を外して全行の本文を順に連結すると、一行の文法と同じ列になる。復号器はこの列から構文上の不可分範囲を導き、各行境界がその内部に入っていないかを検査する。範囲を別のデータから渡さない。

段落開始は、文書直下の主張・質問・発話実行・仮定の開始に限る。仮定の内側の文や引用の内部を、段落標識によって外へ出すことはできない。段落位置は可視の構成情報として読み戻し、論理的な仮定や新しい量化の範囲にはしない。段落間に空行を増やしても読みに変更はない。

行順の連続性、最終行の終端、語・数・文法標識の不可分性を検査する。行の脱落・重複・入れ替え、最初や最後の行の欠落、段落標識の不正な位置、行間を結ぶ余分な線を拒否する。正しい別の本文へ書き換えた図形まで原本の破損と判定する規則ではない。これは署名や誤り訂正符号ではない。

## 実装と検証

実装は `scripts/visible_page.py`。入力は円と線の座標および学習する共有語彙・文法であり、行番号や本文のASTを不可視属性から読むことはない。出力SVGにも円と線だけを保存する。平行移動、共通倍率の拡大縮小、行の字下げ、行間の変更、行内の上下配置、線分の分割と格納順は、規則内なら同じ文書として読める。

一文書の可視要素は4096個、本文の字形は768個、行は128行まで。各行の字形・図形は既存の幾何検査を通し、行間にも規定の余白を置く。行幅に不可分な名前や数が収まらなければ、途中で切らず明示的に失敗する。処理系の資源制限と、言語の有限列の構成規則を区別する。

行幅は左の固定余白を含む描画枠の幅であり、追加の字下げは別の余白として扱う。段落の指定は文書直下の文の0始まりの位置で行う。出力では位置の番号を付属データへ保存せず、該当する文の開始行に段落標識を描く。

```powershell
python -X utf8 -m scripts.visible_page render examples/v016/visible-syntax-document-v1.noema output/visible-page-v1/reader-example.svg --width 2400 --paragraph 0 --paragraph 2
python -X utf8 -m scripts.visible_page decode output/visible-page-v1/reader-example.svg
python -X utf8 -m scripts.visible_page decode output/visible-page-v1/reader-example.svg --native
```

通常の復号結果は文書と段落位置を持つJSON、`--native` は意味内容のNoema本文である。後者には段落位置を含めない。描画先に異なる既存ファイルがある場合は、新しい出力先を指定する。

[同一文書のページ画像](../output/visible-page-v1/standalone-page.png)と、幅1800・2400・3600の[検証報告](../reports/visible-page-v1.json)を保存した。原文は前段階の自立文書と同じであり、可視の語形や構文を再定義していない。

```powershell
python -X utf8 -m scripts.project_work check --module scripts.check_visible_page --tests tests/test_visible_page.py --verify reports/visible-page-v1.json
```

局所検査では、宣言・新語・引数の型・負の分数・変数参照を含む文書の全字形境界を一つずつ折り返し、合法な境界は同じ文書へ戻り、不可分な範囲内の境界は拒否されることを確認する。二重引用と二重量化、仮定内の文、複数行の欠落・重複・順序違いも対照にする。これらは特定文書と規則への検査であり、任意の手書き画像や第三者の読解の成功率を測った結果ではない。

共有引数の融合、二論文の全語彙の可視化、人による読解試験は別の残課題である。このページの復号が通っても、固定した旧論文ページの復号が成立したことにはならない。
