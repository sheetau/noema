# 球面と座標系ごとの同時刻の形

アインシュタイン§4の `u0109`〜`u0115` を部分記述した。移動系で静止する同じ物体の表面を、前段の最終の四座標式によって静止系の記録へ接続する。球面の時空的な集合と、静止系の時刻t=0で選んだ表面の形を分けた。

```text
移動系: ξ²+η²+ζ²=R²
静止系: β²(x-v*t)²+y²+z²=R²
静止系のt=0: x²/(√(1-(v/V)²))²+y²+z²=R²
正の半軸: R/β = R*√(1-(v/V)²), R, R
```

半径Rは正、速度はv²<V²、βは正の枝とする。保存済みの数式構造では分母に平方根が含まれる。文字列だけの抽出では平方根が消えて見えるため、MathMLの構造を参照して式を保持した。原文の軸の値はRから始まるため中心からの半軸として読み、端から端の直径とは区別する。原刊画像との照合はまだ行っていない。

`ssy` は正の半径の球面条件であり、内部を含む球体の条件ではない。`ssz` は同じ四座標記録の空間成分をこの条件に結ぶ。`stc` は静止系での移動を含む球面条件、`std` はその時刻零の断面である。`stf` は本文の平方根を保った断面式、`sti` と `stj` は半軸を使う回転楕円体の条件を表す。一般文書では運動軸の周りの回転によって表面条件が変わらないことも検査した。

`zhu` は出来事が同じ物体の物理的な表面に属する関係で、座標式への適合とは独立に与える。`stk` は物体の剛性、移動系での静止、中心と原点の一致、速度・単位、表面の所属と球面条件の一致を要求する。`stl` は同じ表面を静止系の記録で表す。どちらも非空の表面と測定記録を要求し、対象範囲の全記録について所属と式を双方向に結ぶ。内部の出来事を表面に加える、表面上の出来事を落とす、別の物体や記録のない出来事を混ぜる場合を退ける。

`stm` は静止系でt=0の記録を選び、その範囲内で表面と楕円体式を結ぶ。一般には、この同じ出来事集合は移動系で同時ではない。V=5、v=3、R=5の例では、静止系でt=0の両端x=−4とx=4が、移動系でτ=3/5とτ=−3/5になる。別々の系の同時性を同一の条件として使わない。

節題、球の設定、変換、時刻零の選択、楕円体という帰結、半軸の値を六つの帰属として分けた。著者が帰結を述べることを、その帰結の証明済みという判定にはしない。特に、時空的な表面条件だけではt=0の測定の存在を保証しない。零時刻の記録を持たない有限モデルでは `stp` が真でも `stq` は偽になる。全空間・全時刻の測定可能性を補う一般的な条件は残る。

新規9件を含む関連32テストが通過した。有理数の代数・反例9件、表面式11例、半軸9例、物体表面14例、同時性2例、帰属11例を含む。静止、負の速度、光速境界、負の半径、直径との取り違え、異なる測定記録を検査した。有限モデルでは座標測定と物理的な表面を外部解釈として与えており、連続空間の全域を検証した結果ではない。
