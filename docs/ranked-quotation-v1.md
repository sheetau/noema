# 評価を含む引用の試作（0.15、標準版には未採用）

カントの「職務上の義務に制約されない他の人々」への許可を、既存の意味定義から本文の主張へ接続する途中で、引用の制限が障害になった。0.14では、引用する式が別の記述を評価することを、参照先の定義も含めて禁止している。義務の内容を調べる一般的な条件 `hzg2` は、この制限により引用できない。

固定した一つの判断内容を全員へ適用すれば、引用できる形に狭められる。しかし、人ごとに異なる判断や義務を扱う原文の条件を保持できない。その置換は行わず、引用に評価層を付ける方式を別モジュールで試作した。**カント本文の著者主張への統合は未完了である。**

## 実装した範囲

試作の版記号は `o:`。型 `i[T]` と引用 `r[式]` は従来どおり層0で、`i b[T]` と `r b[式]` は層1、`i c[T]` と `r c[式]` は層2になる。層は既存の32進表記で指定し、先頭の余分なゼロを認めない。型と引用値の同一性に層を含める。

層1の引用内では、層0の記述を評価する式を書ける。層2では層0と層1を扱える。明示的な評価構文と、名前で参照する定義の依存先について、同じ層以上の記述の評価を拒否する。呼出先だけでなく引数内の評価も検査する。自由変数の捕獲、前方参照、再帰定義を許可する変更は加えていない。

[人物ごとに異なる内容を持つ例](../examples/v015/person-dependent-reports.noema)では、二人に別々の記述を割り当て、その双方の内容を調べる条件全体を引用する。引用を誰かへ帰属するだけでは内容を実行せず、引用を評価したときに本人に対応する記述を調べる。二人の真偽の4組合せで結果を確認した。これは一般的な機能例であり、カントの訳文ではない。

[カントの制約条件を引用する例](../examples/v015/kant-nonrestriction-description.noema)は、既存草案から `hzg2` と `hzg3` の定義と依存先を抽出したもの。旧版で拒否された `hzg2` への参照を層1で引用でき、引用の同一性を調べても義務の内容を実行しないことを確認した。この一文は引用機能の検査であり、著者による許可の主張を記述したものではない。

## 未解決の制限

**関数の引数を通じて実行される評価は、今回の層検査では追跡していない。** 例えば、層0で引用した関数が、後から渡された関数を呼び、その内部で層1の記述を評価する例が通る。この挙動を再現するテストも保存した。したがって、あらゆる実行経路で評価層が下がること、無矛盾性、停止性を保証した実装とは扱えない。

既存の評価回数上限と、同じ評価器が発行した引用値だけを受け入れる検査は維持する。ただし、これらを型・評価層の保証の代わりにはしない。記述の全領域への量化も、有限評価器では引き続き拒否する。既知の引用の一覧を全領域と見なす変更はしていない。

次に必要なのは、関数値が内部で行う評価を型や検査条件へ反映する設計である。その後、各人の判断内容と職務上の要求を保ったまま、著者・対象者・行為・条件・許可を本文へ接続する。引用可能になったことだけでは、この統合も原文との意味一致も達成していない。

## 検証と利用

関連23テストが通過した。層の違反、参照先に隠れた評価、型とJSONの層注記、外部で作られた引用値の拒否、表記の往復、既存の三文書の解析結果の一致を含む。二つの新しい例はCLI解析、長形式と固有文字の往復、SVGのXML検査も通過した。SVGの目視検査は行っていない。

通常の `python -m noema` と文語0.14の実装は変更していない。試作を実行する場合は専用入口を指定する。

```powershell
python -X utf8 -m noema.ranked parse -i examples/v015/person-dependent-reports.noema
python -X utf8 -m noema.ranked format -i examples/v015/person-dependent-reports.noema --script
python -X utf8 -m noema.ranked render -i examples/v015/person-dependent-reports.noema -o person-dependent-reports.svg
python -X utf8 -m scripts.check_ranked_quotation --verify-only
python -X utf8 -m pytest tests/test_ranked_quotation.py -q
```

出力先に既存ファイルがある場合は上書きしない。APIの `promote` は0.14文書のコピーを0.15へ明示的に移し、入力を変更しない。旧評価器と試作評価器の関数値・引用値は別のクラスであり、混用しない。

[検査記録](../reports/ranked-quotation-v1.json)には旧版の拒否、四つの人物別の結果、未統合の状態、成果物のハッシュを保存した。新しい原文対応範囲は増えておらず、248件・566文書の既存集計は据え置いた。集計が固定した818ファイルのハッシュも一致している。二作品とも意味一致の確認済み区間は0のままである。
