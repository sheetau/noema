# 補助概念の段落の参照順序

原文u0176では、磁動力への類推を述べる第一文に続き、第二文が補助概念の役割、その導入理由、根拠となる場の系依存性を述べる。旧本文は、末尾の根拠節が主節より前にあるという本文順序を含んでいた。原刊910頁と固定転記を照合し、主節から末尾の根拠節への順序に訂正する。

第二文全体には専用の位置参照を与える。主節の部分内容と、導入理由を含む第二文全体の内容を区別し、後者の同じ内容を著者による主張と「Man sieht」の提示へ結ぶ。主節は第二文全体に含まれるため、主節と文全体を前後に並ぶ二箇所とは扱わない。第一文から第二文全体への順序を記述する。

磁動力への類推、非空の全構成的使用における補助性、同じ概念の導入理由、電気・磁気の作用の系依存性については、既存の合成内容と採用解釈を維持する。今回追加する基本記号は文全体の位置参照だけであり、その取得から物理的主張や明白さを導かない。

旧宣言と旧判断はそのまま保存し、修正した合成定義を追加する。検査は原文の実際の文字範囲から旧順序の不成立と修正後の成立を確認し、文全体と主節の取り違え、提示内容の交換、未知の参照を区別する。型と表記の往復、有限検査、原文全体の意味判断は別の根拠として記録する。
