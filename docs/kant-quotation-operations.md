# 引用を組み立て、解く規則

`quoted_application`、`quoted_lift`、`disquote` は既存native構文の書記対応である。語義や引用の評価規約は変えない。通常の `quote` と異なり、これら三つの操作は引数式を現在の束縛範囲で読む。引数に `quote` が現れた箇所では、その引用の内側だけ範囲と命名順をリセットする。

`quoted_application` は通常の関数適用と同じ順序を使う。関数の記述を本文側の最初の子として読み、その公開型が記述する関数型から引数数を得る。残る子は通常の枝順の先頭部分に対応させ、元の引数順で読む。結果は関数の結果型の記述となり、順位は関数記述と全引数記述の最大順位である。復号器は式を評価せず、組み立ての操作そのものを復元する。

`quoted_lift` は記述を一つ読み、それをもう一段記述する型を返す。内側の記述の順位を維持する。`disquote` は記述を一つ読み、その結果型を返す。native構文に必要な順位注記は、引数の公開型から復元する。注記用の字形は追加しない。関数型・記述型でない値、引数の過不足を読取時に拒否し、引数型や引用内評価の順位制約は復元後の既存native検査でも確認する。

三字形は大円と小円を隣の罫線へ配置する。大円中心を `(x, PITCH)` とすると、小円の中心は `x ± sqrt(LARGE² − PITCH²)` と上段または下段に置く。このため中心間距離は常に大円半径であり、小円が偏心して内包される形にはならない。組み立ては左上小円と右下の半径線、持ち上げは右上小円と左下の半径線、復号は左下小円と右上の半径線を用いる。大円の斜線は上下端と同じ高さで終わり、先へ接続しない。外部との接続口は大円に置く。

三つの配置は従来の同段・同心の配置に追加する。上下の位置と線方向は公開された字形の違いであり、描画ごとに自由に回転して選ばない。幾何規則、既存根語と文法字形の非衝突、SVGからの構文一致を確認する。これだけで未使用の許容形や文書全体の外観が解決したとはしない。最終的な見た目は利用者の確認前に固定しない。

線分の記録の切れ目は読順や接続の根拠にしない。読取器と同じく、配置候補の検査でも同一直線上の連続した線を結合してから判定する。四本の線分の端点を重ねて作った十字交差を、二本の線を交差させた場合だけ拒否する食い違いを防ぐ。旧検査器は保存し、現行規則の入口で同じ正規化を適用する。
