# 担体の物体内相対移動と電気的作用

導入u0003の導体を記述する準備として、物体の参照配置と独立した担体の軌跡を結ぶ。剛体の構成点集合に担体を含めると、既存の剛性条件が担体の相対移動まで禁止するため、二つの対象と履歴を分ける。原文207主張と著者表示の意味判断を保持する。

| 記号 | 内容 |
| --- | --- |
| eibt | 同じ系・文脈・単位・区間での物体の剛な参照履歴と別の点状担体の完全な軌跡 |
| eibu | 指定時刻の担体位置が同じ物体の物質領域にあること |
| eibv | 区間の全実時刻での所在。両端だけの確認では成立しない |
| eibw | 物体付随軸で担体の位置が変わる、前後二時刻の証人 |
| eibx | その相対移動と、同じ軌跡上の出来事での非零電荷への電気的作用 |

新しい基礎関係eiroは、指定した座標・時刻・系・単位・文脈で物体の物質領域に属することを表す。物質のある表面を含め、穴や外接領域内の空間だけでは成立しない。物理的な所在の規約であり、有限標本による形状の同定ではない。既存zkは位置個体を使い、数値座標との対応がないため、その名前だけを流用しない。

eibxは電気的作用eibsの場評価用四座標を、同じ担体の軌跡と作用時刻へ成分ごとに結ぶ。出来事への担体の関与と座標割当も既存sbで要求する。電荷はその出来事で非零とし、時間不変、電子という種類、非零の力、電気的作用が移動の原因であることは要求しない。正味電流の存在や導電性は、この併存条件からは導けない。

検査は有理数の厳密な座標値を用いる。全履歴eiaq/seと全区間所在eibvは明示した境界で与え、投影・位置差・出来事接続sb・電気的作用eibsは本体を評価する。共通並進、共通回転、物体内の相対移動、回転する物体内の相対移動、途中で戻る運動を区別する。作用接続の全引数を変更し、別の出来事・座標・単位・担体・文脈を拒否する。eibvの全実時間量化は有限評価器が拒否することも確認する。境界の有限照合を全履歴の証明とは数えない。

参照物体の剛性と非共線な三標識点、担体の点状近似、物質領域の尺度は適用時に明示する必要がある。次は許容試行の下で電気的作用と通過電流を結び、材料を保持する条件、作用強度、応答時間を含む導体の解釈を定める。微小な漏れや破壊的な通過だけを導電性の根拠にしない。磁石・電磁相互作用などの残りの語義と導入全体の通読判断は引き続き未完である。
