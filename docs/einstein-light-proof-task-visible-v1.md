# 光速度保存の証明課題と未提示の証明

原文u0086を、光速度保存をこれから示す課題と、その課題を行う理由の提示として円文字本文へ接続する。既存の合成定義9個と意味規約4個を再利用する。参照型を追加せず、共通基盤375語を保つ。任意プロファイル51版は786語となる。

原刊900頁末尾から901頁冒頭に続く一文を、第44段落第一文の51トークンとして保持する。課題と条件は1–30、dennで始まる理由は31–51を指す。セミコロンと改頁を文の終わりとして扱わない。仮定採用への挿入的な振り返りも、課題の条件の内側に保持する。

課題の内容は、同じ設定において、静止系Kの全光区間に速度Vが成り立つなら、運動系kの全光区間にも同じVが成り立つという条件である。現在の各系の時計・測定規約を使い、特定の縦光線や後続の球面波の標本だけへ狭めない。両系の距離と時間の個別の数値一致は要求しない。

「仮定したように」は、同じ著者による先行箇所wuでの光速度原理の採用へ結ぶ。採用の対象範囲wvと、現在の課題を置く第三節を区別する。仮定の採用は、現在の速度法則の実証や、課題の達成を意味しない。

証明の未提示は、この段階までの同じ論説全体において、同じ著者が二原理の両立性の証明として提示した論証が存在しないという内容である。探索範囲を現在の節に限定しない。別の対象、著者、論説、後の段階の提示は数えず、論証の提示とその妥当性を分ける。未提示から両立性の否定や証明不可能性を導かない。

両立性は、同じ二原理が一つの許容設定で共に成り立つ余地として合成する。原理ごとに別の設定を用意するだけでは足りない。許容範囲を、両方が真になるものだけから逆に選ばない。証明未提示を課題の理由とする提示も、その理由の真理や論理的十分性とは別の関係として保持する。

段階zfxには既存の役割付き状況参照を使う。課題箇所、著者、引用した課題内容、候補段階、節、提示文脈を結ぶ閉じた役割を定義する。参照取得は役割や物理法則を実行せず、先行する原点定数の段階とも区別する。

検査では、条件の向き、同じ速度と設定、未対応の光区間、証明探索の全範囲、共通許容設定、引用の非実行、著者帰属、参照の各引数を区別する。旧検査のモデルを使う場合も、検査対象の定義は復号したNative本文へ置き換える。有限検査を一般の物理的導出や第三者読解の証拠とは扱わない。
