# 物体に付随する軸と相対運動

参照物体の同じ三物質点から、原点と右手系の三本の単位軸を定める。第一軸は原点から方向点へ向かい、第二軸は三点の平面内で平面点側を正とする。第三軸は第一軸と第二軸の外積である。三点が重なる場合や一直線に並ぶ場合は軸を決められない。数値が同じだからといって、別の物体の標識点へ付け替えない。

既存の内積sexbと正方向比較sexdを再利用した。eiajは三本の単位直交性と右手系、eiakは二つの標識変位への向きの対応、eialは同じ物体の全成員範囲と三点・同時刻の座標を結ぶ。方向点が原点から一単位の距離にある必要はなく、平面点への変位も第一軸に直交していなくてよい。

eiamは点から原点を引いた変位の内積で、一つの相対位置成分を得る。eian・eiao・eiapはこれを物質点と時刻の関数族にし、第一・第二・第三成分を返す。位置・原点・軸をすべて同じ時刻で評価する。軸を単位長に固定するため、参照側の軸の倍率を変えて相手の移動を隠すことはできない。

eiaqでは、参照物体の全区間履歴に加え、全時刻で同じ三点からこの軸が定まり、全成員の物体軸での位置が不変であることを要求する。三標識点だけが同じ配置でも、別の成員が変形すれば条件は満たさない。この定義は剛な参照配置を使う。非共線な三点を持たない理想化や参照側の変形は、別の扱いが必要な場合として明示する。

eiarは、異なる二物体の履歴を同じ評価系・時刻区間・長さ単位・時間単位で結ぶ。左側を剛な参照物体とし、右側は変形してもよい。eiasは右側の同じ成員が物体軸で位置を変える前後二時刻の証人、eiatはその存在、eiauは有効な全履歴の下で全成員の相対位置が不変であることを表す。絶対座標の変化や中心間距離だけを代用しない。

共通の並進・回転で二物体と参照軸が一緒に変わる場合、ここでの相対配置は不変であり得る。相手だけの回転や参照物体だけの回転では、中心間距離が変わらなくても相対配置が変わる。ただし、これは運動学的な配置の記述である。共通回転に電磁的な効果がないこと、回転する系が慣性系であること、異なる系の同時刻が一致すること、電流が同じであることは導かない。

有限検査では、符号付き座標軸の右手系と鏡映、非単位軸・斜交軸、標識点と各成分の取り違え、共通運動と相対運動、変形する非標識点の反例を確認する。既存の実数演算には構成して保持した有理数埋込みだけを与える。全履歴と実数全域の条件は有限サンプルへ置換せず、検査境界と評価拒否を記録する。

原文の磁石と導体へ適用する記述尺度、剛な参照配置を採る根拠、異なる二場合で「同じ相対運動」とする対応、磁石・導体・電磁相互作用の意味と全文への接続は残る。新しい基本関係や著者主張は追加せず、既存207主張と著者表示の判断を保持する。
