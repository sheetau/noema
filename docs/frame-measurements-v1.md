# 各座標系の物差しと時計による測定

アインシュタイン§3の `u0045` を部分記述した。静止系と運動系のそれぞれに、初期設定と同じ物差し・原点・三軸・時計を結び、位置の三成分と時計配置点の時刻を定める想定を表す。両系の座標値や時計の指示が等しいという条件は加えない。

位置の測定は、地点を各有向軸へ正射影し、原点から射影点までの符号付き距離を物差しで測る操作として展開した。この展開は原文の「空間を測り座標を求める」に対する操作的な解釈であり、原文がこの段落で正射影を明記したわけではない。射影と物差しの反復配置の構成説明は残る。

`sgj` は同じ地点・系・軸・原点・物差し・単位・文脈を測定値へ結ぶ。負値と零も座標として受け入れる。`sgk` は選択した座標の測定が存在し、他の有効な測定候補も同じ値になることを要求する。`sgl` はその条件を全地点の三成分へ課し、物差しがその系で静止することも要求する。静止系のx・y・zと運動系のξ・η・ζは、三成分の役割を異なる系へ結び付けて表す。

時刻の付与では、全配備時計を同期の対象範囲へ一致させ、同じ系で静止して空間内に置かれることを確認する。参照時計も配備時計の一つであり、全時計がその同じ参照時計へ同期する。同期条件には、§1で構成した光往復の全試行による定義 `qo` を再利用する。

`sgo` は、配備時計がある場所で起こる出来事と、その時計の読みを結ぶ。`sgp` は同じ出来事・場所・系について時刻候補の存在と値の一意性を要求する。`sgq` はこれを時計のある全地点の対象出来事へ適用する。時計のない地点に時刻値を補間することや、各地点で出来事が実際に起こることまでは含めない。

再利用する一般定義も独立した文書にした。`sgf` は場所と成分の全組合せへの条件、`sgg` は全配備時計の配置・使用条件・共通参照との関係、`sgh` は時計がある地点、`sgi` はその地点の全対象出来事への条件を表す。これらには基本述語を追加していない。物理的な意味は原文接続側で引数へ与える。

二つの測定想定は著者へ帰属させ、前段の平行な運動の設定から順に追加する。想定内容の引用は実行せず、現実の測定済み事実とは区別する。旧文書の宣言と主張は変更していない。

新規10件を含む関連40テストが通過した。二地点・三成分の64組合せ、時計配置と出来事の範囲12例、位置の接続20例、時刻の接続20例、整数切断の符号付き座標6例、両系への接続6例、帰属6例を扱う。別の系の物差しや参照時計、軸の交換、未配備の時計、座標・読みの欠落、矛盾する別候補を拒否する。同じ値の別表記、両系で異なる時刻、時計のない地点に時刻を要求しない場合を受け入れる。

存在と一意性の有限検査では、実数切断を有限の値の集合へ置き換える。時刻の検査は局所的な読みの条件を実行した後、その結果を外側の範囲検査へ渡す。空間の幾何と同期の物理条件は検査用の関係を与える。整数切断を使う検査も別に行うが、任意の実数値、全空間、連続時間や現実の測定精度を証明したものではない。

標準表記・圧縮表記・固有文字の往復、CLIのJSONと構文木の一致、SVGのXMLとしての妥当性も確認した。SVGの目視確認と全テストの再実行は含めていない。

一般文書は基本述語0・定義4、原文接続文書は基本述語248・定義197・主張32である。原文接続文書は継承分を含め44,090文字、追加は3,727文字。これは定義集の長さであり、一文の圧縮率ではない。原文の明示範囲が空白と数式マーカーを除き602文字増えた。原刊照合と意味確認は未完で、意味確認済み全文単位はアインシュタイン0/282・カント0/20のままである。
