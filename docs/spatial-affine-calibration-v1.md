# 現在の測定による空間アフィン成分の較正

u0081以降では、光線上で得た式を四座標の一般式へまとめる。そのために、現在の座標対応に属する一つのアフィン行列と定数ベクトルを、三本の光線と同じ移動原点へ結ぶ依存群を追加した。今回の段階では本文の著者主張や全文判断を増やさない。

## 同じ行列行と全入力延長

ei6yは空間候補zfhの各成分を、同じ行列の対応する一行と定数成分による全実数四入力のアフィン式へ結ぶ。ei6zはその関数を現在の同じ出来事対応eiyyにも結ぶ。測定された入力の範囲と、同じ式による全入力延長を区別する。任意の四数の組が現実の出来事として存在するとはしない。

三本の光線の値だけでは、空間成分のアフィン関数は決まらない。たとえばV=5、v=3、横成分w=4では、4x+2y+2z−20tは三本の光線上で零になるが、移動原点x=3t、y=z=0では−8tになる。この行を加える余地を除くため、原点の別の正時刻での値を保持する。

ei63は同じk原点の実際の出来事を、現在のK/k両測定、全k静止・K並進、全一次軌道と出会いへ結ぶ。その出来事のK時刻は正で、現在の運動区間内にある。K位置は(v*t,0,0)、kの三空間ラベルは零である。時刻を1に固定せず、kの時刻とKの時刻も等置しない。

## 実際の時刻を使う五点条件

ei64は零点、移動原点の正時刻、三光線のそれぞれの正の到達時刻で候補関数の値を指定する。縦と横二方向の時刻は独立に選べる。ei65は各数値入力を実際の光線と原点の到達出来事から取り、ei62によって同じ候補関数をその両系測定へ結ぶ。

五点一致だけで非線形な関数を排除することはできない。全入力でのアフィン性はei6yで別に要求し、同じ五点で零になる非線形な付加項も検査する。原点の値と同じ全入力アフィン性を必要とする五点の十分条件は、原文の省略を補う採用解釈として明記する。

## 検査と残る接続

検査では、同じ行列行と定数、全現在座標対、具体的な両系測定、原点履歴、各光線の時刻、同じ未定係数aを変えて区別する。独立な正の時刻を持つ有理数のアフィン較正補題も検査する。全実数入力と関数の存在量化は有限評価を拒否する。

有限の関数指紋は結合検査の境界であり、一般の関数同値や物理法則の証明ではない。次に現在の全座標範囲へ四式を結び、x′の置換、φ=aβへの再表示、βの定義と著者の提示を統合する。
