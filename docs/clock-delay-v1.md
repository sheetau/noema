# 時計の遅れと二次近似

アインシュタイン§4の `u0125` を部分記述した。前段の同じ時計と照合記録に、一秒あたりの遅れ、秒で表した経過量、二次近似、四次の残差を接続する。近似値を厳密値と等置せず、原文にない具体的な誤差の上下限は補足として分けた。

```text
u = v/V, |u|<1
進み率 f = √(1-u²)
厳密な遅れ率 l = 1-f
二次近似 a = u²/2
残差 e = l-a

観測の経過がT秒なら:
  時計の指示の経過 = T*f 秒
  厳密な遅れ = T*l 秒
  近似した遅れ = T*a 秒
  近似の誤差 = T*e 秒
```

`svq` は許容速度と正の進み率から、厳密な遅れ率・近似値・残差を同時に結ぶ。対象速度での三つの値を `svt`、`svu`、`svv` として定義した。速度が零でなければ二次近似は厳密な遅れを過小評価する。V=5、v=3では、厳密値1/5、近似値9/50、残差1/50となる。

遅れ率は無次元であり、全経過時間の遅れと同じ数値とは限らない。`svp` は座標と時計の指示に共通の時間単位から秒への正の換算尺度を要求する。`swd` は同じ時計の時間順の二記録について、観測時間差と指示差の両方へ同じ尺度を掛ける。`swe` は対象の全記録対でその同じ尺度を使う。原文の秒という単位を明示したが、歴史的な秒の実現方法と換算規約の一般的な構成は残る。

V=5、v=3で、記録の観測時間差が5、指示差が4の場合、換算尺度1なら5秒間に1秒遅れる。尺度1/5なら観測経過は1秒、指示経過は4/5秒、遅れは1/5秒になる。一方の値だけを別の尺度で換算すると条件を満たさない。「一秒あたり」という率の記述のために、一秒ちょうどの区間が実際に観測済みであることは要求していない。

近似の留保には `svy` のBig-O型の条件を使う。指定点が定義域の集積点であり、ある正の定数と正の近傍幅を選べば、その穿孔近傍の全入力で誤差が定数倍の比較尺度以下になる、という量化である。関数・近似・比較尺度の値は定義域全体で有効であることを要求し、近傍内の比較尺度は非負とする。定数や近傍幅を入力ごとに選び直さない。誤差は両側から抑えるため、負の誤差にも使える。

`swc` は速度比uの零近傍で、`1-√(1-u²)` と `u²/2` の差がu⁴のオーダーであることを表す。`swg` はこれを同じ時計の遅れの内容へ接続した。原文の「四次以上を省略する」をこの誤差条件として読んでおり、任意次数までの解析的な級数展開全体を確立したとは扱わない。

数学的な補足 `svr` では、許容速度に対して次の具体的な境界を付けた。

```text
e = l²/2 = u⁴ / (2*(1+f)²)
u⁴/8 ≤ e ≤ u⁴/2
```

これらの恒等式と境界を有理数の補題として検査した。原文は係数1/8や1/2の境界を明記していないため、著者の近似の主張とは別の追加解釈に置く。速度比24/25では残差が162/625となり、たとえば1/100以下ではない。四次の評価があることを、光速に近い場合も近似誤差が十分小さいという保証にはしない。

誤差条件の定義を有理数へ特殊化し、定数誤差、正負の線形誤差、誤差零、空の定義域、不正な比較尺度、足りない定数を検査した。同じ条件を全実切断へ有限モデルで適用しようとすると拒否する。有限の速度を選んで検査することを、全近傍にわたる漸近条件の証明と取り違えないためである。実切断全域の演算法則と、この具体的な平方根関数のBig-O条件の機械的証明は未完である。
