# 例外を許す回避傾向と、二つの結果への因果的寄与

第二段落の冒頭には、既存の部分草案に二つの不足があった。`mj`・`mk`は全ての評価機会での回避を要求し、回避傾向に例外がある場合を排除していた。また`ol`は、要因を原因説明に採用することだけを表し、[原文](https://korpora.org/Kant/aa08/035.html)の「原因である」という主張に必要な、内容の成立と因果的な寄与を要求していなかった。

改訂した`mj`・`mk`では、既存の非数値の通常性条件`rqt4`を使う。同じ本人と基準文脈について、評価機会を`mh`で固定し、新しい関係`hzwm`で、どの機会をどの機会より通常とみなすかを指定する。この比較には労力または恐れの記述も渡す。別人・別の要因・別の文脈での比較を流用しない。

通常候補の全てに、同じ人物・行為・状況の要因、回避、回避理由を要求する。劣後する例外で回避しなくても傾向を表せるが、比較不能な通常候補での不成立は消さない。比較が循環する場合、範囲が空の場合、通常性や理由が未知の場合も、傾向の成立を補わない。労力を避ける人と恐れから避ける人が同一人物であることは要求しない。

これは回避傾向の条件を改善する変更である。怠惰・臆病という語にある程度や規範的評価、合理的な休息・慎重さとの区別まで完成したわけではない。回避した事例だけを通常と選び直す規約にもしていない。どの条件を比較範囲に採るかは文脈の解釈として明示する必要がある。

一般定義`rqxa`は、要因の記述列と結果の記述列の全組合せについて、既存の`rqqu`を要求する。要因と結果が成立し、同じ対象・記述・状況について実際の因果的な寄与`hzie`があることを意味する。両列は非空とし、原因対象と結果対象は異なってもよい。説明への採用`ea`だけで真にはならず、各要因の単独十分性・必要性・唯一原因性も追加しない。

本文の`ol`は、二要因`mq`・`mr`と、未成熟に留まる人々の割合という第一の結果`ms`、他者が後見の立場を引き受けやすいという第二の結果`ok`への固定した特殊化である。四つの内容を直接呼び出し、四つの因果的寄与を結ぶ。汎用の記述評価をそのまま埋め込むと引用の階層が上がるため、固定された内容には実行時の脱引用を使わず、著者へ引用して帰属できる形を保つ。従来からの各要因・各結果への寄与という読みを保持し、二要因の連言だけを一体の原因とする別解釈とは区別する。

本文の帰属文は、著者がこの因果内容を主張していることを表す。その帰属を評価するだけなら、要因や結果が現実に成立するかは未知でよい。著者の主張の真実性や心理的な因果機構を証明したとはしない。

因果の検査では、実際の旧`ol`と新`ol`の定義本体を使い、そこから呼ぶ四つの内容には検査用の明示的な解釈を与える。これは外側の結合の検証であり、割合・自然による解放・容易さの全定義を一括実行して再確認した結果ではない。一方、回避傾向は元のエピソードと集団条件まで実行する。検査は通常評価で行い、結果キャッシュや短絡用変換を使わない。
