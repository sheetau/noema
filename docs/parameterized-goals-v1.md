# 対象を変えられる目的と、全称的な規範条件

目的を一つの閉じた内容だけで指定する構成に加え、目的を表す関数の記述と、順序付きの対象列を分けて渡す構成を追加した。同じ目的の型を使って、対象の集団・時代・契約を変えられる。実行時の値から新しい引用文字列を生成せず、既存の型・関数・個体列・量化で記述する。

| 定義 | 内容 |
| --- | --- |
| `rjt` | 同じ引受け行為と、目的記述・対象列への志向 |
| `rju` / `rjv` | 当事者の一部または全部が共有する目的付き引受け／同じ行為での厳粛な宣誓 |
| `rjw` / `rjx` | 指定した対象列での結果を生じさせる行為／その行為が存在する内容 |
| `rjy` / `rjz` | 適用条件を満たす全ての五個体の組についての禁止／積極的許可の欠如 |
| `rj2` | 適用条件を満たす組が少なくとも一つ存在すること |
| `hzdq` | 同じ時代区分・集団・契約を保持する目的付き宣誓 |
| `hzdr` | 人間による行為の生起・参加と、対象列を持つ因果的な結果の接続 |
| `hzds` / `hzdt` | 既存の要求・許可関係を用いた全称的な規範条件の内容 |

目的の記述と対象列の両方を照合する。内容が同じ別名の記述、順序を入れ替えた対象列、別契約についての目的を、元の目的に置き換えない。引受けの条項には当事者ごとの引数列を使い、共有する目的の対象列とは区別する。引受け・宣誓・目的志向は、同じ人物・行為・時点に結び付ける。

目的を持つことは、達成や実現可能性を意味しない。目的への志向だけを述べる場合は、引用した内容を実行評価しない。一方、結果を生じさせたという構成では、因果関係が指すものと同じ記述・同じ対象列の内容も成立することを要求する。既知の結果関数を静的に特殊化すれば、対象列を変数のまま残して通常の引用に含められる。未知の関数の内容を推測して展開するものではない。

カントu0013への接続では、対象列を「先行集団・後続集団・先行時代・後続時代・契約」の五個体に固定する。全称条件はこの五位置をそれぞれ量化し、明示された適用条件を満たす全ての組に同じ規範条件を課す。一つの具体的な契約について否認できるだけでは全称条件は成立しない。実際に契約が形成された事例だけへ対象範囲を縮めることもない。

適用条件を満たす組が一つもない場合にも、全称条件自体は真になる。適用対象の存在は`rj2`で別に述べる。検査は二個体の有限領域で五位置の32組を全て評価し、そのうち二つの契約候補の選択・禁止・許可の64通りを比較する。この有限領域が現実の全時代や全契約を網羅するとは主張しない。適用条件や規範関係が未知の場合は評価を拒否する。

[一般文書](../examples/v014/parameterized-goals.noema)は5,154文字、[原文付き草案](../examples/v014/kant-parameterized-goals.noema)は139,504文字、[抽出文書](../examples/v014/parameterized-goals-core.noema)は8,446文字である。12定義を追加し、原始記号や著者主張を増やさず、親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-parameterized-goals-basis-v1.json)と[検査記録](../reports/parameterized-goals-v1.json)を保存する。

関連23テストが通過した。三文書のCLI解析結果は構文木と一致し、通常表記・簡略表記・独自文字v2の往復を確認した。抽出文書のSVGはXMLとして検査した。字形の視覚的な確認を行った結果ではない。全体監査は208件の対応表と452件のNoema文書を検査し、保存済みの集計と一致した。

今回の対象列には個体だけを渡す。数・状況・関数を個体へ読み替えず、それらの全てをこの列で量化できるとはしない。また、五位置という型と長さだけでは、任意の目的関数が意図した意味規約を満たすとは保証しない。

前版の改善不能・必然性・因果関係を含む目的全体を、五個体を受け取る一つの政策へ組み直す作業は残る。全称的な規範条件へその政策を接続し、代表資格・理由付け・著者帰属を確定する作業も未完である。今回の骨格だけを、原文の全称命題の完成と数えない。意味確認済み全文単位数は増やしていない。
