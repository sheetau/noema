# 横棒と両端座標を円文字へ接続する

原刊902頁のu0097–u0100を第51段落の三文として参照する。同じφの物理的意味への問い、η軸の区間を考察へ取り上げる行為、同じ棒の運動と両端の座標表示を保つ。第三文はコロン、第一表示、und、第二表示の句点までを含む。

指定区間はkのξ=ζ=0、0≤η≤lを全て占める理想化した線状棒である。端点だけの一致では区間全体の占有を代用できない。同じ棒の全物質点の履歴、Kでの速度vの並進、自軸との直交、各系の測定と時間区間を既存定義へ結ぶ。tとτは等置しない。

対象となる各K時刻で同じ端の現在の二系記録が存在し、全ての該当記録対が座標式を満たす。同じ値を持つ別記録は許す。第一表示はη=l側で(x₁,y₁,z₁)=(vt,l/φ(v),0)、第二表示はη=0側で(x₂,y₂,z₂)=(vt,0,0)である。第一のyは分数であり、負のφを絶対値へ変えない。φの偶関数性、正値性、値1はここでは加えない。

問いは計算や解答の完了を意味しない。対象へ注意を向ける行為と仮定の採用も区別する。nunは先行する相反積からの議論の移行として読む。二つの表示は同じコロンに続く順序付きの主張であり、引用の取得がその内容を実行することはない。

既存27定義と参照方式を再利用し、採用済みの問い・対象選定の2規約を任意プロファイル56へ公開する。アルファベットと共通375語を維持し、このプロファイルは798語となる。固有長を正のパラメータとして参照し、その長さ・設定の棒、下端、上端を順に同じ区間条件へ結ぶ。未参照の端は存在量化し、参照間の循環を避ける。本文の区間条件は選ばれた四対象を一緒に保持する。参照取得時に物理条件を評価しない。

原文への逆投影、実際に復号した定義の有限対照、参照と引用の非実行、独立復号、描画点検を別々に確認する。実数時刻の量化は有限標本へ縮めず、明示的な例化検査と全領域評価の拒否を用いる。これらを一般物理的証明や第三者読解の完了とはしない。
