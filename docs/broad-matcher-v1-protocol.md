# 共通判定器の教師資料と開発概念の再編

過去の定義照合v1〜v5を、今後は観察済みの教師資料として扱う。新しい分類クラスや語別規則は作らず、既存の同時符号化・線形ヘッドの学習区分を広げる。以下を今回のモデル予測前に固定する。

- 注釈のある90概念をentity/place/event/state別にし、seed 17と概念IDのSHA-256で整列する。各種類のceil(件数/5)を開発、次の同数を留保評価、残りを学習にする。結果は学習52・開発19・評価19概念。注釈のない名前付き人物agも推論の91候補には残す。
- 既存v1〜v5の既知範囲を上記で分ける。旧3係数方式の学習資料から、今回の学習概念だけを補う。旧資料では、記録された文内概念に開発・評価のものがあれば文ごと除く。v1〜v5は対象しか注釈されていないため、文脈に留保概念が全く現れないという保証はせず、対象概念の留保と呼ぶ。
- 評価→開発→学習の優先順で原文の重複を除き、同じ原文を区分間で共有しない。同一言語・原文・範囲を重複計上しない。学習は言語・概念ごと最大8件とし、過去の手作業注釈を旧定型資料より優先する。それぞれの中では原文と範囲のハッシュ順を使う。分類結果やスコアは区分作成に使わない。
- 学習は272範囲、開発64範囲、歴史的な留保評価78範囲。過去に一度も観察されていない評価とは呼ばない。新しいv6は留保19概念の日英19組と未知6組とし、今回の予測前に作成する。
- 構成は前回の固定MiniLM二列入力と線形1,537パラメーターのまま。学習候補は52、開発・確認は91。基盤モデル、定義、特徴抽出、補正幅0.25、スコア倍率10を変更しない。
- AdamW、学習率0.002、weight decay 0.001、batch 32、20 epoch、seed 17。各言語・概念の総損失寄与が等しくなるよう、範囲ごとの交差エントロピーを件数の逆数で重み付けする。全学習範囲で平均重み1に正規化する。
- 開発は各概念の正解率を言語ごとに平均し、その日英平均が最高のepochを選ぶ。同点なら早いepoch。以前の方式との差には概念の種類、例数、候補数、均等化、選択指標の変更が含まれるので、一要因だけの因果効果とは主張しない。
- 既存の3係数、前回の同時・線形、新しい同時・線形を同じ資料で比較する。確認結果で係数・epoch・方式を選び直さない。過去の未知例も診断に残すが、今回は未知判定を学習しない。
- 以前の32文は観察済み回帰として、予測範囲と役割スコアを固定し、新しい概念照合から同時選択を再計算する。新しい教師資料との直接の原文重複を報告する。

区分の不交差、各種類と両言語の包含、例数の均等化、反復一致、固定特徴からの再学習、禁止経路0回を検査する。旧モデルが今回の留保概念の一部を以前に学習・開発で扱っていることも比較の限界に含める。全文の確定翻訳は行わず、広い自然文と意味構造一致率95%の要求を維持する。
