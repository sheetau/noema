# 同じ比較内容が有利に見えること

第三文の「市民的自由の程度が高いことは、民衆の精神の自由に有利に見える」に向けて、[二種類の自由の比較](civic-intellectual-options-v1.md)を見かけの候補へ接続した。比較する共同体・二法秩序・人物・活動・課題は固定し、各候補で同じ制度条件の評価点だけを対応させる。

見かけの内容は、市民的許可と精神的活動の機会がともに厳密包含で増えるという、閉じたNoema記述で与える。既存の非空の候補範囲と全候補での成立を用い、基準点では市民的自由の大小だけを要求する。精神的な利益が実際にも成立する場合と、見かけにとどまる場合の双方を許す。

この観点は文章が示す一見の見通しとして扱い、著者が実際にその内容を確信したという心理的事実は補わない。表面的な情報に沿う候補の指定は明示した解釈入力である。候補を実際の成立状況だけから選んだり、空の候補で見かけを成立させたりすることは認めない。

検査では、市民的自由と精神的機会の実際・見かけの四条件と候補の有無を組み合わせた32例を使う。呼称の指示先、両制度の評価点、観点・対象記述・基準点を取り違える場合も調べる。記述の構成だけでは、その中の自由や能力を実行しないことを別に確認する。

これは比較内容を持つ見かけの構成であり、二制度の共変動だけで因果的な利益を説明したものではない。第三文の障壁、低い自由が与える発展機会、全能力、対照・照応・全文帰属へ引き続き接続する。全文の意味確認文字数は増やさない。
