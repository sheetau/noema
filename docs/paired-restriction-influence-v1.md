# 同じ背景に対応する結果を比較する

カント第五段落の二問では、制限によって啓蒙の進行が妨げられるか、促されるかを区別する必要がある。制限あり・なしの結果を総当たりで比べるだけでは、制限に由来しない結果のばらつきも差として検出する。[今回の構成](../examples/v016/paired-restriction-influence.noema)では、同じ背景条件と選択枝に対応する結果の組を明示する。[意味規約](../data/paired-restriction-influence-basis-v1.json)と[検査報告](../reports/paired-restriction-influence-v1.json)に条件と限界を保存した。

## 影響のないモデルによる対照

検査では、制限の有無にかかわらず結果が低い枝と高い枝を持つモデルを使う。旧構成の全解交差比較では、あり側の低い結果となし側の高い結果を組にできるため、悪化も改善も検出する。

新構成では、このモデルの同じ枝どうしを対応させる。低い結果は低い結果と、高い結果は高い結果と比べるので、全組が同順位になり、悪化も改善も生じない。旧構成は全組に対する頑健な比較としてそのまま保存し、その語義を後から書き換えない。新構成に全組の対応を渡した場合には、旧構成と同じ結果になることも確認する。

## 対応の範囲と有効性

`matches` は、あり側となし側の順で受け取る関係である。同じ外生条件・介入前の状態・非決定的な選択を保ち、制限の要因だけを変えた結果を対応させる。結果を見て有利な組を選ぶ規約ではない。対応はモデルから自動推定せず、意味を説明した入力として与える。

`r2wi` は両側に解があり、どちらの側でも全ての解に対応先があることを求める。多対多の対応を許すが、一部の解を落とした対応は拒否する。さらに `r2wj` は全解の評価、比較の反射性・推移性、対応組の比較可能性を確認する。異なる背景で対応しない結果まで、一列の尺度で比較できることは要求しない。

この構成は対応の全域性を検査するが、その対応が現実に妥当かを証明するものではない。意味上対応する組が複数ある場合に、その全てを与える責任はモデルの説明に残る。

## 原文へ向けた採用読解

阻害を、同じ背景に対応する結果の少なくとも一組で啓蒙の進行が悪くなりうることとして扱う。非阻害は全対応組で悪化がないこと、促進はそれに加えて少なくとも一組で改善しうることとする。これは潜在性の読みであり、平均的・典型的な効果や、全ての背景で必ず改善するという主張を追加しない。混合効果は阻害側に入り、非阻害・促進側には入らない。

`r2wq` 以降は、既存の全要求の適用・解除と同じ公衆・基準・啓蒙内容族 `r2ln` を維持する。`r2wu`〜`r2wx` は直前の四命令と同じ宛先別要求表を渡す。統治者の議論への許可、服従内容の全記述域、発話と実際の履行の区別は変更しない。

## 未統合の部分

啓蒙の進行尺度と期間、公衆・背景の具体的な固定、四事例以外の要求表、問いの提示・照応・対照・留保・強調は残る。六つの検査群はモデル内部と引数の接続を確認するもので、二問の通読判断を代替しない。本文の70主張、旧14全単位判断、追加の文単位確認496文字はそのままとし、今回のライブラリに新しい著者主張や意味確認済み文字数を加えない。
