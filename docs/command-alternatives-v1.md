# 三つの命令の内容

第五段落u0012[274,426)の将校・財務担当官・聖職者の発言について、共通する「議論するな」と三つの肯定的な命令の内容を構成した。発言者の役割や発話の対応、代替を示す`sondern`、三文全体の著者帰属・通読はまだ接続していない。[原文と後続の職務の例](https://korpora.org/Kant/aa08/037.html)を文脈とする。

| 原文の肯定側 | 内容 | 誤って同一視しないもの |
| --- | --- | --- |
| exercirt | `r2tg`：同じ本人が、軍事教練の遂行型を練習する活動に参加し、活動が生起する | 別人の訓練、一般的な反復、訓練能力だけ、実戦の成功 |
| bezahlt | `r2th`：指示で指定する取引について、同じ本人から別人へ価値媒体を移転し、その媒体が支払いに受け入れられる | 無関係な贈与、自分への移動、別の媒体の受容 |
| glaubt | `r2ti`：固定した非空の宗教的教えの範囲について、同じ本人がその内容を真として受け入れる | 教えの真理、単なる理解、偽装された同意、別人の信念 |

教練は[Dudenの軍事訓練の用法](https://www.duden.de/rechtschreibung/exerzieren)も参照し、他者を訓練する読みではなく本人が教練を行う読みを採った。信仰は[歴史辞書の宗教的用法](https://fwb.sub.uni-goettingen.de/lemma/glauben.h1.3v)も参照したが、信頼などの全側面を還元せず、この文脈で教えを真として受け入れる読みを明示している。どちらも辞書の項目だけを原文の意味一致の証明にはしない。

支払いには既存の`rfa/ti/tj`を用いる。文脈上の指定取引を別に保持するため、何かを移転したというだけでは成立しない。原文にない金額や税目は補わないが、指定取引の同定は文脈入力として必要である。財務担当官の役割を、単なる取立人と同一視する判断はしていない。

`r2tj`は、同じ本人・基準・評価点について、前文の禁止内容`r2ta`と肯定側の内容を連言し、命令型の発話へ包む。`r2tk/r2tl/r2tm`が三種類の内容を渡す。片方だけの成立では命令内容を満たさず、否定を肯定側へ広げない。

有限検査では三内容を実際に評価し、禁止と各肯定側の全16通りを確認する。別の検査では三つの命令を閉じた記述のまま提示し、基準の評価・活動・信念を未知のまま保つ。引用から履行、教義の真理、正当な規範を導くことはない。

現在の65主張、14区間の意味判断、第五段落先頭二文232非空白文字を保持した部分構成である。新しい著者主張・意味確認済み文字数は追加しない。次は三つの発信者の役割と対応、発話の省略、`sondern`による代替の提示を接続する。
