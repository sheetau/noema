# 電磁過程への変換適用の円文字接続

u0156–160を第71段落の一文として接続する。原刊907頁の変換適用の導入と四式、908頁の残る二式、wobeiに続くβの指定までを同じ文に含める。移動系における場の定義は次の文であり、ここへ先取りしない。

既存の25定義と既出の座標・領域・場の定義を再利用する。電磁過程の記述、同じ過程の二場による記述、全所属出来事の関係という採用済み3規約を任意profile68へ公開する。共通375語と固定アルファベットは維持する。過程の参照は導入箇所を位置とし、現在の二場・領域・系を用いた既存の物理的な記述を役割とする。この役割は変換の成功や結論を条件にしない。参照取得では役割を実行せず、存在・唯一性を証明したとも扱わない。

同じ過程の所属出来事が非空であること、全所属出来事に両系の記録が存在すること、同じ出来事の全記録対に変換を適用することを保持する。成功した記録だけへの限定や、別の出来事の片側記録の組み合わせを許さない。第三節の最終変換と同じ速度・光速を使い、場の成分混合と座標引数の逆変換を区別する。両場と領域へ同じ速度−vの逆写像を用い、全四座標と正のβの条件を保つ。

六つの回転式だけでは変換後の六式を一般に導けないという既存反例を保持する。発散条件や全微分の仮定を追加しない。「変換して得る」という著者の提示、引用した式の内容、式の真理を区別する。

検証では、診断用に抽象化する前のNative定義を既存の採用表現と照合する。その後、同じ過程・場・領域・出来事・記録の結合、全所属範囲、逆写像の各座標、参照位置、引用の非実行を診断する。有限例を全実数・全関数域の証明とは扱わない。生成、見える構造からの復号、描画確認、意味判断、人間による読解は別の証拠として扱う。
