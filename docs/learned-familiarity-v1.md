# 経験に由来する慣れと、仮定内の理由

経験したこと、経験の影響が残ること、現在の反応が定着していることを分け、これらを組み合わせる慣れの構成を追加した。カントの不確かな跳躍に続く理由節へ接続し、同じ本人・活動の記述・仮定状況を保持する。

対象は[電子本文の AA VIII 36、12〜13行](https://korpora.org/kant/aa08/036.html)である。固定資料と電子本文を比較したが、原刊画像との照合ではない。今回は「そのような自由な運動に慣れていないから」という理由節の部分草案であり、原文の意味を全て表したとは扱わない。

## 経験と現在の定着

一般構成は、新しい文法や基本関係を加えず、既存の量化・関数・型付きの式記述・時間順序を使う。活動の記述は引用されたまま経験・定着・寄与に共通して渡し、現在その活動が実行されていることを要求しない。

| 定義 | 要求する条件 |
| --- | --- |
| `rcg` | 正当な同じ履歴の現在より前に本人の経験があり、その同じ経験が現在の同じ活動への反応に寄与する |
| `rch` | `rcg` に加え、その活動への反応の仕方が現在定着している |
| `rci` | 履歴と現在への所属が正当で、`rch` が成立しない |
| `rcj` | 同じ履歴の現在より前に、その活動を本人が経験したことがある |

定着には、その活動へ毎回初めてとして対処の仕方を作り直す必要がない、という意味規約を置く。これは反応の正しさや成功を保証する条件ではない。経験が現在の反応形成へ寄与していても、定着の基準を満たしているとは限らない。経験回数の閾値や、能力がなかった状態から能力を得る変化は要求しない。

したがって、経験があっても現在は慣れていない場合を表せる。現在の能力も独立した条件であり、慣れていても実行できない場合や、実行できても慣れていない場合を排除しない。これまでの[経験による能力取得](experience-acquisition-v1.md)を、慣れの同義語として再利用しない理由である。

`rci` の否定は、与えた意味モデルにおける不成立を表す。調査していない経験を不存在として入力し、そこから不慣れと推定する手続きではない。現在が履歴に属さない場合、空の履歴、循環する順序では、肯定・否定のどちらの構成も成立しない。履歴の網羅性、経験の事実、定着や寄与の解釈は入力側の前提として残る。

## 身体の運動と活動の記述

原文側の `h3j` は、本人の身体移動と、その同じ運動に対する足側の物理的な阻害の不在を組み合わせる。本人の足・同じ運動・同じ状況を結び、別人や別の動作への阻害を混ぜない。

この構成が述べる自由は限定されている。全身のあらゆる障害の不在、法的許可、知的自立まで表したものではない。また、「そのような」が選ぶ運動の種類の範囲はまだ記述していない。今回の草案では、これらの意味を対応範囲の中に残る未完事項として記録する。

`h3k` は `h3j` の記述に対する慣れ、`h3l` はその不成立、`h3m` は過去の経験を表す。仮定ごとの同じ履歴を使う。記述を引用するだけでは、現在の身体運動を実行評価しない。

## 同じ条件文に理由を接続する

先行する[条件文](conditional-release-v1.md)の除去対象と最小の溝は、基準文脈に固定されている。今回もその同じ基準文脈 `wh` を保ち、除去の内容を `h3n`、不確かな跳躍を `h3o` として参照する。引用内に未束縛の変数を置かずに、同じ対象を指せる。

`h3p` は、同じ仮定状況で本人に不慣れ `h3l` と不確かな跳躍 `h3o` が成立し、説明において前者を後者の原因として採用することを要求する。原因の採用には既存の `ea` を使う。両内容が同時に成立するだけではこの説明関係は成立せず、説明への採用だけで実在の因果機構を証明したことにもならない。

`h3q` と `h3r` は、除去が成立する仮定にこの理由付きの帰結を置く。仮定集合の非空性と、前件が成立する仮定の存在を維持する。`h3t` は著者への帰属と本文順序を記録し、仮定の内容を実行しない。

この接続では、不慣れを除去が成立する仮定内で評価する読みを明示した。原文の現在形から、仮定の外の現実の基準時にも不慣れが成立するとする読みとの関係は未確定である。帰属の対象は理由を加えた条件文であり、現実の経験や身体拘束を新たに断言する主張ではない。

## 検証と進捗

経験・現在への寄与・定着・能力の16組を検査し、慣れと能力の四つの組合せが全て可能であることを確認した。人物・経験・活動記述・時点の取り違えと不正な履歴18例、身体運動と阻害の7例も検査した。未知の経験を返す評価は例外として停止し、不存在へ変換しない。

原文側の15例では、経験があっても不慣れな場合、慣れている場合、別の活動の経験、説明関係の欠落、原因と結果の記述違い、別の人物・状況・基準文脈を区別した。帰属の6例では、内容の非実行と本文順序を確認した。これらは明示した解釈モデルに対する検査であり、現実の学習機構や原文との完全な同義性の証明ではない。
