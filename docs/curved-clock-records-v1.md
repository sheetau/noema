# 曲線の全期間と現在の時計表示

u0128は、折れ線で得た結果が連続して曲がる曲線にも成立すると仮定し、その下で閉曲線を一周した時計の遅れを述べる。続いて、同じ構造でその他の条件も等しい赤道と極の時計を比較する。今回は、この全体へ接続する曲線と現在表示の定義群を整える。著者の発話と地球時計の比較は後続であり、単位全体の意味確認済み件数は増やさない。

原刊904頁末から905頁冒頭を通読した。改頁は帰還時計の比較文の途中にあり、所要時間と遅れの式は同じ文に属する。原文の「一定の速度」は速さの一定として読む。位置と速度が連続し、速度が位置の微分に等しいC1曲線をモデルとして用いる。端点は区間に相対的な片側微分であり、周回を繰り返すときの速度の周期性までは要求しない。

同じ時計の現在の対象出来事・表示出来事・記録・場所を共有し、候補指示と両出来事での指示を一致させる。全ての現在候補が同じ曲線と記録・指示・場所の関数に対応し、区間内の全実時刻でそのような表示が存在することを別々に要求する。観測記録と候補記録は四座標の値で照合するため、同じ値を持つ別名の記録を使える一方、矛盾する別記録は排除される。

完全な代表軌跡を現在表示へ接続し、初期同期・参照時計の残留・到着直後の同所比較を前段から保持する。閉曲線では出発と帰着の場所が同じでも出来事は異なる。二時計が初め同じ出来事を共有することを許し、帰還時計を初期から別の場所に置かない。

同じ到着指示差と全所要時間の秒換算、二次近似と固定所要時間での高次誤差の留保には前段の定義を使う。区間列を使わない端点比較の引数を空列で埋める箇所があるが、これは関数の未使用引数を接続するためであり、曲線を空の折れ線で近似する操作ではない。現在の折れ線結果を条件部とする曲線への拡張内容と、閉曲線の条件付き帰結を分けて定義する。

曲線の幾何と現在表示の設定には、移動時計の平方根の進み率を加えない。全期間の指示法則は補足のモデルとして別に持ち、仮定や著者の主張を幾何の定義へ隠さない。有限検査で使う閉じた多項式曲線は表示との対応だけを検査し、一定の速さや全曲線での物理法則の証明には使わない。

残る接続は、拡張仮定の採用と前段の証明済みという著者の位置付け、閉曲線の帰結と所要時間tの説明、そこからの地球時計の比較である。Unruhuhrの調速機構、同じ構造とその他の同条件、赤道と両極の位置、離れた時計のごく小さい歩度差を保持してから、一単位全体を判断する。
