# 動く時計：読み・経過時間・近似誤差

[動く時計のNoema定義](../examples/v011/einstein-moving-clocks.noema)を座標変換へ接続した。時計の進み率、二出来事の間の経過時間、文字盤の尺度と原点、二次近似の誤差を区別する。既存の時計の基本関係を5個再利用し、14定義を追加した。全体は15基本記号・95定義となる。

対象は[アインシュタインの論文](https://de.wikisource.org/wiki/Zur_Elektrodynamik_bewegter_K%C3%B6rper)§4のu0118〜u0125である。後続の折れ線・閉曲線の運動や地球上の時計の比較は、今回の等速直線運動の記述で完了したとは扱わない。

## 時計の進み率を正の枝で定める

光速度をV、符号付きの速度をv、時計の進み率をrとすると、haは次を表す。

```text
V > 0, |v| < V, r > 0
V²r² = V² − v²
```

既存のβは1以上の正の値であり、hbでβr=1と結ぶ。rとβを同じものにしない。正の進み率は一意で、0<r≤1、v=0ならr=1、v≠0ならr<1となる。速度の向きだけを変えてもrは変わらない。これらを有理数についての多項式の主張として検証した。

hcは動く座標系の空間原点にある出来事を、既存の四座標変換fhへ渡す。静止系の位置はx=vt、y=z=0、動く系ではξ=η=ζ=0となる。その条件からβτ=tを得る。hdは同じ世界線の二つの出来事と、t₂>t₁を結び、次を導く。

```text
β(τ₂−τ₁) = t₂−t₁
τ₂−τ₁ > 0
```

原点より前の出来事も式では扱える。例えばt=−10、τ=−8は上記の変換と整合するため、「τの数値は常にt以下」とは言えない。進み方の比較には、対応する出来事の差を用いる。

## 文字盤の原点と単位尺度

hkは`読み = scale × 座標時刻 + offset`という校正関係を、正のscaleとともに表す。同じscale・offsetを二つの読みに使えば、差を取ったときoffsetは消える。異なるoffsetを使った場合は相殺しない。座標時刻の単位と時計の読みの単位も別に保持し、尺度変更を暗黙に補わない。

hnはこの数値関係を、一つの時計、二つの出来事、時計が静止する側の基準系と場所、両系の座標、時計の指示へ接続する。時計が同じ場所にあっても、別の時計の指示や別の出来事の読みを代用できない。相対速度・光速度・基準系の設定も既存の観測関係へ結ぶ。

時計・場所・静止・読み・時間単位には、以前の時計同期の意味規約を再利用した。新しい文書で記号が衝突しないようma・mb・mc・me・miと命名し、対応元を意味規約に記録した。この再利用によって、時計の物理的な構造・精度・指示原理の定義まで完成したわけではない。二つの読みの一致から、全時刻での理想的な時計の振る舞いを結論することもしない。

## 二次近似を厳密値から分離する

s=(v/V)²、r=√(1−s)とおき、単位時間の厳密な遅れをL=1−r、二次近似をA=s/2、誤差をE=L−Aとする。hg〜hjはこれらを別の値として結び、次の剰余の等式を記述する。

```text
2E = L²
2E(1+r)² = s²
s²/8 ≤ E ≤ s²/2
```

0≤s<1、r>0の範囲でこれらを多項式として検証した。s²=(v/V)⁴なので、誤差が速度比の四乗に比例する範囲へ収まることを表せる。近似値を厳密な遅れと同一視したり、剰余をゼロにしたりはしない。これは剰余の具体的な評価であり、一般のテイラー展開や無限級数の理論を実装したという主張ではない。

非負の継続時間Tに対しては、経過時間がTr、厳密な遅れがTL、近似がTA、誤差がTEとなる。v/V=3/5、T=10の検査例では、時計の経過が8、厳密な遅れが2、近似した遅れが1.8、誤差が0.2となる。

実数の切断についてもhl・hmで進み率・経過・遅れを記述した。ただし、切断演算の一般法則を使った機械的証明は未完であり、有理数の検証からその完成を主張しない。

## Noema本文と検査の範囲

[17件の条件付き主張をNoema文書として保存](../examples/v011/einstein-moving-clock-claims.noema)した。[検査記録](../reports/moving-clocks-v1.json)には、その17件の性質、5つの誤った主張の反例、16の数値例、18の観測例がある。共通原点の相殺と、別々の原点では相殺しないことも区別した。

時計の読みの観測例では、明示した有理数10・18・19・490を下側切断へ埋め込んで使う。この有限の候補を区別できる有理数の試験点で比較しており、任意の実切断の同一性を検証するアルゴリズムではない。数値・単位・時計・出来事の結び付けを検査した範囲を超えて、現実の測定の正しさを認定しない。

原文の5箇所の数式・近似表現に、定義とハッシュを対応付けた。時計の導入、問いの発話と観測者への帰属、後続の加速・帰還経路、物理的な時計の一般定義は未完成である。確認済み全文単位数はアインシュタイン0/282、カント0/20のままである。
