# φを1と定める議論：往復・対称性・符号を分ける

[アインシュタインのφの草案](../examples/v011/einstein-phi-normalization.noema)は、先行する四座標変換の定義へ14定義を追加する。原文u0093〜u0106の、逆向きの変換を重ねる議論と、横向きに動く棒の長さを比較する議論を対象とする。基本記号は増やさず、既存の10基本記号と64定義から構成した。

ここで扱うのは、[『運動物体の電気力学について』](https://de.wikisource.org/wiki/Zur_Elektrodynamik_bewegter_K%C3%B6rper)のφを定める部分である。前回までのφが任意の関数である段階と区別し、前提が成立しないφを自動で1へ置換しない。原文の物理的な設定・論述全体や、実切断上の一般法則の機械的証明まで完成したわけではない。

## 二つの変換を重ねる

速度vの変換に速度−vの変換を続けて適用すると、出力の四座標はそれぞれ元の座標のφ(v)φ(−v)倍になる。fgで二回の変換、ffで共通の倍率を記述し、既存の四式eaからこの関係を検証した。二方向のβが等しいことも、正の枝を選ぶ既存のβ条件cmから検証している。

この倍率が1なら往復は恒等変換となる。逆に、非零の座標について往復後の値が元に戻るなら、倍率は1でなければならない。原点の一事象だけは、倍率が何であっても原点へ戻るため、この結論の根拠にならない。原点しか調べない誤った主張には有理数の反例を得た。

原文では、三つの座標系の初期原点と原点時刻を合わせる設定が先行する。今回の合成はその原点をずらさない四式について行う。相対的に静止しているという事実だけから、単位・原点・軸の向きも一致した恒等変換になるとは主張しない。こうした物理的設定の意味と帰属は、代数の検証とは別に残る。

## 棒の長さと正の枝

| 条件 | 定義 | それだけで残る自由度 |
| --- | --- | --- |
| φ(v)φ(−v)=1 | fa | 2と1/2なども許す |
| φ(v)=φ(−v) | fb | 共通値を1に限定しない |
| 上の二条件 | faかつfb | 共通値−1も許す |
| 上の二条件とφ(v)>0 | fd | 両方とも1に定まる |

原文の棒の端点は、動く座標系でξ=0、η=l、ζ=0と、ξ=η=ζ=0にある。fkはこの端点を四座標変換へ代入する。非零のφについて、静止系ではx=vt、z=0、φ(v)y=lとなることを検証した。l=0を代入すると、もう一方の端点も同じ式で扱える。

fcは、同じ棒の固有長lと、正負の運動で測る長さL₊・L₋が正であること、φ(v)L₊=l、φ(−v)L₋=l、L₊=L₋を合わせる。ここから二つのφ値が等しく正であることを得る。往復条件も加えたfeから、φの両値が1、測定長が固有長に等しいという結論を検証した。

これは原文のl/φを正の長さとして扱う規約を明示したものである。もし観測する長さをl/|φ|とだけ定義するなら、φ=−1も同じ正の長さを与える。その場合は軸の向きや連続性など別の条件が必要であり、今回の正の長さの式をそのまま使ったことにはならない。この符号条件を原文にない独立の文章が明記されているかのようには扱わず、長さの表記を解釈する際の条件として記録した。

## 同じ関数と適用範囲

fmは一つの関数φへvと−vを渡し、その値にfdを適用する。二つの無関係な関数を比較する構造ではない。foは正の光速度Vと、|v|<Vを満たす全有理速度についてfmが成立する条件を記述する。有限検査器は、この全域の量化を有限個の速度に置き換えず拒否する。

fhはφ=1の場合の四式である。fdと先行する任意のφの四式からfhが成立することを検証した。φがまだ定まっていない箇所の式は、既存文書のまま保持する。

実数については、fi・fj・fnを下側切断と既存の乗法・順序・符号反転から記述した。これらは型検査と往復検査を通るが、切断全域の一般法則を使ったφ=1の機械的証明は未完である。今回の多項式検査では実数の反例がないことから有理数の主張を確認しているものの、それを実切断ライブラリ全体の正当性の証明とは数えない。

## 検査と原文対応

[検査記録](../reports/phi-normalization-v1.json)には10件の普遍的な多項式の性質と、前提を落とした4件の誤った主張の反例を保存した。さらに15の数値・関数の具体例、全有理速度の列挙を拒否する1例を検査した。未知の結果を成功や反例へ読み替える処理は行っていない。

原文の8箇所の数式を、定義の参照先・原文単位・MathMLのハッシュとともに対応付けた。三座標系の設定、恒等性の採用、棒の物理的意味、対称性の根拠を述べる周辺段落は引き続き部分対応である。従って確認済みの全文単位数はアインシュタイン0/282、カント0/20のままである。

