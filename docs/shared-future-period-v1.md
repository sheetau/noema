# 許可と将来予測で共用する期間

前段の条件付き伝播では、許可を調べる期間と、独立して考える人々の将来を予測する期間を別々に渡せた。同じ条件付きの読みとして使うため、許可に使う期間枠から将来の機会範囲と時間順序を作る接続を追加した。

`rqtw` は期間枠と仮定候補を固定し、既存 `h7q` からその期間内の時点を選ぶ。`rqtx` は同じ候補を既存 `ic` の比較文脈に固定し、二時点の順序を返す。`rqty` はこの二つを `hzps` の機会範囲と順序へ渡す。これまで外部指定していた22供給関数のうち二つを内部で構成するため、残る指定は20供給関数になる。

`rqtz` は許可の期間枠を `rqty` に共用する。許可と予測の両方で、同じ候補と同じ基準点を使う。基準点は `origins` の対応から得るので、現実の提示文脈を仮定内の基準点へ代入しない。

この構成は具体的な始終日時を決めない。原文に日時が明記されているとする読みでもない。同じ期間の下で許可と予測を解釈する選択を明示し、その選択の内部で期間を取り違えないようにする。別々の期間を明示する一般の `rqtp` と `hzps` は保持する。

期間が基準点しか含まない場合、将来を空虚に真とはしない。既存の `hzne` と `rqtj` により、整合した順序と基準点より後の機会を要求する。予測の条件は厳密に将来側へ適用し、基準点自身で同じ条件が成立することは加えない。

四つのテストで次を確認する。

- 期間への所属と時点ごとの真偽の64組合せ、および別期間・別候補・別候補の順序の取り違え。
- 期間外の成功を使えないこと、基準点だけの期間を拒否すること、必要な六入力の未知を保持すること。
- 実際の許可・期間検査の定義と、検査用の将来述語を使った八組合せ。許可された各候補の将来だけを要求する。
- 存在する伝播内容・後見役・期待背景を含む閉じた枠を、前段の著者帰属へ渡すこと。

将来述語を単純な検査用述語にした検証と、具体的な伝播の引用構造を扱う検証は区別する。後者では世界の事実と期待比較を未知のまま保持する。無制限の中継列を有限の一覧へ変えず、集団全体の伝播の真理を証明したとはしない。
