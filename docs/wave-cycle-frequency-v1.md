# 角周波数と周期数の橋渡し

u0188ではω′の式から、光源の周期数νと観測者が知覚する周期数ν′の関係へ移る。ωとνを同じ数値に置き換えるだけでは、この移行を記述できない。今回、一周期の位相、時間周期、周期数を、先行の同じ波と変換表示へ接続した。光源・観測者・方向角・帰結の提示はまだ接続していない。

ekcy–ekc2は二関数の共通の最小正周期を構成する。全実数点での反復を要求し、それより小さい正の共通周期を排除する。一点の零点、半周期での符号反転、周期の整数倍を一周期とはしない。ekc3は既存の正弦・余弦の初期値微分条件と積分によるpiを使い、一周期を2*piへ結ぶ。

ekc6は角周波数ω、時間周期T、周期数νについてωT=2*pi、νT=1を同じ一周期へ結ぶ。ekc7は任意の位相原点を持つ正弦・余弦の時間関数について、このTが最小正周期であることも要求する。これは周期の解析的性質を明示した条件であり、有限検査による一般定理の証明ではない。

ekda–ekdcは、四座標の位相を同じ三位置関数と時刻へ適用し、局所の閉時間区間の全時刻でωt+位相原点に一致することを述べる。数学的な周期を指定することと、観測者の軌跡上の位相を調べることを分ける。短い観測区間が一周期を含むとは仮定しない。

ekddは、同じ一周期を共有する旧新のω、T、νを、先のβ(1−av/V)へ結ぶ。ωとνは同じ倍率、Tは逆の倍率になる。ekdeはこれを先行ekclの同じ41役割の設定へ接続し、六つの周期関連値も含む43証人をekdfで束縛する。既存370主張は保持し、新しい著者主張は追加しない。

場の近似誤差と用途上の十分性は先行の設定へ残る。誤差上限から実際の波の周波数を一意に推定したことにはならず、全成分が零の場合に任意の周期を観測したことにもしない。次の統合では、同じ源・波・系・時間単位・観測者への周期の帰属、無限遠という理想化、運動方向との角度を明示する必要がある。

局所検査では有限の周期関数を正弦とは呼ばず、全位相での量化の接続、最小性、単位換算、軌跡と区間、二系の数値と証人の対応を区別して確認する。全実数・全関数の列挙は引き続き拒否する。この依存群だけでu0188又はu0189を完成済みに数えない。
