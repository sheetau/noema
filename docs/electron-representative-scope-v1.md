# 一般性を保つ電子の代表配置

u0245第一文の「一般性を損なわずに」を、同じ電子の局所的な物理設定を座標の回転と原点移動によって代表配置へ移し、問われている運動法則の答え候補を保つこととして読む。単に原点の座標を零とする数値操作では足りない。場と領域、同じ出来事、完全な軌道、速度三関数、加速度、電荷、質量、単位も共有する必要がある。

既存ek4pは物理条件だけでなくK=raへの固定を含む。その規約は変更せず、ek3vから同じ電子・位置変化・速さを保持した任意の座標記述での条件を構成する。法則の候補も同じ方法で一般化する。Kへ固定したときは前の設定と候補条件へ戻る。一般性の比較でK固定を二つの異なる座標記述へ同時に強制しない。

代表配置は、指定出来事を時空の原点へ移し、同じ瞬間速度の非負ノルムを正X成分に置く。回転は正の向きの直交回転である。電気側と磁気側の場は、それぞれ同じ逆座標写像で評価してから空間成分を回転する。二場の交換やboostによる混合、場の一様性、無磁場、真空、無放射を加えない。時間領域、軌道、三速度関数と加速度には同じ回転と時刻原点を使う。

変換後も物理的な設定の全条件を要求し、同じ出来事の座標を両方向に結ぶ。電荷記録は座標記述に応じて選べるが、電子・出来事・電荷値・単位は変えない。低速慣性質量の値と全ての単位尺度も同じである。新しい実験や物理的な運動を起こす操作とは読まない。

法則の問いでは、同じ物理的な法則個体について、旧設定で答え候補となることと代表設定で答え候補となることを同値にする。数式の文字列や成分表示の同一性ではない。候補が空の場合も複数の場合も扱い、特定の方程式が既に求まったことは要求しない。全ての許容設定にこの対応を持つ代表があるという閉じた内容を構成するが、その物理的真理や全実数の回転存在を有限検査から証明したとはしない。

今回の範囲は一般性の内容に必要な依存群である。著者による仮定の許容と採用、考察へ取り上げる指定瞬間、第二文の明白さ、七つの表記と著者帰属を統合するまではu0245の全文判断を追加しない。後続の共動系を選ぶ際の光速未満という局所適用域を、この第一文の座標回転の条件へ先取りしない。
