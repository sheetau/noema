# 能力の保持と、その場の実行機会

[汎用の定義](../examples/v016/standing-ability.noema)では、本人側の状態を基準から変えず、外的な実行条件を与えた仮定場面での達成可能性を記述する。現在の場所や時刻に機会がなくても、このプロフィールでの能力は成立し得る。[比較例](../examples/v016/standing-ability-example.noema)では、カントの現在の能力条件と、この別の条件を同じ本人について評価する。

既存の `xd` は、指定した状況で方法を選択して実行できることを要求する。その状況の外的制約で全方法が使えなければ `xd` は偽になり、評価が整った不能 `xg` は真になり得る。この条件だけで、機会が与えられた場合にも能力がないとは言えない。

[Kittleの研究](https://onlinelibrary.wiley.com/doi/full/10.1111/papq.12424)は、現在の機会を要求するかという区別と、能力を評価する場面範囲の広さという区別を分ける。今回も、単に多数の場面を並べることを能力の保持とは扱わない。以下の構成は、この区別を表現するための一案であり、論文の分析全体の実装や、技能一般の定義ではない。

| 定義 | 記述する条件 |
| --- | --- |
| `rqu6` | 同じ本人・基準状況に対応する候補場面 |
| `rqu7` | 全候補が本人側の指定状態を保持し、課題の外的実行条件を備える |
| `rqva` | 非空の通常場面の全てで、同じ目標を達成する方法がある |
| `rqvb` | 非空の通常場面の全てで、達成方法がないと判定できる |
| `rqvc` | 非空の通常場面の全てで、能力の可否を判定できる |
| `rqvd` | 全通常場面で判定できるが、全通常場面での達成可能性は成立しない |

通常場面の選択には既存の `rqt2`〜`rqt4` を使う。選んだ候補と通常性の関係について、非反射性・推移性・極小場面への関係を要求し、極小場面全てで応答を評価する。劣後する例外で失敗することを許し、比較不能な二つの通常場面の片方での失敗は無視しない。

`rqva` と `rqvb` は互いの単純な否定ではない。通常場面Aではでき、通常場面Bではできない場合、双方は偽になるが、評価が整っていれば `rqvd` は真になる。候補が空、通常性に循環がある、評価結果が未指定である場合は、否定だけで不能を確認したことにしない。

本人側の保持条件には、身体・知識・習慣・意図など、当該能力判断の基礎として固定する状態を指定する。結論となる能力そのものの同一性を仮定する関係にはしない。外的機会も、技能・達成・許可とは別に与える。別の時点で学習した人や、別人の成功を基準状況の能力へ流用しないための条件である。保持条件に違反する候補を黙って捨て、成功する候補だけに縮める処理は行わない。

機会・保持・通常性の条件が課題に適切かは、意味入力の妥当性として残る。成功結果を見て選び直してよいという規則ではない。数値の成功率や場面数の閾値は追加していない。方法は場面ごとに異なってよく、一つの固定手順で全場面を処理することも要求しない。

比較例では、現在は方法が使えないが、本人の状態を保持して機会を与えれば自立的使用 `bb` ができる場合を記述した。このとき、現在の未成熟条件 `bc` と、機会を与えた場面で通常できないという条件は異なる。現行の `bc` が常に誤りだという判断ではなく、原文のUnvermögenをどの意味で読むかによって選ぶ条件が変わるという検討材料である。カントの本文35文と意味確認の登録簿は変更しない。

検査では16組合せ、13のプロフィール対照、七つの未知入力、実際の `bb`・`bc` を用いた七つの比較を扱う。機会はあっても目標を達成できない例も含む。新しい基本関係や文法演算子はなく、六つの合成定義を加えた。比較例の局所入力は、著者が指定した事実ではない。通常記法・短縮記法・固有文字の往復も検査する。元の能力評価の範囲、原文での読みの採用、第一段落全体の意味確認は残り、原文対応率と意味確認済み件数は増やさない。
