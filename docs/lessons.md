# Noemaの読み書き練習

[0.3の入門](writing-v03.md) と語彙表を読み、最初は代用文字で書く。文法の検査には `python -m noema edit` を使える。固有文字の練習は、同じ文を「固有文字にする」で置き換え、文字表を見ながら読み直すところから始める。

## 1. 主体と対象を入れ替える

`ih` は追う、`mu` は犬、`si` は猫である。次の2文を別々に書く。

1. 犬が猫を追う。
2. 猫が犬を追う。

解答例：

```text
noema c c
ih i mu j si.
ih i si j mu.
```

`i` と `j` の後の対象が違うので、別の意味になる。役割句の順だけを変えた `ih j si i mu.` は第1文と同じ意味になる。

## 2. 数・時間・否定を区別する

「明日、2匹の犬が眠る」と、その命題を否定する文を書く。`po` は眠る、`t` は明日、数の `c` は2である。

```text
noema c c
t po i mu m c.
u [ t po i mu m c ].
```

否定文は肯定文の数量や時間を消さない。第2文から「犬が何匹眠るか」を決めることはできない。

## 3. 同じ人物と物を参照する

「Akiが本を読む。そのAkiが、その本をMioに渡す」を書く。固有名の表記と参照名を区別する。

```text
noema c c
vac i qo n "Aki" o aki j jx o book.
ku i p aki j p book k qo n "Mio".
```

2文目で `qo n "Aki"` と新たに書いただけでは、1文目と同一人物であることを表明したことにならない。参照を共有すれば同一性を明示できる。

## 4. 行き先を尋ね、別の文で依頼する

「Akiは家からどこへ移動するか」を尋ね、「Akiが本を学校から家へ運ぶ」ことを依頼する。ここでは2文のAkiを同じ人物として書く。

```text
noema c c
b vae i qo n "Aki" o aki z tp 2 c.
d vaf i p aki j jx z lac 2 tp.
```

質問の `c` は答えを求める位置であり、未指定の `?` と区別する。2文目の `d` を消すと依頼から断定へ変わる。2か所の家は参照を共有していないので、同じ家だという主張は含まない。

## 5. 作用範囲を読む

次の2文の違いを説明する。

```text
noema c c
u [ w [ po i mu ] [ wm i si ] ].
w [ u [ po i mu ] ] [ wm i si ].
```

第1文は「犬が眠る、かつ猫が空腹である」という組合せ全体を否定する。第2文は犬が眠ることを否定し、猫が空腹であることを肯定する。括弧の位置が否定の範囲を変える。

## 段落を読む

[対訳読本](readings.md) に、複数段落の文章2編と日英の対訳を収録した。各対訳は文順に対応する。対訳は人が読むための説明であり、モデルによる逆翻訳ではない。[reading.json](../examples/reading.json) に原資料を保存する。

まず対訳を隠し、各文の述語・役割・参照・時間を手で確認する。次に、本文にない名前や物を使って続きの2文を書き、検査する。字形を使う場合は、代用文字への復号結果と見比べる。構文検査だけでは、書き手の意図と一致しているかまでは判断できない。

## 利用者評価で確認すること

未掲載の文を読んだ人に、主体・対象・否定の範囲・共有参照を答えてもらう。別の人には日本語の課題を渡し、Noemaで書いてもらう。課題の意味構造との一致、修正回数、参照や文字の取り違えを記録する。実施前の課題、採点方法、参加人数を固定し、自動テストの結果と分けて報告する。現時点では、この利用者評価は実施していない。
