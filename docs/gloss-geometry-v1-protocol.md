# 定義ベクトルの長さと共通方向を切り分ける診断

前回のGlossReaderは、対象を犬・猫・追う出来事に切り替えても犬を選んだ。モデルを再学習・交換する前に、内積が候補ベクトルの長さや共通方向に左右されていないかを調べる。今回の予測を計算する前に以下を固定する。

既存の`glossreader-v1`で保存した文脈・定義ベクトルを、記録済みSHA-256を照合して再利用する。正解範囲、91概念の定義、全482行は変えない。生成、辞書による絞込み、語別補正、学習、正解に応じた係数調整を追加しない。

比較は以下の4条件だけとする。qは対象の文脈ベクトル、gは候補定義、mは全定義の平均、uはmを単位長にした方向。

- `dot`：qとgの内積。前回と同じ対照。
- `cosine`：qとgをそれぞれ単位長にして内積を取る。候補の長さへの依存を除く。
- `projected_cosine`：q、gからu方向の成分を引き、それぞれ単位長にして内積を取る。定義集合の共通方向1本だけを取り除く。
- `centered_dot`：qと(g−m)の内積。各候補から同じ値q・mを引くので、実数演算では順位を変えない負の対照。浮動小数点による順位変化の有無も記録する。

平均方向は定義集合だけで決まり、評価文や正解ラベルを使わない。候補集合を変更すれば平均方向も変わるため、概念追加に対する普遍的な不変性は主張しない。入力のゼロベクトル・非有限値・形状不一致は拒否し、方向を除いた残差が数値的にゼロになる場合も拒否する。閾値で意味の確定は行わない。

全条件の既知正解、未知例のスコア分布、対象切替の指標を同じ資料で報告する。ベクトルのノルム、共通方向成分のエネルギー比、定義間のコサイン分布も記録する。順位の改善があっても、内積から意味の確率が得られるとはしない。

全資料は既に観察済みで、新しい確認評価ではない。条件の採用や翻訳器への接続はこの資料だけでは決めない。改善がなければ、長さ・共通方向1本の補正だけでは失敗を解消できないと判断する。改善があれば、独立した資料で検査する候補として残す。

検証は、手計算できる小さなベクトルによる式の一致、コサインの正の倍率への不変性、共通方向の除去、候補の並べ替えとバッチ分割への整合性、不正な入力・退化した残差の拒否を含む。全スコアを保存し、別プロセスで入力ハッシュとスコア・予測・評価の一致を確認する。エンコーダーforwardは前回の実験証拠を参照し、今回は再実行しない。
