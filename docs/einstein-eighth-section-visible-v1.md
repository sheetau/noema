# 第8節の円文字への接続

対象は u0202–u0226 の採用読解である。同じ光の部分、球面と楕円体、体積とエネルギーの比、完全鏡での反射、圧力、先頭近似、光学問題を扱う方法を一つの依存群として接続する。元の意味判断と登録は変更しない。

本文87–98段落の文と数式を既存の位置参照で指定する。相対性原理の呼称は冒頭の第2段落第2文の命名へ遡り、別表記も保持する。入射光、移動系の反射光、元の系へ戻した反射光の記号は、局所の命名箇所を区別する。経験の規則、展開変数、先行の方法、同じ光の部分、節そのものは、既存の関係から構成した役割を引用して参照する。

任意profile77は既存22契約の型・意味・引数順序を公開し、固定アルファベットと共通375語を維持する。語の追加だけで本文の統合完了とはしない。

境界の局所相対流と正味流、各系の同時断面、面積と体積、位相平均と瞬間値を区別する。原刊の反射角と周波数式の不一致、保存済みの反例を残す。先頭近似は速度比の次数0として扱い、厳密等式に置き換えない。方法への帰属から、すべての物理問題が解けることを検証済みとはしない。
