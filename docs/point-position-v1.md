# 静止物質点の位置指定

固定原文 `einstein-1905:u0009` の全242文字（非空白211文字）を扱う。原刊892頁の「Ruht ein materieller Punkt」から「ausgedrückt werden.」までを画像と転記で照合した。行末分割 Koordinaten-system と aus-gedrückt を接続した転記であり、数式・著者脚注はない。

原文は、先に導入した座標系に対して物質点が静止するなら、その同じ系に対する位置を、剛体の物差しとEuclid幾何学の方法によって決定し、Cartesian座標で表せると述べる。`diesem` と `letzterem` はともに既存の `ra`、`seine Lage` は同じ物質点の位置に結ぶ。`kann` は実施可能性として保持する。

`eih6` は物体の構成点であることと、指定された全対象期間・系・尺度での完全な履歴 `se` を結び、区間内の全時刻対で三位置成分が一致することを要求する。`eiia` はその履歴を存在量化する。物体全体の静止は要求せず、一時刻や往復運動の端点だけで静止を認定しない。全対象期間は文脈が定め、静止する部分だけを後から選ばない。

`eiib` は使用する物差しの校正と使用期間を、同じ全成員履歴の剛性 `eigy` へ結ぶ。目盛の差を同じ単位の長さへ対応させ、端点の一致、長さの比較・移し取り・分割を許す。一つの物差しを繰り返し使う方法も含む。`eiid` は使用道具の存在と全道具の条件を要求するので、一部の正しい物差しだけを選べない。

`eih7` は共通の補助Euclid表示における点P、原点O、右手正規直交三軸U,V,Wに対して、三座標がそれぞれ `(P−O)·U`, `(P−O)·V`, `(P−O)·W` であることを合成する。既存の正規直交条件 `eiaj` と射影 `eiam` を再利用し、三成分の符号と零を保持する。右手系は明示した座標規約であり、原文が一つの原点や軸方向を指定したという読みではない。正規直交基底なので、三射影から同じ変位を再構成できる。

`eiic` は18成分の幾何記録を同じ物質点・系・単位へ帰属させ、射影の整合性を要求する。`eiid` は同じ位置決定の操作と同じ記録へ接続する。Euclid幾何学の使用は、長さの比較・移し取り・分割、直線・平行・直交の作図と三射影として読む。記録の物理的対応、校正、操作と結果の関係は意味規約を明示した入力であり、数値だけから実測を導かない。文全体を真偽入力として一記号に置き換えてはいない。

`eiie` は参照状況と同じ対象・位置・系・尺度を保持する実施可能な設定を存在量化し、その設定での `eiid` を要求する。参照状況で測定済みである必要はない。理想的な物差しと操作の記述であり、任意の実機精度や任意の実数を有限回で全桁算出する能力を追加しない。`eiif` は静止する全物質点についての条件文、`eiig` はその主張、本文223の `eiih` は同じ著者・論説への帰属と先行する命名段落からの順序である。
