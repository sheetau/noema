# 静止系の時間という命名

u0022の207文字・177非空白本文文字を扱う。一文は原刊894頁末から895頁冒頭へ続く。前半では同じ静止系で静止する時計を用いて時間を定義したことの重要性を述べ、後半ではその系への所属を理由に、直前に定義した時間を「静止系の時間」と呼ぶ。

時刻付与は直前のeingを再利用し、先に共通時間として導入した同じ規約eisjdへ結ぶ。eingの定義をqu、qt、saf、saeへ展開すれば、局所時計の静止・所在と参照時計の静止が、同じ系raに対する連言として現れる。この限定された含意は定義の展開と連言除去で確認でき、全実数表現を有限標本へ縮める必要はない。

この系への所属は、時計と共通参照をその系に固定して時刻を与えるという操作上の依存として読む。名称だけから静止や絶対時間を導かず、他の全系に共通する時刻とも同一視しない。直前の規約への照応、定義理解にとっての重要性、系への依存から命名へ向かう理由を分けて保持する。

命名には既存eisd4を使い、引用された呼称の印字形は識別表記へ保存する。著者の現在の命名宣言であり、別規約の再定義や社会全体の呼称の承認ではない。空の改頁標識A0006は本文への追加内容として扱わない。
