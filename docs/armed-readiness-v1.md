# 武力行使の遂行能力と、現在の戦闘を分ける

カント第17区間の軍隊に関する草案へ、未充足だった任務の内容を接続した。採ったのは「対象共同体のために、対立集団へ道具を用いた身体的な制約を加える集団行動を遂行できる」という操作的な候補である。任務の割当、現在の遂行能力、現に行動していることを別々に扱う。

軍隊の唯一の定義や、原文との意味一致を確認した完成訳ではない。武装警察などとの制度上の境界、公的平穏の全条件は残る。

## 道具・行為・集団の方法を結ぶ

[一般定義](../examples/v016/armed-readiness.noema)は既存の能力条件 `xa`・`xd` を再利用し、四定義を追加する。新しい構文演算子は使わない。

| 定義 | 内容 |
| --- | --- |
| `rwc` | 同じ操作者・道具・対象について、道具の物理的作用で対象の身体的行為能力を制約する結果を実現できる。 |
| `rwd` | 同じ集団の指揮下で、その構成員が別の対立集団の構成員へ道具を向けて使用する。道具による制約の可能性と対象共同体への活動の帰属を要求する。 |
| `rwe` | 同じ集団・共同体・状況で `rwd` を満たす出来事が存在する。 |
| `rwf` | 同じ集団・対象共同体の方法で、`rwe` を達成できる。 |

`rwc` と `rwf` は、ともに利用可能な方法、非空の評価結果、想定結果への包含、全評価結果での達成を要求する。別の方法の利用可能性と成功結果を継ぎ合わせない。道具・対象・操作者や対象共同体の取り違えも排除する。

身体的制約は、道具の物理的作用による行為能力の制約という意味規約を持つ入力関係である。単なる命令、制度上の禁止、道具と無関係な不動状態は含めない。ただし、この関係を物理学や身体の理論から導出したものではなく、基礎付けは残る。道具の使用・対象への方向付け・集団の指揮・共同体への帰属も、それぞれ別の入力関係として結ぶ。

## 平時にも記述できる任務

| 評価した状況 | `rwf`の能力 | 現在の`rwe` |
| --- | --- | --- |
| 利用可能な方法で行動を達成できるが、現在は行動していない | 真 | 偽 |
| 現在の行動はあるが、指定した利用可能な方法はない | 偽 | 真になり得る |
| 現在の身体的制約はないが、方法の評価結果では制約が可能 | 成立できる | 現在の行動とは独立 |

実際の負傷や制約を、現在の行為や準備能力の成立条件にはしない。評価結果に相対的な能力であり、即座に行動できることや、全ての緊急事態への対応能力を保証するものでもない。

## 任務の割当と能力を実際に合わせて検査する

[本文の後継草案](../examples/v016/kant-armed-readiness.noema)の `hzzmission` は、`rwf` を集団と対象共同体から得る内容にしたもの。その閉じた記述を、前段の任務割当へ渡す。軍事的任務の引数を未記述のまま残す方式から、内容を明示した候補へ進めた。

`hzzqualified` は、この任務の実際の能力、残余条件、基準時の構成員の一致を要求する。前段の保護条件の構成員と、今回の行動能力の構成員を同じ集団について照合し、別の名簿を使った成功を混ぜない。将来まで人員を固定する条件は加えていない。

今回は前段の `rwb` による任務割当・役職・指揮担当と、今回の `rwf` による遂行能力を、一つの解釈で実際に評価した。割当だけある場合と、能力だけある場合を区別し、結合した資格には両方を要求する。残余条件が不成立なら、割当と能力が成立していても結合した資格は成立しない。

原文への帰属は、この候補の記述を保持する。帰属文を評価しても、戦闘の発生や能力の現実の真偽は実行評価しない。親の全宣言と先行18文を保持し、最後の解釈注記を更新した。[抽出文書](../examples/v016/armed-readiness-core.noema)にも同じ接続を保存する。

## 検証と限界

180テストが通過した。方法・評価結果・道具の効果・使用を変える128通り、現在の行動と身体的制約を独立に変える4通り、参照の取り違えや不整合な評価結果、未知入力、任務割当と実際の能力の8通りを含む。任務の内容を含む引用に必要な層も検査した。

保護機構・発言能力・今回の資格を全て一つの解釈で同時実行した検査は残る。今回の結合検査は任務割当と遂行能力までであり、原文単位全体の意味確認には代用しない。[検査記録](../reports/armed-readiness-v1.json)と[意味規約](../data/armed-readiness-basis-v1.json)に範囲を明記する。

```powershell
python -X utf8 -m scripts.compose_armed_readiness
python -X utf8 -m scripts.check_armed_readiness --verify-only
python -X utf8 -m pytest tests/test_armed_readiness.py -q
```

同じ原文範囲の具体化なので、部分草案の対応割合は増やさない。軍事的役割の全体、身体・物理・因果の基礎、原文の解釈と全文の意味確認は未完であり、意味確認済みの全文単位は両作品とも0のままである。
