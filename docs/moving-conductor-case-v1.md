# 導体が動く場合と電流の比較

導入u0003[771,1203)を、先行文と同じ通常の理解による第二の場合の説明として読む。磁石が静止し導体が動くとき、磁石周囲には電場がなく、導体内には起電力が生じる。それ自体にエネルギーは対応しないが、二場合の相対運動が同じなら、第一の場合の電気的な力と同じ大きさ・経過の電流を生む、という内容である。

本文u0174は、旧い言い表しでの起電力を動く単位電荷への追加の作用として説明し、u0176は座標系の運動状態に依存する電気・磁気の力に関する補助概念として扱う。ここではこの用法を参照し、起電力を導体内の局所的な力/電荷の係数として読む。閉回路を一周する仕事/電荷の積分だけには限定しない。導入の条件を記述するため、後半の一次近似式を厳密な相対論的変換の証明へ置き換えることもしない。
