## 接続したもの

旧版の引用は `senx(tc, zqd, zqe, zqf)` という構造で、密度と速度の帰属を未展開の `zqd` に渡していた。改訂版は `seov` を引用し、次の既存定義を本文で使う。ここでの括弧表記は構造の説明用で、実際のNoema文書は厳密な構文で保存している。

- `seov → seon → seof → seoe → seoc`：同じ物質点の座標時間による三方向の微分。
- `seov → seon → seom → seol → seok → seoj`：同じ分布について、縮む球の平均値の極限から求める密度と規格化。
- `seov → seou → seos → seor`：同時刻の空間領域に割り当てる符号付きの加法的総電荷。

新しい定義や文法演算子は追加していない。上の説明に渡す11個の固定参照を宣言した。分布、円周率、長さ・時間・電荷の単位、電気量の帰属、座標の単位、分布への所属、座標時刻、総量の定義域、総量関数である。光速度・電場の帰属・二つの系の配置には、元の同じ参照を使う。固定参照の引数順序と意味は[意味規約](../data/einstein-density-interpretation-basis-v1.json)に記録した。

本文から参照されない定義は382から357に減った。25定義が新たに参照されたことを示す数であり、25概念の意味を完成したという数ではない。電気的作用、単位の実現、分布と物質点の対応などの基本関係は未完である。

## 同義性と区別する点

条件文では、説明を詳しくした結果として対象が減ると、以前は反例だった事例が前提を満たさなくなることがある。例えば旧版では新旧両方の量を割り当て、式が不成立だった事例が、新版で片側の速度や密度を説明できなくなると、その事例についての条件文は真になる。この変化を「精度が上がった」と数えない。

逆に、新しい説明が以前なかった事例を含めれば、条件文が偽になる場合もある。新版には円周率の条件もあるため、帰属の一致だけで十分とはしない。両方の内容が一致する十分条件として、円周率条件と、同じ物質・系・出来事・密度・三速度・文脈の全組について旧帰属と新帰属が双方向に一致することを記録した。この条件が現実に満たされることは未証明である。

また、同じ真理値になる二つの引用を、著者が同じように提示しているとは推論しない。引用の変更は、原文に対応させる読解の改訂として明示した。著者への帰属を評価するときに、引用した物理内容を実行しない性質も維持している。
