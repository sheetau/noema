# 光源と遮蔽物に相対的な影の記述

影の字義的な説明を、指定した光源からの直接光が物体によって遮られる場所として構成した。光源が消えているだけの暗さ、物体の介在、介在した物体の不透明性を区別する。場所の条件から領域の性質を作り、その性質の記述を前段の心理状態の対象として使えるようにした。

完全な遮光と部分的な遮光の区別は[NASAの解説](https://science.nasa.gov/eclipses/geometry/)で確認した。今回は光線を使う幾何光学のモデルであり、[OpenStaxが説明する光線モデル](https://openstax.org/books/college-physics-2e/pages/25-1-the-ray-aspect-of-light)の範囲を採る。これらの資料はモデル範囲の確認に使い、カントの比喩の意味を確定する根拠にはしない。

## 光源・経路・遮蔽物を共有する

`rvp` は、指定光源の発光部分から対象の場所へ至る直接経路を調べる。指定遮蔽物だけを除いた場合、その経路を妨げる別の遮蔽がないことも要求する。この比較では、光源や他の条件を変えない。

`rvq` は、その候補経路の少なくとも一つに、同じ物体が介在し、かつその直接光を透過させないことを要求する。経路に介在しても透明なら、この条件では遮光としない。別の物体の不透明性や、別の経路への介在も流用しない。

| 候補となる直接経路の状態 | 一部以上の遮光 `rvq` | 全遮光 `rvr` | 部分遮光 `rvs` |
| --- | --- | --- | --- |
| 候補がない、または光源が発光していない | 偽 | 偽 | 偽 |
| 全候補が指定物体で遮られる | 真 | 真 | 偽 |
| 遮られる候補と遮られない候補がある | 真 | 偽 | 真 |
| 候補はあるが指定物体では遮られない | 偽 | 偽 | 偽 |

この条件は指定光源からの直接光に相対的である。他の光源や反射光が場所を照らしていても成立し得る。周囲より暗いという観測だけで、指定物体による影だとはしない。別の物体が既に同じ経路を完全に遮っている場合、その経路を指定物体だけの寄与としては数えない。

## 領域の性質を心理状態の対象へ渡す

`rvt` は、指定領域が非空であり、その全ての場所が同じ光源・遮蔽物・文脈の `rvq` を満たすことを要求する。空領域や、影になっていない場所を含む領域は成立しない。領域の最大性や連結性までは要求しない。

作例の `jytopic` は、この領域条件を性質として定義する。「影」という自然言語の綴りを内容の代わりに格納せず、既存の量化・関数・関係から作った説明を引用する。

前段の `rvm` は、この性質の記述へ向けられた不快な心理状態と不利益の予期を検査する。対象の存在を調べる `rvo` は独立に使う。したがって、実際には影の領域がなくても、その記述に向けられた心理状態は成立し得る。反対に、影があっても本人が恐れているとは限らない。

光学的な入力が未知でも、心理状態がどの記述に向けられているかは調べられる。その場合、実在する影の有無の評価は拒否する。未知の光学条件を「影は存在しない」と補わない。同様に、光学条件が判明していても、未知の情動を肯定・否定へ補わない。

[一般定義](../examples/v016/cast-shadow.noema)は5宣言・本文0文で、原始記号はない。[心理状態への接続例](../examples/v016/cast-shadow-example.noema)は26宣言・8質問である。新しい構文演算子は追加していない。

277テストが通過した。二つの経路について、発光、他の遮蔽の不在、介在、不透明性を変えた256組合せを、独立した集合の計算と照合した。光源・場所・物体・文脈の取り違え、空領域と一部だけが影の領域、指定外の領域の存在も検査した。心理状態との接続では、無発光、遮光なし、全遮光、部分遮光の各条件について、恐れがある場合とない場合を分けた。

保存文書と検査記録の再現、通常表記・短縮表記・固有文字の往復、CLI解析、作例の固有文字SVGのXML検査、キャッシュなしの評価を確認した。SVGの目視検査は含まない。

発光部分・直接経路・介在・不透明性・領域は、意味規約を持つ入力関係である。座標からの交点計算や現実の観測による同定まで実装したものではない。回折、散乱、連続的な透過率、波長依存、明るさ・形・色の全体も残る。
