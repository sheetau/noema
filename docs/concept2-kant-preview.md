# Concept 2：Kant の最初の外観試作

[比較ページ](../output/kant-concept2/index.html)は、元の `kant-page-script-v3` と同じ4段落・40項目を描く。採用・固定前の外観候補であり、[統合設計案](alphabet-concept2-proposal-v1.md)全体の実装完了を意味しない。

対象は元の生成器 `scripts/proof_kant_page_script_v3.py` の `kant-1784:u0008` から `u0011`。保存された原文・主張の選択と、引数0個の先頭定義だけを展開する表示方針を引き継ぐ。公開名への対応と語義は既存の `kant-public-revolution-visible` の橋渡し、語の綴りは `kant-presentation-spellings` の公開辞書を使用する。原文一文ごとの新しい原始語は追加しない。

**描画する構成**

- 三段・四段階の半径、同心、規定の接触、直交する円、くりぬき、日食、部分円を使う。支持円の外接範囲を取ってから配置し、別の字形の円を偏心包含しない。
- 根語の形は明示した表から取る。合字は根語の並びへ展開できる12種類で、辞書番号・文番号・ハッシュ・乱数から生成しない。合字の意味は語の綴りの一部であり、根語同士の論理的適用と混同しない。
- 三段の候補から、横幅・累積した円弧の重心・同じ段の連続を評価して配置する。元の生成器の三段・重心の考え方を参考にし、長い経路探索や旧生成器の文書別語形番号は再利用しない。
- 連言などは結合順を保持する中置表記とし、必要な箇所を範囲で囲む。通常の主張に固定の文頭記号を付けない。
- 引用、関数参照、引用された値を区別する。今回の対象に現れる明示的な引用階数1・3も描く。関数と全称変数の導入では、同心の内包小円を未接続のまま残す。
- 改行は水平の接続線か文間で行う。円弧の途中では切らず、接続線で切った場合は次行の同じ段へ継続する。

**確認の境界**

公開辞書の綴りと構文を並べた中間列から、40項目それぞれの構文が完全一致で戻ることを確認する。引用階数・引数順・連言の結合順も比較対象に含む。語の宣言は保存された公開本文と同一で、原文から公開本文への対応も保存済みの橋渡しと照合する。

SVGを円・円弧・線分だけとして再読込し、円の半径・大円の段・円同士の関係・直線の方向・円弧への直角入射を検査する。中間列の構文一致を、SVGからの構文復号成功として扱わない。SVGには構文、語ID、元の項目番号を埋め込まない。

図形だけから語の境界・接続の役割・範囲を一意に読む復号器は未実装。局所略記、一般的な引数共有、ドット対応、段の役割宣言も今回の試作には含まない。束縛は対象に現れる個体型・名前 `va` の一変数に限定し、未対応の構文は省略せず拒否する。全ての近接条件・線の接続形態の網羅的な検査も、上記の幾何検査とは別の残件である。

今回の線は主に字形を順に接続し、分岐は合字や局所構成の内部にある。意味構造全体に応じた共有・分岐配置まで実現したものではない。元のページより綴りが長い点と合わせて、外観評価時の制限とする。

**生成と局所確認**

```powershell
python -X utf8 -m scripts.build_concept2_kant --run .noema-project/runs/concept2-kant-new
python -X utf8 -m scripts.project_work check --tests tests/test_concept2_preview.py
```

実行は `LongRun` で入力・実装の内容ハッシュを固定し、40項目を個別に保存する。同じ入力の途中実行を再開するときだけ、同じ `--run` と `--resume` を指定する。表示・規則を変えた場合は新しい実行名を使う。既存の意味診断や歴史版全量監査は、この外観試作のためには繰り返さない。

比較ページには一枚の概観、拡大用の全範囲SVG、4段落別SVG、根語・合字表、構文の形の一覧、検査範囲を明示したJSONを置く。公開辞書の全定義は本文へ展開せず、元ページと同様に別の共有辞書として参照する。
