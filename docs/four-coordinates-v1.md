# 四座標の式と係数の再表示

アインシュタイン§3の `u0081`〜`u0084` を部分記述した。x′をx-v*tに戻し、先行する係数aを新しいφ=a*βへ結ぶことで、四つの式を同じ二座標記録へ適用する。

```text
τ = φ(v)*β*(t-v*x/V²)
ξ = φ(v)*β*(x-v*t)
η = φ(v)*y
ζ = φ(v)*z
β = 1/√(1-(v/V)²)
```

ここで本文のβはV/√(V²-v²)であり、v/Vではない。先行箇所でも未知係数をφ(v)と表記していたが、その値aをそのまま新しい四式のφへ代入すると係数が合わない。`spb` は速度関数aに同じ速度のβを掛け、`spc` をこの箇所の新しいφとする。先行する `zeq` の意味を変更せず、φ=1などの後段の結論も補わない。

`soy` と `soz` はβの二つの表示を構成し、`spa` は0≤v<Vと正のβ、両表示の一致を要求する。`spd`、`spe`、`spf` が四式の右辺を作る。`sph` は先行するaの四式、`spg` は新しいφの四式を、同じ有効な二記録に対して全て要求する。時刻・縦・横二成分で、別の速度や別のφを使うことは許さない。

有理数の代数的検査では、φ=a*βとx′=x-v*tを使うと、時間・縦座標・横座標の式がそれぞれ一致することを確認した。正のβによる係数の再表示は、異なるaの値を同じφへ潰さない。V=5、v=3、a=2ならβ=5/4、φ=5/2である。光線上ではない入力x=7,y=3,z=4,t=2に対し、ξ=25/8、η=15/2、ζ=10、τ=29/8となり、先行形と新しい形が一致した。

光線から全座標へ拡張する際の追加前提も明示した。`spl` は空間成分の候補に、零点、運動原点の一単位後、三方向の光の一単位後の五つの値を与える。`spm` はそれに加えて、一組の係数が全入力で同じ候補関数を与えるアフィン性を要求する。有理数のアフィン行について、この条件が全入力の式を定めることを確認した。

運動原点の条件は省けない。アフィンな差 `w*x+(V-v)*(y+z)-w*V*t` は三方向の光の指定点で零になる一方、運動原点では一般に零にならない。また、`x*(x-3)*(x-5)` を加えた非線形関数は検査用の五点では同じ値を持つ。五点の一致だけを全域のアフィン性の証明に使わず、有限検査器が全実切断のアフィン表示を評価しないことも確認した。

`spn` は各候補の空間成分を、同じ出来事に対応する二記録の該当成分へ結ぶ。さらに、値だけの方程式から記録の対応へ戻るには追加条件が要る。`spt` は同じ座標値を持つ出力記録へ替えても対応が成立することを要求する。`spo` は非空で関数的な対応の存在、この置換条件、先行するτの式、空間成分のアフィン性と五つの値を拡張前提としてまとめる。

`spi` は対象範囲の全記録対について、四式の成立と同じ出来事の対応が過不足なく一致することを要求する。正しい対応の例だけでなく、余分な対応、欠けた対応、同じ値を持つ別記録の扱いも検査した。現実の記録で同じ座標を持つ異なる出来事をどのように扱うかは未確認であり、この条件を物理的な同一性の一般定義とはしない。

追加した五点と記録の条件を、著者が逐語的に述べた前提としては扱わない。`zfl` は十分条件を補った部分解釈の注記であり、本文の係数の書換えを表す `zd3` と分けた。全実切断の体の法則、実際の測定全域でのアフィン性、一般の座標対応への拡張の機械的証明は未完である。
