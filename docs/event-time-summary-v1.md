# 同時性と時刻の定義のまとめ

u0018の二文、515文字・447非空白本文文字を対象とする。第一文の「われわれ」は論説を進める著者の声として読み、先の手続きを受けた振り返りを保持する。物理的な経験内容であることと思考上の素材であることを分け、局所時計と光往復の想定へ接続する。現実に実験したという報告にはしない。

先に採用した同期の定義は、異なる場所の静止時計を同じ系・単位と全関連光往復試行で結ぶ。その定義に至る手段と、そこから同時性・時間の定義を得たという理由の向きを保持する。offenbarは著者がその到達を明らかと提示する働きであり、評価器による証明済みの印ではない。

第二文の時刻付与は既存quを再利用する。対象出来事と時計表示出来事が同じ場所で生起を一致させる条件をeisgmで明示し、両方を同じ時計・単位・指示値へ結ぶ。別周期に同じ値を示した表示、遠方の出来事から信号が届いた時点の指示はこの条件を満たさない。

規則は全ての適用で同じ参照時計rcを使う。出来事ごと、局所時計ごとに参照を選び直せない。参照時計も局所時計も同じ系で静止し、同期関係は既存qoに結ぶ。同時性は同じ参照時計の下での時刻値の一致という旧草案qwの読みを、現行の数値等値scaで合成して採用する。

定義を得たことと、現実の全出来事について読取りが存在し一意であることの証明は分ける。原文は適用規則を与えており、任意の矛盾した計測データから一意な値を生成する算法は述べていない。有限例は結合と条件の検査に用い、全実数・全物理状況や意味同値の自動証明へ広げない。
