# 使用のない時間にも続く作用

第三文の候補で、各時点に使用行為があるという条件を見直した。使うかどうかが問題になる局面では使い続け、その間の時間にも以前の行為の作用が残る、という構成へ更新する。使用のない時点を履歴から取り除かず、結果は基準以降の全点で検査する。

前版では、三時点の中央だけ使用行為がない場合、結果が三時点とも成立していても、継続条件を満たす候補がなくなった。これは旧演算の仕様どおりだが、使い続けることを行為の途切れない生起に限定していた。新しい候補では、中央が適用局面でなければ成立できる。一方、中央で結果や因果的関与が失われれば成立しない。

[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)の第三文と直後の離脱仮定を踏まえ、適用局面に応じて使い続けるという読みを採る。原文がこの条件付き形式を一意に指定しているとはしない。第三文全体の意味一致は引き続き未確認である。

## 適用局面と結果の範囲を分ける

`r2g4` は、指定履歴の基準以降の各点について、適用局面なら使用内容が成立することを要求する。局面でない時点での使用は要求しない。

`r2g5` はこの条件を候補履歴の比較へ組み込む。

1. 全候補の履歴が基準を含み、厳密な全順序を持つ。
2. 基準は全候補で適用局面である。
3. 以後の全適用局面で使用する候補が少なくとも一つある。
4. そのような全候補について、基準以降の全点で結果が成立する。

不正な順序や基準の欠落を持つ候補を、継続しない候補として除外しない。使用する局面の集合と、結果を評価する全将来の範囲は別である。基準以降に追加の局面がない場合も扱えるが、基準での使用と全将来の結果は必要になる。

原文側の新入力 `hzzzl` は、同じ提示文脈・対象・本人・基準・候補についての適用局面を表す。使わなかった局面を後から取り除いたり、結果がよかった時点だけを選んだりしないという意味規約を持つ。現実の局面を漏れなく同定したかどうかは、形式検査だけでは証明できない。

これは適用局面での行動の継続であり、過去の経験から反応が定着した慣れ `rch` とは異なる。経験、無意識性、本人による方針の宣言を本文に補わない。途中で使うのをやめた候補の停止以前だけを保証する演算も、今回の範囲には含めない。

## 以前の同じ行為を現在の結果へ結ぶ

`r2g6` は正当な同じ履歴について、次の条件を合わせる。

- 現在が履歴に属し、結果内容が現在成立する。
- 現在以前の履歴内で行為が生起している。
- その同じ行為が現在の結果に因果的に関わる。

行為が現在にも起きる必要はない。未来の行為、別履歴の行為、別の行為についての因果関係を借りることはできない。過去に行為があって結果が続いているだけでも成立しない。因果関係は別に要求する。

原文側の `r2g7` は、以前の使用に既存 `r2ev` を使い、同じ対象・本人・能力・使用行為の結合を保持する。因果関係には既存 `g3`、結果には同じ本人の未成熟 `bf` を渡す。以前の行為から現在への作用が実際にあるという入力が必要であり、過去の因果関係を自動で現在へ延長する規則ではない。

`r2ga` はこの結果を全将来に要求する比較へ結ぶ。`r2gb` は二種類への一般化、`r2gc` は前二文からの人物範囲を保持した主張内容、`r2gd` は対象と本人の二位置を持つ比喩対象、`r2ge` は第三文への帰属である。同格、言い直し、前後文との順序は保持する。

九定義と適用局面の一入力を追加し、本文の第53文（索引52）を更新する。他の53文と既存の定義・意味規約は変えない。一般形は、例えば間欠的な操作が後の状態へ作用する場合にも、対象や原因の意味を明示して使える。

## 検査と限界

局面・使用・結果の256組合せで、旧条件との違いと全将来の結果を検査する。行為の時点・因果関係・現在の結果の512組合せでは、過去の同じ行為の作用と、未来や別の行為の取り違えを区別する。不正な履歴、基準の欠落、未知入力も確認する。

原文側では、局面のない中央時点、そこを局面に変えた場合、中央で作用や結果が失われる場合、原因行為・人物・種類・履歴の取り違えを検査する。ここでは分類と能力を境界で分離する。別の検査で実際の使用・能力・因果の定義を実行し、現在の使用がなくても以前の使用の作用を表せることと、因果関係が失われれば成立しないことを確認する。能力を実行した状態で、一般化全体の全候補を同時評価した検査ではない。

帰属の32組合せ、旧内容への取り違え、引用内容の非実行、短縮・展開・固有文字の往復を検査する。十二全単位2,212文字と、別記した先頭二文247文字の判断を保持する。原文対応文字数や意味確認済み分量は増やさない。

残るのは、第三文の語義と持続の強さについての通し判断、第四文の指示と知的活動への比喩の接続である。機会の選定・因果関係・完全な履歴という解釈入力の妥当性も、有限モデルの検査だけで証明されたものではない。
