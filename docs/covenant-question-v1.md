# 合意形成の資格を問う文とその回答

カント第六段落の冒頭の問い `[0,409)` と回答 `[410,443)` を、[本文](../examples/v016/kant-covenant-question.noema)の第96・97文（0始まり）へ統合する。既存96主張と15全単位判断は保持する。判断はこの二文に限り、第六段落全体の完成は意味しない。

問いは、教会関係者の団体が、同じ不変の信条への相互宣誓によって成員と人民への永続的な後見を図る合意を形成してよいかを尋ねる。資格は正当な規範上の許可として読む。回答は同じ資格事例が一つもないという全面的な拒否である。問いの否定を再度反転せず、形成や後見の物理的な実現不能へも移さない。後続の契約の無効性は次の文として残す。

`etwa` は教会会議とClassisを非網羅的に例示し、一般範囲を二例に限定しない。`oder` は包含的選言である。Classisには教会職務の代表者として長老を含められる。括弧は同じClassisの敬称付き自己呼称を説明し、敬称から著者の道徳的な称賛を導かない。

形成対象は団体・合意・信条・宗教的主題・政治的共同体の五個体を保つ。目的は、合意の同じ固定基準で、中断しない媒介的な後見と、その終点なしの成立・維持を結ぶ。`sogar` は後者までを目的とする取り立てとして読む。五引数から既存の四引数の目的へ射影する際、信条を別の後見対象にはしない。期待の比較は閉じた目的記述を用い、目的の実現を外側で要求しない。

`Aber` の先行評価に対する反対考慮、`sollte nicht` の仮の肯定的見込み、括弧説明、`Ich sage` の回答者自身の明示、`ganz` の全面的拒否を、同じ著者と第六段落専用の提示文脈に結ぶ。仮の見込みは著者の確定した賛同ではない。回答導入は回答内容に先行するが、導入を包含する回答全体より前だとは記述しない。

[読解記録](../data/covenant-question-reading-v1.json)に全語句の対応、原刊488頁の照合、採用する解釈と限界を保存する。[検査](../scripts/check_covenant_question.py)は、参照の入替え、否定と発話の働き、二例以外も許す範囲、五引数の射影、期待の厳しい順序、引用内容の非実行、未知入力の拒否を確認する。規範・相互宣誓・制度・時間の構成は固定済みの依存検査を引き継ぎ、ここではその接続を検査する。有限モデルの通過を無限の将来や原文との意味同値性の証明とはしない。
