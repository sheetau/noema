# 同じ波への場・座標変換の適用

u0182後半からu0187までを、原刊911頁の一続きの導出、七表示式、パラメータの補足として構成した。§6の参照は最終六場変換ejvm、§3の参照は最終座標時刻変換ejehへ結ぶ。両規則を引用することと、同じ波へ具体的に適用する条件、変換後の式を別に表す。

ekceは同じ出来事の旧新四座標を正変換と逆変換へ全成分で結ぶ。ekcfは同じ過程の全所属出来事が両系の記録を持つこと、ekcgは同一出来事の全記録対への変換、ekchは旧局所領域への所属と新逆像領域への所属の一致を要求する。局所領域にある出来事は非空とするが、光源も含む過程全体を原点の近くへ押し込めない。変換に成功した出来事だけを対象に選別する構成にもしていない。

ekciは、先行の41役割を保ったまま、実際の二場を同じ変換で写したものが、同じ観測者の問いに対する物理的な候補になる条件を述べる。古い第六節の固定場や過程群を現在の波の代わりに使わない。先行の仮定と現在の適用を共有する37存在証人は、変形の前後と補足でも同じ割当を引き継ぐ。

ekcjの点条件とekckの全領域条件は、旧近似場の成分混合・逆座標変換から得た六成分と、旧位相の引戻しを、表示の七等式へ結ぶ。四つの横成分の符号と交差相手を保持し、位相を六成分から独立に照合する。ekclは同じ表示に現れるω′とa′,b′,c′を四式で指定する補足である。ω′は角周波数の位相率であり、通常の周期数ν′と同じ数値とはしない。

実際の二場と表示用の近似場の区別も維持する。変換後の成分誤差は既存seau/seavのβ(εE+|v/V|εH)とβ(εH+|v/V|εE)を使い、同じ逆像領域の全点でseatへ接続する。誤差を零に変えず、数値上限があるだけで物理的な周波数や方向を厳密に同定したことにもしない。元の考察の用途上の十分性は先行設定に保持する。

unmittelbarは、採用した変換への代入と式の整理で直接結果を得るという著者の提示として読む。所要時間や読者の容易さではない。eissgは同じ型の前提規則と結果規則に同じ割当を使う一般の導出提示関係であり、具体的な物理・数学条件は各規則の本体にある。参照する両法則、コロンの前方参照、表示、wobei ... gesetzt istの補足を分けて著者へ帰属する。

固定在庫の区切りはM0325が六成分、M0326が位相、M0327がω′と三方向の四式である。以前の再開情報でM0326を方向変換と案内していた点は訂正した。原資料の本文・MathML・画像は変更していない。

局所検査は、同一出来事と異なる出来事の記録、全記録対、領域内外、六成分と位相の誤り、非零の誤差、同じ引数と存在証人、引用と著者帰属を対照する。診断用の波形は正確な有理数値の関数であり、正弦とは称しない。全実数・全関数の列挙拒否と、既存の物理的導出に関する反例は維持する。局所検査と原文全体の意味判断は別の証拠である。
