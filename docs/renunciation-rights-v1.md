# 本人・後世についての放棄と人類の権利

第九文後半の放棄を、現在の主体が啓蒙の継続全体を退ける実践上の方針として読む。本人の場合には既存の放棄を再利用する。後世の場合には、同じ選択点が属する時代より後に生存する人々全体へ対象を広げる。将来の人々の同意や、実際の服従は含めない。

後世の成員は、選択した人の子孫だけでも直後の一世代だけでもない。先行時代からの生存者と、さらに遠い後代を含める。その全成員について知るべき事項の対応を保ち、対応のない人を集団から除かない。放棄の対象は、その後代の誰かが探究を継続する内容である。負極性の方針採用により継続全体を退け、一定期間後に再開する方針との同時採用を認めない。

人類の権利は、啓蒙の進展を追求し得る条件と機会への全関連請求と読む。進展には、既存の認識獲得・誤りの訂正・理由ある自己判断の三つの選言を使う。権利の担い手は通時的人類に固定する。神聖という性格づけは、都合や取引で顧みなくしてよいものではないという尊重の位置付けとして保持する。

本人と後世のどちらについても、放棄が行われる仮定では、同じ権利集合への侵害と不遜な軽視という評価を結ぶ。引用した行為内容を評価関係だけで実行せず、権利の存在は放棄の実例がなくても消さない。

身体的な足で踏みつける見立ての提示、後世の場合を強める mehr noch、zwar/aber の対照、全文帰属と通読は残る。今回の構成を第九文全体の意味確認として数えない。原文は保存済み原刊489–490頁と [AA VIII 39](https://korpora.org/kant/aa08/039.html) による。
