# 後見・危険提示の参照名を短く綴る

## 先行計画

保存された40本文は2,825円で、そのうち語の綴りが2,342円、文法形が483円を占める。各本文のイベント列から数えた値は、保存SVGの円数と全40件で一致する。行間調整だけでは、元kant-pageの629円との差を解消できない。

今回は第二段落の後見人、働きかけ、危険提示、経験による能力取得、試みを思いとどまらせる説明に関係する七つの既存参照名を一群として扱う。不足する意味関係はない。元の基本宣言、語義、参照先を保持し、長い綴りだけを短くする。新しい原文一文専用のprimitiveは加えない。

| 既存名 | 綴り | 元の参照先を区別する手掛かり |
| --- | --- | --- |
| db | aki・above | 指図する立場を引き受けた後見人群 |
| mw | book・give・inside・book | 第二段落の働きかけによる原因説明の談話節点 |
| dq | book・methodpossible・give・book | 自立への一歩を危険と考えることの原因説明箇所 |
| hzsq | book・above・give・book | 先行する働きかけと後の危険提示を述べる複文の箇所 |
| fv | book・methodpossible・inside | 経験による能力取得の見込みを理由とする箇所 |
| g2 | book・methodpossible・candidateexcluded | 例による萎縮と後の試みの抑制を述べる箇所 |
| fu | book・candidateexcluded・inside | 危険がそれほど大きくないという部分解釈の箇所 |

bookは文書上の参照、giveは働きかけや提示、aboveは本文順序または指図の立場、methodpossibleは能力・試み、insideは説明の範囲、candidateexcludedは除かれる評価・試みを区別する手掛かりとする。これらは複合語全体の公開された語彙規約であり、根語を論理的に適用して本文の真理を導くものではない。dbを根語akiの指す個人と同一視せず、g2を現実の不実行と読み替えず、fuを危険の完全な不存在と読み替えない。短縮から追加の意味を導入しない。

mw・dq・hzsqの末尾bookを除いた三部品列は既存語と衝突するため採用しない。文書上の箇所を指す末尾bookまで含め、他の語を上書きしない。文番号、辞書の登録順、ハッシュで綴りを作らない。

元宣言全体と意味記録を照合し、既存の完全名・省略名の対応を保持する。ただし語の追加によって最長一致の境界が変わる可能性は別に扱う。新旧の40イベント列を比較し、必要な再配置範囲を記録する。全40件の新図形を完成・検証したと扱うのは、その全件を実図形から復号できた後とする。小さい語形対照と一つの実本文の確認を、その代わりにしない。
