# Skandalの評価と処罰の規範的可能性

カント第五段落u0012[2513,2770)の `als ein Skandal ... bestraft werden` に向けた依存構成である。同じ賦課への批判と一般的反抗の誘発可能性への全文接続はまだ行わず、新規の意味確認文字数も加算しない。

Skandalは、公に他者へ示される振舞いの例と、厳格な義務規則を軽視する姿勢を結ぶ評価として読む。カント自身が後年の[AA6/474](https://korpora.org/Kant/aa06/474.html)でこの意味を説明しているため、[補助資料記録](../data/scandal-reading-v1.json)に本文とハッシュを保存した。これは1797年の別著作であり、1784年の唯一の解釈を証明しない。また、この資料自身がSkandalと法律上の不処罰を併記するため、評価だけから処罰の許可を導く規則は置かない。

`r34j` は公然と示される行為の例、同じ共同体で厳格な義務規則として扱う基準、その基準の軽視を表す振舞いを結ぶ。全員の現実の観察や模倣、全読者世界への刊行、既に反抗が広がったことは必要としない。`als` の評価は、処罰する際の評価根拠として同じ批判活動へ接続する。

`r34k` は既存 `rfm` と同じ四条件、すなわち同じ施行者による措置の実行、本人への不利益、不利益を与える意図、同じ行為の評価への応答を構成する。評価の共同体・規則・基準を明示するため、応答関係の引数を拡張した。評価の真理を処罰から逆算しない。`r34l` は施行者・措置・本人・批判・共同体・規則の正確な六個体列と基準を閉じた段階1の内容へ束縛する。

`bestraft werden kann` は、本文接続では規範的に処罰対象となり得るという読みを採る。`r34n` が同じ規範の出所からの積極的な許可と反対要求の不在を結び、`r34o` が制度上の処罰を扱う施行者・立場・措置について、その許可を持つ組の存在を表す。原文の前後にある拒否の禁止と市民の義務への不違反を踏まえた解釈上の選択であり、現行法上の合法性の判断ではない。出所は全文接続時に明示し、許可対象を現実に実行しない。

実行可能性は `r34m` で別に記述する。同じ候補で措置の四条件が成立する可能性であり、現実の処罰や規範的な許可とは独立である。本文の規範的な読みへこれを無条件に連言すると、原文にない実現可能性まで要求するため、その連言は採用しない。処罰の義務、全措置の許可、特定の刑種・量・手続も補わない。

局所検査は評価・措置・候補・許可を実定義で評価する。六個体列の位置検査のみ `r34k` を型付き境界とし、措置の意味は別検査で実評価する。許可の検査では引用内の処罰も評価も未知のままにして、引用内容の実行が不要なことを確認する。全体の意味確認は、賦課批判、括弧内の誘発説明、sogar、全文帰属を接続してから行う。
