# 非対称性の解消と所在の問いの円文字統合

対象は採用本文u0177の二文である。第一文の非対称性解消、括弧内の単極機の語義注記、第二文の問いの前提に関する判断を、既存の三主張から接続する。固定アルファベットと共通375語を維持し、本文の物理的条件と論述関係を既存定義から合成する。

序文の磁石・導体・結合設定は、本文第一段落の別々の名詞句を参照する。参照取得に使う役割は引用し、物理的な存在や性質をその取得時に断定しない。通常の見方と展開した理論の見方を区別し、同じ理論・対象・準備・相対履歴・単位と説明範囲を保つ。

前段の導入理由は第二文の第17～37語、今回の二文は第80段落を指す。導入理由の相対節は、第23～37語だけの根拠節と区別する。序文の略記「z. B.」を文境界として分割しない。括弧内の装置名は今回の第二文の第12語に結び付け、既存の単極機の構成で語義を指定する。

引用符付きのSitzには、自立した作用源の場所を求める読みを採る。問いが実質的な探究として要する前提を新理論が積極的に退けることを、gegenstandslosへ接続する。前提の拒絶、不明、無回答、前提そのものの偽は個別に評価できる。werdenは理論の移行に伴う問いの扱いの変化として保持する。

検査では復号した定義を原文側と照合し、物理的な本体と各引数・証人の束縛を分けて診断する。多くの証人がある定義では他の証人を固定し、一つずつ小さい区別可能領域で動かす。有限診断を実数全域や全関数の証明とはしない。実際のSVGからの復号、独立CLI、表示確認と統合監査が揃った後に正式な統合へ数える。独立した人間の読解確認は対象外である。
