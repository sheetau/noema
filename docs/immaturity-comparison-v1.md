# 宗教的未成熟の有害さと不名誉

u0016第一文の最後の理由に向けて、主題別の自己に帰責される未成熟を構成し、その同じ内容の有害さと不名誉を別々に比較する。全文の意味判断はまだ行わない。

各事柄の活動内容は、本人が自分の理解能力を用い、同じ活動について他者の指導を受けないことである。宗教の場合にも判断の客観的正しさや特別な習熟を追加しない。既存の通常行使能力の評価へ、この同じ活動内容と閉じた記述を渡す。

主題の全関連事柄で評価が整い、全事柄の行使能力がそろってはいない状態を、その領域での未成熟と読む。空の主題や評価漏れを不能にしない。現時点での不使用や外的な機会の欠如、将来の学習可能性は区別する。さらに、同じ本人の同じ状態が本人の選択・不作為について帰責されることを結ぶ。

`jene Unmündigkeit`は冒頭の自己に帰責される未成熟を宗教事項に具体化したものとして読む。比較する他領域も同じ構成を使い、名前だけの状態や、宗教だけ異なる能力基準で作った状態を混ぜない。冒頭の一般的な未成熟`bc`を再定義せず、領域の指定を持つ具体化として追加する。

有害さは判断・行為・生き方に不利益を及ぼす性質、不名誉は理解・判断を担う者としての尊重に反して人を貶める性質と読む。実測被害や実際の嘲笑・恥の感情、本人の人間としての価値の消滅ではない。どちらも性質の肯定と、同じ全関連領域での最大を要求する。同順位は許すが、一方の最大から他方を導かない。

比較は同じ閉じた状態記述・人々・基準へ結ぶ。その状態が現実に全員へ成立することや被害の発生は、比較の前提にしない。候補範囲は結果から選別せず、呼称の誤参照や比較漏れを最大へ補わない。

検査は通常能力の下位定義を実評価する試験と、引用状態を実行せず比較する試験に分ける。事柄ごとの能力の四通り、準備方法との区別、同じ状態の帰責、二比較それぞれ27通りの順位、比較の不整合と未知の拒否を確認する。著者の評価が現実に正しいことや全候補の網羅性を有限試験で証明したとはしない。
