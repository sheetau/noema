# 現行の表題・回答・著者注を結ぶ点検

現行本文の表題、冒頭の回答への接続、著者注の九主張を、同じ有限解釈で評価した。旧点検後に追加された現在の回答への言及、注の標識との接続、敬称の分類を含む。表題の問いが説明を求める型へ改訂されたため、旧脚注だけの検査をそのまま現行本文の検査とは扱わない。

検査対象は現行41文のうち、先頭、18〜26番、40番の計11文である。表題箇所を表す個体を、先の回答の紹介と現在の論説への言及で共用する。冒頭の回答箇所、現在の論説、メンデルスゾーンの文献は別個体にする。表題の文脈と脚注の文脈も分け、文脈が同じという仮定で参照を合わせない。

十二の解釈で、表題の欠落、異なる説明対象、応答方向の逆転、先の回答と現在の回答の問いの取り違え、先の紹介だけの流用、注の接続や敬称の欠落を区別する。問いの真理条件、思想の一致、偶発性、本人の実際の性別分類は未知のままで、問いや分類の提示を記述できる。提示や参照、反事実の受領が未知の場合には評価を拒否する。定義の差し替え、短絡変換、メモ化は使わない。

原刊494頁を再読し、[AA版の著者注](https://korpora.org/Kant/aa08/042.html)とも照合した。[更新した句別点検](../data/footnote-audit-v2.json)では、旧版の九つの原文範囲を保ったまま、後続実装で解消した課題と未解決の課題を分けた。現在の回答と同じ問いの接続、著者注の標識への接続は実装・同時検査済みである。

敬称は、丁寧な言及と男性向け分類を同じ使用へ結ぶ読みを採用する。[Adelungの第三語義](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_3_1_1987)を補助資料とし、具体的な身分・権限や本人の実際の属性を追加しない。後年の辞書が1784年の全慣習を確定するとはしない。

末尾の容認と限定は、現在の文書をここに置く態度と、この箇所での提示を試みという種類へ限る読みを採る。原刊の文脈と、既存の種類による限定 `rqrw` を照合した。別の試みの個体も同じ問いへ向くなら許す一方、他者による評価や文献の全価値まで制限しない。これらの句についての採用判断は、脚注全体の完成判定とは別である。

残る作業は二つに絞った。

| 未解決箇所 | 完成へ必要な証拠 |
| --- | --- |
| Büschingへの帰属と週刊という刊行物の説明 | 固有呼称から独立した人物・系列・周期の記述、提示範囲の読解、別系列・別周期・欠刊との区別。実際の全刊行日時が規則的だったことの証明は求めない |
| 偶然による思想の一致を問う箇所 | 偶発性の文脈的な読みと内容対応の規約を明示し、同義の別構文と同じ真偽だけの異内容を区別する。問いを述べるために実際の一致の答えを計算する必要はない |

これらを解消して全句を再確認するまでは、著者注を意味確認済み単位へ加えない。今回の成果は現行本文の結合検査と未完事項の更新であり、新しい文法・基本語・本文は加えていない。既存十単位604非空白文字、約3.89%の確認済み分量を保持する。選択した構文の通常表記・簡略表記・固有文字v2の往復と、登録済みの意味判断の一致も検査する。

[検査記録](../reports/current-footnote-v1.json)は新しい原文対応を申告しないため、部分草案の集計に加算しない。旧点検や既存の検査記録は保存する。
