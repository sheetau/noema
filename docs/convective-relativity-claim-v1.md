# 第九節の相対性原理への適合という結論

原刊917頁の u0237 は、第五節の速度合成則によれば直前の三成分は k で測った電気的な担体の速度にほかならないことを理由に、著者の運動学的原理を基礎とすれば Lorentz 理論の電気力学の基礎が相対性原理に適合すると示された、と述べる。

速度の同定は `ek2j` を使う。同じ分布の全成員・同じ出来事の記録を両系で対応させ、構成した三成分を新系の実際の座標時刻微分へ結ぶ。第五節の参照は、同じ点の三運動式 `ejnp` と角度付き速度合成則 `ejpc` を併せた `ek2s` に固定する。速さの式を三成分そのものに替えず、著者がそこから同定が従うと述べる役割を保持する。

「適合する」は、ここで指定された同じ条件付き基礎法則が、相対性原理の要求する完全な共通法則体系に含まれるという読みを採る。`ek2n` は元の Lorentz 理論の同じ基礎採用と、任意の表示系で読める `ek2l` → `ekyq` の内容を、一つの法則参照へ結ぶ。新しい一般関係 `eiswp` はこの内容の対応だけを述べ、成立や適合保存は含めない。

`ek2o/ek2p` はその同じ法則が `eiff` の共通体系に属することを要求する。体系の全法則には、全適格系での法則としての成立と、全候補履歴の全対応記述での適合保存が及ぶ。不適合な候補も比較し、両側の記述存在と全対応対の一致を要求する。元の Lorentz 理論全体を共通体系だと固定せず、この節で指定された基礎を対象にする。`ek2q` は絶対静止に対応する現象特性の否定も保ち、先行原理の一部分を捨てない。

採用する運動学的原理 `ek2r` は、先行の相対性原理 `eifj` と真空光速度 `eify` の同じ内容である。第二節での定式化の対応は既存の記述を引き継ぐ。`ek2u` は同じ文脈で原理を基礎にした条件付き結論を表す。`ug` が著者自身による採用、`uh` がその範囲の主張、`zc` が根拠からの結論、`ui` が示されたという位置付けを保つ。引用内容を実行して真理を認定する仕組みではない。

同じ三速度、k、第五節の内容、直前の変換結果、先行の Lorentz の基礎、相対性原理の全内容、著者と論説を一文へ接続する。M0389 の磁気側の 1/V 欠落は保存し、著者の結論を成立させるために印刷式や前提を修正しない。後続の任意運動での総電荷不変はこの文の前提にしない。
