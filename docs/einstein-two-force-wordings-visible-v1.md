# 力の二つの言い表しの円文字接続

原文u0174–175の番号付き二項を、先行する導入で取得した同じ項目参照へ接続する。各項の末尾にある旧来・新しい言い方という括弧も含める。第一項の引用用語は、引用符を含む識別表記と、追加の機械力を指す閉じた役割規則を保持する。

第一項では、同じ背景の電磁場、対象、出来事、系、単位を共有し、速度応答から電気側の寄与を引いた追加力を扱う。外積の順序と三方向を保存し、固定した場・地点・方向で速度を小さくする際の二次以上の留保を残す。有限速度での厳密等値や電位差へ読み替えない。

第二項では、その瞬間の対象速度に合わせた慣性系を用いる。全域の物理的な座標対応、同一出来事の逆座標写像、二場と領域の変換、同系の力の記録と単位を結ぶ。前後も対象が静止することや加速度零を要求しない。旧系の力の成分を新系へコピーせず、二項の対置を無条件な数値の同一性としない。

固定アルファベットと共通375語を維持する。任意profile73は、速度を入力とする試験力応答、引用用語の役割、旧新の言い方、物理的な座標対応について、既存の四規約の型と意味を保存する。原文主張を一つの原始関係へ置き換えない。

検査では復号した定義の逆写像と親本文の保存を確認し、有限の数値・方向・記録・参照・束縛を診断する。多数の証人は他の束縛を固定して一つずつ識別する。近似の全実数域、全関数域、物理法則の証明とは区別する。
