# 仕組みの目的と文全体の接続

第五段落の `Nun ist zu manchen Geschäften` から `zu werden.` までを、先行する主節・関係節と目的節を結んだ一文として構成した。必要な仕組み、受動的に振る舞うべき成員、その振る舞いを公的目的へ向ける機能的関係を別々に保つ。

必要性と職務上の要求には前回の `r2zx` を再利用する。目的の手段となる `r3b` は、同じ機構・事務について、基準で固定した成員が同じ役割で受動的に遂行する内容である。要求内容と同じ `r2zu` を使い、本人・役割・事務の束縛を変えない。この内容を引用しただけでは、現実に従っていることを意味しない。

目的内容 `r3a` は、同じ事務の政府・共同体・成員・目的記述・協調配置を `r2zr` へ渡す。人為的一致は制度的に整えた実務上の協調と読む。方向付けと破壊の抑止にも同じ配置を渡すため、無関係な一致が存在するだけでは満たさない。両者の目的記述も同一である。

方向付けられる人と、少なくとも破壊を抑止される人は、同じ対象範囲の中で混在してよい。選言は包含的であり、一人に両方が成立してもよい。いずれも目標の実現そのものではない。方向付けがあれば抑止が論理的に成立するという条件も加えていない。

`um` は、受動的遂行 `r3b` を目的内容 `r3a` へ向けた仕方として置く機能的な目的関係 `h237u` で表す。個人の内心の意図を政府へ移さず、目的の達成や成功の確実性を要求しない。政府の管轄と目的の公共性は外側の `r3c` で別に保持する。

`wenigstens` には、同じ目的内容の各人について、方向付け `r3e` より抑止 `r3f` を控えめな最低限として示す提示関係を置く。論理的な強弱、数値、確率の代用ではない。`Nun` は先行する私的使用の定義に続き、職務上の制約を説明する移行と読み、既存の説明関係 `uf` と本文順序 `ue` を使う。

`manchen` と `einige` は、具体的な件数・人数を定めない非空の範囲として読む。全てを要求せず、必ず除外対象があるとも断定しない。制度的な機構を物理機械へ分類せず、職務上の受動性を思考能力の欠如や職務外の議論の禁止に広げない。これは後続文の、同じ人が学識者として論じうるという留保と整合する採用解釈である。

原刊485頁で一文全体とその後続を照合した。通読判断はこの明示した解釈に限る。有限モデル検査は参照と作用域の接続を確かめるものであり、原文との同義性の自動証明や独立査読ではない。二作品全体は未完である。
