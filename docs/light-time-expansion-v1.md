# τの引数展開と同じ光速度原理

u0051の文（142文字、本文116文字）と、u0052–u0053に分かれた一つの表示式を合わせて読む。前の中点式について、τの引数を明示し、静止系の光速度一定を適用して書き換えたという著者の提示である。

## 座標と往復時間

この表示式では出発・反射・帰着の補助座標を0,x′,0、横座標をy=z=0とする。k原点のx-vtが零となる座標の選択として明示し、同じ三出来事の現在のK四座標へ接続する。Kでの出発位置そのものはvtであり、一般には零ではない。出発時刻tも任意の有効値のまま保つ。

正方向の非退化な試行としてx′>0、v>0、v<Vを用いる。往路は光と前端が同じ向きに進むためx′/(V-v)、復路は光と戻る原点が逆向きに進むためx′/(V+v)となる読みである。先行の一般的な往復では許していた負や零の補助値に、この向きの正の経過時間式を無条件には適用しない。

両端点の等速履歴、往路と復路の完全な光の履歴、同じ三出来事での出会いは既存eitiへ接続する。始位置は同じK四座標から取り、端点間隔を同じx′とする。真空と反射、全軸経路を保ち、二端の数値だけを全経路の代わりにしない。

## 光速度と現在の局所時計

第二原理は静止系の全真空伝播区間・全部分区間へ同じVを与えるeiosを使う。両光路の記録zdx,zdyをその範囲へ含め、eifw/eiorの同じ光・放出元・出来事・幾何学的弧長・単位へ結ぶ。往路長は反射位置−出発位置、復路長は反射位置−帰着位置とし、上の全直線履歴を伴わせる。

両端のK時刻は現在の配備時計の局所表示eiyg、一意な時刻付与eiyi、系内時点との対応eiyjへ結ぶ。同じ値を区間のwo/wpと四座標の時刻成分sjhへ渡す。kに静止して移動する時計のτを、これらK時計のtへ代入しない。

同じ候補関数zd4は、現在の全出来事の対応と全k時計指示への一致eizzを満たすという前提で用いる。sjkにより実際の三出来事の補助位置とK時刻での関数値を、同じ試行のτ₀,τ₁,τ₂へ結ぶ。具体的な関数形や解の発見を先取りしない。

展開式は既存sjgの三回の関数呼出しを保存する。左辺は出発と帰着の関数値の半和、右辺は反射の関数値である。二分母の符号、四引数の順序、同じtと同じ関数を保持する。分割された二数式を別々の主張として扱わない。
