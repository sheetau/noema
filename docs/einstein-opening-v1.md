# 冒頭の原刊照合と記述要件

原刊891頁の画像を保存し、固定転記u0001–u0003を紙面と照合した。表題の前には論文番号「3.」がある。これは誌面の配列番号として記録し、固定単位の表題内容とは分ける。頁番号891、改行、行末の分綴、文字の強調も版面情報として保持する。u0003は一つの連続段落であり、電子表示上の改行を新しい論証単位にしない。

著者表示は「von A. Einstein.」である。「von」は当該論説の著者としての表示を結び、「A.」をこの単位の内部でAlbertへ展開しない。名称個体と人物を分け、既存206主張が使う著者参照rdを同じ表示対象へ結ぶ。誰が組版・印刷・提示したか、自筆かどうか、表示が歴史的に真正かは、この前付の表示内容から導かない。

この関係には、カントで構成した名称使用・適用・著者表示の一般定義rqqxを再利用する。0.14で使える本体であることを確認し、eiaaへ名前を移して引数と意味を保持した。七つの入力は名称使用の成立、名称の適用、著者表示の役割という三関係と、名称・箇所・文書・文脈の四参照である。新しい原始関係一つで原文全体を代用しない。終止の句点は表示の区切りとして扱い、姓名の構成部分にはしない。

表題の主題記述は未完である。「運動する物体の電気力学について」という主題の提示を、特定の物体が実際に運動したという断言や、著者がその分野を完全に解決したという主張にしない。既存zneは分野への参照であり、電気・磁気の相互作用を扱う分野概念そのものの説明にはなっていない。既存weも光の放出時の運動を受け取る入力であって、一般の運動の説明には使えない。

導入段落の第一文は、通常の理解におけるMaxwellの電気力学を動く物体へ適用すると生じる説明上の非対称性と、現象にはそれが属さないように見えることを、知られた事柄として提示する。現在の慣用的な理解という挿入部、非対称性が現象に属さないという見かけ、「知られている」という提示を残す必要がある。理論一般の欠陥や現象の厳密な対称性の無条件の証明へ置き換えない。

第二文は一つの磁石と一つの導体の相互作用を考えるよう求める例示である。第三文では、この例の観測可能な現象が相対運動だけに依存することと、通常の理解ではどちらの物体が動くかで二場合を厳密に分けることを対照する。同じ二物体・相対運動・現象を保ち、座標系ごとの説明と観測量の同一性を混ぜない。

第四文は磁石が動き導体が静止する場合で、磁石の周囲に一定のエネルギー値を伴う電場が生じ、導体部分のある場所で電流を生むという説明である。第五文は磁石が静止して導体が動く場合で、磁石周囲の電場は生じず、導体にはそれ自体にエネルギーが対応しない起電力が生じるという説明を対置する。同じ相対運動を仮定したとき、電流の大きさと経過が第一の場合と一致する。起電力を単なる力の別名とせず、どの場所の電場を否定しているか、どの量にエネルギーが対応しないか、同一性の条件の範囲を固定する必要がある。

ここまでの原刊照合と読解要件は、導入段落のNoema記述が完了したという判断ではない。既存の座標割当・世界線・場・数量の候補は再利用箇所を調べ、対象の物理的な同定、理論への帰属、全事例範囲、提示の役割を順に接続する。著者表示の短い単位だけを確認しても、論文全体の意味完成率はほとんど増えない。
