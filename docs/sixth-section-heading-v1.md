# 第六節の二つの主題

u0152の二文を原刊907頁に照合した。第一の主題は真空のMaxwell-Hertz方程式の変換、第二は磁場中の運動で現れる起電力の性質についてである。どちらも同じ第六節の案内として保持し、本文の仮定・変換結果・解釈の結論は見出しから断言しない。

方程式側は、前回の真空領域と物理的な二場・単位の規約ejspへ既出のV=tcを渡す。長さ時間尺度を速度単位tbへ結び、六つの回転方程式を閉じた規約ejsqとして指定する。Maxwell-Hertzの歴史的な呼称もこの規約へ結ぶ。変換は第三節で構成した同じ出来事の二座標系での表示対応eiu2を保つ、式の表示系の変更という研究主題である。同じ形の成立や導出の正しさを主題の条件に追加しない。

見出しは場の一般的な規約を案内するので、引数として場と領域を残す。後の本文が指定する現在のznl/znm/znkを既に真とする必要はない。この区別により、式の主題とu0153からの仮定を混同せず、具体的な場への適用を次の作業へ残せる。

起電力はu0173–u0176の説明を参照し、動く正の単位試験電荷に対する局所的な作用として読む。ejsrは同じ担体・系・出来事の磁気作用eico、力/電荷の単位eisar、同じ局所速度と磁気側値による駆動eidzを結ぶ。実際の座標時刻微分と軌跡、場の評価、力の記録を再利用し、導体・磁石・閉回路の存在を見出し一般の条件にしない。

ejssはその駆動が非零で現れる場合を指定する。磁場と速度が平行な場合などの零作用を、運動や磁場だけから非零へ変えない。性質を検討する主題関係は、零作用との比較も許す。同じ系の局所作用の規約を使うことと、u0174の一次近似を厳密な系間の力変換として証明することは別であり、補助概念という後段の結論も追加しない。

追加する二つの一般関係は、閉じた方程式規約と座標対応を使う変換研究、閉じた作用規約を使う物理的な性質の研究である。これらは主題を扱う関係だけで、方程式、真空、場、運動、駆動の内容は引数の合成に置く。呼称・節・見出し箇所の三つの参照も分ける。第六節は第二部の深さ2・表示番号6で、冒頭の仮定範囲znoとは別の区分である。

検査では、全ての引数を同じ磁気作用へ渡すこと、局所駆動の三成分と零作用、単位電荷、単位規約、Vの指示と速度単位、二主題の引用、見出しの階層・番号・順序を確認する。全軌跡や真空領域を有限列挙せず、引用を実行しない。局所検査と原文全体の通読判断は別記録とし、本文357主張と既存判断を保持する。
