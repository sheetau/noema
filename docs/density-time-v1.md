# 密度と総量の時刻をそろえる修正（2026-10-15）

[前版](density-interpretation-v1.md)の密度の説明には、時刻を照合する接続が不足していた。球は中心点の座標時刻に置かれ、総電荷は `clock` が指定する時刻の対象範囲で評価される。この二つの時刻が同じであることを、意味規約だけでなくNoemaの式にも追加した。

## 再現した問題

旧 `seou` は指定した時刻の対象範囲と領域の共通部分を使う。これは一般の領域量の構成としては意図した動作だが、局所密度の球に接続するには、球の時刻との一致が必要になる。

総量がゼロなら、時刻4の球を時刻5の対象範囲で評価してもゼロになり得る。量の一致からは、同じ時刻を評価したと判断できない。既存検査の総量条件の代用関数には、期待する時刻の対象範囲と一致するという追加の照合があった。そのため、密度側で時刻を照合しなくても検査は通っていた。

今回は、どちらの時刻でも成立するゼロ総量の条件を与え、旧接続が一致・不一致の両方を受け入れることを再現した。この再現は空間全域の加法性を実行したものではなく、空間の条件を明示した代用関数で与える接続検査である。この限界を検査結果に保存した。

## 追加した条件

三つの定義を追加した。原始記号や文法演算子は増やしていない。

- `seox`：同じ物質・系・出来事・文脈に属する全ての有効な四座標について、座標時刻が同じ系・出来事・時間単位・文脈の `clock` の値に一致する。
- `seoy`：既存の密度条件 `seom` と、同じ引数を使う `seox` の両方を要求する。
- `seoz`：総量の接続 `seou` と密度の接続 `seoy` に同じ `clock` を渡し、速度の説明と本文の式へつなぐ。

一致する記録が一つ見つかればよい、という条件にはしていない。同じ出来事について別の有効な座標記録が異なる時刻を持てば不一致になる。一方、別の物質・系・出来事・文脈の記録に同じ時刻は要求しない。

`seox` 単独では座標記録の存在を主張しない。密度側の `seom` が同じ対象の有効な中心点の存在を要求するため、記録の不在を密度の存在の根拠にはできない。時刻不一致は密度の帰属候補を満たさなくする。本文全体は条件付きの主張なので、それだけで本文全体が偽になるとはいわない。

17テストが通過した。実際の全称条件から取り出した11通りの座標例では、時刻・時間単位の不一致、別の対象の記録、負数・分数の時刻を区別した。一致する例と不一致の証人は確認したが、全POINT域での一致を有限の地点一覧から認定することはしない。全域の評価は有限解釈器が拒否し、未知の時計解釈も勝手に偽や既定値へ置き換えない。

検査器は参照経路と引数、本文の変更範囲、帰属と引用の区別、表記・固有文字の往復も確認する。CLI解析とSVGのXML検査も通過した。今回、SVGの視認性評価は行っていない。[検査結果](../reports/density-time-v1.json)と[確認記録v4](../data/density-formula-review-v4.json)を保存した。

この修正は時刻の不整合を防ぐもので、旧版の帰属と新しい説明の双方向一致、電気量や単位の基礎説明、原文全体の意味確認を完了するものではない。原文対応範囲は増えておらず、意味確認済み区間も0のままである。
