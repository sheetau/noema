# 同じ伝播内容を保つ部分集団の比較

「後見役の中にさえ」という読みを表すには、後見役にも該当者がいるという存在条件と、それを強調する比較背景を分ける必要がある。今回、既存の[主張と比較背景の構成](scalar-backgrounds-v1.md)を、具体的な自己思考・自己離脱・性向の伝播へ接続した。人物や経路を比較対象ごとに取り替えず、部分集団の条件だけを変更する。

`hzp2` は履歴・母集団・人ごとの行為や経路・共通の性向記述など、30引数を充足した枠の記述を作る。`rqtk` はその同じ枠へ、部分集団を指定する閉じた述語記述を適用する。`rqtl` は全比較対象へ同じ枠を適用し、`rqtm` は焦点の主張と尺度条件の背景を組にする。構成中に伝播や任用の事実を実行しない。

枠の中では既存の `hzoo` を再利用する。各人が独立判断・自己離脱・自分の経路による伝播を満たすこと、全体に複数の該当者がおり、指定部分集団にも該当者がいることを結ぶ。`rqtj` は与えた順序付き履歴の全将来機会を調べる。基準点自身での成立は要求しないが、基準点の欠落、将来機会が空であること、不成立の将来点を黙って除くことは許さない。

検証例では焦点を既存の任用された後見役 `hzhb`、比較対象をその否定とする。同じ履歴・母集団・複合条件の下で、「後見役にも該当者がいる」と「後見役でない人にも該当者がいる」を比べる例である。この比較対象や尺度がカント原文に唯一適切であるという判断ではない。Noemaでは別の閉じた述語も明示して渡せる。

| 検証例 | 焦点の主張 | 比較対象の内容 | 指定した比較背景 |
| --- | --- | --- | --- |
| 該当者の二人とも後見役 | 真 | 偽 | 成立 |
| 後見役一人と後見役でない一人が該当 | 真 | 真 | 成立 |
| 二人とも後見役ではない | 偽 | 真 | 成立 |
| 二人とも後見役だが比較尺度を満たさない | 真 | 偽 | 不成立 |

今回は尺度だけを背景とする `rtg` を使うため、比較対象の実際の成立を追加条件にしない。特定の部分集団の外にも該当者が実在すると勝手に補わない。これを `sogar` の全用法に対する決定とは扱わない。尺度の意味・視点・基準文脈は明示した入力であり、具体的な確率や意外性を補完しない。

主張だけを否定する `rsw` は背景の記述を保持する。背景が成立しないことから主張を偽としたり、主張が偽であることから背景を否定したりしない。原文への帰属関係もこの組から自動では導かない。

六項目の検査を行う。一般形では主張に関わる条件と尺度の16組合せ、空・自己比較・重複・別視点・別文脈を調べる。具体的な伝播では五対照を調べ、比較時の閉じた共通30引数と性向記述の一致を検査する。後見役を焦点とした主張は、前回の閉じた内容 `hzow` の評価とも四対照で比較する。大きい全将来内容の実行には短絡診断を用い、通常評価の完了とは扱わない。背景だけを読む場合は、世界の事実が全て未知でも通常評価できる。将来機会の六対照、必要な未知入力の拒否、引用階数・引数型の不一致、通常・短縮・固有文字の往復も検査する。

新しい合成定義は七つで、既存の比較背景の十三定義を再利用した。基本関係は増やしていない。一般形は2,535文字、累積接続文書への追加は4,674文字。既存32文と全意味規約、七単位の確認は保持する。

```powershell
python -X utf8 -m scripts.compose_focused_dissemination
python -X utf8 -m pytest tests/test_focused_dissemination.py -q
python -X utf8 -m scripts.check_focused_dissemination --verify-only
```
