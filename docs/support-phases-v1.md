# 足の接地と荷重支持の移行

Noemaで、同じ身体の二つの足が接地し、身体の荷重を受け渡す過程を記述できる構成を追加した。接地、荷重支持、状態を調べた範囲の完全性を分ける。これは歩行の身体的説明に使う部品であり、「歩く／走る」の完成した分類器ではない。

カントの [gehen lernen](https://korpora.org/Kant/aa08/036.html) には歩行の習得が現れる。現行の `zal` は外部の身体支持がない脚による移動を表すため、走行との区別をまだ持たない。ただし、これを「両足が同時に浮かない」だけに置き換えても、語義の問題は解決しない。子ども22名と成人7名を対象とした[歩行・走行の発達研究](https://d-nb.info/1228757739/34)は、接地・空中期とエネルギーの関係に加え、多くの運動特徴を比較している。単一条件をすべての発達段階に共通する語義としない判断に、この研究を参照した。

| 定義 | 表す内容 |
| --- | --- |
| `rqvx` | 同じ履歴の連続した範囲と、その開始・終了 |
| `rqvy` | 同じ本人・活動・二足について、全範囲の接地と荷重支持を評価できること |
| `rqvz` | その全範囲で、少なくとも一方の足が接地していること |
| `rqwa` | 接地を保ったまま、第一の足のみ、両足、第二の足のみへ荷重支持が移ること |
| `rqwb` | 同じ範囲のどこかで、両足がともに接地しないこと |

接触だけから荷重支持は導かない。反対に、荷重を支持しているのに接地していないという入力は、この構成の意味規約では矛盾として拒否する。足が接地しない状態でも、手や装置が身体を支えている可能性は残るため、それだけで全身が空中にあるとは表さない。

`rqvz` と `rqwb` はともに評価済みの条件を含む。そのため、`rqvz` が偽であることだけから `rqwb` を導かない。範囲が不完全な場合や未評価の場合は、どちらも確定しない。評価済みの同じ範囲では、全点の接地と非接地の点の存在は両立しない。

範囲の完全性は `complete(person, act, scope, context)` という明示的な入力である。有限モデル内で履歴に穴がないことと、現実の活動全体を記録したことは別である。たとえば記録から中間点を除き、履歴そのものからもその点を除くと、履歴内の順序検査だけでは欠落が見えない。この場合でも完全性の入力を要求する。実測が非空という理由で完全と補わず、未知なら判定を拒否する。

範囲内の三点で荷重移行が見られるだけでは `rqwa` は成立しない。範囲全体の接地条件も必要である。ただし、立ったままの体重移動や接地を保つ別の運動も同じ支持記述を満たしうる。位置の移動、速度、身体制御、技能、外部補助、エネルギーの交換や運動の分類は、それぞれ別の内容として加える。

一般文書は五つの定義を追加し、新しい基本関係や実行時演算子を持たない。例文書の15入力は、本人や活動の参照と、履歴・接触・荷重等の意味規約を示す。検査用の具体的な人物名や時間列をNoemaの語義に固定しない。独自文字を含む表記の往復も検査する。

現行カント本文と意味確認登録簿は変更しない。対応記録は `gehen lernen` の既存範囲に関連する部分的な説明部品として残し、原文との意味一致の証拠や確認済み分量には加算しない。本文に採る歩行の語義、見込みの語用論、第二段落全体の確認は引き続き必要である。
