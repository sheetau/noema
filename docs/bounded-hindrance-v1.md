# 許容する低下と進歩への留保

「啓蒙の進歩を特に妨げない」という留保について、同じ背景条件で制限の有無を変え、結果の低下が許容値を超えないことを記述する候補を追加した。既存の因果変数の範囲指定、二値介入、算術、型付きの政策記述を再利用しており、新しい基本概念や構文は追加していない。原文の意味に一致すると確認した定義ではない。

各比較では、同じ方程式・背景・要因・尺度を使う。制限を適用した側の結果と、適用しなかった側の結果について、次を検査する。

```text
制限あり側の尺度値 ＋ 許容する低下 ≧ 制限なし側の尺度値
```

許容値は非負とし、境界と等しい低下は許す。尺度が10から9へ低下する例では、許容値2なら条件を満たし、許容値1/2なら満たさない。0を指定すれば低下を全く認めない強い条件になるが、原文の「特に妨げない」を常に0へ固定しない。具体的な数値は検査用の仮定に限る。

| 定義 | 内容 |
| --- | --- |
| `red` | 一組の結果の低下が許容範囲内である |
| `ree` | 指定した要因が変数列に含まれ、両介入に解が存在する |
| `ref` | 許容範囲内となる結果の組が少なくとも一つある |
| `reg` | 許容値を超える低下となる結果の組が少なくとも一つある |
| `reh` | 両側に解があり、どの組でも許容値を超える低下がない |
| `hze` | 介入要因の真偽と、対応する状況での同じ政策内容の真偽が一致する |
| `hzf` | 政策が成立し、その政策との対応を持つ比較で低下が許容範囲内となる内容 |

解が複数ある場合には、一部の結果の組が許容範囲内でも、別の組が上限を超えることがある。`ref` と `reg` はその場合ともに真になり、全組での保証 `reh` は偽になる。また、片側または両側に解がなければ、全組での無害を空虚に認定しない。未知の尺度や政策内容も、低下なしという結果で埋めない。

因果変数は既存の `rz`〜`rx` により明示した列に限定する。文書内の人、役職、場所などを全て因果変数へ増やすことはない。二変数と、それとは無関係な14個体がある場合も検査した。重複する変数列や、要因が列にない場合は拒否する。列外の値は既存規約に従い偽に固定し、比較に必要な背景条件は方程式に保持する。計算量は変数の数に対して依然指数的であり、大きいモデルの効率的な解法を追加したものではない。

政策と因果変数の関係を、記号の名前だけでは認めない。`hze` は両介入の全解について、その解に対応する状況で政策が成立することと、要因が真であることの一致を検査する。反対の政策、無関係な政策、誤った状況対応を使う例は拒否する。ただし、指定した状況対応と方程式が現実の介入結果を正しく表すことまでは、この真偽の一致から証明できない。

`hzf` へ既存 `h77` の程度・頻度を含む政策内容を渡し、その全体を `hza` の許可対象にできる。実際の制限状態と、悪影響の上限を保持した対象記述になる。型付き記述を二段階で組み立てることと、その許可を対象未評価のまま扱えることを検査した。完全な社会的政策の全反事実状況まで検証したわけではなく、因果比較の実行検査は明示した小さいモデルについて行った。

悪影響が許容範囲内であることと、実際の進歩は別である。両側とも進歩が0でも低下は0であり、両側とも後退しているが差が小さい場合にも比較条件は成立し得る。これを進歩の実現や、政策の正当性へ読み替えない。尺度の原点を共通に変えても差は変わらず、正の倍率で単位を変える場合は許容値にも同じ倍率を適用する。単なる順位尺度へ数値差の意味を無条件に与えることはできない。

一般文書は [bounded-hindrance.noema](../examples/v014/bounded-hindrance.noema)、原文への接続は [kant-bounded-hindrance.noema](../examples/v014/kant-bounded-hindrance.noema)。既存の宣言と15件の主張を保持した。全解の全組を比較する条件は強い読みであり、確率的な傾向や、対応する結果同士だけの比較とは区別する。啓蒙の進歩の尺度を先行する自立・離脱の定義へ接続すること、適切な許容基準、規範の作用範囲、原文全体の意味一致は未完である。

