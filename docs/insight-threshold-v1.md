# 同じ共同提案に足りる公的認識と期間の到達点

カントu0013第七文の「洞察が、共同提案できるほどまで公に進み確かめられる」を、提案に関連する公的認識の質的な十分性として構成します。単に認識が増えたことと提案可能性を並べるだけで済ませず、同じ提案に対する認識の充足を比較します。

`r5gl` は、同じ政策・制度・領域に関連する内容について、既存 `r5fu` の把握・根拠・公開・確証を保ちます。`r5gm/r5gn` は、この公的認識の内容の包含と一致です。別名や同じ水準の担い手の交代は増加にせず、人数・件数・数値的な程度も補いません。

`r5go` は、関連認識が非空で実際に同じ共同提案が可能であり、認識以外の背景をそろえた全比較例でも、その認識内容を備えれば同じ提案が可能であることを要求します。`r5gp` はさらに、以前と同じ公的認識を後点の背景条件に置く非空な比較例では、同じ提案ができないことを要求します。外的な機会が改善しただけ、無関係な項目が増えただけ、比較例が空という場合は、洞察が不足から十分へ達したことにしません。

この比較範囲は明示した解釈入力です。関連する資源・制度上の発言経路・宛先・成員などをそろえますが、認識を使った方法の利用可能性や提案可能性そのものを固定しません。全可能世界に通用する必要十分条件や唯一の最小閾値を証明する構成ではなく、文脈上の質的な十分性について採用する強い読みです。

`r5gq` は同じ開始点からの到達内容、`r5gr` はそれを同じ導入活動・法・制度・短期の `r5fp` に渡します。終了点が最初の到達点となり、それまで制度と全市民の書面批評の自由が保たれます。導入の目的も保持し、終点後の廃止や現実の必然的な到達は追加しません。

検査は関連内容の比較、以前の認識を後点の背景で比べること、空虚な全称の排除、同じ提案・真偽評価・候補点の同一性、同じ期間の最初の到達を対象にします。認識と共同提出の内部、導入と公的批評の内部は保存済みの実評価証拠を保ち、今回の接続検査ではそれらを明示した境界として扱います。公的認識と提案の間の比較および時間条件は実評価します。
