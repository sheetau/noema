# 動く鏡面のエネルギー流と仕事

u0222–u0223の入出エネルギーと仕事を記述するため、同じ鏡の物質的矩形部分、同じK時間区間、同じ入射・反射モデルと力を接続する。現在の402主張を保存し、今回は必要な依存定義を追加する。四文の提示やエネルギー原理への帰属まで完成したとはしない。

入射するエネルギー流はJx−v*u、戻るエネルギー流はその反転である。密度uと流Jを同じ波の同じ点・時刻・単位へ結び、鏡の軌跡x=v*tへ引き戻す。静止した面を横切るJxだけでは、動く面への単位面積時間あたりのエネルギーを表せない。

平均は同じkの一周期に対応する鏡上のK時間区間を使う。矩形内の全接線位置で同じ時間平均となる条件を要求するため、瞬間の場が面全体で一様であるとの仮定は不要である。密度と流の物理的なモデル採用、原文の単位校正、同じ局所領域内での全照射は独立に保持する。

仕事は同じ光の相互作用の法線力Fx(t)と鏡速度vの積を時間積分し、同じ面積と時間幅で正規化する。平均圧力はFx(t)の時間積分を同じ面積と時間幅で正規化する既存定義を使う。v=0でも圧力は定義でき、仕事が零だから圧力も零という逆推論はしない。接線力自体を零とする条件も加えない。

原文の入出流の右辺、仕事=入出差、仕事=P*v、圧力の閉じた式は帰結候補へ分ける。物理設定や積分条件へ結論を埋め込まない。エネルギー差を機械的仕事だけへ結ぶ理想化とエネルギー原理への参照、offenbar、Pの命名、導出と表示は次の本文統合で扱う。

有限の数値・多項式波形による診断は軌跡、符号、単位、積分境界と全引数の接続を調べる。全実数の面領域と時間積分は本文の定義に残し、標本の通過を一般的な物理法則や意味同義性の証明にしない。
