# 宗教上の援助を主要な務めとする役割

三つの代行例にある宗教上の助言者の部分説明へ、社会的な役割と、その主要な務めという条件を接続した。旧 `sp` は、人であり宗教的な事柄の判断を継続的に援助することを要求していたが、その援助が役割上の主要な務めであるかは区別しなかった。

バイエルン州立図書館のAdelung電子本文では、[Seelsorger](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_2_0_135)を、魂への配慮を主要な務めとする聖職者として説明している。[Seelsorge](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_2_0_134)は精神的な安寧への配慮で、通常の用法では他者に対する配慮として説明される。この二項目を、職務上の読みを支える資料とした。辞典の記述だけからカントの唯一の語義を確定したり、聖職者の制度上の全条件を説明済みとしたりはしない。

取得したページのHTML、文字コード、取得日時、元バイト列のハッシュ、抽出した項目本文を[出典記録](../data/pastoral-role-evidence-v1.json)に保存した。保存形式はUTF-8のJSONとし、元の文字コードで再構成したバイト列のハッシュも検査する。通常の検証ではネットワークへアクセスせず、固定した記録を参照する。これは言語の語彙を実行時に引く対訳辞書ではなく、原文を読む際の根拠である。

一般定義 `rqxl` は、主体が役割を持ち、その役割が指定した活動への援助機能を持ち、その機能が主要な務めであることを結ぶ。保持する役割、機能を持つ役割、主要性を評価する役割は同じものを使う。別々の役割の条件を寄せ集めて成立させない。

役割の保持と機能には、医師の部分説明で追加した二関係を再利用する。今回加える基本関係は、役割における機能の主要性だけである。主要性は役割の位置付けであり、最近の行為の回数、本人の好み、実際の成功とは区別する。唯一の務めや、数値的な時間配分は要求しない。役割に複数の主要な務めがあってもよい。

本文の `sp` は、旧条件を保存した広い援助者 `rqxm` に、この役割条件を加える。同じ人物による宗教的な生き方・安寧についての判断 `so` への援助を、役割の機能と主要性へ渡す。役割を持つだけで実際の信仰、教義の真理、本人の行う仕事の成功が成立することにはしない。特定教派の叙任手続も追加しない。

教えることを主な機能とする役割の有限モデルで、二役割の三関係を変えた64例を検査した。本文の15対照では、主体・役割・機能・主要性・状況、援助の利用と供給先を取り違える場合を区別した。一人が宗教上の援助者と医師を兼ねる場合や、複数の主要機能がある場合を排除しない。役割を結ぶ三関係が不明なら、既知の意味へ補完しない。

三つの代行例をまとめた五対照でも、同じ本人の前件・適用可能性・条件文を確認した。役割条件が欠けると例の前件は偽になるが、条件文だけは真になり得る。これを例が成立したこととは数えない。実際の本文の定義を使い、検査用の基本関係には置き換えていない。結合検査では純粋な計算結果を再利用し、基準例を通常評価とも比較した。八つの帰属対照では、役割・宗教的判断の事実は不明のままにする。

新しい意味が及ぶのは代行例の文4だけである。本文42文の構文、確認済み十一単位、冒頭一文と支払いの文の意味を保持し、三記法の往復も検査する。既存の二関係の宣言位置を前へ移したのは、同じ宣言を先に参照できるようにするためであり、その意味や型は変更していない。登録簿v48へ根拠を結び直すが、確認済みの単位や分量は増やさない。

宗教的な配慮を判断の援助で表す範囲、聖職者の制度的な全条件、良心の語義と談話上の働き、書物・医師の残る意味、第二段落と二作品全文の確認は残る。
