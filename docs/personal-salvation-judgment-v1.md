# 臣民と、自分の救済に必要だという判断

カント第六段落第十一文の `u0013[3353,3464)` に向け、同じ君主の臣民と、本人が自身の救済のため必要と考える営みを構成します。この範囲のlassenによる委ね方や限定表現、文全体はまだ統合していません。

臣民は、同じ共同体の最高統治職の権力・管轄に服する制度上の立場として読みます。同じ君主が保持する同じ職へ接続し、現に命令を守る人だけには絞りません。[AdelungのUnterthan第二義](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_4_1_1277)は国家・領邦の最高権力に対する所属を扱います。私的領主の農奴という別義や、現代の国籍・参政要件は加えません。

Seelenheilは、本人自身の宗教的・精神的な究極の安寧ないし救済を扱う目的内容として読みます。具体的な内容は閉じたNoema記述で指定します。魂の実在や不死、特定宗派の教義の真理を分類だけから断定しません。営みも本人の行為として具体的な内容を指定し、公的な議論だけに限定しません。

「必要」の内容は、明示した背景条件の下で目的達成が可能であり、目的が達成される全経過にその営みが含まれることです。目的が不能だから何でも必要になる空虚な読みを避けます。経過全体を評価する状況を使い、先行する行為と後続の救済を同じ物理的瞬間へ押し込みません。これは目的に相対的な必要条件で、営みだけで救済が保証される十分条件ではありません。

この必要性内容と、本人がそれを受け入れていることを分けます。原文のnöthig findenは誤りうる本人の判断と読み、実際の必要性・救済可能性・行動を臣民の対象条件へ追加しません。必要性の内部では段階0の内容を実行するため、信念の対象は段階1の引用です。本人・営み・目的・基準の呼称が元の対象を指すことも個別に照合します。

検査は、同じ職への服属、目的と行為の本人帰属、目的達成を欠く空虚な必要性、別の経過での反例、十分性との相違、信念と真偽の独立、引用段階・呼称・三対象列・未知入力を扱います。君主の役職内部は保存済みの検査を境界として再利用します。全文での臣民への量化、本人に委ねる範囲、君主の職責、暴力的妨害の防止と後続の救済の決定・促進は未接続です。本文106主張・意味確認文字数は据え置きます。
