# 植え付けと報復の非字義的な描写

第三文後半の植物の植え付けと、偏見を報復の主体として扱う描写を、既存の事例・主張・範囲へ接続した。本文の未確認の統合を `r2pn` に更新する。描写が接続できたことと、第三文全体の意味確認の完了は分ける。

## 植物側と対象側の役割

植物の植え付けは、根を持つ植物を生育させるため培地へ置く描写と読む。[辞書のpflanzen](https://www.duden.de/rechtschreibung/pflanzen)を語義の補助に用いた。種子を播くこと、農業上の収量、実際の生育成功までは加えない。

植物側 `r2pa` は、同じ人・行為の生起と参加、同じ植物と培地についての生育目的、同じ行為による配置状態への因果的寄与を結ぶ。配置状態 `r2oy` は植物・培地の分類と、根の領域が培地内部で接することを要求する。生育目標 `r2oz` は既存の目的関係 `hzu` へ閉じた記述として渡す。目的が達成されたことは要求しない。

対象側 `r2pc` は既存の偏見採用の生成 `r2ob` である。描写側 `r2pd` は、同じ事例の生み手・行為・意見・受け手・植え付け点を、植える人・配置行為・植物・培地・配置点へ対応づける。受け手を指す閉じた名前も元の参照と照合する。

この対応は、受け手の人が実際の土壌であることや、意見が実際の植物であることを主張しない。対象側に描写側の生育意図も追加しない。`r2ph` は同じ評価主張 `r2ot` の中で、一位置の事例列を共有する範囲・対象・描写を既存 `h224n` に渡す。

## 報復の主体としての偏見

対象側では、先行する偏見採用が生み手本人またはその役割を継いだ人への害に寄与する既存 `r2oi` を保持する。偏見に意志や悪意があるとはしない。

描写側 `r2pj` は、同じ主体が先行行為を自分への不当な扱いとして受け止め、その行為への応報として同じ対象者の害を意図し、同じ応答行為が実際にその害へ寄与することを要求する。[辞書のrächen](https://www.duden.de/rechtschreibung/raechen)が区別する、意図的な報復と悪い結果をもたらす用法を、この二つの側として区別する。

既存の処罰 `rfm` は対象者本人の行為への応答を扱うため、先任者が生み手である枝を含むここではそのまま使えない。生起・参加・目的・不利益・因果は再利用し、応答が受ける先行行為と害を受ける対象者を独立に結ぶ。処罰の正当性や先行行為の客観的な不当性は要求しない。

`r2pk` は同じ事例の `r2oi` をそのまま保持し、意見を応答主体、植え付け行為を先行行為、同じ帰結点を応答点として描写を加える。これにより生み手本人と先任者の選言や、経過の終点を描写側でも落とさない。

対象族 `r2on` と描写族 `r2pl` は `[事例,意見,本人]` の三位置を共有する。`r2pm` は同じ理由節の主張 `r2ok` と範囲 `r2om` に、この非字義的な提示を帰属する。

## 検査と全体の意味判断

植物側では分類・配置・目的・因果を直接実行し、どれかが欠けても対象側の偏見の植え付けが成立し得ることを確認する。成長目標は未知のままにし、実際の成長を要求していないことを検査する。

報復側では、同じ対象側の関係を直接実行した上で、受け止め・応報・加害意図・応答主体・行為の生起・因果・対象者名を検査する。対象側の害だけでは報復の描写は成立しない。本人の枝と先任者の枝をともに保つ。

役割の族は構文木でも照合し、二つの帰属は世界の入力を全て未知にして検査する。引用された植物・意図・報復行為を、帰属から事実として導かない。
