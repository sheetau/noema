# 電動力の補助的な役割と導入理由

対象はEinstein 1905のu0176全体である。原刊910頁を固定転記と照合し、冒頭の磁動力への類推、後半の補助概念の役割、その導入理由、著者による明白さの提示を続けて読む。冒頭と末尾の系依存性は既存の文169・170を保持する。今回は文171・172を更新する。

## 概念の同一性と役割の限定

電動力は第一項の引用語eisqsと同じ概念であり、値の役割は既存のejygへ結ぶ。その規則は物理的な動的応答と静止時の電気側の作用との差を指定する。数値の外積一次項が厳密に等しいという条件は語の意味に含めない。残差の構成ejx4と一次近似の主張を区別する。

補助概念は、既存の量を用いる定義上の補助として読む。ejzuは、理論の記述や説明を構成する使用が少なくとも一件あり、その全てで残差ejx4による定義展開ができる、と述べる。使用の集合には法則・定義・予測・説明に寄与する全ての役割を含める。成功例だけを集めるとnurを表せないため、範囲の完全性をeisq2の意味規約に明記する。

各使用の展開は、同じ物理的な量と説明上の役割を保ち、当該概念の値を独立に与える入力を残さない。これはeisq3という一般の型付き定義展開の関係である。特定の残差式や「補助概念」という結論自体をその関係に埋め込まず、ejzuで具体的な構成規則と量化を合成する。全理論の保存拡張定理を証明することや、語の使用・物理的な力の存在を禁止することは、この読みの要件に加えない。

## 同じ概念の導入理由

ejztは表現・物理的役割・理論への導入eiscwを一つの概念証人へ結ぶ。ejzwはその証人を主節と関係節で共有し、同じ展開済み理論eisqwについてejzoの系依存性を述べる。その事情が同じ概念の導入を説明する理由だという関係をeisq4へ結ぶ。主節とは別の概念を導入するだけでは成立しない。

系依存性の読みは前の構成から引き継ぐ。電気側・磁気側の局所作用の有無を理論全体で系の運動状態から独立な区分にできない、と読む。同じ物理的な過程・出来事・単位を共有する二系の比較と、両種それぞれの許容反例を要求する。全ての場と速度で零・非零が反転するとはしない。

導入理由は理論上の説明として読む。根拠と結論の引用に、同じ理論・概念・状況を与える。eisq4だけでは両命題の成立を含意しないため、ejzwで系依存性と導入も別に述べる。歴史上の心理的な因果や必要十分条件は付加しない。
