# 七表示式と振幅・波面法線

u0180のM0320は、六成分の式と共通位相の定義からなる。u0181は、その同じ六係数を二つのベクトルにまとめ、三つの方向値を波面法線の方向余弦として説明する。文364・365は、この表示と説明を直前の遠方源・局所近似の仮定の内部へ接続する。

## 表示の等号と実際の場

ekbgは同じ四座標で七つの等式を個別に述べる。X,Y,ZとL,M,Nの各係数を対応する成分へ掛け、全成分に同じsin Φを使う。位相の式はΦ=ω(t−(ax+by+cz)/V)であり、三つの空間項全体をVで割り、ωを括弧全体へ掛ける。ekbhは同じ領域の全有効四座標にこの七式を要求する。

表示された二つの場は、先行の近似に用いる表現場である。実際の二場は物理的な源と単位へ結び、表現場との誤差をseat、用途の十分性をeisrwで保持する。表示式の等号を理由に、物理場の誤差を零へ変更しない。ekbiはこの先行の設定ekazと七式を同じ引数で結ぶ。

ωは位相の時間係数であり、正弦の位相をラジアンで測る角周波数として読む。通常の周期数νと数値同一視しない。KとVは先行と同じra/tc、座標と単位は同じ校正済みCartesian基底を使う。

## 二つのベクトルと波面

ekbeは三成分を三空間軸へ割り当てる。ekbjは(X0,Y0,Z0)と(L0,M0,N0)の成分をそれぞれのベクトルへ保ち、その非負の大きさを二乗和の平方根に結ぶ。係数の符号と相対方向は保持する。大きさだけに縮めると、同じ係数が表す偏光方向を失う。正規化した正弦に掛かるこれらの固定ベクトルが、波列の振幅を定めるという読みである。

波面は同時刻の等位相面と読む。ekbkはn=(a,b,c)が単位長さを持ち、同時刻の二位置の位相が等しいことと、その位置差に対するnの内積が零であることを同値として述べる。校正された直交Cartesian基底で、単位法線nの三成分は各軸との方向余弦である。Φの式と正のω,Vが伝播側の向きを定める。

ekblは同じ領域内・同じ時刻の全位置対についてこの法線条件を保つ。実際の場が持つ全波面を厳密な平面へ置換せず、近似表現の平面波面について説明する。別時刻の点を一つの空間平面へ混ぜず、横波の振幅関係をここで追加しない。

## 同じ仮定の明示

七式の内容ekbmと説明の内容ekbnは、先行と同じ31役割の証人から一つの設定を選ぶ。一般関係eissbは、先行の仮定を同じ割当と範囲で明示・説明する著者の提示を表す。u0180はu0179の具体的な表示、Hierbeiで始まるu0181はその表示で使う量の説明として接続する。別の波や新たな実験の存在を追加しない。

## 検査

七式では六成分を一つずつ変え、さらに位相を変えて六成分も整合的に変えた場合を対照する。後者も位相の定義を満たさないため拒否する。ベクトルでは符号付き係数と非負の大きさを区別し、法線では全三軸、同時刻の位置差、誤った位相を調べる。量化は領域の内外と全座標位置を区別し、35引数の設定と31存在証人の接続を点検する。

これらは正確な有理数切断又は明示した有限診断である。診断関数を正弦と認定せず、全実数・全関数の有限列挙で一般性を代用しない。原刊の七式と説明の読解判断は、検査の通過とは別の記録に置く。
