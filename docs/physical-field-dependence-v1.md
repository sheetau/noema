# 電気・磁気の区分と系の運動状態

u0176末尾の「電気的および磁気的な力は、座標系の運動状態から独立した存在を持たない」を、単位試験量への電気側・磁気側の局所作用の有無が、理論全体で運動状態に独立な区分にはならない、という読みで記述する。電磁的な過程自体が消滅するという意味にはしない。

一つの理論が許す同じ過程について、二つの等速並進系、同じ出来事の座標対応、両場と領域を共有する。新系の場は、同じ逆四座標で評価した二場を混合して構成する。両系それぞれで、電荷と磁極強度の静止試験応答、量・場・力の単位、換算1を結ぶ。任意の数値関数や別々の現象を持ち寄って、物理的な系依存性を認定しない。

その同じ地点の三成分について、一方の系では零、もう一方では非零となる許容例を、電気側と磁気側でそれぞれ要求する。二つの例は別の過程でもよい。これにより両側の区分をそれぞれ理論全体で系に独立とはできないと表す。全ての場が全ての系で変わること、同じ例で両側が同時に出現・消失すること、非零の成分値や向きが変わるだけの例では済ませない。

比較には非零の任意方向の速度を持つ純粋boostの代表を使う。同じ向きの対応軸、校正された共通の長さ・時間単位、全系の並進、同一出来事の全域写像を保持する。軸を回しただけ、単位を変えただけ、別地点を測っただけの比較とは区別する。

理論が許す配置を指定する一般関係`eisqx`は、数値変換から物理的な許容を推定するものではない。仮定上の配置を含み、観測済みの実験や孤立磁荷の実在を追加しない。現在の理論は同じ論説の構成課題`eigj`を展開したものとして`eisqy`へ結び、著者の論述段階と物理的な真理の証明を区別する。

局所検査は、零・非零を変える二種類の数値例、符号と方向、変化しない例、同じ過程・二系・単位・四応答の引数結合、著者と理論の参照を調べる。多数の存在証人の結合は、一つずつ量化を残し他を明示した証人で代入する二値診断で全位置を区別する。実際の型の本体は別に検査し、全実数・全関数域を有限列挙しない。

この節の接続だけでは、u0176後半全体の完成にはならない。電動力が補助概念の役割だけを持つという限定、その同じ概念の導入と系依存性との説明関係、「Man sieht」の提示を続けて構成し、冒頭の磁動力への類推と合わせて全単位を判断する。
