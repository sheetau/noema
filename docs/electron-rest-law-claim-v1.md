# 電子の導入と静止時の運動法則

u0240–u0243を原刊917頁へ照合する。電磁場中で電荷εを持つ点状粒子を動かす設定、以後「Elektron」と呼ぶ命名、その運動法則について後続のことだけを仮定する限定、瞬間静止条件と直後の三式、座標と低速質量の意味説明を一続きに扱う。

導入は仮定的な設定を置く指示である。同じ粒子に、校正された電磁場中の完全な局所履歴と位置変化があることを仮定する。位置変化は異なる二時刻の座標の差で表し、途中や初期の瞬間静止を許す。呼称の採用と運動法則の前提は、設定指示とは別の断定的な伝達形式へまとめる。

「直後の時間部分」は、同じ座標時刻の右側への初期速度変化という読みを採る。元の局所領域と時刻t₀を使い、t ≥ t₀の部分領域で、同じ速度関数の差商極限を同じ加速度へ結ぶ。基点を含むので既存の微分定義を適用でき、過去側の値を右側の診断へ混ぜない。有限な時間粒や有限時間の一定加速度、運動方程式の解の存在一意性は補わない。

「ただ次のことだけを仮定する」は、この粒子の運動法則について、この導出段階で独立に採る前提を、後続の条件付き三式に限定する。三行を同じ一組の法則内容へまとめ、同値な表示はその指定内容を参照する。背景原理、設定、意味規約、後で導く帰結を追加の独立前提として数えない。

ε、x,y,z、μは、同じ点粒子の物理的設定からそれぞれ電荷、三空間座標、低速慣性質量を取り出す規則へ結ぶ。低速という限定はμの意味に掛かる。現在の全運動を低速に限定せず、電荷と質量、座標と場の三成分、座標時刻と固有時を区別する。式の表示は先行の静止条件と仮定採用を受け、無条件の物理法則の証明とはしない。

第十節見出しu0239の「緩く加速される」電子の動力学という主題全体は別に確認する。この依存と提示の統合を有限検査で確認した後、原刊へ戻した全文判断を独立した記録に残す。
