# 関係節で限定した人物についての一般命題

カントu0015の冒頭から「そのような君主は啓蒙されている」までを、同じ人物についての条件と結論へ部分接続した。君主の地位、発言についての本人の評価、名称拒否を同じ人物に結び、その人物について既存の能力条件を述べる。特定君主の存在を前提にはしない。

| 定義 | 内容 |
| --- | --- |
| `rnz` | 三つの条件内容を同じ人物・文脈に適用する |
| `ro2` | 条件を満たすすべての個体が、同じ文脈で結論を満たす |
| `ro3` | 条件を満たす個体が存在する |
| `ro4` | 条件を満たしながら結論を満たさない反例が存在する |
| `hzf7` | 君主についての三条件から、既存`h4l`の能力内容への一般命題を構成する |
| `hzga` | 同じ一般命題を主張する発話を構成する |

`ro2`は存在を含意しない。条件に合う個体がいなければ真になるが、`ro3`は偽になる。条件に合う人物が二人いて一人だけが結論を満たさなければ、`ro2`は偽で`ro4`は真である。条件に合わない別人が結論を満たさないことは反例にならない。これらは既存の量化・含意・内容関数で構成し、新しい文法演算子を導入していない。

原文への接続例では、地位を`hzfn`の同じ組織・役職での唯一の最高保持者という構造へ結ぶ。本人の評価には、`rng`の行為基準への適合を`hzfr`によって本人の判断内容にする既存構造を使う。評価対象は「その政策を自分の義務と考える」と報告する行為である。本人がその報告行為を品位に反しないと考えることから、報告の実行や内側の義務判断、実際の義務、政策の実現までは導かない。

名称拒否には、同じ人物を対象とする名称適用をしないよう求める`hzfw`と、その内容を本人が表明する`hzft`を接続する。ここでの表明は制限条件の一部であり、一般命題だけから誰かが実際に表明したとは言えない。三条件を別々の人物から集めることや、拒否の話者と対象を交換することはできない。

結論には、既存`h4l`の「評価済みの条件下で、他者の指導なしに自分の理解力を使える」という能力内容を再利用する。検査では実際の能力定義を通し、他者による指導がある場合や評価が欠ける場合を区別した。この構成は啓蒙された人物への候補であり、決意・自律・学識・政治的評価のすべてを説明済みにはしない。組織と役職も接続例で明示した範囲に限られ、世界の全君主を列挙したとは扱わない。

一般命題の閉じた記述は、既存`uc`で同じ箇所・著者・文脈に帰属させる。帰属の検査では内容の真偽を実行評価しない。反例のある命題にも帰属を記録でき、真の命題にも帰属がない場合がある。引用と異なり、有限解釈器で発話の意味値そのものを計算するときは、各状況の内容の評価が必要になる。それでも主張発話の構成は、その内容が真だという断言にはならない。

[一般文書](../examples/v014/qualified-princes.noema)は392文字、[原文付き草案](../examples/v014/kant-qualified-princes.noema)は192,873文字、[抽出文書](../examples/v014/qualified-princes-core.noema)は7,940文字である。六定義を追加し、原始記号・著者主張は増やしていない。親の宣言と15件の著者主張を保持した。[意味規約](../data/kant-qualified-princes-basis-v1.json)と[検査記録](../reports/qualified-princes-v1.json)を保存する。

二人の三条件と結論の256通りを検査した。原文付き文書と抽出文書では十二条件ずつを比較した。追加16テストは、存在を含まない一般化、別人からの条件の流用、反例、文脈の違い、報告の不実行、内側の信念・義務・政策との独立性、空の判断候補、著者帰属、引用、指導と能力評価を対象とする。三文書のCLI解析、正規形と固有文字v2の往復、SVGのXML検査も通過した。SVGの目視確認は含めない。

これは原文への明示的な解釈注記であり、意味一致の確認を終えた文ではない。不定名詞句を一般条件として読むことの適切さ、君主・品位・名称批判・啓蒙の意味の十分性、alsoによる論証の根拠、自らという強調、称賛に値すること、政府による解放と後続本文の記述が残る。原文範囲の集計には対応する部分草案として数えるが、完成した区間には数えない。
