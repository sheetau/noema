# 方向、逆正接の枝、二速度の間の角

アインシュタイン1905年論文§5のu0138・M0253と、u0139前半について、成分比の逆正接と二速度の間の角の部分草案を追加した。原文の枝の選び方は未確定であり、両者を無条件に同じものとは扱わない。

今回は角を、単位円上の二成分c、sで表す。条件はc²+s²=1であり、向きの正負を区別できる。二成分は既存の真偽値を引数に取る関数へまとめ、真ならc、偽ならsを返す。新しい文法や角専用の基本演算は追加しない。この表現は一周を法とする角であり、周回数やラジアン・度の実数値を含む角の記述は別の課題として残す。

非零のベクトル(x,y)の向きは、正の大きさrを使い、x=rc、y=rsと記述する。零ベクトルには向きを割り当てない。一方、成分比y/xの逆正接の関係は、x≠0、c≠0、xs=ycという条件で表す。この関係だけなら、単位円上で反対側にある二候補が残る。

主値を選ぶ候補は、さらにc>0を要求して右半円に制限する。[NIST DLMF §4.23](https://dlmf.nist.gov/4.23)が区別する一般の逆関数関係と主値を参考にした。ただし、これは現代の規約との比較であり、アインシュタインがこの箇所でどの枝を採用したかの歴史的な証拠にはしない。原文へ帰属させる部分草案は枝を未確定のまま残し、主値の候補を別の内容として定義した。この未確定性があるため、M0253の全意味を保持した訳とは判定しない。

二つの非零ベクトルの間の角では、余弦を内積へ、正弦を有向面積へ結び、それぞれ二つの大きさの積で尺度を合わせる。向きなしの角は別に定義し、余弦を保持したまま正弦を非負にする。前者ではベクトルの順序を入れ替えると正弦の符号が変わり、後者では角が変わらない。

原文の二速度の角は、基準系の符号付き縦速度と、動く点の二速度成分へ接続し、向きなしの角として読む部分草案を置いた。基準系の速度が零なら、二つの非零ベクトルの角という条件は満たさない。角を自動で0にする処理は追加していない。

検査では、(−3,4)の実際の向きは(c,s)=(−3/5,4/5)であり、比の主値の候補は(3/5,−4/5)になる。縦成分が0の(0,5)は方向を持つが、比y/xは定義しない。横成分や基準系の速度が負の場合も、向き付きの角、向きなしの角、逆正接の主値を別々に検査した。

十二の有理数多項式の検査では、正の尺度変更に対する方向の不変性、主値の二成分の一意性、順序反転の性質などを確認した。垂直な成分比にも逆正接を割り当てる候補、零ベクトルに方向を割り当てる候補、主値が常に実際の向きになる候補は退けた。実切断の具体例15件、原文へ接続した解釈11件、帰属6件も検査した。実数全体の代数的・解析的な構成や、ラジアンの測度を証明したものではない。

通常記法・短縮記法・固有文字の構文上の往復、CLIのJSONと構文木の一致、SVGのXMLとしての読み込みを確認した。全テストの実行と字形の目視確認は今回の検査に含まない。

新規8件と関連19件のテストを実行し、26件が通過した。残る1件は解釈例の総数を12とする期待値の誤りだったため、実際の11件へ修正し、そのテストの再実行で通過を確認した。検査報告書と進捗集計も再計算し、保存済みの結果と一致した。

累積文書は基本記号480、定義700、文133である。今回の基本記号は角への参照と本文箇所二つの計3個で、定義を17個追加した。正規形は182,387文字で、親文書から3,686文字増えた。これは累積の定義を含む文書長であり、一文の翻訳長ではない。

原文の明示範囲は60文字増え、部分草案の文字範囲は13,113/35,614文字（36.82%）となった。対応する数式要素はM0253〜M0256の4個増えたが、変数の文字記号も含む。u0137の接続語、u0139後半の計算への移行、訂正を確認したM0257との接続、近似の論述、原刊照合と意味一致確認は残る。意味確認済みの区間は両作品とも0のままである。
