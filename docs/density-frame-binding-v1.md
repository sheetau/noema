# 密度式の二系と速度を先行設定へ結ぶ

密度・速度変換式M0390で参照する二つの系と速度を、先行して導入した静止系`ra`、移動系`zbm`、速度`zb7`へ結んだ。既存の物理的な標準配置関係`zqf`も同じ引数で要求する。配置に関する語の意味を説明し終えたものではなく、本文内の参照先を明示する修正である。

## 残っていた接続

前版は長さ・時間を先行する座標単位へ揃えたが、二系と速度は関係引数`zqf`だけを通じて指定していた。`zqf`の解釈が別の系や別の速度にも真なら、その場合も本文の式の対象になり得る。値が同じことから、同じ二系を指しているとは判断できない。

先行する等速並進の設定`sfl`では、`ra/zbm`の順序と速度`zb7`が既に使われている。今回の読解は、M0390の二系をその設定のKとkとして指す。式を満たした場合だけを選ぶことはしない。速度の具体的な数値も本文へ書き込まない。

## 合成した条件

`sewy`は、順序付きの二参照と値を固定する汎用の条件である。第一参照と第二参照がそれぞれ指定先に一致し、値と固定値が妥当で、指定した比較関係によって一致することを要求する。さらに、元の関係を同じ二参照・値・文脈で評価する。参照が合うことと、元の関係が成立することは別の条件である。

本文用の`sewz`は、この構成を`ra/zbm/zb7`へ結ぶ。値の妥当性は既存の実切断条件`ba`、値の一致は`sca`を使う。二系は異なる個体であることも確認する。汎用条件そのものは同一参照の組を禁止しないため、別の用途で自己比較を表すこともできる。

| 条件 | 元の関係だけを使う場合 | 今回の参照条件を加えた場合 |
| --- | --- | --- |
| 同じ二系・速度で配置が成立する | 成立 | 成立 |
| 元の関係が別の二系や速度にも成立する | その場合も受け入れ得る | 今回の参照とは一致しない |
| 同じ参照だが配置が成立しない | 不成立 | 不成立 |
| 二系を逆順にして速度を反転する | 元の関係の解釈による | 今回の順序と値には一致しない |
| 元の関係の解釈が不明 | 評価できない | 一致から補完せず評価を拒否 |

逆向きの系を扱いたい場合には、期待する二参照と値を明示的に変える。物理的な逆変換が成立するかは、その元の関係で別に検査する。数値の符号を機械的に反転しただけで物理的な逆関係を作る規則は加えていない。

元の配置関係へは、呼び出された文脈をそのまま渡す。初期配置の`zb4`や運動段階の`zb6`を、本文の評価文脈と同一視しない。先行設定との接続は同じ二系と速度への参照によるもので、異なる状況を一つへ潰すことではない。

## 本文と検証

[累積本文](../examples/v014/einstein-density-frame-binding.noema)は206文を保ち、密度式を提示する一文の`frames`引数だけを`zqf`から`sewz`へ変えた。他の205文と既存の宣言はそのままで、新しい原始記号はない。[抽出した一文](../examples/v014/density-frame-binding-manuscript.noema)と[汎用定義](../examples/v014/ordered-value-binding.noema)も同じ構文で解析できる。

検査は、別の第一系・第二系、逆順、逆順と符号反転、速度の大きさ・符号の違い、二つの系の参照が同一個体になった場合を区別する。配置の不成立、異なる評価文脈、未知の配置・速度も扱う。元の配置関係を広く真とする試験で、参照条件が実際に追加の区別をすることを確認する。

値が零の場合も、異なる二参照という条件を保つ。この有限例は参照条件の検査であり、先行する正のx方向の運動設定の全条件が零速度で成立するという主張ではない。汎用条件では負の固定値と明示的な逆順の組も試し、符号を消さないことを確認する。

著者への提示、先行箇所への説明、本文順序を変えた8例でも、引用された配置・速度は実行しない。旧引用と新引用は異なる記述として保持する。通常表記・短縮表記・独自字形の往復、CLI解析、単位の修正の保存、実際の参照経路も検査する。

## 未完の点

`zqf`は引き続き解釈を与える物理的な関係である。対応軸の平行と正の向きの一致、共通原点、時計原点、慣性系、測定と配置の説明は今回構成していない。座標変換の数値が合うだけでこれらの条件を推定することもない。

参照の固定は、旧関係が許す範囲を狭め得る。旧関係が既に同じ二系と速度だけを含む場合とは区別し、新旧の無条件の意味一致を主張しない。配置が存在しないため条件文が空に成立する場合や、原文の対象範囲の完全性も未解決である。[意味確認記録v7](../data/density-formula-review-v7.json)へこの限界を保存し、原文対応率と意味確認済み区間数は増やさない。
