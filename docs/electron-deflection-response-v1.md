# 同じ電子の横偏向と二つの応答

原刊920頁のu0266–u0267を全文へ接続するため、第二(A)の数値式と、同じ電子の実際の運動・場・単位を結ぶ。今回は依存定義の追加であり、全文判断件数は増やさない。

Kでの指定時点の速度を(v,0,0)、電場を(0,Y,0)、磁場を(0,0,N)とする。場の物理的帰属と単位は既存ejsn、同じ電子の電荷と低速慣性質量はek3u/ek3o、実加速度は校正された履歴と二階座標時刻微分ek3qへ結ぶ。電気的な力qYと磁気的な力−qvN/Vは、既存eibs/eicoで同じ粒子・出来事・場に帰属させる。Y,Nを電子への力そのものと取り違えない。

同じ電子・系・速さ・質量・電荷・全単位を二つの試行の外で固定する。電場単独と磁場単独では、それぞれ別の許容状況・出来事・履歴を使える。各試行の実横加速度に第二(A)を課し、さらに両場を与える第三の試行を合わせると、VY=vNの下で二つの横加速度が逆向きで同じ大きさになり、両場の横加速度が零になる。有限時間の同じ軌道を三試行へ要求するものではない。

Ablenkbarkeitは、この標準配置の瞬間的な横座標加速度の大きさを正の場成分で規格化した応答と読む候補にする。Ae=|ay(electric)|/Y、Am=|ay(magnetic)|/Nであり、長さ・時間及び二場の単位は同じ背景に固定する。これは原文にない任意の幾何係数を置く方法を解消する。スクリーン上の有限変位や曲率を使う実験は、同じ応答を取り出すための時間・幾何条件が別途必要である。

Aeは正、Amは非負とし、負の電荷でも符号付き加速度から同じ大きさの比を得る。速度零ならAm=0という数値関係は残す。速度が正の場合だけを通過型の測定装置へ適用する等の限定を、この数値関係の中へ隠さない。数値の復元V Am/Aeと、それを用いた実験の可能性・実際の測定・既知の答えは別に扱う。

新しい原始関係は追加しない。既存の物理的帰属、微分、単位、許容状況、第二(A)のsetk、釣合seto、比sets、復元settを合成する。検査では、正負の電荷と零速度、場強度の変更、同じ背景の保持、三つの実加速度、二試行の全証人、未知入力と全関数量化の拒否を区別する。

全文統合には、u0265の列挙予告、u0266の第二式への照応と著者の推論、任意速度での決定可能性、u0267の式表示、u0268の独立直接測定と高速振動場の例が残る。実際の速度決定を記述する際には、応答を観測して数値を得る仕組みを接続する。現在の試行の存在だけを測定可能性の完成とは数えない。
