# 密度・速度・本文の座標が一致する条件（2026-10-15）

既存の条件から、密度の中心点・速度を求める点・本文で使う点が、同じ出来事・同じ基準系では同じ四座標を持つことを示した。新しい制約や原始記号は追加していない。この結果を[Noemaの条件付き定理](../examples/v014/coordinate-witness-coherence.noema)として保存した。著者の文章への追記ではなく、言語側で記述した定義から得られる帰結である。

## どの条件から導くか

前版の `seox` は、同じ物質・系・出来事・文脈に属する有効な座標記録の時刻を、一つの `clock` の値へ結ぶ。それだけでは空間座標の一致は言えない。そこで、速度の説明に既に含まれる次の条件を使う。

1. `seoc` の速度の点は有効で、同じ対象と出来事の座標記録に属する。
2. `senz` により、その点の時刻は履歴の定義域に入る。
3. `seob` は、定義域内にある同じ物質・系・文脈の座標記録を、その時刻の同じ曲線の座標へ結ぶ。

任意の有効な同じ出来事の点も、`seox` により速度の点と同じ時刻を持つ。したがって同じ定義域に入り、`seob` により同じ曲線の同じ時刻の座標になる。この導出を四成分について検査した。密度の中心点は `seom → seol → seok`、本文の新旧の点は `senu` から必要な有効性と参照先を持つことも、実際の構文で確認した。

新旧二つの基準系の座標が互いに等しいと述べるものではない。上の結論を各基準系の内部で適用する。座標が同じことから、出来事の同一性や、点を表す関数そのものの同一性も導かない。

## 検証の方法

検査器は、保存されたNoema定義の実際の連言項と全称条件の具体化を取り出し、必要な条件へ弱めて検査する。履歴の存在、前向きの対応、近傍、微分など、証明に使わない項を落とす。存在しない前提を追加して結論を得る方法ではない。

まず `sca → sag → bc` を実際の定義から展開し、切断の相互包含が外延的な関数の等しさに一致することを、配列の外延性を使って検査する。有理数の順序や微分の性質はこの補題には不要である。続く座標の証明では、切断の有効性を任意の述語として残し、点を個体から切断値への関数として扱う。実際の有効性条件もその場合に含まれる。

Z3で前提と結論の否定が同時に成立しないことを確認した。これは選んだ有限個の地点が一致したという検査ではない。さらに、使用した七組の前提を一組ずつ外すと、弱めた前提集合では座標が食い違うモデルを作れることも確認した。これらの反例は論理的な射影に対する反例であり、物理的な履歴の全条件を満たす反例と主張するものではない。

同じ四座標でも、未使用の引数で異なる点の関数が存在できることも検査した。余計な同一性を結論へ混ぜないための確認である。未知の構文・意味は拒否し、ソルバーの時間切れを証明成功には扱わない。
