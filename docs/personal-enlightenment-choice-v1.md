# 本人の啓蒙を延期する選択と放棄する選択

第九文では、本人についての一定期間の延期と、本人又は後世についての放棄を区別する。今回は本人の選択の内容を構成する。

「知るべき事柄」は、把握し根拠をもって保持する認識の内容を、同じ規範・本人・立場で要求することから選ぶ。実際に知っている事項を選ぶのではない。全義務項目が本人の自己判断の対象と対応することを確認し、未対応の事項を落とさない。

啓蒙の営みは、同じ対象への学習・探究・検討を本人が行い、理由ある自己判断を目指すことと読む。目的と成功を区別し、実際の認識達成は要求しない。義務事項全ての一斉の完成も要求しない。

延期は、同じ本人の同じ選択において、固定した正の有界期間内には進めず、終了以後に続けるという二つの方針を採用することとする。期間の全範囲と一意の終点を検査するが、将来の計画通りの再開を選択時の条件にはしない。放棄は、同じ本人の今後の継続全体を退ける方針の採用である。単なる未達成・不能・無反応とは分け、正当な権利放棄の効力や永久の実際の不実行は導かない。

規範出所と立場はまだ引数である。本人に限られる許容、一定期間に限られる許容、後世についての放棄、神聖な権利の侵害と踏みにじる見立て、全文の対照・増幅・帰属は次に接続する。第九文の確認文字数はまだ加算しない。
