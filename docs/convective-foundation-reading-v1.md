# 第九節の担体解釈と条件付きの理論的基礎

対象はu0232第二文の意味依存群です。小さな剛体への電荷付着という仮定と、原系の方程式を理論の電磁的基礎として用いるという位置付けを、同じ設定について接続します。本文への著者帰属、先行する式・説明と見出しへの統合は残ります。

## 条件と方程式

既存ekylは物理的設定と方程式の成立をともに要求します。これを条件節に使うと、方程式の成立を仮定した場合だけを扱ってしまいます。新しいekyoは同じ電荷分布・担体・二場・密度・流速・単位を保持しつつ、方程式を含めません。局所の密度と領域電荷合成はekynで共有し、全担体への付着、全物質出来事の座標対応、非零密度の支持、全成員の速度を既存定義へ結びます。

ekyqは同じ32引数を持つ方程式の規則です。非空領域の全有効点で、同じ二場の偏微分族を存在量化し、semhの原系六式と電気側発散へ接続します。原系のframe=ra、長さta、時間rb、光速度tcと二場の換算1・1/Vはekymで指定します。磁気側発散零や後続の系間電荷不変を補いません。

一般関係eiswaは、同じ設定についての条件と法則を閉じた規則として受け、同じ理論がその法則を自らの基礎として採用する役割を表します。eisdiで同じ理論の依存先へ結びます。eisdiだけでは基礎の規約の修正も許すため、指定した方程式の採用先として理論をeiswaにも明示しています。引用内容の真理、実験確認、条件からの数学的導出、理論全体を導く十分性は、この役割関係から導きません。

## 二つの担体名と主題

IonenとElektronenは別の歴史的な名称として保持し、この箇所に必要な共通の古典的担体モデルekyrへ対応させます。ekyrは完全な物質部分への固定電荷と小さな剛体という既存ekx3に、少なくとも一つの部分の非零電荷を結びます。全体の正味電荷だけで判定せず、内部での正負相殺を許します。

この対応は二種類が同じ粒子種だという主張ではありません。本文が述べない内部構造・質量・特定電荷値・符号・点粒子性を加えず、全ての担体がこの二種類だけだとも要求しません。[Lorentzの1899年論文](https://en.wikisource.org/w/index.php?title=Page:Lorentz_Simplified1899.djvu/1&oldid=6718558)の荷電担体・物質要素への付着と、[1902年講演](https://www.nobelprize.org/prizes/physics/1902/lorentz/lecture/)の正負の電子への言及を補助資料としています。取得方法と限界は[記録](../data/historical-carrier-reading-v1.json)に保存しています。

Lorentz理論の研究対象は、既存eie6の運動を含む電気力学と、実際のNoema質問に結んだekwmの動く物体の光学を併記します。解決済み問題だけを選ばず、第八節の静止系への方法を研究対象の条件へ加えません。同じ理論・基礎研究・論述文脈を共有し、物理的設定のcontextと論述のreferenceを区別します。

## 検査と未完部分

局所検査は単位・換算・密度・速度・偏微分の引数接続、条件と法則の独立性、非空領域と二地点、八つの物理証人及び二つの偏微分証人の全束縛位置、二名称、条件・法則の引用順序、同じ理論と研究への結合を対照します。存在束縛は二値の小領域で各位置を検査し、全実数・全関数域を有限標本へ置き換えません。

全408主張、既存意味規約と旧証拠は保持します。条件の依存閉包にsemh・semf・ekxj・ekyf・ekylが含まれないことも検査します。有限検査の成功を原文同義性の判断に換算せず、u0227–u0232の本文への統合と通読後に単位全体を判断します。
