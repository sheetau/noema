# 同じ物体の静止系への両場の変換

u0226の三文で使う物理的な手続きの依存群を、ekvv–ekvz/ekv2–ekv6の10定義で構成する。既存406主張と意味判断は保存する。原文の全問題・本質的役割・著者提示はまだ接続していないため、今回は原文単位の完成件数を増やさない。

ekvvは同じ過程の同じ出来事の二系の記録を結び、ekvwは全所属出来事に両記録を要求する。ekvxはその全記録対に既存ekceの正逆の四座標変換を適用する。系をra/zbmに固定しない。ekvyでは旧領域内に出来事が存在し、全記録対で旧領域とs6mによる新逆像領域の所属が一致する。領域外の出来事も座標対応から取り除かない。

ekvzは両系の電場・磁場について、物理的な同定ejsnと同じ過程への帰属eispnを要求する。座標記録の測定規約に合わせ、長さ時間の単位はta/rbを共有する。電荷・電場・磁場・力の単位も共有し、電気側の係数1、磁気側の係数1/Vを明示する。数値変換ができることと、その関数が同じ過程の物理的な場であることを分ける。

ekv2は同じ物体の全物質点を両系で追跡し、旧系ではeiagの運動、新系ではeiahの全区間静止を要求する。三標識点や重心の静止へ置き換えない。両区間はそれぞれの座標時刻で指定し、正の長さを要求する。ekv3は対象領域内の全過程出来事の旧新時刻を対応する履歴区間へ結び、別の期間の静止で代用することを防ぐ。

一般関係eisviは、同じ物体の物理的作用が同じ領域で同じ過程の状態又は伝播へ因果的に寄与するという入力である。反射・完全鏡・唯一原因へ限定しない。単なる数値の変換、同時生起又は空間的一致から因果を導かない。光としての帰属は別に結ぶ。

ekv4は以上を一つの設定へ結び、ekv5はその固定設定の下で新系の電場・磁場という実際の二関数を問うNoema質問を作る。ekv6はs6k/s6lで旧両場を同じ速度で混合し、同じ逆座標写像を合成した二関数を、その質問に照合する。場候補ごとに物体・過程・系・単位・期間を選び直さず、片方の場や答え名だけで代用しない。

この構成には平面波や正弦波の条件がない。局所検査では一般のアフィンな三成分場を用い、正負の速度、全六成分、混合の符号、四座標の逆変換を確認する。その他の検査は、同じ出来事・全記録対・局所領域・両履歴区間・物理単位・同じ物体と作用の引数接続を扱う。実数全域の履歴の有限評価拒否を保持し、境界の診断を物理法則の証明としない。

適用する変換は軸を相対速度に合わせた一様なLorentz変換である。任意の動体が一つの慣性系で静止するとはこの定義から言えない。加速・回転・変形を黙って原文の全問題範囲から除外せず、後続では適用条件と著者による一般化の主張を分けて記述する。物体の構成が固定された区間という既存履歴の限界も保存する。
