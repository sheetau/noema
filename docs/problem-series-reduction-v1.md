# 問題列への還元と方法による解決可能性

u0226の三文には、元の問題を別種の問題の列へ還元し、その全ての答えから元の答えを構成する接続が必要である。今回の15定義ekvg–ekvuはこの依存群を構成する。新しい原始関係や本文主張は追加せず、先行406主張と意味判断を保存する。光学の三文全体の意味判断はまだ行わない。

問題は個体の参照、質問はNoemaのg[a]、答えは個体の解答記録として扱う。questionsが各問題へ実際の質問を与え、answer_matchesで答えを確認する。光学への接続では記録内の量・場・単位・設定と質問の本体を明示する。自然言語の答え文字列や、実数・関数の暗黙の個体化で代用しない。

ekvgは有限列をfoldして0始まりの位置列を作る。ekvhは非空列の全項の分類、ekviは同じ長さの問題列と答え列の全位置の対応を要求する。順序と反復を残し、列長を二項に固定しない。一般形では単項列も認める。原文のReiheを光学へ接続するときには、その読みを別に確定する。

ekvjは全答え列に同じ再構成写像を適用し、元の質問との合致を調べる。ekvkは全有限答え列について「還元先の完全な正解なら再構成も元の正解」という条件を要求する。還元先に答えがなければ、この条件だけは空虚に成立し得る。ekvlは完全な答え列の存在を別に要求し、ekvmで同じ還元設定へ結ぶ。ekvnは元の答えの存在である。

ekvoは還元先の全項の種類を固定する。ekvpは同じ方法・元問題・問題列・再構成写像・状況で認められた手続き案に接続し、ekvqはその問題列と写像の存在、ekvrは非空の全問題範囲での還元を表す。ekvsは同じ問題列の解答存在を加え、ekvtは全問題範囲にそれを要求する。解を得る手続きを認めることと、既に実行したことを混同しない。手続き案の入力だけで方法の実効性を証明したことにもならない。光学への接続では具体的な変換と再構成の根拠を必要とする。

ekvuはekvmからekvnへの論理的帰結である。ekvlの証人である答え列をekvkの全称条件へ代入すれば、同じmapperの値が元の質問を満たす。これがekvnの証人になる。この推論は光学の全問題が解けるという著者の主張を証明するものではない。

局所検査は、空列・任意の有限長・反復・各位置の誤答・順序交換・長さ違いを実際の列演算と質問で評価する。還元の全称条件は一つの答え列に対する本体を別に評価し、全有限列の量化自体は有限評価器が拒否することを確認する。存在証人の結合は二個体域の診断で列・関数の型を明示的に置き換え、全ての共有位置と異なる証人の取り違えを調べる。この診断を無限の列・関数域の意味論としない。元の定義では型と量化を保持する。未知入力は拒否する。

未接続なのは、光学問題と実際の質問の対応、同じ動く物体に影響された光の両場を同一出来事で同じ相対静止系へ変換する手続き、その本質的役割、先行方法への参照、三文の著者提示である。鏡・平面波の成功例へ全問題範囲を縮めず、既存の一般場変換と物体の全点の静止条件から接続する。
