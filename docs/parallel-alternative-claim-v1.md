# 同じ点の速度式へ至る別導出

u0147第一文の `hätten ... auch ... erhalten können` を、先の段階で別の方法も利用できたという振り返りとして読む。実行済みや不採用は補わない。以前の方法は、現在の取得ejpbから角度付きの式ejpcを経て同方向の条件付き内容ejprへ至る。別の方法も同じejprを結論とし、§3の最終変換を二回使う。

二変換の結果が同じ点の速さの式に対応する読みを、補助設定として明示した。第三系の原点を同じ点の現在世界線へ合わせ、第三系のkに対する速度zltを、その場合の点のk速度zkqへ一致させる。第一系又は第二系の全現在出来事を対象にし、非空性・第三系記録の存在・全候補記録の三位置零を要求する。第三系の時刻まで零にすることはない。

第三系原点の三位置が零なら、合成四式はKにおける原点軌道x=Ut,y=z=0へつながる。この単一記録上の代数関係と、同じ点の全K履歴・実際の座標微分の非負ノルムへの接続を分けた。方法の途中内容には後者を含め、速度の記号を同じUと呼ぶだけで物理的な取得を済ませない。

ここには適用範囲の差がある。二つの物理的な座標変換は系速度の光速未満条件を持つが、前段の点の速さにはその上限を加えていない。補助設定はより狭い場合であり、その存在を一般の場合へ主張しない。元のejpp/ejprも狭めない。著者が同じ式を得られたと述べる方法の終点は同じejprへ保つが、そこへ進む許容規則zlaや導出の一般的妥当性を、この記述から証明済みとはしない。

別方法の同じ非空有限列に、補助設定、二回適用、合成四式、点の履歴・速さへの条件付き接続、同じ結論という各一手を要求する。別の方法の途中式、違う段階の規則、同じ真偽を持つ別内容の引用では代用しない。この手順構造は明示した解釈であり、原文の逐語的な証明列や実行ログではない。

現行文148をこの振り返りと§3参照の提示へ更新した。u0147後半の第三系の命名・本文統合と、u0149の群・必要性は残るため、この段階で全単位の判断数を増やさない。
