# 正負定義の順位学習の結果

同じ文中の対象について、正しい定義を誤った定義より高く評価する損失を追加した。候補の偏りは変わったが、Noemaへの転用は依然として失敗した。内部開発で選ばれた線形・順位追加方式の概念正解は、日本語12/179、英語7/179だった。未知の入力にも全件で既知候補を肯定したため、翻訳器へ採用しない。

## 区分と比較条件

[事前条件](contrastive-verifier-v1-protocol.md)に従い、[前回取り込んだWiC-TSV](wic-verifier-v1-results.md)の公式Training 2,828例を再区分した。同じ見出し語または原文を共有する行を861個の連結成分へまとめ、見出し語一覧のハッシュで学習・内部開発へ割り振った。正解ラベルやモデルの結果で割り振りを調整していない。

| 項目 | 学習 | 内部開発 |
| --- | ---: | ---: |
| 行 | 2,203 | 625 |
| 原文 | 1,687 | 447 |
| 見出し語 | 691 | 173 |
| 正例 | 1,118 | 296 |
| 同じ対象に正負があるグループ | 351 | 95 |
| 注釈済みの正負対 | 436 | 145 |

全行をいずれかの区分へ含め、区分間の原文・見出し語の重複を避けた。定義そのものの不交差までは条件にしていない。[行とグループの記録](../reports/contrastive-verifier-v1/data-selection.json)を保存した。

固定MiniLMが前回計算した特徴を、入力・抽出コード・特徴ファイルのハッシュ検査後に再利用した。今回の新規エンコーダー呼出しは0回である。学習対象は1,537パラメーターの線形ヘッド、または98,433パラメーターのMLPで、概念別の出力層は持たない。

各構造について、二値損失だけの対照と順位損失を加えた条件を比較した。同じ構造の初期値・バッチ順を揃え、グループごとの寄与を均等化した。順位の教師には原資料で正負が明示された対だけを使った。Noemaの学習例、未注釈候補を負例とする変換、推論時の辞書検索は追加していない。

## 内部開発による選択

順位正解率は、各グループ内の正負対の正解率を求め、95グループで平均した値である。完全な同点は0.5点とする。最終選択したepochでは、どの条件にも同点はなかった。二値均衡正解率は正例再現率と負例再現率の平均であり、順位とは別の指標である。

| 方式 | epoch | 内部開発の順位正解率 | 内部開発の二値均衡正解率 | 公式開発の二値均衡正解率 |
| --- | ---: | ---: | ---: | ---: |
| 線形・二値のみ | 17 | 69.807% | 64.85% | 54.80% |
| 線形・順位追加 | 17 | 69.842% | 63.37% | 56.65% |
| MLP・二値のみ | 3 | 69.421% | 63.32% | 55.33% |
| MLP・順位追加 | 3 | 68.807% | 64.38% | 57.09% |

事前に決めた順位指標で線形・順位追加が選ばれた。ただし対照との差は約0.035ポイントであり、改善の確証とは扱わない。全ての正例が全ての負例より高かったグループ数は、線形対照の62/95から61/95へ減った。MLPでは順位追加により平均順位正解率も下がった。

公式Development 389例は今回の選択には使わなかったが、前回観察済みであり、独立した最終評価ではない。前回は学習区分と選択指標も異なるため、前回との差を順位損失だけの効果とは解釈しない。[選択記録](../reports/contrastive-verifier-v1/selection.json)、[公式開発の診断](../reports/contrastive-verifier-v1/official-dev.json)、同じディレクトリの4条件の学習履歴に根拠を保存した。

## Noemaの既存資料への転用

全方式の選択を終えた後、観察済みv1〜v6の442範囲を91候補で照合した。既知概念は各言語179範囲、未知は各言語42範囲である。対象範囲を正解として与えており、全文の意味構造一致率ではない。

| 方式 | 日本語の概念正解 | 英語の概念正解 | 未知で肯定候補あり：日本語／英語 |
| --- | ---: | ---: | ---: |
| 線形・二値のみ | 5/179 | 6/179 | 42/42・42/42 |
| 線形・順位追加 | 12/179 | 7/179 | 42/42・42/42 |
| MLP・二値のみ | 5/179 | 6/179 | 42/42・41/42 |
| MLP・順位追加 | 16/179 | 7/179 | 42/42・42/42 |

線形対照では442範囲中337範囲で同じ候補`di`が先頭だった。順位追加では最多の候補が`ac`の126範囲へ変わったが、`fr`も105範囲で先頭となった。単一候補への集中が減っても、正しい概念の選択や未知概念の拒否には結び付いていない。logit 0の閾値はNoema向けに校正されておらず、これを翻訳の確信度として使えない。[v1](../reports/contrastive-verifier-v1/v1-evaluation.json)〜[v6](../reports/contrastive-verifier-v1/v6-evaluation.json)に全条件の内訳を保存した。

今回は英語名詞中心の351グループから学習した一条件群である。この結果だけで非生成型全体の可否を決めることはできない。一方、二値損失へ順位項を加えるだけで転用失敗が解消する、という見込みはこの実験では支持されなかった。全文の確定出力は0件で、意味構造一致率95%と広い自然文への対応は未達のままである。

## 検証と再現

全436テストが通過した。区分の原文・見出し語の不交差、全行の包含、行順への非依存、グループ間の均等な損失、未注釈の比較を作らないこと、順位同点の扱いを検査した。4条件を保存済み特徴から再学習し、区分・選択・全履歴・重み・各442範囲の予測と集計が完全一致した。[再現検査](../reports/contrastive-verifier-v1/verification.json)

学習環境はPython 3.12.10・PyTorch 2.13.0 CPU、float32、8スレッド、seed 17。元の特徴抽出の環境・固定モデル版は前回記録を参照する。今回の一致は固定特徴からの再学習と推論についての結果であり、基盤モデルの特徴を再抽出した検査ではない。[実行記録](../reports/contrastive-verifier-v1/run.json)には依存コードと入力・出力のハッシュを保存した。

```powershell
artifacts/kwja-venv/Scripts/python.exe -m scripts.probe_contrastive_verifier
artifacts/kwja-venv/Scripts/python.exe -m scripts.probe_contrastive_verifier --verify-only
```

前回の注釈と特徴ファイルが必要である。初回実行と再現検査はそれぞれ新規出力を作り、既存成果物は上書きしない。
