# 公的な理性使用を許す方針と、不利益の可能性

未記述だったカントu0016のうち、「臣民に自分の理性を公的に使うことを許しても危険はない」という部分へ草案を追加した。許可対象の行為、許可を与える方針、その方針を採った場合の想定結果を区別する。同じ方針が成立する非空の結果範囲で、不利益がないという部分的な読みである。

[新しい本文](../examples/v016/kant-public-permission-risk.noema)では、既存の1,370宣言と16文を保持し、この部分内容の帰属を一文追加した。著者への帰属と、引用した内容が実際に真であることは別である。

## 同じ行為を許可の対象にする

許可対象には、本人が所有する理解力を使い、公的な立場で同じ内容を提示する行為の記述を構成する。理解力を使う行為と提示行為を同じものに固定し、別の行為で自分の能力を使ったことを流用しない。

役割、受け手、対象、発話内容、伝達経路、自己への発話帰属は、本人・活動・基準文脈ごとに指定できる。これらから作る行為記述と、許可の対象記述を一致させる。役割も同じ指定から取り出す。公的提示には既存の `hzb4` を用い、許可には既存の `rdm` を用いる。

方針は、基準文脈で選んだ各対象者・各活動に、この同じ記述への積極的な許可があり、反対要求がないという内容である。対象者や活動を結果時点で選び直し、許可が得られた者だけ残すことはしない。ここでは実行の許可を扱い、不実行の許可、能力、実効的な無妨害などを含む自由全体を定義したとはしない。

## 危険の評価と実行を分ける

方針の記述、評価文脈、想定結果を一つの関係へ結ぶ。発言した場合の結果と、発言を許可する方針を採った場合の結果を同一視しない。評価する結果が非空で、各結果で同じ方針の許可が実際に成立することを確認してから、その結果に不利益がないかを調べる。

許可が成立することは、許可対象の発言が実際に行われることを要求しない。また、方針を採った場合の危険を評価するために、現在すでにその方針が採られていることも要求しない。内容が同じ真偽を持つ別の行為記述への許可を、この対象への許可に移すこともない。

| 定義 | 内容 |
| --- | --- |
| `rrh`、`rri` | 同じ本人・活動での自分の理解力の使用と公的提示を、閉じた行為記述にする。 |
| `rrj`、`rrk` | 対象者・活動・提示項目を固定し、同じ対象への許可を与える方針の内容と記述を作る。 |
| `rrl` | 選んだ想定結果が非空で、その全てで同じ方針が成立する。 |
| `rrm` | `rrl` を満たし、その同じ結果の全てで不利益がない。 |
| `rrn` | `rrl` を満たし、その同じ結果のいずれかで不利益がある。 |
| `hzmpolicy`、`hzmsafety` | 本文の参照先と項目指定を、方針とその危険評価へ結ぶ。 |
| `hzmriskreport` | この部分内容を、著者・本文箇所・範囲・文脈へ帰属する。 |

空の結果範囲や、方針が成立しない結果を混ぜた範囲では、`rrm` と `rrn` はどちらも偽になる。そのため「安全だという条件が成立しない」を、そのまま「危険な結果がある」とは扱わない。結果範囲や不利益の解釈が未知なら、空集合や不利益なしで補わず検査を拒否する。

## 原文との対応と残る意味

保存済み原文のu0016の範囲 `[539, 649]`、110文字（非空白95文字）を部分注記として対応させた。原文中の「立法に関しても」という限定、「見抜く」という認識、よりよい法文案、率直な批判、比較・強調、後続の実例は、この範囲の完成に含めていない。

理性使用には、既存の公的使用と自分の理解力の使用の構成を再利用した。`Verstand` と `Vernunft` の語義上の区別をこれで尽くしたわけではない。臣民と統治者の制度的な関係、公的役割・公衆の意味、各対象範囲の網羅性も未完である。

危険を、指定した可能結果での不利益の有無として扱う。誰のどの不利益か、想定結果が適切か、確率的な危険をどう測るか、政策と結果の因果をどう同定するかは別に必要となる。原文にない被害者、確率、金額、閾値を補ってはいない。段落全体との意味一致や、現実の政策の安全性を証明した結果ではない。
