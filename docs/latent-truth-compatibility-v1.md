# 隠れた真理の可能性と内面の宗教との無抵触

カント第五段落`u0012[3899,4278)`の理由節に向けた依存群である。同じ規定群・内容・基準を固定し、隠れた真理の可能性と、内面の宗教に反する部分がないことを構成する。本文91主張と確認済み文字数は増やさない。

`verborgen läge`は、含まれる命題部分の真理が本人には明らかになっていない、という認識上の読みを採る。[Adelungのverbergen項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_5_0_87)の知識から隠れる語義を参照した。物理的な遮蔽、意図的な隠蔽者、本人が賛同していないだけの場合を補わない。所属`r42k`、閉じた内容`h246e`の真理、まだ明らかでないこと`h252k`を別々に結ぶ。

`nicht ganz unmöglich`は、利用できる根拠から排除されていない同じ非空の検討範囲`h252l`で、隠れた真理を全排除できないと読む。範囲は真理・抵触の結果を見て選ばず、同じ固定内容を評価する。二値の読みでは存在可能性と一致するが、数値確率、未知入力の補完、現実での真理とはしない。

内面の宗教は、内的な信仰・良心に即した道徳的態度と義務の承認に関わる基準として読む。関係`h252m`はこの位置付けを表し、具体的な原則は`h246e`の閉じたNoema内容で与える。[AdelungのReligion項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_6_1_1173)、[1776年書簡AA X 192](https://korpora.org/Kant/aa10/192.html)、[後年の宗教論AA VI 105](https://www.korpora.org/Kant/aa06/105.html)を比較資料とした。教会の外的な制度への適合だけとは区別するが、1793年の精密な教説全体を1784年に遡及した定義や、唯一の作者意図を主張するものではない。

抵触`h252n`は、第一の内容を是とすることが、第二の内容の原則・要求に反し、その実践的な基準の下で両方を認められないという関係である。有限の例に共同充足が見つからないだけの場合を抵触とはしない。部分ごとの無抵触から規定群全体の共同充足可能性も導かない。`angetroffen wird`はここでは抵触するものが内容中に含まれないという状態として読み、実際に探索を完了した行為を要求しない。後続文の「抵触を見出したと信じたなら」は別途、非事実的な判断として扱う。

局所検査では、二候補の選択・真理・隠れ方の64組合せ、空範囲、別の部分や別の時点の流用、全場合のうち一つだけ抵触する場合を調べる。部分の内容は実際のNoema式で与え、第一規定を二部分の連言として、全体が偽でも一部分に真理がありうることを評価する。宗教基準の診断例は、状況条件が成立するとき当該部分を否定する閉じた内容である。抵触関係はその条件に合わせた解釈入力として与える。これは有限例の接続検査であり、任意の教義の無矛盾性を自動証明する仕組みではない。未知の関係は拒否し、引用を構成するだけでは内容を実行しないことも確認する。

残るのは、引受け可能性への理由関係、`aber/wenigstens/doch`の対照と焦点、本人の仮定的な賛同を問う状況、会衆への全実益と`alsdann`、文全体の著者帰属である。真理の可能性と無抵触の連言だけで良心上の許容を成立させない。資料は`data/latent-truth-compatibility-evidence-v1.json`、結果は`reports/latent-truth-compatibility-v1.json`に保存する。
