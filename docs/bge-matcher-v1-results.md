# 固定BGE-M3への交換による概念照合の結果

固定エンコーダーをBGE-M3へ交換し、既存資料で共通の3係数だけを学習した。新しい日英24組では、日本語14/24・英語13/24で、既存MiniLM方式の16/24・17/24を下回った。予測した句範囲を使う既存32文でも改善はなかった。この構成は主画面の翻訳器にも、研究用の既定モデルにも採用しない。

## 入力と学習の範囲

[事前条件](bge-matcher-v1-protocol.md)をモデルの予測前に固定した。BGE-M3の公開リビジョンを固定し、原文・対象範囲だけの文字列・Noemaの定義をそのまま入力した。指示文の付加、生成、単語辞書による検索、基盤モデルの追加学習は行っていない。[公開モデル](https://huggingface.co/BAAI/bge-m3)は指示文を要しない埋め込みモデルであり、今回使う文表現は公開設定に従うCLSとした。

実測の基盤モデルは567,754,752パラメーター、重みファイルは約2.27GBで、従来のMiniLMより大きい。文脈内の対象はトークン平均、対象だけと全文はCLSを使い、それぞれと定義とのコサインを3個の共有係数で足す。概念の追加に伴う分類層や、語別の学習パラメーターはない。一方、文全体の検索用に学習した表現が対象範囲の意味照合にも適するかは未確立であり、この実験で検査した。

学習資料は従来と同じ3,072範囲、開発資料は288範囲である。学習に含めない3概念でepochを選び、開発平均が最高の19 epoch目を採用した。係数は文脈1.5713・対象だけ0.7259・全文0.2018。開発正解率は日本語93.06%・英語100%だったが、開発時の候補は15概念、確認時は91概念であり、この成績を広い語彙への精度と解釈しない。

## 新しい日英資料での比較

[新資料v4](../data/definition-probe-v4.json)は既知24概念と未知6概念の日英対である。購入・売却、聴覚と発話、開閉の動作と状態、物体とその性質などを含む。過去の確認資料や学習・開発資料と文の完全一致がないことを検査した。ただし、概念の多くは観察済みで、同じ作成者の小規模な確認資料である。正解の対象範囲を与えるため、自然文全体の翻訳精度ではない。

| 方式 | 日本語 | 英語 | 日英とも正解 |
| --- | ---: | ---: | ---: |
| 既存MiniLM・学習済み3係数 | 16/24 | 17/24 | 16/24 |
| BGE・学習済み3係数 | 14/24 | 13/24 | 13/24 |
| BGE・文脈範囲平均のみ | 13/24 | 13/24 | 12/24 |
| BGE・対象だけのCLS | 15/24 | 17/24 | 14/24 |
| BGE・全文CLS | 7/24 | 7/24 | 6/24 |

BGEの3係数方式では、既存方式が正解した「購入した」「聞こえた」「書いた」「学校」なども誤った。文中で関連する物体への偏りは残り、「書いた」はペン、「学校」は教師を選んだ。対象だけのCLSが3係数方式を上回る結果もあるが、確認資料で方式を選び直してはいない。今回の学習資料と選択条件では、BGEの文脈特徴を利用した改善は確認できなかった。

未知6概念の日英12範囲では、両モデルとも全て既知候補を返した。BGEでは「翻訳した」を読む出来事に、比喩的な英語の「blue」を青色へ対応させた。全文の確定出力は行っていないため誤確定は0件だが、未知判定そのものは未実装である。各スコアの分布と日英の一致は[全方式の集計](../reports/bge-matcher-v1/v4-evaluation.json)に記録した。

## 観察済み資料の回帰

従来の定義照合資料でもBGEの3係数方式を比較した。次の値はいずれも正解範囲を与え、91候補から選んだ結果である。

| 資料 | MiniLM：日本語／英語 | BGE：日本語／英語 |
| --- | ---: | ---: |
| v1・40組 | 31/40・34/40 | 32/40・30/40 |
| v2・26組 | 13/26・18/26 | 13/26・15/26 |
| v3・50組 | 33/50・35/50 | 29/50・31/50 |

さらに、[前回の同時選択](joint-lexical-v2-results.md)で保存した出来事・句範囲・役割logitを固定し、概念照合だけをBGEへ交換した。この32文は既に観察済みであり、今回の新しい確認には数えない。正解範囲は与えず、保存された予測範囲を使った。

| 指標 | 以前の18文：MiniLM→BGE | 以前の14文：MiniLM→BGE |
| --- | ---: | ---: |
| 述語概念の一致 | 18→16 / 19件 | 8→8 / 15件 |
| 役割・範囲・概念の一致 | 34→34 / 40項 | 31→31 / 36項 |
| 全フレーム一致 | 12→11 / 18文 | 6→6 / 14文 |
| 余分な役割・範囲・概念の組 | 3→5 | 3→3 |

書く出来事の受動文が一つ悪化し、全フレーム一致で改善した文はなかった。これらは否定・数量・時間・節関係を含まない部分評価であり、[全文の完成条件](open-problems.md)は未達のままである。

## 検証と再実行

全411テストが通過した。モデルの重み固定・eval、同一入力の反復一致、取得したトークンとCLSが直接forwardと一致することを検査した。固定特徴から3係数の学習を再実行し、選択epoch、全履歴、重みが完全一致した。保存特徴からv1〜v4の340範囲のBGE各方式を再計算し、32文の同時選択も再現した。32文の評価集計も別途再計算して一致を確認した。生成等の禁止経路5種の呼出しは全て0回だった。

実行環境はPython 3.12.10・PyTorch 2.13.0 CPU・Transformers 4.57.6、float32・eager・8スレッドである。今回の入力長は128トークンを上限にし、切断入力を拒否する。BGEの最大長8192での解析を検証した結果ではない。[実行記録](../reports/bge-matcher-v1/run.json)、[学習履歴](../reports/bge-matcher-v1/training.json)、[再現検査](../reports/bge-matcher-v1/verification.json)を保存した。特徴、重み、生スコアはGit管理外の`artifacts/bge-matcher-v1`にある。

```powershell
artifacts/kwja-venv/Scripts/python.exe -m scripts.probe_bge_matcher
artifacts/kwja-venv/Scripts/python.exe -m scripts.probe_bge_matcher --verify-only
```

公開モデルの固定リビジョンを標準キャッシュへ取得済みであることが必要で、実行中の外部通信は行わない。初回の結果は上書きしない。

今回の結果から、モデル規模を増やすだけで対象語と関連概念の混同が解消するとは判断できない。現在の3係数と12概念の学習では、対象範囲と定義の意味の一致を十分に学べていない。次の対象は、語彙によらない共通判定を維持しつつ、関連する物体・述語・状態を区別する学習と、開発時の概念・候補数の不足である。v4をその調整後の独立した確認資料として再利用しない。
