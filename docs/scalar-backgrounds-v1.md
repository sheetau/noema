# 主張と、強調を支える背景を分ける

「批判を伴う提示も許される」という主張と、それを「さえ」と強調する背景は区別する必要がある。今回は、主張内容と背景内容の閉じた記述を別々に保持する組を、既存のNoemaの関数と引用だけで構成した。19定義を追加し、文法演算子やライブラリの原始関係は増やしていない。

強調の尺度を一律に確率へ固定していない。英語の *even* については、起こりにくさを満たしても適切に使えない反例が報告されている。[Greenberg（2016）](https://semprag.org/index.php/sp/article/view/sp.9.2)を、尺度を確率だけに限定しないための注意として参照した。その理論全体の実装や、ドイツ語の `sogar` の全用法の説明ではない。

## 主張を否定しても背景を取り消さない操作

`rst` は、主張内容と背景内容の記述を二つの位置に保持する。組は二つの値を受け取る選択関数へ値を渡す通常のNoema関数であり、文字列や外部データを意味の代用にしない。`rsu` と `rsv` がそれぞれの記述を取り出す。

`rsw` は主張内容だけを否定し、背景の記述は同じまま保持する。背景の不成立から主張を偽と判断したり、主張の否定から背景まで否定したりしない。`rsx` と `rsy` で各内容を別々に評価できる。

`rsz` は主張内容についての肯否の質問を、発話の記述として構成する。構成時には主張内容を実行しない。元の組は背景を保持するが、取り出した質問の発話型そのものに背景が自動で付くわけではない。一般の複合文における前提の投射、背景の受容や修復、背景自体への異議申し立てを完成させた機構ではない。

## 比較対象と尺度を明示する

`rta` は、明示した内容記述の列上で、同じ視点・同じ基準文脈の比較関係が非反射的・推移的であることを検査する。比較対象同士が全て順位付けできる全順序までは要求しない。

`rtb` では、焦点の内容記述を比較対象列から分けて渡す。比較対象列は非空で、焦点自身を含まない。焦点を加えた範囲で比較関係が整合し、焦点が全比較対象より指定尺度で上位にあることを要求する。尺度の「上位」が、より意外なこと、より注目すべきことなどのどれを表すかは、別に意味規約を与える必要がある。

`rtc` は、比較対象の少なくとも一つが評価状況で成立するという追加条件である。焦点の内容の真偽は検査しない。尺度条件だけを背景にする `rtg` と、この追加条件も持つ `rth` を分けた。全言語・全用法の強調へ、同じ追加条件を一律に要求してはいない。尺度は指定した基準文脈に固定し、追加条件の真偽は内容を評価する状況で調べる。

| 背景の状態 | 主張の状態 | 今回の表現 |
| --- | --- | --- |
| 成立 | 真 | 背景を満たし、主張も真。 |
| 成立 | 偽 | 背景を満たすが、主張は偽。 |
| 不成立 | 真 | 主張は真だが、指定した強調の背景を満たさない。 |
| 不成立 | 偽 | 背景と主張がそれぞれ不成立。 |

未知の解釈は、上の真偽のいずれかへ補わず拒否する。尺度だけの背景は比較対象の内容を実行しないため、その真偽が未知でも尺度を調べられる。追加条件を持つ背景では、比較対象の真偽を評価する。

## 許可対象だけを変える比較枠

本文へ接続する際、許可の出所・本人・役割・行為まで比較対象ごとに変えると、焦点以外の条件が混ざる。`rti` と `rtj` は同じ閉じた枠へ焦点の行為記述と比較対象の行為記述を適用する。`rtk` が比較内容の列の記述を作り、`rtl` がそれらを主張と背景の組へ結ぶ。

[許可の作例](../examples/v016/scalar-permissions-example.noema)では既存の `rdm` を使う。出所・本人・役割・行為と規範関係を同じ枠に固定し、通常の提示と、批判を伴う提示の行為記述だけを変える。背景は通常の提示への許可と指定尺度を調べ、主張は複合した提示への許可を調べる。どちらの許可も、記述された行為の実行を要求しない。

枠が行為記述の引数を無視する場合や、意味的に無関係な比較対象を選んだ場合まで、適切な強調と認定するものではない。記述は構文で識別するため、同じ内容を表す別名を自動で統合しない。比較対象の選定根拠と尺度の妥当性は、構文の一致とは別の課題である。
