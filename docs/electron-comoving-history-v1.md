# 同じ電子の二系の履歴と瞬間静止

u0245の第二文へ接続するため、同じ電子・出来事・長さ時間単位を保った共動系の履歴を構成する。既存のek5i/jの原点ずれを持つ正逆写像、eiojの全配置・全時点の等速並進、ejsl/eisqtの座標規約、seob/seocの完全な履歴と実際の座標時間微分を再利用する。新しい原始関係は不要である。

必要な対応は二方向に要求する。旧領域の各時刻に対して、変換した四座標は新領域の同じ出来事の曲線上にあり、逆写像でも元へ戻る。新領域の各時刻からも同じ条件を要求し、片側だけの対応で余分な軌道や欠けた時刻を許さない。両履歴の全座標出来事を同じ単位へ結ぶ。これらは選択した局所領域についての完全性であり、電子の全生涯を追加で要求しない。

旧系の瞬間速度はseocの三微分として与える。新系の三速度も同じseocで、その系の座標時刻による微分として記述する。変換された数値速度に名札を付けるだけでは済ませない。条件付きの帰結は、旧系の物理的履歴と実際の速度、両系の完全な対応、正の時刻変化率から、新系の実際の三微分が変換値に一致するという内容にする。有限検査はその全実数の連鎖律を証明したことにはしない。

現在の電子の設定ek4pから、指定出来事の四座標を零、同じ時点の速度を(v,0,0)とした場合を接続する。並進系の速度も同じvであり、原点ずれは任意に残す。結論は同じ電子の同じ出来事における新系の三速度零である。非零の横加速度を持つ軌道も扱い、前後の静止、加速度零、無放射を追加しない。
