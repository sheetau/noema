# 良心に従った職務遂行の不能と辞職への要求

原文 `kant-1784:u0012[4279,4407)` の前提と帰結を結ぶ依存群である。本人が規定群内に抵触を見いだすと信じる前提は、[perceived-doctrinal-conflict](perceived-doctrinal-conflict-v1.md) から保持する。ここでは同じ本人と職務について、良心に従って務めることの不能と、その職を手放す要求を構成し、この前提へ接続する。先行本文の同じ規定群への照応、談話・著者帰属との全文統合は残る。

`r43s` は、その場面での職務保持 `cf`、職務の立場での活動 `cb`、本人による実行 `cg`、固定した担当業務を務める活動分類 `h2522` を結ぶ。`r43t` は同じ活動の良心上の許容 `h252j` を加える。地位を持つだけの状態や、別の活動が許容されることでは満たさない。職務を務めることを全生涯の業務の完全な終了には強めない。

`r43v` は当該事情を保つ実践候補のどれかで、良心に適う遂行が可能であることを述べる。`r43w` は同じ候補範囲を非空とし、全候補でそのような遂行を排除する。空の候補範囲や未知の評価を不能とはしない。

既存の `rg5/xg` は、評価した全結果で成功を保証する方法がないことを表す。この条件だけでは、失敗する可能性とともに成功する可能性が残り得る。今回の不能にはそれでは足りないため、可能な良心的遂行を全て排除する構成にした。検査には、一つの方法の二結果が成功・失敗に分かれる場合を含め、旧構成では保証不能でも新構成では遂行可能となることを確認する。旧定義は変更しない。

`r43x` は既存の `hzby/rhd/rhc/rcf` を再利用する。本人の同じ履歴内で、職務保持が成立する点から将来の非保持へ、自分の同じ行為によって移る。新しい `h2524` は、その行為が本人の職を手放す選択に沿った保持の終結として働くことを示す。単なる勤務中断、他者だけによる解任、偶然の非在職は区別する。辞表の形式や受理手続など、原文にない制度は補わない。

`r43y` は同じ本人・職務の二個体列を束縛し、その退任を実現する活動の存在を内容の内側へ置く。`r43z` は段階1の閉じた `r43y` と同じ二個体列を、既存の要求関係 `h237z` に肯定極性で渡す。要求の出所 `h2525` は同じ本人・職務に適用する良心上の実践基準であり、教会の現実の命令権者や罪悪感へ置き換えない。要求は退任内容を実行せず、実際の退任とも独立である。

`r432` は不能と要求の連言である。不能から要求を自動導出する公理にはしない。`r433` が、同じ本人・職務・規定群・宗教基準・四呼称を用いる `r43r` の帰結としてこれを渡す。全仮定候補で信念・不能・要求を結び、不能の実践候補はそれぞれの仮定候補を開始点として選ぶ。現実の評価点の候補範囲をそのまま流用せず、現実の信念・要求・辞職を別に要求しない。

[Dudenのverwalten](https://www.duden.de/rechtschreibung/verwalten) は職を務める用法を、[niederlegen](https://www.duden.de/rechtschreibung/niederlegen) は役職の継続をやめる用法を掲載する。[AdelungのAmt](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_3_1_1839) も職務の義務範囲と役職を区別し、両表現を挙げる。これらは原文前後に基づく採用読解の補助資料であり、唯一の歴史解釈や現代法の判断とはしない。

検査では候補選択・遂行・良心上の許容の64組合せ、同じ活動と本人への結合、実際の将来の自己終結、規範内容の非実行、要求の極性・記述段階・列の順序を確認する。退任内容は直接実評価し、二個体列からの全目標も三個体・二時点のモデルで実評価する。列の順序・長さの検査だけは `r43x` を型付き境界にして、全履歴評価の無関係な組合せ反復を避ける。帰結全体の引用は、内側の段階1の要求内容を保持できる段階2で検査する。有限範囲の接続検査と原文との意味判断は別であり、この依存群だけで確認文字数は増やさない。
