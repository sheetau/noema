# 全体の複数性と部分集団への所属

カントの自己思考者に関する接続候補には、「任用された後見役の中に該当者が複数いる」という条件が入っていた。これは「該当者が全体で複数おり、その中に後見役も含まれる」という条件より強い。後見役が一人、後見役でない人が一人で、両者とも自己思考・自己離脱・伝播の条件を満たす場合、前者は偽、後者は真になる。

今回、後者を別の読解候補としてNoemaで記述した。旧候補の定義や引用は変更していない。どちらが原文の適切な読みであるか、`sogar` の比較背景をどう指定するかは、この数量の区別だけでは決まらない。原文との意味一致や全文の完成は認定しない。

`rqti` は同じ母集団・評価点・複合条件について、該当者が二人以上いることと、その該当者に部分集団の人が一人以上含まれることを結ぶ。部分集団の外にも該当者がいることは要求しない。二人とも後見役である場合も成立する。母集団の外にいる後見役や、自己思考などの条件を満たさない後見役を、別の存在証人として足すことはできない。

`hzos` は部分集団の条件に既存の任用・役割の定義を渡す。`hzot`・`hzou` は指定した将来機会と全将来機会を扱い、同じ点で人数と所属を評価する。`hzov` は人ごとの判断・自己離脱・伝播を結ぶ内容、`hzow` は33引数を充足した内容記述、`hzox` はその内容への著者帰属である。七つとも合成定義であり、新しい基本関係は加えていない。

全将来機会という条件は、与えた履歴の内部での条件である。`immer` の文脈上の機会範囲や自由の仮定への従属まで確定したことにはならない。比較の尺度や背景には既存の[主張と背景の構成](scalar-backgrounds-v1.md)があるが、今回の存在条件へ自動で付加していない。

検証では、三人について所属・部分集団・該当条件の全512組合せを調べる。任用の具体的な定義を実行して二つの読みを比較し、過去だけの任用、任用行為の欠落、無関係な後見役、将来点での欠落と人物交替を区別する。具体的な独立判断・自己離脱・性向の伝播も元の定義で評価する。この大きい全将来内容の検査には短絡診断を用い、通常評価の完了とは扱わない。小さい将来検査は通常評価と短絡診断の一致を確認する。

二つの閉じた内容は人数条件以外の33引数を共有するが、同義とは扱わない。世界の事実が未知でも、それぞれへの帰属を独立に指定できる。未知の任用・資格を偽で補わない。既存32文、全既存意味規約、七単位の確認を保持し、通常・短縮・固有文字の往復を検査する。
