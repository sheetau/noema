# 自己理解と書面による公的使用

学識者として論じる場合を述べる文の条件側に向け、本人の自己理解と書面による公的使用を同じ人へ結ぶ依存群を作成した。本文への帰属と一文全体の意味確認はまだ行っていない。

`r3p` は政治的共同体の成員性、`r3q` は国家を越えた世界市民社会の成員性を、本人・共同体・世界市民社会という同じ三引数から構成する。`r3r` は同じ本人が同じ判断で両内容を肯定し、自分を一人称として捉えることを要求する。判断対象が偶然本人と同一であるだけの第三者についての判断とは分ける。引用された成員性を真と認定する必要はない。

共同体全体への所属を、職務内の部分集団への所属と区別する。また、世界市民社会を、現在実在する世界政府や特定の国際機関へ置き換えない。ここでは個別の国家を越えて市民として位置付ける社会の構想という読みを明示した。具体的な国籍や全人類の現実の自覚は含めない。

`r3s` は既存の公的使用 `r2zi` に、同じ活動の宛先が読者世界全体であることと、同じ書かれた作品を介することを加える。作品・記録・外部媒体・参照可能性には既存 `sc` と `sd` の構成を使う。別の作品が流通しているだけ、活動で単に作品名を挙げるだけでは足りない。実際の発信や全読者の読了・理解は要求しない。

記録の存在と参照可能性は、分類を評価する状況の条件である。今後これを仮定の前件へ置く際に、現実の刊行済み作品の存在を別の主張として足さない。媒体をどこまで活動候補の側で扱うかも、文全体の作用域とともに確認する。

`r3t` は先行する職務内の同じ人・事務・役割 `r3m` に、この自己理解と学識者としての公的使用を束縛する。職務と学識者の立場は別の引数で追跡するが、公的・私的使用を論理的に排他的な二分類にはしない。

残るのは、`So fern` の条件化、`mithin` による説明、`ja sogar` の段階的な強調、`aber` と `allerdings` の留保、機械の部分という照応、`zum Theile`、同じ職務を損なわず論じうるという後半との接続である。有限検査を原文との同義性の証明とはしない。
