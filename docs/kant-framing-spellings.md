# 比喩・仮定例の綴りと接続点の復元

比喩・仮定例に関係する既存の6語を、三〜四部品の綴りへ整理した。[綴りと語義](../data/kant-framing-spellings-v1.json)は複合語全体の公開規約であり、根語の単独語義による論理的な合成ではない。前段の21語に加え、明示した短い綴りは27語となる。

| 語 | 区別して保持する意味 |
| --- | --- |
| qa | 対象の性質記述を別の記述で非字義的に提示する関係 |
| qh | qaに加えて、対象と描写の記述が異なるという既存の定義 |
| s4 | 人物を引数とする記述を仮定的一人称例として提示する関係 |
| s3 | 三つの代替供給例を含む一人称条件文の文章箇所 |
| h3a | 足枷除去を仮定した不確かな跳躍の条件文の箇所 |
| h3s | 同じ条件文に、不慣れという理由節まで接続した箇所 |

描写を現実の出来事として断言せず、例の話者を著者自身へ固定しない。h3aとh3sの参照範囲も同一化しない。[前段の照合](kant-discourse-spellings.md)と同じく、既存の意味説明・型・宣言全体を照合し、qhの定義本体と依存先qaも変更していない。

## 接続点の丸め誤差

主張9の新しい配置では、一つの折れ点 `(1009.057430250, 32)` が、端点と交点の計算で別々の七桁丸め値になった。その結果、長さ約 `1e-7` の架空の枝が生じ、復号器が余分な線端として拒否した。図形の語義や円配置の違反ではなく、観測グラフの頂点同定の不具合だった。

`kant_geometry_reader` の版3では、点を座標順に処理し、既存の幾何許容差 `EPS=1e-6` 未満にある代表点へ統合する。接近点の連鎖によって遠い端点までまとめず、一点が異なる二つの代表点に近い場合は曖昧として拒否する。入力要素の順序を変えても同じ頂点・辺を得る。

正体不明の自由な線端を認める規則は追加していない。離れた点をつなげないこと、接近点の連鎖を潰さないこと、実際の折れ点の誤差を解消することを対照検査した。変更は図形の読取に限り、生成器の円と線の許容条件は保持する。

## 確認結果

[検査報告](../reports/kant-framing-spellings-v1.json)では元の40文すべての復元構文が前段と一致した。既存語形、引用・束縛・共有、元生成器の40文の幾何読取、丸め境界の回帰例など、316件の検査が通った。全体の円数は3042から2887、合計横幅は209693から196586へ約6.3％減った。主張51は279から239円、横幅18406から14689となった。

出力は `output/kant-framing-spellings/index.html`。同フォルダーの `inspection.png` では主張4・51の全体と、主張51の先頭4500単位を各組同倍率で目視した。部分拡大は同じ構文位置で切った比較ではない。

文頭の反復には、同じ比喩提示・仮定例を繰り返す構文自体の共通性も関わっている。短い語形だけでは、元kant-pageに近い有機的な構成を達成できていない。引数の枝、語の合成、接触による構成、行・頁の規則を進め、全体復号と外観確認を終えるまで固定しない。
