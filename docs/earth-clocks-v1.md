# 赤道と極の時計の比較

アインシュタイン1905年論文§4の原文区間u0128末尾について、赤道にある時計が極にある時計より非常に僅かに遅く進むという帰結の部分草案を追加した。同じ構造、その他の条件の一致、差の程度をそれぞれ記述する。原文との意味一致の確認は未完である。

`syi` は、時計の構成部分に弾性的な復元作用を持つ回転振動系があり、それを歩度の調整に使うことを要求する。Unruhuhrをこの機構として読む草案である。機械式時計の調速に用いる往復振動とばねの説明は [Patek Philippeの用語集](https://www.patek.com/en/glossary)を参照した。脱進機の詳細や一般的な力学まで定義したものではない。

`syk` と `syl` は、物体の表面にある場所を、中心回転軸からの距離と軸方向の座標で区別する。赤道では軸方向座標が零で軸からの距離が正、極では距離が零で軸方向座標が非零となる。どちらの極も含め、中心点は除く。「地球」の固有参照は、この幾何的な説明の代用にはしない。

`syj` は、比較するその他の条件の範囲が完全かつ非空であり、選択された各条件について両時計で成立・不成立が一致することを要求する。両方にない条件も一致として扱う。同じ構造を表す既存の `cd` とは別に検査する。どの条件を尽くせば十分かという一般的な判定は未実装であり、範囲の完全性は明示的な基礎関係に残した。

`syn` は、共通の時間区間・基準系・時間単位における正の平均進み率を比較する。第一の率が第二より小さいだけでなく、その差が比較文脈の「非常に小さい」という基準を満たすことを要求する。文字盤の絶対値や初期の同期はこの比較に含めない。検査では率999/1000と1、差の上限1/100を使うが、これは検査用の解釈であり、原文の閾値や地球上の実測値ではない。

`sym` は、同じ構造の二時計を一様回転する同じ物体の赤道と極に固定し、その他の比較条件を一致させる設定である。一様回転は採用した解釈の前提であり、実際の地球の運動や環境を全て説明するものではない。

`syo` は、この設定の二時計についての条件付き内容である。先行する曲線の帰還結果 `syd` から著者が帰結する内容として接続した。赤道と極で離れたままの時計と、同じ場所へ帰還して比較する時計は区別する。この接続は著者への帰属を記述し、物理的な導出が十分であると認定するものではない。

25通りの具体的な解釈で、機構、条件、場所、進み率の区別を検査した。著者・前提・結論・適用範囲などの帰属は6例で検査した。新規7テストと関連テストの計27件が通過した。

通常記法・短縮記法・固有文字の構文上の往復を検査した。CLIの解析結果を構文木と比較し、SVG出力をXMLとして読み込めることも確認した。字形の目視確認や全テストの実行は今回の検査に含まない。
