# 許可と、規範を変更する権能

カントu0013の契約する資格について、以前の許可の読みを残しつつ、指定した要求や積極的許可を成立・廃止させる権能の候補を追加した。行為の許可、制度的効果を生む権能、実際の行使を別に記述する。

設計上の区別には、[Hohfeldの原論文](https://persweb.wabash.edu/facstaff/helmang/phi213-1314S/phi213-txtbrwsr/Hohfeld/Hohfeld1913.html)の「Powers and Liabilities」を参照した。そこでは、人の意思による統制のもとにある事実から法的関係を変更することが権能として説明される。ただし、後世の理論をそのままカントの語義へ帰属させない。また、既存の`rdu`は積極的許可と反対要求の不在を求めるため、反対義務の不在を表すHohfeldのprivilegeそのものではない。

| 定義 | 内容 |
| --- | --- |
| `riv` | 同じ規範対象について、不在から成立、または成立から不在への変更がある |
| `riw` | 本人が選ぶ行使を制度的枠組みが同じ前後状況の移行として認め、その同じ移行に`riv`の変更がある |
| `rix` | 基準状況から`riw`を満たす結果状況があるという、特定変更への権能の候補 |
| `riy` | `riw`の行使を本人が実行し、その同じ前後状況への移行が現実に生じた |
| `hzc2` | 指定した要求を成立・廃止させる権能についての内容 |
| `hzc3` | 指定した積極的許可を成立・廃止させる権能についての内容 |
| `hzc4` | `hzc2`の権能と、同じ行使への反対要求と衝突しない積極的許可を併記する内容 |

規範の出所、名宛人、立場、対象の閉じた記述、順序付き引数列、対象内容の極性を前後で固定する。別の人への要求が成立したことや、別名の政策への許可があることを、指定対象の変更へ流用しない。行使の側も、主体・立場・記述・引数・基準状況を固定する。行使引数列の先頭は同じ主体でなければならない。

`polarity`は規範が対象にする内容の肯否、`status`はその規範関係の有無を指定する。ある行為をするよう求める規範の廃止は、その行為をしないよう求める規範の生成ではない。両方を独立に指定でき、要求と積極的許可も別の規範関係として扱う。

制度上の移行を示す`recognizes`には、その枠組みが同じ行使を前状況から後状況を生む行使として扱う、という意味規約を与える。単に前後に二つの状態を観測しただけではこの関係は成立しない。主体による選択の統制は`controlled`で別に要求する。どちらも入力関係であり、制度の承認・正当性や共同主体の意思の一般的な説明を済ませたものではない。

結果状況は制度上の候補として存在すればよく、現実に移行済みとは限らない。実際の行使を述べる`riy`には、同じ行使の実行記録と同じ前後状況への現実の移行を追加する。行使を実行できたという物理的な能力、行使の許可、制度的な効果は自動的に同一視しない。

この構成は特定の規範対象の変更について述べる。他の規範が一切変わらないこと、全制度的効果、権能や免責そのものの変更まで表したものではない。既存の同じ規範を確認するだけの行使は変更条件を満たさないが、その行為自体が無効だと述べる定義でもない。

要求対象や行使の記述は脱引用して実行しない。規範の変更を述べることから政策が実現したと推論せず、権能を問うことから権能が実際にあると推論しない。前版の質問・回答構成へ、同じ権能内容の閉じた記述を渡し、否定疑問と否定回答を作れる。権能の関係が未知でも、その問いと回答の帰属自体は記述できる。

検査では、前後の規範状態・変更方向・主体の統制・制度による認定の32通りを調べた。肯否と成立・廃止の4通り、行使と現実の移行の8通りも区別した。別主体・別立場・別制度・別名・別対象・引数の誤り・異なる結果状況の混同など18対照例を確認した。一つの指定結果が不適切でも、別の整合した候補があれば権能の証人にできる。

原文側の構成では32通りを使い、行使への積極的許可、反対要求、要求を変更する権能、許可を変更する権能を独立に検査した。許可だけがある場合、権能だけがある場合、行使が禁止されても制度上の変更能力はある場合を書き分ける。これらは明示した解釈の検査であり、現行の法的判断を返す機能ではない。

[一般文書](../examples/v014/normative-powers.noema)は1,478文字、[原文付き草案](../examples/v014/kant-normative-powers.noema)は125,736文字、[抽出文書](../examples/v014/normative-powers-core.noema)は3,322文字である。7定義を追加し、親の宣言と15件の主張を保持した。新しい原始記号・著者主張は追加していない。[意味規約](../data/kant-normative-powers-basis-v1.json)と[検査記録](../reports/normative-powers-v1.json)に原文への解釈注記と制限を保存した。

原文の資格を、許可だけと読むか、制度的な権能と読むか、その両方と読むかは未確定である。具体的な契約が将来世代にどの規範を成立させるか、制度の正当性、団体の代表権、全文の問いと否定判断への帰属も残る。以前に対応範囲へ数えた箇所を深めた変更なので、原文の対応文字数は増やしていない。意味確認済みの全文単位は0のままである。
