# 関数の型から引数を読む

既存のnative `apply` を円文字で表す。関数参照、ラムダ式、束縛された関数変数、関数を返す呼び出しや適用を対象とし、関数の評価や定義の展開は行わない。

適用の子は、関数を第0位置、引数を第1位置以降に置く。子数が二つ以上なら、通常の中央位置を第一枝とし、第0位置を本文の続きに残す。他の位置は元の順序で枝候補に加える。枝数がkなら、この公開順序の先頭k位置に対応する。無引数の適用は関数だけを本文に置く。この構成では関数が枝へ移ることはない。

復号器は適用の印を読んだ後、本文側から関数の式を一式読む。その結果型を、公開辞書の関数署名と、図形から読んだ束縛変数の型から求める。関数型のparameter数によって引数数が決まり、各引数を元の順序で枝または本文から読む。引数数を記す追加の記号列や、描画器のイベント情報は使わない。関数を表さない式、関数型を超える枝数、欠けた引数、枝に余った式は拒否する。

変数の型は、変数名とともに現在の束縛範囲に保持する。引用内ではその範囲を空に戻す。ラムダ式の型は引数の型と本体の結果型から求める。関数値を返す呼び出しは公開された結果型、適用は関数型の結果型を用いる。これは読取に必要な結果型の導出であり、すべての型・作用範囲の検証を置き換えない。復元後は従来のnative検査を通す。

適用の字形は、大円の左円周上に中円の中心を置き、大円の中心から右下45度へ伸ばす形とする。線は大円の下端と同じ高さで終わり、他の円へ接続しない。既存の根語、文法字形、予約された根語との衝突を検査する。偏心内包、罫線外の横線、円への斜め入射を許可する変更ではない。

検査は無引数・一引数・複数引数、引数交換、関数変数、ラムダ式、関数を返す適用、関数を引数に取る適用、引用の束縛、枝の配置順と束縛の命名順の違いを区別する。定義本体の適用が読めても、定義宣言そのものの円文字化や未対応のnative構文が完成したとはしない。外観の固定には別途確認が必要である。
