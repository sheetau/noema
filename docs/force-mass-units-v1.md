# 力・加速度・質量の尺度を含む係数

μの読みと、力を加速度で割った係数の数値を、独立した単位尺度で結ぶ定義を追加した。質量・力・加速度の尺度をそれぞれM、F、Aとすると、縦係数Lと横係数Tは `L×F = μ×M×A×β³`、`T×F = μ×M×A×β²` を満たす。基準の力を基準の質量×加速度に整合させ、三尺度は正の一定値として指定する。

この関係では、質量単位のμをそのまま係数にできるのは、尺度が `F=M×A` を満たす場合である。質量単位だけを変えてμの読みも同じ量になるよう変換すれば、係数は変わらない。一方、力や加速度の単位を変えた場合は係数の読みも変わる。これらの有理数の関係と、尺度を無視した誤った主張の反例を検査する。

本文の内容構成子は、前段の軌跡・座標時刻・加速度の換算・力の記録を保持する。さらに、力と質量の次元と尺度を同じ単位規約へ結び、μの帰属先が同じ対象・出来事・質量単位・文脈であることを要求する。数値が正しい別の対象の記録を流用する読みは受け入れない。低速での質量の帰属関係そのものは、測定上の解釈を要する入力として明示する。

次元には独立した質量の基底軸を使い、力の指数を質量と加速度の指数の和として構成する。次元の整合だけで、実際の力や質量の測定を導いたとはしない。一般定義は実切断の尺度を許すが、今回の実行検査は登録した有理数の埋め込みによる。全実数の演算法則、基準量の共有、単位の実現と校正、電荷と場からの力の説明は残る。

また、単位を変えることと、力や加速度そのものの物理的定義を変えることは別である。原文u0259の異なる定義・理論の比較を、この換算だけで記述し終えたとは扱わない。対応は既存u0255の数値式への解釈注記とし、原文範囲と意味確認済み区間数は据え置く。先行176文は保存し、新しい著者主張は追加していない。
