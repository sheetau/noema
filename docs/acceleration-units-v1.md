# 座標加速度と単位付きの読み

位置の二階微分として求めた数値を、質量係数の式で使う加速度単位の読みに換算する定義を追加した。長さの単位尺度をL、時間をT、加速度の単位尺度をA、座標の二階微分をx、換算後の読みをyとすると、関係は `y × A × T² = x × L` になる。尺度は共通の基準に対する値で、いずれも正でなければならない。

一般定義には、有理数版と、尺度自体も実切断で与えられる版を設けた。値が零でも、尺度が零や負である例は受け入れない。次元は既存の基底次元の定義を再利用し、加速度の指数を「長さの指数 − 2 × 時間の指数」として構成する。次元が一致するだけで、量の種類や測定の校正が同じだとは判断しない。

本文の接続では、同じ対象・系・文脈の軌跡に対して、領域内の全時刻で単位付き座標記録との対応を要求する。以前の座標帰属と、別のライブラリにある物体・出来事・単位付き座標の語彙は、明示した同値条件で結ぶ。単に同名の記号として共有することはしない。単位・次元・尺度・文脈の規約を各入力へ適用し、換算した三成分を力と質量係数の式へ渡す。

例えば L=2、T=3、A=5 なら、座標加速度9の読みは2/5となる。時間尺度を一乗だけ掛ける誤りや、換算前の9をそのまま力の式へ使う誤りを区別する。単位が変われば係数の数値も変わるため、本文のμと二係数も採用した単位に合わせて与える。今回、力とμの測定尺度そのものを導出したわけではない。

有理数では、換算値の一意性、零と符号の保存、整合する尺度での数値の一致、連続した換算の合成を検証する。実切断版は登録した有理数の埋め込みで対照例を調べる。全実数の連鎖律や二階微分の単位変換則を証明したとは扱わない。全軌跡の観測対応もモデル前提と、実際の量化条件の一時刻での検査を分け、有限の標本から全域の成立を認定しない。

旧来の有理数尺度の単位規約を利用するため、実尺度を受ける関係への変換用定義も用意した。一般の換算式は無理数尺度を排除しないが、この旧規約を包む定義の対象は正の有理数尺度である。無理数尺度の規約は別の単位関係として記述する。

尺度は選んだ時間領域内で一定とする。一般の時間依存尺度や非線形変換、単位の実現・校正、力とμの物理的な量の説明は残る。先行176文を保持し、原文対応は既存u0255への解釈注記として扱うため、原文範囲と意味確認済み区間数は増やさない。
