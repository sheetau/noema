# 時刻原点の条件と同じアフィン式の延長

u0062–u0064では、先の偏微分条件とτの線形性から具体形を示し、係数を未知の速度関数として残す。その際、記述を短くするため、k原点でτ=0のときt=0と仮定する。この接続に先立ち、旧草案の強い共通零点条件を分解する。

ei4gは同じk原点の出来事を現在の二座標組へ結ぶ。ei4hはそのτが零であること、ei4iは同じ組でtも零であることを要求する。ei4jは全対象出来事・全現在座標組で「τ=0ならt=0」を保ち、その零点が少なくとも一つある非空の時刻原点規約として読む。一つの成功例だけで全範囲を代用せず、異なる出来事の零値を混ぜず、全時刻でt=τとはしない。

ei4kはその同じ零点で補助三座標x−vt,y,zも零となる空間原点規約である。これは先の原点往復の表示式へ合わせる選択であり、原文の時刻条件自体が全空間座標零を述べたことにはしない。ei4lは同じτの全対応と全k時計指示、時刻規約、空間零点、τ(0,0,0,0)=0を合わせる。偏微分条件だけから加法定数が消えるとはしない。

アフィン表示も同じ座標変換へ結ぶ。K座標の時間行を(A,B,C,D;E)とすると、x=x′+vtを代入した表示はAx′+By+Cz+(D+vA)t+Eとなる。ei4mはこの五係数を同じ行列・定数ベクトルから取り出す。時間係数をDのままにしたり、符号を逆転したり、定数Eを先に消したりしない。

ei4nは現在の測定入力上のアフィン変換eizfと同じτの全時計条件を保持し、同じ五係数による全実数四入力のsmdを要求する。測定済み入力だけから全実数での表現を証明したとはせず、同じアフィン式を延長して用いるという解釈を明示する。未測定入力の全てが実際の出来事として存在するという追加主張ではない。

この段階では著者主張と全単位件数は増やさない。同じτの偏微分係数、未定のφ(v)、原点の仮定と簡潔さの理由、式への帰結を本文へ接続し、三単位全体を判断する作業が残る。
