# 発信者を中心とする伝播先と、想定読者の分離

前段の`hzof`と`hzog`では、伝播先が想定読者`h6t`に固定されていた。想定読者、本人の周囲にいる人、実際に受領・理解した人は一致するとは限らない。今回の一般形では、発信者と参照文脈に結んだ関係から伝播先の範囲を作る。

## 範囲の中心・向き・参照文脈

`rqth`は、指定関係を同じ中心人物・対象・参照文脈へ適用し、中心本人を除く。関係を逆向きに読んだり、関係をたどれる全員へ自動的に広げたりしない。中心の本人を受け手として数えることもない。

関係はNoemaで定義した関数として渡せる。「周囲」という新しい未説明の基本語は追加していない。社会的な接点、場所を基準とする範囲などは、その関係の定義を明示して区別する必要がある。

具体例の`hzom`は、既存の`sa`を使い、一方が他方を情報源・援助の供給元として利用できる関係を少なくとも一方向に持つ二人を選ぶ。対称なのは二方向の選言を記述したためであり、一般の関係に対称性を仮定した結果ではない。実際の利用、物理的な近さ、親密さ、理解や同意は要求しない。この条件を、カントの「周囲」や社会的な近さの普遍的な定義として採用したわけではない。

## 同じ発信者の自己離脱と将来の伝播

`hzok`は、`hzof`の想定読者に関する部分を、発信者・参照文脈・指定関係から作る範囲へ一般化した。自己活動による離脱、最初の発信との順序、同じ経路の受領・理解、具体的な性向の取得、基準時までの持続は元の定義を用いる。

指定された範囲の全員が人であることを検査し、その範囲の中で伝播の条件を満たした人を内部で求める。一般の関係に非人間が混じった場合は、人だけに黙って絞り直さない。まだ伝わっていない相手は母集団に残る。人数や割合などの広がりの基準は引数で指定するため、全員への伝播を原文の既定の意味とはしない。

`hzol`は、この伝播と、初期評価点での独立判断への応答傾向`hzhh`を同じ発信者へ結ぶ。発信者が変われば範囲の中心も変わる。参照文脈は伝播結果を評価する途中で変更しない。取得に成功した時点の範囲へすり替えて、未達の相手を消すことはできない。

旧`hzog`は想定読者に向けた表現として保存した。新旧の範囲が一致し、そこに中心本人が含まれない場合は同じ結果になる。一方だけの範囲が空なら結果は異なり得る。一般形の導入から、想定読者と本人に結び付く範囲が同義になったとはしない。

## 検証と残る意味

5テストで以下を検査する。

- 所属・取得・人であることの64組合せ。空範囲、未達の相手、非人間の混入を確認し、関係の向き・参照文脈・本人除外・推移性を別に調べる。
- 人であることと両方向の利用可能性の16組合せ。既存の`sa`から範囲を構成し、本人を伝播先に数えない。
- 具体的な性向の伝播を含む11対照、利用可能性の3対照、二人の中心の違い、新旧の範囲が一致する場合と異なる場合。新しい一般形では`h6t`を未知としても実行できる。一人以上という広がり基準では、二人の母集団を保持したまま、一人が取得した例が成立する。
- 四つの未知入力の拒否、既存の全意味規約・32文・七単位の確認の保持、通常・短縮・固有文字の往復。

具体的な二つの成立例は、保存された意味定義を通常評価で実行し、短絡診断の結果と照合する。複数の対照例には既存の短絡診断を使う。これは未使用の枝の未知入力まで通常評価と同じように検出する方法ではないため、未知入力の検査には通常評価を使う。性向・自己離脱・伝播の意味定義の本体を実行し、その接続を検査する。

四つの合成定義を追加し、新しい基本関係はない。範囲と広がりの一般形は依存先込みで702文字、累積本文への追加は1,426文字である。原文対応はカントu0011の422–440、既存の`um sich verbreiten`の部分範囲を補う。原文対応率、本文の主張数、意味確認済み単位数は増えない。

原文に適した社会的な範囲と広がりの基準、関係の形成・変化、頚木の比喩、比較と因果の談話関係、自由と将来の様相、著者帰属への全文接続は残る。
