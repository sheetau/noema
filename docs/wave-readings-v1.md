# 波の表現と観測記録の接続（2026-10-14）

波の振幅を、どの波・基準系・観測者・出来事・量の種類・単位についての値かという条件へ接続した。既存の測定記録、場の割当、正弦波の表現、振幅変換を再利用し、四つの定義を追加した。新しい基本関係は追加していない。

## 一つの基準系での記録

`sean`は、一つの光の対象と基準系へ、電気側と磁気側の場、その領域、量の種類を割り当てる。二場が、指定した正弦・位相・六振幅の波形と領域全体で一致することを要求する。領域を空にして一致条件を通すことはできない。横波の振幅条件も同じ入力に適用する。

`seao`は、観測者に帰属する結果記録を、同じ波・量の種類・基準系・出来事・単位・値へ結ぶ。観測者はその測定設定で当該系に静止し、記録の出来事の四座標が波の記述領域に入っている必要がある。結果記録は仮定上の測定にも使えるため、この条件だけで現実の観測が行われたとは断言しない。

`seap`は両者を接続し、電気側または磁気側の三成分から求めた非負の振幅が、単位尺度を掛けた記録値と一致することを要求する。電気側と磁気側の量の種類は区別する。数値が等しいという理由だけで、磁気側の記録を電気側へ移すことはできない。

## 二つの基準系の接続

`seaq`は、同じ波・正弦関数・量の種類・文脈について、二系の`seap`を結ぶ。移動系の周波数、方向、六振幅を、静止系と同じ光速度・相対速度から既存の変換式で構成する。領域も座標の逆変換で対応させる。

観測者、出来事、記録、単位は系ごとに別に指定できる。例えば検査では、静止系の振幅5を尺度2の単位で5/2、移動系の振幅25/4を尺度5の単位で5/4と記録した。記録値の比1/2を、そのまま振幅の比5/4と混同しない。この構成は平面波の一定振幅についてのものであり、二つの記録が同じ光子や同じ位相を検出したという条件は加えていない。

## 明示的に与える関係

既存の数値と場の割当だけからは、波の物理的な同一性、記録の観測者への帰属、二つの任意の基準系の相対配置を決められない。そのため、次の三つを型付きの関係引数とした。

| 引数 | 必要な対応 |
| --- | --- |
| `assigned` | 同じ波・基準系・二場・領域・二つの量の種類・文脈の割当と、場の成分を表す基準尺度の規約 |
| `recordedby` | 記録・観測者・文脈の帰属 |
| `motion` | 二系・光速度・符号付き相対速度・文脈について、使用する標準配置と尺度の対応 |

これらを入力から推定する仕組みは追加していない。関係引数を渡すだけでその物理的な説明を完了したとも扱わない。場の関数値は各量の種類の基準尺度で解釈し、既存の電磁理論の規約の下で変換する。電気側と磁気側に同じ数値倍率を使うことを、任意の単位系に無条件で適用するものではない。

## 検証の範囲

電気側と磁気側のそれぞれについて34例、計68例を検査した。基準例は二系で異なる観測者・出来事・単位を使う。同じ波と変換の対応を保ったまま、次の取り違えを区別した。

- 別の波、記録、観測者、基準系、出来事、文脈への帰属。
- 電気側と磁気側の量の種類の交換、違う単位尺度、零・負の尺度、負の振幅。
- 周波数、方向、振幅、速度、場の一成分、領域の変更。
- 正弦の全域条件、場の全域一致、変換領域の一致の欠落。

累積草案と必要な依存先だけの独立文書で同じ結果になった。実数の数値演算は、正確に構成した有理数切断へ与えた演算を使っている。

この検査は引数の接続を検査するためのものである。正弦の全域条件、場の全域一致、領域の全域一致は、検査側から与える条件として分離した。有限例の波形には線形関数を使っており、それが正弦であるとか、完全な物理モデルであるとは主張しない。全域一致についての有限個の比較点は、取り違えを検出する証人としてのみ使った。

三つの全域条件をそれぞれ元の定義へ戻すと、有限解釈器は有理数全域への量化を拒否する。少数の比較点を通っただけで、全域の正弦や場の一致を証明したことにしないための境界である。
