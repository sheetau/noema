# 近似値と漸近的な誤差

[漸近的な誤差の定義群](../examples/v011/asymptotics.noema)は、関数の値と近似値を等置せず、その差を比較尺度で抑える関係を表す。既存の定義域・集積点・関数・量化から9定義を作り、4基本記号・47定義となった。文法・字形・基本語を追加していない。

## 誤差を比較する条件

点aに近づく定義域D上で、fをgで近似するとき、比較尺度hに対して次を要求する。

```text
正の定数Cと正の近傍幅δが存在し、
すべてのxについて、
  x ∈ D、x ≠ a、|x−a| < δ なら |f(x)−g(x)| ≤ C |h(x)|。
```

さらにaがDの集積点であることを要求する。空の定義域だからどんな近似も成立する、という扱いにはしない。Cとδはxを見る前に選び、xごとに変えない。比較尺度が負になる場合も絶対値で評価する。

| 有理数領域 | 実数の切断領域 | 内容 |
| --- | --- | --- |
| oi | — | 単一の誤差に対する絶対値の比較 |
| oa | oc | 指定したC・δによる穿孔近傍全体の誤差上限 |
| ob | od | 集積条件と、成立するC・δの存在を要求するBig-O型の関係 |

oa・ocは近傍での上限の条件であり、それだけでは定義域が集積しているとは限らない。ob・odで集積条件を加える。実数版は、点と定数と近傍幅が有効な実切断であり、各関数が定義域内で実切断を返すことも要求する。

この関係だけで「誤差が0へ近づく」とは限らない。例えばh=1なら、非零の定数誤差もO(1)として成立する。何を小さいとみなすかは比較尺度によって決まる。測定器の誤差範囲や確率的な信頼区間とは別の概念である。

## 時計の二次近似

速度と光速の比をuとしたとき、既存の正の進み率から得る単位時間の厳密な遅れと近似を、次の構成式に分けた。

| 定義 | 式と意味 |
| --- | --- |
| oe | `1−sqrt(1−u²)`。実数として使う範囲は|u|<1 |
| of | `u²/2`という二次近似 |
| og | 比較尺度u⁴ |
| oh | u=0へ近づくとき、oeとofの差がogのオーダーで抑えられる、という関係 |

ohを定義することと、その式を証明することは別である。今回の補助検査器は、全実切断の意味論まで含めたohの一般的な証明は行っていない。

[原文へ接続した草案](../examples/v014/einstein-curve-approximation.noema)は、前の曲線・観測・仮定の文書へqe・qfを追加した。qeは区間時間T、速度v、光速V、正の進み率rについて、次を同時に記述する。

```text
厳密な指示差 L = T(1−r)
近似値 A = T(v/V)²/2
残差 E = L−A
T(v/V)⁴/8 ≤ E ≤ T(v/V)⁴/2
```

vは速度の大きさで0以上、Vは正、v<V、Tは0以上とする。rは`V²r² = V²−v²`の正の枝である。vが非零でTが正なら、二次近似を厳密値と等しいものにはしない。例えばv/V=3/5、T=10では、厳密な遅れ2に対して近似は1.8、残差は0.2となる。

この残差評価はTを固定して速度比を0へ近づけるときの四次評価である。Tを速度に依存させて増やす場合まで、同じ定数で一様に四次と評価できるとは主張しない。

qfは前のqdと同じ観測と一定速度の前提を保持し、帰結だけを「qeを満たす近似値と残差が存在する」へ拡張する。原文に帰属する範囲内の主張uhにはqfの記述を渡し、無条件の断言にはしない。観測条件へ先に近似法則を混ぜて検査を通す構成も避けている。

## 原文との対応

u0126のM0229は`(1/2) t v²/V²`、u0128のM0241は`(1/2) t (v/V)²`であり、保存したMathMLと対応を確認した。前者の段落にある四次以上の項の留保を後者にも引き継ぐ読みとして、二次の値と四次の残差を別に保持した。

残差の上下界に使った1/8と1/2は、原文にそのまま書かれた定数ではない。高次項を省く意味を説明するための数学的な補足であり、著者がこの具体的な境界を明示したとは記録しない。近似の留保を、誤差が全くないという等式へ置き換えないために用いる。

世界線と実時計の観測・単位の結合、先行する折れ線の証明内容、地球上の時計の推論、原刊の確認と全実切断の微積分法則の機械的証明は残る。今回も原文単位全体を完成と判定せず、アインシュタイン0/282、カント0/20を維持する。
