# 発生源別の力と導体内の担体

磁石に由来する場の寄与を、導体内の担体への局所作用へ接続する。既存の全電磁力eicpは、全発生源を合わせた力の記録eirvを要求するため、源を限定する今回の構成では呼ばない。電気的寄与eibsと磁気的寄与eicoを再利用し、それらの和を同じ源による寄与として記録する。

eicwは異なる源物体・所在物体と、その物体全体とは別の点状担体を受け取る。同じ源の場eirw、二つの力の記録、担体の出来事sbを結び、同じ四座標が所在物体の物質領域eiroにあることを要求する。場の源条件と各力の源条件をeiryで共有し、数値の一致だけでは他の源や全力の記録を代用できないようにする。eiryは源別の記録帰属の規約であり、電気的・磁気的という寄与の種類や、和の等式は合成側へ残す。

電気的寄与、磁気的寄与、その和はいずれも零を許す。eicxは、同じ源による和の少なくとも一成分が非零であるという追加の証人である。二寄与がそれぞれ非零でも相殺する場合は、eicwを満たしてもeicxは満たさない。力の大きさの一致だけで向きの異なる記録を通すこともない。

eicyは同じ源物体へ磁石の読みeicrを、同じ所在物体と元状況へ導体の能力eiciを結ぶ。能力の電荷・時間単位を作用の記述と共有する一方、成功する可能な能力試行を今回の局所作用と同一視しない。能力の輸送率閾値や最小持続時間を、力の大きさや継続時間へ課さない。eiczはこの分類と非零の局所作用を合わせる。

検査では電荷・場評価・速度への接続、出来事の単位付き座標、物質領域、源別の三力記録、ベクトル和を実行する。実数演算と条件選択、全軌跡・微分・全時刻の単位対応は明示した境界へ置く。正負・零の電荷、二寄与の相殺、各記録の源帰属の欠落、各成分の誤りを対照する。分類への接続では磁石・導体・局所作用を境界にして全引数を検査し、全実数履歴は有限評価を拒否する。

これは磁石から導体内担体への一方向の局所寄与であり、電磁相互作用の全文記述はまだ完了していない。逆方向の作用、物体全体の応答、電流生成、場の交換、例示の呼びかけは残る。同時に等大反対向きの機械力があることや、実験を実施済みであることを追加条件にはしない。旧207主張と著者表示判断を保持し、検査成功を原文単位全体の意味判断へ変換しない。
