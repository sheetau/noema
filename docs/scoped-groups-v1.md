# 集団全体の包含と、後見人の働きかけ

カント第二段落の、女性全体を含むという挿入句と、後見人が人々の危険判断を生じさせるという主節を、先行する判断の草案へ接続した。著者の主張への帰属、集団の範囲、監督する立場、実際の行為、原因説明を別々に記述する。

## 集団を扱う共通定義

`ro`は、指定集団が非空で、その全員が母集団に含まれ、同じ性質を満たす条件である。該当者が一人でもいるという条件ではない。空集団に対する全称が自動的に真になることを避けるため、存在前提を明示した。空集合も許す数学的な包含とは区別する。

`rp`は、行為者群と対象群が共に非空で、全ての行為者が少なくとも一つの対象に関わり、全ての対象が少なくとも一人の行為者に結び付く条件である。二人の行為者が対象を分担しても成立する。各人が全対象に関わる条件、担当者が一人に限られる条件、集団の一部が何も担当しなくてよい条件とは異なる。

`rr`は、実際に生じる同じ行為へ、指定した行為者全員が参加する条件である。ある人が一つの行為に、別の人が無関係な行為に参加しているだけでは成立しない。一つの行為に複数の部分行為があることは許し、共通の意図や各人の単独の因果的な十分性は要求しない。

`rq`は、対象を指す基準と、その対象に使う呼称の描写を分け、使用した著者・文書箇所・文脈を保存する。双方の内容を現実の真理として評価しない。呼称が字義通りか、慣用か、皮肉かをこの条件だけで決めない。

## 原文への接続と解釈

対象の本文では、女性の集団への分類と、美しいという描写を分けた。カント自身の別著作でも、この呼称は女性と男性を対比する箇所に使われている。[『美と崇高の感情に関する観察』第三節](https://www.gutenberg.org/cache/epub/41197/pg41197-images.html)の用例を参照し、今回の対象範囲を読む根拠とした。著者の女性観が正しいという証拠としては扱わない。

`dn`は、既存の大きな割合の条件`u5`と、指定した女性集団全員の包含を組み合わせる。美的な評価を女性集団の選別条件にしない。女性集団の分類`da`は意味規約を与えた基本関係であり、分類そのものの生物学的・社会的な構成説明は未完である。名前を付けただけで概念を説明済みにはしない。

`di`では、ある人が別の人を現在総括的に監督し、それより前に、同じ対象への立場を実際に引き受ける行為を行ったことを要求する。従来の`ob`は立場を称する場合も含むため、今回の引受けにはより強い関係`dv`を使う。一方、自ら発意したことや法的な資格の正当性までは補わない。

`dk`は、この関係で後見人群が対象を分担して覆う条件である。代名詞の対象は、先行文と同じ母集団のうち負担と危険判断の性質に該当する人々とした。これは明示した読解であり、全人類への監督や、各後見人が全員を担当する読みが一意に排除されたという意味ではない。

`dl`は後見人群の実際の活動、`do`はその立場・活動・人々の判断の成立と、活動をその結果の原因説明へ採用する条件を結ぶ。原因の対象は危険判断であり、実際に高い危険が生じることではない。原因説明への採用は、現実の因果機構の証明と区別する。後続する家畜や歩行器の描写を含めた説明は、これから接続する。

本文の新しい二つの文は、内容の主張と呼称の使用をそれぞれ著者へ帰属する。Noemaの処理系が女性全体への一般化、美的評価、危険性、因果関係を事実と認定することはない。

`gütigst`の評価と皮肉、`schon`と`auch`の焦点、分類と監督の一般的な意味、後続の比喩、原刊画像との照合は未完である。第五文の全範囲に部分草案を対応させたが、文全体の意味一致を確認済みにはしていない。

## 検証

包含64組合せ、二人ずつの行為者と対象の結合16組合せと空範囲3例、共同作用64組合せ、原文への接続20例、著者への帰属8例を検査した。女性集団の一人が判断を持たない場合、集団外の人物を混ぜた場合、担当のない後見人、監督されない対象、単なる自称、別行為の混同、原因説明の対象が危険そのものに変わった場合を区別した。

一般文書は基本記号0・定義4、カント接続文書は基本記号117・定義151である。有限の明示的な解釈で実際の定義を評価し、定義を基本記号に置き換えて検査を省くことはしていない。型検査、短縮・通常表記、固有文字の往復、SVG出力も確認した。
