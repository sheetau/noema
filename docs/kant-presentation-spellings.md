# 提示・記述・本文順序の公開綴り

中央段への集中を調べると、代表5文（11・13・51・52・55）には枝内を含めて語境界の空白がなかった。大円を含む空白列の固定を解除しても、この5文の配置は改善しない。長い複合語に大円の根語が多く含まれることが原因の一つである。

今回の対象は、複数の文で再利用される提示の四つの関係とする。欠けている意味関係はなく、既存の一基本語・三定義をそのまま使う。文ごとの意味primitiveや、本文を収録した復号用辞書は作らない。

| 既存名 | 新しい公開綴り | 区別する内容 |
| --- | --- | --- |
| hzxu | give・book・assessmentdecisive | 同じ主張の焦点内容を確言する提示態度 |
| rqzv | book・inside・candidateexcluded・home | 一個体・二状況を対応させる非字義的な提示での記述の区別 |
| rqtv | give・book・home・book | 同じ組から主張と背景を取り出し、別々の範囲に帰属する関係 |
| rqvt | above・book・candidateexcluded | 二つの文章箇所の正順と逆順の排除 |

give・bookは既存の提示語群、book・insideは記述を用いる提示語群、above・bookは本文の順序を表す既存の綴りを継ぐ。assessmentdecisiveは確言する提示態度の手掛かりであり、主張の真理や実際の知識を追加しない。homeは文脈・背景・対応する状況を、candidateexcludedは記述同一性または逆順の排除を区別する手掛かりとする。これらは複合語全体の語彙規約であり、根語を論理的に適用した定義ではない。

`data/kant-presentation-spellings-v1.json` は元の意味記録、引数型、結果型、宣言全体のハッシュを保持する。`kant_presentation_context.py` は既存27綴りにこの4綴りを加える。旧完全綴りは別名として残し、nativeの識別子・定義本体・参照先を変えない。

描き直す範囲は、単に語の使用箇所を数えるだけでなく、新旧辞書で作るイベント列を比較して決める。短縮予約による他の略記・語境界の変化も含め、イベント列が変わる文を再生成する。一致する文はハッシュを確認した保存SVGを使う。どちらも新しい公開辞書と実図形から元の構文へ戻し、前段の構文ハッシュと比較する。

この変更で中央段の集中全体や文頭反復が解消したとはしない。円の形と幾何規則は変更せず、新しい意味審査や外観の固定も行わない。
