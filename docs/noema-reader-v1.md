# 円文字の読本と読解課題

この文書は旧字体の検討記録です。旧試作の生成物は整理しました。現行の仕様・本文・証拠は[Noema 1.0](language-edition-v1.md)を参照してください。

Noema 0.16・共有語彙第12版のためのオフライン教材を作る。読本（旧試作・整理済み）、375語の辞書（旧試作・整理済み）、17問の読解課題（旧試作・整理済み）を収録する。配布用ZIP（旧試作・整理済み）はこの三つだけを含み、通信を必要としない。旧0.3版の教材と、固定して保存した旧論文画像は変更しない。

## 学ぶ範囲

行の読み順・継続・終端、単独語と複合名・固有名、二進の自然数、型と引数順、否定と量化、変数の束縛距離、定義と主張、仮定、引用と評価、式共有を一つの読本にまとめる。49の文法操作、行標識4種、名前の入口2種、自然数の例、二つの解説付き全文を図版で示す。辞書は375語の形・意味・型・引数の役割・入力規約・反例・定義を公開資源から収録する。

基本課題14問には、引数交換、否定の位置、二重量化、記述の同一性と内容の真理、定義だけの文書、局所定義、仮定、式共有、順序付き列、引用評価を含む。発展課題3問は[円文字第12版](visible-senses-v1.md)の全文を使い、語義候補と選択、主張と背景、同義と引用枠の置換を読む。基本課題は各1ページ、発展課題は各4ページで、合計26ページである。

設問と正解理由は[教材の正本](../data/reader-course-v1.json)に保持する。これは作成者・実施者側の資源であり、学習者へ配布するZIPには含めない。学習者用HTMLには図形と質問・選択肢を載せ、正解や元のNative本文は埋め込まない。候補の選択肢に正しい読みがあることと、正解の位置を公開することは区別する。

## 実施方法

1. 読者には `noema-reader-v1.zip` のみを渡す。リポジトリや `reviewer/` には設問の答えがあるので、試験前には渡さない。
2. 読者は読本と辞書を参照し、課題を解く。匿名コード、設計への関与、解答の事前閲覧を自己申告する。解答時間・読本の参照方法・利用端末などの実施条件は、実施者が別途記録する。
3. 不明なら「わからない」、未着手なら未回答のままにする。迷った図形や作用範囲を自由記述で残す。解答保存ボタンはJSONをダウンロードするだけで、外部送信しない。
4. 実施者は、受け取った原本を保存して採点する。設問の版が違う、設問が欠ける、未知の選択肢がある場合は受け入れない。
5. 選択肢の正誤に加え、自由記述を人が読む。独立した読者だったか、以前の解答を見ていないかを自己申告だけで確認済みにしない。設計者自身の検査や自動生成した解答を、第三者の成績へ混ぜない。

```powershell
python -X utf8 -m scripts.reader_course grade <受け取った解答.json> <新しい採点結果.json>
```

採点前に教材の公開報告が固定するソース・成果物のハッシュを確認する。解答の設問ハッシュが一致していることも確認し、採点結果には元解答のハッシュを記録する。正解・誤答・不明・未回答を別々に数える。独立性の確認や自由記述の意味判断は自動採点の対象にしない。

## 検証と残る条件

[検査器](../scripts/check_reader_course.py)は、配布するHTML内の円・線から全課題を復号し、期待する文書と照合する。辞書の各語と文法標識も図形から読み直す。24の二個体モデルと三つの固定引数診断で、量化・否定・引用・定義・仮定・順序・共有の対照を検査する。破損した図、別の正当な図への差替え、設問の欠落や重複、解答形式の不正、採点前の入力改変を拒否する。

[検証報告](../reports/reader-course-v1.json)は機械検査の証拠である。実際の参加者はまだ0人で、第三者読解は未確認のまま記録する。自動採点器の合成データを参加者として数えない。選択式課題に正解しても、自由な構文復元・作文・任意文書の読解を確認したことにはならない。第三者試験ではこれらの追加課題と読者の説明を含めて評価する。

二作品全体の新書式化と最終完成監査は別の未完課題である。今回の教材は既存の文字・語彙・意味を変更せず、現在読める範囲を学べる形にする。
