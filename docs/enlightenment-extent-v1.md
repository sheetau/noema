# 同じ啓蒙の進行を比較する尺度

第五段落の二問に向けて、既存の啓蒙目標 `r2ln` と同じ能力変化を比較する[尺度](../examples/v016/enlightenment-extent.noema)を構成した。[意味規約](../data/enlightenment-extent-basis-v1.json)と[検査報告](../reports/enlightenment-extent-v1.json)を保存し、モデルの結果に好きな順位を付ける入力から、既存の変化内容を使う比較へ進めた。

## 何を進行として比べるか

先行する採用読解では、公衆の全読者のうち、知的自立に関する能力変化を遂げた人の比率が文脈上の基準を超えることを集団の啓蒙とする。その同じ読者全体・期間・起点・変化条件を使い、一つの集団変化過程としてどれだけの読者に変化が広がったかを比較する。

数える変化は既存の `hzmx` の内容である。結果の自立性、当事者と対象者、作用・活動部分・因果、前後の能力変化を保つ。単なる議論の回数、経済的な成果、指導への服従を人数へ読み替えるものではない。同じ人に複数の当事者や活動部分があっても、一人として数える。

期間内に複数の過程がある場合は、一つの過程として達する最大の広がりを比べる。ある過程で一人、別の過程で一人が変化したことを合併して、二人が変化した一つの過程を作らない。これは既存の目標が同じ過程・前後を共有していたことに合わせた条件である。

## 到達前と変化のない場合も比較する

右候補の各過程の比率に対し、それ以上の比率を持つ過程が左候補にあるなら、左は少なくとも同程度に進んでいるとする。最大値を返す未説明の関数は追加せず、この証拠間の比較を量化で構成する。

目標の閾値に達しなくても、ゼロから一部の読者への変化を区別できる。変化がない有効な二経過は同順位になる。一方、空の母集団、読者の欠落・重複、不適切な期間は比較の定義域から外し、「進行ゼロ」や「害がない」へ置き換えない。

同じ尺度で閾値を厳密に超えるという条件を再構成し、既存の `r2ln` と同じ判定になることを検査した。閾値に等しいだけでは達成としない。

## 読解の範囲と接続

この尺度で採る「進行」は、同じ期間内に達する広がりである。期間内の速度や、個人の自立の質的な深さを別軸として比較する読解は採っていない。日数・人数・閾値の固定値を原文へ補うこともない。こうした解釈選択と、原文が一意に指定した条件とを区別する。

同じ公衆・基準・目標記述を確認したうえで、この尺度を前回の対応比較へ渡す。要求の全適用・全解除、同じ背景の対応組、四命令の内容を保ち、別の目標へ尺度を流用した場合や尺度が未評価の場合は拒否する。

個人の能力変化と公衆分類は先行の検査を再利用し、今回の検査では比率、過程間の比較、目標の閾値対応、比較への引数接続を分けて確認する。さらに、尺度と対応比較を結合したNoemaの評価でも、基準未満の進展、同じ広がりの維持、広がりの減少を区別する。有限検査を現実の因果や全域の証明とは扱わない。問いの提示文脈における共通の公衆・背景、追加の制限候補、照応・対照・留保・強調は未統合であり、本文主張と意味確認済み文字数は増やしていない。
