# 三つの座標系と二つの平行変換の合成

アインシュタイン1905年論文§5の、第三座標系k′を導入して二つの変換を合成する箇所を部分記述した。u0147の第二文からM0285、u0149冒頭の「tritt;」までを対象とする。原刊906頁で第三系の導入と数式を照合した。

Kからkへ速度vで変換し、kからk′へ速度wで変換する。その合成は、同じ四座標式へ次の速度を渡したものとして記述する。

```text
U = (v+w)/(1+vw/V²)
β(U) = β(v)β(w)(1+vw/V²)
```

二行目は、係数も合成速度に対応しなければならないことを示す補助関係である。原文M0285に追加の式が書かれていると主張するものではない。速度引数を置き換えた同じ変換を使うため、位置だけでなく時刻の式にもβ(U)が使われる。横方向の二座標は元の値を保つ。

係数1の四座標式は、既存のsreへ任意の速度を与える定義s4lとして構成した。二回の適用では同じ中間記録を共有する。元からあるssnの速度参照や、未知の係数関数を含む過去の定義は変更していない。

実際の記録との接続では、三つの異なる座標系が同じ出来事を同じ設定で記述することを要求する。対象出来事の範囲は非空であり、全出来事に三系の記録が存在し、対応する全三記録が式を満たす。単に一組の都合のよい記録が見つかるという条件にはしていない。同じ値を持つ別名の記録は許し、値が食い違う追加記録は拒否する。

第三系の速度wには新しい参照を与えた。前の点運動の速さwとは、綴りが同じという理由だけで同一視しない。第三系の運動は中間系の縦軸を基準に記述し、静止系を基準にした値との取り違え、軸・速度・単位・設定の取り違えを検査した。

原点と尺度は§3で得た係数1の式の規約を採用する。二系が相対運動するという関係だけから、任意の原点ずれが消えるとは推論しない。二つの変換式を満たすこと自体を合成の前提に保持している。全実数座標に対応する物理的な出来事が存在することも、この記録の接続だけでは保証しない。

V=5、v=w=3なら、合成速度は75/17、合成後の係数は17/8となる。β(v)β(w)=25/16だけを使うと異なる変換になる。検査例では最初の四座標(7,3,4,2)が中間の(5/4,3,4,29/20)を経て(-31/8,3,4,13/8)へ移り、一回の合成変換と一致した。逆向きの等速二変換では元の座標に戻り、片方または両方の速度が0の場合も扱う。

有理数の補助検査9件では、許容された二速度の分母の正性、合成速度の上限、合成係数の正性とβ条件、四座標式の一致、横座標の保持、逆速度での零への合成を確認した。通常の速度加算への置換と、交差項を欠いた係数の積は反例で拒否した。この検査は、実切断全域の体・順序・平方根の法則を機械的に証明したものではない。

具体的な座標11例、三記録の接続11例、第三系の設定7例、帰属6例も検査した。中間記録だけを誤らせた場合、直接の合成式は成立しても二段階の関係は成立しない。最終時刻や横座標を誤らせた場合は両方が不成立になる。物理的な記録割り当てと相対運動は、明示した検査モデルの条件を使っている。

新規7件を含む関連26テストが通過した。通常記法・短縮記法・固有文字の往復、CLIのJSONと構文木の一致、SVGのXMLとしての読み込みも確認した。全テストの実行と字形の目視確認は今回の検査に含まない。
