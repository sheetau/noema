# 原点に置く時計と進み率の質問

アインシュタイン§4の `u0118`〜`u0124` を部分記述した。時計が二つの系で時刻を表示できる能力と、今回その時計を移動系の原点に置いてτを表示させる設定を分ける。同じ時計の指示と両系の座標記録を結び、進み率の質問、二つの方程式、代入後の比例式を記述した。

```text
同じ時計について許容される別々の設定:
  Kで静止している場合: 指示がtに合う
  kで静止している場合: 指示がτに合う
今回の設定: kの原点に置き、τを表示させる

τ = β*(t-v*x/V²), x=v*t
τ = t*√(1-(v/V)²) = t-(1-√(1-(v/V)²))*t
```

`suy` は指定系で静止する時計の全照合記録を、その系の座標時刻に結ぶ。各記録には同じ時計、出来事、場所、時間単位、実際の指示、測定済みの座標記録を要求する。対象記録の範囲は非空とし、必要な全記録を尽くすという前提を別に保持した。この完全性は有限個の観測から認定しない。

`suz` は、同じ時計をKで時刻tに合わせられる許容設定と、kで時刻τに合わせられる許容設定が存在することを表す。許容される配置・調整の関係は外部の意味規約であり、その物理的な実現機構まで定義したものではない。時計が現在両系に静止するという条件にはしない。有限モデルでは、能力が成立していても時計は実際のKには静止していない例を検査した。二つの系を同じ対象に潰した場合も退ける。

`sva` は移動系の原点での同じ時計と出来事を両系の測定記録へ結び、移動系の三つの空間座標が零であることと、時計の指示がその記録のτに合うことを要求する。`svb` はこれを全照合記録に適用した今回の配置である。原点以外の場所、別の時計への置換、指示の欠落、時間以外の単位、測定と結び付かない候補記録を区別する。

進み率の条件 `svc` は、観測系で異なる時刻の記録が少なくとも二つあり、時間順に並ぶ全記録対で、指示差が候補の進み率と観測時間差の積に等しいことを要求する。`svd` はこの条件を満たす正の実数値を問う。等速・校正済み時計の一定進み率という今回の読みであり、瞬間的に変化する時計の速度一般を定義したものではない。

この質問へ平方根の式を先に代入していない。V=5、v=3、観測時刻0・5・10、指示0・4・8なら4/5を受理し、5/4や1を退ける。同じ配置の仮の記録を0・5/2・5に変えると、質問は1/2を受理する一方、座標変換の式は偽になる。これは相対論的にその時計が実現するという証明ではなく、指示から比率を判定する条件と、理論の式との区別を検査する例である。

一時刻の記録や、全記録の観測時刻が等しい場合は、方程式が数値上成立していても進み率を特定しない。三番目の指示だけを変えた場合も、最初の二記録から得た率を全期間の率として受理しない。時計の能力の一方の許容設定が利用できない場合には、その能力を含む原文の設定は成立しなくなるが、今回の実際の記録から比率を計算できることとは区別する。

`svf` がτ=β*(t-v*x/V²)、`svg` がx=v*t、`svh` が同じ時計の全記録で両式を要求する内容である。移動系の原点に置く設定と前段の最終変換からこの二式を得る帰属を記述し、原文の「明らか」という提示も別に保持した。`svj` と `svk` は代入後の比例式と差の式を結ぶ。ここでtは符号付きの座標時刻であり、常に正の経過時間として扱わない。負の時刻や負の速度の例でも検査した。

今回の指示は同じ時間単位でτそのものに合わせる。共通の指示原点の変更は差では消えるが、この正確な校正条件は満たさなくなる。尺度の変更は比率も変える。一般の校正関係 `sux` で共通原点の相殺を検査し、記録ごとに違う原点や尺度変更を無条件に相殺する誤った主張には反例を確認した。
