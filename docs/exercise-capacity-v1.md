# 現在の行使能力をカント本文へ接続する

カント冒頭の Unvermögen は、現在の本人側の判断基盤のもとで、通常の実行機会があっても自立的に理解力を使える能力がない、という読みを採る。単にその場に機会がないことと、準備的な習得によって将来できるようになることを分ける。[冒頭の定義](https://korpora.org/Kant/aa08/035.html)と、試みを許されなかった履歴や自分の精神への働きかけを述べる[後続部分](https://korpora.org/Kant/aa08/036.html)を参照した。この文脈における採用読解であり、能力一般の唯一の哲学的分析を証明したものではない。

## 本文の変更

`kant-exercise-capacity.noema` は旧本文の35文を構文として保持し、共有する四つの定義本体を改訂する。`bc` は評価済みの通常行使能力の欠如、`up` はその能力、`fo` はその判断に必要な評価条件を表す。未成熟から離脱する過程 `be` の終点も、同じ `up` を使う。終点だけ旧来の現在地での実行可能性を残す不整合を解消した。

通常場面の全てで能力基準を満たすことと、個々の場面で絶対に何もできないことは別である。今回の否定は前者の欠如であり、後者を全場面に要求しない。プロフィールや方法分類の評価不足から不能を断定することも認めない。分類済みの有効な達成方法があれば、別の方法の未分類だけで肯定の証拠を取り消さない。

五つの一般定義 `rqvk`–`rqvo` は既存の機会プロフィール・方法範囲・評価条件を合成する。一般ライブラリに新しい基本関係はない。一方、本文には六つの文脈関係 `hzsc`–`hzsh` を明示的に追加した。候補場面、本人側の基盤保持、外的機会、通常性、方法範囲、分類の評価状態である。これらの入力まで自動的に推定できるという主張ではない。

方法範囲は、既存の準備履歴の構成で具体化できる。現在の判断基盤を行使する思考や努力を排除せず、別の基盤を先に取得することを要する方法を、取得前の能力の証拠に混ぜない。原文が指定しない訓練履歴や認知機構を、本文の主張として補わない。理解・決意・勇気の十分さも、同じ本人の自立的使用という目標に関する文脈基準を保ち、数値閾値や測定法を追加しない。

## 確認範囲

検査は定義本体を通常の評価器で実行する。16組合せで現在の機会と通常場面の成功を分け、九対照で学習方法だけの成功・未分類・不正なプロフィールを検査する。七つの未知入力は未確定として拒否する。旧本文と新本文の五比較、離脱過程の四対照、著者への帰属の七対照も行う。最後の確認では引用した能力内容を実行せず、著者が提示した内容とその真実性を区別する。
