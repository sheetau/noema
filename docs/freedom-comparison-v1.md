# 自由の種類と害の比較

固定原文kant-1784:u0012第一文の「最も無害な、自由と呼びうる全てのものの中で」を、自由の種類ごとの内容を比較する最小性として構成した。比較の焦点は、直後に説明される全事柄についての理性の公的使用である。第一文全体の著者への帰属と通読はまだ行っていない。

原文は[アカデミー版第8巻36頁](https://korpora.org/Kant/aa08/036.html)で確認した。比較の方向は害が少ない側とし、同順位を許す。「最も」を、害が絶対にゼロであることや、最小の種類が一つしかないことへ強めない。自由を現実に認めているかどうかによって比較対象を切り詰めない。

`h232b`は同じ基準で自由と呼びうる種類の全範囲、`h232c`はそれぞれが何を許容・可能とするかの内容族、`h232d`は同じ公衆と基準に適用した二つの内容の害の比較である。具体的な害の対象と評価背景は文脈入力に残す。害を読者だけへの身体的危害に限定せず、実際の被害の件数を自由の性質と取り違えない。

`r2sm`は既存の最小性`rce`をその範囲と比較へ適用する。空範囲、範囲外の最小候補、反射性・推移性・全比較可能性を欠く比較では成立しない。比較不能を同順位とは扱わない。

`r2sn`は、最小となる種類の内容が既存`r2sl`そのものを指すことを要求する。`r2sl`には各読者・各主題の公的活動記述と、同じ出所・起点・後続期間での許可維持が構成されている。ここでその内容を引用することは、現実に許可があると断言することではない。別の自由についての最小性は流用できない。`r2so`は先行する同じ非空の公衆範囲`h222e`について比較を述べる。

有限検査では、同順位、別の種類の方が害が少ない場合、比較不能、非推移的な比較、別の公衆や基準の評価の流用、内容のすり替え、空範囲、未知入力を区別する。検査用の内容供給にはNoema自身が作る閉じた引用を渡し、引用先の許可・実行・達成を未知のままにする。全世界の自由の列挙やカントの評価の正しさを証明する検査ではない。

残るのは、同じ啓蒙への照応、自由以外の要件を求めない限定、対比と特定化の提示、第一文全体の帰属・通読である。著者主張は63文のままで、以前の14区間の意味判断と確認済み文字数を保持する。
