# 移動系での単位電気量の推論

u0173第三文は、相対性原理によれば先の電気量は移動系で測っても1である、という著者の推論である。実装前に、先行する点状電気量と現在の第一原理、Kとk、同じ量種・単位・尺度、系ごとの結果記録、原理に基づくという提示を確認項目にした。既存のejwf、eion、scc2とsbw2、zc、eischを再利用し、新しい基本記号を加えない。

diese elektrische Masseは先行する点状電気量zolを指す。慣性質量、校正の第二対象zom、力の大きさへの言い換えではない。Kで値1とする仮定と、同じ出来事をkで測っても値1とする結果を、同じ電気量種zor・単位zou・尺度1へ結ぶ。二系の記録はzoxとzpdで区別し、第一の結果を単にコピーして第二の測定が成立したとはしない。

第三文に別時刻の指定がないため、ここでは同じ対象上の出来事zooを二系で記述すると読む。後続の力の評価出来事zpoへの電気量の保持は別に接続する。前提には点状電気量1の仮定ejwfと現在の第一原理eionを使う。第二文の校正に使ったKで静止した試行を、後続の状態にも無条件に要求しない。

Nach dem Relativitätsprinzipは、原理の内容を実行して結論を得る処理命令ではなく、著者が示す根拠である。前提と結論を別々の内容として引用するzcで、その推論を提示する。したがって、原理の内容とKでの単位電気量の仮定が成立しても、kでの指定記録が欠ければ結論内容は成立しない。これは表現の区別を検査する対照であり、相対性原理の物理的な反例や電荷不変性の証明ではない。

原刊909頁と固定本文を再読し、diese、auch、im bewegten System gemessen、Größe eins、原理による帰属を保持した。旧文164だけを置き換える。段落の残る導入・静止条件付きの力と場・末尾の二表現への接続は未完であり、u0173の全単位判断は増やさない。
