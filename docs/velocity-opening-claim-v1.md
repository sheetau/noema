# 速度合成の見出しと点の運動の仮定

第5節見出しu0129は、速度の合成規則を、その条件から導く定理として扱う主題を示す。系の相対速度、その系での点の速度、もう一方の系での同じ点の速度を三つの成分量として結ぶ。対象・二系・適用状況は関係の引数に残し、両系で追う出来事の全範囲も一致させる。座標時刻の数値を等置して範囲を合わせることはしない。

見出しは第一部に属する深さ2、表示番号5の節を案内する。区分は第二部直前のu0150までを含む。合成規則の主題と、前提から導く定理という論述の種類を分けて合成し、見出し自体に特定の公式や証明済みという認定を加えない。

u0130–u0132は一つの設定文である。bewegeを、同じ既出のK/kの比較で点の運動を考える仮定として読む。三式ξ=wξτ、η=wητ、ζ=0は同じ点の全期間の現在記録と定速度へ接続し、原点を通る条件も保持する。点の速度成分には負・零・正を許し、光速未満の制限は追加しない。

wobei以下の二つの記号説明では、wξとwηという表記を、同じ点の縦・横の定速度を与える規則に結ぶ。その規則は同じ二係数を全実時刻で共有する。系の速度v、点の位置ξ/η、一瞬だけの値とは区別する。識別表記、物理量の規則、仮定を採用する発話はそれぞれ保持する。
