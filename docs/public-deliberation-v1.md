# 公に確かめられた情報の進展と共同提案

前版で引数にしていた到達条件を、情報の進展、公に確かめられる根拠、共同提案の可能性へ接続した。カントu0013の「理解が公に進み、確かめられ、声を合わせて提案できるようになる」という部分の解釈候補である。

| 定義 | 内容 |
| --- | --- |
| `rkm` | 同じ命題の同じ検討に用いられ、その検討を支持する理由が、公衆にアクセス可能である。命題自体も同じ公衆へ開示されている |
| `rkn` | 以前の正しく支持された情報を失わずに情報が増え、後段階の範囲内の全ての正しく支持された項目が`rkm`を満たす |
| `rko` | 二人以上の市民が同じ行為に参加し、同じ採用を求める内容を同じ相手へ提案する |
| `rkp` / `rkq` | 同じ集団に利用可能な方法があり、想定結果の一つ／非空の全てで共同提案が成立する |
| `rkr` | 情報の後段階で、公的な根拠を伴う情報進展と共同提案の可能性がそろう |
| `hzef` | 同じ対象についての情報に限定し、既存の理由使用・支持・生起・参加・時間順序へ接続する |
| `hzeg` / `hzeh` / `hzei` | この具体的な到達条件を、前版の到達必須／未到達の持続も許す／到達点も含む継続へ渡す |

情報の増加には既存の`ri5`を使う。同じ範囲・主体・評価状況で、以前の正しく支持された情報を保ち、内容上の区別が増えることを要求する。すでに知っていた内容を公表しただけでは、この増加にならない。根拠を公表したことだけで理解の深さを測ったとも扱わない。

公的な確認では、命題、検討行為、そこで用いた理由、その理由による支持、理由へのアクセスを結ぶ。別の命題の検討や別の判断を支持する理由では足りない。後段階で保持する正しく支持された項目の全てを検査するため、新たに増えた一項目だけを公開しても条件を満たさない。支持の妥当性と証拠の信頼性は、与える関係の意味規約に残る。

提案集団の成員は提案能力を評価する時点で固定する。想定結果で参加できた人だけを選び直さない。全市民が参加しても、一部の市民が参加してもよい。原文の「全員でなくても」を、必ず反対者がいるという条件にはしない。ただし二人以上の結合として構成しており、代表一人の行為へ還元した制度的な説明は含まない。

共同提案は、一つの行為について参加者・提案内容・相手がそろうことを要求する。各人が別々の行為で話しただけでは成立しない。採用を求める内容は閉じたNoema記述として保持し、その提案の検査で内容の真偽や実現を評価しない。提案可能性は、現在すでに提案済みであることとも、必ず提案できることとも異なる。

継続への接続では、批判する制度を情報の対象とし、批判の公衆を根拠公開の公衆とする。提案集団が市民に含まれるかの判定には、制度維持・批判許可の判定と同じ市民関係を使う。別の市民一覧で資格を補わない。制度と批判許可が続いても、公開根拠や共同提案の条件が欠ければ強い到達条件は成立しない。到達しない持続を許す読みでは、その場合も維持だけが成立し得る。

検査では公開された支持理由の五条件32通り、情報進展・公開根拠・方法利用・提案成功の16通りを調べる。単なる公表、非公開の根拠、別の命題・判断・対象、別々の提案行為、異なる相手、非市民、結果時点での成員変更、空の結果集合、成功と失敗を含む方法を対照する。無関係な原始関係と提案内容の真理は、実行されれば検査を失敗させる解釈を使う。

[一般文書](../examples/v014/public-deliberation.noema)は3,263文字、[原文付き草案](../examples/v014/kant-public-deliberation.noema)は152,129文字、[抽出文書](../examples/v014/public-deliberation-core.noema)は9,556文字。十定義を追加し、新しい原始記号と著者主張は追加していない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-public-deliberation-basis-v1.json)と[検査記録](../reports/public-deliberation-v1.json)を保存する。

ここで記述したのは、明示した解釈での到達条件である。理解一般の十分な定義、根拠の健全性、情報進展が提案能力を生む因果、程度や譲歩の効果、集団の形成と代表資格は未完。宛先が君主である説明と、改正した宗教制度の共同体を保護し、旧制度を望む共同体を妨げないという提案内容も残る。構文の往復や有限検査を、原文全体の意味一致の証明にはしない。
