# 足枷についての第三文の判断

カント第三段落第三文の161非空白文字について、文脈上の読みを明示した通し判断を記録した。先頭二文の247文字と合わせ、同段落の文単位の確認は408文字になる。段落全体の判断と第四・第五文は残る。全単位の確認済み2,212文字、草案対応8,264文字は変えない。

この判断は、アシスタントが原文と意味規約を照合した結果である。独立した査読や、ドイツ語との同義性の自動証明ではない。構文が通ることを理由に意味一致と判定するものでもない。

## 採用する読み

[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)では、規定と定型表現を機械的な道具と呼び、合理的な使用から誤用へ言い直して、持続する未成熟の足枷と描く。直後には、それを捨てる仮定と、離脱に成功した少数者が続く。この接続を踏まえ、第三文を、吟味せず使い続ける場合の作用についての種類一般化として読む。

規定は、採用された条件付き要求の構造として記述する。定型表現は、固定して再利用する表現の構成として扱う。任意の機器にコードがあるだけでは該当しない。[DudenのFormel](https://www.duden.de/rechtschreibung/Formel)も固定した表現と科学的な公式の語義を区別する。ただし現代辞典から1784年の唯一の語義を決めるわけではない。特定の制度、成立史、原語の綴りは、この一文が述べる命題へ補わない。

二種類は別々に一般化し、一方について成立するだけで全体を通さない。同格の指示は同じ種類記述を受ける。機械的な使用では、同じ対象を同じ活動に適用することへの本人の吟味がない。無意識や全般的な思考能力の欠如までは含めない。

合理的使用と誤用の間は言い直しとして残す。両方を同時に断定せず、誤用を合理的使用の単純な否定にもしない。同じ本人・自然に備わる能力・使用活動を保つ。足枷の比喩では、対象と本人の二位置を、足側を拘束する物体と被拘束者へ対応させる。物理的な足枷が実在するという主張は追加しない。

持続については、適用局面で使い続ける比較履歴の、残りの生涯の全点に未成熟と因果的関与が続く読みを採る。使用のない時間も評価から除外しない。[Dudenのimmerwährend](https://www.duden.de/rechtschreibung/immerwaehrend)の持続の用法も比較したが、そこから数学的な無限時間や不死を導かない。離脱が不可能という命題、途中でやめた履歴の停止前だけの保証、やめれば成熟するという逆向きの結論は含めない。この限定が適切かは解釈の判断であり、有限テストの結果ではない。

比較事例・通常性・適用局面・完全な履歴・誤用・因果関係には、意味規約に従う入力が必要である。反例を都合よく除外することは認めないが、現実の入力を漏れなく正しく与えたことまで形式検査で証明できるわけではない。
