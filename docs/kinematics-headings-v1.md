# 運動学と同時性の定義の見出し

原刊892頁の `I. Kinematischer Teil.` と `§ 1. Definition der Gleichzeitigkeit.` を、固定原文u0006・u0007と照合した。番号、句点、部と節の階層を保持する。第一部の区分はu0006から第二部u0151の直前まで、第一節はu0007から第二節u0023の直前までを含む。

`eihn` は前段落と同じ、剛体の位置・時刻・配置とその変化を扱う運動学の主題である。見出しはこの研究領域を扱う第一部を案内する。全物体が現に動くこと、力の原因の理論を完成したこと、既成の時間規約を全て採用することは述べない。

同時性の関係 `eihm` は、同じ系・単位・文脈で二出来事に有効で一意に付与された時刻が一致することへ接続する。既存 `seh` が局所時計の読みと共通参照時計との同期、有効性と全候補値の一意性を保持する。`eisb7` の校正規約と `sca` の値の一致を使い、未付与の候補時刻だけを比べない。別の場所の出来事や、同じ出来事の自己比較を許す。異なる系での同時性の不変は要求しない。

`eiho` はこの同時性の関係を研究の対象とする主題、`eihp` はその意味と適用基準を明示する定義の仕事という主題である。後続本文が何を定義するかを案内し、特定の出来事が同時だとは断言しない。見出しの時点で全ての定義・導出が完成済みだとも認定しない。

`eihq` は同じ見出し・区分・親区分・論説・階層深さ・表示番号・主題を結ぶ。文書を深さ0とし、この論説では部が深さ1、節が深さ2となる。表示番号は部のIも節の1も整数1として記述し、元の字形は原文記録へ残す。階層と番号を分けるので、後半の部に移っても節番号が継続する構造を表せる。

`eihr` は第一部を論説に、`eihs` は第一節を同じ第一部に結び、導入第三段落、第一部見出し、第一節見出しという本文順序を保つ。見出しの機能は主題と構造の案内であり、本文中の物理命題の発話へ変換しない。

検査では、番号と階層、親区分と論説、主題の型、箇所と区分、順序の取り違えを区別する。同時性の接続は、時刻の一致と両出来事の有効な付与を分けて確認し、全実数の候補値を有限標本で置き換える評価は拒否する。保存済みの時計・時刻・剛性の定義を再利用し、ここで全物理設定を証明したとはしない。

二見出しは、明示した読みの下で原文全体の意味と役割を記述した。後続u0008以降の全単位判断は別に進める。
