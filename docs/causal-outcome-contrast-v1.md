# 同じ活動種類による二つの結果の対比

カント第四段落の後半は、革命によって専制や圧迫から離れることが生じる可能性と、同じ方法では考え方の真の改革が生じないことを対比している。この「その方法では生じない」を、「その結果はどんな方法でも起こり得ない」と同一視しない構成を追加した。

今回接続したのは因果的な可能性とその否定の作用範囲である。革命、専制、利欲や支配欲による圧迫、真の改革の概念は引数として残り、説明済みとはしない。`vielleicht`の認識的な留保、`wohl`の語用、未来の範囲、`aber`による提示行為も未完である。

## 可能な結果と、原因を限定した否定

`rqc`は、指定した種類の活動の中に、指定結果を同じ対象へ生じさせる可能性があるものが存在することを表す。既存の`rfk`を用い、同じ活動・評価文脈・候補状況について、活動の生起、因果的な結果生成、その結果内容の成立を要求する。別の活動の因果記録、別の対象の結果、別の候補状況の真理を継ぎ合わせない。

`rqd`は、その同じ種類の活動のどれについても、指定結果を生じさせる候補がないことを表す。ある一つの活動だけの失敗では足りない。二つ目の活動や二つ目の候補で結果を生むなら、この否定は成立しない。

この否定は、結果そのものの真理を否定しない。別種の活動が同じ結果を生じさせることも、指定した活動と同じ場面で結果が別の原因によって成立することも両立し得る。たとえば、あるリセット操作で保留された仕事を消せても、損傷した部品を修復できないという条件は、別の修理作業による修復を排除しない。

`rqe`は、第一の結果について`rqc`、第二の結果について`rqd`を同時に要求する。対象・活動種類・基準文脈・候補関係は両側で共有する。第一を生む活動だけへ範囲を絞って第二の結果を否定しない。種類が空なら否定側だけは真になり得るが、第一の可能性を含む対比全体は成立しない。

## 本文への部分接続

`hzhk`は、活動の生起を既存の`dg`、記述された結果の生成を既存の`g3`へ結ぶ。活動種類、二つの結果記述、対象、候補関係を明示的な引数として残す。[累積本文](../examples/v014/kant-causal-outcome-contrast.noema)に四つの合成定義を追加し、原始記号と著者の主張は増やしていない。既存15主張と全宣言は保持している。

原文u0011の`vielleicht wohl`、`aber niemals`、`zu Stande kommen`へ部分対応を記録する。名詞句全体を完成した対応範囲として加算しない。候補関係を全ての関連する可能性に適切に対応させたことや、原文全体の意味一致をこの部分構成だけで認定しない。

結果は記述として保持し、`rfk`がその記述を実行して候補状況での成立も確かめる。二つの記述が同じ真偽を持っても、一方への因果関係を他方へ移さない。脱引用を含む定義は、現行の引用規則でそのまま著者帰属の内容へ引用できない。この制約を隠さず、今回も本文全体の主張への帰属は未接続としている。
