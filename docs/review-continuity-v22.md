# 参照指示を追加した版での既存六単位の確認

対象は`examples/v016/kant-cross-reference.noema`と`data/cross-reference-basis-v1.json`である。参照指示の一文を末尾に加え、既存31文・全宣言・意味規約・名称表記を保存した。前付四単位、署名、日付行について、選択した文と依存する宣言・意味・来歴のハッシュが前版と一致することを確認した。

既存六単位をその固定原文と照合し、採用した読みを維持する。前付の1784年12月という号の表示、脚注内の1784年9月号、署名の日付行の9月30日、新しい参照先の1783年12月は異なる指定である。新しい住所は促される行動の内容の内部にあり、既存の日付や名称への同一性主張を追加しない。

登録簿v22は、前付四単位の確認v2、署名v22、日付行v8、新しい参照指示の確認v1を後継本文へ結ぶ。六単位の継続判断と新しい一単位の判断を区別する。七単位はいずれも短い前付・署名・日付行であり、本文の長い段落や脚注全体を確認済みへ追加しない。判断はアシスタントによるもので、独立査読ではない。
