# 直前の命令と比較候補を結ぶ

第五段落の二問へ向けて、直前の四事例の命令内容を、要求の有無と啓蒙への影響を比べる構成へ接続した。[正本](../examples/v016/kant-demand-candidates.noema)は旧70主張を保持する。[意味規約](../data/demand-candidates-basis-v1.json)と[検査報告](../reports/demand-candidates-v1.json)に、具体的な束縛と検査の境界を保存した。二問の著者帰属と通読判断はまだ追加していない。

## 一人につき同じ全命令を一行にする

先行文と同じ発話者・発話・基準時点・全宛先を使い、各宛先を索引として一つの要求行を作る。これは人を物理的な記録文書とみなすことではなく、一人につき一行を割り当てる構成である。

行には、同じ出所、受け手本人、その受け手の立場、要求される行為型、閉じた内容記述、正極性を保持する。行為型は実行済みの出来事でも発話行為そのものでもない。前三者では「議論しない」と教練・支払い・信仰の各要求を一つの内容のまま保つ。統治者では、同じ出所の要求に従って履行する既存の内容を使う。

統治者の議論への許可は、要求の行に禁止として混ぜない。先行する発話の接続に残し、服従の内容だけを要求の対象にする。各内容は本人と行為型の二引数を受け、別の型を渡した場合には成立しない。原語の文の名前だけを記述の代わりに使う構成ではない。

## 発話と要求の適用は別に扱う

`r2wa` は事例ごとの閉じた内容と、先行する同じ話者・発話・基準への接続を調べる。ここから要求の現実の適用や法的正当性は導かない。

新しい `h234s` は、段階1の内容記述を対象にする要求関係である。既存の段階0の要求関係や、発話を提示したという関係へ暗黙に置き換えない。`r2wb` は全宛先について要求がある／ないこと、`r2wc` は同じ本人の自由選択候補が要求内容を満たさない例を扱う。比較へ進む構成では、事例の接続とこの表を同じまま使う。

統治者の履行内容には、全記述域を通じて要求を尽くす条件がある。その有限評価を拒否する既存の限界を保持する。局所検査では、先行検査と同じ評価境界を明記して内容の選択と引数の一致を確かめ、網羅性を省略した結果を全域の検証として扱わない。

## 四事例は候補の全部とはしない

`r2we` は、直前の四つの異なる事例が比較候補の範囲に含まれることを求める。逆向きの条件を置かないので、それ以外の制限の種類を除外しない。検査では、四事例だけの範囲と第五の候補を追加した範囲を受け入れ、一つを落とした範囲や空の範囲を拒否する。

四事例については、各行の出所・本人・立場・行為型・内容・極性、自由選択、同じ公衆と基準を、前回確認した比較へ渡す。前三者の命令内容は既存のNoemaを評価し、記述の取り違え、部分的な適用・解除、他人の選択を利用した制約を区別する。巨大な比較の全組合せを再実行せず、既存比較の実評価と今回の具体的な束縛検査を組み合わせる。

## 残る統合

追加の制限候補の全要求表、同じ啓蒙の進行尺度・対象・期間・背景、潜在性と一般的な傾向をどう読むかを確定する必要がある。二問での同じ制限と啓蒙への照応、問いの帰属、対照、留保・強調、後続の回答への接続も未統合である。先頭七文496文字と旧14全単位判断を保持し、今回の構成だけで原文の意味確認済み分量を増やさない。
