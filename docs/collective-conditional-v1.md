# 集合的な前件と同じ集団の後件

固定した原因側の人々全員について思考の発展が成立することを前件にし、同じ共同体の態度と行為能力の変化を後件へ接続した。前段では別の注記だった共同原因を、条件文の中で実際に評価する。政府の原則と尊厳などの残余条件にも、同じ読み・共同体・原因側の列・基準文脈・始点・終点を渡す。

## 条件文と前件の実例を分ける

[一般定義](../examples/v016/collective-conditional.noema)の `rxt` は、非空の原因側の列と範囲を一致させ、各仮定で同じ性質記述を全員に適用する。全員について成立した場合には、その仮定の同じ履歴の後の時点で後件が成立しなければならない。一人だけ成立したことを、全員に成立したことへ変換しない。

| 仮定の状態 | 条件文で必要になること |
| --- | --- |
| 原因側の全員に前件が成立 | 同じ読み・人々・始点を保持した後続の結果 |
| 少なくとも一人に前件が成立しない | 後件の成立は要求しないが、範囲と履歴の整合は必要 |
| 原因側や仮定が空、範囲や履歴が不正 | 条件文の成功とは扱わない |

`rxu` は、範囲の整合が取れた仮定のうち、全員に前件が成立する実例があるかを別に調べる。条件文が成立することから、その実例や現実の現在における発展を導かない。この実例の検査自体は、全ての仮定の時間順序を検証する条件文全体の代替ではない。

一般条件の `valid` は、前件とは別に与える仮定の評価範囲の条件である。全仮定で前件が偽でも、`valid` が成立しない仮定を含めば条件文は成立しない。未知の必要入力も偽の前件へ補わず、有限診断では例外として残す。

## 仮定ごとに対象を選び直さない

[本文草案](../examples/v016/kant-collective-conditional.noema)の `iaqinventory` は、原因側の人々、影響先の構成員、各人の判断対象と活動の完全な列挙を確認する。全員が人であり、原因側が影響先共同体に所属すること、増加上限が正であることも求める。

`iaqfixed` は、その範囲を基準文脈と各仮定の間で固定する。原因側、影響先、判断対象、活動、増加上限のどれも、成功する側に合わせて選び直せない。列の順序は同じでなくてよい。各列の完全性と範囲の一致によって、並び順の違いと対象の交換を区別する。

例えば「甲だけ発展する」という仮定で乙を原因側から外すと、前件を「全員が発展する」へ変えてしまう。各仮定の列がそれぞれ重複なく整っていても、基準の原因側と一致しないため不成立になる。判断対象、活動、上限だけを変える場合も同様である。

## 共同原因と後続内容を一つに結ぶ

前件が成立する仮定の後件では、`iaqaligned` が条件文の履歴と共同原因モデルの観測履歴を照合する。始点・終点・全履歴・履歴内の順序が一致したうえで、前段の `iapnecessary` を実行する。これにより、各人がこの組合せに必要であり、同じ集団の応答傾向が行為選択の拡大を媒介するという強い候補を接続する。

`iaqschema` は前段の二つの発展の読みから同じ一つを選ぶ。内的な衝動の読みを前件に使って、途中から課題の付与の読みへ切り替えることはできない。対象共同体も非空で、全ての選択した共同体について同じひな形を使う。

残余条件には、共同体だけでなく原因側の列と基準文脈も渡す。政府の原則や尊厳を後で記述するときに、別の人々や別の期間へ暗黙に移さないためである。残余条件の意味そのものは、この引数名で定義したことにはならない。

親の全宣言と先行21文を保存し、最後の部分注記を、接続した集合的条件文の階数2のひな形への帰属へ改訂した。帰属と引用内容の真偽は引き続き区別する。

## 検査と残る課題

100件のテストが通過した。一般条件では、二人・二仮定の前件と後件の64組合せを、論理条件の独立計算と照合する。空の範囲、不正な履歴、後続時点の不在、記述や原因側の取り違え、未知入力を検査する。

本文では、二人の発展、実際の判断条件、実行・不実行の方法を使った共同原因の評価まで実行する。前件が全仮定で偽なら未知の後件を評価しない一方、その仮定の範囲が変わっていれば不成立になることを確認する。列の並べ替え、片側だけの尺度変更、因果モデルと条件文の履歴の不一致、残余条件の不成立も含む。

診断には明示的な短絡評価と純粋で外延的な解釈向けの関数再利用を使う。キャッシュなしとの比較は一般条件の基準例に限る。 三文書の長形式・短縮形式・固有文字の往復とCLI解析、抽出文書のSVGのXML検査も通過した。形式的な評価、表記の往復、CLI解析、SVGのXML検査は、原文との意味一致や字形の目視確認を代替しない。

```powershell
python -X utf8 -m scripts.compose_collective_conditional
python -X utf8 -m pytest tests/test_collective_conditional.py -q
python -X utf8 -m scripts.check_collective_conditional --verify-only
python -X utf8 -m noema.constructed parse -i examples/v016/collective-conditional-core.noema
```

[意味規約](../data/collective-conditional-basis-v1.json)と[検査記録](../reports/collective-conditional-v1.json)に限定を残す。指定した原因側全員の発展と、各人が必要な共同原因を選んだ候補であり、原文がその人数や必要性を明示したとはしない。発展・態度・自由の語義、単調な件数尺度、構造モデルの適合は前段から未確定である。作用の独立した時刻、政府の原則、尊厳、自然の比喩、原文との意味一致は残る。新たな原文文字範囲と意味確認済み区間は加算しない。
