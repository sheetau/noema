# 予測した範囲・役割と概念定義の接続結果

正解の語句範囲を与えず、自然文から予測した述語・項を91概念の定義へ照合する研究用APIを実装した。語彙ごとの分類クラスや補正規則は追加していない。日本語18文では、役割と範囲が40項中37項、概念まで含めると32項で一致した。述語概念は19件中11件で、文内の全フレームがそろったのは5文だった。**広い自然文を翻訳できる精度には達していない。**

## 接続した処理

固定KWJAと選択済みevent-gate-v6のヘッドで出来事・語句・役割を予測する。文字位置の処理には修正済みAlignedJapanesePASを使う。次に、実際に予測された範囲からMiniLMの文脈・単独・全文ベクトルを取り、既存shared-matcher-v1の3係数方式で全91定義と比較する。

推論APIへ渡すのは原文だけである。正解の範囲、概念、型、評価用の文は読み込まない。同じ原文位置の照合は共有するが、異なる範囲の同一参照を推測して統合しない。先頭候補が述語として使えない「本」であっても、都合のよい次点へ置き換えず、型不整合として記録する。

これは文語の完成した文章を返すAPIではない。否定・時間・数量・名前・性質・同一参照・発話と節の作用範囲はまだ接続していないため、`status: research_lexical_frames`、`confirmed: false`、`document: null`と不足する処理を返す。未抽出の意味を肯定や未指定時刻へ置き換えて、翻訳が成功したように表示しない。

## 事前に固定した18文での結果

[検査条件](lexical-frames-v1-protocol.md)と[資料](../data/lexical-frames-v1.json)を今回の予測前に作成した。能動・受動、主体と対象の逆転、旧15概念の外の語、未知概念、状態、数量、否定・時間、関係節、主体省略を含む。ただし過去に観察済みの概念や文型を含む接続試験であり、広い入力の独立した採用評価ではない。英語の構造抽出は未接続のままである。

| 指標 | 結果 |
| --- | ---: |
| 正解の出来事／予測した出来事 | 19 / 19 |
| 述語概念の一致 | 11 / 19 |
| 正解の役割・範囲／予測した役割・範囲 | 40 / 39 |
| 役割・範囲の一致 | 37 / 40 |
| 役割・範囲・概念の一致 | 32 / 40 |
| 欠落／余分な役割・範囲・概念の組 | 8 / 7 |
| 述語・役割・範囲・概念の全フレーム一致 | 5 / 18文 |
| 型や役割に不整合のある予測フレーム | 12 / 19 |
| 確定した全文の翻訳 | 0 / 18文 |

同じ出来事件数だったことは、全ての意味が正しかったことを示さない。[全件の評価](../reports/lexical-frames-v1/evaluation.json)に候補欠落・余分な割当てを含めた。否定や数量を含めた全文の評価基準は、確定率0%・確定出力の一致率は未定義で不合格である。フレームだけの5/18を全文の意味構造一致率とは呼ばない。

## どこで失敗したか

「先生が学校で本を読んだ」では、語句と役割はそろったが、述語の「読んだ」に「本」を、「学校」に「先生」を選んだ。「水は子供によって飲まれた」の述語には「カップ」を選んだ。正解範囲を与える別の診断でもこれらの誤りは残り、単に語句を長く取れば解決する問題ではなかった。

正解範囲での診断は、対応する57範囲中46範囲で概念が一致した。未知の2範囲には両方とも既知の候補を返しており、未知判定は成立していない。「診断した」を「見つける」とする誤りは、主体・対象の型だけは整合していた。型検査に通ることも意味の正しさを保証しない。

「本は青い」「本は赤い」は概念を選べたが、本を主体ではなく対象役割へ割り当てた。関係節を含む文では役割が一つ欠落した。一方、洗うの能動・受動、飲むの能動、追うの役割逆転の2文では、今回測ったフレーム要素がそろった。成功したものにも時制等の未接続要素は残る。

次の対象は、**独立に選んだ先頭候補の型検査だけで終わらず、概念と役割の候補を構造全体として比較する処理**である。これはNoemaの型と役割制約を使う共通の推定で検証し、特定の日本語を別の語へ読み替える修正では行わない。未知概念が既知の型へ収まる誤りと、未接続の意味要素は別途解決が必要である。

## 検証と環境

全18文で、接続した経路と構造解析単独の出力が完全一致した。先頭4文では原文からの反復結果も一致した。[保存結果の再検査](../reports/lexical-frames-v1/verification.json)で全18文の組立てと評価を再現し、生成・辞書等の禁止経路5種の呼出しは全て0回だった。重複割当て、未知概念、範囲不一致、型不整合、推論への正解非入力を含む全403テストが通過した。

概念判定器の学習時はPython 3.14.2・PyTorch 2.12.0 CPUだったが、今回はKWJAと一緒に動かすためPython 3.12.10・PyTorch 2.13.0 CPUを使った。モデルのリビジョン、重み、定義、精度・プーリングは同じであり、今回の環境内で反復一致を検査した。旧環境との全スコアのビット一致を検証したという主張ではない。[実行条件](../reports/lexical-frames-v1/run.json)に両環境を記録した。

```powershell
artifacts/kwja-venv/Scripts/python.exe -m scripts.probe_lexical_frames
artifacts/kwja-venv/Scripts/python.exe -m scripts.probe_lexical_frames --verify-only
```

初回の結果を上書きしない。推論は`noema.lexical_frames.LexicalFrameAnalyzer().analyze(text)`で原文だけから実行できるが、研究用の未確定結果であり、主画面の翻訳器には採用していない。
