# 能力を得るために取り組む機会

カントu0014の「自由にそこへ向けて自己を形成するための場が開かれる」という部分に、許可と実行可能な自己作業を結ぶ草案を追加した。前段で扱った能力を目標の内容にし、その能力の獲得を目指す活動を、本人の実際の参加と作業から構成する。取り組む機会があることから、現在の努力や能力の達成は導かない。

| 定義 | 内容 |
| --- | --- |
| `rlt` | 同じ人・活動・時点の生起、能動的参加、自己作業、本人に結び付いた目標志向から、活動の実行内容を作る |
| `rlu` | 人から内容への関数を、ちょうど一人を含む個体列を取る目標関数へ接続する |
| `rlv` | 同じ活動への衝突のない実行許可、利用可能性、想定結果での同じ実行内容を要求する |
| `rlw` | `rlv`に加え、同じ活動を実行しないことも積極的に許されるという強い選択条件 |
| `rlx` | 非空の対象者範囲の全員に、同じ文脈で指定された機会がある |
| `hzey` | 前段の同じ主題・基準時点・事柄についての自立的判断能力を目標関数へ接続する |
| `hzez` | 実行内容を、本人の参加と、自分の精神的な営みを吟味し組み直す既存の自己作業へ接続する |
| `hze2`・`hze3` | 取り組む機会と、不実行も許される選択条件を、既存の規範・方法・結果の関係へ接続する |
| `hze4` | 人ごとの役割を保持し、非空の対象者全員についてその選択条件を満たす活動の存在を述べる |

目的の内容には、本人が同じ範囲の事柄について理由に支えられた自立的判断を行えるという前段の能力を使う。目的を記述し、それを目指すことと、その能力が現在成立することは別である。目標内容を評価できなくても、その目標を持つ活動への許可や機会は述べられる。目標の真偽を問うときには、必要な関係が未解釈なら評価を拒否する。

同じ本人・役割・活動・実行記述への許可と、その本人がその活動を実行できることを結ぶ。別の方法への許可と、利用可能な方法を寄せ集めない。想定結果の少なくとも一つで本人の参加と自己作業が成立することも要求するが、現時点でその作業をしていることは要求しない。作業の目標を達成することや、全ての結果で作業できることも条件に加えない。

「取り組んでよい」と「取り組まないことも許される」を分ける。`rlv`は前者を持つ機会であり、`rlw`は後者も積極的に許され、実行要求とも衝突しない強い候補である。実行を要求されている場合、取り組む機会は成立しても後者は成立しない。これは規範上の選択条件であり、物理的に不実行を選べること、全規範源からの自由、原文のfreiの唯一の意味を確定したものではない。

原文への接続では、閉じた`hzey`の記述を同じ本人の目標とし、それを持つ`hzez`の閉じた記述を規範と実行可能性の両方へ渡す。型が一致するだけの無関係な目標を自動で採用しない。本人の目標引数には一個体だけを許し、空列や余分な引数を切り捨てない。

[一般文書](../examples/v014/free-pursuit.noema)は1,339文字、[原文付き草案](../examples/v014/kant-free-pursuit.noema)は171,211文字、[抽出文書](../examples/v014/free-pursuit-core.noema)は4,414文字である。10定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-free-pursuit-basis-v1.json)と[検査記録](../reports/free-pursuit-v1.json)を保存する。

実行許可・不実行許可・利用可能性・結果での作業の16通りを検査した。三文書で、活動・本人・目標・許可対象の取り違え、自己作業や結果の不在、禁止と強制、許可や機会がなくても実際の作業がある場合を検査した。追加10テスト、三文書のCLI解析と構文木の一致、固有文字v2のSVGのXML検査が通過した。SVGの目視確認は含めない。

この構成は、場が「開かれつつある」という進行や変化の機構をまだ表さない。活動を方法として選ぶ粒度であり、複数段階の計画・反復・努力量・精神的営みの構造・能力獲得の因果機構も残る。対象者の範囲と規範の出所は入力で指定し、現実の人類全体や正当な規範を確定しない。同じ段落の障害の漸減、明瞭な徴候、著者帰属と全文の意味確認も未完である。
