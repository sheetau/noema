# 棒の設定・運動想定・二方法への問いの可視接続

Einsteinの確定稿の主張88〜90、原文u0029の三文を任意プロファイル27と文書内定義へ接続する。段落19の初期測定、配置と運動の想定、二方法による長さへの問いを扱う。方法a/bは段落20/21への前方参照であり、この版では後続文の新しい主張を加えない。

共通375語と以前の意味契約は保持する。任意プロファイルは632語から660語となる。旧関係26のうち、個体の導入を表すintroducesreferentを再利用し、25契約を公開する。再利用する関係の第四引数は旧資料のreferenceと既存プロファイルのcontextが同じ提示文脈を指す。型と意味を変えず、対応記録にこの役割名の違いを記す。新たな三関係は、記述された設定への参照と、二端点測定の個体欄・数値欄である。

初期測定、配置後、運動後、方法a、方法bの五設定を本文に示した役割で参照する。役割の引用は参照の取得時には実行しない。参照から設定の実在・成立・唯一性を導かない。初期長と速度も同じ方式で切断型の値を参照し、数値を補わない。速度の役割は既存の完全な運動条件から値をパラメータ化して合成し、一文を置き換える新しい基本語を作らない。

同じ棒、物差し、静止系、長さ・時間の単位を保つ。初期観測者は存在だけを要求し、後の観測者へ固定しない。配置後の初期長は保つが、運動後の長さには固定しない。正のX方向、全物質点と全区間への条件を保持する。加速機構、加速中の剛性、実現可能性は追加しない。端面中心には幾何学的標識を許し、棒の厚みを零にしない。

二端点の個体記録には、端点、出来事、時計、場所をそれぞれ二つ収める。数値記録には二つの局所読みと指定時刻を収める。同じ物体・系・測定設定で照合し、側の対応を保つ。公開された欄番号は記録の位置であって文書専用の語義番号ではない。同期・同時刻・時計の帰属・測定成立は本文の合成条件に残す。未知の記録や欄は拒否する。

最初の文の指示と、続く想定についての主張を区別する。最後の文は方法と値の候補を組にした問いを保持する。二方法の値の一致・相違、存在・唯一性、測定完了を先取りしない。関係入力を差し替える帰属10診断と内部提示22診断では、引用内容を実行せずに文脈・順序・前方参照への感度を確認する。

検証は179宣言の逆写像、既存文書の保持、参照と記録の各欄・キー、入れ子の軌道関数の結合、未知入力の拒否を含む。小さな区別可能領域での結合診断は全実数・全物理条件の証明ではない。元の合成条件と明示した読解の判断は保持する。SVG幾何からの復元、独立CLI、表示確認は第三者の読解とは別に扱う。
