# 共同体に広がる実践的反抗と誘発可能性

カント第五段落u0012[2513,2770)の挿入説明 `das allgemeine Widersetzlichkeiten veranlassen könnte` に向け、反抗の事例、共同体での広がり、同じ批判による誘発可能性を構成した。[AA8/37](https://korpora.org/Kant/aa08/037.html)と保存した原刊486頁を再読した。一文全体の統合・意味判断は未完で、確認済み文字数は増やさない。

`r34e` は公的な指図への実践的な反抗の一事例を表す。同じ市民・共同体・指図の出所を結び、本人が同じ要求への反応を実行し、要求と反対の極性を実践方針として取る。禁止への反抗も記述できる。要求の内容記述と引数列を保ち、要求対象の実行や成功、要求の正当性は推定しない。単なる不履行や能力不足では実践的な立場が欠けるため、反抗にはならない。

`r34f` は本人についてそのような事例が存在するという内容である。全ての型に合う要求記述・引数列を量化し、納付拒否だけに対象を狭めない。個々の記述を与えた `r34e` は実評価できるが、この全領域の存在量化は有限評価器では拒否される。既知の少数の要求を全領域と偽って列挙する実装は加えない。

`allgemeine` は同じ共同体の人々に広く及ぶことと読む。`r34g` が基準時に固定した成員列と「人かつ共同体成員」の同値を全個体に要求し、`r34h` が既存の `rfl` で重複・空列を排除して正確な割合を算出する。割合は正で、同じ基準の一般的な広がりの条件を満たす必要がある。反抗した者だけを母集団にしたり、候補結果ごとに分母を選び直したりしない。万人、過半数、特定人数、命令の種類数という読みへは固定しない。有限な政治的共同体の全成員を扱う解釈であり、無限母集団や標本統計は導入しない。

`r34i` は既存 `rfj` を使い、同じ候補結果で批判の生起、一般的反抗を誘発する因果関係、反抗の成立が揃うことを要求する。因果へ渡す段階1の閉じた記述は `r34h` であり、対象共同体・固定基準を結果の評価と共有する。活動、因果、結果が別々の候補でしか成立しない場合は拒否する。成功しない別候補の併存を許し、現実の反抗や必然性、処罰可能性・許可はここから導かない。

局所検査では `r34e` を実定義で評価し、肯定要求と禁止の両方に対する反抗、同じ出所・応答・記述・引数列・時点を確認する。広がりと可能性の検査では `r34f` を型付き境界とし、その外側の割合・母集団・候補接続を実定義で評価する。この境界を使った検査は、全要求についての実評価や原文との同義性の証明ではない。未知入力の拒否、全記述域の有限評価拒否、旧意味の保持、表記の往復も確認する。

次は批判を `Skandal` として扱う評価と処罰の可能性を結ぶ。原文の括弧を補足説明として保持し、処罰の可能性と許可、sogarの焦点、wenn節の作用域を文全体で確認する。
