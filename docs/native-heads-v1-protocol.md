# 固定モデルの主辞スコアと候補欠落の検査

共通参照判定器の開発評価では、正解の参照ペア920件中160件で、片方以上の主辞が上流の予測から欠けていた。主辞1,183件の欠落のうち855件は予測済みの単一トークンとして存在し、103件は複数トークンの結合で表せるが、225件は境界そのものが異なる。参照判定器だけの再学習より先に、この候補欠落を検査する。

KWJAの固定したwordモデルが既に出している「基本句-主辞」の確率を取り出す。既存の句分割では、一つの句で複数の主辞タグが立っても、一つだけを主辞として採用する。また、タグがなくても句の先頭等を主辞として返す。今回の研究用APIは、句へのまとめ方とは別に各トークンの主辞確率と候補を返す。元の解析・句・参照先を変更せず、追加候補から参照を確定したことにしない。

判定は既存モデルのタグに使われている0.5以上へ固定し、閾値の探索・語句表・入力別の補正を行わない。基本モデルの重みは固定し、今回の検査では新しい分類器も学習しない。

公式dev512文書について、既存の句の主辞、主辞確率だけによる候補、両者の和集合を同じ正解で比較する。全トークンを候補にした場合も計測するが、これは語の分割を固定した候補の網羅性の上限であり、主辞を正しく判定した成績とは呼ばない。主辞の適合率・再現率・F1・文書単位の集合完全一致、正解参照ペアの両端が候補にある割合、候補数の増加を報告する。モード付き参照はペア評価から外し、文書数と主辞評価には残す。解析失敗を分母から消さない。

これは前実験の誤りを見た後の開発診断であり、独立した最終評価ではない。testの結果を見ながら閾値や方式を調整せず、今後の学習・採用判断には別の検証を要する。Noema全文の意味精度、自然文の広い対応、短い表記の完成条件は維持する。

全件の原文解析が保存済みの固定解析と同一であることを検査し、先頭8文書は原文から二度解析して候補と確率の反復一致を確認する。コード・モデル・原文・保存記録のハッシュを記録し、中断時は文書単位で再開する。生成・辞書禁止経路の呼出しも検査する。
