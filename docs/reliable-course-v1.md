# 「確かな歩み」の通常比較と本文への接続

第五文の「確かな歩み」の対象側を、理由に支持される独立判断を継続し、各判断について通常の比較状況でもその遂行が保たれる活動へ改訂した。第四文で導入した確実性 `r2ib` を再利用する。旧草案の理由支持だけでは、現在は支持されるが通常比較では不安定な活動も成功者に数えられた。

## 同じ課題の確かさを全過程へ結ぶ

新しい `r2jh` は、一つの同じ課題について実際の理由ある独立判断 `r2gy` と確実な遂行 `r2ib` を要求する。別の課題への支持や、別の活動についての確実性を借りない。比較は空でなく、同じ本人の基盤と課題・外的機会・対応活動・通常性が有効でなければならない。比較材料の欠落は成功にも不確実性にも変換しない。

`r2ji` は旧 `h5d` の全過程と全判断を保ち、各判断へこの条件を渡す。途中の判断が不安定なら、最後だけ確かでも成立しない。判断のない準備時点、話題や理由の更新、別の活動での失敗は許す。「確か」を無誤謬性や生涯の全場面における無失敗へ強めない。

原文に比較状況の一覧が書かれているわけではない。これは第四文の不確かな跳躍との対比を保つ、明示した遂行上の読みである。比較状況や通常性を成功した結果から選び直すことは、既存の意味規約が禁じている。

## 数える性質と比喩の対象をそろえる

達成と活動の完了点を結ぶ既存の `rct` を保持し、新しい活動を `r2jm` の成功者条件へ接続した。数量前景、該当者に分配する譲歩背景、身体歩行との対応の三箇所を同時に更新した。どこかに旧 `h5k` や `h5e` が残って、別の性質を数えたり描いたりすることを避ける。

本文の変更は14番と15番の帰属である。既存の全宣言・意味規約、他の主張、十二全単位および先頭四文の判断は保持する。十八の合成定義を追加し、新しい基本記号はない。うち十七は既存定義の参照を新しい活動へ明示的に結び直したもので、対応表と構文木の比較を保存している。

身体側は、同じ活動の全過程で均衡と足の配置を制御する既存 `h4z` を保持する。これは知的活動を描く非字義的な対応であり、実際に歩けることを成功者の人数条件へ加えるものではない。

## 検査と残件

現在の理由支持と比較場面での遂行を独立に変える検査に加え、活動全体とその存在量化を実際の定義で実行する。途中の不安定さ、理由支持の欠落、指導、別課題、空の比較、基盤の交換、対応活動の欠落を区別する。数量と背景の演算は前版の検査を継承し、新しい性質を渡す構文木の一致を確認する。引用の検査では旧数量内容・旧背景・旧比喩対象の取り違えを拒否する。

自己形成の説明、解放の描写、自己活動による因果が離脱と確かな活動の双方へ及ぶ範囲は未確認である。第五文と第三段落全体の意味判断はまだ行っておらず、確認済み文字数は増やさない。
