# 「一つも許されない」の対象範囲を明示する

カント第二段落の `keinen Schritt` を接続する前に、現行の許容表現が区別できていない範囲を調べた。`hztc` は一つの目標記述への許容欠如を表す。「ある活動一般への許可がない」という条件は、個別の小さな行為も全て許されていないことを、それだけでは保証しない。

たとえば、包括的な目標を「一つ目か二つ目の活動を行う」と構成し、その包括的内容への許容は偽、一つ目の個別活動への許容は真、二つ目は偽とする。従来の包括的目標を渡した `hztc` は真になるが、「いずれの個別活動も許容されない」は偽になる。既存の規範関係は内容記述と引数を区別し、含意に沿った許容の閉包を自動では仮定しない。この解釈は現在の意味規約と矛盾しないため、「一歩も」の全称的な読みには別の構成が必要になる。これは現在の積極的許容の規約に対する反例であり、許容の論理的帰結を閉包する別の規範体系にまで同じ反例が成立すると主張するものではない。

一般定義 `rqy6` は、候補範囲、候補ごとの閉じた内容記述と引数列を受け取り、その全候補に同じ出所・名宛人・役割・極性・文脈で許容欠如を要求する。`rqy7` は同じ範囲に許容された候補が一つでもあるかを表す。許容の有無を調べる際に、対象内容を実行して行為の成功を要求することはない。禁止命令や本人の勇気も、許容欠如から補わない。

引数が適合しない候補を「許可が見つからない」として処理することは避ける。選ばれた候補の引数が不適合なら、`rqy6` は成立しない。そのため、無条件に `rqy6 = not rqy7` となるわけではない。選択候補の引数が全て適合し、許容の真偽が与えられた解釈では、この二つは反対の値になる。空の範囲に対する全称条件は真だが、候補や実行可能性の存在を主張するものではない。

既存の「勇気を伴って取り組む」内容には `rqza` を用意した。候補ごとの閉じた目標を同じ本人の `hztc` に渡して全称化する。この結果が、引用構成 `hzta` を一般形 `rqy6` に渡した場合と一致することを検査する。基本関係を追加せず、三つの合成定義だけを加える。

## 検査と本文への採用条件

四テストで、二候補の所属・許容・引数適合性の64組合せ、出所・本人・役割・引数・極性・文脈・範囲の十対照、未知入力五種を確認した。包括的目標と二つの個別目標の許容を独立に変える八組合せでは、問題となる反例と、一般形・取り組み用の構成の一致を確認した。包括的目標が二つの個別内容の選言であることも、内容を実行する四組合せで確認した。既存47文・意味規約・十一単位の判断と、通常記法・短縮記法・固有文字の往復も保持する。

現行の評価器は含意の両項を評価するため、選択範囲外の関係にも完全な解釈を要求する場合がある。空範囲なら未知の入力を一切読まない、という最初の検査仮定は失敗した。現在の挙動を確認し、範囲外が未知の場合も評価不能として返る制限を記録した。未知を偽へ補った検査結果は使わない。これは有限評価器の挙動であり、完全な解釈の下での空範囲の論理的な値と区別する。

この定義は指定された範囲を全称化するが、その範囲が「全ての一歩」を尽くすという証明にはならない。[AdelungのSchritt項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_7_2_2862)には、足を前へ置いて移動する動作、距離単位、歩き方の用法が区別されている。原文に適用するには、身体的な一歩の内容、装置外という位置条件、候補範囲の完全性、同じ先行時点の阻止・許容を結ぶ必要がある。

その接続前に有限の検査候補を原文の全候補と認定することはできないため、今回は比較構成として保存する。採用中の本文は前版の47文のままで、一文全体や段落全体の意味確認数は増やさない。次の作業は身体側の目標と範囲の構成であり、`ruhigen` と `ja`、一文全体の照合も残る。

