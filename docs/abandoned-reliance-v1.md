# 吟味のない使用傾向を自らやめる

カント第三段落の第四文にある「足枷を捨てる」仮定について、規定・定型表現への吟味のない使用傾向を自らやめるという、比喩の対象側の前件候補を構成した。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)では、捨てた者にも不確かな跳躍しかできないことが続く。このため、離脱の成立に理解力の獲得を含めない。これは採用を検討する読みであり、依存一般の唯一の定義ではない。

## 不使用と傾向の消失

一般形 `r2gl` は、比較場面、本人側の基盤を保つ条件、外的機会、通常性の優先関係、応答、極性を受け取る。全候補について保持条件と機会を確認した上で、非空の通常場面の全てに指定極性の応答を要求する。通常性は応答の成否から決めない。負極性は「肯定傾向が成立しない」の意味ではない。混合した応答、空の比較、条件不足を、応答しない傾向と扱わない。

`r2gn` は同じ本人・対象・活動での吟味のない使用と活動の生起を結び、`r2go` はその応答傾向を表す。`r2gp` と `r2gq` は、先行箇所を受ける同じ非空の対象範囲の全てについて、肯定と負極性の傾向をそれぞれ要求する。指示対象の範囲は提示文脈で固定し、前後の状態から選び直さない。今は静かにしていても使用傾向は成立しうる。吟味した上での再利用は、吟味のない使用へ戻ったとは数えない。

## 本人の作用による交替

一般形 `r2gm` は、同じ順序付き履歴、本人、過程、前後時点、二つの性質記述を結ぶ。前では旧性質だけ、後では新性質だけが成立し、同じ過程について本人への作用、本人の行為主体性、生起、変化内容、結果生成を要求する。評価する性質と、変化内容・因果結果として渡す性質記述を一致させる。前後の真偽の差だけでは本人による離脱を推論しない。

`r2gr` は二つの性質を `r2gp` と `r2gq` に固定する静的特殊化である。四つの脱引用を除き、世界の内容を実行せずに引用できる定義にする。未特殊化の一般形を引用できるように安全規則を緩めるものではない。`r2gs` は知的活動側の仮定履歴へ接続し、`r2gt` が終点に至る本人の過程を存在量化した前件候補になる。

本人側の基盤の保持は、それぞれの基準と比較場面との間で要求する。離脱の前後で同じ基盤であることは要求しない。また、元から意識的に依存を選んだ経歴、全対象を実際に使用した出来事、永久に依存しないこと、未成熟の消滅は補わない。一つの過程として対象群を扱うため、対象ごとの内部の離脱時点や部分離脱を表すには別の構成が必要になる。

## 検査と残る接続

九定義と五つの解釈入力を追加した。応答・保持・機会の64組合せ、状態と作用の1,024組合せ、前後の応答の16組合せを検査する。対象の取り落とし、他人の作用、履歴の欠落、別の因果結果、混合応答、循環した通常性、未知入力を対照にする。実際の能力定義と前件を同時に実行し、離脱の有無と能力の有無の四通りを許す。これらは有限モデルでの構成検査であり、ドイツ語との同義性の自動証明ではない。

能力との同時検査は、具体的な同一過程・前後時点を指定した `r2gs` と既存の能力定義を、同じ有限世界で実行する。過程を存在量化する `r2gt` の検査は原文側の接続検査で行う。両方を大きい世界で一括探索する試験は評価器の計算量上限に達したため、この二つを分ける。能力の真偽を仮の入力で置き換えることはしない。

新しい前件はまだ著者へ帰属する本文に採用していない。先行する54文、全宣言と意味規約、十二全単位2,212文字および先頭三文408文字の判断を保持する。本文と独立した二つの一般形・候補文書について、代用文字の短形・長形と独自文字の往復を検査する。

第四文の完成には、対象側の不確かな知的活動、不慣れによる理由、譲歩・限定を結ぶ後件と、既存の身体的描写との対応が必要になる。原文対応範囲と意味確認済み分量は増やさない。
