# 密度式の配置と共通の零出来事

密度式の二系配置へ、既存の共通零条件を接続した。数値だけが一致する二つの出来事を、一つの出来事として扱わない。同じ文脈で一つの出来事が両系に割り当てられ、両系の原点に位置することを要求する。基本関係は追加せず、合成定義を二つ加えた。

`sexu(event, context)`は、出来事の型、両系の四成分記録の有効性、既存の`smk`、静止系の実際の原点割当と配置を結ぶ。動く系の原点割当と配置は`smk`が既に要求する。`smk`の静止系条件は厳密には`x−vt=0, y=z=t=0`、動く系は四成分とも零である。零時刻の条件を外して、動く原点にいる任意の出来事へ広げるものではない。

`sexv`は従来の`sext`をそのまま要求し、同じ文脈で`sexu`を満たす出来事の存在を加える。二系と符号付き速度、物理的配置、方向記録と座標差、各所有系での正方向を引き継ぐ。二つの原点物の識別子を同一にする条件は加えない。一つの共通零出来事から、すべての出来事の座標時刻や物理的な時計指示が一致するとは判断しない。

[累積本文](../examples/v014/einstein-density-origins.noema)の密度式の引用内で、配置引数だけを`sext`から`sexv`へ変更した。他の205文と既存の全宣言は保持する。[抽出本文](../examples/v014/density-origins-manuscript.noema)は実際の累積本文の当該文から依存定義を抽出したもの。原文に新しい主張を追加していないが、採用する配置条件を強めたため、旧版との無条件の意味同値は主張しない。

固定した原文資料では、u0064に動く系の原点での`τ=0`と`t=0`の約束がある。u0085では初期位置と時刻の原点を仮定しない場合、変換式の各右辺へ加算定数を付けると説明している。今回は既存の零定数の座標変換を用いる密度式の読みへ接続した。一般の原点移動は既存の独立加算定数の記述で区別され、今回の条件へ自動的には含まれない。これらの参照は文脈の根拠であり、原文の全適用事例が新条件を満たすとの確認ではない。

検査では、抽出本文と累積本文それぞれ30例を評価する。八つの成分の個別変更、原点と時刻の共通移動、別々の出来事の零座標、座標割当の系・文脈の取り違え、原点候補だけで実際の割当・配置がない例、無効な出来事・記録・成分・役割を区別する。指定した一つ目の出来事が条件を満たさず、二つ目が共通の証人になる場合も検査し、存在条件を一つの固定名へ狭めない。

`smk`・`sha`・`sexu`・`sexv`の本体を評価する一方、座標割当`shd`と先行配置`sext`は型を保った外部条件として与える。算術は構成済み有理切断に対する正確な演算である。この検査は物理的な測定や先行配置の全定義を実行するものではない。既存宣言を変更していないこと、先行配置が偽なら新配置も偽になることを別に確認する。各本文の4例はキャッシュなしでも比較する。未知の座標・割当・有効性は補完せず評価を拒否する。

引用帰属の8組合せでは、物理条件を実行せずに内容を保持する。通常・短縮・固有文字の表記往復、意味規約、CLI解析も確認する。原点割当・位置関係・座標割当の物理的充足、測定と校正、慣性系、電気的帰属、物質軸全体、全適用事例と全文の意味確認は未完である。[密度式の確認記録v11](../data/density-formula-review-v11.json)も部分的な接続として扱う。原文対応範囲と意味確認済み区間数は増やさない。
