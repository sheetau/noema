# 別の定義と理論比較の慎重さ

原刊919頁のu0259全文を対象にする。前半は、同じ動く電子について力・加速度の定義を変更すれば質量の数値も変わるという条件文。後半は、そこから電子運動の異なる理論を非常に慎重に比較しなければならないと導く文である。

前半の計画は、元のkの力とKの加速度、同じ単位・物理設定を維持した操作的再定義、全応答での係数同定、元との数値差、仮定範囲を分けることとした。既存emf、enn、ek75、enkを使う。enp/enqが同じ46役割から元の量を取り、eiszc/eiszdが物理的定義の採用と変更を対応させる。再評価mapを任意の係数合わせと同一視しない。

enr/ensは三成分の全応答に同じ縦横係数が適用できることを表す。縦と横の非零応答を必要とし、零の一例だけでの係数同定を避ける。entの選択条件に差を入れず、enuの結論にだけ元のμβ³,μβ²との差を置く。env/enwは、文脈上関連する別定義が非空で、その全てについて新たな係数が得られるという著者の条件文である。全ての想像可能な定義への無制限の主張にも、一つの成功例の存在にも替えない。選択範囲は結果の良否より先に固定する。

同じkの実加速度へ替える既存例では縦β³・横β²という変換がある。eny/enzはそのmapを同じ履歴へ接続する。v=0では係数は一致するし、力・加速度を補償して変更すれば動いていても係数は保たれ得る。このため関連範囲と動く電子という文脈を明示する。原文の物理的な主張があらゆる場合に真であることをNoemaの記述完成条件にはしない。

後半は、体系的な理論の範囲eisvd、電子運動法則の範囲vd/eisxn、理論の内容への所属eiszfをen2へ結ぶ。en3は同じ比較主体・左右の理論・活動を固定する。en4は非空の関連事項すべてへの持続的な吟味に、既存seqmの意味・単位・事例対応を確認してから不一致を結論する手続きを合わせる。この手続きを唯一の辞書的な慎重さとはしない。en5はその程度が通常基準を大きく超えるというsehrを加える。

en6は同じ主体・活動がen5を行うべきという要求であり、現実に比較を実施したとも遵守したとも述べない。Natürlichはzdgによる明白さの提示、man ersieht darausはzcによる著者の推論帰属である。en7/eoa/eobで二句と前の二質量への照応、著者・論説、本文順序を接続する。前半の数値差から方法上の規範が論理的に自動導出されるという証明にはしない。
