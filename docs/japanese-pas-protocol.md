# 日本語学習済み解析器の辞書を使わない転用

KWJAの文字・単語モジュールを固定して使い、日本語の句と述語項の関係を取り出す。公開ソースは `821df300630b4d05c38406945536eaac848619da`、配布重みは `ku-nlp/kwja-checkpoints` の `4c5db234089ca9e524fc5d32d383bc45e6fe27a2` に固定する。baseのcharとwordだけを使い、typo・seq2seq・生成・プロンプトは使わない。

標準のWordModuleWriterは原形・意味の辞書検索を含むため呼び出さない。文字・語の境界、品詞、基本句、基本句の特徴、項の選択は学習済み分類器の出力から得る。原形を表層形のまま保ち、読み・辞書の意味属性は付けない。入力を書き換える正規化も実施しない。必要な形態素の型やBIOなど、出力形式上の整合性は翻訳規則と区別する。

初回は、既存の `srl-span-v1` と `srl-boundary-v1` の日本語24文を再利用する。新しい独立評価ではない。原文から文・語・句を予測し、正解の述語位置や項の範囲は入力しない。原文の文字位置を保持し、上限超過や分割で失われた入力は拒否する。

モデルの「ガ」「ヲ」「ニ」などはそのまま保存し、Noemaの主体・対象や英語SRLのA0/A1へ固定対応させない。能動と受動で同じ意味役割になったかは、元のラベルと対象を見て診断する。ガ格を主体として数えた成績で受動態の解決を主張しない。

指定した述語に対し、注釈された内容を含む項が得られるかを役割を問わない診断として集計する。これは意味役割の正解率でも全文意味構造一致率でもない。全基本句・元の関係ラベル・文外参照候補を保存し、主体の省略を著者等として確定する挙動も調べる。省略補完をNoemaの意味本体へ自動採用しない。

公開の分類器・前処理・句の組立てを再利用する範囲と、省いた辞書・正規化・出力処理を記録する。辞書や生成の経路に到達したら検証を失敗させる。反復一致、原文位置、実行条件を検査する。日本語の学習済みモデルを動かせても、広い自然文を翻訳できる完成条件と95%の意味構造一致率は引き続き必要である。
