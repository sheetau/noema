# 転倒の経験から歩行能力を得る見込みを結ぶ

カント第二段落末尾の学習の理由節に、身体側の能力取得とその見込みを追加した。既存の記述には、知的な不成功経験による能力取得の見込みと、その経験を転倒として描く対応があった。今回、身体側にも取得過程と見込み全体を構成し、同じ本人についての知的側の見込みを描く内容として結ぶ。

## 身体の動作と能力を分ける

歩行の目標は、同じ身体が足で支持し位置を変え、他者や装置による身体支持を受けない既存の `zal` とする。これは第六文の確認で採用した広い足移動の読みであり、特定の歩容を追加しない。

能力は現在の移動実行ではない。既存の `rqvm` と `rqvn` を用い、その本人の現在の技能基盤を保ち、外的な機会がある通常場面で、既有の技能を行使して達成できる方法があるかを評価する。未分類の方法や未評価の結果を不能の証拠にせず、これから技能を取得する方法を、既にその技能を持つ証拠へ流用しない。

この評価に必要な六つの文脈関係には、対象活動の記述を明示的な引数として加える。候補・基盤の保持・外的機会・通常性・方法範囲・範囲の判定を分け、同じ身体移動 `zal` に結ぶ。知的活動の評価用プロフィールを無条件で借りない。六関係は他の活動の評価にも使えるが、採用するプロフィールの根拠は利用する文脈で説明する必要がある。

## 同じ経験が同じ取得に寄与する

`r2aw` は、同じ本人の同じ過程について、文脈上の少数回の経験を非空の順序付き列にする。各経験は既存の `hzum` による転倒であり、足支持の姿勢から制御せず下降し、身体が下方の支持面に接する。別人や別の経験の転倒は使わない。

既存の取得構成 `r5` に、身体側の能力と評価条件を渡す。前状態では評価済みの能力がなく、後状態ではあり、各経験がその同じ変化に寄与することを要求する。回数が多いだけ、時間順に出来事があるだけ、別の過程へ寄与しただけでは成立しない。ここでいう取得は能力の欠如から保有への変化であり、既にある技能の連続的な熟達とは分ける。

`r2ay` は、その取得が、指定された非空の将来候補の全てで成立するという見込みを作る。回数の基準は見込みの元の文脈に保つ。現在の候補を将来と扱わず、候補の一部だけで成立する場合も受け入れない。

理由節の `r2az` は、知的側の見込み `fr` を、この身体側の見込みとして非字義的に提示する。経験・過程・時点・候補の索引は既存のものを使って対応させる。両側の真理値や実現、実際の出来事としての同一性を要求しない。身体側だけが成立し、知的側が成立しない解釈も可能である。

## 検証と未完了の範囲

五テストで、能力評価の十対照と必須の未知入力七種、取得の十七対照と未知入力三種、知的側と身体側を独立に変える四組合せ、将来候補の三対照と未知入力二種、帰属の七対照と未知入力を検査する。身体の能力と転倒、経験列と寄与、見込みには実際の定義を用い、途中の定義を検査用の基本関係へ置き換えない。複合した内容の評価には純粋な結果キャッシュを使う。引用した提示の検査では、世界の内容を全て未知に保つ。

追加は七定義と六つの活動別の能力評価関係、本文一文である。既存50文と意味規約、十一単位の意味確認、第二段落先頭六文の1,021非空白文字の判断を保持する。通常・短縮記法・固有文字の往復も照合する。

今回の構成は、既存の取得と将来候補による部分的な読みを身体側にも接続したもの。`würden`・`wohl`・`endlich` の作用、危険の程度、萎縮と通常の回避を含む末尾一文の判断は残る。末尾190文字や段落全体を確認済みとは数えず、原文対応範囲も増やさない。二作品全文の完成と基本関係の構成的説明は引き続き未完了である。
