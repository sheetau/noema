# 批判を伴う提示への許可と、強調の背景

カント第16区間の `sogar` に、批判を伴う比較提案への許可を強調する読解候補を接続した。元の安全性・統治者の認識についての主張は保持し、強調を支える背景を別の内容として著者へ帰属する。[本文草案](../examples/v016/kant-focused-permission.noema)は1,510宣言・17文、最後の帰属文に必要な[抽出文書](../examples/v016/focused-permission-core.noema)は136宣言・1文である。

## 比較する条件をそろえる

`rtm` と `rtn` は、許可の出所・本人・役割・行為・規範関係を固定した枠を作る。`rto` は同じ枠に、批判を伴う比較提案と、比較提案の行為記述を渡し、二つの許可内容を構成する。後者は批判の不在を要求する記述ではなく、批判の追加条件を含まない比較基準である。行為記述間の含意から許可を自動で移す規則は設けていない。

`rtp` は、構成に用いた本人・行為の閉じた参照が、選択した本人・行為を実際に指すことを確認する。別人の許可や別の発言の尺度を混ぜて背景を成立させることはできない。

本文の `hzrpackage` は著者の視点と原文の基準文脈を使う。対象者・活動の選択もその文脈に固定し、`hzrbackground` が各選択対の参照整合性と尺度条件を要求する。選択範囲が空なら普遍条件は空虚に真となり、人や発言の存在を補わない。

## 元の主張と背景を別々に帰属する

`rtq` は既存の主張帰属と、同じ主張に背景を付す帰属の両方を要求する。本文の `hzrattribution` では、従来の箇所・著者・主張内容・主張範囲・文脈を保ち、背景内容と背景の原文範囲を別に渡す。引用した内容は帰属の検査時に実行しない。

親文書の1,477宣言と先行16文を保持した。元の `hzqpolicy`・`hzqsafety`・`hzqinsight` に背景条件を足していないため、強調の成立と、安全性や統治者の認識の成立を区別できる。

今回は尺度条件だけを背景にする。許可についての見通しを述べる箇所に、比較対象の許可が現在既に成立しているという条件を補わない。尺度は「許可としてより際立つ」という明示的な入力関係であり、確率へ固定していない。この焦点・比較対象・視点は一つの読解候補であり、唯一の解釈を確定したものではない。

## 検証と限界

52テストが通過した。対象の選択、尺度、本人と行為の参照、許可の真偽を変える32組合せに加え、別視点・別文脈・逆の順位、未知の解釈、主張だけの否定、帰属先の取り違えを検査した。元の主張の帰属と背景の帰属の四組合せも区別した。

今回の有限モデルでは、前段で検査済みの複雑な行為構成を二つの閉じた行為記述へ置き換え、実際の新しい比較枠・背景・参照検査を評価している。複合行為そのものの全意味を今回の52テストだけで再検証した結果ではない。実際の本文では既存の行為構成を参照し、焦点と比較対象に同じ人物・活動・文脈を渡す構造を確認した。
