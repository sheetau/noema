# 任意に小さい電荷の追加と可能な結果

u0260後半の「任意に小さい電荷を加えて、ここでいう電子にできる」という部分を記述した。任意に小さいとは、同じ対象・単位・元の状況について、どの正の有理数上限を指定しても、その上限より絶対値が小さい非零の追加量を持つ操作と結果状況が存在するという条件である。操作と結果は上限ごとに変えてよい。一つの固定した小さい電荷を選ぶだけでは、この条件を満たさない。

同じ操作と対象に許容された結果状況で、電荷の値が「元の電荷＋追加量」と一致することを要求する。対象は元と結果の両状況で点状として扱われ、結果の電荷は零でない。負の追加量や既に荷電した対象も許すが、追加によって電荷が相殺される場合は、この結果条件を満たさない。電荷の追加という関係は数値の変化とは別に保持し、数値の差だけで操作を補わない。

可能性の記述は、現実に操作が実行されたという主張とは分ける。選んだ可能な結果が条件を満たすという読みであり、全ての実行結果で成功するという保証までは含めない。原刊919頁と照合し、この箇所の電子を著者が呼称した点状の荷電対象として扱う。現代の特定の粒子種への変化とはしない。

有理数については、任意の正の上限の半分と負の半分が数量条件の証人となること、固定した非零電荷はその絶対値を上限にすると失敗すること、正の単位倍率で数量条件が保存されることを一般命題として検査する。これは可能な物理操作が存在するという証明ではない。有限評価では指定した上限の事例を検査し、全有理数上限の評価を要求された場合は未対応として拒否する。

正の実数上限についても、その下に正の有理数を選べるため、全有理数上限の量化で任意の小ささを表せる。この順序の性質を全実切断について機械的に証明する実装は残る。物質点・電荷・操作・物理的に可能な結果の基礎説明、前半の質量結果への適用拡張と理由接続、原文全体の意味一致も未完である。
