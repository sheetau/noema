# 継続条件を含む政策の統合検証

前版で未検証だった、継続条項を含む政策全体の有限評価を通過させた。同じ条項を合意・維持の目的・保護する活動へ渡す定義を、そのまま評価している。基準作例は13個体・10状況で、以前の6,400万ステップの上限に対し、新しい検証器では6,413,339ステップで結果を得た。

計算量を増やしていたのは、同じ構文と束縛から関数を繰り返し作り、その関数を引数にした式を再評価する処理だった。[新しい検証器](../noema/higher_order_semantics.py)は、同じ構文と自由変数の値から得た結果、同じ名前と引数による呼出し、同じ関数と引数による適用結果を、評価一回の内部で再利用する。新旧検証器の構文木を比較し、演算の本体、型検査、量化する領域、引用・脱引用、内容の評価方法が保持されていることも確認した。

この再利用には、原始記号の解釈が決定的で、Noemaの値に従うという条件がある。関数の返す意味、列の順序と要素、記述の構文を使って判断し、Pythonオブジェクトの割当て回数や同一性によって意味を変えない。診断用の呼出し回数は数えられるが、それを返す値や例外の条件に使う解釈は対象外である。新しいモジュールを選ぶことが、この条件を採用する明示的な操作になる。既存の検証器と過去の検査記録は保存した。

関数の再利用では、異なる関数を少数の入力で比較して同一視することはしない。同じ構文でも、捕捉した値が違えば別の構成として扱う。関数を引数に取る場合のキーはその関数の同一性であり、意味が等しい別の関数を推測してまとめない。引用は構文の同一性を保ち、別の評価で発行された記述を脱引用することは引き続き拒否する。

内容は、与えた全状況について評価する。論理演算の両側も従来どおり評価し、現在選ばれていない状況や偽の前提の後ろにある未知の値を隠さない。型検査に成功した結果だけを再利用し、例外を成功結果として保存しない。キャッシュは文書・モデル・評価の境界を越えない。

統合検査では、原文付き文書と抽出文書のそれぞれについて、基準例、保護する活動の不一致、政策未実施を検査した。さらに将来の状況を一つ加え、現在の新制度と旧制度は成立したまま、変更側の新制度だけが将来失われる場合と、維持側の旧制度だけが失われる場合を分けた。基準例は成立し、活動の不一致・政策未実施・二種類の将来の喪失は不成立になる。計12例を、継続条件を外さず評価した。

新旧検証器を直接比較した合意・目的の16通りは、すべて同じ結果になった。前版に保存された制度状態の政策三例とも一致する。追加26テストと従来の再利用処理に関する15テスト、計41テストが通過した。捕捉した値、関数の等価性、列の順序と重複、質問への回答、記述の同一性、未知の将来、領域の制限、型と計算量の検査を含む。

[検査記録](../reports/continuing-policies-v1.json)は各例の結果・ステップ数・再利用件数と、使用した入力のハッシュを保存している。この検証は明示した有限モデルについての確認であり、検証器一般の意味保存の機械的証明ではない。原始記号、Noemaの定義、著者主張、原文の対応範囲は増やしていない。宗教制度の具体的な内容、当事者の判断、代表資格、君主の位置、著者帰属と全文の意味確認は残る。
