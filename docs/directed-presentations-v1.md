# 条件付きの内容を相手に示す

カント第二段落の「後で危険を示す」という箇所に、提示する人・受け手・話題となる人・提示内容を結び付ける部分草案を追加した。危険を告げたという事実から、その危険が実在することや、受け手が理解・納得したことは導かない。

## 一つの行為に結び付ける

一般定義 `r2` は、非空の提示者群と受け手群について、同じ提示行為への関与を要求する。提示者は示す側の役割を持ち、各受け手には、その受け手へ対応付けられた対象についての発話記述が示される。一般形では、受け手と話題の対象は別人でもよい。今回の原文では同じ人へ対応付ける。

発話記述は、対象から発話への閉じた関数を引用したものである。提示の成立を検査する際には、その関数が述べる内容を評価しない。主張と質問は同じ命題内容を持ち得るが、異なる発話として扱う。新しい構文や実行時演算子は追加していない。

一般定義 `r3` は、現在とは異なる先行状況に前提が成立することを要求する。原文の接続 `ex` は、現在の提示対象者を固定した上で、それらの人々への先行する制約を既存の `er` で調べる。過去の状況で対象集団を選び直すことはしない。

## 条件と危険の程度

| 定義 | 内容 |
| --- | --- |
| `et` | 自立した活動について、不利益となる結果の可能性がある |
| `eu` | 非空の仮定状況の範囲で、自立を試みるなら `et` が成立する |
| `ev` | `eu` を主張する発話の対象。文書でその主張を実行するものではない |
| `e2` | 仮定状況の中に、試みるという前件が成立する例がある |
| `ew` | 後見人の集団が、対象者それぞれへ `ev` の記述を示す |
| `ex` | `ew` と、同じ対象者への先行する制約を接続する |
| `e3` | 不利益の可能性はあるが、既存の「非常に高い」危険度の基準は満たさない |
| `e4` | 非空の対象者群の全員について `e3` が成立する |

全仮定状況で前件が偽なら、条件 `eu` は成立し得る。適用例の存在は `e2` で別に表し、原文へ無条件に付け加えない。実際に試みたことも、現在危険があることも、条件を示しただけでは確定しない。

後続の「それほど大きくない」は `e3`・`e4` に部分的に対応させた。「それほど」の基準を先行する非常に高い危険度へ結び付ける解釈である。危険の不在、非常に高い危険、危険はあるがその基準に届かない場合を区別する。程度基準の解釈と、譲歩・理由の接続は未確定である。

## 検証と残る範囲

提示役割32例、時間条件64例、仮定条件16例、原文接続13例、程度4例を検査する。提示者や受け手を別の行為へ分散させる例、別人への警告、質問との取り違え、前後の逆転、効果のない制約、対象者のない集団を区別する。提示内容を評価しようとすると例外になる検査モデルも使い、提示と内容の真理が独立していることを確認する。

一般文書は基本述語0・定義2、原文へ接続した文書は累計基本述語125・定義174である。追加した基本述語は提示関係・提示者の役割・仮定状況の選択であり、自然言語からこれらを自動判定するものではない。過去の妨害は前回の明示的モデルに依存する。現実の機構まで立証した結果ではない。

原文の `zeigen` が持つ証拠提示の強さ、文字通りの歩行と歩行器・家畜の描写、先行する認知状態の変化、転倒による学習、萎縮、譲歩と焦点は未記述である。既存の8件の本文主張は変更せず、今回の定義を原文全体の意味が確定した主張として追加していない。二つの対応範囲はいずれも部分的な解釈草案である。
