# 公衆に及ぶ革命の結果

[第四段落](https://korpora.org/Kant/aa08/036.html)は、公衆の自己啓蒙が遅いと述べた後、革命による離脱と、思考様式の真の改革を対比する。後半では新しい偏見と古い偏見の作用を比べる。今回の読みでは、第五文の結果を公衆に及ぶ変化として扱い、革命をきっかけに一人が考え直す可能性まで否定する主張にはしない。

## 同じ活動の結果を集める

先頭文と同じ公衆の範囲・全読者列・候補経過・期間枠を使う。政治的な共同体は、公的な議論の宛先としての公衆と別の参照で与える。

`r2qt` は、同じ共同体に実施される専制と、利益欲または支配欲を持つ圧迫からの個人の離脱を構成する。`r2qu` は個人の思考様式の改革を構成する。どちらも既存の結果定義を同じ時間枠へ結び、各人の過程と完了点が異なることを許す。誰かの支配者・過程・状態を別人の条件の代用にしない。

`r2qr` は、同じ革命が同じ候補で同じ個人結果を生み、その結果も実際に成立する人の比率を求める。全読者の一部だけを母集団にしたり、別々の革命の成果を一つに合算したりしない。

政治的離脱と判断の仕方の変化では、広がりの文脈基準を別に与える。基準を結果から逆算せず、原文に固定値・過半数・全員を補わない。各基準は0と1の間にあり、実際の比率がそれを厳密に超えるという明示した読みである。閾値や対象範囲が原文の文脈に適切かは解釈上の要件であり、数値例の検査からその唯一性は導かない。

## 二つの結果と量化範囲

`r2qy` は、政治的離脱を公衆へ広げる革命と候補が少なくとも一つある一方、思考様式の改革を公衆へ広げる革命と候補はないとする。改革を否定する活動の範囲を、政治的離脱に成功した活動だけへ狭めない。個々人については、小範囲の改革があっても、公衆の改革という基準に達しない場合を許す。

閉じた結果記述に使う公衆と基準文脈は、元の参照と一致することを検査する。全候補の時間枠も検査し、無効な時間枠で第二結果が失敗しただけのケースを不可能性の根拠にしない。

`r2qz` は先頭四文と同じ非空の公衆範囲について内容を一般化する。`r2ra` は、その閉じた内容を著者と第五文前半の箇所へ帰属し、第四文からの本文順序を保持する。帰属は、著者の予測が現実に正しいという証明ではない。
