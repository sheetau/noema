# 二場合の同じ相対運動

同じ二物体を二つの場合へ置き、同じ物質点と標識点の識別を保って相対配置の履歴を比較する。各場合の評価系・文脈・座標・軸は別引数であり、絶対座標の一致は要求しない。長さと時間の単位、参照物体の原点・方向点・平面点は共有する。別の物体や点を、同じ形のものとして黙って置き換えない。

eiavは時刻原点の定数差を結ぶ。第二区間の始点と終点は第一区間に同じoffsetを加えた値であり、両区間は有効で非零の幅を持つ。比較する時刻も第二時刻＝第一時刻＋offsetとする。この対応は第二区間全体を尽くし、経過時間を保存する。逆向きの再生、再生速度の変更、途中だけ速く進む対応は同じ運動として扱わない。

eiaxは、この時間対応と、同じ全成員範囲を使う二場合の既存履歴eiarを結ぶ。eiayは参照物体の全成員の局所位置を始点で照合する。各場合で既存eiaqが参照配置の剛性を要求するので、この照合によって参照側の形・寸法を途中で変更できない。三標識点だけを見て、別の部分の形が違うことを見逃さない。

eiawは同じ一点・指定した二時刻の全三成分を照合し、eiazはこれを経過時間対応と対象成員の範囲へ結ぶ。eia2は全対象点と区間の全実時刻についてこの照合を要求する。形の同じ軌道や始終点だけの一致、中心間距離の一致、物質点の交換では満たさない。参照物体を含む共通の配置変換があっても、同じ物体軸での履歴が一致する場合は比較できる。

eia3では、第一の場合の左側の運動と右側の静止、第二の場合の左側の静止と右側の運動を既存の区間定義eiag/eiahへ結ぶ。eia2自体は双方が相対静止する同じ履歴も比較するため、二場合の運動・静止の役割はこの別条件に置く。比較内容を定義したことで、二場合が現実に実行されたという事実を加えるわけではない。

有限検査は、原点の正負の時刻差、時間幅、全引数の接続、参照形状、対象の各成分と物質点、途中だけ異なる経過、速度変更、二場合の運動・静止の割当を区別する。実数全域のeia2は有限評価を拒否する。個々の照合を通した時刻列を、連続する全履歴の証明へ変換しない。

磁石と導体への適用では、座標以外の物理的な性質、マクロの記述尺度、剛な参照配置を採る根拠、比較する二場合の範囲が残る。今回の一致条件から電流や電磁現象の一致は導かず、通常の理解への帰属と原文全体の記述も未完である。既存207主張と著者表示の判断を保持し、新たな原始関係は追加しない。
