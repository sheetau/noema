# 仮定の範囲と、曲線の時計の帰結

[条件付きの論述](../examples/v014/conditional-discourse.noema)では、内容の真理、著者が仮定として採用すること、その仮定の下で帰結として述べることを区別する。0.14の既存文法に、一般的な談話の意味規約3つと定義1つを追加した。数学の内容を引用して帰属するだけでは、その内容を実行したり証明済みと認定したりしない。

## 仮定・主張・証明済みという位置付け

| 記号 | 関係 |
| --- | --- |
| ug | 著者が、文章箇所の内容記述を、指定した推論範囲の仮定として採用する |
| uh | 著者が、文章箇所の内容記述を、その推論範囲内の主張として提示する |
| ui | 著者が、先行箇所を既に証明されたものとして扱う |
| vd | 仮定と帰結を同じ著者・文脈・推論範囲へ結び、本文順序と帰結としての提示を要求する |

ug・uh・uiは談話の基本関係であり、実際の原文から自動で認定する機能ではない。今回の原文確認に基づく帰属を明示する。これらを一般的な行為や認識の定義へ還元する作業は残る。vdは従来のvbを用い、仮定箇所が帰結より前にあり、その箇所を根拠として著者が帰結を提示することを要求する。

内容は0.13以降の型付き記述`i[e]`として渡す。同じ推論範囲に置かれたことを、その内容が真であることへ自動変換しない。従来の無条件の主張への帰属ucとも区別する。仮定と帰結の範囲が異なれば、vdは成立しない。

例えば「0=1を仮定して、0=1を結論として述べた」という発話への帰属は記述できる。そのことから0=1を真とはしない。また「0=0から0=1を導いたと著者が述べた」ことも、論理的に正しい推論だったこととは別である。四つの真偽の組合せを検査し、帰属と内容の評価を分離した。

## 曲線の時計への部分適用

[アインシュタインの論述草案](../examples/v014/einstein-curve-discourse.noema)は、積分の定義群と時計の観測関係を組み合わせ、24基本記号・62定義からなる。基本記号24個には、既存の算術4個、再利用した時計関係5個、汎用の談話関係9個、文書内の局所参照6個を含む。時計関係は衝突しない別名ta〜teで再利用し、対応元を意味規約へ記録した。

| 定義 | 内容 |
| --- | --- |
| qa | 閉曲線、速度成分、連続した正の進み率、光速との関係 |
| qb | qaと、同じ場所の二時計についての出発・帰着の指示 |
| qc | qbの各ケースで、移動時計の指示差が進み率の積分に等しい、という拡張を採用する内容 |
| qd | 一定の速度の大きさと正の係数のもとで、帰還時の指示差を区間時間と係数で述べる、厳密なモデル帰結 |

qbでは静止時計の出発時と帰着時の指示をlower・upperにそろえ、同じ時間単位と指示原点を使う。移動時計の出発指示もlowerで一致させるが、帰着指示readingは積分値へ固定しない。**qbに積分法則を埋め込んでから、同じ法則を帰結として提示する構成にはしていない。** 積分と実際の指示差を結ぶ部分はqcへ分離した。

本文では、先行の折れ線の結果を著者が証明済みとして扱うことをuiで記述し、qcをug、qdをuhで同じ推論範囲へ置く。qcやqdを無条件の数学的主張として実行しない。特に、帰属の検査中に算術や物理関係が呼び出されたら失敗する検査を設けた。

## 原文と一致していない部分

対象はu0128の「曲線にも結果が成立すると仮定する」導入と、その下での帰還時計の帰結である。[対応記録](../reports/curve-discourse-v1.json)は原文を、仮定の導入・帰還時計の帰結・地球上の時計の推論の三区間へ分け、前二つを部分対応、最後を未記述とした。

qdの式は`区間時間 × (1 − 正の進み率の係数)`という厳密なモデル式である。原文M0241の二次近似`(1/2) × 区間時間 × (速度/光速)²`とは異なる。前段から引き継ぐ高次項の扱いと、この近似への接続は今回の草案では未完としている。厳密式を書けたことを、原文の近似表現を完成させたことに数えない。

また、qbは幾何学的な曲線と端点の時計の指示を併記する段階にある。実際の時計がその曲線をたどる世界線、長さ単位、光速度の観測、加速の法則の物理的根拠は未完である。先行する折れ線の結果の内容も、局所参照wbへ完全には接続していない。uiは著者の「証明済み」という位置付けを保持するだけである。

原文全体と同義な完成訳ではなく、数学的なモデルと仮定の論述を分ける言語機能を接続した段階である。確認済み全文単位はアインシュタイン0/282、カント0/20のままである。

