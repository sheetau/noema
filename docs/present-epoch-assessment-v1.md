# 現在の人口・時代と到達判断の接続

第七段落冒頭の問答では、「啓蒙された」という到達状態と、「啓蒙の進む」という過程を区別する。既存の草案には、選んだ人々の全員が無修飾の能力を持つことを到達とする版と、集団基準や質を明示する後の版がある。今回は後者を使うために、同じ現在人口・時代・現在点を固定する接続を追加する。第一文の全文判断はまだ行わない。

`r5sb/sc` は時代の非空の区間に現在点を置き、同じ現在点に生存する人間と集団所属が過不足なく一致すること、発話の基準主体がその集団に属することを求める。`wir` を同時代の人々一般と読むための候補であり、能力を評価できた人だけを集めたり、過去に生存した人を現在の人々へ混ぜたりしない。

`r5sd`–`r5sg` は既存の集団到達基準を同じ人口と現在点に適用し、評価の充足、到達、進行、未到達かつ進行中を分ける。全員の評価が整うことと全員の能力保有は異なる。基準の両端条件だけでは中間分布の単調性や妥当性は決まらず、原文への採用時に基準の意味を固定する必要がある。過半数や全員一致を暗黙の語義にしない。

`r5sh`–`r5sm` は現在点を固定した問い・回答と、否定側・肯定側の内容を作る。外側の評価点が変わっても、原文の `jetzt` を別時点へ替えない。質問と主張の発話種別を区別し、実際に誰かが質問した出来事や著者の提示はまだ追加しない。

`r5sn`–`r5sq` は質を含む活動記述 `hzvr/hzvs` へ接続する。同じ本人の全対象事項・現在・基準文脈・質の記述を保持するため、無修飾の `h4l` のプロフィールを流用できない。質の基準を能力評価の後から緩めることも許さない。

検査は現在人口の欠落・混入、話者不在、時代の境界、評価欠落、集団外の能力、到達と進行の四組合せ、閉じた問答の現在点、質付き評価への引数接続を確認する。具体的な宗教的範囲、`sicher und gut` と集団基準の採用、進行内容、条件付きの問いの提示と著者帰属は残る。検査成功から意味確認済み文字数は増やさない。
