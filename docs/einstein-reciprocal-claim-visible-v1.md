# 相互静止から相反積への推論を円文字へ接続する

u0095–u0096を、原刊901頁末から902頁冒頭へ続く第50段落の二文として参照する。第一文の前半は空間式に時刻が現れないことから相互静止へ進み、後半は恒等変換の必要性と明白さを述べる。第二文は「Es ist also:」からφ(v)φ(−v)=1の表示と句点までを含む。固定転記の空白欠落「[M0162]und」は保存し、明示した空白区切りで位置を数える。

既存16定義を再利用し、三位置の最終式、両方向の相互静止、全対象出来事での四座標値の恒等性を結ぶ。相互静止は全固定配置・全比較時点で要求する。同じ値を持つ別の記録を許し、KとK′を同一個体にはしない。三つの推論と恒等性の明白さは、同じ著者・論説・本文順序へ帰属する。

積1には、2と1/2や負の相反する値も適合する。そのため各値1、偶関数性、正値性をこの箇所へ追加しない。また、著者の推論を記述するために、原文にない校正条件や非零の証人を補わない。有限モデルによる引数・作用範囲の検査と、推論の物理的な正しさは別に扱う。

語彙は既存の任意プロファイル55・796語をそのまま使う。新しい基本語・意味規約・参照型は不要で、共通375語とアルファベットも維持する。検査では原文への逆投影、復号した定義の有限対照、引用の非実行、独立CLIでの復号、描画点検を区別する。
