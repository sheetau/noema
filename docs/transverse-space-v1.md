# 横方向の光線とη・ζの式

アインシュタイン§3の `u0073`〜`u0080` を部分記述した。y方向の光線について `η=Vτ` へ同じτの式を代入し、`t=y/√(V²-v²)` と `x′=0` を使って `η=a*V*y/√(V²-v²)` を得る過程を記述する。z方向は別の光線・出来事に同じ型の条件を適用し、`ζ=a*V*z/√(V²-v²)` へ結ぶ。

`soa` は選べる軸をy,zに限り、縦軸を含む三役割が異なることを要求する。`soc` は選択した横軸について、両系の区間記録を同じ光・同じ始終出来事へ結ぶ。共通零点、正方向、運動系で軸に沿う光路、両系の時計と座標、先行するτとの一致を要求する。到達点ではx′=0、運動系のξ=0、非選択の横座標=0となる。

静止系から見る光路は斜めになる。その光路長を、縦変位と選択した横変位の平方和へ結ぶ。横変位だけを光路長にしてはならず、平方したとき同じ値になる負の長さも拒否する。これは直線的な幾何を明示的に要求するモデルであり、物理的な全光路の幾何を証明したものではない。

`sod` はこの幾何に、両系で同じ全速さVを測る法則、同じ局所区間の速度条件、同じτの式を加える。`soe` は選んだ軸の運動系座標=Vτと、τの式を代入した値の両方を記述する。`sof` は静止系の横成分 `w=√(V²-v²)` を使い、横距離=w*t、t=横距離/w、x′=0を結ぶ。`sog` はその値を代入した空間座標の式である。

`soh` は軸に対応する両系の記録を選び、`soi` はy,z両方の前提を要求する。一方だけが成立する場合を両方向の議論として受理しない。本文のy方向の等式列、時刻とx′の付帯条件、代入後のη、同様に得られるζを別々の帰属として記述した。z方向の省略された時刻条件も前提として明示し、y方向の到達出来事をそのまま流用しない。

検査例ではV=5、v=3、a=2、w=4とした。y方向の到達点は静止系でx=6,y=8,t=2、運動系でη=20,τ=4である。z方向は静止系でx=9,z=12,t=3、運動系でζ=30,τ=6である。静止系の光路長はそれぞれ10と15であり、横距離8と12より長い。この二つの値を使い、yとz、静止系と運動系、光路長と横距離を混同する例を検査した。

有理数の補題では、正の距離と時刻、v²+w²=V²、斜めの光路の平方和から横距離=w*tが従うことを確認した。同じx′=0を使うと、τの縦方向の項が消え、各横座標の式と同値になることも確認した。v=0では横座標の係数がaになる。分母のwをVに変える例と、静止系時刻tを運動系時刻τに変える例は反例を持つ。

両横軸の光線でも、光線外を含む一般座標変換の確認は終わらない。横座標の候補へ任意定数λによる `λ*x′` を加えても、今回のx′=0の光線上では同じ値となる。光線外で異なる具体例を確認し、光線上の代入を全座標での一意な変換の証明とは区別した。
