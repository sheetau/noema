# 共動系の初期三式と七変換式

u0246–u0249を原刊918頁の一続きの範囲として読む。上の静止時の法則と相対性原理から、同じ電子の共動系での初期三式を述べ、その座標・場の記号を説明し、両系の四原点を合わせた上で時空四式と電場三式を提示する。

電子テキストと原刊には二つの転記差がある。M0406の「小さい値」の記号は電子テキストではt、原刊ではτ。M0409の記号一覧は電子テキストではτを欠くが、原刊にはξ,η,ζ,τ,X′,Y′,Z′がある。この範囲では原刊を採る。固定在庫とMathMLは変更せず、両者の差とハッシュを読解記録に保存する。

旧設定と新設定を同じ電子・出来事・単位・電荷・低速慣性質量に結ぶ。kは前の文で選んだ同じ系であり、新時間域と曲線も引き継ぐ。新電磁二場、電荷記録、三速度関数、三加速度を共同証人として選び、校正された物理場と実際の二階微分を要求する。運動三式と新電場の変換一致をこの設定の前提には入れない。

「直後」「小さいτ」は、後続の原点選択の下でτが正側から零へ近づく初期運動として読む。各速度の初期一次式の剰余をo(Δτ)で保持し、その同じ初期加速度にμa=εEを要求する。有限時間の厳密な一次速度、全期間の静止、一定加速度を追加しない。この読みは有限区間の微分方程式を厳密に主張する読みとは区別する。

新電場と新磁場は独立した物理場として入力し、旧二場の混合と逆座標変換による関数との一致を帰結側で要求する。一致は新領域全体、七式は旧領域の全有効四点を対象とする。座標原点一箇所の数値一致で済ませない。「第三節と第六節の変換式が成り立つ」という全適用の主張は磁場三式も含む。その全体からM0413の七式を取り出し、未表示の磁場三式は表示内容に追加しない。
