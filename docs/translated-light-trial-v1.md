# 任意の出発点を選ぶための光試行

u0058の可能な出発点の選択を、現在の測定・時計・出来事の規約で記述するための依存群である。この段階では著者主張と全単位判断を増やさない。

現在の座標対応と全k時計の指示条件はzb6を固定参照している。ei26–ei3cでは状況を引数に取り、同じ対象出来事・両系・全座標対・全局所時計表示への量化を保つ。ei3dでは計器・並進・全期間の軸平行性の履歴も引数にする。別の候補状況を、元の一つの履歴へ同一視しない。

光往復の出発点はk原点に限らない。ei3fは現在の二時計・同じ一光線・三出来事・全同期範囲への所属・局所表示を保持する。光路は縦軸に平行な支持線上にあり、原点軸との一致は要求しない。ei3eもK側の光区間について同じ変更だけを施し、全光速度適用範囲と幾何学的弧長、現在の局所時刻を保つ。

ei3gは二端点と往復光の全軌道を、任意の一定横座標y,zへ平行移動する。縦方向の正の間隔、速度、光速、交点条件をそのまま使い、全区間の出来事と同じ三出会いを保持する。横速度は零だが横座標は零とは限らない。

ei3jは一つの同じ試行について補助位置(x′,x′+gap,x′)、横座標(y,z)、出発時刻t、三つのτ値、全軌道、両光区間を接続する。ei3kは同じ設定の全計器・全k指示・全K時計と光速度原理も合わせる。実際に試行が行われたという主張や、全地点でこの条件が実現できるという主張は、この定義だけからは導かない。

元設定の地点を示すei3lは、その代表軌道と同じ時点の測定位置からx-vt,y,zを取る。kで静止する全軌道とKでの並進を保持するが、元設定の全地点に時計が既に置かれているとは要求しない。候補試行の出来事では現在の局所時計表示が必要である。

次に、同じ地点・補助座標・時刻を元と候補の状況で共有し、地点ごとに選べる試行の可能な結果へこの条件を結ぶ。空間原点を移した近傍条件と各地点の微分値、注意喚起、全空間値への帰結を合わせてu0058を通読する。有限の接続例と全実時刻・全候補の存在証明は区別する。
