# 理論を比較するときの慎重さと要求

u0259後半の注意を、比較手続きと、その手続きを求める規範に分けて部分記述した。前半の「別の定義なら数値も変わる」という内容から、この要求を導く著者の推論も接続する。数値関係から規範を数学的に証明したという意味にはしない。

慎重さの一部には、未整理の数値差だけから不一致と結論しないという手続きを採った。指定した比較事例について、採用すべき解釈候補が非空であり、その全てで意味・単位・物理事例の対応を確認でき、正規化した二値に差がある場合に判定を認める。一つの候補で差が消える場合や、対応が不明な場合は、この手続きで不一致との結論を支持しない。

同じ比較活動の主体・二つの対象・対象領域を固定し、全ての不一致判定にその条件を課す。結論を保留することは許す。これは慎重さの一側面を具体化した候補であり、常に結論を出さなければならないという要求でも、慎重さ一般の十分条件でもない。誤差や近似を含む比較には、別の対応条件が必要である。

著者の要求には、同じ主体・立場・活動と、Noemaで定義した手続きの記述を渡す。要求の真偽は、実際の遵守の真偽とは独立である。手続きに違反していても要求は存在し得るし、手続きを守っているだけでは著者の要求が存在したことにはならない。規範の評価では手続き記述を実行せず、前半からの推論帰属でも前提や結論の正しさを補わない。

意味・単位・事例の対応がどの証拠で確かめられるか、解釈候補の選定と完全性、理論や電子の運動の一般的な概念構成は未完である。また、数値予測の不一致から、理論全体の論理的矛盾や誤りを自動判定しない。

原文対応は、推論と比較の箇所、および「vorsichtig verfahren muß」の箇所へ解釈注記として付ける。冒頭のNatürlichと、慎重さの程度を強めるsehrは残す。原文が今回の確認項目を列挙しているとは扱わず、区間全体の意味一致を認定しない。先行177文を保存し、著者への推論帰属を一文追加した。
