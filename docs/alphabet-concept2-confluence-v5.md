# concept2：中円の円弧・方向指定・参照合流 v5

v4の形を保ちながら構成を拡張する未固定の試作。作者の2026-11-05追加指定を優先する。半円による接続起点、第4円内の方向線、小円への直線侵入禁止、直交交差、範囲・束縛・引用はv4を継承する。

## 計画する意味の単位

対象は呼出しに隣接する2～3個の宣言済み参照。必要なのは各参照先、引数順、範囲への所属、後続構文への接続であり、新しい語義やprimitiveは不要。既存の段宣言と参照を再利用する。先に参照列へ展開する規則を定め、図形からその列を回収する。

## ドットの中円を自由に切り替える

中円の8区間はそれぞれ45度単位で独立に選ぶ。通常の識別形は左右90度ずつの円弧とし、完円を要求しない。ドットへ線を通すために円弧の選択を制限することも、接続口が欠けたことだけを理由に大円へ繰り上げることもしない。

円周の左右端がある側では半径幅の線で接続する。左端がない場合は中円の完円端からMの空きを置いた小円を入口とする。右の小円は常に置き、右端がある場合だけ円弧からつなぐ。欠けた端と小円の間は一つの字形内部の非接続として扱う。中円内のドット中心は接続口にしない。字形外の接続は従来どおり実接点と半円基準で測る。

識別キーは中円弧だけで決まる。番号0と153のmaskを交換し、通常の番号0をmask153（左右の円弧）とする。中円弧なしの番号153のみ大円を使い、その対応先には裸ドットも使える。他の255形は中円だけで構成できる。外側の円や補助小円は識別キーを変えない。同じキーは範囲内で先頭から対を作る。未対応、引用境界越え、範囲外参照は拒否する。

## 中心から最初の参照先を指す

大円をくりぬく小円の位置は上・中・下の参照先を示す。中心から小円の中心方向へ1本だけ伸ばし、小円の手前の円周で止める。この線が最初の引数を指定する。残りは角度の増す向き（画像上では時計回り）へ、小円のある位置だけを一周以内で読む。線なしの既存選択形は上・中・下の順を保つ。

既定では昇順の異なる2参照に方向線付き選択形を使う。同じ参照を繰り返す場合や3参照の組は次の合流形へ進む。中心線は読順を担い、装飾や全字形共通の追加要素にはしない。中心の小円で境界・接続・未充足役割を表す既存形は維持する。

## 2段・3段を小円へ合流させる

2引数は上下段、3引数は上中下段に枝先を置き、物理的な上から下の順を引数順とする。各枝先は小円と外向きの中円弧で構成する。円弧は45度区間2個のうち、前半のみ・両方・後半のみを、それぞれ上・中・下の宣言への参照とする。基準角度は上枝225度、中枝135度、下枝45度。枝先の段が引数順、円弧が参照先なので、入替えと同じ参照の反復を区別できる。

上下の枝は半円基準のM幅を持つ水平線から45度線へ移り、出口の小円の左上・左下の円周で止まる。中枝はM幅で左端へ接続する。線を一点で交差させず、小円の円周を介して合流する。小円内へ線を入れない。合流後は右端から通常の後続接続へ戻る。各枝先の位置は接続起点から逆算し、中円弧のある側で線が不足しないようにする。

これは参照列を1回の呼出しへ渡す合流であり、値の等置、論理和、制御フローの合流を意味しない。2/3引数の全順序・重複を扱い、4個以上は既存の引数群区切りで組み合わせる。呼出し結果を段へ再定義すれば、後続の合流へ再利用できる。引用・束縛に入ると既存の範囲規則に従い、出口の小円自体が新しい参照範囲を作ることはない。

任意の部分式を枝上へ直接配置する一般的なグラフ描画、循環、前方参照、行境界を横断する独立した複数の枝は未対応。合流構成は一行内に保ち、字形間だけで折り返す。

## 検証範囲

256ドット識別形、方向付き選択、2/3段参照合流の公開構成を局所検査する。特に逆順・重複、合流結果の再使用、引用・束縛の復帰を短い対照で確認する。実SVGの幾何要素と共有辞書だけから構文へ戻し、元ASTや文番号を復号へ渡さない。元kant-pageの4段落40項目も新規則で生成・復号する。

語義・参照対応・復元構文が変わらない部分は既存意味判断を継承する。検査通過を全言語の自由配置一意性や外観承認とは扱わず、意味モデル全量診断も繰り返さない。v4と旧検査器は保存する。
