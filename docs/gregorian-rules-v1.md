# 自然数の証拠とグレゴリオ暦の年月日規則

暦上の日付番号の有効性を、Noemaの合成定義で検査する条件を追加した。数値型が有理数であるため、まず年番号・商・余りを32進の数字列として表し、整数性を列の桁から確認する。整数・剰余・閏年を返す新しい基本関係は加えていない。

rqseは非空の列の全桁が0から31の整数であることを調べる。rqsfは左から32倍と加算を繰り返して値を得る。rqsgは被除数・除数・商・余りの数字列を検査し、正の除数、割り算の等式、除数より小さい余りを要求する。先頭の0を含む別の数字列も同じ値を表せる。

rqshは、同じ正の年を4・100・400で割った三組の証拠を検査する。rqsiはその余りから閏年規則を適用する。rqsjは年証拠と月長規則を併せて月日を検査する。年証拠が不正な場合に、閏年でないから平年の日付ならよい、と受け入れることはない。

日番号にもrqseを再利用し、0から31の整数であることと0より大きいことを要求する。1から31の日番号一覧を重ねて定義せず、月長の条件だけを追加する。

規則は[米国海軍天文台が公開する暦解説](https://aa.usno.navy.mil/downloads/c15_usb_online.pdf)の表15.5と節15.4.2を参照した。保存PDFの597頁の月表と599頁の民用規則を画像で確認した。4で割り切れる年を閏年とし、100で割り切れる年は400でも割り切れる場合だけ閏年にする。2月以外の月長と、平年・閏年の2月の日数も同じ資料に従う。

rqskは数値上の有効性と、前版の暦内の期間割当を同じ年・月・日に結ぶ。原文用hzloには1784年の商・余りをNoemaで直接記述し、日付行と脚注の9月13日・30日の割当に接続した。これは三つの日付が規則に適合するための追加条件であり、原刊がグレゴリオ暦を使うという歴史的な同定にはならない。既存の本文へ新たな主張は追加していない。

検査は1600年から1999年の400年と、世紀境界・小さい年・大きい年を扱う。月日については閏年、平年、400で割り切れない世紀年、400で割り切れる年の全月で境界を調べる。証拠の各欄に空列・負の桁・32・分数を入れた場合や、誤った商・余りは拒否する。証拠生成器の出力を信用して判定するのではなく、Noemaの等式と桁検査を実行する。

有限検査には有理数の加算・乗算・比較の解釈だけを渡し、閏年の正解は実行器へ渡さない。結果の照合にはPython標準ライブラリの暦計算を使う。400年の検査から、無限に長い証拠を含む全実行の形式的証明を得たとは扱わない。

正の年番号を対象とし、紀元前年・0年の規約、改暦時の欠番、地方ごとの導入日、絶対時刻・日境界の説明は未完である。八定義を加え、既存23文と全意味規約を保存した。原文対応範囲と意味確認済み単位は増やさない。
