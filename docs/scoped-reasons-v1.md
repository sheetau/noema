# 仮定の下で導き、仮定を解除する

推論列の各段階に局所的な仮定列を持たせた。「Pを仮定するとQが導ける」ことから、仮定Pを解除して「PならQ」を導ける。PやQをそのまま事実として外へ持ち出すことはできない。

前回の推論列を拡張する7定義であり、新しい文法演算子は使わない。既存の判断・理由使用への接続も保つ。条件付きの理由を記述する基盤であり、洞察一般やカントの語義を確定した定義ではない。

## 仮定列が示す範囲

各段階には式の記述、規則、参照式に加え、その段階で有効な仮定の記述の列を指定する。式の記述が同じでも、仮定列が異なる先行段階は通常の推論規則へそのまま流用できない。

含意導入の条件は次の形になる。Γは順序を持つ仮定列である。

```text
先行段階：ΓにPを末尾追加した仮定列の下で、Qを導いている
現在段階：Γの下で、P ⇒ Qを導く
```

解除するのは一番内側のPだけで、Γは残る。最終結論として受け入れるには、全段階が正当で、最後の式が指定結論に一致し、最後の仮定列が空でなければならない。

仮定列は、編集上の開始・終了位置を持つブロック構文ではない。それぞれの導出記録が明示する前提範囲である。同じ仮定列を持つ先行記録を再利用できるが、未解除の仮定列を空だと読み替えることはできない。

## 追加した規則と定義

前回の規則0〜4（外部前提、含意除去、連言導入、連言の左右除去）には、参照先の仮定列も一致することを要求する。新たに次の三規則を加えた。

| 規則 | 内容 |
| --- | --- |
| 5：局所仮定 | 現在の仮定列に含まれる式を、その仮定列の下で使う。 |
| 6：含意導入 | ΓとPからQを導いた先行段階を使い、Γの下でP ⇒ Qを導く。 |
| 7：仮定追加 | Γの下で導いた式を、Γに一つの仮定を追加した範囲へ移す。 |

規則7は仮定を追加する方向にだけ使える。仮定を減らして同じ結論を持ち出す操作にはならない。仮定を使わずにQを導ける場合も、Pを加えた範囲でQを導き、P ⇒ Qと述べてよい。Pが現実に真であることは要求しない。

| 定義 | 内容 |
| --- | --- |
| `rra` | 先行式の記述と仮定列を照合する。 |
| `rrb` | 一段階を八規則のいずれかで検査する。 |
| `rrc` | 全列の正当性と、局所仮定の残らない最終結論を検査する。 |
| `rrd` | 最終段階が外部前提の列挙だけでないことも要求する。 |
| `rre` | 結論と同じ記述を外部前提として使った段階がないことも要求する。 |
| `rrf` | 同じ理由・判断・時点の結論を、この推論列に結ぶ。 |
| `rrg` | 同じ本人・対象についての判断で、その理由を用いる既存の条件へ接続する。 |

`rre` が対象にするのは外部前提の使用である。導出中の局所仮定と、その後の解除を、結論の直接の前提採用と混同しない。同義な前提を介した循環や、前提の正当化が結論に依存する場合まで検出するものではない。

## Noemaで書いた二段階の具体例

[具体例](../examples/v016/scoped-identity-example.noema)では、Pに閉じた偽の内容を用い、次の記録をNoemaの断言で指定している。

| 段階 | 仮定列 | 式 | 規則 |
| --- | --- | --- | --- |
| 第一段階 | `[P]` | `P` | 局所仮定 |
| 第二段階 | `[]` | `P ⇒ P` | 仮定Pを解除する含意導入 |

文書の七つの断言は、二段階の参照が異なること、および各段階の式・規則・仮定列を指定する。P自体を事実として断言してはいない。後続の四つの問いは、列の妥当性、理由としての条件、Pの真偽、P ⇒ Pの真偽を調べる。検査結果は順に真・真・偽・真となる。

具体例には記録の参照・選択・規則・評価時点を指定する6記号と、記録へ接続する2定義がある。これらは有限の記録データであり、新たな自然言語の意味を原始記号で代用したものではない。検査モデルはそのデータの値を与え、証明判定はNoemaの `rrc` と `rre` が行う。規則や仮定列を変更すると、記録の断言と証明判定の双方が不成立になることも検査した。
