# 向き付き積分の変数変換

Noemaで、変数変換の条件と結論を独立に記述した。時間区間上の変換関数をg、その微分をg′、外側の被積分関数をfとすると、変換後はf(g(t))g′(t)となる。時間区間、gの値が入る区間、gとg′の連続性、fの連続性を明示する。端点の微分は区間に相対的な片側微分を許す。

積分には向きがある。gが減少する場合は負の微分を保持し、絶対値に置き換えない。gが途中で停止したり折り返したりすることも許し、速度や微分で割らない。同じ端点へ戻る場合、符号付きの積分値は零になる。

電子の仕事にはこの定義を二度適用する。一度目は時刻から位置へ、二度目は時刻から速度へ変換する。両方で同じ軌道・速度・加速度・場・電荷・質量を使う。縦方向の運動方程式に速度を掛けると二つの時間積分の被積分関数が一致する。速度側の範囲は厳密に光速度未満に収める。対応する内容構成子は既存の仕事・収支前提を共有するが、追加した正則性仮定を著者の発話として帰属させない。

検査では明示的に登録した有理係数多項式と、その合成・積だけを解析する。係数から微分と積分を計算し、増加、減少、停止、折り返し、逆向きの符号、誤った微分を区別する。未知の関数の標本から多項式を推定しない。連続性や積分の全実切断にわたる条件は、有限評価を拒否する。

積分値の一致だけでは、正しい微分を使った証拠にはならない。検査には、三つの標本点で正しい微分と一致し、積分値も同じになる誤った微分関数を含めた。この例でも多項式の係数による恒等式検査と、別の時刻での局所条件は不一致を検出する。

これは変数変換の命題を言語内に記述し、限定した解析的モデルで接続を検査した成果である。全実切断の積分の基本定理と変数変換の機械的証明は残る。原刊の中間積分には質量係数がないため、今回の質量を含む候補と引き続き区別する。原文対応の文字数と意味確認済み区間数は増やさない。
