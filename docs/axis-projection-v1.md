# 軸への正射影と符号付き距離

u0045第一文の座標測定について、旧sgj/sgkが原始関係zcw/zcxへ残していた幾何を構成する。原刊897頁末と898頁冒頭を画像で照合した。静止系Kでは静止物差し、運動系kでは共に動く物差しを使い、それぞれの三成分を得るという思考上の設定である。正射影と符号付き距離はこのプロジェクトの操作的読解であり、原文に計算手順が記されているという判断ではない。

原点Oから対象点Pと射影点Qへの変位をp、q、非零の軸方向をdとする。eiw4はqとdの共線性と、p−qとdの内積が零であることを要求する。qやp−qが零でもよい。既存eiu6は両ベクトルを非零に限定するため、ここではその直交条件をそのまま使わない。

eiw5は符号付き距離sについてs²=q・qとし、sとq・dの正負・零を一致させる。dは単位ベクトルでなくてもよく、正の倍率で値は変わらない。dを逆にすれば符号が変わる。eiw6はこの距離を同じ正射影へ結ぶ。既存の切断実数、積・差・内積・比較を使い、平方根を新しい原始演算にしない。

eiw7では、実際に系と役割へ割り当てた軸、その原点、同じ軸の物質方向標識、対象地点と射影地点を要求する。eiv2の完全な物質線履歴とeipwの系に対する静止を保ち、原点と両地点のeismh候補を同じ系・単位・区間のeit2へ渡す。原点の代表座標はeiv2を通じて物質軸側の座標にも結ばれる。同じ時刻の実座標差を幾何条件へ渡し、座標取得関数の名前だけで射影を認定しない。これは各系の固有の計量を使う記述で、Kとkの値を等置しない。

物質方向標識は原点の負側でもよい。eixaは既存zsaの正方向記録を別に要求し、全記録について実際の非零軸方向との平行性と同じ符号付き距離を確認する。原点への射影では符号付き値が零なので、正負の二方向はいずれも同じ零値を与える。軸全体の正方向規約の整合性は、後続の全地点・三成分の条件にも必要である。zsaの意味規約は保持しており、その記録の物理的取得を数値から証明するものではない。eixbは同じ点・軸・役割と値について全実時刻へ量化する。

検査は零・正負・三成分・斜めの方向・倍率・平行でない射影を識別し、原点を平行移動しても同じ距離が得られることを確認する。物理履歴の境界は各引数を取り違えた場合と欠落した場合を検査し、位置と方向の本体は有限モデル内で計算する。履歴関数の有限指紋は引数接続の検査であり、完全履歴の証明ではない。元の全実時刻量化は有限評価で拒否する。

新しい原始記号はない。270の本文主張、既存の意味規約と全単位判断を保持する。次に同じ校正済み物差しによる測定操作、全空間と三成分の存在・値の一意性へ接続する。時計配置点の時刻設定、§1の同期手順、思考設定と追加指示、表記対応も残っているため、この依存群だけでu0045を完了にはしない。
