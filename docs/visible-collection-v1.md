# 円文字の文書群と冊をまたぐ参照

一つのNoema文書を複数冊へ分け、冊の続きも円文字から読める書式を追加した。定義の型・本体、名前、引用、束縛、主張の順序は元の文書のまま保つ。冊への分割は物理的な区切りであり、別の名前空間や新しい仮定の範囲を作らない。

既存の一ページ・一冊の読解規則と制限は変更しない。新書式は各冊に明示的なヘッダーを付けるため、旧書式の文書と区別できる。[検証例](../examples/v016/visible-collection-v1.noema)は現行375語の全宣言、語義比較と引用の例、同じ本体を持つ二つの異なる名前を含む。二論文を新書式化した完成版ではない。

## 冊のヘッダー

「発話」文法群の字形に、半径線のない中円修飾を続けた組を文書群の開始標識とする。既存の字形と寸法を使い、旧来の49操作との衝突はない。この標識の後に次の欄を順に読む。

1. 文書群書式の版1、Native文法の版16、公開語彙の版12。
2. 複合名または固有名の形で書いた文書群名。
3. 0から数える冊番号と総冊数。
4. 全文の本文字形数、その冊の開始位置、その冊が含む本文字形数。
5. 全文の宣言数と最上位の文の数。
6. ヘッダーの終端。

文書群名は、その文書群を識別するための表記である。個体についての新しい基本宣言や意味定義にはならない。番号と位置は冊の順序と続きを指定し、語を辞書番号へ置き換える用途には使わない。各冊は同じ文書群名・総冊数・全文の字形数・宣言数・文数を繰り返し示す。

本文の位置は、行枠と冊ヘッダーを除いた可視字形列の位置である。続く冊は直前の冊の末尾から始まらなければならない。欠落・重複・並べ替え・異なる文書群名の混在は拒否する。各冊内の行番号は0から始まり、行末の継続標識または最終行標識から冊の終端を読む。ファイル名や別の一覧で冊の区切りを補わない。

## 定義・束縛・引用

本文には従来と同じ文書ヘッダー、宣言列、宣言列終端、文の列、文書終端を一度だけ記す。公開語彙の導入はその語形によるimportであり、未公開の名前には型と定義本体が必要になる。新しい名前の番号表や別ファイルのASTから本体を補わない。

文法操作の二字形、自然数の桁列、新しい名前の綴りの途中では行や冊を切らない。それらの単位の間なら、定義本体・引用・量化・明示的な共有の途中でも次の冊へ継続できる。冊の境界で変数や共有の環境を初期化せず、引用に入るときの既存規則だけを適用する。

復号後には全文を型検査し、宣言の重複、未定義・前方・自己参照、引数や結果型の違いを拒否する。同じ本体の二つの定義も別々の名前として保持する。検証例では、両定義を実行した値の一致と、両方の名前を含む引用の不一致を同時に確認する。

## 処理上限と検査範囲

各冊は8ページ・128行まで、各ページは本文字形768個・円と線4,096個までという既存の上限を守る。各宣言と最上位の各文は、明示的な共有を展開した後も8,192節点以内とする。文書群全体には別の上限を設ける。

| 対象 | 文書群全体の上限 |
| --- | ---: |
| 宣言 | 16,384 |
| 最上位の文 | 4,096 |
| 展開後の節点 | 524,288 |
| 本文字形 | 4,194,304 |
| 冊 | 4,096 |

これらは処理系の資源制限であり、任意長の文書を実行できる保証ではない。冊の分割目標は既定で本文2,048字形とし、行・ページの制限に収まらない場合は拒否する。語形や型の長さによって配置負担は変わるため、目標字形数だけからページ数を確定しない。CLIは一冊ずつ描画・保存し、過去のページ図形を全てメモリに保持しない。復号も入力ページを順に読む。

検証例は共有375語と局所17定義を持つ392宣言、15の質問からなる。旧一冊の節点数とページ数の制限を超える文書を保存SVGから復号し、16通りの二個体関係で語義比較・引用の同一性・量化の向きを確認する。小さい対照文書では、全ての合法な位置で二冊に切った場合と、名前・数・操作の途中で切った不正な場合を検査する。証拠は[検証報告](../reports/visible-collection-v1.json)に保存する。

文書群名は暗号学的な署名ではない。同じ名前と整合したヘッダーを持つ別の有効文書が与えられたとき、その本文が意図した正本かは書式だけから認証できない。この報告では保存SVGと原本の内容ハッシュを別に固定し、同じ語形の復号と成果物の同一性を区別する。

二作品の全宣言の語形割当と基本関係の規約の接続は残る。この検証例だけで二作品の全文図形復号、人の独立読解、画像OCRの成功とはしない。

## 再現入口

```powershell
python -X utf8 -m scripts.project_work check --module scripts.check_visible_collection --prepare --tests tests/test_visible_collection.py --verify reports/visible-collection-v1.json
python -X utf8 -m scripts.visible_collection render examples/v016/visible-collection-v1.noema output/collection-copy --label book treeone home --public-names --payload 768
$collectionPages = Get-ChildItem -LiteralPath output/collection-copy -Filter 'page-*.svg' | Sort-Object Name | ForEach-Object FullName
python -X utf8 -m scripts.visible_collection decode @collectionPages
```

復号コマンドには全ページを順に渡す。出力先は新規または空のディレクトリに限定する。
