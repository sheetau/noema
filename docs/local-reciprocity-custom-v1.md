# 局所的な返礼作法を説明する例

二作品以外の適用例として、架空の共同体の作法を既存の構文だけで定義する。現実の特定文化についての調査結果ではない。文化によって行為に意味や規範が与えられる場合に、その局所性を定義へ保持できるかを確認する。

採用する規約は次のとおりである。同じ共同体の構成員の間に物の無償の譲渡があると、受領者が贈与者へ上体を短く傾ける義務を負う。その共同体では、その身体行為を相手から受けた利益への謝意の表示として取り扱う。この二条件の組合せを、この例の返礼作法と呼ぶ。

贈与、構成員、身体行為、義務、表示規約、謝意の六関係を意味基盤で説明し、変項・量化・条件・定義・型付き引用から作法を合成する。返礼作法そのものを新しい原始関係にせず、名称や自然言語の文を本文へ埋め込まない。共同体と場面を共有し、受領者が贈与者へ行うという向きを固定する。

身体動作と文化的な表示規約を分ける。同じ動作でも表示規約がなければ、この例の作法の全条件は成立しない。義務の対象は行為型の引用であり、実際に会釈したことや本心で感謝したことを義務から導かない。該当する贈与がない場合は条件付き義務が空虚に成立し得るため、贈与の存在も別に扱う。購入代金の支払い、物の返却、普遍的な道徳義務は補わない。

さらに0.16の型付き記述合成を使い、受領者と贈与者の閉じた記述から、その二人についての行為内容の記述を作る。生成した記述が直接書いた引用と同じ構文になることを確認する。論文で用いた機能をこの別話題でも使い、記述の一致と行為の実行を区別する。

贈与・構成員・義務・表示規約・動作の32組合せと未知入力の拒否を検査する。意味規約の全宣言への対応、長形式・短縮形式・固有文字の往復も確認する。これは明示した局所規約を合成できる例であり、あらゆる文化の全概念を記述できる証明ではない。
