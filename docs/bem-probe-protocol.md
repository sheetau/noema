# 学習済み語義モデルをそのまま使う比較

Noema側で追加学習せず、文中の対象範囲とNoemaの概念定義を照合する。
UCRELの[多言語Small BEM](https://huggingface.co/ucrelnlp/PyMUSAS-Neural-Multilingual-Small-BEM)
をリビジョン `2e42e0de8d5b00144a8eb1e61013457021b016c0` に固定する。
[公開実装](https://github.com/UCREL/WSD-Torch-Models)では、文中の対象トークンを平均し、
定義文の平均ベクトルとの内積で候補を順位付けする。このチェックポイントには追加層やScalarMixがない。
モデルは非生成のModernBERTエンコーダーであり、指示文も生成APIも使用しない。

既存のUSAS候補や対訳辞書は読み込まず、Noemaの91個の英語定義へ置き換える。
概念IDや正解の品詞で候補を絞らない。語彙ごとの分類器・訓練例・追加パラメーターは設けない。
対象範囲は正解を与えるため、意味解析全体の試験ではない。

モデルの予測を見る前に、コード、本書、新資料 `data/definition-probe-v2.json` を固定する。
旧v1は回帰比較、新v2は追加26概念と対応外8組の探索確認とする。
新資料は旧資料とは異なる文章だが、同じ作成者と概念群による小規模資料であり、独立した外部評価ではない。
比較対象は前回のMiniLMと日英定義の平均。BEMは公開実装に沿う英語定義・内積を主条件とする。
モデルだけでなく定義言語とスコアも異なるため、学習手法単独の効果とは解釈しない。

CPU・float32・8スレッド・eager attention・eval・固定重みで実行する。
入力を128トークンで検査し、切り詰めが必要なら停止する。反復一致も同じバッチ形状で測る。
全候補のうち上位3件、言語別の先頭正解率、日英一致、対応外入力の最高スコアを記録する。
内積もコサインも確信度と解釈せず、棄却閾値を調整しない。

これは語彙候補の比較である。主体と対象、否定、時間、数量、対応外構文を含む
意味構造完全一致率95%・確定率80%の採用条件を満たしたことにはしない。
結果にかかわらず本番の翻訳画面へ直結せず、全予測と失敗を保存する。
