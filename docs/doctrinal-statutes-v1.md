# 同じ規定群への賛同と、含まれる真理の可能性

カント第五段落 `u0012[3899,4278)` の規定群を、前の文から続く同じ教会・信条・教示基準へ結ぶ依存群である。本文91主張と確認文字数は据え置く。

`Satzungen` はここでは教会が教示すべき立場として定めた教義の定式化群と読む。[AdelungのSatzung項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_7_0_464) は宗教・信仰に関する規定の語義を含む。本文の教示・賛同・含まれる真理という文脈に合わせ、規定の規範的な位置付けと、そこで教える命題内容を分ける。行為への条件付き要求`rba`をそのまま各教義の真理条件へ代入しない。この読みが歴史的な唯一解釈であるとは主張しない。

`r42j`は既存`r35s`の教会・信条・主題・採用基準を再利用する。対象群の成員は`h6t`で固定し、明示した有限列がそれを尽くすことを既存`rcm`で検査する。複数の規定という読みを、少なくとも二つの異なる成員がある条件で示す。各成員について、同じ基準の教示規定という位置付け`h252e`と、同じ教会がその閉じた内容`h246e`を共同の立場として採用する`h246g`を要求する。教会の全規定をこの群へ集めるという意味にはしない。

全内容への賛同は、規定列の内容を実際にNoemaで連言して構成する。`r42h`は各内容記述を`o a`で連言の構文へ組み込み、`r42i`は同じ内容を対象・基準引数を持つ閉じた関数へ持ち上げる。記述を構成する際には教義の真理を実行しない。得られる記述は段階0のままで、既存の本人の判断`h245q`と確信の構成`r42g`へそのまま渡せる。高い段階の引用を低い段階へ押し込めたり、全内容を新しい原始命題へ置き換えたりしない。

`r42m`は同じ規定群・列・固定基準を保持し、構成した内容に対して本人が仮定の下で十分な確信を伴っては肯定しないことを結ぶ。この局所的な読みは規定群全体への集合的な賛同であり、各規定を一つずつ全て否定するという読みではない。個別内容への肯定から連言全体への確信を自動的に導く条件も設けない。前回の[本人の確信の読み](personal-conviction-v1.md)と、その技術的な認識論上の限界を継承する。

部分の真理は別に構成する。`r42k`は群の成員そのものと、その成員が肯定的に含む命題部分`h252f`を対象にする。否定・反駁のためだけに引用した内容や、任意の論理的帰結まで含めない。両者の内容は閉じたNoema記述として示す必要がある。`r42l`は既存`rgn`を用い、同じ本人・群・基準に対する可能状況のどれかで、その部分の内容が真であることを述べる。部分の所属と内容は基準に固定し、候補ごとに入れ替えない。全体の真理、実際の真理、本人の賛同とは区別する。

局所検査では、実際の`r35s`・`rcm`・`rgn`・`rgm`・`r42g`を実行する。診断上の差替えは内容提供関係`h246e`と基準提供関係`h246j`だけで、評価器が発行した具体的な閉じたNoema記述を返す。部分だけが真の例では、一つの規定を二命題の連言として実際に記述し、その一方だけを真にする。単なるPythonの真理値配列を部分構造の証拠にしない。

規定列からの欠落・余分な成員、他の教会・基準、採用されていない内容、未知入力、規定全体が偽でも内部の部分が真の場合、別候補でだけ真の場合を検査する。同じ内容構文が本人の同じ規定群への判断に渡されることも記録する。列の順序は明示解釈に保持し、重複は拒否して、真理値が等しいという理由だけで構文を同一視しない。

有限の規定群、教義内容、部分の構成関係は明示解釈の契約である。検査がその選択自体や原文との意味同値性を証明するものではない。残るのは仮定の具体的な補充、前文の同じ職務・会衆への本文接続、全実益、引受け可能性、真理が隠れていること、内面の宗教との無抵触、接続語と焦点、全文の著者帰属である。資料は`data/doctrinal-statutes-evidence-v1.json`、検査結果は`reports/doctrinal-statutes-v1.json`に保存する。
