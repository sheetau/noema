# 同じ規定の説明を引き受けられること

カント第五段落`u0012[3899,4278)`の説明の引受けについて、遂行内容・責任の引受け・実践的な可能性・良心上の許容を分けて構成した依存群である。本文91主張と確認済み文字数は増やさない。

[Adelungのanheischig項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_3_2_2244)は、自分を拘束する引受けとして説明する。ここでは説明する責任を自分で引き受けるという読みを採る。試みただけの`wagen`、本人の希望、他者による任用、実際の履行を同じ意味にしない。`kann`は、当該事情で可能な、良心上許容できる引受けと読む。先行する良心の非帰責と、後続の抵触を信じた場合の辞職条件を文脈として保持する。

同じ規定群の有限列は`h252g`で基準に固定する。`r42j`が所属との一致・非空性・重複なし・同じ教会による採用を検査する。列を、確信や説明の成否に応じて候補ごとに選び直さない。

| 定義 | 内容 |
| --- | --- |
| `r42n` | 同じ列の各教義から構成した連言内容を述べる、閉じた発話族を作る。 |
| `r42o` | 同じ規定群について、担当機会・活動・宛先・教会の名・基準適合を既存`r374`で結び、実際の説明を表す。 |
| `r42p` | 九個体の聖職者事例と規定群を正確な十個体列に束縛し、その説明活動と担当機会が存在するという目標内容を作る。 |
| `r42q` | 同じ本人の同じ行為について、生起・行為者・同じ目標の責任ある引受けを結ぶ。目標を実行しない。 |
| `r42r` | 実践的な候補のどれかで、同じ引受け行為が成立し、良心上許容される。 |
| `r42s` | 同じ規定群と本人について、`r42p`の説明を引き受けられるという条件を結ぶ。 |

担当宛先は同じ担当機会の範囲であり、教会の全会員へ全教義を一度に話すことではない。説明活動は複合的な活動でもよく、期日や一回の短い講義を補わない。説明の構成は教義の真理、本人の賛同、受け手の理解を要求しない。

引受け関係`h252h`は閉じた段階1の目標関数・個体列・基準をそのまま保持する。実践候補`h252i`は現在の関連事情を保つ評価範囲であり、成功や許容を確認してから選ぶ範囲ではない。良心上の許容`h252j`は別の条件で、罪悪感の不在、教会からの任用、禁止が見つからないことだけでは成立しない。可能な行為と許容される行為は、同じ候補・同じ本人・同じ行為で一致しなければならない。これらの関係は一般的な解釈入力であり、良心や実践的可能性の全哲学を定義したものではない。

局所検査では`r42o`から`r374`・`r357`・`r356`まで実評価し、説明・宛先への伝達・代表・基準適合に同じ発話記述が渡ることを調べる。実践候補、引受け、生起、許容の16組合せと、別の行為・人物・時点からの流用も検査する。可能性を調べるときは説明の実行を未知のままにし、引受けから履行を要求しないことを確認する。

十個体列の束縛検査は、`r42o`だけを型付き境界に置いた二個体の有限診断である。長さ・順序・担当機会と活動の存在量化を調べ、別に行う実際の`r42o`の検査と区別する。全個体域を有限診断で尽くしたという意味ではない。

残るのは、本人の確信の否定との接続と仮定の補充、`gleichwohl`と`weil`、会衆への全実益、隠れた真理、内面の宗教との無抵触、全文の著者帰属である。本文全体の意味判断はこれらを接続してから行う。資料は`data/responsible-exposition-evidence-v1.json`、検査結果は`reports/responsible-exposition-v1.json`に保存する。
