# 良心における帰責と、その可能性

第五段落の次の一文、`kant-1784:u0012[3453,3527)` に向け、「良心に落ち度として帰せられ得る」という内容を構成した。ここでは、本人の道徳的な自己判断として、根拠をもって帰責できるという読みを採る。実際に自責しているか、感情としての負い目があるかとは分ける。この依存群だけで一文全体を確認済みとはしない。

[AdelungのLegen項目](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_7_0_820)は、zur Last legenの用法を、人の落ち度として解釈することとして説明する。取得本文と原HTMLは[出典記録](../data/imputation-evidence-v1.json)に固定した。[Gewissen項目の既存記録](../data/conscience-evidence-v1.json)と[良心の機能上の読み](conscience-reading-v1.md)も再利用する。これらは身体的な重さや単なる気分への読み替えを避ける根拠となるが、könnteの唯一の解釈やカントの作者意図を証明するものではない。

`r37r` は同じ本人の判断 `fa`、本人の行為の道徳的評価 `se`、判断対象 `fb`、同じ事柄を本人の落ち度として扱う判断内容 `h247h` を結ぶ。良心の既存定義 `sm` の二関係を保持し、同じ判断に対象と帰責を加えた。既存の `hziq` は状況上の帰責評価であり、判断個体・事柄個体を受ける非事実的な判断内容ではないため、引数や意味を変更して代用しない。`h247h` 自体は誤った帰責も記述できる。

`r37s` は、その同じ判断の正当化可能性 `h247i` を要求する。続くDennの説明と整合するよう、ここでの可能性は、心理的に自分を誤って責め得るというだけの意味にはしない。ただし、何を妥当な根拠・評価基準とするかの一般理論を今回完成させたわけではない。`h247i` の意味規約を明示し、正当化が不明なら検査でも真偽を補完しない。

`r37t` は、同じ本人と基準時の同じ事柄を保持する判断候補の範囲 `h247j` の中に、`r37s` となる判断が存在することを表す。候補は帰責が成功するものだけに絞らない。現時点の自己非難がなくても、候補で正当な帰責が成立すれば可能性は成立する。候補内での本人・判断・事柄・基準の取り違えは認めない。処罰の許可・義務、教義の真理も追加しない。

`r37u` は呼出側から受け取る事柄の範囲について、その全てに帰責可能性がないことを要求する。二つ目の対象だけに可能な帰責があっても否定文は不成立になる。一方、範囲外の事柄への帰責からこの否定を崩したり、限定された否定を人生全体の無過失へ広げたりしない。空範囲と候補不存在は区別する。
