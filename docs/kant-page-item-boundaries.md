# 一項目一行の図形境界

未登録名を宣言から学ぶ読取器を、一枚のSVG上の行に接続する。最初の段階は一宣言または一文を一行に置く方式とし、本文ごとに同じ開始記号を追加しない。

各行の全ての円・線の上下端を求め、次の行まで少なくとも4罫線間隔（128単位）の空白帯を置く。読取側は図形のy方向の占有範囲からこの帯を検出し、上から下へ読む。SVGの要素順、グループ名、項目番号、別添ASTを使わない。行内の円は三罫線に収まり、許容される無線接続の上下幅も2罫線間隔以内なので、この大きさの空白帯を行内の語境界とは解釈しない。線だけの迂回も全て占有範囲へ含める。

大円を含む行は、その共通中心yを中央罫線とする。大円がない行では円の中心から三罫線への整合候補を有限に求める。候補ごとに幾何と構文を読み、成功する候補が全て同じnative項目を返す場合だけ採用する。候補ごとに違う構文になる行は曖昧として拒否する。行の位置を復号するための候補は語義・参照先の候補ではない。

各行は一項目として全て消費する。復元した宣言を登録してから次の行へ進み、未定義依存、順序逆転、宣言の重複、本文の後の宣言を拒否する。離れた線片や行間を越える接続を黙って捨てない。

これは実SVG全体から順序と項目境界を読む最初の方式である。元kant-pageの40項目を18行に近づける複数項目配置、項目の行折り返し、ページを越える継続は未実装。現在の余白や縦の長さを最終外観として固定しない。形の配置・半径・線の制約は各行の元生成器・読取器の検査を通す。
