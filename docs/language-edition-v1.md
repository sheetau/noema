# Noema 1.0 完成版

2026年11月5日、Noemaの言語本体を完成版1.0として確定する。完成の範囲は、意味として自然言語に匹敵する表現幅、説明と定義による語彙の拡張、型と作用範囲を保つ構文、採用した円文字からの一意な構文復号である。カントとアインシュタインの二作品は、各判断で明示した解釈の下で全文記述した。今回の不足探索と確認で、完成条件に関する未解決項目は残っていない。

1.0は成果物をまとめた完成版の番号である。既存の構文版0.14・0.15・0.16や、採用済みconcept2 v7の字体を改番するものではない。構文、語義、字形、原文の読みを、この確定作業で変更していない。

## この版で使う仕様

構文と型は[0.14までの仕様](spec-v014.md)、[評価層付き引用](ranked-quotation-v1.md)、[記述合成](quotation-construction-v1.md)に従う。意味の組立てと語彙の導入は[共通仕様](general-language-v1.md)と[意味の境界を保つ規則](semantic-boundaries-v1.md)、表示・接続・分岐・復号は[円文字仕様](circle-writing-v2.md)を正本とする。旧構文の処理系と互換資産も保持する。

任意の適格な型の関数・関係・列、量化・否定・条件・様相、引用・信念・参照を組み合わせられる。非実在の対象、未定義と情報不足、矛盾する資料、上限を固定しない反復、自己言及も、区別を失わず記述する規則を持つ。未知の概念は、既存概念との関係と、残る経験的な基本関係の意味を説明して導入する。

こうした構成原理と分野横断の区別の確認を合わせ、意味の表現幅について利用者が指定した完成条件を満たすと判断する。内容を記述できることと、その真偽や値を必ず計算できることは別である。人が実際に会話し、読んで受ける効果は完成条件に含めない。

## 保存と確認

`output/noema-1.0/` は、本文・図形・辞書・仕様・直接の証拠入力を元の相対パスで持つ保存コピーである。台帳へ退避済みの証拠文書も、保存された元バイト列を収録する。完成版を読むために開発用SQLiteやキャッシュへ接続する必要はない。開発の引き継ぎ台帳は別にバックアップして保持する。

コピーの内容は、標準ライブラリだけの確認コマンドで照合できる。

```powershell
python -X utf8 output/noema-1.0/scripts/verify_language_edition.py --root output/noema-1.0
```

別の場所へコピーした場合は、その保存フォルダー内で `python -X utf8 scripts/verify_language_edition.py --root .` を実行する。

確認器は内容ハッシュとファイルの欠損を調べる。これは意味判断を新しく実行するコマンドではない。新しい語義や構文・字体の改訂は別版で行い、変更部分の意味・構造・図形の必要な検査を加える。1.0の証拠を書き換えて新しい変更へ流用しない。

二作品の判断はアシスタントによるもので、独立査読や同義性の自動証明ではない。全自然文を列挙した網羅証明、万能な真理評価器、原著者の理論の真理も完成の主張に含めない。自動翻訳器とモデル比較は引き続き保留する。
