# 同じ約束の行為に結び付く宣誓

カントu0013の「宣誓して」という箇所へ、厳粛な表明と、記述で指す権威への呼びかけを部分接続した。約束の表明と同じ本人・行為・時点・条項の引数を保持する。宣誓したことから、約束の履行・信念の誠実さ・契約の有効性を導かない。

原文は宣誓文の具体的な文言や制裁を指定していない。[1784年の本文](https://www.korpora.org/Kant/aa08/038.html)35–36行では、一定の変更しない信条への相互の引受けが宣誓によって修飾される。ここに特定の祈祷文を補うことはしない。

構成候補の検討には、後年のカントの宣誓論を補助資料として参照した。[『人倫の形而上学』303頁](https://korpora.org/Kant/aa06/303.html)30–35行では、宣誓の宗教的な仕組みとして、発言が偽の場合の報復を自分へ呼び求めることが論じられる。[305頁](https://www.korpora.org/Kant/aa06/305.html)3–15行では、約束の宣誓と事実に関する宣誓が区別される。これらは今回の候補を作る根拠であり、1784年の語義全体を確定する証拠でも、本文へ追加する著者の主張でもない。

| 定義 | 内容 |
| --- | --- |
| `rim` | 同じ引数列の対象内容が偽なら、同じ引数列の応答内容が成立するという条件内容 |
| `rin` | `rim`の条件内容を満たすよう求める発話 |
| `rio` | 同じ約束の行為で、本人が厳粛な表明をし、記述で指す権威へ指定の発話を呼びかける |
| `rip` | 相互引受けの全当事者について、各人の同じ引受け行為が`rio`の追加条件を満たす |
| `riq` | 指定した目的主体の目的志向も、同じ引受け・呼びかけの行為へ結び付ける |
| `hzcv` / `hzcw` | 通常の引受け／目的付き引受けを、原文草案の既存の人・行為・時間順序へ接続する |

権威は実在する個体として渡す代わりに、個体の性質を表す閉じた記述で指定する。その性質の真理を実行評価せず、該当個体も存在量化しない。宗教上・虚構上の対象への呼びかけを記述しても、その対象が実在するとは断言しない。ただし、任意の性質を渡せるという型だけでは、神・最高権威・全知の意味を説明したことにはならない。

厳粛な表明と呼びかけの関係は、意味規約を明示した引数である。慣習上の認定や厳粛さの一般的な説明は残る。原始記号の追加はないが、これらの入力関係の意味まで既存の論理式だけで説明し終えたわけではない。

条項と呼びかけの内容を渡す一般引数は独立している。具体例では、約束の条項に渡した同じ関数を`rin`にも渡した閉じた記述を使う。Noemaで直接書いた`r[k rin[p jq p jeresponse]]`は、例中の条項関数`jq`と応答関数`jeresponse`から作る呼びかけの記述である。既知の式を組み合わせる操作であり、自然言語からの生成や翻訳ではない。型だけで全ての呼びかけと条項が対応すると保証するものではない。

`rim`の前件は対象内容の不成立である。故意の違反、虚偽の発言、期限超過を同定するには、それぞれを表す対象内容が必要になる。将来の履行全体を対象関数に含めれば、条件はその全体の不成立について述べる。応答も任意の内容を渡せるため、処罰・非難・儀礼のどれかは型だけでは決まらない。今回の検査は、具体的な制裁や神の概念を記述し終えた結果には数えない。

検査では、生起・本人による表明・引受け・厳粛な表明・呼びかけの5条件を独立に変える32通りを確認した。二人の厳粛さと呼びかけの16通り、別人・別行為・別時点・別名・引数の反転・代替行為を含む10対照例も調べた。一つの行為で約束し、別の行為で儀礼を行った記録を組み合わせても成立しない。他の適切な同一行為があれば、その行為を証人にできる。

目的志向と二人それぞれの追加条件の8通りも検査した。目的主体は基準文脈で指定する範囲のままで、全当事者へ同じ目的を補わない。条項・権威の性質・応答・目的の真理を未知にしても表明を記述できるが、厳粛さや呼びかけの記録そのものが未知なら検査器は推測せず停止する。条件内容の真理表4通りでは、呼びかけと断言の発話を区別した。

[一般文書](../examples/v014/solemn-undertakings.noema)は3,386文字、[原文付き草案](../examples/v014/kant-solemn-undertakings.noema)は121,880文字、[抽出文書](../examples/v014/solemn-undertakings-core.noema)は4,165文字である。7定義を追加し、親の宣言と15件の主張を保持した。新しい著者主張は追加していない。[意味規約](../data/kant-solemn-undertakings-basis-v1.json)と[検査記録](../reports/solemn-undertakings-v1.json)に対応範囲と限界を保存した。

この構成は制裁を呼び求める宣誓への候補であり、全文化の宣誓の必要十分条件ではない。原文で指定されていない呼びかけ先・慣用式・応答を補って完成扱いにはしない。契約の資格や正当性、宗教・教会の説明、反語と強調、問い全体と回答の著者帰属は未完で、全文単位の意味確認済み件数は0のままである。
