# 二乗振幅比の零角の場合と形式の比較

u0199–u0200を、直前の二乗振幅比の式への照応、φ=0の条件、より簡明な形への提示と表示へ接続する。原刊912頁のM0346はφ=0、M0347はA′²=A²(1−v/V)/(1+v/V)であり、この式に根号はない。

ekivは同じ63設定ekibに旧実数角angle=0を加える。先行の角の規約によってcosφ=1となるが、余弦だけの指定で角の条件を代用しない。電気側又は磁気側の選択、旧新の非負の振幅、物理場と校正、局所近似の誤差と十分性を引き継ぐ。

同じ59全称役割と零角条件の下で、一般形をekix、特殊形をekiyとして表す。許容域0<v<Vでは1−rと1+rは正なので、一般形のA²(1−r)²/(1−r²)はA²(1−r)/(1+r)となる。新振幅の二乗を新振幅そのものへ替えず、分子と分母の差・和を保持する。

welche Gleichungは直前の表示eiss6とその内容ekikを受ける。eissbによる書換え提示の前後には、同じ零角条件のekixとekiyを渡す。einfachereは、同じ記号規約で構成や依存量を読み取る際に、特殊形の方が少ない入れ子や補助量の追跡で済むという厳密な比較としてeistbへ結ぶ。これはeisspと同じ評価観点の二項比較であり、新しい形が単独で簡明という絶対評価への置換ではない。両方が簡明でも比較でき、逆方向や同程度の評価では満たさない。

コロンから同じ特殊式への説明と順序、表示内容、著者・論説への帰属を保持する。形式比較だけで内容の同値性や真理、導出の容易さを認定しない。原刊と電子在庫のM0345の相違は先行の照合記録のまま残す。

検査は同じ実数角の条件、63設定の全位置、二内容の各59全称位置、正負零の速度や零振幅を含む式の代数対照、負号・和・二乗・尺度変更、比較相手と方向、引用・照応・表示を扱う。角の境界診断用pi=4は正本の積分で定めるpiではない。許容物理域の外の数値検査を物理的主張へ広げず、全実数の評価を有限列挙で代用しない。
