# 観点を限った時代の分類と、人物にちなむ呼称

カントu0014末尾の「この観点では、この時代は啓蒙の時代、あるいはフリードリヒの世紀である」という箇所へ、対象を共有する分類・呼称の部分草案を加えた。先行する機会の成立過程と障害の漸減を、同じ時代についての性質として渡す。人物にちなむ呼称は別の性質記述で保持する。

| 定義 | 内容 |
| --- | --- |
| `rmu` | 同じ役職・始年・終年の在職記録を使う人物プロフィール |
| `rmv` | 明示した候補範囲で、プロフィールに当てはまる者が指定対象ただ一つである |
| `rmw` | 指定人物の指定役職への在職時点と重なる時代区間という描写 |
| `rmx` | 同じ著者・箇所・対象記述に、異なる二つの性質記述を呼称として用いる |
| `rmy` | 呼称の使用に加え、対象記述が同じ範囲で指定対象を一意に指す |
| `rmz` | `rmy`に加え、その対象について観点の性質が実際に成立する |
| `hzfj` | 同じ人々・履歴・進行内容を保持した、時代ごとの進行条件 |
| `hzfk` | 人を表す`aa`を使う、在職時点と重なる時代の描写 |
| `hzfl` / `hzfm` | 始年1740・終年1786の在職プロフィールと、その範囲内での人物の一意性 |

「この観点」は、閉じたNoemaの性質記述へ接続する。今回の具体例では、同じ人々の自由な取り組みの機会が新しく生じる過程と、その人々の能力を尺度にした障害の漸減を使う。この分類が成立しても、能力への到達や、他の観点での分類までは補わない。他の観点では必ず不成立である、とも主張しない。

二つの呼称が同じ対象を指すことと、二つの性質が一般的に同じ意味を持つことは異なる。原文の接続を同じ時代への別の描写として扱い、二者択一の排他的選択にしない。同じ真偽を返す別名へ、著者の呼称使用の記録を自動的に引き継がせることもない。対象記述が複数の時代を指す場合、指定した時代を勝手に選ばない。

呼称を使う記録だけなら、二つの描写の真理を実行評価せず保持できる。記述した内容が偽でも、その呼称が使用されたことはあり得る。`rmz`で観点の実際の成立を追加し、検査用の最も強い組合せでは人物の一意性と在職時点との重なりも確認する。これらは、それぞれ別に否定できる条件である。

時代の呼称には一般の対象を受け取る`presents`関係を明示的に渡す。既存の`du`は人の集団に対する呼称を意味するため、そのまま時代へ適用しない。今回の具体例の提示記録は検査用の解釈であり、本文中の著者による提示をすべて実装・確定したものではない。

人物名の参照確認には、単なる綴りの一致に代えて、役職と在職期間によるプロフィールを使う。フリードリヒ二世について、ドイツ歴史博物館の所蔵品目録はプロイセンの王と在位年1740–1786を記載している。[DHMの所蔵品目録](https://www.dhm.de/archiv/sammlungen/kunstgewerbe/89_1157.html)を2026年10月14日に確認し、参照情報を検査記録へ保存した。この情報を原文の人物への文脈的な同定候補として使うが、目録だけでカントの指示対象を証明したとはしない。

在職年は人物を同定するための編集上の情報であり、カントがこの箇所で年を述べたという主張は追加しない。人物が候補内に存在しない場合、複数人が一致する場合、別の役職や年の記録である場合は同定を認めない。候補の実世界での網羅性、記録の真実性、プロイセンの王位の制度的説明、暦と年単位の精度は入力規約として残る。このプロフィールだけで固有名の社会的な意味や人物の全経歴を説明し終えたとは扱わない。

人物にちなむ時代の描写では、在職時点との重なりを使う。時代と在職期間の境界が完全に一致することや、長さがちょうど100年であることを要求しない。その人物が進歩の原因である、功績を独占する、全員がその人物を称賛する、といった内容も導かない。原文の歴史的な時代区分や修辞の全意味を確定したものではない。

[一般文書](../examples/v014/named-epochs.noema)は1,943文字、[原文付き草案](../examples/v014/kant-named-epochs.noema)は182,937文字、[抽出文書](../examples/v014/named-epochs-core.noema)は20,409文字である。十定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-named-epochs-basis-v1.json)と[検査記録](../reports/named-epochs-v1.json)を保存する。

分類・在職・人物記録・呼称使用の16通りを検査した。原文付き文書と抽出文書それぞれで、基準例、人物の曖昧さ、在職年の不一致、時代との重なりの不成立、進行条件の不成立、別の呼称への記録の六条件を検査した。追加16テストは人物と時代の一意性、対象範囲、別役職、別名・別著者への帰属、未知入力の拒否、引用内容の非実行、過去の文書の固定を検査し、全て通過した。三文書のCLI解析と固有文字v2の往復、SVGのXML検査も通過した。SVGの目視確認は含めない。
