# 定義と本文の接続確認（2026-10-15）

部分定義を増やすだけでは、論文本文を記述したことにならない。今回、本文の各主張・質問・仮定から、直接または他の定義を経由して参照される記号を調べる機能を追加した。引用内の参照も含むが、引用した内容を実行したり、著者の主張を真と認定したりはしない。

## 現在の接続状況

| 対象文書 | 文の数 | 定義数 | 本文から参照される定義 | 本文から参照されない定義 |
| --- | ---: | ---: | ---: | ---: |
| einstein-additive-charge | 175 | 1,169 | 787 | 382 |
| kant-unrestricted-others | 15 | 1,055 | 220 | 835 |

「文」はNoema文書の最上位の文を数えたもので、原文の区間数とは異なる。参照されない定義には再利用用の関数も含まれるため、この数を未完成率に換算しない。外部から与えられる関数値の内部は追跡できず、同じ値になる別名への参照も推定しない。

理系側では、M0390の式を提示する実際の文が、`senx → senw → senv → sent → sens` を通して数式と参照先へつながっている。著者への帰属と先行箇所への説明関係も `seny` で記述済みだった。この点について古い確認記録を引き継ぎ、[確認記録v2](../data/density-formula-review-v2.json)では「構造上は接続済み」に更新した。旧版は変更していない。

一方、その文が受け取る密度・速度の帰属関係は `zqd` のままである。後から作った速度の説明 `seoe/seof`、局所密度の説明 `seom/seon`、加法的な総電荷の説明 `seou/seov` は、この文にも他の本文の文にも参照されていない。文系側でも、最近追加した `hzgv`、`hzgy`、`hzg3`、`hzg4` は本文から参照されていない。個別のテストで使えても、本文への統合は別に必要になる。

## 単独で確認できる本文

[密度の式を提示する一文](../examples/v014/einstein-density-manuscript.noema)を、必要な67宣言とともに抽出した。元文書の175番目の文をそのまま保ち、不要な1,725宣言を抽出結果から省いた。原文書は変更していない。これは定義だけの抜粋ではなく、著者・提示箇所・先行箇所・範囲・文脈・引用内容を持つ実際の一文を含む。

[意味規約](../data/einstein-density-manuscript-basis-v1.json)には、元文書の未解決事項を削らず残した。その全部がこの一文の完了条件という意味ではない。この一文に関係する未解決事項は、確認記録v2で区別している。

次は、`zqd` と後続の説明をどう結ぶかを明示し、そこで加える連続性・微分可能性・密度の存在などの条件が原文の主張を狭めないか確認する。説明を置換するだけでは意味一致にならない。基準系や電気的帰属の意味規約、先行するM0389との関係、原文単位全体の確認も残る。物理理論の実証的な真偽を、翻訳完成の条件にするものではない。
