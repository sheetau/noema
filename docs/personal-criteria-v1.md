# 当事者が採用した基準に基づく合意

カントu0013の「当事者自身の、よりよい理解についての考えに従って」という部分に、判断と合意を結ぶ構成を追加した。各当事者が採用した比較基準、その基準についての本人の判断、同じ引受け表明でその判断を理由に使うことを区別する。判断があることから、実際に理解が改善したとは結論しない。

| 定義 | 内容 |
| --- | --- |
| `rlg` | 同じ人・対象・判断・基準記述・引数列を結び、非空の判断候補で内容が成立する |
| `rlh` | 同じ本人と共同体について、二制度に対応づけた認識段階を既存の情報拡大条件`ri5`で比較する |
| `rli` | 比較内容を本人・共同体・旧制度・新制度の四個体列へ接続する |
| `rlj` | 制度変更への合意に、各人が同じ引受け表明で自分の採用した基準の判断を理由に使う条件を加える |
| `hzeo` | 人、表明行為、時間順序、本人の判断と対象の既存規約へ`rlj`を接続する |
| `hzep` | 変更側を`hzeo`で選び、前版と同じ継続条項の保護・観測・維持側の条件へ接続する |

判断候補は、その人がその判断で採用した状況である。空なら肯定判断とせず、実際の状況を必ず含むとも仮定しない。そのため「本人は改善だと判断しているが、実際の改善条件は偽である」という組合せが成立する。実際に改善していても、本人がそう判断していなければ、この理由に基づく合意の条件は満たさない。

比較基準は、型付きの閉じた式の記述として指定する。同じ記述を、本人による採用、判断の対象、その内容の評価に使う。各人が異なる基準を採用していてもよい。別の記述が偶然同じ真偽を返すことから、その記述も本人が採用したとは扱わない。四つの引数は順序を保ち、旧制度と新制度の逆転や、別の人・共同体への交換を拒否する。

理由は、合意と無関係にどこかに存在するだけでは足りない。同じ当事者が同じ条項を引き受ける、同じ表明行為・同じ時点へ判断を結ぶ。その表明は現在の評価時点と同時か以前でなければならない。過去の引受けに、将来行う別の表明の理由を結びつけても、現在の合意の理由にはならない。

検査作例の比較基準には、既存の`ri5`を用いる。同じ範囲の正しく支持された情報を失わず、区別できる情報が厳密に増えるという条件である。受け入れる命題項目が増えても、内容が以前と同じなら改善とは数えない。ただし、この基準で理解一般を定義し終えたわけではない。制度と認識段階の対応は明示した入力であり、制度変更が理解を改善するという因果の証明にもならない。

政策への接続でも、当事者の判断を実際の改善に置き換えない。判断に基づく合意を持つ共同体を変更側として選び、その同じ合意の継続条項を保護対象にする。理由の条件を欠く共同体が選択範囲から外れても、その共同体に関する保護の実施を、この条件文だけで要求するものではない。旧制度を望む側の条件は保持する。

政策を提案として引用する検査では、条項と基準の選択関数を既知の閉じた構成へ固定して、静的な特殊化で脱引用を除去する。提案すること自体の成立には、未知の基準の真偽、政策の実施、保護の実現を実行評価しない。

[一般文書](../examples/v014/personal-criteria.noema)は5,258文字、[原文付き草案](../examples/v014/kant-personal-criteria.noema)は164,456文字、[抽出文書](../examples/v014/personal-criteria-core.noema)は17,685文字である。六定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-personal-criteria-basis-v1.json)と[検査記録](../reports/personal-criteria-v1.json)を保存する。

これは原文の一つの部分的な読みである。判断候補による信念モデル、基準の採用と理由の使用の認知過程、事前に形成された判断の保持・再利用、洞察の質などは未構成である。宗教制度の具体的な内容、共同体の代表資格、原文の不確定性と接続法、君主の位置、著者帰属と全文の意味確認も残る。

基準の採用・対象の結合・理由への使用・判断候補での成立・実際の成立の32通りと、九種類の対照例を検査した。原文付き文書と抽出文書では、政策への接続三例ずつと、未知の内容を実行しない提案を確認した。統合の基準例は39,052,263ステップで通過している。追加14テスト、三文書のCLI解析と構文木の一致、固有文字v2のSVGのXML検査も通過した。SVGの目視確認は含めない。
