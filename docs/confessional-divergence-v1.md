# 採用信条と発表内容の相違

第八段落第二文の「採用信条から所々異なる判断と洞察」を、同じ論点に関する内容の比較へ接続する。教会が採用した信条、信条が肯定的に含む部分、その部分が同じ論点で述べる内容を、既存の定義と関係で固定する。新しく加えるのは認識項目と比較論点の一般的な結合一つであり、相違そのものは既存のrpbで構成する。

比較する双方の内容はNoema命題として与える。教示規則への不適合、語句の違い、無関係な別論点の追加だけで相違とはしない。固定した関連候補の一つ以上で内容の真偽が異なるという明示した読みを採る。現在の真偽が一致するだけでは内容の一致とせず、双方が現在真でも他の関連候補で異なる場合を扱う。

hier oder daは、発表する見解群の少なくとも一論点で差があることと読む。全項目での相違、正確な割合、他の全論点での一致、信条全体の否認は要求しない。その同じ項目列を、本人の保持判断・洞察、公的な発表、同じ内容の審査目的へ結ぶ。個々の教理は原文に指定されていないため補わない。

新しい実行記述は後続の自由と職務義務の保持へ渡すためのもので、現に発表したという著者の主張は追加しない。君主への照応、聖職者への敬意、他者へのなおさらの適用と全文帰属を統合してから第二文全体を判断する。
