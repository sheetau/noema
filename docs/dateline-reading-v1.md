# 日付行全体の読解と暦の指定

カント末尾のu0019を、同じ論説の場所と日付を表示する一つの行として再読した。固定転記は「Königsberg in Preußen, den 30. Septemb.[er] 1784.」。保存した原刊494頁を視認し、場所・地域・30日・Septemb.・1784の順と署名の下の配置を確認した。[er]は電子版による展開である。

暦はグレゴリオ暦の西暦1784年9月30日と読む。根拠はRoland Wielenの[暦勅令の研究（2016年、188頁）](https://edoc.bbaw.de/files/2589/BBAW_Publikation_Jahresthema_2015_16_Leibniz_edoc.pdf#page=207)である。同頁は1700年以降の改良暦の日付計数とグレゴリオ暦の一致、復活祭計算法の相違、1777年からの統一を説明している。これを当該日付に適用するのは、このレビューの歴史的推論である。カント自身が暦名を書いた証拠とは扱わない。プロイセンの最初の改暦年について検索結果に現れた1610年・1612年のいずれも、判断の前提にしない。

月名の番号、月長、閏年と西暦の年始は、前段で保存した[USNOの暦の章（597・599頁）](https://aa.usno.navy.mil/downloads/c15_usb_online.pdf)に照合している。数値的規則はNoemaの既存定義に分解済みである。史料の同定と算術検査は別の根拠なので、数字が有効であることだけから歴史的な暦の使用を結論しない。

`hzix`の規約に、この採用した暦の読みを明記した。`hzjg`と`hzjh`には旧版の「列内の位置」という説明が残っていたため、実装通り月番号・日番号による一意の指定へ直した。全宣言、本文23文、名称の識別表記は保存し、Noema本文の長さも増やしていない。規約を改訂したため本文・規約・識別表記を後継版として固定し、旧版は残す。

日付行が述べる関係は、名称が場所と地域を指すこと、その場所が当該日の地域内にあること、同じ文書の日付行がその場所と日を表示することの組合せである。地名は名付けの対象を持つ固有名として扱い、名称個体と場所個体を区別する。「プロイセン内」という関係は地理的な所在として説明されており、現代の国家・国境・座標を補わない。原文にないUTC時刻、提示者、実際の執筆場所、執筆完了日、刊行日は要求しない。日付の指示と日時への換算は異なり、ここで時刻を未指定に保つのは意味の欠落ではない。

この読みで、原文全体、依存する21宣言の規約、日付の三階層、同一文書への表示を点検し、八項目を満たすと判断した。[単位別の判断](../data/dateline-review-v1.json)を明示的な登録簿へ加える。これはアシスタントによる読解であり、独立査読や意味一致の自動証明ではない。有限モデルは誤った参照・番号・曖昧な割当を区別できることを確認する。史実の真理や原文解釈の唯一性を証明しない。

日付行は43非空白文字であり、既存の署名16文字と合わせても59文字である。意味確認済みの単位が二つになっても、二作品全体や任意の内容への表現力を確立したことにはならない。脚注には刊行物の関係、敬称、代名詞、思想の比較などの課題が残る。
