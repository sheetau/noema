# 時計の移動・帰還・地球上の比較の円文字表現

u0126–u0128の七つの既存主張を、一組の依存関係として円文字本文へ接続する。直線上の移動、多角形経路での帰還、曲線への拡張を仮定した帰結、地球上の時計の比較を扱う。既存100定義を再利用し、機械時計・回転物体・物理的推論に関する15規約を任意プロファイル61へ接続する。共通375語と固定アルファベットは維持する。

直線移動では、初期区間全体で同期している同じ二時計を使う。移動する時計の三次元の全軌跡、Bに留まる比較時計、出発と到着の出来事、実際の局所的な表示、両系の記録を結び付ける。到着後の不同期と遅れは同じ到着出来事・場所で比較する。経過時間と表示の遅れは同じ正の秒換算尺度で測る。二次の遅れと高次の残差を分け、一定の経過時間に対するO((v/V)⁴)の条件を、距離を固定した別の一様評価へ置き換えない。

多角形経路は任意の非空な有限列として表す。隣り合う区間は同じ境界出来事と表示を共有し、単に同じ場所に着くことでは代用しない。交差する経路や、後の時刻に出発地点へ戻る経路を許す。採用した読みの範囲では、長さ零の区間や途中の待機は挿入しない。始動・方向転換・停止による追加の表示変化がないという理想化は解釈注記に残し、著者の条件文の前件へ紛れ込ませない。

曲線への移行は原文の明示した仮定として保持する。多角形の場合の結果を証明済みとして提示することと、曲線へ適用する仮定を区別する。位置の連続微分可能性、連続した速度、端点での片側微分を含む全軌跡を扱い、頂点の有限標本だけで代用しない。この接続は、加速中の時計の物理的な振る舞いを慣性系の式から証明するものではない。

地球上の比較では、てんぷによる歩度調整、機械的な構造の一致、その他の条件の完全な一致、回転軸に対する場所、文脈上の非常に小さい進み率の差を分ける。両極を許し、文字盤の表示原点の一致を歩度比較の条件にしない。推論の候補状況は結論の真偽を調べる前に定める。候補が空でないこと、基準状況を含むこと、全候補で帰結が成立することを本文で要求し、規範上の許可や無制限の論理的必然性へ読み替えない。

時計・出来事・記録・数値・設定の参照は、既存の型付き参照規約で取得する。直線移動の13参照は同じ16項の設定関係から順に選び、先に選んだ項を固定し、残りをその型で存在量化する。地球・軸・設定・条件範囲も循環しない役割で結ぶ。地球の参照を、時計の進み率の結論が成立する物体という定義にはしない。解釈注記と推論範囲にはそれぞれ独立した役割を与える。参照取得は役割の引用を実行せず、対象の存在・一意性や物理法則の成立を証明しない。

第59段落の二文、第60段落の一文、第61段落の二文を保持する。Sek.の略記、曲線の文中のコロン、ページをまたぐunbewegtを新しい文の境界としない。経過秒数の二つの表記は、直線と曲線それぞれの全引数を持つ規則へ結ぶ。

検証では既存の識別モデルを復号した定義へ接続し、元の量化本体も別に照合する。多項の参照役割は他の証人を固定して一つずつ結合を検査し、大きな領域の全組合せを列挙しない。これは有限の結合診断であり、全実数域の証明ではない。意味の採用判断、円文字の復号、描画確認、第三者による独立読解はそれぞれ区別する。実行結果と未完了の工程はプロジェクト台帳に記録する。
