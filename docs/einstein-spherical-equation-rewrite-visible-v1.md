# 球面方程式の変換と同じ計算の評価

原文u0089–u0090の計算提示と表示式を円文字本文へ接続する。既存の7合成定義を使い、意味規約と参照型は追加しない。共通375語と任意プロファイル52版の787語をそのまま使う。

原刊901頁の第46段落を、本文13トークンと末尾の式・句点を合わせた14トークンの一文として指す。「この方程式」は直前のKの球面式、「われわれの変換式」は現在の四座標式へ結ぶ。式の内容は三平方の和と光速度・時刻の平方の積で表し、外部の数式識別子で代用しない。

書換えの前提は、同じKの球面波、到来点のKの式、四座標変換、対象出来事の両系における現在の記録範囲である。全て同じ設定と速度・係数関数を使う。別の原点定数を足したり、未確定の係数関数を1に固定したりしない。

任意のKでの到来記録には、同じ出来事のkの記録が必要である。その全ての記録対についてkの二乗式を要求し、対応記録の欠落を空の全称で成功扱いしない。同じ値を持つ別記録も対象にする。二乗式だけから正時刻、係数の正値、kでの全波面、二原理の両立性の証明完了は導かない。

「簡単な計算」は、同じ著者が同じ文脈で利用できる方法についての評価として表す。その一つの有限手順列が、現在の前提から同じ結果まで許容された変形でつながり、各手順の出現ごとの非負負担の合計が文脈上の低負担基準に入る。原文にない手順数・実行時間・数値閾値は指定しない。引用した前提や結果は評価中に実行せず、計算の評価と物理的な真偽を分ける。

書換え、計算評価、著者、第三節、本文箇所と直前の式との順序を接続する。検査では、全到来記録と対応する座標、負・零の係数、記録の別名、手順の欠落・逆順・重複・負負担、方法と文脈の違い、引用の非実行を区別する。旧検査のモデルを使う場合も、検査対象の定義は復号したNative本文へ置き換える。有限診断を一般実数上の証明や独立した読解と同一視しない。
