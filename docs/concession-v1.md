# 先行する条件と、期待に反する成立

[先行条件と譲歩の定義](../examples/v014/concession.noema)を既存文法で構成し、[カント第二段落の草案](../examples/v014/kant-prior-concession.noema)へ接続した。前後関係、十分以前という文脈的な程度、通常の期待に反して成立することを別々に表す。

## 「前」と「とうの昔」を分ける

teは、同じ時間的履歴内のある状況が、生涯として評価する範囲の全状況より先行する条件である。履歴と範囲には、前版のtbによる順序・非空性・途中の状況を省かない条件を要求する。評価範囲の途中や、別の履歴の状況を先行条件として使わない。

tfは、さらに経過が文脈的な基準を満たすことを要求する。単に前であることと、十分以前であることを同じ意味にしない。何年前なら十分かという数値は、原文へ補わず引数で明示する。

## 「それでも」の期待を明示する

jaは、ある前提を認めたときに通常予想する比較候補が空でなく、全候補でその前提が成立し、結論が成立しない条件である。候補集合は人物・前提の記述・文脈を区別して与える。前提を満たさない候補や、空の候補から、期待に反するという結果を作らない。

jbは、実際の文脈では前提と結論が両方成立し、jaの比較候補では結論が成立しない条件を結合する。例えばAとBが実際に成立していても、Aの下でBが成立しないという期待がなければ、この譲歩条件は成立しない。比較候補の期待を、現実の論理法則や因果法則として追加することもない。

これは明示した候補集合を使う操作的な読みである。候補の採用根拠、確率的な予想、自然言語の譲歩の全種類を定義したものではない。前提の内容と記述の対応は呼出側で保持する。

## 自然的な成熟と知的自立の区別

kcは、人であり、自然的な成人の段階に達し、自然的な発達上の依存によって他者の指導が必要な状態ではない、という条件を構成する。自然的成熟kaと発達上の依存kbは意味規約を与えた基本関係であり、その一般理論の構成は残る。

原文の自然による解放と括弧内の説明を手掛かりにした部分的な読解である。これを、知的自立が現にできること、実際に他者の指導を受けていないこと、特定の法定年齢に達したこととは同一視しない。自然を宣告者に見立てる比喩の働き、ラテン語の独立した語義確認も未完として残す。

kcは状態の条件であり、依存する状態からそこへ移行する出来事までは記述していない。先行する状態の成立と、解放という過程の全体の記述を区別する。

kfは、同じ人の履歴で、生涯の評価範囲より十分前にkcが成立した状況があるという内容である。kgは、このkfと前版の持続的な状態ieを結合し、著者の視点でkfを認める通常の比較候補ではieが成立しない、という譲歩を表す。視点は既存の著者waへ接続し、別人の期待や別の前提を混ぜない。

khはkgを既存の割合表現hqへ渡す。kiは比率を明示した検査用の形である。「とうの昔に自然による解放があったのに、それでも好んで生涯未成熟に留まる」という対比を、同じ人々の性質として接続した。怠惰・臆病の原因説明、後見人になることの容易さ、残る段落は未接続であり、本文全体を記述済みとはしない。確認済み全文単位数はカント0/20・アインシュタイン0/282のままである。

## 検査

前提・結論・候補の256組合せで、実際の真偽と期待の区別を検査した。時間の7対照例では、同時・後・履歴外・空範囲を拒否し、先行だけを満たして経過基準を満たさない場合を区別した。

原文に接続した12例では、他の人だけが成熟している場合、発達上の依存が残る場合、前後が逆の場合、異なる視点・人物・前提を使う期待、前提を満たさない候補、実際の持続の欠落を検査した。さらに二つのモデルで割合表現との接続を確認した。有限の時間範囲は結合の検査用であり、現実の生涯全体の再現ではない。

```powershell
python -S -m scripts.compose_concession
python -S -m scripts.check_concession --verify-only
python -S -m noema parse --input examples/v014/kant-prior-concession.noema --output artifacts/kant-prior-concession.json
python -S -m noema render --input examples/v014/kant-prior-concession.noema --alphabet v2 --output artifacts/kant-prior-concession.svg
python -m pytest -q
```
