# 公的発表の自由と職務義務の保持

第二文のunbeschadet ihrer Amtspflichtを、発表によって職務義務を免除せず、同じ発表と全義務の履行が両立するという読みで構成する。自由は積極的許可と反対要求の不在であり、両立だけから許可を推論しない。

各義務は出所、本人、職務、目標記述、束縛列、内容の基準、極性、規範の評価点を保持する。選択一覧が実際の要求であることに加え、同じ型で表す職務要求が一覧にすべて含まれることを要求する。比較候補で義務を消したり別の要求に取り替えたりして履行済みとはしない。相反する要求があれば、保存はできても共充足はできない。

発表と履行は同じ候補点で成立する必要がある。発表できる候補と義務を果たす候補を別々に見つけても足りない。比較範囲内の全発表候補に義務の非免除を要求し、その中に履行との共充足が一つ以上あることを確認する。現実の発表、身体的能力、因果的な無害性はこの読みからは追加しない。

全目標記述・全束縛列への量化は有限評価器では列挙しない。限定した診断と全域評価の拒否を区別する。新しい基本記号は追加せず、既存の規範関係と発表記述へ接続する。職務や比較範囲の本文への供給、君主への照応、敬意、他者への適用、全文帰属は引き続き統合が必要である。
