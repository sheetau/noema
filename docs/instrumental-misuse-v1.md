# 機械的な使用と誤用を、同じ原因行為へ結ぶ

カント第三段落第三文の部分記述を接続した。規定や定型表現を吟味せず使うこと、自然的な能力の誤用、その行為が未成熟の持続へ関わることを、同じ本人・能力・使用行為について述べる。第三文全体の意味確認は未完である。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)

従来の足枷の対象側 `h2i` は、規定または定型表現の使用活動と、未成熟の持続への結果生成を結んでいた。一方、機械的な使用と能力の誤用は別の部分定義にあり、その同じ活動へ接続されていなかった。新しい `r2er` はこの接続を行う。別人の能力使用や、別の活動の誤用・結果生成を借りて成立させない。

## 吟味の不在と誤用を分ける

一般形 `r2ep` は、本人が対象を活動で使うことと、その適用を吟味する本人の判断が同じ文脈にはないことを結ぶ。使用、判断、判断の対象、適用の吟味という四関係を引数にする。別人が考えたこと、別の対象や活動を検討したことを、この使用への本人の吟味とは数えない。記録が見つからないというだけで判断の不存在を入力するものでもない。

この一般形には、一項の式の型や具体化された式を必須条件として入れない。既存の `h24` はそうした式の使用の構成例だったが、吟味せずに使うこと一般をその形式だけに限定する必要はない。今回の本文では既存の表現使用 `hx2` と判断関係を渡す。定型表現の分類 `h22` に残る一項の型という制約を、これで解消したとはしない。

`r2eq` は、同じ使用活動に既存の誤用 `hn2`、活動の生起、結果生成 `g3`、結果の成立を結ぶ。誤用は同じ本人の同じ自然的能力を同じ活動で使う条件を含む。適用を吟味しなかっただけでは誤用にせず、合理的使用の評価があるだけでも成立させない。合理的使用から誤用への言い直し `ho2` はそのまま保持する。

| 定義 | 内容 |
| --- | --- |
| `r2ep` | 対象を使うが、その活動への適用を本人が吟味していない一般形 |
| `r2eq` | 同じ能力・活動の誤用、生起、結果生成と結果の成立 |
| `r2er` | 規定または定型表現について、同じ活動を満たす能力と行為がある部分関係 |
| `r2es` | 道具側の対象と利用者を二つの位置で保持する列への変換 |
| `r2et` | この対象側を、同じ位置対応の足枷で描く著者への帰属 |

五定義を追加し、新しい基本関係は追加しない。本文54文のうち第53文の対象側だけを改訂し、他の53文、第三文の言い直し、第四文の条件付き跳躍を保持する。

## 持続と原文判断の限界

未成熟の持続には、既存の `h26` の指定範囲内での条件を使う。途中で状態を失う場合や能力評価が欠ける場合は成立させない。ただし、この範囲は `immerwährenden` の意味全体を確定したものではない。Dudenにも持続を表す説明があるが、現代辞典だけから原文の唯一の範囲や無期限性を決めることはできない。[Duden「immerwährend」](https://www.duden.de/rechtschreibung/immerwaehrend)

今回の対象側は、実際の使用活動と結果生成を要求する部分候補である。道具の目的・潜在的な働き・通常の作用の全条件とは区別する。規定の制定と拘束性、任意の型の定型表現、二種類の一般化と列挙、持続の強さ、第三文全体の比喩の読みは残っている。

## 検証

一般形では使用と三つの判断関係の16組合せと十三対照を検査する。使用・吟味・誤用・生起・原因・持続の64組合せと二十四対照では、本人、対象、能力、行為、時点、結果の取り替えを検査する。使用する行為と誤用・原因の行為を別々に与えても、同じ行為を存在させる条件を満たさない。

この64組合せは持続内容だけを分離した接続試験である。別に、現行の能力と `h26` を置換せず実行する四例で、基準例、後の能力取得、評価欠落、別の原因行為を検査する。これは有限の持続範囲の検証であり、永久の持続を証明するものではない。

比喩帰属の八対照では、対象側と身体側を入れ替えることや、古い対象側へ戻すことを拒み、引用内容を実行しない。規定・定型表現の分類は式記述の全域への量化を含むため、有限評価器で全体を実行することは拒否する。少数の既知の式だけでその全域を代用しない。未知入力、既存三報告の宣言・意味規約、先頭二文247文字の判断、十二全単位2,212文字の判断、三記法の往復も確認する。

対応記録は既存の三範囲 `[316,344)`、`[345,416)`、`[427,438)` のままで、新しい対応文字数や意味確認済み分量は増やさない。

検証は `python -X utf8 -m scripts.check_instrumental_misuse`、テストは `python -X utf8 -m pytest tests/test_instrumental_misuse.py -q` で実行する。
