# 公的な承認主体と厳粛な合意の方式

カント第六段落の文 `[444,712)` に向け、最高権力の保持者、帝国身分会議、合意文書を通じた確認を分けた。これは依存定義の構成であり、和平締結の分類と一文全体の意味判断は残る。

`r5am/n` は既存の厳密な順位 `rex` と最高位 `rqyi` を使い、同じ政治的共同体を管轄する組織の最高役職とその保持者を結ぶ。会社内の最高位だけでは政治的な最高権力としない。保持者を一人に限定せず、制度的な位置から道徳的な正当性を導かない。

`r5ao–s` は帝国共通の機関、構成身分、全所属者の代表資格、公的事項の審議という共同実践を結ぶ。本人の身分上の資格で参与する場合と、同じ役職・身分から派遣された場合を許す。構成身分と所属者の両方向を確認し、出席者だけを範囲にしない。審議は既存の行為・担い手・会議手続・論点・議決担当を使って記述し、実践の引用だけで会合の実行や議決の成立を求めない。

`r5at/u` は厳粛な締結・公示方式を固定範囲で比較する。同程度の最上位を許す `rqyi` を再利用し、比較不能と同程度を区別した。「厳粛」の分類も別に要求するため、装飾のない方式だけを集めて最高位と呼ぶことでは成立しない。合意が方式を備える候補点と、方式を比較する固定基準を区別する。

`r5av–y` は同じ契約への確認を構成する。最高権力と帝国身分会議は主体として承認し、合意文書は条項を通じて確認の根拠となる。三種類のいずれかの確認を条件に使えるが、全歴史的会議・全条約の同時承認は要求しない。合意の種類は明示した関数引数に残しており、和平締結を名称だけで充足してはいない。

語義と制度的な読解は [根拠記録](../data/public-confirmation-evidence-v1.json) に保存したAdelungの Obrigkeit・Feyerlich と、1654年の帝国議会決議の掲載転写本文に照らした。原刊488頁と対象文は [読解記録](../data/public-confirmation-reading-v1.json) に固定する。歴史的な個別税制・軍制・開催日を原文の分類条件へ輸入しない。

検査は最高位と極大・循環・欠落役職、保持者と管轄、代表資格と構成範囲、同じ審議行為、実行されない実践の引用、同順位と比較不能、主体と文書の別、契約・点・比較基準の入替えを扱う。大きい構成を境界付きで検査する箇所は報告に明示し、その境界の定義は別の局所検査で実評価する。有限モデルは制度や語義の完全性を証明しない。
