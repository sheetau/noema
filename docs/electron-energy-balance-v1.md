# 仕事積分と無放射のエネルギー収支

u0261の場から取り出すエネルギー、粒子の初期・最終運動エネルギー、放射量を別々に記述した。全ての値を同じ交換過程・粒子・場・基準系・両端の出来事・エネルギー単位へ結ぶ。数値が等しくても、別の場や粒子、時点、単位に属する量で条件を満たしたことにはしない。

収支は「取り出した量＝最終運動エネルギー−初期運動エネルギー＋放射量」とし、この過程で他の移転や内部エネルギーの変化がない設定を明示する。この収支と初期運動エネルギー零、放射量零を合わせると、取り出した量と最終運動エネルギーが等しくなる。初期運動エネルギーと放射量が等しい非零値でも同じ等値が成立するため、等値から無放射を逆推定しない。

仕事は、電荷と静電場の軸方向成分の積を位置について積分する。正方向は既存の全分割による積分、逆方向は符号反転、零区間は値零として定義した。電荷や場の符号を正に固定しない。本文では原点から指定位置までの積分を同じ取り出したエネルギーへ接続する。速度についての積分への変数変換はまだ接続していない。

積分の向きと符号の検査には、登録した定数場だけを扱う解析的なモデルを使った。関数の構文と参照先を確認し、未知の関数を有限点で標本化して積分値を補うことはしない。このモデルは上下端・電荷・符号の接続を検査するもので、全実切断の積分の定義を証明するものではない。

初期エネルギー零は原文の初速零に対応させる前提として置いた。軸上の軌道、静電場と力の基礎説明、ゆっくりした加速から放射しないという読みの論証は残る。収支も物理法則から証明済みとはせず、明示した前提として扱う。単位は積分とエネルギー値に整合する共通規約を仮定し、任意の単位の数値を直接掛け合わせる一般化はしない。
