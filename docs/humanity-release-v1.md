# 時点別の人類と同じ君主による解放

第八段落第一文の「最初に人類を、少なくとも政府側から、未成熟から解放した」を、各出来事の前後の人口に対して構成する。9定義r5z3–r5z7・r52a–r52dを追加し、新しい基本関係は置かない。本文112主張・登録簿v196・確認済み17単位は保持する。

## 人類と人口の入替

人類一般という読みを採り、具体的な対象を各時点に生存する全人間へ展開する。一国の臣民だけへの暗黙の縮小はしない。これは原文の政治的・規範的な主張内容の構成であり、現実のフリードリヒが世界中の全員を解放したという歴史的事実の実証ではない。この具体化が原文の唯一の読解だとも主張しない。

r5z3は、同じ固定基準で集団の成員とその時点の全生存者の一致を要求する。r5z4では前後の集団を分け、前の全員の状況を評価し、後の全員に政府側の自由を要求する。出生者も後の自由に含めるが、出生前の拘束や解放過程は要求しない。死亡者へ死後の自由は要求しない。

前後とも生存し、前で自由でなかった各人には、前回のr5zsによる同じ活動・同じ前後点・同じ政府側の自由への変化を要求する。少なくとも一人は、前で政府による積極的な指図又は介入を受け、その出来事で解放される必要がある。拘束された人が亡くなり、自由な人が生まれただけでは解放としない。既に自由だった人は後の自由に含めるが、新たに解放されたとは扱わない。

## 同じ比較条件と同じ政府

固定集団についての既存r5zt・r5zzは保存する。原文へ使うr52bは各出来事の人口をその都度決めるr5z5を使い、まだ生まれていない現在の人々の解放を過去の達成者へ要求しない。比較対象ごとの政府・共同体は変わってよいが、全人類、政府側の自由、前の拘束、同じ出来事による変化という達成条件は変えない。

r5z7は既存robの対象・目標を達成関係の内側に閉じる特殊化である。全人間の候補点までの評価、厳密な時間順序、本人も含む先行達成の排除、同時達成の許容を保存する。検査では引数を戻し、元のrobの構文木全体と一致することを確かめる。

r5z6は同じ人・役職・共同体の君主と、その役職が同じ政府の最高職であること、本人が実際にその職を担うことを結ぶ。結合する時点は解放の公的行為点である。個人と政府組織は区別し、両者の規範の出所を自動的に同一化しない。r52cはこの同じ君主・政府・具体的出来事と最初の達成を結び、r52dはその出来事で自由を得た同じ個人への恩恵を接続する。集団を人として扱ったり、世界と後代の実際の感謝を先取りしたりしない。

## 検査の範囲と残る接続

全人口の一致、出生・死亡・既存の自由、死亡だけによる見かけの解放、同じ公的行為、最高職と本人の対応、先行・同時・後続の達成、比較評価の欠落、未知入力を検査する。個人の自由・変化・恩恵は前回の実評価済み構成を境界として使い、引数の同一性を検査する。人口・政府の最高職・量化・比較は実評価し、境界を検査報告へ記載する。有限モデルの検査を原文との同義性の判断へ代用しない。

次は前件の同じ君主・役職・共同体への束縛と、功績・恩恵の記述を世界と後代から値する称揚へ接続する。比較評価の具体的な供給、全適合基準、wenigstens等の提示、独立した名称評価・著者帰属、sondern、一文全体と後続は未完であり、確認済み文字数は増やさない。
