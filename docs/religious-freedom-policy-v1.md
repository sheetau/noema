# 宗教的自由の方針、その義務、本人の判断

第八段落の最初の一文では、宗教上の自由を残す方針が、本人の義務判断、義務判断を述べる自己報告、その自己報告を品位に反しないと考える判断の内側にある。今回構成するのは方針とその義務・本人の義務判断までであり、文全体の意味確認数は増やさない。

旧rm5は両方向の許可を構成できるが、現実の権威的・強制的介入の不在は扱わない。第六段落で構成したr5nvは指図と介入の不在を扱うが、対象は本人が救済に必要と考える営みである。今回は両者の意味を確認し、宗教的自己選択の全範囲を固定して構成し直した。宗教領域h26j7、本人の営みh26hkと内容h246e、自己選択の立場h26hn、要求h237z、許可h245c、介入h26hoを再利用する。

r5vw–r5vyは本人の宗教的選択内容と立場を束縛する。r5vzの非指図は実行要求と不実行要求がともにないことであり、自由を認めるという積極的な許容とは別である。r5v2は両方向の許可を加える。r5v3–r5v4は同じ統治側が関与する生起活動による、同じ本人・立場・内容への介入を除く。別の人の行為、別の宗教事項や市民的職務の規律で判定しない。

r5v5–r5v7は固定集団全員の全宗教的選択へ量化する。各人の候補が非空であり、全候補の規範・介入の評価が済むことを確認する。既に許可された人や現在実行している営みだけを範囲にして、全面的な自由があることにはしない。規範出所は同じ統治側であり、他の全主体の規範の消滅や身体的な実行能力までは主張しない。

r5waはこの方針を正確な四対象列と固定基準へ閉じる。r5wbは同じ本人が同じ立場でこの方針を満たすよう要求される内容であり、方針の現実の成立を実行しない。要求を定める規範の出所と方針を適用する本人は別の引数に保つ。r5wc–r5weは各呼称の指示対象を確認し、この同じ義務内容を本人が受け入れることを構成する。実際には義務がないときも、方針が守られていないときも、その判断自体は成立しうる。

行為内容を段階1、その規範と介入を扱う方針を段階2、方針への義務を段階3として引用する。固定の文の真偽を返す基本関係は作らず、具体的な内容・対象列を合成して渡す。新しい基本関係は宗教的営みの全候補範囲、評価済みという条件、高い段階の要求と誤りうる判断の四つである。

[AA08:040の28–35行](https://korpora.org/kant/aa08/040.html)と[原刊491頁](../artifacts/royal-writing-oversight-v1/page-491.jpg)で、この埋込みと宗教的な範囲を確認した。sondernの訂正的な対置、品位評価、寛容という名称の拒否、称賛と最初の解放の功績は後続の構成へ残す。原刊492頁を含む一文全体の照合・判断もまだ行っていない。

検査では、両方向の要求・許可の16通り、全成員の一候補だけが欠ける反例、介入の活動と主体の不一致、未知入力、名前の取り違えを調べる。義務・本人の判断・方針実現の8通りを別々に評価し、合成した引用を脱引用すると同じ義務内容に戻ることも確認する。これらは接続の検査であり、全文の意味同値を自動認定するものではない。
