# 同じ既存法への率直な批判

第九段落第二文の批判を、同じ既存法の問題点を自分の評価として隠さず公に述べること、と読む。欠点の論点は、法が備えるべき条件の不充足を記述する既存のr326へ結ぶ。法全体とその定式、評価観点を固定し、否定一般を批判にせず、客観的に欠点があることも発表の前提にしない。全命題内容は本人の保持判断と公的提示で共有するNoemaの内容供給へ残す。

率直さは、内心の全開示や恐怖が全くないこととは区別する。同じ発表で扱う自分の評価について、意図的に伏せたり、違う評価に見せたり、迎合して和らげたりする回避がないと読む。礼儀ある表現、留保の正確な提示、単なる要約を排除しない。発表の企てから決まる全関連評価の範囲は、実際に公表した項目列と分ける。列外に隠した評価があれば率直さは成立しないが、全関連項目の逐語的な列挙までは要求しない。この範囲の現実の網羅性は解釈入力の責任であり、有限模型だけで証明したとはしない。

思想列と批判列は同じ本人・一つの活動・学識者の立場・世界としての公衆・立法課題へ束ねる。各批判は異なる評価条件を持て、思想との重複も許す。現在の君主の立法範囲にある同じ全法内容・定式について、固定した履歴上の起点より前の採択を要求する。過去の制定者を現在の君主へ固定せず、発表する将来時点までに採択されればよいという意味にも変えない。

引用では二つの列、条件選択、履歴と起点を保ち、同じ十対象列と基準を受ける複合行為を作る。引用を作るだけでは批判の保持・発表・率直さ・過去の採択を実行しない。思想だけの発表は既存の定義で保持する。複合行為の許可を各単独行為の許可から推論しない。

局所検査では、同じ対象と定式への批判、誤りうる本人の判断と公的提示、列外の評価の意図的隠蔽、無関係な私的見解、別活動へのすり替え、非空の複数項目、先行採択の固定起点、十対象の直接・引用結合、未知入力の拒否を調べる。全法内容と採択の内部構成は固定済みの報告を再利用する。全臣民と全候補への許可、sogar、危険・洞察・実例・全文提示は残っており、第二文の意味判断文字数は増やさない。
