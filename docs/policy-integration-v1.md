# 政策の条件文全体を同じモデルで評価する

前段の接続検査は、親ひな形を引数記録用の関数に置き換えていた。今回は本文から抽出した `iayschema` とその親定義を変更せず、同じ有限モデルで評価する。集団の変化から政策置換へ至る因果条件、自己利益判断、対象者の独立判断、公的理性使用の許可を同時に検査する。

検査用の新政策 `jpnew` は、具体的な `iavtreatment` の内容を持つ。政策が成立するという単独の真偽入力では代用しない。主体・職務・規範の出所・対象者を指定し、公的活動への許可と基準への要求を評価する。対象者は同じ政策記述・共同体・基準時に結び付け、集団の二人の構成員は以前のモデルから保つ。

正常例では条件文全体が真になり、前件が成立する例も存在する。政府の自己利益判断は真で、現実の評価状況での利益条件は偽である。判断内容を現実の真理へ変えないことが、追加した条件との併用後も保たれる。

対照例は、公的許可の欠落、扱い基準への要求の欠落、他者に指導された判断、旧政策の要求の残存、認識の欠落、利益改善の欠落、対象者に結ぶ政策の取り違え、基準の比較状況の欠落、古い世話の描写への帰属、残りの条件の不成立である。それぞれ条件文全体が偽になることを確認する。

世話の描写について確認するのは、新しい描写を同じ著者・箇所が提示するという関係である。引用された世話の内容そのものを現実の事実として要求しない。前件の成立例、対象者の判断、利益判断、政策内容、原則置換の因果条件は別途直接評価する。

この検査は、既存の定義を同時に使える具体例を与える。原文の読みの妥当性、規範の正当性、尊厳の完全な説明、八引数のひな形の未充足部分を解消したとはしない。有限モデル内の成立を、任意の状況における定理や原文との意味一致へ拡張しない。翻訳済み範囲の集計は変更しない。

検査は `python -m pytest -q -s tests/test_policy_integration.py` で実行できる。集約結果は [検証記録](../reports/policy-integration-v1.json) に保存する。記録には、実行したモデルと評価器を含む入力ファイルのハッシュを付ける。
