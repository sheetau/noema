# 第七段落末の二つの時代呼称

固定原文u0014の第四文[675,778)、90非空白文字を、同じ進行という観点に限った現在の時代の分類と、その説明的な呼称として読む。

`In diesem Betracht` は、未到達でも自由な取り組みの機会が開かれ、離脱への障害が減るという先行内容を受ける。r5vsは第一文と同じr5u4を同じ時代h26kiへ結ぶ。既に啓蒙された状態への到達には交換しない。diesesは第一文への指示であり、指示表現と観点限定は別の関係にした。

`oder` は同じ対象への説明的な第二呼称と読む。r5vtは既存rmwへ、同じ候補履歴・時代区間とフリードリヒ二世の王職を渡す。在職点と時代の重なりを構成するが、それだけで時代名を作ったことにはならない。h26m2で、その人物を特徴として時代を呼ぶ提示を結ぶ。h26myの限定の下でこの呼称を用い、全ての進展の単独原因や全在位期間との同一性を加えない。

[原刊491頁](../artifacts/royal-writing-oversight-v1/page-491.jpg)では末尾がFriederichsであり、[AA08:040](https://korpora.org/kant/aa08/040.html)の綴りへ変更しない。[DWBのJahrhundert](https://www.dwds.de/wb/dwb/jahrhundert)にはZeitalter・Menschenalterという広い用法がある。この用例と文脈から、ここでは厳密な百年間という長さを採らない。辞書はこの読みが可能である証拠であり、意図の一意な証明ではない。

人物の参照は[ベルリン国立博物館のフリードリヒ二世追悼メダル記録](https://ikmk.smb.museum/object?id=18202077)で確認した。人物h26mu、名称h26mv、王職h26mwを分け、hzihで同じ名称使用を人物へ結ぶ。在位年1740–1786は編集上の確認に留め、原文の内容には加えない。記録は1786年の資料なので、原文執筆時の著者がこれを参照したとも主張しない。

内容r5vuは進行の性質と時代プロフィールを連言し、r5vvは著者帰属・観点限定・二呼称の説明・人物名の照応・本文順序を結ぶ。局所検査は進行の真偽、別時代、在職の不一致、空区間などの反例、各提示関係の引数の不一致と未知入力、旧判断の依存一致を扱う。段落全体の判断は四文を通読して別記録に残す。これらは独立査読又は意味同値の自動証明ではない。
