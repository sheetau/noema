# 同じ対象への世話と、慈しみの比較

前回の本文点検で未記述だった、自然が同じ芽を最も慈しんで世話する描写へ、目的を持つ行為・肯定的な感情・範囲内の比較を接続した。今回は定義を作例で使うだけでなく、本文の最後の帰属が参照する比喩の描写を更新した。尊厳の候補定義はこの作業では本文へ接続していない。

原文の関係節は、自然を受ける代名詞と同じ芽を結び、世話に最上級を付ける。[アカデミー版041頁33–34行](https://www.korpora.org/Kant/aa08/041.html)で確認した。また、[AdelungのZart項2(c)](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_9_0_142)は、愛情・好意・同情に関わる用法でzärtlichがより明確で普通だとする。この比較資料を踏まえ、単なる物理的な柔らかさや目的達成で代用しない。zärtlich自体の独立見出しの本文は取得できておらず、語義が一意に確定したとはしない。[読解記録](../data/tender-care-reading-v1.json)に参照範囲を残した。

`ryj` は、同じ行為者による生起した行為と、その行為における目的志向を結ぶ。目的は関数の記述と対象一個体の列で指定し、同じ対象の存続・損傷の防止または内在的能力の発展を表すものとして分類する。実際に成功したこと、成功が可能なこと、目的が道徳的に正しいことまでは含めない。対象への保全目的と、行為者の利益だけを目的にした利用を区別するための内容分類は、意味規約として明示した入力である。

`ryk` は同じ対象に向けた肯定的な感情と、その強さの評価を加える。感情の存在は数値とは別に指定する。強度には比較用の非負有理数を使い、零を感情の不在とは定義しない。数値を共通の順序保存変換で置き換えても比較は変わらず、原文へ測定値を補うものではない。

`ryl` は対象を含む非空の比較範囲を完全に列挙し、全対象への目的付き行為と強度の評価を要求する。その範囲で指定対象より強い感情を向ける別対象があれば、指定対象は最大とはならない。同率は認める。一対象だけの範囲も許すが、比較対象の存在を原文以上に作り足すことはしない。未評価の対象を落として最大と判定することはできない。

これは「最も」を範囲内最大として読む候補である。原文は比較対象や尺度を列挙しておらず、強調を表す絶対最上級として読む可能性も残る。世話も一つの評価文脈での目的付き行為として構成しており、継続的な役割・習慣、感情や保全目的の基礎説明まで完成したとはしない。

`iawdepiction` は、既存の覆いの下での展開と、新しい世話の内容を同じ対象・文脈で結ぶ。双方の行為者は自然 `qb` だが、展開行為と世話行為が同じ出来事であることは要求しない。自然の感情と目的は描写の内部に留め、著者への帰属だけを評価するときはその内容を実行しない。

本文では、最後の `iatattribution` に至る依存経路だけを新しい名前で複製し、引用された描写参照を `iawdepiction` へ変更した。新しい本文主張は `iawiatattribution` を使う。旧定義と先行21主張は保存する。これは内容を加えた改訂読解で、旧引用と同じ意味・同じ記述だとする変換ではない。

[本文点検v2](../reports/kant-manuscript-obligations-v2.json)では、世話の三つの候補に本文からの参照経路があることを確認する。ただし元の14項目は全て意味確認を継続中とし、最後の帰属も八つの引数を持つ部分ひな形のままである。原文の対応文字数と意味確認済み区間数は増やしていない。

成果物は[一般定義](../examples/v016/tender-care.noema)、[抽出本文](../examples/v016/tender-care-core.noema)、[改訂本文](../examples/v016/kant-tender-care.noema)、[意味規約](../data/tender-care-basis-v1.json)、[検証記録](../reports/tender-care-v1.json)。再検証は `python -X utf8 -m pytest tests/test_tender_care.py -q` と `python -X utf8 -m scripts.check_tender_care --verify-only` で行う。
