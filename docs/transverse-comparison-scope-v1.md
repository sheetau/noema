# 同じ横棒の比較範囲と正負速度の測定

u0101–u0104の対称性を、正負速度の二例だけへ縮めず記述するため、同じ棒の固有形状と方向一般の比較範囲を構成する。ここでは著者の主張を追加せず、全文判断数を増やさない。

ejc6は二設定で同じ全物質点を保ち、固有系の同じ全成員対の距離二乗を一致させる。比較に使う時刻は各設定自身の開始時刻であり、各設定で静止・剛性が別に要求される。棒の位置や向き、時計の原点は変えられる。固有長だけが同じでも内部点の配置や物質点の集合が違えば、同じ棒の比較として受け入れない。

ejdaは同じ棒・二端・固有長・尺度を保つ一つの設定とその正の測定長を、先行ejc5の固有静止配置・全点並進・横運動・現在測定へ結ぶ。速度三成分は全系のeiojと同じeislcを使う。候補は0<|v⃗|<Vであり、長さの基準値との一致やφの対称性を候補条件には含めない。測定長が異なる適格設定も比較対象になる。

ejdbは速度の三成分を明示した値へ結ぶ。ejdcは、非零で光速未満の各実三成分に適格設定と測定長が存在することを要求する。これは対称性を考察するための理想化した設定群であり、現実の有限な実験記録、全設定への加速過程の実現、光速以上への外挿ではない。異なる方向と向きを、正X方向と負X方向だけで代用しない。

ejddは二設定の速度の二乗和が等しいことを述べる。同じ大きさなら長さも等しいという結論はここへ入れない。ejdeが、現在設定の適格性とejdcの全範囲を保持した上で、全設定・全測定長の同速条件から長さの一致を要求する。これは後続で著者に帰属する不変性の内容であり、設定の存在から不変性が証明できたという認定ではない。

ejdfは前段の端点式を指定した符号付き速度へ一般化する。同じ端の全K時刻に現在二系記録が存在し、全対応記録に同じφをその速度で適用する。ejdgは速度を(speed,0,0)へ指定し、同じη軸区間・両端の現在式と、測定長=l/φ(speed)を結ぶ。ejdhは現在設定と異なる逆向き設定を同じ規則へvと−vで渡す。K/kを交換したり、負引数へ正引数の関数値を流用したりしない。

ejdiはM0186の二つの商の等値を直接記述する。一般の距離は正であり、符号付き商をその長さへ等置する向きの読みはejdgに明示している。純粋な分数等値だけなら負のφでも成立し得るし、等値だけでφ=1とはならない。後続のoder、同じφの正負値の一致、相反積と合わせる議論を混ぜない。

局所検査では、全成員と固有点対距離の本体、同じ速度の引数接続、異なる長さも候補に残ること、全方向の存在条件と同速の長さ不変性、正負引数と現在記録の全範囲、二分数の等値を分ける。物理的履歴と測定は先行証拠を保持する。全実数速度・長さの量化は有限評価を拒否し、例化した本体や有限関数の指紋を全域の証明に替えない。原刊と本文の通読判断は次の著者への接続で行う。
