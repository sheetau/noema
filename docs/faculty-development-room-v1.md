# 同じ制度での全能力への発展の余地

対象はカント第十段落第三文の後半「ein Grad weniger von jener verschaft hingegen diesem Raum, sich nach allem seinen Vermögen auszubreiten」です。この依存群では、民衆の精神を同じ共同体の各人が自分の悟性を用いて判断する働きへ分配し、その関連能力を全て対象にする読みを採用します。第三文全体の意味判断はまだ行いません。

「余地」は、能力ごとに固定した潜在的な課題範囲の全体を行使できる状態へ至る方法があることとします。現在行使できる課題の集合と、能力が展開し得る課題の全範囲を分けます。終点では後者の全課題へ到達できるという強い条件です。質・熟練・強度の全側面を別に数値化したとは主張しません。

旧faculty-opportunitiesは全員の各能力へ厳密な増加を要求していました。今回は、既に全課題を行使できる能力には維持を認めます。一方、全体には評価済みでまだ行使できない課題が少なくとも一つあることを要求し、展開の余地を空虚にしません。人と能力ごとに別の方法・結果時点でよく、全能力を同時に展開する共同計画や、実際に発展した事実は主張しません。
