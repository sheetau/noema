# 接続候補の重複する幾何検査を減らす

40項目の生成を始めると、第3項目が187秒、第4項目が227秒かかった。実行中の標本では、接続候補の幾何検査、とくに既存の線同士の距離計算が多くを占めた。旧生成器・旧判定器は保持し、候補の採否と描画結果を変えずに重複だけを減らす。

同じ接続元・接続先の探索中は、円と既存の線は変化せず、候補の接続線だけが追加される。旧 spacing_check の条件を次の三つに分ける。

- 全円と既存線の組は、探索中に一度だけ検査する。
- 全円と追加線の組は候補ごとに検査する。円の相手に関する例外があるため、近い円だけへ絞らない。
- 既存線と追加線の各組も候補ごとに検査する。

円同士、円と線、線同士の全組を旧判定器で覆っており、判定条件を変更しない。追加する線によって、既存の組の距離や、相手となる円の有無は変わらない。既存部分が不適合なら、その接続先の探索を打ち切れる。永続的な結果キャッシュや意味判断の流用ではなく、一回の探索内で変わらない条件を分離する。

さらに、分岐の接続候補が採用される直前に行われた幾何検査を、採用直後に同じ引数でもう一度呼んでいた箇所を除く。先読みを使わない経路と、分岐元以外の経路の必要な検査は残す。最終の全図形検査と実図形復号も維持する。

旧コードの保存写しと新コードで小さい三つの配置を比較し、SVG自体の一致と元構文への復元を確認する。距離条件の分解は、円の相手を必要とする例外、近すぎる線、正常な線の追加で旧判定と対照する。全40項目の配置完成とは区別する。
