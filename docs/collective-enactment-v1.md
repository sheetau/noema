# 共同決定による規範変更

共同統治の決定規則と、既存の規範変更の権能を接続した。同じ組織・役職・行使・対象規範を固定し、可決、制度上の変更可能性、現実の行使と結果を別に記述する。役職が共同で保持されることだけから、その組織に規範を変更する権能があるとは推論しない。

## 決定規則を同じ行使へ結ぶ

[共通定義](../examples/v016/collective-enactment.noema)は、前段の共同保持 `rwp` と、[規範変更の権能](normative-powers-v1.md)の `riw` を再利用する。四定義を追加し、新しい原始記号や文法演算子は追加していない。

| 定義 | 内容 |
| --- | --- |
| `rwq` | 同じ最高役職を複数人が共同保持し、指定された各人の二値入力が決定規則を満たす。規則の肯定出力が、同じ制度・組織・役職・行使記述・引数・時点についての決定に当たることも要求する。 |
| `rwr` | `rwq` に加え、同じ組織がその役職で行う行使を制度が認定し、同じ前後状況で指定した規範が成立または廃止される。 |
| `rws` | 同じ入力と対象について `rwr` を満たす結果状況がある。 |
| `rwt` | `rwr` に加え、全保持者の指定入力の記録、同じ組織による行使の記録、同じ前後状況への現実の移行がある。 |

組織を人間として扱わず、役職保持者である人と、制度上の行使主体である組織を分ける。行使の引数列の先頭は同じ組織でなければならない。別の人物や別の役職が持つ権能を、その組織の共同決定へ流用できない。

決定規則の対象範囲は `mandates` という関係引数に明示する。これは、その規則の肯定出力を指定行使についての決定として扱うという制度上の対応である。三人が同じ規則で食事の献立を決めることから、法規範の変更が決まったとは扱わない。関係自体の社会的な成立や正当性は、未説明の入力として残る。

## 可決と実際の変更

三人の多数決で二人が賛成する入力を考える。規則が対象とする行使と一致していれば `rwq` は成立する。それでも、制度がその行使による規範変更を認めなければ `rwr` と `rws` は成立しない。

`rws` は制度上の候補を調べるため、投票や行使が実際に行われていなくても成立できる。各人が物理的に投票できることや、独立して判断したことを証明する条件でもない。実際の行使を述べる `rwt` では、保持者全員が同じ行使について指定入力を行った記録を別に要求する。反対する保持者についても、偽の入力の記録が必要である。

行使を実行した記録があっても、別の結果状況へ移行しただけでは `rwt` は成立しない。逆に、指定した結果状況では失敗しても、別の整合した制度上の結果候補があれば `rws` は成立できる。特定の試行の失敗と権能の不存在を分ける。

## 変更対象を保持する

規範の出所、名宛人、立場、対象記述、引数列、内容の肯否を前後で固定する。成立・廃止の方向と、対象内容の肯定・否定は独立である。肯定内容への要求を廃止しても、否定内容への要求が成立したとは述べない。

政策と行使の記述は脱引用して実行しない。要求を成立させることと、その要求の内容を実現することを分ける。同じ真偽を返す別名の記述も、元の対象の規範記録を自動的には継承しない。行使への許可や道徳的正当性は、この定義では判定していない。

## 検査と次の課題

105テストが通過した。決定の適用範囲・可決・選択の統制・制度上の認定・規範の変化の32組合せと、実際の入力・行使・結果の8組合せを含む。人物、役職、制度、記述、引数、時点の取り違え、未知の入力、成立と廃止、肯否、同じ真理値の別名を検査した。元の定義の再利用と、評価キャッシュなしでの一致も確認した。

二文書の長形式・短縮形式・固有文字での往復、CLI解析、作例のSVGのXML検査が通過した。字形の目視検査は行っていない。

```powershell
python -X utf8 -m scripts.compose_collective_enactment
python -X utf8 -m pytest tests/test_collective_enactment.py -q
python -X utf8 -m scripts.check_collective_enactment --verify-only
python -X utf8 -m noema.constructed parse -i examples/v016/collective-enactment-example.noema
python -X utf8 -m noema.constructed render -i examples/v016/collective-enactment-example.noema --notation compact -o collective-enactment.svg
```

この構成は会社や団体にも適用できる。国家の統治範囲、住民・領域との関係、公的な権限の成立、対外的地位はまだ説明する必要がある。カント本文に特定の立法行使が存在するという主張を追加せず、その条件を記述するための一般構成として保存した。
