# 同じ政府・同じ原則についての自己利益判断

政府が人間をその尊厳に即して扱うことを、自らにとって有益だと判断する部分を、前段の条件文へ接続した。判断主体・行為主体・受益対象を同じ主体へ束縛し、対象には同じ新原則の内容を渡す。原則への要求があることと、その内容を実現することの利益について判断することは区別する。

原文の関係節は[アカデミー版41頁37行](https://www.korpora.org/Kant/aa08/041.html)にあり、判断対象の扱いを述べる不定詞句は[42頁1–2行](https://www.korpora.org/Kant/aa08/042.html)へ続く。今回は肯定判断を非事実的に構成する。この選択により、著者が利益自体の真理を外側で断言したことにはしない。[読みの記録](../data/self-benefit-reading-v1.json)に、原文で確認した点と今回の解釈選択を分けて保存した。

| 定義 | 内容 |
| --- | --- |
| `rx6` | 同じ内容を実現する側・しない側の非空の結果候補と、固定した全目標の評価を確認する |
| `rx7` | 実現しない側で保証される全目標を実現する側でも保ち、保証される目標がさらにある |
| `rya` | 同じ主体・受益対象・政策記述・評価手続について認識があり、非空の判断候補全てでその手続が成立する |
| `iatbenefit` | 受益対象と判断時点で選んだ目標範囲を、全判断候補で固定する |
| `iatappraisal` | 政府に対応させる同じ主体について、自己利益の判断を構成する |
| `iatschema` | 同じ新原則への判断を政治的終点に加え、残余条件の関係者と時点を保持する |

有益さは、指定した目標についての保証集合の真包含という候補を用いる。例えば、政策を実現しない側では目標Aだけが保証され、実現する側ではAとBが保証されるなら条件を満たす。一方、Aを失ってBを得る交換は、その重要性を比較する別の規約がなければ有益とは判定しない。結果が複数ある場合、一つの好都合な結果でBが達成されるだけでは保証に数えない。

この構成は、期待効用や福利、有益さ一般の唯一の定義ではない。原文が具体的な目標一覧を指定したとも扱わない。目標・比較範囲を明示して評価するための候補であり、損益交換や確率的な利益には別の説明が必要である。

結果候補が空の場合や、目標一覧が不完全・重複を含む場合は利益条件を認めない。同じ政策内容を評価し、実現側では成立、不実現側では不成立であることも確かめる。各候補では同じ受益対象の全目標を評価する。別人の利益や、判断候補ごとに選び直した目標で自己利益を代用しない。

判断の対象には、政策と評価手続それぞれの記述を保持する。基準の現実の真理を判断条件へ追加しないため、誤った肯定判断も記述できる。検査例では判断候補で利益条件が成立する一方、現実の評価文脈の結果候補では成立しない。前段の因果条件文全体も、その誤認を許すまま成立する。ここでの「現実の評価」は実際の判断文脈での見込みの評価であり、政策の実行や利益の発生を記録したことではない。

判断の明示的認識がない場合や、判断候補が空の場合は肯定判断としない。未知の候補、目標の達成、評価状態を偽として補わない。受益対象や政策記述を替えた認識も、元の判断へ流用しない。組織が判断主体になる仕組みや、矛盾した信念の一般的な扱いは未完である。

45テストが通過した。検査では、二目標の保証集合16通り、評価不足・空の結果候補・内容の実現との不一致、利益と判断の真偽の違い、主体と記述の保持、条件文全体への接続を確認した。診断には明示的な短絡評価と純粋で外延的な解釈向けの関数再利用を用いる。三文書の長形式・短縮形式・独自文字の往復、CLI解析、抽出文書のSVGのXML構造も確認した。字形の目視確認は今回行っていない。表記の往復や有限例の成功は、原文との意味一致の証明ではない。
