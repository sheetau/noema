# 本来的使命と人間本性への重大な違反

カントu0013第五文 `[1005,1264)` の、人間本性・本来的使命・啓蒙の進展・仮定的な犯罪評価を構成します。本文100主張は変更せず、文全体の意味確認はまだ加算しません。

## 読みと構成

`deren` は同じ人間本性を受けます。`r5dx` は、人としての本性、その本性に固有の展開の課題、その関係の本来的な由来、使命を成す進展の内容を結びます。課題の内容を実行せず、現に全員が進展していることや、出生時の完成、後に任命された職務を述べません。

`in diesem Fortschreiten besteht` は、直前の啓蒙全般の進展に使命が存するという読みです。`r5dw` は既存`r5cr`を同じ集団・固定基準・候補経過・前後点へ適用します。前文の`r5dn`と同じ進展であり、認識量の増加から自立した判断の進展を導く規則にはしません。内容の同定は記述として保持し、一時点の真偽が一致するだけの別内容では代用できません。

`Verbrechen wider die menschliche Natur` は、同じ本性を規範的根拠に置き、その規範から同じ企てを禁止し、本性への重大な侵害として評価する構成`r5dy/r5dz`です。単なる許可欠如から犯罪を演繹せず、禁止と重大な評価をそれぞれ保持します。行為の実行、目的達成、刑法上の罪名や裁判は要件にしません。

`Das wäre` は同じ六対象の目的付き相互宣誓形成`r5db`を受けます。`r5d2`が形成された場合の重大な違反評価、`r5d3`が同じ`r5dc`の全候補への条件文を構成します。形成の実例を存在主張せず、成功した企てだけへ条件を強めません。`r5d4`は使命の相対節を補足として保持し、該当する合意がない場合でも補足内容は消えません。

原文の照応は[AA VIII 39、9–13行](https://korpora.org/kant/aa08/039.html)と保存した原刊488頁に基づく採用解釈です。本性論の一般的証明や、一意の哲学的解釈を与えるものではありません。

## 検証と残件

本性・使命・由来・内容の取り違え、禁止の有無と極性、保護対象・行為内容・六対象の取り違え、条件文の四組合せ、全候補の量化を検査します。接続検査は形成内容だけを境界とし、使命・禁止・重大な評価・条件文を実評価します。引用された進展と目的達成は未知のままにします。既存の進展・形成・拒否資格の証拠はハッシュを固定して参照します。
