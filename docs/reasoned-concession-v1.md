# 理由付けと、期待に反する結果の提示

カント第二段落の末尾を、現在の本文へ接続した。「危険はそれほど大きくない」という主張、その理由としての学習の見込み、「それでも一例が萎縮と通常の回避につながる」という主張を結ぶ。既存の部分解釈を用いた追加であり、第二段落全体の意味確認はまだ終えていない。

## 主張・理由・期待背景を分ける

本文の構成は次の通りである。

| 役割 | 既存の内容・関係 | 今回の接続 |
| --- | --- | --- |
| 危険の程度P | `e4` | 危険がないとはせず、非常に大きいという基準を満たさない。 |
| 学習の見込み | `fs`、理由付け`ft` | 著者がPの根拠として提示する。学習が実際に起きたことや、根拠の十分性は断言しない。 |
| 萎縮・通常の回避Q | `gx`、帰属`gy` | 既存の有限事例による部分解釈を、後続の主張として保持する。 |
| 期待背景 | `hztv` | PかつQが、Pかつ非Qより見込まれにくいという比較を表す。 |
| 背景と主張の帰属 | `hztw`、`hztx` | 同じ著者・箇所・文脈へ結び、主張と背景の範囲を区別する。 |

期待は二つの内容記述の質的な比較であり、確率の数値や論理的含意ではない。Pだけから「Qは起きない」と推論する規則も追加しない。両側に同じPを残すので、PかつQとその全体の否定を比較する場合とは区別できる。

非Qの意味にも限界がある。複合的なQが成立しないことは、全員が全く恐れず、どの試みも避けないという強い反対を意味しない。また、`gx`に含まれる事例範囲と通常性の操作化は以前のままである。ここを一般的な通常性の完成した理論とは扱わない。

この読みは、原文の`zwar`、理由を示す`denn`、後続の`allein`と`doch`を一文の構造として接続するもの。[原文35頁](https://korpora.org/Kant/aa08/035.html)と[36頁](https://korpora.org/Kant/aa08/036.html)を参照した。IDSの説明では、譲歩を通常の見込みに対する例外として区別し、対立・譲歩などの接続関係を分類している。ただし、今回の原文の比較範囲や、二候補の質的比較という操作化までを資料が指定しているわけではない。[IDS・譲歩](https://grammis.ids-mannheim.de/systematische-grammatik/2109)、[接続関係の分類](https://grammis.ids-mannheim.de/systematische-grammatik/366)。

## 再利用できる構成

一般定義`rqvq`と`rqvr`は、閉じたP・Qの記述から、それぞれPかつQ、Pかつ非Qを合成する。原語の文字列や未定義の「翻訳済み内容」を引数にしない。`rqvs`は既存の期待比較`rqts`を用いて、同順位・比較不能・逆向きの比較を厳密な見込み差から分ける。比較する二記述の範囲で反射性と推移性も検査する。

`rqvt`は、異なる二つの本文箇所の正順と逆順の不在を確認する。本文への接続では、先行する危険提示、危険の程度、学習の理由、萎縮という隣り合う三組を確認する。世界の出来事の時間順と混同しない。

主張と背景は既存の`rst`による組、`rqtv`による帰属を再利用した。七定義と一つの原文範囲への参照を追加し、新しい意味の基本関係や文法演算子は増やしていない。一般文書にはカント固有の原始記号を含めない。本文の既存37文を保ち、末尾に一つの候補帰属を追加する。九つの既存の意味判断では、選択した文・依存する定義・意味規約が変わらない。

## 検査と未解決事項

検査は現行の評価器を用い、定義・式の結果キャッシュを無効にして行う。

- 内容の真偽と比較関係の64組合せで、PとQの真偽から期待を補わないこと、Pの否定とQの否定を混同しないことを確認する。
- 順序の8組合せと未知入力を検査し、同じ箇所同士や両方向の順序を拒否する。
- 帰属の64組合せ、13対照、五つの未知入力で、著者・文脈・範囲・理由の向き・背景と主張の交換を検査する。帰属の一つが偽でも、別の未知の背景帰属を確定しない。
- 原文に使う背景そのものを六条件で評価し、比較の両側に同じ`e4`と`gx`が渡ることを確認する。世界の事実は未知のままにする。
- 三文書の長形式・短縮形式・固有文字の往復と、既存九単位の意味判断との結合を確認する。

これらは構成と有限解釈の検査であり、原文との同義性を自動証明するものではない。内容を引用した帰属が通ることと、`e4`・`fs`・`gx`の意味が十分であることも別である。今回はその三内容の現実の真理や内部の因果機構を新たに検証していない。身体的な歩行・転倒の比喩、学習の様相、萎縮の原因と原因説明の区別、通常性と範囲の妥当性は引き続き未完である。

原文対応は既存の三範囲と同じで、文字数や全体確認数を増やさない。確認済みは九単位・587非空白文字のままである。
