# 共動系での新しい力の言い表し

u0175、原刊910頁の第二項を全体として扱う。点状の単位電気量が同じ電磁場で動く条件、その対象に働く力、同じ対象の場所の電気側の場、対象に相対静止する座標系への場の変換、新しい言い方という位置付けを接続する。

運動前提は第一項と同じ`ejyb`を共有する。任意方向の三速度uに対し、その大きさsをs²=u·u、s≥0で指定し、β=soy(V,s)を用いる。κ=β²/((β+1)V²)として、四座標をx′=x+κ(u·x)u−βut、t′=β(t−u·x/V²)へ写す。場の同じ旧地点での混合はE′=β(E+u×H/V)−κu(u·E)、H′=β(H−u×E/V)−κu(u·H)である。新座標での場は、両場とも同じ反対速度の四座標写像で旧地点へ戻してから混合する。領域にも同じ逆像を用いる。

この形は標準配置の縦・横成分を三ベクトルへ展開したもので、速度をx方向へ制限しない。軸を同じ向きで対応させ、共通の原点出来事と時刻原点を選ぶ純粋boostの代表を使う。原文の不定の「座標系」を、そのような共動系を選べるという存在として読む。任意の回転や原点ずれを持つ全座標表示で数値が同じだという主張は加えない。

物理的な相対運動は既存`ejm2/eioj`の全固定配置・全比較時点へ結ぶ。新しい一般関係`eisqt`は、原点・軸・尺度・局所時計の規約を持つ二つの物理的な座標記述と、同一出来事の全域写像を対応させる。この関係には特定の変換公式・相対速度・場・力・対象の静止は含めず、それぞれを別に合成する。測定済みの一点の一致だけでは、未占有の場所も含む座標記述の対応を保証できないため、物理的な座標規約への帰属を明示する。

同じ対象の当該出来事は、変換した位置時刻で`ejwr`の瞬間静止を満たす。前段の「少なくとも当該瞬間に」を共有する読みであり、対象の加速度0やその前後の静止は要求しない。系自体はその瞬間速度に合わせて等速並進する代表で、対象へ加速追従する系ではない。

同じ電磁過程`eispp`を、Kの二場と新系の変換後の二場へ`eispn`で結ぶ。新地点の電気側の場を、同じ対象・出来事・新系・量単位zouの値1、力単位Dyn、場単位と換算1、物理的な静止試験応答を保持した`ejwt`へ渡す。第一項のKの力zplや標準配置の固定kの力zpmを代入しない。力の各成分はその力を測る新系の場と比較する。

検査は任意方向・符号・零速度の数値上の退化例、逆四座標変換、時空間隔、標準x配置の既存写像との一致、電気・磁気側の混合と符号、場の逆座標評価、領域の逆像を調べる。相対運動、物理的座標対応、同じ過程、瞬間静止、静止試験力の各境界では全引数の結合を対照する。新旧の計算結果を物理的帰属の代用にしない。全実数・全関数域の有限処理による拒否を保ち、証人結合は二値の診断と本体の実際の型の検査を分ける。

文168だけを更新し、既判断の第一項を含む他359主張と旧証拠を保存する。第二項全体の意味判断は別記録で行う。u0176の磁動力と補助概念、u0177の非対称性解消と二作品全体の目標は後続である。
