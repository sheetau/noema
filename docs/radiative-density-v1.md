# 光のエネルギー密度と動く境界

原刊913頁のu0203–u0205は、エネルギー密度、二系での体積、光速で動く球面、同じ光の集合及び新系の総エネルギーの問いを接続する。今回はその依存群として、同じ波の瞬間密度・周期平均密度・境界に相対的な流を構成する。著者帰属と全文の意味判断は残る。

エネルギー密度は、同じ系の空間における単位体積当たりの電磁エネルギーである。物理的な対応は、既存の流と同じ仕事・交換収支及び校正された単位へ結ぶ。密度と流、物質への仕事を分ける解釈の参照として[Feynman Lectures II, 27](https://www.feynmanlectures.caltech.edu/II_27.html)を確認した。同資料のSI表現の係数を原文へ直接代入せず、ここでは原文の電気・磁気係数が同じ次元となる規約を使う。

共通波形の六係数をE₀,H₀、光速度をV、流の換算係数をκとすると、瞬間密度はκ(|E₀|²+|H₀|²)sin²Φ/(2V)である。原文の単位係数4πκ=Vと横波H₀=n×E₀を明示すると、瞬間密度はA²sin²Φ/(4π)となる。正弦の一周期の二乗積分を周期長で割って1/2とし、平均密度A²/(8π)へ結ぶ。任意波形の平均を1/2に固定しない。

u0203第一文の新系の「Lichtenergie」も、直前の「pro Volumeneinheit」と後続の体積との積から平均密度と読む。両系で同じ波・物理的な単位対応を使い、それぞれの位相率・位相原点・周期で積分する。第7節末尾の正面接近と非零強度の条件は、この一般の密度設定へ追加しない。

境界の速度wに対する流はJ−u wである。横波のJ=V n uと、同じ速度w=V nを結ぶと、このベクトルは各点で零になる。球面の法線は波の法線nと異なるが、零ベクトルの法線方向成分はどの面でも零である。球面の運動と同じ光の集合への帰属、全時刻の領域、保存の帰結は、この局所計算に続けて記述する必要がある。

検査では一般波形の区間平均、二系の全役割の結合、横波の方向と外積順序、移動境界との差を対照する。有理数で置いたpiは式の係数と引数の診断にだけ用い、正本のpiは既存の積分定義を保持する。密度モデルの採用や保存則の真理を、局所検査の通過から認定しない。
