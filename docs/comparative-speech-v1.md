# 比較判断の公的提示と二つの許可

カントu0016の「よりよい法文の作成について自分の考えを世界へ公に示す」という部分を、比較判断の提示として記述した。[改訂した本文](../examples/v016/kant-comparative-speech.noema)では、本人の判断、示す内容、その行為への許可、方針の安全性を分ける。本人が肯定して発言していても、現在の評価では改善になっていない場合を許す。

既存の1,415宣言と先行16文を保持し、最後の帰属文を改訂した。12定義と9原始宣言を追加し、本文は1,436宣言・17文となった。文法や評価器は変更せず、既存の型付き記述合成を使っている。

## 同じ比較を判断と発話へ結ぶ

比較基準は「話題・比較元の表現・改訂候補」の順に三個体を受け取り、評価状況ごとに候補の方がよいかを返す関数である。原文から特定の数値尺度、正義観、優先順位を補わない。この基準そのものの妥当性は、本人の判断が成立することとは別に残る。

比較元と候補は異なる表現対象として、同じ話題へ結び付ける。意味内容が違うこと、現に採択済みであること、実際に法が変更されることは要求しない。表現と話題を結ぶ関係の基礎説明、法文の具体的な構成、比較元の参照先を原文全体から確定する作業は未完である。

| 定義 | 内容 |
| --- | --- |
| `rru` | 同じ比較基準・比較元・候補から、その話題について肯定する発話の記述を構成する。 |
| `rrv` | 本人の判断を同じ基準・話題・比較順序へ結び、非空の判断候補で比較が成立し、同じ行為で公的に提示することを要求する。 |
| `rrw` | 比較基準の関数と記述、二表現、判断の関係、`rru` の発話を一組の入力から構成する。 |
| `rrx`、`rry` | 同じ人・活動・話題範囲・役割について、構成した行為記述への許可を方針にする。 |
| `rrz` | 二つの方針が同じ状況で共に成立する内容の記述を構成する。 |

本人の判断には、同じ人・話題・基準の記述・比較順序を要求する。別人の判断、別の話題、逆向きの比較、同じ結果になる別名の基準を流用しない。発話の内容も同じ入力から作るため、ある比較を判断しているだけで別の比較を示したことにはならない。

今回の提示は、同じ比較内容の肯定発話という部分的な読みである。問い、留保、複数論点など、考えを示すすべての方法をこの形に限定するものではない。また、受け手の同意や採択を求める発話を追加していない。

## 一般的な公的使用の許可を保持する

比較発言への許可を加えても、先行する一般的な公的使用の許可は保持する。両者には別々の活動範囲を渡す。一般の公的使用をすべて比較発言へ限定したり、比較発言への許可だけで前の許可を置き換えたりしない。

安全性は、二つの方針を結合した同じ記述について評価する。一方の許可がある将来と、他方の許可がある別の将来がそれぞれ存在するだけでは足りない。同じ想定結果で両方が成立することを要求してから、その結果の不利益を調べる。本人の認識も、この変更後の安全性の記述へ結び直した。

許可の評価や発話記述の構成は、対象となる発言や比較判断を実行しない。判断や比較の解釈が未知でも、閉じた記述を構成して許可を調べる操作とは区別できる。未知の判断を実行評価する場合は、偽で補わず拒否する。

## 原文対応と残る課題

新しい範囲は `[651, 706]` の `und ihre Gedanken über eine bessere Abfassung derselben` と、`[765, 795]` の `der Welt öffentlich vorzulegen` である。非空白75文字を追加する。間にある率直な批判と強調は含めず、先行する認識・立法の対象範囲・安全性は重複加算しない。

比較基準、表現と法の関係、判断の成立過程は解釈入力として残る。空の活動範囲の空虚な真、対象の網羅性、公衆・理性・洞察などの既存課題も継承する。率直な批判、強調、統治者への照応と後続の実例、全段落の意味一致は未確認であり、意味確認済み区間数は増やさない。

## 再現手順

55テストが通過した。発言の実行・本人の判断・候補での比較・現在の比較の16組合せと、二つの活動範囲・二つの許可の16組合せを検査した。別人・別の話題・逆向きの比較・同じ定義を持つ別名の基準・異なる提示内容を区別し、二つの許可が別々の結果でしか成立しない例も確認した。未知の判断や比較は実行時に拒否し、記述の構成と許可の評価では実行しないことを確認した。

構成した行為と発話内容は、キャッシュあり・なしで同じ結果になった。長形式・短縮形式・固有文字の往復、検査記録の再現、本文と抽出文書のCLI解析、抽出文書のSVGのXML検査も通過した。SVGの目視検査は行っていない。
