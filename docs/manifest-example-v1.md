# 自由の実例と、政府に明瞭に示される根拠

第四文の例を、先行する自由と同じ共同体の平穏・一致が共存する実例として読む。r6abは例の現実性、同じ政府設定の自由r56h、同じ共同体の平穏r572と一致r575を、同じ事例点へ結ぶ。単なる政府の言明や、別の国の自由と平穏を取り合わせたものでは足りない。

例が明らかに示されるというr6acは、組織からの参照可能性、内容を支える実質的な根拠、その根拠の明瞭さを分けて結ぶ。情報が世界のどこかにあるだけでも、印象的だが根拠にならない例でも満たさない。一方、その政府が実際に納得したことや、全構成員が認識したことは要求しない。政府を人の知覚主体として扱う既存の認識関係へ代入しない。

r6ad/r6aeは、対象政府の同じ自由条件下で、平穏か一致への根拠ある危害懸念が一つもないという内容を、段階2の閉じた支持対象にする。r6afで実例側と対象側を接続し、全引数の呼称を検査する。実例側には自由の実現を要求するが、対象政府に自由の実現や改心を要求しない。別政府への適用は、その相違を踏まえた支持根拠の関係として明記し、一例からの演繹的証明とはしない。

局所検査は、同じ例・自由設定・共同体・事例点、三つの根拠関係の独立性、閉じた支持対象の全六引数、呼称の誤対応、未知入力、引用内容の非実行を扱う。自由・平穏・一致と危害懸念の内部は既存の検査に依存し、今回の接続検査の境界を報告する。
