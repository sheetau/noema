# 納付の要求と公的な批判

カントのu0012には、課された納付を拒めない市民でも、学識者としてその賦課の不適切さや不公正さについて公に意見を述べる、という対比がある。このうち、納付の内容、指定された役割への要求、別の公的活動での批判を部分記述した。既存の15件の著者主張は保持し、新しい条件式を著者の追加主張としては登録していない。

従来の支払いの定義`rf`は、仕事の対価として価値媒体を移転する条件を持つ。そのままでは対価を必須としない納付に使えないため、移転と媒体の受容だけを要求する`rfa`を追加した。この共通部分は納付以外の贈与や返済にも使える。要求があるか、対価なのか、どの制度によるものかは、別の条件で指定する。

| 記号 | 内容 |
| --- | --- |
| `rfa` | 本人とは別の受け手への、受容された価値媒体の移転。 |
| `rfb` / `hzah` | 受け手と媒体を固定し、本人・行為から移転の成立内容を返す。`hzah`は既存の移転・受容の基本関係へ接続する。 |
| `rfc` / `rfd` | 適切さと公正さの別々の基準列について、一方以上の基準に不足があるという内容／その内容を述べる発話。 |
| `hzai` | 同じ出所・本人・役割・行為・対象記述について、納付内容の成立を要求する。 |
| `hzaj` | その要求があり、同じ対象記述の内容が指定文脈で不成立である。 |
| `hzak` | 同じ本人に納付要求があり、その人が別の公的活動を実際に行う。 |
| `hzal` | 同じ本人への納付要求と、別の公的活動への積極的な実行許可が併存する。 |

規範の対象は「支払い」という記号だけで指定しない。受け手と媒体を固定した`hzah`の適用を閉じた記述として渡し、その記述を本人と行為に適用する。これにより、別の受け手や別の行為への移転を組み合わせて、納付済みと判定することを防ぐ。要求を記述するだけなら、現在の移転の真偽を知る必要もない。

同様に、批判は「不適切」「不公正」という固定の語彙番号で表さず、対象が満たすべき条件を関数の列で渡す。適切さと公正さの列は分け、一方に不足があるという内容を作る。これは明示した基準に依存する読みであり、基準自体の正当性を保証しない。両方の列が空なら不足の内容は偽になるが、その偽の内容を主張する発話も記述できる。発話や許可から、批判が正しいという結論を補わない。

検査では、要求・許可・禁止・納付・発言の32通りを分け、本人、対象行為、役割、出所、記述、文脈、移転先などの17対照例を確認した。要求と公的活動への許可は、実際の納付・発言・批判内容の真偽が未知でも記述できる。一方、納付済みか不足があるかを評価するときは、必要な情報が未知なら停止する。

さらに、移転・媒体の受容・対価の8通りで、対価なしの移転を新定義が扱えることを確認した。適切さと公正さの条件列36通りでは、空列と重複、内容の真偽、主張と質問の違いを検査した。全文草案と独立抽出文書の評価結果は一致した。市民への納付要求に、官吏として職務を委ねられているという条件は追加していない。

今回の定義は、指定した納付と公的活動の対応を扱う。課された納付全体の範囲、市民・共同体・賦課の制度、金額と期限は未完である。「納付を拒めない」は規範上の要求へ部分接続し、拒否の意思や支払不能を未払いから推定しない。また、「市民の義務に反しない」という原文の判断を、積極的な許可と同じ意味にはしていない。納付時の批判の処罰可能性と、それが一般的な抵抗を誘発しうるという条件も残る。

既存の文法と基本関係から9定義を追加した。新しい基本記号はない。全文草案は84,483代用文字で、親文書からの増分は1,172文字、独立抽出文書は2,757文字である。これらは定義を含む文書の長さであり、翻訳文の圧縮率や完成率ではない。
