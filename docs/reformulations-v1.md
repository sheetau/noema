# 前の表現を後の表現へ言い直す

カント第三段落の「使用、むしろ誤用」に、方向を持つ言い直しの記述を追加した。二つの内容の選言や、前の内容の否定としては扱わない。人物・能力・使用行為の三つの引数位置を共通にし、何について言い直したのかを保持する。

対象は[電子本文の AA VIII 36、8–10行](https://korpora.org/kant/aa08/036.html)である。固定した原文と電子本文を比較した読みであり、原刊画像の照合ではない。自然に備わる能力、合理性、誤用の評価根拠は未完であり、対象句全体の同義性を確認したとはしない。

## 記述と内容の区別

`rbf` は、著者が談話箇所・文脈で、先の三項関係の記述から後の記述へ言い直す関係である。`rbg` はさらに二つの記述が異なることを要求する。同じ記述の反復は、この形の言い直しには含めない。

先の内容が偽であることや、後の内容が現実に真であることは条件に含めない。前後が両方真、両方偽であっても、著者による表現の修正は記述できる。向きを交換した関係を自動的には導かないが、逆向きの別の言い直しが存在しないという一般公理も加えていない。

この基本関係は意味規約として与える。どちらが客観的に適切かを判定する処理ではない。ここでは三つの対象を取る内容の記述を使い、任意の型・引数数を一つの関係で扱う多相構文は追加していない。

## 同じ人物・能力・行為への接続

| 記号 | 内容 |
| --- | --- |
| `hh2` | この能力が、この人自身に自然に備わるものとして位置付けられる |
| `hi2` | この人が、この能力を、この行為で使用する |
| `hj2` | この行為に対する合理的使用／誤用の明示的な評価 |
| `hk2` | 著者が言い直す談話箇所 |
| `hm2` | 同じ人物・能力・行為について、能力の帰属、使用、合理的使用の評価が成立する内容 |
| `hn2` | 同じ三項について、能力の帰属、使用、誤用の評価が成立する内容 |
| `ho2` | 著者が `hm2` の記述を `hn2` へ言い直す |

`hj2` の真偽引数は評価の種類を指定する。誤用は、合理的使用の評価がないだけでは成立せず、独立した明示的な評価を要する。両評価が成立する解釈も、どちらも成立しない解釈も、現時点の関係は許す。評価基準の整合性は、この構造だけでは確定しない。

追加した本文の主張は `ho2` 一件である。引用した `hm2` と `hn2` の内容を実行せず、現実の使用行為の存在も、この主張だけからは確定しない。能力を理解力だけに縮めず、別の人の能力、別の使用行為、別の文脈の評価を混ぜない。

## 検証と残る作業

前後の真偽と言い直しの有無を変えた8例、能力の帰属・使用・二つの評価の16例、人物・能力・行為・文脈を取り違える8例、帰属の向きや著者等を変える7例を検査した。言い直しへの言及時には使用や評価の基本関係を実行すると失敗する解釈を用い、非実行を確認した。同一記述の反復も拒否する。

原文接続文書は基本関係183・定義250・主張10件となった。親文書の宣言と9主張を保持し、追加は基本関係5・定義4・主張1件である。正規形は36,654文字、増分は532文字。これは累積した定義を含む文書の大きさであり、短文の翻訳文字数や圧縮率ではない。

原文範囲の対応は空白を除く64文字増え、カント全体で2,451 / 15,513文字（15.80%）となった。範囲内にも未説明の概念があり、完成率としては扱わない。合理性・自然的資質・適切な用途の基礎説明、機械的な道具としての働き、足枷の比喩と依存の持続への接続が残る。

関連25テストが通過した。保存した検証記録の再生成一致、短縮・通常記法と固有文字の往復、CLIから出力したJSONの構造一致、SVGのXMLとしての妥当性も確認した。字形の目視確認は今回行っていない。
