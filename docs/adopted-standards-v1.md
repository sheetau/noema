# 採用された基準の記述と、その評価を結ぶ

前版の教示モデルでは、組織が採用する基準列を関数の値として渡していた。有限検査の採用関係は組織・基準・状況と列の長さだけを照合しており、同じ長さの別の基準列を区別する検査が不足していた。

今回、採用記録と実際に評価する基準列を、一つの閉じた記述へ結んだ。前版を保持したまま、新しい構成`rfw`と、カント草案への接続`hzbi`を追加した。新しい原始概念や文法は使っていない。

## 同じ記述から評価対象を取り出す

基準を表すNoema関数を`zt`、`zu`とすると、その列は次のように記述できる。

```text
r[l[h[a i[h[a] f]] e][p zt p zu]]
```

`rfw`はこの記述を採用関係に渡し、同じ記述を脱引用して実際の基準列にも使う。採用関係に合う記述と、別の実行用の列を独立に渡す構造をなくした。各基準が受け取る対象・発話記述と、組織・役割・活動・受け手の接続は前版を再利用する。

ここで保持するのは、型付きの式の記述である。順序を変えた`[zu,zt]`、同じ基準を重複させた`[zt,zt]`、同じ値を返す別名に置き換えた列も、元の採用記述とは異なる。こうした別記述を組織が明示的に採用すれば、その採用として評価できる。

列の順序や重複が、全基準への適合の真偽を必ず変えるという意味ではない。例えば二基準をともに満たしていれば、その順序を交換しても適合の真偽は同じである。それでも、どの記述が採用されたかという記録を同一化しない。任意の基準同士の意味の等しさを自動判定する方式ではない。

## 義務の対象として引用する

`rfw`と`hzbi`は基準記述を実行時に脱引用するため、そのまま引用することは既存の規則が禁止する。基準記述が閉じた引用として分かった段階で、既存の`specialize_definition`を使い、その引数だけを固定する。静的に分かる脱引用を一つ除去すると、通常のNoema定義として引用できる。

この操作は基準の真偽を実行しない。定義や基本関係の解釈が未知でも、式の構造が分かっていれば引用する対象を構成できる。生成された定義は、同じ展開を人がNoemaで書いてもよい。補助処理が自然言語から教義を推測しているわけではない。

検査では、この固定後の定義を前版の義務・未履行・公的発言への許可に渡す。基準を知っていることや、その基準を満たしたことを、義務が存在する条件へ加えない。

## 検査

要求・許可・禁止・伝達・二基準の真偽を変えた64設定で、動的な構成と固定後の定義の結果を比較した。全文草案と独立抽出文書でも結果は一致した。比較は純粋で全域的なモデルの解釈で行っており、副作用やPythonのオブジェクト同一性を観察する関数の動作一致を保証するものではない。

7種類の別の列を使い、元の採用記録では拒否し、別記述を明示的に採用した場合には受け入れることを確認した。順序変更・重複・同じ結果を返す別名など、同じ長さの例も含む。採用判定には列の長さを使わず、記述の構造を照合する。組織・基準・状況を交換した場合と、採用がない場合も拒否する。

実際の採用関係へ渡された記述を記録し、評価元の記述と一致することを確認した。未知の基準を評価しようとすると停止するが、その基準への義務や公的許可の存在は評価できる。発話の真理と本人の賛同を未解釈としても、今回の条件からそれらを推定・実行しない。

未固定の構成を直接引用する操作と、基準記述が未知のまま固定しようとする操作は拒否する。引用の安全規則を緩めて通した結果ではない。

## 原文への接続と残る課題

カントu0012の「奉仕する教会のSymbolに従って」という既存範囲の接続を具体化した。基準の取り違えを検査できるようにした変更なので、原文の対応文字数は増やしていない。

具体的な教理の内容、基準の完全性と正当性、教会の採用や受任の制度的な意味、良心、辞職の条件は未完である。検査用の二つの基準を、カントや教会の実際の教義として採用したことにもしていない。

2定義を追加し、原始概念・局所参照・著者の主張文は追加していない。全文草案は94,103代用文字で、前版から616文字増えた。一般的な構成の文書は1,279文字、依存定義を抽出した文書は3,450文字である。いずれも定義を含む長さで、原文の一文の圧縮率ではない。
