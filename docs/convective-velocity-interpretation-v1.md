# 新流速の物理的同定と基礎法則の表示系

u0237 は、第五節の速度合成則による新しい三速度の意味説明を理由として、運動学的原理の下で Lorentz 理論の電気力学の基礎が相対性原理に適合すると結論する一文である。原刊917頁で、挿入された §5 参照、nichts anderes、im System k gemessen、Da ... so、damit gezeigt、unter Zugrundelegung、unserer、同じ理論と相対性原理への言及を確認した。

この文全体に必要なのは、構成した三速度と実際の電荷成員の速度との同定、同じ基礎法則の表示系を越えた適用、採用する運動学的原理、適合の意味、著者が導出済みとして提示する役割である。今回の依存群は最初の二つを接続する。本文の全単位判断は、残りも接続して再読した後に行う。

`ek2f/ek2g` は、同じ物質・出来事について旧記録から新記録、新記録から旧記録を要求する。各方向で同じ正逆 Lorentz 写像を使い、両側の単位付きの物理的位置を保持する。`ek2h` は同じ電荷分布の全成員・出来事・対象領域内の全記録について両方向を要求する。新側だけの全称条件にして、新記録の欠落で同定が空虚に通ることを避ける。

`ek2i` はこの対応、k の速度単位校正、k の同じ分布の実際の流速 `ekxl` を結ぶ。流速場は前回の `ekzu` をそのまま使い、領域は同じ逆像 `s6m` である。`ekxl` 内の `ekxi/ekxh/seoc` は、同じ成員の物理的な履歴を同じ座標時刻で微分する。固有時速度、速さだけ、同じ数値時刻、全物体の一様運動へ替えない。`ek2j` が同じ全変換設定でこの同定を述べる閉じた内容となる。

既存の基礎法則の解釈条件 `ekyo` には、校正 `ekym` を通じて K という固定参照が含まれる。他系での同じ法則を比較するため、`ek2k` はその表示系の固定だけを外し、`ek2l` はそれ以外の完全な担体付着・物質対応・密度・成分合成・支持・流速を保つ。K に戻せば元の条件に一致する。`ek2m` はその条件の下で同じ原系形の `ekyq` を要求する法則内容で、全系での真理を定義だけで断言しない。

次に、この具体的な法則内容と同じ Lorentz 理論の基礎としての採用を結び、全適格系での法則成立と全候補履歴での適合保存を表す必要がある。相対性原理 `eifj` の全内容への参照を保持し、一組の数値が合うだけ、別の法則が各々の系で成立するだけ、都合のよい履歴だけの比較へ縮めない。第五節への参照、運動学的原理の採用、著者の推論と結論提示もまだ残る。

印刷 M0389 の磁気側に 1/V がないことは保存する。基礎法則は元の `ekyq` の形であり、印刷された変換結果を黙って修正しない。著者が適合を結論するという記述と、その導出が物理的に健全かどうかは別の問題である。
