# 剛な球と球面式、著者脚注の円文字表現

原刊903頁のu0110–u0111と著者脚注u0281を、同じ物体・半径・二つの座標系へ接続する。既存の28定義と文書内の参照を使い、アルファベット、共通375語、任意プロファイル58の802語を維持する。

対象の球には、内部と境界を含む理想的な閉球連続体という採用済みのモデルを用いる。全物質点の履歴と閉球の全実数三位置への被覆を保持し、境界は占有領域と任意の正半径の開近傍から定める。このモデルは当該物体について明示した選択であり、球形という語だけから内部充填や一様密度が必然的に従うとは扱わない。

その同じ物体について、kでの静止と測定原点にある中心、Kでの同じ速度による並進を結ぶ。各系の期間と同時性を区別し、kの現在記録の全範囲で、占有領域の境界とξ²+η²+ζ²=R²との双方向の一致を述べる。正例だけを範囲として選別せず、少なくとも一つの境界記録を要求する。一般の静止時の形状分類には非零の中心を許し、中心零は今回の設定で加える。

本文の二文と表示式は、採用済み第53段落に続く第54段落に属する。第一文は23トークン、第二文と表示式は17トークンである。式提示の参照は第二文の16–17番に結び、16番の`ist:`内にあるコロンを記録する。脚注の付着箇所は第一文の`Kugel`直後、`vom`の直前であり、原刊の注番号1とHTMLの参照番号3、原刊掲載頁903とインベントリ末尾の921を区別する。

半径は設定箇所に結び付く正の実数切断として参照し、物体はその半径と同じ物理設定を使う役割で参照する。役割は本文に定義し、参照の取得時には実行しない。考察の前提としての設定採用、球面式の提示、静止時の形による著者脚注の説明を別々の発話として保持する。

検査では復号した本文の定義を使い、全形状・全履歴・現在記録の引数接続、三座標と半径、表面条件の両方向、参照の各引数と未知入力の拒否を確認する。有限診断で実数の証人を例化する場合も、元の量化を持つ本文を別に照合する。有限点による診断、一般実数域の証明、原文の意味判断、独立した読解は区別する。後続のK座標への変換、t=0断面、楕円体と収縮は次の範囲に残る。
