# 言語として使えるNoemaへの開発目標

**評価の訂正:** KWDLCの主辞位置の取り込みに不備を確認し、旧コーパス評価・参照判定器v1の学習と選択を撤回した。[基本句の注釈を使う修正](corpus-reference-v2-correction.md)を実装し、旧重みの読込みを禁止した。以下の過去の到達点にある旧主辞・参照精度は現在の根拠に使わない。

現時点では全体を完了していない。文語0.6までの記述体系・複合語・状態からの派生語・複数対象の結合と再参照、文字版2の機能別の字形構成・資料・編集画面を実装した。15概念の自然言語解析はv7の新規人工文で数値条件を満たした一方、未対応判定を改善するv8・v9は英語の確定率が下がり、不合格となった。基本語全体の意味構成、解析器の未解決問題、字形を含む利用者の読み書きの未検証が残る。

利用者が追加した[文字数・対応範囲・辞書／ハードコード依存の課題](open-problems.md)も完成条件に含める。通常のLLMが理解できる文を翻訳可能にする目標を、現在の限定範囲へ縮小しない。現行の定型文による逆変換も、最終方式としての置換が必要である。

## 完了を判断する対象

1. **人が文を作れる記述体系**。概念のIDやノード宣言を毎回書かず、役割・否定・時間・数量・名前を表せる。文を連ね、同じ対象を明示的に参照し、質問・依頼・条件・接続の作用範囲を区別できる。
2. **拡張できる語彙と語形成**。日常の記述に使う基本概念を定義し、語の追加・組合せ・版管理の手順を確立する。既存概念を別の意味へ変えない。語彙数を増やしただけで表現力の検証を済ませたことにはしない。
3. **一貫した書記体系**。固有アルファベットを作成し、代用文字との対応、句読法、単語の境界、数字、外来固有名を定義する。図の存在だけで人にとっての識別性を保証しない。ユーザーの指定により文語を優先し、発音・会話体系は今回の必須作業から外す。
4. **意味と実装の一致**。意味構造・文法・型・参照・作用範囲を検査し、Noemaと意味構造の往復を保証する。旧版の文書と意味を保存する。読めない版や意味を黙って切り捨てない。
5. **学習して利用できる資料と道具**。入門、文法・語彙参照、対訳付きの複数段落の文章、練習と解答、入力して誤りを確認する方法を用意する。資料中のNoemaを実装で検査する。
6. **非生成型解析の実用判定**。固定した多言語モデルと小型分類器を使う方針を継続し、範囲・概念・役割・否定・時間等の失敗を改善する。日英を別々に測定し、対応範囲内の確定率80%以上・確定出力の完全一致率95%以上という元の基準を保持する。未知・未対応を既知の意味に押し込む誤りも報告する。
7. **独立した検証**。原文や正解を変えて通過させず、語彙・文型・組合せの汎化を測る。確信度やモデルの選択に最終評価資料を使わない。人が資料を使って未掲載の文を書けるかという使い勝手は、自動テストと別に扱う。
8. **冗長な表記を減らす**。日英の短文に対する文字数の膨張を測り、意味を保って改善する。全ての文が原文より短いことまでは要求しないが、ヘッダーや空白の除外だけで短縮を主張しない。
9. **広い自然文を辞書・ハードコードなしで翻訳する**。通常のLLMが理解できる文を対象とする。対訳表・例文検索・個別テンプレートによる対応例の追加を解決策にせず、非生成型・プロンプト不使用の制約と同時に満たす。

## 継続する制約

- Noemaの意味・語彙・文字はモデルから独立させる。生成モデルと指示プロンプトによる翻訳、原文の復元は実装方針に含めない。定型文による逆方向は既存の限定試作であり、2026-09-28の追加指定により最終方式として採用しない。
- 構造不整合や低確信度を、特定の自然文だけに適用する補正規則で隠さない。
- 2026-09-28の利用者指定により、プロンプトで生成モデルに翻訳させる方式は今後も採用しない。固定概念の分類器の反復改善を優先する進め方を見直し、[意味からの語・文字の構成と既存モデルの利用](design-review.md) を検証する。
- 変更と検証結果は区切りごとにローカルコミットする。重み・特徴量・一時成果物はGit管理から外す。
- 言語としての完成を、旧版のテスト成功や人工文の成績だけで宣言しない。外部の利用者による定着・普及は、設計・実装の完成とは別の事実である。
