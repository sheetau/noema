# 言語として使えるNoemaへの開発目標

現時点では全体を完了していない。文語0.4の記述体系・固有文字・複合語・資料・編集画面を実装し、15概念の自然言語解析はv7の新規人工文で数値条件を満たした。一方、未対応判定を改善するv8・v9は英語の確定率が下がり、不合格となった。解析器の未解決問題と、利用者による読み書きの未検証が残る。

## 完了を判断する対象

1. **人が文を作れる記述体系**。概念のIDやノード宣言を毎回書かず、役割・否定・時間・数量・名前を表せる。文を連ね、同じ対象を明示的に参照し、質問・依頼・条件・接続の作用範囲を区別できる。
2. **拡張できる語彙と語形成**。日常の記述に使う基本概念を定義し、語の追加・組合せ・版管理の手順を確立する。既存概念を別の意味へ変えない。語彙数を増やしただけで表現力の検証を済ませたことにはしない。
3. **一貫した書記体系**。固有アルファベットを作成し、代用文字との対応、句読法、単語の境界、数字、外来固有名を定義する。図の存在だけで人にとっての識別性を保証しない。ユーザーの指定により文語を優先し、発音・会話体系は今回の必須作業から外す。
4. **意味と実装の一致**。意味構造・文法・型・参照・作用範囲を検査し、Noemaと意味構造の往復を保証する。旧版の文書と意味を保存する。読めない版や意味を黙って切り捨てない。
5. **学習して利用できる資料と道具**。入門、文法・語彙参照、対訳付きの複数段落の文章、練習と解答、入力して誤りを確認する方法を用意する。資料中のNoemaを実装で検査する。
6. **非生成型解析の実用判定**。固定した多言語モデルと小型分類器を使う方針を継続し、範囲・概念・役割・否定・時間等の失敗を改善する。日英を別々に測定し、対応範囲内の確定率80%以上・確定出力の完全一致率95%以上という元の基準を保持する。未知・未対応を既知の意味に押し込む誤りも報告する。
7. **独立した検証**。原文や正解を変えて通過させず、語彙・文型・組合せの汎化を測る。確信度やモデルの選択に最終評価資料を使わない。人が資料を使って未掲載の文を書けるかという使い勝手は、自動テストと別に扱う。

## 継続する制約

- Noemaの意味・語彙・文字はモデルから独立させる。生成モデルと指示プロンプトによる翻訳、原文の復元は実装方針に含めない。
- 構造不整合や低確信度を、特定の自然文だけに適用する補正規則で隠さない。
- 変更と検証結果は区切りごとにローカルコミットする。重み・特徴量・一時成果物はGit管理から外す。
- 言語としての完成を、旧版のテスト成功や人工文の成績だけで宣言しない。外部の利用者による定着・普及は、設計・実装の完成とは別の事実である。

## 現在の作業順

まず人が書く文の記法と複数文の意味構造を整備する。その後、語彙・読み方・学習資料・入力支援を拡張し、並行して解析器の学習資料と関係抽出を改める。各項目の実装・検査・未検証事項をこの目標に照らして記録し、全体の未完了を維持する。

## 2026-09-27の到達点

- 文語0.3は91概念と8役割、参照・質問・依頼・接続・否定範囲を扱う。旧版の読込みと意味を保った変換を検査した。測定単位、時間の組合せ、量化などは後続の拡張事項である。
- 固有アルファベット32文字、TrueTypeフォント、SVG表示、文字の相互変換を実装した。人による識別性評価は未実施。
- 入門・語彙参照・対訳読本・練習解答・ローカル編集画面を実装し、資料の全用例を構文解析と往復で検査した。未掲載の文章を利用者が読み書きできるかは未検証。
- 関係分類器を追加し、開発用データでは言語別モデルの選択により両言語が基準を通った。選択を固定した最終評価では、日本語の確定率69.44%・完全一致率99.81%、英語68.05%・90.44%となり、必須基準を満たさなかった。[実験報告](structured-experiments.md) に失敗を含めて保存した。
- 解析の対象語彙は依然15概念であり、文語0.3全体の自然言語解析ができるとはしていない。最終評価を参照した後の改善には、新しい独立評価が必要になる。
- 続く共同役割割当て・学習資料拡張で、既存の回帰資料は日本語749/756件、英語884/892件を確定し、確定出力は全件正解となった。ただし手書きの日本語受動態で役割逆転が残る。その後、予測前に固定した新しい人工文の確認評価では、日本語の確定率92.00%・完全一致率99.82%、英語65.67%・99.24%だった。英語の確定率と日本語の未対応誤確定率5.56%が不合格となった。[最新報告](joint-experiments.md) に失敗を含めて保存した。利用者評価も未実施であり、完成目標は未完了のまま継続する。
- 文型追加と未知概念の範囲学習の後、別の新規人工文では日本語96.50%・97.75%、英語90.17%・100%となり、両言語の確定率・完全一致率と未対応誤確定率の固定条件を通過した。従来の手書き対応例28文もすべて正解になったが、代名詞など未対応3文を誤確定した。[現在の報告](surface-experiments.md) に合格範囲と後退を併記した。
- 91語の意味説明を日本語で読めるようにし、編集画面で文書の再読込み・復元、数量と名前の入力補助を実装した。ブラウザーで大きな整数が丸められる問題を修正し、`9007199254740993` を正確に表示・JSON保存できることを確認した。

## 2026-09-28の到達点

- 文語0.4で名詞・場所と13種類の性質を組み合わせる語形成を実装した。修飾を否定の外へ移動させず、参照・数量を保持する。厳密な仕様、複合語の対訳読本、編集画面の入力補助を追加した。意味を失う旧版変換は拒否する。
- 読む12問・書く6問の練習画面を追加した。固有文字／代用文字、解答の参照、初回と再回答を区別して記録できる。ブラウザーで回答と記録の動作は検査したが、実際の利用者の結果はまだ受け取っていない。
- 参照の対照例を加えたv8は、新規確認で日本語89.00%・100%、英語49.83%・100%だった。英語の確定率と名前／抽象概念区分の誤確定率が不合格となった。手書きの代名詞など3文は保留できたが、英語の文頭場所句の過剰抽出が増えた。[失敗と内訳](reference-experiments.md) を保持し、既知の周囲の範囲も教える対照実験を進める。
- 周囲の範囲注釈を加えたv9も、新規確認で日本語91.67%・99.64%、英語51.00%・100%となり、不合格だった。同じv3回帰でも英語の確定率は回復していない。[学習量別の成績・要素別の失敗・回帰結果](context-experiments.md) を保存した。個別文への修正規則や閾値の再調整で合格にしていない。
- 旧版との往復、複合語、練習の採点、学習済み重みの上書き防止をテストした。追加ライブラリを読み込まないPythonでも、文語の解析・整形・SVG表示・編集用処理・練習採点が動作した。利用者確認の結果は未受領。
