# concept2の文書・辞書規則

採用されたv7の497字形と幹の参照順を保持し、語の宣言、定義、別綴り、仮定範囲の4記号を補う。既存の語義や原始語は増やさない。追加記号は中円、大円の225度円弧、円周間の方向線で区別し、中心線を型や命令の番号に転用しない。

## 宣言から本文までの読順

文書は宣言・綴り登録、本文の順に読む。各項目の境界は本文と同じ幾何規則で決める。途中の改行には中円半径の継続線を置き、次の行へ構文の読取り状態を引き継ぐ。項目が完結してから次の項目を登録する。

宣言名は公開された根の列で書き、末尾の語境界を省略しない。1根なら根語、2根以上なら複合語として元の公開名へ復元する。宣言時点でその語を辞書から探す必要はない。記録の構成は次のとおりである。

| 記録 | 読む順序 |
| --- | --- |
| 原始語 | 原始語の記号、完全名、語境界、引数型列、型列終端、結果型 |
| 定義語 | 定義の記号、完全名、語境界、結果型、パラメータを束縛するlambdaと本体 |
| 別綴り | 綴りの記号、登録済みの完全名、語境界、新しい根列、語境界 |

型列と再帰的な型の規則は[型・束縛規則](alphabet-concept2-typed-v6.md)を共用する。定義は結果型と本体の型が一致した後に登録する。定義自身や、まだ宣言されていない語を本体から呼ぶことはできない。定義の変数名はnativeの正規名へ戻し、束縛先、引数順、引用の独立性を保存する。

型が続けて同じになる箇所と、変数の参照距離を数える印の連続は、既存の2〜5回の反復記号でまとめる。復号時は先に反復を展開してから型や束縛を読む。6回以上は最大5回ずつに分け、反復記号そのものの連鎖は許さない。小円単独は引き続き圧縮対象から外す。これによって型の個数と参照距離を保持しながら、同形の円が長く続く箇所を減らす。

別綴りは既に登録した語へ追加する。既存の完全名・別綴りとの衝突、重複登録、未宣言語への割当てを拒否する。以前の綴りも有効なままとし、以後の生成では最後に登録した綴りを選ぶ。既存辞書を出版するときは、その辞書が選んでいる綴りを最後に登録する。

本文では、その時点までに登録された綴りから最長一致で語を読む。後続の根が長い別語を作ってしまう箇所にだけ語境界を置く。引数数は登録済みの型署名から決まり、未宣言の語、引数の不足、型の不一致を拒否する。将来の宣言や文書ごとの番号表を読む必要はない。

## 基礎語彙と語義の保持

旧公開辞書の綴り表には1,705語がある一方、保存された宣言本文は1,344語だった。基礎語彙からの361語を既存の語彙実装から明示的に取り込む。最終的な1,705宣言は原始語487件、定義1,218件となる。元の1,344宣言、2,109綴り対応、選択綴りを保持する。

原始語の宣言は型署名を与える。原始語の解釈は、従来の公開名に結び付いた意味規約を引き継ぐ。定義語は既存の本体をそのまま記載する。描画から回収した宣言・本体・参照先の一致と、原文についての意味判断は別に記録する。

## 仮定範囲

仮定範囲は、仮定の記号、括られた条件、括られた子文列からなる。各子文も個別に括り、仮定範囲を再帰的に入れ子にできる。条件は真偽型、子文列は1文以上とする。条件と各子文では、段参照、局所参照、ドット対、変数の状態を独立させる。条件中の一時的な参照を子文で誤って使うことはできない。

## 復号と処理範囲

`DocumentCodec` は空の辞書、または明示した共有辞書から開始する。SVGの円弧・直線・ドットだけを読み、宣言と本文を順次登録する。SVG要素の順番、不可視の属性、配置記録、元の構文、期待する語列は復号入力にしない。失敗した記録は登録しない。失敗前に完結した記録は保持する。

実装は公開字形と接続規則に沿ったSVGを対象とする。任意の自由配置、画素画像、手書き文字の認識まで保証するものではない。nativeの深さ上限128、型の階数上限128、完全名の最大24根を引き継ぐ。有限の対照検査の件数を、制約外の配置についての一意性証明とは扱わない。

高速復号版は同じ入力の線についての被覆判定を1回の読取り内で再利用し、数値だけからなる図形要素を浅く複製する。異なるSVGへの判定持越しや、意味判断としてのキャッシュ保存は行わない。旧復号器を残し、構文の区別と不正入力を含む対照で結果を比較する。

`CompactDocumentCodec` はこの反復と高速復号を合わせた実行入口である。既存の497字形と文書用4字形は `DocumentCodec` と同一である。変更前後の語列も同一の項目は、検証済みSVGの内容ハッシュと描画実装の一致を確認して既存証拠を引き継ぐ。語列が短くなった項目だけを再描画・再復号する。

新規文書には `scripts.concept2_document_reader.DocumentReader` を使う。これは上記の処理に、原始語の結果型が反復記号で終わる場合の終端規則を加えた入口である。たとえば入れ子の質問型では、型列終端が連続する。その反復の後に語境界の小円を置き、記録が縦線だけで終わらないようにする。別綴りの末尾に必要な語境界とは区別して読む。

## 実行入口

```powershell
python -X utf8 -m scripts.project_work check --tests tests/test_concept2_document.py tests/test_concept2_fast_reader.py
python -X utf8 -m scripts.build_concept2_dictionary --run .noema-project/runs/<new-run> --out output/<new-output> --geometry
python -X utf8 -m scripts.build_concept2_dictionary_compact --run .noema-project/runs/<new-run> --out output/<new-output>
```

辞書生成は記録ごとのチェックポイントと60秒以内のheartbeatを保存する。中断後は同じ引数へ `--resume` を追加する。入力・実装・既存SVGの内容ハッシュが変わった場合は以前の結果を再利用しない。
