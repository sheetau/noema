# 付随する式を著者の提示へ結ぶ

M0390の五つの等式と参照関係を、本文の「wobei」に続く著者の提示へ接続した。著者がある範囲で式を提示すること、直前の箇所をその式で説明すること、式の内容が真であることを分ける。

| 定義 | 役割 |
| --- | --- |
| `senw` | 同じ参照先について、五つの等式と必要な三偏微分を満たす微分表が存在する |
| `senx` | 光速度と帰属・配置の三関係を固定し、その文脈で参照条件に合う各場合について`senw`を要求する内容 |
| `seny` | 著者の範囲内提示、先行箇所への説明関係、本文順序を同じ著者と文脈で結ぶ |

`senw`の微分表は存在量化する。未使用の成分まで実際の微分値として決めたり、任意の表が正しいと要求したりしない。実際に関係する三成分は、先行版の`sent`を通じて同じ電場・地点・軸へ結ばれる。

`senx`では光速度と、物質の量の割当・電場の割当・二系の標準配置の三関係を引数として固定する。残る18個の対象・量・場などを量化し、参照条件`senu`を満たす場合にだけ`senw`を要求する。帰属関係そのものを任意の関係として量化すると、偽の割当まで含む全ての入力について式を要求してしまう。また光速度を量化すると、同じ物体の値に対して任意の光速度で式が成り立つという強すぎる主張になる。原文への接続では既存の光速度`tc`を明示した。

著者の提示には既存の`uh`を使う。本文順序`ue`と、先行箇所を後の箇所で説明する`uf`は、カント側ですでに定めた一般の談話関係を同じ意味規約で使用した。新しい文法演算子は追加していない。説明される先行箇所と説明する箇所は区別し、本文順序を出来事の時間順序や論理的な含意として扱わない。

原文付き草案には一つの帰属主張を追加した。同じ著者と文脈で、M0389の箇所の後に、M0390の内容を§9の考察範囲内で提示し、先行の式を説明するという記述である。前の式の内容・全ての仮定・導出まで完成したとは数えない。「wobei」を付随する関係による説明として読む部分解釈であり、この語の全用法を一つの関係に固定したものでもない。

引用内容には、三つの帰属・配置関係への参照も残す。関係の識別表記だけで意味説明を済ませず、型と引数の意味規約を記録した。ただし、電荷・速度・基準系・測定の共有された意味を完全に説明する課題は残る。過去の原文単位別の確認記録は、その時点の記録として保持する。

検査では、提示・説明・本文順序・内容の真偽を独立に変える16例を使った。内容が偽でも提示の帰属は成立しうる。同じ真偽を持つ別の記述への置換は認めない。原文側では著者・箇所・範囲・文脈・本文順序の12条件を比較し、光速度や三つの帰属関係を別の参照へ置き換えた引用も区別した。引用された物理内容や関係は、この帰属検査では実行されない。

内容そのものを評価しようとした場合は、実数を表す切断の全域量化に達した時点で、有限解釈器が拒否することを確認した。構文の往復や有限の対照例を、全ての実関数にわたる内容の真理の証明にしない。逆に、物理理論の真理を証明できないことを、言語として引用・提示できないこととも混同しない。

一般の`seny`は209文字の[独立した文書](../examples/v014/accompanying-relations.noema)として抽出した。例えば、調査報告書で表を提示した後に、測定値の定義を添えて説明する場面にも、著者・先行箇所・説明箇所・範囲・文脈・引用内容を変えて使用できる。一般検査は電磁気の記号や物理量に依存しない。

[原文付き草案](../examples/v014/einstein-equation-presentation.noema)は325,799文字、[必要な定義の抽出文書](../examples/v014/equation-presentation-core.noema)は10,796文字である。3定義、既存の談話関係2個・局所参照3個・関係値3個の宣言、1件の帰属主張を追加し、親の174件の主張を保持した。[意味規約](../data/einstein-equation-presentation-basis-v1.json)と[検査記録](../reports/equation-presentation-v1.json)を保存した。
