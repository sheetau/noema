# 現在の回答と、表題の同じ問い

脚注の`die gegenwärtige`を現在の論説への言及として明示し、その論説を表題と同じ問いへの回答へ結んだ。前版では、先の回答は問いへの回答として紹介される一方、現在の論説は差し控えや思想比較の対象として参照されていた。表題と冒頭の説明提示の接続もあったが、脚注の現在の文書個体を同じ問いへの回答として指す関係がなかった。

新しい局所参照`hzls`は、この脚注内の現在の回答への言及を指す。`hzlt`で、その言及の成立、現在の論説内での記載、表題箇所が表す問いへの回答としての言及を結ぶ。先の回答と現在の論説、案内記事内の紹介と現在の言及をそれぞれ区別する。問いの内容は既存の表題記述へ接続し、新しい問いや文献を作らない。

意味関係は既存の`dg`・`hzjk`・`hzjj`を使う。文献内の記載と回答としての言及は、文献が自分自身に言及する場合にも適用できる。新規の基本関係はなく、局所参照と合成定義を一つずつ加える。既存24文・全宣言・意味規約・名称表記は保存する。回答として言及されることから、答えの真理・正しさ・十分性を導かない。

この読みは、既に固定した原文と原刊494頁の、先の回答から現在の回答への対比に基づく。先の回答を受領した場合の帰結が反事実であっても、現在の文献が何を指すかという言及は脚注の実際の文脈へ置く。現実に差し控えたことを主張せず、執筆・送稿・刊行の段階も追加しない。

検査では、言及・文献・問い・文脈・記載先の取り違えと欠落、先の紹介だけによる代用、文献や言及の同一化を退ける。新しい七文の同時検査には前版の11解釈と今回の8対照を含み、既存六文が成立しても現在の回答の接続だけが欠ける場合を区別する。現在の回答という関係が未知なら保留し、回答の正しさについては真と偽の両解釈を許す。

署名と日付行の意味と依存関係は変わらない。既存二単位の全体確認を後継本文へ移すが、脚注の確認済み単位は増やさない。著者注の補足先、刊行物名の説明要素、敬称の社会的含意、偶発性と思想の比較基準など、[前段の全体点検](footnote-audit-v1.md)に挙げた他の項目は残る。元の点検記録は変更せず、現在の回答の接続についてはこの実装と検査を後続の根拠とする。
