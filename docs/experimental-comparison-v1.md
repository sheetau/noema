# 独立した測定の比較と実験の可能性

アインシュタイン1905年論文u0268の「電子の速度を直接測れるため、この関係を実験で調べられる」という箇所を部分記述する。偏向から予測する速度と、独立に直接測った速度を比較する条件を作った。比較の実行可能性、実際の測定、結果の両立は別の内容である。

原文は誤差区間を指定していない。今回の区間モデルは比較を具体化する解釈候補であり、原文全体の同義表現として完成したとは扱わない。高速に振動する電場・磁場による測定装置の例は、対応範囲から除いた。

## 数値と記録

電気側の応答を `[el, eh]`、磁気側を `[ml, mh]` とする。`0 < el ≤ eh`、`0 ≤ ml ≤ mh`、光速度 `V > 0` の下で、予測速度の区間を `[V ml / eh, V mh / el]` と定義する。電気側の区間が零を含む場合にはこの比較を成立させない。

直接測定の区間との共通部分に、零以上かつ光速未満の速度があれば数値上は両立する。境界一点だけの重なりも認めるが、その一点が光速度なら両立しない。直接測定の下限が負でも入力を書き換えず、許容速度との共通部分を調べる。入力が無効な場合は、実験結果の不一致とは区別する。

三つの記録は同じ対象・基準系・比較条件に結び、記録、量の種類、出来事、単位、正の尺度、測定法を保持する。異なる出来事で測った値も比較できるが、同じ運動条件に対応するという入力関係 `matched` を要求する。単位換算は既存の校正関係 `zof` を使う。

直接法が検査対象の式を算出の前提として使わないという独立性も、明示した入力関係である。異なる方法名だけから独立性を認めない。区間は保守的な上下限として扱い、確率分布や信頼区間は含めない。

| 定義 | 内容 |
| --- | --- |
| `setz` / `seua` | 有理数 / 実切断による予測区間 |
| `seub` / `seuc` | 許容速度を含む共通部分 |
| `seud` / `seue` | 有効な数値入力 / 有効だが両立しない入力 |
| `seuf` / `seug` / `seuh` | 記録付きの比較条件 / 両立 / 不一致 |
| `seui` | 偏向記録の存在を前提にしない直接測定の記録 |
| `seuj` | 許容状況の少なくとも一つで内容が成立する可能性 |
| `seuk` / `seul` | 本文の比較内容 / その可能性 |
| `seum` / `seun` | 本文の直接測定 / その可能性 |
| `seuo` / `seup` | 同じ記録の両立 / 不一致を調べる内容 |

## 可能性と著者への帰属

偏向測定と直接測定が別々の許容状況で可能でも、同じ比較条件で両方を得られるとは限らない。両者を実行できる共同の状況を、比較可能性の条件に含めた。共同の状況があっても、現実に実施済みであることや、結果が式と両立することは要求しない。

本文では比較可能性と直接測定可能性を著者の主張として引用し、後者を前者の理由として挙げる接続を記録する。この接続自体を妥当な推論規則とはしない。両立・不一致の検査用内容を、著者が得た実験結果として帰属させることもない。先行194文を保存し、帰属の三文を追加した。

## 検証と残る範囲

有理数上では、予測区間による包含、共通速度からの両立、両立時の最大下限による共通速度の構成を一般命題として検査する。区間の重なりが中心値の一致を要求するという主張には反例を残す。実切断の実行例は登録した有理数埋め込みであり、全実数の演算法則の機械的証明とは区別する。

数値の境界例に加え、単位変更、対象・系・量の種類・記録の取り違え、独立性の欠如、出来事の対応欠如、共同状況の欠如を検査する。本文と抽出版で同じ結果になること、通常表記・独自字形の往復、CLI解析、出典範囲と入力ハッシュを検証報告に保存する。

区間の妥当性、独立性、出来事の対応には、物理的な説明が残る。また区間が広すぎる比較でも条件を満たしうるため、結果を区別する力や必要な精度、十分な反証可能性までは構成していない。高速に振動する場を使う装置、u0266後半の任意速度での決定可能性、原文全体の意味一致は未完である。
