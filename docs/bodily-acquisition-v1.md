# 身体的な能力取得とその見込み

カント第二段落の「少数回転びながら、やがて歩くことを学ぶ」という描写を、活動ごとの能力評価、経験による取得、将来の見込みの三段階で構成する。原文は `kant-1784:u0009` の1259–1324に対応し、既存の部分草案の範囲内である。これは採用した読みの下での追加であり、第二段落全体の意味確認ではない。

`rqvv` と `rqvw` は、既存の評価条件 `rqvm` と行使能力 `rqvn` に、閉じた活動記述を加える。候補状況、本人側の基盤の保持、外的機会、通常性の順序、方法の範囲、範囲の評価済み条件へ、同じ本人・活動・基準を渡す。知的活動向けの `hzsc` などを身体側に流用しない。今回の六つの活動付き入力関係は、特定の身体技能を丸ごと判定する語ではなく、一般的な能力条件の文脈を指定する。既存の方法選択・結果・結果評価も保持する。

一般形では実行内容と閉じた活動記述を別に受けるため、両者を一致させる責任は呼出側に残る。身体側の `hzuw` と `hzux` は同じ本人の `zal` とその記述を渡す。文脈モデルで真理値が偶然一致する二つの活動でも、機会や技能の評価を自動で共有しない。準備学習だけが成功する方法を既有能力へ数えず、未評価を能力不足と確定しない。

`hzv5` は同じ試行の同じ結果が転倒の身体条件を満たし、取得終点以前であることを求める。早い非転倒の結果と遅い転倒の結果を組み合わせて期限条件を満たすことはできない。`hzuy` は非空で重複のない順序付き経験列を既存の `r5` へ渡し、各転倒の同じ取得への寄与、本人と過程の同一性、両端の評価、能力の不在から存在への変化を確認する。回数が少ないかは元の文脈の基準で判断し、普遍的な固定回数を置かない。

`hzv3` は活動付きの見込み候補 `hzv2` を使い、非空の将来候補の全てに取得が成立する内容を作る。取得が実際に起きたことや全可能性での必然性は含めない。`hzv4` は同じ学習節で、知的活動の取得見込み `fr` を身体的な取得見込み `hzv3` で非字義的に提示する。両側の本人を保持するが、両内容の真理や同一性を主張しない。

検証は現在の評価器で定義本体を実行する。一般形の16組合せと六対照、身体的取得の19条件、取得終点と転倒結果の三条件、見込みの八条件、比喩帰属の七条件、未知入力、既存本文と九つの確認済み判断、標準・短縮・独自文字表記の往復を検査する。一般形と期限条件は通常評価、入れ子の取得・将来候補の探索は純粋な計算結果の再利用を使う。能力や取得の定義を検査用の真偽述語へ置換しない。

九定義と七基本関係を追加し、本文は39文を保持して40文になる。確認済み九単位・587非空白文字は増やさない。原文が能力の評価モデルを一意に指定するわけではなく、熟達の程度的な改善、`zal` の歩行と走行の区別、würden・wohl の語用論の全体、第二段落全体の確認は残る。著者の心理・教育上の主張を実証することは、言語として記述できることとは別である。
