# 納付要求のある状況での批判

カントu0012の「その賦課に対する批判、それを本人が納付すべきとき」という箇所へ、納付要求・批判・誘発可能性・措置の可能性を結ぶ条件文を追加した。同じ人への要求と、その人の批判行為を保持する。批判されている対象が、どの納付要求の賦課に対応するかも明示する。

| 記号 | 内容 |
| --- | --- |
| `rfo` / `hzaw` | 指定した人が同じ発話行為で、非空の受け手範囲へ、同じ対象に関する同じ発話記述を示す。`hzaw`は既存の提示関係へ接続する。 |
| `hzax` | 同じ文脈で納付の要求があり、本人が別の行為で批判を述べ、その対象が同じ納付要求の賦課に対応する。 |
| `hzay` | `hzax`の批判行為が、指定した評価性質を同じ文脈で満たす。 |
| `hzaz` | 同じ批判について、抵抗を誘発する可能性と、その人のその批判への措置の可能性がある。 |
| `hza2` | 指定した非空の仮定状況範囲の全てで、`hzay`なら`hzaz`が成立する。 |
| `hza3` | 指定範囲のどこかで`hzay`が成立する。条件文の真理とは別の条件。 |

条件文には既存の`rc`を、前件の実例の存在には既存の`re`を再利用した。範囲内に前件が成立する事例がなくても、条件文は真になりうる。一方、範囲内の一事例だけで前件と帰結が成立しても、別の事例で前件だけが成立すれば、条件文は偽になる。

納付内容は、受け手と媒体を固定した`hzah`の閉じた適用で指定する。批判内容には、適切さと公正さの条件列から作る`rfd`を使う。要求・発言・対象の対応を調べる際に、実際の納付や批判内容の真偽は評価しない。また、この文の批判へ「学識者として公に述べる」という後続節の条件を先に追加しない。

賦課との対応関係`charge`には、批判の対象、要求の出所、本人、役割、納付行為、納付記述、文脈を全て渡す。要求の存在と批判の存在が別々に確認できても、両者が同じ賦課に結び付かなければ`hzax`は成立しない。この対応関係は明示すべき意味上の前提であり、制度や税の一般的な定義を代わりに与えるものではない。

二つの可能性は別々の候補範囲で評価する。抵抗の起きる候補と処罰の起きる候補が異なっていても、それぞれの可能性は成立しうる。ただし、因果の中では批判と抵抗を同じ候補へ結び、措置の中では同じ施行者・本人・批判・評価・措置を保持する。どちらの可能性からも処罰の許可は導かない。

検査では、納付要求・発言・対象の対応・評価性質・誘発可能性・措置の可能性の64通りと、参照や仮定範囲を変えた20対照例を確認した。全文草案と独立抽出文書の結果は一致する。実際の納付、批判と措置の評価内容の真偽、公的使用、許可を未知のままにしても、これらの条件は評価できる。賦課との対応自体が未知の場合は停止する。

*wenn sie von ihm geleistet werden sollen* は、納付を要求されている状況へ条件を制限する読みを採用した。同じ文脈への参照は保持するが、具体的な支払期限、支払い中という進行状態、未払いの故意を補わない。*vorwitzig* の評価性質を渡す位置は用意したものの、その具体的な語義は未完である。*als ein Skandal*、*sogar*、後続の *demohngeachtet* も残る。挿入説明の誘発可能性を条件文の帰結側へ置くのは、今回の明示的な読みであり、仮定の外でも独立に述べられる付加説明という読みを排除した証明ではない。

7定義を追加し、基本記号と著者主張は追加していない。全文草案は89,651代用文字で、親からの増分は1,759文字、独立抽出文書は4,075文字である。これらは定義を含む文書の長さであり、翻訳の圧縮率や意味確認率ではない。
