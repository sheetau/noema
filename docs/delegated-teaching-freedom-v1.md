# 同じ教示の自由に対する現実の否定と規範的否定

原文 `kant-1784:u0012[4408,4734)` の一文に向け、聖職者として自由ではないことと、自由であってはならないことを分けて構成する。原刊487頁の前後を再読し、同頁前方の教示内容の自由な決定権限と、直後の学識者として世界へ語る自由との対照を保持する。

自由はここでは、同じ職務で同じ主題と発話について教示の内容・扱いを自分の判断で決める権限と読む。既存 `r4d` の、決定権限 `h247p` と、他者の指定に拘束されず本人の判断を最終的な基準とする `h247q` の組合せを使う。`r44i` はその現実の否定 `r4e` である。権限自体がない場合のほか、権限はあるが他者の指定に従う必要がある場合にも成立する。思考不能や全ての実務判断の禁止にはしない。

`r44j` は同じ自由内容への負の要求であり、既存の規範関係 `h237z` を再利用する。規範源 `h253f` は、同じ委託元の職務に当たる者の責任を評価する枠組みを指す。現に教会が発令した命令や現代の法令とは区別し、参照だけから個別の禁止を導かない。自由が実際にないこと、自由が認められないこと、許可を見つけられないことは別の条件である。

発話の記述は個体列に入らないため、`r44g` が発話記述を別引数として受け、教会・本人・職務・主題の正確な四個体列と基準を `r4d` に結ぶ。`r44h` は既存の引用持上げ `o r` と引用適用 `o a` を使い、その発話だけを組み込んだ段階1の閉じた内容関数記述を作る。個体は実行時の四個体列から受け取るので、自由変数を引用へ捕捉したり、名前のない個体のコードを捏造したりしない。規範の対象となる関数は、要求時には実行されない。

`r44k` は現実の否定と同じ対象への負の要求の連言、`r44l` はそれを先行の会衆の前での私的使用・受託業務遂行・家内的な集会の性格へ接続した内容である。要求対象は教示内容を独立に決定する権限であり、教示の実行そのものを禁止する記述ではない。同じ本人の別の学識者としての立場へ広げない。

検査では、元の自由内容・列アダプター・構成した記述を脱引用した内容を同じ通常評価で比較する。発話記述の別名、個体列の順序と長さ、規範の出所・本人・職務・基準・極性を取り違えた場合も確認する。構成した内容の実評価には四個体の焦点化した領域を使い、会衆の大きな事例領域の全四組合せを繰り返さない。会衆への接続は先行定義を通常評価する。引用や要求の評価では、権限・発話内容を未知にしても実行を要求しないことを確認する。

全文では同じ職務上の全該当使用への一般化が必要であり、個別の発話についての条件だけで完成としない。also・二つのweil・in Ansehung dessen・auch・規模への譲歩の提示と著者帰属も残る。本文・確認文字数は据え置く。
