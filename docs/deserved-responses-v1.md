# 根拠に基づいて応答に値すると評価する

カントu0015の「称賛されるに値する」へ、対象者・応答の記述・根拠・評価基準を結ぶ構造を追加した。称賛の実行と、称賛に値するという評価は独立に扱う。前段の一般命題にも接続し、同じ人物について能力条件と応答への適合を並べられるようにした。

| 定義 | 内容 |
| --- | --- |
| `ro5` | 対象者について根拠内容が真で、同じ対象者・応答記述・根拠記述が非空の評価基準列をすべて満たす |
| `ro6` | `ro5`を対象者ごとの内容関数にする |
| `ro7` | 対象者について指定した評価内容を主張する発話を構成する |
| `roa` | 話者が非空の受け手群に、対象者についての同じ発話記述を提示する行為内容を構成する |
| `hzgb` | `roa`を既存の生起・提示者・伝達関係へ接続する |
| `hzgc` | 前段の条件を満たす同じ人物について、能力条件と応答への適合の両方を述べる一般命題を構成する |

応答の記述には話者・行為・対象者の三引数を使う。称賛する人と称賛される人を別に保持するためである。根拠の記述は対象者の一引数で評価する。応答の記述を評価基準へ渡すこと自体は、応答行為の実行ではない。対象者を話者へ入れ替えたり、同じ真理値を返す別の根拠・応答記述へ評価を移したりしない。

`ro5`の評価は、真の根拠内容と明示した基準を必要とする。空の基準列は適合の証拠にならず、基準が未知なら判定できない。この構成だけで道徳的な正当性を認定するわけではなく、どの基準がなぜ適切かという説明は別に必要である。特定話者の義務、積極的な許可、将来の実行は追加しない。指定した基準が内部で実行や規範を調べることは可能だが、共通の構造がそれらを強制することはない。

接続例では、前段の自由政策を実現したという内容を根拠に使う。称賛する発話の候補も、その人物について同じ内容を肯定的に取り上げる。これは肯定的な事実報告と称賛を完全に区別する定義ではない。敬意・感情・評価の強さ・皮肉などの説明と、肯定的な評価として扱う基準の確立は残る。原文の「最初の解放者として」という功績全体を、この政策内容で置き換えたとはしない。

`hzgc`は、同じ人物について「能力条件を満たす」と「応答に値する」の両方を結論にする。片方だけが真なら連言は成立しない。前段の地位・本人による発言の評価・名称拒否は同じ人物に固定し、一般命題からその人物の存在や実際の称賛を導かない。閉じた内容は既存`uc`で著者に帰属させ、帰属の確認だけなら根拠・能力・適合を実行評価しない。

応答適合の内容と一般命題を引用できるよう、既知の根拠記述への脱引用をそれぞれ一箇所ずつ静的に解消した。未知の記述を真偽の近さで代用する操作は使わない。[一般文書](../examples/v014/deserved-responses.noema)は852文字、[原文付き草案](../examples/v014/kant-deserved-responses.noema)は193,769文字、[抽出文書](../examples/v014/deserved-responses-core.noema)は8,836文字である。

六定義を追加し、原始記号と著者主張は増やしていない。親の宣言と15件の著者主張を保持した。[意味規約](../data/kant-deserved-responses-basis-v1.json)と[検査記録](../reports/deserved-responses-v1.json)を保存する。根拠・二基準・生起・提示者・伝達の64通りと、原文付き文書・抽出文書の十一条件ずつを検査した。追加16テストは、実行との独立性、空・未知の基準、根拠・応答記述の取り違え、対象者と話者、引用の非実行、能力との連言、著者帰属、原文範囲を対象とする。三文書のCLI解析、正規形と固有文字v2の往復、SVGのXML検査も通過した。SVGの目視確認は含めない。

原文の対応範囲は「値する」と「称賛される」の二箇所に限定する。間にある世界・後世という集団と時点、感謝、最初の解放者としての功績はまだ対応済みとしない。称賛と応答に値することの基礎概念、政府による解放、本文全体の意味確認も未完であり、今回の解釈注記を完成訳には数えない。
