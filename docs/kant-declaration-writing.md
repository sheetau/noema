# 円文字による宣言

## 接続前の計画と共通規則

不足しているのは、原始語と定義の宣言を文から区別し、宣言名・引数・本体の範囲を復元する規則である。既存の公開語の綴り、語境界、型列、外向き変数参照、式の結果型推論を使う。定義本体を確認用の全称式や等式に包む方法から、宣言そのものの書記へ進む。

- 原始語：primitive 頭、宣言名、引数型列、結果型。
- 定義：definition 頭、宣言名、引数型列、本体。

引数型列は従来の types_end で閉じる。本体は自己終端する式なので宣言終端を追加しない。定義の結果型は本体と依存語の型から復元する。生成前に native の型検査を行うため、本体と宣言の結果型が異なる入力は図形にしない。結果型の省略は任意の情報損失ではなく、正しい定義における重複の省略である。

宣言名は公開された語の綴りとして読み、関数呼出として引数を消費しない。頭・名前・型列には引数枝を付けない。本体の枝は既存の引数順で読む。定義の引数名は native の正規形と同じく順に割り当て、本体を読む前にその型とともに束縛環境へ入れる。本体内の束縛はその続き、引用は既存の独立範囲規則に従う。原始語の引数には変数名を導入しない。

primitive / definition 頭には大円の右上円周上に小円の中心を置き、東／西方向の半径線で区別する。旧生成器由来の合法な円・線構成を使い、偏心内包、近接、円周への入射等の制約を変えない。

参照先は宣言より先に利用可能な依存語とする。対象宣言そのものを依存語として読み込まず、直接・間接の自己依存を拒否する。読取側の対象本体・対象型を除いても同じ宣言を回収できることを確認する。期待する定義との一致は復号後の検査であり、復号規則には含めない。

## 範囲

公開語の綴りと依存語を利用する一宣言の規則である。語義の説明、綴りの公開、依存する複数宣言の文書内順序、文と宣言のページ配置をこれだけで完成扱いにしない。小さな原始語・定義の対照から、保存された実定義へ接続する。新しい意味判断は行わず、回収構文と語義・参照先の不変を確認した範囲で既存判断を保持する。
