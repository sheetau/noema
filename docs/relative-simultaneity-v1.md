# 同時性の基準系依存と一般化の範囲

アインシュタイン§2の `u0041` を部分記述した。前段の観測者による同期判断の対比から、「同時性に絶対的な意味を与えてはならない」という結論へ接続する。基準系を変えても同時性が保存されるという全称条件、その反例、全ての同時な出来事対が非同時になるという別の全称条件を区別した。

## 未付与と非同時を区別する

比較範囲 `sdx` は、異なる二出来事・異なる二基準系・共通の文脈を要求する。それぞれの出来事に、それぞれの基準系で時刻が付与されていなければ、同時かどうかを比較する範囲に含めない。時計の読みがないことを、違う時刻を持つことと取り違えない。

原文接続では、各基準系の静止局所時計と出来事が同じ場所にあり、共通参照時計に同期しているという既存の時刻付与条件 `saf` を使う。候補値の検査 `sei` と、一意性も要求する `seh` を分けた。`seh` は、その系で付与できる全ての値が候補値に一致することを要求する。同じ時刻を表す複数の時計・表現は許すが、矛盾する二時刻から都合のよい方を選ぶことは許さない。

## 反例の存在と全称条件

| 定義 | 内容 |
| --- | --- |
| `sea` | 範囲内の全ての有効な比較で同時性が保存される |
| `seb` | 第一系で同時、第二系で非同時となる例がある |
| `sec` | 同時性の真偽が異なる例がある。変化の向きは限定しない |
| `sed` | 範囲内の全ての有効な比較で、第一系で同時なら第二系で非同時となる |

`sec` は `sea` の否定に対応する。`seb` から `sed` は導けない。同時性が変わる出来事対と、同時性を保つ別の出来事対が、同じ比較設定にあってもよい。空の比較範囲では全称条件は空虚に真となるが、反例の存在は偽となる。これを非絶対性の証拠にはしない。

これらの一般定義は、範囲・利用可能性・判定関係を引数で受け取る。文ごとに専用の文法演算子を追加する方式ではない。

## 時刻変換による補助検査

原文の後段にある座標変換の時間成分を、次の条件として記述した。

```text
c²(変換後時刻 − 共通原点) = 共通尺度(c²時刻 − 速度 × 運動方向の位置)
```

`see` は c>0、速度²<c²、共通尺度≠0を要求する。`sef` は同じパラメータで二出来事を変換する。以前に保存した四座標変換式から、尺度をφβとした原点ゼロの `see` が導かれることも検査した。既存の式を別の変換式で置き換えてはいない。

第一系で同時な二出来事について、第二系でも同時となる条件は、このモデルでは「速度×運動方向の位置差=0」である。非零の相対速度だけでは非同時を保証しない。運動方向の位置が同じで、横方向だけが異なる場合などは、同時性が保存される。共通の時刻原点は二時刻の差から消えるが、出来事ごとに異なる原点を使ってよいわけではない。

この補助検査は有理数の式について行った。§2のこの箇所で著者が既に後段の変換式を証明したことにはせず、実切断全体の物理的な導出とも区別する。

## 原文へ接続した読み

原文の後半は全称的にも読めるが、条件を補わず「動く系では、どんな同時な二出来事も必ず非同時」とすると、上記の保存例を排除してしまう。今回の `seq` は、絶対性の否定、同時性が失われる例の存在、運動方向の位置差を持つ場合に制限した一般則を合わせる部分解釈とした。

位置差の限定は原文に明記されていない。そのため、補足した範囲を意味規約と検証記録へ明示し、同義性を確認済みの訳には数えない。「絶対的な意味を与えてはならない」という認識上の要請や、「そう捉える」という論述上の強さも未説明である。

著者が前段の判断からこの結論を提示することは既存の帰属関係 `zc`、否定側と肯定側の対比は `zbc` で記述した。これらは引用された内容を真にする操作ではない。棒の一例から一般の出来事へ至る推論、座標・基準系・測定の物理的な基礎、原刊画像との照合は引き続き残る。
