# GlossReaderの長さと共通方向を切り分けた結果

固定したGlossReaderの特徴量について、追加学習なしで比較方法を変えた。共通方向を1本取り除くと、既知概念の正解は日本語92→103/196、英語95→103/196になった。ただし既存MiniLMの133/196・146/196には届かず、対象を犬・猫・追う出来事に切り替えたときの取り違えも残った。主画面への接続は行わない。

## 比較したもの

[事前条件](gloss-geometry-v1-protocol.md)の4方式を固定し、[前回の実験](glossreader-v1-results.md)で保存した482範囲と91定義のベクトルを再利用した。入力と順序をハッシュ・注釈で検査し、元の内積による全予測が前回と完全一致することを確認した。エンコーダーの再実行、重みの更新、定義の変更、辞書による候補選別は行っていない。

対象の文脈をq、候補定義をg、定義集合の平均をmとする。内積q・gを対照に、単位長に揃えるコサイン、平均方向への射影を双方から引いてから計算するコサイン、定義から平均を引く内積q・(g−m)を比較した。平均方向は候補定義だけから求め、評価文や正解を使って調整しない。

平均を引くだけの内積は、候補によらないq・mを引く操作なので、実数演算では順位を変えない。今回も全482範囲の先頭候補が元の内積と一致した。float32の引き算順序による最大差は約0.00134で、スコア自体の完全一致を主張する対照ではない。

## 長さより共通方向が大きい

91定義のノルムは約30.4615〜30.4655で、差は非常に小さかった。定義どうし4,095対のコサインは平均0.997666、最小でも0.994069である。定義平均の方向への射影が持つ二乗ノルムの比率は、平均99.7692%だった。[診断値と全評価](../reports/gloss-geometry-v1/evaluation.json)

候補定義の表現はほぼ同じ方向へ集中している。ただし、残りの小さな成分にも情報はあり得るため、この数値だけで「意味を保持していない」とは判断しない。実際に正しい概念を選べるかを、次の比較で測った。

| 比較方法 | 日本語の概念正解 | 英語の概念正解 | 日英とも正解 |
| --- | ---: | ---: | ---: |
| 内積 | 92/196（46.94%） | 95/196（48.47%） | 87/196 |
| コサイン | 92/196（46.94%） | 96/196（48.98%） | 88/196 |
| 共通方向を除くコサイン | 103/196（52.55%） | 103/196（52.55%） | 95/196 |
| 平均を引くだけの内積 | 92/196（46.94%） | 95/196（48.47%） | 87/196 |

長さを揃えるだけではほぼ変化しない。共通方向を除いた場合は、内積に対して日本語15件が改善し4件が悪化、英語12件が改善し4件が悪化した。全体の正解数は増えたが、正解が一方的に増えたわけではない。

## 同じ文の対象を区別できるか

| 対象切替資料の指標 | 内積：日本語／英語 | 共通方向を除く：日本語／英語 |
| --- | ---: | ---: |
| 概念正解 | 10/17・9/17 | 10/17・12/17 |
| 異なる概念の対象対で先頭候補が変わる | 11/17・11/17 | 11/17・13/17 |
| 両対象とも正しい | 4/17・3/17 | 4/17・7/17 |
| 文内の既知対象が全て正しい | 2/6・2/6 | 1/6・3/6 |

英語では改善する一方、日本語の文内全対象正解は2文から1文へ減った。「朝の路地で、犬が猫を追いかけた。」では、犬・猫・追いかけたの全てに犬を選ぶ誤りが残った。対応する英語でも同じで、共通方向の除去だけで対象の意味を分離できたとは言えない。

未知例は各言語45件で、共通方向を除いた後も正解例とスコアが重なる。日本語の既知正解は約0.176〜0.465、未知は約0.138〜0.444。英語の既知正解は約0.200〜0.494、未知は約0.129〜0.467だった。拒否閾値は選ばず、意味の確定出力は0件とする。

## 検証と判断

全450テストが通過した。追加した4テストでは、手計算できる式、倍率・候補順序・バッチ分割への整合性、共通方向の除去、不正入力と退化した残差の拒否を確認した。数値誤差だけが残るベクトルを単位長へ拡大して方向として扱う処理は拒否する。

別プロセスで4方式それぞれ全482範囲のスコア、予測、評価を再計算し完全一致した。入力・コード・出力のハッシュを[実行記録](../reports/gloss-geometry-v1/run.json)、一致結果を[再現検査](../reports/gloss-geometry-v1/verification.json)へ保存した。これは保存特徴を使う検証であり、エンコーダー自体の検証は前回の記録を参照する。

```powershell
artifacts/kwja-venv/Scripts/python.exe -m scripts.probe_gloss_geometry
artifacts/kwja-venv/Scripts/python.exe -m scripts.probe_gloss_geometry --verify-only
```

前回の保存特徴と予測が必要で、既存結果は上書きしない。全資料が観察済みであり、正解範囲も与えている。今回の改善を独立評価や全文の意味構造精度として扱わない。

この条件では、長さと共通方向1本を補正しても、語をまたぐ概念選択の失敗は解消しなかった。共通方向除去は研究用の対照として残すが、これだけを根拠に採用試験へ進めない。次は、公開語義モデルの学習時の候補条件と、Noemaで必要な概念選択の条件の違いを調べる。語ごとの候補辞書を推論へ追加することはしない。
