# φの意味への問いと横棒の両端座標

u0097–u0100を、同じφの物理的意味への問い、軸区間を考察へ取り上げる行為、同じ棒の横方向運動と両端座標という三つの著者の提示として接続する。原刊902頁の保存画像・本文と固定原文を照合する。ここでφの決定が完了したことや、後続の長さの対称性は述べない。

ejcoは同じ正規化後φ=spcについて既存zhgで物理的意味を問う。nunは直前の相反積に続くこの議論段階への移行であり、物理系の時刻tではない。ejcpは同じ横棒をejckの指定区間として考察へ取り上げ、その設定を採用する。仮定採用ugは注意を対象へ向けることまで意味しないため、汎用関係eisnxを補った。これは対象・特徴の記述・論述範囲を引数に取り、軸・棒・速度・座標式を原始語へ埋め込まない。

指定区間はkのξ=ζ=0、0≤η≤lを全て占める理想化した線状棒である。ejclは前段で構成した同じ棒の全物質点履歴・静止・区間占有と、Kでの全点の速度vの並進、自軸への直交をejcfで保持する。原刊のHの印字をη軸の役割として読む。物質を切断する操作、任意の厚い棒の線への還元を追加しない。

ejcgは同じ棒・端・出来事の現在のK/k記録を、各系の測定と履歴にejceで接続する。ejchは指定K時刻にその記録対が存在すること、ejciは正の時間幅の全実数時刻で存在することを述べる。ejcjはそれに加えて全該当記録対に既存srwとsryを適用する。したがって、記録がないため空虚に通る全称や、一回だけの端点測定は一般式の代用にならない。K/kの時間区間と時刻値は各自の規約を使い、tとτを等置しない。

ejcmはη=l側の第一端、ejcnはη=0側の第二端の式である。Kの表示はそれぞれ(x₁,y₁,z₁)=(vt,l/φ(v),0)、(x₂,y₂,z₂)=(vt,0,0)。同じtの任意値について両端の記録が存在するので、同じK時刻の両端を選べる。添字を時間番号やlow/highの引数順に置き換えない。第一表示のMathMLは分数であり、平坦化したlφ(v)を積として読まない。srxの(lφ)/φ²は非零φに対する同じ商で、負値を絶対値に替えない。

ejcqは同じ棒の運動と二つの表示を著者の主張uhとして述べ、各表示を同じコロンの第一・第二項へeiskjで結ぶ。undは両項の連言と順序を保つ。この列挙と著者・論説への帰属は、数式内容の定義だけとは区別する。三つの伝達内容を315–317番の新しい主張へ接続し、既存315主張を保持する。

局所検査は符号の異なる非零φ、両端、三つの時刻でsrw/sryの本体を評価し、各空間値・時刻を変える。記録存在の三つの個体量化と全記録の三つの全称量化は二値域で各位置を区別して調べ、全実数時刻は本体の明示的例化と有限評価の拒否を確認する。現在測定と全物理履歴には先行証拠を使い、問い・注意・仮定・主張・引用・列挙・帰属の引数を対照する。これらの成功を全文の意味判断や一般物理的証明へ自動変換しない。
