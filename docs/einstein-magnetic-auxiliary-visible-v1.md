# 磁気側の類推と補助概念の円文字統合

対象は採用本文u0176の二文である。磁気側の類推、場の座標系依存性、補助概念の主節、第二文全体の提示を、既存の四主張から合成する。原文の文数を増やさず、固定アルファベットと共通375語を維持する。

公開する八関係は既存の意味規約と型を保持する。追加定義は既存の定義との本体・引数・結果型の一致を先に調べ、同一のものは再利用する。磁気側の静止基準H、負符号の外積、二次以上の留保、仮定上の単位点磁極、共動系の逆座標を保つ。補助概念では非空の全構成的使用を同じ残差へ展開し、主節と導入理由に同じ概念を束縛する。

本文位置は第79段落の二文とその語区間で指定する。主節は第二文の第1～16語、根拠節は第23～37語であり、主節が根拠節に先行する。第二文全体は主節を含むので、両者に前後関係を課さない。「Man sieht」の提示は第二文全体に係る。理論の参照は第6～7語に付けた役割の引用から取得し、参照取得時に物理的な主張を実行しない。

検査では復号した定義を原文側と照合してから有限モデルを適用する。物理的な本体と、証人の各束縛先を区別する診断を分ける。多変数の存在量化は他の証人を明示的に固定して一つずつ二値で変化させる。この診断を実数全域や関数空間の証明とはしない。未知入力の拒否と引用の非実行も確認する。
