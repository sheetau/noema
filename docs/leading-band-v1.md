# Leitbandの描写と判断の誘導

第四段落第五文後半の予測に、Leitbandの物理的な描写を接続する。対象は固定原文 `kant-1784:u0011[1102,1216)`。第五文全体の意味判断はまだ行わず、確認済み文字数を増やさない。

Adelungの[Leitband項目](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_7_1_1207)の本文を取得した。歩けるようになっていない子どもを導く幅広い帯を指す。[DudenのGängelband](https://www.duden.de/rechtschreibung/Gaengelband)も、歩行を学ぶ子どもを導き、保持する帯として説明する。この身体的描写を採用する。辞書の同義語を根拠に、二本という数、特定の結び方、材質や身分までは補わない。取得したAdelungのHTMLは `artifacts/leading-band-reading-v1/adelung-leitband.html` に原バイトで保存した。

`r2rs`は、製作された帯状物、その身体への接続、別の人による保持、張力による同じ歩行の制約を要求する。子ども・歩行・外部補助・訓練用途は既存の `zah/zai/zaj/zae` を使う。用途としての独立歩行 `zal` は引用し、既に独立歩行できるという結果にはしない。新しい基礎関係は形・接続・保持・張力の作用の四つであり、「Leitband」という一語に全文の意味を委ねない。

| 共有する位置 | 対象側 `r2rv` | 描写側 `r2rw` |
| --- | --- | --- |
| 第一位置 | 判断に使われる意見 | 幅広い帯 |
| 第二位置 | その意見を未吟味のまま使う本人 | 帯で導かれる子ども |
| 第三位置 | 同じ本人の判断行為 | 同じ子どもの歩行 |
| 内容評価点 | 意見を判断の理由に用いる時点 | 身体移動を制約する時点 |

対象側は既存 `r2rc` をそのまま使う。意見の単なる保有や、判断と無関係の吟味の欠如では足りない。描写側の保持者は対象側の役割に追加しないため、偏見を操作する特定の人物の存在を現実の主張に補わない。

範囲 `r2rt/r2ru` は予測 `r2rn` と同じ公衆・大衆・革命候補・旧新の意見群へ結ぶ。旧意見は候補の起点、新意見は同じ有効時間枠の後続点に置く。対象側の成功を条件に参照を選別せず、関係の成立、複数性、内容差、大衆への広がりは既存の予測内容に保つ。新旧で同一人物が導かれることや、同一判断行為が時を越えて続くことは要求しない。

`r2rx`は、同じ箇所・著者・予測・文脈について、範囲と両側の三位置の関係を閉じた段階3の記述で `h224n` に渡す。帰属から、意見が実際に物理的な帯であることも、公衆が実際に子どもであることも導かれない。既存の予測・語調・本文順序 `r2rq` と合わせた `r2ry` で、未レビューの文62を置き換える。先頭62文と既存の全定義は変更しない。

検査では物理的関係を実評価し、接続・保持・力の作用の欠落、別の帯・身体・行為・時点を区別する。参照範囲の検査では革命分類と時間枠を既存検査済みの境界とし、新旧の意見・大衆・候補への引数接続を調べる。三位置の検査は個別関係を境界として役割と時点の共有を調べ、引用の検査では全ての世界内容を未知のままにする。巨大な全称量化を重ねた全組合せの実評価ではなく、この境界を明示した組合せで検証する。

残るのは `vielleicht wohl` の留保と譲歩、`aber/sondern` の対比、既存 `niemals` の否定範囲を含む第五文の通読、および第四段落全体の判断である。
