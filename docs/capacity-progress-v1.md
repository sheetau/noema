# 自立的な使用能力と進歩の候補尺度

介入比較に渡していた進歩の数値尺度を、既存の自立的な使用能力 `h4l` へ接続した。固定した集団について、共通の開始時点から各介入結果までに能力を持つ人数が何人増減したかを数える。任意の外部評価点を「進歩」と呼ぶ方式から、数える性質と評価条件をNoemaで示す形に進めた。人数の純増を、カントの啓蒙の全意味と同一視したわけではない。

`h4l` は、能力評価の範囲が整合する `fo` と、他者の指導なしで自分の理解力を使う達成方法を持つ `up` を組み合わせた既存定義である。単なる未成熟の否定ではない。今回もこれらを基本記号へ置き換えず、使用・所有・指導・方法・結果の関係まで実行して検査した。

比較には、同じ対象者の列、独立に指定した対象範囲、同じ開始時点を渡す。対象範囲が非空で、全て人であり、列に過不足や重複がないことを要求する。制限あり・なしの双方の全結果について、終点が開始時点より後であり、全対象の能力評価が前後とも整合することを確認する。未評価の人を能力なしとして数えない。

| 定義 | 内容 |
| --- | --- |
| `rei` | 同じ対象列の性質該当人数の、後から前を引いた純増 |
| `rej` | 全対象の列挙、前後の評価条件、時間順序の確認 |
| `rel` | 共通始点から、各介入に対応する終点までの純増を返す関数 |
| `rek` | 両側の全結果で評価条件が整い、純増尺度の相対的な低下が許容範囲内である |
| `hzg` | 評価条件を `fo`、数える性質を `h4l`、対象を人へ固定した比較 |
| `hzh` | 同じ集団の `h4l` 該当人数の純増を返す数値関数 |
| `hzi` | 同じ政策が実現し、政策と介入が対応し、人数尺度での比較条件も満たす内容 |

たとえば、開始時点では二人とも能力を持たず、制限あり側で一人、なし側で二人が能力を持つなら、純増はそれぞれ1人と2人になる。最初から一人が能力を持つ場合の純増は0人と1人、最初から二人とも持つ場合は−1人と0人になる。相対的な差はいずれも1人だが、実際の進歩・停滞・後退は異なる。共通始点を保存することで、この違いを隠さない。

評価した結果として方法がない場合と、方法の評価対象を設定できていない場合も区別する。前者は既存の評価条件の下で能力なしと扱えるが、後者は集団全体の比較を確定させない。指導付きの使用ができるだけの場合も、指導なしの使用能力へ置き換えない。

`hzi` では、評価する文脈が同じモデルの制限あり側の解に対応する終点であることも要求する。単に別の場所・時点で政策が成立したことを借りない。`hzi` 全体は既存の型付き記述として許可対象にでき、その許可だけを述べるときは人数や能力を実行評価しない。

この人数尺度には限界がある。ある人が能力を得て別の人が失った場合、純増0という一つの値だけでは両者を区別できない。個人別の変化は元の性質で記述できるが、この集計値だけから、全員への悪影響が小さいとは結論しない。また、能力を得る原因、未成熟から離脱する過程、自分の精神への働きかけが実際に起きたことも、前後の人数差だけでは示せない。能力の程度、知識内容、制度の変化を含む啓蒙一般への妥当性も残る。

`rei`・`rel`・`hzh` は生の数値を返す。これらを評価条件の確認なしで、確認済みの進歩の値として用いない。独立した対象範囲の正当性、時間の比較可能性、方法と結果の採用基準、方程式と現実の因果過程の対応は、形式的な全列挙だけでは保証できない。

一般文書は [capacity-progress.noema](../examples/v014/capacity-progress.noema)、原文への接続は [kant-capacity-progress.noema](../examples/v014/kant-capacity-progress.noema)。新しい基本概念や構文を加えず、既存の宣言と15件の主張を保持した。原文の許容基準と対象範囲、規範の作用範囲、啓蒙の全意味との一致は未完である。
