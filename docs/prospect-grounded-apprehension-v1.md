# 恐れる候補ごとに根拠を結ぶ

第十段落第一文の「影を恐れない」は、根拠のない不利益予期の不在として記述を進める。原刊493頁に第一文全体が収まり、494頁には段落末尾が続くことを画像で確認した。[照合記録](../data/tenth-paragraph-source-reading-v1.json)は固定本文を変更せず、頁境界、AA版、語義の補助資料を分けて保存する。

以前の `rvy` では、一つの不快な心理状態に複数の不利益予期があるとき、その一つに支持理由があれば状態全体が除外された。例えば、同じ対象について、根拠のある小さな損失と根拠のない破局をともに恐れても、後者を検出しない。今回は、恐れの対象として予期している不利益候補を一つずつ検査する。旧定義の誤実装を修正するのではなく、採用する読みを明確にして強い条件を追加した。

`r6en` は同じ本人が利用できる理由による、同じ対象記述・候補への支持を構成する。`r6eo` は支持を欠く不利益候補、`r6ep` はそれを含む同じ本人の不快な心理状態、`r6eq` はそのような状態の存在を表す。状態の経験・対象・不快さは既存 `rvv` をそのまま使用する。`r6er` は全対象記述についてその存在を否定する。`r6es/et` は七つの基礎関係と固定した評価基準を接続する。

根拠のある恐れは許される。支持された害が実際には起きないことも、支持なく恐れた害が起きることもある。支持は当該候補を恐れの対象として見込む十分な認識的根拠とし、本人が検討できる反対証拠も考慮する。感情の発生原因、確信、現実の害を根拠の代用にしない。恐れの強さの適切さや生涯の性格までは述べない。

検査は、支持された候補と支持されない候補の混在、別状態・別人・別対象・別時点・別評価基準・別候補の理由の流用、未知入力の拒否を調べる。全対象記述への量化は保存し、二つの記述への本体適用を有限の診断例として使う。全域を列挙できない実行器による直接評価は拒否する。対象記述を実行しない引用も確認する。
