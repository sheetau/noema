# 第四節の物理的意味という主題

u0109は、第三節末に得た方程式の物理的意味を、動く剛体と動く時計について扱う第四節の見出しである。ejeuは現在のK/k記録範囲と最終四式ssnを結び、ejevはその方程式と二種類の対象を既存zhrの主題提示へ渡す。ejewは第一部に属する深さ2・表示番号4の第四節を案内し、直前のβの指定からの順序を保つ。

動く剛体ejesは、同伴側kの尺度と同時性での全物質点の剛性eigyと、Kでの全物質点履歴に基づく運動eiagを結ぶ。球の形状や特定の収縮率は見出しへ加えない。動く時計ejetは、時計の型と代表配置の完全な履歴ejerを用いる。針だけが動く静置時計と時計自体の移動を区別し、内部の全物質点を凍結しない。

ejerは任意の指定対象・系・単位・区間と三位置関数を取り、完全なse履歴の下で、区間内の前後する二時刻に少なくとも一成分の位置差があることを記述する。区間の途中で動いて元へ戻る場合も含む。全実数の存在量化を有限標本へ替えず、検査では局所の証人と引数の接続を分けて確認する。

原刊903頁の見出しと後続の球の設定を視認した。球に付く注は原刊の著者脚注であり、固定原文u0281の「静止して調べると球形を持つ物体」という説明に対応する。u0110–u0111とその脚注は次の意味群で接続する。見出しを記述したことから、後続の球・収縮・時計遅れまで完成したとは判断しない。
