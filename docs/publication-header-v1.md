# 誌名・年・号数と月・記事番号

原刊481頁の冒頭四単位を、刊行物の表示情報として記述した。対象は誌名、1784年、年内の第12号と12月、記事番号1である。原刊画像で配置と文字を確認し、脚注中で紹介される9月号と、この論説が掲載される12月号を別の参照にした。

誌名の名称と刊行系列、論説、暦、1784年の期間には既存の参照を使う。新しい号と12月の期間をその系列・年へ結ぶ。署名の日付行が9月30日であることと、掲載号に12月と表示されることは矛盾しない。表示年月から実際の刊行日・執筆完了日・閲読日を補わない。

名称の識別表記には、脚注中の活用形`Berlinischen Monatsschrift`を残し、見出しの形`Berlinische Monatsschrift`を同じ名称`hzkh`へ追加する。別の名称個体や刊行系列を作らず、両方の綴りを検索できるようにする。綴りの一致から人物や文献の同一性を自動推定する規則は追加しない。

号数と月番号はいずれも12だが、異なる関係で記述する。月番号には既存の暦の割当を使い、号数と記事番号には新しい表示番号の関係`hzmi`を使う。番号付けの規約、対象、親参照の経路、数値、文脈を明示する。第12号の親経路は同じ刊行系列と年期間、第1記事の親経路は同じ号である。月、巻内の号数、記事番号、頁番号、PDFの画像番号を混同しない。

一般定義`rqso`は、指定項目への番号割当と、同じ規約・親経路・番号・文脈での一意性を要求する。別規約や別の号にある同じ番号は重複と見なさない。印刷された順序番号としての読みを採用し、実際にその前に何冊刊行されたかを数える条件にはしない。欠落した巻号や後世の合本の配列を、表示された番号の意味へ混ぜない。

| 定義 | 原文単位 | 記述する表示 |
| --- | --- | --- |
| `hzml` | u0001 | 同じ号の刊行系列を誌名で示す |
| `hzmm` | u0002 | 同じ暦の1784年を号の表示年へ結ぶ |
| `hzmn` | u0003 | 同じ年の第12号と12月を別々に示す |
| `hzmo` | u0004 | 現在の論説の掲載先と、その号内での記事番号1 |

24対照で、誌名、系列、9月号と12月号、年、月、号数、記事番号、番号規約、親経路、重複を取り違える場合を検査する。番号割当と同一規約内の重複、別規約・別の親にある同番号の16組合せも調べる。既存の脚注九文と新しい四文の同時検査では、表示年や号数を変えても脚注側の意味を変えず、対応する前付の文だけが不成立になる。未知の年・月・番号は補わない。構文解析結果を再利用するが、意味評価のメモ化や短絡変換は使わない。

四単位の全体判断は、[前付の意味確認](publication-header-review-v1.md)に別途記録する。有限テストの成功だけを全体の意味一致とせず、原文・表示の役割・意味規約・参照・追加と省略を確認する。この確認は表題の問いや本文の完成を意味しない。同頁の1783年12月516頁への参照指示u0007は、引き続き記述が必要である。
