# 尊厳の地位と公的な扱い

u0017の `seiner Würde gemäß zu behandeln` を、同じ人に肯定的かつ価値上代替できない地位があり、政府の公的処遇がその価値を独立の拘束理由として守ること、と読む。政府がその扱いを自らに有益と判断する内容は、この扱いの内容を作った後で別に接続する。

`r6lg` は、人であること、固定した規範的評価で肯定的な価値を持つこと、他の対象によって本人への配慮を価値上等価に置換できないことを結ぶ。代替否定は全ての別対象に量化する。人々が等しく尊重されることと、一人への尊重を他人や利益で埋め合わせられることは異なる。職員の交代、財産の売買、補助具の利用をこの代替関係そのものとはしない。

規範的な価値と代替関係は、公開した解釈の入力である。それらを行動データや有限例から証明したとはしない。後年の『道徳形而上学の基礎づけ』の[AA IV 434](https://www.korpora.org/kant/aa04/434.html)と[435](https://www.korpora.org/kant/aa04/435.html)では、価格と内的価値、等価物による代替、利益とは区別された価値が論じられる。HTMLと転記を比較資料として保存した。1784年の唯一の語義へ遡及させず、後年の自律や普遍的立法の体系全体を追加しない。

`r6lh` は、同じ人を対象とする政府の実際の公的処遇を取り出す。同じ生起活動に、人間の行為者がその政府の公的資格で参加することを既存 `r5zk` で確認する。単なる職員の私的行為や、別対象への活動は含めない。

`r6li` は、その同じ活動・対象・基準・点について評価が整い、対象の価値が他の目的の手段であることとは独立の拘束理由として、行為の選択と実施に現に反映され、別対象での等価な埋合せとして放棄されていないことを要求する。口先の承認や偶然生じた利益だけでは足りない。対象を手段にも用いることは排除しない。

`r6lj` と `r6lk` は、この地位と扱いを同じ全人間成員・全公的処遇へ結ぶ。能力がある者だけを選ばず、ある適合活動で別の不適合活動を隠さない。一般方針なので、その点に処遇の実例がなければ行為部分は条件的に充足し得る。実際の処遇があったことと、一般方針に反する処遇がないことを混同しない。

`r6ll` は具体的な一般方針、`r6lm` はその閉じた記述である。外側の引数列が空であることを検査し、名前を照合した同じ政府・共同体・基準を固定する。`r6lo` で前回の規則内容入力 `h27dc` をこの記述そのものへ結ぶ。`r6lp` の採用と `r6lq` の採用かつ履行は分ける。同じ真偽になる別名の記述へ規範を移さない。

公的な発言の許可だけを尊厳全体とする読みや、未記述の基準の一覧は採らなかった。今回は価値上の非代替性と実際の公的処遇での独立した配慮を本体にした解釈である。個別の権利や特定の法令は補っていない。政府自身の利益判断、原則への因果作用、時間・強調・条件文全体・著者注・全文帰属はなお未完で、局所検査を全文の意味確認へ加算しない。
