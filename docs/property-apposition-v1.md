# 性質記述を指す同格

カント第17区間の、芽の名詞句と「すなわち」で導かれる傾向・使命の句を、同じ性質の組を指す説明的同格として接続した。原文は芽を述べた後、自由な思考へのHangとBerufを挙げる。ここでは比喩の対象側の参照を明示し、人物そのものを芽と同一視しない。[AA VIII, 41頁33–34行](https://www.korpora.org/Kant/aa08/041.html)

一般定義 `ryt` は、二つの異なる箇所が同じ著者・範囲・発話文脈で同じ性質記述を指すこと、本文順序が正向きで逆向きでないこと、後の箇所が前を説明することを要求する。単なる繰り返しや前後関係だけから説明行為を推定しない。指示対象の型は階数1の性質記述であり、個人の識別子を渡すと型検査で拒否する。内容が同じ別名の記述も、参照先として自動的には同一視しない。

`ibbbundle` は、既存の `iahmanifest` を使い、同じ人・時点・読解における傾向と使命の二性質を連言する。`ibbinner` は使命を内的な衝動として読む組、`ibbvocation` は課題の付与として読む組である。発展の定義 `iahinner` / `iahvocation` と同じ性質条件を共有するため、別の定義で説明句だけを満たすことはできない。

性質の組が現在成立することと、潜在していた性質が発展したことは別である。前者には発展過程や初期の潜在性を加えず、後者には従来の過程・前後・潜在性の条件を残す。検査では、組が成立していても発展条件は成立しない例を確認する。他人に付与された課題や別時点の付与で、本人の第二性質を補う例も通さない。

`ibbapposition` は選ばれた発展の読解と同じ読みの組を二つの名詞句へ結ぶ。新しい `ibbfamily` は従来の成長描写と覆いの参照を保持し、同格を追加する。旧定義と先行21主張は保存し、最終帰属から新しい同格へ参照が届くことを本文点検v7で調べる。名詞句が性質記述を指すだけでは、その性質を誰かが実際に持つことも、植物個体の存在も断言しない。

今回の検査は性質の組、既存の発展条件、改訂した描写の提示と同格を対象とする。以前の因果・利益判断モデル全体は再評価していない。名詞化の分析、Berufの二候補の選定、芽の生物学的内容・起源、自然との関係、原文の意味一致は未完である。AdelungのKeim見出しは取得できなかったため、その語義を確認済みとは扱わない。八引数の部分ひな形と未達項目を残し、原文範囲の集計は増やさない。
