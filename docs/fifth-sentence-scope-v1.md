# 第五文の人数と譲歩の範囲

第三段落第五文の既存草案には、自己活動による自立達成、知的活動との時間的接続、少数者数、数量焦点の排除、歩行との比喩対応がある。今回、その結論の帰属15番を更新し、人数の前景と「それでも」の背景を分けた。第五文の通し確認はまだ完了していない。

## 採用した範囲の読み

`giebt es nur Wenige` は、一人以上の成功者がいて、同じ母集団における人数が文脈上の上限未満である読みを採る。既存の `h5w` は数量代替の排除も含む。具体的な人数、上限、母集団を原文に補わない。比較条件は人数についての条件であり、予想される世界とは別の入力である。

`dennoch` は実際の該当者に分配する譲歩背景とする。本人の自立を認める通常予想では、その人が確かな知的活動も達成するとは予想されない、という既存の `ja` による読みである。予想候補は非空で、全候補について前提成立と帰結不成立を要求する。確率の大小を表す構成ではない。

旧 `h5x` は人数と譲歩を一つの内容にしたため、その内容の否定は「少数者数の否定」と「譲歩背景の否定」を区別できなかった。新しい前景 `r2jd` と背景 `r2je` は既存の内容対に収め、否定は前景だけへ適用できる。両方が成立する場合の旧内容との関係も、境界入力を明示した検査で確認する。

背景側にも全母集団の正確な列挙と評価条件を残す。成功者だけの標本を選んで背景を満たすことはできない。一方、成功者がゼロの場合や少数と言えない場合でも、背景が成立することはある。これは人数を前景側だけで評価することの帰結であり、その状況で元の文全体が成立するという判断ではない。

`Daher` は直前の第四文の主節と理由を直接の根拠とする読みを保持する。同じ箇所は現行本文の第四文でも参照されている。著者が根拠から結論を提示したという記述であり、条件付きの描写から現実の少数者数を論理的に証明するものではない。段落先頭まで直接の根拠集合に含める別の読みとは区別する。

[AA VIII036](https://korpora.org/Kant/aa08/036.html)の第五文と前後を再読した。保存済み原文の綴りを保持する。新しい `h222d` は文末の譲歩節の位置を指す定数であり、新しい意味演算子ではない。

## 検査の範囲

実際の人数・数量焦点・予想比較・内容対の定義を実行する。自己活動の長い履歴と能力評価の内部は、既存の検証済み定義を保持した上で、今回の局所検査では境界入力にする。未知を偽へ変換することは認めない。

人数を変えずに予想だけを変える条件、成功者ゼロ、上限到達、不完全な母集団、重複、非該当者の評価不足、既知の該当者の別履歴の評価不足を区別する。帰属検査では著者、引用内容、前景と背景の範囲、推論の根拠集合、本文順序を取り違える条件を拒否する。引用内容は実行せず、任意長の有限列への量化も有限候補へ置き換えない。

既存の全宣言と意味規約、他の53主張、十二全単位の判断、第三段落の先頭四文544非空白文字の判断を保持する。
