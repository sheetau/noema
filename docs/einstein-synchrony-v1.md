# 二地点の時計から同期・共通時刻への可視接続

Einstein 正本の主張70–80、原文 u0013–u0018 を、先行する時刻の説明と同じ円文字文書へ接続する。原文の十一の主張を構成する251宣言を旧正本と照合し、既存の377宣言・16主張を保持する。

## 接続する内容

点Aの時計と観測者による局所的な時刻の評価から始め、点Bにも同じ構成の別時計を置く場合へ進む。「同じ構成」は完全な共通規約での特徴の一致を要求する。現在の指示値、初期位相、時計の個体同一性まで一致するとは読まない。二つの追加表現と、同じ構成を条件に加える意思の挿入も残す。

前二文までに定義したものは局所的なA時間とB時間だけであり、追加規定なしには二地点の出来事を時間的に比較できない。ここでの未定義は論述段階に限定される。第四文はその先へ進み、光が両方向へ進む所要時間を等しいと定めることによって、共通時間を定義できると述べる。後の規定を先の段階へ遡って成立させない。

続く光往復の設定では、一つの試行に同じ光、出発・反射・帰着の三出来事、A・B・Aでの三読みを結ぶ。第五文の想定と、第六文の同期の定義を分ける。第六文は本文末の条件節から別行の式 M0030 までを含む一文である。式を独立した本文の第七文として数えない。必要な全関連試行で満たす条件を残し、一回の数値一致だけで時計全体が同期しているとはしない。

無矛盾性の仮定は、上限を設けない有限点列について、一つの配置と各時計の一つの履歴を共有して同期条件を実現できるという内容を持つ。時計対や試行ごとに都合のよい配置や値を選び直さない。続く二法則は一般関係とA/B/Cによる代表的な条件形を結び、列挙の番号と順序を保つ。この二法則だけで任意個数への物理的実現可能性を代用しない。

最後の二文は、それまでの思考上の物理的経験を用いた考察を振り返り、出来事の時刻と同時性の定義へ結ぶ。同じ静止参照時計への同期、同じ場所の時計表示、出来事との局所的一致、指示値の数値的一致を維持する。明白であるという著者の提示や、規則を定義として採用する行為を、検査器による物理的証明へ替えない。

## 参照と語彙

既存の前方参照 `eish2` と `rj` を、そのまま u0013 冒頭と u0018 第二文へ接続する。A/B/Cの点、時計、観測者、指針、課題、局所規約などは、文書・導入箇所・閉じた役割記述・文脈によって参照する。役割は本文内の17定義に示す。同じ「点」の役割でも導入箇所が異なるため、参照先を取り違えない。参照の取得から、役割の現実的成立や対象の世界唯一性は導かない。

三出来事・光・三読みは、既存の光往復記録の成分取得へ結ぶ。新しい参照基本語は、指定した箇所までの論述段階を取得する一語だけである。第二文までと第四文までの段階を区別し、物理的な時刻へ置き換えない。A-Zeit と B-Zeit の綴り注記は呼称の識別に使い、時間規約の意味は別の定義で表す。
