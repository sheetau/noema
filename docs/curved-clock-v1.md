# 曲線への拡張仮定と帰還時計

アインシュタイン§4の `u0128` の前半を、直前の折れ線の結果へ接続した。曲線の位置・速度・時計の観測を結ぶ設定と、折れ線と同じ遅れの式が曲線でも成立するという仮定を分離する。原文の地球上の時計の比較は、今回の接続範囲に含めない。

曲線のモデル `sxv` には、端点の記録で定まる正の時間区間と、連続した三座標・三速度成分を与える。各座標の微分が対応する速度成分に等しく、三成分の平方和が共通の正の速さの平方に等しいことを要求する。向きが変わっても速さは同じであり、速さは光速度未満である。

連続性は既存の実数切断の定義を再利用した。全ての正の精度に対して近傍を選び、その範囲内の全入力で条件を満たすことを要求する。原文の曲がり方を、時間区間上で連続な導関数を持つC1の座標関数として読む。両端では片側の微分条件となり、同じ経路を繰り返し周回する際の速度の周期性までは課していない。この滑らかさの指定は、採用したモデルの解釈として明示する。

`sxw` は、その時計の出来事・測定された記録・指示を、出来事から記録と指示を得る関数へ結ぶ。候補記録と実際の記録は四成分の値で比較し、三位置がその記録時刻における曲線の値と一致することを要求する。別の記録を対応させたり、同じ出来事に矛盾する座標を追加したりすると条件を満たさない。

`sxx` は測定済みの出来事を検査する部分条件である。全時間にわたる対応 `sxy` は、それに加えて区間内の全実時刻に時計の出来事と記録が存在し、その出来事の全ての有効な指示が同じ候補指示に一致することを要求する。中間の測定が欠けていても、有限の標本だけからその時刻の存在を補わない。

設定 `sya` には曲線と観測の対応、出発と帰着の異なる出来事、初期の同期・指示一致、比較時計の残留、秒への換算尺度を含める。前段の折れ線で使った端点比較を再利用するが、ここには全区間の指示の進み率や到着時の遅れの式を入れていない。曲線に合う観測があることから、時計の遅れまで定義上成立させないためである。

原文の拡張仮定と帰結は、次の関係として保存した。

```text
P = 前段の折れ線の結果 sxq
C = 曲線の設定に対して同じ到着差・近似留保が成立する内容 syg

拡張仮定 syb: P → C
推論の前提 sye: P かつ (P → C)
帰還の帰結 syd: Cの設定を、同じ位置へ戻る場合に限定した内容
```

`syb` は先行結果の内容 `sxq` を条件部に使う。以前の草案にあった、先行箇所の参照名だけでは本文の内容へ接続できていない状態を改めた。著者がその先行結果を証明済みとして扱うことは、既存の談話関係 `ui` で表す。これは検査器が物理法則を証明したという記録ではない。

仮定の採用、閉曲線の帰結、その推論前提への参照は、同じ推論範囲に置く。引用した内容を評価して真と認定する処理は行わない。Pが真でCが偽なら拡張仮定は偽だが、著者がその仮定を採用したという帰属は成立し得る。この区別を四つの真偽の組合せで確認した。

帰還は正の時間の後に同じ三位置座標へ戻る条件である。到着指示差は前段の厳密値と二次近似・四次残差の留保を引き継ぐ。全所要時間を固定する評価と、速度を変えると所要時間も変わる評価を混同しない。曲線への適用そのものは仮定として明示し、幾何学的な滑らかさだけから加速中の時計の挙動を導いたとはしない。

検証は、位置・記録・指示の結合14例、速さの大きさ8例、有理数へ特殊化した連続性7件、仮定と真偽の分離4例、帰属11例を含む。閉じた多項式曲線の有限点は観測との結合だけに使い、その曲線が一定速度であるとはしていない。全時間の対応、C1条件、全設定と近似の量化は有限評価器が拒否することを確認した。有限標本の合格を、曲線全体や拡張法則の成立と扱わない。

新規8件を含む関連28テストを確認した。初回に検査用の命題内容の型が不正だった1件を修正し、残り27件の通過後にその1件を再実行して通過した。保存する検証報告も修正後の検査器で再構築した。標準・圧縮表記・固有文字の往復、CLIのJSONと構文木の一致、SVGのXMLとしての妥当性を確認した。SVGの目視確認と全テストの再実行は含めない。
