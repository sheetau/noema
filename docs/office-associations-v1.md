# 職務の内容で記述する団体

カントu0013の聖職者の団体へ、所属と各構成員の職務内容を組み合わせた部分草案を追加した。「聖職者の団体」という未説明の名詞記号を一つ置く方法にはしていない。人・委任・組織への奉仕・活動の記述を使って条件を組み立てる。ただし、聖職や教会制度の意味全体を記述し終えたものではない。

| 定義 | 内容 |
| --- | --- |
| `rir` | 同じ文脈の団体に、団体自身とは異なる人が二人以上所属する |
| `ris` | 人が同じ組織の同じ職務を委ねられ、その職務で奉仕し、組織がその職務の仕事として指定活動を位置付ける |
| `rit` | `rir`の全構成員について、指定活動を仕事とする`ris`の組織と職務がある |
| `riu` | 団体への所属関係を、そのまま人と文脈から構成員判定への関数にする |
| `hzcx` | `rit`を既存の人・職務の委任へ接続する |
| `hzcy` | 対象活動を、宗教的な生き方や安寧についての判断`so`へ固定する |
| `hzcz` | 同じ団体の構成員を、目的付き・厳粛な相互引受けの当事者として渡す |

団体と、各人が職務を担う組織は別の引数である。二人がそれぞれ別の組織に職務を持つ場合でも、一つの団体に所属できる。全員の任用元を同じ教会としたり、その教会を団体自身と同一視したりする条件は追加していない。同じ組織に属する場合も表せる。

職務の委任、奉仕する組織、職務内容の指定は、同じ人・職務・組織・文脈で結ぶ。ある役職を委ねられた記録と、別の役職で宗教的な仕事をする記録を混ぜても条件を満たさない。一つの役職が条件を満たさなくても、別の整合した組織・役職の組があれば、その組を使える。

職務の仕事は型付きの閉じた活動記述で指定する。その仕事を現に実行したこと、成功したこと、教義が真であること、本人が信じていることは要求しない。原文の問いの対象を記述する段階で、実際の教示や契約が起きたという主張を加えない。

`hzcy`は、既存の`so`を使った宗教上の指導職への候補である。礼拝・祭儀・教示・叙任や聖職者の全ての機能を、この活動一つで尽くすとはしない。組織が活動を職務内容として指定する関係にも、制度・任用・慣習を認定する仕組みの説明が残る。新しい原始記号を増やさないことと、入力関係の意味説明を全て終えることは別である。

同じ構成は他の仕事にも使える。検査では、職務の活動記述だけを`so`から、身体の健康に関する判断`sq`へ変えた。前者を指定する職務は宗教側に、後者を指定する職務は健康側に対応し、別の仕事へ自動的に分類されない。団体や職務の構文・演算子を追加する必要はない。これは別分野への再利用例であり、医師の資格制度や医療専門職の全意味を定義した例ではない。

相互引受けには、別の当事者名簿を受け取らず、`riu`で同じ所属関係を渡す。団体に追加の適格な構成員がいるのに、その人を約束の当事者から落とすことはできない。基準文脈の構成員を固定し、過去の各人の宣誓時点で当事者範囲を選び直さない。団体の構成員全員による引受けと、団体の法人としての行為や代表権は別である。

検査では、人・委任・奉仕・職務内容の指定の16通りを調べた。空の団体、一人だけの団体、団体自身の成員化、別団体、未委任の構成員、役職・組織・時点・活動記述の混同、代替職務など14対照例も確認した。原文側では13例を使い、追加の構成員、過去と現在の構成員範囲、団体外の目的主体が引受けへどう影響するかを検査した。

所属と資格の関係が未知なら、空集合や不成立として穴埋めしない。二人以上という条件は、この複数人が現に所属する団体の候補に対する条件である。一人になった組織や無人期間の組織が存続できないという一般的な定義にはしていない。
