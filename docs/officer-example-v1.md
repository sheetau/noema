# 将校の例示と服従要求

固定原文 `kant-1784:u0012[2123,2331)` の一文を、先行する職務内の制約の例示として構成する。既存の将校・上官・命令の束縛と、同じ命令の目的適合性または有用性について勤務中に声に出して論じようとする意向を使う。

`r32x` は、その議論を実行した場合としなかった場合を同じ背景で比較する。同じ事務の遂行が全比較対で低下し、その差が文脈上高い程度に達することを `r32w` で要求する。意向の存在だけを被害にせず、仮定の実行や結果を現実の出来事へ移さない。ここでは頑健な全解比較を採用し、確率的な通常性や全面的破壊とは読まない。

`r32y` は一つの指示への服従を、同じ出所・本人・職務・対象行為・極性の要求、内容への対応、指示に従った遂行の調整として構成する。`r322` はその内容への規範的要求であり、引用した服従内容を実行しない。否定命令でも、服従を求める側の極性は正である。全職務要求を扱う先行 `r3i` の網羅条件はそのまま残す。

一文全体の `r324` では、同じ命令事例への服従要求を議論の意向条件から独立させる。上官による指示の提示から規範的正当性を導かず、後半の「従わねばならない」を別の規範内容として記述する。`r325` は文全体を著者と提示文脈に帰属し、先行する職務内の制約の具体例として結ぶ。

解釈の全条件は意味規約の `limitations` と文単位の読みの記録に置く。検査では因果比較・同じ対象の束縛・命令の極性・服従の非事実性を個別に実評価し、全文の量化接続には明示した型付き境界を使う。原文との意味判断と検査成功は区別する。
