# 全断面の電流分布

前回の一断面の電流履歴を、同じ物体に付随する全有向断面の関数族へ拡張する。ここで「全」は、採るマクロ尺度と幾何学的適用範囲における全断面を意味する。その範囲は電流の比較結果を見る前に固定する。端子の一箇所や測定した場所だけを選び、導体全体の一致と呼ぶことはできない。

eirjは、その物体・文脈の全断面と向きの組への物理的な所属入力である。eibeはsectionsをこの入力と双方向に一致させ、空でないことを要求する。未知の範囲を空として補わない。同じ断面という識別は同じ物質部分に付随する断面を指し、同じ向きという識別は同じ物質的側を正とする。二場合で位置や姿勢が変わっても、この対応を付け替えない。

eibfは全ての組に、既存eibaの電荷通過と電流履歴を結ぶ。累積量と電流は断面・向きごとの関数族として受け、同じ組から選ぶ。異なる断面で電流値が異なることを許し、枝分かれした箇所や局所的な流れを、一つの共通値へ押し込めない。既存eiriが各断面への物理的通過を要求するので、勝手な数値族だけで物理的分布を認定するわけではない。

eibgは同じ全範囲について二場合の履歴を結び、時刻原点の定数差で経過時間を保つ。両場合の全断面範囲は個別に確認するため、第二の場合だけ別の断面を省いたり加えたりできない。eibhは指定した一組・一時刻の比較、eibiは全ての組について既存eibcの全時刻比較を要求する。全体の和だけ同じ場合、一部の断面だけ異なる場合、断面の交換、向きの交換を区別する。

eibjは、この分布一致を相対運動の比較eia3と同じ右側物体・二つの系と文脈・単位・区間へ結ぶ。同時に満たす内容の構成であり、相対運動だけから分布一致を証明する条件文ではない。電流密度ベクトル場や体積積分との同値、電荷保存則もこの構成から導いていない。

検査では有限の断面族に対して全所属・全組の量化を実行し、範囲の欠落・余分な組・空範囲・場合間の不一致を区別する。全時間の物理的履歴は明示した検査境界として受け取り、一時刻の数値比較は本体を評価する。実数全域を有限の時刻列に置き換えない。原文に採る実際の尺度と断面範囲の妥当性は、有限の対照例からは認定しない。

今回で全断面を束ねる構文と参照接続を用意したが、原文の適用範囲、磁石・導体の性質、電気量の作用・校正との接続、二場合で保つ物理的性質、電場・起電力・エネルギー、通常の理解への帰属は残る。既存207主張と意味判断を保持し、原文の確認済み文字数は増やさない。
