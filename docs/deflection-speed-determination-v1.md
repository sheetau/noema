# 偏向応答を測って速度を決定する

原刊920頁のu0266全文とu0267の比の式を扱う。第一項の番号、第二(A)からの帰結、電気・磁気偏向の同じ強さ、同じ理論による任意速度の決定、Am/Aeの順序、直後の式への前方参照を接続する。u0265の列挙導入自体とu0268の独立直接測定は別の単位として残す。

Ablenkbarkeitは、標準配置での局所横加速度の大きさを正の場成分で規格化した応答と読む。Y,Nは電場y成分と磁場z成分であり、電子への力qY,−qvN/Vとは区別する。二試行は同じ電子・K・速度・低速質量・電荷・単位を共有する。第二(A)に基づく理論主張と、測定対象となる物理的な応答を分けた。後者の定義には(A)や比の成立を前提として入れない。

測る量は、実二階座標時刻微分からの横加速度と、同じ出来事で評価した物理的二場である。各読取りは、その量の記述に対する装置の校正、同じ対象・出来事の観測操作による信号取得、信号の変換値と実際の量の一致を要求する。校正は標準との物理的比較であり、任意の関数を選んだだけでは成立しない。取得操作も、仮定した数値記録とは別の入力である。

四つの取得記録を同じ観測者が同じ可能過程の評価段階で利用できることを要求する。これにより、相容れない別世界で独立に可能な二つの測定を寄せ集めない。規格化によるAe,Am、Am/Ae、V倍という算術操作と数値関係を結ぶ。測定・計算の構成eq4は、復元値と実速度が等しいことを前提にしない。一致は決定成功eq5で、全速度についてのその可能性は著者の内容eq7で述べる。

「任意速度」は、同じ理論と一つの基準電荷尺度を固定した0≤v<Vの全実数範囲である。低速近似や測定済み標本だけに縮めない。零速度も局所加速度の理想的な測定として含めるが、静止粒子が通過型装置を通るという条件は補わない。原文は装置の細目を指定していないため、理想化した測定尺度を採る。有限装置が任意実数の全桁を出力するという主張ではない。

第二(A)への照応は、先行の同じ三式の第二行をeraとして取り出す構造的対応である。そこから偏向条件を得ること、さらに比を用いて速度を決定できることは著者の論述として記録する。処理系が数式だけから測定器の実現を証明したとはしない。AmとAeの命名規則も同じ物理応答へ戻し、式表示単位だけを取り出したときにも、量の帰属と適用範囲をたどれるようにする。

追加する基本関係は、物理的校正、信号取得、算術操作の実行、記録の因果的な保持、順序ある内容の部分指定である。いずれも原文一文全体の真偽を代用せず、具体的な物理量・数式・可能性・対象同一性・全速度への量化は合成側に残す。検査成功と、原文全体を再読した意味判断は別に記録する。
