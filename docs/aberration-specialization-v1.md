# 光行差則の一般形と直角の場合

u0195–u0196を、原刊912頁の法則名・適用域・特殊条件・表示へ接続する。M0341はφ=π/2、M0342はcosφ′=−v/Vである。前段の377主張と意味規約は変更しない。

「最も一般的な形」は、先行の標準配置で許容した速度と方向の全域を扱うという読みとした。全61役割を量化したekhcには、特定方向や小速度の追加条件がない。この同じ内容を光行差則という呼称へ結び、先行の式の表示と著者の主張へ接続する。あらゆる理論や座標表示の中での最大性は補わない。

特殊条件ekhnは、同じ65役割の設定ekgyに、旧実数角angleが同じpiの半分である条件を加える。角を余弦の値だけで代用せず、φ′や別の波の角に取り違えない。一般印刷形ekhpと特殊印刷形ekhqには同じ全称変数と条件を渡す。旧角の規約の下でcosφ=0だから、一般形の右辺は(0−v/V)/(1−0)=−v/Vとなる。

この整理は、同時刻の源→観測者結線という前段の読解を訂正するものではない。V=5、v=3、旧法線(0,1,0)では、新法線と結線の実際の角の余弦は4/5となり、印刷式の−3/5と一致しない。一般形と特殊形の著者帰属はこの不整合を残したまま表す。引用された内容の真理を、提示関係や名前の対応の検査に含めない。

einfache Gestaltは、既出の記号と演算によって依存量を見渡しやすい形という評価として既存eisspへ結ぶ。最短の文字列や全読者の理解を主張しない。eissbで同じ直角条件下の表示への書換えを、ufとueでコロンと後続式への接続を、eisoxで表示内容を保持する。新しい一般基本関係は加えない。

検査は負比の符号・尺度変更・一般形右辺との一致、実数角の分岐本体、65設定の全位置、三内容の各61量化位置、名前・全域・提示・表示への参照を扱う。角の境界用モデルのpi=4は診断用の仮解釈であり、正本の積分で定めるpiではない。全実数域の評価を有限列挙へ置き換えず拒否する。旧判断の依存と原文・原刊のハッシュを確認し、意味判断は別記録で単位全体を再読して行う。
