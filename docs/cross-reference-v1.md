# 年月・頁番号による参照指示

カント論説の表題直後にある「1783年12月、516頁を参照」という補足を記述した。原刊481頁の括弧内の表示と固定電子転記を照合し、最初のS.はSieheという促し、第2のS.は頁の指定と読む。同じBerlinische Monatsschriftへの指示という文脈的な読みを採用する。現在の論説を掲載する1784年12月号とも、脚注で紹介される1784年9月号とも別の住所である。

一般定義`rqsp`は、系列・暦・年番号・月番号・頁番号・頁番号の規約を受け取る。年と月の割当、その系列に属する号の表示年月、その同じ号を親とする頁番号を結ぶ。年・月・号の候補を別々の存在量化で導入するため、途中で別の号の表示へすり替えることはできない。頁番号の割当には既存の`rqso`を使い、同じ規約・号・番号の内で頁を一意にする。誌面の頁という論理的な所在を扱い、現存する複数の冊子を一冊に限らない。号番号・記事番号・PDF画像位置は頁番号として受け入れない。

`hzmt`は受け手を引数に取る発話で、既存文法の「促す」という働きを持つ。その内容は、住所条件を満たす所在を受け手が参照する行為である。所在と行為は内容の内部に置く。`hzmu`は、著者がこの箇所で暗黙の受け手にその発話を提示することを記す。受け手を著者や特定の人物へ固定せず、全人類が実行するという量化にも置換しない。

新しい基本関係は二つである。`hzmp`は受け手を引数に持つ発話の提示、`hzmq`は情報を確認するため所在の記載を参照する行為を表す。前者は発話の働きや内容を型付きの記述として受け取り、後者は人・所在・行為・状況を区別する。新たな参照は頁番号の規約、指示の文章箇所、提示文脈の三つに限った。参照先の年・月・号・頁を、その文だけに意味を隠した新しい基本語にはしない。

提示の6対照、住所の18対照、促された内容の6対照、既存13文と合わせた3対照を検査する。年・月・頁・系列・暦・番号規約・親・重複・表示の欠落を変え、同じ号への接続を確認する。別規約や別の号に同じ番号があっても、対象号内の一意性は壊さない。住所と行為が未知でも、閉じた記述を提示する文は評価できる。住所や実行を明示的に調べる場合には、未知値を推測せず停止する。

原文は、参照先の主張への賛同、全文の通読、理解の成功、法的義務、実行日時を述べていない。これらは追加しない。一般定義と原文への適用の構文、代用表記と固有文字の往復、既存31文と意味規約・名称・六つの意味確認の結び付きを保存する。有限モデルの検査と、原文全体の意味についての判断は[別記録](cross-reference-review-v1.md)に分ける。
