# 恩恵の認識に基づく相手への態度

第八段落第一文のdankbarenに向け、恩恵の内容、その受容、相手への寄与の帰属、その認識を根拠にした肯定的な態度を接続する。11定義r5yf–r5ypと3基本関係h26nt–h26nvを追加する。本文と意味判断の登録は増やさない。

行為者、恩恵を受ける人、感謝する人を分ける。行為の生起点と結果点も分け、結果は評価点以前にあるが行為と同時でなくてよい。既存g3による結果生成を必要とし、時間的先行だけでは寄与としない。自分への恩恵はidで受け入れ、他者への恩恵はh26ntで受け入れる。後代の人が過去の行為による結果を受ける場合や、他の人への恩恵を認める場合を排除しない。

寄与を認めることはh26nfの誤りうる判断である。その内容を引用して保持し、判断から実際の行為・結果・因果を実行しない。これに相手への肯定的な態度と、その認識に基づいて態度を保持する関係を結ぶ。結果だけを喜ぶこと、寄与を認めるだけ、無関係な理由で相手を好むことは区別できる。発話や返礼をしなくても態度は成立する。

[DWBのdankbar](https://www.dwds.de/wb/dwb/dankbar)を語義の補助とする。後年の[AA VI 454](https://korpora.org/kant/aa06/454.html)は恩恵に基づく相手への敬意を述べ、[455頁](https://korpora.org/kant/aa06/455.html)は心情と行為、先祖への感謝を扱う。ただし、後年の義務論全体を1784年の形容詞へ移さない。善意だけに対する感謝も、今回の恩恵の実現を認める構成で網羅したとはしない。

r5ypは同じ人物が同じ相手に感謝の態度を持ち、その相手を称えることを結ぶ。過去の恩恵の行為と現在の称揚行為は別引数である。態度だけで発話済みにせず、態度を発話の唯一の原因とも断言しない。原文へ統合するときには、称揚される解放の功績と、この認められた恩恵の内容を同じ出来事へ束縛する必要がある。

現在と後代の全人物範囲・時代順序、集団としての態度の分布、両側から値するという評価への引用、政府側での最初の解放と良心事項の自由は未完である。有限例の検査は、その内容の歴史的な真理や一文全体の意味判断を代替しない。
