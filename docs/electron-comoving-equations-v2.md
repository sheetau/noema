# 共動系の初期三式と七変換式：小さいtの訂正

原刊918頁を再確認したところ、u0246の括弧は「für kleine Werte von t」だった。v1で記録した「電子テキストはt、原刊はτ」という差は存在しない。この照合判断を撤回する。旧読解・本文・規約・検査・判断は書き換えず、訂正版で四単位を再判断する。

M0409の記号一覧は原刊にξ,η,ζ,τ,X′,Y′,Z′があり、電子テキストにはτがない。この差は維持する。小時間の限定に使うKのtと、共動系の微分変数τを区別する。

訂正版では、同じKの三速度の初期変化を右微分とo(Δt)へ明示的に結び、同じkでは右微分とo(Δτ)、三運動式を保持する。両履歴は先行文の同じ出来事対応を共有する。Kの初期速度は(v,0,0)、0≤v<Vなので、初期のdτ/dt=1/βは正である。したがって両方の正側初期変化を同じ直後の運動として読むことができる。有限の時間区間全体での厳密な静止系法則や等加速は主張しない。

旧419主張は保存する。u0246–u0249の二主張には訂正した規約と同じKの初期変化を接続し、原刊全体を再読して判断する。記号説明、追加の四原点選択、第三節と第六節の全変換の適用、表示七式の区別は維持する。新しい原始関係と参照定数は追加しない。

検査では、旧tと新τで時刻原点・速度関数・加速度を取り違える例、片側の初期条件を欠く例を拒否する。登録した多項式の解析的微分と剰余、既存の三式と場の変換、本文の提示と量化の結合も確認する。検査成功は画像の文字認識や原文同義性の証明ではなく、原刊との照合は別の読解判断である。
