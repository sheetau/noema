# 提示・受領・再伝達の経路

内容を相手に提示すること、その相手が受け取ること、さらに別の人へ伝えることを分けて記述した。カント第四段落の `um sich verbreiten` に必要な伝播の部分構成である。理性的な自己評価や自己思考への態度が広まることを、発話の転送だけで表し終えたとは扱わない。

## 同じ内容が届く経路

`rdb` は、同じ生起する提示行為に、示す側・受け手・話題の対象・発話記述・状況を結ぶ。既存の提示関係を一対一の段階として使う。`rdc` はその同じ行為で受け手が発話を受領したことも要求する。提示されただけでは受領にならず、受領しても意味を理解したとは限らない。

`rdd` は、最初の段階と有限の後続列から伝達経路を作る。最初の段階が必ずあるため、後続列が空なら一回の直接伝達になる。各段階では次の条件を保持する。

- 同じ話題の対象と、同じ正規化されたNoemaの発話記述を伝える。
- 送信者と受け手は異なり、共に指定した適格条件を満たす。
- 後続段階の送信者は、直前の段階の受け手である。
- 後続段階は同じ順序付き履歴で厳密に後に起こる。
- 再伝達は直前の受領に基づく。同じ内容を別々に知っただけでは成立しない。
- 最終受け手と受領時点が、指定された終端と一致する。

既存の列の集計を使い、経路の長さに応じた専用の文法は追加していない。各段階を読むたびに、そこまでの条件を満たす終端を表す関数へ更新する。自己送信は除外する一方、複数の段階を経て最初の人へ再び届くことは許す。最初の発信者が情報の発見者だとは主張しない。

`rde` は、指定した非空の受け手範囲の全員へ経路があるという条件である。各人へ異なる経路・時点で届いてよい。`rdf` は、最終受け手が同じ話題・発話を終点で理解している条件を別に加える。途中の人々の理解や賛同、内容の真理、理解がその伝達だけに起因することは補わない。

## 原文側への接続

提示行為の生起・示す側・示される発話には既存の `dg`・`f3`・`f2` を再利用する。新しい基本関係は、受領 `h6e`、直前の受領に基づく再伝達 `h6f`、記述された発話の理解 `h6g` の三つである。これらの媒体・認知・因果機構の説明は、まだ基本関係の意味規約に依存する。

`h6h` は、発信者の同じ基準文脈の実際の履歴で、人の間の経路を記述する。終点は基準時以前でなければならない。`h6i` は終点での理解を加える。`h6j` は重複のない非空の人の集団全員への到達を表す。仲介者まで受け手集団の構成員である必要はない。

原文の具体的な発話内容と話題は、今回の接続では引数として残している。原語の文字列を内容として格納したり、未記述の自己評価や使命を表現済みとして数えたりしない。原文の未来の様相も未接続なので、実際にその内容が広まったという本文主張は追加していない。

## 検証と限界

提示の生起・示す側・提示・受領・理解の32組、経路の23対照例、長さ1・2・3の経路、受け手範囲の4例を検査した。原文接続の12例では、集団外の仲介者、理解の不在、欠けた受領、未来の受領、空・重複・非人間を含む集団を区別した。受領のみの経路は理解の評価を実行せず、受領自体が未評価なら判定を拒否する。発話の内容や賛同の条件は検査中に実行しない。

これは有限の具体例の検査であり、全ての有限長の経路に対する帰納証明ではない。発話記述が異なる言い換えの同義性も自動判定しない。時点は受領を含む粗い完了状況であり、送出時刻と受領時刻、伝達媒体の遅延、誤伝達と修復は未記述である。

指定した集団への到達は、公衆へ利用機会が開かれていることとは異なる。公開性、読者世界、周囲という範囲、到達・理解・態度変化の程度、集団内の能力変化との接続が残る。原文の理性的な自己価値の評価、各人が自ら考える使命、`Geist` の語義、全文の意味一致も未完である。

一般文書は基本関係0・定義6、原文接続文書は基本関係229・定義384・主張15である。既存の定義と主張を保持した。累積正規形は3,195文字増えて60,890文字であり、今回の変更は記述を短縮したものではない。
