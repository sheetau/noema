# 同じ波の強度と光速への仮定的接近

u0201の一文を、先行する式からの帰結、同じ光源と観測者、接近、V、無限に強く現れること、näherteとmüßteの仮定的な形を保って読む。原刊912頁のM0348はVであり、既存の有限Lorentz変換へVを代入する読みは採らない。

強度は、局所平面波が単位横断面積を通じて移転するエネルギーの時間平均である。エネルギーは仕事及び交換収支で扱う量、単位は力と変位の積に整合する基準へ結ぶ。換算係数の物理的対応eisteと、数式のベクトル場を同じ波のエネルギー流モデルとして採用するeistfを分けた。後者は成分誤差が小さいことだけから認めず、実測済みとも扱わない。数式は既存ekjfから三方向のκ(E×H)sin²Φを作る。

同じ正弦・余弦・一周期を保持し、各系でsin²の一周期積分がperiod/2になることを明示する。その同じ波形を流の積分平均へ渡す。旧系の基準静止点でのincidentと、新系の同じ観測者の経路でのreceivedを区別する。数学的一周期の平均であり、局所観測区間の長さを一周期以上に増やしたり、実際の流の領域外の値を断言したりしない。

非零の伝播する真空光の局所平面波という解釈を採り、当文では横波条件seajを明示する。先行の一般振幅の主張へ条件を遡及追加しない。旧法線−x・旧実数角πでは、源の−R*n配置は+x側にあり、同じ観測者の+x速度は源への接近となる。前文φ=0の後退側や、新角φ′についての先行の不整合と混ぜない。

66役割の有限設定を構成し、先行の同じ電気側二乗振幅比へ接続する。背景50役割には同じ源・波・過程・観測者・単位、旧場、旧振幅、正の入射平均流を固定する。新周期・新振幅、二系の観測経路と位相原点、代替状況の16役割は各速度・出力の点の中で存在量化する。各速度の状況は同じ理論に関するeisoeで選び、同一の現実状況に相反する運動を押し込めない。代替状況の選択に出力の大きさは使わない。

仮定的な「Vで近づくと無限に強く見える」は、この有限関係のv→V−での発散と読む。有限設定が非空である同じ背景について、Vへ任意に近い設定の存在と、その近傍にある全ての出力の上限超過を共に主張する。零のincidentは含めない。これは採用する境界解釈であり、光速観測者の実在や、その静止系における無限大という実数値の存在ではない。

先行変換表示ekcoと二乗振幅比ekikを展開済みの式への参照にする。eissbで強度・接近を伴う適用形を明示し、zcで同じ式から同じ境界内容への帰結、uhでその仮定範囲内の主張、eir3で著者・論説への帰属を保持する。müßteを現在の実測、規範的要求、引用内容の自動証明へ替えない。

検査は周期積分への引数、ベクトル成分、物理的対応、全66設定と代替状況、16存在位置、62及び46全称位置、同一背景、引用と帰結を確認する。実数・関数の全域を有限標本に縮めない。有限の波形診断は正弦の存在定理又は周期積分定理の機械証明とは区別する。原文の全単位判断は、これらの検査報告だけでなく、別の通読記録で行う。
