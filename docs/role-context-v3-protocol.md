# 範囲の境界にある文脈表現を役割判定へ加える

前回は正しい範囲をnoneとする誤りと、受け手・場所の取り違えが残った。役割の入力は主に語句内の平均表現と述語の表現であり、語句の直後の表現は独立した特徴として使っていなかった。固定モデルの特徴から学習する方針を維持し、境界の情報を追加して比較する。

語句の範囲モデルとその学習64文・開発16文はv2の保存結果に固定する。役割の教師候補も、v2の述語群4分割による予測を再利用する。元の学習・評価資料の正解、範囲モデル、分割は変更しない。

比較は従来の平均表現と、以下の4ベクトルを追加した方式とする。

- 語句範囲の最後の語の文脈ベクトル。
- 範囲直後の語の文脈ベクトル。文末で存在しないときはゼロ。
- 述語主辞と直後語の要素ごとの積。
- 述語主辞と直後語の差。

各語のベクトルはL2正規化する。文字列、助詞名、辞書、語別の結合・役割規則は特徴抽出に使わない。追加する語は原文位置のみで決める。境界の前後は語句の意味範囲へ含めず、役割を判定する特徴として分離する。

両入力方式で線形・64次元tanhを比較する。seed17、AdamW、学習率0.003、重み減衰0.01、全件バッチ、200エポックまでとし、開発の平均交差エントロピーで入力方式・分類器・エポックを選択する。選択の保存後に新しい4述語群8文を解析する。今回の学習では候補を拒否する閾値やクラス重みは追加しない。

新規資料は主たる出来事と内部の修飾を区別し、場所を含む能動文では主節の場所を文頭に置いて区切りを入れる。能動・受動の各組で同じ4役割の範囲を注釈し、異なる読みがないか予測前に確認する。ただし、これによって自然言語の解釈が一般に一意になると保証するものではない。

範囲と役割の一致、余分な項・欠落に加え、正しい候補をnoneとした数、別役割とした数を分ける。前回の後退が解消したかを既知の回帰48文で測る。正解範囲を与えた診断を行う場合は、原文だけからの結果に混ぜない。全項一致は指定した一つの出来事だけの部分条件であり、全文意味構造95%以上の達成とは呼ばない。

生成・辞書の禁止経路、固定特徴からの学習再現、保存ヘッドでの原文解析・反復一致を確認する。新しい確認文の結果を見て方式や正解を変えない。
