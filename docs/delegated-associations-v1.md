# 聖職者の団体と教会の代表会議

第六段落冒頭の問いに向け、全員が聖職者である団体と、諸教会から職務上の代表を送る団体を分けて構成した。新しい依存群は[delegated-associations.noema](../examples/v016/delegated-associations.noema)にある。問い全体は未統合で、現行本文の96主張と意味確認の分量は変えていない。

旧`hzcy`は宗教に関わる仕事の指定を全構成員に要求する部分候補だった。現行の聖職者には、主要な務め、役割の保持、教会からの任用、公的な宗教奉仕の責務を結ぶ`r35m`がある。今回の`r455`はその同じ人・役割・教会へ奉仕関係を結び、`r456`は全構成員にこの整合した職務を要求する。任用元と奉仕先が別の記録でもよいという弱い条件にはしない。人ごとに異なる教会へ仕えることは許す。

一方、Klassisをこの全員聖職者の条件だけで分類するのは狭すぎる。[ドルト教会規則の第41条](https://kerkrecht.nl/node/2149/)は、近隣の諸教会が牧師と長老を信任状付きで送る会議を規定する。[Huygens Instituutの史料紹介](https://www.huygens.knaw.nl/resources/classicale-acta-1573-1620/)も、classisを地方教会の会議と州のsynodeの間に位置する制度として説明している。原刊488頁、固定本文、取得した両資料を[出典記録](../data/delegated-associations-evidence-v1.json)へ結び、検査時には保存した資料だけを読む。

| 定義 | 今回構成した条件 |
| --- | --- |
| `r454` | 二人以上の団体の全構成員が、指定した資格を満たす一般構成 |
| `r455` | 同じ聖職者の役割・任用元・奉仕先の結合 |
| `r456` | 全員に`r455`の役割がある団体 |
| `r457` | 全構成組織に適格な所属代表がいて、全所属者が同じ組織・役割で代表委任を受ける一般構成 |
| `r46a` | 基準時の全所属者を固定し、宣誓等の評価時点でも同じ当事者を返す関数 |
| `r46b` | 宗教指導を主要な務めとする条件を足さない、同じ人・役割・組織の制度上の職務 |
| `r46c` | 構成組織を既存`r35r`の教会とし、`r46b`の職務代表を結ぶ団体 |

代表委任`h254f`と構成組織の範囲`h254g`を新しい基本関係とした。前者は誰をどの職務でどの会議へ送るか、後者は会議体がどの組織を代表するかを表す。人の所属には既存`h246c`を使う。資格のない人を所属から落としたり、代表が欠けた教会を代表範囲から落としたりして成立させることはできない。一つの組織に複数の代表がいる場合や、一人が複数組織を代表する場合は、別途制限を置かない限り排除しない。

構成員の任用や代表委任から、不変の信条を契約する権限は導かない。団体を引用して問いの対象にすることと、その団体の実在、実際の宣誓、契約の正当性も別である。`r46a`は今後の相互誓約へ渡す当事者を固定するための関数であり、この群自体は誓約を主張しない。

[局所検査](../reports/delegated-associations-v1.json)では、欠けた代表、余分な構成組織、無資格の所属者、役割・派遣元・派遣先・基準時の取り違え、牧師と長老に相当する混合集団を区別する。現行の`r35m`を実際に評価し、全員聖職者の団体には入らない人でも職務代表の団体には入れることを検査する。教会側の`r35r`だけを型付きの境界とし、その変更されていない構成は既存報告のハッシュで確認する。未知の所属・委任を偽として処理しない検査も行う。有限モデルは歴史的な団体の所属を証明するものではない。

`r46c`はまだKirchenversammlungやKlassisの完成定義ではない。教会の審議・統治機能、Klassisの地域と制度段階、オランダでの呼称、ehrwürdig、etwaによる例示をこの構成へ接続する必要がある。第41条の代表人数、会期間隔、議長選出の細則を、カントの一語に自動的に含めることもしない。その後、同じ信条への相互誓約、全構成員とそれを介する人民への上位後見、持続、権限の問いと次の否定回答を統合する。

