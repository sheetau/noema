# 同じ仕事への支援と、その継続

アインシュタイン論文の謝辞前半に、同じ研究への支援を表す候補を追加した。起きた行為、行為者、受け手、仕事、目的、時点を結び、実際の同席や研究の成功だけから支援を認定しない。前段の[着想の寄与を認める内容](intellectual-credit-v1.md)と同じ人物・仕事への参照を使う。

## 原文の読み

原刊921頁のu0276には、著者がここで扱った問題に取り組む際、M. Bessoが支えとなった旨がある。[原刊画像](https://de.wikisource.org/wiki/Seite:Einstein-Elektrodynamik.djvu/31)との対応範囲を[読解記録](../data/sustained-assistance-reading-v1.json)に保存した。

zur Seite stehenには援助の用法があるため、立っている姿勢や隣接する位置へ直訳しない。[Dudenのbeistehen](https://www.duden.de/rechtschreibung/beistehen)を参照した。treuには相手や物事に対する態度の安定性・信頼性という語義がある。[Dudenのtreu](https://www.duden.de/rechtschreibung/treu)を踏まえ、今回は、明示した支援機会に応じて目的に向けた行為を続けるという強い候補を作る。

これは忠実さの必要十分条件ではない。準備だけの支援、精神的な支え、例外を含む信頼性、困難な場面での態度を全て扱ったとはしない。友人・同僚という関係と、結びとして言明する働きは今回の対応範囲へ加えない。

## 構成

| 定義 | 条件 |
| --- | --- |
| `sewm`・`sewn` | 既存の厳密な全順序と非空の連続区間を、参照の衝突を避けて再利用する。 |
| `sewo` | 受け手の同じ仕事が進む時点に、助け手が同じ行為を行い、その受け手と仕事のための目標へ志向する。 |
| `sewp` | その時点に条件を満たす行為が少なくとも一つある。 |
| `sewq` | 同じ履歴で、同じ本人が仕事を進めていた区間を基準より過去に置く。区間内に仕事が途切れる点を残さない。 |
| `sewr` | 支援機会が非空で、全て同じ作業区間内にある。 |
| `sews` | 有効な範囲の少なくとも一機会に、目的に向けた支援行為がある。 |
| `sewt` | 有効な範囲の全支援機会に、その行為がある。 |
| `sewu` | 有効な範囲の少なくとも一機会に、その行為がない。 |
| `sewv` | 受け手・仕事の順序付き二個体列から、その仕事の前進を目標内容として表す。 |
| `seww`・`sewx` | 同じ著者・Besso・研究と、明示した区間・機会へ、少なくとも一度の支援と継続的支援をそれぞれ結ぶ。 |

目的は既存の引数付き目標記述を使う。目標の内容が真かどうかを支援の判定中には実行しない。達成されなかった仕事に向けて支援したことも表せる。目標の記述と、その受け手・仕事を渡す列は保持し、真偽が等しい別名へ勝手に交換しない。

支援機会は、作業区間の全時刻とは別である。たとえば三つの時点を含む作業区間で、最初と最後が支援機会なら、中間時点にも行為を要求することはない。一方、後から中間時点を支援機会へ加えれば、その時点の不履行が検出される。成功した時点だけを見て機会を選んだ場合の結果は、範囲の完全性の証明には使えない。

本文では先行205文を保ち、継続的支援の候補を著者へ帰属する一文を追加した。前段の着想を生んだ行為と、支援行為が全て同一であることは要求しない。

## 検証

[検査器](../scripts/check_sustained_assistance.py)は、一度の支援、全機会への支援、欠けた機会を別々に返す。後半の支援を別人が行った場合や、一つの機会を追加した場合を区別する。範囲が空、機会が空、機会が範囲外、履歴の順序が不正、作業区間の中間が欠ける、現在や未来へ区間を移す場合には、範囲の不備を不履行と混同しない。

行為の発生だけ、目的だけ、別の行為に付いた目的、受け手・仕事・引数順・目標記述の取り違えでは成立しない。目的が達成される場合と達成されない場合で支援の結果が同じになることも検査する。汎用定義には研究以外の庭の仕事を対象とした有限解釈を与え、文書や文法を変更せず同じ構成を評価する。これは園芸の概念全体を定義した証拠ではなく、仕事への役割接続の再利用試験である。

未知の作業区間・意図は補完せず評価を拒否する。著者への引用帰属だけを評価するときは、目的・履歴・支援行為を実行しない。通常表記・短縮表記・独自字形の往復、CLI解析、既存宣言と文の保存、再利用した時間定義の構造一致を別に確認する。

```powershell
python -X utf8 -m pytest tests/test_sustained_assistance.py -q
python -X utf8 -m scripts.check_sustained_assistance --verify-only
```

## 残る課題

作業の進行、目標の受益対象、目的志向、前進の判定は、解釈を必要とする原始関係に残る。実際に援助となる仕組みや、目的の形成まで説明し終えたとはしない。絶対日時、作業の端点、支援機会の完全な列挙も原文から補わない。

過去の非空の連続区間と、全支援機会への応答は、今回明示した候補の強さである。原文が要求する忠実さの強さや語用との一致は未確認であり、有限例の通過を歴史的事実や全文の意味一致へ昇格させない。全文意味確認済みの区間数は増やさない。
