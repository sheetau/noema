# 磁場中の軌道と曲率半径

アインシュタイン1905年論文のu0271からu0274について、軌道の曲率半径と磁場による偏向の式を部分記述した。半径を独立した数値として置くだけでなく、同じ電子・基準系・出来事の軌道の一階微分と二階微分へ接続する。前段の静電加速とは別の磁場中の事例として軌道と出来事を指定し、先行199文を保存した。

## 曲率の定義

ユークリッド三空間で、速度をu、加速度をaとし、`S = u・u`、`C = S(a・a) − (u・a)²`を作る。`S > 0`、`C > 0`、`R > 0`の下で、`R² C = S³`を曲率半径Rの条件にする。速度と加速度から曲率を定める構成は[MITの曲率の説明](https://math.mit.edu/~djk/18_022/chapter02/section07.html)に対応する。根号を除いた式でも、正の半径という条件は残す。

接線方向の加速度は、速さを変えても同じ瞬間の曲がり方には寄与しない。定義は加速度の全体を大きさだけで扱わず、速度に沿う成分を差し引く。検査では接線加速度の追加と座標の四分の一回転で半径が変わらないことを一般命題として確認する。

静止点と曲率零の点には、有限の曲率半径を割り当てない。これは直線運動を記述できないという制約ではなく、有限で正の半径を表す関係の適用範囲である。また、この局所的な半径から軌道全体が円であることや速度が時間的に一定であることは推定しない。

## 原文の向きと一般の半径

[原刊921頁](https://de.wikisource.org/wiki/Seite:Einstein-Elektrodynamik.djvu/31)のM0441は、`−a_y = v²/R`を磁場による横加速度に等置する。M0442は同じ式を半径について整理した形である。原刊画像と電子MathMLについて、先頭の負号、`v²/R`、`ϵ/μ`、`μ/ϵ`、`1/N`を照合した。

Rを正の幾何学的な半径として読むと、原文の負号は負のy側へ曲がる向きに対応する。数値化では、光速度Vと質量μを正、速度を`0 < v < V`、正規化係数βを正とし、次の条件を保持する。

- 横方向の運動方程式：`μβV a_y = −qvN`。
- 原文の曲がる向き：`−a_y R = v²`。
- 整理した半径式：`R qN = μβVv`、かつ`qN > 0`。

電荷qと磁場成分Nを同時に反転すると、曲がる向きと半径を保つ。一方だけを反転すると向きが反対になり、原文の向きの式は満たさない。方向によらない一般定義では、その場合も正の半径を表せる。原文を絶対値付きの式へ黙って書き換えることはしない。

二つの印刷された形の同値には、同じ運動方程式が前提となる。半径の数値だけが合っていても、加速度の向きが逆なら最初の等号列は成立しない。その反例も本文の検査に含める。

## 軌道と場への接続

軌道の接続には既存の`sepp`を使う。同じ局所的な時間領域で速度関数が座標関数の微分になり、それをさらに微分した値を加速度として使う。一点や有限個の標本だけで一致する偽の速度関数は、登録した多項式の係数全体を比べるモデルで区別する。

本文では瞬間の速度をx方向、磁場をz方向に取り、横電場を零にする。電場・磁場・領域は既存の`znn`で同じ基準系へ割り当て、同じ出来事の座標で評価する。縦電場と接線加速度は排除せず、縦方向の運動方程式は今回の記述に含めない。

さらに、その磁場以外の偏向原因がないことを明示する。横電場が零でも他の偏向原因がないとは限らないため、この条件を数値から補わない。半径の式、導出の前提、著者の主張・理由づけは別に保持し、著者への帰属を四文追加した。

| 定義 | 内容 |
| --- | --- |
| `sevb` / `sevc` | 有理数 / 実切断による三次元の曲率半径 |
| `sevd` | 同じ座標履歴の一階・二階微分への接続 |
| `seve` / `sevf` | 原文の向きを保持した横方向の等号列 |
| `sevg` / `sevh` | 非零分母と符号条件を保持した半径式 |
| `sevi` / `sevj` | 向きを問わない磁場中の正の半径 |
| `sevk` / `sevl` | 同じ軌道・場・偏向原因の設定 / 本文への接続 |
| `sevm` / `sevn` / `sevo` | 本文の等号列 / 半径式 / 導出候補の前提 |

## 検証と残る課題

有理数の五つの一般命題と一つの反例を検査する。軌道と本文の検査には、登録した多項式の解析的な微分、明示した座標履歴、場の割当を使う。全実切断の微分法則や曲率公式の同値を証明したとは扱わず、全時刻の履歴を有限列で代用しない。

座標の長さ・時間尺度、電荷・場・質量の単位は式に整合する規約を前提とする。測定・校正、電磁的な力の基礎説明、接触円としての幾何学的特徴づけ、全実数上の解析法則、原文全体の意味一致は残る。
