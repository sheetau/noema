# 呼称の著者と使用箇所を、規約どおりの順序で渡す

著者注の敬称を表す旧 `hzmd` には、型検査で検出できない引数役割の不整合があった。旧関係 `du` の規約は `node, author, referent_description, label_description, context` の順だが、`hzmd` は最初の二項を著者・使用箇所の順で渡していた。旧テストの解釈も著者・使用箇所の順を受け入れており、不具合を隠していた。二項がともに個体型なので、型の一致だけでは正しさを確認できなかった。

同じ解釈対象を保ち、`du` を規約どおりの順で解釈すると、旧敬称の文は成立しない。この反例を保存した上で、現行辞書の `hzmd` 自体を改訂する。改訂した `hzmd` は丁寧な名称使用 `hzlr` と対象・性質の記述をそのまま使い、著者・使用箇所の順が明示された既存の `hzwh` へ渡す。刊行物の呼称を記述する文41と、同じ一般関係を使う。

新しい基本関係や人物参照は追加しない。過去版のファイルは改変せず、新版に完全な意味規約を保存するため、過去の記録を再現して比較できる。現行辞書には誤った旧定義を残さず、`hzmd` の接続先を修正する。前方参照を避けるため、既存 `hzwh` の宣言を `hzmd` の直前へ移す。本文42文を参照先まで調べると、旧 `du` に依存するのは文8と文26だった。修正後に残る文8は、箇所 `dq`・著者 `wa` の順であり、規約どおりの解釈で成立する。交換すると成立しないことも別に検査した。本文から未参照の旧定義まで正しいと認定するものではない。

検査では、旧テストの解釈では旧敬称が通ること、規約どおりの解釈では失敗すること、新しい敬称と刊行物の呼称は同じ規約で通ることを確認する。人物と刊行物の二つの使用について四組合せを調べ、著者・箇所の交換、別著者・別箇所・別対象記述・別性質記述・別文脈・欠落の十四対照を検査する。互いの性質の取り違え、丁寧さの欠落、使用自体が未知の場合も分ける。

両方の呼称は性質の記述を引用して用いる。男性分類や刊行周期の現実の成立を、呼称だけから推定しない。表題・回答への接続・著者注と合わせた12文を八つの解釈で評価し、選択した結合部分が旧 `du` に依存しなくなったことも確認する。保存した通常グラフを使い、短絡変換やメモ化は使わない。
