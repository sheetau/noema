# 遠距離の方向極限と三次元の角

u0188の無限遠の光源と角φに必要な幾何学を構成した。先行の単一の有限な遠方源を、そのまま実数座標の無限大へ置き換えない。今回の数学的な配置族と、原文の光源・観測者との物理的な対応は次の統合で指定する。

単位方向nに対して源の代表位置を−R*nに置き、有限位置pの観測者へ向かう変位をp+R*nとする。長さLで正規化したこの変位がnに近づくことを、各成分の不等式|d_i−L*n_i|<εLで記述する。L=0を拒否し、零除算を使わない。

ekdk–ekdmは、各固定位置pと各正のεについて、ある境界以遠の全Rでこの不等式を満たすという極限を表す。境界はpとεに依存してよいが、その後のRごとには選び直さない。全空間で一様に近づくことや、観測者も同時に無限遠へ移動することは要求しない。各Rで空間位置を固定した曲線も構成したが、物理的な源の静止を数値曲線だけで認定しない。

ekdn–ekdqは、同じnと非零の速度ベクトルの内積から角の余弦を定め、非負の正弦と既存の象限処理で0からpiまでの実数角へ結ぶ。三次元の横成分を保持し、直角と反対向きを含む。速度を正の+x方向へ取った標準配置で初めてcosφ=aとなる。零速度には任意の角を付けない。

ekdrはM0333の正の平方根を含む式をその形で構成し、ekdsは前段の共通周期による変換と同じ方向角へ結ぶ。ekdt/ekduは先行47設定役割へ角関連5値を加え、48証人を一つの割当に束縛する。既存のpi、一周期2*pi、場の近似誤差と用途上の十分性を保持する。

本文370主張と全単位判断は変更しない。光源に静止する系、同じ観測者の運動と知覚される周期数、有限の源と理想化との対応、帰結と式を著者が提示する役割が未接続なので、u0188–u0189の完成は認定しない。

検査は有理数による具体例、全称・存在量化の結合、角の枝と符号、印刷式への引数の対応を区別する。全実数の極限・pi・逆正接を有限標本で証明したとはしない。
