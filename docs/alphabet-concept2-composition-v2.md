# Concept 2：意味の構成から形を組み立てる規則案 v2

2026-11-05の図例と確認回答を優先する。[前案](alphabet-concept2-proposal-v1.md)の中大円のくりぬき、日食型の内側だけの残し方、接続長の自由調整を撤回する。原文・既存の語義・定義・参照先は変えない。外観は利用者の確認前に固定しない。

**作図の基準**

小円半径を `u`、中円半径を `r₂=(1+√2)u` とする。大円は `r₃=(1+2√2)u`、第4円は `r₄=(1+3√2)u`、三段の間隔は `p=(2+√2)u`、ドット半径は `(√2−1)u`。大円以上の中心は中段。横線は三段、線の方向は縦・横・45度を継承する。

中大円の中心間距離は `√(r₂²+r₃²)`。中円側へ向く大円の90度区間は、全体を残すか全体を消す。その外側の6区間は45度ずつ独立に選べるが、少なくとも1区間を残す。全周を残す交差型も認める。中円内だけ大円弧を消すくりぬき、中円内の大円弧だけを残す形は認めない。円の交点で弧を切断してこの制限を迂回しない。

小中・小大の直交交差では、全周交差と小円によるくりぬきを残す。日食型は中大だけに用いる。同心、既定の中小・中中の接触も使える。小円の偏心包含を追加しない。交差相手が複数の場合も、個々の円の組と残る区間が同時に適合しなければならない。

接続の端の長さは中円半径 `r₂`。単なる外接矩形から測らず、接続する円周から測る。内包小円から出る線なら小円周、欠けた円弧の開口へ入る線ならその構成が公開する中心基準から測る。実際の円周を横切る線は必ず直交させる。内側の円周へ接続する線と、外側の円弧へ接続する線を区別する。

同じ段の二つの接続口は、円周間の半径線1本で接続できる。曲がる接続では、円周から最初の曲がりまでと、最後の曲がりから相手の円周までがそれぞれ `r₂`。その間は三段の移動に必要な縦・45度の区間で構成する。字形内の半径線や同心円間の線は、それぞれの半径と差から決まり、外部の余白調整には使わない。

大円の斜め自由端は第4円の上下端の高さで止める。その後の上下小円への無線の接続は、大円の左右端から小円の中心までの水平距離を `r₂` とする。この組を別の無関係な要素として読ませない。

改行では線の途中を任意の位置で切らない。端の構成から `r₂` の半径線を出して終わり、次行でも `r₂` の半径線から接続する。継続する段の集合を保存し、複数段の継続なら各段に対応する線を置く。円の途中、ドット単独、無線の接続の途中では改行しない。

**意味の構成を選ぶ順序**

構文木から、型付きの役割、同一対象の使用、引用・束縛の範囲を取り出す。まず意味上の関係を決め、次に合法な形と接続口を選び、最後に配置する。形を順に並べた後で、余った空間へ線を伸ばす方法を使わない。

| 意味上の条件 | 選ぶ構成 | 回収すべき情報 |
| --- | --- | --- |
| 対象への性質や否定の付加 | 同心・接合・内側へつながる短い線による局所付加 | 対象、付加内容、作用する範囲 |
| 複数の引数を持つ関係 | 順序付きの接続口と、必要な分岐 | 各引数の位置・型・値。上下だけで順序を推測しない |
| 同じ値を何度も使う | 段への値の宣言と、後続の接続口による共有 | 宣言元、役割、使用回数、使用箇所 |
| 同じ複雑な語・式を再利用する | 内容を示した局所定義と、その定義への呼び出し | 元の綴りまたは式、引数、定義が有効な範囲 |
| 同じ引用操作などが続く | 段への構成ひな形の宣言 | 引用の種類と階数、関数参照と値の区別 |
| 短い直接接続では表せない一対の関係 | ドットによる接続 | 出力と入力、対の順序、引用領域 |
| 未充足の引数や束縛変数 | 円弧内の未接続小円と、役割を埋める操作 | 役割の型、束縛元、未充足と既存値の区別 |
| 複数の項目・可変長の組 | 区切りと、延長可能な役割群 | 順序、終端、外側の構文への復帰 |

六系統を六個の固定記号へ置き換えない。例えば共有は、独立した共有記号を各回に置く方法だけでなく、述語の円へ接合した小円を、既に宣言した値の使用口として読めるようにする。接合の向きと接続先は役割を表し、輪郭の都合だけで変えない。

**字形の組み合わせと自由度**

語の綴りに由来する区別、構文操作、引数の接続口を分ける。語形全体を毎回独立した囲いに収めず、接続口を持てる部分へ局所操作を合成する。内側に線が接続しない円弧は、範囲、未充足、定義の呼び出しなど、その分離自体に意味がある場合に使う。通常の語の識別は、それだけへ集中させない。

同心の複数円、円弧と内包円をつなぐ線、直交する円、接触、片側だけの分岐、三段への分裂、後続での合流を候補にする。小円の中心線、直径、同じ中心へ複数方向の線、線だけの閉路、連続する直角曲がりを避ける。新しい線が他の円を横切る場合も例外にはしない。

合字は、公開された元の根語列と順序へ戻せる場合に限る。原文一文の専用字形を追加しない。向き・部分円の選択・接続の合成でできた異体も、同じ語と同じ構文へ戻る規則を持つ。辞書順、文番号、ハッシュ、乱数を外観の選択に使わない。

同じ意味の合法な候補間では、描く要素数、線の長さ、重心、近接、直前の構成の反復を評価する。使わなかった形には、未実装、今回の意味では不要、他の条件に不適合、という理由を区別して残す。全種類を本文へ無理に混ぜる割当てはしない。

**段の宣言、共有、局所定義**

段への宣言は「この値を使う」と「この構成ひな形を適用する」を区別する。値には型を付ける。ひな形には入力の役割と、展開後の構文を定める。引用された関数参照を表すひな形と、引用された引数0個の値を表すひな形は別物で、階数も含めて宣言する。

宣言は内容を読み終えた後の使用に有効。後の宣言は同じ段の意味を上書きし、内側の範囲を抜けると外側の状態へ戻す。宣言の前方参照と循環定義は認めない。三段を超える役割は、順序付きの群と区切りによって延長する。段へ意味を割り当てた後は、衝突を避けるだけの移動でその意味を交換しない。

同じ対象を共有しても、各使用箇所は残す。連言の結合順、関係の引数順、繰り返して適用した回数は省かない。共有するのは同じ構文・同じ型・同じ束縛先の値だけ。閉じた定数、閉じた引用値、明示した引数を持つひな形を対象にし、自由変数の偶然の一致でまとめない。

局所略記は、一つの語の綴り、一つの閉じた式、または引数を明示したひな形を表す。名前だけを略す場合は語の適用先まで取り込まない。式を略す場合は一つの式の終端を型と引数数から定め、線で到達できる全要素を無制限に取り込まない。略記の展開で変数の捕捉を起こさない。

同じ値の多用には共有、共通操作には役割のひな形、複雑な語・式の反復には略記を使い分ける。全ての反復を同じ空円弧へ置換しない。宣言を増やす方が長くなる場合は元の形を使う。

**ドット、範囲、束縛**

ドットの識別形は同心の中円の45度区間だけ。上位円や外部線では識別を変えない。裸のドットは識別区間なしとする。ドットに線を接続せず、小円内へ入れず、文頭・文末にしない。ドットの後には、対象の内容または入力の接続口を必ず描く。

同じ文・同じ引用領域の同じ識別形を出現順に1–2、3–4と対にする。一つのドットを全使用先への放送にしない。片方は出力、もう片方は指定された入力であり、型が合うという理由だけで相手を選ばない。未対応の対を残して文や引用を閉じない。

引用では、変数、段の役割、局所略記、ドットの対応を新しく始める。引用全体を外側で値として共有することと、引用内から外側の変数を参照することは別である。通常の範囲では外側の定義を参照できるが、束縛された変数を範囲外へ漏らさない。

未充足の役割には、接続のない小円を内包する円弧を使える。役割が空であることと、値が存在しないこと、引数0個の値、空の列を区別する。中心からの線は方向を指定するために用い、線長で束縛階層を変えない。八方向は全て使えるが、前後・上下段・同じ局所構成内の参照として、選ばれる対象を先に定義する。

**次の試作で確認する範囲**

本文は元のkant-pageと同じ4段落・40項目。前回省いた共有、段の宣言と上書き、局所略記、ドット、束縛・引用の範囲、未充足の役割、区切り、半径線による改行を対象にする。本文に自然に現れない用法は、意味の異なる短い対照例で併記し、本文に無意味な要素を足さない。

最初に構成の展開で元の構文が保たれることを確認し、次に実際のSVGの円弧・線・ドットで幾何規則と接続を検査する。構成データからの復元と、図形だけからの復号を混同しない。語義と参照先が変わらない部分の原文意味確認は引き継ぎ、配置変更を理由に歴史版全量の意味診断を再実行しない。生成は項目別に保存し、入力・実装の内容ハッシュを固定する。

**今回の実装範囲**

本文では、値の共有、引用操作の共有、語と閉じた式の局所略記、ドット対、引用・束縛、順序付き引数の区切りを使う。共有の使用口は幾何条件を満たす場合に語形へ合成する。略記は実際の使用回数で判定し、宣言だけ残るものと長くなるものを取り除く。接続は半径線から作り、線が円の中心を通り抜ける場合と、中心から二方向以上へ分かれる場合も拒否する。

通常の範囲での段の上書き・復帰、引用ごとの独立、同じドット識別形の再使用、適用先が異なる語の略記、未充足役割への適用、外側の束縛の参照は短い構文対照例にする。これらは既存の公開辞書を使って型を検査し、カント本文には追加しない。

大円の斜め端から小円への四方向の接続、八方向の中心線、二段・三段同時の改行は作図対照に含める。これらを文全体の意味付き配線として自動選択する処理は未実装。本文の大域的な構成は引き続き順序付きで、局所の合成だけでは基準ページの密度や複雑さに届かない可能性がある。単一個体型の束縛を実装し、未対応の型・複数引数の束縛を同じ形で代用せず拒否する。

図形からの語境界・合成された共有口の読順を含む一意な構文復号は未完成。現段階の試作を固定表記の整合完了とは扱わない。線だけの閉路や全ての近接条件の一般的な証明も、今回の幾何検査には含めていない。
