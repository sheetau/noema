# 一般的な萎縮と、回避の頻度を別の範囲へ結ぶ

カント第二段落の末尾で、無修飾の「例が萎縮させる」を通常事例についての一般的な因果反応として、「通常は後の試みを避けさせる」を例外を含む事例全体の頻度として記述する読みを採用した。前版は現況の有限列で全員の萎縮と回避の過半数を要求したため、現況の集計と、状況の違いを超えて述べる傾向を区別できていなかった。

この改訂は原著者の主張の真理を証明するものではない。一般文と頻度表現を区別する必要は前段の[検証](frequency-under-variation-v1.md)で確認したが、今回選ぶ比較条件が唯一の歴史的読解とはしない。[原文36頁](https://korpora.org/Kant/aa08/036.html)、[Cohen, Genericity, 第4節](https://tzin.bgu.ac.il/~arikc/gen.pdf)を参照する。

比較状況の範囲では、不成功例との遭遇や認識の環境、対象者間の差を検討する。活動の意味と指示する対象集団は基準に保持する。状況の通常性を比べる順序と、その状況内の事例の通常性を比べる順序を分ける。いずれも明示した解釈入力であり、萎縮・回避の結果を見て成功したものだけを優先する規約ではない。

| 構成 | 範囲と応答 |
| --- | --- |
| `r2bh` | 比較状況の事例・先行例の認識と、基準状況の対象集団への所属を結ぶ |
| `r2bj` | 通常の比較状況ごとに、通常事例で因果的な萎縮が成立する |
| `r2bi` | 同じ比較状況ごとに、事例全体で因果的回避が過半数と基準の割合条件を満たす |
| `r2bk` | 同じ基準について両条件を合わせる |

萎縮の通常事例から外れる例外も、回避頻度の分母には残す。全事例の三例中二例が回避する場合、その二例だけへ範囲を縮めて全員の回避として扱わない。通常性で比較不能な事例の萎縮が欠ける場合は、一般的な萎縮も成立としない。循環や空の範囲を成功扱いにしない。

対象集団は比較先の`dj`で再選定せず、基準の`dj`を使う。比較先で集団の見え方が変わっても、元の対象者を除いた別集団の反応では代用できない。割合の基準も基準文脈に固定する。現況の実際の反応と、比較状況での因果的反応は独立して評価する。

本文の第37文（ゼロ始まり）では、主張、主張と背景の組、期待比較のQを同じ`r2bk`へ更新した。危険の程度P、学習を理由とする関係、著者、本文の順序は保持する。引用した反応を実行せずに著者へ帰属できるため、著者の主張を記述しただけで現実の心理反応を確定しない。

十二定義と、比較範囲・状況の通常性・事例の通常性を指定する三関係を追加する。このうち一般的な事例順序の三定義は、既存の状況順序と同じ条件を個体型の事例へ適用する。前段の頻度構成`r2bd`は式と意味規約をそのまま取り込む。本文52文のうち一文を改訂し、既存の宣言と残る51文を保持する。

検査では三事例の全512関係と19の厳密な半順序、応答の152組合せを独立した関係合成による判定と照合する。原文側では現況・一般的萎縮・回避頻度の8組合せと17対照を、現在の失敗経験・認識・勇気・恐れ・回避理由・因果の定義で評価する。帰属の8組合せ・7対照、未知入力、三記法の往復、十一単位と先頭六文1,021文字の意味判断の保存も確認する。

有限・等重みの事例という頻度側の制約、比較条件の経験的な根拠、架空の例、萎縮の全語義は残る。学習の見込みを含む末尾一文と段落全体の通し判断も未完である。既存の対応範囲内の改訂であり、原文の対応文字数や意味確認済み分量は増やさない。
