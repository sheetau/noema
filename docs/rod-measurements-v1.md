# 同じ棒を測る二つの方法

棒と共に動く物差しによる直接測定と、静止系での両端の同時刻の位置から長さを求める方法を、別々の条件としてNoemaに記述した。同じ棒・物差し・観測者への参照を保ち、測定設定を混ぜない。二方法の値が同じか異なるかは、この設定だけから決めていない。

対応するのは[アインシュタイン原文§2](https://de.wikisource.org/wiki/Zur_Elektrodynamik_bewegter_K%C3%B6rper)の `u0030` と `u0031` である。前段の棒の初期長・剛性・軸・運動を与える設定と問い、後段の長さの命名や相違の導出はまだ接続していない。両区間とも意味一致を確認済みの完成訳とは扱わない。

## 測定設定を分ける

方法aでは、棒・観測者・物差しが同じ移動側基準系で静止する。その物差しを棒に当て、同じ観測者が長さを読み取る。静止側の基準系に対しては、棒が動いていることも明示する。

方法bでは、物差しが静止側の基準系で静止する。同じ棒の異なる二端点について、それぞれの出来事と場所を保持し、同じ指定時刻の二地点の距離を同じ物差しで測る。原文にない観測者の静止条件は加えていない。

同じ物差しが、相対運動する両基準系に同時に静止すると解釈してはならない。そのため棒・観測者・物差しの静止条件に測定設定の文脈を明示した。方法aでの静止と方法bでの静止は、別の設定に属する。どちらの方法を説明するかという本文の帰属も、現実に測定を実行済みであるという事実とは分ける。

## 端点の同時性

| 定義 | 条件 |
| --- | --- |
| `sbe` | 同じ対象・観測者・物差しの共動、配置、直接の読み |
| `sbf` | 同じ対象の異なる二端点と、それぞれの出来事・場所の対応 |
| `sbg` | 長さの候補が正の実数であること |
| `sbh` / `sbi` | 方法aの結合と、実数条件への接続 |
| `sbj` / `sbk` | 方法bの結合と、同期・時刻一致・実数条件への接続 |

動く端点の位置には出来事を指定する。静止対象の全期間の設置場所を、そのまま動く端点の位置の代用にはしない。両端は同じ棒に属し、異なる端点であることも要求する。

各出来事の時刻には前節の `qt` を使い、同じ参照時計に同期した、その場所の静止時計の読みを結び付ける。二つの読みが互いに一致するだけでなく、本文で指定された時刻とも一致することを要求した。指定時刻は `M0048` の文字記号に対応し、任意の数値は補わない。

実数の接続では、読みと指定時刻が有効な下側切断であることを確かめ、値の一致を両方向の包含で記述する。関数の実装上の同一性による比較ではない。二地点の距離と、観測者が物差しでその距離を測る関係も分けて保持する。

## 値を先取りしない

方法aと方法bは、長さの候補値が満たす条件として書いた。全ての対象について値が存在する、値は必ず一つである、両方法で値が等しい、あるいは必ず異なるという条件は補っていない。ローレンツ収縮の式もまだこの測定設定から導出していない。

著者による方法の提示は、候補判定関数の記述を引数に取る。提示を評価するとき、その測定の内容や実数の条件を実行しない。二つの方法を入れ替えたり、違う考察範囲へ帰属させたりすると不成立になる。

## 検証と残る課題

直接測定の型・三対象の静止・配置・読みという八条件の256組合せを検査した。原文接続の27例では、方法aの値を5、方法bの値を4とする明示モデルと、両方を5とする明示モデルのどちらも扱える。これは実際の収縮量や物理的実現可能性を示す例ではなく、測定条件だけで結果の一致・相違を決め付けていないことの検査である。

別の物差し、同じ端点の二重使用、違う時計や参照時計、配置や読みの欠落、動く局所時計、異なる出来事の端点位置、二方法の設定の混在などを拒否した。時刻が異なる場合と、時刻は一致するが指定時刻とは異なる場合も拒否する。方法bでは観測者が動くという明示関係を加えても、そのことだけでは拒否しない。

接続の有限検査では、同期・正の長さ・数値の一致を、入力した整数の埋込みに限る判定関数で与えた。実切断全域の物理モデルを近似して証明したわけではない。正の実数長への全量化を有限実行器が拒否することも確認した。方法の帰属は6例で検査した。
