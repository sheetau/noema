# 移動球面の局所無流出入と内部輸送

u0203第四文からu0204の球面式を挟むu0205へ、同じ光の部分の運動を接続するための定義群である。今回の段階では旧388主張を保持し、新しい原文一文全体の意味判断は増やさない。

球の中心はVnt、波面法線はn=(a,b,c)である。一方、球面の外向き法線は(x−Vnt)/Rとなる。並進方向と球面法線を分け、同じ時空点で瞬間流Jと瞬間密度ρから相対流J−ρVnを作る。その球面法線成分の正の部分を外向き、負の部分の大きさを内向きの局所通過量とする。

ekniは、全実時刻の全表面点でこの二量がともに零であることを記述する。ある点での流入と別の点での流出が相殺するだけでは成立しない。これは単一の平面波連続体の流れという読みであり、任意の複数モードが同一点で逆向きに交換する過程を、合成したPoyntingベクトルから復元する定義ではない。

eknkは同じ平面波の瞬間流・密度をekniへ渡す。共通波形を持つ横波ではJ=ρVnなので、球面法線がどちらを向いていても相対流は零になる。平均密度A²/(8π)を瞬間流へ代入せず、節で密度が零になる場合も保持する。球面が光速度で動くことは幾何学的な境界の運動であり、光速度の慣性系を導入しない。

内部の持続は別の条件である。eknlは初期位置x0からx(t)=x0+Vntという経路を取り、球の閉内部・表面への所属、位相、瞬間密度の初期値との一致を結ぶ。eknmは全内部初期位置と全時刻でこれを要求する。境界の流れだけを見て内部生成消滅がないと推論することを避け、内部で何を保つかを明示する。並進が体積を保つことと組み合わせた連続体輸送の読みであり、粒子や光子の同一性の記述ではない。

eknnは同じ波・過程・系・校正単位・部分について、球の全時刻の閉内部を領域にした流と密度の物理モデルを採用する条件である。先行の有限の局所近似が、そのまま永久に追跡できると証明したものではない。原文のdauerndに向けて、理想的平面波モデルを球の全領域履歴へ採用することを明示する。eknoはこの採用と無流出入・内部輸送を同じ設定で結び、eknp/eknqは前二文の同じ70役割へ接続する。

検査では、球面法線と波面法線の相違、内外通過の符号、反対側での相殺例、各点の運動と位相・密度の持続、モデルに渡る全役割と領域履歴を確認する。全実数・関数域を有限標本へ縮めず、量化の接続と数値本体を別に検査する。有理関数の共通波形は代数的な診断であり正弦の全域解析の代用ではない。
