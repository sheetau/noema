# 理由に基づく応答傾向の変化

前段で未充足だった媒介の内容と評価条件に、同じ判断対象への独立した応答が段階的に広がるという候補を接続した。カントの `Sinnesart` 全体をこの条件と同一視するものではない。心理的な態度を未定義の一語で済ませず、少なくとも何を比較する候補なのかをNoemaで明示した。

## 応答と評価を分ける

[一般定義](../examples/v016/reasoned-response.noema)の `rxi` は、本人、判断対象の一覧と範囲、履歴と順序、開始点と終了点を受け取る。対象の一覧は非空で、重複も範囲からの欠落もなく、区間内の全対象について応答の成立・不成立が分類されていなければならない。一段階の増加上限も正にする。この条件だけでは応答の成立や増加を要求しない。

`rxj` は、応答しない対象の集合へ既存の段階的減少 `rl6` を適用する。以前に応答した対象を失わず、応答する対象が少なくとも二回増え、隣接する時点の増加が指定上限を超えないことを要求する。変化のない途中の時点は許す。人数や成功数だけを比較して、以前できた対象の喪失を隠すことはできない。

例えば、三時点で応答できる対象が「なし」「甲」「甲と乙」と変わる場合は成立し得る。「なし」「甲」「甲」のような一回だけの増加や、「甲」「乙と丙」「甲と乙と丙」のような対象の入れ替わりは成立しない。応答が全時点でなくても、分類済みなら評価条件は真で変化条件は偽になる。未評価の場合とは区別する。

## 判断内容から作る媒介

[本文草案](../examples/v016/kant-reasoned-response.noema)では、次のように候補を構成する。

| 定義 | 条件 |
| --- | --- |
| `iamresponse` | 同じ本人・対象を提示した仮定場面で、自分の理解力による、理由に支持され他者の指導によらない判断 `rcr` があり、その判断が提示した対象について述べる |
| `iamassessed` | 同じ本人・対象・場面で提示があり、応答条件を満たすかどうかが分類済みである |
| `iamreviewed` / `iamchange` | 同じ履歴で、前者は評価可能性、後者は応答対象の段階的拡大を求める |
| `iamschema` | 前段の媒介条件の `meaning` と `reviewed` に、`iamchange` と `iamreviewed` を渡す |

判断対象の一覧・範囲・増加上限は、元の開始点で固定する。原因や媒介へ介入しても、別の容易な対象へ交換しない。評価場面は各時点とモデルの解に対応させる。仮定場面での応答が成立することから、現実の開始点で既に判断したことや行為を実行したことは導かない。

前段の因果比較は引き継ぐ。自然に現れる解だけでなく、原因を保って媒介を偽へ固定した解でも、同じ応答条件を評価する。そこで分類が欠ける場合を、態度が変化しなかった証拠に使わない。原因だけが結果を決め、態度の候補が連動するだけのモデルも排除する。

親文書の全宣言と先行21文を保存し、最後の部分注記を改訂した。二つの思考の発展の読みは選択肢として残し、同じ読み・本人・区間を残余条件まで保持する。著者への帰属はひな形の記述を渡すもので、引用内容の真偽を直接断定しない。

## 検証の範囲

103件のテストが通過した。有限診断では、三時点の入れ子の応答対象数64組合せ、対象交換、範囲の欠落・重複、順序、評価不足、未知入力を検査する。本文の診断には実際の `rcr` を使い、別人、別対象、自分の理解力を使わない判断、理由に支持されない判断、他者の指導、提示の欠如を区別する。媒介を強制した側だけに評価不足がある例、二つの発展の読み、偽の前件、残余条件の不成立も含む。

診断用の短絡評価と、純粋で外延的な解釈向けの関数再利用を明示的に使う。キャッシュなしとの照合は一般条件の基準例に限る。長形式・短縮形式・固有文字の往復、CLI解析、SVGのXML検査は、原文との意味一致や字形の目視確認を代替しない。

```powershell
python -X utf8 -m scripts.compose_reasoned_response
python -X utf8 -m pytest tests/test_reasoned_response.py -q
python -X utf8 -m scripts.check_reasoned_response --verify-only
python -X utf8 -m noema.constructed parse -i examples/v016/reasoned-response-core.noema
```

[意味規約](../data/reasoned-response-basis-v1.json)と[検査記録](../reports/reasoned-response-v1.json)に限界を残す。この候補は感情・欲求・習慣的行為・道徳的原則を尽くさず、有限の対象に対する強い包含拡大である。仮定場面の提示方法や難しさを比較できることは、解釈を与える側の前提として残る。新しい基本語として原文全体を包んだものでも、一般的な心理変化の定義を完了したものでもない。

[前段の資料確認](../data/mediator-reading-review-v1.json)も原文の唯一の読みを確定していない。媒介する変化の時刻、各人と民衆全体の対応、自然の比喩、自由の語義、政府の原則と尊厳は未完である。今回も原文文字範囲と意味確認済み区間を加算しない。
