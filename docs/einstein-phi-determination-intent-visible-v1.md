# 未知関数を決定する意図を円文字へ接続する

原刊901頁のu0092を、第48段落第一文の18トークンとして参照する。1–13は変換式に未知関数がなお残るという箇所、14–18は同じ関数をこれから決める意図の箇所である。先行する両立性の結論と、後続の第三系導入との順序を保つ。

既存の5定義を再利用する。現在の四変換式に現れる同じ関数φについて、先行段階と現在段階の双方で候補が複数残ることを記述する。対象域は同じ0≤v<Vであり、有効な現在候補を保持した上で、少なくとも一つの速度で異なる値を持つ候補を要求する。ある速度での一致だけで関数全体が決まったとはしない。前後の候補集合が同一だという条件も加えない。

決定する意図には既存規約zgmを公開名`presentsfunctiondeterminationintent`で使う。著者・関数の記述・段階・範囲・文脈をそれぞれ引数として保ち、決定済み、成功、一意解、方法の発見を含めない。現在段階は意図の箇所と閉じた役割から参照する。参照の取得や関数への言及は、役割の成立確認や関数の実行を意味しない。

共通375語と固定アルファベットを維持し、任意プロファイル54は789語となる。新しい参照型は追加しない。検査では復号した定義の本体を使い、有限の例化と、実関数全体の量化を拒否する境界を区別する。原文への逆投影、意味の対照検査、画像復号、描画点検はそれぞれ確認する。一般実数域の証明や第三者読解を完了したという意味ではない。
