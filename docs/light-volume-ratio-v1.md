# 同じ二体積の命名と体積比

原刊913頁のu0208–u0209は、直前の球と楕円体の体積をSとS′と名づけ、簡単な計算が示す比を提示する一文である。M0362は S′/S = √(1−(v/V)²)/(1−(v/V)cosφ)。平方根は分子にあり、比の向きも保存する。

ekpa/ekpbは、同じ物理部分zvaaの設定ekn7から、旧系と新系の体積を対象・値・状況の型付き規則として取り出す。ekpcが量記号へ結び、識別表記にS/S′を登録する。各規則には残余証人があるが、ekpeの比は一つの68設定に含まれる二体積を使う。独立に選んだ二対象の比ではない。

Sは旧系t=0の球内部、S′は新系τ=0の楕円体内部の体積である。既存ekl4が同じ物理部分と座標・領域を接続し、sedpが正の半径とπを持つ二つの断面積積分を指定する。新旧の零時刻を同じ出来事集合にしない。表面積へ読み替えない。

ekpdは同じ設定から二体積の積分とcosφ=aを取り出す計算前提、ekpeは同じ設定から印刷比を述べる帰結である。角の対応はekn7→eklp→eklf→eket→ekdqの既存条件から得る。積分からの D*S′=S、D=β(1−a v/V)、β=1/√(1−(v/V)²) により比を変形する。体積比を物理設定の前件へ加えて循環させない。

ekpfは引用した同じ前提から帰結まで、同じ利用可能な有限計算列が許容変形で接続し、その非負負担の総和が低いというs2yの内容である。原文の「簡単」を具体的な手数や閾値へ固定せず、実行済みログを補わない。ekpgは命名、帰結と容易性の著者主張、コロン、表示、順序、直前の楕円体への参照を結ぶ。

検査は比の向き、根号と余弦、正の体積、全63設定と量名の残余証人、計算列の始終点・途中接続・負担、表示と帰属を対照する。先行する積分の原始関数と端点の有理補題は既存の証拠を参照し、今回の補題は比への代数的変形を扱う。有限の有理π代用品は診断用であり、本文の積分的πの証明ではない。全実数・関数域を有限評価せず、積分論や原文の物理理論、意味同義性を自動証明したとはしない。

今回の範囲は二体積の命名と比の一文である。次のE/E′の命名とエネルギー比は含めない。
