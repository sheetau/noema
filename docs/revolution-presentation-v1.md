# 第五文の留保・譲歩・対比

第五文の二結果と後半予測へ、提示の仕方を接続する。構成と通読判断を分け、この段階の局所検査だけでは意味確認済み文字数を増やさない。

`vielleicht wohl` は、政治的離脱が生じる可能性を留保付きで認めるものと読む。[Dudenのvielleicht第一語義](https://www.duden.de/rechtschreibung/vielleicht_eventuell_circa)は成立の確実さを弱める用法、[wohl第五語義](https://www.duden.de/rechtschreibung/wohl_gut_besser_durchaus)はaberなどと組み合わさる限定的な承認である。この読みでは、wohlを高い数値確率へ変えず、vielleichtの限定を消さない。辞書は読みの補助であり、この歴史的文章に唯一の解釈を与える証明とはしない。

`r2rz/r2sa` は、既存 `r2qy` の構文から政治的離脱の可能性と改革経路の不在を取り出す。閉じた名前の照合と全候補の時間枠を両側に保持する。`r2sb/r2sc` は、既存 `r2qz` と同じ非空の公衆範囲・分類・全成員の確認を保つ。二内容の連言が元の主張と一致することを、複数候補、別の革命による改革、空範囲、入力不整合で検査する。

`r2sd` は同じ候補の革命が同じ公衆へ政治的離脱を生む結果族である。留保の関係 `h227t` へは、この結果族と可能性の限定 `r2rz` を分けて渡す。「可能性があるという主張が疑わしい」とする二重の様相にはせず、結果の成立を確言しない提示として扱う。失敗する候補が実在することまで付け加えない。

`r2sg` は、政治的離脱の可能性を認めつつ改革を否定する二内容を、既存の対比 `h222q` と一般的な譲歩の提示 `h227u` へ渡す。二つの箇所と同じ革命の帰結という観点 `r2se` を明示する。譲歩は第一の内容を無条件の事実へ強めず、通常予想の全候補で矛盾するという別の構成にも置き換えない。

`r2sh` は、改革の経路の不在から、新しい偏見の働きの予測へ `h227v` の訂正的提示を結ぶ。[sondernの語義](https://www.duden.de/rechtschreibung/sondern_jedoch_hingegen)に沿って、否定した見通しに代えて肯定する側を示す読みである。否定は維持し、政治的離脱の可能性を撤回しない。予測が否定の論理的な反対命題であることや、唯一の選択肢であることも要求しない。

`niemals` の既存の範囲は、公衆の改革と呼ぶ広がりを、固定したどの革命・候補も生まないというもの。一人の改善まで不可能とする読み、全時代・全世界への無制限な否定、革命以外による改革の否定は採らない。後半の予測は全ての同じ革命候補へ別に課す。

`r2si` は、前半の帰属、後半の予測・大衆の語調・Leitbandの描写、留保・譲歩・対比・訂正的提示、本文順序をまとめる。先頭62文と全ての既存定義を保持し、最後の未レビュー文62だけを置き換える。引用の検査では世界の内容を未知のままにし、必要な提示関係の欠落や参照の取り違えを一つずつ拒否する。
