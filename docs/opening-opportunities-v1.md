# 機会がある状態と、機会が新しく生じる変化

カントu0014の「いま彼らに、自ら自由に取り組む場が開かれる」という箇所へ、機会の成立前後と変化過程を加えた。従来の`hze4`は、現在の取り組みの機会を記述していた。今回の追加では、同じ人・活動について前の状態も評価し、以前からあった機会と新しく生じた機会を区別する。

| 定義 | 内容 |
| --- | --- |
| `rmo` | 同じ履歴で前後が順序をなし、対象者が非空で、各人の固定した活動候補が非空かつ前後とも評価済みである |
| `rmp` | 同じ人・活動の機会が、評価済みの前ではなく、後ではある |
| `rmq` | 全対象者に新しい機会が一つ以上生じる |
| `rmr` | 以前の機会を全対象者・全候補で保持し、少なくとも一人に新しい機会が生じる |
| `rms` | 全員に新しい機会が生じ、以前の機会も保持する |
| `rmt` | 全員の新しい機会に、同じ前後を結ぶ指定過程、変化を受ける本人、後端での過程の生起を結ぶ |
| `hzff` | 同じ規範源・役割・実行記述に対する`hze3`の機会内容を、人と活動に対応させる |
| `hzfg` / `hzfh` | この機会内容を新規成立と変化過程へ接続する |
| `hzfi` | 現在を後端とする機会の成立過程と、同じ人々の能力を尺度にする障害の漸減を結ぶ |

新しい機会が生じることと、選択肢全体が広がることは異なる。例えば、以前利用できた学習方法を失い、別の方法が新しく利用できるようになる場合、`rmq`は成立し得るが`rmr`は成立しない。また、一人の選択肢だけが増えても、全員への新しい機会を意味しない。人数や選択肢の総数だけに置き換えず、人と活動の同一性を保持する。この比較構造は、利用できる施設や提供されるサービスなど、機会内容を交換した別の題材にも使える。

候補活動は前後で固定する。前の状況が未評価であるだけなら、機会の不在を補って新規成立に数えない。実際の全選択肢を候補が網羅しているか、評価が現実に適切かは、対象範囲と意味入力に関する前提として残す。未知の評価入力は偽で補わず実行を拒否する。

原文への接続では、以前の全機会の保持を追加条件にしない。自由な自己作業への新しい機会を各人に要求し、その変化過程を既存の`ag`・`la`・`dg`へ結ぶ。別人の過程や、別の活動に割り当てた過程は流用しない。後端でその過程が生起することを要求するため、前後の差があるだけの場合や、過程の生起を過去にしか確認できない場合と区別する。受動表現から特定の行為者を推定しない。

この条件は、指定した過程と機会の状態差を結ぶ有限の前後モデルである。機会を生じさせた因果機構、区間内部の連続性、現在より後までの継続、進行形の全アスペクトを証明しない。以前の機会を両端で保持する`rmr`も、中間で一時的に使えなかった場合を除外しない。

実行記述には、既存の`hzez`で表した、同じ本人の能力獲得を目標にする自己作業を渡す。目標記述を引用するだけで、その目標が達成されたとはしない。機会の成立過程が現在あり、障害も減っている一方、本人は現在取り組んでおらず能力も未到達、という例を検査した。既存の「到達していないが進行条件がある」という回答へ、この新しい進行内容を接続できる。問答の引用は、その内容の評価を実行せず保持できる。

[一般文書](../examples/v014/opening-opportunities.noema)は2,265文字、[原文付き草案](../examples/v014/kant-opening-opportunities.noema)は181,439文字、[抽出文書](../examples/v014/opening-opportunities-core.noema)は18,771文字である。十定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。抽出文書には既存の問答・進行内容を接続する検査用の依存定義も含む。[意味規約](../data/kant-opening-opportunities-basis-v1.json)と[検査記録](../reports/opening-opportunities-v1.json)を保存する。

二人の前後状態16通り、評価不足と空範囲を検査した。原文付き文書と抽出文書で、基準例、以前から機会がある例、機会を失う例、未評価、過程なし、別人の過程、現在の生起なし、障害の漸減なしの八条件ずつを検査した。引用した問答の帰属も検査した。追加16テスト、三文書のCLI解析の構文木一致、固有文字v2のSVGのXML検査が通過した。SVGの目視確認は含めない。

今回の原文範囲は従来の部分草案と重なるため、草案の文字数範囲は増やさない。状態だけだった箇所に変化の条件を加えた進捗であり、同義性を確認し終えたという記録ではない。場の比喩、自由の全意味、実際の学習・能力獲得の過程、著者帰属と段落全体の意味確認は残る。
