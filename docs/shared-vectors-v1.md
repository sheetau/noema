# 成分列・ベクトル・アフィン条件を共有する

アインシュタイン正本の8定義を、依存名の変更だけで共有語と円文字へ接続した。辞書第16版は424語、401定義、23基本宣言であり、旧416語の意味・型・本体・綴りを保持する。このライブラリの宣言は全て構成定義で、新しい基本関係はない。

## 演算と比較を引数で指定する

| 共有語 | 内容 |
| --- | --- |
| vectorcomponents | 空でなく、同じ成分識別子を重複しない有限列 |
| vectorvalid | 選択した全成分が、指定した妥当性判定を満たす |
| vectorcompare | 選択した各成分の左右の値が、指定比較関係を満たす |
| vectorcombine | 同じ成分の左値・右値へ指定二項演算を適用する |
| vectoraffinevalue | 成分ごとの定数項から、行列の出力行・入力列と入力値の積を順に加算する |
| vectorequalincrement | 二出発点に同じ変位を与え、変換後の二増分を比較する |
| vectoruniform | 非空の対象域で、条件を満たす全出発点対・変位の増分を比較する |
| vectoraffine | 同じ行列・定数項を全対象入力で使い、変換結果を比較する |

値の型は有理数から真偽への関数である。型だけでは実数切断と決まらず、妥当性、比較、加算、差、積の意味は引数として指定する。実数の等号や体の法則を暗黙に補わない。物理的な軸・単位・測定条件も、成分の名前から自動推定しない。

vectoraffinevalueは演算を組み立てる関数であり、列の妥当性を自身では検査しない。空列なら定数項を返し、重複した成分は重複して集計する。vectoraffineでは非空・重複なしの列、定数項と全行列成分の有効性を要求する。行列と定数項は入力の全称量化の外側にあり、入力ごとに選び直すことはできない。

vectoruniformは、両移動先が対象域に残る有効な変位についての条件である。対象域が非空でも、有効な変位がなければ比較条件は空虚に成立する。対象域の全入力の妥当性やアフィン形を単独では保証しない。この条件から線形性・連続性・アフィン形を導く定理を追加したものではない。

## 原文と検証の対応

[対応記録](../data/einstein-vectors-correspondence-v1.json)はshm・shn・sho・shp・shq・shr・shs・shtを対象にする。元の型・本体・意味説明・本文使用箇所を保存し、以前の40宣言と合わせた48宣言の改名が正本全文で単射かつ逆変換可能であることを確認する。別の名前や引用を統合せず、正本・登録簿・意味判断を変更しない。

[保存SVG](../output/visible-vectors-v1/)から8定義と4質問を復号する。質問は空列・単一成分・重複・異なる二成分を扱い、1個体と2個体のモデルで答えを確認する。残りの定義も型と本体を含めて図形から復元する。

最初の26診断は、元のNativeの型と本体を使う。値として定数真・定数偽の関数を渡し、演算と比較を明示する。これは実数切断のモデルではなく、引数と成分の結合を調べる診断である。行列の転置、成分ごとの定数項、左右の演算順、列の順序・重複、入力と結果の有効性を区別する。

さらに値の型をtruthへ明示的に変えた有限モデルで、全称条件を調べる。二成分ならベクトルは4個であり、二出発点と変位の組合せは64通りになる。全対象を同じ行列で表す条件、空の対象域、非線形な変換、行列各位置と定数項各成分の不正値を20モデルで区別する。三つの入力で同じ行列に適合しても、四つ目で破れる例を含む。この有限モデルを全実数ベクトルや任意次元の証明とはしない。

元の数・関数領域を有限標本へ置換して評価することは拒否する。未選択成分を比較したと主張せず、比較関係に「常に真」を渡した場合も値の等号へ読み替えない。検査の範囲は[報告](../reports/shared-vectors-v1.json)、意味と役割は[規約](../data/shared-vectors-basis-v1.json)、綴りは[公開語形](../noema/resources/visible-vectors-vocabulary-v1.json)に保存する。
