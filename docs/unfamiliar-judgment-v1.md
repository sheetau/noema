# 活動の種類への不慣れと、判断への因果的寄与

カント第三段落の第四文にある、自由な運動への不慣れを理由とする部分を、知的活動側の条件骨格へ接続した。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)の対象側を「自分の理解力を他者の指導なしに使う判断活動に、経験に由来する慣れがない」と読む候補である。

## 不慣れの対象となる種類

前版の `r2gx` は、同じ本人・判断・課題・時点について、自分の理解力による、他者の指導なしの判断活動を表す。`r2he` はその課題を存在量化し、`r2hf` はその種類の判断活動があるという内容にする。特定の課題への同一性、理由の支持、遂行の不確かさを、活動の種類の条件に加えない。

これにより、前版の不確かな判断の同じ活動が、その種類に属する。別の課題であっても同じ種類の活動は成立しうる。一方、他者の指導による判断や、本人の理解力を使わない判断は、この種類には入らない。共有する性質をこのように定めるのは明示した読解候補であり、原文の種類照応の唯一の解釈ではない。

## 経験と現在の慣れ

`r2hg` は、既存 `rch` に同じ活動記述 `r2hf` を渡す。知的活動側の同じ仮定履歴で、本人の過去の経験、その同じ経験の現在への寄与、現在の反応の定着を要求する。`r2hh` は、同じ履歴が有効で評価時点を含むことを確認した上で、この経験由来の慣れが成立しない場合を表す。

経験の有無だけを述べる `r2hi` も分けた。経験があっても、現在への寄与や定着が失われていれば、不慣れは成立する。未来の経験、別人の経験、別の活動記述への経験、別の出来事の寄与を借りることはできない。履歴の欠落や未知入力を不慣れと判定することもない。

経験・寄与・定着は、活動の同じ記述を引用して受け取る。慣れを評価するために、その活動を現在実行する必要はない。既存の意味規約を再利用するため、新しい基本関係は追加していない。

## 理由付きの条件骨格

`r2hj` は、同じ本人・仮定終点で、不慣れ `r2hh` と不確かな判断 `r2hb` が成立し、前者が後者へ因果的に寄与することを要求する。両内容の真偽を確認した上で、同じ二記述を既存の因果関係 `hzie` へ渡す。併存や時間順序だけから原因を導かない。

対照用の `r2hk` は、同じ二内容を原因説明へ採用する既存の関係 `ea` を使う。`ea` の対象引数は要因と結果の主体で、説明者を指定する引数ではない。また、説明に採用されることだけでは、`hzie` の因果的寄与を満たさない。

`r2hl` と `r2hm` は、前版の依存離脱を前件、この理由付きの帰結を後件として、同じ人物・仮定集合へ結ぶ。前件を満たす仮定も少なくとも一つ必要になる。理由をその仮定内に置く読みであり、現実の提示時点にも不慣れが成立するという投射は追加しない。

## 検査と残る範囲

七テストで、活動種類と不確かさの8組合せ、経験・寄与・定着の8組合せ、内容の成立と因果・説明採用の16組合せ、条件文の16組合せを検査する。別人・別記述・別出来事・別時点の流用、未知入力、不正な履歴、前件が全候補で偽の場合も対照にする。

さらに、実際の離脱、判断、経験由来の慣れ、因果条件を同じ有限世界で実行する。経験はあるが現在の定着がない例を許し、慣れている例、因果関係がない例、別の記述を原因にした例、実際の判断や離脱がない例は、理由付き条件を満たさないことを確認する。原因説明への採用は、因果条件に追加しない。引用と三種類の表記の往復も検査する。有限モデルでの検査は、心理的因果の実証や原文との同義性の自動証明ではない。
