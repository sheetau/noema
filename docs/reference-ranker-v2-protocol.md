# 注釈済みの基本句範囲で学習する参照判定器v2

[正解位置の修正](corpus-reference-v2-correction.md)後の資料を使い、語彙ごとの出力クラスを増やさない共通判定器を学習し直す。原文を解析するKWJAの重みは固定し、プロンプト・生成・対訳辞書・語別補正を使わない。

## 候補と正解の対応

正解単位はKWDLCで注釈されている基本句全体の原文範囲とする。予測した基本句と正解の範囲が完全一致するときに対応付ける。主辞の位置・文字列・境界の重なりで一致へ補正しない。予測主辞の文脈ベクトルはモデルの特徴量として使うが、正解主辞のラベルを作るためには使わない。

保存済みのv1特徴のうち、原文・固定モデル・予測基本句・文脈ベクトル・照応スコアだけを再利用する。旧正解主辞・学習済みの重み・選択結果は使わない。全ファイルのハッシュに加え、文書ID・原文・関係ラベルと参照先ID・基本句ID順・特徴の主辞トークン位置を照合する。修正資料と旧資料で原文や関係が違う場合は停止する。

候補は以前の全予測基本句と「先行対象なし」。明示的な文書内同一参照だけを対象に、同じ正解対象のどの先行候補を選んでもよい周辺化損失を使う。句範囲が一致しない予測、正解先行句が全て欠けた予測、モード付き同一参照を持つ文書は損失から外し、件数を記録する。評価では欠落した句と参照を分母に残す。判定はargmaxで、閾値を探索しない。

## 固定する学習と検証

v1と同じ5個の数値特徴による線形方式と、文脈ベクトルを64次元へ射影する浅い方式を比較する。パラメーター数は6と115,201。seed17、AdamW、学習率0.001、重み減衰0.01、16文書バッチ、20エポックに固定する。公式train3,915文書で学習し、dev512文書の参照ペアF1、同率なら平均損失、先のエポック、線形方式の順で選択する。文書完全一致や失敗の内訳も報告するが、成績を見た後で選択条件を変更しない。

公式test700文書は既に旧実験で観察しているため、選択固定後の再評価を回帰確認として報告する。未使用の独立評価とは呼ばない。学習本文重複1文書を除いた集計も併記する。KWJA自体の学習資料にもKWDLCが含まれるため、未知の文章全般への成績とは扱わない。最終採用には別の未使用資料での確認が必要である。

保存した両重みのdev評価と、選択モデルのtest再評価を照合する。原文APIで先頭8文書を再推論し、保存特徴からの予測・候補確率との一致と反復一致を検査する。以前の手書き12文は固定した回帰確認だけに使う。生成・辞書禁止経路の呼出し数を記録する。全文意味構造95%以上・広い日英翻訳・逆変換・表記の冗長さの完成条件は維持する。
