# 速度合成の導入と点の運動の円文字表現

u0129–u0134の四つの既存主張を、見出し、点の平面運動の仮定、K系での運動を求める問い、第三節の変換を使う書換えとして接続する。既存39定義を再利用し、主題・定理としての論述・位置関数を求める課題・先行節の内容への参照に関する四規約を任意プロファイル62へ接続する。共通375語と固定アルファベットは維持する。

第六の見出しは第一部の第五節を案内し、第二部の直前までを範囲とする。見出し自体と節の参照を区別する。速度の合成を主題にすることは、通常の加算を主張することや、規則の存在・唯一性・証明の完了を主張することではない。

点の運動の設定は、同じ点、二つの系、同じ二つの符号付き定数、全期間の実際の位置関数を結び付ける。第三成分が零であることと、二成分の座標原点を通る条件を残す。期間の開始が零であるとは仮定せず、開始時刻を新しい座標原点にしない。点の速さには原文にない光速上限を加えない。

問いはK系での三軸とK時刻に対する位置関数を求める。答えの式を問いの定義へ挿入せず、答えの存在、一意性、発見済みであることも補わない。書換えの提示は、同じ設定と第三節の変換を前提とし、同じ出来事に属する両系の記録と元の式、結果の三式を接続する。共通分母、正の平方根、二系で異なる座標時刻を保持する。非零分母は採用した解釈の定義域として明示し、原文に印字された条件と区別する。負の分母を許し、分母が零であることだけで元の変換に合う記録を排除しない。

点の参照は二定数を存在量化した設定で選び、第一の定数は点を固定し第二の定数を存在量化した役割で選ぶ。第二の定数は、先に選んだ点と第一の定数を固定する。これにより参照の循環を避ける。参照取得は引用された役割を実行せず、存在・一意性や物理法則の成立を証明しない。

原刊905頁の第62段落は運動の仮定、三式、wobeiの定数説明を一文として扱う。第63段落は問いと書換えの二文とし、コロンに続く三式を後者に含める。点の導入と二つの数式表記の位置を別に保持する。

識別検査は、従来のモデルを円文字から復号した定義へ接続する。すべての引数の結合、追加の記録や区間内部での逸脱、符号と零、未知入力の拒否を確認する。関数型の存在証人は全域を有限列挙できないため、元の量化本体を照合し、証人を明示した結合診断と有限列挙の拒否を別に検査する。有限の診断を全実数域の証明や第三者の独立読解とは扱わない。実行結果と未完了の工程はプロジェクト台帳に記録する。
