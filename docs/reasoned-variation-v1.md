# 指示だけで決まる応答と、独立した判断の対比

カントの「人間は機械以上のもの」という句へ、外部からの指示だけに応答が限定されないという読解候補を接続した。同じ人・同じ論点について、同じ指示でも、本人が理由を吟味して異なる選択をできることを表す。数量として人間が機械より大きい、優れているという比較にはしていない。

同じ論説の[037頁16–26行](https://www.korpora.org/Kant/aa08/037.html)では、政府の目的へ受動的に向けられる役割を機構・機械の部分として述べ、公衆へ著作で語る立場では理性を使えるとする。[042頁1–2行](https://www.korpora.org/Kant/aa08/042.html)の対比を、この政治的な役割の文脈で読む候補とした。[読解記録](../data/reasoned-variation-reading-v1.json)に判断を保存した。物理的機械の一般定義や、あらゆる機械に理性がないという命題ではない。

`rym` は比較候補が非空で、同じ本人・論点について全て評価済みであることを検査する。`ryn` はその範囲で、同じ指示に対して必ず同じ選択をすることを表す。候補が少なければ理性的な人にもこの条件は成立するため、能力の欠如を意味しない。

`ryo` は同じ範囲の二状況について、指示が同じ、選択が異なる、双方に独立した判断がある、用いる理由の集合が異なることを要求する。返答が無作為に変わるだけでは成立しない。`ryn` とは両立しないが、二つは網羅的な二分法ではない。例えば選択だけが変わり、用いる理由が同じなら両方とも不成立になり得る。

本文側の `iaxindependent` は既存の `rcr` を使い、本人の理解力の使用、理由の支持、他人の指導によらない判断を結ぶ。さらに、その判断が同じ論点に関するもので、その同じ判断に基づく選択であることを確認する。別人の吟味や、別の論点について考えたことを借用しない。

`iaxbeyond` は、指定時点にそのような比較候補を持つ論点があることを要求する。候補状況は実行可能な事例という意味規約を持つが、指定時点で本人が実際に判断していることは要求しない。比較候補の妥当性や全機会の網羅性はこの構造だけでは証明できない。また、理由の違いだけが選択差を生んだという因果的な介入条件は加えていない。

新しい `iaxbeneficiaries` は、同じ政府役の主体・新政策・共同体・基準時で選んだ対象者を非空で完全に列挙し、その全員に政治的終点で `iaxbeyond` を要求する。原因側の民衆と政策で扱われる人々を勝手に同一化しない。`iaxschema` が既存の条件文の後件へこれを加え、残余条件の引数も保つ。最後の帰属だけを `iaxattribution` へ更新し、旧定義と先行21主張は保存した。

これは原文の強い操作的な読みである。同じ指示への応答差が必ず必要なのか、どの対象者を含めるか、機械という名詞の一般的な説明、尊厳に即した扱いとの接続は未完である。関係節を条件文の後件時点の資格として置いたが、補足的な関係節が条件文の外にも意味を及ぼす可能性は未解決である。「いま」を終点へ結んでも、以前は理性がなかったとは推定しない。

検証は、指示・選択・理由の組合せ、両側の独立判断、同じ本人・論点への束縛、政策と対象者の照合、実行を伴わない帰属を対象とする。新しい条件を親ひな形へ渡す検査では、親の型付きインターフェースを記録用の代替関数で評価した。従来の因果・自己利益モデル全体を再実行した検査とは区別する。

[本文点検v3](../reports/kant-manuscript-obligations-v3.json)では、この対比と先行する世話の描写が実際の帰属から参照されることを確認する。14項目は全て意味確認を継続中で、最後の帰属も八つの引数を残す部分ひな形である。原文の対応範囲と意味確認済み区間数は増やしていない。

成果物は[一般定義](../examples/v016/reasoned-variation.noema)、[抽出本文](../examples/v016/reasoned-variation-core.noema)、[改訂本文](../examples/v016/kant-reasoned-variation.noema)、[意味規約](../data/reasoned-variation-basis-v1.json)、[検証記録](../reports/reasoned-variation-v1.json)。再検証は `python -X utf8 -m pytest tests/test_reasoned_variation.py -q` と `python -X utf8 -m scripts.check_reasoned_variation --verify-only` で行う。
