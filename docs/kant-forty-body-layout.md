# 元ページの40項目へ複数枝と折返しを適用する

## 先行計画

元 kant-page の四段落・40項目と公開構文の対応は既にある。語義や参照先は変えず、保存された公開辞書を入力として複数枝配置と実図形復号を揃える。辞書は宣言と綴りを含む明示的な共通知識で、本文や期待する構文を含まない。本文専用 reader は途中で辞書の宣言を書き換えない。

第1・第2項目の保存済み複数枝図形は、対応する報告の構文・図形ハッシュを照合して利用する。他の項目は、現在要求されるイベント列と保存時の配置条件を比べる。同じ場合は図形を再利用し、異なる場合だけ描く。どの場合も円・線を現在の辞書で復号し、確認済み公開構文と一致することを確かめる。配置が枝を減らした箇所は隠さず残す。

各項目を独立した進捗・再開の単位にする。保存図形の復号、必要な描画、折返しの構文回収を確認する。全体の行数、円数、縮尺、文頭の反復、長い接続を元ページと比較する。一文ずつ段落にしてしまう暫定配置は完成候補ではない。項目間の連結、行末の余り、頁境界、共有辞書の提示と外観確認が残れば固定しない。

全歴史版の意味モデルや原典の意味判断を再実行しない。元の40項目との構文対応、語義・参照先の入力ハッシュ、実際の図形復号を今回の範囲とする。
