# 内部にいることと、移動を制限されること

カントの歩行器の描写に現れる閉じ込めについて、移動経路を制限する部分的な読みを追加した。装置の内部にいるという条件だけでは成立させず、同じ対象の同じ移動条件で、制限によって外への到達が失われることを要求する。歩行器の構造・用途や、閉じ込めの開始行為はまだ記述していない。

## 場所と通路から構成する

場所の有限列と、ある場所から別の場所へ一段階に移動できる関係を指定する。定義 `rad` は、零回以上の移動による到達関係を作る。列内の場所を一つずつ中間点へ加える操作を、既存の有限列と関数で書いた。通路専用の新しい演算子や「閉じ込め」という未説明の基本述語は追加していない。

各場所は、対象となる装置に対して内部・外部のいずれか、またはどちらでもない位置を持つ。境界を外部と取り違えないため、外部を内部の単なる否定にはしない。内部と外部が同時に成立する分類は拒否する。

定義 `rag` は次の条件を結ぶ。

1. 出発点が指定した場所の一つで、装置の内部にある。
2. 制限を外した通路では、外部へ到達する経路がある。
3. 制限の対象となる通路を除くと、外部へ到達する経路がなくなる。

例えば内部から境界を通って外部へ出る経路がある場合、最後の通路を閉じると条件を満たす。内部から外部への迂回路が残る場合は満たさない。初めから移動できない場合も、今回の比較からは制限による閉じ込めと判定しない。この条件は、元々動けない人を監禁する場合などを含む一般語義の全体ではない。

## 原文への接続と仮定

[原文の電子本文](https://www.korpora.org/Kant/aa08/035.html)では、歩行器内の閉じ込めを述べる関係節が、外への一歩を試みることと独りで歩くことの描写の間にある。この読みでは、身体的な移動の制限を、先行する自立的な活動への制約と対応させる。[読解記録](../data/confinement-reading-review-v1.json)に、確認した資料と解釈の範囲を記録した。

原文への接続 `q2` は、同じ制限・対象・装置・文脈を全関係に渡す。さらに、後見人集団内の人が参加する実際の行為が、その制限をその対象と装置へ適用していることを要求する。別の制限が閉じた通路や、別人への行為を借用して成立させない。

場所と通路を省いた図では、出口がないように見える。そこで、その対象・装置・制限について、指定範囲が必要な移動可能性を尽くすという前提 `q7` を別に要求する。これは記述者が明示する前提であり、コードが現実の全経路を確認する仕組みではない。連続空間、途中で変わる制限、姿勢や道具の変化を捨象してよいという証明も含まない。

| 定義 | 接続した内容 |
| --- | --- |
| `q2` | 移動制限の比較と、同じ制限を適用する行為 |
| `q3` | 監督される人が、自立的な活動の試みを制約されるという既存の対象側の読み |
| `q4` | 家畜としての描写と、対応する装置内の移動制限 |
| `q6` | `q3` と `q4` を内容を実行せず参照する、比喩の部分的な注記 |

本文の既存9主張は変更していない。`q6` も新しい独立した主張には加えていない。装置を識別するだけでは、その装置が歩行器であることを説明したことにならないため、歩行器の構造と用途、穏順さ、許可・機会・勇気、閉じ込めの開始と時間順序を未解決として残す。
