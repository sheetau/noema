# 同じ光のエネルギーと振動数を比較する

アインシュタイン1905年論文のu0214には、光の集合のエネルギーと振動数が、観測者の運動状態に対して同じ変換則に従うという記述がある。既存の`seck`は数値の条件を表していた。今回、その値を同じ光の集合、二つの基準系、観測者、量の種類、単位に結ぶ定義を追加した。

記録は仮定上の比較にも使える。原文が四つの実測を報告しているとは解釈せず、記録の存在や正確さを論文の事実へ補わない。追加したのは既存構文から作る3定義であり、新たな原始概念・局所参照・著者の主張文はない。

## 同じ倍率と、同じ対象

`seia`は、一つの値の記録を対象・量の種類・系・出来事・単位・正の尺度・文脈へ結ぶ。さらに、記録の観測者への帰属と、その観測者が当該系に静止する条件を要求する。

`seib`は、この記録を旧系と新系のエネルギー・振動数の計四つへ適用する。四記録の対象は同じ光の集合である。各系内では同じ観測者と出来事を使い、二系間では別でもよい。各記録の単位と尺度は独立に指定できる。二系の運動は、同じ光速度と符号付き相対速度を持つ標準配置の対応関係として与える。

`seic`は`seib`と、換算した値についての`seck`を同時に要求する。正の基準尺度で表した値をE、E′、ν、ν′とすると、条件は次の形になる。

```text
D = β(1 − a v/V)
E′ = D E
ν′ = D ν
```

Eとνの数値の等しさは要求しない。また、一つの光について同じ係数が使われることから、全ての光に共通するエネルギーと振動数の比例定数を導くこともない。

記録との対応と数値条件は別々に調べられる。数値の倍率が合っていても、振動数だけが別の光の記録なら`seib`と`seic`は成立しない。反対に、指定された記録の内容が変換式を満たさなければ、`seib`だけが成立する。「二つの比が等しい」だけでも足りず、その倍率が同じ速度・方向から決まるDと一致する必要がある。

## 検査

符号付き速度3通り、方向成分4通り、単位尺度2組の24設定で検査した。一組は全て尺度1、もう一組は四記録の尺度がそれぞれ2・3・5・7である。値をそれぞれ換算すれば同じ条件が成立する。

50対照例では、四記録それぞれの対象・種類・系・出来事・単位・文脈・観測者・単位の種類を変更した場合、同じ系や同じ量の種類を混ぜた場合、倍率を二乗した場合、振動数を変えなかった場合などを区別した。量の比は互いに一致するが指定の運動の倍率とは違う例も拒否する。比を扱うため、零エネルギーや零振動数はこの条件の対象外である。これは前版のエネルギーの問いが零を許すことと両立する。

読みの関係が未解釈なら検査器は停止する。未知の値の帰属を肯定したり、単に偽と判定したりして埋め合わせない。全文草案と依存定義だけを抽出した文書で同じ結果を確認し、二つの代用記法と32文字の固有表記について解析後の構造の往復も検査する。

実数演算の検査では登録した有理数切断の解釈を使う。これは全実数の演算法則や、全ての物理的設定での法則の成立の証明ではない。比較に用いる記録・単位・静止・系間運動の関係も、明示的に与えた有限モデルの解釈である。

## 残る課題と成果物

光の物理的同一性、エネルギーと通常の振動数の基礎的説明、光と方向の対応、単位の実現、エネルギー密度からの導出は残る。各系内で同じ出来事と観測者を用いるのは比較のための明示的な設定であり、原文の唯一の解釈とは認定しない。「注目すべきである」という著者の評価と、法則についての一般的な主張の接続も未完である。
