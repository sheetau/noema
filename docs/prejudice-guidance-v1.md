# 新旧の偏見による判断の方向付け

第五文後半の予測へ接続するために、新旧の偏見が同じ働きをする結果条件を構成する。[原文](https://korpora.org/Kant/aa08/036.html)の `eben sowohl als die alten` は、今回の読みでは働きの共通性であり、人数や影響の強度の完全一致ではない。

## 吟味しないまま判断の根拠にする

`r2rb` は、既存の偏見 `r2nz` の採用判断を明示したもの。内容を確定した原則として受け入れ、そのための十分な根拠を本人が吟味していないという条件を保持する。

`r2rc` は、その同じ採用判断を同じ本人の後続判断で理由として使うことを要求する。さらに、その意見をその後続判断の根拠にしてよいかを本人が吟味する判断がない。採用しただけ、別人が使っただけ、理由として挙げただけで後続判断が生起しない場合を区別する。理由の使用と、その理由が正当に判断を支持することは別なので、支持の妥当性を付け加えない。

`gedankenlos` には[Dudenの第一語義](https://www.duden.de/rechtschreibung/gedankenlos)に沿って吟味を伴わないという読みを採る。認知能力の欠如、意識がないこと、全生涯に思考がないことを意味させない。吟味が未知なら検査は未解釈として失敗し、記録がないだけで「吟味しない」とはしない。

## 新しさと働きの共通性

同じ集団・基準の全構成員で、古い複数の偏見による方向付けが広がっている状態と、新しい複数の偏見による方向付けが広がる状態を比較する。新しい意見群は、以前には確定した原則として広く採用されていないものとする。以前に十分な吟味をして採用していた人も、既存の採用として数える。

新旧で内容の実質的な違いを要求し、単なる改名を新しい偏見としない。新旧の各項は少なくとも一人に実際に働き、列に使われない名前を加えて複数形を満たすことも許さない。意見ごとの受け手は異なってよく、全員が全意見を採用する必要はない。

古い偏見が後にも残る場合を許す。新しい意見を誰かが初めて発明したことや、全員にとって初耳であることも要求しない。新旧で共通にするのは、未吟味の原則が後続判断の根拠として使われる働きである。

`r2rk` は、第二文で指した大衆とその人数条件を再利用する。公衆の想定読者と大衆を同一にせず、別集団の状態を比較に流用しない。

## 残る接続

これは後半の対象側の結果条件であり、未来予測そのものの帰属ではない。新旧の意見群・時点の文脈供給、革命候補の中での量化、Leitbandの身体的描写と対応、低く扱う呼称、前半の留保・対比、一文の通読を続ける。既存62文と13区間の意味判断、先頭四文771非空白文字の確認を保持する。
