# 三つの役職者の命令

カント第五段落u0012の第三〜五文 `[274,426)` を、将校・財務担当官・聖職者による呼び声の具体例として構成した。既存の禁止・教練・支払い・信仰の内容に、役割を持つ同じ話者、発話、複数宛先、代替の提示、著者への帰属を接続する。三文134非空白文字の通読判断は [reading](../data/role-commands-reading-v1.json)、実行検査は [report](../reports/role-commands-v1.json) に置く。

## 採用した読み

三つの単数役職名は、著者が社会的な方面を代表させて提示する人物例と読む。各職の全員がこの発言をするという全称命題、世界に一人しかいない人物という唯一性、実在する発言の日時・記録を補わない。著者が語る場面の中で、役割を持つ話者とその呼び声を要求する。

将校・財務担当官には、既存の役職保持 `hzwn` と有効な制度的任用 `hzxf` を用いる。同じ役職と機関でなければ結合できない。将校は軍事組織における将校の任官階級の保持者とし、単に号令を発した人や武器を持つ人では足りない。財務担当官は公的な収入管理を担当する参事・官吏とする。[AdelungのKämmerer第三義](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_6_0_208) は、領邦の収入管理に関連してFinanz-Räthe等の呼称を挙げる。徴税窓口の人や現代の財務大臣へ一意に置き換えない。[DudenのOffizier](https://www.duden.de/rechtschreibung/Offizier) は階級の保持者という語義の確認に用い、現代の階級表を当時の制度へ転用しない。制度領域と役職分類は意味規約に残る語彙的関係であり、軍制・行政の全概念を物理的な関係まで定義展開したという主張ではない。

聖職者には既存 `sp` を用い、継続的な宗教上の援助、役割の主要な務め、共同体による任用、公的な宗教奉仕の責務を保持する。単に信仰を持つ人とは区別する。現在の活動・能力・本人の信仰、特定教派の叙任儀礼は付けない。

三文とも、[前文の「聞こえる呼び声」](heard-prohibition-v1.md) の具体例として同じ `r2tc` に接続する。軍務・財務・宗教の方面と役職者と命令内容をそれぞれ対応づける。後二文のコロンにも省略された `sagt` を補い、単なる引用文の一覧にしない。三人が必ず別人であること、方面が互いに排他的であること、三方面以外がないことは要求しない。

`nicht ... sondern ...` は、同じ宛先に検討の不実行と肯定的な行動を求め、後者を前者で退ける活動に代えて行うものとして提示する。連言の命令内容 `r2tj` に、同じ話者・呼び声・宛先の代替提示 `h233h` を加えた。内容の論理的矛盾や時間的順序には置き換えない。教練・指定取引への支払い・教えの内容への非事実的な信念は、[前の内容構成](command-alternatives-v1.md) の解釈を保持する。

役職者の構成、三種類の発話と代替提示、帰属と引用をNoemaで実評価する。方面と役職者を探索する外側の検査では、別に検査した発話 `r2tq`、新しい二役割、既存の聖職者 `sp` を境界に置き、受け渡す全引数を検査する。巨大な宗教的援助・発話構成を全人物組合せで反復評価しない。この検査の境界を報告に明記し、`sp` の既存定義と意味規約が変化していないことも検証する。

命令の提示と著者による引用の検査では、実行・信念・教義の真理・正当な義務の入力は未知のままでよい。必要な発話・知覚・代替提示の入力が未知の場合は拒否する。旧65主張・14区間の意味判断・第五段落先頭二文232文字の判断を依存ハッシュごと保持し、新たに三主張を追加する。表記の往復変換も検査する。
