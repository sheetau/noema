# 全臣民への立法に関する公的使用の許可

第九段落第二文の許可を、同じ統治者の全臣民について三つの対象に結ぶ。立法に関する公的理性使用一般、改善についての思想の公表、既に与えられた法への率直な批判を伴う思想の公表である。一般の使用を、現在持っている肯定判断の発表だけへ狭めず、問い・検討・留保も扱う。同じ公的活動で自分の理解力を用いる実行内容を許可へ渡す。

思想列と批判列は任意の有限列を量化する。批判の評価条件も、型の合う全ての閉じたNoema関数記述を扱う。各発表の活動、公衆、法の人民、比較元法、定式、評価観点を固定の標本に狭めない。本人が現在既にその見解を持つこと、実際に公表したこと、内容が真であること、現在許可されていることを、候補資格へ追加しない。

全臣民の集団は同じ統治者・共同体の臣民と過不足なく一致し、非空である。法の名宛人としての人民は候補ごとに量化するので、臣民集団と同一視しない。許可の出所は三対象とも同じ統治者であり、別の規範源から許可を借りない。積極的許可と反対要求の不在を要求し、物理的な無妨害や実際の実行は別に保つ。

候補比較の起点、制定済み法の履歴、内容の固定基準は政策へ保持する。許可を評価する点と、将来の発表を試す候補点を区別する。同じ内容の引用を候補資格と許可の両方に使い、思想のみへの許可から批判付きへの許可を推論しない。全体を閉じた方針内容として構成し、続く危険と洞察の記述へ接続できるようにする。

検査は下位の公的使用と規範関係、引用した目標と引数の一致、全候補・全臣民の量化を分ける。無限にある有限列と閉じたコードの全域を有限評価器で検査済みとはしない。診断用の標本への置換箇所を明記し、元の全域が拒否されることも確かめる。候補範囲の現実の網羅性は意味規約の責任である。国家元首の思考態度と啓蒙への照応、拡張、危険と洞察、実例、sogar等の談話関係、全文帰属と通読は未接続である。
