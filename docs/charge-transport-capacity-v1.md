# 電流の実現と通過能力

導体という種類の記述には、現在の電流とは別に、電荷が物体に対して移動できる性質が必要になる。[OpenStaxの静電平衡の説明](https://openstax.org/books/college-physics-2e/pages/18-7-conductors-and-electric-fields-in-static-equilibrium)は、動き得る電荷を持つ導体が平衡に達する場合を説明している。[抵抗率の説明](https://openstax.org/books/university-physics-volume-2/pages/9-3-resistivity-and-resistance)では応答の大きさに材料の性質が関係し、単純な比例関係には適用範囲がある。これらを2026-10-23に参照し、現在の非零電流や普遍的なOhm則を導体の定義にしない。

eibkは符号付き率の絶対値が非負の閾値を超える条件である。eiblは、その応答値を完全な断面電流履歴と、同じ断面・向き・区間内時刻へ結ぶ。eibmはこのような証人の存在を表す。一時刻での超過であり、全区間の持続や全断面の成功を述べない。

eirkは、元の状況で同じ物体の構成を保つ許容試行を指定する基礎関係である。破壊や別物質への変質を、元の物体がもともと持つ能力の成功例へ混入しない。結果の物理的可能性には、既存のzrdpossibleを再利用する。この関係自体は一般の対象・操作・元状況・可能結果を結ぶもので、旧来の電荷追加能力で使った点状理想化や電荷追加を今回の条件には含めない。

eibnは許容試行・可能な結果・その結果での通過応答を同じ物体に結ぶ。eiboは成功する操作と可能結果が存在するという能力である。現在の電流を要求せず、成功する全結果の保証も要求しない。元状況・操作・結果ごとの系・区間・断面・累積量・電流は同じ三引数で関数族から選ぶ。別の操作の応答や別の物体の成功例を流用しない。

eibpは二場合の比較eibjに、同じ右側物体の各元状況での能力を結ぶ。同じ閾値・単位と許容試行規約を使い、成功する操作は各場合で別でもよい。二場合の能力と実際に比較する電流履歴は別の条件である。

この能力を導体一般の定義として確定したわけではない。微小な漏れ、応答時間、作用の強さ、幾何学的な配置をどう扱うかには適切な試行と基準の選択が必要である。零閾値も表せるが、その場合は非零という条件だけで漏れと通常の導電を分けられない。原文には数値閾値がないため、任意の数値を補って語義確認を済ませない。次は電気的作用と担体の移動の意味へ接続し、例示の導体に採る読みを判断する。

検査は正負・零と閾値、完全な履歴への接続、許容試行と可能結果の区別、元状況で電流がなくても能力を持つ場合、実際の成功だけでは能力条件を満たさない場合、操作・物体・状況の結合を確認する。全実数時刻の存在は有限時刻で代用しない。既存207主張と原文の意味判断を保持する。
