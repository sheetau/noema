# 現況の割合と、状況を変えて保たれる頻度

観測した事例の多数で成立すること、通常とみなす場合すべてで成立すること、比較状況を変えても多数で成立することを区別する一般構成を追加した。現行カント本文の置換はまだ行わない。どの比較状況を採るかを指定せずに、現況の割合から一般的な傾向まで確定できないためである。

Cohenの論文第4節は、明示的な頻度表現と無修飾の一般文を区別し、現況での偶然の一致だけでは説明できない一般化も論じている。通常の個体だけへの量化を頻度副詞全般へ流用する問題も指摘する。このため、既存の頻度構成を既存の通常性構成へ単に交換する方針は採らない。今回の二段階構成自体を同論文の提案とはしない。[Ariel Cohen, Genericity (2002)](https://tzin.bgu.ac.il/~arikc/gen.pdf)

`r2bd`は、基準文脈、比較状況の範囲、その範囲の通常性順序、状況ごとの事例列・適格性・応答・網羅性、割合の基準を引数に取る。外側では既存`rqt4`で非空の通常候補を選び、内側では各候補の事例について既存`r7`で過半数と文脈基準を評価する。例外の事例を消さず、比較状況間で件数を合算しない。割合基準は基準文脈に固定する。

たとえば、比較する各状況で三例中二例が応答する場合、全例が応答するという条件は偽だが、頻度が保たれる条件は真になる。現況が三例中三例でも、同等に通常な比較状況で三例中一例なら、頻度が保たれるとはしない。現況の成否を比較状況の成否へコピーする規則はない。

比較状況の選択と通常性は別の入力である。成功した状況を優先することで結論を作るのは、この意味規約に反する。どの事情を変えてよいか、どの背景を保つかを実例に即して説明する必要がある。有限の等重み事例という内側の制約は残り、無限母集団の測度や連続確率分布を実装したものではない。

検査では、現況と比較状況それぞれの成功数を変えた16組合せを独立した計数と照合する。順序、空範囲、例外の除去、重複、不適格な事例、比較不能な失敗、劣後する例外、循環、基準の取り違えを13対照で確認する。七種類の未知入力は確定しない。

原文側では、現在の`hzud`と、実際の`gw`・`hzuc`を渡した比較条件を一緒に実行する。失敗経験・認識・恐れ・回避理由・原因を検査用の単一述語へ置換しない。現況と比較状況での成立は四組合せすべてに分かれ、現行`hzud`だけでは比較状況での傾向は保証されない。さらに六対照と四種類の未知入力を検査する。

これは原著者の主張の真理や、`gemeiniglich`の唯一の語義を証明する検査ではない。原文に適した比較条件、無修飾の「萎縮させる」の量化、有限事例による範囲の妥当性は残る。一方、数値なしの通常性へ交換すれば解決する、という方針は反例により退けられた。

一つの一般定義を追加し、新しい意味の基本関係は増やさない。本文52文、意味確認済み十一単位、原文の対応文字数を維持する。検査用の宣言は解釈モデルの入力であり、カント本文の新しい語彙には登録しない。長形式・短縮形式・固有文字の往復も確認する。
