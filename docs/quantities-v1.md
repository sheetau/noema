# 次元・量の種類・単位尺度

βの式へ値だけを渡す形では、速度と長さを混ぜたり、異なる単位の読みをそのまま割ったりする誤りを防げない。[量と単位の定義](../examples/v011/quantities.noema)では、次元・量の種類・単位尺度を明示し、適合条件をNoemaの式で記述した。18定義を追加し、実数の定義と既存の尺度・原点変更の2定義を合わせて、4基本演算と42定義からなる。

これは意味上の条件を表すライブラリである。例えば次元の異なる値をdjへ渡した式自体は構文解析できるが、換算関係は成立しない。構文パーサーが自動的に現実の単位を推定・修正する機能ではない。

## 次元を合成する

次元は、基底軸の識別子aから有理数の指数bへの関数`h[a] b`で表す。長さの次元なら長さ軸が1、他は0であり、速度なら長さ軸が1、時間軸が−1となる。基底軸の個数や名称を文法に固定せず、使用する体系を文書側で指定する。

| 定義 | 意味 |
| --- | --- |
| da | 全ての指数が0の次元 |
| db / dc / dd | 次元の積／逆／商 |
| de | 有理数乗による次元の指数変更 |
| df / dg | 次元の同一性／無次元条件 |
| dh | 一つの基底軸だけ指数1、他は0という基底次元の特徴付け |

積は指数の加算、商は減算、冪は指数への乗算で定義する。長さ/時間に時間を掛ければ長さとなる。同じ次元同士の商は無次元となるが、それだけで量の種類まで決まるわけではない。平方根に対応する指数の半減を表せても、元の値に平方根が存在するかは別に検査する。

例えばdhは、基本記号で与えた関数を、指定軸で1・他軸で0と完全に特徴付ける。このため、基底次元の意味を単なる名前の登録に任せない。ただし、指定軸が物理的な「長さ」や「時間」を指す根拠は別の意味規約である。

関数型そのものは任意の軸への有理数指数を許す。物理的に使う有限の基底体系は明示する必要があり、全ての関数値が現実に採用する物理的な次元だとは主張しない。

## 次元と種類を分ける

同じ種類の量は同じ次元を持つが、同じ次元だから同じ種類とは限らない。この区別は計量の国際用語集でも明示されている。[VIM 1.7](https://jcgm.bipm.org/vim/en/1.7.html)

diは、二つの量の種類が同じこと、次元が同じこと、双方の単位尺度が正であることを要求する。異なる無次元の量同士などを、次元の一致だけで換算しない。種類の識別子と物理的な意味との対応は、文書側の定義・解釈に残る。

## 単位換算

単位尺度は「その単位1つが基準単位の何倍か」を表す正の有理数である。値に尺度を掛けて、基準単位へ換算する。

```text
左の読み × 左の単位尺度 = 右の読み × 右の単位尺度
```

djは有理数の読みについて、この等式とdiの条件を合わせた関係である。dkは実切断の読みを同じように比較する。単位名の対訳辞書は持たず、例えば尺度5/18と1を明示すれば、読み36と10の換算を検査できる。元の読みだけを36と10として比較する誤りや、尺度の向きを取り違える誤りを区別する。

dlは量の積、dmは商を有理数の読みについて記述する。結果の次元が正しいことと、基準単位へ換算した値の関係を要求する。商の分母は非零でなければならない。結果の量の種類を次元だけから自動決定しない。

ここでは乗法的な単位尺度を扱う。無理数の尺度、原点の異なる座標、対数で表す量の換算は別の理論が必要である。以前の座標変更bkは保持するが、原点の加算をdj/dkの単位換算として認めてはいない。

## βへ適用する

dnは、長さ軸と時間軸が異なること、長さ・時間の次元がdhを満たすこと、二つの速度が同じ種類かつ長さ/時間の次元を持つこと、係数が無次元であることを要求する。長さの読みを速度として渡す場合や、係数に時間次元を与える場合は成立しない。

dpは、二つの速度と係数を、それぞれの単位尺度で換算して、前回の有理数のβ条件cmへ渡す。doはdnとdpを合わせ、dqは実切断に対してdnと元のβ関係clを合わせる。各読みの尺度は同一である必要はない。

検査例では、速度3・光速度5・係数5/4という仮定の値を使う。速度だけを尺度5/18、読み54/5へ変更しても同じ結果となる。係数を尺度1/100、読み125と記述する場合も同じである。これらは換算の確認用の数値であり、現実の光速度が5であるという主張ではない。

さらに全有理数を対象に、両速度の尺度を同じ正の倍率で変えてもβ条件が変わらないこと、読みと尺度を同じ量になるよう変更しても条件が変わらないことを多項式で検証した。共通の値を加える操作は、単位尺度の変更ではなく、同じβ条件を一般に保たない。

この文書は前回の数式M0136への接続を補強する追加の意味条件である。単位の検査式を原文に存在する新しい主張として扱わない。同じ種類・次元であることだけでは、同じ対象・出来事・基準系の測定であるとは分からないため、観測関係への接続はなお必要である。
