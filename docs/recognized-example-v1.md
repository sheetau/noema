# 認識した先行例と、その経験者

カント第二段落の末尾で、「そのような一例」を直前の転倒経験の種類へ結び付けた。既存の知的な不成功例の記述を保持し、同じ事例の身体的な描写を後続する萎縮節に追加する。学習節にある転倒の提示だけでは、別の節でどの例を受けるかまで明示できていなかった。

[原文36頁](https://korpora.org/Kant/aa08/036.html)では、転倒を通じて歩行を学ぶ見込みに続いて、この種の例が人を萎縮させると述べている。今回はその例を先行する転倒の種類を受けるものとして読む。これは明記した採用読解であり、原著者の意図を一意に証明したものではない。

一般構成`r2ba`は、例を認識する人、例、評価時点を固定し、同じ例の先行時点に、指定した範囲の経験者について経験内容が成立することを要求する。認識・時点・先行・経験者の範囲・経験内容は引数で渡す。このため、対象者自身の経験も他人の経験も扱え、直接目撃に限定しない。一つの例を指定することから、それ以外の例の不在も推論しない。

本文の`r2bb`はこの構成へ既存の転倒経験`hzum`を渡す。認識された例とは別の出来事で誰かが転んだだけでは成立しない。`r2bc`は、同じ事例の知的な失敗例`gr`をこの身体側の例で描く提示を、萎縮節`g2`へ帰属させる。学習節の提示や単なる転倒の記述では代用できない。引用した内容の真偽や、実際の身体転倒は帰属の成立条件にしない。

三定義と本文一文を追加し、基本関係は増やさない。既存51文とその定義を保持する。一般構成は単独のNoema文書としても保存する。

検査では一般構成の16組合せと8対照、原文の既存定義を用いる二内容の独立な4組合せと18対照、帰属の7対照を評価する。本人と経験者の同一・不同、別の例、別の認識時点、先行条件、結果の欠落、別人の転倒、制御した下降を区別する。未知入力は確定しない。既存の失敗と転倒の定義を検査用の基本関係で置き換えずに評価する。三文書について長形式・短縮形式・固有文字の往復を確認し、十一単位と先頭六文1,021文字の意味判断の依存関係を保持する。

原文のこの範囲は既に部分草案へ対応しているため、新しい対応文字数はゼロ。架空の例、通常性を有限の等重み事例で扱う読み、萎縮の程度、見込みの様相、末尾一文と段落全体の意味判断は未完である。この追加を完成率の増加とは数えない。
