# 同じ電子に対する別の加速度規約

u0259は、力・加速度の定義を変えれば質量数値も変わり、電子運動の理論を比べる際には非常に慎重でなければならないと述べる。旧草案seqg/seqhには数値比較、seqk–seqoには比較上の要求があるが、現在の電子の実際の量との接続と、仮定的な比較範囲・慎重さの程度の説明が残っている。

この依存群では、先行する同じ物理設定から構成できる別規約を接続する。元はkでの力とKでの加速度を使う。変更例は、力を同じkのεE′へ保ち、加速度もkの実座標時刻二階微分にする。量の単位、低速質量μ、電荷、出来事、力の記録を共有し、別の粒子や新しい軌道へ交換しない。変更を採用する仮定文脈だけを別に渡す。

新しい加速度は、以前に構成した同じkの軌道とτ微分から取る。先行の加速度変換a′x=β³ax、a′y=β²ay、a′z=β²azとkの初期運動式が成り立つなら、変更規約の二係数はμ,μになる。正のμと0<v<Vでは、元のμβ³,μβ²と異なる。v=0では一致する。単位の換算ではなく、加速度を定義する系を変更した例である。

endは全ての有効な三加速度・三力についての係数恒等条件、eneはその明示形である。現在の零加速度の一例だけから質量を決めない。enfはさらに、数値評価を正の一定倍率で変えるときの係数対応を記述する純粋な代数関係である。力と加速度を同率で変えれば係数が保たれる場合を許す。この任意倍率の診断を、任意の倍率が実現可能な物理的定義だという認定にしない。

検査では実k加速度の各成分、力の各成分、元と変更後の規約の系・対象・出来事・単位・文脈、条件文と全係数の共有を区別する。全称本体の引数契約を独立に比較した後、各束縛位置を小さな域で検査する。全実数域の証明と有限診断を分け、未知の入力を拒否する。

これは原文が明示しない別規約の具体例であり、u0259の一般的な条件文をこの一例へ縮めない。全文判断には、結果に依存しない関連する別定義の範囲、Natürlichの提示、電子運動の理論という比較対象、非常に慎重に進めるべきという要求とその推論帰属を接続する必要がある。既存426主張と261全単位判断を維持し、今回の依存群だけでは完成件数を増やさない。
