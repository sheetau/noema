# 任意形状の寸法と光速への極限

アインシュタイン§4の `u0116` と `u0117` を部分記述した。球面に限定せず、三座標を受け取る任意の条件を形状として渡し、同じ物体の表面と観測記録に結ぶ。寸法は座標の射影の上限と下限の差から定義し、光速への極限と光速での通常の変換を分けた。

```text
物体の静止系の形: S(ξ,η,ζ)
観測系の時刻tでの形: S(β*(x-v*t),y,z)
縮小率f(v): √(1-(v/V)²), |v|<V
同じ観測時刻の座標差: Δx=f(v)*Δξ, Δy=Δη, Δz=Δζ
有限幅が存在するとき: Lx=f(v)*Lξ, Ly=Lη, Lz=Lζ
```

`stv` は形状の条件へ座標を代入する関数である。球面性、連結性、端点の存在は要求しない。`sua` は物体が指定系で静止し、形状条件と物理的な表面の所属が、その系の全測定記録で一致することを表す。`sub` は観測系の指定時刻に同じ条件を課す。`sue` は両系の全出来事の記録、座標変換、物体の運動と単位、選んだ時刻の非空の表面を要求し、`suf` はこの前提から観測時刻の形への条件付き帰結を表す。

有限の検査には、z=0上でxが[−5,−2]または[3,5]、yが[0,2]にある二つの長方形の面を使った。この形状はNoemaの論理式で定義している。別の物体、表面に含まれない点、欠けた測定記録、異なる時刻、物体の静止や運動条件の欠落を区別した。ただし、測定記録と物理的な表面の関係は検査で外部解釈を与えている。有限の記録から連続空間の全位置を検証したとはしない。

`suc` と `sud` は同じ観測時刻の二記録と、それぞれに対応する物体静止系の記録から、三方向の座標差の関係を記述する。物体静止系の二時刻が等しいという条件は追加しない。V=5、v=3の例では、観測側で同時の両端が静止側では3/5と−3/5になる。時刻の異なる観測を混ぜた場合は、同時測定の条件を満たさない。

寸法の定義では、三軸を区別した射影 `sui` を作り、その非空集合の上限と下限を `suj` で指定する。単に全点を囲む値ではなく、最小の上界と最大の下界を要求する。`suk` がその差を幅とするため、開区間にも適用できる。空集合や無限に広がる集合に有限幅を与えない。`sul` は変換前後の幅が定義される場合の関係、`suv` はこれを任意の形状と時刻について述べる内容である。

上下限の定義そのものを有理数に特殊化し、開区間、単一点、不連続な二区間、変換後の開区間で検査した。余分に広い上下界、空集合、上に有界でない集合は受理しない。この検査は有理数の線形な例であり、実切断全域の完全性や、任意形状についての上限・下限の変換定理を機械的に証明したものではない。

逆の系から見る帰結では、観測する系と物体が静止する系を交換し、速度を−vにする。同じ物体を両系で同時に静止させる条件にはしない。`suu` は、この逆向きの形状変換と三軸の幅の関係を合わせる。向きに依存せず速さが大きいほど縮小率が小さいという比較も、速度の二乗を使って `sus` と `sut` に記述した。

原文のv=Vで平面状になるという記述は、正の有限な縦幅Lに対して、vが下側からVへ近づくとL*f(v)が零へ近づくという追加解釈で接続した。`sup` は集積条件に加え、全ての正の精度εについて正の近傍δを選ぶ量化を含む。光速そのものは定義域に含めない。近傍の候補 `sun` は次の式である。

```text
δ = V*ε² / (2*(L²+ε²))
0≤v<V かつ V-v<δ なら L*f(v)<ε
```

この条件を有理数の多項式の補題として検査し、候補の実切断表現の計算も確認した。全ての実切断への量化を有限モデルで評価しようとした場合は拒否する。精度によらない固定近傍で十分とする誤った主張には反例がある。平面集合への位相的な収束や、無限に大きい物体も含めた一様な収束を、この縦幅の極限で証明したとは扱わない。

光速以上の速さには通常の変換条件を満たす有限βがないという内容も分けた。これは本文の「議論が無意味になる」という留保の一部分である。後続で光速が無限大速度の物理的役割を果たすという予告は未記述であり、今回の原文範囲の集計から除いた。
