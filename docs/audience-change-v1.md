# 想定読者の範囲と能力変化

構成員の固定リストを必要とする能力変化の構成を、宛先と基準文脈に結び付く範囲の述語へ一般化した。既存の`h6t`が表す想定読者の範囲を使い、その内部で誰の能力が変わったかを記述する。実際に受領した人の一覧や、変化に成功した人だけの範囲へ置き換えない。

`rqsz`は、指定した対象・基準文脈の範囲に入る全個体が適格かを調べる。列の長さや重複検査は要らない。この検査だけでは非空性を要求しないが、能力変化には異なる内部の当事者と対象者が必要であり、集団的な広がりには非空の変化範囲を要求する。

`hzmx`は、一人についての能力変化を既存の`rda`へ接続する。旧`h6b`から変えたのは、範囲の適格性の確認と、内部の当事者・対象者を選ぶ範囲の二点だけである。対象者の履歴、開始点と終了点、評価の基準時、能力の前後評価、結果側での自立性、対象者への作用、活動部分、内部の人の参加、結果生成の因果条件は保つ。

`hzmy`は、同じ過程・前後時点・基準文脈で`hzmx`を満たす人の範囲を作り、前段の`rqsw`の広がり基準へ渡す。`hzmz`は範囲関係に既存の`h6t`を指定する。比較中は同じ宛先と同じ基準文脈を使うため、途中の時点で成功者だけへ範囲を狭めても「全員が変わった」という判定へ変わらない。別の基準文脈を指定すれば、その文脈での範囲を記述できるが、加入・離脱自体の説明は別途必要である。

## 旧構成との整合性と対照

一般形では、範囲に入るかと適格であるかの16組合せを検査し、問い合わせる対象と基準文脈が共通であることも確認する。

能力変化の定義を実行する22対照では、一人・複数人・全員、別の宛先や基準時、集団外の変化、別過程・別時点の変化、すでに能力を持っていた人、因果や内部関与の欠落を扱う。三人が全員変わっていても、受領記録を持たない四人目が想定読者の範囲に入っていれば、その四人全員の変化とは認定しない。範囲に人でない対象を混ぜた場合は、黙ってその対象を除外せず不成立とする。範囲、適格性、能力評価、広がり基準が未知の場合も推測しない。

旧リストが人を重複なく表し、同じ基準時の範囲と一致する場合、旧構成と新構成の一人以上・複数人・全員の結果が一致することを検査する。旧リストに同じ人が重複する例では、旧構成は不正なリストとして拒否する。一方、同じ人を二重に含めることのない述語の範囲は、それだけで不正にならない。この違いを互換性の条件から隠さない。

新しい接続の依存先に`mp`、受領の`h6e`、発話理解の`h6g`、取得条件側の読者範囲`h6n`がないことを確認する。旧構成との比較以外では、それらの解釈を利用不能にしても検査できる。元の能力変化の式を基本関係へ置き換えずに実行し、具体的な一人の証拠はメモ化なしでも同じ結果を得る。集団範囲の多重の存在量化にはメモ化を使い、保存した式の短絡変換は行わない。

構造の検査では、変更した二つの範囲指定だけを旧指定へ戻し、束縛変数の名前を正規化した宣言全体が`h6b`と一致することを確かめる。列依存を外す際に、履歴や因果の条件まで弱めていないことを、この照合と実行例の両方で調べる。

## 公衆について残る内容

想定読者の範囲へ接続したことだけでは、その宛先が公衆として適切かは確定しない。既存の`ce`は読者世界全体としての公衆を表すため、原文の「ある公衆」を無条件にその全体と同一視する条件は加えていない。公開性の社会的な条件、公開された議論、理性的な自己評価や自ら考える態度の普及、適切な広がりの基準は引き続き必要である。

語法は有限列を要求しないが、今回実行したモデルの領域は有限である。無限の読者範囲を列挙・実行検証したという結果ではない。自由、個人の場合との比較、著者帰属への接続も未完で、既存の部分対応を補う記録として扱う。原文対応率と意味確認済み七単位は据え置く。

