# 使用を続ける場合の作用と、実際の生涯の結果を分ける

カント第三段落第三文の「持続する未成熟」を検討するため、条件付きの作用を表す六定義を追加した。既存の `r2eq` は実際の活動が、本人の指定された残余生涯で未成熟が続く結果 `h26` に関わるという部分記述だった。新しい構成では、選んだ将来の範囲で使用を続ける場合に、その範囲で同じ本人への因果的結果も続くと述べられる。

第三文に続く文は足枷を投げ捨てる場合を扱い、段落の末尾には少数の脱出者が登場する。このため、全ての利用者が実際に永久に脱出できないという読みを自動的に補うことはできない。ただし、今回の条件付き候補が原文の唯一の読みだと決めたわけでもない。著者への帰属を含む既存54文は保持した。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)

| 定義 | 内容 |
| --- | --- |
| `r2eu` | 候補ごとの継続範囲について、条件が全体で成り立つなら結果も全体で成り立つ一般形 |
| `r2ev` | 同じ対象・本人・能力・活動について、吟味しない使用、誤用、生起を結ぶ |
| `r2ew` | そのような能力と活動があるという条件内容 |
| `r2ex` | 同じ活動が同じ本人の未成熟に因果的に関わり、未成熟も成立するという結果内容 |
| `r2ey` | 同じ対象と本人について、使用の継続を条件に因果的結果の継続を述べる |
| `r2ez` | 基準状況で規定または定型表現に属する対象に、この条件付き作用を結ぶ原文候補 |

一般形は既存の条件付き必然性 `rjm` と候補ごとの将来全体 `rjo` を合成する。全ての比較候補に少なくとも一つ継続点を要求し、さらに使用条件を全体で満たす候補も少なくとも一つ要求する。比較候補が空であることや、条件を満たす場合が一つもないことだけでは成立させない。使わなくなった候補で成熟しても、この条件付き作用とは矛盾しない。

候補・条件・結果・継続点は引数で渡すので、道具やカントに固有の新しい基本関係は不要である。例えば「電力の供給が続く候補では照明が続く」という比較にも、同じ一般形を使える。ただし、その装置の故障条件などをどこまで候補に含めるかは別に定める必要がある。結果のよい候補だけを選べば現実の作用を立証できる、という仕組みではない。

因果関係は結果側に置く。使用しただけで原因と判定したり、原因がない候補を使用条件から除いて反例を隠したりしない。使用、誤用、因果関係は同じ活動を要求する。複数の継続点で、全て同じ活動や同じ能力を使用する必要はない。

この候補にも限界がある。選んだ範囲の全体で使用する場合の比較なので、途中で使用をやめた候補について、その停止前だけの結果を保証する演算ではない。また各点で使用活動の生起を要求し、一度の使用が後まで残す効果はまだ扱わない。継続点の時間順序、区間の凸性、終点の不存在、連続時間、通常性と例外はこの定義に含まれない。既存の無終点・無上界の持続表現も保持しているが、それらと同義にはしない。

現在の使用や結果はこの比較の成立条件ではない。将来の選び方、原因性の根拠、規定の制定と拘束性、任意の型の定型表現、第三文全体の一般化と比喩の解釈は引き続き検討が必要である。`r2ez` は未採用の定義であり、新しい著者主張、対応文字数、意味確認済み分量を加えない。

検証では、一般形の1,024組合せ、候補や基準状況の取り違え、将来範囲の欠落、途中での結果の喪失を調べる。原因行為・結果本人・結果内容を変えた例では、能力の内容だけを境界として分離した接続試験と、既存の能力評価をそのまま動かす試験を区別する。未成熟の現在値と現在の使用がともに偽でも、使用継続の候補内で条件付き作用が成立する例を含む。未知入力を拒否し、式記述全域を必要とする対象分類を有限個の式で代用することも拒否する。

既存の十二単位と先頭二文の意味判断、全宣言と意味規約、54文、三記法の往復を検査する。これは有限例と保存条件の確認であり、原文との意味一致の自動証明ではない。
