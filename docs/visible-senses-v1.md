# 情報構造と語義を円文字で読む

共有複合語辞書第12版は375語を持つ。内訳は352構成定義と23基本宣言、綴りの内訳は30単独語と345複合語である。[情報構造](shared-focus-v1.md)の38語と[文脈ごとの語義](shared-senses-v1.md)の新25語を接続した。[第11版](visible-evidence-v1.md)の312語、固定した32文字、旧版の読取器は保持する。

[登録表](../noema/resources/visible-senses-vocabulary-v1.json)では、主張と背景・尺度を `book/red`、焦点の比較・主題・対比を `book/bird`、語義と置換を `book/treeone` から始まる綴りにした。綴りは型と意味規約を持つ語を識別する。部品名だけで語義を推測させる規則ではなく、番号・ハッシュ・登録順を字形に変換したものでもない。

語義群で再利用する `memberof`、`distinctmembers`、`focusentails`、`focusequivalent` は、同じ定義・意味・引数規約を持つ一語として統合する。既存語の意味や型を変更した登録、同じ依存の異なる意味、綴りの衝突を拒否する。

## 本文と引用

情報構造の四例と語義の四例を円文字文書として保存する。元のNative例にある意味本体・関係の定義を全て保持し、個体参照をAkiとNao、状況参照を既存の `situationslot` へ接続する。状況番号は参照先を指定するだけであり、時間順序や真理値を含まない。

情報構造の例では主張と背景、否定、限定・添加・尺度、主題、帰属、対比を確認する。語義の例では候補と選択・列挙完了、文脈、同義規約、引用枠への置換、多義と同音異義の判断を確認する。どちらも解釈関係をPythonで計算して渡す方式ではなく、関係の本体を可視本文に含む。二個体・数状況の架空の解釈であり、現実の特定語についての語義分析ではない。

63語それぞれの型付き呼び出しと引用を図形へ変換し、図形だけから復号する。引用の必要段階は定義と依存から求める。本文ではSVGの円・線の位置からページ順・宣言・引用・式を復元し、復元した文書を評価する。隠したASTや別ファイルの本文から復号結果を補わない。

保存したSVGも直接読み直して期待する文書と一致を調べる。ファイルの欠落・余分なページ・図形破損・別の正当な文書への置換は、過去の検査成功を理由に受け入れない。検査結果と入力のハッシュは[検証報告](../reports/visible-senses-v1.json)に保存する。

## 使用と範囲

入口は `python -X utf8 -m scripts.visible_senses_page` と `python -X utf8 -m scripts.visible_senses_book`。第1版から第12版の見える版指定に応じて辞書を選ぶ。複数ページの例は `output/visible-senses-library-v1/` にある。

一ページ768本文字形・4,096図形、一文書8ページ・128行・展開8,192節点という制限は維持する。主張の真偽と背景、帰属と実際の成立、候補と選択、範囲内同値と同義規約・置換許可は別の条件である。有限例の一致や図形復号の成功は、あらゆる意味の等価性、画像OCR、第三者による読解を証明しない。学習資料と第三者読解、二作品全体の新書式化は別に進める。
