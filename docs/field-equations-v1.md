# 同じ場の偏微分と六つの方程式

アインシュタイン1905年論文の§6冒頭にある六つの方程式M0287をNoemaで部分記述した。場の成分を四座標の関数として扱い、各式で使う微分値を、同じ関数・場所・時刻に結び付ける。微分記号を意味のない文字列として格納する方式ではない。

偏微分には既存の差商の極限sjsを使う。四座標の一つだけを動かして一変数の関数を作り、残りの三座標を固定する。同じ操作を定義域にも適用し、指定領域の軸方向の切片で極限を取る。評価点が領域内にあり、四座標と微分値が有効な実数であることも要求する。領域の開性や物理的な境界条件は今回指定していない。

二つの場にはそれぞれ三成分を持たせた。原文のX,Y,ZとL,M,Nを同じ三軸順序へ対応させ、各成分の時間微分と他の二空間軸の微分、計18個を結ぶ。その同じ値が次の六条件を満たすことを要求する。下付き文字は対応する変数についての偏微分を表す。

| 電気側の成分 | 磁気側の成分 |
| --- | --- |
| Xₜ = V(Nᵧ − M_z) | Lₜ = V(Y_z − Zᵧ) |
| Yₜ = V(L_z − Nₓ) | Mₜ = V(Zₓ − X_z) |
| Zₜ = V(Mₓ − Lᵧ) | Nₜ = V(Xᵧ − Yₓ) |

原文の1/Vを含む形は、Vが正である条件を明示して分母を払った。両者の同値性は有理数の代数として検査した。V=0や負のVを受け入れず、空の領域によって全点の条件が空虚に成立することも除外する。領域の全点では、各点で18個の微分値が存在し、その値が六式を満たすことを量化している。

原文の六式にない発散条件は追加していない。例えば静的なE=(x,0,0)、H=(0,0,0)の微分値は六つの回転の式を満たすが、Eの発散は零ではない。この違いを検査し、今回の記述を完全な真空電磁場の全条件とは扱わない。

原文への接続では、前段と同じ静止系Kと光速度Vを参照する。二つの成分場と領域を同じ座標系・文脈へ割り当てた上で、六式の成立を仮定として導入する。引用した内容が実際の物理的真理であるかは、仮定の帰属を検査する際には実行しない。

電気的・磁気的な力と真空の一般概念、測定による成分の定義、単位系の説明は未完である。関数への参照だけでこれらの意味を説明済みとは数えず、u0153冒頭の名称と真空の語、u0155の説明、節見出しは今回の原文範囲から除外した。全領域での方程式の解や後続の座標変換も未完である。

検査では、四軸の切片36例、18微分の接続23例、六式の代数25例、原文の参照7例、仮定の帰属5例を確認した。18個の使用微分を一つずつ変更すると、接続条件と六式のそれぞれが失敗する。一般の偏微分と全領域の条件は検査用の関係で明示的に置き換えた箇所があり、これらの有限例を実数上の微分の証明とはしない。置き換えない極限、微分値の存在、全領域の量化は有限検査器が拒否する。

新規9件を含む関連32テストが通過した。通常記法・短縮記法・固有文字の往復、二文書のCLIのJSONと構文木の一致、SVGのXMLとしての読み込みも確認した。全テストの実行、字形の目視確認、907頁の原刊照合は今回の検査に含まない。

累積文書は基本記号532、定義798、文153、正規形204,469文字となり、親文書から4,191文字増えた。新しい文法演算を加えず、既存の関数・量化・実数・極限の構成を使っている。明示原文範囲は51文字増えて14,354/35,614文字（40.30%）、部分対応区間は135/282、数式要素は258/446となった。意味一致確認済み区間は両作品とも0のままである。
