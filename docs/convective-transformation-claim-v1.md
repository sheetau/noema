# 第九節の変換提示と二つの表示式

u0233–u0236 は、K の方程式を仮定して k へ変換する一文である。意味の要件は、先行方程式への照応、K での成立仮定、第三節の座標変換と第六節の場変換の使用、結果の六式、wobei による三速度・密度の五等式の説明である。原刊916頁下半分で、この順序と全ての式を確認した。

先行の `ekzc` は、元の電荷分布・密度・流速と物理的な二場を共有する K の方程式である。`ug` でその成立を議論の仮定として採り、`eiswm` で同じ導入箇所へ照応させる。「gelten mögen」は実験確認や K だけで成立する限定にはしない。担体の付着について前文で行った解釈を、変換の追加前提として要求しない。

前回の `ekzx` は、同じ K/k の正逆座標規約、単位、同じ元の場から作る新しい両場、同じ領域の逆像を保持する。今回の `ekz3` はこの変換設定の全引数について旧方程式を要求する内容で、先行 `ekzc` を現在の設定へ適用した形である。`ekz4` と `ekz5` が六式と五等式の表示内容、`ekz7` が同じ設定の両方の結果となる。物理的な文脈を評価点へ固定し、他の32引数を全称量化する。

著者の「式を得る」という提示は `zc` で記述する。双方向の同値性を意味する書換え関係は使わない。`eisov` は第三節の最終座標式 `ejeh` と第六節の最終場変換 `ejvm` を、その同じ節と論説から参照して用いる役割を保持する。現在の変換設定の本体は同じ `s46`、`s6k/s6l` を現在の対象と量へ適用する。過去の特定の数値例を現在の場へ流用しない。

`zqa` は M0389、`zqb` は M0390 の既存参照を再使用し、導入と wobei の箇所だけを追加する。六式と五等式はそれぞれ `eisox` で内容へ結び、五等式の補足の主張、説明関係、本文順序、四箇所の区別、同じ著者と論説への帰属を一つの主張にまとめる。

M0389 には電気側の三式だけに 1/V が印刷されており、磁気側の三式の欠落は `semf` に保存する。M0390 は三つの速度の分数と、同じ ρ′ が新電場の発散及び β(1−v ux/V²)ρ に等しい五つの等式である。新しい密度と三速度は同じ逆座標写像から構成し、六式にも同じ関数を渡す。偏微分はその同じ場・地点の微分に接続する。

分数の適用域は V>0、|v|<V、正の β、D≠0 を明示する。D>0、正の密度、流速の上限は補わない。新速度が k で測った電荷の速度だという次文の同定や、総電荷の不変性は前提にしない。印刷された式と著者の導出を記述することは、その導出が物理的に正しいという証明とは別である。

局所検査では、四内容の全32量化位置、二結果の同じ引数、仮定・照応・二節参照・推論・表示・補足・説明・順序・帰属を区別して調べる。原刊と固定MathMLの照合、形式検査、四単位を前後へ接続した全体読解の判断を別々の証拠として残す。
