# 芽と覆いの比喩を対象側へ接続する

第十段落第四文の前件について、同じ低い制度下での心理的発達を、自然が芽を育てて覆いの下で展開する描写へ接続する。両側には既に構成したNoema内容を使い、同じ比較組と同じ本人を対応する引数として保つ。これは前件の比喩の接続であり、条件文全体や後件を完成扱いにはしない。

対象側は、前文と同じ共同体・二法秩序・制度の比較基準について、その人の二性向が発達する内容である。描写側では、同じ比較組の提示文脈から自然のまとまり、本人についての芽、同じ覆い、描写の解釈基準を選ぶ。覆いと自然の指示は本人ごとに変えず、どの選択も発達の結果時点や成功を引数に取らない。両側の過程と始点はそれぞれの記述内で選び、物理的に同じ過程とする条件は加えない。

「この覆い」の先行範囲は、第三文の低い市民的自由の側とする採用済みの読みを保つ。その箇所の全内容が著者へ帰属されていること、覆いの句が別箇所として後に続くこと、逆順でないことを確認し、同じ比較組の低い法秩序への対応を要求する。比較に含まれていない別の制度や、高い側の障壁へ替えると成立しない。

芽と二性向の同格は、植物個体と人を同一視する条件ではない。既存の同格は二つの句が同じ性質を指すことを扱い、今回の対応は、その性質を同じ本人へ適用した性向の組が、指定された芽によって描かれることを扱う。共同体の全成員について指示の対応を保つが、全員の性向が既に顕在化したことや全員が同時に発達することは主張しない。

比喩の提示には既存rw7を再利用し、対象側と描写側の異なる閉じた段階1の性質記述を渡す。提示・照応・同格の検査では心理的な発達、植物の成長、自然の感情、先行制度比較の真理を実行評価しない。明示的に引用を評価した検査では二側を独立に評価できることを確かめる。下位の発達本体の検査は、前回までの変更していない証拠を引き継ぐ。

検査は、比較組と本人の全引数、提示文脈で固定する参照、覆いの九つの対応引数、先行内容と文脈、全成員の芽への対応を確認する。二つの選択された比較組に対する四条件の全256真偽組も、独立した真理表と照合する。どちらかの側の現実の成立を、比喩が提示されたことの条件として追加しない。

次はWenn/soの全体条件と人口・時間の量化を固め、民衆への漸次の反作用、行為能力、政府原則・自己利益・機械以上の人間・尊厳、著者注参照を統合する。今回の局所検査から新しい意味確認文字数は加算しない。
