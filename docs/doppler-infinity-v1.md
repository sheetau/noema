# 印刷された無限大の主張と通常理解との対照

u0192は `Man sieht, daß — im Gegensatz zu der üblichen Auffassung — für [M0336], [M0337] ist.` である。固定在庫のMathMLと保存済みの原刊912頁では、M0336を `v=−∞`、M0337を無印の `ν=∞` と読む。先行式に都合のよい `v=−V` や `ν′=∞` へ訂正しない。

この表記は、有限実数の関係の境界挙動として読む。二実数関係Gについて、任意の有限Bより小さい入力を持つ点が存在し、さらに任意の有限Mに対して、十分小さい入力を持つ**全て**の点の出力がMを超えることを要求する。後者だけなら空の関係も通るため、前者の非有界性を外さない。MごとにBを選ぶ順序、多価関係の全出力、厳密な大小を保持する。これは新しい実数∞の存在を述べる定義ではない。

Gは先行のφ=0の物理的条件ekeyと同じ周期数の式ekezを共に満たす点から作る。入力は速度v、出力は印字通りの放射周期数νであり、受信ν′を背景に保つ。背景15役割は源・過程・波・系・観測者・各単位・節・状況・V・ν′である。残る43役割は各点に存在量化し、周期・位相率・軌道を全点に固定しない。K・V・節・状況以外の背景11役割について、Gが非空ならこの発散があるという内容を作る。この固定ν′による関係的読解は明示した解釈であり、著者の歴史的意図を一意に確定したものではない。

この内容は先行の適用域と整合しない。Gの各点は0<v<Vを要求するので、B=0より下に点を持てない。正のVに対するこの反例は平方根を適用域外で計算せずに得られる。Noemaに必要なのは、この主張を正しい式へ改作することではなく、主張された内容とその帰属を区別して記述する能力である。局所検査では、印刷された主張の一般的真理を証明したとは扱わない。

`Man sieht` は同じ内容の主張uh、認められる帰結としての提示zdg、直前の式からの帰結zcで結ぶ。通常理解の具体式は原文に書かれていない。そこで見解と閉じた内容を存在量化し、eisahで当時の論点における通常性、eisaiで見解への内容帰属、eisnpで今回の主張との対照を保つ。共通観点は同じ波・相対速度・φ=0の放射及び受信周期数の関係である。通常理解を主節の厳密な否定や特定の古典式に置き換えず、eisa5で対照を同じ主節への挿入部として結ぶ。一文全体はeir3で同じ著者・論説へ帰属し、直前の表示からの順序を保つ。

新しい一般基本関係は追加しない。既存の実数、量化、関数、閉じた引用、主張・帰結・通常理解・対照・挿入の関係を合成し、二つの局所参照だけを加える。検査は実数の局所点、空の関係と定義域、量化順序、43証人と11背景の全位置、原記号の対応、提示の各引数を対象とする。有限模型で量化の結合を確かめる検査と、全実数について発散を証明することを混同しない。全実数・全記述の有限評価は拒否される。
