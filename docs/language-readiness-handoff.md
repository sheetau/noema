# 言語完成への引き継ぎ

二作品の意味確認は、明示した解釈の下で完了している。次は円文字の見た目を維持しながら、読者が付属データなしで読める書記規則と、作品を越えて再利用できる意味体系を完成させる。発音・自動翻訳器・モデル比較は対象外。停止中のgoalは、この文書を作ったことによって再開しない。

正本の選択は [work-state.json](../data/work-state.json) が指定する登録簿v456、全体監査v432に従う。カント20単位・119主張、アインシュタイン282単位・283主張、計51,127非空白本文文字の判断を保持する。過去の文書にある「後続段落は未完」は当時の状態であり、現在の未完課題へ戻さない。[完成基準](language-completion.md)と[意味判断の条件](semantic-review-v1.md)は維持する。独立査読やあらゆる意味に対する完全性の証明まで済んだとはしない。

## 最優先：見える形だけで読む

固定した見た目と再生成入口は [書記体系](writing-system.md)、ハッシュは [固定記録](../data/writing-freeze-v1.json)。描画器の内部ASTが元の式を保持する検査と、人が線・円から読み戻せることは別である。

### W1 語の識別と辞書番号からの独立

現行描画で `rain(town)` と `rain(home)` は、同じ宣言順の辞書を渡しても同じ可視形状になる。異なる語の識別は、規則を文書化するだけでは解決できない。出現参照を局所的に並べて番号を振る方式が、参照名の違いを図形に保存していない。[再現検査](../scripts/check_writing_freeze.py)は不可視のASTや番号を比較から除き、`shapes`・`paths`・`width`だけで衝突を確認する。[結果](../reports/writing-readiness-v1.json)では `above(birdone,treeone)` と `above(aki,nao)` も一致し、通常文③は同じ式でも辞書の順を反転すると形が変わった。これは網羅的な衝突検査ではなく、現行の非一意性と辞書順依存を示す反例である。

次の作業はこの最小対から始める。語の安定した構成・識別規則を定め、既存の円・接続・融合の範囲で異なる語を区別する。辞書の挿入順・追加・内部番号の変更で既存語の形や読みが変わらないことを確認する。意味から自動的に全語の形が決まることまでは要求しないが、語の形に公開された識別根拠が必要。番号のハッシュを円へ置き換えるだけでは、番号依存の意味体系を解消しない。

共通の学習可能な語彙・文法は使用してよい。「付属データなし」は、文書専用の辞書番号表、元の自然言語、AST、JSON、SVG内の不可視属性を見ないという条件。新語・固有名は文中で導入・参照できるようにし、既知の語と新語を区別する。同義語・多義語・同じ物の別名も、字形の同一性と意味の同一性を分けて扱う。

### W2 枝の順序・結合・境界

以下を公開規則として決め、それぞれに「入れ替えると意味が違う」最小対を作る。

- 文頭からの走査方向と、複数の枝に入る順番。述語の第1・第2引数、束縛変数と出現、否定・量化・引用の範囲を一意にする。
- 複数語の融合・共通引数の共有と、別の語が接しているだけの場合の区別。交差、接触、円周・中心への接続が構文上何を担うかを定める。
- 上下への配置変更や折り返しで不変な読み。省スペース化のための枝配置が、引数順を変えてはいけない。
- 語・節・主張・段落の境界と行継続。現在の主張間の空白（描画上40単位）や、引用入口の非描画接続を、読者がどう見分けるかを決める。空白をすべて文区切りと解釈しない。

受入条件は、公開規則と見える幾何だけを入力する復号器が、正規化を明示したASTへ戻すこと。許す正規化（変数名の付け替え、純粋な配置変更など）を先に限定し、引数交換・否定範囲・引用と実行を同値扱いしない。不正・曖昧な入力は推測で補わず拒否または候補を明示する。最初は可視幾何を抽出した入力でよく、手書きOCRの完成は別課題。ただしSVGの不可視属性を読む実装では達成としない。最後に人が画像だけから読む試験も行う。

### W3 文書全体を自立させる

現行のページ画像は主張を描いており、全宣言・定義を自立した円文字の文書として収録したものではない。一般文書に必要な語の導入、定義、型、束縛、数値（符号・有理数等）、引用、仮定、参照範囲、版・語彙の指定も対象にする。参照をすべて展開して画像を巨大化させるのではなく、同じ言語で定義して後で参照する規則を作る。

受入条件は、少なくとも一つの新語定義と数式、入れ子の引用、複数の主張を含む文書を、付属データなしで再構成できること。二作品の既存定義・判断を置換するのは、この規則が確立してから。美観の再設計は行わず、固定した部品と接続で成立しない場合のみ、反例と必要最小限の変更案を記録する。

## 次段階：意味体系の一般化

以下は「すべて未対応」という一覧ではない。既存の構成能力、作品内で確認済みの読み、一般化が未検証の範囲を分ける。新しい構文を増やす前に既存の定義で表せるか調べる。

| 領域 | 既存の足場 | 次に確認する区別・不足 |
| --- | --- | --- |
| 型・論理・定義 | 個体・有理数・真偽、任意引数の関係・関数、量化、定義、高階関数参照 | 読者向けの共通語彙と意味規約。前方・再帰参照等を必要とする用途は、仕様上の制限と代替構成を明示 |
| 時間・相 | 状況、期間、経路、変化、反復等の作品内定義 | 「走った／走っていた／走り終えた」「毎朝／一度」、発話時と報告内の現在。出来事の時間と視点を共有できる一般規約 |
| 様相・反事実 | 能力・義務・許可・候補状況、[反事実の構成](counterfactual-withholding-v1.md) | 可能性・能力・許可の区別、評価主体と根拠、空の候補の扱い。反事実の候補選択・近さは文脈規約であり万能選択器ではない |
| 指示・照応・省略 | 明示した識別名と文脈、作品内の先行参照 | 私・ここ・今の話者交替、引用内外の指示、先行詞が複数ある代名詞、省略と補完の条件。単なる識別子のコピーでは補完過程を説明しない |
| 定性・前提 | 存在・一意性・帰属を明示して組み合わせられる | 「その王は来ない」「また来た」等の前提が否定・問い・条件文の下で残る／残らない読み。記述の参照失敗を偽と同一化しない |
| 数・集合・複数 | 有限列・順序・重複、[複数の行為](plural-actions-v1.md) | 集合的／分配的行為、「二人で一台を運ぶ／各自一台」、各人に同じ物／別の物、相互性、物質量と数えられる単位 |
| 総称・程度・曖昧さ | [通常例と例外の構成](generic-fetters-v1.md)、程度・頻度・比較 | 「鳥は飛ぶ／すべての鳥が飛ぶ」「高い／より高い／十分高い」、比較基準、境界不明と未知の区別。曖昧な語に勝手な数値閾値を加えない |
| 発話行為・問い | [主張・質問・指示](spec-v010.md)、[型付きの問い](spec-v012.md)、発話の記述と実行の区別 | 依頼・助言・許可・約束、間接依頼、問いへの部分回答・理由の十分性、会話の受諾と訂正。質問内容から答えの存在を導かない |
| 証拠・知識 | 帰属、候補状況、記述の認識 | 目撃・伝聞・推論という出所と確信度、同じ情報の再伝聞、誤信念。未知を否定へ変換しない |
| 情報構造 | [焦点と背景帰属](attributed-focus-v1.md)、限定・対置の局所定義 | 主題、only／also／even／butに相当する範囲と期待背景、否定や引用との相互作用。単なる論理積で対比まで表したとしない |
| 比喩・慣用・待遇 | 総称内の比喩、[敬意表現](courteous-reference-v1.md)、[好意的描写と批判的距離](benevolent-framing-v1.md)、架空共同体の返礼規約 | 換喩・慣用句・皮肉・感情表出・文体の別領域への移植。意図、文字通りの内容、聞き手の受け取りを区別し、一つの文化規約を普遍化しない |
| 数学・専門分野 | 実数切断、量・単位、座標、極限・微積分などの定義 | 未扱いの分野でも定義を合成できるか。記述の成立と、無限領域の真理を計算できることを分ける |
| 曖昧な読み・不完全情報 | 明示した解釈を選ぶ運用、状況ごとの内容 | 複数の読みを未決定のまま保持する表現、文脈不足、修正履歴。「AまたはBという主張」と「AともBとも読める記録」を区別 |

0.13の型付き引用は記述の同一性と真理の同一性を分ける。0.15/0.16の段階付き引用・評価は、[実行時の評価上限](runtime-quotation-v1.md)を含む。古い段階検査の反例を、修正後にも残る不具合として転記しない。一方、一般的な静的効果検査・停止性の証明・無限領域の万能評価器は提供していない。これらすべての実装を「言語として記述できる」ための必須条件にしない。

## 語彙を作品から切り離す

現行統合稿の宣言数はカント6,061（定義3,941・primitive 2,120）、アインシュタイン6,255（定義4,398・primitive 1,857）。[検査結果](../reports/writing-readiness-v1.json)で本文ハッシュとともに再集計する。未使用の旧宣言や作品専用の定数を含むため、この数を基本語彙数や「文ごとのprimitive」の数と解釈しない。

必要なのは、共通概念・構成定義・作品固有名・文脈の仮定を区別した公開語彙である。[意味カタログ](meaning-catalog-v1.md)を入口に、頻出する関係を依存グラフ付きで抽出し、同じ関係を二作品と新しい日常文で再利用する。各語に型・役割・成立条件・反例・文脈引数を付け、英語識別名だけで意味が伝わったことにしない。

既存稿の整理・名前変更は現在の判断を壊し得る。まず新しい共通モジュールと対応表を作り、意味の変わらない移行だけを検証して行う。未使用に見える宣言も、過去の判断や旧検証の依存を確認するまで削らない。作品の一文全体を新しい基本関係へ押し込んで、表現できたことにする方法は禁止を維持する。

## 他言語との比較から設定する課題

比較対象の形態をそのまま輸入する必要はない。他言語が区別できる読みを、Noemaが合成によって区別・説明できるかを確かめる。

- 英語の時制・完了・進行などを比較用の組にする。WALSは時点の位置づけと出来事内部の捉え方を区別している。Noemaの全動詞に同じ活用を義務化するのではなく、時間・相の意味の区別を試す。[WALSの時制・相概説](https://wals.info/chapter/s7)
- 証拠の出所と確信度を別軸で試す。トルコ語を含む証拠性の例は、目撃・非目撃や伝聞・推論の区別を比較する足場になる。言語ごとの差があり、一つの必須区分を世界共通とはしない。[WALSの証拠性](https://wals.info/chapter/77)
- Lojbanの照応と態度表現の公開規則を、学習者が参照先や作用範囲を決められるかという観点で比較する。Noemaでも枝の読み順だけでなく、照応・話者の態度の範囲まで説明可能にする。[照応](https://lojban.org/publications/cll/cll_v1.1_xhtml-chapter-chunks/chapter-anaphoric-cmavo.html)、[態度表現の範囲](https://www.lojban.org/publications/cll/cll_v1.1_xhtml-section-chunks/section-attitudinal-scope.html)
- 日本語の日常的な自作例「もう食べた」「それはいい」「来られますか」を、主語省略、時点・評価・依頼の異なる文脈に置いて試す。日本語全体の分類を済ませたという意味ではなく、二つの論文に偏った試験を補うための例である。

形式言語としての型・束縛・引用は既存の強みであり、一般的な自然言語の曖昧さをすべて消すことを目標にしない。曖昧さを選んで残す場合も、何が未決定かを明示できるようにする。他言語との比較から、万能性の百分率を算出しない。

## 再開時の順序と完了判定

1. W1の `rain(town)` / `rain(home)` を異なる形で安定して読み戻す。辞書の並べ替え・語の追加でも既存の読みを保つ。ここを直す前に大量の画像を増やさない。
2. W2の引数交換・量化と否定・引用の範囲・行継続を最小対で確認し、同じ規則で通常文と数式を読む。元ASTの持ち回りを往復成功と数えない。
3. W3の小さな自立文書を完成させ、学習者向けに語の作り方と読み方を説明する。現行ページの全面変換はこの後。
4. 共通語彙と上の意味領域表を、一つの関連する意味群ずつ調べる。既存定義、欠ける関係、採る解釈、残す曖昧さ、統合先を実装前に記録する。
5. 各群で少なくとも二つの話題・文脈を用意し、主客交換、否定、時間、作用範囲など、その群に必要な対照を確認する。自然言語での読み戻し説明と有限モデルの反例検査を分け、未解決だけをこの引き継ぎへ残す。

完了は、公開された語彙・書記規則・構成規則によって、対象とした意味領域と新しい例を第三者が学習・記述・読解でき、既知の反例が解消されていることとして評価する。「あらゆる自然言語の意味を尽くした」という有限試験では証明できない主張に置き換えない。第三者の読解・意味レビューが未実施なら、その項目を未実施と表示する。

作業は [WORKFLOW](WORKFLOW.md) に従う。局所検査と報告を一回の `project_work check` にまとめ、意味群の統合・引き渡しで `project_work audit` を行う。旧判断の内容ハッシュを更新して問題を隠さない。旧字体の画像は整理済みだが、現行が呼ぶ旧描画処理、互換文字資産、意味判断、原典、旧検証器は引き続き保存する。
