# 平均エネルギー流と有限左境界

u0201を統合する前に、強度の数式と境界の条件を構成した。本文の383主張と既存の意味判断は保存し、この段階では全単位の完成件数を増やさない。

採用予定の強度は、波に垂直な単位面積を通るエネルギー流の周期平均である。[Feynman Lectures II §27](https://www.feynmanlectures.caltech.edu/II_27.html)は光の強度を平均エネルギー流として説明し、[MIT Optics Lecture 14](https://ocw.mit.edu/courses/2-71-optics-spring-2009/c15fc0942eac409b6adb1b558c210c00_LDlGKU0ryQ8.pdf)は時間平均と振幅二乗への比例を区別する。これらは採用する物理概念の参考資料で、1905年の語の唯一の解釈を確定する資料ではない。原文の根拠は保存済み原刊912頁とする。

同じ共通波形p(t)を持つ電場E0・磁場H0に対し、方向nへの流の候補をκ n・(E0×H0)p(t)²とする。正のκは単位への換算係数である。ekjhは有限区間での実数Riemann積分を区間長で割った平均を定義する。周期も正弦も仮定しない一般の区間平均なので、平均二乗を常に1/2にはしない。横波条件seajと同じ電場の振幅sealの下でn・(E0×H0)=A²となり、別に確認した二乗平均mに対して平均流はκmA²となる。

先行の旧振幅比の余弦を−1にすると、正面接近側の比は(1+r)/(1−r)である。φ=0の後退側の逆比と区別する。固定された正の入射平均流Iに対し、0<v<VでI′=I(V+v)/(V−v)を数値グラフにする。VやIを速度ごとに選び直さない。

ekjtは任意の小さな正の左近傍にグラフの点があることを要求し、任意の有限上限Mごとに正の近傍幅δを選び、その近傍内の全ての点の全ての出力がMを超えることを述べる。空グラフと境界から離れたグラフを排除し、多価関係の小さい出力を無視しない。実数Vそのものへ代入した有限値は定義しない。

正のI,Vについて、δ=VI/[2(I+max(M,0))]を選べる。0<δ≤V/2であり、V−δ<v<VならV−v<δ、I′>IV/δ=2(I+max(M,0))>Mとなる。任意の正の近傍幅εにはv=V−min(ε,V)/2があり、0<v<VとV−ε<vを満たす。従って数値グラフは空虚でない。I=0のグラフは各点でI′=0であり、正の発散を支持しない。

検査では符号と外積順序、一般の区間平均、平面波の振幅二乗、接近と後退の比、厳密な近傍端、零入力、多価出力、量化順序、同じV/Iの固定を分けて確認する。有限の順序表は量化の接続診断であり、実数の極限を有限標本に置き換える検査ではない。一般の代数証拠と局所的な実数埋込み評価も区別する。

次に必要なのは、同じ源・波・観測者・系・単位と流の物理的対応、各系の周期平均と共通換算係数、旧実数角πによる接近、速度ごとに補助量を選べる非空な関係、反実仮想と展開済みの式からの帰結、著者帰属である。現段階の数値グラフを、その物理的関係の代わりにしない。
