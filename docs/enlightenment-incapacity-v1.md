# 啓蒙に至る不能と後見役

第四段落第三文の後見役と啓蒙不能を、作用の反転の条件へ接続した。取得の機会・開始時点の状態保持・外的条件を指定する三つの汎用的な基本関係と、四つの合成定義を加えた。本文全体の意味確認と著者帰属は未完である。

## 行使できないことと取得できないこと

第三段落は現在の理解力の行使不能を述べる一方、この箇所は「aller Aufklärung unfähig」と述べる。今回は、自立的な理解力使用の能力 `up` に至る方法が、指定した取得機会のどこにもないという強い読みを採る。現時点で自力の判断ができなくても、学習や他者の援助を通じてその能力を得られる場合は、この不能を満たさない。[原文 AA VIII 36](https://korpora.org/Kant/aa08/036.html)

`r2ms` は非空の機会候補を取り、その全てで本人の基準状態の保持と外的条件を検査する。各候補で利用可能な全方法の結果評価 `xe` が整合し、目標達成方法 `xd` がないことを要求する。空の候補、未評価の方法、結果が空の方法を不能の証拠として使わない。ある候補だけに達成方法がある場合も不能を認定しない。

既存の行使能力評価では、まだ得ていない技能の学習を現在の技能行使へ流用しないよう、方法を分類している。今回の取得評価ではその分類を使わない。利用できる学習方法は候補に含める。基準状態を保持するのは方法を始める時点であり、方法の途中で本人の知識や習慣が変わることを禁止しない。

`r2mt` はこの目標を `up` に固定し、機会・状態保持・外的条件を同じ閉じた目標記述へ結ぶ。新しい `h223p/h223q/h223r` は任意の状態記述を取り、その取得を評価するための入力を分けて表す。活動を行う機会を表す既存 `hzyf/hzyg/hzyh` へ、取得したい状態を活動として流用しない。現在の未成熟 `bf` の成立だけからは取得不能を導かない。

この構成は、全ての物理的可能世界や無限の将来を量化するものではない。部分的な知識の増加を一切否定するものでもない。文脈で採る機会・方法・結果が十分かは解釈根拠を要し、有限モデルの通過では証明できない。第三文の通読時に、この強い読みの適切さを再点検する。

## 後見役と条件への接続

`r2mu` は本人が人であり、公衆の少なくとも一人の他の構成員に対して、総括的な指導・監督の立場を持つことを要求する。既存 `dc` と `r2m5` を使う。第三文の後見役に、第二文の任命履歴や、指導の合法性・成功・本人の能力を無条件に補わない。

`r2mv` は作用の反転 `r2mr` の二つの関数引数を、この役割と取得不能へ充足する。不能を要求するのは扇動条件内の各扇動者であり、先行する後見人全員ではない。扇動そのものの関係は残っている。

局所検査では、学習を通じた取得、一つの候補だけでの成功、評価欠落、外的機会の欠如、本人の入れ替えに対する判定を確認する。統合検査では役割・方法評価・作用の反転・期間内保持の実際の定義を実行し、未成熟と取得目標の内容を境界として明示する。旧59文、十三の全単位判断、先頭二文382非空白文字を保持し、確認済み文字数は増やさない。
