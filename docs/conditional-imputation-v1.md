# 因果条件・帰責・条件の主張を分ける

カント冒頭第三文のwennを、因果条件が成立すれば自己に責任がある未成熟に分類する、という一方向の読みで記述した。[原文の比較用電子版](https://korpora.org/Kant/aa08/035.html)と、[IDSの条件接続の説明](https://grammis.ids-mannheim.de/terminologie/1872)を確認した。一般的な条件接続の説明だけで、この文の読解を一意に決められるわけではない。定義的な同値の読みは比較対象として残す。

旧bpは因果条件bdの別名だった。初文の離脱もbdを始状態に要求していたため、特定の原因条件と、本人に責任があるという分類を別々に記述できなかった。旧第三箇所は、そのbpを概念の説明として提示していた。

新しいhziqは、指定状況の評価で、本人について記述された状態を本人の選択や不作為に関する落ち度として本人に帰す基本関係である。単なる因果、未履行、誰かが非難したという発話記録とは区別する。これは帰責の意味規約であり、正当な責任判断の全理論や法的制裁の規則ではない。

rqrjは、実際の未成熟bcと、その同じ状態bfについてのhziqを結ぶ。bpはその性質を内容化し、離脱beの始状態もrqrjへ移した。過程・本人・前後状況の結合と、bpからupへの変化という記述は保つ。既存bdの因果条件は変更していない。

rqrkは、同じ評価状況の全対象についてbdからrqrjへの含意を述べる内容である。該当者の存在や、条件が今成立していることは要求しない。比較用rqrlは両者の同値を要求する。rqrkは逆向きを断言しないが、逆向きが成立する可能性も否定しない。

本文のcpでは、第三箇所だけを、uaによるbpの概念説明からucによるrqrkの主張へ変更した。先行する啓蒙と未成熟の概念説明、ラテン語・ドイツ語の引用、標語、六箇所の相違と順序、説明と帰結の関係は保持する。17文の構文は同じだが、bp・be・cpの定義本体を改訂したため、意味まで不変とは扱わない。

四つの因果条件・帰責の組合せでは、一方向だけの条件、同値条件、離脱の成立を別々に検査する。別の人物だけが条件に違反する場合も全称的な条件は不成立になる。bdの五条件32組合せは旧版のまま維持する。帰責対象の人物・状態記述・状況を取り違える例、状態自体がない例、未知の帰責を原因から補う誤りも検査する。

著者による第三箇所の主張では、rqrkを実行せず引用する。内容の評価を実行すれば例外になる解釈でも提示の記録は成立する一方、同値rqrlを提示したという別の記録では成立しない。本文の引用層は0を維持する。四例の直接評価は短絡変換とキャッシュを使わず照合し、通常・短縮・固有文字の往復とCLI解析も確認する。

この変更は一つの読解を明示した部分草案である。十分条件と定義的な同値のどちらがこの箇所の全意味を保つか、帰責の程度と例外、評価基準、決意と勇気の不足の読み、第一段落全体の意味確認は残る。意味確認済み区間数と原文の対応範囲は増やさない。署名の依存内容は不変だが、本文の版を更新したため単位別の確認も新しい版へ明示的に結び直す。
