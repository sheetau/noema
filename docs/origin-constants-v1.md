# 四つの原点定数とφの未決定性

アインシュタイン§3の `u0085` を部分記述した。先行する四座標の式に、時刻・縦座標・横二座標それぞれの定数を加え、原点についての仮定を外した場合を記述する。

```text
τ = φ(v)*β*(t-v*x/V²) + Cτ
ξ = φ(v)*β*(x-v*t)    + Cξ
η = φ(v)*y           + Cη
ζ = φ(v)*z           + Cζ
```

`spu` は同じV、v、正規化後のφを使い、四つの独立した定数を受け取る。全てゼロでも、一成分だけが非ゼロでもよい。`spy` は一組の定数が対象範囲の全記録対で共通であることを要求し、方程式の成立と出来事の対応を双方向に結ぶ。`spz` は四つの定数の存在量化を全記録対の量化の外に置く。入力ごとに定数を選び直して任意の結果を合わせることはできない。

`spv`、`spw`、`spx` は指定された設定での出来事と座標記録に接続する。先行する零原点の状況 `zb6` に固定しない。原点を変えた別設定でも、二つの座標記録が同じ出来事に属することは必要である。

原点について「仮定を採用しない」ことは、「原点が異なる」という事実とは区別した。`zfo` は論述段階と設定についての仮定の非採用、`zfn` は原点以外の物理条件・単位・尺度を維持する対象設定という基本関係である。`sqa` がその条件内容、`sqb` が共通定数の存在という結論内容になる。本文への接続は著者の条件付き推論として記述し、実世界での成立を無条件に断言しない。

φの未知性には、u0064とは別の論述段階 `zfm` を与えた。`sqc` は先行係数aの候補関数族を、各候補状況でβとの積へ写す。`sqd` は現在のφとその族を結び、同じ速度域に有効な候補が残り、その中に異なる値を持つ候補があることを表す。φ=1という後段の結論は加えていない。これは残存する候補による部分解釈であり、知識一般の定義ではない。

有理数の代数では、入力・出力の原点移動がアフィン式の定数項だけを変えること、同じ定数が差を取ると消えること、定数が同じ入力で一意に決まることを検証した。正のβによる再表示が異なる係数値を同じ値にしないことも検査した。一般の実切断についての体の法則と、物理的な記録全体に共通定数が存在する証明は含まない。
