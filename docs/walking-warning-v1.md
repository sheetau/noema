# 身体の歩行を試みる場合の警告を接続する

カント第二段落の、家畜への働きかけから後の危険提示までの一文を、[原刊482頁](https://www.digitale-sammlungen.de/de/view/bsb10926843?page=522)と現行Noemaへ照合した。知的自立を試みる場合の危険は既に記述されているが、それを「独りで歩こうとすると危険がある」と描く条件文の接続が欠けていた。今回、その身体側の条件文を既存の関係から合成し、同じ箇所の比喩として加える。

一般定義 `rqy3` は、本人、試みの目標、危険評価の目標、比較する仮定範囲を受け取る。非空の仮定範囲の全事例で、本人が指定活動を試みるなら、その活動に関する可能な結果に本人への不利益があることを要求する。二つの目標は独立に指定できる。既存の知的側では理解力の使用 `bb` を試み、自立状態 `up` へ向かう場合の危険を評価する。この組合せを一般形へ渡すと、従来の条件文 `eu` と同じ検査結果になる。

身体側の `rqy4` は、試みと危険評価の両方に、他者や装置の身体支持なしに脚で移動する既存の `zal` を指定する。試みることから移動の成功を導かず、危険から実際の転倒や負傷を導かない。原文の「独りで」を、歩行器の補助から離れる描写として読む候補である。単に同行者がいないという読みや、歩行と走行の運動学的な境界は、この構成だけで確定しない。

同じ本文箇所 `hzsq` に置く `rqy5` は、知的側の条件文 `eu` を身体側の `rqy4` によって非字義的に提示する。両側は同じ人物位置を持ち、`f4` で指定する対応事例の索引を共有する。ある事例で身体側の試みや危険が真でも、知的側の真理値は独立である。現実の同一出来事、両側の因果的な同一性、全ての比喩で共通の仮定範囲が必要だという一般論は追加しない。この範囲の対応も、今回明示する解釈の一部である。

合成には既存の条件 `rc`、可能な不利益 `rl`、試み `ei`、結果候補 `uq`、不利益 `ur`、非字義的な提示 `qh` を使う。新しい意味の基本関係はゼロで、追加は三定義と本文一文である。一般文書は関係を引数として受け取り、カント固有の参照や基本述語を持たない。既存46文と全ての既存定義・意味規約は保持する。

## 検証と一文全体の残る課題

五テストで、条件の48組合せ、人物・目標・事例・結果の八対照、複数事例の全称条件、未知入力四種を確認する。試みの目標内容が真・偽・未知でも、条件文はそれを実行して成功条件へ置き換えない。身体側と知的側を独立に変える16組合せ、身体移動と外部支持の四組合せ、著者・箇所・描写の向きなど十二対照も確認する。通常記法・短縮記法・固有文字の往復と、既存十一単位の意味依存関係の保持を照合する。

一文を十二範囲に分けた[読解記録](../data/walking-warning-reading-v1.json)では、未完の意味を明示する。

- `ruhigen` の穏やかさ・非抵抗の描写。試みていないだけで、その態度を補うことはできない。
- `ja` の強調が誰の態度に属し、どの否定・許容へ作用するか。
- `keinen Schritt außer dem Gängelwagen` の身体的な一歩の最小単位と、装置外という目標範囲、許容との結合。
- 家畜と歩行の語義範囲、許容と実行機会の読みを含む一文全体の確認。

今回の追加は原文一文全体の意味一致を認定するものではない。確認済みの十一単位・1,001非空白文字と、第二段落の先頭五文・777非空白文字は維持する。二作品全文の完成、第二段落全体の完成、任意の内容の表現率は引き続き未達・未測定である。記述と有限モデルの検査、アシスタントによる読解判断を、自動的な意味一致証明や独立査読とは区別する。
