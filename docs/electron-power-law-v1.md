# 同じ軌道の縦方向の運動方程式と仕事率

u0261末尾の「全運動過程で第一の式(A)が成り立つ」という箇所を接続した。前段と同じ曲線のx座標を時間で微分して速度を、速度を微分して加速度を定め、その時刻の位置で前段と同じ静電場のプロファイルを評価する。betaも各時刻の速度から求め、終了時の値を全区間へ流用しない。

縦方向の式は `epsilon*X=mu*beta³*a` とする。この両辺に同じ速度を掛けると仕事率の等式が得られるが、速度で割る操作は使わない。初速零では仕事率が零でも力の式が成立するとは限らないため、元の力の式を全時刻で保持する。逆向きの推論が使えるのは速度が零でない場合に限られる。

検査では登録した多項式の曲線と速度の解析的な微分を使い、三つの時刻で場・位置・速度・加速度を接続した。終端のbetaを固定する例、零速度で力の式だけが違う例、電荷や速度関数の取り違えを区別する。本文の全区間条件から一時刻を取り出す検査も行うが、それらの結果を全実時刻の証明とはしない。全領域の有限評価は拒否する。

同じ全区間の式、仕事積分、収支と無放射の前提を合わせる内容構成子も作った。仕事率の一致から積分の変数変換を得る一般定理と、静電力・単位の物理的な説明、ゆっくりした加速と無放射の論証は残る。原刊の中間速度積分にmuがない点も、今回の局所的な式によって訂正済みとは扱わない。
