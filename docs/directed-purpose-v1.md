# 目的を担う参加者と、他の参加者への方向付け

現行の後見人の記述は、選択した全員が同じ行為に参加し、同じ目的を持つことを要求する。この条件では、目的を担う一人が他の参加者を動かす場合と、全員がそれぞれ同じ目的を持つ場合を区別して記述できない。[比較候補](../examples/v016/kant-directed-purpose.noema)には、その違いを表す五定義を追加した。

rqysは、非空の参加者群と、同じ行為の実行・参加を結ぶ。rqytは、その群の中で同じ行為・目標・状況について目的関係を満たす人だけを選ぶ。群の外の誰かが目指しているだけでは、その群の目的を担う人として数えない。

rqyuは、各参加者がその目標を持つか、その目標を持つ参加者から方向付けを受けることを要求する。例えば、二人が同じ仕事へ参加し、一人目が目標を持ち、その目標に向けて二人目の参加を実際に導く場合を記述できる。二人目が同じ目標を持つことまでは要求しない。一人目が目指しているだけで、二人目への働きかけがない場合は満たさない。

方向付けの関係は引数で渡す。意味規約では、供給者のその目標に向けた計画・働きかけが、受け手の当該参加を実際に導くことを要求する。命令を出しただけで相手が無視した場合、肩書だけがある場合、同時に別の仕事をしている場合には使わない。供給者・受け手・行為・目標・状況を全て同じ関係へ結ぶ。具体的な方向付けの仕組みを説明することは、引数の実装側に残る。

この条件は、全員の目的が一致していれば、他者への方向付けがなくても成立する。そのため、共通知識や相互承認を含む「共同意図」の定義とは呼ばない。また、目的を担う人からの直接の方向付けを扱い、中間担当者を経由する連鎖や、誰も全体目標を明示的に持たない制度的な目的までは表していない。

本文用のrqyv・rqywは、現在と同じ監督の立場、負担と危険判断、実際の因果的寄与へこの条件を接続する。同じ行為の目的と因果を結び、別の活動での目的を流用しない。目的を持つことと、目標が実際に成立することは、一般形では独立している。

保存済みの[Sorgenの出典](../data/guardian-causation-evidence-v1.json)だけから、後見人全員の同じ意図や、特定の指揮関係を確定することはできない。今回の候補は二つの読みの差を検査できるようにするものであり、原文の確定訳として現行本文を置き換えるものではない。既存45文、全ての既存定義、確認済み十一単位の登録は保持する。原文の複数主語と後続描写に適した目的の帰属範囲を選ぶ作業は残る。

検査では、二人の参加・目的・方向付けを変える128組合せを独立した真理条件と照合する。方向付けがない場合は全員の目的を要求する既存定義と一致し、一人が他者を方向付ける場合は区別できる。対象・目標・状況の取り違え、集団外の目的、活動未実施、空の集団、未知入力も検査する。本文の28対照は、二人の後見人が同じ一人を同順位で監督するモデルで、現在の監督・目的・因果の定義をメモ化評価して確認する。元の三人の母集団でも、基準例と目的分担例を比較する。

追加した本文用の目的条件は、二人の目的が異なる場合を含む三対照で通常評価とメモ化評価を比較する。周辺の監督・判断・因果条件は、目的条件の呼出しを元に戻して構文木全体が旧定義と一致することを検査する。束縛変数名を正規化し、目的以外の条件やその作用範囲が変わっていないことを確認する。三人の直接・間接の方向付けも検査し、方向付けの推移を勝手に補わない。

初期の二回の検査は計算量が大きく、完了前に停止した。初回はCPU時間約10分、二回目は約5分に達していた。進行ログを加えた三回目で、全接続のメモ化評価にも時間がかかることを確認した。小さいモデルの四対照を別途照合してから、そのモデルへ検査を移した。停止した検査を合格と数えず、全接続の通常評価とメモ化評価の一致や、任意のモデルでの同値性を保証したとも扱わない。現在の検査範囲は、一般形と追加した本文用条件の通常評価、周辺構造の一致、全接続のメモ化評価である。
