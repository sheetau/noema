# 政策を対象にする要求と許可

「発言することを許可する」と「発言を許可する状態を実現するよう要求する」を、別の規範として記述した。制限することへの許可も、実際の制限や、制限せよという要求から分けた。先行版で残っていた、カントの評価側の要求・許可と内側の政策状態との接続を具体化している。

## 対象の引数を保つ

規範の対象は、Noemaの内容を返す関数への記述参照と、個体を並べた引数列の組で表す。例えば、行為の実行なら「本人・活動」の二引数、政策状態なら「規範の出所・本人・立場」の三引数を渡す。いずれも同じ要求・許可の基本関係を使うため、引数の個数ごとに基本関係を作る必要はない。

列は順序と個数を保持する。余分な引数を切り捨てたり、欠けた引数を補完したりしない。個体以外の数値・状況などを、この列へ暗黙に変換することもない。対象ごとの引数規約は別の条件として渡し、原文への接続では対象記述とその規約を固定する。

| 定義 | 条件 |
| --- | --- |
| `rdr` | 引数列の長さが指定値に一致する |
| `rds` | 引数規約を満たし、指定対象への要求がある |
| `rdt` | 引数規約を満たし、指定対象への積極的な許可がある |
| `rdu` | 指定対象への許可があり、反対極性への要求がない |
| `rdv` | 同じ対象の成立と不成立を共に要求する |
| `rdw` | 要求があり、現在の対象内容が要求極性を満たしていない |

`rdt` は許可があること自体を述べる。反対要求との衝突も除く場合には `rdu` を使う。対象内容を評価するのは未履行を調べる `rdw` であり、要求や許可だけを述べる定義では対象の真理を補わない。

## 外側の規範と内側の政策

`h7h` は二引数の列を、既存の本人・活動の実行内容へ渡すアダプターである。`h7i` は三引数の列を公的活動の許可状態 `h7d` へ、`h7j` は私的活動の制限状態 `h7e` へ渡す。長さ規約はそれぞれ `h7f`・`h7g` で検査する。

原文側の基本関係 `h7k` は要求、`h7l` は許可を表す。外側の出所・名宛人・立場は、対象の引数列とは別に取る。外側で規制者に要求することと、内側である人の発言を許可することの役割を混ぜない。

`h7m` は評価側の出所が規制者に、その職務で、指定した内側の許可状態を実現するよう要求する条件である。`h7n` は内側の制限状態を許可する条件であり、制限が既に実施されたことも、実施する義務も意味しない。

`h7o` は `h7m` の要求があるにもかかわらず、内側の許可状態が現在成立していない条件である。要求があるから許可状態も真になる、という推論をしない。`h7p` は同じ列を受け取る規範関係を二引数の行為へ使い、先行版の行為別の許可と対応する解釈で比較する。

原文が特定の政府・規制者・人物を指定したとはせず、それらの指示対象は引数として残している。また、内側の全称的な公的活動の許可は、該当する活動がない場合も成立する。外側の要求から、発言の実例の存在を補わない。

## 検証と限界

引数規約・極性・要求・許可・実際の成立の128組と、列長の48例を検査した。負数・非整数の長さを丸めない。外側と内側の出所・人物・立場、引数の入替え・欠落・追加、対象記述、極性、文脈を変えた16例で参照の固定を確認した。内側の規範や活動分類が未評価でも要求・許可を記述でき、外側の要求自体が未評価なら判定を拒否する。

要求と許可状態の4組では、未履行と既に成立している場合を区別した。二種類の政策アダプターと既存内容との一致、公的許可アダプターの過不足のある列、行為アダプターの順序・長さも検査した。二引数の行為への許可は、先行版と対応する規範の解釈を与えた4組で一致した。基本関係同士を自動的に同一化した結果ではない。

関連29テストが通過し、保存済み検証記録との再生成一致、旧定義・主張の保持、要求の引用と未履行判定の引用制限も確認した。

一般形が扱うのは有限の個体列であり、任意の型を混在させた引数列ではない。長さが正しくても、社会的な役割に適切な個体を渡したかは対象の意味規約に依存する。順序を変えた三引数は別の政策対象となり、正しい順序へ自動修正しない。全ての有限列に対する一般的な証明を、有限例の検査で代替しない。

「常に」「しばしば」「非常に狭く」「啓蒙を特に妨げずに」という時間・頻度・程度・留保、権利保障、公衆や役割の基本的な意味、原文全体との意味一致は未完である。今回の原文対応範囲は既存部分と重なり、対応文字数や意味一致確認済み区間数は増えていない。
