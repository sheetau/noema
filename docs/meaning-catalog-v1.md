# 継承した意味規約の一括点検

本文の各記号について、型・定義・意味説明と、その説明を導入した文書を取り出せるようにした。最新版のカント草案は0.14の基礎と六つの差分からなる。新しい定義の説明だけを読むと、継承した基本関係や文脈依存の条件を見落とすため、引用の内側も含めて依存先をたどる。

## 検査対象

`noema.meaning_catalog` は0.13から0.16の明示的な版を読み分ける。意味規約の基礎文書では全宣言、差分では追加宣言だけについて、説明の有無と型の一致を検査する。空の説明、余分な記号、引数名の不足・重複、JSONキーの重複を拒否する。

継承元の文書と意味規約が一致し、既存宣言の型・定義本体・順序が変わっていないことも確認する。版の降格、循環参照、指定したプロジェクトの外のパスを拒否し、読んだ入力のSHA-256を出力する。この入口は宣言を末尾に追加する系譜を対象とする。既存定義を改訂した版は、別途確認した完全な意味規約を起点として扱う。

| 文書 | 基本記号 | 合成定義 | 本文の文 | 意味規約の段階数 |
| --- | ---: | ---: | ---: | ---: |
| カント・定義質問まで | 258 | 1,116 | 16 | 7 |
| アインシュタイン・正方向の校正まで | 894 | 1,323 | 206 | 1 |
| 定義質問の独立ライブラリ | 0 | 4 | 0 | 7から投影 |

独立ライブラリは同じ版・同じ宣言の部分集合として検査する。宣言の改変や順序の変更は拒否する。本文については追加・削除した文の件数と順序を含む一致を別に記録するため、定義を抽出しただけで本文を保存したとは判定しない。

## 説明を読む手順

リポジトリのルートで実行する。出力先は未作成のファイルを指定する。同名ファイルの上書きは拒否する。

```powershell
python -X utf8 -m noema.meaning_catalog audit --basis data/definition-question-basis-v1.json --output artifacts/kant-meaning-audit.json
python -X utf8 -m noema.meaning_catalog explain --basis data/definition-question-basis-v1.json --symbol hzic --output artifacts/kant-title-explanation.json
```

`explain` では指定した記号と、その定義が静的に参照する全宣言を元の順序で出力する。各宣言には意味説明、説明の出典、型付きの定義本体、直接の依存先と最終的な基本記号を含める。関数・性質記述などの未指定の引数は `formal_parameters` に残す。実行時に渡す引数の内容は推測せず、Noemaの式も評価しない。

カントの表題の質問と回答を結ぶ `hzic` は40宣言を参照し、そのうち20個が基本記号である。能力評価に採る結果の範囲、決意・勇気・理解能力の十分さ、原因として採用する説明、著者による提示関係と局所参照などが含まれる。この一覧から、外部に置いた条件と既に合成した部分を区別して読める。

基本記号への静的な依存が零でも、引数として関係を受け取る定義は、意味をすべて説明し終えたことにはならない。質問の独立ライブラリにもそのような定義がある。引用内の定義参照を追うことと、引用内容が真であると判定することも別である。

## 検証と残る作業

21テストで、説明・型・継承元の不整合の拒否、同じ型のまま定義本体を変えた場合の検出、引用内の参照、未指定の関数引数、版0.15の層の保持、抽出文書、CLIの出力と上書き拒否を確認した。三文書の定義・本文の基本記号への依存先を、従来の各版の検査器とも照合する。

```powershell
python -X utf8 -m pytest tests/test_meaning_catalog.py -q
python -X utf8 -m scripts.check_meaning_catalog
```

[検証記録](../reports/meaning-catalog-v1.json)は入力を固定し、表題の20基本記号の説明も収録する。説明が存在し型が一致するという検査であり、説明自体の十分さや原文との意味一致の判定は含まない。本文ごとに、必要な範囲・基準・参照を確定し、否定・量化・因果・著者帰属の取り違えがないか確認する作業が残る。今回の記録には新しい原文対応を加えず、[進捗集計](written-progress-v1.md)の意味確認済み区間数を変更しない。
