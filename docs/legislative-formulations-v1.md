# 立法の範囲と同じ法の定式

第九段落第二文の「その統治者の立法」「そのよりよい定式」「既に与えられたもの」を接続する依存群である。全文の判断はまだ行わない。

立法の対象範囲は、同じ共同体の君主が保持する同じ最高統治職へ結ぶ。本人の私的な所有物や本人が起草した法だけには限定しない。法は既存の完全な人民・共同体・非空の全規範条項を使い、名前だけで説明を済ませない。

定式は、法として定める内容を言語的に構成して示す文案として読む。法そのものや媒体の写しとは区別する。法の全条項が定式の規範部分に表され、逆にその全規範部分が同じ法の条項を表すことを確認する。重複表現は許し、一対一対応や現に印刷された物を要求しない。閉じた内容を表すことと、その規範が現に成立することも別である。

改訂は同じ公的規律の課題に対する改め方として比較元と候補を結ぶ。文章のみの変更に限らず、条項の追加・削除・変更も許す。両方でそれぞれの全内容を表す定式を使う。比較元と候補の法内容の同一性又は差異を強制せず、どちらがよいかは別に判断する。

既に与えられた法については、同じ法の採択活動・制度上の設定・全条項の規律状態を同じ先行点に結ぶ。現在の統治者が自分で制定した法だけにはしない。現在の提案や別法の制定を過去の証拠にせず、過去の制定から現在も有効だと自動的には導かない。
