# 入出エネルギー、仕事率、光圧と近似

アインシュタイン1905年論文のu0222–u0225にある、鏡に入る光と出る光のエネルギー、光圧による仕事、光圧の式、低速での近似をNoemaへ部分的に接続した。前版の反射による振幅と方向を再利用し、仕事率の符号と、速度が零の場合の未決定性を保持する。

原刊915頁の6つの数式要素を画像と照合した。今回の式に転記訂正はない。前版で確認したM0376の振動数最右辺の不整合は、その記録を保持している。今回のエネルギー収支は振幅と方向を使うため、不整合な振動数式を同一視して補正する必要はない。

## エネルギー収支を共有する値

光速度をV、鏡の符号付き速度をv、入射光の振幅と縦方向余弦をA、a、反射後の値をB、bとする。密度を指定する正の係数Cを使い、同じ単位面積・単位時間の規約で入出するエネルギーを次のように表す。

```text
C I = A²(Va−v)
C O = B²(v−Vb)
```

Noemaでは、入射・反射の相対法線速度Va−v、v−Vbを非負にする。この条件は、数値を正にしただけでは補えない。等号は鏡を掠める境界として許し、実際に光が到着したという断言は加えない。振幅が零でもこの幾何的な条件を保つ。

同じI、O、vについて、仕事率Wと非負の圧力Pを結ぶ。

```text
W = I−O
W = P v
```

vとWには負の値を許す。例えば鏡が光に向かって動く場合、反射後の光へ出るエネルギーが入るエネルギーを上回り、光が鏡にする仕事率は負になる。この場合を、流出量が不正という理由で拒否しない。

`sekf`と実数版の`sekm`は、反射、入出エネルギー、仕事の条件を同じ引数で結ぶ。圧力の結論を前提に含めない。先行する反射の三段階から得た振幅・方向の式との対応も、有理数の代数で検査した。

## 速度が零のときの扱い

v≠0なら、これらの条件から次の光圧式を導ける。

```text
C (V²−v²) P = 2 A²(Va−v)²
```

この式自体はv=0でも値を持つ。しかし、仕事の式だけから静止時の圧力を一意に決めることはできない。例えばV=5、v=0、A=B=2、a=1、b=−1、C=8とするとI=O=5/2、W=0である。P=1でもP=2でも同じ仕事の条件を満たすが、上の光圧式を満たすのはP=1である。

`seke`と実数版の`sekl`は光圧式を表し、仕事からの決定とは分ける。静止時の値を運動量移転や連続性から物理的に正当化する部分は未完である。今回は零速度でvによる除算を行い、式だけで決定できたことにする処理を避けた。

## 近似の項と誤差

原文に続く近似式は、速度零の項P0として分けた。

```text
C P0 = 2 A²a²
```

`sekg`と実数版の`sekn`がこの条件を表す。一般の非零速度でP=P0とは要求しない。厳密式と近似項から、差について次の恒等式が得られる。

```text
C (V²−v²)(P−P0) = 2 A²[−2Va v + (1+a²)v²]
```

さらに、|v|≤V/2の範囲では次の上界が成立することを有理数について検査した。

```text
|P−P0| ≤ (8 A²/C) |v|/V
```

V、A、a、Cを固定して速度比を小さくすると、誤差を抑える値も小さくなる。この上界は比較に使う数学的な条件であり、原文がこの誤差評価を明示しているとは扱わない。原文の「最初の近似」を、速度に一次まで正確な展開と読み替えることもしない。

## 8πとの接続と検査

有理数の独立文書ではCを任意の正の係数として扱う。原文に対応する実数版の`seko`・`sekp`・`sekq`では、既存の積分によるπの指定を要求し、C=8πを収支・圧力・近似項へ渡す。[原刊PDF](https://sedici.unlp.edu.ar/bitstream/handle/10915/2786/Documento_completo__.pdf?isAllowed=y&sequence=1)の照合根拠は[記録](../data/light-pressure-facsimile-v1.json)に固定した。

代数検査は10件で、反射との対応、流出側の向き、エネルギー差の恒等式、非零速度での圧力、静止時の未決定性、近似誤差などを扱う。誤った主張2件は反例として拒否した。

有限検査では、速度3通り・方向5通り・振幅2通りの30設定を用いた。流入側の条件を満たす18設定で収支が成立し、残る12設定はこの面への流入出の条件を満たさない。22対照例では、中間値の混入、仕事の符号の逆転、近似項との等置、無効な速度・振幅・方向、πの条件の欠落などを区別した。

実数の検査には登録した有理数切断を使い、πの積分条件を明示的な真偽へ置き換えている。検査用の数値3はこの条件を照合するための代用値で、πの値として採用したものではない。全実数の演算法則、πの積分、連続性、物理的なエネルギー原理を証明した検査ではない。

## 残る意味の接続

単位面積・単位時間は同じ規約で正規化した値として扱っている。面積や時間の測定、圧力の量の種類、単位の実現、鏡と光の所属、接触出来事、完全反射の境界条件は残る。仕事やエネルギー原理の一般的な物理的説明、経験と他理論との一致、著者が「明らか」とすることや導出を提示する談話も未完である。
