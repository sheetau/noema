# 球面波と二原理の両立を述べる段階

アインシュタイン§3の `u0086`〜`u0091` を部分記述した。両立性の証明がまだ提示されていないという冒頭の留保から、共通原点での球面波の放出、方程式の変換、両立が示されたとする著者の結論までを接続した。著者の結論への帰属と、検査器による証明認定は分けている。

```text
静止系の波面: x²+y²+z² = V²*t²
運動系の波面: ξ²+η²+ζ² = V²*τ²
```

`sqg` と `sqj` は球面式の左辺と右辺の差を、それぞれ有理数と実切断で表す。既存の四座標式を使うと、この差はφ²倍になる。有理数の代数についてその恒等式を検証し、静止系の差が零なら運動系の差も零になることを確認した。この段階ではφ=1は必要なく、その値を決定したことにもならない。

式が成立することと、未来へ広がる非退化な波であることは異なる。φ=0なら全出力が原点へつぶれても二乗方程式は成立する。φ<0なら二乗方程式を保ったまま時刻の向きが逆になる。`sqk` は二乗方程式、`sql` はさらに時刻が正である側を表す。共通原点での放出時刻t=τ=0は `sqo` で別に記述した。正のφと0≤v<Vのもとで未来側が未来側へ写ることは、有理数の検査で確認した。

波を単に一つの座標点として扱わない。`sqm` は同じ波を構成する光線と、同じ放出出来事からの伝播を結ぶ。`sqn` は対象範囲の全出来事・記録について、実際の到来と未来側の球面式が過不足なく一致することを要求し、到来点の存在も要求する。波面上の一方向が欠ける場合、球面外にも到来がある場合、空の波や空の出来事範囲は区別できる。ただし、対象範囲が連続空間の全点を含むことは有限の検査例からは示せない。

`sqq` と `sqr` は選んだ同一出来事の両系の記録に式を結び、`sqs` は既出の四座標式を変換の前提に含める。`sqz` は未来側の波面へ進むため、両系の記録の存在、正のφ、同じ到来を両系で追跡することを追加した十分条件の解釈である。この条件を著者の逐語的な前提とは扱わず、追加注記 `zfl` で区別する。

両立性の `sqh` は、同じ許容設定で二つの内容が共に成立し得ることを表す。異なる設定で片方ずつ成立するだけでは満たさない。`sqw` はこの関係へ先行する相対性原理 `saw` と光速度一定 `sbd` を渡す。許容物理設定の一般的な構成は未完であり、今回の有限モデルは物理的な両立性そのものの証明ではない。

`sqi` はある内容の証明として提示した論証の存在を、主体・論述段階・範囲に結ぶ。`sqx` はその存在を否定して「まだ提示していない」を表す。対象の主張が偽であることや、証明が不可能であることは含めない。後の段階での提示が、前の段階の状態を書き換えることもない。本文中の証明課題は `zga`、未提示であることを課題の理由として挙げる関係は `zgb` に分けた。
