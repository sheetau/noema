# Concept 2 v3：作図と読解を同時に定める

## 円弧と接続

中大円の直交交差では、中円内の大円弧を常に残す。重なり側90度のうち、中円の外側に出る二つの部分だけを一括して残す／消す。残りの大円弧は45度単位で選び、外側に最低45度を残す。交点まで消して中円内の弧を失うv2の処理を訂正する。

小円の内部には直線を一切入れない。端点が円周上でも、その手前の線分が内部を通るなら違反とする。円周で止めるか、別の接続口を使う。

接続は「実際に線が接する場所」と「長さを測る基準」を分ける。中大円の左右の開口が135度以下なら、欠けていても完円周の左右端を基準にする。180度以上空いていれば実際の接続位置を基準にできる。両方が該当する同心の中大円では大円を優先し、第4円は繰り上げの対象にしない。外部の半径幅は中円半径r₂。折返しにも同じ計算を使う。

## 同じ形の連続と分岐

同じ値の反復は、既存の共有・局所略記を優先する。同一綴り要素などの連続には、直前の一要素を指定回数へ展開する回数表記を使える。小円だけの形は対象外。円を含まない縦線の半長u・r₂・r₃・r₄を、それぞれ計2・3・4・5回と読む。長い反復はこの単位を組み合わせる。文末が回数線になる場合は小円の境界形を添え、文の最後を円要素にする。展開後の順序と個数は変えず、明示的な反復を残す選択肢も維持する。

隣接する共有引数を、幹から枝へ分けた一つの構成にできる。幹に沿った接続口の順番を引数順とし、枝が上下のどちらに出るかで順番を交換しない。枝先の形が参照する宣言を示す。枝は実際の使用箇所であり、装飾として付けない。

引数群の区切りは、円と縦線を組み合わせた形を基本にする。円周を介して上下へたどれる構成とし、小円を線で貫通しない。後続の群が値・引用操作を含む群・宣言済みの参照の群のどれかと、その呼出しの最終群かどうかで六形を使い分ける。円を含む区切りの上下端はr₄のままとし、円を含まない縦線を使う場合だけ中央からの四段階の長さを区別に使う。

大円の斜め端と小円による無線接続は、公開された根語対の合字にも使う。小円→大円と大円→小円を左右の順序で区別し、上下はその合字を置く引数位置に応じた異体とする。四方向を復号器に登録し、同じ根語列へ戻す。斜め線は第4円の高さで止め、大円端から小円中心への水平距離をr₂に保つ。

## 読解の境界

共有の公開綴り辞書を使う。根語列が別の語の先頭にもなり、直後の形を連結するとその語を延長できる場合だけ語末を明示する。延長不能なら辞書の綴りだけで境界が確定する。接続先の型や元の文に境界推測を任せない。合字と回数表記は、辞書照合の前に根語列へ展開する。

字形は、同じ位置の円要素を取り残さずに一致する最大の公開構成を読む。同じ大きさの候補が複数残る場合は拒否する。必要な内部線に加え、残った線が公開された接続規則で全て説明できることを確認する。円だけが似ていても、線の余りや不足を許して読み進めない。分岐の幹順、語境界、既知の引数数、中置の優先順位、明示した範囲を順に使う決定的な規則とする。

SVGから円・円弧・線・ドットだけを読み取り、公開字形規則、接続規則、公開辞書で構成を回収する。元の構文、文番号、保存した構成列、SVG要素順、隠し属性を復号器へ渡さない。異なる構文へ読める候補が残れば成功にせず拒否する。

最初に短い対照例を検査し、その後同じ4段落40項目へ適用する。構文の一致と語義・参照先の不変を確認する。画像の画素認識、手書き誤差への頑健性、未対応の構文を含む全言語の一般証明は、この検査の成功と区別する。

## 対応範囲

今回の復号器は、本文と対照例に使う呼出し、否定・連言・選言・含意・等値、引用と階数、関数参照、適用、状況での評価、個体型一変数の束縛、共有、局所略記、ドット対を扱う。未対応の型・複数引数の束縛・他の構文は生成時に拒否する。固定字形からの一意な読解と、全ての許容図形を自由に置いた場合の一意性を同一視しない。

同心、直交交差、接触、小円によるくりぬき、中大円の日食、円を含む区切り、幹からの分岐、大円の四方向接続を組み合わせられる。八方向の中心線のうち、各方向を全て独立した意味参照として使う一般化と、任意の三段配線を自由に合流させる構文は残る。形を出すためだけに本文の意味を追加しない。
