# 思考様式の改革の結果条件

第四段落第五文の `wahre Reform der Denkungsart` を、自分の理解力と理由によって判断する仕方への実際の変化として読む。[原文](https://korpora.org/Kant/aa08/036.html)の後半は、新しい偏見が古い偏見と同じ働きをすると続く。その対比から、意見の内容が入れ替わるだけでは改革に足りないと解釈する。

[AA VIII146の別著](https://korpora.org/Kant/aa08/146.html)は、自己思考を知識量から区別し、自分の理性による検討を述べる。この照合を1784年本文の逐語的な定義とは扱わず、別著の宗教論や普遍化試験の全条件は補わない。

## 判断の仕方を評価する

`r2ql` は、同じ本人・対象・場面に対応する全判断へ、既存の `r2gy` を適用する。自分の理解力を使うこと、同じ判断に用いた理由の支持、他者の指導の不在、実際の生起を要求する。内容の正しさだけ、自己申告、別の判断での理由の存在では足りない。

`r2qm` は、固定した領域の全対象について、非空な比較、基盤の保持、外的機会、対応する取り組み、通常性の順序を検査する。`r2qn` はさらに全ての通常場面で `r2ql` を要求する。通常性に劣後する例外は許す。領域や通常性を成功結果から決めることは、基本関係の意味規約で禁じる。現実に適切な範囲を選んだかは、有限モデルでの形式検査とは別の解釈上の要件である。

この構成は、判断に取り組む機会を与えた場合の傾向を評価する。能力があるだけの人、偶然一回だけ理由ある判断をした人、個々の新しい意見を覚えた人を、それだけで該当者にしない。生涯の全ての判断で失敗しないことも要求しない。

## 実際の変化を要求する

`r2qp` は、有効な履歴の前後点と同じ本人への作用を持つ過程を要求する。前後とも同じ領域を評価でき、前には `r2qn` がなく、後にはある。前の入力不足を「改革前」、過程のない二状態の違いを「改革」と扱わない。

`r2qq` は、この変化を結果内容として引用するための関数である。改革過程に特定の訓練や革命を埋め込まないので、革命がこの結果を生むかどうかは、先行の `r2qk` の因果関係で別に扱える。

## 今回の範囲

自己判断の局所実行、固定領域の通常比較、同じ本人の変化、革命の二結果対比への接続を検査する。接続検査では、前後の傾向を評価する部分を境界として置く場合と、局所でその定義自体を実行する場合を区別する。

公衆全体の対象範囲と共通の候補供給、著者帰属、様相・対比、後半の新旧の偏見と誘導、第五文全体の通読は残る。既存61文と13区間の意味判断、段落先頭四文771非空白文字の確認を保持し、第五文の意味確認済み分量は増やさない。
