# 第八段落第三文の依存群：先行する自由と、それを支持する態度

第三文の「この自由の精神」へ向け、先行二文の宗教的自己選択・公的提示の自由と、それを好ましいあり方として支持する態度を分けた。第三文全体の完成ではなく、本文114主張と確認文字数は変えない。

r55wは同じ君主・統治職・共同体の管轄下の人々と、固定した対象集団の成員を正確に一致させる。r55xは全ての聖職者の組へ既存r55cの自由・非免除・共充足を接続し、r55yは先行聖職者群の外の人について、全職務による無制約を条件に全公的提示の自由を述べる。r55zはその二条件と、r5v7の全宗教的自己選択の自由を同じ評価点へ結ぶ。

この内容は自由のあり方を述べるため、君主の自己報告、寛容という名称を拒否する評価、功績などを前件にしない。一方、r5xhの君主的統治職は先行する例の設定として保持する。政府組織一般を人一人として扱う定義ではない。公的提示の規範出所は、先行定義と同じ基準のh247bを使う。

r552はこの自由内容を同じ五対象と固定基準で閉じ、r553は呼称の指示先を照合する。r554/r555は、それを支持する人と態度の評価点を別に置く。新しい基本関係h26pgは命題内容への肯定的な受容であり、引用された自由の実現や信念ではない。先行のid/h26ntと同様に、態度を持つことから内容の現実の真理、実際の発話・行動、客観的な善を導かない。

検査は全人物と全六対象の量化、範囲の不足・混入、同じ比較関数、全自由条件の連言、呼称と内容の同一性を扱う。既存の深い条件は独立の検査報告を保存し、今回の量化検査では明示した引数境界を使う。態度の検査では引用内の自由・義務・行動を未知のまま残し、内容を実行せず支持を記述できることを確かめる。

残る作業は、この先行例への支持と自由一般への志向の関係、元と外の統治圏、同じ態度の共有・取得・影響経路、障害・格闘の必要・政府の自己誤解、auch/selbstと全文帰属である。既存の発話伝達モデルは受領する同一発話を必須とするため、そのまま第三文へ入れると条件を加えすぎる。単なる前後の人数差だけでも社会的な広がりの全内容とはしない。
