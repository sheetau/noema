# τの局所的な微分条件と、二つの微分形の式

アインシュタイン§3の `u0054`〜`u0057` を部分記述した。微小なx′から得る式と、それを整理した式を、同じτ候補・評価点・偏微分値へ結ぶ。

```text
½(1/(V−v) + 1/(V+v)) ∂τ/∂t = ∂τ/∂x′ + (1/(V−v)) ∂τ/∂t
∂τ/∂x′ + (v/(V²−v²)) ∂τ/∂t = 0
```

前者を `sjx`、後者を `sjy` で構成した。両方とも有効な実切断と `0≤v<V` を要求する。ここでは原点 `(0,0,0,t)` の値を扱い、任意の場所へ成立範囲を広げることはしていない。

`skc` は、固定したτ候補・速度・時刻について、指定した正の半径より小さい全ての正の変位hで前段の中点式が成り立つという条件である。一つの光往復や、有限個の距離での一致ではこの条件を満たしたことにならない。原文の「無限小に選ぶ」は、hを正側から0へ近づける通常の実数の極限として解釈した。

`sjw` は、同じ四引数関数のx′とtの各切片を作り、他の三変数を固定して偏微分値を指定する。差商の極限には既存の `li` を `sjs` として再利用した。有効な関数、近さ、集積点、極限の定義も記号を置換して再利用し、元の構文木との一致を確認した。切片の定義域には全ての有効な実切断を使う。

偏微分が別々に存在することだけでは、二変数を同時に動かす経路上の連鎖律は得られない。このため `sjv` では、yとzを固定した二変数の一次近似を明示する。任意の正のεに対して正の近傍半径δがあり、全ての非零の変位 `(dx,dt)` について、関数値と一次近似との差が `ε(|dx|+|dt|)` より小さくなる条件である。

この条件が必要になる理由は、`F(x,t)=xt/(|x|+|t|)`、`F(0,0)=0` という例で確認できる。両軸上ではFが0なので原点の二偏微分は0だが、正のhに対して `F(h,h)=h/2` となる。零の一次近似では、εを1/8にすると誤差が `ε(2h)` より常に大きくなる。今回の有理数検査は、この正のhでの商の等式と誤差の不等式を確認する。

推論前提 `skd` は、先行する試行とτ候補との接続、任意に小さいhでの中点式、二変数の全微分可能性、同じ評価点の偏微分値を要求する。これは導出を扱うための十分条件を明示した解釈であり、原文がこの形で前提を書いているとは主張しない。先行する線形性からこれらの条件を導く接続も未証明である。
