# 原刊照合による数式の転記訂正

§5の速度合成式の記述を進める際に、保存済みのWikisource電子テキストと原刊画像の食い違いを二箇所確認した。数学的に自然な式へ推測で書き換えるのではなく、[原刊906頁の画像](https://thumb.wikimedia.org/wikipedia/commons/thumb/e/eb/Einstein-Elektrodynamik.djvu/page16-1920px-Einstein-Elektrodynamik.djvu.jpg)を目視で照合した。画像は [Commonsの資料](https://commons.wikimedia.org/wiki/File:Einstein-Elektrodynamik.djvu)の16頁目である。

| 対象 | 保存済み電子テキスト | 原刊画像で確認した表記 |
| --- | --- | --- |
| u0140 / M0257、速度の大きさの式の分母 | 1 + vw sin α / V² | 1 + vw cos α / V² |
| u0146 / M0273、光速についての式の分母 | 1 + w/v | 1 + w/V |

M0257の分子にあるsin αはそのまま残す。M0273では、相対速度の小文字vと光速の大文字Vを区別する。確認したのはこの二箇所の文字であり、原刊全頁の照合や周辺の意味確認を終えたものではない。

訂正台帳は、元の数式のSHA-256、対象となる分母、変更前後の文字、原刊画像のURL・バイト数・SHA-256、確認方法を保持する。適用関数は対象のハッシュと一箇所だけの一致を要求し、元のMathMLを変更せず別のMathMLを返す。対象が複数ある、変更前の文字がない、ハッシュが異なる、未確認の訂正である場合は停止する。元のスナップショットと既存の対応表は保存したままである。

後続の草案から訂正版を使う場合は、`reviewed_math()` を明示的に呼び、返される訂正ID、元と訂正版の数式、両者のハッシュを記録する。既存の読み込み処理が黙って訂正版へ切り替わる仕組みは追加していない。原文への対応は、どちらの表記を採用したか分かる形で残す必要がある。

Noemaによる検査用文書も追加した。V=5、v=3、w=1、方向が平行な例では、原刊の分母から得るUは25/7、電子テキストの分母から得る値は4になる。光速についての式では、V=5、w=1、小文字v=3とすると、原刊の式は5、電子テキストの式は9/2になる。速度が零になるなど、誤記が数値に現れない例も別に検査した。これらは原刊の読み取りを補う代数的な検査であり、数学的な正しさだけから原刊の表記を決める手順ではない。

検査用文書は、方向の余弦・正弦に相当する二値と平方根の非負条件を、有理数の多項式条件で扱う。九つの主張候補のうち、誤った読みが正しい値を保つという二候補は反例によって退けられ、残る七候補は検証を通った。この文書には意図的に成立しない検査候補も含む。論文のNoema訳や著者の断言として扱わない。

新規8件を含む関連20テストが通過した。訂正箇所が分母の一文字だけであること、分子が変わらないこと、元資料が変わらないこと、曖昧な訂正を拒否することを検査した。通常記法・短縮記法・固有文字の構文上の往復も確認した。

今回の作業は原文の信頼性を整えるものであり、翻訳の対応範囲を増やしたとは数えない。アインシュタインの部分草案の明示範囲は36.62%、意味一致の確認済み区間は両作品とも0のままである。速度の大きさ、角度、近似と周辺の論述のNoema記述は引き続き必要である。
