# 第5節の点の運動と現在の座標記録

原刊905頁のu0130–u0132は、X方向へ一定速度vで動く系kで、一つの点がξ=wξτ、η=wητ、ζ=0に従って動くという設定である。二つのwの成分は同じ定数として後続へ渡される。旧草案の数式に、現在の測定と全実時刻の履歴を接続する。

点は、同じ位置対象を一つの三座標の世界線として追う運動学的な理想化と読む。質量や電荷は指定しない。同じ対象の出来事・記録・場所・系・単位を結び、現在の局所時計による時刻と物差しによる位置を、代表位置の完全な履歴へ対応させる。全候補記録の一致と、全実時刻の現在記録の存在を別に要求する。

一般の定速度は、任意の初期位置からの三成分の位置変化が、同じ三速度成分と経過時間の積になることとして構成する。負・零・正の成分を許し、点の速度に光速上限を追加しない。原文の平面と原点を通る条件は、全期間の下端に三式を課すことで別に結ぶ。下端を零時刻と仮定せず、任意の時刻で同じ式を満たす。

系K/kは第3節と同じ配置、単位、現在の比較状況を使う。系の速度vと点のwの成分、Kの時刻とkの時刻を混同しない。längs der X-Achseは既出の正X方向への等速並進として読む。新しい原点設定や同期操作は補わない。

今回はこの意味依存群を点検する。第5節見出しの速度合成定理という主題、bewegeという仮定提示、式の提示と二成分の記号説明、各単位全体の意味判断は次に接続する。u0133の運動を求める課題提示と§3の変換式の適用、u0134の結果の三式も残る。有限検査の成功を、これらが記述済みであることには数えない。
