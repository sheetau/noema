# 三量の定義導入と角の意味

原刊905頁のWir setzen:に続くU、w、αの三つの式を、一つの定義導入として接続した。u0137のundはU/wの二定義ejomとαの定義ejozの連言、及びwの式からαの式への本文順序で保持する。直後の906頁の「αをvとwの間の角と見る」は、同じαの値を幾何学的な役割として理解する説明へ結ぶ。

αは前段の[積分による実数角](velocity-angle-measure-v1.md)を使い、正の系速度vから点の速度への向き付き角の代表(-π,π]と読む。成分比の逆正接の主値に、二成分の象限による補正を加える。これは明示した解釈であり、原文が完全な枝の規約を逐語的に述べたとするものではない。零の速度には角なし、縦成分零では印刷された商なしとする。幾何学的な直角の指定と商の定義を混同しない。

実数の測度eiso4、単位円の二成分zkt、表記の個体eiso5を区別し、同じ点・K/k・速度成分・速さ・現在文脈へ合成側で結ぶ。三量の定義導入は同じ著者の発話内容へ帰属させ、定義の引用を実際の測定や積分の実行へ変換しない。新しい関係eiso7は、型付きの数量規則を同じ値と状況の意味・役割として理解する説明である。角度に固有の数学は含めない。

旧部分主張の文131・132だけを現行稿で置き換えた。旧s2kは逆正接の枝を未確定のまま残し、旧s2mは向きなし角としていたため、今回の読みと等価とは扱わない。旧定義・旧本文・旧判断は保存する。その他354文と過去の全単位判断の依存は保ち、同じ内容のものだけを登録し直す。
