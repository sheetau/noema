# 速度間の角の実数測度

対象はu0137のund、u0138のα=arctg(wη/wξ)、u0139前半の「αをvとwの間の角と見る」である。今回は、この一続きの定義導入に必要な角度の依存群を作る。著者の提示と全単位判断は次の統合で行う。

原刊905–906頁を照合し、角を正の系速度から点の平面速度への向き付き角、代表値を(-π,π]と読む。逆正接の主値だけでは負の縦成分で方向を区別できない。主値A=∫₀ʳdt/(1+t²)を先に定め、縦成分正ならA、縦成分負・横成分非負ならA+π、両成分負ならA−πを選ぶ。これは明示した解釈であり、原文がこの枝を逐語的に指定した、あるいは歴史的慣習を一意に確定した、とはしない。[DLMF 4.23](https://dlmf.nist.gov/4.23)は積分表示と逆関数の枝の区別の参照であり、Einsteinの意図の証拠ではない。

主値ejorは、既存の正方向の全タグ付き分割積分sedeと被積分関数sedhを使う。負の上端では区間と値の符号を反転し、零では値零を明示する。円周率は既存のsediを使い、別の数値定数を導入しない。ejosは元の二成分と比をx*r=yで結び、x≠0を要求する。

単位円上の向きと実数角度は別の対象である。ejotが両者を接続し、ejouは既存の内積と有向面積によるs2gを再利用する。余弦零の直角はejotで±π/2と指定するが、元の商を定義したことにはしない。零ベクトルには角を与えない。ejov/ejowは同じ現在のK/k、実際の相対速度、同じ点のk速度と大きさを共有する。ejowだけが元の商を含む指定も要求する。点の光速上限は追加しない。

旧s2k/s2mの部分主張は、逆正接の枝を未確定とし、角を向きなしで表していた。今回の依存群は新たな主張を加えていない。本文統合ではこの二つの部分主張を現行稿で置き換え、原文対応と未変化の判断を検査する必要がある。旧証拠を消したり、二つの読みが等価であるとして再登録したりしない。

検査では、実際のNoema本体による被積分関数・象限・内積・有向面積と、全実数積分を境界に置いた引数接続を分ける。境界検査のπや主値の有理数は接続確認用の仮値であり、実際のπや逆正接のモデルではない。小さい分割の有理数和は積分近似の確認に限る。全実数の量化を有限列挙へ変更せず、ネイティブ評価が拒否することも確認する。通過例数は原文の意味判断の代わりにならない。
