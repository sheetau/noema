# 複数の結果から選ぶ能力と、選択の順序

二値の決定規則に限らず、複数の方法・他者側の応答・結果を持つ選択を記述した。一つの方法と応答の組合せに複数の可能結果がある場合も扱う。指定した結果が起こり得ることと、本人が一つの方法を選んで結果を保証できることを分ける。

モデルは三つの有限列と可能結果関係から成る。方法は本人に利用可能とする手段、応答は他者側や環境側の応答配置、結果は同じ対象について区別する帰結である。それぞれの列が指定範囲を重複なく完全に列挙していることを確認し、全ての方法と応答の組合せに、評価済みの非空な可能結果集合を要求する。指定した結果列の外に可能結果があるモデルも無効とする。

| 定義 | 内容 |
| --- | --- |
| `rqqa` | 三範囲の完全性と全組合せの評価・結果の存在・範囲内への収まりを検査する。 |
| `rqqb` | 指定した一つの方法で、全応答の全可能結果が指定目標に一致する。 |
| `rqqc` | 指定目標について、そのような方法が存在する。 |
| `rqqd` | 二つ以上ある全目標について、それぞれ保証する方法を選べる。 |
| `rqqe` | 応答を知った後なら、各目標を保証する方法を選べる。比較用の別条件。 |
| `rqqg` | 同じ相手・対象・基準点の結果範囲を固定して、各評価時点のモデルが有効か検査する。 |
| `rqqf` | 対象とは別の相手が、同じ基準点の結果範囲について`rqqd`を満たす。 |
| `hzhu` | 有効かつ評価済みの前後で、同じ相手との`rqqf`の関係から離れる内容を作る。 |
| `hzhv` | 設定の記述から、その同じ離脱内容の記述を構成する。 |
| `hzhw` | 因果対比の第一の結果へ、その同じ内容記述を渡す。 |

`rqqd`と`rqqe`は選択順序が異なる。次の表では、目標をAに固定すると、左の応答なら方法1、右の応答なら方法3を選べばよい。しかし相手の応答を知らずに一つの方法を選ぶと、Aを保証できない。BやCについても同様である。このモデルは`rqqe`を満たし、`rqqd`を満たさない。

| 方法 | 応答が左 | 応答が右 |
| --- | --- | --- |
| 方法1 | A | B |
| 方法2 | B | C |
| 方法3 | C | A |

これに対し、方法1が左右ともA、方法2が左右ともB、方法3が左右ともCなら`rqqd`を満たす。目標ごとに方法を選ぶため、全目標を同時に実現する要求ではない。また、A・B・Cのどれが生じるか定まらない方法4を追加しても、先の三方法が残っていればこの能力は失われない。全ての方法が確実であることと、各目標を確実に実現する方法があることは異なる。

一方、方法1の左側でAまたはBが生じるなら、その方法はAを保証しない。成功する結果だけを取り出して評価したり、可能結果がない組合せを全称命題の空虚な真で成功としたりしない。二値の決定的な全16規則では、前段の一方的な決定力と同じ判定になることも検査する。

前後比較では、結果列と結果範囲を同じ相手・対象・指定基準点に固定する。後の時点だけ目標結果を追加・削除して、能力を失ったように見せない。方法や他者側の応答の範囲は各時点で変化してよいが、両方の時点で完全性と全組合せの評価を要求する。離脱内容から作る引用は、方法・応答・結果や因果関係を実行しない。

## 検証と利用

二方法・二応答・二結果の可能性関係は、空集合を含めると256通りある。その全てについて、Noemaの有効性・各目標を先に選ぶ能力・応答を見てから選ぶ能力・一つの目標への能力を、独立したPythonの集合判定と照合する。三結果、結果が複数ある方法、追加の不確実な方法、定数結果、結果のない組合せも検査する。

全文草案と依存定義だけの文書で、前後の関係の継続・不在、無効な終了点、対象・過程・原因・結果記述の取り違えを検査する。リストの順序の変更、欠落、重複、範囲外の結果、未評価、未知入力、独自字形を含む表記往復、専用CLI解析、親文書の全宣言と15主張の保存も確認する。有限診断では既存の短絡評価変換を用い、元の文書は変更しない。二つの代表モデルでは元の評価・キャッシュなしとも一致することを確認する。

```powershell
python -X utf8 -m scripts.check_outcome_choice --verify-only
python -X utf8 -m pytest tests/test_outcome_choice.py -q
```

## 残る意味

このモデルでは方法と応答を独立に組み合わせる。方法によって相手に可能な応答が変わる状況、途中の観察に応じた方策、連続な選択肢、確率付きの成功はまだ別の説明を要する。評価用の有限列が現実の全手段や全応答を網羅していることを、構文・モデル検査だけで確認したとは扱わない。

利用可能な方法、他者の応答、結果の識別とその内容は、同じ場面に対する意味規約を要する。今回の定義はその組合せと量化の順序を明示するもので、現実の強制・命令・服従・制度上の権限や正当性を説明し終えてはいない。個人的専制、圧迫、革命、真の改革の完成した記述と著者帰属は引き続き残る。
