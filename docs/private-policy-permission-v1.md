# 私的使用の条件付き方針への許可

回答文の私的使用側[833,980)を、同じ本人の委ねられた職務における理性使用への許可として構成する。`darf` の出所は著者、名宛人は先行する同じ方針規範源、その立場は方針を決める立場と読む。本人の職務と規範源の立場を取り違えない。

許可の対象は「強い制限がしばしば適用され、それによる同じ啓蒙への低下が許容範囲に収まる方針案がある」という内容である。方針案の存在量化も留保も、許可の対象の内側に置く。これは採用した作用域の解釈であり、許可から現実の制限や無害性を導くものではない。全ての制限案への許可とも異なる。

人物・職務・案・要求表・選択肢を同じ基準へ結ぶ。全公衆と各公衆の全本人・職務の組を扱い、同じ本人が複数の職務を持つ場合も区別する。入力範囲を許可済みの人や結果のよい案だけへ縮めない。本人の私的使用の分類は既存の `zzp` で確認する。

程度・頻度・許容低下の基準は同じ公衆・参照で固定し、案ごとの結果から決めない。具体的数値は原文に補わない。要求表とモデルの入力欄は先行のものを再利用するが、介入要因には全期間の方針を表す別の参照を用いる。先行の単一時点の全要求適用と取り違えない。

方針は段階2の閉じた記述として許可の対象へ渡す。許可を含む節は段階3で著者へ帰属する。低い段階への変換や、引用を実行した上での許可判定は行わない。検査では方針の入力を未知にしたまま許可を評価し、許可も未知にしたまま著者への帰属を評価する。

入力の接続と量化を局所検査し、先行の頻度・完全解除・対応比較の実評価の証拠を固定する。この検査は原文の全対象や歴史的な因果モデルの正しさを証明しない。`aber` と `ohne doch darum` の対照・期待の取り消し、`Ich antworte` の自己提示、回答全体の原刊照合と通読が残るため、意味確認済み文字数は増やさない。
