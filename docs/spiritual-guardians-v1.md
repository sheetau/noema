# 宗教上の後見役と本人の未成熟への要求

対象はカント第五段落の最終文u0012[5022,5190)です。原刊487頁末から488頁冒頭へ続く文を確認しました。今回は、人民の宗教上の後見人自身が未成熟であるべきだという、評価される要求方針を構成します。不合理という評価とその永続化への帰結、Dennの理由提示まで含む全文判断はまだ行いません。

Volkは同じ政治的共同体の人々の全体として読みます。r45dは既存mpの構成員列が非空で人のみからなり重複しないことと、政治的共同体の成員h237cに全個体上で過不足なく一致することを求めます。読者世界と政治的共同体を同一視せず、会衆の一部だけを人民の全体とも扱いません。

r45eは、その人民の少なくとも一人の他者への後見関係を同じ本人・役割・宗教的な事柄へ結びます。本人の役割保持hzwn、一般的な指導・監督dc、相手の宗教的な生き方に関わる事柄sgを再利用し、同じ役割の担当範囲h253rを追加しました。一般的監督と、別人の宗教的な事柄を混ぜた証人では成立しません。一人が全人民を監督する条件も加えません。

geistlichは宗教・教会の領域を指すという読みです。[Dudenの語義](https://www.duden.de/rechtschreibung/geistlich)はこの領域指定を支えます。知的活動全般というgeistigの読みとは分けます。現代辞書だけで1784年の文の全解釈を証明したとはせず、[同じ箇所の学術版転記](https://korpora.org/Kant/aa08/038.html)と原刊の前後も照合しています。

未成熟は、冒頭以来のbfの定義を保持します。r45fは本人一個体の正確な束縛列からその内容を作ります。r45gは既存h237zで同じ本人・役割への正極性の要求を表し、本人が導く相手の未成熟への要求にはしません。r45hは宗教上の後見役の非空の全範囲へこの要求を広げ、r45iは出所・人民・政治的共同体の正確な三個体列から同じ方針内容を作ります。

全文ではこの方針を閉じた段階2の記述として評価・帰結関係に渡します。引用対象を構成しただけでは要求の実在や未成熟の現実の成立を断言せず、Kant自身の命令にも変えません。selbst wiederは他者を導く本人自身も依存を要求されるという対比へ接続する予定で、過去の成熟から再転落した履歴を追加しません。

後続の語義検討用に[Ungereimtheit](https://www.duden.de/rechtschreibung/Ungereimtheit)と[verewigen](https://www.duden.de/rechtschreibung/verewigen)も保存しました。前者には不整合な発言・関係という用法、後者には物事を持続させる用法があります。要求方針そのものの評価と、持続する複数の不合理を区別する必要があります。原文のVerewigungを無限の数値時間や個人の不死へ変換するかは別問題で、ここでは確定しません。

検査は人民の欠落・余分な成員・重複、相手・役割・事柄の取り違え、追加の後見役への要求の欠落、規範対象の極性と引用段階を調べます。bfは既存の能力評価を通常実行して一個体アダプターと比較し、規範の評価時には能力や未成熟の真偽を実行しないことを確認します。本文95主張・既存の意味判断・確認文字数は保持します。
