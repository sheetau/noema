# 同じ活動内の限定と、離脱後の譲歩

カント第三段落第四文の `nur unsicheren` と `dennoch` を、前版の最小課題・不確かな判断・不慣れの原因に接続した。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)について、同じ活動の確かな遂行を対照にする限定と、離脱を認めた通常の予想に反する帰結として読む候補である。

## 限定の範囲は、同じ判断活動の内部

一般形 `r2ia` は、同じ対象・状況で焦点の条件が成立し、明示した非空の代替条件列が全て不成立であることを表す。列にない条件、別の対象、別の時点は排除しない。期待や望ましさも要求しない。この演算自体は、焦点から含意される弱い条件を自動的に比較対象から外すものではない。呼出側で適切な代替を指定する。

今回の対象側では、対象を一つの判断活動、焦点をその不確かな遂行、代替を同じ活動の確かな遂行とした。`r2ib` は前版の不確かさ `r2gz` と同じ比較場面・基盤・機会・通常性・対応活動を使い、応答が全ての通常候補で確保される側を評価する。`r2ic` は、同じ実際の判断があり、この確実な遂行条件を満たす場合である。

`r2id` は不確かな判断を焦点とし、その同じ活動についての `r2ic` を排除する。既に前版の非確実性が同じ比較上の確実性を否定しているため、この読みでは真理条件を強めない。ここで追加するのは、どの活動のどの対照を限定しているかの明示である。新たに全方法の不可能性を主張するものではない。

`r2ie` は固定課題について、その限定を満たす判断が少なくとも一つあるとする。別の判断が確かであることや、現在の判断に理由の支持があることは許される。不確かさの範囲を本人の全判断へ拡大しない。無効な比較や実行の不在を、不確かな判断の代用品にすることもない。

## 二つの背景を分ける

最小課題に対する `auch` の尺度背景は、前版の `h222c` と `r2hu` を保つ。これとは別に、`r2ig` は既存の `ja` と `ke` を使い、同じ人物が依存から離脱したという前提を認めた通常予想の候補を検査する。

候補は空であってはならず、全候補が同じ離脱 `r2gt` を実際に満たし、不確かな判断 `r2hb` は満たさないことを要求する。違う人物、違う前提記述、違う文脈の候補を流用できない。通常候補は現実の履歴ではなく、明示した比較の入力である。

これは全ての採用候補で帰結が成立しないという、既存の譲歩の操作化である。数値確率の比較とは同じではなく、自然言語の譲歩全般を一意に定めたものでもない。また、不確かな判断がないことから、確かな判断の存在を導いていない。後者を積極的に予想する読みには、別の根拠が必要になる。

`r2ih` は、この譲歩背景と最小課題の尺度背景を同じ本人・仮定状況へ結ぶ。どちらかだけが成立する場合は、二つを含む背景全体は成立しない。期待が成立しても、実際の判断や原因が成立するとは限らない。

## 条件文と帰属への接続

前景 `r2if` は、前版の最小性と理由付き帰結に、同じ課題についての限定付き判断を加える。因果入力は引き続き `r2hh` と `r2hb` を結ぶ。限定や最小性自体が不慣れの結果だという原因を加えていない。

`r2ii` と `r2ij` は、同じ本人・仮定集合・依存離脱の前件に、前景と二つの背景をそれぞれ接続する。前件を満たす仮定も少なくとも一つ必要になる。第一文からの同じ非空の人物範囲へ広げた内容が `r2ik` と `r2il`、その閉じた記述の対が `r2im` である。

候補帰属 `r2in` は、理由付き条件文の箇所に前景、主節に背景を置き、同じ著者へ帰属する。同じ先行比喩と両側の指示対応 `r2gi`、主節から理由節への順序も保持する。引用内容を評価して現実の事実にする操作は含めない。

## 検査と未完の範囲

八テストで、焦点と代替の8組合せ、判断の実際の理由支持と通常候補の応答の8組合せ、譲歩候補の16組合せ、二人の前景と二種類の背景の64組合せを検査する。無効な比較、空の候補、前件が成立しない通常候補、人物・記述・文脈の取り違え、未知入力も対照にする。

実際の仮定と通常予想の仮定に、それぞれ依存離脱の履歴を持つ有限世界でも実行する。限定された不確かな判断と、別の確かな判断が同じ人物・課題に共存する例を許す。因果理由・最小性・尺度期待・譲歩期待を変えた対照例も検査する。帰属の検査では指示対応部分を境界入力とし、内容を実行せずに同じ前景・背景・範囲を渡すことを検査する。指示対応自体の検査は前版の記録を保持する。

引用と三記法の往復、既存の本文54文と全宣言・意味規約、十二全単位2,212文字および先頭三文408文字の判断を保持する。現行の有限評価器は論理式の両辺と内容の全状況を評価するため、範囲外の関数値を要求する場合もある。意味上の無断言と、部分入力だけでの実行可能性は区別する。

十四定義を追加し、新しい基本関係はゼロ。身体的な幅・跳躍・運動種類と、対象側の課題・判断・慣れの全対応、種類照応、第四文全体の読解確認は残る。候補帰属も本文にはまだ採用せず、原文対応文字数や意味確認済み分量は増やさない。有限検査は原文との同義性の自動証明ではない。
