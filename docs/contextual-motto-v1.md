# 著者の説明に沿ってラテン語の呼びかけを読む

カント冒頭の `Sapere aude!` を、この箇所では「自分の理解力を使うことへ、勇気を持って取り組め」という呼びかけとして記述する。新しい `hzsi` は既存の取り組みの命令 `hzs5` と、自分の理解力を使う内容 `bm` を結ぶ。直後のドイツ語が同じ目標への勇気を求め、ラテン語を説明するという著者の提示に従った読みである。

[カントの本文](https://korpora.org/Kant/aa08/035.html)と保存済み原刊481頁を再読した。[Lewis and Short の sapio II.2](https://alatius.com/ls/index.php?met=up&ord=sapio)には分別・理解に関わる語義があり、[Allen and Greenough §456](https://dcc.dickinson.edu/grammar/latin/complementary-infinitive)は同じ主体による敢えて行う動詞と補足不定詞の接続を説明する。辞書や文法だけで今回の形式化が一意に決まるわけではない。目標をこの箇所の `bm` に定める根拠は、カント自身の後続説明である。語の一般的な意味と文脈で解釈した内容を区別する。

旧草案の `bk` は、評価範囲内の全ての事柄について、理由を用い、その理由が支える判断を成功させる方法があるという能力を要求した。原文はこの能力試験を列挙していない。その獲得を命令の目標にすると、理解力を実際に使おうとすることから目標が変わる。そこで旧構成を比較資料として保存し、新しい冒頭の意味依存から外した。文脈に沿って解釈するために、一般定義や学習モデルを増やす必要はなかった。

命令の充足条件には、本人の勇気と、本人が同じ目標に取り組む行為が生じることを置く。実際の目標達成は要求しない。ドイツ語の呼びかけ `bn` は目標に向かう勇気を求める。目標を共有しても、二つの発話を一つに縮めず、順序と説明の向きを保存する。標語の内容も、新しいラテン語と同じドイツ語の二つを参照する。

本文には四つの合成定義を追加し、新しい基本関係はない。35文のうち第一段落を提示する一文だけを更新する。既存の八単位の判断は、依存定義・意味規約・選択した文のハッシュが同じままで引き継げる。

検証では、勇気・試み・行為者・生起・目標達成の32組合せと、本人・目標・行為・所有者などの六対照を実行した。四つの未知入力は拒否し、引用した目標の真偽は未確定でも取り組みを記述できる。十の談話対照と五つの標語対照で、古い引用先や逆向きの説明、欠けた条件文を拒否する。現在の能力定義を使った16組合せと理解力の原因に関する四対照では、因果条件と帰責の関係を再確認する。表記と固有文字の往復も確認した。

```powershell
python -X utf8 -m scripts.compose_contextual_motto
python -X utf8 -m pytest tests/test_contextual_motto.py -q
python -X utf8 -m scripts.check_contextual_motto --verify-only
python -X utf8 -m scripts.register_opening_paragraph_review
```

この形式検証自体は、自然言語との意味同値を証明しない。[第一段落全体の読解確認](opening-paragraph-review-v1.md)で、各箇所の採用する読みと、その読みをNoemaで表せているという判断を別に記録する。実行時の辞書検索、生成モデル、翻訳器は使わない。
