# 判断済み本文を収録した二作品の統合版

累積稿から、登録された全文判断が選択する主張を収録する。二作品の原文単位を増減せず、語義、式、引用名、束縛、前提、主張の提示役割を変更しない。各主張の依存する宣言と意味規約の出典も元のまま保持する。

累積稿には、新しい記述とは別に初期の部分草案の主張が残っていた。例えばアインシュタインの旧文203は、u0275に対する旧部分草案sewaへの帰属であり、現在の全文判断が選ぶ文445とは異なる。統合版では全文判断が選んだ文を本文とし、採用されていない旧主張は元の累積稿で読める状態にする。元ファイル、判断、証拠、検証器は変更しない。

定義の辞書は全宣言をそのまま残す。未使用の定義を削ったり同じ本体の名前を統合したりせず、引用された記述の同一性と過去の意味規約の出典を保つ。旧定義が存在することと、その内容を作品本文として主張することを区別する。

本文の出現順は累積稿から保持し、原文を読む順序は[対応表](../data/reviewed-works-assembly-v1.json)の各作品の`units`に示す。そこには原文単位、元の意味判断、旧新の文番号、統合版に収録しなかった旧主張の番号・ハッシュ・直接参照を記録する。元判断が単位内の原文順を明示している場合はその順も移す。明示のない旧判断では`source_order_statements`をnullとし、選択した文番号から順序判断を新しく作らない。同じ文が複数単位に対応するときも、その対応を残す。

登録簿v456で、元の302件の判断を全て検証した上で、現行本文の構文、推移的な依存定義・意味規約、識別表記が元判断と一致することを確認する。本文の全主張が少なくとも一つの全文判断に含まれること、二作品それぞれの長形式・短縮形式・固有文字の往復も検査する。新しい意味判断は作らない。

```powershell
python -X utf8 -m scripts.project_work check --module scripts.assemble_reviewed_works --tests tests/test_reviewed_works_assembly.py --prepare --write-report reports/reviewed-works-assembly-v1.json
```

この統合は二作品全体の完成監査の一部である。言語仕様、基礎概念、原文照合と解釈の限界、他分野・文化固有の概念への適用例については、完成条件の六成果物に照らした別の確認を要する。全単位が判断済みであることを、あらゆる人間の意味を表現できる証明にしない。
