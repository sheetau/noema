# Noema 0.3の語彙参照

語形・概念ID・定義は版付き資源から生成する。短い日本語見出しは検索用であり、意味の範囲は定義と役割の型で定める。英語の定義も資源に保持する。詳しい文法は [記述体系](writing-v03.md) を参照。

定義中の主体は `i`、対象は `j`、受け手は `k`、場所は `l`、出発地は `z`、到着地は `2`、道具は `3`、受益者は `4` に対応する。
