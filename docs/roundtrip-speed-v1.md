# 光の往復速度と、経験に従う法則の採用

アインシュタイン論文§1の、二地点間の距離と光の往復時間から速度を定める箇所をNoemaに記述した。二地点間の距離を2倍し、出発地点の同じ時計で測った往復経過時間で割る。これが関連する全試行に共通の値になるという内容と、著者が経験に従ってその内容を採用するという帰属を分ける。

[原文の電子本文](https://de.wikisource.org/wiki/Zur_Elektrodynamik_bewegter_K%C3%B6rper)の `u0019`〜`u0021`、式 `M0040` に対応する部分草案である。原文はこの値を真空中の光速度とする。数値は補っていない。後続§2にある光源の運動からの独立性や、他の慣性系での不変性を、この箇所だけで記述したとは扱わない。

## 数値の条件と測定の結合

| 定義 | 内容 |
| --- | --- |
| `sah` | 非負の実数を表す下側切断の積。既存の定義を別名で再利用 |
| `sai` | 正の距離・経過時間・速度について、速度×経過時間＝距離＋距離 |
| `saj` | 有理数の読みと正の単位尺度を使う、換算付きの同じ速度条件 |
| `sak` | 非空の指定試行の全てが、一つの共通値を満たす |
| `sal` | 同じ試行の時計・場所・光・読み・距離・単位・真空の条件を結合 |
| `sam` | 完全と指定した範囲の全試行へ、同じ値と条件を渡す |
| `san` | `sam` の判定を実切断の速度条件 `sai` に接続 |
| `sao` | 著者が採用する、共通値の成立という状況ごとの内容 |

実数の式では割り算を直接実行せず、正の経過時間を要求した上で積の等式を課す。ゼロの経過時間を受け入れることはない。積と距離の2倍が同じ値かどうかは、切断の両方向の包含で判定する。関数の実装上の同一性は使わない。

出発と帰着の読みは、同じ試行の同じ時計・同じ場所・基準系・時間単位へ結び付ける。反射の出来事とその場所の時計も、既存の光往復の設定に結び付ける。ただし反射時計との同期は、往復速度の条件には追加しない。出発地点の時計による経過時間を測るため、反射時計の原点が異なっていてもこの速度の式は変わらない。

長さ単位と時間単位、それらの商である速度単位の対応を要求する。距離は指定基準系での二地点間の一方向の距離であり、往復距離や任意の曲線の長さとは区別する。往路と復路の両方に真空中の伝播を要求した。距離・真空・単位の実現をより基本的な概念から説明する作業は残る。

## 共通値と経験的根拠

試行ごとに別の速度値を選んで成立させる条件と、一つの同じ値が全試行で成立する条件は異なる。`sak` は後者を記述する。対象が空のときは成立させず、`sam` では指定範囲が対象試行を尽くすという前提も保持する。

この範囲指定は、観測した有限個の試行から普遍性を認定する仕組みではない。法則の対象範囲を記述上明示したものである。普遍性の全範囲の解釈、未観測の試行への適用、物理的実現の説明は未完である。

本文の主張は、著者が法則の記述を採用し、その採用を経験的根拠に従うものとして位置付けるという帰属である。根拠の具体的な実験内容は原文に列挙されていないため補わない。この帰属が評価できることは、経験の正しさや法則の真理を検査器が証明したことを意味しない。

## 検証の範囲

有理数の具体例17件で、単位換算、共通の時刻原点の移動、負の時刻原点、ゼロや逆向きの経過時間、片道と往復の混同を検査した。9件の量化付き多項式条件では、固定単位での速度の一意性、原点移動、適切な尺度換算など8件が成立し、時間の読みと速度尺度を同時に同じ倍率で増やす誤った主張には反例が得られた。尺度換算の主張は、変更前後の尺度が正という前提を保持する。

二試行・二候補値について、試行の選択と成立条件64通りを検査した。各試行にそれぞれ適合値があっても、共通する値がなければ成立しない。原文接続の22例では、異なる距離と経過時間を持つ二往復が同じ速度を共有でき、反射時計の原点の変更も許す。一方、別の試行の距離や帰着、別の時計の帰着読み、不完全・空の範囲、片側だけ真空でない場合などを拒否する。

接続の検査は、明示した整数の埋込みを使う判定関数を渡したものであり、実数全域の `sai` を有限値で代用して証明した結果ではない。実数の一般法則の機械的証明は未完である。切断の積は既存定義と構造が一致し、有理数全域の量化を有限実行系が黙って近似しないことも確認した。

帰属は7例で確認した。採用や経験的根拠の欠落、内容・著者・範囲・根拠の取り違えを拒否する。物理内容を実行すると失敗する検査用の関数を使い、帰属だけを扱うことを確認している。
