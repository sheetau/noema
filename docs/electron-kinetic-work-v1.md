# 静電場からの仕事と運動エネルギー

固定原文のu0261–u0262を一群として扱う。原刊919–920頁を照合し、原点・初速零・全区間のX軸運動、静電場からの取り出し、緩い加速と無放射の設定、運動エネルギーとの等置、第一(A)の全過程での適用、直後の積分列を接続する。旧428主張とその証拠は保存する。

## 構成と読解

`eor–eou`は同じ電子、K、実履歴と校正された単位を、時間独立の軸方向電場と電気的作用へ結ぶ。電荷と低速慣性質量は運動区間で共有する。原文の「静電的な力X」は先行の用語に従う電場成分で、電子に働く電気力はεXである。端点の確認だけで全区間の軸上運動・力の帰属を認めない。

`eov/eow`は実際の座標時刻微分を使い、同じ文脈の小ささの基準で加速度を評価する。原文が数値閾値を与えないため具体値を追加しない。緩い加速と無放射は別の内容にし、soll/mögeの設定とinfolgedessenの著者の理由付けを提示する。無放射を一般的な物理定理として登録しない。

`eox–eo5`は初期・終端の運動エネルギー、場からの取り出しと放射量を同じ過程と仕事単位へ帰属させる。運動エネルギーは当該系に相対的な並進運動の寄与で、静止で零とする。力×変位の仕事基準と同じ単位を使い、他の移転・内部変化を含めない簡略収支を明示する。これらの限定からの等置を著者の推論として読む。

M0425とM0427の位置積分は上下端を印刷していない。直前の原点から同じ終位置までの過程を指す定積分として読む。速度積分のβは積分変数の関数であり、終端のβを積分内で固定しない。

**M0427の中間積分にはμがない。** 原刊920頁と固定MathMLはともに `∫₀ᵛ β³v dv` である。原文保存の`serg`を使い、μを補う`serh`又は質量を1とする訂正を著者の式へ混入しない。式が物理的に不整合であることと、その式を著者が述べたことの記述は分ける。第一(A)からこの印刷式を厳密に証明することは主張しない。

## 追加した意味規約

運動エネルギー、場からの取り出し、放射損失は、物理的な対象・出来事・系・単位を引数に持つ一般関係とした。エネルギーは仕事と交換収支、放射は外向きに伝播する電磁的な移転によって意味を説明する。場の個体参照と成分モデルの同一性、仕事の単位、文脈的な程度基準、量をこれから決定する論述上の取組も一般関係である。原文一文を一つの原始関係へ格納していない。

既存の軌道・微分・静電力・積分・収支・印刷式は再利用する。全実時間・全分割の条件を有限列へ置き換えない。新しい検査は役割接続、単位尺度、実微分、収支の対照、印刷された積分への接続、引用と全称・存在束縛を診断する。既存報告の依存ハッシュを確認し、全域解析や物理的真理の自動証明とは区別する。

全文判断では、第一文の決定の取組、第二文の条件と「明らか」、第三文の二つの設定・理由・等置、第四文のしたがって・全過程・第一(A)と前方参照、直後の式の全四項を照合する。後続の光速境界と実験的関係はこの群に含めない。
