# 冒頭の離脱と、その変化を受ける本人

カント冒頭の第一文を再点検し、離脱を表す定義 `be` の対象接続を修正した。旧版では、同じ人の前状態と後状態を調べても、その間にある変化過程がその人に関わることを要求していなかった。そのため、別人の過程や単に目撃した過程を使って条件を満たせた。

## 既存の関係を接続する

旧定義は、過程が先行状況から後行状況へ移る `ag`、先行状況で本人に自己に原因が帰せられた未成熟がある `bd`、後行状況で本人が自立的使用を達成する方法を持つ `xd` を結んでいた。改訂版はこの三条件を保ち、既存の基本関係 `la` を加える。

`la` の引数は本人・過程・先行状況・後行状況であり、四つとも既存の三条件と同じ値を渡す。意味規約は「その人が、その前後状況を結ぶ変化過程において、状態変化を受ける対象である」。目撃しただけ、過程の原因であるだけ、別人が変化しただけでは成立しない。本人の意図的行為や、本人だけで生じさせた変化という条件は加えない。

この接続により、過程を引数に取る啓蒙の性質 `bi` にも本人への関係が含まれる。表題の質問と冒頭の回答は同じ `bi` を参照しているため、双方へ修正が反映される。帰属の文を評価するときには引用内容を実行せず、著者がその定義を提示したことを表す。内容が真かどうかは別に検査できる。

## 改訂文書と意味規約

[改訂本文](../examples/v016/kant-subject-bound-departure.noema)は258基本記号・1,116合成定義・16文を保つ。宣言の追加はない。`la` を使用箇所より前へ移動し、`be` の本体だけを変更した。他の宣言本体と本文16文の構文は旧版と一致する。

意味を変更したため、追加宣言だけの差分とはせず、[完全な意味規約](../data/subject-bound-departure-basis-v1.json)を作った。改訂元とその入力ハッシュ、従来の未解決事項を保持する。旧版のファイルは変更していない。同じ記号を含んでいても、旧版と新版の引用はそれぞれの文書・意味規約とともに解釈する。

[独立文書](../examples/v016/subject-bound-departure.noema)には `bi` までの依存先を抽出した。本文の定義と一致する部分集合として、前段の意味規約点検器でも検査する。

## 検査の範囲

四条件（過程の成立、本人の関与、離脱前の状態、離脱後の能力）の16組合せを検査する。本文と独立文書のそれぞれで、本人・過程・両端の状況の取り違え、目撃のみ・原因としての関与のみ、能力評価の欠落や不正な範囲、指導の継続、方法の不在、原因説明の不在、過程の逆向きを比較する。

七つの反例では、旧版が `be` と `bi` をともに真とする一方、改訂版はともに偽とする。二例は短絡変換もキャッシュも用いない評価と照合する。対象関係が未知なら判断を拒否し、表題の提示だけなら関係を評価せず処理できることも検査する。通常・短縮・固有文字の往復とCLI解析を両文書で確認する。

```powershell
python -X utf8 -m pytest tests/test_subject_bound_departure.py -q
python -X utf8 -m scripts.check_subject_bound_departure --verify-only
python -X utf8 -m noema.meaning_catalog explain --basis data/subject-bound-departure-basis-v1.json --symbol bi --output artifacts/subject-bound-departure-explanation.json
```

[意味確認記録](../data/subject-bound-departure-review-v1.json)には第一文の役割と未解決点を記録する。今回解消したのは本人への接続漏れである。同じ人が別の性質について変化した場合と、問題となる能力の変化との区別は、`la` だけでは確定しない。能力評価の範囲、原因説明の採用、決意と勇気の不足の読み、過程全体の記述と原文の解釈も残る。新しい原文範囲や意味確認済み区間は加算しない。
