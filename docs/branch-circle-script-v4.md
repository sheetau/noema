# 分岐と分割を持つ書記・試作04

更新されたコンセプトに従い、試作03の一続きの並びを、中央の主部と引数の枝からなるまとまりへ変更した。比較画像は `output/alphabet-circle-v4/overview.png` の一枚に集約する。通常文六例、カントの二主張と後半の内容定義、アインシュタインの二式を同じ縮尺0.48で描き、三本の薄い罫線を表示する。前案の通常例文の縮尺1.65に対し、約29%の大きさである。

## 構造から配置する

入力はNoemaの解析済み構文木。引数列の容器は適用へ融合し、単純な引数は主部の上・下・反対側の枝に直接取り込む。構造を持つ引数は、その入口を枝に置き、続くまとまりへ部分木を送る。まとまりは構文の順序で読む。三項を超える適用は引数の順序を保持して複数組へ分割する。長い線で部分木を横断してつなげない。

二分岐には円の外の実際の分岐点がある。位置関係は上下を両側へ展開し、条件は前件と後件を非対称に、等値は両側へ対称に置く。単項の局所的な出来事だけは小中円の接触を許す。これらは入力の構文や明示した関係の種類による規則であり、例文ごとに手描きした配置ではない。

主部は中央の罫線に置く。枝先に複数の大きな円が必要になると主部も大円にして、各まとまりの円面積の半分以上を中央へ集める。上段や下段だけが続く構造は作らない。大円の線は中心を通り、接続用の斜線は大円から離れた分岐点で開始する。

通常文とカントは、この一覧では主張として提示する。外側の `assert` は表示の規約へ統合するが、元の構文木には保持する。引用内の構文や名前を展開・同一視しない。

## 参照と読み分け

定義名・個体名・変項・演算子を一文字ずつ置換しない。構文の種類と参照全体を、放射線・内包する一円・接続距離の組で区別する。主部の左右の線は引数への接続で使うため、主部の参照標識には上下方向と内円、間隔を用い、接続線が名前の区別を消さないようにする。引数位置に応じて出入口と標識の向きが変わる。

参照の順序は宣言や量の登録順から取る。出現順だけで番号を振ると、与える者と受け取る者を逆にしても同じ図になってしまうため採用しない。定義名の改名では形が変わらず、引数の交換では形が変わることを検査する。これは語義を名前の文字列から推測する処理ではない。

現試作は一つの表示辞書につき30種類までの参照標識を扱い、超過時は拒否する。語の形全体は構文と引数の組合せで生成するが、この参照標識の上限と、画像だけの一意な復号は今後の課題である。意味を支える既存の定義・辞書は依然として必要である。

## 追記された幾何条件

円の寸法は試作03と同じ。検査は次を追加する。

- 接触・交差・内包を合わせて、一円の相手は最大一円。
- 大円には中心を通る線が必要。大円に接する45度線を使う場合は、円の上下端と同じ高さで自由端として終え、曲げたり接続したりしない。
- 同じ連続した線の二連続の直角曲がりを禁止。入力で線を分割しても、つながる端点を調べる。
- 円周に接する線は、その円の中心を向く。二円の接点をかすめる接線も拒否する。
- 各まとまりの中央の円面積比、線の閉路と矢印、実際の外部分岐、まれな円周接触を確認する。

## カントの表示

前回は原文とASCIIのNoema参照だけを掲載していた。今回は現行本文にある `s[k r2lg[]].` と `s[k r2lo[]].` の、無引数の定義本体を実際に描く。前者は中核の主張、後者は対比・強調・条件の提示を保持する。後半の閉じた内容 `r2ll` の本体も別行で描き、量化を含む構文を見られるようにする。

これは三つの既存の構文を図形表記したもので、カントの一文を新しい一個の原始概念へ置き換えたものではない。引用内の内容・関数への参照と既存の語義定義は保持する。全依存定義を再帰的に展開した表示ではない。

元の構文木、表示用の融合木、辞書、各まとまりが担当する位置、配置をJSONとSVGへ保存する。融合木から原構文を正確に復元できることと、実際のPNGのカント領域に読める濃さの字形があることを検査する。構文の保持は、画像単独の読解精度や新たな原文同義性の証明とは区別する。
