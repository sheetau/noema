# 全物質点から構成する軸の支持直線

u0043の二系の配置には、物質線の直線性・剛性・静止と、三軸の直交・対応軸の配置を同じ物体の座標へ結ぶ必要がある。今回の依存群はその関係を構成する。計器の仕様、d. h.の説明、設定指示の提示は残るため、段落全体の意味確認件数は増やさない。

物質線は、巨視的に一つの連続する線状支持体として扱う。厚みを捨象する理想化と連続性は形状の物理的入力 `eismv` に明記し、有限点の検査から推測しない。実際の座標には全物質点を使い、原点と同じ物体内の方向標識を通る直線上にすべてがあることを `eiu7` で要求する。方向は非零であり、原点の場所にも物質点が存在する。幾何学的な共通原点と、各物体に属する物質点の個体同一性は分ける。

`eiva` は完全な静止履歴と全点対の剛性、原点標識の完全な静止軌道を保持する。この条件があるため、初期断面で確かめた配置は同じ区間全体で保たれる。有限の始終二時刻だけで途中の変形や移動を除外したとはしない。

`eivc/eivd/eive` は実際の方向から直交、平行、支持直線の一致を構成する。平行は逆向きも許す。支持直線の一致には、方向の平行に加えて二原点の差がその方向と共線であることを要求するので、軸方向に原点がずれた二系を受け入れ、横にずれただけの平行線は排除する。有限の物質線から支持直線を延長することは、無限の物質棒を要求することとは異なる。

`eivf` は既存 `sex` にこの物理的な条件を渡す。三つの軸役割と実際の全割当てを一致させ、原点割当ても一つに保つ。`eivg` は既存 `sey` に実際の支持直線一致と平行を渡す。X軸の一致、Y軸同士とZ軸同士の平行を保ち、二原点や軸の正方向の一致、右手性、運動後の配置は補わない。

検査は明示した有限モデルでの幾何学と結合を扱う。完全な全実数履歴の境界で有限の関数値を比較する場合は、その境界の引数を確認する検査と記録する。全履歴の成立や外延的な関数等値の証明にはしない。未知の点・軸・値は拒否する。
