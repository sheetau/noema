# 母集団と文脈に依存する割合

[有限集団の割合](../examples/v014/proportions.noema)を、既存0.14の列・関数・量化で定義した。人数、母集団、比率、比率を評価する基準を分ける。「大きい割合」を常に「過半数」と解釈したり、原文が指定していない数値を補ったりしない。

## 数え方と成立条件

加算・乗算・大小比較に加え、真を1、偽を0とする指示関数hdを基本関係として用いる。heは真理値の両方についてこの条件を記述する。hfは列の各出現を数えるため、同じ人が二度現れれば二回数える。人数として使うときは、別の条件hhで重複を拒否する。

hjは空でない重複なしの母集団、0以上1以下の比率、指示関数の条件を要求し、「比率×母集団の人数＝性質を満たす人数」を検査する。空集団の比率を0や1と決めることはない。hkはさらに、全員が指定された種類に属し、その比率が渡された評価基準を満たすことを要求する。hlは厳密に1/2を超えるという別の条件である。

列を並べ替えても同じ性質の人数と比率を保つ。人数を増やしても比率が同じなら、比率だけを見る同じ評価基準は同じ結果となる。一方、その列が対象集団の全員を列挙していることは、重複検査だけでは分からない。

## カント第二段落への部分接続

[草案](../examples/v014/kant-large-share.noema)のhn・hqは、保存済み原文u0009の「ein so großer Theil der Menschen」に対応する量化表現である。hrは列がこの文脈の母集団を過不足なく列挙するという前提、hsは文脈上の大きさの評価基準を表す。調査した標本を無条件に全人類と同一視しない。

hqは、母集団と性質を引数に取り、その性質を満たす人の比率が文脈の基準を満たすという内容を返す。原文の具体的な人数・比率・閾値は断言しない。性質は引数として残しており、生涯にわたって好んで未成熟に留まること、先行する自然による解放、怠惰や臆病との原因関係はまだ接続していない。既存の第一段落の談話草案も保持している。

これは有限の母集団についての記述であり、無限集団の測度や標本からの統計的推定を定義したものではない。母集団の選定、文脈の評価基準、曖昧な程度表現の一般的な理論も残る。確認済みの全文単位数はカント0/20、アインシュタイン0/282のままである。

## 検査

人数0〜8の45通りと64人の例を、有理数の厳密計算で検査した。Noemaの集計結果が独立した出現数の計算と等しいことも確認する。12の対照例では、重複、不正な指示関数、誤った比率、母集団への異種対象の混入を区別した。過半数未満でも文脈の基準を満たす例と、過半数でも基準を満たさない例を別々に検査する。

原文へ接続した7例では、母集団の完全性、人の範囲、文脈、空集団、重複を検査する。hqは全有理数にわたる存在量化を使うので、有限実行器はその評価を拒否する。有限個の候補へ置き換えて一般的な真理を確認したことにはしない。具体的な比率を与えたhnの検査と分けて記録する。

```powershell
python -S -m scripts.compose_proportions
python -S -m scripts.check_proportions --verify-only
python -S -m noema parse --input examples/v014/kant-large-share.noema --output artifacts/kant-large-share.json
python -S -m noema render --input examples/v014/kant-large-share.noema --alphabet v2 --output artifacts/kant-large-share.svg
python -m pytest -q
```

[検査記録](../reports/proportions-v1.json)は原文の該当範囲、入力ハッシュ、未接続の内容を保存する。全文法表記・短縮表記・固有文字との往復も検査する。モデルや生成処理を使用しない。

新規4件を含む全758テストが通過した。`python -S`による再生成・記録照合、CLI解析、固有文字のSVG出力も確認した。
