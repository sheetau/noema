# 任用された役割の中の自立した判断

カントの第四段落には、独立して考える人が、任命された後見役の中にも見いだされるという記述がある。今回、任用の履歴、現在委ねられた役割、自立した判断、同じ人の母集団への所属を結ぶ部分構成を加えた。

十三の定義を既存文法で合成し、原始記号は増やしていない。「独立して考える人」の恒常的な性向、後見役の制度的・文化的な意味、「さえ」に当たる比較背景は未完として区別する。

## 任用の事実と現在の役割

`rpt`は同じ人・職務について、現在その職務を委ねられていることと、同じ履歴の過去に任用行為があったことを要求する。行為の生起、任用の出所・本人・職務、その時点での委任を、一つの行為と時点へ結ぶ。

過去に任用されたことだけで、現在もその役割にいるとはしない。自ら後見人を称しただけでも成立しない。一方、この箇所には特定の採用条件や誓約の記述がないため、任用条件を扱う既存定義のそれらの項目は追加していない。現在の職務遂行、正当性、本人の同意も別の内容である。

本文用の`hzha`はこれを既存の本人の履歴・順序・行為生起・委任へ結び、`hzhb`はその職務が指定集団の後見役として分類されることを加える。後見役の分類と任用記録は引数で明示する。未知なら、自己申告や現在の地位から任用履歴を作り出さない。

## 同じ人と、異なる状況の人々

`rpu`は同じ人が、同じ状況で所属・立場・性質を満たすことを表す。役職者が一人、独立して判断する別人が一人いるだけでは成立しない。`rpv`は少なくとも一人、`rpw`は異なる二人の存在を要求する。二人以上という条件は「ちょうど二人」や「全員ではない」を意味しない。

`rpx`は非空の状況範囲の各状況で一人以上が該当することを、`rpz`は各状況で二人以上が該当することを表す。状況ごとに人が交替してよい。同じ一人が全状況で該当する強い条件`rpy`を別に用意した。たとえば、勤務時間ごとに資格を持つ担当者がいることから、同じ担当者が常にいるとは言えない。

本文用の`hzhc`は、本人の理解力を用い、同じ判断の対象・理由・支持があり、他者の指導を伴わない既存の`h5c`の判断を証人とする。これにより、実際の判断の構造までは接続する。ただし、一回の判断から恒常的な性向や全判断の自立性を認定しない。

`hzhd`と`hzhe`は、同じ人々について任用された役割とその判断を結ぶ。母集団と後見の対象集団は別の引数であり、公衆と「大衆」を同一の集合として補完しない。`hzhf`は、基準より後にある非空の範囲で複数人の存在を要求する部分読解である。任用は各状況より前に必要だが、必ず基準時より前に済んでいなければならないとはしない。
