# 任用時の条件と、現在の要求を分ける

カントu0012の「その条件で採用された」という箇所へ、過去の任用行為と、その行為に付された条件を部分接続した。同じ目標記述を過去の条件と現在の要求に渡すが、過去の任用だけから現在の義務を導かない。

## 記述する構造

| 定義 | 内容 |
|---|---|
| `rfx` | 指定した任用行為・時点が、同じ履歴の現在より前にあり、同じ出所・本人・職務・条件へ結ばれている。 |
| `rfy` | `rfx`を満たす任用行為と時点の組が存在する。 |
| `rfz` | `rfy`の事実と、同じ出所・本人・職務・活動・目標記述・極性への現在の要求が併存する。 |
| `hzbl`・`hzbm`・`hzbn` | これらを既存の履歴`ia`・順序`ic`・生起`dg`・職務の委任`cf`・要求`h7a`へ接続する。 |

任用行為と条件の関係は、型付きの引数として明示する。任用関係は行為・出所・本人・職務・時点を、条件関係は同じ行為・活動・目標記述・極性・時点を受け取る。この結合により、別の任用から条件だけを取り出したり、違う時点の記録をつないだりできない。関係の値が未知なら、現在の職務や要求から埋め合わせない。

ここでいう条件は、任用に付された実行上の約束事である。採用前に仕事を完了しているという条件や、本人の自発的な同意ではない。任用の存在を記述しても、指定した仕事を実際にしたことや、その内容を信じることは含めない。

履歴は既存の`ta`で厳密な全順序として検査し、任用時点と評価時点の所属と先行関係を要求する。現在や将来の任用だけでは満たさない。一方、初回の任用や唯一の任用であることは要求せず、再任や複数の該当行為を許す。現在まで同じ職にいることも、過去の記録の条件に加えない。

## 教示の記述との接続

前版の[採用基準に従う教示](adopted-standards-v1.md)を、既知の基準記述で固定して引用する。その同じ閉じた教示記述を、任用条件と現在の要求へ渡す例を検査した。教示・各基準・発話内容の真理を評価する必要はない。

比較する二つの基準による教示は、同じ文書内で別の定義名を持つ。異なる文書で同じ記号を別の意味に定義したものを、記号の一致だけで同じ対象と認定していない。順序を変えた基準による別の教示へ、任用条件や要求を無断で移す例は拒否する。

## 検証と限界

生起・過去の委任・任用関係・条件関係・現在の要求・現在の委任・現在の実行を独立に変えた128設定を検査した。29対照例では参照先、条件の記述と極性、時点、別々の証人、不正な順序を変えた。全文草案と独立抽出文書の結果は一致する。特定の教会に依存しないことを、研究施設での任用と仕事の解釈でも確認した。

否定の条件が課されていても、対象が実際には真である状況を記述できる。未知の実行対象を評価しようとすると停止するが、任用条件と要求自体は記述・評価できる。任用・条件・履歴・要求などが未知なら、その存在や不在を補わず停止する。検査は明示した有限モデルに対するものであり、任意の制度についての意味一致の証明ではない。

原文との対応は`er ist auf diese Bedingung angenommen worden`の部分構造に限る。任用・条件関係の制度的な構成説明、全ての将来の教示への適用範囲、期間や解除、`denn`による規範的な説明は未完である。単なる併存を義務の正当化や原因として扱わない。教会・聖職者・教理の名詞全体、良心、辞職、原文全文の意味一致も残る。

6定義を追加し、新しい原始概念・局所参照・著者の主張は追加していない。全文草案は95,731代用文字で、前版から1,628文字増えた。一般構成は1,287文字、独立抽出文書は2,095文字である。定義を含む長さであり、一文の翻訳の圧縮率ではない。
