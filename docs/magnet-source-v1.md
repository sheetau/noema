# 磁石の読みと場の発生源

導入のMagnetは、比較する二場合で同じ物体が活動中の磁気源となり、物体外へ磁場を作る例として読む。永久磁石の磁化と、作動中の電磁石の内部電流を許す。特定の材質、棒形状、電源不要という性質は原文へ補わない。この読みは、電源を切った装置や完全に外部を遮蔽した配置まで分類する辞書の定義ではない。

磁化と内部電流による磁場の説明は、[OpenStaxの強磁性体・電磁石の説明](https://openstax.org/books/college-physics-2e/pages/22-2-ferromagnets-and-electromagnets)を確認した（2026-10-23）。本構成では原子を古典的に回転する電荷として仮定せず、内部の磁気モーメントや電流配置を基本的な物理入力として扱う。磁気側場が移動電荷の速度依存の力を定める量であるという規約は、既存の[磁気的作用](magnetic-action-v1.md)と共通である。

eirxは物体に対して保持される内部の磁気源配置を述べる。eirwは、その物体の源に帰属する電気側・磁気側の成分場を指定する。源の帰属には初期・境界条件と、他の源や自由場から寄与を分ける規約が必要であり、sourceconditionに固定する。物体を外部磁場の中に置いただけでは、この帰属は成立しない。正味電荷のある物体の共通並進だけも、内部の磁気源配置とは区別する。

eicqは二つの入力を同じ物体・文脈・源条件へ結び、既存znn・eirnで系・場・領域・単位を接続する。その上で、物質占有eiroの外にある四座標を使い、scb2による磁場評価の少なくとも一成分が非零であることを要求する。eicrはその点と場値を存在量化する。外部の一点を要求するだけで、全空間で非零、任意の電荷に非零の力、観測実験の実施済みとはしない。

eirwが指定するのは、その物体による場の寄与である。他の源や導体も含めた全場と同一視しない。相互作用の本文への接続では、この区別と、寄与が働く対象・場所・出来事を保つ必要がある。源の場の方程式を実際に解くことや、微視的磁化の実証を翻訳の完成条件には加えない。

eicsは第一・第二のeicrへ同じ左側物体と長さ・時間単位を渡す。各場合の評価系、場関数、場単位、源条件、領域は別に指定できる。内部準備の対応は既存eirsへ残し、場の数値が同じという条件へ置き換えない。eictはこれと既存の導体・相対運動・準備条件eickを合わせる。eicuはその前件から電流一致eibiへの条件内容、eicvは前件も結論も満たす内容である。

検査は外部の点での場評価と非零判定を実行し、零・正負の三成分、物体内部の点、欠けた源帰属と未知入力を対照する。二場合の接続では下位の全履歴・存在条件を境界へ置き、全引数の取り違えと、位置を識別する別値を調べる。全実数値を返す点関数の存在量化は有限評価を拒否する。有限例を物理法則の証明や意味判断へ昇格させない。

Magnetの六箇所は読みの記録で同じleftへ対応づけた。例示の呼びかけ、相互作用、通常の理解への帰属、周囲の領域、起電力・エネルギーと全文判断は残る。旧207主張と著者表示判断を保持し、今回を原文単位全体の完了には数えない。
