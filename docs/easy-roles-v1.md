# 容易に達成できることと、指図する立場を引き受けること

[容易さの定義](../examples/v014/easy-roles.noema)を既存の能力条件へ加え、[カント第二段落の第二の結果](../examples/v014/kant-easy-guardians.noema)を原因説明へ接続した。可能性、現在の実行、正当な権限を分ける。

## 同じ方法について成功と負担を検査する

ndは、実行できる方法があり、その評価対象が空でなく想定結果の部分集合で、全評価結果において目的を達成し、その同じ方法の負担評価値が文脈の基準を満たす条件である。負担が小さいが失敗する方法と、成功するが負担の大きい方法を別々に見つけても成立しない。

負担の尺度と容易さの基準は引数で与える。原文が指定していない固定値や単位は補わない。ここでは低負担の方法で達成できるという操作的な読みを採り、速度、成功確率、心理的な気軽さなど全ての容易さを定義済みとはしない。

## 自分から立場を引き受ける

odは、自ら発意した行為によって、本人と異なる対象の判断・行為を指図する立場を自分のものとして引き受ける内容である。行為者・行為・対象を対応させ、別人の行為や別の対象への働きかけと混ぜない。法制度上の後見資格、正当な権利、周囲の承認は含めていない。

ogはodを目的としてndへ渡す。その立場に現在あるという事実は要求しない。逆に、現在その立場にいても、容易に達成できる方法が存在するとは限らない。自発的な立場の引受けという読みは、後見の歴史的な全意味や、原語の評価的な響きまで確定したものではない。

## 「その人々」と「他者」の範囲

oiは、既存の母集団に属し、前の割合表現が数えるkgの性質に該当する人を選ぶ。無関係な集団を後見の対象にせず、先行する移行・譲歩・持続の条件への参照を保つ。

ojは、対象範囲と文脈上の他者の範囲が共に空でないことを要求する。各他者と各対象が人であり、両者が異なり、その組合せでogが成立する条件である。対象ごとに異なる方法を許すため、一つの方法で集団全員へ同時に立場を確立できるとは主張しない。okはoiの対象範囲をojへ渡す。

これは文脈で選んだ範囲内の各組合せについて述べる読みである。全人類を無条件に対象とせず、一般的傾向や例外を許す読みとの違いを残す。容易さの尺度と範囲、「容易になる」の変化の含意も未確定である。

## 二つの結果への原因説明

olは、前版の第一の結果msと今回の第二の結果okについて、同じ要因mq・mrをそれぞれ原因説明へ採用する。四つの対応の一つでも欠ければ、この結合した説明は成立しない。mxをこの内容へ更新し、著者への帰属と前段落より後という本文順序を接続した。

説明への採用だけで要因や結果の内容を実行評価せず、因果機構の証明とも区別する。第一文の二つの結果には部分草案が接続したが、語義、比喩、評価範囲、原因の意味の確認が残る。段落全体の完成ではなく、確認済み全文単位数はカント0/20・アインシュタイン0/282のままである。

## 検査と限界

方法・想定結果・評価対象・成功・負担の256組合せと、異なる方法の混同を防ぐ2例を検査した。役割の16例では、現在の成立と容易さの違い、別人・別行為・別対象、空の範囲、自己への後見、評価対象の不整合を確認した。

対象参照の4例は、新しい接続部分だけを検査するため、先行するkgを仮の真偽を返す基本関係へ置き換えた検査文書で実行した。配布するNoema文書では元のkg定義を保持する。この検査は母集団所属とkg条件の両方を要求することを示すが、kg全体を再検証した結果や、全文の端から端までの意味確認としては数えない。

5つの原因説明モデルでは四つの対応の欠落を検出し、3つの帰属モデルでは著者と本文順序を検査した。いずれも引用内容を実行しない。全文法表記・短縮表記・固有文字との往復も確認する。
