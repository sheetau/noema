# 小さい剛体への不変な電荷の付着

u0232第二文の条件を、同じ物質部分の電荷が変わらず、その部分の運動に伴って空間分布が移るという読みで構成する。全体の電荷が一定でも、内部の二部分の間で電荷が移れば不変な付着とはしない。今回の依存群は著者提示や文全体の意味判断を追加しない。

ekxn–ekxrは既存の符号付き有限加法的総量の構成を物質ラベルに適用する。全物質点、適格な部分族、一つの部分量関数を区別する。空部分は零、同じ部分は同値、重ならない部分の和の量は和になる。全体部分を定義域に含めるが、全ての任意部分集合や可算加法性は補わない。

eisvyは、指定した物質部分に同じ電気量がその時刻に帰属するという一般の物理入力である。時刻ごとに変わり得る入力を、同じ部分量関数へ全時刻で結ぶことにより、不変性を合成する。数値関数だけを電荷と認定せず、種類をzorへ、校正尺度を先行のeirm/eisvxと同じ規約へ結ぶ。零電荷の部分も物体に含める。

ekxsは指定時刻に空間領域へ入る物質点の逆像を作る。ekxtは物質部分の量を、ekxuはその同じ値を空間保有量eisvxへ接続する。ekxvは完全な物体履歴eiad、校正座標、非空の全成員と正長区間の全時刻を保持し、全ての適格物質部分と適格な空間逆像へ適用する。同じ空間の箱に入る物質は時刻とともに変わり得るので、固定箱の電荷を時間不変とはしない。各時刻の全物質部分と全空間領域には同じ出来事を共有する。

小ささは、比較する文脈と尺度を先に固定するeisvzと、全物質点対の距離二乗がその上限の二乗未満というekxwを組み合わせる。ekxxは同じ履歴の剛性eigyと全時刻の寸法条件を結ぶ。有限の物体なら何でも後から十分大きな上限を選べる、という条件にはしない。原文に数値閾値、球形、点状性、三標識点、物体全体の静止を補わない。ekxyは同じ物体・区間・評価系・全成員・座標族で不変な付着と小さい剛体を共有する。

この版のdistributionは一つの物体に対応する局所成分である。複数のイオン・電子の全体を一個の剛体としない。場に用いた全分布との分解・合成、各担体の評価系と場の系の対応、イオン・電子の読み、Lorentz理論の電磁的基礎という条件付き位置付けは次の統合で扱う。剛性の条件を全系での同時成立やBorn剛性に替えず、電荷の不変をMaxwell方程式から証明したとも扱わない。

検査では二つの物質部分に正負の量を与え、全体量が同じでも内部交換を拒否すること、移動する物質と固定空間領域を区別すること、各時刻に全部分と同じ出来事を共有することを確認する。寸法は各座標成分、境界、非成員、別時刻、別物体の取り違えを対照する。全実数時刻と全空間領域の量化は有限標本へ変えない。
