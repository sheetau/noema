# 複合語の内部を円周接触で結ぶ

同じ複合語の隣り合う二部品を、既定の中円同士の接触で結べるようにした。語義や語順を省略せず、二つの核を独立した部品として読む。文番号や登録順によって接触形を割り当てる規則ではない。

## 構成と読取

候補は、それぞれ単独の中円で表す二部品に限る。同心円や円周上の小円を伴う部品は対象外とし、一つの円が二つ以上の円に触れる配置を作らない。二中心を隣接する段に置き、右の中心を32単位進める。中円半径が `16√2` なので、中心間距離 `32√2` は直径と一致する。

主列では、同じ語の続きであり、間に語境界がない場合だけ接触を候補に加える。接触点を既存の入口や枝の入口と重ねず、従来の幾何検査と重心・幅の比較で配置を選ぶ。描画器は一語に最大一か所を選び、接触を常態化させない。`contacts=False` では従来の離して描く形を作れる。

横枝の複合語でも使える。この場合は外側の段と中央段の間で二部品が接触するため、枝の全核を同じ外側段に置く従来の配置に例外が生じる。最初の核を親より右に置く規則と、枝全体を一語として読み終える規則は保持する。

図形読取器は接触を二核間の辺として扱い、二円を一核へ縮約しない。語を読んだ後、接触する二核が、その一語の隣り合う単独中円の部品に当たることを確認する。異なる引数や語の境界を接触で置き換えた図形は拒否する。接触を取り除いて通常の接続で描いても、復元されるnative構文は同じである。

## 横枝の後の接続

接触した中円が中央段にあると、必要な線との間隔を含めて三つの水平段を塞ぐことがある。現在の描画器は、通常の経路が成立しないときだけ、隣接段を経由する経路と、障害円の外側を二本の45度線で通る経路を候補に加える。

円の近くでは水平な直角入射区間と所定の長さを保つ。三段の外へ水平線を追加せず、45度線の折返しによる一回の直角と、その前後の45度の折れだけを許す。大円に接する45度線を曲げること、連続した直角、ループ、近すぎる線を認める変更ではない。候補はすべて従来の幾何検査を通す。元生成器を呼ぶ経路の既定動作は変えず、新描画器だけが追加候補を使う。
