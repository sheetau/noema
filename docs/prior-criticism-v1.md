# 既に採用された規定への批判を伴う公的提示

カントu0016の、よりよい構成についての考えを批判とともに示す箇所へ、[複数評価の行為記述](disclosure-actions-v1.md)を接続した。比較提案と批判は同じ本人・同じ提示行為・同じ状況で成立する一つの行為として記述し、その複合行為への許可を明示する。比較提案と批判それぞれへの許可から、両者を併せた提示への許可を自動では推論しない。

この草案は「率直な」の語義全体を確定するものではない。明示範囲の本人の評価を省略せずに提示する条件を使うが、範囲自体の選び方、誤導の意図、恐れの有無、誠実さまでは定義していない。`freimüthigen` と `sogar` は新しい対応範囲へ含めない。

## 以前の採用を現在の状態から推定しない

批判の話題を、条件・目標・肯否を持つ採用済みの規定として部分的に記述する。既存の `rba` は、ある出所が特定の役割に対して、その条件に当てはまるなら目標を満たすよう求める規定を採用している関係である。この規定と、その採用主体・役割・条件記述・目標記述・肯否を保持し、基準時点より前に採用があることを `rsp` で表す。

過去の採用時点と基準時点は同じ履歴に属し、その履歴の順序は既存の `ta` で非空の厳密全順序として検査する。未来の採用、別の履歴での採用、基準時点を含まない履歴、循環した先行関係では成立しない。現在もその規定が採用されていることは要求せず、現在の法的効力もこの条件だけからは導かない。

現在の統治者と過去の採用主体、規定の名宛人の役割と批判する人の役割は別の引数である。現統治者がその法を制定した本人であることや、批判者自身が法の名宛人であることを補わない。

これは条件付き規定の採用履歴を用いた操作的な読解である。公布の手続、法律一般の成立要件、法文と法の関係を全て説明し終えたものではない。過去の規定の条件・目標と、比較元の法文の版との対応も未説明である。「すでに」が持つ期待との比較や前提投射も残る。

## 話題・複合行為・許可をそろえる

`rsq` は、選択した全ての批判の話題に `rsp` を要求する。過去の採用がない話題を選択範囲から除いて成立させることはしない。同じ基準時点で選んだ話題・採用内容・履歴を保ち、方針の想定結果ごとに都合よく選び直さない。

`rsr` はその参照条件と、既存 `rrx` の立法範囲・全選択行為への許可を併記する。`rss` はこの方針の閉じた記述を構成する。本文の `hzqtarget` は、同じ提示について比較判断と否定評価を含む公的提示を結合する。いずれも同じ話題の選択値を用い、片方だけ別の法について述べる形にはしない。比較発言側が持つ本人の能力使用の条件も維持する。

新しい `hzqpolicy` は、従来の一般使用・比較発言の許可を保ち、批判を伴う提示への許可と同じ評価状況で結合する。許可対象を限定して既存方針を置き換える変更ではない。安全性は新しい結合方針の想定結果で調べ、認識もその安全性の記述へ結び直す。

許可を調べる際に比較判断・批判・伝達を実行しない。一方、過去の採用と立法範囲は参照対象の条件なので、方針の評価時に検査する。これらが不明なら拒否し、存在や不存在を補わない。対象活動の選択が空なら普遍条件は真になり得るため、法や批判の存在をその結果から主張しない。
