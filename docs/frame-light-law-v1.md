# 各系の現在の時計に結ぶ光速度

u0065では二原理を組み合わせ、運動系で測っても光は同じVで伝播すると述べる。その個別の光線へ進む前に、既存の全区間法則と現在の時計・座標を接続する。

ei42は指定系の同じ光・源・放出出来事を保ち、源の静止又は運動を分類する。両端の時刻はその系の現在の局所表示、一意な出来事時刻、系内時点へ結ぶ。光源が動いていることと、測定に使う時計が自系に静止していることは別である。同じ源が二系で異なる運動分類を持つことを許す。

ei43はeifxの全真空区間に対する一つの速度とeiyfの現在の時計網を保持し、全選択区間でei42を要求する。範囲の完全性・非空性、校正、幾何学的な光路長は既存の定義から引き継ぐ。K専用の参照時計rcや時刻取得sjhをkへ渡すことはなく、各系のzbhを使う。

ei44は選択した区間の同じ光・始終出来事・光路長をその系の法則と現在の両端四座標へ結ぶ。ei45はK/kの二記録が同じ光・源・放出・始終出来事を測ることを要求し、各系の全区間法則へ同じVを渡す。同じτの全対応と全k時計指示も保持する。Kの経過時間4・光路20と、kの経過時間5・光路25は、どちらもV=5を満たし得る。二記録の時刻や距離の数値一致は要求しない。

この依存群では著者の新しい主張や全文判断を加えない。正のξ方向の全光軌道、同じ原点からτ=0での放出、二原理の適用と容易さの評価、ξ=Vτとτの式の代入の本文接続が残る。各系の速度法則が成り立つという条件を構成したことは、二原理からの物理的な導出を検査器が証明したことではない。
