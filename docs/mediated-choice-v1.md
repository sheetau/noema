# 途中の変化を介する因果的な依存

思考の発展と行為能力の増加の間に、指定した変化が媒介するという条件を追加した。途中の変化が原因と同時に現れるだけの場合と、原因がある状態で結果に必要な役割を持つ場合を区別する。**民衆の態度という心理的内容は未確定**であり、媒介の内容と、それを評価できる条件を明示的な関数引数として残した。

## 媒介と単なる連動

[一般定義](../examples/v016/mediated-choice.noema)の `rxh` は、前段の全体としての依存 `rxg` を保存する。その同じモデルに、原因を表す要因とは異なる、宣言済みの媒介変数を指定する。観測された状態では、媒介の内容が評価済みで成立していなければならない。

| 比較 | 確認すること |
| --- | --- |
| 元の方程式のもとで、原因だけを偽・真へ固定する | 両側に解があり、全解で媒介の内容が原因とともに偽・真へ変わる |
| 原因を真に保ち、媒介を偽へ固定する | 解があり、全解で結果が評価済みで成立しない |
| 原因を真に保ち、媒介を真へ固定する | 解があり、全解で同じ結果が評価済みで成立する |

方程式と背景は全比較で共通とする。原因だけへの介入では媒介の方程式を残し、同時介入では原因と媒介の二式だけを置き換える。各解で変数の真偽と実際の内容を照合するため、意味を伴わない変数の反転を比較の成功にしない。解がない場合や、強制した媒介状態の意味を評価できない場合も成功とは扱わない。

例えば「媒介は原因に連動するが、結果は媒介に関係なく原因だけで決まる」というモデルは、前段の全体依存を満たしても新しい条件を満たさない。一方、原因と媒介の両方が結果に必要なモデルは認める。**完全媒介や直接的な寄与の不存在は主張していない。** 原因が偽で媒介が真という側の結果までは要求していないためである。

## 同じ内容を保持した本文への接続

[本文草案](../examples/v016/kant-mediated-choice.noema)の `ialcausal` は、前段と同じ本人・開始点・終了点・方程式・観測履歴を用いる。選んだ思考の発展の内容と行為の選択能力の増加も、前段の定義そのものを評価する。

新たな媒介の内容 `meaning` と評価条件 `reviewed` は、同じ本人・元の開始点・終了点・モデルの解を受け取る。自然に生じる解だけでなく、媒介を強制した仮定世界でも内容を照合する。別人の態度や別の時点の変化を流用しない。

`ialschema` は媒介条件と残余条件を前段の条件文の後件に接続する。二つの発展の読みを途中で取り替えず、前件が偽の仮定から結果を断定しない。著者への帰属はひな形の記述を渡すもので、未充足の内容を実行しない。親文書の全宣言と先行21文を保存し、最後の部分注記を更新した。

## 心理的内容を未確定とした理由

原文の `Sinnesart` の読みを調べたが、今回の資料確認では一つの心理状態へ確定できなかった。[AdelungのDenkungsart項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_6_0_467)は習慣となった思考と行為の様式を述べ、[Charakter項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_5_0_271)は概念に関わるDenkungsartと傾向に関わる性格を区別する。これらの近傍語を、そのままカントのSinnesartと同一視していない。

[資料確認記録](../data/mediator-reading-review-v1.json)には電子翻刻の保存先とハッシュ、完全一致検索で得られた応答、原刊画像との未照合を残した。検索応答に一致がなかったことは、歴史的資料全体に語が存在しない証明ではない。資料は原文の読みの検討に使い、Noemaの自動翻訳辞書や、完成済みの心理的基本語へ変換していない。

## 検査と残る課題

95件のテストが通過した。二段の非循環な二値方程式64組合せに加え、循環による解の不在、自然な状態では見えない意味・評価の欠落、同一変数の流用、未知入力を検査した。本文でも実際の発展と行為能力の定義を使い、全体依存だけが成立する例と、媒介条件も成立する例を区別した。媒介の心理的内容は有限解釈として与えており、その内容の定義を検査済みとはしていない。

有限診断には明示的な短絡評価と、前段の純粋で外延的な解釈向けの関数再利用を用いる。キャッシュなしの照合は一般の媒介条件の基準例に限る。三文書の長形式・短縮形式・固有文字の往復とCLI解析、抽出文書のSVGのXML検査も通過した。これらは原文との意味一致や字形の目視確認を代替しない。

```powershell
python -X utf8 -m scripts.compose_mediated_choice
python -X utf8 -m pytest tests/test_mediated_choice.py -q
python -X utf8 -m scripts.check_mediated_choice --verify-only
python -X utf8 -m noema.constructed parse -i examples/v016/mediated-choice-core.noema
```

[意味規約](../data/mediated-choice-basis-v1.json)と[検査記録](../reports/mediated-choice-v1.json)に、強い介入比較としての限界を記録した。心理的内容、その漸進的な変化と時刻、各人と民衆全体の関係、政府の原則と尊厳は未完である。媒介関係の実装だけで新しい原文文字範囲や意味確認済み区間を加算しない。
