# 原点・物質軸・計器に共有する並進

u0044第一文では、初期に置いた同じ第二系の原点へ、静止系の正X方向に一定速度を与え、その速度を軸・物差し・時計にも共有させる。原刊897頁の小文字k、v、x、大文字Kと、原点だけにとどまらない対象範囲を照合した。

`eivx` は既存 `sfj` による対象保存と時計群の完全な一致を再利用し、唯一の同じ原点、三軸の全役割とその出発点を保持する。後の設定に初期静止条件を適用しない。`eivy` は各物質軸と物差しを全物質点の並進・剛性へ、原点と全時計を代表位置の完全な軌道へ接続する。

代表位置の `eivu` は、候補の三位置関数と一定速度から構成する三一次関数を、同じ対象・期間・基準系・単位の完全な `se` 履歴へ結ぶ。原点で任意の開始位置を許し、全区間で同じ速度を要求する。時計の針や歯車まで並進以外の運動を禁止する条件にはしない。

`eivz` は同じ系の全固定配置・全時点の `eioj` へこれらを接続し、三速度成分を `zb7`、零、零へ固定する。以前の棒に使った `yb` とは独立である。加速の方法、初期長さの保存、遠隔時計の同期、運動後の指示値の一致は補わない。

検査では全計器への引数の接続、時計の追加・脱落、三軸と原点の取り違え、全物質点履歴への結合、一次関数の位置を調べる。有限関数標本は境界への接続を識別するために用い、全実時刻の証明とはしない。元の全実数量化を有限評価できない場合は拒否する。

この依存群では本文の著者主張と全単位判断を増やさない。設定指示と名前の導入、後半の一意な配置、対称性を根拠とする仮定、時刻tの括弧説明を接続してから段落全体を判断する。
