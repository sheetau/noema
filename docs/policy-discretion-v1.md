# 自由を残す義務と、授けるか控えるかの裁量

カントu0015では、宗教上の事柄で人々へ何も指図せず自由を残すことを自分の義務とする記述の直後に、寛容という名称を傲慢と評価し拒む記述がある。[アカデミー版第8巻40頁28–35行](https://korpora.org/kant/aa08/040.html)でもこの配置を確認した。

この接続への解釈候補として、自由を残す義務がある立場と、自由を授けるか控えるかを選べる立場を区別した。原文が以下の規範モデルを明記しているという主張ではない。寛容一般を裁量的な許可だけで定義するものでもない。

| 定義 | 内容 |
| --- | --- |
| `rnk` | 同じ本人・立場・政策について、成立と不成立の双方が積極的に許され、それぞれの反対要求がない |
| `rnl` | `rnk`の裁量があり、その同じ政策が現に成立する |
| `rnm` | 同じ政策の成立が義務であり、その政策が現に成立する |
| `rnn` | 指定した裁量上の立場を取る本人の資格条件として、`rnk`を用いる |
| `rno` | 同じ行為でその立場を自ら取りながら、`rnn`の条件を満たさない |
| `hzfx` / `hzfy` / `hzfz` / `hzf2` | それぞれの裁量・実現・履行・資格不足を既存の政策規範`h7k`・`h7l`へ接続する |

規範の出所、本人、立場、政策記述、一人の引数列、評価文脈をそろえる。対象政策には、前段で作った同じ宗教上の範囲に実行・不実行の両方を許す政策を渡す。内側で人々に許可を与える出所と、外側で本人の裁量や義務を評価する出所は別である。

要求がないだけでは裁量を認めない。政策を成立させる許可だけでなく、成立させない許可も必要である。政策を成立させる義務があるなら、同じ対象について裁量条件は成立しない。相反する要求が共存する場合も裁量とはしない。一方、`rnm`による義務の履行は、規範体系の無矛盾性や正当性を別途証明する条件ではない。

裁量があっても政策が実現しているとは限らない。政策が実現していても、裁量がある場合と義務を履行している場合を区別する。規範上の選択可能性から、その政策を実現する能力、他者の権利を変更する権能、統治の正当性を補わない。

`rno`では、実際に裁量上の立場を取る行為と、その資格条件の不充足を組み合わせる。条件が不足していても、本人がその立場を取っていなければこの評価は成立しない。同じ政策について自由を残す義務を負いながら、授けるか控えるかを選ぶ側として振る舞う場合を表せる。性格としての傲慢、侮蔑や優越感をこの条件だけで認定しない。

裁量と資格の判定は、政策の内容を実行評価せずにできる。実際の実現を含む`rnl`・`rnm`は脱引用を使うため、引用前には既知の閉じた政策記述へ特殊化する。同じ真理値を返す別名の政策へ許可を自動で移さない。未知の規範は、裁量や義務の不在として補わない。

[一般文書](../examples/v014/policy-discretion.noema)は5,026文字、[原文付き草案](../examples/v014/kant-policy-discretion.noema)は189,559文字、[抽出文書](../examples/v014/policy-discretion-core.noema)は6,163文字である。九定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-policy-discretion-basis-v1.json)と[検査記録](../reports/policy-discretion-v1.json)を保存する。

政策の成立、成立・不成立への許可と要求、立場を取る行為の64通りを検査した。原文付き文書と抽出文書では、人物・行為・立場・文脈・規範源・政策の取り違えを含む10条件ずつを検査した。追加16テストで未知の規範、片側だけの許可、相反する要求、政策の非実行、別名記述、引数の長さ、閉じた特殊化後の引用を確認した。三文書のCLI解析、固有文字v2の往復、SVGのXML検査も通過した。SVGの目視確認は含めない。

対応箇所は既に部分草案がある範囲内であり、この追加で原文範囲の割合は増えない。名称の使用がこの立場を表すという慣習上の説明、寛容に含まれ得る不賛同・抑制・非干渉、評価の著者帰属と論証は残る。宗教・良心・権利の基礎概念、品位、称賛、政府による解放、全文の意味確認も未完である。
