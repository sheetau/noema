# 拘束の除去を仮定する条件文と、比較範囲内の最小対象

カントの足枷の描写に、同じ本人が同じ拘束を取り払う仮定と、その場合の不確かな跳躍を接続した。比較範囲・指示対象・人物を固定し、別の対象への動作を混ぜない。条件文の内容は著者への帰属として記録し、現実に除去や跳躍が起きたとは主張しない。

原文は[電子本文の AA VIII 36、10〜12行](https://korpora.org/kant/aa08/036.html)と固定資料を照合した。今回の対応は条件文の前半であり、後続の自由な運動への不慣れを述べる理由節は含まない。原刊画像の照合ではない。

## 比較範囲と最小対象

一般定義 `rcd` は、非空の比較範囲と、その範囲内で反射的・推移的・全比較可能な関係を要求する。`rce` は、その条件の下で、対象が範囲に属し、全候補以下であることを表す。同じ順位の対象が複数あってよく、対象としての唯一性は要求しない。比較不能は同順位として扱わない。また、無限の比較範囲に最小対象が必ず存在するとは主張しない。

原文側の `h3c` はこの構成を溝の幅へ適用する。比較候補は基準文脈で選び、仮定状況で溝に該当するものについて同じ尺度で比較する。深さや危険度に読み替えない。`h3d` は文脈が指す一つの対象を人物と基準文脈から返し、その最小性を `h3c` が別に検査する。

同幅の最小対象が複数あっても、その全てで跳ぶという原文にない出来事は追加しない。仮定状況ごとに都合のよい対象へ指示先を変えることも許さない。この指示と比較範囲は採用した部分的な読みの前提であり、現実の全ての溝から唯一の最小対象を選んだものではない。

## 同じ人が同じ拘束を除去する

一般定義 `rcf` は、同じ順序付き履歴の前後で、同じ対象と本人の状態関係が成立から不成立へ変わることを要求する。さらに、本人が行い本人に作用する同じ過程と、その過程による状態の終結を要求する。状態の差だけから因果関係を認定しない。

原文側の `h2w` は、先行する描写から指す除去対象が非空で、その全てにこの条件が成り立つことを表す。対象は基準文脈で固定する。複数の対象を除去する過程は別々でもよいが、本人を他人へ置き換えない。単なる拘束の不在、他人による除去、無関係な状態変化とは区別する。

`h2x` は、指示された同じ最小対象に対して、同じ本人の跳躍があり、その動作が不確かであることを記述する。安定した技能、実際の転倒、傷害は追加しない。

## 仮定と帰属

`h2y` は既存の条件構成 `rc` を使い、選ばれた仮定状況全てで `h2w` なら `h2x` が成立することを述べる。さらに `re` により、除去が成立する仮定状況を少なくとも一つ要求する。状況集合が空、あるいは前件が一度も成立しない場合を、十分な条件文の記述とは認定しない。

これは選択した状況に対する条件の検査であり、反事実条件文の一般的な状況選択理論を完成させたものではない。仮定内の履歴を実際の履歴と混ぜない。

`h2z` は、描写の基準文脈で除去対象が指定される人についてこの内容を構成する。`h3b` は著者がその内容を提示するという帰属だけを追加する。引用された仮定の内容を実行せず、その出来事の真偽を断言しない。

## 検証と残る意味

3対象間の比較関係512通りを調べ、全前順序13通りと、そのうち最小対象が複数ある4通りを確認した。実際の定義を展開した一階論理の検査では、最小対象の範囲への所属、最小対象同士の同順位、適格な対象が最小対象以下ならそれも最小であることを検証した。最小対象が唯一であるという推論には反例を得た。

除去については、前後の状態・変化・本人への作用・行為者・終結の64組と、人物・対象・過程・前後の取り違え17例を検査した。原文側の15例では、選ばれた溝への跳躍がない場合、より広い溝にしか跳躍がない場合、比較不能、候補や仮定の欠落などを区別した。同順位でも選ばれていない別の溝に跳躍がないことは、条件文を否定する理由にしない。帰属の5例では、人物・箇所・内容・文脈の一致と内容の非実行を検査した。

一般用文書は基本関係0・定義9であり、新しい文法は加えていない。原文接続文書は基本関係205・定義299・主張12、正規形45,667文字になった。前版からの追加は基本関係11・定義9・帰属主張1、1,848文字である。全文書には定義と以前の本文も含むため、これは今回の原文86文字に対する翻訳長の比率ではない。短く記述する課題は残る。
