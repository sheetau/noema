# 束縛引数の上下接触

## 実装前の対象と確認範囲

偏心包含を禁止した二円配置には、中円と小円が同じx座標・隣接する罫線で接する四配置がある。既存の中円同士の接触は語内の構成要素を結ぶ。中円と小円の接触には別の文法上の役割が必要である。

既存の最寄りの束縛参照 `bound0` は線のない小円である。述語名の最後の構成要素が単独の中円で、その核から出る引数の枝が `bound0` 一つだけなら、中円と小円の上下接触を通常の線接続の代わりに使う。引数の位置は既存の公開型・枝順規則で決まり、参照先は既存の束縛環境で決まる。新しい語義・primitive・文番号による形を追加しない。

中円は一つの円とだけ組になる既存制約を守る。語内で既に接触・重なりがある核には追加しない。主な連なりは枝の最初の核より右に続く。複数の枝の最初の核が同じx座標になれば不許可とする。合法な接触配置がなければ、従来どおり線で接続する。

復号はSVGの円と線から枝を取り出す。中円側が実際に読んだ語の最後の核であり、小円側がその引数の枝全体であることを確認する。小円が主な連なりにある場合、外側の束縛参照、引用の外の変数、未束縛の参照をこの規則で許可しない。型と構文は従来の解析器で検査する。

局所確認は四配置の幾何、実SVGからの引数順・型・入れ子の束縛・引用の回収、許可条件を外した図形の拒否を対象とする。変更前の描画器と読取器は `output/kant-bound-contact-prefix/` に保存する。旧証拠のハッシュを書き換えず、変更のない意味判断と旧SVGを保持する。全四十項目の生成前にこの共通規則を確定し、全体の外観は別途利用者へ提示する。
