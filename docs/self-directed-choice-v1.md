# 自分の判断に従って行う・控える能力

第四文の「行為の自由への能力」を、自由な選択が認められる条件で、自分の理由に基づく判断に従い行う又は控えられる既有の実践的能力として読む。動作の可能性だけではこの内容を満たさない。一方で、完全な道徳性や絶対に正しい判断まで要求すると、原文にない条件を増やすことになる。

行う側は、本人が行為について自分の理解力と支持理由による判断を持ち、他人の指導によらず、その判断が本人の決定と遂行を導くことを要求する。控える側も同じ条件を持ち、行為が生じなかっただけでは成立しない。睡眠、不能、偶然の不実行を意図的な控えと区別する。したがって二つの内容は単純な否定関係ではなく、両方が偽となる状況もある。

能力比較では同じ人・行為・基準・方法空間を保つ。行う内容を満たす方法と、控える内容を満たす方法がそれぞれ存在すればよく、同じ方法に二つの矛盾した結果を同時に求めない。各方法の候補結果と評価範囲を確認し、評価していない結果を成功や不能へ補わない。

外的な比較条件には、同じ共同体の法秩序、規範的出所、市民の立場を指定する。同じ閉じた実行内容について行う側と行わない側の双方が積極的に許され、反対極性の要求がないことを確認する。その条件の下で、基準点の本人の理解・技能・習慣などを保持した全比較場面を用いる。通常場面全体で能力を要求し、例外的な条件での失敗は許す。

ここで自由な比較場面を与えることは、現実の低い制度が既に自由を拡大したという主張ではない。能力の増加と法的な許可の増加を分けるための条件である。[後年のカントAA VI 188注](https://korpora.org/Kant/aa06/188.html)も、自由において自己の力を用いることと成熟を比較する資料として確認した。ただし後年の主張を1784年の本文へ追加せず、この箇所の唯一の意味の証明にも使わない。転記とHTMLは保存している。

民衆については同じ全成員と各人の全関連行為を有限に固定し、能力がある人・行為の組に割り当てた正の重みを合計する。この尺度で終点が始点より高く、間に厳密に中間の得点があることを能力増加とする。固定上限を超える上昇・下降にも中間値を要求する。全員の単調な改善は要求せず、停滞や局所的な後退も許す。重み・行為の範囲・段階上限は公開する解釈条件であり、技能の全側面や成功確率をこの尺度だけで尽くすものではない。

同じ心的変化による媒介と条件文全体は後続で接続する。法的自由、現実の実行、既有能力の区別を保ち、括弧文全体の意味確認文字数はまだ増やさない。
