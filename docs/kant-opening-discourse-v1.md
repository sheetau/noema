# カント冒頭段落：定義・引用・帰結を一つの文書へ接続する

[冒頭段落の新しい草案](../examples/v013/kant-opening-discourse.noema)は、六つの本文区間を同じ著者と文脈に結び付ける。先行草案で別々に記述した概念の定義に加え、二つの呼びかけ、その説明関係、標語として位置付ける結論、本文の順序を記述した。文法は0.13のままで、新しい演算子は追加していない。

原文は[カント『啓蒙とは何か』](https://de.wikisource.org/wiki/Beantwortung_der_Frage:_Was_ist_Aufkl%C3%A4rung%3F)の保存済み単位u0008である。六区間すべてに部分草案を置いたが、意味を確認済みの全文単位数はカント0/20、アインシュタイン0/282のままとする。ラテン語の意味全体、能力・因果・離脱の解釈、基本関係の定義と原刊画像の照合が残る。

## 本文にある行為を分ける

| 区間 | Noemaで指す内容 | 談話上の役割 |
| --- | --- | --- |
| 啓蒙の定義 | `r[p bi]` | 性質の説明を提示する |
| 未成熟の定義 | `r[p bf]` | 性質の説明を提示する |
| 自己に責任がある未成熟の説明 | `r[p bp]` | 条件を含む性質の説明を提示する |
| ラテン語の呼びかけ | `r[k bl[k ao[]]]` | 発話を引用する |
| ドイツ語の呼びかけ | `r[k bn[k ao[]]]` | 発話を引用し、直前の箇所を説明する |
| これが啓蒙の標語である | `r[k bo[]]` | 内容を主張し、先行部分からの帰結として提示する |

式への参照には、Noemaで記述した内容とその定義が含まれる。原文の文字列や外部リンクを意味の代わりに格納する仕組みではない。著者・受け手・本文箇所の局所参照は文脈が与えるが、「啓蒙」などの意味は先行する定義を参照する。本文箇所の参照を増やしただけで、語義を定義したことには数えない。

[汎用の談話定義](../examples/v013/expository-discourse.noema)には6基本関係・3定義がある。uaは性質の説明の提示、ubは発話の引用、ucは主張の帰属、udは根拠側の箇所と結論箇所を結ぶ帰結の提示、ueは本文順序、ufは説明の向きを表す。これらの関係自体は明示した意味規約を持つ基本関係であり、人間の発話の社会的意味を共通の基礎からすべて還元したものではない。

帰結の定義vbでは、根拠箇所が空でないこと、結論自身を根拠に混ぜないこと、全根拠箇所が結論より前にあることを要求する。順序の定義vcは選択した箇所内の非反射性と推移性を要求する。本文箇所を同一に潰したり、引用と説明の向きを逆にしたりした解釈は、段落の条件を満たさない。

## 帰属と正しさを混同しない

著者がある内容を主張したことと、その内容が真であることは別である。著者が結論として提示したことも、前提からの論理的な証明に成功したことを意味しない。この草案の主張は、著者の段落を記述するcpであり、元の標語の主張をそのまま外側で断言する式ではない。

検査用の解釈では、標語の関係amや勇気alを偽にしたままでも、著者がそれを提示したことを表せる。さらに数学を題材にした別例で、ある話者が0=1と主張したことを真として記述し、0=1自体は偽と判定した。引用の構成時に、その中の命題や能力の計算を実行しないことも確認している。

原文のalsoについては、先行五箇所をまとまりとして結論の根拠側に置く読みを採った。原文が形式的な証明の前提集合を明示したとは扱わない。別の根拠範囲を採る読みや、談話上の説得力・妥当性の評価は今後の課題である。

## 呼びかけの過剰な補完を修正する

旧草案bgは、先行する自立的使用bbをそのまま呼びかけの目的に使っていた。そのためドイツ語の呼びかけに再掲されていない「他者の指導なし」を含めていた。新しいbmは自身の理解能力を使うことだけを表し、bnはその目的へ向けた勇気を求める。先行定義のbbは変更せず、本文の引用と標語の主張をbnへ切り替えた。

他者が同じ行為を指導している検査例では、bmは真、bbは偽になり得る。この違いが、呼びかけの目的内容にも反映される。勇気を持つよう求めることを、能力の使用が既に実現したという主張へ変換しない。

ラテン語の箇所には、後続のドイツ語説明を用いて読んだ文脈的な草案blを置いた。bkはその採用した目的内容への参照であり、ラテン語のsapere一般を定義した語ではない。この選択では二つの草案の発話内容は一致するが、本文上の二つの箇所とNoemaの記述は別に保持する。独立した逐語訳、原語の綴り・語義・含意の完全な保持を達成したとは数えない。

## 検査と残る作業

統合草案は28基本記号・19定義からなる。基本記号のうち8個は著者・本文箇所・文脈の局所参照である。[意味規約](../data/kant-opening-discourse-basis-v1.json)に引数と残る制約を記録した。先行する能力を全想定結果での達成保証として読む点、因果説明、決意と勇気の不足、離脱過程の解釈は未解決のままであり、談話の接続によって解消したとはしない。

[検査記録](../reports/kant-opening-discourse-v1.json)には14の談話の解釈、7つの呼びかけの区別、別題材の主張帰属、空・自己参照の根拠を拒否する検査を収めた。六区間で全非空白文字を一度ずつ扱い、各区間のNoemaの参照先を記録する。この範囲検査は原文の脱落を防ぐものであり、訳の意味が完成したことを証明するものではない。

```powershell

```

通常記法・短縮記法・固有文字の往復を検査する。解析・表示・今回の検査には学習モデルも生成処理も使わない。原文対応表の再現には保存済みの原文単位が必要となる。
