# 文頭の構文に応じた形・試作10

前版のカント四段落では、全40主張が「左から中心に入る線」で始まっていた。これは文法上の必然ではない。試作09の描画器が、前の円から中心へ接続する予定の円を文頭に置くとき、一律に左の導入線へ変換していたためである。原文の文頭と改行後の行頭も区別する必要があり、折り返し後に左端へ続く線は文頭記号ではない。

新しい描画器`contextual_opening_script.py`では、最初の構文要素に次の規則を適用する。

| 実際の構文 | 文頭の描画 | 今回の数 |
| --- | --- | --- |
| 複数の主張の結合（and） | 上向き半径線。衝突時は下向き。既存の複合円は保持 | 22 |
| 引用を引数に持つ関係 | 中心から左下への斜線。衝突時は左上 | 11 |
| 関数参照を引数に持つ関係 | 大円では円周から左上への終端斜線。衝突時は左下。中円では半径線 | 4 |
| 評価構文（evaluate） | 中円の中心に線を入れない | 1 |
| 上記以外 | 既存の構文別規則を使用。対象間の関係には従来の導入線も残る | 2 |

引用と関数参照の両方を直接の引数に持つ場合は、関数参照の規則を優先する。引用の中身を見て文頭を分類することはしない。語の綴り、文番号、辞書番号、乱数で文頭の種類を割り当てない。配置による代替方向は同じ種類内の二方向に限り、従来の幾何検査を満たす方を選ぶ。これは新しく定めた書記上の約束であり、その角度が意味から必然的に導かれるという説明はしない。

文中の中心終端接続を一括して半径線へ置き換えることはしていない。既存の輪郭、接続、間隔、分岐、局所的な縦並びの生成規則を再利用し、文頭が変わった結果として必要な周辺の配置を再計算する。大円の斜線を曲げたり次の円へつないだりしない制約も維持する。

表示範囲は前版と同じ冒頭四段落・原文592語・40主張。行間と文字倍率0.53も維持する。Noema画像は`output/kant-page-script-v3/kant-page.png`、同じ英訳は同フォルダの`kant-page-english.png`。英訳の本文と組版は前版と同一。原文・既存の意味判断・旧描画器は変更していない。

全構文出現の保存、全体の幾何、折り返し、範囲・英訳の一致に加え、文頭の種類、識別名を変えても形が変わらないこと、通常文六例と等式の既存の描画が維持されることを検査する。画像単独での復号、自然言語の話題・感情・命令といった分類は今回の変更に含まれない。語を識別する規則と枝の読み順の課題は残る。
