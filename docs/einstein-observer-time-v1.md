# 時計表示の定義案と観測者に依存する時刻の可視接続

Einstein 正本の主張65–69、原文 u0011 の二文と u0012 の三文を、先行する時間・同時性の説明と同じ円文字文書へ接続する。五文の意味を構成する182宣言を旧正本と照合し、既存の235宣言・11主張を保持する。

## 接続する意味と参照

まず、時計の短針の表示を時間の代わりに使う定義案を扱う。すべての困難を解決できるように見えるという導入では、見かけを評価する候補と、その案を採用した場合の結果を分ける。次文は同じ案の十分性を時計の現在地だけへ限定し、異所の出来事系列の連結や遠隔出来事の時間的評価には不十分だと述べる。実際の確認、対比、二つの遠隔課題の同等性を説明する挿入を残す。

続く三文では、原点の時計を持つ観測者へ届く光信号に受信時の指針表示を割り当てる方式、その方式の観測者位置への依存、後続の考察による実用性の改善を扱う。原出来事・光信号・出発・受信・表示候補・読取り候補を同じ記録に結ぶ。原出来事の時刻と受信時刻を同一視せず、未指定の伝播補正や遠隔同期を追加しない。可能な代案に対する譲歩と、経験によって知るという根拠の挿入も保持する。

文書内の参照は、すでに公開した本文位置と役割記述の仕組みを使う。前の列車例の時計、著者の自分の時計、原点の時計を無条件に同じ個体としない。参照名が異なるだけで必ず別個体とも主張しない。同じ「時間単位」の役割を使う場合も、導入箇所と文脈を組にして照合する。共通の参照時計は既存の基準系・文脈別の取得関数へ結ぶ。

最後の文は第九本文段落の冒頭から第十三本文段落第二文までの考察を指す。これは原文 u0013 から u0018 の時刻定義への前方参照である。同期による時刻付与規則は定義を本文に保持して引用するが、その全適用や後続の全主張を実行しない。実用性の比較では、同じ尺度の二程度、厳密な優越、顕著な差を分ける。最良性や数値閾値は補わない。

## 構成と検証

共通基盤375語は変更しない。任意プロファイル23版は既存462語と旧関係53語からなる515語で、新しい参照用基本語は追加しない。五文全体の内容を一つの基本語へ隠さず、旧51定義、24参照定義、14役割定義を本文に置く。文書は377宣言・16主張（原文14、綴り注記2）となる。

到達記録の五欄、比較配置の七欄、時計・単位別の読取り候補、配置の評価状況は、それぞれの公開規約と型を保つ。欄位置は記録の成分番号であり語義番号ではない。取得処理は未知の記録や文脈、範囲外・非整数の欄を拒否する。切断の形を持つ読取り候補から、実数の妥当性や物理的成立を導かない。

`tests/test_observer_time_profile.py` は可視復号、旧本文への逆写像、23の外側帰属診断、16の役割参照と参照時計、記録成分の束縛、未知入力拒否を検査する。束縛診断は小さい識別可能な値域で一つずつ欄を変える。全実数や全状況の証明ではない。旧内側の意味判断は型付き本体の一致と既存監査で保持する。

`reports/einstein-observer-time-v1.json` に入力と生成物を固定する。独立CLIの復号と全ページの表示確認は台帳へ記録する。二論文全文の可視統合と第三者の読解は、この五文の接続とは別に残っている。
