# 勇気を持つことと、勇気を伴って取り組むこと

[更新した本文](../examples/v016/kant-courageous-undertaking.noema)では、冒頭のラテン語の呼びかけを「判断する力という目標へ、勇気を持って取り組め」と読む候補を記述した。従来の `bl` は勇気を持つことを要求するだけだった。今回の `hzs6` は実際の試みも命令の充足条件に含める。本文がその命令を引用したことから、読者が実行したとは推論しない。

この選択は原語から機械的に決まる唯一の訳ではない。[Allen and Greenough §456](https://dcc.dickinson.edu/grammar/latin/complementary-infinitive)で、敢えて行う動詞と同じ主体の補足不定詞との構造を再確認した。[カントの電子版](https://korpora.org/Kant/aa08/035.html)と保存済み原刊481頁では、ラテン語の直後にドイツ語の説明が続くことを確認した。これらの資料だけで「試み」を必要条件とする形式化が証明されるわけではない。その読みを旧版と比較できるようにした変更である。

汎用定義 `hzs4` は、同じ本人・状況・閉じた目標記述について、十分な勇気 `hzio` と、その本人が実際に行う試みを結ぶ。試み `f5`、行為者 `df`、行為の生起 `dg` は既存の基本関係を使う。同じ目標に向ける勇気があっても何もしない場合、別人の試み、別の目標に向けた試みは成立しない。取り組んでも失敗する場合は表せる。目標記述を引用するので、その成功を評価する必要もない。

`hzs5` はこの内容を命令型の発話にする。`hzs6` は既存の判断能力 `bk` をその目標に選ぶ。ドイツ語の `bn` は、自分の理解力を使う勇気を求める内容として維持する。`hzs7` と `hzsa` は更新したラテン語と同じドイツ語を標語として参照する。冒頭全体の提示 `hzsb` は、ラテン語の引用と標語の参照だけを更新し、定義・条件・説明の向き・帰結・順序を保つ。

新しい基本関係はない。六つの合成定義を追加し、本文35文のうち冒頭段落の提示一文を更新する。比較のために旧定義を保持するので、この累積資料のファイル自体は短くならない。一般の文の短縮を達成した変更とは扱わない。

検査では、勇気・試み・行為者・生起・成功の32組合せ、引数の11対照、四つの未知入力を調べる。ラテン語の旧版・新版とドイツ語の内容を比較し、標語が旧ラテン語に戻る誤りを拒否する。七つの談話対照では、引用した世界の関係をすべて未知にしたまま、著者による提示だけを評価する。通常記法・短縮記法・固有文字の往復も確認する。

第一段落の全体確認はまだ行わない。`sapere` を理由に支えられた判断能力とする既存の読み、能力の評価範囲、決意と勇気の不足を連言とする読み、条件の向きなどには検討が残る。過去の課題のうち、離脱の同一人物・同一過程への接続、前後状態の内容指定、実際の原因と帰責の区別は現在の本文ですでに修正されている。未修正の課題として重複計上しない。
