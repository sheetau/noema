# 光エーテル導入の不要性という予告

導入第二段落の第四文 `[1082,1425)`、303非空白文字を記述する。これから展開する見解では、特殊な性質を備える絶対静止空間を導入せず、電磁過程が生じる真空空間の点へ速度ベクトルを付与しない。その点・範囲において光エーテルの導入は不要と明らかになる、という限定付きの予告として読む。

光エーテルは先行する光伝達媒体 `eisby` と同じ対象を指すという解釈を採る。理論へ導入することは、その対象を物理的な説明や記述の構成要素として採用することであり、引用や否定のために語へ言及することとは区別する。`eigr` の不要性は、同じ物理的な対象・量・予測・説明を保つ記述の仕方があり、それが光媒体を導入しないこととして構成する。媒体の物理的実在を否定せず、未説明部分を捨てて不要とすることも認めない。

`eigo` は、同じ見解が空間に特権的な絶対静止と特殊な物理的性質を備えさせて導入する組の不存在を述べる。絶対静止の概念は第一文の `eisbk` を再利用する。否定を普通の空間・座標格子・ある系に対する位置不変へ広げない。

`eigp` は、電磁過程が生じる真空空間の点への速度付与を否定する。関係節 `in welchem elektromagnetische Prozesse stattfinden` は真空空間を修飾すると読み、その空間の点を対象にする。個々の点で過程が現に起きることは条件にしない。電磁過程の分類は、既存の電荷輸送・電気的作用・磁気的作用の型を通して同じ物理語彙へ結ぶ。

速度の記録には基底・基準系・長さと時間の単位に対応する三実成分を与え、既存の `sch2` で成分と軸を検査する。零ベクトルも速度の付与として扱う。空間点そのものに運動状態を帰属することを否定するのであり、そこを通る物体・光の速度や座標値の指定を否定しない。
