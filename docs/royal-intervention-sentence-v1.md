# 君主の介入を扱う第十二文の全文統合

第六段落の最終文 `[3645,4155)`、435非空白文字を、既存の条件内容と談話上の提示を結んで108番目の主張にする。既存107主張とその判断は変更しない。基本介入からの威厳の損傷、自身の見識による場合、宗教的専制を支援する場合、対応する二側の程度比較は [条件構造](royal-intervention-conditions-v1.md) の定義をそのまま使う。

`r5ro`–`r5rs` は全文と各条件内容を同じ一般基準で閉じる。`r5sa` はその内容を著者へ帰属させ、同じ対象列と仮定場面を受ける内容族を使って、語句の働きを結ぶ。著者の帰属を記述することから、現実の介入、君主の認識の正しさ、実際の批判発言は導かない。

`selbst` は君主自身の威厳にまで損傷が及ぶという取り立て、`indem` は同じ介入の具体的な仕方の説明と読む。`würdigt` では、同じ作品への内容審査 `r5ru` と、それを自分の配慮に値するものとして扱う内容 `r5rf` を分ける。好意的な見せ方 `h26jf` と、その評価からの著者の批判的な距離 `h26jg` を同じ箇所へ結ぶ。語義を論理的に否定したり、君主の悪意を追加したりしない。

`sowohl/als auch` は二つの条件付きの側の並列、`noch weit mehr` は第一側を取り消さない追加的な大きな程度比較とする。排他的な二者択一や数値比率にはしない。`so weit ... zu unterstützen` は、不相応な権能使用の程度を、その同じ専制支援によって具体化する。同じ職・活動・支援先を保ち、物理的な権力の低下とは区別する。

格言 `Caesar non est supra Grammaticos` は固定転記と原刊490頁の表記を保存する。表現対象 `h26jy` と引用箇所 `h26jv` を分け、字義的原則 `r5rx`、宗教的認識への文脈的適用 `r5ry`、批判への曝露 `r5rz` を接続する。字義は統治職だけでは文法・言語用法・文献解釈の専門的判断の上位に立てないという限界と読む。本文への適用は明示した拡張であり、字義から自動的に導出したとも、特定の歴史的人物がこの文言を実際に発言したとも主張しない。

原刊490–491頁と固定原文を通読し、全語句に連続した範囲を割り当てる。代名詞は同じ君主・共同体・臣民へ戻す。`höchsten` は君主自身の評価、`geistlichen` は専制の宗教的領域という読みを保つ。専門家の無謬性、正式な聖職者資格、全対象の服属成功を補わない。

検査では新しい接続の引数、評価を外した出来事、引用内容を実行しない帰属、必須関係の欠落と対象混同を確認する。既存の条件・因果・比較・支援の検査報告は内容ハッシュで保存を確認する。有限検査の成功と、全文を明示した解釈の下で同等と判断することは別の証拠として記録する。第六段落全体の確認は次の作業で行う。
