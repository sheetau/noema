# 判断の実際の適切さと安定した遂行

第七段落の `sicher und gut` を、同じ本人・事柄・判断の仕方について、課題に必要な条件を実際に満たすことと、その遂行が通常の関連変化でも保たれることに分ける。既存の `hzvx` は証拠に基づく適合の候補であり、資料不足を実際の判断能力の不足へ替えないため、今回は別の構成を追加する。

この読みは、Adelungの [Sicher](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_2_0_590) にある誤りを避ける用法と熟練した手の例、[Wohl](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_6_2_2635) にある事柄にふさわしい遂行の用法を補助にする。カント自身も [AA IV 331](https://korpora.org/kant/aa04/331.html) で同じ二語を、細かな演繹を伴わない理性の仕事に使う。これらは解釈を選ぶ資料であり、この箇所の唯一の語義を証明するものではない。

`r5sr/ss` は、結果を見る前に固定した非空の全適用条件を、その同じ判断についてNoemaの内容として評価する。知的課題の区別・根拠・推論・認識の限界に関する条件を具体的に与える必要がある。条件が実際に成立することと、それを観察者が資料で確認できたことは異なる。`r5s4/s5` は、同じ判断への十分な認識根拠と、非空の全使用理由の支持を構成する具体例であり、これらだけで全課題の適切さを尽くすとはしない。

`r5st` は同じ判断に本人の理解力による理由ある自立的な遂行を結ぶ。`r5su/sv` は同じ技能基盤・課題・判断の仕方を保った全ての通常の関連比較で、その適切な遂行を要求する。元の実行点も比較範囲へ含め、対応判断が元の判断と一致することを検査する。現在だけ偶然うまくいった例、比較状況ごとに方法を替えた例、失敗する場合だけを除いた範囲を安定性の証拠にはしない。

この読解では安定性が現在の適切さも要求するため、二つの修飾の内容は重なりうる。全可能性での無謬性、主観的な自信、将来学習した技能、数値的な信頼率を補わない。比較範囲と基準を現実の対象に適切に与える責任は解釈入力に残る。

`r5sw/sx` はこの二つの質を同じ遂行内容と閉じた活動記述へ結ぶ。`r5sy/sz` と `r5s2/s3` は同じ記述を現在能力と支援後の能力評価へ渡す。対象事項や基準を結果の後から替えず、無修飾の活動のプロフィールも流用しない。

局所検査は、全条件の実評価、現在の成功と通常変化での失敗、同じ対応判断と固定基準、未知入力の拒否、閉じた活動記述と実際の能力への接続を確認する。宗教的な対象範囲、集団基準、進行内容、問答の提示と著者帰属はまだ統合していないため、全文の意味確認済み文字数は増やさない。
