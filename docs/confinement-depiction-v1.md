# 閉じ込めの描写を、同じ人物への先行する阻止へ結ぶ

[原文AA VIII 35頁](https://korpora.org/Kant/aa08/035.html)の歩行器に関する関係節を、本文の非字義的な提示として追加する。閉じ込めの成立と継続を表す `zbf` は既にあったが、旧注記 `zbg` の対象側 `q3` は特定の因果方程式モデルに依存する `er` を使い、注記自体も本文に入っていなかった。

新しい対象側 `hzss` は、後の提示時点で `qj` により監督対象として選んだ同じ本人について、先行時点で同じ後見人群の行為が試みの不成立を生じさせたことを表す。前段で追加した実際の因果関係 `hzsn` を使う。過去にも危険だと信じていたことや、後の提示時点でも試みていないことは要求しない。対象者、監督者、原因となる行為や時間を取り違えた場合は区別する。

描写側 `zbf` は、飼育・集団への帰属・同じ歩行訓練装置・閉じ込めの成立と継続を組み合わせる。制限を適用する行為が終わっても制限状態は続き得る。一方、途中に解除や評価の欠落がある場合は、継続したと認めない。これは記述者が指定した履歴内の解釈であり、唯一の時制解釈や実世界での連続性の証明ではない。

`hzsu` は既存の非字義的な提示関係 `qh` により、対象側と描写側の人物引数を対応させる。両内容を実行せず参照するため、人間が実際に家畜であること、実際に身体を装置へ閉じ込められたこと、二つの内容の真偽が同じであることは導かない。局所参照 `hzst` は、前段の複文 `hzsq` 内にある関係節を指す。内包関係は参照の規約と原文範囲で固定する。

二定義・一局所参照・本文一文を追加する。新しい意味の基本関係はない。既存36文、意味規約、九単位の意味判断は保持する。

## 検証の範囲

対象側の14対照では、同じ人物と監督関係、先行する原因、後の選択時点を検査する。四つの未知入力を偽へ補わない。閉じ込めの23対照では、現在のカタログの定義を現在の評価器で実行し、成立過程・現在の制限・履歴内での継続を分ける。過去の検査から使うのは基本関係の入力例であり、列値を現在の型へ変換する。定義を検査用の真偽値に置き換えない。

八つの提示対照は、両内容を未知のままにして、対象と描写の逆転、旧モデルへの差し替え、別の著者・箇所・文脈を区別する。通常記法・短縮記法・固有文字の往復と、既存九単位の依存定義・意味規約も照合する。計算量を抑えるため、純粋な定義計算の結果を再利用する。

これらは閉じ込めの条件と本文接続の検査であり、家畜や歩行器の概念全体を独立に検証し終えたことを意味しない。身体的な歩行の詳細、家畜概念の境界、許可・機会・勇気、慎重さ・穏順さ・皮肉、比喩全体と第二段落全体の意味確認は残る。原文対応範囲と確認済み九単位・587非空白文字は増やさない。
