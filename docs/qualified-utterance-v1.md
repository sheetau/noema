# 発言資格に本人の自立的な使用能力を接続する

カント第17区間の「自ら啓蒙されている」という条件へ、先行本文でも使った能力定義を接続した。発言者本人が、同じ基準文脈で、他者の指導なしに自分の理解力を使えるという候補である。啓蒙の全意味を確定したものではなく、恐れ・軍隊・公的平穏などの残る条件は引き続き未充足の引数として示す。

## 同じ本人と同じ時点に条件を結ぶ

`hzuqualification` は、本人の既存能力内容 `h4l` と残りの条件を、同じ本人・基準文脈で結ぶ。`hzuonly` は、この複合条件を前段の発言制限 `hztonly` へ渡す。引用内の話者・聞き手・基準文脈も前段の照合を通るため、別人の能力や別時点の条件では代用できない。

必要条件の向きは保持する。引用の発言が可能なら、この能力と残りの条件が必要である。条件を満たせば必ず発言できるという逆向きの含意や、条件を満たす人の存在は追加しない。

## 能力の中身を既存の定義で評価する

`h4l` は、全利用可能方法の評価範囲が整合していることと、成功する方法があることを要求する。成功の目標 `bb` は、同じ人に所属する理解力を、その本人が同じ行為で使い、その行為に他者の指導がないという内容である。

| 指定した評価モデル | 成功する方法 | 全利用可能方法の評価整合性 | 接続した能力条件 |
| --- | --- | --- | --- |
| 成功方法があり、全方法が評価済み | 真 | 真 | 真 |
| 成功方法はあるが、別の利用可能方法は未評価 | 真 | 偽 | 偽 |
| 利用可能な方法がない | 偽 | 真 | 偽 |
| 別人だけに成功方法がある | 本人について偽 | 本人について真 | 本人について偽 |

能力が成立しても、基準時点で既にその行為を実行したとはしない。検査例では基準時点の実行はなく、評価対象の結果で使用が成立する。理解力を使う方法の評価と、引用を発言する方法の評価も別の関係で保持する。

同じ行為への他者の指導は目標を不成立にするが、別人・別行為への指導はその理由にはならない。本人を指導者として指定した関係も「他者の指導」には該当しない。この区別は今回の操作的な目標の範囲であり、指導や学習の社会的意味全体を定義したものではない。

## 本文の改訂と検証

[本文の後継草案](../examples/v016/kant-qualified-utterance.noema)は1,581宣言・19文、[抽出文書](../examples/v016/qualified-utterance-core.noema)は100宣言・1文である。三定義を追加し、原始記号は追加していない。元の全宣言と先行18文を保持し、最後の解釈注記だけを、部分的に具体化したひな形を指す注記へ置き換えた。

95テストが通過した。所属・使用・他者の指導・評価整合性・残りの条件・発言成功の64組合せ、人物・理解力・時点の取り違え、未知の解釈、参照の不整合、全評価と一つの成功方法の違いを検査した。実際のNoema定義と評価器を使用し、キャッシュなしでも結果が一致した。引用したひな形を著者へ帰属させる際には、資格条件や発話内容を実行しない。

通常表記・短縮表記・固有文字の往復、保存文書と検査記録の再現、両文書のCLI解析、抽出文書の固有文字SVGのXML検査を確認した。SVGの目視検査は含まない。

今回の原文対応は `selbst aufgeklärt` を加えた部分的な解釈注記である。同じ候補者への適用で本人への照応を保つが、`selbst` の対比・強調の意味までは完成していない。能力による読解は[第15区間の先行草案](qualified-princes-v1.md)の解釈を再利用しており、自律・決意・学識・政治的評価の全側面を網羅しない。残りの資格、自由国との対比、政治的な発言可能性、段落後半と全文の意味確認は未完である。
