# 同じ全形状の平面への極限

u0116第二文の「v=Vで全ての運動対象が面状になる」を、同じ有限形状に対する光速未満からの極限として読む。著者への帰属と、この読みの解釈注記は別の主張にする。光速ちょうどの有限βや正則な座標変換、光速で実在する物体を補わない。

元の位置(x0,y0,z0)を、速度vとK時刻tについて(√(1−(v/V)²)x0+vt,y0,z0)へ写す。光速未満ではこの前向き像と既存stvの逆代入による形状を全位置で一致させる。同じ物体の現在の全物質点の占有形状にもejgmを通じて接続する。

極限の像は、元の形状を横二座標へ射影し、縦位置Vtの平面上に置いた集合である。射影に属するには元の有効な縦位置が存在しなければならない。横方向の穴や離れた部分を埋めず、平面全体や外接長方形に置き換えない。縦方向の違う点が同じ横位置へ重なることは許す。

各固定の有限形状・時刻について、任意の正精度ごとに一つの正の近傍幅を選び、その近傍の全速度で、元の形状の全点が同じ精度で平面上の対応位置へ近づくことを要求する。近傍は形状・時刻・精度に依存する。全物体や全時刻に共通の近傍を要求せず、少数の端点や中心だけの極限にも縮めない。

これは同じ静止側形状に対する比較の族であり、加速中の物体の履歴ではない。有限検査では横射影、非連結の形状、前向き像、全点の共通精度、各量化の範囲、著者と解釈注記の分離を点検する。一般実数域の収束証明や、u0116第三文の適用限界・予告は別に残る。
