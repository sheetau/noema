# 格解析に限定しない役割候補の比較

前回は、注釈した主体のうち学習9件・評価6件が、KWJAのPAS関係の候補に入らなかった。語彙別の修正を加えず、述語から原文中の基本句を比較する方式へ候補を広げる。

対象の述語は、学習済みの基本句特徴で用言または非用言格解析と判定された基本句とする。関係先は、その基本句自身以外の原文内の全基本句。金の位置情報、語彙一覧、助詞の表層パターンは使わない。文外推測は人物として追加しない。従来のPAS関係ラベルは候補を除外する条件から外し、学習に使う入力特徴として残す。複数の格ラベルはmulti-hot、関係がない場合は専用の未接続ビットで表す。

特徴と小型ヘッドの構成、16述語群32文の学習、4群8文の開発、seed17・学習率0.003・200エポックまで等は[前回](role-transfer-protocol.md)と同じにする。前回の評価8群16文は既知の回帰資料として扱い、方式選択には使わない。新しい[8群16文](../data/role-candidates-v2.json)を予測前に保存する。方式とエポックを開発損失で決めて保存してから、新資料を解析する。

注釈のある述語について、正解役割のない基本句を `none` として学習する。別の未注釈述語は教師なしのままとし、誤った負例にしない。時間等、今回の4役割の外の意味は元の解析証拠に残す。

指定した項が候補に入る数と、役割まで正しい数を分けて測る。加えて、無関係な基本句に非noneの役割を付けた数、別の役割を付けた数を測り、正解候補を含めただけの成功にしない。「指定した役割が全部正しい」と「注釈した述語について余分な役割もない」を区別して報告する。句の主辞への注釈照合であり、全文の意味構造一致率ではない。

余分な候補を作る方針の比較として、保存済みの前回の判定器も新資料へそのまま適用する。結果を見て採用方式や注釈を変えない。生成・辞書補完・個別文の修正は使わず、原文からの再実行、固定特徴からの再学習、候補の構造を検査する。広い自然文への対応と意味構造一致率95%以上の完成条件は保持する。
