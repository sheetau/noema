# 語句範囲をラベル列全体で学習する

関係節を含む範囲が途中で切れる問題に対し、語ごとのBIO分類の学習に、隣接ラベルのつながりを学ぶ線形連鎖CRFを追加する。語別規則や辞書は使わない。固定KWJAの語ベクトルと、学習64文・開発16文は維持する。

分類部は線形と64次元tanhを比較し、BIOの開始・遷移・終了のスコアを学習する。O→I、文頭Iは構造上の禁止として保持する。有効な全ラベル列の確率で正規化した負の対数尤度を、バッチ中の語数で割って損失にする。文の間に遷移は置かず、パディングを損失にも推論にも含めない。

seed17、AdamW、学習率0.003、重み減衰0.01、全件バッチ、200エポックまでとし、開発の語数正規化した負の対数尤度で方式とエポックを選ぶ。従来の語ごとの交差エントロピーとは損失の定義が違うため、その値で従来方式との優劣を判定しない。従来方式は保存済みv3を比較対象とする。

役割はv3の境界特徴を使う線形・64次元tanhで比較する。学習述語群を前回と同じ4分割にし、3分割で選択済み設定の範囲モデルを学習して、残る1分割の候補を作る。役割の教師はその候補から作り、正解範囲を候補として与えない。開発には全学習で作った範囲モデルを使用し、開発平均交差エントロピーで役割方式・エポックを選ぶ。

両段階の選択を保存してから、新しい4述語群8文を解析する。既知の確認56文と、新規8文を分けて報告する。範囲完全一致、範囲と役割の一致、余分な項、欠落、正しい候補の棄却、別役割への誤分類を数える。原文範囲は変更せず、語の途中への丸めや誤りの自動修復をしない。

新規資料では能動・受動の意味役割を一致させ、場所の修飾先を予測前に点検する。今回も指定した一つの出来事の4役割だけの注釈であり、内部の出来事・否定・数量などを含む全文意味構造95%以上を検証したことにはならない。

CRFの正規化と復号は小さい列の全列挙との一致、勾配の有限性、パディングと文境界の独立性を検査する。学習再現、保存済みAPIによる原文解析と反復一致、生成・辞書の禁止経路の不使用も確認する。
