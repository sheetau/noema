# 特定の行為が要求に反しない条件

カントu0012の「それでも同じ人は、市民の義務に反することなく……公に自分の考えを述べる」という箇所へ、行為を指定した不違反の条件を部分接続した。同じ人に未履行の納付要求があっても、その人の別の発言行為が要求を満たすことは両立する。また、要求に反しないことと、積極的な許可を与えられていることを別々に記述する。

| 記号 | 内容 |
| --- | --- |
| `rfe` | 同じ出所・本人・役割・行為・対象記述・文脈について、成立を要求されれば成立し、不成立を要求されれば不成立である。 |
| `rff` | 明示した出所範囲と記述の有限列について、全組合せで`rfe`が成立する。 |
| `rfg` | 全出所・全ての型に合う記述について、同じ行為への要求を満たす。 |
| `rfh` | 該当する要求の出所と対象記述が、明示した範囲に全て含まれる。 |
| `rfi` | 範囲の網羅性`rfh`と、その範囲での適合`rff`がともに成立する。 |
| `hzam` / `hzan` / `hzao` | それぞれ範囲内・全域・網羅性付きの適合を、既存の要求関係`h7a`へ接続する。 |
| `hzap` | 納付要求を持つ同じ本人が公的発言を行い、その発言に市民側の役割で課される全要求を満たす。 |
| `hzaq` | 指定した本人の公的発言が行われるなら、上記の全要求を満たすという条件文。 |

該当する要求がなければ、適合条件は真になる。成立と不成立を同時に要求されれば、実際の内容の真偽にかかわらず偽になる。矛盾する要求の優先順位、免除、要求自体の正当性は、この条件に含めない。

既知の一覧に違反がないだけでは、全ての要求に反しないとは結論しない。例えば禁止の出所を一覧から除けば`rff`は成立しうるが、網羅性`rfh`は成立しない。記述の同一性も保持する。評価結果が同じ別名を一覧に入れても、要求が指定した記述を含めたことにはならない。重複は真偽を変えない。

有限検査では、要求の肯否と内容の8通り、発言への禁止・追加要求・性質の成立・納付・発言・許可の64通り、および範囲欠落など7対照例を確認した。全文草案と独立抽出文書の結果は一致する。`hzaq`は条件文なので、前件が偽なら真になりうる。それを発言が実際に行われたという主張に読み替えない。行為の性質が未知の場合は、評価を停止する。

網羅性の式本体については、二つの出所と二つの対象記述に検査領域を限定し、要求の有無・肯否と範囲選択の1,296通りを確認した。この検査では要求内容を実行せず、式本体の出所と記述の照合を評価する。原文へ接続した64通りの検査では、網羅性だけを明示した有限の要求表で評価し、残りの式との接続を調べた。どちらも任意の記述を対象とする全域の証明ではない。保存したNoemaの`rfg`・`rfh`は全域量化を保持し、有限検査器はその直接評価を拒否する。

`rfe`・`rff`・`rfg`・`rfi`は対象記述の内容を評価するため、既存の脱引用制約により、そのまま引用できない。網羅性`rfh`は内容を評価せず、引用できる。新しい著者主張は追加せず、親文書の15件を保持した。

ここでの不違反は、指定した行為に課された要求への適合という操作的な読みである。その行為が別の義務の履行を妨げるという因果的な評価、市民・制度・義務の一般的な意味、先行する処罰可能性との譲歩関係は未完である。条件式の成立を原文との意味一致の確認とは扱わない。

既存の文法と基本関係から10定義を追加し、新しい基本記号は追加していない。全文草案は86,387代用文字、親からの増分は1,904文字、独立抽出文書は4,558文字である。定義を含む文書の長さであり、翻訳の圧縮率や完成率ではない。
