# 同じ能力を目指す取り組みと機会の開放

第七段落第三文の `sich dahin frei zu bearbeiten` は、前文の質を伴う宗教的な自己判断能力へ向けて、本人が学習・探究・吟味に取り組むことと読む。目標内容 `r5to` は同じ能力 `r5tb` を参照し、本人・主題・固定基準を共有する。実際の取り組み `r5tq` は同じ活動の生起・本人の参加・活動構成・目標志向を結ぶ。目標は引用され、取り組んだことから能力の達成や達成可能性を推論しない。

`frei` は、その取り組みを強制又は禁止する適用規範と、権威的な代行・妨害がないこととして読む。全規範源の範囲を結果の前に固定する。旧草案 `rlw` の不実行にも積極的な許可があるという条件は採らない。これに同じ本人・活動の実践上の実行機会を結んだものが `r5tv` であり、単に禁止が見当たらないことだけで機会が成立したとはしない。無関係な活動の義務や職務の規律まで解除するものではない。

`r5tz` は既存 `rmt` を用い、同じ履歴の前後で、固定された人々の各人に少なくとも一つ新しい機会が生じ、その変化過程が本人に関わり後端で生起することを表す。全候補の前後評価を要求し、以前の機会が不明だったことを新規開放へ数えない。人ごとに異なる活動があってよく、全員を同時に実行させる計画や、旧機会すべての保持は要求しない。

`r5t3/t4` は同じ現在人口・話者・時代の枠組みへ接続し、その現在点を機会開放の終点に固定する。これは [AA VIII 40](https://korpora.org/kant/aa08/040.html) の機会が開かれる側の構成であり、同じ第三文の障害の漸減や徴候はまだ含めない。「場」の比喩的提示と現在進行の提示、第一文の問答・著者帰属も別に統合する必要がある。

局所検査は、同じ目標への志向と達成の区別、強制・禁止・介入、現在の機会と実行、前後の評価と同じ変化過程、現在人口への接続を扱う。既存能力を目標として実行する検査と、目標を実行しない機会検査を分ける。本文108主張と意味確認済み文字数は増やさない。
