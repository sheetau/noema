# 参照の対照例と確認評価v3

v8は、代名詞などの誤確定を減らした一方、英語の対応文を大量に棄却するようになった。新規確認評価の英語の確定率49.83%は、必要な80%に届かない。日英の確定出力の完全一致率は100%だったが、全体の採用条件は不合格とする。前版v7の合格記録をこのモデルへ付け替えない。

## 変更と選択

v7の40,178文へ、日本語の主題標識、参照先のない代名詞、名前か抽象概念かを文脈なしでは決められない例を加え、50,966文とした。推論時の辞書や修正規則は加えていない。学習・開発用の追加内容と旧回帰分割の不変性は [資料の記録](../reports/corpus-v8-manifest.json) に残した。

XLM-Rの固定特徴量から374,451パラメーターの分類器を30エポック学習した。開発用の確定率・精度・誤確定率による選択は25エポック、閾値は日本語0.87、英語0.73。CPU学習時間は約24.5分だった。[選択記録](../reports/routed-v8-selection.json) と [学習・回帰集計](../reports/joint-v8.json) を保存した。

## 次の対照実験

未知語の範囲だけを学習すると、その周囲の文字が対象ではないというラベルは与えられない。v9では、置換元が注釈済みの参照例について、周囲の既知語と非対象部分のラベルを保持する。文全体は未対応のままとし、完全な意味構造の正解を作らない。これは過剰な範囲抽出を抑えられるかという仮説であり、今回の観察だけで原因を断定しない。

v9は文・順序・ID・開発用資料・旧回帰資料を変えず、学習用注釈だけを変更する。固定特徴量を同一入力の検査後に再利用する。確認v3は既に参照したため、次回から回帰資料として扱う。v9の学習結果はまだ採用結果ではない。
