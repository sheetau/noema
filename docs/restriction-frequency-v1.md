# 制限の程度と頻度

各時点で活動の何割が禁止されているかと、対象期間のどれだけの機会で強い制限が成立するかを分けて記述した。既存の規範・私的活動・期間・算術を合成し、新しい基本概念は追加していない。カントの `öfters sehr enge eingeschränkt` への候補であり、原文の頻度と程度の全意味に一致すると確認したものではない。

たとえば、同じ人と職務について、二つの活動の禁止割合が三つの評価機会で順に1、1/2、0だったとする。「制限が強い」という仮の基準を1/2以上にすると、三機会のうち二機会が該当する。各機会を等しく数えた頻度は2/3になる。程度の基準を3/4以上に変えると、該当するのは最初の機会だけで、頻度は1/3になる。頻度を高いとする基準は、これとは独立に指定する。これらの数値は例示であり、原文へ補う閾値ではない。

各機会の判定には二つの段階がある。`h75` は、その機会の私的活動が全て列挙され、規範の衝突や未分類がなく、禁止割合も正しいことを確認する。その上で、既存の `h74` が程度の基準を満たすか評価する。この区別により、未分類・衝突・誤った割合を「強い制限がない機会」として数えることを防ぐ。規範を評価できない場合は、偽で補わず評価を拒否する。

| 定義 | 内容 |
| --- | --- |
| `rd3` | 状況が有限列に含まれる |
| `rd4` | 条件を満たす状況の重みを合計する |
| `rd5` | 非空の対象範囲の全列挙、重複の不在、全対象の分類、正の重みを検査する |
| `rd6` | 全体の重みと該当部分の重みから正確な比率を検査する |
| `rd7` | その比率に頻度の評価基準を適用する |
| `h76` | 同じ期間枠内で、各機会の制限の程度と期間内の頻度を結び付ける |

機会ごとの重みを全て1にすれば、機会数の割合になる。例の重みを2、1、1にすると、1/2以上の制限が成立する部分の重みは3、全体は4で、頻度は3/4になる。全ての重みを同じ正の倍率で変えても、割合は変わらない。同じ状態の機会を細分化する際も、その合計重みを保持すれば割合を保てる。重みを保持せずに同じ観測を増やす操作は、同じ測定とは扱わない。

重みは自動的に継続時間を意味しない。継続時間として読むには、各状況が代表する重複しない区間、その完全性、区間内の状態の保持を別に確かめる必要がある。有限の観測点の比率を、現実の連続時間全体の頻度と同一視しない。活動の粒度、機会の範囲、重み、程度と頻度の基準は、結果を見て選び直すことを認めるための引数ではなく、解釈を明示するための引数である。

期間は既存の `h7q`・`h7r`・`ic`・`tb` を使い、一つの経過の非空で間の抜けない範囲とする。評価の途中で基準文脈を各点へ取り替えない。ただし、この有限範囲が原文の対象を尽くすこと、活動の種類が変わった場合の程度の比較可能性までは、構文や有限検査から証明できない。現行の評価器は式の評価順によって範囲外の引数も参照し得るため、範囲内だけ定義された部分関数を無条件に受け付けるという主張もしていない。
