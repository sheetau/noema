# 自由の条件と将来予測で公衆の範囲を共有する

自由を許される公衆と、将来の自己思考者を数える公衆を同じ参照に結んだ。前段の接続では、許可条件に公衆と参照文脈を渡す一方、予測の母集団を別の供給関数で指定できた。そのため、許可を受ける集団に足りない該当者を、別の集団から数える指定も可能だった。

`rqu3` は、公衆と参照文脈から構成員の述語を作る。既存の想定読者関係 `h6t` を使用し、人物と将来の評価機会を引数に受ける。参照文脈は固定しておくため、評価機会が変わるだけでは構成員の範囲を変えない。許可を得たか、実際に受領したか、自己思考者になったかは、この範囲を作る条件に含めない。

`rqu4` は、許可条件と同じ公衆・参照文脈から `rqu3` を作り、前段の条件付き伝播へ渡す。構成員の供給関数を外部から渡す必要がなくなり、残る供給関数は13から12になる。候補ごとの時間・性向・伝播条件は保持する。

同じ公衆の中で、各機会に該当する人物が交替することは許す。固定するのは参照範囲であり、誰が独立して判断し、依存から脱し、性向を伝えるかではない。また、人でない個体が誤って範囲へ含まれた場合は、その個体を除いて成功させず、既存の適格性検査で不成立にする。

後見役が担当する集団、発信者の周囲、公的発信の宛先としての読者世界は、この公衆と別に記述する。原文の「大衆」を公衆と同じ対象へ置き換える変更は加えていない。任用と役割は引き続き、その対象集団・本人・時点について検査する。

四項目のテストで次を確認する。

- 公衆・参照文脈・人物・評価機会の36組合せ。評価機会を参照文脈へ代入しない。
- 構成員・資格・許可の64組合せ。既存の公的使用への許可、将来範囲と複数人の条件を実行し、両者の公衆が一致することを調べる。
- 許可対象の公衆には一人しかいないが、独立した旧母集団には二人いる対照。同じ評価で、許可は成立し、共有した範囲での予測は不成立、旧母集団での複数人条件は成立する。
- 人でない構成員、五つの未知入力、閉じた著者帰属と期待背景、既存の34文と七つの意味確認の保持。

64組合せの検査では、資格に試験用の述語を渡す。任意長の経路を含む伝播全体の真理を、この検査で証明したとは扱わない。本文への帰属の検査では、実際の伝播定義と性向記述を含む閉じた内容を使用し、内容の真理は未知のまま帰属を評価する。
