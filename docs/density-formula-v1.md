# M0390の五つの等式と、単位全体の確認課題

アインシュタインのM0390にある三速度と二つの密度関係を、周囲の場の方程式から分けて記述した。既存の`semx`や`semy`は、微分係数の変換や対流を含む場の式まで結ぶ構成である。これらの強い条件をそのままM0390だけの意味とすると、原文の式に別の前提を混ぜることになる。既存の構成は保持し、式だけの条件を新しく設けた。

原文には三つの速度成分の等式と、ρ′＝新電場の発散＝密度の変換結果という連鎖がある。確認上は五つの等式として扱う。

| 定義 | 範囲 |
| --- | --- |
| `senr` | 五つの等式の有理数による比較形 |
| `sens` | 同じ五つの関係を有効な実切断と新電場の微分表で表す |
| `sent` | 必要な三つの対角微分値を、同じ新電場・領域・地点の各偏微分へ結ぶ |

三速度の条件と、同じ新密度の二つの等式を共有する。光速度・基準系速度・βの正規化と、共通分母が零でないことは引き継ぐ。分母を払うことで未定義の分数が成立したように見せない。一方、原文の式にない物質速度の上限や分母の正値条件は追加しない。数学上の反例に使う数値が、そのまま現実の荷電物体の運動を表すという意味ではない。

有理数の検査では、1/V²、1/β、共通分母の逆数を明示し、原文の分数形の五つの関係と`senr`が、定義された範囲で双方向に同値であることを確認する。数式が電磁気学の経験的に正しい法則であることを証明する検査ではない。

新電場の微分表では、対角外の値を変えてもこの式の条件は変わらない。必要なのは三つの空間対角微分であり、時間微分や磁場の微分を要求しない。ただし二つの対角値を互いに打ち消すように変えると、和は同じでも実際の三微分ではなくなる。その場合、式だけの条件`sens`は成立しうるが、偏微分への接続`sent`は不成立になる。この差を検査する。

原刊916頁との過去の照合記録、保存した数式のハッシュ、Noemaの引数位置と原文の記号、五つの関係、残る確認項目を[単位別の確認記録](../data/density-formula-review-v1.json)にまとめた。機械検査は、引数や関係の欠落、密度の参照先の取り違え、根拠のない完成への変更を拒否する。記録の形式が正しいこと自体を、読解の正しさの証明にはしない。

現段階で確認したのは、式の局所的な対応、分母の条件、同じ密度値の共有、新側の必要な微分への接続、不要な場の前提を追加していないことまでである。次の項目は残る。

- 旧側と新側の量が、本文中のどの物体・系・出来事を指すかを、この単位の使用へ結ぶこと。
- 直前の`wobei`が式を導入する役割を、著者の提示として記述すること。
- 基準系、速度、電気密度などの物理概念の共有された意味規約を確認すること。
- これらを含めて単位全体を再読し、原文との意味一致を判断すること。

新しい著者主張や原始概念は追加せず、親文書の宣言と174件の主張を保つ。式の条件を定義しただけで著者の提示を完成したとは数えない。このため対応範囲の割合も、意味確認済みの単位数も増やしていない。判断の共通方針は[原文単位の意味確認](semantic-review-v1.md)に記した。
