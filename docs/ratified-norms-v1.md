# 承認と、そこから生じる要求・許可を分ける

カントのu0013には、ある契約について無効だと述べ、権力者などによる確認があったとしても、その判断を変えないという箇所がある。今回は、承認があることと、同じ契約から要求・許可が生じることを分け、基準文脈での判断と仮定した状況での判断をNoemaで記述した。[アカデミー版電子本文39頁](https://www.korpora.org/Kant/aa08/039.html)の2–5行でも、この文の順序と仮定の形を確認した。保存済みの原文単位は変更していない。

無効性は、指定した出所から要求も積極的な許可も生じない、という範囲に限定して構成した。単に要求がないことと、許可があることは異なる。契約を作成・署名した事実、強制した事実、内容の真理とも別である。権能・免責・資格など全ての制度的効果を含む無効性を定義し終えたものではなく、原文に対する部分的な解釈注記として記録する。

| 定義 | 内容 |
| --- | --- |
| `rhp` | 一つの対象について、成立・不成立それぞれの要求と許可が全てない |
| `rhq` | 同じ出所・文脈の全ての名宛人・立場・記述・引数列について`rhp`が成立する |
| `rhr` | 明示した一覧に含まれる対象について`rhp`が成立する |
| `rhs` | 同じ出所・文脈の全ての要求・許可の対象が一覧に含まれる |
| `rht` | 一覧内の不成立と、一覧の完全性をともに要求する |
| `rhu` | 指定した非空の承認主体の全員が、同じ出所を同じ文脈で確認する |
| `rhv` | 候補状況の各々で、承認があれば同じ出所について指定条件が成立する |
| `rhw` | 指定候補の中に、承認がある状況が存在する |

対象には、名宛人・立場・Noemaの内容記述・順序付き引数列を保持する。同じ真偽になる別名の記述へ、要求や許可を自動で移さない。引数列の順序や個数を変えた対象も区別する。要求や許可の不成立を述べるときは、対象内容の真偽を実行評価しない。

一覧に要求・許可が見つからないことだけでは、全ての対象で不成立とは言えない。空の一覧なら`rhr`は真になるが、一覧外に要求や許可があれば`rhs`は偽になる。`rht`では両方を要求するため、知らない対象を一覧から落として無効だと判定することを避ける。全記述と全有限列への量化はそのまま残し、有限の既知一覧を全領域として扱わない。

承認の主体と規範の出所も分けた。承認は外部の主体による同じ対象への確認であり、要求・許可の判定に使う出所をその主体へ置き換えない。承認されていても規範が生じない場合と、承認されていて規範が生じる場合を、異なる解釈として記述できる。また、契約を出所とする要求・許可を否定しても、外部の出所による返還や制裁などの要求まで否定したことにはならない。

原文への接続では、`hzce`が契約を規範の出所として既存の要求関係`h7k`と許可関係`h7l`へ渡す。`hzcf`は、基準文脈で`hzce`が成立することと、基準文脈で固定した候補状況で承認があるなら`hzce`が成立することを合わせる。候補を調べるたびに、別の契約や別の候補範囲へ切り替えない。

この条件から、現実に承認されたことや、承認される候補が存在することは導かない。候補が空なら条件付きの部分は真になり得るが、存在を別に尋ねる`rhw`は偽になる。承認主体の範囲が空の場合も、全員の確認というだけで承認済みとは扱わない。

検査では、二つの対象に対する両極性の要求・許可256通り、一覧の選択4通り、完全性の条件を一対象へ適用する16通りと7つの参照対照例を調べた。承認主体二つ・候補状況二つの承認と条件の64通りでは、承認と規範の状態を独立に変えた。原文接続の16通りでは、基準文脈の判断と候補二状況での判断が異なる場合も区別する。未知の規範や確認関係は、不成立として補わず評価を拒否する。

原文接続の検査では、全対象にわたる規範の不成立を明示した検査用の解釈として与える。全記述と全有限列をそのまま有限解釈器へ渡す検査では、それぞれ量化を拒否することを確認した。特定対象への完全性の条件を検査したことは、実際の全規範対象を列挙し終えた証明ではない。

[一般用文書](../examples/v014/ratified-norms.noema)は1,862文字、[原文付き草案](../examples/v014/kant-ratified-norms.noema)は112,331文字、[抽出文書](../examples/v014/ratified-norms-core.noema)は2,127文字である。10定義を追加し、親の宣言と15件の主張を保持した。新しい原始概念と著者主張は追加していない。[意味規約](../data/kant-ratified-norms-basis-v1.json)と[検査記録](../reports/ratified-norms-v1.json)に、意味と検査範囲を保存した。

原文との対応は「無効」「確認の仮定」「確認されている」という三つの短い範囲に限定した。契約の相互約束としての構造、永久に啓蒙を妨げる目的、確認する諸制度と最上級、通常予想に反する譲歩の効果、著者の主張への接続は未完である。規範の評価文脈も著者の見地へ結ぶ必要があり、現に支配権力が採用している規範と同一視しない。原文単位全体の意味確認を終えた区間数は増えていない。
