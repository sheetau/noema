# 第三系の導入から群の主張まで

u0147第一文の過去の別導出は、現在の同方向の速度式へ至るejriで保持する。続く第三系導入の条件文は、906頁の表示式M0285を挟み、907頁冒頭の `tritt` で完結する。その直後の群の主張と `wie dies sein muß` の挿入句までを、一続きの関連群として読む。

第三系k′はzloであり、§3の逆変換用K′とは別である。新しい呼称個体だけを追加し、導入・仮定採用・命名・先行節への参照には既存の関係を使う。Kとkは§3の同じ設定、x/y/z/tはKの現在の測定・時刻の規則を参照する。三系の並進、原点の軸上運動、尺度と零点の規約、全現在記録の存在と値の一意性は前回の構成を引き継ぐ。

M0285は(v+w)/(1+vw/V²)である。同じs4lの速度引数へこの値を渡すので、縦位置だけでなく時刻式とβも同じ値を使い、横二成分を保つ。著者がこの設定と二回適用から同形式の四式を得ると提示する内容に接続し、表示式を独立した無条件の主張へ分断しない。

群は、同じ軸・同じ光速度・係数1・共通原点を持つ平行変換の族として読む。許容速度は−V<v<Vで、負の速度と零も含む。全四入力での写像の合成、単位写像、両側逆、速度の群と写像の忠実な対応をs5e/fで構成する。現在の一組の三記録の一致と、数学的な写像の全域の性質を区別する。「そこから分かる」は合成結果と全域の合成則を根拠とする著者の帰結提示であり、閉性だけから群を推論してよいという認定ではない。

挿入句は、同じ数学的前提に相対的な必要性として読む。前提は有効で正のVと異なる四座標役割であり、変換族は既存s46の定義を共有する。その前提を満たす評価状況が少なくとも一つあり、全てで同じ群の内容が成立することを要求する。候補は前提だけから選び、群であることや合成則の真理を候補条件に含めない。未説明な候補選定zlzは使用しない。

これは固定した数学的解釈内の必要性であり、演算や変換の定義を変えた全モデルでの論理的必然性ではない。数学的な内容が状況に依存しなければ各状況の真偽は同じになるが、非空の前提範囲と全称を省略しない。命令、義務、心理的な当然さの全てを含む読みでもない。挿入句は同じ群の内容にeisa5で結び、独立した別の論点にはしない。

別導出の補助第三系が許される速度域と、前段の点の式の範囲の差は保持する。元の結論を狭めず、著者が同じ式へ至れると述べることと、その一般的な導出の健全性を区別する。有限検査、保存した代数的証拠、全域量化の列挙拒否、原刊を通して読む意味判断は別の証拠である。
