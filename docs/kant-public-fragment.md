# 公開語形と局所構文の試作

この文書はコミットb92fe125時点の限定構文を基礎とし、字形には[偏心配置を禁止する訂正](kant-circle-pair-rule.md)を反映する。公開語彙全体への接続と語境界の後続規則は [複合語の仕様](kant-public-words.md)を参照する。

この試作は [kant-pageの生成規則](kant-generator-decoding-design.md)から、公開語の識別、引数順、引用、変数の束縛を一つの処理として接続する。生成は scripts/kant_public_fragment.py、読取器の入力は円と線だけである。完成候補や新しい固定仕様ではない。

## 何を再利用するか

既存の Vocabulary が公開する16語について、形・引数型・語義・参照先をそのまま使う。rain と above のように、半径線の南北だけで区別している語は回転させない。town の中小同心円と home の中円の円周上に小円の中心を置く形も保持する。語を文中の辞書順位で割り当てず、一文専用の primitive は追加しない。

三段の候補探索、円周へ直角に入る経路、円周から曲げるまでの長さ、面積重心の累積補償は、実際の kant-page 生成器から再利用している。経路関数は入口・出口を分けた試作を直接呼ぶ。小円中心線、同中心の二方向線、三円の重なり等は、元の幾何検査を変更せず拒否する。

## 可視形状の識別

読取器は、同じ核の円サイズ、中心間の相対位置、中心線の方向、大円の外側終端斜線から語を識別する。接続によって半径線が外まで伸びても語は変えない。描画時に radius と名付けた線が、接続後に center_external と観測される問題を、見えない生成ラベルで区別しないためである。

上下の段、語間の長さ、経路の曲がる位置は配置の異体になる。語の中心方向は公開表が許すものだけを選ぶ。文法上の同じ要素に複数の形を許す場合も、表に明示し、他の語と衝突しないことを有限の字形表で確認する。

| 構文要素 | この試作での形 |
| --- | --- |
| and / or | 小円中心を中円の左円周上に置く二円。andは中心線なし、orは中円中心から上への線 |
| implies | 同じ二円に、中円中心から下への線を付ける |
| not | 中円中心から左下への線 |
| equal | 大円の円周から外へ出る終端斜線。四方向を異体として許す |
| quote | 大中同心円と上下いずれかの中心線 |
| forall / exists | 大中同心円と、それぞれ左・右への中心線 |
| 最寄りの束縛への参照 | 小円 |
| 一つ外側の束縛への参照 | 大小同心円と円周外の終端斜線。小円中心には線を入れない |

この表は限定した構文の識別を可能にする実験的な割当てである。すべての有機的形状に意味を対応させた最終体系ではない。たとえば二円の接触による適用や、共有引数を一つにまとめる形は未接続である。

## 順序と範囲を先に決める

通常主張は最初の意味要素から始まり、共通の文頭記号を置かない。読取器は、回収した主な連なりを、公開された引数数に従う前置式として読む。二項演算子なら式を二つ、単項演算子なら一つ読むため、閉じ記号や隠れた木を必要としない。

引数が二つ以上ある場合、横枝へ出せるのは引数位置 floor(引数数/2) だけとする。その位置が中円または小円を主円とする終端項であれば、横枝にしても、主な連なりに残してもよい。大円は三段をまたいで後続の経路を塞ぐため、元の生成器の横枝と同じく対象外とし、主な連なりに残す。横枝があれば読取器は既知のその位置へ戻す。「終端項の候補を集め、その中央を選ぶ」という元の規則には依存しない。主な連なりは枝の中で最も右へ続くものとし、横枝は一つの終端核に限る。

連言の左右結合は省略しない。左右の and を独立した要素として残すので、元の構文を正確に回収できる。共有の融合を再導入する場合も、可視形状から逆変換できる規則が必要になる。

引用の先頭には公開された quote の形を置き、その後の一式だけを引用する。前の連結成分と引用頭の中心が同じ段にあるときは、不可視の直線接続も許す。空白を読んだだけで引用を補うことはない。見える接続を選んでも同じ構文へ戻る。

変数は現在の範囲の最寄り、または一つ外側の束縛を参照する。引用に入ると束縛環境を空にし、引用を出ると元の環境へ戻す。隣の式の束縛も持ち越さない。名前は既存の native 正規化規則に合わせて復元する。入力は正規化済みの構文に限り、入力名を黙って変更したうえで一致と報告しない。

## 検証範囲

既存の16語、二・三引数、論理結合の左右、順位0の引用、二段までの individual 束縛を対象にする。各対照例を実際のSVGにしてから、付属の語名・元構文・引数位置を渡さず復号する。横枝ありと主な連なりだけの両方を確認する。SVG要素の順序を逆転し、線を分割しても同じ構文に戻ること、未知の形・余分な線・引用をまたぐ自由変数を拒否することも確認する。

型は既存の native 正規化器で確認する。語義のモデル検証や過去の全文監査は繰り返さない。ここで一致するのは、公開語の参照先を保った限定した構文であり、二作品全体の固定円文字の復号完了ではない。

語形の衝突確認は、実行対象の16語だけでなく、公開済みの全30根語を予約して行う。初期試作の中円斜線三種類は、16語内では衝突しなかったが、残りの根語と衝突したため撤回した。その後の偏心した内側小円も違反として撤回し、小円中心が中円の左円周上にある形へ訂正した。旧試作のコードと報告は履歴に保持するが、現行の許容形の根拠には使わない。

未対応は、全語彙への複合語展開、任意深度と型の束縛、順位付き引用、共有の融合、接触による適用、改行・改頁と任意倍率の復号である。短い対照例だけから、kant-page全体の密度や反復が適切だとも判断しない。完成候補を構成した後に、利用者の外観確認を経て固定する。

見本は output/kant-public-fragment/index.html。生成・局所検査・報告は project_work check の同一プロセスで行う。
