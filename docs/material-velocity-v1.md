# 物質点の履歴から速度を説明する

速度を、密度と一緒に値を割り当てるだけの関係から、同じ物質点の位置の時間変化へ接続した。既存の差商・極限による微分`sjs`と、出来事の四座標への対応`zpb`を再利用し、新しい原始的な速度関係は追加していない。

| 定義 | 内容 |
| --- | --- |
| `senz` | 評価時刻の前後を含む正の半径の実開区間が、時間領域に含まれる |
| `seoa` | 曲線の引数を座標時刻と一致させ、同じ物質点・系・出来事・文脈の座標へ結ぶ |
| `seob` | 空でない領域の各時刻に対応する出来事があり、割り当てられた全座標も同じ曲線に一致する |
| `seoc` | 履歴の内点における三空間座標の時間微分を、その出来事の速度成分にする |
| `seod` | M0390の既存の式と参照関係に、同じ物質点・出来事の新旧二系の速度の説明を結ぶ |
| `seoe` | 密度だけの帰属関係と、履歴・微分による速度の説明から、密度と速度の帰属関係を構成する |
| `seof` | 構成した関係を既存の式の内容`senx`へ渡す |

曲線は、時刻を受け取って四座標を返す関数である。その時刻成分は引数と同じ値でなければならない。固有時など別のパラメーターで位置を微分した値を、基準系の座標時刻に対する速度としてそのまま使うことを防ぐ。

履歴には二方向の条件を置いた。各実時刻に、その物質点の出来事と座標が存在することだけでは足りない。同じ物質点・系・文脈に別途割り当てられた座標も、その曲線に一致する必要がある。これにより、一つの都合のよい記録だけを採用し、同じ時刻の矛盾する記録を無視することを避ける。

速度を取る時刻には、前後の実開区間を含む領域を要求する。既存の相対微分は片側の領域でも定義できるため、そのままでは片側の履歴を通常の内点での瞬間速度に使える。孤立点や片側だけの履歴を速度の根拠にしない条件を、微分の一般的な定義とは別に明示した。

`seoe`は、密度だけの帰属関係を受け取り、同じ物質点・系・出来事・文脈について、速度を説明する領域・曲線・地点が存在することを要求する関数を返す。密度を速度成分として使ったり、別の対象の履歴を共有したりしない。`seof`はこの関数を先行版の式の内容へ渡す。前版の未展開の関係`zqd`との無条件の同値を宣言したり、新たな解釈を著者へ帰属させたりはしていない。

ここで扱うのは、一つの物質点の履歴である。広がりのある荷電物体全体や、複数の電荷種の流れを無条件に一本の曲線へ縮めるものではない。基準系・時刻と長さの単位・測定記録の実現は既存の意味規約に依存する。規格化密度を電荷分布から説明する部分も残る。

検査では、静止・正負の速度・加速を含む五つのアフィン／二次曲線を用いた。15の対照例で、速度成分、物体・系・出来事・文脈、曲線上の位置、別のパラメーター、履歴の欠落、片側・孤立・空の領域を区別した。基準系の時刻以外のパラメーターを使う例では、一点の座標と局所的な微分値が一致しても、履歴の時刻条件が成立しない。

履歴の逆方向の条件そのものを二つの具体的な座標に適用し、同じ時刻に矛盾する記録を拒否することも確認した。内点条件の全称部分には、三つの正の半径について前後の時刻を与え、18例で片側・孤立した領域の不足を検出した。これは実際のNoemaの条件の具体化であり、全実時刻にわたる履歴や内点の存在の証明ではない。

新旧二系への接続では、元の式、旧側の速度、新側の速度、曲線の対応を六つの条件で分けて検査した。この接続検査の全履歴・微分・元の式の成立は、明示したテスト用の解釈を使う。全域の履歴・内点・差商極限をそのまま評価しようとすると、有限解釈器は実数を表す切断への全域量化を拒否する。未知の関係も数値の一致から補わない。
