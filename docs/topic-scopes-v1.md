# 許可の話題範囲と同じ統治者への参照

カントu0016の「その統治者の立法に関して」という対象範囲を、公的使用の許可・危険・認識へ部分接続した。[本文の改訂案](../examples/v016/kant-topic-scopes.noema)では、選択した各発言の話題が、同じ統治者の指定範囲に属することを要求する。原文の「も」に当たる焦点や、宗教から立法へ議論を広げる比較は、今回の記述には含めていない。

既存の1,405宣言と先行16文を保持し、最後の帰属文を改訂した。7定義と3原始宣言を追加して、本文は1,415宣言・17文になった。旧版との同義変換ではない。許可があっても、その発言の話題が指定範囲から外れている場合、新しい条件は成立しない。

## 範囲条件と許可条件

| 定義 | 条件 |
| --- | --- |
| `rrr` | 基準文脈で選んだ各人・各活動の話題を、同じ出所の対象範囲へ結ぶ。 |
| `rrs` | `rrr` と、既存 `rrj` の全選択行為への許可を同時に要求する。 |
| `rrt` | 対象範囲を指定する関係も含めて、`rrs` の閉じた方針記述を構成する。 |
| `hzopolicy` | 本文の人物・活動・提示項目を保持し、立法に関する範囲の指定を加える。 |
| `hzosafety` | 変更後の同じ方針が成立する想定結果で、不利益がないかを調べる。 |
| `hzoinsight` | 変更後の安全性の内容について、本人の認識・肯定判断・真理の条件を保つ。 |
| `hzoattribution` | 改訂した内容を同じ著者へ帰属する。 |

二人の発言を対象にした場合は、両方の話題と両方への許可を確認する。一人の話題が範囲外なら、その人を対象から除いて方針を成立させることはしない。一人に許可がない場合も、結果の状況で対象者を選び直してその人を除くことはしない。人・活動・話題・対象範囲の選択は、元の基準文脈に固定する。

範囲条件が成立しないことは、対象外の話題について発言することの禁止を意味しない。今回の範囲指定と選んだ発言の間に不一致があるという条件である。同様に、方針が成立しないことから危険な結果の存在を導かない。

母集団や活動の選択が空なら、全称条件は空虚に真となり得る。対象の存在や、全ての法・意見を網羅したことは補わない。解釈が未知の場合は、空集合や偽で補わず評価を拒否する。

## 立法の意味と参照範囲

今回の `hzodomains` は、統治者・話題対象・文脈を結ぶ参照範囲の入力である。「法」や「立法」の意味を、この関係名だけで説明済みにしたものではない。既存の規範変更や権能の定義を範囲条件へ無条件に追加すると、意見の対象が特定の実行済み立法や権能行使だけに狭まるため、今回は追加していない。

法的な制度、規範集合、法文、立法行為の関係と、「その統治者の」という照応の全体は残る。既存の法に限定するか、提案や改訂も含むかという範囲の説明も必要である。今回確認したのは、指定された参照範囲を人物・話題・文脈の混同なしに本文へ接続する条件である。

原文対応は `[507, 538]` の `in Ansehung seiner Gesetzgebung` を加えた。非空白28文字であり、前回の認識 `[485, 494]` と安全性 `[539, 649]` は重複加算しない。よりよい法文案、率直な批判、先行する統治者の照応、強調、後続の実例は未記述である。
