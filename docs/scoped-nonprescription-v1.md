# 主題を限った非指図・自由と、本人の義務判断

カントu0015冒頭の君主と、宗教上の事柄で人々に何も指図せず自由を残すことを自分の義務と考える内容へ、部分草案を加えた。命令の不在、実行・不実行の双方への積極的な許可、実際の義務、本人が義務だと考えることを別々に記述する。

| 定義 | 内容 |
| --- | --- |
| `rm2` | 同じ組織内で、他の全役職より上の役職を指定本人だけが保持する |
| `rm3` | 非空の人々と、同じ主題・基準時点に固定した非空の活動範囲について、現在の評価が済んでいる |
| `rm4` | 同じ規範源から、対象の実行要求も不実行要求もない |
| `rm5` | 同じ規範源が実行と不実行をともに積極的に許し、反対要求との衝突がない |
| `rm6` | ちょうど一つの引数を規範源として、固定範囲の`rm5`を返す政策内容 |
| `rm7` | 同じ本人に、その本人を規範源とする指定政策の成立が要求されるという義務内容 |
| `hzfn` | `rm2`の本人が人で、同じ役職を委ねられているという追加条件 |
| `hzfo` / `hzfp` | 人`aa`と既存の行為規範`h7a`・`h7b`へ自由条件と政策を接続する |
| `hzfq` | 外側の政策への義務を`h7k`・`h7l`へ接続する |

規範の出所、本人、立場、活動、実行記述、評価文脈をそろえる。一つの活動が許可されても、別の立場や記述にその許可を移さない。実行も不実行も要求されない状態には、両方を積極的に許す状態と、何も許可していない状態の両方があり得る。実行を要求しながら不実行を許す場合も、衝突として自由条件から除く。

宗教上の対象範囲は、主題と基準時点に結び付いた活動関係で与える。判断の候補状況を評価するときも、基準時点を動かして都合のよい別範囲へ交換しない。各人の対象活動がない場合や評価不足の場合を、「何も指図していない」「全面的に自由だ」という証拠にしない。範囲外の活動への要求は混ぜず、その活動を明示的に範囲へ含めた場合には判定を変える。

ここで扱う自由は、指定した規範源からの要求・許可に限る。他の規範源による拘束や、物理的な実行不能を取り除いたとはしない。許可の判断のために活動を実行評価することもない。宗教の具体的な語義、対象範囲の実世界での網羅性、権利の保障、実際の不干渉は引き続き必要である。

「自分の義務だと考える」という内容には、閉じた義務記述を既存の`rlg`へ渡す。同じ本人の同じ判断が、本人を引数とする義務内容に結び付き、その判断で採用した非空の候補状況すべてで内容が成立することを要求する。本人の判断での成立と、現在実際に義務があることは別である。さらに、義務があることと、その政策が現に実施されていることも別である。

外側で義務を評価する規範源と、内側で人々への指図・許可を行う本人を区別する。政策にはちょうど一人を順序付き引数として渡し、同じ本人を政策の規範源にする。空の引数列や長さが一でない列は拒否する。別人を渡した場合にはその別人が対象となり、元の本人への要求・許可は流用しない。同じ本人を内側の規範源にするのは、閉じた`rm6`・`hzfp`の記述を渡した接続例の性質であり、型だけで任意の政策記述の内部を保証するものではない。義務についての判断だけなら、内側の実際の許可関係が未知でも記述・評価できる。

君主の制度的位置には、同じ組織内の役職順序と保持関係を使う。順序は非反射的かつ推移的であり、指定役職は範囲内の他のすべての役職より上にある。比較不能な別の頂点がある場合、「自分より上が見つからない」という理由だけで最高役職にしない。同じ役職の共同保持者、循環した上下関係、正式な委任の不在も区別する。他組織の役職保持者は同じ組織での一意性を壊さない。

この構造だけでは君主制の説明は完成しない。組織が国家であること、主権、世襲、正当な命令権、実効支配などは含まない。ここでの君主は段落冒頭の一般的な対象の構造候補であり、直前に言及した人物と自動同一化しない。

[一般文書](../examples/v014/scoped-nonprescription.noema)は3,241文字、[原文付き草案](../examples/v014/kant-scoped-nonprescription.noema)は185,741文字、[抽出文書](../examples/v014/scoped-nonprescription-core.noema)は4,015文字である。十定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-scoped-nonprescription-basis-v1.json)と[検査記録](../reports/scoped-nonprescription-v1.json)を保存する。

要求・禁止・二つの許可・実際の義務・本人の義務判断の64通りを検査した。原文付き文書と抽出文書では、最高役職の共同保持・比較不能・委任なし、空の対象者・活動、未評価、空の判断候補、別人への判断対応など九条件ずつを検査した。追加16テストでは主題・役割・規範源・本人の引数・組織の範囲と、引用内容の非実行を確認し、全て通過した。三文書のCLI解析の構文木一致と固有文字v2の往復、SVGのXML検査も通過した。SVGの目視確認は含めない。

原文中の「それを言うことを品位に反しないと考える」、寛容という名称の拒否、称賛、政府による解放、後続の職務と公的使用、自由の波及、自己発達の過程は残る。今回の義務判断の構成を、実際にそう述べた出来事や、段落全体の意味一致へ昇格させない。
