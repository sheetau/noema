# 未知関数と四加法定数

u0085の前半は、直前の四式で用いたφが当面は未知のvの関数であると説明する。ここでは、現在の導出段階で値の異なる候補関数が残るという読みを採る。ある一速度で候補が一致しても、他の許容速度で違えば関数は未決定である。先の係数aの候補族を同じβで正規化し、現在のφ=aβへ結ぶ。後続のφ=1は加えない。

後半は、運動系の初期位置とτの零点について仮定を採らなければ、四式の各右辺へ加法定数が必要になるという条件文である。仮定の非採用を物理的な零点の不一致に替えず、他の物理条件・単位・V,v,φは保つという既存の意味規約を用いる。

四定数の順はτ,ξ,η,ζであり、値は互いに独立で零も許す。一つの設定では同じ四定数を全記録対へ使うため、存在量化を全記録対の量化の外に置く。各右辺は先の正規化後の四式に対応する定数を加えた値である。記録ごとに定数を変えると、原文の定数ではなくなってしまう。

対応には既存のei26/ei27/ei3aを使う。これらは現在の測定定義eiyxへ指定設定を渡し、同じ出来事の両系の座標と全記録範囲を保持する。元の零原点設定へ固定せず、同じ値を持つ別記録も許す。四式を満たすことと全範囲の対応を双方向に結び、余分な解と対応の欠落を区別する。

二文を同じ著者・第三節・論説へ帰属し、βの定義からの順序を保つ。「加えるべき」は数学的な一般形の帰結として記述し、読者への命令や実際の加算行為にしない。候補関数と仮定の扱いは明示した読みであり、有限検査から史実上の心理や物理的導出の正しさを証明するものではない。
