# 同じ電磁過程への第三節の変換の適用

u0156–u0160を、原刊907–908頁の導入、改頁をまたぐ六式、wobeiとβの指定まで続く一文として読む。既存の場の混合s6i/s6j、逆写像との合成s6k/s6l、領域の逆像s6m、六式s6nを再利用し、現在の仮定ejs6と第三節の最終変換ejehへ接続する。

必要な関係は、現在の二場が記述する同じ電磁過程、そこに属する全出来事、各出来事の両系の座標記録、同じ速度vの二系、表示関数の引数への同じ逆写像、先行節で展開・導入した内容への参照、式を得るという著者の提示、βの補足である。場で過程を記述する一般関係と出来事の所属を新たに明示し、電磁過程の分類は既存eig3、記録と局所時計はeiyx、系の運動はeivz、式の書換え提示はzd3を再利用する。

対象の過程群は現在の二場znl/znmと領域znkで記述するものとして指定する。出来事を変換式の成功例だけへ限定せず、全所属出来事に両系の記録があり、全ての同じ出来事の記録対で対応が成り立つことを要求する。現在の比較設定zb6で第三節の測定・時計規約を使い、前の仮定内容ejs6もその同じ設定に適用する。これは著者が行う仮定下の記述であり、現実の実験の実施や全実数四組に対する測定記録の実在を追加しない。

同じ出来事の旧座標と新座標には係数1のssnを使う。旧座標は新座標へ速度−vのs46を適用した値と四成分で一致し、領域は同じ逆写像によるs6mへ結ぶ。これにより、旧場の成分を新座標の関数として読むときの引数が別の出来事や未変換の数値へ替わらない。三成分の混合と引数の変換は別操作として保持する。

変換後の式で使う混合成分は、ここでは旧場の式を新変数で書いた量である。u0161以降で導入する移動系の物理的な場や、その電気的・磁気的質量への力による定義を先取りしない。原刊の六式は四式が907頁、残る二式が908頁にあり、最後に同じ正のβ=1/√(1−(v/V)²)を指定して文を閉じる。

原文は変換によりこの六式を得ると述べる。一方、既存の反例E=(x,0,0),H=0は、表示された六回転式だけでは変換後の六式が一般には導けないことを示す。この反例を保持し、真空の語から発散条件や全微分の条件を黙って足さない。著者への導出提示の帰属と、処理系による健全性の証明を分ける。

検査では同じ過程・出来事・両記録の全引数と全範囲、四つの逆写像の成分、場の混合と領域、原文の六式の符号・偏微分順、引用とβ補足を確認する。全軌跡や全実関数を有限標本で代用せず、下位の既存証拠は内容ハッシュで保持する。旧文153の部分的な導出提示を置き換え、旧定義・旧版・旧証拠は残す。
