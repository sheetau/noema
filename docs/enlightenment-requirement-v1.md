# 啓蒙の要件と自由の特定

カント第五段落u0012第一文[0,214)、183非空白文字を、[原刊484頁](../artifacts/public-reversal-reading-v1/page-484.jpg)と固定転写に照らして通読した。採用した読みの下で、一文全体をNoemaの主張63へ接続する。原文は[アカデミー版36頁](https://korpora.org/Kant/aa08/036.html)、公的使用の後続定義は[37頁](https://korpora.org/Kant/aa08/037.html)でも確認した。

「この啓蒙」は前段落と同じ公衆の自立的な理性使用への能力変化を指す。期間・起点・公衆内部の作用・広がりを持つ既存`r2ln`を、照応先と当文の目標へそのまま用いる。先行する「ゆっくりとしか到達できない」という叙述と、要件は自由だけという提示の対比を`aber`の読みとした。遅さや革命の限界を否定する読みではない。

`nichts erfordert als`は、背景を固定した下で啓蒙を進めるために供給を求める要件の内容が自由だけだと読む。`r2sp`は焦点内容を求める要件の存在と、全要件の内容が焦点に一致することを要求する。自由以外の種類も含めて全要件を調べる。空の要件集合や、一つだけ自由を含むが他にも要件がある集合は成立しない。同じ内容の別名の項目は許す。

この要件関係は、既存の背景や人が思考する過程まで不要とするものではない。また、自由が現在あること、全可能世界での論理的必要性、自由があれば必ず即座に成功するという十分性を表さない。前段落の留保と遅さを保つ。既存の「足りる条件として提示する」関係だけでは当文の要件の肯定と他要件の排除を表せないため、一般的な要件関係を加え、その量化と限定は合成した。

要件の内容は`r2sl`へ固定する。これは全事柄についての理性の公的使用の活動記述と許可維持を結ぶ内容族である。害の最小比較`r2sn`も同じ内容族を指す。`und zwar`と`nämlich`は、自由を挙げる句、最も無害な種類とする句、公的使用によって特定する句の間で、同じ内容の参照と説明の向きを保持する。既存の説明関係`ibbclarifies`を再利用し、語ごとの専用関係は追加しなかった。

| 要件 | 記述と確認 |
| --- | --- |
| 同じ啓蒙への照応 | `r2sv`で前後の表現が同じ`r2ln`を指し、参照の順序を保持 |
| 自由の要件の存在と他要件の排除 | `r2sp/r2sq/r2sr`。空集合、他内容の追加、目標・対象・基準のすり替えを拒否 |
| 同じ自由の最小性 | 既存`r2sn/r2so`と`r2sl`を変更せず接続。同順位を許し、害ゼロを補わない |
| 対比・特定化・著者帰属 | `r2st/r2su/r2sw`。参照一致だけで説明関係を代用せず、帰属から世界内容を実行しない |
| 全文との整合 | 以前の63主張・14区間の意味判断を保持し、新主張を一つ追加 |

句ごとの全範囲対応と解釈は[通読記録](../data/enlightenment-requirement-reading-v1.json)に保存する。有限検査では要件と最小性の双方が必要なことを確認し、最小性の内部は前回の実評価を根拠として境界を明記する。著者帰属の検査では、要件・許可・害・達成に関する世界入力を未知のままにする。

これは明示した解釈に基づくアシスタントの意味判断であり、自動同義性証明や独立査読ではない。第五段落全体の判断は未完で、第一文183文字を既存の14区間へ重複加算しない。次は[215,5190)の禁止の声、問い、公私の使用の定義と例へ進む。
