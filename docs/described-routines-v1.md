# 定型表現の具体化と、その適用の吟味

同じ表現の型へ引数を入れること、その表現を実際に使うこと、その使い方を本人が吟味することを分けた。カントの定型句と機械的な道具についての部分草案へ接続したが、道具や足枷の比喩全体を記述し終えたものではない。

対象の句は[電子本文の AA VIII 36、8–10行](https://korpora.org/kant/aa08/036.html)で確認した。固定本文と電子本文の比較であり、原刊画像を照合した記録ではない。定型表現の適用をその都度吟味しない、という明示的な読みを置く。これを原文の唯一の解釈とはしない。

## 評価せずに、型と引数から式を組み立てる

既存の引用と関数適用だけで、例えば次の三つを区別して書ける。

| 記述 | Noema |
| --- | --- |
| 個体一つから内容を作る型 | `r[p aa]` |
| その位置へ入れる個体の式 | `r[k ab[]]` |
| 同じ型を同じ引数へ適用した式 | `r[c[p aa][k ab[]]]` |

`aa` は `h[a] e` 型の関数、`ab` は個体を返す式である。引用したままの構造比較では、どちらも実行しない。具体化された内容が真か、その使い方が正しいかも、この一致だけからは決まらない。

実装の `apply_description(document, template, arguments)` は、型と引数の引用からこの適用式の引用を構成する。`is_description_instance` は、候補の引用が同じ構成になっているかを検査する。既存の型検査と正規化を使い、新しい文法や生成モデルは追加していない。任意の型付き引数数を扱えるが、以下の原文接続例は個体一つから内容を作る型に限定している。

閉じた型付きの引用だけを受け取り、自由変数、型違い、引数数の違い、未知の名前、不正なフィールド、引用内評価の制限に抵触する式を拒否する。入力と構成する式の大きさにも上限を設ける。本文や意味解釈を実行することはない。

束縛変数名は正規化するが、別名展開やベータ簡約は行わない。同じ値になる別の型や引数を使った式は、別の記述である。直接呼出しと関数参照を介した適用も、ここでは構文の異なる記述として保持する。この関係を、意味上の同義性の判定と混同しない。

## 使用と吟味の結合

構造関係 `rbo` は、同じ文書における上記の具体化の一致を表す。名前だけで語義を済ませず、`is_description_instance` で判定できる構文上の関係として意味規約を与えた。

| 定義 | 内容 |
| --- | --- |
| `rbp` | 表現が保持する同じ型と引数から、同じ具体化された記述が得られる |
| `rbq` | 本人が同じ表現を同じ活動で使い、その具体化された記述を活動に採る |
| `rbr` | `rbq` に加え、本人がその表現のその活動への適用を吟味する判断が、その文脈にはない |
| `rbs` | 再利用できる固定した一項の型を保持する表現である |

表現を所有・参照できるだけでは使用にならず、内容が真であるだけでも採用にはならない。別の人が吟味したこと、別の表現や別の活動について考えたことも、同じ使用への本人の吟味として数えない。

吟味の不存在は、事実を確定した解釈の条件である。記録を見つけられないだけで判断の不存在を結論することはできない。また、この文脈に吟味がないことから、本人が判断できない、常に何も考えない、その使用は誤用である、といった結論は導かない。

カント側では `h22` が定型表現の部分的な分類、`h23` が使用、`h24` が同じ使用の吟味の不在を表す。`h25` は、自然に備わる能力を使う行為と、この定型表現を使う活動を同じ行為へ結ぶ。既存の合理的使用・誤用の評価を置き換えていない。

`rbs` と `h22` は式記述全体へ存在量化する。少数の保存済みの型だけでその全領域を代用することはできず、有限検査器はこの評価を拒否する。具体的に型を与えた `rbp`〜`rbr`、`h23`〜`h25` の検査とは区別する。

## 検証と残る作業

型・引数・具体化の一致と四つの取り違えを、内容を実行せず検査した。表現の保持・使用・採用・吟味・能力の帰属・能力使用を変えた64例と、人物・表現・行為・文脈の27の誤った接続も検査した。補助APIでは型、任意の引数数、同名の束縛変数、別名、引用制限、不正入力と上限を検査する。

関連53テストが通過した。既存の0.13の引用制限を維持し、検証記録の再生成一致、通常・短縮記法と固有文字の往復、CLIのJSONと構文木の一致、SVGのXML形式を確認した。字形の目視確認は今回行っていない。

原文接続文書は基本関係188・定義272・主張10件となった。既存の全宣言と主張を保持し、基本関係5・定義8件を追加した。うち構造関係 `rbo` は上記の構文検査で意味を固定する。残る四つは型の保持・使用・採用・吟味を結ぶ意味規約であり、その一般的な基礎説明は未完である。

正規形41,392文字、増分1,310文字であり、累積した定義を含む。定型句の全語義、規定と定型句の列挙、これらという指示、道具としての一般化、足枷と持続の比喩は残る。新しい本文の主張は追加しておらず、本文全体の意味一致を確認したものではない。
