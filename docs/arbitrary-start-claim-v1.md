# 任意の出発点の選択と全空間の微分条件

u0058は、原点の代わりに任意の他の地点を光の出発点として選べたことに注意を促し、そのため直前の式が全てのx′,y,zで成り立つと述べる。原刊899頁の前後の式と照合し、選択可能性と帰結を同じ一文として扱う。

## 同じ地点の可能な試行

ei3mは元と候補の状況で同じ地点、補助座標x′,y,z、K出発時刻を共有する。候補の試行では、前段で一般化したei3kにより現在の測定、全時計指示、全光軌道、両K光区間の光速度原理と局所時刻を要求する。元の地点に時計が既に設置されていることまでは追加しない。

ei3nは、その地点について議論主体が選べる試行と可能な結果の存在をskjで表す。各地点で別の試行や結果設定を選んでよく、一つの試行が全地点から同時に出るとはしない。実際に全試行が行われたこと、選択した試行の全結果が成功することも意味させない。

ei3oは全ての有効な実数値x′,y,zについてこの選択可能性を要求する。先行する原点の例と任意の他の点を合わせた範囲である。有限の記録地点だけを量化する形にはしない。時刻は同じ出発時刻をパラメータとして保持する。

## 各地点で同じ式を読む

空間の原点を移すskiは、τ(x′+dx,y+dy,z+dz,t)を作る。時刻、τ値、尺度は変えない。sklは、この移した原点での正近傍全体の中点条件と、元の同じτの指定点での全微分可能性・二偏微分を結ぶ。正側極限と十分な局所正則性を明示した前段の読みを引き継ぐ。

結論には既存skvを使う。そのsknは全空間値を量化し、skmは各点で同じτの二偏微分値を存在量化して、整理後の式τx′+v/(V²-v²)τt=0を要求する。原点の二候補値zd6とzd7を全地点へ定数として配らない。新たに全時刻の量化やy,z偏微分の零、具体的なτ解を加えない。

## 提示と確認範囲

注意喚起zeiと内容の主張uhにより、選択可能性を著者へ帰属する。deshalbはその同じ内容を理由とする全空間の式への帰結zcとして表す。二つの著者主張は同じ第三節・論説に属し、直前の整理後の式からの本文順序を保持する。

固定原文と原刊の通読、引数と作用範囲の対照検査、保存した空間移動・微分・代数の証拠を区別する。全実数の量化は有限評価を拒否し、可能な試行が現実に全地点で実現することや全域の物理的導出を、この検査が証明したとはしない。新規原始語はない。
