# 自分の活動による達成と、過去の成功者の数え方

カントの段落末に、本人の精神への働きかけによって依存状態から自立へ移った人を記述する部分草案を追加した。現在の状態だけを成功とせず、同じ人・過程・前後の状態・結果生成を結ぶ。少数者の数量候補にも接続したが、後続の確かな歩みはまだ含めていない。

## 活動と達成を同じ過程へ結ぶ

一般構成 `rcp` は、既存の時間順序と変化過程に次の条件を重ねる。

- 同じ履歴の前後を結ぶ同じ過程が、本人に作用する。
- 前状態は成立から不成立へ、目標は不成立から成立へ変わる。
- その同じ過程が本人の関与する活動として生起し、指定された作業に当たる。
- その活動が同じ本人に、記述された目標を生じさせる。

単に後の状態が成立した場合、他人の活動、同時にあった別の作業、前後関係だけでは成立しない。結果生成関係は因果的な作用の意味規約であり、この構成から因果を発見するものではない。活動過程を変化過程と同じ個体で表す粒度を採り、全ての部分活動や内部機構はまだ展開していない。

本人の関与は要求するが、他者の援助や別の原因を排除しない。作業量、方法の合理性、本人の意図、将来の永続性も補わない。一般構成には新しい文法や基本関係を加えていない。

## 自立へ達した人の候補

原文側の到達状態 `h4l` は、既存の評価範囲の整合性 `fo` と、自分の理解力を他者の指導なしに使える達成方法の存在 `up` を結ぶ。依存状態 `bf` の単なる否定ではなく、肯定的な達成方法を要求する。この読みは既存の能力評価の操作的な意味に依存し、原文の自立の全語義を確定するものではない。

自分の精神への働きかけ `h4o` には、本人の精神的な営みを構成する部分 `h4m` と、同じ本人がその部分のあり方を吟味し組み直す活動 `h4n` を置いた。任意の所有物や他人の精神への作業を混ぜない。ただし、精神の構成、自己形成の方法、努力や改善の程度はまだ基礎説明を要する。二つの基本関係を追加したことだけで、それらを説明し終えたとは扱わない。

`h4p` は、本人の実際の履歴について `rcp` を使い、基準時までの依存状態から到達状態への変化を記述する。`h4q` はそのような過程を持つ人の候補である。未来の成功は既に達した成功に数えない。一方、過去に成功した後で能力を失っても、その達成経験そのものは消えない。

## 評価が欠けた人を不成功と数えない

成功条件を単純な真偽として数量へ渡すだけでは、能力評価が欠けた対象者を不成功と扱い、人数を少なく見積もるおそれがある。そこで、数える前提を `h4t` と `h4u` に分けた。

`h4t` は、本人の正当な履歴の基準時までの全状況で、利用可能な方法の評価範囲が整合することを要求する。`h4u` は対象範囲の全員について、有効な成功例 `h4q` があるか、`h4t` が成立することを要求する。肯定には有効な一例で足りるため、その後の評価不足で既知の達成を取り消さない。成功例がない人の評価不足は、人数の確定を妨げる。

この検査は、宣言された履歴と方法に対する整合性の確認である。現実の全履歴・全方法・活動・因果関係の知識が完全であることを証明するものではなく、未観測を偽にする規則でもない。未来の評価までは、過去の達成者を数える前提にしない。

数量候補 `h4r` と `h4s` はこの前提の下で、[対象の全列挙と人数の上限](scoped-counts-v1.md)に `h4q` を接続する。前者はゼロ人を許し、後者は少なくとも一人を要求する。ただし、原文が数える人には確かな歩みという後続条件もある。今回の候補はまだそれを含まないため、新しいカントの主張としては帰属させていない。

## 検証と対応範囲

前後の二状態と活動・因果条件の1,024組を検査し、同時成立だけで達成と認定しないことを確認した。人・過程・時点・結果記述の取り違え、不正な履歴など21例も拒否した。

原文接続の20例では、過去の成功と後の能力低下、未来の成功、以前から自立していた人、他人の精神への作業、別の活動、原因の欠落、指導に依存する結果、能力評価の欠落を区別した。本人に成功例があっても、他の対象者の過去の評価が欠ける場合は、少数者の人数を確定しない。基準時より後の評価不足や、既知の成功の後の評価不足による過剰な拒否も避けた。関連32テストが通過した。

保存した検証記録の再生成一致、通常・短縮記法と固有文字の往復、2文書のCLIによるJSONと構文木の一致、SVGのXML形式も確認した。字形の目視検査は今回行っていない。

対応箇所は[電子本文 AA VIII 36、13〜15行](https://korpora.org/kant/aa08/036.html)の、達成と自己への働きかけによる離脱の部分である。固定資料では空白を除く90文字を新たに対応させた。後続の譲歩と確かな歩み、段落末の推論、精神・自立・原因の基礎説明、原文との完全な意味一致は残る。原刊画像の新たな照合は行っていない。
