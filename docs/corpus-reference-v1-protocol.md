# 公開文章での参照解析の基準測定

手作りの短文だけで評価する状態を改めるため、KWDLCの公式`split_for_pas`を取り込む。取得元は https://github.com/ku-nlp/KWDLC 、固定リビジョンは`c6ae49d29eca4e1134c6676d682adf5ed6a25f5a`とする。本文・注釈はローカルの`artifacts`に置き、リポジトリには取得情報、文書ID、ハッシュと集計結果を保存する。配布元の利用上の注意を保持する。

今回は公式devの全512文書を、モデル・閾値・コードの選択を行わず、既存の固定KWJAで原文から解析する。trainとtestは取り込み整合性の検査だけに使い、testの予測評価は行わない。KWJA自身がKWDLCを利用しているため、devは独立した未知資料とは呼ばない。追加学習の前に、実際の文章でどこが失われるかを測る基準である。

入力は注釈済み文書の形態素表層を順に連結した原文とする。モデルへ正解の語境界、文境界、依存先、照応先を渡さない。辞書による形態素補完と生成処理は禁止する。既存の文字数・トークン数制限を超えた文書を切り詰めず、失敗として文書IDと理由を報告する。その他の予期しない実装エラーで処理が止まった場合は、黙って評価対象から除かない。

正解と予測を原文中の主辞範囲で比較する。正解は明示的な文書内の同一参照タグ`=`・`=構`・`=役`を統合する。`≒`付きと外界への参照は同一参照の正解に混ぜず、種類別件数を記録する。内部の明示リンクだけを評価するため、外界参照を介した同一性も推定しない。公式評価ツールの総合スコアとは異なる。

予測前の注釈監査で、同一参照にもAND・OR・曖昧のモードがあると分かった。複数対象を一つの同一性グループへ無条件に畳み込まないため、これらのモード付き同一参照を持つ文書は全体の未対応件数に残すが、ペア精度の対象から外す。その数と除外理由を必ず報告する。対象モードを黙って消して別の対象とすることや、未対応文書を完全一致に数えることはしない。これは現在の参照グループ表現の制約であり、完成に向けて解消が必要である。

予測は既存モデルの文書内`=`から推移的なグループを作る。語句の一致による統合と、正解を用いた境界・照応修正をしない。全基本句の主辞を位置で比較し、境界一致数と欠落・過剰を測る。同一参照ペアの適合率・再現率、全参照ペアの一致文書数、主辞集合も含めた完全一致文書数を分ける。参照ペアがない文書だけで結果が良く見えないよう、正解ペアの有無別に集計する。解析不能文書も全devの分母と正解ペア数に残す。

同じ原文の反復解析はID順の先頭8文書で行う。保存した出力から全評価を再計算する。参照グループの作成、原文位置の保存、分割の重複検査、取得リビジョン・ファイルのハッシュ検証をテストする。全文意味構造の一致やNoemaへの翻訳率とは区別し、ここでの結果を理由に完成目標を縮小しない。
