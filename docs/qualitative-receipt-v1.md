# 同じ性向記述の取得と持続

受け手が取得する性向にも、前段の数値を使わない応答条件を適用した。理由ある自己評価と、全ての人が自分で考えることを課題として認める判断を、同じ人・同じ仮定場面で要求する。発信者の独立判断への性向とは別の内容であり、通常性の比較も別々に指定できる。

`hzq6` は、本人と評価時点に候補範囲・通常性比較を固定し、候補場面での応答を既存 `rqt4` へ渡す性質関数である。`hzq7` は、応答と二つの条件の閉じた記述から、その性質の記述を構成する。`hzr2` は応答として既存 `hznv` の自己評価・規範承認を使う。

取得の検査には、この同じ記述を既存 `rqte` へ渡す。本人が以前はその状態になく、後にその状態になり、同じ伝達行為が同じ人のその状態を生じさせる条件を保つ。別の評価基準や通常性比較を含む性質を原因の目標に指定した場合は、記述が一致しない。

理解を伴う経路の検査 `hzoa` と、取得後の持続も求める `hzob` は変更していない。同じ記述から状態を評価し、その記述を原因にも使う。受領や理解だけを取得とはせず、最後の伝達行為を別の行為や別人の変化に置き換えない。

持続を検査する際も、取得した性向の記述を使う。取得完了後に失い、基準時点までに回復した例は、取得だけなら成立しても持続としては不成立になる。候補の範囲は評価時点ごとに異なり得るが、その対応関数と通常性比較を含む記述全体を途中で交換しない。

五項目のテストで、次を確認した。

- 応答と通常性の八組合せ、本人・評価時点の取り違え、未知入力。
- 既存の自己評価と規範承認を実行する六対照。別々の場面での二条件の成功を合算しない。
- 受領・理解・取得・原因・状態記述・作用先・持続に関する12対照と、途中の喪失・回復。別の通常性基準を含む型の正しい性向記述への因果が成立しても、求める性向の取得にはならないことも同時評価する。
- 必要な五入力が未知の場合の保留。加重プロフィールの入力は未知のまま使わない。
- 発信者と受け手で別の通常性条件を使い、条件付き伝播と期待背景を同じ本文箇所・著者へ帰属する接続。

有限の解釈では、試験用に指定した初期状態と後の状態へ、それぞれの仮定場面を対応させる。これは応答結果から都合よい候補を選ぶ実装規則ではない。全ての検査は通常評価で行い、実際の判断・伝達・因果・持続の定義を実行する。無制限の中継列を含む集団命題全体の真理を検証したとはしない。
