# 条件の不充足と、公衆による判断を目的とする発言（2026-10-14）

カントの軍人の例にある「軍務の欠陥について注記し、公衆の判断に示す」を具体化する部分草案を追加した。欠陥の一つの読みを、指定した達成条件の不充足として構成する。その不足を述べる発話、発話を公衆に判断してもらう目的、実際の判断を分けた。

一般定義は[criterion-failures.noema](../examples/v014/criterion-failures.noema)、カントへの接続は[kant-public-assessment.noema](../examples/v014/kant-public-assessment.noema)に保存した。後者は252基本関係・505定義・15本文主張からなり、前版の宣言と本文主張を保持している。正規形は81,515文字で、追加は669文字である。定義ライブラリを含むファイルの長さであり、原文との翻訳文字数比ではない。

## 「欠陥」を組み立てる条件

`ret`は、対象と、対象から命題内容を返す関数の列を受け取る。その列に含まれる条件のうち、指定状況で不成立となるものがあれば、不足があるとする。たとえば、手続きに求める条件を二つのNoema定義として与え、その一方だけを満たしていない場合を表せる。具体的な条件は定義で展開するため、軍務専用の単語表を必要としない。

空列からは不足を導かない。条件の順序を入れ替えたり、同じ条件を重複させたりしても不足の有無は変わらない。ただし、別の条件を追加すれば結果が変わり得る。条件列が適切か、必要な条件を尽くしているか、未達を非難すべきかは、この定義だけでは決まらない。

`reu`はその不足を述べる主張の発話、`rev`は不足があるかを尋ねる質問の発話を返す。同じ内容を対象にしても、主張と質問を同じ発話にしない。主張の発話を記述できることは、その内容が真であることを意味しない。

条件の評価が未知なら、充足にも不充足にも補わない。現在の有限解釈器は列の全要素を評価するため、既に一つの不足を発見した場合でも、別の条件が未知なら評価を拒否する。

## 提示の目的と、実際の判断

| 記号 | 保持する意味 |
| --- | --- |
| `hzu` | 本人が同じ活動の計画・遂行で目指す、記述された目的内容 |
| `hzv` | 同じ判断が、指定対象についての指定発話の内容を検討・評価すること |
| `hzw` | 本人による実際の判断`fa`を、対象`fb`と発話記述`hzv`へ結ぶ |
| `hzx` | 指定受け手群の少なくとも一人が、同じ発話について判断するという内容 |
| `hzy` | 既存の公的活動の分類`h6v`と、その活動で指定目的を目指すことを結ぶ |

目的と判断対象については、二つの基本関係`hzu`と`hzv`を追加した。特定の職業や原語に対応する基本語ではなく、他分野の活動や発話にも適用する意味規約である。ただし、意図の形成や判断行為の認知過程まで既存関係から分解し終えたわけではない。

作例では、`reu`に具体的な条件列を渡した閉じた発話記述を作る。その同じ記述・対象・受け手群を`hzx`へ渡した目的の引用を、公的活動の`hzy`に対応させる。発話と目的の式は[検査記録](../reports/public-assessment-v1.json)にも保存した。通常のNoema引用と型付き関数適用であり、人が直接記述できる。補助コードによる意味の補完ではない。

一般関数`hzy`は任意の目的を受け取れる。任意の引用を渡すだけで公衆による判断の目的になるわけではなく、上記の引数対応を記述者が明示する。また、`hzx`は各状況における同じ集団の成員を対象にし、成員が全状況で固定されるとは仮定していない。

発言の予定と目的だけでは、発言の実行・受領・理解・判断・賛同・真理を要求しない。目的が達成されなくても意図は記述できる。実際に判断された場合にも、その判断が発言に同意したことや、正しい結論に達したことは含まれない。
