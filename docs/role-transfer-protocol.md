# 語彙クラスに依存しない役割ヘッド

日本語の格と意味役割を区別するため、固定KWJAの文脈表現からNoemaの主体・対象・受け手・場所を分類する共通ヘッドを学習する。語ごとの出力クラス、対訳表、受動形に応じた役割交換の規則は用いない。生成・辞書補完を使わない前回の経路を維持する。

[注釈56文](../data/role-transfer-v1.json)は、学習16述語群32文、開発4群8文、評価8群16文に分ける。同じ動詞の能動・受動を別の分割に置かない。追加の既存24文は、これまで結果を見た回帰診断とする。人工的な短文の少量データであり、広い自然文の独立評価とはしない。

分類対象は、KWJAが予測した述語・名詞述語から文中の基本句へのPAS関係である。文外の「著者」等の推測は、人物として採用せず別の証拠として残す。正解位置を候補抽出に渡さない。学習・採点時だけ、予測した主辞が注釈の範囲と重なるかで照合する。見つからない正解項も報告し、分類対象から消えた分を成功として数えない。

学習前に、3つの学習文に時間の付加部を加えた。今回の4役割以外の関係を `none` として学ぶためであり、時間の意味そのものを不要とする変更ではない。未注釈の別述語に対する候補は教師なしとして除外し、`none` にしない。

特徴量は、述語主辞・項主辞・述語句の固定ベクトル、述語と項の積・差、および予測された元の格ラベルとする。各ベクトルは正規化する。原文の単語や述語群IDを出力クラスや検索キーにしない。5分類（none、agent、patient、recipient、location）の線形層と、64次元の浅いtanh層を比較する。追加の概念クラスは作らない。

学習はseed17、AdamW、学習率0.003、重み減衰0.01、全件バッチ、200エポックまで。開発の平均交差エントロピーが最小のエポックを各方式で保存する。方式の採用は開発損失で選び、選択を保存してから評価分割を開く。評価結果に合わせて語、注釈、閾値、エポックを変えない。

役割分類の正解率と、検出漏れ込みの指定項の役割正解数を分けて測る。能動・受動別、役割別、同じ述語群の両文で指定役割が全部そろう数も示す。部分注釈であるため、余分な出力を含めた全文意味構造一致率とはしない。95%以上という完成条件と広い対応範囲は維持し、この試験だけで画面の翻訳器を置き換えない。
