# 公衆の範囲を固定し、比較を著者の主張へ接続する

第四段落第一文の中核内容を、閉じたNoemaの著者主張として本文へ追加した。前版で引数として残した公衆・比較個人・期間・候補・尺度・広がりを、文脈上の入力と先行段落への照応から供給する。既存の55文を保持し、56文目に新しい帰属を加える。第一文全体の意味確認はまだ行っていない。

## 公的な議論の宛先としての公衆

`ein Publikum` は、ある時代の読者世界の中で公的な議論の宛先となる集団として読む。[原文の比較](https://korpora.org/Kant/aa08/036.html)と、後続する[読者世界・公的使用の説明](https://korpora.org/Kant/aa08/037.html)に基づく採用解釈である。

`r2la` は、同じ参照文脈の宛先の想定読者が二人以上の人であり、読者世界全体の範囲に含まれることを要求する。さらに、自分の理性による見解を公衆の検討へ示す立場での同じ活動記述が、その宛先と読者世界へ向けられていることを要求する。私的な職務の命令先でしかない集まりを、この条件だけで公衆とはしない。

これは実際の発言や読書の成立条件ではない。公衆は自由を制限されていても、議論の予定された宛先であり得る。現実の許可・受領・理解を分類に要求すると、自由を仮定する原文の条件を先取りしてしまう。集団は読者世界の一部分でも全体でもよく、全体との同一性は要求しない。

この構成は、宛先・学識者の立場・読者世界という既存の公開された基本概念を組み合わせる。社会制度や公衆の全用法を、人数と集合包含だけから一般的に定義したという主張ではない。

## 広がりの基準と、比較する個人

公衆の自己啓蒙は、その内部の人の働きかけによって自立的な理解力の使用が広がる変化として読む。既存 `hzmy` の本人・履歴・内部参加・因果は変更しない。第二文の自己評価や態度の伝播の全機構を、第一文の必須条件として重ねない。

`r2lb` は、想定読者全体を重複なく列挙した有限列から、変化した人の正確な比率を計算する。結果の比率が、あらかじめ固定した文脈上の最低比率を超えれば、広がりの条件を満たす。閾値は0と1の間にあり、過半数や特定の百分率を原文に補わない。基準と等しい場合は今回の厳密な読みでは不成立とする。

`r2lc` はこの基準と全読者列を、同じ公衆と参照文脈から供給する。成功者だけの標本、外部の成功者、候補ごとに変わる母集団は受理しない。すでに自立して他者を助ける内部の人まで、再び能力を獲得する必要はない。例えば二人のうち一人が新たに自立する変化でも、明示した基準次第で集団の変化として記述できる。

比較個人は、第三段落冒頭の `hzzq`・`wh` に固定された対象範囲 `hzzn` の各人とする。話題上の各公衆と、この範囲の各人を比較する文脈的な全称の読みを採る。任意に選んだ一人の実例や、例外を許す確率的な総称とは区別する。どちらの範囲も非空を要求し、不適格な対象を黙って除かない。

## 固定した入力と閉じた帰属

`r2ld` は、比較と条件付きのほぼ必然を表す `r2kw` の十五引数をすべて供給する。同じ公衆では、比較する人を替えても期間・候補・公衆の目標・広がり・尺度を保つ。個人とその程度だけが変わる。尺度は重複のない順序付きの列から作り、両端と近さは既存の様相定義が検査する。

新しい十二基本宣言は、対象範囲、全読者列、閾値、期間、候補、尺度などの文脈入力である。原文の一文を丸ごと判定する記号は追加していない。意味は、分類・量化・比率・自己形成・能力変化・因果・許可・様相の定義から合成する。入力が未知なら、検査を成功させるために補わない。

`r2le` が全対象への主張、`r2lf` が閉じた内容、`r2lg` が著者への帰属である。第四段落第一文の箇所 `hzp4` と提示文脈 `hzp3` に結び、第三段落末からの本文順序も示す。引用時に世界の内容は実行せず、カントの主張が現実に正しいことは認定しない。

## 検査と残件

検査は、公衆分類、母集団・変化・閾値の320組合せ、比較枠の十五引数、全称の範囲と比較結果の256組合せ、閉じた帰属、既存の十三単位の判断を対象とする。比率と公衆の新定義は実行する。接続の検査では、前版の様相本体を明示的な境界とし、その検査報告と依存定義が変わらないことを確認する。全定義を同時に実行して現実の公衆を網羅したという結果ではない。

`aber` の対比、`ja` の強め方、`nur` の作用範囲を接続し、自由の規範的な読みを後続段落と照合する作業が残る。その後に第一文全体を再読する。今回の中核主張の追加や検査成功を、一文全体の完成へ自動変換しない。
