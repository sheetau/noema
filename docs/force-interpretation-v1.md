# 六式の解釈と二つの言い表し

u0173の六文を一つの段落として読む。既に接続した第二文から第五文は、点状の単位電気量と作用による校正、相対性原理による移動系の値1、Kへの静止とkへの瞬間静止の下での場と力の同定である。今回の要件は、第一文を直前の六式の解釈導入へ結び、第六文を同じ電気側三式と先の同定から二つの言い表しへの帰結として構成すること、六文全体の参照と提示を再読することである。

第一文のdieser Gleichungenは直前の最終六式M0314を指す。著者がその解釈のために以下の注記を述べるという働きを、同じ表示・導入箇所・各注記の説明関係と本文順序で保持する。wirは著者による論述の声として読み、読者全員の同意や共同実験を補わない。

原刊は六式を左右二列に置いている。第六文の「最初の三式」は左のX′,Y′,Z′の三式であり、上から三行の六式全体ではない。同じ物理的な両場・出来事の対応・領域の下で、現在の電気側znrと、逆座標変換を合成した電気側の混合s6kの三成分の一致を、全領域に要求する。磁気側の変換式をこの三式に混ぜない。

二つの言い表しが可能だという内容は、同じ単位電気量、同じ系で測る力と場、静止条件の解釈を共有する。言葉を着せるという表現は、数式の量と条件を言語的な物理の役割へ展開する働きとして読む。mithinはこの解釈と三式に基づく著者の帰結へ結ぶ。続く二項zpq/zprを第一・第二として指定し、別の二例への交換を防ぐ。可能な表現がこの二つだけだという排他性や、後続二項の厳密な同義性の自動証明は加えない。

段落全体では、仮定、校正の説明、原理に基づく推論、定義への参照、二つの条件文、後続への導入を区別する。点状電気量を慣性質量や座標点へ替えず、校正で相手に及ぼす力と、その電気量自身に働く力を分ける。単位値1を力の評価出来事でも保持する読みを明示し、校正出来事との同一性や一般の保存則を補わない。瞬間静止は加速度非零も許す。仮定の試験応答を測定済み又は真空内の試験体の実在へ変えない。

旧358主張を保ち、二つの導入を追加する。保存上の文番号と本文順序は別にし、六文を358,163,164,165,166,359の順で結ぶ。原刊909頁、固定本文、M0315–M0317と各定義を照合して、全単位の判断を別記録に残す。後続u0174–u0175の近似や旧来・新しい言い方の対比は次の単位で確認する。
