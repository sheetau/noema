# 軸自身の座標で正方向を校正する

前版では、方向記録を同じ時点の二点の座標差へ結んだ。ただし、その二点の順序が軸の正方向に沿うことは、記録の帰属に与えた意味規約に残っていた。今回、同じ二点の順序を、その軸を持つ系の座標増加へ結んだ。

新しい原始記号はない。既存の記録項目、位置座標、軸割当てを使い、六つの合成定義を加えた。物理的な計器の校正方法や全空間の幾何学を完成させたものではない。

## 正方向の条件

`sexo`は有理数の始値より終値が大きいことを、`sexp`は同じ条件を有効な実切断について表す。値そのものが正である必要はない。−3から−1への増加は正方向であり、3から1への減少は逆方向である。等しい値では方向の順序を定めない。

`sexq`は、三つの異なる座標役割のうち指定した軸の成分が増加し、始点・終点の他二成分がともに零であることを要求する。他二成分が等しいだけなら、軸から離れた平行な線も含まれてしまうためである。指定する役割は三軸のいずれかでなければならない。

この条件は正の半軸に点を限定しない。たとえばy座標が−4から−2へ増加し、x・z座標が両端とも零である二点も認める。選んだ二点の座標上の関係を表す条件であり、軸に沿う全点の直線性は別に説明する必要がある。

## 共通観測系と所有系を分ける

`sexr`は、前版と同じ記録の始点・終点・観測時点を取り出し、その記録への結合、所有系での軸割当て、配置点としての帰属、所有系の位置座標の利用可能性を要求する。その上で`sexq`を適用する。

`sexs`は、共通観測系で元から選ばれていた全方向記録に、この所有系での条件を課す。比較に都合のよい記録だけを選び直すことはしない。`sext`は、二系・速度・物理的配置、共通観測系での方向一致と二点の座標差を保持し、両系の所有座標での正方向条件を加える。

共通観測系に位置座標があることから、所有系でも取得できるとは判断しない。逆に、所有系で同じ正方向と確認できても、両系から測った二点間の長さが一致するとは要求しない。有限の例では方向の増加条件を検査しており、任意の尺度変更が物理的な全座標変換を満たすとの主張ではない。

同じ観測時点の参照を引き継ぐことも、両系の時計の指示や同時性の一致を意味しない。今回、所有系の時計指示を計算する条件は追加していない。

[累積本文](../examples/v014/einstein-positive-axis-calibration.noema)は206文を保ち、密度式の引用内の配置引数だけを改訂した。他の205文と既存の宣言は保持した。[抽出本文](../examples/v014/positive-axis-calibration-manuscript.noema)が、実際の累積本文から当該文と全依存定義を取り出したものに一致することも検査する。[汎用定義](../examples/v014/positive-coordinate-rays.noema)は所有系や物理的な記録への参照を持たず、数値の順序と座標軸上の二点を表す。

## 検証と限界

数値12例で三軸の増加、負の座標値、逆順、未知の役割、軸からずれた線、始点・終点だけが軸を外れる場合を区別する。重複役割と無効成分も拒否する。四つの有理数の検証では、正の尺度と任意の原点変更が一成分の増加順序を保つこと、逆順が同時には増加にならないことを確認する。これは他二成分の零を含む軸配置全体の原点変更の不変性ではない。

抽出本文22例と累積本文6例で、三軸それぞれの逆向き、所有系の零増分・成分入替え・軸からのずれ、共通観測系でそろって逆を向く記録、所有系の座標の欠落、単位・状況・時点の不一致を区別する。異なる二系の原点や整合する追加記録は、そのことだけでは排除しない。元の配置、座標差、速度参照、非空の記録範囲も要求し続ける。

未知の所有系座標や利用可能性は補完せず評価を拒否する。著者への引用帰属8例では、引用内容の校正条件を実行しない。通常表記・短縮表記・固有文字の往復、CLI解析と入力ハッシュも検査する。

```powershell
python -X utf8 -m pytest tests/test_positive_axis_calibration.py -q
python -X utf8 -m scripts.check_positive_axis_calibration --verify-only
```

[意味確認記録v10](../data/density-formula-review-v10.json)では、選択した二点の正方向の座標条件を接続済みとし、物質軸全体の直線性、座標と計器の物理的校正、記録の完全性、共通原点・時計原点・慣性系、原文の適用範囲と全文の意味一致を未完として残す。原文対応範囲と意味確認済み区間数は増やさない。
