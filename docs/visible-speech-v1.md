# 発話関係を含む円文字辞書第8版

[提示・応答・発話行為の19定義](shared-speech-v1.md)を円文字へ接続した。第8版は218語で、30単独語と188複合語、21基本宣言と197構成定義からなる。第7版の199語はそのまま保持し、新しい基本字形・基本宣言を追加していない。社会的な解釈関係の意味規約はNative側で追加されており、宣言数が増えないことを意味の入力が増えないこととは扱わない。

[共有綴り](../noema/resources/visible-speech-vocabulary-v1.json)は既存語を組み合わせ、bookから始まる複合語とする。これは記憶を助ける命名規約である。部品の語義だけから依頼や約束の意味を計算する規則ではなく、型・定義・公開規約を読むための名称になる。同じ版で意味や綴りの異なる辞書は拒否する。

## 本文に関係を記述する八例

| 可視例 | 明示する条件と判定 |
| --- | --- |
| [依頼](../examples/v016/visible-speech-request-v1.noema) | 提示、宛先、対象行為、求める関係を結び、依頼が成立する |
| [依頼の実現](../examples/v016/visible-speech-request-outcome-v1.noema) | 同じ依頼でも、受け手に対する後続状況の内容は偽で、実現しない |
| [約束](../examples/v016/visible-speech-promise-v1.noema) | 話し手が行為を引き受ける関係を明示し、約束が成立する |
| [約束の実現](../examples/v016/visible-speech-promise-outcome-v1.noema) | 後続状況で話し手について内容を評価し、実現する |
| [受諾](../examples/v016/visible-speech-accepted-v1.noema) | 同じ提示・受け手・対象・発話記述への受諾を明示する |
| [辞退](../examples/v016/visible-speech-declined-v1.noema) | 辞退関係を偽とした例では、辞退が成立しない |
| [助言](../examples/v016/visible-speech-advice-v1.noema) | 理由、目的、受け手の行為への支持、理由を示した関係を結ぶ |
| [命令](../examples/v016/visible-speech-command-v1.noema) | 権限を主張する関係を偽とした例では、命令が成立しない |

社会的な関係は本文のlambdaで明示する。外部モデルが与えるのは、既存の二つの個体名Aki・Naoの解釈だけである。行為内容は「行為者がAkiなら真、Naoなら偽」という抽象的な束縛検査用の定義であり、実際の人物の行動を主張していない。各状況で同じ真偽になる内容を使うため、期限や途中経過を検証したことにもならない。

話し手と発話活動、受け手と話題の対象には、それぞれ同じ検査値を使う。この八例だけで全ての役割の取り違えを区別できるとはしない。[Native側の報告](../reports/shared-speech-v1.json)に、各枠を一つずつ変える68の束縛診断を別に保持する。

本文全体を円と線から復号してから、二個体・二状況で量化を評価する。相異なる個体や状況を要求する前件が満たされる割当を含める。引用先の行為内容を否定しても依頼・約束・受諾・助言の成立は変わらず、実現についての二つの主張は偽に変わる。約束の実現では前後関係の引数を逆にしても主張が偽になる。内容の引用と実行評価、受け手と話し手、時間の向きを分けた検査である。

## 復号と互換性

[検証報告](../reports/visible-speech-v1.json)は新19語の型付き呼出し・引用、語彙文書と八つの意味例の図形復号を記録する。型付き高階呼出しの往復は構文の検査であり、全ての関数値に対する意味証明ではない。

実現判定の二関数は段階0の行為記述を評価するため、その関数自体の引用は段階1とする。他の17関数は段階0で引用できる。引用段階を省略して実行の制約を回避せず、既存の型規則に従う。

```powershell
python -X utf8 -m scripts.visible_speech_page render examples/v016/visible-speech-promise-outcome-v1.noema output/visible-speech-library-v1/promise-copy.svg --width 4800 --public-names
python -X utf8 -m scripts.visible_speech_page decode output/visible-speech-library-v1/promise-copy.svg --native --public-names
```

可視ヘッダーで第1〜8版を区別する。旧版の局所名と新共有語の綴りが衝突しても、旧文書は旧版の意味で読む。SVGの要素順を入れ替えても図形から同じ本文を復元する。固定字体、旧描画器、旧報告、字形768・図形4096・行128などの上限を保持する。

ここで確認したのは、明示した解釈入力と本文の関係である。現実の意図・受諾・約束・権限を認定する方法、部分回答や会話での訂正・撤回、約束の期限・解除・不履行は別の課題として残る。画像OCR、人による学習と第三者読解、二作品全体の新書式化も完了していない。
