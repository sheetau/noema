# 名称の意味と、自分への適用の拒否

第八段落の君主は、宗教的自由を義務として残すと述べることを自分にふさわしくないとは考えず、続いて寛容という名称を自分から退ける。今回は、その名称を自分へ適用することへの拒否を構成した。既存の呼びかけによる拒否だけに限定せず、発言又は行動上の選択として、本人が明確な負の実践的立場を取る場合を扱う。

名称の説明には、この箇所の義務との対照に従い、宗教的自由を裁量による許容として与える側という読みを採った。r5wrは同じ自由方針の実現・非実現への積極的な許可と、両方向の要求の不在を組み合わせる。r5wsは同じ自由方針の現実の成立も要求する。その人物の性質を段階3で引用し、同じ名称・用法共同体・基準へ結ぶ。名称が保持する内容と、その人物について内容が真であることは別に評価する。

これはToleranz一般の唯一の定義ではない。[DWBの語例](https://www.dwds.de/wb/dwb/toleranz)は宗教的許容や、寛容と承認との区別を示す。この文ではPflichtとの対照を採用解釈の根拠とし、君主が実際に他人の信仰を嫌悪しているという心理までは加えない。高慢という評価の根拠も、この語例だけで確定したとはしない。

拒否の対象は、固定した非空の使用者集団の誰かが、その名称を同じ本人へ適用するという内容である。本人・名称・集団の三個体列と固定基準を保ち、本人が実行する同じ反応において、その内容を負極性の実践方針として引き受ける。実際に名前を使われていないこと、そう呼ばれる性質を欠くこと、将来誰も呼ばないことから拒否を推定しない。他者が拒否に従わず名前を使い続ける場合も記述できる。

[DWBのablehnen](https://www.dwds.de/wb/dwb/ablehnen)には、提案や栄誉を断る用法がある。今回の構成では特定の口頭発言、過去の命名、相手からの要求を前提にしない。原文のvon sichは、拒否の主体と名称の適用対象を同じ本人に固定する。selbstの強調とalsoの帰結提示は、全文の談話へ別に接続する。

検査は規範の16通り、名称の意味保持・実際の裁量・自由方針の8通り、拒否・名前使用・意味保持の8通りを分ける。引用を脱引用した実評価、同じ活動・人物・名称・対象・評価点、三個体列の位置と長さ、固定参照、未知入力を調べる。名前の意味を引用で扱う場面では、現実の許可や義務を評価しない。

高慢という評価には未解決点がある。[後年のAA6:465](https://korpora.org/Kant/aa06/465.html)では、他者を自分より低く扱うよう求め、相手への尊重を欠くことが説明される。旧草案の「裁量の資格を欠くのにその立場を取る」だけでは、この対人評価を表し切れない。後年の説明を1784年の全理論として移植せず、今回の呼称における優越の含意とその評価を次に構成する。

原文は[AA08:040](https://korpora.org/kant/aa08/040.html)と原刊491頁の関係節を参照する。本文112主張と確認済み17区間は変更していない。一般的な君主への束縛、高慢評価、強調・帰結、後半の啓蒙と称賛・解放の功績、一文全体の確認は残る。
