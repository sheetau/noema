# 全物質点対による剛性

導入第三段落u0005で必要となる「剛体」を、指定した評価系・同時性・尺度で物質点間距離が保たれる理想化として構成する。原刊892頁の二文、369非空白文字を[固定転記と照合](../data/einstein-kinematics-source-reading-v1.json)した。今回は剛性の依存群を追加し、運動学への基礎依存や理由、考慮不足と困難の説明は次の接続に残す。

既存の `eiaq` は、三つの非共線な物質点から向きの付いた参照枠を作り、その枠で全成員の位置が変わらないことを要求する。この構成は参照枠に必要な一方、棒状の物体をそのまま扱えない。一般の剛性には非共線な標識点を要求せず、全物質点対の距離不変を使う。

`eigw` は同じ二物質点の同じ時刻の三座標差から、距離の二乗を計算する。`eigx` は同じ対の二時刻について、時刻・全座標の実数としての有効性と、距離の二乗の等しさを要求する。平方根を取る必要はなく、座標値をそのまま等しくする必要もないため、並進・回転による位置の変化を許す。

`eigy` は既存の `eiad` で同じ物体の非空の全物質点・全区間履歴を要求し、区間内の全時刻対と全成員対へ `eigx` を適用する。三標識点以外の変形や、始点と終点の間だけの伸縮を除外できる構造である。線状・点状の幾何学的理想化も排除しない。単一物質点の距離条件は自明になるが、物体の同定や完全な履歴の条件は残る。

距離を物理的な量として読むため、共通の直交Cartesian基底、固定された長さ尺度、同時刻を比較する時間規約を基礎入力として明示する。時刻ごとに尺度を変えて伸縮を見えなくする座標を認めない。原文の剛体は巨視的な基準物体の理想化として扱い、微視的熱運動の消滅、全系での同時性や長さの同一視、相対論的加速運動のBorn剛性を加えない。任意の回転・加速が実際に可能だという主張でもない。

検査では、静止・並進・回転、全体の伸縮、第三の物質点だけの変形、端点で元に戻る伸縮を、既知の有理数から構成した実切断で比較する。全称条件を一つの物質点対・時刻対へ明示的に適用した検査では、成員・区間・系・単位・完全履歴の結合を確認する。これは全称量化を有限標本に置き換える処理ではなく、元の全実数域を評価しようとすると拒否する。有限例の一致から物理的な全区間の剛性を認定しない。

既存217主張と、表題・著者表示・導入二段落の全単位判断を保持する。今回の剛性は次の文を記述するための内容であり、第三段落を完成と数えない。
