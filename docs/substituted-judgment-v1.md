# 判断の代替供給と仮定上の一人称

[代替供給の共通定義](../examples/v014/substituted-judgment.noema)と、[カント第二段落の条件文の部分草案](../examples/v014/kant-delegated-judgment.noema)を追加した。本・宗教上の助言者・医師の三例を同じ仮定上の人物へ結び、その人物の努力なしに目的を満たす方法があるという後件へ接続する。原文全体の完成訳とはせず、採用した読みと不足を記録する。

## 供給元と本人の活動を混同しない

raは本人と異なる供給元、本人からの利用可能性、仕事の記述についての供給関係を結ぶ。rbは供給元の種類も要求し、一つの供給元が全条件を満たすことを確かめる。種類に該当する対象と、実際に利用できる別の対象を継ぎ合わせることはできない。

仕事には人物から命題内容への関数の記述を渡す。記述を参照するだけで本人がその仕事を行ったことにはならず、供給元に人間性や思考能力を要求することもない。本から供される表現を本人の理解力の使用の代わりにすることと、本が実際に理解力を使うことを区別できる。

三例の仕事は、既存の本人による理解力の使用bm、本人の行為を道徳的要求に照らす判断sm、本人の食事・生活の調整に関する判断snである。種類についても、外部から参照できるまとまった書かれた作品sl、宗教的な事柄への援助の役割sp、身体的な健康への援助の役割srを構成した。既存の判断行為・対象関係fa・fbを再利用している。

これらは名詞の部分説明である。書物の歴史的な範囲、良心の感情・能力としての意味、宗教上の役割の全条件、医師の専門性や制度上の資格には不足がある。基礎関係の自然言語による意味規約も残るため、「任意の名詞を完成した基礎概念だけから説明できた」とはしない。対訳表を実行時に引く処理は追加していない。

## 努力しないことと、努力する必要がないこと

rdは、本人が選択できる同じ方法について、評価範囲の全結果で目的が満たされ、その経路に本人の対象となる努力がないことを要求する。評価結果は非空で、想定結果に含まれていなければならない。目的が達成できない「何もしない方法」と、努力を要する成功方法を混ぜることはできない。

努力の関係は開始・方法・結果を受け取る。終わった時点で努力していないだけで、その経路が努力不要だったとは認めない。目的、努力の種類、方法と結果の範囲は解釈の前提として明示する。この定義を、あらゆる必要性や義務の否定の意味へ一般化することはしない。

原文草案では、三つの供給元の存在を前件svとし、rdによる本人の努力なしの達成sxを後件とする。前件の供給元がその成功方法の機構を構成するという因果関係までは、この条件文に追加していない。

## 条件文と一人称の範囲

rcは、選んだ非空の仮定状況で、同じ人物の前件から後件が成立することを要求する。現在の状況での所持や成功を断言しない。前件が全候補で偽でも条件は成立しうるので、reで「前件を満たす候補があるか」を別に調べる。検査記録ではこの二つを分け、条件文が真という結果だけを代行例の成立と数えない。

草案syでは人物を関数の引数として保持する。著者への帰属s4は、その引数を仮定例の一人称の位置として提示する関係であり、著者本人へ固定したり、実在する全員についての事実へ全称化したりしない。本文に対応する文はsyの記述を参照するため、著者への帰属を検査するだけで仮定内の所持・判断・努力を実行評価することはない。

三例は順序付きの記述列szとしても保持し、s5で列挙が網羅的ではないことを表す。列外の例を捏造せず、原文が列挙した三例の連言svとは区別する。供給元は例ごとに存在量化するが、宗教上の助言者と医師が必ず別人であるとは補わない。

## 出典の照合と未完部分

保存した原文単位kant-1784:u0009の該当条件文をハッシュと文字範囲で固定した。[Korporaのアカデミー版電子転記AA VIII 35](https://www.korpora.org/Kant/aa08/035.html)の13〜16行でも、三例と条件の順序を確認した。この転記にはmichの重複など底本との差があるため、保存原文を黙って修正していない。[照合記録](../data/delegation-reading-review-v1.json)に相違と取得範囲を残す。1784年の原刊画像との照合ではない。

直前の「未成熟であるのは便利だ」という文、後続の支払いの文、残る段落は今回の部分草案には含めていない。名詞と仕事の語義全体、条件の目的と評価範囲、jaの働き、皮肉を含む談話的な効果も未確認である。意味確認済み全文単位は、カント0/20・アインシュタイン0/282のままである。
