# 脚注全体の点検と、六文の同時解釈

カント脚注の現在の草案は、六つの主張を同じ有限解釈で成立させられる。紹介、現実の未受領、日付付きの読書、反事実の差し控え、試みとしての提示、敬称付きの言及である。これまでは最初の三つと敬称を合わせた四文の検査にとどまっていた。今回は六文を元の構文のまま、同じ人物・文献・文脈・基準時へ結んで評価した。

ただし、同時に成立するモデルが一つあることは、原文全体の意味一致を示さない。[句ごとの点検記録](../data/footnote-audit-v1.json)では、固定した原文462文字を重複のない九範囲に分け、対応する定義と読解上の未完事項を記録した。原刊494頁も再読した。記録は未完という判断であり、肯定的な意味確認の登録簿には追加しない。

## 同時検査で確認した範囲

現実の脚注文脈と反事実の比較文脈を分け、どちらでも受け手は著者、対象はメンデルスゾーンの同じ回答とした。比較文脈での受領と差し控えは、現実の未受領に混入しない。比較文脈で別の人が受領した場合、別の文献を差し控えた場合、回答からの影響がない場合は、反事実の文だけが不成立になる。現実にも受領した場合は、未受領とそれを前提にした反事実の双方が不成立になる。

紹介、号への掲載、敬称、試みの位置付けにも個別の欠落を入れ、どの主張が不成立になるかを検査する。基準例と現実の差し控えを加えた例を含めて11解釈を扱う。現実の差し控えの有無は元の条件文からは決まらない。比較状況の受領が未知なら評価を保留する。

試みの位置付けには、同じ問いのNoema記述を渡す。偶発性・可能性・思想の比較に使う七関係は未知のままで、六主張を評価できる。これは「問いへの答えがなくても問いを記述できる」という構造の確認である。答えを空や偽で補った検査ではない。評価器の短絡変換とメモ化は使わない。

## 完成に必要な確認

| 対象 | 現在の状態 | 次に必要な作業 |
| --- | --- | --- |
| 現在の回答と同じ問い | 表題の問いと冒頭の説明提示は`hzic`で結ばれる。文書個体`hzik`をこの問いへの回答として指す関係は脚注にない | 既存の回答としての言及関係を使い、現在の論説を同じ問いへ接続する |
| 刊行物の呼び方 | 系列・号・名称・日付・掲載関係はある。Büschingとの関係や週ごとという記述を名称の綴りだけに置く扱いが未確定 | 固有の題名と説明的な修飾を区別して採用する読みを定める。題名から毎週必ず刊行したという事実は導かない |
| 敬称 | 丁寧な言及と引用記事内の使用は分離した | 当時の性別・社会的な慣習のうち、この使用が伝える要素を特定して記述する |
| 試み・偶然・思想の一致 | 限定、質問、可能状況、過程と結果、論点ごとの対応を構成した | `mag`と`nur`の採用した読みを全体文脈で確認し、偶発性と一致の比較基準を語の言い換えだけに頼らず説明する |
| 著者注としての接続 | 原文の脚注区分と出典は資料側にある | Noema文書内でどこを補足する注なのかという提示上の関係を確認する |

日付は、既に採用したグレゴリオ暦の年・月・日番号を共用する。未受領の`sie`は先の回答、`die gegenwärtige`は現在の論説、`worin`は案内へ結ぶ読みを明示している。代名詞の別解釈が存在するという理由だけで永久に未完扱いにせず、読みの妥当性と、その読み通りの接続を確認する。

## 表現の完成とは別に扱うこと

実際に著者が読んだか、受領したかを歴史資料で証明する必要はない。著者が述べた内容と、その内容が現実に真であることは異なる。同様に、二文献の思想の一致を実際に計算すること、反事実の比較状況を自動発見すること、因果機構の全科学理論を完成させることも、脚注を記述する前提ではない。

原文が差し控える段階を特定しないなら、送稿・公表・執筆の一つへ勝手に絞らない。時刻を述べていない日付にUTCや時計時刻を足す必要もない。ただし、こうした非要求の整理によって、現在ある意味上の不足を解消済みにはしない。一般の因果・可能性などを言語の基礎概念としてどこまで定義するかは、言語全体の設計課題として継続する。

文書個体`hzik`と表題箇所`hzia`の直接の参照元も列挙し、固定した意味規約と照合する。前者は署名・日付・差し控え・提示・思想比較で使われ、後者は表題への回答の提示`hzic`と先の回答の紹介`hzjt`で使われる。本文の冒頭が問いへ答えることと、その本文を含む現在の文書を回答として指すことの間に、明示的な接続が必要である。参照元の列挙だけで自然言語的な含意の不在を証明したとはしない。

次の実装は、既存の回答としての言及関係`hzjj`を再利用し、現在の論説を同じ問いへ結ぶ作業とする。全句の意味確認、上記の提示上の関係、独自文字による可逆な記述をそろえてから脚注の全体確認を判断する。今回、本文・文法・基本語・文字数・表現範囲・意味確認済み区間数は変更しない。

```powershell
python -X utf8 -m pytest -q tests/test_footnote_joint.py
python -X utf8 -m scripts.check_footnote_joint --verify-only
```
