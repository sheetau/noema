# 各人の事柄と、自分で判断することへの許可

カントu0015の「各人が、良心に関わるすべての事柄で、自分の理性を使う自由」という箇所へ、人物ごとの事柄と活動を保つ構造を追加した。許可される活動の記述と、本人が実際に行う判断を分ける。

| 定義 | 内容 |
| --- | --- |
| `rox` | 同じ本人・判断行為・事柄について、自分の理解力の使用、理由の支持、他者の指導の不在を要求する内容 |
| `roy` | 人々、各人の事柄、事柄ごとの活動が非空で、全対象活動が評価済みである |
| `roz` | 同じ人物・事柄・活動・記述のすべてについて、同じ出所が実行・不実行の両方を許し、反対要求がない |
| `rp2` | 明示した分類例の中で、本人が同じ事柄について自己の行為を評価する判断がある |
| `hzgo` | `rox`を既存の理解力・判断・理由・指導の関係へ結ぶ |
| `hzgp` | `roz`を人の適格性`aa`と規範`h7a`・`h7b`へ結ぶ |
| `hzgq` | `rp2`を判断`fa`・対象`fb`・道徳的要求に照らした自己評価`se`へ結ぶ |

たとえば一人目には事柄AとB、二人目にはBが関わる場合、それぞれの範囲で許可を検査する。一人目のAだけ、二人目のBだけが許されていても、一人目のBへの許可がないため全体は成立しない。一方、二人目の範囲にないAについての不許可は、この限定された主張を否定しない。他人の許可で不足を埋めることもない。

同じ活動個体でも、事柄を固定した実行記述は別々に保持する。規範の判定ではその記述を実行しない。本人の理解力の使用・理由・支持・指導の事実が未入力でも、分類と規範の入力がそろえば許可の条件を検査できる。実際の判断が成立していても、許可があるとは限らない。

良心に関わる事柄は、現在の実行履歴と別に指定した分類例を使って部分的に説明した。本人が自己の行為を道徳的要求に照らして判断する例で、同じ判断対象になっている事柄を選ぶ。別人の自己評価や、別の判断の対象をつなぎ合わせない。この例の存在は、本人が現在判断済みであることや、実行する能力があることを意味しない。例の集合が良心に関わる全事柄を尽くすかは別の検討事項である。

[一般形](../examples/v014/personal-matter-freedom.noema)は1,858文字、[原文付き文書](../examples/v014/kant-personal-matter-freedom.noema)は202,866文字、[抽出文書](../examples/v014/personal-matter-freedom-core.noema)は2,360文字。七定義を追加し、原始記号と著者主張は増やしていない。親の宣言と15件の著者主張を保持した。[意味規約](../data/kant-personal-matter-freedom-basis-v1.json)と[検査記録](../reports/personal-matter-freedom-v1.json)を保存する。

人物の選択と事柄ごとの許可の64通りを検査した。原文付き文書と抽出文書では、それぞれ16通り、範囲・規範の九条件、実際の判断の五条件を確認した。追加22テストは人物別の範囲、全称と存在の違い、空範囲、評価不足、両方向の許可、反対要求、許可と実行の独立性、所有者・理由・事柄の保持、引用、未確定入力、親文書と原文範囲を扱う。CLI解析、正規形と固有文字v2の往復、SVGのXML検査が通過した。SVGの目視確認は含めない。

有限解釈器は条件の両辺を評価するため、分類例に含まれない状況についても自己評価などの関数値を要求する場合がある。未知の入力を偽として埋めない。意味上の対象範囲の限定と、評価器が部分的な入力だけで実行できることは別である。

自由は一つの規範源に相対的な条件であり、物理的な妨害の不在、権利の保障、能力の獲得、過去から自由を保っていた経過は未記述である。理性使用には既存の理解力の使用を再利用したが、カントの`Vernunft`と`Verstand`の語義を同一と確定したわけではない。本人による誤った推論、良心の感情・葛藤・宗教的側面、道徳的要求の内容と正当性、原文の全含意と全文の意味一致も未完である。
