# 同じ職務を損なわず論じる方法

カント第五段落の `kann ... räsonniren, ohne daß dadurch die Geschäfte leiden` に向け、同じ人が論じる活動を実行でき、そのために担当事務の遂行が悪化しないという構成を追加した。一文全体の条件・帰属・談話はまだ統合していないため、原文の意味確認済み範囲には加えない。

`r3u` は既存の介入比較 `r2vh` と内容対応 `hze` を結ぶ。実行側と不実行側で同じ方程式と背景を使い、要因の真偽が同じ本人の同じ活動の実行 `zzq` に対応することを確認する。同じ事務を同じ観点で評価し、その遂行の低下を調べる。担当事務が全面的に不成立になる場合だけを害と数えるのではなく、実行が続いていても品質や進行が低下する場合を区別できる。

`r3v` は一つの方法を固定し、その方法の評価対象の結果と、同じ因果モデルの実行側の解を状況へ写した集合とを双方向に照合する。その上で既存の能力 `xd` を評価する。安全な結果だけを抜き出すことや、別の方法で実行できることを流用することはできない。

`r3w` は同じ方法を一度だけ選び、その本人・方法・開始点から得た一つのモデルで両条件を満たすことを要求する。安全でも利用できない方法と、利用できても有害な方法を継ぎ合わせる反例を検査する。`r3x` はこれを先行する自己理解・書面による公的使用 `r3t` と、理拠を述べ検討する活動 `h232p` へ結ぶ。

ここでの `kann` は実践的な両立可能性を構成する候補である。社会的な許可は能力の入力に含めない。原文の規範的な対照がどこまで許可を含むかは、前文の禁止と `aber/allerdings` を含めて一文全体で判断する。単なる論理的な無矛盾や、現在違反していないことを実行可能性とはしない。

非悪化は、同じ背景の下で実行側と不実行側の全解を比較する頑健な読みである。確率的な通常性や無期限の無害性を主張する構成ではない。異なる外生条件を同じモデルへ混ぜる場合には、対応する解を限定する別の構成が必要になる。方法・因果モデル・事務の評価観点が適切であることは解釈上の仮定であり、有限検査が社会的因果の妥当性を証明するわけではない。

この依存群は新しい基本関係を追加せず、既存の能力、実行内容、介入比較、役割、自己理解、書かれた記録の定義を再利用する。先行職務の服従要求と全記述域の有限評価拒否は変更しない。
