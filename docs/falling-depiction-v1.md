# 学習に寄与する経験と、転倒の身体的描写

カント第二段落の`einigemahl Fallen`に、身体的な転倒の構成を加えた。従来は自立的な活動の不成功経験を`fg`で表していたが、それを転倒で描く身体側の定義がなかった。今回の追加は、同じ人と経験を保持して両者を比喩として結ぶ。身体的な歩行能力の取得と、その将来への見込み全体はまだ接続していない。

## 状態だけでなく、同じ過程を記述する

一般定義`rqvu`は、同じ身体主体・過程・前後状況について、次の条件を結ぶ。

- 前後に時間順序があり、同じ過程が生起して二状況を結び、本人がその変化を受ける。
- 前には足による支持の上に姿勢・均衡を保ち、後にはその状態が成立しない。
- 後には足底以外の身体部分が地面側に接して荷重を受ける。
- 同じ身体が同じ過程で下方へ移り、その姿勢と支持の移行を制御して遂行したわけではない。

低い場所にいるだけ、地面に触れているだけ、時間が過ぎただけでは成立しない。制御して身体を下ろす行為も、この読みの転倒とは分ける。傷害や永続的な不能は条件に加えない。

身体側には、足支持の姿勢`hzui`、地面側の身体接触`hzuj`、同じ過程での下降`hzuk`、制御した姿勢移行`hzul`の四関係を追加する。それぞれの意味規約を分け、原語一語を不透明な基本述語で代用しない。既存の状態移行`ag`、影響を受ける本人`la`、生起`dg`と時間順序`dd`を再利用する。身体力学や運動制御の実証理論をこの文語の完成条件にすり替えるものではない。

[カントの原文](https://korpora.org/Kant/aa08/036.html)は転倒を歩行の学習へ結ぶ。[Dudenの身体的な語義](https://www.duden.de/rechtschreibung/fallen)も支持・均衡の喪失と身体が地面へ至る場合を区別している。これを参考に、今回は歩行を試みる中での転倒を読む。現代辞書を1784年の唯一の解釈の証明とはしない。寝台から落ちる場合、空中にある途中、制御した受け身など、`Fallen`の全語義をこの一構成で尽くすわけではない。

## 本人と経験を比喩の両側で保つ

`hzum`は、同じ人が同じ経験で既存の身体移動`zal`を試み、その経験の結果に`rqvu`の過程があることを要求する。実際に歩行を成功させたことを前提としない。`zal`は外部の身体支持がない脚による移動の目標であり、歩行と走行の境界の精密化は残る。

`hzun`と`hzuo`は、順序付きの二個体「本人・経験」を受け取り、それぞれ対象側の不成功経験`fg`と身体側の`hzum`を返す。引数を逆転した列や、空・不足・余分な引数を持つ列は拒否する。既存の`rbt`による非字義的な提示へ両記述を渡し、`hzup`で著者・学習の理由節`fv`・提示文脈を結ぶ。

対象側の学習では既存の`fp`・`fr`が、同じ本人の経験列、少数回、能力変化への寄与、将来の見込みを表している。今回の追加は、その中で使う経験関係の身体的な描写である。身体の転倒と知的な失敗の真偽を同じにせず、全ての知的な失敗が身体の転倒であるとも主張しない。描写への帰属だけを評価する場合は、どちらの世界の事実も未知のまま保持できる。

## 検証と残る接続

追加五テストが通過した。一般形の九条件512組合せと六つの結合対照、八つの未知入力を検査した。原文用の身体描写には、別人・別経験・別の試み・結果の欠落・制御した下降など13条件と三つの未知入力を用いる。活動目標の内容を実行せず、同じ活動の試みとして指定できることも確認する。

二つの引数列の受け取り口では各五形を確認し、身体側だけ成立して対象側は成立しない解釈も扱う。非字義的な提示の七条件では、著者・節・文脈・描写の向き・内容の取り違えを検査する。引数列から実際の内容を評価する診断だけ純粋な結果キャッシュを使い、一般形・身体描写・帰属はキャッシュなしで評価した。

三文書の長形式・短縮形式・固有文字の往復と、既存九区間の意味判断の保持を確認する。五定義と四基本関係を追加し、既存38文を保って比喩の帰属を一文加える。一般文書にはカント固有の原始記号を含めない。

身体的な歩行能力の取得とその見込み、活動の途中から完了までの比喩対応、歩行と走行の区別、経験の全ての身体的な型は未完である。今回の対応箇所は既存範囲内にあり、原文対応文字数と全体確認数は増やさない。確認済みは九単位・587非空白文字のままである。
