# 全市民への自由と共同提案への参加

第六段落u0013の第七文 `[1437,2309)` では、批評の自由を持つ全市民と、声を合わせて提案する集団を区別する必要がある。「とりわけ聖職者」に注目しても他の市民の自由は失われない。一方、「全員でなくても」という括弧は、共同提案に全員参加を要求しないが、一部の参加だけを義務付けるわけでもない。

`r5gy–r5g5` は、既存の批評候補と同じ九対象・基準・候補経過・基準点を共有する。候補、聖職者への焦点、個別の自由、公的使用、書面による提供、全市民への自由を別々の内容族にした。聖職者には既存 `sp` の職務・任用を含む読みを用い、前段の教理問答の生徒や特定の信条まで追加しない。

`r5hc` はこの区別を保った取り立てと、公的使用を同じ書面提供で説明する提示を結ぶ。二つの特徴が同時に成立するだけでなく、`d. i.` による説明の向きも保持する。公的使用一般と書面一般の無限定な同値は述べない。

`r5g6` は二人以上の市民からなる提案集団、`r5g7` はその中に全市民が含まれない場合、`r5ha` は全市民を含む場合である。どちらも同じ基準点の成員関係を用いる。`r5hb` は既存の保護・非妨害を内容とする共同提案可能性を返し、部分参加を必要条件にしない。`r5hd` はその同じ可能性を非全員の場合にも排除しない譲歩として提示し、括弧の挿入先も結ぶ。

三つの提示関係は閉じた内容族を受け取る汎用の関係である。本文の真偽を一括して返す語にはせず、焦点・自由・書面提供・成員範囲・提案内容をNoemaで別に構成した。提示関係から引用した内容の真理や対象の実在を導かない。内容族の引用は段階1でそろえる。
