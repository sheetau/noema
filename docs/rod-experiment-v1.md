# 静止した棒から運動する棒への想定と二方法への問い

u0029の三文は、初期設定、思考上の配置と運動付与、長さへの問いを順に述べている。第一文のEs seiとderselbe besitzeは、静止した剛体棒とその測定長を議論の設定として置く指示と読む。第二文と第三文のWirは著者の論述上の声であり、複数人による実験の報告とはしない。

初期設定では、同じ棒xiと物差しxjが同じ静止系raで静止し、物差しを棒に当てた読みがl=yaである。既存sbqの測定関係を保ち、棒の剛性と軸長にはeipe、物差しの静止には全物質点のeiahを接続した。棒と物差しの履歴には共通の時刻区間を渡す。初期観測者は存在だけを要求し、後の観測者xkとの同一性や観測者自身の静止は補わない。

その後、同じ棒をX軸上へ置き、さらに正のX方向へ速度v=ybの等速並進を与えると想定する。初期測定yc、配置後eislr、運動後ydを区別した。配置後の長軸にはeipd、全物質点の並進と剛性にはeipgを使う。置き直した段階の初期長は保つが、運動後の長さをyaに固定しない。配置後の待ち時間や加速法則、加速中の剛性・実現可能性は指定しない。

三文目の問いは、運動する同じ棒の長さを後続の二操作で求めると考えるものである。既存sbvの方法付き値候補へ参照を結び、同じ運動設定から二つの測定設定ye/yfへ条件を引き継ぐ。方法aとbの値が同じであるとも異なるとも先取りせず、答えの存在や一意性、実際の測定完了も主張しない。コロンから続く二項の順序と同じ考察範囲xyを保つ。

棒の端面中心は幾何学的標識として扱い、断面の厚みや空洞を排除しない。形状の同定、物差しの接触と尺度の読みは明示した物理的入力である。座標候補の選択だけで履歴を認定せず、全物質点と幾何学的標識に既存の全区間出来事対応を要求する。検査で用いる有限の履歴関係と、全実数時刻の記述は区別する。
