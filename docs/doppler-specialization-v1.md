# 原理の同定と角度ゼロの式

u0190の二文とu0191の表示式を、原刊911–912頁・固定本文・M0334/M0335へ照合する。第一文は直前の式をドップラー原理と同定し、任意速度への適用を述べる。第二文はφ=0での見通しのよい形を導入する。呼称の原綴りDoppelersche Prinzip、適用域、条件、形の評価、コロン、後続表示をそれぞれ保持する。

従来はvを固定記号zb7としていたため、式だけを速度引数へ置き換えると物理的な系・観測者の速度が残る。依存する12定義eivv/eivw/eivy/eivz/ekb2/ekb3/ekci/ekck/ekcl/ekd6/ekd7/ekeaを、速度を第一引数に持つekej–ekeuへ一般化する。身体・計器の運動、座標と場、領域、位相、周期数を同じ速度へ結び、速度に依存しない定義は共有する。旧定義と文は変えない。新しい速度をzb7へ戻すと元の各本体になることを構造で検査する。

全60役割のうちK、V、節、状況を固定した56役割に、速度を含めて全称条件を置く。許容域は先行の0<v<Vであり、v/Vの一次近似や有限の標本値に限定しない。零速度では先行の角が未定義なので別の拡張をせず、光速以上にも式を適用しない。同じ状況に異なる実在速度を同時に要求せず、各割当が同じ物理条件を満たすなら、という条件である。

φ=0は同じ実数角への条件としてekeyに置く。既存の単位方向・上半円・象限付きの角の規約からcosφ=1となる。このときr=v/Vについて0<r<1で、1−rと1+rはともに正である。一般形の(1−r)/sqrt(1−r²)の平方は(1−r)/(1+r)、その値は正だから、同じ正の平方根sqrt((1−r)/(1+r))に等しい。νは根号の外に置く。両表示は同じ物理条件・同じν′に結び、別の周波数の存在証人を選ばない。

呼称には既存eisch、同じ内容の明示にはeissb、表示対応にはeisox、著者・論説にはeir3を用いる。新しい一般関係eisspは、式の構成と量の依存が既出の記号規約で見渡しやすいという提示形式の評価だけを担う。数学内容、全速度への適用、原理の名前の意味をこの関係へまとめない。全読者の心理、最短の文字列、計算時間又は導出の容易さを追加しない。

検査は、正確な有理数で平方根が表せる多数の速度比、単位尺度の変更、平方根の正負と分子分母、角の零と他の枝、全56量化位置、全12速度伝達の構造と元への復元、引用・同定・表示を対照する。全実数域又は全関数域を有限集合で代用せず、未知入力は拒否する。物理法則の一般的な真理と原文の意味判断は検査成功から自動認定しない。

u0178とu0192以降は未完。特にu0192の無限大の印字を、現在の亜光速式に合わせた内容として先取りしない。
