# 同じ判断に質の基準を結ぶ

カントu0014の能力は、理解力を他者の指導なしに使うことに加え、`sicher und gut` という質を伴う。これまでの `rlk` は同じ判断を支持する理由が少なくとも一つあることを求めていたが、それだけで質の条件を満たしたとは扱えない。質を能力の目標と活動記述に含める比較候補を追加した。

`rqwq` は本人・事柄・判断・実行時点・基準文脈を固定し、既存 `rcr` と二つの質の条件を同じ判断に課す。判断Aが第一の基準、判断Bが第二の基準を満たしていても、両方を満たす判断がなければ成立しない。別人、別の事柄、別時点の質を借りることもできない。

質は閉じたNoemaの式として指定する。一般の例として `rqwr` は、同じ判断で用いた理由が一つ以上あり、その全てが同じ判断を支持することを表す。既存の `rcr` が求める「少なくとも一つ」と区別できる。例えば、次の定義は既存の理由使用 `fc` と支持 `fd` を組み合わせ、能力目標へ渡せる五引数の条件を作る。

```text
d zsecure[p a m a j a c d s d] c[k rqwr[v j v s p fc p fd]].
```

これは確実さや適切さの完全な定義ではない。全理由が支持することから、全理由の真理、無矛盾性、十分さ、結論の真理まで導くことはしない。ここでは質の基準を実際のNoemaの構成として使えることと、一つの支持理由があるだけの旧目標との差を検査する。

`hzvp` は質を含む本人の判断内容を返し、`hzvq` は事柄・基準文脈・二つの基準の閉じた記述から活動記述を構築する。記述の構築時には、その内容の真偽も参照先も実行しない。能力を調べるときには同じ記述を目標内容と六つの活動別プロフィールへ渡す。基準が違えば記述も変わるため、偶然同じ真理値の別基準や無修飾の活動のプロフィールは自動流用しない。明示的に新しい活動へ与えられたプロフィールは使える。

`hzvr`・`hzvs` は評価と能力、`hzvt`・`hzvu` は全支援結果の評価と支援可能性、`hzvv`・`hzvw` は集団の到達と未到達だが進行中の内容を表す。いずれも元の質の記述と基準文脈を保持する。支援後に容易な事柄へ範囲を縮めたり、質を緩めたり、異なる結果の部分能力を集めたりしない。支援可能性は能力のある状態へ置く可能性であり、前状態の能力欠如や実際の新規取得を含まない。

検査では二つの判断について支持・二つの質の64組合せ、五つの結び付けの対照、四つの未知入力、理由使用と支持の16組合せを確認する。本文用の十条件では、質の不成立、誤った文脈・参照、活動記述が異なるプロフィール、同じ真理値を持つ別基準、Noemaで合成した全理由の支持条件を実行する。さらに支援の五条件と集団の二条件、記述の構築と実行、表記の往復を検査する。

原文で適切な質の基準を選ぶ判断はまだ残る。宗教的な対象範囲、不足の程度、集団基準、問答・進行・徴候・著者帰属の統合も未完である。有限例の通過を原文全体との意味同一性とせず、現行41文と十単位・604非空白文字の確認を保持する。

初回の集団接続検査は6,000万評価ステップの上限で停止した。対象領域や実行する定義を削らず、この検査の上限を1億8,000万ステップへ引き上げる。文脈ごとの内容を逐次評価する現行実行器では集団の量化が重く、通常利用に十分な性能を得たとは扱わない。他の検査は元の上限を維持する。

実行: `python -X utf8 -m pytest tests/test_qualified_judgment.py -q`。記録の再照合: `python -X utf8 -m scripts.check_qualified_judgment --verify-only`。
