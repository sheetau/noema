# 語を構成する円字形を重ねて綴る

## 先行計画

既存語を短く命名し直すだけでなく、同じ語の隣り合う部品を構成的に詰める。対象はそれぞれ単独の円からなる大小の根語形とする。大円は中央罫線、中円は隣の罫線に置き、中円の中心を大円の円周上に置く。円のサイズと中心線の方向は元の根語形を保持する。左右の中心順が部品順であり、上下は同じ綴りの配置候補とする。

一つの円が二つ以上の相手を持つ形は作らない。三部品以上の連続も、重ならない隣接二部品組へ分ける。同心円や既存の二円字形をもう一円と重ねること、偏心した内包、円周への斜め入射は許可しない。元の幾何検査で成立しない組は、元の分離した綴りを使う。

これは単語や辞書の番号を一字形へ置き換える操作ではない。二つの可視根語形の組合せから、同じ二部品列を読む。既存の語義、根語形、完全綴り、文法字形を変更しない。未使用だった大円と中円の隣段での重なりに、語内部の構成順という共通の役割を与える。

読取は、実際の円・線から重なった根語形を識別して部品列へ展開し、その後に既存の語・引数・束縛・引用の規則を適用する。枝は組の末尾へ、語境界は組の先頭へ対応させる。組の二部品が別々の語として消費されたら拒否する。元構文や生成時の部品ラベルを読取器へ渡さない。

まず合法な組合せと衝突の有無、順序、語境界、引用・束縛、旧字形の読取を小例で確認する。その後に実本文で幅と復号を比較する。円数は原則として減らさず、横方向の冗長さと三罫線上の偏りを減らすための規則である。全体の外観と40本文の完成は別に確認する。
