# 局所時計による出来事の時刻

出来事の時刻を、その出来事が起きた場所にある静止時計の読みとして記述した。各時計を同じ参照時計へ結び付ける。遠隔地へ光が届いた時刻は別の出来事の読みであり、元の出来事の時刻として混ぜない。

[アインシュタイン原文§1](https://de.wikisource.org/wiki/Zur_Elektrodynamik_bewegter_K%C3%B6rper)の `u0018` 第二文に対応する部分草案である。前回は末尾の共通参照時計だけを扱ったが、今回は出来事・その場所・局所時計・その時点の読みまで接続した。第一文の談話、時計や読みの物理的な基礎、全出来事への時刻の存在と一意性、原刊画像との照合は残る。

## 時刻の付与と値の一致

| 定義 | 条件 |
| --- | --- |
| `sae` | 出来事と時計が同じ場所にあり、時計が同じ基準系で静止し、当該出来事の読みが指定値になる |
| `saf` | `sae` に加え、その時計が静止した参照時計と同じ単位・文脈で同期する |
| `sag` | 二つの下側切断が互いに包含される |
| `qt` | 原文の共通参照時計・基準系・単位を `saf` へ渡す |
| `qu` | 読みの実数条件と、既存の光往復による同期定義を `qt` に接続する |
| `qw` | 二出来事を同じ条件で評価し、その読みの値が一致する |

`qw` は異なる場所にある別々の時計を許す。比較に使う参照時計・基準系・単位・文脈は共通である。既存の `bc` は切断の包含であり、一方向だけでは数値の一致を意味しない。そこで `sag` は両方向の包含を要求する。切断を実装する関数の同一性も、値の一致の代用にはしない。

時刻は、候補の値に必要な条件を課す関係として書いた。存在や一意性を証明せず、どの出来事にも値を返す関数を導入することは避けている。時計の測定精度や指示機構の説明、遠隔観測からの時刻の推定はまだ含まない。

本文の新しい主張は、著者が `qu` を時刻の付与規則として定義に採用するという帰属である。規則の記述を引数に渡し、その内容を実行しない。従来の同期法則の仮定に関する主張はそのまま保持した。

## 検証

一般定義と原文の接続をそれぞれ20例で検査した。出来事の場所の時計が7を示し、別の場所で信号を受け取ったときの時計が9を示す例では、それぞれの局所的な読みを受け入れ、9を元の出来事の読みとして扱う混同を拒否する。これは明示した有限の関係の検査であり、伝播速度や遅延量の物理法則の証明ではない。

時計・出来事・場所・基準系・単位・参照時計・文脈の取り違えも拒否する。接続の検査では同期関係を明示的に与えた。実数全域の量化を含む `qu` と `qw` の物理モデルを有限近似して実行した結果ではない。読みの検査で使った数点の比較も、入力として与えた有理数7と9の埋込みだけを識別する。

別に、有理数を埋め込んだ切断について、両方向の包含と数値の一致、共通の原点移動で一致が保たれること、片方だけの移動はずれが0のときだけ一致を保つことを線形算術で検証した。一方向の包含から一致を導く誤った主張には反例が得られた。任意の実切断についての一般定理ではない。

定義の帰属は6例で確認した。著者・対象規則・本文箇所・範囲・文脈が異なる場合は拒否し、物理内容を評価しなくても帰属を扱えることを検査した。

一般文書は基本述語0・定義3、原文接続文書は基本述語38・定義31・主張2である。文法や実行系、新たな翻訳規則は追加していない。関連29テストが通過した。通常記法・短縮記法・固有文字の往復、CLIのJSONと解析構造の一致、SVGのXMLとしての妥当性、検証記録の入力ハッシュ、進捗集計の再生成一致も確認した。SVGの目視検査や全テストの再実行ではない。全文の意味確認済み区間は両作品とも0のままである。
