# 推測の内容と全ての適格系

導入第二段落u0004を原刊891–892頁と照合した。891頁末の「nur scheinbar unverträgliche」から892頁冒頭の「Voraussetzung einführen」へ第二文が続く。光速度の記号は大文字Vで、固定転記のM0001に対応する。A0002は頁境界の注記であり、著者の脚注や欠けた命題ではない。第四文までが同じ段落で、次の理論の運動学への依存はu0005として別に始まる。記録は[einteinの原刊892頁](https://de.wikisource.org/wiki/Seite:Einstein-Elektrodynamik.djvu/2)と保存した画像・HTML、既存891頁を固定する。

今回の依存群は第一文の推測内部[148,460)を対象とする。絶対静止に対応する現象の特性が力学だけでなく電気力学にもないことと、力学方程式が成り立つ全ての系で同じ電気力学・光学法則が成り立つことを、同じ内容eifjに組み合わせる。これを本文の新しい主張としてはまだ追加しない。第一文全体には、類似例・運動検出失敗が推測へ導く関係、対照の提示、一次の量では既証という限定が残る。

既存sawは相対等速で回転しない二系をsatで選ぶため、そのまま今回の条件にはできない。eifbは物理的座標系vaに、力学方程式が成り立つというeisbdを結ぶ。後続u0008に合わせてNewtonの力学と読む。適格性は力学の成立に関する物理的入力であり、座標系名、相対速度、電気力学が成立するという結果で代用しない。

eifcは同じ体系の電気力学・光学の法則を選ぶ。同じ法則とは物理量・適用条件・単位規約を共有した一般的関係である。単に同じ名前の式を系ごとに用意することではない。eisbhは法則、物理履歴候補、全適格系での対応する記述の完全性を要求する。結果を見て候補や法則を抜粋できない。

eifdは既存sar/saq/sapを再利用する。全ての候補履歴について両側の記述が存在し、同じ法則への適合viの真偽が全ての対応記述対で一致する。実現した履歴や適合する候補だけには量化しない。さらにeifeで同じ法則が各系の現象について法則として成り立つことも要求する。適合条件が両系で同じでも、両系でともに妥当しない法則体系では原文のgeltenを満たさないためである。

eiffは完全性、両分野の法則と適格系の非空性、全適格系での成立、全適格系対での保存を結び、eifgはそのような共通体系の存在を内容とする。二つ以上の異なる系があること、系同士が同じ座標値を持つこと、光学と電気力学が排他的な法則一覧であることは加えない。これは法則の許容条件と適用の共通性という採用解釈であり、説明機構の同一性やあらゆる歴史的な法則観を表す定義ではない。

eifhは絶対静止の概念に対応する現象の特性が存在しないとする。eifiで力学と電気力学の双方へ適用する。否定するのは座標系の選択によらず特権的な静止を特徴付ける現象の特性であり、物体・位置・相対運動・基準系に対する静止の存在ではない。「未検出だから不存在」という推論もここへ入れない。

有限検査は全称・存在・否定の構造、全ての系と両分野、法則の成立と適合保存の違い、対応記述の非空性と全対比較を確認する。入力が有限の模型であることを実際の物理域の網羅や実証とみなさない。旧213主張と既存の三単位の判断は保持する。第一文・段落全体の意味判断は未完である。
