# 磁気偏向の局所曲率半径

原刊921頁の第三項u0271–u0274を対象とする。同じ電子が速度に垂直な磁場Nの作用を受け、その磁場が唯一の偏向原因であるとき、軌道の曲率半径Rを計算する。第二(A)から得る−d²y/dt²＝v²/R＝(q/μ)(v/V)N√(1−(v/V)²)と、oderで続くR＝V²(μ/q)(v/V)/√(1−(v/V)²)/Nを保存する。

第二項の静電加速とは別の局所的事例として、同じ電子・K・低速質量・符号付き電荷・速度・単位を使う。esoは実座標時刻の三速度・三加速度と実二場、電気的・磁気的な力の寄与を、同じ出来事と四座標へ結ぶ。瞬間速度を正x、磁場をz、瞬間の曲率の法平面をxy面に取る。原文の−ayと正のRに対応してqN>0の向きを選ぶ。負電荷と負のNの組も許し、原文を絶対値付きの式へ替えない。

唯一の偏向原因という条件は、横電場零だけから補わない。eis4tで同じ出来事の実際の各作用源の力を同じ単位へ帰属し、esm/esnで全ての非磁気的寄与のy,z成分が零であることを要求する。記録一覧の完全性を仮定せず、関係の範囲自体が全ての実際の作用源を含む。二つの横力が相殺するだけの例も除く。接線方向の電場・他の力・加速度は零に限定しない。

espは既存sevcを使い、同じ実三速度uと実三加速度aから、S＝u・u、C＝S(a・a)−(u・a)²、R²C＝S³、S,C,R>0で局所半径を定める。半径は座標長さと同じ正の尺度を使う。接線加速度を変えても局所半径は変わらない。全軌道が平面円であること、等速、一様な磁場又は有限時間の等加速を追加しない。

essは同じ実横加速度へ第二(A)を適用し、estはその法則と物理的局所曲率を導出の前提として共有する。esq/esrは既存sevf/sevhの適用条件を保ち、印刷の分数・平方根・負号・全等号を明記する。oderは同じ前提の下での同値書換えであり、前提なしの同値や排他的選択肢ではない。

原文の計算の取組、wennの条件、括弧内の唯一性、RとNの呼称、第二(A)への照応、導出、二つの表示とoder、同じ著者と論説への帰属を接続する。局所検査は原文の全文意味判断と分けて記録する。数値と多項式の診断を全実数の解析・物理的真理又は同義性の自動証明にはしない。
