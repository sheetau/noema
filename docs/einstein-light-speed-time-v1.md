# 光速定数と静止系の時間の可視接続

Einstein 正本の主張81–82、原文 u0019–u0022 を、先行する同期・時刻の定義と同じ円文字文書へ接続する。二つの主張に必要な119宣言を旧正本へ逆写像し、意味を判断済みの型付き本体と照合する。既存の577宣言・29主張を保持し、原文二主張と呼称の綴り注記一つを追加する。

## 数式を含む一文

光速の規定は、導入節 u0019、表示式 u0020、続きの文 u0021 で一文かつ一段落を構成する。原刊894頁の段落に従い、参照は第14段落の第一文へ結ぶ。収録単位の区切りを段落番号に読み替えない。次の u0022 は894頁末から895頁冒頭へ続く第15段落の第一文であり、改頁は命題を追加しない。

数式は、同じA時計の帰着時刻から出発時刻を引いた経過時間と、二地点間の正の一方向距離の二倍を用いる。正の経過時間と速度の下で、速度と経過時間の積が距離二つ分に等しいという既存の合成定義を使う。反射地点の時刻を分母へ入れず、速度測定の必要条件に同期の等片道時間式を加えない。出発・反射・帰着、同じ光の往路と復路、真空条件、長さ・時間・速度の整合する単位を保持する。

普遍定数は、同じ静止系の全適用光往復に一つの値を共有するという読みである。非空性、適用範囲の完全性、位置・方向・距離・出発時刻を変えた試行への一般性を既存の定義で保持する。数値は指定せず、既観測の成功例だけを範囲としない。著者の経験に従う追加採用、同じ値を真空中の光速度と説明する括弧補足を、物理的な実証完了とは区別する。

## 値の参照と時間規約

新しい参照語は、文書・導入箇所・閉じた役割記述・文脈に結び付けた切断型の値を取得する。ここでは既存の `san`、すなわち全適用試行に共通な値の条件をそのまま役割にする。`san` は参照される値 `tc` 自体に依存しないため循環しない。参照を取得しても、役割を実行したこと、実数として妥当であること、実測済みであること、唯一の値があることは主張しない。未知の入力を既定値で埋めない。

長さ単位・速度単位・経験的根拠は、既存の個体役割参照と三つの本文内定義で示す。原文にない単位名、実験名、現代の光速の数値は補わない。試行の出発帰着時計・反射時計・一方向距離は、同じ試行をキーとした三つの既存関数に結ぶ。

最後の文は、直前に定義した同じ共通時間規約を受ける。同じ系で静止する時計による定義が重要であるという提示と、その系への依存を理由に名付ける向きを保つ。重要性を論理的必然性へ替えず、名前から静止条件を作らない。「die Zeit des ruhenden Systems」の文字列は呼称の識別注記に限り、時計・系・規則との関係は合成定義で表す。
