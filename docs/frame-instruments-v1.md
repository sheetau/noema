# 二座標系と同じ仕様の計器を置く初期設定

u0043全441文字・361本文文字を、原刊897頁の三文として読む。二座標系の構成、対応軸の配置、各系の物差しと時計群を一つの初期設定へ結び、Seien、mögen、sei、es seienをその設定を採用する指示として保持する。

前回の `eivf/eivg` により、三本ずつの剛な物質線とその静止・直交・支持直線の配置を接続している。今回は `eivk` で物差しの完全な静止履歴・剛性と目盛尺度の校正を結び、`eivj` で時計の校正と代表配置の静止を保持する。時計の針や歯車を止める条件は加えない。物差しの校正方法があることも、実測の実行を意味しない。

genau gleichは、構成と尺度仕様の全特徴が正確に一致するという読みを採る。時計には第一節の `eild` を再利用する。物差しの `eivi` も完全な比較規約、非空の全特徴、各特徴に対する非空の記述集合の両方向一致を要求する。構成の余分な部分、違う目盛り、未知の特徴を見落とす比較にはしない。

既存 `sfa` にこれらの比較を渡し、両系に与える全時計のすべての組合せを保持する。時計の具体的な数は定めず、両群とも非空とする。仕様が同じでも、個体・場所・現在の表示値・初期位相・遠隔同期は同一とはしない。製作や検定の手順、運動後の時計の進みや物差しの測定値の一致も補わない。

「静止した」空間という引用修飾は、第一節で呼称を与えた同じ静止基準への照応とする。d. h.は同じ二座標系を三物質線によって説明する言い直しであり、別の設定への変更ではない。`eivr/eivs` はこの説明と照応を保持し、同じ全設定を第三節の仮定として採用する指示を記述する。著者への帰属では引用内容を実行しない。

有限の特徴表と設定モデルは、全範囲の結合・肯否・引用の扱いを調べる検査である。完全な仕様範囲や全物理履歴を有限標本から実証したとはしない。原刊と三文全体の読みを照合して意味判断を別に登録し、u0044の運動付与と対称性の説明は後続に残す。
