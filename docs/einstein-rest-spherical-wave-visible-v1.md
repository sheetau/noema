# 共通原点からの球面波と到来点の式

原文u0087–u0088の二文と表示式を円文字本文へ接続する。既存の合成定義12個と、同じ波の構成光線を指定する意味規約1個を再利用する。共通基盤375語を維持し、任意プロファイル52版は787語となる。参照型は追加しない。

原刊901頁の第45段落は、放出を仮定する第一文27トークンと、表示式で終わる第二文13トークンに分ける。式を外部識別子で代用せず、三座標の平方和と光速度・時刻の平方の積を既存定義で表す。

波には少なくとも一つの構成光線があり、その全てが同じ放出出来事から伝播する。放出時の両系の座標原点と時刻零を結び、全時刻の原点一致や時間一致は要求しない。到来には同じ光線・放出元・区間・局所時計・両端の現在座標・光路長を使う。

球面性は、現在の全対象出来事と座標記録において、到来と正時刻の球面式が過不足なく一致する条件として合成する。成功した標本だけを対象にせず、波面上の欠落と波面内の余分な到来を区別する。平方の式だけでは時刻の正負を区別できないため、未来側の波面の条件と零時刻の放出を分ける。

波と放出出来事は、同じ仮定箇所に固定した役割付き参照で指す。波の役割は放出を存在量化し、放出の役割はその波に結び付ける。参照定義を循環させず、参照取得時には引用した役割を実行しない。名前の取得から現実の放出や仮定の成立を導かない。

第二文は、同じ波が到来した任意の対象出来事と現在の座標記録について式を述べる。仮定、条件付き帰結、著者帰属、直前の証明課題との本文順序を保持する。後続の運動系への変換、係数関数の確定、二原理の両立性の証明完了はこの部分には加えない。

検査では、数式の各座標、正負の時刻、同じ放出への結合、全構成光線、波面の両方向、同じ座標値の別記録、空の到来範囲、引用の非実行を区別する。旧モデルを再利用する場合も検査対象は復号したNative定義へ置き換える。有限診断は全実数・全物理モデルの証明や第三者読解とは区別する。
