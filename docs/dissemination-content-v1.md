# 伝わる性向と発信者の独立判断

第四段落第二文の条件付き予測について、内容・性向・周囲・広がり・評価機会の供給を接続した。発話の文面と具体的な話題は原文で指定されていないため、各発信者・評価機会の中で存在として記述する。受け手が取得する性向は、理由ある自己評価と、全ての人が自ら考える課題を認める判断への性向として固定する。

## 発話の存在と取得される内容

`r2lu` は、同じ人・評価機会に、既存の独立判断と自己離脱・伝播を満たす話題と閉じた発話記述が存在することを要求する。原文にない台詞を作って発信者へ帰属しない。話題と発話を存在量化しても、実際の提示・受領・理解・因果・同じ性向の取得・持続という既存の条件は残る。

同じ発信者・機会では一つの抽象的な発話内容を共用する読みを採る。受け手ごとの経路と取得過程は異なってよい。発話記述の一致は表面の綴りの一致を意味しないが、内容が変わる伝播や任意の言い換えの同義性まで、この構成で認定するものではない。

`r2lv`–`r2ly` はこの存在を、前版の評価機会・自由条件・第一文の入力へ接続する。無制限の発話記述や有限経路を量化する文法を保持し、列挙可能な候補だけへ制限しない。実行時に具体的な証人を確認できても、失敗から存在命題の否定は導かない。

## 受け手の性向と文脈上の基準

`r2lz` は、既存の理由ある自己評価と規範承認 `hznu` を応答とし、通常の反事実場面でその応答をする性向 `hzq6` を構成する。自己評価は人としての価値・長所に関する基準を用い、評点を原文へ補わない。使命は、人として理性を用いる立場から各人の自己思考を課題とする規範として読む。神・国家・雇用者による命令や、規範の現実の正当性へ同定しない。

受け手の性向の場面・通常性と、発信者の独立判断の場面・通常性は別の入力にした。どちらも本人の能力、利用できる理由、判断の機会、異常な妨害などを踏まえて指定し、成功する応答だけから選ばない。非空性や比較の整合性は既存の定義で検査するが、適切な反事実場面を自動発見したという意味ではない。

`r2m2` が作る閉じた性向記述を、受け手の状態評価・取得の原因・持続へ共用する。公衆・参照状況・仮定経過を引用内で指すには閉じた呼称を使い、`r2m4` で元の対象と等しいことを要求する。誤った呼称の候補を範囲から除いたり、外側の変数を暗黙に引用へ取り込んだりしない。呼称候補の供給は一般的な二つの基本入力とし、意味規約を明記した。

## 社会的な周囲と複数人への広がり

`um sich` は、情報・援助の供給元として一方が他方を利用できる社会的な接点の範囲として読む。既存 `hzom` を用い、物理的な近さ、親密さ、実際の利用を追加条件にしない。伝播側の `rqth` は中心本人を受け手から除き、受け手を全公衆の読者へ自動的に広げない。

`verbreiten` は、その周囲の異なる二人以上に同じ性向の新しい取得が生じる読みとした。既存 `rqsy` へ正確な範囲と取得者の述語を渡す。全員や過半数への取得、同時の取得、中継者全員の同意を要求しない。この人数条件を、この語の全ての用法へ適用する定義とはしない。

## 接続の検査と残件

`r2m3` では、話題・発話の存在量化後に残った八つの供給関数を全て充足する。新しい入力は、評価基準・規範の参照・反事実場面・通常性・評価機会の十一項目と、閉じた呼称の二種類である。原文一文を返す基本演算子は追加しない。

検査では、性向の実際の定義、八供給の同じ文脈への接続、周囲と複数人の条件、呼称の取り違え、話題・発話の具体的な証人を調べる。自己評価・規範承認、条件付き予測、任意長の伝播はそれぞれ明示した検査境界とし、前版の依存定義と検査根拠を保持する。有限検査の通過を、原文の意味確認に自動変換しない。
