# 第三文の依存群：同じ態度の社会的取得と経路

共通の自由方針を支持するr56nの態度を、異なる人の間で共有される状態として扱う。r56oはその人物性質の段階2の記述であり、支持対象の方針そのものの記述とは分ける。

r56pは、同じ人・変化過程・履歴において態度が不成立から成立へ変わることと、その同じ態度を同じ活動が結果として生じさせたことを結ぶ。活動時点は取得区間の中に置き、取得完了点とは分ける。新しいh26phは既存g3の結果生成を段階2の性質へ保った関係であり、時間順序や同時成立から因果を推論しない。

r56qは、人が実際に持つ態度と、その人の同じ活動における態度の表れh26piを結ぶ。r56rでは、この活動が別の人の同じ態度の取得を生じさせる。言語的な表明だけでなく実践や応対による表れも許し、受領する同一発話を必須にしない。態度と活動が無関係に共存するだけの例、別の態度への影響、活動の生起・当事者性・結果生成の欠けた例は区別する。

r56s/r56tは同じ内容の社会的取得を任意長の有限経路へ結ぶ。前の取得者が次の活動者となり、前の取得完了が次の表れ活動以前にある。r56uは最後の人の同じ態度が基準点まで続くことを既存rafで求める。中継者の全員がその後も保持し続けることは要求しない。r56vは経路全体へ同じr56oを渡し、引用された自由方針の実現から態度取得を代用しない。

これは同じ態度の新たな取得を含む経路の読みであり、既存の態度の強化だけを取得と数えない。過去に同じ態度を持ったことが一度もないという生涯の初回条件は課さず、全社会への拡大完了も述べない。社会的な影響の現実の機構と、適切な履歴・過程の個体化は意味規約の入力として残る。

r56w/r56xは経路の元の人を同じ君主の管轄下へ、終点の人を異なる共同体の公的政府の管轄下かつ元の管轄外へ結ぶ。国外を制度的統治圏の外と読む。外国政府に君主制や自由政策の実現を求めず、旅行時の物理座標や近代的国籍を同一視しない。r56yは与えた経路証人により国外の取得者が少なくとも一人いることを示す。全員への到達や全潜在経路の探索完了は主張しない。

局所検査では、実際のr56nの支持内容を評価し、同じ引用・人物・活動・過程・時点への接続を調べる。自由方針の実現は未知のまま保つ。1・2・3段階、切断・時間逆転・異内容・無原因、最終取得者の喪失と中継者の後の喪失、無関係な外国人と別人の経路の寄せ集めを区別する。本文の統治圏と経路証人の設定、先行例への照応、障害・格闘・政府の自己誤解、auch/selbstと全文帰属は未接続であり、第三文の意味確認文字数は増やさない。
