# 方法の対象となる本人と、努力を担う実施者

カントの代行例の「自分で努力する必要がない」について、従来の本人の努力という関係を二者の結合として定義した。目的に関係する本人と、努力を担う実施者を別の引数で指定する。本人の努力が不要な方法で他者が努力する場合を表せる。他者の努力が必ずあるという条件は加えない。

旧基本関係skは、もともと本人の努力を対象としていた。今回の変更は、その条件を実施者の指定から構成できるようにするものである。原文の対応範囲は増えず、全文の意味確認率も増えない。

## 定義と作用範囲

新しい基本関係hzwzは、実施者・本人・方法・開始・結果を受け取る。その本人の目的に関する同じ方法の経路で、その実施者の努力が必要になることを表す。引数名method_beneficiaryは目的に関係する本人を指し、実際の利益や目的達成を保証しない。経路の評価と、方法を実際に選択・実行したことは別である。

skは、hzwzの実施者と本人を同一にした定義となる。一般定義rqxrは、指定した実施者の範囲内に努力を担う者がいるかを調べる。本人だけ、他者だけ、指定集団を分けられ、空の範囲では成立しない。基本関係を一つ加えて旧skを定義へ移すため、基本関係の数は増えない。

本文のsxは、従来どおり同じ利用可能な方法について、選択した結果が空でなく、各結果で目的が達成され、本人の努力が不要であることを要求する。成功するが努力の要る方法と、何もせず失敗する方法を寄せ集めることはできない。他者の努力の有無はこの条件と独立であり、本人の不実行・努力不能・活動の禁止も導かれない。

旧skと新定義の比較では、同じ独立した実施者の関係を旧skにも投影して解釈する。この対応を置かず、任意の旧skの解釈と新定義が等しいとは主張しない。
