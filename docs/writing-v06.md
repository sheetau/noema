# 複数の対象をまとめて書く

犬は`mu`、猫は`si`。対象を書く位置で二つを`w[mu][si]`と結合できる。文字版2でも、命題の結合に使ってきた同じ結合文字を使う。文書の先頭を`f:`にすると文語0.6の短縮記法になる。

```noema
f:no fo w[mu][si].
```

「子供が犬と猫を見る」に対応する記述例。`no`は見る、`fo`は子供で、短縮記法では先の対象が主体、次が見る対象になる。複数対象を一つの対象の位置に置けるので、述語を繰り返す必要はない。これがあらゆる共同・分配の意味を表せるという保証ではない。

全体を再び指すなら、結合の後へ参照名を付ける。

```noema
f:no fo w[mu][si]o pets.
po p pets.
```

犬だけも再び指したいなら、犬の語の後にも参照名を付ける。

```noema
f:no fo w[mu o dog][si]o pets.
po p pets.
b no c p dog.
```

三文目は、先に書いた犬を誰が見るかという質問。集合全体と犬は別の参照先のままである。

数量は対象ごとに書く。`m c`は数量2であり、次の猫の数量を決めるものではない。

```noema
f:no fo w[mu m c][si].
```

「一緒に」「それぞれ」「どちらか」の違いまで書きたい場合、この版の集合記法だけでは足りない。無理に省略して同じ文章にせず、後続の量化・分配の拡張課題としている。

試すには`/writing`の文章欄か、CLIを使う。

```powershell
python -m noema parse --text "f:no fo w[mu][si]o pets. po p pets."
python -m noema render --text "f:no fo w[mu][si]o pets. po p pets." --output artifacts/group-example.svg
```

固有文字へ切り替えても、全体の参照と成員の区別は変わらない。自然言語との自動翻訳は集合にまだ対応していない。詳細な意味、型、旧版との互換性は[文語0.6の仕様](spec-v06.md)を参照。
