# 全時刻に共通する運動の選択と対称性の理由

アインシュタイン§3の `u0044` 後半を部分記述した。各時刻で軸の配置が定まること、一つの運動を選んで全時刻で軸を平行に保つこと、著者が対称性をその仮定の理由として挙げることを分けて表す。

一般定義 `sfo` は、空でない時間範囲の全時刻に配置が存在し、同じ運動・時刻の配置が指定した同値関係で一致することを要求する。`sfp` はその全配置に条件を課す。同じ配置を別の識別子で記述することは許すが、条件を満たす記述だけ選ぶことは許さない。

`sfq` は全時刻で条件を満たす一つの運動の存在、`sfr` は時刻ごとに条件を満たす運動の存在である。前者の量化順序は「ある運動について、どの時刻でも」、後者は「どの時刻にも、ある運動が」であり、後者から前者は導けない。

`sfs` は候補範囲上の可逆な変換と、その変換による許容条件の保存を表す。対称性だけでは平行な運動の存在を保証しない。候補を交換する対称性があっても、どの候補も全時刻で平行にならない反例を検査した。原文が念頭に置いた具体的な変換は未同定であり、この定義を原文の対称性の完全な説明とは扱わない。

原文との接続では、`sft` が前段の並進条件と共通の時間範囲を候補に課す。`sfu` は静止系で測った同じ時刻の値に配置を結び、`sfv` は原点と三軸の配置点の座標を、その運動の同じ時刻の座標へ照合する。配置を別の記録へ差し替えて平行に見せることを防ぐ。軸配置に時計内部の状態まで含めることはしない。

`sfw` は初期設定と同じ原点・軸の役割を保つ二つの直交三軸を要求し、対応する三軸すべての平行を検査する。平行移動後の原点の一致や、X軸を含む直線の一致までは要求しない。`sfx`・`sfy` が全時刻で平行になる選択と存在を、`sgb`・`sgc`・`sgd` が配置の確定性・存在・採用した選択を表す。

著者への帰属は引用した内容を評価せず保存する。対称性を仮定の理由として提示する関係 `zct` は、理由が正しいことや仮定を証明したことを含意しない。旧文書の宣言と主張はそのまま継承した。

新規11件を含む関連40テストが通過した。二つの運動・二時刻の16組合せを一般定義と原文接続の両方で検査し、配置の一意性6例、対称性7例、時刻の結合13例、三軸の配置12例、履歴との座標照合12例、帰属10例を検査した。原文接続の有限検査では、許容条件などへの検査用関数と構成済みの整数切断を使う。任意の実数時刻・座標を有限標本で検証したものではない。

標準表記・圧縮表記・固有文字の往復、CLIのJSONと構文木の一致、SVGのXMLとしての妥当性、検証記録の再現と進捗集計の整合性を確認した。SVGの目視確認と全テストの再実行は含めていない。

一般文書は基本述語0・定義5、原文接続文書は基本述語240・定義183・主張30である。原文接続文書は継承分を含め40,363文字、追加は4,783文字。この定義集の長さは、利用時の一文の圧縮率ではない。原文の明示範囲は空白と数式マーカーを除き300文字増えたが、原刊照合、具体的な対称性の同定、配置と時間範囲の完全性、全文の意味確認は残る。意味確認済み全文単位はアインシュタイン0/282・カント0/20のままである。
