# 時代の後続関係と、先行する人々の引受け

カントu0013の「ある時代」と「その次の時代」を、明示した時代区分と、その時代に生きる人々の集団へ結ぶ部分草案を追加した。時代の区間、集団の所属、契約の当事者、目的の影響を受ける集団を別々に指定し、同じ参照で接続する。

| 定義 | 内容 |
| --- | --- |
| `rjc` | 時代に割り当てた範囲が、同じ順序付き履歴内の非空で間の抜けない区間である |
| `rjd` | 先行時代の全状況が、後続時代の全状況より前にある |
| `rje` | 選んだ全時代が有効な区間で、異なる時代同士の範囲が重ならず順序付けられる |
| `rjf` | 同じ時代区分の中で、二時代の間に別の選択時代がない |
| `rjg` | 集団の所属が、同じ母集団内でその時代に生きる人々と一致し、空でない |
| `rjh` | 同じ基準で選んだ二集団を、`rjf`で続く二時代へ結ぶ |
| `hzde` | `rjh`の人間・時間順序を、原文側の既存の関係へ接続する |
| `hzdf` | 先行時代に属する当事者による、その時代内の目的付き宣誓の引受け |

直後という関係は、指定した区分に相対的である。二時代の間に別の時代を選べば、以前の直後関係は成立しなくなる。未選択の時間まで埋まっていることや、世界全体で唯一の歴史区分であることは要求しない。一つの時代の内部に抜けがある場合、区間が重なる場合、選んだ区間が履歴の外へ出る場合は、この構成では不正な区分となる。

時代をまたいで生きる人は、両方の集団に所属してよい。二集団の構成員が全く同じでも、時代に対応する異なる集団として指定できる。反対に、構成員が全て入れ替わる場合も扱う。ここでの時代の後続は、血縁上の親子関係や、生物学的な世代の年数ではない。

`rjg`は母集団を前後で固定し、その中の人間で、その時代の少なくとも一状況に生存する人と所属範囲を照合する。単に集団に名前を付けたことを、時代の人々を同定したことにはしない。ただし、母集団の社会的な範囲、生存の一般的な定義、集団の制度的同一性は解釈の前提として残る。

`hzdf`では、全契約当事者が先行集団に属することを要求するが、その集団の全員を当事者にはしない。また、人が先行時代に生きていたという条件だけでは足りない。各人の引受け・宣誓・目的志向を結ぶ同じ行為が、同じ先行時代内で生じたことも要求する。別の時代での行為を流用できない。

具体例では、後続集団を前版の`hzdd`の知識主体へ固定し、その後続時代の中に改善が不可能な状況があるという閉じた内容を構成する。既存の`hzcq`によって、先行する契約当事者がその状態を生じさせるという内容へ接続し、静的な特殊化を使って`hzdf`の目的記述に渡す。目的の段階では、未知の知識状態・利用可能な方法・因果関係を評価しない。

この例は、現在の能力不足を将来へ流用しない。達成を評価する検査では、後続時代に同じ後続集団の情報拡大・誤りの修正が可能なら、現在にそれが不可能でも指定した結果を達成したとはしない。また、将来の不可能性が成立するだけで、先行する当事者の行為がそれを生じさせたとは認定しない。

ただし、`hzdf`へ渡せる目的は一般の閉じた内容である。型だけで全ての目的の対象が後続集団になるわけではない。今回の具体的な構成で対象・時代・行為者を固定した。集団全体を代表して契約する資格、規範的効力、全員の共同意図を、それだけで与えてはいない。

検査では、二区間の選び方と中間時代の採否による128通りを、集合と区間による独立した計算と照合した。集団の重なり・同一構成員・空集団・所属の過不足・母集団の違い・時間順序の循環など19対照例を調べた。原文側では目的と宣誓の4通り、行為が別時代にある場合や当事者が集団外にいる場合など6対照例、将来の結果と因果の4通りを検査する。

[一般文書](../examples/v014/successive-cohorts.noema)は2,103文字、[原文付き草案](../examples/v014/kant-successive-cohorts.noema)は131,311文字、[抽出文書](../examples/v014/successive-cohorts-core.noema)は8,774文字である。8定義を追加し、新しい原始記号・著者主張は追加していない。親文書の宣言と15件の主張を保持した。[意味規約](../data/kant-successive-cohorts-basis-v1.json)と[検査記録](../reports/successive-cohorts-v1.json)を保存する。

関連19テストが通過した。三文書のCLI解析結果は構文木と一致し、通常表記・簡略表記・独自文字v2の往復を確認した。抽出文書のSVGはXMLとして検査した。字形の視覚的な確認を行った結果ではない。

原文での時代の読み、集団を代表する資格、kann nichtの規範的な否認、verschwörenの否定的・共謀的含意、mussの必然性、啓蒙全体の進展への接続と著者帰属は未完である。未来の結果は存在する一状況として構成しており、全ての未来や必然的な結果を表したとはしない。原文の対応範囲は部分的な解釈注記として集計し、意味確認済み全文単位数は増やさない。
