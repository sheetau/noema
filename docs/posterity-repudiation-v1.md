# 後代の人による同じ決議の拒否

カントu0013第五文 `[1005,1264)` のうち、後代の人・同じ決議・拒否行為・拒否の資格を構成した依存群です。本文は第四文までの100主張を保持し、確認済み文字数を増やしません。

## 採用する読みと構成

`Nachkommen` は先行時代より後に生きる人々と読みます。血縁や相続資格を追加せず、直後の時代だけでなく同じ経過のさらに後の人々も含めます。`r5ds` は有効な時代区分、登録された先行時代の非空性、本人の人間性・生存、先行時代の全点より後という順序を結びます。先行時代にも生きていた人を排除しません。

`jene Beschlüsse` は同じ先行合意により採択された拘束の決定事項の全範囲とします。`h26bk` が合意・項目・固定した形成基準を結びます。非空性と全項目を要求しますが、一般的な複数形から正確な個数を作りません。採択だけで効力や正当性を認めません。

`verwerfen` は同じ決議を自分の判断・行為を拘束する根拠として受け入れないという実践上の方針を、応答行為として取ることとします。`r5dp` が受容内容、`r5dq` が同じ決議への応答と行為の実行、既存`h244j`の負極性の方針を結びます。単なる不履行や受容の不在では拒否になりません。受容内容は引用されるため、その真偽は拒否の判定で実行されません。

`r5dr` は本人・合意・決議の三対象に対する拒否行為の存在を内容にします。`r5dt` は同じ規範`h26ax`と後代の立場`h26bm`から、その内容への積極的な許可と反対要求の不在を既存`rdu`で構成します。特定の手段全てへの許可ではなく、拒否を選ぶことへの資格です。資格の判定は拒否の実行を要求しません。

`r5du` は前文の同じ六対象の候補`r5dc`を保ち、後代の各人・各時点・各決議へ資格を適用します。`r5dv` が正確な六対象列からその内容を返し、第五文の理由付けへ接続する入口です。

## 検証と限界

局所検査は、同じ応答・本人・合意・決議・極性、三時代の範囲、先行時代からの生存者、許可と反対要求の四組合せ、全員・全項目への量化、三列と六列の全位置および長さを確認します。未知の必須入力は拒否し、引用内の受容や実際の拒否を未知のまま資格を検査します。

量化の検査は候補・後代範囲・資格を型付き境界にして切り分けます。接続検査では候補`r5dc`のみ境界にし、三時代の構成と資格`rdu`を実評価します。`r5dc`自体の実評価は固定した既存報告を参照します。全てを大きな個体域で再展開する検査は行いません。
