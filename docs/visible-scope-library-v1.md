# 規範と局所参照を含む円文字辞書第4版

## 120語への拡張と旧版の保持

辞書第3版の80語を保存し、[規範と反事実](shared-norms-v1.md)の21定義と、[未知個体の導入・局所参照](shared-discourse-v1.md)の19定義を共有複合語として追加した。計120語の内訳は、従来の30単独語と90複合語である。意味の宣言は16基本関係・定数と104構成定義となり、新しい基本関係や単独字形は増やしていない。

各語の綴りは[公開綴り表](../noema/resources/visible-scope-vocabulary-v1.json)の2〜3部品で固定する。`give` で始まる語群は規範、`candidatecontingent` は比較条件、`inside` は局所参照と作用範囲の目印となる。これは綴りの命名規約であり、部品の語義を論理積にする規則ではない。正確な意味は、元のNative定義と型・引数・解釈条件に従う。

文書内で使う語は依存先も含めて可視導入する。導入標識に続く複合語の名前から、公開された同じ定義を取得する。文書専用の番号表、名前のハッシュ、付属AST、不可視のSVG属性を使って意味を復元する方式ではない。文書内で共有語を別の本体や基本関係へ置き換える入力は拒否する。未登録の複合名による局所定義は引き続き使える。

新しい入口は可視ヘッダーから辞書第1〜4版を区別する。旧文書に独自定義された複合名が、新版の共有語と同じ綴りであっても、旧版の意味を保つ。旧文書を第4版へ移す際に意味が衝突すれば拒否し、明示的な改名を必要とする。第1〜3版の辞書・検証器・固定画像は変更していない。

## 復号する型と作用範囲

追加40語の呼出しと、引用した関数参照を、それぞれSVGの円と線から復号する。型には行為記述、規範の多引数関係、参照状態の有限列、後続へ状態を渡す高階関数、個体を答える質問が含まれる。復号後の宣言・束縛・引数・引用を、描画前の正規化Native文書と照合する。

語ごとの検査は、型付きの呼出しを同じ呼出しと比較する式を用いる。これは型と構文の検査であり、高階の引数領域全体を実行評価した証明ではない。元の二つの意味検査報告と前版の辞書報告については、依存ファイルのハッシュが変わっていないことも確認する。

`normviolated`・`normfulfilled`・`counterfactualsupported` は階層0の記述を実行するため、これらの関数参照は階層1で引用する。他の37語は階層0で引用する。この階層も可視表記から復元し、既存の段階付き引用の制約を維持する。

局所参照の位置は、本文の参照状態に対する束縛情報として円文字で書く。語彙番号とは異なり、参照列の導入・追加・利用・閉鎖を同じ文書で表す。参照を共有する後続関数や質問の中でも、同じ位置と作用範囲を復元する。

## 文書全体の検査

7文書を改行込みのSVGから復号する。辞書一覧は、既存80語と追加40語の二つの独立した文書とし、各文書が可視ヘッダーと必要な導入を持つ。残る5文書では、次の意味を評価する。

| 文書 | 評価する区別 |
| --- | --- |
| 規範 | 指定極性に許可と要求がある一方、実行記述は不成立であり、未履行となる |
| 比較条件 | 同程度の二候補の一方だけで帰結が成立する場合、全称条件と可能条件が分かれる |
| 局所参照 | 存在量化した個体を後続検査で絞り、同じ位置の一意性と同定を保つ |
| 作用範囲 | 区間内で導入した参照を外へ出さず、条件では前件の全成功状態を検査する |
| 質問 | 同じ局所参照の候補と評価状況を、型付きの問いとして復元する |

評価は二個体・三状況のモデルで行う。比較条件の例は三つの異なる状況を量化し、優先関係の検査を含むため、この診断に限り評価ステップ上限を100万に指定する。他の例は通常の10万を使い、処理系の既定値は変更しない。字形768・可視図形4096・128行などの文書資源制限も従来どおりである。

この結果は、未知の関係を入力しても意味を自動認定できるという主張ではない。規範の採用・根拠、比較候補の適切さ、指示や同定の入力規約は元のモジュールと同じまま保持する。二作品全体を全宣言込みで新書式へ変換する作業と、第三者による学習・読解は残る。

## 入出力と再現

最新の入口は `scripts.visible_language_page` である。[局所参照のNative例文](../examples/v016/visible-scoped-language-v1.noema)を公開語名で編集し、円文字へ変換できる。`--public-names` は書き出し時に公開名を可視名へ変換し、読み戻し時にヘッダーで選んだ辞書の公開名へ戻す。

```powershell
python -X utf8 -m scripts.visible_language_page render examples/v016/visible-scoped-language-v1.noema output/visible-scope-library-v1/referents.svg --width 3200 --public-names
python -X utf8 -m scripts.visible_language_page decode output/visible-scope-library-v1/referents.svg --native --public-names
python -X utf8 -m scripts.project_work check --module scripts.check_visible_scope_library --tests tests/test_visible_scope_library.py --prepare --verify reports/visible-scope-library-v1.json
```

[検査報告](../reports/visible-scope-library-v1.json)は各語の字形数・図形数・依存導入数と、文書ごとの復号・評価結果を記録する。`--prepare` は `output/visible-scope-library-v1/` に7枚のSVGと、10語ずつの語形一覧 `scope-forms-1.png` 〜 `scope-forms-4.png` を生成する。PNGの英語ラベルは語形を探す索引であり、復号器へ渡す意味情報ではない。機械的な図形復号と、人が画像から読解する試験、ラスターOCRを区別する。
