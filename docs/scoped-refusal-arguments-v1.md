# 義務と裁量、および仮定の範囲内での拒否の論証

カントu0015の接続語alsoを、前提と結論を同じ仮定範囲に置く談話の構造へ部分接続した。義務があること、本人が義務だと判断すること、名称を実際に拒むこと、著者が拒否を帰結として提示することを分ける。

| 定義 | 内容 |
| --- | --- |
| `rnx` | 同じ評価出所・本人・立場・政策・文脈で、`rm7`の義務があれば`rnk`の実行／不実行の裁量はないという条件内容 |
| `rny` | 同じ著者・文脈・仮定範囲での前提採用と結論提示を、異なる本文箇所・本文順序・帰結提示の関係で結ぶ |
| `hzf5` | `rny`を共通の談話関係`ug`・`uh`・`ud`・`ue`へ接続する |
| `hzf6` | `rnx`を既存の政策要求・許可`h7k`・`h7l`へ接続する |

義務と裁量の関係は既存定義から従う。同じ有効な引数に対して、`rm7`は政策の実行要求を必要とする。一方、`rnk`は実行と不実行の両方を許し、それぞれに反対する要求がないことを必要とする。不実行についての裁量には実行要求の不在が必要なので、実行義務とは両立しない。不正な引数では義務の前件が成立しない。この関係は政策の実際の実行や、本人の認識を要求しない。ここでの裁量は規範上の両方向の選択であり、身体的な能力や制度上の権力とは異なる。

接続例の前提は、本人が同じ自由政策を義務だと判断する内容である。これは義務そのものではない。結論は、同じ本人を名称の対象とし、その名称を適用しないよう求める内容を表明する行為である。前提と結論を閉じた記述として渡し、同じ著者・文脈・仮定範囲に結ぶ。引用時には判断や拒否の内容を実行評価しない。判断内容にある既知の政策記述への脱引用一箇所を、静的な特殊化で解消した。

`rny`は、文章中でその帰結を提示したという関係を表す。その推論が論理的に妥当であることや、前提から心理的に拒否が生じることは保証しない。本人が義務だと考えていることから、実際の義務や拒否を自動で導かない。関係節内の仮定を扱うため、ある君主が現在存在し、実際に拒否したという無条件の主張も追加しない。本文順序は出来事の時刻の順序ではない。

`ug`と`uh`は、他の文書群ですでに使っている「仮定範囲内の前提採用」と「その範囲内での結論提示」の原始関係である。共通の意味規約をそのまま取り込んだ。今回のカント文書への追加は原始記号二つと定義四つであり、新しい言語演算子や著者主張は増やしていない。親文書の宣言と15件の著者主張を保持した。

[一般文書](../examples/v014/scoped-refusal-arguments.noema)は6,639文字、[原文付き草案](../examples/v014/kant-scoped-refusal-arguments.noema)は192,337文字、[抽出文書](../examples/v014/scoped-refusal-arguments-core.noema)は8,393文字である。[意味規約](../data/kant-scoped-refusal-arguments-basis-v1.json)と[検査記録](../reports/scoped-refusal-arguments-v1.json)を保存する。

要求・禁止・両方向の許可の16通りと、信念・拒否・前提採用・結論提示・帰結提示の32通りを検査した。原文付き文書と抽出文書では、著者・範囲・文脈・内容・根拠・順序・箇所の取り違えを含む十条件ずつを検査した。追加15テストで、実際には偽の前提や結論を仮定内で扱う場合、引用の非実行、未知の規範・結論関係、人物の取り違え、共通関係の意味規約の保持を確認した。三文書のCLI解析、正規形と固有文字v2の往復、SVGのXML検査も通過した。SVGの目視確認は含めない。

原文のalsoに対する論証の接続候補であり、原文の意味確認を終えた訳ではない。君主一般の量化、前段の品位判断からの接続、名称批判の根拠、自らという強調、啓蒙・称賛・政府による解放、後続本文は未完である。談話関係が型検査に通ることを、著者の意図した論証を十分に記述した証拠には数えない。
