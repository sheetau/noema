# 第二・第三関係への実験的アクセス

u0265の「実験で調べ得る運動の性質」に向け、既存の第一項の比較`erw`に加えて、第二項の電位降下と第三項の局所曲率半径を検査する構成を作る。今回は意味依存群であり、列挙する取組と(A)からの帰結の提示はまだ追加しない。旧444主張と全文判断279件を保持する。

電位降下は、始点と終点を持つ同じ過程を測定対象にする。`et7`は実軌道・実静電場・全電位区間・電位の積分と仕事の対応`er7`へ、同じ過程の実エネルギー取り出し`eoy`を結ぶ。終端の粒子時点だけを対象にして、別の始点や別の過程の電位差を混ぜない。速度・質量・電荷の各測定は、その同じ過程の同じ電子・終端に結ぶ。検査条件`eud`は初速零、緩い加速、無放射、閉収支を保持し、第一(A)や運動エネルギーの速度式を含めない。

曲率半径の量内容`eua`は、校正された実三次元軌道の一階・二階微分と`sevc`による幾何学的定義である。磁場や力学法則は半径の定義に使わない。第三項の検査条件`eue`では既存`esp`の標準配置・全非磁気的寄与の接線条件・qN>0を採るが、第二(A)や予測半径式は要求しない。一般の量内容と、この項の物理的な適用条件を分ける。

低速慣性質量`eub`と非零の符号付き電荷`euc`も、それぞれ既存の物理的帰属に結んだ量として測定する。速さは既存`erm`、磁場z成分は`equ`を使う。全チャンネルについて校正と信号取得`eqv`、検査対象の公式を算出・校正の前提にしない`eis36`、同じ可能な過程内での記録共有`eis3u`を要求する。Vは同じ既存の校正単位系の光速度定数である。

第二項は測定された終速度・質量・電荷から`esa`で予測電位差を定め、第三項は測定された速さ・質量・電荷・磁場から`esr`で予測半径を定める。予測の数値条件と、観測値に対する`eis37`の比較操作を分け、一致判定が数値の等否と合うことを要求する。一致していなければ検査不能、とはしない。原文にない計算回路や全実数の全桁出力は追加しない。

`euh/eui`は一つの同じ設定の全測定・比較過程を存在量化し、`euj/euk`が現在の各項へ固定する。`eul`は第一項を含む全三項へのアクセスである。全項を同時に一つの装置で測ること、全実験法や全ての電子への普遍性、実験の実施済みを追加しない。未知の関数域の評価は拒否し、束縛位置の有限診断と下位の本体の検査を分ける。
