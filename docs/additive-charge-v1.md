# 領域内の符号付き総量と電荷密度

前版では、球内の総電荷と体積の比の極限から局所密度を説明した。今回は、その総電荷に必要な加法性と領域の一致条件をNoemaで記述し、密度の定義へ接続した。総量を単に半径ごとの数値表として与える場合に、領域同士の関係を無視できる不足を補う。

| 定義 | 内容 |
| --- | --- |
| `seoo` | 指定範囲内の全点で所属が一致する二領域 |
| `seop` | 指定範囲内で重ならない二領域 |
| `seoq` | 空領域を含み、和集合と差集合で閉じ、同じ領域の別表現を同じように受け入れる定義域 |
| `seor` | 空領域では零、同じ領域では同じ値、重ならない領域の和集合では値の和となる符号付き総量 |
| `seos` | 定義域内の領域と、その総量関数による値を結ぶ |
| `seot` | 指定した座標時刻を持つ有効な四座標の点 |
| `seow` | 定義域内の各領域について、四座標が同じ点表現で所属が一致する条件 |
| `seou` | 元の電荷帰属に、同時刻の領域族・総量・単位の整合性を課す |
| `seov` | 整合性を課した総電荷の帰属を、既存の密度と速度の説明へ渡す |

総量の定義域を明示し、空間全体や全ての部分集合に有限な値があるとは要求しない。Noemaの関数自体は全引数に値を持つが、定義域外での値を量として採用しない。定義域内では、領域の別表現を使っても同じ値になり、分割と再結合で値が変わらない条件を課す。対象範囲外の所属を変えても、定義域への所属と総量は変わらない。

電荷は符号付きの量として扱う。例えば二つの部分の値が3と−3なら、両方を含む領域の総量は零になる。このことから領域が空であることや、電荷がどこにもないことは導かない。領域を広げても負の寄与が加わる場合があるため、非負の測度に課す単調性も要求しない。

空間への適用では、同じ系・出来事・時刻単位・文脈での座標時刻を使って対象範囲を切る。領域族と総量関数には、系・出来事・長さ単位・時刻単位・電荷単位・文脈を同じ順で渡す。別の出来事や単位の関数を使って、偶然同じ数値になっただけの値を流用しない。

点の表現についても条件を加えた。既存の点型は、軸を引数にして座標値を返す関数であり、四つの軸以外の引数にも値を持てる。四座標が等しい点を、それ以外の値で別の場所として数えてはならない。`seow`は、採用する全領域が四座標の一致を尊重することを要求する。関数としての内部の違いを、空間の第五の座標にはしない。

有限加法性だけでは、電荷と別種の量を識別できない。そのため、元の電荷帰属も条件として保持した。今回の追加は、その帰属へ領域と総量の整合性を課す構成である。電気的作用を使った同定、測定・校正の基礎説明、一般の積分との接続は残る。可算加法性や、特異な分布でも局所密度が必ず存在することは、この有限加法性からは主張しない。

一般用の五定義は、個体の集合を領域にする。三個体の有限解釈では全8領域と全ての領域対を量化して、空領域・閉性・所属の一致・加法性を検査した。12の解釈で、正負・零・空の対象範囲・限定された定義域を受け入れ、欠落した空領域、和・差に閉じない定義域、範囲外への依存、零でない空領域の量、加法性の不一致を拒否した。定義域外に便宜的な値999を与えても、定義域内の条件は変わらない。別の16例で各領域の値と誤った値を比較し、相殺による零を確認した。

空間版の五定義は、同じ構成の個体型を四座標の点型へ置き換えたものであり、構文木を比較して一致を確認した。電荷帰属への接続は正負・零の3例と29の対照例を使い、元の帰属、分布、系・出来事・単位・文脈、時刻、領域族、総量関数の取り違えを検出した。座標表現の条件自体を具体的な領域と二点に適用し、同じ四座標なのに内部値で所属を変える例を拒否するなど5例を検査した。

接続検査における空間全体の加法性と表現の一致は、明示した検査用の解釈に依存する。有限集合での全領域の検査は、連続空間の全領域の証明ではない。空間版の条件をそのまま有限解釈器へ渡すと、実数を表す切断への全域量化を拒否する。これらの区別は[検査記録](../reports/additive-charge-v1.json)に保存した。
