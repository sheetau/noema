# 文語0.7：集合への適用と成員ごとの分配

文語0.7は、複数対象への適用を未指定のまま保持する0.6の記法に、集合全体への適用と、直接の成員ごとに本文を述べる分配を加える。文書の先頭は`noema g g`、短縮記法は`g:`。基本概念91個と32文字は増やさない。自然言語からこの区別を抽出する処理は未完成であり、今回は直接記述・解析・整形・固有文字表示の仕様である。

## 集合全体への適用

`w-w 役割 [ 節 ]`は、指定した役割にある集団を一体として、その節を述べる。主体の`i`なら共同の主体として、対象の`j`なら対象の集まりを全体として扱う。集団の恒常的な属性ではなく、その節への適用の仕方である。

```noema
g:w-w i[no w[mu][si] fo].
```

犬と猫を共同の主体として、子供を見る。各成員が別々に見るという命題へ自動展開しない。同じ集団を別の文で指したときに、この指定を引き継がせない。

`w-w`の直下には節、または別の役割の`w-w`を置く。同じ役割の重複指定は拒否する。対象には明示された集合が必要で、数量2の対象や未指定・質問変項へ共同性を補わない。否定・条件・分配をこの標識の直下へ置き、どの節に適用するか曖昧にする記述も拒否する。否定は適用された節全体の外へ置ける。

```noema
g:u[w-w i[no w[mu][si] fo]].
```

これは共同の主体として見ることの否定であり、各成員が見ないこととは区別する。共同参加の具体的な協力方法、同時性、各人の動作の同一性まで追加しない。

## 成員ごとの分配

`w-p 参照名 [ 集合 ] [ 本文 ]`は、集合の直接の各成員について、参照名をその成員に結び付けて本文を述べる。本文では`p 参照名`で成員を指す。参照名は本文の内側だけで有効である。

```noema
g:w-p a[w[mu][si]][po p a].
```

この例は犬についても猫についても眠ることを述べる。意味は、明示された成員集合を`G`、参照名を`a`、本文を`B`として、`∀a ∈ direct_members(G): B(a)`である。全ての犬や猫という種類全体の量化ではない。別々の成員について本文を満たすが、出来事IDの同一／不同まではこの版で表していない。

集団全体も再び指すには、通常の`o`による参照登録を併用する。

```noema
g:w-p member[w[mu o dog][si]o pets][no p member p dog].
w-w i[po p pets].
```

分配の局所参照`member`と、通常の対象参照`dog`・`pets`は別である。本文に書く通常の対象は文書内の同じ対象IDを保ち、分配の回数だけ新しい対象を生成しない。分配内の対象を別の成員ごとに新しく存在させる存在量化はまだ別の課題である。

既に有効な局所参照や通常参照と同じ名前は使えない。本文内で同じ名前を通常参照として登録することも拒否する。分配の外へ局所参照を持ち出せない。一つの分配が終わった後、独立した分配で同じ綴りを再利用することはできる。

## 否定と接続の作用範囲

次の二つは異なる意味構造になる。

```noema
g:w-p a[w[mu][si]][u[po p a]].
```

各成員について眠ることを否定する。

```noema
g:u[w-p a[w[mu][si]][po p a]].
```

全ての成員について眠ることが成り立つ、という全体を否定する。一方が眠り、他方が眠らない解釈では、前者は偽、後者は真になる。否定を分配の内外へ動かす正規化はしない。

条件や論理積・選択の接続、質問・依頼も、記載した範囲を保存する。

```noema
g:w-p a[w[mu][si]][y[wm p a][u[po p a]]].
```

この例では各成員について、空腹なら眠らないという条件を述べる。条件全体と分配の順を入れ替えない。

## 入れ子、型、数量

分配は直接の成員だけを対象にし、入れ子の集団を平らにしない。集団の各成員が全て集団である場合は、局所参照を次の分配の対象にできる。

```noema
g:w-p team[w[w[mu][si]][w[fo][mu]]][w-p member[p team][no p member p team]].
```

内側では各成員が所属する直接の集団を見る。外側の参照`team`も有効なままである。異なる二集団を独立に分配すると全ての組合せになる。列挙順に一対一で対応する意味を補わない。

```noema
g:w-p a[w[mu][si]][w-p b[w[fo][mu]][no p a p b]].
```

型検査は、その局所参照が取り得る全ての成員について行う。人と場所の混合集団の各成員を、対象型だけを許す主体役割へ置くことはできない。局所参照に共同適用する場合は、その参照が取り得る全ての成員が明示的な集団でなければならない。

```noema
g:w-p team[w[w[mu][si]][w[fo][mu]]][w-w i[po p team]].
```

数量指定された対象の内部は列挙されていない。`w[mu m c][si]`への分配は「数量2の犬という成員」と「猫という成員」への分配であり、犬を未知の2個体へ展開しない。個体ごとの数量量化、存在・割合・選択の量化、対応するペアの指定は未実装である。

局所参照を新しく作る集合の成員に埋め込む構文は、この版では定義しない。集合ノードは従来どおり文書の対象参照だけを成員とする。式の深さと集合の深さはそれぞれ64段まで。

## 意味JSONと互換性

分配は`kind: each`、`group`、`variable`、`body`の4フィールドで表す。`group`は集合の参照IDまたは外側の局所参照、`variable`は本文内の変項名、`body`は式である。局所参照の形は`{"bound":"va"}`。これは対象ノードのIDでも質問用の`{"query":true}`でもない。

集合全体への適用は`kind: collective`、`role`、`body`の3フィールドで表す。`role`は既存8役割の識別子、`body`は節または異なる役割への共同適用である。新しいフィールドを古い節へ暗黙に追加する方式ではない。

正規化は局所変項を出現順に付け直す。束縛名だけが違う表現は同じ正規形になる。対象の同一性、集団の入れ子、局所参照と通常参照、否定・接続の順は保持する。保証する往復は`parse(format_graph(document)) == normalize_document(document)`。

0.1〜0.6の意味を保って0.7へ変換できる。0.7の新演算子がある文章を旧版へ戻すと拒否する。成員への分配を単なる集合の節に置き換えたり、共同性を未指定へ変えたりしない。演算子を使わない文書は、変換先で表せる範囲なら元へ戻せる。

二つの標識は、既存の結合文字`w`と参照文字`p`から作った文法語である。全体への適用は`w-w`、成員の参照を伴う分配は`w-p`とする。合成の規則を学ばずに字形だけで意味を理解できるとはしない。独自字形の単位・既存フォントを再利用し、英語の語へ字形を当てる変更ではない。

## 検証と残る課題

全396テストで、否定の異なる真理条件、局所参照の範囲・名前の正規化、入れ子・型・数量・質問・依頼、旧版との往復と意味を失う変換の拒否を確認した。本文中の用例も解析・往復の検査対象に含む。モデル依存ライブラリを読み込まないCLIでも動作した。

[実HTTPの検査](../reports/written-v07.json)では8例について完全記法・短縮記法・固有文字の計24入力が同じ意味構造に戻った。本文外の局所参照を拒否し、旧逆変換が共同性や分配を落として訳さないことも確認した。[実ブラウザー](../reports/written-v07-browser.json)でもダークモードの入力、固有文字による再解析、新しい説明を確認した。人による読み書きの成績ではない。

8例の全文字数は完全記法537、短縮記法322だった。ヘッダー・空白も含めた同じ意味のNoema表記の比較であり、自然言語より短くなったことを示さない。新しい意味の区別のための負担と、まだ削減できる冗長さは引き続き測定対象にする。

既存英語解析の回帰では「The dog chases the cat.」が確定し、「A dog chases a cat.」は未確定だった。コミット`27b21cf`の変更前のコードと同じ重みでも同じ結果であり、今回の文語拡張による後退ではないが、自然文の広い対応という目標には届いていない。主画面の解析器は、この版の集合への適用や分配へ未接続である。
