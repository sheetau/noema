# 旧来の力の言い表し

u0174、原刊909末尾から910頁の第一項を扱う。固定原文の全体、M0318のv/V、頁境界A0024を対応記録へ保存する。必要な意味要素は、点状の単位電気量が電磁場で動くという条件、電気力に加わる作用、引用用語、二次以上を省く留保、速度と磁気側の場の外積を光速度で割る順序、旧来の言い方という位置付けである。

同じ対象の運動・量・位置は`ejxm`、静止時の電気基準力と単位は`ejwu`を再利用する。新しい`eisqp`は、同じ場・地点・量・系・単位で速度も入力とする理想的な試験応答を物理的に帰属させる。静止試験の`eispt`を速度入力へ拡張した概念であり、外積や特定の力の公式を基本関係に含めない。異なる速度の入力は同じ背景での仮想比較で、同じ出来事に複数の実速度を与える条件ではない。

`ejx7`は実際の速度における応答、電気基準、両者の差を同じ対象・評価出来事・K・Dynへ接続する。全寄与と追加寄与を別の記録として保持するが、追加値が非零であることは要求しない。これにより、電動力という語を、同じ機械的な応答から電気基準を引いた寄与として読む。電位差、回路の電源、独立した新実体の意味は加えない。

第一項の速度は三成分を直接扱い、x方向へ制限しない。同じ三速度uをparameter倍し、場・地点・電気基準・応答規約を固定してparameterを0へ近づける。`ejx6`は各成分について、追加応答と(parameter·u × H)/Vの差をO(parameter²·(u·u)/V²)へ結ぶ。これは原文の「v/Vの二次以上を無視する」を、一次部分を保つ意味として読むものである。固定した場と方向ごとの定数・近傍を許し、全場一様性、解析性、有限速度での厳密等値を加えない。三方向の数式を記述することと、場変換から任意方向の力の法則を証明することは別である。

二つの言い表しは直前の場変換の解釈なので、正のVと光速未満の速さという既存の適用域を明示する。量と場の単位の積を同じDynへ直す換算1を、電気側では`ejwu`、磁気側では`eirn`と`eispu`へ結ぶ。現代SIの係数や異なる単位の数値の一致は持ち込まない。

`eisqq`は引用して取り上げる用語を、同じ追加ベクトルの閉じた役割規則`ejyg`へ結ぶ。ここでの引用符は用語を取り上げる働きと読む。`eisqr`は第一項を既に使われてきた言い方、第二項を今回新しく提示する言い方として対置する。旧表現の誤り・廃棄、歴史上の初出、皮肉や他人の発言を追加しない。本文の条件付き主張と用語の意味を分け、引用から法則の真理を認定しない。

検査は実際の型のベクトル演算、物理応答の全引数、対象・系・出来事・単位・場・記録の取り違え、全三成分の差、任意方向・符号・平行・零磁場、二次・三次の差と定数・一次の誤差の対照を行う。漸近条件の有限診断では、明示した低次数多項式の応答族とその係数を見る。これは任意の実関数の漸近性の自動証明ではない。全実数・全関数の量化は有限処理で拒否し、未知入力の拒否を保つ。存在証人の結合は二値の診断域で全位置を調べ、本体の実際の型の検査とは分ける。
