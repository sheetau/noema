# 同じ軍事集団の任務・準備能力・人数

第十段落第一文の `zahlreiches Heer` を、軍務を担う制度的な集団に、指揮担当と構成員の任務、実際の武力行使の準備能力、文脈上の基準を満たす人数を結ぶ読みで具体化した。既存の軍事組織分類は武装警察や単なる武器保有集団と区別する。陸海軍の歴史的境界や、この語の全用法に対する必要十分条件を主張するものではない。

任務には、既存の武力行使準備能力 `hzzmission` の閉じた記述を渡す。同じ指揮者・制度・集団・対象共同体について、既存 `rwb` が全構成員の役職と任務上の責任、指揮担当者の役職を結ぶ。割当があることと実際に準備能力を持つことは別条件である。指揮担当者が兵の一人であることや、現実の戦闘、指揮権の政治的・法的正当性は追加しない。

準備能力の内容は既存 `rwf` を保持する。同じ集団の構成員が、対立集団の別人に身体的制約を行える道具を向けて使用する活動を、同じ共同体に関する方法で遂行できるという読みである。現在の負傷や強制の発生とは分ける。名簿と任務と準備能力には同じ成員関係を使い、別集団の成功を人数や任務の条件に流用しない。

人数は、固定した文脈上の閾値と比較する。その閾値は1より大きく、評価点の名簿が実際の全成員と過不足なく一致し、非空・重複なしであることを既存 `rcm` で確認する。原文に具体的な人数を補うことはしない。閾値や名簿を結果に合わせて選び直すことも許さない。

六定義 `r6e6–fd` と、閾値・名簿の二入力を追加した。旧入力宣言25個は構文を保存し、旧資料でまとめて説明されていた意味を個別の規約にした。旧 `xa/xd/rwb/rwf/hzzmission` の内容も変更していない。

検査では、同じ任務記述の割当、全成員の人・役職・責任、同じ集団の人数、別制度を混ぜない存在量化を調べる。軍事的準備の実内容は一つの局所モデルで評価し、道具や結果の詳細な対照は同じ既存定義の固定済み検査を再利用する。存在量化の接続は二値域で検査し、大きな人物域と軍事的能力の本体を掛け合わせて列挙しない。

規律、手元で利用できること、公的平穏の保証はまだ必要である。旧共同保護モデルが守る活動可能性・保有を、公的平穏と同一視しない。第一文全体の統合・通読は未完で、本文119主張と19単位の意味判断、確認文字数を保持する。
