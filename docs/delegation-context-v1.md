# 代行例の目的と努力を解釈する範囲

「自分で努力する必要がない」という条件文について、現行の式へ与える文脈を固定した。従来の意味規約は目的と努力の範囲を解釈の前提として要求していたが、この文に何を採るかが未確定だった。本文・文法・基本関係・定義は変更せず、登録簿v52の文4と文42を対象に読解記録と結合検査を追加する。

## 採る読み

[原刊482頁](https://www.digitale-sammlungen.de/de/view/bsb10926843?page=522)では、理解・良心・食事と生活の判断を他に任せる三例に、本人の努力の不要が続く。その直後には、本人が考える必要と、支払い・他者の引受けを述べる文がある。この前後関係から、問題の努力を、用事に必要な判断を自ら行う取組みとして読む。身体活動・支払い・指示に従う動作まで不要だとする読みは採らない。

| 対象 | 固定した解釈 |
| --- | --- |
| 本人 | 仮定例の一人称の位置。前件・後件・仕事の受け手で同じ人を保つ |
| 目的 | 理解・道徳的評価・身体の生活調整に関わる本人の実際上の用事を処理できること。自分で判断したことを達成条件へ含めない |
| 努力 | その用事の判断を本人が自ら行うための取組み。他者の努力や無関係な活動とは分ける |
| 方法 | 仮定状況で本人が利用可能な方法。現実の選択・実行は要求しない |
| 結果 | 同じ方法に属する非空の評価範囲。日常の実用的な可能性に関わる文脈で選ぶ |
| 仮定状況 | 提示文脈を基準に同じ本人を置く非空の範囲。前件が成り立つ各場合で後件を要求する |

これは省略された目的語を原文の明示的な列挙として復元する処理ではなく、前後関係に基づく意味規約の適用である。無関係な満足や別人の成功は目的達成の代用にならない。供給された判断の正しさ、現実の達成、著者による生活態度の推奨も付加しない。

本文sxは選ばれた結果に関する達成可能性を述べる。論理的に可能な全結果で成功する保証ではない。結果範囲を変えると意味も変わるため、失敗例を見た後にそれだけを除外して同じ解釈だと称することはできない。構文検査だけでは、外部から与えた評価範囲が文脈に適切かどうかまでは決められない。

前件の三供給元が成功方法を因果的に作り出すという別の主張も追加しない。条件文としての結合と、機構を説明する文は区別する。前件を満たす場合が一つもなければ条件文だけが真になることがあるため、適用可能性reを別に照合する。

## 検証

二つの仮定状況を同時に使う十六対照で、片方だけの失敗、本人の努力、別人・別目的の成功、他者の努力、仮定範囲と基準、前件の不成立、方法の利用可能性、空または範囲外の結果を検査する。失敗結果を含める場合と除外する場合も明示的に比較し、両者を同じ成功保証とは数えない。意味の定義を検査用の基本関係へ置き換えてはいない。

結合検査は純粋な評価のメモ化を使う。目的と結果範囲の四対照では、実際のsx以下の定義を通常評価でも実行し、一致を確認する。目的・努力・結果選択が未知なら補完しない。著者による提示の十二対照では、努力の事実を未知のまま扱う。四テストに加え、読解記録の原文範囲・意味の依存先・出典ハッシュと、三記法の往復を照合する。
