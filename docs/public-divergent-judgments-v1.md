# 異なる判断の公的な提示・吟味の目的・残る職務義務

カントu0015の公的な提示について、前版の個人的判断と教理の相違を、発言の許可・職務義務の保存へ接続した。五つの合成定義と、閉じた式を結ぶ構成処理を追加した。新たな原始記号や著者主張は加えていない。

## 同じ発言を各条件で共有する

本人の基準内容と組織が採用した基準を、同じ論点について比較する。その本人の基準から主張の発話を作り、同じ主張を同じ公衆が吟味することを目的内容にする。本人がその主張を自分の立場で公的に提示するという実行内容を、一つの閉じた記述にまとめる。

| 構成 | 接続する内容 |
| --- | --- |
| rpi | 本人の基準に同じ論点を一つの引数として与え、その内容を主張する発話を作る。 |
| rpj / hzgx | 同じ論点についての本人の判断・基準との差・組織による同じ基準の採用を結ぶ。hzgxはfa・fbへ接続する。 |
| rpk | 同じ本人・活動・文脈について、人物の条件、実際の提示、目的への意図を結ぶ。 |
| hzgy | hzgx、自己帰属を持つ公的提示hzb4、同じ目的への意図hzuを、本人と活動から実行内容への関数にまとめる。 |
| 既存hzgu | この実行記述への許可と、同じ実行が成立する比較候補で職務要求が残る条件を結ぶ。 |

許可の対象は、単に「何かを話す」という別の記述ではなく、上記の実行内容そのものに固定する。発言の内容が別の論点へ替わること、判断とは別の内容を伝えること、別の目的や別人の立場で話すことは、同じ実行には数えない。

## 閉じた構成の手順

[bind_presentation](../scripts/compose_public_divergent_judgments.py)は、本人の基準・標準基準・論点・公衆・役割・経路などの閉じたNoema式を受け取る。基準は明示的な引用で渡す。主張と目的を独立した入力として受け取らず、次の順で導出する。

1. rpiを本人の基準へ静的特殊化し、同じ論点の主張を作る。
2. その同じ主張・論点・公衆について、既存hzxの吟味を目的内容として引用する。
3. hzgyを二つの基準へ静的特殊化し、主張と目的を結んだ実行内容を引用可能にする。
4. その同じ実行記述を既存hzguの許可と義務保存へ渡す。

自然言語から内容を推測する処理ではない。全て通常のNoema式の接続であり、生成モデル・指示プロンプト・対訳辞書は使わない。検証例では五箇所の脱引用を静的に除去した。元の文書は変更せず、特殊化した定義を追加する。

hzgyという一般定義単独では、主張と目的を任意に受け取れる。この接続の保証は、同じ入力から両者を作るbind_presentationの構成結果についてのものである。自由変数の混入、主張や目的の独立した差替えは構成処理が拒否する。

## 許可と実行を分ける

許可があっても、発言・個人的判断・公衆の判断が既に起きているとは限らない。対象の条件を満たす実例がなければ、義務を免除しない条件は空虚に成立し得る。実例を持つ条件rp6と、同じ候補で義務も履行するrpaを別々に確認する。

実行する候補では、同じ基準の採用、本人の同じ論点についての判断、学者としての公的使用、実際の提示、自己帰属、同じ吟味目的を要求する。目的を持っても、実際に公衆が評価したことや、その評価が正しいことは要求しない。本人の判断内容は現在の状況で偽でもよく、許可を真理の保証にしない。

職務義務が残ることと、その義務を履行することも別である。発言が実際に起きる候補で要求が消えていれば、発言そのものへの許可があっても、義務保存を含む条件は成立しない。

## 原文対応と残る範囲

対応表では既存の職務義務・教理との差異の二箇所を再利用し、「in der Qualität der Gelehrten, frei und öffentlich der Welt zur Prüfung darlegen」を新しい部分注記として加える。「Unter ihm」の君主への照応、「verehrungswürdige」の評価、聖職者という名詞、「Einsichten」の洞察としての含意まで記述したとは数えない。

一つの論点についての一回の提示を結べた段階である。複数の判断・洞察を示す一般化、対象となる聖職者の範囲、君主による許可への照応、続く「職務に制約されない他の人にはなおさら」の比較は残る。これらを揃えて文の量化と著者への帰属を記述する必要がある。目的・公衆・学者・教理の基礎的な説明、職務義務の網羅性、因果的な無妨害、全文の意味確認も未完である。
