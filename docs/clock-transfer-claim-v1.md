# 移送時計の到着時の遅れ

u0126は、前の単位秒あたりの遅れから「特有の帰結」を予告し、続く一文で二時計の移送を述べる。Kで静止して同期する二時計の一方をAからBへ直線に沿って速度vで運ぶと、到着直後の同所比較では指示が一致せず、運ばれた時計が遅れる。その量を所要時間tと速度比の二乗の半分で表し、四次以上の量を除くという留保を付けている。

初期同期、全時間の直線移送、B時計の残留、同じ到着出来事と場所での表示には、前回の現在記録と完全な代表軌跡の定義を使う。非同期はこの同所比較で指示が等しくないこと、遅れは移送時計の指示が小さい方向である。原文が指定していない到着後の再調整や無限の未来にまで差の不変性を付け加えない。

tはKでの出発から到着までの正の経過を秒にした数値である。到着指示差にも同じ正の換算尺度を使う。本文の末尾の説明をこの量の規則へ結び、以前の座標時刻と綴りだけで同一視しない。初期の両指示には共通の原点を許すため、遅れを出発時刻そのものから計算することもない。

近似の残差は、前段の厳密な一秒あたりの遅れ率に基づいて構成する。固定した所要時間Tについて、T(1−√(1−u²))をTu²/2で表す誤差がu=0の近傍でO(u⁴)となる、という明示した読みである。全実数近傍の共通定数・近傍幅を保持する。距離を固定してTも速度に依存させた族の一様な四次評価や、具体的な残差係数は追加しない。

原文の条件付き主張は、初期同期と移送の設定を前件として保持する。一方、厳密な遅れから近似を構成するための、移送中の率f、B時計の率1、発進停止で追加の指示変化がないという区間法則は、発話の外側の解釈注記に置く。著者がこの追加前提を明記したことや、原点時計の慣性運動から加速応答まで証明したことにはしない。

導入のHierausは前の遅れの内容を参照し、folgendeは同じ後続の条件付き結果を指す。eigentümlicheは通常の予期から外れる帰結としての著者の評価と読む。Kantで用いた一般的な特異性の提示規約と同じ意味を、この本文の引用型で適用する。単なる注目価値や数値的な稀少性へ置き換えず、評価の帰属から引用内容の真理を導かない。

有限検査、通読による意味判断、物理的真理の証明は別である。u0127の折れ線と帰還、u0128の曲線と地球上の時計は、今回の単一直線移送とは別に接続する。
