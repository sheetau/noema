# 同じ制限と啓蒙への比較の接続

前回の質的比較へ、要求群と介入要因の対応、比較する啓蒙の同一性を接続した。[Noema](../examples/v016/aligned-restriction-influence.noema)・[意味規約](../data/aligned-restriction-influence-basis-v1.json)・[検査報告](../reports/aligned-restriction-influence-v1.json)に構成と限界を保存する。本文の二問への著者帰属は未統合で、確認済み文字数は増やしていない。

## 要求の存在と履行を分ける

一つの要求記録は、出所・宛先・役割・活動・内容記述・極性を保持する。`r2vl` は固定した非空の記録群の全要求について、有無が指定したフラグと一致することを調べる。「全要求あり」と「全要求なし」は別の内容となる。

要求されたことと、その通りに行動したことは同じではない。要因を切り替えるのは要求の存在であり、服従したかどうかではない。`r2vm` だけが内容を評価し、同じ本人の自由選択候補に、その内容の極性に適合しないものがあることを確認する。これは選択肢への制約を記述するためで、現実の違反を主張するためではない。

内容記述は段階1とし、内部で別の記述を評価する履行条件も保持できる。統治者の既存 `r2ud` を段階0へ無理に引用しないためである。要求関係の引数も同じ段階1を受ける。従来の段階0の規範関係を、型だけを無視して同一視することはしない。検査では実際に内部の記述を評価する内容を使い、段階を下げた引用が拒否されることも確認する。

自由選択候補では、出所・本人・要求内容・他者と関連する背景を固定する。要求を満たす候補だけを選ぶこと、他人の違反を借りること、もともと不可能な行為で制約を作ることは認めない。この候補範囲の適切な供給は解釈上の条件として残る。

## 一部の解除では足りない

既存 `hze` は、政策内容の真偽と介入要因の真偽が全解で一致することを調べる。しかし「全要求あり」の否定だけでは、一つの要求だけを撤回した状態でも「要因なし」になり得る。

`r2vp` は `hze` に加えて、要因なし側の全解で「同じ全要求なし」が成立することを要求する。要因あり側では全要求があり、なし側では全要求がない。他の独立した要求は保持できる。固定した要求群の完備性と、他の背景を変えないモデルであることは、内容の供給側が満たすべき条件である。

## 同じ啓蒙を比較する

`r2vq` は、結果の評価と「少なくとも同程度」という比較の両方へ、同じ公衆、同じ基準、既存の啓蒙内容族 `r2ln`、同じ割当てから状況への対応を渡す。単に良い結果という名前を付けて、別の目標の改善を用いることを防ぐ。

ここで固定するのは目標の記述であり、尺度の実質を自動的に決める規則ではない。`r2ln` が表す同じ公衆の啓蒙の進行を比較し、人数や経済的な成果など別の尺度へ無断で置き換えない解釈が必要である。目標を引用して評価関係へ渡すだけで、現実の啓蒙を成立させたり、その完了を主張したりはしない。

この対応、自由選択肢の排除、前回の比較の有効性をまとめた上で、悪化の組の存在、非悪化、非悪化かつ改善を構成した。接続が無効な場合は、悪化が見つからないだけで非悪化にしない。

## 検査と残る接続

要求の有無と内容の真偽を独立に変え、要求から履行が導かれないことを確認する。介入については、部分的な適用・解除、反転した要因、履行を政策の有無とした場合、別の出所・宛先・役割・内容を拒否する。啓蒙の比較では、別の公衆・基準・目標・状況対応、評価不足を区別する。既存の内容記述、介入解の評価、比較を実行して結合を確認する。

次に原文の候補へ具体的な全要求記録を接続する。候補を直前の四個人だけに縮めず、二問で同じ制限と啓蒙を参照する必要がある。モデル内の潜在性と原文の一般的な傾向をどう結ぶか、`aber`・`sondern` の対照、`wohl`・`gar` の語用、問いの帰属と回答への接続は残る。今回の構成だけで第五段落の二問を完成とはしない。
