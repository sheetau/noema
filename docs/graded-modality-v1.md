# 可能性の程度の比較と、条件の下でのほぼ必然

「AはBより可能性が高い」と「条件CがあればAはほとんど避けがたい」を、同じA・候補範囲・比較尺度へ結ぶ定義を追加した。カントu0011の冒頭を記述するための構成であり、公衆・個人・自由の内容は引数として渡す。可能という真偽だけでは「より」を区別できず、全候補で成立するという必然だけでは「ほとんど」を保持できないため、程度の尺度を分けた。

尺度は大小関係を持つ値で、数値や確率である必要はない。最小値は候補のどこでも成立しない内容、最大値は全候補で成立する内容へ対応させる。その中間の値は解釈の条件として明示する。候補の個数や成功例の割合から自動算出しない。同じ条件を別名で複製しても、それだけで程度が上がる規則にはならない。

| 定義 | 構成 |
| --- | --- |
| `rqsq` | 異なる両端を持つ厳密な全順序。循環、同値でないのに比較不能な値、自己より大きい値を拒否する。 |
| `rqsr` | 非空の候補、尺度内の値、不可能・必然と両端の対応。尺度の順序の有効性は`rqsq`で別に検査する。 |
| `rqss` | 最大値の手前で近いと採る非空の範囲。その範囲より上の中間値も近い側に含める。順序の有効性は別条件。 |
| `rqst` | 同じ候補で二つの内容を評価し、第一の程度を高くする。第一だけが成立する候補も要求する。 |
| `rqsu` | 基準の候補を条件Cが成立する場合に制限し、その中でAを最大値の手前の近い範囲に評価する。 |
| `rqsv` | `rqst`と`rqsu`で同じA・候補・尺度を使う。比較値と条件付きの値は区別する。 |

比較では、Aを満たす候補がBの候補にすべて含まれるのに、Aの程度だけを高くすることを拒否する。AとBが同じ候補で成立する場合も、異なる程度で「Aの方が高い」とはできない。両者の成立範囲が異なれば、それだけでどちらがどれだけ高いかまで自動決定するものではない。

条件付きの評価では、Cを満たす候補の存在を要求する。Cがどの候補でも成立しない場合に、空の全称条件からAを必然と認定しない。現実にCが成立していることや、現実にAが実現したことは要求しない。CなしでAが成立する候補があってもよく、Cを必要条件へ強めない。条件の制限は関数の内部で作るため、成功する候補だけの別の一覧へ渡し替えることもできない。

ここでの「ほとんど」は、最大値に近いが最大値とは異なるという厳密な読みである。「実質上は必然」と呼ぶ緩い用法まで同一視しない。順序だけでは距離や近さの基準は決まらないため、どの範囲を近いと採るかも明示する。95%などの数値を原文へ補わず、尺度や解釈が不明な場合は不明のまま扱う。

27対照で空の候補、条件の範囲、両端、中間値、比較の向き、包含関係、近い範囲の欠落、循環、未知値を調べる。三つの値の上の二項関係512通りをすべて調べ、指定した両端に適合する一つの順序だけを受理する。候補と値の列挙順、候補の複製、現実の状態の変更も検査する。Noemaの式をそのまま評価し、短絡変換や意味評価のメモ化は使わない。既存本文へ六定義を組み込んだ構文木でも、記号の衝突がなく、32文と全既存宣言が変わらず、固有文字との往復が成立することを検査する。

## カント本文への接続で残る内容

原文の冒頭は、公衆が自ら啓蒙することの比較的な可能性と、自由を残した場合のほぼ避けがたさを述べる。既存の`h6d`は、集団の内部の一人の働きかけで別の一人の能力が変わるという部分構成である。これを公衆全体の啓蒙と同一視して代入すると、元の主張より狭い内容へ置き換わる。

したがって今回の定義は言語の構成として保存し、原文の完成した一文や新しい著者主張には数えない。次の接続では、公衆における変化の範囲、個人の場合との比較背景、自由を残す内容を明示する必要がある。`ja`の強め方と著者帰属も残る。原文対応範囲と七単位の全体確認は据え置く。完成の判定は、これらを実際に接続して原文全体を確認した後に行う。

```powershell
python -X utf8 -m scripts.compose_graded_modality
python -X utf8 -m pytest -q tests/test_graded_modality.py
python -X utf8 -m scripts.check_graded_modality --verify-only
```

[Noemaの一般定義](../examples/v016/graded-modality.noema)と[意味規約](../data/graded-modality-basis-v1.json)は、特定の作品の語を新たな基本記号にせず六つの定義から成る。検査モデルが有限であることと、現実の候補・尺度の選定が妥当であることは別であり、検査成功から後者を認定しない。
