# 使用の目的達成と、基準に照らした評価

使用が目的を達成したことと、その使い方が評価基準に適合することを別々に記述した。既存の使用・誤用の評価 `hj2` は意味規約のままだったため、今回はその評価根拠を具体的に構成する候補を追加した。新しい基本語や文法演算子は増やしていない。

たとえば、ある計測器が値を表示できても、採用した校正基準に違反している場合がある。一方、手順を守った試行でも目的を達成できない場合がある。この区別は、特定の器具の仕様や特定の文化の規則を言語へ固定せず、評価基準を引数にすることで表す。

## 評価の範囲と証拠

評価では、同じ基準・本人・資源・使用行為・文脈を保持する。基準が採用され、その基準に属する適用項目が少なくとも一つあり、実際の使用もあることを要求する。空の基準や適用項目の不在を、適合の成功とはしない。

各項目について、充足を支持する証拠と、違反を支持する証拠を独立して与える。証拠の不在を、反対の事実の証拠に変えない。

| 定義 | 条件 |
| --- | --- |
| `rbh` | 採用基準・実際の使用・非空の適用項目が揃う |
| `rbi` | 全適用項目で、充足／違反の証拠のちょうど一方がある |
| `rbj` | 全適用項目に、充足の証拠だけがある |
| `rbk` | 衝突する項目がなく、少なくとも一項目に違反の証拠がある |
| `rbl` | 少なくとも一項目に、充足と違反の証拠が両方ある |
| `rbm` | 衝突する項目がなく、少なくとも一項目は両方の証拠がない |

違反が確認できた項目と未確認の項目は、同じ評価に共存できる。その場合 `rbk` と `rbm` は両方成立する。衝突がある場合は `rbj` と `rbk` による確定を保留する。これらは一つの真偽へ押し込めた判定ではなく、別々の性質である。

基準への所属は、その基準の全項目の範囲として与える。都合のよい既知項目だけを選んで網羅したとする仕組みではない。所属・適用条件そのものが不明な場合に、偽を代入して項目を除くことも正当化しない。範囲の完全さ、適用条件の確定、基準の正当性、証拠の信頼性は、呼出側の意味規約と別の検証を要する。

## 目的の達成と原文への接続

`rbn` は、同じ使用行為に本人についての目的記述を結び、同じ行為がその結果を生じさせ、結果も成立することを要求する。結果が偶然共存するだけでは足りない。引用した目的の記述を評価するため、現行版の引用内評価の制限を受ける。

これは一回の使用行為の目的達成である。資源そのものの因果的な必要性、反復した場合の有効性、効率や合理性までを示すものではない。目的達成と基準適合の両方を求める場合は、二つの条件を明示して組み合わせる。

カント側では、`hp2`〜`ht2` が既存の能力使用 `hi2` を評価対象に固定する。`hv2` は同じ使用と既存の結果生成 `g3` を目的へ結ぶ。`hu2` は、候補による適合・違反と、既存 `hj2` の合理的使用・誤用の評価が一致するという条件である。

`hu2` は新しい本文の主張にはしていない。カントが特定の評価基準や証拠制度を採用したとは、原文からまだ確定していないためである。`hj2` を削除したり、候補の定義へ無条件に置き換えたりしていない。合理性や自然的資質の基礎説明、道具・足枷への接続は残る。

## 検証

二項目の証拠状態、使用、基準採用を変えた64例で、一般形とカント側の五つの評価定義の一致を検査した。範囲と適用項目の16例、人物・資源・行為・文脈などを取り違えた16例、目的達成と適合・違反の独立性を示す32例も検査した。目的と結果の9つの誤った接続、および同じ内容を持つ別の記述への取り違えを拒否し、橋渡し条件の4例では既存評価との不一致を保持した。

一階論理の補助検査器を状況型へ拡張した。個体と状況をそれぞれ任意の非空領域として、実際のNoema定義を展開し、次の5性質の否定が充足不能であることを確認した。

- 証拠が全項目で確定していれば、適合と違反のちょうど一方が成立する。
- 適合と違反は同時には成立しない。
- 衝突があれば、適合も違反も確定しない。
- 全項目で証拠が確定していれば、未確認も衝突もない。
- 適合には、全項目の確定した証拠が必要である。

「未確認なら違反」「違反なら全項目の証拠が揃う」「使用と適用項目があり、衝突がなければ全項目の証拠が揃う」という三つの推論には反例モデルを得た。状況を一つに固定したり、少数の項目だけを全領域とみなしたりした証明ではない。ただし、目的の内容や実際の基準の正当性を証明するものでもない。
