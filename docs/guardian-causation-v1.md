# 後見人の働きかけと危険判断の因果関係

[カント本文の新しい固定版](../examples/v016/kant-guardian-causation.noema)では、後見人の働きかけを述べるdoを改訂した。原因説明への採用だけでは足りないことを明示し、既存の因果的寄与hzieを再利用する。基本関係は追加しない。旧doはrqybとして残し、説明への採用を述べる内容も引き続き表せる。

旧doは、後見人群が監督の立場を持ち、同じ群が活動し、人々に所定の負担と危険判断があり、活動の記述がその結果の原因説明へ採用されることを要求していた。この条件では、活動と判断が同時にあるだけで、実際には因果的な寄与がなくても、説明への採用があれば真になる。新doでは説明への採用を要求せず、実際の寄与を要求する。著者がこの内容を主張したことと、その主張が歴史的事実として正しいことは別であり、本文への帰属から因果の真理を推論しない。

もう一つの変更は、因果結果の範囲である。旧来のdnには、成熟への一歩の負担と、危険だという判断の両方が入っていた。新しいrqydは危険判断uxだけを集団について評価し、後見人の働きかけの因果結果として参照する。既存の負担を含むdnは別の事実条件として保持する。これにより、負担そのものや、危険が客観的に存在することを因果結果の記述へ混ぜない。

rqycは既存u5の選択性質を引数にした割合の定義である。人間の母集団としての整合性、文脈で認識された範囲、厳密な過半数、「はるかに最大の部分」という程度基準を保つ。元のuzを渡すと従来のu5を再現し、uxを渡すと危険判断だけを数えられる。rqydはその割合条件と、文脈で女性とされる非空の範囲の包含・同じ判断への該当を結ぶ。美しさの評価は数える条件にしない。

歴史資料の[AdelungのSorgenの項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_2_1_1140)には、ある事柄の実現に向けて配慮し、手配しようとする用法がある。この語だけから、試みが必ず成功したとは言えない。今回の修正は、人々の判断が実際に成立しており、後見人の働きかけがそれに寄与するという、既存草案の結果の読みに対する修正である。目的的な働きかけの条件とその寄与の接続はまだ残る。辞典の取得本文とハッシュは[出典記録](../data/guardian-causation-evidence-v1.json)に固定した。

検査は、要因・結果・実際の寄与・説明への採用の16組合せ、性質と程度基準を変える割合の64組合せ、不正な母集団、本文の28対照を扱う。本文では、因果的寄与がない場合、説明への採用がない場合、別の集団・要因・結果・状況へ結び付けた場合を分ける。負担がない場合でも危険判断だけの分布は成立でき、客観的な危険の有無を変えても危険判断を述べる内容は保てることを確認する。

通常評価との三照合、未知入力、元の性質を渡す五つの特殊化、著者への帰属六対照、三記法の往復も検査する。通常評価は当初の大きな検査世界で計算量の上限に達したため、母集団と後見人を各一人とする別の有限モデルで行う。定義本体は置き換えず、同じモデルでメモ化した評価との一致を確かめる。この照合は任意のモデルでの等価性証明ではない。既存44文の構文と全基本関係を保持し、意味が変わる本文は文7に限る。既存十一単位と、第二段落の先行四文の意味依存関係は変えない。
