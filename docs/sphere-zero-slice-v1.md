# 同じ球面のK零時刻断面

u0112–u0113は、前の球面をKのx,y,zで時刻t=0に表す二単位である。比較元もKの零時刻に属する出来事へそろえる。ejftはその出来事のk記録と元の球面式を、ejfuはK記録と新しい式を用いる。どちらも同じ物体の独立な物質境界との双方向の一致を、全ての適格なK零時刻記録について述べる。

k側にはτ=0を要求しない。例えばV=5、v=3、R=5なら、Kの両端x=±4,t=0はkでξ=±5,τ=∓3/5になる。同じK時刻面をkの同時刻面へ替えると、元の表面の違う部分を比較してしまう。対象区間はこの断面の表面記録を両系で含むように読むが、区間端や時刻値を等置しない。

Kの式はx²/(√(1−(v/V)²))²+y²+z²=R²である。数値核stfを再利用し、分母の外の二乗、横二成分、同じ半径と光速・速度を保持する。球の設定ejff、kの表面式ejfh、現在の最終四式ejehを前提とする書換えとして、同じ著者の提示へ接続する。

今回の一つの球を内部と境界を占める理想的な連続体とする読みは前段から引き継ぐ。有限点による検査は全物質境界の証明ではない。旧数値検査の証拠は使うが、未構成だった旧zhuや旧座標記録shdは復活させない。回転楕円体という分類と三半軸の値は、次の二単位で接続する。
