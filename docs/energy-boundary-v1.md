# 境界でのエネルギー発散と物理的な可能性

原刊920頁のu0263は、Wがv=Vで無限大になるという記述と、超光速度には存在可能性がないという記述を並べている。前半を、正の質量を固定して速度を光速へ下から近づけたときの発散として記述した。光速そのものに有限のエネルギー値を与えたり、無限大を通常の実数へ追加したりはしない。この極限としての読解は明示した解釈である。

一般の発散は「どんな有限の上限Bに対しても、十分小さい正の近傍幅を選ぶと、その左側近傍内の全ての定義域上の値がBを超える」と記述する。境界へ任意に近づける点の存在も別に要求する。空の定義域を用いて発散が成立したことにはできない。

エネルギー関数には、R=1+max(B,0)/(μV²)、δ=V/(2R²)という近傍幅の候補を与えた。正の質量・光速、非負の速度、既存のbetaの正規化式とエネルギー式の下で、V−δ<v<VならW>Bとなる有理数の一般命題を検証した。δはBに依存する。一つの固定した幅で全ての上限を超えるという命題には、厳密な有理数の反例を与えた。

局所検査には、負の上限、零、大きさ10の12乗の上限と、異なる光速・質量を含めた。平方根まで厳密に計算できる有理数の速度を構成し、浮動小数点による近似は使わない。一般の実切断について全ての近傍内の値を検査したものではなく、全実切断の極限の機械的証明は残る。

後半の存在不可能性は、同じ物体・基準系について、許容される全ての物理状況で超光速度の実現がないという別の内容にした。許容状況の範囲は空でないことを要求する。許容されない状況だけの実現、別の物体や基準系の実現は区別する。発散を真として与えても物理的な実現関係を別に変えられる検査モデルを用意し、発散から不可能性を自動で導出する規則を追加していないことを確認する。
