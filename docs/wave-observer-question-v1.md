# 静止観測者と波の性質を問う質問

u0182前半の「移動系kに静止する観測者が同じ波を調べるとき、その波の性質を問う」に必要な依存定義を構成した。今回の六定義は、静止と調査条件、物理的な二場の候補、質問の構成までを扱う。既存366主張は変更せず、原文の完成数も増やさない。

質問の引数には観測者、波、物理過程、系、領域、代表位置関数、時間区間と単位規約を先に渡す。答えの型は電場と磁場の関数対である。候補を取り替えても質問の対象は変わらない。二つの候補が別の波に属していたり、同じ数値関数というだけで物理的な場と見なされたりすることを防ぐため、同じ過程の場の記述eispnと物理的校正ejsnを要求する。

ekbuは既存eit2を使い、観測者の代表位置が正の長さを持つ全時間区間で静止する条件を再利用する。終点で出発点へ戻る運動は静止ではない。身体内部の全構成粒子の停止も要求しない。ekbvは同じ時刻の三位置が指定領域に入る点条件、ekbwはその全区間への量化である。調査区間を変換後領域内に取る局所的な理想化を明記し、変換後領域を旧系の矩形な時空領域と同一視しない。

ekbxはこの観測者が同じ波・過程を同じ系・領域で調べる条件、ekbyは候補二場の物理的な対応、ekbzはその条件から作る質問である。一般関係eissdは調査者と調査対象の物理的な対応を担う。観測者の静止、候補の値、答えの発見、著者の発話を一つの原始記号へまとめない。新しい測定記録や特定の装置も補わない。

「性質」はまず実際の物理的な二場の時空記述を求める問いとして準備した。後続の正弦波形は先行の近似を受けた表現であり、この問いの候補と無条件に厳密同一とはしない。近似的な答えの接続には、元の誤差と用途上の十分性を維持する必要がある。

局所検査は静止と途中の移動・往復、三位置と時刻の順序、全時刻と領域の内外、固定された質問引数と二つの答え位置、未知入力の拒否を対照する。全実数履歴・全関数域の列挙を拒否したまま、診断用に時刻の型を有限個体域へ変更した検査と、実際の型を持つ点ごとの本体を分ける。静止の既存の全履歴は物理入力として扱い、有限時刻での一致を全履歴の証明とはしない。

次に、先行の同じ仮定の証人へこれらの引数を結び、K/kと相対運動、変換後領域、著者のWir fragenを接続する。質問を作れたことは、著者による質問提示を記述できたこととは異なる。u0182後半の二種類の変換の適用と「直ちに得る」、後続表示への参照も残っている。
