# 横方向の完全な光往復

u0059–u0061では、先の議論を二つの横軸へ適用し、静止系から見た横方向の伝播成分を使ってτのy,z偏微分が零であると述べる。旧草案の微分定義を使う前に、その試行を現在の測定と時計の規約へ接続する。

ei3wは現在の二時計の往復をkの指定横軸へ移す。光線の全経路はその軸に平行な支持線上にあり、三つの同じ出来事、第一・第二・第一の時計、局所表示、同期の全試行範囲を保持する。

Kでは光が斜めに進む。ei3yは全速さVと横成分wを分け、既存skzのw=√(V²−v²)>0と同じ横距離の二時間式を要求する。ei3zは両端の縦速度v、光の縦速度vと横速度±wを、四つの完全な軌道と六つの同じ出来事での出会いへ結ぶ。反射点と帰着点のK縦位置は移動しており、kに戻ることをKの元の位置へ戻ることにはしない。

ei3xは現在のK光区間の条件から縦軸上という制限だけを外す。幾何学的な経路長と両端の現在の時計表示・一意な時刻は保持する。ei32では同じ三出来事の現在K座標を接続し、補助x−vtと非選択横座標を一定にする。両区間の全経路長はVΔtであり、横距離wΔtとは区別する。

ei33は候補設定の履歴、全τ対応と全k時計指示、全K時計網と全光速度原理を合わせる。一般化した数値条件は比較用にv=0も許すが、現在の本文の試行では既出の正のvを保持する。未知の測定や軌道は既定値で埋めない。

この依存群では著者主張と全単位判断を増やさない。全候補範囲・各地点の局所微分・類似議論と注意喚起を本文へ接続し、原刊のH・Z表記とy,zへの対応を明示して全文を判断する作業が残る。有限の関数指紋は接続の検査であり、全軌道や物理的推論の証明ではない。
