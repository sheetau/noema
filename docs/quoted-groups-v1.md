# 説明を伴う引用全体への参照

[引用のまとまり](../examples/v014/quoted-groups.noema)を、既存0.14の有限列と0.13の式記述から構成した。複数の発話を、順序付きの一つの対象として指せる。発話ごとに独立した役割を与えることとは区別し、元の発話の働きと定義への参照を保持する。

## 全体と各部分の役割を分ける

列の要素型は`i[f]`、列全体の型は`j[i[f]]`とする。要素は発話の記述なので、引用した命令を実行したり、その内容を真と認定したりせずに列を構成できる。説明が二つ以上あっても、同じ列の構文で書ける。

gaは、このまとまり全体を、指定した事柄の標語として位置付ける基本関係である。事柄は性質定義の記述`i[h[a] e]`で渡す。発話の役割が現実に認められているかを推論する機能ではなく、与えた解釈の意味規約である。

gbは、列が空でなくgaを満たす条件である。gcは、その発話記述が列のいずれかの位置に含まれるかを確認する。全体が標語であることから、各要素が単独でも標語であるとは導かない。反対に、各要素が別々に標語でも、連結したものが一つの標語だとは導かない。

順序と重複は保持する。Aの後にBを置いた列とBの後にAを置いた列は異なり、Aを二度置いた列はAだけの列とは異なる。説明付きの借用表現や複数節からなる標語も、個々の部分と全体の指示対象を区別して記述できる。ただし、原語の綴りや印刷字体の復元を保証するものではない。

## カントの標語の指示範囲

[更新草案](../examples/v014/kant-quoted-group.noema)のbtは、ラテン語の呼びかけbl、ドイツ語の呼びかけbnをこの順で引用した列である。boはbtの全体を、先行定義biが述べる啓蒙の標語と位置付ける内容となった。

```text
bt = [blの記述, bnの記述]
bo = bt全体が、biで定義した事柄の標語である、という内容
```

両発話が同じ意味だと仮定せず、ラテン語の箇所をドイツ語で説明する既存のufを保持した。段落の主張帰属ucは、この新しいboの記述を指す。本文を記述しただけでboを真と認定することはない。

これは引用全体を指示対象に採る読解候補である。後続のドイツ語だけを指す旧文書も比較用に残し、原文が一意に全体を指すことを証明したとは扱わない。[Wikisourceの転記](https://de.wikisource.org/wiki/Beantwortung_der_Frage:_Was_ist_Aufkl%C3%A4rung%3F)では二つの呼びかけに標語の述語が続くことを確認したが、原刊画像の配置の確認は今回も完了していない。

転記の所蔵先リンクであるBielefeldは閲覧を拒否し、[別の公開アーカイブDTA](https://www.deutschestextarchiv.de/kant_aufklaerung_1784)でも、この実行環境では画像を表示できなかった。書誌や転記を読んだことを画像の確認として記録しない。標語の指示範囲と原刊照合、ラテン語の行為性、基本概念の解釈が残るため、確認済み全文単位数はカント0/20・アインシュタイン0/282のままである。

## 検査と再現

長さ0〜3の二種類の引用からなる15列について、順序・重複・所属を検査した。基本関係gaが空列にも真を返す場合でも、gbは拒否する。

カントの9モデルでは、全体だけ、片方だけ、各部分だけ、全体と各部分、逆順、反復、異なる主題・文脈の役割を区別した。4つの談話モデルでは、引用や説明関係の欠落・逆転を検出した。全て引用内容を実行せずに検査している。元の内容が現実に正しいことや、原文の唯一の解釈を証明した結果ではない。

```powershell
python -S -m scripts.compose_quoted_groups
python -S -m scripts.check_quoted_groups --verify-only
python -S -m noema parse --input examples/v014/kant-quoted-group.noema --output artifacts/kant-quoted-group.json
python -S -m noema render --input examples/v014/kant-quoted-group.noema --alphabet v2 --output artifacts/kant-quoted-group.svg
python -m pytest -q
```

[検査記録](../reports/quoted-groups-v1.json)に、入力ハッシュ、定義の対応、原文の指示範囲についての採用した読みと未確認事項を保存する。モデルやソルバーを使わず、32文字の体系と既存の文法で解析・表示できる。

新規4件を含む全754テストが通過した。`python -S`で文書と検査記録を再現し、CLI解析と固有文字SVG出力も確認した。
