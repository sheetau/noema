# 後代集団の三つの進展と方法ごとの継続

カント第六段落 u0013 [713,1004) について、認識の拡大・誤りの訂正・啓蒙の進展のどれも可能でない条件をまとめる。三つを同時に達成できないだけでは、この不能性を満たさない。

`r5cq/cr` は、既存の理由ある自己判断 `r5aa/r5ab` を同じ後代集団に限定する。前後の生存者が非空で全員の判断評価が整うことを確認し、一人の一部の進展や次の生存者による範囲の拡大を許す。集団外の人の進展、単なる保有者の交代、消滅や未評価を流用しない。`r5cs` はこの進展と認識の獲得 `r5co`、訂正 `r5ci` の選言である。

既存の認識・訂正の比較は、指定した一つの経過内の前後を扱う。方法選択では別の継続経過で成功する結果があり得るため、元の経過に結果点がないことを理由に不能とはできない。新しい `h26ak` は同じ集団・方法・基準経過・起点・結果を、その結果に至る全継続へ結ぶ。

`r5ct/cu` は継続の順序と起点より後の結果点、起点での同じ生存集団、前後の非空で有効な評価を確認する。将来の出生まで基準経過と一致させる条件は加えない。過去の全出来事の保存と継続の網羅は入力の意味規約であり、有限模型だけから現実について証明しない。

`r5cv` は、利用可能な各方法に結果があり、その各結果に継続があり、選択した全継続が有効であることを要求する。無効な継続を捨てて成功候補を空にすることは許さない。`r5cw` は、この同じ範囲に三種類のどの進展も生む結果がないことを述べる。個人の学習・検討と共同の活動をともに方法へ含める。

検査では、三種類の成否の8通り、異なる方法での成功、成功と不成功が混じる結果、継続の欠落・循環・起点集団の変化・集団外の進展を区別する。認識の獲得と訂正を実行する統合例では、元の経過にない成功結果を別の継続へ接続する。旧 `r5cp` の固定経過の比較では捉えられない成功を、新しい構成で保持する対照も置く。既存の判断評価についてだけ型付き境界を使い、その意味と検査証拠は保持する。

同じ先行合意が後代をこの状態へ置く目的、状態からの不能性の必然性、規範的否認、重要性・総括・共謀的提示・全文帰属は残る。今回の不能性だけから合意の実在、原因性や道徳的否認を導かない。本文99主張と既存の意味判断を保持し、全文の確認済み文字数は増やさない。
