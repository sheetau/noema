# kant-pageの入口・出口を分ける局所変更

この試作は、元の生成器を使い続けながら主な連なりと横枝を復元するための検証である。新しい書体の完成版ではなく、語・引用・束縛を含む構文の復号は未完である。[描画規則と設計の調査](kant-generator-decoding-design.md)で確認した語の衝突も残る。

## 同じ円周位置を使う入出力

元の生成器では、ある円への入口と、その円から次へ出る出口が同じ円周位置になる場合がある。その二線を見える一本の線として統合すると、円は主な連なりの途中ではなく横枝の末端に見える。元の描画手順やpathsの順序を読めば訪問順を知ることができるが、図形だけの読取器は使えない。

カントの題名に相当する図形では、元の8つの主な要素と1つの横枝を、接続だけからは6要素と3横枝として読む。これは回収した語の意味の問題ではなく、線の接続が生成意図を区別していない問題である。

## 経路生成への条件追加

scripts/kant_readable_flow.pyは、contextual_opening_script.pyとbalanced_circle_script.routeを元にした実験用の別モジュールである。凍結された元コードを変更しない。文頭分類、構文からの横枝選択、円のプロフィール、面積重心の費用、接触・融合、元の幾何検査を維持する。

新たな経路候補を選ぶとき、前の要素へ入った円周位置から再び出る候補を除外する。現在の要素に横枝がある場合も、その枝の出口と同じ位置から主な連なりへ入る候補を除外する。中心へ入る線については、中心で止まった点ではなく、円周を横切る位置で比較する。残った候補から従来の規則で配置を選ぶ。

この条件は、すべての入力について一意な復号を証明したものではない。分岐の交差・円の接触・異なる複合円の組合せを広げる場合には、その合成が読順を壊さないことを別に示す必要がある。

## 図形からの回収

scripts/kant_flow_reader.pyは観測済みの円・線の関係を受け取る。同心と中心・円周の重なりを一つの要素へまとめ、円周接触は要素同士の接続として保持する。線上の途中の点をまとめ、自由終端の線は図形の特徴として残しつつ、主な連なりの要素とは数えない。一意に回収した不可視接続も接続へ加える。

接続が一つの木になることを確認し、左端の開始要素から進む。分岐後に最も右まで続く側を主な連なり、それ以外の単独の終端要素を横枝とする。同じ位置で開始を決められない場合、継続側を一つに選べない場合、横枝に複数要素がある場合などは推測せず拒否する。この限定を言語全体の確定規則とはしていない。

元の40主張では、主な連なりと横枝が生成時の記録に一致するものは21主張だった。入口・出口を分けた後は40主張すべてが一致した。読取器に渡すのは、一文全体の実SVGから読んだ円・線だけである。生成時のgroups・satellitesは、回収した結果を最後に照合するためだけに使う。

## 同内容のページ比較

output/kant-port-flow-probe/index.htmlには、元のkant-pageと今回の実験出力を並べる。どちらも同じ40主張と同じ参照を使い、元の段落配置・折返し関数を呼ぶ。新しい出力も18行・倍率0.53で収まった。文頭の番号や共通ヘッダーは加えていない。

比較用の頁は、折返し前の主張ごとに復元を確認した図形を組版したものである。頁全体から改行を解除して構文を復号する機能の完成を意味しない。これは見た目の確認を求める最終候補ではない。

## 未解決の部分

語の識別は、元の文書内順位依存を残している。公開辞書と異体字の対応へ置き換え、形の衝突を解消する必要がある。引数の位置、融合前の構文、引用の範囲と変数束縛も、回収した主な連なり・横枝に公開文法を接続して復元する。接続構造が一致したことだけで既存の意味判断を引き継がない。

既存の原稿・定義・語義・参照先・意味判断と旧検証器は変更していない。新しいprimitiveの追加や意味モデル群の再検証は行わない。
