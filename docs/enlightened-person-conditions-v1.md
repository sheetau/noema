# 自分の判断能力と恐れを同じ人物へ結ぶ

第十段落第一文の `selbst aufgeklärt` は、宗教上の判断と法・統治・公的討論を含む領域で、本人が自立的で適切かつ安定して自分の理解力を使える状態として読む。直前の第九段落が宗教から立法へ議論を広げているため、宗教だけに限定した旧 `r5xv` をそのまま流用しない。これは文脈に基づく明示的な読みであり、全知やあらゆる専門技能を啓蒙の条件にするものではない。

新しい領域指定と、既存の「その本人に関係する全事項」の関係を組み合わせ、既存の判断能力評価へ渡す。各課題に必要な全条件と通常の変化での安定性、本人側の既有基盤を保つ行使可能性、同じ事項を指す閉じた名前は従来の構成を保持する。今ここで実際に判断することや、全事項を同時に処理する一方法は要求しない。課題範囲を得意な事柄だけに選び直すことも許さない。

`r6eu–ey` がこの範囲・能力・引用を構成する。`r6ez/e2` は、前群で構成した「支持理由のない不利益予期がない」を同じ本人・点・固定基準へ結ぶ。判断能力があることから恐れの不在を導くのではなく、両方を独立した条件として保つ。

`r6e3–e5` は当人自身への強調と人物条件の提示を結ぶ。`selbst` は、他者への働きかけだけではなく本人自身が啓蒙されているという強調として採る。人物範囲は後続の全文接続で渡すため、実在や発言の成功をここで断定しない。`nur` の限定、軍隊、公的平穏、自由国との対比は別途必要である。

検査では、課題ごとの判断内容から通常機会での能力まで実際のNoema定義を評価する。質の失敗、指導への依存、空の事項範囲、参照の取り違え、未知入力を調べ、直接評価と段階7の脱引用が一致することを確認する。能力と恐れの結合では深い二条件を検査済みの境界とし、人物・点・基準の共有を確認する。談話検査では能力や恐れの真理を評価せずに同じ内容が提示されることを調べる。

十定義と領域指定の一関係を追加し、過去の定義・判断・本文119主張は保持する。この群だけで第一文全体の意味確認を済ませたとは扱わず、確認済み文字数は増やさない。
