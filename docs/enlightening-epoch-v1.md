# 到達した状態と、進行している時代

カントu0014冒頭の「われわれはいま啓蒙された時代に生きているか」「否、しかし啓蒙の時代には生きている」という問答へ、同じ時代・人々・評価文脈を保持した部分草案を加えた。現在の到達状態と進行条件を別々に記述する。到達していても進行が続く場合を許し、二者択一の分類にはしない。

| 定義 | 内容 |
| --- | --- |
| `rmh` | 指定した履歴内で時代が非空の区間をなし、現在がその区間に属し、指定した非空の人々が現在生存している |
| `rmi` | 同じ人々の能力評価が現在すべて整合している |
| `rmj` | 評価済みで、同じ人々の全員が指定した能力を現在持つ |
| `rmk` | 同じ時代・人々・現在について、指定した進行内容が成立する |
| `rml` | 評価済みで、到達条件は成立せず、進行条件は成立する |
| `rmm` / `rmn` | 同じ設定についての到達を問う発話と、未到達だが進行中という回答発話 |
| `hzfb` / `hzfc` | 評価と能力を既存の`fo`・`h4l`へ結んだ到達内容と対比内容 |
| `hzfd` / `hzfe` | この到達内容を問う発話と対比内容を主張する発話 |

現在についての判断であり、その時代の全過去や未来で能力を持つことは要求しない。進行が将来成立するだけでも、現在進行しているという回答は成立しない。時代の境界、対象者の選択、生存の関係は入力で明示する。対象者がいない場合を全称条件の空虚な成立として受け入れず、全人類や全住民を暗黙に補うこともしない。

評価が済んでいる範囲では、到達と進行の四つの組合せを許す。評価が不足している場合、到達条件が確認できないことから未到達を結論しない。個々の評価を実行するための意味入力自体が未知なら、真偽を補わず評価を拒否する。

原文への接続で使う到達条件は、選んだ人々の全員が、指導なしに自分の理解力を使えるという強い候補である。「啓蒙された」の全語義を確定したものではない。進行には、同じ人々に自己作業の機会があり、その人々の能力を尺度にした障害が漸減するという既存の`hzfa`を接続した。機会があることと、実際に学習・獲得が進んでいることは別である。場が開かれつつある変化や宗教上の判断の確実さなどは引き続き未完である。

質問・回答は同じ閉じた設定から構成する。さらに既存の`hzcu`を使い、質問の提示、回答の提示、本文順序、応答関係を結び付ける。意味内容が同じでも質問と主張の発話種別は異なる。引用された問答への帰属は、その内容を実行評価せず確認できる。回答の記述が違う場合、順序が逆の場合、応答関係がない場合は、この問答への帰属を認めない。

この帰属の検査は、仮の明示的な記録に対する検査である。原文の条件付きの問いかけを現実の質問出来事とみなしたものではなく、著者による提示全体を記述し終えたものでもない。対比・強調、フリードリヒへの言及、段落全体の意味確認は残る。

[一般文書](../examples/v014/enlightening-epoch.noema)は2,221文字、[原文付き草案](../examples/v014/kant-enlightening-epoch.noema)は178,855文字、[抽出文書](../examples/v014/enlightening-epoch-core.noema)は16,355文字である。十一定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。抽出文書には接続検査に使う依存定義も含み、最短表記ではない。[意味規約](../data/kant-enlightening-epoch-basis-v1.json)と[検査記録](../reports/enlightening-epoch-v1.json)を保存する。

評価・到達・進行の32通りと、無効な時代・空の対象者・現在不在の対象者を検査した。原文付き文書と抽出文書それぞれで、具体的な能力と進行を接続した六条件、引用した問答の四条件を検査した。追加14テストでは現在と他時点の区別、評価不足、未知入力の拒否、同じ内容での発話種別、帰属の保持、過去の成果物の固定を確認した。三文書のCLI解析の構文木一致と固有文字v2のSVGのXML検査も通過した。SVGの目視確認は含めない。
