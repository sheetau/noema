# 現在の同時刻測定長と任意方向の横運動

u0101–u0104へ進むため、同じ棒の測定長と、符号付き三成分の全物質点並進を構成する。著者による長さの結論・物理的意味の提示・対称性の理由・二設定の比較は次の接続に残す。この依存群だけでは主張数や全文判断数を増やさない。

ejcxは同じ棒の長軸の全履歴eipcと、その二端の現在の測定記録ejceを結ぶ。二つの異なる端点出来事の時刻値を同じ系で等しくし、その時刻の同じ履歴関数の端差からeipaで正の距離を得る。測定座標はeiyxで現行の時計・位置測定に結ばれ、計量はeisddに保持される。前段の縦棒xiに固定されたeiqgや、未接続な数量関係zaを代用しない。

ejcyは指定時刻の現在二端記録の存在、ejczは正の時間幅の全実数時刻での存在と同じ正の長さを要求する。長さの読みは、同じ系の測定座標から得る同時刻の二端距離である。この箇所に特定観測者の追加の物差し操作や、現実に実験を行ったという報告は補わない。系ごとの時刻と区間は別々の規約のまま保持する。

ejc2は現在の横棒の設定・両端式・Kでの測定長に、長さ=l/φ(v)という原文の結論の条件を結ぶ。ただし一般の距離は正であり、先行する二端の座標差から得る距離はl/|φ(v)|である。符号付き商l/φ(v)を長さと同一にする条件は正の枝を選ぶ。この読みを明示して保持し、端点代数だけからφの正値が証明されたことにはしない。一般のejcx/ejczは負向きの軸でも正の距離を返す。

ejc3は全物質点の全順方向時刻対で、三成分それぞれに同じ符号付き速度と経過時間の積による変位eiohを要求する。全体の履歴と同じ計量を保ち、正X方向だけに限定しない。ejc4はその全点並進と測定長に、全時刻の実際の端差と速度との非零直交eiu6を合わせる。斜方向や反対向きも扱い、速度零や潰れた軸を横運動としない。

ejc5は同じ棒・二端を固有静止系の全履歴・剛性・固有長と、相異なる測定系のejc4へ結ぶ。これは一つの設定の条件であり、同じ棒を比較する設定間の全物質点と固有形状の一致、方向と向きの全比較範囲、同速での測定長の不変性はまだ構成していない。原文は方向一般を述べるため、後続の比較を正負反転二例だけで済ませない。

検査ではeipaの距離本体、四つの出来事・記録量化の位置、全時刻の存在条件、全物質点の三成分並進、実際の直交を対照する。二端が正しくても内部成員が別に動く場合を拒否し、負速度・斜方向・負向きの軸と正の測定長を区別する。実数時刻は明示した本体の例化に限り、元の全域量化の有限評価は拒否する。有限関数指紋と既存物理定義の境界は先行証拠とともに記録し、全実数・全物理世界・原文の意味一致を自動証明したとはしない。
