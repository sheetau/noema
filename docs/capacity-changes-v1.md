# 個人別の前後変化と離脱過程の証拠

自立的な使用能力を持つ人数の純増に加え、個人別の前後変化を四つに分けて記述した。さらに、能力が新たに成立したことと、本人の自己活動による離脱過程があったことを別の条件として接続した。新しい基本概念や構文は追加していない。

| 前の能力 | 後の能力 | 分類 |
| --- | --- | --- |
| なし | あり | 新規成立 |
| あり | なし | 不成立化 |
| あり | あり | 前後とも成立 |
| なし | なし | 前後とも不成立 |

いずれも、同じ本人の前後の能力評価が整合し、指定の時間順序が成立することを要求する。未評価の人を「前後とも不成立」へ補わない。一般定義は `rem` が評価と順序、`ren`〜`req` が四分類である。原文側は既存の `fo` と `h4l` をそのまま用いる。

`rer` は四分類の人数を表の順で返す。`res` は、非空の対象範囲を全て重複なく列挙し全員が評価済みであることを確認してから、次の二つの一致を検査する。

```text
四分類の人数の合計 ＝ 対象人数
新規成立人数 − 不成立化人数 ＝ 能力を持つ人数の純増
```

たとえば一人が能力を得て一人が失った場合も、二人とも変わらなかった場合も、純増は0である。四分類では前者が `[1, 1, 0, 0]`、後者の一例が `[0, 0, 1, 1]` となり、同じ状況として消去しない。さらに、四人数が同じでも誰が変化したかは異なり得るため、個人別の条件を保持する。

この分類は二時点を比較する。前後とも成立していても中間に一時的な喪失がある場合、前後とも不成立でも中間に一時的な獲得がある場合を許す。区間全体の持続や、過去に一度も成功しなかったことは、この分類からは導かない。原文用の `hzj` は四人数、`hzk` は人の集団についての評価・範囲・保存則の確認を行う。

離脱過程は別に記述する。`hzl` は前後の能力の新規成立に加え、同じ本人・過程・前後・基準時に対して既存 `h4p` を要求する。これには本人を対象とする実際の変化、本人の精神への働きかけ、同じ活動による結果生成などが含まれる。因果関係がない、別人の過程である、本人の働きかけがない、結果の記述が違う、完了が基準時より未来である場合は、人数の新規成立が同じでもこの証拠条件は成立しない。

`hzm` は、同じ集団で新規成立した全員に、指定した本人ごとの過程が `hzl` の証拠になることを要求する。一人分の証拠を、もう一人の獲得へ借用しない。各人の過程を互いに異なるものとする要件はなく、同じ過程を使うなら各人との必要な関係が成立していなければならない。

これは指定した証拠の条件であり、証拠を確認できないことを能力の新規成立の否定へ変換しない。前後の人数を確認するだけなら、過程や原因を実行評価する必要もない。一方、過程の証拠を検査する際の未知の関係は、偽で補わず評価を拒否する。現在の評価器は条件式を先に評価する場合があるため、非該当者の過程への参照を必ず省略するという実行上の保証はしていない。

新規成立者がいない場合、`hzm` の全員への証拠条件は空虚に成立し得る。これは新たな離脱を達成した人がいるという主張ではない。対象集団の非空性と、新規成立者の存在は別である。新規成立者がいないことも、途中や過去の成功がなかったことを意味しない。

一般文書は [capacity-changes.noema](../examples/v014/capacity-changes.noema)、原文への接続は [kant-capacity-changes.noema](../examples/v014/kant-capacity-changes.noema)。既存の宣言と15件の主張を保持した。自己活動を含む `h4p` は獲得過程の一つの強い条件であり、他者の援助を排除せず、啓蒙の全ての獲得をこの過程だけに限定しない。人数尺度の適切さ、個人別の保護を原文がどこまで要求するか、離脱過程の一般的な意味と全文の意味一致は未完である。
