# 同じ賦課への非難と発言上の立場

カント第五段落u0012の[2513,2770)にある `vorwitziger Tadel solcher Auflagen, wenn sie von ihm geleistet werden sollen` へ向けた依存構成である。本文への統合と一文全体の意味判断はまだ行わず、確認済み文字数も増やさない。

`r34a` は同じ賦課について、採用した評価条件を満たしていないという内容 `r326` を主張する発話を作る。`r34b` はその発話を、本人の同じ批判活動で、固定した非空の宛先範囲の各人へ示すことと、対象を是認できないものとして評価する立場を結ぶ。原文のこの節には全読者世界への刊行を要求する語がないため、その条件を加えない。批判の論点を指定する構成であり、発言の全内容がこの短い命題に尽きるという意味ではない。

`vorwitzig` には、自分から評価・裁定する立場を取り、その立場に必要な検討・範囲・時機等の条件が不足するという読みを採る。保存済みの[語義資料記録](../data/vorwitzig-reading-v1.json)と三資料の本文を再読した。Adelungの性急な知的欲求の説明と、DWBに記録された出過ぎた発言の用法を根拠にする設計上の推論であり、カントの当該語を一意に定義したものではない。1811年版の補訂と1951年刊の歴史的整理という資料の限界を保持する。

この読みを `r34c` で構成する。既存 `rfq` / `rfp` が、本人・立場・評価点を揃えて少なくとも一つの条件不足を検査する。新しい `h244l` は自ら立場を取る関係、`h244m` は同じ対象・固定基準に適用する条件列を与える。旧 `hzba` の役割分類と活動実行だけでは自発的に前へ出ることを表し切らないため、この二つを区別した。条件の不明を不充足に変えず、空列では不足を成立させない。有限列は明示した評価観点の列であり、全記述域の代用ではない。職務の委託や許可の不在、反政府的な内容、批判内容の偽から自動で不適切さを導く規則もない。

`r34d` は[市民への賦課と納付の拒否](civic-levy-refusal-v1.md)の `r33w` とこの二内容を接続する。固定基準で同じ本人に課された賦課について、批判する時点にも同じ出所・市民の立場・支払い行為・受取先・媒体への要求 `r33v` が適用されることを要求する。`wenn` 節をこの要求時の条件として読む。原文にない日付、期限、実際の納付・未払いは導入しない。一般的反抗、Skandal、処罰可能性、sogarとの作用域は一文全体の統合時に確認する。

局所検査では発話の力と内容の真理、全宛先への同じ提示、自己から取る立場と条件不足、基準時と批判時の同じ納付要求を実定義で評価する。引用内の批判の真理と支払いの実行は未定義のままにし、それらを評価せずに構成が成立することも確かめる。旧意味・証拠ハッシュと両表記の往復を保持する。有限模型での検査は構成と引数接続の検査であり、原文との同義性の証明ではない。
