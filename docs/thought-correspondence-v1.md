# 論点ごとの内容対応による思想の一致範囲

カント脚注の「思想の一致」を表す基本関係hzkvを、論点ごとの内容対応を調べる定義に置き換えた。文献の対と範囲を一度に判定する関係を、比較する論点、候補範囲への所属、各文献が述べる内容項目、項目間の対応という四つの局所的な関係へ分解する。

一般定義rqrxは、同じ論点について両文献が内容を述べ、各側の全項目に相手側の対応項目があることを要求する。対応は両方向に調べる。項目の識別子や数が違っていても多対多の対応を認めるが、一方に対応しない内容が残れば成立しない。二文献が同じ論点に沈黙している場合も、内容が一致したとは数えない。

一般定義rqryは、比較論点のうちrqrxを満たす論点と、候補範囲の論点が過不足なく一致することを要求する。比較する領域自体は非空とする。一致する論点がなければ空の候補範囲を答えにできるため、「どこまで一致するか」の候補からゼロを排除しない。範囲外の論点の混入や、一致した論点の取りこぼしは拒否する。

新しいhzkvを既存の問いへ接続した。比較は偶発性・因果的寄与と同じ状況、同じ二文献、同じ候補範囲について行う。実際の一致を断言せず、可能な状況での範囲を問う構造を保持する。問いの記述を提示する文では、項目や対応が未知のままでも、問いの答えを評価せず記述できる。

これはwiefernを論点の範囲として具体化した読みである。重み付きの程度・数値・最大値を補っていない。内容項目には肯否、対象、量化、条件、主張と問いなどの違いを残すという規約を設けるが、その内部構造・帰属の網羅性・対応基準の妥当性はまだ解釈入力に残る。字面や真偽値だけの一致を内容対応と同一視する規則はない。一致から真理性・無矛盾性を導く規則もない。非対応は、積極的な反対や矛盾を意味しない。

検査では、二項目の左右への帰属と対応関係の256組合せを、独立した集合上の判定と照合する。標準評価と短絡診断の両方で確認する。論点領域・対応した論点・候補範囲の64組合せでは、空の候補、空の比較領域、余分な論点、取りこぼしを検査する。原文への接続では短絡診断を明示的に使い、保存した本文を診断用に書き換えない。問いを提示する文は標準評価で確認する。
