# 試みの阻止と、その後の危険提示

第二段落の「先に働きかけ、後に危険を示す」という複文について、対象側の部分記述を本文に追加する。旧 `er` は、特定の因果方程式の解と反事実的な比較を妨害の成立条件にしていた。[原文AA VIII 35頁](https://korpora.org/Kant/aa08/035.html)はそのモデルを指定していないため、新しい記述では、実際の行為と結果を結ぶ既存の因果関係を使う。

`hzsm` は、本人が自立した理解力使用を試みていないことを表す。`hzsn` は、同じ行為者群が参加する実際の行為が、その本人についてその非試行を生じさせたことを表す。既存の `raa` を使い、行為の生起・参加者・影響を受ける人・結果内容・因果関係を結ぶ。単なる不実行、制約を適用しただけの行為、原因と結果の同時成立は、この条件を満たさない。

ここでの否定は、試みの有無を評価した上での否定である。未知入力を偽とみなして非試行を作らない。また、非試行とそれへの因果的作用は、規範上の不許可や実行不能とは異なる。原文の `wagen durften` に含まれる許可・機会・勇気の区別は、この対象側の記述だけで解決したことにはしない。

## 先行する二つの働きかけ

旧 `g5` は、理解不足を生じさせる働きかけ、試みの妨害、危険提示を厳密にこの順序へ並べていた。今回、`zuerst` と `nachher` を、先行する二つの働きかけと後続の提示の対比として読む。両方が提示より前にあることを要求し、二つの働きかけ相互の厳密な順序は追加しない。この読みが原文から一意に決まるとは主張しない。

`hzso` は提示時点で選んだ対象者を固定し、全員について理解不足を生じさせる `g4` と、試みの阻止 `hzsn` を結ぶ。過去の時点で対象者を選び直し、別人についての働きかけを使うことはできない。`hzsp` は同じ後見人群による危険提示 `ew` へこれらを接続する。提示した警告の内容が真であること、受け手が同意したこと、実際に危険が生じたことは要求しない。

五つの合成定義と一つの本文箇所への参照を追加し、既存35文を保持したまま著者への帰属を一文加える。新しい意味の基本関係はない。旧 `er` と `g6` は比較用に残すが、新しい文の依存関係には含まれない。
