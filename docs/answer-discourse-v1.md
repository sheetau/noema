# 公的使用と私的使用を分ける回答文

第五段落の回答文[690,980)を、先行二問への著者自身の回答として構成した。公的使用の自由への要求、公的使用だけが啓蒙を実現できるという内容、私的使用への条件付き許可を、同じ評価点の連言にする。段階3の閉じた記述で全回答を帰属し、その真理や規範の現実の成立は帰属時に評価しない。

「Ich antworte」は、自分を現在の回答者として明示する論述上の自己提示と読む。単に後から回答者を帰属することや、前の仮定例の一人称とは区別する。二問に同じ全文を回答として結び、ダッシュとコロンによる移行を、導入箇所と回答内の節の順序へ対応させる。

公的使用と私的使用の間の `aber` は、本人の理性使用の扱いについて、全時機の自由への要求と、強い制限の頻度を含む方針への許可を対照する。公的使用の要求を撤回せず、二つを論理的矛盾とも扱わない。前半の `und` は自由への要求と実現能力の連言とし、原文にない理由関係を加えない。

`ohne doch darum` は、この制限があることから著しい阻害を帰結させる見通しを退ける譲歩的な留保と読む。強い制限の頻度を表す部分と、同じ方針の適用・全解除の対応比較からなる留保を、同じ公衆・本人・職務・案に結ぶ。両部分の連言が従来の方針内容と同じ条件になることを検査する。単に二つの状態が同時にあるという説明に置き換えない。

程度・頻度・許容低下は先行の固定基準を継承する。進行の尺度は、同じ期間内の一過程における自立的能力変化の広がりである。公的使用の生産的関与を欠いた実現経路を認めないという読みは、公的使用一つだけが十分な原因であるという強い主張とは区別する。私的使用への許可も、実際の制限や全ての制限の無害性を意味しない。

原刊484頁末から485頁冒頭と[AA8/37](https://korpora.org/Kant/aa08/037.html)を照合した。頁境界は `zu / Stande` の間にあり、文の区切りではない。485頁で私的使用の節と直後の用語定義を確認し、同じ本人の理性と、委ねられた市民的職務への参照を保持した。

原文の全語句を連続した範囲へ対応付け、否定、様相、照応、談話関係と作用域を通読した。明示した読みの下で回答文250非空白文字を確認し、第五段落の文単位の確認は先行588文字と合わせて838文字となる。これはアシスタントの意味判断であり、独立査読や自動同義性証明ではない。第五段落全体と二作品全文の確認は引き続き必要である。
