# 行為と記述を保持する規範

許可・禁止の対象に、行為の同一性とNoemaの実行記述を保持する方式を追加した。旧方式では、評価モデルの全状況で同じ実行状態になる行為を、内容値の違いによって区別できなかった。新方式は、同じ実行結果を持つ二つの発言のうち、一方だけを許可・禁止する場合も記述できる。

## 規範の対象

規範は、出所・人・立場・行為・実行記述・極性・評価文脈を取る。実行記述は、人と行為を受け取って状況ごとの内容を返すNoemaの関数への参照であり、原語の文章を格納したものではない。極性が真ならその記述の実行、偽なら不実行を対象とする。

要求と積極的な許可には別の関係を使う。実行を要求しないことだけで、不実行を許可したとはしない。また、実行と不実行を共に許可することは、両方を要求する衝突とは異なる。

| 定義 | 条件 |
| --- | --- |
| `rdm` | 指定極性を許可し、反対極性を要求しない |
| `rdn` | 指定極性と反対極性を共に要求する |
| `rdo` | 指定極性を許可し、反対極性を要求する |
| `rdp` | 反対極性を要求しない。積極的な許可は含まない |
| `rdq` | 指定極性を要求するが、現在の実行状態がそれに一致しない |

全て同じ出所・人・立場・行為・記述・文脈に結び付く。別の行為の要求を衝突へ混ぜたり、同じ真偽を持つ別の記述へ許可を移したりしない。一方、別名で書かれた同じ活動の規範的な扱いや、記述間の含意に沿う規範推論は自動化していない。

## 許可と未履行では必要な情報が違う

`rdm` から `rdp` は記述を参照するだけで、その実行結果を評価しない。実際に行われたか未評価でも、規範が明示されていれば許可や衝突は判定できる。規範そのものが未評価の場合は、許可の不在や禁止の不在へ変換せず、実行評価を拒否する。

`rdq` は未履行を調べるため、同じ記述を同じ人と行為へ適用し、現在の実行状態を評価する。その情報が未評価なら、未履行という結論は出さない。脱引用を含むため、現行の引用制約に従い `rdq` を含む式をさらに引用することはできない。脱引用しない許可の定義は引用できる。

## 公的・私的使用への接続

原文側の要求 `h7a` と許可 `h7b` を追加した。`h7c` は、先行版の `h6v` で発言者・活動・立場・宛先・提示内容を固定した上で、同じ活動の実行記述に対する許可を `rdm` で調べる。公衆へ提示する発話の記述と、その活動を本人が実行する記述は型も役割も異なり、混同しない。

`h7d` は、その人・立場で公的使用に分類される全活動について、同じ行為と実行記述を保持した許可を求める。該当する活動がなければ全称条件として成立するので、実際の発言や該当例の存在を意味しない。`h7e` は、私的使用に分類される活動のうち、同じ実行記述の不成立を要求されるものがあるという内容である。

旧 `h6y` と旧公的・私的使用の内容値による定義は比較用に保持し、新しい接続には `h7c`・`h7d`・`h7e` を用いる。旧文書や既存主張を変更せずに、新方式との違いを検査できるようにした。

## 反例での検証

実行・不実行の要求、実行・不実行の許可、実際の実行状態、対象極性の64組を検査した。出所・人・立場・行為・記述・文脈の6つの取り違えも除外する。同じ内容を返す別名の関数でも、記述自体は異なることを確認した。

原文接続の10例では、二つの発言がモデルの全評価状況で共に未実行でも、一方だけを許可できる。旧方式は内容値に対する同じ許可を両方へ適用するが、新方式は指定された行為を保持する。両方を許可した上で一方だけを禁止する場合も、他方の許可を維持する。私的な活動の禁止、異なる記述・出所・文脈、該当する公的活動がない場合も分けた。

関連25テストが通過した。保存済み検証記録との再生成一致、旧定義・主張の保持、許可の引用と未履行判定の引用制限も検査した。これらは有限モデルでの区別の確認であり、原文全体の意味一致や、規範一般の完全な理論を証明したものではない。

公的使用の自由を実現するよう求める著者側の規範、私的使用を制限することへの許可、常に・しばしば・程度・留保を新方式へ接続する作業は残る。規範の優先順位・例外・正当性、公衆・学識者・職務の意味規約も未完である。今回の原文対応は既存範囲の具体化であり、対応文字数や意味一致確認済み区間数は増えていない。
