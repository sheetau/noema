# 同じ組織の役職順序と命令の発出

カントの「上官から何かを命じられる」という箇所へ、役職の上下と、それぞれの役職を持つ本人を接続した。上下の順序は、同じ組織・状況の役職の範囲に対して指定する。既存の命令内容、発出、職務要求へ結ぶ部分草案であり、軍制や正当な命令権の説明は残る。

## 定義と作用範囲

| 記号 | 条件 |
| --- | --- |
| rex | 指定範囲の関係が非反射的かつ推移的である。比較不能な二対象を許す。 |
| rey | rexが成立し、範囲内の第一対象が第二対象より上位である。 |
| rez | 同じ組織・状況で、異なる二人がreyの上位・下位の役職をそれぞれ保持する。 |
| hzae | rezと、両者に該当する職務が委ねられていることを結ぶ。 |
| hzaf | hzaeの同じ上位者が同じ本人へ、指定行為について発話を実際に発出・提示する。 |
| hzag | hzaeと、同じ発出者・本人・行為・役職に関する提示および職務要求が成立する。 |

順序の引数は推移的な上下関係を表す。直属の報告先だけを列挙して推移的な辺を欠いた入力は、順序の条件を満たさない。隣接辺からの推移閉包計算は行わない。空範囲はrexを満たすが、二つの役職を要求するreyやrezは満たさない。範囲外にある辺や循環は、範囲内の順序を無効にはしない。

役職の順序と人物全体の序列は別である。一人が二つの役職を兼ねていてもよい。ある役職でAがBより上位、別の役職でBがCより上位でも、AがCより上位になるとは限らない。また、自分が保持する二つの役職に上下関係があっても、自分を自分の上官とは数えない。

職務上の義務は既存のhznを通して別に与える。hzafだけが成立し、義務の成立が不明な状態を記述できる。命令を受け取ったこと、理解したこと、実行したこと、制裁や責任も追加しない。作例の発話記述には、同じ本人へ同じ行為の実行を求めるhzzを使う。任意の発話記述を渡した呼出まで命令とは認定しない。
