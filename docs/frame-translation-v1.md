# 原点・軸・計器に共通する並進

アインシュタイン§3の `u0044` 第一文を部分記述した。初期静止設定の一方の座標系に正のx方向の一定速度を与え、その運動を原点・三軸・物差し・全時計へ共有させる。同じ対象を引き継ぐことと、全対象に同じ運動条件を課すことを分けている。

## 配置を表す点へ運動条件を課す

一般定義 `sff` は、非空の対象範囲の各対象に、少なくとも一つの配置点があることを要求する。`sfg` は、それらの配置点と原点の和集合を作る。`sfh` は、全選択時点でその座標が利用可能であり、時間幅を持つ区間の逆向きでない全時点対で運動条件が成立することを要求する。途中の時点を外して始点・終点だけ一致させても、全区間の条件にはならない。

配置点は時計の据付位置などを表す。時計の全物質点に同じ並進だけを要求すると、針や歯車が動くことまで禁止してしまうため、内部機構の運動はこの配置条件に含めない。軸や物差しを含め、どの点で位置・姿勢を尽くせるかは完全性の前提として明示する。有限例で少数の点を検査しただけで、現実の全体を尽くしたとは認めない。

運動の数値条件は、棒の設定で既に定義した `sbm` を再利用した。静止系の同じ二時刻について、正の共通速度vによるx変位と、y・zの不変を要求する。

```text
x後 − x前 = v × (t後 − t前)
y後 = y前
z後 = z前
```

各点の初期位置を同じにする必要はない。全時計が同じ空間的速度で動くことも、時計が同期していることや同じ速さで刻むこととは異なる。

## 同じ系と計器を引き継ぐ

`sfi` は、初期設定にある同じ系の三軸・物差し・全時計を対象範囲に取る。`sfj` は、別の後続設定へ同じ系を移し、原点・軸の役割・物差しの同一性と配備を保持する。時計の範囲は前後で双方向に一致し、時計の追加・脱落・交換を検出する。後から都合のよい計器だけを選び直さない。

`sfk` は、各配置点と二時点を、共通の静止系・時間単位・長さ単位・速度・三座標に結ぶ。`sfl` は範囲の完全性、座標・時刻の利用可能性、単位の商、基準系間の相対速度との値一致も要求する。実数の下側切断を使う本体は `sfm`、運動設定 `zb6` に適用した想定内容は `sfn` である。

原文の速度vにはこの設定の識別子 `zb7` を割り当て、前の別の棒の設定の速度と同一とは決めない。時刻は静止系での値を使い、動く時計の指示をそこへ混ぜない。初期設定 `zb4` と等速並進の設定 `zb6` は別であり、加速過程の機構を勝手に追加しない。

著者がこの運動を想定し、前段の三軸・計器の設定へ追加することを既存の `ug`・`zao` で保存した。引用した内容を評価せず、現実に操作が実行されたこととは分ける。旧文書の定義と主張はそのまま継承した。

## 検証と残る範囲

新規9件を含む関連41テストが通過した。対象・配置点・中間時点の64組合せ、原文との接続24例、想定の帰属と設定の継承7例を検査した。原点だけ速度が違う場合、軸の途中時点だけ位置がずれる場合、物差しが横へ動く場合、時計一台だけ速度が違う場合を区別した。

時刻や座標の欠落、配置点が空の時計、完全性の前提の欠落、時間幅のない区間、逆の時間順序、相対速度や単位の不一致も拒否した。内部機構が別に動く時計は受け入れ、時計の指示を読む述語には依存していない。

有限の原文接続検査では、構成した整数切断の時刻・座標に限って値を読み取り、時間順序と `sbm` の条件を検査する関数を渡す。この検査用関数は純粋であり、同じ切断の読み取りを個体同一性で再利用する。任意の実切断の同一性を標本から決める処理ではない。実数全域を扱う本体の評価は有限実行器が拒否する。

配置点・時点の完全性や座標の一意性は、ここでは明示した意味規約である。全実時間の運動、内部機構、加速時の応答、前後の物差しの長さを検証したとはしない。`u0044` 後半の各時刻での軸配置、対称性を理由とする仮定、続く両系での測定と原刊照合は未完である。

標準表記・圧縮表記・固有文字の往復、CLIのJSONと構文木の一致、SVGのXMLとしての妥当性、検証記録の入力ハッシュと進捗集計の整合性を確認した。SVGの目視確認と全テストの再実行は今回含めていない。
