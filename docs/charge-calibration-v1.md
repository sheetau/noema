# 単位を伴う値と仮定上の校正条件

アインシュタイン1905のu0173冒頭から、静止系で電気量を1とし、同じ大きさの別の電気量へ距離1 cmで力1 Dynを及ぼすという条件を部分記述した。実測結果の報告ではなく、著者が単位を説明するために置く仮定として扱う。

## 値・単位・対象の区別

[一般用文書](../examples/v014/charge-calibration.noema)の `sbv2` は、量の種類が同じであることを確認し、正の有理尺度で共通の基準へ換算して実数値を比較する。数値が同じでも単位尺度が違えば、量の一致にはならない。尺度2の単位で1/2と、尺度1の単位で1は一致する。負の量も扱えるが、原点をずらす換算や対数量は今回の範囲に含めない。

`sbw2` は、結果の記録・対象・量の種類・基準系・出来事・単位・値・文脈を一つの関係へ結ぶ。値1だけを保存して距離と力を混同したり、別の出来事の結果を使ったりしない。単位の物理的な実現と次元の導出は、これだけでは与えられない。

`sbx2` は、異なる二対象を同じ試行に結び、量が等しいことと第一対象の静止を要求する。量が同じでも二対象は同一物体にはならない。原文にない第二対象の静止条件は補わない。

## 論文への接続

[論文文書](../examples/v014/einstein-charge-calibration.noema)の `sby2` は、同じ試行について距離1 cmと力1 Dynを要求する。`sbz2` は、同じ第一対象の電気量を同じ基準系・出来事で1とする。`sca2` が両条件を結び、既存の仮定の帰属構文 `ug` に渡す。仮定された内容を引用しても、測定を実行したことにはならない。

cm・Dyn・電気量の単位は、それぞれの校正用の基準尺度を1として指定した。点状の理想化、電気量、力、等しい電気量の判定、Dynの質量・長さ・時間による実現は未完である。これらの名前や関係を追加したことを、概念の説明の完成とは数えない。また、一つの試行が実行されたことを、単位の一般定義の必要十分条件にはしていない。

原文は[保存した原刊909頁](../artifacts/written-facsimiles-v1/einstein-1905-unlp-p909-0.jpg)にある。移動系での電気量1と力ベクトルへの同定は、今回の追加には含まれない。対応範囲内にも物理概念の説明不足が残り、意味一致を確認した全文区間数は0のままである。
