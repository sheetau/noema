# 動く両端の間の光往復と中点条件

アインシュタイン§2の `u0036`〜`u0039` と、`u0040` 冒頭の長さの説明をNoemaへ部分接続した。時計と共に動く二観測者、同じ光の出発・反射・帰着、三つの時計読み、往復時間の二式を結ぶ。

## 交点の条件から二つの時間を区別する

静止系で測った棒の長さをr、光速度をV、棒速度をvとする。`sda` は有理数について、正のr、0≤v<V、tA<tB<tA′と、次の二式を同時に要求する。

```text
(V − v)(tB − tA) = r
(V + v)(tA′ − tB) = r
```

正の分母を持つので、原文の r/(V−v) と r/(V+v) に対応する。`sdb` は同じ関係を実数の下側切断で記述し、値の一致を両方向の包含で判定する。分母ゼロ、光速度以上の棒速度、ゼロの棒長、時間順の逆転は、この設定の範囲外とする。

別の定義 `sdc` は、光と端点の位置の一致から出発する。出発時のA端の位置をx₀とし、A端はx₀+v(t−tA)、B端はx₀+r+v(t−tA)を進む。往路光は速度+V、反射後の光は速度−Vで進む。この直線軌道のモデルで、反射・帰着の交点条件と `sda` が同値であることを代数検査した。原点x₀はゼロに固定しない。

正のvでは往路時間が復路時間より長い。中点条件 `tB−tA = tA′−tB` が成立するのは、この条件の範囲ではv=0の場合だけである。数式の定義では静止極限を比較用に許すが、原文の正方向への運動は先行する棒の設定に属する。

## 同じ試行の時計と観測者へ接続する

`sde` は同じ光が異なる出発・反射・帰着の出来事を結ぶ条件である。時計が静止していることや、出発位置と帰着位置が同じであることは要求しない。

`sdf` は、A端での出発、B端での反射、A端への帰着を、前段の動く時計の記録へ結ぶ。各時点の端点と時計の現在位置、静止系の局所時刻との指示の一致、同じ光・反射・真空中の二経路・試行を保持する。帰着時に出発時と違う場所へ移っていてもよい。

`sdg` は各時計のそばにいて共に動く観測者を結び、両者が同じ二時計・試行に既存の中点条件 `bi` を適用することを述べる。条件を適用したことと、「同期している」という肯定判定を分ける。時計の静止も観測者の静止も補わない。

`sdi` は、静止系での測定方法bによる棒長と、同じ三記録の読み、同じ単位による光速度・棒速度を時間式へ渡す。この長さを初期静止長や光が進んだ全距離に置き換えない。`sdj` が測定方法と実切断の式への接続である。

著者が時計の想定へこの観測者・光往復の設定を追加することと、光速度の原理に基づき二式を得ると述べることも記述した。後者は論証の帰属であり、全ての物理的な基本関係から導出を完成させたという検査器の認定ではない。

## 検査と限界

新規8件を含む関連36テストが通過した。有理数の12例では、動く場合、分数時刻、時刻原点の移動、静止極限を受け入れ、中点条件を勝手に課す場合、分母の交換、長さのすり替え、定義域外の入力を拒否した。

代数的な主張6件のうち、交点条件との同値、正速度での往路時間の長さ、中点条件と速度ゼロの同値、時刻原点変更、長さと速度の共通尺度変更の5件が成立した。動く時計が常に中点条件を満たすという主張には反例がある。

原文接続26例と帰属7例も検査した。光の片方の経路や反射の欠落、別試行、共動していない観測者、違う判定条件、帰着時の時計・場所・読みの取り違え、同期していない局所時計、測定設定・単位・速度の違いを区別する。

有限の接続検査では、作成した整数の切断に限る指示の一致と式の判定、明示した局所同期関係を渡す。実切断全域の条件の評価は有限実行器が拒否する。`sdc` の代数モデルを、物理的な全軌道・全位置の解釈から導く橋渡しは未完である。

標準表記・圧縮表記・固有文字の構文往復、CLIのJSONと構文木の一致、SVGのXMLとしての妥当性、入力ハッシュと検証記録の再現、進捗集計の整合性を確認した。SVGの目視確認と全テストの再実行は今回の検証に含めていない。

一般文書は基本述語4・定義41、原文接続文書は基本述語190・定義110・主張21である。正規表記は継承した定義を含め24,401文字、今回の追加は3,336文字となった。完成訳の圧縮率ではなく、表記量の記録である。

原文対応には二つの式 `M0060`・`M0061`、長さ `M0062`、三時刻と端点の記号を含む。`u0040` の観測者ごとの判定と、続く相対的同時性の結論への接続は残る。観測者・共動・近接・反射・測定の基礎、原刊照合、全文の意味確認も未完であり、意味確認済み全文単位はアインシュタイン0/282・カント0/20のままである。
