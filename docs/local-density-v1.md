# 球内の総電荷から局所密度を説明する

電荷密度を、同時刻の小さな球に含まれる総電荷を体積で割り、球の半径を正の側から零へ近づけた極限として記述した。この構成を、先行版の位置の履歴による速度の説明と組み合わせ、論文中の規格化密度と速度の関係へ接続する。新しい原始記号は追加していない。

| 定義 | 内容 |
| --- | --- |
| `seog` | 中心と時刻が一致し、三空間座標の距離が正の半径より小さい開球 |
| `seoh` | 体積が正で、総電荷＝平均密度×体積となる条件 |
| `seoi` | 正の上限より小さい全ての正の半径で、総電荷・体積・平均密度の関数が同じ条件を満たす |
| `seoj` | 平均密度が、半径を正の側から零へ近づけたとき指定値へ収束する |
| `seok` | 追跡点が属する分布、その場所・系・出来事・単位に球内の電荷と体積を結ぶ |
| `seol` | 物理的な電荷密度を、同じπの4π倍の規格化密度へ結ぶ |
| `seom` | 分布と単位規約を固定し、上記の説明を満たす規格化密度の帰属関係を構成する |
| `seon` | 構成した密度の関係を、履歴による速度の説明と既存の式の内容へ渡す |

速度を追跡する物質点と、その点が属する電荷の分布を別の対象にした。一点自体の電荷を小球の体積で割ると、一般に有限な連続密度の説明にはならない。分布の所属関係を明示し、その分布が球内に持つ総電荷を使う。分布は関係を構成する際に固定し、地点ごとに都合のよい分布を選ぶ存在量化にはしていない。

球は指定基準系の同時刻の三次元領域である。既存の断面積分`sedm`で体積を記述する。時空の四次元体積や、物質と一緒に動く境界をこの球と同一視しない。総電荷・体積・平均密度の関数は全て同じ半径を受け取り、各半径で総量と比が整合しなければならない。

総電荷と密度の負値・零は許すが、体積は正でなければならない。極限の接近領域は`0 < r < upper`であり、平均密度の零半径での値は使わない。上限にも正値を要求し、空の領域から極限を成立させない。球平均による局所極限を採用した構成であり、任意形状の縮小領域との一致、全地点での存在、点電荷の有限密度は主張しない。

長さ・時刻・電荷の単位を参照関係に含めた。座標の数値をL倍、総電荷の数値をC倍に変えるなら、体積の数値はL³倍、密度の数値はC/L³倍となる。この数値変換について、総量＝密度×体積が保存される有理数の代数条件を検証した。Q=12、V=3、密度4からL=2、C=3へ変える例では、Q'=36、V'=24、密度3/2となり、密度の数値を4に据え置く条件は成立しない。これは単位の物理的な校正の完了を示すものではない。

検査では、球の境界・時刻・半径を変える7例、符号付きの平均と体積の12例、5種類の密度関数と3半径の組合せ15例を使った。20の対照例で、物質点・分布・系・出来事・地点・文脈・単位・球領域の取り違えを検出した。さらに、体積の零・負値、比の不一致、誤った極限値・規格化値、空の接近領域、πの指定不足を分けて検査した。元の文書と必要な定義だけを抽出した文書で結果が一致する。

接続検査の全域の関数条件・極限・体積・πは、明示した検査用の解釈に依存する。検査のπには便宜的な値3を使い、数学的なπとして認定しない。実際の有理数の極限条件については、アフィン関数の片側極限と負値・零の定数関数が成立し、誤った極限値と空領域では成立しないことを別に検証した。全実数にわたる関数条件と極限を有限解釈器に直接渡すと、量化を拒否する。有限個の半径の検査から一般の密度の存在を証明したことにはしていない。

`seon`では同じπの指定を外側にも要求し、構成した密度関係を既存の速度の構成へ渡す。前版の未展開の帰属関係`zqd`との無条件の同値や、この構成を著者自身が提示したという新たな主張は追加していない。電気量の測定・校正、一般の加法的な電荷測度や三次元測度との接続、原文単位全体の意味確認は残る。
