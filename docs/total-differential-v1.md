# 全方向に共通する一次近似の条件

場の微分値を変換する条件の基礎として、有限次元の全微分可能性をNoemaで定義した。ある点で各座標方向の偏微分があることと、複数の座標を同時に動かしても同じ一次近似が成立することを分ける。原文への数学的な解釈注記であり、新しい本文範囲を完成したとは数えない。

一般定義には有限の軸列、実数値関数、領域、基準点、勾配を渡す。軸列は空でなく、同じ軸を重複して含まない。変位の大きさは、指定軸の数値成分の絶対値を加えたL1ノルムで測る。ここで扱うのは数値座標の近傍であり、物理的な時空間隔の定義ではない。関数へ渡す点は指定軸以外を零にし、未指定の成分が評価へ入り込まないようにした。

一次近似の剰余は `F(p+h)−F(p)−Σgᵢhᵢ` である。基準点の周りに正半径の開球を一つ要求し、その球が領域に含まれ、全点で関数値が有効な実数になることを明示する。その上で、次の順序で量化する。

1. 任意の正のεを取る。
2. そのεに対し、局所開球の半径以下の正のδが存在する。
3. `0<‖h‖₁<δ` を満たす全ての変位で、剰余の絶対値が `ε‖h‖₁` より小さくなる。

δはその近傍の全方向で共通である。変位ごとに都合のよいδを選ぶ条件や、有限個の点だけを調べる条件にはしていない。領域が空の場合や、一方向からの点列だけで近傍を代用することも除く。

区別の検査には `F(x,y,z,t)=xt/(|x|+|t|)` を使った。x=t=0では値を零とする。原点から各座標軸だけに沿って動くと値は零なので、四つの偏微分は零である。一方、x=t=h>0と同時に動くと値はh/2になる。零の勾配とε=1/8では、許される誤差はh/4であり、どんな正のhでも一次近似の条件を満たさない。小さな三尺度でのNoemaの剰余検査に加え、任意の正の有理数hについてこの不等式を検査した。

一次関数では全四変数の任意の変位で剰余が零になること、二次関数 `x²+y²+z²+t²` では剰余が変位の二乗和になることを有理数の代数で確認した。二次関数の誤差が十分小さい近傍で一様に抑えられる不等式も確認している。これらの補題を、任意の実関数の連鎖律の機械的証明とは扱わない。

場への適用では、四引数の関数と領域を、四座標ベクトルを受け取る形へ接続した。同じ二場・領域・点の六成分について、それぞれ同じ四つの勾配値を全微分可能性の条件へ渡す。別の条件として、前段の24個の偏微分との一致も保持した。全微分可能性から各偏微分への接続を自動的に証明済みとはせず、現在は両方を明示する。

逆変換先の旧点でこの条件を満たすなら、新点の変換した場が変換した勾配で同じ条件を満たす、という連鎖律の命題もNoemaで記述した。ただし、一般の実切断での証明は未完である。逆写像で近傍と誤差がどう変わるか、実数の演算法則、物理的な測定・単位・真空の意味との接続は残る。

一般の定義は、実際に依存する定義だけを取り出した独立文書にも保存した。基本記号は既存の有理数の順序・加算・符号反転・乗算の四つであり、物理的な場を表す基本記号を含まない。二軸での使用と軸の並べ替えを検査し、四座標だけに固定した定義ではないことを確認した。

剰余の12例、同時方向の反例15例、場の勾配の接続6例と、有理数の補題5件を検査した。局所開球とε・δによる全微分条件については、有限検査器が評価を拒否する。場の接続には全微分・偏微分を検査用の関係で指定する箇所があり、それを一般の微分の認定には使わない。
