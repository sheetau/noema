# 文語の進捗集計（2026-09-30）

任意の内容に対する「表現率」は未測定である。評価対象の二作品について、既存の対応表から部分草案の範囲を集計した。草案があることと、原文の意味を十分に表せたことを区別する。

| 対象 | 部分草案がある区間 | 原文範囲を明示した草案の文字数 | 意味一致の確認を終えた区間 |
| --- | ---: | ---: | ---: |
| カント1784 | 3 / 20（15.00%） | 2,127 / 15,513（13.71%） | 0 / 20 |
| アインシュタイン1905 | 23 / 282（8.16%） | 392 / 35,614（1.10%） | 0 / 282 |

区間には見出し・本文・数式・著者注があり、長さは均等ではない。一部分の草案でも区間数には数えるため、15%や8.16%を全文の完成率とは呼べない。

文字数は空白と数式の代用マーカーを除き、明示された原文範囲の和集合で数えた。同じ箇所を更新した複数の草案は重複加算しない。対応区間だけが指定され、開始・終了位置のない草案は、この文字数には含めない。特にアインシュタインの草案には数式や区間単位の対応が多く、1.10%は草案全体の分量を示さない。数式要素については、446要素中25要素（5.61%）に部分的な対応がある。これも数式の意味確認率ではない。

明示的なモデルを仮定した解釈注記も、対応記録のある部分草案として集計に含む。今回の介入比較の注記はその一例であり、その原文範囲を同義に記述し終えたことを示さない。

カント第二段落には、末尾の例による萎縮と通常の回避まで部分草案を接続した。空白を除く1,211文字のうち、明示的な対応範囲は1,164文字（96.12%）である。これは上表と同じく範囲の指標であり、その意味を全て表せた割合ではない。家畜や歩行器、転倒と歩行の描写、認知状態の変化のほか、対応範囲内にも譲歩・機構・程度・皮肉・基礎概念など未記述の意味要素が残る。96.12%を段落の完成率とは扱わない。

40件の対応表と、それらが固定した79件のNoema文書を検査した。文書のハッシュと構文、原文のハッシュ・範囲・引用、参照する記号、数式の所属を確認した。編集者による資料、未記述の範囲、文脈として言及するだけの区間は除いた。歴史的な検証時点の実行環境まで再検証した集計ではない。

この集計は構文の検査や対応記録の監査であり、意味の同一性を判定するものではない。意味確認済みの区間は現在記録されていない。今後、完成済み件数が正になった対応表が追加された場合、集計器は停止し、区間別の意味確認手順を追加することを要求する。

検査結果は [written-progress-v1.json](../reports/written-progress-v1.json)、集計器は [audit_written_progress.py](../scripts/audit_written_progress.py) に保存した。

```powershell
python -S -m scripts.audit_written_progress --verify-only
python -m pytest tests/test_written_progress.py -q
```
