# 文語の進捗集計（2026-10-13）

任意の内容に対する「表現率」は未測定である。評価対象の二作品について、既存の対応表から部分草案の範囲を集計した。草案があることと、原文の意味を十分に表せたことを区別する。

| 対象 | 部分草案がある区間 | 原文範囲を明示した草案の文字数 | 意味一致の確認を終えた区間 |
| --- | ---: | ---: | ---: |
| カント1784 | 3 / 20（15.00%） | 2,171 / 15,513（13.99%） | 0 / 20 |
| アインシュタイン1905 | 118 / 282（41.84%） | 12,995 / 35,614（36.49%） | 0 / 282 |

区間には見出し・本文・数式・著者注があり、長さは均等ではない。一部分の草案でも区間数には数えるため、15%や41.84%を全文の完成率とは呼べない。

文字数は空白と数式の代用マーカーを除き、明示された原文範囲の和集合で数えた。同じ箇所を更新した複数の草案は重複加算しない。対応区間だけが指定され、開始・終了位置のない草案は、この文字数には含めない。特にアインシュタインの草案には数式や区間単位の対応が多く、36.49%は草案全体の分量を示さない。数式要素については、446要素中221要素（49.55%）に部分的な対応がある。今回の速度成分の変換で9要素増えた。地点・時刻・長さの文字記号も含むため、この件数を完成した数式の本数や意味確認率とは扱わない。

明示的なモデルを仮定した解釈注記も、対応記録のある部分草案として集計に含む。過去に追加した介入比較の注記はその一例であり、その原文範囲を同義に記述し終えたことを示さない。

カント第二段落では、空白を除く1,211文字のうち、明示的な部分草案の対応範囲が1,208文字になった。範囲外の3文字は節の境界の句読点である。この数字は段落の完成率ではない。範囲内にも家畜や歩行器、転倒と歩行の描写、譲歩・機構・程度・皮肉・基礎概念など未記述の意味要素が残る。これからの段落の進捗は範囲の拡大だけで判断せず、[現在の意味確認の課題](caused-conditions-v1.md)を解消した証拠で判断する。
