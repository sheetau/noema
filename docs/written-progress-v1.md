# 文語の進捗集計

現在の正本・登録簿・集計結果は [work-state.json](../data/work-state.json) から参照します。数値と次の作業は [STATUS](STATUS.md)、検証コマンドは [WORKFLOW](WORKFLOW.md) にまとめています。

部分草案の対応範囲、原文の単位数、単位全体の意味確認済み分量は別の指標です。対応文字が100%になっても、未説明の概念や未接続の主張が残れば完成ではありません。判断は明記した解釈の下でのアシスタントの読解であり、独立査読や自動同義性証明ではありません。

2026-10-20までの集計説明は [履歴](written-progress-history-through-20261020.md) に改変せず保存しました。旧集計 [written-progress-v1.json](../reports/written-progress-v1.json) と既存検証器は再現用に保持します。新しい集計は [written-progress-v2.json](../reports/written-progress-v2.json) です。
