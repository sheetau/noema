# KWDLCの正解位置の不備と修正

**旧コーパス評価の主辞位置と、それに基づく参照判定器v1の学習・選択を撤回する。** 公開コーパスに注釈されていない語位置を、こちらの取り込み処理が正解主辞として扱っていた。生成を使わない条件やモデルの再現性とは別の、評価と監督信号の不備である。

## 原因と影響

[KWDLCの配布形式](https://github.com/ku-nlp/KWDLC#format-of-the-corpus-annotated-with-annotations-of-morphology-named-entities-dependencies-predicate-argument-structures-and-coreferences)では、参照先は文IDと基本句IDで指定される。一方、取得した版の形態素には、rhoknpの主辞取得処理が読む「内容語」「準内容語」「基本句-主辞」の特徴が付いていなかった。

従来の`corpus_document`は`phrase.head`を正解位置として使っていた。このAPIは対象の特徴がなければ句の先頭形態素を返す。たとえば括弧で始まる句で開き括弧が主辞になり、モデルが句内の内容語を選んだことを誤りと数えていた。

[全配布文書の監査](../reports/corpus-reference-v2/preparation.json)で次を確認した。これは一部の括弧だけの問題ではない。

| 分割 | 文書数 | 基本句数 | 主辞取得用の特徴がある句 | 先頭語へのフォールバック |
| --- | ---: | ---: | ---: | ---: |
| train | 3,915 | 92,971 | 0 | 92,971 |
| dev | 512 | 11,019 | 0 | 11,019 |
| test | 700 | 16,973 | 0 | 16,973 |

先頭語が実際の主辞と重なる例もあるが、それを全句で保証できない。旧評価の「正解主辞」「主辞欠落」「主辞位置に基づく参照ペア精度」は根拠にできない。前回の再現率上限82.61%という診断も撤回する。参照判定器v1はこの位置対応を監督信号にも使っているため、重みと選択結果を無効とし、研究用API・重み読込み・旧学習コマンドが無効化記録を検出して拒否するようにした。

元の原文、参照の基本句ID、固定モデルの予測と特徴量、文字位置保存の検査、反復一致は保持する。過去の結果は削除・書換えず、各報告の`invalidated.json`と資料冒頭で撤回範囲を示す。旧コードの数値再現はコミット`9d6900d`の時点の実装に対応するが、その再現性は正解データの妥当性を証明しない。

## 修正した正解と評価

新しい取り込み処理は、実際に注釈されている**基本句全体の原文範囲**を関係の端点にする。主辞取得APIを呼ばず、基本句の先頭から末尾までの形態素位置で範囲を作る。語の辞書、品詞による主辞推測、文字列別の修正は使わない。

基本句の境界が少しでも異なる場合、範囲一致とは数えない。境界の重なりや予測した主辞の包含だけで正解へ寄せる処理もない。明示的な文書内同一参照のグループをこの範囲で比較し、原文・参照ラベル・参照先ID・分割は以前の資料から変えていない。複数対象・曖昧な参照、外界参照は引き続き評価上の制約であり、公式の照応評価全体やNoemaの意味精度とは呼ばない。

既存の固定解析を変更せず、dev512文書を再集計した[結果](../reports/corpus-reference-v2/native-development.json)は次のとおり。

| 項目 | 修正した評価 |
| --- | ---: |
| 基本句の範囲一致 | 10,667 / 11,019 |
| 欠落／過剰な基本句 | 352 / 355 |
| 基本句集合の文書完全一致 | 361 / 512 |
| 正解の参照ペア | 602 / 920 |
| 余分な参照ペア | 536 |
| 参照ペア適合率／再現率 | 52.90% / 65.43% |
| 基本句集合と参照グループの文書完全一致 | 185 / 512 |

40文書のモード付き参照はペア評価では未対応として残している。正解参照ペアがある301文書の完全一致は66件、ペアがない171文書では119件だった。新旧の値は評価単位が異なるので、改善率として比較しない。

この不備は、既存モデルの主辞スコアを直接取り出す診断中に見つかった。その診断用API自体は実装したが、`native-heads-v1`の旧正解位置に対する精度は無効とする。候補を増やすことの有効性を示した結果として扱わない。

## 検証と次の作業

```powershell
artifacts/kwja-venv/Scripts/python.exe -m scripts.prepare_phrase_reference_corpus
artifacts/kwja-venv/Scripts/python.exe -m scripts.evaluate_phrase_references
artifacts/kwja-venv/Scripts/python.exe -m scripts.verify_phrase_reference_corpus
```

準備・評価は保存先を上書きしない。新しい資料は`artifacts/corpus-reference-v2`、報告は`reports/corpus-reference-v2`に保存する。主辞APIを呼ぶと失敗するテスト用コーパス、句境界の不一致、解析失敗の分母、未対応注釈、無効化モデルの読込み拒否を検査した。

[全資料の再検査](../reports/corpus-reference-v2/verification.json)で5,127文書を原本から再構築し、原文・関係ラベル・関係ID・分割が旧資料と同一であること、dev512文書の未変更の予測から評価を再現できることを確認した。全332テストが通過した。[主辞スコア抽出の検査](../reports/native-heads-v1/verification.json)でも512件の記録照合と原文8件の反復一致、禁止経路0回を確認したが、その検査記録には主辞の精度評価が無効であることを明記している。

次は、修正した基本句範囲で候補と監督信号を対応付け、共通参照判定器を学習し直す。文脈ベクトルは固定モデルの予測主辞から取れていても、正解との位置対応は注釈済みの基本句範囲で行える。既存の特徴を再利用する際もモデル・原文・句IDとの対応を検査する。これまでに見たtestを新規の独立評価とは呼ばず、最終的な採用には別の未使用資料による評価を要する。

全文意味構造95%以上、広い日英入力への対応、辞書に依存しない双方向変換、表記の冗長さの解消は未完了のまま維持する。
