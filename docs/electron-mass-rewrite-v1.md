# 式(A)の三行六等号への書換え

原刊919頁のu0252第二文とu0253（M0417）を、直前と同じ電子・出来事・二系の設定に接続する。第一文の縦横質量の問いは、後続の力と加速度の規約を含む次の判断へ残す。u0252全体の意味確認件数は増やさない。

必要な関係は、(A)への照応、同値な書換えの提示、各行の二つの等号、同じ実加速度と実電場、同じ指定点の座標対応である。既存のPAIR、ek63、ek66、elb、ek74、zd3、eiswm、eisoxを再利用する。新しい基本記号は導入と表示の箇所への参照だけである。

三行は次のとおりである。

- μβ³ ax = εX = εX′
- μβ² ay = εβ(Y − vN/V) = εY′
- μβ² az = εβ(Z + vM/V) = εZ′

elqは左辺と中辺、elrは中辺と右辺を構成する。右辺は独立に与えた同じkの実電場を、旧指定点の写像ek5iで評価する。場の変換から得た数値関数を実電場の定義として使わない。elsが六等号とKの右側初期変化を合わせ、eluが先行(A)と同じ38束縛の物理設定へ結ぶ。実二階微分、両系の単位、電子と時点の帰属は先行ek63に保持する。

eltは同じ設定と既出変換の下でelbとelsが同値である内容である。本文ではzd3を用い、著者が同じ変換内容ek7sの下で(A)のelkをeluへ書き換えて提示すると記述する。これは提示の帰属であり、引用内容の真理や同値性の自動証明ではない。

数値対照では両等号を別々に破り、負の電荷、縦の非零加速度、横の符号、三軸、βの次数、実新電場の取り違えを検査する。さらに原点以外の座標と原点ずれを使って、旧点を新電場へ直接渡す誤りを区別する。数値境界では零電荷で第二等号が成立しても場変換の逆推論はしない。物理的な電子設定への適用条件とは別の代数的な対照である。

全設定の量化は実際の束縛ごとに二値の診断を行い、引数のASTを公開する役割表から独立に作った契約と比較する。有限モデルによる全実数・全関数域の認定、未知入力の補完は拒否する。解析的な二階微分は変更のない先行検査の証拠を継承する。

u0253全体は、原刊、固定MathML、三行の左右、先行(A)と次の力の説明を再読して判断する。原刊の横係数μβ²を現代の別規約のμβへ修正しない。物理的な力の同定、ばね秤による可能な測定、質量の命名、規約の選択、係数の一意決定はu0254以降の未完事項であり、今回の数値式だけで完成としない。
