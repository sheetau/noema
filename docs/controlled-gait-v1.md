# 全過程の制御を持つ歩行の描写

カントの段落末にある「確かな歩み」の身体的な描写側を追加した。脚による身体移動に、姿勢・荷重の均衡と足の配置の制御を結び、その同じ活動の全過程での成立を要求する。転倒の不在だけを安定性の定義にしない。

## 同じ活動の全過程

一般構成 `rcq` は、既存の履歴・順序・区間の定義を使う。評価する範囲は、同じ履歴に含まれる非空の区間であり、完了点とそれより前の点を含む。範囲の全点は完了点以前でなければならない。一点だけの観測、途中を除いた範囲、完了点の後まで続く範囲は、この完了した活動の条件を満たさない。

身体移動の生起と、各時点での制御には、同じ本人と活動を渡す。範囲の全ての時点で、身体の均衡と足の配置の制御の両方を要求する。始点と終点が安定していても、途中に制御できていない時点があれば成立しない。

この構成は、履歴と範囲が現実の全過程を表しているという前提に依存する。有限の観測点の間に何が起きたかを保証するものではなく、安定していた部分だけを選ぶ根拠でもない。一般用の新しい基本関係や文法は追加していない。

## 原文の描写への接続

原文側では、既存の脚による身体移動 `zai` と、活動の生起 `dg` を再利用した。`h4v` は姿勢・荷重の移し方についての均衡の制御、`h4w` は移動の方向と支持に沿う足の配置の制御を表す。毎瞬間足を動かすという条件ではなく、支持中の配置と次の配置への移行を制御するという意味規約を置く。

`h4x` は、同じ完了点で記述する活動の全過程の範囲を指定する。`h4y` はこれらを同じ本人・基準文脈の履歴へ接続し、基準時までに完了した活動であることを要求する。`h4z` はそのような身体移動を持つ人の描写内容である。未来の完了を済んだ活動として数えない。

原文の確かな歩みという表現に、他者や装置による補助が一切ないという条件は加えていない。既存の歩行訓練の用途 `zal` は補助の不在を含むため、その定義をそのまま転用せず、身体移動の部分 `zai` を使った。補助を受けながらも本人の制御がある場合を、この構成だけで除外しない。

制御の基本関係には、まだ力学的な条件・許容差・知覚運動の機構が必要である。歩行と走行の境界、確信・安全性・技能の持続など「確かさ」の全語義も完成していない。一つの活動の制御から、あらゆる外乱への頑健性や将来の無事故は導かない。

## 知的な自立との区別

身体的な歩行 `h4z` と、自分の精神への働きかけによる自立の達成 `h4q` は独立した内容として保持した。前者を後者にそのまま論理積で加えると、比喩で述べた知的な活動の安定を、現実の身体能力の条件へ置き換えてしまう。

今回は身体的な描写の条件を構成した段階である。安定した知的活動を対象側として定義し、両側の対応と譲歩を記述するまで、少数者の結論には加えない。以前の13主張はそのまま保持し、新しい本文主張を追加していない。

## 検証と進捗

3時点での均衡・足の配置の制御、活動の生起と身体移動の256組を検査した。空・一点だけ・途中の欠落・履歴外・循環する順序・完了点以後の範囲と、本人や活動の取り違え16例も拒否した。

実際の定義を展開した一階論理の検査では、完了点と全範囲での制御、完了点以後の点の不在、同じ範囲の完了点の一意性を検証した。一方、「両端の制御だけで足りる」「転倒していなければ足りる」という推論には反例を得た。これらは明示した意味モデルの性質であり、人体の制御機構の物理的な証明ではない。

原文接続の16例では、中間の制御の欠落、別の活動の範囲、別人の均衡、未来の完了を区別した。補助の存在による自動的な拒否を避け、歩行が成立しても自立の達成が成立しない例と、その逆の例を確認した。関連39テストが通過した。

保存した検証記録の再生成一致、通常・短縮記法と固有文字の往復、2文書のCLIによるJSONと構文木の一致、SVGのXML形式も確認した。字形の目視検査は今回行っていない。
