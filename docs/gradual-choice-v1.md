# 実行と不実行を選べる能力の段階的な増加

カント第17区間の条件文の後件へ、行為の選択能力が段階的に増すという候補を接続した。同じ活動を実行できる方法と、実行しないでいられる方法の両方を持つことを、その活動の選択能力とする。**反作用の因果関係と政治的な帰結は未充足**であり、原文全体の意味一致を確認したものではない。

## 能力、許可、実際の行為

[一般定義](../examples/v016/gradual-choice.noema)の `rxc` は、同じ本人・目標内容・時点について、既存の `xd` で実行側と不実行側の能力を別々に判定する。それぞれに本人が利用可能な方法があり、非空の評価結果が想定結果に含まれ、その全結果が該当する側の内容を満たす必要がある。

| 利用可能な方法 | 選択能力 |
| --- | --- |
| 実行できる方法と、不実行を実現できる方法がある | ある |
| 実行できる方法だけがある | ない |
| 不実行を実現できる方法だけがある | ない |
| 一つの方法が、実行する結果としない結果の両方を含むだけ | その方法だけでは確認できない |

二つの側で別の方法を使ってよいが、本人・内容・時点・方法空間・結果の評価基準は共通である。非空の同じ評価結果を持つ一つの方法が、同じ内容とその否定の両方を保証することはない。別の行為を選ぶことで対象の行為をしない場合も、不実行の方法に含められる。

これは方法と結果による選択能力の候補である。規範的な許可、判断の自律、責任など自由の全側面は説明していない。また、能力があることから現在その活動を実行したとは導かない。

`rxd` は両側に既存の `xf` を適用する。成功する方法を一つ確認できるか、全方法の結果の評価範囲が整合することを求める。まだ評価できていない方法があるという理由だけで「選択能力がない」と数えない。

## 同じ活動集合で増加を測る

`rxe` は、固定した活動一覧について `rxc` が成立しない活動を数え、既存の単調な漸減 `rl6` に渡す。活動一覧は非空で、重複なく対象範囲を完全に列挙する。区間内の全時点で全活動が評価済みであることも要求する。

この構成では選択能力を失わず、少なくとも二回増加し、隣接時点の増加が指定の正の上限以内になる。例えば上限1なら、選べる活動が「1個→2個→3個」は成立し、「1個→1個→3個」は成立しない。「1個→2個→2個→3個」の停滞は許す。件数が同じように増えても、以前の選択肢を失って別の活動へ入れ替えた場合は拒否する。

活動範囲、時間の刻み、上限は解釈の入力であり、望む結果を得るために変更しない。活動数の単調な増加という強い読みで、熟練度、局所的な後退、連続変化、実時間に対する速度の全内容は表していない。

## 条件文への接続

[本文草案](../examples/v016/kant-gradual-choice.noema)の `iajexecution` は、活動が実際に起こることと、同じ本人が自分の行為として遂行することを連言する。別人が行っただけでは本人の実行にならない。遂行関係の身体的・意思決定上の基礎説明は残る。

`iajgrowth` は活動一覧と上限を開始点で固定し、前段の同じ仮定履歴と時間順序を使って選択能力の増加を調べる。`iajschema` は前段の条件文の後件にこの増加を加え、残りの条件 `remaining` と連言する。同じ語義・本人・起点・終点を残りの条件へ渡すため、違う候補の発展や別の時点の作用を継ぎ合わせない。

現行の候補は各人の能力増加を要求する分配的な読みであり、集合としての民衆の能力とは同一視しない。前件が偽の仮定について能力増加を断定せず、ひな形の著者への帰属だけでも内容を実行しない。親文書の全宣言と先行21文を保存し、最後の部分注記を更新した。

## 検査と残る課題

101件のテストが通過した。三時点の能力数64組合せに加え、選択肢の入替え、停滞、一度の急増、活動一覧の欠落・重複、不正な順序、評価不足、未知入力を区別した。本文の検査でも能力を真偽値で代用せず、実際の方法と結果の定義を評価した。実行と不実行を選べても、現在は実行していない例を含める。
