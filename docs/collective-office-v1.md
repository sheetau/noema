# 最高統治役職の共同保持

カント第17区間の `Freistaat` に、最高の統治役職を複数人で担う制度の候補を追加した。保持者を全員列挙するだけでなく、各人の判断が制度上の決定を変え得ることを要求する。国家や共和国の語義全体を完成したとは扱わず、市民的・国家的な構成条件を明示的な引数として残す。

## 読みの根拠と範囲

Adelungの[Freystaat](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_1_2_2733)は、自由な国家という広い意味に加え、君主制に対する共和国という狭い用法を示す。[Republik](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_6_1_1236)では、狭い用法として最高権力を複数に委ねる制度が説明される。今回は後者の側面を具体化した。

参照したMDZの電子転写は1811年版で、1784年のカント本文より後の資料である。原刊画像との照合はしていない。唯一の歴史的解釈を確定したのではなく、本文に付す候補解釈として記録する。[取得記録](../data/republic-reading-review-v1.json)には出典、文字コード変換、保存物のハッシュを残した。

辞書が特定の投票方式を定めているわけではない。以下の二値決定規則は、共同保持の一側面を検査するために選んだ形式化である。選挙、普通選挙、等しい票の重み、多数決を共和国の条件として補わない。

## 人数と意思決定への関与

[共通定義](../examples/v016/collective-office.noema)は既存の列、関数、量化、役職順序を合成する。新しい文法演算子は追加していない。

| 定義 | 条件 |
| --- | --- |
| `rwl` | 保持者列の順序に沿って、各人の二値入力を列にする |
| `rwm` | 他の入力を固定し、その人の入力だけを反転すると決定が変わる組合せがある |
| `rwn` | 全保持者を重複なく列挙し、二人以上で、全員が `rwm` を満たす |
| `rwo` | 同じ組織・時点の役職順序が厳密な部分順序であり、指定役職が他の全対象役職より上位にある |
| `rwp` | その最高役職の保持者が全員人であり、同じ決定規則で `rwn` を満たす |

役職の上下は統治上の意思決定権限についての関係であり、席次ではない。比較不能な別の最高役職がある場合は `rwo` を満たさない。この構成は一つの最高役職を共有する制度に限られ、権力分立や連邦制の一般的な定義ではない。

保持者が三人なら、八通りの二値入力を調べる。多数決、全員一致、少なくとも一人の賛成などを区別できる。一人の入力だけを決定として使う規則は、他の二人に影響可能性がないため失敗する。全員の影響可能性だけでは、決定規則の単調性、実際の政治的影響力、強制の不在、独立した意思形成は保証しない。

並び順と決定規則の位置は対応する。人の順序だけを逆にすれば、位置に依存する規則で影響を持つ人も変わる。列外の個体の全関数は列挙せず、指定した保持者の全入力を既存の `rs` で生成する。計算量は保持者数に対して指数的である。

## 本文への接続

[本文草案](../examples/v016/kant-collective-office.noema)の `iabsharing` が最高役職・全保持者・規則を選び、`iabpolity` が残る市民的・国家的条件と合わせる。単なる会社の取締役会を自由国と認定する構成にはしない。この残余条件は未充足であり、国家の統治範囲、規範変更権能、対外的地位などを説明する必要がある。

`iabcontrast` は、この分類を前段の発言資格と非許可の条件へ渡す。親の全宣言と先行19文を保持し、最後の候補解釈の帰属を更新した。引用の帰属を記述する時点では、制度や発言内容を実行評価しない。

有限診断では、国家を表す集団と個人の話者を別の対象にした。前段の検査例が引用の話者参照を一人の人物に固定していたため、検査例の参照選択だけを、集団なら集団の記述を返す形に変更した。人を表す元の記述は保持する。集団を人の記述へ誤って接続すると、非許可の上位条件は成立しない。

分類される主体が空なら、その全員への非許可は全称条件として真になる。一人が独占する制度を分類から除外した結果は、その制度に非許可が成立する証拠にはならない。本文の対象範囲の妥当性と、非許可を判断する基準の説明は残る。
