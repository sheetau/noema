# 範囲の学習量と役割候補の作り方を分ける実験

前回は、開発資料に継続タグIがなく、役割学習にもnoneの例がないまま、複合・修飾表現で多数の分割誤りが生じた。個別語の結合規則を加えず、範囲の学習資料と、役割を学習する候補の作り方を比較する。

従来の16学習述語群に32文、4開発述語群に8文を追加する。複合名詞、形容・連体修飾、関係節を含める。注釈は指定した一つの出来事の4役割だけであり、内部の出来事や所有・修飾の意味構造が完成したとは扱わない。語句の原文範囲を保持しても、その内部の意味が分解できたことにはならない。

範囲ヘッドでは、同じ拡張済み開発16文を使い、学習32文と64文を比較する。線形・64次元tanh、seed17、AdamW、学習率0.003、重み減衰0.01、全件バッチ、200エポックまで、開発平均交差エントロピー最小という条件を維持する。BIOの有効列を対数確率の和で選び、正解と語境界が合わない場合は停止して記録する。

役割学習は64文の範囲ヘッドを使い、二つの候補条件を比較する。一つは学習64文そのものを学習済み範囲ヘッドで再解析する従来条件。もう一つは、学習述語群の名前をソートして順番を4で割った余りで4分割し、3分割で範囲ヘッドを学習して残る1分割の候補を予測する条件とする。分割ヘッドには、全学習と開発から選んだ範囲ヘッドの方式とエポック数を固定して使う。候補を作る際、対象文と同じ述語群を範囲ヘッドの重み学習に使わない。

4分割で作った候補の範囲が正解と完全一致する場合だけ役割の教師を与え、他はnoneとする。範囲誤りが一件も生じなければ、noneを学習できなかった事実を報告する。手製の誤りや語別規則は追加しない。注釈のない内部の述語は従来どおり損失から除外する。

役割の線形・64次元tanhヘッドを両候補条件で学習し、開発16文の平均交差エントロピーで方式・候補条件・エポックを選択する。開発と実行時には全64文で学習した範囲ヘッドを使う。範囲32文条件は学習量の診断であり、実行時の候補方式の選択には混ぜない。

全選択の保存後に、新しい4述語群8文を原文から解析する。従来の40評価文は既知の回帰資料として扱う。保存済みv1も同じ資料で比較し、各条件の予測をすべて残す。範囲と役割の完全一致、余分な項、欠落、注釈済み出来事の全項一致を報告する。全項一致を全文意味構造95%以上と呼ばない。

モデルや語彙ごとの規則は更新せず、生成・辞書の禁止経路を検査する。原文からの再解析、保存結果との一致、再学習の再現を確認する。結果に応じて新規8文の正解やモデル選択条件を変更しない。
