# 同じ読みを保持する条件文と後続時点

カント第17区間の「発展したなら、その後……」という接続に使う条件のひな形を追加した。前段の二つの発展の読みから一つを選び、同じ人・仮定状況から後の結果へ結ぶ。**社会への作用を表す後件は未充足**であり、この追加を原文の新たな文字範囲や意味一致の完了には数えない。

## 条件の成立と実例の存在

[一般定義](../examples/v016/conditional-aftermath.noema)の `rxa` は、空でない仮定状況の集合を受け取る。それぞれの状況には、自分自身を含む履歴と、既存の `ta` を満たす厳密な時間順序がある。選んだ性質の記述を同じ人について評価し、前件が真なら、その履歴の後の時点で結果が成立することを要求する。

結果を表す関数には、選んだ記述、人、前件の成立点、結果の成立点を渡す。別の人や別の仮定の結果を流用しない。別の記述が偶然同じ真偽になっても、結果へ渡す記述を置き換えない。

| 指定した範囲の状態 | 条件 `rxa` | 前件の実例 `rxb` |
| --- | --- | --- |
| 全ての前件が偽、履歴は有効 | 真 | 偽 |
| 前件が真の全ての仮定に適切な後の結果がある | 真 | 真 |
| 前件が真の仮定のどれかに後の結果がない | 偽 | 真 |
| 仮定範囲が空 | 偽 | 偽 |

`rxb` は既存の `re` を使う独立した診断である。適用例が必要な場面で明示的に要求できるが、本文の条件に追加していない。どちらも基準文脈そのものの前件や後件を断定しない。

## 前段の発展の候補との接続

[本文草案](../examples/v016/kant-conditional-aftermath.noema)では、`iaiconditional` が仮定状況・履歴・順序を同じ本人と基準文脈に固定する。`iaiframe` は前段の `iahfamily` により、自由な思考への志向と内的な衝動の発展、または志向と課題の付与の発展という二候補から一つを選ぶ。この選択は対象者と仮定状況への量化の外側に置き、都合に応じた読み替えを防ぐ。

`iaiattribution` は、このひな形の階数2の記述を同じ箇所・著者・範囲・文脈に帰属する。帰属を評価するだけでは内容を実行しない。親文書の宣言と先行21文を保存し、最後の注記を更新した。文法演算子や翻訳機は変更していない。

後件 `result` は関数引数として残した。時間的に後の出来事があるだけでは因果や反作用を説明できないため、原文の作用を単なる前後関係へ置き換えて完成扱いしない。今後、民衆の態度への漸進的な作用、自由な行為能力の増加、政府の原則と尊厳をこの引数へ具体的に接続する必要がある。一人ずつの発展と集団への作用の対応も未完である。

## 検査と再現

54件のテストを確認した。二つの仮定における前件と後件の16組合せ、記述の同一性、候補ごとの読み替え、人物・基準文脈・履歴の取り違え、同時点や過去の結果、空の範囲、不正な順序、未知入力を検査する。本文では前段の発展の定義そのものを実行し、内的な衝動と課題の付与の4組合せに対して、条件と実例を分けて評価した。

有限診断には既存の明示的な短絡評価を用いる。後件の起点を命題内容の全状況へ展開すると、前件が偽の仮定の未知の結果まで評価されるため、後件を各仮定の条件の内側で直接判定する形にした。全前件が偽の場合に加え、一方だけが真の場合にも不要な後件を実行しない。通常の評価器の先行評価方式は変更していない。一般定義と本文の基準例はキャッシュなしでも一致した。

三文書の長形式・短縮形式・固有文字の往復、CLI解析、抽出文書のSVGのXML検査も通過した。SVGのXML検査は目視検査ではない。[意味規約](../data/conditional-aftermath-basis-v1.json)と[検査記録](../reports/conditional-aftermath-v1.json)に、未充足の後件と検査の限界を記録した。
