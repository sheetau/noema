# 確認資料v2の予測前点検

固定した条件から1,344文を作成した。日本語672文、英語672文で、各言語600文が対応範囲内、72文が未対応である。作成時にモデルや予測を読み込んでいない。草案からの内容修正はなく、最初の出力を確認資料として固定した。

全6述語の肯否と代表文を点検した。「今後、11人の子供は鳥を家で追わない」は、英語の `11 children, in the home, will not chase the bird.` と対応する。11は主体の数量で、鳥の数量は未指定である。「37人の先生はLeonによって公園で見られる」ではLeonが主体、37人の先生が対象となり、英語の受動態でもこの役割を保持する。送付・所有などの文語0.3の新概念は今回の資料へ含めていない。

主体省略は128文、明示数量なしは368文に含まれる。肯定580文、否定620文で、未指定・過去・現在・未来・昨日・今日・明日の各時間区分も含めた。これらは日英と表現違いをすべて数えた件数である。大きな数量を現実的な状況とみなすかどうかは評価せず、入力が明示した整数の保持を検査する。

未知概念には狼・栗鼠・ハムスターと対応する英語を使った。残る未対応区分には量化、限定否定、複数出来事、様相、質問を含めた。全注釈を監査し、過去の資料と文章および完全な意味構造が重ならないことを確認した。構文の系統はv1と共通であり、言語の広い領域への汎化を示す資料ではない。

[資料と構成数](../reports/confirmation-v2-fixture.json) および [事前条件](confirmation-v2-protocol.md) を保存した。重みと閾値は開発用データから選択した後、最初の予測取得前に別の実行マニフェストへ固定する。
