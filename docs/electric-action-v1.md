# 電荷・場・力を同じ作用へ結ぶ

同じ担体・系・出来事について、電荷の値、そこでの電場、電気的な力の三成分を接続する。電気的寄与を表す数値関係は、単位換算を明示した `F = conversion × q × E` である。負電荷による方向の反転と零電荷を扱い、電荷で割る操作にはしない。

電気力と磁気力を合成して全電磁力を述べる式とは区別する。この区別は[OpenStaxのMaxwell方程式とLorentz力の説明](https://openstax.org/books/university-physics-volume-2/pages/16-1-maxwells-equations-and-electromagnetic-waves)を参照した。磁気的な寄与は速度に関係するため、今回の電気的寄与だけを合力へ置き換えない。参照日は2026-10-23である。

eibqは一成分、eibrは互いに異なる三空間軸の数値関係である。eibsは既存sbw2で電気量の記録・単位尺度を、zpbで担体の出来事と四座標を、znnとscb2で同じ系の領域とそこでの電場評価を結ぶ。力には既存zpcと単位尺度の規約を使い、eirlでその記録が電気的寄与であることを特定する。支持力や重力を含む合力の数値を流用しない。

eirnは同じ成分場に表示単位を結び、eirmは電荷単位と電場単位の積から力単位への換算を固定する。場への単位の帰属がなければ、次元が合う係数を置いただけでは実際の値を比較できない。係数は正であり、極性の反転を単位の変更へ隠さない。現代SIの単位や定数を原文に補わず、採用した規約を引数として保持する。

力は方向を持つ機械的作用の量として、運動量変化への寄与や、それを釣り合わせる機械的作用との比較で同定する基礎量として採る。電荷は電気的作用の強さと極性を担う加法的な符号付き量、電場は同じ系の地点・時刻で十分小さい静止試験電荷へ働く電気力を電荷で割った極限として解釈する。これらの物理的同定規約と、Noemaで合成する値・単位・参照の関係を分ける。言語で作用を記述するために物理法則自体を証明する必要はないが、単なる名前や任意の数値関数をその物理量として認定することもしない。

今回の接続は、有限の実験で試験電荷の影響の極限を証明したものではない。担体が導体内で移動する条件、散乱・抵抗、磁石の性質、原文の電磁的説明と通常の理解への帰属は残る。既存の未完という記録を上書きせず、207主張と原文の意味判断を保持する。
