# 構成員の発展から集団の変化への媒介

前段で並べていた個人の因果条件と集団の変化を、一つの候補へ接続した。原因は同じ構成員の思考の発展、媒介はその共同体の応答傾向の拡大、結果は同じ構成員たちの行為選択の拡大である。**複数人の発展が共同して原因になる読みは未記述**であり、この接続だけで原文の集合的な原因を表し終えたとはしない。

## 集団の行為選択を構成する

[一般定義](../examples/v016/cohort-mediation.noema)の `rxo` と `rxp` は、各人と各活動の組について、前段の `rxc` と `rxd` を使う。

| 条件 | 内容 |
| --- | --- |
| `rxc` | 同じ人・活動・時点で、実行する方法と実行しない方法の双方がある |
| `rxd` | 同じ実行・不実行の能力を評価できる |
| `rxo` | 固定した非空の構成員と各人の活動の全範囲で、区間内の評価がそろっている |
| `rxp` | 既に選べた同じ人・活動の組を失わず、集団全体の組の数が段階的に増える |

二人が別の時点で一つずつ選択能力を得れば、集団として二段階の増加になり得る。各人が二段階で増加することは要求しない。また、他人が実行できることを本人の能力へ移さず、全員共通の一方法があることや、集団を一つの主体とする共同的な行為能力とも区別する。

本文の `iaochecked` と `iaoeffect` は、同じ本人の実行内容 `iajexecution` を使う。活動が起こるだけでは本人の実行にならない。判断対象の一覧と行為の活動一覧は別に指定するが、どちらも同じ共同体の、元の開始点で固定した構成員について評価する。

## 同じ集団・同じ解で媒介を比較する

[本文草案](../examples/v016/kant-cohort-mediation.noema)の `iaocausal` は、前件の本人が元の開始点で影響先共同体に所属することを要求する。その本人の発展の内容を原因変数へ、前段の `ianchange` を媒介変数へ、新しい集団の行為選択 `iaoeffect` を結果へ結ぶ。

原因だけを偽・真へ固定した双方で、同じ構成員と対象・活動を評価する。さらに、原因を真に保って媒介を偽・真へ固定した双方でも評価する。自然な解で態度の変化が原因に連動するだけの場合と、原因がある状態で結果に必要な場合を区別する。強制した側に評価不足や解の不在があれば、媒介の成立に数えない。

本人の前件を評価する履歴と、集団の変化を評価する履歴は、`iaomatched` で各解ごとに照合する。始点・終点・全履歴・履歴内の順序が一致しなければならない。観測した状態だけ一致させ、介入した側では別の時間経過を使うことは認めない。

この照合は、両方の履歴がそれぞれ妥当であるという条件より強い。例えば、集団側だけに区間終了後の時点を一つ加えても、集団の区間内評価は成立し得る。しかし、同じ因果世界の履歴としては一致しない。検査ではこの差も確認する。

## 条件文と残りの内容への接続

`iaoschema` は、二つの発展の読みから選んだ同じ一つを、前件から後件まで保持する。前件が成立した場合の後件として `iaocausal` を求め、残余条件へ同じ読み・本人・共同体・開始点・終了点を渡す。前件が偽なら、集団の変化や行為の現実の実行を断定しない。

前段の個人の二段階の能力増加を、集団の条件に重ねて要求する経路は使わない。これにより、各人は一段階しか伸びていなくても、同じ集団の二段階の増加を後件にできる。

親文書の全宣言と先行21文を保存し、最後の部分注記を、接続した候補の階数2のひな形への帰属に改訂した。引用内容の真偽と著者への帰属は引き続き分ける。

## 検査と未完の範囲

92件のテストが通過した。一般条件では、二人・各一活動・三時点の64通りについて、実行・不実行の方法と結果を使う評価を、独立したビット集合の計算と照合する。本文では、集団の実際の判断条件と行為能力の条件を同じ有限解釈で実行する。個人の二段階増加と現在の実行が偽でも集団の媒介条件が成立する例、評価不足、別集団、構成員の欠落、本人の非所属、未知入力、介入側だけの履歴の交換を含む。

診断用の短絡評価と純粋で外延的な解釈向けの関数再利用を明示的に用いる。キャッシュなしとの比較は一般条件の基準例に限る。 三文書の長形式・短縮形式・固有文字の往復とCLI解析、抽出文書のSVGのXML検査も通過した。形式的な評価、表記の往復、CLI解析、SVGのXML検査は、原文との意味一致や字形の目視確認を代替しない。
