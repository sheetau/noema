# 将校・上官・同じ本人への命令

第五段落の将校の例示 `[2123,2331)` に向け、役職と命令内容を同じ人へ結ぶ依存群を追加する。原刊485頁末尾から486頁冒頭までを確認した。勤務中の議論の意図、命令の目的適合性・有用性、重大な害の評価、服従要求、例示としての提示は未統合であり、今回の追加を一文全体の意味確認には数えない。

`r32k` は既存の将校分類を、明示した本人・役職・軍事組織へ固定する。`r32l` は同じ組織の役職体系と指揮上の上下を、既存の順序・保持・委任の定義へ渡す。別の役職で将校であること、別組織に上位役職があること、自分自身を上官にすることでは満たさない。

命令の内容 `r32j` は、既存の本人・行為の実行内容 `h7h` と、命令の働き `j m` から構成する。正極性なら実行、負極性なら不実行を求める。対象行為は引数のまま保持し、原文にない教練や戦闘へ固定しない。

`r32m` は同じ生起する提示行為・提示者・受け手を結び、命令内容の本人をその受け手へ明示的に束縛する。既存 `f2` の一対象への発話提示を、順序付きの複数束縛と極性へ拡張する `h242v` を使う。これは文全体の意味を隠した基本記号ではなく、渡す発話関数の働きと内容を保つための一般的な関係である。

`r32n` は同じ将校と上官を、この同じ命令の受け手と発出者へ結ぶ。命令が発せられたこと、受領・理解、制度上の正当性、実際の履行は別である。後続の「従わねばならない」は、同じ内容に対する規範的な要求として改めて接続する。

`Oberen` は同じ組織の上位者を指す複数形と読み、最低二人が共同で命じたことや唯一の直接上官という限定は加えない。原文の仮定を組み立てる段階で、対象となる人・命令・文脈を量化する。
