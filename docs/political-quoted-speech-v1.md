# 同じ公式発言と政治的な発言可能性

第十段落第一文の引用を、第五段落で確認した同じ出所の全宛先への許可・服従内容へ結んだ。各人の望む話題と量で論じることを許す内容 `r2ug` と、政治的・市民的な要求を指示として受け入れ履行することを求める `r2uh` を保存する。引用から許可の実際の成立や聞き手の服従を導かない。

`nur gehorcht!` は、この呼びかけに付す唯一の留保が服従であるという読みを採った。同じ発話・実行者・宛先・出所・第一内容に付す留保の閉じた発話族を全て量化し、第二の内容以外を置かない。許可方針の真理条件に服従の現実の成功を加えたり、世界の他の義務を廃止したりする条件ではない。提示で使う閉じた記述の同一性を保ち、別構文を自動同義化しない。

発言の実行者と内容の出所を分けた。人が自分として述べる場合と、公的な主体を代表して述べる場合に同じ二内容を使う。後者では同じ人・主体・発話・基準・点について代表資格と制度的な行為帰属をともに要求する。国家について誰かが私見を述べただけの場合を、その国家自身の発言とはしない。代表資格から方針の政治的な妥当性や規範的許容も導かない。

`kann das sagen` は、公式にこの方針を打ち出し、その許可と同じ共同体の公的平穏を両立できるという政治的・実践的な能力として読む。利用可能な方法が少なくとも一つあり、その非空の全選択結果で同じ発言・許可・平穏が成立することを既存 `xd` で要求する。単なる発声や朗読、成功した結果一例だけでは通らない。一つの方法が失敗しても、別の方法が必要な全結果で成功できれば能力を認める。

同じ全宛先が同じ共同体の成員であることも確認する。許可の成立は能力の内側の目標であり、現実に既に発言・許可したことを外側の前提にはしない。服従を命じる内容が提示されることと、聞き手が実際に従ったことは分け、後者は能力の目標へ追加しない。方法・結果は通常の実践的な範囲を先に固定し、成功確率の数値や全異常事態への保証は補わない。

上位の `nur derjenige` は、そう言える全ての人が、同じ本人・点の判断能力、根拠のない恐れの不在、軍隊の利用と平穏保証の条件を持つという必要条件へ結んだ。人物条件を能力の定義へ混ぜて含意を自明にすることはせず、逆向きの十分条件や実在も要求しない。基準の呼称が誤っている場合を、発言できる人がいない場合へ隠すことも認めない。

八定義 `r6fv–fz, r6f2–f4` と五入力を追加した。検査では同じ引用の二内容、唯一の留保、全宛先、代表と行為帰属、許可・平穏の失敗、方法・全結果の範囲、必要条件の反例を確認する。留保の全記述域量化は保存し、診断用コピーではその実際の束縛本体を二つの閉じた発話族へ適用する。全域の直接評価は拒否し、この有限試験を全域の証明とはしない。既存の許可・平穏・人物条件の本体の証拠は固定済みの報告を参照する。

自由国の `nicht wagen darf` と危険を認める試みの非許可基準、照応、比喩と強調、接続語、全文帰属・通読は残る。第一文全体の意味判断はまだ行わず、本文119主張・登録簿v203・19全単位判断と確認文字数を保持する。
