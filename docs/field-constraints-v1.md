# 発散零と、微分値の変換条件

前回の反例が示した前提不足に対して、二つの場の発散零と、同じ点での微分値の変換条件をNoemaで追加した。原文への数学的な解釈注記として保存し、著者がこの形で条件を明記したとは扱わない。既存の著者への帰属文と、その前提は変更していない。

発散は、三つの同軸空間偏微分の和として定義した。先行する六つの回転の式が使う18個の偏微分に、Xₓ,Yᵧ,Z_z,Lₓ,Mᵧ,N_zの六つを加える。全24値を同じ二場・領域・四座標へ結び、六式と二つの発散零を同じ値に要求する。有効性の検査も新しく使う六値へ広げた。

微分値の変換には二段階ある。まず逆座標変換に対応して、各成分のx方向の値をβ(dx+v·dt/V²)、時刻方向の値をβ(dt+v·dx)にし、横方向の値を保持する。次に、その各方向の値に、場の成分と同じ電気側・磁気側の混合を施す。この数値条件を、同じ新座標とその逆変換先の旧座標で実際の微分へ結ぶ。

数値条件の十分性を調べるため、方程式の左辺と右辺の差を残差として定義した。時間をu=Vtで表し、電気側の三残差をRᴱ=∂E/∂u−rot H、磁気側をRᴴ=∂H/∂u+rot E、二つの発散をDᴱ,Dᴴとする。r=v/Vと置くと、構成した微分値の変換に次の恒等式が成立する。

| 変換後の量 | 変換前の量による表示 |
| --- | --- |
| Rᴱₓ | β(Rᴱₓ+rDᴱ) |
| Rᴴₓ | β(Rᴴₓ+rDᴴ) |
| Dᴱ | β(Dᴱ+rRᴱₓ) |
| Dᴴ | β(Dᴴ+rRᴴₓ) |
| Rᴱᵧ, Rᴱ_z, Rᴴᵧ, Rᴴ_z | それぞれ変換前と等しい。ただしβ²(1−r²)=1 |

八つの恒等式は、任意の有理数の微分係数について検査器で確認した。したがって、正規化条件の下で変換前の八つの残差が全て零なら、変換後も全て零になる。前回不足していた発散が、x方向の回転の式へ混ざることも、この表示で分かる。

静的なE=(x,0,0)、H=0と、電気側・磁気側を入れ替えた反例は、旧六式を満たすが発散零を満たさない。微分値の変換を正しく保ったまま、新しい前提から除外できる。v=0で旧六式の変換の失敗が見えなくなる場合にも、発散の条件は残る。

ここまでの証拠は、微分値の代数と接続についてのものである。Noemaでは一般の実数を使う条件と、元の場・変換後の場の偏微分への接続まで記述したが、一般の実関数の全微分可能性から数値の連鎖則を導く証明は未完である。別々の偏微分が存在することだけで連鎖則を保証しないように、連鎖則に対応する等式を追加条件として明示した。

局所条件を満たす点で変換後の二場が八条件を満たすという条件付き命題と、非空の全領域で八条件を要求する表現も加えた。全実切断上の体の法則、領域の開性と境界、物理的な真空の概念や測定との接続は残る。全域の微分条件を有限検査器で代用することは認めていない。

検査には八条件の8例、全24微分への接続9例、微分値の変換27例、反例3例、新旧の点と場の接続6例を使った。変換後の24値を一つずつ変更すると不一致を検出する。旧・新の微分値の交換、逆座標写像のずれ、領域外、連鎖則条件の欠落も拒否する。微分や座標の接続には検査用の関係を使う箇所があり、有限例を一般の微分の証明とはしていない。
