# 式と引数の可視共有

## 元の式を保つ共有

同じ引数や部分式を一度だけ記し、限定した範囲で参照する。既存の関数抽象・適用でも意味上の共通化はできるが、引用された構文の同一性まで保つ変換ではない。本書式はNoemaの意味演算子を追加せず、可視の略記を展開して元の構文木へ戻す。

「共有」は、既存の関数操作の分類字形と右下方向の操作字形を組み合わせる。その後に共有対象の一式と、有効範囲となる一式を書く。「共有参照」は同じ分類と左下方向の操作字形で、その後に最も内側の共有を0とする距離の自然数を書く。距離は明示された共有の入れ子を指し、語の意味を文書専用の番号へ置き換えない。

共有対象は有効範囲の中で少なくとも二回参照する。一式の引数数と終端によって共有の範囲が決まり、単なる円の接触や線の分岐では省略を補わない。線と円の接続規則は従来どおりであり、共有対象を各出現へ結ぶ不可視の辺は使わない。

## 束縛と引用

共有対象を読んだ位置の自由変数を保持する。その後に別の量化や関数抽象があっても、参照先の変数を「現在いちばん内側の変数」へ読み替えない。共有対象が導入位置で参照できない変数を含む場合は拒否する。

引用の内部へ入ると共有環境を空にする。引用の内部で新たに共有することはできるが、外側の共有を借りることはできない。引用全体を外側で共有する場合は、同じ引用された式を各出現へ戻す。共有範囲は宣言・文をまたがず、行の折り返しでは失われない。

復号は共有対象の構文を複製し、既存の型検査・変数名の正規化へ渡す。定義の展開、真理値による置換、論理同値への書換え、関数の一回評価への変更は行わない。未導入・範囲外の共有参照、不要な共有、型の合わない参照は拒否する。

## 自動選択と制限

自動描画では、同じ構文と同じ自由変数を持つ反復を候補にする。導入位置で参照できない変数を含む式を外へ移動しない。共有標識・参照の字形も数え、通常の反復より短くなる候補だけを選ぶ。短い定数を二度書く場合など、共有の方が長くなるものはそのまま反復する。共有はすべての文を短くする方法ではない。

共有を展開した構文には資源上限を設け、短い参照の入れ子による過大な展開を拒否する。可視の字形から共有範囲と参照先を読み、付属の番号表やASTは使わない。旧描画器の暗黙の融合を復号できると主張するものではなく、未使用だった文法操作へ追加する明示的な書式である。

現在は展開後の文書と参照複製の作業量をそれぞれ8192構文節点に制限する。自動選択は完全一致する構文を候補とするヒューリスティックで、最短表記の証明ではない。入れ子の短縮後にも実際の参照数と字形数を再確認し、参照が二回未満になった共有や、反復より長くなる共有は採用しない。

## ページと再現入口

行継続・段落・語と数の不可分性は[可視ページの規則](visible-page-v1.md)を引き継ぐ。共有の分類字形と操作字形、参照距離の自然数は行の途中で分割しない。共有範囲は本文の構文によって継続するため、行頭で参照を初期化しない。共有のない旧ページも新しい復号器で読める。旧復号器は新しい共有操作を未割当てとして拒否する。

[数列の共有例](../examples/v016/visible-shared-argument-v1.noema)は、一つの有限列の三つの位置を照合し、その式の引用も比較する。[円文字ページ](../output/visible-sharing-v1/shared-page.png)を描画して読み戻し、元の正規化されたNoema文書との一致を検査する。短い個体の共有、内側の量化、共有の入れ子、引用内外の環境、型の誤りと過大展開も局所検査に含める。

```powershell
python -X utf8 -m scripts.visible_shared_page render examples/v016/visible-shared-argument-v1.noema output/visible-sharing-v1/reader-example.svg --width 3000 --paragraph 1
python -X utf8 -m scripts.visible_shared_page decode output/visible-sharing-v1/reader-example.svg --native
python -X utf8 -m scripts.project_work check --module scripts.check_visible_sharing --tests tests/test_visible_sharing.py --verify reports/visible-sharing-v1.json
```

`--no-sharing` を描画に指定すると通常の反復表記になる。`--native` を付けない復号結果は、展開後の文書と可視の段落位置を持つJSONである。[検証報告](../reports/visible-sharing-v1.json)は両表記の字形数と依存ファイルのハッシュを保存する。語義の一般化や人による読解の成功を、この構文の復元試験で代用しない。
