# 内容の把握と根拠を伴う認識の拡大

カント第六段落 u0013 [713,1004) の `Erkenntnisse zu erweitern` を、同じ人々が把握し根拠に基づいて保持する認識内容の新たな獲得として構成する。命題が論理的に真でも、本人が以前から理解していたとは限らない。旧 `ri5` の比較世界を絞る情報増加だけでは、この違いを表せなかった。

`r5ck/cl` は、同じ内容の受容、内容の把握、本人の保持する肯定判断、その判断で用いる理由、理由による支持、十分な認識根拠として実際に働く結び付きを区別する。真偽は前後で固定した評価状況に置く。単に結論が当たった場合や、引用しただけ、理由を使っていない場合、内容を把握せず繰り返すだけの場合は保有条件を満たさない。

把握・保持・根拠の働きは、それぞれ意味規約を持つ一般的な入力関係である。一文全体や拡大の成否を入力する関係ではない。この構成を全哲学的な知識理論の必要十分条件とはしない。現実の根拠が適切かという判断も、有限模型の検査だけでは証明しない。

`r5cm/cn` は、同じ本人が以前持たず後に持つ認識を一つでも得ることを述べる。新しい内容を受け入れる場合に加え、既に受け入れていた内容を把握し直す場合や根拠を得る場合も含む。別名は前の訂正構成と同じ代表項目で扱い、名前の追加だけでは増やさない。他の全認識の無損失は要求しない。

既知の結論への新しい証明や説明は、その根拠関係を別の Noema 内容として記述できる。検査では既存 `rre` による二段階の仮定解除の証明を、認識対象の内容として実際に評価する。証明の妥当性が偽なら、その内容への新しい受容を成功としない。妥当な証明の存在だけから、本人の受容・把握・根拠の保持を補うこともしない。

`r5co` は集団の同じ成員の獲得に加え、後の生存成員が以前のどの生存成員にもなかった内容を持つ場合を含める。出生を許すが、既存の水準を保有する人が入れ替わるだけの場合は集団の拡大としない。前後で対象集団の生存者がいなくなる場合も除く。`r5cp` はこの拡大の成功可能性がないことを `rjb` へ接続する。

64通りの独立条件、別名・既知内容・新しい把握・新しい根拠・他所での損失・出生・人口交代・同じ時点などの対照を検査する。量化部分では保有条件の型付き境界を使い、別途、全定義を実行して拡大と不能性を接続する。未知の認識関係や内容は拒否する。
