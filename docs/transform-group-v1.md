# 群の条件と平行変換の族

アインシュタイン1905年論文§5末尾のu0149について、平行変換が群をなすと述べる主節を部分記述した。群という語を基本記号として登録する代わりに、範囲・合成操作・単位元・逆操作を引数に取る定義へ展開した。

群の条件は四つに分けている。

| 条件 | 保持する内容 |
| --- | --- |
| 閉性 | 範囲内の二要素を合成した結果も範囲内にある。 |
| 結合則 | 三要素の合成は括り方を変えても値が一致する。 |
| 単位元 | 単位元自身が範囲内にあり、左右どちらから合成しても値を変えない。 |
| 逆元 | 各要素の逆元が同じ範囲内にあり、左右どちらの合成でも単位元になる。 |

交換則は含めない。三要素の巡回的な加算と、三対象の置換を合成する非可換な群を、同じ定義で扱う例を検査した。さらに、閉性・単位元・両側逆元を持つが結合則を満たさない五要素の操作を拒否した。空の範囲、単位元の取り違え、範囲外の逆元なども別々に検査した。これらの例には物理的な基本関係を使っていない。

個体型の一般定義は単独の[group-laws.noema](../examples/v014/group-laws.noema)にも保存した。実数値へ適用する版では、範囲の全要素が有効な実切断であることを要求し、値の一致を既存のscaで比較する。型を変えるために群の条件を弱めてはいない。

速度への適用では、V>0かつ−V<v<Vの範囲を使う。合成は既存の(v+w)/(1+vw/V²)、単位元は0、逆速度は−vである。正の速度だけでは逆元を保持できない。これより前の本文で採用した非負の速さの条件を書き換えず、変換の族に必要な符号付きの範囲を別に記述した。±Vの境界は含めない。

「変換が群をなす」は速度の演算だけでは記述を終えず、四座標への作用へ接続した。係数1の既存の位置・時刻式から写像を作り、任意の有効な四成分入力に対して、合成速度の写像と二回の写像の一致、速度0での恒等性、vと−vによる両側の逆変換を要求する。

写像の同一性も、任意の四成分入力に対する値の一致として定義した。関数を実装するプログラムの識別子を比較するものではない。原点の零ベクトルだけでは異なる速度の写像も一致するため、そこから変換の同一性を結論しない。有理数の補助検査では、(x,y,z,t)=(0,0,0,1)に対する縦座標と時刻が同じなら、二つの許容速度が一致することを確認した。

数値ベクトルの四つの役割だけを座標成分として扱い、それ以外の役割に値を持つ関数も、四成分の値が同じなら同じ座標を表す。出力の役割外の値は0へ統一する。観測済みの三記録に限定した前段の接続とは区別し、今回の写像は全ての有効な四成分数値入力を対象にする。全実数座標の物理的な実現を保証したという意味ではない。

有理数の補助検査7件では、符号付き速度の閉性、結合則、両側単位元と逆元、写像を区別する入力の性質を確認した。正の速度だけで全逆元を持つという主張と、零の原点だけで速度を決めるという主張は拒否した。具体例では有限の構造9例、四座標への作用9例、速度範囲11例、帰属6例を検査した。全実切断と全写像への量化は有限解釈器に拒否させ、これらの例を全域の証明として数えていない。

新規8件を含む関連27テストが通過した。二つの文書について通常記法・短縮記法・固有文字の往復、CLIのJSONと構文木の一致、SVGのXMLとしての読み込みも確認した。全テストの実行と字形の目視確認は今回の検査に含まない。

本文への接続では、先行する合成則の一般形と群という結論を記述として区別し、著者の推論として帰属させた。閉性だけで群が従うという推論を検査器が承認したものではない。結合則・単位元・逆元を展開したのは現代的な群の明示的な読みであり、歴史的な用語法の全確認は残る。
