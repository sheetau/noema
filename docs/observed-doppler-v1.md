# 光源と観測者の周期数、条件付き帰結

対象は u0188 の全文と u0189=M0333。原刊911頁、固定本文とMathMLを照合する。前段の角周波数と時間周期・周期数、遠距離方向と角の定義を、同じ物理対象と著者の帰結提示へ接続する。

不足していた関係は、対象と配置モデルの対応、放射又は受信される同じ成分と位相の対応、源に静止する系における同じ観測者の運動、先行の式からの条件付き帰結の提示である。前二者にだけ一般関係 eissk/eissl を導入し、速度・静止・方向の極限・角・周期・式は既存定義と合成する。帰結提示は zc、表示への対応は eisox、説明と順序は uf/ue を再利用する。

源のモデル族 ekdv は距離 R ごとに位置 −R*n を固定し、第四座標を時刻とする。全正実数 R を許容し、全有限観測位置に対する ekdm の方向極限を使う。一対象の同時多地点実在又は無限の実数座標を要求しない。方向 n は単位ベクトルであり、d=p+R*n、L=|d| に対して |L−R|≤|p|、|d_i−Ln_i|≤2|p| だから、R>|p|+2|p|/epsilon の尾部で各成分の誤差条件を満たす。これは有限標本検査とは別の数学的な読みである。

源の位相族 ekdw は ω(t+R/V) で位相原点をそろえる。現実の場を源まで厳密に外挿する主張はしない。eissl は同じ源・波・過程・系・単位への放射位相の帰属を指定し、ekc7 が最小周期と周期数を固定する。R ごとに別の ν を選び直さない。受信側も同じ関係を受信の真偽指定で用い、同じ観測者の経路と変換後位相に結ぶ。近似場の成分誤差だけから正確な周期数を推定しない。

ekd6 は同じ観測者の旧系 K における正 X 方向速度 v の物理的履歴 eivu と、旧経路の位相率 ω(1−av/V)、新観測区間全時刻の逆 Lorentz 対応 ekd5 を合わせる。k の静止観測者は ekcl から保持する。旧時刻は逆写像から算出するため τ と t を無条件に同一視しない。角 φ は源から観測者への方向とこの速度との角で cosφ=a、0≤φ≤pi。既存の標準配置 0<v<V を使い、零速度で未定義な角を勝手に与えない。

ekd7 は59役割の条件を構成する。放射・受信周期数を同じ一周期へ結び、受信位相率には先行の ω′ の式を用いるが、結論 ν′=ν(1−cosφ*v/V)/sqrt(1−(v/V)^2) は条件に含めない。ekea がこの結論、ekeb は固定 K/V/節/状況以外の55役割の全称条件である。両辺の周期から ν=ω/cycle、ν′=ω′/cycle、cosφ=a が得られ、先行式の代入で印刷形になる。著者の導出を記述することと、現実の法則の真理を認定することは別である。

u0188 は先行 M0327 第一式への参照 eisso、帰結 zc、同じ条件内容 ekeb、表示への説明と順序を含む。u0189 は同じ内容への eisox で結ぶ。二箇所は同じ著者と論説に帰属する。ω′、ν、v、φ、ν′の参照を維持し、νをω又は時間周期に置き換えない。
