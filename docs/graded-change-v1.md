# 近い状態と、そこへ進む変化

「ほとんど本性となった」を検討する中で、状態の新規取得だけでは程度の進行を表せない点が残っていた。以前から近い状態にあって、さらに程度が進む場合があるためである。今回は、既存の質的な尺度と実際の変化過程を組み合わせ、その後も近い状態を保つことを記述する。

この変更は「本性」の構成を完成させるものではない。Adelungには、習慣が別の本性となる用法と、物の起源としての自然の語義がある。後天的な定着を生来の起源へ置き換えることは避け、比較すべき特性を明示する必要がある。[Adelung, Die Natur](https://lexika.digitale-sammlungen.de/adelung//lemma/bsb00009133_2_0_600)

## 三つの区別

| 内容 | 必要な条件 |
| --- | --- |
| 今、近い状態である | 現在の一意な評価値が近接域にある |
| 新しく近い状態になった | 前には近接域になく、後には入っている |
| 程度が進んで、近い状態になっている | 実際の変化で程度が増加し、後端は近接域にあり、その後も域内にある |

三番目は、前端が既に近接域にある場合を許す。同じ近接域内での程度の進行を、単純な不成立から成立への変化として記述すると排除してしまう。反対に、前後で程度が同じままの履歴は、現在近い状態であっても、三番目の変化にはならない。

尺度には既存の`rqsq`を、近接域には`rqss`を使う。最小値と最大値を持つ厳密な全順序であり、近接域は最大値の手前にある非空の範囲として与える。数値、割合、確率、等間隔、95%などの閾値は要求しない。Dudenのbeinaheの説明は近似の意味を示すが、今回の尺度や上端を除く読みまでを一意に定める資料とはしない。[Duden, beinahe](https://www.duden.de/rechtschreibung/beinahe)

## 評価、過程、保持

各状況では、同じ評価関係による値が尺度内に一つだけあることを検査する。値が欠ける場合や、異なる複数値が与えられた場合を、低い程度と決めつけない。前後で異なる比較基準を使って値が上がったように見せることも認めない。

| 定義 | 構成 |
| --- | --- |
| `r2cl` | 同じ状況の尺度内の一意な評価値 |
| `r2cm` | 有効な尺度・近接域の下で、その状況の値が近接域にある |
| `r2cn` | 同じ履歴の実際の過程で本人が変化を受け、前後値が増加して後端が近接域にある |
| `r2co` | 同じ変化の後端から現在まで、近接域にある状態を保つ |
| `r2cp` | 本人の現在の未成熟と、同じ本人・記述・比較基準・評価文脈による`r2co`を結ぶ部分ひな形 |

変化には既存の`tg`を使い、本人への作用も別に要求する。程度の前後比較だけで、実際の過程や因果を推定しない。取得過程内の単調性と連続性は要求せず、その後の保持では近接域内の増減を許す。後で域外へ出た履歴は、今回の保持の読みを満たさない。

## 検証と未完の比較基準

前端・後端・現在の四つの程度値を変える64組合せを、集合と順序による独立の計算と照合する。33対照には、程度の評価欠落や多値、近接域の穴、循環する尺度と履歴、別人・別過程、途中で域外へ出た場合を含む。近接域内で程度が進んだ場合に、新しい構成は成立し、二値的な新規取得は成立しないことも検査する。

対照用の二値式は、有効な近接評価の不成立から成立への移行をそのまま調べる負の対照である。以前の評価が欠けている場合にも、この式だけでは取得のように見えることがある。実際の程度変化r2cnでは前後の一意な評価を別に要求し、その誤認を拒む。二値式を原文側の取得条件として採用してはいない。

原文側のひな形では、現在の未成熟を既存の能力定義から実際に評価する。本人・性質の記述・比較基準・評価文脈の取り違えと、実際の過程の欠落を検査する。診断用の比較入力は本文の基本記号や著者の主張として加えない。

`r2cp`には、本性に相当する比較特性、尺度、評価の根拠を引数として残している。この空欄を「本性」という名前の基本記号で埋めて完成と数えることはしない。習得した状態の定着と、元来の性質に似た働き方との比較を、別途組み立てる必要がある。したがって今回の成果は程度と変化の合成であり、句全体や第一文の完成訳ではない。
