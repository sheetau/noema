# 支払う能力と他者による引受けの見込み

[支払いと予想の共通定義](../examples/v014/payment-expectation.noema)を追加し、[カントの支払いの文の部分草案](../examples/v014/kant-payment-expectation.noema)へ接続した。支払う能力を条件とする部分と、他者が煩わしい仕事を引き受けるという見込みを、同じ仮定上の話者について保持する。

## 支払う能力を支払い済みと取り違えない

rfは一つの価値移転を、支払う人・受け手・価値媒体・対価となる仕事の記述へ結び付ける。媒体が支払いに受容されることと、その移転が同じ仕事の対価として扱われることを分ける。贈与、別件の支払い、違う受け手への移転を組み合わせても成立しない。通貨や金額、受け手の固有名は原文へ補わない。

原文草案toは、そのような支払いの存在を命題内容として表す。tpは既存の能力定義xdを使い、本人が選択できる方法の非空で整合した評価結果においてtoを達成できることを表す。したがって、現在は未払いでもtpが成立する場合がある。

支払いの基礎関係には、価値媒体とその管理・利用に関する地位の移転という説明を与えた。ただし、貨幣・権利・契約の制度全体の構成的な定義には至っていない。bezahlen kannをこの文脈の支払い達成能力として読む部分草案であり、支払能力の全ての語義を確定した結果ではない。

## 本人が考えずに目的を満たせること

tqは前版のrdを用い、本人の実用上の目的swを満たす一つの方法があり、その評価結果への経路に、問題となる本人の思考tlが含まれないことを要求する。本人が今考えていないことや、考える能力がないこととは異なる。目的を満たせない不実行を、思考が不要な方法として数えない。

trは同じ本人について、選んだ仮定状況内でtpからtqが成立することを要求する。ここではnurを十分条件を提示する読みとして扱い、支払えなければ必ず自分で考えるという逆方向の条件を追加しない。焦点や強調、皮肉を含む原文の談話的効果は未完である。

前件が成立しない場合、条件文が真でも支払能力があるとは判定しない。検査記録では支払い済み・支払う能力・本人の思考なしの達成・条件文の真偽を別々に記録している。

## 見込みは現在の事実でも履行の完了でもない

rhは本人と異なる人が、本人のために記述された仕事を引き受けることを表す。仕事の記述は参照するだけで、実行や完了を要求しない。誰も引き受けない場合や本人だけが行う場合は成立しない。一方、特定の一人を全ての予想候補へ固定することも要求しない。

riは予想候補の集合が非空で、その全てが文脈より先に位置付けられ、そこで予想内容が成立することを要求する。文脈自身を未来の候補にすることは拒否する。予想候補の外にある可能性を排除したり、現実の履行を保証したりはしない。

原文のt2では、仮定上の話者が本人の理解力の使用bmを煩わしいと評価し、他者による引受けtzを予想する。対象となる仕事を前の思考の記述へ接続し、著者本人が思考を客観的に煩わしいと認定しているとはしない。werden ... schonは確信を伴う将来の見込みとして読むが、数値確率や具体的な期日は補っていない。

t3は条件文trと予想t2を同じ人物・文脈について結ぶ。著者への帰属には前版の仮定的一人称の提示s4を用い、前の三例の文との本文順序も保持する。支払いが引受けを必ず引き起こす機構や、支払いの受け手と将来の引受け手が必ず同じ契約当事者であることは追加していない。後半をどの仮定の範囲で解釈するかという語用論上の課題は残る。

## 検査と残る作業

支払いの結合条件12例、候補・未来性・内容の真偽・現在の真偽を変えた予想128例、引受けの参照8例、候補ごとに異なる人が引き受ける3例を検査した。候補ごとに引受け手がいることと、全候補で同じ人が引き受けることを区別できる。

原文へ接続した16例は、実際の定義を評価し、能力等の定義を仮の基本関係へ置き換えていない。通常評価と、純粋な解釈向けの定義結果の再利用を有効にした評価で、基準例の結果が一致した。著者への帰属6例では、支払い・思考・予想の内容が実行評価されると失敗する解釈を使っている。

対象の一文は、保存した原文単位kant-1784:u0009のハッシュと文字範囲で固定した。今回の部分草案を、原文の唯一の解釈や全文完成とはしない。思考と支払いの一般的な意味、nurとschonの働き、皮肉・作用範囲、直前の便宜さの文、残る段落、原刊照合は未完である。意味確認済み全文単位はカント0/20・アインシュタイン0/282のままである。
