# 公開語義注釈の取り込みとNoemaへの転用結果

英語の語義対応資料WiC-TSVを取り込み、Noemaの例文を追加せずに共通の二値判定器を学習した。公開開発資料で選択したMLPの均衡正解率は59.17%だった。Noemaの観察済み資料では先頭候補が「職場」に偏り、既知179範囲の正解は日本語6件・英語10件にとどまった。この判定器は翻訳器へ採用しない。

## 注釈の利用条件と変換

[WiC-TSVの公開リポジトリ](https://github.com/semantic-web-company/wic-tsv/tree/7bddf326add99eb40a2b85a331deffafead2a73f)をコミットへ固定した。文中の対象語と付属する定義の対応をT/Fで注釈した資料であり、今回の英語学習・開発は名詞中心である。定義はWordNet等に由来する。データの[CC BY 4.0](https://github.com/semantic-web-company/wic-tsv/blob/7bddf326add99eb40a2b85a331deffafead2a73f/data/en/LICENSE)とリポジトリコードのMITを区別し、元のライセンスも保存した。出典はAnna Breit、Artem Revenko、Kiamehr Rezaee、Mohammad Taher Pilehvar、Jose Camacho-Colladosによる[WiC-TSV（EACL 2021）](https://aclanthology.org/2021.eacl-main.140/)である。

対象の空白区切り位置を元の文字範囲へ変換した。原文の空白・表記は変更せず、反復語も注釈位置で区別する。行数、対象位置、対象表層、定義、正負ラベルの不一致は拒否する。付属の見出し語は監査用メタデータに置き、モデルへは渡さない。Noemaへの語義ID変換表や、推論時の辞書・例文検索は作っていない。

学習・開発間の原文と注釈入力の重複は0件、見出し語の重複は98件、定義の重複は30件だった。開発を未知語だけの評価とは扱わない。公式テストのラベルは公開ファイルに含まれないため取得せず、スコアを推測していない。[原資料の監査](../reports/wic-tsv-source-v1/audit.json)、[出典・変換・ハッシュ](../reports/wic-tsv-source-v1/manifest.json)、[再読込み検査](../reports/wic-tsv-source-v1/verification.json)を保存した。

## 共通の二値判定器

[事前条件](wic-verifier-v1-protocol.md)を固定し、MiniLMの重みを変更せず、原文と定義を二列入力した。対象範囲と定義のトークン平均を正規化し、q・d・差の絶対値・要素積から一つのlogitを出す。線形は1,537、幅64のMLPは98,433パラメーターで、見出し語数や候補数によらない。

学習は二値交差エントロピー、判定閾値はlogit 0に固定した。開発の正例再現率と負例再現率の平均でepochと方式を選び、Noemaの結果は選択に使わない。公開資料には128トークンを超える学習例が2件あったため、今回の二列上限を256とした。最大長は学習170・開発76で、全例を切断せず使用した。

| 方式 | 選択epoch | 開発正解率 | 開発均衡正解率 | 真陽性／偽陽性／真陰性／偽陰性 |
| --- | ---: | ---: | ---: | ---: |
| 線形 | 20 | 56.81% | 56.51% | 145 / 115 / 76 / 53 |
| MLP | 4 | 59.38% | 59.17% | 141 / 101 / 90 / 57 |

MLPが選ばれたが、公式開発はモデル選択に使った値であり、独立した最終評価ではない。[選択記録](../reports/wic-verifier-v1/selection.json)と同じディレクトリに両方式の全学習履歴を保存した。

## 91候補からの選択への転用

選択後、観察済みNoema v1〜v6の日英442範囲へ、既存の91定義を与えた。正解範囲を使う概念照合の回帰であり、新規の採用試験や全文の翻訳評価ではない。日本語の学習例を今回加えたわけでもない。

| 方式 | 日本語の既知範囲 | 英語の既知範囲 | 未知で一つ以上の候補が閾値以上：日本語／英語 |
| --- | ---: | ---: | ---: |
| 線形 | 5/179 | 7/179 | 42/42・41/42 |
| MLP | 6/179 | 10/179 | 42/42・40/42 |

選ばれたMLPは442範囲中341範囲で「職場」を先頭にした。型別の正解数は次のとおりで、元資料と同じ名詞に近い対象・場所でも低かった。英語名詞中心という制約だけで、今回の失敗の全てを説明できるとは判断しない。

二値の対応判定と、多数の異なる候補を順位付けすることの両方に問題が残る。Noema向けに校正していない閾値では未知例にもほぼ全て肯定候補が出たため、この値を翻訳の確信度として使えない。[v1](../reports/wic-verifier-v1/v1-evaluation.json)〜[v6](../reports/wic-verifier-v1/v6-evaluation.json)に、両方式の全指標、型別結果、閾値の診断を保存した。全文の確定出力は0件である。

## 検証と次の対象

全433テストが通過した。対象位置と反復語の処理、壊れた注釈の拒否、ラベル・見出し語がモデル入力へ混入しないこと、語彙数や候補順に依存しない共通ヘッドを検査した。元の注釈を再変換し、学習・開発3,217例が一致した。両方式の学習を固定特徴から再実行して、選択epoch・全履歴・重みが完全一致し、それぞれ442範囲の予測と評価を再計算した。モデルの重み固定・eval、4組の反復一致を確認し、生成等の禁止経路5種の呼出しは全て0回だった。[再現検査](../reports/wic-verifier-v1/verification.json)

実行環境はPython 3.12.10・PyTorch 2.13.0 CPU・float32・eager・8スレッド。コードと入力・出力・モデル条件は[実行記録](../reports/wic-verifier-v1/run.json)に保存した。原資料、変換後の注釈、特徴、重み、生予測はGit管理外の`artifacts`に置く。

追加の監査では、同じ原文と対象範囲に正負両方の定義が付く学習グループが446件あった。これは、候補を一つずつ二値判定する学習と、同じ対象に対する候補の差を学習する方式を比較できる資料である。次の検査ではこの実際の正負注釈を使えるが、未注釈の定義を勝手に負例へ変換しない。今回の転用失敗を語別補正で隠さず、動詞・状態・日本語への対応と全文の完成条件は未解決として維持する。
