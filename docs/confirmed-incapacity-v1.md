# 現在の不能への強調と、第二文の通し判断

カント第三段落第二文の139非空白文字を、以下の読みの下でNoemaの内容へ照合した。判断者はアシスタントであり、独立した査読や同義性の自動証明ではない。第一文108文字の判断と合わせ、第三段落では先頭二文の247文字を確認した。段落全体の判断は残る。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)

第一文と同じ非空の人物範囲の各人について、その人自身の未成熟への愛着の取得と保持、現在の理解力の行使不能、過去の試行の許容不在から不能への寄与を述べる。愛着を不能の原因にはしない。`sogar` は愛着の取得を焦点とし、先行する内的定着に対して期待しにくい内容として提示する読みを継承する。比較対象と作用範囲は明示した解釈選択であり、唯一の読解を証明したものではない。

## 強調の対象を分ける

`wirklich` は現在の不能を確かなこととして述べる確認的な強調と読む。既存の `hzxu` は、同じ著者・箇所・主張・文脈の中で、指定した内容を確かなものとして提示する関係である。`r2en` が現在の不能だけを取り出し、`r2eo` が主張と期待背景の帰属へこの提示を加える。愛着、内的定着、原因全体を強調の対象へ移さない。新しい基本関係は追加せず、二定義を追加した。[Duden「wirklich」の副詞用法](https://www.duden.de/rechtschreibung/wirklich_tatsaechlich_eigentlich)

現代辞典の用法説明は比較資料として使う。1784年の唯一の読解を現代辞典から決めたとはしない。確かな内容として述べることから、著者が実際に知っていること、内心で確信していること、内容が世界で真であることも導かない。

## 現在の能力と将来を分ける

`vor der Hand` は現在の局面についての限定として読む。Adelungの項目もこの表現を現在について説明している。ここでの基準状況は必ずしも一瞬ではない。本文にない期間、回復時期、将来も続く不能を追加しない。[Adelung「Vor」](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_5_1_1450)

自分の理解力の使用 `bm` には、独立した使用 `bb` の「他人の指導なし」という条件を加えない。不能は現在の本人の基盤を保持した通常機会での評価である。あらゆる可能な援助の下で絶対に使えない、という意味ではない。前版の説明文にあった「他人の指導があっても使えない」は、この評価範囲内で読む。履歴として述べるのは試行を許されなかったことであり、実際に試行したことがないという別の内容へ置換しない。

## 確認した範囲

原刊483頁を見直し、原文の位置126から292までを八範囲へ分けた。各人への照応、愛着の取得、併記、時間限定、強調、不能、因果を現行の定義と対応させる。原文範囲と採用した読みは `data/confirmed-incapacity-reading-v1.json` に保存する。

能力の試験は実際の定義を実行し、現在の機会、二つの通常場面での成功、場面の優先関係を変える16組合せを確認する。指導ありの成功、訓練だけによる成功、分類や評価の欠落、空の人物範囲などの十対照も確認する。帰属・期待背景・確言・本文順序の16組合せと十四対照では、別の著者、箇所、文脈、主張、焦点への取り替えを区別する。未知の入力は補完しない。

愛着の取得、因果、期待比較などの既存検証は、依存する宣言と意味規約が同一で、固定入力のハッシュも保存されていることを確認して再利用する。世界内容全体を同時に実行した試験や、ドイツ語との意味一致の自動証明とは区別する。三記法の往復、第一文の判断、十二全単位の判断を保持することも検査する。

既存の第12文を改訂し、他の51文を保持する。さらに、前版で取り除いてしまった二文を復元し、本文を54文とした。`h2c` は第三文の足枷の比喩、`h3b` は第四文の足枷を外した場合の不確かな跳躍の帰属であり、第二文の部分帰属ではなかった。前版の説明と置換判断は誤りだった。変更前の `kant-nature-sentence.noema` の第12・13文を内容を変えず末尾へ戻し、依存する宣言と意味規約も確認する。既に数えていた草案範囲なので、新しい対応文字数としては加算しない。

旧第11文の `ho2` も第三文の「理性的使用、むしろ誤用」という言い直しを扱っており、第一文の重複ではないため保持した。第三段落の残る三文と段落全体の判断は未完である。今回確認した139文字は文単位の記録として別記し、全単位の意味確認済み2,212文字や草案対応8,220文字を増やさない。
