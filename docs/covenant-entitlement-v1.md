# 同じ合意形成への資格と否定疑問・回答

第六段落冒頭のberechtigt seinを、同じ永続的な後見を目的とする相互宣誓の合意を、正当な規範の下で形成してよいという資格として読む。形成の実行能力や、法制度上の拘束力を生む権能とは分ける。後続のnull und nichtigで述べる無効性は別の内容であり、この問いへ先取りしない。

一般の団体範囲`r47e`には、全成員が聖職者である`r456`と、教会の職務代表者による`r46c`の二構成を許す。これは原文の会議体の例示に即した、教会関係者の団体という採用解釈である。長老を含むClassisへ全員牧師条件を課さず、二構成の排他性や同時成立も要求しない。全時代の用語の必要十分条件とはしない。

`r47f`は団体・合意・信条・主題・政治的共同体の五個体列から、既存の目的付き相互宣誓`r47d`の形成内容を作る。合意の固定基準`h254z`を使い、規範の評価点が変わっても形成時の当事者や条項を選び直さない。評価される形成と規範の判断時点を分けている。

`r47g`は既存の`rdu`を使い、同じ出所・団体・立場・形成記述・引数列に正極性の積極的許可があり、反対極性の要求と衝突しないことを述べる。許可を調べるために形成や目的の成功を実行しない。本文統合では評価側を道理・人間の啓蒙に関する規範へ固定する必要があり、団体自身の規則や現行法上の許可だけで正当性を済ませない。

`r47h`は団体と信条の候補を、許可や形成の成功とは独立に分類する。`r47i`は、その候補に当該形成への資格がある事例が一つでもあるという内容である。`r47j`はその存在を否定する。一つの不適格な例を見つけただけで全否認にはならず、別の合意に資格があれば否定は成立しない。

`r47k`は同じ共通内容を負極性で問う発話、`r47l`は同じ共通内容を負極性で主張する回答発話である。否定疑問全体をもう一度否定して肯定に変えず、形成や目的の不成立を回答内容にすり替えない。質問と回答の発話の働きは異なる。

[検査](../reports/covenant-entitlement-v1.json)は、許可と反対要求の4組合せ、別出所・別名宛人・別立場・別記述・引数反転・極性・時点を区別する。形成・信条・目的・神的な権威の真理は未知のまま保持する。候補量化と否定・発話の構成は実際の定義で評価し、所属の複雑な判定だけを既存の検証済み境界で受ける。

ここまでの構成に新しい基本関係はない。第六段落専用の参照供給、etwaの例示と自己呼称、sogarの強調、Aberとsollte nichtの期待、Ich sageとganzの帰属・全面的な拒否は残る。本文96主張と確認済み分量を保持し、問いと回答全体の意味確認済みとは数えない。
