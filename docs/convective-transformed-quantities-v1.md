# 第九節の変換量を同じ座標へ接続する

対象は u0233–u0236 の一文である。必要な意味は、K での先行方程式の成立仮定、第三節の座標変換と第六節の場変換を手段とする k への書換え、変換後の六式、wobei による三速度と密度の五等式の説明である。次文 u0237 は新しい速度の物理的同定と相対性への適合の結論なので、その結論を先行する変換の前提にしない。

今回の依存群は、原系の密度・流速の物理解釈 `ekyz`、正逆座標写像 `s46`、全座標規約 `eisqt`、場の変換 `s6k/s6l`、領域の逆像 `s6m`、五等式 `sent`、印刷された六式 `semf` を再利用する。新しい原始概念はない。式を各々に閉じ込めず、同じ新座標上の密度関数と三速度関数を構成して双方へ渡す。

`ekzr` は D = V² − v ux、`ekzs` は三つの分数、`ekzt` は βDρ/V² を作る。`ekzu/ekzv` は新座標を逆写像で旧座標へ戻した後にこれらを評価する。D の非零性は `ekzw` に分け、負の D や負・零の電荷密度を排除しない。D が零の点を新領域から取り除く操作は行わず、対象領域全体における式の適用条件として明記する。

`ekzx` は同じ K/k、単位、正逆写像、旧領域とその新表示を保持する。新しい電場・磁場は同じ旧場から構成し、既存の物理的な場規約へ接続する。変換した速度と密度を新系で実測する物理量だという条件、担体付着、磁気側の発散零、方程式の成立はここへ加えない。

`ekzy` は M0390 の五等式と同じ新電場の三対角偏微分を結ぶ。`ekzz` は M0389 の六回転式、`ekz2` は五等式の全点条件で、どちらも同じ構成関数を使う。原刊916頁の磁気側には 1/V が印刷されていないため `semf` を保つ。式の記述を、その導出が物理的に正しいという証明に変更しない。

現在はこの依存群を検査する段階であり、本文の著者提示と全単位の判断はまだ追加しない。次に同じ設定を閉じた内容へ束縛し、先行方程式への照応、第三・六節への参照、仮定と導出提示、二表示と wobei を一つの文へ接続する。その後に u0237 の新系で測った速度と適合の結論を扱う。
