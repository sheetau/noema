# 役割の資格要件と、本人の実際の技能

医師の部分説明を、健康上の継続的な助言者から、専門的な知識・技能を資格要件とする社会的な役割へ限定した。旧 `sr` は、人であり健康判断を継続的に援助することだけを要求していた。そのため、専門的な役割を持たずに家族を助ける人も同じ条件を満たせた。

本人の技能をそのまま必須条件にすると、役割を持つが技能が不足している人を表せなくなる。そこで、役割の保持、役割の機能、役割に課される資格要件、本人の実際の知識・技能を別の関係にした。役割が要求することと、本人が満たしていることは独立に述べられる。

一般定義 `rqxh` は、同じ主体・役割・状況について、保持・機能・資格要求の三関係を結ぶ。機能には受け手の活動の記述、資格には担い手の性質の記述を渡す。役割Aを保持し、役割Bが対象活動を扱い、役割Cに専門性が求められるだけでは成立しない。記述は参照するだけなので、資格要件を述べるために担い手の実際の能力を知る必要はない。

今回追加した四つの基本関係は職名を返す対訳表ではなく、これらの関係をそれぞれ明示するためのものとした。ただし、自然言語の意味規約を与えることと、その基礎をすべて構成的に説明することは異なる。社会的な役割の成立や、学習と知識の判定を完成したとはしない。新しい文法や職名専用の演算子は加えていない。

本文の `sr` は、旧来の健康上の助言者の条件を `rqxj` に保存して要求し、健康判断 `sq` を援助する同じ役割へ専門性の資格記述 `rqxi` を結ぶ。`rqxi` を別途実行すれば、本人が実際にその知識・技能を持つという内容も表せる。役割の資格要求だけからは、実際の習得、助言の正しさ、活動の成功を導かない。

[原文の該当箇所](https://korpora.org/Kant/aa08/035.html)は、医師が本人に代わって食事・生活の調整を判断する例である。ここでは専門的な役割を含む読みとして部分説明を改訂し、現代の特定の免許・学位・法制度を追加しない。ほかの健康専門職と医師との歴史的な区別は、今回の条件だけでは説明し終えていない。専門職でもある家族まで除くのではなく、専門的な役割がない助言だけで条件を満たすことを防ぐ。

二つの役割に三関係を配分する64例で、同じ役割の証人が必要なことを検査した。医療とは異なる修理の実践を想定した六対照でも、担い手・作業・資格・役割・状況を共有する条件を使える。修理や訓練の内容自体を完成した語彙として追加した例ではなく、同じ一般定義の再利用を確かめる有限モデルである。

本文の22対照では、実際の供給・例の連言・適用可能性・条件文の定義を実行し、旧版と比較した。役割に関する不足で前件が偽になっても、条件文だけは真になり得る。これを原文の例が成立したことと取り違えないため、前件と適用可能性も別々に検査している。

役割と技能の四組合せ、技能の主体・対象・状況を取り違える三対照も検査した。技能が不明なまま役割を述べられることと、役割を結ぶ三関係が不明ならそれを補完しないことを確認した。八つの著者帰属対照では、役割や作業の事実は不明のままにした。通常の評価を使い、既存の定義を検査用の基本関係へ置き換えていない。

改訂が影響するのは本文の文4だけで、42文の構文、確認済み十一単位、冒頭一文と前回の支払いの意味を保持する。完全記法・短縮記法・固有文字の往復も確認する。登録簿v46では判断の根拠を新しい本文へ結び直すが、完成した単位や原文の対応範囲は増やさない。書物・宗教上の助言者・良心の説明と、第二段落・二作品全文の確認は残る。
