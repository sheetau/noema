# 符号付き座標と校正済み物差しの測定

u0045第一文の座標測定を、軸への正射影と符号付き距離に加え、実際に同じ道具と方法で得た測定結果へ結ぶ。原文範囲は[軸への正射影の照合記録](../data/einstein-axis-projection-source-reading-v1.json)と同じ[0,240)、176本文文字である。原刊897〜898頁の保存済み画像照合を引き継ぐ。

eixcは符号付き値の絶対値を非負距離として定める。負の座標でも測定距離は負にならず、原点への射影では零になる。eixdは指定された物差しだけを同じ方法の全道具範囲eisejへ含め、校正eisef、完全履歴の静止eipwと剛性eigyを同じ系・尺度・期間へ結ぶ。余分な未校正の道具を範囲から隠すことはできない。

eixeは観測者が同じ方法で二地点間を測る操作、同じ物差しの読取りxh、空間距離thを同じ非負値へ結ぶ。追加した一般的関係eisncはどの方法を実際に使ったかを指定する。既存xhには方法の引数がないため、校正した方法が別の方法であっても接続できてしまう問題を防ぐ。道具の全範囲・校正・履歴・数値幾何・存在と一意性は別条件であり、この原始関係一つに一文全体の意味を委ねない。

eixfは同じ原点と射影点への測定を、前段eixbの全期間の物理的射影と符号付き距離へ渡す。eixgはその系へ配備した物差し、初期と同じ原点・軸・物差し、現在の同じ方向標識を保持する。eixhは射影点・観測者・方法・非負距離の存在を要求し、特定の候補取得関数が返す射影点だけへ限定しない。eixiは選択した座標値の成立と、全ての実数値候補との一致を要求する。方法や観測者が複数あっても、同じ値なら排除しない。

この依存群の文脈は、一つの静止した測定配置の全期間として用いる。物差しを置き直す前後を含む全操作に一つの静止履歴を要求すると、同じ有限の物差しで空間を測る操作を妨げる。全空間へ統合する際は、同じ対象・軸・空間配置・尺度を保持する測定配置ごとの文脈を接続する必要がある。今回の定義だけで、全空間の測定が一つの固定配置で完了するとはしない。

検査は符号付き値と非負距離、方法と校正の一致、全道具範囲、各境界の全引数、同じ初期個体を識別する。存在量化の個体域には二値を使い、射影点・観測者・方法の各位置を確認する。実数の存在量化と全値候補の量化は本体を検査し、元の全実数量化が有限評価を拒否することを別に確認する。履歴関数の有限指紋は引数の結合確認であり、完全履歴の証明ではない。
