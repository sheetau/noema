# 二つの制度条件を対比する提示

カント第17区間の高い側の自由と低い側の自由を、著者が順序を付けて対比する構造へ接続した。前段の見かけの利益・実際の障壁・発展機会の内容は保持する。今回の追加は、すでに草案がある範囲の談話構造を補うもので、原文の対応文字数を増やさない。

## 内容の連言と対比する行為

前段の `iaecontrast` は、同じ比較視点で見かけの利益、実際の障壁、低い側の発展機会を合わせた内容だった。これだけでは、著者が二つの側をどの順で対比したかは記述されない。

[一般定義](../examples/v016/ordered-contrast.noema)の `rw3` は、異なる二つの本文箇所への内容の帰属、第一から第二への本文順序と逆順の不在、同じ二内容の対比としての提示を結ぶ。著者・範囲・文脈を全ての帰属で共有し、内容の記述の左右を保持する。別の著者の対比や逆順の対比を流用できない。

対比を提示したことと、内容が真であることを分ける。二内容が論理的に矛盾することも要求しない。例えば、ある制度の利点と欠点を対比することは可能であり、利点があるという内容だけから欠点がないとは導けない。今回の原文でも、有利さと一部の障壁は両立し得る。

`rw3` は新しい文法演算子ではなく、既存の型・記述・関数適用・同一性・連言・否定による定義である。対比する行為そのものの帰属は引数として与える。これは既存の観測者の判断に用いた `zbc` と同じ役割であり、今回は階数3の記述を扱う。一般的な談話行為の理論や、自然言語から対比を自動認定する方法まで説明済みとはしない。

## 本文への接続

[本文草案](../examples/v016/kant-ordered-contrast.noema)には、次の二内容を置いた。

| 内容 | 定義 | 同じ基準視点での条件 |
| --- | --- | --- |
| 第一側 | `iafleft` | 前段の `iadcontrast`。高い側が有利に見えることと実際の障壁。 |
| 第二側 | `iafright` | 前段の `iaeroom`。同じ低い側と要因を外した全解での発展機会。 |

`iafparallel` が、二つの本文箇所と二内容の記述を `rw3` へ渡す。内容の帰属には既存の `iaereport`、本文順序には既存の `ue` を用いる。局所参照 `iafleftnode` と `iafrightnode` は本文箇所を指し、概念の意味を原語の名前だけで代用するものではない。

`iafannotation` は、この対比の帰属に加えて、前段の `iaeattribution` も要求する。親の全宣言と先行20文を保持し、最後の注記を更新した。二内容を別々に評価したときの連言も、元の `iaecontrast` と一致する。

`hingegen` による二側の提示を部分記述した。`doch` の期待違反は別に残る。見かけの利益から「障壁がないと期待していた」を自動的に導く条件は加えていない。

実際の前段の能力・因果モデルを用いた7条件で、左右の内容の連言が元の内容と一致することを確認した。左右の真偽の4組合せを全て含む。全能力の範囲が空の場合や、別人に機会がない場合、要因を外した結果の一つで失敗する場合も含む。この検査は両者の構成上の対応を確かめるもので、原文の解釈の正しさを証明するものではない。
