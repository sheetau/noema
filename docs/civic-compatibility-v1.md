# 改善の実否・信念と市民的秩序との両立

カント第六段落の第十一文に向け、真の改善又は改善と思われる変更と、市民的秩序との両立を構成します。対応する部分は固定原文`u0013[3256,3341)`です。原刊490頁を再表示し、[AA VIII 40](https://korpora.org/kant/aa08/040.html)の前後を確認しました。全文の意味確認はまだ行っていません。

宗教的な理解・判断・実践・共同制度のあり方を対象に、変更の前後と評価基準を固定します。真の改善は同じ基準による厳密な優越、改善という信念はその同じ比較内容を本人が真として受け入れることです。両者を包含的な選言に置き、誤った改善判断も範囲に残します。既存の信念関係`h233c`と閉じた呼称`h223g/h223h`を再利用し、引用内容の比較を信念の成立から実行しません。

既存の制度配置の比較`r36z`は規則・手続・役割関係に対象が限られるため、そのまま個人の理解の改善には使いません。同じ比較構造を、Noemaで内容が与えられた一般のあり方へ広げています。候補や評価基準の完全性は明示した解釈契約であり、原文が具体的な改善一覧を列挙したことにはしません。

市民的秩序は、公的法による外的共同生活の秩序と読みます。その全条件を閉じたNoema内容で指定し、非空の条件群を要求します。両立は、一つの実践的可能状況で、同じ変更後の内容と秩序の全条件がともに成立することです。各条件の別々の充足例を集めたり、抵触を見つけられないことだけで両立としたりはしません。現行制度の全細目の凍結や宗教内容の正しさを秩序へ含める読みも採りません。

全候補のうち、真又は信じられた改善である各変更に、この両立を要求します。相互に排他的な全改善を一度に採択する条件は加えません。信念を指定する呼称の不一致は、前件がないことにして隠さず、全称条件の不成立として検出します。

局所検査は厳密比較、信念と真理の分離、四対象の呼称、選言、変更と秩序の同一候補、全条件、全変更への量化、未知入力を扱います。巨大な一括模型を使わず、個別の実評価と量化の接続を分け、検査境界を報告します。本文106主張と既存の意味判断は変更しません。君主による両立の確保、臣民自身の救済目的と判断、委ねる範囲、暴力的妨害の防止、全文の照応・提示は次の構成へ残ります。
