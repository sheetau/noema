# 必要な命題の総括と、応用を示す課題

アインシュタイン1905年論文のu0150に、必要な命題を導いたという総括と、応用を示すことへの移行を部分記述した。総括する命題の範囲、その内容、次の課題を共有しつつ、導出を提示したことと応用を示し終えたことを分けた。

一般定義s5oは、主体・課題・段階を指定し、選んだ非空の項目範囲と必要とされる項目範囲が過不足なく一致することを要求する。一部の必要項目だけを選んでも成立しない。s5pは、その全項目の内容について同じ主体が同じ段階までに導出を提示したという条件である。内容そのものの真理や証明の正当性は、この条件だけから認定しない。

s5qは、同じ各項目の内容について、指定分野への応用例があり、それを同じ主体が示したという目標内容を作る。応用に当たる例と提示した例は同じものでなければならない。一つの例が複数の内容の応用になることは許す。この目標内容を引用して課題を提示する文は、現在すでに目標を達成したという文と区別する。

論文の総括s5rは、同じ範囲と内容の写像を導出の提示へ接続し、対象理論が既存の二原理saw・sbdを使うことを要求する。目標s5sも同じ範囲と内容の写像を使う。総括と課題への移行は別の箇所へ帰属させ、いずれも前段の第一部を指す範囲を共有する。§5の第三座標系の局所仮定範囲とは混同しない。

この接続には部分解釈がある。「必要」は次の応用課題に対する必要性、「その応用」は各命題に応用例があるという分配的な目標としている。必要性が前段全体を指す読みや、命題群をまとめて使う読みとの関係は未確定である。「二原理に沿う」ことも、両原理を用いる条件への部分接続にとどまり、無矛盾性や論理的帰結を認定してはいない。

運動学と電磁気学の分野名は参照先として置いたが、その概念自体を説明し終えたとは扱わない。原文中のKinematikとElektrodynamikを対応範囲から除外した。また、必要な命題の全項目と内容の具体的な割当は未完である。検査には既存の座標変換・速度合成の内容を代表例として使い、それを原文が指す全命題の一覧とはしていない。

一般条件18例、論文への接続14例、帰属8例を検査した。必要項目の不足・余分な選択、別の主体・課題・段階、別の内容の導出、原理の片方の欠落、別の応用例の提示を区別する。引用した内容を真として実行しなくても、総括や課題提示の帰属を検査できる。

新規7件を含む関連26テストが通過した。二文書の通常記法・短縮記法・固有文字の往復、CLIのJSONと構文木の一致、SVGのXMLとしての読み込みも確認した。全テストの実行、字形の目視確認、907頁の原刊照合は今回の検査に含まない。

累積文書は基本記号526、定義790、文152、正規形200,278文字となり、親文書から1,149文字増えた。新しい文法演算は追加していない。必要性・導出提示・応用・提示行為の意味規約を基礎概念から説明する課題は残る。
