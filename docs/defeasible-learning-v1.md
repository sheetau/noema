# 試行の仮定と、学習の見込み

カント第二段落の学習節について、試みに取り組む仮定の背景と、著者がその経過をどの程度もっともらしいとみるかを分けた。従来の`fl`は、能力取得を著者が見込む候補を一つの関係で与え、その全てで取得を要求した。候補の選定と見込みをまとめた規約だったため、候補に残した失敗と、優先して見込む結果を区別しにくかった。

新しい構成は、学習に失敗する仮定も範囲に残す。著者の背景知識から妥当とみなす候補に優先順序を付け、最も優先する候補すべてで取得が成立することを求める。同程度に優先される候補での失敗は無視せず、劣後する候補での失敗は許す。成功したという結果を見て候補や順位を作る規約にはしない。

この読みは数値確率を置かない推量である。[Adelungのwohl項](https://lexika.digitale-sammlungen.de/adelung///lemma/bsb00009134_6_2_2635)の推量に関する用法を採用するが、すべての用法や唯一の歴史的解釈を形式化したとはしない。[IDSのwürde形の説明](https://grammis.ids-mannheim.de/systematische-grammatik/312)に従い、würdeという形だけから未来時制を導かず、経験の後に学ぶという原文の文脈で将来への位置付けを与える。

一般構成`r2by`は、仮定範囲・優先順序・将来関係・目標内容を別々の引数に取る。順序には既存`rqt4`を使い、循環や空の候補、極小候補を欠く範囲を拒否する。全候補について将来への位置付けも検査するため、優先されない候補が現況や不明な時間に置かれていても、その不備を隠さない。全ての可能世界や無限の時間を有限検査で列挙したという主張ではない。

| 条件 | 新しい見込み |
| --- | --- |
| 優先する仮定で取得し、劣後する仮定では取得しない | 成立し得る |
| 比較不能な優先候補に、取得しない仮定がある | 成立しない |
| 結果は成立するが、仮定範囲が空か順序が循環する | 成立しない |
| 優先候補は将来にあるが、残る候補が基準時点自身にある | 成立しない |

知的側では既存の不成功経験からの取得`fq`、身体側では転倒からの取得`r2ax`を渡す。本人と基準を保持し、活動記述はそれぞれ知的活動と補助なしの足移動へ結ぶ。両側の仮定や真偽が一致することは要求しない。原文の非字義的な描写は、同じ著者・学習節・本人について両記述を対応させる。

[endlich項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_7_1_1214)には時間・順序の終わりを表す用法がある。今回は、少数回の経験を経て能力を得る終点という読みを採る。経験の順序、前状態の能力欠如、後状態の能力保有は既存の取得構成にある。別の用法にある長い期間や、無限に反復すれば必ず学ぶという保証を付け足さない。

本文は、学習を危険の程度の理由にする帰属と、現在の身体的取得構成による描写を更新した。旧第39文に残っていた初期版の身体描写は、旧第50文の改訂後も併記されていたため削除する。過去の宣言と文書は保存し、現行本文の意味参照から古い見込みを外す。本文は51文になる。旧第40文以降の番号は一つ繰り上がるが、確認済みの十一単位と先頭六文について、文の内容ハッシュと依存する意味規約は同じままである。

検査では二候補の全関係、応答、将来関係、現在の真理を独立に変える512組合せを照合する。原文側は現在の能力評価・経験列・因果的寄与・取得を実行し、知的側と身体側の独立な四組合せと十一対照を調べる。仮定の対象者・活動・基準、著者、循環、空範囲、時間の不備、寄与の欠落、未知入力、理由と描写の帰属、番号変更後の意味保存、三記法の往復も検査する。

仮定背景と認識的な比較の妥当性は解釈入力として明示する。今回は七定義と二関係を加え、原文の新たな対応範囲や意味確認済み分量は加算しない。末尾一文の全体を、危険の程度・理由・萎縮・頻度・対比を含めて通して確認する作業が残る。
