# 等体積を否定する第三文

u0203[390,421)の「Dies ist jedoch nicht der Fall.」を、直前の等体積の仮置きを受けた否定として記述する。第二文の「等体積ならエネルギー比は二乗振幅比」という条件文を撤回する読みではない。第一文からの平均密度と、同じ光の部分・単位・領域・総量を保持する。

原文は量化の強さを明記しない。今回は、先行の図式的な議論の各設定について等体積を否定する、無限定の強い読みを著者へ帰属する。これは解釈上の選択であり、唯一の読みではない。特定の未指定の一例、通常の場合、一般的不変性の否定を採る読みはそれぞれ別である。

| 内容 | Noema | 論理的な範囲 |
| --- | --- | --- |
| 実際の二体積が等しい | ekmz | 同じ設定の正のSとS′が等しい |
| 各設定で等体積でない | ekm3 | ∀設定（ekmo → ¬ekmz） |
| 常に等体積である | ekm4 | ∀設定（ekmo → ekmz） |
| 常に等体積というわけではない | ekm5 | ¬∀設定（ekmo → ekmz） |

ekm3を著者の主張へ結ぶ。ekm4・ekm5は読みの違いを確認する比較用の定義で、著者への帰属には含めない。前件にD≠1を加えて否定を自明にしたり、検査に合うようekm3をekm5へ置き換えたりしない。

強い読みには、後続の体積式から反例がある。D=β(1−av/V)、S′=S/Dにおいて、V=5、v=3、方向n=(1/3,2/3,2/3)ならβ=5/4、D=1であり、非零速度でも等体積になる。E=(-2,2,-1)、H=(-2,-1,2)はこの方向の横波で、A=3。変換後はE′=(-2,1,-2)、H′=(-2,-2,1)、n′=(-1/3,2/3,2/3)、A′=3となる。半径2ならS=S′=32π/3、平均総量E=E′=12である。これは速度零や振幅零だけによる例外ではない。

検査では横波条件・場と方向の変換・体積の二積分・総量の積を具体的に確認する。積分の診断にはπ=3/4を使うが、本文のπをこの有理数へ変更しない。標本による積分オラクルと、全実数域での物理モデルの存在証明は区別する。先行報告が保存する一般の断面積分の読みを引き継ぐ。

「Dies」の後方参照には既存eisraを使い、先行内容ekmsと現在のekm3を固定する。「jedoch」の対照には既存eisnpを使う。共通の対象はekm6で同じ光の部分の物理的設定へ結ぶ。引用は実行されないので、著者の無限定の否定を記述することは、その物理的真理を証明することを意味しない。

この一文の本文26非空白文字を判断対象とする。前二文と合わせて追加327文字・5数式等要素であり、u0203全体の完成件数は増やさない。続く球面・無流出入・同じ光の集合・エネルギーの問いは未完である。
