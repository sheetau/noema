# 第三系の導入と四式の二回適用

u0093の三文とu0094の四連鎖等式を、原刊901頁に照合して一つの意味群として記述する。前文で表明したφの決定意図を目的とする第三系導入、仮定する運動と零点、座標の命名、二回変換で得る式までを保持する。

第三系導入ejbhは、同じK′を議論へ導入するeisd3、先に構成した運動・三零点ejbbの仮定ug、K′という呼称の採用eisd4を合わせる。目的付きのejbiでは、同じ導入行為を実行し、前文zgnの同じ正規化後φ=spcを決める意図zgmへ手段関係eisnqを結ぶ。目的は、意図が新たに生じることでも、φの決定が既に成功することでもない。eisnqは表明済みの意図を受ける一般の目的関係であり、第三系やφ自体を原始語の意味に埋め込まない。

物理条件は[第三系の依存群](third-frame-geometry-v1.md)を引き継ぐ。−vの共通速度を全固定配置・全比較時点へ要求し、原点が縦軸上にある条件を横二座標零で保つ。K、k、K′の共通零は同じ基準出来事zgkへ結び、光の放出出来事を使うことは要求しない。原刊のΞはkの縦軸と読む。

三位置記号の現在の命名には、同じ地点・値・状況に対する規則を指定して名称を採用する一般関係eisnwを用いる。ejbd、ejbe、ejbfはそれぞれ第三系の三軸の現在eixu測定であり、t′のejbgは第三系の時刻規則eiylである。命名宣言の対象は三位置座標だけとし、時間記号はその解釈対応を保持する。第三系のx′を以前の補助x′=x−vtと同一視しない。新しい五つの呼称個体の綴りは識別表記へ保存し、意味は測定・命名関係で結ぶ。

結果提示ejblは、現在の四式、第三系の設定、全出来事の三記録と二回適用から成るejbcを前提とし、ejbkの全四連鎖等式を得ると著者へ帰属する。中間系の記録を共有し、同じφをvと−vで評価する。原刊の順序は時間、第一、第二、第三位置であり、時間の中間式にはvξ/V²、第一位置にはvτ、横二式にはβがない。最終値の共通倍率はφ(v)φ(−v)で、1とは限らない。

局所検査は、目的の引数と引用、三位置の命名と四規則への対応、同じ前提・結果・著者・節・本文順序を対照する。先の280例による運動・三記録・全八等式の検査と保存代数証拠は変更せず引き継ぐ。引用された物理条件や関数を提示の検査中に実行しないことも確かめる。原文の通読判断はこれらの検査とは別に記録する。

採用した読みでは、u0093–u0094の目的・追加導入・仮定・参照・命名・二回適用・全八等式を欠落なく保持する。φの対称性、φ=1、KとK′の相対静止、恒等変換は後続の論述へ残す。これは明示した読みの下でのアシスタントの判断であり、独立査読や意味同値の自動証明ではない。
