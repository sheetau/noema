# 同じ球面の新系における楕円体面

u0206–u0207は、前の同じ球面を動く系kで考察すると楕円体面となり、新系時刻τ=0では表示された方程式を持つ、という一文である。原刊913頁と保存MathMLを照合した。第一項はβξ−aβ(v/V)ξ、横二項はη−bβ(v/V)ξとζ−cβ(v/V)ξであり、それぞれを二乗して加え、R²へ等置する。

楕円体を単なる名前として追加せず、三角線形写像L(x,y,z)=(Dx,y−Bx,z−Cx)とその逆を構成する。D=β(1−av/V)>0、B=bβv/V、C=cβv/Vである。正半径の球面の可逆な線形像という一般的な幾何学の意味で、‖L(position−center)‖²=R²を楕円体面とする。主軸の方向や半軸をこの文で追加計算する必要はなく、せん断項を落とした軸沿いの回転楕円体にしない。

新系の任意時刻τでは、L(center)=(β(Va−v)τ,Vbβτ,Vcβτ)となる中心を使う。逆Lorentz変換した同じ球面との所属の双方向の一致を全四座標に要求し、両順序での位置復元も保持する。したがって形状の説明をτ=0だけへ縮めない。表示式の方はτ=0の全三位置で同じ面への所属と一致させる。Kのt=0を追加条件にしない。

同じ68設定の物理部分・波・系・校正単位と初期部分輸送は先の質問条件ekn7から引き継ぐ。形状だけから放射部分の同一性や保存を結論しない。本文ではK・V・同じ部分・範囲・状況を固定し、残る63役割を形状と表示で共有する。

著者の形状主張、コロンからの式の導入、表示の内容、前の質問への照応をuh・uf・eisox・ue・eisraで表す。新しい一般関係は追加しない。光学的な見かけや写真像、物質の剛体殻、光速の慣性静止系、式の導出済みという主張も加えない。

検査は三角写像の逆、非軸方向と符号付き速度、任意時刻の中心、面の内外、旧新零時刻の区別、全四座標と63設定の束縛、引用の非実行と提示の向きを扱う。多項式補題は有理数の代数に限り、全実数の主軸定理や物理理論又は意味同義性の自動証明とは区別する。次のS/S′の命名と体積比は未完である。
