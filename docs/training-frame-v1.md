# 枠の構成と、歩行学習のための用途

カントの歩行器について、構造部分を接続した物体、身体を支える配置、脚を動かす空間、学習のための用途を組み合わせた部分記述を追加した。前回は装置の識別と閉じ込めの関係を扱ったが、今回はその装置の構成と用途を説明する。

学習用であることから、実際に学習を促すと推論してはいけない。[AdelungのLaufwagen項目](https://www.zeno.org/Kategorien/T/Adelung-1793?s=29099)の電子検索抜粋では、子どもが歩行を学ぶ枠として説明されている。一方、Rink編の[カント『教育学』1803年版47頁](https://de.wikisource.org/wiki/Seite:Immanuel_Kant_%C3%9Cber_P%C3%A4dagogik_K%C3%B6nigsberg_1803.pdf/47)の電子本文では、そのような道具を使わない方針が述べられている。この区別を受け、用途の記述に効果の実証や成功を含めない。

参照できた範囲と、直接取得できなかった資料を[読解記録](../data/training-frame-reading-review-v1.json)に残した。原刊の図や器具の実物を調べて形状を確定したわけではない。身体支持と脚の空間は、今回の暫定的な構成として明示し、車輪数や材質は固定しない。

## 構造部分を組み合わせる

一般定義 `rah` は、意図的に形成した装置に、互いに区別できる二つ以上の構造部分があり、それらが物理的な接続で一つにつながることを要求する。前回の経路の到達関係を再利用し、ここでは接続を対称的に扱う。構成部分の列を並べ替えたり同じ部分を重複記載したりしても意味は変わらない。

装置自身をその部分として数えたり、記述していない外部の部材を介して連結したことにしたりする場合は拒否する。構造部分は製造時に別々だった部品に限らない。一体成形でも区別できる構造部分を選べる。ただし、この部分の選定や接続関係を現物から自動認定する機能は含まない。

`rai` は、この構成に身体支持のための配置と運動を許す配置、そして利用者群と活動を指定した学習用途を加える。構成があるだけ、用途を称するだけ、身体支持だけでは、この合成条件を満たさない。

## 用途と実際の活動を分ける

| 定義 | 内容 |
| --- | --- |
| `zal` | 同じ身体移動の行為に、他者や器具による身体支持がないという活動の目標 |
| `zam` | 子どもがその活動を習得する用途を持ち、身体支持と脚の空間を備える構成 |
| `zan` | 前回の家畜・閉じ込めの描写と、同じ装置の `zam` を結ぶ |
| `zao` | 対象側の記述と `zan` を、実際の身体活動を実行評価せず比喩として参照する |

`zam` は利用者群と活動の定義を記述として保持する。そのため、装置が現在使われていなくても、利用者が実際には子どもでなくても、活動が実現していなくても、構成と用途の条件は独立に評価できる。実際に身体を支えられながら移動している場合と、補助なしで移動している場合は `zal` の評価で分ける。別の人や別の行為への支持を混ぜない。

これにより、学習のための通常の用途と、本文中の制限的な使われ方を同じ装置へ記述できる。どちらも、子どもであるという性質を原文の人々へそのまま付け加える条件ではない。本文の既存9主張は変更せず、新しい注記を独立した主張には加えていない。

## 検査した範囲と残る課題

一般形64組合せ、構造の接続8グラフと8範囲例、原文の構成・用途15例、身体移動5例、閉じ込めとの接続5例、比喩の帰属3例を検査する。用途を評価するだけで利用者や活動を実行すると失敗する関数を使い、成功を暗黙に要求していないことも確認する。

一般文書は基本述語0・定義7、原文接続文書は累計基本述語174・定義217である。新しい文法や実行時演算子は加えていない。

新規7件と、移動制限および進捗監査を含む関連26テストが通過した。通常・短縮記法と固有文字の往復、検証記録と進捗集計の再生成一致、CLIのJSONと構造の一致、SVGのXMLとしての妥当性も確認した。変更範囲に合わせた検査であり、全テストの再実行は行っていない。

意味の説明はまだ部分的である。構造部分や意図的形成、支持配置、学習用途を基本関係として与えており、その一般的な意味の基礎説明が残る。また、今回の身体移動には、歩行と走行などを厳密に分ける運動学がない。子どもの分類、歴史的な形状の範囲、閉じ込めの開始・時間、比喩の評価的な意味も未完成である。原文との対応範囲は既存草案と重なるため、文字数の集計も意味確認済み区間数も増えない。
