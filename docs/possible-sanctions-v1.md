# 抵抗の誘発可能性と処罰の可能性

カントu0012には、批判が一般的な抵抗を誘発しうるという挿入説明と、処罰されうるという節がある。今回の草案では、可能な結果での因果関係、意図的な不利益の措置、措置への規範的な許可を分けて記述した。誘発可能性から許可を導く規則は追加していない。

| 記号 | 内容 |
| --- | --- |
| `rfj` | 同じ活動・評価文脈で選んだ可能結果のどれかが、指定条件を満たす。 |
| `rfk` | 同じ可能結果で活動が起き、その活動が指定対象についての記述された結果を生じさせ、結果内容も成立する。 |
| `rfl` | 非空・重複なしの適格な集団について、指定性質を持つ成員の割合が明示した基準を満たす内容。 |
| `rfm` | 同じ施行者・措置・対象者について、実行、不利益、その不利益を与える意図、対象行為の評価への応答が成立する。 |
| `rfn` | 対象者・対象行為・評価記述と関係を固定して、施行者と措置から`rfm`の成立内容への関数を作る。 |
| `hzar` / `hzas` | 誘発可能性と、集団内の抵抗の広がりを既存の因果・成員関係へ接続する。 |
| `hzat` / `hzau` | 固定した対象者への措置内容と、その措置が実行される可能性。 |
| `hzav` | 同じ施行者・役割・措置記述への積極的な許可があり、反対の要求がない。 |

可能な結果は、活動と評価文脈に対応付ける。批判が起きた候補、因果関係がある候補、抵抗が生じた候補が別々に存在するだけでは、`rfk`は成立しない。候補が空なら可能性は偽になり、一つでも成立する候補があれば、他の候補で不成立でも可能性は真になる。実際の状況で起きた措置から、選んだ別の可能結果の中にも措置があるとは補わない。

「一般的な抵抗」の広がりには、記述者が説明した性質と割合基準を渡す。全員や過半数へ固定しない。集団の成員範囲と抵抗の具体的な性質、原文に妥当な基準は、なお説明と確認が必要である。

処罰の草案は、対象者に不利益を与える意図を持ち、その人の対象行為に関する評価への応答として実施する措置を構成する。不利益が生じただけでは成立しない。評価は閉じた式記述として保持し、内容を真として評価しないため、誤認による措置も表現できる。この構成は、意図した不利益が実際に生じる場合を扱う操作的な読みである。失敗した処罰の試み、象徴的な非難、刑罰制度や手続の全体はまだ含まない。

`hzat`の閉じた適用を引用すると、誰のどの行為をどの記述で評価した措置かを保持したまま、規範の対象へ渡せる。許可の記述には、措置が実行されたか、不利益が生じたか、評価が正しいかという情報は不要である。原文の *bestraft werden kann* について、実行可能性と規範的な許可を別々に用意し、どちらか一方に自動的に読み替えない。

検査では、因果的結果の可能性・措置の実行・不利益・意図・応答・許可の64通りと、対象や状況の取り違えなど18対照例を確認した。行為の発生・因果関係・結果の成立も8通りで分けた。集団の大きさ、該当人数、三つの割合基準の60通りを検査し、空・重複・不適格な成員を含む列を拒否した。全文草案と独立抽出文書の結果は一致する。

*vorwitzig* の評価、*Skandal* の説明、納付すべき時期との接続、*sogar* と *demohngeachtet* の談話は残る。原文の意味一致を確認し終えた区間は増やしていない。既存15件の著者主張を保持し、今回の操作的な解釈を新しい著者主張として登録していない。

既存の文法から10定義を追加し、基本記号は追加していない。全文草案は87,892代用文字で、親からの増分は1,505文字、独立抽出文書は2,739文字である。定義を含む文書長であり、翻訳の圧縮率ではない。
