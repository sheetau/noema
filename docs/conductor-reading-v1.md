# 導体の基準付き解釈

導入u0003のLeiterは、通常の条件で材料を変えず、有意な電荷輸送を持続させられる物体として読む。電流が現に流れていることは種類の条件にしない。量、尺度、許容する作用、評価時間を先に固定した基準に相対的な読みであり、すべての物質を一つの数値で二分する普遍的な定義ではない。

この選択は、導体では電荷が物質内部を比較的自由に動けるという[OpenStaxの説明](https://openstax.org/books/college-physics-2e/pages/18-2-conductors-and-insulators)を参考にする（2026-10-23確認）。ここで使う「有意」と「持続」の評価基準は本プロジェクトの明示的な解釈であり、Einsteinが数値閾値や試験時間を述べたという帰属はしない。電子種、線形Ohm則、抵抗の数値、微視的散乱機構を原文へ補わない。

| 記号 | 合成する内容 |
| --- | --- |
| eice | 正の輸送率閾値と最小時間、履歴内の十分長い応答区間 |
| eicf | 完全な電流履歴の同じ断面で、応答区間の全実時刻に閾値を超えること |
| eicg | その断面・向き・応答区間が存在すること |
| eich | 基準に適合した、材料を保つ電気的試行の可能な結果に、その試行に由来する持続応答があること |
| eici | 同じ元状況・基準で、そのような試行と結果を持つ能力 |

基礎規約は三つに分けた。eirpは事前の評価基準と数量の帰属、eirqはその基準に属する電気的試行、eirrは具体的な全電流履歴が試行に由来する応答であるという帰属を表す。試行に由来する零・弱い応答もeirrを満たし得るので、これを成功や導体の別名にはしない。数値条件と持続はNoemaの合成側で要求する。物理的な応答の帰属は基礎関係として明示し、単なる併存から導かず、微視的な機構の実証も翻訳の完成条件にしない。

三つの基礎規約は有限検査で発見・証明するものではない。材料、温度、相、接触、作用強度、尺度、過渡応答を除く評価時間、無視する漏れの範囲について、文脈に適切な基準を与える必要がある。基準を結果に合わせて取り直すこと、破壊的な通過、無関係な既存電流を成功に混ぜることは規約上許さない。これらが不明なら成立を補わない。

能力の試行と、原文が比較する磁石・導体の二場合は区別する。種類を確かめる可能な試行が持続応答を持つことから、本文で現に流れる電流に正の下限や一定方向を課さない。特定の担体を全区間追跡できること、参照物体の剛性、二値モデルでの全解保証も導体の必要条件ではない。既存の担体軌跡・介入モデルは、それらの条件を採る説明に使える補助構成として保持する。

検査は区間と数値条件を実行し、基準・試行・元状況・可能結果・全電流履歴の引数を一つずつ変える。元状況に電流がなくても能力を持つ場合と、試行種類・許容性・可能性・応答帰属・持続条件のいずれかが欠ける場合を区別する。全実時刻の持続や実数区間の存在を有限評価器へ渡した場合は拒否する。有限検査では全履歴と持続応答を明示した境界として扱い、端点標本で検証したとはしない。

原文の語の使用箇所と採用した読みは[解釈判断記録](../data/conductor-reading-decision-v1.json)に固定した。具体的な原文文脈へ基準と同じ導体を結ぶこと、磁石・電磁相互作用、起電力・エネルギー、談話全体の合成と通読判断は残る。今回の語義構成を原文単位全体の完成には数えない。
