# 数値の表からアフィン場を構成する

前段では、密度と三速度の数値解を構成し、新電場の三つの対角微分値の和を密度へ合わせられることを確認した。今回は、その係数を持つ場そのものをNoemaで構成し、偏微分の既存定義へ接続した。[独立文書](../examples/v014/affine-field-witness.noema)に一つの合成定義と二つの導出主張を置く。論文本文への追記や基本語の追加はない。

構成する各成分は、四座標x・y・z・tについて、定数と四つの「係数×座標」の和である。係数表は三成分×四座標の12値、定数は成分ごとの3値を持つ。定義`sexw`は、この二つの表から場を表す関数を返す。対角外の係数や時間依存も零へ固定しない。

第一の主張では、四つの座標役割が異なり、係数・定数・評価点が有効なら、この場の12個の偏微分がそれぞれ係数表の値になると述べる。第二の主張は、同じ係数表が数値条件`sens`を満たすなら、構成した場・領域・評価点を用いた`sent`の条件も満たすという接続である。密度式が要求する三つの対角偏微分は、第一の主張の該当する三つを使う。数値条件の引数と係数表を取り替えないことを、保存された`sent`の本体を展開して確認する。

今回の検査には明示した範囲がある。実切断を標準的な実数の値として扱い、加減乗算・順序・非零値の逆数・条件選択を通常の実数演算で解釈する。その解釈の下で、保存された`s5t → sjs → sjr`と、有効性・近傍・集積点の定義を展開した。微分値の成立を外部の判定関数へ渡す従来の検査とは異なり、差商と極限の条件が検査対象になる。一方、実切断の集合演算がこの実数算術を実現することや、無効な切断候補も含む全関数領域についての表現定理までは証明していない。

アフィン関数の差商は、評価点を除けば対応する係数に等しい。極限の近傍半径には1を選べる。集積点条件では、任意の正のεに対して「評価点+ε/2」を選ぶ。これらの存在量化の証人を実際の定義へ代入し、残る任意の係数・座標・精度・近傍点について反例がないことを確認した。有限個の点から微分を推測する方法ではない。

証人の代入は正の論理位置にある存在量化に限る。この代入は検査する条件を強める。正の位置の全称変数には、それぞれ新しい任意の記号値を与え、反例探索で全値を対象にする。否定側の量化はこの方法で置き換えず、未処理の量化が残れば成功扱いを拒否する。未知の構文・意味やソルバーの時間切れも成功にしない。

逆数の零での値は任意の記号値に置いたまま検査できる。差商の極限が評価点そのものを除いているためであり、零除算を通常の演算として認めたことにはならない。誤った微分値、半径零、評価点そのものを集積点の証人にした構成は認証されない。場へ二次の項を混ぜると、同じアフィン微分の証人では検査を通らなくなる。これらは構成した証人の検査であり、失敗したことだけから任意の存在主張を反証したとは判断しない。

この結果は、前段の数値解を、標準的な実数解釈の下では具体的な場の偏微分として実現できることを示す。電気的な場の帰属、物質の軌跡、電荷分布からの密度極限、Maxwell方程式の全条件を同時に満たす物理的事例の構成は残る。[確認記録v13](../data/density-formula-review-v13.json)もこの範囲に限定する。原文対応範囲と意味確認済み区間数は増やさない。
