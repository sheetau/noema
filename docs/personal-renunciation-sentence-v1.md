# 本人の延期と放棄をめぐる第九文

第六段落第九文 `[2678,2985)` を、本人についての一時延期の許容と、本人・後世についての放棄への権利評価を対照する文として記述した。前半の許容は規範的な可能性と読み、本人自身・有界期間・再開方針を必要とする。必要条件から任意の有限期間への許可を逆推論しない。

後半では、本人と後世の二場合を同じ権利評価へ結ぶ。後世の全範囲は同じ選択点が属する時代に対して固定する。放棄は主体による実践的方針の採用であり、将来の全員の服従や永久の不成功を加えない。人類の権利は、啓蒙の進展を追求する条件と機会への全関連請求という明示した読みを保持する。

「足で踏みにじる」は、同じ主体が自身の足で同じ権利を踏む姿への見立てとして接続する。身体的な足・押し付ける動作・行為主体・対象を分けて構成し、その描写を引用する。権利が物理的に踏まれる出来事は中心命題に含めない。
