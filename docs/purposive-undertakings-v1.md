# 引受けの目的と二段階の監督

カントu0013の、信条へ互いに拘束されることで構成員と人々への後見を目指す箇所について、目的を引受けに接続した。目的を持つ人物、引受けを表明する行為、その時点を保持し、目的の達成を表明の成立条件に含めない。[アカデミー版電子本文38頁](https://www.korpora.org/Kant/aa08/038.html)の35–37行にも、この引受けから目的へ続く構造がある。

| 定義 | 内容 |
| --- | --- |
| `rh6` | 同じ本人・表明行為・時点に、指定した目的内容への志向がある |
| `rh7` | 相互引受けの当事者のうち、明示した非空の目的主体範囲で、引受けと目的を同じ行為・時点に結ぶ |
| `ria` | 統括主体が各構成員を監督し、対象者の各人をその構成員の誰かが監督する |
| `rib` | 同じ対象範囲について、明示した将来区間の全状況で`ria`が成立する内容 |
| `hzck` | `rh7`を既存の人・行為・時間順序・目的志向へ接続する |
| `hzcl` | `hzck`が成立するなら、同じ合意に対する既存の無効性判断が成立するという内容 |
| `hzcm` | `rib`の監督を既存の監督関係、順序を同じ評価文脈の時間関係へ接続する |

全当事者に同じ内心の目的を補うことを避けるため、目的主体の範囲は当事者範囲とは別に指定する。目的主体は当事者に含まれ、少なくとも一人いる必要がある。その各人には、指定目的を伴う適切な引受けが必要になる。目的主体に選ばれていない人には、同じ目的を要求しない。組織の共同意図をこの個人範囲の選択だけで説明し終えたものではない。

表明記録を探す際は、目的の条件をその表明と一緒に評価する。ある行為で引き受け、別の行為で目的を述べていたという二つの事実だけでは足りない。最初の表明に目的が伴わなくても、同じ人の別の適切な表明に目的が伴うなら成立できる。時間と行為を無関係な記録から継ぎ合わせない。

監督の目的には、閉じたNoemaの内容記述を使う。`hzcm`へ統括主体・構成員・対象者・履歴・区間を適用した式を引用し、同じ記述を`hzck`の目的へ渡す。目的志向の認定には既存の`hzu`を使い、その認知過程や動機形成の説明を完成したとは扱わない。

二段階の監督では、構成員と対象者の範囲をともに非空とする。統括主体から各構成員への関係と、構成員から対象者への関係を区別する。対象者ごとに担当構成員は異なってよく、全組合せの監督を要求しない。各段で主体と対象が同一になる自己監督は認めないが、階層全体の非循環性まで保証する条件ではない。

統括主体から人々への直接の監督だけでは、構成員を介した二段階の条件を満たさない。また、構成員外の人が対象者を監督していても、その人を中間の担当者として補わない。この定義から直接の監督関係の推移律は導かない。委任、命令の伝達、上位者の意図が人々を因果的に動かす仕組みや、制度的な正当性の説明は残る。

持続の評価では、構成員と対象者の範囲を基準文脈で固定する。明示した区間はその基準時を含む将来区間であり、履歴内の途中の状況を抜かさない。対象者を監督する構成員は時点ごとに交代できる。将来の新構成員も含む読みや、無限時間の持続、後見を永続化することは別途記述する必要がある。

検査では、目的志向と達成の4通り、本人・行為・時点・別名・目的主体範囲・別の表明を変える9対照例を調べた。監督の六つの関係を独立に変える64通りでは、分担による被覆と全組合せを区別した。空範囲、直接監督だけの例、外部の担当者、途中の監督喪失、担当交代、欠けた期間など10対照例も検査した。

原文接続では、目的志向・目的達成・規範的な効力の不成立を独立に変える8通りを調べた。監督の実際の成立が未知でも目的付きの引受けを記述でき、達成を評価するときには未知の監督関係を要求する。別の統括主体の指示記述や別の構成員範囲を持つ目的を、元の目的へ自動移送しない。全対象についての規範の不成立は前版と同じ検査用の解釈として与えており、全記述を列挙した証明ではない。

[一般文書](../examples/v014/purposive-undertakings.noema)は2,962文字、[原文付き草案](../examples/v014/kant-purposive-undertakings.noema)は117,399文字、[抽出文書](../examples/v014/purposive-undertakings-core.noema)は4,860文字である。7定義を追加し、新しい原始概念・著者主張は追加していない。親の宣言と15件の主張を保持した。[意味規約](../data/kant-purposive-undertakings-basis-v1.json)と[検査記録](../reports/purposive-undertakings-v1.json)に条件と限界を保存した。

原文への対応は、目的へつなぐ箇所と、各構成員および構成員を介した人々の範囲への部分的な解釈注記である。宣誓、宗教や組織の一般的な意味、後見の全権限、因果的な媒介、永久性、著者の問い・否定判断への帰属は未完である。全文単位の意味確認済み件数は増えていない。
