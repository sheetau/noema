# 密度式を先行する座標単位へ結ぶ

密度と速度の変換式M0390について、本文に渡す長さ・時間の参照を、先行する光速度の評価と同じ単位へ結び直した。新しい文法、定義、原始記号は追加していない。既存の206文のうち、密度式を提示する一文の引用内で二つの引数だけを変更した。

## 接続の不足

光速度の読み`tc`は、先行する光往復の`sam/san/sao`と片道の`sba/sbb/sbc/sbd`で、長さ単位`ta`、時間単位`rb`、その商の速度単位`tb`を使う。一方、後から追加した密度の解釈`seoz`には、長さ単位`zqi`と時間単位`zqj`を渡していた。

`zqi`と`ta`、`zqj`と`rb`がそれぞれ同じ単位を指すなら、この違いは別名の違いにとどまる。しかし、その同一性を本文で課してはいなかった。密度側の座標・時計を別の単位で解釈しながら、光速度の数値だけを元のまま使う解釈が残る。値の一致や零速度の例だけでは、この不足を検出できない。

これは全ての旧解釈が誤りだったという意味ではない。新旧の内容の無条件の同値も主張しない。今回は、先行する座標単位を後続でも使う読解を明示的に選ぶ。

## 修正した本文

| 引数 | 以前 | 今回 |
| --- | --- | --- |
| 光速度の読み | `tc` | `tc` |
| 長さ単位 | `zqi` | `ta` |
| 時間単位 | `zqj` | `rb` |
| 電荷単位 | `zqk` | `zqk` |

残る引数、`seoz`から速度・密度・総量へ至る構成、著者・提示箇所・先行箇所・範囲・文脈は保つ。`seou`には同じ時間単位`rb`、`seoy`には同じ長さ・時間単位`ta/rb`が渡る。過去の宣言は残すが、改訂した一文から`zqi/zqj`への参照はなくなる。

変更先は[累積本文](../examples/v014/einstein-density-units.noema)と[必要な宣言を抽出した一文](../examples/v014/density-units-manuscript.noema)である。過去の本文と検証記録は変更していない。[意味確認記録v6](../data/density-formula-review-v6.json)はこの接続を記録し、電気的帰属・二系の配置・適用範囲・全文の意味一致を未完のまま保持する。

## 数値で確認した差

元の単位で光速度を5、系の速度を3とすると、正の正規化係数は5/4になる。新しい長さ単位を元の3/2倍、時間単位を元の2倍とすれば、速度の数値はどちらも4/3倍になる。光速度20/3、系の速度4なら、正規化係数は同じ5/4である。

光速度を5に据え置いて系の速度だけを4へ変えると、この係数は成立しない。実際の参照条件`senu`が使う`srd`を、この有理数を埋め込んだ切断で評価して差を確認した。負の系速度でも同じ不一致を検出する。一方、速度が零なら正規化だけでは単位の違いが表れない。数値条件の成功は、単位の同一性の証明ではない。

正の共通倍率では有理数版の正規化条件が両方向に保存されることを一般式で検証し、系の速度だけを変えても常に保存されるという式には反例を得た。この結果は全実切断の解析法則や実際の測定・校正の証明ではない。

本文の式は条件付きである。単位の混在で`senu`の条件が偽になると、その場合が適用範囲から外れてしまう可能性がある。今回の数値例から本文全体の真偽を決めたり、密度の全定義域を評価したと扱ったりはしない。

## 検証と限界

参照の検査では実際の`seoz`を実行し、`seou/seoy`へ届く引数を記録する。π条件・総量・密度・全称された物理内容の四つの境界は明示した代用解釈を使い、全物理条件の真理を証明したと扱わない。旧単位を明示的に同じ値へ解釈した例では、受け渡しが改訂後と一致することも確認する。

著者への帰属、先行箇所への説明、本文順序を変える8例を検査する。旧引用の単位を同じ値と解釈しても、異なる引用記述への態度は自動で交換しない。帰属を評価するだけでは、引用された物理関係を実行しない。

通常表記・短縮表記・独自字形の往復とCLI解析、全宣言と他の205文の保存を検査する。原文の新しい範囲は加えず、部分草案の対応率と意味確認済み区間数は据え置く。二系の標準配置`zqf`の構成説明は今回変更しておらず、引き続き必要である。
