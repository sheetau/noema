# 認識した例が萎縮と回避に作用する

カント第二段落末尾の因果条件を修正した。旧版の`gu`・`gv`は、例と反応が成立し、その例を原因説明に採用する条件だった。そのため、説明が誤っていて実際には作用していなくても成立し、逆に実際に作用していても説明に採用されなければ成立しなかった。

[原文36頁](https://korpora.org/Kant/aa08/036.html)は、一例が萎縮させ、通常は後続の試みを思いとどまらせると述べる。今回の読みでは、その主張を実際の因果的な寄与を含む内容として表す。ただし、著者の因果主張をNoemaで記述することと、その主張を実証することは別である。

## 既存の因果関係を使う

冒頭段落で導入済みの`hzie`は、要因側の対象と性質記述、結果側の対象と性質記述、評価状況を結ぶ因果寄与の関係である。要因・結果の成立は別に検査する。新しい「萎縮させる」という一語の基本述語は追加していない。

| 定義 | 条件 |
| --- | --- |
| `gr`（既存） | 同じ事例の対象者が認識した先行する不成功例。経験者と対象者は別でもよい。 |
| `hzua` | 同じ対象者に、活動`bb`へ向かう十分な勇気がなく、後続する試みへの害の恐れがある。 |
| `hzub` | `gr`と`hzua`が成立し、同じ事例で前者が後者に因果的に寄与する。 |
| `hzuc` | `gr`と既存の回避`gt`が成立し、同じ事例で前者が後者に因果的に寄与する。 |
| `hzud` | 非空・重複なし・適格性・網羅性を保つ事例範囲で、萎縮と通常の回避を集計する。 |

`hzub`・`hzuc`は、一般形`rqqu`を固定した二記述へ特殊化したものである。一般形は任意の記述を脱引用するため、本文の引用境界へそのまま入れられない。本文では固定した性質定義へ直接適用して両内容の成立を検査し、同じ記述を`hzie`へ渡す。引用の制約を緩めず、一般形と特殊化した形の結果を現行評価器で照合する。

勇気の対象も、従来の内容値を受ける`al`から、既存の閉じた性質記述を受ける`hzio`へ接続した。同じ本人についての`bb`を指定するため、別の活動が同じ真偽を持っていても、その活動への勇気を流用しない。活動の成功を先に評価する必要もない。

回避`gt`に含まれる本人の理由認識`me`は保持する。本人が恐れを理由に避けることと、認識した例がその反応へ実際に寄与することは違う条件である。`ea`による原因説明も比較用に残し、言語として誤った原因説明を表す能力を失わない。

## 本文と期待背景を同時に更新する

前版の理由付け`ft`と本文順序を保持し、末尾の主張・背景の組を更新した。`hzue`は更新後の`hzud`を著者へ帰属させ、`hzuf`は期待比較の両側に同じ更新後の内容を使う。`hzug`と`hzuh`がこれらを同じ著者・本文箇所・範囲・文脈へ結ぶ。主張側だけ新しい内容にして背景側に旧版を残す誤りは拒否する。

新しい定義は八つで、基本関係や構文の追加はない。本文38文のうち末尾一文だけを更新する。他の37文と、九つの全体確認で選択した文・依存定義・意味規約は変わらない。

## 検証と限界

六テストが通過した。勇気以外の負例で勇気の不足を固定し、原因の向きの対照を追加した後、該当する二テストも通過した。検査記録は最終の検査用データから生成する。

- 一般の因果条件では、要因・結果・実際の因果・説明への採用の16組合せと七対照、三つの未知入力を検査する。
- 勇気と恐れでは九条件を検査する。別の活動・別人・別状況への勇気を流用せず、活動内容は未知のまま保つ。未知の勇気を不足と扱わない。
- 原文の反応では、二つの因果関係と説明への採用の八組合せ、本人・例・活動・原因・恐れ・回避理由などの11対照を、実際の`gr`・`hzua`・`gt`を使って評価する。一般形と本文の特殊化が一致することも確認する。
- 通常性の13条件では、例外の削除・重複・空範囲・不適格な事例を拒否する。実際の原因と説明への採用を入れ替えた場合は、旧版と改訂版の真偽が分かれる。
- 著者への帰属では八組合せと七対照、期待背景の実際の記述を確認する。帰属中に世界の因果や勇気を評価しない。
- 二文書の長形式・短縮形式・固有文字の往復と、既存九区間の意味判断の保持を確認する。

原文の反応と通常性の有限診断には、純粋な評価結果のキャッシュを使う。一般因果・勇気・帰属・期待背景の検査はキャッシュなしで行う。旧検査のデータ設定は再利用するが、列値を現在の型へ変換し、意味の評価には現行の評価器と現在のNoema定義を使う。旧版の検査結果を実行結果の代わりにはしない。

因果寄与の一般理論、心理機構、唯一原因性、詳細な時間変化は解決していない。架空の例、身体的な転倒との比喩、`schüchtern`の全語義、通常性の有限事例による操作化、後続する試みの範囲も残る。第二段落全体の確認は追加しない。原文対応は既存の末尾範囲と同じで、確認済みは九単位・587非空白文字のままである。
