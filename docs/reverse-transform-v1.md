# 逆向きの変換とφの相反条件

アインシュタイン§3の `u0092`〜`u0096` を部分記述した。未知のφを決めようとする意図、第三の座標系K′の導入、二回の座標変換、相対静止・恒等変換についての著者の推論、φ(v)φ(−v)=1という結論を接続する。

```text
K  → k  :  速度 v、係数 φ(v)
k  → K′ :  速度 −v、係数 φ(−v)

t′ = φ(v)φ(−v)*t
x′ = φ(v)φ(−v)*x
y′ = φ(v)φ(−v)*y
z′ = φ(v)φ(−v)*z
```

この箇所のx′は第三系の座標であり、前段の補助変数x−v*tとは別である。Noemaでは第三系の記録の成分として参照し、原文の同じ字形をそのまま同じ意味記号へ割り当てない。

先行する `spa` は0≤v<Vを前提としていたため、負速度を使う後段には新しい `srd` を追加した。V>0、v²<V²、β>0とβの関係を要求し、βは速度の符号を反転しても同じ正の値になる。先行する定義の意味は変更していない。

`sre` は符号付きの速度と係数関数を受け、四座標式を作る。`srf` は同じ中間記録を挟んで二回適用し、どちらも同じ正規化後の関数 `spc` を使う。φ(v)とφ(−v)が等しいことは仮定しない。`srh` はその二値の積、`srg` は四成分共通の倍率による関係である。

`sri` は同じ出来事が異なる三系で持つ三記録を結ぶ。`srl` は対象範囲の非空性、全出来事での三記録の存在、全ての対応三記録で二回の式が成立することを要求する。都合のよい一組だけを選んだり、別の出来事の記録を混ぜたりしない。`srm` は同じ範囲について共通倍率の結果を述べる。

第三系の運動には、参照する運動系、その縦軸、符号付き速度−v、長さ・時間単位を明示する。`srj` は先行二系の共通零点に第三系の原点と時刻零を結ぶ。第三系の時刻を省いた設定、正方向の速度、異なる参照系・軸・単位では `srk` の条件を満たさない。並進と平行軸の物理的な全軌道は検査用の外部解釈であり、一般的構成は未完である。

往復変換が恒等であるなら、零でない座標値を持つ記録を使って共通倍率が1であることを導ける。`srr` はその非零の記録の存在を明示し、`sro` がφ(v)φ(−v)=1を表す。原点だけでは倍率を決められない。検査では、倍率が5でも全成分零の入力は零へ戻り、積1の条件は成立しない例を確認した。

積が1でも、各係数が1とは限らない。φ(v)=5/2、φ(−v)=2/5では、入力(7,3,4,2)へ二回の式を適用すると元に戻る。一方、φ(v)=5/2、φ(−v)=2なら結果は(35,15,20,10)であり、共通倍率の式は満たすが恒等ではない。負の相反係数も代数上は受理する。時間方向や正の物理尺度についての条件は、代数的な往復条件と分けて扱う。

本文は空間の関係に時刻が現れないことから相対静止を述べ、続けて恒等変換であることを明らかとしている。相対静止を表す `srs` と座標値の恒等性 `srn` は分離した。原点が共通でも、軸尺度や時計率が違えば相対静止したまま数値は異なる。その推論と明白さは著者への帰属として記述し、校正の一致が証明済みとは扱わない。

未知性の `srp` にはu0092の段階を与えた。先行する正速度域の候補関数による未決定性を継承し、負速度全域の候補集合を自動で補わない。二回適用する速度±vでの関数値の有効性は、式側の条件として要求する。`zgm` は同じφ関数を今後決める意図への帰属であり、決定済みという主張ではない。
