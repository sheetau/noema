# 愛着の傾向と、その取得・持続

カント第三段落の部分草案は、「愛着を持つようになった」を、自分の状態への好ましい受容とその取得・持続で表していた。今回は、対象へ向かう感情の傾向を受容から分け、同じ取得と持続の構成へ接続する。

Adelungはlieb gewinnenを、人や物への愛情・傾きを獲得する語義として説明している。この箇所では、自分の未成熟な状態への愛着を獲得して保持する読みを採る。比較状況での応答として愛着を定義することや、その持続範囲までが辞書から決まるとはしない。[Adelung, Lieb](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_7_1_1390)

## 感情と傾向

一般の感情入力には、本人・対象・対象を捉える記述・状況を明示する。親しみを伴う肯定的感情を、合理的な賛同や道徳的な承認と分ける。記述が真実であることも、この感情関係だけからは導かない。これにより、悪いと判断している状態へ愛着が残る場合を矛盾なく書ける。

傾向の評価では、基準における本人の心理的基盤を保ち、対象を同じ記述のもとで意識する状況を比較する。背景の通常性で優先される非空の候補すべてに、その感情への応答を要求する。現在その感情を感じていることは必須にしない。比較範囲と優先関係は、感情が生じた結果から独立に与える。

| 定義 | 内容 |
| --- | --- |
| `r2ci` | 本人・対象・記述を固定した一般的な応答傾向 |
| `r2cj` | 本人自身の未成熟な状態への親しみを伴う感情の傾向 |
| `r2ck` | 現在の未成熟と、その状態への愛着の取得・現在までの持続 |

比較と通常性には既存の`rqt4`を、取得と持続には`raf`を使う。新しい基本入力は感情、比較状況、通常性の三つである。原文の「愛着を持つようになった」という句全体を一つの基本関係にはしない。ただし、感情の生理機構や心理的な比較範囲の妥当性まで、今回の形式化で説明し終えたわけではない。

## 取得と持続

愛着の取得には、同じ本人が実際の変化過程を受け、同じ履歴上で傾向が不成立から成立へ移ることを要求する。その後端から基準まで傾向が保持されなければ、今回の結果状態の読みは成立しない。瞬間ごとに感情を経験していること、履歴全体で初めての取得であること、将来も永続することは要求しない。

以前の傾向が不明な場合を、傾向がなかった証拠にできない。取得前端では、常に真の応答を与えた一般構成を使い、感情の有無から独立に比較範囲と通常性の有効性を検査する。空の範囲や不正な優先関係は取得の証拠として拒否し、比較範囲や感情の入力が未知なら検査を中止する。ただし、形式上は有効でも心理的に不適切な比較を選んだ場合の妥当性までは、自動判定しない。

## 検証と残る範囲

感情の二つの比較候補、通常性、現在の感情、好ましい受容を独立に変える32組合せを検査する。別人、別対象、別記述、別基準、空の候補、循環や反射的な優先関係も対照にする。取得の検査では、過去から既に愛着がある場合、途中や現在に失った場合、過程や本人が異なる場合を扱う。現在の未成熟も既存の能力定義を実行して検査する。
