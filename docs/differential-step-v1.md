# 同じτの無限小への移行と偏微分条件

u0054–u0057を原刊899頁冒頭と照合する。前の中点式からx′を無限小に選ぶと偏微分の関係が従い、さらに同じ式を整理するという二段階の提示である。

## 極限としての読み

ここでの無限小は、正の変位hを零へ近づける通常の実数の極限として読む。skcはある指定した正の半径の内側の全てのhについて、同じ候補τ、V、v、出発時刻tによる展開済み中点式sjgを要求する。固定された一回の試行距離zdtの成功だけでは、この近傍条件を満たさない。

微分点は(0,0,0,t)である。sjvはy,zを固定したx′,tの全微分可能性をε–δ条件で表し、sjwは二つの切片の差商極限を同じ二係数へ結ぶ。先行u0047の線形性の主張と整合する十分な正則性を明示する読みを採る。原文がこのε–δ条件を逐語的に述べたとはせず、座標対応のアフィン性だけから対象域外を含む関数の正則性を証明したとも扱わない。

ei2wはこの条件を現在のei2pへ結び、同じ候補zd4、V、v、出発出来事のK時刻、半径zd5、偏微分値zd6とzd7を渡す。旧skdとsjlは保存するが、新しい前提で使わない。τをK時刻へ交換せず、出発tを零にせず、任意の出発地点への一般化も先取りしない。

## 式と推論の提示

M0103の左辺は二逆数の和の半分とτのt偏微分の積、右辺はx′偏微分とt偏微分の1/(V-v)倍の和である。M0104では同じ二偏微分を使い、τx′+v/(V²-v²)τt=0と整理する。既存sjx/sjyとその内容skf/skgをそのまま再利用する。分母の符号、係数、偏微分の役割を交換しない。

この読みでの推論は、a=1/(V-v)、b=1/(V+v)として中点式のh=0での定数項を引き、hで割り、hを正側から零へ近づけるものである。全微分可能性により反射側の一次係数はτx′+aτt、帰着側は(a+b)τtとなる。半和を保つことで最初の式が得られる。既存の有理代数の検査はその整理を確認するが、この説明を全実数上の連鎖律の機械的証明とはしない。

Hieraus folgtは同じ前提から最初の式が従うという著者の提示zc、oderはその前提の下での同値な書換えzd3とする。u0054とu0055は前者、u0056とu0057は後者の主張を共有する。既存の全同期、全光路、現在の局所時刻との接続を保ち、具体的なτの解の発見を加えない。

引数と同一性、零座標、二偏微分の切片、正の半径の全称条件、数式の符号と係数、帰属と順序を検査する。有限例で全実数の極限や近傍を認定する実行は拒否する。構文・型・旧定義の保存、正確な有理切断による対照、旧多項式の証拠、原文の通読判断を区別する。新規原始語はない。
