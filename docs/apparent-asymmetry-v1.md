# 適用上の非対称性と見かけの留保

導入u0003[0,209)は、Maxwellの電気力学を当時通常の仕方で理解して動く物体へ適用すると、現象自体には属さないように見える非対称性が生じることは知られている、という文である。理論・その理解・適用上の説明・現象・見かけ・周知性を区別する。

eisaxは歴史的な理論への参照で、電荷・電流を源とする電気側と磁気側の場の関係および物質への作用を扱う理論体系として意味を示す。eisayはその理論を理解し適用するviewとの関係、既存eisahは論説の記述時点で通常とされる理解への帰属である。eieyはこの二つを結び、挿入部のgegenwärtigを現代の読者の時点へ移さない。

eisazはその同じ理解による、動く物体への理論の適用事例を二つの系・状況と比較範囲へ結ぶ。物体の運動は既存eiagの閉じた型に従う全物質点・全区間の履歴であり、名前だけで代用しない。許容される説明は、その理論の解釈から認める説明全体として既存eisafへ接続する。eiddがその説明の全てに、両事例の非空で共通分類のない説明機構の分類を要求する。

ここで非対称性は、どちらを動く側として扱うかで説明機構を区別することとして読む。eiexはそうした適用上の区別を持つ比較が存在することを述べる。原文の複数形から独立した実験を二件以上要求せず、理論の全適用が非対称であるとも加えない。後続は一例として提示されるため、この一般文の範囲を磁石と導体だけへ縮めない。

eisa2は同じ対象・準備・尺度の比較で、区別が観測可能な現象自体に現れることを意味する。説明の機構名や観測の未確認と区別し、eieuはその否定内容を構成する。eisa3は基準点で利用できる観察・説明上の情報に沿って、その同じ内容がどう見えるかを評価する候補の全範囲である。候補を内容が真になるものだけへ後から絞らない。

eievは候補が非空であることと、その全候補で同じeieuが成立することを要求する。これは現実の基準点でも区別がないという断言ではない。実際に差があってもなくても、同じ候補条件の下で見かけは成立し得る。逆に候補が空であることや判断材料が未知であることを、差がないように見えることの成功にはしない。eiewは同じ比較の説明上の区別とこの留保を結び、welcheの指す区別を取り替えない。

eiezは当時通常の理解という限定と、その適用上の非対称性・見かけを結ぶ。eie2はこの内容を述べる部分と、関係する知識共同体で既に知られた事柄として扱われるeisa4を結ぶ。周知性のラベルだけを残したり、留保を消した命題が知られているとしたりしない。知識としての提示と、処理系が物理的真理を検証したという主張も分ける。

eie3/eie4は主張の力と著者・論説への帰属を、既に後続から参照していたeir7へ接続する。eisa5で同じeieyを挿入補足として示し、後続の例示eir6との本文順序を保つ。Noemaの主張番号への追加順は原文の順序ではなく、原文順序はこの明示した談話関係で保持する。
