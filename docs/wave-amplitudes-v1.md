# 横波の振幅と二乗比（2026-10-14）

アインシュタイン1905の第7節へ、六つの成分の振幅を非負の大きさへ結ぶ定義を追加した。方向ベクトルnと電気側E、磁気側Hについて、単位方向、n・E=0、H=n×Eという条件を明示する。この条件と既存の成分変換から、電気側と磁気側の振幅が同じ倍率で変わることを有理数の代数として確認した。

## 原刊と電子テキストの相違

保存した電子テキストのM0345は、振幅の二乗比の分母が√(1−(v/V)²)になっている。保存済み原刊PDFの912頁では、分母は1−(v/V)²であり、根号はない。したがって今回採用した式は次のとおりである。

$$
A'^2=A^2\frac{(1-(v/V)\cos\varphi)^2}{1-(v/V)^2}.
$$

電子テキストのスナップショットは変更せず、[照合記録](../data/wave-amplitudes-facsimile-v1.json)へ原刊PDFと抽出したページ画像のハッシュ、修正箇所、確認範囲を保存した。[検査記録](../reports/wave-amplitudes-v1.json)には元と照合後のMathMLを両方保持する。修正処理は外側の分数の分母にある一つの根号だけを外し、分子や指数を保持する。原文ハッシュが違う場合、確認済みでない場合、対象が一意でない場合は拒否する。

V=5、v=3、cosφ=0、A²=1なら、原刊の式はA′²=25/16、保存電子テキストの式は5/4となる。両者の違いを検査例に含めた。原刊の次の式M0347は、cosφ=1のとき

$$
A'^2=A^2\frac{1-v/V}{1+v/V}
$$

となり、この特殊例との代数的な対応も確認した。照合対象は二つの振幅式であり、912頁全体の意味を検証したことにはしない。

## 大きさ・向き・振幅を区別する

| 定義 | 内容 |
| --- | --- |
| `seaa`〜`sead` | 有理数の二乗ノルム、内積、二次の行列式、横波の振幅条件 |
| `seae` | 分母を払った(V²−v²)A′²=A²(V−av)²と、その適用条件 |
| `seag`〜`seaj` | 同じベクトル演算と横波条件を実数切断で表す |
| `seak` | 実数切断の二乗振幅比。方向余弦と速度の許容範囲を保持 |
| `seal` | 三成分の二乗和と、非負の振幅Aを結ぶ |
| `seam` | 同じ速度・方向・六成分の変換前後を、それぞれ共通の振幅A、A′へ結ぶ |

`seam`には二乗比の結論`seak`を前提として含めていない。電気側と磁気側の六成分とその変換から、大きさを求める条件である。二乗の等式だけでは振幅の符号を決められないため、`seal`はA≥0を要求する。零の波は許す。場の成分全体を負の係数で変えることと、大きさを負にすることは区別する。

横波の条件を外すと、同じ振幅比は一般には成立しない。例えば進行方向と同じ向きの電気成分だけを持つ入力は、その縦成分が変換で保たれるため、横波の比をそのまま適用できない。今回の定義はこの入力を横波条件で拒否する。

横波の条件は導出に必要な前提を明示するために追加した。原文で省略されている導出を、著者が明示的に断言した文として追加したものではない。正弦波の全域条件と真空の微分方程式から、これらの振幅条件を導く機械的な証明は残る。

## 検証

有理数の多項式検証器で、外積のノルムと直交性、変換後の電気側のノルムの恒等式、電気側と磁気側のノルム差の恒等式を確認した。これらに加え、横波条件とβ²(1−(v/V)²)=1の下で、両側の二乗ノルムがA²β²(1−av/V)²になることを確認した。全部で10件が妥当、電子テキストの値と縦方向の場を横波として扱う2件が反例付きで不成立となった。

実数切断の式については、構成済みの有理数切断へ正確な演算を与え、以下を検査した。

- 正・負・零の相対速度、五つの方向と偏り、零・負・正の場の尺度を組み合わせた45例。
- 振幅の符号と値、方向、磁気側の向きと大きさ、六つの変換後成分、光速境界と光速度の符号を変えた16例。
- 二乗比を直接検査する12例。原刊と電子テキストの違い、零の波、負の二乗値、範囲外の方向余弦などを含む。

61件の成分と大きさの検査は、累積草案と独立文書で同じ結果になった。切断の定義を展開した際は、有理数全域への量化を有限解釈器が拒否することも確認した。数値例の成功を、実数切断の全域的な演算法則の証明として扱わない。

関連する45テストが通った。三文書の全文・短縮記法と固有文字の往復、CLI解析結果の一致、SVGのXML妥当性を確認した。字形の目視検査は今回行っていない。
