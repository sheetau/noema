# 情報の拡大と、誤りの除去

カントu0013の知識の拡大と誤りの除去へ、同じ主体の二段階を比較する部分草案を追加した。文や項目の数ではなく、正しく支持された情報と、受け入れられている誤った内容の変化を記述する。世代間の拘束を述べるには、その拘束によって妨げられる活動の内容が必要になるため、まずこの二つの活動を分けた。

| 定義 | 内容 |
| --- | --- |
| `ri2` | 主体が受け入れ、根拠による支持があり、評価状況で真となる項目 |
| `ri3` | 固定した範囲の`ri2`の全内容を同時に満たす状況を表す内容 |
| `ri4` | 後段階の`ri3`を満たす比較状況が全て前段階の`ri3`も満たし、以前の正しい情報を失わない |
| `ri5` | `ri4`に加え、前段階では除外できなかった比較状況を後段階で少なくとも一つ除外できる |
| `ri6` | `ri4`を保ち、新しい誤りを加えず、以前の誤った内容を少なくとも一つ除く |
| `ri7` | `ri6`を満たし、指定範囲で受け入れられた誤りが一つも残らない |
| `hzc5` / `hzc6` / `hzc7` | 情報拡大・誤りの減少・範囲内の全除去を、評価状況についての内容にする |

ある段階で正しく支持された内容がPだけで、後段階にはPと独立したQも正しく支持されるなら、Pだけでは区別できなかった状況の一部を後段階で除外できる。これを比較範囲内の厳密な情報増加として記述する。誤った項目や支持のない項目を追加しただけでは、この条件を満たさない。

同じ真偽内容を持つ別名項目への置換や、比較範囲の全状況で真となる項目の追加も、情報増加とは数えない。既存の受容項目に新しく支持が得られ、それによって正しい情報が増える場合は、文面を追加しなくても拡大を記述できる。

誤りの比較では、支持の有無にかかわらず、主体が受け入れていて評価状況で偽となる項目を取り出す。誤った内容を別名の項目へ移しただけなら除去とは扱わない。同値は明示した比較状況全体での真偽によって判定する。誤りを一つ減らしても別の誤りが残る場合と、選択範囲内の誤りが全てなくなる場合を分ける。

情報を全て捨てれば、受け入れられた誤りも消せる。しかし`ri6`と`ri7`には、以前の正しく支持された情報を失わない条件`ri4`も含めた。正しい情報まで捨てる操作を、そのまま改善と認定しない。後段階で以前の内容をより強い内容から満たせる場合は、元と同じ項目名を残す必要はない。

主体、命題範囲、各命題の内容、比較状況の範囲、真偽の評価状況は二段階の間で固定する。他の主体が知ったことを当人の拡大へ流用しない。評価状況を二段階で切り替え、世界が変わったために真偽が変化したことを認識の改善として数えることもしない。比較範囲には評価状況自身を含める。

この構成は知識一般の完成した定義ではない。支持の信頼性、理解、偶然の正しさの排除、証拠を得る過程は別に説明する必要がある。`ri5`の意味内容による情報増加だけでは、数学の恒真命題の新しい証明を理解することや、同じ内容を別の仕方で認識することを測れない。従来の記述への認識と、命題内容の一致の区別は維持する。

また、情報の増加と同値の判定は比較範囲に相対的である。有限モデルの一致を全ての可能状況での論理的同値とはしない。比較状況が評価状況だけなら、正しい二つの内容を区別する情報増加を検出できない。範囲外に誤りが残っていても、範囲内の全除去は成立し得る。この結果を知識全体の完成や無誤謬性へ広げない。

検査では、以前の正しい情報の保持、新しい項目の受容と支持、前後の誤りの5条件による32通りを、一般文書と原文側でそれぞれ確認した。別名・恒真項目・支持の獲得と喪失・部分除去・別の誤りへの置換・別主体・空の範囲・評価状況の欠落など18対照例も調べた。PをPかつQへ置き換える場合には情報の保持と増加を認め、逆の置換ではQの情報の損失を検出する。

三つの内容は閉じたNoema式として引用できる。受容や支持、項目の真偽が未知でも、その拡大・修正を目標として述べられることを検査した。実際に達成済みか評価する際は、それらの未知の関係を空集合や偽として補わない。今回の引用検査は一般の目標関係へ渡す検査であり、カントの世代間の妨害や契約へ接続し終えたものではない。

[一般文書](../examples/v014/epistemic-revision.noema)は1,854文字、[原文付き草案](../examples/v014/kant-epistemic-revision.noema)は127,907文字、[抽出文書](../examples/v014/epistemic-revision-core.noema)は2,283文字である。9定義を追加し、親の宣言と15件の主張を保持した。新しい原始記号・著者主張は追加していない。[意味規約](../data/kant-epistemic-revision-basis-v1.json)と[検査記録](../reports/epistemic-revision-v1.json)に原文の二箇所との対応を保存した。
