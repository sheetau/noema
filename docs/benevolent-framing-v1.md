# 好意的な評価と、それへの批判的な距離

[カント本文の新しい固定版](../examples/v016/kant-benevolent-framing.noema)には、同じ引受け行為を親切なものとして描写しながら、その評価から批判的に距離を置く提示を追加した。gütigstをこのように読む場合、現実に親切だったと断言することも、評価を機械的に否定へ反転することも、その読みを十分には表さない。

[Gütigの項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_2_3_3566)は、他者の善を図ろうとする態度と、その態度に基づく振る舞いを記述する。[Güteの項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_2_3_3555)には礼儀的な用法もある。取得本文とハッシュは[出典記録](../data/benevolent-framing-evidence-v1.json)へ固定した。これらの項目だけで、当該箇所の皮肉や著者の内心が証明されるわけではない。ここでは、後続する人々を依存させる働きかけの叙述との対照から、批判的な距離を示す読みを採る。

評価内容は、他者の利益が実現する内容hzxp、その目標をそれ自体求めて進んで取り組む意向・準備hzxq、同じ行為の目的hztlに分ける。rqynは同じ行為への参加・生起とこれらの条件を結ぶ。実際に利益が生じることは要求せず、善意の行動が失敗した場合も表せる。一方、他者の利益を単なる手段として狙うだけでは、目標をそれ自体好ましく求める条件を満たさない。他の動機が併存しないことまでは要求しない。

程度の関係hzxrは、指定した性質を同じ対象と文脈で高いものとして扱う。gütigstの程度を強める読みとして使い、数値尺度や他の全ての行為を上回る最大性を補わない。基礎の性質の成立は別に要求する。rqypは同じ監督の引受けに、同じ行為者から同じ受益対象へ向くrqynと、その高い程度を結ぶ。

評価対象となる引受けは、本文の量化範囲から切り離さない。前版diにあった主体・対象・行為・先行状況の条件をrqylへ抽出し、元の位置から呼び出す。rqylを展開したdiの構文木が前版と完全に一致することを検査する。評価記述rqypも同じ四引数でrqylを要求するため、別の行為の親切さや、人物の性格全体の評価へ置き換えない。

提示の関係hzxsと批判的な距離の関係hzxtは、同じ箇所・提示者・主張記述・出来事記述・評価記述・文脈を持つ。rqyqはそれらを同じ基礎内容の主張帰属へ結ぶ。同じ箇所が複数の主張を含む場合も、別の主張から評価を流用しない。二記述の対応する四位置は、主張内の同じ出来事の参与者と時点を指すという意味規約を持つ。引用された内容を評価せず、真・偽・未知のいずれでも、提示態度の記述と区別する。批判的な距離を示しただけで、後見人の悪意や、評価の正反対が事実だとはしない。また、実際の先行発話の反復、聞き手の理解、笑いや感情の全効果は補わない。

本文にはrqyrの提示記述を一文追加する。既存44文の構文と意味を保ち、diの抽出は展開による一致を確認する。七定義と五つの基本関係を追加し、確認済み十一単位と先行四文の意味依存関係を保持する。基礎関係が人の利益・意向・程度・態度を解釈するための規約である点は残り、皮肉の全類型や親切さの全語義の完成とはしない。

検査は、行動条件と受益の真偽・未知を変える48組合せ、主張・好意的提示・批判的距離の八組合せと結合七対照、同じ箇所の複数主張の区別、同じ引受けの15対照、引数列の五対照、本文提示の九対照を扱う。通常評価との三照合、未知入力、定義展開の一致、三記法の往復も検査する。意味の基本関係を与えた有限モデルの検査であり、原文との意味一致や現実の態度の自動認定ではない。
