# 第一近似の帰結と二つの速さ

原刊905頁で、直前の三運動式から平行四辺形則への帰結を述べ、その後に「Wir setzen:」としてUとwの二乗式を導入する部分を扱う。必要な関係は、同じ理論への帰属、同じ先行内容からの帰結、Uの実際の時間微分、wの二定速度成分、二つの非負の速さ、表記と定義導入の対応である。後続のundと角度の定義も同じ導入に属するため、u0135全体の判断はまだ行わない。

「我々の理論」は、先行の構成課題eigjの到達先として同じ論説が指す体系と読む。その体系に属する主張項目を、既に構成した第一近似の内容ejocへ結ぶ。体系への所属eiscrは既存の関係を使い、項目と閉じた内容の対応を一般関係eisoxで明示する。前提として用いる関係eiscqを、帰結の内容対応へ無条件に流用しない。著者が直前のK三式からこの位置付けを帰結として提示することと、処理系が引用内容を真として実行することは別である。

Uとwは非負の速さとして読む。U²=(dx/dt)²+(dy/dt)²では、同じ点のKにおける現在の全座標履歴からx(t),y(t)を取り、同じK時刻での実微分を要求する。kにおけるw²=wξ²+wη²は、既出の同じ点の二定速度成分から構成する。二乗和は旧szn、二微分とノルムの接続は旧szqを再利用し、旧版の部分的な履歴設定は使わない。

先行の運動は平面内で等速なので、速さを全対象期間で同じ値とする。微分には同じ系の正の対象期間を定義域として渡す。端点ではその閉区間に対する片側の読みを許し、全実時間にわたる測定や区間外の実在を補わない。零の速さ、負の速度成分、負の合成分母を保ち、点の速度に上限を加えない。零速度に角度を割り当てることは、この二乗式から導かない。

有限検査では、符号と零を含むノルム、同じ二座標関数・微分時刻・導関数、全期間の量化、物体・系・単位・状況、U/wの表記役割、二式の定義提示を区別する。関数は数値的な振る舞いを比較し、同じPythonオブジェクトかどうかで同一視しない。全実数の微分と量化は有限評価を拒否し、一般定理の証明や原文の意味判断を検査成功で代用しない。
