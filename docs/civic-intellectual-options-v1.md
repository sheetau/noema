# 市民的許可と精神的活動の機会

第三文の比較に用いる二種類の自由を、同じ共同体の成員と固定した活動範囲へ結ぶ。市民的自由は公的な法秩序からの積極的許可、精神の自由は自分の理解力と支持理由による判断課題の達成機会として構成した。どちらも、その行為が現に実行されたことは要求しない。

市民的自由では、同じ本人・市民の立場・行為・閉じた実行記述を、指定した法秩序の規範的な出所へ渡す。既存の許可定義を使い、実行への積極的許可と不実行の要求の不在を確かめる。比較時には、両側の法秩序が同じ共同体の公的な制度として対応する点で運用されることも要求する。

精神的活動の目標は、課題名だけで与えない。課題の全事項を非空の範囲として固定し、それぞれについて同じ人が自分の理解力を使い、支持理由に基づき、他人の指導によらずに判断する内容を組み立てる。課題への帰属も確認するため、別課題の成功は流用できない。この目標に達する方法があることを、指定された制度条件での実効的な機会とする。

民衆の精神は、ここでは成員に分布する判断の営みとして読む。人と別に存在する一つの心は導入しない。比較は人と課題の組を保持するので、別人に機会が移っただけではその人の自由の増加にならない。芸術的想像や感情を含む精神の全側面を、この課題モデルだけで定義し終えたという主張でもない。

程度の大小には、既存の選択肢の厳密包含を用いる。低い側の全選択肢を高い側でも保持し、高い側だけの選択肢があることを要求する。数値一単位の差や、比較制度間の時間順序は追加しない。精神的機会の比較では全対象の評価を両側で確かめ、未評価を「できない」と数えて見かけの増加を作らない。

検査では、市民的許可の四組の真理条件、二人・二行為の許可集合の全256組、全事項への実際の理由ある判断、機会・評価済み・不能の区別、二課題の全16組の機会比較、方法評価への引数接続を扱う。市民的な法秩序の接続検査だけは既存の分類定義を境界とし、不変の本体と以前の検査報告を固定する。

この依存群は第三文全体の意味判断ではない。見かけの利益、因果的な障壁、低い側での全能力に応じた展開、対照・照応と著者帰属は、同じ比較条件へ続けて接続する。確認済みの本文と意味確認文字数は保持する。
