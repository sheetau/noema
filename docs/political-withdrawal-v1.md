# 第五文の結果条件：専制と圧迫からの離脱

第四段落第五文は、革命による政治的な離脱の可能性と、思考様式の真の改革の不可能性を対比し、その後に新しい偏見の働きを述べる。この一文全体を構成するため、今回は固定本文 `[950,1040)` の離脱結果を、先行する支配・圧迫と同じ当事者の関係へ結んだ。第五文全体の完成判断は行わない。

## 支配と動機を区別する

個人的専制 `r2qa` は、人である担い手の事実上の決定統制と、個人の裁量への独立した抑制の欠如を合わせる。肩書や通常の監督役だけでは専制としない。特定の憲法・君主・革命事件を補わない。[Despotismusの語義](https://www.duden.de/rechtschreibung/Despotismus)は無制限の支配という読みの補助とする。

圧迫 `r2qb` は優越的な圧力による選択・生活・資源利用の制約と、同じ行為の生起による同じ対象者への不利益の因果を結ぶ。後者には既存 `rqqu` の、行為の生起 `r2pb` と本人の不利益 `r2od` を固定した形を使う。二内容の評価を `dg` と `ur` へ展開し、同じ因果 `hzie` を保つことで、結果を引用する際の不要な階層の増加を避ける。Bedrükkungを、ここでは気分の重さではなく社会的な圧迫として読む。

過度な欲求がその行為の目的になることは `r2px` で構成する。同じ人・引用目標・引数を、既存の内在的な欲求 `hzxq`、過度な追求の評価 `h226m`、行為目的 `hztl` へ渡す。物質的利益への目標 `r2py` と、同じ仕組みへの決定統制の目標 `r2pz` を分け、`r2qc` でその選言を同じ圧迫へ接続する。どちらか一方でもよく、併存も許す。

[gewinnsüchtig](https://www.duden.de/rechtschreibung/gewinnsuechtig)と[herrschsüchtig](https://www.duden.de/rechtschreibung/herrschsuechtig)は、単なる利益や支配の希望より強い評価を含む読みとして扱う。欲求の成立だけで圧迫行為との関係を補わず、実際に利益を得たことや支配拡大が成功したことも要求しない。欲求・過度さ・行為目的が別々の目標を指す場合は不成立になる。

## 同じ二つの関係から離れる

[Abfall](https://www.duden.de/rechtschreibung/Abfall)の政治的な関係から離反する語義を採り、当事者が服属を拒んで結び付きを断つ過程として読む。`r2qd` は特定の仕組みへの継続的な服属であり、支配者の交代、動機の変化、一つの行為の終わりだけでは消えない。

`r2qe` は、同じ対象者・過程・履歴・前後点について、先行する個人的専制と、利得欲または支配欲を持つ圧迫を要求する。既存 `rcf` を二つの服属関係に適用し、前には成立し後には成立しないこと、本人の参加、同じ本人への作用、関係の終結への関与を要求する。専制と圧迫の仕組み、専制者と圧迫者は、それぞれ同じでも別でもよい。

この読みでは、本人が服したまま支配の様式だけが穏当になることを離反とはしない。無関係な支配関係の消失や、外部者だけによる変更とも分ける。永久的な自由や、他の全ての支配の不在は追加しない。

## 検査と残る接続

検査は動機の二枝、同じ目的への結合、実際の圧迫・不利益・因果を実行する。離脱は二つの同じ服属関係について、前後、本人の参加、作用、終結関与を実行する。動機の消失だけ、片側だけの離脱、別対象への過程、逆順・欠落した時点では成立しない。

結果条件は、既存 `rqc` の「同じ候補における活動・因果・結果」の枠へ閉じた段階0の記述として渡せることも検査する。この検査の活動種類は仮の入力であり、革命の意味を定義したことにはしない。引用された帰属から世界の状態を実行しない検査も分ける。

今回追加したのは支配・圧迫・過度な欲求・服属とその終結に関する基本関係と合成定義である。一文の真偽を返す基本語は追加していない。既存61文・全単位13区間・第四段落先頭四文771非空白文字を保持する。

次は革命の活動種類、同じ公衆の対象範囲、思考様式の真の改革を構成し、`hzhk/rqe` の二つの結果へ接続する。その後に様相・対比・新旧の偏見・誘導の比喩・著者帰属を統合し、第五文と段落全体を通読する。
