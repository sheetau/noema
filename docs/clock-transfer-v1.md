# 初期同期と時計の移送

アインシュタイン§4の `u0126` に、AからBへの時計の移送と到着時の比較を部分記述として接続した。初期の二時計の同期、直線等速運動、二つの指示法則、到着時の指示差を別々に構成する。本文の帰結への評価語、加速中の時計の挙動、原刊照合と意味一致の確認は残る。

二時計が離れている初期状態では、Aでの出発と、それと同時刻にBで静止時計を読む出来事を区別する。到着時には、両時計を同じBの同じ出来事で比較する。出発時と到着時を同一の出来事にしたり、移動時計を静止時計の別名にしたりしない。

`swl` は指示・単位・時計・出来事・座標記録と場所を結ぶ。`swm` は三出来事と二場所、初期静止と同期、静止時計のBへの残留、初期二出来事の同時性と指示一致を要求する。初期の設定と移送中の設定を分け、出発記録と初期指示は両方で同じものを使う。

`swo` は端点の距離と速さ・所要時間を結ぶ。方向はX軸に固定しない。`swp` は途中の記録に各空間成分の時間に対する線形補間を要求する。端点の距離が合っても、迂回や途中だけ進み方が異なる記録はこの条件を満たさない。

`swx` は同じ時計の測定済み出来事を検査する部分条件である。測定されていない中間時刻を存在すると補わない。全区間の等速直線運動 `swq` は、区間内の全実時刻に時計の出来事と対応記録が存在することも要求する。この全称条件を有限の標本だけで認定しようとすると、評価器は拒否する。

指示法則 `swr` では、正の所要時間Tと進み率fについて次を前提にする。

```text
初期指示: 移動時計A₀ = 静止時計B₀
移動時計の指示差: A₁ − A₀ = f*T
静止時計の指示差: B₁ − B₀ = T

到着時の差: B₁ − A₁ = (1−f)*T
f = √(1−(v/V)²), 0<v<V
```

この区間法則には、発進・停止・設定変更による追加の指示変化がない理想化が含まれる。前段の慣性運動の時計だけから加速時の法則まで導いたことにはしない。著者の設定 `sws`、追加解釈としての指示法則 `swt`、両方を前提にした帰結を、異なる帰属の主張として保存した。

初期指示が等しくなければ、到着差には初期のずれ `B₀−A₀` も加わる。一方、四つの指示すべてに共通の原点変更を加えても差は変わらない。座標時刻そのものではなく経過時間を使うので、出発時刻が負でも同じ比較ができる。

`swk` は所要時間と到着差を同じ尺度で秒へ換算し、二次近似と残差を分ける。V=5、v=3、所要時間10秒の場合、移動時計が8秒、静止時計が10秒進む。到着差は2秒、二次近似は9/5秒、残差は1/5秒となる。初期指示は両方7でもよく、この場合の到着指示は15と17である。

`swy` は正の所要時間を固定したときの、速度比u=v/Vについての四次残差条件を表す。距離を固定して速度を変える場合は所要時間Tも変わるため、無条件にO(u⁴)とはせず、誤差の尺度をT*u⁴として保持する。`sxa` と `swz` の具体的な上下限は数学的な補足であり、原文の記載そのものとして帰属させない。全実切断での漸近条件の機械的証明は未完である。
