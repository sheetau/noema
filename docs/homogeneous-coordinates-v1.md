# 一様な増分、アフィン形、著者の推論

アインシュタイン§3の `u0047` を部分記述した。空間と時間へ一様性を帰属させること、そのため方程式は線形でなければならないと述べること、その結論を明らかであると提示することを分けて保存する。

一様性には「同じ変位に対する変換後の増分が、出発点に依存しない」という操作的な解釈を与えた。二つの出発点をpとq、変位をh、変換をFとすれば、対象範囲内で次の条件を要求する。

```text
F(p + h) − F(p) = F(q + h) − F(q)
```

`shr` は一組のp・q・hについてこの条件を検査し、入力・出力・増分の値の妥当性も要求する。`shs` は非空の対象範囲の全出発点対と、移動後も範囲内にとどまる全有効な変位に同じ条件を課す。ある一組で一致しただけでは `shs` の証明にはならない。物理法則の一様性一般をこの条件だけで説明し終えたとも扱わない。

線形性の部分解釈には、原点のずれを残せるアフィン形 `F(p) = A p + b` を使う。`shq` は各出力成分に、同じ行列Aと成分別の定数項bを適用する。`sht` は全対象入力を一つのAとbで表せる条件であり、入力ごとに係数を選び直せない。原点を保つ線形写像ではbが零になるが、ここではそれを仮定しない。

数値の四成分は固定した長さ単位と時間単位に従う。時間と長さを物理量のまま足す操作ではなく、各係数をその単位表記に対する数値として扱う。成分の列は空でなく重複もない。係数の符号は正負の両方を許し、符号付き実切断の積を既存の非負積と符号反転から構成した。

変換候補は前段の同じ二系・単位・運動設定へ結ぶ。`sib` は、その出力が測定済みの同じ出来事の座標対応と過不足なく一致し、全入力に対応先が存在して値が一意になることを要求する。行列形なら何でも座標変換として認めるわけではない。

ベクトルを関数で表す際には、四役割以外の引数にも値がある。この値を隠れた入力にしないよう、`sie` は四役割以外を零に固定する。変換の前後でこの表現規約を適用するため、選択外の値を変えても四座標の結果は変わらない。余分な物理座標を追加したという意味ではない。

原文の推論は、`sic` の一様性から `sid` のアフィン形が必要になるという著者への帰属として記述する。著者が結論を「明らか」と提示する関係と、前段の方程式を求める課題にこの条件を課す関係も加えた。引用内容は実行せず、検査器がこの推論を証明したとは断定しない。

新規10件を含む関連31テストが通過した。行列の計算10例、局所的な増分8例、係数の符号と零9例、四役割と系・単位の接続8例、前段の座標対応との接続6例、帰属8例を検査した。二次式でも変位が零だったり出発点が同じだったりすれば局所的な増分は一致するため、それらの例から全域の一様性を認定しない。

有理数の一行のアフィン式については、増分の出発点独立性、増分への定数項の不関与、原点の像が定数項になることを代数的に検証した。「アフィン式は必ず原点を保つ」と「二次式の増分は出発点に依存しない」には有理数の反例を得た。これらは全有理数変数についての多項式の検査であり、有限標本の一致とは分けて記録する。

検証した向きはアフィン形から増分の性質への帰結である。一様性から実数全域の行列表示を導く逆向きの一般定理、連続性などの条件、対象範囲の形と完全性は未検証である。実切断の一般的な体の法則、物理的な一様性との同義性、具体的な変換の導出と原刊照合も残る。

標準表記・圧縮表記・固有文字の往復、CLIのJSONと構文木の一致、SVGのXMLとしての妥当性、検証記録の再現と進捗集計の整合性を確認した。SVGの目視確認と全テストの再実行は含めていない。
