# 断面積のタグ付き和と任意の有限分割の誤差

球と楕円体の体積を表す断面多項式について、積分値の候補との差を、分割の細かさに比例する上限で抑える記述を追加した。有理数の計算では、分割の長さを固定せず、空の接頭列と一つの区間を追加する手順から誤差評価を導く。

## 一区間から全分割への評価

前版の断面多項式と原始関数候補を

\[
 f(x)=p(R^2-D^2x^2),\qquad
 F(x)=p(R^2x-D^2x^3/3)
\]

とする。p≥0、B>0、区間全体が[−B,B]内にあることを要求する。K=2pD²Bと置くと、幅hの一区間について、区間内のどの代表点tを選んでも

\[
 |h f(t)-(F(r)-F(l))|\le K h^2
\]

となる。`seeh`はこの符号付き誤差、`seej`は区間・代表点・係数・細かさの条件である。幅がδ未満なら、この誤差はKδh以下でもある。

`seei`は、下端aから現在の端xまで処理したときの不変条件

\[
 |S-(F(x)-F(a))|\le K\delta(x-a)
\]

を表す。最初はx=a、S=0なので成立する。一つの区間を追加すると、二つの誤差とその上限をそれぞれ加算でき、端点差もつながる。すべての区間を処理した時点では、既存の分割条件`mb`によりxが指定した上端bと一致する。したがって、任意の有限長の妥当な分割について

\[
 |S-(F(b)-F(a))|\le K\delta(b-a)
\]

を得る。

検査器は、実際に使う`md`のfoldと`ma`・`mb`・`mc`の分割条件が保存された定義のままであること、`seek`が対象の断面多項式をそのfoldへ渡すこと、`seel`が必要な前提をすべて含むことを確認する。そのうえで、開始・延長・前提の接続・結論の取り出しを含む11のスカラー義務を、Noemaの定義を展開した多項式として検証する。

任意の有限長への移行には、言語の有限列とfoldの意味に対する構造的帰納規則を使う。これはこの定義形に対する専用の検査であり、任意の高階プログラムを証明する汎用の帰納証明器ではない。必要な条件を偽にして延長条件を空虚に通したり、不変条件を常に真へ置き換えたりしても、前提・結論の接続検査で拒否する。foldの初期値の変更も拒否する。

## 正の細かさの構成

誤差の目標ε>0と区間長L=b−a>0に対して、`sedw`は実切断で

\[
 \delta=\frac{\varepsilon}{2(K+1)L}
\]

を構成する。K=0でも分母が正になる。`sedx`はこのδをすべての妥当な実分割に対する誤差条件`sedv`へ渡し、KδL<εを要求する。`sedu`は一つの指定分割に対する条件である。

正のδを選ぶことと、それより細かい分割の存在、全実切断の演算法則、積分の存在・一意性を証明することは区別する。今回の帰納的な検査は有理数の任意の有限分割を対象とし、実切断全域での積分関係の同値性を完成済みとはしない。原文の体積比を支える誤差の議論を進めたもので、一般の三次元測度や光エネルギーの物理的説明は残る。

## 具体例と対照検査

分割数・代表点・係数・Dを変えた72例を、有理数のNoema文書として評価した。零係数・零Dも含む。空列、隙間、重なり、逆順、範囲外の代表点、端点の不足、細かさの境界、無効な係数など9例は、分割の採用条件を満たさない。

登録した有理数切断の18例では、実数側の`sedd`による和と断面多項式を実際に評価した。分割の妥当性・接続・細かさは、同じ登録値による厳密な比較を用いる。4つの不正な分割も拒否した。これらの例は帰納的な検査を補うもので、分割数の有限標本を全称量化へ置き換えるものではない。

細かさの構成と全域条件への引数の接続は24例で検査した。この検査では実数側の全分割条件を明示的な仮定へ置き換えており、その成立自体を検査したものではない。全分割への量化を残した実行は「非有界な列の領域を有限評価できない」として停止する。
