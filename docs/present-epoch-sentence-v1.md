## 仮定的な問いと提示

`Wenn ... gefragt wird ... so ist die Antwort` は、同じ問いが提出される場合の回答を著者が示すと読む。新しい提示関係 `h26kz` は同じ問い・回答発話・回答内容を受け取る。実際に質問又は口頭の返答があったとはせず、問いの肯定命題を前件とする物質含意にも変えない。
