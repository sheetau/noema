# 集団内の参加を伴う能力変化

カント第四段落の「公衆が自ら啓蒙する」という記述へ進むため、集団内の一人が参加する活動によって、別の構成員が依存状態から自立的な能力を持つ状態へ変わる部分構成を追加した。一人の変化を集団全体の啓蒙と同一視せず、公開性や言説の伝播は残る課題として明示する。

## 同じ活動を通じた変化

一般定義 `rda` は、同じ集団に属する異なる当事者と対象者を取る。順序のある同じ履歴で、対象者の前後の状態が評価済みであり、前状態から目標状態へ変わることを要求する。変化過程は同じ対象者に作用し、その過程を構成する活動部分に当事者が参加する。結果を生じさせる活動も、その同じ部分でなければならない。

二人が同じ集団にいること、無関係な活動が同時に起きること、別の人に結果が生じることだけでは成立しない。一般形では結果の記述と目標状態を一致させる接続規約が必要であり、原文接続では同じ定義 `h4l` とその引用を使って固定している。

部分活動は過程全体であってもよい。生起・参加・結果を完了側の状況へ記録する粗い時間粒度を採用しており、全てが同じ瞬間に起きるとは主張しない。途中の活動期間や機構は別途必要である。また、活動への参加と、その活動による結果生成を結ぶものであり、当事者一人だけで結果の十分な原因になることは保証しない。

## 援助と依存の区別

原文接続 `h6b` は、既存の構成員列 `mp` を使い、列が重複のない人の集合であることを検査する。対象者の同じ基準文脈の履歴で、前後の能力評価 `fo`、依存状態 `bf`、自立的能力 `h4l` を結ぶ。活動部分の関係には新しい基本関係 `h6a` を使う。

能力を得るまでに他者から援助を受けることと、得た能力の使用に他者の指導を必要とすることは異なる。内部の当事者に加えて外部者が援助しても成立し得るが、結果側で自立的な使用の条件を満たさなければ成立しない。全構成員が能力を得ることや、共同意図、外部者の援助の不在は要求しない。

`h6c` は同じ集団・過程・前後・基準文脈を固定して、内部の当事者・対象者・活動部分の存在を表す。`h6d` は基準時までにそのような変化があるという内容を作る。原文は比較的可能であることを述べるため、現実に `h6d` が成立するという主張は追加していない。

## 検証と残る範囲

- 前後の評価・前状態・目標状態の64組を調べ、評価済みの適切な変化だけが成立することを確認する。
- 所属・変化・作用・生起・構成関係・参加・結果生成の512組を調べ、必要な関係を欠く場合を除外する。
- 人物、過程、部分、前後の時点、結果の記述、履歴に関する24例を検査する。全体を部分として使う場合も扱う。
- 原文接続の20例で、外部援助、結果側での指導、無関係な活動、集団外の人物、一人だけの集団、未評価の能力、未来の結果、非人間や重複した構成員を区別する。明示した役割の `h6b` と、役割の存在を量化する `h6c` の両方を実行する。

`h6d` の全過程・全時点への量化は、この原文接続の有限評価では実行していない。型検査と記法・固有文字の往復は確認する。有限のモデルでの検査は、任意の世界での一般的な証明や原文との同義性の確認を代替しない。

固定した構成員列を持つことだけでは「公衆」にならない。公開の言説、理性的な自己評価の伝播、構成員の加入・離脱、集団全体の変化の程度、比較的可能であること、自由の条件とほぼ避けられないことは未記述である。能力・因果・活動部分などの基本関係の説明と、原文との意味一致の確認も残る。

一般文書は基本関係0・定義3、原文接続文書は基本関係226・定義376・主張15である。親文書の全定義と全主張を保持している。累積正規形は1,197文字増えて57,695文字である。原文対応は `sich selbst aufkläre` の部分構成として記録し、完成済み区間には数えない。
