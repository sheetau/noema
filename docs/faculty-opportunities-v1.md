# 全能力についての発展機会

カント第17区間の「市民的自由が少ない側では、精神がその能力を広げる余地を得る」という節へ部分草案を追加した。各能力の発展目標への方法があることを表し、現在すでに発展したことや、全能力を一つの方法で伸ばせることは要求しない。

## 同じ能力の前後を比較する

[一般定義](../examples/v016/faculty-opportunities.noema)の `rwy` は、同じ人と、その能力に属する活動の範囲を固定する。開始状況が結果状況より先であり、前後の全対象活動の能力評価が成立し、以前の達成可能性を失わず、新たに達成できる活動があることを要求する。

評価には既存の `xf`、達成可能性には `xd` を使う。開始時点で方法の評価が欠けている活動を「できなかった」と補い、後で方法が見つかっただけで新しい能力の獲得とすることは避ける。一方、有効な達成方法が確認できていれば、別の方法が未評価でもその活動の能力評価は成立し得る。

能力の発展を活動の真包含拡大として読む候補であり、知識の深さ、技能の質、能力の強度の全てを記述したものではない。活動を入れ替えて件数だけ増やす場合や、以前できた活動を失う場合は、この条件の発展には数えない。

## 各能力への方法と、一つの共通方法

一般定義は、量化の順序を分ける。

| 定義 | 方法の条件 |
| --- | --- |
| `rwz` | 能力範囲が非空で、各能力の目標について達成方法がある。方法は能力ごとに違ってよい。 |
| `rw2` | 能力範囲が非空で、全能力の目標を同じ評価結果で達成する一つの方法がある。 |

例えば、能力Aを発展させる方法と能力Bを発展させる別の方法があり、両方を達成する共通方法がない場合、`rwz` は真、`rw2` は偽になる。本文には `rwz` を用いる。`rw2` も、各行為が同じ時刻に起きることまでは要求しない。

目標は結果状況についての内容であり、方法があることを述べる時点では、その結果が現在生じたとは主張しない。全能力を実際に伸ばしたことや、本人がその方法を選んだことも別である。

## 同じ低い側の制度へ接続する

[本文草案](../examples/v016/kant-faculty-opportunities.noema)の `iaedevelopment` は、基準視点で固定した本人・能力の活動範囲について、開始状況から `rwy` を満たす目標を作る。`iaeopportunities` は、前段の対象者が非空で、各人の全選択能力にこの目標への方法があることを要求する。選んだ活動も前段の精神的活動範囲に入らなければならない。

`iaeroom` は、現在の低い側と、前段の要因を外した非空の全解で `iaeopportunities` が成立することを要求する。既存の `iadaligned` により、許可集合と制度の比較も維持する。一つの結果では機会があっても、別の結果で機会がなければ、この全解についての条件は成立しない。

原文の「一度合い少ない」を数値差や最小差には置き換えず、前段で比較した低い側を保持する。対象となる能力を結果に合わせて減らしたり、発展しやすい別人へ置き換えたりしない。民衆の精神を各人の能力機会へ分配する読みは強い候補であり、集団的精神の独自の意味や、能力・活動範囲の原文への適合はまだ確認が必要である。

`iaecontrast` が前段の見かけの利益・実際の障壁と合わせる。親の全宣言と先行20文を保持し、最後の候補内容の帰属を更新した。

## 検査と残る範囲

58テストが通過した。活動の前後16組合せ、前後の評価と時間順序の8組合せ、別々の方法と共通方法の8組合せを検査した。本文側では、能力や活動の欠落、別人への機会の流用、元の能力の喪失、未評価、時間の逆転、全解のうち一つだけでの失敗を区別した。

全対象活動の達成方法が確認できる人では、他の未評価の方法があっても発展機会が成立する。一方、別の人について未評価の活動が残れば、その人を含む全体の条件は成立しない。この違いも実際の `xf` と `xd` を用いて確認した。

本文全体の有限診断は、明示的な短絡評価とメモ化を使い、計算枠を1,000万段階に指定した。一般定義ではキャッシュを外しても結果が一致した。今回の本文統合全体についてはキャッシュなしの再実行を行っていない。三文書の長形式・短縮形式・固有文字の往復、CLI解析、抽出文書のSVGのXML検査も通過した。SVGの目視検査は行っていない。
