# 固定BGE-M3による共通概念照合の比較条件

既存の3係数方式では述語・状態と関連する物体の混同が残った。語別の例や補正を追加せず、固定するエンコーダーを交換した比較を行う。以下を新モデルの予測前に固定する。

- BAAI/bge-m3のリビジョン`5617a9f61b028005a4858fdac845db406aefb181`を使う。公開設定のCLSを文の表現とし、対象範囲は既存方式と同じトークン平均とする。CPU、float32、eager、8スレッド、seed 17、evalで全重みを固定する。入力は原文そのままで、指示文を付加しない。生成・疎な単語照合・追加の検索辞書は使わない。
- 原文、対象範囲だけ、概念定義を符号化する。Noemaの91概念と日英定義は既存のまま固定する。各言語の定義CLSを正規化して平均し再正規化する。原文の対象トークン平均、対象だけのCLS、原文CLSと定義とのコサインを共通3係数で足す。BGEの既存学習が対象範囲平均の語義照合を保証するとは仮定しない。
- 入力長は今回128トークンまでに固定し、切断された入力は黙って使わず拒否する。モデルの最大長8192と、今回検査する長さを区別する。
- `reports/shared-matcher-v1/selection.json`の学習3,072範囲と開発288範囲をそのまま使う。概念を留保する既存の区分を維持し、新しい語別訓練例は作らない。学習12候補、開発15候補、20 epochの既存条件で3係数だけを学習する。開発3概念の日英平均が最も高いepoch、同点なら最も早いepochを選ぶ。候補数による開発・確認条件の差は残る限界として報告する。
- 新しい双線形モデルの探索や係数調整は行わない。既存MiniLMの固定3係数と、BGEの未学習の3種類のコサインを比較対象にする。
- v1〜v3は観察済みの回帰資料。新しいv4は24既知概念と6未知概念の日英対で、今回の予測前に作成する。各種の言い換え・状態と動作・関連概念の区別を含むが、外部による独立評価ではない。ここでモデル・閾値を選び直さない。
- `joint-lexical-v2`の32文は観察済み回帰資料。保存した出来事・句範囲・全役割logitを固定し、概念スコアだけをBGEへ交換して同じ同時選択を再計算する。原文範囲は予測値であり、正解範囲で補正しない。旧方式の生出力とハッシュを検査し、概念選択の変更による差を測る。
- 小型ヘッドの学習を固定特徴から再実行して重みと履歴を比較する。固定モデルの反復一致と、CLS・トークン表現を直接forwardした結果との一致も検査する。生成等の禁止経路の呼出しを検査する。

未知概念にも既知候補が必ず出る構成なので、類似スコアを確信度とは扱わない。否定・時間・数量・節関係等の未接続は残し、全文の確定出力を行わない。広い翻訳の完成条件も、短文の文字数の課題も維持する。モデル重み、定義、選択資料、コード、特徴、出力、環境のハッシュを保存する。

参照：[公開モデルと指示文不要の説明](https://huggingface.co/BAAI/bge-m3)、[CLSの公開設定](https://huggingface.co/BAAI/bge-m3/blob/5617a9f61b028005a4858fdac845db406aefb181/1_Pooling/config.json)。検索用の学習をNoemaの意味区別へ転用できるかは今回の実験対象である。
