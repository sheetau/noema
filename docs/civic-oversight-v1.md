# 実施される改善と市民的秩序を結ぶ監督

カント第六段落第十一文の冒頭に向け、同じ君主が改善と市民的秩序の両立を確保する監督を構成します。固定原文`u0013[3226,3341)`に対応する依存群です。条件文全体とnurの限定、後半への接続はまだ完成していません。

接続に当たり、[前回の両立判定](civic-compatibility-v1.md)と監督の条件を分けました。全案がそれぞれ秩序と両立可能であることを、君主の監督の必要条件にすると強すぎます。秩序と相いれない案を実施させない場合も、秩序を保つ監督になり得るためです。旧定義と証拠を保持し、新しい目標では、真又は信じられた改善が実施される場合に、同じ点で秩序の全条件を満たすことを要求します。

実施は、同じ変更を導入する活動の生起と、その変更後の内容成立を結びます。全候補を量化してから実施の有無を判定し、未実施の案を範囲から消しません。改善判断の閉じた呼称の不備も、前件が偽であることにして隠しません。

監督は、同じ点での君主の役職、活動の生起、本人の参加、同じ目標への意図と注意、同じ活動による実効的な寄与、目標内容の成立を結びます。意図と注意だけの未成功な活動も別に表せます。寄与は成立の維持も含み、偶然の一致で代用しません。君主の単独原因性、すべてを本人が直接執行すること、全未来への無失敗保証は付け加えません。

引用する目標の内側では、段階0のNoema内容を評価します。そのため、目的と注意を段階1の閉じた内容族へ拡張し、共同体・秩序の二対象列と固定基準を、目的・注意・寄与・結果で共有します。引用関係の検証から実際の結果を導かず、結果は別に検査します。

検査では、未実施の不適合案について旧条件は偽でも新条件は真になり得る反例、追加の不適合な実施、別の活動・共同体・秩序・点への取り違え、未知入力、引用段階、引数列を確認します。君主的役職の内部と巨大な全候補評価は保存済みの個別証拠へ分け、境界を報告します。本文106主張と意味確認済み文字数は据え置きです。
