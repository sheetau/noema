# 名称から意味の記述、自己位置付けへの接続

カントu0015の名称への批判について、名称を指すだけだった箇所を、前段の「裁量によって自由を残す政策を実現する人」という説明候補へ接続した。説明の本体はNoemaの政策と規範の式であり、原語の綴りや自然言語の説明文を格納して代用しない。

| 定義 | 内容 |
| --- | --- |
| `rnp` | 一人の引数列を取る政策内容を、同じ一人についての性質へ変換する |
| `rnq` | 実際の名称適用と、その名称が保持する性質記述・引数記述・正確な適用例・実際の対象を結ぶ |
| `rnr` | `rnq`の同じ人が、その表現と適用例を同じ活動の言い方や定め方として採っている |
| `rns` | `rnr`の対象が話者本人である |
| `rnt` | `rns`の自己適用を、指定した立場を取る関係の構成候補にする |
| `hzf3` | 自由政策の裁量による実現を、人物の性質として構成する |
| `hzf4` | 自己適用を、既存の名称使用・意味型の保持・適用例の採用の関係へ接続する |

既存の`rbp`・`rbq`・`rbo`を再利用し、名称が保持する説明の型へ対象の記述を適用した式と、採用された式が構文上同じか確認する。さらに、対象の記述が指す個体と、実際にその名称で呼ばれた対象を照合する。式の形が正しくても別人を指していれば、この接続は成立しない。同じ人を指す別名の式も、自動的に同じ構文へ置き換えない。

自己適用には、話者と呼称対象の一致に加え、同じ行為で説明を採用したことを要求する。別人への命名、引用、他人の語の報告、表現が使われたという記録だけからは本人の自己位置付けを補わない。採用の関係も、その人の全ての信念や内容の真理を保証するものではない。

接続例では、`hzf3`で作った性質を名称の説明に使い、裁量上の立場へ結ぶ。その自己位置付けを前段の`hzf2`へ渡すと、同じ自由政策について裁量の資格がないのに裁量を持つ側として振る舞う、という評価候補になる。任意の名称や任意の性質が裁量を表すという規則ではない。意味記述と立場の組合せをそろえるのは接続例の条件であり、型だけでその内容の一致を保証しない。

名称がこの説明を保持することは、文脈付きの説明規約として既存の`hw2`で与える。これはNoemaの明示的な概念定義への接続であり、日英から語を探す翻訳辞書ではない。ただし、現実の社会で原語がその意味を持つことを検証し終えたわけではない。寛容一般を裁量的な許可だけで定義したとはせず、不賛同・抑制・非干渉や歴史的な用法は残す。

説明の型と適用例を確認するときには、説明された政策を実行評価しない。対象を同定するための個体記述だけを評価する。名前の使用や自己適用が分かっていても、政策の現実の許可が未知なら説明内容の真偽は評価できない。逆に、その性質が真であるだけでは、誰かが名称を使ったことにはならない。

`hzf3`は実際の政策成立を含むので、引用前に閉じた政策記述へ特殊化する。検査例では脱引用を一箇所解消し、通常のNoemaの引用として扱う。原始記号による寛容という真偽表や、名前の綴りの置換処理は追加していない。

[一般文書](../examples/v014/described-labels.noema)は6,682文字、[原文付き草案](../examples/v014/kant-described-labels.noema)は190,901文字、[抽出文書](../examples/v014/described-labels-core.noema)は8,126文字である。七定義を追加し、原始記号と著者主張は増やしていない。既存の構造照合用原始記号`rbo`を使用する。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-described-labels-basis-v1.json)と[検査記録](../reports/described-labels-v1.json)を保存する。

名称の使用・意味型の保持・使用と適用例の採用・裁量・政策成立の64通りを検査した。原文付き文書と抽出文書では、人物・名称・行為・文脈・型・適用例の取り違えを含む12条件ずつを検査した。追加16テストで他者への命名、対象と式の照合、引用と採用、未知の規範、閉じた説明の引用、異なる立場を確認した。三文書のCLI解析、固有文字v2の往復、SVGのXML検査も通過した。SVGの目視確認は含めない。

今回の追加は既存の対応範囲内で説明の接続を進めたもので、原文範囲の割合は増えない。現実の語用慣習との照合、著者が名称を評価する行為への帰属、前段からの論証、婉曲・反語、称賛と政府による解放、段落全体の意味確認は残る。
