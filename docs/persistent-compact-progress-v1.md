# 固定化の全期間と人類の改善

第八文の制度の固定化を、有界期間と終点のない期間の両方へ広げる。新しい期間範囲 `h26e3` を、結果を評価する前に固定する。`r5jc` は非空で連続した期間と開始点を検査し、`r5jd` は既存の一意な有界端点との完全な一致を要求する。

終点のない分岐 `r5je` は、開始以後の全履歴が期間に含まれ、既存の `rbz` が終点なしを満たすことを要求する。有限の端点指定との併存は認めない。通常の自然数の履歴なら、どの点にもその次の点があるため、開始以後の全体はこの時間構造を満たす。一方、有限の検査模型では終点なしは成立しない。有限の観測打切りを無期限の存続として扱わない。

`r5jf` が二つの期間形式をまとめ、`r5jg` が全期間で同じ制度と公的な問い直しの禁止を保持する内容を返す。有界部分は、範囲対応を満たす場合に旧 `r5h6` と同じ内容になる。引用記述の名前そのものを同じとは扱わない。共同合意 `r5jh` は新しい内容族を対象に取るが、その実現や無限性を合意の成立条件にはしない。`r5ji` は一人の生涯内に収まる有界部分を保つ。

人類の改善を比べる際には別の注意が要る。制度の維持範囲は終了点を含まなくても、その終了点で得た改善は期間の成果に含まれる。`r5jk` は評価範囲へ有界の終了点を加え、`r5jj` は人類の通時的な全成員を全人間に一致させる。時点ごとの生存は既存の関係で判定し、現在の生存者や合意の当事者だけへ縮めない。

`r5jl` は既存の認識獲得・理由ある誤りの訂正・理由ある自己判断の進展のいずれかを同じ期間の前後へ結ぶ。`r5jm` は全評価点の非空の人類と評価の有効性を保ち、全ての前後点で改善がないことを要求する。途中の獲得と喪失を見落とさず、期間外の改善は算入しない。この三種類による改善の捉え方と、不毛さを全不在で読む強さは採用解釈として明示する。

同じ合意が不毛化を引き起こすこと、期間の消去への見立て、後世への害、全文の不許可と談話はまだ残る。今回の結果条件だけで原因性を認定せず、意味確認済み文字数も増やさない。
