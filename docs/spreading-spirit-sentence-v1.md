# 第八段落第三文：自由の精神の国外への広がり

固定原文u0015の[890,1049)、159文字・136非空白文字を、先行二文と同じ君主条件を継続する一般的な叙述として記述する。`Dieser Geist der Freiheit`は、先行例の宗教的自己選択と公的提示の自由を政府一般について支持する共有可能な態度と読む。先行例の君主の功績・自己報告・名称評価まで支持内容へ複写しない。この型の継承を先行二文の内容へ結び、文頭と後半のerには同じ人物性質を参照させる。

同じ君主・最高職・共同体の条件を満たす場合、同じ出発者から国内の別人への経路と、国外の取得者への経路がある。国内側はauchが背景として保つ広がりであり、単に元の一人が態度を持つという条件へ弱めない。国外側は、別の共同体の政府の管轄下にあり、元の最高職の管轄外にある人への取得・保持である。全世界への到達、全外国政府の自己誤解、特定の実在王・国名は加えない。

社会的経路は同じ態度の表れとなる活動を通じた取得として構成する。活動の表れと結果生成を分け、任意長の有限経路、異なる当事者、各段階の同じ活動・過程・時点、最終本人の現在までの保持を結ぶ。発話の受領だけに限らない。原文の現在点は先行二文と共有し、外側の評価点では移動させない。

`selbst da, wo ...`は、国外への広がりが、自己誤解する政府の外的障害へ対抗する努力を要する場合にも成立する、という不利な場合の取り立てと読む。単なる空虚な条件文にはせず、同じ君主条件の下でこの場合の証人を要求する。一般の国外側と障害下の焦点側は同じ態度の到達を扱い、全ての外国がその状況にあるとはしない。無障害の外国の実例を別に存在させる必要もない。

自己誤解は、政府自身に帰属する公的役割の理解の肯否が、同じ内容の真偽と食い違うことである。障害の由来を同じ政府へ結ぶが、誤解が障害を作ったという因果は加えない。異なる複数条件について、同じ取得者に外的な条件として適用され、同じ取得・保持を潜在的に妨げることを確認する。条件の有無を比較する際は、同じ背景と選択枝を対応させる。

格闘は、同じ態度を担う人の活動・態度の表れ・実際の力の投入・その条件の働きへの対抗の方向性を結ぶ。態度そのものを人として扱わず、受け手本人だけに努力を負わせない。必要性は、同じ障害背景の関連経過に目標達成例があり、その全達成経過に対抗的努力が含まれる、という目的相対的な読みである。規範的義務、努力の十分性、政府打倒、障害の撤去・克服完了は述べない。

本文用の設定は、五対象列で経路を、八対象列で外国側の条件とモデルを固定する。各候補経過で取得があればそれを示す経路証人を与え、現実の一経路が使えないことを取得不能へ変換しない。必要性の範囲は同じ障害下の全関連実践的経過とし、結果で事後選別しない。入力の完全性・現実適合は公開した意味規約の条件であり、有限の検査が全可能経路や実際の社会的因果を証明したという意味ではない。
