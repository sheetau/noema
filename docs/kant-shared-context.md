# 状況引数を二つの述語で共有する

同じ状況を参照する二つの述語適用を、共有頭から出る一つの枝で表す。新しい字形や語義は追加せず、既存の共有頭と終端複合語を使う。省略された引数の位置は、それぞれの述語の公開型から決まる。

## 構成と復元

共有する位置は、結果型が `truth` の述語について、次の順に決める。

1. `situation` の引数があれば、最後のその位置。
2. なければ、従来の `individual → truth` の単項述語に限り、唯一の引数。

共有できるのは、二項連言の直接の子が二つとも述語適用で、指定位置の型と引数構文がそれぞれ完全に一致するときである。前方に別の共通引数があっても、位置を選び直さない。共有対象は、中小円の四部品以内で表せる無引数語か、許容される束縛参照に限る。

例えば `P(s₁, x, s), Q(s, y)` は、P の第三引数と Q の第一引数が公開型によって共有位置になる場合、共有枝に s を置き、主列には P・s₁・x・Q・y の順で描く。読取器は P の型から残り二引数を読み、第三位置へ s を戻す。その後 Q を読み、その第一位置へ同じ s を戻す。引数はそれぞれ通常の式として読むので、残りの引数内にも引用や分岐を置ける。

共有頭は一つの二項連言だけを復元する。連言の左右・結合順や引用の境界を変更せず、他の連言まで共有範囲を広げない。公開された共有位置のない述語、異なる型、後述する数を超える枝は拒否する。復元後のnative型検査も通す。

## 共有された述語の残りの引数を枝にする

複数枝の試作では、共有済みの引数位置を除いてから通常の枝順を求める。残りが二引数以上なら、通常の第一枝位置が残っている場合はそこを第一枝とし、それ以外の最初の位置を本文に残す。通常の第一枝位置が共有済みなら、残りの最初の位置を本文に残し、他を元の引数順に並べる。残りが一引数以下なら枝は付けない。

例えば共有位置が第四引数の `P(a,b,c,s)` では、aを本文に残し、b・cを枝に置ける。共有位置が第一引数の `Q(s,x,y,z)` では、xを本文に残し、y・zを枝に置ける。枝数がkなら公開順の先頭k位置を使い、各枝の入口の左右順で対応を決める。共有頭の枝は従来通り一つであり、PやQから出る枝と同じものとして扱わない。

復号は元の引数順に行い、共有位置に同じ終端対象を戻す。残りの位置は対応する枝または本文から一式ずつ読み、枝に余った式や不足を拒否する。束縛の命名順は見た目の枝順から決めない。旧来の枝を付けない共有述語も同じ規則のk=0として読める。描画への選択は `multiple=True` に従う。

## 接続を確保してから配置する

複合語の枝が中円の右出口を使うと、直後の大円へ中央段のまま接続できない場合がある。中央段の枝付き候補を確定する前に、次の核も中央段へ固定されているか調べる。その場合は、実際の次の字形へ合法な接続があることを確認し、なければその候補を除く。次の核は描画候補の最大間隔に置いて調べ、現在の核の別段候補を選べるようにする。

これはすべての後続配置が成功する保証ではない。次の核の枝などは実配置時に検査し、完成一文の幾何検査も維持する。字形の意味を変える回転や、円配置の禁止事項を緩める処理は行わない。

## 証拠と残件

`scripts/check_kant_shared_context.py` は、前段と同じ40主張を使う。各文を実SVGから復号し、前段の回収構文と一致することを確認する。さらに前段のSVGも新しい読取器へ渡し、従来の明示された適用を同じ構文へ戻せるか確認する。本文を含まない公開辞書を読み直して用い、元構文の位置表は復号器へ渡さない。

確認結果は [kant-shared-context-v1.json](../reports/kant-shared-context-v1.json)、描画は `output/kant-shared-context/index.html` に保存する。40文すべてで新旧の図形から元の構文が復元され、13文で計13か所の共有が成立した。円数は3285から3246、合計横幅は229964から228314となった。異なる引数数と共有位置、複数の状況引数、入れ子の連言、引用、束縛下の残りの引数、共有できない組合せを含む208件の検査が通った。

`inspection.png` は主張2・33・7の変更前後を各組同倍率で描いた比較である。共有対象の重複は減るが、似た構文の文頭が依然似た形になることと、長い単列の語形が残ることを目視した。共有数や円数の削減だけを、要求された外観の達成とみなさない。

状況の反復を減らしても、ほかの長い語形と主列の単調さは残る。一般の部分式を枝に置く規則、全構文・型・束縛、接触による合成、行・頁の復号、未使用の許容形への意味対応は未完成である。外観の固定候補としては扱わない。
