# 確認資料v1の予測前点検

モデルは前段階で選択したv6のままとし、この資料から得た予測で語彙・文型・閾値を選んでいない。最終資料は日本語672文・英語672文で、それぞれ600文が対応範囲内、72文が未対応である。全300意味構造には日英各2種類の表現を付けた。

## 予測を取得する前の修正

1. 最初の生成では、場所を行為者の前に置く受動態が主に主体省略の例となり、明示された行為者との順序を十分に確認できなかった。時間の区分と表現番号により態を交互に選ぶようにし、明示主体を持つ能動・受動の対と、主体省略を持つ受動の対を含めた。日本語の対象を先に置く能動文も、この変更で追加された。
2. 英文の文頭を大文字にそろえた。量化の例では文頭の `The` も対象に含め、埋め込んだ文の冠詞・場所・時間句が不要に大文字にならないようにした。固有名は変更していない。

最初の草案のハッシュは `6010bb365cd5b81be0482509b8d295cf48636df58752ca4b5369305dcc6a0d57`、態の配分を修正した草案は `495b170f02b45809e4c0574e176d746665b3b3e4b1a03d0800ea0c67ff0476dd`。草案はローカルのartifactsに保存した。予測に使用する最終資料と選択済みモデルのハッシュは [マニフェスト](../reports/confirmation-v1-manifest.json) に固定した。

## 点検した意味の対応

全6述語の肯定・否定、能動・受動、相対時間と時制の活用を、生成規則と代表例で確認した。たとえば「明日、17匹の猫はIrisによって公園で見られない」と「公園で明日、17匹の猫をIrisが見ない」は、同じ主体・対象・数量・否定・相対時間を保持する。英語の対応例でもIrisを行為者とし、17匹の猫を対象とする。

数量は文脈によって現実的とは限らない大きさも含め、明示された整数を変えずに注釈した。名前を翻訳したり、主体が省略された文へ人物を補ったりしない。各語の文字範囲、数量、固有名、同義グループの正解一致は全件を機械検査した。機械検査だけで原文の意味が正しいと判定してはいない。

資料は人工的に構成した短文であり、独立した利用者が自由に書いた文章ではない。概念の組合せ自体は以前の保留資料で点検済みで、今回新しいのは表現・数量・名前などの組合せである。この制約を成績とともに報告する。
