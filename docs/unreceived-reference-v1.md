# 文献への言及と基準時までの未受領

カントの著者脚注から、他の回答への言及と「Mir ist sie noch nicht zu Händen gekommen;」の二箇所を部分草案へ追加した。案内を読んだこと、回答を紹介されたこと、回答そのものを受け取ったことを分ける。既存18文を保存し、紹介と未受領の二文を加える。

`rqrn`は、履歴と先行関係と基準点、事象条件から「基準点以前にその事象がない」を構成する。既存`ta`で履歴内の厳密な全順序を検査し、基準点の所属を要求する。基準点を含むため今ちょうど届いた場合も未受領にはならず、過去に届いてから失った場合も除外する。履歴外の別経過と未来の受領は、この条件を変えない。未来の到来や期待は主張しない。

`rqro`は同じ受け手・文献・評価文脈を固定して受領へ適用する。既存`h7q`の引数は履歴枠・評価文脈・時点の順である。履歴が実際の関連する過去を欠かさないことは意味契約に残る。順序検査だけで現実の全過去を復元したり、記録がないことを未受領とみなしたりはできない。

`hzjt`は同じ案内の紹介行為、同じ回答文献、同じ人物、既存表題の問いの内容を結ぶ。名称使用と著者表示には既存の`hzih`と`hzij`を使う。問いの箇所`hzia`は問いの内容を指示する参照であり、メンデルスゾーンが後発のカント文書へ物理的に返信したという意味ではない。回答の正しさや全文の収録も主張しない。姓の綴りは名称個体の識別表記に保持する。

`hzju`は紹介された同じ回答文献について、著者`wa`への未受領を述べる。`sie`をその回答、`worin`を案内に受ける読みを採るが、雑誌を介する指示を含む別解釈を解決済みとはしない。原刊494頁の脚注と固定転記が対象である。敬称、週報と雑誌の情報、二つの日付と「今日」、後続の反事実、試み、偶然と思想の一致は今回の範囲外である。

有限検査は過去・現在・未来・別経過の事象16組合せ、無効な履歴、紹介の対象・人物・問い・媒体・文脈の取り違えを含む。標準の逐次評価器は論理的には不要な枝も評価するため、未来の値が未知なら保留する。既存の短絡診断ではその枝を評価せず、既知の全解釈では両方式の真偽一致を確認した。診断によって未知の過去や基準点を偽に補うことはない。保存したNoema本文は診断用に書き換えない。

新規基本記号は受領・回答としての紹介・記載媒体の三関係と八局所参照である。二つの一般定義は既存`ta`だけに依存し、語ごとの対訳表や生成処理は使わない。長さは共有宣言・参照・識別表記を含めて報告する。脚注全体の意味確認と作品全文の完成は未達である。
