# 同じ相互引受けへの宣誓修飾

第六段落のeidlichを、この教会団体の文脈では宗教的な宣誓として読む。[変更不能な信条の条項](irrevisable-confession-v1.md)へ、各人の同じ引受け行為が厳粛な表明であり、神的な権威を自分の誠実さの証人と、意図的な偽りや裏切りへの裁き手として呼ぶ条件を加えた。これは採用する解釈であり、全文化・全時代の宣誓の定義ではない。

[AdelungのSchwören項](https://lexika.digitale-sammlungen.de/adelung//lemma/bsb00009133_7_3_3548)を補助根拠として[保存した](../data/promissory-oath-evidence-v1.json)。この説明は厳粛さ・証人・不誠実への裁きという機能の区別を支える。1784年のこの文で使う宣誓文、呼びかけ先の固有名、罰の種類を特定する資料ではない。旧構成で参照した後年のカントの宣誓論全体も、今回の文へ追加しない。

`r46w`は神的な道徳上の証人・裁き手の性質を閉じたNoema記述にする。ここでは人間の制度に従属せず人の誠実さや違反を知り裁く上位の人格的存在、という呼びかけ先の描写を採る。固有名や神学上の全属性を指定せず、引用から該当者の実在を導かない。

`r46x`は同じ本人・行為・時点に厳粛さ、証人への呼びかけ、意図的な裏切りへの自己の責任を結ぶ。二つの呼びかけには同じ権威記述、条項関数、引数列を渡す。表明は誠実さを保証する形でも、本人が実際に誠実とは限らない。単なる履行の不成功を故意の裏切りへ置き換えず、実際の違反・処罰も断言しない。

`r46y`は引受けの表明と他の全当事者に対する相互性を、同じ`r46x`の行為へ結ぶ。`r46z`は旧`r46v`と同じ固定基準・全所属者・合意・信条・五引数条項を使い、この強めた表明関係を既存`hzcg`へ渡す。各人の宣誓の時点は異なってよいが、約束と別の儀礼を合成することは許さない。

旧`rin`は対象内容が不成立なら応答内容、という一般の条件付き呼びかけだった。その前件を今回の意図的な偽りに同一視しない。今回の`h255g/h`は証人・裁き手への呼びかけを表す基本関係であり、同じNoema条項と引数への参照を持つ。これらの発話を認定する入力は必要だが、引用内容の真理や権威の実在を実行評価しない。

[検査](../reports/promissory-oath-v1.json)は、三修飾の8組合せ、別人・別行為・別時点・別の権威記述・別条項・別信条を区別する。全当事者の形成は実際の`hzcg`と新定義で評価し、通常の相互引受けだけが成立する場合と宣誓条件まで成立する場合を並べる。余分な成員、未来の宣言、片方向だけの相互性、割当ての欠落も引き続き拒否する。権威の性質、信条内容、未来の履行を未知のままにし、呼びかけの記録自体が未知なら検査を止める。

これは問い全体の確認ではない。一般団体への例示、自己呼称の提示、全成員への上位後見と人民への媒介・永続化の目的、権限の問いと直後の回答は残る。本文96主張と確認済み文字数を保持する。
