# 固定モデルの並列関係の検査

## 目的と固定条件

文語0.6の集合へ自然文を接続する前に、KWJAの学習済み係り受け分類器から並列関係を取り出せるかを測る。生成、辞書、語句別の補正、追加学習、閾値選択は行わない。公開KWDLCの公式dev512文書を全件使用する。既存モデルの学習資料でもあるため、未知資料での汎化や最終評価とは呼ばない。

係り先はWordModuleの `topk` の先頭を使い、その候補に対応する `dependency_type_logits` のargmaxを使う。別々のargmaxによる同点時の候補ずれを避ける。公式の木修復処理は使用しない。循環、自己参照、未知の係り先、それらへ至る経路は不整合として残し、確定した並列辺へ含めない。

`P` は並列という構文予測であり、集合の論理積とは同一視しない。`D`（通常の係り受け）、`A`（同格）、`I`（不完全並列）も原出力に保存するが、`P` の評価へ混ぜない。並列の推移閉包から集合を作らず、成員の名詞範囲、論理積／選択、共同／分配、否定範囲は未決定のままにする。

## 正解と指標

KWDLCの各基本句行に注釈された係り先と種別を読み、句の最初から最後までの原文位置で対応させる。語彙主辞を推測して正解にしない。句番号は文ごとに解決し、文書全体の番号へ変換する。正解と予測の両端の基本句範囲と方向が完全一致する場合だけ並列辺を正解とする。

全件、正解並列辺のある文書、ない文書を別々に集計する。並列辺の適合率・再現率・F1、辺集合の文書完全一致、基本句も含めた完全一致、余分な辺を出した文書数を報告する。解析失敗も分母に残す。欠落辺は、端点の句がない場合、句はあるが係り先が違う場合、係り先は合うが種別が違う場合、経路不整合の場合へ分ける。

## 検証

原コーパスのハッシュと修正済み基本句資料を照合する。全512文書で既存の保存済み解析と原出力が変わらないことを検査し、先頭8文書は反復一致を検査する。保存結果から全指標を再計算する。生成・辞書など既存の禁止経路5種を実行時に遮断する。本文を含む成果物はartifacts内に保存し、公開する報告には件数・ID・ハッシュを含める。

この検査は句間の構文関係だけを測る。意味構造の完全一致率、日英翻訳の対応率、文語0.6への自動変換成功率として扱わない。
