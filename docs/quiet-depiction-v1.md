# 同じ先行局面での、外面の落ち着き

カント第二段落の「diese ruhigen Geschöpfe」を、先行する家畜像の同じ対象が、その局面では外から見て落ち着いている描写として本文へ接続した。既存48文を保持して一文を加える。内面の平静、服従、抵抗しない性格は付け加えない。

## 採用する読み

直前の家畜の描写と、同じ対象を指す `diese` を引き継ぐ。対象側では、既存の慎重な阻止と許容欠如 `rqzw` の人物・先行時点・基準時点を保持する。描写側 `rqz7` は、同じ人物位置に既存の家畜像 `qk` を置き、同じ先行局面の外面の落ち着き `rqz6` を結ぶ。

[Adelung の Ruhig 項目](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_6_2_2115)は、身体の動きに関する用法と、内面の感覚や他者への煩わしさに関する用法を区別している。ここでは家畜・装置・身体歩行という周辺の描写から、外に現れる身体的な動揺の不在を採る。これは文脈についての明示的な解釈であり、辞典から一意に決まる読みではない。

`Geschöpfe` は同じ家畜像の呼び直しとして扱い、神による創造という主張を追加しない。原文語の全用法や修辞的な含みを、この一箇所の定義で説明し終えたとはしない。

## 人の能動的な行為に限定しない

前段の `rqz4` は、人が能動的な当事者として参加する `df` を用いていた。この関係は動物や不随意の身体運動を網羅するものではないため、本文へそのまま流用しない。

追加した `hzyc` は、身体が自ら生じさせる外に現れる運動の主体との関係である。意図的な行為と反射的な動きの両方に使え、他の身体の動きや外からの移送だけとは区別する。`hzyd` は同じ身体・運動・時点について、反復・速さ・急激な変化などの様式が、基準文脈で外面の動揺として目立つ水準にあるという関係である。

二つの基本関係は、現実の生起、感情、能力、許容を代わりに判定しない。動揺の基準は文脈に固定する知覚・評価上の規約として残り、物理的な測定法の全理論ではない。単に動いていることや速く移動することだけを動揺とはしない。

## 局面と人物を固定する

一般形 `rqz5` は、前段の `rqz2` の履歴と評価範囲を指定した一状況に固定する。同じ主体との関係・生起・性質を持つ出来事が、その状況にはないことを表す。空の範囲から不在を主張する構成にはしない。

`rqz6` は `hzyc`・既存の生起 `dg`・`hzyd` をこの一般形へ渡す。基準文脈は基準時点へ固定し、過去の局面へ移して都合のよい基準へ変えない。動揺のない身体運動は許されるため、身体が静止している必要はない。別時点に動揺がある反例も許し、持続する性格や生涯の状態には一般化しない。

追加文 `r2aa` は既存の対応関係 `rqzv` と `hzyb` を使い、同じ複文の内部で人物と二時点を対応させる。外面の落ち着いた家畜という内容は引用の内側にあり、実際の人を動物と分類したり、内面の平静を断言したりしない。前段の身体側の不許容も保持する。

## 検証と残る課題

五テストで次を検査する。

- 一局面の不在の64組合せと、別時点には動揺がある反例。
- 身体運動の八組合せと七対照。身体・出来事・時点・基準を混ぜない。
- 実際の飼育定義を評価する十四対照と、同じ身体の異なる二時点の対照。
- 提示の九対照と、現実の内容が未知でも関連六文を評価できること。
- 未知入力の拒否、三記法の往復、既存48文と十一単位の意味依存関係の保持。

四定義と二つの身体関係を追加し、本文は49文となる。原文照合で `quiet_creatures` は未接続から部分接続へ進めるが、一文全体の意味確認は増やさない。強調の `ja`、局面上の読みと家畜・歩行の語義範囲を含む一文の確認、段落末尾と二作品全文は残る。
