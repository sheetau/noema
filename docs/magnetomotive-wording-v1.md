# 磁動力への類推

u0176冒頭の「磁動力についても同様のことが成り立つ」を、直前の二つの電気側の言い表しへの対応として読む。旧来の言い方では、動く単位磁極への力から静止時の磁気側の基準を引いた追加寄与が、二次以上を省けば−(u×E)/Vとなる。新しい言い方では、その極へ当該瞬間相対静止する系に場を変換し、その場所の磁気側の場H′で、その系で測る力を記述する。旧Kの追加力と共動系の全寄与を同一成分にはしない。

磁極強度には既存の符号付き試験量`eisps`を使う。点状担体・出来事・位置・量単位・値1の記録を、同じ物理的履歴の三つの座標時刻微分へ結ぶ。これは仮定上の試験極を運動前件とする条件文であり、孤立した磁荷が実在したという主張を加えない。磁石全体への合力や、電荷に働く磁気的な寄与`eico`とは区別する。

旧Kでは、磁極強度に対する静止試験応答`ejts`と動的な機械力応答`eisqp`を共有する。量1・零速度での応答をその地点の磁気側の場へ一致させ、基準・全寄与・差の三記録を同じ対象・出来事・力単位へ接続する。磁極量と場の単位の積が力単位へ換算1となる規約を、磁気側の基準と電気側の一次項の両方で明示する。

共動系では、前段で検査した任意方向の四座標変換、両場の混合と逆座標評価、全系の並進・物理的な全域座標対応を再利用する。同じ担体・出来事・量単位と変換後の位置を保持し、瞬間静止、その地点の磁気側の静止試験応答、同系の力の記録を結ぶ。加速度0や前後の静止は条件にしない。

新しい一般関係`eisqu`は、著者が二つの閉じた内容を類推として提示する関係である。対応する物理的な内容そのものは別に合成する。引用用語は`eisqq`を再利用し、近似の真理を含まない物理的な追加寄与の規則へ結ぶ。

検査では、実際の型の一次近似の符号と三成分、物理的な量・運動・単位・力記録の引数、二つの言い表しへの同じ証人の結合、著者と引用の提示を調べる。先行の履歴微分・静止応答・一般方向変換は固定した証拠に基づく検査境界であり、今回その全実数域を有限列挙することはしない。存在結合は二値の診断で全位置を区別し、実際の型の本体を別に確認する。

この構成はu0176冒頭の一文を対象とする。後半の「Man sieht」、展開した理論における補助概念だけの役割、電気・磁気の力の系依存性とその事情による導入理由は残る。単位全体の完成件数はまだ増やさない。
