# 規範上の制約、目的、実現する能力

同じ結果について、規範上の禁止・許可、実現する能力、本人の目的を別々に記述した。結果を制御できるだけでは、何を要求されているか、本人が何を目指すか、すでに実行したかは決まらない。前段の複数結果のモデルと、既存の記述付き規範・目的の関係を、同じ対象へ接続する。

この区別は、カント本文の個人的専制を検討する際に必要になる。比較資料である1795年の『永遠平和のために』では、支配者の人数による分類と統治の仕方による分類が分けられ、後者について立法と執行の分離、および公的意思を統治者の私的意思として扱うことが論じられている。[AA VIII, 352, 1–18行](https://korpora.org/Kant/aa08/352.html)。一人で結果を決められることを、そのまま専制の完成した語義とはしない。

ただし、この比較資料は対象の1784年本文より後の著作である。[AA VIII, 36, 28–33行の対象箇所](https://korpora.org/Kant/aa08/036.html)を1795年の定義に置き換えない。電子転写二ページを取得してハッシュを固定し、[読解記録](../data/norm-bound-choice-reading-v1.json)に用途と限界を記した。原刊画像との照合や、1784年の一意の解釈を確定したものではない。

## 同じ内容への接続

規範と目的は、同じ閉じた内容記述と、`本人・対象・結果`という順序付き三個体の引数を受け取る。規範の出所、名宛人、立場、評価時点も固定する。同じ真理値を返す別名の記述、別人への要求、別の立場での要求へ置き換えない。

能力については、指定した一つの方法が、他者側の全応答に対して同じ目標結果を保証するという前段の`rqqb`を実行する。目的は、その同じ本人がその同じ方法で、その同じ記述と引数の内容を目指す関係へ結ぶ。目的だけがあって実現手段がない場合や、実現手段はあるがその目的を持たない場合も区別できる。

| 定義 | 内容 |
| --- | --- |
| `rqqi` | 可能結果モデルが有効で、全結果の同じ規範対象について評価が済んでいる。 |
| `rqqj` | 指定方法で目標を保証でき、その同じ内容の不成立が要求されている。 |
| `rqqk` | 指定方法で目標を保証でき、その成立が積極的に許可され、不成立要求はない。 |
| `rqql` | `rqqj`を満たし、本人がその同じ方法でその目標を目指している。 |
| `rqqm` | `rqql`を満たす方法と結果が少なくとも一組ある。 |
| `rqqn` | 全結果の評価が済み、禁止された結果を保証する方法がない。 |
| `rqqo` | 規範と同じ本人・対象・時点からモデルの全設定を取得して`rqqm`へ渡す。 |

禁止されていることと、許可が見つからないことは異なる。`rqqj`には不成立を求める要求が必要であり、許可の欠落だけでは成立しない。`rqqk`には積極的な許可が必要であり、禁止の欠落だけでは成立しない。成立と不成立の両方が要求される衝突の場合、禁止側の要求は消さない。優先順位や例外の裁定は、この条件には含めない。

肯定の存在条件と否定の全体判定でも評価範囲を分ける。ある結果について禁止・目的・手段が確定していれば`rqqm`の一つの証拠になる。一方、別の結果の規範が未評価なら「禁止された結果を保証する方法は一つもない」とは判定できない。そのため`rqqn`には全結果の規範評価を要求する。

`rqqo`は、規範の名宛人・結果の対象・評価時点と同じ三者を、方法・応答・結果・可能性・評価の各設定の取得に渡す。規範が本人に対するものであっても、別人や別時点の能力を借用して条件を満たさない。取得したモデルの現実への適合性まで、この引数の一致から証明するものではない。

## 検証

規範の評価済み・禁止・積極的許可・目的・能力の五条件、全32組合せを検査する。全文候補と依存定義だけの文書の両方で、規範の出所・名宛人・立場・時点・対象・引数順・引数数・記述、および目的の本人・方法・時点・対象・記述の取り違えを検査する。対象として選んだ一つの結果だけを検査して、別の禁止結果を見落とさないことも確かめる。

規範・目的・能力の検査中は実際の内容を評価する関数を禁止し、引用の構成時には全入力関数を禁止する。実際の内容が真の場合と偽の場合で規範・目的・能力の判定が変わらず、内容を明示的に評価した場合にだけ真偽が返ることも検査する。未知の規範評価・要求・目的はエラーを保持する。

有限診断では既存の短絡評価変換を用い、元の文書は変更しない。二例で元の評価・キャッシュなしと一致することを確認する。表記・固有文字の往復、専用CLI解析、親文書の全宣言と15主張の保存、意味説明と型の対応を検査し、[検査報告](../reports/norm-bound-choice-v1.json)に保存する。

## 本文への採用に残る条件

規範の出所を変数として持つだけでは、公法や公的意思の意味は完成しない。公的制度、権限、適用範囲、立法と執行の関係を説明する必要がある。目的の主体を本人に固定しても、その目的が利己的であること、本人の感情や悪意を意味することにはならない。今回の七定義はこれらの区別に使う部品である。

`rqqn`は、禁止された結果を保証する手段がないという状態の条件である。規範が原因となって能力を制限したことまでは示さず、禁止自体がない場合にも成立し得る。規範の実効性を述べる場合は、禁止の存在と因果関係を別に記述する必要がある。

今回の条件の消滅を、前段の政治的な離脱へ自動接続しない。禁止が撤回された場合や本人が目的を変えただけの場合にも`rqqm`は消え得るからである。実行済みの違反、責任、専制政治、その関係からの解放をこの診断から推定しない。新しい原始記号や著者主張は加えず、原文の新しい対応範囲と意味確認済み区間も加算しない。
