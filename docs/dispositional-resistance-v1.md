# 未試験の物にも述べられる耐性

性質を評価する時点と、負荷を加えた場合の応答状況を分けた。先行の `rys` は、指定状況で実際に正の荷重を受け、小さい変形にとどまる条件だった。これをそのまま成長区間の全時点に要求すると、覆いを常に試験していることまで必要になる。新しい `ryu` は、各時点を起点にした仮定の応答状況で `rys` を評価する。

試験範囲は、従来と同じ非空で重複のない完全な列挙を使う。各試験に候補状況が少なくとも一つあり、その全てで同じ物・方法・二単位について負荷応答の条件が成立することを要求する。一部の試験の候補が欠ける場合も、良い候補と悪い候補が混在する場合も成立しない。評価時点自体が未試験であることは、性質を否定する理由にしない。

カント本文では、発話文脈で試験法・単位・閾値を固定し、成長区間の各時点について同じ覆いの応答候補を調べる。発話文脈、性質の評価時点、応答候補状況を別々に束縛する。世話の描写、先行する制度条件への参照、性質の組を指す同格も保持する。描写への帰属だけでは、候補状況の内容を事実として主張しない。

検査には、未試験でも耐性のある例、実際の試験には成功しても候補応答が失敗する例、途中の時点だけで失敗する例を含めた。対象・試験・方法・単位・評価時点の取り違えと、空の候補、不明な解釈入力も区別する。従来の因果・自己利益の条件文全体は今回再評価していない。

応答候補をどう選ぶか、その物理的な根拠と完全性は解釈入力として残る。成功した候補だけを選べば現実の耐性を正しく表せるとは限らないため、この定義だけを硬さの完全な理論とはしない。通常性や例外、妨害の扱い、適切な試験法・閾値、原文の意味一致も未完である。八引数の部分ひな形を残し、原文の対応範囲や意味確認済み区間は増やさない。
