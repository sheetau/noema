# 観測系を交換した同じ形状結果

u0117の「同じ結果」は、直前の物体の形状・三軸寸法・速さによる縮小の程度と光速への極限を指すと読む。後続で見出すと予告した内容をここで証明済みの結果へ変えず、まだ導入されていない時計の結論も加えない。

共通規則ejidは静止系・観測系・方向を引数に取る。kに静止する物体をKから見るときは+v、Kに静止する物体をkから見るときは−vである。対象の同一性は各適用の内側で保ち、二つの適用の物体を同一個体に固定しない。どちらの系にも同時に静止する物体を作らない。

ejhw/ejhxで同じ全物質点の全時間区間の符号付き並進を構成した。両系の現在記録、同じ出来事の四式、系間速度三成分へ結び、静止側の完全な形状と観測側の完全な占有集合・実際の三軸幅を接続する。形状は各観測系の同時刻で取り、Kとkの時刻を等置しない。

縦の縮小係数は√(1−(v/V)²)なので正負の速度で等しい。一方、中心の移動は+vtと−vtで異なる。球を例に取れば、任意中心(cx,cy,cz)は(f*cx±vt,cy,cz)、半軸は(f*R,R,R)となる。同じ形状規則の適用とは、この対応を共有することであり、別の物体の大きさや位置まで同値にすることではない。

極限も符号を保持する。速さがVへ下から近づくと、同じ元の形状の全位置が共通の精度で±Vtの平面へ近づき、元形状の横射影が残る。光速未満ではこの前向き像と符号付きstvを一致させる。光速ちょうどの有限βや正則変換は使わない。
