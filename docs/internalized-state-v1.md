# 経験による形成と、内側からの状態への寄与

「ほとんど本性となった未成熟」の比較対象を具体化した。前の版では「程度が増し、近い状態を保つ」という構造に、何を測るかという空欄が残っていた。今回は、経験によって形成された内的構成が未成熟へ因果的に寄与し、外からの維持作用が更新されなくても、その寄与が比較範囲で広く成立するという読みを組み合わせる。

これは原文に対する解釈候補である。カントは後年の『人間学』で、習慣を以前と同じ仕方を続ける内的な強制として論じ、別の自然への類比に言及する。ただし、その記述から1784年の句の意味や今回の比較方法が一意に決まるわけではない。[Kant, AA VII149](https://korpora.org/Kant/aa07/149.html)

対象段落には、自分の理解力を試すことの不許可、定式への依存、自由な運動への不慣れが続く。指導下での経験を形成の一因として置くのは、この文脈を踏まえた選択であり、句自体がすべての人の特定の経験を断言すると確定したものではない。[Kant, AA VIII036](https://korpora.org/Kant/aa08/036.html)

## 組み合わせた条件

| 定義 | 内容 |
| --- | --- |
| `r2cq` | 本人が実際の活動に参加し、その同じ活動で別人に指導される |
| `r2cr` | 指定された内的構成が作動している |
| `r2cs` | 同じ本人の過去の指導下の活動経験が、現在の同じ内的構成の形成へ寄与する |
| `r2ct` | 同じ構成が作動し、本人の未成熟があり、前者が後者へ実際に因果的に寄与する |
| `r2cu` | 外的維持の更新がない非空の比較範囲で、その内的寄与の程度を両端と整合させる |
| `r2cv` | 上の比較を、同じ本人・構成・尺度での実際の程度増加と近接状態の保持へ接続する |

内的構成の所属、作動、経験による形成、比較候補、外的維持の更新という五つの一般的な入力を追加した。「本性」「習慣化」の語全体を一つの判定器へ移してはいない。具体的な心理機構をすべて還元したとも主張しない。

形成した構成が今は休止している場合と、作動している場合を分ける。単に過去の経験と現在の状態を並べても、形成への寄与にも現在の因果にもならない。また、後天的な経験が形成に寄与したことから、生来の要因が一切ないとは導かない。

比較候補では、本人の当該履歴点の内的構成と関連背景を保ち、外的な維持作用の更新を比較する。維持したい結果そのものを背景として固定しない。候補の選定と更新の有無は、未成熟が残ったかどうかから独立に与える。経過期間、背景、外的更新の範囲が妥当かは、形式検査だけでは決まらない。

現在の内的な因果的寄与と、外的更新がない場合の比較は別条件である。現在も外部から支えられていることは内的寄与を否定しない。しかし、比較範囲から外的更新のある局面を除いた結果が空であれば、比較は成立しない。過去に外から影響されたことと、今も更新され続ける必要があることを区別する。

## 程度と検証

既存の質的尺度を使い、すべての比較局面で不成立なら最小、すべて成立なら最大、その中間なら両端以外とする。中間値は件数の割合から自動計算しない。近接域の校正も文脈入力であり、95%などの数値を原文へ補わない。

元の測定関係に一意な尺度内の値があることを確認してから、比較結果との整合を検査する。不整合な値を先に取り除くことで、元の多値や欠落が隠れることを防ぐ。その上で、同じ実際の過程と本人への作用、前後の増加、現在までの近接域内での保持を要求する。

検証は、活動・経験・形成・所属の16組合せ、人物・活動・経験・構成・時点を取り違えた対照、休止中の構成、現在の因果と能力、比較候補の各部分集合を含む。原文側の合成では、実際の経験、既存の未成熟の能力定義、因果、比較、程度変化を通常の評価器で実行する。引用の検査では内容の真偽を未知のままにし、著者への帰属と現実の成立を分ける。

この比較軸は、習慣の強制性・自動性・無反省の全条件や、自然という語の全用法を尽くさない。候補と尺度の校正、個々人の離脱の困難、also、人称と量化、著者への帰属も残る。句・第一文・段落全体を意味確認済みとは数えない。既存51本文文と十二単位の判断、意味確認済み2,212非空白文字を保持する。
