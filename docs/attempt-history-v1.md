# 過去に許容されなかったことと、現在の能力

カント第三段落の能力不足と、その説明を部分草案へ追加した。「許容されなかった」「試みなかった」「現在はできない」を別々に表す。同じことを述べるように見える文でも、許容なしに試みた場合や、許容されていてもできない場合を区別できる。

## 過去の範囲と否定

一般定義 `rab` は、一つの履歴から固定した基準状況より前の状況を選ぶ。`rac` はその範囲で対象の関係が一度も成立しない条件である。同時点・将来・別の履歴にある関係を混ぜない。過去範囲が空のときは全称条件が成立するが、過去に機会があったことを意味しない。

意味上の否定と、記録の欠落は別である。比較用の `rad` は各状況の肯定・否定の分類がちょうど一つあることを要求し、`rae` はその上で全てが否定側であることを要求する。肯定記録がなくても、未評価や矛盾した分類があれば `rae` は成立しない。ただし、分類の完全さは入力した範囲内の条件であり、証拠の正しさや現実の全過去を調査したことの証明ではない。

この一般形に許可という語の対訳や、特定の文専用の演算子は含めていない。同じ構造で機械の作動履歴なども記述できる。範囲と対象の関係は引数として指定する。

## 原文への接続

対象節を[アカデミー版電子本文の第36頁](https://korpora.org/kant/aa08/036.html)と照合した。これは原刊画像の確認ではない。解釈上の判断と未完事項は[読解記録](../data/attempt-history-reading-review-v1.json)に保存した。

| 定義 | 内容 |
| --- | --- |
| `h2` | 本人の履歴が基準状況を含み、先行関係が履歴内で厳密な全順序になる |
| `h3` | その過去範囲で、本人による同じ活動の試みを許容した行為者がいない |
| `h4` | 現在の整合した能力評価で、自分の理解力を使う方法がない |
| `h5` | 同じ本人について `h3` と `h4` が成立し、前者を後者の原因説明へ採用する |
| `h6` | 比較用に、同じ活動を過去に実際に試みなかったことを表す |

活動は既存の `bm`、自分の理解力の使用へ結ぶ。この節には他者の指導を排除する条件がないため、その条件を持つ既存 `bb` には置き換えない。説明対象の能力も `bm` に対して評価する。原文の不特定の行為者を、前段落の特定の後見人へ固定してはいない。

社会的な許容の関係 `g7` は基礎関係として新しく宣言した。法的な許可だけに限定せず、実行・成功・能力・物理的な機会とも区別する。ただし、この関係の一般的な基礎説明は未完であり、新記号を与えたことで語義全体を説明済みとはしない。

現在の能力不足は未来の永続的な不能を含まない。また、許容の不在から能力不足を導く一般法則は追加していない。原因として説明に採用する既存 `ea`、二つの内容の成立、現実の因果機構を区別する。`h6` は対照例のための定義であり、原文の内容として未経験を断言しない。

第三段落の一般化、愛着、慣れ、足枷や跳躍の比喩、強調、能力の基礎説明は残る。この段落を完成扱いにせず、新しい無条件の本文主張も追加していない。前の文書の全宣言と8主張はそのまま保持した。
