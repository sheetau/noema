# 計算手順と、その内容への評価

アインシュタイン1905年論文§5のu0139後半とu0141第一文へ、計算からの帰結、計算の容易さ、二速度の対称性、対称性への評価を部分的に接続した。式が真であること、著者が式を導いたと述べること、その計算や式を評価することは別々に記述する。

手順列と評価の四つの定義を、物理の前提を含まない[独立した文書](../examples/v014/calculation-assessments.noema)にも保存した。文法や字形は増やしていない。手順の前後の記述を一組にする構成も、既存の関数と関数適用だけで作る。

| 定義 | 保持する条件 |
| --- | --- |
| s2w | 非空の手順列が、指定した前提から結論へ順につながり、各変形が同じ許容関係に入る |
| s2x | 同じ列の各手順に付いた負担評価を加算する。重複した出現も数える |
| s2y | s2wと同じ列の各負担が非負で、合計が指定した低負担基準に入る |
| s2z | 同じ内容記述と文脈の尺度値が、その文脈の評価基準に入る |

例えばA→B、B→CはAからCへの列となるが、順序を入れ替えたB→C、A→Bはならない。A→Bの負担が1、B→Cが2なら合計は3であり、無関係な低負担の手順で置き換えない。B→Bを二回挿入した場合は、その二回の負担も加算する。空列や負の負担を「容易な計算」として認めない。

この例の数値は検査用であり、原文の計算負担を測った値ではない。s2wが使う許容変形関係も、機械検証された論理規則に限定したものではない。本文への帰属、ある解釈で許容された変形、数学的に健全な導出を区別する。引用した前提・途中式・結論を、手順列の確認のために実行評価する必要はない。

「簡単な計算」は、同じ前提と結論をつなぐ有限手順の負担が小さいという読みを採用した。前提には先行する運動と座標変換、同じ点の速さ、角と成分の対応を接続し、結論には前段階の速度合成式s2vを使う。原文に具体的な手順列、負担値、閾値はないため、これらの値は未指定のままである。検査用の一段の手順を、著者が実際に実行した計算として本文へ追加してはいない。

対称性は、光速度と角を同じに保ち、合成式の二つの非負入力を交換しても、同じ結果を持つ関係が保存されることとして定義した。選んだ一組の数値の一致ではなく、実切断全体へ量化する。平方根と符号付き分母の条件も保持し、二つの基準系の意味役割や測定値を同一視しない。

「注目に値する」は、その対称性の記述に注意を向ける価値が文脈基準に入るという読みである。尺度と基準は引数から与え、原文にない普遍的な閾値を作らない。式の記述と対称性の記述を交換すると、この評価は同じとは限らない。意外さや驚きを含む別の読みまで記述し終えたとはせず、採用した部分解釈として残した。

検査記録には、手順と負担13例、記述ごとの評価5例、本文の計算への接続7例、対称性の評価への接続5例、対称性の引数と定義域4例、帰属6例を保存した。20回繰り返す手順でも各出現を加算した。内容を誤って評価した場合には検査が失敗するようにし、引用が保持されていることを確認した。

二つの非負入力の交換については、有理数の平方根条件と符号付きの商の多項式による検査も行った。実切断の有限例は引数の接続検査であり、全実数上の証明ではない。元の全称量化を有限解釈器へ渡すと実行を拒否することも確認し、標本の一致を全域の対称性へ昇格させていない。

新規9件を含む関連29テストが通過した。両文書の通常記法・短縮記法・固有文字の往復、CLIのJSONと構文木の一致、SVGのXMLとしての読み込みも確認した。字形の目視確認と全テストの実行は今回の検査に含まない。

独立した四定義の文書は939文字、本文への累積文書は基本記号489、定義718、文138、187,271文字である。本文文書は親版から2,219文字増えた。累積の定義を含む長さであり、一文の翻訳長ではない。

今回の明示原文範囲は133文字増え、部分草案の文字範囲は13,246/35,614文字（37.19%）となった。部分対応は124/282区間、数式要素は230/446件である。今回は速度の文字記号二つも数えており、完成した数式の本数ではない。原文とNoemaの全意味確認済みの区間は両作品とも0のままである。具体的な計算方法、評価尺度の構成、角と分母の規約、後続の平行運動、一般の実切断の演算法則は残る。
