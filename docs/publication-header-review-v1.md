# 冒頭四単位の意味確認

原刊481頁の誌名、年、第12号と12月、記事番号1の四単位を、それぞれ表示情報として確認した。[保存画像の原資料](https://www.digitale-sammlungen.de/de/view/bsb10926843?page=521)と固定電子転記を照合し、以下の読みと公開した意味規約の下で、各単位を記述できたと判断する。実装したアシスタント自身の判断であり、独立査読や意味一致の自動証明ではない。

| 単位 | 採用した読みと記述 | 追加しない情報 |
| --- | --- | --- |
| u0001 | この号の刊行系列を、既存名称Berlinische Monatsschriftで示す誌名表示。名前、系列、号を分ける | 誌名の語源から刊行地や実際の毎月の刊行実績を導かない |
| u0002 | この号に表示された年は、共有する暦で1784年である | 実際の刊行日、執筆日、時刻 |
| u0003 | 同じ系列と表示年の下で第12号と表示し、同時に12月の号と表示する。号番号と月番号を別々に保持する | 第12号から月を算出すること、現存冊数・実発行順・巻内の号数との同一視 |
| u0004 | この号に掲載される現在の論説に、記事の表示番号1を付ける | 論説の優先権・重要性・実際の執筆順・頁番号 |

全四単位の表示は同じ12月号へ結び、論説・誌名・系列・1784年・暦には既存の参照を使う。脚注の9月号と別であることも明示する。u0003は上の年表示を文脈として参照するが、u0002のNoema文に月や号数の主張を混ぜていない。u0004の対象は直後の表題を持つ同じ論説であり、任意の別記事にはしない。

号・記事の順序番号は印刷上の番号として扱う。原刊は本文見出しに年と第12号を掲げる一方、頁脚には別の巻内表示を持つ。このため、合本の物理的位置や巻内番号へ一律に置き換えない。一つの親経路と番号規約で二項目を同じ番号へ割り当てる不整合は拒否する。別の番号規約に同じ数値が現れることは許す。

確認では、固定原文の全範囲、関係の型と引数、参照、誌名・年・月・番号という表示上の役割、追加と省略、依存する意味規約、検査と読解の限界、単位全体の再読という八項目を扱った。各判断の根拠は`data/publication-header-u0001-review-v1.json`から`u0004`までの四記録に保存する。未知の分類や未実行の問いに依存する脚注・本文の意味を、この四単位の確認から推定しない。

この四単位の確認対象には、表題の「回答」「啓蒙とは何か」、1783年12月516頁への参照指示、冒頭の思想内容は含めない。長さの異なる四単位が増えるため、単位数の割合を本文全体の完成分量と呼ばない。
