# 力・加速度の別の評価規約を採る場合

アインシュタイン論文919頁のu0259前半に、別の力・加速度の定義を採る場合の比較を部分接続した。今回の一般定義は、固定した対象・速度条件・方向・物理事例を共通の単位で評価する関数を扱う。単位だけを変えた数値の差は前段の換算と区別する。

まず、指定した評価領域の全事例で係数×加速度＝力となることを要求する。加速度が非零の事例を少なくとも一つ含めるため、全て零の入力だけで係数が定まったとは扱わない。比較では両規約にこの条件を課し、同じ事例・方向で評価値と係数が異なることを確認する。縦横の全ての係数が変わることは要求せず、少なくとも一方向で差があるという読みを採る。

ただし、評価規約が変わっても係数が変わらない場合がある。力と加速度をどちらも二倍にした規約では、その比は同じになる。また、定義の記述が異なるだけで評価値が同じ場合もある。このため、原文を「どのような別定義でも必ず全ての質量係数が変わる」とは形式化しない。

本文は、比較内容と現在の文脈について選定された非空の仮定状況全てで係数が変わる、という部分読解である。既存の候補状況の定義を使い、仮定状況での成立と現在の成立を分ける。元の係数には前段の縦横係数を使い、別規約の評価関数と係数は同じ仮定状況から取る。著者がこの内容を述べるという帰属を一文加え、先行176文を保持する。帰属の成立だけから、内容が正しいとは推論しない。

検査では、指定した有限の事例領域を評価する。力と加速度を比例して変える例、領域外だけの差、事例の取り違え、全て零の入力、候補の空集合、選ばれていない現在状況だけで成立する例を区別する。有理数の一般命題では係数の一意性などを確認し、両評価の変更が常に係数を変えるという過剰な主張には反例を求める。

評価領域の完全性、固定する物理条件、具体的な別定義と仮定状況の選択理由は、まだ解釈入力である。自明性を示す冒頭のNatürlichと、後半の理論比較・慎重さ・程度・推論も未記述である。今回は「würde man」からセミコロンの直前までに部分対応を付け、区間全体の意味一致は認定しない。
