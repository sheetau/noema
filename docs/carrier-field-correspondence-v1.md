# 担体の履歴と場の全領域の対応

各担体の小ささ・剛性・電荷付着を評価する系と、電荷密度・速度・場の方程式を記述する系を区別したまま、同じ物質点の同じ出来事を両側へ結ぶ。対象の同一性は座標値の一致では代用しない。

ekygは、同じ担体の座標族から同じ物質点・時刻の四座標を構成する。ekyhは、その担体への所属、全分布と局所成分への所属、両系の校正、四値の妥当性、担体側の履歴区間を保持し、両側の位置を同じ物質点・世界線出来事へ割り当てる。担体側の時刻が場の系の時刻と数値的に一致する条件は加えない。ekyiは担体と時刻を一緒に選び、別々の成功例から取り合わせない。

ekyjは、場の領域内の全成員・全世界線出来事・全有効四座標へ対応を要求する。選択条件には既存の位置割当zpbを用い、明示単位のeisqdを帰結に含める。単位情報が欠ける出来事を対象から消して条件を通すことはできない。場の領域外の履歴まで領域内に入れることは求めない。

ekykは領域総量、球平均、偏微分、各担体の成分電荷を一組の局所証人として、同じ設定・地点へ結ぶ。ekylは非空の場の領域の全有効点でこの条件を要求し、非零密度の物質支持と全成員の実際の速度を共有する。領域総電荷の同時刻断面を参照するeventと、個々の物質点の世界線上のworldeventは別の束縛である。

担体ごとに異なる評価系と区間を保持し、一つの共通静止慣性系、等速運動、全系での同時の剛性は補わない。場の系での電荷にはその系の物理的帰属を要求し、担体の別の評価系で固定した量を代入しない。後続の系間電荷不変や変換後の式は先取りしない。

検査では四座標の数値本体、同じ対象への両側の接続、全成員・出来事への適用、十個の局所証人の全束縛位置、全有効点への適用を分ける。無限域の有限列挙は拒否し、検査の通過を連続体全域の証明や原文単位全体の意味判断へ置き換えない。イオン・電子、理論の電磁的基礎、条件付き提示と原文冒頭群の統合が残る。
