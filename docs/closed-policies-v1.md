# 型付き引数を保持した規範の対象

制限の程度と頻度を表す内容を、既存の許可関係の対象へ接続した。個体だけでなく、数値、状況の列、状況から活動列を返す関数、評価基準を、その型と順序を保持したまま記述に含める。新しい構文や基本概念は追加していない。

従来の政策規範は、個体の列を対象記述へ渡していた。これに数値や関数を個体として詰め込むと、型の区別が失われる。今回は、全ての型付き引数を通常のNoemaの閉じた式として対象記述の内部へ置く。外側から渡す個体列は空にする。個体の列へ任意の型を暗黙に変換する方式ではない。

たとえば、`aa` が個体と数から内容を返す関数、`ab` が個体を表す零引数記号なら、次の引用は、`ab` と1/2を渡す内容の記述になる。

```text
r[i[bindings j[a]][c[p aa][k ab[] n p b c]]]
```

この記述を空の個体列で適用する。`bindings` は外側の共通インターフェースの引数であり、内容を決める二つの引数は引用の中に保持されている。関数と数の型は通常の型検査で確認する。引用の外側の変数を暗黙に捕捉しないため、内容を決める式は全て閉じている必要がある。

[policy_descriptions.py](../noema/policy_descriptions.py) の `close_policy_description` は、既存の記述生成補助 `apply_description` を使い、この通常の引用を組み立てる。入力は関数の引用と、型付き引数それぞれの引用であり、戻り値もNoemaの構文木である。補助関数は対象や引数を実行評価せず、内容を返さない関数、引数の数・型の不一致、自由変数、引用制約に反する脱引用を拒否する。人は補助関数を使わず、同じNoemaを直接記述できる。

| 定義 | 内容 |
| --- | --- |
| `rea` | 同じ対象記述を空の引数列で適用することへの要求 |
| `reb` | 同じ指定対象への明示的な許可 |
| `rec` | 許可があり、その反対極性への要求がない |
| `h77` | 程度・頻度の既存条件を、評価状況ごとの内容へする |
| `hza` | 型付き引数を含む対象記述の内容を、評価側が規制者に許可する |
| `hzb` | その許可に反対要求がない |
| `hzc` | 同じ対象記述の内容が現に成立する |
| `hzd` | 許可はあるが、同じ対象の内容は現に成立していない |

カントへの接続では、`h77` の引用と11個の型付き引数から対象を作り、`hza` へ渡す。これにより、程度の基準と頻度の基準を満たす制限状態全体を許可の対象にできる。許可を述べるときには、活動の分類・禁止割合・期間・重みなどが現在どうなっているかを実行評価しない。実際の状態を確かめる `hzc` と、許可のある未実現状態 `hzd` は別に評価する。後者は義務違反を意味しない。

記述の同一性も保持する。別の人や立場、別の期間、別の頻度値、別名の評価関数を含む記述へ、許可を自動的に移さない。同じ値になる式でも、その記述を認めたかどうかは別である。また、対象の内側の規範出所・人・立場と、許可を与える側の出所・名宛人・立場を別々に束縛する。

閉じた式は、既知の値や永遠に不変な値と同義ではない。参照する定数・関数の意味規約と解釈が必要であり、それが未確認でも許可そのものを記述できる。実際の状態の評価で未知の規範が必要になれば、偽として埋めず評価を拒否する。`hzc`・`hzd` は脱引用を含むため、現行の引用制約により、これらをさらに引用することはできない。

一般文書は [closed-policies.noema](../examples/v014/closed-policies.noema)、原文への接続は [kant-closed-policies.noema](../examples/v014/kant-closed-policies.noema)。既存の宣言と15件の主張を保持した。これは程度・頻度を含む政策状態を許す作用範囲の候補であり、各時点で制限を許すという別の作用範囲との同値は主張しない。原文に数値や対象範囲を補ってもいない。候補となる数値・範囲全体の量化、進歩を特に妨げないという留保、原文全体の意味一致は未完である。

許可と反対要求の4通りを対象未評価で検査し、対象と外側の束縛の対照10例、許可・反対要求・実際の状態の8通りを検査した。生成した記述は簡略記法・完全記法・固有文字で往復し、特別な実行機構なしで通常のNoemaとして解釈できる。

```powershell
python -X utf8 -m scripts.check_closed_policies --verify-only
python -m pytest tests/test_policy_descriptions.py tests/test_closed_policies.py -q
```

結果は [closed-policies-v1.json](../reports/closed-policies-v1.json)。既存範囲の具体化であり、原文の対応文字数と全文の意味確認済み区間数は増やさない。

今回の追加・既存の記述生成と政策規範・進捗集計に関する47テストが通過した。両文書のCLI解析結果と構文木の一致、およびSVGのXMLとしての妥当性を確認した。今回、字形の目視検査は行っていない。対応表143件・Noema文書271件の集計を再生成し、再検査で一致した。
