# 任意の折れ線と同じ場所への帰還

u0127は、前段の到着時の遅れが任意の折れ線でも成立し、出発地点と終着地点が一致しても成立すると述べる。一つの直線の結果を特定の三角形だけに限定せず、任意の非空有限区間列について同じ条件付きの結果を記述する。

各区間は正の所要時間を持ち、前段から引き継いだ共通の正の速さで進む。出発と到着の出来事、記録、指示、場所を経路全体で共有する関数へ結び、前区間の終わりと次区間の始まりには同じ出来事を使う。位置と時刻の数値が一致するだけの別出来事を接続しない。幾何学的な場所の再訪や自己交差は許す。

区間内の全実時刻の現在表示と完全な代表軌跡を要求するため、頂点だけが合う迂回や非等速移動では条件を満たさない。隣接する重複頂点による零区間は表記上の冗長として除く。正の速さでの移動に待機時間を加える読みではない。

帰還では、同じ場所へ戻っても出発と帰着の出来事と時刻は異なる。両時計が初め同じ場所で同じ出来事を比較する場合も許す。参照時計の初期同期と全期間の残留、到着直後の同所比較は前段から保持し、異なる二地点専用だった条件を流用しない。

全所要時間は区間ごとの時間差の和と出発・到着の差へ結び、同じ指示関数の差も望遠和として結ぶ。実際の到着指示差と全所要時間には同じ秒換算尺度を使い、二次近似と固定した全所要時間についての四次以上の留保を保持する。

各区間と折れ点で追加の指示変化を生じないという読みは、著者の発話外の補足解釈に置く。原文が述べる折れ線・初期同期・比較の前件をその法則で狭めない。Man sieht sofortは同じ拡張についての著者の明白さの提示であり、全読者の認知や処理系の証明済み認定ではない。

任意有限列・関数・実数の量化は本文に残す。有限例の検査は、全経路の一般成立や加速時計の物理的導出を証明しない。次のu0128の連続曲線への適用仮定は別に記述する。
