# 軍務の欠点への注記と公衆の判断

次の一文 `kant-1784:u0012[2332,2512)` に必要な、注記の内容・作成・提出を準備する。本文への統合と規範内容はまだ行わず、新しい意味確認文字数には数えない。

欠点は、同じ対象に採用された「備えるべき条件」が満たされない内容として `r326` で表す。注記の各所見は、その同じ対象と条件についてこの内容を分析・説明・指摘する。所見の全内容を二値命題一つに縮めず、何がどの観点で不十分かという論点を束縛する。注記が扱う欠点の現実の真理は、注記の分類から導かない。

`r33b` は、同じ人が同じ学識者の立場で注記を作る活動と、その同じ注記を同じ公衆へ提出する活動を結ぶ。提出の目的には、同じ公衆の読者が同じ注記について判断する内容 `r327` を引用する。作品が制作済みであること、実際に提出したこと、読者が判断・同意したことは要求しない。

`r33c` はこの活動構成を任用された将校と同じ組織の軍務領域へ結ぶ。軍務を一つの命令や現に行われている戦闘だけに狭めない。実際の作成・提出を述べる内容は `r33d/e` で別に構成し、同じ作品の外部記録と、同じ活動による作成・提供を要求する。提出の成功にも、公衆の判断の達成は追加しない。

次の統合では、`billigermaßen nicht verwehrt werden` を上位の規範として構成し、作成と提出の両活動への保護を確認する。連言だけへの禁止拒否では、一方だけへの禁止を見落とし得る。同じ命令事例への照応、`aber` の対照、文全体の帰属も残る。
