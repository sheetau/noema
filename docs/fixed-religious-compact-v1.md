# 固定した宗教制度への共同合意

第六段落第八文の合意対象を構成する。原刊489頁を表示して読み、[AA VIII 39の28–32行](https://korpora.org/kant/aa08/039.html)と照合した。`beharrlich` は同じ制度配置を対象期間中に変えず存続させること、`von Niemanden öffentlich zu bezweifelnde` は誰にもその受容を公に問い直すことを認めない規範的な限定として読む。実際に誰も疑わないこととは分ける。

`r5hz` は期間対象に一意の端点と有効な履歴を結ぶ。`r5h2` はその期間が同じ一人の生涯に収まることを、既存の生涯範囲と連続区間の構成で検査する。生涯の入力は出生から死までの完全な範囲として与える。この限定は、当人が合意の参加者であることを要求しない。

`r5h3` は公的に制度の受容を問い直す活動候補、`r5h4` は同じ本人の同じ活動の実行、`r5h5` は全員の全候補への禁止を区別する。市民・聖職者・学位の保有者だけに対象を狭めず、禁止された活動が実行されていることも要求しない。候補の非空性も確認し、候補を空にして無規制を禁止済みとする構成を避ける。

`r5h6` は開始を含み終了を含まない全期間で同じ配置の存続と規制を要求する。合意の時点は期間開始以前に固定する。終点後の継続・廃止は決めない。今回は有界期間を扱い、無期限の固定化まで記述できたとはしない。

`r5h7/r5ja` は既存の同意表明を使い、固定した複数当事者が同じ内容への同意を済ませた共同合意を構成する。宣誓や署名、全住民の一致を追加しない。宗教制度への特殊化 `r5jb` は、同じ共同体・配置・公衆・期間の `r5h6` を引用して渡し、その実現を合意の成立条件にしない。共同合意の構成自体は別の主題の内容にも使える。

全文の全面的不許可、改善過程への因果的影響、消去への見立て、不毛化、後世への害、前文との対照は残る。今回の検査は依存構成の確認であり、文全体の意味確認文字数は増やさない。
