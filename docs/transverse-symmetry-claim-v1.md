# 測定長によるφの解釈と対称性

u0101–u0104を、同じ棒の測定長からφの意味を与える説明、方向・向きへの不変性、正負交換による長さ不変、二つの商の等値、φの二値の一致への同値書換えとして接続する。原刊902頁の保存画像・本文を固定原文へ照合した。

ejdkは先行する同じ横棒の全点の運動と両端の全対象時刻の現在記録を保持する。ejdlは、Kでの正の同時刻距離として構成した測定長をl/φ(v)へ結ぶ。ejdmはalsoの帰結と、damitによる同じφの物理的意味の提示を区別する。距離自体はl/|φ(v)|であり、原文の符号付き商との一致が正の枝を選ぶという読みを明示する。先行式だけからその符号が証明されたことにはしない。

ejdnは同じ物質点・固有形状・固有長・尺度を持つ比較設定を使う。0<|v⃗|<Vの任意の三成分に適格設定が存在するという理想化を明示し、同速の全設定で測定長が一致する内容を述べる。方向Richtungと向きSinnを正負二例へ縮めず、異なる長さの設定を候補から取り除かない。ここでの速度のみに依存するという読みは、この対称性比較の条件の下で速度の大きさだけに依存することである。

ejdoはこの内容を主張し、空間の向きを特別扱いしないという対称性を理由として明らかだと著者が提示する。汎用の理由帰属eisn2は対象・速度・長さを原始語に埋め込まず、具体的な範囲と不変性をejdnに保つ。理由と明白さは著者への帰属であり、処理系による全物理法則の証明や実験的認定ではない。

ejdpは同じK/k・棒・尺度について、現在のvと別設定の−vでの測定長を同じ規則へ結ぶ。各設定の時刻と区間はその系の規約を保つ。ejdsは一般の不変性とこの二設定から、長さが変わらないejdrが従うと述べる。ejduはその同じ測定長の一致から、M0186のl/φ(v)=l/φ(−v)を提示する。保存MathMLの分数線を落とした平坦化文字列を積として読まない。

ejdvはoderを同値な書換えとして、同じ二設定の条件の下でφ(v)=φ(−v)へ進める。ejdtは二つの商の等値と二つのφの等値が同値であることを明示する。正のlと非零φを保持し、単なる選択肢や片方向の含意へ替えない。二値の一致は各値1を意味せず、前の相反積との合成は次のu0105へ残す。

今回の五つの著者主張は318–322番であり、既存318主張を保持する。局所検査では、前提と二測定の結合、引用の非実行、物理的意味・理由・明白さ・二つの帰結・同値書換えの各引数を対照する。数値核は正負を含む非零の係数で両方の等値を評価し、一致していても1ではない場合を残す。全方向と全物理履歴の局所検査は先行証拠を使い、全実数域の有限評価を拒否する。これらの検査と原刊の通読判断は別に記録する。
