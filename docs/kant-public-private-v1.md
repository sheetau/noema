# 規範と立場、公的使用と私的使用

[カントの公的／私的使用の草案](../examples/v011/kant-public-private.noema)を追加した。同じ人が職務を遂行する立場と、読者世界へ見解を提示する立場を区別する。前者を単に非公開、後者を単に人前で行うこととは定義しない。既存の0.11の型・関数・命題内容を使い、新しい文法は追加していない。

## 一般的な規範の記述

独立した[規範の定義集](../examples/v011/normative-roles.noema)には、2つの基本関係を置く。

```text
aa(source,person,role,goal,situation)  内容を満たすよう要求する
ab(source,person,role,goal,situation)  内容を満たすことを積極的に許可する
```

両方とも、出所・人・立場・内容・評価状況を明示する。同じ人でも別の立場の要求を取り込まない。別の出所の規範を自動的に統合したり、いずれかを優先したりもしない。

要求されていることから、実際に行ったことや、実行可能であることは導かれない。許可されていることと行ったことも別である。禁止は、内容の否定を要求することとして定義する。禁止がないことは、積極的な許可があることとは異なる。

定義集では、要求があり内容が成立していない状態、相反する要求、許可と禁止の併存、禁止と衝突しない許可を組み立てた。相反する要求があっても、内容そのものとその否定を事実として断言したことにはしない。関係のない要求をそこから導く規則もない。

これは規範の意味を記述するための関係であり、現実の規則を自動判定する処理ではない。記載を見つけられなかったことを「禁止がない」と変換しない。責任・罰・正当性・規範の優先順位・期限は、別の内容として記述する必要がある。

## 活動の種類と実行を分ける

草案の活動は、実行された出来事だけでなく、行うことを考えている活動の記述も含む。禁止されて実行されなかった活動を「自由であるべき活動」の対象から除かないためである。実行の事実には、別の関係`cg(person,activity,situation)`を使う。

公的使用の分類`da`は、本人の理性を使う活動であること、その活動を学識者として行う立場であること、読者世界全体へ向けることを要求する。学識者としての立場は、職業名や資格だけとは同一視しない。

私的使用の分類`db`は、本人に委ねられた市民的な職務と、その活動をその職務として行う立場を結び付ける。公的使用に分類されない活動を全て私的使用にする定義ではない。同じ職業の人が、別の活動では学識者として発言することを妨げない。

学識者、市民的職務、読者世界などの基本関係は、[意味規約](../data/kant-public-private-basis-v1.json)を与えた段階である。一般的な社会関係や役割の構成から、全てを定義し終えたわけではない。

## 許可を求めることと、現に許可すること

`dd(regime,person,role)`は、その人・立場で公的使用に分類される全活動について、指定した規範体系の許可があり、同じ指定の禁止と衝突していないという内容を作る。実際に行ったかどうかを条件にしない。全称の対象が空なら条件は真になるため、これだけで公的活動の存在を証明することにもならない。

この条件をさらに別の規範的な要求の対象にできる。`df`は、評価側の規範の出所が、規制する人に、その職務で`dd`を実現するよう要求することを表す。「自由であるべきだ」という要求があるが、現に自由な状態ではない場合を区別できる。

同様に`de`は、職務としての私的使用に分類される活動の中に、指定した規範体系が禁止するものがあるという内容を作る。`dg`は、その状態を実現することへの許可を表す。許可しただけで、既に禁止していることや、禁止する義務があることにはならない。

`dh`は、自由を求める要求を全ての評価状況について述べる。一つの状況で要求されているだけでは満たさない。ただし、原文の「常に」という時間範囲と状況領域の対応は、まだ確定していない。

自由を積極的な許可と禁止の不在だけで完全に定義したとはしない。物理的・社会的な干渉の不在や、権利の保護などは残る。私的使用への制限についても、原文の頻度・程度・啓蒙を妨げないという留保は未記述である。

## 原文との対応と検証

対象は保存した原文段落`kant-1784:u0012`である。[対応表](../data/kant-public-private-alignment-v1.json)には、公的使用を自由にすべきこと、私的使用を制限してよいこと、両者の定義という4箇所を選び、いずれも部分草案と記録した。選択外の範囲も文字位置を保存し、未処理とした。将校・納税者・聖職者についての長い各論を、検査用の役割の例だけで記述済みとは扱わない。

一般的な規範の12例と、公的／私的使用の17例を具体的な解釈で検査した。主な区別は次のとおり。

- 要求があるが実現していない場合と、実現している場合。
- 別の人・立場・出所に対する規範。
- 禁止の不在、積極的な許可、許可と禁止の衝突。
- 同じ人の職務上の活動と、学識者として読者世界へ向ける活動。
- 実行されていない活動の分類と、その活動を許可するよう求める規範。
- 制限することへの許可と、実際に制限されている状態。
- 一つの状況と、全ての評価状況にわたる要求。

原文の状況を自動推定した検査ではなく、明示的に与えた解釈で定義の区別を調べた結果である。学識者と公衆の意味、著者による定義行為の帰属、具体的な指示対象と時間範囲などは未完成で、確認済み全文単位数は依然0である。

## 再現

```powershell
python -S -m scripts.compose_kant_roles
python -S -m scripts.check_kant_roles --verify-only
python -S -m noema parse --input examples/v011/kant-public-private.noema
python -S -m noema render --input examples/v011/kant-public-private.noema --alphabet v2 --output artifacts/kant-public-private-v1.svg
```

モデルもZ3も使わない。合成した草案、意味規約、原文の対応範囲、検査用の29例と往復の結果を[記録](../reports/kant-public-private-v1.json)へ保存した。一般の規範の定義集は、カントの語彙を含めず単独でも解析できる。許可と禁止が衝突する公的使用の例も含め、リポジトリ全574テストが通過した。
