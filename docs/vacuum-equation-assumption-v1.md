# 第六節冒頭の仮定と成分説明

対象はu0153–u0155の一文である。静止系Kで真空のMaxwell-Hertz方程式を仮定する導入、コロン後の六式、wobei以下の二つのベクトルの意味説明を一続きに扱う。原刊907頁の三行二列の式では、電気側と磁気側の時間微分が交互に置かれている。

必要な関係は、同じK・領域・二場・光速度への適用、同じ文脈と単位、六式と実際の18偏微分への結合、仮定としての採用、式による具体化、成分の意味の説明、見出しからの順序である。既存ejsn/ejsm/eiscc/s5yを再利用する。ugは仮定、eischは呼称と内容、eisoxは表示箇所と内容、ufは説明の向きを保持する。旧文152の部分的な仮定だけを新しい本文で置き換え、旧版と旧定義は保存する。

場と領域は既出znl/znm/znkへ、系と尺度はra/ta/rb、速度はtcとtbへ固定する。場の四単位と二換算係数は同じ物理的な割当の証人として存在量化する。個々の実験が行われたこと、係数が1や1/Vであること、特定のSI単位は追加しない。物理的な規約と全領域での真空・六式は同じ仮定内容の内側へ置く。

(X,Y,Z)と(L,M,N)は、その同じ場の三成分を順に指定する表記として読む。新しい一般的な表記関係は、三成分場と状況を受け取る閉じた規約を指定表記へ結ぶ。物理的な意味は既存の場・単位の規約へ、同じ成分であることは領域内の全有効四座標での成分値の一致へ分けて構成する。関数実装の同一性や一地点の値だけで同じ場とはしない。識別表記の引用だけを概念の説明へ代用しない。

ここでのelektrische/magnetische Kraftは機械力の次元そのものではなく、当該系の電気側・磁気側の場の強さを表すという読みを明示する。電気側は静止試験電荷への力/電荷、磁気側は電気的寄与と区別した運動電荷への横向きの作用を用いる既存の規約を共有する。後のu0161で現れる磁気的質量についての説明を、この読みだけで処理済みにしない。現代の物質中のHや透磁率も補わない。

六式は既存s5t/s5uの18偏微分とs5wの符号・循環順序を使い、正のVの下で分母を払った形で表す。真空という条件から発散零を自動で導かず、六回転式の表示へ発散条件を足さない。原文のso daßはここでは後続の式による仮定の具体化として読み、真空の存在から方程式を証明したという推論へ変えない。

検査では、同じ証人の結合を小さい区別可能な域で調べ、物理的な下位規約は既存の検証記録へ接続する。全四座標での成分比較は診断用の二点代入と実際の点ごとの本体を分け、全関数域の有限列挙拒否を保持する。式の符号・成分順・偏微分軸を原刊と固定MathMLに照合する。局所検査、原文の通読判断、物理法則の真理は別々に扱う。
