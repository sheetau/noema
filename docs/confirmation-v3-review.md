# 確認資料v3の予測前点検

資料のSHA-256は `941dfd3e27dbab155c0d192e529d0f4b2917e6c41978864d4ef46f404f93cb72`。点検はモデル予測を取得する前に行った。前回までの学習・開発・回帰・確認資料と、手書き回帰の文および完全な意味構造との重複はない。

1,392文すべてについて、文字範囲・型・参照・同義グループの内部整合性を検査した。さらに各述語の日英・能動受動の代表例24文と、追加した未対応48文を読んで、役割・数量・肯否・時間の対応と代名詞の格を点検した。これは独立した人手注釈者による全件評価ではない。

## 対応例

- 「今後、2048人の先生はTheoを公園で追わない。」と「公園で今後、Theoが2048人の先生によって追われない。」は、先生が主体、Theoが対象で、未来の否定として対応する。英語の `will not chase` / `will not be chased by` も同じ役割になる。
- 「13匹の犬は13人の子供を家で見た。」と `13 dogs, in the home, saw 13 children.` は数量・場所・過去を保持する。
- 「Noelは41羽の鳥によって公園で助けられない。」はNoelが対象、鳥が主体。否定の助ける出来事である。
- 「今後、29人の先生は子供に41冊の本を公園で渡さない。」は主体・対象・受け手・場所を区別する。受け手の子供の数量は未指定。
- 「今日、8192人の子供は眠らない。」は数量・相対時間・否定を保持する。
- 「今日、41匹の猫は家で空腹でない。」は状態の否定である。

大量の数量や動物の行動には現実的でない例がある。これは数量と役割の保持を測る人工文であり、自然な使用頻度を再現する資料ではない。

## 未対応例

代名詞は「彼女」と英語の主格 `she`、受動態の `by her` を区別した。日本語は「彼女によって」とする。名前／抽象概念は勇気・幸運・真実、Courage・Luck・Truthへ置換し、それ以外の節構造は維持した。これらの名前としての解釈を否定せず、文脈なしで指示対象が一意にならないときの保留を測る。

追加48文は追う・見るの文に偏っている。今回の区分別条件を通っても、全述語や自由な文体における参照解決を検証したことにはならない。質問などは文語では書けるが、今回の15概念・単一出来事の解析器では未対応のままである。
