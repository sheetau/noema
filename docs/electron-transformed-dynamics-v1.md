# 共動系からK系への初期運動式(A)

u0250–u0251を、直前の七変換式を用いて同じkの運動三式をKへ表し直す一群として読む。原刊918頁の導入と三行、式ラベル(A)を対象とする。前の「小さいt」はKの時刻であり、kの微分変数τと区別する訂正版の読みを保つ。

先行PAIRが持つ同じ電子・出来事・二つの完全な局所履歴に、両系の三速度関数と実二階微分を結ぶ。初期のK速度(v,0,0)における時刻変化率はdτ/dt=1/βとなる。したがって加速度の接続はa′x=β³ax、a′y=β²ay、a′z=β²azとなる。これを物理設定の前提に埋め込まず、条件付きの変換内容として保持する。

同じ七式による新電場の値と、kのμa′=εE′を結ぶと、Kの三行はax=εX/(μβ³)、ay=ε(Y−vN/V)/(μβ)、az=ε(Z+vM/V)/(μβ)となる。三加速度は同じKの座標時刻の二階微分であり、電場・磁場は同じ旧四点で評価する。単に三つの独立した数値を等置した式にはしない。

法則の参照個体には、すべての適用設定の全対応記述について、viによる適合と(A)の初期運動内容との同値を要求する。この内容対応だけでは法則の真理を認定しない。別に、同じ設定と同じ法則が先行の質問ek4xの候補ek4wを満たすという内容を結ぶ。候補の存在を著者の提示の外側で断定せず、唯一解や実験確認も加えない。

die obigen Bewegungsgleichungenは先行のkの三式、dieser Gleichungenは直前の七変換式を指す。前者をKの結果へ先取りして置き換えない。既存の照応、推論提示、命名、式表示、説明、順序と著者帰属を使い、両系の向きを式の共有引数と同じ系の表記へ結ぶ。途中の加速度変換は意味を接続するための定義であり、原刊に追加の表示式があるという主張ではない。

解析的な対照には、Kのx(t)=vt+A t²/(1+bt)、y(t)=B t²/(1+bt)、z(t)=C t²/(1+bt)、b=β²vA/V²を用いる。対応時刻はτ=t/[β(1+bt)]で、逆はt=βτ/(1−βbτ)。極を避けた対応する開区間を選ぶと、両系の軌道と速度を有理関数として厳密に評価できる。A≠0も使い、縦加速度を零にしてβ³の取り違えを見逃さない。保持した関数の係数から解析的に微分し、未知の関数を有限標本から推測しない。物理的な履歴帰属は明示したモデル入力であり、全実数の量化、一般の連鎖律、原文同義性の自動証明とは区別する。
