# 芽の対象側と、同じ制度下での発達

第十段落第四文の前件について、二つの思考性向の発達を第三文の低い市民的自由の側へ接続する。「芽、すなわち自由な思考への傾きと内的な促し」は、同じ二性向を名詞化して説明する同格として記述する。第四文全体の意味判断はまだ追加しない。

発達する本人、共同体、法秩序、比較範囲と固定基準を前文から保つ。低い側という名前だけでは比較を成立させず、全関連成員・市民的行為について、許可集合が高い側の真部分集合であることを既存の定義で要求する。発達の開始・終点とその間の全履歴で、同じ低い法秩序を運用し、許可集合を比較時点と一致させる。一人の態度が発達した間に別の成員の許可が増減した場合も、この読みの条件を満たさない。

制度の比較時点、心理的な発達の始点と終点、性向を診断する仮想的な通常場面は別に扱う。発達には既存の潜在性・変化過程・両端の有効な評価・終点の両性向を要求する。制度を保持するのは両端を含む発達区間であり、履歴に含まれる区間外の時点まで同じ制度を要求しない。許可集合を固定するのは、前文の同じ条件下で発達するという明示した強い解釈であって、原文が制度上のあらゆる変動を禁じたという主張ではない。

同格には、芽の句と説明句が異なる箇所であること、同じ著者・論述範囲・提示文脈で同じ性質記述を指すこと、本文上の順序、後の句が前を説明する関係を必要とする。指す性質は、前回構成した二性向の連言である。その引用を組み立てて指示しても、本人の応答や思考活動を実行評価しない。性質を持つ人、性質そのもの、発達過程、描写側の植物個体を同一にしない。

検査では二性向と発達の既存本体、市民的許可と反対要求、許可集合の真包含、同格の既存本体を実評価する。公的法秩序の成立だけは、既存検査を保存した上で呼出境界として扱う。制度の途中変更、別人・別過程への交換、許可の増減、同格の片側欠落・逆順・別の指示内容を検査する。存在量化の接続は二値の個体域と引数別の不一致検査で確認し、同格については心理入力が未知でも指示が成立することと、引用を明示的に評価した場合の二性向の真理表を分けて確認する。

自然の意味と擬人化、描写側の植物の芽・硬い覆い・世話は未統合である。保存済みの旧候補を消さず、次の作業でこの対象側へ対応させる。条件文全体への人口・時点の量化、民衆への漸次の反作用、行為能力、政府原則と利益判断、尊厳、著者注参照も必要である。正本122主張と既存の意味確認範囲を保持する。
