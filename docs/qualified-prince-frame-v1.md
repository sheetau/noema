# 君主の条件と、名称拒否への帰結提示

第八段落第一文の二つの関係節を、同じ人物・役職・共同体へ接続した。君主的な最高職の保持、自己報告を品位に反しないと考える本人の判断、名称の自分への適用拒否という三条件を共有する。別々の人物がそれぞれの条件を満たすだけでは、この人物の条件は成立しない。

君主の範囲には既存の最高役職の構成を使い、今回の役職を品位判断や義務の役職と同じ引数に保った。統治制度の役職の全範囲と上下関係、唯一の保持、同じ共同体への任用・委託を調べる。世襲や特定国を条件にせず、世界でただ一人の統治者という主張にも変えない。

この人物条件から結論へ進む一般条件、該当する人物の存在、結論を満たさない反例を別々に構成した。一般条件が真でも、そのような君主が実在するとは限らない。結論は後続の啓蒙・称賛を接続する引数として残す。条件の中には本人の品位判断を置き、内側の義務判断、実際の義務・自由政策、自己報告の実行を追加しない。

alsoは、同じ仮定範囲で前の人物描写を前提として採り、同じ人物による名称拒否を帰結として提示する働きとして構成した。本文順序と帰結提示を既存の関係で結ぶ。著者が帰結として提示することと、その推論の妥当性、人物の心理的因果、現実の名称拒否は別である。

selbst den hochmüthigen Namenは、今回は「その名称さえ」という目的語の取り立てとして採る。[IDSの焦点助詞の説明](https://grammis.ids-mannheim.de/systematische-grammatik/408)を文法上の補助とし、具体的一文の唯一の解釈をそこから導かない。資料は検索で取得した本文の範囲を保存し、直接取得した完全なページとは区別した。名称への拒否がそこまで及ぶという期待背景を、同じ節・範囲・名称へ結ぶ。von sichによる本人照応と、後続のist selbst aufgeklärtの本人への焦点は分ける。

談話へ渡す人物性質は段階7の閉じた記述にそろえた。同じ人物引数を範囲・前提・帰結の性質へ共用し、八個体と固定基準の呼称が元の設定を指すことを検査する。提示関係を評価する際には、実際の役職保持、品位判断、内側の義務、名称拒否を実行しない。

検査は三条件の8通りと引用した条件の実評価、別人物・役職・共同体の取り違え、一般条件と存在と反例、前提採用・帰結提示・取り立ての同一設定、全呼称の参照、未知入力、段階7の引用を調べる。全称量化の接続検査では、別に実評価した三性質を境界で置き換えて小さい人物域を使い、検査範囲を記録する。

名称の高慢評価を著者に帰属する部分は、君主の条件へ隠さずに全文で接続する。全設定と本文箇所の固定、sondern、具体的な啓蒙と称賛、最初の政府側の解放、良心事項の理性使用と一文全体の判断は残る。本文112主張と確認済み17区間は変更しない。
