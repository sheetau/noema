# 数値を使わない独立判断への性向

従来の `hzhh` は、有限の場面一覧と評価済みフラグ、重み、閾値を必須とする応答プロフィールだった。これは指定した測定条件での成績を表せるが、性向をその採点方式に限定する。新しい候補では、文脈上より通常とみなす場面の比較から、例外を許す応答条件を作る。

構成の参考にしたのは、Kraus・Lehmann・Magidorの極小状態に基づく意味論である。同論文の定義4は各状態と極小状態の関係を、定義8は極小状態全てでの成立を用いる。本実装は一つの明示した候補範囲に対する条件であり、論文の推論体系全体や全ての部分範囲の性質を実装・証明したものではない。[原論文](https://arxiv.org/abs/cs/0202021)

`preferred(first, second)` は、同じ本人・基準状況について、第一の仮定場面を第二より通常とみなす比較を表す解釈引数である。本人が場面を好むという心理的な好みや、場面の数値確率ではない。比較自体を「独立して考える」という未説明の真偽値に置き換えず、候補ごとの応答は既存の独立判断の定義で評価する。

| 定義 | 条件 |
| --- | --- |
| `rqt2` | 候補範囲に属し、その範囲の他の場面に劣後しない場面を選ぶ |
| `rqt3` | 比較の非反射性・推移性を検査し、全候補が極小であるか極小候補に劣後することを求める |
| `rqt4` | 極小候補が少なくとも一つあり、その全てで応答が成立することを求める |
| `hzq3` | 同じ本人・基準状況の比較と候補範囲へ、同じ話題についての独立判断 `hzhg` を渡す |
| `hzq4`・`hzq5` | その性向を同じ本人の自己離脱・存在する伝播と、将来の集団条件へ接続する |
| `rqt5`・`rqt6` | 許可期間を共用し、条件付きの内容族と比較用の枠を構成する |

通常とする候補で応答が成立し、劣後する候補で失敗する場合は認める。比較不能な極小候補での失敗は残り、成功した一候補だけを採用しない。候補が空の場合や、極小候補を欠く場合は成立としない。状況全域への量化を使い、候補列の長さ上限は定義しない。ただし、有限評価器の検査から無限状況についての成立を推定しない。

候補範囲と比較を結果を見て都合よく選べば、性向を正しく表せるとは限らない。どの仮定場面が適切か、何を通常とするか、現実の本人と仮定場面をどう対応させるかは解釈条件として残る。この条件だけを性向の心理的説明や `Selbstdenkende` の唯一の語義にはしない。

既存 `hzhg` は、人であること、同じ話題が提示されること、その話題への独立した理由ある判断 `h5c` を要求する。今回もこの本体を実行する。現在の一回の判断がなくても仮定場面での性向を述べられ、現在の成功だけから性向を認めることもない。想像・疑問・探索など、判断以外の思考は引き続き未記述である。

五項目のテストを行う。

- 三場面上の全512関係を、関係の合成による独立した判定と比較し、19の厳密な半順序を受理する。その19関係について、応答の152組合せを調べる。
- 例外の失敗、比較不能な失敗、通常候補の失敗、循環、空範囲、範囲外の場面、未知入力を区別する。
- 実際の `h5c`・`hzhg` を用い、他人の指導への依存・理由の不足・話題の取り違え・現在の判断だけの成功を検査する。
- 加重プロフィールの入力を未知にしても新しい性向を評価できることと、理由の支持が未知なら確定しないことを確認する。
- 閉じた伝播内容と期待背景を、同じ本文箇所・著者へ帰属できることを確認する。
