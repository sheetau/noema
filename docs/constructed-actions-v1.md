# 公的提示の行為記述を一般許可へ接続する

前回の主張・目的の記述合成を使い、既存 `hzgy` の公的提示全体を、閉じた行為記述として構成できるようにした。その同じ構成結果を、一般許可文の資格条件へ接続した。判断、採用基準との差、自己帰属を持つ提示、吟味目的への意図を一つの対象に保つ。

本文では、前回の部分草案16文のうち最後の一文を改訂した。従来の資格範囲を指定する原始値 `hzjc` は、改訂した一文から参照されなくなった。対象者・活動に選んだ記述枠から行為を構成し、対象記述と公的役割が一致することを条件にする。著者・発話箇所・原文範囲・文脈は保持したが、旧文と同義であると確認した改訂ではない。

## 行為を構成する定義

`hzgy` では、本人の基準と標準基準の記述を参照するとともに、その内容を評価する。これを引用可能な行為のひな形へ移すため、二つの基準を仮の閉じた記述に静的特殊化し、明示的な脱引用3箇所を取り除いた。その後、実行する関数の参照と、基準の記述としての参照を別々の引数へ抽象化した。

この変換はモデルを実行しない。特殊化で展開した定義と、記述・実行それぞれの置換件数を保存した。仮の記号は最終成果物に残さず、既存の型検査と引用検査を通している。

| 定義 | 役割 |
| --- | --- |
| `rqd` | 基準の実行関数と、その基準の記述を受け取る行為のひな形。既存 `hzgy` から導出する。 |
| `rqe` | 各基準の一つの記述から、実行関数と記述値の両方を渡す。主張 `rqa` と目的 `rqb` も内部で作り、閉じた行為記述を返す。 |
| `rqf` | 許可の対象記述が、同じ入力から作った行為記述と構文として一致することを確認する。 |
| `rqg` | 本人・活動に選んだ枠があり、`rqf` と、公的役割の一致を満たすことを確認する。 |

`rqd` だけなら、実行関数と記述を別々に渡せる。同じ基準であることは `rqe` の構成によって保証し、資格条件でも `rqf` を使ってその構成結果に一致することを要求する。実行関数だけを他の基準へ差し替えた記述は受け入れない。

## 本文の資格条件との接続

枠には、論点、本人と標準の基準、判断と基準を結ぶ関係、比較候補、組織と採用関係、役割、公衆、受け手、経路、発話の帰属先を持たせる。各項目を閉じた式の記述として渡すため、行為記述を作る段階では内容を実行しない。主張と目的は独立した差替え入力にしない。

`hzkeligible` は、対象記述が構成した行為記述と一致し、その枠の公的役割が、一般許可で照会する本人の公的役割と一致することを確認する。枠の選択は本人・活動・基準文脈ごとに行える。同じ人物や同じ活動の枠を一つに固定する条件は加えていない。

`hzkclaim` は、既存 `rpu` の資格条件をこの `hzkeligible` に置き換える。他の人々の範囲、本人ごとの職務義務、比較候補、権限側、役割、基準文脈は、前回の指定を引き継ぐ。義務との非制約条件と許可には、引き続き同じ対象記述を渡す。

資格条件は、対象行為が今実際に行われたという条件ではない。提示の内容や意図が実例で欠ける場合、構成した行為内容は偽になるが、その記述への許可は独立して照会できる。許可の全条件には既存の非制約条件もあり、資格だけで許可や実行可能性を認定しない。

## 検査の範囲

追加43テストが通過した。元の `hzgy` と構成後の行為記述に同じ基準・主張・目的を渡し、提示・意図・許可・実際の吟味の16組合せで、行為内容の結果が一致することを確認した。許可や目的の実現を、行為そのものの成立へ混ぜていない。

13種類の比較では、判断者、論点、標準基準、判断候補、主張、目的、発話の帰属先、公衆、学者の役割の取り違えを、元の行為定義と同様に区別した。別の対象への許可、反対要求、枠の不存在、許可側との役割の不一致も確認した。枠の不存在と役割不一致の検査では、本文から取り出した実際の `hzkeligible` を使用した。

構成と構文一致の検査だけでは、基準や行為を実行しないことを確認した。基準の関数と記述を混ぜた二つの不正な構成は拒否した。未知の枠選択を偽で補完する処理は設けていない。

本文と抽出文書の双方で、著者への帰属は引用内容を実行しないことを確認した。一般許可の全記述量化をそのまま評価すると、有限評価器は拒否する。選んだ枠や既知の引用一覧を、全記述領域の代わりにはしていない。有限モデルでの比較は、全域の意味一致を証明するものではない。

## 残る意味確認

今回は行為の構成を本文に接続したが、選んだ枠が原文の対象となる公的提示を尽くすことは確認していない。構文一致は任意の同義記述より厳しく、別の書き方を自動的に同じ対象へまとめない。一枠では一論点の提示を扱うため、複数の判断や洞察を一度に示す一般化も残る。

特殊化による意味保存は、値の等しさを尊重する全域的で純粋な解釈を前提とする。評価順序、資源消費、途中で失敗する解釈関数の挙動まで同じになるとは主張しない。今回の有限検査はその前提下の具体例である。

対象人口、聖職者・学者・公衆・教理の意味、君主への照応、全職務と比較候補の同定、「なおさら」の論証、原文全体の意味確認は未完である。標準版には未採用の草案であり、248件・566文書の原文対応集計と意味確認済み区間0件は据え置く。
