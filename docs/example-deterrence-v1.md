# 例による萎縮と、通常起こる回避

カント第二段落の末尾に、一つの不成功例による萎縮と、その後の試みを通常思いとどまらせるという部分草案を接続した。原文の `gemeiniglich` と `allen ferneren Versuchen` を同じ全称条件へまとめず、事例間の通常性と、各事例内での後続する試みの全範囲を分けている。

## 二つの範囲

一般定義 `r6` は、対象範囲が非空で、その全項に同じ人物・文脈の関係が成立することを要求する。原文では、現在問題となる自立的な活動の試みのうち、予定・想定時点が後であるものを範囲にする。過去の行為、現在の行為、別の仕事を試みる行為は含めない。実行された行為の一覧ではない。

一般定義 `r7` は、重複のない非空の適格事例列で、指定した性質の割合が過半数であり、文脈の基準も満たすことを要求する。例外を許す。有限の等重み事例を使った操作的な読みであり、通常性の唯一の意味、無限母集団の測度、現実の統計的な頻度を確立したものではない。

原文への接続では、事例列が評価範囲を過不足なく含むという既存の `hr` も要求する。回避しない事例を削って割合を高くした列や、同じ事例の重複を拒否する。これは与えられた網羅性の前提を検査に使うことであり、現実の代表的な資料を自動収集する機能ではない。

## 例を知る人と、経験した人

各事例には、対象者と一つの経験行為を結び付ける。経験行為は、ある人による同じ自立的活動の不成功経験 `fg` であり、対象者がそれを認識する。対象者が自分で失敗したことや、直接目撃したことは要求しない。伝聞で知った他者の経験も、この関係に含められる。

「一つの例」は、その事例で結び付ける例を一つにする。世界にそれ以外の例がないという唯一性や、同じ人がそれまでに一度も失敗していないことは追加しない。

| 定義 | 内容 |
| --- | --- |
| `gq` | 同じ人について問題となる、後続の自立的活動の試み |
| `gr` | 対象者が認識した、先行する一つの不成功例 |
| `gs` | 同じ目的へ行動する勇気が十分でなく、後続の試みに害への恐れがある |
| `gt` | 非空の後続する試み全てを、その害への恐れを理由に避ける |
| `gu` | `gr` と `gs` が成立し、その例が萎縮の原因説明に採用される |
| `gv` | `gr` と `gt` が成立し、その例が回避の原因説明に採用される |
| `gw` | 事例が適格で、対象者が人であり現在の対象集団に属し、例の条件も満たす |
| `gx` | 網羅性を明示した事例列で萎縮が成立し、回避は過半数と文脈基準を満たす |
| `gy` | `gx` の部分解釈を著者へ帰属させ、学習の見込みの後という本文順を保存する |

恐れだけでは回避としない。単なる未実行や実行不能とも分け、本人の回避、恐れを理由として採用する関係、例を原因として採用する説明をそれぞれ確認する。外部から物理的に妨害されたという介入モデルは、この回避の定義には用いない。原因の説明と、現実の因果機構の証明も区別する。

`macht ... schüchtern` の無修飾の部分は、明示した評価事例で萎縮が成立するという読みを採った。一方、回避については同じ事例列で例外を許す。この一般文の作用範囲が唯一この通りだと確定したわけではない。恥ずかしさ等を含む語義、恐れの増加、架空の例の扱いも未解決である。

## 検証と残る意味

全項への適用16例、独立した計数との割合照合126例、不正な割合評価5例、原文接続21例、未来の対象範囲5例、著者への帰属5例を検査する。割合の検査では、例外があるまま成立する27例を含めた。原文の基準例も3事例中2事例の回避で成立し、回避しない1事例を落とした資料では成立しない。同じ全事例の並べ替えは受け入れ、全事例を含んでいても成功例を重複加算した列は拒否する。

人物・例・仕事・理由・原因説明の取り違え、単なる未実行と回避の混同、勇気がある場合、1項だけ避けていない場合、対象集団外や人でない対象者、評価事例が空の場合も検査する。既存の定義を検査用の基本述語に置き換えてはいない。一般文書は既存の算術基本述語5・定義13、原文接続文書は累計基本述語144・定義194である。

この追加によって段落末まで部分草案がつながったが、段落全体の意味確認が終わったわけではない。`allein`・`doch` の譲歩と焦点、文字通りの転倒・歩行と比喩の対応、先行する認知状態の変化、因果機構と語義、事例の代表性、原刊照合は残る。本文の既存8主張は維持し、今回の部分解釈を無条件に実行する主張としては追加していない。
