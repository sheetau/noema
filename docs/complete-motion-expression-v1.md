# 三関係による運動法則の完全な表現

原刊921頁のu0275を、第三項の最終表示と謝辞の間で確認した。「この三つの関係」は第一項の全偏向条件・比・任意速度の決定、第二項の実電位と積分・獲得速度式、第三項の全加速度等号列・半径表示・条件付き書換えへ戻す。

`vollständiger Ausdruck`は、同じ背景に属する全候補運動について、三関係を満たすことと、当該理論が許すこととの双方向の一致として読む。[旧来の範囲相対的な表現](law-characterization-v1.md)の必要条件・十分条件の区別を保ち、状況を比較域とする。三関係を満たすのに理論は許さない場合と、理論は許すのに三関係が排除する場合は別の反例である。候補範囲は非空とするが、理論自体の整合性や実現済みの運動を追加条件にはしない。

旧数値射影`sevy`は使わない。第二項の図式は、同じ電子・K・V・低速質量・電荷・単位校正と緩加速の基準を固定し、初期と終端、全軌道、場、電位関数と区間、獲得速度、エネルギー、記録を全称化する。`eud`の初速零・静電過程・無放射・閉収支等が適用される場合に、`er7`と`esa`の全内容を要求する。検査対象の速度式を適用条件へ含めない。

第三項も全局所事例を全称化し、`esp`の実幾何学的半径、同じ単位、標準方向qN>0、磁気だけによる偏向という条件の下で、両表示とその条件付き同値を要求する。接線加速度、軌道の変化、局所的な場の値を固定しない。元の第二・第三項の値を代入すると、既存の全内容`esd/euo`へ戻ることを式の構造で検査する。第一項は既に全速度・全試行にわたる`eun`を再利用する。

比較範囲を示す一般的関係`eis6w`は、固定した背景の下で同じ対象・系の全候補運動を指定する。基本的な運動学と量の意味を保ち、比較する動力学の結論に反する候補も含める。理論が許す状況だけ、測定できた状況だけ、式が合った状況だけを選ぶものではない。候補でも同じ校正背景`eu6`を要求し、許容を既存の独立した`eisoe`で評価する。

`gemäß vorliegender Theorie`と`muß`は、この論説の理論内で許される運動への制約として扱う。義務、因果的強制、物理的真理、実測一致の認定にはしない。何も適用されない事例はその関係では制約されず、全三関係が同時に適用されることや互いに独立であることを補わない。原文の射程を、この明示した背景・適用条件の読みで記述する。

局所検査は、双方向の一致と二種類の反例、範囲の拡大と空範囲、三内容の欠落、全称束縛の全位置、未知の関数域の拒否、元の全文内容への特殊化、著者と参照の役割を確認する。高階の全領域の成立や物理的完全性を有限診断から認定しない。原文全体の意味判断は検査とは別の記録に置く。
