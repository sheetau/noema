# 秩序と公的批判を、到達条件まで共に保つ

カントu0013の、導入された秩序を維持しながら各市民に公的批判を認める部分へ草案を広げた。秩序の存続と批判への許可を同じ時点で評価し、その状態が指定した到達条件まで続く構成を追加した。

| 定義 | 内容 |
| --- | --- |
| `rkh` | 指定点が基準点以降の最初の到達点であり、それより前で維持内容が成立する |
| `rki` | そのような到達点が存在する |
| `rkj` | `rki`が成立するか、到達条件が一度も成立せず維持内容が続く |
| `rkk` | `rki`に加え、最初の到達点自体でも維持内容が成立する |
| `rkl` | 同じ制度が存続し、各市民に該当活動が少なくとも一つあり、その全てが許可される |
| `hzeb` | `rkl`の活動を、同じ立場・公衆・経路・制度・批判内容の公的使用へ接続する |
| `hzec` / `hzed` / `hzee` | `hzeb`の状態を、到達を要求する継続／要求しない継続／到達点も含む継続へ接続する |

基準点と到達点は、一つの固定した履歴に属する。到達前の全点を検査するため、始点と終点だけで秩序や許可が成立していても、途中に欠落があれば継続は成立しない。最初の到達点を要求し、既に到達条件が成立した点を飛ばして後の点を採用しない。

到達条件まで続くことは、そこで制度が廃止されることを意味しない。到達点以後も制度と許可が続く場合を排除しない。また、到達点自体での維持を要求するかどうかを分けた。基準点ですでに到達している場合、到達前の期間は空なので`rki`は維持内容を要求しないが、`rkk`はその基準点でも維持内容を要求する。

各市民の所属と許可は時点ごとに評価する。途中から市民に加わる人を、基準時点にいなかったという理由で除外しない。ある人への許可を別の人へ移したり、ある時点の許可を期間全体へ広げたりしない。該当する公的活動が一つもない人について、全活動への許可が空虚に成立したと扱わない。ただし市民集合自体の存在や、活動の物理的な実行可能性は別の条件である。

批判内容には、既存の`reu`へ条件列を渡した不足の指摘を使う。対象は同じ制度に固定する。批判への許可を評価するだけなら、その指摘の真理や実際の発話を評価しない。制度が存続していること、公的活動として分類されること、その活動が許可されることを別の条件として結ぶ。

一般検査は三時点の維持・到達の64通りを扱い、位置による独立した判定と比較する。原文側の検査は制度存続・二人の許可・到達の16通り、途中の欠落、境界点の扱い、該当活動の不在、別制度、反対要求、途中で加わる市民を扱う。未知の時間・制度・規範関係は偽として補わない。

[一般文書](../examples/v014/provisional-order.noema)は1,526文字、[原文付き草案](../examples/v014/kant-provisional-order.noema)は147,831文字、[抽出文書](../examples/v014/provisional-order-core.noema)は3,884文字である。九定義を追加し、原始記号と著者主張は追加していない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-provisional-order-basis-v1.json)と[検査記録](../reports/provisional-order-v1.json)を保存する。

最初の到達点を要求するのは今回の明示的な読みである。密な時間順序で到達点集合に最小点がない場合は強い継続条件を満たさない。また、有限履歴で到達せず維持できたことは、現実の無限持続の証明ではない。

理解の公的な進展・確認・提案可能性を含む具体的な到達内容、一定の短い期間、改善への期待、聖職者についての強調、改正・保護・妨害禁止、著者帰属は未完である。到達内容を渡せることだけで、後続節まで記述済みには数えない。

新規8件と既存の時間・職務発話の回帰検査14件、計22テストが通過した。三文書のCLI解析結果が構文木と一致し、抽出文書の固有文字v2のSVGがXMLとして正常であることを確認した。SVGの目視確認はこの検査に含めない。
