# 経験による能力取得と、その見込み

カント第二段落の「何度か転ぶことで、やがて歩くことを学ぶだろう」という箇所に、自立した理解力の使用へ対応付ける部分草案を追加した。経験の時系列、能力の変化、経験の寄与、将来への見込み、著者による理由付けを分けている。文字通りの転倒・歩行の描写と比喩の対応は未完成である。

## 取得を表す条件

一般定義 `r4` は、経験の非空列と各経験の時点を受け取り、開始以上・終了未満の順序を検査する。同じ行為の重複や順序の逆転を拒否する。時点比較は、厳密な時間順序を表すという引数の意味規約に依存する。任意の関係の推移性を認定する検査器ではない。列は関数の合成で一回ずつ処理し、経験の増加に対して同じ接頭列を繰り返し評価しない。

一般定義 `r5` は、次の条件を同時に要求する。

- 同じ本人について、能力評価が前後とも整合している。
- 前には能力がなく、後には能力がある。
- 同じ変化過程が二状況を結び、その本人が変化を受ける。
- 時間順に並ぶ各経験が本人のもので、同じ能力変化の過程へ寄与する。

この寄与は、単に先に起きたという事実から導かない。寄与関係は明示した意味規約として与え、具体的な認知機構の説明は未完として残す。選んだ経験全ての寄与を要求するが、人生の全経験を列挙したり、各経験が単独で必要十分な原因だとしたりはしない。既存能力の程度的な改善も、この「ない状態からある状態へ」の取得とは区別する。

## 原文への接続

| 定義 | 記述する区別 |
| --- | --- |
| `fg` | 本人による同じ活動の試みと、非空の実際の結果での不達成 |
| `fo` | 実行可能な全方法について、能力評価の対象が整合していること |
| `fp` | 文脈の少数回基準を満たす不成功経験から、本人の能力が変わる過程 |
| `fq` | その過程が終わる状況。過程は人や候補ごとに異なってよい |
| `fr` | 非空の将来候補全てで `fq` が成り立つという見込み |
| `fs` | 現在の非空の対象集団全員について、同じ文脈から `fr` を見込む |
| `ft` | 著者が `fs` を「危険はそれほど大きくない」という `e4` の理由として示す関係 |

`fg` の結果は、方法一般の可能な結果候補とは別の、経験行為で生じた結果である。結果が空なら不成功とは数えない。また、「何度か」に固定の回数は割り当てず、回数基準を文脈の引数で保持する。見込みを調べる間、この基準を将来の文脈へ取り替えない。

能力そのものには既存の `up`・`xd` を使う。単に成功例が一つあるだけでは足りず、選んだ評価対象が非空で想定結果に含まれ、その全てで目的を達成する方法を要求する。評価の欠落を不能と扱わないため、前後の `fo` も確認する。

`fr` は `würden ... wohl` の明示的な解釈候補である。経験や能力取得が実際に起きたとは断定せず、数値確率も補わない。`ft` は主張の帰属と理由付けを表し、「学べるなら必ず危険が小さい」という論理的含意にはしない。今回の定義は本文の既存8主張へ無条件に追加していない。

## 検証

経験列と時点割当て2,560例を独立した順序判定と照合した。24経験の列も5,000評価ステップ以内で処理できることを検査する。能力評価・前後状態・変化過程・寄与の64組合せと、人物・過程・時間の結合を壊す8例を用意した。

原文の接続では20例を検査する。評価が欠ける能力、未知の結果、成功した試み、他者に指導された成功、別人の経験、寄与のない経験、重複、逆順、空の見込み、現在を将来とする誤り、悪い見込み候補の追加、対象者のない集団を区別する。理由付けの7例では、著者・内容・根拠と結論の方向・本文順を確認し、内容を実行評価すると例外になるモデルを使う。

一般文書は基本述語0・定義2、原文への接続文書は累計基本述語135・定義183である。追加した基本関係には、行為に結び付いた試み、結果、時点、経験列、過程への寄与、予想候補、回数基準、談話箇所がある。これらの入力を自然言語から自動で推測する翻訳処理は含まない。

身体的な転倒・歩行、経験が能力へ作用する機構、熟達度の改善、様相の語用論、譲歩と後続の萎縮・断念、原刊照合、全文の意味一致は残る。今回の原文範囲は部分的な解釈であり、意味確認済みの全文区間として数えない。
