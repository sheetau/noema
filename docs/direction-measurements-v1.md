# 方向記録を二点の座標差へ結ぶ

前版では、方向記録の数値が同じ正方向を示すことを比較したが、その数値と実際の軸の位置座標との関係は説明していなかった。今回、選ばれた全方向記録を、その記録に結ばれた二点と一つの観測時点へ接続した。方向の各成分は、共通の観測座標と単位による「終点の座標−始点の座標」に一致しなければならない。

この接続は、位置の測定方法や正方向の校正の完成を意味しない。座標の利用可能性、物質点の配置、記録への帰属には明示した意味規約が残る。

## 一つの記録に課す条件

汎用定義`sexk`は、次の条件を同時に要求する。

- 同じ記録に、始点・終点・一つの観測時点がその順序で結ばれている。
- 始点と終点は異なり、どちらも同じ対象の配置を表す点である。
- 両点の三座標が、同じ時点・座標系・長さ単位・状況で利用できる。
- 三つの成分の役割が異なり、各方向成分が同じ二点の符号付き座標差に等しい。
- 方向全体が零ではない。

成分の差には、有理数の`sexi`と実切断の`sexj`を用意した。始値・終値・増分の有効性は実切断側で検査する。成分の一つが零でもよいが、三成分すべてが零の方向は受け入れない。

記録の項目候補を取り出す`zsc`と、実際に記録へ結ばれた順序付き二点・時点を表す`zsd`を追加した。項目の添字は0が始点、1が終点、2が観測時点である。候補を取り出せたことだけで実際の記録と認めない。`zsd`も成立する必要がある。

## 既存の本文への接続

本文用の`sexl`は、既存の配置点`zcc`、位置座標の利用可能性`zce`、位置座標`ym`、方向成分`zsb`を汎用定義へ渡す。二点を別々の時点に置き換える引数はない。同じ観測時点を両端の座標へ渡す。

`sexm`は、既存の帰属`zsa`が選んだ全記録にこの条件を課す。不一致な記録を除外した集合を新しく作ることはしない。正方向の比較には元の記録範囲をそのまま使い、空の範囲は前版の条件で拒否する。

新しい配置条件`sexn`は、二系・符号付き速度への参照、元の物理配置、三軸の正方向の一致を保持した上で、両系の全方向記録を座標差へ結ぶ。[累積本文](../examples/v014/einstein-direction-measurements.noema)の206文中、密度式の引用にある一引数だけを改訂した。他の205文と既存の宣言は変えていない。[抽出本文](../examples/v014/direction-measurements-manuscript.noema)と[汎用定義](../examples/v014/recorded-displacements.noema)も保存した。

## 検証する違い

二点の座標へ同じ原点移動を加えても差は変わらない。二点を交換すると差の符号が反転する。有理数の演算ではこの二点を検証し、終点だけの変更や差の絶対値への置換には具体的な反例を確認する。実切断の検査は構成した有理数埋込みで行い、実数全域の演算法則の証明とはしない。

本文・抽出本文それぞれ24例で、方向数値だけの倍率変更、座標との整合した変更、共通の原点移動、二系の異なる原点、後の時点での共通移動、追加記録の整合・不整合を区別する。方向の一致だけでは原点の一致は要求されない。時点を変えた例は座標差の保存を調べる有限例であり、物理的な全運動を証明するものではない。

記録との結合欠落、結合された順序の相違、軸の配置点でない場合、位置座標の欠落、別座標系・別単位・別状況・別時点だけで利用できる場合も区別する。未知の項目や位置座標は評価を拒否する。著者への引用帰属を調べる8例では、引用内の配置や測定を実行しない。

```powershell
python -X utf8 -m pytest tests/test_direction_measurements.py -q
python -X utf8 -m scripts.check_direction_measurements --verify-only
```

通常表記・短縮表記・固有文字の往復、CLI解析、入力ハッシュと意味基盤の署名も検査する。[意味確認記録v9](../data/density-formula-review-v9.json)には、軸自身の座標による正方向の校正、軸に沿う全点の直線性、物理測定の構成説明、原点・時計原点・慣性系、適用範囲と全文の意味一致を未完として残す。原文対応範囲と意味確認済み区間数は増やさない。
