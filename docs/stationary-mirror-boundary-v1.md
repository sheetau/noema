# 静止した理想鏡の全成分境界

u0215の仮定と問いを接続するには、旧sejiの振幅・法線余弦・周期数だけでは足りない。同じ平面に接する入射波と反射波の位相、二つの接線方向、電磁場の六成分を保持する必要がある。この依存群は、その数学的な候補を既存の波形・横波・周期・エネルギー流から構成する。本文394主張と既存判断は変えず、原文完成件数も増やさない。

候補の読みは、静止した平滑な完全導体平面の理想化である。局所座標をx,y,z,tと書き、面をx=0、入射側をx<0とする。本文へ接続するときのxはk系のξであり、K系のx=0ではない。完全反射という語一般に対して、この特定の偏光位相を必須とする定義ではない。

同じ入射方向n=(a,b,c)と横波係数E,Hに対し、反射候補をnᵣ=(-a,b,c)、Eᵣ=(Eₓ,-Eᵧ,-E_z)、Hᵣ=(-Hₓ,Hᵧ,H_z)と構成する。H=n×Eと非零電場、a>0を入射条件にする。二つの偏光、その混合、斜め入射と垂直入射を保持する。接線伝播と零波は、面へ到達する入射の条件から除く。

入射と反射は同じ波形、同じV、同じ位相率を使う。x=0では二つの位相が一致するため、E+Eᵣの二接線成分とH+Hᵣの法線成分が零になる。法線電場と接線磁場は一般に残る。境界条件は全四座標への量化で表し、一つの標本だけの一致には縮めない。正弦と周期を用いるモデルでは既存ekc7を共有し、位相率ωと周期数νを取り違えない。

各進行波のκ(E×H)を全三方向で比較すると、反射の法線流は入射と逆符号、二接線流は同符号になる。境界面へ出入りする正味の法線流は零だが、接線流まで消えるとはしない。この式だけで物理的な吸収・透過の不在、面に働く力、光圧又は移動鏡の仕事を認定しない。

検証は、全十八係数の取り違え、全場成分と位相、境界内外、零以下のV・位相率・換算係数、同じ周期設定の全引数と全四量化位置を対象とする。有理数値の任意波形は正弦と称さず、全関数域の列挙を拒否する。ノルム、横性、磁場の外積及び三方向の流については全有理数の多項式補題も照合する。有限検査や補題は、材料の物理モデルや原文同義性の自動証明ではない。
