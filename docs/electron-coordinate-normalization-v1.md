# 電子の代表配置と原点を固定しない共動変換

u0245を原刊917–918頁で照合した。原刊にも頁末の「Koordinaten-」と次頁冒頭の「sprung」があり、固定在庫の綴りを変更せず、後続のt=x=y=z=0という指定に照らして座標原点と読む。第一文の一般性を保つ仮定の選択と採用、同じ電子の指定時点での原点・X軸方向・速さv、第二文の明白な帰結としての瞬間静止、一定速度で平行並進するk、t=0という指定を全て接続する必要がある。

最初に必要な依存をまとめる。空間の原点移動と向きを保つ直交回転、時刻原点の変更で、指定出来事を四座標零に移せる。速度は同じ回転で変換し、その大きさvを正のX成分へ配置する。v=0なら特定の方向を要求しない。位置だけでなく、同じ時間領域、位置曲線、速度三関数、加速度三成分も同じ回転と時刻移動へ結ぶ。物理的な座標規約は既存eisqtと両系の校正ejslへ接続し、任意の数値写像を物理的な座標系と認定しない。

続いて選ぶkは、電子の指定瞬間の速度vに合わせて一定速度で並進する系である。電子が全期間等速だとはしない。後続の文がt=x=y=z=0に対してτ=ξ=η=ζ=0を追加で指定するため、この段階のboostは新系側の任意の四原点ずれを残す。原点ずれは速度を変えない。同じ座標時刻での局所速度を、Lorentz写像の時間方向の微分で割って新系の座標時刻の速度へ移す。固有時の微分や単純なGalilei速度差には替えない。

共動慣性系の構成にはV>0と0≤v<Vを用いる。前のu0244へ遡って上限を付加せず、ここで使う相対論的な局所配置の適用域として明示する。元の粒子速度が(v,0,0)なら、新系の三速度は零になる。加速度はこの条件から零にならず、近傍全体の静止も導かない。

今回の依存群だけではu0245の全文を確認済みとしない。次に、一般の物理的設定を代表配置へ過不足なく対応させる範囲、同じ粒子・出来事・単位付き履歴の再表現、一定速度で並進するkとその瞬間の実際の三微分、仮定の許容と採用、明白さ、同じ著者への帰属、七つの数式表記を統合する。u0246以降では、その同じkで前の静止時法則と相対性原理を使う。u0244の問いが求めるlawと具体的な運動方程式の内容の接続も残す。
