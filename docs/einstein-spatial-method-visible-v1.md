# 空間座標の計算方法と縦方向の光線

原文u0065–u0068を、既知の時刻式τから空間三座標を求める方法、運動系でも同じ光速度を要請する説明、正のξ方向への光線の二式として接続する。既存の合成定義39個と関係契約7個を再利用する。共通基盤375語を保ち、任意プロファイル46版は776語となる。

原刊899頁の第39段落を二文として参照する。第一文は44トークンで、1–12番が容易な計算の主節、13–44番が二原理の括弧書きを含む方法説明である。第二文は16トークンで、1–14番が光線の条件とξ=Vτ、15–16番がoderとτを代入した別表示である。参照する箇所と、そこへ帰属させる主張の意味範囲を区別する。主張を短い参照範囲の語句だけに切り詰めず、第一文全体への参照も保持する。

容易さは、同じ方法の連続した非空の有限手順に対する文脈上の評価である。各手順の負担は非負で、同じ列の合計を低負担の基準へ照合する。具体的な時間、閾値、手順数、全読者の能力は補わない。列は先行τと二原理の前提から始まり、途中でτと運動系の光速度の式を使い、同じ方法・段階の候補空間写像を現在の方程式課題へ結ぶ。三空間成分と既知のτによる四式を保持する。

静止系と運動系の光区間は、それぞれの局所時計・座標・経路長で記述する。同じ光源、光、放出、出発と到達の出来事を要求するが、異なる系の経過時間や経路長を数値的に等しいとはしない。各系の非空の全区間範囲と全軌道を保つ。τ=0だけから空間原点を導かず、原点放出は隣接する式と零点規約を合わせた明示的な読みとする。

光線二参照と方法参照には既存のdescribedreferenceを用いる。同じ文書・箇所・提示文脈と閉じた役割を照合し、未知の参照を拒否する。参照取得は役割の成立や唯一性を証明しない。二つの光線が同じ対である条件、方法の連続性、候補の正しさは本文の別条件で要求する。

ξ=Vτとξ=aV(t−v*x′/(V²−v²))は同じ光線上の式であり、同じV、v、φ(v)、x′、tを使う。oderは条件付きの同値な別表示として扱う。光線外の全座標変換や、後続のV−vとtの消去は先取りしない。
