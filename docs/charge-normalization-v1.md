# 電場の発散・4πの換算・物質領域の電荷

前版で未接続だった4πの換算を、同じ物質領域の密度・体積・総電荷へ結んだ。電場の発散としての規格化密度と、物理的な電荷密度を別の値として保持する。総電荷の計算に使う密度を取り違えず、二系で共通の換算を使うことを明示する。

新しい原始概念と著者の主張は加えず、8定義を追加した。親文書の宣言と174件の主張は保存する。原文u0238の同じ解釈注記を精密化したものであり、新たな原文範囲を対応済みに数えない。

規格化密度をr、電荷密度をρ、共通の正の換算係数をCとすると、両側でr=Cρ、r′=Cρ′を要求する。まずrとr′に既存の密度変換を課し、そこから電荷密度ρとρ′にも同じ変換が成立することを、有理数の一般係数について検査する。電荷密度側の変換を前提へ重ねて結果を作ることはしない。

| 定義 | 接続 |
| --- | --- |
| `senj` / `senl` | 同じ正のCによる二密度の換算と、規格化密度の変換。有理数版／実数版 |
| `senk` / `senm` | 上記に同時刻体積の変換と、物理的な総電荷＝電荷密度×体積を加える |
| `senn` | 既存の`seml`と同じπを使い、Cを4πに固定する |
| `seno` | 同じ物質領域・二系・二切片へ、電荷密度・体積・総電荷を割り当てる |
| `senp` | 各系の電場の微分表の発散を、同じ規格化密度r・r′へ結ぶ |
| `senq` | 微分表も同じ物質領域・基準系・切片へ割り当て、上記をまとめる |

総電荷はQ=ρW、Q′=ρ′W′であり、rWはCQに等しい。例えば一般係数C=12、電荷密度4、体積11なら、規格化密度は48、物理的な総電荷は44、規格化した総量は528になる。528を電荷の値44と同一視しない。この12という数値例は4πの値を与えるものではない。

旧側だけC=12、新側だけC=24を用いると、規格化した総量が一致しても物理的な総電荷は一致しない例を作れる。反対に、両側の電荷密度が零なら、観測した零の値だけではCを一意に決められない。共通の換算を採るという条件と、数値から換算を同定できるかという問題を分ける。

実数の4π版は、既存の積分によるπの指定`sedi`を通じて`seml`へ接続する。ここで実装するのは厳密な切断と定義への参照であり、πを有理数3や有限小数へ変更する処理ではない。有限検査では、接続の成否を試すための仮のπ判定オラクルを明示して使用する。その検査を、πの実値・全実数の演算法則・積分の証明に数えない。

電場の微分表の発散は三つの空間対角成分から構成する。対角成分を変えれば密度との一致が壊れる。一方、対角外の成分を変えても発散は同じでありうるが、元の切片へ割り当てた微分表と同じものとは限らない。`senq`はこの違いも保持する。数表の実際の偏微分としての根拠や、二つの微分表全体のローレンツ変換を今回の構成だけで証明したことにはならない。

検査対象は、有理数の5つの帰結と3つの反例、密度・基準系速度・換算係数の27設定、割当とπの33対照例、微分表の24変更、数値の混同7例である。抽出文書と原文付き文書で同じ結果を返すこと、未解釈のπ・場の微分・物質の対応を補わないことを確認する。

関連37テストと、186件の対応表・387件のNoema文書を対象にする進捗監査は通過した。3文書のCLI解析結果は直接解析と一致し、通常表記・圧縮表記・固有文字の往復も成立した。抽出文書のSVGはXML構造を検査したが、見た目の検査は含めない。

前版の一様並進・一様な電荷密度・正の同時刻体積という適用条件を引き継ぐ。今回つながったのは規格化から電荷密度と総量までの記述である。単位の物理的な実現、任意の加速・変形、非一様密度の体積積分、動く境界の流束、全場の微分と変換、時間を通じた一般の保存則は残る。原文の任意運動の主張を完成したとは扱わない。
