# 私的使用の選択肢と制限の程度・頻度

旧い私的活動の禁止率は、肯定の要求が非実行の選択を排除する場合を数えない。そこで、固定した本人・職務の選択肢のうち、適用中の要求に適合しなくなる割合を構成した。要求の内容と極性は、先行の制限の問いと同じ段階1の記述を使う。

`r2yo` は、同じ本人と職務への要求の少なくとも一つに適合しない選択を判定する。要求の存在だけでは、その内容の実行や違反を意味しない。`r2yp` は全要求行の出所・本人・職務をそろえ、各活動が同じ基準で私的使用 `zzp` に分類されることを確認する。

`r2yq` は全選択肢を過不足なく一度ずつ列挙し、正の重みを使って排除される割合を計算する。適合選択が一つもない場合は認定しない。たとえば「Aを行う」「Bを行わない」の二要求は、A/Bをそれぞれ行うかどうかの四選択から三つを除く。どちらか一要求なら二つを除く。これは活動二種類のうち一種類を禁止するという数え方とは異なる。

`r2ys` は同じ選択範囲・重み・活動分類を全対象時点で保持し、強い制限が成立する時点の頻度を構成する。程度と頻度には別の基準を渡す。程度0、評価不足、適合選択の不存在を区別し、評価できない時点を頻度の分母から外さない。

選択肢と評価機会は有限列、重みは正の有理数という操作的な読みである。選択の分割・統合や連続時間の測度まで自動的に解決しない。候補の網羅性と比較可能性、強い・しばしばという基準は意味規約上の入力であり、検査例の数値を原文へ追加しない。

[定義集](../examples/v016/private-choice-frequency.noema)、[意味規約](../data/private-choice-frequency-basis-v1.json)、[検査報告](../reports/private-choice-frequency-v1.json)を保存する。新しい基本関係と著者主張は追加しない。次にこれを私的使用の方針へ束縛し、許可と、同じ啓蒙の進行を特に妨げないという留保へ接続する。段階1の内容を評価するため、外側の方針の引用には段階2が必要となる。
