# 組織が用いる理由と、その支持を分ける

カントu0012の「これらが、その組織の用いる証明の根拠である」という報告へ、組織に帰属する判断と理由の範囲を部分接続した。理由を用いたこと、理由が判断を支えること、挙げた理由で一覧が尽くされることを別に表す。

## 同じ判断に理由を結ぶ

| 一般構成 | カント草案への接続 | 条件 |
|---|---|---|
| `rge` | `hzbs` | 組織に帰属する同じ判断を、対象と発話記述へ結ぶ。非空の指定範囲の各理由が、その判断・状況で用いられる。 |
| `rgf` | `hzbt` | 上の条件に加え、指定された各理由が同じ判断を支持する。 |
| `rgg` | `hzbu` | 上の使用条件に加え、その判断・状況で用いる理由が指定範囲で尽くされる。 |
| `rgh` | `hzbv` | 組織・判断・内側の発話・理由範囲を固定し、`rgg`が成立するという外側の主張を作る。 |

判断対象には既存の`fb`と`hzv`、理由の使用には`fc`、支持には`fd`を使う。組織への帰属は関係引数`institutional`で明示する。人が判断するという`fa`へ、組織を人間として代入していない。

支持の関係は使用とは独立である。ある理由が使われていても、支持が成立しない場合を記述できる。`rgf`も、その理由だけで十分な証明になることや、複数の理由の組合せが論理的に妥当であることを自動的には意味しない。具体的な推論規則や前提の真理は別途記述する必要がある。

## 一部を挙げることと、尽くした一覧

理由の範囲は、個体を受けて真偽を返す条件で指定する。順序や重複を強制せず、有限の配列だけに限定しない。

例えば判断で理由A・B・Cが使われている場合、A・Bを指定した`rge`は成立しうるが、`rgg`は成立しない。A・B・Cを指定すれば、同じ使用関係に対する一覧は尽くされる。Cの支持が不成立でも、使用理由の完全な一覧であることは変わらない。

この完全性は、同じ判断・同じ状況に限る。他の判断で使う理由や、別の状況で使った理由を排除しない。組織にとって可能な全ての根拠を尽くす意味でもない。理由の使用が未知なら、それを不使用として一覧を閉じない。

原文の定冠詞を、この文脈の判断に使う理由の一覧として読む候補を置いている。この箇所の唯一の読解だと確定したものではない。非空性は、指示された理由があるという今回の報告の条件であり、あらゆる証明が前提や根拠を非空に持つとの一般原理ではない。

## 二つの報告で内側の主張を共有する

前版の[組織の教示についての報告](institutional-voice-v1.md)と、今回の理由についての報告は、同じ組織・対象・内側の発話記述を共有する。どちらも閉じた記述として提示できる。

「この組織はこう教える」と「この組織はこれらの理由を用いる」は別の主張である。一方が真でも他方を導かない。両方が真でも、内側の内容が真であること、本人が賛同すること、理由の支持が成立することは要求しない。外側の報告を提示した事実だけなら、これら全てが未知でも記述できる。

同じ真偽を返す別名や、働きが質問である別の発話へ内側の記述を変えた場合、元の判断の理由を自動的に流用しない。検査では、実際に提示した閉じた報告記述そのものを脱引用して評価し、別に用意した似た条件で代用していない。

## 検査と未完部分

組織への帰属・対象・発話への判断・二理由の使用・二理由の支持による128設定を検査した。19対照例で、判断・組織・対象・記述・状況の取り違えと、他の判断や状況の理由を区別した。理由範囲の8例では、空範囲、一部の指定、範囲外の使用理由、追加理由の支持の欠落を確認した。

二つの報告の真偽、内側の真理、本人の賛同の16通りを独立に変えた。報告内容が事実でも、それだけでは報告行為は生起しない。支持・内側の真理・本人の賛同を未解釈にしても、外側の報告と使用理由の内容は扱える。未知の組織帰属や理由の使用を評価する場合は停止する。全文草案と独立抽出文書の結果は一致した。

これらは指定した有限モデルの検査である。全理由領域の走査や、証明の論理的妥当性を確立したものではない。`Beweisgründe`の証明としての地位、具体的な理由の内容、組織の意思形成と承認、集団の指示、原文の例示と予想、自由な裁量・良心・辞職は未完である。原文全文の意味一致も確認していない。

8定義を追加し、原始概念・局所参照・著者主張は追加していない。全文草案は98,699代用文字で、前版から1,451文字増えた。一般構成は956文字、独立抽出文書は2,338文字である。定義を含む長さで、一文の翻訳の圧縮率ではない。
