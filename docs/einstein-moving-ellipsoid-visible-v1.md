# 運動する球形剛体と回転楕円体の円文字表現

原刊903頁のu0114–u0115を、静止時に球形を持つ剛体の一般的な帰結として接続する。既存13定義と文位置の参照を組み合わせ、共通375語、任意プロファイル58の802語、アルファベットを維持する。

対象は特定の球zhwに限らず、同じ二系・速度・尺度の設定で条件を満たす全ての物体、正の半径、任意の静止側中心である。kの全物質点の剛性・静止・球形と、Kにおける全物質点の並進を保持する。閉じた領域を占める理想的な連続体という採用済みの読みを継承し、球殻一般の意味をこれで定めたとは扱わない。

静止側の中心(cx,cy,cz)は、Kの時刻tで(cx/β+vt,cy,cz)へ移る。全対象時刻で形状を述べ、中心を原点や時刻零へ固定しない。全物質点の包含と閉領域の全実数位置の被覆を共に要求する。独立に定義された物質境界と表面式の一致も、全ての適格な現在記録について保つ。

表示された三値は、順に縦半軸R/β=R√(1−(v/V)²)、横半軸R、Rである。原文のAchsenはこの表示値に従って半軸として読み、直径や三方向の一様縮小に置き換えない。Kから見た形状は同時刻座標による形状であり、光の到着時間を含む写真の見え方を追加しない。

alsoによる帰結は、先行する設定・球面式・変換・零断面の式から著者が述べる関係として保持する。引用された内容の取得は、全物体についての物理的証明の実行ではない。本文位置は第54段落の第四文とし、一般の物体、観測系を示す挿入、三半軸の表示を一つの33トークンの文へ結ぶ。末尾句点はM0200内にある。

検査では、復号された定義本体を使って、非零の中心と時刻、半軸の順序、全物質点と領域被覆、任意の二物体への条件付き主張、各半径・中心引数の結合を調べる。実数の量化を例化する診断と、保存された全実数量化を別に確認する。有限診断、採用した意味判断、円文字復号、独立した読解は区別する。続く一般形状の寸法変化や光速極限は後続単位で扱う。
