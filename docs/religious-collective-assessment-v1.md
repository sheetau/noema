# 宗教的事項と集団としての到達

第七段落冒頭の時代評価は、後続の `in Religionsdingen` が明示する宗教上の理解力使用についての評価と読む。[AA VIII 40](https://korpora.org/kant/aa08/040.html) の直前には個人の救済に関わる選択があり、直後には良心上の事柄と聖職者の自由が続く。[AA VIII 41](https://korpora.org/kant/aa08/041.html) の著者自身の説明も宗教上の問題を主眼に置く。この接続を採用し、教会組織の運営だけにも、全ての知的分野にも対象を変えない。

`r5s6/s7` は同じ本人・宗教領域・基準の全事項と閉じた参照を渡す。本人が信仰を持つこと、教義が真であること、特定の教会に属することは要求しない。事項の内容とその課題に必要な条件は明示する必要があり、参照名を与えただけで内容の説明を済ませたとはしない。`r5ta/tb/tc/td` は前回の適切さ・安定性を現在能力と支援後の能力へ接続する。

「全体として」は、同じ有限な現在人口における等重みの能力保有割合と、事前に固定した文脈的な到達閾値で読む。原文は具体的な割合を指定していないため、その値は解釈入力として残す。これは集団的判断の一つの形式化であり、影響力による重み付けや制度の質を直接評価する読みと区別する。

`r5te/tf/tg/th` は人口の完全性・人間性、非空性、重複の不在、正確な割合、0より大かつ1以下の固定閾値を結ぶ。全員一致は選択できるが、必須ではない。同じ人口と閾値なら、人の順序や誰が成功したかを入れ替えても人数が同じ場合は判定が変わらず、能力保有者が増えて到達が失われることもない。少人数では1未満の閾値でも全員必要となりうる。

`r5ti/tj/tk/tl` はこれらを現在人口・時代・話者に結び、全員の評価、集団到達、未到達かつ進行、有効な未到達を分ける。`r5tm/tn` は同じ現在点を固定した問答内容である。未知入力や未評価を到達の否定へ置換しない。

局所検査では、宗教的事項と参照の一致、同じ質付き能力への引数接続、割合の匿名性・単調性・両端条件、人口の過不足、固定閾値、同じ現在の問答を確認する。能力内部は前回の実評価を再利用し、今回の集団検査で置く型付き境界を報告に明記する。進行内容と条件付きの問答提示、第二文の甚だしい不足、著者帰属は未統合で、意味確認済み文字数を増やさない。
