# 状況を束縛して内容を作る

nativeの `content(variable, body)` は状況変数を一つ束縛し、truth型の本体からcontent型の値を作る。円文字でも同じ規則を使う。状況型は構成語によって決まるため、型の見出しや引数列を追加しない。

読取器はcontentの字形を読んだ時点で、nativeの命名順に新しい変数名を割り当て、その名前とsituation型を現在の束縛範囲へ追加する。本体は一式だけ読む。外側の範囲は保持するため、外側の個体・状況・関数も、従来の外向き参照を使って読める。本体を読み終えれば範囲を戻し、隣のcontentへ束縛を漏らさない。

引用はこの規則と異なる。`quote` 内では外側の範囲を空に戻し、引用内で新たに現れるcontentの束縛を読む。content内にquoteが現れた場合も、引用を読み終えてから内容の束縛範囲と命名順へ戻る。`evaluate` の引数順は従来どおり内容・状況であり、関数が返した内容、引用を解いて得た内容にも同じ規則を使う。型・作用範囲の最終確認は既存native検査を通す。

字形は大円と右下段の小円を用いる。大円中心が `(x, PITCH)` なら、小円中心を `(x + sqrt(LARGE² − PITCH²), 2PITCH)` に置く。小円中心は大円円周上にあり、偏心内包は起きない。大円の中心線は左上45度へ伸ばし、上端と同じ高さで終わる。外部との接続口は大円に置く。先行する引用操作三字形と対になる、隣段の四つ目の配置である。

検査は、局所の状況、外側参照、内外の引数順交換、入れ子、引用の境界、関数返却、内容の評価を区別する。実際の図形から元構文へ一致することを確認し、意味モデルの再審査には置き換えない。定義宣言、他の未対応構文、長い型列や枝の配置、行頁の復元、外観の最終確認は残る。
