# 「高慢な名称」の評価

第八段落のhochmüthigenは寛容という名称を修飾し、君主はその名称を自分から退ける。今回は、その呼称を自分の立場として採用する用例への評価を構成した。拒否する君主本人を高慢と分類せず、現実の名称使用がない場合にも、呼称の含意を評価できる。

採用した読みは、自分への尊重を求める一方、相手に必要な尊重を与える立場は認めないという対人上の非対称である。[DWBのhochmuth第二義](https://www.dwds.de/wb/dwb/hochmut)は自己を上に置く傲慢な誇りを示し、[後年のAA6:465](https://korpora.org/Kant/aa06/465.html)は相手から尊重を求めつつ相手には与えないという関係を説明する。後年の倫理学全体や永続的な性格を1784年の形容へ追加せず、この対人的な評価を補助にする。

尊重の内容は、相手をその人自身の判断と選択に固有の立場を持つ者として扱い、自分の都合だけに従属する下位の者として扱わないこととした。判断の正しさへの賛同、全行為の無制限な許容、称賛や親愛、王と臣民の職階の同一性とは区別する。三対象列の主体と相手を逆にすることで、同じ基準での相互の扱いを表す。

同じ活動で、自分が受ける側の内容には正の実践方針、自分が与える側の内容には負の実践方針を取ることを組み合わせる。さらに、同じ規範出所が同じ相手への尊重を本人に要求する条件を結ぶ。現実に相手を尊重していないことだけでは、この意図的な立場を認定しない。規範上の裁量資格の不足だけを高慢とする旧候補も使わない。

名称の意味には、前回の「宗教的自由を自分の裁量によって認める側」という段階3の記述を再利用した。同じ人が同じ名称を自分へ適用し、その説明を自分の位置付けとして採用する場合だけを用例にする。引用、他人の用法の報告、批判や皮肉としての言及から自己採用を補わず、引用された裁量や自由方針の真理も要求しない。

名称の評価は、先に固定した人物範囲と仮定場面範囲の全採用用例について、同じ活動で対象集団の少なくとも一人への非対称があることを調べる。人物・場面・採用用例の各非空性を要求する既存rnvを使い、一つでも反例となる用例があれば評価は成立しない。これは全世界の全用法や統計的な典型性の主張ではない。範囲を結果に合わせて選ばず、この文の用法を十分に含むよう固定することは、本文への接続時の読解責任として残る。

検査は、正負の立場と尊重要求の8通り、同じ記述の逆向きの三対象列、意味の保持と自己採用、全仮定用例と反例、空の範囲、別の人や活動の態度、未知入力を調べる。評価が成立しても現在の名前使用が成立しないモデルを含め、君主が実際に高慢であるとの読み込みを防ぐ。
