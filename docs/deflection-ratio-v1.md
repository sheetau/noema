# 二つの偏向の強さと速度を求める比

u0266前半とu0267の式を、横方向の運動方程式、二つの効果の比較、応答値の比に分けて記述した。第二の運動方程式(A)はmu*beta*V*a=charge*(V*Y−v*N)とし、同じ速度・質量・電荷について、電場単独、磁場単独、両場の場合を比較する。ここで用いる係数mu*betaは、共動系の力で定めた横質量mu*beta²とは別である。

非負のYとNがV*Y=v*Nを満たすと、電場単独と磁場単独の加速度は同じ大きさで逆向きになり、両場での加速度は零になる。電荷の符号を反転すると双方の向きが反転するが、強さの比較は保たれる。零電荷ならどの場でも加速度が零になるため、強さの一致から場の釣合を逆推定するには非零電荷が必要になる。

原文のAblenkbarkeitは、共通の正の校正・幾何学的要因Gを持つ二つの応答値Ae,Amとして読む候補を設けた。mu*beta*Ae=G*|charge|、mu*beta*V*Am=G*|charge|*vを課すと、Am/Ae=v/Vが得られる。Aeは正であり、分母零の交差積だけでは式を満たせない。実際の曲率や通過時間、測定装置、単位の詳細は未展開で、原文がこの応答モデルを明記したとは扱わない。

速度の数値はV*Am/Aeで復元できるが、正しい校正が前提となる。検査には、磁気側だけの応答を半分にすると、形式上は許容速度でも元の速度とは違う値が得られる例を含めた。両場が零で加速度が零という一例から速度を決めることもできない。速度零の数値式は認めるが、静止した粒子で実際の測定法が成立するという主張にはしない。

先行191文を保存し、同じ強さの条件、比の式、第二式からの理由づけを著者へ帰属させた。二つの応答に共通要因Gを置く追加モデルは解釈候補に留める。u0266後半の任意速度での決定可能性、u0265の列挙の予告、u0268の直接測定との照合、原文全体の意味一致は残る。
