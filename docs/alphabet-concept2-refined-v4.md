# concept2：半円基準・方向線・参照選択 v4

作者のconcept2とexamples画像、および追加指定に従う試作規則。v3を保存し、この版の生成器・復号器を分ける。外観の確認前には固定しない。以下の変更以外はv3の構文・描画規則を継承する。

## 円周を基準に接続する

- 中円半径を M、小円半径を S、大円半径を L、第4円半径を F とする。
- 接続する側の半円に正の長さの大円弧があれば、大円の完円周端を半径幅 M の起点とする。なければ同じ条件の中円を使い、どちらもなければ実接点を使う。半円境界の点だけは円弧があることに数えない。第4円はこの繰上げから除外する。
- 中円内にある大円弧は常に残す。重なり側90度にある中円外の二つの弧は一括で残すか消す。それ以外は45度単位で選び、少なくとも45度を残す。
- 円に属する方向線・自由端は、中心からの距離 F 以下で止める。45度線の限界座標は各軸 F / √2 であり、各軸 F ではない。
- 別の円へつながる線は半径幅の規則で扱う。改行端も M を保ち、復号器が端の長さと前後の段を照合する。方向線の例外として任意の長い自由端を認めるものではない。
- 小円の内部に線を入れない。接続は円周で止める。

## 参照の順序から形を選ぶ

幹で引数の順序を示す場合、幹の小円中心間は 2S + M。小円間の実線は常に M になる。各枝先の小円も次の幹小円と同じ縦列へ置く。枝の屈曲部はこの列と段から位置を求め、外部接続の半径幅と混同しない。

上・中・下のうち異なる2段または3段を、その順序で読む場合は「選択形」へまとめられる。大円に直交する小円を右上45度・右0度・右下45度へ置き、小円内だけ大円弧を抜く。ある小円だけが選択した段を表す。小円中心は大円中心から √(L²+S²)、抜く弧の半幅は atan(S/L)。中大円に禁止されるくりぬきとは区別する。単独の大円・小円の接続形との混同を避けるため、選択形は小円2個以上に限る。

異なる順序、同じ段の再使用は幹をたどる分岐で表す。これにより構文上の引数順を保ち、見た目の都合で並べ替えない。反復圧縮は従来どおり小円を対象外とし、意図的に同形を続ける表記も残す。

## ドットは中円から始める

通常の対応ドットは完円の中円へ収める。識別に使う中円の45度区間を変え、左右の接続口を中円だけで確保できない場合に大円を加える。ドットへ接続線を通してはならない。

公開番号0の形を中円8区間すべてあり、番号255を中円なしへ割り当て、それ以外は従来の8ビット区間とする。この交換は全256識別形の一対一対応を保つためのもので、番号をSVG属性に埋めて読むことはしない。中円なしの対応先だけは裸のドットも使える。対応は引用・束縛の範囲内で閉じ、未対応のドットは拒否する。

## 復号と確認の範囲

生成は構文から公開字形へ進み、復号はSVGに実在する円・円弧・線・ドットから公開辞書と構成規則だけで進む。元AST、文番号、配置表、保存したトークン列を復号器へ渡さない。要素順や識別属性にも依存しない。線分を分割しても方向線の長さ制限を回避できない。

局所的な候補配置では近傍を切るため自由端検査を行わず、完成した行と復号後の全線で行う。改行端の除外は長さを検証した端に限る。意味・参照が不変で復元構文が一致すれば既存の意味判断を引き継ぐ。今回のレイアウト変更に対して全意味モデルの再走査は行わない。

対象は元kant-pageの4段落40項目と短い対照構文。任意型・複数束縛を含む全構文への対応、任意の多段合流、手書き・画素OCR、作者による外観承認は別の残件である。
