# 折れ線の時計と位置への帰還

アインシュタイン§4の `u0127` に、任意の有限個の直線区間を経る時計と、出発位置へ戻る場合の比較を部分記述として接続した。前段の速さvを全区間で共有する読みを採用する。向きは変えられるが、区間ごとの速さまで変える場合には、それぞれの進み率を掛けた和が必要になる。

有限列は区間の順序を保持する。`sxc` は最初の始点、隣接する区間の境目、最後の終点を出来事の同一性で結ぶ。各出来事から座標記録と時計の指示を得る関数を経路全体で共有するため、角に到達したときと角から出発するときに別の指示を割り当てない。数値が一致しても、別の出来事で接続した列は条件を満たさない。

`sxg` は同じ時計の端点観測、共通の正の速さと端点の距離、各区間で測定された途中の記録の直線等速条件を要求する。`sxh` はさらに、各区間内の全実時刻に、その時計の出来事と対応する直線等速の記録が存在することを要求する。中間記録が欠けている有限標本は `sxg` を満たし得るが、それだけで `sxh` を認定しない。

指示法則は運動条件と分けてある。`sxi` は全区間に同じ進み率fの法則を課し、`sxm` は残った静止時計にも指示差が全所要時間に等しい法則を課す。角での方向転換、出発、停止で追加の指示変化がないことは、この理想化の前提に含まれる。慣性運動の時計の式だけから、加速中の機構まで導出したとは扱わない。

```text
区間iの座標時間差: Δtᵢ > 0
区間iの移動時計の指示差: f*Δtᵢ
共通の進み率: f = √(1−(v/V)²)

全所要時間 T = ΣΔtᵢ
移動時計の指示差 = Σ(f*Δtᵢ) = f*T
初期指示が等しい二時計の到着差 = (1−f)*T
```

`sxj` と `sxk` は、共有した端点の時刻差と指示差を有限列に沿って加算する。空列の和は零であり、同じ区間を二度並べれば二度数える。これらの集計関数そのものには、経路としての正しさを認定する働きはない。たとえば角で指示を一度ずらし、次の区間で元へ戻せば、全指示差は変わらなくても区間法則には反する。

初期同期と比較時計の条件 `sxl` には、両時計の初期静止・同期、初期指示の一致、比較時計の終着位置への残留、到着の同じ出来事と場所での指示を含む。開いた経路では、移動時計の出発と比較時計の初期読みは離れた場所の出来事になる。帰還経路では同じ出発出来事を使える。前段のA≠Bという直線移送の条件をそのまま持ち込まない。

帰還条件 `sxo` は、正の時間が経過した後、異なる出来事で同じ三つの位置座標に戻ることを表す。位置が同じだから出発と帰着も同じ出来事だ、とする条件にはしない。`sxq` は一般の折れ線、`sxr` は位置への帰還を加えた場合の条件付き内容である。全有限列と各区間の全実時刻への量化を持ち、有限評価器はどちらの無限領域も標本で置き換えず拒否する。

到着差の結論 `sxn` と、その二次近似の留保 `sxp` を接続した。秒への換算尺度があることも前提に含める。四次残差の条件は全所要時間を固定した評価であり、速度とともに所要時間を変える族について同じ定数が使えるとは断言しない。原文の「直ちに分かる」という提示は、著者が明らかな帰結として扱う関係で記述し、機械的証明の完了と分けた。

検証では、往復、斜めの往復、三角形、曲がる開いた経路を扱った。V=5、v=3、全時間10の場合、移動時計は8進み、静止時計は10進む。初期指示7から出発すると帰着時は15と17となる。全時間4の三角形では移動時計の指示差が16/5になる。これは指定した物理関係と区間法則の具体的な解釈であり、実測結果ではない。
