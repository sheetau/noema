# 同じ認識内容の訂正と後代の改訂不能

カント第六段落 u0013 [713,1004) の `von Irrthümern zu reinigen` に向けて、同じ集団の人が誤った認識を訂正する構成を加える。原文は認識の拡大、誤りの除去、啓蒙の進展を並べている。[AA VIII 39](https://korpora.org/kant/aa08/039.html)でも同じ箇所を照合した。全文判断はまだ行わない。

旧 `ri6` は、正しく支持された情報を一切失わず、新しい誤りも生じない場合の誤りの減少を表す。これを個別の訂正にも要求すると、一つの誤解を解く変化を取り逃がす。一方、受容項目が消えただけでは忘却や死亡も含んでしまう。今回は、以前の誤った受容、同じ内容への理由ある否定判断、その後の受容の撤回を接続する。

`r5cc/cd` は同じ内容を表す別名を固定した代表項目へ結ぶ。別の項目名で同じ誤りを受け入れ続ける場合を訂正にしない。代表への対応は明示した意味規約であり、有限の真理値表が一致するという理由だけで、異なる認識内容を同じものにしない。内容は Noema の命題として与え、原語の綴りでは代用しない。

`r5ce` は受容と偽を分け、固定した評価状況で誤りを判定する。`r5cf` は既存 `ya` と `h245q` により、本人・否定判断・対象内容・そこで用いた理由・その支持を同じものに結ぶ。他人から教わる場合も許し、自立した判断だけに狭めない。判断の帰属と、その内容の真理は別に検査する。

`r5cg/ch` は同じ本人が前後とも生存し、間に理由ある否定判断があり、その後に同じ誤った受容が残らないことを確認する。履歴の順序も確認する。`r5ci` は対象集団の少なくとも一人の訂正へ進める。他の誤りが残る場合や別の箇所で悪化する場合でも、この一つの訂正の存在は取り消さない。集団全体の正味の改善量を測る定義ではない。

`r5cj` は、この訂正を生む結果の成功可能性が一つもないことを既存 `rjb` で表す。方法は個人の学習も共同の検討も含めた全範囲とし、利用可能な各方法の結果を空にして不能を作らない。成功保証がなくても成功する結果が一つあれば不能ではない。誤りが元からない場合の訂正不能だけで、妨害や害があるとは結論しない。

検査では、別名の維持、単なる忘却、出生・死亡、世界だけの変化、別の人・内容・理由・支持・時点へのすり替えを区別する。残る誤りや新たな別の誤りは局所的な訂正を妨げない。引用の検査、個別定義の実行、型付き境界での接続検査に加えて、訂正から不能性まで全定義を実行する例を置く。

知識の新規獲得・根拠・理解の拡大と啓蒙の進展は別に残る。この部分を知識一般の定義に昇格させない。同じ合意と後続集団への目的・状態・必然性、規範的否認、括弧の重要性・総括・共謀的提示・全文帰属も未接続である。本文99主張と確認済み文字数を保持する。
