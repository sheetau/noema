# 固定した範囲における障害の漸減

カントu0014の「一般的啓蒙の障害が徐々に少なくなる」という部分に、同じ障害候補・対象者・時間範囲で減少を比較する草案を追加した。障害が少ない状態、始点より終点で少ないこと、途中も増えずに複数段階で減ることを分ける。原文の全ての「徐々に」の読みを確定するものではなく、件数を使う明示的な候補である。

| 定義 | 内容 |
| --- | --- |
| `rly` | 固定した候補列で妨害条件を満たす件数 |
| `rlz` | 同じ履歴の始点から終点までの、両端を含む区間 |
| `rl2` | 順序・両端・候補列の完全性と、全候補の区間内全時点での評価を確認する |
| `rl3` | 区間内のどの前後でも件数が増えず、終点が始点より厳密に少ない |
| `rl5` | 指定した履歴に中間点のない隣接関係 |
| `rl4` | `rl3`に加え、各段階の減少が正の上限以内で、二回以上の減少があり、大きな差には中間値がある |
| `rl6` | `rl4`に加え、後で妨害条件を満たす候補が必ず前にも満たすという、入替えを許さない条件 |
| `rl7` | 各候補・時点の両側の介入に解があり、同じ人々の能力評価が全解で整合する |
| `rma` | 要因ありの能力人数が要因なしより少ない介入解の組があるという潜在的妨害 |
| `hze5`・`hze6` | 介入の評価と人数尺度を、既存の人・指導なしの理解力使用能力へ接続する |
| `hze7` | 同じ期間・候補列・上限について、全評価を確認した潜在的妨害の件数の漸減を述べる |

「3→3→2→1」は二回の減少を持つ。「3→3→0→0」は全体として減少していても一度の急減なので、複数段階の条件を満たさない。「3→1→2→0」は終点が少なくても途中で増えるため、非増加の条件を満たさない。「3→1→1→0」を許すかどうかは、一段階の上限を1にするか2にするかで変わる。この上限や観測の刻みを、原文が指定した数値として扱わない。

隣接点の比較に加え、任意の前後二点で件数の差が上限を超えるなら、その間に両端と異なる件数の中間点があることを要求する。これにより、隣接点を持たない時間順序であっても、大きな跳躍を隣接条件の空虚な成立だけで許さない。実行した検証は有限の履歴に限る。

件数の減少だけでは、同じ障害が除かれ続けたとはいえない。三つの候補のうち、最初に二つが残り、その後は以前と異なる一つだけが妨害条件を満たす場合も、件数は減る。`rl4`はこれを許し、`rl6`は拒否する。各障害の強さや、誰にどれほど影響するかも件数だけからは分からない。

区間は、同じ履歴と両端から定める。途中の悪化した点だけを除いたり、終点で評価できない障害を候補列から取り除いたりしない。評価欠落、重複した候補、不完全な列挙、循環した時間順序があれば、確認済みの減少とはしない。始点より前の評価は、その選択した区間の内部条件には加えない。

原文への接続では、候補となる要因を有効・無効にした構造モデルの解を比較する。両側で同じ人々と同じ能力内容を使い、全解で能力評価を確認する。人数尺度には既存の`h4l`を用いる。これは評価済みで他者の指導なしに自分の理解力を使える能力であり、前文の宗教的な事柄についての確実さや判断の質をそのまま代入したものではない。

要因あり側の能力人数が少ない解の組が一つでもあれば、そのモデルで潜在的な妨害とする。全ての解の組での妨害、現実に要因が存在すること、除去を実施したこと、実際に啓蒙が進んだことは別である。複数解の対応づけや、モデルが現実の背景と介入を正しく表すことも未確定である。解がない場合や能力評価が欠ける場合を、障害が消えたことには置き換えない。
