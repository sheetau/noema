# 本人に対する基準と、その履行を分ける

「尊厳に即して扱う」を記述する準備として、同じ本人に対する基準が要求されていること、その基準内容を実際に満たすこと、比較する状況を通じて要求が維持されることを分けた。前段の政府の自己利益判断を、これらの代用にはしない。今回の構成だけで尊厳を定義し終えたとは扱わない。

対象論説の[アカデミー版42頁1–2行](https://www.korpora.org/Kant/aa08/042.html)には尊厳に即した扱いが現れるが、具体的な基準の一覧はない。比較資料である別著作『道徳形而上学の基礎づけ』では、尊厳に基づく義務を将来の利益から区別し、価格と等価物による代替を許さない価値を対比している。[434頁20–34行](https://www.korpora.org/kant/aa04/434.html)。続く[435頁](https://www.korpora.org/kant/aa04/435.html)では内的価値や道徳性・人間性との関係を述べる。これを1784年の論説の語義へそのまま移してはいない。[読みの記録](../data/dignity-reading-v1.json)に比較の範囲を保存した。

| 定義 | 内容 |
| --- | --- |
| `ryb` | 固定した非空の基準一覧の全てについて、同じ本人に対する内容の実現が要求される |
| `ryc` | 同じ一覧の内容が、同じ行為主体・本人・文脈で実際に成立する |
| `ryd` | 要求と履行がともに成立する |
| `rye` | 指定した非空の比較状況全てで、同じ一覧への要求が維持される |
| `ryf` | 比較状況間の要求の維持と、現在の要求・履行がともに成立する |

基準の内容には、Noemaの式の記述を使う。記述へ渡す二個体列は「行為主体、扱いの対象になる本人」の順序で固定する。規範の出所と職務は別の引数として保持する。別人への義務、逆順の内容、外延が同じでも違う記述への要求を、本人に対する元の要求へ流用しない。

現在の要求と履行は別々に調べられる。内容の成立が不明でも、同じ内容が要求されているという状態は記述できる。反対に、要求されていない行為の内容が成立する場合もある。好都合な結果や善意だけで、未履行の内容を成立扱いにはしない。利益がないことだけで履行を否定することもない。

比較する状況では、本人と基準一覧を元の基準時点へ固定する。守られていない基準だけを一覧から外してから「全て満たした」とは判定しない。空・重複・範囲と不一致の一覧は受け付けない。比較範囲が空なら、要求が維持されるという条件も認めない。現在が比較範囲に入っていなくても、現在の要求と履行を別に確認する。

`rye`は指定状況間での不変性であり、あらゆる利益や価格に対する不可侵性を証明するものではない。また、どんな基準を守るべきかは一般形の外にある。不当な基準の履行もこの構造では記述できるため、履行したというだけで道徳的な尊厳への適合を導かない。人格、自律、目的それ自体、具体的な扱いの基準とその根拠は引き続き必要である。

原文側の`iaustanding`と`iautreatment`は、扱いの対象を人に限定し、既存の要求関係`h7k`へ接続する。現在は言語上の接続を提供する段階であり、本文の新しい主張にはしていない。親の全宣言と全22主張を保存する。

動的に与えた基準記述の内容を評価するため、`iautreatment`の引用には少なくとも階数1が必要になる。前段の政策引数は階数0であり、この内容をそのまま代入する型の変更はしていない。具体的な基準をNoemaの閉じた定義へ展開して特殊化するか、必要な引用階数を保つ別の明示的な接続が必要である。階数を無視して通すことは検査で拒否する。

96テストが通過した。検査では、二基準について現在・比較二状況の要求64通りと、現在の要求・履行16通りを照合した。別人、引数の逆順、同内容の別記述、空の範囲、未知の内容、現在が比較範囲外の場合も含む。診断の関数再利用を外した基準例との一致も確認した。三文書の長形式・短縮形式・独自文字の往復とCLI解析、抽出文書のSVGのXML構造も確認した。字形の目視確認は今回行っていない。これらは尊厳の語義や原文との意味一致の検証を代替しない。
