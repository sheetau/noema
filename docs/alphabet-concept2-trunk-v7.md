# concept2：v4の幹と、語参照の後方線 v7

作者の指定に従い、本文の参照順表記をv4へ戻す。v5でコンパクトな段選択・合流へ置き換えたのは新しい構成を利用するための選択であり、復号上の必須変更ではなかった。幹の形状自体は保存されており、復元できる。

異なる段を上・中・下の順に読む場合は、v4の線なし小円選択形を使う。それ以外の順序や重複はv4の幹をたどる形に戻す。幹の小円間の線は中円半径、枝先の小円は次の幹小円と同じ縦列という規則も維持する。合流・方向付き選択は任意の表記として残すが、本文の既定の出力には使わない。

小円を含まない中心線の形は、宣言済みの語の呼出しに限定して増やす。語を識別する中円弧と大円弧の両方が左180度に残り、後続の接続先となる中円弧も右0度に残る場合、中心の小円を外し、中心から大円の左円周まで1本の線を伸ばす。線は前方の宣言への参照を示す。識別円弧、対応キー、参照先、適用引数は変えない。対象は公開キー1・7であり、出現順に飾りとして交替させる規則ではない。右側の円弧がない場合は中心に2方向の線が集まるため、置換しない。

この条件に合わない語参照、値の局所参照、定義側、境界・分岐に必要な小円は維持する。今回の置換対象には小円が残らず、中心線は第4円の上限内に収まる。中心から左への線を、数字や型の識別コードへ転用することもしない。

v6の任意型・複数束縛・式・引用の修正は保持する。旧版の生成器・復号器・成果物は保存し、この版はv6を継承する差分として実装する。幹の全36形の一致、対象語参照のSVG復号、本文40項目と追加構文の復号を確認する。内容・語義・参照対応を変更しないため、既存の意味判断は引き継ぐ。外観は作者確認前に固定しない。
