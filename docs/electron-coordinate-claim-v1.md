# 電子の座標選択と共動系での瞬間静止

u0245の二文を、一つの電子・指定出来事・瞬間速さを共有する論述として接続する。第一文の一般性は、既存ek6eの全物理設定の代表配置と法則の答え候補の保存で読む。新しいek6f/gがKの四原点と瞬間速度(v,0,0)を指定し、著者による正当な許容・仮定の採用・指定瞬間についての考察を既存の関係で組み合わせる。原刊のKoordinaten-sprungは座標原点と読むが、固定原文は変更しない。

第二文は、一つの共動系kとその原点ずれ・局所時間域・曲線への参照を保つ。ek6nは同じ電子の両系の完全な履歴と旧微分を要求し、ek6oは同じ出来事での新系の実際の三微分零を帰結にする。ek6pの非空性とek6qの条件付き帰結を分けるため、前提がない場合の空虚な静止にも、新系の静止を最初から仮定する循環にもならない。光速度は既存tcへ固定する。

第一文の回転選択に光速上限を追加しない。第二文は正の光速度と0≤v<tcでの局所的な共動系として読む。電子は指定瞬間に静止すればよく、加速度零、前後の静止、無放射は要求しない。kの原点ずれは未指定で、後続u0248の零原点を先取りしない。

XとKは既存の軸と系、vはu0244の同じ値、t=0はKの同じ指定瞬間、kは今回選んだ系に接続する。著者が同じ帰結を述べ、明白として提示すること、第一文への照応、括弧の補足、二文の順序を保持する。
