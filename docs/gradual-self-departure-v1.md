# 自己活動による未陶冶からの漸進的な離脱

第五文の前半を、同じ本人が同じ未陶冶から抜け出す過程として構成する。既存rcpの変化・被作用者・前後状態・生起・能動的参加・自己形成の作業・結果生成を再利用し、未成熟bfや能力upを未陶冶の同義語にしない。r6azでは同じ基準のr6apと、その状態から外れるr6ayを前後へ渡す。

本人が参加したという事実だけでvon selbstを済ませず、r6a2で同じ過程を本人の関心・経験・検討からの働きかけへ結ぶ。助言や教育、他者との協力を一律に排除しない。無意図の反応、努力不要、本人だけが十分な原因になることも要求しない。

r6aw/r6axは形成度の質的な比較を使う。履歴・両端・全区間の評価と、比較の反射性・推移性・比較可能性を確認し、始点より高い終点と、その間の厳密な中間の形成度を要求する。一段として小幅でない正の増分には、時間上も形成度上も途中にある点が必要である。単なる中間時刻や、一度の飛躍と長い停滞だけでは満たさない。

途中の後退は許す。障害の件数、全区間の単調増加、数値上限、実時間当たりの速度や連続性は原文に加えない。比較対象と小幅の基準は同じ本人・基準で固定し、結果に合わせた刻みの選別はしない。r6a3は、未陶冶の状態から外れた点の形成度が未陶冶の点より高いことを全区間で確認し、状態区分と段階比較を別の内容にしない。

r6a4で同じ過程・本人・区間の自己活動、漸進、状態区分を接続する。終端での成果を扱う構成であり、本文では非介入という条件の内側にこの達成内容を置く。現在すでに全員が離脱を完了したという事実へは移さない。

局所検査は複数段階・一挙の変化・途中の後退・評価漏れ・循環する比較、同じ自己活動と結果生成、状態区分との整合、本文接続に渡す全引数、未知を確認する。小幅や自己からの働きかけという入力の現実の適合を自動認定する検査ではない。全関連時機・目的期間の非介入、条件とnur、人々の範囲、全文帰属と通読は残る。正本116主張と既存判断は変更しない。
