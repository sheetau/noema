# 良心に適う職務遂行と、条件付きの辞職要求

カントu0012の、規定群に内的宗教と対立するものがあると本人が判断した場合に、良心に適う職務遂行ができず、職を辞すべきだという箇所を部分記述した。能力の判定、条件文、辞職への要求、実際の役職保持の終結を別々に表す。

## 同じ結果で職務遂行と良心への適合を満たす

`rg3`は、同じ人・役職・状況について、職務遂行と良心に適うという評価が共に成立する内容である。一方の結果で職務を行い、別の結果で良心への適合を満たすだけでは成立しない。二つの関係は独立した引数であり、職務遂行から良心への適合を推定しない。

既存の能力構成`xd`・`xg`・`xe`を、同じ役職に結びつけて使う。

| 定義 | 条件 |
|---|---|
| `rg4` | 利用可能な方法のうち、非空で整合した評価結果の全てで`rg3`を満たす方法がある。 |
| `rg5` | 利用可能な全方法の評価が整合し、その中に`rg3`を達成する方法がない。 |
| `rg6` | 全利用可能方法について、評価対象の結果が非空で想定結果に含まれる。 |

ある方法の評価が欠けているとき、`rg4`が偽というだけで`rg5`を真にしない。成功する方法が一つ確認できても、別の方法は未評価という状態も表せる。その場合、`rg4`は真、`rg6`は偽となる。

利用可能な方法がないと明示されていれば、達成方法がないという判定は成立しうる。方法や評価が未知である場合は、方法が存在しないとは補完しない。評価範囲が実際の選択肢を尽くしているか、何を良心に適うとするかは、この形式だけでは保証できない。

## 本人による役職保持の終結

`rhc`は既存の自己による状態終結`rcf`を使う。同じ本人・役職・行為について、順序付き履歴の前では役職を保持し、後では保持しないことに加え、本人の行為であること、本人への作用、同じ保持状態の終結関係を要求する。二時点で真偽が異なるだけの変化とは区別する。

`rhd`は、この終結の目標を人・行為から内容への関数として作る。評価文脈を始点とし、それより後に終点があることを表す。期限や所要時間は加えない。後の終結が起きるという内容を記述できることと、その未来を予測できることは別である。

カント側の`hzby`は、既存の本人別履歴・順序・委任・変化・本人への作用・行為の関係に接続する。ここでは委任状態の終結を辞職の一部分として読む。辞意の表明、受理、法的な効力、強制の有無や意図の全意味まで定義したものではない。

## 仮定の中の要求と、現実の辞職

`rg7`は、前版の「対立する部分があるという本人の判断」を、仮定状況で評価する。その際、規定群にどの部分が含まれるかは元の基準文脈で固定する。仮定ごとに別の規定群や別の部分へ差し替えない。

`rha`は、明示した非空の仮定範囲の全てについて、`rg7`の判断があるなら、同じ役職について`rg5`が成立し、同じ行為・目標記述への肯定的な要求があるという条件文である。`rhb`は、さらに前件を満たす仮定状況の存在を要求する。

全候補で前件が偽なら、`rha`は成立しうるが`rhb`は成立しない。範囲自体が空なら、どちらも成立しない。前件を満たす候補において、遂行できる方法がある、評価が欠けている、要求がない、のいずれかなら条件文は不成立となる。本人の判断から不能や義務を常に導く公理を追加したわけではない。

カント側の`hzbz`・`hzb2`は、これらを既存の要求関係`h7a`に接続する。目標には、同じ役職と終結関係を閉じた式で渡した`hzby`の引用を使う。記述生成補助は通常のNoema引用と関数適用を作るだけであり、人が同じ式を直接書ける。規範の出所・本人・役職・行為・引用構造・極性・文脈を保ち、同じ値になる別名にも自動で要求を移さない。

要求を調べる際に目標内容を実行しないため、終結関係が未知でも要求を記述できる。実際の終結を調べる際にはその関係が必要になる。現実の判断、現実の辞職要求、後の辞職がそれぞれ成立しない設定でも、仮定範囲内の条件文が成立しうることを検査した。

## 検査と残る意味

能力64設定と5対照例、仮定の前件・遂行能力・要求64設定、仮定範囲16設定、未評価の方法を含む4設定を検査した。参照先・目標記述・極性の21対照例に加え、役職保持の終結64設定と履歴・本人・役職・行為を変えた24対照例、現実の判断・要求・終結を独立に変えた8設定を検査した。全文草案と独立抽出文書で同じ結果になること、未知の関係を補わないことも確認した。

内的宗教と良心の実質、発見という認識行為、仮定範囲の選び方、`denn`による説明、要求の出所、辞意表明・受理、全文の意味一致は未完である。形式上の条件を満たすことを、規範が正当だという証明として扱わない。

12定義を追加し、原始概念・局所参照・著者主張は追加していない。全文草案は105,691代用文字で、前版から3,351文字増えた。一般構成は4,853文字、独立抽出文書は5,680文字である。定義を含む長さで、一文の翻訳の圧縮率ではない。
