# 任意運動する物体の総電荷の履歴

u0238 の定理は、任意に運動する帯電物体について、物体とともに動く座標系から見た電荷が変わらなければ、K から見ても変わらないと述べる。二系の電荷の数値等値と、各系で時間を通じて一定であることは別の内容である。

今回は同じ物体の全物質点を追う完全な履歴から、各時刻の全体電荷を構成する。`ek22/ek23` は同じ物体・分布・全成員・系・出来事・時刻・単位を既存の物理的保有量 `eisvy` へ結ぶ。各時刻に記録を要求し、同じ追跡点の全記録で値を一致させる。内部の各部分の電荷まで一定にする既存の不変付着は使わない。

`ek24` は正長の全区間の任意の二時刻で総量が等しいという一定性、`ek25` は少なくとも一時刻での非零の総電荷である。負電荷を含み、全体一定でも内部での電荷移動を許す。端点だけの一致、途中の記録欠落、時間とともに単位を変える操作では一定性を満たさない。

物体とともに動く座標系は、その物体の一つの同じ物質的な追跡点へ原点を随伴させた系と読む。`ek26` はその全区間で追跡点の三座標が零であることを要求する。物体全体の剛性・等速・一様密度や、共通の静止慣性系は要求しない。比較する二期間は `ek27/ek3a` により同じ追跡点の同じ出来事で両方向に対応させる。二系の時刻値や、全体電荷を計る同時切片の出来事集合を同一視しない。

`ek3b` はこの物理的設定と K での運動をまとめる。`ek3c` は随伴系の一定性を前件、K の一定性を後件とし、`ek3d` がすべての設定へ量化する。原刊の一般運動を一つの定速 Lorentz 写像に縮めず、旧 `seni/senh` の一様密度の相殺だけを使って結論を完成扱いにしない。

対象は構成員を追跡する持続的な物体と、同じ過程の有限区間という明示した読みである。物質の生成消滅や構成員が変わる開放系をこの定義だけで扱ったとはしない。数式と物理的帰属の結合は検査するが、著者の一般的な物理的導出を証明したとはしない。容易に導ける重要な定理という評価、簡潔な補足の提示、引用符付きの「静止」系 K、全文の著者帰属と意味判断は残る。
