# 真空中の共通光速度

u0004第二文のうち、光が真空を常に一定の速度Vで、放出元の運動状態によらず伝播するという仮定の内容を構成する。前文の推測を前提へ採用する意思、その命名、二原理の見かけの不整合は次の接続で扱う。この依存群では著者の主張を追加せず、第二文全体の意味確認も登録しない。

`eifw` は同じ光線・放出元・放出・伝播区間・系・単位を束ね、真空という条件と幾何学的な経路長を与える。区間の両端では既存の `saf` により、その系に静止した局所時計を同じ参照時計へ同期して時刻を読む。既存の `sax` が正の距離・経過時間・速度と、距離＝速度×経過時間を要求する。放出元の速度を足す項や、往復測定の係数2をこの式へ加えない。

`eifx` は `sak` を再利用し、空でない全適用区間へ同じ速度を渡す。範囲は全方向・全時刻・全ての非零部分区間と、光源の運動状態を変えた設定を含む。その完全性は独立した意味入力であり、静止と運動の二標本の一致から認定しない。物理的な記録を整える条件と、望んだ速度が得られるという条件を分け、後者で対象を選別しない。

`eify` では、力学方程式が成り立つ系を任意に選んでも、この共通速度Vを使うという読みを明示して採用する。各系の単位規約を同じ物理的な尺度へ結ぶ。旧草案の固定系 `ra` に限定せず、加速座標系や媒質中へ等しい座標速度を要求することもしない。原文の記号Vは実数値 `tc` へ接続し、数値は指定しない。

新しい基礎入力は、電磁放射としての光、真空、伝播記録、時計と単位の規約、幾何学的な経路長、適用範囲とその完全性である。経路長は全有限折線長の上限としての弧長を意味する量の帰属として扱う。この版で一般的な弧長計算器や実験による光速度の証明を実装したとはしない。理想時計を用いるため、全地点に実機が設置済みであることも要求しない。

検査は、引数ごとの結合、両端の時計と場所の取り違え、同期の欠落、単位の取り違え、異なる速度、空の範囲、一つだけ不適合な区間、適格系の全称範囲を扱う。局所時刻と速度条件の本体を実行する一方、同期と実数演算を検査入力として切り出す。既知の有理数から構成した切断で算術を検査し、未知の切断を有限点で推測しない。全実数の定義は有限評価を拒否する。これらの検査は物理的な全域の確認や原文との同義性の自動証明ではない。
