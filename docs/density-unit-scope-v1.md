# 密度説明における単位の適用域

u0203第一文の[前候補](density-relativity-v1.md)は、エネルギー単位の校正を結論側の密度モデルにだけ含めていた。全称量化の前件にその校正がないため、校正されていない個体まで「単位」として扱う過剰な適用域になっていた。

本版では、旧系と新系の同じエネルギー単位・力・長さ時間・場の単位・換算係数の対応を、既存eisteで前件へ明示する。密度モデルの採用eistj及び周期平均の値は結論側に残す。これにより、校正された共通単位の下で、相対性原理から新系の密度説明へ進むという第一文の読みを保つ。

検査では両系それぞれの校正を必要とし、一方だけ、異なる単位、異なる係数又は別の状況を拒否する。未校正の単位を含めた前候補の読解判断は、この現在の文書には適用しない。旧候補と検査証拠は履歴として残し、全単位判断済みの旧385主張を変更せずに、第一文の文番号385だけを改訂する。
