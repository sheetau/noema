# 未知関数φの残存と決定の意図

Einsteinのu0092は、得られた変換式に速度vの未知関数φがなお残っており、これからその値を決めるという一文である。原刊901頁の両立性の結論と第三系の導入の間にある。現在の四式ei7cと正規化後の同じ関数spcを参照し、前の係数aとの区別を保つ。

未決定性には既存のsqdとsrpを使う。sqdは四式を得た先行段階zfm、srpは決定へ進む現在段階zglに属する。同じ0≤v<Vの範囲で、現在の関数を含む有効な候補が残り、少なくとも一つの速度で異なる値を持つ候補があることを表す。ある速度で候補が一致しても、関数全体が決まったとはしない。先行と現在の候補集合を同一に固定する条件はない。

ejawは現在の四式と両段階の未決定性を合わせる。「noch」は同じ問題が現在も残るという読みであり、間の全瞬間の心理状態を補わない。未知であることを関数の不存在へ置き換えず、後で用いる負速度域やφ=1をここで決めない。

ejaxでは、著者がこの残存を述べるuhと、同じ関数の記述を対象に現在段階zglから値を決める意図zgmを結ぶ。関係節の「welche」は同じspcを受け、「nun」はこの論述上の段階を指す。意図は成功・決定完了・一意解・具体的方法の発見と異なる。未知性の箇所から意図の箇所へ、また前の両立性の結論からこの一文へ進む順序を保持する。

検査では、現在の関数と正規化された候補族、同じ段階・同じ速度での相違、現在候補の残存、引用対象と意図の参照を確認する。実数切断や関数全体への量化は有限評価器が拒否することを保ち、明示的な例化と境界で検査する。全文の意味判断は原刊・固定本文・意味規約の通読に基づき、有限例の通過から自動生成しない。
