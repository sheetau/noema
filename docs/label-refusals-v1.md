# 名称の使用を拒む表明

カントu0015の「寛容という名称を自分について拒む」箇所へ、指定した名称で自分を呼ばないよう求める表明を構成した。名前を使う行為、名前が表す性質、名前の使用を拒む表明、実際に使われなくなることを分ける。

| 定義 | 内容 |
| --- | --- |
| `rnh` | 同じ行為の生起と提示者を確認し、その行為で指定した名称を指定対象へ適用する |
| `rni` | 明示した非空の使用者範囲に、同じ対象を同じ名称で呼ぶ行為がないという内容 |
| `rnj` | `rni`の不使用を実現するよう促す発話を構成する |
| `hzfv` / `hzfw` | 不使用の内容と呼びかけを、既存の生起`dg`・提示者`f3`へ接続する |

`hzfw`の閉じた記述を既存の`hzft`へ渡すと、話者本人について名称を使わないよう求める実際の表明を記述できる。話者・対象・行為・文脈・メッセージをそろえ、指定した非空の受け手全員への提示を求める。発話を構成しただけでは実際の表明にならず、表明があっても相手が従ったとは限らない。

この構成での拒否は伝達的な形であり、内心で受け入れない態度や、非言語的な拒絶、制度的な称号返上まで同一視しない。原文が特定の発言場面や受け手を挙げているという主張でもない。受け手と不使用を求める相手の範囲は別引数であり、接続例で同じ範囲を渡す。型だけで一致を強制しない。

名称は個体として識別する。同じ性質を表す名称が二つあっても、その一方の使用拒否をもう一方へ自動的に広げない。また、名称で呼ばれたことは、その名称が表す性質を実際に持つ証拠ではない。その性質を持ちながら名称を拒む場合も記述できる。

名称適用の関係は、同じ行為・名称・対象・文脈を結ぶ。名称への単なる言及はこの関係に含めない。同じ文脈に発話行為と名称適用の記録があっても、行為が別なら結合しない。名前の綴りや音、社会的な命名慣習、概念定義との対応は引き続き説明が必要である。対象となる名称を識別する参照だけで「寛容」の意味を説明したとは数えない。

不使用の内容は各評価状況について判定する。過去の全履歴や将来の永続的な不使用を含めない。指定範囲外の人の名称使用は、その範囲への不使用の要請とは別である。空の使用者範囲を達成の証拠にせず、名称適用の記録が未知なら評価を拒否する。

[一般文書](../examples/v014/label-refusals.noema)は883文字、[原文付き草案](../examples/v014/kant-label-refusals.noema)は187,935文字、[抽出文書](../examples/v014/label-refusals-core.noema)は1,195文字である。五定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-label-refusals-basis-v1.json)と[検査記録](../reports/label-refusals-v1.json)を保存する。

表明の生起・提示者・内容提示、名称使用、名称が表す性質の真偽の32通りを検査した。原文付き文書と抽出文書では、話者・行為・対象・名称・文脈の取り違えや空の範囲を含む12条件ずつを検査した。追加15テストで別名、複数の受け手、範囲外の使用、未知の記録、引用の非実行、主張・質問・呼びかけの区別、時間範囲を確認した。三文書のCLI解析、固有文字v2の往復、SVGのXML検査も通過した。SVGの目視確認は含めない。

「寛容」の概念と呼称の社会的な意味、「傲慢な名称」という評価とその帰属、前段からの論証関係、「自ら」という強調、称賛・解放と後続の論述は残る。この部分草案を原文の拒否概念の全てや段落全体の意味一致へ昇格させない。
