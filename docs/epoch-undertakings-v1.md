# 前後の時代の人々と相互の宣誓

カント第六段落の `Ein Zeitalter kann sich nicht verbünden ... weiter zu schreiten.`（u0013 [713,1004)）について、前後の時代に生きる人々と、先行する人々の合意・宣誓の接続を作る。全文の意味判断はまだ行わない。

`Zeitalter` は各時代に生きる人々として読む。既存 `rjh` は、固定した区分での直後関係と、その時代のいずれかの時点に生きる全ての人からなる集団を構成する。同じ人が両時代に属してもよい。新しい `r5bw` は対象履歴の全点を区分が覆うことを追加する。旧定義では時代の間の時間が未割当でも直後と判定できたためである。`r5bx` がこの条件を、生存関係・全人類・同じ候補での集団所属に結ぶ。

合意当事者の範囲 `h26ac` は、時代の全生存者から区別して固定する。`r5by/bz` は当事者が先行集団の人であり、条項の基準点が先行時代にあることを確認する。同時代の全人類の署名や後代の同意を要求せず、当事者に時代全体を合法的に代表する資格があるとも述べない。

`r5ca` は本人の引受け・他の全当事者への相互の引受け・宗教的な宣誓を、同じ行為・合意・条項・引数・時点へ結ぶ。`r5cb` は既存 `rhz` により、二人以上の全当事者、条項の割当て、行為の生起と担い手、固定基準までの配置を確認する。宣誓は直前の文と同じ宗教的な読みを採る。条項と神的な権威の内容は引用であり、履行や神の実在をここで評価しない。

検査は小さな時系列の27区分を独立した区間判定と比較し、全成員・時代の間の空白・生存者の重なり・先行当事者・同一の相互表明への反例を調べる。接続用の境界検査に加え、全定義を実行する統合例を置く。未入力の関係は拒否する。旧文書・旧判断・99主張の本文を変更しない。

条項と引数関数はまだ明示した引数である。後代の知識の拡大・誤りの除去・啓蒙進展の不能性、それを生む状態への目的と必然性、共謀的提示、規範的な `kann nicht`、括弧の重要性と `überhaupt`、全文の著者帰属は残る。確認済み文字数は増やさない。
