# 二つの逆変換の求め方と、その比較

アインシュタイン1905のu0165を部分記述した。先行する変換式を解く方法と、同じ規則を逆速度−vへ適用する方法を区別し、両者の一致から係数の積1へ進む論述を追加した。

## 計算する関数と、手順の記述

第一の方法 `sbj2`・`sbk2` は、逆速度の変換に係数ψ(v)の逆数を掛ける。第二の方法 `sbl2`・`sbm2` は、係数関数を−vで評価したψ(−v)を掛ける。先に両係数を同一視せず、異なる式として構成する。逆数を使う条件 `sbi2` は、係数が有効で非零であることを要求し、負の係数も許す。

[一般用文書](../examples/v014/inverse-methods.noema)の `sbs2` は、既存の有限手順列を再利用する。同じ前提の記述から異なる二つの結論記述まで、それぞれの手順が順につながることを要求する。空の手順、途中の断絶、結論の取り違え、許容されない変形を区別する。

[論文文書](../examples/v014/einstein-inverse-methods.noema)では、二つの逆式の内容を `sbp2`・`sbq2` に分けた。両方とも同じ新系の場から同じ旧系の場を復元し、場と座標系の割当、領域の一致を保持する。`sbt2` は先行する式の記述からこの二式へ至る手順を結ぶ。手順が記述されたことを、実際に実行済みであることや数学的に健全であることとは扱わない。

## 一例の一致と一般的な一致

零の場なら、異なる係数を掛けても両方法の出力は零になる。その一例からψ(v)ψ(−v)=1とは結論できない。

二つの方法は同じ逆速度の線形変換を共有するため、残る係数写像を比較する。`sbn2` は指定した入力値についての一致、`sbo2` は任意の有効な実数入力についての一致を表す。原文の「二つの方程式系が一致する」という要求を、特定の場だけの一致に弱めない。

非零入力で二つの係数写像が一致すれば積1が得られることを、有理数の一般式で検査した。全実数上の一致を有限標本に置き換える評価は拒否する。新しい推論前提 `sbu2` は、手順の接続、先行する式の成立、一般的な係数写像の一致を別々に要求する。
