# 同じ合意の因果的帰結と形成の禁止

第八文の「合意し、それによって期間を不毛にする」ことの不許可を構成する。禁止の対象は合意形成そのものに置き、結果が現実に出た合意だけへ狭めない。その合意に基づく制度方針が不毛化へ至るという帰結は、別の内容として同じ対象へ結ぶ。

`r5jn` は合意・共同体・制度・公衆・期間の正確な五対象列から合意形成を返し、`r5jo` は同じ期間の人類の改善不在を返す。真偽評価は固定基準から与え、都合のよい候補へ替えない。`r5jx` は同じ合意の形成とその制度方針の実施を結ぶ。

実際の因果結果 `r5jp/r5jq` には、同じ候補で形成・実施・結果がそろい、既存 `h26as` の因果的な働きがあることを要求する。結果の共存だけで原因とはしない。一方、`r5jr` は既存 `h253x` を使い、同じ合意に基づく方針を適用・維持すると同じ期間の不毛化に至る、という帰結を引用された内容のまま結ぶ。現実の形成や結果は要求しない。どちらも現実の因果を自動的に発見する手続ではない。

候補枠組み `r5js` は、指定集団を同じ合意の固定した複数当事者に過不足なく一致させ、制度・公衆・期間・合意基準を保つ。同意表明や成功を範囲の条件にしない。集団を先頭にした六対象列の `r5jt` が、規範上の禁止対象となる共同形成を表す。

`r5ju/r5jv` は全候補への負極性要求として禁止を表す。許可が見つからないこと、実際に誰も合意しなかったこととは区別する。`r5jw` は同じ全候補への因果的帰結を別に述べる。禁止と帰結はどちらも保持するが、片方から他方を機械的に導かない。
