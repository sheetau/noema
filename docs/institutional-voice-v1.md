# 組織の名による提示と、その組織についての報告

カントu0012の「他者の名で述べる」と「われわれの教会はこれこれを教える」という箇所へ、組織の声としての提示と、組織の教示についての報告を部分接続した。本人の発話、職務の委任、組織の実際の立場、内側の内容の真理、本人の賛同を分ける。

## 同じ行為に役割と組織を結ぶ

`rga`は、本人が同じ発話を非空の受け手群へ実際に提示し、その行為を同じ組織・役割の声として位置付ける条件である。提示者・行為・組織・役割・対象・発話記述・状況を一つの帰属関係に渡す。別の人や行為の帰属を混ぜない。

`rgb`は、そこへ同じ職務の分類、委任、その組織への奉仕を加える。単に組織の声として提示する場合と、その職務を委ねられた人が提示する場合を区別する。ただし、委任があることから、個々の発話が許可されていること、組織が実際に承認したこと、発話の正当性までは導かない。

カント草案では`hzbp`・`hzbq`が、これらを既存の生起・提示者・伝達・職務の関係へ接続する。帰属関係`voices`と奉仕の関係`serves`は明示的な入力であり、数値や発話の真偽から推定する処理ではない。

## 実行せずに、任用条件として記述する

`rgc`・`hzbr`は、組織・役割・受け手・対象・発話などを固定し、本人と行為から上の内容への関数を作る。閉じた適用を引用すると、前版の[任用条件と現在の要求](appointment-terms-v1.md)へそのまま渡せる。

任用や義務の対象として記述することと、実際に述べたことは別である。原文の「述べるために任用されている」を、既に講義したという断言に置き換えない。現在の提示や役割遂行が成立していない設定でも、過去の任用条件や現在の要求は成立しうる。

## 報告の内側を勝手に真にしない

`rgd`は、指定した組織が、指定対象について内側の発話を教示内容として提示する、という外側の主張を構成する。組織の教示関係を`teaches`、内側の発話記述を`message`として渡す。内側の記述を実行する操作は含まない。

この外側の発話を提示したことは、「組織が実際にそう教えている」という関係の成立とは別である。さらに、その組織関係が成立しても、内側の内容が真であることや本人が賛同することは要求しない。外側と内側の対象は同じ引数で保持し、組織や内容を途中で入れ替えない。

例えば、組織の教示についての報告が誤りでも、その報告を本人が提示したことは記述できる。組織がその内容を教えていても、内容が偽で本人が賛同しない場合も記述できる。組織に教示があるか不明なら、報告の提示だけを評価し、組織関係を補わない。

## 検査と残る課題

提示の生起・提示者・伝達・組織への帰属・役割分類・委任・奉仕の128設定を検査した。35対照例では、本人・行為・組織・役割・対象・状況・発話記述の取り違え、空の受け手範囲、伝達の不足などを区別した。実際の提示条件と、引用した構成を評価した結果は一致する。

組織の実際の教示、内側の真理、本人の賛同の8通りを独立に変えても、外側の報告は提示できた。外側の働きが主張であることも確認した。5対照例で、別の組織・対象・状況・質問・同じ真偽を返す別名への置換を拒否した。

任用の32設定では、過去の生起・委任・任用・条件と、現在の要求を分けた。現在の提示を全て不成立にしても、同じ閉じた記述を任用条件と要求へ渡せる。全文草案と独立抽出文書は同じ結果になった。これらは指定した有限モデルの検査であり、原文全体との意味一致を証明するものではない。

組織の教示を構成する制度・伝達経路・集団意思、教会や教理の一般的な意味は未完である。「われわれの」の集団の指示、「これこれ」の例示と不特定性、「言うであろう」の予想、証明の根拠、本人の自由な裁量の不在、良心と辞職も残る。今回の帰属関係だけで、組織の代表権や発話の正当性を定義し終えたとは扱わない。

7定義を追加し、原始概念・局所参照・著者主張は追加していない。全文草案は97,248代用文字で、前版から1,517文字増えた。一般構成は1,238文字、独立抽出文書は3,664文字である。定義を含む長さで、一文の翻訳の圧縮率ではない。
