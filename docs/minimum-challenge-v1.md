# 最小の困難と、人物・課題を固定した期待の比較

カント第三段落第四文の「最も狭い溝でさえ」に相当する部分を、知的活動側の「最も小さい困難でさえ、不確かな判断になる」という読解候補として構成した。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)の物理的な幅を、知的な困難と同一視した証明ではない。身体的な描写との対応は引き続き必要になる。

## 課題の最小性

`r2hr` は、提示文脈で本人について選ばれた同じ課題 `hzzzz` を、固定した課題範囲 `h222a` と困難の比較 `h222b` に結ぶ。既存の `rce` を使い、範囲が非空で、比較が反射的・推移的・全比較可能であることと、指定課題が全課題以下の困難であることを検査する。同順位の最小課題は複数でもよい。選ばれた一つを行うことから、同順位の全ての課題を行うことは導かない。

`r2ht` は、この最小性と、前版の不慣れによる不確かな判断 `r2hj` を前景として要求する。最小性を因果関係の結果記述へ追加していない。不慣れが課題の難しさ自体を生み出すという主張にはならず、因果関係は引き続き同じ `r2hh` と `r2hb` の記述を結ぶ。

## 期待の比較で保持するもの

課題が難しいことと、その課題で不確かな判断になると見込まれることは、独立した意味入力である。難しさの順序から期待を自動的には作らない。

既存 `hzpt` は閉じた内容記述どうしを比較する。今回、人物と課題を量化したまま比較するため、一般の二引数内容述語を引用し、その両側の人物・課題と観点主体・文脈を明示する比較 `h222c` を追加した。実行時の自由変数を閉じた引用に隠さず、各人の内容を全員についての別の内容へ置き換えない。異なる形式の記述に対する `hzpt` の比較値と自動的に一致するという規約は追加していない。

`r2hn` は指定課題についての不確かな判断を表す。固定課題を渡すと前版 `r2hb` と一致する。期待比較は、この同じ閉じた述語と同じ人物を保ち、課題だけを変える。比較するために述語を実行する必要はなく、代替課題で実際に判断することも要求しない。

`r2ho` は期待の弱い順序の反射性と推移性を検査する。比較不能を許し、数値確率や全順序は要求しない。`r2hp` は、逆向きの弱比較が成立して順向きが不成立である場合だけを、厳密に見込まれにくいとする。同順位・比較不能・未知入力をこの条件と混同しない。

## 前景から分離した尺度背景

`r2hq` は最小課題に対し、同じ範囲で厳密に難しい課題が少なくとも一つあり、その全てでの同じ内容より焦点の内容が見込まれにくいという背景を構成する。都合のよい一つだけを比較対象に選べない。同順位の最小課題はこの代替範囲に加えない。単一課題や全て同順位の場合、最小性は成立しても、この背景は成立しない。

`r2hv` と `r2hw` は、同じ本人・非空の仮定集合に対して、依存離脱からの前景と背景をそれぞれ結ぶ。背景を離脱の仮定内に置く読解であり、現実の全時点への投射は加えない。`r2hx` と `r2hy` は先頭文から継承する同じ非空の人物範囲を使い、`r2hz` は閉じた二内容を既存の前景・背景の対にする。前景だけを否定しても、背景の記述は保たれる。

この分離により、期待比較が成立しなくても、最小課題で不確かな判断になるという前景は成立しうる。逆に期待があっても、因果的な帰結を満たすとは限らない。どちらかの内容を引用しただけで、その内容が現実に起きたと主張することもない。

## 検査と残る範囲

七テストで、三課題間の困難比較512通り、期待比較512通り、二人それぞれの前景・背景16通りを検査する。最小性の同順位、空範囲、指定課題の範囲外、順序の不整合、期待比較の人物・述語・文脈の取り違えも対照にする。未知入力を偽に補わず、引用された判断内容が未知でも期待の比較を実行できることを確かめる。

同順位の別の最小課題に関わる比較値を32通りに変えても、尺度背景の結果が変わらないことも確認する。現行の有限評価器は論理式の両辺を評価するため、範囲外の比較値も問い合わせることがある。この検査が保証するのは結果への非依存であり、範囲外の未知入力を評価しないという実行上の保証ではない。

さらに、前版の離脱・不慣れ・判断・因果関係と、新しい最小性・期待比較を同じ有限世界で実行する。最小性や期待を変えても、元の因果条件の結果は独立して保たれる。固定課題を引数に開いた内容との一致、引用、および通常・短縮・独自字形の三記法の往復も検査する。有限検査は原文との同義性の自動証明ではない。
