# 入射光と反射光の量の指定

原刊914頁u0216–u0219の本文184非空白文字と六つの数式要素を接続する。入射光をKでA、cosφ、νにより指定する二文と、そのkでの三式、反射過程をkで扱うと得られる三量の導入と表示を、それぞれ著者の提示として保持する。

同じ完全反射面と前節の波の設定を引き継ぐ。振幅は一度選んだ電気側又は磁気側の三係数の非負の大きさ、周期数は同じ正規化した一周期と時間単位に結ぶ。三数の指定はこの計算で扱う量の指定と読み、偏光・接線方向・位相まで三数で一意に定まるとはしない。同じ三次元の場と二偏光は残す。

角については前節の固定した読解を維持する。φは源―観測者方向と速度との角であり、φ′はu0193にある、kでの波面法線と光源―観測者の同時刻結線との角である。φ″は反射した法線と同じ比較結線との角として読む。同じ文字を使う式だけを根拠として、角の基準線を座標軸へ変更しない。

この読みでは角の式に不一致が残る。V=5、v=3、旧法線(111,48,80)/145を取ると、kでの入射法線は(15,24,40)/49、同時刻結線の極限方向は(111,60,100)/161になる。その内積145/161がcosφ′だが、M0372の右辺は15/49である。反射後の法線は(−15,24,40)/49で、同じ結線との内積は3775/7889となり、M0374の−145/161とは一致しない。この例はkでの法線縦成分が正で、現在の鏡への入射側にも適合する。

この不一致は原文を変更せずに記述する。印刷された三式は著者の条件付き主張と表示として保持する。三式を物理設定の前件へ入れず、正面入射だけへ限定して一致を作ることもしない。前節の意味判断も変更しない。波の振幅と周期数の変換、法線の鏡映、指定された角についての式の真理、著者が式を提示することは別の事柄である。

同じ82設定を量の定義と各三式に共有する。新しい表記個体はこの箇所の量の使用を識別するもので、同じ波・系・側・基準線・状況へ結ぶ表記規則を伴う。仮定採用、量の命名、kへの参照、帰結提示、コロン、式の表示、著者帰属と順序は既存関係で合成する。新しい一般基本関係は加えない。

原刊と六つの数式要素を全行読み合わせ、明示した角の読解の下で、これら四単位の対象・量・条件・式と提示を記述したと判断する。これは著者の式をすべて真と認定する判断ではなく、有限検査による同義性の自動証明でもない。次にKへの再変換とその原刊の式を扱う。
