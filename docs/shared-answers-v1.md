# 部分回答と全回答の共通定義

一個体、または順序付きの二個体を答える問いについて、回答の正しさ・網羅性・未回答の候補を20定義で構成した。[型付きの問い](spec-v012.md)と既存の関数・量化・引用を使い、新しい基本宣言や構文を追加していない。[本文](../examples/v016/shared-answers-v1.noema)と[意味規約](../data/shared-answers-basis-v1.json)を正本とする。

## 正しい回答と、全て答えたという明示

回答は、肯定した候補の範囲、否定した候補の範囲、肯定した候補が全回答だという明示の三つを持つ。候補は一個体、または順序付きの二個体の組である。否定した候補の範囲を、肯定した候補の補集合で自動的に埋めることはしない。

たとえば、参加者がAkiとNaoである場面で「Akiが参加した」と答えれば、その情報は正しい。しかし、「Akiだけが参加した」という全回答として扱うと誤りになる。参加者が実際にはAki一人であっても、「Akiが参加した」という情報だけから、話し手が全回答を明示したことまでは導けない。この区別のため、実際の網羅性と網羅の明示を別々に検査する。

| 一個体についての定義 | 検査する条件 |
| --- | --- |
| `answerconsistent` | 肯定域と否定域が重ならない |
| `answersound` | 肯定した全候補が答えであり、否定した全候補は答えでない |
| `answerinformative` | 肯定または否定した候補が少なくとも一つある |
| `answercovers` | 実際の答えを全て肯定域に含む |
| `answercomplete` | 情報が正しく、実際の答えを網羅し、全回答だという明示もある |
| `answerpartial` | 情報が正しく、一候補以上を肯定または否定し、全回答だとは明示していない |
| `answerunsettled` | 指定候補が肯定域にも否定域にも入っていない |
| `answernone` | 問いを満たす候補が存在しない |

二個体の問いには、同じ八条件を`pairanswer`で始まる定義として与える。両者の型を明示しており、型の異なる問いを暗黙に混ぜない。

ここでの部分回答は「全回答を明示しない正しい情報」という読みである。偶然全ての答えを含む場合も許す。一方、何も肯定・否定しない空情報は、矛盾がなくても部分回答とはしない。「答えはない」という全回答は、空情報に全回答の明示を加え、実際にも答えがないことを検査する。既知候補について言及していないことと、処理系が解釈を与えられていないことも区別する。後者は評価エラーになる。

## 二対象の対応を保つ

「誰が誰と組んだか」という問いでは、第一の対象と第二の対象の対応が答えに含まれる。組が(Aki, Aki)と(Nao, Nao)なら、第一候補にも第二候補にも両者が現れるが、(Aki, Nao)は答えにならない。

`answerfirstquestion`と`answersecondquestion`は、相手が少なくとも一人いる候補を尋ねる問いを作る。`answerafterfirst`は第一対象を固定して第二対象を問い、`answerbeforesecond`は第二対象を固定して第一対象を問う。これらは問いを返す関数であり、答えの存在は主張しない。二つの候補集合から全ての組を作る操作を、元の対応関係の復元とは扱わない。

公開した共通語の対象は一個体と二個体の問いである。言語仕様自体は数値や関数等の型を含む任意の有限個数の回答位置を持てる。同じ条件を別型へ使う場合は、その型と位置に合わせて定義・量化を記述する。今回の有限検査は、無限の数値候補を全列挙する実行器や、全ての型に対する証明を提供しない。

## 提示した回答と、その内容の真理

[接続例](../examples/v016/partial-and-paired-answers-v1.noema)は、一部だけの正しい情報、網羅を明言しない全候補、明示された空の全回答、二対象の射影と対応を一つの文書に含める。例中の範囲と条件は本文のlambdaで定義し、外部モデルは二つの既存個体名だけを解釈する。参加者や組は抽象的な検査値であり、実在の人物についての主張ではない。

同じ文書で、[既存の提示関係](shared-speech-v1.md)に「Akiだけが全回答だ」という偽の内容を引用して接続する。明示した提示関係の下では提示が成立し、内容を別に評価すると偽になる。提示関係を本文で真とした検査例であり、現実の対話の認定根拠を与えるものではない。引用した内容を未知の解釈へ変えても、提示だけの判定は内容を実行しない。

[検証報告](../reports/shared-answers-v1.json)には、一個体の候補2個について肯定・否定・実際の答えの全64組合せ、二個体の順序付き候補4組について全4,096組合せを記録する。各モデルで網羅の明示の有無を両方検査する。射影は全16関係・192候補判定で、存在する相手と固定した相手を区別する。これらは有限領域での意味検査であり、全自然言語の回答行為の網羅証明ではない。

会話の受諾・訂正・撤回、前後の状態と履歴、円文字辞書への20語の接続は後続課題である。既存の二作品の採用解釈と固定字体は保持する。
