# 経路の存在と、同じ本人の自己離脱

以前の伝播候補は、受け手ごとに一つの経路を供給する関数を外から受け取っていた。今回の候補は「条件を満たす経路がある」と記述する。指定した経路が失敗しても、別の経路まで不存在になったことにはしない。

`hzpb` は最初の伝達、中継の有限列、取得過程とその前後点を存在量化する。同じ発信者・受け手・発話・性向記述を保ち、自己離脱が最初の発信に先行し、受領・理解・取得・持続が成立する既存 `hzoe` を使う。伝達と取得の時点は指定期間に属し、取得完了は初期点より後でなければならない。

中継列の型 `j[a]` は全ての有限列を表す。長さの上限や事前に選んだ候補表は文の意味に加えない。存在量化自体は既存文法で書けるので、新たな文法記号や基本関係は不要である。

`hzpc` は発信者を中心とする人の範囲から、`hzpb` を満たす受け手の正確な範囲を内部で作る。`hzpd` は、その外側で一つの自己離脱過程と前後点を存在量化する。これにより、経路は受け手ごとに異なってよいが、発信者が自立した過程は全受け手で共通になる。

`hzpe` は同じ人の独立判断への傾向とこの伝播を結び、`hzpf` は将来の各機会に複数の該当者がおり、その中に指定部分集団の人がいる内容を作る。自由の条件を評価する `hzpa` の内容族へ渡し、閉じた階数1の記述として著者へ帰属できることも検査する。帰属の評価では、内容の事実や存在量化を実行しない。

有限評価器は、長さが無制限の列を全列挙できない。この制約に対して、[証人検証](../noema/existential_witnesses.py)を追加した。先頭の存在量化に、型の合う閉じたNoema項を渡し、元の条件へ適用して通常評価する。束縛変数を文字列で置換せず、型検査された関数適用を使う。引用の境界と既存の評価階数も保つ。

| 結果 | 分かること |
| --- | --- |
| `valid` | 指定した解釈内で、この証人が条件を満たし、存在が成立する |
| `uncertified` | この証人は条件を満たさない。別の証人があるかは未判定 |
| 未知入力・資源上限のエラー | この評価では判断できない。真偽の値に置換しない |

これは全ての解釈に通用する定理証明ではない。解釈の基本関係は純粋な関数で、その意味が与えられていることを前提とする。また、見つかった受け手だけを集めても、存在を満たす受け手の正確な集合とは限らない。任意の広がり基準は単調とは限らないため、個々の証人検証を集団命題全体の証明へ昇格させない。否定・含意・全称量化の内部を自動的に証人で置き換える機能も持たない。

検証では、空列・一要素・257要素の列、数値・関数の証人、引数と束縛、型違い・自由変数・不足した証人・未知入力を調べる。具体的な性向については、自己離脱・受領・取得・持続を元の定義で通常評価し、人物・原因・順序・期間などの15対照を検査する。同じ存在命題で悪い証人とよい証人を試し、前者の失敗を不存在にしないことを確認する。

```powershell
python -X utf8 -m scripts.compose_existential_dissemination
python -X utf8 -m pytest tests/test_existential_witnesses.py tests/test_existential_dissemination.py -q
python -X utf8 -m scripts.check_existential_dissemination --verify-only
```

[累積候補](../examples/v016/kant-existential-dissemination.noema)、[意味規約](../data/existential-dissemination-basis-v1.json)、[検証記録](../reports/existential-dissemination-v1.json)を保存する。五つの合成定義を追加し、既存33文と七単位の確認を保つ。本文への新しい著者主張や原文対応範囲は加算しない。

発話・性向の評価基準・社会的範囲・広がり・期間などの解釈引数は残っている。経路と自己離脱を存在量化したことで、それらの値や、原文の比較・比喩まで確定したわけではない。全文の意味確認は引き続き未完である。
