# 同じ時刻の軸配置とその一意性

u0044の「各静止系時刻に一定の軸配置が対応する」を、同じ物理的な三軸の配置記述として読む。複数の記述が同じ配置を表すことを許し、状態の識別子を一つに限定しない。

配置断面は、履歴と同じ原点・三軸を同じ全役割で記述する。各軸の全成員と原点について、その時刻の三座標を履歴の実位置関数へ結び、断面の記録との値一致を要求する。原点標識の物体側の候補位置も、先行の `eiv2` で同じ原点の完全な軌道へ接続している。断面側へ期間全体の静止や運動を課す必要はない。

二配置の同値性 `eiwg` は、同じ時刻・原点・全軸成員の座標一致として構成した。名前の一致、平行方向だけの一致、見えている標識だけの一致ではない。`eiwh` は対応状態の存在と全対応状態の同値性を合わせ、一つの都合のよい記述を選んで不一致を隠さない。

`eiwj` は現行の並進と三軸幾何を同じ候補履歴へ結び、全選択時点での配置一意性を要求する。共通の時点範囲と運動の完全な時点範囲を一致させ、区間内の全実時刻に記録を持つ時点が存在することも明示した。二つの時点記録が同じ時刻値を持つ場合は許す。

有限検査は座標の取り違え、記述の重複と不一致、軸や時点の省略、各実時刻への被覆条件を検査する。全実数の量化は保持し、有限標本で全域を証明したとはしない。

この依存群では、平行な一つの候補運動の存在や対称性による採用をまだ帰属していない。全時刻の平行性と候補の量化、第一文の設定指示、時刻tの説明を接続してから段落全体を判断する。
