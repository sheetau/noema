# 移動系の物理場と相対性原理の条件付き要求を円文字へ接続する

対象はアインシュタイン原文u0161–162、908頁の一文である。直前の変換適用の文に続く段落72・文1として、原理による要求、`d. h.`以下の説明、二場の呼称、六表示式を結ぶ。略記`d. h.`と`bez.`で文を分割せず、表示式の後の`Offenbar`からは次段落とする。

固定375語とアルファベットを保つ。任意profile69は既存の磁極強度の量種、符号付き試験量への理想力応答、単位積校正の3規約を公開する。原文の17定義を既存の構成のまま接続し、新たな文専用の意味原子を設けない。親profile68の160主張・36注記に一つの主張と二つの印刷形を加える。

電場と磁場は、同じ系・座標尺度・領域・文脈での局所的な理想応答から定める。正負零の試験量、全三成分、全有効点、正の換算係数を保持する。磁気的質量は符号付き試験磁極という採用済みの読みであり、慣性質量、全磁石に働く合力、孤立磁荷の発見へ置換しない。真空中の実際の試験体の存在や、大きな試験体に対する厳密な線形性も主張しない。

領域、二場、法則、候補履歴、両系の記述は、既存の型付き記述参照から取得する。二場の役割は互いを参照せず、単位・係数・応答を存在量化する。共通の力単位と同じ過程への帰属は本文の共同条件で要求する。法則と候補履歴の参照取得だけでは同じ理論への所属を認定せず、本文の単一の理論証人で結ぶ。引用した役割や候補関数は、参照取得では実行しない。

相対性原理は全適格系対に関する既存の構造を維持する。要求は「Kで成り立つならkでも成り立つ」という条件文であり、両方の法則の無条件の真理を表さない。物理的に定義する二場を、前文で計算した混合関数へ先取りして同定しない。

検証では円文字の形から復元した定義をNativeの全型付き本文と照合してから、有限点・有限試験量・束縛位置の診断へ進む。九つの証人を持つ条件は、他の証人を具体化して一つずつ二値で変える。二場の役割の五証人も同様に扱う。これは束縛の診断であり、全実数・全関数域の証明ではない。全域の無断サンプリングと未知入力は拒否する。人間による独立した読解は対象外である。
