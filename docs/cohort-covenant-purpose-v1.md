# 同じ合意の因果的目的と相互宣誓

カント第六段落 u0013 [713,1004) の後代を特定の状態へ置く目的を、同じ合意の当事者・条項・宣誓へ接続する。状態と条件付き必然性は前版の `r5c2/r5c3` をそのまま使用する。

`r5c4` は、同じ合意の実施による原因性と、その同じ結果の成立を結ぶ。`r5c5` は六個体列（先行集団、後続集団、先行時代、後続時代、合意、状態）からこの因果的な達成内容を返す。原因性だけ、あるいは結果だけでは達成としない。合意の実施が機関や委任された人を介することを許し、全署名者の直接の因果を要求しない。

`r5c6` は、本人を先頭に加えた七個体列から、本人が同じ合意の実施に参加し、同じ目的の実現へ向けて役割を果たす内容を返す。これが個人別に引き受ける条項となる。原文にない個別の役割分担や、本人一人による成功保証は加えない。合意形成時の発言、実施参加、共同目的の成功を区別する。

`r5c7` は既存 `r5ca` の相互宣誓と、その同じ本人・行為・表明点による同じ共同目的の当事者間での表明と採用を結ぶ。`r5da` は既存 `rhz` に具体的条項と七個体列を渡し、実際の全当事者についてこの条件を要求する。目的内容の六個体列と、個人別条項の七個体列を混同しない。先行時代の全員が当事者だとは仮定せず、目的の採用から内心の一致や正当な代表権を導かない。一般公衆への公開も要求しない。

`r5db` はこの形成内容を六個体列に束縛する。目的、条項、形成内容はそれぞれ閉じた記述として引用でき、引用だけでは内容を実行しない。このため、まだ実施も成功もしていない目的に関する相互宣誓を述べられる。第四文の固定基準 `h26av` は、先の教会団体の種類へ対象を狭めず、合意形成時点と真偽評価を区別する。

検査は、原因性と結果成立の四通り、目的・結果・合意・対象列・基準の取り違え、六引数と七引数の全位置の区別、同じ引受け行為への目的採用、全当事者の相互性と宣誓を確認する。全位置の検査には二個体模型を用い、不要な大きな組合せ列挙を避ける。合意形成は時代・当事者の定義からも実行し、未評価の目的達成・条項履行・神的権威の実在を要求しないことを確認する。

規範的な `kann nicht`、共謀的な否定的提示、括弧内の重要性、`überhaupt` の総括、著者帰属と一文全体の通読は残る。本文99主張と既存の意味判断を保ち、確認済み文字数を増やさない。
