# 同じ出来事の四座標と方程式の課題

u0046は、静止系で出来事の場所と時刻を完全に定める各四座標に、同じ出来事を移動系に対して指定する四座標が対応すると述べ、その量を結ぶ方程式系を求めることを現在の課題にする。原刊898頁のWertsystemに対して固定本文にはWert Systemという分かち書きがあるが、内容の差とはせず原文データは変更しない。

三位置成分は`eiyu`で現在の測定規則`eixu`へ結ぶ。各地点の有効な値と、同じ地点についての測定の存在・全候補の値の一意性を保持する。`eiyv`は、同じ三値を持つ測定空間の全地点を比較して唯一の場所を要求する。これは原文の「場所を完全に定める」の条件を明示したもので、地点名を選んだだけでも、別の点の測定が欠けているため唯一に見えるという意味でもない。前段の`eixs`が全測定空間を対象とすることを受ける。直交幾何の一般定理をここで自動証明したとはしない。

`eiyw`はその同じ場所にある出来事に、配備時計による`eiyi`の局所時刻と、`eiyj`の系内時点との対応を結ぶ。第四成分はその同じ値と一致する。`eiyx`はこの全条件を一つの場所で満たす存在条件である。四成分の役割を区別する既存`sha`、値として四成分を比較する`shh`を再利用する。時点の記述名の唯一性や、同じ場所・同じ時刻の別出来事を禁止する条件は加えない。

`eiyy`は既存`sgu`を使い、一つの同じ出来事から二系の四座標を得る。`eiyz/eiy2`はそれぞれの側の全有効範囲、`eiy3`は既存`sgv/sgw`を使う全体の対応内容である。対象の全出来事が両側の値を持ち、値として同じ静止系の四座標には値として同じ移動系の四座標が対応する。記録個体の同一性、逆向きの一意性、任意の実数四組の実現を追加しない。

`eiy4/eiy5`はこの同じ対応を表す方程式系の条件と質問である。既存`sgy/sgz`により、非空の有限方程式列の全式を満たす座標対が、対象範囲の対応と過不足なく一致することを求める。式の左右は二組の四座標と左右の選択を受け取る実数値関数である。原文はこの時点では具体的な式の構文・線形性・解法を指定していない。質問を述べただけで解の存在や発見済みを主張しない。

`eiy6`は八つの量を既出の規則へ結び、kの名称は先行の命名箇所を保持する。`eiy7`は同じ第三節の仮定の下での対応の主張と、方程式系を見いだす課題を接続する。`eiza/eizb`はそのメッセージと著者帰属である。今という段階は、先行する時計設定から対応主張へ、さらに課題提示へ続く本文順序に結ぶ。

有限検査では、欠落した三成分・第四成分、同じ三値を持つ別地点、誤った局所時刻、別出来事の混合、同値な記録、同一時空位置の別出来事、対応の欠落と非一意、余分な方程式の解を区別する。原文の主張を条件として記述することと、その物理的真理・一般の座標変換を証明することは分ける。新しい原始記号は追加していない。
