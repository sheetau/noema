# 対象範囲を伏せた前後の関連度差を測る条件

固定rerankerの全文入力は対象範囲を区別しない。そこで、原文と候補定義のスコアから、原文の対象範囲だけを伏せた場合の同じ候補のスコアを引く。語別の規則・指示文・追加学習を使わず、対象に応じた候補選択が改善するかを測る。これは入力の変更によるスコア差の実験であり、意味への因果寄与や語義の確率と同一視しない。

モデル・重み・トークナイザー・環境は[前回](pretrained-reranker-v1-protocol.md)の固定BGE rerankerと同じ。候補も既存91概念、原文と同じ言語の定義を用い、型による絞込みはしない。対象範囲の文字列をトークナイザー自身の`mask_token`一つへ置換する。原文中の前後の文字と定義は変更しない。同じ文字列の全出現を一括置換せず、注釈位置だけを使う。

一部のトークンが対象の外の文字も含む場合があるため、元のトークン列の重なりだけでマスクしない。文字列の範囲を置換した後で通常どおり再トークン化する。この処理では系列長や隣接部の分割が変わり得る。マスクを含む文も通常の検索用文章とは異なるため、スコア差が対象の意味だけを表すと仮定しない。入力や定義に既にマスク文字列がある場合は区別できないので拒否する。

対照は未加工の全文関連度と対象だけの関連度。差分方式は`full_logit - masked_logit`に固定し、重み・閾値・候補ごとの補正を学習しない。91候補の順位を返し、同点はID順。未知判定や確定翻訳には使わない。

観察済みv6の50範囲と、今回予測前に作る[対象切替資料](../data/target-switch-v1.json)40範囲を評価する。後者は日英7組の文から各言語20対象（既知17、未知3）を注釈する。同じ文にある犬・猫・追う出来事など複数の対象を別々に照合する。自然文全体の意味注釈ではなく、小規模な手作り資料で、既存モデルの事前学習資料との不交差も保証できない。

新しい文が以前の`data`内JSON文字列に完全一致しないことを予測前に監査する。語彙は新規とは呼ばない。文ごとの既知対象が全て正しい割合、異なる正解対象間で候補が変わる割合、両対象とも正しい割合を区別する。単に出力が変わることを正解とは数えない。新資料・観察済み資料・未知のスコア分布を分けて報告し、この結果で方式を選び直さない。

v6の全文・対象だけのスコアは、前回の依存コード・入力・出力ハッシュを検査して再利用する。新資料は全条件を新規推論し、重複する入力文対だけをまとめる。batch 16、長さ256以内、切断なし。スコア行列・予測・処理時間を保存する。

文字範囲の正確な置換、反復語・日本語・複数語・句読点の保持、差分の向きと候補共通バイアスの相殺、非有限値の拒否、対象切替指標をテストする。実モデルのマスク前後4組で反復・直接forwardを検査し、生成等の禁止経路を監視する。保存行列から全予測・評価を再計算し、再読込み後の4組も照合する。良い結果でも全文翻訳の95%一致や通常の自然文全体への対応を満たしたとは扱わない。
