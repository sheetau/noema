# 本人に限られた一時延期の許容

第九文前半の kann は、本人について一定期間だけ延期する選択が、規範的に許容される可能性として読む。本人が現に選択したことや、全ての有界期間が許されることにはしない。

規範の出所は先行する人間の啓蒙・進展の評価を引き継ぐ。立場は知るべき事柄について自ら理解し判断する側とし、固定基準を第九文の全人・全義務事項・全仮定候補へ定める。立法者や現在の合意の当事者だけへ範囲を狭めない。

候補では選択主体と対象本人を分ける。期間内の対象本人の営みを中断する広い選択 `r5kz` は、他者を対象にする場合や終点なしの期間も表せる。許可を評価する前に、本人・有界・再開の限定を満たした例だけを選ばない。

同じ仮定内で実行された中断に衝突のない積極的許可があるなら、本人自身・有界期間・再開方針という限定を必要条件にする。その上で、各人についてそのような許容される仮定が少なくとも一つあるとする。可能性と必要条件を分けるため、任意の有限期間への許可は導かれない。仮定範囲の完全性は解釈入力の責任である。

自己の場合の有界部分では、期間内・終了以後の内容は前群の構成と明示した対応の下で一致する。ただし引用記述が異なるため、前の引用への方針採用を新しい引用へ自動転用しない。

後世についての放棄、神聖な人類の権利への侵害、踏みにじる見立て、対照・増幅・全文帰属は残る。第九文を確認済みの文字数へ加算しない。原文は保存済みの原刊489–490頁と [AA VIII 39、33–37行](https://korpora.org/kant/aa08/039.html) による。
