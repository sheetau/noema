# 同じ本文箇所への主張と期待背景の帰属

条件付きの伝播内容と期待の比較背景を、同じ著者・理由側の文章箇所・提示文脈へ結ぶ構成を追加した。既存の許可についての比較で使っていた `rtq`・`hznreport`・`hzrbgreport` を再利用する。主張と背景をそれぞれの内容記述として渡すので、両者の真偽を一つの命題へまとめない。

今回の内容の組は階数2の閉じた記述を返し、既存の帰属関係は階数3の記述を受け取る。`rqtu` は閉じた恒等関数の引用適用により、内容を実行せず階数3の記述を構成する。内容を評価すれば同じ値を返すが、変換前後の構文が同一であるとはしない。任意の同義な記述へ帰属を自動で移す規則も加えない。

| 構成 | 接続する内容 |
| --- | --- |
| `rqtu` | 階数2の内容記述から、同じ内容を返す階数3の記述を構成する |
| `rqtv` | 同じ組から主張と背景を取り出し、既存の二つの帰属関係へ渡す |
| `hzpx` | 公衆・任用関係・後見役関係の閉じた記述から、人物と時点を受け取る後見役の述語を作る |
| `hzpy` | 同じ枠の伝播内容と後見役の期待比較を、`hzp5`・`wa`・`hzp3` へ帰属する |

主張範囲 `hzpz` はカントu0011の原文位置137以上448未満、背景範囲 `hzq2` は178以上217未満を指す。これらは原文の位置への参照であり、その範囲全体を記述し終えたという宣言ではない。著者・帰属文脈・内容の評価時点も区別する。帰属文脈を仮定内の基準時点へ代入しない。

具体的な接続例では、前段の `rqtp` が自由の条件・候補・基準点を共用し、`hzps` が存在する伝播内容の22引数を候補ごとに与える。これを閉じた枠として `hzpy` へ渡す。公衆・任用・後見役も閉じた記述から構成し、検査用の不透明な「翻訳済み内容」へ置き換えない。

四項目のテストで、帰属の真偽と内容の真偽の16組合せ、本文箇所・著者・二つの範囲・文脈の取り違え、主張と背景の交換、七つの未知入力を検査する。主張帰属が偽でも背景帰属の未知を隠さず、通常の評価で未確定として扱う。主張の否定では主張側の記述だけが変わり、背景の記述を保持する。

具体的な後見役の接続は、世界の事実と期待比較を全て未知にした通常評価で確認する。帰属に渡された閉じた記述には、条件付きの枠・後見役・期待尺度が残る。これは帰属の構成の検査であり、伝播の実在や期待の正しさを証明するものではない。

原文に適した履歴・公衆・評価基準・社会的範囲などの解釈を充足した全文の帰属は残る。今回の引数付き構成を無条件の本文主張としては追加せず、原文対応文字数と意味確認済み単位数も増やさない。次に、その解釈をどこまで原文から指定でき、どこに文脈依存の未指定を残すべきかを整理する。
