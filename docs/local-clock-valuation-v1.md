# 点Aの時計による局所的な時間評価

固定原文u0013第一文[0,251)を原刊893頁と照合した。本文は197非空白文字で、三つの数式記号M0002–M0004はいずれも同じ点Aを指す。既存の場所参照ziqへ固定し、座標原点や前段落の観測者の位置と同一視しない。

時計がAにあるという条件の下で、Aにいる観測者が近傍の出来事を時間的に評価できることを記述する。対象と同時の指針表示を観測して探し当て、その時計の読みを対象へ付与する手段を保つ。時計の存在、表示の存在、観測者の照合操作、値の付与は別の関係として結ぶ。

近傍には同一場所と、先行脚注の局所同時性の理想化で同じ場所として扱える近接場所を含める。出来事と表示の生起を局所的に一致させ、両方の読みを確認する。別周期の同表示や、遠隔から届く信号の受信で元の出来事を置き換えない。指針は短針だけに限定せず、遠隔同期も前提にしない。

可能性は、同じ時計・場所・対象範囲を保ち、全対象の対応が一つの候補状況で成立することとして表す。対象ごとに違う成功状況を選ばず、元の状況で固定した対象を途中で抜粋しない。一般的な方法の説明なので、現実に少なくとも一件の出来事が生じたという条件は加えない。未知の候補欄や値は拒否し、有限例を実数全域や実機の観測可能性の証明としない。

点Bの時計以降と段落全体の確認は残る。
