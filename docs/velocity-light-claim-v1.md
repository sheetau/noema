# 光速度の不変性と合成式の特殊化

原刊906頁のu0145–u0146を扱う。必要な関係は、前の合成式からさらに得る帰結、光速度と光速未満の速度の合成で値が変わり得ないという全称、この場合の式を得る提示、U=(V+w)/(1+w/V)=Vの二つの等号である。既存s4b–s4iの不動点・特殊化・全称を再利用し、原刊の簡約商も直接構成する。

この段落を同じ一次元合成則の数式上の帰結として読む。表示式のwは特殊化された合成のもう一方の入力、Uはその同じ合成結果という局所的な変数である。前の点の固定値zkq/zkpをそのまま代入すると、実際の系速度が光速であるという条件や、別の運動での結果を混ぜかねない。ejqjは全ての0≤w<Vに対して元のs3jから結果を構成し、その同じ結果が簡約商ejqhとVへの等値の双方を満たすと記す。入力の一方をVにする数式上の操作と、物理的な系を光速にする仮定を分ける。

物理的な参照を失わないため、ejqk–ejqmで同じ点・K/k・全現在履歴・尺度・座標微分とノルムへの適用も結ぶ。ここでは点のkでの正方向の速さがV、系速度が光速未満の合成相手である。物理的な入力順s3g(V,other,V,U)と、交換した数式の順s4d(V,other,U)を同じUへ結ぶ。数値入力の交換を系や観測上の役割の交換とみなさず、実際の系速度zb7をVにはしない。

ejqtは、現在の同じ取得規則でこの光速度の点の場合が成立すれば、取得した同じ結果が両入力順の式と原刊の等式を満たすという条件である。新しい点や光速の系の実在を主張しない。ejquは数式上の一般内容とこの条件付き適用を合わせる。零の合成相手は一般式に含め、既存の正の相対運動の設定に零の方向を追加しない。

原刊の分母は1+w/Vである。固定電子転記の小文字vとの差は既存の訂正層を用い、原データと両方のハッシュを保存する。ejqg/ejqhは簡約商の加算、Vによる除算、外側の符号付き除算をそのまま保持する。U=Vだけでは商の成立を代用せず、w=−Vは分母零として拒否する。代数上の広い領域を原文の光速未満の範囲へ混ぜない。
