# 事物を指す範囲と意味役割を分けて学習する

一つの項が複数の基本句へ分かれて異なる役割を与えられる問題を扱う。固定KWJAの語ごとの文脈ベクトルから、事物を指す範囲をBIO分類で抽出し、その範囲を一つの候補として役割判定へ渡す。語彙、助詞、複合名詞ごとの結合規則は追加しない。

学習は従来の16述語群32文、開発は4群8文を使う。役割注釈の対象範囲をB/I、それ以外をOとする。今回の範囲は4役割の項の言及を対象とし、原文中のあらゆる事物や時間を網羅した固有表現抽出ではない。形態素境界で正解範囲を表現できない場合は黙って丸めず記録して停止する。

線形層と64次元tanh層を比較する。固定ベクトルをL2正規化し、seed17、AdamW、学習率0.003、重み減衰0.01、全件バッチ、200エポックまでを用いる。開発の平均交差エントロピーが最小のエポックと方式を選ぶ。推論では対数確率の和が最大の有効なBIO列を選び、原文の文字範囲へ戻す。語の途中で始まる範囲や、個別語の補正は使わない。

続いて、選んだ範囲モデルが学習・開発文から予測した範囲を使い、従来と同じ共通役割ヘッドを学習する。項の特徴は予測範囲内の語の平均とし、格ラベルはその範囲に含まれる主辞への予測関係から集める。注釈と文字範囲が完全一致する候補だけに正解役割を与え、注釈のない別述語は教師なしとする。

従来の評価32文は既知の回帰資料として使う。新しい[4述語群8文](../data/mention-scope-v1.json)を予測前に固定し、範囲・役割の両方の選択を保存してから解析する。複合名詞に加え「貨物船の船長」のような範囲も含め、学習にない構造への失敗を除外しない。

評価では範囲の完全一致による適合率・再現率と、範囲が正しい上での役割の一致を分ける。余分な項と欠落も数える。主辞だけの重なりを範囲の正解に置き換えない。正解範囲を与えた役割診断を追加する場合は別に記録し、原文だけからの成績に混ぜない。生成・辞書補完は使わない。これだけでは概念・数量・否定等を含む全文意味構造95%以上を達成したことにはならない。
