# 運動中の回転楕円体と三半軸

u0114–u0115のEin starrer Körperを、同じK/k・速度・尺度の下で静止側に球形を持つ任意の剛体についての帰結として読む。物体、半径、静止側の中心を量化し、先の一つの球や原点中心だけに限定しない。内部と境界を占める理想的な連続体という明示した読みは引き継ぐ。

回転楕円体を、中心からの縦差と横二差の規格化二乗和によって構成する。横二方向の半軸が等しいため、縦軸の周りの回転で形が変わらない。ejf6は全物質点の包含と閉領域の全位置被覆を共に要求し、少数の表面点だけで全形状を代用しない。現在記録における独立な物質境界との一致も保持する。

静止側の中心(cx,cy,cz)はKの時刻tで(cx/β+vt,cy,cz)となる。Kの全対象時刻にこの中心を使い、形状が変わらないことと物体が同じ場所に留まることを区別する。vom ruhenden System aus betrachtetはKの同時刻座標での形状であり、眼や望遠鏡へ遅れて届く光の画像の形ではない。

三半軸は順にR/β=R√(1−(v/V)²),R,Rである。原文のAchsenは表示値に合わせて中心から表面までの半軸として読み、直径はその二倍として区別する。前の球面式・最終四式・零断面の式から、この一般の形状と半軸が従うという著者の提示を記述する。有限検査はその一般的な物理的真理を証明したことにはしない。
