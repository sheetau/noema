# 「ただ試みとして」の種類による限定

前版の脚注末尾は、著者が採る提示上の位置付けを`hzla`という一個体だけに限定していた。この条件は、異なる二つの位置付けがどちらも同じ問いを検討する試みである場合にも偽となる。「試みという種類だけ」と「一つの識別子だけ」を取り違えた過剰な制限だった。

新しい一般定義`rqrw`は、指定した位置付けが採用されていることと、同じ提示者・文献・文脈で採られる全位置付けが指定の性質を満たすことを要求する。原文用`hzle`には、「同じ問い`hzld`を検討する試み」という性質を渡す。二つ以上の異なる位置付けでも、全てがその性質を満たせば成立する。

この変更で位置付けを自由に増やせるわけではない。異なる問いの試みや、試みではない位置付けが採用されていれば不成立となる。指定した`hzla`の採用も残すため、採用が空の場合や、別の位置付けだけを採る場合には成立しない。制限は同じ著者・文献・文脈の提示上の位置付けに限り、他者や別文脈、文献の全目的・価値には広げない。

既存の単一個体限定`rqrv`は、それ自体を必要とする記述のために保存する。今回変更する既存定義の本体は`hzle`だけで、一般定義を一つ追加し、基本関係・局所参照・本文23文の構文は増減しない。定義の変更を含むため意味規約は新しい完全版にし、前版の宣言・意味・引数との比較と未解決事項を残す。

検査は、三位置付けの採用と性質判定の64組合せを使う。旧版が拒否していた五つの組合せを新版が受け入れ、それ以外の真偽は一致する。原文用では二つ・三つの試みを受け入れ、別の問い・非該当の位置付け・採用されていない証人を退ける。問いの内容は未知のままでも記述を接続でき、答えを肯定しない。

採用されている位置付けの性質が未知なら判断を補わない。標準の非短絡評価器は採られていない位置付けの未知判定にも保留し得る。短絡診断ではその枝を評価せず、完全な解釈の64組合せで両方式の真偽が一致することを確認する。保存したNoema本文は診断用に書き換えない。

原文の対応範囲は増えない。`nur`の焦点範囲や`mag`の読み、思想の比較基準・偶発性などの課題は残り、脚注全体を意味確認済みにはしない。署名は依存する宣言・意味規約の一致を再確認するが、完全版の意味規約への移動に伴って来歴を含む依存ハッシュは更新する。
