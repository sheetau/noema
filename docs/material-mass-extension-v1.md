# 質量結果の物質点への適用と理由の帰属

u0260前半の質量結果を一般の物質点へ適用する主張と、後半の電荷追加をその理由として挙げる関係を接続した。前段と同じ物質点の範囲について、各点の対象となる全ての出来事で質量係数の関係を要求する。先に記述した電荷追加の可能性と、今回の係数関係は別々の内容として保持する。

各事例には同じ対象・出来事・文脈の基準系、単位、尺度、低速質量と二つの係数を渡す。力を評価する瞬間共動系と加速度を評価する系を区別し、数値化規約、低速質量の帰属、単位校正を結ぶ。数式は既存の単位尺度付きの定義を再利用するため、横の係数はこの規約でのbetaの二乗となる。

選んだ一つの物質点の式が正しくても、別の対象や同じ対象の別の出来事で式が違えば、全体の主張は成立しない。指定範囲に対象や出来事がないときは全称文が空虚に成立するが、そのことから実際の対象の存在を推定しない。事例範囲の完全性や、測定・校正の物理的根拠は入力として残す。

著者への帰属では、質量結果の主張と、電荷追加を理由にする推論を記述する。引用された内容を実行して真理を補う処理は行わない。電荷を任意に小さく加えられるという可能性だけでは、追加に伴う質量・運動の変化や極限での移行は説明されていない。この物理的な論証と、物質点・電荷の基礎説明、原文全体の意味一致は未完である。
