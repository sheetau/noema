# 概念の説明を求める問い

表題の「啓蒙とは何か」を、概念の構成や成立条件を明らかにする記述を求める問いへ改訂した。従来の `rqqp` は参照と候補が全対象・全状況で同じ真偽を持つかを調べる。この条件だけでは、説明にならない別名も候補に含む。新しい問いは、外延条件と説明としての条件を区別して要求する。

`rqwc` は同じ参照・候補について、外延一致と指定文脈での説明関係を結ぶ。`rqwd` はこの条件を満たす性質記述を求める型付き質問、`rqwe` は参照・文脈・基準を保った質問の層1記述を作る。質問記述を作るだけでは、候補や基準の真偽を実行しない。

説明関係 `hzv6(reference, candidate, context)` は、候補が参照する概念の構成・成立条件を明らかにするという意味規約を持つ。現在の実例が偶然一致すること、未説明の別名を示すこと、著者が説明として提示したこととは区別する。全読者が実際に理解することや、候補が新奇であることまでは含まない。原文にない数値的な十分さや固定した評価者を加えない。

この関係を持つことは、あらゆる候補を自動で採点できるという意味ではない。Noemaの意味関係として説明の役割を記述することと、その具体的な真偽の判定は別である。有限の検査では関係の真偽を明示したモデルを使い、同じ外延でも説明としては不十分な場合を区別する。原文ごとの答えの表や、生成による翻訳処理は使わない。

同じ構文の記述を一律に循環説明とみなすこともしない。Noemaの定義を展開して成立構造を説明する場合があるためである。反対に、表記が違うだけで説明として認めることもしない。記述の構文同一性、外延一致、説明関係は三つの異なる条件である。

`hzv7` は第一段落の `bi` と同じ啓蒙の内容について、表題・冒頭の文脈 `wh` で説明を求める問いを表す。`hzva` は、その問いを著者 `wa` が表題箇所 `hzia` に提示していることだけを述べる。本文先頭の文をこれへ更新した。冒頭の説明との回答関係は `hzvb` として末尾に分け、同じ質問記述と文脈を使う。これにより、問い単位の確認に回答の正しさを混入させない。

一般の `rqwf` も質問・回答の提示と本文順序を接続するだけで、答えが正しい・十分であることは要求しない。著者が不十分な説明を回答として提示したことも記述できる。表題の問いを実際の聞き手への回答要求に変えたり、唯一の答えの存在を追加したりしない。

七定義と一つの一般的な説明関係を追加する。既存の全宣言と、先頭以外の39文を保持し、本文は41文になる。原文対応範囲は増えない。独立した[表題の全体確認](title-question-review-v1.md)では、原刊と第一段落の確定した読みを使い、テストの通過と意味判断を分ける。

検査は現在の評価器を変換・キャッシュなしで使う。外延と説明の512組合せ、個体・状況の八対照、四つの記述・文脈対照、提示の32組合せ、本文の13条件、未知入力、記述の階層、全候補の有限列挙の拒否を確認する。通常・短縮・独自文字の往復と、九つの既存確認の依存関係も検証する。

実行: `python -X utf8 -m pytest tests/test_explanatory_question.py -q`。固定根拠の照合: `python -X utf8 -m scripts.check_explanatory_question --verify-only`。
