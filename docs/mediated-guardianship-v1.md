# 成員を介する後見と永続化の共同目的

第六段落冒頭の目的を、同じ団体が全成員を宗教上の事柄で指導し、その成員の指導を介して人民に影響を及ぼす構成にした。旧`ria`の二段の監督だけでは、成員が独立に同じ人々を指導している場合も通る。今回は同じ団体・成員・役割・相手・事柄の媒介関係`h255j`を追加し、この差を保つ。

`r462`は団体が成員を後見する役割と事柄、`r463`は成員が人民の一人を後見する役割・事柄と団体の指導の媒介を結ぶ。宗教的な事柄は既存`sg`の事柄・人・時点の順序で指定し、主題との関係`h255i`を固定基準で保つ。団体を人と扱わず、制度的役割の担い手として記述する。

`r464/465`は、その時点の全成員への上位後見と、政治的共同体の全人民への媒介を要求する。成員と人民はともに非空で、個々の担当を分担できる。会衆だけを人民全体に代用せず、将来に人が交代しても同じ団体と共同体を保持する。実際の命令の発令や服従を各時点に要求するのではなく、指導・監督する立場とその媒介の継続を述べる。

`r466`は全将来で中断しない後見、`r467`はそれに加えて同じ将来履歴に終点がない後見である。ここではunaufhörlichを中断なし、verewigenをその制度的な後見を終わりなく続くものにする強い目的として読む。後続のauf immerという説明とも対応する採用解釈であり、数値尺度の無限大は加えない。個々人の不死や基準時の人々の残留も求めない。

`r47a`は団体・政治的共同体・主題の三個体列から終点なしの結果を作る。`r47b`は、同じ合意の実施・維持が同じ結果を生じさせる働きと、その結果の成立を結ぶ。因果関係へ渡した記述に対応する式を静的に展開し、別の結果の真理へ交換しない。ここでの成功内容は目的の内側に置く。目的を持ったことから成功を断言しない。

`r47c`は団体・合意・共同体・主題の四個体列を受け、途切れない後見と、その終点なしの永続化を同じ目的にする。`r47d`では同じ団体がこの目的を合意形成の共同目的として採用し、全当事者の同じ相互宣誓行為がその営みに参加する。全員が同じ私的な望みを持つこととは区別する。目的の採用と参加には入力が必要で、単なる所属や儀礼からは推定しない。

[検査](../reports/mediated-guardianship-v1.json)では、全成員・全人民の取りこぼし、別の役割や事柄の混入、独立した下位の指導、成員と人民の交代、途中での媒介の中断を実評価する。履歴の欠落・循環・推移性の欠落、因果と結果、三個体と四個体の束縛は、その接続に必要な型付き境界を明記して分けた。宣誓の形成と共同目的は実際の定義で評価し、目的内容を未知のまま保持する。

有限履歴は終点なしの条件を満たさない。その診断を、現実の不可能性や原著者の規範判断の証明に使わない。引用された目的はその達成を実行せずに記述できる。履歴・成員・人民の完全な範囲、媒介と因果の現実の認定は解釈入力の責任である。
