# 書物の内容と、実際または予定された媒体の形

カントの書物による代行例について、現行の「参照できる記された作品」へ媒体の形を接続した。旧定義はまとまった壁面の記述や短いメモも含み得たため、書物を他の記された作品から区別する条件が不足していた。新定義は、葉を一つに集める媒体の形で実際に参照できるか、その形で実現することが制作上予定されていることを求める。

[AdelungのBuch項目](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_4_4_4406)は、紙や羊皮紙の葉を一つに集めたもの、その内容、将来書物にする原稿を挙げ、未製本の用法も示す。そこで、物理的な写しと内容を区別したまま、実際の媒体と予定された構成の両方を表す。[保存した出典](../data/book-form-evidence-v1.json)から本文の抽出と元バイト列のハッシュを再検査でき、通常の検証ではネットワークを使用しない。

一般定義 `rqxn` は、同じ作品を実現する読める記録が、同じ構成条件を満たす媒体に保持されることを述べる。既存の作品・記録・媒体の結合を再利用し、媒体の形を条件として渡す。別の作品の記録や別媒体の形は代用できない。

二つの基本関係を追加する。一つは複数の薄い葉を順序のある一まとまりとして扱える媒体構成 `hzwv`、もう一つは作品の制作・提供において指定構成での実現が予定される関係 `hzww` である。前者は製本済み、印刷済み、特定の材質を要求しない。後者は構成の記述を引数に取り、その構成が現在存在するとは断定しない。任意の読者の希望だけでは制作上の予定としない。

`rqxo` は、葉の集合という同じ構成を、実際の媒体の条件と予定の対象記述へ接続する。実際と予定のどちらか、または両方が成立すればよい。本文の `sl` はこれに加え、旧条件を保存した `rqxp`、すなわち現在参照できる記された作品を求める。したがって、まだ何も記録されていない構想だけを、本人が利用する書物の例へ加えない。現時点の原稿が別の形に記されていても、指定構成での制作予定があれば形の条件を満たせる。

辞典には、狭い用法ではある程度の分量を要するという慣習も記載されている。今回の形の条件だけでは、短い作品と長い作品、独立した刊行物と付随資料を全て区別できない。固定ページ数や現代の出版規格を原文へ追加する根拠にはしない。媒体の形を含む部分説明の改善であり、Buchの全語義を定義し終えたとはしない。

検査では、二つの記録について四関係を変える256条件と、作品・記録・媒体・状況の九対照を評価する。本文の十六対照は、実際の形、予定された形、両方、どちらもない場合に加え、別作品・別構成・別状況の予定、記録がない場合、本人の利用と供給を区別する。これらでは現行定義を通常評価する。三つの代行例をまとめた六対照では純粋な計算結果を再利用し、基準例を通常評価とも比較する。

本文42文の構文と、`sl` 以外の既存宣言・意味規約は保持する。変わるのは代行例の文4だけであり、確認済み十一単位、冒頭の因果文、支払いの文の意味は変わらない。前回確認した良心の自己判断と代行の二定義、およびその依存先も保持する。八つの帰属対照では実際の媒体や予定を不明のままにし、仮定例の提示からその存在を断定しない。通常表記・簡略表記・独自文字v2の往復も検査する。

成果物は[一般定義](../examples/v016/intended-carrier-forms.noema)、[本文の抽出](../examples/v016/book-form-core.noema)、[累積本文](../examples/v016/kant-book-form.noema)、[意味規約](../data/book-form-basis-v1.json)、[検査記録](../reports/book-form-v1.json)である。登録簿v50へ移すが、確認済み本文の分量は1,001文字のままである。分量と刊行単位の慣習、他の名詞、条件文と第二段落全体、二作品全文の確認を続ける。
