# 同じ行為に結ぶ目的と因果的な寄与

[カント本文の新しい固定版](../examples/v016/kant-guardian-purpose.noema)では、後見人が危険判断を目指して働きかけることを、同じ行為の因果的な寄与へ結んだ。前版doは意図しない寄与も許していた。また、目的を持つ活動を別に要求するだけでは、目的を持った活動Aと、意図せず結果に寄与した活動Bを組み合わせられる。新doでは、参加・目的・生起・因果の四条件が同じ行為を参照する。

既存の目的関係hzuと因果的な寄与hzieを再利用し、基本関係は追加しない。rqyeは行為の生起dgを内容として表し、rqyfは指定した非空の行為者群の各人が、同じ生起行為に参加して同じ閉じた内容記述を目指すことを述べる。目標の内容は実行評価しない。目的を持って行動したが達成しなかった場合も、この定義で表せる。

本文用のrqygは、重複のない人間としての後見人群をrqyfへ渡し、目的を同じ母集団mvの危険判断分布rqyd(mv)に固定する。新doは従来の監督の立場、負担と判断、危険判断の分布を保持し、rqygを満たす同じ行為の生起がその分布へ実際に寄与することを加える。行為者の目的・著者の主張・現実の真理を区別し、目的が達成されたという保証や、危険の客観的な実在を補わない。

各参加者が同じ目標を目指すことは、今回採用する分配的な読みである。集団の一部だけが目標を知り、他の者が別の目的で協力する場合はrqyfを満たさない。こうした集合的な目的の全形態をこの定義で代表させず、本文中で各参加者に目的を要求してよいかは全体確認に残す。同じ行為には部分行為を持つ活動も許すが、無関係な二活動を便宜上同一とみなす解釈は採らない。

[保存済みの歴史辞典の出典](../data/guardian-causation-evidence-v1.json)は、Sorgenについて実現に向けて手配しようとする用法を含む。これは目的的な働きかけという読みの根拠になるが、動詞だけから成功や各人の同じ意図を必然とする根拠ではない。新doは前版と同様に、本文の前後に基づいて結果が成立する読みを採ったものとして扱う。監督の語義、gütigstの評価、schon・auchの焦点、一文全体の照合は未完である。

旧doはrqyhとして保存する。四定義を追加し、既存定義の変更はdoだけで、影響する本文は文7に限る。hzuの宣言を新しい利用箇所より前へ移すが、型・意味・名前は変えない。既存44文の構文と、確認済み十一単位・先行四文の意味依存関係を保持する。

検査は、参加と目的と生起の32組合せ、本文37対照、帰属六対照、未知入力と三記法の往復を扱う。別行為の目的、別対象・内容・状況の目的、集団の一人だけの目的、目的を持つ行為と因果の行為の分離を区別する。本文の定義を実際に評価し、目標未達でも目的的活動は成立することを確認する。通常評価とメモ化評価の三照合は、母集団と後見人が各一人の有限モデルで行う。任意のモデルでの同値性や、原文との意味一致の自動証明とはしない。
