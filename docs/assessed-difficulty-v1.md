# 非容易性と、達成する経路の不在

第三段落第一文の記述候補から、「対象者の全員に、自己作業で達成できる方法がある」という追加の含意を取り除いた。本人の性向、各人への全称、著者への帰属、先行する説明からの帰結提示は保ち、第52文が引用する困難さの内容を改訂する。

原文は各人の困難さを述べた後、当面の不能と成功者の少なさを述べ、次の段落では公衆の自己啓蒙の可能性と対照させる。今回はこの文脈から、個人それぞれの到達可能性までは追加しない読みを採る。原文から自動的に導かれる唯一の解釈とはしない。[Kant, AA VIII036](https://korpora.org/Kant/aa08/036.html)

後年の『人間学』では、容易・困難を能力との関係へ導入し、容易さを本人の力の余裕と結びつける一方、相対的な実行不能や煩わしさとも区別している。この区別を参考に、評価する方法と結果を固定し、「容易に達成を確保できない」という内容を用いる。[Kant, AA VII146](https://korpora.org/Kant/aa07/146.html)、[AA VII147](https://korpora.org/Kant/aa07/147.html)

## 成功する結果と、成功を確保する方法

旧定義は、利用可能な一つの方法の全ての採用結果で、本人の力の範囲内で達成することを要求していた。これは一つでも成功する結果があることより強い。例えば同じ方法に成功する結果と失敗する結果があるなら、成功を確保する方法はなくても、成功する経路はある。

| 評価された条件 | 容易な方法がない | 上限内の成功経路がない |
| --- | --- | --- |
| 全ての採用結果で、余裕を持って達成する方法がある | 偽 | 偽 |
| 達成する方法はあるが、余裕を確保できない | 真 | 偽 |
| 安く成功する結果と失敗する結果が同じ方法にある | 真になり得る | 偽 |
| 全方法が失敗する、または全成功経路が本人の上限を超える | 真 | 真 |
| 成功経路の必要量が未評価 | この肯定を出さない | この肯定を出さない |

最後の行は、世界の成否についての第三の真理値を導入したという意味ではない。意味上の評価条件が満たされない、または入力が未知で評価器が保留する場合を、肯定判断へ変えないという区別である。

## 成功経路ごとの評価

新しい`r2ds`は、各方法の結果範囲を検査し、その中の成功する経路すべてに、尺度内の一意な必要量を要求する。全結果で成功する方法だけを調べる旧`r2dd`では、成功と失敗が混在する方法の未測定の成功経路を見落とし得る。旧定義は歴史的な意味を保ち、新しい定義でこの検査を追加した。

既知の失敗経路については必要量を要求しない。一方、失敗したと分からない経路や未知の方法集合を、失敗や空集合へ置き換えることは認めない。評価器は未知の入力を保留する。述語を既知の空集合として与えることは、その範囲に対象がないという明示的な解釈であり、データ未入力の代用品ではない。

| 定義 | 内容 |
| --- | --- |
| `r2dr` | 尺度・本人の一意な上限・帯の整合性 |
| `r2ds` | 混合結果を含めた成功経路ごとの評価 |
| `r2dt` | 同じ方法に、本人の上限内で達成する採用経路がある |
| `r2du` | 評価が整い、余裕を持って達成を確保する方法はない |
| `r2dv` | 評価が整い、本人の上限内で達成する採用経路はない |
| `r2dw`・`r2dx` | 非容易性を本人の自己作業と文脈尺度へ結ぶ |
| `r2dy`・`r2dz` | 各人への内容と著者帰属を更新する |

本文に使うのは`r2du`であり、`r2dv`の経路の不在を追加主張しない。どちらも同じ開始時点の基盤と評価範囲に相対的な内容である。全世界での不可能性や、将来の訓練後も成功できないという主張にはならない。

## 検証と残る読解

二方法の必要量と成否の64組合せを、独立の集合計算と照合する。混合結果、成功経路の欠測・多値・尺度外、失敗経路の未測定、既知の空の方法集合と未知入力を対照に含める。既存の自己作業・能力・変化・因果の定義を実行し、閉じた尺度の接続でも旧式と新式を比較する。

本文への帰属は世界内容を未知のまま検査し、旧内容の引用、別人・別箇所・別文脈、帰結や順序の欠落を検出する。各人への範囲と性向の定義は、以前の構成から参照先だけを変更したことを構造比較で確認する。これを全内容の同時実行や原文との同義性の証明とは呼ばない。

追加は九定義、基本入力はゼロ。旧定義と先行51文、十二単位の意味判断を保つ。原文の対応量と意味確認済み分量は増やさない。本性に近い性向の読解、尺度の校正、形容節の情報構造を含む第一文の通し判断は残る。
