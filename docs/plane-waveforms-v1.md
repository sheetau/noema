# 共有位相を持つ六成分の波形（2026-10-14）

アインシュタイン1905の第7節で、電気側と磁気側の六成分に同じ正弦波の位相を与える式を追加した。波形を適用する操作、振幅の混合、座標の逆変換を既存の定義から構成した。新しい基本関係は追加していない。

## 正弦の指定

正弦に名前だけを与える代わりに、実数上の二関数S、Cに次の条件を課す。

- SとCは有効な実数切断を有効な実数切断へ写す。
- 全ての実数xで、S′(x)=C(x)、C′(x)=−S(x)。
- S(0)=0、C(0)=1。

`sdt2`は一つの点での微分条件、`sdu2`は原点条件、`sdv2`は両者と全域の有効性を結ぶ。微分は既存の`sjs`を使い、差商の極限へ展開できる。原点条件を省くと、零関数や振幅・位相を変えた解も含んでしまう。

これは正弦・余弦を初期値問題として指定した定義である。実切断上で解が存在し、一意であることの機械的証明は未完である。有限個の値からその証明を代用しない。

## 位相・振幅・場の接続

`sdw2`は、既存の位相Φ=ω(t−(ax+by+cz)/V)から、一成分の値A₀S(Φ)を作る。`sdx2`で三成分をまとめ、電気側と磁気側にそれぞれ使う。これにより六つの振幅が同じ波形と位相を共有する。一般の波形も指定できるが、正弦波として使う場合は`sdv2`を要求する。

変換する振幅は、r=v/V、β=1/√(1−r²)として次の六つである。

| 成分 | 変換後の振幅 |
| --- | --- |
| X | X₀ |
| Y | β(Y₀−rN₀) |
| Z | β(Z₀+rM₀) |
| L | L₀ |
| M | β(M₀+rZ₀) |
| N | β(N₀−rY₀) |

`sdz2`が六つの入出力を同じ変換へ結ぶ。`sd22`と`sd23`は、その振幅と前回定義した周波数・方向余弦の変換値から、新四座標の場を作る。光速度の正値、光速未満の相対速度、正の周波数、単位方向、有効な振幅は`sdy2`で要求する。`sd24`はこの入力条件と正弦の全域条件を合わせる。

場を作る関数だけでは、入力が許容範囲内だとは認定しない。また、六つの振幅を任意に選んだだけでは真空の電磁波の解になるとは限らない。横波の制約、場の方程式、光源、観測者、測定と近似の条件は別に接続する必要がある。

## 検査した範囲

既存の場の変換`s6k/s6l`は、旧座標の六成分を混合してから逆座標変換を合成する。今回の`sd22/sd23`は、振幅・周波数・方向を変えてから新座標で波形を評価する。この二通りを、正・負・零の相対速度、四つの方向、三つの波形を組み合わせた36例で比較し、六成分全ての一致を確認した。

具体例の波形は線形、多項式、定数の正確な有理数関数である。これらを正弦と称していない。波形の共有と座標・成分の対応を検査するために使った。位相、逆変換の向き、未変換の座標・振幅、四つの横成分の符号を誤った8例も区別した。累積草案と必要な定義だけの独立文書で同じ結果になった。

有理数の多項式検証器では、共通の波形値を掛ける操作が二種類の成分混合と可換であることを証明した。別の波形値を混ぜる式には反例を確認した。これは実切断上の一般的な場の恒等式を証明した結果ではない。

正弦の条件については、原点条件と局所的な微分条件を7例で分けて検査した。例えばS(x)=x、C(x)=1は原点の条件を満たすが、x=1で微分条件に失敗する。定義を全域へ展開した場合と、微分の定義を極限へ展開した場合は、有限解釈器が有理数全域への量化を拒否することも確認した。局所検査の微分には、登録した多項式の解析的な導関数を用いている。

加えて、入力条件の8例と、六つの出力振幅を一つずつ変えた場合を含む21例を検査した。
