# 状態を生じさせる行為と、段落全体の残る課題

カント第二段落の先行する行為に、後見人が対象者について理解の不足を生じさせるという部分的な読みを追加した。これまでの妨害と危険提示へ接続し、三つの局面で同じ対象者を保つ。部分草案の範囲が段落全体に及んでも、各箇所の意味確認が完了したことにはしない。

## 何を生じさせたのか

既存の `bj` は、文脈で問題となる理解が十分でないという `ak` の否定である。自立的な使用の能力がない `bf`、勇気の不足 `br`、決意不足 `bq` とは別に定義されている。今回の読みでは `bj` を使い、知能の数値、能力の減少量、以前は十分な能力があったという条件を加えない。

原文の因果的な言い方と先後関係を[アカデミー版の電子本文](https://www.korpora.org/Kant/aa08/035.html)で再確認した。`dumm` の知的な弱さに関わる用法は[DWBの項目](https://woerterbuchnetz.de/?lemid=D14372&sigle=DWB2)の検索抜粋にもあるが、それだけでカントの語義を一意に確定することはできない。参照範囲と解釈上の判断は[読解記録](../data/caused-conditions-reading-review-v1.json)に保存した。本文の固定版と電子比較資料の句読点の差も保持する。

一般定義 `raa` は、非空の行為者群・同じ行為・影響を受ける人・記述された結果を結び付ける。結果が成立するだけでも、原因だと説明されるだけでも成立しない。同じ行為が生起し、その行為に全行為者が参加し、同じ人に結果を生じさせる関係を要求する。

結果を生じさせる関係は明示的な入力であり、現実の因果を実証するものではない。また、前状態の否定をこの一般形には含めない。状態が新しく始まったのか、程度が変わったのか、既存の状態へ別の原因が作用したのかを原文以上に固定しないためである。

| 定義 | 接続した内容 |
| --- | --- |
| `g4` | 後見人の同じ共同の行為が、同じ人について理解不足 `bj` を生じさせる |
| `g5` | 提示時点で固定した対象者全員について、先に `g4`、その後に既存の妨害 `er` が成立する |
| `g6` | その二段階に続き、同じ後見人による危険提示 `ew` がある |

過去の時点で対象集団を選び直すと、別の人々について成立した条件をつないでしまう。今回も現在の対象者の選択を固定し、過去ではその選択が成立しない検査モデルで接続を確認する。

## 段落を完成扱いにしない理由

今回、歴史的な草案から引き継いだ未解決メモとは別に、現在必要な意味確認を14項目に整理し、原文位置とともに[検証記録](../reports/caused-conditions-v1.json)の `paragraph_review` に保存した。これは網羅的な確認項目の完成版ではなく、少なくとも現在残っている課題である。

- 怠惰・臆病、好みと生涯の期間、自然による解放の語義と作用範囲。
- 本・宗教上の助言者・医師、支払いと引受けの概念説明。
- 女性集団の挿入句、監督の立場、皮肉・評価・焦点。
- 家畜と所有・支配、穏順さ、歩行器と閉じ込め、転倒・歩行の身体的描写と比喩の対応。
- 理解の十分さ、結果を生じさせる関係、慎重さ、許可・機会・勇気。
- 学習の様相、末尾の譲歩、通常性と後続する試みの範囲。

`ak` の理解の十分さ自体も、まだ基礎関係として与えている。今回の合成によってこの基礎説明が完成したとはしない。同様に、`er` は前回の明示的な介入モデルに相対的な読みであり、家畜や歩行器の描写の代用にはしない。

## 検証

一般形64例、原文への結合11例、時間と対象者の接続6例を検査する。結果だけ成立する例、行為がない例、行為者が別々の行為へ分かれる例、別人への作用、依存状態との取り違え、異なる時点の結果、空の行為者群を拒否する。前状態が十分でも不十分でも、他の条件が同じなら今回の条件の結果は変わらない。

一般文書は基本述語0・定義1、原文接続文書は累計基本述語145・定義198である。新しい構文・実行時演算子・翻訳ルールは追加していない。本文の既存8主張も変更せず、今回の部分的な読みを無条件に実行する主張としては追加していない。

新規5件と、接続先の提示・妨害・進捗監査を含む関連31テストが通過した。今回変更した範囲に合わせた検査であり、全テストの再実行とは分けて記録する。検証記録と進捗集計の再生成一致、通常・短縮記法と固有文字の往復、CLIで出力したJSONと元の構造の一致、固有文字SVGのXMLとしての妥当性も確認した。
