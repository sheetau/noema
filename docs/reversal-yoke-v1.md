# 反転する作用と頚木の照応

第三文前半の先行作用と後の保持を、同じ役割と事例参照を持つ頚木の描写へ結んだ。対象側の未成熟と、描写側の身体的な装着状態の真理を同一視しない。`Besonders`・二つの `selbst` と第三文後半はまだ統合していない。

## 状態の種類を受ける読み

「この頚木」は前文の除去描写を受け、「その下に留まる」は第三文のこの頚木を受けると読む。引き継ぐのは、知的未成熟と頚木装着という種類の対応である。前文の自己離脱者、公衆側の人々、後に強制される後見人を同一人物へ縮めず、全員に同じ一個の装具を仮定しない。

身体的な状態 `r2nh` は、首・頭側に装着され、別の荷へ牽引を伝える枠が同じ主体に存在することを、既存 `hzpk` で表す。前文の除去 `hzpm` が前状態に要求する同じ装具の分類である。知的な離脱 `h4p` の前状態は既存の未成熟 `bf` であり、二つの前状態を種類の照応の根拠として確認する。

保持は、この種類の装着状態が期間中続く描写とする。一人について各時点に装着される物体が常に同じ一個であることまでは加えない。

## 同じ事例による対象と描写

先行作用の結果と後の保持状態を、同じ閉じた状態記述として受け取る一般形を作った。先行する作用者・被作用者、後の強制者・対象、扇動条件、履歴と前後点、期間内の保持と因果は保持している。

対象側の関係族 `r2nl` と描写側の関係族 `r2nn` は、順序付き列の第一位置を公衆、第二位置を事例とし、同じ内容評価点を参照文脈に使う。範囲 `r2nm` も同じ二位置を使う。対象側は既存の事例記述 `r2ne`、描写側はその状態だけを身体的な装着へ替えた構成を評価する。

`r2no` は、同じ主張・範囲・役割に結んだ非字義的な提示を帰属する。`r2np` は二つの照応と本文の順序を結ぶ。引用された知的・身体的な出来事は、いずれもこの帰属の評価時には実行しない。

60番目の前半記述を、従来の内容帰属 `r2ng` に描写と照応を加えた `r2nq` へ置き換えた。先頭59文とその意味規約は変更していない。

## 検査と残件

一般化した反転の定義から状態引数だけを戻すと、従来の時間・条件・人物関係の構文木が正規化後に完全に復元されることを検査する。有限解釈では、知的状態の関係が成立しても、身体状態・身体側の先行原因・圧力・保持因果が欠ければ描写側だけが不成立になることを確認する。

頚木の状態自体は、枠、首・頭側の部位、装着、荷への機械的結合の定義を直接実行する。反転全体の実評価では `bf/up` と身体状態の内容を境界に置き、関係族の検査では別途検査した事例関係を境界に置く。引用の帰属は全世界入力を未知にして検査する。これらの境界を、原文との自動的な意味一致の証明とは扱わない。

既存十三の全単位判断と先頭二文382非空白文字を保持する。次は `Besonders` と二つの `selbst` の焦点を接続し、後半の偏見の植え付け・害・報復とともに第三文全体を統合して通読する。今回の追加で確認済み文字数は増やさない。
