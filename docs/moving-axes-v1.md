# 動く三軸の全時刻の配置

u0044後半は、静止系の各時刻に動く軸の配置が定まり、全時刻で対応する軸が平行になる一つの運動を仮定できると述べる。その接続に必要な、静止を前提にしない物質軸の幾何を構成した。

`eiv2` は同じ線状支持体の全物質点履歴と剛性を保持し、全時刻で全成員が原点と方向標識を通る直線上にあることを要求する。原点の位置には物質点が存在するが、原点標識そのものを三本の軸で同一の物質点にする必要はない。各軸側の原点候補と代表位置の双方を、同じ原点の完全な `se` 軌道へ結ぶ。

時刻ごとの原点と標識の位置差から、`eiv4/eiv5` が平行・直交を判定する。`eiv6/eiv7` は唯一の原点、三軸の全役割、原点からの出発とこの実座標による直交を、各時刻と全履歴に接続する。静止の初期配置を扱った `eiva/eivf` は流用していない。

`eiwa/eiwb` は異なる二系の対応する三軸に、各時刻と全区間の平行を要求する。逆向きの軸、異なる原点、離れた支持直線を許す。X軸についても、初期設定の支持直線一致を全時刻の追加条件にしない。

完全な履歴の条件は元の全実数量化を保持する。有限検査では時刻を取り出した本体と境界への引数を検査し、有限標本を全時刻の証明としない。途中の一時刻だけ向きが変わる場合や、原点候補を別の位置履歴へつなぐ場合も区別する。

この依存群だけでは、配置を表す状態の存在・一意性や候補運動の存在を述べていない。次に現行の並進条件とこれらの幾何を同じ候補履歴へ結び、対称性による採用の正当化、設定指示、時刻tの説明とともに段落全体を記述する。
