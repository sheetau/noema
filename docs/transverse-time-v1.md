# 横方向の光伝播と、y・z方向の時刻の偏微分

アインシュタイン§3の `u0059`〜`u0061` を部分記述した。横方向の光の往復に同様の議論を適用し、`∂τ/∂y=0` と `∂τ/∂z=0` を得るという著者の提示を、同じ関数・速度・試行範囲へ結ぶ。

横成分速度をwとすると、`skz` は `0≤v<V`、`w>0`、`v²+w²=V²` と `w=√(V²-v²)` を要求する。Vは静止系での光の全速さであり、wは横方向の成分である。例えばV=5、v=3ならw=4であり、横成分へV=5を代入する条件は拒否する。平方根の構成 `sky` は既存の非負平方根の定義と記号名以外が同じであることを確認した。

`slo` は、前段の原点以外の光往復のプロトコルをyまたはzの軸へ一般化した。変更は軸の引数化と横軸の範囲指定に限り、同じ光、出発・反射・帰着、時計、同期、局所時刻の条件を残す。X軸方向を横方向として受理しない。

`slp` はその試行の静止系座標と時計の読みを接続する。三出来事でx-vtが一定であり、選んでいない方の横座標も変わらない。選んだ軸では正の距離hまで進んで元の位置へ戻る。往路・復路の両方について `w*経過時間=h` を要求するため、静止系の時刻は `t, t+h/w, t+2h/w` となる。ここで静止系の光路は、横移動と同時にx方向にも進むことを許す。

`sls` は、y,z両方向の試行範囲が空でなく、指定範囲の全試行が同じ光速度と並進速度でこの条件を満たすことを要求する。範囲が必要な試行を尽くすという前提も明示する。有限個の例が通ったことから、実際の全光路を調べ終えたとは判断しない。

横方向の中点式 `slf` は、出発位置、選んだ軸だけh進んだ反射位置、元へ戻った帰着位置で同じτを評価する。`slg` は十分小さい全ての正のhについてこの式を要求し、`slh` は軸変数と時刻に関する全微分可能性と偏微分値を結ぶ。前段と同じ十分条件を補った解釈であり、この形の条件が原文に全て明記されているとは主張しない。

`skw` はτのx′とyの引数、`skx` はx′とzの引数を交換する。交換した関数に対応する座標を渡すことで、既存の一番目の変数についての微分定義を、そのままyまたはzの偏微分へ使える。`sli` が選んだ軸の偏微分を0に指定し、`slk` が同じ四座標で両方を要求する。`slm` は前段と同じ時刻パラメータで、全空間座標へこの条件を課す。

新規12件を含む関連36テストが通過した。成分速度9例、τの引数と偏微分6例、軸を引数とする試行8例、座標と伝播時間13例、試行範囲12例、帰属9例を検査した。yだけに依存する関数ではyの条件だけ、zだけに依存する関数ではzの条件だけが失敗する。時刻に非線形に依存する検査例では、両軸の偏微分が0でも有限距離の中点条件が失敗することを確認し、両条件を同一視しない。

有理数の代数的検査では、正の横成分の一意性、v>0でw<Vとなること、等しい往復時間の中点条件、微分係数の両辺の時間項の相殺を確認した。検査用アフィン関数については、横方向の中点式が該当する空間係数の0と同値になることも確認した。静止系の二成分による光路の平方和は全速さVを保つ。これらを実際の光路の一般的な幾何や連鎖律の証明とは扱わない。

有限検査には構成した有理数切断を使う。平方根は正確な有理数根を持つ検査例に限る。同期、局所時刻、先行するτとの結合、微分、光速度の法則などは各接続検査で検査用の関係を明示する。近傍全体、全空間の前提、全空間の偏微分条件について、有限検査器が評価を拒否することも確認した。
