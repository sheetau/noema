# 冒頭の条件文と、標語を導く提示

カント冒頭第三文の条件の向きと、末尾の標語の提示について、現行本文で採る読みを決めた。[原文](https://korpora.org/Kant/aa08/035.html)の再読による判断を[更新した作業記録](../data/opening-reading-status-v2.json)に残す。新しい文法や語彙は追加しない。

第三文は、原因の条件が成立する場合に、その未成熟を本人の責任に帰すという十分条件の主張として読む。原因条件 `bd` と帰責を含む状態 `rqrj` を結ぶ現行の `rqrk` を採用する。逆向きも要求する `rqrl` は比較用として残す。この選択は、定義的な同値という別の読解が不可能だと証明したものではない。条件接続を十分条件として保つ、という今回の読解である。

本人に責任があるという判断は、誰かが非難したという発話記録ではなく、本人の選択や不作為に関する落ち度として状態を本人に帰す意味規約 `hziq` による。原因があるだけでは帰責を埋めない。帰責が記録されていても、対象の未成熟がない場合には `rqrj` は成立しない。これらは、著者の責任判断が正しいことの実証を翻訳の条件に追加するものではない。

末尾では、ラテン語とドイツ語の呼びかけを並べた全体を標語として位置付ける。先行五箇所を談話上の根拠側のまとまりとする読みを採用する。原文が形式的な前提集合を明示したとは扱わず、個々の箇所の真実性、独立した必要性・十分性、論理的な導出可能性は要求しない。説明の向きはラテン語からドイツ語への説明付与であり、両者の内容が同じだという等式にはしない。

現行本文の第二文は、著者がこれらを提示したという記述である。引用先の条件を評価する文とは区別する。条件そのものを評価する検査では、原因条件と帰責の組合せに応じて真偽が変わる。一方、著者による提示の検査では、原因・帰責・能力・呼びかけの実行について全て未知でも、正しい引用先と談話関係があれば成立する。引用先を一方向の条件から同値条件へ取り替えれば成立しない。

検査は二人についての16組合せ、人物・状態・場面などの五対照、未知の帰責の拒否、八つの提示対照を含む。現行の定義本体を評価し、定義をPythonの真偽値に置き換えない。短絡変換とキャッシュは使わない。[比較用Noema](../examples/v016/opening-conditional-review.noema)は既存定義と四つの質問からなり、通常記法・短縮記法・固有文字の往復を確認する。

条件の向きと談話の範囲については、今回の読解を以後の本文確認に使う。残る作業は能力と不足の文脈基準、ラテン語の判断能力と取り組みの読み、これらを合わせた第一段落全体の意味確認である。前回の能力保持の定義が本人の状態を固定するのは候補場面の始点であり、方法の途中の学習まで排除したことにはしない。原文の対応範囲、意味確認済み八単位・166文字は増やさない。
