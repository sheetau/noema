# 日付行を追加した本文での署名の再確認

kant-calendar-dateline.noemaに日付行を追加した後、既存の署名単位u0018全体と八項目の判断を再読した。署名の文は引き続き17番目で、依存する10宣言の本体・型・意味規約・引数ラベルと名称の四表記は変わらない。日付行の追加によって、署名の表示行為や文脈を日付行と同一視する条件も加わっていない。

原刊494頁には著者の略記と、その下に場所・日付がある。署名を「同じ名称使用が同じ人物をこの文書の著者として表示する」と読む前回の判断を維持する。頭文字は固定電子転記のI.という読みを採用し、[mmanuel]という展開は原刊の印刷と区別する。掲出者、筆跡、自筆性や真正性を推定しない。

[新版の判断記録](../data/author-signature-review-v5.json)は新しい本文・意味規約・識別表記と依存比較へ結ぶ。同じ短い署名についてのアシスタントによる判断であり、新たな意味確認済み単位を増やさない。隣接する日付行は暦の同定等が残る部分草案として扱う。
