# 条件付きの規定を、同じ対象への要求へ結ぶ

規定の採用・適用を表す既存の構成と、要求・許可・不履行を表す構成を接続した。規定が存在しても、その本人が指定の立場になく、または条件に該当しなければ、その規定からの要求は成立しない。適用があっても、目標が実現しているとは限らない。

例えば「点検担当者は、故障があれば報告する」という規定を記述できる。規定が変わらなくても、故障が発生して条件に該当すれば報告への要求が生じ、条件に該当しなくなればその条件付きの要求はなくなる。この変化だけから、新たな制定行為や廃止行為があったとは言わない。条件・目標・役割はNoemaの式と引数で渡すため、例文固有の翻訳規則は使わない。

## 出所と採用者を保つ

既存の `rba` は、出所が規定を、指定の立場と条件に合う人への要求として採用している関係である。今回新たに要求を認める根拠は、この既存の意味規約にある。署名や承認だけを要求へ変換する法則を追加したものではない。制定の社会的な機構や正当性を説明し終えたとも扱わない。

| 定義 | 内容 |
| --- | --- |
| `r2fn` | 人から内容への目標記述を、一人だけの個体列から内容への記述へ包む |
| `r2fo` | その列がちょうど一要素であるという条件 |
| `r2fp` | 明示された一つの規定採用から、同じ本人・立場・目標・肯否・文脈への要求の寄与を構成する |
| `r2fq` | いずれかの採用者・条件記述・目標記述による、その規定からの寄与があるという存在条件 |

共通の規範関係へ渡す出所は規定そのものであり、その規定を採用した人や組織は別の位置に保持する。同じ採用者の別の規定や、別の目標記述へ要求を流用しない。既存の規範関係 `h7k` の全ての解釈をこの構成に置き換える規則も追加しない。

一つの証拠の寄与 `r2fp` が成立しないことは、他の証拠からも要求がないことを意味しない。`r2fq` はその区別を保つために全ての条件・目標記述へ量化する。有限検査器はこの全域量化を拒否し、既知の例だけを全領域として評価しない。

## 内容の実現と規範を分ける

`r2fn` は既存0.16の引用合成を使う。目標を実行して真理値へ置き換えず、同じ目標記述を適用する構文を引用として構成する。元の目標の別名が同じ真偽を返しても、その記述を採用されたものへ自動的に置換しない。

この要求の寄与を既存 `rds` に渡すと、同じ対象への要求を検査できる。`rdw` に渡すと、同じ対象の現在の真偽と要求の肯否を比較し、不履行を検査する。前者は適用条件を評価するが目標を実行せず、後者は目標も評価する。未知の目標は不履行として処理せず、評価を停止する。

積極的な許可は独立した関係として残す。正負の要求が両方ある場合は既存 `rdv` で衝突を表せるが、目標とその否定が事実としてともに成立したとはしない。既存 `riv` にも接続し、要求の成立・消滅と、その内容の肯否を区別する。制定・採用の変化による場合と、条件への該当だけが変わる場合を別々に検査した。

## 検査と残る範囲

六テストで、採用・役割・条件・目標・肯否・許可の64組合せ、結合と対象記述の18対照、未知入力四種、相反する要求の八組合せ、採用と適用条件の時間変化の16組合せを検査した。既存の適用・遵守・違反、共通の規範、規範変化の定義を実際に評価し、別に作った代替述語で模擬していない。目標の包みでは二つの真偽と四つの引数列形状を調べ、通常・短縮・固有文字の往復も確認した。

これらは有限モデルにおける検査であり、制度の正当性、例外・優先順位、期限、制裁、実行能力を確立したものではない。対象も既存の一人への条件付き規定である。任意の型の規範対象全体や、あらゆる社会的規範を網羅したとはしない。

カントの `Satzungen` に用いている採用済み規定の構成について、その要求としての帰結を共通の言語要素へ結んだ。原稿54文と登録簿v101は保持し、名詞の全語義や第三文全体の意味確認、新しい原文対応文字数は加えない。
