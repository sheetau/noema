# 共同体の活動可能性と保有の維持

前段の共同保護では、保護する目的を任意の内容として渡していた。今回は、保護される共同体の人々が指定した活動を行えることと、指定した物を同じ人が保有し続けることから、その目的を構成した。保護側の集団と保護される共同体は別に指定できる。

カント第17区間の「公的平穏」を検討する際、Adelungの同時代の辞書にある関連語 *Friede* の説明を参照した。同項目は公共の平穏・安全を人の安全や財産の安定に結び付け、暴力的な不和の不在も別の語義として挙げる。今回の活動可能性と保有の維持は、そこから検討する一つの構成要素である。*Friede* と原文の *öffentliche Ruhe* の完全な同義性や、カントの意図の一意性を示す根拠にはしない。[Adelung「Der Friede」](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_1_2_2757)

## 同じ本人の、同じ活動を行えるか

`rva` は、本人・活動・評価時点に方法と結果評価を結び付け、既存 `xd` の能力条件を適用する。その人の活動内容を満たす方法が少なくとも一つ利用でき、非空で整合した全評価結果で成功することを要求する。

活動内容は本人と活動の両方を受け取る。別人の成功、別の活動の方法、別の評価時点の利用可能性を流用できない。各人は別々の方法を使えるため、共同体全員が同じ方法を持つことは要求しない。活動の実行、許可、能力の成立も別の条件である。

## 維持対象を結果に応じて選び直さない

`rvb` は非空の共同体構成員を基準時点で選ぶ。各人の指定活動は少なくとも一つあり、その全活動について、基準時点と評価時点の両方で `rva` が成立する必要がある。選んだ全保有物についても、同じ人が両時点で保有することを求める。保有物のない人を除外する条件は加えない。

`rvc` はこの条件を状況ごとの内容にする。共同体、人、活動、保有物の選択は基準時点へ固定する。評価時点で人が共同体から外れても、活動が選択されなくなっても、保有物が一覧から消えても、基準時点で選んだ対象について調べる。

| 作例の状態 | 維持条件 |
| --- | --- |
| 一人が活動能力を失い、後から構成員の一覧から外される | 不成立 |
| 一人が物を失い、後からその物が維持対象から外される | 不成立 |
| 物が他の構成員へ移り、共同体全体では保有が続く | 元の人の維持としては不成立 |
| 各人に異なる成功方法があり、指定活動を行える | 成立可能 |
| 保有物のない人も、指定活動を行える | 成立可能 |

これは指定した状態を維持する条件である。任意の譲渡、消費、活動の変更まで禁止する社会規範は導かない。それらを許す目的が必要なら、維持内容そのものを別に記述する。対象範囲の妥当性や網羅性は、この検査だけでは決まらない。

## 共同保護の目的へ接続する

`rvd` は `rvc` を既存 `ruy` の共通目的へ渡す。同じ内容が、共同計画の結果、保護要因と脅威を切り替える介入比較、各評価結果の記録の整合性で使われる。`rve` は、その条件を満たす計画が少なくとも一つあることを表す。

作例では、保護側の二人の共同活動、保護される共同体の二人の活動可能性と保有、三変数の保護機構を接続した。共通目的を単独の真偽入力にはせず、各人の方法・結果・活動内容・保有関係からNoema自身が計算する。

## 成果物と限界

[定義文書](../examples/v016/community-continuity.noema)は37宣言・本文0文で、新規定義は五つ。[作例](../examples/v016/community-continuity-example.noema)は70宣言・10質問である。38テストが通過した。各人の能力と保有を変える16組合せ、時点や本人の取り違え、範囲の変更、空の共同体や活動集合、評価不足、未確定の関係を検査した。単独の能力判定は評価キャッシュの有無でも一致した。

通常表記・短縮表記・固有文字の往復、保存文書と検査記録の再現、CLI解析と固有文字SVGのXML検査も通過した。SVGの目視検査は行っていない。

意味評価の作例は13個体・11状況の有限領域を使う。能力の量化と保護の比較は実際のNoema定義を評価しているが、この作例を全ての共同体や現実の能力についての証明にはしない。

公的平穏そのものの完成ではない。身体の安全、暴力・騒擾の不在、社会制度の存続、軍隊の位置付けと指揮権、原文の上位主張への接続は残る。保有関係も法的権利や正当性の全理論には置き換わらない。今回は原文対応範囲と意味確認済み区間数を据え置く。
