# 短期の制度を自らに課し得ること

第六段落u0013の第七文 `[1437,2309)` にある `dieses` を、直前の「人民が自らにその法を課し得るか」という問いへの照応として読む。同じ人民・共同体・法について、規範的に許される自己賦課と、これまで構成した短期間の制度導入を一つの仮定経過へ接続した。原文の前後は[AA VIII, 39](https://korpora.org/kant/aa08/039.html)の15–27行で照合した。

`r5gs` は、結論から選別しない候補範囲 `r5ep`、同じ法の自己賦課への衝突のない積極的許可 `r5eq`、同じ制度の導入・短期・公的批評の自由・目的・洞察到達 `r5gr` を要求する。導入主体は同じ人民にする。共同の採択帰属という先行読解を保ち、全員一致の心理、直接投票や現行制度の権能は補わない。

`r5gt` はその同じ候補・開始・終了の存在を要求する。許可と導入を別候補から集めること、成功例のない空範囲、実施だけを根拠にした正当化を認めない。一方、一つの適切な候補があれば足り、全候補での成功や現実の実施を要求しない。洞察の真偽評価も固定引数のまま保つ。

本文を接続するため、十対象の列に可能性 `r5gu`、人民と法案の枠組み `r5gv`、字義的な期待描写 `r5gw`、前文の自己賦課可能性 `r5gx` を対応させた。期待描写は同じ人民・活動・法へ結ぶが、可能性の成立条件にはしない。この分離によって `gleichsam` を実際の心理状態の追加として扱わずに済む。

可能性 `r5gu` と期待描写 `r5gw` の内容族は段階1で引用する。期待描写も、さらに内側の「よりよい法」の全条項評価を依存先に含むため、段階0へ下げない。引用を受け取る側の型も同じ段階にする。

新しい基本関係は追加していない。規範的許可、採択、制度の維持、到達の内部構成は既存の定義を保持している。今回の検査は同じ候補と対象への接続、既存構成を通した採択・期間の評価、引用と字義内容の区別を確認する。有限モデルの検査を原文の意味判断や仮定範囲の現実的網羅性の証明にはしない。

これは全文統合に使う依存群であり、全法案への肯定を主張する文ではない。本文全体の量化と文脈範囲、目的・焦点・譲歩・換喩・期待描写の提示関係、著者への帰属と通読が残る。第七文の747非空白文字はまだ確認数へ加算しない。
