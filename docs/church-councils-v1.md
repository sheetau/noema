# 教会の審議機能と地区会議の位置

[前回の代表団体](delegated-associations-v1.md)へ、共同の宗教上の事柄を審議する機能と、地方内部の会議・地区会議・州会議の段階を接続した。[church-councils.noema](../examples/v016/church-councils.noema)の8定義は、第六段落冒頭のKirchenversammlungとKlassisの制度的内容を構成する依存群である。原文の問い全体はまだ統合していない。

会議体の分類には、現在審議が行われていることを要求しない。`r46d`は、本人の同じ行為が同じ会議体の公式手続として行われ、同じ論点を検討し、その論点が同じ教会の共同の事柄であるという活動を構成する。`r46e`はこの活動の内容を関数にする。`r46f`は、聖職者の団体または教会の職務代表団体が、この関数の閉じた記述を共同の実践として持つことを要求する。結論が出ない会合も審議に含め、実践を引用しただけで会合や議決を実行しない。

この読みでは、会議の手続、論点についての審議、論点を議決する制度上の担当、宗教組織の共同の事柄という四関係を分ける。制度上の担当は、不変の信条へ永久に拘束する契約の道徳的な権限を意味しない。後続のberechtigtを、会議体という名詞の定義から先に肯定することを避けている。

Klassisの位置には、同じ教会統治制度の機関範囲と、申立てや下位で処理しきれない事柄を上で扱う段階の関係を使う。既存`rey`で非反射性・推移性を確認し、`r46g`で範囲内の中間機関がない一段階差を構成する。`r46h`は同じ地区会議が地方会議の直接上、同じ州会議の直接下にあることを結ぶ。役職者の年齢や名声、現在の命令の発出とは別の関係である。

`r46i`は全構成教会が同じ近隣地区にあることを確認する。`r46j`はその地区を州区分の真部分へ結び、同じ州会議の全域にわたる担当と審議機能を保持する。そのうえで、構成教会ごとの地方内部会議を同じ中間・上位会議へ接続する。`r46k`はこれらの地区・州・制度・州会議を存在量化する。原文にない特定の実在会議名は補わない。

[ドルト1619教会規則](https://kerkrecht.nl/node/2149/)第30・31条は、教会の共通事項を扱うことと上級会議への申立てを規定する。第36・37・41・47条は、地方内部の会議、牧師と長老を送る地区会議、複数地区から代表を送る上級会議を記述する。保存済みの本文から該当条文を[今回の読解記録](../data/church-councils-reading-v1.json)へ切り出した。[Huygensの史料案内](https://www.huygens.knaw.nl/resources/classicale-acta-1573-1620/)の中間段階という説明とも照合した。個別の人数、多数決、会期間隔、議長の交替等の規則までをカントの名詞句の必須条件にはしない。

[検査](../reports/church-councils-v1.json)では、実際の審議内容と実践の指定を別々に評価する。行為・人・論点・教会の取り違え、機関の循環や推移辺の欠落、挿入された中間段階、別制度の辺、別地区の構成教会、別の州会議や地方会議の証人を区別する。大きい量化の接続は型付き境界で検査し、構成要素の実評価と分けた。境界と保存済み検査への依存は報告に明記している。

機関と構成教会の全範囲は解釈の入力条件であり、有限モデルが史実の完全さを証明するものではない。特定の制度における採用読解を、全教派・全時代の教会会議の普遍的定義とはしない。Klassisの自己呼称、Holländern、ehrwürdig、etwa、相互誓約、上位後見とその持続、否定疑問と次の回答は引き続き接続する。本文96主張と意味確認済み分量は増やしていない。
