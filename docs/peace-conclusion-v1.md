# 和平締結と文書を通じた確認

カント第六段落の文 `[444,712)` に向け、政治的な当事者が交戦関係を終える合意と、その文書による確認を構成した。前回の `r5ax/r5ay` に残していた合意の種類引数を、新しい `r5bh` の分類で具体化する。

`r5az/ba` は、同じ合意が終結の対象とする組と、実際の交戦関係をそれぞれ対称化する。`r5bg` は対象の全組について、相異なる当事者同士が同じ履歴の固定基準より前に交戦していたことを求める。組の範囲は非空とし、同盟者同士や交戦していない保障者同士まで戦っていたとはしない。

`r5bb/bc` は、指定した相手との交戦関係がなく、自らの組織的な武力敵対行動もない状態を条項内容とする。戦闘を一時停止していても交戦関係が続く休戦と区別する。条項は当事者と合意の正確な二個体列を受け、対象の組を固定基準に保つ。他国との無関係な戦争、全世界の永遠平和、具体的な賠償・通商条項を追加しない。

合意の当事者と表明する人を分けた。`r5bd/be` は人の行為・代表権限・政治的主体・合意・条項・相手を結び、全ての相手への表明を同じ人と同じ行為に保つ。`r5bf` は既存の相互引受け `rhz` を再利用し、二者以上の全政治的当事者が同じ内容を引き受けたことを構成する。無権限の署名や交渉案は資格・確定的な引受けの入力で区別する。

`r5bh` は同じ候補の履歴における先行交戦、相互引受け、固定基準と候補点の前後を結ぶ。条項は引用され、締結時に全ての敵対行動が既に終わったことや、その後に和平が守られ続けることは締結の形成に要求しない。現実の政治的手続の認定や条約の正当性を、有限モデルが自動決定する構成ではない。

`r5bi/bj` はこの分類を、同じ契約を確認する最も厳粛な合意文書へ接続する。主体による承認と文書の条項による確認を区別し、方式の固定比較基準と候補点を保持した。

[辞書の根拠記録](../data/peace-conclusion-evidence-v1.json)はAdelungの Friedensschluß・Friede の保存本文を参照する。[読解記録](../data/peace-conclusion-reading-v1.json)に原文・原刊画像と残る統合事項を固定した。検査は戦争関係と戦闘の違い、全対象組と中立の保障者、実行者の取り違え、全当事者の同じ引用条項、未表明・後日の表明・不正な履歴、同じ文書による確認を扱う。境界付きの検査箇所と、その境界を実評価する検査を報告に明示する。統合検査では二つの政治的当事者・二人の代表者を分け、和平の新定義と既存の相互引受け・履歴を実評価して文書による確認へ結ぶ。先行検査のある厳粛な方式の分類だけを境界に置く。

```powershell
python -X utf8 -m scripts.fetch_peace_conclusion_evidence
python -X utf8 -m scripts.project_work check --module scripts.check_peace_conclusion --tests tests/test_peace_conclusion.py --prepare --write-report reports/peace-conclusion-v1.json
```

残るのは、同種契約の仮定形成と無効性の接続、承認の列挙・全面性・譲歩の提示、全文の著者帰属と通読判断である。本依存群だけで確認済み文字数は加算しない。
