# 実数切断の極限・連続性・微分・積分

アインシュタイン正本の17定義を、元の型・本体・量化の順序を保って共有語と円文字へ接続した。円文字辞書第15版は416語、393定義、23基本宣言である。旧399語を保持し、新しい基本関係や基本字形は追加していない。

## 同じ構文から解析の条件を組み立てる

| 共有語 | 条件 |
| --- | --- |
| cutfunctionvalid | 定義域の全有効入力で関数値も有効な実切断 |
| cutnear | 正の半径に対する厳密な近傍。境界は含めない |
| cutaccumulation | どの正の近傍にも、その点自身と異なる定義域内の点がある |
| cutlimit | 各精度に半径を選び、穿孔近傍内の全入力の値が目標値へ近い |
| cutderivative | 点を除いた定義域の差商についてcutlimitが成立 |
| cutcontinuousat / cutcontinuous | 定義域内の一点／全有効点での相対的な連続性 |
| cutclosedinterval | 有効な下端以上・上端以下。両端を含む |
| cuttaggedcell | 左端・右端・代表点。区間幅は正で、代表点には両端も許す |
| cutpartition | 非空の有効な区間列が、指定された両端の間を順に接続する |
| cutmeshbelow | 全区間幅が正の指定幅未満。単独では空列も許す |
| cutriemannsum | 代表点での関数値と区間幅の積を、零から順に加算する |
| cutintegral | 各精度で十分細かい分割が存在し、全てのその分割の和が値へ近い |
| cutleftnear / cutleftaccumulation | 境界より左の厳密な近傍／左側からの接近 |
| cutleftdivergespositive | 任意の有限上限を、十分近い左側の全入力で超える |
| cutinterior | 点を含むある正の開近傍全体が定義域に属する |

孤立点での連続性は許すが、ここで採用する極限には集積点の条件がある。極限の点は定義域の外でもよく、連続性と微分では点自身が定義域内にある必要がある。微分は指定定義域に相対的なので、片側の端点でも成立し得る。両側の内点が必要な利用箇所ではcutinteriorを加える。

積分は下端が上端より小さい閉区間を扱う。各精度に対応する分割幅があり、その幅未満の分割が実際に存在することも要求する。空の分割範囲による空虚な成立を認めない。逆向き・零幅・広義の積分をこの語へ暗黙に追加しない。

cutleftdivergespositiveは、有限の実切断を上限として量化する。無限大という新しい実数を導入せず、境界そのものに関数値を与える必要もない。空の定義域や、境界に接近しない定義域による発散認定は排除する。

## 意味と名前の保存

[正本との対応](../data/einstein-cut-analysis-correspondence-v1.json)は17宣言の元の意味説明・型・本体・本文使用を保存する。前二版と合わせた40宣言を正本全文に対して単射に改名し、元へ戻せることを確認する。関数の等号を実装上の識別子比較へ変えず、他の歴史的な別名も統合しない。正本・原文の意味判断・登録簿は変更しない。

このうち左側の集積と正の発散を表すsess・sestは、現行正本に宣言が保存されているが、選択中の最上位の文からは参照されていない。本文で使われているという記録を追加せず、再利用できる定義として保持する。

物理的な軌跡や時刻に関する元の利用箇所から、数学的な定義を共有する。利用側に必要な観測・単位・滑らかさ・近似の前提は、これらの解析語だけから補わない。

## 三種類の検査を区別する

[保存SVG](../output/visible-cut-analysis-v1/)から45宣言と10式を復号する。近傍・閉区間・左側近傍の有理数埋込みに関する三法則と、有効なタグ付き区間の三例が成立する。代表点が外にある場合や幅が正でない場合の四つの主張は不成立である。検証用文書は意図的に偽の式を含み、全てを真な理論として採用するものではない。

極限などの量化条件は、別途、実切断の型を有理数の型へ明示的に置き換えた診断で調べる。下位の切断演算を正確な有理算術へ変え、上位17定義の演算構造・量化順序・有限列の集計を保持する。有理数への量化は全有理数のままであり、有限標本ではない。孤立点・片側の定義域・空の定義域・誤った極限値を区別する。これは実切断全体についての証明ではない。微分に必要な逆数は、線形検証器を通すために削除しない。

分割と和は、この有理数版の具体的な有限列でも調べる。隙間、重複、列の反転、区間幅の境界、代表点の変更を検出し、空の和は零となる。元のNativeの空の和についても、返される零の切断の開境界を別に確認する。有限列の検査から、全分割を量化する積分の存在や微積分学の基本定理を証明したとはしない。

各検査の結果は[報告](../reports/shared-cut-analysis-v1.json)で区分する。全実切断の関数・全有限列を扱えない評価器には拒否を要求し、未処理を偽や成功へ置換しない。[意味規約](../data/shared-cut-analysis-basis-v1.json)と[公開語形](../noema/resources/visible-analysis-vocabulary-v1.json)から語の役割と条件を確認できる。

```powershell
python -X utf8 -m scripts.project_work check --module scripts.check_shared_cut_analysis --prepare --tests tests/test_shared_cut_analysis.py --verify reports/shared-cut-analysis-v1.json
$analysisPages = Get-ChildItem -LiteralPath output/visible-cut-analysis-v1 -Filter 'page-*.svg' | Sort-Object Name | ForEach-Object FullName
python -X utf8 -m scripts.visible_analysis_collection decode @analysisPages --public-names
```
