# 名称そのものへの評価と、仮定された使用

カントu0015の名称への批判を、実際にその名称を使った人物への評価から分離した。前段の「裁量を持つ側としての自己位置付け」と「その資格の不足」を、明示した仮定状況で比較する。名称を拒む君主が現実にその立場を取ったとは断言しない。

| 定義 | 内容 |
| --- | --- |
| `rnu` | 固定した非空の人物範囲と仮定状況範囲で、その名称の使用には同じ人物・行為・状況で不足条件が伴う |
| `rnv` | `rnu`に加え、その範囲に少なくとも一つの名称使用の仮定例がある |
| `rnw` | `rnv`を名称についての評価内容にし、引用・帰属の対象にできるようにする |

人物範囲と仮定状況範囲は、名称と外側の評価文脈に固定する。仮定状況を評価する途中で都合のよい別範囲へ交換しない。使用と資格不足は同じ人物・行為・名称・状況について照合する。別の行為について不足が見つかっただけでは、評価対象の使用が不足条件を満たす証拠にはならない。

仮定範囲内に適格な使用が一つあれば、この条件による批判は成立しない。仮定例が全くない場合には`rnu`が空虚に成立し得るが、`rnv`は成立しない。人物範囲や仮定状況範囲が空なら両方とも不成立である。条件文の成立、条件に合う仮定例の存在、現在の出来事の存在を別に扱う。

接続例では、名称の自己適用を前段の説明された名称の構造へ、資格不足を同じ自由政策についての裁量評価へ結ぶ。現実には名称の使用がなくても、仮定状況でその立場を取る場合を評価できる。現在の使用が適格でも、現在を含まない仮定範囲の評価とは別である。この範囲指定を、全話者・全ての用法・全可能世界で成り立つ批判へ広げない。

評価内容は通常のNoemaの式として引用し、既存の候補選択`rj6`・`hzd2`へ渡す。選択した同じ記述が候補列にあり、同じ箇所・著者・文脈への帰属記録があることを要求する。内容が真でも著者帰属は自動で生じず、帰属があっても内容が真とは限らない。帰属だけを確認するときには、引用された仮定状況の使用や資格を実行評価しない。

前段で政策内容の脱引用を解消した説明に加え、自己適用の関係にある対象の脱引用を、既知の閉じた個体記述への特殊化で一箇所解消した。これによって仮定評価全体を通常の引用へ入れられる。未知の資格や帰属は、偽・真のいずれにも補わない。

[一般文書](../examples/v014/label-appraisals.noema)は7,506文字、[原文付き草案](../examples/v014/kant-label-appraisals.noema)は191,555文字、[抽出文書](../examples/v014/label-appraisals-core.noema)は9,053文字である。三定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-label-appraisals-basis-v1.json)と[検査記録](../reports/label-appraisals-v1.json)を保存する。

現在の使用、二つの仮定状況での使用・資格、著者帰属の64通りを検査した。原文付き文書と抽出文書では、空の範囲、名称・箇所・著者・文脈・内容の取り違えを含む八条件ずつを検査した。追加15テストで反例、空虚な成立、範囲外の使用、現在との独立性、未知の資格・帰属、別行為からの不足の流用、引用の非実行を確認した。三文書のCLI解析、固有文字v2の往復、SVGのXML検査も通過した。SVGの目視確認は含めない。

これは名称の批判を仮定された使用から説明する解釈候補であり、傲慢一般の必要十分条件ではない。カントがこの形式的モデルを明示した、またはそのモデルの全てを主張したという結論も出していない。現実の語用慣習、典型性や傾向、評価の論証、寛容に含まれる不賛同・抑制、称賛と政府による解放、全文の意味確認は未完である。既存の対応範囲内の追加なので原文範囲の割合は増えない。
