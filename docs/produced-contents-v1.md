# 持続する状態と、それを生じさせる行為

カントu0013の永続化を目指す箇所へ、持続を結果として生じさせる内容を部分接続した。[アカデミー版電子本文39頁](https://www.korpora.org/Kant/aa08/039.html)1行では、この目的が問いの中に置かれている。今回も、永続化する行為が現実に成功したという主張は追加していない。

| 定義 | 内容 |
| --- | --- |
| `rig` | 指定した非空の行為者群が同じ生起する行為に参加し、その行為が記述された結果を生じさせ、その同じ内容が成立する |
| `rih` | `rig`を満たす行為が存在するという内容 |
| `hzcq` | 行為者を人に限定し、既存の行為の生起・参加の関係へ`rih`を接続する |

因果関係へ渡した閉じた内容記述を、そのまま脱引用して結果の成立にも使う。別々の「結果の記述」と「結果の値」を受け取らないため、因果関係が参照する内容と、真偽を確かめる内容を取り違えない。結果の別名への因果や、別の行為・時点に関する記録を借りて成立させることも認めない。

行為者群の全員は同じ行為に参加する。ある人だけが参加した別の行為を集めても条件を満たさない。候補となる一つの行為が失敗しても、別の同じ条件を満たす行為が存在すれば`rih`は成立できる。一人ずつが単独で十分な原因であること、他の原因がないこと、事前に結果が偽だったことは要求していない。

因果関係は`produces`という型付き引数で明示する。単なる同時成立や時間的な先行から、この関係を推論する規則は追加していない。既存の`g3`は人についての状態を結果とする意味規約なので、組織全体の状態に暗黙に広げず、一般の閉じた内容への関係を別に受け取る。この入力の指定だけで因果機構や認定方法を説明し終えたとは扱わない。

結果には、前版の履歴全体の持続、終点のない持続、数値的に無期限の持続をそれぞれ指定できる。行為と結果は同じ評価文脈で結ぶが、結果内容の内部には将来全体への量化がある。結果が現在観測できることと、未来全体にわたって結果が成立することを混同しない。

未知の結果記述を受け取る一般形は、動的な脱引用を含むためそのまま引用できない。目的へ使う際は、閉じた結果記述を固定して既存の特殊化処理へ渡す。処理は既知の引用の脱引用を式へ展開し、通常のNoema定義を作る。その定義へ行為者群と因果関係を適用した閉じた式を引用すれば、「その状態を生じさせる」という目的を記述できる。

この展開は因果や結果を実行評価しない。未知の結果を推測して埋める操作でもない。同じ展開後の定義を人が直接Noemaで記述してもよい。純粋で全域的な解釈のもとで、一般形を直接評価した結果と、特殊化した定義の評価結果が一致することを検査した。

検査では、行為の生起、二人それぞれの参加、因果関係、結果の成立を独立に変える32通りを調べた。原因関係がないまま結果だけ成立する場合も、因果関係だけ与えられて結果が偽の場合も、達成済みの因果的行為として認めない。空の行為者群、未参加の追加行為者、別名・別行為・別時点、別の適切な行為の存在を含む6対照例も検査した。

原文接続では、目的志向・因果関係・結果の持続の8通りを調べた。目的を持っていても永続化に成功していない場合を表せる。非人の行為者、行為の不生起、参加者の欠落も区別する。因果が未知でも目的は記述できるが、達成を評価する際は未知の関係を補わない。既存の無効性条件には前版と同じ検査用の解釈を与えており、全規範の列挙証明には数えない。

終点なしの結果は有限モデルでは成立せず、数値的な全時間限界を含む結果の評価は有限解釈器が拒否する。その両方を、未達成の目的として引用できることを確認した。有限モデルの不成立を、現実の永続化が不可能だという結論にはしていない。

[一般文書](../examples/v014/produced-contents.noema)は361文字、[原文付き草案](../examples/v014/kant-produced-contents.noema)は118,938文字、[抽出文書](../examples/v014/produced-contents-core.noema)は6,863文字である。3定義を追加し、親の宣言と15件の主張を保持した。新しい原始概念・著者主張は追加していない。[意味規約](../data/kant-produced-contents-basis-v1.json)と[検査記録](../reports/produced-contents-v1.json)に意味と限界を保存した。
