# 制度変更への合意と継続を望む意思

前版では、変更を望む共同体と旧制度を維持する共同体を、外から与える条件で選んでいた。今回は、同じ条項への引受けと、その条項を実現する目的から、この二つの条件を構成した。合意・目的・保護する活動が、本人・共同体・制度を同じ順序で参照する。

| 定義 | 内容 |
| --- | --- |
| `rk7` | 条項の記述を本人・共同体・制度へ適用する |
| `rla` | 同じ比較範囲で旧制度と新制度の条項内容に差がある |
| `rlb` | 同じ共同体の二者以上が、新制度への同じ条項を引き受け、その内容に旧制度との差がある |
| `rlc` | 空でない成員の集合が、同じ共同体に帰属する計画で同じ条項の実現を目指す |
| `rld` | 同じ履歴の基準点以降で条項が持続する、という条項を構成する |
| `rle` | 共同体・制度から得る状態を、本人・共同体・制度の三個体列へ接続する |
| `rlf` | 基準点で固定した対象者について、同じ条項が成立する活動を構成する |
| `hzel`・`hzem` | 合意と継続の目的を、人・行為・時間順序の既存規約へ接続する |
| `hzen` | 同じ条項から共同体を選び、保護・不干渉の対象活動を構成する |

制度を変更する合意には、当事者全員の引受けを要求する。当事者は共同体の適格な成員だが、共同体の全成員である必要はない。合意の対象は同じ新制度であり、本人の引受けを他人のものに置き換えられない。合意が成立しても、新制度の実施済みまでは要求しない。

識別子だけの変更は制度内容の変更と数えない。`rla`は、明示した比較範囲で同じ条項の真偽に差があることを要求する。ただし、比較範囲に含まれない違いや、条項に記述していない儀礼・制度史まで判定するものではない。一方、引受けの記録では記述の同一性も保つ。内容が等しい別名へ、記録された条項を勝手に置き換えない。

旧制度を維持したいという側は、変更への合意がないことから推定しない。同じ計画に帰属する明示的な目的を要求する。これは集団の意思の一つの強い読みであり、個々人の願望や発言だけから成立させない。目的の活動を実行したことも、その目的が実現したことも含意しない。

継続は、現在の状態だけでは足りない。同じ履歴の基準点以降でも条項が成立することとして構成する。現在は旧制度が成立していても、その後で失われれば継続内容は偽になる。将来の状態が未知なら、成立すると補わず評価を拒否する。有限の履歴での継続を現実の永続と同一視しない。

保護する活動は、合意・目的が参照する同じ条項から構成する。共同体を選ぶときだけ正しい条項を使い、保護効果の検査では別の活動へ取り替えることを防ぐ。変更側には新制度の条項、維持側には旧制度の条項を用いる。選択時点の成員と評価時点の観測を区別し、観測整合性は前版の規約を保持する。

この政策内容を共同提案の対象にもできる。内容の比較・実現に必要な脱引用は、同じ既知の閉じた条項記述へ静的に特殊化してから引用する。政策や観測が未知でも、その政策を提案すること自体は記述できる。未知の政策を実行して提案の成立を決めることはしない。

[一般文書](../examples/v014/institutional-choices.noema)は3,183文字、[原文付き草案](../examples/v014/kant-institutional-choices.noema)は161,352文字、[抽出文書](../examples/v014/institutional-choices-core.noema)は14,551文字である。十定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-institutional-choices-basis-v1.json)と[検査記録](../reports/institutional-choices-v1.json)を保存する。

宗教制度の具体的な内容、よりよい理解についての当事者の判断、共同体の正当な代表資格、原文の不確定性・接続法、君主の位置、著者帰属は未完である。今回の対応は解釈上の部分注記であり、該当する原文を同義に表し終えたという認定ではない。

検査では、合意と目的には継続条項を使い、政策の真理評価には制度状態の条項を使った。継続条項を含む政策全体の直接評価は、13個体・10状況の基準作例で6,400万ステップの上限に達した。これは反例を得たという意味ではないが、全体の通過も確認していない。継続の意味と、同じ条項を保護対象へ接続する構成を個別に検査した段階であり、時間条件を含む統合評価の計算量を減らすことが残る。継続政策の引用・提案については、その内容を実行せず検査する。

引受けの三条件と目的の16通り、11種類の対照例、現在の状態と将来の継続の差、制度状態を使う政策と継続政策の提案を検査した。追加13テストと観測整合性の回帰7テスト、計20テストも通過した。三文書のCLI解析は構文木と一致し、抽出文書の固有文字v2のSVGをXMLとして検証した。SVGの目視確認は含めない。
