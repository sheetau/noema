# 同じ命題への問いと否定回答

カントu0013の否定疑問と、それに続く否定判断を記述する定義を追加した。質問の文法上の肯否と、回答で肯定・否定する命題を分ける。原文の資格を規範上の許可として読む部分的な解釈であり、問いの全文と著者の回答の意味確認を終えたものではない。

基準となる命題をPとすると、正極性の内容はP、負極性の内容は¬Pである。「Pではないのか」という問いを述べたあとにPを否認する場合、質問も回答も同じPへの負極性を取れる。否定疑問の内容¬Pをさらに否定してPに変える規則は設けていない。

| 定義 | 内容 |
| --- | --- |
| `rii` | 命題と極性から、元の命題またはその否定を作る |
| `rij` | その内容を問う発話を作る |
| `rik` | その内容を主張する発話を作る |
| `ril` | 異なる二箇所で同じ著者が問いと主張を提示し、問いが先行し、主張を回答として提示する |
| `hzct` | 指定した規範の出所・名宛人・立場・対象について、反対要求と衝突しない積極的許可があるという内容 |
| `hzcu` | `ril`を原文草案の質問提示・著者主張・本文順序・回答関係へ接続する |

質問の提示と回答関係には二つの原始関係を追加した。既存の発話引用`ub`は他者の発話を引用する関係であり、著者が自分で問うことへ転用していない。本文順序`ue`だけから、後続文が回答だと認定することもしない。原始関係は意味規約を持つ入力であり、現実の文章から認定する方法や一般的な基礎への還元は未完である。

`ril`は内容の異なる回答や不適切な回答の帰属も記述できる一般関係である。型だけで問いと回答の同一命題性を保証しない。検査用の具体例では、一つの閉じた基準命題を作り、それを質問の`rij`と回答の`rii`へ渡す。質問側と回答側の極性をそれぞれ負に固定し、両方の記述を`hzcu`に渡す。同じ真理値になる別名を回答だけに代入しても、元の記述への帰属とは一致しない。

この閉じた記述の組立ては既存の`apply_description`による通常のNoema式の構成であり、自然言語からの生成や翻訳ではない。命題の真偽を実行評価せずに、その命題を問うことや否認することを記述できる。帰属が真であっても、回答内容そのものを解釈器が真と認定したことにはならない。

`hzct`は既存の規範関係`rdu`を再利用する。指定した対象内容の積極的許可があり、その否定を要求されておらず、引数列が適合することを条件とする。契約が現に成立したことや、永続化という目的が達成されたことは条件に含めない。許可が未知の場合、内容の真偽の評価は停止する。一方、著者による質問や回答の帰属を記述するために許可の真偽を知る必要はない。

これは原文の「資格がある」という語義の候補であり、制度的な権能・正当性・正規の資格を全て積極的許可へ還元したものではない。また、後続の不可能性を資格の否認と読む候補であり、目的の物理的不可能性へ置き換えない。否定疑問に含まれる期待や反語、判断の強調、宣誓、組織・契約・役割の具体的な特定は未完である。

検査では真偽と極性の4通りを調べ、同じ内容への質問と断言が異なる発話であることを確認した。質問提示・主張・順序・回答関係の16通りを一般文書と原文側でそれぞれ検査した。著者・文脈・順序・回答方向・同一箇所、質問極性・回答極性・別名の8対照例も区別する。規範の許可・反対要求・引数適合の8通りを調べ、対象の現実の実行を評価せずに許可と否認を記述できることを確認した。

[一般文書](../examples/v014/question-responses.noema)は398文字、[原文付き草案](../examples/v014/kant-question-responses.noema)は119,627文字、[抽出文書](../examples/v014/question-responses-core.noema)は1,064文字である。6定義・2原始関係を追加し、親文書の宣言と15件の主張を保持した。新しい著者主張は追加していない。原文の契約内容を全て特定した帰属文の完成形とは扱わない。

[意味規約](../data/kant-question-responses-basis-v1.json)と[検査記録](../reports/question-responses-v1.json)に、原文の資格・回答提示・否定判断への部分的な解釈注記を保存した。構文の往復と有限解釈の検査は原文全体の意味一致を証明しない。全文単位の意味確認済み件数は引き続き0である。
