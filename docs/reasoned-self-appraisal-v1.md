# 理由ある自己評価と、全ての人の自己思考への課題

カント第四段落の、自分の価値を理性的に評価することと、各人が自ら考える使命を、具体的な内容の候補へ接続した。前段の「自分の状態を好ましく受け入れる」という態度だけへ置き換えず、評価する人・評価される対象・判断内容を別々に保持する。

## 採用する読み

[AdelungのWerth項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_6_1_1875)は価値・長所の評定と外的事情や価格に関する用法を区別し、[Schätzen項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_7_0_999)も一般の評定と高く評価する用法などを記す。ここでは、原文にない価格・数値・高い評点を固定しない。人としての価値に適した評価基準は文脈で指定する。

[Beruf項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_4_1_1767)には内的傾向、義務、職務などの用法がある。今回は、全ての人が自分で考えることを課題として要求されるという規範的な読みを採る。職業・国家の命令・神からの命令へ自動的に限定せず、規範の出所と立場を明示する。これを唯一の読解と認定するものではない。

取得した電子翻刻とハッシュ、読みの選択と限界を[読解記録](../data/self-appraisal-reading-v1.json)へ保存した。原刊画像の照合はしていない。資料は記述体系を設計するときの語義確認であり、実行時の対訳辞書や語別学習には使わない。

## 判断・対象・理由を同じ行為へ結ぶ

`rqtf`は、同じ判断について、本人が判断すること、その事柄についての判断であること、その判断で用いた理由が同じ判断を支えることを要求する。単に理由が存在する場合や、別の判断への支持では足りない。既存の`fa`・`fb`・`fc`・`fd`へ接続する。

二つの一般的な基本関係を加えた。

| 関係 | 保持する内容 |
| --- | --- |
| `hznm` | 同じ判断が、同じ対象を、指定した評価基準の下で、ある評定として評価する |
| `hznn` | 同じ判断が、指定対象へ同じNoemaの内容記述を適用した内容を、肯定または否定する |

`hznm`は自分自身専用の関係ではない。人・物・実践などの価値を評定する場合に、対象・基準・評定を保持する。評定は質的な対象として与えられ、数値の大小や金銭に還元しない。評価基準そのものの妥当性を、この関係だけで保証することもない。

`hznn`は内容を検討する既存`hzv`と異なり、判断が取る肯否を明示する。一方、その内容の真理は含意しない。別人の判断、別の内容、同じ内容の否定を肯定へ代入することはできない。記述の真偽が偶然同じでも、その記述を同一化しない。

`hznr`は判断主体と評価対象を同じ本人に結び、理由ある自己評価を述べる。どの判断・どの評定かは存在量化し、特定の評点を原文へ補わない。`hznt`は本人の理由ある肯定判断を、同じ話題と内容記述へ結ぶ。

## 全ての人が、それぞれ自分で考える

思考の内容`hzno`は、自分の理解力と理由を用い、他人の指導によらない判断を行うという既存`iahthinking`の本体をそのまま再利用する。`hznp`は一人だけの引数列を受け、その同じ人の`hzno`を記述する。空列や余分な人を切り捨てない。

`hznq`は、人の範囲全体について、各人にその人一人の引数列を結んだ`hznp`が要求されるという内容を作る。全員に同じ代表者の思考を要求したり、判断を持つ本人だけに範囲を狭めたりしない。対象となる思考を引用するため、要求を述べても思考の実行を評価しない。

この全称命題は、解釈に人が一人も存在しない場合には通常どおり真になる。一方、本人による自己評価・肯定判断には、本人が人であることを別に要求する。有限検査の二人が、現実の全人類を尽くすという主張ではない。

`hzns`は規範の出所と立場の閉じた参照から、この内容の記述を構成する。内容を認める判断の中で、出所・立場・各人への目標の結び付きを失わない。参照の同義性を一般に解決する仕組みではなく、同じ対象を指す別表記でも記述として区別し得る。

## 二つの内容と取得への接続

`hznu`は同じ人・同じ状況で、理由ある自己評価と、全ての人の自己思考への課題を認める判断を結ぶ。自己評価と規範についての判断は、別の判断行為でもよい。規範を認める本人の判断が成立しても、解釈上その規範が実際に採用されていない場合を許す。

`hznv`は評価基準・話題・規範源・立場の参照から、この性質の閉じたNoema記述を構成する。既存`rqte`へ渡すと、その記述から状態を評価し、その同じ記述を原因の目標にする。自己評価と規範承認を、自分の状態を好む`hzni`で包み直す必要はない。

これは一つの状況で評価・承認を行う具体的な状態である。持続的な精神や性向としてのGeistを、一回の判断で表し終えたとはしない。伝達経路全体、周囲の範囲、将来の様相、著者帰属への接続も残る。
