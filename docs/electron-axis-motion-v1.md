# 原点・初速零・軸上の運動と仕事の条件文

u0261の運動設定を、前段のエネルギー過程と同じ粒子・系K・開始と終了の出来事へ接続した。開始の三空間座標と速度成分を零とし、終了のx座標を仕事積分の上端、終了のx方向速度を前段のvへ結ぶ。速度には既存の座標時刻による履歴と微分の定義を使い、点の名前だけで初速零を補わない。

開始から終了までの閉区間の全実時刻が履歴の定義域に入り、その全てでyとzが零であることを要求する。時間引数と座標の時刻成分も一致させる。領域を端点だけに狭めたり、途中で軸を離れる時刻を除いたりして条件を満たすことは認めない。速度の二側の近傍を扱うため、履歴自体は運動区間の外にも延びてよい。

検査には登録した多項式の曲線と解析的な微分を使った。端点と中点でyが零、両端で横方向速度も零となる曲線でも、その多項式が区間内で恒等的に零でなければ軸上の運動とは認めない。少数の点で値を合わせて未知の曲線を推定する検査ではない。物理的な全履歴はモデルで指定した前提として扱い、全実切断の極限や観測を証明したとはしない。

原文の「この運動と静電力の設定なら、場から取り出したエネルギーが仕事積分に等しい」という条件文を保持する。前件が成立しない場合の条件文の真理から、実際の粒子や運動を推定しない。静電場・電荷・位置プロファイルは同じ仕事積分へ結ぶが、静電力の基礎説明、ゆっくりした加速、無放射の論証、積分の速度への変数変換は残る。

先行185文を保存し、条件文への著者帰属を一文追加した。軌道と既存の収支・無放射の前提を結ぶ内容構成子も用意したが、初速零から運動エネルギー零への物理的な導出を証明したとはしない。[本文](../examples/v014/einstein-electron-axis-motion.noema)、[一般定義](../examples/v014/electron-axis-motion.noema)、[当該箇所](../examples/v014/electron-axis-motion-core.noema)、[読解記録](../data/electron-axis-motion-reading-v1.json)を保存する。検証は `python -X utf8 -m pytest tests/test_electron_axis_motion.py`、報告の再確認は `python -X utf8 -m scripts.check_electron_axis_motion --verify-only` で実行する。
