# 複数時計の同期条件と、仮定としての採用

アインシュタイン論文§1の同期に関する二つの関係法則を、既存の光往復の条件へ接続した。同じ参照時計を全比較で使う条件も別に記述した。以前の草案は二つの法則を直接主張していたが、今回は著者がそれらを仮定の範囲へ置くという発話上の位置付けを保持する。

[原文の電子本文](https://de.wikisource.org/wiki/Zur_Elektrodynamik_bewegter_K%C3%B6rper)では、光往復の等式に続き、同期を任意個数の地点で矛盾なく定義できると仮定し、対称性と三時計の関係を挙げる。その後、全ての時刻決定に同じ参照時計を使う。今回の対応は `u0015`〜`u0017` と、`u0018` の参照時計に関する末尾部分である。原刊画像との照合、任意個数での物理的実現可能性、時刻決定の全文は未完である。

## 一往復から、評価範囲全体へ

一回の光往復で条件が成立しても、それだけでは同期の全期間を記述したことにならない。新しい接続 `qn` は、同じ二時計・基準系・単位・文脈に関連する試行の集合を扱う。集合が空でなく、指定範囲が必要な試行を尽くすという前提があり、その全試行で判定条件を満たすことを要求する。

実際の同期関係 `qo` では、その判定関数へ既存の `db` を渡す。各試行の出発・反射・帰着、場所、光信号、三つの読みを同じ試行から取り、共通の時計対・基準系・時間単位とともに渡す。`db` の物理的な結合条件と実数の切断による等式は変更していない。同じ有効な時計の自己同期は、同一性による規約として明示した。

試行範囲が完全という条件は記述上の前提である。有限の観測から全時刻の成立を自動認定するものではない。選択した時計の中に時計でない対象、動く時計、設置場所のない時計があれば、無効な対象だけを除いて合格にはしない。

## 二つの法則と、共通の参照時計

| 定義 | 条件 |
| --- | --- |
| `saa` | BがAと関係するなら、AもBと関係する |
| `sab` | AがBとCに関係するなら、BもCと関係する |
| `sac` | 一つの同じ参照対象が範囲内にあり、全対象がそれと関係する |
| `sad` | 非空の関連試行の全てが判定条件を満たす |

対称性と `sab` だけでは、全時計間の同期は導けない。例えば互いに無関係な同期集団でも条件を満たせるし、空の関係でも二つの含意は成立する。これに `sac` を加えると、二時計から参照時計への関係を対称性で反転し、参照時計を始点とする `sab` により二時計間の関係を導ける。

3対象の関係512通りでは、二法則を満たすものは15通り、一つの共通参照対象を持つものは64通り、三条件を全て満たすものは全対象間が関係する1通りだった。この有限検査と論理的な条件の説明は、任意個数の時計を現実に調整できるという物理的証明とは別である。

## 仮定の帰属を内容の真理と分ける

原文接続文書の `qp` と `qq` は、同じ時計範囲の二法則をそれぞれ内容として記述する。`qr` はそれらを合わせた、仮定内容の部分草案である。既存の仮定採用 `ug` と範囲内主張 `uh` を使い、同じ著者・文脈・推論範囲へ結び付けた。

文書を評価してこの帰属が成立しても、関係法則や光の伝播を検査器が真と認定したことにはならない。検査では、物理内容を実行すると失敗する関数を使って分離を確認する。別の内容や推論範囲、二法則の取り違えは受け入れない。

`qs` は同じ参照時計の条件を表すが、出来事の時刻や局所的な時計の読みまで定義したものではない。原文の「任意個数で矛盾なく可能」という部分も、二法則の記述だけでは説明し終えていない。これらを今後の意味確認の課題として残す。
