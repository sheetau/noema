# 出所を限定した解放と、広い範囲での解放

カントu0015の「少なくとも政府側から」という限定へ、非空の最小範囲と広い比較範囲を区別する構造を追加した。選んだ出所についての成立を述べ、他の出所の成立・不成立はどちらも要求しない。「政府側だけ」と排他的に限定する読みへ変えない。

| 定義 | 内容 |
| --- | --- |
| `roh` | 選んだ最小範囲が非空で、明示した比較範囲の部分集合である |
| `roi` | 同じ対象・文脈について、最小範囲内のすべての出所の条件が成立する |
| `hzgg` | 同じ集団・人々・役割・主題・活動・実行記述について、出所ごとの規範上の選択条件を返す |
| `hzgh` | 政府側の出所一つを最小範囲にし、その出所について`hzgg`が成立する内容を作る |

最小範囲で条件が成立しても、広い範囲で成立するとは限らない。たとえば政府が実行と不実行を許していても、別の出所が両方を許していなければ、政府側の条件だけが成立する。別の出所が実行を明示的に要求して不実行の選択を制限する場合も、政府側の判定へその要求を混ぜない。両方が許す場合にも、政府側の条件は成立する。この二つを許すことで、「少なくとも」という限定から他側面の否定を導かない。有効な部分集合であることが確認できれば、広い範囲の全条件の成立から最小範囲の成立は従う。

出所を比較するとき、対象集団の成員・役割・主題・基準時・活動と実行記述を固定する。別の人や活動への許可を集めて全体への許可にはしない。選んだ出所が比較範囲に含まれなければ限定の条件は不成立となり、空の最小範囲も成立の証拠にはならない。比較範囲そのものが現実の全出所を尽くすかは別の課題である。

`hzgg`は既存`hzfo`を出所ごとに適用する。実行と不実行の両方に積極的な許可を要求し、反対要求との衝突も排除する。実行してよいという片側の許可だけでは足りない。出所間の優先順位や、競合する規範の最終的な許否は決めない。ここでの政府側からの解放は規範上の選択条件への部分接続であり、政府という制度の全意味、実力による強制・干渉、学習不足や内面的な依存をこの条件へ還元しない。

同じ限定内容を閉じた目標として既存`hzge`へ渡し、政府側の条件が不成立から成立へ変わる行為と、その行為への関与・結果生成を接続した。最初の達成者は既存`rod`で比較する。政府側の条件が現在成立するだけでは解放行為や最初の達成者を補わず、先行する達成の評価が欠ける場合も最初とは認定しない。広い範囲での解放や実際の知的自立を、この限定された目標の達成から導かない。

意味上の無断言と、部分的な入力だけで計算できることは分ける。現行の有限解釈器は条件式の両辺を評価するため、最小範囲外の出所についても関数値を要求する場合がある。値が未知なら判定を拒否し、偽に補わない。この実装上の制約を検査で保存した。限定された目標を引用するだけなら、内容は実行評価しない。引用へ渡す達成関係では、既知の目標への脱引用を一箇所静的に解消した。

[一般文書](../examples/v014/limited-release.noema)は238文字、[原文付き草案](../examples/v014/kant-limited-release.noema)は196,432文字、[抽出文書](../examples/v014/limited-release-core.noema)は5,049文字である。四定義を追加し、原始記号と著者主張は増やしていない。親の宣言と15件の著者主張を保持した。[意味規約](../data/kant-limited-release-basis-v1.json)と[検査記録](../reports/limited-release-v1.json)を保存する。

最小範囲・比較範囲・各出所の条件の64通りを検査した。原文付き文書と抽出文書では、それぞれ両出所の規範の16通りと八つの対照条件を確認した。追加17テストは、排他性を含まない限定、他出所の制約、空・範囲外の最小条件、複数出所、人物と活動の保持、実際の達成と最初の達成、引用、評価器の入力要求、能力や因果関係との独立性、原文範囲を対象とする。三文書のCLI解析、正規形と固有文字v2の往復、SVGのXML検査も通過した。SVGの目視確認は含めない。

原文の限定句への解釈注記であり、政府側からの解放の必要十分条件を確定した訳ではない。人類・未成熟・良心・政府の基礎概念、物理的な干渉と規範の関係、感謝・世界・後世、原文全体の意味一致は未完である。
