# 固定した荷重条件に対する変形の小ささ

カントの覆いの描写で、従来は「変形への抵抗がある」という真偽入力を使っていた。今回は、同じ物へ指定した荷重を与えたとき、変形が所定の上限以下であるという説明に置き換えた。物理的な描写側についての操作的候補であり、原文の「硬い」の意味を確定したものではない。

`rys` は非空の完全な試験範囲を取り、全試験について次を要求する。

- 物・試験・方法・荷重単位・変形単位・評価状況が同じ組合せで評価済みである。
- 正の荷重下限以上の力を与えている。
- 変形量は非負で、指定した非負の上限以下である。

試験をしていないことや、力を与えなかったため形が変わらなかったことでは条件を満たさない。試験の重複、範囲からの省略、未評価の行、別物や別の方法の結果も区別する。変形が0でも除算しないため、判定は定義される。二つの量の数値表現をそれぞれ正の倍率で変え、対応する閾値にも同じ倍率を掛ければ結果は変わらない。単位の自動換算や次元の推論を追加したわけではない。

`ibaresistant` は、覆いと発話文脈で試験の範囲・方法・単位・閾値を先に固定する。成長の各時点では応答だけを評価し、都合のよい試験範囲へ選び直さない。新しい `ibadepiction` は、前段で指示先を定めた同じ覆いにこの条件を使う。開始と終了だけが条件を満たし、途中で変形が上限を超える例は、全区間での抵抗を持つ描写としては成立しない。

現代語の *hart* には抵抗性や容易には変形しない用法がある。一方、工学的な押込み測定では荷重と深さから表面・機械的性質を調べる。今回の閾値判定を、押込み硬さ・弾性率・強度・靱性の定義とはしない。現代の測定技術をカントの歴史的な意図へ帰属させることもない。[Duden](https://www.duden.de/rechtschreibung/hart)、[NIST](https://www.nist.gov/news-events/news/2013/07/new-nist-nanoscale-indenter-takes-novel-approach-measuring-surface)

試験法には荷重の方向と与え方、物体の支持、基準形状、応答時点、温度などを含める。評価済み条件は二つの単位と読みの適合を含み、変形は剛体移動と区別する。ただし測定・校正の物理的基礎、形状や支持と材料固有の性質の分離、原文に適切な方法と閾値は未完である。固定した試験外の力や時間への耐性も主張しない。

実際の成長・世話の描写を評価し、旧来の抵抗の真偽入力が偽でも新しい説明は独立に判定されることを検査する。引用された描写への帰属は、描写の成立や測定の実行と別に保つ。以前の因果・利益判断モデル全体は再評価していない。本文点検v6で接続を更新するが、八引数の部分ひな形と意味確認の未達は残し、原文範囲の集計は増やさない。
