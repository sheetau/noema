# 同じ点の運動をKで求めるための接続

原刊905頁のu0133–u0134は、直前と同じ点のKに対する運動を求め、§3の変換を元の運動方程式へ適用して三式を得る二文と表示式である。今回の構成は、その問いと代入前後の内容に必要な依存関係を扱う。著者が課題と代入を提示する発話、§3への参照の提示、全単位の通読判断は次の接続で行う。

両系の記録は同じ点の一つの出来事を共有する。各記録はその系の現在の場所・物差し・局所時計と全期間の実際の位置に結び、両系の出来事の全範囲を一致させる。全記録対を既出の§3の座標範囲と対応へ接続するので、変換式に合う対だけを取り出すことはない。両系の時刻値は異なってよい。

問いの答えの候補は、各軸とK時刻から点の位置を返す関数である。同じ点の全期間の実際の三座標と一致することを要求する。問いの候補条件には結果の三式、等速性、原点を通る条件を埋め込まず、先行の設定は問いの文脈として共有する。

元の平面三式と係数1の四座標変換を、同じ記録対に適用する。結果はx=(wξ+v)/(1+vwξ/V²)t、y=√(1−(v/V)²)/(1+vwξ/V²)wηt、z=0であり、正の平方根とβの逆数の一致を保つ。内部では既存の分母を払った三等式を再利用する。

商の定義域として1+vwξ/V²≠0を明示する。この条件は原文に印字された追加仮定ではなく、tの関数としてこの表示を読む範囲である。負の分母や符号付き成分は許し、点の光速上限を追加しない。零分母では元の変換と平面式に合う記録もあり得るが、この商で表示する結果には含めない。

検査では数値三式と代入、存在証人の同一性、全候補の対応、候補関数の三軸・全時刻条件を分ける。実際の全実数量化は有限評価を拒否する。有限対照例、原文の意味判断、物理的真理の証明を区別し、今回は確認済みの原文単位数を増やさない。
