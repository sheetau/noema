# 提示者を補わない著者表示

原刊494頁の署名は、その文書の著者を名称で示す。誰が印刷・掲出したかは書かれていない。[旧版](author-signature-v1.md)の本文hzilは著者wa自身を提示者にも置いていたため、原文にない条件を加えていた。今回、その条件を外す。

新しいrqqxは、同じ文脈で名称使用が成立すること、その使用が同じ名称を同じ対象へ適用すること、その使用が同じ文書の著者として同じ対象を表示することを結ぶ。hzilは名称hzifと人物waの相違を保ち、この三関係へ接続する。表示者を指定する既存rqqwは残す。名称・人物・文書・使用・文脈の参照は旧版と同じで、17文の構文も維持する。新規の原始記号はない。

原刊は[バイエルン州立図書館の公開画像](https://www.digitale-sammlungen.de/de/view/bsb10926843?page=534)で確認した。右寄せの略記と姓、句点はあるが、電子版の[mmanuel]は印刷されていない。頭文字のFraktur字形だけから現代のI/Jを一意に区別したとは扱わず、固定した電子転記に従う読みを「I. Kant.」と記録する。画像・IIIF目録・読みの判断は[照合記録](../data/author-signature-facsimile-v1.json)で分ける。名称の表記は識別用の別添えであり、綴りから人物や著者関係を推定しない。

三関係の全8組合せ、二文書の各7対照例、本文の8例、名称を人物自身とする反例、未知の適用・著者表示の拒否を検査する。提示者関係を評価すると例外になる解釈でも新版が成立し、著者本人による提示がないと旧版だけが不成立になることを確認する。通常・短縮・固有文字の往復とCLI解析も対象とする。

これらは型・参照・有限解釈の検査である。原文単位全体の意味判断は別に行い、この検査報告から完成件数を自動生成しない。12文字の参照文だけを原文と比較して圧縮率を主張せず、共有宣言・表記添付の費用を区別する。

python -X utf8 -m scripts.check_author_credit --verify-only
