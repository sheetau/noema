# 学習済みモデルの依存関係・照応を使った参照統合

固定したKWJAの出力を使い、出来事ごとの項を同じ事物へ結び付ける研究用APIを追加した。追加学習と語別の補正は行っていない。正解範囲を与えた場合の参照分割は10/12文、モデルが範囲も抽出した場合は8/12文が一致した。参照だけでも誤りが残り、全文の意味構造一致95%を満たす結果ではない。

## 実装と評価

[予測前に固定した方針](reference-head-v1-protocol.md)と[評価資料](../data/reference-head-v1.json)に従った。基本句主辞の依存先はモデルのtop-1を採用し、右隣への補完や依存木の修復は行わない。項の内部から外へ依存する主辞が一つなら、その原文位置を項の主辞とする。同じ位置の主辞を持つ項、またはモデルの文書内照応`=`で結ばれた主辞を統合する。循環や複数主辞は未確定にする。

`ReferenceFrameAnalyzer.analyze(text)`は、原文解析・出来事の採否・範囲と役割を保持したまま、依存先、項の主辞、参照グループ、統合の根拠を返す。推論時には評価資料を読まず、文字列の一致や代名詞表で参照先を決めない。別の出来事で使われる同一範囲は一つの観測にまとめるが、「花」と「庭師が育てた花」は別の範囲として残し、共通の参照IDへ結ぶ。

12文中、父の例は以前の学習資料、上着と住民の2例は以前の確認資料と同文である。残る9文が今回新たに解析した原文である。再利用した3文はいずれも一致した。新規9文だけでは正解範囲で7/9、予測範囲で5/9文の一致であり、12文全部を未知文への汎化とは扱わない。

| 測定 | 正解範囲を与える診断 | 予測範囲による評価 |
|---|---:|---:|
| 項範囲の一致 | 47/47（入力条件） | 45/47 |
| 欠落／余分な項範囲 | 0 / 0 | 2 / 3 |
| 正しい同一参照ペア／正解ペア | 13/14 | 12/14 |
| 余分な同一参照ペア | 1 | 4 |
| ペア適合率 | 92.9% | 75.0% |
| ペア再現率 | 92.9% | 85.7% |
| 項集合と参照分割が完全一致した文 | 10/12 | 8/12 |

今回、主辞が未確定になった項は0件だった。ただし正しく主辞が決まっても、モデルが誤った照応先を返せば誤統合する。参照分割の評価には役割ラベル、概念選択、否定・数量・時制の正しさを含めていない。

## 保持した失敗

- 修飾節の内外4文は、予測範囲でも全て一致した。ここには前述の再利用3文が含まれる。
- 文をまたぐ照応5文では、正解範囲で4/5、予測範囲で2/5文が一致した。「その本」を「本」に縮める範囲抽出の誤りと、「その人」に加えて余分な「人」を役割に結ぶ誤りがあった。参照先が合っていても範囲の誤りを正解へ修正していない。
- 「スープ」と「その料理」の照応を取り逃した。元の照応は「料理人」の内部の「料理」へ向いており、この誤った根拠も保存した。予測範囲は「その料理」の「その」も欠落させた。
- 別物を統合してはいけない3文のうち、「赤い本」と「青い本」を同じ本として誤統合した。「別の猫」と家族関係の2例は分離できた。色の語を見て強制分離する個別ルールは追加していない。

次の改善には、範囲・修飾情報を含めた参照の判定と、原文の範囲抽出そのものの改善が必要である。既存モデルの照応出力を無条件に最終意味へ採用することはできない。今回の12文を使った補正で成功率を上げるのではなく、今回の失敗を保持し、別の資料で改善を確認する。

## 再現と検証

```powershell
artifacts/kwja-venv/Scripts/python.exe -m scripts.probe_reference_heads --output reports/reference-head-v1-rerun
artifacts/kwja-venv/Scripts/python.exe -m scripts.verify_reference_heads
python -m pytest -q
```

プローブは存在しない保存先にだけ書く。検証コマンドは既定の保存先を検査し、検証記録も上書きしない。

- [原文と全根拠](../reports/reference-head-v1/evidence.json)、[評価](../reports/reference-head-v1/evaluation.json)、[モデル・コード・出力のハッシュ](../reports/reference-head-v1/run.json)、[再評価の検証](../reports/reference-head-v1/verification.json)を保存した。
- 12文全てを原文から反復解析し、出力の完全一致を確認した。参照処理のないv6でも同じ原文を解析し、元解析・出来事の採否・範囲・役割が変わらないことを確認した。
- 保存した依存予測から参照グループと全評価を再計算し、一致した。生成・辞書の禁止経路5種はいずれも呼出し0回だった。
- 循環・自己参照・不明な親・複数主辞、未確定同士の誤統合防止、照応の推移性、外界参照の除外、範囲の欠落と余分な参照の計数、例外時のhook除去を含め、全271テストが通過した。

本番の翻訳画面には未接続である。概念・否定・時間・数量を含む全文の意味構造、英語での同等の検証、辞書に依存しない逆変換、文字数の膨張は引き続き未解決として保持する。
