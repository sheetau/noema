# 移動系の場を力への応答で定義する

u0161–u0162を、相対性原理による条件付きの要求、その言い換え、移動系の二つの場の物理的定義、六つの式まで続く一文として扱う。必要なのは同じK/k、同じ法則と候補履歴、原理の適用条件、空の領域、場の三成分、同じ地点・時刻と単位、電気側と磁気側の試験量への力、条件文と表示式の説明関係である。

elektrische Massenは符号付き電荷、magnetische Massenは符号付き磁極強度を担う試験系という読みを採る。慣性質量への加速度の係数とはしない。磁極強度の正負と力による尺度の歴史的な用法は、[Maxwell, Treatise, Part III, Chapter I, §§374–377](https://en.wikisource.org/wiki/A_Treatise_on_Electricity_and_Magnetism/Part_III/Chapter_I)を参照した。この参照は採用する語義を支えるもので、Einsteinの文の全てをMaxwellの法則へ置換するものではない。

ponderomotorische Wirkungは、運動量変化への寄与またはそれを釣り合わせる機械的な作用として同定する力と読む。試験系を当該座標系に瞬間的に静止させ、試験量と大きさを零へ近づけて元の場への影響を除く規約を使う。力の応答関数はその一次応答を符号付き試験量で表示した理想化であり、大きな実物の試験体への力が常に線形だとは述べない。磁気側は一方の試験磁極の局所寄与であり、磁石全体への合力や実在する孤立磁荷の発見ではない。

一般の応答関数と単位積の規約を基本入力とし、同じ四座標での場の値と三力成分の比例を既存の実数演算から構成する。全有効点と全有効な符号付き試験量で要求し、零だけ・正だけ・一成分だけの一致を排除する。試験応答の規約は仮定上の定義なので、真空の領域へ試験物体が実在するという存在量化を加えない。単位と正の係数は両側で明示し、数値を1や現代SIの定数へ固定しない。

第一原理の現在の定式化eionと同じ全法則・全候補・全対応記述の範囲を用いる。一つの同じ理論の下で原理とこの法則・候補の所属を結び、K/kの対応記述における法則適合を旧・新の方程式内容へ接続する。原理の適用条件を原文に列挙された追加の実験事実とはせず、原理をこの具体的な法則へ適用する読みの明示とする。

表示された六式は新しい二場znr/znsと領域zntのs5yであり、前文で計算した混合関数s6k/s6lとは同一視しない。仮定ejs6が成立する場合に新しい内容が成立する条件文を保持し、両側が無条件に真とはしない。著者が原理からこの条件文を要求する提示と、処理系による物理理論の証明を区別する。
