# 剛な球の設定、球面式、静止時の形状の脚注

原刊903頁のu0110–u0111と著者脚注u0281を同じ物体・半径・二系へ接続する。今回の一つの球は、内部と境界を占める理想的な閉球連続体として読む。密度や質量は指定しない。この選択は原文の球形という語から内部充填が必然的に従うという主張ではなく、明示したモデルの下での記述である。

設定ejffは前段のejfcにより、全物質点の剛性、kでの静止、測定されたk原点にある中心、Kでの同じ速度vによる並進を保持する。Wir betrachtenはこの設定を考察の前提として採る提示であり、実物の製作や測定実験の報告ではない。

ejfdは独立に構成した占有領域の境界と、同じ現在記録のξ²+η²+ζ²=R²を双方向に結ぶ。対象区間の全ての適格記録を範囲とし、球面式に合う正例だけを先に選ばない。設定側の全位置被覆と全物質点の記録存在を保持し、表面の有限点だけで全形状を代用しない。式を提示する著者への帰属と、式の物理的真理は区別する。

脚注のDas heißtは同じ球の言い方への説明である。ejfeは同じ静止系で中心がどこかに存在する球形を述べ、一般の形状分類に原点という条件を埋め込まない。ruhend untersuchtは形状を調べる静止側の基準を示す。過去の測定の実施や、動く側Kでも球形であることは補わない。

原刊の注1)はKugel直後に付き、903頁下部の注本文に対応する。固定インベントリの参照番号3と末尾の収録位置は、原刊の注番号・掲載頁と分けて記録する。設定、式の提示、脚注の説明は三つのメッセージとして同じ著者・論説へ帰属する。後続のK座標への変換とt=0の断面はまだ加えない。
