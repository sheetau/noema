# 構造間の余白と八方向の半径線・試作07

試作06の形を基に、更新された `concept/alphabet-concept.md` の近接と形の選択肢に関する追記を反映した。通常文六例、カントの既存構文三例、アインシュタイン二式を `output/alphabet-circle-v7/overview.png` の一枚にまとめる。縮尺0.48、薄い三罫線、元の構文と読みは維持する。

## 近くを通る別の構造

円周から曲がり・分岐までの直進距離は罫線間隔の1/2のまま。これに、**無関係な構造同士の最小間隔を罫線間隔の1/3**とする条件を加えた。基本座標では約10.67、一覧では5.12ピクセル。

- 線と別の円は、線から円周までの距離を測る。接触していなくても、近すぎれば経路を選び直す。
- 離れている円同士、接続していない線分同士にも最小間隔を適用する。小円の近接した二つの出入口も線分同士の距離として検出する。
- 二線分の途中同士の交差は拒否する。実際の共通端・分岐は接続として扱う。45度以上の開きでは、分岐から既定の直進距離を進んだところで必要な間隔が得られる。
- 意図した円の内包・交差・接触には、従来の円同士の規則を適用する。一つの複合形の相手円へ接する外向きの線が両円の中心軸上にある場合は、その複合形の一部として扱う。別の方向からかすめる線はこの例外に含めない。

接続経路を選ぶ時点で既存の円と線を考慮し、曲がる位置・接続する罫線・間隔を調整する。直角入射だけを満たした線を先に描いて、近接を後から見逃す方式にはしない。生成SVGから実際の円・線の座標を読み直し、直角入射・直径禁止と最小間隔を検査する。

## 半径線の向き

試作06では、中円の半径線が左・左下に、大円が右に固定されていた。この実装上の制限を撤去し、中円・大円とも45度刻みの八方向を候補にした。大円の斜線は既定の条件に従い、円の上端または下端の高さまで伸びる自由端とする。

優先方向は構文上の役割から決める。論理積は右、否定は左、全称は上、存在は下、条件は右上、内容は左上、引用は左下を優先する。引数の位置にも固定した優先順を設ける。周囲の円や線に干渉すれば、優先方向から近い順にほかの方向を試す。これは同じ内容に対する文脈依存の異形であり、向きだけに演算子の全意味を担わせるものではない。乱数・識別子の綴りのハッシュ・例文専用の座標は使わない。

八方向は独立した幾何検査だけでなく、今回の一覧でもすべて出現する。同じ入力・参照登録から同じ形になることと、識別子を改名しても変わらず引数交換では変わることを確認する。

## ほかの選択肢の点検

| 構造 | 試作07の扱い |
| --- | --- |
| 中円・大円の半径線 | 八方向を生成可能。小円の中心線は禁止を維持 |
| 大円と中円の同心円 | 八方向の片側線を生成可能 |
| 中円と小円、大円と小円、大円と中円の円周・中心の重なり | 左右両方を生成可能。相手円をかすめる向きは周囲の条件から除外 |
| 一回だけの直角曲がり | 経路候補へ追加。連続する直角曲がりは禁止 |
| 中円・小円の上下接触、中円同士の45度接触 | 幾何検査と配置候補で扱う。演算子と原子的な引数を結ぶ場合に限り、一式につき最大一箇所の候補とする |
| 小円を内包する同心円 | 小円の中心禁止と、内側の線を中心から片側へ出す規則に反する接続になるため、現在の連続書記では採用しない |
| 不可視接続 | 中心間の水平・垂直・45度の直線を検査可能。一覧の引用境界では水平を使い、空白の数にも上限を設ける |

許される図形の全配置を網羅する最終仕様ではない。今回は固定されていた半径線・曲がり・左右配置を広げ、許容形が生成可能かを検査に加えた。既存の論理積の共有、文全体の上下の重さ、罫線を飛び越える接続の抑制は維持する。
