# 運動エネルギー式の物質点への適用

原刊920頁のu0264は、先に述べた議論により、運動エネルギーの表現もponderableな質量に適用されなければならない、と述べる。この「先の議論」を、u0260で同じ物質点へ任意に小さい電荷を加えられるとした内容へ結び、著者による理由づけとして記述した。「muß」は推論の必然性を提示する表現と読み、行為者への命令にはしない。

適用先の物質点は前段と同じ範囲を使う。各物質点の全てのエネルギー適用事例について、低速質量、速さ、光速度、運動エネルギー、基準系、単位を同じ対象・出来事・文脈へ結ぶ。運動エネルギーの帰属には既存の関係を再利用する。エネルギーの適用事例は、力の係数を検査する事例とは別に指定する。

単位の変更を扱うため、エネルギー値とエネルギー尺度の積を、質量値と質量尺度、共通の速度尺度で換算した光速度の二乗、beta−1の積に等しいとする。質量・速度・エネルギーの各単位を変えても、同じ物理量を表す換算なら式は維持される。整合する単位系では、元のW=μV²(beta−1)へ戻ることも有理数の一般命題で検査した。

検査では二つの物質点、同じ物質点の別の出来事、静止した場合を含めた。一つ目の事例が正しくても、二つ目のエネルギー値が誤っていれば範囲全体の条件は成立しない。別の物体・基準系・出来事・単位・文脈のエネルギーへの置換、光速度の値の取り違え、校正の欠落も区別する。範囲が空であることから物質点や適用事例の存在は推定しない。

先行189文を保存し、適用拡張の主張と、電荷追加の議論を理由とする帰属を加えた。後者は、電荷追加の可能性からエネルギー式を証明する推論規則ではない。電荷を零へ近づける物理的な議論、量の測定・校正・帰属の基礎説明、物質点の範囲の完全性、原文全体の意味一致は残る。原刊の中間速度積分に質量係数がない点も、今回の最右辺の表現の適用とは分けて保持する。
