# 行為の記述を基準に照らす判断

カントu0015の「自分にふさわしくないこととは考えない」という評価へ、明示した基準に不足しないと本人が判断する構造を追加した。評価する対象には、前段の「自分はこれを義務だと考えている、と述べる」行為の記述を渡す。実際の発言を前提にせず、その行為をすることの評価を組み立てる。

| 定義 | 内容 |
| --- | --- |
| `rne` | 同じ本人と行為記述について、明示した基準列の少なくとも一つが不成立である |
| `rnf` | 基準列が非空であり、その全てについて不足がない |
| `rng` | 行為記述と基準列を固定し、ちょうど一人の順序付き引数列へ`rnf`を接続する |

基準は「本人・行為記述から命題内容を返す関数」の列で渡す。個々の基準をNoemaで定義でき、品位という単語に固定した真偽表を言語へ追加する方式ではない。基準を定めずに適合と認めることは避け、空列では不足ありにも適合にもならない。基準が未知の場合は実行時の判定を拒否する。二値の意味体系に新しい未知値を追加したわけではない。

`rng`の閉じた記述を既存の`rna`へ渡すと、本人が同じ本人の行為を基準に反しないと判断する内容になる。判断で採用した非空の候補状況全てで適合を求める。現実には不適合でもこの判断を持ち得るし、現実に適合していても本人がそう判断しているとは限らない。否定的な判断が見つからないだけでは、肯定的な判断の存在を認定しない。

行為記述の内部には、本人の義務判断を述べるメッセージが入る。外側の基準適合の判断、その行為の実行、内側の義務判断、実際の義務、政策の成立を別々に保つ。行為が起きていなくても記述を評価でき、行為記述を引用しただけで中身を実行しない。任意の基準関数が内部で実行の有無を参照しないことまでは型で保証しない。

基準の順序や重複は不足判定を変えない。同じ真理値を返す別名の行為記述を、自動的に同じ記述へまとめることもしない。判断がどの記述・本人・基準列について行われたかは保持する。空の引数列や複数人の列を一人用の評価へ流用しない。

この構成は、原文の品位についての評価の部分的な候補である。どの基準が人や役職にふさわしいか、文化的・制度的・道徳的な根拠、基準の網羅性はまだ説明し終えていない。「品位」を任意の条件充足へ完全に還元できるという主張ではない。否定表現による婉曲や程度、寛容という名称の拒否、称賛、政府による解放と後続の論述も残る。

[一般文書](../examples/v014/action-standards.noema)は4,645文字、[原文付き草案](../examples/v014/kant-action-standards.noema)は187,291文字、[抽出文書](../examples/v014/action-standards-core.noema)は5,863文字である。三定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-action-standards-basis-v1.json)と[検査記録](../reports/action-standards-v1.json)を保存する。

実際の基準適合・判断内の適合・発言・内側の義務判断・義務・政策の64通りを検査した。原文付き文書と抽出文書では、対象人物・内容対応・候補状況・行為記述など八条件ずつを検査した。追加15テストで空の基準、未知の基準、実行の非仮定、引数の長さ、別人、順序・重複、Noemaだけで定義した基準と別名記述を確認した。三文書のCLI解析、固有文字v2の往復、抽出文書のSVGのXML検査も通過した。SVGの目視確認は含めない。
