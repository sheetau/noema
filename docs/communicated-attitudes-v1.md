# 伝達を受けて態度を取得すること

伝わった内容を理解することと、その内容を受けた人の態度が変わることを分けて結んだ。カント第四段落の態度の普及を記述するため、既存の伝達経路の最後の行為に、受け手の新しい態度の取得を接続する。五定義を追加し、新しい基本記号は使わない。

## 態度の対象と、態度そのもの

`hzni`は、指定した性質に該当する自分の状態を好ましく受け入れるという、既存`id`の態度を作る。引数は性質のNoema記述であり、日本語やドイツ語の文字列ではない。

例えば`bb`は、本人が他人の指導に頼らず自分の理解力を使う状態を既に記述している。`k hzni[r[p bb]]`は、その状態に対する本人の好ましい受容を表す関数になる。`reader`と`now`を人と時点の参照として本文で指定すれば、次の形でその態度を問える。

```text
q[t[c[k hzni[r[p bb]]][k reader[]]][k now[]]].
```

この問いは、本人が実際に自立的な思考をしているかを問うものではない。対象の状態が未実現でも態度は成立し得る。思考能力、義務、将来の実行も追加しない。この受容だけで、自己価値の理性的な評価や自己思考の使命の意味を尽くしたとは扱わない。

## 同じ態度が変化し、同じ態度が生じる

一般定義`rqte`は、性質の記述から評価する関数を取り出し、その同じ記述を原因の目標へ渡す。別々に与えた関数と記述の一致を呼出側の約束だけに委ねない。既存の`th`で不成立から成立への変化を検査し、同じ対象者が同じ過程の変化を受けたことを要求する。過程とその活動部分が生起し、その同じ部分が対象者に記述された性質を生じさせなければならない。

`hznj`では、対象の性質の記述から`hzni`の態度記述を内部で合成し、`rqte`へ渡す。異なる二人の同じ提示行為について、提示・受領・理解を既存の関係で確認し、その行為を態度取得の過程の部分とする。別の人の取得、別の態度の原因、同時に起きただけの無関係な行為は足りない。

ここでいう因果は、既存`g3`の結果生成という意味規約に従う。伝達行為と態度変化が偶然重なるだけでは成立しない一方、心理的な説得機構や、発話内容だけが十分原因であることは要求しない。受領と取得完了は同じ粗い終点で記録する。受領後の細かな遅延はまだ分解していない。

## 中継経路と集団への広がり

`hznk`は既存`h6i`の有限経路を使う。経路の最後の段階は、先頭と後続列からNoemaの列集計で取り出す。その段階の送信者と行為を`hznj`へ渡すため、最初の発信者の別活動を最後の受け手の取得原因へすり替えない。途中の人は賛同していなくても再伝達でき、発信者の誠実さもこの条件からは導かない。

`hznl`は、同じ宛先・参照文脈の想定読者を固定し、その中で伝達と取得が成立した人の範囲を`rqsw`で作る。一人以上・複数人・全員という広がりは選択する条件であり、原文へ一律の人数を補わない。中継者が想定読者の外にいてもよい。各人の取得過程と終点は違ってよく、全員の同時変化を要求しない。

これは新しい取得の構成である。以前から持っていた態度の強化や維持とは区別する。取得後に失われたとしても、過去の取得という事実は消さない。取得時から基準時までの持続が必要な文では、既存の持続条件を別に加える。

## 検証と限界

一般形の前後状態・過程・対象・生起・部分・原因について256組合せを検査する。伝達の23対照では、欠けた受領・理解・因果、別の態度や対象者への原因、最初の段階や経路外の行為の原因、独立した同内容の発信、切れた経路、履歴外の変化、逆転した前後などを区別する。直接伝達と一人を介する中継を確認し、通常評価とメモ化した評価も肯定・否定の二例で照合する。

具体的な`bb`への態度を使う検査では、状態評価と原因へ同じ合成記述が渡ることを確認する。対象の実際の思考や、伝達した命題の真理を評価しようとすると失敗するモデルを使う。集団の18対照は、固定した読者の範囲、範囲外の中継者、個別の取得時点、一人・複数人・全員、空や非人間を含む範囲を検査する。十の未知入力は通常の偽へ置き換えない。

記述から関数を取り出す箇所は既存の引用層の制限に従う。この構成全体を引用して評価する検査では層1を使い、内部の層0の態度記述を評価する。層0で全体を引用すると、参照先の評価まで調べる既存の構文検査で拒否する。引用自体を、その内容が実現したという主張には変えない。

追加した6テストが通過した。通常表記・短縮表記・固有文字の往復、既存32文と意味規約、七単位の意味確認との結び付きを検証記録でも確認する。一般形は1,025文字、累積本文への追加は1,563文字。自己価値・自己思考の使命を具体的に結ぶこと、原文に適した態度の読み、周囲の範囲、将来の様相、公衆全体の自己啓蒙は残る。新たな原文範囲や意味確認済み単位には加算しない。
