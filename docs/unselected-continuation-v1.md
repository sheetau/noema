# 選び直さずに続くことと、反対の決定

内的な構成が未成熟に寄与するだけでは、その都度考えて選ぶ活動と、選び直さずに続く性向を区別できなかった。今回は、当該局面で新たに採る実践的な決定を記述し、その決定をやり直さない比較でも内的な寄与が成立するという軸を加えた。

カントは後年の『人間学』で、習慣による考えなしの反復を論じる一方、意図的に採用する習慣も認めている。したがって、習慣を持つ人が現在も反対の意思を持つことや、以前に意識して方針を決めたことがないことを、一律には要求しない。この参照は1784年の句の唯一の読解を証明するものではない。[Kant, AA VII149](https://korpora.org/Kant/aa07/149.html)

## 決定・一例・傾向を分ける

| 定義 | 内容 |
| --- | --- |
| `r2cw` | 同じ本人の同じ判断が、同じ対象・記述・極性について新たに採る実践的決定である |
| `r2cx` | 内的寄与が実際にあり、作動させる・やめるという両方の新たな決定が当該局面にない |
| `r2cy` | やめると決め、反対の決定はないが、それでも同じ内的寄与が実際にある |
| `r2cz` | 外的更新も新たな決定もない非空の比較範囲で、内的寄与の程度を評価する |
| `r2da` | その比較を、経験による形成、現在の寄与、実際の程度増加と近接状態の保持へ接続する |

追加した一般入力は、実践的決定の内容と、その決定を比較できる局面の二つである。判断の主体には既存の`fa`を使う。既存の`hznn`は、ある状態が事実だと認める判断であり、その状態を実現する方針を採る決定とは分ける。表現の適用を吟味せずに使う既存の`rbr`も、実践的決定そのものの代用にはしない。

同じ本人・同じ判断の結合が必要である。本人がした別の判断と、他人の実践的決定を組み合わせてはならない。性質の記述、対象、極性、局面も同じ組として保持する。判断の記録が見つからないだけで、その不存在を与えることも認めない。

新たな決定がないとは、その局面の選択肢を検討して方針を定め直していないという意味である。以前からの目的や方針、意識、能力、適切さを否定しない。対象は本人に適した捉え方で指定する必要があり、内的機構の詳細を本人が理解しているという前提は置かない。

## 比較と限界

比較では、外的な維持の更新を調べる既存の範囲と、実践的決定を調べる範囲の共通部分を使う。以前からの方針など関連背景を保ちつつ、新たな決定の有無を比較する。結果の作動を保存条件にしたり、都合のよい結果だけから候補を選んだりはしない。

そこから外的更新と両極性の新たな決定がない局面を選び、残った範囲が非空であることを要求する。現在は意識して選んでいても、別の適切な比較局面で選び直さずに働く傾向はあり得る。反対に、意識して選んだ局面だけで働くものは、以前の内的寄与の条件を満たしても、新しい条件を満たさない。

二つの比較へ同じ尺度値を使う読みを採り、両方で最小値・最大値との整合を検査する。中間値を事例の件数から算出しない。元の測定の一意性も比較による絞り込みの前に検査し、不整合な値だけを除いて多値を隠さない。比較期間と背景、中間値や近接域の校正の妥当性は、文脈に応じた判断が残る。

やめると決めても作動した一例`r2cy`は、停止する能力の欠如ではない。実際に停止を試みたか、適切な手段を利用できたか、その手段の結果はどうかを別に調べる必要がある。この区別により、自動的な側面を示すことと、本人には止められないと断言することを分ける。

検証は、主体・両極性の決定・事実判断の16組合せ、作動と両極性の8組合せ、決定がある局面の八部分集合を含む。原文側では、以前の内的寄与の式と新しい式を同じモデルで比較し、現在の選択、現在の反対決定、選んだときだけ働く場合、空の比較、別対象、評価欠落・多値、変化過程の欠落を確認する。内的寄与と未成熟の能力定義は通常の評価器で実行する。

対象段落には、本性となった未成熟のほか、定式、自由な運動、自己の働きかけがある。これらを含む全体の意味確認はまだ終えていない。[Kant, AA VIII036](https://korpora.org/Kant/aa08/036.html)
