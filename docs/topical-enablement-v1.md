# 主題を固定した能力と、その能力を可能にする支援

カントu0014の第二文に、現在の自立的判断能力と、その能力を持てる状態に置く可能性を分けた部分草案を追加した。本人・主題・対象となる事柄を固定し、支援の結果で別の人や容易な事柄へ置き換えない。

| 定義 | 内容 |
| --- | --- |
| `rlk` | 指定された事柄について、自分の理解力を使い、理由に支えられ、他者の指導なしで判断する内容 |
| `rll` | 非空の対象範囲について、利用可能な各方法の評価対象が非空で想定結果に含まれること |
| `rlm` | 同じ本人が、対象範囲の各事柄について目標を達成する方法を持つこと |
| `rln` | 指定した実施者の利用可能な各支援方法に、非空の想定結果があること |
| `rlo` | 同じ実施者に、同じ本人を全対象について能力のある状態へ置く方法と成功結果があること |
| `rlp` | 完全に列挙された同じ母集団について、現在能力と支援可能性の該当人数が指定した上限未満であること |
| `hzeq`–`hzeu` | これらを既存の人・理解力・判断・理由・指導の規約と、固定した主題の範囲へ接続する |

今はできなくても、支援後にはできる場合を表せる。現在できることだけでは、指定した実施者に支援方法があるとは限らない。何もしない方法や、能力が将来まで保持される条件は自動で加えない。支援後に本人が指導なしで判断できることと、その状態へ至るために他者の支援を受けることは両立する。

事柄ごとに別の方法を使ってよい。一方、支援の成功を判定するときは、一つの結果状態で全対象について能力を持つ必要がある。ある結果では第一の事柄だけ、別の結果では第二の事柄だけ判断できても、全対象について能力を得る可能性とはしない。成功する結果が一つあるという可能性であり、全結果での成功保証ではない。

方法がない場合と、方法はあるが結果の評価が欠ける場合を分ける。後者を能力なしの人数へ加算しない。母集団は非空で重複がなく、対象範囲を完全に列挙する必要がある。人数上限も母集団の大きさ以下とし、全員に能力があるのに上限を大きくして不足とする読みを防ぐ。

原文の受動表現は実施者を名指ししていない。この草案では実施者を明示した引数として固定するため、誰の支援まで考慮するかは未確定である。指定した一人に方法がないことから、あらゆる支援が不可能とは結論しない。また人数の上限は読みを試すための文脈的な基準であり、カントが数値を指定したものではない。

宗教的な主題の具体的内容は入力された範囲に依存する。「確実に、よく」という質も、理由に支えられた判断と指定結果での成功だけで確定したとは扱わない。習熟、確信、外乱への頑健性、能力の程度と分布、現実の全人類や全方法への一般化は残る。段落冒頭の時代についての問答、進行中の啓蒙、障害の減少と徴候、フリードリヒへの言及、著者帰属も未接続である。
