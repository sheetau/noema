# 語境界を保つ句の抽出の比較条件

前回の句抽出では、サブワード列が正しいBIOでも、語の先頭だけを選ぶと開始ラベルが消える場合があった。これを、語彙・言語・役割ごとの補正なしで解消する。

## 推定する系列

固定モデル、述語検出、分かち書きは前回と同じにする。各サブワードの分類確率を得て、すべての語に対するBIO系列を推定する。語のラベルから内部のサブワード列を次のように一意に展開する。

- `O` はすべて `O`。
- `B-X` は先頭が `B-X`、残りが `I-X`。
- `I-X` はすべて `I-X`。

語の間でもBIOの開始・継続の制約を満たす。文頭・文末の特殊トークンは `O` とする。各語の候補の得点は、その展開列に対するサブワードの確率値の和であり、文全体の和が最大になる系列をViterbi法で選ぶ。対数確率、語長による平均、語別の例外は用いない。既存の不正な出力を後処理で修復するのではなく、モデルの全候補から構造制約を満たす系列を選ぶ。

ラベル一覧に対応する `I-X` がない `B-X` は、1サブワードの語でだけ選べる。欠けた分類ラベルを追加・推測しない。この在庫上の条件は初回起動で不整合を検出した後、比較予測を得る前に明記した。

この制約は分かち書きが適切なことを前提にする。語の内部に意味範囲の境界が必要なら、その出力は表現できなくなる。BIOが整合していることは意味の正しさを保証しない。

## 予測前に固定する資料と比較

既存の[16組](../data/srl-span-v1.json)は回帰資料とし、前回の結果を既知のものとして扱う。さらに[新しい8組](../data/srl-boundary-v1.json)を予測前に保存する。固有名・修飾句・受動態・授与・従属節・複数文・主語省略を含める。新資料も少量の人工文であり、広い自然文への対応を証明するものではない。

同じモデルの同じ分類確率に、公開実装に合わせた従来のデコードと、語境界制約付きのデコードを適用する。正解の述語位置や句の範囲は推論に渡さない。述語を余分に予測した場合も除外しない。

日英別・資料別に、指定した役割と文字範囲の完全一致、不正な語単位BIO列の数、従来から改善・後退した指定範囲の数を集計する。句の完全一致が減った場合もそのまま報告し、成績に合わせた方式選択や注釈変更は行わない。全予測と実行条件を保存し、小さい系列の全列挙との一致と反復一致を検査する。

この比較は範囲分類の検査であり、語義、否定の作用範囲、文間参照などを含む全文意味構造の95%以上という条件の代わりにはしない。主画面へは接続しない。
