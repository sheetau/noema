# 学識者として論じることと職務の両立

カント第五段落の固定原文 `[1743,2122)`、`So fern` から `angesetzt ist.` までを、条件・照応・様相・談話を保って本文へ接続する。対象は非空白323文字である。先行する職務内の議論の許可否定と服従要求はそのまま残す。

前件は、先行事務の機構に割り当てられた同じ人が、同じ基準で共同体全体と世界市民社会の成員として自分を捉え、学識者として本来の公衆へ書面で向ける活動を行う立場にあることである。自己理解の内容を真と認定せず、単に第三者について考えた対象が偶然本人だった場合とも分ける。世界市民社会は国家を越えて市民として位置付ける社会の構想と読み、現存する世界政府や法的国籍を補わない。

`So fern` の条件は、この活動内容の分類に当てはまる各組に適用する。`mithin` は広い社会の成員という捉え方を、書面で公衆へ向ける学識者の立場として説明し具体化するつながりと読む。自己認識だけで能力や資格が生じるという論理的な含意ではない。前件と後件をともに一つの条件内容として著者へ帰属し、前件の現実の成立を別に主張しない。

`kann` は、この立場で論じることと職務の遂行との実践的な両立可能性として読む。後件では、一つの利用可能な方法によって同じ活動を実行でき、そのために同じ事務が悪化しないことを要求する。前文の職務内の禁止を、個別の積極的な許可へ書き換えない。公的使用の自由についての規範的主張は先行回答にあり、ここではその人の異なる立場からの対照を明示する。

書面については、活動候補の構成 `r3z` と、実行した場合の書かれた作品・外部記録 `r3y` を分ける。以前の `r3s` は評価状況に作品と記録がある分類であり、そのまま基準状況の前件へ使うと刊行済みの作品を必要条件にしてしまう。今回は同じ作品を指す候補を分類し、同じ方法の実行側の全結果で記録を要求する。現実の刊行、全読者の受領や理解は含めない。

因果的な留保は、実行する側としない側で他の方程式と背景を固定し、同じ事務の遂行を同じ観点で比較する。事務が続いていても品質や進行が低下すれば非悪化を満たさない。全解の比較という頑健なモデル解釈を明示し、評価欠落や解なしを害の不在とはしない。これは確率的な通常性や、すべての世界で無期限に害がないという主張ではない。

`dieser Theil der Maschine` と末尾の `passives Glied` は、先行する同じ機構・固定成員・割当て職務への照応である。人を物理的な機械部品と同一視しない。`zugleich` は同じ人・基準での職務上の位置付けと広い社会への自己理解の併存、`zum Theile` は職務がその人のある側面であるという限定として読む。本人の全生活を従属させたり、勤務時間や割合の数値へ変えたりしない。

`ja sogar` は共同体への成員性から世界市民社会への成員性まで進める取り立てとして、`aber` は前文との役割別の対照として、`allerdings` は限定された両立可能性への承認として保持する。これらの提示を評価するときには、引用された条件内容や比較モデルを実行しない。
