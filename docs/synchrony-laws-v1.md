# 同期の対称性と三時計条件

u0016の74非空白本文文字とB・A・A・B、u0017の114本文文字とA・B・C・B・Cを対象とする。前単位で予告した二つの関係法則を、同じA/B時計と地点、新たに参照するC時計と地点へ接続する。

第一法則は、Bの時計がAの時計と同期するなら、Aの時計がBの時計と同期するという条件である。第二法則は、同じA時計がBともCとも同期する二つの前件から、BとCが互いに同期することを述べる。sowohl/als auchは二前件の連言であり、どちらか一方だけでは結論を要求しない。

第二の「互いに」は両方向を明示する。既存の三時計条件qqは全三時計へ量化されているため、B/Cの代入順を交換すれば逆方向も得られる。両方向の明示は一般法則を強めない。一般性は既存のqp/qqに保持し、代表名A/B/Cによる条件形だけへ法則の範囲を縮めない。

同期関係は、指定した場所への時計の対応を確認した上で既存qoを用いる。値の一回の偶然の一致や絶対時間への参照で代用しない。番号1・2、前のコロンからの列挙、同じ著者への帰属と順序を保持し、物理的な実証を補わない。後続の定義のまとめは残る。
