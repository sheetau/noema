# 制度の存続と全市民の書面批評

第六段落第七文の、全市民が学識者として現行制度への所見を公に書き、その間も同じ制度が続くという条件を構成する。全文 `[1437,2309)` の依存群であり、一定の短い期間や後続の到達条件、著者帰属はまだ接続しない。

`r5e5` は同じ宗教上の制度とその検討領域に、市民本人の所見を結ぶ。所見は既存 `r33a` の非空のまとまりであり、備えるべき条件の不充足を分析・説明・指摘する。作成する本人、学識者の立場、同じ書面と公衆を `r2zi` / `r3z` へ接続する。候補はまだ書かれていなくてもよく、指摘した欠点が現実に真であることを条件にしない。

将校の書面所見から使える構成を取り出すが、軍務の検討領域は持ち込まない。以前の文にあった「公衆の判断を目的とする」という条件も加えない。この文にはその目的句がなく、公に所見を示すことと、読者が判断することを目的にすることは別だからである。

`r5e7` はその市民の批評候補を非空とし、その全候補への自由を要求する。`r5fa` は同じ共同体のその点の全市民へ量化する。市民の範囲を批評した人や聖職者だけに狭めず、加入・離脱を各評価点で追う。市民の存在自体は普遍条件から付け加えない。
