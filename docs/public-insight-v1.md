# 公的な洞察の把握・根拠・確証

カント第六段落u0013第七文 `[1437,2309)` に向けて、制度の事柄を把握した認識、その判断と根拠の公開、同じ内容の検証を結ぶ。全文の意味判断ではなく、確認文字数は増やさない。

旧public-deliberationの `rkn` は、正しく支持された内容が論理的に厳密に増えることを要求していた。この条件だけでは、同じ結論を初めて理解することや、その根拠を新たに把握して確かめることを扱いきれない。今回は後に構成した `r5cl` の受容・把握・保持・十分な認識根拠・固定評価での真理を再利用する。既知の結論に対する新しい説明を理解する場合は、その説明関係を認識内容として明示できる。

`r5fq` は同じ宗教制度と検討領域に項目を結ぶ。`r5fr` は本人が保持する肯定判断の内容、そこで用いる十分な根拠、その同じ判断と根拠の公開を要求する。別の判断が公開されていたり、根拠の名前だけが掲示されていたりする場合では足りない。

`r5fs` はその同じ判断を確かめる検証が生起し、同じ内容を肯定する結論を持ち、そこで用いた証拠に支えられ、その証拠も公衆に検討可能であることを要求する。検証したという行為の分類だけでは確証にしない。元の理由と検証の証拠の同一性・相違は固定せず、検証者が必ず別人であることや特定の実験形式も追加しない。

`r5ft` が本人の認識とこの公開・検証を結び、`r5fu` はそれを満たす人の存在を表す。公的な洞察を、全市民が同じことを信じるという条件へ強めない。制度について理解する人がいても、その判断と根拠が私的なままなら、この公的な条件は満たされない。

`r5fv` は同じ履歴の前後について、この公的な認識が新たに成立する項目の存在を表す。既存の私的な認識が初めて公開され検証される場合も含み、同じ水準の担い手の交代や別名への変更だけは進展にしない。ただし一項目の進展だけで、共同提案に十分な程度へ達したとはしない。その到達基準と提案可能性を次に接続する。

検査は、保持判断と公開根拠の七条件128組、検証の六条件64組、同じ判断を共有する非空の証拠組を確認する。小さな模型では `r5cl` を含む全定義を実評価し、理解・受容・根拠・真理・公開・検証のいずれが欠けても失敗することを確認する。大きい量化の検査では境界を明示し、同じ公衆・項目・基準・真偽評価・候補を固定する。
