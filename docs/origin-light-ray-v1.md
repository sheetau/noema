# 同じ原点から正のξ方向へ進む光

u0065のτ=0で正のξ方向へ放出する光を、前段の原点規約と後続のξ=Vτを合わせて、同じk原点から出る光として読む。時刻条件だけに空間零点を混ぜず、ei46でその同じ出来事のk空間ラベルを零に合わせる。Kの補助三座標と両時刻の零は、現在の二座標組に結ぶei4kから引き継ぐ。

ei47はその系の現在の一区間測定ei44を保ち、放出が始出来事そのものであること、始時刻と空間原点の零、正の終時刻と縦位置、横二成分の零を要求する。全経路が指定縦軸に沿うことに加え、同じ系の全時間区間の三位置をeitf/seへ渡し、両端の光と出来事の出会いをsbへ結ぶ。一定の速度成分(V,0,0)は、先行する全区間光速度原理をこの直線伝播設定へ適用する運動学的な読みである。

ei5aはK/kの二記録ei45、同じ原点規約、その同じ始出来事、各系の全光軌道をまとめる。同じτの全対応と全k時計指示を保った上で、両端の現在座標へのτの適用snfと、同じφ(v)を使う全時間式smjも保持する。Kのt=4,x=20とkのτ=5,ξ=25は、V=5,v=3,a=2ならx′=8を介して同じ時間式に合う。両系の時刻や位置を同じ数値へ固定しない。

この段階では二原理の組合せ、求め方の容易さ、ξ=Vτとτを代入した式の著者帰属を加えていない。全単位確認数は据え置く。全軌道を有限の端点例だけで証明したとはせず、光線上の式を光線外の全座標変換へ拡張することもしない。
