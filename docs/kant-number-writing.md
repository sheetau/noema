# 数値の円表記

数値は既存の native `number`（整数分子と正の整数分母）へ戻す。新しい語義や数ごとの語は追加しない。数値の開始、桁、分母への切替、終端を構文として定め、語彙辞書の順位から数字を割り当てない。

開始は、大円の右円周上に中円の中心を置いた二円とする。大円の円周から外へ伸びる終端斜線が左上なら非負、左下なら負を表す。この二形は既存の語・文法形と区別する。斜線は大円の上下端の高さで止め、続きを接続しない。開始形に引数の枝は付けない。

開始後は中円一個を一桁とする。中心線なしが0、東から時計回りの8方向が1〜8で、九進の上位桁から読む。これは通常の語の内部形も利用するが、数字を読んでいる間は語彙の綴りを探索しない。方向は数値を表し、配置の都合で回転させない。桁は通常の三段配置と接続規則に従う。

小円一個で整数を終える。分数では分子の桁の後に中小の同心円を置き、分母の桁を続けて小円一個で終える。同心円はこの範囲では分母への切替であり、通常の語としては読まない。整数では分母1を省く。正の分母が2以上で、分子と分母が互いに素の場合だけ分数形を受理する。

各整数は少なくとも一桁を必要とし、先頭の0は値0の場合に限る。負の0、分母0/1、未約分の分数、途中の枝、語境界の不可視接続は拒否する。数値内で円周接触を使う場合も、同じ数値の隣り合う中円の桁に限る。開始形と終端から範囲が決まり、語の解釈、引用の範囲、変数束縛を変更しない。

実装前の検査計画：9桁と複数桁、符号、零、分数の境界を小さい対照例で調べる。数値を等式の両引数、引用、数型の束縛、数を返す関数適用へ接続し、SVGの円・線から元構文へ戻す。非正規形は図形からの読取でも拒否する。既存の語・型・束縛の保存SVGを再読し、文法追加の影響を区別する。配置・文書全体の完成や外観承認は別途必要である。
