# 自ら依存を脱した発信者と、その後の伝達

カント第四段落の「自ら未成熟の頚木を投げ捨てた後で」に対し、発信者自身の自立への変化を、最初の発信より前へ結んだ。前段の性向の伝達・取得・持続と接続し、指定した基準点より後に取得を完了した受け手の範囲も記述する。

## 同じ発信者の変化と、最初の発信

`rqtg`は、厳密に順序付けられた同じ履歴に、先行する完了点・後続する開始点・基準点があることを要求する。完了点は開始点より厳密に前、開始点は基準点以前とする。時点の順序だけから、出来事や因果関係の存在を導くものではない。

`hzod`はこの時間関係へ、既存`h4p`の自己活動による自立の達成を接続する。同じ本人が同じ過程で精神的な営みに働きかけ、その活動が同じ本人に、他者の指導なしに理解力を使う能力を生じさせる。能力評価の整合性、前状態からの変化、本人の活動、原因を省略しない。他者の援助を禁止する条件も付け加えない。

これは自己離脱の一つの対象側の読解候補である。原文の「頚木」を物理的な道具として除去したと主張するものではなく、その比喩の対応はまだ接続していない。全ての自己離脱がこの精神的な自己形成過程だけによるとも確定しない。

`hzoe`は、受領・理解・性向の取得・持続を記述する`hzob`と、最初の発信者の`hzod`を結ぶ。最初の発信時点は、同じ伝達経路の最初の段階から取り出す。最終受領者の受領時点や、中継者の離脱で代用しない。

実際の離脱が成立していても、その完了が発信と同時か、発信より後なら「離脱してから発信した」という条件は満たさない。この区別は同じ評価グラフで確認する。時間を粗くまとめて同時点となった場合には、その粒度で厳密な順序を確認できないという扱いになる。

## 基準点より後に完了する伝達

`hzof`は、指定した期間枠に基準の開始点より後の点があることを確認する。その枠の中で開始点より後に性向を取得し、評価基準時まで維持する人の範囲を内部で作る。

全員について最初の発信者とその離脱過程・前後点を共有する。一方、各受け手の伝達経路、取得の開始・完了点は別々に指定できる。離脱の前後点と、各経路の最初の発信・取得の前後点が、同じ期間枠に属することも確認する。発信者や受け手自身の履歴と、共通の期間枠は区別して検査する。

将来という条件は、受け手の取得完了へ課す。発信が開始点以前から続いていても、その後に取得が完了する場合は許す。開始点と同時またはそれ以前の完了は、新しい将来の取得者へ数えない。想定読者の範囲を過去の受領者や成功者だけに狭めることもない。

これは指定された経過内で成立する内容である。まだ著者の将来判断を帰属した文ではなく、現実の予言、全候補での必然性、自由を条件とする様相判断へ自動的に昇格させない。周囲という社会的範囲を想定読者と同一視することもしない。

## 検証

6テストで次を確認する。

- 時間順序と履歴所属の48組合せ。完了と開始の同時性、開始と基準時の同時性、循環した順序、未知の順序を区別する。
- 元の自己活動・能力・因果・伝達の定義を実行する22対照。同じ人の離脱成立と発信前の完了を三例で同時評価し、自己活動の肯定・否定をメモ化なしでも照合する。
- 想定読者の広がりと将来完了・期間枠の23対照。二人のうち一人が開始点と同時に取得した例で、正確な取得者の範囲が後の一人だけであることを確認する。離脱の開始点と受け手の取得開始点は別の時点にし、期間枠への所属を取り違えない。
- 理由ある自己評価・規範承認への応答傾向と、発信者の自己活動を同時に実行する4対照。規範の真理や実際の思考を補わず、別の性向の記述への原因を拒否する。
- 八つの未知入力、通常・短縮・固有文字の往復、既存の全意味規約・32文・七単位の確認の保持。

新しい基本関係はなく、四つの合成定義を加えた。一般形は依存先込みで558文字、累積本文への追加は1,283文字である。

原文対応はカントu0011の254–315、`nachdem sie das Joch der Unmündigkeit selbst abgeworfen haben`の範囲への部分構成である。比喩、恒常的な自己思考と後見役への任用、周囲への伝播、自由と将来の様相、著者帰属への全文接続が残る。単位全体の意味一致を確認済みとはしない。
