# 実数の記述と時計同期の等式

文語0.11の関数型を使い、有理数上の性質から実数を記述する[定義集](../examples/v011/real-cuts.noema)を追加した。新しい文法やモデルは使っていない。実数を有理数の近似値へ置き換えず、切断として表す。今回は加法・符号反転・差と、アインシュタインの時計同期の等式までを扱う。

## 切断による実数

基盤となる4つの基本関係は、有理数の厳密な順序・加法・符号反転・乗法である。既存の型`b`は有理数のまま維持する。[意味規約](../data/real-cuts-basis-v1.json)に、この4つと9つの定義の意味を記録した。

型`h[b] c`の関数は、有理数ごとに真偽を返す。真となる有理数の集合Lが以下の4条件を満たす場合、それを実数の下側切断とする。

1. Lは空でない。
2. Lは有理数全体ではない。
3. xがLに属し、y<xなら、yもLに属する。
4. Lには最大の元がない。

有理数rは`{q | q<r}`で表し、r自身を含めない。同じrに境界を含む表現と含まない表現の2つができないよう、4番目の条件を置く。切断による構成は[Dedekindの原著の英訳](https://www.gutenberg.org/ebooks/21016)を参照した。境界をどちら側に置くかには別の規約もあるが、この定義集では下側に最大値を持たせない規約に統一する。

| 定義 | 数学的な意味 |
| --- | --- |
| `ba(L)` | Lが上の4条件を満たす |
| `bb(r)` | 有理数rの埋込み`{q | q<r}` |
| `bc(L,R)` | L⊆R。切断に対する小なりイコール |
| `bd(L,R)` | 和`{q | ∃x∈L ∃y∈R, q<x+y}` |
| `be(L)` | 符号反転`{q | ∃u∉L, q<−u}` |
| `bf(L,R)` | 差`bd(L,be(R))` |
| `bg(L,R)` | L⊆RかつR⊈L。切断に対する厳密な小なり |
| `bh()` | `{q | q<0 または q²<2}`。正の平方根2の切断の記述 |
| `bi(A,B,A′)` | B−AとA′−Bが、全有理数で同じ真偽を返す |

任意の有理数上の性質が実数になるわけではない。`ba`は論理的な条件であり、関数型自体を実数の専用型に変更してはいない。演算を実数として使う箇所では、引数が切断であることを別途前提にする必要がある。

`bh`は一般の平方根演算子ではない。例えば−2、0、1、7/5が含まれ、3/2と2が含まれないことを、浮動小数点を使わず厳密な分数で確認した。この具体値の検査だけで、切断の全条件や平方根の一般法則を証明したとはしない。

## 演算の境界を保つ理由

和では、あるx∈L、y∈Rの和より厳密に小さいqを含める。L、Rの外にある上界u、vを選ぶと、u+vは和の切断に入らない。一方、L、Rの元から十分小さいqを選べるので空ではない。下方閉性は不等式から従い、q<x+yの間にもう一つの有理数を取れば最大元も生じない。

符号反転を単純な補集合の反転にすると、有理数の境界を含めてしまう。`be`では、補集合の元uに対してさらに`q<−u`を要求する。元の切断の内側のaと外側のuを使えば、符号反転の切断にも内外の元があることが分かる。下方閉性と最大元の不在は、ここでも厳密な不等式によって保たれる。

これらは定義を確認するための数学的な説明である。切断全体についての代数法則や完備性を証明支援系で形式検証し終えたわけではない。

## 原文の式との接続

保存したアインシュタイン原文の`einstein-1905:u0014`、数式`M0030`は次の等式である。

```text
t_B − t_A = t′_A − t_B
```

`bi(depart,reflect,arrive)`は、この両辺の差を切断の等しさとして記述する。反射時刻を両辺で同じ引数として参照し、出発時刻と帰着時刻を区別する。[対応記録](../data/einstein-clock-equation-v1.json)には原文の数式ハッシュ、直前の段落で使われる各時刻の参照、残る接続課題を保存した。

時計の読みを切断へ結び付けること、共通の単位・基準系、時計と場所・光の出来事の関係、式が同期の定義条件であるという位置付けは未完成である。裸の数式だけで原文単位全体を記述したとは扱わず、対応状態は部分草案、確認済み全文単位は引き続き0とする。

## 全有理数を対象とする補助検査

従来の有限解釈器は、有理数への量化を引き続き拒否する。新しい補助検査器`noema.rational_proofs`は、Noemaの定義・関数適用を式どおりに展開し、有理数係数の線形算術だけを[Z3のAPI](https://z3prover.github.io/api/html/namespacez3py.html)へ渡す。基本記号の算術上の意味は呼出し時に明示し、型と過不足を検査する。

内部ではZ3の厳密な実数算術を利用する。この置換を許すのは、有理数係数の線形式、順序・等号、論理結合、有理数量化だけからなる閉じた式に限定する。線形の存在量化を消去すると、下界と上界の大小・境界条件になる。有理数の境界の間に実数解が存在する場合には有理数解も取れるため、この範囲では有理数と実数で閉じた式の真偽が一致する。

**非線形の式へこの置換を拡張しない。** 例えば「q²=2となる有理数qが存在する」は、実数へ変えると真偽が変わってしまう。変項どうしの乗法は拒否し、`bh`全体の切断条件もこの補助検査器では検証しない。未解釈の基本関係、関数全体への量化、仮定のブロック、発話の実行も対象外である。タイムアウトやソルバーの未決定は`unknown`として残す。

次の6件について、主張の否定が充足不能であることを確認した。有限の例示ではなく、各式で量化した全有理数に対する結果である。

- 有理数rの埋込みが切断の4条件を満たす。
- 符号反転が有理数の埋込みと整合する。
- 加法が有理数の埋込みと整合する。
- 差が有理数の埋込みと整合する。
- 厳密な順序が有理数の埋込みと整合する。
- 時計同期の式が、有理数の読みを埋め込んだ場合に元の差の等式と一致する。

逆に、空集合・有理数全体・最大値0を含む下側集合を切断とする3件と、差の引数を逆にしてもよいとする1件は不成立となった。切断全体の実数演算の性質を自動証明した結果と、これらの有理数埋込みの結果を区別して記録している。
