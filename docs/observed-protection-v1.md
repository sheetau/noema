# 保護・不干渉と実際の観測を一致させる

前版は、政策が実施され、その政策が指定モデル内で保護・不干渉の効果を持つことを記述した。実際の観測がモデルに反している場合も、その構成自体は成立し得た。今回は観測記録への接続を加え、この違いを区別できるようにした。

| 定義 | 内容 |
| --- | --- |
| `rkz` | 同じ時点の観測割当てが元の方程式の解で、政策と活動の内容にも一致する |
| `rk2` | `rkz`に加え、同じ記録の脅威要因が同じ時点の脅威内容に一致する |
| `rk3` | 前版の保護効果・内容対応・政策実施に、`rk2`の観測整合性を要求する |
| `rk4` | 前版の不干渉効果・内容対応・政策実施に、`rkz`の観測整合性を要求する |
| `rk5` | 各共同体を同じ共同体・同じ評価時点の観測記録で検査する |
| `rk6` | `rk3`に加え、その時点で脅威が実際に成立している |
| `hzek` | 前版と同じ共同体の選択条件を使って、観測整合性を含む政策内容を返す |

観測記録は、モデルの変数全体への割当てとして渡す。照合するのは、介入で要因を上書きする前の方程式である。政策を実施したという背景条件もその方程式に含める。仮想的に政策要因を切り替えた側だけで成立する割当てを、そのまま実際の観測の整合性へ流用しない。

実際の状況を、モデルの比較用の状況と同一視する必要はない。モデルに選んだ変数について、観測した割当てと同じ政策・活動・脅威の内容を照合する。比較用の状況には含めなかった事情が実際の状況に存在することまで否定しない。

政策が実施され、モデルに保護効果があっても、実際の活動内容と記録が食い違えば`rk3`は成立しない。観測だけが整合していて保護効果がない場合も成立しない。一方、不干渉の`rk4`は、もともと活動が不可能なら活動の実現を導かない。活動を妨げないことと、活動を生じさせることを分けたまま観測へ接続する。

脅威が実際には起きていない予防的な保護も`rk3`に残した。脅威が実際にある場合は`rk6`を使う。どちらの場合も、政策の実施・モデル上の効果・内容対応・観測整合性を別々の条件として保つ。

各共同体には、その共同体と評価時点を引数にした観測記録を用いる。同じ政策の下で、一方の共同体の活動が成立し、他方は活動が不可能だが政策による妨害はない、という場合も記述できる。前者の成立する記録を後者へコピーしてはならず、過去の整合する記録で現在の記録を置き換えてもならない。

`hzek`の閉じた適用記述を前版の共同提案へ接続した。政策内容と観測記録が未知でも、その内容を提案する可能性は記述できる。提案したことから観測が正しい、政策が実施された、保護が実現したという結論は導かない。政策内容そのものを検査する段階で未知があれば、偽や空の記録で補わず評価を拒否する。

政策・脅威・活動の三つの内容値と観測した三変数の64通りを照合した。政策未実施、実際の脅威、活動の不一致、介入側でしか成立しない記録、モデル外の変数を真にした記録、複数解・無解、活動がもともと不可能な場合も検査する。共同体の検査では、政策実施と二共同体の記録の整合性の八通りを扱う。

[一般文書](../examples/v014/observed-protection.noema)は6,822文字、[原文付き草案](../examples/v014/kant-observed-protection.noema)は158,378文字、[抽出文書](../examples/v014/observed-protection-core.noema)は10,952文字である。七定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-observed-protection-basis-v1.json)と[検査記録](../reports/observed-protection-v1.json)を保存する。

モデルに観測が合うことは、そのモデルが現実の因果を正しく説明する証明ではない。観測方法の信頼性、背景・変数・脅威の選定、保護の法的地位・救済・補償などは未完である。制度への合意・希望と共同体の選択条件、宗教制度の意味、君主の位置、著者帰属と全文の意味確認も残る。今回の原文範囲は前版と重なり、対応文字数を増やす追加ではない。

64通りの観測照合と共同体・提案への接続検査が通過した。追加の検査7件と前版の回帰検査7件、計14テストも通過した。三文書のCLI解析結果は構文木と一致し、抽出文書の固有文字v2のSVGをXMLとして検証した。SVGの目視確認は含めない。
