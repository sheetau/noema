# 文語0.11：定義への参照と関数

0.11では、関数・性質・関係を型のある値として扱う。これまでの名前付き関数の呼出しに加え、定義を別の関係へ渡す、式から関数を作る、関数を受け取る関数を定義することができる。版指定は`k:`または`noema k k`。

カントの草案では、標語が何の標語なのかを示す際に、「啓蒙」を指す未接続の基本記号を置いていた。今回、離脱過程の定義から性質を作り、その性質を標語の関係に直接渡す形へ変更した。先行する説明と後の参照を接続するための拡張である。

## 型と構文

```text
h[引数型 …] 結果型           関数型
p 記号                      宣言済みの関数への参照
i[変項 型 …][式]            式から関数を作る
c[関数の式][引数の式 …]     関数値を適用する
```

| 型の例 | 意味 |
| --- | --- |
| `h[a] c` | 対象を受け取り、真理値を返す性質 |
| `h[a] e` | 対象を受け取り、状況ごとの真偽を返す性質 |
| `h[a a] c` | 2つの対象の関係 |
| `h[b] b` | 有理数から有理数への関数 |
| `h[h[b] b b] b` | 数値関数と有理数を受け取り、有理数を返す関数 |

型は再帰的に構成できる。関数型の意味領域は、引数領域の直積から結果領域への全ての全域関数とする。引数が0個なら、空の引数組に結果を対応させる関数となる。型の入れ子の上限は128である。

`p aa`は宣言`aa`の関数を指す。`k aa[引数…]`は従来の名前付き呼出しで、`c[p aa][引数…]`と同じ適用結果になる。前方参照・再帰参照・未宣言記号は禁止したままである。関数への参照を導入しても、基本記号の意味が新たに説明されたとは数えない。

`i[x a][式]`は、xを引数とする関数を作る。外側の変項を参照でき、内側で同じ名前を束縛するとその範囲だけ遮蔽する。式から結果型を検査し、関数型を決める。例えば`i[x a][e[v x][v x]]`は型`h[a] c`である。関数を適用せずに作った段階で、特定のxについて本体が真だと主張することはない。

JSONでは関数型を次の形で表す。文字列の型名との暗黙変換はない。

```json
{"kind":"function","parameters":["individual"],"result":"content"}
```

式の種類は`function_ref`、`lambda`、`apply`。通常の変項・量化・同一性にも関数型を使える。関数への引数は、個数だけでなく、入れ子になった型まで一致する必要がある。

## 定義から作った性質を再利用する

[統合したカント草案](../examples/v011/kant-linked-draft.noema)は、0.9の離脱定義`be(person,change,before,after)`と、0.10の呼びかけを同じ文書に置く。新しい定義`bi(change)`は、評価状況をafterとして、ある人と先行状況について`be`が成立するという内容を返す。

```text
d bi[change a] e[
  b scene[g person a[g before d[k be[v person v change v before v scene]]]]
].
s[k am[k bh[] p bi]].
```

`p bi`の型は`h[a] e`である。`am`は発話とその性質を受け取り、前者を後者によって記述された事柄の標語として位置付ける。以前の未接続記号`an`は新しい草案に存在しない。内容を一つの時点の真偽へ変えて渡すこともしない。

検査用の解釈では、離脱後にも能力がない場合に性質`bi`は偽となり、能力を得て離脱の条件を満たす場合には真となった。変化に関係しない対象では偽のままである。呼びかけは同時に、まだ実現していない勇気を求める発話として保持した。定義への接続と、呼びかけの実現を混同していないことを確認した。

この性質は離脱を完了した過程についての暫定的な定義であり、歴史的・社会的運動としての啓蒙の意味まで確定していない。能力の保証条件、原因の説明、勇気や標語の基本関係にも課題が残る。[意味の規約](../data/kant-linked-basis-v1.json)に14の基本関係、9つの定義と未解決点を記録した。

原文の対応範囲は前回と同じ冒頭段落の部分草案である。新しい原文区間を完成済みには数えず、ラテン語の標語・ドイツ語の説明の関係と`also`の談話上の帰結も未記述のままである。全文対応済みはカント0/20、アインシュタイン0/282。

## 同じ構文で数値関数を扱う

[関数合成の例](../examples/v011/function-composition.noema)では、`aa`を有理数の加法と解釈し、`ba(fun,value)`をfunを2回適用する関数として定義した。「1/2を加える関数」を引数として渡し、0から1になることを厳密な分数で確認した。新しい関数ごとに構文やモデルのクラスを追加する必要はない。

これはアインシュタインの式を全文記述した結果ではない。有理数型を実数全体として扱うことはできず、実数・数量・単位・微分などの理論が必要である。全域関数型だけでは未定義点を持つ関数をそのまま表せないため、定義域の制限や結果の有無も今後明示する必要がある。

## 同一性と検査の範囲

関数の同一性は外延的で、全ての引数で同じ結果を返すことを意味する。Pythonの関数オブジェクトの一致や、Noemaの綴りの一致ではない。結果が内容なら全状況の真偽まで、結果が関数ならその関数の適用結果まで比較する。

同じ対象・同じ状況で成立する異なる概念の捉え方や説明方法は、この同一性では区別しない。Noemaの式の構造は保存するが、概念の定義を関数値として渡すことと、定義の字面・推論過程を対象にすることは別である。後者は未完成の課題として保持する。

有限解釈器では、関数を参照・構成・適用し、有限の引数領域で外延を比較できる。関数に量化する場合は、宣言済みの関数だけでなく、その型の全ての表を列挙する。2対象に対する任意の真偽の性質や、真理値から真理値への関数で検査した。関数を受け取る基本関係の解釈も、同じ外延を持つ関数を区別しない規約に従う必要がある。

有理数を引数にする関数の全域比較や、無限個の関数への量化は有限の標本で代用せず拒否する。具体的な有理数に適用する計算は可能である。有限の場合も、引数組と関数表それぞれ4,096までの資源上限と評価ステップ上限を設けた。上限超過は検査器の未対応であり、命題が偽という結果ではない。

解釈器が関数を外部の基本関係へ渡す場合も、呼び出された引数と結果の型を検査する。ただし、全入力について外部関数が規約を満たすことや、基本関係が現実に正しいことを自動証明する機構ではない。
