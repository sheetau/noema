# 複数の項目を一行の流れとして読む

## 先行計画

一項目一行の空白帯だけでは、元の kant-page の複数文を含む行へ戻せない。宣言・綴り記録・文のそれぞれを読み終える位置を構文から決め、次の項目を続けて読む。本文に共通の開始記号を足さない。既存の引数数、型のリスト終端、仮定の終端を再利用する。

項目ごとに変数の束縛と採番を閉じる。宣言と綴りは、その項目の検査を終えてから辞書へ登録する。次の項目が、まだ読んでいない名前・綴りを使える状態にしない。図形全体の検査が失敗した場合、呼出元の読取状態を更新しない。

語の最長一致は項目をまたぎ得る。各語をその時点の辞書で読み、隣接項目の基礎語形を取り込む場合だけ、既存の見えない語境界を置く。項目を連結してからこの条件を調べる。字形の追加や項目番号の埋込みはしない。枝の語形と語の成分数は、生成時点の辞書で確定し、後続の省略綴りによって過去の形を変えない。

一行の全円・線から主流と枝を復元し、構文を順に読む。SVG の group、番号、項目ごとの範囲、元の構文は読取器へ渡さない。行は既存の空白帯で分割し、中央罫線が図形から一つに定まらない場合は、成功した読みがすべて同じ項目列になることを要求する。

最初の対照は、文境界での語の接頭部衝突、隣り合う文の束縛、引用・仮定の終端、宣言と綴りの直後の使用、複数行をまたぐ登録順とする。保存済みの実宣言にも適用する。一行は既存の512要素上限を維持する。長い一項目の折返し、頁継続、最終の行幅・行間と外観評価は別に残る。
