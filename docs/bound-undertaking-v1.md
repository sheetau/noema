# 対象を保持した目標を、勇気を伴う試みへ結ぶ

前段で構成した「同じ足を一回移し、その着地点が装置外にある」という目標を、本人が敢えて試みる内容へ接続した。身体・装置・足・目標の移動過程という四つの対象を保持し、その試みを許容の対象として引用できる。

これは、カント第二段落の `keinen Schritt … wagen durften` へ向けた比較構成である。[前段の原文照合](../data/walking-warning-reading-v1.json)と[取り組みへの許容の読み](unpermitted-undertaking-v1.md)を継承する。候補全体の範囲、先行する阻止、比喩への結合は残るため、本文への採用や一文全体の意味確認とは数えない。

## 目標の記述と対象列を分けて渡す

既存の `hzs4` は、本人一人を受け取る閉じた目標記述について、勇気 `hzio` と試み `f5`、行為者 `df`、生起 `dg` を結ぶ。今回の一歩の目標は四つの対象を持つため、目標関数の記述と、順序付き対象列を明示的に渡す形を加えた。

一般定義 `rqzi` は、対象列の適合性を確認し、同じ本人・目標記述・対象列・状況について十分な勇気があり、本人がその目標を試みる行為が生起することを要求する。試みの関係、行為者、生起は同じ行為に結ぶ。勇気や試みなどの関係を引数で受けるため、この一般形には基本述語を追加していない。

`rqzj` はこれを具体的な関係へ接続する。対象列を持つ勇気 `hzxz` と試み `hzya` の二関係を追加し、行為者と生起には既存の `df`・`dg` を使う。旧 `hzio`・`f5` の引数型や意味は変更しない。新旧の独立した基本関係が自動的に一致するという規則は置かず、一般形を旧関係へ明示的に接続した場合に `hzs4` と一致することを検査する。

目標の内容は実行評価しない。失敗した試みも、目標の成立が不明な試みも記述できる。目標記述、対象列、本人、状況のいずれかを取り違えた勇気や試みでは成立しない。異なる記述の意味が偶然一致する場合にも、その記述を自動で同一化しない。

## 試みの行為と、目標の移動過程を区別する

`rqzk` は四つの対象を受け、第一位置の本人が、同じ列に適用した一歩の目標 `rqzg` を勇気を伴って試みる内容である。列の不足・余分な項目を捨てて解釈せず、身体・装置・足・移動過程の各位置を維持する。

ここで生起を要求するのは試みの行為である。目標に名指した移動過程が実際に起きたことは要求しない。両者が異なる場合と、同じ行為が成功した移動にもなった場合を扱える。試みを実行したという記述から、足の接地更新や外部への到達を補完しない。

`rqzl` は指定候補の全てについて、この `rqzk` への積極的許容がないことを表す。前段の `rqy6` を再利用し、身体・装置と候補ごとの引数列を保持する。前段の `rqzh` が対象にする一歩そのものと、勇気を伴う試みとを別の引用内容にする。許容の対象として述べるときは、勇気・試み・身体の状態が未知でも、それらを実行評価しない。

対象列の不適合は「許容されない」という結論へ変換しない。許容関係が未知の場合も、記録がないことを根拠に否定しない。候補範囲は明示的に与える。許容された候補を範囲外へ除けば結論が変わり得るため、原文の候補全体を確定する作業が必要になる。既存評価器では範囲外を含む関係にも完全な解釈を必要とする場合がある。

## 検証

五テストで次を確認した。

- 勇気・試み・行為者・生起・成功の32組合せ、対象や時点などの15対照、未知入力五種。
- 旧一引数目標への明示的な接続について、32組合せで旧構成との一致。目標の内容も実際に評価して比較する。
- 四つの対象、試みの行為、目標過程の生起を区別する18対照。足の接地などの身体関係は未知のまま検査する。
- 二候補の試みへの許容と、一歩への許容の八組合せ、対象列・候補範囲・文脈の六対照、未知入力三種。
- 三記法の往復、採用中の47文と十一単位の意味依存関係の保持。

全て通常の評価器で検査し、Noemaの定義を検査用の真偽値で置き換えていない。有限の組合せ検査は、原文の全候補の網羅性や意味の自動証明ではない。原文への採用には、候補全体の範囲、先行する阻止と同じ時点、非字義的な描写、`ruhigen`・`ja` と一文全体の照合が残る。
