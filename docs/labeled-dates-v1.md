# 日付番号と期間一覧の位置の分離

日付行の30日と脚注の13日・30日を、期間一覧の位置から暦上の番号による指定へ変更した。旧版は月列の位置8、日列の位置12・29で日を指定していた。この方法では一覧に欠番に対応する期間がなければ、それ以降の日番号がずれてしまう。

新しいrqsdは、同じ暦・文脈で年番号が年期間を指定し、その年内の月番号が月期間を、その月内の日番号が日期間を指定することを要求する。各割当が成立し、同じ番号に他の期間が割り当てられていないことも調べる。暦・親期間・文脈が違えば同じ番号を再利用できる。欠番を詰め直す操作は行わない。

原文の日付は年番号1784、月番号9、日番号13または30として記述する。既存の年割当を再利用し、月と日の番号割当を二つの関係として追加した。列位置を扱う旧rqrmは保存するが、日付行hzjeと脚注の読書・号の接続hzkkは新しい番号指定を使う。両箇所で同じ年・月・日の局所参照を共有することも保持した。

検査では、年・月・日の割当の有無と重複を64通り調べる。場所表示・日付表示・号の日付・読書の対象・文脈の既存対照に、誤番号、同番号の別期間、別の親期間、未知の番号割当を加える。欠番の作例は合成したモデルであり、1784年9月に実際に欠番があったと主張するものではない。そのモデルでは旧方式が拒否する日付を、新方式は番号を変えず指定できる。

暦の歴史的同定は今回確定していない。一般定義は数値型の番号を受けるため、その暦でどの番号が有効か、紀元・改暦・閏日・絶対時間とどう結ぶかは依然として割当関係の説明を要する。現行のグレゴリオ暦については[米国海軍天文台の暦解説](https://aa.usno.navy.mil/downloads/c15_usb_online.pdf)に月ごとの日番号と規則の説明があるが、それだけで原刊の日付が使う暦の同定を証明したとは扱わない。

既存23文の構文は保存し、変更した既存定義はhzjeとhzkkだけである。署名の依存内容も保存する。日付行と脚注の原文対応範囲は増えず、単位全体を意味確認済みへ加えない。
