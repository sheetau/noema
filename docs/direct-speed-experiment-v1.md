# 偏向比を独立した速度測定と比較する

原刊920頁u0268を、直前の比の式を実験で調べられるという主張、直接にも速度を測れるという理由、高速に振動する電場と磁場を使う一例に分けて接続する。u0265の列挙導入は今回の判断に含めない。

速度は校正された同じ対象の実履歴から三つの座標時刻微分を取り、その非負ノルムで定める。加速度又は偏向比から速度そのものを定義しない。速度単位の正の尺度Uは、長さ時間尺度L,TとU T=Lを満たす。直接法は同じ量を校正と信号取得から得る方法であり、検査対象の比の成立を算出又は校正の前提として使わない。

前段の偏向測定から得た復元候補と、同じ速さを独立に直接測った値を、同じ観測者の評価段階で比較する。別の許容状況での測定を認めつつ、記録は同じ可能な実験過程で保存・伝達される。数値比較の判定は真でも偽でもよく、一致を検査の前提にしない。ここで述べるのは実験可能性であり、実際の支持結果や普遍法則の証明ではない。

振動場は、連続で非定数の周期波形が中心の上下を取り、局所の使用区間で実際の電場y成分・磁場z成分へ一致する一例として読む。両場の周期は別でもよく、最小正周期をそれぞれ指定する。場を装置の測定操作に使い、時間情報を同じ取得信号へ反映する物理的な結合を要求する。近くに振動場があるだけでは、この測定法の例にならない。

「速く」は、その測定配置の時間情報・応答尺度から定まる文脈上の周期閾値より短いこととして表す。閾値は採用する場の周期から都合よく選ばず、測定法の背景条件に結ぶ。原文が特定の回路・飛行距離・普遍的な周波数境界を指定したとは扱わない。数学的波形の全周期性と、実際の場を用いる有限区間も区別する。
