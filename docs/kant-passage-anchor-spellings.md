# 談話上の参照箇所の綴り

## 先行計画

残っている長い綴りのうち、便宜・代行、後見下の描写、自立と知的活動、公衆の啓蒙に関する十一の既存参照箇所を一群として扱う。不足する意味関係はない。既存の個体定数が指す文章箇所を保ち、表示上の綴りだけを短くする。各箇所を新しいprimitiveとして作り直さない。

| 既存名 | 綴り | 語彙上の手掛かり |
| --- | --- | --- |
| h226h | fruit・methodpossible・book | 公衆が啓蒙へ至ることを述べる文章箇所 |
| h5t | aki・methodpossible・book | 自己活動による自立についての結論箇所 |
| t4 | give・methodpossible・book | 支払いと他者の引受けを述べる箇所 |
| h2d | inside・candidateexcluded・book | 定型表現を足枷として描く箇所 |
| uo | inside・book・methodpossible | 未成熟でいる便宜についての箇所 |
| hzzr | inside・aki・book | 未成熟への愛着と能力欠如を述べる第三段落第二文 |
| hztz | candidatecontingent・methodpossible・book | 危険・経験・試みをめぐる対比の範囲 |
| qp | fruit・inside・aki・book | 対象者を後見人の家畜として描く箇所 |
| hk2 | methodsassessable・candidateexcluded・book | 使用を誤用と言い直す箇所 |
| h5f | methodsassessable・assessmentvalid・book | 知的活動を確かな歩みとして描く箇所 |
| h222d | book・bird・methodsassessable | 確かな歩みの譲歩背景を指す文字範囲 |

bookは文章上の参照、fruitは集団、akiは本人、giveは授受・引受け、insideは状態や描写の内側を手掛かりとする。方法・評価の根語は能力、知的活動、その評価を区別する手掛かりである。book・birdは既存の談話上の対比を表す語群と関連付ける。全て複合語全体の公開された語彙規約であり、根語の適用から文章の内容を推論する規則ではない。語の長さ、文番号、登録順、ハッシュから形を割り当てない。

例えばh226hの綴りだけから啓蒙の実現や速度を主張せず、h5tを本人という個体に取り替えず、h2dを物理的な足枷と同一視しない。hk2の綴りは使用の不可能性を意味しない。h222dは既存の文字範囲への参照であり、そこで述べられる全内容の完成を示す記号ではない。正確な指示範囲は元の意味記録をそのまま公開する。

qpの候補fruit・inside・bookは既存語h222eと衝突するので採用しない。本人への描写を示すakiを加えた四部品列を使う。旧完全名と旧省略名をすべて保持し、新しい最長一致の境界を別に確認する。

まず十一語の元宣言・型・意味記録・旧alias対応を照合する。各語を実図形から復元し、既に確認済みの構文に新しい綴りを入れた実本文も検査する。全40本文のイベント列から変化範囲と円数を計数するが、それを全40の新配置の実測や復号成功と扱わない。合法な語内重なりは共通の既存規則として併用する。
