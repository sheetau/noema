# 代名詞・曖昧な名前を含む確認評価v3

v7は前回の新規人工文では条件を通過したが、別の手書き回帰で代名詞などを誤確定した。今回はv8の学習・開発用に参照の対照例を加えた後のモデルを、予測前に固定した別サンプルで確認する。既存のv1・v2と手書き資料は回帰として保持する。

## モデルと選択

候補はcorpus-v8で30エポック学習するXLM-Rの小型分類器1個とする。エンコーダーと共同役割割当ては前版と同じ。エポックと日英それぞれの閾値は開発用データだけから選ぶ。両言語が開発用条件を満たす場合に限り、重み・閾値・資料のハッシュを固定して確認を行う。v7の重みや報告を上書きしない。

## 新規資料

- 基本15概念、6述語ごとに50種類、計300種類の意味構造を日英各2表現で作る。対応範囲内は各言語600文。文型の作成方式はv1・v2と同じで、未知の文体への汎化とは区別する。
- 乱数種11128。名前はMaya、Olivia、Noel、Dina、Arun、Theo。数量は13、29、41、97、2048、8192。学習・開発・回帰・v1・v2の完全な意味構造と文の重複を除く。
- 既存の未対応6区分を各言語12文ずつ作る。未知概念はカワウソ／otter、ハリネズミ／hedgehog、鰐／crocodileとする。
- 新規資料の名前付き主体を持つ文から、参照先のない代名詞を12文、名前と抽象概念の解釈を一意にしない文を12文、各言語へ追加する。代名詞は彼女とshe（目的格はher）、抽象概念は勇気・幸運・真実とCourage・Luck・Truth。既存の「She sleeps」などの文そのものを複製しない。
- 合計は各言語600対応文＋96未対応文、両言語で1,392文。全注釈と代表文の意味対応を予測取得前に点検する。

名前と抽象概念の区分は、文脈なしでは指示対象を一意に指定できない入力に対して、確定を控えるかを測る。この区分の文が必ず比喩であり、人名としての解釈が存在しないという注釈ではない。既知の人名を用いた対応例への棄却増加も、確定率に反映する。

## 判定

従来どおり、日英それぞれで対応範囲内の確定率80%以上、確定出力の完全一致率95%以上、未対応全体の誤確定率5%以下を必要とする。今回追加する代名詞と名前／抽象概念の2区分はそれぞれ12文なので、各区分でも5%以下、すなわち誤確定0件を追加条件とする。大きな別区分の件数によって参照の失敗を隠さない。

全同義グループの一致、文型・未対応区分別成績、反復・単独／一括実行の一致も報告する。評価時の再学習・閾値変更・候補の再選択は行わない。この結果を改善へ使った場合、以後はこの資料も回帰資料として扱う。利用者の自由記述や文字の識別性の評価は、今回の人工文とは別に進める。
