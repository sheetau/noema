# 発言資格の統合検査

カント第17区間の候補解釈 `hzzonly` を、一つの有限解釈で実行した。発言の実現可能性、自分の能力の自立的な使用、恐れを支える理由、共同体の保護、組織の任務割当、武力行使の遂行能力を、保存されたNoemaの定義から評価する。個別条件の真偽を返す代用関数へ置き換えてはいない。

これは[武力行使の遂行能力](armed-readiness-v1.md)で残した統合検査の追加である。本文は [kant-armed-readiness.noema](../examples/v016/kant-armed-readiness.noema) のままで、新しい原文範囲は加えていない。候補解釈の語義の妥当性や全文の意味一致を確認し終えたという結果ではない。

## 共有する対象

以前の三つの検査例を、30個体・16状況の解釈へ結んだ。話者と指揮者を同一人、保護する集団と任務を割り当てられた集団を同一集団、その共同体を同一共同体にする。保護側の第一構成員を武力行使側の操作者へ結び、第二構成員も同じ組織の役職に就く。保護計画と発言の計画は別の対象として保持する。

元の検査例の名前の変換は [検査スクリプト](../scripts/check_integrated_qualification.py) の `Bridge` に明記した。高階関数の引数と返り値にも同じ変換を適用する。引用記述は検査器が発行した値をそのまま渡し、Python側で作り直さない。

状況の集合を広げたため、保護用の脅威内容は、新しく追加された状況では偽と定めた。これは今回の有限モデルの明示的な選択であり、一般法則ではない。記述全域についての二つの量化は、以前と同じ有限診断に限定する。`rvy` は `hzvshadow` と `jktarget`、`rtx` は `jnact` と `jnalias` を検査する。保存本文の量化域は変更していない。

## 実行方法と確認事項

通常の検査器は論理結合の両側を評価する。この統合例では、式の評価回数が200万回の上限に達した。そのため、[診断用の短絡評価](../noema/diagnostic_short_circuit.py)を明示的に選ぶ。引用の外側にある論理積・論理和・含意だけを、既存の型付き関数と引数なしラムダで表現し直す。元の文書、通常の検査器、言語仕様は変更しない。

純粋で全域的な解釈では真理値を保存する。未使用の分岐にある未知入力や実行失敗を観測しなくなるため、部分的な解釈のエラー動作まで同じとは主張しない。必要な分岐の未知入力、型の不整合、引用の評価階層違反は拒否する。引用された式自体の構文は変更しないが、その式が参照する定義は短絡評価を使う場合がある。引用記述の同一性を、関数の真理値の一致に置き換えることはしない。

統合例では短絡評価と既存の二種類のメモ化を併用する。短絡評価だけでメモ化を無効にした場合も、この予算内には収まらなかった。小さな全域モデルでは、メモ化の有無、通常評価との真理値の一致を検査した。

- 同じ解釈で、上位の発言限定条件と各構成条件が成立する。
- 遂行能力・任務割当・保護・自分の能力・恐れの根拠・解釈対応・残余条件を一つずつ欠くと、発言限定条件が成立しなくなる。
- 構成員、任務の対象共同体、保護対象共同体、指揮者を取り違えた場合も成立しない。
- 必要な入力が未知の場合、引用して保持することはできるが、真偽の評価は拒否する。
- 発言できる人がいなければ、必要条件の含意は真になり得る。残余資格が成立したことや、資格の十分条件まで示したことにはならない。

実行中の原始関係への呼び出し数も記録し、発言、能力、根拠、保護、割当、武力行使の各定義が実際に検査へ関与したことを確認する。

軍隊と他の武装組織の制度的な境界、公的平穏全体、身体的制約などの基礎概念、比喩の語義の確認、残余条件、全記述域での検証は未完である。統合例の成功をこれらの解決とは数えない。意味一致の確認を終えた全文区間は、カント・アインシュタインともに0のままである。
