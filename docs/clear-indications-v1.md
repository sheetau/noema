# 対象を保持した明瞭な徴候

カントu0014の「そのことを示す明瞭な徴候をわれわれは持つ」という部分を、直前の二つの内容へ接続した。対象は、同じ人々に自由な自己作業の機会があることと、その人々の能力を尺度にした障害が減少していることの連言である。徴候の存在、観察者が対象の記述を認識していること、対象が現在実際に真であることを分ける。

| 定義 | 内容 |
| --- | --- |
| `rmb` | 同じ重み付き比較範囲で、徴候が仮説の真の場合に偽の場合より指定倍率を超えて現れやすい |
| `rmc` | 観察者が利用できる同じ項目が同じ対象記述へ結ばれ、徴候が現在成立し、`rmb`を満たす |
| `rmd` | その条件を満たす項目が一つ以上ある |
| `rme` | 異なる二項目がそれぞれ条件を満たす |
| `rmf` | 複数の徴候に加え、同じ観察者が同じ対象記述を認識している |
| `rmg` | 複数の徴候に加え、対象内容が現在真であるという強い比較条件 |
| `hzfa` | 同じ人々・評価文脈について、自己作業の機会と、その文脈を終点とする障害の漸減を結ぶ |

明瞭さの候補には、比較モデルに相対的な識別力を使う。仮説が真の側と偽の側をともに持ち、各比較状況に正の重みを与える。仮説が真の側で徴候が現れる重み比率をp、偽の側での比率をqとすると、pが指定した係数とqの積より厳密に大きいことを要求する。係数は1より大きく、比率の比較は除算せず交差積で記述する。原文が確率や数値を指定したという主張ではない。

仮説が偽でも徴候が現れる場合を許す。そのため、比較範囲に現在の状況が含まれていても、強い識別力を持つ徴候が現在あり、同時に対象は偽、という組合せが成立する。現在の状況が比較範囲の外にある場合も扱える。これらを、実世界の信頼性や真理の保証へ昇格させない。

比較範囲、重み、係数は仮説の両側で固定する。真の候補しか残さない、同じ候補を重複して数える、都合の悪い候補を列挙から落とす、重みを0にする、といった入力では確認済みの識別力を認めない。全重みを同じ正の倍率で変えても結果は保たれる。現実に適切な比較範囲・重み・係数を選ぶ方法は別の課題である。

対象への対応はNoemaの閉じた内容記述で保持する。同じ真偽を返す別名であっても、記録がその別名へ結ばれているとは補わない。観察者、項目、対象記述、評価文脈を共有し、別の対象についての徴候を流用しない。観察者が対象の記述を認識していることも、肯定判断や信念そのものとは区別する。

二つの項目は相関していてもよい。項目の異なりは、証拠の独立性、情報量の加算、信頼性の倍増を意味しない。また、利用できる記録があるだけでその徴候が現在成立するとはせず、現在の徴候内容も要求する。未知の対応や能力評価を必要とする場合には、偽で補わず評価を拒否する。

原文への接続では、既知の自己作業の実行記述を`hzfa`へ静的に代入し、脱引用を除いてから、結合した内容を徴候の対象として引用する。機会だけ、障害の漸減だけへ対象を交換しない。さらにこの徴候についての主張自体も、対象が既知の閉じた記述なら静的に特殊化して引用できる。引用することだけでは、記録や能力を実行評価しない。

[一般文書](../examples/v014/clear-indications.noema)は2,277文字、[原文付き草案](../examples/v014/kant-clear-indications.noema)は176,949文字、[抽出文書](../examples/v014/clear-indications-core.noema)は13,505文字である。七定義を追加し、原始記号と著者主張は増やしていない。親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-clear-indications-basis-v1.json)と[検査記録](../reports/clear-indications-v1.json)を保存する。

徴候の真偽の32通りを検査した。原文付き文書と抽出文書で、対象が偽でも徴候がある基準例、対象が真の例、機会の不成立、漸減の不成立、一項目だけの場合、対象の未認識、異なる対象への対応の七条件ずつを検査した。追加15テスト、三文書のCLI解析と構文木の一致、固有文字v2のSVGのXML検査が通過した。SVGの目視確認は含めない。

この構成は明瞭な徴候の一つのモデルであり、知覚や伝聞の形成過程、記録の信頼性、通常語の明瞭さ全体を説明し終えていない。機会の構成は不実行も許される強い読みで、場が開かれつつある変化は未構成である。漸減も件数と段階の強い読みを引き継ぐ。wirの主体は明示した観察主体であり、全人類の認識や集団全員の同意は補わない。著者帰属と全文の意味確認も残る。
