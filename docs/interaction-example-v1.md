# 相互作用を考えるよう促す一文

対象は導入u0003の[210,307)である。

> Man denke z. B. an die elektrodynamische Wechselwirkung zwischen einem Magneten und einem Leiter.

「たとえば一つの磁石と一つの導体の間の電気力学的相互作用を考えてみよう」という、読者への例示的な呼びかけとして読む。実験を実施したという報告でも、読者が既に同意・検討したという主張でもない。本文207の新しい主張は、この呼びかけを著者が提示しているという帰属を記述する。

磁石と導体には、既存の明示した読みを使う。磁石は活動中の外部磁気源、導体は通常の条件で材料を変えず有意な電荷輸送が可能な物体である。種類を固定名だけで済ませず、eic2でeicrとeiciを要求する。具体的な系・単位・場・源条件・導体の基準はeic3の内容内で存在量化し、原文にない数値や特定の装置を固定しない。例の二物体と結合設定の談話上の参照はeisaa/eisab/eisacへ保つ。

相互作用は、一つの結合設定の中で、両物体の電荷・内部電流・磁化や運動と、相手に由来する場への応答を結び付けて扱う関係として読む。eirzはこの一般的な物理モデルへの帰属であり、同じ磁石の場、単位、源条件と、既存の局所作用型eicwの閉じた記述を受け取る。双方の場と応答が同じ設定の部分であることを要求し、無関係な記録の併置や一方向の一力だけから結合を認定しない。

この基礎規約は、二物体の応答の物理的結合を解釈入力として明示するもので、一般の物理モデルを有限検査から発見したという主張ではない。物体全体を一点で代表したり、どの瞬間にも非零の力があったり、両方向の機械力が同時に等大反対向きであったりする条件は加えない。点状担体の局所力を記述する場合にeicwを使うのであり、全微視的機構をその一式だけへ還元しない。

eic4はこの同じ例の内容である。eic5は、同じ論説の読者としての各人がその記述を思考の対象として検討する内容を作り、eic6はそれに指示の力を与える。読者範囲は論説の提示文脈で固定し、検討する状況とは分ける。「考える」を物理的実現、真理への同意、実験実施へ置き換えない。

eic7はeic6の発話を著者rd・論説eirf・提示文脈riへ帰属し、同じeic4を先行箇所の論点の具体例として提示する。z. B.を単に省略せず、先行箇所、例示対象、著者、本文順序を保持する。先行第一文の内容の全体記述はまだ未完だが、どの論点を受けるかは固定原文の範囲で明示してある。例示を唯一性・網羅性・物理法則の証明にはしない。

検査では、発話帰属の本体を実行しても物理設定や読者の検討を評価しないことを確認する。メッセージ自体を別に評価すると指示の力を持ち、同じ例が全読者の検討対象になる。物理設定の接続は分類と結合の境界を明示して引数を対照し、全実数の存在量化を有限例へ置き換えない。
