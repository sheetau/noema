# 功績の下で称える応答と、二つの範囲からの適合

第八段落第一文の `gepriesen zu werden` を、同じ対象・功績についての発話、肯定的評価の表明、その高い程度から構成した。9定義r5x4–r5yeと2基本関係h26nr/nsを追加し、君主の条件と本人の啓蒙への接続を保持する。本文と意味判断の登録は増やさない。

[DWBのpreisen](https://www.dwds.de/wb/dwb/preisen)の語義2は強い称揚を説明し、2bではals等によって対象を何者として称えるかを示す。この箇所では解放の功績をその対象者の性質として述べ、高く評価する読みを採る。事実を肯定文で報告するだけでは足りない。内心の真摯さが欠けるお世辞も表明としてはあり得るが、評価から距離を置く反語や他人の評価の単なる引用を同じものにはしない。受け手の理解・賛同・評判の実際の上昇も成功条件にしない。

功績は閉じた人物性質のNoema記述として渡す。発話における帰属と功績の真理は別であり、功績が偽でも称える発話は可能である。一方、r5ybが再利用するro5の「値する」評価は同じ功績が実際に成立し、非空の全適用基準を満たすことを要求する。ここで応答自体を実行しないので、後代の発話や将来の全員一致は導かれない。

功績の記述を応答の中では実行しないため、応答の引用は段階0で構成できる。既存のo rで功績記述自体を引用し、o aで応答構文へ適用する。新たな名付け関係や高い段階の評価を増やさず、ro5を変更せずに再利用する。同じ真理値を返す別の記述へ適合基準を移さない。

r5ycは現在側と後代側の二つの応答への適合を連言する。話者集団、時代、聴衆を区別し、片側だけへの適合や一つの混合集団の応答で済ませない。両集団の全人物範囲、時代の先後と本文上の基準、具体的な功績と適合基準は次の統合で指定する。

感謝はまだ未構成である。[DWBのdankbar](https://www.dwds.de/wb/dwb/dankbar)は人格的な態度とその表出を区別する補助となるが、恩恵認識だけを感謝と同一視しない。同じ行為者への好意的な承認、間接的な恩恵、現在と後代での態度の範囲を続けて構成する。原刊の第一文全体、良心事項の自由、政府側での最初の解放を省いて完成とはしない。

検査は実際の称揚と引用の脱引用、功績が偽の発話、肯定的報告と弱い賛同の不成立、二範囲と根拠の組合せ、全参照、未知入力を調べる。一般条件の検査だけは既に検証した人物条件と能力の真理値境界を使い、その内部を再計算しない。適合基準の実質的妥当性は有限例から認定しない。
