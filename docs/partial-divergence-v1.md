# 採用された基準と個人の判断の部分的な相違

カントu0015の「vom angenommenen Symbol hier oder da abweichenden Urtheile」について、組織が採用した基準と、同じ論点について本人が判断した内容の相違を記述した。九つの合成定義を加え、新しい原始記号や著者主張は追加していない。これは原文への部分注記であり、教理や判断の意味を説明し終えた記録ではない。

## 内容の相違と両立不能

同じ論点を唯一の引数にして、本人の基準と標準基準を同じ比較状況で評価する。記述の綴りを比較して意味の相違を判定する方式ではない。

| 定義 | 条件 |
| --- | --- |
| rpb | 選択された比較状況のどれかで、二つの内容の真偽が異なる。 |
| rpc | 比較状況が非空で、その全てで真偽が一致する。 |
| rpd | 両側がそれぞれ充足可能でありながら、同時に真になる比較状況がない。 |
| rpe | 同じ人・判断・論点の個人的判断rlgが成立し、その内容が標準とrpbの差を持つ。 |
| rpf / hzgv | 組織が同じ標準基準記述を採用し、選択論点の少なくとも一つでrpeが成立する。hzgvは判断者と判断対象を既存fa・fbへ結ぶ。 |
| rpg | 非空の選択論点の全てでrpeが成立し、組織が同じ標準基準を採用している。 |
| rph / hzgw | rpfに加えて、別の選択論点では本人の判断と標準がrpcの一致を示す。 |

ある状況で内容が異なっても、別の状況で両方とも真なら両立不能とはいえない。また、一方が指定範囲のどこでも真にならない場合も、rpdは成立しない。範囲の選び方・完全性・現実との対応は別に必要であり、この比較を全可能状況における同義性判定とは扱わない。

## 採用と判断の接続

組織の採用関係へ渡す閉じた標準基準記述を、そのまま比較にも使う。値が同じでも別の記述に対する採用へ差し替えない。採用した組織と判断した本人を別の引数として保持し、採用から本人の賛同や基準の真理を導かない。

個人の判断は、既存rlgの非空候補モデルを使う。判断者、判断対象、基準記述、引数列、文脈を結び付ける。判断の候補状況と内容の比較状況は異なる入力であり、判断内容が現在の状況で偽であることも許す。これは誤った判断を記述するための区別であり、認識の正当性を証明するものではない。

「hier oder da」は、少なくとも一つの論点で差がある弱い読みで部分記述する。差がある点の数や割合は確定しない。残りの論点に対する賛同も推定しない。一致と不一致がともに確認されたrphは別の強い条件として用意し、原文に無断で加えない。rpgも選択範囲内の全称であり、教理全体の否認を意味しない。
