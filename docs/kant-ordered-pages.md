# 順序を持つ頁の間の継続

頁は文書内の順序で読む。PDF の頁順に相当する外側の順序を入力とし、本文の項目番号や構文を別に渡さない。各頁の中は上から下へ行を読む。頁末の線の継続口は、次頁の最初の行と同じ規則で照合する。

表示側は円と線を含む行を丸ごと頁へ配分する。頁の高さを超える行を縮めたり切断したりせず、指定不足を報告する。頁の余白や横位置は構文に使わない。復号側は各頁の行を図形の空白帯から得て、文書順に接続し、既存の折返し読取へ渡す。頁境界で変数の束縛、引用、未完の宣言を閉じない。

頁順を表す追加の円記号は設けない。頁の欠落・並べ替えをあらゆる場合に検出するチェックサムではない。継続口の不一致や不完全な構文は拒否するが、完全な独立文だけを削った文書の意味まで元文書と比較できるわけではない。成果物の完全性は、対象項目の構文一致と一覧照合でも確認する。
