# 信念・証拠・出所の共通定義

25の構成定義で、記述を認識していること、内容を信じていること、証拠記録があること、内容が現実に真であることを分けた。[Native本文](../examples/v016/shared-evidence-v1.noema)には、共通の様相4定義と列の所属・重複検査2定義も含む。既存6定義の本体・型・意味規約を保持し、新しい基本宣言は追加していない。各引数の解釈は[意味規約](../data/shared-evidence-basis-v1.json)に固定した。

## 記述の認識と内容の真理

主体の候補状況と、その主体が認識する閉じた内容記述を明示する。認識した記述が非空の全候補で真なら受け入れられた信念、全候補で偽なら否定された内容、真と偽の候補があれば未決定、という読みである。候補集合が空の場合はこれらを成立としない。記述を認識していないことや、解釈が未知であることを否定とは扱わない。

現在の文脈で真か偽かは、候補内での真偽と別に調べる。したがって、主体が受け入れた内容が現在は偽である誤信念を表せる。同じ真偽を持つ二つの記述も、自動で同じ認識の対象にしない。旧認識モデルの読みを一般化したもので、人間の信念の全用法や理解の過程を説明する理論ではない。

## 目撃・伝聞・推論を記録に結ぶ

| 系列 | 本文で結ぶ条件 |
| --- | --- |
| 観察 | 同じ記録・保持者・内容記述・文脈と、同じ保持者・出来事・記述・文脈の観察関係 |
| 伝聞 | 異なる元記録と新記録、両保持者、同じ内容記述、これらを結ぶ伝達関係 |
| 推論 | 結論記録、順序付きの前提記録列、各前提への利用可能性、同じ前提記述列・結論記述・規則・文脈の推論関係 |

これらの関係は明示的な意味入力であり、単に基本宣言を増やさなかったことで社会的意味を還元したとはしない。観察したと記録されていることから、その内容の真理を補うこともない。

推論の記録、論理的な含意、現実に前提が真であることは別条件にした。`evidencepremises`は前提記録列を記述列へ写し、順序を保つ。`evidenceentails`は非空の比較状況範囲で「全前提が真なら結論が真」を検査し、`evidencepremisestrue`は指定した状況で全前提が真かを調べる。空の前提からの推論も明示できるが、その結論の妥当性は別途検査する。

## 有限な依存列と起源

証拠記録を前提から結論へ並べた有限列を与える。各項目の局所条件が成立し、全ての直接の前提が既に認定された場合に、その項目を認定する。列の重複、自己依存、循環、列の外の前提、後に現れる前提を拒否する。空列自体は妥当だが、そこから対象記録の認定は得られない。

`evidenceparents`で、局所条件が使う前提列と依存関係の全体を過不足なく一致させる。観察では空列、伝聞では元記録の一要素列、推論では順序付きの前提列を与える。推論に使った前提を依存グラフから消しても、同じ証拠列が通ることはない。

この検査は、指定した局所認定条件と前提範囲に対する構造的な検査である。局所条件の適切さや内容真理を保証する万能の論理証明ではない。局所推論には、同じ前提記述を用いる推論記録と含意検査を接続できる。判定済みの局所条件は列の構成時に一度計算し、後続の参照のたびに再計算しない。

各記録自身とその前提の祖先を構成し、祖先に結び付く起源識別子を集合として扱う。同じ観察の再伝聞が複数の経路を通っても、同じ起源は一要素である。二つの起源集合が交われば共有起源、双方が非空で交わらなければ別起源とする。同じ内容記述で別起源なら、出所上の別の裏付けと呼ぶ。

別起源は、統計的独立や共通原因の不在を意味しない。起源の同定と網羅性は明示的な解釈規約であり、異なる番号を付けただけでは現実の独立性を証明できない。空の起源集合も別の裏付けに数えない。確信度の加算は行わない。

## 三つの接続例

- [再伝聞](../examples/v016/evidence-relay-v1.noema)：観察記録から二段階の伝聞をたどり、別の保持者・別の記録でも起源を共有することを確認する。
- [別の観察](../examples/v016/evidence-separate-v1.noema)：一方の伝聞と別の観察は起源を共有せず、同じ記述への別の裏付けになる。
- [推論](../examples/v016/evidence-inference-v1.noema)：観察とその伝聞の二記録を前提に推論する。二つの前提が同一起源なので、推論によって起源は増えない。

三例とも内容は現在の状況では偽、主体の候補状況では真である。裏付けがあり、出所が別である例も、現在の真理にはならない。`beliefgroundedtrue`は内容の実際の真理も要求するが、これを知識一般の十分条件とはしない。

観察・伝達・依存・認識・候補・推論・起源は全てNative関数で記述し、外部モデルは個体名と状況名だけを解釈する。一つの文脈で認定関係を比較する例であり、記録の実際の発生時刻や、その後の認識更新を同時に表したものではない。

## 検証と残る範囲

[検証報告](../reports/shared-evidence-v1.json)には、信念128モデル、二記録の依存関係と列順序512モデル、起源288モデル、比較範囲と含意192モデルを記録する。合計1,120モデルで、空集合、循環、反例状況、同一起源、空の起源などを対照する。26件の単枠束縛診断では二値領域の他の引数を固定し、一枠ずつ変える。全引数の組合せを列挙した証明とはしない。三つのNative接続例は各14判定である。

未知の解釈は評価を拒否する。証拠を記録・引用するだけなら内容を実行しないが、内容の真理や含意を調べる場合には解釈が必要になる。論理演算は短絡しないので、最終結果が偽になる条件でも必要な内部入力が未知なら拒否する。

新25語の円文字接続、証拠を受け取った前後の認識更新との接続、情報構造、一般的な同義・多義、学習と第三者読解、二作品全体の新書式化は続く課題である。有限例を全可能状況の証明にせず、知識や証拠の唯一の一般理論を実装したとも扱わない。
