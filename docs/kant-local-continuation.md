# 枝の終端位置に依存しない読取順

`kant-public-fragment-12-local-continuation` は、分岐直後の円で主列と枝を区別する。従来の「最も右まで届く経路を主列とする」規則では、長い枝の全体をまたぐ線が必要になった。局所的な順序に変えることで、枝が主列の終端より右へ続く配置も読める。

## 見える形から決める順序

二円組を一つの核として扱い、文頭から接続をたどる。分岐では、それぞれの経路で最初に到達する主円の中心を比べ、右側の経路を主列、左側を横枝とする。最初の主円のx座標が等しい場合は曖昧として拒否する。後続の枝の長さや、語義上もっともらしい解釈で順序を補わない。最初の主円に達する前にさらに分岐する配置も、この版では拒否する。

枝に割り当てる引数位置、主列と枝の前置文法、枝一式の全消費、語境界、引用と束縛は[部分式の枝](kant-expression-branches.md)の規則を引き継ぐ。読取器は、元の構文木、描画スケジュール、SVG要素の順序を参照しない。

## 描画順

一般部分式の枝がある場合は、枝を先に全部描かず、未完の各経路から次の円を選んで配置する。親を置いたら枝の最初の円を先に置き、その右側に主列の最初の円を置く。それ以降は「現在の終端のx座標＋残る部品数×段間隔」が小さい経路を優先する。この見積もりは、短い経路を早く閉じながら、接続元から長く離れた経路を放置しにくくするための配置判断である。言語上の意味や引数番号を表す数値ではない。

円の段、直角入射、曲げるまでの長さ、許容二円配置、中心線、語内接触の制約は変えない。候補を採用する前に、ほかの未完の経路にも次の円への接続を残せるか調べる。一定間隔の空白でつながる語境界は途中に別の経路を挟まず、後続の空白接続列まで配置候補の検査へ含める。

この配置器では接続先を円に限定する。既存の線へ途中で合流する候補を拒否し、別の接続が増えて構文上の閉路になることを防ぐ。旧生成器の線分岐自体を禁止する変更ではない。

交互配置ができない場合は、同じ部分式枝の従来配置を試す。報告には `interleaved`、`serial-fallback`、一般部分式枝のない `serial` を区別して記録する。復号失敗を理由に配置を差し替えたり、意味情報を捨てたりはしない。

## 検査と残る制約

`scripts/check_kant_local_continuation.py` は小さい対照例と既存40文をSVGから読み、前段で保存した40文のSVGも新しい局所規則で読む。文ごとの処理は入力・実装ハッシュ付きのチェックポイントを持つ。意味判断は、回収した構文の一致と既存の語義・参照規約の不変を確認して引き継ぐ。

この変更で全ての長い接続線がなくなるわけではない。従来配置へ戻る例があり、短い主列を先に置いた場合にも、その主列を越える枝の線は残り得る。入れ子の物理的な枝、同一の核からの複数の引数枝、行・頁の復元も未対応である。文頭の同形反復と語形の単調さを含め、外観の完成判断は別途必要になる。利用者の確認前に固定しない。
