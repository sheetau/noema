# 条件付きの必然性と、候補ごとの将来

カントu0013の「不可能にならざるを得ない」に対して、明示した条件と候補に相対的な必然性の部分草案を追加した。前版では後続時代に改善不能となる状況の存在を記述した。今回は、条件に合う各候補でその結果へ至ることと、一つの候補に結果があることを分ける。

理系の[導出の様相](derivation-modalities-v1.md)で使った`s5k`を、構文木と意味規約を変更せずに再利用した。空でない候補の全てで内容が成立するという構成に、数学や哲学の固有語は組み込まれていない。既存の文系文書にも`s5k`という名前の宣言がないことを確認し、親文書を変更せずに追加した。

| 定義 | 内容 |
| --- | --- |
| `s5k` | 非空の全候補で内容が成立する、理系から再利用した定義 |
| `rjk` | 非空の全候補で、同じ前件が成立すれば同じ後件も成立する |
| `rjl` | 指定候補に、前件が成立するものが少なくとも一つある |
| `rjm` | `rjk`と`rjl`がともに成立する |
| `rjn` | その候補の将来の少なくとも一状況で対象内容が成立する |
| `rjo` | その候補の将来が空でなく、選択した全状況で対象内容が成立する |
| `hzdh` | 適用例のある条件の下で、各候補の後続時代に改善不能となる状況がある |
| `hzdi` | 同じ条件の下で、各候補の選択した後続時代の全状況で改善不能となる |
| `hzdj` | `hzdh`の条件成立を保ち、前件の適用例の存在は要求しない |

例えば、候補Aでは早い時点、候補Bでは遅い時点に同じ結果が起きるなら、各候補に結果の成立点がある。全候補に共通する一つの成立点は不要である。また、一つの候補に結果が成立する時点と成立しない時点の両方があれば、一度の成立は記述できても、全時点での成立とはしない。

前件がどの候補でも成立しない場合、条件式は成立し得る。`rjk`と`hzdj`はこの性質を保つ。適用例のある必然性を述べる場合は、`rjl`を合わせた`rjm`や`hzdh`を使う。前件の実例を原文へ無条件に補わないため、二つの強さを残した。候補そのものが空なら、いずれの全候補条件も成立させない。

適用例だけを確認する`rjl`は、後件の内容を引数に取らない。後件が未知でも、候補と前件から適用例の存在を確認できることを検査する。

候補の選択は基準文脈を引数とする関係で指定し、後件を選択関数の引数にしない。ただし、関係が現実の可能性を網羅することや、選び方が妥当であることまで、この型から保証されるわけではない。後件が真となる候補だけを選んで、現実の必然性を立証したとは扱わない。

将来の関係は、基準文脈・候補・その候補の継続点を組にして渡す。原文側では、継続点が同じ後続時代に属し、既存の先後関係で基準状況より後にあることも要求する。別候補の結果、別の時代、現在の能力不足を将来の結果へ流用しない。時代区分と集団の妥当性は前版の条件で別に扱い、この様相の定義だけで再認定しない。

前版の`hzdf`の宣誓に対し、後続集団を固定した`hzdh`・`hzdi`・`hzdj`を、それぞれ生じさせるという閉じた目的を構成した。因果を表す既存の`hzcq`は、既知の結果を固定して静的に特殊化する。目的を述べる段階では、候補の選定、前件の真理、将来の知識状態、実際の因果を実行評価しない。実例のある必然性を目指すことも、既に実例や達成があるという断言にはならない。

一般検査は、候補・前件・後件・現在の真理による128通りを確認する。候補ごとに成立点が違う場合、一つの候補に失敗点も含む場合、候補の将来が欠ける場合も比較する。原文側は候補・前件・改善不能の64通りに加え、候補の欠落、前件の実例なし、別の時代・文脈・候補、現在だけの結果など9対照例を確認する。未知の関係は空集合や偽に補わない。

[一般文書](../examples/v014/necessary-futures.noema)は637文字、[原文付き草案](../examples/v014/kant-necessary-futures.noema)は132,971文字、[抽出文書](../examples/v014/necessary-futures-core.noema)は10,434文字である。既存1定義を再利用し、新しい8定義を追加した。新しい原始記号・著者主張は追加せず、親文書の宣言と15件の主張を保持する。[意味規約](../data/kant-necessary-futures-basis-v1.json)と[検査記録](../reports/necessary-futures-v1.json)を保存する。

理系の導出様相を含む関連15テストが通過した。三文書のCLI解析結果は構文木と一致し、通常表記・簡略表記・独自文字v2の往復を確認した。抽出文書のSVGはXMLとして検査した。字形の視覚的な確認を行った結果ではない。

この構成はmussの操作的な読みの候補である。原文がどの条件・候補を指定しているか、制度や因果機構が候補をどう制約するか、規範的な禁止や資格の否認、共謀的な含意、著者の主張への帰属は未完である。選択した全将来点での成立も、無限時間の持続や全ての可能世界での論理的必然性とはしない。既存の対応範囲内の解釈を深めたもので、意味確認済み全文単位数は増やさない。
