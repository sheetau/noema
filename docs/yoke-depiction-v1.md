# 自らくびきを脱するという描写

カントの公衆の自己啓蒙を論じる段落には、自分で未成熟のくびきを脱した人々が、考え方を周囲へ広めるという記述がある。既存の伝播候補は知的自立と時間順序を扱っていたが、身体的な装具を脱する描写を保持していなかった。今回、対象側の知的自立と描写側の身体的な除去を、既存の比喩帰属で結ぶ一文を追加した。

原刊483頁の当該句を目視し、固定本文の `[254,315)` と照合した。語義の参考として、[Frühneuhochdeutsches Wörterbuch の joch](https://fwb-online.de/lemma/joch.s.2n)の字義・負担・支配に関わる用法を確認した。字義の首や頭に載る牽引用の枠という説明を、描写の出発点に採る。この歴史的な語義資料はカントの唯一の読解を証明するものではない。[読解記録](../data/yoke-depiction-reading-v1.json)には画像と語義資料の保存先・ハッシュ・採用した対応・留保を残した。

`hzpk` は、同じ身体主体の首・頭側に装着され、牽引を別の荷へ伝える枠状の装具を構成する。枠、部位への帰属、装着、牽引の結合の四条件を共用する。別の装具や別の人の部位を足し合わせても成立しない。木製、二頭一組、現在の牽引や強制労働は追加しない。

足枷を表す既存の定義は足側に限定されているため流用しない。一般の装着 `h2e` と、履歴・変化・本人の作用・行為・状態終結 `rcf` を再利用する。首・頭側の部位、荷重を支える枠、牽引の機械的な結合、物理的な除去への因果関与の四関係には、新しい意味規約を与える。これらも物理学や解剖学の全体系から導出し終えた概念ではない。

`hzpm` は、本人が行う同じ過程で、装具を基準時までに取り外したことを述べる。取り外しの前には `hzpk` の装着状態があり、後には同じ物体が本人のどの部位にも装着されていない。`hzpn` は物体・過程・前後点を存在量化し、人物の性質を作る。

| 条件の違い | この除去の記述 |
| --- | --- |
| 本人の同じ過程で装具を取り外す | 成立 |
| もともと装着していない | 不成立 |
| 首から足へ付け替える | 不成立 |
| 分類が変わっただけで装着は続く | 不成立 |
| 別の人だけが取り外す | 不成立 |
| 他の装具はまだ付いている | それだけでは不成立にしない |

`hzpp` は、原文箇所 `hzpo`、著者 `wa`、同じ段落の提示文脈 `hzp3` を用いて、知的自立の達成 `h4q` と身体的な除去 `hzpn` を `qh` で対応させる。両側は同じ人物を引数に取る。内容を引用したまま扱うため、現実の装具の存在や、二つの内容の真偽一致、二つの過程の同一性は要求しない。

五項目のテストで、四条件の16組合せ、装具・身体・荷の八対照、自己除去の17対照、六つの未知入力、本文全体と最小構成それぞれでの帰属六対照を確認する。身体的・知的な内容の全基本関係を未知にしても、帰属だけを通常評価できる。固有文字を含む往復、原文・資料のハッシュ、既存33文と七単位の確認も検査する。

```powershell
python -X utf8 -m pytest tests/test_yoke_depiction.py -q

```
