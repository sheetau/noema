# 等片道光時間による共通時間の定義

固定原文u0013第四文[822,1070)、181非空白本文文字とA・B・B・Aの四記号を対象とする。直前の「まだ定義していない共通時間」を受け、両方向の光の所要時間を等しいと定義で定めることにより、その共通時間を導入できるという読みを採る。

所要時間は、同じ候補の時間規約・基準系・単位における到着時刻から出発時刻を引いた値として記述する。光の伝播、始終の出来事と場所、時刻値の割当て、実数としての非負の差を別に結び、往路A→Bと復路B→Aの所要時間を比較する。到着時刻同士や距離の等値では代用しない。

両方向で対応する全比較組に等時間の規則を適用する関係型を、定義として採用する対象にする。実際の全試行が済んだことは要求しない。具体的に一つの光が反射して戻る設定は次文で追加されるため、この文に同じ光子や反射を余計な条件として入れない。

定義可能性は、同じ案を採用する可能な結果で、規則が定義上の条件として採用され、その時間規約が新しい論述段階で定義されて両地点に適用されるという構成にする。前二文の局所規則と同じ時計・地点を保持し、地点間の原点の対応を追加できる。等しさを既に測定された事実へ変えず、引用した規則を帰属だけで実行しない。

Die letztere Zeitの照応、nunの論述段階、kannの可能性、indemとdurch Definitionによる手段、著者の主張と本文順序を保持する。manは定義手続きの一般的な提示と読み、特定の第三者や万人の能力を追加しない。未知の割当て・比較組・採用可能性を偽や零で埋めない。第五文以降と段落全体の判断は残る。
