# 改善の不可能性と、その状態を生じさせること

カントu0013の、後続する時代を知識の拡大や誤りの修正ができない状態へ置くという箇所に、部分草案を追加した。前版の情報拡大・誤りの減少を、同じ主体の利用可能な方法と、その想定結果へ接続する。実際に改善していないこと、成功が保証されないこと、成功する可能性がないことを分ける。

| 定義 | 内容 |
| --- | --- |
| `rja` | 利用可能な全方法について想定結果が少なくとも一つある |
| `rjb` | `rja`を満たし、利用可能な方法のどの想定結果でも指定目的が成立しない |
| `hzda` | 同じ開始段階から`ri5`の情報拡大を達成する成功可能性がない |
| `hzdb` | 同じ開始段階から`ri6`の誤りの減少を達成する成功可能性がない |
| `hzdc` | 同じ開始段階から`ri7`の範囲内の誤りの全除去を達成する成功可能性がない |
| `hzdd` | `hzda`と`hzdb`がともに成立する |

例えば、ある方法には情報が増える結果と増えない結果の両方がある。この場合、成功は保証されなくても、情報拡大が不可能とはしない。別の方法で誤りを修正できる場合も、情報拡大と誤りの修正を一つの方法で同時に達成する必要はない。`hzdd`はそれぞれの成功可能性がともにないという、より強い条件である。

評価する目的の前段階は、方法を利用できる開始状況に固定する。後段階には、その方法の想定結果の状況を入れる。真偽を判定する評価状況は前版からの別の引数として保つ。他人の改善、別の開始状況で使える方法、想定結果と無関係な時点での改善を流用しない。

`rja`は評価情報の欠落を不可能性へ変換しないための整合条件である。利用可能だとした方法に想定結果が一つもないときは、`rjb`を成立させない。利用可能な方法がないという完全な解釈を明示した場合は、成功可能性がないと記述できる。利用可能性や結果が未知の場合は、空集合に補完せず評価を拒否する。

ただし、結果が一つあるだけでは、全ての方法・結果を網羅したことにはならない。指定した関係が必要な可能性を十分に表すという前提は残る。有限の例で不可能と判定できたことを、現実や全ての可能状況での不可能性の証明とはしない。

誤りの減少と全除去も区別する。一つの誤りを除けても別の誤りが残る場合には、部分修正は可能で全除去は不可能となり得る。また、元から誤りがない主体は、誤りを厳密に減らすことができない。その事実だけで害や妨害を認定しない。

閉じた`hzdd`の式を、既存の結果生成`hzcq`へ渡す例も構成した。指定した行為者群全員の同じ行為への参加、その行為の生起、同じ結果記述への因果関係、記述した結果の成立を結ぶ。結果が成立するだけ、または因果関係を指定するだけでは全体は成立しない。違う内容・時点への因果や、参加者が欠ける例も区別する。

この因果関係は入力する解釈であり、妨害の機構を発見したり証明したりする処理ではない。既知の閉じた結果に対する静的な特殊化を使い、結果がまだ未知でも、その状態を生じさせることを目的として引用できる。引用の段階では因果・利用可能性・知識状態の真偽を実行しない。一般的な目的の検査であり、原文の世代間の契約や宣誓へ接続し終えたものではない。

一般検査は二つの方法と二つの結果による128通りを集合による独立した計算と照合する。原文側では、方法の有無・結果の有無・情報拡大・誤りの減少・全除去の32通り、別主体・別開始状態・評価状況の違い・危険を伴う方法・元から誤りのない状態を検査する。因果接続は結果と因果の4通りに加え、空の行為者群・非人間・行為の不在・参加者の欠落・別時点・別内容を確認する。
