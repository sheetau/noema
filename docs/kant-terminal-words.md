# 複合語を終端引数として読む

この規則は、引数を取らない複合語を一つの横枝として描く。従来は一核の終端しか枝へ置けず、長い綴りの参照がすべて主列に並んでいた。枝を増やすために構文の順序を変えることはせず、公開された語の型から枝の引数位置を決める。

## 枝に入る語と引数位置

横枝に入る語は、公開辞書に載る無引数語で、綴りの全要素が中円・小円を主円とし、四要素以内のものとする。一つの束縛参照も従来どおり使える。大円を含む語は三段をまたいで継続経路を塞ぐため、現在は主列に残す。引数を持つ部分式や、枝の内部で分岐する構文は対象外である。

引数が二つ以上ある語では、公開された引数型に `situation` があれば最後のその位置を、なければ `floor(引数数/2)` を横枝の位置とする。描画側・読取側の両方がこの規則を使う。実際に渡された引数の形を見て、別の位置を選び直すことはしない。枝へ置けない語は同じ引数順のまま主列に残す。

枝の綴りは接続元から終端へ向かう一方向の連なりとし、全要素を同じ外側の罫線へ置く。複数要素の枝の先頭は接続元より右へ置く。これにより、文頭の核と枝の先頭が同じ左端に並び、どちらも二つの接続を持って文頭が曖昧になる配置を避ける。主列は従来どおり、分岐先のうち最も右まで続くものとして読む。

読取器は枝全体を公開綴りの最長一致で読み、一語を読み終えた位置が枝の終端と一致することを要求する。余った語、途中の分岐、引数を取る語は拒否する。枝の位置はその語の公開型から復元するため、SVGの要素順や描画時の構文情報は使わない。

## 談話の四語の綴り

元の40主張で使う四語に、意味記録を保った短い綴りを宣言した。これは複合語全体の語彙規約であり、部品の単独語の対象を著者や文脈へ置き換える規則ではない。

| 意味 | 綴りの部品 | 保持する区別 |
| --- | --- | --- |
| この文書の著者 | book・aki | 部品の単独語 aki の人物とは同一視しない |
| 段落を提示する文脈 | home・book | 引用された呼びかけの達成状況と区別する |
| 本文上の前後関係 | above・book | 出来事の時間順序や因果関係と区別する |
| 主張内容の著者への帰属 | give・book・aki | 解釈器による内容の真偽認定と区別する |

対応は `data/kant-reference-spellings-v1.json` に記載する。現行の意味基準から必要な継承元をたどり、記載された意味文と型が既存記録に一致することを確認する。既存の公開名と宣言は変えず、従来の完全な綴りも読める。新しい綴りが既存の語を上書きする場合は拒否する。文番号・登録順・ハッシュから字形を生成しない。

公開辞書は schema 2 で、明示した綴りと意味文を含む。本文の主張は含めない。これをJSONから読み直した辞書と円・線だけで復号する。[共有引数](kant-shared-argument.md)の対象にも、この終端複合語を使える。後続の[状況引数の共有規則](kant-shared-context.md)では複数引数の述語も対象にした。

## 確認範囲

[検査報告](../reports/kant-terminal-words-v1.json)では、同じ40主張すべてについて、回収構文が前段の公開名接続結果と一致した。33文に計57本の複合語の枝が入り、合計横幅は261681から229964へ、円数は3589から3285へ減った。これは元の kant-page と同程度の密度を達成したという意味ではない。ほかの長い語形、一般の部分式の枝、接触による合成、行・頁の復号は残っている。

新旧の終端語、引用、共有、禁止円配置、元の流れの読取を含む201件の検査を通過した。比較は `output/kant-terminal-words/index.html`、同倍率の画像はその `inspection.png` にある。語義と参照先を保持した表示変更として扱い、意味モデルの全面再実行は行っていない。
