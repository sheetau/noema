# 要求への適合と、委任経路に基づく権限

要求が履行されていることだけでは、その要求を出す権限の根拠は説明されない。今回は、同じ組織と要求範囲を保った委任経路をNoemaで記述し、既存の要求への適合と独立に検査する四定義を追加した。

## 出発点と、委任できる範囲

`rvi` は、出発点から指定した指揮者までの列を検査する。列は非空で、同じ人を重複させず、最後の人は指定した指揮者でなければならない。最初の人には、委任列の根拠となる権限を要求する。各隣接段階では、前者が権限を委任できることと、前者から後者への委任関係の両方を要求する。

根拠・再委任可能性・委任関係は、同じ組織、集団、受け手、役割、行為、行為記述、肯否、基準文脈へ照合する。根拠が正しくても、一段だけ別人への要求や別の役割を対象とする委任であれば、その経路は成立しない。肯定要求の権限を否定要求へ、自分の権限を別の集団への権限へ移し替えない。

同じ人が直接の根拠を持つ単一要素の列も記述できる。その場合、委任関係を追加する必要はない。反対に、根拠のない循環を出発点の代わりにはできない。反復を除いた経路を使うという表現上の条件であり、現実の組織に循環関係が一つあれば全権限が失われるという主張ではない。

## 各要求記録と同じ内容へ接続する

`rvj` は、同じ指揮者・集団・構成員・計画・基準文脈の選択された各要求記録に、上記の経路を要求する。記録から役割、行為、行為記述、肯否を取り出し、その全てに対応する権限を検査する。記録ごとに異なる有効な経路を指定できる。

`rvj` 単独では、要求が実際にあること、記録が全要求を網羅すること、実際に履行されたことは主張しない。`rvk` は、これらを確認する既存 `rvf` と `rvj` を合わせた内容である。

| 作例の状態 | 要求への適合 `rvf` | 経路の検査 `rvj` | 両方を要求する `rvk` |
| --- | --- | --- | --- |
| 要求が履行され、有効な経路もある | 真 | 真 | 真 |
| 要求は履行されているが、指定経路に根拠がない | 真 | 偽 | 偽 |
| 根拠と委任関係はあるが、途中の人が再委任できない | 真 | 偽 | 偽 |
| 委任が別の受け手を対象にしている | 真 | 偽 | 偽 |

経路に現れる根拠と委任は、全て同じ基準文脈で照合する。過去の任命、失効、撤回、権限の継承などの履歴を、この状態の検査だけで説明したとは扱わない。

## 権限を含む保護条件を別に持つ

`rvl` は、人数基準、全利用可能計画での `rvk`、具体的な共同体の活動可能性と保有を保護する計画の存在を合わせる。保護の介入比較と評価結果の記録にも、同じ権限条件付きの適合内容を用いる。

既存の権限を問わない `rvh` は保持する。接続例では、要求に適合し共同体を保護できるが、指定した権限の根拠はない状態を区別する。カントの「軍隊を手元に持つ」という表現に、ここでの権限条件を自動的に加えることはしない。

## 検証と範囲

[定義文書](../examples/v016/command-authority.noema)は50宣言・本文0文で、新規定義は四つ。[経路の作例](../examples/v016/command-authority-core.noema)は17宣言・2質問、[共同保護への接続例](../examples/v016/command-authority-example.noema)は97宣言・17質問である。

71テストが通過した。根拠・二段階の再委任可能性・二つの委任関係を変える32組合せ、直接の根拠と長い経路、空列・反復・逆順、要求範囲の取り違えを検査した。根拠は一致しても委任先の範囲だけが異なる八つの例も含む。接続例では、要求への適合と権限の根拠を分け、権限を問わない保護が成立しても、権限を含む保護は成立しない場合を確認した。

経路の判定は評価キャッシュの有無でも一致した。通常表記・短縮表記・固有文字の往復、保存文書と検査記録の再現、CLI解析、経路の作例の固有文字SVGのXML検査も通過した。SVGの目視検査は行っていない。

経路の作例では9個体・2状況、接続例では16個体・11状況を使う。接続例は前段の有限モデルへ権限の入力を追加し、実際のNoema定義と評価器で計算する。要求網羅性については、従来と同じ二記述の有限診断を用い、保存文書の全記述域への量化は変更しない。全域の直接評価は拒否する。

```powershell
python -X utf8 -m scripts.compose_command_authority
python -X utf8 -m pytest tests/test_command_authority.py -q
python -X utf8 -m scripts.check_command_authority --verify-only
```

この権限モデルは、明示した根拠と委任関係に相対的である。根拠そのものの社会的承認、法体系や道徳的正当性は別に説明する必要がある。また、指定経路が検査に失敗しても、他の有効な経路が存在しないとは結論しない。

軍隊の軍事的役割、訓練、身体的強制、公的平穏の全体、カント本文の上位主張への接続は残る。今回は原文対応範囲と意味確認済み区間数を変更しない。
