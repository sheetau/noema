# 同じ放射部分の同時断面と体積

u0203の「同体積なら」とu0204–u0205の光の集合を接続するため、同じ放射部分を両座標系で記述する設定を構成した。正本は `examples/v014/einstein-light-region-slices.noema`。既存386主張をそのまま保持し、今回は新しい文全体の意味判断を数えない。

移動球の閉内部をeklw、その逆Lorentz変換をeklxで指定する。eklyは渡された領域の時刻を固定する。新系の時刻零の断面は、旧系の時刻零の断面をそのまま空間変換したものではない。ekl2は既存secfの二乗距離を用いる閉楕円体内部で、球面・楕円体面だけに体積を割り当てない。

一般関係eistmは、選んだ放射部分・波・過程・座標系・単位・全領域履歴の物理的なモデル割当を受け持つ。正弦の瞬間的な節は包絡領域の穴としない。任意のラベル集合の不変性だけで物理的な放射部分と認めない。ekl3は旧新の同じ部分を二領域へ結び、eisqtにより同じ出来事の四座標の変換を校正する。これは仮定可能なモデルの指定であり、閉じた光の集合の保存をこの関係へ隠さない。

ekl4は同じ半径とpiによる既存の体積積分sedpを、この物理的設定へ結ぶ。旧新とも体積単位は同じ長さ単位の三乗である。ekl5の体積比を前提にせず、ekl6の等体積条件とekl7の不等体積条件を別にした。

非零速度でも等体積の特殊例がある。v/V=3/5、方向(a,b,c)=(1/3,2/3,2/3)なら方向は単位長さで、D=β(1−av/V)=1となる。したがって後続の体積式ではS′=Sとなる。u0203の「Dies ist jedoch nicht der Fall」を全ての非零速度・方向で体積が異なると読むと、この例に反する。一般には等体積でないという読みは後続式に合うが、原文の意味判断ではその読みを明示する必要がある。

検査は逆変換の時刻成分、各系の同時断面、閉内部と境界、符号付き速度・零速度、両系への対象帰属、四座標の校正、体積積分の上下端と被積分関数、全18引数の接続を扱う。積分を有限の関数標本で照合する診断は、全実数上の積分定理の証明ではない。検査用のpi=3/4は積分境界を差し替えた標本であり、実際の円周率へ置き換える規約ではない。

残るのは、同じ平均の規約における総エネルギーと平均密度×体積の接続、同体積の反実仮想、球面の全時刻の運動・相対流零・内部生成消滅の条件からの同じ光の集合、帰結と言換えの提示、新系エネルギーの問いである。有限球内の瞬間総量を説明なしに周期平均へ替えない。
