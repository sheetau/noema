# 五つの等式と物体・出来事・基準系の接続

M0390の式だけを表す`sens`と、必要な三偏微分を結ぶ`sent`に、同じ物体・出来事・基準系への参照を接続した。数値だけが一致する別の対象の量を使っても、式の参照関係は成立しない。

| 定義 | 記述する条件 |
| --- | --- |
| `senu` | 同じ物体・出来事・文脈における新旧の規格化密度と三速度成分、その地点と二系の配置、新系の電場の割当 |
| `senv` | `senu`と、同じ値・場・地点を使う五つの等式および三偏微分`sent` |

新旧の物理量の割当は、物体・系・出来事・密度・三速度成分・文脈を引数に取る関係として明示した。地点の割当には既存の`zpb`を使い、同じ物体と出来事を参照する。新旧の四座標は既存の`s46`で結ぶ。同じ出来事は両系で同じ時刻になるとは限らず、時刻の一致で出来事の同一性を代用しない。

新系の電場は、系・電場関数・領域・文脈を結ぶ関係引数で指定した。式が使わない旧電場の方程式や磁場を、接続の前提に含めない。`senu`は参照先の整合条件なので、電場の微分表も五つの等式も要求しない。`senv`で初めてそれらを同じ引数へ結ぶ。

二系は標準配置の順序付きの組であり、符号付き速度と正のβを保持する。任意の原点移動を含む一般の座標対応へ拡張したものではない。規格化密度が零または負の値を取る例も扱う。形式的に分母が非零の速度入力を受け付けることは、その運動が実際の荷電物体に可能だという物理的な認定ではない。

検査では、三つの基準系速度、三つの密度、三つの物質速度を組み合わせた27例を用いた。帰属関係については40の対照例を作り、物体・出来事・系・地点・密度・速度成分・文脈・電場の割当が違う場合に、単独の数式が成立したまま接続条件だけが不成立になることを確認した。

この40例には、地点の割当関係が正しいと解釈されても、新旧の座標変換が合わない四例を含む。これにより、座標の検査を地点への帰属の検査で代用していないことを確認した。さらに、対角微分の値を相殺して和を保つ例と、一つの微分が成立しない三例では、参照関係と数式の和が成立しても、実際の三偏微分への接続が成立しない。必要な偏微分は新電場の三つだけである。

帰属関係や偏微分の解釈が与えられない場合、数値の一致から補わず評価を拒否する。有限検査の電場はアフィン関数であり、関係引数には明示したテスト用の解釈を与えている。この結果は、現実の物理的な帰属や任意の実関数を検証したものではない。

[前版の確認記録](../data/density-formula-review-v1.json)は、その検査時点の記録として保持する。今回、式の参照を結ぶ条件は追加したが、原文の`wobei`による導入と著者の提示、基準系・速度・規格化された電気密度の共有された意味規約、単位全体の意味確認は残る。二つの定義を追加しただけで、意味確認済み単位へ昇格しない。

原始概念と著者主張の追加はなく、親文書の宣言と174件の主張を保持した。全文草案の代用文字による長さは322,165文字から324,042文字へ増えた。今回の差分は1,877文字であり、全文草案には累積した定義が含まれる。この値は一文の翻訳長や固有字形の見た目の長さではない。必要な定義だけを抽出した文書は9,313文字である。

成果物は[原文付き草案](../examples/v014/einstein-density-referents.noema)、[抽出文書](../examples/v014/density-referents-core.noema)、[意味規約](../data/einstein-density-referents-basis-v1.json)、[検査記録](../reports/density-referents-v1.json)に保存した。既存の数式内の接続を精密化したため、原文の対応範囲や数式要素数は増えていない。
