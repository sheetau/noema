# 応答傾向の伝達・取得・持続

理由ある自己評価と、全ての人が自ら考える課題を認める判断を、場面ごとの応答傾向へ接続した。その性向の記述を、伝達を受けた人の取得と、取得後から基準時までの持続へ同じまま渡す。新しい基本関係は追加せず、既存の評価・伝達・変化・持続の定義を組み合わせる。

## 現在の一回の判断と応答傾向

`hznw`は、同じ本人と評価時点について、指定した場面の応答を既存`rqb`で評価する。場面は非空で、過不足なく一度ずつ列挙され、全て評価済みで正の重みを持つ。応答した場面の重みの合計が、全体の重みと指定閾値の積以上であることを要求する。閾値は0より大きく1以下とし、特定の数値を原語の意味に固定しない。

場面には仮定場面も使える。評価時点で実際の判断をしている必要はなく、逆に現在の一回の判断だけから他の場面での応答を推定しない。場面・重み・閾値を事前に選ぶことと、それが本人の状態を適切に評価できることは解釈上の条件であり、構文検査だけでは証明できない。

`hznx`は応答関数と五つの評価条件の閉じた記述から、性向を表す記述を組み立てる。評価条件を含む同じ記述を、後の状態評価と因果の目標へ渡す。状態だけ同じ真偽を返す別の評価基準へ、原因の記述を無条件に流用しない。

`hzny`は応答の内容を、前段の理由ある自己評価と規範承認`hznv`へ接続する。各場面で同じ本人の両条件を要求する。自己評価が成立する場面と規範承認が成立する場面が完全に分かれている場合、両方を備えた応答に数えない。

規範を認める判断と、その規範が実際に成立することや本人が思考を実行することは引き続き区別する。今回の性向は、指定範囲での応答を用いた操作的な読解候補である。有限の場面で成立することから、生涯の性向やGeistの全ての意味を確認済みとはしない。

## 伝達による取得と、その後の持続

| 定義 | 要求する条件 |
| --- | --- |
| `hznz` | 同じ提示行為の受領・理解と、その行為による受け手の状態取得 |
| `hzoa` | 有限の伝達経路と、その最後の送信者・活動による最終受け手の取得 |
| `hzob` | 同じ取得に加え、取得完了から基準時までの全履歴点での状態の持続 |
| `hzoc` | 固定した想定読者のうち、取得と持続を満たす人の正確な範囲と、指定した広がり |

状態は受け取った記述から直接評価する。以前の、自分の状態を好ましく受け入れる`hzni`へ置き換えない。これにより、本人だけの自己状態への好みへ、全ての人についての規範承認を縮めてしまうことを避ける。

同じ状態の不成立から成立への変化を既存`rqte`で確認し、最後の受領行為が同じ変化過程の部分で、同じ状態を生じさせることを要求する。単に受領と判断が同時に起きただけでは足りない。発話内容と取得する性向は別の記述であり、発話の真理や発信者・全中継者の賛同は追加しない。

持続には既存`raf`を使う。取得完了と基準時の両端だけでなく、その間の同じ履歴の全点を調べる。一度失ってから基準時までに取り戻した場合は、取得自体を認めても、この期間の持続とは認めない。取得時点が違う複数人についても、それぞれの終点から同じ基準時までを調べる。

## 検証と原文上の位置

7テストで、次を確認する。

- 応答と閾値の12組合せ、範囲の9対照、不正な閾値3例と未知入力5例。空・重複・欠落・余分な場面、未評価、非正の重みを拒否し、列挙順の変更を許す。
- 伝達・原因・取得・持続の23対照。直接受領と中継の肯定例、持続の否定例をメモ化なしでも照合する。途中で失い、最後に回復した例も区別する。
- 自己評価と規範承認の定義を実行する8対照。応答傾向が真で現在の判断が偽になる例、別内容への原因、別々の場面にしかない判断を検査する。未知の規範の真理や思考の実行は評価しない。
- 想定読者の18対照。以前取得していても失った人を、持続している取得者へ数えない。実際の受領者に合わせて想定読者の範囲を狭めない。
- 九つの未知入力、引用階数、通常・短縮・固有文字の往復、既存の意味規約・32文・七単位の確認の保持。

七定義を追加した。一般形は既存の依存定義込みで1,500文字、累積本文への追加は2,014文字である。

対応は、前段のカントu0011の333–421という既存範囲に対する部分構成である。新しい原文範囲や意味確認済み単位は加算しない。適切な価値基準・評価場面、心理的な性向の成立根拠、周囲という社会的範囲、将来の様相と著者帰属への全文接続は残る。
