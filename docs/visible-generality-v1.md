# 総称・程度を含む円文字辞書第7版

[総称と質的程度の23定義](shared-generality-v1.md)に共有の綴りを与え、円文字で読み書きできるようにした。第7版は199語で、30の単独語と169の複合語、21の基本宣言と178の構成定義からなる。第6版の176語を保持し、新しい基本字形・基本宣言は追加していない。

綴りは[公開資料](../noema/resources/visible-generality-vocabulary-v1.json)に固定する。通常事例の群はbird、尺度と判定の群はaboveから始まる複合語とした。これは語を覚えるための命名規約であり、部品の語義から新しい語の意味を自動計算する規則ではない。語の意味は共有定義・型・役割の規約から読む。同じ版番号で意味や綴りを変えた辞書は拒否する。

## 本文に条件を記述する四例

| 可視例 | 本文に含める関係と確認する区別 |
| --- | --- |
| [通常事例と例外](../examples/v016/visible-generic-exception-v1.noema) | 二事例の範囲、第一を優先する通常性、第一だけが満たす応答。総称は真、全称は偽、第二は例外 |
| [種類別の総称](../examples/v016/visible-kindwise-generic-v1.noema) | 二種類を合わせると総称は真になるが、各種類を別々に判定すると第二の反例を隠せない |
| [程度の判定基準](../examples/v016/visible-degree-standards-v1.noema) | 低・中・高の順序、肯定域は高、否定域は低。中は境界にあり、低より高く、中以上という目的基準を満たす |
| [様相の中間値](../examples/v016/visible-modal-degree-v1.noema) | 二つの候補状況の一方だけで成立する内容を中間値へ対応させ、最低・最高値への割当を拒否する |

範囲・順序・応答・判定域は、本文のlambdaと同一性・論理演算で構成する。共通の関数は一度作って呼出しへ渡し、本文を省略した測定関数や外部判定コールバックで補わない。四例の宣言は全て定義である。具体的な鳥や人についての経験的な主張ではなく、明示した条件を持つ事例の検査である。

三つの尺度値を使う例でも、全ての変数の束縛を復号する。評価は三個体・二状況の領域で本文の全量化をそのまま実行する。相異なる値を要求する前件が実際に満たされる割当を含み、順序を反転した本文では主張が偽になる。小さすぎる領域で前件が一度も成立しないため真になる検査ではない。

## 復号と互換性

[検証報告](../reports/visible-generality-v1.json)には、新23語の型付き呼出し・引用、語彙文書と四つの意味例の図形復号を記録する。SVGの円と線から戻したASTを正本と比較してから意味を評価する。型付き高階呼出し・引用の往復は構文の検査であり、全ての関数値を列挙して意味を証明したものではない。

```powershell
python -X utf8 -m scripts.visible_generality_page render examples/v016/visible-degree-standards-v1.noema output/visible-generality-library-v1/degree-copy.svg --width 4800 --public-names
python -X utf8 -m scripts.visible_generality_page decode output/visible-generality-library-v1/degree-copy.svg --native --public-names
```

可視ヘッダーで第1〜7版を区別する。旧版の局所名が新しい共有語と同じ綴りでも、旧文書は旧版の意味で読む。以前の描画器・証拠・固定字体は保持する。字形768・図形4096・行128など既存の上限は変えていない。

有限例の図形復号は、実際の通常性や尺度・判定基準を選ぶ根拠の検証とは別である。画像OCR、第三者の学習と読解、二作品全体の新書式化は残る。総称を多数決へ、境界を未知入力へ読み替えないというNative側の意味規約も維持する。
