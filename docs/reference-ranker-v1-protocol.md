# 公開資料で学習する共通の参照判定器

原文位置を保つ`AlignedJapanesePAS`を固定し、KWDLCの公式学習3,915文書から共通の参照判定器を学習する。モデルの重みは変更せず、語や概念ごとの出力クラスも作らない。推論時に例文や語句の表は参照しない。

候補は、予測された各基本句主辞について、それ以前の全ての基本句主辞と「文書内の先行対象なし」である。名詞表や代名詞表による候補制限はしない。後方の対象を先行する語から直接指す代わりに、後の語から同じ対象へのリンクを作る。最終的な同一性グループは採用したリンクの推移的閉包とする。原文解析・候補スコア・採否を保持する。

固定モデルのトークン文脈ベクトルと照応logitを、一度だけ原文から抽出して保存する。主辞ベクトルと基本句内の平均ベクトルはL2正規化する。モデルの文書内候補logitと、外界・NULL・NA候補の最大logitとの差を用いる。ROOTは非参照候補に混ぜない。差には符号付きlog1pを適用する。さらに主辞同士と基本句同士のcos類似度、正規化した語位置間距離、先行対象なしのフラグを使う。

比較は二方式に固定する。線形方式は上記5特徴からスコアを出す。文脈方式は主辞と基本句の結合ベクトルを共有の64次元tanhへ射影し、候補の両側・要素積・差と5特徴から64次元tanhを経てスコアを出す。語彙数が増えても層や出力クラスは増えない。

監督信号は前回と同じ、明示的な文書内の同一参照`=`・`=構`・`=役`である。モード付き同一参照を持つ文書は今回の単純な参照グループでは学習せず、未対応として記録する。予測主辞が正解範囲と一致しない場合は、その主辞の損失を無視する。正解の先行対象があるのに、候補のどれも正解範囲へ一致しない場合も損失から外し、欠落件数を報告する。先行する正解対象がない場合は「先行対象なし」を正解とする。複数の正解先行対象がある場合は、その確率の和の負の対数を最小化する。

seed17、AdamW、学習率0.001、重み減衰0.01、文書16件のバッチ、20エポックに固定する。エポックごとにseed17から再現可能な文書順へ並べ替える。各バッチでは、監督信号がある主辞の損失の平均を用いる。推論では候補のargmaxを使い、後から閾値を調整しない。

方式とエポックは公式dev512文書の参照ペアF1で選び、同率なら監督信号の平均損失、さらに同率なら先のエポック・線形方式を優先する。分母は元の注釈に基づき、予測から欠落した正解主辞・参照を評価から取り除かない。全体・正解ペアあり・なし・未対応注釈の内訳を報告する。主辞集合も含めた一致と全文意味構造の一致は区別する。

選択済み重みを保存した後に公式test700文書を評価する。既知の学習本文重複1文書は明示し、重複を除く集計も別に示す。KWJA自身もKWDLCを利用していることを維持して報告し、完全に未知の文章全般への性能とは呼ばない。以前の手書き参照12文は回帰確認に使い、選択条件に使わない。

特徴の抽出は文書ごとに原文・モデル・コードのハッシュと対応付ける。中断後は既存ファイルを検証して続行できるようにし、欠けたファイルや不一致を成功扱いしない。解析不能・未対応注釈・候補欠落を区別して保存する。小さな固定特徴からの再学習、保存重みの原文推論、生成・辞書禁止経路0回を検査する。完成条件の全文意味構造95%、広い日英翻訳、逆変換、文字数の課題は維持する。
