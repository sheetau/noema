# 一歩の接地更新と、装置外への着地を構成する

「一歩も許されない」の対象を記述するため、身体の足が一回の接地更新を行い、その着地点が装置外にあるという目標を加えた。前段の候補全体の無許容へ、その閉じた目標関数と順序付き引数を渡すこともできる。許容の検査と、実際に一歩を行ったかの検査は分離する。

[AdelungのSchritt項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_7_2_2862)は、足を前へ置いて移動する動作、距離の単位、歩き方としての用法を分けている。今回は足による身体移動の一回の接地更新という通常の型を構成する。辞典は語義選択の参考であり、以下の接地モデル全体を辞典が定義したものではない。取得した本文・元HTML・文字コード・ハッシュを[出典記録](../data/grounded-step-evidence-v1.json)へ保存した。

## 同じ足・移動過程・時間範囲を保つ

一般定義 `rqzb` は、同じ部位が異なる二位置で接地し、その間では接地を離れていることを表す。時間履歴は厳密な順序を持ち、過程範囲は履歴内で欠落がなく、指定する始点と終点を両端に持つ。厳密な中間時点が存在し、その全てで同じ部位がどこにも接地していない。途中の再接地を含む二回の更新、接地したままの滑走、位置が変わらない足上げ、都合のよい中間時点だけを除いた範囲を区別する。

`rqzc` は同じ範囲の全時点で、移動している足とは別の、その同じ身体の足が地面側に接していることを要求する。足の所属と接触を同じ時点に結び、別人の足を支持側へ流用しない。接触から荷重の数量や身体の均衡まで推論しない。身体の全足が離地する型は、今回の通常歩行の候補と分かれる。

`rqzd` は両方の一般形を、同じ身体・足・移動過程へ接続する。身体が脚で移動しており、同じ過程が生起して前後状況を結び、身体と足がその同じ変化を受け、足は過程全体でその身体に属していることを要求する。既存の移動 `zai`、生起 `dg`、状態移行 `ag`、変化を受ける対象 `la`、履歴 `ia`・`ic`、全過程の範囲 `h4x` を再利用した。

追加する関係は、脚の末端で接地を担う部位の所属 `hzxw`、身体部位と地面側の接触 `hzxx`、その部位の位置変化が同じ過程を構成するという `hzxy` の三つである。最後の関係により、その過程が足の別の性質を変える一方で、位置だけは別の過程で変わる場合を区別する。「Schritt」という語そのものの判定器は追加しない。足という部位分類と接触の基本規約は公開するが、解剖学・接触力学の全説明を完成したとはしない。一般形は関係を引数で受け取り、カント固有の参照を持たない。

## 装置外の目標を、許容の対象へ渡す

`rqze` は、同じ移動過程の終端で、同じ足の位置が指定装置の外部 `qv` にあることを加える。内部でないだけの境界位置では足りない。また、身体の中心や反対側の足が外部にあるだけでは、この足の着地点を外部と認定しない。装置外で既に歩いている場合も含められるよう、始点が内部であるという条件は付けない。

`rqzg` は、身体・装置・足・移動過程の四引数をこの順序で取り、評価時点を終端とする `rqze` を目標内容にする。四位置の取り出しには既存の列の畳み込みを使い、全個体領域から四つの引数を組合せ探索しない。空・不足・余分な列を受け入れず、足と身体、装置と過程を交換した列も区別する。

`rqzh` は、前段の `rqy6` へこの閉じた目標関数と候補別の四引数列を渡す。名宛人と身体、指定装置と第二引数が一致することも検査する。目標は引用されたままなので、足の所属・接触・移動が未知でも、その目標に対する許容の有無を調べられる。候補が許容されないことから、現実の不実行、禁止命令、身体的不能や勇気不足は導かない。

## 検証と残る接続

五テストで、接地・離地・位置差・範囲の32組合せ、時間順序の二対照、未知入力五種を確認した。身体・足・過程・着地点の23対照、四引数列の六対照、許容と引数不一致の八組合せも確認した。23対照には、足の位置差が単に同時発生する場合、別の部位だけが移動過程に結び付く場合、別の終点に結び付く場合も含めた。身体側の定義と目標関数を実際に評価し、検査用の真偽値で置き換えていない。一般形と基準例は通常評価でも確認し、構造の大きい対照では純粋な計算結果を再利用する。三記法の往復、既存47文と十一単位の意味依存関係も保持する。

今回の型は、足を滑らせる歩き方や片足跳び、全ての階段・不整地・補助具利用を網羅しない。また、意味上の完全な履歴を指定することと、有限の観測点で現実の全中間時点を確認することは異なる。通常の一歩の構成候補として扱う。

原文への採用には、さらに「勇気を伴ってこの目標を試みる」内容を許容の対象へ結ぶ必要がある。現在の `rqzh` は一歩そのものを目標内容としているため、そこを同一視しない。候補範囲の指定、先行する阻止と同じ時点への結合、比喩としての提示、`ruhigen` と `ja`、一文全体の照合も残る。今回は比較構成として保存し、採用中の本文と確認済み分量を変更しない。

