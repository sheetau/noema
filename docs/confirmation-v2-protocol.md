# 確認評価v2の固定条件

v1の不合格を受けた一般的な文型の追加と未知概念の範囲学習について、別の新規事例で確認する。v1の資料と結果は保存し、以後は回帰検証として扱う。v2は同じ人工文作成方式の別サンプルであり、新しい構文領域や利用者の自由記述への汎化を証明するものではない。

## 候補と選択

候補はcorpus-v7で30エポック学習するXLM-RとMiniLMの2個に限定する。エンコーダーは固定し、共同役割割当てv1を使う。チェックポイントと閾値は開発用データだけで決定し、言語別の選択は既存の選択スクリプトと同じ条件に従う。v2の予測を取得する前に、選択済み重み・閾値・資料・本条件のハッシュを記録する。開発用条件を満たす候補がなければ確認評価を行わない。

## 資料

- 基本の15概念による単一出来事・状態を対象とする。6述語それぞれ50種類、合計300種類の意味構造を作る。日英各2表現、対応範囲内は各言語600文とする。
- 乱数種は91028。作成方式はv1と同じで、主題・態・場所句・時間句の順序を変える。学習に含まれない概念の組合せを用い、学習・開発・既存回帰・v1と完全一致する意味構造は除外する。既知の構文で新しい数量や名前などを組み合わせる条件である。
- 名前はLewis、Eva、Nina、Kenji、Samira、Leon。数量は11、19、37、73、512、4096。数量なし、主体なし、肯否、相対時間も作成規則の範囲で含め、最終的な構成数を記録する。
- 未対応は未知概念・複雑な量化・入れ子の作用範囲・複数出来事・様相・質問を各言語12文ずつ、計72文とする。未知概念は狼／wolf、栗鼠／squirrel、ハムスター／hamsterで、学習した未知概念とは分ける。
- 全注釈の内部整合性、以前の入力との重複、モデルを実行する前の代表文と意味の対応を点検する。修正が必要な場合は草案と修正理由を保存し、予測取得後には正解や文を変更しない。

## 判定

日本語と英語のそれぞれで、確定率80%以上、確定出力の意味構造完全一致率95%以上、未対応の誤確定率5%以下を維持する。どれかが不足すれば不合格とする。同義グループの一致、文型別の成績、モデルと実行環境、反復・単独／一括推論の一致も記録する。評価時には学習、閾値の再校正、モデルの再選択を行わない。

v1から改善を重ねた後の確認であることを結果とともに報告する。v2の結果を参照して再び改善する場合は、v2も回帰資料へ移す。人工文で条件を満たしても、文語0.3全体の解析、未知の自然文全般への対応、文字の人による識別性を検証したことにはしない。
