# 通過した電位差と獲得速度

原刊920–921頁の第二項u0269–u0270を対象とする。運動エネルギーの導出から、電子が通過した電位差と獲得速度の間に成立すべき関係を述べ、P＝∫X dx＝(μ/ε)V²{1/√(1−(v/V)²)−1}を表示する。印刷の二つの等号、符号付きε、μ、平方根と逆数を保存する。

前段と同じ原点・初速零からの軸上静電加速として読む。eouが電子・実軌道・実電場・低速質量・非零電荷を共有し、er4が同じ仕事と電荷の校正を電位単位へ結ぶ。単位尺度は正で、電位尺度×電荷尺度＝エネルギー尺度、速度尺度×時間尺度＝長さ尺度を満たす。追加基本関係eis4fは仕事/電荷という物理的な単位校正だけを担う。

er6は開始と終了に加えて全実軌道のx位置を含む閉区間を使う。区間上の全二点で電位差を同じプロファイルの有向積分に結ぶ既存seuwを再利用し、区間全体を同じ物理的静電場の領域へ接続する。往復や途中の逸脱を、端点が合うことだけで省略しない。Pは初期電位−終端電位であり、電位の加法定数は自由。負電荷の加速に負のPを許す。

er7で同じ積分から仕事＝εPを得る対応を共有し、esaで既存seurと印刷された右辺を結ぶ。esdが両等号を合わせる。eseは先行ep7の導出・閉収支・無放射・運動エネルギー最右辺に同じ通過電位の対応を結ぶ。M0427中間積分に欠けるμを補わず、その印刷項を新しい物理前提として使わない。

esfは列挙第二項、運動エネルギー導出への照応、folgtとmußの推論上の必要性、直後の表示を接続する。esjはPという呼称と全等号列を保持する。著者がこの設定で成立すべきと述べる内容であり、処理系が物理的真理を証明したという主張ではない。

検査は符号・非単位質量・静止・誤った値、同じ電子と各単位の接続、仕事/電荷の尺度、区間内部の実場と途中の軌道逸脱、本文の照応・引用を対照する。既存の全多項式係数による電位・向き付き積分の検査は固定証拠を再利用する。全実数・全関数域は有限評価で認定せず拒否する。局所検査を原文全文の意味判断へ自動変換しない。
