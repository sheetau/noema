# 時間範囲での持続と、状態に対する態度

[時間範囲と持続の定義](../examples/v014/persistence.noema)を、既存0.14の関数・量化・命題内容から構成した。ある状態が続くこと、その状態を本人が好ましく受け入れること、そのような人々の割合を分けて記述する。新しい構文や生成処理は使用していない。

## 順序と途中の状態

taは、指定した履歴が空でなく、その履歴内の先行関係が非反射的・推移的で、異なる二状況の前後を比較できることを要求する。循環した先行関係や、前後が決まらない二状況を同じ一本の時間的履歴として受け入れない。

tbは、評価範囲が履歴の空でない部分集合で、選択した二状況の間にある履歴内の状況を全て含む条件である。例えば履歴が「初期・中期・終期」なら、初期と終期だけを選んで中期を隠すことを拒否する。開始・終了の時刻や数値的な長さは、この条件からは決まらない。

tcは、評価範囲の全状況で指定した内容が成立するという持続の条件である。初期と終期の状態が同じでも、中期で異なれば成立しない。空の評価範囲でも成立しない。履歴自体から観測していない中期を省いた場合まで自動検出できるわけではなく、履歴の完全性と状況の粒度は解釈の前提として残る。有限モデルの検査を現実の連続時間全域の証明とはしない。

## 好ましく受け入れることは別の条件

tdは、全評価状況で、その人が指定した性質の記述に該当する自分の状態を好ましく受け入れているという条件である。性質は型付きの式記述で渡す。同じ真理値を持つだけの別の性質を、態度の対象と勝手に同一視しない。

この態度から、状態が実際に成立すること、本人が自由に選んだこと、強制されていないこと、その好みが継続の原因であることは導かない。tcとtdは独立しており、両方を記述したいときに結合する。一般定義では内容と記述を別に渡すため、その対応は呼出側で保持する。

## カントの割合表現への接続

[更新草案](../examples/v014/kant-lifelong-state.noema)のieは、既存の未成熟bfを使い、同じ人の同じ時間範囲について次を結合する。

1. 履歴内の空でない、間の抜けない評価範囲がある。
2. その範囲の全状況でbfが成立する。
3. その範囲の全状況で、その人が同じbfの記述に該当する状態を好ましく受け入れる。

ifは、前回の割合表現hqの性質引数へieを渡す。「人々のこれほど大きい割合」と「好んで生涯、未成熟に留まる」の二つの部分を接続した。具体的な人数、比率、過半数という閾値は補っていない。igは具体的な比率を渡して条件を検査するための形である。

iaは人物と文脈に対応する履歴、ibはその生涯として評価する範囲、icは文脈上の先行関係、idは状態への肯定的な態度を表す基本関係である。順序と範囲の整合性は定義から検査するが、生涯の選定や好ましく受け入れることの一般的な心理理論まで定義済みとはしない。

原文の「gerne Zeitlebens」を、文脈上の生涯の範囲における持続的な状態と態度として読む候補である。出生から死亡までの全瞬間の気分を主張すると決めつけず、範囲と粒度を前提として明示する。既存の能力の読解も引き継ぐ。原因、自然による先行する解放、「それでも」の譲歩、後見人が現れる容易さは未接続であり、段落全体の主張を追加したものではない。全文確認済み単位数はカント0/20・アインシュタイン0/282のままである。
