# 集団の発展と、後の原則置換の因果条件

前段では原則の内容・採用・履行・置換を分けた。今回は、同じ集団の発展が民衆側の変化と、その後の原則置換に作用するという部分的な条件文へ接続した。原則が前後で変わることと、その変化が集団の発展に依存することを別に検査する。

集団の前件には、前段と同じ人々と同じ発展の読みを用いる。政府側の因果条件でも、人々を変数に対応させる関係、変数一覧、方程式、観測割当て、履歴を共有する。政府側だけで別の原因集団や都合のよい履歴を選び直さない。

| 定義 | 内容 |
| --- | --- |
| `rx4` | 非空の原因側の人々を完全列挙し、各人を相異なる宣言済み変数へ結ぶ |
| `rx5` | 観測で結果が成立し、全原因をまとめて偽・真に固定した両側の全解で、評価済みの結果が偽・真になる |
| `iaschecked` | 同じ履歴に後の政治的終点があり、原則の内容差と、旧新原則の前後の要求を評価できる |
| `iaseffect` | 同じ解の始点と政治的終点で、同じ規範源・主体・職務に対する旧新原則の置換を評価する |
| `iascausal` | 同じ集団の発展の内容とモデルの変数を各解で照合し、原則置換への`rx5`の依存を要求する |
| `iasschema` | 集合的な条件文の後件へこの因果条件を追加し、後続の未記述内容へ同じ関係者と時点を渡す |

原則置換は前段の`iarreplacement`を実行して確認する。旧原則への要求が消え、新原則への要求が生じ、同じ比較状況で両内容の真偽が異なる実例が必要である。「政府が変わった」という未定義の真偽値を、結果として渡してはいない。構造モデルの解に対応する各時点から、既存の要求関係`h7k`を評価する文脈へ接続する。

負の結果を認める側にも評価条件がある。旧原則が残っているため置換が不成立になる場合でも、新原則への要求が評価済みであることを先に確認する。未評価を、変化なしの根拠にはしない。両介入側には少なくとも一つ解があり、全解で同じ結果と評価条件が必要になる。解のない側や、結果が分かれる側を依存の証拠にしない。

政治的終点は、同じ履歴の中で民衆側の変化の終点より後に置く。因果モデルの原則置換に使う文脈と、履歴の時点を対応付ける。単に二つの文脈名が異なることから時間的先後を導くことはしない。ただし、この時間関係は原文の「endlich」に対する候補である。両過程の開始時刻や、過程が重ならないことまでは要求していない。

政府側の変化には、全原因をまとめた介入への依存を要求する。各人が一人ずつ必要であることは要求しない。また、民衆の態度を必須の媒介として政府の変化へつなぐ条件も加えていない。原文は同じ発展が両方に作用すると述べるため、両結果の間の因果経路まで今回の接続で確定しない。

有限検査のモデルでは、二人の発展、民衆の応答傾向、行為選択の拡大に加えて、原則状態に対応する変数を用意した。その変数から前後の要求文脈へ接続し、実際のNoemaの条件付き原則と置換を評価する。変化する基準例に対し、集団が発展しなくても原則が変わる例では、置換自体は成立したまま因果条件が不成立になる。原則を置き換えず追加する場合、別の主体への要求しかない場合、後の時点がない場合も区別する。この原則内容は構造の検査例であり、尊厳の意味を代用するものではない。

48テストが通過した。診断には明示的な短絡評価と、純粋で外延的な解釈向けの関数再利用を用いる。再利用なしとの比較は一般条件の基準例について行う。長形式・短縮形式・独自文字の表記往復、三文書のCLI解析、抽出文書のSVGのXML構造も確認した。これらは原文との意味一致や字形の目視検査ではない。

政府という組織と当該共同体の統治関係、具体的な旧新原則、自らにとっての有益さ、人間と機械の対比、尊厳に即した扱いは未記述である。旧原則の廃止と新原則の採用は「原則への作用」の一候補であり、原文がその置換を明示したとは扱わない。記述の名前や未充足引数を付けたことを完成に数えない。
