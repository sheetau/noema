# 第三文の依存群：国外への広がりと障害への格闘

r57aは、同じ元と先の統治圏、元の人、国外の取得者、自由への態度の基準を固定した到達・保持の内容である。仮定状況ごとに、その状況の経路証人、履歴、順序、当事者・活動・過程・時点をr56xへ渡す。現実の一経路を全ての候補へ固定すると、別経路で到達する候補まで失敗にしてしまうためである。供給する証人は、その候補で到達が成立するならそれを示せるものとする。この充足性は解釈入力に課す条件であり、有限検査で全可能経路を探索したと主張しない。

r57bは既存r5nlの必要性の形を一般化し、同じ目標が達する関連経過が少なくとも一つあり、その全達成経過で同じ営みもあることを求める。努力だけで成功するという十分条件、法的義務、達成不能だから何でも必要となる空虚な条件とは区別する。

`ringen`を、態度を担う人が、その態度の取得・保持に対する障害へ、力を投入して対抗する活動と読む。r57cは生起・本人参加・実際の努力h26poを結び、r57dは同じ態度の表れr56qと、同じ条件の妨げる働きへ対抗する方向h26pnを加える。態度そのものを人や組織として扱わない。方向性から成功を導かず、反政府行動の特定手段、政府の打倒、障害の撤去、最大限の努力を要求しない。

r57eではr56oの同じ自由への態度を使い、当事者と活動を存在量化する。受け手が自ら取り組む場合も、他の保持者が同じ受け手の取得・保持のために取り組む場合も含む。共通自由政策が実現していることは、同じ政策を支持する態度の成立条件にしない。

r57fは、異なる少なくとも二条件を含む指定列を複数の障害として扱う。各条件について、同じ政府の自己誤解、同じ受け手への外的性格・現在の適用、その条件の介入モデルにおける同じ目標への潜在的妨害を結ぶ。同じ一条件の重複は複数と数えない。r57gはその全条件への対抗的努力を求めるが、当事者・活動を一つにそろえる必要はない。

必要性の関連経過は、背景を固定した全実践的経過として供給し、達成や努力から事後選別しない。r57hが、その全経過で同じ政府由来の全障害が適用されることを確認する。障害の有無を変える因果比較と、障害がある下で何を要するかという比較は別の範囲である。評価状況は関連する経過を含めて解釈でき、全活動が物理的に同時である必要はない。

r57iは、同じ国外取得者への現実の到達・保持、同じ外国政府の複数障害、現実の対抗的努力、同じ障害背景での非空虚な必要性を接続する。局所検査は、候補ごとの経路引数、努力と態度と方向性の独立性、複数条件の全称、必要性の真理表と反例、同じ政府・人・目標への結合を調べる。大きな内容を丸ごと有限世界で証明したとはせず、既検査の深い内容を境界にした箇所は報告で明示する。
