# 未決定の関数と四つの原点定数

原文u0085を、四座標式の係数φが当面未決定であるという補足と、原点についての仮定を採らない場合の条件文として円文字本文へ接続する。既存の合成定義13個と意味規約2個を再利用する。新たな参照型は加えず、共通基盤375語を保つ。任意プロファイル50版は782語となる。

冒頭のundからist.までは、先行する四座標式と同じ第43段落第一文の14–22トークンを指す。続くMacht manからzuzufügen.までを同段落第二文の全29トークンとして保持する。φ、v、τの三つの数式参照も元の記録へ対応させる。

φは先行するaをβで正規化した同じ関数である。未決定性は、現在の関数を含む有効な候補が残り、ある許容速度では異なる値を返す候補も残るという採用解釈を保つ。現在の速度で一致するだけでは、関数全体が同じとは限らない。後続のφ=1を先取りしない。

この論述段階は、先行する係数の未決定段階とは別の参照zfmとして定義する。文書、補足箇所、既存の閉じた役割、提示文脈をすべて保持して照合する。参照の取得は、役割の実行や候補の存在証明にはならない。候補への所属と現在の関数との一致は、本文のsqdで別に要求する。

原点変更の条件では、系・単位・V・v・φなど他の物理条件を保ったまま、初期空間原点とτの零点についての仮定を採らない。これは原点の物理的不一致を断定しない。時間、縦方向、横二方向の四定数を独立に許し、同じ設定の全記録対で一組を共有する。定数は零や負値でもよい。存在量化は記録対の量化の外側に置く。

検査は、各出力と各定数の交換、対応の欠落や余分な解、同じ値を持つ別記録、設定の取り違えを区別する。四定数の束縛は、他の三つを固定して一つずつ二値で変える診断と、本体の記録対の検査を分ける。全実数・全関数の量化を有限試験で代用しない。旧診断用のsqe/sqfを本文へ追加せず、選択した依存閉包内の候補族と一致・相違の関係を直接調べる。
