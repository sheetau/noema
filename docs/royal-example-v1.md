# 立法上の自由の実例と君主の比較

第九段落第二文末の実例は、前半と同じ国家元首・思考態度・立法上の自由を具体化する。`r6d4`では前群の洞察に、同じ全臣民・三対象への許可方針の実際の成立を加える。一般的な洞察の定義から政策実施を導くのではなく、実例側の要件として分けている。

`r6d5`は八対象を閉じた引用にする。`r6d6`は、その同じ内容の現実の事例であるという関係と、同じ点における内容の成立を要求する。例を知り得る公衆、際立って優れ鮮明な例であるとの評価、同じ君主への敬意はそれぞれ別に結ぶ。`wir`は著者を含む指定公衆とし、全世界の人々や全臣民へ広げない。

`vorging`の読みは、旧引継ぎで仮に用いていた「先行者不在」から具体化した。[AdelungのVorgehen](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009134_5_1_1605)の1(1)には優越の比喩用法、1(3)には模範を先に示す用法がある。ここでは`glänzendes Beispiel`と`wodurch`を受け、この実践の例として**まだ他の君主が上回っていない**という質的比較を採る。辞書だけで原文の一意な解釈が決まるとはしない。

このため、時間的な最初の達成を扱う既存`rob`は使わない。以前に同等の実践をした君主がいても今回の読みは成立する。`r6d7`は、同じ履歴の評価時までの全候補について比較の評価がそろい、指定人物を上回る者がいないことを要求する。将来の優越例は含めず、未知を低評価や不在として埋めない。同等や比較不能を厳密な優越に数えず、唯一の最高位や数値順位も要求しない。

`r6ea`はその範囲を、各時点でいずれかの共同体の君主である全人物に具体化する。比較対象には前半の条件を満たした良い君主だけを選ばない。比較に渡すのは同じ八引数の`r6d4`の内容型であり、各君主の国・臣民・法・歴史的な設定へ具体化する。元の君主の国や現在の設定を他の君主へ押し付けない。比較評価の現実的な妥当性と完全性は、明示した解釈入力に残る。

`r6ec`の敬意は既存`h26nu`を再利用する。肯定的な価値を認め敬意を保つ態度であり、客観的な徳、具体的な恩恵への感謝、服従や称賛発話の実行までは述べない。`r6ed`が、実例・公衆・同じ君主への敬意・同じ内容型での比較を一つに接続する。

検査は政策の実現と洞察の区別、引用対象・全引数の対応、同等の先行例と未来の優越例を許すこと、過去又は現在の優越例を拒否すること、評価不足、同じ公衆と君主の対応を調べる。歴史上の君主の全評価を実証する検査ではない。下位の政策・思考態度・安全性は固定した前群の証拠を継承し、接続検査の境界を報告する。

一般化の範囲、先行する君主への談話上の同定、`davon/wodurch/welchen`の原文箇所、`Aber/noch/selbst/sogar`、全文帰属と通読は未接続。第二文の意味確認文字数はまだ増やさない。
