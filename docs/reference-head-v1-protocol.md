# 固定モデルによる参照の同一性

出来事・範囲・役割はv6の選択済みモデルに固定する。追加学習せず、KWJAが既に予測する依存関係と照応を取り出す。語の一致、対訳辞書、代名詞表、右隣の名詞への補正は用いない。

基本句の主辞について、依存先logitの最大値の位置をそのまま採用する。ROOTはモデル設定の特殊語位置から得る。自己参照・循環・不明な依存先は未確定にする。上流ライブラリの依存木修復による右方向優先の補完は呼ばない。

項の範囲に完全に含まれる基本句主辞を集める。範囲内の主辞が全て有効で、その集合の外に依存する主辞が一つだけなら、それを項の主辞とする。複数またはゼロなら未確定とする。同じ原文位置の主辞を持つ項を統合する。別位置の主辞は、固定モデルの文書内照応ラベル`=`だけを根拠に統合する。`ノ`等の関連性を同一性に置き換えない。外界の著者・読者は特定の人物として補完しない。

評価は予測前に固定する12文。修飾節の内外4文、代名詞・言い換え・名前の再出現5文、異なる本・猫・人物を統合してはいけない3文を含む。繰り返す表記には出現番号を注釈し、語の一致で参照正解を作らない。資料は実行時に読み込まない。

正解の項範囲を与える診断と、v6が予測した役割付き項の範囲による評価を分ける。同一参照ペアの適合率・再現率、項範囲の欠落・過剰、未確定主辞、文単位の参照分割完全一致を報告する。参照分割の完全一致には項集合の完全一致も必要とし、項が全て欠落した文を正解にしない。役割ラベルや概念・否定・数量まで含む全文意味構造の一致とは呼ばない。

原文解析・依存予測・採否・範囲と役割・参照根拠を保存する。同じ原文からの反復一致、保存データからの再評価、既存解析出力の不変性、生成・辞書の禁止経路0回を検査する。結果を見た閾値調整や手作業の参照補完は行わない。
