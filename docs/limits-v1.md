# 極限・連続性・閉曲線の定義

[極限の定義群](../examples/v011/limits.noema)は、既存の関数型・量化・実数の下側切断から16定義を構成する。文法や字形を増やさず、4つの有理数算術の基本記号と38定義で記述できる。数値を有限個調べて連続性を判定する機能ではなく、任意の精度とすべての近傍の点について述べる言語上の定義である。

## 定義域を明示した極限

定義域Dは、入力がそこに属するかを返す性質である。関数f、近づく点a、目標値Lを別々に渡す。極限の条件は次の順序で量化する。

```text
すべての ε > 0 について、δ > 0 が存在し、
すべての x について、
  x ∈ D かつ 0 < |x − a| < δ なら |f(x) − L| < ε。
```

δは精度εに応じて選ぶが、個々のxを見て選び直すものではない。また、aに任意に近いDの点がa以外に存在する、という集積条件を要求する。空の定義域や孤立した点に「どんなLも極限になる」とする扱いを採用しない。a自体がDに属する必要はないため、端点の片側から近づく極限を表せる。

連続性は、aがDに属することを要求し、近づく先をf(a)とする。孤立した定義域の点でも連続性は成立し得る。極限に課した集積条件を、そのまま連続性へ追加していない。

| 有理数領域 | 実数の切断領域 | 内容 |
| --- | --- | --- |
| — | la | 定義域内のすべての有効な実数入力で、関数値も有効な実数になる |
| ka | lb | 正の半径より距離が小さい |
| kb | lc | 定義域の集積点である |
| kc | ld | 定義域に対する極限 |
| kd | le | 定義域の点における連続性 |
| ke | lf | 定義域の全点における連続性 |
| kf | lg | 閉区間への所属 |
| kg | lh | 正の長さの区間で定義した連続閉曲線 |
| — | li | 差商の極限としての、定義域に対する微分関係 |

有理数版は型bと`h[b] b`を用いる。実数版は、実数を有理数の下側切断`h[b] c`で表す。実数上の関数の型は`h[h[b] c] h[b] c`となる。この型を持つ値すべてが実数の関数とは限らないので、laが有効な切断から有効な切断への対応を条件にする。量化も、baを満たす有効な切断に制限する。

有理数領域の関数と実数領域の関数は別の型であり、一方の連続性を他方の証明として扱わない。特に有理数版kcの目標値は有理数に限られる。有理数では表せない極限値を、この型へ丸めて入れることはしない。

## 曲線と微分

lhは、正の長さの実数の閉区間をパラメータ領域とする三つの連続座標関数x・y・zを受け取り、両端の三座標がそれぞれ一致することを述べる。自己交差、停止、角はこの定義では排除しない。連続な閉曲線を記述する条件であり、滑らかさや一定の速さ、実際に物体がその経路を進むことを暗黙に含めない。

liは、aが定義域の有効な点であることを要求し、次の差商がaで指定した値へ収束する、という関係を定義する。

```text
(f(x) − f(a)) / (x − a)    ただし x ∈ D、x ≠ a
```

分母が0になる点を差商の定義域から明示的に除く。既存の逆数の構成式cgは、その除外した点における意味のある値として使用しない。liは元の定義域に対する相対的な微分であり、閉区間の端点では片側の条件になり得る。導関数の連続性や、微分・積分の一般法則までは、この一つの関係から結論しない。

## 機械的に確認した範囲

[19の検証主張](../examples/v011/limit-claims.noema)を、有理数の線形算術として量化を保ったまま検証した。任意の有理点での恒等関数と`2x+3`の極限、閉区間上の連続性、片側極限、孤立点の連続性など9件が成立し、空集合の極限や誤った目標値など10件が成立しないことを確認した。

各例で有限個のxやεを選んだのではなく、全称・存在量化を含む式の否定を検査している。この検査器は有理数の線形算術に限り、非線形の量化を実数上の問題へ無断で変換しない。二乗関数を同じ検査器へ渡す場合も拒否する。二乗関数が連続でないという意味ではなく、その主張はこの補助検査器の対応範囲外である。

実数版は、構文・型・束縛範囲・算術定義への依存と、通常記法・短縮記法・固有文字の往復を検査した。**実数切断全域の連続性や微分法則を機械的に証明した結果ではない。** 有限解釈器も、有理数全体への量化を有限標本で代用せず拒否する。[検査記録](../reports/limits-v1.json)に区別を保存した。

## 原文への接続

アインシュタインu0128にある閉曲線の幾何学的な連続性を、lhへ部分対応させた。ただし原語の曲がり方・滑らかさの解釈、一定の物理的な速さ、時計の指示の積分、折れ線の結果を曲線にも適用するという仮定の発話は未記述である。有限経路の検査結果だけから、連続曲線上の時計の法則を証明したとはしない。

これまでの[有限経路の観測接続](path-observations-v1.md)とは別の数学的な基盤であり、両者を結ぶ収束と積分の定義が次に必要になる。確認済み全文単位数はアインシュタイン0/282、カント0/20を維持する。

```powershell
python -S -m scripts.compose_limits
python -m scripts.check_limits --verify-only
python -S -m noema parse --input examples/v011/limits.noema --output artifacts/limits-v011.json
python -S -m noema render --input examples/v011/limits.noema --alphabet v2 --output artifacts/limits-v011.svg
python -m pytest -q
```

解析・表示にモデルやソルバーは不要である。19主張の算術検証には、既存の`z3-solver`を用いる。

新規4件を含む全722テストが通過した。モデル不要の再構成・JSON解析・SVG表示と、検査記録の再現も確認した。
