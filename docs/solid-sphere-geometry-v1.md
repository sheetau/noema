# 球体の全形状と物質境界

剛な球の設定へ向けて、物質点の完全な位置集合とその境界を構成する。eje2は同じ時刻・座標族で三位置全てを満たす一つの物質点の存在であり、eje4は全成員の閉球への包含と、その閉球の全実数三位置への被覆を合わせる。表面の有限点や内部の穴がある集合を完全な球体と認定しない。

このモデルは内部を含む閉じた球体を占める連続体である。密度や質量は指定しない。殻だけの物体の外形とは異なるため、原文のKugelgestaltから内部の充填が無条件に従うとは扱わない。本文へ採用する場合はこの読みを明記する。今回は依存定義の構成であり、原文全体との意味一致はまだ判断しない。

境界eje3は球面式から定義しない。占有されている地点の任意に小さい開近傍に非占有地点がある、という閉領域の境界条件を用いる。近傍半径は全正実数、候補位置は全実数三組である。この形なら、閉球の境界を数値の二乗和の式と結ぶ際に、表面という名詞の説明をその式と循環させずに済む。

eje5は一般の全物質点履歴・剛性・静止に全時刻の形状を結び、棒専用の端点条件を持たない。eje6/eje7は同じ物質点の現在の出来事記録を全時刻へ接続する。ejfaは同じ物体の占有領域に基づき、現在記録の位置が境界上にあるかを述べる。境界上の光の出来事などを排除しないよう、出来事そのものを必ず物体の世界線へ限定することは避ける。

ejfbは中心零の球体と実測された同じ原点を結び、ejfcはkでの静止とKでの全物質点の正X並進を同じ速度・二系へ接続する。K/kの時刻区間はそれぞれの規約に従う。原刊903頁の考察行為・球面式の提示、最終四式との接続、著者脚注u0281の説明と全文判断は次の作業に残る。
