# 基準時までの受領と反事実の差し控え

カント脚注の「sonst würde sie die gegenwärtige zurükgehalten haben,」を追加した。直前の未受領に対し、「先の回答が届いていたなら、その影響で現在の回答を差し控えただろう」と読む部分草案である。既存21文を保存し、反事実の一文を加える。

`rqrq`は基準点までに事象が成立することを表す。履歴の順序と基準点の所属を検査してから、同じ履歴の基準点以前に事象があることを要求する。未成立条件`rqrn`の単なる否定ではない。履歴が空、基準点が範囲外、順序が不正という場合には、成立と未成立の両方が偽になる。`rqrr`で受領へ適用し、現在の所持と区別する。

`rqrs`は実際には前提が成立しない条件文を扱う。採用された比較状況が一つ以上あり、その全てで前提と帰結がそろうことを要求する。空の選択、前提のない比較、別々の比較から前提と帰結を集めることを許さない。実際の帰結には条件を課さず、帰結が現実に起きたとも起きなかったとも主張しない。

比較の選択には、視点となる人物、前提の閉じたNoema記述、実際の状況、比較状況を渡す。前提記述は`hzkr`への参照を引用したもので、自然言語のプロンプトではない。人物・前提・実際の文脈を変えた選択を流用しない。比較状況の適切さや最類似性は基本関係の意味契約に残り、この検査が自動的に比較状況を発見するものではない。

原文の記述`hzkt`は、実際の履歴と基準時を前版の`hzjs`・`hzjm`へ結び、実際の未受領`hzju`も要求する。比較状況にはその状況の履歴・基準時を使い、同じ受け手`wa`と先の回答`hzjn`を保持する。帰結では、同じ著者が現在の論説`hzik`の提示を差し控える対応と、先の回答からその対応への因果的な寄与を結ぶ。先の回答を意図ある人物として扱わない。

有限検査には、過去・現在・未来・履歴外の事象16組合せ、条件文の真偽128組合せ、文献・人物・文脈・比較状況・因果対象の対照を含む。原文用の比較は既存の短絡診断を使い、主要四例は保存したグラフを変更せずキャッシュなしでも照合する。未知の選択・受領・履歴・帰結を補わない。保存文書の意味を診断のために書き換えるものではない。

新しい基本記号は状況の履歴枠・基準時、比較の選択、差し控え、文献から対応への因果寄与の五つで、局所的な人物や文献の参照は増やしていない。一般の受領・反事実の三定義と原文用の三定義を追加する。執筆・送稿・公表のどの段階を差し控えるか、因果機構、比較の妥当性、後続の試み・偶然・思想の一致は未完である。脚注全体の意味確認には数えない。
