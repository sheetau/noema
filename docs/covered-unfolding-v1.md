# 覆いの内部で進む性質の顕在化

カント第17区間に続く成長の比喩について、描写側のひな形を追加した。同じ対象が持つ潜在的な性質が、一つの過程を通じて顕在化し、その間も同じ覆いの内部にあることを記述する。自由な思考への傾向と使命を表す対象側の記述は未充足であり、このひな形を比喩全体の完成訳とは扱わない。

## 前後の変化と同じ対象・過程

[一般定義](../examples/v016/covered-unfolding.noema)の `rw4` は、既存の `tg` による順序付き履歴と変化過程を使う。同じ開始点・終了点を同じ過程が結び、その過程が同じ対象の変化に関わることを要求する。前後で性質が異なるというだけでは、この条件を満たさない。

性質の範囲を固定し、次の条件を結ぶ。

- 選択した全性質について、開始時点で同じ対象にその性質を発現させる構成・素質がある。
- 終了時点で、それら全てが同じ対象に顕在化している。
- 少なくとも一つは、開始時点には顕在化していない。

これにより空の性質範囲、初めから全性質が発現済みの場合、別の対象の潜在的性質や発現の流用を除く。一部が開始時点で発現済みでもよい。中間時点の一時的な後退や、選択範囲外の性質の変化は制約しない。

潜在的性質は単なる論理的可能性とも、観測者が未確認であることとも分ける。ただし、素質の物理的・生物学的な機構は入力の意味規約として残る。`rw4` だけで植物の芽や胚の分類を定義したことにはならない。

## 覆いを取り除いたことを補わない

`rw5` は `rw4` に加えて、対象とは異なる同じ覆いが、開始から終了までの履歴内の全時点で対象を包み、変形への抵抗を持つことを要求する。途中だけ別の覆いへ交換したり、別の対象を包んだりする場合は成立しない。終了時点でも覆いは残るので、破裂・脱出・除去の出来事を補わない。

包むことと変形への抵抗は引数で与える。硬さの尺度や材料機構、包まれることが発展を引き起こす因果関係は、この構成だけでは定義しない。履歴が全時点を尽くすことも意味規約であり、有限の診断例から連続的な現実の全時点を検証したとはしない。

## 比喩の内側と条件文の事実性

[本文草案](../examples/v016/kant-covered-unfolding.noema)の `iagdepiction` は、同じ対象と基準視点で固定した履歴・性質範囲へ `rw5` を適用する。描写の内部では、既存の自然への参照 `qb` を過程の行為者へ結ぶ。ここで個体型を使うことは、自然が人間や意識ある存在だという主張ではない。

`iagframe` は、明示的な対象側の性質記述と `iagdepiction` を、既存の比喩提示 `qh` へ渡すひな形である。対象側の引数を、適当な人や前段の全能力の機会へ暗黙に置き換えない。`iagattribution` はこのひな形の記述を部分注記として帰属する。比喩の内容や、条件文の前件が現実に成立したことは実行評価しない。親の全宣言と21文を保持し、注記を一文追加した。

語義確認では、Adelungの電子翻刻に植物の初期形態と比喩的な始まりの用法が記載されていることを確認した。このため `Keim` を種子そのものに固定しない。参照した1811年版は1784年の原文より後であり、この資料だけでカントの読みを一意に確定しない。[MDZのKeim項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_6_0_692)、[取得記録と限界](../data/unfolding-reading-review-v1.json)に記録した。
