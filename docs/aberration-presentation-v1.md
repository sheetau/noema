# 結線との角の命名と光行差の表示

u0193–u0194を、先行の同じ波・源・観測者・二系の設定へ接続する。φ′は移動系の波面法線と「光源―観測者」の結線との角、a′は先行M0327の第二式が与える変換後法線の縦方向余弦である。M0340の分子はcosφ−v/V、分母は1−(v/V)cosφ。原文の基準線や記号を、式に都合よく変更しない。

結線は同じ移動系の同時刻に取る源から観測者への向きとする。[先行の幾何学](aberration-line-v1.md)で構成した新源曲線、結線の遠距離極限、変換後の波面法線、二方向の0からπまでの実数角を共有する。

括弧内のStrahlrichtungは、この局所平面波の位相が前方へ伝播する幾何光学的な向きと読む。正のV、正の位相率、単位方向nに対し、位置pからp+V*n*δへ、時刻tからt+δへ進んだときに同じ位相を保つことを、δ>0かつ両端が同じ新領域に入る全割当に要求する。同じ新位相の等位相面がnに直交する条件も全ての同時刻位置対で要求する。旧位相を逆Lorentz写像で引き戻した関数と、同じ新領域を直接使う。光子の個体軌跡や実測されたエネルギー流の主張は追加しない。

φ′の表記は、対象を同じwave、候補値をnewangle、評価状況を同じcontextとする閉じた規則へeisloで結ぶ。K・V・第七節を保持し、残る59役割は一つの設定の証人として存在量化する。命名規則は角の物理的・幾何学的役割を含み、表示式の成立を含めない。従って、原文の主張を真にするために名前の意味を選び直す構成ではない。

先行a′式と今回の表示は、同じ61役割への条件として構成する。eissbは、著者が先行の式をこの形として明示するという提示を表す。波面法線と光線方向の説明をuhで帰属し、eisa5で同じ命名への挿入として保持する。コロンはufとueで表示へつなぎ、表示自体はeisox、二単位の著者と論説への帰属はeir3で記述する。

この字義的な結線読解では、旧方向が速度に垂直なV=5、v=3の例で角の余弦4/5と表示式−3/5が一致しない。先行a′は−3/5のままであり、両量を混同しない。この不整合は原文の誤植や歴史的意図を確定するものではない。採用解釈の下で何を述べたかを記述することと、その主張が物理的に正しいことを区別する。

検査は前方伝播の座標・位相、同時刻法線、局所領域、同じ設定の結合、59の存在位置と61の全称位置、表記・引用・挿入・表示の引数を対象とする。全実数の量化は有限評価を拒否する。有限診断や全テストの通過を、原文との意味同義性の自動証明にはしない。
