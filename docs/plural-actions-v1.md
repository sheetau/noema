# 複数の判断を一つの公的提示として構成する

複数の論点について、本人の判断と公的提示を一つの行為記述へまとめた。すべての論点で判断・提示・吟味への意図を要求し、採用教理との差は少なくとも一論点で要求する。各論点がすべて教理と異なる、という強い条件にはしていない。

カント草案の最後の帰属文を、この複合した行為記述への一般許可へ改訂した。親の1,356宣言と先行15文は保持している。今回の改訂も部分的な解釈案であり、原文全体との意味一致を確認した完成訳ではない。

## 全内容の成立と、一部での相違

従来の一論点用の行為記述をそのまま複数連結すると、各論点に教理との差を要求してしまう。このため、従来のひな形から取り除く条件を構文木で照合し、比較候補における相違の存在条件だけを分離した。本人の判断、組織による基準の採用、公的提示、自己への発話帰属、吟味への意図は保つ。

| 定義 | 内容 |
| --- | --- |
| `rqh`、`rqi` | 一論点の判断・提示を構成する。単独では教理との差を要求しない。 |
| `rqj` | 同じ論点・比較時点で本人と教理の基準に差がある条件を構成する。 |
| `rqn`、`rqo` | 二つの内容の連言・選言を、同じ本人・行為・文脈に適用する。 |
| `rqk`、`rql` | 有限列の全内容・少なくとも一内容を満たす記述を構成する。 |
| `rqm` | 全枠の判断・提示と、少なくとも一枠の相違を組み合わせる。 |
| `rqp`、`hzleligible` | 非空の枠列、本人・行為への枠選択、許可側との役割一致、対象記述の構文一致を検査する。 |
| `hzlclaim`、`hzlattribution` | 複合した対象を一般許可へ渡し、同じ著者・範囲・文脈へ帰属する。 |

全内容の連言は空列で真、少なくとも一内容の選言は空列で偽になる。したがって空列の複合行為内容は偽であり、資格条件でも非空を明示的に要求する。一要素の場合は、従来の「その論点で判断・相違・提示が成立する」という条件と同じ真偽になる。ただし構成した式の形は異なる。

列の順序と重複は記述に残るが、発話の時間順を意味しない。異なる本人・行為・文脈で一つずつ成立する内容を、一回の行為として合成することもない。

## 許可の対象

本人・活動・基準文脈ごとに集合を選び、その集合から有限の枠列を得る二つの指定を追加した。各枠の項目は前回の指定を引き継ぐ。すべての枠が同じ本人と活動に選ばれ、各枠の公的役割が許可の役割に一致することを要求する。

個々の提示への許可と、まとめた提示への許可は、異なる記述を対象とする。前者から後者、後者から前者を推論する規則は設けていない。反対符号の要求によって許可を妨げる場合も、同じ対象記述かを照合する。

資格条件は記述の選択条件であり、実際に行為が成立したことを要求しない。ある内容の提示が行われていなくても、その内容を提示する行為への許可を問うことはできる。

## 検証と再現

二論点の相違の4組合せ、各論点の判断・提示・意図を欠く6例、集合・枠・役割の4例、三対象の許可の8組合せを検査する。追加テストでは、反対要求、未知の集合、一要素列と従来定義の一致、異なる人物・活動・文脈の混在、空列の真偽、個別記述と複合記述の不一致も検査する。

追加39テストの確認を終えた。意味条件など36項目と、修正後の帰属・全域拒否・再現の3項目が通過した。長形式・短縮形式・固有文字の往復、検査記録の生成と再実行による照合も通過した。二文書のCLI解析と、抽出文書の固有文字SVGのXML検査も通過した。SVGの目視検査は行っていない。

本文から抽出した実際の資格条件を使用する。原始関係の解釈を与えた有限モデルの検査であり、原文との全域的な同義性の証明ではない。未知の集合は空列に置き換えず、解釈不足として扱う。論理演算の評価は先行実装と同じく短絡しないため、未選択の候補でも参照される項目には全域的な解釈が必要である。

著者への帰属を検査する際には引用内容を実行しない。一般許可の全記述量化を評価すると、有限評価器は引き続き拒否する。今回の有限の枠列を、すべての記述の領域の代用にはしていない。

## 残る課題

この列の構成は複数内容の指定を可能にするが、原文にある洞察 `Einsichten` の認識上の含意はまだ説明していない。選択集合と枠が対象範囲を尽くすこと、聖職者・学者・公衆・教理の意味、君主への照応、「なおさら」の論証も未完成である。

任意の同義な式を同じ記述として扱うことは保証しない。意味の異なる対象の許可を混同しない一方で、同義でも構文の異なる表現への許可は別途扱う必要がある。標準版への採用、静的な評価層の追跡、全原文の意味確認も残る。

同じ原文範囲内の改訂であり、原文対応集計は248件・566文書のまま。意味確認済み区間も両作品とも0件のままにする。
