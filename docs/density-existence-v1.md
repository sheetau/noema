# 密度式の有理数解の存在と一意性

密度式の数値条件を満たす値が実際に存在することを、具体的な構成式で示した。これまでの条件付きの一致検査に加え、許された有理数入力から出力を作れることを確認する。[独立したNoema文書](../examples/v014/density-existence.noema)の二つの定理として保存した。アインシュタイン本文へ新しい主張や定義を加えたものではない。

入力は光速度V、系の相対速度v、正の正規化係数β、密度ρ、三速度成分ux・uy・uzである。既存の正規化条件`sra`と、D=V²−v uxが零でないことを仮定する。βも有理数の入力として与えるため、任意の有理数vについて有理数のβがあるとの主張にはならない。Dが負の入力も許し、式にない流速制限を追加しない。

次の四値を構成する。

| 出力 | 構成式 |
| --- | --- |
| ρ′ | βDρ / V² |
| uξ | V²(ux−v) / D |
| uη | V²uy / (βD) |
| uζ | V²uz / (βD) |

前提からV・β・Dは非零なので、これらは有理数として存在する。密度で割らないため、ρが零の場合も速度を構成できる。新電場の対角微分値のうち二つを任意に与え、残る一つをρ′からその二つを引いた値にすれば、五つの等式をまとめた既存の`senr`を満たす。

二つ目の定理は、同じ入力に対して`senr`を満たす二組の出力があれば、密度と三速度がそれぞれ等しいことを述べる。三つの対角微分値の組は一意とはしない。たとえばV=5、v=3、β=5/4、ρ=4、速度=(1,−2,3)なら、出力はρ′=22/5、速度=(−25/11,−20/11,30/11)となる。対角値は(22/5,0,0)でも(−3/5,7,−2)でも和が22/5になり、同じ式を満たす。

存在検査器は、保存されたNoemaの前提と結論を読み、与えた構成式を存在変数へ代入する。構成式に許す操作は有理定数・入力変数・加減乗除だけで、各除算の分母が前提の下で非零になることも検査する。実数上の反例がないことと、有理数の四則演算による閉性を組み合わせる。実数上で存在すると判定された値を、そのまま有理数の証人として扱う方法ではない。たとえばx²=2の実数解や、小数による近似値を有理数の解へ昇格しない。

検査器が扱う形は「全称量化した有理数入力について、量化を含まない多項式の前提なら、存在量化した有理数出力が量化を含まない多項式の結論を満たす」である。未対応の構文や構成式は拒否する。証人が不適切だった場合は未認証とし、定理自体が偽だとは判断しない。時間切れは未確定のまま返す。また、前提を満たす入力の存在はこの一般検査だけでは証明しない。

そのため、密度式では別途七つの具体的な有理数入力から出力を構成し、保存された`senr`へ代入して成立を確認した。正・負・零の密度、負のD、逆向きの系速度、静止系、異なる対角値の分配を含む。Dの非零条件を削った場合や、構成した縦速度の符号を変えた場合は認証されない。零分母は未定義として拒否する。

今回証明したのは、有理数による比較形の出力の存在と一意性である。実切断上の全演算との対応、物理的な量の帰属、軌跡や密度の極限、指定した微分値を実現する電場の存在までは証明していない。とくに、数値の前提に事例があることと、本文の物理的な全前提に事例があることは別である。[確認記録v12](../data/density-formula-review-v12.json)へこの区別を残し、原文対応範囲と意味確認済み区間数は増やさない。
