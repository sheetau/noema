# 未成熟でいる便宜を述べる一文の確認

「Es ist so bequem, unmündig zu sein.」を、登録簿v58の本文と意味規約へ照合した。**この一文は、下記の目的相対的な読みの下で意味が対応すると判断する。** アシスタントによる読解判断であり、自動証明や独立査読ではない。

対象は[原刊482頁](https://www.digitale-sammlungen.de/de/view/bsb10926843?page=522)の短文で、固定した単位u0009の[290,325)、35文字・29非空白文字である。[読解記録](../data/convenience-reading-v1.json)には五つの連続範囲、採用読解、文脈設定、出典ハッシュを保存した。[Noemaの文6と全依存先](../examples/v016/convenience-reading-core.noema)を確認対象とする。

Adelungの[Bequem](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_4_1_1393)には、目的達成に必要な労を軽くする用法がある。同じ項目には、障害を避けたがる人や、好みに合う使いやすさ、否定的な含みを持つ用法も区別される。今回は、直後の代行例・支払いの文に続く文脈で、実際上の用事を低い負担で満たせる読みを採る。語の全用法を一つの条件へ還元したとはしない。原データは[出典記録](../data/convenience-reading-evidence-v1.json)に保存した。

| 部分 | 採用読解と対応 |
| --- | --- |
| Es ist | 文脈で評価する人々と仮定場面に関する主張としてunを著者へ帰属する。 |
| so | 負担の水準ukを元の文脈に固定し、「これほど便利」という程度を表す。具体的な数値や別状態との比較を補わない。 |
| bequem | 選べる同じ方法で、状態と実用上の目的を評価結果において満たし、その負担が基準内であることをrj・rk・ulで結ぶ。 |
| unmündig | 第一段落で定義された、自立的な理解力の行使能力の不足という現在のbc・bfを使う。 |
| zu sein | その状態にある場合の便宜を評価する。状態へ入る容易さ、本人がそれを好むこと、実際に選んだことは含めない。 |

評価対象の人、仮定場面、目的、結果範囲、負担尺度と基準を先に定める。成功した人や結果だけを後から選び直すことは正当化しない。原文を全人類・全場面での無条件の主張にはせず、その一般化を適用する範囲を文脈入力として保持する。対象者を追加すれば、その人についても便宜の条件を要求する。

目的には、確認済みの[代行例の文](delegation-reading-v1.md)と同じswを渡す。本人の実際上の用事が対象であり、自分で考えること自体を目的へ組み込まない。状態と目的と低負担を別々の方法から集めて条件を成立させない。開始と評価結果で状態が保たれることは要求するが、全生涯の継続や、その後に成熟できないことまでは含めない。

現行のbcは、単に現在の実行機会がないという条件ではない。本人の判断基盤を保ち、通常の外的機会を与えた場面で行使能力を評価する。このため、初期の便宜の検査記録だけに依存せず、現在の能力定義を含む検査を追加した。人物の好意、動機、実際の選択や、著者による未成熟の推奨は便宜の条件に入れていない。

## 検証と集計

五つのテストで、状態・目的・方法・評価結果・負担の64組合せ、条件を別方法から集める等の四対照、現行の能力定義を含む十八対照、通常評価との照合、四種の未知入力、帰属七対照、原文の五範囲と三記法の往復を調べる。評価不足を既知の便宜として補わず、評価対象外の人物の追加と、評価対象への追加を区別する。

一般定義と、切り出した現行の能力不足の判定は通常評価でも実行する。全文の結合には純粋な計算結果の再利用を用いる。能力や便宜の定義を検査用の真偽値へ置き換えていない。有限モデルの検査だけで歴史的・哲学的な意味一致を証明したとはせず、公開した定義と出典、文脈設定、上表の読解を合わせて判断する。
