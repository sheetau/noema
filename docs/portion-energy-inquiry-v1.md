# 同じ光の部分の新系エネルギーを問う

u0205第二文の「この面が動く系で囲むエネルギーを問う、すなわち光の集合のその系に相対的なエネルギーを問う」を、同じ部分・単位・系を固定した実数値質問へ接続する。原刊913頁の二つの系記号はいずれもkである。前の球面と初期部分の連続体輸送を引き継ぐ。

| 役割 | 構成 |
| --- | --- |
| 答えと独立な設定 | ekn6はekmiの波、校正、部分割当、同時体積、全点位相平均を保ち、旧新総量の積分条件を除く |
| 同じ部分 | ekn7は同じK・V・部分・波の範囲とeknwの初期部分輸送を接続する |
| 候補の意味 | ekoaは新系の同時断面の密度の空間積分をvalueへ結ぶ |
| 質問とその言換え | ekobは実数値質問、ekocは同じ質問の参照。ekod/ekoeは二つの記述による同じ質問提示 |
| 著者の提示 | ekofはekodの提示とeismeの説明方向、eisraの後方参照を保ち、ekohが本文に帰属する |

平均は先行のA²/(8π)の読みと同じ位相平均である。空間領域を固定した各点の平均密度を積分し、有限球の瞬間エネルギーとは区別する。後続のτ=0に合わせて新系の同時断面を選び、旧系のt=0と同一の出来事集合とはしない。球面の領域履歴を逆Lorentz写像してから断面を取る。新系体積と振幅は記号的な設定値であり、計算済み・既知の数値とは要求しない。

質問の条件にnewenergyという固定答えも、総量の存在証人も入れない。68設定を先に一度固定し、その後で候補だけを変える。候補ごとの別の波・部分・単位の選択を許さない。後続の総量比や等体積も条件に入れない。

既存の質問提示関係は41設定の二場、61設定の振幅、閉じた単一の実数値質問に型付けされている。eistsはその条件付き質問提示を68設定へ型付けした一般関係である。語義に光・エネルギー・原文の文全体を含めない。物理的内容と候補は定義で合成し、言換えと帰属には既存の一般関係を使う。

後半は新たな質問行為として追加せず、同じ問いの説明としてeismeへ渡す。ekocが同じ質問ekobを呼ぶのは、この説明の対象が同じ量であるためである。問いを立てること、候補が成立すること、答えの存在・一意性・既知性は別であり、質問提示の検査は引用を実行しない。

検査では、ekmiからの設定分離、同じ68役割、前の初期部分との接続、新系の断面因子・平均密度・体積・候補の積分、空・単一・複数候補の質問構成、言換えの向きと引用の非実行を点検する。有理数のπ代用品は検査用であり原文のπではない。有限診断を全実数の物理理論や意味同義性の自動証明とはしない。
