# 試みとしての提示と、可能な一致の範囲を問う質問

カント脚注の末尾「die jetzt … bringen könne.」を追加した。現在の回答をここに置くことを容認し、この箇所では問いを検討するための試みという位置付けを与える、と読む部分草案である。既存22文を保存して一文を追加する。

`rqrt`は、検討可能な状況で指定条件を満たす範囲・程度を候補答えとする質問を作る。実際の状況と検討状況を分け、可能性と内容を同じ状況で要求する。答えが一つでも存在すること、最大値や唯一性を主張しない。原文にない数値尺度や一致率も作らない。

`rqru`は同じ成立過程の生起・偶発性・因果的な寄与と、同じ二文献の指定範囲・程度の一致を結ぶ。`hzlc`で既存の現在の論説と先の回答へ適用し、`hzld`でその可能な一致範囲を問う。異なる文献、別の過程や状況の性質を寄せ集めて一致が説明できたことにはしない。偶発性と思想の比較基準の基礎説明は未完である。

`rqrv`は、この著者がこの文書にこの文脈で与える提示上の位置付けを一つに限定する。指定した位置付けの成立も要求するため、何も与えられていない場合に成立しない。他者の位置付け、別文書、別文脈、文献の全ての目的や価値には制限を広げない。

原文用の`hzle`では、既存の著者・論説・基準時・脚注文脈を使う。試みの位置付けへは、`hzld`への呼出しを引用したNoema記述を渡す。これは答えの成立ではなく、何の問いを検討する試みかの指定である。実際の一致、偶然による結果、試みの成功は断言しない。名称の表記は増やさず、新しい局所参照は提示上の位置付け一つだけである。

検査では可能性と内容の64組合せ、成立過程の四条件16組合せ、文献・範囲・過程・文脈の対照を扱う。さらに、問いの内容に使う基本関係を全て未知のままにしても、問いの記述を接続した提示の文を評価できることを確認する。問いを実際に評価して未知の内容に到達した場合は保留し、答えを補わない。

`mag`を容認の態度、`nur`をこの提示上の位置付けへの限定として読む。控えめな態度の語用論、可能性の種類、比較基準や偶発性の一般理論は未確定である。脚注の全文章に部分草案の範囲が対応しても、先行する周期・編集者・暦・敬称・指示・反事実の課題と合わせ、全体を意味確認済みにはしない。
