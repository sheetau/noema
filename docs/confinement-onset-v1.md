# 閉じ込めの成立過程と、その後に続く状態

閉じ込めの描写について、制限を適用する行為、制限状態への変化、その後に続く状態を分けた。行為が終わった後も出口の制限が残る場合を記述できる。前回までの構成と用途を保ち、同じ対象・装置・制限を過程の前後と継続期間へ結び付ける。

## 状態の不成立と、評価の欠落を分ける

以前の `q2` は、その文脈で制限を適用する実際の行為まで含む条件だった。新しい状態定義 `zbb` は、移動範囲の前提と出口が制限される条件を保持し、現在も適用行為が生起していることは要求しない。`q2` の既存文書は変更していない。

成立過程を表す一般定義 `raj` は、既存の状態移行 `th` を使う。同じ履歴の前状態で制限が成立せず、後状態で成立し、その二状態を実際の変化過程が結ぶ。さらに、対象がその過程で変化を受け、同じ過程が同じ制限を同じ対象と装置へ適用する行為として生起することを要求する。

ただし、前の状態が評価できなかっただけでも、条件式は偽になり得る。そこで両端の妥当性 `zbc` を別に要求する。移動範囲の完全性の前提があり、位置がその範囲に含まれ、内部と外部の分類が矛盾しないことを検査する。未知の位置や欠けた評価を、過去の自由の証拠にしない。

この過程は、前に外部にいたことを要求しない。初めから内部にいた対象について、出口の制限が新たに成立した場合も扱う。前から同じ制限が成立していた場合は、その制限の新しい成立とはしない。これ以前に他の制限もなかったという主張は含めない。

## 同じ制限が基準時まで続く

| 定義 | 内容 |
| --- | --- |
| `zbb` | 現在の適用行為を含めない制限状態 |
| `zbc` | 同じ状態を評価するための前提と位置・分類の整合性 |
| `zbd` | 同じ過程・対象・装置・制限・行為者を結ぶ成立過程 |
| `zbe` | 成立後から基準時まで、同じ履歴内の全時点で評価と制限状態が続く条件 |
| `zbf` | 家畜の描写と歩行器の構成・用途を、同じ装置での成立過程と継続へ接続 |
| `zbg` | 内容を事実として実行せず参照する比喩の部分注記 |

基準時だけ制限があっても、途中で解除されていれば `zbe` は成立しない。途中の評価が欠ける場合も同じである。また、ある制限で始まった過程を別の制限の現在の状態につなぐことはできない。

履歴の指定自体は記述者の前提である。記載しなかった時間の状態を補ったり、実世界で連続して制限されていたと認定したりする処理ではない。これは、[原文の関係節](https://www.korpora.org/Kant/aa08/035.html)を、成立した閉じ込めがその後も続くものとして読む候補の明示であり、原文の全時制や論述順序を確定したものではない。
