# 横二寸法の不変と縦寸法の縮小

u0116第一文を、原刊903頁の本文と五つの数式要素へ照合する。Y・Zの寸法は変わらず、Xの寸法は比1 : √(1−(v/V)²)で縮むという対照である。この比は静止時から運動時への順に読む。後の二文の光速極限と適用限界は、この一文の完成に混ぜない。

寸法を、同じ物体の占有集合の軸射影の有限幅として読む。静止時に三つの有限幅を持つ任意形状の対象について、Kの全対象時刻の形状と幅を述べる。前段の条件付きの六幅関係だけでは幅の存在は主張できないため、ejgqは静止幅と各時刻の運動幅の存在も要求する。空洞・非凸・非連結は許し、球の内部充填へ一般化しない。

横二方向は同じ静止幅を保ち、縦方向はその幅に縮小係数を掛ける。正の静止縦幅では厳密に短くなり、零幅は零にとどまる。Kとkの同時刻面を等置せず、同じ物体が静止系で同じ形を保つ期間の基準時刻と、Kの全対象時刻を比較する。光の到着による見かけの画像を記述しているとは読まない。

速度による比較は、同じ光速と同じ正の静止幅の下で二つの許容速度を比べる内容である。速度が大きい側で縮小後の幅が小さいことを述べ、元の大きさが違う物体を比べたり、加速中の形状変化を追加したりしない。

先の球形剛体と最終四式から任意形状へ進むalso、横縦を対照するWährend、指定比から速度比較へ進むalsoを既存の談話関係で接続する。新しい原始記号は二つの原文箇所の識別に限り、物理的内容は既存の幅・形状・速度演算から合成する。著者の帰結の提示は、処理系がその物理的真理を証明したという認定とは別である。
