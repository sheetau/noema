# 球面方程式の座標変換と計算の評価

対象はEinsteinのu0089–u0090、原刊901頁の「Diese Gleichung transformieren wir」からξ²+η²+ζ²=V²τ²と句点までである。直前のK球面式を、既出の四座標変換式によってkの式へ変形する提示として読む。著者がその計算を簡単だと評価している点も含める。

## 同じ波・出来事・四座標

先行する球面波ei77とK式ejaa、現在の四式ei7c、全対象出来事の両系の記録ei3aを前提ejagにまとめる。四式は同じV,v,φと共通零原点の設定に属する。追加の加法定数やφ=1を補わない。

ejaeは同じ波のKでの到来を一つの出来事に結び、その出来事の現在K記録とk記録を取る。結果ejafは、任意のK到来記録に同じ出来事のk記録が存在することと、結ばれた全記録対についてkの三位置の平方和がV²τ²に等しいことを要求する。記録の欠落を空の全称で成功扱いせず、同じ値を持つ別記録も保持する。Kの到来を指定しているため、ここからkにおける全波面の到来一致や未来方向までは断定しない。

数値式は既存sqj/sqkを用いる。既存の有理多項式証拠では、四式の代入により球面残差がφ²倍になる。φが負なら時間方向が反転し、零なら座標値が退化しても二乗式は成立し得る。したがって、この表示式に正時刻や非退化性を混ぜない。u0091で述べる球面波と両立性の結論は別に扱う。

## 同じ計算への「簡単」の帰属

ejahでは、著者がその文脈で利用できる方法を存在量化する。同じ方法の手順列zlxが前提ejagから結果ejafまで許容された変形でつながり、その各出現の非負負担の合計が文脈上の低負担基準に入ることをs2yで表す。引用した式は評価対象の記述として保持し、計算の評価中に物理的な真偽を実行評価しない。

低負担の尺度は原文の「簡単」に対する明示的な読みであり、手順数・処理時間・閾値を原文に追加しない。方法はこの計算の前提と結果により特定されるため、文専用の原始語や既存の別計算の方法名を増やさずに表せる。

ejaiは同じ箇所zgeへ、K式からk式への書換えzd3と計算評価uhを結ぶ。ejaj/ejakが同じ著者・論説・第三節への帰属と直前のK式からの順序を保持する。「wir」は論述上の著者の計算提示であり、読者の参加や実行ログを追加しない。
