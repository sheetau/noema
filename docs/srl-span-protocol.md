# 学習済み範囲分類器による項の抽出

依存型の意味役割出力が「を」「by」などに付き、Noemaに必要な事物の範囲を取り出せない問題を検証する。個別の助詞・前置詞の前後を拾う補正は追加しない。

## 固定するモデルと処理

[LIAADのsrl-en_xlmr-base](https://huggingface.co/liaad/srl-en_xlmr-base)を使う。モデル版は `55387c653aba11f0025a2f7089435c11c4c583f6`、分類層とラベルは[著者の公開リポジトリ](https://github.com/asofiaoliveira/srl_bert_pt)の `634d145cdca1aa2dfb0cf66143e3a358ac6e56fd` に固定する。追加学習はしない。日本語は学習対象として公開されておらず、転用として評価する。

このモデルは述語位置を入力として必要とする。主試験は前回のUnify-SRLのEN側が予測した全述語位置を渡し、正解位置や人が選んだ位置で置き換えない。分かち書きと文分割も同じStanzaモデルを用いる。正解位置を使う診断を行う場合は別にする。

入力は原文のトークンと、予測された述語を示す0/1の位置情報。モデルは各サブワードのBIOラベルを予測する。文章生成・質問文・指示プロンプトは用いない。著者の実装に合わせ、確率値を用いたViterbi法でBIOの構造制約を適用する。語彙別の対応表や翻訳例は参照しない。

## 予測前に保存する評価

[16組の範囲注釈](../data/srl-span-v1.json)を固定する。原文は前回の転用試験と同じであり、新しい独立評価とは呼ばない。役割の対象となる句を、限定詞・修飾・数量・格を示す語を含めて指定する。日本語の「犬が」「猫を」と英語の「The dog」「the cat」をそれぞれの原文の範囲として扱う。

1. 指定した述語を見つけ、その役割と句の文字範囲が完全一致した数を日英別に測る。
2. 文内の指定条件がすべて成立した数も数える。ただし、未注釈の役割や余分な予測があるため全文意味構造一致率とはしない。
3. 前回の内容語に関する部分条件も再計数する。これは句の完全一致より弱い診断であり、主成績に置き換えない。
4. 省略例の主体が勝手に追加されていないか、複数文の原文位置が保たれるかを確認する。
5. 無効なBIO系列や入力上限超過は明示する。範囲を黙って補正・切断しない。

全予測と正規化前のラベルを残し、公開前処理・分類層・デコードとの互換性と反復一致を確認する。成績を見て個別の文だけを補正したり、対象語句を変えたりしない。

## 判断の範囲

句が取得できても、名詞の概念、否定の作用範囲、数量や時間の意味、文間参照を確定したことにはならない。述語の誤検出・誤分類も継承する。英語で改善しても日本語の基準を免除せず、広い自然文への対応と意味構造一致率95%以上の完成条件を保持する。画面への本番接続は、この部分試験だけでは行わない。
