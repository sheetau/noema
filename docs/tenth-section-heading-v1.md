# 緩い加速をする電子の動力学

原刊917頁の第10節見出しを、前節末尾の電荷に関する定理と、直後の点状荷電粒子の設定の間で確認した。番号10、第二部に属する節という階層、動力学の主題、電子を限定する括弧内の「緩く加速された」を一つの見出しへ接続する。

電子は、後続で導入してその名で呼ぶ同じ点状荷電粒子である。`ek34`の実履歴・場・低速慣性質量・非零の符号付き電荷・校正単位を使い、現代の固定負電荷や量子論を名称から補わない。動力学は、この物理設定と既存の運動法則の定式化`elm`を対象として、作用・慣性・運動変化の規則性、成立条件、説明と導出を扱う研究として読む。

緩さは速度に掛けない。同じ系・長さ時間単位・第十節の理想化について既存`eiszx`が指定する正の基準を、全区間の外で固定する。完全な非空履歴`ek3p`の全有効時刻で、三空間座標の実一階・二階微分から三加速度を得て、その二乗和が基準の二乗より小さいことを要求する。各成分を個別に比べるだけでは、合成した大きさの上限にならない。

同じ軌道・時間領域・三速度関数・単位を共有し、端点又は一時刻だけが緩い例で全区間を代表させない。直線又はx軸だけの運動、全軌道が円であること、低速、無放射、特定の運動方程式を緩さの定義へ入れない。比較基準は文脈的な程度規約であり、任意に大きい数を後付けして条件を満たすものではない。

見出しは研究の主題と区分を示す。引用した物理設定の実在、運動法則の真理、導出や実験の完了を主張しない。括弧の修飾は、別の粒子の加速を添えるのではなく、同じ粒子・同じ履歴へ限定を合成する。新しい原始関係は必要ない。

検査では三成分の大きさ、符号と境界、実多項式軌道の微分、全時刻と各加速度の束縛、物理的背景と程度基準の取り違え、引用の非実行、番号・階層・前後関係を確認する。有限診断を全連続体の証明にしない。全原文単位の判断が揃っても、最終完成監査を別に行う。
