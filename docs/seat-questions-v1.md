# 起電作用の所在を問うことの失効

u0177第二文は、起電作用の「所在」を求める問いについて述べる。著者がその問いを発して回答を求める文ではない。新規文362は、その問いと必要な前提、従前の扱い、新理論による前提の拒絶を組み合わせて、問いが対象を失うという判断を著者へ帰属する。

## 採用した読み

引用符付きのSitzは、記述系に依存する力の分解とは独立した、自立的な起電作用の発生場所を求める読みを採る。前段の補助概念と系依存性を踏まえた解釈である。通常の局所力の位置を問うことまで禁止する読みではない。

gegenstandslosは、この問いに必要な自立した発生源の前提を、新理論が物理的な帰属として退けるため、従来の探究の対象を失うことと読む。答えがまだないことや、候補が空であることだけでは足りない。werdenは理論の移行による扱いの変化とし、物理的な時間経過で力が消えることにしない。従前の前提が正しかったとも述べない。

局所検査では、問いの候補集合、自立した担い手と所在の証人、必要前提・従前の扱い・拒絶の組合せ、全設定への量化、同じ概念の共有、Auchと主張内容の対応を点検する。未知の入力を拒否し、引用を自動実行しない。下位の電動力・非対称性解消・単極機は保存した検査証拠へ接続する。
