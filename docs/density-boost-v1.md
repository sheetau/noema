# 速度・密度・電流の変換と、発散との一致

アインシュタイン1905年論文§9のM0390にある三速度成分と密度の変換を部分記述した。Kからkへの変換として向きを固定し、同じ物質・出来事・二つの基準系の場と微分へ接続する。

## 速度と電流を分ける

光速度を`V`、基準系の相対速度を`v`、正の変換係数を`β`とし、`D=V²−v ux`と置く。`semp`は、`V>0`、`v²<V²`、正の`β`とその正規化、`D≠0`を保ち、次の関係を分母を払った形で表す。

\[
u'_x=\frac{u_x-v}{1-vu_x/V^2},\qquad
u'_y=\frac{u_y}{\beta(1-vu_x/V^2)},\qquad
u'_z=\frac{u_z}{\beta(1-vu_x/V^2)},\qquad
\rho'=\beta(1-vu_x/V^2)\rho.
\]

密度が零でも、三速度の式はそのまま残る。密度で電流を割って速度を復元する構成にはしていない。密度が零である場合と、速度変換の分母が零である場合も区別する。

`semq`は、密度と電流を独立な入力として、次の変換を表す。

\[
\rho'=\beta(\rho-vJ_x/V^2),\qquad
J'_x=\beta(J_x-v\rho),\qquad J'_y=J_y,\qquad J'_z=J_z.
\]

`semr`は、変換前後のそれぞれで`J=ρu`という単一の対流への分解を要求する。`sems`は速度・密度の変換と、この分解を結ぶ。有理数の代数では、これらから`semq`の電流変換が成立することを確認した。

独立な電流の変換は、密度が零でも電流が非零の配置を許す。その場合、単一の密度と速度の積では表せないことがある。回帰検査にも零密度・非零電流の具体例を含め、速度の変換と電流の変換を混同しないことを確認した。`semt`・`semu`・`semv`・`semw`は、同じ四構成を有効な実切断で表す。

速度の大きさが`V`以下なら、許容された基準系速度に対して`D`は正となり、密度の符号が保存される。この追加条件を定義へ暗黙に入れてはいない。形式上の超光速入力では負の分母も表せるが、それを現実の荷電物体の運動と認定するものではない。

## 密度と電場の発散を同じ値へ結ぶ

`semx`は、元の場の六式・発散による密度、既存の24微分係数の変換、今回の速度・密度変換を結ぶ。変換後の発散が密度と一致することは、この段階の前提には含めない。

`semy`は、変換後の電場の発散が、その同じ変換後の密度に等しいという条件を加える。有理数の微分係数の代数では、元の六式と発散の密度から、この一致を確認した。検査では時間座標を`Vt`に取り、速度成分を`V`で割った変数で扱っている。一般の実関数の連鎖律を、この代数だけから証明したことにはしない。

例として`V=5`、`v=3`、`β=5/4`、`ρ=4`、`u=(1,−2,3)`なら、`ρ′=22/5`となる。密度そのものは一般には不変でない。逆向きには`v`を反転し、速度・密度・電流が元に戻ることを有理数の式で検査した。

## 磁場の発散条件と、原刊の係数の相違

`semz`は、変換後の六式が従来の磁気側の係数`1/V`を含む形で成立する条件である。`sena`は、元の磁場の発散が零であるという追加条件を、`semx`へ明示的に加える。

元の六式だけでは、変換後の磁気側の式を一般に導けない。時間座標を`Vt`で表した磁気側x成分の残差には、`β(v/V) div H`という項が残る。磁場の発散が非零で、基準系速度も非零である有限例では、密度と電場の発散の対応が成立していても、変換後の磁気側の式は成立しないことを検査した。追加条件を原文M0383の六式へ黙って付け足してはいない。

これは、前版で確認した原刊M0389の磁気側三式に`1/V`がないという問題とは別である。今回も印刷形`semf`を保持し、従来の係数を用いる`semz`と区別する。原刊の式を修正したという扱いにはしない。

## 二つの基準系への帰属

`senb`は、同じ物質・出来事・文脈を、二系それぞれの場・領域・地点・密度・流速へ結ぶ。四座標は同じ向きの変換を満たし、両側の微分表は同じ地点の実際の場へ結びつくことを要求する。この接続では24微分を使うため、元の21微分だけの式よりも多くの微分の存在を明示的に要求する。

規格化した密度と電荷密度は、両側で同じ`4π`の換算を保つ。基準系の配置は関係引数で指定し、数値の一致から物理的な配置を推定しない。密度・流速・微分値・基準系・出来事を一つずつ変えた対照例では、対応の条件が崩れることを確認した。

`senb`は、元の磁気側の零発散も、変換後の六式も自動的には要求しない。両側の場全体が関数として変換則に従うこと、連鎖律、物理的な測定、著者の相対性原理への結論まで表し終えたものではない。

## 検査と未完の範囲

有理数の主張9件と、変換後の残差・発散に関する恒等関係8件を検査した。零密度から速度を確定すること、独立な電流の変換に単一速度への分解を要求すること、密度の不変性には反例を使う。

有限例では、正・零・負の密度、正負と零の基準系速度、二つの流速、磁場の発散条件の有無を組み合わせた36設定を使う。零分母と負の分母も別に検査した。実数演算は登録した有理数の実切断で代用し、偏微分には明示的なアフィン場の検査用解釈を使う。πの積分条件には検査用の値3を用い、実際のπや全実関数の解析を検証したとは扱わない。

[原刊916頁の照合記録](../data/density-boost-facsimile-v1.json)に、M0390の分子・分母・密度の係数を保存した。原文は変更していない。相対性原理との適合、電荷不変の議論、全実数上の解析と原文全文の意味一致は残る。
