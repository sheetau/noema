# 光の片道時間と、τの引数を明示した中点式

アインシュタイン§3の `u0051`〜`u0053` を部分記述した。静止系での光速度一定を使い、前段の三つの時計の読みを、次の四引数関数の値に結ぶ。

```text
τ₀ = τ(0, 0, 0, t)
τ₁ = τ(x′, 0, 0, t + x′/(V−v))
τ₂ = τ(0, 0, 0, t + x′/(V−v) + x′/(V+v))
½(τ₀ + τ₂) = τ₁
```

抽出資料の `M0100` は左辺、`M0101` は等号と右辺である。両者を一つの条件として構成した。`sjf` は三組の引数を作り、中点条件へ渡す。`sjg` がこれを実切断の演算と半和の式に接続し、`sjn` が本文で扱う候補関数・補助距離・速度・出発時刻を当てはめる。帰着時刻には往路と復路の両方の時間を加え、帰着場所の補助座標は0へ戻す。

除算には、既存の正の実切断の逆数を `sjd` として再利用し、`sje` で分子との符号付き積を作る。既存定義と記号名以外が同じであることを構文木で確認した。式の適用条件は `0≤v<V` と入力・結果の妥当性であり、光速度に達する場合やそれを越える場合は受理しない。実数体の一般法則の機械的証明は今回含めていない。

静止系での物理的な接続は `sjj` が担う。往路と復路を光速度一定の同じ適用範囲へ含め、同じ光と三出来事、軸上の経路、同期した静止系の時刻、各光路長を先行する `sba` に結ぶ。三出来事の静止系座標から作った `x-vt` がそれぞれ0・x′・0となることを確認し、光路長を符号を保ったx座標の差へ接続する。候補関数の値と運動系の三つの時計の読みは `sjk` が照合する。

数式だけなら負のx′も引数にできるが、今回の向きで往路・復路を正の経過時間と解釈するにはx′>0が必要になる。`sjj` ではこの条件を明示した。前段の抽象的な往復は負の方向も許しており、そこへ今回の時間式を無条件に適用することはしない。反対向きの光往復の式を同じ式として追加したわけではない。

本文の「または」による書換えは、前提・書換え前・書換え後を持つ帰属関係 `zd3` で記述する。前提 `sjm` は、先行する往復、光速度一定の適用、既存の座標対応を満たすτ候補、三つの時計の読みとの一致を含む。具体的なτの関数形は与えず、著者の書換えの提示と、同値性の検証済みという主張を区別する。

新規8件を含む関連28テストが通過した。展開式13例、物理的接続31例、帰属7例を検査した。往路・復路の分母の取り違え、静止系時刻をそのままτとする候補、時刻を無視する候補、異なる光、交換された出来事、別の座標記録、誤った光路長や時刻、光速度一定の適用範囲からの欠落を検出する。展開式の検査では、τに実際に渡した三組の引数も照合した。

有理数の代数的検査では、正の分母の商の一意性、正のx′からの時刻順序、同じ出来事の補助座標と光路条件から二つの商が得られることを確認した。検査用のアフィン候補 `τ=a*x′+b*t+c` に限定した場合は、非零のx′について中点条件が `a*(V²−v²)+b*v=0` と同値になることも確認した。この検査は、任意のτがアフィン形になるという導出ではない。二つの商の交換と、τ=tの無条件な採用には反例を得た。

有限検査は構成済みの整数切断を用いる。先行する光往復、光速度の法則、各区間の測定、座標取得、候補関数の全対応は、接続条件の検査では明示した検査用の解釈を使う。これらの検査と有理数の代数的検査を合わせても、全実数・全光路についての物理的な一般定理の証明にはならない。
