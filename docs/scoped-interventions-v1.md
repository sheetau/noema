# 変数を限定した介入比較と、実際の妨害

本文の登場人物や出来事が増えても、因果モデルで明示した変数だけを比較できる定義を追加した。カントの、後見人が自立した行動を妨げるという箇所に対し、単に行動がなかった場合と、制約によって行動の試みが失われた場合を分けるモデル内の読みを接続した。

新しいPython演算子や生成モデルは使っていない。既存のNoemaの有限列、関数、量化、真偽だけで構成している。

## 全対象を二値変数にしない

[従来の介入比較](interventions-v1.md)は、個体領域の全対象から真偽への関数を量化する。二変数だけの例なら小さいが、人物・集団・出来事などが16個ある本文へ組み込むと、65,536通りの全関数が対象となり、有限検査器の4,096通りという上限に達する。

今回の`rs`は、変数の識別子の列から割当てを構成する。空列には、全ての識別子を偽にする一つの割当てがある。変数を一つ追加するたびに、既存の各割当てを、その変数が真の場合と偽の場合の二つへ展開する。それまでの変数の値は保つ。識別子が重複しなければ、各段階で全ての組合せを一度ずつ生成するので、n変数では2ⁿ通りになる。

変数列の外は偽に固定した全域関数として扱う。列外の背景変数を自由に変動させる意味ではない。必要な背景条件は方程式へ明示する。検査では16個の個体がある文脈でも、二変数なら4通り、三変数なら8通りだけを生成できた。変数数に対する指数的な計算量は残る。

| 定義 | 条件 |
| --- | --- |
| `rz` | 識別子が変数列に含まれる |
| `rs` | 指定変数への全二値割当てを構成する |
| `rt` | 変数名の重複がない |
| `ru` | 指定介入後の方程式と、列外を偽とする条件を満たす |
| `rv` | 目標を満たす解が存在する |
| `rw` | 解が存在し、全解で目標を満たす |
| `rx` | 制約なしでは目標が可能で、制約ありでは全解で目標が不成立となる |

解なしを「全解で目標が不成立」として妨害に数えない。制約の有無によらず目標が成立しない場合も、妨害とはしない。複数解のうち一つだけで目標が失われる場合は、この強い妨害条件を満たさない。

## 実際の行為と観測を結ぶ

カント接続文書では、制約の適用と、本人による自立した活動の試みを二つの変数にした。後者は既存の「自分の理解力を他者の指導なしで使う」内容を参照する。試みることから、成功や許可、十分な勇気は導かない。

`ek`は、同じ後見人群・本人・文脈に対応する方程式を、制約ありとなしの両側で固定して比較する。`eq`では、後見人群が参加する同じ実際の行為が、同じ本人へ制約を適用していることを要求する。別の行為、別の人への制約、共同作用への参加が欠けた場合は使えない。

`er`は、モデル内の比較が成立するだけでなく、実際に制約があり、本人が試みていないことを要求する。その観測から作った割当てが、介入で置換する前の方程式の解であることも確認する。モデルが実際の観測と矛盾する場合は、妨害が成立したとはしない。

`es`は、先行する文で対象となった人々の範囲が非空で、その全員についてこの条件が成立する内容である。一人だけモデル上の効果がない場合や、実際の制約が適用されていない場合は区別する。

方程式や制約の機構を現実から推定したわけではない。現実の機構へ合っているかは、記述者が別に示す必要がある。

## 原文への対応の限界

これは、行動の試みを制約によって失わせるという明示的なモデル内の解釈である。原文の`wagen durften`に含まれる許可・機会・勇気、慎重さ、強調は未確定である。家畜と歩行器の描写、その前の認知的な変化、後の危険の提示もまだ接続していない。

対応表では、この箇所を解釈を明示した注記として記録した。この断片を新たな著者の独立断言として追加せず、原文と同義な完成訳ともしていない。

## 検証

二変数の全256方程式について、両変数を真／偽へ固定する1,024介入を検査した。介入していない変数が真になる解・偽になる解の有無と、保証、妨害の比較を、Pythonで独立に求めた解と照合した。循環・複数解・解なしも含む。

16個体の文脈、空の変数列、隣接・非隣接の重複、列外の値が不正に真である割当て、変数列にない要因を検査した。原文接続では14例、対象集団への接続では4例を用い、実際の定義を置き換えずに評価した。通常評価と定義の計算再利用も基準例で一致した。

一般文書は基本記号0・定義7、接続文書は基本記号122・定義164である。基本関係の意味規約を与えた有限モデル内の検査であり、現実の因果関係や原文との同義性を実証したものではない。
