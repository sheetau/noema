# 暦内の日付と文書の日付行

カント末尾の未記述単位u0019を追加した。固定転記は「Königsberg in Preußen, den 30. Septemb.[er] 1784.」。保存済み原刊494頁では、著者表示の次に場所と日付が二行で印刷されている。Septemb.に対する[er]は電子版の展開である。

`rqrm`は、指定暦の年番号から年期間を選び、その年の月列、その月の日列の位置で日を指定する。列演算は0始まりなので、第9月は8、第30日は29となる。年番号1784は有理数構文で記述し、月名と日付全体を原語文字列として本文に埋め込まない。暦・年・月・文脈を共通の引数で結ぶため、他の年や月の同じ日番号は代わりにならない。日付だけの一般形は一つの合成定義で、基本記号を持たない。

`hzje`は、この日付と場所を同じ文書の日付行へ結ぶ。名称と場所・地域を分け、名称使用の関係は既存`hzih`を再利用する。KönigsbergとPreußenの綴りは名称個体の識別表記に置く。場所がその日に地域内に位置するという関係を含めるが、現在の領土や政治的主権へ拡張しない。表示する人物、実際の執筆イベント、刊行日も追加しない。

本文には一般関係・関数6個と局所参照10個を追加した。後者は暦、行の提示、文脈、二名称と二対象、年・月・日の期間である。期間を明示したうえで暦内の位置を要求し、個体領域の総当たり探索に依存しない。汎用概念の説明を固有名の綴りで代用するものではない。既存17文と全宣言を保存し、日付行の一文を追加する。定義・参照・識別表記を含む長さを検査報告に残し、末尾の短い一文だけで圧縮率を主張しない。

有限検査は、暦・年・月・日・場所・地域・文書・提示・文脈の取り違え、名称と場所の混同、未知の割当、負・非整数・範囲外の列位置を確認する。隣接日や別の月長も表現できる。暦の列は重複なく全期間を順に並べるという基本関数の意味契約であり、検査用モデルから歴史的な暦の正しさを証明したことにはならない。

原文が使う暦の局所参照を置いた段階で、グレゴリオ暦との同定、改暦による欠番、閏日、絶対時刻との対応は未確認である。Septemberを第9月、30を第30日と読む部分も含め、単位全体の意味確認は未完として集計する。署名単位の既存の判断は依存宣言を確認して新本文へ引き継ぐが、日付行を確認済み単位へ加えない。
