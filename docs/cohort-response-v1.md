# 同じ構成員についての応答傾向の拡大

個人の応答傾向を、固定した集団について比較できる形へ拡張した。集団として二段階で変わることと、全員がそれぞれ二段階で変わることを区別する。前段の個人についての因果条件は保存し、集団の変化を記述する候補を別の注記として加えた。**集団の変化と行為能力を一つの因果条件へ統合する作業は残っている。**

## 人と判断対象の組を保持する

[一般定義](../examples/v016/cohort-response.noema)の `rxk` は、構成員の非空の一覧と範囲を一致させる。各構成員についても、判断対象の非空の一覧と範囲を一致させる。どちらも重複、欠落、範囲外の追加を認めない。判断対象の一覧は人ごとに異なってよい。

`rxl` は各人の各対象への応答を二重に数える。同じ対象でも別の人の応答は別の一件である。集団を一人の巨大な主体へ置き換えず、人と対象をそのまま保持する。

| 時点 | 甲の応答 | 乙の応答 | 集団の件数 |
| --- | --- | --- | ---: |
| 開始 | なし | なし | 0 |
| 中間 | 対象Aに応答 | なし | 1 |
| 終了 | 対象Aに応答 | 対象Aに応答 | 2 |

この例は集団として二回増えるが、一人ずつ見ると増加は一回だけである。新しい `rxn` は集団の拡大を認め、前段の個人の二段階拡大 `rxj` はどちらの人についても成立しない。この差を、個人の評価が欠けているための偽と混同しない。

件数が増えるだけでは足りない。以前成立していた同じ人・対象への応答を、後の全時点でも保持する。甲ができなくなったことを乙の新しい応答で埋め合わせても、今回の強い拡大条件は満たさない。途中の停滞は許すが、始点と終点の間に両端と異なる件数の時点が必要である。隣接点での増加上限と、大きな区間差に対する中間値の条件も課す。

## 評価不足と構成員の交換を除く

`rxm` は同じ人・対象・区間について評価がそろっているかを確認する。構成員と判断対象の完全列挙、時間順序、正の増加上限に加え、全ての人・対象・時点で応答条件の成立・不成立を分類済みとする。全員が応答しなくても評価は成立し得る。応答の増加は `rxn` で別に求める。

[本文草案](../examples/v016/kant-cohort-response.noema)の `ianreviewed` と `ianchange` は、構成員、各人の判断対象、増加上限を、同じ共同体と元の開始点へ固定する。仮定したモデルの解が変わっても、応答できない人を一覧から外したり、容易な判断対象へ交換したりしない。期間の途中で観察できなくなった構成員も、基準の範囲から消えたことにはしない。

応答の内容には前段と同じ `rcr` を使う。同じ本人が自分の理解力を用い、理由に支持され、他者の指導によらず、提示された同じ対象について判断することを要求する。仮定場面の判断を現実の開始点での判断へ移すことはない。所属だけから人であることを補わず、各人に `aa` も要求する。

親文書の全宣言と先行21文を保存した。最後の文では、前段の注記への帰属と新しい集団候補への帰属を連言にしている。新しい候補は階数1の関数記述として引用し、個人の因果ひな形の階数2の記述と区別する。帰属だけで両内容の真偽や、両者の因果的な接続を主張しない。

## 検査と限界

123件のテストが通過した。二人・各一対象・三時点の64通りを、Noemaの実装とは独立したビット集合の計算と照合する。二人・各二対象の16通りでは、同じ話題でも別の人の応答を別に数えることを確認する。異なる長さの対象一覧、件数増加に隠れた応答の喪失、構成員の欠落、評価不足、未知入力、本人・対象・共同体の取り違えも検査する。

本文の診断では実際の判断条件を評価する。集団の二段階拡大、両個人の一段階だけの拡大、現在の判断の不在が同時に成立する例を使う。仮定した解を変えても、構成員と対象の選択が元の開始点に固定されていることも確認する。有限診断用の短絡評価と関数再利用を明示的に使い、キャッシュなしとの比較は一般条件の基準例に限る。 三文書の長形式・短縮形式・固有文字の往復とCLI解析、抽出文書のSVGのXML検査も通過した。これらは原文との意味一致や字形の目視確認を代替しない。

python -X utf8 -m scripts.compose_cohort_response

python -X utf8 -m scripts.check_cohort_response --verify-only

[意味規約](../data/cohort-response-basis-v1.json)と[検査記録](../reports/cohort-response-v1.json)に評価範囲を残す。尺度は応答する人と対象の組の件数であり、人数比や多数派の賛同ではない。対象を多く持つ人は件数へ多く寄与し得る。各人を等しく重み付けした平均や集団的な意思決定とは区別する。

これは有限の同じ構成員についての強い単調な拡大の候補である。民衆の社会的な境界、構成員の出入りを伴う変化、態度や自由の語義全体を定義し終えたものではない。思考の発展・集団の行為能力・政府の原則を一つの条件へ結ぶ作業も残る。原文文字範囲と意味確認済み区間は加算しない。
