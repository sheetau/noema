# 回避傾向と、その傾向への評価

第二段落の冒頭で用いる「怠惰・臆病」の部分解釈に、評価を加えた。従来の定義は、労力や恐れを理由に通常は行為を避けるという傾向だけを表していた。そのままでは、評価されていない休息や慎重な危険回避も、批判的な語の条件を満たしてしまう。

[原文の第一段落と第二段落](https://korpora.org/Kant/aa08/035.html)は、自分の落ち度による未成熟、決意と勇気の不足、他人への委任を続けることを結んでいる。この文脈の読みとして、回避傾向の成立と、その傾向が本人の落ち度として評価されることを結合する。これは採用した解釈であり、二語の全用法や唯一の歴史的読解を決めるものではない。

評価を含まない傾向は `rqxb`・`rqxc` に保存した。前段の `mj`・`mk` の本体と同じであり、通常性、例外、人物、行為、労力または恐れという理由の区別を保つ。新しい `mj`・`mk` は、同じ人物・状況でこの傾向が成立し、既存の一般関係 `hziq` により、その同じ傾向が本人の落ち度に帰せられることを求める。

帰責は独立の条件である。回避したこと、恐れたこと、努力が必要だったこと、結果の原因になったことからは導かない。帰責が否定される場合、傾向だけを述べる文は真でも、新しい評価付きの文は真にならない。帰責が不明なら、非難にも免責にも補完しない。本人ではない人物への評価、別の傾向への評価、別の状況の評価も流用しない。

評価基準は `hziq` に渡す状況の意味規約に含まれる。本文は、その評価を含む因果内容全体を `uc` でカントへ帰属する。したがって、誰の主張として提示されるかは保持される。ただし、帰責基準の全内容を原文が列挙しているわけではなく、今回も独立した道徳理論を定義してはいない。著者の主張の帰属を確認することから、アシスタントが人々の落ち度や因果関係を真と認定することはない。

一般定義 `rqxd` は、任意の性質記述について、同じ本人・状況での内容の成立と帰責を結ぶ。努力や恐れ、カント固有の名前は含めない。本文の二定義はその固定した特殊化であり、既知の内容を直接呼ぶ。一般形の記述実行によって引用の階層を上げず、因果内容を従来どおり引用できる形を保つ。新しい基本関係は追加しない。

検査では、実際のエピソード条件、通常性、傾向、帰責、集団内の要因を実行する。十五種類の傾向条件と二つの帰責の四組合せ、人物・記述・状況の交換、集団外の人物、未知の解釈を調べ、一般形と本文の特殊化を照合する。回避とは無関係な性質にも一般形を適用し、同じ事実が異なる評価状況で異なる帰責を受けられることを確認する。これらは与えた解釈の結合の検査であり、現実の帰責の正しさを判定する仕組みではない。
