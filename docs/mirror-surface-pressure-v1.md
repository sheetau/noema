# 同じ物質的面と圧力の問い

u0215を接続するため、理想鏡の数式に加え、物質的な面・有限の面部分・そこへ作用する力・圧力の候補を構成する。既存394主張と判断は保持し、原文の新しい完成範囲は加えない。

面は固定物質点を持つ厚さ零の剛なシートという理想化で扱う。既存の全物質点履歴・静止・計量・現在出来事記録を再利用し、全時刻の占有集合を座標平面と双方向に一致させる。単なる有限標本の包含は全面の占有ではない。物質点と座標上の位置は区別する。

同じ面はkでξ=0、Kでx=v*tである。各物質点の同一出来事について両系の記録の存在を要求し、全記録対へ正逆Lorentz写像を適用する。時間と空間、別の出来事、成功した一対だけへの選別を区別する。両系の時間区間の数値は等置しない。

面の二接線方向に有限で正長の閉区間を選び、その矩形に属する物質点と、指定したpatchの全物質点とを全時刻で一致させる。patch自身も完全な履歴を持ち、同じ物質点の三座標はbodyと一致する。面積は二つの幅の積で、単位は同じ長さ単位taの二乗とする。x方向のLorentz変換はy,zを変えないため、両系でこの同じ物質部分の面積を用いる。

新しい一般関係eisubは、ある過程がこの部分へ及ぼす機械的な力の寄与を、指定系・単位・区間の三成分履歴へ結ぶ物理的対応である。力は運動量変化への寄与又はそれを釣り合わせる機械的作用との比較で同定する。支持力を含む合力、同じ物体から他へ及ぼす力、任意の数値関数と区別する。この関係自体に光・反射・面積・圧力・時間平均の意味を入れない。

圧力の候補Pは、同じ+x法線力の時間積分をP×面積×区間長へ結ぶ。したがって静止鏡でも正の力と圧力を扱える。P*vの仕事からPを定義せず、v=0で割らない。接線力はあってよく、候補は符号付き実数とする。物理的な反射設定から圧力が正になることは後の導出で扱う。

質問は物体・部分・過程・系・単位・力履歴・区間を候補の外側に固定する。未知の圧力を別の既知値との一致で定義せず、候補ごとに面部分を選び直さない。質問を作ることは、答えの存在・一意性・既知性や著者の質問提示を意味しない。

検証では平面の全占有と有限標本、全同一出来事記録対、矩形の二幅、部分と本体の全三座標、正負・零・時間変化する法線力、非零の接線力、候補を変えた際の対象固定を調べる。有限の数値モデル・積分境界の診断を、全実数上の連続体や積分存在の証明にはしない。

残るのは、この同じ物理的面への前節の入射波・反射波と相互作用過程の所属、完全反射の吸収・透過の読み、力の平均区間と同じ波の周期、反射後の方向・周期数・平均強度、Es seiとWir fragenの提示及び前節照応である。今回の面と力の構成だけでu0215全文を完成扱いしない。
