# 飼育の役割、帰属と家畜の比喩

カント第二段落の家畜という描写について、飼育上の役割と所有主体への帰属を組み合わせた部分的な記述を追加した。対象となる人々についての記述と、動物としての描写を別々に定義し、著者による比喩の提示へ結び付ける。これで家畜の語義全体を定義し終えたとはしない。

## 合成した条件

一般定義 `rab` は、動物の分類、非人であること、継続する飼育上の役割を結ぶ。履歴と期間には既存の時間順序 `tb` を使う。期間は空でなく、履歴内で途中が抜けず、異なる二時点を含む。

選んだ期間の各時点で、人である飼い手が次の三つの関係を同じ動物に対して持つ。

- 生存条件を維持管理する役割。
- 行動・移動・生活条件を飼育のために管理する立場。
- その維持管理が、人間の生活のために活動や産物などを利用する目的に結び付くこと。

ここで扱うのは役割と目的である。毎時点で給餌が実行される条件や、利用目的が実際に達成された条件ではない。飼い手の交代は許すが、一つの時点で異なる人が持つ別々の関係を寄せ集めて、誰かが三関係を担ったことにはしない。分業を含む一般的な飼育組織の説明は、この一人の役割を基に別途構成する必要がある。

所有者と飼い手は別の引数である。飼育されているという条件だけで所有関係は導かない。また、建物内に居住することも要求しない。[対象段落の電子本文](https://www.korpora.org/Kant/aa08/035.html)に加え、カントが放牧される羊を家畜として言及する[別作品の箇所](https://korpora.org/Kant/aa08/021.html)を参照した。後者は建物内という条件を採らない判断の傍証であり、対象段落の比喩の意味を一意に確定する資料ではない。[読解記録](../data/husbandry-reading-review-v1.json)に参照範囲と推論を保存した。

## 原文への接続

| 定義 | 内容 |
| --- | --- |
| `qj` | 現在の対象範囲に属する人で、同じ後見人集団内の人が監督する対象 |
| `qk` | 同じ集団に帰属するものとして描かれ、その集団内の人が継続的に飼育する非人の動物 |
| `qq` | 著者が、`qj` の対象を `qk` として比喩的に提示するという帰属 |

集団を所有主体とする読みを採り、個々の飼い手が単独で所有するとは仮定しない。`qq` は両方の定義への参照を保持するが、その内容を事実として実行評価しない。人である対象について `qj` が真、`qk` が偽でも、比喩の提示は成立し得る。

今回、既存の8主張を維持したまま、この提示の帰属を9番目の主張として追加した。人が文字通り家畜であるという主張は追加していない。

## 検証と残る課題

分類・役割の32組合せ、時間と関係の束縛12例、原文接続15例、監督の対象5例、帰属7例を検査する。所有者・飼い手の集団・動物・時点の取り違え、途中の役割の欠落、単一時点、非凸の期間、循環する時間順序を拒否する。帰属だけを評価する検査では、対象・描写の内容が実行されると失敗する関数を使って分離を確認する。

一般文書は基本述語0・定義5、原文接続文書は累計基本述語153・定義202である。追加した8基本述語には動物分類、三つの飼育関係、帰属、期間・履歴、談話箇所が含まれる。これらを名前だけで完成済みの語義と扱うことはできない。

新規6件と既存の時間表現・比喩・進捗監査を含む関連26テストが通過した。通常・短縮記法と固有文字の往復、検証記録と進捗集計の再生成一致、CLIのJSONと構造の一致、固有文字SVGのXMLとしての妥当性も確認した。今回は言語定義の追加に合わせた検査であり、全テストの再実行は行っていない。

動物の生物学的な基礎、家畜と愛玩動物・飼育下の野生動物等との境界、分業、所有制度、支配や比喩の評価的効果は未解決である。対応する原文範囲は既存の部分草案と重なり、[範囲集計](written-progress-v1.md)の文字数は増えない。意味確認済み区間も増えない。今回の進展は、飼育・帰属・非字義的な提示の区別を構成して検査できるようにした点にある。
