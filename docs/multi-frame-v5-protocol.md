# 出来事ごとに重なる項の範囲を扱う

一つの文に一つのBIO列しかない従来方式では、主節の「父が洗った皿」と、その内側の「父」「皿」を同時に項として抽出できない。今回、固定KWJAが予測した各述語について別のBIO列を推定し、述語を条件にした共通分類器を学習する。

各語の入力は、その語、述語主辞、述語基本句の正規化した文脈ベクトル、語と主辞の積・差の5ベクトルとする。線形・64次元tanhの分類器とBIO連鎖CRFを学習する。語彙別の出力層、辞書、語ごとの規則は使わない。候補述語は学習済みKWJAの「用言」「非用言格解析」から取得し、実行時に正解の述語位置を与えない。

従来の学習64文・開発16文に、二つの出来事を注釈した学習16文・開発4文を追加する。省略した主体を文外の人物として補完しない。各出来事の内部では項の範囲を重ねず、別の出来事の項との重なりを許す。既存の一出来事注釈の文にある未注釈の述語は、引き続き学習損失から除外する。

同じ文に現れる学習述語群を連結成分としてまとめ、成分名をソートして4分割へ配る。役割教師を作る分割モデルでは、その文と関連する述語群をすべて学習から外す。役割候補は述語ごとに抽出した範囲だけとし、別の述語の候補を混ぜない。役割入力は前回の境界特徴を使う。

seed17、AdamW、学習率0.003、重み減衰0.01、200エポック、全件バッチを維持する。範囲は開発の語数正規化した列の負の対数尤度、役割は開発の平均交差エントロピーで線形・MLPとエポックを選ぶ。正解の範囲や述語が語境界・予測述語候補に対応しない場合は、その欠落を記録し、黙って丸めたり正解述語を挿入したりしない。

選択の保存後に、学習・開発にない8述語群を含む新規8文を原文から解析する。範囲と役割の一致を「どの出来事の項か」も含めて数える。新規資料では注釈した全出来事を対象とし、別述語に付けた余分な役割も失敗とする。既存の一出来事資料では未注釈の出来事について完全性を評価できないため、集計を区別する。

述語候補の検出、項範囲、役割、文中の全注釈項の一致を分ける。外側と内側の範囲を出せても、同一の事物への参照統合、修飾関係、否定・数量等を解決したとは扱わない。Noema全体の意味構造95%以上という完成条件は維持する。生成・辞書の不使用、分割の分離、学習再現、原文APIと反復の一致を検査する。
