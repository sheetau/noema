# 市民への賦課と納付の拒否

固定原文 `kant-1784:u0012[2513,2770)` に向け、同じ市民・共同体・公的賦課・納付内容と、その要求への拒否を構成する。後半の批判・反抗・処罰可能性と全文への統合は残るため、新しい意味確認文字数には数えない。

市民の立場は、同じ政治的共同体の成員としての立場と役割保持で結ぶ。官吏への任用や職務委託は要求しない。賦課という負担対象と、履行する移転行為を区別し、出所・本人・立場・受取先・価値媒体を同じ納付要求へ対応させる。支払いの実行には既存の価値移転を再利用し、特定の税目・金額・期限は補わない。

`r33x` の拒否は、その同じ要求への応答として本人が反応を実行し、同じ支払い内容を行わないという実践上の立場を取ることとする。単なる未払い、不能、内心の希望や予測では成立しない。拒否後に支払う場合も表せるよう、拒否の成立に不払いの結果は要求しない。

`r33z` はその拒否内容を成立させてはならないという規範を別に記述する。要求があることから拒否禁止や正当性を自動的に導かず、現実の無拒否・納付済み・物理的な拒否不能とも区別する。本文統合では、同じ要求への候補反応の全範囲に接続する必要がある。
