# 同じ公式発言の試みへの政治的な禁止

第十段落第一文の `was ein Freistaat nicht wagen darf` を、同じ引用方針を公式に述べる試みを政治的・実践的判断上してはならない、という意味で記述する。現行法による禁止に限定せず、積極的許可がないことだけでも成立させない。旧 `rwk` は許可の欠落でも真になるため使わず、同じ対象への負極性の要求を直接確認する。

発言目標は、現行 `r6fy` の許可・服従・唯一の留保と、本人又は資格ある代表者による公式発言である。その主体と活動を二引数として残す閉じた記述を作り、既存 `rwi` へ渡す。同じ目標を認識した非空の全判断候補で不利益な可能結果があり、その目標を目指して活動を始めることを「敢えて試みる」と読む。成功、現実の害、恐怖の心理、勇敢な人格は付け加えない。

共和国の認識と開始は、公的な意思決定に帰属するものとして入力する。代表者の私見や無資格の私人の行動を、その国家自身の判断と試みにはしない。発言を達成した場合の代表資格は既存の発言目標に残す。試みの成立に、実際の発言や許可・平穏の達成を前提としない。

禁止の対象は、この試みの閉じた記述である。規範を調べる際にはその内容を実行しない。実行・成功・許可の有無によらず固定した非空の全活動候補について、同じ主体・共同体・判断基準・公的統治上の役割・引用基準・点で負の要求を調べる。未知入力は拒否する。禁止と積極的許可が衝突する場合でも、明示された禁止そのものを消さない。

`ein Freistaat` は、既に明示した最高職の共同保持モデル `r6fu` に属する全主体への一般的な主張として読む。分類の内容は変更せず、その共同体自身を発言主体として同じ禁止へ結ぶ。共和国の実在、全ての政治主体への禁止、全歴史的共和国へのモデルの十分性は補わない。

六定義 `r6f5–f7, r6ga–gc` と八入力で構成する。入力は、可能結果・不利益・認識・判断候補・開始・追求という既存の六関係を政治的な共同体と基準へ固定したもの、および検討活動の範囲と明示的な要求である。原文の句全体を一つの未説明の関係に置き換えない。後続で判断基準と役割の指示、照応・接続語・強調・全文帰属を統合し、第一文全体を通読する。今回の依存群のみで意味確認文字数を増やさない。
