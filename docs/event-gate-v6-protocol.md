# 述語候補を出来事として扱うかを学習する

v5では、新規8文の余分な役割25件のうち20件が、正解と対応しない述語候補に付いていた。候補を削る語別の規則は加えず、固定モデルの文脈表現から出来事の候補を二値分類する共通ヘッドを追加する。

範囲と役割のモデルはv5の選択済み重みに固定する。学習80文・開発20文と分割も維持し、新しい学習例文や語彙分類は増やさない。注釈と対応する候補を正例とする。文中の全出来事を注釈した資料に限って、対応しない候補を負例とする。一出来事だけの旧注釈では、未注釈候補を負例にせず損失から除く。

特徴は、述語主辞、基本句全体、主辞の直前語、直後語の正規化した文脈表現、および主辞と基本句の要素ごとの積・差の6ベクトルとする。文端の欠ける隣接語はゼロとする。語の文字列や辞書項目は特徴抽出に使わない。

線形と64次元tanhを比較する。seed17、AdamW、学習率0.003、重み減衰0.01、全件バッチ、200エポックを維持し、開発平均交差エントロピーで方式とエポックを選ぶ。分類は二値のargmaxとし、評価を見た閾値調整やクラス重みは追加しない。

選択を保存した後に、新しい12文を解析する。「料理人／料理した」「研究者／研究した」など同じ語を含む名詞と出来事を同一文に含め、名前の除外だけでは通らない確認資料とする。主節だけの8文と、主節・修飾節の両方を注釈した4文を含む。対応する6述語群は今回の学習・開発から外す。

候補判定の正負、正しい出来事を落とした件数、上流ですでに検出できなかった出来事を分けて報告する。範囲・役割の保持と余分な項も数え、正しい出来事を捨てた結果を精度改善として隠さない。v5の全候補方式を同じ原文・同じ範囲と役割の重みで比較する。

候補が出来事ではないと判定されても、原文や元解析を消さない。たとえば「によって」が表す関係をすべて不要と判断したことにはならない。今回の対象は出来事候補であり、原因・修飾・参照などの全意味構造への変換は別に必要である。生成・辞書の不使用、同一条件の再学習、保存モデルでの原文解析と反復一致を検査する。
