# 同じ原因による後の政府原則の変化

u0017の政府原則への作用を、民衆の心的傾向・行為能力の変化と同じ集団原因が、後の原則内容の採用変化にも差を生じさせることとして読む。政府への作用に別の因果モデルを選び直さず、同じ変数・方程式・背景・観測割当てを使う。民衆への作用が政府への作用を完全に媒介することや、原因側の各人が一人ずつ必要であることは要求しない。

時間の接続では、心的・能力変化を確認する点より後に政治的な評価点を置く。元の履歴の全点・順序と始点から中間終点までの区間を保持し、延長した履歴から各介入解の履歴への対応も全射・一対一・順序保存にする。元の範囲での対応は既存の写像と一致させる。中間終点は民衆の変化が完全に止まる時刻ではなく、政府作用の初発が必ずその後だとも断言しない。

`r6l2` が履歴、`r6l3` が原則の採用内容を表す変数を検査する。`r6l4` は、同じ政府・規則範囲・公的立場について、全候補の始点と政治的終点で実際の採用内容を評価し、変数の値と照合する。規則の名前だけを付け替えた場合は、既存 `r6k6` の内容同値類による比較を保つ。内容が常に一致する複数箇所で変数を共有してもよいが、原因変数そのものへの置換は認めない。

`r6l5` は、少なくとも一つの規則内容について、観測と対照の前後の採用増減を比較する。例えば観測で二つの内容が新たに採用され、対照でもその一つが採用される場合に、残りの内容の変化へ原因が寄与することを表せる。両側の変化が全く同じ場合や、初めからの差が一定の場合は足りない。採用と撤回という反対方向の変化は区別する。終点で元へ戻る途中だけの変化は、この前後比較の対象外である。

`r6l6` は、観測された原則変更と、原因要因の真偽両側に解があり全解で内容・時間が整うことを要求する。偽側の全解で観測と異なる採用変化を確認し、一つの都合のよい解だけを選ばない。原則の変更全体が偽側で消えること、旧規則の撤回と新規則の採用の両方を必須にはしない。この比較は公開した構造モデルに依存し、有限検査による現実の社会的因果の実証ではない。

`r6l7` と `r6ma` は、同じ政治的終点で、同じ全人間成員の自分の理由による行為能力と、同じ政府の尊厳に応じた扱いへの自己利益判断を結ぶ。集団の能力得点の増加だけから全員の能力を推論せず、能力のある人だけを尊厳の対象にもしない。利益判断から実際の利益・履行や尊厳方針の規範的採用を追加しない。

今回の時間条件は `endlich` の採用解釈であり、`auch/sogar` の追加・期待上の強調を代用しない。前件の比喩、`Wenn/so` の全体量化、著者注参照と全文帰属・通読判断は残る。部分定義の原文対応と単位全体の意味判断を区別する。
