# 期限の円文字接続と複数ページの本文

[期限の14定義](shared-deadlines-v1.md)を円文字辞書第10版へ接続した。特定の時点を閉じた記述で指す共通関数を1つ追加し、辞書は267語（245構成定義・22基本宣言）になった。旧252語の綴り・本体・型・意味規約は保持する。新語は[公開辞書](../noema/resources/visible-deadline-vocabulary-v1.json)のbook/above系の複合語で、単独の基本字形は増やしていない。

## 閉じた記述で状況を指す

期限条件を約束や規範の対象として引用するには、期限・起点を閉じた記述で指定する必要がある。以前の円文字辞書には状況を返す基本関数がなく、量化した時点変数をそのまま閉じた引用に持ち込むこともできなかった。

追加した`situationslot`は文脈識別子と有理数のアドレスを受け取り、その文脈の参照表が指定する状況を返す。[Native宣言](../examples/v016/shared-situation-reference-v1.noema)と[意味規約](../data/shared-situation-reference-basis-v1.json)を独立して保存した。アドレスの大小は時間順序を含意せず、差は経過時間を表さない。参照表を変えても、同じ対応で本文の時点名を解釈し直す限り判定は保たれる。

この基本関数は時点の参照だけを解釈する。期限・履行・解除を外部で判定する関数ではない。完全なモデルでは全引数の解釈を要し、有限実行で未指定の文脈やアドレスを要求した場合は未知として拒否する。既定の時点や偽を補わない。

## 認定根拠を含む五ページ

[接続例](../examples/v016/visible-deadline-history-v1.noema)には、約束、起点の規範認定、権限と理由を持つ解除、実現の内容、四時点の範囲と順序を全て記述した。外部モデルが解釈するのは、既存の二個体名と四つの状況参照だけである。これらの関係を実際の制度について認定した例ではない。

同じ本文で11の問いを評価する。期限前と期限時点では未実現で猶予中、期限後には実現と解除があるが、期限時点の不履行も残る。現在の行為の成立と、期限条件の成立は異なる。調査完了を明示しない場合には、不履行の認定は成立しない。

この全体は2,951字形となり、従来の一ページ上限には収まらなかった。共通関数で記述の反復を減らした上で、全文を五ページに分けて描く。新しい複数ページ入口は、各ページの上限を本文768字形・4,096図形に保ち、一文書を最大8ページ、通算128行、共有展開後8,192節点に制限する。従来の一ページ入口は変更せず、この本文を一ページとして与えると拒否する。複数ページ入口では文書全体の字形数が768を超えられることを明示した拡張である。

行番号はページをまたいで継続し、最終行だけに終了記号がある。復号器はSVGの円と線から行番号と継続記号を読み、本文の構文上分割できる位置で行が終わることも検査する。ファイル名、SVG要素順、不可視のASTや文書別対応表には依存しない。ページの欠落・重複・順序違い・途中終了を拒否する。ただし構文的に有効な別本文への改変を暗号学的に検出する仕組みではない。

```powershell
python -X utf8 -m scripts.visible_deadline_book render examples/v016/visible-deadline-history-v1.noema output/deadline-copy --public-names
python -X utf8 -m scripts.visible_deadline_book decode output/deadline-copy/page-1.svg output/deadline-copy/page-2.svg output/deadline-copy/page-3.svg output/deadline-copy/page-4.svg output/deadline-copy/page-5.svg --native --public-names
```

短い文書には従来と同じ一ページ操作も使える。`scripts.visible_deadline_page`は辞書第1〜10版の可視ヘッダーを読み分ける。

## 検証の範囲

[検証報告](../reports/visible-deadline-v1.json)は新15語の型付き呼出しと引用、辞書の一ページ、接続例の五ページを記録する。引用段階は期限内容を実行評価する9定義が1、それ以外が0である。図形復号後に正本の構造と一致することを確認してから、11の問いを有限モデルで評価する。

実現を期限時点へ移すと、期限内履行が成立して不履行・遅い実現は成立しなくなる。認定根拠の欠落と、権限または解除行為の欠落も別々に検査する。参照先の時点名を入れ替えても、アドレスの大小を時間順序へ読み替えないことを確認する。Native期限の40テスト・1,024モデル等の既存報告は保持する。

高階関数の全値や連続時間全域の証明、画像OCR、人による学習と第三者読解はこの検証に含めない。二作品全体の新書式化も未完である。今回の複数ページ処理は一文書の有限な規模を拡張したもので、二作品の全文表示を完了したとはしない。
