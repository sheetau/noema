# 補助座標x′と、運動系の時刻を求める下位課題

アインシュタイン§3の `u0048` を部分記述した。x′をx-vtと置く定義、運動系で静止する点のx′・y・zが時間に依存しないという主張、まずτを求める課題、そのため同期時計の読みを方程式で表すという目的を分けて保存する。

`sif` は有理数のx-vt、`sig` は指定された差と積による同じ演算、`sin` は実切断の差と符号付き積への接続である。xとtには静止系の値を使う。x′を運動系の物差しで測ったξへ置き換えず、tを運動系の時計のτへ置き換えることもしない。

`sih` は、同じ点の全対象時刻について全指定成分が一定である条件を表す。点の範囲は空でなく、時刻には時間幅が必要である。全点・全時刻で座標が利用可能であることも要求する。始点と終点だけ同じでも、途中で値が変われば条件を満たさない。別の点同士の座標が同じであることは要求しない。

原文接続の `sik` は、運動系で静止する点を対象に取り、同じ速度、静止系の時刻、長さと時間の単位、座標の利用可能性を結ぶ。`sij` がx-vt・y・zを取り出し、`sil` が実切断の演算へ接続する。運動系で動いている点はこの不変性の主張の対象外であり、範囲内の静止点を別々の時刻で選び直すことはしない。

τを求める下位課題は、四つの実数値x′・y・z・tを引数とする関数を答えとする質問 `sip` で表す。候補条件 `sio` は、対象範囲の同じ出来事の座標対応すべてについて、候補関数の出力が運動系の時刻値と一致することを要求する。その時刻値は前段の `shd`・`sgp` を通じ、同じ系で静止し同期した配備時計の読みに結ばれている。今回の質問に具体的なτの式は埋め込んでいない。

著者への帰属には、補助量の定義の導入、静止点の座標についての主張と明白さの提示、先行する座標変換課題の中でまず取り組む下位課題、同期時計の条件を方程式で表す必要をそれぞれ記述する。引用した内容は実行せず、答えが発見済みであることや目的の達成を含意させない。

新規8件を含む関連30テストが通過した。一般定義の履歴12例、原文との接続17例、τの候補14例、帰属11例を検査した。途中の時刻だけ変わる座標、時間幅のない例、時刻や座標の欠落、速度や単位の不一致を拒否する。τの候補がx′をxへ置き換える場合、引数の一つを無視する場合、別の系・速度・設定を使う場合も拒否する。

有理数の代数的検査では、二時点のx′の一致と `x₂-x₁ = v(t₂-t₁)` の同値、`x = x₀+vt` の補助座標がx₀になること、`x = x′+vt` による復元を確認した。一方、速度を変更しても補助座標が必ず同じになるという主張と、任意に尺度を変えた座標がx′と必ず等しいという主張には反例を得た。この検査は物理的な静止と等速並進の一般的同値性の証明ではない。
