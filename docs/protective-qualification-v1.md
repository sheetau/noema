# 発言資格と、同じ指揮者による共同体の保護

カント第17区間の軍隊・規律・人数・公的平穏・利用可能性に関わる部分へ、既存の共同保護の定義を接続した。前段では一つの未充足引数だった条件を、集団の人数、同じ指揮者の要求への適合、共同体を保護する計画の存在へ分解する。軍隊の制度的な役割と、公的平穏全体の説明は残余条件として保持している。

[原文 AA VIII, 41頁24–25行](https://www.korpora.org/Kant/aa08/041.html)で、集団を持つ人物が発言資格の候補者と同じであることを確認した。今回の記述は、その文への操作的な解釈注記であり、原文の唯一の読みや意味一致を確認した訳ではない。

## 既存の保護条件を本文で使う

[後継草案](../examples/v016/kant-protective-qualification.noema)の `hzxgroup` は、既存の `rvh` をそのまま呼ぶ。次の条件を同じ候補者・集団・基準文脈に結ぶ。

- 構成員列がその集団を過不足なく列挙し、重複がなく、人数基準を満たす。
- 利用可能な計画が存在し、その全てについて、構成員が同じ指揮者・集団・計画の要求を満たす。
- 同じ共同体の活動可能性と保有を守る計画が存在し、保護の介入比較・内容対応・評価結果の記録も整合する。

人数基準は文脈の引数として持ち、原文にない具体的な人数を補わない。全計画での要求適合は規律の強い候補であり、訓練の履歴や例外の頻度を意味するものではない。保護対象の活動・保有も、公的平穏の全条件と同義にはしない。

## 情報と集団を取り違えない

保護に必要な情報を選ぶ各関数には、同じ候補者・集団・基準文脈を渡す。人数だけ別時点から取ったり、保護機構だけ別集団から取ったりすることを、構文上の省略で許さない。返された関係の内部では、従来の定義が指揮者・集団・構成員・計画・文脈を改めて照合する。

`hzxremaining` は、保護条件と残余条件を満たす集団の存在を要求する。残余条件へ渡す共同体は、保護条件へ渡す共同体と同じ選択結果である。別々の集団でそれぞれの条件を満たすだけでは成立しない。

残余引数 `qualification` は、候補者・集団・共同体・基準文脈を受け取る。軍隊としての役割や、保護対象を公的平穏の条件として採る妥当性をここへ接続する必要がある。語を新しい原始記号に置き換えて説明を終えたとは扱わない。

`hzxonly` は、この存在条件を前段の `hzwonly` へ渡す。啓蒙と影の解釈候補、発言能力と引用内の参照照合は保持する。前段の全宣言と先行18文を残し、最後の解釈注記を新しいひな形へ更新した。[接続部分の抽出文書](../examples/v016/protective-qualification-core.noema)も保存する。

## 検査の範囲

26テストが通過した。本文は1,673宣言・19文、抽出文書は203宣言・1文で、両方のCLI解析と抽出文書のSVGのXML検査も通過した。SVGの目視確認は行っていない。

検査は、保存された `hzxgroup` と `hzxremaining`、既存 `rvh` とその依存定義を実際に評価する。人数不足、別人・別集団・別時点、命令と計画の取り違え、失敗する別計画、空の要求では保護条件が成立しない例を扱う。入力が未知の場合は、偽として補完しない。

要求網羅性の全行為記述への量化は、保存文書では変更しない。有限検査用コピーだけを従来の二記述へ具体化し、全域の直接評価は拒否されることを確認する。帰属文を評価しても、引用された保護条件や影の解釈は実行されない。

本文の `hzxonly` から `hzwonly` への引数の接続は、実際の構文木で確認する。新しい保護モデルと前段の発言能力モデルを一つの解釈で同時実行した検査ではない。この境界を[検査記録](../reports/protective-qualification-v1.json)にも明記し、全文の意味確認に代用しない。

```powershell
python -X utf8 -m scripts.compose_protective_qualification
python -X utf8 -m scripts.check_protective_qualification --verify-only
python -X utf8 -m pytest tests/test_protective_qualification.py -q
```

正当な指揮権を原文へ追加することはしていない。軍事的役割、訓練・即応性、暴力や騒擾の不在、原文の保証の読み、残余条件の同定と原文全体の意味確認は未完である。詳細は[意味条件](../data/protective-qualification-basis-v1.json)に記録する。
