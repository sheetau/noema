# 通常の運動学の仮定と幾何学的な置換

原刊896頁のu0034は、一般に使われる運動学が、先の二操作で決めた長さを互いに厳密に等しいと暗黙に仮定する、と述べる。続く「oder mit anderen Worten」は、それを動く剛体の幾何学的置換として言い換える。この帰属を保持し、著者がその仮定を承認したという内容へ変えない。

二操作の長さは、前の二文の初期静止長との比較ではない。現行のeip2/eip6と設定ye/yfを、既存sckの存在・値の一意性・相互の厳密な一致へ結ぶ。「暗黙」は仮定の使用ztと明示zuの否定を同じ体系・範囲で要求するscjとして保持する。単に明示の記録が見つからなかった場合とは区別する。広く用いられるというzsの社会的関係は、使用率や全員一致を要求しない。

幾何学的に完全に置換できるとは、同じ時刻・基準系・校正した尺度で、同じ物体の二配置の全占有位置が一致することと読む。全物質点の三座標像について、第一配置の各点に同じ位置の第二配置の点があり、その逆も成立する。二端の距離、重心や有限の測定標本の一致では足りない。物質点のラベルまで同じ位置であるとは要求せず、密度、速度、時計表示や力学的作用の同一性も付け加えない。

動く側と静止側は同じ物体と全物質点の範囲を保つ。運動と静止はeiag/eiah、剛性と固定計量はeigy、完全な物質点履歴はそれらに含まれるeiadに接続する。両方に正の幅の時間区間を要求し、指定時刻をその共通部分へ置く。印刷されたtは既存zpへの参照とし、前の操作bのxvやゼロ時刻へ同一視しない。tは任意に指定された比較時刻として読む。

比較側の静止配置は既存zlが許す同じ物体の配置から選ぶ。ここでzlを物理的入力として採る際、その物体の静止時の形状と寸法を保つ位置・姿勢の選択を意味する。移動中の形を単に凍結した任意の静止模型、物体の加工・変形や別物体への交換を、この関係の実例として補わない。静止形状や許容配置の物理的充足は入力の規約であり、幾何の数値が一致することから推測しない。停止に至る加速度や力、停止過程での剛性はこの可能性の記述には要求しない。

一般の運動剛体の範囲znは、考察設定ydで扱う全対象を含むという既存の意味規約で読む。棒一つや置換できるものだけを選ぶ範囲ではない。非空性と全対象への適用を保持し、各対象について少なくとも一つの適切な静止配置を要求する。物体や配置の唯一性は加えない。時間・対象・設定を任意に指定した一般命題であり、検査の小さな有限領域と原文の範囲を同一視しない。

長さの一致から任意の剛体の全形状一致は自動では導けない。そこで二内容はそれぞれ記述し、既存zxによって著者の言い換えとして接続する。この一文専用の原始関係は追加していない。

検査は、全座標像の双方向の一致、内部だけの形状差、点ラベルの入れ替え、余分な占有点、空の物体、異なる時刻・単位・履歴・許容配置、暗黙と明示、二つの仮定の引用を対象とする。実数切断全域や完全な物理履歴を有限標本で証明しない。原文の全体判断は、この意味規約を明示した上で別に行う。
