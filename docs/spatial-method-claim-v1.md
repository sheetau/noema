# 空間座標の計算方法と縦方向光線の二式

原刊899頁のu0065–u0068を、先行するτの利用、空間三成分を求める低負担の方法、二原理によるkの光速度の要請、ξ=Vτとその代入式の提示として接続する。原刊画像、固定原文と六つの数式要素を照合した。

## 計算方法と「容易」

目標は現在の方程式課題eiy4の答えである。ei5bは候補空間写像から三式を組み立て、同じzd4のτ(x−vt,y,z,t)を第四式へ残す。候補は同じ方法と段階に割り当てられる。原文にない具体的な候補や実行済みの解を補わない。

容易さは、この議論で利用できる計算方法の負担が小さいという評価として読む。既存s2yは、同じ有限手順列の接続、各手順の非負負担、その合計と文脈基準を要求する。ei5iは出発内容を先行τと二原理へ、到達内容を同じ候補のeiy4へ固定し、途中でτとkの光速度の式ei5fを用いる。同じkのei43は全適用区間の経路長=V×経過時間を現在の時計と測定へ結ぶので、単なる記号Vの引用で代用しない。

manはこの議論の方法を用いる主体として著者に代表させる。全読者の能力、実際の計算時間、具体的な負担値や手順数は主張しない。手順と許容変形は既存の入力規約zlx/zlaであり、ここで歴史的な計算履歴や機械証明を創作するものではない。原文は容易さを著者の評価として述べているため、その評価の真理と記述の完成を分ける。

## 二原理・光線・表示式

ei5dは現在のK/kの等速並進、第一原理eion、Kの第二原理eiosとτ対応を保つ。ei5kはここからkでも同じVを測るei43が要請されるという著者の提示である。Kの参照時計をkへ流用しない。

選択した同じ二区間のei5aを光線の前提とする。τ=0で正のξ方向へ放出するという原文と前後の零点規約に合わせ、同じ原点からの放出と読む。これは時刻零だけから空間原点を推論することではない。全区間の直線一定速度、両端の出来事と現在四座標、同じτとφ(v)を維持する。

ξ=Vτは既存snr、ξ=aV(t−v*x′/(V²−v²))は既存snsを再利用する。oderはこの同じ条件の下での等価な別表示としてzd3で保持する。未定のaを1に固定せず、光線上の式を全空間の変換へ拡張しない。V−vとtの消去は後続u0069以降に残す。
