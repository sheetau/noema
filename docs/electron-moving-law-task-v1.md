# 速度vの場合と初期運動法則の探究

原刊917頁のu0244には二つの役割がある。第一文は、先に導入した同じ電子が指定時点で速さvを持つ第二の場合を置く指示である。第二文は、その同じ時点の直後の運動法則を探すという現在の課題を述べる。先の静止条件の法則、同じ粒子の物理的設定、初期速度変化、仮定の提示、著者への帰属を再利用し、瞬間速度の大きさと法則候補の同じ設定への対応を補う。

vは三つの符号付き瞬間速度から得る非負の大きさと読む。次の文がX軸方向を選ぶため、この二文では方向を固定しない。零は退化例として許し、第二の場合という順序を排他的な二分法へ替えない。現在の速度、全期間の等速運動、二系間の並進速度は異なる。直後は前段と同じ通常実数の右側の初期微分であり、有限時間の一定加速や厳密軌道解は足さない。

答えの型は物理的な運動法則である。三加速度の数値だけには縮めない。既存の法則範囲vd、法則としての一般的な成立eisbi、記述の適合viを使い、同じ粒子・系への適用範囲と同じ物理的設定の全対応記述を結ぶ。対応記述を一つは要求し、その全てが同じ法則へ適合することを候補条件に置く。特定の公式をまだ知らない問いなので、法則の許容条件はlawを引数とするviに保持する。後続の答えを統合する際は、その法則と実際の方程式内容を接続する必要がある。

設定は質問の外側で固定し、法則候補ごとに粒子・時点・場を選び直さない。問いを提示したことから、仮定の現実成立や答えの発見・存在・一意性は導かない。物理法則としての成立は明示的な物理入力であり、有限点で数式が合うだけで真と認定しない。

検査では三次元ノルム、同じ時点の三速度、設定と候補の束縛、記述の欠落・余分な不適合記述、法則の成立と適合の区別、二文の発話形式と順序を対照する。原文の全文判断はそれらの検査と別に記録する。第十節見出しu0239、次の座標選択と瞬間静止系への移行は残る。
