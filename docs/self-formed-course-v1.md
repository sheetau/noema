# 自己形成を二つの成果へ結ぶ

第五文の自己形成を、自立の達成と確かな知的活動の双方へかかるものとして接続した。旧草案は自己形成が自立を生じさせることと、その後に確かな活動を持つことを表していたが、時間順だけでは後者への因果を表せない。

[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)の並列を再読し、「自分の精神への働きかけによって」を両成果へかける読みを採る。これは明示した解釈であり、狭い範囲の読みが文法的に不可能だという主張ではない。

## 同じ作業と同じ活動を因果へ渡す

`r2kb` は、本人・自己形成過程・先行時点・自立達成時点・知的活動・活動完了時点・基準時を固定する。既存 `rct` で、同じ本人と履歴に自立達成 `h4p` と確かな活動 `r2ji` を接続する。そこへ、同じ過程が同じ活動の成立に寄与する `rqqu` を加えた。

因果の要因記述 `r2jz` は、その過程が自己形成によって自立を達成した過程であったことを表す。結果記述 `r2ka` は、その活動が確かな知的活動であったことを表す。両記述は同じ基準時までの履歴を扱うため、作業と活動が現在も続いている必要はない。外側でも同じ本人の過程・活動・時点を検査するので、別人の経験を混ぜられない。

自己形成から自立への結果生成 `g3` は従来どおり残す。新しい寄与 `hzie` は、その自己形成過程から知的活動への関係である。どちらも共存や時間順、原因として説明されたという帰属だけでは代用しない。唯一原因性や因果機構の新しい理論は加えない。

過程と知的活動が同じ複合過程の二つの記述である場合も許す。ただし、同じ個体であれば因果が自動的に成立するとはしない。他者が同じ作業に参加する場合や、他の原因がある場合も排除しない。

## 精神への自己活動の読み

既存 `h4m` は本人の考え方・判断の習慣・認知的な働きなどの部分を表し、任意の所有物や物理的な脳器官とは区別する。`h4n` は、その部分のあり方を本人が吟味し組み直すように働きかける関係である。`h4o` が本人・部分・作業を共有して両者を結ぶ。この意味規約を今回の自己形成の読みとして採用する。

原文は具体的な方法・反復回数・努力量を示していないため、それらの値を翻訳条件に足さない。精神の全構成を解明したという判断でもない。単なる能力の使用、他人の精神への作業、同時にあった別の作業では不足する。成功そのものは作業の種類に埋め込まず、結果・活動・因果の接続で別に要求する。

## 数量への統合と検証

新しい成功者条件 `r2kc` を、評価条件・人数・数量の限定・譲歩背景の全てへ接続した。基本記号は追加せず、十五の合成定義を追加する。歩行比喩の対象となる確かな活動は前版と同じなので、その帰属14番は保持し、結論の帰属15番だけを更新した。

局所検査は精神的な部分、自己活動、本人の参加、変化過程、自立への結果生成、両成果の時間順と寄与を実行する。能力内容と前版で検査した確かな活動の内部は境界入力とし、そのことを報告へ明記する。別人・別作業・別活動・別の記述・別時点の因果を拒否し、同時完了、同じ複合過程、共同参加を区別する。成功者の存在量化も、因果がある場合と共存だけの場合で実行する。

既存十二単位と先頭四文の判断は保持する。残るのは解放の描写と対象側の対応、および第五文と第三段落の通し確認である。今回だけで意味確認済み文字数を増やさない。
