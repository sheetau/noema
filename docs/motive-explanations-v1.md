# 行為回避の理由と、複数の原因を挙げる説明

[動機と説明の定義](../examples/v014/motive-explanations.noema)を、既存の関数・量化・有限列・式記述から構成し、[カント第二段落の草案](../examples/v014/kant-motive-explanations.noema)へ接続した。行為を避けること、ある要因を回避の理由とすること、集団についての結果の原因として挙げることを分ける。

## 労力と恐れを別の理由として扱う

nbは、その人に関係する行為があり、指定した要因が成立し、本人が行為を避け、その要因の記述が回避理由として採用される条件である。全条件で本人・行為・状況を共有する。別の行為で労力を予想したことを、いま避けている行為の理由として流用しない。

原文草案ではmfが労力を理由とする回避、mgが害や危険への恐れを理由とする回避の例を表す。行為が実行されなかったことだけで回避とせず、労力が要ることを知的能力の不足と同一視しない。恐れていることから客観的な危険の実在も導かない。理由の採用は関係meで明示し、要因と回避が同時に成立するだけでは理由と判定しない。

ncは、指定された評価機会が空でなく、その全てでエピソード条件が成立するという反復の条件である。mjとmkはそれぞれmf・mgをこの条件へ渡す。単発の例を生涯の性格へ拡張せず、評価範囲をmhで明示する。

これは「Faulheit」「Feigheit」を回避傾向として構成する読解候補である。単なる決意不足や勇気不足の別名にはしていないが、程度、規範的な評価、例外を許す傾向や確率的な意味までは含めていない。労力・恐れ・回避の一般的な説明と評価機会の代表性も残る。

## 同じ集団の結果について原因を挙げる

mpは説明対象の集団と構成員の列を対応させる。mqはその中にmjの傾向を持つ人がいること、mrはmkの傾向を持つ人がいることを表す。両者が同じ人であることや、全員が両方に該当することは要求しない。

msは、同じ集団の列を既存khへ渡し、先行する移行と譲歩を含む割合の内容を指す。mtはmqとmrの記述の列である。naは列が空でなく、各要因が同じ対象・結果の原因説明へ採用されることを要求する。原因説明の基本関係には既存eaを再利用した。

muは、mtの二要因を、集団の結果msの原因として挙げる条件である。これは二要因をそれぞれ説明へ採用する読みであり、二つを連言したものだけが一体の原因になるという読みとは区別する。各要因が単独で十分条件になること、両者の相互作用、必要性、これ以外に原因がないことは主張しない。

mxはこの説明の内容を作る。本文には、第二段落の談話節点mwで著者waがmxを主張するという帰属を追加した。要因を原因として挙げたという説明と、要因の現実の存在や介入効果の証明は別である。著者へ帰属させる際にも、引用された内容を実行して真と認定しない。

原文には続いて「他者が後見人になることが容易になる」という第二の結果があるが、その接続はまだ行っていない。今回の帰属は最初の結果についての部分草案であり、第一文全体の完成ではない。自然の比喩、原因の機構、語義の独立確認、段落の残部と原刊確認も残る。確認済み全文単位数はカント0/20・アインシュタイン0/282のままである。

## 検証

行為の関連性・要因・回避・理由採用の16組合せと、別行為への取り違えを検査した。10の傾向モデルでは、二要因が別人に存在する場合、片方だけ、空の評価範囲、途中の欠落、集団外、異なる理由・行為・人物を区別した。同じ真偽を持つ労力と恐れでも、理由の記述は区別する。

9つの説明モデルでは、片方の原因しか採用しない場合、別の集団・結果・文脈、説明の逆転を検査した。空の原因列も拒否する。説明や著者への帰属を記述しただけでは、要因や結果の内容を評価しないことを検査した。

```powershell
python -S -m scripts.compose_motive_explanations
python -S -m scripts.check_motive_explanations --verify-only

python -m pytest -q
```
