# 同じ変更不能な信条への相互引受け

第六段落冒頭の問いに向け、[irrevisable-confession.noema](../examples/v016/irrevisable-confession.noema)に同じ信条の保持、制度上の変更不能、他の全当事者に対する引受けを接続した。旧`rh4`は有限区間での基準保持を表す部分候補だった。今回は、保持の結果と変更を認める権能を別々に構成する。

`r46p`は宗教的主題と信条の定式化を結ぶ。`r46q`は同じ信条の内容を保つ採用、`r46r`は全改訂候補のうち実質的内容を変えるものが同じ合意の規則では認められない条件を表す。`r46s`で両者を結び、`r46t`で候補履歴の基準以後の全体へ接続する。過去に変更しなかっただけでも、変更を認める規則があるなら変更不能とは数えない。

内容の一致には新しい基本関係`h254w`を使う。Noemaの閉じた二記述を受け、同じ信条の固定解釈で実質的な内容を保つことを述べる。表記や構造が違っても内容を保つ改記を許す一方、同じ名称や同じ真理値だけでは一致としない。これは意味解釈の契約であり、任意の記述の同義性を自動判定する仕組みではない。

改訂候補は基準時に固定し、許可されたものや実際に提出された案だけへ絞らない。元の信条を保持する選択も範囲に含める。制度上の変更不能は、その合意の規則の内部における改訂権能の不在として読む。原文の後続部分で問われる、そのような拘束を設ける道徳的な権限とは別である。

`r46u`は本人・合意・団体・信条・主題の正確な五個体列を受ける条項である。全員が同じ共同の制度上の規則を、自分も拘束されるものとして引き受ける。先頭の本人だけを変え、その他の対象と合意の基準時は共有する。各人の内心の信仰、履行の成功、同じ人間の不死を要求しない。

`r46v`は既存`hzcg`の相互引受けを使い、基準時の全所属者を当事者にする。さらに、各人の同じ引受け行為・時点で、他の全当事者に対して責務を負う表明を要求する。全員が別々に独白しただけ、一人の約束と別行為の相互関係を合わせた場合、二人目だけが別の信条を引き受けた場合は満たさない。表明の成立から、条項の真理・履行・正当性を導かない。

[検査](../reports/irrevisable-confession-v1.json)では、内容を保つ改記、同名のままの教理変更、採用中断、改訂が許されるだけで実際には起きない場合、途中での変更・復帰を区別する。全当事者の相互表明は実際の旧`hzcg`を使って評価する。五引数の条項アダプターは持続部分を型付き境界にし、持続条件そのものの実評価と分けた。未知の候補・内容の一致・権能・表明を偽に補わない。

履歴と改訂候補の完全さは明示解釈の入力条件であり、有限検査だけで全将来や全候補を観測したことにはならない。元の信条を含む候補範囲を、都合よく元の一件だけへ縮めることも許さない。rcaの全将来を使うが、数値的な無限時間や終点のない履歴はこの語だけから追加しない。

[読解記録](../data/irrevisable-confession-reading-v1.json)は原刊488頁と固定本文の範囲を保持する。eidlichの宣誓修飾、団体の例示・自己呼称、上位後見と人民への媒介という目的、権限の問いと次の否定回答はこれから結ぶ。今回は問い全体の意味判断ではなく、本文96主張と確認済み分量は変えていない。
