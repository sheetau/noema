# 序文の磁石・導体の非対称性の解消

対象はEinstein 1905のu0177第一文である。原刊910頁の「Es ist ferner klar」から「verschwindet.」までを、序文の磁石・導体の例と前段の新しい力の言い方に接続する。第二文の単極機と力の「Sitz」の問いは別に構成する。

序文の非対称性は、通常の理解の下で磁石運動・導体静止とその逆を異なる説明機構へ必然的に分類する扱いとして記述してある。既存eiddは、許される完全な説明が非空であり、その全てで二場合の分類が非空かつ互いに交わらないことを述べる。一方、同じ相対運動で観測される電流が一致する内容はeidgへ分けてある。今回の解消を、電流値の一致だけで表すことはできない。

解消は、同じ分類観点で両場合を共通の機構によって説明できる、という読みを採る。新しいejz5は、許容説明が非空であり、その全てに両場合で共有する分類がある、とする。全ての分類名が一致すること、説明が一つしかないこと、電気・磁気の成分が各系で同一になることは要求しない。分類の意味は既存eisagのままであり、「いずれも物理現象である」という別の粗い分類に替えない。

比較の範囲は序文の同じ磁石eisaa・導体eisab・過程eisacから引き継ぐ。ejz6は、物理的に妥当な二場合eida、同じ相対履歴eia2、運動側と静止側の交換、同じ電流への相対運動の生成寄与を結ぶ。生成寄与eisq5は、同じ物質点・全履歴・区間対応・電荷輸送を共有する物理的な関係である。数値一致や時間順だけから生成を認定しない。既存の場・物体・導体能力・準備条件はeidaの内部に保持する。

ejz7は、この具体的な比較を二系・二状況・範囲へ射影する。物理量と履歴の証人は一組のまま保持し、別の配置の断片を混ぜない。ekabは全ての比較に、同じ現在の見方での共通説明を要求する。一般的な条件主張として表し、比較例を実験で実現したという存在主張は加えない。許容された比較では説明が一件もないまま条件を満たすことはできない。

現在の見方eisq6は、同じ論説で展開した理論eisqwへの解釈関係eisayを持つ。序文で取り上げた通常の理解eisakを上書きせず、見方を区別したまま同じ例へ適用する。一般的な非対称性の導入eir7/eiezと、例での説明上の区別eisaj/eidhへの後方参照を記録する。fernerは前の結論への追加、klarは同じ主張を著者が明白と提示することとして接続する。

検査では、二つの説明候補と二つの分類の全組合せ、空の説明、片側だけの分類、共通分類が一つもない場合、二番目の説明だけが区別を残す場合を対照する。物理的比較の引数は実際の型を保って接続を検査し、射影の多くの証人は一つずつ量化に残した二値診断で検査する。実数・関数域の完全な量化は有限評価器で代用しない。物理的な下位定義は固定済み証拠を境界として照合し、この記録で原著者の結論を法則から証明したとはしない。
