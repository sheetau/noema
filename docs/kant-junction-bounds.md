# 接続検査の遠方除外

## 先行計画と適用範囲

現行の綴りと語内重なりを使った本文35を120秒だけ計測した。描画は未完了であり、本文の復号成功を意味しない。3303回の経路呼出しがあり、余計な接点の検査に累計49.57秒、そこで多用する点と線分の所属判定には全呼出し合計で56.11秒を使った。重複する累計時間を足して総時間とはしない。

経路候補、選択順、接続の許可条件、幾何検査を保ったまま、接触し得ない線の組を先に除く。各経路探索の冒頭で既存の線の範囲を計算し、その探索内で再利用する。これは検査結果の永続キャッシュではない。残った組には従来と同じ判定を適用する。旧関数と旧経路生成器は保存して対照に使う。

## 許容誤差を含めた範囲

旧判定は線の端点A・Bと点Pについて、距離AP＋PBと距離ABの差がEPS未満かを調べる。その許容域は細い楕円であり、線分の矩形をEPSだけ広げた領域ではない。線分が長いほど横方向の許容幅も増えるため、単純なEPSの矩形では旧判定が受け入れた点を誤って除外する。

線分長をL、距離和の許容差をtとすると、楕円の短半径は `sqrt(t * (2L + t)) / 2`。線分の軸に沿う端部の延長t/2もこの幅以下である。この幅で線分の外接矩形を上下左右に広げれば、楕円を包含する。二つの拡張矩形が離れている場合だけ、どちらの端点も相手に属しないとして省略する。

座標の絶対値が百万以下の有限値である場合だけこの除外を使う。この範囲では、距離和に関わる浮動小数点の丸め誤差はEPS=10⁻⁶より十分小さい。tを2EPSとして余裕を確保し、矩形の端もnextafterで外側へ広げる。範囲外・非有限値では除外せず旧判定を呼ぶ。座標を切り詰めたり、除外処理だけで新しい接触を受理したりしない。

接触、共有端点、線の分割、許容域の内外、退化線分、遠方・巨大座標について旧関数と比較する。実本文では旧経路器と新経路器を同じ入力で実行し、SVGの一致と実図形からの構文回収を確認する。意味モデルや全歴史監査を反復しない。
