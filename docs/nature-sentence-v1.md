# 本性に近い定着と、第一文の通し判断

カント第三段落第一文を、明示した読解の下で意味確認した。原文の範囲は `[0,125)`、空白を除いて108文字である。文中の主体、離脱の目標、性向の変化、困難さ、先行説明からの帰結提示を、一つの文の記述へ結ぶ。段落全体の確認はまだ終わっていない。[原文 AA VIII036](https://korpora.org/Kant/aa08/036.html)

## 原文にない形成原因を取り除く

以前の性向の定義は、本人が他人の指導下で活動した経験と、その経験による内的構成の形成を必須にしていた。第一文の「本性に近いものとなった」は、そこまで具体的な形成原因を述べていない。新しい `r2ea` はこの条件を外し、実際の程度の変化、現在までの結果状態の保持、本人の内的構成による現在の未成熟への寄与を残す。

「本性」をここでは、生来の起源ではなく、内側から働く性向として読む。Adelungの説明には内的な構成と作用・変化の力の用法があり、習慣が別の本性になる例もある。後年のカント『人間学』にも習慣の内的強制と別の本性への言及がある。ただし、後年の習慣論の全条件を、この文の比喩へ必須条件として加えることはしない。[Adelung, Natur](https://lexika.digitale-sammlungen.de/adelung//lemma/bsb00009133_2_0_600)、[AA VII149](https://korpora.org/Kant/aa07/149.html)

## 異なる比較範囲を混同しない

以前は「外的更新がない比較」と「外的更新も、その都度の選び直しもない比較」の両方へ、同じ程度と端点を要求していた。たとえば以前は、選び直せば内的構成が働いたが、選び直さなければ働かなかったという状態があり得る。前者の比較では寄与が一部にあっても、後者では下端になる。この区別を許すため、後者の共同条件で一つの程度を評価する。

生の測定の一意性、尺度の整合性、実際の変化、現在の寄与の検査は保つ。比較候補や測定を主張の成否に合わせて選ぶことは認めない。未知の入力を、低い程度や原因の不存在に置き換えることもしない。

## 一文の読解

| 原文の役割 | Noemaの内容 |
| --- | --- |
| 帰結としての提示 | 同じ著者が、先行する六箇所からの帰結として提示する。妥当な証明であるとは追加しない |
| 各個人 | 同じ文脈に固定した非空の人物範囲の各人へ、同じ内容を適用する |
| 困難さ | 本人の力と評価された選択肢に照らし、余裕を持って達成を確保する方法がない |
| 自己の未成熟からの離脱 | 同じ本人が精神を働かせ、独立して理解を用いる能力へ至ることを目標とする。他者の援助一般は禁止しない |
| 本性に近いものとなった状態 | 内的構成が更新や選び直しを要さず寄与する程度を実際に増し、現在も完全な上端より手前の近接域にある |

この肯定の単独文では、形容的な背景説明と主たる困難さの主張を、同じ本人について併記する。一般の埋込みや否定の下で、背景説明がどのように維持されるかまで実証したわけではない。「本性に近い」を内的な定着の軸で具体化すること、近接域を上端の手前に取ること、困難さを評価された非容易性で読むことは、今回の明示的な解釈である。あらゆる解釈や語感の同一性を主張しない。

## 検証と計上

新旧の性向を同じ有限モデルで比較する。指導活動・経験・形成原因を欠く場合、以前の選び直しによる寄与がある場合、変化や現在の因果寄与を欠く場合を含める。新しい内容だけを実行する未知入力の検査も行う。著者への帰属、引用内容、六つの先行箇所、順序は256組合せと別人・別箇所などの対照で確認する。

変化、内的寄与、選び直し、困難さ、尺度の既存検証は、依存する定義と意味資料の一致を確認して再利用する。既存の全検証を今回再実行したとは数えない。また、世界内容全体の同時実行や、ドイツ語との同義性の自動証明とも区別する。

追加は四定義、基本入力はゼロ。旧定義、先行51文、十二単位の意味判断を保存する。今回の108文字は一文単位のアシスタントによる意味判断として別に記録する。段落などの全単位を対象にした集計は十二単位・2,212文字のままであり、第三段落全体やアインシュタイン論文を完成扱いにしない。独立した査読は未実施である。
