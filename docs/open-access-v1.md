# 取得の許可・利用機会・実際の受領

読者へ向けることの公開性を検討するため、取得方法が許可されていること、許可された方法を実行して取得できること、現に取得したことを分けた。カントの `vor dem ganzen Publikum der Leserwelt` への部分構成である。公的な理性使用や公衆の完全な定義ではない。

## 許可と実行可能性を同じ方法へ結ぶ

`rdg` は、規範の出所・人・取得方法・提供経路・話題の対象・発話記述・開始状況を固定する。同じ出所による積極的な許可があり、同じ条件についての禁止がない場合に成立する。禁止の不在だけでは許可にならず、許可と禁止の両方があれば衝突として除外する。

`rdh` はその人物に許可された方法があるという条件、`rdi` は非空の対象範囲の各人にそのような方法があるという条件である。取得手段や実際の受領は、この段階では必要ない。

`rdj` は、許可され、実行できる同じ方法によって、取得目標を満たせるという条件である。既存の文脈的な能力評価 `xa`・`xd` を再利用し、その方法の評価対象が非空で想定結果に含まれ、選択した全結果で目標が成立することを求める。許可された方法Aが実行不能で、別の無許可の方法Bだけが実行可能なら成立しない。

`rdk` は非空の対象範囲の全員について `rdj` を要求する。人ごとに異なる取得方法を使ってよい。費用・負担・障害への対応を含めたアクセス全般や、あらゆる偶発事象での取得保証を定義したものではない。評価対象の選定基準は別途必要である。

## 何を受領するか

原文接続の `h6o` は、同じ人が、指定した提供経路による生起した行為で、同じ話題・Noema発話記述を受領する内容である。先行する受領 `h6e` と生起 `dg` に、提供経路との関係 `h6k` を結ぶ。別の経路で同じ情報を知っていることを、指定経路からの取得に混ぜない。

`h6l` と `h6m` はその取得方法への許可と禁止を表す。`h6p` は一人に許可された方法があること、`h6q` は同じ読者範囲の全員への許可、`h6r` は全員の実効的な取得機会を記述する。方法と結果の候補は、既存の `ae`・`af`・`ap` を使う。読者がまだ誰も利用していなくても、許可と取得機会は成立し得る。

`h6s` は指定した人が現在受領したという条件である。許可の有無や他者の利用機会とは独立しており、引数にも規範の出所を要求しない。無許可でも実際には受領している場合を表せる。内容の理解、賛同、真理も受領からは導かない。

## 対象範囲を狭めた検査の限界

読者範囲 `h6n` は、今回許可された人や実際に読んだ人とは独立に与える。読者二人のうち一人だけに取得を許可する例では、全員への許可は成立しない。一方、対象範囲自体をその一人だけへ狭めれば、同じ許可条件でも全員への許可が成立してしまう。この対照例も検証した。

したがって、全員に条件を課す論理式だけでは、対象範囲が公衆全体を適切に捉えたことは証明できない。`h6n` は読者世界の一般的な説明に代わる完成済みの語義ではなく、独立した範囲を与えるための接続点である。許可が広いこと、利用機会があること、発言を公衆へ向けていることも別である。取得できない人がいるという理由だけで、公的な発言ではないとは結論しない。

規範の出所も固定している。別の出所による禁止はこの出所内の衝突へ混ぜないが、複数の出所の競合を解決したり、全体として許されると認定したりするものではない。

## 検証と未完の範囲

許可・禁止・実行可能性・想定結果・選択結果・取得成功の512組と、原文接続の25例を検査した。空の評価対象、想定結果にない評価対象、選択範囲に失敗が残る場合、別方法・別経路・別内容・別文脈の取り違えを区別する。単なる許可の判定では方法・受領・理解の評価を実行せず、許可自体が未評価なら判定を拒否する。関連26テストが通過し、保存済み検証記録との再生成一致も確認した。

学識者としての立場、自分の理性による発言、読者世界の範囲、討議への参加や応答、第四段落の集団的啓蒙への接続は未完である。旧0.11の公的・私的使用の草案も保持しており、同名記号を混ぜずに全文へ統合する作業が残る。今回の条件が原文で現に成立するという本文主張は追加していない。
