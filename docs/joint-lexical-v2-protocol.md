# 概念と役割を同時に選ぶ検査

語別規則、生成、追加学習を使わず、固定した概念・役割のスコアをNoemaの型・役割制約で組み合わせる。既存の独立選択18文は観察済みの回帰資料とし、予測前に作る別の14文を確認資料にする。今回の結果を見て係数・モデル・閾値を変更しない。

## 固定する推定

- event-gate-v6の出来事と句範囲は変更しない。未採用の句を追加したり、語末を補正したりしない。
- 句ごとの概念候補はshared-matcher-v1の全91候補。以前に捨てていた下位候補も使う。役割候補は選択済みヘッドの`none, agent, patient, recipient, location`全てを使う。スコアだけをフックで取得し、既存の出力を変えない。
- 概念スコアは学習時の倍率10を使ってlog-softmaxへ変換する。役割の生logitもlog-softmaxへ変換する。異なるスコアの重みはどちらも1で固定し、この変換値を校正済み確率とは呼ばない。
- 各出来事について、述語の概念スコアと、各句の概念・役割スコアの合計を最大化する。述語はevent/state、各非none役割は述語が許す役割と型でなければならない。同じ役割へ二つの句を割り当てない。どの役割も必須とはせず、省略を補わない。
- `none`の場合も、全91候補からの最高概念スコアを目的関数に含める。非noneにだけ概念の負の対数スコアを加え、句を捨てる方が機械的に有利になる定式化を避ける。noneの概念は出力する意味の項ではなく、比較のための潜在変数である。
- 述語候補を列挙し、各候補の役割使用ビット集合で動的計画法を行う。役割ごとの貪欲選択ではない。完全同点では概念ID、役割ラベル順と概念IDの辞書順で固定する。

これは出来事ごとの同時推定であり、文書全体の照応・節関係を最適化する処理ではない。同じ原文範囲を複数の出来事で異なる概念に選んだ場合は、整合した文書とせず競合として記録する。グループや名前を補完する処理もない。4役割以外の役割、否定・数量・時間・発話・作用範囲の未接続は保持する。

## 比較と検証

前回18文では、独立方式の原出力と全スコア先頭候補が保存結果と一致することを検査する。新規14文でも独立方式と同時方式を同じ原文から比較し、概念・役割・範囲の完全一致、欠落と余分な項、未知例の誤対応、型不整合を報告する。未知概念を型に合う既知概念へ押し込む危険は、型不整合の減少と分けて扱う。

全スコアの取得では未接続の句が入力バッチに増える可能性があるため、共通する範囲の上位3候補の順序一致とスコア差1e-5以内を確認する。独立方式そのものと前回保存結果の比較は許容差なしで行う。

小さな人工スコアでは全探索と最適解を比較する。元の構造出力の不変性、先頭4回帰文の反復一致、保存した全スコアからの再計算、禁止経路5種の呼出し0回を検査する。両方式とも全文の確定出力は行わず、完成基準の確定率80%・意味構造一致率95%は未達として残す。
