# 文脈上の条件から必然でない、計画されない一致

カント著者注の問いに使っていた未分解の偶発性`hzkw`を、結果・比較条件・目標を分ける構成へ置き換えた。現行本文は`kant-incidental-agreement.noema`である。本文42文の構文を保ち、文22の問いが依存する`hzlc`を改訂する。

一般定義`rqw6`は、基準状況で結果が成立し、その状況を含む比較範囲に結果が成立しない状況もあることを要求する。比較範囲が空であること、結果が未知であること、低確率や心理的な驚きでは代用しない。比較条件は文脈の説明上の条件であり、全宇宙の微視的状態を固定する条件ではない。

一般定義`rqw7`は、同じ過程の構成行為を担う人物が、その行為で当該結果を目標としていないことを表す。既存の引数付き目標関係`hztl`を使い、閉じた目標記述と順序付き引数を渡す。別の行為の目的を混ぜず、引用した目標の成立を実行しない。人物が関与しない過程も扱えるが、目的について未知なら非目的性を確定できない。

本文用の`hzwk`は二文献と範囲を同じ内容対応へ結ぶ。`hzwl`は上の二条件を合わせ、`hzlc`はその同じ過程の生起と因果的な寄与を要求する。`hzld`は引き続き可能な一致範囲を問う。現実の一致、最大値、成功は断言しない。古い`hzkw`は履歴のため宣言に残るが、現行の問いからは参照しない。

[著者注](https://korpora.org/Kant/aa08/042.html)の、他方の回答がまだ手元にないという文脈から、計画して一致させたのではない符合を問う読みを採った。これはアシスタントによる解釈であり、Zufallの全語義の定義や唯一の歴史的解釈ではない。共通の問題・背景原因・真理探究を排除せず、一致一般が意外だという期待も補わない。関係する比較条件と目標内容は解釈者が指定する。字面の違いだけで目的の内容を別物にする規約ではない。

一般定義は通常評価で検査する。本文の候補答えは、多重の範囲探索で無関係な候補を評価しない診断用短絡変換を明示して検査する。保存本文をその形へ書き換えない。問いを提示する文と既存の著者注への接続は通常評価で検査し、問いの答えに必要な関係を未知のままにする。有限モデルでの検査は歴史的な意味一致の証明ではない。

内容対応の採用規約と著者注全体の再読は残る。既存十単位・604非空白文字の意味確認を引き継ぎ、新たな全体確認や対応文字数は加算しない。自然言語の翻訳機は保留のままである。
