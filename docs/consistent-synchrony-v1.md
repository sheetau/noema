# 任意個数の地点で矛盾なく同期を定義する仮定

固定原文u0015全149非空白本文文字を対象とする。著者は、直前の同期の定義を任意個数の地点に矛盾なく適用でき、一般に続く二つの関係法則が成り立つと仮定している。

任意個数は、個数の上限を置かない全有限点列への量化として読む。非空・重複なしで同じ系の点からなる列を対象にし、二点や三点の検査例へ限定しない。無限個の時計を同時に配置する主張までは追加しない。全有限列への量化を有限評価器で標本化することも拒否する。

各点列について、一つの候補配置と一つの評価状況で全地点を一緒に扱う。配置は各点へ一つの時計を割り当て、各時計には出来事ごとの値を持つ一つの許容指示履歴を与える。異なる点対を比較するときも、その同じ写像と履歴を使う。点対ごとに別の原点や値を選び直して整合したことにはしない。

異なる二地点の同期には、必要な光往復試行の非空の全範囲で、同じ光・反射・出来事・時計と三読みの等時間式を要求する。同一点の自己同期は既存の規約を引き継ぐ。一時計の履歴の許容性と、全時計対の式が同時に成立することを別に確認する。候補配置の値を現在の実測値へ混ぜない。

原文は実現可能性を仮定するのであり、この記述が物理的な存在証明を与えるわけではない。仮定の採用、直前の定義への参照、alsoによる二法則への説明の向き、コロン後の二項目への予告を保持する。u0016・u0017の場所記号と列挙の提示の接続は次に残る。
