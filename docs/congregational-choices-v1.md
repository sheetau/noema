# 宗教共同体の制度変更への合意と維持の意向

カントu0013第七文の保護対象を選ぶため、地域の宗教共同体、その制度配置、基準点までに成立した同意、旧配置を続けたい意向を構成します。本人のよりよい認識に基づくことと保護そのものは、まだ接続していません。

`r5fz` は、同じ政治的共同体内の宗教共同体について、既存 `r363` の制度的な組織・宗教主題・共同実践・検討領域と非空の人間の成員を結びます。`r5f2` は政治的共同体・宗教共同体・領域・主題・制度配置の正確な五対象から、その配置の運用内容を返します。合意・維持の意向・後の保護が別の制度内容を指さないための共通内容です。

`r5f3` は、基準点の現行配置と変更先を固定し、比較範囲のどこかで運用内容が異なることを要求します。名前を変えただけでは満たさず、新配置が実施済みであることや客観的に優れていることも要求しません。

`r5f4` は、同じ合意内容へ同意した人・活動・時点を保持します。`r5f5` は、共同体に帰属するその合意について、固定した複数当事者全員が基準点までに同意を表明したことを結びます。同じ時刻の集会や全成員の満場一致を要求せず、宣誓・法的契約への強化もしません。本人の認識基準は、次にこの同意活動の理由として結びます。

`r5f6` は同じ配置をその後も運用する内容、`r5f7` は現行の旧配置について共同体自身がその継続を望むことです。改革合意の不在から維持意向を推論せず、望むことから将来の実現も推論しません。履歴の範囲は明示した入力であり、有限の模型で永続を証明したとはしません。

検査では宗教共同体の構成、同じ領域の内容差、基準点までの同意行為と本人、全当事者、非空性、同じ内容記述と束縛を確認します。五対象の内容束縛は二つの標識による全32パターンと提示する32パターンを照合します。制度の目標内容の評価と、合意・意向における引用を分けて検査します。全文の意味判断と確認文字数は据え置きです。
