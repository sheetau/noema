# 綴り対応を図形として公開する

## 先行計画

完全名を読んで語を登録できるが、その後も長い完全綴りだけを使うため反復が残る。既存の省略綴りを隠れた対応表として渡さず、宣言・本文と同様に図形から読み取る記録を追加する。語義や native の名前は変えない。

綴り記録は spelling 頭、登録済みの名前、types_end、2〜4個の基礎語形、types_end の順に書く。名前は現在公開されている綴りで参照する。二つの終端によって名前と新綴りの境界を明示し、新綴りの基礎語列は最長一致で単語へ分割しない。頭・名前・新綴りには枝を付けない。新綴り内部の隣接中円接触は、一語の内部として読む。

spelling 頭は大円の左下円周上に小円の中心を置き、右方向の半径線を使う。既存の円・線規則を変えない。綴り記録は辞書の前置きにだけ置き、本文に共通の開始形を追加しない。

記録を読み終えた後に、元名と新綴りの対応を後続の語読取へ登録する。完全綴りと以前に公開した綴りも保持する。新しい綴りを出力時の優先形にするが、他の名前の省略形を自動再計算しない。対象未登録、基礎語の改名、既存の別語との衝突、同じ対応の重複、本文開始後の追加を拒否する。後から宣言する完全名が先行する省略綴りと衝突した場合も、その宣言を拒否する。

読取結果は native 文書と、読んだ綴り記録を分けて保存する。綴りの登録で定義本体・型・参照先を変えない。旧形式の完成済み辞書への書出しで、この記録を失うことを許さない。公開辞書に既存の意味に基づく綴りがある場合、その対応と意味記述の保存内容を生成側で照合する。復号側は図形の記録から対応を得る。

## 確認範囲

未知の完全名から宣言→綴り→本文を読む例、二つの綴りの共存、後続宣言での利用、接頭部の衝突、順序・登録衝突を小例で確認する。保存済みの実宣言と綴りにも適用する。一項目一行のページ読取を再利用し、複数項目一行・折り返し・最終の行間は別に残す。
