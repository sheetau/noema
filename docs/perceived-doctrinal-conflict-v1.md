# 規定群に抵触を見いだすという本人の信念

原文 `kant-1784:u0012[4279,4407)` は、本人が内面的な宗教に反するものを規定群内に見いだすと信じた場合を仮定し、良心に従った職務遂行の不能と辞職義務を述べる。今回はその前提を、閉じたNoemaの内容として構成した。後件と全文の帰属は未統合であり、本文の確認文字数は増やさない。

`das letztere` は直前の「内面的な宗教に反する部分」に、`darin` は同じ規定群に結ぶ。`r43l` は既存の所属 `r42k` と内容間の実践的抵触 `h252n` を使い、同じ基準に反する部分の存在を述べる。部分の存在量化は信念内容の内側に置き、現実の抵触を信念の前提にしない。

`finden` は対象の内容に目を向け、検討や気付きによって当該事柄を認める読みを採る。[IDSのfinden・語義2](https://grammis.ids-mannheim.de/verbs/view/400584/2)と[Dudenのfinden](https://www.duden.de/rechtschreibung/finden)には、検討を通じた発見や認識に関わる用法がある。これは現代語義との比較であり、1784年の唯一の語義の証明とはしない。意図的に探索したこと、以前は全く知らなかったこと、完全な確信、特定の証拠や検索時間は追加しない。

`h252z` は、本人が対象の内容に即して指定内容に当たる事柄を認めるという認識だけを述べる。内容関数には対象・比較基準・固定基準を同じ順で渡す。`r43n` が同じ `r43l` を直接評価する条件と合わせて、実際に見いだすという内容を作る。閉じた信念内容を構成する際に同じ段階の脱引用を必要としない形で、内容の一致を保持する。単に抵触が存在するだけでも、誤って抵触を認めるだけでも、実際の発見にはならない。

その全体を `r43o` で閉じた内容記述へ構成し、`r43p` が既存の非事実的信念 `h233c` の対象にする。したがって、本人が誤って見いだしたと思う場合にも信念は成立する。信念を検査するときに実際の所属・抵触・認識の関係を実行しない。抵触そのものへの裸の信念と、自分が対象内にそれを見いだすという信念を区別する。

`r43m/r43o` の構成には、本人・規定群・宗教基準・固定基準の四つの閉じた呼称を渡す。`r43p/r43r` は各呼称の指示先との一致を要求する。同じ個体を指す別名は許すが、構文の異なる内容への信念を自動的には移送しない。

`r43q` はこの信念を状況から真偽への閉じた前提関数にし、`r43r` が `r42f` を使って、非空の全仮定候補で前提と指定帰結を要求する。現実に前提が偽だという条件は追加しない。後件は引数であり、ここでは信念から不能や義務を導く公理を置かない。
