# 第三節の変換理論という主題を円文字へ接続する

四組の時刻成分は、三位置成分と異なり、同じ出来事・系・単位・文脈の局所時刻候補を持つ欄として役割を記述する。既存の記述参照はこの役割を引用し、取得時には実行しない。参照できることから、物理的な割当ての存在や唯一性を導かない。完全な割当て、四成分の区別と妥当性は `eiuz/sha` で別に要求する。

`eiuz` は四つの数値を同じ出来事と実際の座標割当てへ結び、共通の長さ・時間単位、Cartesian計量、全実数にわたる座標一意性、既存の局所時刻規約を保つ。`eiu2` は、同じ一出来事の二つの四組を、第一系から相対運動する第二系への向きで結ぶ。別々の出来事から値を集めたり、第一系の時刻を第二系へコピーしたりしない。

研究主題は、閉じた対応関係から表示変換の規則、条件、説明、導出を扱うことを表す。主題を提示しただけでは、具体式の発見・証明、全域性、可逆性、線形性を主張しない。直前の同時性の結論からの本文順序も保持する。
