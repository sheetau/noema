# 主張と背景を分ける情報構造

この語彙群は、主張の真偽と、焦点・主題・比較背景・対比の提示を分けて記述する。たとえば、ある内容が真であることだけから、それが意外な内容として提示されたことは導けない。背景が満たされないことも、主張の否定とは別に判定する。

[Native本文](../examples/v016/shared-focus-v1.noema)は38定義で、新しい基本宣言を含まない。[意味規約](../data/shared-focus-basis-v1.json)に型と引数の役割を記した。旧尺度背景の19定義、主張・背景の帰属、段階変換、順序付き対比の計22定義は、本体と意味を改名だけで保持する。残る16定義で限定・添加・条件文・主題・期待違反を接続する。

## 組の主張側と背景側

`focuspackage`は二つの閉じた段階2の内容記述を保持する。`focusclaim`と`focusbackground`がそれぞれを取り出し、`focusclaimtrue`と`focusbackgroundtrue`が別々に評価する。`focusnegate`は主張側だけを否定した記述に変え、背景の記述をそのまま保つ。`focusquestion`は主張側の肯否を問う発話の記述を作る。元の組は背景を保持するが、質問の発話値に背景を埋め込んだものではない。

条件文には二つの操作を用意した。`focusif`は主張同士を含意にし、両背景を全体に保持する。`focusfilteredif`は、左の背景と「左の主張が成立するなら右の背景が成立する」という条件を背景にする。どちらが自然言語の文脈に適切かを自動で選ばない。`focusand`は主張同士と背景同士をそれぞれ論理積にする。

これらは通常の関数・閉じた引用・引用適用から構成する。組を作る時点で内容を実行せず、未知の内容を保持できる。真理や含意を調べる段階では、未知入力を偽として処理せず評価を拒否する。

## 限定・添加・尺度の区別

`focusentails`は固定した比較状況域に相対的な含意、`focusequivalent`は同じ域での相互含意を表す。構文の同一性や全可能状況での同義性を判定する関数ではない。空の域では含意は空虚に成立する一方、限定と添加の条件は評価点が比較域に含まれることを要求する。

| 組 | 主張側 | 背景側 |
| --- | --- | --- |
| `focusonly` | 非空の比較列について、焦点から従わない比較内容を全て排除 | 焦点の内容 |
| `focusalso` | 焦点の内容 | 焦点から従わない比較内容の少なくとも一つが成立 |
| `focusscalar` | 焦点の内容 | 指定尺度で焦点が比較列の全要素より上位 |
| `focusscalaralso` | 焦点の内容 | 尺度条件と、比較列の少なくとも一つの内容の成立 |

限定は、焦点から従う弱い条件や同値な別記述を排除しない。添加では、それらを独立した追加内容と数えない。これは内容間の比較を使う明示的な読みであり、only・alsoの全用法を一意に定義したという主張ではない。数量の代替条件を扱った旧`count-focus`の考え方を、内容と状況域へ適用している。

尺度の19定義は従来の意味を保持する。`focusorder`は指定記述列上の非反射性と推移性を調べ、全順序は要求しない。`focusextreme`は非空の比較列、焦点自身の除外、全比較対象との厳密な順序を要求する。尺度は確率や意外性に固定せず、視点と基準文脈を引数に持つ。旧`focusadditional`は比較列内の成立を調べる条件で、新しい`focusaddition`の「焦点から従わない」という条件は含まない。両者を改名や共通化によって同一視しない。

`focusaction`と`focusactions`は、同じ閉じた枠へ焦点と比較対象の行為記述を適用する。列の順序と重複を保ち、比較対象ごとに人物や基準を勝手に変えない。`focusquotedlist`はその列の閉じた記述を構成し、`focusactionalso`まで同じ尺度背景へ接続する。

## 主題への結合と帰属

`topiccontent`は個体から内容を作る同じ閉じた枠へ、主題の閉じた個体参照を適用する。枠の中の条件・否定・量化を保つ。`topicmarked`は、参照が同じ個体を指すこと、組の主張記述がその適用記述と一致すること、同じ主体・箇所・主題参照・主張記述・文脈の「その主題について述べる」という関係、組の帰属を要求する。

主語の位置や主張の真理から主題を補う条件ではない。同じ真偽を持つ別名の枠へ差し替えても、記述の一致とはしない。複数主題や談話全体の追跡の一般理論は、この個体主題の構成とは区別する。

`focusattributepackage`は二つの記述を従来の段階3の帰属へ接続し、同じ主体・箇所・文脈に対して主張範囲と背景範囲を別に渡す。帰属の成立は、主張や背景が実際に真であることを要求しない。

## 対比と期待違反

`contrastordered`は、異なる二箇所で同じ主体が提示する二つの内容記述、本文の順序、同じ順での対比提示を結ぶ既存定義である。二内容が論理的な否定同士であることは要求しない。両内容が真でも、別途の対比関係がなければ対比の提示とは認定しない。

`contrastpackage`は、両内容の成立を主張側に置き、同じ視点・二記述・基準文脈の通常予想を背景側に置く。予想候補は非空で、全候補で左内容が成立し右内容は成立しないことを要求する。これは期待違反の強い操作化であり、確率的な傾向やbutの全用法とは同一視しない。主張だけを否定しても、固定した予想背景は変わらない。

## 検証した範囲

[限定](../examples/v016/focus-exclusion-v1.noema)、[添加](../examples/v016/focus-addition-v1.noema)、[尺度](../examples/v016/focus-scalar-v1.noema)、[主題と対比](../examples/v016/focus-topiccontrast-v1.noema)の四つのNative文書は各14判定を持つ。外部解釈は二個体と状況の識別値だけで、内容・比較域・尺度・帰属・主題関係・期待候補は本文の関数から構成する。尺度例では主張が真でも添加背景が偽、主題例では帰属が成立しても主張が偽という区別を確認する。

[検査報告](../reports/shared-focus-v1.json)は、内容の含意と限定・添加128モデル、独立した四真偽による投射16モデル、尺度256モデル、期待違反128モデルの計528モデルを、別に書いた集合・真理条件と照合する。帰属・主題・本文順序・期待・尺度については、他の引数を固定して各枠を変える45件の結合診断も行う。これらを任意の高階関数領域における一般証明とは扱わない。

旧22定義の本体・意味、旧報告が固定した入力のハッシュを保持する。円文字接続、一般的な同義／多義、学習文書と第三者読解は別の課題として残る。
