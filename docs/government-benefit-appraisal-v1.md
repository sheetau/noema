# 同じ政府自身への利益の判断

u0017の `die es ihr selbst zuträglich findet` は、政府が、同じ人々を尊厳に応じて扱うことを政府自身にも有益だと肯定する内容として読む。扱いの価値上の正しさ、政府への利益、その利益についての政府の判断を区別する。判断があっても、現実に利益があること、規則を採用したこと、現に適合して扱ったことは導かない。

利益の比較には、同じ受益対象の固定した全目標、目標の正の重み、政策を実現する側としない側の全結果場合と見込みを使う。各結果で目標のNoema内容を評価し、重み付き達成の見込みが厳密に増えることを要求する。目標一覧と結果一覧の非空・重複なし・完全性、両側の政策の真偽、全目標の評価、見込みの非負と総和1を確認する。未知の状態を未達や零の見込みへ補わない。

旧 `rx7` は保証される目標の集合の真包含であり、不確実な利得や損失との交換を認めない。今回の比較は、例えば重み3の目標が半分の見込みで達成できるようになり、重み1の確実な目標を失う場合にも改善を表せる。これは数値や確率を原文に発見したという意味ではない。有限の結果場合・有理数・加法的な比較を用いる明示的なモデルであり、非加法的又は比較不能な価値の全てを扱う語義理論とはしない。具体的な目標や重みを著者へ帰属せず、比較の背景・期間とともに解釈の入力として固定する。

`r6lr` から `r6lu` は、この比較の本体である。`r6lv` は政府自身を行為主体と受益対象にし、前回の具体的な扱い `r6ll` とその閉じた記述 `r6lm` を渡す。`r6lw` はこの利益内容の閉じた記述を作る。同じ外延になる別名を認知対象に移すことや、扱い自体の記述を利益内容の記述と取り違えることは認めない。

`r6lx` は、一人の人間が同じ生起した判断に能動的に公的資格で参加し、その判断を同じ政府が自身の見解として引き受けていることを要求する。任意の職員の私見や助言の受領だけでは政府の判断にしない。既存 `rlg` に同じ政府を主題、同じ利益記述を肯定内容として渡し、非空の全判断候補でその内容を満たす。現実の点が候補に含まれることは要求しない。`r6ly` と `r6lz` は、この同じ人と判断の存在を同じ政治的評価点へ接続する。

目標内容や見込み、組織の意思形成上の引受けは明示した解釈入力であり、有限モデル検査で現実の政策効果や制度の正当性を証明したとはしない。組織の判断に全職員の一致を追加せず、政府を人間だと仮定することもない。原則への因果作用、時間・強調、条件文全体と著者帰属は未完で、今回の局所構成を全文の意味確認へ加算しない。
