# 光速未満の合成と不足量による説明

対象は原刊906頁のu0143–u0144である。必要な関係は、直前の一次元式からの帰結、常に光速未満になるという全称、v=V−κとw=V−λの仮定、双方の不足量の正性と厳密上限、置き換え後の式とU<V、そしてその式を先の主張の論証として示す役割である。既存s3o、s3q/s3r、s3s–s3y、s4aを再利用する。

ejpvは同じ現在の三量の取得ejpaと、同じ一次元式の一般形s4aを結ぶ。ejpwは同じ光速Vについて、任意の非負でV未満の二入力から構成した値が合成関係を満たし、V未満となるs3wを述べる。「常に」を実際の一組だけの検査に縮めない。量化された入力は実際のv/wとは別であり、現在の物理的な参照を保つことは量化範囲をその一組へ狭めることではない。直前の式と一般形は同じs3g/s3jを共有し、本文順序もzlfからzliへ結ぶ。

原文のκ・λの条件は0<κ,λ<Vである。ejpxはこれを現在のv/wへそれぞれ結び、ejpyは同じ正方向条件ejppと同じ一次元式ejpqを説明の前提として保持する。一般主張の0≤v,w<Vには零が含まれるが、原文の厳密な不足条件は0<v,w<Vに対応する。この差を残し、零速度もこの置き換えによる同じ論証で扱ったことにはしない。

ejpzは同じUがV*(2V−κ−λ)/(2V−κ−λ+κλ/V)に等しく、かつVより小さいという内容である。上限だけを確認して等号を済ませず、係数2、二つの減算、内側のκλ/Vと外側の商を保持する。κ・λを入れ替えて商の値が同じでも、それぞれのv/wへの対応が失われれば前提は成立しない。

ejp2は前の式から一般主張を得る提示、ejp3は局所範囲zlkへの仮定導入、ejp4はその条件から表示式を得る提示、ejp5は表示式を一般主張の論証として示す提示である。これらを同じ著者・論説へ帰属する。nämlichを省かず、仮定・帰結・論証の提示と、主張や論証の真理を区別する。

原刊の二文、七つの行内数式、コロン、M0271の等号・二重分数・厳密不等号・句点を通読した。転記のϰは不足量κの表記として既存の同じ記号参照を使う。原データは変更しない。有限の対照、全実数量化の列挙拒否、保存された有理多項式証拠、原文の意味判断は別の根拠として扱う。旧文139–142以外の352主張を保存する。
