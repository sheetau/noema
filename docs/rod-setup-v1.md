# 棒の初期設定・等速並進・長さの問い

アインシュタイン§2の `u0029` を、初期の静止測定、運動を与える設定、その後の二方法による長さの問いへ分けてNoemaで記述した。[前回の二つの測定方法](rod-measurements-v1.md)をそのまま参照する。これは部分草案であり、剛性などを説明し終えた完成訳ではない。

## 初期状態と測定設定

`sbp` は棒と物差しが同じ静止系に静止していること、正の初期長、物差しを当てる配置と読みを要求する。初期測定の観測者は存在だけを述べ、後の測定の観測者と同一とは決めない。観測者自身の静止も原文へ補わない。`sbq` は長さを実数の下側切断へ接続する。

`sbw` は初期状態と後の運動状態を結び、棒の長軸をX軸上へ置く設定、同じ棒へ運動を与える順序、その運動状態を二つの測定設定で評価する対応を保持する。方法aと方法bの設定は区別する。`sbt` は初期状態と運動状態の具体的な定義へ接続した想定内容である。

著者がその設定を採用することと、現実にその測定が実行されたことは分けている。既存の仮定採用の関係 `ug` に想定内容の記述を渡す。原文の「考える」に伴う全ての認知的な意味をこの採用関係だけで説明したとは扱わない。

## 等速並進を座標変化で記述する

`sbl` は有理数の対条件、`sbm` は実数の下側切断による対条件である。正の速度vと、逆向きでない二時刻について、次を要求する。

```text
x₂ − x₁ = v(t₂ − t₁)
y₂ = y₁
z₂ = z₁
```

時刻原点・位置原点をゼロに固定しない。同じ時刻を表す別の記録にも同じ位置を要求する。実切断の一致には両方向の包含を使い、関数の実装上の同一性で代用しない。速度の数値は、指定した長さ単位と時間単位の商に関する数値である。

`sbn` は非空の点集合と時間幅を持つ時点集合について、全ての点と逆向きでない全時点対に対条件を課す。`sbr` は同じ棒の物質点、同じ基準系・単位・文脈の時刻と三座標、共通の速度へ接続する。両端点も点集合に含む。`sbs` は時間順序と対条件を実切断の定義へ接続する。

始点と終点の座標だけでは途中の運動は定まらない。全物質点・全時点を尽くす範囲は別の前提として明示する。有限の標本で条件が成立しても、その前提が真であることや、連続時間全域の等速性は認定しない。

この条件は選択した等速運動区間について述べる。静止状態からの加速過程を等速運動と呼んだり、静止時と運動時の棒の長さが同じだと推論したりしない。

## 二方法の答えを分ける

`sbo` は「方法の識別子と長さの候補値」の組を答えとする質問である。`sbu` で二方法の設定を結び、`sbv` で既存の直接測定 `sbi` と同時端点測定 `sbk` へ接続した。

方法aで5、方法bで4という候補を別々に扱える。両方で5でもよく、候補なしや複数候補も質問の構造として許す。ここで値を生成したり、値の存在・唯一性・相等性を保証したりはしない。例の整数は検査用の明示モデルであり、実際の収縮率を意味しない。

本文では、著者がこの質問を指定の考察範囲で提示したことを記述する。質問の引用時には候補判定を実行せず、無限の実数候補を有限列挙した回答集合も返さない。
