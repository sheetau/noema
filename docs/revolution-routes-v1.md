# 革命的な試みと同じ候補での結果

第四段落第五文の `Durch eine Revolution` を、政治秩序の根幹を変えようとする集団的な対抗と、その同じ活動による結果の候補として構成する。先に構成した専制・圧迫からの離脱を、実際の結果条件として接続する。第五文全体の意味確認はまだ行わない。

## 革命は必ず成功するという定義にしない

[Revolutionの政治的な語義](https://www.duden.de/rechtschreibung/Revolution)は、根本的な変更を目指す転覆の試みも含む。今回の読みでは、成功や流血を必須にしない。単なる通常の継承や一職員の交代、案を述べるだけの行為は区別する。

`r2qg` は、同じ共同体に実施されている旧政治秩序と、根幹の異なる別の提案秩序を指定する。政治秩序の構成 `h226q`、根本的な相違 `h226r`、既存統治権力への対抗の実行 `h226s`、現に実施される秩序 `h226t` はそれぞれ別の基本関係である。

行為・生起・参加・共同体の成員・集団的な作用への帰属は既存 `r2ml` を再利用する。旧秩序を終えて提案秩序を実施する目標 `r2qf` は、同じ集団の同じ行為の目的として `hztl` に渡す。目標は引用し、達成を評価しない。各参加者の私的な意図が全て同一であることも要求しない。

この構成では、まだ実施されていない提案の存在を、実現した政治秩序と取り違えない。新秩序が望ましいこと、当事者が啓蒙されたこと、全住民が参加したことは定義に含めない。

## 活動の種類も同じ候補で判定する

既存 `rqc/rqe` は、活動の種類を一引数の述語で判定する。今回の政治的な対抗は、どの候補の状況で起きているかによって判定する必要がある。ある候補で革命に当たる行為と、別候補の効果だけを結び付けることはできない。

`r2qh` は、同じ活動と候補時点に、候補への所属・活動種類・生起・因果・結果の成立を集める。`r2qi` は同じ対象・種類・基準・候補について、第一結果の経路の存在と第二結果の経路の不在を結ぶ。第二結果の否定は、第一結果に成功した活動だけに限定しない。

`r2qj/r2qk` は同じ共同体と、活動・候補時点ごとの旧秩序・提案秩序・参加者を供給し、種類の定義を `r2qg` へ固定する。結果記述と候補範囲は引数として明示する。種類が時点に依存しない場合は旧 `rqe` と同じ真偽になることも検査する。

## 検査した接続と残る範囲

革命の構成を実行し、根本的でない変更、通常の継承、提案のみ、集団的な参加や目標の欠落を区別する。提案秩序の実施は未知のままでも、試みの分類は成立する。

さらに `r2qj` へ先行の `r2qe` を結果として渡し、同じ革命的行為が同じ候補で同じ当事者の離脱を生じさせることを実行する。行為・原因・離脱のどれかが欠けた場合、別の候補や分類を流用した場合を拒否する。

否定側の比較検査に使う結果は仮の内容であり、「真の思考様式の改革」を定義したものではない。公衆の全対象範囲と共通の候補供給、その改革の具体的な内容、様相・対比・新旧の偏見と誘導の描写、著者帰属、文全体の通読は残る。既存61文・全単位13区間・先頭四文771非空白文字の判断は保持し、第五文の確認済み分量は増やさない。
