# 第三文の依存群：政府の自己誤解と外的障害

`sich selbst mißverstehenden Regierung`を、政府が自分たちの公的な役割・目的・任務・権限について制度上採用している理解に誤りがある、と読む。個々の官吏の私的信念や多数決、悪意、全構成員の同意は要求しない。既存h247uが判断を組織自身へ帰属させ、h26pjが同じ内容項目における制度的な自己位置付けを、h26pkが同じ共同体での公的役割についての内容であることを指定する。個人用h242hを政府へ代入しない。

r56zは、固定範囲の項目とその代表、同じ組織の判断、同じ内容についての自己位置付け、受容した極性を結ぶ。r562は、代表項目のNoema命題h26aeの真偽と、その極性との不一致を同じ点で求める。偽の肯定と真の否定をともに扱い、別名の項目へ差し替えて誤りを消さない。r563は、そのような判断・項目・極性が少なくとも一組あることを記述する。全判断が誤っているという意味にはしない。

`einer ... Regierung`は、障害の出所を同じ政府へ結ぶ。h26plは政府の公的な設定・維持・実施に由来する条件、h26pmは同じ人の理解や態度の内的構成ではなく、社会的・制度的環境に属する条件を表す。r564は、その条件が現在存在又は適用されることをh26kgで確認する。出所・外的性格・現在の存在だけでは、妨害や政府の自己誤解を導かない。

r565は一つの目標命題について、同じ割当てから状況への対応を使い、達成の二値を比較する。r566は条件の有無をモデル要因の真偽へ全介入解で一致させ、既存r2wmで同じ背景・初期条件・選択枝の対応組を比較する。両側の解と全解の評価・対応を要求し、少なくとも一組で条件あり側だけが同じ目標を達成できなければ、潜在的な妨害とする。平均効果・全背景での失敗・現在の達成不能とは区別する。このモデルの現実への適合は意味規約の入力であり、有限検査が社会的因果を実証するものではない。

r567は同じ政府の自己誤解と、同じ条件の現在の存在・出所・外的性格・妨害を結ぶ。誤解が条件を生んだという因果や故意は原文から追加しない。別政府の誤解、別条件の現在の存在、別目標への悪化を寄せ集めた例を検査で除く。誤りの両極性、代表項目の別名、未知入力、無害な枝の違い、未対応・未評価・解なしも区別する。

目標は実際のNoema命題で渡すが、第三文の同じ自由の精神の国外到達・保持との接続は次の作業である。複数障害、格闘する活動と必要性、本文の設定、先行自由例への照応、auch/selbst、全文帰属と通読は未完。本文114主張と既存の意味判断を保持し、第三文の意味確認文字数は増やさない。
