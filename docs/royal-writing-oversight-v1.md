# 著作による明確化と君主の監督

第六段落最終文のうち、臣民が著作を通じて自分の見識を明確にしようとする営みと、それへの君主の統治上の介入を構成する。原刊490–491頁とAA VIII 40頁を照合した。全文統合と通読判断はまだ行わず、既存の107主張と意味確認分を保持する。

`r5o5` は本人・作品・領域の理解内容を、`r5o6` はその明確化条件を非空の範囲に固定する。`r5o7` は全項目の代表内容を本人が把握し、全ての明確化条件を満たす目標である。条件はNoemaの命題内容で明示し、単に「明確」というラベルで判定しない。対象・理由・適用条件の区別や、曖昧さと未決点の整理を扱い、全宗教内容の真理又は全員の同意を要求しない。

この読解では、Einsichtenを、ここで本人が検討し明らかにしようとする理解内容として扱う。[AdelungのRein](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009133_6_1_1007)は清書と比喩的な整理・確定を区別する。後者を採るが、唯一の歴史解釈の証明とはしない。先に構成した、公に確証される洞察 `r5ft` の成功条件を、そのまま未完の試みの前提にはしない。

`r5pa/pb` は実際の検討活動・本人参加・同じ書かれた作品・参照可能な外部記録と、その表現を手段として使うことを結び、同じ本人・作品・領域への `r5o7` を目標にする。目的を引用するので、完成した理解や内容の正しさは実行条件にならない。作品の所持だけ、別作品の記録、他人の試み、単に目的を抱くだけの場合は足りない。

`r5pc` は同じ君主・共同体に属する臣民と、その共同体の宗教的な検討領域へ結ぶ。`r5pd` は同じ君主が保持する最高統治職を用い、作品の知的内容を審査・承認・統制の対象に置く活動である。作品を自分の注意に値すると扱う本人側の関係を分け、著者の賛同や所管の正当性は補わない。出版禁止や没収が実行される前の監督も扱う。

`r5pe` はこの監督を、同じ作品を通じた同じ臣民の試みへの介入に結ぶ。`r5pf` は七つの対象を保存する引用用の内容族で、威厳への損傷と二つの介入方法を後で接続する入口となる。

検査では非空性、全項目と全条件、別名と代表項目、同じ記録と媒体、目標の不実行、役職・作品・臣民・領域の取り違え、七引数と未知入力の拒否を確認する。解釈入力の条件の網羅性を有限検査だけで証明したとはしない。威厳の損傷、皮肉、ラテン語の批判、専制の支援、程度比較と全文提示は残る。
