# 三つの関係による法則の表現

アインシュタイン1905年論文u0275の「三つの関係が、本理論による電子の運動法則を完全に表す」という主張を部分記述した。指定した事例の範囲で、理論が許す事例と、適用される式が許す事例とが過不足なく一致する、という候補を用いる。主張を記述することと、その主張が物理的に正しいと確認することは別である。

## 過不足のない一致

一つの事例について、選んだ関係のうち、その事例に適用されるものが全て成り立つことを「式が許す」と定義する。三つの式のいずれか一つが成り立てばよい、という条件にはしない。一方、設定が異なる式を全事例へ無条件に適用することも避ける。

次に、同じ対象・基準系・文脈・理論と評価範囲を保って、二方向の一致を述べる。

| 条件 | 排除する問題 |
| --- | --- |
| 理論が許す全事例は、適用される式を全て満たす | 式が厳しすぎて許される事例を排除する |
| 適用される式を全て満たす事例を、理論は許す | 式が緩すぎて許されない事例まで認める |

両方が成り立つときに、過不足のない表現とする。選んだ関係と評価範囲は非空とし、範囲内の全事例が同じ対象と基準系へ結ばれることも要求する。対応が欠けた事例を、評価対象から自動的に取り除くことはしない。

「適用される式が何もない」事例は、式側では制約を受けない。その事例を理論も許すなら、両者の一致は成立しうる。全事例へ少なくとも一つの式が適用されるかは別の診断とし、一致の必要条件には加えない。同様に、全ての式が互いに独立であることも、完全な表現という条件へ混ぜない。

## 直前の三関係への参照

[原刊921頁](https://de.wikisource.org/wiki/Seite:Einstein-Elektrodynamik.djvu/31)の「三つの関係」は、直前の偏向の比、電位降下と速度、磁場中の曲率半径を指すものとして接続する。先行本文の`setw`・`seuz`・`sevn`を順序付きで引用し、それぞれの提示箇所への参照を保つ。三つの参照は異なるものとして扱い、先行203文を保存して著者への帰属を一文加えた。

事例ごとの数値条件は、既存の`sets`、`seur`と`seus`、`sevh`を用いる。電位降下については、エネルギーとの数値関係だけでなく同じ場の向き付き積分も残す。適用条件と理論の許容は独立した入力であり、式が合う事例だけを選んで完全性を作る手続きは追加しない。

この数値条件への接続だけでは、先行本文の全ての履歴・場・出来事・単位・校正条件を復元してはいない。それらが事例の意味と各関係の適用条件に正しく含まれるか、また原文の「完全な表現」をこの形で十分に表せるかは、引き続き意味確認の課題である。

| 定義 | 内容 |
| --- | --- |
| `sevp` | 一事例で適用される全関係の成立 |
| `sevq` | 非空の範囲・関係と、全事例の対象・系への対応 |
| `sevr` / `sevs` | 必要条件側 / 十分条件側の一致 |
| `sevt` | 両方向を満たす範囲相対的な表現 |
| `sevu` / `sevv` | 式が許しすぎる反例 / 排除しすぎる反例 |
| `sevw` | 全事例へ何らかの関係が適用されるかの診断 |
| `sevx` / `sevy` / `sevz` | 三関係の選択 / 事例ごとの数値条件 / 先行内容の引用 |
| `sewa` | 本文の完全な表現という主張の候補内容 |

## 検査と限界

二つの事例について、理論の許容集合と式の許容集合の全16組を検査する。さらに範囲の拡大、空範囲、対象の取り違え、複数の式が同時に適用される場合、何も適用されない事例を区別する。本文では三つの式を個別に変えた例と、数値上の一致があっても理論が許さない例を確認する。

狭い評価範囲で一致した後に、反例を含む範囲へ広げると一致が失われる。この検査は範囲の取り違えを示すためのものであり、有限モデルで全運動・全軌道を証明したという意味ではない。現実に観測されたかどうかも、この理論内の一致条件からは導かない。

数値検査には、全領域で解釈を明示した合成的な関数と、登録した多項式の場を使う。現行の有限評価器は論理枝を先に評価するため、不適用の関係を含む関数解釈が必要になる。未知の量・適用条件・理論の許容を補完せず、解釈が欠ける検査は拒否する。これは自然言語翻訳器を追加する変更ではない。
