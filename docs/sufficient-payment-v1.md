# 必要な対価を賄う支払能力

カント第二段落の「支払うことさえできれば」という部分について、必要な対価を賄えることと、その一部を渡せることを分けた。[本文の新しい固定版](../examples/v016/kant-sufficient-payment.noema)ではtoだけを改訂し、旧toはrqyaとして保存する。支払いの一文全体への意味一致の判断はまだ行わない。

旧版では、受け入れられる価値媒体を仕事の対価として移転できれば、支払能力tpが成立した。たとえば必要対価が2で、算入額が1/2の移転しかできない場合も真になった。新しい共通定義rqxzは、同じ人・受け手・仕事・状況で必要額が正であり、同じ移転の算入額が必要額以上であることを要求する。例の数値は検査用であり、本文や共通定義には埋め込まない。

歴史的用法の判断には[AdelungのBezahlenの項](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009131_4_2_2380)を参照した。同項は出金、物の価値への償い、受け取った物の価値を支払う負担を分け、第三の用法に目的語を明示しない支払不能の例を挙げている。今回は、対象の仕事を対価面で賄えるという読みを採る。辞典だけでカントの意図や必要額の決まり方が一意に証明されるとはしない。取得した本文とハッシュは[出典記録](../data/sufficient-payment-evidence-v1.json)に固定した。

算入額hzxjと必要額hzxkは、同じ取引文脈の共通尺度で解釈する数量関数である。前者は所持金や別の仕事への支払額と区別し、後者は移転直前に必要な額を表す。支払後の残額0を必要額へ代入すると、支払いを正しく評価できない。既払分や合意に応じた十分な対価を解釈に反映できるが、その取引制度を比較式だけから導くことはできない。

移転が実際に起きること、媒体が受け入れられること、同じ仕事の対価であることは、既存のrfで別に要求する。金額だけを満たしても支払いにはならない。既知の必要額0は無償として扱い、この正の対価を払う定義には含めない。部分払いはrqyaで引き続き表せる。未知の金額は0や支払不能へ補わず、評価を拒否する。

この構成は、対価を同一尺度の有理数量で比較できる取引を対象とする。全ての交換制度、非数量的な履行条件、価値や権利の基礎を完成させたものではない。二つの数量関数の意味規約に残る制度上の前提を明記し、比較そのものは既存の有理数順序と合成する。共通定義はカントの人名や仕事の記号を含まず、別の仕事にも使える。

検査は次を区別する。

- 負値・0・分数・境界を含む36組合せと、支払者・受け手・仕事・移転・状況の10対照。共通単位を正の倍率で換えても大小関係を保つ。
- 現行の支払能力・思考の不要・将来の見込み・条件文を評価する34対照。部分払いだけで能力ありとなる旧版の反例を、新版と同じモデルで比較する。
- 同じ方法の複数結果に十分な支払いと不足が混ざる場合など、五つの対照。別の方法で十分に払える場合と、選択範囲外の結果も分ける。
- 支払い済みと支払能力を別々に照会する三対照、通常評価との三照合、未知入力、著者への帰属六対照。
- 本文43文の構文、既存十一単位と先行三文の意味依存関係、完全形・短縮形・固有文字の往復。

支払能力がない場合でも条件文自体は真になり得るため、条件文の真を能力の成功として数えない。検査では各内容を別の照会結果として保存する。原文から金額を抽出する機能や翻訳機は追加していない。
