# 共通の開始記号を置かない複合語

元kant-pageの配置探索と幾何制約を使う限定構文へ、公開済みの30根語・345複合語を接続する。旧語形や語義を再割当てしない。scripts/kant_public_lexicon.py が既存の SensesVocabulary から綴り、型、定義を読み、scripts/kant_public_fragment.py が実際の円と線へ組み立てる。

## 語境界の規則

複合語の部品は、既存の根語の形をそのまま連ねる。各語の先頭に同形の記号を置かず、公開された綴りの最長一致で語を読む。部品が最長でも三つの現語彙では、次の三部品まで見れば語が決まる。元の構文を候補ごとに復元する探索や、意味モデルによる選別はしない。

根語の連続が別の複合語の綴りになる場合には、そのままつなぐことはできない。たとえば book と home の連続は speechreceived の綴りでもある。別々の項として使う場合だけ、その間に不可視の直線接続を置く。根語を語の部品として使う場合は線でつなぐ。同じ横段の中心同士を結び、連結成分の順序から回収するので、好きな位置に空白を置いて意味を補う規則ではない。

終端引数を横枝へ付けた位置も、その語の終わりになる。複合語の場合は最後の部品から実引数の横枝を出す。横枝そのものには、一つの核で読める終端項だけを置く。複合語の終端項は主な連なりへ残す。これにより、語の部品の枝と構文の引数の枝を見分けるための新たな記号を増やさない。

読取器が見るのは円、中心線、許容された二円関係、線の接続、回収した空白だけである。描画時の語名や単語境界の配列は渡さない。引用の空白も同じ幾何規則で回収し、引用を意味するかどうかは可視の引用頭で決める。

## 関数参照と適用

関数への参照を表す形は、大中同心円から左上または左下へ出る終端斜線とする。その後の一語を参照先として読み、引数を適用しない。普通の適用では語自体から始め、公開された引数数に従って読む。関数参照の専用形を通常の文頭へ付けることはない。

型確認には既存の実定義と必要な依存を取り込み、定義を新しいprimitiveに置き換えない。構文を正規化した結果が入力と異なる場合は、勝手に修正して成功扱いにせず拒否する。

## 検証と残る範囲

375語それぞれについて、その語への関数参照を含むnative文を実SVGへ描き、円と線だけから元の構文へ戻す。全語の参照先が一致することを確認する検査であり、375語の全適用例を検証したとは扱わない。複合語の通常適用、数を返す適用、関数を返す適用、引用、隣り合う二語・三語の境界は別の小さな対照例で確認する。既存の文頭・引数・引用・束縛30例も、横枝あり／なしで確認する。

共通語の定義・語義・参照先は変更しないため、哲学・物理の意味モデル検証と過去全文の監査は繰り返さない。語彙の実際の構築コード、語形表、定義と意味規約のファイルを報告へ固定する。

共有引数の可逆な融合、任意の型と束縛の深さ、全構文、順位付き引用、行・頁と倍率の復号は未完である。短い対照例の成功を、kant-page全体の密度・有機性や二作品の完成と同一視しない。完成候補の外観は固定前に利用者へ確認する。
