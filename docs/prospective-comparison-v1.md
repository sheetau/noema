# 公衆と個人の可能性を同じ将来で比較する

第四段落第一文は、公衆の自己啓蒙が個人の場合より可能であり、自由を残せばほぼ避けがたいと述べる。[原文と前後関係](https://korpora.org/Kant/aa08/036.html)を確認し、既存の能力変化・自己形成・継続的な許可・質的様相を接続した。六定義を追加し、新しい基本記号と本文主張は追加していない。

以前の `hznd` は公衆の変化を比較対象の任意の条件へ結んでいた。将来を扱う `hznh` は自由の条件付きの側だけを記述していた。比較対象に既存の `h4q` をそのまま代入すると、過去に終わった個人の自立まで、公衆の将来の変化と比較できてしまう。

`r2ku` は、本人の自己形成による自立 `h4p` の完了を、候補内の起点より後に限定する。同じ期間枠・候補・先後関係を使い、本人の履歴にも同じ前後点が属する。開始が起点より前の場合は許す。単に将来に能力があることではなく、本人の精神への働きかけと、その変化を生じさせる因果が必要である。

`r2kv` は、比較対象が人であることを確認し、この個人の将来と公衆の将来の変化 `hzng` を、同じ候補集合・期間枠・起点対応・尺度で比較する。人でない対象の変化が偽であることを、「個人の成功が不可能」という最低値へ流用しない。`r2kw` は、同じ公衆の同じ変化について `hznh` の条件付きのほぼ必然を加える。比較の途中で対象集団や評価起点を取り替えない。

公衆の程度が個人より上であることと、自由の条件下で公衆の程度が必然に近いことは区別する。後者が前者より常に厳密に上だという条件は加えない。原文の `ja` は論述上の強め方を別に記述する必要があり、この数値的な条件を代用にすると余計な主張になる。尺度は数値確率ではない。

`r2kx` はこれを内容にし、`r2ky` は十五の引数を閉じた記述で充足する。`r2kz` は既存の第一文の箇所 `hzp4`・著者 `wa`・提示文脈 `hzp3` への帰属構成である。帰属するときには候補世界の内容を実行しない。原文用の引数を固定した本文主張は、まだ追加していない。

## 今回の読みと残件

第一文の自己啓蒙は、公衆内部の働きかけによって自立的な理解力の使用が広がる変化として読む方向を採る。第二文の自己評価や態度の伝播は、その理由を具体化する記述であり、その全機構を第一文に重複して必須条件とする必要はない。

ただし、想定読者の範囲だけで、どんな集まりも公衆になるわけではない。公衆の社会的な範囲、変化の広がり、一般的な個人との比較を支える対象選択が未確定である。自由についても、公的理性使用の許可を維持するという読みの適用範囲を確定する必要がある。`aber`、`ja`、`nur` の提示と作用範囲、固定した閉じた内容の本文への帰属を接続した後、一文全体を再読する。

## 検査の範囲

個人側では自己形成の定義を実行し、完了済み、別人・別の精神、本人の活動や因果の欠落、共通経過と本人履歴の不一致を比較する。能力内容そのものは既存検査への明示的な境界とする。

二つの様相を同時に評価する検査では、将来の選択・比較・条件付きの範囲を実行する。公衆の能力変化、個人の自己形成、公的活動の許可の内部は、それぞれ既存の検査を持つ境界とし、引数・候補・時点を調べる。過去の成功の流用、両者が同じ候補で成立するのに優劣を付ける比較、途中の許可撤回、候補の不正、必要条件・十分条件への強め方を区別する。能力と許可と様相の全定義を一度に再実行したという結果ではない。

閉じた引用の検査では、十五の引数、比較個人の差し替え、著者・箇所・文脈を確認する。未知の世界内容でも帰属だけを評価でき、未知の帰属は補わない。旧定義と意味規約、十三単位の判断、先行の検査報告の依存を保持し、三表記の往復を確認する。テストの通過を第一文全体の意味確認には数えない。
