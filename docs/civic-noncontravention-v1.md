# 同じ発言についての市民義務への不違反

第五段落u0012[2771,2983)に向け、市民の義務への不違反を、同じ発言について市民の立場で評価すべき全要求への適合として構成した。本人の公的見解r347との条件接続、先行文との譲歩対照、追加焦点、全文帰属は続けて行う。本文と意味確認文字数はまだ更新しない。

現在の本文は、行為を直接渡すh7a、順序付き個体列を段階0の内容関数へ渡すh7k、個体列と内容基準を段階1の内容関数へ渡すh237zの三形式で要求を扱う。r35a/r35bは後二者の同じ記述・束縛・極性・評価点を実際の内容評価へ接続する。正の要求なら真、負の要求なら偽を求め、相反する要求は両方を満たせない。要求の不在から積極的許可は導かない。

r35c/r35dは同じ活動についての適用範囲h245s/h245tを固定し、全記述・全有限個体列、段階1では全内容基準も量化する。範囲は適合の成否で選ばず、関係する全対象を含めるという意味契約を持つ。単に列に活動名が現れるかどうかでは決めない。その発言による他の義務の妨害を採用解釈で評価するなら、その対象も範囲に含める必要がある。試験用の少数の対象から現実の範囲の網羅性を推定することはしない。

r35eは既存rfgの全記述域への量化とrfeの極性別適合を再利用する。r35fは同じ市民の立場r33sと先行文と同じ規範源h245dを保ち、三形式の適合を同じ評価点で結ぶ。実際の賦課発令者の全要求を著者の採用する義務へ置き換えず、別の納付行為を済ませたことや本人の全生活の無過失も要求しない。

旧rfe/rfgの脱引用を含む構成は、そのままv016へ保持できる。全体r35fは段階2で引用できるため、不違反そのものを基本関係として追加する必要はない。引用の検査では要求・適合内容の評価を全て未知のまま保持する。一方、全記述域を実評価する要求は有限評価器が拒否する。

局所検査では、各対象の正負要求と実際の真理の全組合せを検査する。全域量化の本体については、二つの明示した記述と二つの束縛列への適用を診断し、二番目の対象だけにある違反も検出する。この有限化は試験内のみで、保存するNoema定義は変更しない。これを全域の実行証明や現実の義務の網羅性の証拠とはしない。

三形式は現在の本文にある要求の範囲を覆うが、任意の引用段階を型を越えて量化する仕組みではない。将来さらに高い段階の要求形式を導入する場合、その形式への適合も拡張する必要がある。この限界を伏せて「あらゆる規範」の完成とはしない。
