# 自由の仮定内で評価する伝播内容

伝播内容をそのまま本文へ置くと、自由を残す場合についての予測を、現実の無条件な事実として読ませてしまう。[前段の読解記録](../data/dissemination-reason-reading-v1.json)で採用した条件の範囲に向けて、公的な理性使用への許可が継続する仮定の中で、対応する伝播内容を評価する構成を追加した。

`rqtn` は候補範囲と条件から評価対象を内部で選ぶ。選ばれた範囲は非空で、その全候補について、同じ候補の内容を同じ候補の基準時点で評価する。現実の評価時点を、仮定内の基準時点へ自動で代入しない。

`hzp7` は全候補の経過を既存の `hzne` で検査し、許可継続 `hznf` を条件として渡す。自由の条件を満たさない候補であっても、経過や基準時点の不備を見逃さない。`hzpa` はこの判断を内容として構成し、既存の `hzon` で閉じた内容を引用して帰属できるようにする。検証では前段の根拠側箇所 `hzp5` と著者 `wa`、段落の提示文脈 `hzp3` を共用する。

内容族は、候補を受けて内容を返すNoema関数で記述する。具体例では `hzoy` を使い、候補ごとの履歴・順序と、独立判断・自己離脱・受領者の性向取得を実行する。母集団は二候補で同じ二人を保ち、時間範囲と基準点を変える。後の基準点では、指定した伝播期間がもはや将来の取得を満たさず、予測が偽になる。公的活動の分類・許可も元の定義を実行し、「伝播が成功した」という不透明な基本述語へ差し替えない。

| 対照 | 条件付き判断 | 現実の許可 | 内容への帰属 |
| --- | --- | --- | --- |
| 許可のある候補内では予測が成立 | 真 | 偽 | 成立 |
| 現実の許可だけを追加 | 真 | 真 | 成立 |
| 予測が偽の候補にも許可を追加 | 偽 | 偽 | 成立 |
| 許可を満たす候補がない | 偽 | 偽 | 成立 |
| 許可のない候補の経過が不正 | 偽 | 偽 | 成立 |

これは、指定した範囲で例外なく予測が成立するという読みの構成である。全可能世界での必然性や、先頭文の「ほぼ不可避」という程度判断と同一視しない。空の条件範囲を真とする一般の含意とも区別する。自由についても、公的活動への継続的な規範上の許可という既存の読みであり、物理的な機会や妨害の不在まで表せたとはしない。

四項目のテストで、候補・条件・内容・基準時点の256組合せ、具体的な許可と伝播の七対照、未知の経過・基準点・許可・内容、帰属の独立性を検査する。一般形と帰属だけの検査は通常評価し、大きい具体例とその未知入力検査には短絡診断を用いる。内容の全事実が未知でも、閉じた内容への帰属を通常評価できる。通常・短縮・固有文字の往復、既存33文・全意味規約・七単位の確認を保持する。

三つの合成定義を追加し、新しい基本関係はない。一般形は175文字、累積文書への追加は486文字である。
