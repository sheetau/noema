# 二つの力の言い表しに共通する運動

対象はアインシュタインu0174–u0175、原刊909末尾から910頁の番号付き二項である。二項を一群として、点状の単位電気量、同じ出来事、位置、瞬間速度、測定系、単位と場の対応を先に接続する。

原文の第一項には、電気力に加わる「電動力」、速度比v/Vの二次以上を無視する留保、速度と磁気側の場の外積を光速度で割る順序、旧来の言い方という位置付けがある。第二項は、同じ対象に相対静止する系へ場を変換し、その対象の場所の電気側の場によって力を述べる新しい言い方である。A0024は910頁への区切りで、脚注ではない。

今回の実装は共通の運動依存群と標準配置への接続に限る。`ejxj–ejxn`は三方向の非零速度を許す。`ejxk`は`seoc`の同じ座標履歴・内点・三つの微分に、点状電気量、評価出来事の値1の記録、`ejsl`の座標規約、`eisqd`の単位明示位置を結ぶ。速度ごとに別の対象や履歴を使うことはできない。加速度0や前後の静止は要求しない。

`ejxo`は実際の三速度を既存変換の(zb7,0,0)とする標準配置の特殊化である。`ejxp`は同じ出来事のkにおける瞬間静止、両系の物理的な場、単位明示位置、全四座標の変換を追加する。数値上の一点の対応だけでは共動を認定しない。

旧文167を更新する`ejxq`は、この標準配置で既存の二次剰余`scm2`を同じ地点の場へ結ぶ。旧文168を更新する`ejxr`は、同じkの物理的な力`ejwv`、電場の全領域の変換`ejs3`、同じ場所での変換後の場と力の一致を結ぶ。Kの力とkの力を成分ごとに等置しない。旧`xm`、`zok`、`zpa`、`scn2`、`scf2`はこの接続の根拠に使わない。

任意方向に合わせた軸と場・力の対応、第一項の追加の機械的寄与の帰属、引用語と旧来／新しいという対比が残る。第一項の一次式を有限速度で厳密な式にせず、固定した場ごとの誤差定数と近傍を保つ。標準配置の部分記述を二項全体の完成とは数えない。

検査では実際の型を保った本体と、二値の個体域に写した存在証人の結合を分ける。三つの座標微分、非零加速度、履歴欠落、片側・孤立時刻、対象・系・出来事・単位・位置の取り違え、全四座標、力の全三成分、逆座標での場の評価を対照する。全履歴・微分・全領域の場の条件は明示した境界又は既存証拠を使い、全実数・全関数域を有限標本に置換しない。未知入力の拒否を保つ。

新しい原始記号は追加しない。旧360主張のうち167–168だけを更新し、u0173の六文を含む他358主張、旧定義・意味規約・証拠を保存する。新たな全単位意味判断は行わない。
