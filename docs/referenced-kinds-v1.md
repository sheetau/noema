# 参照元と性質の範囲を固定する種類の照合

カントの「そのような運動」に、前の跳躍の描写を参照する構造を追加した。運動の種類を照合する性質を基準文脈に固定し、経験・定着・理由の対象を同じ活動記述へ結び付ける。具体的にどの性質まで共有させる読みを採るかは、引き続き未確定である。

前版では、不慣れの対象を足側の物理的阻害がない身体移動としていた。この範囲の広い活動への慣れの不在と、種類を限定した活動への慣れの不在は同義ではない。そのため、新しい文書では末尾の帰属主張 `h3t` を `h4f` に置き換えた。旧文書は変更せず、新文書にも比較用の旧定義と先行する12主張を残している。

## 対象と状況を分けた性質の一致

一般定義 `rck` は、空でない指定性質群の全てについて、二つの対象がそれぞれの状況でその性質を持つかどうかの一致を要求する。指定外の性質が異なっていてもよい。同じ対象が状況によって変わることも表せる。

`rcl` は、さらに二つの対象がそれぞれの状況で同じ適格範囲に属することを要求する。例えば、ある身体運動の性質がないという点だけで、身体運動ではない物まで同じ種類に含めない。これらは既存の量化・関数・真偽の同値から構成し、新しい文法や一般用の基本関係は追加していない。

これは性質群を明示して行う一致の検査である。対象そのものの同一性、全ての性質の一致、任意の自然種の同一性を示すものではない。性質が未確認の場合も、偽として照合しない。

## 同じ描写を参照する運動の種類

原文接続では、`h3u` が人物・基準文脈・参照元の運動・描写状況を結ぶ。`h3v` は運動の性質、`h3w` は種類の照合に採る性質群を指定する。どの性質が原文の比較に適切かは、ここで新たに置く解釈上の入力である。

`h3x` は次の条件を組み合わせる。

- 参照元が少なくとも一つある。
- 全参照元が、同じ人物と基準文脈の仮定集合に属する。
- 全参照元が、先に指した最小の溝への、その本人の不確かな跳躍として描かれる。
- 候補の運動と各参照元が、身体移動と足側の阻害の不在 `h3z` を満たす。
- 同じ非空の性質群について、候補と全参照元が一致する。

参照元が複数ある場合、一つと一致しただけでは受け入れない。互いに異なる種類を示す参照元が混ざれば、この構成は成立しない。比較対象ごとに性質群を変えることや、別人の描写を継ぎ合わせることも拒否する。

`h4g` は、参照元の一つを候補にしてこの構成が成立することを要求する。これにより、種類の参照自体が非空で整合しているかを、現在の運動を要求せず検査できる。参照元や性質群が欠けている場合は、慣れの肯定・否定のどちらも認定しない。

## 慣れと理由の対象を限定する

`h3y` は、固定した基準文脈で `h3x` に該当する運動を行う活動内容である。慣れ `h4a` とその不成立 `h4b` は、経験・現在への寄与・現在の定着の全てに、この同じ記述を渡す。一般的な身体移動の経験を、そのまま限定された種類の経験として移す規則は加えていない。

この記述参照は、慣れている本人が今その動作を実行していることを要求しない。過去の経験や現在の反応を記述へ結び付ける基本関係の解釈は、前版と同じく外部の意味規約として残る。ある経験がどの活動記述に該当するかを、名前の一致だけで現実から自動判定する仕組みではない。

理由の内容 `h4c` は、限定された活動への不慣れを、同じ仮定内の不確かな跳躍の説明要因として採用する。`h4d` と `h4e` は先行する除去条件・同じ仮定集合・対象者を保つ。`h4f` の帰属では新しい内容だけを使い、旧来の広い活動を対象にする理由記述を受け入れない。

## 検証と残る解釈

性質群・性質の真偽・適格範囲の256組を検査した。実際の定義を展開する一階論理の検査では、固定した性質群についての反射性・対称性・推移性、適格な一致から両対象の適格性と性質の一致が導かれることを確認した。「同じ性質なら同一個体」「状況を変えても性質は変わらない」「性質の一致だけで適格になる」という三つの推論には反例を得た。

原文接続の15例では、複数の整合した参照元、矛盾する種類の混在、人物・基準文脈・描写状況・溝の取り違え、性質群や参照元の欠落、広い活動にだけ慣れている場合を検査した。今の候補動作を実行しなくても慣れが成立する例も保持した。帰属の6例では旧内容への取り違えと内容の非実行を検査した。

関連41テスト、検証記録の再生成一致、通常・短縮記法と固有文字の往復が通過した。2文書のCLIによるJSONと構文木の一致、SVGのXML形式も確認した。字形の目視検査は今回行っていない。

一般用文書は基本関係0・定義2、原文接続文書は基本関係213・定義325・主張13である。追加は基本関係3・定義12、帰属主張1件の置換で、主張数は増えていない。正規形は1,830文字増え、49,552文字になった。
