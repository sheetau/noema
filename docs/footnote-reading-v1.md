# 著者注全体の意味確認

カント1784年論説の著者注`u0020`を、原刊494頁の画像と[AA VIII 42頁の電子本文](https://korpora.org/Kant/aa08/042.html)に照らして再読した。現在のNoema本文と、下記の読みを採った意味規約の下で、著者注全体を表せていると判断する。実装者であるアシスタントの判断であり、独立査読や意味同値の自動証明ではない。

| 原文の範囲 | 保持する意味と接続 |
| --- | --- |
| 0–3 | 注の標識を同じ文献の本文側標識と著者表示へ結ぶ。直前の主張への論理的説明は追加しない。 |
| 3–72 | Büschingへの編集上の帰属と週刊の性質を呼称内の説明として使う。13日付の掲載号と系列を区別する。 |
| 72–116 | 著者が同月30日に案内を読む。読書と未受領の基準時を同じ日に置き、同一瞬間には固定しない。 |
| 116–177 | 案内が対象とする当月の月刊誌の号と、案内を掲載する週報の号を分ける。 |
| 177–255 | 紹介されたMendelssohnの回答と、現在の論説が答える同じ問いを結ぶ。敬称の丁寧な使用と男性向けの描写を保持する。 |
| 255–298 | その回答が基準時までに著者へ届いていない。現在の不所持や内容の未理解に置換しない。 |
| 298–352 | 届いていたなら、その回答の影響で現在の論説を差し控えただろうという反事実を述べる。差し控えの具体的な段階は補わない。 |
| 352–394 | 現在の論説をここに置くことを容認し、この提示の位置付けを、続く問いを検討する試みという種類へ限定する。 |
| 394–462 | 非目的的で文脈上必然でない符合が、二回答の思想の一致をどの範囲に生じさせ得るかを問う。実際の一致・成功・数値・最大値を断言しない。 |

今回確定したのは思想の比較規約である。同じ問いに関係する論点を結果の判定前に共通の粒度で定め、片側の余分な内容を消さずに比較する。文や語の個数を内容項目の数とはしない。たとえば同じ肯定的な主張内の独立な連言は、順番や一文へのまとめ方が違っても内容ごとに対応させられる。一方、否定・量化・様相・引用の作用域を越えて分割してはいけない。

対応には、指示対象、出来事と参与役割、肯否、数量・量化、時間・様相、条件、主張・問い・要求の違いを保つことを要求する。片方向の内容保持は相手に追加内容がある場合にも成立し得るが、思想の一致には両方向の対応と全内容項目の網羅を要求する。同じ語があること、同時に真であること、任意の論理的同値だけでは足りない。逆に、構文や定義の展開形が違うことだけで不一致にはしない。

この規約は全同義関係を決定する算法ではない。人が内容の解釈を指定して書くNoemaの意味規約である。実際の二回答の全思想を抽出したり、問いの答えを計算したりする必要はない。問いを表現できることと、答えを既に知っていることを分ける。

検査では、小さな命題断片に限った独立な解釈を用意した。全真偽割当てに対する内容保持と、述語の同一性・発話種類を確認し、連言の並べ替え、片側の追加内容、同じ標本真理値の別内容、否定、問いとの違い、条件の向き、別主題の恒真式を区別する。この診断用の解釈を自然言語の翻訳器や一般的な意味判定器として使わない。断片外の式は未確定として拒否する。

現行の可能性の問いへこの解釈を接続し、別構文の同内容を候補から除外しないことと、未知の内容対応を補わないことを検査する。候補探索では診断用短絡変換を明示する。表題・二回答の照応・著者注の計12文は通常評価で検査し、問いの答えが未知でも記述できることを確認する。過去の暦・未受領・反事実・呼称・偶発性の検査記録も、その入力のハッシュを再確認して参照する。

現行本文は[全文](../examples/v016/kant-footnote-reading.noema)、確認対象の抜粋は[著者注と照応用の文脈](../examples/v016/footnote-reading-core.noema)である。四つの意味規約を明確にし、文法・基本語・定義本体・本文42文の構文は変更しない。抜粋の表題と冒頭回答の二文は照応の証拠であり、著者注の文字数へ重複加算しない。

登録簿v39では、既存十単位604非空白文字の判断を保持し、著者注397文字を追加する。合計は十一単位・1,001文字、カント全文の約6.45%の分量である。文脈的な意味の読みを確認した範囲であり、原文の綴り・書体の復元、あらゆる哲学的解釈、論説全体や文語体系全体の完成を意味しない。旧記録の未解決事項は履歴として保持し、現在の判断は`footnote-audit-v3.json`と全体レビューに記録する。
