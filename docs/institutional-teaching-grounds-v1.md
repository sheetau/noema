# 教会の教えと使用する論拠の報告

対象は `kant-1784:u0012[3794,3898)` の教示報告と証明根拠の一覧である。発言の予想、われわれの教会への照応、不特定の内容、二報告の提示を接続する前に、引用される二内容を構成する。今回の依存群では本文と確認文字数を増やさない。

`r4n` は、組織に帰属する判断 `h247u`、同じ主題 `fb`、同じ発話内容 `hzv`、組織の教えとしての公的位置付け `h247v` を結ぶ。`r4o` はそうした判断の存在である。個人が判断する `fa` へ組織を代入せず、単に教示条件に適合する任意の内容を教会の教えとはしない。教会という組織自体の構成は既存の `r35t` の設定で行い、本文統合で同じ教会へ束縛する。

[DudenのBeweisgrund項](https://www.duden.de/rechtschreibung/Beweisgrund)は証明を支える論拠という意味を示す。これは現代辞書による補助確認であり、カントの歴史的な唯一の用法を確定するものではない。[原文AA8/38](https://korpora.org/Kant/aa08/038.html)では教会が用いる論拠を述べた後に、本人の全面的な確信との違いが続く。ここでは、内容の正しさを示すものとして用いる論拠と読み、その客観的な正しさを外側の著者の断言にしない。

`r4p` は、同じ判断で理由を実際に用いる `fc` と、その理由を正しさを示す論拠として位置付ける `h247w` の連言である。実際の支持 `fd` とは別である。`r4q` は既存の完全な使用理由一覧 `rgg` にこの関係を渡し、同じ教示判断で用いる論拠だけを非空の指定範囲で尽くす。便宜や利益の理由が別にあることは許す。逆に、追加の論拠を一覧から落とすことは許さない。一つ一つの理由が単独で十分な証明になることや、形式的演繹の妥当性は追加しない。

`r4r` は既存の教示報告 `rgd` に `r4o` を接続する。`r4s` は同じ教会・教示判断・内側の発話・理由範囲を持つ `r4q` の報告である。同じ主題を渡すとそれぞれ主張の発話になる。閉じた報告の記述は内側の発話記述を含むため段階1で引用し、引用するだけでは報告内容も内側の教義も実行しない。今後の外側の提示構成もこの段階を保持する必要がある。

検査は教示の四条件16組合せ、理由の使用と論拠としての地位の独立な64組合せ、一覧の空・不足・余剰、同じ組織・判断・主題・発話・状況の接続、未知入力の拒否を扱う。引用した二報告の実際の記述を脱引用して評価する検査も行い、提示の診断用入力と報告内容の真偽を分ける。有限検査を全解釈の同値性の証明や一文全体の判断にしない。

残るのは `Er wird sagen` の予想・例示、`unsere` の同じ話者と教会、`dieses oder jenes` の不特定性、`das` の指示された論拠範囲、二報告を同じ職務上の発言として提示する構成と著者帰属である。
