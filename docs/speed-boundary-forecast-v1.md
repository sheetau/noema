# 超光速での適用限界と光速の役割の予告

u0116第三文の前半は、同じ考察を超光速度へ適用すると意味ある物理的解釈が成立しないという著者の留保として読む。四座標式を速度の内容族ejhkとして構成し、先の寸法と面状化の考察を同じ引用へ結ぶ。有限βの候補がないという数値的条件も保持するが、それだけで物理的適用の不成立を証明したとはしない。

後半の「光速が無限に大きい速度の物理的役割を果たす」は、この節の有限な物質的対象にとって、理論が許す運動状態の到達できない上限となる、という読みを採る。許容状況全体にわたる同じ物体の全点並進から速度域を構成する。単なる数式の定義域や有限の実測例の集合で代用せず、同じ全物質点・系・単位を保持する。

ejhnは、どの指定近傍にも領域の点があり、どの一つの領域内の点も全近傍には属さないという端の役割を表す。物理的速度域にはV直下の近傍を使い、全許容速度がVより小さいことも要求する。比較する無限に大きい速度は、全ての有限上限より上の近傍を持つ端として表す。同じ役割の型を両側へ適用し、無限大を実数や実在する物体の速度として導入しない。光そのものの伝播を、この節の剛体の許容速度域へ混ぜない。

これらは予告される内容である。同じ論説の同じ理論的見解を保持し、eisdbで後続の展開へ向けた予告として引用する。物理的役割を今ここで実証済みとせず、未来の議論を特定の一段落だけへ縮めない。u0263に現れるエネルギー式やその質量条件も、この第三文へ追加しない。

übrigensは同じ見解への補足という談話上の位置付けとして扱う。前半の数式上の留保から後半の物理的境界を証明したという因果関係を付けない。新しい基本関係は、理論における物理的な許容、記述の物理的な適用、補足的な提示の三つである。速度範囲、上限、近傍、物体と全物質点、同じ式族、引用・予告・著者への帰属はNoemaの既存構文と定義で合成する。
