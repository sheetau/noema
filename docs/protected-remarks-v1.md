# 学識者としての注記を妨げてはならないという規範

固定原文 `kant-1784:u0012[2332,2512)` を、先行する同じ将校が、学識者として軍務の欠点に注記を作り、その注記を公衆の判断に供することへの規範的保護として記述する。

`billigermaßen` は、公正・道理に照らした評価の規範源を指定するものと読む。その基準から規制者に対し、当該活動の禁止を成立させてはならないと要求する。規範の報告であり、現実に禁止がないこと、本人への許可が存在すること、物理的に妨げられないこと、本人が実行したことは別である。

作成だけ、提出だけ、両方を行うことの禁止を別々に記述し、その三つを拒否する。これにより、連言への禁止だけを拒否して一方のみの禁止を見落とす構成を避ける。内側の不実行要求と、外側の禁止を不成立にせよという要求は、引用の段階と極性を分ける。

同じ将校への照応には先行する命令事例 `r323` を使い、同じ本人・職務・軍事組織を固定する。学識者としての作成・提出は前段の活動構成を再利用し、制作済み作品や欠点の現実の真理を前件へ追加しない。提出の目的は同じ公衆の読者による同じ注記の判断であり、その達成や同意を要求しない。

`aber` は職務内の制約と学識者としての保護との対照として保持する。先行文の服従要求を撤回せず、一文全体を同じ著者・提示文脈へ帰属する。全解釈条件は意味規約と文単位の読みの記録に保存し、有限の検査と原文の意味判断を区別する。
