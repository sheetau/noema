# 自然による芽の展開と世話

第十段落第四文の前件について、形成初期の植物体が硬い覆いの下で展開し、自然がその芽を最も優しく世話する描写を構成する。前回の心理的発達と制度条件は保存し、今回は描写側の過程をまとめる。両者の比喩対応と第四文全文への帰属はまだ統合していない。

自然は、固定した物体範囲の内的構成に基づく変化力を、一つのまとまりとして捉える。そのまとまりの要素が全ての関連変化力と一致し、空でないことを要求する。植物の内的変化力が同じ形成区間で作動し、同じ芽の同じ展開過程へ寄与することも別に結ぶ。自然を指す名称だけに意味を委ねず、作動・寄与・全体への所属を区別する。

芽は、形成史の初期にある植物体で、展開する構造や生育機能が内部に潜在するものとして扱う。展開の開始時に少なくとも一つは未発現であり、終点には全てが発現する。既に一部が発現していてもよく、特定の植物種や、覆いを破って外へ出ることは追加しない。覆いは同じ対象に被さる別の物体であり、形成区間全体で保持される。

硬さには、既存の負荷に対する抵抗性を使う。覆いについて方法・試験範囲・単位・閾値を先に固定し、各形成時点から負荷した場合の全候補で、十分な荷重にも変形が小さいことを要求する。描写の評価点自体で試験が行われたことは要求しない。測定の適合と候補の完全性は公開したモデル入力であり、特定の硬さ規格や任意の負荷に対する不変形を主張するものではない。

世話の目的は、同じ植物体の構造・生育機能が発現するという閉じたNoema内容にする。その目的へ向けた行為と肯定的な感情を、固定した比較対象範囲内の最大の強度へ結ぶ。同率を許す。形成区間全体で世話を要求するが、世話する行為は時点ごとに異なってよく、展開過程そのものとも同一にする必要はない。目的への志向から目的の成功を導かず、感情と能動的参加は擬人化の描写内部だけに置く。

旧世話候補では、汎用定義が受け取る `performs(act, actor, point)` に、`df(actor, act, point)` を直接渡していた。旧展開候補にも同じ逆順がある。新しい世話接続はラムダで順序を変換し、展開への参加は自然・過程の順で呼び出す。旧資料と検査は保存し、その接続を今回の意味判断の根拠にはしない。新検査では、行為者と行為を逆にした入力が失敗することを実評価する。

語義候補の確認には、保存したAdelungの[自然](https://lexika.digitale-sammlungen.de/adelung//lemma/bsb00009133_2_0_600)と[芽](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_6_0_692)の転記を用いる。自然の変化力とその擬人化、植物の初期段階と比喩的な始まりを区別する資料である。1811年版の転記は原文より後で、原刊画像の照合でもカントの唯一の解釈の証明でもない。取得したHTMLと抽出本文のハッシュを読解記録に残す。

全過程の検査では、自然のまとまり、植物の初期性、潜在性と発現、時間順序、抵抗性、世話を既存の汎用定義も含めて実評価する。対象・過程の取り違え、途中の被覆・世話・抵抗性の欠落、比較対象や負荷候補の欠落、目的内容の交換を拒否する。検査成功と原文の意味一致は区別し、今回も意味確認済み文字数は増やさない。
