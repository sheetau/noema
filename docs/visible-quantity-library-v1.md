# 複数と量を含む円文字辞書第5版

円文字の共有辞書を120語から171語へ拡張した。[複数の24定義](shared-plurality-v1.md)と、[量の23固有定義・既存算術4基本宣言](shared-quantities-v1.md)を接続している。辞書全体は30単独語と141複合語、意味の宣言は20基本宣言と151構成定義からなる。既存120語の形・意味・定義本体は保持し、新しい単独字形は追加していない。

[公開綴り表](../noema/resources/visible-quantity-vocabulary-v1.json)では、`fruit` で始まる複合語を集団・割当・相互性、`round` で始まる複合語を数・量・単位・内容物の目印とした。各語は2〜3部品からなる固定の綴りを持つ。この命名規約は部品の意味を論理積にする規則ではなく、正確な語義は共通Native定義または算術の基本規約で与える。登録順、文書専用の番号、名前のハッシュは綴りに使わない。

## 基本宣言と共有依存

既存の `rationalbelow`・`rationaladd`・`rationalnegate`・`rationalmultiply` は、基本宣言のまま導入する。定義専用だった旧辞書の検査を通すために、仮の定義へ置き換える処理は設けていない。第5版では基本宣言の一覧を構成定義と分けて保持し、四つの既存署名と一致することを検査する。文書中で共有算術を別の局所定義へ置き換える入力は拒否する。

複数と量の両モジュールには `memberof`・`distinctmembers`・`membercount` が含まれる。この三定義は、宣言本体・型・引数の役割・意味の説明が一致する場合だけ一つに統合する。説明や本体に差があれば拒否し、後から読み込んだ側で上書きしない。モジュールごとの制限事項は集合としてまとめ、読込順で定義や語形が変わらないようにする。

文書内では、使う語とその依存を可視導入する。依存の導入を省略した文書や、共有語を局所定義で隠す文書は拒否する。算術の意味規約は公開辞書で固定し、評価時にはその規約に従う厳密な有理数の解釈を渡す。SVGに計算結果やASTを隠して復号に使うことはない。

## 旧版を保つ可視ヘッダー

新しい入口は文書の可視ヘッダーから辞書第1〜5版を選ぶ。例えば第4版までの文書で独自に定義した `round/give` という複合名が、第5版の算術語と同じ綴りになっても、旧版の文書は元の意味で読める。第5版へ移す場合は衝突を拒否するため、必要な改名を明示して行う。

ヘッダーが複数行に分かれていても版を選択できる。行の順序・継続標識・段落位置・分割禁止単位の検査は以前の検証器をそのまま使う。第1〜4版の辞書・入口・検証器・固定画像は変更していない。

## 図形から読み戻す検査

追加51語について、型付きの呼出しと関数参照の引用を円と線のSVGから復号し、正規化したNative構文と照合する。算術の4呼出しは基本宣言への参照、残る47呼出しは構成定義への参照として保つ。この呼出し検査は同じ式同士を比較する型・構文検査であり、関数型の全引数領域を実行した証明ではない。

文書全体は次の10文書を検査する。

| 文書 | 検査する内容 |
| --- | --- |
| 辞書一覧3文書 | 既存80語、次の40語、追加51語の全可視導入。各文書が独立したヘッダーと依存を持つ |
| 算術 | 分数の加算、積、符号反転、大小比較。厳密な有理数で評価する |
| 単位換算 | 正の尺度と値の対応、種類の不一致、零尺度の拒否 |
| 行為 | 同一出来事への全員の参加と、各人への別の出来事の分配 |
| 相互性 | 三人の有向環で、各人に入出する相手がいても全組合せや双方向の相手を保証しないこと |
| 内容量 | 登録・測定・部分・完全性・内容の関係を本文内で定義した、一部分・正の量の構成 |
| 人数と範囲 | 異なる二個体、同じ個体の重複、空列の個数の区別 |
| 質問 | 明示した列の構成員を答える型付きの問い |

内容量の可視例は、一つの全体部分に明示的な一定の読みを与える構成検査である。多部分の水・米の具体的測定関数を、公開辞書にない関数として隠して補っていない。多部分の加算、容器数と量の分離、測定・単位・完全性の対照は、保存したNativeの量報告とその依存ハッシュも照合する。図形復号の範囲と、その意味検査の範囲は別々に記録する。

相互性の区別には三個体が必要なため、この文書だけ三個体・二状況で評価し、検査用ステップ上限を100万に指定する。他の意味例は二個体・二状況と通常の10万を使う。処理系の既定値、字形768・可視図形4096・行128などの書記資源制限は変更していない。

## 入出力と保存した証拠

最新の入口は `scripts.visible_quantity_page` である。[内容量のNative例](../examples/v016/visible-counted-contents-v1.noema)を公開語名で編集し、円文字へ変換できる。

```powershell
python -X utf8 -m scripts.visible_quantity_page render examples/v016/visible-counted-contents-v1.noema output/visible-quantity-library-v1/contents.svg --width 3200 --public-names
python -X utf8 -m scripts.visible_quantity_page decode output/visible-quantity-library-v1/contents.svg --native --public-names
python -X utf8 -m scripts.project_work check --module scripts.check_visible_quantity_library --tests tests/test_visible_quantity_library.py --prepare --verify reports/visible-quantity-library-v1.json
```

[報告](../reports/visible-quantity-library-v1.json)には各語の字形数・図形数・依存導入数と、10文書の復号・評価結果を保存する。前版の可視辞書、複数、量の三報告の依存も再照合する。`--prepare` は `output/visible-quantity-library-v1/` に10枚のSVGと6枚の語形一覧PNGを生成する。PNGの英語ラベルは索引であり、復号へ渡す意味情報ではない。

機械的な円・線の復号を、人が画像だけで読む検証やラスターOCRと同一視しない。第三者の学習と読解、二作品全体の新書式化、他の意味領域の一般化は残る。
