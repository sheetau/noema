# 採用円文字の共通規則 v2

2026年11月5日に採用されたconcept2 v7の字形を基準とする。語義・構文を変えず、文書の宣言、共有、長い枝の表記を補った。現行の実装入口は `scripts.concept2_writing.WritingReader`、採用記録は [writing-freeze-v2.json](../data/writing-freeze-v2.json)。旧v1と試作v2～v8の記録は履歴として保存する。規則の相違がある場合は本書を優先する。

## 読む対象と生成の順序

生成は、型検査された構文 → 範囲内の共有計画 → 公開字形 → 接続 → 改行の順に行う。共有計画を展開した構文が元と一致することを先に確認する。字形を描いた後に、その図へ意味を割り当てる方式ではない。

復号は、可視の円・円弧・線・ドット → 字形と接続 → 語と構文 → 共有の展開 → 型・束縛の検査の順に行う。復号器への入力はSVGの描線と公開済みの辞書だけであり、元AST、文番号、期待するトークン列、配置記録、SVGの識別属性は不要。空の辞書から宣言を順に読むこともできる。

ここでの一意性は、以下の字形・接続・文法に従うベクトル表記についてのものとする。円を自由に並べた任意の絵、手書き、写真からのOCRは対象に含めない。一般の幾何検査 `ink_check` に通るだけでは有効な文章にならず、公開字形の認識と構文検査にも通る必要がある。

## 円と線

小円半径を S とし、中円 M = (1 + √2)S、大円 L = (1 + 2√2)S、第4円 F = (1 + 3√2)S とする。上下段は中央から P = (2 + √2)S。ドット半径は (√2 − 1)S。拡大縮小しても比率を保つ。大円・第4円の中心は中央段に置く。

同心の内包と、許された直交交差を使う。直交交差の円種は小中・小大・中大の三組で、中心間距離は √(r² + R²)。偏心した完全内包は禁止する。例図から継承する接触は、同じ縦列の小中円と、縦横それぞれPずれた中円同士に限る。小円は完円とし、直線を内部へ入れない。接続は小円周で止める。

中大円の交差では、中円内の大円弧を必ず残す。重なり側90度のうち、中円外にある二つの翼状の弧は一括して残すか消す。その90度の外では45度区間ごとに選び、少なくとも45度を残す。中円内だけを抜く形、中円内だけに大円弧を残す形は禁止する。小大円では、小円内の大円弧を抜く形を使える。

その他の中大円弧は45度単位で構成する。直交交点での切断はこの刻みの例外。第4円は上下の禁止区間を描かず、基準と許可された側方の弧に使う。円に属する方向線・自由端は中心からF以内で止める。45度方向の限界座標は各軸F/√2である。別の円への接続線と、長さを確認した改行端は次の規則で扱う。

## 接続長と改行

接続側の左右半円に正の長さの大円弧があれば、その大円の完円周端を基準にMを測る。大円が該当しなければ中円について同じ判定を行う。どちらも該当しなければ実接点を使う。半円境界の一点は「円弧がある」に数えない。第4円はこの繰り上げから除外する。弧が欠けているからといって、中心から短く接続しない。

大円の斜め終端から上下段の小円へ移る形では、大円の左右完円端から小円中心までの水平距離をMとする。方向線自体はF以内に保つ。通常の小円間の横線は円周間でM。幹の参照順を示す形では、小円の中心間を2S + Mとし、各枝先の小円を次の幹小円と同じ縦列へ合わせる。

行は上から下、各行は左から右に読む。新しい文は2Mの間隔で区別し、一文の継続は行末・行頭の半径幅の端と段の一致で区別する。字形内部では折らず、字形間で折る。改行しても字句・構文・参照環境は継続する。段落の余白は文の意味を変えない。

## 語、文頭、引数

語は公開された30根の列で識別する。13種の合字と2種の向きの異形は、対応する根列へ展開する。辞書の行番号や文書固有の番号を語名にしない。語が別の語の接頭部になる場合は語終端を明示する。宣言名と別綴りの登録には必ず終端を置く。したがって、既知語の後ろへ根を足すことと、次の語を始めることを区別できる。

文頭へ一律の記号を追加しない。主張は式から始められ、質問・指令・仮定などはそれぞれの構文によって区別する。演算子は既定の引数数を持ち、呼出しはそれまでに読んだ宣言の引数数・型によって読む。可変長の型列・引数列は既定の終端を持つ。区切りは円を含む「値・引用・参照」の三系列と、その群の終わりを区別する二形を使う。

引数の読順は構文順を保つ。2～3段の異なる参照が上・中・下の順なら、複数小円を持つ選択形へまとめられる。それ以外はv4／v7の幹をたどり、同じ段の再使用も区別する。方向付き選択形では中心線が最初の小円を指し、残りを時計回りに読む。合流形では枝の上から下が引数順、各枝の円弧が参照先を示す。合流は値の同一視や論理和を意味しない。

4個以上の引数も通常の引数列と群区切りで読める。2～3段の形に無理にすべてを収めない。

## 引用、型、変数の束縛

基本型と、列・記述・質問・関数の再帰的な型を表記する。束縛は宣言する型と範囲を持ち、変数使用は束縛の深さと位置で読む。外側への移動にはscope-hopを使う。引数位置を変えたり、内側の同名変数に置き換えたりしない。範囲を抜ければ外側の環境へ戻る。

引用は通常の式とは別の束縛・参照環境を作る。評価段階、関数への引用参照、引用値、記述の持上げ・適用を区別し、宣言済み定義を介した評価段階も検査する。仮定文の条件と各子文は独立した文の環境で読む。ある子文の略記を次の子文へ漏らさない。

実装上の構文深さは128、型階数は128、複合語名は24根まで。定義の検査用に一時的に作る式は、元の定義の深さ制限へ加算しない。境界内の型付き定義を受理し、境界を超える式・誤型・範囲外参照を拒否する。

## 共有、反復、離れた対応

共有は同じ構文と同じ束縛先を持つ部分にだけ適用する。局所値参照8組、語参照8組、段参照3組、引用テンプレート3組を使える。語の略記と、値そのものの再使用は別の記法である。テンプレートは引用の共通形式を省略しても、中身の異なる値を同一化しない。

既定の生成は、同じ範囲内で繰り返される式を候補にし、従来の表記と比較して短くなるものを選ぶ。変数を含む式も、束縛先が同じ範囲なら候補にできる。内側の束縛・引用へまたがって持ち出さない。外側の共有に隠されて使われなくなった定義は除く。本文に特定形を一定数出すための選択は行わない。

同じ字形が続く箇所では2～5回の反復記法を使い、長い列は組み合わせる。円なしの縦線の長さS・M・L・Fが回数を区別する。型と束縛距離も圧縮対象とする。小円だけの根は対象外とし、意図的に同形を続ける通常表記も受理する。

離れた対応にはドットを使える。中円の8個の45度区間が256種類の識別を与える。通常形は左右の弧を持つ中円で、完円を要求しない。中円弧がない一形だけ大円へ進み、その対応先は裸のドットにもできる。外側の円や接続用小円は識別を変えない。ドットへ線を接続せず、小円へ内包しない。同じ識別形は同一範囲内で順に対を作り、未対応・引用境界越えを拒否する。

## 長い枝と多段の組立て

任意の長い2～3引数を分岐へ渡すには、局所的な組立て範囲を使う。既存の「group-open、参照群区切り」の並びで始め、異なる段への定義を元の引数順に読み、終端区切りの後で段参照を呼出しへ渡し、group-closeで閉じる。通常のgroupの先頭には引数区切りが来ないため、この開始形を区別できる。新しい字形や言語の原始語は不要。

各定義は型付きの式であり、長さ・内部の引用・束縛・入れ子の組立てを持てる。定義が複数行へ続いても、最後の幹や選択形は一字形として残る。段の割当順と引数順を混同せず、外側の段・局所・語参照は終了時に復帰する。ドットの対応範囲は通常の束縛範囲と同じ扱いにする。

これは長い枝を局所定義と参照へ分ける表記である。任意に長い複数の枝を並行して別々の行へ折り返す描画、循環グラフ、未定義の先への参照は採用しない。同じ構文は通常の直列形でも表せる。すべての文の先頭へ組立て範囲を付けない。

## 文書と辞書

原始語宣言・型付き定義・別綴り登録を別の形で読む。宣言は使用より前に置き、定義本体は既知の語だけを参照する。未宣言、前方参照、自己循環、重複名、綴り衝突を拒否する。検査に失敗した記録は辞書へ登録しない。

公開辞書は1,705宣言（原始語487・定義1,218）と404件の別綴り登録からなる。根による正式名を含めて2,109綴りがある。旧出版データで省略されていた361基礎語を既存定義から明示したもので、原文の文ごとに原始語を追加したものではない。

## 一意な読みに必要な条件

字形は位置やSVG要素順で識別せず、規定半径、弧、線、ドットの組で識別する。左端の未処理の円を起点に公開形を照合し、途中の円を飛ばさない最大の形を選ぶ。同順位の候補が複数あれば拒否する。候補の線に加えて、字形間の接続経路・半径幅・継続端を照合し、説明できない線を残さない。縦線だけの反復は四段階の長さで読む。

回収した字形列は、語終端、宣言された引数数、群の終端から構文を読む。段や局所参照は定義済みの環境でのみ展開できる。引用・束縛・組立ての入口と出口で環境を切り替えるため、外形が同じでも作用範囲を推測する必要がない。文を読み終わって余分な字形・未閉鎖の範囲・未対応ドットがあれば拒否する。

この決定規則、有限の公開形、構文の再帰規則を合わせて読み方を定める。有限例の往復成功だけを、任意の自由配置の一意性の証明とは扱わない。可視の印を削れば別の有効な文になる場合もあるため、復号可能性と誤り訂正能力も区別する。

合計501形。全形を単独の図形として読めることと、文法の中で使えることを分けて確認する。幾何の作図関数では、日食型の外側6区間の選択など、未割当ての組合せも生成できる。許された幾何の全組合せへ無条件に語義を付けることはしない。新たな語は既存の根列から作れ、未割当ての単一字形を使う場合は字形表と復号規則の版更新が必要になる。

主要な確認は `tests/test_concept2_release.py`、`test_concept2_semantic_forms.py`、`test_concept2_sharing.py`、`test_concept2_assembly.py`、`test_concept2_assembly_compatibility.py`、`test_concept2_definition_depth.py`。幾何・型・文書・高速復号については既存のconcept2試験と保存結果を継承する。実際に空辞書から順に読んだ2,168 SVGの記録は [統合復号報告](../output/concept2-unified-reader-v1.json)。全1,705宣言、404別綴り、カント40項目と58対照で構文が一致した。

構文・語義・参照先が不変な部分には既存の意味判断を引き継ぐ。保存済み意味監査の8,510依存ファイルの内容一致は [継承報告](../output/concept2-semantic-carry-v1.json)にある。今回の完了範囲は残件1の共通書記・復号基盤であり、二作品全402主張を新字体の最終文書へまとめる作業とは分ける。
