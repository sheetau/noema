# 作品と、その記録を保持する媒体

書物の部分説明で用いる「外部の持続する媒体から参照できる」という基本関係 `sd` を、作品・記録・媒体を結ぶ定義へ置き換えた。作品の内容を参照することと、紙などの複製媒体を所有することを区別して述べるための変更である。

一般定義 `rqxk` は、指定した作品を実現する記録が、指定した媒体に保持され、同じ状況で参照可能であることを要求する。三つの関係は同じ記録を共有する。作品Aを記録したものとは別の記録が媒体にあり、さらに別の記録が読めるだけでは成立しない。作品や媒体、状況の取り違えも区別する。

本文用の `sd` は、そのような媒体が少なくとも一つあることを述べる。複数の媒体に同じ作品の写しがあってよく、一つの媒体に別々の作品が記録されていてもよい。作品と写しを同一視したり、写しが一つしかないことを要求したりしない。一つの写しが読めなくなっても、別の参照可能な写しが残る場合を表せる。

作品を表す `sc` と、外部の記録が参照可能である `sd` は別の条件である。写しの破壊から作品自体の同一性や内容の消失を推論しない。特定の人が作品を利用できることは既存の `sa` で別に要求する。したがって、記録が存在して読めるだけで、本人が手元に持つ、言語を理解する、内容に賛同するとはしない。

三つの一般関係として、記録が作品の表現を実現する関係、持続する外部媒体上に保持される関係、記録を参照できる条件を追加した。これらの関係の意味規約を持つことと、作品・版・記号表現をすべて基礎から説明することは別である。従来の基本関係 `sd` を定義へ移したため、基本関係の純増は二つである。新しい文法や、原語の文字列を検索する処理は追加していない。

書物の条件 `sl` は、記された作品 `sc` と構成した `sd` を結ぶ。同じ作品を本人が利用でき、その表現が本人の理解力の使用に代わって供されるという既存の例へ接続する。作品そのものが人間のように考えるという主張にはしない。書物を手紙や短いメモなど他の記された作品から区別する全条件は、今回の構成だけでは説明し終えていない。

二記録の三関係の真偽を変える64例と、作品・記録・媒体・時点を取り違える八対照で、同じ記録の証人を要求することを検査した。複数の写し、同じ媒体上の別作品、片方の写しだけが読めなくなった三モデルも確認した。これらは異なる作品と媒体を持つ解釈を受け入れる検査であり、一般定義があらゆる個体の同一性を自動決定するという主張ではない。

本文の17対照は、記録の欠落、別作品、別時点、読めない記録、利用できない本人、別人への供給、目的の不達成を含む。比較対象の旧 `sd` には、同じ関係集合から独立に計算した解釈を与えた。この整合した解釈で、新旧の供給・前件・適用可能性・条件文が一致することを確認する。旧 `sd` に無条件に真を与え、関係の証人がない新定義と比較して旧意味が誤りだったとする検査ではない。

三つの新関係が不明な場合は既知の意味へ補わず、八つの帰属対照では作品や媒体の事実を不明のままにした。実際の本文の定義を通常評価し、検査用の基本関係への置換はしていない。完全記法・短縮記法・独自文字の往復も検査する。
