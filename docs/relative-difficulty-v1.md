# 本人の力と、達成方法に必要な投入

離脱が「困難である」という部分を、本人の力に対して必要な投入が大きいことから組み立てた。従来の`uy`は活動全体の負担が大きいという部分的な読みだった。今回は、利用可能な方法、その方法による達成、同じ経路の必要量、本人が投入できる上限を結ぶ。

カントは後年の『人間学』で、容易さと煩わしさを分け、本人の力が必要な投入を上回る余裕について述べる。この区別を参照するが、今回の方法評価や尺度が1784年の句から一意に定まるとはしない。[Kant, AA VII147](https://korpora.org/Kant/aa07/147.html)

## 余裕を持って達成できるか

| 定義 | 内容 |
| --- | --- |
| `r2db` | 本人の上限まで上方に閉じた、余力が少ないとする帯 |
| `r2dc` | 同じ本人・方法・開始・結果の一意な必要量が、本人の上限以内である |
| `r2dd` | 全利用可能方法の結果評価と、達成方法の全経路の必要量評価が整う |
| `r2de` | 同じ利用可能な方法の全評価結果で、上限内の投入によって達成する |
| `r2df` | その同じ達成方法の全評価経路で、余力が少ない帯の外にある |
| `r2dg` | 本人の一意な上限と尺度・帯の下で、余裕を確保できる方法がある |
| `r2dh` | 達成方法はあるが、余裕を確保できる方法がない。方法の評価も整っている |
| `r2di` | 本人の自己作業による未成熟から自立的な行使能力への移行へ、この困難さを適用する |

追加した入力は、同じ実施者・受益者・力の種類・方法・経路の必要量と、同じ本人・種類の投入上限の二つである。尺度は質的な順序として与え、数値や物理単位を原文に補わない。下端は当該種類の力を追加投入する必要がない基準とする。上限がその下端なら帯を空にし、追加投入不要の達成方法も扱う。未知の評価は下端とは区別する。

上限と必要量には同じ種類と尺度を使う。同じ必要量でも本人の上限が異なれば、余力も異なり得る。帯の境界は文脈で校正する。形式検査は帯が上限を超えず上方に閉じていることを確認するが、「どこから余力が少ないか」を順序だけで発見するものではない。

## 方法と結果を混ぜない

成功する方法と、安いが失敗する別の方法を組み合わせても、余裕を持って達成できる方法にはならない。ある方法に容易な結果が一つあっても、他の評価結果で余力が少なければ、全結果に余裕を確保できる方法とは扱わない。結果の採用基準は文脈入力であり、都合の悪い結果を除いてよいという規則ではない。

困難さの否定を、単に評価が見つからないことから出さない。利用可能な方法の結果評価が整い、達成方法については必要量も一意であることを要求する。逆に、全評価結果で達成しないと分かっている方法の必要量が未評価でも、それだけで有効な困難さの評価を取り消さない。余裕のある一つの達成方法を確認できた場合は、別方法の必要量の欠落だけでその肯定を取り消さない。

今回の`r2dh`は、少なくとも一つの上限内の達成方法を要求する。「達成可能だが余力が少ない」という内容であり、達成方法の不在、上限を超える必要量、未評価とは分ける。到達不能を含み得る自然言語の困難さの全用法を、この一つへ還元したとはしない。

## 自己作業への接続

原文側では、同じ本人の自己作業が未成熟から自立的な使用能力への移行を生む既存の`h4p`を使う。想定結果ごとの仮定内で、同じ過程・本人・前後の状態・自己の精神への働きかけ・結果への因果を評価する。現在の世界で各代替方法を既に実行したと断言する式ではない。一つの方法を一つの活動過程へ対応させる粒度と、仮定内の履歴を採ることは明示的な解釈上の選択である。

必要な力を出す人と、能力を獲得する人を同じ本人に結ぶ。他人の努力や別の評価種類を流用しない。本人の働きかけは必要だが、他人の援助が一切ないことまでは要求しない。現在の行使能力がないことと、基盤を変える自己作業によって将来の能力を得ることを区別する。

検証では、二方法の必要量と達成可否の64組合せを独立の集合・順序計算と照合する。評価欠落や多値、上限超過、空の結果、帯の不整合、安い失敗方法、結果ごとの必要量の違い、同じ必要量で本人の余裕だけが変わる場合を対照に含む。原文側では現在の不能、将来の能力、自己作業の過程を通常の評価器で実行し、自己作業・参加・因果・変化・将来能力の欠落や、他人の努力・別種類の量を取り違えないか確認する。

対象段落は個人の離脱の困難に続いて、自己の精神への働きかけで成功した少数者を述べる。この文脈を参照するが、今回の到達可能な困難さを、そのまますべての個人へ全称化しない。[Kant, AA VIII036](https://korpora.org/Kant/aa08/036.html)
