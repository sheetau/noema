# 継続する状態と、保持された態度

[原文の「gerne Zeitlebens unmündig bleiben」](https://korpora.org/Kant/aa08/035.html)には、未成熟な状態が続くことと、本人がそれを好ましく受け入れることが含まれる。今回は、後者を保持された肯定的態度として読む。全瞬間に楽しく感じていたり、自分の状態を意識して判断したりする、という条件にはしない。

既存の `id` は、ある人が自分の状態を好ましく受け入れる関係だった。その意味規約に、保持された態度と瞬間的な感情・注意の区別を明記した。睡眠や注意の移動だけで態度の消滅とはしない。一方、無自覚、無反応、抵抗の記録がないことだけを肯定的態度の証拠にしない。本人がその状態を嫌い、態度を反転させている場合は、同じ態度が続いている場合と区別する。

本文の `ie` は、同じ本人の同じ生涯の範囲で、未成熟 `bf` と、その同じ状態への態度 `id` が続く条件を保持する。構文や定義本体は変更しない。これは原文に対する持続的な受容という読みであり、態度の反転も例外として許す別の読みとは同一視しない。自発的な選択、強制の不在、将来の全出来事の予見、好みが継続を引き起こす因果関係も追加しない。

生涯の範囲 `ib` は、文脈で指定された開始点から、その人の生涯の終わりまでの全範囲と明記した。出生からか、成人後からか、基準時から残る生涯かは文脈で指定する。都合のよい観測期間で打ち切ったり、状態が成立した点だけを選んだりすることは、この意味規約に合わない。既存 `h26` が要求する「基準時以降の残る生涯」も、この範囲の選択をさらに制約する条件として保つ。

ただし、区間の整合性検査が実世界の生涯の完全性まで判定するわけではない。検査には、後半で状態が失われる全範囲と、その前で観測を打ち切った範囲を両方入れた。後者だけを与えれば有限の区間条件は通る。この限界を記録し、観測が短いだけの例を、生涯にわたる継続の証拠にはしない。

一般定義 `rqxf` では、状態の継続範囲と、態度を要求する機会を別々に渡せる。状態は非空の連続範囲の全体で成立し、態度機会はその範囲内の非空の部分集合となる。態度は全機会で要求するが、機会同士が連続している必要はない。例えば状態は三時点で続き、態度を確かめる機会は最初と最後、という構成も記述できる。機会を成功した点から後付けで選ぶだけでは、現実の態度について十分な根拠にはならない。

性質は閉じた記述を一つだけ渡す。その記述から本人についての内容を作り、同じ記述を態度の対象にも渡す。真偽が同じ別の性質への態度を、指定された性質への態度と取り違えない。本文の `ie` は状態範囲と態度機会を同じ範囲に固定した特殊化であり、既知の `bf` を直接呼ぶことで引用の階層を維持する。新しい基本関係や構文は追加しない。

検査は状態と態度の64組合せ、範囲・機会・人物・記述・文脈など十一対照、態度機会の間に態度だけが欠ける例と状態が欠ける例を含む。一般形と本文の特殊化を比較する検査では、実際の `ie` の本体を使い、`bf` には明示的な検査用の性質を与える。未成熟を判定する能力の全定義や人口比率まで再実行した結果とはしない。未知の解釈は真偽へ補完しない。

意味規約の変更が届く本文は文2・3・11である。七つの帰属対照では、その三文を、状態・態度・生涯の事実を全て不明のまま実行する。著者への帰属や比喩の提示から内容の真実性を導かないことを確かめる。既存十一単位のレビューは全依存先が不変であることを検査して引き継ぐ。
