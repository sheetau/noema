# 同じ対象の正負定義を直接比較する条件

WiC-TSVの二値判定をNoemaの91候補へ転用した前回の結果は、特定の定義へ強く偏った。今回は既に注釈されている正負の定義を同じ原文・対象範囲ごとに比較する。未注釈の候補を負例にせず、生成や語別の補正は使わない。

## 区分と候補の比較

- 固定した公開英語Trainingの2,828例だけから内部の学習・開発を作る。同じ見出し語または同じ原文で結ばれる例を連結成分にし、成分内の見出し語一覧とseed 17のハッシュを5で割った余りが0なら開発、それ以外を学習とする。原文と見出し語の両方を区分間で共有しない。結果や正負比率で区分を調整しない。
- 学習は2,203例・691見出し語、開発は625例・173見出し語。同じ原文・同じ対象範囲に正負があるグループは学習351、開発95。正負の全組合せはそれぞれ436、145対。原資料の不確実性と英語名詞中心という限界は維持する。
- 公式Development 389例は今回のepoch・方式の選択に使わず、選択後の二値診断にする。ただし前回までに観察済みなので、全く未観察の最終評価とは呼ばない。公式Testのラベルは使わない。

## 学習

- 前回保存した固定MiniLMの特徴をハッシュ検査して再利用する。原文・対象・定義のみから計算した特徴であり、見出し語や正解ラベルは入力しない。基盤モデル、二列入力、対象と定義の平均、線形または幅64のMLPは変更しない。
- 同じ対象の候補グループを単位に学習する。各グループの二値交差エントロピーを定義数で平均し、さらにグループ間で平均する。
- 順位の損失は`softplus(-(positive_logit-negative_logit))`。グループ内の実際の正負対で平均し、比較できるグループ間で均等に平均する。各グループの定義数が多いだけで寄与が大きくならないようにする。
- 二値損失のみ（順位係数0）と、二値損失＋順位損失（係数1）を、線形・MLPそれぞれで比較する。グループ一様抽出のミニバッチでは、順位項を全グループ数／比較可能グループ数で補正する。正負比較のないグループから順位の正解を作らない。
- AdamW、学習率0.002、weight decay 0.001、batch 32グループ、20 epoch、seed 17。最終層0初期化。同じ構造の対照と順位追加で初期値・バッチ順を揃える。
- 内部開発でグループごとの正負順位正解率を平均し、最大のepochを選ぶ。同点は二値の均衡正解率、それも同じなら早いepoch。順位の完全同点は0.5点とし、同点数も報告する。方式間の同点は線形、順位なしを優先する。

## 確認

選択後だけ、公式Developmentと、観察済みNoema v1〜v6の日英442範囲を評価する。Noemaの閾値は元のlogit 0のままで、ここで調整しない。順位・二値判定・未知例への過剰な肯定を別々に記録する。Noemaへ校正済みの確信度とは呼ばず、全文を確定しない。

区分の原文・見出し語の不交差、行の完全な包含、注釈済みの対だけを使う損失、定義数によらないグループ均等化、順位の同点処理、固定特徴からの再学習と全予測の再計算を検査する。前回の全Training・公式Development選択とは条件が異なるため、前回との差を順位損失だけの効果とは主張しない。今回の同一区分の対照間で比較する。
