# 有限経路の出来事・時計・指示

[経路の観測草案](../examples/v014/einstein-path-observations.noema)は、0.14の有限列と既存の時計の基本関係を組み合わせ、区間の端点における座標と指示を接続する。新しい文法や物理的な基本記号は追加せず、15基本記号・107定義となった。

従来の時間集計では、区間の時間と進み率を加算しても、その数値が同じ時計の読みかどうかは条件に入っていなかった。今回の草案では、同じ時計・基準系・文脈・長さ単位・座標時刻単位・文字盤の単位を全区間で共有する。区間の終点と次の始点は同じ出来事を参照し、出来事から時刻・位置・指示を得る関数も共有する。

## 四つの定義

| 定義 | 条件 |
| --- | --- |
| ja | 二出来事の座標・指示、正の時間差、変位と速度ベクトル、速度の大きさと時計の進み率、指示差の法則 |
| jb | 同じ出来事で接続する非空の区間列、全区間のja、継続時間・経過・遅れの集計 |
| jc | jbに加え、出発と帰着の三つの位置座標が等しい |
| jd | jcに加え、その場所の別の静止時計との出発時の指示一致・共通尺度での校正・帰着時の指示差 |

jaでは、座標時間差をΔt、速度の三成分をvₓ・vᵧ・v𝓏、速度の大きさをs、進み率をr、共通の文字盤尺度をkとし、以下の条件を記述する。

- Δt > 0、k > 0、s ≥ 0。
- 各座標の変位はΔtと対応する速度成分の積。
- s² = vₓ² + vᵧ² + v𝓏²。
- 既存のhaにより、0 < r、s² < V²、V²r² = V² − s²。
- 指示差はk·Δt·r。

座標はpa、光速はpc、時計と時間単位はma・mi、実数の切断で表した指示はmeという既存の関係へ渡す。数値を引数で与えただけでは観測があったとは扱わず、それぞれの基本関係が成立することを要求する。原点にある一本の等速世界線を対象とした旧hnを、向きが変わる経路へそのまま流用していない。

**端点の座標と指示がこの式に合うことだけで、区間内の等速運動や加速点での時計の法則を導いたとはしない。** jaの指示差の式は、この経路モデルで採用する理想的な区間法則である。実際の運動と時計への適用根拠は別に必要になる。中間の全時刻における世界線や、加速中の機構を定義したものではない。

jbでは区間ごとの継続時間を、共有した時刻関数の「終点−始点」から構成する。途中の出来事が二つの区間で共有されるため、時刻と指示を別々に設定し直すことはできない。座標や指示が一致する別の出来事を境目として渡しても、出来事の同一性を要求するifが拒否する。

帰還する場合、出発と帰着の**場所は同じでも出来事は異なる**。jcは位置座標の一致を要求し、出来事を同一視しない。正の時間差を持つ接続列なので、同じ出来事を出発と帰着に指定した正の時間の循環は成立しない。異なる位置へ向かう開いた経路はjbで記述でき、jcでは成立しない。

jdの静止時計は移動した時計とは別の対象とする。出発・帰着の出来事と静止時計が同じ場所にあること、静止時計の二つの読み、同じ尺度kと原点oによる読み`k·t+o`を明示する。出発時の指示が一致しなければ同期済みと扱わない。帰着時の指示差は指定したgapとして保持する。離れた場所の二時計の同期まで、この同じ場所での比較に置き換えてはいない。

## 検査した結果

具体例では、光速5、往路と復路の速度の大きさ3、各区間時間5、進み率4/5を用いた。出発時の指示を10とすると、移動した時計の読みは10→14→18、静止時計は10→20となる。帰着時の差は2である。これらは指定した区間法則の解釈であり、測定結果ではない。

35の観測例では、共通の時刻原点、任意の指示原点、60倍の共通文字盤尺度、二方向の速度成分、速度0の区間、開いた経路を区別した。途中の時計・出来事・単位の置換、指示のリセット、速度と変位の不一致、同期していない静止時計、到着場所の不一致など28例は成立しない。

有限解釈のmeは、各例で実際に構成した有限個の有理数埋込みだけを対象とする。候補値間の中点による判別位置を[検査記録](../reports/path-observations-v1.json)に保存した。任意の実数切断の等しさを、有限個の値で一般に判定できたとは扱わない。

さらに、[四つのNoema主張](../examples/v014/path-observation-claims.noema)を有理数の多項式として検証した。

1. 隣接する二つの時刻差の和は、最初と最後の時刻差に等しい。
2. それまでの指示差がk倍の経過合計に等しいとき、次の区間で同じ法則が成立すれば、その等式は更新後も保たれる。
3. 空の集計では指示差と経過合計がともに0である。
4. 出発時の指示が一致し、静止時計が同じ尺度・原点で校正されていれば、帰着時の指示差はk倍の遅れになる。

主張2と3は有限列についての帰納の初期条件と更新条件に対応する。ただし補助検査器が証明したのは記述した有理数の等式であり、有限列の意味論を含む帰納定理全体の機械的な証明ではない。jbの条件に、望ましい全体の指示差を追加して検査を通す方法は採っていない。
