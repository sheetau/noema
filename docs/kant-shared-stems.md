# 一枝でも主列と線を共有する

円から出る一本の線を途中で分け、枝と主列へつなぐ配置を、枝が一本の場合にも使う。以前は同じ円から複数の枝が出るときだけ許可しており、一枝では主列への接続を円周から別に引き直していた。この制限により、枝の上を大きく迂回する線が必要になる例があった。

分岐位置は、同じ親円から最初の枝へ引いた線の曲がり角、または所定の長さがある線分の中点から選ぶ。他の円から出た線へ合流すること、同じ接続を途中でもう一度交差させること、閉路を作ることは許可しない。円周への入射、三段の基準、偏心内包の禁止、曲げるまでの距離は従来の検査を通す。

読取規則は変えない。円を出た後で線が分岐している場合も、各経路で最初に達する円を集め、左から枝、最後を主列として読む。最初の円のx座標が等しい配置は曖昧として拒否する。途中の分岐位置や描画順は語義や引数番号を表す追加情報ではなく、読取器へ渡す隠れた対応表も設けない。

検査では保存済みSVGと新しいSVGをそれぞれ復号し、元の構文との一致を確認する。円数と既存の枝数を照合し、線分の重複を統合して線の総延長を測る。幅、三段の外への張り出し、線の総延長は別に比較する。代表例が短くなっても、全体の外観が完成したとは扱わない。長い迂回、型語と文頭の反復、未対応構文、行頁の復元、利用者による最終確認は残る。
