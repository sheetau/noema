# 両横軸の光線とη・ζの導出

u0073–u0080は、直前の縦光線と同じ方法を両横軸へ適用する箇所である。原刊900頁を確認し、原点から正方向へ放出する先行の設定を横二軸にも適用する読みを採る。新しい原始語は加えず、既存の軌道、数式、類推と書換えの関係を使う。

## 全光路と現在の測定

ei6cは同じ光・始終出来事・現在の時計と四座標を、零点から進む全直線軌道へ結ぶ。Kでの速度成分は縦にv、選択横軸にw=√(V²−v²)、他の横軸に零である。kでは縦が零、選択横軸がVである。Kでの光路長は斜めの経路の長さであり、横距離と混同しない。

ei6dは両系で同じ光を測るei45、零原点の規約、両端の同じτと全τ式を保持する。kの軸に沿う全光路とKの斜めの全光路を別々に要求する。端点二つが同じ値でも途中で曲がる経路を受理しない。

yとzは別々の区間を選べる。共通のV、v、未定φ(v)を使う一方、光・到達出来事・距離・時刻は軸ごとの測定へ結ぶ。両方の光線の考察を記述し、一方だけの測定で他方の条件を済ませない。

## 数式と本文の役割

既存soeはη=Vτ=aV(t−vx′/(V²−v²))、sofはt=y/√(V²−v²)とx′=0を同じy光線の到達出来事へ結ぶ。ei6hはこの二式と現在の光線を同時に保持し、書換えの結果を既存sogのη=aVy/√(V²−v²)へ結ぶ。

zの結果は、その軸の同じ形の時刻条件を補う類推として記述する。原文のAuf analoge Weise、wobei、also、undを、考察の類推、同じ導出に伴う条件、代入の帰結、二つの横方向の並列として接続した。著者の計算提示と、計算を実際に行った履歴は区別する。

aは未定のままであり、1へ固定しない。光線上の式から光線外の全変換を確定する段階は、次の単位へ残す。

## 検査の範囲

有限例ではKのV=5、v=3、w=4を使い、y到達のK時刻2とz到達のK時刻3を区別する。全軌道への引数、三速度成分、始終位置、光路長、時計・座標の接続、未定係数を変えた式を対照検査する。全実数時刻の量化は有限評価を拒否する。

現在の全時計網と原点、一般の時間式は既存の検査証拠へ結び、新しい結合検査では境界として扱う。関数の有限指紋や既存の有理多項式補題を、一般の連続軌道・平方根・物理法則の証明とはしない。全文の意味判断は原刊と本文全体を通読して別記録に残す。
