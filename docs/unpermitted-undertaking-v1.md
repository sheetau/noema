# 取り組みへの許容と、実際の試みを分ける

[カント第二段落](https://korpora.org/Kant/aa08/035.html)の `wagen durften` について、後見人の監督下で「勇気を伴って取り組むことへの許容がない」という対象側の読みを記述する。前段の実際の阻止だけでは許容の有無を表せなかったため、同じ人・同じ先行時点の規範状態を本文へ加える。

[IDSの様相動詞の整理](https://grammis.ids-mannheim.de/terminologie/155)と[許可に関する用法](https://grammis.ids-mannheim.de/verbs/view/401128)を参照した。現代語資料は許可と能力を区別する参考であり、1784年の原文の唯一の読みを証明しない。今回の選択は、原文と前後関係から採用する明示的な解釈である。

## 規範が対象とする内容

`hzta` は閉じた目標記述を固定し、一個体の引数列から本人を取って、勇気を伴う取り組み `hzs4` を返す。`hztb` は列の長さを確認する。目標と本人を保持したこの記述を、既存の引用合成で構成する。自由変数を引用内へ持ち込まず、内容を実行して置き換えることもしない。

`hztc` は同じ出所・本人・立場・目標・状況について、既存 `rjp` による積極的許容の欠如を表す。許容の情報が未知の場合は否定へ補わない。検査例の完全に指定した関係の偽と、実世界で記録を見つけられなかった場合を同一視しない。

この条件は、明示的に不実行を要求する `rjq` と異なる。許容も禁止もない状態、許容と禁止が衝突する状態を分けられる。また、取り組みを規範の対象として述べるだけでは、本人に勇気があるか、実際に試みたか、目標を達成したかは評価しない。許容されなくても行った場合や、許容されても行わない場合を表せる。

## 同じ時点と対象者へ接続する

`hzte` は既存の二つの先行段階 `hzso` に、阻止と同じ第二時点の許容欠如を加える。対象者は後の危険提示時点で固定する。一人だけ許容されている場合を、別の人の許容欠如で埋めない。後の時点、別の出所、別の立場、別の目標や別の引数への許容を混ぜない。二つの先行段階相互の厳密な順序は追加しない。

`hztf` はこの内容と危険提示を結び、`hztg` は著者へ帰属させる。比喩の対象側 `hzth` も、同じ先行時点の阻止と許容欠如を含む。`hzti` はそれを既存の閉じ込め描写へ非字義的に対応させる。規範の出所には同じ後見人群を使い、許容を受ける立場は局所参照 `hztd` で固定する。特定の法制度や制裁、後見人の正当な権限は追加しない。

八定義と一つの立場の参照を追加し、新しい意味の基本関係は使わない。本文の二文（0起算35・36）を更新し、他の35文と九単位の意味判断は保持する。旧候補も比較用の定義として残す。

## 検証と限界

許容・禁止・勇気・試み・成功の32組合せを通常評価で検査する。八つの規範対象対照、列の過不足・別人・引用合成、15の本文接続対照、八つの帰属対照を調べる。本文の時間探索では純粋な計算結果を再利用する。定義を検査用の真偽値に置き換える処理はない。通常記法・短縮記法・固有文字の往復も確認する。

許容欠如が阻止の唯一の原因だとは主張しない。身体的な一歩、`ja` の強調、慎重さ・穏順さ・皮肉、歩行と転倒の描写、学習と萎縮の接続は残る。規範を選んだ読みだけで、実行機会や第二段落全体の意味を解決したとは数えない。原文対応範囲と意味確認済み九単位・587非空白文字は維持する。
