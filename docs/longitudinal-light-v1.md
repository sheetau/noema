# 縦方向の光線と空間座標への代入

アインシュタイン§3の `u0065`〜`u0072` を部分記述した。原点から正のξ方向へ出る同じ光について、`ξ=Vτ`、τの式の代入、静止系時刻による `t=x′/(V-v)`、その代入で得る `ξ=a*V²*x′/(V²-v²)` を順に結ぶ。今回の式は選択した光線上の出来事に適用し、光線外の全座標で成立するとは主張しない。

`smt` は指定した基準系の局所時計と、同じ系の参照時計を使う。時計の配置・静止・同期・読みを、一意な出来事時刻へ接続する。`smu` は既存の片道の光速度条件 `sba` の基準系を引数にし、時刻の条件をこの `smt` へ変更した。光源、放出、伝播、真空、光路長、単位の条件を保持する。`smv` と `smw` は、必要な全区間を尽くす非空の範囲で、同じ速度Vを要求する。

原理の内容を記述した `sno` は、今回の二系が相対性原理の比較対象であることと、運動設定・静止系での光速度の原理を含む。そこから運動系でもVを測る `snp` への本文の推論を帰属として記述した。一般的な法則不変性の記述から、光速の測定法則が導けることを証明したものではない。

`snc` は両系の区間記録に、同じ光・同じ放出出来事・同じ到達出来事を要求する。共通零点、正の縦方向、軸に沿った光路、座標差に等しい光路長、両端の局所時計を結ぶ。静止系記録と運動系記録の時刻や距離は別の値を持てる。先行する同じτを、到達出来事のx′,y,z,tで評価した値が運動系時刻になることも要求する。

`sng` は同じ到達出来事でξ=Vτ、`snh` はそのτへ先行する式を代入した条件である。`sni` はx′=(V-v)tとt=x′/(V-v)を同時に記述する。ここでtは静止系の時刻であり、V-vを運動系で測った光速として使わない。`snj` は同じx′と係数aによる縦座標の式である。`snk` は局所の両区間だけでなく、両系の光速度の法則と同じτの式も前提へ結ぶ。

検査例ではV=5、v=3、a=2とし、到達時の静止系座標をx=20,t=4、運動系座標をξ=25,τ=5とした。このときx′=8である。tをτへ、x′をξへ置き換える取り違えと、別のφ値を代入する取り違えを拒否した。一般の式の有理数検査でも、時刻の代入後の式と縦座標の式の同値を確認した。

この光線上の一致だけでは、一般の座標変換は決まらない。縦座標の候補へ任意定数λを使って `λ*(x′-(V-v)t)` を足しても、対象の光線上では同じ値になる。光線外では値が異なる具体例を確認した。全座標への拡張には他の条件との接続が必要であり、今回の代数的な代入だけでその接続を済ませたとは扱わない。

先行結果を使えば空間三座標を容易に求められるという文、二原理の適用、光線の式、二回の式の書換え、相対速度による時刻の式を別々の帰属として記述した。「容易」は著者の評価として保持するが、成功する計算方法の負担からの構成説明は残る。

新規10件を含む関連32テストが通過した。指定系の光速度の法則16例、同じ光線と出来事の接続18例、四つの式の値6例、前提の接続8例、帰属12例を検査した。全体の光路がVに合っていても、選択した部分区間が合わない例を拒否した。同期・一意な時刻・速度の条件や、原点・運動・測定記録は各検査で明示的な検査用関係を用いる。全実切断の物理モデルを有限例で証明したものではない。
