# 実際の該当者の人数と、譲歩・推論の提示

第三段落末の少数者について、自分の精神への働きかけによる自立達成と、その時点以後に完了する独立した判断の活動を持つ人を数える構成を追加した。人数の真理条件、期待との対比、著者が根拠から結論を提示する関係を分ける。

## 数える性質と評価条件

人数を数える性質は先行版の `h5k` である。時間順を持つ達成と活動を要求し、身体的な歩行は条件に含めない。期待に反したかどうかを表す `h5l` を人数の性質として使うと、期待を評価できないだけの人まで成功者から除いてしまう。そのため、人数は `h5k` のまま数える。

一般構成 `rcu` は、列の各対象について、数える性質の肯定例があるか、否定の評価に必要な完全性条件を要求する。`rcv` はこれに全対象の正確な列挙と上限未満の人数条件を加え、`rcw` はさらに少なくとも一人の該当者を要求する。列に載らない対象をここで評価しないため、範囲を尽くすことは既存の `rcm` によって別に検査する。

原文側の `h5m` は、肯定例に `h5k`、否定評価の条件に履歴内の能力評価 `h4t` を使う。旧 `h4u` の「どこかで自立した経験 `h4q` があればよい」という条件では不十分だった。自立の前に知的活動を終えていて、その間の能力評価が欠けている例では、後の自立経験だけを根拠に「結合した性質を持たない」と数えられない。今回の条件は、この評価不足を拒否する。

有効な `h5k` の肯定例がある場合は、別時点の能力評価が欠けていてもその例は失われない。これは真偽のモデルに明示した肯定証拠についての条件であり、未知の理由・活動範囲・因果を偽として埋める許可ではない。そうした基本関係には完全な解釈が必要である。検査用の有限評価器は、未評価の関係を読み出すと失敗する設定でも確認する。

## 存在と譲歩を分ける

`h5n` はゼロ人を許す上限条件、`h5o` は少なくとも一人いる上限条件である。本文の候補には `giebt es` を存在を伴う読みとして `h5o` を採用した。ゼロを許す候補も保持し、原文の存在含意や具体的な上限を確定したとは扱わない。上限は既存の文脈依存の関係 `h4h` で与える。

`h5p` は、列に含まれる実際の `h5k` の該当者について、同じ文脈で `h5l` の期待との対比が成立することを要求する。人数条件だけの内容を `h5q`、人数と譲歩の両条件を持つ内容を `h5r` とした。予想の候補が空になったり、予想でも活動が成立するようになったりすると譲歩条件は変わるが、実際の人数は変わらない。

これは譲歩を実際の該当者へ分配する一つの読みである。集団全体にかかる別の読み、期待の程度・選定理由、`nur` の焦点の全意味は未完である。

## 全文の候補と推論の帰属

`h5s` は、指定した対象範囲を尽くす有限列が存在し、その列について人数と譲歩の条件 `h5r` が成立する内容である。対象範囲との一致を要求するため、成功者だけの標本へ差し替えても成立しない。任意の有限列への存在量化を使い、有限評価器はこれを有限個の候補列で代用しない。

新しい談話参照 `h5t` は、この結論の文章箇所を指す。`h5u` は、著者が `h5s` をこの箇所で提示し、直前の条件付き描写 `h3a` とその理由 `h3s` を根拠として結論を述べ、理由の後に結論を置くことを記述する。既存の `uc`・`ud`・`ue` を使い、内容を引用のまま扱う。

この推論の帰属は、条件付きの身体描写から現実の人数が論理的に導かれるという証明ではない。`Daher` の参照範囲を直前の二箇所とする明示的な候補であり、段落全体との関係を唯一に確定しない。

## 検証と限界

- 一般形では性質・評価条件・上限の256組、列の順序6例、評価不足・不完全列挙・重複・空列・ゼロ・上限境界の7対照例を検査する。
- 原文への接続では、実際の成功、時間順の逆転、評価不足、肯定例の保持、不完全な列挙、期待の未評価を区別する。理由の支持の未評価は人数を下げず、評価エラーとして返す。
- 人数と譲歩の3対照例では、予想だけを変えても実際の人数条件が変わらないことを検査する。
- 帰属の9例では、著者・結論・引用内容・根拠集合・本文順序を区別し、人数や引用内容の基本関係が一切実行されない設定で確認する。
- 全有限列への存在量化を有限の列挙で代用する処理は拒否する。

結合した二人分の履歴を評価する検証が従来の800万ステップの上限に達したため、この検証に限り上限を3,200万ステップにした。言語の意味条件や全域的な解釈の契約は変えていない。肯定例・非該当者・評価不足を同じ全列挙で検査し、計算量を減らすために非該当者を外すことはしない。

一般文書は基本関係4・定義14、原文接続文書は基本関係224・定義365・主張15である。新しい基本記号は談話箇所を指す定数1個であり、人数・譲歩・推論の演算子は追加していない。定義11・本文主張1・1,030文字を追加し、累積正規形は55,532文字になった。
