# 点粒子の局所的な運動法則

原刊917頁のu0240–u0243は、電磁場中の電荷εを持つ点状粒子を置き、ある時点で静止している場合の三つの式 μ d²x/dt² = εX などを仮定する。x,y,zは同じ粒子の座標、μは低速時の質量である。今回は、この内容を後続の全文記述へ渡す物理的な依存群を構成する。

同じ対象の完全な局所履歴 `seob` と二階微分 `sepp` を再利用し、`ek3p/ek3q` で全対象出来事を同じ長さ・時間単位へ結ぶ。曲線の時刻成分は座標時刻と一致し、評価時刻は両側の内点である。校正は評価点だけに限らず、選んだ時間領域の全履歴へ適用する。場の領域もその局所履歴を含む。

点状担体は既存 `eisqc` の理想化、電荷は同じ対象・系・出来事・単位の符号付き非零量として `sbw2` へ結ぶ。低速慣性質量は一般関係 `eisww` で同じ状態へ帰属させる。これは機械的作用に対する運動変化の低速域の係数であり、電荷や移動時の縦横質量と同じ量ではない。現在時刻の速度を低速に制限する関係ではなく、低速域を基準にした慣性の値である。

長さ・時間・質量・力の各単位は既存の次元と正の尺度の規約で与える。力の尺度Fと他の尺度には F T² = M L を要求し、電荷と電場の積から力への換算を1に固定する。これにより、μと二階座標時刻微分の積と、εと同じ場所の電場の積を、印刷式の係数を変えずに比較できる。特定の単位名や数値尺度へ固定しない。

`ek3r` は同じ三速度関数が評価時刻で零であることを表し、`ek3w` はそれを条件に三成分の式 `ek3t` を要求する。瞬間静止と加速度零は別であり、静止から加速を始める軌道を許す。物理的設定 `ek3v` にはこの運動式、真空、無磁場、無放射を前提として入れない。

局所式だけで「直後の時間部分」の全提示を済ませない。著者がこの運動法則だけを仮定するという限定、以下「Elektron」と呼ぶ命名、前方参照、座標とμの意味説明、表示式と原文の接続、緩い加速を含む第十節見出しは次の統合で扱う。全単位の意味判断は増やさない。
