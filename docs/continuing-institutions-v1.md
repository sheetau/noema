# 構成員が交代しても続く状態

カントu0013の途切れない後見への目的について、各時点の構成員と対象者を使う記述を追加した。前版は基準時の人々を将来まで固定する読みだったが、組織が続くことには人の交代を許す読みも必要になる。両者を別の式として保持する。原文の対象語は[アカデミー版電子本文38頁](https://www.korpora.org/Kant/aa08/038.html)36行にもある。

| 定義 | 時間の条件 |
| --- | --- |
| `ric` | 一つの時点で、その時点の構成員・対象者について二段階の監督が成立する |
| `rid` | 基準時以降の履歴の全状況で`ric`が成立する |
| `rie` | `rid`に加えて、基準時以降のどの状況にもさらに後の状況がある |
| `rif` | `rie`に加えて、同じ時間尺度のどんな有理数の限界も超える将来の状況がある |
| `hzcn`・`hzco`・`hzcp` | 上記三つの時間条件を、既存の監督と文脈ごとの時間順序へ接続した内容 |

人々の範囲を各時点で選ぶため、構成員、監督される対象者、個々の担当者が交代できる。統括主体は同じ対象として保持する。各時点で構成員と対象者はともに非空でなければならず、誰もいない期間を成功と扱わない。各人が全期間に存在することや、最初の構成員が未来まで残ることは要求しない。

`rid`では、観測した期間や任意に選んだ区間を履歴の残り全体に置き換えない。選んだ短い期間では監督が続いても、その後に失われれば`rid`は偽になる。一方、履歴に最後の状況があり、そこまで監督が続く場合は真になり得る。終点の不在は`rie`で別に要求する。

終点のない順序も、数値的な無限時間とは限らない。例えば0以上1未満の有理数の範囲には最後の点がないが、1という限界を超えない。0以上の有理数の範囲はどんな有理数の限界も超える。既存の有理数検証器で、この二つの範囲について四つの性質を再検査した。状況型を数型へ暗黙に読み替えたものではない。

`rif`へ渡す比較関係は、同じ原点・単位を持つ正当な時間座標との比較として解釈する必要がある。その尺度の構成、実数の切断としての妥当性、時間順序との整合は今回完成していない。任意の真偽関数を渡せば現実の無限時間を示せる、という意味ではない。有限評価器は全有理数への量化を拒否し、少数の限界値で代用しない。

無期限の内容も、閉じたNoemaの式として引用し、前版の目的付き引受けへ渡せる。目的を記述する段階では、全有理数への量化を実行しない。目的が真であること、実現可能なこと、引受けの行為が持続を引き起こしたことは別の条件である。有限モデルで終点なしの条件が偽になることを、現実の組織の永続が不可能だという結論にしない。

検査では、基準時と後続時点の二段階の監督関係を変える16通りと、構成員・対象者の交代、空範囲、短い評価区間、履歴の欠落・循環など13対照例を調べた。旧来の固定した人々への持続と、新しい各時点の人々への持続を比較し、一方だけが成立する場合も確認した。

一般の非空の個体・状況領域を対象に、終点のない持続から履歴全体の持続が従うこと、履歴全体の持続から基準時の監督が従うこと、最後の状況があれば終点なしの条件を満たさないことを検証した。基準時だけの成立から将来全体を導く主張、将来全体の成立から終点の不在を導く主張、将来全体の成立から最初の構成員の残留を導く主張には、それぞれ反例が得られた。最後の反例は将来履歴の条件に関するもので、現実の無限の人口交代を実証したものではない。

原文接続では三つの時間的強さごとに、目的志向と規範的な効力の不成立を変える計12通りを検査した。数値的に無期限の目的を持つことも、全時間の事実を評価せずに記述できる。目的達成を実際に評価しようとした場合には、未知の監督関係や全有理数への量化を補わず拒否する。規範の全対象にわたる不成立には、前版と同じ明示した検査用の解釈を用いる。
