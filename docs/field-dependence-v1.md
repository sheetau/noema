# 磁気側の対応と、基準系による零・非零の違い

アインシュタイン1905のu0176冒頭と末尾を部分記述した。磁気側への対応は既存の外積から構成し、基準系への依存は電気側・磁気側の成分群が零か非零かという条件で限定的に扱う。「存在一般」の意味を、この数値条件だけで説明し終えたとはしない。

## 磁気側の追加項

[一般用文書](../examples/v014/field-dependence.noema)では、磁気側の一次の追加項を `−(u × E) / V` とし、Hへ加える。前段の電気側の式を再利用し、符号の反転を明示した。電気側と磁気側を交換するだけでは符号が合わない。

x方向の速度比rについて、厳密な磁気側の混合式は `Hx, β(Hy + rEz), β(Hz − rEy)` として既存の正規化変換に接続した。電気側と同様に、固定したE・Hでrを零へ近づけたときの二次の誤差条件を一次式と分けて記述する。

符号反転後の電気側の式と磁気側の式が一致することを、有理数の一般式で確認した。この対応によって、前段で確認した固定成分の誤差評価を再利用できる。ただし、全実切断についての漸近定理を機械的に証明したものではない。

## 変わることのある条件と、必ず変わる条件

有効な三成分のうち少なくとも一つが非零であるという条件と、二つの成分群の一方が零でもう一方が非零であるという条件を分けた。非零のまま大きさ・符号・向きだけが変わる場合は、後者には当たらない。

既存の変換則には、電気側が零で磁気側に横成分がある配置から、非零の電気側を得る例がある。電気側と磁気側を入れ替えた別の配置では、零だった磁気側が非零になる。この二つは異なる入力配置であり、一つの場について同時に断言していない。

許容された非零速度であっても、縦方向の成分だけを持つ場は零・非零を変えない例になる。したがって、全ての場が全ての系で存在・不在を切り替えるという主張は追加しない。論文文書では、変換則に前記二配置の証人となる速度比が存在することを、基準系への依存についての部分的な読みとして記述した。
