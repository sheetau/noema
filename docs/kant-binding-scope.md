# 外側の束縛を参照する共通規則

量化と一引数lambdaの束縛を二段までに限定していた制約を外す。既存の「直近」「一つ外側」の字形は変更せず、それより外側の参照を同じ規則の反復で表す。新しい意味の基本宣言や、変数番号ごとの字形は追加しない。

後続の[型と複数引数の規則](kant-typed-binders.md)で、以下の参照規則を全native型と複数引数lambdaへ接続した。

## 字形と読み方

`bound_shift` は、中円の左円周上に小円の中心を置き、中円の中心から右上45度へ半径線を出す形とする。小円を中円の内部に偏心させない。小円の中心に線を入れず、線との所定の間隔を保つ。既存の全30根語と文法形を含む54異体の間で識別できることを確認している。

参照は次の規則で読む。

- `bound0` は現在の範囲で直近の束縛を参照する。
- `bound1` はその一つ外側を参照する。
- `bound_shift R` は直近の束縛を検索範囲から一つ除き、残った範囲で `R` を読む。`R` は `bound1` または、さらに `bound_shift` を重ねた参照に限る。

したがって、外側への距離が2なら `bound_shift bound1`、3なら `bound_shift bound_shift bound1` となる。一回の接頭形で範囲が必ず一つ縮まり、最後の `bound1` が一つの束縛を選ぶ。閉じ記号や、見えない変数番号表は必要ない。図形には通常の前置順で接続し、この接頭形自体を引数や語彙項としては扱わない。

`bound_shift bound0` は既存の `bound1` と同じ意味を別綴りで作るため採用しない。接頭形の後に一般の式を置くこと、外側に必要な束縛がないこと、接頭形だけで終わることも読取エラーとする。

引用に入ると束縛範囲を空にし、引用内の束縛だけを数える。外へ進む接頭形を重ねても引用境界を越えられない。隣の式の束縛も持ち越さない。復元する変数名は既存のnative正規化規則に従う。入力は正規化済みの構文であり、入力名を黙って変更した後に一致を報告する方式ではない。

## 確認範囲と残る制限

[構造報告](../reports/kant-binding-scope-v1.json)には16の独立例と、前段で保存した40文のSVGの復号結果を収める。三段・五段の全位置、三引数の参照順、lambdaの外側参照、通常・順位付き引用、同名変数の内側での束縛、隣の式を確認した。SVG要素順を逆転した読取でも元の構文へ一致する。保存済み40文は再描画せず、新しい読取器で同じ構文のハッシュを回収した。辞書と旧SVGのハッシュも前段報告と照合している。

回帰検査では387件が成功し、字形数を53に固定した旧テスト1件が失敗した。その期待値を54へ更新し、該当検査の成功を確認した。処理系の変更は不要だった。構造報告の生成と修正後の検査は `project_work check` の同一プロセスで実行した。これは束縛の構造診断であり、意味モデルの全領域検証ではない。

参照規則そのものに「二段まで」という上限はなくなったが、現在の実装にはnative構文の深さ128、描画512イベント等の資源制限が残る。今回の対応対象はindividual型の量化と一引数lambdaである。他の型、複数引数lambda、文書宣言、一般の部分式の枝、行・頁の復号は別途完成させる必要がある。

見本は `output/kant-binding-scope/index.html`、同倍率の抜粋は `inspection.png`。束縛の違いを確認するための検査例であり、量化の繰返しを含むこの見本を完成版の外観とはしない。外観は未固定である。
