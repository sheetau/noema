# 因果的な対比の引用と帰属

前段の因果的な対比`hzhk`は、結果の記述を評価するため、0.14ではその全体を引用できなかった。既存の0.16試作の型付き記述構成を使い、内容を実行せず引用を作り、その同じ引用を著者・箇所・範囲・文脈へ結ぶ構成を追加した。

[後継本文](../examples/v016/kant-quoted-outcomes.noema)は、最新の0.14本文を明示的に0.16へ移したものである。既存の全宣言と15主張を保持し、二つの合成定義だけを加えた。新しい原始記号と著者の主張は追加していない。他の0.16本文枝を統合した文書ではなく、この因果的な対比を含む本文の後継である。

## 内容を実行しない構成

`hzhl`は、次の六項目の閉じた式記述を受け取り、`hzhk`へ適用する式の記述を作る。

- 対象
- 活動の種類
- 第一の結果記述
- 第二の結果記述
- 可能性を評価する基準状況
- 活動・基準状況ごとの候補関係

各入力の式記述と結果全体は層1に置く。第一・第二の結果を表す層0の記述は、その内側に保持する。これにより、対比全体を後から評価したときだけ、その内部で結果記述を評価できる。層0への暗黙の引下げ、自由変数の捕獲、未知の意味の補完は行わない。

構成時には、対象の指示先や活動種類、候補、因果、結果の内容を実行しない。同じ構文をリテラルで引用した場合との一致を確認する。内容が偽でも、解釈がまだ与えられていなくても、型の合う閉じた引用の構成自体は可能である。

## 帰属と真理の分離

`hzhm`は、`hzhl`が作った同じ記述について、指定箇所・著者・範囲・帰属文脈への提示記録があることを表す。記録関係は明示的な引数であり、その記録や著者を構文から推測しない。

可能性の評価基準と帰属の文脈は別の役割である。たとえば、ある基準からの可能性を述べる文章が、別の状況で書かれたことを表せる。帰属文脈を変えても、内側の可能性の基準を勝手に変えない。

真偽が同じ内容や、同じ対象を指す別の式も、引用された構文としては区別する。指定対象の別名を使った内容が実際には同じ真理値になる場合でも、元の引用を述べたという記録へ自動的に差し替えない。これは厳密な記述の同一性であり、任意の言い換えの同義性を判定する機能ではない。

## 検証

汎用の[引用構成文書](../examples/v016/quoted-causal-outcomes.noema)で、二つの結果の生起・因果・真理の64組合せと、帰属記録の有無を交差させた128例を検査した。累積本文でも代表例8組を検査し、計136例で、引用を明示的に評価した結果と元の対比の結果が一致した。

両文書でそれぞれ9例の対照検査を行い、著者・箇所・範囲・帰属文脈、対象の別名、結果の交換、同じ真偽の別記述を区別した。引用の構成と帰属だけを調べる際は、内容に関わる全解釈を実行すると失敗する設定でも通過した。明示的な内容評価では未知の因果・結果を拒否し、帰属評価では未知の記録を別に拒否する。

型や引用の層の誤り4種と、旧入口からの暗黙の0.16採用も拒否する。既存の短絡診断を用いるが、引用の構成・帰属と、肯否二つの明示的評価は通常の評価順・キャッシュなしでも確認した。二文書の通常表記・短縮表記・固有文字の往復、専用CLI解析、親文書の保持と意味規約の型の対応も確認する。

## 残る課題

引用できる構成ができたことと、原文の具体的な概念を充足して著者の主張を記述したことは別である。革命・専制・圧迫・改革の説明、認識的な留保と候補範囲、提示行為と具体的な著者帰属は未完である。今回も新たな原文範囲や意味確認済み区間は加算しない。

0.16は既存の試作版であり、今回これを標準入口へ採用したわけではない。実行時の層検査と資源上限は保持するが、任意の高階関数の効果を実行前に検査する仕組みや、無矛盾性・停止性の一般証明まで完成したとはしない。[意味規約](../data/quoted-outcomes-basis-v1.json)は、継承した規約と新しい二定義を分けて記録している。
