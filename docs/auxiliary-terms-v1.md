# 元の条件を変えずに導入する補助項

アインシュタイン1905のu0176中間へ、電動力の補助的な役割と、その導入理由の部分記述を追加した。数学的な構成の性質と、著者がその構成を導入する理由を分ける。

## 状態の保存と追加値の一意性

[一般用文書](../examples/v014/auxiliary-terms.noema)では、元の状態が許容されることと、追加値を持つ許容された拡張が存在することを同値とする。これにより、補助項の導入で元の許容状態を排除したり、不許可の状態を新たに許可したりしない。

その上で、同じ元の状態には追加値が一つだけ対応することを要求する。許容状態を保存していても、追加値が複数なら新しい自由度が残る。逆に、別々の元の状態が同じ追加値を持つことは問題にしない。元の許容状態が空なら両条件が成立する場合があるため、これを元の理論の整合性や実現の証明とは扱わない。

既存の全域関数で計算した値への等値だけを追加すれば、この二条件が成立する。[一階論理の検証器](first-order-proofs.md)で実際のNoemaの定義を展開し、任意の空でない個体領域についてこの性質を確認した。有限例だけに依存する検査ではない。

## 電動力の追加項への適用

[論文文書](../examples/v014/einstein-auxiliary-terms.noema)では、既存の `(u × H) / V` の三成分に一致することを追加値の定義関係とした。有効な入力ごとにその値が存在し、空間三成分について一意であるという条件を記述する。関数の実装が同一であることや、空間成分以外の一致は要求しない。

有理数の成分では、非零の除数に対する値の一意性と、逆数による構成を補助検査した。実数の下側切断については、演算の閉性と一般の存在証明が別に必要である。個体領域の一階論理の結果を、そのまま実数ベクトルの証明へ読み替えない。

この構成は、追加項を独立に自由な値として与えないという意味で、原文の補助的な役割の一部を表す。ただし、理論全体への保存的な拡張や、原文の「補助概念としてのみ」という理論上・存在論上の役割全体との意味一致は未確認である。

## 導入理由を述べること

基準系への依存の内容と補助項の性質がともに成立しても、それだけで前者が後者の導入理由になるとはしない。著者が特定の理由の記述を、特定の型付き構成の導入理由として採用する関係を別に保持する。理由・構成・著者・適用範囲・文脈を同じ関係へ結ぶ。

構成と同じ値を返す別名を定義しても、その記述を説明の中で自動的に置き換えない。式の値と、説明で取り上げた式の記述を区別する。引用された構成を実行したことや、歴史的・心理的な因果関係を証明したことにも扱わない。
