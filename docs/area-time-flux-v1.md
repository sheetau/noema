# 同じ面積と時間で、エネルギーと仕事を正規化する

アインシュタイン1905年論文u0222の、鏡の単位面積・単位時間に入るエネルギー、出るエネルギー、光圧の仕事へ、面積と時間を明示した条件を接続した。前版の入出と仕事の値は単位面積・単位時間あたりの値だった。今回は、それらと総量を区別する。

## 共通の面積と時間

面積をS、時間の長さをT、入出の単位面積・単位時間あたりの値をI、O、同じ規約の仕事率をWとする。一様・定常な比較設定で、次の正規化を使う。

```text
S > 0, T > 0
E_in  = S T I
E_out = S T O
E_work = S T W
```

`sela`はこの条件を有理数で、`seld`は実切断で表す。入出エネルギーは非負だが、仕事は符号付きである。鏡から光へエネルギーが移る場合の負の仕事や、振幅零の場合のエネルギー零を排除しない。面積と時間のどちらも正とし、零で割る正規化や、負の時間を認めない。

同じSとTを使うと、`W=I−O`と`E_work=E_in−E_out`を対応させられる。`selb`・`sele`が総量の収支を表す。`selc`・`self`は前版の反射・入出・圧力による仕事率に正規化を結ぶが、総量の収支を前提に加えて結論を先取りしない。

例えばS=2、T=3、I=1/3、O=1/12、W=1/4なら、E_in=2、E_out=1/2、E_work=3/2となる。総量を率と同じ数にしたり、時間の因子を落としたりすると、別の値になる。

## 五つの記録を結ぶ

`selg`は五つの値の記録を、同じ交換場面・鏡・面部分・時間区間・入射光・出射光・基準系・観測者・文脈へ結ぶ。面積の対象は面部分、時間の対象は区間、入出エネルギーの対象はそれぞれの光、仕事の対象は鏡である。出来事として参照する交換場面と、観測者が静止する基準系を共有する。

面積・時間・エネルギーは異なる量の種類として保持する。仕事の総量はエネルギーと同じ種類を使うが、五記録の単位と正の尺度は別々でもよい。`selh`は各値を基準尺度へ換算してから、同じS、Tによる正規化へ渡す。数値が合っていても、別の面・時間区間・観測者・系の記録は転用しない。

`seli`は前版のπの積分条件を要求し、密度の係数を8πにして接続する。新しい原始概念は追加していない。交換設定への帰属と一様・定常な条件は、型付きの関係引数`exchange`で明示する。この関係や記録が未知なら、値から推測して補わない。

## 検証

有理数の代数検査9件で、正規化の下での収支の対応、率の一意性、面積・時間の正値条件、非単位の面積と時間、負の仕事を確認した。総量と率の同一視、時間因子の省略という誤った主張2件には反例がある。

有限検査では、3速度、2振幅、3組の面積と時間、2組の単位尺度による36設定を検査した。各記録の参照先・量の種類・系・出来事・単位・文脈・観測者を取り違えた例を含む67対照例も検査した。全文草案と独立抽出文書の評価は一致する。

速度零では、面積と時間を明示しても仕事だけから圧力は決まらない。異なる二つの非負圧力で同じ仕事の条件が成立することを確認した。この未決定性を正規化で消していない。

実数の有限検査は登録した有理数切断を使い、πの積分条件を検査用の解釈に置き換える。そこで使う数値3はπの計算値ではない。全実切断の演算法則や積分、物理的なエネルギー原理の証明とは区別する。

## 残る意味

原文が五つの実測を行ったという主張は追加していない。今回の記録は、原文の量の指定を検査するための仮定上の設定である。非一様・非定常な場の積分を、一般にS*T倍へ置き換えることも認めない。

面積測度、区間の端点と時計、装置・誤差・単位の実現、鏡と光の物理的な帰属、一様性の判定、完全反射の境界条件は未完である。圧力を測る方法、力と変位による仕事の一般定義、エネルギー原理による正当化、著者の導出の談話も残る。原文全文の意味一致は確認していない。

9定義を追加し、原始概念・局所参照・著者主張は追加していない。全文草案は298,819代用文字で、前版から3,893文字増えた。有理数の文書は6,334文字、実数版の独立抽出文書は9,654文字である。定義を含む長さで、一文の翻訳の圧縮率ではない。
