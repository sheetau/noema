# 横棒の測定長とφの決定

アインシュタイン§3の `u0097`〜`u0108` を部分記述した。移動系のη軸上にある棒の両端、静止系での同時測定、速度反転による長さの一致、先行する相反条件を接続し、正の枝を明示したうえでφ=1と最終の四座標式を記述する。

```text
運動系の両端: (ξ,η,ζ) = (0,0,0), (0,l,0)
静止系の同じ時刻t:
  η=l側: (x,y,z) = (v*t,l/φ(v),0)
  η=0側: (x,y,z) = (v*t,0,0)
正の測定長: L(v)=l/φ(v)
```

本文の座標1はη=l側、座標2はη=0側に対応する。端点を提示した順序だけで番号を交換しない。`srw` は同じ端点出来事の両系の記録へ既存の四式を適用する。`sry` が静止系の端点式、`srz` が二組の式と静止系での同時性を表す。両端の時刻が異なる場合、各端点で式が合っていても測定の組としては受理しない。

`ssa` は同じ棒、異なる両端と出来事、両系の測定記録、η軸上の配置、運動との直交、速度と単位を結ぶ。`ssb` はさらに正の測定長を、符号付きのy差、l/φ、二地点の距離、棒の長さの呼称へ接続する。記録の数値だけで別の棒や別の測定を代用できない。座標測定と物理的な距離・配置の関係は、検査では外部解釈を与えている。

φを初めから正として割ることはしない。`srx` はl/φを `(l*φ)/φ²` として表し、非零の負のφでも符号を保持する。負のφではη=l側の静止系y座標が負になるため、その符号付き差を正の測定長とする今回の規約とは一致しない。この規約は正の枝を選ぶ追加解釈として明示した。絶対距離l/|φ|だけを使えば、φ=−1は相反条件と反転対称性を満たしたまま残り得る。

`ssc` は同じ速さを持つ許容設定で測定長が等しいという一般形、`ssd` は同じ棒・固有長・単位・横方向の運動を持つ比較設定である。向きは設定に残し、速さの比較には符号付き速度の二乗を使う。`ssi` は正負速度の対象設定をこの範囲に結ぶ。方向と向きによらないという物理的な対称性を、端点の代数だけから導いたとは扱わない。

`ssh` は同じ棒を正負速度で測る二設定を表す。各設定に固有の出来事と場所を使い、正速度の出来事を逆速度の測定へ流用しない。両測定と対称性から長さの一致 `ssj`、同じ正の固有長との関係から係数の一致 `ssk` へ進む。`sst` は測定条件の下でこの二つの一致が同値であることを表し、本文の「または」による書換えを双方向に保持する。これに先行するφ(v)φ(−v)=1と正の枝を合わせた `ssm` から、対象速度でのφ(v)=φ(−v)=1を表す `ssl` を得る。

有理数の検査では、正の等しい測定長から係数が正かつ等しくなること、相反条件を加えると両係数が1になることを確認した。相反条件だけなら(2,1/2)、正で等しいだけなら(2,2)、符号条件がなければ(−1,−1)が残る。零の棒では係数を識別できない反例も検査した。

最終形の `ssn` は係数1の四式、`sso` は対象範囲の全記録対でその式と出来事の対応が過不足なく一致する内容である。先行する未知関数 `spc` の定義は変更せず、φ=1という条件の下で書き換える。

```text
τ = β*(t-v*x/V²)
ξ = β*(x-v*t)
η = y
ζ = z
β = 1/√(1-(v/V)²)
```

φの「意味を問う」箇所には、その関数の物理的な解釈を問う関係を使った。長さの式によってその意味を示すことと、数値を計算し終えたことは分けている。本文の対称性を明らかとする評価、長さから係数への推論、正の枝の追加解釈、最終式への書換えも別の記述として保持した。
