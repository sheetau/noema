# 約束の期限・実現・解除・不履行

起点より後から期限までに少なくとも一度行為が成立する、という期限付き要求を14定義で構成した。[本文](../examples/v016/shared-deadlines-v1.noema)は、既存の時間順序・規範の根拠・約束の8定義も含む。[意味規約](../data/shared-deadlines-basis-v1.json)に各引数と解釈上の範囲を固定し、新しい基本宣言は追加していない。

## 期限と評価点

時間の枠には、同じ履歴、厳密な時間順序、起点、期限、評価点を与える。起点は期限より前で、評価点は起点以後とする。行為が起点より後、期限以下、評価点以下で成立した場合に、期限内に実現したと判定する。起点で既に成立していた状態だけでは満たさず、期限時点の実現は含む。

| 定義 | 条件 |
| --- | --- |
| `deadlinevalid` / `deadlinewindow` | 時間枠の妥当性と、起点を除き期限・評価点までを含む範囲 |
| `deadlineobserved` / `deadlineachieved` | 同じ本人の行為内容が、その範囲内の少なくとも一時点で成立する |
| `deadlineclause` / `deadlinedescription` | 同じ行為と時間枠から、規範が要求する期限条件の関数・記述を構成する |
| `deadlinerequired` | 同じ出所・本人・役割・活動・期限条件について、起点に肯定的要求がある |
| `deadlinefreedat` / `deadlinereleased` | 指定時点の権限と解除行為の証人、または評価点までにその証人が存在すること |
| `deadlinefulfilled` | 起点の要求があり、期限内の実現が評価点までに成立する |
| `deadlinepending` | 期限以下の評価点で、調査完了を明示した上で、まだ実現も解除もない |
| `deadlinebreached` | 期限より後の評価点で、調査完了を明示した上で、期限までに実現も有効な解除もなかった |
| `deadlinelate` | 期限内の不実現を調査完了付きで確認し、期限後から評価点までに同じ行為が実現する |
| `promisedeadline` | 同じ話者・行為記述の約束と、同じ起点の期限付き要求を結ぶ |

履行・解除・不履行・遅い実現は、排他的な四分類にはしていない。期限後に行為を実現したり解除したりしても、期限までに実現も解除もなかったという履歴は残る。期限時点での解除は期限内に数える。この規約を全ての制度へ適用する規則とはしない。

## 同じ行為を約束と規範へ結ぶ

既存の約束は一個体を受け取る行為内容の記述を扱い、規範は本人と対象活動の二個体を受け取る記述を扱う。この型の差を、期限条件を構成する関数で接続した。構成後の内容は対象活動の同一性も要求するため、別の活動に同じ真偽を与えて代用することはできない。

規範用の記述は、引用した`deadlineclause`へ、同じ行為・履歴・順序・起点・期限・活動の閉じた記述を適用して作る。構成時に行為内容は実行しない。根拠となる規範は、既存の`normwitness`と`groundedrule`で認定主体・適用範囲・理由を結び、起点の要求記録を保持する。約束を述べただけで要求の有効性を補うことはしない。

解除には、同じ対象についての権限と、その権限主体が理由を持って解除したという二つの関係を与える。これらは新しい明示的な意味入力である。会話の採用記録から発言を撤回したことを、要求の解除とは扱わない。今回の解除時点は解除行為と効力が生じる同じ時点であり、遡及的な免責や再有効化は含めない。

## 観測不足と不実現

否定的な判断には、対象期間の実現・解除について関連記録を尽くしたという明示を要求する。記録の標本で実現が見つからないことだけでは、この条件を満たさない。調査完了が偽で`deadlinebreached`が成立しない場合も、実際に履行したことや不履行がなかったことの証明にはならない。定義に含めた認定条件の不足として読む。

未知の解釈は、調査完了がないこととも異なる。有限評価器は論理演算を短絡しないため、時間条件の外の時点を含め、実行に必要な解釈が未知なら評価を拒否する。未知の将来内容を偽へ置換して「まだ実現していない」と判定する機能は提供していない。時間履歴そのものを、観測できた点だけへ縮めることもしない。

## 接続例と検証

[接続例](../examples/v016/late-fulfillment-and-release-v1.noema)は、起点・中間・期限・期限後の四時点を持つ。本人は期限後に行為を実現し、同じ時点に要求が解除される。中間と期限時点では猶予中、期限後には解除済みかつ遅い実現が成立するが、期限不履行も残る。行為が今成立することと、期限条件を満たしたことを別々に評価する。

時間順序・行為内容・約束・規範の認定・解除は、本文のNative定義で記述する。外部モデルは個体名と時点名だけを解釈する。実際の制度や人物についての判断ではなく、明示した規約を検査する例である。

[検証報告](../reports/shared-deadlines-v1.json)には、四時点における実現の有無と解除の有無、四つの評価点を組み合わせた1,024モデルを記録する。各モデルで調査完了の有無を両方検査する。時間枠の8対照と、根拠・権限・解除・約束の54単枠束縛診断も含む。束縛診断では規範と理由等の証人を固定しており、全引数領域の列挙による証明とは区別する。

今回の読みは、肯定的な一回の期限要求である。持続・反復・複数条項の全履行や連続時間全域の証明を同時に完了したことにはしない。新14語の円文字接続、知識と情報構造、一般的同義・多義、学習と第三者読解、二作品全体の新書式化は引き続き扱う。
