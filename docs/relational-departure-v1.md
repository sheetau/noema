# 同じ相手との関係から離れる変化

前段の因果的な対比では、二つの結果が未充足の記述引数として残っていた。今回は第一の結果へ、同じ対象が指定された相手との関係から離れるという変化の構成を渡した。支配・圧迫の関係そのものの意味はまだ未充足だが、「離れる」を単なる結果ラベルにはしていない。

[後継本文](../examples/v016/kant-relational-departure.noema)に五つの合成定義を加え、既存15主張と全宣言を保持した。新しい原始記号と著者の主張は追加していない。0.16の既存の記述構成機能を使う。

## 関係の前後と、その対象に作用する過程

`rqr`は、同じ相手・同じ対象の関係が、評価済みの開始点では成立し、終了点では成立しないことを要求する。既存の`tg`で同じ順序付き履歴の前後を結ぶ変化過程を確認し、その同じ対象がその過程の影響を受けることも要求する。

以前から関係がなかった場合、前後で別人の関係を調べた場合、無関係な変化過程が生じた場合は成立しない。終了点の評価が不明なことも、関係がなくなった証拠にはしない。前後二点の構成なので、途中の全経過や唯一の終了時点、離脱後の恒久的な状態を補わない。

`rqs`は、これに加えて終了点で指定範囲の全相手との関係が評価済みかつ不成立であるという強い診断を表す。以前の相手との関係を終えて別の相手へ移った場合、`rqr`は成立しても`rqs`は成立しない。例えば、ある供給者との取引を終えることから、全ての供給者との取引を終えたとは言えない。

比較する相手の範囲は明示的に与える。特定の相手から離れたことを、その種類の関係が世界全体で消滅したことへ強めない。逆に、全相手との関係の不在を調べる際に、不利な相手を範囲から外してよいという規則もない。

## 因果的な結果への接続

`hzhn`は、対象と評価する終了状況について、`rqr`を満たす相手・過程・開始点が存在する内容を作る。`hzho`は、同じ関係・相手範囲・履歴・評価・過程接続の閉じた式記述から、この内容の記述を組み立てる。構成だけでは関係や変化を実行しない。

`hzhp`は、前段の対比`hzhk`の第一の結果を、この離脱の記述に固定して引用する。因果記録が結果として参照する記述と、候補状況で実行する離脱内容は同じ構文になる。因果記録だけがあっても、実際に対応する変化過程や前後の関係がなければ、対比の第一側は成立しない。

離脱を生じさせる活動と、対象が変化する過程は別の役割としてよい。前者と結果の因果関係は`g3`、後者の対象・前後は`rqr`で結ぶ。原因と変化過程を無条件に同じ出来事へ統合しない。また、離脱が成立しても、同じ種類の活動で第二の結果を生む候補があれば、元の対比全体は不成立になる。

原文の`Abfall`に向けた部分読解であり、その語を完全な制度廃止や後継者の不在と同義と確定したものではない。今回の第一側には`rqs`の強い条件を付けていない。支配者の交替を排除する読みを採る場合は、その条件を別に明示する必要がある。
