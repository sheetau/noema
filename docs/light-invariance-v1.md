# 合成しても変わらない値と光速度

アインシュタイン1905年論文§5のu0145〜u0146を部分記述した。光速未満の速度との合成で光速度が変わらないという主張と、その場合の式を接続した。

```text
0 ≤ w < V,  V > 0
U = (V+w)/(1+w/V) = V
```

M0273の分母は、保存済み原刊906頁との照合で確認した大文字Vを使う。電子テキストのスナップショットには小文字vがあるが、そのファイルは変更していない。対応表には元の数式のハッシュ、訂正後のハッシュ、訂正記録の識別子を保存した。たとえばV=5、w=1で、分母へ別のv=3を入れると9/2となり、正しい結果5とは異なる。

「変わらない」は、一引数の操作を適用した出力が元の有効な値と等しいという不動点の関係で表した。この定義は速度に限らない。恒等操作の3、二乗操作の0が不動点であり、1を加える操作の3と二乗操作の3は不動点でないことを検査した。

光速度の主張では、任意の0≤w<Vについて、既存の合成式で構成した結果が式の定義域を満たし、Vが不動点となることを量化した。有限の速度一覧に置き換えていない。全実切断への量化を有限解釈器が拒否することも確認した。適用範囲外では含意が真になるが、それを光速度不変の物理的な実例には数えない。

代数上の式の領域と原文に採用した適用範囲は分けている。V>0かつw≠−Vなら、この商の値はVになる。wが負の場合や光速を超える場合でも代数的に成立し得るが、そのために本文の0≤w<Vという読みを拡張しない。w=−Vでは分母が0になるので、U=Vを別に指定しても式は成立しない。

一方の入力へVを代入する記述は、座標系速度zb7=Vという断言ではない。先行する一次元合成式の引数を特殊化する。二引数を交換しても同じ関係となることは有理数の補助検査で確認したが、光速度で動く座標系や無限大のローレンツ係数を物理的に許容したことにはしない。

数式の等式、既存の結果Uと物理的な速度との接続、著者が述べた帰結は別に保持する。一般主張の前提と結論を逆にする、数式の内容を一般主張へ取り替える、著者・文脈・仮定範囲を取り替える検査で、それぞれの違いを確認した。物理的な速度との接続は、明示したモデルの条件を使う検査であり、測定や微分の全理論を実装したものではない。

検査記録には有理数の代数9件、式と境界13例、速度以外の不動点4例、本文との接続10例、帰属6例を保存した。有理数の補助証明と実切断の具体例の検査は、実切断全域の体・順序の法則の証明とは区別する。
