# 評価範囲を明示した、省略のない公的提示

カントu0016の「率直な批判」を検討するため、明示した評価範囲の判断を省略せずに示す条件をNoemaで記述した。肯定評価と否定評価を含む一つの提示について、本人・話題・判断・基準の記述・肯否を結び付ける。[定義文書](../examples/v016/candid-assessments.noema)と[二項目の作例](../examples/v016/candid-assessments-example.noema)を保存した。

これは率直さや誠実さの必要十分条件ではない。話者が開示範囲を恣意的に選んでいないこと、実際の考えをすべて調べたこと、誤導の意図がないことは保証しない。カント本文の許可対象へは未接続であり、原文対応範囲や意味確認済み区間数は増やさない。

## 基準の充足と本人の評価

基準は、話題から状況ごとの真偽を返すNoema関数である。肯否が真なら基準が成立すると述べ、偽ならその基準が成立しないと述べる。同じ基準の記述と肯否から発話を構成するため、本人が判断した基準や比較方向と異なる内容を示したことにはならない。

本人の評価は、同じ人・判断・話題・基準の記述・肯否・文脈に結び付ける。その判断の候補状況が非空で、全候補で指定の評価が成立することを要求する。現在の状況で基準が成立するかは別に評価する。同じ定義を持つ別名の基準についての判断も、自動では流用しない。

| 定義 | 条件 |
| --- | --- |
| `rsa`、`rsb` | 同じ基準と肯否を述べる発話と、その閉じた記述を作る。 |
| `rsc` | 同じ判断について、本人・対象・基準・肯否・非空の判断候補を結ぶ。 |
| `rsd` | 指定した判断記録が有限列に含まれる。 |
| `rse` | 記録列が非空で、列の項目と明示した範囲が一致する。 |
| `rsf` | 範囲内の全項目で、本人の評価と同じ内容の公的な自己提示が成立する。 |
| `rsg` | `rsf` の中に少なくとも一つ否定評価がある。 |

否定を含めば常に批判になるわけではない。基準が「満たすべき要件の充足」を表す場合、その不充足を述べる `rsg` を批判的な提示の作例として使える。基準が何を表すかは別途説明する必要がある。肯定評価だけの提示や、肯否が混在する提示は `rsf` で区別せず記述できる。

## 記録列と開示範囲

明示した範囲に二つの判断があるなら、列に一つだけ載せても `rse` は成立しない。列に範囲外の判断を混ぜた場合も不成立となる。これは記録列と範囲指定の整合条件であり、範囲外の発言そのものを禁止してはいない。実際の提示が、列にない別の内容も含むことを排除する条件は加えていない。

空の範囲と空の列から「省略なく示した」とは判定しない。順序と重複はNoemaの列として保存するが、今回の全項目検査では評価に重みを付けない。順序を変えたり同じ項目を繰り返したりしても、肯否の判定や開示の成立条件は変わらない。

全項目を同じ人・提示行為・役割・宛先・文脈へ結ぶ。一つの文書や講演に複数の評価を含める読みであり、別々の発言の一部を無条件に寄せ集めない。公的提示には既存の [`hzb4`](speech-principals-v1.md) を再利用し、その役割・公衆・伝達関係の基礎説明に関する限界も引き継ぐ。

## 作例と検査

定義文書は26宣言で、19宣言を既存文書から保持し、7定義を加えた。ライブラリに新しい原始関係は追加していない。52宣言・3質問の作例には、二つの判断記録と評価基準を用意した。検査用の解釈では、一つ目を肯定、二つ目を否定して公に示すが、現在は二つ目の基準も成立している。この例の結果は「全項目を提示した」「否定評価を含む」「現在は二つ目の基準が成立する」の三つとも真になる。否定評価の提示から、その内容の真理を推定しないためである。

98テストが通過した。判断候補での評価・現在の真偽・二項目の伝達の64組合せに加え、項目の欠落、範囲外の追加、空の列、順序・重複、肯否混合、本人の判断の不在、空の候補を検査した。別人・別の話題・別名の基準・異なる肯否・提示行為・発話の帰属先を取り違える場合も区別した。

未知の解釈は偽で補わず拒否する。発話記述の構成だけでは基準を実行せず、キャッシュあり・なしの評価結果も一致した。長形式・短縮形式・固有文字の往復、検査記録の再現、両文書のCLI解析、作例のSVGのXML検査が通過した。SVGの目視検査は行っていない。

