# 総称と質的な程度の共有定義

通常事例に基づく総称と、比較尺度に基づく程度を、作品固有の対象から切り離して記述する。共有モジュールは23定義で、既存10定義を本体・型・語義ごと再利用し、13定義を構成した。基本宣言は追加していない。[Native本文](../examples/v016/shared-generality-v1.noema)と[型・役割・解釈の規約](../data/shared-generality-basis-v1.json)を正本とする。

## 通常の事例と例外

「鳥は飛ぶ」の読みの一つとして、比較対象にした鳥の事例のうち、通常性で劣後しない事例すべてが飛ぶことを要求する。例示では飛ぶ事例aを通常、飛ばない事例bを例外として与える。この場合、総称は成立するが「全ての事例が飛ぶ」は成立しない。順位は解釈入力であり、飛ぶ事例を成功例だから優先してよいという規則ではない。

| 定義 | 区別する内容 |
| --- | --- |
| normalcase | 指定範囲に属し、範囲内に優先される事例がない |
| normalorder | 範囲内の非反射性・推移性に加え、各事例が通常事例か通常事例に劣後すること |
| casegeneric | 上の順序条件と非空の通常事例を要求し、通常事例すべてで応答が成立する |
| kindwisegeneric | 二種類の各範囲で別々に総称が成立する。範囲の重なりは許す |
| caseuniversal | 範囲内すべてで応答が成立する。空範囲でも真になる |
| caseexception | 指定事例が範囲内にあり、応答を満たさない |

最初の四定義は、既存の[二種類への一般化](../examples/v016/conjoined-kinds.noema)のr2be・r2bf・r2bg・r2faを改名したもの。比較不能な通常反例も検査し、二種類をまとめた際に一方の反例が全て隠れる問題を避ける。非通常の事例には例外を許すため、多数決とは一致しない。仮定の事例も扱え、総称だけから現在の実例の存在は導かない。

## 比較と判定基準

尺度値には個体型を使う。数値、等間隔、確率である必要はない。scaleorderedは非空の尺度に厳密全順序を要求するが、最低値や最高値の存在は要求しない。異なる尺度・比較集団・時点を比べる場合は、今回使う尺度と割当の意味を先に固定する。

形容詞の判定では、明確な肯定域と明確な否定域を別々に渡す。standardsvalidは肯定域が上方、否定域が下方に閉じ、両域が重ならないことを検査する。どちらにも属さない既知の値をdegreeborderlineで表す。これは値や基準を知らないこととは異なり、未知の入力は評価を拒否する。

| 定義 | 判定 |
| --- | --- |
| degreepositive / degreenegative | 妥当な基準の肯定域／否定域に、対象の尺度値が入る |
| degreeborderline | 尺度内の既知の値が、妥当な二つの判定域のいずれにも入らない |
| degreemore / degreeequal / degreenotless | 同じ尺度と割当で、左の値が右より高い／同じ／低くない |
| degreeenough | 尺度内の値が、別に明示した上方に閉じた目的基準を満たす |

例えば低・中・高の三値で、肯定域を高、否定域を低とすると、中は境界にある。それでも中は低より高い。目的基準が中以上なら、その目的に十分という判定も成立する。「高い」「より高い」「十分高い」を同じ条件にしない。目的基準を満たすことだけから、実際の目的達成は導かない。

空の肯定域・否定域も許す。妥当性は判定域の存在を強制する条件ではない。尺度が不正、値が尺度外、判定域が重なる場合には判定が成立しないため、判定の偽だけから対象が否定域にあると推論してはいけない。二値の真偽上で明示的な判定域を構成しており、新しい多値論理を実装したものではない。

## 様相の程度との接続

[既存の質的な様相尺度](graded-modality-v1.md)の六定義も共有する。boundedscale、modaldegree、neartop、modalmore、conditionednear、comparedconditionednearは、順にrqsq〜rqsvの本体と語義を保持する。不可能・必然には両端を対応させ、条件で候補を制限した後の「最高値に近いが端点ではない」判断を区別する。一般の程度尺度に、この様相用の両端を強制しない。

## 検証と残る範囲

[検証報告](../reports/shared-generality-v1.json)では、二事例上の総称256モデル・種類別1024モデル、三値上の順序512モデル、基準64モデル・判定域64モデル・比較36モデル、様相の両端48モデルを調べる。順序512通りのうち全順序は六つ、最低・最高値も固定すると一つになる。共有名へ接続した様相の六定義は、既存27対照の期待値と照合する。

[組合せ例](../examples/v016/generic-and-degree-readings-v1.noema)の最初の三問は通常事例と例外、後続七問は低・中・高の割当と上記の判定域を使う。検査上のa・b・cは役割ごとの入力値で、鳥の通常性と人の身長の関係を主張しない。役割ごとに異なる関数へ渡して検査する。

これらは有限モデルの検証であり、全自然言語の総称・形容詞の網羅や無限領域の証明ではない。比較範囲、通常性、文脈の基準を選ぶ根拠は明示的な解釈に残る。円文字辞書第6版は変更せず、この23定義の共有綴りと可視本文への接続を次に進める。二作品の採用した読みと判断は保持する。
