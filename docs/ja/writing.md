# 円文字

[English](../guide/writing.md) · **日本語** · [文書一覧](README.md)

採用字体は円・円弧・線・ドットで型付きのNoema構造を表します。幾何形状が語彙・文法情報を担います。描画規則に合う図でも、登録字形・接続・構文に従わなければ有効な文にはなりません。

固定した字体はconcept2 v7で、文書・共有規則を含む採用記録は[writing-freeze-v2.json](../../data/writing-freeze-v2.json)です。このページは共通規則の説明であり、固定版の規範記録は[円文字仕様の原本](../circle-writing-v2.md)に保存します。登録字形は `scripts.concept2_writing.WritingReader().forms` から取得できます。

## 意味から図形へ、図形から構文へ

生成は、型検査済み構文、範囲内の共有計画、登録字形、接続、改行の順です。描画前に共有計画の展開が元の構文と一致することを確認します。任意の形を描いた後に意味を割り当てる方式ではありません。

復号では可視の円・円弧・線・ドットから字形と接続を認識し、語と構文を戻し、共有を展開して型と束縛を検査します。入力はSVGの幾何と公開辞書であり、隠したAST、期待トークン列、文番号、SVGの識別属性を必要としません。空辞書から宣言を順に読むこともできます。

対象は規則に従うベクトル表記です。手書き認識、写真、ラスタOCRは対象外です。テキスト・JSONの往復や旧フォントの描画は、この可視図形復号の証拠にはなりません。

## 幾何と線長

小円半径をSとし、各半径と段の間隔を次のように定めます。

| 要素 | 大きさ |
| --- | --- |
| 中円M | `(1 + √2)S` |
| 大円L | `(1 + 2√2)S` |
| 第4円F | `(1 + 3√2)S` |
| 上下段の間隔P | 中央段から `(2 + √2)S` |
| ドット半径 | `(√2 − 1)S` |

拡大縮小でも比率を保ちます。大円・第4円の中心は中央段です。内包は同心とし、直交交差は小中・小大・中大の組で中心間距離を `√(r² + R²)` とします。偏心した完全内包は禁止です。継承した接触は、同じ縦列の小中円と、縦横それぞれPずれた中円同士に限ります。小円は完円とし、直線は円周で止めて内部に入れません。

中大円の交差では、中円内の大円弧を常に残します。重なり側90度のうち中円外の二つの翼状部分は、一括して残すか消します。その90度の外では45度ごとに選び、少なくとも45度を残します。中円内だけを抜く形、中円内だけに大円弧を残す形は不可です。小大円では、小円内の大円弧を抜く形を使えます。

その他の中大円弧は45度単位とし、直交交点での切断は例外です。第4円は上下の禁止区間を描きません。円に属する方向線・自由端は中心からF以内、45度方向なら各軸 `F/√2` 以内で止めます。別の円への接続線には、次の接続長規則を使います。

左右への接続では、その側の半円内に正の長さの円弧があるL・Mのうち、大きい方を選びます。弧が欠けていても、その円の**完円周端**から半径幅Mを測ります。どちらも該当しなければ実接点を使います。半円境界の一点は含めず、第4円は繰り上げの対象外です。

大円の斜め終端から上下の小円へ移るときは、大円の左右完円端から小円中心までの水平距離をMとします。通常の小円間の水平接続は円周間でMです。参照順の幹では小円中心間を `2S + M` とし、各枝先を次の幹小円と同じ縦列へ揃えます。

## 読順と引数

行は上から下、各行は左から右へ読みます。新しい文は2Mの間隔で区別します。継続する文は行末・行頭の半径幅の端と段の一致を使います。字形内では折らず、字形間で折り、字句・参照環境を保持します。

語は公開した30根の列です。13種の合字と2種の向きの異形を根列へ展開します。語の終端で、語の終わりと綴りの延長を区別します。宣言名と別綴り登録には常に終端を置き、文書の行番号を語名にはしません。

一律の文頭記号はありません。主張は式から始められ、質問・指令・仮定にはそれぞれの構文があります。演算子は固定の引数数、呼出しは宣言済みの型と個数を使います。可変長列には終端を置き、円を含む区切りで値・引用・参照の群とその終わりを区別します。

引数順は構文順です。異なる2〜3段の参照が上・中・下の順なら、複数小円の選択形を使えます。別の順や同じ段の再使用は採用したv4／v7の幹を使います。方向付き選択形は中心線が指す小円から時計回りに読みます。合流では枝を上から下へ読み、各枝の円弧が参照先を示します。合流は同一性や論理和を意味しません。4個以上の引数は通常の列と群区切りで表せます。

## 束縛、共有、ドット

束縛は型・範囲・深さ・位置を保持します。scope-hopで外側へ移動し、範囲を抜けると外側の環境へ戻ります。引用は別の束縛・参照環境を作り、仮定の下の兄弟文には互いの局所省略を持ち越しません。

共有は同じ構文かつ同じ束縛先にだけ適用します。局所値参照8組、語参照8組、段参照3組、引用テンプレート3組があります。語の省略と値の再使用は別であり、引用テンプレートを共有しても異なる内容を同一化しません。

既定の生成器は、範囲内の繰り返しで短くなる表記を選びます。変数があっても束縛先が同じなら共有でき、内側の束縛・引用を越えて持ち出しません。使われなくなった共有定義は除きます。字形頻度は文書とこの選択に依存し、許可された形が均等に出る必要はありません。

反復記法は連続する2〜5回を表し、長い列は組み合わせます。円なし縦線の長さS・M・L・Fで回数を区別します。小円のみの根は対象外で、意図的に省略しない連続表記も許容します。

ドットは範囲内の離れた出現を対にできます。中円の45度区間8個で256識別を作ります。通常は左右の中円弧を持ち、完円は不要です。中円弧がない一形だけ大円へ進み、その対応先は裸のドットにもできます。外側の円と接続用小円は識別を変えません。ドットへ線をつながず、小円へ内包しません。同じ識別を順に対にし、未対応や引用境界越えを拒否します。ドットは省略の選択肢であり、必須の装飾や万能の参照記号ではありません。

長い2〜3引数の枝は局所組立て範囲で扱えます。元の引数順で異なる段へ値を定義し、定義群を閉じ、段参照を呼出しへ渡します。値は入れ子の範囲・束縛・引用を含められます。最後の幹・選択形は一字形として残り、終了時に外側の参照環境へ戻ります。長い複数枝を独立に改行する描画、循環グラフ、未解決の前方参照は採用しません。直列表記も使えます。

## 実装と拡張

文書APIは[WritingReader](../../scripts/concept2_writing.py)で、`encode_record` と `read_svg` を備えます。[採用版テスト](../../tests/test_concept2_release.py)には小さな図形往復例、[組立てテスト](../../tests/test_concept2_assembly.py)には長い枝の例があります。リポジトリ内のAPIであり、汎用GUIエディタではありません。二作品は記録済みの補正生成器と同じ採用復号器を使い、入力は[出版記録](../../data/two-work-publication-v1.json)で選択します。

基本宣言・型付き定義・別綴りは使用前に導入します。未宣言、重複名、綴り衝突、前方参照、循環を拒否し、失敗した記録を辞書へ追加しません。固定字形は501種です。新語は既存の根列で作れますが、新しい単一字形の割当てには字形表と復号規則の版更新が必要です。
