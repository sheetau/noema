# 証拠と完成範囲

[English](../guide/evidence.md) · **日本語** · [文書一覧](README.md)

Noema 1.0は2026年11月5日に確定しました。完成範囲は、型付きの合成、語彙拡張、作用域の保持、復号可能な円文字によって明示的な意味を記述することです。構成原理と確認した区別によって、意図した自然言語相当の意味表現幅を備えると判断しています。考え得るすべての自然文に対する網羅証明ではありません。

[完成版の選択記録](../../data/language-release-v1.json)が基準を選びます。言語の完成版1.0は、構文版0.14・0.15・0.16を改番しません。このガイドは公開説明を整理したもので、保存済み完成版と証拠は固定したままです。

## 三つの別の確認

| 問い | 証拠 | そこからは言えないこと |
| --- | --- | --- |
| Noema文が意図した原文の意味を保持しているか | 明示した読み・語義規約・参照・対照例に基づく項目別判断 | 独立査読や同義性の自動証明 |
| 構造変換で文を保持したか | 正規化構文・束縛・語義・参照先の一致 | 変更された文への新しい意味判断 |
| 可視の表記から読み戻せるか | 公開辞書と実SVG図形からの復元を、確認済み構文と比較 | 任意画像・手書きのOCR、見た目だけによる意味の正しさ |

構文解析・型検査・有限モデルの診断は、それぞれの層の特定の主張を支えるもので、互いに置き換えられません。復元構文・語義・参照先が同じなら、既存の原文判断を継承できます。意味や関連する参照先が変われば、型の一致やハッシュ更新で審査を代用できません。

## 確定した成果

- カント20単位、アインシュタイン282単位の二作品全文。主な主張は計402で、補助主張と原文対応を含みます。
- 共通カタログ1,952項目。基本宣言1,489と定義463を分け、作品内参照補助27項目を識別します。
- 36分野への合成の対応付けと、作用域・確率・解釈・意味境界の対照。
- 二作品10,946記録、以前の辞書1,909記録、共通構成148記録、追加195記録の保存済み図形復号証拠。成果物の記録数であり、重複しない語数ではありません。

[二作品の出版報告](../../reports/two-work-final-publication-v1.json)、[一般言語の完成記録](../../reports/general-language-completion-v1.json)、[意味境界の完成記録](../../reports/semantic-boundaries-completion-v1.json)、[完成版の照合](../../reports/language-release-v1.json)を参照してください。固定した内容と実装の一致を確認して、以前に実行した検査を継承する結果もあります。変更のない検査をすべて再実行したという意味ではなく、個別報告に継承範囲を記録します。

二作品の意味判断は、記録した読みの下でのアシスタント判断であり、独立した審査ではありません。人の読みやすさ、実際の会話から生じる効果、暗黙の意図の自動推定、自動翻訳は完成範囲外です。未知の経験的意味には説明と解釈入力が必要です。数学や科学の文を記述できても、その真理・決定可能性・無限領域での実行可能性を保証しません。

## 保存した完成版を照合する

別途保存した描画済み完成版がある場合、同梱の標準ライブラリだけの検証器で、ファイルの存在と内容ハッシュを照合できます。

```sh
python -X utf8 output/noema-1.0/scripts/verify_language_edition.py --root output/noema-1.0
```

別の場所へコピーした場合は、その完成版のルートで実行します。

```sh
python -X utf8 scripts/verify_language_edition.py --root .
```

これは保存スナップショット用であり、任意のGit checkoutに対するコマンドではありません。意味判断を再実行するものでもありません。Gitで配布する範囲は[作品ガイド](works.md)、スナップショットの内容は[固定ハッシュ一覧](../../data/language-release-lock-v1.json)を参照してください。

1.0以後に語彙・構文・字体を変更する場合は、その版に対応する証拠が必要です。元の判断と入力を保持し、古いハッシュを書き換えて新しい文書が検査済みに見えるようにしません。適切な検査範囲の選び方は[開発への参加](../../CONTRIBUTING.ja.md)で説明します。
