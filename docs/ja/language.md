# 言語ガイド

[English](../guide/language.md) · **日本語** · [文書一覧](README.md)

Noemaは型付きの式、名前付き定義、明示的な作用域から意味を組み立てます。このガイドは1.0で使う利用者向けの規則をまとめたものです。表は短縮テキスト記法で、`EXPR` や `T` などの模式的な名前は説明用の仮置きです。

## 値と型

| 型 | 意味 |
| --- | --- |
| `a` | 個体。抽象的対象も含め、文書が扱う非空の対象領域の要素 |
| `b` | 厳密な有理数 |
| `c` | 真理値。真または偽 |
| `d` | 状況。非空の事例・状態領域の要素 |
| `e` | 内容。状況ごとに真理値を対応させるもの |
| `f` | 発話。主張・質問・働きかけの働きと内容の組 |
| `h[T …] R` | 順序付きの引数型から結果型Rへの関数 |
| `g[T …]` | 指定した型の順序付きの組を答えとする質問 |
| `i[T]` | 型Tの閉じた式の記述。評価層0 |
| `i b[T]`, `i c[T]` | 評価層1・2の記述。他の層も同じ数表記を使う |
| `j[T]` | 型Tの有限列。順序と重複を保持する |

型は入れ子にでき、関数・記述・列も引数として渡せます。関係は真理値を返す関数であり、すべての文を同じ役割数に揃える文法ではありません。宣言された関数は指定した領域で全域的です。部分性は適用条件と候補関係で表し、仮の既定値で埋めません。

領域内の個体として参照できても、現実に実在すると主張したことにはなりません。物語の人物や設計中の家は、枠組みと実在条件を別に持てます。同様に、型 `d` の状況であることだけでは物理的な可能性を認めません。

## 文書と再利用できる定義

構文0.16は `p:` で始まり、宣言・定義を文より先に置きます。

| 形 | 意味 |
| --- | --- |
| `r NAME[T …] R.` | 基本記号の引数型と結果型の宣言 |
| `d NAME[x T …] R[EXPR].` | 型付き引数を持つ式による定義 |
| `s[PROP].` | 真理値を返す命題の主張 |
| `q[PROP].` | 命題の真偽を問う |
| `q[QUESTION].` | 型付きの答えを求める質問 |
| `l[MESSAGE].` | 発話の言語的な働きを実行する |
| `a[PROP][STATEMENT. …].` | 明示した仮定の範囲内で述べる |

宣言の解釈は別に説明します。定義は以前の意味を再利用するもので、定義に当てはまる対象の存在を主張しません。名前の重複、未宣言語、前方参照、再帰定義は拒否します。繰り返す過程は関係と制約でも記述できます。

次は局所的に意味を説明した基本記号を使う完全な文書です。固定した文脈で、`aa(x)` を「xは人」、`ab(y)` を「yは本」、`ac(x,y)` を「xはyを読んだ」と解釈します。

```text
p:
r aa[a] c.
r ab[a] c.
r ac[a a] c.
d ba[x a] c[g y a[w[k ab[v y]][k ac[v x v y]]]].
s[f x a[y[k aa[v x]][k ba[v x]]]].
```

`ba(x)` は、xが何か本を読んだことを表します。文は各人にその性質があると述べ、全員が同じ本を読むことは求めません。時点、言語、「読んだ」の解釈を解析器が推定するわけではありません。より詳しく表すときは、状況と必要な条件を明示的に渡せます。

## 式と作用域

| 形 | 意味 |
| --- | --- |
| `v x` | 最も内側にあるxの束縛を使う |
| `k NAME[EXPR …]` | 宣言済みの語へ順序付き引数を適用する |
| `e[A][B]` | 同じ型の値の同一性 |
| `u[P]` | 否定 |
| `w[P][Q]`, `x[P][Q]` | 論理積、包含的論理和 |
| `y[P][Q]`, `z[P][Q]` | 実質含意、同値 |
| `f x T[P]`, `g x T[P]` | 型T全体への全称量化、存在量化 |
| `p NAME` | 宣言済みの関数を値として参照する |
| `i[x T …][EXPR]` | 型付き引数を持つ関数を作る |
| `c[FUNCTION][ARG …]` | 関数値を適用する |
| `b w[P]` | 状況wを束縛して内容を作る |
| `t[CONTENT][SITUATION]` | 指定した状況で内容を評価する |

演算子の役割は固定されており、同じ文字も括弧と構文上の位置で区別できます。呼出しの括弧は引数列全体を囲み、二項論理演算では各引数を別々に囲みます。自由変数と型違反は拒否し、正規化による束縛名変更でも参照先を保持します。

`∀x ∃y` と `∃y ∀x` の作用域は異なります。[導入例](getting-started.md)を参照してください。実質含意そのものは因果・時間順・反事実を意味しません。意図した意味に必要な関係と条件を別に与えます。

内容は状況ごとの真偽を表します。今ここで真偽が同じでも、二つの内容が同一とは限りません。全状況で真偽が一致すれば型 `e` では同一となるため、表し方の違いが重要なら記述値も使います。内容式へ渡した真理値の引数はその値のままであり、各状況で評価し直す式には変わりません。

## 発話、質問、引用

`j s[CONTENT]`、`j q[CONTENT]`、`j m[CONTENT]` は主張・質問・働きかけの発話を構成し、`o[MESSAGE]` は内容を取り出します。構成しただけでは発話を実行しません。`l[MESSAGE].` は言語的な働きを実行しますが、現実の窓を閉めたり、制度上の権限を与えたり、社会的な受領を保証したりするものではありません。

`j v[FUNCTION]` は真理値を返す関数から型付きの答えを持つ質問を作り、`h[QUESTION][CANDIDATE …]` は順序付き候補の組を判定します。条件を満たす対象を尋ねても、その存在や答えの一意性を主張しません。

| 形 | 意味 |
| --- | --- |
| `r[EXPR]` | 閉じた式を評価せずに記述する。層0 |
| `r b[EXPR]` | 層1で記述する。高い層も同じ数表記を使う |
| `s[DESCRIPTION]` | 記述された式を明示的に評価する |
| `o a[FUNCTION-DESCRIPTION][ARGUMENT-DESCRIPTION …]` | 関数適用の記述を構成する |
| `o r[DESCRIPTION]` | 入力された記述を引用する記述を構成する |

引用は独立した束縛環境を持ち、周囲の文から自由変数を捕獲できません。誰かに帰属させる内容の内部へ束縛対象を結ぶときは、閉じた関数記述と型付き引数値を組として保持します。対象の値を渡すことと、その対象の記述を渡すことは別です。

記述の同一性は現在の真偽だけでなく、正規化構文を保持します。二つの名前が同じ対象を指しても記述は異なり得ます。記述合成は引数の型を検査し、入力の最大層を保ち、記述された適用を評価・簡約しません。

引用内部の評価は下位の層を対象とします。参照先の定義を検査し、高階の評価経路には実行時の制限も適用します。この規律と実行予算によって、一般的な無矛盾性・停止性を証明したとはしません。当初の0.15試作文書には以前の制限が記載されているため、採用動作は固定版と現在の実装を参照します。

## 数と列

`n p NUM DEN` は非負の有理数、`n u NUM DEN` は負の有理数です。数の字面は32進法で `a = 0`、`b = 1`、`c = 2`。`n u b c` は−1/2です。厳密に約分し、分母0、浮動小数点リテラル、余分な先頭ゼロは拒否します。

| 形 | 意味 |
| --- | --- |
| `l[T][ITEM …]` | 有限列。`l[T][]` は空列 |
| `d[SEQ]` | 長さ |
| `a[SEQ][INDEX][VALUE]` | 0始まりの整数位置INDEXにVALUEがあるか |
| `m[LEFT][RIGHT]` | 同じ要素型の列の連結 |
| `q[SEQ][INITIAL][STEP]` | 先頭からの集計。更新関数の型は `h[STATE T] STATE` |

不適切な位置では位置関係は偽となり、要素を補いません。空列の集計は初期値を返します。順序と重複を保持します。すべての有限列への量化は記述できますが、有限解釈器でその無限領域を列挙することはできません。

## 意味の区別を保つ

| 区別する内容 | 保持する方法 |
| --- | --- |
| 記述と現実の実在 | 記述と実在条件を分ける |
| 値が不明であることと、値がないこと | 適用条件・候補・候補範囲の完全性を記録する |
| 選択肢と資料の衝突 | 候補と、出所に帰属する両立しない断定を分ける |
| 信念と事実 | 内容や記述を帰属させても、それを真として主張しない |
| 字義と意図した読み | 両方の記述、対応、その解釈を採る根拠を示す |
| 制度上の宣言と実効 | 同じ行為に権限・手続・前提・結果を結ぶ |
| 有限標本と上限を固定しない過程 | 一般関係や量化した制約を述べ、検査した事例で全領域を置き換えない |

基本の真理値は二値のままです。記述への肯定・否定の支持を別の関係として記録するため、矛盾した資料を持っても、文書自身が矛盾を主張する必要はありません。モデル入力の欠損を偽で埋めません。

上限を固定しない有限到達は、辺をすべて含む任意の推移的関係への量化で定義できます。無限の番号付き過程は関数と後続条件で記述できます。自己言及は記述に関する制約として表せ、解がないことを偽と評価されたことにはしません。これらを記述できても、機械的に解けるとは限りません。

実装では構文深さと型階数の上限を128、円文字の複合語名を24根に制限します。これらの資源上限は、不明な答えを補う意味規則ではありません。拡張規則は[語彙](vocabulary.md)、検査範囲は[証拠](evidence.md)を参照してください。
