# 語彙と定義

[English](../guide/vocabulary.md) · **日本語** · [文書一覧](README.md)

[1.0の共通カタログ](../../data/general-language-catalog-v2.json)は、基本宣言1,489項目と合成定義463項目、計1,952項目です。以前の1,909項目に意味境界の43定義を統合しました。項目数は辞書の収録数であり、表現力の点数ではありません。

| 再利用区分 | 項目数 | 使い方 |
| --- | ---: | --- |
| 共通語 | 375 | 語義・型・順序付きの役割・文脈を保持する |
| 共通追加 | 62 | 確率・解釈・意味境界の合成を再利用する |
| 分野別の意味規約 | 1,488 | 単位・尺度・制度・比較域など、必要な条件を保持する |
| 作品内参照補助 | 27 | 固定事例の対象を指す。参照先を汎用概念として流用しない |

## 項目を読む

カタログの `entries` は名前から宣言・綴り・語義・出典へ対応します。主なフィールドは次のとおりです。

| フィールド | 内容 |
| --- | --- |
| `declaration` | 基本記号の型、または型付き引数・結果・本体を持つ定義 |
| `spelling`, `symbol` | 根による綴りとテキスト記号 |
| `meaning`, `roles` | 語義と順序付きの引数役割 |
| `context`, `contrast` | 必要な条件と保持する区別 |
| `sources` | 項目を支える原本ファイル |
| `portability`, `usage` | 再利用区分と制約 |

固定カタログの語義・役割説明は**日本語の原記録**です。英語ガイドはその使い方を説明しますが、新しい翻訳で意味規約を置き換えません。過去の意味判断データも同様です。機械可読の名前・型・定義は、どちらの言語の文書でも元の形を保ちます。

例えば `above` は、個体二つを取り真理値を返す基本記号です。指定した空間的な上下軸と比較方法で、第1対象が第2対象より上にあることを表します。接触・支持・順位の優越は含みません。位置と時点も文脈に関わり、引数の型が同じでも交換すれば意味が変わります。

モデルや台帳を使わずに項目を読む例です。

```python
import json
from pathlib import Path

catalog = json.loads(Path("data/general-language-catalog-v2.json").read_text(encoding="utf-8"))
entry = catalog["entries"]["above"]
print(entry["declaration"])
print(entry["meaning"])
print(entry["roles"])
```

## 新しい概念を導入する

1. 必要な対象・状況・引数の順序と役割・型を決めます。
2. 既存の定義を探し、その条件を保って組み合わせます。
3. 合成できる部分をNoemaで定義します。残る経験的関係や文化規約には、何を認め、何を認めず、どの文脈を使うかを説明します。
4. 小さな対照例を確認します。参加者・時点・記述・作用域を変えたとき、意図した意味の違いが残るかを調べます。

新しい制度なら、参加者・役割・成立手続・義務・時期などが必要になります。感覚なら経験者と経験を区別する条件が必要で、物理量へ還元することまでは求めません。どちらも名前を付けただけでは説明になりません。

原文の一文の結論だけを判定する基本語を設けたり、原文を引用文字列として保存しただけで意味を合成したことにしたりしません。定義は別の文でも同じ意味で再利用できるものにします。

## よく使う合成

**確率。** 有限確率は、重複のない事例列、非負の有理数の重み、総和1から構成します。事象の確率は条件を満たす事例の重みの和です。条件付き確率は条件の重みが正の場合に限り、0で既定値を補いません。未知入力を拒否します。無限分布には測度などの条件を明示し、有限標本を全体の代用にしません。[確率の規約](../../data/general-probability-basis-v1.json)と[対照例](../../data/general-probability-contrasts-v1.json)を参照してください。

**解釈と社会的行為。** 比喩は源と先の特徴・対応・字義・意図した記述・読みの根拠を保持できます。皮肉を、偽の字義の単純な否定へ限定しません。謝意・約束・助言・制度上の宣言は、特定の行為へ参加者・内容・規約・条件を結びます。基本発話の三種だけで社会的な成功は決まりません。[語用の規約](../../data/general-pragmatics-basis-v1.json)を参照してください。

**実在と情報。** `actualtargetwitness` は記述された性質と同じ状況での実在を結びます。`uniquevalue…`・`missingvalue…` は適用条件と完全性を保ち、列版は有限候補を扱います。`reportedsupport` は出所付きの支持を記録し、`valueconflict…` は関連する値の一意性も要求します。それぞれ別の構成であり、「不明」を示す交換可能なラベルではありません。[意味境界の定義](../../data/semantic-boundaries-basis-v1.json)を参照してください。

**束縛された内容。** `boundcontent…` は閉じた内容関数の記述と型付き引数値を組にします。`boundcontentholds…` で初めて、その値と指定状況で評価します。引用内に自由変数を捕獲せず、有限の型付き引数列へ一般化できます。

作用域と型は[言語ガイド](language.md)、これらの構成検査と新しい翻訳の意味審査の違いは[証拠ガイド](evidence.md)を参照してください。
