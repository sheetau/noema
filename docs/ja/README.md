# 文書一覧

[English](../README.md) · **日本語** · [Noema](../../README.ja.md)

読者と開発参加者のためのNoema 1.0のガイドです。英語を標準とし、各ページから対応する日本語版へ切り替えられます。

1. [導入](getting-started.md)：小さな例を実行し、利用できるツールを知る。
2. [言語](language.md)：型付きの意味を組み立て、テキスト記法を読む。
3. [円文字](writing.md)：採用した描画規則と復号の範囲を知る。
4. [語彙](vocabulary.md)：カタログを読み、既存の意味を変えずに拡張する。
5. [作品と例](works.md)：本文、例文、読書版を探す。
6. [証拠と完成範囲](evidence.md)：完成の主張と検査結果を区別する。
7. [開発への参加](../../CONTRIBUTING.ja.md)：変更対象を絞り、対応する層を検査する。

## 版と過去の記録

言語の完成版は **1.0** です。構文版 **0.14〜0.16**、Pythonパッケージの版番号は、それぞれ別のものを識別します。[完成版の選択記録](../../data/language-release-v1.json)が固定仕様と証拠を選択します。

`docs/` 直下の版番号付き日本語文書には、当初の仕様、意味判断、開発報告があります。証拠がその内容を参照しているため、元のパスとバイト列を保存します。「試作」という題名や、その後に解決した残件も当時の記録です。導入には現在のガイドを、確定版の選択には完成版の記録を使います。

[当初の完成記録](../language-edition-v1.md)と[円文字仕様の原本](../circle-writing-v2.md)は、日本語の保存資料です。利用者向けの現在の内容は両言語のガイドへ整理しています。過去の判断記録の書き換えや、すべての審査記録の翻訳は行いません。辞書の語義も元の日本語を保存しています。[語彙ガイド](vocabulary.md)を参照してください。

保守担当者向けの手順は、日本語の[WORKFLOW](../WORKFLOW.md)、[台帳の管理](../project-records.md)、[長時間処理](../long-jobs.md)に残します。これらは非公開の引き継ぎDBと証拠の維持に関する手順であり、Noemaを読む・構文解析するための前提ではありません。
