# 対称性の脚注から最終六式へ

u0167–u0172と著者脚注u0282を一つの意味依存群として扱う。本文は、さらに対称性から係数の偶性が従い、したがって係数は1となり、式は最終六式になる、と提示する。脚注は、その対称性を考える一つの仮定例として、五成分が零でNだけが非零の場を挙げる。

実装前に、対称性を理由とする帰結、係数の同一参照、積1と偶性を用いた値1の提示、最終六式、脚注番号、例示、仮定、明白さ、符号反転の必要性を要件として整理した。sbe2/sbf2の同じ点での場の条件と応答、sar2/sat2/sau2の数式内容、ejrjの必要性、eisn2の対称性の理由、zdgの明白さ、eir5の例示、eisfoの著者脚注参照を再利用する。新しい基本関係は追加しない。

脚注の比較では、同じ旧系の同じ領域内の同じ点でX=Y=Z=L=M=0かつN≠0とする。場全体を一様に限定しない。同じVとNを保ち、vを-vへ変える。直前の変換規則から求めるY′は-ψ(v)β(v)(v/V)Nであり、反転後は-ψ(-v)β(-v)(-v/V)Nとなる。旧系の同じ出来事で比較するため、新系の数値座標を両速度で一致させる必要はない。

原文の「数値を変えずに符号を変える」は、大きさを保つという読みを採る。反対符号だけでも絶対値の一致だけでも足りない。非自明な比較のv≠0と非零N、先行する積1を背景にする。v=0にはこの符号反転例を適用せず、係数の偶性が同じ引数の恒等になることを別に保つ。

ejvfは現在の共通係数付き六式・積1・仮定例を合わせ、ejvgは応答、ejvhは非空の全仮定状況で応答が必要だという内容である。応答の成功や係数の偶性を仮定状況の選定条件にはしない。ejvqはその必要性を著者に帰属し、対称性を理由として明白だと提示する。ejvrは本文の理由箇所と脚注1)を結び、同じ内容を具体例として位置付ける。

本文の偶性ejviから積1と合わせたejvjへ、係数1のejvkへ、最後に現在の物理的な両場を保持する六式ejvmへ進む。これらの帰結を著者の提示としてzcで接続する。積1と偶性だけでは-1も残るため、その二条件を処理系が値1の十分条件として認定しない。正値や連続性を原文に補わず、既存の負の枝の反例を保存する。著者の推論を欠落なく記述することと、その推論の数学的な妥当性は区別する。
