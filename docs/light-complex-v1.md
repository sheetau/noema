# 移動する光の領域と体積・エネルギーの比

アインシュタイン論文§8の、光とともに移動する球面、別の基準系での同時刻の断面、体積比とエネルギー比を記述した。既存の座標変換・横波振幅・周波数の定義を使い、原刊913–914頁の5式へ部分的に対応させた。

## 同じ領域の座標変換

光速度をV、方向を単位ベクトルn=(a,b,c)、半径をRとすると、球面の条件は

\[
(x-Vat)^2+(y-Vbt)^2+(z-Vct)^2=R^2
\]

となる。`secb`がこの表面、`secc`が境界を含む内部を表す。半径と光速度は正、方向は単位ベクトルであることを要求する。球面を指定しただけでは、光やエネルギーがそこに属することまでは主張しない。

`secd`は既存の逆ローレンツ変換を使い、新しい四座標から元の球面条件を評価する。`sece`はその新しい時刻を零に固定する。旧時刻を零に固定してから空間座標だけを変換する操作とは異なる。

速度比をr=v/V、βを既存の正の係数とすると、新時刻零の断面は

\[
\{\beta(1-ar)\xi\}^{2}+(\eta-b\beta r\xi)^2+(\zeta-c\beta r\xi)^2=R^2
\]

である。`secf`が左辺、`secg`が有効な引数と等式を要求する条件を表す。原刊のM0359に対応し、座標を合成して作った`sece`との一致を具体例で検査した。一般の実切断上の演算法則を機械的に証明したという意味ではない。

## 体積の変化を含めたエネルギーの条件

既存の周波数係数をD=β(1−ar)とする。許容速度と方向余弦のもとではDは正になる。`sech`は正の二体積に対してDS′=Sを要求する。これは原文の体積比の式を条件として記述したものであり、球と楕円体の体積を空間測度から構成した証明ではない。

`seci`は次の条件を同時に指定する。

- 既存の振幅変換により、A′²=D²A²である。
- 体積はDS′=Sを満たす。
- 同じ正の換算係数Cについて、CE=A²S、CE′=A′²S′である。
- エネルギー・二乗振幅・体積は正である。

これらからE′=DEが導けることを有理数の多項式として検証した。この結論は`seci`の前提に含めず、別の`secj`として記述する。`seck`では、同じ速度と方向で周波数もν′=Dνを満たす。`secl`は前向き平行方向a=1での正の平方根の式に対応する。

原刊のCは8πであるが、今回の定義ではCを正の共通係数として残した。πの構成、光エネルギー密度の物理法則、空間積分、球と楕円体に共通する体積測度は未完である。二つの式から共通係数が消えることと、その係数の意味を説明できたことを区別する。

比には正の分母を要求する。零振幅を持つ場は既存の定義で扱えるが、零エネルギー同士の0/0を比として認定しない。観測者・単位・基準系・同じ光の集合への帰属、球面をエネルギーが横切らないという主張、その帰結の談話も未記述として残す。

## 検査と保存した文書

有理数の代数では、中心とともに移動した際の二乗距離、逆変換による新時刻零の式、Dの正値性、平行方向の正の平方根、エネルギーの残差の恒等式、エネルギー比、エネルギーと周波数の比の一致という7項目を検証した。体積を不変とする値、エネルギーをD²倍とする値、負のβを使う値には反例を得た。

実数の定義を使う具体例では、四則演算と平方根だけを、登録した有理数切断の厳密な演算へ置き換えた。75例で移動球面・変換後の断面・陽に書いた楕円体の結果を比較し、表面45例、内部を含めて60例が成立した。新時刻が零でも旧時刻が零にならない例、表面ではない内部の点、外部の点を含む。無効な半径・方向・速度など6例を拒否した。

エネルギーでは、符号付き速度・方向・共通換算係数を変えた30例を検査し、体積・二乗振幅・周波数を取り違えた例や零・負の値を含む13例を区別した。平行方向の6例では負の平方根を採用しない。定義域外の演算が返す仮の値を0と17に変えても、無効な速度等の拒否は変わらない。元の切断定義を抽象化せずに有限解釈へ渡すと、有理数全域の量化で停止する。

原刊PDFの913–914頁を画像で確認し、5式の符号・二乗・根号・分子と分母を照合した。今回の対象式に電子テキストの訂正は追加していない。[照合記録](../data/light-complex-facsimile-v1.json)にはPDF・画像・式のハッシュを保存した。全頁の意味確認を終えた記録ではない。
