# 法の改善についての自分の考え

第九段落第二文の自分の理性の公的使用、よりよい定式についての思想、世界への公的提示を結ぶ依存群である。率直な批判と全臣民への許可、危険・洞察・全文提示はまだ接続しない。

改善の課題は、同じ統治者・人民・共同体・比較元の法と定式・評価観点を固定し、改訂法と新定式を引数に残す。両方の全法内容と表現、改訂の方向を保持して適切さを比較する。同順位を改善とせず、数値尺度・唯一の最良案・採択の新しさは要求しない。

本人の思想は、この同じ課題について保持する見解として読む。すべてが完成した特定案への賛成であるとはしない。改善の条件・限界・方法についての内容や、特定案を退ける内容も扱う。実際に成功する改訂案があるか、見解が客観的に正しいかは、本人がその見解を持つことと別である。各項目の全命題内容は既存のNoema内容供給へ結び、題名だけで済ませない。

その同じ内容を、本人が一つの活動で自分の理解力を使い、学識者の立場から全読者公衆へ本人名義で示す。実行には少なくとも一人の人間への提示を要求するが、全世界の受領・理解・賛同は加えない。前段落の審査目的はこの文に明記されないので継承しない。

非空の任意有限列で複数の見解を一つの発表候補に束ねる。各項目が同じ本人・活動・立法課題を共有することを検査し、別人の判断や別活動の発表を寄せ集めない。十対象の束縛と項目列を保つ引用を作り、後続の許可時点に現在の判断保持や実際の発表を前提として持ち出さない。

検査では比較16通り、全参照、誤りうる自分の見解と公的提示の下位定義、複数項目の同一活動、直接・引用した十対象の結合、未知拒否と往復を確認する。法の全条項・定式の構成は固定された依存群報告を再利用し、境界を記録する。これを第二文全体の意味一致や現実の法案の優越の証明とはしない。
