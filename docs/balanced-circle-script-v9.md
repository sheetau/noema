# 接続の比率と局所的な縦並び・試作09

試作08では独立した半径線を107主部中1個まで減らしたため、利用者の求めた「他の接続が相対的に増える」という範囲を越えて、形の変化が乏しくなった。今回は半径線を戻し、中心終端・中心線なしと併用する。通常文六例、カント三欄、アインシュタイン二式、大円の斜線の確認欄は一枚の `output/alphabet-circle-v9/overview.png` に収める。

## 接続の比率

今回の107主部では、半径線36、外から中心で止まる接続32、中心線なし31、文頭の導入線5、円周始点の斜線3となる。半径線は引用・束縛・否定・内容境界・関数参照・単項述語や演算子などの構造で使い、向きは従来どおり構文上の役割と周囲の幾何条件から選ぶ。中心終端と中心線なしを合わせた数は半径線より多いが、半径線を少数例に押し込めない。例文中でも八方向が出現する。

形をランダムに振る処理や、円・構文要素の削除は行わない。円周・中心の重なりの抑制、大円の二種類の45度線、近接・直角入射・中心の接続条件は試作08から維持する。

## 縦方向を使う範囲

同じ構文上の親を持つ隣接した原子的な項に限り、二つの円を同じ横位置で縦に置く候補を追加した。既存の側枝・内包・円の交差を持つ項、連続する三段の積み重ね、短い文全体の組み替えには適用しない。罫線間の距離から両円の半径を引いても最低間隔を確保できる場合だけ採用する。

候補が横幅を節約し、文全体の上下の重さと既存の接続条件を満たす場合に限り選ぶ。今回の採用はカント②の二箇所で、同じ比率・語彙・字形規則で縦並びを無効にした場合に比べ、横幅は4603.4から4536.5へ約1.45%短縮した。読みの対象、構文要素、参照を省いた短縮ではない。

折り返しでは縦にまとめた二項を一単位として扱い、途中で円を切らない。全体の接続、全ての元の出現位置との対応、円数と線の総延長を確認する。まとめた二項を交換すると形が変わることも検査する。

## カントが長い理由

原文は `data/public-first-sentence-reading-v1.json` が対応づけている、第四段落第一文である。①②は、この一文について既に作成・判断された形式記述の表示。自然言語の語をそのまま字形へ置き換えたものではなく、採用した解釈の下で関係を明示する記述になっている。

| 一覧の欄 | 元の構文と役割 |
| --- | --- |
| ① | 現行本文の `r2lg` の主張本体。著者が述べる内容を定義参照で提示し、発話の位置づけを記録する |
| ② | `r2lo` の主張本体。前の個人の場合との対比、強調、自由を残す条件、発話・引用内容の関係などを明示する |
| ③ | ②に実際に現れる `r2ll` への参照を展開した補助表示。後半の量化を見せるための再掲であり、原文の追加の一節ではない |

「aber」「ja」「nur」などの語が担う関係や、同じ公衆を指すこと、条件の範囲と程度などを明示するため、普通の訳文より構造が増える。これに加え、現在の描画器は参照・引用・引数の構文を細かく図形化するため長くなる。③も別に掲示している。この全量が一文を表すために不可避な最短長という意味ではない。

一方で、全ての依存定義を展開した長さでもない。共有する語義・定義は別に保持し、①②では多くを参照する。短い日常的な表記、完全な明示記述、説明用の定義展開をどう表示し分けるかは今後の課題。今回、本文や判断を変更せず、一覧に③が補助の再掲であることを明記した。
