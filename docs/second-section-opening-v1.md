# 長さと時間の相対性、二原理への依拠

第二節の見出しu0023と導入文u0024の計201本文文字を扱う。原刊895頁では、長さと時間の相対性という見出しの下に、以下の考察が相対性原理と光速度一定の原理に基づき、その両者を以下で定義するという一文がある。

見出しは第一部に属する第二節の案内として記述する。長さは同じ系で定めた両端の地点間距離、時間は出来事への時刻付与・間隔・同時性に結ぶ。それぞれの量や判定が基準系と測定規約にどう依存するかを主題とし、全ての系対や方向で必ず値が異なるとはしない。具体的な測定方法や変換式を、見出しだけで導出済みと扱わない。

導入文の二呼称は、既出の相対性原理eifjと真空光速度の原理eifyを指す。同じ著者が同じ後続議論の範囲へ両方を仮定として置く採用を保持する。二原理だけから全結論を導出済みであることや、定義・数学的規則を追加利用しないことは要求しない。

「以下の仕方で定義する」は、直後の第一原理の箇所vkと第二原理の箇所wtへ向かう予告として扱う。同じ二内容をそれぞれの定義先へ結び、順序も保持する。この参照を記述することと、後続の定式化が既出内容を忠実に表すかを確認することは別である。後者はu0025以降の全単位判断で進め、既存の部分草案saw/sbdの完成や同値をここで認定しない。
