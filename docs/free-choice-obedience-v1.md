# 議論の自由選択と要求に従う履行

第五段落 `[427,536)` の括弧文に必要な内容として、話題と量を本人の希望に委ねる許可と、同じ出所の要求に従う履行を構成した。既存の独立した試作 `choice-permissions` と `scoped-obedience` の九定義を変更せず現正本へ取り込み、現在の理性使用・言語的検討・規範関係へ接続する。役割、唯一性、発話と対照、著者帰属はまだ未統合であり、一文全体の意味判断は追加しない。

## 二つの内容

`räsonnirt, so viel ihr wollt, und worüber ihr wollt` は、各宛先に望む量と話題で論じることを許す働きと読む。本人が望む話題と程度を独立に固定し、全組合せに活動候補を要求する。同じ範囲の全候補に、同じ出所・本人・立場・実行内容の積極的許可があり、反対要求がない。実行済みの活動だけを候補にしたり、未許可の組合せを希望から削ったりすることは認めない。

候補は既存 `ca` と `h232p` による理性を用いた言語的検討であり、指定話題を扱う関係 `h227z` も要求する。許可の対象記述は既存 `zzq` の本人による活動の実行である。候補の存在と現実の実行・能力を区別する。希望が空の場合は議論を強制せず、原文にない数値的な上限は付けない。

`gehorcht` は、同じ出所に対する政治的・市民的な立場での要求を漏れなく履行し、その要求を自分の遂行を導く指示として扱う読みを採る。[Dudenのgehorchen](https://www.duden.de/rechtschreibung/gehorchen) の、指示に従って行う用法を参照した。既存 `rty` は要求された内容との一致を構成していたが、それだけでは偶然の一致も通る。新しい `r2ud` は、要求の網羅性 `rtx`、妥当な記録と履行 `rtw` に、同じ要求を遂行の指示として扱う `h234b` を加える。道徳的な賛同、内心の無批判、唯一の動機、要求の正当性は追加しない。

基準時の要求と評価時の履行を分ける。評価時に要求がなくなったことを、既に指定した要求の履行として扱わない。記録から要求を消せば、網羅性の条件で拒否する。実行と不実行の両方を求める衝突も、都合のよい片側へ縮めない。

`r2ue/r2uf` は同じ出所・基準の全宛先へ二内容をそれぞれ適用する。`r2ug` は許可方針を述べる発話、`r2uh` は服従を求める命令の族である。許可の真理条件を実際の服従に依存させない。本文の `aber` による対照は、後続の発話構成で別に接続する。

## 検査と限界

許可の検査では、二話題・二程度の全組合せ、組合せの欠落、未許可・禁止、別人・別の出所・別の立場・別の記述を区別する。この有限例を話題や程度の全領域とはしない。

服従の網羅性は、型に合う閉じた内容記述の全域を量化するため、有限評価器は直接の評価を拒否する。検査では元の定義を保存した上で、診断用のコピーに三つのNoemaの引用を代入し、要求の欠落・衝突・別の記述を確認する。実行と指示への従属を変えた16組合せも検査する。有限診断を全記述域の証明とは扱わず、報告に境界を明記する。

服従の内容には記述の脱引用があるため、閉じた発話族の引用には段階1が必要になる。段階1なら基準名・許可・要求・実行・遂行を導く指示が未知でも引用を保持できる。段階0へ落とすことは拒否する。本文へ発話を接続する際にも、既存 `f2` の段階0の引数へ強引に渡さず、この段階を保持する必要がある。
