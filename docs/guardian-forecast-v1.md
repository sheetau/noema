# 任用された後見役の予測と比較背景

第四段落第二文の中核内容を、閉じた主張と比較背景として著者へ帰属する文を追加した。公衆ごとの伝播の枠に、その文脈で指導役が関わる大衆と、任用された後見役の条件を結ぶ。頚木の比喩との接続と第二文全体の再読は残るため、この追加だけで意味確認済みの文として数えない。

## 公衆と大衆の区別

公的議論の読者としての公衆と、指導・監督の対象となる大衆は別の参照にした。[原文](https://korpora.org/Kant/aa08/036.html)の「大勢の人々」を、その文脈の被指導者として言及される人口集団と読む。両者の全員が一致すること、貧困層や特定身分であること、全員が自分で考えられないことは加えない。

`r2m7` は、大衆の全構成員列に重複がなく全員が人であり、人数が固定した文脈下限を超えることを要求する。下限自体は二人以上でなければならない。原文に具体的な人数はないため、背景の人口規模に照らした基準を入力に残す。自己思考者や伝播成功者の人数で大衆の大きさを代用しない。

これは人数に基づく大きさの読みである。Haufenの侮蔑的な含みの強さ、民衆の身分や組織性を数値条件から推論しない。第二文全体の判断では、前後の集団描写との関係も再確認する。

## 職務の内容と任用の履歴

後見役の職務は、その人々への指導・監督を担う公的な責務として構成した。`r2m5` は集団の少なくとも一人の他者について監督の立場を持つ内容、`r2m6` はその活動を担う責務が同じ職務と集団へ制度上委ねられていることを表す。既存の監督関係と公的責務の関係を再利用し、一人の後見役が全ての構成員を監督するとはしない。

その職務への任用は既存 `hzhb` で接続する。過去の一つの任用行為、その出所・本人・職務・時点での委任、評価機会でも委ねられている同じ職務を要求する。任用を表す新しい一般関係の意味規約を明記した。自己申告、現在の活動実績、過去に一度任じられた事実だけで条件を満たさない。

職務の責務を引用することと、その人が現実に監督を行うことは区別する。法的な未成年後見、正当性、本人の同意、特定の任命儀礼も一律には加えない。大衆を単一の法人や一箇所に集まった群衆とする条件はない。

## 各公衆の主張と期待背景

`r2ma`–`r2mc` は、同じ公衆・参照文脈について、大衆の人数条件と条件付き伝播を共用した枠を作る。焦点は任用された後見役、比較対象はその外側である。「後見役にも該当する人がいる」という主張と、そのことが外側の場合より見込みにくいという期待背景を、既存の比較構成で分けて記述する。

この読みは、条件付きの予測内容同士を、著者が提示する期待の下で比較する。数値確率、著者の心理的驚きの測定、外側の該当者の実在は要求しない。同順位や比較不能を、厳密に見込みにくいという差へ変換しない。

公衆ごとに大衆と焦点が異なり得るため、`r2md` と `r2me` で、それぞれの主張と背景を同じ非空の公衆範囲へ量化する。`r2mf` がその二つの閉じた内容を、第二文の箇所・著者・提示文脈へ帰属する。既存の二つの帰属関係と、主張範囲・背景範囲の区別を保つ。帰属時に伝播や任用の世界の事実、期待比較を実行しない。

閉じた呼称は候補なので、`r2mg` で量化した元の公衆・参照状況との一致も要求する。引用の内側で指し先を検査するだけでは、別の公衆に置き換わった後の整合性しか確認できない。検査では、取り違えた先の内容を真に保っても元の公衆への主張・背景が不成立になることを確かめる。

## 検査と残件

検査は人数と下限の組合せ、任用・現在の委任・職務と集団の取り違え、比較背景、各公衆への量化、閉じた帰属、既存の判断と構文往復を対象とする。人数・任用・比較・量化の新しい接続は実行し、伝播本体などの境界は各検査に明示する。既存十三区間と第一文108非空白文字の判断を保持する。
