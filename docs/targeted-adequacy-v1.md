# 不足を評価する対象の明示

カント冒頭の第三文は、他人の指導なしに自分の理解力を使うことに関わる決意・勇気・理解力の不足を対比する。[比較用の電子本文](https://korpora.org/Kant/aa08/035.html)でも、その対象を述べる不定詞句を確認した。旧版のai・aj・akは本人と状況しか引数に持たず、「問題となる行為」を文脈に任せていた。

今回、同じ本人・目標の性質記述・評価状況を取る三つの基本関係を加えた。hzinは決意、hzioは勇気、hzipは理解能力の文脈上の十分さを、その目標に関して表す。特定の単語との対訳表ではなく、任意の目標記述を引数にできる関係である。目標の真偽を実行してから態度や能力を認める方式ではなく、未達成・達成不能な目標についても評価を記述できる。

本文では、三関係の対象をすべて自立的使用bbの性質記述へ固定した。rqqyはその決意の不足、rqqzはその勇気の不足、rqrhは両方の不足、rqriは同じ目標に必要な理解能力の不足を表す。bdはrqrhの成立と、その同じ要因から未成熟bfへの実際の因果寄与を要求し、rqriが実際の原因であることを否定する。要因の真偽と因果関係に渡す引用の両方を更新した。

旧ai・aj・ak、bq・br・bj・bsは保存する。他の文の意味を黙って変更せず、目標が明示されていない判断を新関係へ自動変換しない。既存の定義本体で変えたのはbdだけで、17文の構文も維持した。beとbiを通る離脱・啓蒙の説明は改訂したbdを参照するが、他の段落の目標未指定の評価は今後点検する。

## 検証

二つの目標に対する三つの十分さの全64組合せを、それぞれ独立に扱えることを検査する。目標そのものを評価しようとすると例外になる解釈でも、この六判断を扱える。本文の五条件は32組合せで、固定した引用を直接使うbdと、一般的な因果対比rqqvの値を照合する。

旧版との四比較では、別の目標に対する不足で旧版だけが成立する例と、別の目標では十分でも実際の対象について不足する例を区別する。旧三評価の全8組合せが新条件へ影響しないことも確かめる。評価対象・本人・状況の記録がない場合は未知として拒否し、記録の不在を不足へ変換しない。因果の向きと人物、過程の本人・前後状況、評価範囲の取り違えも対象とする。

本文の引用は層0を維持し、著者による説明の提示時には決意・勇気・理解力や因果を評価しない。通常・短縮・固有文字の往復とCLI解析を確認する。これらは有限検査と構文の検査であり、原文段落全体の意味一致を証明するものではない。

## 署名の確認と残る課題

今回の本文更新で、確認済みの署名hzilの依存する10宣言・各意味規約・本文文・四つの識別表記は変わっていない。署名の読みを再確認し、新版の本文と別添えへ結んだ判断記録を別途登録する。旧版の確認をファイル名だけで新本文へ流用しない。意味確認済み区間数は署名一つのままである。

決意と勇気の不足を連言で読むこと、十分さの程度基準、wennの条件提示と自己責任の意味全体、自立的使用と能力評価の一般的な説明は残る。今回の修正で責任を因果へ還元できたとは主張しない。原文対応範囲も増やさない。
