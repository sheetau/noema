# 救済への全力の営みと暴力的妨害の防止

カント第六段落第十一文後半 `u0013[3489,3644)` に向け、本人の救済の決定・促進への営みと、他人による暴力的妨害、その予防を君主の職責にする内容を構成します。前半との条件・限定・対照、規範源の固定、著者帰属と全文判断はまだ統合していません。[原文AA VIII 40頁](https://korpora.org/kant/aa08/040.html)の7–9行に対応します。

Bestimmungは自分の救済が何から成り何によって進められるかについて本人が見解を定めること、Beförderungは同じ救済の達成に向けることと読みます。同じ生起する活動に本人が参加し、両方を目指すことで営みを構成します。複数段階の取り組みを許し、見解の完成や正しさ、救済の成功を求めません。

「全ての力に応じて」は、本人の固定能力基準に相対的な最大の投入程度と読みます。使える力の全範囲と質的な比較を指定し、その比較の反射性・推移性・比較可能性を検査します。実際の投入程度は既存r2clで尺度内の一意な値と確認した上で、全ての可能な程度以上であることを要求します。他人の能力上限、特定の数値単位、成功量には置き換えません。能力種類間の相互制約を含む総合的な程度という解釈であり、この尺度を原文の唯一の能力理論だとはしません。

保護対象は、固定基準で同じ二目標への取り組みに属する全候補です。妨害を受けた後の能力や実行量に合わせて基準を下げません。すでに必要だと信じた営み、成功した営み、現に実行できる営みだけに限定せず、まだ実行を阻まれている候補も残します。

暴力的妨害は、異なる二人について、加害側が参加する生起活動による被害側への優越的な強制力と、その行使の正当な根拠の不在、同じ被害側の営みへの因果的な妨害を結びます。[AdelungのGewaltthätig](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_2_1_1899)は権限なき力の行使を語義としています。身体的実力だけの草案を改め、正当な公的規律まで防止対象にする過剰な読みを避けました。君主や教会の自己申告だけで力の行使を正当化することもありません。負傷や全面的な不能は要求せず、余分な障害を乗り越えてなお取り組む場合と、全く実行を阻まれた場合を両方扱います。

予防の目標は、同じ君主の臣民の異なる全ての組と全候補について暴力的妨害がないことです。実効的な予防活動は、君主の参加、同じ目標、その成立又は維持への寄与、実際の無妨害を結びます。脅威がすでに起きていることや君主一人による執行は要求しません。その予防を同じ最高統治職の所管とし、同じ本人・職・内容に規範上の要求を結ぶことで職責を構成します。職責の判定では予防内容を実行しません。

検査は、最大でない投入、多値・未評価・尺度外・不正な比較、両目標と成果の独立、加害側と被害側の同一性、妨害下での成功と失敗、全ての臣民の組、目標・寄与・結果、所管と要求、対象列と引用段階を分けて確認します。固定証拠と本文106主張は保持し、意味確認済み文字数は増やしません。
