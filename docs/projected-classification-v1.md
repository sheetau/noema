# 呼称の人物分類と、実際の属性の分離

脚注の敬称付きの人名使用に、男性向けの呼称が示す分類を追加した。これまでの`hzlr`は、同じ名称使用で同じ人を丁寧に指すことを表す。今回の`hzmd`は、その同じ使用に人物分類の描写を結ぶ。描写の使用と、本人が実際にその分類に当てはまるという主張を分ける。

[Adelungの第三の語義](https://lexika.digitale-sammlungen.de/adelung/lemma/bsb00009132_3_1_1987)は、名前などに付く男性向けの敬称と、呼びかけ以外の人物への丁寧な言及を説明する。権限や所有を述べる別の語義をこの箇所へ移さない。後年の辞書の説明を1784年の全慣習と同一視せず、原刊494頁の使用を読むための補助資料とする。年齢や具体的な身分を原文へ追加する根拠にはしない。

`hzmb`は、既存のMendelssohn参照と同一である人物を選ぶ性質である。`hzmc`は、人であることと、文脈における男性分類を結ぶ性質である。両者をNoemaの閉じた記述として、既存の呼称関係`du`と定義`rq`に渡す。人物の選択と呼称の描写を同一視せず、新しい人物・名前・使用箇所は作らない。意味本体に原語の綴りや翻訳用の説明文を埋め込む方式でもない。

男性分類`hzma`は新しい基本関係として明示する。女性分類`da`の否定からは作らず、自然的成人`ka`も条件にしない。分類基準が生物学的な特徴、社会上の扱い、本人の認識、登録のどれに基づくかを、語の使用だけで決めない。この基本分類の詳細な構成説明は残る。今回の合成で、性別や敬称の全意味を説明し尽くしたとはしない。

対象の属性が未知でも、その分類を呼称内で用いたことは記述できる。実際の属性を問い合わせたときだけ、分類の解釈が必要になる。検査では、同じ呼称使用の記述が成立しながら属性判定が真となるモデルと偽となるモデルを両方許す。未知の分類を偽で埋めない。これは呼称から本人の属性や話し手の内心を自動推論しないことの確認であり、Mendelssohn本人について新たな歴史的主張をするものではない。

九つの接続対照で、著者・使用箇所・人物選択・分類記述・文脈を取り違える場合を退ける。紹介記事内での使用だけを脚注自身の使用へ流用できない。既存八文と合わせた七つの同時解釈も検査し、注の接続が欠ける場合と、呼称の分類が欠ける場合を区別する。

既存26文・全意味規約・名称表記を保存し、基本関係一つ、合成定義三つ、一文を追加する。敬称への社会的な扱いの規約、語用論、偶発性・思想比較、脚注全体と二作品全文の意味確認は継続する。既存の原文範囲内の追加なので、草案範囲と確認済み単位数は増やさない。
