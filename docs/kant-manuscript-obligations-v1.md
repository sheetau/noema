# カント最終段落の帰属本文と、未接続の定義

現行の本文を調べると、前回の公的理性使用の許可 `iavclaim` と、それを用いる扱いの基準 `iavtreatment` は、用意した定義と検証用作例にとどまっている。本文の最後の主張からは参照されていない。先に作った `iaustanding` と `iautreatment` も同様である。定義を追加し作例が通ることと、その内容を原文の翻訳に組み込むことは別の工程である。

対象は固定した `kant-1784:u0017` の最後の条件文、原文位置 `[716, 1174)` と著者注の印である。[点検表](../data/kant-manuscript-obligations-v1.json)はこの範囲を14項目に分け、欠落や重複がないことを検査する。この分割は点検した範囲であって、翻訳済みの文字数には加算しない。段落の前半や他の段落について完了と判断するものでもない。

| 確認対象 | 現行本文の状態 | 残る仕事 |
| --- | --- | --- |
| 条件、自然による発展、覆い、芽、思考への志向 | 引用ひな形から候補定義への参照がある | 自然・芽の意味、覆いと制度の対応、完了と程度、同格の接続、読解候補の選定 |
| 自然が最も慈しんで世話すること | 対応する構成をこの点検表に記録できていない | 世話の作用、最上級の比較、同じ芽への対応 |
| 民衆の態度と行為能力の漸進的な変化 | 引用ひな形から因果・変化の候補への参照がある | 原文より強い条件になっていないか、反作用・自由・程度の意味 |
| 政府の原則と自己利益判断 | 同じ主体・原則への部分的な接続がある | 政府の資格、原則の作用を置換に限定する読み、焦点、利益の意味 |
| 人間と機械の対比 | 対応する構成をこの点検表に記録できていない | 機械の説明、数量の大小ではない比較、時間的な位置付け |
| 人間を尊厳に即して扱うこと | 要求・履行・具体的許可の候補が本文外にある | 尊厳の内容を説明し、対象者と扱いを本文の同じ政策へ結ぶ |
| 著者注への参照 | この条件文への接続を記録できていない | 注の印と注本文・対象句を対応させる |

本文の最後の主張は `iatattribution` を呼び出し、その内部で階数2の `iatschema` の関数参照を引用している。この関数には、読み、規範の出所、主体、職務、旧原則、新原則、比較状況、残余条件という八つの引数が残る。関数を引用することは、これらの引数を具体的な値に束縛したことではない。既存の意味規約どおり、これは部分ひな形への帰属であり、完成した条件文の帰属と数えない。

検査器は選択した本文から定義へ至る経路を、引用内部も含めて記録する。別の本文で参照されていても、選択した本文の接続とは混ぜない。参照があることは、評価の実行や意味一致の証明ではない。また、特定の名前へ参照がないことだけで、別の同義表現や動的な引数渡しまで存在しないとは判定しない。意味上の課題と候補の指定は、原文と既存規約を読んだ点検入力である。

今後は、未記述の世話と機械の対比を構成し、尊厳の説明を具体化した上で本文への接続を行う。公的理性使用の許可一つを尊厳全体の代わりに置いたり、既存の原文対応範囲を広げたりして完了扱いにはしない。確認済み単位数は両作品とも0のままである。

再検証は `python -X utf8 -m pytest tests/test_manuscript_obligations.py -q` と `python -X utf8 -m scripts.check_kant_manuscript_obligations --verify-only`。固定した原文・本文・点検表・検査器のハッシュと参照経路は[検査結果](../reports/kant-manuscript-obligations-v1.json)に保存する。
