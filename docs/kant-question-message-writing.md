# 同値・質問・発話の式を読む

既存 native の `iff`、`question`、`answer_matches`、`message`、`message_content` を接続する。質問の意味や発話種別を新しく定義せず、元構文の関数・引数・内容をそのまま復元する。この段階は式の文法であり、文書の `ask`、`perform`、`suppose` は別途接続する。

`iff` は二つの真偽式を既存の二引数順で読む。`question` は一つの真偽値関数を受け取り、その関数の引数型の列が質問型になる。`answer_matches` は先に主列の質問式を読み、その型から回答の数と順序を決める。残りの引数には既存の関数適用と同じ分岐規則を使う。回答数を表す別の見出しや、質問ごとの語は必要ない。引数のない質問にもこの規則を使う。

`message` は発話種別 `assert`、`ask`、`direct` と一つの content を保持する。開始形の中心線の方向で三種を区別し、続く一式を内容として読む。`message_content` は一つの message から content を取り出す。message 自体は変数を束縛せず、内部の content、関数、引用がそれぞれ既存の範囲を保つ。

| 式 | 字形 |
| --- | --- |
| iff | 大円の左円周に中円中心、大円の右下へ外向き終端斜線 |
| question | 大中同心円、中心から右上へ終端斜線 |
| answer_matches | 大円の左円周に中円中心、中心から右上へ終端斜線 |
| message の三種 | 大円の左上・隣段の円周上に小円中心、中心線が assert は右、ask は下、direct は左 |
| message_content | 同じ左上の二円、大円の右下へ外向き終端斜線 |

既存の形・三段・円周直交・最小間隔を維持し、方向を配置都合で回転させない。型検査は既存 native 検査器を使い、質問でない値への回答照合、引数数・型の不一致、内容でない値からの発話生成を拒否する。

実装前の検査計画：同値の二項、零・一・複数回答、回答順交換、質問型の束縛、引用した質問、三つの発話種別と内容取り出しを対照にする。実SVGから元構文へ戻し、不正な型・回答数・枝は実図形でも拒否する。変更しない図形は再描画せず読む。保存定義の同値・発話本体へ接続し、外観は未固定のまま評価する。
