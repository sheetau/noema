# 思考への寄与と、その価値の認識

アインシュタイン論文末尾の謝辞について、相手から得た複数の有益な入力を、その相手の寄与として認める部分を記述する。対象はu0276後半の候補解釈であり、謝辞一文の完成ではない。

## 原文の読みと範囲

原刊921頁の後半は、著者がM. Bessoから価値あるAnregungを得たことを述べる。[原刊画像](https://de.wikisource.org/wiki/Seite:Einstein-Elektrodynamik.djvu/31)と、原文の文字範囲・ハッシュを[読解記録](../data/intellectual-credit-reading-v1.json)へ固定した。demselbenは前半のM. Bessoと同じ参照へ結ぶ。

Anregungには思考のきっかけという用法があり、採用を求める具体的な提案だけには限定されない。[Dudenの語義](https://www.duden.de/rechtschreibung/Anregung)を踏まえ、問いや方向づけも受け取れる入力として扱う。verdankenは起源・原因の帰属を表せるため、金銭の負債や返礼義務を必要条件にしない。[Dudenの語義](https://www.duden.de/rechtschreibung/verdanken)だけから、あらゆる用例に感謝の感情があるとも決めない。

今回の候補では、同じ研究の思考に用いた入力について、著者が肯定的な評価基準を満たすものとしてBessoの寄与に帰す。mancheは少なくとも二つという複数性を採る。多さの程度、過去時制、謝辞としての語用は残る。前半の友人・同僚・忠実な支援と、冒頭の結びの言明は対応範囲へ加算しない。

## 構成

| 定義 | 内容 |
| --- | --- |
| `sewb` | 同じ本人・対象・基準の記述・順序付き引数列に結ばれた判断。候補状況を非空とし、全候補で判断内容を満たす。既存の`rlg`を参照の衝突なしに移した。 |
| `sewc` | 起きた行為を寄与者が行い、その行為から生じた入力を受け手が同じ仕事の思考に用いる。 |
| `sewd` | その受け手がその仕事に関して用いる肯定的な評価基準を、同じ入力が満たす。 |
| `sewe` | 同じ入力・受け手・相手・仕事について、寄与と肯定的評価の両方が成立する。 |
| `sewf`・`sewg` | 上の関係を四引数の内容へまとめ、受け手・相手・入力・仕事の順序付き四個体列へ接続する。 |
| `sewh` | 任意の基準記述について、同じ四引数を結んだ本人の判断がある。基準を指定するまでは寄与についての判断に限らない。 |
| `sewi` | 互いに異なる少なくとも二入力について、その判断がある。二判断記録だけでは二入力と数えない。 |
| `sewj` | 本文で用いる寄与と評価の基準。 |
| `sewk`・`sewl` | 著者・Besso・同じ研究へ結んだ候補内容と、その既知の基準を静的に展開した引用可能な内容。 |

基準記述は引用としての同一性を保持する。同じ真偽を返す別名へ無条件に交換しない。既存の引用規則は変更せず、既知の閉じた基準だけを既存の特殊化処理で展開する。原始関係の解釈を実行して文章を生成する処理ではない。

本人の判断が実際の状況と一致することは要求しない。たとえば、現実にはその相手の寄与がなくても、本人がそう認めている状況を表せる。歴史上の事実の確認と、著者がそう述べたという引用の帰属も別である。本文では先行204文を保存し、引用した主張の帰属を一文加える。

## 未完の点

思考への取り入れ、入力の産出、肯定的評価基準の採用は、まだ解釈を与える原始関係である。今回の構成はそれらの役割と同一性条件を分離したもので、認知や価値の説明を完了したものではない。因果機構、時系列、共同で生じた着想の詳しい構成は残る。

M. Bessoは同じ人物を指す原文ラベルとして記録する。綴りから人物の性質を導かず、独立した命名行為の構成も今後の課題とする。入力に真なる命題であること、相手が唯一の起源であること、命令・採用提案であることは課さない。

有限例の通過はこの謝辞の意味一致や歴史的事実の証明ではない。全文意味確認済みの区間数は増やさず、明示した後半の原文範囲だけを部分草案として集計する。
