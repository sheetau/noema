# 任意形状と同じ物体の三軸寸法

u0116第一文の一般化には、球形を前提にしない占有形状が必要である。全物質点が指定形状に含まれ、指定形状の全有効三位置が同じ物体の点によって占められることをejghで要求する。空洞や離れた部分は形状条件にそのまま残り、凸包や外接球の内部を埋めない。

静止系では、全時刻に同じ形状を占める条件を既存の剛性・静止へ接続する。運動系では、既存stvのβ(x−vt),y,zという代入で得られる形状を、全対象時刻の実際の全物質点へ接続する。少数の表面記録の一致だけで全形状を代用しない。一般の形状条件に全称量化し、球専用の前提は入れない。

寸法は、実際の占有形状を各軸へ射影した集合の上限と下限の差として読む。既存sui/suj/sukを再利用するため、端点が達成されることや連結性を仮定しない。同じ物体の静止系の基準時刻とKの任意対象時刻を比べ、六つの有限幅が定義される場合に、縦幅を√(1−(v/V)²)倍、横二幅を不変とする。零幅も許す。空集合・無限幅へ有限値を割り当てない。

この依存群は332主張と既存の意味判断を保持する。u0116の対照・著者の帰結・速度による比較、光速極限、超光速での適用限界と予告への本文接続は後続である。検査では非連結・空洞の区別例、完全占有の二方向、同じ物体と軸の幅、全時刻と全形状の範囲を扱い、有限例を一般実数域や物理的帰結の証明とはしない。
