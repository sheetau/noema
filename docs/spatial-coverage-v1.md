# 同じ空間を保つ測定配置と三成分の被覆

u0045第一文の空間測定を、両系それぞれの全地点・三成分へ拡張する。原文[0,240)、176本文文字と原刊897〜898頁の照合は[前段の記録](../data/einstein-coordinate-measurement-source-reading-v1.json)を引き継ぐ。今回も本文の設定指示そのものと全単位の意味判断はまだ追加しない。

eixjは同じ点の完全な静止履歴を両側に要求し、同じ系・単位の三位置座標を一致させる。期間は異なってもよいが、途中で動く点を初期値だけの一致で保存したことにはしない。eixkは両側の全正方向記録を比較する。零座標の測定結果だけでは正方向の反転が見えない場合も、この条件で排除する。

eixlはその系自身に静止する実際の物質軸と正方向記録を結び、eixmは同じ原点から出る三軸の剛性・直交・全役割と、唯一の原点を保持する。初期と同じ原点・三軸・物差しを使う。旧eivfは静止系raを固定した初期配置の定義なので、運動系自身に対する静止の条件としてそのまま流用しない。

測定配置の帰属eisndは、同じ思考上の空間測定に使う配置を指定する一般的な入力である。単なる別世界での実施可能性とは区別し、測定結果や全域の被覆は別に要求する。eixnはその帰属に加え、原点・各軸・物差しの個体、全地点範囲、各軸の全物質成員の位置と正方向を保存する。物差しや時計の配置を軸の位置保存に混ぜない。物差しを置き直すことを許しながら、測りやすい別の場所へ対象を動かしてしまう解釈を排除する。

eixoは対象地点そのものの位置保存と、同じ系・役割・値の実測eixhを結ぶ。eixpはそのような測定配置の存在、eixqは配置をまたぐ全有効候補値の一致を要求する。各配置の中だけで値が一意でも、配置を変えた際に違う値が出るなら条件を満たさない。eixrはsgfを再利用して、非空の全地点と三役割の全組合せにこの条件を課す。eixsは異なる両系へ適用するが、Kとkの座標値や正方向を等置しない。

原点・軸・対象の幾何を保存する文脈と、物差しを使う静止配置の文脈を区別する。後者を元の一つの運動履歴の時刻部分区間へ無条件に埋め込まず、同じ思考上の測定構成として接続する。距離比較の内部操作は既存eisef/eisncの長さ比較・移し取り・分割の意味規約を使う。原文にない特定の再配置手順や、任意の実数を有限回で計算できることを追加しない。

検査は各座標・各軸成員・各方向記録・各地点と三成分の欠落を識別する。静止履歴と幾何・測定の境界は既存の検査記録を保持し、接続する全引数を調べる。全実数候補の量化は元のまま有限評価を拒否する。有限モデルを全空間や完全履歴の証明とは扱わない。
