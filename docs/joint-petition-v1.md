# 声を結合して君主へ提出できること

カントu0013第七文の「声の結合によって、全員の声でなくても、一つの提案を王座に届けられる」を構成する依存群です。全文の意味判断はまだ行いません。

`r5fw` は基準点に固定した二人以上の市民集団、`r5fx` はその全員が同じ行為に参加し、同じ内容を自分の声として共同提出することです。集団外の市民の同意を要求せず、全市民が参加する場合も許します。各自の別の投稿や同席だけでは満たしません。代表を通じた提出も、共同行為への参加と全員の支持があれば扱えます。

宛先には既存の `r2uj` を用います。同じ共同体の君主的な最高役職を、任用と委託を伴って唯一の本人が保持する構成です。原文の王座はこの統治上の宛先を指すと読み、椅子や特定の君主名を補いません。換喩の文章上の提示と括弧の譲歩は全文帰属で接続します。

提案内容は段階1の閉じた内容族と対象列・固定文脈です。内部で記述の評価を使う保護内容も渡せますが、提案の成立を検査するときは内容を実行しません。`r5fy` は同じ有効履歴で利用可能な方法の結果の一つに共同提出があることを、既存の `xb` で表します。失敗の結果も併存でき、現実の提出済みや採用・保護の実現を要求しません。

検査では成員の空集合・単独者・市民外・基準点の移動、別々の行為、声や参加の欠落、内容の型と対象列、同じ宛先を確かめます。可能性については空の結果・失敗のみ・使えない方法・別履歴・循環を拒むことを確かめます。共同提出の検査では `r2uj` の接続位置を境界として扱い、その最高位・唯一性・任用・委託は既存の定義を実評価する検査で別に確認します。

公的な洞察がこの提案可能性に足りる条件、具体的な保護と非妨害、期間の到達内容と文章全体への帰属は残ります。本文102主張、登録簿v185、集計v76と確認文字数を保持します。
