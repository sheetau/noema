# 同じK時刻による相対速度とtの消去

u0069–u0072は、kで測る光速Vに続き、Kで測った光とk原点の相対速度V−vからtを求め、その値を先のξの式へ代入する。原刊899頁末から900頁の二式までを照合した。

## 相対速度の接続

ei5wは同じ二時刻の光と原点の位置の差を取り、その増分を速度と経過時間の積へ結ぶ。ei5xはこれを同じ区間の全実数時刻対へ要求する。端点二つで同じ差が得られても、中間で曲がる軌道を一定相対速度とは扱わない。

ei5yは既存ei5aの同じ光線と現在の両系の時計・座標を保持し、同じk原点の全設定内の履歴eizmを接続する。原点は同じ放出出来事でK時刻0・位置0にあり、その後の位置はK時刻でv*tとなる。光線の到達出来事に原点も位置するとは要求せず、同時刻の別の位置を比較する。原点の全履歴と光線区間の一次軌道は同じ物理対象・系・単位へ結ぶ。

相対変位は同じKのxから同じ原点位置v*tを引いたx′である。V−vをkのτで測る速度へ替えず、x′とξも等置しない。先行する正のvとv<V、非退化な光線区間を保持する。

## 帰結と代入の提示

Nun ... aberは、同じ光のkでのVとKでの原点に対するV−vの対照として読む。先の主張の否定や論理的矛盾ではない。共通観点を持つ既存h222qの基本規約を、0.14の閉じた引用型に合わせたeisnpで再使用する。共通観点ei6bは同じ光・始終出来事の二区間を指す。

同じ原点との相対運動を著者の主張として保持し、そこから既存sni/sntのx′/(V−v)=tを得る提示を加える。この同じtの値と先のsnh/snsのξの式を前提として、snj/snuのξ=a*V²*x′/(V²−v²)へ書き換える。Setzen wir ... einは著者の計算提示と読み、実際の実行履歴や読者の参加を加えない。

aは同じ未定φ(v)であり、1や後段の確定係数へ固定しない。光線上の式だけで一般の空間変換を決定せず、横二方向の類推はu0073以降へ残す。

## 検査と判断

有限の対照例は、同じK時刻の使用、全区間と端点だけの違い、原点の履歴と同時刻位置、同じ出来事のt・τ・x′・ξの区別、未定係数を保つ代入、対照と帰結の引用を調べる。全実数時刻への量化は有限評価を拒否する。既存のlongitudinal-light報告の有理多項式補題と、origin-light-ray報告の全光線への接続を保存する。

これらの検査は、一般実数体や物理法則の証明ではない。本文の全体判断は固定原文、原刊画像、採用した読みと式の意味を合わせ、別のレビュー記録へ残す。
