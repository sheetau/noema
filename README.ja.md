# Noema

[English](README.md) · **日本語**

Noemaは、意味を明示的に記述するための独自言語です。円・円弧・線・ドットを接続する書記体系を持ち、型付きの式、定義、量化、引用、質問、言説を組み合わせます。円文字はその構造を表し、図形から同じ正規化構文へ戻せます。

日常の状況、数学、信念、仮定の世界、未知の概念を合成によって記述し、意味として自然言語に匹敵する表現幅を持つことを目指しています。Noema 1.0は、この範囲で言語と採用字体を確定した版です。自動翻訳器や、どんな文でも真偽を決定できる処理系は含みません。

## Noemaの特徴

- **作用域と役割を明示します。** 「全員が本を読んだ」では、人ごとに別の本なのか、全員が同じ一冊を読んだのかを区別します。関係の引数順も意味の一部として保持します。
- **概念を合成し、再利用できます。** 既存の意味から新しい概念を定義します。経験的な基本関係を導入する場合は、その解釈の説明が必要であり、型宣言だけで意味を説明したことにはしません。
- **内容とその記述を区別します。** 対象、その対象についての信念、それを表す引用は、それぞれ別に扱えます。依頼を引用しても、その依頼を実行したことにはなりません。
- **構造に応じて字形を組み立てます。** 分岐、範囲内の共有、反復記号、離れたドットの対で省略しても、束縛先と引数順は保持します。すべての文を同じ視覚的な型へ揃える必要はありません。

例えば「まだ存在しない家を設計している」なら、家の記述を保持しつつ、現実の実在を主張せずに表せます。「値が不明である」と「値が存在しない」も区別します。[言語ガイド](docs/ja/language.md)では、これらの区別とテキスト記法を説明します。

## 試す

Python 3.11以降を使います。構文解析にモデルのダウンロード、APIキー、外部ランタイム依存は必要ありません。リポジトリのルートで次を実行します。

```sh
python -X utf8 -m noema.constructed parse -i examples/intro/scope.noema
python -X utf8 -m noema.constructed format -i examples/intro/scope.noema --notation full
```

最初のコマンドは型検査・正規化済みのJSON文書を返し、次は長形式のテキスト記法を表示します。どちらも文の真偽は評価しません。[導入ガイド](docs/ja/getting-started.md)で、例文、インストール、テキストCLIと採用円文字の違いを説明します。
